Infraの運用が止まったときの再開手順｜順番に戻す

Infra・長期インターン課題別（追加） 更新日 2026/11/4

Infraに長期インターンの求人を掲載したものの、担当者が忙しくなり、募集原稿は古いまま、応募への返信も滞っている。気づけば数か月、運用が止まっていた。こうした状態から立て直したいという相談は少なくありません。結論から言うと、運用が止まったときは、募集原稿を書き直す前に、止まった原因を切り分け、受け入れの体制と応募の対応を先に戻すのが再開の順番です。 原稿だけを新しくしても、応募に返信できる体制がなければ、すぐにまた止まります。この記事では、症状の確認、原因の切り分け、再開の手順、外に出せる範囲を順に整理します。Infraは株式会社Legaseedが運営する、大学生向けの長期・有給インターンの求人サイトです。

運用が止まっているときの症状

運用が止まっている状態は、次のような形で表れます。

  • 募集原稿が、掲載したときのまま更新されていない
  • 応募が来ても、返信までに何日もかかっている、あるいは返信していない
  • 管理画面を開く担当者が決まっていない
  • 面接の日程の調整が進まず、応募者が離れている
  • そもそも、今どの求人が掲載中なのかを誰も把握していない

最初に確かめたいのは、返信していない応募が残っていないかです。応募したまま放置されている学生がいれば、まずその学生に連絡します。遅れたことを詫び、まだ関心があるかを確かめます。原稿の見直しより、この対応が先です。

原因の切り分け｜この順番で確かめる

運用が止まった原因を、次の順で確かめます。

  1. 担当者が決まっていたか：管理画面を見て、応募に返信する人が決まっていたか
  2. 担当者の時間が足りていたか：担当者が他の業務を抱え、運用の時間が取れなくなっていないか
  3. 受け入れの体制があったか：応募が来ても、受け入れる部署や任せる仕事が決まっていなかった
  4. 募集原稿が古くなっていないか：仕事の内容や条件が、今の受け入れと合っていない

一つ目と二つ目は、運用の担い手の問題です。三つ目は、運用の前の受け入れの問題です。受け入れの体制がないと、応募が来ても進め方が決まらず、担当者が返信をためらいます。運用が止まったように見えて、実は受け入れの側が止まっていた、ということもあります。

四つ目の原稿の古さは、最後に確かめます。原稿を新しくすることは大切ですが、一つ目から三つ目が戻っていないと、新しい原稿で応募が来ても同じことが起きます。

止まっていた運用をどこから戻すか、順番の整理から一緒に考えます。相談だけでも構いません。

運用の相談をする

再開の手順

切り分けの結果に合わせて、次の順で再開します。

  1. 残っている応募に連絡する：返信していない学生に、詫びと関心の確認を送る
  2. 担当者を決める：管理画面を見る人と、応募に返信する人を決める。一人で兼ねても、二人で分けても構わない
  3. 運用の時間を決める：担当者が、週のどの時間に運用を見るかを予定に入れる
  4. 受け入れの体制を確かめる：どの部署で受け入れ、何を任せ、誰が日々を見るかを決め直す
  5. 募集原稿を見直す：仕事の内容、勤務の条件、職場の様子を、今の受け入れに合わせて書き直す
  6. 応募から面接までの流れを決める：返信の目安、面接の担当者、日程の決め方を決める

三つ目の「運用の時間を決める」が抜けると、担当者が決まっても、また忙しさに押されて止まります。短い時間でも、週の決まった時間に管理画面を開く習慣を作ります。

五つ目の原稿の見直しでは、受け入れる部署の社員に、仕事の中身を聞き直すことを勧めます。掲載したときから仕事の内容が変わっていることがよくあります。原稿の書き方は長期インターンの募集原稿にまとめています。

エージェントベストの見解

運用が止まった会社の相談を受けて、当社がまず確かめるのは、止まる前に応募がどれくらい来ていて、そのうちどこで止まっていたかです。応募が来ていたのに返信が滞っていたなら、原因は運用の担い手にあります。応募そのものが来なくなって担当者が見なくなったなら、原因は原稿か、募集の条件にあります。この二つは、打ち手がまったく違います。前者に原稿の書き直しで応えても、後者に担当者の増員で応えても、効果は出ません。再開の前に、止まった地点を一つに特定してください。応募の記録をさかのぼれば、多くの場合、どちらだったかが分かります。

外に出す場合の範囲

運用が止まった原因が担当者の時間の不足なら、作業の一部を外に出すことも考えます。

  • 外に出しやすいこと：募集原稿の作成と更新、応募への一次返信、面接日程の調整
  • 社内に残すこと：受け入れの体制の決定、面接、採用の判断、受け入れ後の指導

外に出すときは、社内に残す部分の担当者と時間も、あわせて決めておきます。外に出した作業が回っても、面接や判断が社内で止まれば、運用全体は止まります。

当社はInfraの代理店として、掲載の申し込みや運用の相談の窓口を担っています。運用を再開するときに、どこまでを社内で持ち、どこからを外に出すかを一緒に整理することもできます。

募集原稿の更新や応募対応を外に出し、面接と判断に社内の時間を集める形もあります。範囲から相談できます。

エージェントベストの見解

運用を再開するとき、止まっていた期間を取り戻そうとして、一度に多くの求人を出したり、受け入れの人数を増やそうとしたりする会社があります。気持ちは分かりますが、勧めたいのは、再開の最初は求人を一つに絞ることです。一つの求人で、応募の返信から面接、受け入れまでが回るかを確かめ、回ったら次を出す。運用が止まった会社は、どこかに止まりやすい箇所を抱えています。一度に広げると、その箇所がまた詰まり、同じことが起きます。最初の一つで流れを確かめることが、遠回りに見えて、再び止まらないための近道です。

止まらない形を作る

再開したあとは、また止まらない形を作ります。

  • 担当を二人にする：主に見る人と、代わりに見られる人を決めておく
  • 運用の時間を予定として固定する：週の決まった時間に管理画面を見る
  • 月に一度、振り返る：応募の数、返信の速さ、面接に進んだ数を、担当者と受け入れの部署で確かめる
  • 原稿の更新の時期を決めておく：受け入れの仕事が変わったとき、季節が変わったときに見直す

担当者が不在になったときの対応は、長期インターンの担当社員が不在になったときで整理しています。応募が来ないときの見直しの順番は、長期インターンの応募が来ないときも参考になります。

まとめ

  • 運用を再開する最初の一歩は、返信していない応募への連絡
  • 担当者、担当者の時間、受け入れの体制、募集原稿の順に原因を切り分ける
  • 担当者を決めるだけでなく、週の運用の時間を予定に入れる
  • 再開の最初は求人を一つに絞り、流れが回るかを確かめてから広げる
  • 担当を二人にし、月に一度の振り返りで止まりかけに気づく

よくある質問

長く放置していた応募者に、今から連絡してもよいですか

連絡することを勧めます。遅れたことを詫び、まだ関心があるかを確かめます。すでに他の機会を見つけている学生もいますが、返信がないまま終わるより、会社の印象は保たれます。

募集原稿は全部書き直すべきですか

全部を書き直す前に、今の受け入れと合っていない箇所を確かめます。仕事の内容や勤務の条件が変わっていれば、その部分から直します。書き直しの量より、今の受け入れと合っているかが大切です。

運用を再開するより、受け入れをやめるべきか迷っています

受け入れの体制を立て直せるかどうかで判断します。やめるかどうかの判断の進め方は、長期インターンの受け入れをやめる判断で整理しています。
