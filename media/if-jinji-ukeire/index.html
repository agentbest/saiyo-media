人事・採用アシスタントの長期インターン生の最初の1か月｜任せる仕事と育て方

人事・採用アシスタントの長期インターン生を受け入れると、採用の繁忙期ほど、初日から日程調整や候補者への連絡を任せたくなります。けれども、候補者と接する仕事は、一度の行き違いが会社の印象に直結します。結論から言うと、最初の1か月は「情報の扱いを約束する」「候補者に見えない裏方の作業」「社員の確認つきで候補者に出る作業」の順に任せる範囲を広げると、学生も候補者も安心できる受け入れになります。 この記事では、Infraで採用した人事・採用アシスタントの長期インターン生を受け入れる会社に向けて、週ごとの任せ方と育て方を整理します。

最初の1か月で目指す状態を決める

受け入れの前に、1か月後に学生がどうなっていればよいかを一文で決めます。たとえば「面接の日程調整の連絡を、決まった文面と手順に沿って、社員の確認を経て一人で回せる」といった形です。

人事・採用アシスタントで目指す状態を決めるときは、次の三つを確かめます。

  • 情報の扱い：候補者の情報をどこで扱い、何をしてはいけないかを守れるか
  • 採用の流れの理解：自社の採用が、どんな段階で進んでいるかを説明できるか
  • 候補者への接し方：会社を代表して連絡する立場であることを理解しているか

学生は、事務の作業そのものは早く覚えます。最初の1か月で身につけてほしいのは、作業の速さより、候補者の情報と候補者への接し方に対する感覚です。任せやすい仕事と社員が持つ仕事の線引きは人事・採用アシスタントの長期インターンを採るで整理しています。この記事では、その線引きを前提に、最初の1か月の進め方に絞ります。

週ごとの任せ方

最初の1か月は、次のような段階で組むと無理がありません。週の区切りは設計上の例で、学生の稼働日数や採用の時期に合わせて調整します。

  1. 一週目：情報の扱いの約束と、採用の流れを知る：情報の扱いの決まりを一緒に読み、約束してもらう。自社の採用の流れを図にまとめてもらい、社員が確かめる
  2. 二週目：候補者に見えない作業：応募や面接の数の集計、説明会の資料の準備、過去の案内文面の整理など
  3. 三週目：文面の下書き：日程調整や選考の案内の文面を、過去の例をもとに下書きする。社員が確かめてから使う
  4. 四週目：社員の確認つきで候補者に出る：日程調整の連絡を、社員が確認してから学生が送る。説明会の当日の運営を補助する

一週目に「採用の流れを図にまとめてもらう」のは、学生が自分の作業の意味を理解するためです。日程調整の連絡が、どの段階の、どんな候補者に向けたものかが分かっていると、文面の言葉の選び方も変わります。社員にとっても、自社の採用の流れを外から見直す機会になります。

人事・採用アシスタントの長期インターン生に、最初の1か月で何を任せるか。週ごとの組み方から一緒に考えます。

無料で相談する

情報の扱いの約束を最初に置く

人事・採用アシスタントの受け入れで、最初の週に最も時間をかけたいのが、情報の扱いの約束です。次の項目を、言葉にして渡します。

  • 扱う場所：候補者の情報は、決められた道具と場所でのみ扱う。手元の端末や私物の道具には保存しない
  • 持ち出さない：知り得た情報を、自分の就職活動や友人との会話に持ち出さない
  • 知り合いがいたら申し出る：候補者の中に知り合いがいた場合は、その候補者に関わる仕事から外れる
  • 迷ったら聞く：これは扱ってよい情報か、と迷ったら手を止めて社員に聞く

約束は、一度伝えて終わりにせず、二週目以降に作業を渡すたびに、関わる情報の範囲を確かめます。扱う情報の範囲は、雇用契約や誓約書の中でも確認しておきます。情報の管理の考え方は長期インターン生の情報管理でもまとめています。

エージェントベストの見解

人事・採用アシスタントの受け入れで、最初の1か月のうちに問題が起きる会社に共通するのは、「繁忙期に受け入れて、初日から候補者への連絡を任せる」ことです。採用の山場で人手が足りないから長期インターンを入れる、という順番は自然ですが、その時期は社員に確認の余裕がなく、学生の送った連絡の言葉づかいや日時の誤りが、そのまま候補者に届いてしまいます。当社が勧めるのは、繁忙期の一か月以上前に受け入れを始めることです。最初の1か月を裏方の作業と下書きにあて、繁忙期に入るころには社員の確認つきで候補者に出られる状態にしておく。受け入れの時期を採用の山場から逆算して決めると、学生が戦力になるのはちょうど山場の時期になります。受け入れの時期の決め方そのものが、最初の1か月の成否を分けます。

確認の流れで育てる

人事・採用アシスタントの職種では、研修の時間を別に取るより、日々の確認の流れで育てるほうが続きます。候補者に出る作業には、次の流れを決めておきます。

  1. 学生が下書きする：過去の文面と手順書をもとに作る
  2. 社員が確かめる：日時や名前の誤り、言葉づかい、伝えるべきことの漏れを見る
  3. 直した点を学生に返す：どこを、なぜ直したかを一言添える
  4. 学生が送る：送ったあと、送った記録を決められた場所に残す

三つ目の「なぜ直したか」が育成の中心です。「候補者は複数の会社から連絡を受けているので、件名に会社名と用件を入れる」のように理由を添えると、学生は次から自分で気づけるようになります。同じ指摘が三回ほど続かなくなったら、その種類の連絡は確認を軽くしてよい段階です。

週に一度、その週の確認で多かった指摘を振り返る時間を取ると、個別の指摘が学生自身の判断に変わります。振り返りの進め方は長期インターン生との1on1も参考になります。

つまずきの見つけ方と戻し方

人事・採用アシスタントの長期インターン生のつまずきは、次のような様子に表れます。

  • 候補者への連絡で、確認を飛ばして送ってしまう：急ぎの依頼が重なったときに起きやすい
  • 候補者の様子について、社員に意見を言いすぎる：同世代として感じたことを伝えたくなる
  • 作業が事務に偏り、意欲が下がる：採用の全体が見えなくなっている

一つ目は、確認の流れを守ることを改めて伝え、急ぎの依頼が重ならないよう依頼する側を整理します。二つ目は、学生の感じたことは採用の改善に役立つ材料でもあります。合否の判断には使わないことを伝えたうえで、案内の文面や説明会の改善の場で意見を聞く機会を作ると、学生の視点を活かせます。三つ目は、採用の全体を見られる場面、たとえば社員の採用の振り返りの場に同席してもらうと、作業の意味が戻ってきます。

勤務の時間や学業との両立に関わる調整が必要になることもあります。説明会などの行事は日程が決まっているため、授業と重なることがあります。インターン生の労働時間や学業への配慮には法令で定められた項目や指針がありますので、詳しくは社会保険労務士や公式の案内で確認してください。

繁忙期に向けて受け入れの時期をどう決めるか、採用の運用の見直しもあわせてご相談いただけます。

運用の相談をする

社内の分担

人事・採用アシスタントの受け入れでは、次のように役割を分けます。

  • 確認する人：人事の社員、または採用を担う社員。下書きの確認、週の振り返り
  • 受け入れの責任者：目指す状態の決定、扱う情報の範囲の判断、月の終わりの振り返り
  • 年の近い社員：仕事以外の相談、社内の慣習の説明
  • 総務：契約、勤怠、情報の扱いの誓約の手続き

人事の専任がいない会社では、確認する人と受け入れの責任者が同じ人になることがあります。その場合でも、確認の流れと情報の扱いの約束は同じように置きます。専任がいない会社での進め方は専任の人事がいない会社の長期インターン採用でも整理しています。

エージェントベストの見解

当社は長期インターンの募集を支援しながら、新卒採用の媒体の運用も見ています。その立場から勧めたいのは、人事・採用アシスタントの学生に、最初の1か月の終わりに「自社の採用で、学生として分かりにくかったこと」を三つ挙げてもらうことです。学生は、候補者とほぼ同じ立場で自社の採用を外から見られる、社内でただ一人の存在です。説明会の資料の言葉が分かりにくい、案内の連絡が届くまでの間に不安になる、選考の流れが原稿から読み取れない。こうした気づきは、社員には見えにくくなっています。挙げてもらった三つのうち一つでも採用の改善に使えば、学生は自分の仕事が採用を変えたと実感できます。作業を任せるだけでなく、学生の視点を採用の改善に使う場を一つ置くことが、その後の続き方を左右します。

まとめ

  • 最初の1か月は、情報の扱いの約束、裏方の作業、文面の下書き、確認つきの候補者対応の順に任せる
  • 情報の扱いの約束は最初の週に言葉にして渡し、作業を渡すたびに範囲を確かめる
  • 受け入れの時期は、採用の繁忙期から逆算して早めに決める
  • 候補者に出る作業は、下書き、確認、理由を添えて返す、送るの流れで育てる
  • 1か月の終わりに、学生として分かりにくかったことを挙げてもらい、採用の改善に使う

よくある質問

繁忙期にどうしても人手が足りず、すぐ候補者対応を任せたいです

任せる場合は、文面を決まった型に限り、送る前に社員が確認する流れだけは外さないことを勧めます。確認の時間が取れないなら、候補者に出る作業ではなく、集計や資料の準備など裏方の作業を学生に任せ、その分の時間を社員が候補者対応に使う分け方もあります。

学生に説明会の司会を任せてもよいですか

最初の1か月は、司会の補助や受付から始めることを勧めます。司会を任せる場合は、話す内容を事前に社員と確かめ、質問への答えは社員が受け持つ形にします。

1か月が過ぎても、確認の指摘が減りません

指摘の種類を分けて見ます。日時や名前の誤りが多いなら、送る前の確かめの手順を学生と一緒に作ります。言葉づかいの指摘が多いなら、過去の文面から使ってよい言い回しの一覧を作ると減ることがあります。受け入れの体制全体を見直す考え方は長期インターンの受け入れ体制にまとめています。
