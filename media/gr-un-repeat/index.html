Greenを2年目以降に使うときの見直し点

Green・IT中途採用運用ノウハウ（追加） 更新日 2026/11/4

目次

  2. 振り返る材料をそろえる

Greenを使って一年がたつと、「来年も同じように続けるか」を決める時期が来ます。1年目は手探りで始めたので、続けるかどうかの判断材料が手元にそろっていないことも多いはずです。結論から言うと、Greenを2年目以降に使うときは、全体の結果で続けるかを決めるより、採れた求人と採れなかった求人を分けて見直し、求人ごとに続ける・直す・止めるを決めると、次の一年の打ち手がはっきりします。 この記事では、振り返る材料、求人ごとの判断、文面と体制の見直し、社内の分担を整理します。

1年目の延長で続けると起きること

1年目の運用を振り返らずに2年目に入ると、次のようなことが起きがちです。

  • 1年目に採れた求人を、もう採れたのに出したままにしている
  • 反応のなかった求人を、理由を確かめないまま続けている
  • 1年目の終わりに作った文面のひな形が、そのまま使われ続けている
  • 1年目に関わった現場の協力者が異動していて、求人票の中身が今の現場と合っていない

1年目の結果を「採れた人数」だけで見ると、こうした細かいずれが見えません。2年目の見直しは、全体の結果ではなく、求人ごと、段階ごとに分けて見ることから始めます。

振り返る材料をそろえる

見直しの前に、次の材料を求人ごとに集めます。

  1. 段階ごとの人数：求人票の閲覧、「気になる」やスカウトへの反応、応募、面談、面接、内定、承諾、入社
  2. 段階ごとの期間：最初の接点から面談まで、面談から内定まで、内定から承諾まで
  3. 辞退の理由：候補者から聞けた範囲で。分からないものは「不明」と書く
  4. 入社した人の様子：入社後に、求人票や面接で聞いていた話とずれがなかったか
  5. かかった時間と費用：社内の担当者が使った時間の見積もりと、外部に払った費用

材料がそろわない項目があっても構いません。そろわなかったこと自体が、2年目に記録の仕組みを直す理由になります。記録の残し方はGreen運用の数字の記録の残し方で整理しています。

1年目のGreenの運用を、求人ごとに振り返るところから一緒に整理します。

運用の相談をする

求人ごとに続ける・直す・止めるを決める

集めた材料をもとに、求人ごとに三つのどれかを選びます。

状態判断次にやること
採れた。同じ職種をまた採る予定がある続ける入社した人の声を求人票に反映し、現場の今の様子に合わせる
採れた。同じ職種を採る予定はない止める求人を終了し、文面と記録を残しておく
反応はあるが、選考で止まった直す選考の段階を見直す。面接の回数や期間、条件の提示の仕方
反応が少なかった直すか止める求人票と送る相手の条件を見直す。それでも合わなければ別の手段を検討

「直す」を選んだ求人は、どこで止まったかによって直す場所が違います。反応の段階で止まっているなら求人票や送る相手、選考の段階で止まっているなら面接の進め方です。反応の少ない求人の見直し方はGreenで応募が来ないときの見直し順｜求人票・条件・露出の切り分けにまとめています。

エージェントベストの見解

当社はGreenの運用代行と人材紹介の両方をしているので、2年目に「Greenを続けるか、紹介に切り替えるか」と相談されることがあります。このとき勧めている判断の順番は、媒体を比べる前に、求人ごとにどの段階で止まったかを見ることです。選考の段階で止まっている求人は、紹介に切り替えても同じところで止まりやすい。面接の期間が長い、条件の提示が遅いといった理由は、経路が変わっても残るからです。反対に、反応の段階で止まっている求人、つまり求める経験の候補者にそもそも届いていない求人は、紹介で採る方法を併せて検討する価値があります。経路を変える判断は、止まった段階が「接点」なのか「選考」なのかを分けてからにすると、2年目も同じ結果を繰り返さずに済みます。

文面と求人票を一年分の材料で直す

2年目の見直しでは、1年目に使った文面と求人票を、一年分の材料をもとに直します。

  • スカウトや「気になる」の後に送る文面：反応があった文面となかった文面を並べ、違いを一つ見つける。違いが見つからなければ、送る相手の条件の差を疑う
  • 応募への最初の返事：返事の速さと、その後の面談につながった割合の感触を、担当者に聞く
  • 求人票：入社した人に「求人票のどこを読んで応募を決めたか」「入ってみて違ったところはどこか」を聞き、その答えで直す

入社した人の声は、2年目の求人票にとって最も確かな材料です。入社して数か月たった人に、短い時間でよいので話を聞きます。面接での現場の声を求人票に戻す方法は現場からの面接フィードバックを求人票に戻すで整理しています。

体制を見直す

1年目と2年目では、社内の事情が変わっていることがあります。次の点を確かめます。

  1. 担当者は同じか：異動や退職で担当者が替わるなら、引き継ぎの資料を作る
  2. 現場の協力者は同じか：求人票の確認や面接を頼んでいた人が替わっていないか
  3. 作業の量は1年目と同じか：求人の数が増えるなら、1人で回せるか、分担が要るか
  4. 外に出す範囲は合っているか：自社で持っていた作業が回らなくなっていないか。外に出していた作業を自社に戻せるようになっていないか

担当者が替わる場合の資料の作り方はGreenの運用を引き継ぐときの資料で扱っています。

2年目に自社で持つ作業と外に出す作業を、1年目の実績から分け直す相談も受けています。

エージェントベストの見解

2年目に入る会社の相談で多い思い込みは、「1年目で運用の型ができたので、2年目は手間が減る」というものです。実際には、2年目は手間の中身が変わります。求人票を一から書く手間は減りますが、採れた求人の後始末、入社した人からの聞き取り、現場の入れ替わりへの対応といった、1年目にはなかった作業が出てきます。勧めているのは、2年目の最初の月に、1年目の材料をそろえて求人ごとの判断を済ませる時間を、予定としてまとめて押さえることです。この時間を取らずに走り出すと、1年目の型のまま、今の現場や今の候補者とずれた運用が続きます。見直しにかける時間は、2年目の残りの月の手間を減らすための準備と考えます。

まとめ

  • 2年目は、全体の結果ではなく求人ごと・段階ごとに分けて見直す
  • 段階ごとの人数と期間、辞退の理由、入社した人の様子、かかった時間と費用をそろえる
  • 求人ごとに続ける・直す・止めるを決め、止まった段階で直す場所を変える
  • 入社した人の声で求人票を直し、反応のあった文面となかった文面を比べる
  • 担当者・現場の協力者・作業量・外に出す範囲が1年目と同じかを確かめる

よくある質問

1年目に採れなかった場合、Greenをやめたほうがよいですか

採れなかった理由が、どの段階で止まったかによります。反応はあったが選考で止まったなら、選考の進め方を直して続ける選択があります。反応そのものが少なかったなら、求人票と送る相手の条件を見直し、それでも難しければ他の手段の併用を検討します。

2年目に求人を増やしたいのですが、注意点はありますか

求人ごとに送る相手が重ならないように分け、運用の担当者が回せる量かを先に見積もります。求人の分け方はGreenで求人を複数出すときの分け方｜職種と役割の切り方にまとめています。

振り返りはいつ行えばよいですか

自社の事業計画の節目に合わせると、次の一年の採用計画と一緒に決められます。年間の組み立て方はGreen運用の年間スケジュールで整理しています。
