Infraの企業紹介と写真｜社内の様子を伝える素材の選び方

長期インターンの求人で、仕事内容や勤務条件と並んで学生が気にしているのが「どんな場所で、どんな人と働くのか」です。これを伝えるのが、企業紹介の文章と写真です。結論から言うと、写真はオフィスの見栄えより「働いている場面」を、企業紹介は会社の沿革より「インターン生が関わる仕事の周り」を優先すると、学生に伝わります。 この記事では、Infraに掲載する会社に向けて、写真の選び方と撮り方、企業紹介の書き方、掲載前に確認しておくことを整理します。掲載できる写真の枚数や形式などの仕様は変わることがあるため、ここでは素材の中身の選び方に絞ります。

学生は写真から何を読み取っているか

学生は写真を見て、主に次の3つを確かめています。

  • 自分がここにいる姿を想像できるか：同年代の人が働いているか、どんな机で、どんな服装か
  • 放っておかれないか：社員と学生が話している様子があるか、教わる場面があるか
  • 求人の内容と合っているか：営業の求人なら電話や打ち合わせ、ライターの求人なら書いている場面があるか

ここから分かるのは、きれいなエントランスや会議室の写真だけでは、学生の知りたいことに答えられないということです。広くて明るいオフィスは好印象ではありますが、学生がそこで何をしているのかは伝わりません。

撮るべき場面

撮影するなら、次の場面を優先します。

  1. インターン生が業務をしている場面：パソコンに向かう、電話をする、資料を作る。求人の仕事内容と一致する場面
  2. 社員と学生が話している場面：画面を一緒に見ている、ホワイトボードの前で話している
  3. チームの定例や振り返りの場面：何人くらいで、どんな雰囲気で話しているか
  4. 担当社員の顔が分かる写真：インターン生を受け持つ社員が誰か
  5. 作業する席や周りの環境：学生が座る席、使う道具

1と2が特に大切です。どちらも、作った構図より、普段の業務の中で撮ったほうが自然に見えます。撮影のために特別な日を設けるより、普段の業務の時間に少しずつ撮るほうが、実態に近い写真が集まります。

掲載中の写真と企業紹介を見て、学生に伝わっているかを一緒に確かめることもできます。

運用の相談をする

避けたい写真

  • ストック写真やイメージ画像：実際の職場ではないと分かると、かえって不信感につながる
  • 懇親会や飲み会の写真ばかり：仕事の様子が伝わらず、仕事より交流が中心の場に見えることがある
  • 社員が一列に並んだ集合写真だけ：雰囲気は伝わっても、何をしているかが分からない
  • 何年も前の写真：オフィスや人が変わっていると、来てからずれを感じる
  • ほかの求人と同じ写真：職種ごとに求人を分けているなら、その職種の場面を使う

集合写真や懇親会の写真を使ってはいけないわけではありませんが、仕事の場面の写真がそろってから、補う位置に置くのがよいでしょう。

エージェントベストの見解

写真の相談で多いのは、「オフィスがきれいではないので写真を載せたくない」という声です。当社の見方は逆で、きれいでなくても実際の職場を載せたほうが、入ってからのずれが小さくなります。整ったオフィスの写真を見て来た学生が、雑然とした作業場に案内されると、それだけで最初の印象が下がります。逆に、狭くても人の距離が近い場面を見て応募した学生は、来てから同じ景色を見るので、違和感を持ちません。当社がInfraの原稿作成を支援する際も、まず今あるスマートフォンの写真を集めてもらい、そこから業務の場面が写っているものを選ぶところから始めます。プロの撮影が必要になるのは、その後です。写真は見栄えを競う材料ではなく、来る前と来た後の景色をそろえる材料だと考えると、選び方が変わります。

企業紹介の文章で書く順番

写真と並んで掲載する企業紹介は、学生が「この会社で働いてみたい」と思い始めた後に読む部分です。書く順番は次のとおりです。

  1. 何をしている会社か：誰に、何を提供しているかを一文で。業界用語は避ける
  2. インターン生が関わる仕事の周り：インターン生が入るチームは何をしていて、会社の中でどんな役割か
  3. 一緒に働く人：担当社員、チームの人数感、いまいるインターン生の傾向
  4. 働き方：出社とリモートの割合、服装、席の決まり方など
  5. 会社として大事にしていること：理念や行動指針。インターン生の仕事とどうつながるかを添える

沿革や資本金、受賞歴などの会社概要は、学生の判断材料としての優先度は低めです。必要なら、最後に短くまとめる程度で構いません。

写真と文章は、別々に用意するより、組み合わせて考えると伝わり方が変わります。たとえば「2. インターン生が関わる仕事の周り」の段の近くに、チームの定例の写真を置く。「3. 一緒に働く人」の段の近くに、担当社員の写真を置く。写真に一行の説明を添えて、「毎週月曜の定例。インターン生も自分の担当の数字を報告します」のように、写っている場面が何かを書いておくと、学生は写真を見ながら働く様子を具体的に想像できます。説明のない写真は、雰囲気は伝わっても、何をしている場面かまでは伝わりません。

写真に写る人の同意を取る

写真には、社員やインターン生が写ります。掲載する前に、写っている人の同意を取ります。

  • 掲載先と期間を伝える：どの媒体の、どの求人に載せるか。いつまで載せる予定か
  • 断れる雰囲気にする：社内の依頼でも、写りたくない人は断れるようにする
  • 辞めた後の扱いを決める：インターン生が卒業した後、写真を差し替えるかどうか
  • 画面に映る情報に注意する：パソコンの画面、ホワイトボード、書類に、顧客名や個人情報が写り込んでいないか

特にインターン生は、卒業後に写真が残ることを気にする場合があります。卒業のタイミングで差し替えるルールにしておくと、頼みやすくなります。

Infraの代理店として、写真の選び方を含む原稿作成から運用まで支援しています。プランの違いもご案内します。

無料で相談する

エージェントベストの見解

写真と企業紹介を整えるとき、順番を間違えると手戻りが起きます。当社が勧めるのは、先に仕事内容の段を固め、次にその仕事の場面を撮り、最後に企業紹介を書く順番です。写真から先に撮ると、何を撮ればよいかが決まらず、結局オフィスの全景や集合写真が中心になります。企業紹介から先に書くと、会社の説明が長くなり、仕事の周りの話が薄くなります。仕事内容が決まっていれば、撮る場面はそこから自然に決まります。インサイドセールスなら電話をしている場面と、商談の数字を共有している場面。ライターなら取材メモを見ながら書いている場面と、編集者と原稿を直している場面。仕事内容の書き方は長期インターンの仕事内容の書き方で整理しています。

まとめ

  • 学生は写真から「ここにいる自分」「放っておかれないか」「求人と合っているか」を読み取る
  • 優先して撮るのは、インターン生が業務をしている場面と、社員と話している場面
  • ストック写真、古い写真、懇親会ばかりの写真は避けるか、補う位置に置く
  • 企業紹介は沿革より、インターン生が関わる仕事の周りと一緒に働く人を先に書く
  • 写る人の同意を取り、卒業後の差し替えのルールを決めておく

よくある質問

プロのカメラマンに頼むべきですか

最初から頼む必要はありません。普段の業務の場面をスマートフォンで撮った写真でも、明るさと構図に気をつければ十分に伝わります。仕事の場面の写真がそろい、見栄えを整えたくなった段階で検討すれば足ります。

インターン生が今いない場合、写真はどうすればよいですか

社員が実際に業務をしている場面や、インターン生が座る予定の席、担当社員の写真を使います。インターン生がいないことを隠す必要はありません。「初めての受け入れで、最初のメンバーを探している」と書くほうが、合う学生に届くこともあります。

写真はどのくらいの頻度で入れ替えればよいですか

オフィスの移転や、写っている人の卒業・異動があったときが入れ替えの目安です。季節ごとに原稿を見直すときに、写真も実態と合っているかを確認しておくと、ずれが溜まりにくくなります。
