OfferBoxのイベント機能｜「かんたん日程調整」で面談・説明会を組むときの確認事項

OfferBoxで「イベント機能」と言うとき、指しているのは多くの場合、公式の機能一覧にある「かんたん日程調整」です。結論から言うと、この機能はオファーを承認した学生との選考の日程調整を自動で行うもので、面談やセミナーイベントを作って学生を招待し、申込を管理できると説明されています。学生を集めてから日程を組むのではなく、オファーで接点を持った学生を、あらかじめ作った面談やイベントに招く流れです。この記事では、公開されている範囲で仕組みを整理し、画面の細部は申込前に確認する前提で、使う前に決めておくことをまとめます（2026年9月30日時点。最新は公式ページでご確認ください）。

結論｜「かんたん日程調整」は承認後の段取りをまとめる機能

公式の機能ページで確認できる「かんたん日程調整」の説明は、次の2点です。

  • オファー承認後に、選考の日程調整を自動で行う
  • 面談やセミナーイベントを作成して学生を招待し、申込を管理できる

ここから読めるのは、この機能が学生を新しく集めるための機能ではなく、すでにオファーを承認してくれた学生を次の接点に進めるための機能だということです。メールや電話で候補日を何往復もやり取りする手間を、あらかじめ枠を作っておくことで減らす、という位置づけになります。

なお、企業向けサイトにある「イベント」のページは、i-plugが人事担当者向けに開いているセミナーの案内です。人事コミュニティの「LiNK」も同様で、どちらもサービスの中で学生向けのイベントを組む機能とは別のものです。名前が似ているので、社内で共有するときは混同しないようにしておきます。

仕組み｜オファーの種類とイベントのつながり

オファーの段階で「何に招くか」が決まっている

学生向けの公式ヘルプでは、企業はオファーの種類を選んで送れるとされ、種類として「個別面談」「少人数座談会」「説明会」「インターン/仕事体験」が挙がっています。つまり学生は、オファーを承認する時点で、どの形の接点に進むのかを知っています。かんたん日程調整で作る面談やイベントは、この約束の続きです。オファーで少人数座談会と伝えたのに、承認後の案内が大人数の説明会になっていると、学生の側では話が違うと感じます。

承認からイベントまでの流れ

公開情報から組み立てると、流れは次のようになります。

  1. オファーの種類を決めて、学生ごとにプロフィールを見て送る
  2. 学生が承認すると、メッセージでやり取りできるようになる
  3. かんたん日程調整で作っておいた面談やイベントに、学生を招待する
  4. 申込の状況を管理し、選考管理リストなどで次の段階を追う

学生の側には、面談や説明会の日程変更・キャンセルについての公式ヘルプがあります。学生が日程を動かすことがある前提で、枠の組み方を考えておくほうが現実的です。

面談と説明会のどちらを入口にするかで、必要な送信数と社内の時間が変わります。申込前の整理だけでもどうぞ。

運用の相談をする

エージェントベストの見解

イベントの枠を作る前に先に決めておきたいのは、「オファーの種類ごとに、誰が出るか」です。当社は申込後の運用も見ていますが、日程調整の機能を使い始めてから止まる会社に共通するのは、枠は作ったのに、面談に出る社員の予定が週によって空いたり埋まったりして、枠を出したり引っ込めたりしていることです。承認した学生から見ると、招待された枠が少なかったり、次の週まで空きが無かったりすると、その間に他社との予定が埋まっていきます。個別面談なら出る社員を2人以上決めて、週ごとの固定の枠を先に押さえる。座談会や説明会なら開催の間隔を決めて、次回が常に見えている状態にする。機能は日程の往復を減らしてくれますが、出る人の予定を決める作業は社内にしか残りません。面談そのものの組み立てはOfferBoxの面談設計にまとめています。

確認する項目｜申込前とデモで聞いておくこと

かんたん日程調整について、公式ページで確認できるのは上の説明までです。画面の操作や設定できる項目は公開されていないため、トライアルや個別面談で次の点を確認します。

  1. 面談とイベント（セミナー）で、作れる形式に違いがあるか
  2. 1つの枠に何人まで申し込めるか、定員を設定できるか
  3. オンラインと対面の両方に対応できるか、会場やURLをどう案内するか
  4. 学生が日程を変更・キャンセルしたときに、企業側にどう伝わるか
  5. 社内の複数の担当者の予定を、どう扱えるか
  6. 申込の状況を選考管理リストとどうつなげるか

特に4つ目は、当日の欠席や直前の変更にどう備えるかに関わります。オンライン面談の段取りを整える場合はオンライン面談の進め方も参考になります。

注意点｜機能に任せる部分と、人が見る部分

  • 学生を集める機能ではない：公式の説明はオファー承認後の日程調整です。イベントを作っただけでは学生は来ないので、オファーの段階で何に招くかを伝えておきます
  • オファーの種類と中身を揃える：個別面談・少人数座談会・説明会・インターン/仕事体験のどれで送ったかと、招く先の形を一致させます
  • 承認直後の一言は人が書く：日程の案内が自動でも、承認してくれたことへの一言や、なぜその学生に会いたいかは担当者が書くほうが伝わります。承認からの連絡の早さは承認からの連絡を早くする体制に書いています
  • 仕様は変わることがある：利用規約では、i-plugが事前通知なくシステムの仕様を変えることがあるとされています。申込時点の画面で確認します

説明会を軸にするか、個別面談を軸にするか。媒体の特性と合わせて一度整理してみませんか。

無料で相談する

エージェントベストの見解

OfferBoxで説明会型のイベントを組むか、個別面談を軸にするかは、媒体の機能より社内の体制で決めるほうがうまくいきます。3媒体を扱っていると、大人数の説明会で一度に多くの学生と会いたい会社には、掲載やイベント出展を軸にできる媒体を先に検討することがあります。OfferBoxは企業が一人ひとりのプロフィールを見てオファーを送る仕組みなので、送った理由がそのまま伝わる少人数の接点と相性が良い、というのが当社の見方です。説明会を使うなら、説明会を最終の目的にせず、参加した学生を個別面談に進めるための入口として置き、説明会のあとに誰がどの学生に連絡するかまで決めておきます。説明会を他の手段と組み合わせる考え方は説明会との併用で整理しています。

まとめ

  • OfferBoxのイベントに関わる機能は、公式の機能一覧の「かんたん日程調整」
  • オファー承認後の選考の日程調整を自動で行い、面談やセミナーイベントを作って学生を招待・申込管理できる
  • 企業向けサイトの「イベント」ページやLiNKは人事向けの催しで、サービス内の機能とは別
  • オファーの種類（個別面談・少人数座談会・説明会・インターン/仕事体験）と、招く先の形を揃える
  • 定員や変更時の通知など画面の細部は公開されていないため、デモで確認する

よくある質問

かんたん日程調整を使うと、学生の申込は自動で増えますか

公式の説明では、この機能はオファー承認後の日程調整を自動で行い、面談やイベントに学生を招待して申込を管理するものです。学生を新しく集める機能としては説明されていないため、申込の数はオファーの送信と承認の数に左右されます。

学生が日程を変更したとき、企業側ではどう分かりますか

学生向けの公式ヘルプには日程変更やキャンセルについての案内がありますが、企業側でどう表示されるかは公開ページでは確認できません。トライアルか個別面談の場で確認しておくと安心です。

イベントの組み方も相談できますか

できます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、申込前の媒体選びから申込後の運用まで相談を受けています。代理店手数料は媒体側から支払われるため、企業の料金は各媒体の正規料金のままです。
