Wantedly経由の入社者が早期離職したとき｜読んだ会社との差を見直す

Wantedly課題別 更新日 2026/9/12

Wantedly経由で入社した社員が、まもなく離職した。「共感して入ったはずなのに」と、戸惑う。「本人が合わなかった」で終わらせたくなりますが、Wantedly経由の離職には、採用の側に見直す点があります。結論から言うと、共感で来た人ほど、「読んだ会社」と「入った会社」の差に敏感です。ずれの場所を四つに分けます。会社ページの「なぜ」と日々の判断、記事の「こんなことやります」と実際の仕事、面談で会った人と配属先の人、記事で書いた働き方と入社後の最初の数か月。本人に聞ける範囲で聞き、事実と推測を分けます。配属先が記事を知らないことがずれの元になりやすく、記事を実態に合わせて直します。良く見せた記事は、離職で戻ってきます。一件で全部を変えず、直す場所を一つに絞ります。 この記事では、本人の問題で終わらせないこと、共感で来た人の敏感さ、四つの場所、聞き方、配属先とのずれ、直し方、一件で全部を変えないこと、分担を整理します。選考中の離脱はWantedly経由の候補者が選考で離脱する理由、OfferBoxの場合はOfferBoxで採った学生が早期離職したときに見直す点で書きました。

この作業の目的｜離職を、次の採用の「直す場所」に変える

早期離職は、採用の結果が最も強く出る場面です。「本人が合わなかった」で終わらせると、同じずれで次も採り、同じ離職が起きます。

目的は、離職した本人を責めることでも、採用担当を責めることでもなく、「どこでずれたか」を見つけて、記事の時点から直すことです。

共感で来た人ほど、差に敏感

  • Wantedly経由の入社者は、会社ページの「なぜ」を読み、記事の場面を読み、ストーリーで人を見て、面談で話して、入っている：「読んだ会社」の像が、他の経路より具体
  • 具体な像は、実態との差が見えやすい：「なんとなく良さそう」で入った人より、「〇〇の場面に重なった」で入った人のほうが、その場面が実態と違ったときに気づく
  • 共感は、裏切られたときの落差が大きい：「共感で釣られた」と感じると、条件の差より重く残る
  • だから、Wantedly経由の離職は、記事の側の見直しが特に要る：記事が「読んだ会社」を作っているから

これは、Wantedlyが悪いのではなく、記事が具体であるほど、実態と合わせる責任が重い、ということです。

ずれが起きた場所を、四つに分ける

場所ずれの中身見るもの
1. 会社ページの「なぜ」と、日々の判断「〇〇で困っている人のために」と読んで入ったが、日々の判断が「なぜ」と関係なく決まっていた会社ページの「なぜ」と、配属先の判断の場面
2. 記事の「こんなことやります」と、実際の仕事「最初の月から△△を持つ」と読んだが、実際は半年間補助だった募集記事と、配属先の実際の最初の数か月
3. 面談で会った人と、配属先の人面談に出た人、ストーリーに出た人と、配属先で一緒に働く人が違い、「話が違う」面談に出た人、記事に出た人、配属先の人
4. 記事で書いた働き方と、最初の数か月「自分で決めて進める」と読んだが、実際は指示に従う形だった。「残業は少ない」と読んだが、多かった記事の「どうやっているのか」と働き方の実態、入社後の実際

四つは、記事と面談で「読んだ会社」を作った場所と、入社後の実態の間で起きます。

いま使っている媒体の運用の相談だけでも構いません。早期離職のずれが、四つのどこで起きたかを一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyで共感して入った人が辞めたのだから、本人の共感が浅かった」というものです。当社は採用媒体の代理店として、Wantedlyの運用を見ています。離職した本人に聞ける範囲で聞いた記録を並べると、「共感が浅かった」ではありません。「記事で読んだ場面が、入ってみたら起きていなかった」「面談で会った人と、配属先の人が違った」が多くあります。本人の共感は本物で、共感の対象だった記事の場面が実態と違った、という問題です。当社が早期離職の相談を受けるとき、最初にやるのは、共感の深さの話ではなく、その人が「記事のどこを見て来た」と面談で言った言葉と、配属先の実際の場面を、並べることです。並べると、ずれの場所が見えます。

本人に、聞ける範囲で聞く

  • 退職の手続きの中で、人事が聞ける範囲で：「今後の参考に、差し支えなければ」
  • 四つの場所を、順に聞く：「会社ページの『なぜ』と、実際の判断は違ったか」「記事で読んだ仕事と、実際は違ったか」「面談で会った人と、配属先は違ったか」「記事で読んだ働き方と、最初の数か月は違ったか」
  • 入社前に「記事のどこを見て来た」と言った言葉を、先に見る：その場面が、ずれの候補
  • 事実と推測を分けて記録する：「本人が言った：〇〇（事実）。人事の推測：△△」
  • 本人を責める形にしない：「なぜ辞めるのか」ではなく、「採用の側で直せることを知りたい」

聞き方は、辞退の理由の聞き方と同じです。Wantedlyで面談後に辞退されるときの見直しで書きました。

配属先が記事を知らないことが、ずれの元

  • 記事の「こんなことやります」を、配属先が読んでいたか：読んでいないと、「2」のずれが起きる
  • 記事に出た人が、配属先の人だったか：別の部署の人が記事に出て、配属先は別、で「3」のずれが起きる
  • 記事の「どうやっているのか」を、配属先が「約束」として受け取っていたか：受け取っていないと、「4」のずれが起きる
  • 会社ページの「なぜ」を、配属先の責任者が自分の言葉で言えるか：言えないと、「1」のずれが起きる
  • 配属先に、採用の記録（記事のリンク・面談の記録・本人が挙げた場面）を渡していたか：渡していないと、配属先は「初めて会う新人」として受け入れる

ずれの多くは、「記事が伝えたこと」を「配属先が知らない」ことから起きます。人事が書いた記事を、配属先が読んでいないことは、珍しくありません。

直し方

ずれの場所採用の側で直すこと配属先と直すこと
1. 「なぜ」会社ページの「なぜ」を、日々の判断の場面で書き直す。理念ではなく判断。Wantedlyのストーリーで代表の考えを書く方法配属先の責任者が「なぜ」を自分の言葉で言える形に
2. 仕事「こんなことやります」を、配属先の実際の最初の数か月に合わせる配属先に記事を見せ、「これで合っているか」を確かめてから出す
3. 人記事とストーリーに、配属先の人を出す。面談に配属先の人が出る。出せないなら「配属先は別です」と面談で言う配属先の人が面談に出る形を作る
4. 働き方「どうやっているのか」と働き方の実態を、実際に合わせる。良く見せない配属先が「約束」として受け取り、最初の数か月を実際にそうする

「実態に合わせて書く」が、採用の側の直しの中心です。良く見せて採り、実態でずれると、離職で戻ってきます。素顔の出し方はWantedlyで会社の素顔を出す範囲で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。記事と面談を、配属先の実態に揃える作業の時間をお伝えします。

媒体選びを相談する

良く見せた記事は、離職で戻ってくる

  • 「自分で決めて進める」が実態でないなら、記事から消す：来る人は減るが、離職は減る
  • 「残業は少ない」が実態でないなら、実態を書く：「〇〇の時期は多い」
  • ストーリーの「入社した最初の月」が、いまも起きている場面か：過去の一人だけの場面なら、「その人の場合」と書く
  • 記事の場面が、配属先で起きるかを、出す前に配属先に確かめる
  • 良く見せた分は、面談で気づかれれば辞退、気づかれなければ離職で戻る：どちらも記事の側の問題

「読んだ会社」と「入った会社」を同じにすることが、Wantedly経由の離職を減らす唯一の道です。記事の直し方はWantedlyの募集記事の反応を見て直す手順で書きました。

一件で、全部を変えない

  • 一件の離職で、会社ページも記事も面談も全部変えると、何が効いたか分からなくなる
  • 四つの場所のうち、本人が挙げた場面に最も近い一つを直す
  • 直した結果を、次の採用と入社後で見る：一年
  • 同じずれが二件続いたら、その場所を重く見る
  • 離職の記録を、四つの場所で分類して残す

一件は、直す場所の「候補」で、複数件が「証拠」です。

社内の分担

作業誰が
本人に聞ける範囲で聞き、事実と推測を分けて記録する人事
本人が入社前に挙げた記事の場面と、配属先の実際を並べる人事
ずれの場所を四つのどれかに分類する人事と責任者
記事と会社ページを実態に合わせて直す人事と配属先と代表
記事を出す前に配属先に確かめる形を作る人事と配属先の責任者
配属先の人が記事と面談に出る形を作る配属先
採用の記録を配属先に渡す人事
直す場所を一つに絞る判断責任者

運用代行や代理店が支えられるのは、四つの場所の切り分け、聞き方の型、並べる表の型、記事と面談の直し方の案までで、本人に聞くこと、配属先との合意、実態を変えるかの判断は企業が行います。

エージェントベストの見解

これは契約後に起きることの話です。Wantedly経由の入社者が早期に離職すると、社内で「共感採用は定着しない」という声が出て、翌年の運用が止まることがあります。当社が契約後にお願いしているのは、離職が出たときに、「共感」で判断せず、「ずれの場所」で判断することです。共感で来た人は、記事の場面を具体に覚えていて、その場面と実態の差を、面談で「記事のどこを見て来た」と言った言葉として残しています。この言葉と配属先の実態を並べれば、直す場所は見つかります。逆に言えば、Wantedly経由の離職は、「何に共感して来たか」が記録に残っているので、直す場所が最も見つけやすい離職です。

まとめ

  • 共感で来た人ほど、「読んだ会社」と「入った会社」の差に敏感。記事が具体であるほど、実態と合わせる責任が重い
  • ずれの場所を四つ（会社ページの「なぜ」と日々の判断・記事の仕事と実際・面談で会った人と配属先の人・記事の働き方と最初の数か月）に分け、本人が入社前に挙げた記事の場面と配属先の実際を並べる
  • 本人に聞ける範囲で四つを順に聞き、事実と推測を分けて記録する。責める形にしない
  • ずれの多くは「記事が伝えたこと」を「配属先が知らない」ことから起きる。記事を出す前に配属先に確かめ、配属先の人が記事と面談に出る
  • 直しの中心は「実態に合わせて書く」。良く見せた記事は辞退か離職で戻る。一件で全部を変えず、一つを直して一年見る

よくある質問

本人が「共感していたのに、思っていたのと違った」としか言いません

「思っていた」の中身を、入社前の面談の記録から見ます。面談で「記事のどこを見て来た」と言った場面が、その人の「思っていた」です。その場面が、配属先で起きていたかを確かめます。起きていなければ、そこがずれの場所で、記事をその場面が起きる実態に合わせるか、その場面が起きる形を配属先と作るか、です。

配属先が「人事の書いた記事は読んでいない」と言います

そこがずれの元です。次からは、記事を出す前に配属先に見せ、「最初の数か月」と「どうやっているのか」が実際と合っているかを確かめ、内定が出たら採用の記録（記事のリンク・面談の記録・本人が挙げた場面）を配属先に渡します。配属先が「約束」として受け取っていれば、「2」と「4」のずれは減ります。

Wantedly経由の早期離職の見直しは、御社に相談できますか

できます。当社は、四つの場所の切り分け、聞き方の型、並べる表の型、記事と面談の直し方の案を支えられます。本人に聞くこと、配属先との合意、実態を変えるかの判断は、企業が行ってください。当社は採用媒体の代理店として、Wantedlyの運用を支えています。
