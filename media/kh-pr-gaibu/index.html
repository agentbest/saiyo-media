採用広報を外に頼むときの範囲｜内製と外注の分け方

採用広報を自社だけで続けるのが難しくなると、外に頼むことを考え始めます。ところが、頼んでみたら会社らしさのない記事が届いた、何度も直しを頼んで結局自分で書いた、という声もよく聞きます。結論から言うと、採用広報を外に頼むときは、社内の人にしか書けない中身を自社に残し、それを形にする作業を外に出すのが基本です。 この記事では、外に出せる作業と出しにくい作業の分け方、依頼前に決めること、進め方の型を整理します。

外に出せる作業と、出しにくい作業

採用広報の作業を分解すると、外に出しやすいものと出しにくいものに分かれます。

作業外に出しやすさ理由
発信の目的と対象を決める出しにくい採用計画と経営の方向に結びつくため
伝えたい中身（仕事の具体、大変なこと、会社の方向）を決める出しにくい社内の人にしか分からない
取材の段取り、質問の準備出しやすい型があり、経験のある人のほうが速い
取材をもとにした文章の作成出しやすい中身が決まっていれば、書く技術で補える
撮影、動画、デザイン出しやすい専門の技術が要る
SNSの投稿の作成と予約出しやすい中身と方針が決まっていれば回せる
公開前の内容確認出しにくい事実や社外秘の判断は社内でしかできない

表の「出しにくい」作業を外に任せると、届いたものが一般的な言葉の並びになりやすくなります。外の人は会社の中を知らないので、決まっていない部分を一般論で埋めるしかないからです。

採用全体で外に頼む範囲の考え方は採用の外注範囲の決め方で整理しています。

依頼前に決めておくこと

外に頼む前に、社内で次の四つを決めておきます。

  1. 目的：この発信で、誰に何を知ってもらい、選考のどこを変えたいか
  2. 対象：読んでほしい人の像。新卒か中途か、どんな経験や関心を持つ人か
  3. 中身の骨組み：伝えたいことを、箇条書きでよいので社内で書き出す
  4. 確認の流れ：公開前に誰が何を確認するか。社員の名前や写真の扱いも含めて

3番目の「中身の骨組み」がないまま依頼すると、取材の場で一から話すことになり、時間がかかります。箇条書きでも先に渡しておくと、外の人が質問を準備でき、取材の中身が深くなります。

広報と媒体の運用を、どこまで社内で持ち、どこから外に出すか。分け方から相談できます。

運用の相談をする

エージェントベストの見解

自社で持つべきなのは、「何を伝えるか」と「公開してよいか」の二つまでです。ここから先、取材の段取り、文章の作成、見た目の制作、投稿の作業は外に出しても、会社の言葉は残ります。逆に、「何を伝えるか」まで外に出すと、届くものが他社と似た記事になります。媒体の運用代行を受ける立場から見ても、同じ線が当てはまります。スカウトの文面を作る作業は受け持てても、どんな人に会いたいか、その人に会社の何を伝えたいかは、会社の側で決めてもらわないと文面に中身が入りません。広報でも媒体の運用でも、外に頼むときに渡すのは「作業」であって「判断」ではない。この線を引いておくと、頼んだあとの直しの回数が減ります。

頼み先の種類

採用広報を頼める先には、いくつかの種類があります。それぞれ得意な範囲が違います。

  • 編集や執筆の会社・個人：取材と文章の作成が得意。採用以外の記事も書いていることが多い
  • 採用広報を専門にする会社：採用の文脈を理解したうえで企画から関わる。媒体の運用まで扱う会社もある
  • 撮影や動画の制作会社：見た目の質を上げたいときに頼む
  • 採用代行や媒体の運用代行：スカウトや掲載ページの作成と合わせて、発信の中身を媒体で使える形に整える

どこに頼むかは、外に出したい作業の範囲で決めます。文章だけなら編集の会社、媒体での使い方まで含めるなら運用代行も選択肢になります。一社にすべてを任せるより、範囲ごとに分けて頼むほうが合う会社もあります。

進め方の型

外に頼んだあとの進め方は、次の型にすると行き違いが減ります。

  1. 最初の打ち合わせ：目的、対象、中身の骨組み、確認の流れを渡す
  2. 一本目を試しに作る：最初から多くを頼まず、一本作って方向を合わせる
  3. 直しの基準を共有する：一本目の直しで出た指摘を、次から守る約束として書き出す
  4. 月ごとの予定を決める：何を、いつまでに、誰の取材で作るかを並べる
  5. 四半期ごとに振り返る：発信が採用の場面で使われているか、効果を確かめる

2番目の「一本目を試しに作る」は、とくに大切です。最初からまとめて頼むと、方向がずれていたときに作り直しが多くなります。一本目で言葉の選び方や、どこまで踏み込んで書くかをすり合わせると、二本目からの直しが少なくなります。

効果の確かめ方は採用広報の効果の測り方で扱っています。

作った記事や資料を、スカウトや掲載ページでどう使うか。媒体ごとの使い方を一緒に整理します。

無料で相談する

エージェントベストの見解

採用広報を外に頼んだあと、最初の数か月で発信が止まる会社に共通するのは、社内の確認が詰まることです。外の人が記事を書き上げても、現場の社員や経営者の確認が返ってこず、公開できないまま次の記事に進めなくなります。当社が媒体の運用を受けるときにも、スカウトの文面や掲載ページの確認で同じことが起きやすい場面があります。勧めているのは、依頼の前に「確認する人」と「確認にかけてよい日数」を決め、確認する人の予定にあらかじめ時間を入れておくことです。確認の窓口を一人にし、その人が社内の意見をまとめて返す形にすると、外の人とのやり取りも一本になります。外に頼むかどうかより、確認の流れが社内で回るかどうかが、続くかどうかを分けます。

よくある行き違い

外に頼んだときに起きやすい行き違いと、その防ぎ方を挙げます。

  • 会社らしさがない：中身の骨組みを渡していない。箇条書きでも先に渡す
  • 事実の誤り：取材の内容を外の人が解釈して書いている。公開前に事実の確認を社内で行う
  • 社員が嫌がる：載せ方を本人と相談していない。名前や写真の扱いは取材の前に確かめる
  • 媒体で使えない：記事の長さや形が、媒体のページやスカウトに合っていない。使う場所を最初に伝える

社員の協力を得るときの考え方は採用広報に社員の協力を得る方法にまとめています。

まとめ

  • 「何を伝えるか」と「公開してよいか」は社内に残し、形にする作業を外に出す
  • 依頼前に、目的、対象、中身の骨組み、確認の流れを決める
  • 頼み先は、外に出したい作業の範囲で選ぶ
  • 最初は一本だけ作り、直しの基準をすり合わせる
  • 確認する人と日数を先に決めておくと、発信が止まりにくい

よくある質問

採用広報をすべて外に任せることはできますか

作業の多くは外に任せられますが、何を伝えるかと公開してよいかの判断は社内に残すことを勧めます。判断まで外に出すと、会社の実情と発信の中身がずれやすくなります。

外に頼むと、社員の取材の負担は減りますか

取材の段取りや質問の準備は外の人が担うので、負担は減ります。ただし、取材に応じる時間そのものは残ります。取材を短く済ませるために、中身の骨組みを先に渡しておくと効果があります。

外注の費用はどう考えればよいですか

頼む範囲で変わるため、範囲を決めてから見積もりを取ります。社内の時間とお金を合わせて考える方法は採用広報の予算の考え方で整理しています。
