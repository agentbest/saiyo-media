長期インターン生の権限とツールのアカウント

長期インターン生が初日に出勤したのに、チャットにも共有フォルダにも入れず、午前中を待って過ごす。逆に、急いで社員と同じ権限を渡してしまい、見せるつもりのない資料まで見える状態になる。どちらも受け入れでよく起きることです。結論から言うと、インターン生には任せる仕事に必要な範囲の権限だけを、本人専用のアカウントで、初日までに用意しておくのが基本です。 この記事では、アカウントの準備、権限の決め方、共有アカウントを避ける理由、退職時の止め方を整理します。

初日までに用意するアカウント

アカウントの準備は、受け入れが決まった時点で始めます。初日に間に合わないと、本人は何もできないまま時間を過ごし、会社への印象が下がります。

用意するものは、おおむね次のとおりです。

  • 社内の連絡手段：チャットやメール。どのチャンネルやグループに入れるかも決めておく
  • ファイルの置き場所：共有フォルダやドライブ。見られる範囲を絞る
  • 仕事で使うツール：任せる仕事に必要なものだけ。予定を管理するツール、作業の進み具合を管理するツールなど
  • 勤怠の記録：出勤と退勤を記録する仕組み

すべてを社員と同じにそろえる必要はありません。最初の数週間に任せる仕事を先に決め、その仕事に要るものから順に用意します。任せる仕事の決め方は長期インターン生に任せる仕事の切り出し方で扱っています。初日の流れは長期インターン初日の受け入れも参考になります。

権限は「任せる仕事」から逆算する

権限の決め方で迷ったら、任せる仕事から逆算します。手順は次のとおりです。

  1. 任せる仕事を並べる：最初に渡す仕事を三つほど書き出す
  2. 仕事ごとに必要な操作を書く：見るだけでよいか、編集が要るか、外に送る操作が要るか
  3. 最も狭い権限を選ぶ：見るだけで済むなら閲覧のみ、編集が要るならその場所だけ編集を許す
  4. 外に出る操作は社員に残す：公開・送信・支払いといった操作は、権限そのものを渡さない

4つ目は、責任範囲とそろえるための考え方です。「公開の判断は社員が持つ」と決めていても、本人のアカウントに公開の権限があれば、操作の間違いで公開されることがあります。権限で線を引いておけば、本人も安心して作業できます。責任範囲の分け方は長期インターン生の責任範囲の決め方で整理しています。

受け入れ前に、インターン生に渡す権限と用意するアカウントを一緒に洗い出せます。

共有アカウントを避ける理由

小さな会社では、ツールのアカウントを一つにして、社員とインターン生で使い回していることがあります。手軽ですが、長期インターンでは避けることを勧めます。理由は次の三つです。

  • 誰が操作したか分からない：問題が起きたとき、誰の操作かを確かめられない。本人が疑われることもある
  • 止められない：インターン生が辞めたとき、パスワードを変えると社員全員が困るため、そのままになりやすい
  • 権限を絞れない：共有アカウントは社員の仕事にも使うため、インターン生向けに権限を狭められない

ツールによっては、個人のアカウントを増やすと費用がかかることもあります。その場合でも、インターン生が使うツールを絞り、本当に必要なものだけ個人のアカウントを用意するほうが、後の手間は少なくなります。費用の扱いは会社によって異なるため、ツールの契約内容を確かめて判断してください。

エージェントベストの見解

受け入れの準備で順番を間違えやすいのが、アカウントの準備です。これをやる前に、先に「インターン生に見せない情報は何か」を決めておかないと、権限の設定で迷い続けます。顧客の個人情報、給与や人事の資料、取引先との契約、未発表の事業の計画。こうした情報がどのフォルダやチャンネルにあるかを先に確かめ、そこを除いた範囲で権限を設定します。見せない情報が決まっていない会社では、担当者が「とりあえず全部見えるようにしておく」か「念のため何も見せない」のどちらかに振れがちです。前者は情報の扱いの面で心配が残り、後者は仕事が進みません。見せない情報を一覧にする作業は、一度やれば次の受け入れでも使えます。

情報の扱いのルールを伝える

権限を絞っても、見える情報の扱い方は本人に伝える必要があります。初日に伝えておきたいのは次のような点です。

  • 社内の情報を、私物の端末や個人のアカウントに移さない
  • 業務で知った情報を、SNSや友人との会話で話さない
  • 画面を開いたまま席を離れない、外で作業するときは周りに気をつける
  • 分からないときは、扱う前に社員に聞く

ルールは口で伝えるだけでなく、一枚の紙やページにまとめて、いつでも見返せるようにします。秘密を守る約束を書面で交わす会社もあります。書面の中身や、業務で知った情報の扱いについて法令で定められた項目があるかは、社労士や公式の案内で確認してください。情報管理の考え方は長期インターン生の情報管理で詳しく扱っています。

権限の見直しと退職時の止め方

権限は、渡したら終わりではありません。次のタイミングで見直します。

  1. 任せる仕事が広がったとき：新しく必要になった権限だけを足す
  2. 担当する仕事が変わったとき：使わなくなった権限を外す
  3. 長く出勤しない期間があるとき：留学や試験で長く休む場合、一時的に止めるかを本人と話す
  4. インターンを終えるとき：最終出勤日に、すべてのアカウントを止める

4つ目は、とくに抜けやすい点です。最終出勤日が近づいたら、どのアカウントを持っているかを一覧で確かめ、止める担当者と日付を決めておきます。本人が作ったファイルや資料は、止める前に社員の場所へ移します。

エージェントベストの見解

当社は人材紹介も行っているので、社員の退職や入社のときに、アカウントの管理が混乱する会社の話もよく聞きます。インターン生のアカウント管理がうまくいかない会社は、多くの場合、社員の入退社でも同じ課題を抱えています。誰がどのツールのアカウントを持っているかの一覧がない、止める担当者が決まっていない、といった点です。長期インターン生は入れ替わりが社員より多いため、この課題が早く表に出ます。インターン生の受け入れをきっかけに、アカウントの一覧と、入るときと出るときの手順を一枚にまとめておくと、社員の入退社の手間も減ります。受け入れの準備を、会社の仕組みを整える機会として使えます。

受け入れてからの権限の見直しや、インターン生の入れ替わりへの備えも相談できます。

運用の相談をする

まとめ

  • アカウントは、任せる仕事に要るものから順に、初日までに用意する
  • 権限は任せる仕事から逆算し、最も狭いものを選ぶ。外に出る操作は社員に残す
  • 共有アカウントは避け、本人専用のアカウントを使う
  • 先に「見せない情報」を一覧にし、情報の扱いのルールを初日に伝える
  • 仕事が変わるたびに権限を見直し、最終出勤日にすべて止める

よくある質問

インターン生に、私物のパソコンを使ってもらってもよいですか

会社の情報を私物の端末で扱うと、管理が難しくなります。会社の端末を貸せるならそのほうが安心です。私物を使う場合は、使うツールと保存してよい場所を決め、社内のルールとして書いておきます。

社員と同じチャンネルに入れてよいか迷います

仕事の連絡が流れるチャンネルには入れ、人事や経営の話をするチャンネルには入れない、という分け方が一般的です。迷うチャンネルは、そこで話されている内容を見て、見せない情報が含まれるかで判断します。

インターン生が自分で作ったアカウントで作業していました

業務で使うツールは、会社が用意したアカウントに切り替えてもらいます。個人で作ったアカウントに業務の情報が残ると、辞めたあとに回収できません。切り替えるときは、本人を責めるのではなく、会社としてのルールを伝える機会にします。
