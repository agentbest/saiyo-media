地方拠点で長期インターンを受け入れるとき

本社が都市部にあり、地方に支社や営業所、開発拠点を持つ会社が、その拠点で長期インターン生を受け入れたいと考えることがあります。結論から言うと、地方拠点の長期インターンは、本社の人事が募集と手続きを持ち、拠点が日々の仕事を持つ、という分担を決め、拠点の外にも相談先を置くと続けやすくなります。 拠点だけで抱えると人手が足りず、本社だけで進めると拠点の実情とずれます。この記事では、地方拠点で割ける時間と人、最初に決めること、運用の分担を整理します。

地方拠点で割ける時間と人

地方拠点は、数名から十数名の社員で運営されていることが多く、拠点長が営業や業務の責任と、拠点の運営を兼ねています。人事や総務の担当者は本社にいて、拠点にはいないこともあるでしょう。

この状況で長期インターンを受け入れると、拠点の側では次のような時間が必要になります。

  • 面接の時間：拠点の社員が学生と会い、仕事の説明をする
  • 日々の指導の時間：仕事の割り振りと確認
  • 拠点の運営との両立：拠点長や社員が外出していることが多い中で、インターン生が一人にならないようにする

拠点の社員は、本社の社員以上に一人ひとりの仕事の幅が広いことが多く、指導に時間を割きにくい状況にあります。この前提を、本社の人事が理解しておくことが出発点です。

拠点で受け入れる意味を整理する

地方拠点で長期インターンを受け入れる理由は、会社によって異なります。最初に、何のために拠点で受け入れるのかを整理しておきます。

  1. 拠点のある地域で、将来の採用につなげたい：地元の学生と早くつながりたい
  2. 拠点の仕事の手を増やしたい：営業の準備や事務の仕事を進めたい
  3. 拠点の存在を地域の学生に知ってもらいたい：本社の名前は知られていても、地元に拠点があることは知られていない

3つ目は見落とされがちですが、地方拠点の採用では大きな意味を持ちます。地元の学生にとって、本社が都市部にある会社は「地元を離れないと働けない会社」に見えることがあります。地元の拠点で働けることを知ってもらうだけでも、将来の採用の候補が広がります。

本社と拠点のどちらが何を持つか、拠点の募集をどう見せるか。地方拠点での受け入れの組み立てを一緒に整理します。

無料で相談する

最初に決めること｜本社と拠点の分担

地方拠点で受け入れるとき、本社と拠点で次のように分担を決めておきます。

項目本社の人事拠点
募集原稿の作成と掲載、応募の受付仕事内容と拠点の様子の情報を出す
選考日程調整、合否の連絡面接、受け入れの判断
手続き契約、勤怠、給与勤怠の確認
日々の受け入れ定期的な面談仕事の割り振り、日々の指導

本社の人事が手続きを持つことで、拠点の負担を仕事の中身に集中させられます。また、本社の人事が定期的に面談をすることで、拠点の中では言いにくい悩みを拾えます。

エージェントベストの見解

地方拠点での受け入れについて相談を受けたとき、当社が最初に確認するのは「拠点長がいない日に、インターン生の相談先は誰か」です。拠点長が営業で外出していることの多い拠点では、インターン生が出社しても、質問できる相手がいない日が続きます。拠点の他の社員も自分の仕事で手一杯だと、インターン生は遠慮して質問を控え、作業が止まります。当社が勧めるのは、拠点の外にも相談先を一人置くことです。本社の人事や、同じ職種の本社の社員が、チャットでいつでも質問を受けられるようにしておく。拠点の中に相談できる人がいない時間を、本社の側で埋める形です。拠点の人数の少なさを、本社とのつながりで補う設計にすると、拠点での受け入れが続きやすくなります。

拠点ならではの仕事の見せ方

募集では、拠点で働くことの特徴を具体的に書きます。

  • 拠点が地域で担っている役割：どんな顧客を担当し、地域のどこで仕事をしているか
  • 少人数の拠点ならではの関わり方：拠点長や社員と近い距離で働ける
  • 本社とのつながり：本社の社員と一緒に仕事をする機会、本社を訪れる機会があるか
  • 働き方：出社の日数、拠点への通い方、リモートの可否

地元の学生に向けては、「地元にいながら、全国規模の会社の仕事に関われる」ことを伝えると、関心を持たれやすくなります。地方での見せ方の考え方は地方企業の長期インターン採用でも整理しています。

拠点と本社のつながりを作る

拠点のインターン生は、本社のインターン生や社員と接する機会が少なく、会社の全体像が見えにくくなります。つながりを作るために、次のような工夫があります。

  1. 本社の初日の説明にオンラインで参加する：会社の事業や働き方のルールを、本社のインターン生と同じ形で聞く
  2. 本社のインターン生との交流：オンラインで月に一度、仕事の様子を共有する
  3. 本社への訪問の機会：受け入れ期間中に一度、本社を訪れて社員と話す
  4. 拠点の仕事を本社に発表する：インターン生がまとめた仕事を、本社の会議で紹介する

エージェントベストの見解

当社は人材紹介も行っており、地方で働きたい人が転職を考えるときの事情もよく聞きます。地元で働きたい人は、地方拠点のある会社を候補に入れますが、「拠点に配属される保証があるか」「本社に異動させられないか」を気にします。長期インターンを地方拠点で受け入れている会社は、この不安に具体的に答えられます。実際に拠点で働いた学生がいて、拠点の仕事の中身が見えているからです。新卒の募集で「地方拠点での採用」を打ち出すとき、長期インターンの実例があると説得力が変わります。拠点での受け入れは、その拠点の将来の採用の土台になる、という見方で計画することを勧めます。

拠点の社員の受け止め方を確かめる

地方拠点での受け入れは、本社の人事が主導して決まることが多く、拠点の社員の受け止め方が置き去りになりがちです。拠点の社員にとっては、日々の仕事に加えて、学生の面倒を見る役割が増えることになります。

  1. 拠点長の意向を先に聞く：受け入れを決める前に、拠点の事情と受け入れの余地を確かめる
  2. 拠点の社員に目的を説明する：なぜ本社ではなく拠点で受け入れるのかを伝える
  3. 拠点の負担を本社が引き受ける部分を示す：手続きや相談の窓口を本社が持つことを具体的に伝える
  4. 受け入れの成果を拠点に返す：インターン生の仕事が拠点の業務にどう役立ったかを、本社からも認める

拠点の社員が受け入れに納得していないと、インターン生は拠点の中で居場所を感じにくくなります。本社と拠点の距離は、そのままインターン生の居心地に表れます。

拠点の社員の納得を得ながら受け入れを進める方法を、本社と拠点の分担とあわせて整理します。

運用の相談をする

まとめ

  • 地方拠点の長期インターンは、本社の人事が募集と手続きを、拠点が日々の仕事を持つ
  • 拠点で受け入れる目的に、地域の学生に拠点の存在を知ってもらうことも加える
  • 拠点長が不在の日に備え、本社の側にも相談先を置く
  • 募集では、拠点の地域での役割と、本社とのつながりを具体的に書く
  • オンラインでの説明や交流で、拠点のインターン生が会社の全体像を見られるようにする

よくある質問

拠点に指導役を置ける社員がいません

拠点の社員が日々の仕事の割り振りだけを担い、質問への対応や振り返りは本社の社員がオンラインで行う形も考えられます。その場合も、拠点で一人きりで働く時間が長くならないよう、出社日を拠点の社員がいる日に合わせることを勧めます。

本社と拠点で、給与などの条件をそろえるべきですか

会社の方針や地域の事情によって異なります。条件を変える場合は、その理由を社内で説明できるようにしておきます。給与の決め方の考え方は長期インターンの給与の決め方で整理しています。

拠点の募集に応募が集まりにくいです

拠点のある地域の学生に向けて、通える範囲や働き方を具体的に書くと、合う学生に届きやすくなります。本社の名前だけを前に出すと、勤務地が地方であることが伝わらず、応募後に辞退されることもあります。
