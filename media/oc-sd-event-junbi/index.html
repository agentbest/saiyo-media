ワンキャリアでイベントを開くと決めたあと、準備は資料づくりから始まりがちです。スライドを整え、会社の紹介を詰め、当日が近づいてから「誰が話すのか」「イベントページに何を書くのか」を決める。これでは、学生がイベントページを見て申し込むかどうか決める時期に、肝心の中身が載っていません。結論から言うと、イベントの準備は「回の目的を一つに決める」「出る人を決めて頼む」「イベントページを出す」「前日までに流れを確かめる」「当日の役割を分ける」の順に進めます。資料は最後で構いません。 この記事では、段階ごとにやること、体験談を読んで回の中身を決める方法、やりがちな抜け、社内の分担を整理します。イベントの種類の選び方はイベントの種類と使い分けで書きました。イベントの枠や形式の条件は変わることがあるので、現在の仕様は管理画面とヘルプ、担当窓口で確認してください。

この作業の目的｜申し込む前の学生が、回の中身を読める状態にする

ワンキャリアの学生は、イベントページを読み、自社の体験談やクチコミを読んで、その回に行くかどうかを決めます。誰が出て、何が確かめられる回なのかが読めなければ、申し込みません。

準備の目的は、学生が申し込むかどうか決める時期に、回の中身が読める状態を作っておくことです。当日の資料の出来より、申し込む前に読まれるイベントページの中身のほうが、来る学生と来たあとの動きに効きます。

準備の五つの段階

段階やることこの段階で決まっていないと
1. 回の目的この回で学生に確かめてもらうことを一つに決める話が広がり、何の回か分からない
2. 出る人目的に答えられる社員を決め、上司の合意を取って頼む直前に人が替わり、イベントページと違う人が出る
3. イベントページ誰が出て何を話すか、どんな学生に向くかを書いて公開する申し込む前に中身が読めない
4. 前日までの確認流れ、話す範囲、答えられない質問の扱いを出る人と確かめる当日、出る人が判断に迷う
5. 当日の役割進行、話す人、質問の受け手、記録を分ける出る人が全部を抱える

順番を守ると、資料は「話の目印」として最後に作るだけで済みます。資料の作り方はイベントで使う資料の作り方にまとめています。

イベントの準備の段取りを、自社の予定に合わせて一緒に組みます。いま使っている媒体の運用の相談だけでも構いません。

運用の相談をする

1. 回の目的を一つに決める｜体験談から逆算する

回の目的は、自社の体験談とクチコミから決めると外れにくくなります。

  1. 自社の体験談を読む：学生が気にしていること、分からなかったと書いていること
  2. 確かめたいことを一つ選ぶ：「仕事の最初の一年」「選考で何を見ているか」「働き方の実際」など
  3. その一つに答えられる回の形を選ぶ：説明会、職種別の回、座談会、少人数の相談会
  4. 一文にする：「入社二年目の営業社員が、最初の一年の仕事を話し、質問に答える回」

体験談がまだない会社は、説明会や面接で学生から出た質問から一つ選びます。

2. 出る人を決めて頼む

出る人は、回の目的に事実で答えられる人を選びます。決めたら、次の順で頼みます。

  • 上司の合意を先に取る：業務の時間として出てもらう
  • 頼むことを三つに絞る：話すこと、質問に答えること、終わったあとに一言感想を戻すこと
  • 話す範囲を一枚で渡す：話してよいこと、人事に回してほしい質問
  • 日程を早めに押さえる：イベントページに名前や役割を書くため

出る人の選び方はイベントに出る社員の選び方、登壇の考え方はイベントに登壇する社員の選び方で書きました。

エージェントベストの見解

これは順番の話です。イベントを開いたのに学生が集まらない、という相談を受けて準備の経過をたどると、イベントページの公開が遅れていることがよくあります。出る人が決まらないまま日程だけ押さえ、ページには会社名と日時だけを載せる。中身が決まってから書き足そうとしているうちに、学生が予定を決める時期が過ぎてしまいます。当社が勧めるのは、回の目的と出る人の役割が決まった時点で、名前が確定していなくても、イベントページを出してしまうことです。「入社二年目の営業社員が、最初の一年を話します」と役割で書けば、学生は何が確かめられる回かを読めます。名前はあとから足せます。資料の完成を待ってページを出すのは、順番が逆です。

3. イベントページを出す

イベントページには、次を書きます。

  • 何が確かめられる回か：回の目的の一文
  • 誰が出るか：役割と入社年次など、学生が想像できる範囲
  • どんな学生に向くか：「まだ志望の業界を決めていない人」のように
  • 選考とのつながり：年度の公表内容と自社の方針に沿って、事実だけ
  • 当日の流れ：話す時間と質問の時間の目安

書き方はイベントページの作り方にまとめています。

イベントをワンキャリアで開くか、ほかの媒体と組み合わせるか。3媒体を並べてご案内します。

媒体選びを相談する

4. 前日までの確認

前日までに、出る人と短く確かめます。

  1. 当日の流れ：誰が何分話し、質問の時間はどこか（時間は設計上の目安でよい）
  2. 話す範囲：話してよいこと、人事に回す質問の例
  3. 答えられない質問の扱い：「人事から後日お答えします」と言ってよいこと
  4. イベントページとの照合：ページに書いたことと、当日話すことが揃っているか
  5. オンラインなら接続、対面なら会場：機材と動線を一度通す

オンラインとオフラインの進め方の違いはオンラインイベントの進め方とオフラインイベントの進め方で書きました。

5. 当日の役割を分ける

役割やること
進行時間の管理、質問の受け付け
話す人回の目的に沿って話し、質問に答える
質問の受け手話す人が答えにくい質問を引き取り、後日の回答を約束する
記録出た質問、学生の反応、答えきれなかったことを残す

少人数の会社では、進行と記録を人事一人が兼ねても構いません。話す人に進行まで頼まないことが大切です。

やりがちな抜け

  • イベントページに、誰が出るかを書いていない
  • 出る人に、話す範囲を渡していない
  • 答えきれなかった質問の扱いを決めていない
  • 終わったあとのフォローの段取りを、当日まで決めていない
  • 記録の担当がいない

最後の二つは、回のあとに効いてきます。フォローの型はイベント後のフォローの型で書きました。

社内の分担

作業誰が
体験談を読み、回の目的を決める人事
出る人を決め、上司の合意を取って頼む人事
イベントページを書いて出す人事
前日までの確認人事と出る人
当日に話し、質問に答える出る人
進行と記録人事

エージェントベストの見解

自社で持つべきなのは、どこまでか。イベントの準備のうち、イベントページの下書き、前日までの確認の一覧、当日の役割表は、外に出しやすい作業です。代理店や運用代行が型を用意すれば、人事の手間は減ります。一方で、回の目的を一つに決めることと、出る人を社内で口説くことは、外からはできません。とくに出る人への依頼は、上司の合意を含めて社内の関係の中でしか進みません。準備が遅れる会社の多くは、型の作業ではなく、この二つで止まっています。準備を外に出すかどうか考えるときは、目的と出る人の二つを先に社内で決め、残りを任せる、という切り分けを勧めます。

まとめ

  • イベントの準備は、回の目的、出る人、イベントページ、前日までの確認、当日の役割の順に進め、資料は最後に作る
  • 回の目的は、自社の体験談から学生が確かめたいことを一つ選んで決める
  • イベントページは、出る人の名前が確定する前でも、役割で書いて早めに出す
  • 前日までに、流れ、話す範囲、答えられない質問の扱いを出る人と確かめる
  • 当日は、進行、話す人、質問の受け手、記録を分け、話す人に進行を頼まない

よくある質問

準備にどのくらいの期間が要りますか

会社の予定と回の形で変わります。目安として、学生が予定を決める時期よりも前にイベントページを出せるよう、そこから逆に、出る人への依頼、回の目的の決定を置いていきます。期間を決めるより、ページを出す日を先に決めるほうが組みやすくなります。

出る人が直前に替わることになりました

イベントページの記載を、替わった人の役割に合わせて直します。役割で書いていれば、直す箇所は小さく済みます。替わった人にも、話す範囲の一枚を渡し、前日までの確認を一度行います。

イベントの準備は、御社に相談できますか

できます。当社は、準備の段取りの整理、イベントページの書き方、前日までの確認の一覧、当日の役割表の型を支えられます。回の目的の決定と、出る人への依頼は企業が行ってください。当社は求人広告代理店として、媒体選びから運用までを支えています。
