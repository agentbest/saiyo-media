メディア業界の長期インターン採用｜編集と運営の両面

Webメディア、出版、動画のメディア。メディアの会社の長期インターンは、文章を書くことや発信に関心のある学生に人気があります。学生の多くは「記事を書きたい」「編集の仕事がしたい」と考えて応募してきます。一方で、メディアの仕事には、記事を作る編集の仕事と、読まれる仕組みを作る運営の仕事の二つの面があります。結論から言うと、メディア業界の長期インターンは、編集と運営のどちらか一方に偏らせず、両面に触れられる形で仕事を組むと、学生の成長も会社への貢献も大きくなります。 編集だけを任せると数字の見方が身につかず、運営だけを任せると学生の「書きたい」という意欲が満たされません。この記事では、学生向けの長期インターン求人サイトInfraで募集するメディアの会社に向けて、両面の仕事の組み方を整理します。

メディア業界の採用構造と、長期インターンの位置

メディアの会社は、少人数の編集部で多くの記事や番組を作っていることが多く、日々の仕事の手が求められる業界です。新卒採用では、編集職の採用の数が限られ、狭き門になることもあります。

メディアの会社で長期インターンが担う役割は、主に次の四つです。

  • 編集の手：記事の下書き、取材の準備、校正の補助
  • 運営の手：数字の分析、SNSの運用、記事の配信の作業
  • 新卒採用の入口：編集職の適性を、働きながら見極める
  • 読者に近い目線：若い世代の読者向けのメディアなら、学生の感覚が生きる

四つ目は、メディアの読者層によって価値が変わります。学生や若い社会人を読者とするメディアでは、学生のインターンは読者そのものに近い存在です。

編集と運営、任せる仕事の分け方

メディアの仕事を、編集と運営の二つの面で分けると、学生に任せやすい仕事が見えてきます。

編集の面

  • 記事のテーマの案出し
  • 取材の準備（質問の下書き、相手の下調べ）
  • 記事の下書き
  • 校正の補助（誤字や表記の揺れの確認）
  • 写真や画像の選定

運営の面

  • 記事ごとの読まれた数の集計と分析
  • SNSでの記事の紹介の投稿の下書き
  • 検索での見え方の調べ物
  • 過去の記事の更新の候補の洗い出し

学生には、編集の仕事を軸にしつつ、週に一度は運営の数字を見る時間を設ける、という組み方が考えられます。自分の書いた記事がどのくらい読まれたかを数字で見ると、学生は読者を意識して書くようになります。

エージェントベストの見解

メディアの長期インターンでよくある思い込みは、「学生には記事を書かせておけば満足する」というものです。確かに書く仕事は学生の意欲を引き出しますが、書いた記事がどう読まれたかを知らないまま書き続けると、学生は手応えを感じにくくなります。記事を出したあと、反応が見えないまま次の記事に取りかかる。それが続くと、書くことが作業になっていきます。当社が受け入れの設計で勧めるのは、学生が書いた記事の数字を、公開の一週間後に学生と一緒に見る時間を作ることです。読まれた数、最後まで読まれたかどうか、どこから読みに来たか。数字を見ながら「なぜこの記事は読まれたのか」を話すと、学生は次の記事で何を変えるかを自分で考えるようになります。編集と運営の両面に触れる仕組みは、こうした小さな時間から作れます。

メディアの会社の長期インターンで、編集と運営の仕事をどう組むか。原稿づくりから一緒に考えます。

校正と事実確認の流れ

メディアの仕事では、記事の内容の正確さが会社の信頼に直結します。学生の書いた記事が公開されるまでの流れを決めておきます。

  1. 学生が下書きする
  2. 編集の担当者が内容を確認する：構成、表現、読者に伝わるか
  3. 事実を確認する：数字、固有名詞、引用の出典
  4. 校正する：誤字、表記の揺れ
  5. 公開する：誰が公開の操作をするか

三つ目の事実の確認は、学生が慣れていない作業です。出典を記録しながら書く習慣を最初に身につけてもらうと、確認の手間が減ります。どの情報をどこから得たかを、下書きの横に書いておく形にすると、編集の担当者も確認しやすくなります。

表記の決まり（用字用語の統一）がある会社は、その決まりを学生に最初に渡しておきます。決まりがない場合は、学生と一緒に作ることも一つの方法です。

業界のイメージと、見せ方

メディア業界に対して、学生は次のようなイメージを持っていることがあります。

  • 自分の書いた記事が世に出る
  • 有名な人に取材できる
  • 締め切りに追われて忙しい

一つ目と二つ目は、学生にとっての大きな魅力です。ただし、長期インターンの段階でどこまで経験できるかは会社によって違います。原稿では、学生が書いた記事に署名が入るか、取材に同行できるかを具体的に書きます。

三つ目のイメージに対しては、学生の働き方を具体的に書くことで応えます。締め切りのある仕事は社員が持ち、学生には締め切りに余裕のある記事を任せる、という形にしておけば、学生の授業や試験とも両立しやすくなります。雇用として受け入れる学生には、締め切り前でも最低賃金と労働時間の規定が当然に適用される点も、担当の編集者と共有しておきます。

運用設計

メディアの会社が長期インターンを運用するときは、次の点を決めておきます。

  • 署名の扱い：学生の書いた記事に学生の名前を出すか、出す場合の範囲と期間
  • 取材への同行：同行できる取材の種類、取材先への伝え方
  • 権利の扱い：学生が書いた記事や撮った写真の権利
  • インターン終了後の記事：学生が卒業した後も記事を残すか、署名をどうするか

一つ目と四つ目は、学生の今後にも関わる点です。署名の入った記事は、学生にとって就職活動で見せられる成果になります。一方で、学生が卒業後に名前を消してほしいと言う場合もあるため、扱いを最初に決めておきます。権利の扱いと合わせて、雇用契約や誓約書の中で確認しておきます。

エージェントベストの見解

メディアの会社が長期インターンを新卒採用につなげるときに考えておきたいのは、編集職を志望する学生の多くが、新卒で大手の出版社や新聞社、放送局も受けるという点です。当社は長期インターンの媒体と新卒向けの媒体の両方を扱っていますが、編集職を志望する学生は早い時期から複数の会社を比べています。中小のメディアの会社が選ばれる理由になりやすいのは、「入社してすぐに、自分の企画で記事を作れるか」という点です。大手では編集の仕事に就くまでに時間がかかることもあるため、早くから企画を任せられることは、学生にとって大きな判断材料になります。長期インターンの間に、学生が自分で企画した記事を一本でも公開できれば、その経験そのものが、自社で働く姿を想像させる材料になります。企画から公開までを一度経験させることを、受け入れの目標の一つにしておくことを勧めます。

編集職の新卒採用と長期インターンをどうつなぐか。媒体の組み合わせからご提案します。

まとめ

  • メディア業界の長期インターンは、編集と運営の両面に触れられる形で仕事を組む
  • 学生の書いた記事の数字を、公開の一週間後に一緒に見る時間を作る
  • 出典を記録しながら書く習慣を、最初に身につけてもらう
  • 署名・取材の同行・権利・終了後の記事の扱いを、受け入れ前に決めておく
  • 新卒採用につなげるなら、企画から公開までを一度経験させる

よくある質問

長期インターンの学生に、取材を一人で任せてもよいですか

最初は社員の取材に同行し、質問の仕方や記録の取り方を見てもらってから任せるのが一般的です。一人で取材に行く場合も、取材先への連絡は社員が確認し、取材後の原稿は社員が確認してから公開します。

文章を書いた経験がない学生でも受け入れられますか

レポートや卒業論文を書いた経験があれば、記事を書く基礎はあります。最初は短い記事や、決まった型のある記事から始めると、書くことに慣れていけます。原稿に「記事を書いた経験は問いません」と書いておくと、関心のある学生が応募しやすくなります。

動画のメディアでも、同じ考え方で受け入れられますか

編集と運営の両面に触れるという考え方は同じです。動画の場合は、制作の流れと確認の回数を決めておくことが大切になります。動画の編集の仕事の任せ方は動画編集の長期インターンを採るで詳しく扱っています。
