長期インターン生から報告が来ないとき

Infra・長期インターン課題別（追加） 更新日 2026/11/4

長期インターン生に仕事を任せたものの、終わったのかどうか分からない。進み具合を聞くと、実は途中で止まっていた。期限の直前になって、終わらないと分かる。受け入れた社員は、自分から確かめに行く手間が増え、任せる意味が薄れていきます。結論から言うと、報告が来ないときは、学生の姿勢を疑う前に「いつ報告するか」「どんな形で報告するか」「報告を受けた社員がどう反応しているか」の三つを決め直すと、報告が届くようになりやすくなります。 社会で働いた経験の少ない学生は、報告が仕事の一部だという感覚をまだ持っていないことがあります。この記事では、症状の分け方、切り分けの順番、打ち手、外に出す範囲を整理します。

症状を確認する｜来ない報告の種類を分ける

報告が来ないと感じるとき、どの報告が来ていないのかを分けます。

  • 終わった報告が来ない：仕事は終わっているが、終わったと知らせてこない
  • 途中の報告が来ない：進み具合が分からず、期限の直前に状況が分かる
  • 困ったときの相談が来ない：つまずいていても、言い出さずに止まっている
  • 悪い知らせが来ない：間違いや遅れを隠したり、後回しにしたりする

終わった報告が来ないなら、報告のタイミングが決まっていないことが多いです。途中の報告が来ないなら、どの時点で知らせればよいかが伝わっていません。困ったときの相談や悪い知らせが来ないなら、報告したときの社員の反応に原因がある可能性があります。

原因を切り分ける順番

1. いつ報告するかが決まっているか

最初に確かめるのは、報告のタイミングを伝えているかです。社員にとっては当たり前の「終わったら知らせる」「半分進んだら一度見せる」も、学生には伝えなければ分かりません。タイミングが決まっていないと、学生は「全部終わってから見せればよい」と考えがちです。

2. どんな形で報告するかが決まっているか

次に、報告の形を見ます。誰に、どの方法で、何を書けばよいかが分からないと、学生は報告そのものをためらいます。チャットで一言送ればよいのか、資料にまとめるのか、口頭で伝えるのか。形が決まっていないと、報告は後回しになります。

3. 報告を受けた社員がどう反応しているか

最後に、報告を受けたときの社員の反応を振り返ります。忙しそうに短く返す、遅れの報告に強く反応する、相談に「自分で考えて」と返す。こうした反応が続くと、学生は報告を避けるようになります。報告が来ないのは、報告したあとの経験から学んだ結果であることもあります。

報告のタイミングや形の決め方から、受け入れる職場の運用を一緒に整理します。相談だけでも構いません。

無料で相談する

打ち手｜タイミング・形・反応を決める

  1. 仕事を頼むときに、報告のタイミングを一緒に決める：「始めて少し経ったら一度見せる」「終わったら知らせる」「期限に間に合わなそうなら、分かった時点で知らせる」の三つを、仕事ごとに伝えます
  2. 報告の形を短い型にする：「終わったこと」「途中のこと」「困っていること」の三行で送ればよい、と決めます。型があると、学生は何を書けばよいか迷いません
  3. 一日の終わりに短く報告してもらう：出勤した日の終わりに、その日の三行を送る習慣を作ります。進み具合が毎回見えるので、期限の直前に驚くことが減ります
  4. 報告にはまず受け取ったことを返す：内容への意見の前に、「ありがとう、見ました」と返します。返事があると、学生は次も報告しやすくなります

定期的に話す場の作り方は長期インターン生との1on1｜頻度と話すことで書いています。

エージェントベストの見解

当社は長期インターンの受け入れの相談を受ける中で、報告が来ない職場ほど、社員の側から状況を確かめに行く回数が多いことに気づきます。社員が先に聞きに行くので、学生は「聞かれたら答えればよい」と受け止め、自分から報告する理由がなくなっています。勧めているのは、確かめに行く代わりに、報告の時刻を決めてしまうことです。たとえば、出勤した日の終わりに三行を送ると決め、社員は届くまで聞きに行かない。届かなかった日だけ、短く声をかける。最初の数週間はもどかしく感じますが、社員が聞きに行かない分、学生の側に報告する役割が移ります。報告が来ないことを注意するより、報告の時刻を決めて待つほうが、報告は習慣として定着しやすくなります。

悪い知らせを早く出してもらう

報告の中でも届きにくいのが、間違いや遅れなどの悪い知らせです。学生は叱られることを恐れ、自分で何とかしようとして、かえって問題を大きくすることがあります。

  • 悪い知らせほど早く、と最初に伝える：受け入れの初日に、「間違いや遅れは、分かった時点で知らせてほしい。早いほど一緒に直せる」と伝えます
  • 悪い知らせを受けたら、まず礼を言う：「早く知らせてくれて助かった」と返し、そのあとに対応を一緒に考えます
  • 原因は責めずに、次の手を一緒に決める：同じことを繰り返さないための手順を一緒に考えます

最初の悪い知らせへの反応で、その後の報告が変わります。強く反応すると、次からは隠されるようになります。初日の伝え方は長期インターン初日の受け入れ｜最初の1週間の組み方が参考になります。

外に出す場合の範囲

報告の受け方は、受け入れる職場の社員と学生の間のことなので、外に出せる部分は限られます。

  • 社内で持つこと：報告のタイミングと形の決定、報告を受けたときの反応、悪い知らせへの対応
  • 外に出せること：報告の型や初日に渡す資料を作る作業、受け入れの設計の見直しの相談、社員向けの説明の段取り

報告の型は、一度作れば次の受け入れでも使えます。作るときは、学生を受け入れるすべての社員に同じ型を使ってもらうことを決めておきます。社員によって求める報告が違うと、学生はまた迷います。

報告の型や初日の資料づくりなど、インターン生の受け入れの運用をご相談いただけます。

運用の相談をする

エージェントベストの見解

当社は媒体の運用と人材紹介の両方に関わっているので、社会に出て最初の職場で報告の習慣を身につけた人と、そうでない人の違いを、中途の採用の場面でも見ることがあります。報告の習慣は、本人の性格よりも、最初に働いた職場の決まりで身につくことが多いものです。長期インターンは、学生にとって多くの場合、初めての職場です。その職場で報告のタイミングと形を教わった学生は、次の職場でも同じように動けます。受け入れる会社にとって、報告の型を作ることは、目の前の仕事を回すためだけでなく、学生が社会で働く準備を手伝うことでもあります。採用の場面でこの経験を語れる学生は、面接でも強みになります。そう伝えると、学生の側も報告を面倒な手続きではなく、身につけたい力として受け止めやすくなります。

まとめ

  • 来ない報告を、終わった報告、途中の報告、相談、悪い知らせに分ける
  • 報告のタイミング、報告の形、報告を受けた社員の反応の順に原因を確かめる
  • 仕事ごとに報告のタイミングを決め、三行の型で送ってもらう
  • 社員から聞きに行く代わりに、報告の時刻を決めて待つ
  • 悪い知らせには、まず礼を言い、次の手を一緒に決める

よくある質問

報告の型を決めても、送ってくれません

最初の数週間は、届かなかった日に短く声をかけて、習慣になるまで続けます。届いた報告に毎回返事をすることも大切です。返事がないと、学生は報告が読まれていないと感じ、送らなくなります。

リモートで働く学生の報告はどうすればよいですか

出社のときより、報告のタイミングと形をはっきり決めておく必要があります。始業と終業の短い報告に加え、週に一度は話す時間を取ると、文字だけでは分からない様子もつかめます。

報告は来るのに、内容が分かりにくいです

型の「終わったこと」「途中のこと」「困っていること」のどれに当たるかを分けて書いてもらうと、読みやすくなります。指示の段階で仕上がりの形が伝わっていない場合もあります。考え方は長期インターン生に指示が伝わらないときで整理しています。
