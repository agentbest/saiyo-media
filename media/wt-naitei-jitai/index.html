Wantedly経由の内定辞退が続くとき｜四つの理由と直す場所

Wantedly経由で内定を出したのに、辞退が続く。多くの会社が、内定後のフォローを厚くしようとします。ところが、Wantedly経由の候補者の辞退には、内定後より前に原因があることが多くあります。結論から言うと、Wantedly経由の内定辞退は、理由を「会社の『なぜ』に共感して来たが最後は条件で決めた」「記事と面談の印象が選考で変わった」「内定後に接点が途切れた」「『こんなことやります』が他社の仕事の具体より薄かった」の四つに分け、辞退した候補者の共通点を記事の時点まで戻って見ます。内定後のフォローだけを厚くしても、原因が記事や選考にあれば直りません。共感で誘った候補者にも条件を先に見せ、内定後に「読んだ会社の人」と話す場を置き、承諾した候補者の理由を次の記事に活かします。 この記事では、四つの理由とサインと直す場所、内定後だけを厚くしても直らない理由、理由の集め方、記事の時点まで戻って見ること、条件を先に見せる意味、内定後の場、承諾の理由の活かし方、分担を整理します。面談後の辞退はWantedlyで面談後に辞退されるときの見直し、選考中の離脱はWantedly経由の候補者が選考で離脱する理由で書きました。この記事は、内定後の辞退です。

この作業の目的｜辞退の原因がある場所を見つけて、そこを直す

内定辞退は、採用の最後の段で起きるので、最後の段（内定後のフォロー）を直したくなります。ところが、Wantedly経由の候補者は、記事と面談で会社の印象を持って来ているので、その印象と実態の差が、最後の段で出ます。

目的は、辞退の原因がどの段にあるかを見つけ、そこを直すことです。内定後のフォローを厚くすることが目的ではありません。

内定辞退の、四つの理由

理由何が起きているか直す場所
1. 共感で来たが、最後は条件で決めた会社の「なぜ」に共感して面談に来て、選考も進んだが、内定を並べたときに条件で他社を選んだ。条件を記事に書いておらず、比べる材料が最後に出た記事の最後に条件を短く。共感と条件の両方を、記事の時点で
2. 記事と面談の印象が、選考で変わった「自分で決めて進める」を読んで来たが、選考で「指示に従う」実態が見え、「読んだ会社と違う」選考を「面談の続き」に。記事を実態に合わせる。Wantedly経由の候補者が選考で離脱する理由
3. 内定後に、接点が途切れた内定を出したあと、承諾までの間に会社からの接点がなく、他社に向いた内定後の場。「読んだ会社の人」と話す
4. 仕事の具体が、他社より薄かった共感はあったが、「こんなことやります」が場面になっておらず、他社の具体的な仕事の話に負けた記事の「こんなことやります」を場面で厚く。Wantedlyの募集記事「こんなことやります」の書き方

「1」「2」「4」は、内定後のフォローでは直りません。記事と選考の話です。

内定後のフォローだけを厚くしても、直らない理由

  • 条件で決めた候補者は、フォローの回数では動かない：比べる材料が変わらない
  • 選考で下がった印象は、内定後に戻りにくい：「読んだ会社と違った」の記憶が残る
  • 仕事の具体が薄いなら、フォローで仕事の話をするより、記事の時点で書いておくべきだった
  • 共感で来た候補者に、内定後に押すと、「共感を利用された」と感じることがある：Wantedly経由の候補者は、押されることに敏感
  • 内定後のフォローが効くのは、原因が「3」の場合だけ

Wantedlyの「お互いを知る」という関係で来た候補者に、内定後だけ「採用側」の顔で押すと、それまでの関係が崩れます。

いま使っている媒体の運用の相談だけでも構いません。内定辞退の理由を四つのうちどれかに、辞退した候補者の記録から一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは共感で来る候補者なので、内定を出せば条件に関係なく承諾してくれる」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、辞退した候補者に聞ける範囲で聞いた記録を並べると、「共感はしていたが、最後に内定を並べたら条件の差が大きかった」が多くあります。共感は、話を聞きに行く理由にはなりますが、承諾の理由の全部にはなりません。記事に条件を書かず、共感だけで誘い、内定の時点で条件を初めて出すと、候補者は「共感で釣られた」と感じます。当社が内定辞退の相談を受けるとき、最初にやるのは、記事に条件が書かれているかを確かめることです。共感で誘う記事ほど、条件を先に見せることが、辞退を減らします。

理由ごとの、見えるサイン

1. 共感で来たが、条件で決めた

  • 辞退の理由が「他社の条件が」「給与が」「働き方が」
  • 記事に条件が書かれていない、または「応相談」
  • 面談で条件の話を避けていた：「まずはお互いを知る場なので」で、条件が最後まで出なかった
  • 内定の連絡で、条件を初めて具体に出した

直すのは、記事の最後に条件を短く書くことと、面談で聞かれたら答えることです。共感と条件は、対立しません。Wantedlyの募集記事に条件をどこまで書くか

2. 記事と面談の印象が、選考で変わった

  • 辞退の理由が「面接で雰囲気が違った」「記事と違う会社に見えた」
  • 面談は良かったのに、選考以降で反応が薄くなった
  • 面接官が記事と面談の記録を読んでいない

直すのは、選考を「面談の続き」にすることと、記事を実態に合わせることです。

3. 内定後に、接点が途切れた

  • 内定を出してから承諾までの間に、会社からの接点がない
  • 辞退の理由が「他社から連絡があって」「迷っているうちに」
  • 内定後に話す相手（面談で話した人、記事に出た社員）を用意していない
  • 内定の連絡が、条件の通知だけで終わっている

直すのは、内定後の場です。

4. 仕事の具体が、他社より薄かった

  • 辞退の理由が「他社のほうが仕事がイメージできた」「何をするかが具体的だった」
  • 記事の「こんなことやります」が、「〇〇の業務全般」で場面になっていない
  • 面談で会社の「なぜ」を話し、仕事の場面を話していない
  • ストーリーが会社の想いばかりで、仕事の一日が見えない

直すのは、記事の「こんなことやります」を最初の数か月の場面で書き、面談で仕事の一日を話すことです。Wantedlyのストーリーの入社エピソードのように、入った人の最初の数か月を書いたストーリーが、具体を補います。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。内定辞退の原因を記事の時点まで戻って見直す作業の時間をお伝えします。

媒体選びを相談する

辞退の理由を、聞いて残す

  • 聞ける範囲で聞く：「今後の参考に、差し支えなければ」
  • 事実と推測を分けて記録する：「他社に決めた（事実）。条件の差（本人の言葉）。選考で印象が下がった様子（推測）」
  • 辞退した候補者に、お礼を送る：Wantedlyでは、辞退した候補者が会社をつながりとして残すことがある。関係を切らない
  • 四つのどれかに分類して、月に一度まとめて見る
  • 面談・面接に出た人にも、「引っかかった様子があったか」を聞く

理由の集め方はWantedlyで面談後に辞退されるときの見直しの「辞退の理由の集め方」と同じです。

辞退した候補者の共通点を、記事の時点まで戻って見る

見る場所見ること
スカウトの文面か、記事のどこで来たか共感で来たか、仕事の具体で来たか、条件で来たか
記事の条件の有無書かれていたか、「応相談」か、無かったか
面談の記録何を話し、候補者が何に反応したか。条件の話をしたか
各段階の記録どの段階で反応が変わったか
内定後の接点内定から承諾の期限までに、何回、誰と接点があったか
辞退の理由事実と推測

「辞退した候補者」と「承諾した候補者」の両方を、この表で並べると、違いが見えます。

内定後に、「読んだ会社の人」と話す場を置く

  • 内定の連絡は、条件の通知だけで終えない：「面談で話した〇〇が、また話したいと言っています」
  • 承諾の期限までに、話す相手を一人以上：面談で話した人、記事やストーリーに出た社員、入社してまもない社員
  • 押さない：「決めましたか」を繰り返さない。Wantedly経由の候補者は、押されると離れる
  • 候補者からの質問に、当日に答える：条件、配属、最初の数か月
  • 承諾の期限を、候補者の状況を聞いて決める：他社の選考が続いているなら、その旨を聞いてよい
  • 内定後も、「お互いを知る」関係のまま：採用側の顔に変えない

承諾した候補者の理由を、次の記事に

  • 「なぜ承諾したか」を聞く：「記事の〇〇が」「面談で△△の話が」「内定後に□□と話せて」
  • 承諾の理由を、記事とストーリーに反映する：承諾した候補者が反応した「こんなことやります」の場面を、次の記事に
  • 内定者に、次のストーリーに出てもらう：本人の同意のうえで。「入社を決めた理由」は、次の候補者に届く。Wantedlyのストーリーの入社エピソード
  • 辞退した候補者の理由と、承諾した候補者の理由を並べる：何が分かれ目だったか

エージェントベストの見解

これは順番の話です。当社がWantedlyで「内定辞退が続く」という相談を受けたとき、内定後のフォローの話をする前に、辞退した候補者の記録を記事の時点まで戻って並べます。そこで、記事に条件がなかった、面談で条件の話を避けていた、「こんなことやります」が場面になっていなかった、が見つかれば、直すのはそこで、内定後のフォローではありません。原因が「内定後に接点が途切れた」だけなら、フォローを直します。当社が勧める順番は、記事の時点、面談、選考、内定後、の順に見ることです。逆から見ると、内定後のフォローを厚くして、共感で来た候補者に「押されている」と感じさせたあとで、原因が記事の条件だったと分かることになります。

まとめ

  • Wantedly経由の内定辞退の理由は、共感で来たが条件で決めた・記事と面談の印象が選考で変わった・内定後に接点が途切れた・仕事の具体が他社より薄かった、の四つ。直す場所が違う
  • 内定後のフォローだけを厚くしても、原因が記事や選考にあれば直らず、共感で来た候補者は押されると離れる
  • 共感で誘う記事ほど、条件を最後に短く書く。共感と条件は対立しない。内定時に条件を初めて出さない
  • 辞退した候補者と承諾した候補者の記録を、来た理由・条件の有無・面談・各段階・内定後の接点で並べて違いを見る
  • 内定後は「読んだ会社の人」と話す場を置き、押さず、「お互いを知る」関係のまま。承諾した候補者の理由を次の記事とストーリーに

よくある質問

共感で来た候補者に、条件を先に見せると、共感が薄れませんか

薄れません。条件を隠されたまま内定で初めて知るほうが、「共感で釣られた」と感じて離れます。記事の最後に条件を短く事実で書き、共感の部分は記事の前半で厚く書けば、候補者は両方を見て話を聞きに来ます。来た候補者は、条件を知ったうえで来ているので、内定時に条件で辞退することが減ります。

内定後に話す相手を、誰にすればよいですか

面談で話した人か、記事やストーリーに出た社員が最も効きます。候補者は、その人の話を読んで、その人と話して、来ています。内定後にその人と話せると、「読んだ会社の人」が続いていると感じます。入社してまもない社員も、候補者に近く、「入る前と入った後」を話せます。人事だけにしないことが大切です。

内定辞退の見直しは、御社に相談できますか

できます。当社は、四つの理由の切り分けの型、理由の集め方の型、記事の時点まで戻って並べる表の型、各理由の直し方の案を支えられます。理由を聞くこと、条件の決定、選考の変更、内定後の接点を持つことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
