OfferBoxのトライアル・デモ画面の使い方｜1週間で確かめる項目

OfferBoxプラン・費用 更新日 2026/9/30

OfferBoxを検討している会社から、「申し込む前に画面を触ってみたい」という相談をよく受けます。料金表を見ただけでは、自社の担当者が毎週どんな作業をすることになるのかが分からないからです。結論から言うと、OfferBoxには1週間デモ画面を試せる無料トライアルがあり、そこから本登録の申込、プランの申込へと進む流れになっています。トライアルの1週間は短いので、何を確かめるかを先に決めてから始めると、申込の判断に使える材料が残ります。この記事では、公式ページで確認できるトライアルとデモの仕組み、1週間で確かめる項目、注意点を整理します（2026年9月30日時点。最新は公式ページでご確認ください）。

結論｜トライアルは「申込の判断材料を集める1週間」

企業向けサイトでは、無料トライアルとして「1週間デモ画面を試せる」ことが案内されています。トライアルの申込フォームには「OfferBox 1週間無料トライアル」「実際にOfferBoxを体験できます」と書かれていて、流れは「トライアル → 本登録申し込み → プランへのお申し込み」の順です。

デモ画面を見る方法はトライアルだけではありません。公式の「よくある質問」によると、個別面談を予約すると、実際の画面で操作の説明や機能の紹介を受けられ、自社が採用したい学生が何人いるかも調べてもらえます。さらに、基本機能とデモ画面の使い方、導入事例を紹介するオンラインセミナーも定期的に開かれています。

方法分かること向いている場面
1週間無料トライアルデモ画面を自分で触った感触担当者が自分で操作して確かめたいとき
個別面談実画面での操作説明・機能紹介、採用したい学生の数の調査自社の条件でどれくらいの学生がいるか知りたいとき
オンラインセミナー基本機能、デモ画面の使い方、導入事例まず全体像をつかみたいとき

3つは、どれか1つを選ぶものではありません。自分で触る前に全体像をつかむ、触ったあとで疑問を個別面談で確かめる、という組み合わせ方ができます。

仕組み｜トライアルから利用開始までの流れ

公式ページで確認できる流れを、順番に並べると次のようになります。

  1. トライアルを申し込む：申込フォームから、1週間の無料トライアルを申し込みます
  2. デモ画面を試す：1週間、デモ画面で操作を確かめます
  3. 本登録を申し込む：使うと決めたら本登録を申し込みます。企業向けトップページでは、導入・利用開始まで「最短3営業日程度」（審査等の状況により前後する場合あり）とされています
  4. プランを申し込む：早期定額型か成功報酬型かを選んで申し込みます

「ご利用の流れ」のページでは、本登録のあと「学生を探す → オファー送信 → オファー承認 → 学生と会う → 内々定」という順で使っていくことが示されています。トライアルで触るのは、このうち前半の「学生を探す」「オファーを送る」あたりの画面の感触だと考えると、見るべきところが絞れます。

ただし、トライアルのデモ画面で具体的にどこまで操作できるのか（実在の学生のプロフィールがどこまで見えるか、オファー送信の操作をどこまで試せるか）は、公開情報では確認できません。「実際に体験できる」とされていますが、本番と同じことがすべてできるとは限らないので、申込のときに範囲を確かめておきます。

トライアルの前に、自社がOfferBoxに向いているかどうかを3媒体を並べて整理します。

媒体選びを相談する

エージェントベストの見解

トライアルの相談で当社が先にお願いしているのは、始める前に「この1週間で何が分かれば申し込むか」を社内で1行にしておくことです。当社は3媒体すべての販売パートナーとして、トライアルを経た会社の相談も受けますが、1週間を「なんとなく触ってみる」で終えると、最後に残るのは「使いやすそうだった」という感想だけです。それでは稟議の材料になりません。たとえば「自社の採用したい条件で検索して、読んでみたいと思う学生が何人いるか」「1人のプロフィールを読んでオファーを書くのに何分かかるか」のように、数えられる問いを決めておくと、1週間の終わりに「週に何通書けそうか」が見えます。検索の感触を先につかみたい場合は、個別面談で採用したい学生の数を調べてもらってからトライアルに入る順番も有効です。触る前に問いを決める、これだけで1週間の使い道が変わります。

確認する項目｜1週間で見ておくこと

トライアルの期間に確かめておきたいことを、申込の判断につながる順に並べます。

  1. 検索の感触：自社が採りたい学生の条件（希望勤務地やインターンシップの有無など）で検索して、どれくらいの学生が出てくるか。検索条件の組み方はOfferBoxの検索条件の組み方に書いています
  2. プロフィールを読む時間：1人のプロフィールを読み、オファーを送りたいかどうか判断するのに何分かかるか。読み方の順番はOfferBoxの学生プロフィールの読み方
  3. オファーを書く時間：1通書くのに何分かかるか。ここから、週に何通書けるかを逆算します
  4. 誰が操作するか：人事だけで回すのか、現場の社員にも読んでもらうのか。トライアルの画面を現場の人にも見てもらうと、協力を頼むときの説明がしやすくなります
  5. 承認のあとの流れ：承認されたあと、メッセージや日程調整をどう進めるか。画面で確かめられない部分は、個別面談で質問します
  6. 申込の範囲：デモ画面でできることと本番でできることの違い。トライアル中に疑問点を書きとめておき、本登録の前にまとめて確認します

この6つのうち、1〜3は数字で残せます。「検索で出てきた学生のうち、読みたいと思ったのが何人」「1通に何分」といった記録が、プランを選ぶときの根拠になります。

注意点

  • 1週間は短い：通常業務の合間に触ると、気づいたら最終日です。初日に「何を確かめるか」を決め、担当者の予定に操作の時間を入れておきます
  • デモ画面でできる範囲は申込時に確かめる：公開情報では、デモ画面で本番のどこまでが操作できるかは確認できません
  • 利用開始までの日数は目安：企業向けトップページの表記は「最短3営業日程度」で、審査等の状況によって前後するとされています。送り始めたい時期から逆算して、余裕を持って本登録を申し込みます
  • プランの費用は別に確認する：トライアルは無料ですが、本登録のあとにプランの申込があります。プランの違いはOfferBoxのプランの選び方、費用の見方はOfferBoxの費用の見方
  • 最新の内容は公式ページで：トライアルの期間や流れは変わることがあります。OfferBoxの企業向けサイトをご確認ください

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。トライアルで測った数字をもとに一緒に考えます。

無料で相談する

エージェントベストの見解

トライアルを経て申し込んだ会社で、最初の1ヶ月に運用が止まる例に共通するのは、トライアルを人事の1人だけで触っていたことです。画面の操作は1人でも覚えられますが、OfferBoxは学生一人ひとりのプロフィールを読んで書く媒体なので、申込後に「現場の人にも読んでほしい」と頼んだ時点で、初めて説明が要ることに気づきます。そこから社内の説明、協力のお願い、書き方のすり合わせをしていると、送り始めるのが数週間遅れます。当社が勧めているのは、トライアルの1週間のうちに、オファーを書いてもらいたい現場の社員に一度画面を見てもらい、1人分のプロフィールを一緒に読むことです。操作を覚えてもらう必要はありません。「こういう学生に、こういう文面を送る媒体だ」と分かってもらうだけで、申込後の協力の頼み方が変わります。社内への説明の仕方はOfferBoxを社内に説明するときにまとめています。

まとめ

  • OfferBoxには、1週間デモ画面を試せる無料トライアルがある。流れは「トライアル → 本登録申し込み → プラン申し込み」
  • 個別面談では実画面での操作説明・機能紹介を受けられ、採用したい学生が何人いるかも調べてもらえる。基本機能とデモ画面を紹介するオンラインセミナーもある
  • 1週間で確かめるのは、検索の感触、プロフィールを読む時間、オファーを書く時間。数字で残すと申込の根拠になる
  • デモ画面でどこまで操作できるかは公開情報では確認できないので、申込時に範囲を確かめる
  • オファーを書いてもらう現場の社員にも、トライアル中に一度画面を見てもらう

よくある質問

トライアルに費用はかかりますか

公式の申込フォームでは「1週間無料トライアル」と案内されています。費用がかかるのは、本登録のあとにプランを申し込んでからです。プランの金額や条件は料金ページで確認し、申込前に見積もりを取っておくと社内の説明がしやすくなります。

トライアル中に実際の学生へオファーを送れますか

公開情報では、トライアルのデモ画面でオファー送信がどこまでできるかは確認できません。「実際にOfferBoxを体験できます」とされていますが、本番の送信と同じ扱いかどうかは、申込の際に確認してください。本番のオファー送信は、本登録とプランの申込のあとになります。

トライアルより先に相談してもよいですか

構いません。公式にも、個別面談で実画面の説明を受けたり、採用したい学生の数を調べてもらったりする方法があります。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、申込前の比較から相談を受けています。代理店手数料は媒体側から支払われるため、企業の料金は各媒体の正規料金のままです。初めての新卒採用なら初めての新卒採用でOfferBoxから始めるときの順番もあわせてご覧ください。
