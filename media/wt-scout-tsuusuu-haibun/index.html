Wantedlyのスカウト通数の配分の考え方｜募集ごとに均等に分けず、「読める数」を、面談枠から逆算した募集に寄せる

スカウトに送れる上限があると、「使い切らないともったいない」と考えて、上限まで送ることが目的になります。複数の募集があれば、均等に分けます。ところが、上限を使い切るために読まずに送ればテンプレになり、均等に分ければ急ぎの募集に足りず、急がない募集に余ります。結論から言うと、スカウトの通数は、上限からではなく「週に読める数」と「返信に対応できる数」から決め、募集ごとの面談枠から逆算して、急ぎの募集に寄せます。余った上限は使い切りません。 この記事では、やりがちな失敗、配分の軸、逆算の手順、募集ごとの寄せ方、時期での増減、送る人が複数のときの分け方、見直し、分担を整理します。送信の上限や仕組みはプランと時期で異なるので、現在の仕様は管理画面とヘルプで確認してください。この記事は、その範囲の中でどう配分するかの考え方の話です。

この作業の目的｜「送れる数」ではなく「活かせる数」を送る

通数の配分の目的は、上限を使い切ることではなく、「読んで書いた文面を、返信に対応できる範囲で、必要な募集に送る」ことです。

送れる数より、活かせる数のほうが小さいのが普通です。読める時間、返信に対応できる時間、面談に出られる枠が、活かせる数を決めます。活かせる数を超えて送ると、テンプレになるか、返信を待たせるか、面談に出られないか、のどれかが起きます。

やりがちな失敗

失敗何が起きるか
上限を使い切ることが目的になる読まずに送る。テンプレになり、返信が来ない
募集ごとに均等に分ける急ぎの募集に足りず、急がない募集に余る
返信に対応できない数を送る返信が来ても放置。相手が離れる
面談に出られる枠を超えて送る返信した人を待たせる
月初に全部送って、月末は送らない返信が月初に集中し、対応が追いつかない
送る人ごとに好きなだけ送る全体の数が見えない。同じ人に複数の募集から送る
反応が無い募集に、送り続ける募集記事が問題なのに、数で補おうとする

最も多いのは、最初の「上限を使い切る」です。上限が「目標」に見えてしまいます。

配分の軸

軸決め方
週に読める数送る人が、プロフィールを読んで一文を書ける数。これが送る数の上限
返信に対応できる数返信が来たときに、翌日までに返せる数
募集ごとの面談枠その募集で、話す人が面談に出られる枠。ここから必要な返信の数が決まる
募集の緊急度いつまでに採りたいか。急ぎの募集に寄せる
募集記事の状態整っていない募集には送らない。送る前に整える

「読める数」と「対応できる数」と「面談枠」の3つが、全体の上限です。プランの上限は、その外側にあることが多く、使い切る必要はありません。

いま使っている媒体の運用の相談だけでも構いません。募集ごとの面談枠から、送る数を一緒に逆算します。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「上限まで送らないと、契約した分を無駄にしている」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、上限を使い切っている会社が、返信と面談で結果を出しているとは限りません。使い切るために読まずに送った文面は返信が来ず、送った数だけ時間が消えます。逆に、上限の一部しか使っていない会社が、読んで書いた文面で返信を得て、面談枠を埋めていることがあります。当社は、契約の上限を「使い切る目標」ではなく「これ以上は送れない線」として扱うようお願いしています。目標は、面談枠が埋まることです。面談枠が埋まるなら、送る数は少なくて構いません。無駄なのは、送らなかった上限ではなく、読まずに送った文面のほうです。

逆算の手順

送る数は、面談枠から逆算します。

  1. 募集ごとに、面談に出られる枠を数える：話す人が、週に何回、面談に出られるか
  2. その枠を埋めるのに、必要な返信の数を考える：返信した人が全員面談に来るわけではないので、少し多め
  3. 必要な返信を得るのに、送る数を考える：自社の台帳で、送った数と返信の数の関係を見る。台帳が無ければ、まず読める数で送って台帳を作る
  4. 送る数が、週に読める数を超えていないかを見る：超えていれば、読める数まで減らすか、読む人を増やす
  5. 募集が複数なら、緊急度で寄せる：急ぎの募集に多く、急がない募集に少なく
  6. 合計が、返信に対応できる数を超えていないかを見る

「面談枠から逆算する」は、OfferBoxの運用で書いた考え方と同じです。OfferBoxの人数計画の立て方で書いたのと同じ順番で、Wantedlyでも逆算します。

募集ごとの寄せ方

募集の状態配分
急ぎで、募集記事が整っていて、面談枠がある多く寄せる
急ぎだが、募集記事が整っていない送る前に募集記事を整える。整うまで送らない
急がないが、募集記事が整っている少なく。途切れない程度に
反応が無い（返信が来ない）増やさない。募集記事と文面を見直してから
面談枠が無い（話す人が忙しい）送らない。返信が来ても対応できない

「反応が無い募集に増やさない」が要点です。返信が来ない理由が募集記事や文面にあるなら、数を増やしても返信は増えず、読む時間だけが増えます。見直しの手順は募集記事の反応を見て直す手順で書きました。

時期での増減

  • 募集の締切が近い：その募集に寄せる。ただし、相手が動く時間を残す
  • 面談に出る人の繁忙期：その募集は減らす。対応できない
  • 連休の前：減らす。返信が連休明けに集中する
  • 募集が終わった：その募集への配分をゼロにし、他に回す
  • 新しい募集が出た：募集記事が整ってから配分する

月の中でも、均等に送るより、対応できる週に送ります。送る時間の考え方はスカウトを送る曜日・時間の考え方で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。面談枠から逆算した送る数と、それに要る読む時間をお伝えします。

媒体選びを相談する

送る人が複数のときの分け方

  • 募集ごとに送る人を決める：その職種の人が、その募集を送る。同じ人に複数の募集から送らない
  • 全体の数を、人事が見る：送る人ごとの数を合計し、対応できる数と面談枠を超えていないかを見る
  • 台帳を共通にする：誰に誰が送ったかが見える。重複を防ぐ
  • 読める数は、送る人ごとに違う：一律に割り振らない。その人が週に読める数で
  • 文面の型と見本は共通：送る人が違っても、トーンと3段の構成は揃える。型の考え方はスカウト文面の書き方

「同じ人に複数の募集から送らない」は、複数の送る人がいるときに最も起きやすい失敗です。台帳で防ぎます。

余った上限は、使い切らない

月末に上限が余っていても、読まずに送りません。

  • 余った分は、翌月に持ち越せるかを確認する：仕様は管理画面で
  • 持ち越せなくても、使い切らない：読まずに送った文面は、返信が来ず、会社の印象を下げる
  • 余りが続くなら、契約の見直しを検討する：上限が実態より大きい。減らす選択もある
  • 余りを「読む時間を増やす」に使う：送る数より、一通あたりの読む時間を増やすほうが、返信は増える

上限が余ることは、失敗ではありません。読める数が上限より小さいなら、それが自社の適正な数です。

月に一度の見直し

見ること直すこと
募集ごとの、送った数・返信・面談反応が無い募集の配分を減らし、募集記事を見直す
返信への対応の速さ遅れているなら、送る数を減らすか、対応する人を増やす
面談枠の埋まり具合埋まっているなら減らす。空いているなら増やすか、募集記事を見直す
読める数と送った数の差読まずに送っていないか
重複（同じ人に複数の募集）台帳で確認

数字は、大小より変化を見ます。「先月より返信が減った」なら、送る数ではなく、文面か募集記事か時期を見ます。

エージェントベストの見解

これをやる前に、先に決めておかないと配分が決まらないことがあります。「募集ごとの面談枠」です。当社がWantedlyのスカウトの配分を支えるとき、逆算の型と配分の案は当社が出せますが、「その募集で、話す人が週に何回面談に出られるか」が決まっていないと、逆算の起点がありません。送る数から考え始めると、上限が起点になり、使い切る方向に寄ります。当社が最初にお願いするのは、募集ごとに「話す人と、その人が出られる枠」を決めてもらうことです。枠が決まれば、送る数は自然に決まり、読む時間も決まります。枠が無い募集には、送る意味がありません。配分は、上限からではなく、面談枠から始めます。

まとめ

  • 通数は上限からではなく、「週に読める数」「返信に対応できる数」「募集ごとの面談枠」から決める
  • 上限を使い切る、募集ごとに均等、対応できない数を送る、反応が無い募集に増やす、が失敗
  • 面談枠→必要な返信→送る数→読む時間、の順に逆算し、急ぎで募集記事が整っている募集に寄せる
  • 時期（締切・繁忙期・連休）で増減し、送る人が複数なら募集ごとに担当を決めて共通の台帳で重複を防ぐ
  • 余った上限は使い切らない。余りが続くなら契約の見直しも。月に一度、変化を見て直す

よくある質問

上限が余ると、上司に「使っていない」と言われます

送った数ではなく、返信と面談の数で報告します。「読んで書いた文面を〇件送り、返信が来て、面談枠が埋まっている」なら、上限の余りは問題ではありません。使い切るために読まずに送ると、返信が減り、会社の印象も下がります。上限は「これ以上は送れない線」で、目標ではないことを共有します。

募集が多く、どれに寄せるか決められません

面談枠がある募集と、募集記事が整っている募集に絞ります。面談枠が無い募集、募集記事が整っていない募集には、送っても活かせません。残った募集を、緊急度で並べます。

スカウトの通数の配分は、御社に相談できますか

できます。当社は、逆算の型、配分の案、台帳の型、月の見直しの型を支えられます。面談枠の確保、送ること、返信への対応、契約の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
