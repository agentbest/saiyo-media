WantedlyとLinkedInの違い｜同じビジネスSNSでも、プロフィールの中心が違う

「WantedlyとLinkedInは、どちらもビジネスSNSと聞くが、採用ではどう違うのか」「外国籍の候補者や海外在住の候補者を採りたいが、どちらを使えばいいか」という相談を受けます。結論から言うと、同じビジネスSNSでも、プロフィールの中心が違います。LinkedInは職務経歴を中心にした世界規模のSNS、Wantedlyは会社の想いを中心にした国内のSNSです。 採りたい人がどこにいて、何を読んで会社を選ぶかで、先に検討する媒体が決まります。Wantedlyはウォンテッドリー株式会社が運営する、会社と人がつながるビジネスSNSで、募集情報を掲載する場です。LinkedInはMicrosoft傘下の、職務経歴とビジネス上のつながりを軸にした世界規模のSNSです。この記事ではLinkedInの仕様や料金には触れず、プロフィールの中心の違いが採用の設計にどう効くかを整理します。

プロフィールの中心が違う

LinkedInでは、人のプロフィールの中心は職務経歴です。どの会社で、どの職種を、どれくらいの期間、何をしたか。学歴、資格、推薦。企業はそれを読んで、経験でつながりを作り、スカウトを送ります。会社のページもありますが、人の側の情報が職務経歴で構成されています。

Wantedlyでは、会社のページの中心は想いです。「なにをやっているのか」「なぜやるのか」「どうやっているのか」。人のプロフィールもありますが、候補者が読むのは会社が書いたストーリーで、そこへの共感が入口です。

観点WantedlyLinkedIn
プロフィールの中心会社の想い・日常個人の職務経歴
集まる人の広がり主に国内世界規模
企業が読むもの志向・プロフィール職務経歴・つながり
候補者が読むもの会社ページ・ストーリー会社のページ・スカウトの文面・つながりの先
入口の動きまず会って話すつながる・スカウトに返信する

どちらも「SNS」で、企業と人がつながる場である点は同じです。違うのは、つながる根拠が「会社の想いへの共感」か「職務経歴とビジネス上のつながり」かです。

採りたい人がどこにいるかで分かれる

対象の広がりが違うので、採りたい人がどこにいるかが最初の問いになります。

国内で、日本語で働く人を採るなら、Wantedlyの会社ページとストーリーが読まれる範囲に候補者がいます。外国籍の候補者や海外在住の候補者を採るなら、LinkedInの職務経歴で探せる範囲に候補者がいます。

ただし、「海外在住の候補者を採りたい」と「日本で働く外国籍の候補者を採りたい」は別です。後者は、すでに日本にいて、日本語か英語で会社を探している人で、Wantedlyの会社ページを読んでいることもあります。

  • 国内で日本語で働く人 → Wantedlyの範囲にいる
  • 海外在住で、日本に来て働く人 → LinkedInの範囲で探す
  • 日本にいる外国籍の人 → 両方の範囲にいる。会社ページの言語で分かれる

採りたい人がどこにいて、何語で会社を探しているか。整理するだけでも媒体は絞れます。

媒体選びを相談する

エージェントベストの見解

媒体を比べるときに「世界規模だから登録者が多い」という説明を判断材料にする会社は多いのですが、登録者の広がりは、自社の母集団ではありません。世界規模のSNSにいる人のうち、自社の職種で、自社の勤務地で、自社の言語で働ける人だけが母集団です。その絞り込みをせずに「多いほうが良い」と選ぶと、送っても返事がなく、来ても条件が合わない、となります。当社は3媒体すべての販売パートナーとして、Wantedlyの契約後の運用まで見ていますが、外国籍の候補者を採っている会社に共通するのは、「日本にいる人か、海外にいる人か」を先に決めていることです。日本にいる人なら、Wantedlyの会社ページを英語でも書き、国内の範囲で集める。海外にいる人なら、職務経歴で探す型で、勤務地と言語の条件を先に置く。広がりの大小ではなく、自社の条件で絞ったあとに誰が残るかで選ぶことを勧めます。

会社の見せ方と、言語が違う

Wantedlyでは、会社の想いを日本語のストーリーで書きます。日本の候補者が、会社の日常と考え方を読んで共感する設計です。英語で書くこともできますが、土台は日本語の記事です。

LinkedInでは、会社のページと募集の内容を、対象の候補者の言語で書きます。海外在住の候補者を対象にするなら英語が前提で、職務経歴の文脈で読まれるので、仕事の内容、求める経験、勤務地、言語の条件を具体的に書くことが要ります。

観点WantedlyLinkedIn
会社の見せ方想いと日常をストーリーで仕事の内容と条件を具体的に
言語日本語が土台。英語も可対象の候補者の言語
更新の頻度通年でストーリーを書き足す募集ごとに整える
効く相手考え方で会社を選ぶ人経験と条件で会社を選ぶ人

「会社の想い」を英語で書くのは、日本語で書くより難しいことが多いです。日本語で言葉になっていない想いは、英語にもなりません。外国籍の候補者を採る場合でも、先に日本語のストーリーが要ります。

この条件ならどちらを先に検討するか

優劣ではなく、先に検討する順番として置きます。

  • 国内で日本語で働く人を採る。会社の想いが言葉になっている → Wantedlyを先に
  • 海外在住の候補者を採る。仕事の内容と条件を英語で具体的に書ける → LinkedInを先に
  • 日本にいる外国籍の候補者を採る → Wantedlyの会社ページを英語でも書く。国内の範囲で集める
  • 職務経歴で絞って、経験のつながりで送りたい → LinkedInを先に。構造はWantedlyとビズリーチの違いで書いた「経験か共感か」と同じ
  • 会社の想いがまだ言葉になっていない → 職務経歴で先に候補者に会い、面談で「自社の何が響くか」を掴んでからWantedlyへ
  • 英語で会社の想いを書きたいが、日本語の記事がまだない → 先に日本語のストーリーを書く

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。言語と対象で、必要な準備が変わります。

運用の相談をする

併用するときの分担

両方を使うなら、次の分担が分かりやすいです。

  1. 国内の候補者と、会社の見せ方はWantedly：日本語のストーリーで想いを書き、面談の前後に読んでもらう
  2. 海外在住の候補者はLinkedIn：職務経歴で探し、仕事の内容と条件を対象の言語で書いて送る
  3. 英語の会社ページは、日本語のストーリーから作る：想いは先に日本語で言葉にし、それを英語に直す。逆の順番は難しい
  4. 面談の入口は1つにする：どちらから来た人も、まず会って話す面談から始め、選考に進む意思を確認してから選考フローに乗せる
  5. 言語ごとに書く人を決める：日本語のストーリーを書く人と、英語の募集を書く人は、同じ人でなくてよい

海外在住の候補者が、職務経歴のつながりで自社を知り、英語の会社ページで想いを読んでから面談に来る。この流れができると、条件は合うが考え方が合わない、というずれが減ります。

エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。それは「日本語のストーリーが、先にあるか」です。外国籍の候補者を採りたい会社が、英語の会社ページから作り始めることがありますが、日本語で言葉になっていない想いを英語で書くのは、ほぼできません。当社が契約後の運用まで見ている経験では、英語の会社ページが読まれている会社は、日本語のストーリーを先に書き、それを英語に直した会社です。順番を逆にすると、英語のページは仕事の内容と条件だけになり、想いで集める型ではなく条件で集める型と変わらなくなります。それなら、最初から職務経歴で探す型に絞ったほうが、時間の無駄がありません。外国籍の候補者を採る場合でも、まず日本語で想いを書く。英語はそのあと。この順番だけは崩さないことを勧めます。

まとめ

  • Wantedlyは会社の想いを中心にした国内のSNS、LinkedInは職務経歴を中心にした世界規模のSNS
  • 採りたい人がどこにいるかが最初の問い。国内か、海外在住か、日本にいる外国籍の人か
  • 登録者の広がりは自社の母集団ではない。自社の職種・勤務地・言語で絞ったあとに誰が残るかで選ぶ
  • 会社の想いは、先に日本語で言葉にしてから英語に直す。逆の順番は難しい
  • 併用するなら、国内の候補者と会社の見せ方はWantedly、海外在住の候補者はLinkedIn

よくある質問

外国籍の候補者を採るなら、LinkedInを選ぶべきですか

「海外在住の人」か「日本にいる人」かで分かれます。海外在住の人を採るなら、職務経歴で探せるLinkedInの範囲で、勤務地と言語の条件を先に置きます。日本にいる人なら、Wantedlyの会社ページを英語でも書き、国内の範囲で集める形もあります。

Wantedlyの会社ページを英語で書けば、海外の候補者も来ますか

集まる人の広がりは主に国内なので、海外在住の人が読みに来る前提の媒体ではありません。英語で書く意味があるのは、日本にいる外国籍の候補者に向けるときです。海外在住の人を対象にするなら、職務経歴で探す型を先に検討します。

LinkedInの企業向けサービスも御社経由で申し込めますか

当社が販売パートナーとして窓口になるのは、OfferBox・Wantedly・ワンキャリアの3媒体です。LinkedInの企業向けサービスは各社の窓口になりますが、採りたい人がどこにいるかの整理や、日本語と英語で会社をどう見せるかは、Wantedlyの運用を見ている立場からご相談いただけます。3媒体の全体像は3媒体の違いと選び方にまとめています。
