大学院生を採る媒体の選び方｜研究室の山の外で会う

媒体比較・選び方新卒採用の媒体選び（時期・予算別） 更新日 2026/11/4

大学院生を採りたい会社が、学部生と同じ媒体を同じ時期に使っていると、「大学院生からの返信が少ない」「面談の日程が合わない」という悩みが出やすくなります。大学院生は研究の比重が大きく、学会や実験、修士論文や博士論文の予定の中で就職を考えるからです。結論から言うと、大学院生を採る媒体は、研究室の忙しい時期の外で会えるかどうかで選び、修士と博士で年間を分けて考えるのが基本です。 この記事では、大学院生の年間を軸に、時期ごとに働く型と、研究の話ができる人の置き方を整理します。

学部生と同じ年間に乗せると起きること

大学院生を学部生と同じ年間で扱うと、次のようなことが起きやすくなります。

  • 研究室の忙しい時期に文面や説明会の案内が届き、読まれずに流れる
  • 選考の回数が多く、研究の時間を削って参加することになり、途中で辞退される
  • 面談で研究の話を聞かれても、人事だけでは答えられない
  • 修士と博士を同じ募集で扱い、処遇や仕事の説明があいまいになる

大学院生の採用の年間は大学院生の採用スケジュールで詳しく書いています。媒体選びでは、この年間のうち「研究室の山の外」にあたる時期を探し、そこに会う場を置くことから考えます。

修士と博士で年間を分ける

区分年間の特徴媒体を使うときの考え方
修士入学して間もなく就職を考え始める学生もいる。学会や修士論文の時期が山になる早い時期に会社を知ってもらい、山の時期は連絡を控えめに。山の合間に面談を置く
博士研究の区切りや学位の見通しで動く時期が決まる。一律の就職活動の時期に乗らないことが多い時期を決めつけず、個別に予定を聞く。研究の中身で一人ずつ届ける

修士の学生は学部生の年間と重なる部分もありますが、研究の山の位置が違います。博士の学生は、一律の時期に合わせるより、一人ずつ予定を聞いて進めるほうが合いやすい傾向があります。

修士と博士で年間をどう分けるか。大学院生の採用の組み方を一緒に整理します。相談だけでも構いません。

媒体選びを相談する

時期ごとに働く型

大学院生に会う型を、時期で並べます。

  1. 研究室の山の前：スカウト型（OfferBox、ワンキャリアのスカウトなど）で、研究の中身に触れた文面を届ける。面談の形と時期を文面に書いておく
  2. 山の時期：新しく送る数を絞る。すでに接点のある学生には、予定を聞く短い連絡だけにする
  3. 山の合間・休みの期間：技術の人が出る少人数のイベントや、研究の話をする面談を置く
  4. 推薦の流れが動く時期：推薦で進む学生と、自由応募の学生で、選考の流れの説明を分ける

スカウト型は、送る時期と相手を企業が決められるので、研究室の山を避けて動かしやすい型です。文面で見られていることは、OfferBoxで大学院生にオファーするときの考え方とワンキャリアで大学院生にスカウトを送るときの考え方でまとめています。

エージェントベストの見解

大学院生に送る文面で、返信が変わりやすいのは「面談の形と時期」を書いているかどうかです。大学院生は、興味のある会社でも、研究の時間をどれだけ取られるかが分からないと返信をためらいます。当社が勧めているのは、文面の最後に「研究の予定を先にうかがい、その外で、オンラインで短く話す形でも構いません」と書くことです。媒体ごとの違いより、この一文の有無で反応が分かれる場面を多く見てきました。もう一つは、面談に出る人です。研究の話を聞ける技術の人が最初の面談に出られないなら、送る数を増やすより、出られる時期まで送るのを待つほうが、あとの選考が続きやすくなります。

研究の話ができる人を、どこに置くか

大学院生の採用では、媒体の選び方と同じくらい、研究の話ができる人を選考のどこに置くかが成果を左右します。

  • 最初の面談：技術の人が研究の話を聞く。人事は会社の全体と選考の流れを伝える
  • 選考の中盤：配属を想定した部署の人と、研究と仕事のつながりを話す
  • 内定の前後：処遇や配属の考え方を、修士と博士で分けて説明する

技術の人の時間は限られます。媒体を申し込む前に、年間のどの時期に何回、面談に出られるかを確かめておくと、送る時期と数が決めやすくなります。

技術の人の時間から、送る時期と数を逆算する。申込前に、運用に要る時間の見積もりだけでも聞いてみませんか。

運用の相談をする

エージェントベストの見解

大学院生の採用で、自社で持つべきなのは「研究の話を聞くこと」と「処遇の説明」です。研究の中身を理解し、それが仕事のどこで生きるかを話せるのは社内の技術の人で、外の手では代われません。処遇も、修士と博士でどう扱うかは会社が決めることです。一方で、研究室の予定を学生に聞く連絡や、面談の日程の調整、研究の中身に触れた文面の下書きは、技術の人の考えを共有したうえで外に出しても質を保ちやすい部分です。技術の人の時間を、聞くことと話すことに集めると、少ない時間でも大学院生との接点を続けやすくなります。

この条件なら、どれを先に検討するか

  • 研究室との関係がある：研究室や学校を通した接点を主にし、媒体は関係のない大学の学生に届ける補助にする
  • 研究室との関係がない：スカウト型で研究の中身に触れて一人ずつ届ける形を先に検討する。送る時期は研究室の山を避ける
  • 研究を仕事に生かすか迷っている学生にも会いたい：掲載型や少人数のイベントで、研究と仕事のつながりを読める・聞ける場を作る
  • 博士の学生を採りたい：一律の時期に合わせず、個別に予定を聞ける型を選ぶ。面談に出る技術の人の時間を先に確保する

どの条件でも、型を一つに決めきる必要はありません。年間の前半は会社を知ってもらう型、研究室の山の合間は会って話す型、と時期で持ち替えると、研究の予定に合わせやすくなります。

まとめ

  • 大学院生を採る媒体は、研究室の山の外で会えるかどうかで選ぶ
  • 修士と博士で年間を分ける。博士は一人ずつ予定を聞いて進める
  • スカウト型は、送る時期と相手を決められるので、山を避けて動かしやすい
  • 文面に面談の形と時期を書くと、研究の時間を心配する学生が返信しやすくなる
  • 研究の話ができる技術の人を、最初の面談に置く

よくある質問

大学院生向けには、学部生と別の媒体を使ったほうがよいですか

媒体を分けるより、時期と文面と面談に出る人を分けることを先に考えます。同じ媒体でも、研究室の山を避けて送り、研究の話ができる人を置くことで、大学院生への届き方は変わります。理系に絞った媒体を併用するなら、OfferBoxとLabBaseの違いが参考になります。

博士の学生を採ったことがありません。何から決めればよいですか

迎える職種と処遇を先に決めます。博士の学生は、研究を生かせる仕事か、処遇がどうなるかを気にすることが多いので、そこがあいまいなまま送ると、面談で答えられなくなります。

研究室の山の時期が分かりません

学生本人に聞くのが確かです。最初の連絡で、研究の予定を先に聞く一文を入れておくと、その後の日程が組みやすくなります。理系学生の年間の見方は理系学生を採る新卒媒体の選び方にもまとめています。
