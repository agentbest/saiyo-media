採用広報でやりがちな失敗｜止まる・届かない・ずれる

採用広報を始めたものの、思ったように採用につながらない。そう感じたとき、何が悪いのかを一つずつ挙げていくと、直すべきことが多すぎて手が止まります。結論から言うと、採用広報の失敗は「発信が止まる」「届いてほしい人に届かない」「実態とずれる」の三つに分けて見直すのが基本です。 三つのどれに当たるかが分かれば、直す場所が絞れます。この記事では、それぞれの典型と原因、見直しの順番を整理します。

失敗は三つに分けて見る

採用広報でよく起きる失敗を、三つに分けます。

失敗の型起きていること主な原因
止まる発信の頻度が落ち、更新が途絶える担当が一人、確認が詰まる、題材が尽きる
届かない発信は続いているが、採用したい人に読まれない対象が決まっていない、届ける経路がない
ずれる読まれているが、選考や入社後に行き違いが出る良いことだけを書く、情報が古い

三つは順番に起きることが多くあります。まず発信が続かないと、届くかどうか以前の問題になります。続いても届かなければ、効果は見えません。届いても実態とずれていれば、選考の途中や入社後に問題が出ます。見直すときも、止まる、届かない、ずれるの順に確かめます。

失敗その一｜発信が止まる

最も多いのが、始めて数か月で発信が止まる失敗です。典型は次のとおりです。

  • 担当が一人で抱える：企画も取材も文章も一人で持ち、本来の業務が忙しくなると止まる
  • 確認が返ってこない：現場や経営者の確認待ちで、書き上げた記事が公開できない
  • 題材が尽きる：最初の数本で伝えたいことを書き切り、次に何を書けばよいか分からなくなる
  • 完成度を求めすぎる：一本ごとに作り込み、公開までに時間がかかる

止まる失敗の多くは、仕組みの問題です。担当者の頑張りで続けようとすると、その人が忙しくなった時点で止まります。続ける仕組みの作り方は採用広報を続けるための仕組みで詳しく扱っています。

広報が止まっていても、媒体の運用は進められます。いま使っている媒体の運用の相談だけでも構いません。

運用の相談をする

エージェントベストの見解

発信が止まる会社に共通するのは、広報を「媒体とは別の仕事」として扱っていることです。当社は媒体の申込後の運用まで見ていますが、広報の記事を書く担当と、スカウトや掲載ページを作る担当が分かれていて、同じ社員に別々に取材を頼んでいる会社もあります。社員の負担は二重になり、どちらかが止まります。勧めているのは、広報の題材を媒体の場面から逆に決めることです。スカウトの文面に添えたい社員の声、掲載ページに載せたい仕事の流れ、面談の前に送りたい会社の紹介。媒体で必要になる中身を先に挙げ、それを広報の記事として書く。こうすると、題材が尽きにくく、書いたものが媒体で使われるので、続ける理由もはっきりします。

失敗その二｜届いてほしい人に届かない

発信は続いているのに、採用につながらない。この場合は、届いてほしい人に届いていない可能性があります。

  • 対象が決まっていない：誰に読んでほしいかを決めずに書き、誰にも刺さらない記事になる
  • 社内向けの言葉で書く：部署名や社内の言い方をそのまま使い、外の人に伝わらない
  • 届ける経路がない：自社の採用ページに載せただけで、候補者が見る場所に出していない
  • 媒体と切り離されている：スカウトや掲載ページから記事への導線がない

届かない失敗を直すには、まず「誰に届けたいか」を一文で書き直します。そのうえで、その人がどこで会社の情報に触れるかを考えます。新卒の学生ならOfferBoxのスカウトを受け取ったときやワンキャリアの掲載ページを見たとき、中途の候補者なら利用している媒体の求人を見たときかもしれません。その場所から記事へつなぐ導線を作ります。

効果の測り方は採用広報の効果の測り方で整理しています。届いているかどうかを確かめる方法も扱っています。

失敗その三｜実態とずれる

読まれていても、実態とずれていれば、選考や入社後に問題が出ます。

  • 良いことだけを書く：制度や雰囲気の良さを並べ、仕事の大変さに触れない
  • 情報が古い：組織や制度が変わったのに、記事を更新していない
  • 一部の部署だけを見せる：目立つ部署の話だけを載せ、募集している職種の実態が伝わらない
  • 言葉が抽象的：「風通しが良い」「成長できる」のような言葉が、具体の裏付けなく並ぶ

ずれる失敗は、選考の途中の辞退や、入社後の早い時期の離職として表れることがあります。面接で「記事で読んだ話と違う」と言われたら、ずれが起きている合図です。仕事の大変さも含めて書く考え方は採用説明資料の作り方でも触れています。

広報で伝えたい会社の姿と、媒体のページに載せている中身がそろっているか。一緒に見直します。

無料で相談する

エージェントベストの見解

当社は媒体で採る支援と人材紹介の両方をしているので、候補者が入社を決めた理由と、辞退した理由を両側から聞く機会があります。辞退の理由として挙がりやすいのは、「事前に読んだ情報と、面接で聞いた話が違った」というものです。広報の記事で明るい雰囲気を伝え、面接で仕事の厳しさを知らされると、候補者は裏切られたように感じます。逆に、記事で大変さを先に伝えていた会社では、面接で同じ話を聞いても、候補者は「書いてあったとおりだ」と受け止めます。ずれを防ぐために勧めているのは、記事を公開する前に、その職種の面接官に一度読んでもらうことです。面接で話している内容と記事の内容が合っているかを確かめるだけで、ずれの多くは防げます。

失敗を防ぐために最初に決めること

これから採用広報を始める会社は、次の四つを最初に決めておくと、三つの失敗を防ぎやすくなります。

  1. 対象を一文で書く：誰に読んでほしいか
  2. 使う場所を決める：書いたものを、どの媒体のどの場面で使うか
  3. 担当と確認の流れを決める：誰が書き、誰が確認し、何日で返すか
  4. 更新の時期を決める：組織や制度が変わったとき、何を見直すか

この四つを一枚にまとめ、関わる人全員に渡しておきます。始めたあとで失敗に気づいたときも、この一枚に戻って、どこが崩れたかを確かめられます。

まとめ

  • 採用広報の失敗は「止まる」「届かない」「ずれる」の三つに分けて見直す
  • 止まる失敗は仕組みの問題。題材を媒体の場面から逆に決めると続きやすい
  • 届かない失敗は、対象と届ける経路を決め直す
  • ずれる失敗は、公開前に面接官に読んでもらうと防ぎやすい
  • 始める前に、対象、使う場所、担当と確認、更新の時期を一枚にまとめる

よくある質問

失敗に気づいたら、それまでの記事は消すべきですか

消す前に、どの失敗に当たるかを確かめます。情報が古い記事は更新し、実態とずれている記事は書き直すか取り下げます。届いていないだけの記事は、導線を作り直せば使えることがあります。

担当が一人しかいません。止まらないようにするには

一人で続けるには、作業を小さくすることが大切です。一本を長く書くより、短い発信を定期的に続けるほうが止まりにくくなります。作業の一部を外に頼む方法は採用広報を外に頼むときの範囲で扱っています。

社員の協力が得られず、題材が尽きました

社員に大きな協力を頼むより、短い一言をもらう形から始めると引き受けてもらいやすくなります。頼み方は採用広報に社員の協力を得る方法にまとめています。
