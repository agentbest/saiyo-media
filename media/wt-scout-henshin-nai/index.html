Wantedlyのスカウトに返信が来ないときの対応｜四つの理由と直す段

Wantedly課題別 更新日 2026/9/12

Wantedlyでスカウトを送っている。ところが、返信が来ない。送った数は増えているのに、返信の記録は空のまま。「Wantedlyのスカウトは返信が来ないものだ」と考える前に、返信が来ない理由を分けます。結論から言うと、返信が来ない理由は四つです。相手が開いていない、開いたが「自分宛」と思わなかった、「自分宛」と思ったが話を聞きに行く先が見えない、相手がいま動く時期ではない。段で切り分け、件名と冒頭、相手から拾った一文、文面の末尾の面談の形、時期の読み方を、理由ごとに直します。返信が来ない相手を追わず、来ない期間に数を増やさず、返信が来た文面と来なかった文面を並べて直す場所を決めます。 この記事では、四つの理由とサインと直し方、追わないこと、数を増やさないこと、並べて見ること、名義と時間帯、分担を整理します。スカウトの基本はWantedlyのスカウトの基本、返信が来たあとはWantedlyでスカウトに返信が来たあとの進め方、フォローはWantedlyのスカウト後のフォロー連絡で書きました。この記事は、「返信が来ない」という症状から逆に辿るものです。

この作業の目的｜「来ない」を、直せる段に分ける

返信が来ないとき、送る側にできることは、「文面を直す」「相手を変える」「時期を待つ」のどれかです。どれをするかは、どの段で止まっているかで決まります。

目的は、止まっている段を一つ指し、そこだけを直すことです。全部を同時に直すと、何が効いたか分かりません。

返信が来ない、四つの理由

理由段サイン直す場所
1. 開かれていない開封管理画面で開封の動きが見えない（見える範囲は現在の仕様で確認）件名、送る人の名義、送る時間帯
2. 「自分宛」と思われなかった冒頭開かれているが返信がない。冒頭が会社説明か、相手に触れる一文が「見出し」相手のプロフィールとストーリーから拾った一文、冒頭の順番
3. 行く先が見えない末尾冒頭は相手のことなのに返信がない。末尾が「ぜひご応募ください」か、面談の形が書かれていない末尾に、選考ではない・誰と・どんな形、を一段落
4. いま動く時期ではない相手文面は整っていて、同じ文面で他の相手からは返信がある時期を読む。送り直しは一度だけ

「1→2→3→4」の順に疑います。「4」を最初に疑うと、「相手のせい」で終わり、文面が直りません。

1. 開かれていないとき

  • 件名が、「スカウトのご案内」「採用について」になっていないか：一覧で他社と区別がつかない。相手に触れる一文を件名に。Wantedlyのスカウトの件名
  • 送る人の名義が、会社名や人事部になっていないか：現場の人か代表の名前で。Wantedlyのスカウトを代表の名前で送る
  • 送る時間帯が、相手の読む時間と合っていないか：「一般に良い時間」ではなく、相手の属性で。Wantedlyのスカウトを送る曜日・時間の考え方
  • 開封の動きが管理画面で見えるかは、現在の仕様で確認する：見えないなら、「2」と合わせて直す

2. 「自分宛」と思われなかったとき

  • 冒頭が、会社説明から始まっていないか：「私たちは〇〇を通じて」は、開いた瞬間に閉じられる
  • 相手に触れる一文が、プロフィールの「見出し」になっていないか：「〇〇社でエンジニアをされていて」ではなく、相手が書いた「なぜ」や、ストーリーで語った一文
  • 相手の「なぜ」と自社の「なぜ」を、一文ずつ：想いを語らず、重なりを置く。Wantedlyのスカウトで共感を伝える書き方
  • 個人化の範囲が、相手ごとに変わっているか：型は同じでよいが、空欄が空のまま送られていないか。Wantedlyのスカウトの個人化

いま使っている媒体の運用の相談だけでも構いません。返信が来ない理由が四つのどれかを、送った文面と管理画面の動きから一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyのスカウトは、もともと返信が来にくいものなので、数を送るしかない」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、返信が来ないと言う会社の送った文面を読むと、件名が「スカウトのご案内」で、冒頭が会社説明で、相手に触れる一文がプロフィールの見出しで、末尾が「ぜひご応募ください」になっています。この文面に返信が来ないのは、媒体の性質ではなく、文面が相手に「自分宛」と読まれていないからです。同じ会社で、相手のストーリーから一文を拾い、末尾を「選考ではなく、〇〇と話す場です」に変えた文面には、返信が来ています。当社が「返信が来ない」の相談を受けるとき、最初にやるのは、数を増やす提案ではなく、送った文面を数通、相手の目で読み直すことです。

3. 行く先が見えないとき

  • 末尾が「ぜひご応募ください」「エントリーをお待ちしています」になっていないか：Wantedlyの返信は応募ではなく「話を聞きたい」。応募を求めると、敷居が上がる
  • 末尾に、面談の形を一段落：「選考ではありません。この文面を書いた〇〇と、オンラインで短い時間、お互いを知る場です」
  • 「返信」で何をすればよいかを、一文で：「話を聞いてみたいと思われたら、一言だけご返信ください」
  • 募集記事につないでいるか：文面で挙げた「重なり」を、記事の「こんなことやります」で確かめられる形に。Wantedlyのスカウトと募集記事のつなげ方

カジュアル面談の形はWantedlyのカジュアル面談の設計で書きました。末尾の一段落で、返信の敷居が変わります。

4. いま動く時期ではないとき

  • 同じ文面で、他の相手からは返信があるか：あれば、文面ではなく相手の時期
  • 相手のプロフィールとストーリーの更新時期を見る：更新が古い相手は、いま動いていないことがある
  • 送り直しは、一度だけ、間隔を空けて、新しい材料で：「前回〇〇についてお送りしましたが、その後△△が」。Wantedlyのスカウト後のフォロー連絡
  • 返信が来ない相手を、「潜在」として台帳に残す：時期が変わったときに、もう一度。Wantedlyの潜在層へのスカウト
  • 「4」と判断するのは、「1」から「3」を直したあと

返信が来ない相手を、追わない

  • 返信がない相手に、二度、三度と送らない：相手の側に「しつこい会社」が残る
  • 送り直しは一度、間隔を空けて、新しい材料で：それでも来なければ、終える
  • 「読んでいますか」「ご確認ください」は送らない
  • 追わない代わりに、台帳に「次の連絡日」を置く：時期が変わったときに、新しい材料で

追いすぎて起きることはWantedlyのスカウト後のフォロー連絡の「追いすぎて、起きること」で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。相手のストーリーから一文を拾って書く場合の、一通あたりの時間をお伝えします。

媒体選びを相談する

返信が来ない期間に、数を増やさない

  • 来ない理由が直っていないまま数を増やすと、来ない文面が増えるだけ
  • 数を増やすと、一通あたりの読む時間が減り、「2」の理由が強くなる
  • 返信が来る形を、少数で作ってから増やす：Wantedlyのスカウトの通数配分
  • 送った数ではなく、返信と面談の数で見る：Wantedlyのスカウトの効果測定

返信が来た文面と、来なかった文面を並べる

  • 台帳から、返信が来た文面と来なかった文面を数通ずつ
  • 件名、冒頭、相手に触れる一文、末尾、で比べる：どこで差が出ているか
  • 差が出た場所を、一か所ずつ直す：全部を変えない
  • 月に一度、並べる：返信の記録は、気づく前に台帳に出る
  • 返信が来た相手の「なぜ返信したか」を、面談で聞く：次の文面の中心

見直しの型はWantedlyのスカウトの振り返りで書きました。

送る人の名義と、時間帯

  • 名義を、人事から現場の人か代表に変える：「1」と「2」の両方に効く
  • 名義の人が、文面を確認する：名前だけ貸さない。Wantedlyのスカウトを現場の名前で送る
  • 送る時間帯を、相手の属性で変える：エンジニア、営業、学生で、読む時間が違う
  • 送る側が続けられる時間帯にする：「一般に良い時間」を探さない

運用代行や代理店が支えられるのは、四つの理由の切り分け、件名と冒頭と末尾の型、並べて見る表の型、送り直しの型までで、相手を読むこと、一文を拾うこと、送ること、面談は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは数字の読み方の話です。「返信が来ない」と言う会社の台帳を見ると、送った数だけが記録されていて、開封と返信の段が分かれていないことがあります。当社がWantedlyのスカウトで見るのは、送った数ではなく、「開封の動き」「返信の数」「返信のうち面談まで進んだ数」の三つで、この三つが分かれていれば、止まっている段が指せます。開封が少なければ件名と名義、開封はあるが返信がなければ冒頭と末尾、返信はあるが面談に進まなければ返信後の対応です。管理画面でどこまで見えるかは現在の仕様で確認しますが、見える範囲で段を分けて台帳に写すだけで、「返信が来ない」は「〇〇の段で止まっている」に変わります。

まとめ

  • 返信が来ない理由は、開かれていない・「自分宛」と思われなかった・行く先が見えない・いま動く時期ではない、の四つ。この順に疑い、「相手のせい」を最初にしない
  • 開かれていないなら件名・名義・時間帯。「自分宛」と思われないなら、相手のプロフィールとストーリーから拾った一文と、冒頭の順番
  • 行く先が見えないなら、末尾に「選考ではない・誰と・どんな形」を一段落。応募を求めず、「一言だけご返信ください」
  • 時期の問題なら、送り直しは一度だけ、間隔を空けて新しい材料で。追わず、台帳に「次の連絡日」を置いて潜在として残す
  • 来ない期間に数を増やさず、返信が来た文面と来なかった文面を月に一度並べて、差が出た一か所を直す

よくある質問

開封の動きが管理画面で見えず、「1」か「2」か分かりません

見えないなら、「1」と「2」を合わせて直します。件名と名義を直し、同時に冒頭を相手から拾った一文に変えて、一か月の返信を見ます。変われば、どちらかが効いています。次に、件名だけ戻して、差が出るかを見ると、切り分けられます。管理画面で何が見えるかは、現在の仕様を管理画面とヘルプで確認してください。

相手のストーリーが無く、拾う一文が見つかりません

プロフィールの「なぜ」や、経歴の中の一文、応援した記事、から拾えることがあります。それでも拾えない相手は、後回しにし、拾える相手から送ります。拾えないまま見出しで埋めた文面は、「自分宛」と読まれず、返信が来ません。相手の読み方はWantedlyのスカウトのターゲットで書きました。

スカウトに返信が来ないときの見直しは、御社に相談できますか

できます。当社は、四つの理由の切り分け、件名と冒頭と末尾の型、並べて見る表の型、送り直しの型を支えられます。相手を読むこと、一文を拾うこと、送ること、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
