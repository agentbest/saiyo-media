業界イメージが不利な会社の採用広報

「きつそう」「古そう」「地味そう」。業界そのものに、そうした印象を持たれやすい会社があります。会社の中身が良くても、業界の名前を見ただけで候補者が離れてしまうことに、悩んでいる採用担当者は多いものです。結論から言うと、業界イメージが不利な会社の採用広報は、イメージを打ち消そうとするより、候補者が抱く不安を一つずつ挙げ、自社の事実で答えていくのが基本です。 この記事では、不安の洗い出し方、答え方の型、媒体ごとの使い方を整理します。

イメージを打ち消そうとすると逆効果になる理由

業界イメージが不利なとき、多くの会社がまず考えるのは「イメージと違う明るい面を見せること」です。おしゃれなオフィスの写真、若い社員の笑顔、「業界の常識を変える」といった言葉。けれども、こうした見せ方は、候補者に「何かを隠しているのでは」と思われることがあります。

候補者が業界イメージから抱いているのは、具体的な不安です。「休みが取れないのでは」「体力的にきついのでは」「将来性がないのでは」。明るい写真はこの不安に答えていません。不安が残ったまま選考に進むと、面接の終盤や内定の段階で辞退が出ます。

業界イメージに向き合うときは、印象を変えることより、不安に答えることを目的にします。

不安を洗い出す手順

まず、候補者がどんな不安を抱いているかを洗い出します。

  1. 面接や面談で聞かれた質問を集める：候補者が気にしている点は、質問に出ます
  2. 辞退の理由を集める：辞退した候補者や、内定を断った人の理由を振り返ります
  3. 入社した人に聞く：「入社前に不安だったこと」を聞くと、外から見た業界の印象が分かります
  4. 家族や周りの反応を聞く：新卒の場合、学生本人より親や周りの人が業界の印象を気にしていることがあります
  5. 不安を一覧にする：集めた不安を、働き方・体力・将来性・待遇などに分けて並べます

一覧にすると、何に答えればよいかが見えてきます。全部に答える必要はなく、多く出てくるものから順に取り組みます。

業界の印象が不利なとき、どの媒体から始めるか。条件に合わせて3媒体を並べてご案内します。

媒体選びを相談する

答え方の型

洗い出した不安には、次の型で答えます。

要素書き方例
不安候補者がどう思っているか休みが取りにくい業界だと聞いている
事実自社では実際にどうか繁忙期と閑散期があり、閑散期にまとめて休む人が多い
理由なぜそうできているか繁忙期の前に、案件の割り振りを全員で決めている
残る課題まだ解決していないこと繁忙期は残業が増えるので、その時期の分担を見直している

この型のポイントは、「残る課題」を書くことです。業界イメージが不利な会社ほど、課題を隠したくなります。けれども、課題を自分から書くことで、事実の部分にも信頼が生まれます。候補者は、すべてが良い会社を探しているのではなく、入社後に驚かない会社を探しています。

エージェントベストの見解

相談で多い思い込みは、「業界のイメージが悪いから、この媒体では採れない」というものです。実際には、媒体の運用を見ていると、業界の印象で離れる候補者がいる一方で、最初からその業界に関心を持っている候補者も一定数います。業界の仕事に興味がある人、地元で安定した仕事を探している人、手に職をつけたい人。問題は、そうした候補者に向けた文面になっていないことです。業界イメージを気にして一般的な明るい文章にすると、関心のある人にも響かなくなります。先に決めるべきなのは、「この業界だからこそ来てくれる人は誰か」です。その人に向けて、不安への答えと仕事の具体を書くと、業界の印象はかえって絞り込みの役割を果たします。

見せ方の工夫

業界イメージが不利な会社が採用広報で使える工夫を挙げます。

  • 仕事の一日を時間の流れで見せる：朝から夕方まで何をしているかを書くと、イメージより実際の姿が伝わります
  • 社員の経歴を見せる：異業種から来た人、未経験から始めた人の話は、候補者が自分を重ねやすい材料です
  • 仕事の意味を顧客の側から書く：自社の仕事が、誰の何に役立っているかを具体的に書きます
  • 変えてきたことを見せる：働き方や設備で、この数年に変えてきたことを書きます。変化の途中であることも伝わります

求人票で正直に書く考え方は、求人票を正直に書くでも整理しています。

媒体ごとの使い方

不安への答えは、媒体の性格に合わせて使い分けます。

  • スカウト型の媒体：OfferBoxのオファーやGreenのスカウトでは、不安への答えを一つだけ文面に入れます。相手が業界に関心を持っていそうなら、仕事の具体を先に書きます
  • 掲載型の媒体：ワンキャリアの掲載ページや求人サイトでは、不安と答えを複数並べられます。読み比べの中で、正直さが判断材料になります
  • 面談・説明会：候補者から聞かれる前に、多い不安に自分から触れます

不安への答えを、スカウトの文面や掲載ページにどう入れるか。運用の相談だけでも構いません。

運用の相談をする

エージェントベストの見解

媒体で採る場合と紹介で採る場合の両方を見ていると、業界イメージが不利な会社は、紹介のほうが立ち上がりやすいことがあります。紹介では、担当者が候補者に会社の事実を一対一で説明できるので、業界の印象を丁寧に解いていけるからです。一方、媒体では、最初の文面だけで判断されるので、不安への答えが文面に入っていないと読まれずに終わります。だからこそ、媒体を使うときは、紹介の担当者が口頭で説明している内容を、文面に書き起こすことを勧めます。「候補者によく聞かれることと、その答え」を一枚にまとめておけば、媒体の文面にも、紹介の担当者への説明にも、同じものが使えます。

よくある失敗

  • 明るい写真だけを並べる：不安に答えていないと、隠しているように見えることがあります
  • 業界の悪口を他社のせいにする：「業界の他社とは違う」と書くと、業界全体を下げることになり、候補者の印象も良くなりません
  • 課題を書かない：入社後に課題を知ると、早い離職につながります
  • 全員に同じ文面を送る：業界に関心がある人とない人では、響く内容が違います

まとめ

  • 業界イメージは打ち消すより、候補者の不安に事実で答える
  • 不安は面接の質問、辞退の理由、入社した人の声から洗い出す
  • 「不安・事実・理由・残る課題」の型で答える
  • この業界だからこそ来てくれる人に向けて書く
  • 口頭で説明している内容を、媒体の文面に書き起こす

よくある質問

業界の印象が悪いことを、求人票に書いてもよいですか

印象そのものを書く必要はありませんが、候補者が抱きやすい不安に答える形で触れることは有効です。「休みが取りにくいと思われがちですが」と前置きし、自社の事実を書くと、候補者の不安に先回りできます。

新卒の場合、親の反対が心配です

新卒の採用では、学生本人より親が業界の印象を気にしていることがあります。内定後に、親にも読んでもらえる会社の資料を用意したり、働き方の事実を丁寧に説明したりすると、反対を減らせることがあります。

知名度も業界イメージも不利な場合はどうすればよいですか

まず候補者が会社を調べたときの受け皿を作り、そのうえで不安への答えを載せます。知名度がない会社の考え方は知名度がない会社の採用広報で整理しています。
