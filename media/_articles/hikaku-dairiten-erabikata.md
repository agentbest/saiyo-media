採用媒体の代理店を、どう選べばよいか。ところが、料金で選び（正規料金で変わらないのに）、扱う媒体が一つの代理店に「比較」を頼み、申込のみの代理店に申込後の相談を期待し、提案の中身を見ずに選び、担当の体制を見ず、やめるときの扱いを聞かない。**結論から言うと、選ぶ軸は料金ではなく、「扱う媒体の範囲・中立性・申込後の相談の範囲・代行の範囲・報告・担当の体制・契約の形・引き継ぎ・稟議の支援」の九つで、重い軸は自社の体制で変わります。一人なら申込後の相談と報告、複数媒体なら扱う範囲と契約の形、代行前提なら代行の範囲と引き継ぎ。「どの媒体を勧めても収入は変わりませんか」を最初に聞きます。** この記事では、選び方で起きる失敗、九つの軸、体制ごとに重い軸、中立性、比べる手順、提案書、選んだ後、分担を整理します。九つの軸の詳しくは[代理店を比較するときの軸](/media/kh-dairiten-hikaku/)、中立性は[代理店の提案が中立かどうかの見分け方](/media/kh-dairiten-chuuritsu/)、使い方は[採用媒体の代理店の使い方](/media/hikaku-dairiten-tsukaikata/)で書きました。

## この作業の目的｜「自社の体制で足りない部分」を支えられる代理店を選ぶ

代理店の価値は、自社の体制で足りない部分を支えることです。だから、良い代理店は「一般に良い代理店」ではなく、「自社の足りない部分を支えられる代理店」です。一人の会社に要るものと、複数媒体の会社に要るものは違い、選ぶ軸の重さも違います。

目的は、九つの軸のうち「自社に重い軸」を先に決め、その軸で代理店を比べることです。

## 選び方で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 料金で、選ぶ | 代理店経由でも正規料金で、料金では差がつかない。差がつくのは申込後 |
| 扱う媒体が一つの代理店に、比較を頼む | 「比較」の結論が、扱う媒体になる。中立ではない |
| 申込のみの代理店に、申込後を期待する | 申込後に相談しても「媒体に聞いてください」で終わる |
| 提案の中身を、見ずに選ぶ | 自社の条件から組み立てられた提案か、よくある提案か、を見ていない |
| 担当の体制を、見ない | 担当が一人で、交代で引き継がれず、更新の声かけも来ない |
| やめるときの扱いを、聞かない | 切り替えのとき、型と記録を持ち出せない |

共通するのは、代理店を「申込の窓口」として選び、「申込後に支える相手」として選んでいないことです。

## 九つの軸

| 軸 | 何を見るか |
|---|---|
| 1. 扱う媒体の範囲 | 自社が使いたい媒体を扱っているか。比較できる幅 |
| 2. 中立性 | どの媒体を勧めても収入が変わらないか。提案が自社の条件から組み立てられているか |
| 3. 申込後の相談の範囲 | 申込のみか、相談までか、代行までか |
| 4. 代行の範囲 | 検索・文面・送信・一次返信を頼めるか。対応する媒体 |
| 5. 報告 | 何を、どの頻度で。止まったときに気づけるか |
| 6. 担当の体制 | 一人か複数か。交代のときの引き継ぎ |
| 7. 契約の形 | 媒体と直接か、代理店と契約か。請求のまとめ方 |
| 8. 引き継ぎのしやすさ | 型と条件を書面でもらえるか。やめるときの扱い |
| 9. 稟議の支援 | 提案書、見積もり、時間の見積もりを稟議に使える形で出せるか |

九つの確認の仕方は[代理店を比較するときの軸](/media/kh-dairiten-hikaku/)の「9つの軸」で書きました。九つ全部を同じ重みで見ません。次の節で、体制ごとに重い軸を置きます。

### エージェントベストの見解

相談で最も多い思い込みは、「代理店はどこも同じで、担当者の相性で選べばよい」というものです。当社は3媒体すべての販売パートナーとして、他の代理店から切り替えてくる会社の相談も受けますが、切り替えの理由で多いのは、担当者の相性ではなく、「扱う媒体が一つで、比較にならなかった」「申込後に相談できなかった」「担当が変わって引き継がれなかった」の三つで、どれも九つの軸で先に確かめられたものです。担当者の相性は、九つの軸が揃ったうえでの話で、軸が揃っていなければ、相性が良くても支えられません。当社を選ぶときも、「担当者が良さそう」ではなく、九つの軸で他の代理店と並べて、当社の弱い軸も含めて見ていただくことをお願いしています。

## 中立性の、確かめ方

- **「どの媒体を勧めても、収入は変わりませんか」と聞く**：答えが曖昧なら、扱う媒体か報酬の構造に偏りがある
- **提案が、自社の条件（採る人数・職種・こんな人・時間の形）から組み立てられているか**：条件を聞かずに媒体名が先に出る提案は、中立ではない
- **「この条件なら、この媒体は向かない」と言えるか**：向かない媒体を言えない代理店は、全部を勧める
- **扱う媒体の一覧を、先に出してもらう**
- **見分け方は[代理店の提案が中立かどうかの見分け方](/media/kh-dairiten-chuuritsu/)**

## 比べる手順

1. **自社の体制を、一つ選ぶ**：一人・兼務・現場・複数媒体・代行前提・自社運用・初めて
2. **重い軸を、三つまでに絞る**
3. **同じ条件（採る人数・職種・こんな人・時間の形・面談に出る人）を、各代理店に出す**：条件を揃えないと比べられない
4. **重い軸を、同じ質問で聞く**：[代理店に聞くべき質問](/media/kh-dairiten-shitsumon/)
5. **提案書と、時間の見積もりと、報告のサンプルと、契約のひな形をもらう**
6. **重い軸で並べ、軽い軸は参考に**
7. **選んだ後に、渡すものと渡さないものを決める**：[採用媒体の代理店の使い方](/media/hikaku-dairiten-tsukaikata/)

手順の詳しくは[代理店を比較するときの軸](/media/kh-dairiten-hikaku/)の「比べる手順」で書きました。

## 提案書で、見るところ

- **自社の条件が、提案の最初に書かれているか**：書かれていなければ、よくある提案
- **「向かない媒体」と「向かない理由」が書かれているか**
- **運用に要る自社の時間が、書かれているか**：書かれていない提案は、申込後を見ていない
- **申込後に代理店がすることが、時期と頻度で書かれているか**
- **料金が正規料金で、行ごとに分かれているか**：[代理店の見積もりの見方](/media/kh-dairiten-mitsumori/)
- **やめるときの扱いが、書かれているか**

## 選んだ後に、確かめること

- **申込後の最初の月に、相談が一度以上あったか**：なければ、申込のみの代理店だった
- **報告が、決めた型で来ているか**
- **担当の名前と、交代のときの流れを、書面で持っているか**
- **契約の八つの項目を、代理店と確認したか**：[媒体の契約で確認する項目](/media/hikaku-baitai-keiyaku/)

### エージェントベストの見解

これは向き不向きの話です。当社は3媒体すべての販売パートナーで、九つの軸のうち「扱う媒体の範囲」と「中立性」（どの媒体を勧めても収入は変わりません）と「申込後の相談」は、当社が自信を持って出せる軸です。逆に、3媒体以外の媒体（ナビ、エージェント、他のスカウト型）を使いたい会社には、当社は扱っておらず、その媒体を扱う代理店のほうが向きます。当社を選ぶ前に、「使いたい媒体が3媒体の中にあるか」を確かめてください。3媒体の外の媒体を使うなら、当社は「向かない代理店」で、それを先にお伝えします。当社の位置づけは[エージェントベストという代理店について](/media/kh-dairiten-agentbest/)で書きました。

## まとめ

- 代理店を選ぶ軸は料金ではなく（正規料金で変わらない）、九つ（扱う媒体・中立性・申込後の相談・代行の範囲・報告・担当の体制・契約の形・引き継ぎ・稟議の支援）
- 重い軸は自社の体制で変わる。一人なら申込後の相談と報告と担当の体制、複数媒体なら扱う範囲と契約の形と中立性、代行前提なら代行の範囲と報告と引き継ぎ、自社運用と初めてなら扱う範囲と中立性と稟議の支援
- 中立性は「どの媒体を勧めても収入は変わりませんか」と、提案が自社の条件から組み立てられているか、向かない媒体を言えるか、で確かめる
- 比べる手順は、体制を一つ選ぶ→重い軸を三つに→同じ条件を出す→同じ質問→提案書・時間の見積もり・報告のサンプル・契約のひな形→重い軸で並べる
- 提案書は自社の条件・向かない媒体・自社の時間・申込後の頻度・行ごとの料金・やめるときの扱いで見る。選んだ後は最初の月の相談と報告で確かめる

## よくある質問

### 代理店から「御社にはこの媒体が最適です」と言われました。信じてよいですか

「最適」の根拠が、自社の条件（採る人数・職種・こんな人・時間の形）から書かれているか、「向かない媒体」も一緒に示されているか、を見ます。条件を聞かずに媒体名が先に出る提案、向かない媒体を言えない提案は、中立ではない可能性があります。「どの媒体を勧めても収入は変わりませんか」と聞き、答えを記録します。当社も、この質問には「変わりません」と答え、向かない媒体を先に言います。

### 小さな会社なので、代理店に相手にされないのではと心配です

代理店経由でも料金は正規料金で、代理店の収入は媒体の側から出るので、会社の大きさで代理店の扱いが変わる理由は、仕組みの上ではありません。変わるのは、申込後の相談の範囲で、小さな会社ほど「申込後の相談」の軸が重く、その軸で選びます。当社は、担当一人や兼務の会社の相談が最も多く、その体制に合う渡し方から始めます。

### 代理店の選び方は、御社に相談できますか

できます。当社は、九つの軸の情報、条件に沿った提案、時間の見積もり、報告のサンプル、契約のひな形、稟議の書類を出せます。体制の選択、重い軸の決定、比較、選ぶ判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーで、どの媒体を勧めても収入は変わりません。3媒体の外の媒体を使うなら、当社は向かない代理店です。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
