ワンキャリアで、体育会の学生に向けたイベントを開きたい。ところが、「体育会系＝粘り強い」で一括りにし、競技の成果で選び、競技の予定を見ずに日程を組み、選考が長く、出る人に競技経験がなく、「体育会向け」と付けて中身は一般の説明会と同じ。**結論から言うと、「体育会系」を一つの型に押し込めず、競技を続けてきた学生が確かめたいこと（競技の予定と選考の両立・引退後の短い期間で決める形・成果ではなく続けた動き方をどう見るか・競技を続けてきた社員がどう働いているか）に答える回にします。日程は競技の予定に合わせ、選考は短く、出るのは競技を続けてきた社員。掲載の区分と形は、管理画面とヘルプで確認してください。** この記事では、体育会向けで起きる失敗、確かめたいこと、回で答えること、出る人、テーマ、日程と時期、選考、見方、オンラインとオフライン、スカウトとのつなぎ、分担を整理します。体育会の学生への文面は[OfferBoxで体育会系学生にアプローチする方法](/media/ob-taiikukai/)、種類の使い分けは[ワンキャリアのイベントの種類と使い分け](/media/oc-event-kihon/)で書きました。

## この作業の目的｜「体育会系」という言葉を、その学生固有の動き方に戻す

「体育会系」は、学生を分類する言葉として便利ですが、回で使うと、学生を一つの型に押し込めます。同じ競技でも、続けた理由、役割、うまくいかなかったときの動き方は、学生ごとに違います。回に来る学生が確かめたいのは、「この会社は、自分を『体育会系』でなく、自分の動き方で見るか」と、「競技の予定と選考を両立できるか」です。

目的は、体育会向けの回を「体育会系向けの説明会」ではなく、「競技を続けてきた学生の確かめたいことに答える場」にすることです。

## 体育会向けで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 「体育会系＝粘り強い」で、一括りにする | 学生は「自分の何を見たのか」が分からず、他社と同じ回に見える |
| 成果で、選ぶ | 大会の順位や記録で見ると、成果が出なかった学生に届かない。成果は動き方ではない |
| 競技の予定を見ずに、日程を組む | 大会・練習・遠征の時期に開き、来られない |
| 選考が、長い | 引退後に短い期間で動く学生は、長い選考の間に他社に決める |
| 出る人に、競技経験がない | 「競技を続けてきた社員がどう働いているか」を答えられる人がいない |
| 「体育会向け」と付けて、中身は同じ | 会社の概要と選考の流れで、競技と仕事のつながりの話がない |

共通するのは、「体育会系」を分類として使い、学生一人ひとりの動き方を読んでいないことです。

## 競技を続けてきた学生が、確かめたいこと

| 確かめたいこと | 回で答えること |
|---|---|
| 競技の予定と、選考を両立できるか | 面談と選考の日程を、競技の予定に合わせて組める形。オンラインの可否 |
| 引退後の短い期間で、決められるか | 選考の段階と間隔。「間隔を詰めて進める」 |
| 成果ではなく、続けた動き方をどう見るか | 「大会の順位ではなく、続けた理由と役割とうまくいかなかったときの動き方を聞く」 |
| 競技を続けてきた社員が、どう働いているか | 競技を続けてきた社員が出て、競技と仕事のつながりを話す |
| 競技以外の自分も、見てもらえるか | 「競技以外に書かれていることも読む」と伝える |

確かめたいことの元は[OfferBoxで体育会系学生にアプローチする方法](/media/ob-taiikukai/)の手順1「自由記述で見るところ」です。回は、この表の右側を話す場です。

### エージェントベストの見解

相談で最も多い思い込みは、「体育会の学生は粘り強く体力があるから、営業向きで、そう伝えれば来る」というものです。当社はワンキャリアの販売パートナーとして、体育会向けイベントの相談を受けていますが、「粘り強さを活かせる」で集めた回は、体験談に「体育会系だからと決めつけられた」「自分の何を見たのか分からなかった」と残り、次に進む人が少ない。逆に、「大会の順位ではなく、続けた理由と役割とうまくいかなかったときの動き方を聞く」と回で伝え、競技を続けてきた社員が「競技のこの動き方が、仕事のこの場面で」と話した回は、「自分の動き方を見てくれる会社」と残っています。体育会向けの回の価値は、「体育会系」と呼ぶことではなく、「一人ひとりの動き方で見る」と伝えることです。当社が体育会向けの相談を受けるとき、最初にやるのは、回の名前と中身から「粘り強い」「体力」「根性」を外すことです。

## 出る人｜競技を続けてきた社員

- **競技を続けてきた社員**：「競技のこの動き方が、仕事のこの場面で活きた」「競技と違ったこと」を話せる
- **入社してまもない社員が向く**：引退から入社までの時期を、近い記憶で話せる
- **面接に出る人**：「成果ではなく動き方を聞く」を、選考の話として
- **人事は、進行と日程の案内**：競技の予定に合わせた日程の組み方を
- **競技を続けてきた社員がいない場合**：面接に出る人が「動き方をどう見るか」を話し、「競技経験の社員はいない」と正直に。[OfferBoxで体育会系学生にアプローチする方法](/media/ob-taiikukai/)の手順5

## テーマの、型

| 型 | 話すこと | 出る人 |
|---|---|---|
| 動き方をどう見るか | 選考で、成果ではなく続けた理由・役割・うまくいかなかったときの動き方をどう聞くか。実際の質問の例 | 面接に出る人 |
| 競技と仕事のつながり | 競技のどの動き方が、仕事のどの場面で活きたか。活きなかったことも | 競技を続けてきた社員 |
| 引退から入社まで | 引退後、短い期間でどう動き、どう決めたか | 入社してまもない、競技を続けてきた社員 |
| 競技の予定と選考の両立 | 面談と選考の日程を、競技の予定に合わせて組む形 | 人事 |

一回に一つか二つ。「競技と仕事のつながり」を、「粘り強さ」の一語にしないことが要点です。

## 日程と時期への、配慮

- **競技の予定で、動ける時期が決まる**：大会のシーズン、引退の時期は競技ごとに違う。前年の実績と本人に聞いて把握する
- **練習と遠征で、平日の日中が空きにくい**：夕方以降、練習がない曜日に
- **オンラインを基本に**：遠征先や練習の合間から参加できる。[ワンキャリアのオンラインイベントの進め方](/media/oc-online-event/)
- **引退の時期に合わせて、回を置く**：引退後に短期集中で動く学生が来られるように。複数の回で
- **時期の目安は、年度の公表内容と、競技ごとの実態で確認**
- **配慮の詳しくは[OfferBoxで体育会系学生にアプローチする方法](/media/ob-taiikukai/)の手順3**

## 選考を、短くする

- **引退後に短期集中で動く学生は、複数社を同時に短期間で受ける**：長い選考の間に、他社が決める
- **段階を減らし、間隔を詰める**：面談から内定までを短く。中身は変えない。[後期の母集団形成の考え方](/media/kh-boshudan-kouki/)の「選考を、速くする形」
- **回で、選考の速さを伝える**：「間隔を詰めて進める」と事実で。数字は自社の実態で
- **回の当日に、次の場（面談）を申し込める形**：引退後の学生は、その場で決めて動く
- **速さの考え方は[OfferBoxで体育会系学生にアプローチする方法](/media/ob-taiikukai/)の手順4**

## 成果ではなく、動き方で見る

- **回で、「成果で選ばない」と伝える**：「大会の順位や記録ではなく、続けた理由・役割・うまくいかなかったときの動き方を聞く」
- **成果に触れない**：成果が出なかった学生に届かない。触れるのは、成果に至る動き方
- **競技以外に書かれていることも、読むと伝える**：学業、アルバイト、他の関心
- **「体育会系」の一語を、回の中で使わない**：「競技を続けてきた方」「部活動に打ち込んできた方」の形で
- **面接官と、見方を揃える**：回で言った見方と、面接で聞くことが同じ。[OfferBoxの面接官への引き継ぎ](/media/ob-genba-mensetsukan/)

## オンラインとオフライン

- **オンライン**：練習と遠征の合間から参加できる。競技の予定と両立しやすい。日程と選考の形は話の中身で確かめられる
- **オフライン**：競技を続けてきた社員と話す時間、職場を見る時間。引退後で時間が取れる時期に。[ワンキャリアのオフラインイベントの進め方](/media/oc-offline-event/)

## スカウトとの、つなぎ

- **競技を続けてきた学生への文面の締めで、この回に誘う**：「続けた理由が〇〇と書かれていて」の文面の締めに、競技を続けてきた社員が出る回を。[OfferBoxで体育会系学生にアプローチする方法](/media/ob-taiikukai/)の手順2
- **回で会った社員が、面談に出る**：回と面談がつながる
- **回の後の一通は、競技の予定に合わせた日程の候補と一緒に**：[ワンキャリアのイベント後のフォロー](/media/oc-event-follow/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「体育会系」の一括りを外し、確かめたいことに答える回として設計する | 人事 |
| 競技を続けてきた社員を探し、出てもらう | 人事と現場の責任者 |
| 「動き方をどう見るか」を話す | 面接に出る人 |
| 競技と仕事のつながり、引退から入社までを話す | 競技を続けてきた社員 |
| 競技の予定を把握し、日程を組む | 人事 |

| 進行、次の場、一通 | 人事 |

運用代行や代理店が支えられるのは、確かめたいことの整理、テーマの型、日程の配慮の型、選考を短くする形の整理、スカウトとのつなぎの型までで、出る社員を探すこと、出ること、動き方で見ること、面接官の枠、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。体育会向けの相談で、「体育会の学生を採りたいので、体育会向けの回で集めたい」と言われることがあります。当社が確かめるのは、「体育会の学生を採りたい理由は何ですか」です。答えが「粘り強いから」「体力があるから」なら、それは「体育会系」という分類への期待で、一人ひとりの動き方ではなく、回で伝えれば学生に「決めつけられた」と読まれます。答えが「うまくいかない時期に続けた経験のある人が、当社の〇〇の場面で活きるから」なら、それは動き方への期待で、回で伝えれば「自分の動き方を見る会社」と読まれます。同じ「体育会の学生を採りたい」でも、理由の言葉で、回の中身が変わります。当社は、体育会向けの相談で、その理由を動き方の言葉に直すところから始めます。

## まとめ

- 「体育会系」を一つの型に押し込めない。競技を続けてきた学生が確かめたいのは、競技の予定と選考の両立、引退後の短い期間で決める形、成果ではなく動き方をどう見るか、競技を続けてきた社員がどう働いているか
- 出るのは競技を続けてきた社員（入社してまもない人が向く）と、面接に出る人。人事は進行と日程の案内。競技経験の社員がいなければ正直に
- テーマは、動き方をどう見るか、競技と仕事のつながり（「粘り強さ」の一語にしない）、引退から入社まで、競技の予定と選考の両立
- 日程は競技の予定（大会・練習・遠征・引退の時期）に合わせ、夕方以降、オンラインを基本に、引退の時期に複数の回。選考は段階を減らし間隔を詰め、当日に次の場を申し込める形
- 成果に触れず、動き方で見ると回で伝え、「体育会系」の一語を使わず、競技以外も読む。面接官と見方を揃え、文面の締めで回に誘い、追いかけを急がない

## よくある質問

### 体育会向けの回に、競技経験のない学生も申し込んできました

回の中身が「続けた動き方をどう見るか」なら、競技以外で何かを続けてきた学生にも当てはまり、来てよい。「体育会限定」と書く必要はなく、中身で来る人が決まります。回の中で、「競技に限らず、続けたことの動き方を見る」と伝えれば、競技経験のない学生にも答えになります。限定すると、競技以外で同じ動き方をしてきた学生を逃します。

### 引退の時期が競技ごとに違い、回の日程が組めません

自社が採りたい学生の競技を絞り、その競技の引退の時期に合わせて回を置きます。全競技に合わせようとすると組めません。絞れないなら、オンラインの回を間隔を空けずに複数置き、「引退後に来られる回がある」状態にします。時期の把握は、前年に来た学生の競技と時期の記録から。記録がなければ、今年の回で聞いて、翌年の材料にします。

### 体育会向けイベントの使い方は、御社に相談できますか

できます。当社は、確かめたいことの整理、テーマの型、日程の配慮の型、選考を短くする形の整理、スカウトとのつなぎの型を支えられます。出る社員を探すこと、出ること、動き方で見ること、面接官の枠、面談は、企業が行ってください。掲載の区分と形は管理画面とヘルプで確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
