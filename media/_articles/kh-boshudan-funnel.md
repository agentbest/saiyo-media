採用ファネルを作った。入口から承諾までの逆三角形の絵。ところが、作ったきりで、何を直せばよいかは分からない。目標値を入れたら、毎月「未達」の表になった。**結論から言うと、ファネルは目標の絵ではなく、「止まりを見つける表」です。段（入口→面談→一次→二次以降→内定→承諾）ごとに、「数」と「日数」と「こんな人に近い人の数」の三つを並べ、細くなった段を一つ指して直します。入口ごとに分けて作り、目標値ではなく変化で見て、台帳から出し、月に一度見ます。** この記事では、ファネルが使えない理由、段の切り方、各段に置く三つ、細くなった段の見つけ方、日数の見方、入口ごとに分ける理由、変化で見ること、台帳との関係、月の見方、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、目標数は[母集団の目標数の決め方](/media/kh-boshudan-keikaku/)、媒体ごとのKPIは[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)で書きました。

## この作業の目的｜「どこで止まっているか」を、一目で指せる表にする

採用の結果が出ないとき、「入口が少ない」「面談に進まない」「選考で離脱する」「内定で辞退する」のどれが起きているかで、直す場所が違います。ファネルは、それを一つの表で見つけるためのものです。

目的は、ファネルを「作って眺める絵」から、「細くなった段を指して直す表」に変えることです。

## ファネルを作っても、使えない理由

| 理由 | 何が起きるか |
|---|---|
| 段が粗い | 「応募→内定」の二段では、途中のどこで止まっているかが見えない |
| 入口を全部足している | スカウトと掲載とイベントを足すと、どの入口が細いかが見えない |
| 数だけで、日数と質がない | 数が減っている段は見えても、「待たせている段」と「合わない人が来ている段」が見えない |
| 目標値を先に置く | 毎月「未達」の表になり、直す場所ではなく「足りない」だけが見える |
| 月に一度見ない | 作ったきりで、年度の終わりに一度見て、直す時間がない |
| 台帳と別に作る | 台帳から出さず、別に数えるので、更新されない |

共通するのは、ファネルを「絵」として作り、「表」として使っていないことです。

## 段の、切り方

| 段 | 何を数えるか |
|---|---|
| 入口 | 承認（OfferBox）、返信（Wantedly）、受諾・エントリー（ワンキャリア）、イベント申込、紹介。入口ごとに |
| 面談 | 面談した数 |
| 一次 | 一次に進んだ数 |
| 二次以降 | 段階ごとに。段階が多いなら全部 |
| 内定 | 内定を出した数 |
| 承諾 | 承諾した数 |

「入口」の前に、「送った」「閲覧」を置いてもよいですが、企業が動かせる範囲で見ます。段の切り方は[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)の「段を分けて、数と日数を置く」で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「ファネルは経営に見せるための図で、各段に目標値を入れて達成率を示すものだ」というものです。当社は3媒体すべての販売パートナーとして、多くの会社のファネルを見ていますが、目標値を入れたファネルは、毎月「未達」の表になり、人事が経営に「足りない」を報告する道具になって、直す場所を指す道具になっていません。逆に、目標値を入れず、段ごとの数と日数と「近い人の数」を先月と並べたファネルは、「面談の段で、先月より日数が延びている」「一次で近い人の割合が下がった」と、直す場所を指しています。当社がファネルの相談を受けるとき、最初にやるのは、目標値の列を外して、日数と「近い人」の列を足すことです。

## 各段に置く、三つ

| 置くもの | 何が分かるか |
|---|---|
| 数 | どの段で減っているか。「細い段」 |
| 日数 | 前の段からその段までの日数。どの段で待たせているか。「遅い段」 |
| 「こんな人に近い人」の数 | その段に、採りたい人がどれだけ残っているか。「合わない人が来ている段」 |

三つを、段ごとに置きます。「数」だけでは、「面談の数は多いが、近い人が少ない」や「数は減っていないが、日数が延びている」が見えません。「近い人」の印の付け方は[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)の「『こんな人』に近い学生の数を、段ごとに持つ」で書きました。

## 細くなった段の、見つけ方と直す場所

| 細い段 | 直す場所 |
|---|---|
| 入口が細い | 入口の質（文面・記事・相手の絞り方）か量（送る数・掲載の広さ）。[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/) |
| 入口→面談が細い | 返信後の対応の速さと、面談の形の見え方。[スカウトに返信が来たあとの文面](/media/kh-bunmen-henshin/) |
| 面談→一次が細い | 面談の中身と、面談後の選択肢の伝え方。[OfferBoxの面談後のフォロー](/media/ob-mendan-go-follow/) |
| 一次以降が細い | 面接官の引き継ぎと、段階の間隔。[OfferBox経由の学生が選考途中で離脱する理由](/media/ob-senkou-ridatsu/) |
| 内定→承諾が細い | 内定連絡と、内定後の接点。[内定連絡の文面](/media/kh-bunmen-naitei/) |
| 「近い人」の割合が、ある段で落ちる | その段の前の段で、合わない人を通している。前の段の見方を直す |

細い段は、一つ指します。全部を直そうとしません。

## 日数で、「待たせている段」を見つける

- **各段の日数を、先月と並べる**：延びている段が、待たせている段
- **入口→面談の日数が延びる**：返信への対応が遅い。当日か翌日に返す形に
- **面談→一次の日数が延びる**：面談後の選択肢の伝え方が遅い、面接官の枠が取れていない
- **一次→二次以降の日数が延びる**：段階の間隔。面接官の枠を先に押さえる
- **内定→承諾の日数**：承諾期限の置き方と、内定後の接点
- **数が減っていなくても、日数が延びていれば、次の月に数が減る**：日数は先行の指標

日数の考え方は[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)の手順1で書きました。

## 入口ごとに、分けて作る

- **スカウト・掲載・イベント・紹介で、それぞれファネルを作る**：足さない
- **入口ごとに、割合が違う**：スカウトは入口が細く面談進行率が高い、掲載は入口が太く面談進行率が低い、など。自社の実績で
- **入口ごとに、「近い人」の割合が違う**：どの入口が「こんな人」を連れてきているかが見える
- **入口ごとの表を並べて、配分を見直す**：[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)
- **全部を足した表は、経営への報告用に別に作ってもよいが、直すのは入口ごとの表で**

## 目標値ではなく、変化で見る

- **各段に、目標値を入れない**：入れると「未達」の表になる
- **先月と今月を、段ごとに並べる**：増えた・減った・延びた・縮んだ
- **変化があった段を、一つ指す**：そこが直す場所
- **目標は、ファネルの外に置く**：「採る人数」と「近い人の面談数」だけ。[母集団の目標数の決め方](/media/kh-boshudan-keikaku/)
- **割合は、月に一度、台帳から出して、逆算の置き直しに使う**：ファネルの各段の目標値にはしない

変化で見る考え方は[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)の手順2と手順3で書きました。

## 台帳から、ファネルを出す形

- **台帳に、相手ごとの「入口」「段」「各段の日付」「近さ」を持つ**
- **月に一度、台帳から段ごとに数える**：数、日数、近い人の数
- **ファネルを別に作らない**：台帳から出す。別に作ると、更新されない
- **台帳の項目は最小限**：[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)の手順5
- **入口が複数なら、台帳の「入口」の項目で分ける**

## 月に一度の、見方

1. **入口ごとの表を、先月と並べる**
2. **数が減った段、日数が延びた段、近い人の割合が落ちた段を、印をつける**
3. **印の中で、最も重い一つを指す**：入口に近い段ほど、後ろの段に効く
4. **その段の直す場所を決める**：上の表から
5. **翌月、その段が変わったかを見る**
6. **見る時間は短く**：表を並べて、一つ指すだけ

月の見方は[OfferBox運用の週次レビューのやり方](/media/ob-shuukan-review/)の「月次レビューとの違い」で書きました。

| 台帳に入口・段・日付・近さを付ける | 送る人と人事 |
| 月に一度、台帳から入口ごとのファネルを出す | 人事 |
| 細い段・遅い段・近い人が落ちた段を一つ指す | 人事と責任者 |

運用代行や代理店が支えられるのは、段の切り方、三つの置き方の型、台帳の型、細い段と直す場所の対応の整理、月の見方の型までで、台帳を付けること、近さの判断、段を直すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。当社がファネルの相談を受けるとき、「見せるためのファネル」と「直すためのファネル」を分けます。前者は、経営に全体像を示すもので、全部の入口を足し、目標値と達成率があってよいものです。後者は、人事が月に一度、細い段を指すためのもので、入口ごとに分け、目標値を入れず、日数と近い人の数を持ちます。相談の多くは、前者だけを作って、後者がなく、「ファネルはあるが、何を直せばよいか分からない」になっています。当社がお願いするのは、後者を先に作ることです。後者があれば、前者は月に一度、足すだけで出ます。

## まとめ

- ファネルは目標の絵ではなく、「止まりを見つける表」。段が粗い・入口を足している・数だけ・目標値を先に置く・月に見ない、では使えない
- 段は入口→面談→一次→二次以降→内定→承諾。各段に「数」「日数」「こんな人に近い人の数」の三つを置く
- 細い段（数が減る）、遅い段（日数が延びる）、合わない人が来ている段（近い人の割合が落ちる）を、一つ指して直す。日数は先行の指標
- 入口（スカウト・掲載・イベント・紹介）ごとに分けて作り、足さない。入口ごとに割合と「近い人」の割合が違う
- 目標値を入れず、先月と今月の変化で見る。台帳から出し、別に作らない。月に一度、短く、一つ指す

## よくある質問

### 経営に見せるファネルと、直すためのファネルを、両方作る時間がありません

直すためのファネル（入口ごと、三つの列）を台帳から出せば、経営に見せるファネルは、それを足して目標値の列を添えるだけで出ます。別々に作るのではなく、直すためのファネルが元で、見せるためのファネルはその集計です。先に作るのは、直すためのファネルです。

### 「近い人」の判断が、送る人によってばらつきます

「こんな人」の一枚を、送る人と面接官で合意し、「近い」「やや近い」「遠い」の三段で、行動の事実で判断します。印象で判断しないことが要点です。最初の数人は、一人が全員分を判断して揃えます。判断の物差しは[OfferBoxで会う学生の評価基準の作り方](/media/ob-gakusei-hyouka-kijun/)で書きました。

### 採用ファネルの作り方は、御社に相談できますか

できます。当社は、段の切り方、三つの置き方の型、台帳の型、細い段と直す場所の対応の整理、月の見方の型を支えられます。台帳を付けること、近さの判断、段を直すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
