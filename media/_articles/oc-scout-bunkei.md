文系学生へのスカウトは、「総合職を募集しています」「営業職で、コミュニケーション力を活かせる方を」という形になりがちです。ところが、文系学生は、職種名から仕事の中身を想像できず、「コミュニケーション力」は誰にでも書ける言葉だと知っています。**結論から言うと、文系学生へのスカウトは、職種名ではなく「最初の月に何をするか」で誘い、学生時代の活動で人とどう関わったかの場面を読み、それを最初の月の「誰に何をどう」の場面と重ね、選考で学生時代の何をどう聞くかを一文添え、文系で入った入社してまもない社員と話す場に誘います。仕事の中身が見えにくい職種ほど、場面で書きます。「文系歓迎」と一括りにせず、配属の決まり方が気になる学生には、企業ページのその部分へ誘導します。** この記事では、文系学生が体験談で読んでいること、やりがちな失敗、プロフィールで読む箇所、4段の型の文系向けの書き方、見えにくい職種の書き方、送り主、企業ページとの整合、分担を整理します。企業ページの文系向けの書き方は[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/)、OfferBoxの文系向けの文面は[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)で書きました。

## この作業の目的｜職種名から仕事を想像できない学生に、最初の月を見せる

文系学生の多くは、「営業」「企画」「総合職」と書かれても、その仕事が具体的に何をするのか分かりません。大学で学んだことと仕事が対応していないからです。

目的は、職種名の代わりに「最初の月に何をするか」を文面で見せ、学生時代の場面と重ねて、「この仕事なら自分にできそうか」を判断できる文面にすることです。

## 文系学生が、体験談で読んでいること

| 読んでいること | 文面への意味 |
|---|---|
| 総合職の中身は何だったか | 職種名ではなく、最初の月の仕事を書く |
| 配属はどう決まったか | 文面で触れるか、企業ページのその部分へ誘導 |
| 営業の実態（新規か既存か、数字の圧力） | 「誰に何をどう」を一文で。隠さない |
| 面接で学生時代の何を聞かれたか | 「選考で学生時代の何をどう聞くか」の一文を入れる |
| 文系で入った人がどうしているか | 送り主と話す人を、文系で入った社員に |

「配属はどう決まったか」は、文系学生の体験談で最も多く書かれることの一つです。文面に全部は書けませんが、「配属の決まり方は企業ページの〇〇に書いています」と一言添えると、学生は確かめに行けます。

## やりがちな失敗

| 失敗 | 文系学生からどう見えるか |
|---|---|
| 職種名だけで誘う（「総合職を募集」「営業職で」） | 何をするか分からない |
| 「コミュニケーション力を活かして」「主体性のある方」 | 誰にでも書ける。自分のことではない |
| 「文系歓迎」「文系でも活躍」 | 一括り。「でも」が下に見ている |
| 配属の決まり方に触れない | 「総合職で入って、どこに行くか分からない」の不安が残る |
| 業界の説明が長い | 業界を知っても、自分が何をするかは分からない |
| 学生時代の活動を「経験」として褒める | 「素晴らしいご経験」は読んでいない印 |
| 営業の実態を隠して「やりがい」だけ | 体験談の「営業は大変だった」だけが残る |
| 学部名から始める（「〇〇学部の方に」） | 検索で拾える情報 |

最も多いのは、最初の「職種名だけ」です。会社側は「総合職」で分かると思っていますが、学生には中身が無い言葉です。

### エージェントベストの見解

相談で最も多い思い込みは、「文系学生には、業界や会社の魅力を伝える文面のほうが返信が来る」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、文系学生の体験談を読むと、「総合職で入ったが何をするのか分からなかった」「配属が希望と違った」「営業の実態が違った」が多く書かれています。学生は、業界の魅力を知りたいのではなく、「自分は最初の月に何をするのか」を知りたいのです。当社が文系向けの文面を整えるとき、最初にやるのは、「総合職」「営業職」の一語を、「最初の月は〇〇から始まります」の一文に置き換えることです。置き換えられない募集があれば、それは「最初の月が決まっていない募集」で、文面より先に社内で決めます。

## プロフィールで、読む箇所

| 読む箇所 | 何が書かれているか | 文面での使い方 |
|---|---|---|
| 学生時代の活動で、人とどう関わったか | アルバイトでお客さまと、サークルでメンバーと、企画で外部と | 「〇〇で△△の人と関わっていたと書かれていたのを読んで」 |
| 詰まった場面と、そのとき何をしたか | 「意見が割れて」「企画が通らず」「お客さまに断られて」 | 「そのとき□□をされた点が」 |
| 興味 | 「〇〇に興味がある」「△△をやってみたい」 | 仕事と重なれば |
| 好きだったこと | 「〇〇が好きだった」「△△が面白かった」 | 本人の言葉で |
| 専攻 | 判断に使う。文面には書かない | 「専攻は問わない」なら、触れない |

「人とどう関わったか」が、文系向けの読む箇所の中心です。文系の仕事の多くは、人と関わる仕事で、学生時代の「誰とどう関わったか」が、最初の月の「誰に何をどう」と重なります。読む観点は[ガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/)で書きました。

## 4段の型を、文系向けに

| 段 | 文系向けの書き方 |
|---|---|
| 1. 学生時代の場面を読んだ一文 | 「アルバイトで、お客さまに断られたあと△△をされたと書かれていたのを読んで」。活動の種類ではなく、人と関わった場面 |
| 2. 最初の月の「誰に何をどう」との重なり | 「うちの〇〇職は、最初の月に先輩と一緒に□□業界のお客さまを訪ねて、話を聞くところから始まります。断られたあとにどうするか、という場面が、そのまま重なります」。企業ページの「最初の1年」と同じ言葉 |
| 3. 選考で学生時代の何をどう聞くかの一文 | 「選考では、学生時代に何をしていたかを、場面で聞きます。大きなことでなくて構いません。詳しくは企業ページに」 |
| 4. 文系で入った社員と話す場 | 「〇〇学部から入った二年目の△△が、最初の1年に何をしたかを話します。選考ではありません」 |

「2段目で『誰に何をどう』を書く」が、文系向けの要点です。「営業」ではなく「□□業界のお客さまを訪ねて話を聞く」と書くと、学生は自分の学生時代の場面と比べられます。ビジネス職の「誰に何をどう」の考え方は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)で書きました。

## 仕事の中身が見えにくい職種ほど、場面で書く

| 職種 | 職種名だけ | 場面で |
|---|---|---|
| 営業 | 「営業職」 | 「□□業界のお客さまに、〇〇を提案する。最初の月は先輩に同行して、お客さまがどんな人かを見る」 |
| 企画 | 「企画職」 | 「〇〇の企画を、△△の人と組んで作る。最初の月は、いまある企画の資料を読んで、一つ手直しする」 |
| 総合職 | 「総合職」 | 「最初の半年は〇〇と△△を経験して、その後に配属を決める。配属の決まり方は企業ページに」 |

## 配属の決まり方への触れ方

文面に全部は書けませんが、触れないと不安が残ります。

- **一文で、企業ページへ誘導する**：「配属の決まり方は、企業ページの〇〇に書いています」
- **希望どおりにならないことがあるなら、企業ページに書いてあることを前提に**：文面で「希望を尊重します」と書かない。守れないことを書かない
- **職種が決まっている募集なら、その旨を**：「この募集は〇〇職として採ります」
- **企業ページに「配属の決まり方」が無いなら、文面より先に企業ページ**：[ワンキャリアの募集コースの考え方](/media/oc-boshu-course/)

## 送り主は、文系で入った入社してまもない社員

- **文面の2段目（最初の月の場面）を、その人が書く**：「文系で入って、最初の月に何をしたか」は、最近経験した人にしか言えない
- **送り主が「〇〇学部から入った」と分かると、学生に近い**：「自分と同じ立場の人からの連絡」
- **4段目の話す場に、その人が出る**：送り主と話す人が同じ
- **その人の時間は、読んで書くことと面談だけ**：分担は[ワンキャリアのスカウトを誰が送るか](/media/oc-scout-tantou/)

## 「文系」で、一括りにしない

- **「文系歓迎」「文系でも」と書かない**：一括りの言葉
- **学部名で絞らず、学生時代の場面で読む**：法学と経済と文学と教育で、興味の方向は違うが、人との関わり方は専攻に依らない
- **型は一つで、2段目の重ね方を学生の場面で変える**：専攻ごとに型を作らない
- **「こんな人」は、学生時代の状態で**：「サークルで企画を立てた人」「アルバイトでお客さまと話すのが好きだった人」

## 企業ページの文系向けの部分と、揃える

- **企業ページに「職種ごとの最初の1年」があるか**：文面の2段目は、そこから
- **企業ページに「配属の決まり方」があるか**：文面から誘導する先
- **企業ページに「選考で学生時代の何をどう聞くか」があるか**：文面の3段目と同じ内容
- **企業ページに「文系で入った社員の話」があるか**：4段目の話す人が、そこに出ている

企業ページの文系向けの部分が無ければ、文面より先に企業ページです。書き方は[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/)で書きました。

| 作業 | 誰が |
|---|---|
| 職種ごとの最初の月を言葉にする | 各職種の責任者と、文系で入った入社してまもない社員（人事が聞いて型に） |

| 配属の決まり方を企業ページに書く | 責任者と人事 |
| 学生時代の場面を読み、一文と重なる点を書く | 文系で入った入社してまもない社員 |
| 型、絞り込み、受諾対応、台帳 | 人事 |
| 話す場に出る | 文系で入った入社してまもない社員 |

運用代行や代理店が支えられるのは、文系向けの型、読む箇所の整理、職種を場面に置き換える型、配属への触れ方の整理、企業ページとの整合の確認までで、最初の月の言語化、配属の決まり方の決定、読んで書くこと、話す場に出ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと文面が「総合職」の一語に戻ることがあります。「最初の月に何をするか」が、募集ごとに決まっていることです。当社がワンキャリアの文系向けのスカウトを支えるとき、型と読む箇所は当社が出せますが、「営業の最初の月は、先輩に同行して〇〇のお客さまを訪ねる」という中身は、その職種の責任者と、最近それを経験した社員にしか言えません。決まっていない募集に文面を書くと、2段目が「幅広い業務」に戻り、学生は「何をするか分からない」で閉じます。当社が最初にお願いするのは、募集ごとに「最初の月、3か月、1年目の終わり」を責任者に聞いてもらうことです。答えが出る募集から、文面を作ります。答えが出ない募集は、文面より先に、社内で最初の月を決めます。

## まとめ

- 文系学生へのスカウトは、職種名ではなく「最初の月に何をするか」で誘う。「コミュニケーション力」「文系歓迎」は誰にでも書ける言葉
- 読む箇所は、学生時代の活動で人とどう関わったか、詰まった場面と行動、興味、好きだったこと。専攻は判断に使い文面に書かない
- 4段は、学生時代の場面を読んだ一文→最初の月の「誰に何をどう」との重なり→選考で学生時代の何をどう聞くか（大きなことでなくて構いません）→文系で入った社員と話す場
- 仕事の中身が見えにくい職種（営業・企画・総合職・事務・CS）ほど、「最初の月」の場面で書く。配属の決まり方は企業ページへ誘導
- 送り主は文系で入った入社してまもない社員。「文系」で一括りにせず、型は一つで2段目の重ね方を変える。企業ページの文系向けの部分と揃える

## よくある質問

### 総合職で、最初の月に何をするかが配属先で違います

配属先の候補ごとの「最初の月」を、企業ページに書いておき、文面では「最初の半年は〇〇と△△を経験して、その後に配属を決めます。配属先ごとの最初の月は企業ページに」と一文で誘導します。文面に全部は書かず、「決まるまでの最初の期間に何をするか」を書けば、学生は想像できます。

### 営業の数字の目標を、文面に書くべきですか

文面には書かず、企業ページの「条件」や「最初の1年」に事実として書き、文面からは「営業の実態は企業ページに」と誘導します。文面で隠すと、体験談の「数字の圧力」だけが残ります。企業ページで「目標はあり、〇〇の形で決まる」と事実で書いてあれば、文面から誘導するだけで足ります。

### 文系向けのスカウトは、御社に相談できますか

できます。当社は、文系向けの型、読む箇所の整理、職種を場面に置き換える型、配属への触れ方の整理、企業ページとの整合の確認を支えられます。最初の月の言語化、配属の決まり方の決定、読んで書くこと、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
