店舗運営職（店長候補）を新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『店長候補』の名前で募集すると、学生には『店長になる』までの年数と転勤の範囲が分からず、『販売職と何が違うのか』と読んで離れる。『バイトリーダー』で絞ると、本当に店を動かしたのか分からない学生が多く来て、面談で『何年で店長ですか』『転勤はどこまでですか』に答えられず、内定の後に転勤の範囲を伝えて辞退される」という問題です。**結論から言うと、「店長候補」の名前では、学生は店長までの年数と転勤の範囲が分からず、販売職との違いが読めません。転勤の可否を譲れない条件として最初に決め、志望職種と「バイトリーダー」の肩書で絞らず、総合職・営業・販売志望の学生の中から「人を動かした・数字を見て変えた・役割を組んだ・任されて回した」の行動で探します。送る型は行動と転勤の可否で絞って店長かエリア長の名義で、記事を置く型は店長の一日と店長が決められる範囲を、比べられる場は「店に配属・転勤が多い」の体験談に対して企業ページに転勤の範囲と店長までの年数を先に書きます。転勤は隠しません。** 販売職の選び方は[販売職の採用媒体の選び方](/media/hikaku-hanbai-erabikata/)で書きました。この記事は店を任される側の店舗運営職に絞ります。

## 店舗運営職の採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「店長候補」の名前だけで募集する | 店長までの年数と転勤の範囲が分からず、「販売職と何が違うのか」と読んで離れる | 年数と転勤の範囲を職種名より先に書く。[ワンキャリアで店舗運営職を募集するときの掲載とスカウト](/media/oc-tenpo-keisai/) |
| 「バイトリーダー」の肩書で絞る | 肩書は多いが、本当に店を動かしたのか分からない | 肩書ではなく、行動で絞る。[OfferBoxで店舗運営職志望の学生を見つける検索の考え方](/media/ob-tenpo-target/) |
| 転勤の範囲を内定後に伝える | 「地元の店だと思っていた」と辞退される | 転勤の可否を譲れない条件として最初に決め、最初に書く |
| 店長が決められる範囲が書かれていない | 店長になってから「決められることが少ない」と離れる | 発注・人の配置・売り場・販促のどこまでを店長が決めるかを書く |
| 店長までの年数が書かれていない | 「いつまで店員なのか」と読まれる。書いて実態が違うと体験談に書かれる | 実態の年数と、早い人と遅い人の差を書く |

## 判断軸を、店舗運営職に当てる

| 軸 | 店舗運営職での見方 |
|---|---|
| 対象（誰に届くか） | 転勤の可否を譲れない条件にして、範囲に応じられる学生に絞る。志望職種と肩書は見ない。総合職・営業・販売志望の学生の中から「人を動かした・数字を見て変えた・役割を組んだ・任されて回した」の行動で探す。 |
| 型（送るか、来るか、比べられるか） | 送る型は、行動と転勤の可否で絞って店長かエリア長の名義で「あなたの人を動かした経験を読んで」と一人に書ける。来る型は、店長の一日と、店長が決められる範囲と、店長になった人の話を記事で通年で。比べられる型は、大手の「店に配属」「転勤が多い」の体験談に対して、企業ページに転勤の範囲と店長までの年数を先に書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 店長かエリア長が名義と面談を持つ時間。店長は店の営業で、エリア長は店の巡回で埋まるので、面談の枠を先に固定しないと運用が止まる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。店舗運営職では、「対象」を転勤の可否で先に絞ることと、「運用工数」をエリア長の巡回の外に確保することが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「店長候補は、アルバイトでリーダーをしていた学生に送ればよい。バイトリーダーなら店を回した経験がある」というものです。当社は3媒体すべての販売パートナーとして、店舗運営職の採用の相談を受けますが、肩書で絞った会社は、「バイトリーダー」が自由記述に多いわりに、本当に店を動かしたのか分からない学生が多く来て、面談で「人を動かした話」が出ません。肩書は店から与えられ、行動は本人が選びます。「シフトが埋まらないとき、誰にどう頼んだか」「売上が落ちたとき、何を見て何を変えたか」「新人にどの役割を組んだか」は、肩書が無くても書かれていて、肩書があっても書かれていないことがあります。当社が最初にお願いするのは、絞る条件から肩書を消し、「人を動かした・数字を見て変えた・役割を組んだ・任されて回した」を「優先する条件」に上げることです。それと同時に、転勤の可否を「譲れない条件」に置きます。行動で合っていても、転勤に応じられない学生は内定後に辞退します。

## 学生が、確かめること

- **店長までの年数**：何年目に店長か。早い人と遅い人でどれだけ違うか。「店長候補」の名前では分からない
- **店長が決められる範囲**：発注か、人の配置か、売り場か、販促か、価格か。本部が決めることと店長が決めることの線
- **転勤の範囲と頻度**：全国か、地域か、県内か。何年に一度か。住まいは変わるか。最も多く辞退の理由になる
- **シフトと休み**：店長になってからの休み。ラインが埋まらないとき誰が出るか
- **本部への道**：エリア長、店舗開発、商品、人事に行けるか。行った人がいるか
- **最初の年に何を任されるか**：販売職と同じ仕事か。店長候補としての最初の役割は何か

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 行動と転勤の可否で絞り、店長かエリア長の名義で「あなたの人を動かした経験を読んで」と一人に書ける | 企業から送る型（OfferBox） | 肩書と志望職種を見ずに、総合職・営業志望の中から探せる。転勤の可否を先に絞れる。[店舗運営職向けのオファー文面](/media/ob-tenpo-offer-bunmen/) |
| 店長になった人が、店長の一日と決められる範囲を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「販売職と同じ」「ずっと店」の像を、店長が決めた話の記事で置き換える |
| 体験談があり、企業ページに転勤の範囲と店長までの年数を先に書ける | 学生が並べて比べる場（ワンキャリア） | 大手の「店に配属」「転勤が多い」に対して、入る前に転勤と年数が分かる会社として読まれる |
| 転勤の範囲が決まっていない | どれも先ではない | 店舗運営の責任者と決めてから。決めずに送ると内定後の辞退になる |
| 店長が決められる範囲が整理されていない | どれも先ではない | 「店を任せる」と書いて決められないと、体験談に書かれる |

どれか一つが正解ではなく、転勤の範囲が決まっているか、店長が書けるか、体験談があるかで、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせる**：文面で人を動かした経験を読んだ一文を、記事で店長の一日と決められる範囲を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **自店のアルバイトからの登用を主に、媒体をアルバイトの外の学生に**：アルバイトから店長になった人の道を、媒体の文面と記事に書く。[リファラルとの併用](/media/ob-heiyou-referral/)
- **文系・総合職の学生の探し方と重ねる**：[文系の採用媒体の選び方](/media/hikaku-bunkei-erabikata/)、[総合職の採用媒体の選び方](/media/hikaku-sogo-erabikata/)。総合職志望の学生の中に、店を任されたい学生がいる
- **面談の聞き方の型を、揃える**：「肩書より、シフトが埋まらないとき誰にどう頼んだか、数字が落ちたとき何を見て何を変えたか」。明るさと元気の印象で決めない
- **内定前に、店長の一日を見せる**：店長の判断の場面と、エリア長との会話と、転勤した人の話を。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)
- **業界の構造と重ねる**：[小売業界の採用媒体の選び方](/media/hikaku-kouri-erabikata/)
- **代行と組み合わせるなら、絞る作業と文面の下書きまで。読んで直すのは店長かエリア長**：[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「店長候補」ではなく、何年で店長になり、何を決められ、どこまで転勤するか

- **「店長候補」「幹部候補」「将来のリーダー」を職種名にしない**：年数と範囲が分からず、販売職との違いが読めない
- **店長までの年数を、実態で**：「店長は〇年目から。早い人は△年、遅い人は□年」。実態より短く書くと、体験談に書かれる
- **店長が決められる範囲を、線で**：「発注と人の配置と売り場は店長が決める。価格と販促は本部」。本部が決めることを隠さない
- **転勤の範囲と頻度を、最初に**：「転勤は〇〇の範囲で△年に一度。住まいは変わる」。地域を限る道があるなら、あると。隠して内定後に伝えると辞退される
- **最初の年を、時期で**：「最初の年は販売職と同じ仕事から。△か月目からシフトの作成、□年目から発注」。販売職との違いはここで書く
- **本部への道を、実態で**：「エリア長に行った人が〇人、店舗開発に△人」。無いなら無いと

| 作業 | 誰が |
|---|---|
| 転勤の範囲と頻度、店長までの年数、店長が決められる範囲、本部への道を決める | 店舗運営の責任者 |
| 店長かエリア長の面談の枠を、営業と巡回の外に固定する | 店舗運営の責任者。書く前に |
| 行動と転勤の可否で絞る条件 | エリア長が作り、人事か代行が絞る |
| 文面と記事 | 店長になった人が話し、人事が書き、本人が確認 |
| 名義と、オファーの一文 | 店長かエリア長 |
| 面談 | エリア長と人事。聞き方の型を揃えて。元気の印象で決めない |
| 辞退の理由の記録 | 人事。転勤か、年数か、仕事の中身か、他社かを分けて |

運用代行や代理店が支えられるのは、絞る条件の型、絞る作業、文面の下書き、記録の型までで、転勤の範囲の決定、面談の枠の固定、名義、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

店舗運営職の採用で、当社が媒体より先に確かめるのは、「転勤の範囲を、文面と掲載の最初に書けるか」です。申し込んだあとに運用が止まる会社に共通するのは、転勤を後ろに置くことです。「地元の店で面談し、内定を出し、配属の前に全国転勤を伝える」と、内定の後に辞退が続きます。学生は面談した店の場所で「ここで働く」と思って承認し、転勤の範囲を知って辞めます。転勤を最初に書くと承認は減りますが、減るのは内定後に辞退する学生です。全国転勤の会社には、当社は、転勤の可否を譲れない条件にして、範囲に応じられる学生だけに送り、その分だけ一人ひとりに店長かエリア長の名義で書くことを案内します。地域を限る道があるなら、それを文面の最初に置きます。承認の数で媒体を評価せず、「内定後に転勤で辞退した数」を記録する場所を先に決めてから、送り始めます。

## まとめ

- 「店長候補」の名前では、学生は店長までの年数と転勤の範囲が分からず、販売職との違いが読めない。年数と範囲と店長が決められることを職種名より先に書く
- 転勤の可否を譲れない条件として最初に決める。隠して内定後に伝えると辞退される
- 志望職種と「バイトリーダー」の肩書で絞らず、総合職・営業・販売志望の中から「人を動かした・数字を見て変えた・役割を組んだ・任されて回した」の行動で探す
- 送る型（OfferBox）は行動と転勤の可否で絞って店長かエリア長の名義で、記事を置く型（Wantedly）は店長の一日と決められる範囲を、比べられる場（ワンキャリア）は「店に配属・転勤が多い」の体験談に対して企業ページに転勤の範囲と店長までの年数を先に
- 承認の数ではなく、内定後に転勤で辞退した数で効果を見る

## よくある質問

### 全国転勤があります。最初に書くと承認が減りませんか

減ります。減るのは、転勤に応じられず、内定後に知れば辞退する学生です。転勤の可否を譲れない条件にして、範囲に応じられる学生だけに送り、その分だけ一人ひとりに店長かエリア長の名義で書きます。地域を限る道があるなら、それを最初に書きます。承認の数ではなく、内定後に転勤で辞退した数で見ます。

### 店長になるまでの年数は人によって違います。どう書けばよいですか

実態の幅で書きます。「店長は早い人で〇年、多くは△年、遅い人は□年」と、早い人だけを書かないことです。早い人の年数だけを書くと、体験談に「聞いていた年数と違う」と書かれ、次の年の学生が離れます。年数の差が何で決まるか（店の規模か、数字か、人の育て方か）も一緒に書きます。

### 店舗運営職の媒体選びは、御社に相談できますか

できます。当社は、絞る条件の型、絞る作業、文面の下書き、記録の型を支えられます。転勤の範囲の決定、面談の枠の固定、名義、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、店舗運営職の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
