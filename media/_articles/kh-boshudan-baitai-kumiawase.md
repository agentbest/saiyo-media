母集団を作るために、複数の媒体を使う。スカウト型、ナビ、イベント、紹介。ところが、最初から全部を薄く回し、同じ役割の媒体が重なり、担当が全部を少しずつ見て、どれも回らない。**結論から言うと、媒体の組み合わせは、一つの入口が回ってから、二つ目を足します。媒体ごとに「役割・担当・台帳・企業ページの導線」を分け、同じ役割のものを重ねません。配分は、「こんな人に近い人が面談まで来た数」と「担当の時間」で、年度の切れ目に見直します。薄く分けません。代理店で窓口をまとめられる部分はまとめます。** この記事では、組み合わせで起きる失敗、順番、媒体ごとに分けるもの、役割の分け方、配分の見直し方、代理店の窓口、分担を整理します。母集団の考え方は[母集団の質を上げる方法](/media/kh-boshudan-shitsu/)、3媒体の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)、複数媒体の混乱は[複数媒体を併用して運用が混乱したときの整理](/media/ob-heiyou-konran/)で書きました。

## この作業の目的｜入口を増やしても、それぞれが「回っている」状態を保つ

複数の入口は、それぞれが回っていて初めて、母集団を広げます。一つも回っていない状態で媒体を増やしても、回っていないものが増えるだけです。

目的は、一つの媒体を回る形にしてから足し、足した側も回る形を保ち、それぞれの役割で母集団を作ることです。

## 組み合わせで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 最初から複数を薄く回す | どの媒体も、読んで書く時間・返信の速さ・記事の質が薄くなり、どれも回らない |
| 同じ役割の媒体を重ねる | スカウト型を二つ、掲載型を二つ、で同じ学生を追い、重複する |
| 全部の媒体を足して見る | どの経路が「こんな人」を連れてきているか分からない |
| 担当が、全媒体を少しずつ | 全部が「少しずつ」で、どの運用も型にならない |
| 配分を変えずに一年 | 効いていない媒体に時間が使われ続ける |
| 「媒体が多い＝母集団が大きい」と考える | 数は増えても、近い人の面談数は増えない |

共通するのは、「使う媒体の数」を増やすことが目的になっていることです。目的は、「近い人が面談まで来た数」を増やすことです。

## 組み合わせの、順番

1. **一つの媒体を選ぶ**：「こんな人」に最も届きやすいもの。[3媒体の違いと選び方](/media/hikaku-3baitai/)の「この条件なら、どれを先に検討するか」
2. **その媒体で、最初の接点→面談→選考が回る形を作る**：型、返信の対応、面談の枠、台帳
3. **回ったら、二つ目を足す**：一つ目と違う役割の媒体
4. **二つ目を足したとき、一つ目の運用が薄くならないかを見る**：薄くなるなら、まだ足せない
5. **三つ目以降も同じ**：役割が違うものだけ
6. **足すたびに、台帳と担当を分ける**

「回ってから足す」が順番の全部です。初めての年に複数を同時に始めない考え方は[初めて新卒採用をする会社の採用媒体の選び方](/media/hikaku-hajimete-erabikata/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「母集団を広げるには、媒体を多く使うほどよい」というものです。当社は求人広告代理店として、複数媒体の組み合わせを見ていますが、最初から三つの媒体を同時に始めた会社は、どの媒体も薄く、返信が遅れ、記事が止まり、一年後に「どれも効かなかった」で全部をやめています。逆に、一つの媒体で回る形を作ってから二つ目を足した会社は、一つ目が母集団を支えている間に二つ目が立ち上がり、二年目に二つが回っています。当社は3媒体を扱いますが、最初から3媒体を勧めません。当社が組み合わせの相談を受けるとき、最初にやるのは、「いま、一つでも回っている媒体がありますか」を確かめることです。

## 入口ごとに、分けるもの

| 分けるもの | 分けないと |
|---|---|
| 役割（何のためにその媒体を使うか） | 全媒体で同じ学生を追い、重複する |
| 担当（誰がその媒体を見るか） | 全員がすべてを少しずつ見て、どれも薄い |
| 台帳（その媒体の段ごとの数） | 数字が混ざり、効いている経路が分からない |
| 企業ページの導線（その経路から来た人が読むもの） | 経路ごとに読む順番が違うのに、同じページで止まる |
| 時期（その媒体が効く時期） | すべてを同じ時期に開け、選考が詰まる |

分けるものの詳しくは[複数媒体を併用して運用が混乱したときの整理](/media/ob-heiyou-konran/)の「四つを、媒体ごとに分ける手順」で書きました。学生の重複だけは、全体で確認します。

## 役割の、分け方

| 役割 | 入口の例 | 母集団のでき方 |
|---|---|---|
| 「こんな人」に企業から届ける | スカウト型（OfferBox、Wantedlyのスカウト、ワンキャリアのスカウト） | 企業が探して送り、返信した人 |
| 広く受ける | 掲載型（ナビ、ワンキャリアの企業ページ、Wantedlyの募集記事） | 探して来た人がエントリー |
| 確かめる場を作る | イベント・説明会 | 参加した人 |
| 特定の層を紹介で | エージェント、内定者・社員の紹介 | 紹介された人 |

同じ役割の媒体を二つ持つより、違う役割のものを一つずつ持つほうが、母集団は広がります。役割が同じものが二つあるなら、役割を変えるか、一つを減らす候補です。役割の考え方は[スカウト型とナビ型の違い](/media/hikaku-scout-vs-navi/)の「併用するときの分担」、[スカウトと紹介の違い](/media/hikaku-scout-vs-shoukai/)、[イベントと掲載の違い](/media/hikaku-event-vs-keisai/)で書きました。

## 配分の、見直し方

- **媒体ごとに、「こんな人に近い人が面談まで来た数」を出す**：[採用ファネルの作り方](/media/kh-boshudan-funnel/)の経路ごとの表
- **同じく、「担当の時間」を出す**：週の枠、記事を書く時間、返信の時間、面談の時間
- **「時間あたりの近い人の面談数」で、媒体を並べる**：費用は自社の見積もりで確認し、時間と一緒に見る
- **効いていない媒体は、役割を変えるか、小さくするか、減らす**：契約の切れ目で
- **効いている媒体に、時間を寄せる**
- **見直しは、年度の切れ目**：途中で急に変えない。[複数媒体を代理店でまとめる方法](/media/kh-dairiten-fukusuu-baitai/)

## 減らす判断

- **役割が重なっている媒体は、減らす候補**：役割が違うものは、数が少なくても残す理由がある
- **減らすときは、契約の切れ目で**：途中で止めると、進行中の学生が放置される
- **減らしたあと、残った媒体の役割・担当・台帳を見直す**
- **減らした媒体の型と台帳は残す**：翌年に戻すとき、または別の媒体に写すとき
- **減らす判断の詳しくは[OfferBoxで成果が出ないときに撤退を判断する基準](/media/ob-seika-detanai/)**

## 代理店で、窓口をまとめられる部分

- **まとめられる**：申込と契約の窓口、請求、更新時期の把握、各媒体の管理画面の使い方、媒体ごとの型と台帳の型、配分の見直しの材料
- **まとめられない**：役割の決定、担当の決定、読んで書くこと、返信への対応、面談、企業ページの中身
- **まとめる効果は、「契約と更新の混乱」が消えること**：運用の混乱は、媒体を分けて扱うことで消える
- **まとめ方は[複数媒体を代理店でまとめる方法](/media/kh-dairiten-fukusuu-baitai/)**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 最初の一つの媒体を選ぶ | 人事と責任者 |
| 一つ目が回る形を作る | 人事と現場 |
| 二つ目を足すかを、一つ目の運用が薄くならないかで判断する | 人事責任者 |
| 各媒体に役割・担当・台帳・導線・時期を分ける | 人事 |
| 学生の重複を全体で確認する | 人事 |
| 各媒体の近い人の面談数と担当の時間で配分を見直す | 人事と責任者 |
| 減らす判断 | 責任者 |
| 契約と更新の窓口 | 人事。代理店にまとめてもよい |

運用代行や代理店が支えられるのは、媒体の選び方の整理、役割の分け方、台帳の型、配分の見直しの材料、契約と更新の窓口までで、役割と担当の決定、一つ目を回すこと、足すかの判断、減らす判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社は3媒体を扱いますが、申込前に、3媒体を同時に始めることを勧めません。先に、「こんな人」に最も届きやすい一つを選び、その一つで最初の接点→面談→選考が回る形を作ってもらいます。回った時点で、一つ目と役割が違う二つ目を足し、一つ目の運用が薄くならないかを見ます。逆に、3媒体を同時に始めると、どれも薄くなり、一年後に「どれも効かなかった」で全部をやめることになります。当社が勧める順番は、一つを選ぶ、回す、役割が違う二つ目を足す、配分を年度の切れ目に見直す、です。当社にとっても、3媒体が同時に薄く回るより、一つが回って翌年に二つ目が足されるほうが、長く続きます。

## まとめ

- 媒体の組み合わせは、一つの入口が回ってから二つ目を足す。最初から複数を薄く回すと、どれも回らない
- 媒体ごとに役割・担当・台帳・企業ページの導線・時期を分ける。学生の重複だけは全体で確認する
- 役割は「こんな人に届ける（スカウト型）」「広く受ける（掲載型）」「確かめる場（イベント）」「特定の層を紹介で」。同じ役割の媒体を重ねない
- 配分は、媒体別の「近い人が面談まで来た数」と「担当の時間」で、年度の切れ目に見直す。効いていない媒体は役割を変えるか、小さくするか、契約の切れ目で減らす
- 代理店でまとめられるのは契約と更新の窓口。運用の混乱は、媒体を分けて扱うことで消える

## よくある質問

### 上司から「複数の媒体を同時に始めて、比べて選べ」と言われています

同時に薄く始めると、どれも回らず、比べる記録が取れません。一つを回して記録を作り、翌年に二つ目を足して、二年で比べる形を提案します。「比べる」には、それぞれが回っている記録が要り、薄く回した記録は比べられません。一つ目の選び方は[3媒体の違いと選び方](/media/hikaku-3baitai/)の「この条件なら、どれを先に検討するか」で書きました。

### 一つの入口で、母集団が足りません

足りないのが「近い人の面談数」なら、入口を足す前に、その媒体の質（文面・記事・相手の絞り方）と、細くなっている段を直します。最初の段が細いのではなく、面談や選考で細くなっているなら、媒体を足しても採れません。それでも足りなければ、役割が違う二つ目を足します。確かめる順番は[母集団の質を上げる方法](/media/kh-boshudan-shitsu/)の「量を増やす前に、確かめること」で書きました。

### 母集団形成の媒体の組み合わせは、御社に相談できますか

できます。当社は、媒体の選び方の整理、役割の分け方、台帳の型、配分の見直しの材料、契約と更新の窓口を支えられます。役割と担当の決定、一つ目を回すこと、足すかの判断、減らす判断は、企業が行ってください。当社は求人広告代理店として、媒体選びから運用までを支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
