募集職種が多い。営業、技術、企画、管理と、いくつもの職種で同時に採る。OfferBoxで全職種を一度に回そうとすると、文面が全職種共通の会社説明になり、人事が全職種の仕事を書けず、面談に出る人が決まらず、台帳が混ざります。**結論から言うと、全職種を同時に回しません。「現場の一文が取れる」「企業ページが整っている」「面談に出る人がいる」「急ぎ」の四つで職種に順位を付け、上から順に回します。職種ごとに、型と名義と「最初の1年」を持ち、企業ページは共通で、募集要項は職種ごとに分けます。一人の学生に複数職種で送らず、台帳は職種ごとに分け、月に一度、職種ごとに見直します。人事一人で回せる職種の数には限りがあり、順に増やします。** この記事では、同時に回すと起きること、順位の付け方、職種ごとに持つもの、共通と個別の分け方、一人の学生への送り方、台帳、回せる数、増やし方、分担を整理します。送信計画は[OfferBoxで採用人数から逆算する送信計画](/media/ob-ninzu-keikaku/)、型の作り方は[OfferBoxのオファー文面テンプレートを作るときの注意](/media/ob-offer-template/)で書きました。

## この作業の目的｜職種ごとに「読んで書く」を保つ

募集職種が多い会社の問題は、職種の数そのものではなく、職種が増えるほど、一つの職種あたりの「読んで書く」が薄くなることです。

目的は、職種ごとに、現場の一文と型と面談に出る人を持ち、回している職種では「読んで書く」を保つことです。全職種を薄く回すより、回せる職種を厚く回すほうが、結果が出ます。

## 全職種を同時に回すと、起きること

| 起きること | 何が起きるか |
|---|---|
| 文面が全職種共通の会社説明になる | 「〇〇職、△△職、□□職を募集しています」で、どの職種の仕事も書かれていない |
| 人事が全職種の仕事を書けない | 現場の一文を全職種から集められず、知っている職種だけ具体で、他は薄い |
| 面談に出る人が決まらない | 承認が来てから「誰が出るか」を探し、遅れる |
| 台帳が混ざる | どの学生がどの職種か分からず、同じ学生に別の職種で送る |
| 検索条件が全職種共通になる | 「こんな人」が職種ごとに違うのに、一つの条件で検索し、どの職種にも合わない |
| 数字が職種ごとに出ない | 「効いている職種」と「効いていない職種」が分からない |

共通するのは、「職種ごと」に分けていないことです。分ければ、一つの職種の運用と同じになります。

## 回す職種に、順位を付ける

| 条件 | 見ること |
|---|---|
| 現場の一文が取れるか | その職種の現場の人が、「最初の月に何をするか」を一つ話せるか。話せる職種が先 |
| 企業ページが整っているか | その職種の仕事の中身と、働く人が、企業ページにあるか |
| 面談に出る人がいるか | 承認が来たら、その職種の人が面談に出られるか。出られない職種は回さない |
| 急ぎか | 採る時期と人数。年度の公表内容と自社の方針を確認 |

四つのうち、上の三つが揃っている職種から回します。「急ぎ」だけで選ぶと、材料がないまま回して、薄くなります。急ぎだが材料がない職種は、材料を揃える時間を先に取ります。現場の一文の取り方は[OfferBoxの現場の巻き込み方](/media/ob-genba-makikomi/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「募集職種が多いなら、全職種を並べた文面で幅広く送って、学生に選んでもらえばよい」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、職種を並べた文面は、どの職種の仕事も書かれていない会社説明になり、開封されても承認まで進みません。学生は、「選ばせてくれる会社」ではなく、「自分にこの仕事をと言ってきた会社」に承認します。当社が募集職種の多い会社の相談を受けるとき、最初にやるのは、職種を並べた文面を止めて、現場の一文が取れる職種を一つ選び、その職種だけの文面で回すことです。一つの職種で承認が来る形ができれば、二つ目の職種は同じ形で足せます。全部を並べた形では、どの職種も来ません。

## 職種ごとに持つもの

| 持つもの | 内容 |
|---|---|
| 「こんな人」 | 職種ごとに違う。営業と技術で同じ「こんな人」にしない。[OfferBoxで採りたい学生像を言葉にする](/media/ob-persona/) |
| 検索条件 | 職種ごとの「こんな人」から。共通の条件で検索しない |
| 現場の一文と「最初の1年」 | 職種ごとに、その職種の人から |
| 型 | 職種ごとに一つ。空欄は学生の一文と現場の一文 |
| 名義 | 職種ごとに、その職種の人か、人事。名義の人が文面を確認する |
| 面談に出る人 | 職種ごとに決めておく。承認が来てから探さない |
| 「何を見るか」の一文 | 職種ごとに。「選考では、〇〇の話を聞きます」 |

型を職種ごとに分けるのは、手間に見えますが、空欄以外は職種ごとに一度作れば使い回せます。名義ごとに型を作る考え方は[OfferBoxのオファー文面テンプレートを作るときの注意](/media/ob-offer-template/)で書きました。

## 共通で持つものと、職種ごとに分けるもの

| 共通 | 職種ごと |
|---|---|
| 企業ページの「会社が何をしているか」の一言 | 募集要項（仕事内容・条件・選考の流れ） |
| 企業ページの「一緒に働く人」（全職種から数人） | 「最初の1年」の場面 |
| 選考の流れの型（回数と期間の目安） | 面談に出る人と、面接官 |
| 条件のうち、全職種で同じもの | 「こんな人」と検索条件 |
| 台帳の項目の型 | 台帳そのもの |

企業ページは共通で一つ、募集要項は職種ごとに分けます。企業ページに全職種の仕事を詰め込むと、どの職種も薄くなります。企業ページは「会社」、募集要項は「その職種の仕事」です。募集要項の書き方は[OfferBoxの募集要項の書き方](/media/ob-boshu-youkou/)で書きました。

## 一人の学生に、複数の職種で送らない

- **同じ学生に、営業と企画の両方でオファーを送らない**：「どちらでもいいから来てほしい」に見える
- **一人の学生に、一つの職種**：その学生の自由記述に最も近い職種を、送る人が決める
- **迷うなら、面談で聞く**：「〇〇と△△のどちらの話を聞きたいか」。文面では一つに絞る
- **台帳を職種ごとに分けても、学生の重複は全体で確認する**：職種をまたいで同じ学生が出てくる
- **職種を変えて再送しない**：一度承認されなかった学生に、別の職種で送り直さない。[OfferBoxのオファーの再送](/media/ob-offer-saisou/)

「複数の職種で送る」は、学生の側から見ると、「読んでいない」の一つの形です。

## 台帳を職種ごとに分け、月に職種ごとに見直す

- **台帳は職種ごと**：送った数、開封、承認、面談、選考、を職種ごとに
- **月に一度、職種ごとに数字を並べる**：効いている職種と効いていない職種が見える
- **効いていない職種は、「材料」「相手」「型」のどれが足りないかを見る**：職種をまたいで原因を混ぜない
- **効いている職種の型と文面を、他の職種の参考にする**：そのまま流用はしない。「最初の1年」は職種ごとに違う
- **全職種の合計だけで見ない**：合計が良くても、一つの職種が全部を持っていることがある

台帳の型は[OfferBoxのKPI設計](/media/ob-kpi-sekkei/)で書きました。

## 人事一人で回せる職種の数と、増やし方

- **人事一人で「読んで書く」を保てる職種は、多くない**：職種が増えるほど、一つの職種の送る数が減る
- **回せる数は、週の時間と、職種ごとの現場の協力で決まる**：現場の一文と面談が職種ごとに要る
- **最初は一つ**：一つの職種で、送る→承認→面談→選考、が回る形を作る
- **回ったら、二つ目を足す**：一つ目の型と台帳の形を、二つ目に写す
- **足すたびに、一つ目の送る数を減らさない**：減るなら、まだ足せない
- **回らない職種は、いったん止める**：止めた職種は、企業ページと募集要項は残し、送るのを止める

人事一人の運用は[人事1人でOfferBoxを回す方法](/media/ob-hitori-jinji/)、工数が足りないときは[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)で書きました。

### エージェントベストの見解

これは順番の話です。当社が募集職種の多い会社からOfferBoxの相談を受けたとき、全職種の型を一度に作ることはしません。先に一つの職種を選び、その職種で回る形を作り、それを写して二つ目を足します。逆に、全職種の型を先に作ると、型はあるが現場の一文がない職種が残り、その職種の文面は空欄が埋まらないまま会社説明になります。当社が勧める順番は、職種を選ぶ、現場の一文を取る、型を作る、回す、回ったら次の職種、です。「全職種の準備を整えてから始める」は、準備が終わらないまま時期が過ぎます。一つの職種で始めて、回っている間に次の職種の材料を集めるほうが、時期に間に合います。

## まとめ

- 全職種を同時に回すと、文面が会社説明になり、現場の一文が集まらず、面談に出る人が決まらず、台帳が混ざる。職種ごとに分ける
- 「現場の一文が取れる・企業ページが整っている・面談に出る人がいる・急ぎ」で順位を付け、上の三つが揃う職種から回す
- 職種ごとに「こんな人」・検索条件・現場の一文・型・名義・面談に出る人・「何を見るか」を持つ。企業ページは共通、募集要項は職種ごと
- 一人の学生に複数の職種で送らない。台帳は職種ごとに分け、月に職種ごとに見直し、合計だけで見ない
- 最初は一つの職種で回る形を作り、回ったら次を足す。足して一つ目の送る数が減るなら、まだ足せない

## よくある質問

### 上司から「全職種を同時に募集しろ」と言われています

企業ページと募集要項は全職種分を用意し、オファーを送る職種を絞る、という形で説明します。「募集している」状態は全職種で保ち、「読んで書いて送る」を回せる職種から順に、という分け方です。一つの職種で承認が来た記録を見せると、次の職種を足す順番が通りやすくなります。

### 職種ごとに面談に出る人を決められません

面談に出る人が決まらない職種は、まだ回せない職種です。その職種は、企業ページと募集要項を残して、送るのを待ちます。出る人が決まる職種から回し、回っている記録を見せて、他の職種の現場に「出る人を決めてほしい」と伝えるほうが、決まりやすいです。

### 募集職種が多い会社の運用は、御社に相談できますか

できます。当社は、順位の付け方、職種ごとの型、共通と個別の分け方、台帳の型、月の見直しの材料を支えられます。現場の一文、面談、職種を足す・止めるの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
