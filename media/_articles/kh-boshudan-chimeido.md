知名度がなく、母集団が作れない。ところが、掲載を出して待ち、会社の説明を厚くし、知名度のなさを隠し、「知られていないから」と諦め、認知を上げる施策に時間を使う。**結論から言うと、知名度の差は、「探されるか」と「承認・面談・承諾するか」で出て、「開くか・読むか」では出ません。だから入口は、「企業から届ける」（スカウト・紹介・大学との関係）を先に、「探されて来る」（掲載）は読む場所として整えます。不安を先に解く材料を企業ページに置き、知名度のなさを隠しません。** この記事では、知名度がない会社で起きる失敗、差が出る段階、入口の順番、文面で埋めるもの、企業ページ、面談、隠さないこと、承諾の段階、翌年への影響、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、媒体ごとは[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)、[知名度がない会社のWantedly運用](/media/wt-chimeido/)、[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)で書きました。

## この作業の目的｜「知らない会社」を、「話を聞いてみたい会社」にする入口を組む

知名度がない会社の母集団形成は、「知ってもらう」ことから始めると、時間がかかります。学生が会社を「知る」のは、文面を読んだとき、企業ページを読んだとき、面談で会ったときで、その三つで「知らない会社」を「話を聞いてみたい会社」に変えられれば、母集団はできます。

目的は、認知を上げることではなく、「届いた人が、知らない会社の不安を解いて、面談まで来る」入口を組むことです。

## 知名度がない会社で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 掲載だけで、待つ | 探されないので、来ない。知名度の差が最も出る入口 |
| 会社説明で、埋めようとする | 文面が会社の説明で長くなり、「自分宛」でなくなる。知らない会社の説明は読まれない |
| 知名度のなさを、隠す | 面談で「知らない会社だ」と気づかれ、隠していたことが不信になる |
| 「知られていないから」と、諦める | 差が出ない段階（開く・読む）で勝てるのに、動かない |
| 認知を上げる施策に、時間を使う | 母集団に効くまでに時間がかかり、今年の採用に間に合わない |

共通するのは、知名度の差が「どの段階で出るか」を見ずに、全部の段階で不利だと思っていることです。

## 知名度の差が、出る段階と出ない段階

| 段階 | 差が出るか | 何で決まるか |
|---|---|---|
| 探される（掲載・一覧） | 出る | 名前で探される。知らない会社は探されない |
| 開く（スカウト） | 出にくい | 件名と冒頭。会社名ではない |
| 読み進める | 出にくい | 「自分宛か」「何の仕事か」 |
| 承認・返信する | 出る | 「知らない会社だが、大丈夫か」。ここで企業ページを見に行く |
| 面談に来る | 出る | 「知らない会社に時間を使うか」 |
| 承諾する | 出る | 周囲に説明できるか |

差が出ないのは「開く・読む」で、差が出るのは「探される」と「承認以降」です。だから、探される入口（掲載）を主にせず、開いて読まれる入口（スカウト）を主にし、承認以降の不安を企業ページと面談で解きます。段階の詳しくは[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)の「知名度の差が、出る段階と出ない段階」で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「知名度がないから、まず知ってもらう施策が要る」というものです。当社は3媒体すべての販売パートナーとして、知名度がない会社の母集団形成を見ていますが、認知を上げる施策から始めた会社は、母集団に効くまでに時間がかかり、今年の採用に間に合わず、翌年も同じことを言っています。逆に、認知を上げず、「企業から届ける」入口を先に回した会社は、知名度と関係なく開かれ、読まれ、企業ページで不安を解き、面談で仕事を見せて、決まっています。知名度は、母集団の妨げになる段階と、ならない段階があり、ならない段階で勝てば、母集団はできます。当社が知名度の相談を受けるとき、最初にやるのは、「探されて来る入口」に時間を使っていないかを確かめ、「届ける入口」に時間を移すことです。

## 入口の、順番

| 順番 | 入口 | なぜ |
|---|---|---|
| 1. 企業から届ける | スカウト | 開く・読むで差が出ない。「読んだ一文」と「仕事の具体」で承認まで。[スカウトからの母集団形成](/media/kh-boshudan-scout/) |
| 2. 知っている人が届ける | リファラル、大学との関係 | 「知らない会社」ではなく「〇〇さんの会社」「〇〇研究室とつながりのある会社」で届く。[リファラルからの母集団形成](/media/kh-boshudan-referral/)、[大学との関係からの母集団形成](/media/kh-boshudan-daigaku/) |
| 3. 確かめる場 | 少人数の回、インターン | 届いた人が、不安を解く場。[イベントからの母集団形成](/media/kh-boshudan-event/) |
| 4. 読む場所 | 企業ページ、記事 | 探されるためではなく、届いた人が読むために整える。[掲載からの母集団形成](/media/kh-boshudan-keisai/) |

掲載を「探される入口」として主にしません。「届いた人が読む場所」として整えます。Wantedlyは知名度の差が出にくい理由があり、[知名度がない会社のWantedly運用](/media/wt-chimeido/)で書きました。ワンキャリアは知名度より「体験談の有無」の差が出て、[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)で書きました。

## 文面で、埋めるもの

- **学生の一文**：読んだ一文。「自分宛」が、知らない会社でも開かせる
- **最初の一年の場面**：事業ではなく、その人の仕事。「入社した年に、〇〇を先輩と二人で担当する」
- **一緒に働く人**：送っている人の一文。「私は入社した年に△△をしていました」
- **何を見るか**：「選考では、〇〇の話を聞きます」
- **話す場**：「選考ではなく、仕事の話をする場です」
- **会社の説明は、一言**：「〇〇を作っている会社です」。それ以上は企業ページに。[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)の「埋めるもの」

## 企業ページで、不安を先に解く

- **「知らない会社だが、大丈夫か」の不安に、順番に答える**：何をしている会社か（一言）、誰が働いているか、仕事の場面、選考で何が起きるか、入社後の一年
- **社員の記事を、複数**：「知らない会社」でも「この人たちがいる会社」になる
- **選考の流れを、書いたとおりに運用する前提で**：知名度がない会社ほど、「書いたとおりだった」が信頼になる
- **事業の説明より、仕事と人**：事業の規模で比べられると負ける。仕事の具体は比べられない
- **書き方は[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)の「企業ページで、『知らない会社』の不安を先に解く」、[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)の「企業ページを、『選考で何が起きるか』で埋める」**

## 面談で、仕事を見せる

- **面談は、会社の説明ではなく、仕事の話**：「最初の一年に、何をするか」を、その仕事の人が話す
- **「知らない会社に時間を使うか」の不安は、面談の中身で解ける**：会社の規模ではなく、仕事の具体と人
- **面談後の連絡を、当日か翌日に**：知名度がない会社ほど、対応の速さが信頼になる
- **面談の組み方は[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)の「面談で、仕事を見せる」**

## 知名度のなさを、隠さない

- **「知られていない会社です」と、書いてよい**：隠すより、書いたうえで仕事の具体を
- **「知られていない理由」を、事実で**：「一般向けの製品ではないので、名前を知る機会が少ない」など
- **大手と比べない**：規模で比べると負ける。比べるなら仕事の具体
- **隠すと、面談で気づかれ、不信になる**
- **隠さない書き方は[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)の「知名度のなさを、隠さない」**

## 承諾の段階で、周囲に説明できる材料

- **承諾の段階で、「周囲（家族・友人）に説明できるか」の不安が出る**：知名度の差が最後に出る段階
- **学生が周囲に説明できる材料を、渡す**：何をしている会社か、誰と働くか、入社後の一年。一枚で
- **内定後の接点で、社員と話す場を**：「この人たちと働く」が説明の材料になる
- **承諾の段階の考え方は[内定辞退を減らす方法](/media/ob-naitei-jitai/)**

## 今年の対応が、翌年の「知られ方」になる

- **今年会った学生の体験が、翌年に読まれる**：体験談、口伝え。知名度がない会社の「知られ方」はここから
- **「書いたとおりだった」「速かった」「仕事の話ができた」が、翌年の知られ方**
- **認知の施策より、今年の対応**：[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)の「『書かれる選考』を、今年する」

### エージェントベストの見解

これは発注側の誤解の話です。知名度の相談で、「大手と同じ媒体を使っても、名前で負けるのではないか」と言われることがあります。当社が確かめるのは、「どの段階で負けているか」です。ナビの一覧で名前で比べられる段階なら、負けます。スカウトが開かれて読まれる段階なら、名前は見られていません。承認以降なら、企業ページと面談で解けます。「名前で負ける」のは、名前で探される入口を主にしているときで、届ける入口を主にすれば、名前は勝負の場に出てきません。当社は3媒体を扱いますが、知名度がない会社に、名前で探される入口を主に勧めません。届ける入口を先に、読む場所を整えて、面談で仕事を見せる、の順番で組みます。

## まとめ

- 知名度の差は「探される」「承認・面談・承諾」で出て、「開く・読む」では出ない。全部の段階で不利ではない
- 入口は「企業から届ける」（スカウト）と「知っている人が届ける」（リファラル・大学）を先に、確かめる場（回・インターン）、読む場所（企業ページ・記事）の順。掲載を「探される入口」として主にしない
- 文面は、読んだ一文・最初の一年の場面・一緒に働く人・何を見るか・話す場で埋め、会社の説明は一言。企業ページは「知らない会社だが大丈夫か」の不安に順番に答え、仕事と人で
- 面談で仕事を見せ、対応を速く、知名度のなさを隠さず、事実で。承諾の段階では周囲に説明できる材料を渡す
- 認知を上げる施策より、今年の対応。今年会った学生の体験が、翌年の「知られ方」になる

## よくある質問

### 上司から「まず知名度を上げろ」と言われています

「知名度の差が出る段階」の表を見せ、差が出ない段階（開く・読む）で勝てる入口から始めることを提案します。認知の施策は、母集団に効くまでに時間がかかり、今年の採用に間に合いません。「届ける入口で今年の母集団を作りながら、今年の対応が翌年の知られ方になる」という順番のほうが、知名度も母集団も、両方に効きます。上司への伝え方は[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)で書きました。

### 承認や返信は来るのに、面談に来ません

差が出る段階（承認以降）で止まっています。承認した人は、企業ページを見に行っており、そこで不安が解けていないか、面談の案内が「知らない会社に時間を使う」価値を伝えていないかです。企業ページを「不安に順番に答える形」に直し、面談の案内に「その仕事の人が、最初の一年の話をする」と中身を書き、返信を当日に返します。切り分けは[知名度がない会社のOfferBox運用](/media/ob-chimeido-nai/)の「届いた学生の反応を、次の文面に活かす」で書きました。

### 知名度がない会社の母集団形成は、御社に相談できますか

できます。当社は、差が出る段階の整理、入口の順番、文面で埋めるものの型、企業ページの型、承諾の段階の材料の型を支えられます。読んで書くこと、社員の記事、面談、内定後の場は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
