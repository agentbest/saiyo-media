「うちの選考は長いのか短いのか分からない」「応募から内定まで、どのくらいが目安か」という相談を受けます。目安を数字で答えることはできますが、その数字は会社の状況によって意味が変わります。**結論から言うと、選考期間の目安は業界の平均ではなく、「候補者が並行して受けている他社より先に、内定を出せているか」で決めます。** 他社より遅ければ、どれだけ短くても長すぎます。この記事では、目安の考え方、期間を段に分けて見る方法、延びる場所の見つけ方、短くする打ち手、短くしてはいけない部分を順に整理します。日数を測る指標の作り方は別の記事に任せ、「期間の設計」に絞ります。

## 目安は他社との相対で決まる

候補者は、ほとんどの場合、複数の会社の選考を同時に受けています。候補者の側から見た選考期間は、「この会社が決めるのを待つ時間」であり、その間に他社から先に内定が出れば、そちらに決めることが多くなります。

だから、選考期間の目安は次のように考えます。

- **新卒**：同じ時期に動いている会社の選考の進み方が基準になる。学生は複数の内定を比べる前提で動くので、「内定を出す順番」が効く
- **中途**：候補者が転職活動を始めてから決めるまでの期間の中に、自社の選考が収まっているかが基準。在職中の候補者は面接の日程が限られるので、面接の枠の取り方が効く
- **人を紹介で採る場合**：紹介会社が同時に他社にも紹介しているので、他社より速く返事をすることが、紹介会社からの優先度にもつながる

「何日が目安か」の答えは、自社の候補者がどんな会社と並行して受けているかで決まります。面接で「他にどんな会社を受けていますか」と聞いているなら、その会社の選考の速さが、自社の目安になります。

## 期間を段に分けて見る

応募から内定までを一つの期間として見ると、どこが延びているかが分かりません。次のように段に分けます。

1. 応募→書類選考の結果連絡
2. 書類通過→一次面接の実施
3. 一次面接→結果連絡
4. 一次通過→二次面接の実施
5. 二次面接→結果連絡
6. 二次通過→最終面接の実施
7. 最終面接→内定の連絡

段に分けると、延びているのが「面接の実施までの待ち」なのか、「面接後の結果連絡までの待ち」なのかが見えてきます。この二つは原因が違います。実施までの待ちは、面接官の予定か日程調整の往復が原因です。結果連絡までの待ちは、採用会議の開き方か、結果を送る担当の動きが原因です。段ごとの日数の測り方は[採用リードタイムの見方](/media/kh-kpi-kikan/)に整理しています。

## 延びる場所の見つけ方

延びる場所は、だいたい次のどれかです。

- **面接官の予定待ち**：役員や現場の責任者の予定が埋まっていて、面接の日程が先になる。最終面接の前で起きやすい
- **日程調整の往復**：候補日を出す、返事を待つ、合わない、また出す。一往復ごとに日数が延びる
- **まとめて選考する癖**：「応募が揃ってから書類選考をする」「候補者が揃ってから会議を開く」。先に応募した候補者ほど長く待たされる
- **会議の開き方**：採用会議が週に一度の定例で、面接の直後に開かれない。面接から会議までの待ちが積み上がる
- **結果連絡の担当の動き**：会議で決まったのに、連絡を送るのが数日後になる
- **課題や適性検査の挟み方**：面接と面接の間に課題を挟み、候補者の提出と社内の確認で日数が増える

延びる場所が分かれば、打ち手は場所ごとに違います。全体を「もっと速く」と言うより、延びている段を一つ指して直すほうが、動きます。

### エージェントベストの見解

相談で最も多い思い込みは、「選考期間が長いのは面接の回数が多いからだ」というものです。実際には、回数より「面接と面接の間の待ち」が期間を延ばしています。当社は複数の媒体で選考の運用を見ていますが、面接が三回あっても間が詰まっている会社と、二回しかなくても間が空く会社とでは、後者のほうが応募から内定までが長いことがよくあります。回数を減らす前に、各段の「結果連絡までの日数」と「次の面接の実施までの日数」を分けて見てください。多くの会社で延びているのは、面接後に会議を開くまでと、会議後に次の面接官の予定を押さえるまでです。ここは面接の回数とは関係なく、会議の開き方と予定の押さえ方で短くできます。

## 短くする打ち手

延びる場所ごとの打ち手を並べます。

| 延びる場所 | 打ち手 |
|---|---|
| 面接官の予定待ち | 面接官の枠を週に決まった時間で先に押さえておく。候補者が出てから予定を探さない |
| 日程調整の往復 | 合格の連絡に候補日を入れるか、予約リンクを送る。往復を一回で終える |
| まとめて選考する癖 | 応募が来るたびに書類を見る。候補者が揃うのを待たない |
| 会議の開き方 | 面接の直後に面接官が集まって決める。定例を待たない。決める人を一人に決めておく |
| 結果連絡の担当 | 会議で決めた当日か翌営業日に送ると期限を決める。連絡の担当を固定する |
| 課題の挟み方 | 課題は面接と並行して出す。提出を待ってから次の面接を組まない |
| 段の数 | 一次と二次で同じことを見ているなら、統合する。段を減らすのは最後の手段 |

打ち手の中で効果が速いのは、面接官の枠の固定と、会議の即日化です。どちらも社内の約束ごとで、ツールや費用は要りません。会議の進め方は[採用決定の会議の進め方](/media/kh-ms-kettei-kaigi/)に、合格の連絡に次の案内を入れる形は[合格の連絡の仕方](/media/kh-ms-goukaku-renraku/)に整理しています。

## 短くしてはいけない部分

期間を短くするとき、削ってはいけない部分があります。

- **候補者が考える時間**：内定を出したあと、候補者が承諾を決めるまでの時間。ここを急かすと、承諾しても入社前に辞退が起きやすい
- **候補者が会社を確かめる時間**：面接の中で候補者が質問する時間、現場の社員と話す時間。選考を速くするために面接を短くしすぎると、候補者が会社を確かめられず、内定後に迷う
- **判断に要る材料を集める時間**：面接官の判断が割れている観点について、事実を確かめる時間。ここを省いて決めると、入社後の不一致につながる
- **候補者の都合**：在職中の候補者が面接に来られる日は限られる。会社の都合だけで日程を詰めない

短くするのは「会社側の待ち時間」であって、「候補者の考える時間」ではありません。この区別を社内で共有しておかないと、「速くしろ」が「候補者を急かせ」に変わります。選考中の辞退を減らす設計は[選考中から辞退を減らす設計](/media/kh-naitei-jitai-boushi-senkou/)にも整理しています。

## 媒体ごとの時期の違い

選考期間の考え方は、媒体によって少し違います。

- **OfferBox**：企業から声をかけた学生なので、声をかけてから面接までの速さも含めて期間を見る。声をかけたのに面談が先になると、学生の温度が下がる
- **ワンキャリア**：掲載を見て応募する学生が多く、同じ時期に他社も動いている。応募が集中する時期に「まとめて選考する癖」が出やすい
- **Wantedly**：カジュアルな面談から始まることが多く、面談から選考に移る段階の速さが効く。面談のあと、選考の案内が遅れると、候補者は「本気ではない」と受け取る

どの媒体でも、段に分けて延びている場所を見つけるという方法は同じです。

### エージェントベストの見解

選考期間を短くする順番として、当社が勧めるのは、「段の数を減らす」ではなく、「最も延びている一段だけを先に直す」です。段を減らすと、見るべきことが抜けて、入社後の不一致が増えます。段を減らす前に、面接官の枠を固定し、会議を即日にし、合格の連絡に候補日を入れる。この三つで延びていた段が縮まれば、段の数はそのままで期間が短くなります。それでも他社に追いつかないなら、一次と二次で同じことを見ていないかを確かめ、重なっているなら統合する。人材紹介の側で企業の選考を見ていると、速い会社は面接の回数が少ないのではなく、面接と面接の間が詰まっています。間を詰めるのは社内の約束ごとで、費用はかかりません。

## まとめ

- 選考期間の目安は業界の平均ではなく、候補者が並行して受けている他社より先に内定を出せるかで決まる
- 応募から内定までを段に分け、「面接の実施までの待ち」と「結果連絡までの待ち」を分けて見る
- 延びる場所は面接官の予定待ち、日程調整の往復、まとめて選考する癖、会議の開き方、連絡の担当の動き
- 面接官の枠の固定と会議の即日化は費用がかからず効果が速い。段を減らすのは最後の手段
- 候補者が考える時間と会社を確かめる時間は削らない。短くするのは会社側の待ち時間

## よくある質問

### 役員の予定が取れず、最終面接までが長くなります

役員の面接枠を週に決まった時間で先に押さえておく形を勧めます。候補者が出てから予定を探すと、どうしても先になります。枠が使われない週があっても、押さえておくほうが全体として速くなります。

### 選考を速くすると、見極めが甘くなりませんか

短くするのは会社側の待ち時間であって、面接の中身や判断の材料を集める時間ではありません。面接と面接の間を詰めても、面接の時間や見る観点は変わりません。見極めが甘くなるのは、段を減らして見るべきことが抜けたときです。

### 候補者から「結果はいつ分かりますか」と聞かれます。どう答えればよいですか

面接の終わりに、結果の連絡の期限を伝えます。期限を伝えたら、それより早く送ります。遅れそうなら、遅れることを先に伝えます。聞かれる前に伝えておくのが、候補者の不安を減らす形です。
