OfferBoxで承認され、初回面談を経て、選考に進んだ学生を、現場の面接官が面接する。ここで、面接官がナビ経由の学生と同じ入り方をすると、学生は「面談で話したことは、伝わっていないのか」と感じます。**結論から言うと、OfferBox経由の学生は、企業が選んで送り、文面で一文に触れ、面談で話した学生です。面接官には、その経緯と、この段階で見る項目を1枚で渡し、「なぜうちに」「志望度は」を聞かない理由を先に説明します。** 経緯を知らない面接官が志望動機から入ると、学生は構え、面談で作った温度が消えます。この記事では、OfferBox経由の学生の違い、面接官に渡す1枚、避ける言葉、面接の入り方、結果を戻す型、面接官の負担の減らし方、やりがちな失敗、分担を整理します。面接官との段階ごとの合意は[選考フローを短くする考え方](/media/ob-senkou-sekkei/)、現場の巻き込み方は[現場社員を巻き込む方法](/media/ob-genba-makikomi/)で書きました。

## この作業の目的｜面談の続きとして、面接に入る

初回面談は「文面の続き」として設計しました。面接は「面談の続き」です。文面→面談→面接と、学生にとっては一本の流れです。ところが、面接官が経緯を知らないと、面接だけが別の流れになります。

面接官への説明の目的は、面接を「面談の続き」にすることです。面談で確かめたことは再確認せず、その先を聞く。文面で触れた一文を知ったうえで、行動の型を深く聞く。この連続性があると、学生は「この会社は自分をずっと見ている」と感じ、選考中の辞退が減ります。

## 手順1｜OfferBox経由の学生の違いを、面接官に伝える

面接官が知っておく違いを、表にして渡します。

| 観点 | ナビ経由の学生 | OfferBox経由の学生 |
|---|---|---|
| 出会い方 | 学生が探して応募した | 企業が選んで送り、学生が承認した |
| 企業を知った経路 | 一覧の中で見つけた | 自分宛の文面を読んだ |
| 面接までの接点 | 説明会と書類 | 文面で触れた一文と、初回面談での会話 |
| 志望の状態 | 応募した時点で志望している | 面談で興味を持ち、選考に進むと自分で決めた。他社も並行 |
| 面接での構え | 志望動機を用意している | 「面談の続き」と思っている。志望動機を聞かれると構える |
| 面接官が知っていること | 書類の内容 | 文面で触れた一文、面談の記録、確かめたいこと |

最後の行が要点です。面接官は、ナビ経由の学生より多くを知った状態で面接に入れます。知らずに入ると、その利点が消えます。

## 手順2｜面接官に渡す1枚

面接の前に、人事が面接官に1枚を渡します。面接官はその1枚を読んで面接に入ります。

| 項目 | 内容 | 出どころ |
|---|---|---|
| 文面で触れた一文 | オファーの冒頭で触れた、学生の自由記述の一文 | 管理表 |
| 面談で話したこと | 学生の経験、志向、質問、温度 | 面談の記録。型は[初回面談の設計](/media/ob-mendan-sekkei/) |
| 面談で確かめたこと | 自由記述と適性検査を照らした仮説の結果 | [適性検査結果の使い方](/media/ob-tekisei-katsuyou/) |
| この段階で見る項目 | 段階ごとに1つ。「仕事に必要な行動の型」など | 段階の目的。[選考フローを短くする考え方](/media/ob-senkou-sekkei/) |
| 聞くこと | 見る項目に対応する質問。文面の一文と面談の話の「その先」 | 評価基準。[評価基準の作り方](/media/ob-gakusei-hyouka-kijun/) |
| 聞かないこと | 志望動機、志望度、面談で確かめたこと、大学名、適性検査の結果そのもの | 次の手順 |
| 他社の状況 | 面談で聞いた他社の進行 | 面談の記録 |
| 名義の人 | 誰の名義で送り、誰が面談したか | 管理表 |

「聞かないこと」を明記するのが、この1枚の特徴です。面接官は、聞くことより聞かないことのほうが、指示が無いと分かりません。

### エージェントベストの見解

相談で最も多い思い込みは、「OfferBox経由の学生は、自分から応募したわけではないので、志望度が低い」というものです。この思い込みを持った面接官は、最初に「なぜうちを受けようと思ったのですか」と聞き、答えが弱いと「やはり志望度が低い」と判断します。実際には、OfferBox経由の学生は、文面を読んで承認し、面談で話を聞き、選考に進むと自分で決めた学生で、その時点での志望は、応募した時点のナビ経由の学生と変わりません。違うのは、志望動機を「用意していない」ことです。用意していないのは、面談の続きだと思っているからで、志望が無いからではありません。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、面接官がこの思い込みを持っている会社は、面接での不採用と、面接後の辞退の両方が多い。面接官に、「志望度は、面談で選考に進むと決めた時点で示されている。面接では行動の型を見る」と、最初に説明することを勧めます。

## 手順3｜面接官が言いがちな言葉と、避ける理由

面接官が、悪気なく言いがちな言葉を、避ける理由と一緒に渡します。

| 言いがちな言葉 | 学生がどう受け取るか | 代わりに |
|---|---|---|
| 「なぜうちを受けようと思ったのですか」 | 面談で話したのに、伝わっていない | 「面談で〇〇の話をされたそうですね。その先を聞かせてください」 |
| 「志望度はどのくらいですか」 | 試されている。他社と比べられている | 聞かない。他社の状況は面談で聞いている |
| 「オファーで来ただけですか」 | 自分から来たのではないと見下されている | 言わない。企業が選んで送った学生 |
| 「自己PRをお願いします」 | 面談で話したことをまた話す | 「自由記述に〇〇と書かれていましたが、そのとき自分はどう動きましたか」 |
| 「うちの事業は知っていますか」 | 試されている | 「面談で仕事の話を聞いて、気になった点はありますか」 |
| 「他に受けている会社は」 | 面談で答えたのに | 聞かない。記録にある |
| 「〇〇大学なんですね」 | 大学で見られている | 言わない。考え方は[大学群を広げるべきか](/media/ob-daigakugun/) |

代わりの言葉に共通するのは、「文面と面談の続き」として聞くことです。「〇〇と書かれていましたね」「面談で〇〇と話されたそうですね」から入ると、学生は「見てくれている」と感じます。

## 手順4｜面接の入り方と、結果を戻す型

面接の入り方と、面接後に人事へ戻す記録の型を、面接官に渡します。

**入り方**

1. 名乗り、自分の仕事を一言
2. 「〇〇（名義の人）との面談で、△△の話をされたと聞いています」と、経緯を知っていることを伝える
3. この段階で見ることを、学生に伝える。「今日は、仕事に必要な動き方を、経験の話から聞かせてください」
4. 文面の一文と面談の話の「その先」を聞く
5. 学生からの質問を受ける
6. 次の段階と、結果連絡の時期を伝える

**結果を戻す型**

| 項目 | 内容 |
|---|---|
| 見る項目の結果 | この段階で見た項目について、行動の事実と判断 |
| 合否と理由 | 理由は行動の事実で。印象でなく |
| 学生の温度 | 面接での様子、質問の内容 |
| 学生が話した新しい情報 | 面談で出なかった経験や志向 |
| 他社の状況の変化 | 学生が言えば |
| 次の面接官に渡すこと | 次の段階で確かめてほしいこと |

結果が戻ると、人事は次の段階の1枚を作れ、辞退の予兆にも気づけます。戻らないと、次の面接官がまた最初から聞きます。

## 手順5｜面接官の負担を減らす

面接官は現場の社員で、本来の仕事があります。負担を減らす工夫を人事が持ちます。

- **1枚を渡す**：面接官が管理表や記録を探さなくて済む。面接の前日までに
- **聞くことを、質問の形で書く**：面接官が質問を考えなくて済む
- **結果の型を用意する**：面接官が書く量を最小に。項目を埋めるだけ
- **面接の所要を短めに**：見る項目が1つなら、長い時間は要らない
- **面接官への説明は、一度にまとめて**：OfferBox経由の学生の違い、避ける言葉、入り方、結果の型を、最初に一度説明する。学生ごとに説明しない
- **面接の結果を、その場で人事が聞き取る形も可**：面接官が書く時間が無いなら、面接直後に人事が数分で聞く

面接官への説明を「面接官研修」のような大がかりなものにしない。1枚と、一度の説明で足ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 面接官が経緯を知らない | 志望動機から入り、学生が構える | 1枚を渡す |
| 「なぜうちに」「志望度は」を聞く | 面談で話したのに、と学生が感じる | 聞かないことを明記 |
| 面談で確かめたことを再確認する | 学生が「また同じ話」と感じる | 面談の記録を渡し、その先を聞く |
| 面接官が「オファー経由は志望度が低い」と思っている | 不採用と辞退が増える | 最初に説明する |
| 聞くことだけ渡して、聞かないことを渡さない | 面接官が自分の型で聞く | 聞かないことを明記 |
| 結果が戻らない | 次の面接官がまた最初から | 型を渡し、戻す |
| 印象で合否を決める | 面接官ごとに評価が割れる | 行動の事実で。基準は評価基準の記事で |
| 学生ごとに面接官に説明する | 人事の負担が大きい | 最初に一度まとめて |

最も多いのは、最初の「面接官が経緯を知らない」です。人事が知っていることを、面接官に渡していない状態です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| OfferBox経由の学生の違いと避ける言葉を、面接官に一度説明する | 人事 |
| 面接の前に1枚を作って渡す | 人事（または運用代行が作り、人事が渡す） |
| 面接する | 面接官 |
| 結果を型で戻す | 面接官（または人事が聞き取る） |
| 次の段階の1枚を作る | 人事 |
| 面接官ごとの結果を並べ、ばらつきを見る | 人事 |

運用代行に出している場合、1枚の作成（管理表と面談の記録から）は代行が行えますが、面接官への説明と、面接官からの結果の聞き取りは社内です。代行の範囲は[運用代行に任せられる範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。「面接官に、聞かないことを明記する」ことです。当社がOfferBoxの運用の相談で面接の話を聞くとき、面接官に「聞くこと」は渡しているが「聞かないこと」は渡していない会社が多くあります。聞くことだけ渡すと、面接官は、聞くことに加えて、自分がいつも聞いていること（志望動機、自己PR、他社の状況）も聞きます。学生には、面談で話したことをもう一度聞かれる面接になります。当社が面接官に渡す1枚に「聞かないこと」の欄を設けているのは、この理由です。「志望動機は聞かない。面談で選考に進むと決めた時点で示されている」「自己PRは求めない。自由記述の一文のその先を聞く」と書いてあれば、面接官は迷いません。聞くことより、聞かないことのほうが、面接官への説明として効きます。

## まとめ

- OfferBox経由の学生は、企業が選んで送り、文面で一文に触れ、面談で話した学生。面接は「面談の続き」
- 面接官に、触れた一文・面談の記録・確かめたこと・この段階で見る項目・聞くこと・聞かないこと・他社の状況を1枚で渡す
- 「なぜうちに」「志望度は」「オファーで来ただけか」「自己PRを」は聞かない。文面と面談の「その先」を聞く
- 結果は行動の事実で戻す。次の面接官に渡すことも
- 面接官の負担は、1枚と一度の説明と結果の型で最小にする

## よくある質問

### 面接官が「志望動機を聞かないと判断できない」と言います

志望の有無は、面談のあとに選考に進むと学生が自分で決めた時点で示されています。面接で見るのは、この段階の項目（仕事に必要な行動の型など）です。「面談で〇〇の話をされたそうですね。その先を聞かせてください」と入ると、志望動機を聞かなくても、学生が何に興味を持っているかは分かります。

### 面接官が複数いて、それぞれ違う聞き方をします

1枚に「この段階で見る項目」「聞くこと」「聞かないこと」を書き、全員に同じものを渡します。加えて、結果の型を統一すると、面接官ごとのばらつきが見えます。ばらつきの直し方は評価基準の記事で書きます。

### 面接官に渡す1枚は、御社に作ってもらえますか

管理表と面談の記録から1枚を作る作業は、当社が行えます。面接官への説明と、面接官からの結果の聞き取りは、企業の人事にお願いしています。当社がOfferBoxの運用代行を受けるときは、1枚の型を最初に決め、面接のたびに当社が作って人事に渡します。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
