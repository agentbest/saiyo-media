メガバンク、地方銀行、信用金庫、ネット銀行、関連の会社が新卒を採る。区分によって、学生に知られている度合いと、採用の形（総合職・エリア職・専門職）と、地域との関わりが違う。学生は「銀行は安定」で来るが、店舗の減少やデジタル化を知っていて、「この仕事は続くか」「自分は何をするのか」を確かめている。「安定」だけを出す文面と記事は、その不安に答えず、営業と転勤と資格の実態で離れる。**結論から言うと、銀行業界は区分で採用の形が違い、学生は「安定」で来て「続くか」を確かめます。媒体の前に、変化の中で自社がどこにいるかを一行にし、営業と転勤と資格の実態を隠さず書きます。メガは学生が並べて比べる場を、地銀・信金は地元で絞って送る型か、地域の企業を支えた場面を記事で読んでもらう型を先に検討し、専門職（デジタル、市場）は専攻や経験で絞って送る型を使います。** この記事では、銀行業界の採用構造、判断軸の当て方、学生が確かめること、変化の中で自社がどこにいるかの一行、区分ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## 銀行業界の採用構造と、媒体との相性

| 区分 | 学生の認識 | 採用の特徴 | 媒体との相性 |
|---|---|---|---|
| メガバンク | 知られている。候補に入っている | 多く採る。総合職・エリア職・専門職。全国転勤 | 比べられる場で選考情報と実態を。送る型は専門職に |
| 地方銀行 | 地元では知られている。都市部では知られていない | 地元の学生が中心。エリア職と総合職。地域の企業との関係 | 地元・Uターンの層に絞って送る型か、地域の企業を支えた場面の記事 |
| 信用金庫・信用組合 | 地域の中で知られている | 少人数の採用。地域密着。転勤は地域内 | 地元の層に送る型か記事。学校との関係も |
| ネット銀行・関連会社 | 知られている度合いが会社で違う | デジタル・専門の職種が多い | 専攻や経験で絞って送る型 |

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 学生が「安定」で来るが、変化を知っている | 「続くか」「何をするか」の不安に文面が答えていない | 変化の中で自社がどこにいるかを書く |
| 営業（法人・個人）、転勤、入社後の資格 | 「安定」の憧れと合わず、実態で離れる | 隠さず書く |

## 判断軸を、銀行業界に当てる

| 軸 | 銀行業界での見方 |
|---|---|
| 対象（誰に届くか） | 「安定」「金融に興味」の記述は多い。絞るのは「地元で続けた・人を支えた・数字を追った・仕組みで手間を減らした（専門職）」の記述。区分と形ごとに |
| 型（送るか、来るか、比べられるか） | メガは「比べられる」型が使える。地銀・信金は「送る」型で地元で絞るか、「来る」型で地域の場面を読んでもらう。専門職は「送る」型で専攻や経験で |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 支店の若手は営業で動く。名義と面談枠を先に固定する。区分と形が複数なら、人事が型と台帳を持ち、支店や部門が名義と面談を持つ |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。銀行では、「型」の軸で区分ごとに位置づけが分かれることと、「安定」を出すだけでは変化への不安に答えられないことが、他の業界と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「銀行は安定志向の学生が多いので、『安定』を出せば来る」というものです。当社は3媒体すべての販売パートナーとして、銀行や信用金庫の相談を受けますが、応募は来ても、面談で「店舗は減っていますよね」「デジタル化で仕事はなくなりますか」「自分は何をするんですか」と聞かれ、「安定しています」で止まって離れる、という形が多くあります。学生は「安定」を求めていますが、業界の変化を知ったうえで、「変化の中で、この銀行は何をしていて、自分はどこに関われるか」を確かめています。当社が銀行に媒体の前に用意してもらうのは、「店舗と営業の今と、デジタルと専門の新しい部署と、新卒の配属の決まり方」を一行にしたものと、営業と転勤と資格の実態の一枚です。一行と一枚があれば、「安定」ではなく「続く理由」で来る学生が残ります。

## 学生が、確かめること

- **変化の中で、自社がどこにいるか**：店舗と営業の今、デジタルと専門の新しい部署、配属の決まり方。「デジタル化」の一語ではなく実態
- **営業の実態**：法人営業と個人営業の中身、数字の追い方、地域の企業とどう関わるか
- **転勤と初任地**：メガは全国、地銀は県内か、信金は地域内か。エリア職との違い。[東京本社で全国採用する会社のOfferBox運用](/media/ob-tokyo-unyou/)
- **入社後の資格**：何を、いつまでに、会社がどう支援するか。自社の方針と制度の確認のうえで、時期と支援の形を書く
- **地銀・信金なら、地域と暮らし**：地元で働けるか、地域の企業との関係。[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| メガで、学生の候補に入り、クチコミと選考情報が付いている | 学生が並べて比べる場（ワンキャリア）で選考情報と実態を | 比べる対象に入っている。採用の形ごとの実態とクチコミをずらさない |
| メガ・ネット銀行で、専門職（デジタル、市場、データ）を憧れの層とは別に採りたい | 企業から送る型（OfferBox） | 専攻や「仕組みで手間を減らした経験」で絞り、別に届く |
| 地銀・信金で、地元・Uターンの層に絞って会いたい | 企業から送る型（OfferBox） | 出身地域と「地元で続けた・人を支えた経験」で絞れる。作業を外に出せる |
| 地銀・信金で、支店の若手が地域の企業を支えた場面を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「安定」ではなく「地域の企業とこう関わる」の場面を読んで選ばれる。業界イメージを変える場 |
| 変化の中で自社がどこにいるかの一行が、まだない | どれも先ではない | 一行を作ってから |

どれか一つが正解ではなく、区分と採用の形と職種で、先に検討するものが変わります。

## 組み合わせ

- **メガは、比べられる場と送る型を組み合わせる**：比べられる場で総合職・エリア職の受け皿を、送る型で専門職を。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **地銀・信金は、送る型と記事を置く型を組み合わせる**：文面で「あなたの〇〇で地元で続けた経験を読んで」を、記事で「地域の企業を支えた日」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **地銀・信金は、地元の大学との関係と組み合わせる**：学校経由の採用がある。学校で会った学生に媒体で送らない。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)

## 見せ方｜「安定」ではなく、変化の中の位置と、地域と、実態

- **変化の中で自社がどこにいるかを、一行で**：「店舗と営業が〇〇で、デジタルと△△の部署を□□の形で始めている。新卒の配属は◇◇の決まり方」
- **「安定」を、雇用・評価・異動の中身で**：「安定しています」では、変化への不安に答えられない
- **地銀・信金は、地域の企業を支えた場面を一つ**：「〇〇の会社の△△のときに、□□をした」。支店の若手の名義で。顧客が特定されない形で
- **営業の実態を、場面で**：「数字は〇〇の決まり方で、法人と個人の割合は△△」。数値は実態で。この記事では書かない
- **新しい部署だけを光らせない**：店舗と営業の現場を選ぶ学生に、その中身と誇りを書く。[エネルギー業界の採用媒体の選び方](/media/hikaku-energy-erabikata/)の「既存の事業を下に置かない」と同じ
- **業界イメージ（古い、縮小、ノルマ）を否定せず、実態と変えたことで**：[業界イメージが不利な会社のWantedlyの書き方](/media/wt-gyokai-image/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 変化の中で自社がどこにいるかの一行と、配属の決まり方 | 経営と人事 |
| 区分と形と職種で、先に検討する型を決める | 人事と責任者 |
| 形ごとの「こんな人」と実態の一枚 | 人事と、支店・部門の責任者 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、支店の若手が地域の場面を話し、整えるのは人事か外に | 若手と人事 |
| 個別の一文、文面の最終確認、名義、面談 | 支店・部門の若手 |
| 学校との関係（地銀・信金） | 人事 |
| 面接官に「なぜ銀行か」を聞かないと伝える | 人事 |

- **支店の若手に頼むのは、名義・一文・面談の三つ。営業の合間で**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)

運用代行や代理店が支えられるのは、一行の型、区分と形の分け方の整理、一枚の型、文面と記事の型、送る型の作業、記事を整える部分、台帳の型までで、一行の中身、配属の決定、実態の開示、名義の選定、面談、学校との関係は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

同じ銀行でも、学生の候補に入っているメガには、ワンキャリアのように学生が並べて比べる場で選考情報と採用の形ごとの実態を透明に出し、送る型は専門職に絞ることを勧め、地方銀行や信用金庫には、OfferBoxで地元・Uターンの層に「地元で続けた・人を支えた経験」で絞って送るか、Wantedlyで支店の若手が地域の企業を支えた場面を記事で読んでもらう型を先に勧めることが多いです。理由は、メガは候補に入っていて比べられる場が機能し、地銀・信金は地域の外では候補に入っておらず、地元の層に「この地域の、この企業と」で届く形が合うからです。地銀・信金の強みは「安定」ではなく「地域の企業との関係」で、それは場面で書けます。当社は3媒体すべての販売パートナーとして、区分と地域で分けて提案しています。

## まとめ

- 銀行業界は、メガ・地銀・信金・ネット銀行で、知られている度合いと採用の形と地域との関わりが違う。学生は「安定」で来て、変化の中で「続くか」「何をするか」を確かめる
- 媒体の前に、変化の中で自社がどこにいるかの一行と、営業・転勤・資格の実態の一枚を作る。「安定」だけでは変化への不安に答えられない
- メガは並べて比べる場で選考情報と実態を、送る型は専門職に。地銀・信金は地元で絞って送る型か、地域の企業を支えた場面を記事で読んでもらう型を先に。採用の形が複数なら形ごとに分ける
- 見せ方は「安定」を中身で、地域の企業を支えた場面を一つ、営業と転勤と資格を隠さず、新しい部署だけを光らせず店舗と営業の現場の誇りを書く
- 支店の若手に頼むのは名義・一文・面談、人事は型と台帳と返信。地銀・信金は地元の大学との関係と組み合わせる

## よくある質問

### 地方銀行ですが、都市部の学生にも来てほしいです

先に、地元・Uターンの層で承認と面談の型を作り、面談で聞かれた「地域」「転勤」「暮らし」の答えを材料にしてから、都市部の学生に「来られる材料」を揃えて少なく送ります。地銀に都市部から来る学生は、「地域の企業と関わる仕事」で選ぶ少数で、「安定」では来ません。順番は[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)で書きました。

### デジタル化を前面に出すと、店舗の営業に配属される学生が離れませんか

前面に出すのではなく、変化の中で自社がどこにいるかを一行で書き、配属の決まり方を添えます。「デジタルの部署は〇〇の条件で、新卒の多くは店舗の営業から始まります」と正直に書き、店舗の営業の中身と誇り（地域の企業を支えた場面）を書くと、営業を選ぶ学生が来て、その学生は配属で離れません。新しい部署だけを光らせると、配属で離れます。

### 銀行業界の媒体選びは、御社に相談できますか

できます。当社は、一行の型、区分と形の分け方の整理、一枚の型、文面と記事の型、送る型の作業、記事を整える部分、台帳の型を支えられます。一行の中身、配属の決定、実態の開示、名義の選定、面談、学校との関係は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
