異動や退職、育児休業などでWantedlyの担当が替わることが決まったとき、多くの会社は「管理画面の使い方」を口頭で伝えて終わりにしがちです。ところが後任が困るのは、画面の操作より、「この記事は誰に確認してもらうのか」「この候補者とは何を約束していたのか」といった、画面に残っていないことです。**結論から言うと、Wantedlyの運用を引き継ぐときは、画面の外にある情報を七つの束にまとめた資料を作り、前任と後任が並んで動く期間を取って渡します。** 引き継ぎがないまま交代した場合の立て直しは[Wantedlyの担当者が交代したときの立て直し](/media/wt-tantousha-koutai/)、スカウトに絞った引き継ぎは[Wantedlyのスカウト運用の引き継ぎ](/media/wt-scout-hikitsugi/)で書きました。この記事では、運用全体を渡すときの資料の中身と作り方を整理します。

## この作業の目的｜画面に残らないことを、後任が探さずに済むようにする

Wantedlyの管理画面には、公開した記事や募集、スカウトの履歴が残っています。後任は、画面を見れば「何があるか」は分かります。分からないのは、次のようなことです。

- なぜこの募集を出しているのか。誰を採りたいのか
- この記事を書くとき、誰に話を聞き、誰に確認してもらったのか
- 面談の約束や、候補者に伝えたことは何か
- 出してはいけない情報、社内で決めた表現の決まりは何か

引き継ぎの資料は、こうした画面の外の情報を、後任が人に聞いて回らずに済む形でまとめるものです。

## 資料の七つの束

資料は、次の七つの束に分けて作ります。

| 束 | 中身 |
|---|---|
| 1. 運用の全体図 | 何のために使っているか、求める人物像、いま出している募集、年間の予定 |
| 2. 権限と契約 | 管理画面の権限を持つ人、契約の期間と更新の時期、窓口の連絡先 |
| 3. 記事の一覧 | 会社ページ・募集・ストーリーの一覧、公開日、話した社員、次に直す予定 |
| 4. スカウトの型と台帳 | 文面の型、絞り込みの条件、送った相手と返信の記録 |
| 5. 対応中の相手 | 返信待ち・面談の調整中・選考中の候補者と、伝えていること |
| 6. 社内の協力者 | 記事に協力してくれる社員、面談に出る人、確認をする人 |
| 7. 決まりごと | 確認の流れ、出してはいけない情報、文体、名称やロゴの扱い |

権限の種類や設定は、管理画面の仕組みに沿って書きます。仕組みは[Wantedlyの管理画面の使い方](/media/wt-kanri-gamen/)、契約の期間の考え方は[Wantedlyの契約期間の決め方](/media/wt-kikan/)で整理しています。

### エージェントベストの見解

引き継ぎの資料を作るとき、前任が最初に書き始めるのは、たいてい「3. 記事の一覧」と「4. スカウトの型」です。目に見える成果物なので書きやすいからです。ただ、交代のあとに後任が最初につまずくのは、「5. 対応中の相手」と「6. 社内の協力者」のほうです。返信を待っている候補者を放置したり、記事に協力してくれていた社員に挨拶がないまま次の依頼をしたりすると、そこから関係が崩れます。当社が勧める作る順番は、5と6を最初に、次に7、そのあとに1から4です。成果物は画面にも残っていますが、人との約束は前任の頭の中にしかありません。消えやすいものから先に書くのが、引き継ぎの資料を作るときの順番です。

## 資料を作る順番と書き方

資料は、前任が一人で一気に書こうとすると、途中で止まります。次の順番で、少しずつ書きます。

1. **対応中の相手と社内の協力者**：交代が決まった時点で、まず書く。人の名前は社内の資料にとどめ、外に出さない
2. **決まりごと**：確認の流れ、出してはいけない情報、文体の決まりを、普段の作業を思い出しながら書く
3. **運用の全体図**：なぜWantedlyを使っているか、誰を採りたいかを、経営や現場と合わせた言葉で書く
4. **権限と契約、記事の一覧、スカウトの型と台帳**：画面や既存の表を見ながら整える

書き方は、説明の文章より、表と箇条書きを中心にします。後任が迷ったときに引く辞書のように使うからです。「なぜそうしているか」だけは、一行でよいので添えます。理由が分からない決まりは、後任が守りにくくなります。

## 引き継ぎ期間の進め方

資料を渡すだけでは、引き継ぎは終わりません。可能なら、前任と後任が並んで動く期間を取ります。

- **前半**：前任が作業をし、後任が隣で見る。資料に書いていないことが出てきたら、その場で足す
- **後半**：後任が作業をし、前任が確認する。候補者への返信は、後任の名前で出し始める
- **交代のあと**：しばらくの間、前任に質問できる窓口を残しておく

並んで動く期間が取れない場合は、資料を読んだ後任が、質問を一覧にして前任に一度で聞く場を作ります。質問をまとめずに思いつくたびに聞くと、前任の新しい仕事を圧迫します。

### エージェントベストの見解

引き継ぎの資料は、交代が決まってから作るものだと考えられがちですが、作っておいてよかったと言われるのは、交代が急に決まったときです。体調や家庭の事情で、前任が引き継ぎの時間を取れないまま交代することは珍しくありません。当社が勧めるのは、七つの束のうち、5の「対応中の相手」と7の「決まりごと」だけは、普段から更新する運用にしておくことです。5は台帳の一部として持ち、7は運用の手引きとして持っておけば、交代のときに新しく書く量は大きく減ります。普段から持つ手引きの作り方は[Wantedlyの運用資料の作り方](/media/wt-sd-unyou-shiryou/)で整理しました。引き継ぎの資料は、普段の資料を一冊にまとめ直したもの、と考えると作りやすくなります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 交代の時期を決め、引き継ぎ期間を確保する | 上司 |
| 七つの束を書く | 前任 |
| 運用の全体図の言葉を合わせる | 前任と経営・現場の責任者 |
| 資料を読み、質問をまとめる | 後任 |
| 権限の付け替え | 管理画面の権限を持つ人 |
| 社内の協力者への挨拶 | 前任と後任が一緒に |

## まとめ

- 引き継ぎで渡すべきは、画面の操作より、画面の外にある情報
- 資料は、全体図・権限と契約・記事の一覧・スカウトの型と台帳・対応中の相手・社内の協力者・決まりごとの七つの束にまとめる
- 消えやすい「対応中の相手」と「社内の協力者」から先に書く
- 前任と後任が並んで動く期間を取り、資料に無いことはその場で足す
- 「対応中の相手」と「決まりごと」は普段から更新しておくと、急な交代にも間に合う

## よくある質問

### 前任がすでに退職していて、資料がありません

画面に残っている記事・募集・スカウトの履歴から、記事の一覧と対応中の相手を先に復元します。進め方は[Wantedlyの担当者が交代したときの立て直し](/media/wt-tantousha-koutai/)にまとめています。

### 資料はどこに置けばよいですか

社内で権限を管理できる共有の場所に置きます。候補者の情報を含むので、閲覧できる人を採用に関わる人に絞ります。担当の個人のフォルダに置くと、次の交代のときにまた見つからなくなります。

### 引き継ぎの資料づくりを相談できますか

できます。当社は採用媒体の代理店として、資料の型や作る順番、引き継ぎ期間の進め方の設計を支えています。資料の中身と、候補者への連絡の判断は企業が行ってください。
