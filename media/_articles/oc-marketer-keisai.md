ワンキャリアで新卒のマーケターを募集したとき、最初にぶつかるのは「『マーケティング職』『データを活用して』と掲載したのに、エントリーは多いが、面接で『本当に新卒でマーケに配属されますか』『営業を経てからですか』『最初の年は何をしますか』と聞かれ、答えた内容が体験談で『マーケ志望で入ったが最初は営業だった』『マーケの仕事は資料作りだった』と書かれる」という問題です。**結論から言うと、ワンキャリアのマーケターの掲載は、「マーケティング職」の名前ではなく「新卒がマーケに配属されるのか、営業を経てからか、マーケティングのどの種類か、最初の年に何をし、数字をどう見て、誰が教えるか」を、学生が体験談で読む前に企業ページと募集に書き、「なぜ新卒でマーケを採るのか」を聞かれる前に話します。** この記事では、マーケター志望の学生が体験談で読んでいること、掲載に書くこと、学生の見つけ方、スカウトの文面、選考への接続、社内の分担、やりがちな失敗を整理します。文系学生向けの掲載の全体は[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/)、中途のマーケター募集で書くべき種類と数字と予算の考え方は[Wantedlyでマーケターを採る募集記事の書き方](/media/wt-marketer-boshu/)で書きました。

## マーケター志望の学生が、体験談で読んでいること

マーケティング職は、学生の志望が多い一方で、新卒で配属される会社が少ない職種です。ワンキャリアの学生は、企業ページを読む前に、体験談で「本当に新卒でマーケに行けるのか」を読みます。

| 読んでいること | 掲載への意味 |
|---|---|
| 本当に新卒でマーケに配属されるか | 「マーケティング職」で募集して、実際は営業に配属される会社が多い。体験談で最も聞かれる |
| 営業を経てからか | 「まず営業で〇年」の実態。それが書かれているか |
| マーケティングのどの種類か | 広告の運用か、記事か、展示会か、SNSか、製品の企画か。「マーケティング」の一語では分からない |
| 最初の年に何をするか | 数字を見る仕事か、資料を作る仕事か、外注の窓口か。「データを活用」の一語では分からない |
| 数字をどう見るか | 何の数字を、誰が見て、どう判断するか。新卒が数字を見られるか |
| 誰が教えるか | マーケの先輩がいるか。一人目の新卒マーケか。外注に出していて社内にいないのか |

「本当に新卒でマーケに配属されるか」が、この職種の体験談で最も多く書かれ、企業ページで最も書かれない項目です。「マーケティング職」で募集して営業に配属すると、体験談に「マーケ志望で入ったが営業だった」と書かれ、次の年のマーケ志望の学生が離れます。

## 掲載に書くこと｜配属の実態、種類、最初の年、数字の見方、営業との関係

| 書くこと | 書き方 |
|---|---|
| 配属の実態 | 「新卒でマーケに配属する。〇人」「まず営業で△年、その後に希望と適性でマーケへ」。隠さない |
| 種類 | 「広告の運用」「検索から来る記事」「展示会」「SNS」「製品の企画」。最初に任せる種類を一つ |
| 最初の年 | 「最初の〇か月は△△の数字を毎日見て報告する。□□か月目に一つの施策を先輩と。一年目の終わりに◇◇を一人で」 |
| 数字の見方 | 「何の数字を、どこで見て、誰と振り返るか」。新卒が見られる数字は何か |
| 誰が教えるか | 「マーケの先輩が付く」「新卒マーケは一人目。責任者が付く」「外注に出していて、社内は窓口。学ぶ相手は外注の担当」 |
| 営業との関係 | 作った見込み客が営業に渡り、その後が戻るか。営業を経てからなら、その理由 |

企業ページには配属の実態と営業との関係を、募集には種類と最初の年を、と分担します。「まず営業で〇年」の会社は、それを企業ページに書いたうえで、営業の掲載として出すほうが、体験談に「マーケ志望で営業だった」と書かれません。営業職の掲載は[ワンキャリアで営業職を募集するときの掲載とスカウト](/media/oc-eigyo-keisai/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「マーケティング職は志望が多いから、『マーケティング職』で出せばエントリーが集まる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのマーケター職の掲載と選考を見ていますが、志望の多さは「エントリーが集まる」ではなく「絞る必要がある」を意味します。「マーケティング職」で出してエントリーを集め、実際は営業に配属した会社の体験談には、「マーケ志望で入ったが営業だった」「マーケの仕事は資料作りだった」が書かれ、次の年のマーケ志望の学生がそれを読んで離れ、営業志望の学生は最初から来ません。逆に、「新卒でマーケに配属するのは〇人。最初の年は△△の数字を毎日見る。営業を経る人は□□」と企業ページに書いた会社は、エントリーの数は減っても、体験談に「配属が事前に分かっていた」と書かれ、面接後の辞退が減ります。当社が最初にお願いするのは、「新卒でマーケに配属するのか、営業を経てからか」を経営者に一文で言ってもらうことです。

## マーケター志望の学生の見つけ方

マーケの用語やSNSの運用の記述で絞ると、用語を知っているだけの学生が集まります。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 志望職種 | 「マーケティング」と書く学生は多く、実態を知らずに書く学生も多い | あればよい条件。これだけで絞らない |
| 数字を見て変えた経験 | 「サークルの集客で、〇〇を見て△△を変えたら□□が増えた」 | 数字を見て判断を変えた記述を優先 |
| 効かなかった経験 | 「◇◇をやったが効かず、やめて別のことをした」 | 「効かなかった施策を止めた」と重なる |
| 届ける相手を変えた経験 | 「最初は〇〇に向けていたが、△△に変えた」 | 届ける相手の設定と重なる |
| 用語の記述 | 「SNSを運用」「分析」の記述 | 用語では読まない。何を見て、何を変えたかを読む |

「数字を見て変えたら、何が起きたか」を書いている学生が、マーケターと重なります。ガクチカの読み方は[ワンキャリアの学生のガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

スカウト文面の型は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。マーケターでは、次の点を足します。

- **相手の一文は、数字を見て変えた経験で**：「サークルの集客で〇〇を見て△△を変えたら□□が増えたと書かれていたのを読んで」。用語を並べない
- **配属の実態を、最初のほうで**：「新卒でマーケに配属します。〇人」「まず営業で△年。その後、希望と適性でマーケへ」。隠さない
- **種類と最初の年を、一文で**：「うちのマーケは〇〇の記事が中心で、最初の年は△△の数字を毎日見て報告するところから」
- **誰が教えるかを、一文で**：「マーケの先輩の私が付きます」「新卒マーケは一人目で、責任者の私が付きます」
- **送り主は、マーケで入った先輩か責任者**：人事の名前で「マーケティングに興味のある方」と送らない

つなげ方は[スカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)で書きました。

## 選考への接続｜「なぜ新卒でマーケか」を聞かれる前に話す

- **面接には、マーケの責任者と、マーケで入った先輩が出る**：「本当に新卒でマーケに配属するか」「最初の年に何をするか」を、責任者本人が話す
- **配属の実態と「なぜ新卒でマーケを採るか」を、聞かれる前に話す**：面接の最初のほうで。「営業を経てから」なら、その理由も。聞かれてから答えると「隠していた」と書かれる
- **学生の「数字を見て変えた経験」を聞く**：結果ではなく、何を見て、何を変えたか
- **「なぜマーケか」を聞くとき、営業に誘導しない**：「あなたなら営業でも」と言うと、体験談に「営業に誘導された」と書かれる
- **内定後に、マーケの一日を見せる**：内定の後、実際に数字を見る場や施策の会議を見せると、辞退が減る。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 配属の実態、種類、最初の年、数字の見方、営業との関係を決める | 経営者と、マーケの責任者 |
| 企業ページのマーケターの記述 | 人事が、責任者と先輩に聞いて書く |
| 「なぜ新卒でマーケか」の一文 | 経営者本人 |
| マーケで入った先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「マーケ志望で営業だった」と書かれていないか） |
| スカウトの一文 | 先輩か責任者 |
| 面接 | マーケの責任者と、先輩 |

マーケを外注に出していて社内にマーケの人がいない会社では、「社内にマーケの人はいない。外注の担当と一緒に進める。学ぶ相手は外注の担当と、経営者」と正直に書きます。

運用代行や代理店が支えられるのは、掲載の型、配属の実態を文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、配属の決定、「なぜ新卒でマーケか」、先輩の話、面接は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

マーケター職の内定辞退が続く会社に共通するのは、「面接で『なぜ新卒でマーケを採るのか』に答えられなかった」ことです。当社がワンキャリアのマーケター職の選考を見ていると、学生が「なぜ新卒でマーケを採るのですか」と聞き、面接官が「若い感覚を」と答え、学生がそれを「配属の根拠が無い＝入ってから営業に回される」と読んで、体験談にそう書き、辞退する形が多くあります。逆に、「〇〇の記事を長く担う人を、一から育てたい。営業を経る人とは別に、マーケで採る」と経営者が本人の言葉で答えた会社は、体験談に「配属の根拠が明確だった」と書かれ、辞退が減ります。当社が案内するのは、「なぜ新卒でマーケを採るのか」を経営者の言葉で一文にし、企業ページに書き、面接で聞かれる前に話すことです。若い感覚で学生は来ません。配属の根拠が書かれていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「マーケティング職」で出して、実際は営業に配属 | 体験談に「マーケ志望で営業だった」と書かれる | 配属の実態を書く。営業を経るなら営業の掲載として |
| 「データを活用」で最初の年を済ませる | 「資料作りだった」と書かれる | 最初の年に何の数字を見て、何をするかを書く |
| 種類を書かない | 何のマーケか分からず、用語だけの学生が来る | 広告か記事か展示会か、一つに |
| 誰が教えるかを盛る | 社内にマーケの人がおらず、入社後に分かる | 外注なら外注と、一人目なら一人目と |
| 「なぜ新卒でマーケか」に「若い感覚」と答える | 「配属の根拠が無い」と読まれ、辞退する | 経営者の言葉で、実態の理由を |
| 面接で営業に誘導する | 「誘導された」と書かれる | マーケを選んだ理由を聞き、誘導しない |

最も多いのは、「マーケティング職」で出して営業に配属することと、「なぜ新卒でマーケか」の抜けです。

## まとめ

- マーケター志望の学生は、体験談で「本当に新卒でマーケに配属されるか・営業を経てからか・どの種類か・最初の年に何をするか・数字をどう見るか・誰が教えるか」を、企業ページより先に読む
- 掲載には、配属の実態を隠さず、種類を一つ、最初の年、数字の見方、誰が教えるか、営業との関係を書く。営業を経るなら、営業の掲載として出す
- 学生は、用語やSNSの記述ではなく、「数字を見て変えたら何が起きたか」「効かなかったのでやめた」の記述で見つける。志望の多さは、絞る必要の意味
- スカウトは、マーケの先輩か責任者の名前で、掲載と同じ言葉で。配属の実態を最初のほうで
- 面接にはマーケの責任者と先輩が出て、「なぜ新卒でマーケか」を経営者の言葉で聞かれる前に話し、営業に誘導しない

## よくある質問

### 新卒はまず営業を経験してから、マーケに行く会社です。「マーケティング職」で出せますか

「マーケティング職」では出さず、営業の掲載として出し、企業ページに「まず営業で〇年。その後、希望と適性でマーケに行く道がある。実際に行った人は△人」と書きます。「マーケティング職」で出して営業に配属すると、体験談に「マーケ志望で営業だった」と書かれ、次の年はマーケ志望も営業志望も来ません。マーケに行った人の実態を、盛らずに書きます。

### 社内にマーケの人がおらず、外注に出しています。新卒でマーケを採れますか

採れますが、実態を書きます。「社内にマーケの人はいない。〇〇の運用は外注に出していて、社内は窓口。新卒は外注の担当と一緒に進め、学ぶ相手は外注の担当と経営者。将来は社内に戻したい」のように、いない事実と、学ぶ相手と、将来の形を書きます。「マーケの先輩が付く」と盛ると、入社後に分かって離れます。

### マーケターの掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、配属の実態を文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。配属の決定、「なぜ新卒でマーケか」、先輩の話、面接は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
