事業が急に伸びていて、採る人数が去年の倍になった。人事は一人か二人で、現場も忙しく、OfferBoxで送る数を増やせば採れると考えて送り始めると、承認への返信が追いつかず、面談が埋まらず、承認した学生が他社に決まる、という形で崩れます。採る人数と「こんな人」が四半期ごとに変わるのに、検索条件と文面は年に一度しか見直されず、送っている相手が今の事業と合わなくなる、ということも起きます。**結論から言うと、急成長フェーズの会社は、採る人数と「こんな人」が四半期で変わる前提で、検索条件と文面を四半期で見直す形に組みます。送る数を増やす前に承認への当日返信の体制を作り、名義を複数にしてチームで回し、文面には「成長中」ではなく「最近変わったこと」を書き、入社後に変わることを正直に伝えます。** この記事では、急成長フェーズの会社が割ける時間と人、最初に決めること、文面の書き方、運用の分担、やりがちな失敗を整理します。チームで回す分担は[OfferBoxをチームで運用するときの役割分担](/media/ob-team-unyou/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 採る人数が急に増えた | 送る数を増やしたくなる。返信と面談が追いつかない |
| 人事が少なく、採用以外の業務も増えている | 承認への当日返信が落ちる。台帳の更新が止まる |
| 現場が忙しく、面談に出られない | 承認から面談までの日数が伸び、学生が他社に決まる |
| 組織と仕事の中身が四半期で変わる | 文面に書いた「最初の年」が、入社時に変わっている |
| 名義の社員が異動や昇進で変わる | 辞めていなくても、文面の名義の人が面談に出られない |
| 経営が「今すぐ人が要る」と言う | 送る時期が就職活動の終盤に寄り、承認しても学生の予定が埋まっている |

急成長フェーズの会社がOfferBoxに割ける時間は、人数が増えても増えません。人事の時間は他の業務に、現場の時間は事業に吸われます。増えるのは「採りたい人数」だけで、「返せる数」と「会える数」は変わらない、という前提で組みます。

## 最初に決めること

1. **採る人数と「こんな人」を、四半期ごとに見直す前提で書く**：年間の採用計画は置くが、四半期の頭に「今、どの職種に、どんな人か」を一行で更新する。[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
2. **承認への当日返信の体制を、送る数より先に作る**：誰が、毎日、どの順で通知を見て返すか。人事が持てないなら、一次の返信を外に出す。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
3. **送る数の上限を、「当日返せる数」と「面談に出られる数」で置く**：採りたい人数からではなく、返せる数と会える数から。上限を超えるなら、返信と面談の担当を増やす
4. **名義を複数にし、チームで回す**：一人の名義に集中すると、その人が異動や昇進で面談に出られなくなったときに止まる。職種ごとに名義を置く。[OfferBoxをチームで運用するときの役割分担](/media/ob-team-unyou/)
5. **文面の共通部分を一つの原稿で持ち、四半期で版を上げる**：「最初の年に何をするか」が変わったら、原稿を直して両方のテンプレートを同じ日に直す
6. **送る時期を、終盤に寄せない**：「今すぐ人が要る」に引きずられると、学生の予定が埋まっている時期に送ることになる。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)

### エージェントベストの見解

送り始めたあと、最初の送る時期で起きることに共通するのは、送る数を増やした分だけ承認が増え、返信が翌日以降にずれ、承認した学生の面談が埋まらず、他社に決まることです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、急成長フェーズの会社が採用計画を倍にした年の数字を見ていますが、送る数を倍にした会社で、承認から返信までの日数が保てた会社はほとんどなく、承認数は増えたのに面談数が増えていません。承認は、返信が当日に来て、数日以内に面談が入ることで、初めて面談に変わります。当社が急成長フェーズの会社に最初に決めてもらうのは、送る数ではなく、「承認の通知を、誰が、毎日、何時に見て返すか」で、この担当が人事に置けないなら、一次の返信を当社が持ち、面談の日程の判断だけを企業に残す形にしています。返信の体制ができてから、送る数を上限まで増やします。

## 文面の書き方｜「成長中」ではなく「最近変わったこと」

| 書かない | 書く |
|---|---|
| 「急成長中」「事業が拡大中」「若手が活躍」 | 最近の四半期で、何が変わったか。組織、仕事、任せる範囲 |
| 「大きな裁量」「早く昇進できる」 | 最初の年に何をするか。誰と組むか。半年後に変わる可能性があること |
| 事業の伸びの数値 | 数値は書かない。書くなら公表している事実だけを確認して |
| 「一緒に会社を大きくしましょう」 | 名義の社員が、最近、自分の仕事がどう変わったか。その場面 |
| 「安定」「整った環境」 | 整っていないところと、今どう整えているか |

- **名義の社員が「最近、自分の仕事がどう変わったか」を一場面書く**：急成長の実態は、仕事が変わり続けること。その場面が、変化に向く学生の記述と重なる
- **「入社後に変わることがある」を、隠さずに一文**：「配属や仕事の中身は、事業の状況で変わることがあります。変わるときは本人と話して決めます」
- **「こんな人」は、「変化の中で動いた行動」で**：「成長意欲がある」ではなく、「前提が変わったときに、自分で優先順位を決め直した経験」
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)。給与で勝負しない会社の伝え方は[給与水準を強みにできない会社のOfferBoxの伝え方](/media/ob-kyuuyo-hikui/)

## 四半期で見直すこと

| 四半期の頭に見直すもの | 見直さないもの |
|---|---|
| 採る人数と、職種ごとの「こんな人」の一行 | 会社の「なぜ」。年に一度 |
| 検索条件 | 承認後の連絡の型 |
| 文面の「最初の年」「誰と組むか」の共通部分 | 面談の入口と、選考の段 |
| 名義の社員（異動・昇進があれば） | 台帳の型 |
| 送る数の上限（返せる数と会える数が変わっていれば） | 「変わることがある」の一文 |

- **見直しの日を、四半期の頭に固定する**：忙しくて飛ばすと、半年前の文面で送り続ける
- **見直しは、人事と現場の責任者で一時間**：「今、どの職種に、どんな人か」「最初の年に何をするかは変わったか」「名義は出られるか」の三つ
- **見直したら、送信を一度止めて、テンプレートを直してから再開する**：直さずに送り続けない

## 運用の分担

| 作業 | 誰が |
|---|---|
| 採る人数と「こんな人」の四半期の見直し | 人事と現場の責任者 |
| 検索、文面の下書き、送信 | 人事、または代行 |
| 承認への当日の返信（一次） | 人事、または代行。担当を毎日置く |
| 面談の日程の判断、面談 | 名義の社員（職種ごとに複数） |
| 文面の共通原稿の版管理 | 人事 |
| 台帳を一つにし、承認した学生の段を追う | 人事（代行と）。[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/) |
| 送る数の上限の決定と、担当を増やす判断 | 責任者 |
| 週次で、承認から返信・面談までの日数を見る | 人事と責任者。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/) |

- **人事の時間が採用以外に吸われるなら、検索・下書き・送信・一次返信を外に出す**：人事は「こんな人」の見直し、台帳、面談の設定に絞る。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **現場が面談に出られないなら、送る数を減らす**：代わりに人事が面談に出ると、名義の人に会えず離れる。現場に頼む範囲は[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
- **時間が足りないときの対処**：[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)

運用代行や代理店が支えられるのは、上限の逆算の型、四半期の見直しの型、原稿の版管理の型、台帳の型、検索・下書き・送信・一次返信、週次の数字の整理までで、「こんな人」の決定、名義の社員の選定、面談、担当を増やす判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。急成長フェーズで自社が持つべきなのは、四半期ごとの「こんな人」の一行、名義の社員の選定、面談、送る数の上限と担当を増やす判断、までです。ここから先の、検索、文面の下書き、送信、承認への一次の返信、台帳の更新、週次の数字の整理は、外に出せます。当社が急成長フェーズの会社のOfferBoxの運用代行を受けるときは、人事の時間が採用以外に吸われる前提で、この線で分けています。この線を引かずに、「忙しいので全部任せたい」とすると、「こんな人」が四半期で変わったことが当社に伝わらず、半年前の学生像に送り続けます。逆に「大事なので全部自社で」とすると、人事の時間が返信と送信に消えて、「こんな人」の見直しと面談の設定が止まります。急成長フェーズで外に出すべきなのは作業で、残すべきなのは「今、誰を採るか」の判断です。この判断だけは、事業の中にいる人にしかできません。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 採りたい人数から送る数を決める | 返信と面談が追いつかず、承認した学生を失う | 返せる数と会える数から上限を置く |
| 検索条件と文面を年に一度しか見直さない | 半年前の学生像に送り続ける | 四半期の頭に一時間 |
| 名義を一人に集中させる | 異動・昇進で面談に出られなくなり止まる | 職種ごとに複数 |
| 「急成長中」「裁量」で書く | 承認は取れるが、面談で「最初の年に何をするか」に答えられない | 最近変わったことと最初の年を書く |
| 「今すぐ人が要る」で終盤に送る | 学生の予定が埋まっている | 時期を前に置き、四半期で補う |

最も多いのは、一つ目です。採用計画の人数が倍になった年に、送る数だけを倍にします。

## まとめ

- 急成長フェーズでは、採りたい人数は増えても、返せる数と会える数は増えない。送る数の上限は「当日返せる数」と「面談に出られる数」で置く
- 送る数を増やす前に、承認への当日返信の体制（誰が、毎日、何時に見て返すか）を作る。人事に置けないなら一次の返信を外に
- 採る人数と「こんな人」と検索条件と文面の共通部分を、四半期の頭に一時間で見直し、送信を一度止めて直してから再開する
- 名義を職種ごとに複数にしてチームで回す。文面には「成長中」ではなく「最近変わったこと」と「最初の年」を書き、「変わることがある」を隠さない
- 外に出すのは作業（検索・下書き・送信・一次返信・台帳）、残すのは判断（「今、誰を採るか」・名義・面談・上限）

## よくある質問

### 経営から「来月までに何人」と言われています。送る数を増やすしかありませんか

送る数を増やしても、返信と面談が追いつかなければ、承認した学生を失うだけです。先に、承認への当日返信の担当を毎日置き、面談に出られる社員を職種ごとに増やします。それでも足りないなら、送る数ではなく、返信と面談の担当を外に出すか増やすかを経営に相談します。人数の目標は、返せる数と会える数の上限で決まります。

### 組織が変わって、文面に書いた「最初の年」が変わりました。送ってしまった学生にはどう伝えますか

承認した学生には、面談で「送ったときから変わった点」をそのまま伝えます。隠すと、入社後に「聞いていた話と違う」になります。送信中のテンプレートは一度止めて直し、直してから再開します。四半期の頭に見直す日を固定しておくと、この「送ってしまってから変わる」が減ります。

### 急成長フェーズのOfferBox運用は、御社に相談できますか

できます。当社は、上限の逆算の型、四半期の見直しの型、原稿の版管理の型、台帳の型、検索・下書き・送信・一次返信、週次の数字の整理を支えられます。「こんな人」の決定、名義の社員の選定、面談、担当を増やす判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
