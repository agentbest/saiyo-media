募集記事は、出して終わりではなく、反応を見て直すものです。ところが、「反応が悪いので全部書き直した」「閲覧は多いのに来ないので、タイトルを煽った」という直し方では、何が効いたか分からず、次に活きません。**結論から言うと、募集記事の反応は「一覧で開かれているか」「開いて話を聞きに行くか」「来た人が合っているか」「面談後に進むか」の4段で切り分け、止まっている段に対応する箇所を、月に一度、1か所だけ直します。材料は閲覧や応募の数ではなく、面談で聞く候補者の言葉で、直した理由を台帳に残します。** この記事では、反応の見方、やりがちな失敗、止まっている場所ごとの直す箇所、月に一度1か所の理由、面談の言葉を材料にすること、記録の残し方、閉じる・分ける判断、分担を整理します。募集記事の差し替えで比べる方法は[募集記事を差し替えて比べる方法](/media/wt-boshu-abtest/)で書きました。この記事は、その前段の「どこを直すか」を決める話です。

## この作業の目的｜「どこで止まっているか」を見てから直す

募集記事の反応が悪いとき、原因は1つではありません。一覧で開かれていない、開かれたが話を聞きに行かない、話を聞きに来たが合わない、面談後に進まない。それぞれ、直す箇所が違います。

切り分けずに直すと、開かれていないのに本文を直したり、来た人が合わないのにタイトルを直したりします。目的は、「止まっている段を見て、その段に対応する箇所だけを直す」ことです。

## 反応の4段

| 段 | 何を見るか | 見える形 |
|---|---|---|
| 1. 一覧で開かれているか | 募集記事が一覧で開かれているか | 管理画面で見える閲覧の動き。ただし数字の大小より、変化 |
| 2. 開いて話を聞きに行くか | 開いた人が「話を聞きに行く」を押すか | 開かれているのに来ないなら、本文で止まっている |
| 3. 来た人が合っているか | 話を聞きに来た人が、募集の意図と合っているか | 面談で「なぜ来たか」を聞く |
| 4. 面談後に進むか | 面談のあと、選考に進むか、辞退か | 辞退の理由に「記事と違った」があるか |

1と2は管理画面で見え、3と4は面談で聞かないと分かりません。3と4を見ずに1と2だけで直すと、来る人は増えても合わない人が増えます。

## やりがちな失敗

| 失敗 | 何が起きるか |
|---|---|
| 閲覧や応募の数だけで判断する | 煽りに寄る。来ても合わない |
| 反応が悪いので全部書き直す | 何が効いたか分からない |
| 一度に複数の箇所を直す | 同じく、何が効いたか分からない |
| 直した理由を残さない | 担当が変わると、なぜこの形かが分からない |
| 面談で「なぜ来たか」を聞かない | 3と4が見えない |
| 反応が無いのに、そのまま放置する | 古い記事が一覧に残り続ける |
| 反応が良い記事を、良いままにせず直す | 効いていたものを壊す |

最も多いのは、最初の「数だけで判断する」です。閲覧が少ないからタイトルを煽り、閲覧は増えたが来ない、という流れです。

### エージェントベストの見解

媒体を比べたり運用を見直したりするときに、募集記事の良し悪しを「応募の数」で判断しようとする会社は多いのですが、応募の数は「開かれて、押された」までで、「合う人が来て、進んだ」ではありません。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、応募が多い募集記事が、面談後に誰も進まないことがあります。理由は、タイトルと本文が「誰でも来られる」形になっていて、来る人が絞られていないからです。逆に、応募は少ないが面談後にほとんど進む募集記事もあります。当社が募集記事の見直しを支えるときは、応募の数ではなく、「面談で候補者が『記事のどこを読んで来たか』と答えた内容」と「面談後に進んだか」を並べて見ます。この2つが、募集記事の本当の反応です。数は、その次です。

## 止まっている場所ごとの、直す箇所

| 止まっている段 | 直す箇所 | 直し方 |
|---|---|---|
| 1. 一覧で開かれていない | タイトル、カバー写真 | 「誰に、何を」が一言で分かるタイトルに。付け方は[募集タイトルの付け方](/media/wt-boshu-title/)。写真は仕事の場面に。[カバー写真の選び方](/media/wt-boshu-shashin/) |
| 2. 開いたが来ない | なにを、なぜ、どうやって | 最初の段落で仕事が分かるか。抽象語が残っていないか。[「なにを」の書き方](/media/wt-boshu-nani-wo/) |
| 3. 来たが合わない | こんな人、条件 | 誰に来てほしいかが書けているか。合わない人が分かる書き方か。[「こんな人」の書き方](/media/wt-boshu-konna/) |
| 4. 面談後に進まない | 面談との整合、条件、一緒に働く人 | 記事と面談がずれていないか。条件が記事に書いてあるか。[条件の書き方](/media/wt-boshu-joukenn/) |

4の「面談後に進まない」は、募集記事の問題ではなく、面談の問題であることもあります。記事に書いたことと面談で言うことが違う、記事に書いていない条件が面談で出る。この場合、直すのは記事より面談です。

## 月に一度、1か所だけ直す

直すときの原則は、「月に一度、1か所」です。

- **1か所だけ**：タイトルだけ、こんな人だけ。複数を同時に直すと、何が効いたか分からない
- **月に一度**：反応が見えるまでに時間がかかる。週ごとに直すと、反応が出る前に次を直すことになる
- **直す前の状態を残す**：戻せるように
- **反応が良い記事は直さない**：直すのは、止まっている記事だけ
- **直す箇所は、止まっている段から決める**：上の表で

「1か所だけ」は、遅く見えますが、何が効いたかが分かるので、次の記事にも活きます。全部直すと、その記事は良くなっても、なぜ良くなったかが分からず、次の記事で同じことを繰り返します。

## 面談で聞く言葉を、材料にする

直す材料は、管理画面の数字より、面談で聞く候補者の言葉です。

- **「募集記事のどこを読んで来ましたか」**：挙がる部分が、効いている部分。挙がらない部分は、読まれていないか、効いていない
- **「読んで、分からなかったことはありますか」**：分からなかった部分が、直す箇所
- **「記事と違ったと感じたことはありますか」**：4段目の材料
- **辞退の理由を聞ける範囲で聞く**：「記事と違った」があれば、記事か面談を直す

面談に出る人に、この3つの質問を型として渡しておきます。聞いたことは、人事に戻します。ストーリーの反応を面談で聞く考え方は[ストーリーでやりがちな失敗](/media/wt-story-ng/)で書いたのと同じです。

## 直した記録を、台帳に残す

直したら、記録します。

| 残すこと | 例（型） |
|---|---|
| いつ | 月 |
| どの記事の、どの箇所 | 〇〇職の募集、タイトル |
| 何から何へ | 「〇〇職募集」→「未経験から〇〇を始めたい人へ」 |
| なぜ | 面談で「何の仕事か分からなかった」と言われた |
| その後どうなったか | 翌月に、面談で「タイトルで自分向けだと分かった」と言われた |

記録があると、担当が変わっても「なぜこの形か」が分かり、同じ失敗を繰り返しません。記事の台帳と一緒に置きます。台帳の考え方は[コンテンツを資産として貯める考え方](/media/wt-naiyou-shisan/)で書きました。

## 閉じる・分ける判断

直しても反応が無い記事は、閉じるか、分けるかを判断します。

- **閉じる**：募集が終わった、その職種を採らなくなった。閉じた記事は台帳に残す
- **分ける**：1本に複数の職種や読み手が入っている。新卒と中途、経験者と未経験、を分ける。分け方は[募集記事を複数出す考え方](/media/wt-boshu-fukusu/)
- **作り直す**：職種の中身が変わった。直すより、新しく書く
- **そのまま**：反応は少ないが、来た人が合っていて進んでいる。数が少ないだけなら、直さない

「そのまま」の判断があることを、忘れないようにします。反応が少ない記事が悪いとは限りません。

| 作業 | 誰が |
|---|---|
| 4段のどこで止まっているかを見る | 人事 |
| 面談で3つの質問を聞く | 面談に出る人 |
| 聞いた言葉を人事に戻す | 面談に出る人 |

運用代行や代理店が支えられるのは、4段の切り分けの型、直す箇所の案、面談で聞く質問の型、台帳の型、閉じる・分ける判断の材料までで、面談で聞くこと、聞いた言葉を戻すこと、直すかどうかの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの募集記事の見直しを支えるとき、4段の切り分け、直す箇所の案、台帳の型は当社が出せます。ただし、「面談で候補者に3つの質問を聞き、その言葉を人事に戻す」ことだけは、企業にしかできません。この言葉が無いと、当社も企業も、管理画面の数字だけで判断することになり、煽りに寄ります。当社が見直しの支援で最初にお願いするのは、面談に出る人に3つの質問を型として渡し、聞いたことを一行で人事に送ってもらうことです。一行が月に数件あれば、当社は直す箇所を絞れます。無ければ、当社の案は推測になります。募集記事の見直しは、書く技術より、聞く一言から始まります。

## まとめ

- 募集記事の反応は「開かれているか」「開いて来るか」「来た人が合っているか」「面談後に進むか」の4段で切り分ける
- 数だけで判断する、全部書き直す、複数を同時に直す、理由を残さない、が次に活きない直し方
- 止まっている段に対応する箇所（タイトルと写真／なにを・なぜ／こんな人・条件／面談との整合）だけを直す
- 月に一度、1か所だけ。反応が良い記事は直さない
- 面談で3つの質問を聞き、直した記録を台帳に残し、閉じる・分ける・作り直す・そのままを判断する

## よくある質問

### 閲覧の数は、見なくてよいのですか

見ますが、大小ではなく変化を見ます。タイトルを直した翌月に開かれる数が変わったか、のように、1か所直したあとの変化として使います。数の大小だけで「良い」「悪い」と判断すると、煽りに寄ります。

### 反応が無い記事を、すぐ直したくなります

出してから反応が見えるまでに時間がかかります。出した月に直すと、反応が出る前に次を直すことになります。月に一度と決め、それまでは面談で聞く言葉を集めます。

### 募集記事の見直しは、御社に相談できますか

できます。当社は、4段の切り分けの型、直す箇所の案、面談で聞く質問の型、台帳の型、閉じる・分ける判断の材料を支えられます。面談で聞くことと、直すかどうかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
