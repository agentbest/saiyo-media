百貨店、GMS、専門店チェーン、ドラッグストア、EC・D2C、地域の小売、運営会社の本部が、Wantedlyで採用する。小売は、候補者が「客として知っている」業界で、ブランド名と店舗名を会社ページに置けば、「あの店だ」と読まれる。ただ、客として知っていることと、働く場として知っていることは別で、店舗の一日（開店準備、品出し、レジ、棚卸し、閉店）、異動、数字（売上、在庫、人時）、本部への道は知られていない。ブランド名で会社ページを埋めると、候補者は客の像で「話を聞きに行きたい」を押し、面談で店舗の実態を聞いて離れる。**結論から言うと、小売のWantedlyは、向く職種に絞ります。本部（バイヤー、MD、EC、マーケ、店舗開発、データ、物流）と、EC・D2Cのスタートアップ。店舗職は、Wantedlyに置くなら「好きなブランド」ではなく店舗の一日と異動と数字を先に書き、主な入口は別に持ちます。ブランド名は一度だけ置き、「なにを」を客層と商品と売り方で、「働く場としての実態」を店舗の一日と本部への道の実例で書きます。「好きなブランドで働きたい」で入った人が、最初の異動と棚卸しで離れる形を防ぎます。** この記事では、小売の採用構造とWantedlyとの相性、向く職種と店舗職の切り分け、ブランド名で埋めない見せ方、店舗の一日と本部への道の書き方、ストーリーとカジュアル面談とスカウトの運用設計、店舗と本部の分担を整理します。媒体の選び方は[小売業界の採用媒体の選び方](/media/hikaku-kouri-erabikata/)、知名度の扱いは[Wantedlyで知名度をどう扱うか](/media/wt-chimeido/)で書きました。数値と料金は書きません。

## 小売の採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| 百貨店・GMS | 店舗から始まり、本部へ。異動と転勤あり | 本部の職種で。店舗職は異動と一日を先に。ブランド名で埋めない |
| 専門店チェーン | 店舗から店長、エリア、本部へ。ブランドで知られる | 「好きなブランド」で集めない。店舗の一日と本部への道を実例で |
| ドラッグストア | 店舗と登録販売者・薬剤師。出店が多く異動が多い | 異動と勤務地の決まり方を先に。資格の入口を分けて |
| EC・D2C | エンジニア、マーケ、CS、物流、MD。スタートアップも多い | 向く。並ぶ場の中で、客層と商品と売り方と「何を決められるか」で |
| 地域の小売 | 地元の店舗。少人数 | 地域と客層で。「小売」の像ではなく店と人で |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| 客として知られている | ブランド名で埋め、客の像で読まれる | 一度だけ置き、働く場の実態で |
| 店舗の一日と異動と数字は知られていない | 面談で聞かれて離れる | 先に書く |
| 店舗職と本部職で採用の形が違う | 一つの募集に混ざる | 向く職種に絞り、店舗職は別の入口 |
| 本部への道が見えない | 「ずっと店舗か」で離れる | 実例で書く |

## 向く職種に絞る｜本部とEC・D2C、店舗職は別の入口で

- **Wantedlyの募集を、本部の職種から**：バイヤー、MD、EC、マーケ、店舗開発、データ、物流、人事。「何を決められるか」で押される職種
- **店舗職（販売、店長候補）は、主な入口を別に**：Wantedlyに置くなら、店舗の一日と異動と数字を最初に。「好きなブランドで働ける」で集めない
- **EC・D2Cは、客層と商品と売り方で**：「〇〇の客層に△△を、□□の売り方で」。「ライフスタイルを提案」で済ませない
- **ドラッグストアの登録販売者・薬剤師は、資格の入口を分けて**：配置と勤務地と異動を先に
- **副業・パートの入口を、社員と分けて**：「何曜日の、何時から何時まで」を最初に。[Wantedlyで副業の募集を書くときの設計](/media/wt-fukugyo-boshu/)
- **「こんな人」は、「数字を持って改善した・在庫や発注を見た・シフトのある現場を続けた」の記述で**：「〇〇が好き」「接客が好き」で絞らない

### エージェントベストの見解

これは媒体の向き不向きの話です。専門店チェーンやGMSから、「ブランドは知られているので、Wantedlyで店舗のスタッフを採りたい」と相談されることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、小売でWantedlyが向くのは、本部の職種（バイヤー、MD、EC、マーケ、店舗開発、データ）と、EC・D2Cのスタートアップで、「この会社で何を決められるか」で押される職種です。店舗職は「好きなブランド」の像で押されやすく、面談で店舗の実態を聞いて離れます。当社がお願いしているのは、Wantedlyの募集を本部とEC・D2Cに絞り、店舗職は主な入口を別に持ち、Wantedlyに置くなら店舗の一日と異動と数字を最初に書くことです。絞ると、会社ページがブランド名ではなく本部の仕事で読まれ、面談の時間が「何を決められるか」で来た候補者に使えます。

## ブランド名で埋めない｜働く場としての実態を書く

- **ブランド名と店舗名は、一度だけ**：「なにを」に事実として。会社ページの全部をブランドの世界観で埋めない
- **「なにを」は、客層と商品と売り方で一言**：「〇〇の客層に、△△の商品を、□□の店舗とECで売っている会社」
- **店舗の一日を、先週の一日で**：「開店前は〇〇。日中は△△。棚卸しと閉店は□□」。[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)
- **異動と転勤の決まり方を、隠さず**：「異動は〇〇の範囲で、△△の周期。転勤は□□」。[Wantedlyの募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)
- **数字の責任を、誰が持つかを書く**：「売上と在庫と人時は店長が持つ。△△は本部で持つ」
- **本部への道を、実例で**：「店長から〇〇年でバイヤーに移った人がいる。△△の道は決まっていない」。「本部への道もあります」の一語で済ませない
- **本部の募集は、「何を決められるか」と店舗との距離で**：「〇〇はバイヤーが決める。△△は店舗と決める。□□は役員の決裁」
- **「なぜ」は、創業者や責任者の「なぜこの客層に、この商品を」を体験で**：[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)

会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)、素顔を出す範囲は[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)で書きました。

## ストーリーとカジュアル面談の設計

- **店舗から本部に移った人のストーリーで、「どう移ったか」と「店舗で見ていたことが本部でどう活きたか」を本人の言葉で**：[Wantedlyの入社後ストーリーの書き方](/media/wt-story-nyusha/)
- **バイヤーやMDのストーリーで、「売れなかった商品の週」を本人の言葉で**：[Wantedlyのストーリーで事業の中身を書く方法](/media/wt-story-jigyo/)
- **カジュアル面談で、店舗の一日と異動と数字と本部への道を、聞かれる前に伝える**：[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **面談の前か後に、店舗を繁忙の時間帯に見てもらう枠を**：客として見た店と、働く場として見る店は違う
- **面談を、繁忙期（セール、年末年始、棚卸し）の外に置く**

## スカウトの設計

- **絞るのは、「数字を持って改善した・在庫や発注を見た・シフトのある現場を続けた」の記述**：「〇〇が好き」「ブランドのファン」で絞らない。[Wantedlyのスカウトで対象を絞る方法](/media/wt-scout-target/)
- **文面は、客層と商品と売り方と「何を決められるか」を最初に**：「〇〇の客層に△△を売っていて、□□はバイヤーが決められる会社で、あなたの〇〇を読んで」。ブランド名で始めない。[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)
- **店舗職のスカウトは、本部と分けて、一日と異動を最初に**
- **送る時期を、繁忙期の外に**：[Wantedlyのスカウトを送る時期の考え方](/media/wt-scout-timing/)

## 店舗と本部の分担

| 作業 | 誰が |
|---|---|
| Wantedlyの募集を本部とEC・D2Cに絞り、店舗職の入口を別に持つ | 本部と人事 |
| ブランド名を一度にし、客層と商品と売り方で「なにを」を書く | 本部と人事 |
| 店舗の一日と異動と数字の責任を、何を書くか決める | 店舗の責任者と人事 |
| 本部への道を、実例で書けるか確かめる | 人事 |
| 創業者や責任者が「なぜこの客層に」を話し、記事に整える | 創業者・責任者（整えるのは人事か外に出せる） |
| 本部に移った人が「移り方」を、バイヤーが「売れなかった週」を話す | 本部 |
| カジュアル面談に本部の人が出て、店舗を見せる枠を持つ | 本部と人事 |
| スカウトを客層と商品と決められることを最初に、記述で絞って送る | 人事（絞る作業は外に出せる） |

運用代行や代理店が支えられるのは、向く職種の整理、募集記事の型、聞き方の型、面談の型、時期の設計、スカウトの絞る作業までで、異動と数字の開示、本部への道の実例、創業者と本部が話すこと、面談、店舗を見せることは会社が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは契約後に起きることの話です。小売の会社が、ブランドの世界観で募集記事を書いて採り、入った人が最初の異動か、最初の棚卸しか、数字の締めで離れる形を、当社は繰り返し見ています。「好きなブランドで働きたい」で来た人は、客として見ていた店を期待していて、実態が「品出しと棚卸しと在庫の数字があり、店舗を移り、本部への道が見えない」であることを、入ってから知ります。当社がお願いするのは、募集記事と面談で「店舗の一日は〇〇。異動は△△の範囲と周期。数字は□□が持つ。本部への道は〇〇の実例がある」と先に伝え、本部に移った人が「どう移ったか」を、「好きなブランド」で入った人が「像と、入った後」をストーリーで本人の言葉で書き、面談の前か後に繁忙の時間帯の店舗を見てもらうことです。働く場としての実態を知って来た人は、最初の異動と棚卸しを越えます。ブランドの世界観で集めた人は、客のまま離れます。

## まとめ

- 候補者は「客として知っている」が「働く場として知っている」わけではない。ブランド名は一度だけ置き、「なにを」を客層と商品と売り方で、働く場の実態を店舗の一日と異動と数字と本部への道で書く
- Wantedlyは本部（バイヤー、MD、EC、マーケ、店舗開発、データ、物流）とEC・D2Cのスタートアップに絞る。店舗職は主な入口を別に持ち、置くなら店舗の一日と異動と数字を最初に。資格の入口と副業・パートの入口を分ける
- 本部への道を「本部への道もあります」で済ませず、実例で。決まっていないなら「決まっていない」と書く。本部の募集は「何を決められるか」と店舗との距離で
- 本部に移った人が「移り方」を、バイヤーが「売れなかった週」を、「好きなブランド」で入った人が「それでも残った理由」を本人の言葉で。面談で実態を先に伝え、繁忙の時間帯の店舗を見てもらう
- スカウトは「ブランドのファン」ではなく「数字を持って改善した・在庫や発注を見た」の記述で絞り、客層と商品と決められることを最初に。繁忙期に送らない

## よくある質問

### ブランドが知られているのに、欲しい人が来ません

知られているのは客としてで、働く場としてではありません。ブランド名で会社ページを埋めると、客の像で押され、店舗の実態で離れます。ブランド名は一度だけ置き、店舗の一日と異動と数字と本部への道を実例で書いてください。Wantedlyの主な募集は本部とEC・D2Cに絞る方が動きます。

### 「ブランドが好き」を条件にしてはいけませんか

「なぜ」に一度、創業者や責任者の体験で書いてください。ただ、「こんな人」を「ブランドが好き」で書くと、客のまま来て、最初の異動と棚卸しで離れます。「数字を持って改善した・在庫や発注を見た・シフトのある現場を続けた」の記述で絞ってください。好きであることは面談で分かります。

### 小売のWantedlyの設計は、御社に相談できますか

できます。当社は、向く職種の整理、募集記事の型、聞き方の型、面談の型、時期の設計、スカウトの絞る作業を支えられます。異動と数字の開示、本部への道の実例、創業者と本部が話すこと、面談、店舗を見せることは、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
