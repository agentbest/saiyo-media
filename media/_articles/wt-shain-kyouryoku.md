Wantedlyの記事は、社員の話が無いと書けません。ところが、「記事に出てほしい」「インタビューを受けてほしい」と頼むと、忙しい、書くのは苦手、何を話せばいいか分からない、で断られます。**結論から言うと、社員の協力は「書いて」ではなく「話して」と頼み、1つの場面だけを、短く、業務時間内で聞き、書いたものを本人に確認してもらい、公開後に反応を戻す、という形で得られます。協力が得られない理由のほとんどは、頼み方が重いこと、業務外になっていること、何のためか分からないこと、反応が戻らないことの4つです。** この記事では、協力が得られない理由、頼む形、最初に頼む相手、上司の合意、断られたときの扱い、反応を戻すこと、協力が広がる順番、分担を整理します。書き手を増やす話は[書き手を社内で増やす方法](/media/wt-story-kakite/)で書きました。この記事は、その前段の「話してもらう」ところの話です。

## この作業の目的｜社員の負担を小さくして、話が出る状態を作る

記事づくりに必要なのは、社員が「書く」ことではなく、「話す」ことです。書くのは人事か外部で、社員は話すだけ。この分担が伝わっていないと、社員は「記事を書かされる」と受け取り、断ります。

目的は、「社員が、短い時間で、1つの場面を話すだけで、記事ができる」状態を作ることです。負担が小さければ、協力は得られ、続きます。

## 協力が得られない理由

| 理由 | 社員の側から見ると |
|---|---|
| 「記事を書いて」と頼まれる | 書くのは苦手。時間がかかる |
| 「インタビューを受けて」と頼まれる | 何を話せばいいか分からない。大ごとに聞こえる |
| 業務外にやることになっている | 自分の時間を削る理由が無い |
| 何のためかが分からない | 「会社の宣伝に使われる」と感じる |
| 上司が知らない | 上司に「そんな時間があるなら」と言われる |
| 前に協力したが、何も戻ってこなかった | 「話した意味が無かった」 |
| 書かれたものが、自分の言葉と違った | 「勝手に変えられる」 |
| 自分だけが頼まれ続ける | 負担が偏る |

最も多いのは、最初の「書いて」と頼むことです。「話して」に変えるだけで、断られる数が変わります。

## 頼む形｜話して、1つの場面、短く、業務時間内

1. **「書いて」ではなく「話して」**：「先月の〇〇の話を、聞かせてもらえますか。書くのはこちらでやります」
2. **1つの場面だけ**：「会社の良さを語って」ではなく、「先月の会議で意見が割れたときの話を」。場面を指定すると、話す側は何を話せばいいか分かる
3. **短く**：1つの場面なら、短い時間で足りる。「長くて〇分くらい」と先に伝える
4. **業務時間内で**：上司の合意を取ったうえで、業務として。昼休みや終業後には頼まない
5. **書いたものは本人が確認する、と伝える**：「勝手に出しません。全文を見せて、直してもらいます」
6. **断ってよい、と伝える**：「無理なら大丈夫です」。断れる頼み方のほうが、次に頼める

「1つの場面だけ」が要点です。聞き方は[社員インタビューを書く手順](/media/wt-story-interview/)で書きました。話す側にとって、「自分の仕事の話を1つする」のは負担ではなく、「会社の良さを語る」のは負担です。

### エージェントベストの見解

相談で最も多い思い込みは、「社員が協力してくれないのは、うちの会社の社員の意識が低いからだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、協力が得られない会社と得られる会社の違いは、社員の意識ではなく、頼み方です。同じ会社で、「記事に出てください」と頼んで断られた人に、「先月の〇〇の件、聞かせてもらえますか。書くのはこちらで、全文見せます」と頼み直すと、話してもらえることがほとんどです。社員は協力したくないのではなく、「書く」「インタビュー」「会社の宣伝」という言葉に負担を感じています。当社が社員の協力の相談を受けるとき、最初にやるのは、頼む文面を「話して・1つの場面・短く・業務時間内・全文見せる・断ってよい」の形に書き直すことです。意識を変える前に、頼み方を変えます。

## 最初に頼む相手の選び方

最初の数人は、断られにくい人に頼みます。

- **記事の題材に直接関わった人**：「あの案件の話」なら、関わった本人。関係の無い人には頼まない
- **普段から仕事の話をよくする人**：話すことに負担を感じない人
- **入社してまもない人**：入る前と後の話は、本人にとって新鮮で話しやすい。書き方は[入社エントリーを書いてもらう方法](/media/wt-story-nyusha/)
- **人事と普段からやり取りがある人**：頼みやすく、断りやすい関係
- **「今週あったこと」の1行を出してくれた人**：1行を出した時点で、話す用意がある。仕組みは[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)

「全社に募集する」「部署ごとに1人出してもらう」は、最初にはやりません。頼まれた側が「なぜ自分か」を分からず、負担に感じます。

## 上司の合意を先に取る

社員に頼む前に、その社員の上司に合意を取ります。

- **「〇〇さんに、△△の話を短く聞きたい。業務時間内で、〇分ほど」と伝える**
- **何のためかを伝える**：募集記事を補うため、会社ページに場面を足すため
- **上司自身の話も、いつか聞かせてほしいと伝える**：上司を「許可する人」から「協力する人」に
- **上司が断ったら、無理に進めない**：別の人、別の時期に

上司の合意が無いと、社員は「上司に何と言われるか」で協力しにくくなります。合意があれば、社員は業務として話せます。

## 断られたときの扱い

断られることはあります。扱いを決めておきます。

- **理由を聞かない**：「分かりました。また別の機会に」で終える
- **別の人に頼む**：同じ題材に関わった別の人
- **時期を変える**：忙しい時期の人には、落ち着いてから
- **頼み方を見直す**：複数の人に断られるなら、文面が重い
- **断った人に、次も頼んでよい**：一度断った人が、次は話すことは普通にある

「断られたら終わり」にしないことが、続ける条件です。断られることを前提に、複数の人に頼める状態を作ります。

## 反応を戻して、次につなげる

協力が続くかどうかは、話したあとに何が戻るかで決まります。

1. **書いたものを、公開前に全文見せる**：直してもらう。本人の言葉を残す
2. **公開したら、本人に知らせる**：「出ました。ありがとうございました」
3. **読まれたら、伝える**：「面談で、〇〇さんの記事を読んで来た人がいました」。何も無くても「読まれていました」
4. **候補者の言葉を戻す**：「記事のこの場面に惹かれた、と言っていました」
5. **上司にも戻す**：「〇〇さんの話が記事になり、候補者に読まれています」

「反応を戻す」が無いと、協力は一度で終わります。あると、本人が次も話し、周りの人が「自分も」と言い始めます。応援の頼み方と同じ考え方で、詳しくは[応援機能を社内で使う方法](/media/wt-ouen/)で書きました。

## 協力が広がる順番

無理に全社を巻き込まず、次の順で広げます。

1. **数人が話す**：断られにくい人から
2. **その記事が読まれ、反応が戻る**：本人と上司に
3. **周りの人が「自分も」と言う**：頼まなくても出てくる
4. **各チームに「拾う人」が決まる**：1行を出す人
5. **話す人が増え、書く人（直す人）も出てくる**：[書き手を社内で増やす方法](/media/wt-story-kakite/)

最初から「全社の協力体制」を作ろうとすると、誰も動きません。数人から始め、反応が戻ることで広がります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 頼む文面を作る | 人事 |
| 最初に頼む相手を選ぶ | 人事 |
| 上司の合意を取る | 人事 |
| 話す | 社員（業務時間内、1つの場面、短く） |
| 書く | 人事（または外部） |
| 全文を見せて確認してもらう | 人事が本人に |
| 反応を戻す | 人事が本人と上司に |

運用代行や代理店が支えられるのは、頼む文面の型、最初に頼む相手の選び方の整理、聞き方の型、書くこと、反応を戻す型までで、頼むこと、上司の合意、話すこと、反応を聞くことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

申し込んだあと、社員の協力で半年後に起きやすいのは、「最初に協力してくれた数人にばかり頼み、その人たちが疲れる」ことです。話しやすい人に頼み続けると、負担が偏り、「また自分か」となって断られ始めます。当社がWantedlyの運用でストーリーの出た人の一覧を見ると、同じ数人が繰り返し出ている会社があります。当社が勧めるのは、記事の台帳に「出た人」を記録し、同じ人が続いたら別の人に頼むことと、各チームに「拾う人」を置いて、話す人が拾う人から出てくる形にすることです。話す人が広がらないのは、社員の意識ではなく、頼む先が固定されているからです。台帳で偏りを見て、頼む先を回す。それだけで、協力は続きます。

## まとめ

- 社員の協力は「書いて」ではなく「話して」。1つの場面だけ、短く、業務時間内、全文見せる、断ってよい
- 協力が得られない理由は、頼み方が重い、業務外、何のためか分からない、反応が戻らない、の4つ
- 最初は、題材に直接関わった人、話すことに負担が無い人、入社してまもない人、1行を出した人に頼む
- 上司の合意を先に取り、断られたら理由を聞かず別の人か別の時期に
- 全文を見せ、公開を知らせ、読まれたことと候補者の言葉を本人と上司に戻す。数人から始めて広げ、頼む先を回す

## よくある質問

### 社員が「話すことが無い」と言います

「会社の良さ」を聞くと、話すことが無くなります。「先月、何がありましたか」「最近、詰まったことは」と、最近の1つの出来事を聞きます。誰でも、先月の出来事は話せます。話すことが無いのではなく、聞き方が広すぎます。

### 上司が「業務時間を使わせたくない」と言います

記事は募集のための業務で、話す時間は短い（1つの場面なら〇分ほど）と伝えます。上司自身の話も聞きたい、と頼むと、上司が「許可する人」から「協力する人」になります。それでも断られたら、別のチームから始め、反応が戻ってから改めて頼みます。

### 社員の協力を得る仕組みづくりは、御社に相談できますか

できます。当社は、頼む文面の型、最初に頼む相手の選び方、聞き方の型、書くこと、反応を戻す型を支えられます。頼むこと、上司の合意、話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
