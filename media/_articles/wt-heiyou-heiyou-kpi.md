Wantedlyと、OfferBoxやワンキャリアやナビサイトを併用している。上司から「どの媒体が効いているのか、並べて見せてほしい」と言われる。ところが、管理画面に出る数字は媒体ごとに違い、Wantedlyの閲覧数と、スカウト型の開封数と、ナビのエントリー数を同じ表に置いても、何も判断できません。**結論から言うと、入口の数は媒体ごとに前提が違うので並べません。並べるのは、面談から先の共通の段（面談・選考・内定）と、「こんな人」に近い人が各段に何人いるか、各段までの日数です。台帳を一つにして、媒体は列の一つとして持ち、Wantedlyには「記事の資産」と「来た人の言葉」を足して見ます。** この記事では、媒体ごとに数が出る段の違い、共通の段で並べる考え方、台帳の項目、予算と工数の見方、Wantedlyだけに足す項目、やりがちな失敗、社内の分担を整理します。媒体全般の並べ方は[媒体の効果を並べて比べる方法](/media/hikaku-baitai-kouka-hikaku/)、Wantedly単体のKPIは[Wantedlyの効果が測れないときのKPIの置き直し](/media/wt-kouka-sokutei/)で書きました。数値は書きません。

## それぞれの役割｜媒体ごとに「数が出る段」が違う

| 媒体の型 | 入口で出る数 | 数の前提 | 共通の段 |
|---|---|---|---|
| Wantedly | 閲覧、応援、「話を聞きに行きたい」 | 会社を読んでから来る。時期を問わない。記事が残る | 面談・選考・内定 |
| スカウト型（OfferBoxなど） | 送信、開封、承認 | 企業側から選んで送る。送った相手の中から来る | 面談・選考・内定 |
| ワンキャリア | 掲載・イベントからのエントリー | 学生がクチコミと情報を見て、自分で来る | 面談・選考・内定 |
| ナビサイト | エントリー、説明会予約 | 決まった時期に、条件で探して来る | 面談・選考・内定 |

入口の数は、それぞれの媒体の中でしか意味を持ちません。Wantedlyの「話を聞きに行きたい」は、会社を読んだうえでの一歩で、ナビの「エントリー」は、条件で並べたうえでの一歩です。同じ「応募」の列に置くと、Wantedlyが少なく見え、ナビが多く見えますが、それは媒体の性能ではなく、数の前提の違いです。

## 並べて見るときの分担｜入口の段は媒体ごとに、面談から先は共通の段で

- **入口の段は、媒体ごとに、その媒体の先月と比べる**：Wantedlyの閲覧数はWantedlyの先月と。他の媒体とは並べない
- **面談から先は、共通の段で並べる**：面談した数、選考に進んだ数、内定を出した数。ここは媒体を問わず同じ意味の数
- **「こんな人」に近い人の数を、段ごとに媒体別で持つ**：「面談した人のうち、近い人は何人」を媒体ごとに。これが並べて見る中心
- **日数を並べる**：入口から面談までの日数、面談から選考までの日数。媒体によって、待たせている段が違う
- **「一人あたりの費用」で並べるのは、一年の台帳が揃ってから**：途中の月で並べると、時期の偏りで結論が逆になる

「こんな人」に近い人の数で見る考え方は[母集団形成のKPI](/media/kh-boshudan-kpi/)で書きました。並べて見る目的は、媒体の優劣をつけることではなく、「近い人が来ている入口はどれか」「どの入口で、どの段が止まっているか」を見つけることです。

### エージェントベストの見解

媒体の管理画面に出る入口の数は、それぞれ「どんな学生が、どの状態で数えられているか」という前提が違う数字なので、そのまま並べても媒体の優劣にはなりません。当社は3媒体すべての販売パートナーとして、「WantedlyよりOfferBoxのほうが応募が多いから、Wantedlyをやめたい」という相談を受けますが、台帳を見ると、OfferBoxの「応募」は企業が選んで送った相手からの承認で、Wantedlyの「応募」は会社を読んだ学生からの「話を聞きに行きたい」です。前提が違う数を同じ列に置いて、多いほうを残す判断をすると、面談まで来て近い人が多かった入口を止めることがあります。当社が並べて見るときに最初に揃えるのは、入口の数ではなく、「面談した人のうち、近い人が何人か」を媒体ごとに出せる台帳です。この一列が揃うと、入口の数の大小は判断から外せます。

## 台帳を一つにする｜項目の揃え方

媒体ごとに台帳を分けると、並べられません。一つの台帳に、媒体を列の一つとして持ちます。

| 項目 | 書き方 |
|---|---|
| 入口の媒体 | Wantedly／OfferBox／ワンキャリア／ナビ／紹介／リファラル。複数なら最初の入口と、決め手になった入口の二つ |
| 入口の日 | その媒体で最初に接点が生まれた日 |
| 「こんな人」への近さ | 近い・やや近い・遠い、の三段。入口で付け、面談で付け直す |
| 面談の日 | 入口の日との差が「入口から面談までの日数」 |
| 選考の段と日 | 一次・二次・最終。各段の日 |
| 結果 | 内定・辞退・不採用・保留 |
| 来た理由の一行 | 面談で聞いた「何を見て来たか」。Wantedlyなら記事の場面、スカウト型なら文面のどこ、ナビなら何の条件 |
| 読んだとおりか | 面談で聞いた、記事や文面と実態のずれ |

- **管理画面から写すのは、月に一度**：入口の数は媒体ごとに、その台帳の欄外に
- **「近さ」は、人事と面接官で基準を揃える**：「こんな人」の一行がないなら、先に書く
- **「来た理由の一行」は、媒体を問わず聞く**：Wantedlyだけ聞いて、他で聞かないと並べられない

Wantedly単体の台帳の作り方は[Wantedlyのスカウト運用のKPI設計](/media/wt-scout-kpi/)で書きました。複数媒体の台帳は、それに「入口の媒体」の列を足したものです。

## 予算と工数の配分｜「一人あたり」より「近い人が来た入口」と「時間」で見る

| 見る項目 | 見方 |
|---|---|
| 費用 | 媒体ごとの年間の費用。現在の条件は各媒体の公式ページで確認。この記事では数値を書かない |
| 時間 | 媒体ごとに、担当者が使った時間。Wantedlyは記事と会社ページの時間、スカウト型は文面と送信の時間、ナビは入力とエントリー対応の時間 |
| 近い人の数 | 媒体ごとに、面談まで来た近い人の数 |
| 止まっている段 | 媒体ごとに、数が大きく減る段 |
| 残った資産 | Wantedlyの記事と会社ページ、スカウト型の文面の型、ナビの説明会の型 |

- **「近い人が面談まで来た入口」に、次の年の時間を寄せる**：費用の大小ではなく、近い人の数で
- **時間は、費用と別に数える**：費用が小さくても、時間が大きい媒体がある。Wantedlyは記事を書く時間が要る
- **止まっている段が「面談から先」なら、媒体の問題ではない**：どの入口から来ても同じ段で減るなら、面談か選考の側を直す
- **残った資産を、費用の側に足す**：Wantedlyの記事は翌年も残る。一年で「効かない」と判断すると、資産を数えずに止めることになる
- **一人あたりの費用は、一年の台帳が揃ってから、参考として置く**：それで媒体を止めない

媒体を何本持つかは、予算ではなく担当者の時間で決めます。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)で書いた考え方と同じです。

## Wantedlyだけに足す項目｜記事の資産と、来た人の言葉

他の媒体と同じ段で並べたうえで、Wantedlyには二つの項目を足します。足さないと、Wantedlyは並べたときに「少なく、遅い」入口に見えます。

- **記事の資産**：出したストーリーの本数、話した社員の数、会社ページの「なぜ」が代表の言葉の場面になったか。翌年の元になる
- **来た人の言葉**：面談で聞いた「記事のどこを見て来たか」。挙げられた場面が「こんな人」の行動と重なっていれば、記事は届いている
- **二つは、数字の表の横に、文章の欄で置く**：数字に混ぜない。「Wantedlyから面談まで来た近い人は何人。挙げた場面は〇〇」の形
- **経営に見せるときは、共通の段の数字と、この二つを一緒に**：数字だけ見せると、Wantedlyを止める判断になりやすい。[経営層にWantedlyの成果を説明する方法](/media/wt-keiei-rikai/)

Wantedlyは、会社を読んでから来る入口なので、入口の数は少なく、面談までの日数は長くなります。それでも面談まで来た近い人の割合と、来た人の言葉で見ると、他の入口と違う役割が見えます。役割が違うものを、同じ数で優劣をつけないための項目です。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 入口の数を同じ列に並べる | 前提の違う数で優劣をつけ、近い人が来ていた入口を止める | 入口の段は媒体ごとに。面談から先で並べる |
| 「一人あたりの費用」で途中の月に判断する | 時期の偏りで結論が逆になる | 一年の台帳が揃ってから、参考として |
| Wantedlyだけ「来た理由」を聞く | 他の媒体と並べられない | 媒体を問わず、面談で一つ聞く |
| 台帳を媒体ごとに分ける | 並べる作業が毎月の手作業になり、止まる | 一つの台帳に「入口の媒体」の列 |
| Wantedlyの記事の資産を数えない | 一年で「少なく、遅い」と見えて止める | 資産と言葉を、文章の欄で横に置く |

最も多いのは、一つ目です。見せる前に、「入口の数は前提が違うので並べません。面談から先で並べます」と一言添えると、表の読み方が変わります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 台帳を一つにし、「入口の媒体」の列を足す | 人事 |
| 「こんな人」の一行を書き、「近さ」の基準を揃える | 人事と面接官 |
| 月に一度、各媒体の管理画面から入口の数を写す | 人事 |
| 面談で「何を見て来たか」を、媒体を問わず聞いて一行で残す | 面談に出る人 |
| 面談から先の段と、近い人の数と、日数を並べる | 人事 |
| Wantedlyの記事の資産と言葉を、文章の欄にまとめる | 人事 |
| 「入口の数は並べない」の方針を上司と合意する | 人事と責任者 |
| 次の年に時間を寄せる入口の判断 | 責任者 |

運用代行や代理店が支えられるのは、台帳の型、並べる段の置き方、「近さ」の基準の揃え方、聞く質問の型、経営に見せる形の整理までで、台帳を付けること、「こんな人」の決定、面談で聞くこと、時間を寄せる入口の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。複数媒体の効果を並べて見るとき、自社で持つべきなのは「台帳を付けること」「『こんな人』への近さを付けること」「面談で聞いて一行で残すこと」「時間を寄せる入口の判断」までです。ここから先の、台帳の型、並べる段の置き方、経営に見せる形は外に出せますし、当社が複数媒体の相談で最初に渡すのもこの型です。逆に、台帳を付けることと近さの判断まで外に出すと、外の人が「近い・遠い」を付けることになり、その会社の「こんな人」から離れた判断になります。当社は3媒体すべてを扱っているので、どれかの媒体を残す方向に並べ方を寄せる理由がなく、面談から先の共通の段で並べる型を、そのままお渡しできます。型は外に出し、判断は中に残す。この線を引いておくと、担当者が替わっても並べ方が変わりません。

## まとめ

- 入口の数は媒体ごとに前提が違うので並べない。Wantedlyの「話を聞きに行きたい」と、スカウト型の承認と、ナビのエントリーは、同じ列に置かない
- 並べるのは、面談から先の共通の段と、「こんな人」に近い人の段ごとの数と、各段までの日数
- 台帳は一つにし、「入口の媒体」を列の一つとして持つ。「来た理由の一行」は媒体を問わず聞く
- 予算と工数は、「一人あたりの費用」より「近い人が面談まで来た入口」と「担当者の時間」で見る。一人あたりは一年の台帳が揃ってから参考に
- Wantedlyには「記事の資産」と「来た人の言葉」を、文章の欄で足す。数字だけで並べると「少なく、遅い」に見える

## よくある質問

### 上司が「一人あたりの費用」で並べてほしいと言います

一年の台帳が揃っていれば、参考として出せます。出すときに、「入口の数の前提が違うので、費用の大小で媒体を止める判断はしない」と添えます。途中の月で出すと、時期の偏りで結論が逆になるので、その月の数字では出さず、共通の段と近い人の数を先に見せます。

### Wantedlyは、他の媒体より面談まで来る人が少ないのですが、止めるべきですか

入口の数が少ないのは、会社を読んでから来る入口の性格です。面談まで来た人のうち、近い人がどれだけいるか、来た人が記事のどの場面を挙げているかで見ます。近い人が来ていて、場面が「こんな人」と重なっていれば、少なくても役割を果たしています。近い人が来ていないなら、記事の側を直します。[Wantedlyの効果が測れないときのKPIの置き直し](/media/wt-kouka-sokutei/)

### 複数媒体の効果の並べ方は、御社に相談できますか

できます。当社は、台帳の型、並べる段の置き方、「近さ」の基準の揃え方、聞く質問の型、経営に見せる形の整理を支えられます。台帳を付けること、「こんな人」の決定、面談で聞くこと、時間を寄せる入口の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
