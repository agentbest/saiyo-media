法務、財務、研究開発、設計、データ分析。専門職の中途採用では、人事だけでは候補者の技能を判断しきれません。かといって、現場の専門家にすべての工程を任せると、本来の業務が忙しくて選考が止まります。**結論から言うと、専門職の中途採用は「人事が持つ工程」と「現場の専門家に見てもらう工程」を募集の前に分け、専門家には技能の判断だけを頼む形にすると、選考が止まらず判断もぶれにくくなります。** この記事では、その分け方と、専門家の時間を守る工夫を整理します。

## 専門職の採用で止まりやすいところ

専門職の採用は、一般の職種と比べて次のところで止まりやすくなります。

- **要件が書けない**：人事が専門の中身を分からず、求人票が抽象的になる
- **書類の判断が遅れる**：人事が判断できないので、すべての書類を現場に回し、現場が見る時間がない
- **面接の日程が合わない**：専門家の予定が埋まっていて、候補者を待たせる
- **評価が言葉にならない**：専門家が「何となく違う」と言うが、理由が人事に伝わらない

どれも、人事と現場の分担が決まっていないことが原因です。専門家に頼むことが多いほど、専門家の時間が選考の上限になります。分担を決めるときは、専門家にしかできないことを見極め、それ以外を人事が持つ形にします。

## 分担の決め方｜専門家にしかできないことだけを頼む

選考の工程を並べ、それぞれを誰が持つかを決めます。次の表が一つの型です。

| 工程 | 人事 | 現場の専門家 |
|---|---|---|
| 要件の作成 | 形を整える | 技能の中身を書く |
| 求人票の作成 | 書く | 仕事の中身を確かめる |
| 書類の一次確認 | 必須要件の確認 | |
| 書類の技能確認 | | 技能の水準を見る |
| 日程の調整・連絡 | 持つ | |
| 技能の面接 | 同席・記録 | 質問と判断 |
| 志向・条件の面接 | 持つ | |
| 合否の決定 | 取りまとめ | 技能の評価を出す |

この表で大切なのは、書類の確認を二段に分けることです。人事が必須要件の確認までを担い、届いている書類だけを専門家に回します。必須要件は、専門家に最初に書いてもらった要件から、人事でも判断できる項目（資格の有無、経験した業務の種類など）を抜き出して作ります。

専門家にしかできないのは、技能の水準の判断です。経験の年数や資格だけでは分からない、仕事の質を見る部分です。ここに専門家の時間を集中させます。

## 現場に頼む範囲を具体にする

専門家に選考を頼むときは、何を見てほしいかを具体的に伝えます。「面接に出てください」と頼むだけでは、専門家は自分の関心で質問を広げ、条件や志向まで聞き始めることがあります。

頼むときに伝えることを挙げます。

1. **見てほしいこと**：技能の水準、仕事の進め方、専門の中で得意な領域
2. **見なくてよいこと**：志望の動機、条件、会社の説明。人事が別の回で扱う
3. **評価の出し方**：任せられる仕事の範囲を、具体的な業務で書いてもらう
4. **使える時間**：面接の時間と、書類を見る時間の目安

3つ目の評価の出し方は、「何となく違う」を防ぐための工夫です。「良い」「悪い」ではなく、「この業務なら一人で任せられる」「この業務は支援が要る」と書いてもらうと、人事が合否を取りまとめやすくなります。専門家どうしで評価が分かれたときも、どの業務で意見が分かれたかが見えます。

### エージェントベストの見解

専門職の採用で多い思い込みは、「専門家に全部見てもらえば、間違いが減る」というものです。実際には、専門家に工程を多く頼むほど、専門家の本来の業務が圧迫され、選考の返信が遅れます。当社は媒体の申込後の運用まで見ていますが、専門職の募集で応募が来ているのに採用が進まない会社の多くは、書類の段階から専門家が見ていて、そこで止まっています。専門家に頼む範囲を、技能の判断の一点に絞る。それ以外の工程、たとえば必須要件の確認、日程の調整、候補者への連絡、志向や条件の確認は、人事か外部が持つ。この線を引くだけで、専門家の負担が減り、選考の速さも上がります。自社で持つべきなのは専門家の判断と合否の決定まで。そこから外の作業は、外に出しても判断の質は落ちません。

## 専門家の時間を守る工夫

専門家が選考に協力し続けられるよう、時間を守る工夫をします。

- **面接の枠を先に押さえる**：週の中で、専門家が面接に使える時間を先に決めておき、候補者にはその枠から選んでもらう
- **書類はまとめて回す**：一通ずつ回すより、決まった曜日にまとめて回すほうが、専門家は見やすくなります。ただし、まとめる間隔が長すぎると候補者を待たせるので、間隔は短めに
- **質問の型を渡す**：毎回質問を考えなくて済むよう、技能を見る質問の型を一緒に作っておく
- **結果を伝える**：専門家が見た候補者が、その後どうなったかを伝える。協力した結果が見えると、次も協力してもらいやすくなります

## 求人の書き方｜仕事の中身を専門家の言葉で

専門職の求人票は、人事が書くと抽象的になりがちです。専門の候補者は、仕事の中身が具体的に書かれているかを見ています。

求人票では、次の点を専門家に確かめてもらいます。

- 扱う業務の範囲と、その中で最も比重が大きい業務
- 使う道具や手法、扱う対象の種類
- チームの体制と、誰と一緒に仕事をするか
- 入社後に最初に任せる業務

専門職の候補者は、一般の求人媒体で求人を探すこともあれば、専門の領域に強い紹介会社やスカウトの媒体を使うこともあります。Greenやdodaのような中途向けの媒体では求人票の具体さが応募の判断材料になり、ワンキャリアのようにスカウトを送れる媒体では、文面に仕事の中身を書けるかが返信の分かれ目になります。どちらの場合も、専門家の言葉で仕事の中身を書けるかが鍵です。

### エージェントベストの見解

専門職の採用で、媒体で採るか紹介で採るかを迷う会社に、まず確かめてもらうのは「専門家が書類を見る時間を週にどれだけ取れるか」です。紹介で採る場合は、紹介会社が技能の一次確認をしてから推薦するので、専門家が見る書類は絞られます。媒体で採る場合は、応募の幅が広い分、人事が必須要件の確認をしっかり担い、専門家に回す書類を絞る仕組みが要ります。当社は両方を扱っているので、どちらかを勧める理由はありません。専門家の時間に余裕がなく、人事にも専門の知識がない会社は紹介を軸に、人事が必須要件の確認を担える会社は媒体を軸にする。判断の基準は、手段の良し悪しではなく、社内で書類を絞れる人がいるかです。

## まとめ

- 専門職の採用は、人事が持つ工程と専門家に見てもらう工程を募集の前に分ける
- 書類の確認は、人事の必須要件の確認と専門家の技能の確認の二段に分ける
- 専門家には見てほしいことと見なくてよいことを伝え、評価は任せられる業務で書いてもらう
- 面接の枠を先に押さえ、書類はまとめて回し、結果を伝えて協力を続けてもらう
- 求人票の仕事の中身は、専門家の言葉で確かめる

## よくある質問

### 社内に同じ専門の人がいない場合はどうすればよいですか

初めてその専門職を採る場合、社内に判断できる人がいないことがあります。その場合は、外部の専門家に技能の面接だけを頼む、紹介会社の一次確認を頼りにする、といった方法があります。どこまでを外に頼むかは、入社後に誰がその人の仕事を見るかとあわせて考えます。

### 専門家の評価と人事の評価が分かれたらどうしますか

技能の評価は専門家、志向や条件は人事、と分担を決めておくと、どの点で分かれたかが分かります。技能は十分だが志向が合わない場合は、その志向のずれが入社後にどう影響するかを話し合います。決め方は、合否を決める場で誰が最終の判断をするかを先に決めておくことです。

### エンジニアの採用も同じ考え方でよいですか

基本の考え方は同じです。エンジニアの場合は、技能を見る方法として、課題やコードの確認を入れることが多くなります。詳しくは[エンジニアの中途採用｜技術評価の入れ方](/media/kh-ch-engineer/)で整理しています。
