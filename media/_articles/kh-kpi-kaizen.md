KPIを見て、改善点を見つけたい。ところが、数字が悪い段をそのまま直そうとし、一度に複数を変え、数字だけで原因を決め、入口を増やして解決しようとし、月の途中で変えて前後が比べられなくなり、前年ではなく他社と比べる。翌月も同じ数字が並びます。**結論から言うと、数字が悪い場所と、直す場所は違います。KPIが教えるのは「どこで減ったか」までで、「なぜ減ったか」は、記録と人に聞かないと出てきません。手順は五つ。悪い段を一つに絞る。その段の前の段を見る（原因は前の段にあることが多い）。数字ではない材料を三つ集める（断りの理由、面談の記録、現場の声）。直す場所を一つ決める。次の月まで、他を変えない。一度に複数を変えると、何が効いたか分からなくなり、翌年に同じ判断を繰り返せません。入口を増やすのは、前の段まで遡って原因が入口にあると分かったときだけです。** この記事では、改善で起きる失敗、五つの手順、段ごとに疑う場所、数字ではない三つの材料、変えた後の見方、変えないことを決める、一枚の型、分担を整理します。KPIの基本は[採用KPIの基本](/media/kh-kpi-kihon/)、ファネルは[採用ファネルのKPI設計](/media/kh-kpi-funnel/)、新卒は[新卒採用のKPI](/media/kh-kpi-shinsotsu/)、中途は[中途採用のKPI](/media/kh-kpi-chuuto/)で書きました。数値と料金は書きません。

## この作業の目的｜「何を一つ変えるか」を決める

改善の目的は、悪い場所を全部直すことではなく、次の月に変える一つを決めることです。担当の時間は限られていて、一度に複数を変えると、どれも中途半端になり、効いたかどうかも分かりません。一つに絞れば、次の月に結果が読めて、翌年に判断を再現できます。

## 改善で、起きる失敗

- **数字が悪い段を、そのまま直す**：面談が少ないから面談を増やそうとする。面談が少ない原因は、前の段（送る数、文面、返信の速さ）にあることが多い
- **一度に、複数を変える**：文面も検索も送る時期も変えて、翌月に数が動いても、何が効いたか分からない
- **数字だけで、原因を決める**：「承認が減った」から文面を直す。実際は送った相手が変わっていた、ということがある
- **入口を増やして、解決しようとする**：止まっている場所が入口でないなら、増やすほど放置が増える。[中途採用のKPI](/media/kh-kpi-chuuto/)
- **月の途中で、変える**：前後が比べられなくなる。変えるのは月の区切りで
- **前年ではなく、他社と比べる**：人数も時間も職種も違う。直す場所が分からない

## 改善の、五つの手順

1. **悪い段を、一つに絞る**：複数が悪く見えても、最も減っている段を一つ。全部を直さない
2. **その段の前の段を、見る**：面談が少ないなら、その前（承認、応募、送った数、送った相手）。減った原因は前にあることが多い
3. **数字ではない材料を、三つ集める**：断りの理由、面談の記録、現場の声。後述
4. **直す場所を、一つ決める**：文面か、検索か、返信の速さか、面談の枠か、要件か。一つだけ
5. **次の月まで、他を変えない**：変えた一つの結果が出るまで、他を触らない

- **手順を飛ばして「入口を増やす」に行かない**：手順2と3で、原因が入口だと分かったときだけ増やす
- **一つを変えた月の記録を残す**：何を、いつ、なぜ変えたか。翌年の材料に。[新卒採用の年間振り返り](/media/kh-schedule-review/)

### エージェントベストの見解

これは順番の話です。改善の相談で、「面談が少ないので、送る数を増やしたい」と言われることがあります。当社がお願いする順番は、「面談が少ないことを確かめる」、「その前の段（承認、返信、日程の出し方）を見る」、「断りの理由と面談の記録を読む」、「直す場所を一つ決める」、です。前の段を見ると、承認はあるのに面談に進んでいない、という形が多く見つかります。原因は、承認の後の返信が遅い、面談の日程が先になっている、面談の案内が事務的で学生が来ない、のどれかです。ここで送る数を増やすと、承認が増えて、返信がさらに遅れ、面談は増えません。3媒体（OfferBox・Wantedly・ワンキャリア）のどれを使っていても、この順番は同じです。数字が悪い段の一つ前を見る。これだけで、直す場所が変わることが多くあります。

## 段ごとに、疑う場所

| 悪い段 | 前の段で疑うこと | その段で疑うこと |
|---|---|---|
| 接点（承認・応募）が少ない | 送った相手、送った数、送る時期 | 文面の最初の一文、件名、企業ページ |
| 面談が少ない | 承認の数、返信の日数、日程の出し方 | 面談の案内の文面、面談の枠 |
| 面接に進まない | 面談に出た人、面談で伝えた内容 | 面接の案内、面接までの日数 |
| 内定が出ない | 面談と面接で見た内容、「こんな人」の基準 | 判断の基準、面接官の人数 |
| 承諾されない | 内定を出すまでの日数、面接で伝えたこと | 内定の伝え方、内定後の連絡。[内定のKPI](/media/kh-kpi-naitei/) |
| 一年後に残らない | 面接で伝えた仕事の実態、内定後の連絡 | 受け入れ、配属 |

- **「その段で疑うこと」より、「前の段で疑うこと」を先に見る**
- **段の切り方は、自社のファネルに合わせる**：[採用ファネルのKPI設計](/media/kh-kpi-funnel/)
- **入口ごとに分けて見る**：全入口を合算すると、どの入口が悪いか見えない。[媒体別のKPI設計](/media/kh-kpi-baitai/)

## 数字ではない、三つの材料

| 材料 | 集め方 | 何が分かるか |
|---|---|---|
| 断りの理由 | 辞退・見送りの理由を、決めた区分で残す | 条件か、仕事の中身か、速さか |
| 面談の記録 | 面談で聞かれたこと、伝えたことを一行 | 学生が何を確かめているか |
| 現場の声 | 面接官・現場に「会った人が要件に合っていたか」を聞く | 母集団が合っているか、基準がずれているか |

- **三つとも、その場で残す形にする**：後から思い出さない
- **断りの理由は、区分を先に決めて選ぶ形に**：自由記述だと書かれない
- **面談の記録の一行が、文面の材料にもなる**：[スカウト文面の基本](/media/kh-bunmen-kihon/)
- **現場の声は、数字が悪くない月にも聞く**：悪いときだけ聞くと、答えが「悪い理由」に寄る
- **三つが集まっていないなら、集める形を作ることが、その月の改善**：数字だけで直す場所を決めない

## 変えた後の、見方

- **変えた月と、その前の月を比べる**：他社や前年ではなく、直前と
- **一か月で判断しない段がある**：承諾と一年後の数は、変えた結果が出るまで時間がかかる。先に動く数で見る。[新卒採用のKPI](/media/kh-kpi-shinsotsu/)
- **数が動かなかったら、変えたことを戻すか、もう一段前を見る**：同じ場所をもう一度変えない
- **数が動いたら、その変更を型にする**：次の卒年、次の募集でも同じ形に
- **変えた記録を、一行残す**：「〇月に、△△を□□に変えた。理由は〇〇」
- **変えた結果が出る前に、次を変えない**：重ねると読めなくなる

## 変えないことを、決める

- **同時に変えるのは一つ**：他は変えないと決めて書く
- **選考期に、文面と選考のやり方を変えない**：進行中の学生が混乱する。[4年生の春に何をするか](/media/kh-schedule-4nen-haru/)
- **うまくいっている段を、念のため変えない**：数が良い段は触らない
- **変えないことを、経営と共有する**：「今月は〇〇だけ変えます」
- **変えたい場所が複数あるなら、順番を決めて並べる**：来月はこれ、再来月はこれ

## 一枚の型

- **上に、今月の悪い段（一つ）と、その前の段の数**
- **中に、数字ではない三つの材料（断りの理由の内訳・面談の記録から拾った言葉・現場の声）**
- **下に、直す場所（一つ）と、変えないこと**
- **横に、変えた日、変えた内容、理由、翌月の数**
- **毎月、一行ずつ積み上げる**：翌年の振り返りの材料に

## 社内の分担

| 作業 | 誰が |
|---|---|
| 悪い段を一つに絞り、前の段を見る | 人事責任者 |
| 断りの理由を、決めた区分で残す | 人事と現場 |
| 面談の記録を一行残す | 面談に出た人 |
| 現場の声を聞く | 人事責任者 |
| 直す場所を一つ決め、変えないことを決める | 人事責任者 |
| 変えた記録を一行残す | 人事 |
| 翌月に、変えた月と前の月を比べる | 人事責任者 |

運用代行や代理店が支えられるのは、手順の型、段ごとに疑う場所の整理、材料の集め方の型、数の集計、変更の実務（文面の書き換え、検索の絞り直し、送信）までで、直す場所の決定、変えないことの決定、現場の声を聞くこと、要件と基準の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。改善の相談で、「文面を直してほしい」と言われることがあります。当社は文面の下書きを支えられますが、先に聞くのは「どの段が悪いか」と「その前の段はどうか」です。文面を直して効くのは、接点（承認・応募）が少ない場合で、面談が少ない場合は、文面ではなく返信の速さか日程の出し方のことが多くあります。承諾されない場合は、文面ではなく内定の伝え方と内定後の連絡です。文面はいちばん外に出しやすい作業なので、相談が文面に集まりますが、直す場所が文面でないなら、書き換えても数は動きません。当社がお願いしているのは、作業を依頼する前に、段で切り分けることです。切り分けてから依頼すれば、外に出す作業も、自社で直す場所も、それぞれ効きます。

## まとめ

- 数字が悪い場所と、直す場所は違う。KPIが教えるのは「どこで減ったか」まで。「なぜ減ったか」は記録と人に聞く
- 手順は五つ。悪い段を一つに絞る→その前の段を見る→数字ではない材料を三つ集める→直す場所を一つ決める→次の月まで他を変えない
- 原因は前の段にあることが多い。面談が少ないなら承認と返信と日程、承諾されないなら内定までの日数と面接で伝えたこと
- 数字ではない三つの材料は、断りの理由（区分を先に決める）、面談の記録の一行、現場の声。集まっていないなら、集める形を作ることがその月の改善
- 一度に複数を変えない。変えた月と直前の月を比べ、動いたら型にし、動かなければ戻すかもう一段前を見る。変えた記録を毎月一行積む

## よくある質問

### 悪い段が複数あるときは、どれから直しますか

最も減っている段を一つ選び、その前の段を見てください。複数が悪いときは、前の段の問題が後ろに波及していることが多く、前を直すと後ろも動きます。それでも複数が独立して悪いなら、来月・再来月と順番を決めて並べ、一つずつ変えてください。同時に直すと、効いたかどうかが読めません。

### 改善の結果が出るまで、何も変えられないのは遅くないですか

接点と面談の段は、翌月に動きが出ます。承諾と一年後の数は時間がかかるので、その間は「先に動く数」（面談の枠の埋まり方、返信の日数）で見てください。遅く見えるのは、一度に複数を変えて何が効いたか分からないまま翌年も同じ判断をするより、結局は速い進み方です。

### 採用KPIからの改善は、御社に相談できますか

できます。当社は、手順の型、段ごとに疑う場所の整理、材料の集め方の型、数の集計、変更の実務を支えられます。直す場所の決定、変えないことの決定、現場の声を聞くこと、要件と基準の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
