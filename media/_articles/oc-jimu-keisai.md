ワンキャリアで新卒の事務職を募集したとき、最初にぶつかるのは「『一般事務』『サポート業務』と掲載したのに、エントリーが少ない。来ても、面接で『総合職と何が違うのですか』『将来はどうなりますか』『繁忙期はどのくらいですか』と聞かれ、答えた内容が体験談で『総合職との差を面接で初めて知った』『将来の道が無い』と書かれる」という問題です。**結論から言うと、ワンキャリアの事務職の掲載は、「一般事務」の名前ではなく「誰の何を支える仕事で、最初の年に何を一人で回し、総合職との違いと待遇はどうで、将来の道はあるのか無いのか、繁忙期はどのくらいか」を、学生が体験談で読む前に企業ページと募集に書き、面接で総合職との違いを聞かれる前に話します。** この記事では、事務職を見る学生が体験談で読んでいること、掲載に書くこと、学生の見つけ方、スカウトの文面、選考への接続、社内の分担、やりがちな失敗を整理します。文系学生向けの掲載の全体は[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/)、総合職の掲載は[ワンキャリアで総合職を募集するときの掲載とスカウト](/media/oc-sogo-keisai/)で書きました。

## 事務職を見る学生が、体験談で読んでいること

ワンキャリアの学生は、事務職の募集を見ると、企業ページを読む前に、体験談で「事務職の実態」と「総合職との違い」を読みます。

| 読んでいること | 掲載への意味 |
|---|---|
| 誰の何を支える仕事か | 営業の事務か、経理の入力か、総務の手続きか、受付か。「一般事務」の名前では分からない |
| 最初の年に何を回すか | 最初の月に何を教わり、何か月目に何を一人で回すか。「サポート業務」の一語では分からない |
| 総合職との違いと待遇 | 給与、昇進、転勤、仕事の範囲。違いがあるなら、どこか。体験談で最も多く書かれる |
| 将来の道があるか | 事務職のまま責任者になれるか。総合職に変われるか。ずっと同じ仕事か |
| 残業と繁忙期 | 月末月初、決算期、年度末の実態。「定時で帰れる」が本当か |
| 事務で入った先輩の実態 | 何年目に何をしていて、総合職との差をどう感じているか |
| 面接で何を聞かれたか | 「なぜ事務職か」をどう聞かれたか。総合職に誘導されなかったか |

「総合職との違いと待遇」と「将来の道があるか」が、事務職の体験談で最も読まれ、企業ページで最も書かれない項目です。ここを企業ページに書かないと、学生は体験談の「差を面接で初めて知った」を、会社の実態として読みます。

## 掲載に書くこと｜仕事の中身、総合職との違い、将来の道、繁忙期

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「一般事務」ではなく「営業の〇〇を支える事務」「経理の入力と請求書の事務」。誰の何を支えるかで |
| 誰の何を支えるか | 「営業〇人の見積書と契約書を作り、顧客からの問い合わせの一次対応をする」 |
| 最初の年 | 「最初の月は〇〇を教わる。三か月目に△△を一人で回す。一年目の終わりに□□まで」 |
| 総合職との違いと待遇 | 給与の仕組み、昇進、転勤の有無、仕事の範囲。違いを隠さず、仕組みで書く。数値は確認したものだけ |
| 将来の道 | 「事務職のまま〇〇の責任者になる道がある」「総合職に変わる仕組みがある。条件は△△」「決まっていない」。無いなら無いと |
| 残業と繁忙期 | 「月末月初と決算期は〇〇。それ以外は△△」。「定時で帰れる」と書くなら、繁忙期の実態も |
| 事務で入った先輩の話 | 最初の年に困ったこと、総合職との差をどう感じているか。盛らない |

企業ページには総合職との違いと将来の道と繁忙期を、募集には誰の何を支えるかと最初の年を、と分担します。

### エージェントベストの見解

相談で最も多い思い込みは、「事務職は応募が集まりやすいから、『一般事務』で出して、総合職との違いは面接で説明すればよい」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの事務職の掲載と選考を見ていますが、「一般事務」で出して面接で総合職との違いを説明した会社の体験談には、「総合職との差を面接で初めて知った」「将来の道を聞いたら、無いと言われた」が書かれ、次の年の学生がそれを読んで離れます。ワンキャリアの学生は、事務職の募集を見ると、まず体験談で「総合職との差」を読みます。差があること自体で離れるのではなく、企業ページに書かれていないことで「隠していた」と読みます。逆に、「総合職との違いは、転勤の有無と、給与の仕組み。事務職のまま〇〇の責任者になる道がある」と企業ページに書いた会社は、エントリーの数は減っても、体験談に「違いが事前に分かっていた」と書かれ、面接後の辞退が減ります。当社が最初にお願いするのは、「一般事務」を「誰の何を支える事務」に変え、総合職との違いを仕組みで一文書くことです。

## 事務職に合う学生の見つけ方

「サポートが好き」「人を支えたい」と書く学生は多くいますが、それだけでは事務職に合う学生とは限りません。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 志望職種 | 「事務職」「サポート」と書く学生 | あればよい条件。理由が「楽そうだから」か「回す仕事が好きだから」かを読む |
| 回した経験 | 部活の会計、サークルの連絡係、アルバイトの締め作業 | 「決まった期限までに、複数のことを順番を付けて回した」記述を優先 |
| ずれを見つけた経験 | 「数字が合わなくて、原因を探した」「予定と違って、先に連絡した」 | 事務の「ずれの原因を探す」「先に伝える」と重なる |
| 誰かの仕事を支えた経験 | 「〇〇の準備を、頼まれる前に整えた」 | 誰の何を支える仕事かと重なる |
| 将来の道への記述 | 「専門を持ちたい」「長く続けたい」 | 自社の将来の道と合うか |

「決まった期限までに、複数のことを順番を付けて回した」を書いている学生が、事務職と重なります。ガクチカの読み方は[ワンキャリアの学生のガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

スカウト文面の型は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。事務職では、次の点を足します。

- **相手の一文は、回した経験とずれを見つけた経験で**：「部活の会計で数字が合わず、原因を探して直したと書かれていたのを読んで」
- **誰の何を支えるかを、一文で**：「うちの事務は、営業〇人の見積書と契約書を作り、問い合わせの一次対応をします」
- **総合職との違いを、隠さず一文で**：「総合職との違いは、転勤の有無と、給与の仕組みです。詳しくは面接で伝えます」
- **将来の道を、盛らず一文で**：「事務職のまま〇〇の責任者になる道があります」「決まっていません」
- **送り主は、事務で入った先輩**：人事の名前で「サポート業務」と送らない

スカウトと掲載の言葉が違うと、学生は体験談で確かめます。つなげ方は[スカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)で書きました。

## 選考への接続｜総合職との違いと将来の道を、聞かれる前に話す

- **面接には、事務の責任者と、事務で入った先輩が出る**：「総合職との違い」を責任者本人が話す。先輩が「最初の年に困ったこと」と「差をどう感じているか」を話す
- **総合職との違いと将来の道を、聞かれる前に話す**：面接の最初のほうで。聞かれてから答えると「隠していた」と体験談に書かれる
- **「なぜ事務職か」を聞くとき、総合職に誘導しない**：事務職を選んだ理由を聞き、総合職を勧めない。誘導すると、体験談に「事務職を軽く見ている」と書かれる
- **繁忙期の実態を、面接で話す**：「月末月初と決算期は〇〇」。「定時で帰れる」とだけ言わない
- **内定後に、事務の一日を見せる**：内定の後、実際の事務の一日と繁忙期の様子を見せると、辞退が減る。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 誰の何を支えるか、総合職との違い、将来の道、繁忙期の実態を決める | 経営者と、事務の責任者 |
| 企業ページの事務職の記述 | 人事が、事務の責任者と事務で入った先輩に聞いて書く |
| 総合職との違いの仕組みの確認 | 人事（給与の仕組み、転勤、昇進を確認。数値は確認したものだけ） |
| 事務で入った先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「差を面接で初めて知った」と書かれていないか） |
| スカウトの一文 | 事務で入った先輩 |
| 面接 | 事務の責任者と、事務で入った先輩 |

将来の道が決まっていない会社では、「決まっていない」と書きます。「事務職からのキャリアアップも」と盛って、実際に道が無いのが、体験談に最も書かれる形です。

運用代行や代理店が支えられるのは、掲載の型、総合職との違いを仕組みで書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、違いと将来の道の決定、先輩の話、面接は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

事務職の内定辞退が続く会社に共通するのは、「面接で『なぜ事務職か』を聞いて、総合職を勧めた」ことです。当社がワンキャリアの事務職の選考を見ていると、面接官が学生の話を聞いて「あなたなら総合職でも」と言い、学生がそれを「事務職を下に見ている会社」と読んで、体験談にそう書き、辞退する形が多くあります。辞退の理由は「総合職との差があるから」ではなく、「事務職を選んだことを、会社が軽く扱ったから」です。逆に、企業ページに総合職との違いと将来の道を書き、面接で「なぜ事務職か」を聞いても総合職に誘導せず、事務で入った先輩が「差をどう感じているか」を正直に話した会社は、体験談に「事務職として見てくれた」と書かれ、辞退が減ります。当社が案内するのは、総合職との違いと将来の道を企業ページに書き、面接で聞かれる前に話し、事務職を選んだ理由を聞いても総合職を勧めない、という形です。差の有無で学生は離れません。事務職を軽く扱われることで離れます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「一般事務」「サポート業務」で書く | 誰の何を支えるか分からず、読まれない | 誰の何を支え、最初の年に何を回すかを書く |
| 総合職との違いを書かない | 体験談に「差を面接で初めて知った」と書かれる | 仕組みで、隠さず書く |
| 将来の道を盛る | 「道が無い」と入社後に分かり、離れる | あるなら書く。無いなら無いと |
| 「定時で帰れる」とだけ書く | 繁忙期に「聞いていない」と体験談に書かれる | 繁忙期の実態も書く |
| 面接で総合職を勧める | 「事務職を軽く見ている」と書かれ、辞退する | 事務職を選んだ理由を聞き、誘導しない |
| 「サポートが好き」だけで学生を絞る | 回す経験の無い学生が来て、離れる | 期限までに順番を付けて回した経験で読む |

最も多いのは、「一般事務」の一語と、総合職との違いの抜けです。

## まとめ

- 事務職を見る学生は、体験談で「誰の何を支える仕事か・最初の年に何を回すか・総合職との違いと待遇・将来の道・残業と繁忙期・先輩の実態」を、企業ページより先に読む
- 掲載には、「誰の何を支える事務」と職種名を書き、最初の年、総合職との違いを仕組みで、将来の道を盛らず、繁忙期の実態を書く。体験談と食い違わないように
- 事務職に合う学生は、「サポートが好き」ではなく、「決まった期限までに複数のことを順番を付けて回した」「ずれの原因を探した」の記述で見つける
- スカウトは、事務で入った先輩の名前で、掲載と同じ言葉で。総合職との違いと将来の道を隠さない
- 面接には事務の責任者と先輩が出て、総合職との違いと将来の道を聞かれる前に話し、「なぜ事務職か」を聞いても総合職に誘導しない

## よくある質問

### 総合職と事務職で、給与と昇進に差があります。企業ページに書くと、エントリーが減りませんか

減りますが、面接後の辞退と、入社後の離職が減ります。「総合職との違いは、転勤の有無と、給与の仕組み。昇進は〇〇の形」と仕組みで書き、数値は確認したものだけ書くか、面接で伝えると書きます。書かずに面接で出ると、体験談に「差を面接で初めて知った」と書かれ、次の年の学生がそれを読みます。差を書いて減るより、隠して体験談に書かれるほうが、長く響きます。

### 事務職の将来の道が、社内に無い状態です

無いなら、無いと書きます。「事務職のまま責任者になる道は、いまは無い。総合職に変わる仕組みも、いまは無い。〇〇の時期に、会社として考える」のように、無いことと、考える時期を書きます。「キャリアアップも」と盛って道が無いのが、体験談に最も書かれ、次の年に最も響く形です。無いと書いて来た学生は、無いことを前提に来ています。

### 事務職の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、総合職との違いを仕組みで書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。違いと将来の道の決定、先輩の話、面接は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
