運送会社、倉庫会社、3PL、フォワーダー・国際物流、宅配、メーカーや小売の物流子会社が、新卒を採る。学生が「物流」で思い浮かべるのはトラックの運転で、新卒の総合職が実際にするのは、倉庫やセンターの現場管理（パート・派遣・協力会社の管理、時間と品質の管理）、荷主への営業、配車と企画、国際物流の手配。このずれが、開かれない理由と、来ても離れる理由の両方になる。大手の宅配や海運系の会社は知られていて、中小の運送・倉庫は知られていない。**結論から言うと、物流業界は「運転手を採るのではなく、現場を回す人を採る」を一行にし、学生のイメージと採る仕事のずれを最初に埋めます。現場管理の実態（人の管理、夜間と交代制、荷主との関係）を隠さず一枚にし、大手は学生が並べて比べる場で選考情報と実態を、中小の運送・倉庫は「人を動かして場を回した・段取りを組んだ」の記述と地元で絞って送る型か、センターの一日を記事で読んでもらう型を先に検討します。国際物流は「海外」の言葉で絞らず、手配と調整の実態で。** この記事では、物流業界の採用構造、判断軸の当て方、学生が確かめること、「現場を回す人を採る」の一行、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## 物流業界の採用構造と、媒体との相性

| 区分 | 採用の形 | 媒体との相性 |
|---|---|---|
| 大手の宅配、海運・鉄道系の物流、大手3PL | 知られている。多く採る。現場管理と営業と企画を職種別か総合職で | 比べられる場で選考情報と実態を。「運転」のイメージを埋める |
| 中小の運送、倉庫 | 知られていない。少人数で採る。現場管理が中心。地域の荷主で成り立つ | 「人を動かして場を回した」の記述と地元で絞って送る型か、センターの一日の記事 |
| フォワーダー、国際物流 | 「海外」「貿易」で学生が来る。実態は手配と書類と調整 | 「海外」で絞らず、手配と調整の記述で。実態を先に |

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 学生のイメージは運転手。採るのは現場管理と営業 | 「物流」の一語で開かれない。来ても「思っていた仕事と違う」 | 「現場を回す人を採る」を一行に。運転ではないことを最初に |
| パート・派遣・協力会社の管理が、若手の仕事の中心 | 年上の人を動かすことを知らずに来て、離れる | 「人を動かした」の記述で絞る。場面で書く |
| 夜間、交代制、繁忙期（年末、セール） | 生活のリズムで離れる | 勤務の形を最初に書く |

## 判断軸を、物流業界に当てる

| 軸 | 物流業界での見方 |
|---|---|
| 対象（誰に届くか） | 「物流に興味」の記述はほぼなく、絞る条件にならない。絞るのは「アルバイトや部活で人を動かして場を回した・段取りを組んで間に合わせた・年上の人と働いた」の記述。地元と出身地域。国際物流は「海外」ではなく「調整して決めた」で |
| 型（送るか、来るか、比べられるか） | 「物流」の一語で学生が来る型は動きにくい。送る型で記述と地元で絞って「現場を回す仕事」を先に渡すか、来る型でセンターの一日を読んでもらう。比べられる型は大手に |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | センターの若手は現場と交代制で動けない。名義と面談の枠を、現場の波の外に固定する。送る型は作業を外に出せる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。物流では、「対象」の軸で「物流に興味」がほぼ存在しないことを前提に記述で絞ることと、学生のイメージ（運転）と採る仕事（現場管理）のずれを最初に埋めることが、他の業界と違います。

### エージェントベストの見解

これをやる前に、先に「運転手を採るのではなく、現場を回す人を採る」を一行にしておかないと、「物流」の一語で開かれず、開いた学生も「思っていた仕事と違う」と離れます。当社は3媒体すべての販売パートナーとして、運送や倉庫の会社の相談を受けますが、「物流に興味のある方へ」で送っている文面は、学生の側に「物流＝運転手」のイメージがあるので、開かれません。物流の新卒の総合職がすることは、倉庫やセンターで、年上のパート・派遣・協力会社の人を動かし、時間と品質を守ることで、これは運転でも企画でもなく、「現場を回す仕事」です。順番は、「現場を回す人を採る」を一行にし、「こんな人」を「アルバイトや部活で人を動かして場を回した・段取りを組んで間に合わせた・年上の人と働いた」に置くことです。一行があると、「物流」の一語では届かなかった学生に、仕事の中身で届きます。

## 学生が、確かめること

- **運転するのか、しないのか**：総合職が運転するか、資格が要るか。最初に確かめている
- **現場管理の実態**：パート・派遣・協力会社の管理、年上の人を動かすこと、若手はどこまで任されるか
- **勤務の形**：夜間、交代制、繁忙期（年末、セール、月末）。休みの取り方
- **配属と転勤**：センターの場所、転居を伴う異動の範囲。センターは郊外が多い

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 大手の宅配・海運系・3PLで、学生に知られ、クチコミと選考情報が付いている | 学生が並べて比べる場（ワンキャリア）で選考情報と実態を | 比べる対象に入っている。現場管理の年数と勤務の形とクチコミをずらさない |
| 大手で、企画・営業・国際物流の職種を現場の層とは別に採りたい | 企業から送る型（OfferBox） | 専攻と「調整して決めた・数字を扱った」の記述で絞り、別の文面で別に届く |
| 中小の運送・倉庫で、地元と「人を動かした」の記述で絞って会いたい | 企業から送る型（OfferBox） | 「物流」の一語で候補にしていない学生に、若手の名義で「現場を回す仕事」を先に渡せる。作業を外に出せる。[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/) |
| センターの若手が、現場の一日と年上の人を動かした日を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「運転」のイメージに、センターの一日と人の管理を先に読んでもらえる。イメージを否定せず変えたことを場面で |
| 「現場を回す人を採る」の一行が、まだない | どれも先ではない | 一行を作ってから。「物流」の一語では動かない |

どれか一つが正解ではなく、区分と知名度、企画・国際の職種を分けて採るかで、先に検討するものが変わります。

## 組み合わせ

- **大手は、比べられる場と送る型を組み合わせる**：比べられる場で現場管理からの道筋の受け皿を、送る型で企画・営業・国際物流の職種を。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **中小の運送・倉庫は、送る型と記事を置く型を組み合わせる**：文面で「あなたの〇〇で場を回した経験を読んで」を、記事で「センターの一日」と「年上の人を動かした日」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **センターの見学と組み合わせる**：媒体からセンターの見学へ。「運転」のイメージを本人が確かめる場。[OfferBoxと合同説明会の併用](/media/ob-heiyou-setsumeikai/)

## 見せ方｜「物流」ではなく、現場を回す仕事

- **運転ではないことを、最初の一文で**：「この募集は運転ではなく、倉庫やセンターで人と時間と品質を管理する仕事です」
- **現場を回す仕事を、場面で**：「〇〇のセンターで、△△の便が遅れた日に、パートの方と協力会社に、こう頼んで間に合わせた」。若手の名義で
- **年上の人を動かすことを、隠さず**：「最初の年から、年上のパートの方に頼む仕事です」。向く人と向かない人を分ける一文
- **勤務の形と配属を、最初に、隠さず**：「勤務は〇〇の形で、センターは△△にあり、異動は□□の範囲」。数値は実態で。この記事では書かない
- **業界イメージ（きつい、長時間、運転手）を否定せず、実態と変えたことで**：[業界イメージが不利な会社のWantedlyの書き方](/media/wt-gyokai-image/)、[知名度がない会社のOfferBoxオファー文面](/media/ob-chimeido-nai/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「現場を回す人を採る」の一行と、勤務・配属・荷主・道筋の一枚 | 経営と人事、センターの責任者 |
| 区分と知名度、企画・国際の職種を分けるかで、先に検討する型を決める | 人事と責任者 |
| 「こんな人」（人を動かして場を回した・段取りを組んだ・年上の人と働いた）の整理 | 人事とセンター長 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、センターの若手が一日を話し、整えるのは人事か外に | 若手と人事 |
| 個別の一文、文面の最終確認、名義、面談 | センターの若手 |
| 面談枠を現場の波の外に固定する | 人事とセンター長 |

- **センターの若手に頼むのは、名義・一文・面談の三つ。繁忙期を避けて**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)

運用代行や代理店が支えられるのは、一行の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分までで、一行の中身、現場管理と勤務と荷主の実態の開示、名義の選定、面談、見学は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

送り始めたあと、最初の年で起きることに共通するのは、「企画」「国際物流」「社会を支える」で承認や応募が付き、面談か入社後にセンターの現場管理から始まり、年上の人を動かす仕事であることを知って離れることです。当社はOfferBoxの運用代行を受けているので、運送や倉庫の会社の承認から面談までを見ていますが、現場管理から始まることと年上の人を動かすことを文面に書かず、「企画」「グローバル」で書いている会社が多く、その言葉で来た学生は、最初の配属がセンターであることを面談で初めて知ります。当社が物流の会社に勧めているのは、最初の一文に「運転ではなく、センターで人と時間と品質を管理する仕事で、最初の年から年上の方に頼みます」と置き、そのうえで「便が遅れた日に間に合わせた」場面を若手の名義で書くことです。書いて来た学生は、現場管理を知ったうえで来ていて、最初の繁忙期で辞めません。

## まとめ

- 物流業界は、学生のイメージ（運転手）と採る仕事（現場管理、営業、企画）がずれている。「運転手を採るのではなく、現場を回す人を採る」を一行にしてから媒体を選ぶ
- 「こんな人」は「物流に興味」ではなく「人を動かして場を回した・段取りを組んで間に合わせた・年上の人と働いた」の記述と地元で。国際物流は「海外」ではなく「調整して決めた」で。企画・国際は別の文面で別に
- 現場管理の実態（年上のパート・派遣・協力会社を動かす）、勤務の形、配属、荷主との関係、企画への道筋を最初に隠さず。「社会を支える」の一語で済ませない
- 大手は並べて比べる場で選考情報と実態を、送る型は企画・営業・国際の職種に。中小の運送・倉庫は記述と地元で絞って送る型か、センターの一日を記事で読んでもらう型を先に
- センターの若手に頼むのは名義・一文・面談で、枠は現場の波の外に固定。見学と組み合わせ、繁忙期を避ける

## よくある質問

### 「運転ではありません」と書く必要がありますか

あります。学生の側に「物流＝運転手」のイメージがあり、書かないと開かれず、開いても運転を想像します。「運転ではなく、倉庫やセンターで人と時間と品質を管理する仕事です」と最初の一文に置くと、「物流」の一語で候補にしていなかった学生に、仕事の中身で届きます。運転する総合職があるなら、それも隠さず書きます。

### 年上のパートの方を動かす仕事だと書くと、来なくなりませんか

来なくなるのは、年上の人を動かすことを知ったら来ない学生で、入社後に離れる学生です。「アルバイトや部活で人を動かして場を回した・年上の人と働いた」の記述で絞ると、それを知ったうえで来る学生に届きます。「最初の年から年上の方に頼む仕事です」と書き、「便が遅れた日に間に合わせた」場面を若手の名義で書くほうが、残る学生が来ます。

### 物流業界の媒体選びは、御社に相談できますか

できます。当社は、一行の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分を支えられます。一行の中身、現場管理と勤務と荷主の実態の開示、名義の選定、面談、見学は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
