「挑戦」「誠実」「チームワーク」。会社ページのバリューの欄に、こうした言葉が並んでいる会社は多くあります。ところが、この言葉だけでは、候補者は自社と他社の違いも、自分が合うかも判断できません。**結論から言うと、バリューを言葉にするとは、単語を並べることではなく、「こういう場面で、こう動く。逆に、こうは動かない」まで書くことです。実例が1つあれば、単語は要りません。** 既にバリューがある会社は各項目に実例を付け、無い会社は活躍している社員の行動から抽出します。この記事では、バリューの位置づけ、ある場合と無い場合の手順、書き方の型、候補者の読み方、数の絞り方、やりがちな失敗、分担を整理します。ミッションの書き方は[会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/)、会社ページ全体は[会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

## この作業の目的｜候補者が「自分はここで動けるか」を判断できるようにする

ミッションが「なぜやるのか」なら、バリューは「どうやっているのか」の中の、判断と行動の基準です。候補者は、バリューを読んで「自分はこの動き方ができるか」「この動き方を求められて嬉しいか」を判断します。

「挑戦」と書いてあっても、どんな場面で何をすることが挑戦なのかが分からなければ、判断できません。「新しい提案は、失敗しても責めない。ただし、提案の前に顧客に聞きに行くことは省かない」と書いてあれば、「自分はそれができる」「それは合わない」と判断できます。

バリューを言葉にする目的は、候補者が自分で「合う・合わない」を判断できる材料を渡すことです。合わない候補者が来ないことも、目的のうちです。

## 手順1｜バリューがある会社は、各項目に実例を1つ付ける

既にバリューの言葉がある会社は、言葉を変えず、各項目に実例を付けます。

| 書くこと | 内容 |
|---|---|
| バリューの言葉 | そのまま。変えない |
| 場面 | このバリューが試された場面。「顧客から〇〇と言われたとき」「納期が迫っていたとき」 |
| そのときの動き | 誰が、どう動いたか。「△△さんは、□□をした」。名前を出すかは本人の同意で |
| 逆に、しないこと | このバリューがあるから、しないこと。「〇〇はしない」。境界が分かる |
| 入社後に求めること | この動き方を、入社した人にも求めるか。求めるなら、どの場面で |

「逆に、しないこと」が、バリューを具体的にする鍵です。「挑戦」だけだと、何でもありに読めます。「挑戦する。ただし、顧客に聞かずに始めることはしない」と書くと、境界が分かり、候補者は自分の動き方と照らせます。

実例が思いつかないバリューは、社内で使われていない可能性があります。載せるかどうかを、次の手順で見直します。

## 手順2｜バリューが無い会社は、活躍している社員の行動から抽出する

バリューの言葉が無い会社は、作るのではなく、抽出します。抽出の元は、活躍している社員の行動です。この方法は、OfferBoxのペルソナで書いた「活躍している若手からの逆算」と同じです。考え方は[採りたい学生像を言葉にする](/media/ob-persona/)で書きました。

1. **活躍している社員を数人挙げる**：職種を問わず。代表と現場の責任者で
2. **その人たちが、最近どう動いたかを集める**：「〇〇の場面で、△△をした」を、1人につき2つか3つ
3. **共通する動き方を探す**：「困ったとき、自分で調べてから人に聞く」「顧客の言葉をそのまま社内に持ち帰る」など
4. **共通する動き方を、場面つきの一文にする**：単語にしない。「〇〇のとき、△△する」の形で
5. **数を絞る**：共通する動き方は、多くても数個。多いと覚えられず、使われない
6. **社内で使ってみる**：会社ページに載せる前に、社内の会議や振り返りで使う。使われなければ、まだバリューではない

「作る」と「抽出する」の違いは、元が「こうありたい」か「こう動いている」かです。「こうありたい」で作ったバリューは、実態と違い、候補者に見抜かれます。「こう動いている」から抽出したバリューは、実例がすでにあります。

### エージェントベストの見解

これをやる前に、先に決めておかないとバリューが書けないことがあります。「実例を先に集める」ことです。当社がWantedlyの運用の相談で会社ページのバリューを見るとき、単語が先に決まっていて、実例があとから探されている会社が多くあります。「挑戦」と決めてから「挑戦した場面は」と探すと、無理に当てはめた実例になり、候補者には作られた話に読めます。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、バリューが読まれている会社は、実例が先で、単語があとです。「〇〇さんがこう動いた」が数個あって、それに名前をつけたのがバリューになっています。この順番だと、実例は本物で、単語は実例の要約です。逆の順番だと、単語は立派で、実例は後づけです。候補者は、どちらかを一読で見分けます。実例が先、言葉はあと。この順番を守ると、バリューは自然に書けます。

## 手順3｜書き方の型

バリューの部分を、次の型で書きます。1つのバリューにつき、この型を1つずつ。

1. **バリューの言葉、または動き方の一文**：「顧客の言葉をそのまま持ち帰る」のように、単語ではなく動き方で
2. **場面**：「先月、顧客から〇〇と言われたとき」
3. **動き**：「△△さんは、その言葉を変えずに社内に共有し、□□を変えた」
4. **逆に、しないこと**：「顧客の言葉を、自分の解釈で言い換えて伝えることはしない」
5. **入る人へ**：「この動き方を、入社した人にも最初の月からお願いしている」

「場面」と「動き」に、社員の名前を出すかは本人の同意で決めます。名前が無くても、「営業の1人が」で成立します。名前があると、メンバーの紹介とつながり、候補者に人が見えます。メンバーの選び方は[会社ページに載せるメンバーの選び方](/media/wt-kaisha-page-member/)で書きます。

## 手順4｜候補者がバリューのどこを読むか

| 候補者が見ること | 書く側が用意すること |
|---|---|
| 自分はこの動き方ができるか | 場面と動きが具体的であること。単語だけでは判断できない |
| この動き方を求められて嬉しいか、しんどいか | 「逆に、しないこと」で境界が分かること |
| 本当にこう動いているのか、建前か | 最近の実例であること。名前があればなお伝わる |
| 入社後、最初からこれを求められるか | 「入る人へ」の一文 |
| 他社との違い | 単語では違いが出ない。場面と動きで初めて違いが出る |

「他社との違い」は、候補者がWantedlyで複数の会社を見比べるときの視点です。「挑戦」「誠実」は、どの会社にも書いてあります。「顧客の言葉をそのまま持ち帰る。言い換えない」は、その会社にしか書けません。違いは、単語ではなく場面に出ます。

## 手順5｜数を絞り、実態と違うものを載せない

バリューは、数が多いほど使われなくなります。載せる前に絞ります。

- **実例が付かないバリューは、載せない**：社内で使われていない証拠。載せると、面談で「実際は」と聞かれて答えられない
- **似ているバリューは、1つにまとめる**：「誠実」と「正直」のように
- **社員が3つ以上言えないなら、数を減らす**：覚えられない数は、判断に使われない
- **「こうありたい」が混ざっていれば、分けて書く**：「いまはできていないが、目指している」と正直に。実態として書かない
- **代表しか体現していないバリューは、載せるか考える**：社員が動けていないなら、まだ会社のバリューではない

絞った結果、1つか2つになっても構いません。具体的な1つは、抽象的な7つより、候補者に届きます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 単語を並べる | 他社と同じ。判断できない | 場面と動きを付ける |
| 「こうありたい」で作る | 実態と違い、見抜かれる | 活躍している社員の行動から抽出する |
| 単語を先に決めて実例をあとから探す | 後づけの実例になる | 実例を先に集める |
| 数が多い | 覚えられず、使われない | 実例が付くものだけに絞る |
| 「逆に、しないこと」が無い | 境界が分からず、何でもありに読める | 各バリューに1つ |
| 褒め言葉だけ | 建前に見える | 場面と動きで書く。しんどい面も |
| 実例が古い | 「いまはやっていない」と映る | 最近の場面に差し替える |
| 社員が言えないバリューを載せる | 面談で気づかれる | 社内で使ってから載せる |

最も多いのは、最初の「単語を並べる」です。バリューの欄があるから単語を埋める、という書き方が、こうなります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| バリューがあるか、抽出するかを決める | 代表 |
| 活躍している社員と、最近の動きを挙げる | 代表と現場の責任者 |
| 共通する動き方を探し、一文にする | 人事（代表と確認） |
| 場面と動きを書く | 人事（本人に聞き、同意を取る） |
| 「逆に、しないこと」を決める | 代表 |
| 数を絞る | 代表と人事 |
| 社内で使ってみる | 全員（会議や振り返りで） |
| 実例を数ヶ月に一度差し替える | 人事 |

代表の時間は、「活躍している社員の動きを挙げる」「しないことを決める」「数を絞る」の3つです。書くのは人事です。代理店や運用代行が支えられるのは、動き方を一文にする型と、単語を場面に置き換える案までです。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの会社ページの整備を支えるとき、バリューの「型」（動き方の一文、場面、動き、しないこと、入る人へ）と、単語を場面に置き換える案は当社が出せます。ただし、「誰がどの場面でどう動いたか」と「しないことは何か」は、企業の代表と現場にしか出せません。ここを当社が想像で書くと、候補者には「どの会社にも書いてありそう」に読めます。当社の役割は、企業から実例を引き出す質問をすることと、引き出した実例を型に整えることです。「最近、社員が判断した場面を3つ教えてください」「そのとき、しなかったことは何ですか」。この2つの質問で、たいていのバリューは出てきます。出てこないなら、まだバリューになっていないので、載せずに「どうやっているのか」の場面だけを書く。無理に埋めないことも、当社が支える判断の1つです。

## まとめ

- バリューを言葉にするとは、単語を並べることではなく、「こういう場面でこう動く。逆にこうは動かない」まで書くこと
- ある会社は各項目に実例を1つ付ける。無い会社は活躍している社員の行動から抽出し、「こうありたい」で作らない
- 実例が先、単語はあと。逆の順番だと後づけの実例になり、候補者に見抜かれる
- 候補者は「自分はこの動き方ができるか」「他社とどう違うか」で読む。違いは単語ではなく場面に出る
- 実例が付かないバリューは載せない。数を絞り、実例は数ヶ月に一度差し替える

## よくある質問

### バリューが無いのですが、会社ページに何を書けばよいですか

無理に作らず、活躍している社員の最近の動き方を数個集め、「〇〇のとき、△△する」の形で書きます。単語の名前をつけなくても、動き方の一文が数個あれば、候補者は「自分が合うか」を判断できます。社内で使われるようになったら、そのときに名前をつけます。

### バリューが7つあります。全部載せてよいですか

実例が付くものだけに絞ることを勧めます。社員が3つ以上言えない数は、判断に使われておらず、候補者にも届きません。似ているものはまとめ、「こうありたい」が混ざっていれば分けて書きます。具体的な1つか2つのほうが、抽象的な7つより伝わります。

### バリューの整理は、御社に頼めますか

型と、実例を引き出す質問と、単語を場面に置き換える案は当社が出せます。実例そのものと「しないこと」は、代表と現場に出していただきます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの会社ページの整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
