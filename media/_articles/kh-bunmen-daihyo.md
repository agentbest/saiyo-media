代表の名前でスカウトを送る。開かれやすく、「代表から直接」が返信の理由になる。ところが、名前だけ借りて人事が書き、代表は面談に出ず、返信は人事が代表の名前で返す。相手には、面談で「代表ではないのか」が残ります。**結論から言うと、代表名の効果は、「代表と直接話せる」を本当に提供したときだけ出ます。代表が話す場に出られる募集に限り、代表の言葉で「なぜ始めたか」の場面と「一緒に働く場面」を書き、代表が文面を確認し、代表が返信を見るか、人事が代表の代理と明記して返します。理念の一文と実績と「私が直接」の押しは避けます。代表が忙しくなったら、名義を切り替えます。三つの媒体で、この考え方は同じです。** この記事では、代表名の効果と落とし穴、送る条件、書くことと避けること、返信の扱い、忙しくなったときの切り替え、媒体ごとの違い、分担を整理します。文面全体の骨組みは[スカウト文面の基本構成](/media/kh-bunmen-kihon/)、Wantedlyでの代表名は[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/)で書きました。

## この作業の目的｜「代表と直接話せる」を、本当に提供する

代表名で送る文面は、相手に「代表と話せるなら」という返信の理由を渡します。その理由が、返信のあとに裏切られると、相手には「名前だけだった」が残り、面談以降に進みません。

目的は、代表名を「開かせる工夫」として使うのではなく、「代表と話せる」という約束として使い、その約束を守ることです。

## 代表名の、効果と落とし穴

| 効果 | 落とし穴 |
|---|---|
| 一覧で開かれやすい。知らない会社でも「代表から」で開く | 名前だけ借りて人事が書き、代表が面談に出ない。「話が違う」 |
| 「代表と直接話せる」が、返信の理由になる | 代表が返信を見ず、人事も見ず、返信が遅れる。「代表からなのに返事がない」 |
| 会社の「なぜ」を、本人の言葉で書ける | 理念の一文を並べて、場面がない。「社長の演説」 |
| 小さい会社の距離の近さが、そのまま伝わる | 代表が忙しくなり、途中から出られなくなる。前半と後半で対応が変わる |
| 代表が面談に出ると、相手が「この人と働く」を想像できる | 代表しか出ないので、現場の人が見えない |

効果は、落とし穴を避けたときだけ出ます。落とし穴の詳しくは[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/)の「代表名の効果と、落とし穴」で書きました。

## 代表名で送る、条件

- **代表が、話す場に出られる募集に限る**：出られない募集は、現場か人事の名義で
- **代表が、文面を確認する**：人事が書いてよいが、代表が読んで「自分が言いそうか」を確かめる。名前だけ貸さない
- **代表が返信を見るか、人事が「代表の代理」と明記して返す**：代表の名前で人事が返さない
- **代表の週の枠を、送る前に押さえる**：返信が来てから代表の時間を探さない
- **送る数を、代表が出られる数に合わせる**：代表名で送る数は、代表の枠で決まる
- **条件の詳しくは[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/)の「代表名で送る条件」**

条件が揃わないなら、代表名で送りません。現場の人の名義のほうが、届くことがあります。名義の考え方は[OfferBoxのオファー文面テンプレートを作るときの注意](/media/ob-offer-template/)の注意3で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「代表の名前で送れば開封率が上がるので、文面は人事が書いて、名義だけ代表にすればよい」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の文面を見ていますが、名義だけ代表にした文面は、開かれてはいるものの、面談で代表が出ないことが分かった時点で、相手の側に「名前だけだった」が残り、選考に進んでいません。代表名は、開封の工夫ではなく、「代表と話せる」という約束です。約束を守れない募集で代表名を使うと、開封は増えても、その先が減ります。逆に、代表が面談に出て、「なぜ始めたか」を本人の言葉で話した募集は、小さい会社でも、相手が「この人と働く」を想像して、選考に進んでいます。当社が代表名の相談を受けるとき、最初にやるのは、「代表は、月に何回、面談に出られますか」を聞くことです。その回数が、代表名で送れる数です。

## 代表の文面で、書くこと

| 書くこと | 例 |
|---|---|
| 相手の一文 | 通常の型と同じ。「〇〇を自分で始めて続けたと書かれているのを拝見しました」。代表名でも、相手のことから始める |
| なぜ始めたかの場面 | 「私がこの会社を始めたのは、△△で困っている人を見て、□□をしたかったからです」。理念の一文ではなく、場面 |
| 一緒に働く場面 | 「入った方とは、私と同じ部屋で、✕✕をその場で決めながら進めます」。代表との距離が見える場面 |
| 選考で何を見るか | 「選考では、学生時代に続けたことの話を、私が聞きます」 |
| 話す場 | 「選考ではなく、私と、オンラインで短い時間、話す場です」。代表が出ることを明記 |

代表の文面は、代表でなければ書けないこと（なぜ始めたか、一緒に働く場面）を書きます。代表でなくても書けること（会社説明、実績）は、書きません。書き方は[Wantedlyのストーリーで代表の考えを書く方法](/media/wt-story-daihyo/)と同じで、理念ではなく場面です。

## 代表の文面で、避けること

- **理念の一文を並べる**：「私たちは〇〇を通じて△△を実現します」。場面がなく、演説に見える
- **実績と受賞**：「創業〇年で□□を達成」。代表が書くと、自慢に見える
- **「私が直接お会いします」の押し**：一度書けば足りる。繰り返すと、「代表が出ることを売りにしている」
- **「優秀な方に、私から」の持ち上げ**：慣れている相手には読まれない
- **会社の全体像**：代表は全体を語りたくなるが、相手が読みたいのは「自分がする仕事」と「この人と働く場面」
- **長い文面**：代表の文面は長くなりやすい。四つの部分の役割を果たす最小の長さで。[スカウト文面の長さの考え方](/media/kh-bunmen-nagasa/)

避けることの詳しくは[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/)の「代表の文面で、避けること」で書きました。

## 返信の、扱い

- **代表が返信を見るなら、翌日までに見る**：代表からの返信が遅いと、「代表からなのに」が重く残る
- **代表が見られないなら、人事が「代表の〇〇に代わってご連絡します」と、人事の名前で返す**：代表の名前で人事が返さない
- **日程は人事が調整し、面談には代表が出る**：この形を、返信で伝える。「日程は私（人事）が調整し、面談は〇〇（代表）が出ます」
- **返信への対応の速さは、名義に関係なく翌日まで**：[Wantedlyで面談につながらないとき](/media/wt-mendan-tsunagaranai/)
- **代表が出る面談の形は[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/)の「代表が面談に出る形」**

## 代表が忙しくなったときの、切り替え

- **代表が出られなくなったら、名義を現場の人か人事に切り替える**：出られないまま代表名で送り続けない
- **進行中の相手には、「面談は代表の代わりに〇〇が出ます」と、事前に伝える**：当日に変えない
- **切り替えた名義の文面は、その人の「一緒に働く場面」で書き直す**：代表の文面をそのまま使わない
- **代表名に戻すのは、代表の枠が戻ってから**
- **切り替えの詳しくは[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/)の「代表が忙しくなったときの切り替え」**

## 媒体ごとに、変わる点

| 媒体 | 代表名の扱い |
|---|---|
| OfferBox | 学生には、代表より若手の名義が届きやすいことがある。代表名は、小さい会社で代表が面談に出る場合に |
| Wantedly | 代表名と相性がよい。会社の「なぜ」を代表の言葉で書け、カジュアル面談に代表が出る形が自然。[Wantedlyのスカウトを代表名で送るときの注意](/media/wt-scout-daihyo/) |
| ワンキャリア | 代表名で送るなら、企業ページの「なぜ」と面接官の一覧に代表がいること。体験談に「代表と話せた」と書かれる形に |

三つとも、「代表が本当に出る」が条件です。送る人の名義の表示のされ方は、媒体の現在の仕様で確認してください。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 代表名で送る募集と、送らない募集を分ける | 人事と代表 |
| 代表の週の枠を押さえ、送る数を決める | 人事と代表 |
| 「なぜ始めたか」と「一緒に働く場面」を話す | 代表 |
| 文面を書く | 人事（代表が話したことを書く） |
| 文面を確認する | 代表 |
| 返信を見る、または「代表の代理」と明記して返す | 代表か人事 |
| 面談に出る | 代表 |
| 代表が出られなくなったら名義を切り替える | 人事 |

運用代行や代理店が支えられるのは、代表名で送る条件の整理、代表の文面の型、返信の扱いの型、切り替えの設計までで、「なぜ始めたか」を話すこと、確認、返信を見ること、面談に出ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。当社が代表名のスカウトの相談を受けるとき、当社が持てるのは、代表名で送る条件の整理と、代表の文面の型と、返信の扱いの型までです。「なぜ始めたか」の場面は代表にしか言えず、面談に出るのも代表で、当社が代わることはできません。当社が線を引くのは、「代表は忙しいので、文面も返信も面談も代理店で、名義だけ代表にしたい」という依頼です。それは、相手に「代表と話せる」と約束して、約束を守らない形で、当社は引き受けません。当社が勧めるのは、代表が出られる回数を先に決め、その回数だけ代表名で送り、残りは現場か人事の名義で送ることです。

## まとめ

- 代表名の効果は、「代表と直接話せる」を本当に提供したときだけ出る。名前だけ借りて代表が出ないと、「名前だけだった」が残り、面談以降に進まない
- 代表名で送る条件は、代表が話す場に出られる募集に限る・代表が文面を確認する・代表が返信を見るか人事が「代表の代理」と明記して返す・代表の枠を先に押さえる
- 代表の文面で書くのは、相手の一文・「なぜ始めたか」の場面・一緒に働く場面・何を見るか・代表が出る話す場。理念の一文・実績・「私が直接」の押し・会社の全体像は避ける
- 返信は翌日までに。代表の名前で人事が返さない。代表が忙しくなったら名義を切り替え、進行中の相手には事前に伝える
- 代表名で送れる数は、代表が面談に出られる回数で決まる。それ以上は、現場か人事の名義で

## よくある質問

### 代表が「文面は人事に任せる、面談には出る」と言います

その形で足ります。人事が書いてよいですが、「なぜ始めたか」と「一緒に働く場面」は代表から聞いて書き、代表が読んで「自分が言いそうか」を確かめます。確認なしに代表の名前で出すと、面談で代表が「そんなことは言っていない」となり、相手に「話が違う」が残ります。確認は、短い時間で済みます。

### 代表が面談に出られる回数が少なく、代表名で送れる数が足りません

代表名で送る数は、その回数までにします。残りは、現場の人か人事の名義で送ります。代表名は、「代表と話せる」を約束できる数だけに使い、約束できない数まで広げません。現場の人の名義で、その人が面談に出る形のほうが、代表名で代表が出ない形より、届きます。

### 代表名で送るスカウト文面は、御社に相談できますか

できます。当社は、代表名で送る条件の整理、代表の文面の型、返信の扱いの型、切り替えの設計を支えられます。「なぜ始めたか」を話すこと、確認、返信を見ること、面談に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
