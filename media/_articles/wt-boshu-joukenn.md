Wantedlyは、会社の想いに共感した人が集まる媒体です。だから条件は書かなくてよい、と考える会社があります。**結論から言うと、共感で集める媒体でも、条件は隠しません。勤務地、働き方、契約の形、勤務時間の実態、転居の有無は、募集記事の最後に、短く、正確に書きます。理由は、共感して話を聞きに来た候補者が、面談のあとで「条件が合わない」と辞退するのが、双方にとって最も残念だからです。** 条件は募集記事の中心ではありませんが、無いと面談の時間が無駄になります。この記事では、条件を書く理由、書く条件と書き方、募集記事に載せにくい条件の扱い、未確定の場合、新卒と中途の違い、やりがちな失敗、分担を整理します。募集記事の全体は[募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。待遇の扱いは[募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)で別に書きます。

## この作業の目的｜面談のあとの「条件が合わない」を無くす

共感型の媒体では、候補者は「想いが先、条件が後」の順で読みます。この順番は[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。想いに共感して話を聞きに来て、面談のあとで条件を確認する。ここで「勤務地が通えない」「出社の頻度が想像と違う」と分かると、辞退になります。

条件を募集記事に書く目的は、候補者が「話を聞きに行く前に、自分に関係する条件を確かめられる」状態にすることです。確かめたうえで来た候補者は、条件で辞退しません。確かめられずに来た候補者は、面談のあとで辞退します。

条件を書くことは、共感で集めることと矛盾しません。共感で来てほしいからこそ、条件でがっかりさせない。それが、条件を隠さない理由です。

## 手順1｜書く条件

募集記事に書く条件を並べます。候補者が「自分に関係するか」を確かめるために要るものです。

| 条件 | 書くこと | なぜ要るか |
|---|---|---|
| 勤務地 | 初任の勤務地。候補が複数なら列挙 | 通えるか、転居が要るかの判断。書き方はOfferBoxの[募集要項の書き方](/media/ob-boshu-youkou/)と同じ |
| 転居・転勤の有無 | あるなら時期の目安。無いなら明記 | 生活の判断 |
| 働き方の実態 | 出社と在宅の実際、週の配分の目安 | 制度ではなく実態。「リモート可」だけでは分からない |
| 勤務時間の実態 | 始業と終業の形、時間外の実態、繁忙期 | 生活の判断 |
| 契約の形 | 正社員、契約、業務委託、副業可など | 応募できるかの判断 |
| 入社時期 | 新卒なら入社の年、中途なら「相談」か時期 | 動ける時期の判断 |
| 選考の流れ | 話を聞く面談のあと、何段階か、期間の目安 | 「話を聞きに行ったら何が起きるか」の判断 |

「働き方の実態」と「勤務時間の実態」が、共感型の募集記事で抜けやすい条件です。制度は会社ページに書いてあっても、この募集の職種の実態は募集記事にしかありません。実態の書き方は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 手順2｜書き方｜最後に、短く、正確に

条件は、募集記事の中心ではありません。書き方を3つで固定します。

1. **最後に置く**：「こんなことやります」「誰と」「求める動き方」のあと、締めの前。最初に置くと求人票に見える
2. **短く**：項目と内容を、1行ずつ。説明を膨らませない。読みたい人が読める形で
3. **正確に**：「本社および各拠点」「当社規定による」「応相談」だけで終わらせない。分かる範囲で具体的に。分からないなら次の手順で

条件を最後に短く置くと、共感で読み進めた候補者が「最後に確認する」形になります。最初に置くと、条件で判断され、想いが読まれません。この順番は、募集記事の基本構成の記事で書いたとおりです。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは共感で集める媒体だから、条件は書かなくてよい。書くと共感型でなくなる」というものです。実際には、条件を書かない募集記事は、共感して話を聞きに来た候補者が面談のあとで「勤務地が」「出社が」と辞退する形になり、面談の時間が双方の無駄になります。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、面談のあとの辞退が多い会社の募集記事を見ると、勤務地と働き方の実態が書かれていないか、「相談」だけで終わっています。逆に、条件を最後に短く正確に書いた募集記事は、話を聞きに来る候補者の数は少し減るかもしれませんが、来た候補者の面談のあとの辞退が減ります。共感で集めることと、条件を書くことは、両立します。順番と量を守れば、条件は共感を邪魔しません。

## 手順3｜募集記事に載せにくい条件の扱い

募集記事の項目の仕様や、自社の方針で、募集記事に書きにくい条件があります。その場合の扱いです。

- **「面談で正確に伝えます」と明記する**：書かないのではなく、「いつ伝えるか」を書く。候補者は「面談で聞ける」と分かって来られる
- **面談の早い段階で、実際に伝える**：明記したのに面談で伝えないと、信頼を失う。初回面談か、遅くとも選考に進む前に
- **候補者から質問が来たら、当日に答える**：答え方は[学生からの質問に答える文面](/media/ob-offer-gakusei-shitsumon/)で書いた考え方と同じ。ぼかさない
- **法令で明示が求められる労働条件は、媒体の記事の書き方とは別に、社内で確認して所定の方法で伝える**：募集記事に何を書くかと、法令上の明示は別の話。人事が確認する

「面談で伝える」と書くのは、「隠す」ではなく「場所を変える」ことです。書かずに面談で初めて言うのと、「面談で伝える」と書いておくのとでは、候補者の受け取り方が違います。

## 手順4｜未確定なら、未確定と書く

条件が決まっていない募集があります。新しく始める事業、配属先が複数、勤務地が決まっていない。

| 状況 | 書き方 |
|---|---|
| 勤務地が複数候補で未定 | 候補を列挙し、「配属は面談で相談して決める」 |
| 働き方がチームで違う | 「配属先によって出社と在宅の配分が違う。面談で説明する」 |
| 入社時期が相談 | 「相談。最短で〇〇頃から可能」のように、目安を添える |
| 契約の形が複数 | 「正社員が基本。副業からの参加も相談」のように、基本と例外を分ける |
| 新規事業で決まっていないことが多い | 「決まっている条件」と「一緒に決める条件」を分けて書く |

「未定」と書くことは、隠すことではありません。「未定なので相談して決める」と書けば、候補者は「相談できる」と分かります。「応相談」だけで終わると、何が決まっていて何が決まっていないかが分からず、判断できません。決まっていることと決まっていないことを分けて書く考え方は、[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書いた「決まっていないなら正直に」と同じです。

## 手順5｜新卒と中途で違うこと

| 観点 | 新卒向け | 中途向け |
|---|---|---|
| 勤務地 | 初任の勤務地と、転勤の可能性。学生は生活の想像がしにくいので丁寧に | 勤務地と転居の支援の有無 |
| 働き方の実態 | 研修期間の働き方と、配属後の働き方を分けて | このチームの実態 |
| 入社時期 | 入社の年を明記 | 「相談」でよいが、最短の目安を |
| 契約の形 | 正社員が基本なら明記 | 副業や業務委託の可否 |
| 選考の流れ | 段階と時期の目安を丁寧に。学生は他社と並行している | 段階と期間の目安 |

新卒向けは、学生が「働く生活」を想像しにくいので、条件を少し丁寧に書きます。中途向けは、経験者が「いまの職場との比較」で見るので、実態を正確に書きます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 条件を書かない | 面談のあとで辞退 | 最後に短く正確に |
| 条件を最初に置く | 求人票に見え、想いが読まれない | 最後に |
| 「本社および各拠点」「応相談」だけ | 判断できない | 候補を列挙し、決まっていないことは「相談して決める」 |
| 制度だけ書いて実態を書かない | 「リモート可」で来て出社中心と知る | このチームの実態 |
| 「面談で伝える」と書いて面談で伝えない | 信頼を失う | 初回面談で伝える |
| 条件の質問に答えない、翌日以降 | 面談前に離れる | 当日に答える |
| 条件を長く書く | 求人票になる | 1行ずつ |
| 新卒向けに転勤の可能性を書かない | 内定後に知って辞退 | 初任と転勤の可能性を明記 |

最も多いのは、最初の「条件を書かない」と、「応相談だけ」です。どちらも「共感型だから」という思い込みから来ています。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 条件を確定する | 人事（勤務地は事業部門、実態は配属先に確認） |
| 募集記事の最後に書く | 人事 |
| 「面談で伝える」条件を決め、面談で伝える | 人事と面談に出る人 |
| 法令上の明示を確認する | 人事（必要なら専門家に） |
| 条件の質問に当日答える | 人事 |
| 条件が変わったら直す | 人事 |

配属先の時間は、「働き方と勤務時間の実態を話す」ことだけです。運用代行や代理店が支えられるのは、書く条件の一覧、書き方の型、未確定の書き分けまでで、条件の確定と法令の確認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと条件が書けないことがあります。「初任の勤務地と、この職種の働き方の実態」を、社内で確定することです。当社がWantedlyの運用の相談で募集記事を見るとき、条件が「応相談」になっている会社に聞くと、社内で決まっていないことが多く、決まっていないから書けない、という状態です。書けないまま出すと、面談で候補者に聞かれ、答えられず、辞退されます。募集記事を書く前に、勤務地と実態を人事と配属先で確定する。確定に時間がかかるなら、出す時期をそれに合わせます。確定しないまま「応相談」で出すより、確定してから出すほうが、面談のあとに残る候補者が増えます。条件は書き方の話ではなく、社内で決める話です。この順番は、OfferBoxの募集要項でも同じで、[募集要項の書き方](/media/ob-boshu-youkou/)で書きました。

## まとめ

- 共感で集める媒体でも、条件は隠さない。面談のあとの「条件が合わない」辞退を防ぐため
- 書くのは、勤務地、転居・転勤、働き方の実態、勤務時間の実態、契約の形、入社時期、選考の流れ
- 最後に、短く、正確に。最初に置くと求人票に見え、「応相談」だけでは判断できない
- 募集記事に載せにくい条件は「面談で伝える」と明記し、初回面談で実際に伝える。法令上の明示は別途確認する
- 未確定なら「決まっていること」と「相談して決めること」を分けて書く。新卒向けは少し丁寧に

## よくある質問

### 条件を書くと、共感で来る候補者が減りませんか

減るのは「条件が合わない候補者」で、その候補者は面談のあとで辞退します。条件を最後に短く書けば、共感で読み進めた候補者が最後に確認する形になり、共感の邪魔にはなりません。来た候補者の面談のあとの辞退が減るほうが、採用には効きます。

### 勤務地が決まっていない募集は、どう書けばよいですか

候補を列挙し、「配属は面談で相談して決める」と書きます。候補が分かれば、候補者は「通えるか」を判断できます。候補も決まっていないなら、募集記事を出す前に事業部門と確定することを勧めます。「応相談」だけで出すと、面談で聞かれて答えられません。

### 条件の書き方は、御社に相談できますか

できます。当社は、書く条件の一覧、最後に短く正確に書く型、未確定の書き分けを支えられます。条件の確定と、法令上の明示の確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
