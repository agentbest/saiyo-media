デザイナーへのスカウトは、「センスのある方を探しています」「作品を拝見し、素敵だと思いました」「〇〇（ツール名）が使える方」という文面になりがちです。ところが、デザイナーは作品の見た目を褒められることに慣れていて、「素敵」の一言では「見ていない」と分かります。ツール名の羅列は、技術名の羅列と同じで、検索の条件です。**結論から言うと、デザイナー向けのスカウト文面は、作品の見た目ではなく「何を、誰のために、どう決めたか」を読み、それが自社の「デザインの場面」（何を作っていて、誰のためで、いま何を決めようとしているか）とどう重なるかを書き、同じ職種のデザイナーと話す場へ誘います。作品は評価せず、過程を読みます。** この記事では、デザイナーが開かない文面、プロフィールと作品で読む箇所、文面の3段の型、作品を見る姿勢、職種の幅への配慮、避ける言葉、面談で話すこと、募集記事との整合、分担を整理します。文面の基本は[スカウト文面の書き方](/media/wt-scout-bunmen/)、エンジニア向けは[エンジニア向けスカウト文面の型](/media/wt-scout-bunmen-rei-eng/)で書きました。

## この作業の目的｜「作品の過程を読んだ人からの、デザインの話」にする

デザイナーが返信する文面は、「この会社の人は、自分の作品の見た目ではなく、なぜそう作ったかを読んでいて、自社のデザインの話を具体的にしている」と分かるものです。

「素敵な作品ですね」は、誰にでも言えます。「〇〇の画面で、△△を優先して□□を削った判断を読んで」は、その作品を見た人にしか書けません。目的は、後者の一文を最初に置くことです。

## デザイナーが開かない文面

| 文面 | デザイナーからどう見えるか |
|---|---|
| 「センスのある方」「クリエイティブな方」 | 抽象語。何を求めているか分からない |
| ツール名の羅列（「〇〇、△△が使える方」） | 検索の条件。ツールはデザインではない |
| 「作品を拝見し、素敵でした」だけ | 見た目しか見ていない。過程を読んでいない |
| 「何でもできる方」「幅広く対応できる方」 | 何をやる仕事か決まっていない |
| 「デザインで会社を変えてほしい」 | 大きすぎる。日々の仕事が見えない |
| 「裁量が大きい」「自由に作れる」 | 誰と、どう決めるかが無い |
| 作るものが書いていない | 何のデザインか分からない |
| 送り主が人事で、デザインの話が無い | 「面談で過程の話ができない」 |

最も多いのは、「素敵でした」だけです。作品を見たことは伝わりますが、何を見たかが無く、褒め言葉と同じです。

## プロフィールと作品で、読む箇所

| 読む箇所 | 何が書かれているか | 文面での使い方 |
|---|---|---|
| 何を作ったか | 対象（画面、サービス、印刷物、ブランド）と範囲 | 「〇〇の△△を担当されたと読んで」 |
| 誰のためか | 使う人、顧客、場面 | 「□□の人が使う画面を作られていた点が」 |
| どう決めたか | 作品の説明に書かれた判断の理由。「〇〇を優先して△△を削った」「□□の課題からこう変えた」 | 「△△を削った判断を読んで」。最も強い一文 |
| 関わった範囲 | 調査から、設計から、実装との連携まで、どこを担ったか | 自社で担ってほしい範囲と重なるか |
| 誰と組んだか | エンジニア、企画、顧客とどう進めたか | 自社の進め方と重なるか |
| 書いていること | デザインの考え、記事、登壇 | 「〇〇についての記事の△△の部分を読みました」 |
| 次にやりたいこと | 「もっと〇〇の段階から関わりたい」 | 自社の範囲と重なれば |

「どう決めたか」が要点です。作品の説明に判断の理由が書かれていれば、それを読んだと書きます。書かれていなければ、「何を、誰のために」から書きます。見た目の感想は書きません。

### エージェントベストの見解

相談で最も多い思い込みは、「デザイナーには作品を褒めれば、見たことが伝わる」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、「素敵」「洗練された」「センスを感じた」と書いた文面は、開かれても返信が来ません。デザイナーは、見た目の褒め言葉を日常的に受け取っていて、それが「見ていない」ことの印だと知っています。返信が来る文面は、作品の説明にある判断の理由を引用して、「その判断は、うちのいまの〇〇と重なる」と書いたものです。当社がデザイナー向けの文面を整えるとき、最初にやるのは、褒め言葉を消し、作品の説明から「なぜそう作ったか」の一文を探すことです。それが無い作品なら、「何を、誰のために」から書きます。見た目には触れません。

## 文面の3段の型

| 段 | 書き方 |
|---|---|
| 1. 相手の一文 | 「〇〇の画面で、△△を優先して□□を削った判断を読んで、連絡しました」。判断の理由か、何を誰のために作ったか。見た目の感想は書かない |
| 2. 重なる点（自社のデザインの場面） | 「うちは、いま〇〇を使う人向けに△△を作っていて、□□をどこまで削るかを決めようとしています。あなたの『削る判断』は、まさにその部分です」。何を、誰のために、いま何を決めようとしているか。募集記事の「なにを」と同じ言葉 |
| 3. 話す場の案内 | 「同じ職種の〇〇（デザイナー）が、うちのデザインの進め方と、いま迷っているところを話します。転職を決めていなくても構いません」 |

2段目の「いま何を決めようとしているか」が、エンジニア向けと同じ要点です。「自由に作れます」ではなく、「〇〇を、△△と□□で迷っている」のように、決めようとしていることを書くと、デザイナーは「その話をしたい」と思います。

## 作品を見るときの姿勢

文面を書く前に作品を見るとき、次の姿勢で見ます。

- **評価しない**：良い・悪いを判断する場ではない。「うちに合うか」も、まだ判断しない
- **過程を読む**：作品の説明、判断の理由、関わった範囲。見た目より説明を読む
- **一つの作品に絞る**：全部を見た印象より、一つの作品の一つの判断
- **見た目の感想を文面に書かない**：「美しい」「洗練」は書かない

「評価しない」は、文面にも面談にも通じます。評価される場は選考で、過程を聞かれる場がカジュアル面談です。

## デザインの職種の幅への配慮

デザイナーは、職種の幅が広く、同じ「デザイナー」でも仕事が違います。

| 領域 | 会社によって違う部分 |
|---|---|
| UI/UX | 調査から関わるか、設計だけか、実装との距離、どのくらいの規模の画面か |
| プロダクト | 事業の判断にどこまで関わるか、企画との分担 |
| グラフィック・ブランド | 何を作るか（広告、印刷物、ロゴ）、誰が決めるか |
| ウェブ | 設計と制作のどちらか、実装まで担うか |
| 社内の唯一のデザイナー | 全部を一人で担うか、外部と組むか |

文面でも募集記事でも、「デザイナー募集」ではなく、「うちのデザイナーは、〇〇を、△△の段階から、□□と組んで作る仕事です」と、範囲を書きます。相手は自分の範囲と比べます。「何でもできる方」は、範囲が決まっていない印です。

## 避ける言葉

| 避ける言葉 | 代わりに |
|---|---|
| センス、クリエイティブ、感性 | 作品の判断の理由 |
| 素敵、美しい、洗練された | 何を、誰のために、どう決めたか |
| ツール名の羅列 | そのツールで何を作ったか |
| 何でもできる方、幅広く | 担ってほしい範囲を具体的に |
| 裁量が大きい、自由に作れる | 誰と、どう決めるか |
| デザインで会社を変える | いま何を作っていて、次に何を作るか |
| ご応募ください | デザインの話をするだけで |

## 送り主と、面談で話すこと

- **送り主は、同じ職種のデザイナー**：自社のデザインの場面の一文は、その人が書く。社内にデザイナーがいない場合は、デザインと最も近く組む人（企画かエンジニアの責任者）。[スカウトを現場社員の名前で送る方法](/media/wt-scout-genba/)
- **面談で話すこと**：何を作っていて、誰のためで、誰と組んで、どう決めていて、いま迷っていること、担ってほしい範囲、最初の月に何をするか
- **相手の作品の過程を、長く聞く**：「なぜそう決めたか」「削ったものは何か」。評価ではなく、興味として
- **作品の評価をしない**：「ここはこうしたほうが」を言わない。カジュアル面談では聞かない。[カジュアル面談で聞くこと・聞かないこと](/media/wt-scout-mendan-shitsumon/)
- **課題の提出を求めない**：カジュアル面談の前後で、デザインの課題を出さない。選考に進んでから、必要なら

「作品の評価をしない」と「課題を求めない」が、デザイナーとの面談で特に守ることです。どちらも、「話す場」を選考に変えます。面談の型は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

## 募集記事との整合

- **募集記事の「なにを」に、何を・誰のために・どの範囲を、が書かれているか**
- **「どうやって」に、誰と組んで、どう決めるか、があるか**：[「どうやって」の書き方](/media/wt-boshu-dou/)
- **デザイナーのストーリーがあるか**：判断の場面、削った話、迷った話。[事業の裏側を書く方法](/media/wt-story-jigyo/)
- **募集記事の写真やカバーが、デザイナーが見て違和感の無いものか**：会社ページの見た目は、デザイナーには第一印象になる。[カバー写真の選び方](/media/wt-boshu-shashin/)

最後の点は、デザイナー向けに特有です。会社ページと募集記事の見た目が雑だと、「デザインを大事にしない会社」と読まれます。整った見た目である必要はありませんが、写真の選び方と統一感は見られます。つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 募集記事の「なにを」を、何を・誰のために・どの範囲、で書く | 人事と、デザインの責任者 |
| 「いま何を作っていて、何を決めようとしているか」の一文 | デザイナー（いなければ、最も近く組む人） |
| 作品を見て、判断の一文と重なる点を書く | デザイナー（または人事が聞いて書き、本人が確認） |
| 型、絞り込み、返信対応、台帳 | 人事 |
| 面談でデザインの過程の話をする | デザイナー |

運用代行や代理店が支えられるのは、デザイナー向けの型、読む箇所の整理、避ける言葉のチェック、募集記事との整合の確認までで、デザインの場面の一文、作品を読んで書くこと、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは、向く会社と向かない会社がはっきり分かれます。デザイナー向けのスカウトが機能するのは、「社内にデザイナーがいて、その人が作品の過程を読んで書き、面談に出られる会社」です。当社が3媒体の販売パートナーとして相談を受ける中で、「社内に初めてのデザイナーを採りたい」という会社があります。この場合、作品の過程を読める人が社内におらず、文面は「素敵でした」になり、面談でデザインの話ができません。当社が勧めるのは、社内で最もデザインと近く組む人（企画かエンジニアの責任者）が、「いま何を作っていて、デザインで何に困っているか」を一文で書き、その人が面談に出る形です。デザイナーでなくても、困っていることを具体的に話せる人がいれば、デザイナーは「その話をしたい」と思います。「素敵でした」より、「ここで困っています」のほうが、届きます。

## まとめ

- デザイナー向けの文面は、作品の見た目ではなく「何を、誰のために、どう決めたか」を読む。「素敵」は「見ていない」の印
- 2段目は、自社が何を作っていて、誰のためで、いま何を決めようとしているか。「自由に作れる」ではなく具体
- 3段目は、同じ職種のデザイナーが、進め方と「いま迷っているところ」を話す場
- 作品は評価せず過程を読み、一つの作品の一つの判断に絞る。ツール名の羅列、センス、何でもできる方、裁量が大きい、を避ける
- 面談で作品を評価せず、課題を求めない。募集記事に何を・誰のために・どの範囲を書き、会社ページの見た目に違和感が無いか見る

## よくある質問

### 作品の説明に、判断の理由が書かれていません

「何を、誰のために」から書きます。「〇〇を使う人向けの△△の画面を担当されたと読んで」で、見た目の感想を書くよりは「見た」と伝わります。判断の理由は、面談で聞きます。「なぜそう決めたか」を聞く場として、話す場を案内します。

### 社内にデザイナーがおらず、作品を読める人がいません

デザインと最も近く組む人が、「いま何を作っていて、デザインで何に困っているか」を一文で書きます。作品は、「何を、誰のために」の範囲で読めば足ります。面談では、困っていることを具体的に話し、相手の過程を聞きます。評価はしません。それで、デザイナーは「困っていることが具体的な会社」として受け取ります。

### デザイナー向けのスカウトは、御社に相談できますか

できます。当社は、デザイナー向けの型、読む箇所の整理、避ける言葉のチェック、募集記事との整合の確認を支えられます。デザインの場面の一文、作品を読んで書くこと、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
