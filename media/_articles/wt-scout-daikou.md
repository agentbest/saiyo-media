スカウト運用は手間がかかるので、代理店や運用代行に頼みたくなります。頼むこと自体は問題ありませんが、「全部お願いします」と丸投げすると、文面が会社の言葉でなくなり、面談で候補者が「文面と違う」と感じ、契約が終わると社内に何も残りません。**結論から言うと、代行に出せるのは、絞り込みの条件・型と見本・台帳の設計と集計・KPIの表・週と月の見直しの材料・返信の型・引き継ぎの記録で、社内に残すのは、プロフィールを読んで一文を書くこと・送り主・返信への対応・面談・上司との合意です。「読んで書く一文」まで代行に頼む場合は、条件を付けます。代行との情報共有の範囲を決め、代行の成果は段で見て、いずれ社内に戻す順番を決めておきます。** この記事では、丸投げで起きること、出せる作業と残す作業、一文まで頼む場合の条件、情報共有の範囲、成果の見方、社内に戻す順番、分担を整理します。代理店の代行の全体は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)、記事づくりの外注は[記事を外部に書いてもらうときの注意](/media/wt-gaibu-writer/)で書きました。この記事は、スカウトに絞った話です。

## この作業の目的｜社内の時間を減らしつつ、会社の言葉で送る

代行に頼む目的は、「社内の時間を減らす」ことと、「運用の技術を借りる」ことの2つです。目的に入っていないのは、「会社の言葉を代行に作ってもらう」ことです。

スカウトの文面を読んだ候補者は、会社ページと募集記事を見て、面談で会社の人と話します。文面の言葉が代行のものだと、面談でずれます。代行に頼んでも、文面の一文は社内の人の言葉で、面談に出るのは社内の人。これが守られていれば、代行に頼んだ運用も、会社の運用になります。

## 丸投げすると、起きること

| 起きること | なぜ |
|---|---|
| 文面が「Wantedlyらしい」一般的な文面になる | 代行は、会社の仕事の具体を知らない |
| 「この経験がこの仕事のどこで活きるか」が薄い | その仕事をしている人の言葉でない |
| 面談で「文面と違う」となる | 送り主と話す人がずれる。話す人が文面を知らない |
| 返信への対応が、代行を経由して遅れる | 通知が代行に届き、社内に転送される |
| 社内に型も台帳も残らない | 代行の中にある |
| 契約が終わると、運用が止まる | 社内に運用する人がいない |
| 上司が「代行の成果」として数字だけを見る | 段で見ず、返信率で判断する |

最も重いのは、「契約が終わると止まる」です。代行は、いずれ終わります。終わったときに社内に何も残らないなら、代行の期間は運用ではなく、外注の期間でした。

## 出せる作業と、残す作業

| 出せる（代行が担える） | 残す（社内でしかできない） |
|---|---|
| 絞り込みの条件の設計 | プロフィールを読んで、相手の一文と重なる点を書く |
| 文面の型と見本の作成 | 送り主（現場社員か人事か代表の名前） |
| 台帳の設計と、毎月の集計 | 返信への対応（翌日までに返す） |
| KPIの表の設計と、段の集計 | 面談に出て話す |
| 週と月の見直しの材料の整理 | 上司との合意（報告の形、目標値を置かない） |
| 返信の型（前向き・質問・断り） | 現場との合意（読んで書く人の枠） |
| 面談の流れの型、聞くこと・聞かないこと | 選考の判断 |
| 引き継ぎの一覧の作成と保管 | 候補者への連絡そのもの |
| 送る前のチェック（避ける言葉、募集記事との整合） | |

「出せる」は、型・設計・集計・材料で、「残す」は、読む・書く・送る・返す・話す・決めるです。前者は仕事の具体を知らなくてもでき、後者は知っている人でないとできません。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「代行に頼めば、社内の時間はほぼゼロになる」という点です。当社がWantedlyのスカウトの支援をするとき、社内から減るのは、絞り込みを考える時間、型を作る時間、台帳を集計する時間、見直しの材料を揃える時間です。残るのは、読んで一文を書く時間、返信に対応する時間、面談に出る時間です。むしろ、当社が絞り込みと型を整える分、社内の人が読んで書く数は増えることがあります。当社は、支援を始める前に、「社内に残る時間」を週の単位で先に見積もってお伝えします。それでも、人事が一人で全部を担う場合に比べれば、社内の時間は減ります。減るのは設計と集計の時間、残るのは候補者と向き合う時間です。この区別を、頼む前に社内で共有しておくと、代行との関係が長く続きます。

## 「読んで書く一文」まで代行に頼む場合の条件

社内に読んで書く時間がどうしても無い場合、一文まで代行に頼むことはあります。その場合、次の条件を付けます。

1. **代行が書いた一文を、送り主本人が読んで了承してから送る**：了承なしに送らない。名前だけ借りる形にしない。[スカウトを現場社員の名前で送る方法](/media/wt-scout-genba/)
2. **代行に、募集記事の「なにを」と、その仕事の場面を先に渡す**：仕事の具体を知らないまま書かせない
3. **代行に、面談で話す人の言葉（トーン）の見本を渡す**：面談でずれないように。[文章のトーンの決め方](/media/wt-bunsho-tone/)
4. **代行が書いた一文と、返信の有無を台帳に残す**：どの一文が効いたかを社内で見る
5. **期間を決める**：「社内で読める人が確保できるまで」。ずっと代行に書かせない
6. **面談に出る人が、送った文面を面談前に読む**：文面の内容を知らずに出ない

条件が守れないなら、一文まで頼まず、送る数を減らして社内で書きます。数が減っても、会社の言葉で送るほうが、面談でずれません。

## 代行との情報共有の範囲

代行に台帳や候補者の情報を共有する場合、範囲を決めます。

- **候補者の個人情報は、採用の目的の範囲で、必要なものだけ**：氏名や連絡先を共有する必要があるか、代行の作業ごとに確かめる
- **台帳の集計だけを頼むなら、個人が特定できない形で渡せるか**：段の数と一文の型だけなら、特定は要らない
- **共有の方法と、契約が終わったあとの扱いを、契約で決める**：自社の方針と管理部門の確認に沿って
- **管理画面のアクセス権を渡す場合は、範囲を限る**：送信の権限を渡すか、閲覧だけか。仕様は管理画面で確認

この記事では、契約や法的な扱いの具体は書きません。自社の方針と、管理部門や専門家の確認に沿ってください。

## 代行の成果の見方

代行の成果は、返信率ではなく、段で見ます。

| 見るもの | 意味 |
|---|---|
| 読んだ数と送った数 | 絞り込みが機能しているか（代行の設計の結果） |
| 返信の数と型 | 型と絞り込みの結果。ただし一文は社内の人の言葉 |
| 返信から対応までの時間 | 社内の返信対応の結果。代行の成果ではない |
| 面談から選考への段 | 社内の面談の結果。代行の成果ではない |
| 社内に残った型・台帳・記録 | 代行の期間が終わったあとに使えるか |

「社内に残ったもの」を成果に含めるのが要点です。返信率だけで代行を評価すると、代行は煽りの型を作ります。段で見て、社内に残るものを見ると、代行は型と設計に力を入れます。KPIの考え方は[スカウト運用のKPI設計](/media/wt-scout-kpi/)で書きました。

## 代行から社内に戻す順番

代行は、いずれ終わります。終わったときに止まらないよう、戻す順番を決めておきます。

1. **最初から、型と台帳は社内の置き場に置く**：代行の中に置かない。代行は、社内の置き場を更新する形で
2. **月の見直しに、社内の人が出る**：代行が材料を揃え、社内が決める
3. **返信の型と面談の型を、社内の人が使う**：代行が作り、社内が使う。最初から
4. **絞り込みの条件の考え方を、社内に伝えてもらう**：条件そのものではなく、なぜその条件か
5. **代行の期間の後半で、集計を社内でやってみる**：代行が確認する形に
6. **引き継ぎの一覧を、代行が作って社内に渡す**：代行が終わるときに。[スカウト運用の引き継ぎ](/media/wt-scout-hikitsugi/)

「型と台帳は最初から社内の置き場に」が、戻す順番の起点です。代行の中にあるものは、契約が終わると消えます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 代行に出す範囲と残す範囲を決める | 人事と責任者 |
| 募集記事の「なにを」と場面を代行に渡す | 人事 |
| 読んで一文を書く（または代行の一文を了承する） | 現場の担当か人事 |
| 返信への対応 | 人事 |
| 面談 | 現場の担当 |
| 代行の成果を段で見る | 人事 |
| 情報共有の範囲を決める | 人事と管理部門 |
| 型と台帳を社内の置き場に置く | 人事（代行が更新） |

運用代行や代理店が支えられるのは、上の「出せる」の一覧のとおりで、「残す」の一覧は企業が行います。

### エージェントベストの見解

相談で最も多い思い込みは、「代行に頼むなら、文面も送信も返信対応も、全部やってもらえるはずだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの支援をしていますが、返信対応と面談を当社が代わりに行う形はお受けしていません。返信した候補者は、会社の人と話したくて返しています。当社が返すと、その時点で「会社の人ではない」と分かり、面談で会う人とも違います。当社が担うのは、絞り込み、型、台帳、集計、見直しの材料、引き継ぎの記録までで、候補者と直接やり取りする部分は社内に置きます。この線引きを、頼む前にお伝えするのは、「全部やってもらえる」と思って始めた会社が、社内に残る時間を見積もっておらず、途中で止まることを避けるためです。代行は、社内の時間をゼロにする道具ではなく、候補者と向き合う時間だけに社内の時間を使えるようにする道具です。

## まとめ

- 代行に出せるのは、絞り込み・型と見本・台帳の設計と集計・KPIの表・見直しの材料・返信の型・引き継ぎの記録。社内に残すのは、読んで一文を書く・送り主・返信対応・面談・上司との合意
- 丸投げすると、文面が会社の言葉でなくなり、面談でずれ、契約が終わると止まる
- 一文まで頼むなら、送り主の了承・仕事の場面とトーンの見本・台帳・期間・面談前に読む、の条件を付ける
- 情報共有は採用の目的の範囲で必要なものだけ、契約と管理部門の確認に沿って
- 成果は返信率ではなく段と「社内に残ったもの」で見て、型と台帳は最初から社内の置き場に置き、戻す順番を決めておく

## よくある質問

### 社内に読んで書く人がいないので、一文も代行に頼みたいです

条件付きで頼めます。送り主本人が一文を読んで了承してから送る、募集記事の場面とトーンの見本を渡す、期間を決める、の3つは外しません。それでも、送る数を減らして社内で書くほうが、面談でずれず、社内に書き方が残ります。まず、週に一度の短い枠で社内の人が読めないかを確かめてから、代行に頼む範囲を決めます。

### 代行の契約を終えたら、運用が止まってしまいました

型と台帳が代行の中にあった可能性があります。代行に引き継ぎの一覧と、型・台帳・記録の引き渡しを頼みます。それが無ければ、募集記事から型を作り直し、管理画面の送信履歴から台帳を起こします。再開の手順は[スカウト運用が止まったときの再開方法](/media/wt-scout-saikai/)で書きました。次に代行を使うときは、最初から社内の置き場に置く形で始めます。

### スカウトの運用代行は、御社に頼めますか

頼めます。当社は、絞り込み、型と見本、台帳の設計と集計、KPIの表、週と月の見直しの材料、返信の型、面談の型、引き継ぎの記録を担えます。読んで一文を書くこと、返信対応、面談、上司との合意は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
