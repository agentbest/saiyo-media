税理士・会計事務所、社労士事務所、弁護士事務所、司法書士・行政書士事務所、特許事務所が、Wantedlyで採用する。士業事務所の採用は、所長と数人から十数人の少人数で、採るのは資格の受験生（税理士の科目合格者、社労士や司法書士の受験生）、未経験の補助者、有資格者で、候補者は「勉強と両立できるか」「繁忙期（確定申告、決算、年度更新）の実態」「所長の考えと人柄」「顧客の規模と業種」「独立を認めるか」を確かめている。事務所の募集記事は、求人票しか書いたことがない所長が書くと「資格要件と業務内容の羅列」になり、Wantedlyの候補者が読みに来る「所長がなぜこの事務所を始めたか」と「顧客の何かが決まった日」が書かれていない。**結論から言うと、士業事務所のWantedlyは、募集記事を求人票にせず、会社ページの「なぜ」を所長が本人の言葉で書き、募集記事の「こんなことやります」を「顧客の〇〇が決まった日」の場面で書きます。勉強との両立と繁忙期の実態、独立を認めるかどうかを、隠さず募集記事に置きます。所長が「なぜ」を話せるかと、繁忙期の外に返信と面談の枠を取れるかを先に確かめてから始め、スカウトは「勉強を続けている・人の困りごとを片づけた」の記述で、繁忙期の外に送ります。** この記事では、士業事務所の採用構造とWantedlyとの相性、会社ページと募集記事の見せ方、ストーリーとスカウトの運用設計、繁忙期の外の枠、社内の分担を整理します。募集記事の基本は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)、会社ページの基本は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。数値と料金は書きません。

## 士業事務所の採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| 税理士・会計事務所 | 科目合格者と未経験の補助者を採る。繁忙期がはっきりしている。顧客は中小企業 | 「なぜ」と「顧客の決算が終わった日」の場面が書ける。勉強との両立を隠さず |
| 社労士事務所 | 受験生と未経験を採る。手続きと相談。年度更新と算定の繁忙期 | 「顧客の〇〇の相談が片づいた日」の場面で。手続きの実態を隠さず |
| 弁護士・司法書士・行政書士事務所 | 有資格者と事務職を採る。所長の専門で顧客が決まる | 所長の専門と「なぜ」で。事務職の募集を分ける |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| 募集記事が求人票（資格要件、業務の羅列）になる | 「なぜ」を読みに来た候補者に読まれない | 「なぜ」と「決まった日」の場面で書く |
| 少人数で、所長の人柄がすべて | 所長が書けないと、記事が空になる | 所長が「なぜ」を話せるかを先に確かめる |
| 勉強との両立と繁忙期が、候補者の最大の関心 | 隠すと、面談で分かり、入所後に離れる | 両立と繁忙期の実態を募集記事に |
| 独立を認めるか、認めないか | 書かないと、独立を考える候補者が来ない、または黙って辞める | 事務所の方針を一文で |
| 所長が一人で運用し、繁忙期に返信が止まる | 「話を聞きに行きたい」の後に返信がなく、候補者が離れる | 繁忙期の外に返信と面談の枠を取る |

## 会社ページと募集記事の見せ方｜求人票ではなく、「なぜ」と「決まった日」

- **会社ページの「なぜ」を、所長が本人の言葉で**：「〇〇の顧客の△△を見て、独立した」「□□の相談を受けたときに、こういう事務所にしようと決めた」。「地域に貢献」「お客様第一」の一語で済ませない
- **「なにを」は、顧客の規模と業種で一言で**：「〇〇の規模の△△の会社の、□□を扱う事務所」。「税務会計全般」で済ませない
- **募集記事の「こんなことやります」を、顧客の何かが決まった日の場面で**：「〇〇の顧客の決算で、△△を見つけて、□□を提案した日」「〇〇の相談が来て、△△を調べて、□□で片づいた日」。業務の羅列にしない
- **勉強との両立を、隠さず**：「繁忙期は〇〇で、その時期の勉強は△△。試験の前は□□の形」。数値は実態で。この記事では書かない
- **繁忙期の実態を、事実で**：「確定申告の時期は〇〇、決算は△△」。「ワークライフバランス重視」で埋めない
- **独立を認めるかを、一文で**：「独立する人を歓迎する」「独立は前提にしていない」のどちらかを、事務所の方針として
- **資格要件は、「こんな人」の中で経験として**：「科目合格者、または勉強を続けている人」。要件の羅列ではなく、「勉強を続けている・人の困りごとを片づけた・数字を扱った」の記述で

「こんなことやります」の書き方は[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)、「なぜやるのか」は[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。士業事務所の所長から、「募集記事には、資格要件と業務内容と待遇を正確に書けばよい」と言われることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、Wantedlyの候補者は求人票を読みに来ているのではなく、「この事務所の所長は、なぜこの事務所を始めたか」「この事務所で働くと、どんな日があるか」を読みに来ていて、資格要件と業務の羅列は、開かれても「どこの事務所でも同じ」として閉じられます。士業事務所は、業務の中身が同業と同じで、違いは所長の考えと顧客と一日にしかなく、それは求人票に書けません。当社が所長にお願いしているのは、募集記事を書く前に、「なぜ独立したか」「なぜこの規模の、この業種の顧客か」「先週、顧客の何が決まったか」を話してもらうことです。

## ストーリーで、所長と若手の「なぜ」と「一日」を

- **所長のストーリーは、「なぜ独立したか」を場面で**：「〇〇の事務所で△△の顧客を見て、□□と思った日」。経歴の羅列ではなく
- **若手のストーリーは、「勉強と両立した一年」を本人の言葉で**：「繁忙期は〇〇で、勉強は△△の時間に。試験の前に所長が□□した」。両立の実態を本人が
- **顧客の何かが決まった日を、一つ**：「〇〇の顧客の決算で、△△を見つけた日」「〇〇の相談が□□で片づいた日」。守秘の範囲で、業種と規模で
- **繁忙期の一日を、隠さず**：「確定申告の時期の〇〇の一日」。「大変だが、こう回している」を場面で

ストーリーの基本は[Wantedlyのストーリーの基本](/media/wt-story-kihon/)、若手の入社後の書き方は[Wantedlyの入社後ストーリーの書き方](/media/wt-story-nyusha/)で書きました。

## 繁忙期の外に、返信と面談の枠を先に取る

- **繁忙期のカレンダーを、先に押さえる**：確定申告、決算の集中する月、年度更新と算定、税務調査の時期。この時期は所長が返信と面談に出られない
- **「話を聞きに行きたい」への返信の枠を、繁忙期の外に**：返信が止まると、候補者は離れ、事務所の側で「Wantedlyは効かない」で終わる
- **募集の公開とスカウトを、繁忙期の外に置く**：繁忙期に公開しても、返信できない
- **所長が返信できない時期は、番頭役か事務の人が一次返信をする**：「所長は〇〇の時期で、△△に面談できます」と先に伝える
- **面談は、繁忙期の外の短い枠で固定する**：所長の枠を先に決め、その枠に候補者を入れる

返信が遅れたときの形は[Wantedlyのスカウトに返信が来ないときの見直し](/media/wt-scout-henshin-nai/)、面談につながらないときは[Wantedlyの面談につながらないときの見直し](/media/wt-mendan-tsunagaranai/)で書きました。

## スカウトの設計

- **絞るのは、「勉強を続けている・人の困りごとを片づけた・数字を扱った」の記述**：「資格に興味」「安定志望」で絞らない。科目合格者と受験生は、勉強を続けていることがプロフィールに出ている
- **文面は、所長の名義で、「なぜ」を一文と、顧客の一文で**：「〇〇の規模の△△の会社の□□を扱う事務所で、私が独立したのは〇〇のため。あなたの△△を読んで」
- **勉強との両立と繁忙期を、文面に**：「繁忙期は〇〇で、勉強は△△の形。独立は□□」
- **繁忙期の外に送る**：送った後の返信が繁忙期に重なると、候補者が離れる。[Wantedlyのスカウトを送る時期](/media/wt-scout-timing/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 所長が「なぜ独立したか」「なぜこの顧客か」「先週、顧客の何が決まったか」を話す | 所長 |
| 話した内容を、会社ページの「なぜ」と募集記事の場面に整える | 番頭役か事務の人（整えるのは外に出せる） |
| 勉強との両立、繁忙期の実態、独立を認めるかを決めて書く | 所長 |
| 若手が「勉強と両立した一年」を話す | 入所してまもない若手 |
| 繁忙期のカレンダーを押さえ、返信と面談の枠を決める | 所長と番頭役 |
| 繁忙期の一次返信をする | 番頭役か事務の人 |
| スカウトを所長の名義で、繁忙期の外に送る | 所長（絞る作業は外に出せる） |
| 面談で、両立と繁忙期と独立の方針を伝える | 所長 |

運用代行や代理店が支えられるのは、「なぜ」を引き出す質問の型、記事の型、場面の整え方、繁忙期の外の枠の設計、スカウトの絞る作業までで、「なぜ」を話すこと、両立と繁忙期の実態の開示、独立の方針の決定、若手が話すこと、面談は事務所が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。士業事務所の所長から、「募集記事を書いて公開したいので、文章を見てほしい」と相談されることがあります。当社は、記事より先に、繁忙期のカレンダーを押さえて、「話を聞きに行きたい」への返信と面談の枠を繁忙期の外に取ることをお願いしています。士業事務所は所長が一人で運用することが多く、確定申告や決算や年度更新の時期に返信が止まり、その時期に来た「話を聞きに行きたい」は、返信がないまま候補者が離れます。Wantedlyは、記事を公開した後の返信と面談で採用が決まる媒体で、記事を整えても、返信の枠がなければ、候補者は面談まで来ません。順番は、繁忙期を押さえ、返信と面談の枠と、繁忙期の一次返信を誰がするかを決め、そのうえで記事を公開し、スカウトを繁忙期の外に送ることです。枠が先にあると、「Wantedlyは効かない」ではなく「繁忙期の外で回る」形になります。

## まとめ

- 士業事務所は少人数で所長の人柄がすべてで、採るのは受験生・科目合格者・未経験の補助者・有資格者。候補者は勉強との両立、繁忙期の実態、所長の考え、顧客の規模と業種、独立を認めるかを確かめている
- 募集記事を求人票（資格要件と業務の羅列）にしない。会社ページの「なぜ」を所長が本人の言葉で、募集記事の「こんなことやります」を「顧客の〇〇が決まった日」の場面で。業務の中身は同業と同じで、違いは所長の考えと顧客と一日にしかない
- 勉強との両立と繁忙期の実態、独立を認めるかを隠さず募集記事に。ストーリーで所長の「なぜ独立したか」と若手の「勉強と両立した一年」を本人の言葉で
- 繁忙期のカレンダーを先に押さえ、返信と面談の枠を繁忙期の外に取り、繁忙期の一次返信を番頭役か事務の人が。記事より枠が先
- スカウトは所長の名義で「なぜ」と顧客の一文を、「勉強を続けている・人の困りごとを片づけた」の記述で絞り、繁忙期の外に送る

## よくある質問

### 募集記事には、資格要件と業務内容と待遇を正確に書けばよいですか

Wantedlyの候補者は、求人票ではなく「所長がなぜこの事務所を始めたか」「どんな日があるか」を読みに来ていて、資格要件と業務の羅列は「どこの事務所でも同じ」として閉じられます。所長が「なぜ独立したか」「なぜこの顧客か」「先週、顧客の何が決まったか」を話し、それを会社ページと募集記事の場面にします。資格要件は「勉強を続けている人」のように、「こんな人」の中で経験として書きます。

### 繁忙期に返信ができず、候補者が離れてしまいます

記事より先に、繁忙期のカレンダーを押さえ、「話を聞きに行きたい」への返信と面談の枠を繁忙期の外に取ります。繁忙期の一次返信は番頭役か事務の人が「所長は〇〇の時期で、△△に面談できます」と先に伝え、募集の公開とスカウトも繁忙期の外に置きます。枠が先にあると、繁忙期の外で回る形になります。

### 士業事務所のWantedlyの設計は、御社に相談できますか

できます。当社は、「なぜ」を引き出す質問の型、記事の型、場面の整え方、繁忙期の外の枠の設計、スカウトの絞る作業を支えられます。「なぜ」を話すこと、両立と繁忙期の実態の開示、独立の方針の決定、若手が話すこと、面談は、事務所が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
