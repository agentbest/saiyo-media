採用KPIの月次のレビューをしている。ところが、数字の表を眺めて未達の理由を一つずつ説明し、気付いたことを五つ出して全部やろうとし、前月に変えたことの結果は確認せず、関係者を多く集めて一時間半かけ、翌月も同じ表を見ている。**結論から言うと、月に一度の場で決めるのは「翌月に変えることを一つ」だけで、数の説明で終わらせません。見るのは「近い人が面談まで来た数（入口ごと）」「段ごとの日数の前年比」「文面と名義と掲載の効果」の三つで、四十五分です。数が未達の説明に時間を使うと、変えることが決まらないまま終わります。変えることは一つに絞り、型と名義を同時に変えません。前月に変えたことの結果を、場の最初に確認します。出席は人事と採用の責任者と、月によって現場の責任者です。** 週次の型は[採用KPIの週次レビュー](/media/kh-kpi-shuukan/)で書きました。この記事は、月次の場の型を書きます。

## この作業の目的｜月次を、「数の説明の場」から「翌月に変えることを決める場」にする

月次の場で数を並べると、未達の数について説明が始まります。説明は必要な場面もありますが、説明だけで時間が尽きると、翌月に変えることが決まりません。変えることが決まらない月が続くと、翌年も同じ数字が並びます。

目的は、月次の場を「今月の数の説明」から「翌月に変えることを一つ決める」に変え、前月に変えたことの結果を確認する場にすることです。

## 月次レビューで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 数の説明で終わる | 未達の理由が並び、変えることが決まらない |
| 未達の理由を一つずつ並べる | 時間が尽きる。理由は説明より、直す場所の特定に使う |
| 変えることを複数決める | 全部が中途半端になり、どれが効いたか分からない |
| 前月に変えたことの結果を確認しない | 変えたことが積み上がらない |
| 人を集めすぎる | 日程が合わず、月をまたぐ |
| 資料が厚い | 作る手間が増え、見る時間が減る |

共通するのは、月次を「数の報告の場」として作っていて、「変えることを決めて、前月の結果を確認する場」として作っていないことです。

## 月次で見る、三つ

| 見るもの | 何を確かめるか |
|---|---|
| 近い人が面談まで来た数（入口ごと） | 逆算した必要数に届く見込みか。どの入口が効いているか。[採用KPIの基本](/media/kh-kpi-kihon/) |
| 段ごとの日数の前年比 | 週次で直した段が戻っていないか。前年より延びている段はどこか |
| 文面と名義と掲載の効果 | 前月に変えた型・名義・掲載の、近い人の面談数への影響。[スカウトのKPI](/media/kh-kpi-scout/)、[掲載のKPI](/media/kh-kpi-keisai/) |

三つだけです。承諾した数と辞退の理由は、内定を出している期間だけ足します。

### エージェントベストの見解

相談で最も多い思い込みは、「月次のレビューは、今月の結果を報告して、課題を洗い出す場だ」というものです。当社は3媒体すべての販売パートナーとして、運用の場に同席することがありますが、課題を洗い出す月次は、毎月五つの課題が出て、どれも着手されずに翌月も同じ五つが出ます。課題が多いのは、状況が悪いからではなく、洗い出す形になっているからです。当社が最初にお願いするのは、月次の出口を「翌月に変えることを一つ」に固定することです。一つに絞ると、その場の議論は「どれを選ぶか」になり、選ばれなかった候補は「来月の候補」として残ります。翌月の場の最初に、前月に変えたことの結果を確認すると、変えたことが積み上がります。一年で十二回変えれば、十二箇所直ります。五つ出して着手しない月が十二回続くと、一箇所も直りません。月次の価値は、洗い出す量ではなく、積み上がる数で決まります。

## 四十五分の、進め方

1. **前月に変えたことの結果を確認する**（十分）：変えたことと、近い人の面談数の前後
2. **近い人の面談数（入口ごと）を見る**（十分）：届く見込みか。どの入口が効いているか
3. **段ごとの日数の前年比を見る**（五分）：週次で直した段が戻っていないか
4. **文面と名義と掲載の効果を見る**（十分）：前月に変えた型の影響
5. **翌月に変えることを、一つ決める**（十分）：候補を三つまで出して、一つを選ぶ
6. **選ばなかった候補を、来月の候補として残す**：捨てない

出るのは「翌月に変えること一つ」と「誰が、いつまでに」です。記録はその二行で足ります。

## 変えることを、一つに絞る

- **候補を、三つまで出す**：多いと選べない
- **選ぶ基準は「翌月に変えられる」**：来年でないと変えられないものは、別の場（年に一度）に回す
- **型と名義を、同時に変えない**：どちらが効いたか分からなくなる。[スカウトのKPI](/media/kh-kpi-scout/)
- **掲載と文面を、同時に変えない**：入口が二つ動くと、比べられない
- **変えたことを、記録する**：いつ、何を変えたか。翌月の最初に確認するため
- **選ばなかった候補を、来月の候補として残す**：次の月に繰り上がる

一つに絞ることは、課題を無視することではなく、順番を付けることです。

## 経営への報告との、分け方

| 場 | 相手 | 出すもの |
|---|---|---|
| 月次のレビュー | 人事と採用の責任者、月によって現場 | 三つの数と、翌月に変えること一つ |
| 経営への報告 | 経営 | 採用した数の見込みと目標との差、直す場所の一文。月次の資料をそのまま使わない |
| 期の途中の場 | 経営と採用の責任者 | 届く見込みと、入口の配分の変更の相談 |

月次のレビューの資料を、そのまま経営に出すと、数の説明の場になります。経営に出すのは、見込みと差と一文です。

## 出席者

- **人事**：数を出し、前月の結果を確認する
- **採用の責任者**：変えることを一つ決める
- **現場の責任者**：変えることが「名義」「面談の枠」「掲載の中身」に関わる月だけ
- **代行**：入っているなら、文面と掲載の効果の回で
- **経営**：呼ばない。別の場で

三人以内に収める月と、現場を呼ぶ月を分けます。

## 媒体ごとに、変わる点

- **OfferBox**：文面の型と名義の効果が、月次で最も見る項目。前月に変えた型の結果が、その月に出る。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)
- **Wantedly**：記事ごとの効果。記事は増えるので、どの記事が近い人の面談につながったかを月次で
- **ワンキャリア**：掲載と企業ページの更新の効果。体験談は直せないので、掲載で答える形の効果を見る

三つとも、月次で見る三つは同じで、三番目（文面・名義・掲載の効果）の中身が違います。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 月次の日程を、月初に固定する | 採用の責任者 |
| 三つの数を出す | 人事。台帳から |
| 前月に変えたことと結果を用意する | 人事 |
| 候補を三つまで出す | 人事 |
| 一つを選び、担当と期限を決める | 採用の責任者 |
| 選ばなかった候補を残す | 人事 |
| 経営への報告を別に作る | 採用の責任者 |

運用代行や代理店が支えられるのは、数を出す作業、候補の提案、記録の型までで、一つを選ぶこと、経営への報告は社内が担います。

### エージェントベストの見解

月次レビューで、当社が先にお伝えしているのは、「前月に変えたことの結果を最初に確認する形にすると、変えることの質が上がる」ということです。結果を確認しない月次では、変えることを決めても、翌月には話題が変わっていて、効いたかどうかが誰も分かりません。効いたかが分からないと、次に変えることも勘で決まります。申し込んだあとに月次が数の説明に戻る会社に共通するのは、この確認が無いことです。当社が案内するのは、月次の場の最初の十分を、前月に変えたことの結果に固定することです。「先月は文面の型を〇〇に変えた。近い人の面談数は前月△、今月□」。この十分があると、決めることが慎重になり、「比べられる形で変える」という意識が付きます。一年続けると、変えたことと結果の記録が十二件たまり、翌年の担当者に渡せる知見になります。月次の価値は、数の共有ではなく、この記録です。

## まとめ

- 月次で決めるのは「翌月に変えることを一つ」だけ。数の説明で終わらせない
- 見る三つは「近い人が面談まで来た数（入口ごと）」「段ごとの日数の前年比」「文面と名義と掲載の効果」。四十五分
- 場の最初の十分を、前月に変えたことの結果の確認に固定する
- 候補は三つまで出して一つを選び、選ばなかった候補は来月の候補として残す。型と名義を同時に変えない
- 経営への報告は、月次の資料をそのまま使わず、見込みと差と一文で出す

## よくある質問

### 課題が多いのに、一つしか変えないのは遅くないですか

五つ出して着手しない月が続くより、一つ変えて結果を確認する月が続くほうが、一年で積み上がります。一年で十二箇所直ります。急ぐ場合は、週次で直せるもの（返信の体制・日程の候補）を週次に回し、月次では文面・名義・掲載のように比べる必要があるものを扱います。

### 前月に変えたことの結果が、一か月では出ません

出ない場合は、「まだ分からない」と記録して、翌月にもう一度確認します。その月は、前月の変更を続けたまま、新しい変更をしません。結果が出るまで待つことも、月次の決定の一つです。二か月続けても分からないなら、変えた箇所が効かない箇所だったと判断して、次に移ります。

### 月次レビューの型は、御社に相談できますか

できます。当社は、数を出す作業、候補の提案、記録の型を支えられます。一つを選ぶこと、経営への報告は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、月次で見る三つの形を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
