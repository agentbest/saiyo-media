ワンキャリアで新卒の機械設計を募集したとき、最初にぶつかるのは「『機械設計』と掲載したのに、機械系の学生しか来ないか、来ても面接で『何を設計するのですか』『図面は誰が見るのですか』『現場には行きますか』と聞かれ、答えた内容が体験談で『設計と言いながら図面の修正だった』『先輩が忙しくて図面を見てもらえなかった』と書かれる」という問題です。**結論から言うと、ワンキャリアの機械設計の掲載は、「機械設計」の名前ではなく「何を設計するのか、設計のどの段階か、図面を誰が見て誰が直すか、試作と現場との距離、最初の年に何を任せ、CADは入社後に覚えるか」を、学生が体験談で読む前に企業ページと募集に書き、設計の話の聞き方を揃えて面接をします。** メーカーとしての設計は[メーカーの新卒採用でワンキャリアを使うときの設計](/media/oc-maker-katsuyou/)で書きました。この記事は機械設計の職種に絞り、掲載とスカウトと選考をつなげて書きます。

## 機械設計志望の学生が、体験談で読んでいること

学生は、企業ページを読む前に、機械設計の選考の体験談と、その会社の先輩の話を読んでいます。大手メーカーの体験談は技術系総合職の選考が多く、「配属で何を設計するかが決まる」と書かれているため、学生は「入る前に何を設計するか分かる会社」を探しています。

| 読んでいること | 掲載への意味 |
|---|---|
| 何を設計するのか | 製品の全体か、部品か、治具か、設備か。「機械設計」の名前では分からない |
| 設計のどの段階か | 構想か、詳細か、図面の修正か。最初の年はどの段階か |
| 図面を誰が見て、誰が直すか | 先輩が見るか、見る時間があるか。直す観点があるか。体験談で最も書かれる |
| 試作と現場との距離 | 自分の図面が試作になるまでの時間。現場に行くか。組み立てを見るか |
| 最初の年に何を任されるか | 図面の修正か、部品の一つか、誰が見るか |
| CADは入社後に覚えるか | 使うCADが何か。学生のときに使っていなくてもよいか |
| 機械設計で入った先輩の実態 | 最初の年に何を設計し、何を直され、いま何を担当しているか |

「図面を誰が見て、誰が直すか」と「何を設計するのか」が、機械設計の体験談で最も読まれ、企業ページで最も書かれない項目です。

## 掲載に書くこと｜何を設計するか、段階、図面の見方、試作との距離、最初の年

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「機械設計」ではなく「〇〇の製品の部品設計」「△△の設備の機構設計」。何を設計するか |
| 何を設計するか | 「〇〇の製品の、□□の部品。最初に任せるのは部品。製品の全体は△年目から」 |
| 設計のどの段階か | 「最初の年は詳細設計と図面の修正。構想は△年目から」。修正が多いなら、そう書く |
| 図面を誰が見るか | 「図面は先輩が見て、観点は〇〇。週に□回、見る時間を決めている」。見る時間がないなら、正直に |
| 試作と現場との距離 | 「自分の図面が試作になるまで〇週間。組み立ては現場で自分の目で見る」 |
| 最初の年 | 「最初の〇か月は先輩の図面の修正。△△か月目に部品を一つ、先輩のレビュー付きで」 |
| CADの扱い | 「使うのは□□。学生のときに使っていなくてよい。最初の〇か月で覚える」 |
| 先輩の話 | 最初の年に何を設計し、何を直されたか。盛らない |

企業ページには図面の見方と試作との距離を、募集には何を設計するかと段階と最初の年を、と分担します。

### エージェントベストの見解

機械設計の募集で、掲載を直した後に起きることを、当社は先にお伝えしています。当社は3媒体すべての販売パートナーとして、ワンキャリアの機械設計の掲載と選考を見ていますが、「何を設計するか、図面を誰が見るか、最初の年は図面の修正」と正直に書くと、エントリーは減ります。減るのは、「設計」の言葉から製品の全体を構想する像を持っていた学生です。その一方で、面接で「思っていたのと違う」が減り、内定後の辞退が減り、入社後に「図面の修正ばかり」と離れる人が減ります。会社によっては、エントリーが減ったことを見て「掲載が悪くなった」と判断し、「機械設計」の名前に戻してしまいます。戻すと、エントリーは戻りますが、辞退と離職も戻ります。当社が案内するのは、エントリーの数ではなく、「面接で『思っていたのと違う』と言われた回数」と「内定後の辞退の数」で、掲載を直した効果を見ることです。数を見る場所を先に決めてから、掲載を直します。

## 機械設計志望の学生の見つけ方

機械系の学科だけで絞ると、設計の行動を持つ学生を落とします。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 学科 | 機械、それ以外の工学系 | あればよい条件。機械系だけで絞らない |
| 作って壊れた経験 | 「〇〇を作ったら△△が壊れ、原因を調べて直した」 | 設計の行動。「ものづくりが好き」より |
| 制約の中で決めた経験 | 「予算と重さの制約で□□を選んだ」 | 設計は制約の中で決める仕事 |
| 図面や3Dを描いた経験 | 「サークルで〇〇の図面を描いた」「3Dで△△を作った」 | あれば強い。無くても外さない |
| 加工や組み立てを見た経験 | 「自分で加工した」「組み立てて合わなかった」 | 試作と現場との距離と重なる |
| 人に説明した経験 | 「設計の理由を先輩に説明した」 | 図面を見てもらうときに理由を話せるか |

「作って壊れて直した」「制約の中で決めた」を書いている学生が、機械設計と重なります。四つの行動は[OfferBoxで機械設計志望の学生を見つける検索の考え方](/media/ob-kikai-sekkei-target/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

理系向けの文面の型は[ワンキャリアで理系学生にスカウトを送る文面](/media/oc-scout-rikei/)で書きました。機械設計では、次の点を足します。

- **相手の一文は、作って壊れた経験で**：「〇〇を作ったら△△が壊れ、原因を調べて直したと書かれていたのを読んで」。「ものづくりが好き」を褒めない
- **何を設計するかを、一文で**：「最初に任せたいのは、〇〇の製品の□□の部品の設計です。製品の全体は△年目からです」
- **図面の見方を、一文で**：「図面は先輩が週に□回見て、観点は〇〇です」
- **試作との距離を、一文で**：「自分の図面が試作になるまで〇週間で、組み立ては現場で見ます」
- **CADを、一文で**：「使うのは□□で、学生のときに使っていなくても最初の〇か月で覚えます」
- **送り主は、機械設計で入った先輩**：人事の名前で「ものづくりに興味のある方」と送らない

## 選考への接続｜設計の話の聞き方を揃える

- **設計の話の聞き方の型を、一つに決める**：「何を作ったかより、壊れたとき何をしたか、制約の中で何を選んだか、なぜそう選んだかを聞く」。面接官が変わっても同じ
- **図面の見方を、聞かれる前に話す**：「図面は先輩が見る。観点は〇〇。見る時間は週に□回」。見る時間が取れていないなら、そう言う。面接で「手厚く見る」と言い、入社後に見てもらえないと、体験談に書かれる
- **最初の年が図面の修正なら、面接で言う**：「最初の〇か月は修正です。修正で図面の癖を覚えます」。修正の意味を話す
- **CADの経験で落とさない**：「学生のときに使っていなくてよい」と書いたなら、面接で聞かない
- **内定後に、図面と試作を見せる**：先輩の図面が試作になった前後と、組み立ての現場を。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

| 作業 | 誰が |
|---|---|
| 何を設計するか、段階、図面の見方、試作との距離、最初の年、CADの扱いを決める | 設計部門の責任者 |
| 企業ページの機械設計の記述 | 人事が、責任者と先輩に聞いて書く |
| 図面を見る時間を確保する | 設計部門の責任者。書いたとおりに見る時間を先に決める |
| 先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「修正だった」「見てもらえなかった」と書かれていないか） |
| スカウトの一文 | 先輩 |
| 面接 | 責任者と先輩。聞き方の型を揃えて |

運用代行や代理店が支えられるのは、掲載の型、図面の見方を文で書く直し方、聞き方の型の整理、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、設計の内容の決定、図面を見る時間の確保、面接、先輩の話は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「機械設計は機械系の学生に決まっているから、機械系の学科で絞って『機械設計』で出せばよい」というものです。ワンキャリアで機械設計を探す学生のうち、機械系の学科は一部で、電気系や物理系や、それ以外の工学系で「作って壊れて直した」経験を持つ学生が多くいます。その学生は、「機械設計」の名前だけの掲載を見ると、「機械系でないと落ちる」と思ってエントリーしません。当社が掲載を見るとき、「機械系の学科に限る」と書かれていないのに、機械系しか来ていない会社は、企業ページに「機械系以外から入った先輩」の話が無く、スカウトを機械系にしか送っていないことが多くあります。逆に、「機械系以外から入った人が〇人。最初の〇か月で図面とCADを覚える」と書き、電気系や物理系にもスカウトを送った会社は、体験談に「学科は問われなかった」と書かれ、次の年に機械系以外の学生が来ます。学科で絞るのは、探す相手を自分で減らすことです。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「機械設計」の名前だけで書く | 製品の全体を構想する像で来て、「修正だった」と書かれる | 何を設計するか、段階、最初の年を書く |
| 図面を誰が見るかを書かない | 「見てもらえなかった」と書かれる | 見る人と観点と時間を書き、時間を先に確保する |
| 機械系の学科だけで絞る | 作って直した経験を持つ学生を落とす | 壊れて直した記述で読む。学科以外にも送る |
| CADの経験で落とす | 「使っていなくてよい」と書いたのに落とすと、体験談に書かれる | 面接で聞かない |
| エントリーが減ったので名前に戻す | 辞退と離職も戻る | 辞退の数で効果を見る |

## まとめ

- 機械設計志望の学生は、体験談で「何を設計するか・どの段階か・図面を誰が見て誰が直すか・試作と現場との距離・最初の年・CADは入社後に覚えるか・先輩の実態」を読み、入る前に何を設計するか分かる会社を探す
- 掲載には、何を設計するか、段階、図面を見る人と観点と時間、試作までの時間と現場に行くか、最初の年、CADの扱い、機械系以外から入った人の有無を書く
- 掲載を正直に直すとエントリーは減る。効果は「思っていたのと違う」の回数と辞退の数で見て、名前に戻さない
- 学生は、学科ではなく「作って壊れて直した」「制約の中で決めた」の記述で見つけ、機械系以外にも送る
- 設計の話の聞き方の型を一つに決め、図面の見方を面接で先に話し、書いたとおりに見る時間を確保する

## よくある質問

### 最初の年は図面の修正ばかりです。書くと学生が来なくなりませんか

製品の全体を構想する像の学生は来なくなりますが、その学生は入社後に「修正ばかり」と離れる学生です。「最初の〇か月は先輩の図面の修正。修正で図面の癖と加工の制約を覚え、△△か月目に部品を一つ任せる」と、修正の意味と、次に何を任せるかを書きます。修正の中で気づいて直した先輩の話を添えると、「修正」の意味が学生に伝わります。

### 先輩が忙しくて、図面を見る時間が取れません

取れないなら、掲載に「手厚く見る」と書かないことです。「図面は先輩が週に□回、時間を決めて見る」と書くなら、書く前に設計部門の責任者がその時間を確保します。確保できないなら、「見る時間は不定期で、聞けば答える」と正直に書き、面接でもそう言います。書いたことと入社後が違うと、体験談に「見てもらえなかった」と書かれ、次の年の学生が離れます。

### 機械設計の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、図面の見方を文で書く直し方、聞き方の型の整理、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。設計の内容の決定、図面を見る時間の確保、面接、先輩の話は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
