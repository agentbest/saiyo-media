新卒採用で、OfferBoxと、Wantedlyやワンキャリアやナビサイトを併用している。来年の採用予算をどう配分するか、上司に説明を求められる。ところが、媒体ごとの費用を並べて割り振っても、送る時期に「文面を書く時間も、当日に返す時間もなくて、送れなかった」という形で崩れることが多くあります。**結論から言うと、予算は「費用」と「担当の時間」の二つで置きます。OfferBoxは、送る時期に時間が集中し、その時間の多くは外に出せる媒体です。配分は、採る人数と「こんな人」を決め、「自社で持つ時間」を先に決め、回っている入口に寄せ、費用と代行の範囲は各媒体の現在の条件を確認して置き、見直しは契約の切れ目で行います。** この記事では、予算の二つの側、媒体ごとの費用と時間の性格、OfferBoxの時間の置き方、配分の手順、複数媒体で配分するときの考え方、やりがちな失敗、社内の分担を整理します。母集団形成全体の予算は[母集団形成の予算配分](/media/kh-boshudan-yosan/)、効果の並べ方は[OfferBoxを含む複数媒体の効果を並べて見る方法](/media/ob-heiyou-heiyou-kpi/)で書きました。費用の数値は、この記事では書きません。

## それぞれの役割｜予算は「費用」と「担当の時間」の二つで置く

採用の予算を「媒体の費用の合計」で置くと、時間の予算が抜けます。媒体は、契約しただけでは動きません。学生を検索する、文面を書く、送る、承認に当日返す、面談に出る。この時間を誰がどれだけ出すかが、費用と同じだけ予算です。

| 媒体の型 | 費用の性格 | 時間の性格 |
|---|---|---|
| OfferBox | プランに応じた費用。現在の条件は公式ページで確認 | 検索・文面・送信・当日の返信・面談。送る時期に集中。外に出せる部分が多い |
| Wantedly | プランに応じた費用。公式ページで確認 | 会社ページ・ストーリー・募集記事を書く時間。通年で薄く。社員が話す中身は外に出せない |
| ワンキャリア | 掲載やイベントに応じた費用。公式ページで確認 | 企業ページの整備、イベントの準備と当日、エントリー対応。時期に集中 |
| ナビサイト | 掲載の枠と期間に応じた費用。各媒体で確認 | 入力、エントリー対応、説明会の運営。開始から締切に集中 |

費用は媒体側の条件で決まり、時間は自社の体制で決まります。OfferBoxは、この表の中で「時間の多くを外に出せる」媒体です。検索・文面の下書き・送信・一次の返信は、運用代行に出せます。出せない時間は、「こんな人」の決定、文面の最終確認、承認への当日の返信の判断、面談です。

## OfferBoxの時間の置き方｜自社で持つ時間と、出せる時間

| 時間 | 誰が持つか | 出せるか |
|---|---|---|
| 「こんな人」の一行と、検索条件の決定 | 人事と現場 | 出せない |
| 学生を検索して選ぶ | 人事、または代行 | 出せる |
| 文面の下書き | 人事、または代行 | 出せる |
| 文面の最終確認と名義 | 送る社員 | 出せない |
| 送信 | 人事、または代行 | 出せる |
| 承認への当日の返信 | 人事、または代行（型があれば） | 一次は出せる。面談の日程の判断は自社 |
| 面談 | 送る社員と面接官 | 出せない |
| 面談前の連絡 | 人事、または代行 | 出せる |

- **出せない時間を先に確保する**：送る社員の確認の時間、面談の時間。ここが埋まらないと、出せる時間を外に出しても回らない
- **送る時期に、出せる時間を自社で持てるかを見る**：持てないなら、代行の費用を予算に置く。持てるなら、費用を置かず時間を置く
- **承認への当日の返信は、時間の予算で最も落としやすい**：送る時期は返信が集中する。当日に返せる体制があるかで、送る数の上限が決まる。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
- **代行に出す範囲は、作業と判断で線を引く**：[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)

### エージェントベストの見解

相談で最も多い思い込みは、「OfferBoxは送れば来るので、予算を寄せれば寄せた分だけ採れる」というものです。当社は3媒体すべての販売パートナーとして、予算の配分の相談を受けますが、OfferBoxに費用を寄せた会社で起きるのは、送る数を増やしたのに、承認への返信が翌日になり、面談の日程が埋まらず、承認した学生が他社に決まる、という形です。送る数の上限は、費用ではなく、「承認に当日返せる数」と「面談に出られる数」で決まります。予算を寄せるなら、費用と一緒に、送る時期の当日の返信と面談の時間を、担当者と送る社員の予定に先に置きます。その時間が出せないなら、送る数を減らすか、出せる時間を代行に出すかのどちらかで、費用だけを増やす選択肢はありません。当社がOfferBoxの運用代行を受けるときも、最初に確かめるのは、面談に出られる人と時間です。

## 配分の手順

1. **採る人数と「こんな人」を先に決める**：職種ごとに、何人を、どんな学生で。これがないと、どの媒体に寄せるかが決まらない
2. **自社で持つ時間を先に出す**：人事が何人で、送る時期に週に何時間を採用に使えるか。送る社員と面接官が、面談にどれだけ出られるか
3. **回っている入口を確認する**：昨年の台帳で、「こんな人」に近い学生が面談まで来た入口はどれか。回っている入口に寄せる
4. **OfferBoxの出せる時間を、自社で持つか代行に出すかを決める**：持てないなら代行の費用を、持てるなら時間を予算に
5. **費用は、各媒体の公式ページで現在の条件を確認して置く**：昨年の請求額をそのまま使わない。プランと条件は変わる
6. **見直しは、契約の切れ目で行う**：途中の月に「効かない」で止めない。切れ目までは、止まっている段を直す

媒体を何本持つかは、予算ではなく担当の時間で決めます。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)で書いた考え方と同じです。予算が少ないときは、費用ではなく運用の幅を削ります。[予算が少ない会社のOfferBoxの使い方](/media/ob-yosan-sukunai/)

## 複数媒体で配分するときの考え方

- **回っている入口を先に埋める**：昨年、近い学生が面談まで来た入口に、時間と費用を先に置く。新しい媒体は、余った時間で
- **時期が重なる媒体を、同じ担当者に置かない**：OfferBoxの送る時期と、ナビの時期が重なると、一人では回らない。重なるなら、OfferBoxの出せる時間を外に出す
- **卒年をまたぐことを見込む**：OfferBoxは学年で送る相手が変わる。年度の予算と、卒年の運用がずれることがあるので、どの卒年の分かを予算の欄に書く
- **「一人あたりの費用」で配分しない**：単価は、送る時期と人数で大きく変わる。一年の台帳が揃ってから、参考として見る。[媒体別の採用単価の見方](/media/hikaku-baitai-tanka/)
- **やめる判断は、配分の場ではなく、契約の切れ目で**：[媒体をやめる判断基準](/media/hikaku-baitai-tettai/)

3媒体の役割は違います。OfferBoxは企業から送り、Wantedlyは会社を読んで来て、ワンキャリアは学生が情報とクチコミで来ます。役割が違う媒体を、費用の大小で並べて削ると、来る学生の状態が偏ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 費用の合計だけで予算を組む | 送る時期に時間が足りず、承認への返信が翌日になる | 時間の欄を先に書く |
| 昨年の請求額をそのまま置く | プランや条件が変わっていて、ずれる | 公式ページで現在の条件を確認 |
| OfferBoxに費用を寄せて送る数を増やす | 返信と面談が追いつかず、承認した学生が他社へ | 当日返せる数と面談の数から送る数を決める |
| 代行に出す範囲を決めずに費用を置く | 作業も判断も出して、自社に何も残らない | 作業と判断で線を引く |
| 途中の月の数字で配分を変える | 送る時期の偏りで、回っていた入口を削る | 見直しは契約の切れ目で |

最も多いのは、三つ目です。費用を寄せた安心で送る数を増やし、承認のあとの時間が足りなくなります。時間が足りないときの対処は[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 採る人数と「こんな人」を決める | 人事と現場の責任者 |
| 自社で持つ時間を出す | 人事と、送る社員の上司 |
| 昨年の台帳から、回っている入口を確認する | 人事 |
| OfferBoxの出せる時間を、自社で持つか代行に出すかを決める | 人事と責任者 |
| 各媒体の公式ページで現在の条件を確認する | 人事 |
| 時間と費用の配分の案を作る | 人事 |
| 配分の承認、契約の切れ目での見直し | 責任者 |

運用代行や代理店が支えられるのは、媒体ごとの費用と時間の性格の整理、配分の型、時間の見積もり、OfferBoxの出せる時間の代行、3媒体を並べた案の提示までで、採る人数と「こんな人」の決定、自社で持つ時間の合意、配分の承認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「送る時期に、自社で持てる時間」を週の単位で出しておかないと、どの媒体に配分しても効果が出ません。当社はOfferBoxの運用代行を受けているので、代行に出す会社と自社で回す会社の両方を見ていますが、配分が崩れる会社に共通するのは、費用を先に決めて、時間をあとから合わせようとすることです。順番は逆で、送る時期に人事が採用に使える時間、送る社員が文面の確認と面談に出られる時間を先に出し、その時間で回せる送る数を決め、足りない分を代行の費用として置きます。時間から入ると、「送る数を減らして精度を上げる」か「出せる時間を外に出す」かの二択になり、費用から入ると、「費用は使ったのに回らなかった」になります。当社が代行の見積もりを出すときも、費用の前に、自社で持つ時間を聞いています。

## まとめ

- 予算は「費用」と「担当の時間」の二つで置く。費用は媒体側の条件、時間は自社の体制で決まる
- OfferBoxは送る時期に時間が集中し、検索・文面の下書き・送信・一次の返信は外に出せる。出せない時間（「こんな人」の決定、文面の最終確認、面談）を先に確保する
- 送る数の上限は費用ではなく、「承認に当日返せる数」と「面談に出られる数」で決まる
- 配分は、採る人数と「こんな人」→自社で持つ時間→回っている入口→代行に出す範囲→費用は公式ページで確認→契約の切れ目で見直し、の順
- 「一人あたりの費用」で配分しない。3媒体は役割が違うので、費用の大小で削ると来る学生の状態が偏る

## よくある質問

### 上司に「媒体ごとの費用の一覧」で予算を出すように言われています

費用の一覧に、「自社で持つ時間」と「外に出す時間」の列を足して出します。OfferBoxは、「送る時期に週に何時間、誰が持ちます。足りない分は代行に出します」と添えると、費用だけで送る数を決める判断を防げます。時間の列がないと、費用を寄せれば採れるという判断になりやすいです。

### 予算が減ったとき、OfferBoxの代行を切って自社で回すべきですか

切るかどうかは、代行に出していた時間を自社で持てるかで決めます。持てないのに切ると、送る数は同じで返信と面談が追いつかず、承認した学生を失います。持てないなら、送る数を減らして代行の範囲を狭めるほうが、費用と成果の両方で崩れにくいです。[予算が少ない会社のOfferBoxの使い方](/media/ob-yosan-sukunai/)

### 複数媒体の予算配分は、御社に相談できますか

できます。当社は、媒体ごとの費用と時間の性格の整理、配分の型、時間の見積もり、OfferBoxの出せる時間の代行、3媒体を並べた案の提示を支えられます。採る人数と「こんな人」の決定、自社で持つ時間の合意、配分の承認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
