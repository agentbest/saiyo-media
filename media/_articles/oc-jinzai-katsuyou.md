人材紹介、求人広告、派遣、採用支援・RPO、HRテック、地方の人材会社が、新卒採用でワンキャリアを使う。人材サービスの会社は採用のプロで、学生に採用のノウハウを教える側にいるため、自社の企業ページが「採用市場の話」と「業界の説明」で埋まり、説明会が「就活講座」になり、面接が「評価的」に見られる。体験談には「勉強になったが、会社が分からなかった」「面接で見抜かれている気がした」と残り、学生は「人の役に立つ」で来て、法人営業の架電と数字、キャリアアドバイザーの求職者対応の実態で離れる。**結論から言うと、人材サービスのワンキャリアは、企業ページから「採用市場の話」と「業界の説明」を外し、法人営業・キャリアアドバイザー・運用の職種を募集で分け、それぞれの最初の年（架電、求職者対応、数字）を先に書きます。説明会は講座にせず「この会社の一日」を若手が話し、面接は「評価されている」と体験談に書かれない聞き方にします。自社が扱う媒体と自社の採用に使う媒体を分け、内定者には「業界の魅力」ではなく「この会社で最初に決まった日」を見せます。** この記事では、人材サービス業界の採用構造とワンキャリアとの相性、企業ページの見せ方、説明会と面接の設計、内定後の設計、スカウトの運用設計、社内の分担を整理します。媒体の選び方は[人材サービス業界の採用媒体の選び方](/media/hikaku-jinzai-erabikata/)、企業ページの基本は[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。数値と料金は書きません。

## 人材サービス業界の採用構造と、ワンキャリアとの相性

| 区分 | 採用の形 | ワンキャリアとの相性 |
|---|---|---|
| 大手の人材サービス | 知られている。多く採る。法人営業が中心。体験談が多い | 体験談に「営業だった」「講座だった」が残りやすい。最初の年を先に |
| 人材紹介・採用支援（中堅） | 業界内では知られ、学生には見えない。キャリアアドバイザーと法人営業 | 職種を分けて募集。「人の役に立つ」ではなく最初の年で |
| 派遣、地方の人材会社 | 地域で知られる。派遣スタッフの対応と法人営業 | 「派遣スタッフの対応」を隠さず。地元で絞る |

| 業界の特徴 | ワンキャリアで起きること | 設計 |
|---|---|---|
| 採用のプロで、学生に教える側にいる | 企業ページと説明会が講座になり、会社が見えない | 講座を外し、「この会社の一日」を |
| 面接官が人事のプロ | 体験談に「評価されている」「見抜かれている」と残る | 評価的に書かれない聞き方に |
| 「人の役に立つ」で来て、架電と数字と求職者対応で離れる | 体験談に「営業だった」と残る | 職種ごとに最初の年を先に |
| 自社が扱う媒体と、自社の採用に使う媒体が混ざる | 自社の商材の宣伝になり、学生に読まれない | 分けて、自社の採用は他の会社と同じ基準で |
| 同業（他の人材会社）と併願され、辞退される | 内定者の体験談に「同業に行った」と残る | 「業界の魅力」ではなく「この会社」で残す |

## 企業ページの見せ方｜講座を外し、職種ごとに最初の年を先に

- **「採用市場の話」「業界の説明」「就活のコツ」を、企業ページから外す**：学生は講座を読みに来ていない。「この会社の選考と最初の年」を読みに来ている
- **法人営業・キャリアアドバイザー・運用（RPO、広告の運用）を、募集で分ける**：「この募集は法人営業で、〇〇」「この募集はキャリアアドバイザーで、△△」。一つの募集で全部を書かない
- **最初の年を、職種ごとに隠さず**：「法人営業の最初の年は、架電と訪問で〇〇の数字を追う」「キャリアアドバイザーの最初の年は、求職者の面談を△△件、決まらない期間が□□」。数値は実態で。この記事では書かない
- **「人の役に立つ」「人生を変える」を、最初の一文から外す**：像を強める言葉。代わりに「求職者や企業に何かが決まった日」の場面
- **自社が扱う媒体の宣伝を、企業ページに入れない**：自社の採用の企業ページは、自社の商材の説明ではない
- **自社の体験談に「営業だった」「講座だった」「評価されていた」があれば、先に読む**：合っているなら隠さず、変えたことを添える。[業界イメージが不利な会社のワンキャリアの見せ方](/media/oc-gyokai-image/)

本選考の書き方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。人材サービスの会社から、「うちは採用のプロだから、企業ページも説明会も面接も、自分たちで上手くできている」と言われることがあります。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、人材サービスの会社の体験談を読むと、「説明会は就活講座として勉強になったが、会社のことは分からなかった」「面接で、見抜かれている気がして本音が言えなかった」「業界の話が多く、この会社で何をするかが最後まで見えなかった」が、他の業界より多く書かれています。当社がお願いしているのは、自社の企業ページと説明会と面接を、クライアントに勧めている基準（最初の年を先に、講座にしない、像を確かめる質問をしない）で、自社にも当てることです。

## 説明会と面接を、講座と評価にしない

- **説明会は、就活講座にしない**：「自己分析の方法」「業界研究のコツ」を話すと、評判は「勉強になった」で終わり、会社が残らない。[ワンキャリアのクチコミで説明会の評判が悪いときの見直し](/media/oc-kuchikomi-setsumeikai/)
- **説明会で話すのは、若手の「最初に決まった日」**：「〇〇の企業に初めて採用が決まった日」「△△の求職者が入社を決めた日」。業界の話ではなく、この会社の場面
- **面接で「なぜ人材業界か」「あなたの強みは」を、評価的に聞かない**：人事のプロの聞き方は、体験談に「見抜かれている」と残る。「〇〇の経験で、誰と何を決めたか」を、場面で聞く
- **面接で、最初の年の数字と求職者対応を伝える**：伝えたことは体験談に「聞いた」と残る
- **面接官に、自社の体験談を読ませる**：「評価されている気がした」がどう書かれているかを、面接官自身が知る。[ワンキャリアのクチコミを面接官教育に使う方法](/media/oc-kuchikomi-mensetsukan/)

## 内定後と、自社が扱う媒体との分け方

- **同業への辞退は、人材サービスの前提**：「業界の魅力」で残そうとすると、同業の魅力と同じになり、辞退される
- **内定後に、「この会社で最初に決まった日」を見せる**：若手の案件、決まった日の場面、クライアントとの関係。「業界」ではなく「この会社」で残す
- **内定者の体験談に「なぜこの会社に残ったか」が書かれる形に**：翌年の学生が読む。[ワンキャリア経由の内定辞退が続くときの見直し](/media/oc-naitei-jitai/)
- **自社が扱う媒体と、自社の採用に使う媒体を、分ける**：自社がワンキャリアを扱っているなら、自社の採用でのワンキャリアの企業ページは「商材の説明」にしない。自社の採用は、他の会社と同じ基準で企業ページを書く

## スカウトの設計

- **スカウトは、職種と最初の年を最初に**：「法人営業の募集で、最初の年は架電と訪問で〇〇の数字。あなたの△△（ガクチカ）を読んで」。「人材業界に興味」「人の役に立ちたい」で絞らない
- **絞るのは、「人と人の間に入って決めた・断られてから関係を作り直した・数字を追った」のガクチカ**：法人営業とキャリアアドバイザーの最初の年に近い経験。[ワンキャリアの学生のガクチカを読んでスカウトを送る方法](/media/oc-scout-gakuchika/)
- **文面を、採用のプロの文面にしない**：「あなたの強みは〇〇です」と評価する文面は、学生に「見抜かれている」として読まれる。「〇〇の経験を読んで、△△の場面で一緒に働きたい」と、場面で

## 社内の分担

| 作業 | 誰が |
|---|---|
| 法人営業・キャリアアドバイザー・運用の募集を分け、最初の年を決める | 経営と人事、各職種の責任者 |
| 企業ページから「採用市場の話」「業界の説明」「自社の商材」を外し、最初の年を書く | 人事。各職種の若手が確認 |
| 自社の体験談を読み、「講座だった」「評価されていた」「営業だった」を分ける | 人事と面接官 |
| 説明会を講座にせず、若手が「最初に決まった日」を話す形に | 人事と若手 |
| 面接を評価的に聞かず、場面で聞く形に変える | 面接官の責任者 |
| 内定後に「この会社で最初に決まった日」を見せる | 人事と各職種の責任者 |
| 自社が扱う媒体と自社の採用の媒体を分ける | 経営と人事 |
| スカウトを職種と最初の年を最初に、評価しない文面で送る | 送る人 |

運用代行や代理店が支えられるのは、企業ページの型、体験談の読み方の型、説明会の型、面接の設計の型、内定後の設計の型、スカウトの型と絞る作業までで、最初の年の実態の開示、講座を外す判断、面接官の聞き方の変更、内定後に見せる案件、扱う媒体と採用の媒体の分け方は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。人材サービスの会社から、「うちは『人の役に立つ仕事』として採っているから、営業の数字を前に出したくない」と相談されることがあります。当社は、職種を分けてから、それぞれの最初の年を書くことをお願いしています。法人営業とキャリアアドバイザーと運用では最初の年がまったく違い、「人の役に立つ」の一語では、どれに向くかが分かれません。「人の役に立つ」で採った学生は、法人営業の架電で「人の役に立っていない」と感じて離れ、体験談に「営業だった」と残ります。順番は、職種を募集で分け、法人営業は「数字を追った・断られてから関係を作り直した」、キャリアアドバイザーは「人の話を聞いて決めるまで付き合った」の記述で絞り、最初の年をそれぞれ先に書くことです。分けると、「人の役に立つ」は最初の一文ではなく、決まった日の場面として後ろに置けます。

## まとめ

- 人材サービスの会社は採用のプロだからこそ、企業ページが「採用市場の話」と「業界の説明」で埋まり、説明会が就活講座になり、面接が評価的に見られ、体験談に「勉強になったが会社が分からなかった」「見抜かれている気がした」と残る。クライアントに勧めている基準を自社にも当てる
- 法人営業・キャリアアドバイザー・運用を募集で分け、それぞれの最初の年（架電と数字、求職者対応と決まらない期間、運用）を先に書く。「人の役に立つ」は最初の一文ではなく、決まった日の場面として後ろに
- 説明会は若手が「この会社で最初に決まった日」を話し、面接は評価的に聞かず場面で聞く。面接官に自社の体験談を読ませる
- 同業への辞退は前提。「業界の魅力」ではなく「この会社で最初に決まった日」で残し、内定者が「なぜこの会社か」を体験談に書く設計を。自社が扱う媒体と自社の採用の媒体を分ける
- スカウトは職種と最初の年を最初に、「間に入って決めた・断られてから関係を作り直した・数字を追った」のガクチカで絞る。評価する文面にしない

## よくある質問

### 採用のプロなので、企業ページと面接は自社で上手くできています

体験談を読むと、人材サービスの会社は他の業界より「講座だった」「会社が分からなかった」「評価されている気がした」が多く書かれています。採用のプロであることが、企業ページと説明会を教える形に、面接を評価する形にしています。クライアントに勧めている基準（最初の年を先に、講座にしない、像を確かめる質問をしない）を、自社の企業ページと説明会と面接に当て、自社の体験談で確かめます。

### 「人の役に立つ仕事」として採りたいので、営業の数字を前に出したくありません

「人の役に立つ」で採った学生は、法人営業の架電で「役に立っていない」と感じて離れ、体験談に「営業だった」と残ります。法人営業・キャリアアドバイザー・運用を募集で分け、それぞれの最初の年を先に書き、職種ごとの記述で絞ると、最初の年を知ったうえで来る学生が残ります。「人の役に立つ」は、決まった日の場面として後ろに置きます。

### 人材サービス業界のワンキャリアの設計は、御社に相談できますか

できます。当社は、企業ページの型、体験談の読み方の型、説明会の型、面接の設計の型、内定後の設計の型、スカウトの型と絞る作業を支えられます。最初の年の実態の開示、講座を外す判断、面接官の聞き方の変更、内定後に見せる案件、扱う媒体と採用の媒体の分け方は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
