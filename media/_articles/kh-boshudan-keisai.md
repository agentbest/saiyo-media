企業ページや募集記事を掲載して、母集団を作りたい。ところが、閲覧数やエントリー数を「母集団」と数え、「誰でも歓迎」で広く書き、他媒体の写しを載せ、更新が止まり、来た人が「こんな人」から遠い。**結論から言うと、掲載の母集団は、「読んで、自分に近いと判断して、来た人」です。閲覧数でもエントリー数でもありません。「こんな人」が自分で選べる材料を事実で書き、他の入口から来た人が読む順番を整え、書いたとおりに運用し、更新を止めません。広く受ける入口だからこそ、絞って書きます。** この記事では、掲載で起きる失敗、母集団のでき方、自分で選べる材料、読む順番、書いたとおりに運用すること、更新、媒体ごとの違い、他の入口との分担、数え方、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、スカウト型との違いは[スカウト型とナビ型の違い](/media/hikaku-scout-vs-navi/)、媒体ごとの基本は[Wantedlyの募集記事の基本](/media/wt-boshu-kihon/)と[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)で書きました。

## この作業の目的｜「こんな人」が、読んで、自分で選んで来る入口にする

掲載は、学生が探して、読んで、自分で判断して来る入口です。企業が相手を選べない代わりに、「何を書くか」で来る人が決まります。書いたものが、そのまま母集団の質になります。

目的は、掲載を「閲覧数の入口」ではなく、「こんな人が自分で選んで来る」入口として整えることです。

## 掲載で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 閲覧数やエントリー数を、母集団と数える | 読んだだけ、押しただけの数を「母集団」と呼び、面談まで来ない |
| 「誰でも歓迎」で、広く書く | 来る人が広がり、「こんな人」に近い人が薄まる。選考の枠が遠い人で埋まる |
| 他媒体の写し | その媒体の読み手が知りたいことに答えておらず、読まれない |
| 書いたことを、守らない | 「行ってみたら違った」で離れ、その体験が翌年に読まれる |
| 更新が、止まる | 「動いていない会社」に見え、読まれなくなる |
| 掲載だけで、待つ | 探して来る人だけに頼り、「こんな人」に届かない |

共通するのは、掲載を「置いておけば来る」ものとして扱っていることです。掲載は「書いたとおりの人が来る」入口です。

## 掲載の母集団の、でき方

1. **学生が、探す**：一覧、検索、体験談、他の入口からの流入
2. **読む**：企業ページ、募集記事、社員の記事
3. **自分に近いかを、判断する**：「こんな人」に自分が当てはまるか。この判断が、母集団の質
4. **来る**：エントリー、応募、「話を聞きに行きたい」
5. **企業が、返す**：当日か翌日
6. **面談で、「こんな人」への近さを見る**
7. **台帳に、入口「掲載」で持つ**

母集団の質は「3」で決まり、「3」を決めるのは「2」で読んだものです。企業が動かせるのは、「2」に何を置くかです。

### エージェントベストの見解

相談で最も多い思い込みは、「掲載は広く受ける入口だから、広く書いて、多く来てもらってから選べばよい」というものです。当社は3媒体すべての販売パートナーとして、掲載型の運用を見ていますが、広く書いた会社は、来る人が多くても「こんな人」に近い人が少なく、返信と面談の枠が遠い人で埋まり、近い人への対応が遅れています。逆に、「こんな人に来てほしい」「こういう人には合わない」を事実で書いた会社は、来る人が減っても近い人の割合が上がり、面談進行率と承諾率が上がっています。掲載は、広く受ける入口だからこそ、「自分で選べる材料」を絞って書きます。当社が掲載の相談を受けるとき、最初にやるのは、「誰でも歓迎」の一文を外して、「こんな人」と「合わない人」を事実で書き足すことです。

## 「こんな人」が、自分で選べる材料

| 材料 | 書き方 |
|---|---|
| 何をやるか | 仕事の中身を、一日の流れと、任せる範囲で。抽象語で書かない |
| 誰と働くか | 社員の記事、面談に出る人 |
| どんな人に来てほしいか | 行動の事実で。「主体性のある人」ではなく、「〇〇を自分で決めて動いた経験がある人」 |
| どんな人には合わないか | 書ける範囲で、事実で。合わない人が自分で外れる |
| 選考の流れ | 書いたとおりに運用する前提で。段階、間隔、面談の形 |
| 条件 | 自社の制度と管理部門で確認し、事実を |

書き方の詳しくは[Wantedlyの募集記事の基本](/media/wt-boshu-kihon/)の手順3と手順4、[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)の「最初に置く4つ」、[ワンキャリアの学生目線](/media/oc-gakusei-mesen/)で書きました。

## 他の入口から来た人が、読む順番を整える

- **スカウトから来た人**：文面で触れた「重なり」を、企業ページの最初で読める順番に。[スカウトからの母集団形成](/media/kh-boshudan-scout/)
- **イベントから来た人**：回で話したことを、記事で読み返せるように。[イベントからの母集団形成](/media/kh-boshudan-event/)
- **体験談から来た人**：体験談で気になったことを、企業ページで確かめられる順番に。[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)の「書く順番」
- **早期の接点から来た人**：「知る」材料（仕事と人の記事）を先に。[早期の母集団形成の考え方](/media/kh-boshudan-souki/)
- **掲載は、全入口の「読む場所」**：入口ごとに、最初に読むものが違う

## 書いたとおりに、運用する

- **選考の流れは、書いたとおりに**：段階を増やさない、間隔を延ばさない
- **任せる範囲は、書いたとおりに**：小さく書いて大きく任せるより、書いたとおり
- **面談に出る人は、書いた人が出る**
- **守れないことは、書かない**：書けることだけを書き、書いたことは守る
- **守らなかったことが、翌年に読まれる**：体験談、口伝え。[ワンキャリアの掲載でやりがちな失敗](/media/oc-keisai-ng/)の「最も重い失敗」

## 更新を、止めない

- **更新の頻度を、先に決める**：月に一度、四半期に一度。守れる頻度で
- **更新の中身は、事実の変化**：社員の記事、選考の流れの変更、任せる範囲の変化
- **更新が止まると、「動いていない会社」に見える**
- **更新の担当を決める**：[ワンキャリアの掲載の担当](/media/oc-keisai-tantou/)
- **更新の頻度の考え方は[ワンキャリアの掲載の更新頻度](/media/oc-keisai-koushin-hindo/)、[ワンキャリアの企業ページの更新](/media/oc-kigyo-page-koushin/)**

## 媒体ごとに、変わる部分と変わらない部分

| 変わらない | 変わる |
|---|---|
| 「こんな人」が自分で選べる材料を事実で書く | 読み手が最初に知りたいこと（Wantedlyは「なにを・なぜ・どうやって」、ワンキャリアは体験談で気になったこと、ナビは条件と流れ） |
| 「誰でも歓迎」と書かない | 書く順番 |
| 書いたとおりに運用する | 更新の形と頻度の目安。現在の仕様は管理画面とヘルプで確認 |
| 他媒体の写しにしない | 媒体ごとの読み手に合わせて書き直す |
| 台帳で入口「掲載」を持つ | 媒体ごとに台帳の入口を分ける |

媒体ごとの違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)で書きました。

## スカウト・イベントとの、分担

- **掲載は「広く受ける」、スカウトは「こんな人に届ける」、イベントは「確かめる場」**：[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)の「役割の、分け方」
- **掲載だけで待たない**：「こんな人」に届かないなら、スカウトを足す
- **掲載で来た人を、回に誘う**：確かめてから面談へ
- **掲載は、他の入口の「読む場所」でもある**：スカウトやイベントから来た人が読む
- **入口ごとに台帳を分け、近い人の面談数で配分を見直す**

## 数え方

| 数えるもの | 何が分かるか |
|---|---|
| 来た人のうち、「こんな人」に近い人の割合 | 書いたものが、近い人を選んで連れてきているか |
| 来た人から、面談に進んだ数と日数 | 返信の速さと、来た人への対応 |
| 面談した人のうち、「掲載どおりだった」と言われたか | 書いたとおりに運用できているか。[ワンキャリアの掲載のKPI](/media/oc-keisai-kpi/) |
| 他の入口から来て、掲載を読んで進んだ数 | 掲載が「読む場所」として効いているか |

閲覧数とエントリー数は、「見つかっているか」の参考にはなりますが、母集団の数ではありません。掲載を一つの入口として、[採用ファネルの作り方](/media/kh-boshudan-funnel/)の入口ごとの表で持ちます。

| 作業 | 誰が |

| 「こんな人」と「合わない人」を事実で決める | 人事と面接官 |
| 何をやるか・誰と働くかを事実で書く | 現場と人事 |
| 媒体ごとに、読み手に合わせて書き直す | 人事 |
| 他の入口から来た人が読む順番を整える | 人事 |
| 来た人に当日か翌日に返す | 返信の担当 |
| 書いたとおりに運用する | 面談に出る人と面接官 |
| 更新の頻度と担当を決め、止めない | 人事責任者と担当 |

### エージェントベストの見解

これは発注側の誤解の話です。掲載の相談で、「掲載の文章を良くして、エントリーを増やしたい」と言われることがあります。当社が確かめるのは、「増やしたいのは、エントリーか、『こんな人』に近い人の面談か」です。文章を「良く」して広く響かせると、エントリーは増え、近い人の割合は下がり、返信と面談の枠が遠い人で埋まります。当社がお願いするのは、文章を「良く」するのではなく、「こんな人」が自分で選べる事実を足し、合わない人が自分で外れる書き方にすることです。エントリーが減っても、近い人の面談が増えれば、掲載は効いています。当社は、エントリーの数で掲載を評価しません。

## まとめ

- 掲載の母集団は「読んで、自分に近いと判断して、来た人」。閲覧数やエントリー数を母集団と数えない。質は学生の判断で決まり、判断を決めるのは企業が書いたもの
- 「誰でも歓迎」と書かず、「こんな人」と「合わない人」を事実で書く。何をやるか・誰と働くか・選考の流れ・条件を、書いたとおりに運用できる範囲で
- 他の入口（スカウト・イベント・体験談・早期の接点）から来た人が最初に読むものを、入口ごとに整える。掲載は全入口の「読む場所」
- 書いたとおりに運用し、守れないことは書かない。更新の頻度と担当を決め、止めない
- 媒体で変わるのは「読み手が最初に知りたいこと」と「書く順番」で、事実で書くこと・写しにしないこと・台帳で持つことは変わらない。数えるのは近い人の割合と、面談の日数と、「掲載どおりだった」か

## よくある質問

### 「合わない人」を書くと、応募が減りませんか

減ります。減るのは、合わない人の応募で、それは母集団ではありません。合わない人の応募が減ると、返信と面談の枠が近い人に使え、近い人への対応が速くなります。書き方は、否定ではなく事実で、「〇〇を一人で進める場面が多い」「〇〇の頻度が高い」のように、合わない人が自分で判断できる材料として書きます。

### 掲載を、複数の媒体で使い回してもよいですか

事実（何をやるか、誰と働くか、こんな人）は同じで構いません。変えるのは、媒体ごとの読み手が最初に知りたいことと、書く順番です。そのまま写すと、その媒体の読み手に答えておらず、読まれません。写しにしない考え方は[ワンキャリアの掲載でやりがちな失敗](/media/oc-keisai-ng/)の「失敗5」と[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)の「他の媒体の企業ページとの使い回し」で書きました。

### 掲載からの母集団形成は、御社に相談できますか

できます。当社は、材料の整理、媒体ごとの書き方の型、読む順番の型、更新の頻度の案、台帳の型を支えられます。「こんな人」の決定、事実を書くこと、返信、書いたとおりに運用すること、更新は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
