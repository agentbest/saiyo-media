総合化学、素材、電子材料、化成品、塗料・接着剤、地方の化学メーカーが、新卒を採る。化学の製品は、最終製品（車、スマートフォン、衣服、食品の包装、建材）の中に入る素材で、学生には見えない。理系（化学、材料、化学工学、応用化学）の学生は研究室と学校の推薦の流れで会社を選び、文系の学生には「化学」の一語で届かない。安定していて業界内で知られている会社ほど、学生には知られていない、というずれがある。**結論から言うと、化学業界は「何に入っている素材か」を最終製品でつなぐ一文にし、「化学」の一語で済ませません。研究・技術は研究室と推薦の流れを主にし、媒体は推薦の外の学生に研究の距離を研究の内容で渡す補助に、文系の営業・管理は「技術を人に説明した・違う立場の人の間に入った」の記述で絞って最終製品の一文を先に渡します。工場の勤務地（地方のコンビナート）を隠さず一枚にします。理系は並べて比べる場より専攻で絞って送る型を、文系は最終製品の一文で送る型を先に検討します。** この記事では、化学業界の採用構造、判断軸の当て方、学生が確かめること、最終製品でつなぐ一文、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## 化学業界の採用構造と、媒体との相性

| 区分 | 採用の形 | 媒体との相性 |
|---|---|---|
| 総合化学（大手） | 理系には知られ、推薦で多く採る。文系は営業・管理を少なく | 比べられる場は文系と情報系に。理系は推薦の外の学生に送る型 |
| 素材、電子材料、化成品（中堅） | 業界内では知られ、学生には見えない。研究・技術・生産を専攻で採る | 専攻と研究の内容で絞って送る型。最終製品でつなぐ |
| 塗料、接着剤、地方の化学メーカー | 学生の候補に入っていない。地元の理系と、文系の営業 | 最終製品の一文と地元で絞って送る型か、研究・工場の一日の記事 |

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 製品が最終製品の中に入り、学生に見えない | 「何をしている会社か」が分からず、開かれない | 「〇〇（最終製品）の△△に使われる素材」の一文で |
| 理系は研究室と推薦の流れ | 媒体の外で決まることが多い。推薦の枠を使わない会社は届かない | 推薦を主に。媒体は推薦の外の学生に研究の距離を |
| 文系には「化学」で届かない | 文系の営業・管理が集まらない | 「化学に興味」ではなく「技術を人に説明した」の記述で |
| 工場と研究所が地方のコンビナートにある | 勤務地を知らずに来て、離れる | 勤務地と異動の範囲を最初に |

## 判断軸を、化学業界に当てる

| 軸 | 化学業界での見方 |
|---|---|
| 対象（誰に届くか） | 研究・技術・生産は専攻（化学、材料、化学工学）と研究の内容で絞れるかを仕様で確認する。推薦で会った学生に送らない。文系の営業・管理は「化学に興味」ではなく「技術や仕組みを人に説明した・違う立場の人の間に入った・数字を追った」の記述で |
| 型（送るか、来るか、比べられるか） | 理系は「比べられる」型で名前を知らない会社が候補に入りにくく、「送る」型で研究の内容と最終製品を先に渡す。文系も「送る」型で最終製品の一文を先に。「来る」型は研究や工場の一日を書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 研究員と技術の若手は実験とプラントで動けない。研究の距離の一文と名義と面談に固定する。送る型は作業を外に出せるが、研究の内容の読み込みは研究員が支える |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。化学では、製品が見えないので「型」の軸で「来る」「比べられる」より「送る」が動きやすいことと、最終製品でつなぐ一文が文面の中心になることが、他の業界と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「うちは素材の会社で学生に知られていないから、媒体を使っても届かない」というものです。当社は3媒体すべての販売パートナーとして、化学や素材の会社の相談を受けますが、届かないのは知名度がないからではなく、「〇〇化学工業」「機能性材料の開発・製造」という言葉で書いているからです。学生は会社の名前で開くのではなく、「自分の研究と近いか」「何に使われているか」で開きます。当社が化学の会社に媒体の前に用意してもらうのは、「当社の素材は、〇〇（スマートフォン、車、衣服）の△△の部分に使われている」という最終製品でつなぐ一文と、研究職なら「あなたの〇〇の研究と、当社の△△は、□□でつながる」という研究の距離の一文です。この二つがあると、名前を知らない会社でも、研究の内容と最終製品で開かれます。

## 学生が、確かめること

- **何に使われている素材か**：最終製品との関係。「化学」の中の何か
- **研究の距離**：自分の研究と会社の研究・技術の距離。研究所のテーマ
- **勤務地と異動**：研究所と工場の場所、地方のコンビナートか、転居を伴う異動の範囲
- **研究・技術・生産・営業のどれか**：理系が営業に回ることがあるか。生産技術と研究の違い

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 総合化学で、文系と情報系の職種を、理系の推薦とは別に採りたい | 学生が並べて比べる場（ワンキャリア）で職種ごとの選考情報と実態を | 文系には比べる対象に入っている。理系は推薦が主 |
| 研究・技術を、推薦の外の学生に、研究の内容で絞って会いたい | 企業から送る型（OfferBox） | 専攻と研究の記述で絞れる。研究の距離の一文を先に渡せる。[OfferBoxで研究職志望の学生を見つける検索の考え方](/media/ob-kenkyu-target/) |
| 中堅・地方の化学メーカーで、文系の営業を最終製品の一文で採りたい | 企業から送る型（OfferBox） | 「技術を人に説明した」の記述で絞り、最終製品の一文で開かれる。作業を外に出せる |
| 研究員や工場の若手が、研究や生産の一日と最終製品との関係を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「何をしている会社か」を、研究の一日と「〇〇に使われた日」の場面で読んでもらえる |
| 最終製品でつなぐ一文が、まだない | どれも先ではない | 一文を作ってから。「化学」「素材」の一語では開かれない |

どれか一つが正解ではなく、理系か文系か、推薦の外か、大手か中堅かで、先に検討するものが変わります。

## 組み合わせ

- **研究室と推薦の流れと、媒体を組み合わせる**：推薦で会った学生に媒体で送らない。媒体は推薦の外の学生と、研究室の分野が違う学生に。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)
- **理系は送る型、文系は比べられる場か送る型、と分ける**：一つの媒体で両方を採ろうとせず、職種で分ける。[理系の学生を採るためのOfferBox運用](/media/ob-rikei-unyou/)、[文系の学生を採るためのOfferBox運用](/media/ob-bunkei-unyou/)
- **インターンと組み合わせる**：研究・技術のインターンは研究の距離を本人が確かめる場。[OfferBoxとインターン募集媒体の併用](/media/ob-heiyou-intern-baitai/)

## 見せ方｜「化学」ではなく、最終製品と、研究の距離

- **最終製品でつなぐ一文を、最初に**：「当社の素材は、〇〇の△△の部分に使われています」。「機能性材料」「化成品」の一語で済ませない
- **研究の距離を、研究の内容で**：「あなたの〇〇の研究と、当社の△△は、□□でつながる」。研究員の名義で
- **勤務地と異動を、最初に、隠さず**：「研究所は〇〇、工場は△△にあり、異動は□□の範囲」。数値は実態で。この記事では書かない
- **文系には、「化学に興味」を求めない一文を**：「化学の知識は要らない。技術を人に説明した経験を読みたい」
- **「〇〇に使われた日」の場面を、一つ**：「自分が関わった素材が、△△の製品に入って店に並んだ日」。若手の名義で

## 社内の分担

| 作業 | 誰が |
|---|---|
| 最終製品でつなぐ一文と、研究の距離の一文の型 | 経営と人事、研究・技術の責任者 |
| 勤務地・異動・職種・交代制の一枚 | 人事と各部門の責任者 |
| 研究室と推薦の流れとの分担 | 研究・技術の責任者と人事 |
| 理系か文系か、推薦の外かで、先に検討する型を決める | 人事と責任者 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行（研究の内容の読み込みは研究員が支える） |
| 記事を置く型なら、研究員や工場の若手が一日を話し、整えるのは人事か外に | 若手と人事 |
| 研究の距離の一文、文面の最終確認、名義、面談 | 研究・技術の若手 |
| 出せる最終製品の範囲の確認（取引先との関係） | 営業の責任者 |

- **研究員に頼むのは、研究の距離の一文・名義・面談の三つ**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)

運用代行や代理店が支えられるのは、一文の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分までで、最終製品の一文の中身、研究の距離の一文、勤務地の実態の開示、名義の選定、面談、推薦の流れは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「出せる最終製品の範囲」を取引先との関係で確認しておかないと、最終製品でつなぐ一文が書けず、「機能性材料」の言葉に戻ります。当社はOfferBoxの運用代行を受けているので、化学や素材の会社の承認から面談までを見ていますが、「取引先の名前は出せない」で止まり、「〇〇分野向けの材料」という言葉で送って開かれない会社が多くあります。取引先の名前を出さなくても、「スマートフォンの画面の△△」「車の□□の部分」のように、製品の種類と使われる部分で書けば、学生には十分に見えます。順番は、営業の責任者が「製品の種類と部分までなら出せる」の線を引き、その範囲で最終製品の一文を作り、研究員が研究の距離の一文を足すことです。一文が変わると、名前を知らない会社でも開かれ、面談で「自分の研究と近い」と言われます。

## まとめ

- 化学業界は、製品が最終製品の中に入る素材で学生に見えず、理系は研究室と推薦の流れで選び、文系には「化学」の一語で届かない。知られていないことは媒体を使わない理由ではなく、最初の一文を変える理由
- 「何に入っている素材か」を最終製品でつなぐ一文（製品の種類と使われる部分まで）と、研究の距離の一文（研究員の名義）を、媒体の前に作る。出せる範囲は取引先との関係で線を引く
- 研究・技術は推薦を主にし、媒体は推薦の外の学生に研究の内容で絞って送る型。文系は「化学に興味」ではなく「技術を人に説明した」の記述で絞り、最終製品の一文で送る型か、比べられる場に
- 勤務地（地方のコンビナート）と異動、研究・技術・生産・営業のどれか、交代制を最初に隠さず
- 研究員に頼むのは研究の距離の一文・名義・面談で、作業は外に。理系と文系で型を分け、インターンと組み合わせる

## よくある質問

### 取引先の名前が出せません。最終製品でつなぐ一文は書けますか

書けます。取引先の名前ではなく、製品の種類と使われる部分で書きます。「スマートフォンの画面の〇〇」「車の△△の部分」「食品の包装の□□」のように書けば、学生には十分に見えます。出せる範囲は営業の責任者が取引先との関係で線を引き、その範囲で一文を作ります。「〇〇分野向けの材料」の言葉に戻すと、開かれません。

### 理系は推薦で採れています。文系の営業だけ媒体で採れますか

採れます。文系には「化学に興味」ではなく、「技術や仕組みを人に説明した・違う立場の人の間に入った」の記述で絞り、最初の一文に最終製品でつなぐ一文と「化学の知識は要らない」を置きます。理系の推薦の流れとは分けて、文系の営業だけの文面で送るか、比べられる場に置きます。一つの文面で理系と文系の両方を採ろうとしないことが、化学の文面の作り方です。

### 化学業界の媒体選びは、御社に相談できますか

できます。当社は、一文の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分を支えられます。最終製品の一文の中身、研究の距離の一文、勤務地の実態の開示、名義の選定、面談、推薦の流れは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
