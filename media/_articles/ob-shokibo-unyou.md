店舗、工場、事務所を営む小さな事業者。社長が職人か店主で、採用は初めてに近い。新卒を採りたい理由は、「技能を継いでほしい」「いずれ後を任せたい」であることが多い。OfferBoxで「一緒に働く仲間を募集」と送っても、学生は「何を教わって、何年で何ができるようになるのか」「後継の話はあるのか」「雇用の条件はどうなっているのか」を確かめられず、承認しても面談で止まります。**結論から言うと、小規模事業者が新卒を採る目的は「技能の継承」か「後継」であることが多く、学生が確かめるのもそこです。最初に決めるのは、目的を一行にすること、送る前に雇用の形と条件を整えること、何年で何ができるようになるかの道筋を書くこと、後継の可能性を隠さず伝えること、地域での役割を書くこと、現場を見てもらう面談にすることです。** この記事では、小規模事業者が割ける時間と人、採る目的、最初に決めること、文面の書き方、分担、やりがちな失敗を整理します。人数の少ない会社の運用は[従業員十名以下の会社のOfferBox運用](/media/ob-jugyoin-10-unyou/)、店舗の場合の文面は[OfferBoxで店舗運営職を採るオファー文面の書き方](/media/ob-tenpo-offer-bunmen/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 社長が職人・店主を兼ね、現場に立っている | 通知を見る時間が日中にない。承認への返信が夜か翌日 |
| 採用の経験がなく、就業規則や条件の文書が整っていない | 学生が条件を確かめられない。面談で「決まっていない」と言うことになる |
| 新卒を採る目的が「技能の継承」「後継」 | 文面に書かないと、学生は「何をする仕事か」しか見ず、目的とずれる |
| 教える人が社長一人 | 社長の時間が、教える時間の上限 |
| 現場が店舗や工場で、事務所がない | 面談の場所が現場になる。それ自体は強み |
| 地域に根ざしている | 地元の学生には知られている。都市部の学生には知られていない |

小規模事業者がOfferBoxに割ける時間は、社長が現場を離れられる時間です。日中に通知を見られないなら、承認への一次の返信は外に出し、社長は面談と、技能を教える時間だけに使います。

## 新卒を採る目的を、一行にする

- **「技能の継承」なら**：「〇〇の技能を、△年かけて教えて、□□を任せられる人を育てたい」。何を、どのくらいの期間で、どこまで
- **「後継」なら**：「いずれ事業を任せられる人を、社員として育てたい」。後継の可能性を、隠さず、約束もせず
- **「人手が足りない」なら、新卒ではないことが多い**：中途かパートのほうが早い。新卒は、教える時間が要る採用
- **目的の一行が、文面の中心になる**：「一緒に働く仲間」ではなく、「この技能を継ぐ人」「この事業を続ける人」
- **目的を、学生が確かめる道筋に変える**：「一年目に〇〇、三年目に△△、五年目に□□ができるように」。数値ではなく、できることで

学生が小規模事業者を選ぶ理由は、「技能が身につく」「いずれ自分の店や工場を持てる」「地域で役割を持てる」のどれかです。目的の一行が、この理由につながります。

### エージェントベストの見解

これをやる前に、先に雇用の形と条件を文書で整えておかないと、送っても、承認しても、面談で止まります。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、小規模事業者の面談の前後を見ていますが、承認した学生が面談で「給与は」「休みは」「社会保険は」と聞き、社長が「決めていない」「これから」と答えて、離れる場面があります。学生は、小さい事業者であることを気にしていません。気にしているのは、雇用の条件が「決まっていない」ことです。順番は、就業規則、雇用契約の形、給与の範囲、休み、保険の扱いを、専門家の助言を受けて文書にし、それを一ページにしてから、送ることです。整える前に送ると、承認した学生を条件の不備で失い、その学生は周りに「決まっていない会社」と伝えます。当社は、条件の文書がない事業者には、送る前に整えることを勧め、整うまで送りません。

## 最初に決めること

1. **送る前に、雇用の形と条件を文書にする**：就業規則、雇用契約の形、給与の範囲、休み、保険。専門家の助言を受けて整える。この記事では条件の中身を書かない
2. **何年で何ができるようになるかの道筋を、文面に書く**：「一年目に〇〇、三年目に△△」。技能の継承は、道筋がないと学生は判断できない
3. **後継の可能性を、隠さず、約束せず**：「いずれ事業を任せられる人を育てたい。約束はできないが、その道はある」。隠すと「後継目当てで採られた」に、約束すると「話が違う」に
4. **地域での役割を書く**：「この地域の〇〇を、△年続けている」「地域の□□を支えている」。小規模事業者の強みは、地域での役割
5. **名義は、社長**：教える人が社長なら、社長の名義で「私が教えます」。[代表名で送るスカウト文面](/media/kh-bunmen-daihyo/)
6. **送る数を、数通だけに**：社長が教えられる人数は、多くて一人か二人。[予算が少ない会社のOfferBoxの使い方](/media/ob-yosan-sukunai/)
7. **承認への一次の返信を、外に出す**：社長が現場にいる日中に返せないなら、型で代行が当日に返す。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
8. **地元の学生から送る**：地域に根ざした事業者は、地元の学生に知られている。地元に残りたい・戻りたい学生を記述から読む。[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)

## 文面の書き方｜「仲間」ではなく「技能と道筋」

| 書かない | 書く |
|---|---|
| 「一緒に働く仲間を募集」 | 「〇〇の技能を継ぐ人を、私が△年かけて教えます」 |
| 「アットホーム」「地域密着」の一語 | 地域で何を、何年続けているか。誰が来る店・工場か |
| 「やる気があれば未経験でも」 | 一年目に何を、三年目に何を、できるようになるか |
| 後継の話を隠す、または約束する | 「いずれ任せられる人を育てたい。その道はあるが、約束ではない」 |
| 条件を書かない | 条件は一ページに。文面には「一ページに書きました」 |

- **社長が「なぜこの技能を継いでほしいか」を一文で**：「この地域で〇〇を続けるために」
- **現場の写真や、社長が作ったもの・売っているものの場面を、採用サイトか一ページに**：小規模事業者は、現場が見えると強い
- **給与で勝負しない事業者は、条件を隠さず、技能と道筋で**：[給与水準を強みにできない会社のOfferBoxの伝え方](/media/ob-kyuuyo-hikui/)
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)

## 現場を見てもらう面談

- **面談は、現場で**：店舗、工場、事務所。「この場所で、この人と、この技能を」が一度に見える
- **社長が作っているもの、売っているものを見せる**：技能の継承は、見せるのが最も早い
- **一日、または半日、現場に入ってもらう**：面談の代わりに、体験で。体験の扱い（報酬、保険）は自社の方針と制度の確認のうえで
- **社員や家族に会ってもらう**：小規模事業者は、家族が働いていることも多い。隠さない。[同族・オーナー企業のOfferBox運用](/media/ob-family-unyou/)
- **選考は、一段か二段**：社長との面談と、現場の体験。段を増やす人がいない。[OfferBox経由の学生との初回面談の設計](/media/ob-mendan-sekkei/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 新卒を採る目的の一行と、道筋 | 社長 |
| 雇用の形と条件の文書 | 社長（専門家の助言を受けて） |
| 「こんな人」の一行と検索条件 | 社長（型は代行が渡す） |
| 検索、文面の下書き、送信、一次返信 | 代行 |
| 文面の最終確認、名義 | 社長 |
| 現場での面談と体験 | 社長 |
| 条件と道筋の一ページ | 社長（型は代行が渡す） |
| 内定のあとの連絡 | 社長 |

- **社長の時間は、面談・体験・教えることに**：検索と文面と返信に使わない。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **条件の文書は、代行では作れない**：専門家の助言を受けて、事業者が整える
- **費用は、プランの費用と代行の費用**：公式ページと見積もりで確認。予算が取れないなら、今年は採らない判断も。[予算がほぼ取れない会社の採用媒体](/media/hikaku-yosan-nai/)

運用代行や代理店が支えられるのは、目的の一行の型、道筋の書き方の型、文面の型、一ページの型、検索・下書き・送信・一次返信までで、目的の決定、条件の文書、文面の最終確認、面談と体験、教えることは事業者が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「技能は、入ってから教えれば身につくので、文面には『未経験でも大丈夫』と書けばよい」というものです。当社はOfferBoxの運用代行で小規模事業者の文面を作りますが、「未経験でも大丈夫」の文面に承認した学生は、面談で「何年で何ができるようになりますか」と聞き、社長が「人による」「やってみないと」と答えると離れます。学生は、技能が身につくかを疑っているのではなく、「どのくらいの期間で、どこまで」の道筋がないことを不安に思っています。当社が小規模事業者の文面を作るときは、社長に「一年目に何を、三年目に何をできるようにするか」を聞き、それを文面に書きます。道筋は、社長の頭の中にはあることが多く、書いていないだけです。書くと、承認の理由が「未経験でも」から「この道筋なら」に変わり、面談で「人による」と言わずに済みます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 条件の文書を整える前に送る | 面談で「決めていない」と答えて離れる | 専門家の助言を受けて整えてから |
| 「一緒に働く仲間」で送る | 技能と道筋がなく、目的とずれる | 目的の一行と道筋を書く |
| 後継の話を隠す、または約束する | 「後継目当て」か「話が違う」になる | 可能性として、約束せず伝える |
| 「未経験でも大丈夫」で道筋を書かない | 「何年で何ができるか」に答えられない | 一年目・三年目でできることを書く |
| 面談を事務所や外で行う | 現場が見えず、小規模事業者の強みが消える | 現場で、作っているものを見せる |

最も多いのは、一つ目です。採る気持ちが先に立ち、雇用の形と条件が文書になっていません。

## まとめ

- 小規模事業者が新卒を採る目的は「技能の継承」か「後継」が多く、学生が確かめるのもそこ。目的を一行にし、道筋（何年で何ができるようになるか）に変える
- 送る前に、雇用の形と条件を専門家の助言を受けて文書にし、一ページにする。整うまで送らない
- 後継の可能性は、隠さず、約束せず。地域での役割を書く。名義は社長で、送る数は数通だけ
- 面談は現場で、作っているもの・売っているものを見せ、一日か半日の体験を。家族が働いているなら隠さない
- 社長の時間は面談・体験・教えることに。検索・下書き・送信・一次返信は外に。地元の学生から送る

## よくある質問

### 就業規則がありません。作ってから送るべきですか

作ってから送ることを勧めます。雇用の形、給与の範囲、休み、保険の扱いが文書になっていないと、承認した学生が面談で確かめられず、離れます。専門家（社会保険労務士など）の助言を受けて整えます。整える前に送ると、条件の不備で学生を失い、「決まっていない会社」と伝わります。

### 後継の話は、面談でしてよいですか

してよく、隠すほうが問題です。「いずれ事業を任せられる人を育てたい。その道はあるが、約束ではない」と、可能性として伝えます。約束すると、数年後に「話が違う」になり、隠すと、あとで分かったときに「後継目当てで採られた」になります。学生が「その道もある」と知ったうえで来る形が、双方に無理がありません。

### 小規模事業者のOfferBox運用は、御社に相談できますか

できます。当社は、目的の一行の型、道筋の書き方の型、文面の型、一ページの型、検索・下書き・送信・一次返信を支えられます。目的の決定、条件の文書、文面の最終確認、面談と体験、教えることは、事業者が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
