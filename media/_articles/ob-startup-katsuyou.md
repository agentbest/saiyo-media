シード期、シリーズA、シリーズB以降、上場前後、大手からのスピンアウトのスタートアップが、OfferBoxで新卒を採る。OfferBoxは、企業が学生のプロフィールを検索してオファーを送り、学生が複数のオファーを並べて比べる場で、スタートアップのオファーは、知名度のある会社のオファーと同じ画面に並ぶ。学生が承認の前に確かめるのは、「成長できるか」「裁量があるか」ではなく、「この会社は自分が入る頃まで続くか」「新卒の自分に、誰が何を教えてくれるか」「入社までに会社が変わっていないか」です。スタートアップの側は、「成長」「裁量」「ビジョン」で文面を書き、学生が確かめたいことに答えない。**結論から言うと、スタートアップのOfferBoxは、会社の段階で「採るべきか」と「書くこと」を分けます。シード期は、新卒を雇用として採る時期ではなく、OfferBoxは向きません。シリーズAは、新卒を育てる人がいる場合に限り、少数を、社長と「決まっていない」を選ぶ学生に。シリーズB以降は、新卒採用として、「変わる会社で、誰が教えるか」を先に書きます。どの段階でも、文面の最初に段階と決まっていないことを書き、「成長」「裁量」で埋めません。検索は「〇〇志向」ではなく、決まっていない中で決めた行動の記述で絞ります。** この記事はスタートアップの総論で、段階ごとの運用は[シード期](/media/ob-startup-seed-unyou/)、[シリーズA](/media/ob-startup-a-unyou/)、[シリーズB以降](/media/ob-startup-b-unyou/)で書きました。媒体の選び方は[スタートアップ業界の採用媒体の選び方](/media/hikaku-startup-erabikata/)で書きました。数値と料金は書きません。

## スタートアップの採用構造と、OfferBoxとの相性

| 段階 | 採用の形 | OfferBoxとの相性 |
|---|---|---|
| シード期 | 創業者と数人。事業が決まっていない。雇用として新卒を採る時期ではない | 向かない。関わってくれる学生に会う入口は別に。[各論](/media/ob-startup-seed-unyou/) |
| シリーズA | 事業が見えてきた。育てる人がいるかで分かれる | 育てる人がいる場合に限り、少数を。[各論](/media/ob-startup-a-unyou/) |
| シリーズB以降 | 組織ができ、新卒を採る余裕が出る。変わり続ける | 向く。「変わる会社で、誰が教えるか」を先に。[各論](/media/ob-startup-b-unyou/) |
| 大手からのスピンアウト | 親会社の名前と、独立した実態が混ざる | 親会社の名前で埋めず、独立した後の決裁と段階を先に |

| 業界の特徴 | OfferBoxで起きること | 設計 |
|---|---|---|
| 知名度のある会社と同じ画面に並ぶ | 「成長」「裁量」では開封されても承認されない | 段階と決まっていないことと「誰が教えるか」で |
| 学生は「続くか」「誰が教えるか」を確かめる | 文面に答えが無く、面談で聞かれる | 文面の最初に |
| 入社までに会社が変わる | 内定後に事業や役割が変わり、辞退される | 変わることを先に伝え、変わったら伝える |
| 段階で採るべきかが変わる | シード期に新卒を採って、双方が苦しむ | 段階で切り分ける |

## 段階で切り分ける｜採るべきかと、書くこと

- **シード期は、OfferBoxで新卒を採らない**：事業と役割が決まっておらず、育てる人もいない。関わってくれる学生に会う入口は、インターンと別の場で。[シード期スタートアップのOfferBox運用](/media/ob-startup-seed-unyou/)
- **シリーズAは、育てる人がいるかで決める**：「新卒の最初の一年を、誰が、どのくらいの時間で教えるか」に答えられないなら、採らない。答えられるなら、少数を、社長と「決まっていない」を選ぶ学生に。[シリーズAのOfferBox運用](/media/ob-startup-a-unyou/)
- **シリーズB以降は、新卒採用として、新卒の型を決める**：中途の型（即戦力、自走）で新卒を回さない。「変わる会社で、誰が教えるか」を文面の最初に。[シリーズB以降のOfferBox運用](/media/ob-startup-b-unyou/)
- **スピンアウトは、親会社の名前を一度だけ**：「独立して〇〇を決められるようになり、△△は親会社の決裁」。親会社の像で承認されないように
- **どの段階でも、「決まっていないこと」を文面に書く**：「〇〇は決まっていて、△△は決まっていない。□□は入社までに変わるかもしれない」

### エージェントベストの見解

これは切り分けの話です。スタートアップから、「OfferBoxで新卒を採りたい」と相談されるとき、当社は3媒体すべての販売パートナーとして、まず「今、どの段階ですか」「新卒の最初の一年を誰が教えますか」と聞きます。シード期に新卒を雇用として採ると、事業も役割も決まっていない中で、教える人もいないまま新卒が置かれ、学生も会社も苦しみます。シリーズB以降で中途の型（即戦力、自走）のまま新卒を回すと、「自走できない」と新卒を責める形になります。当社がお願いしているのは、段階で「採るべきか」を先に決め、採るなら段階に合わせて「書くこと」を変えることです。シリーズAは「社長と、決まっていない中で」を選ぶ学生に少数を、シリーズB以降は「変わる会社で、誰が教えるか」を先に書いて新卒の型で。段階で分けると、採るべきでない時期に採らずに済みます。

## 検索とターゲットの設計｜「〇〇志向」ではなく、決まっていない中で決めた行動で

- **「ベンチャー志向」「スタートアップ志向」「成長意欲」で検索しない**：志向の言葉は、知名度のある成長企業の像を指していて、自社の段階と合わない
- **絞るのは、決まっていない中で決めた行動の記述**：「〇〇を自分で立ち上げた」「決まっていない△△を決めて進めた」「□□で人を巻き込んだ」「うまくいかなかった〇〇を続けた」。[OfferBoxのターゲット設計](/media/ob-target-sekkei/)
- **自由記述で、「終わり方」を読む**：始めた経験は多くの学生が書く。終わらせた、続けた、うまくいかなかった後にどうしたか、が書かれている学生を。[OfferBoxのプロフィールの読み方](/media/ob-profile-yomikata/)
- **上位校と知名度で絞らない**：知名度のある会社と同じ検索をすると、同じ学生に同じ画面で並び、承認されない
- **数は少数でよい**：スタートアップが新卒を育てられる数は少ない。送る数を先に決める。[OfferBoxで送る数のペース](/media/ob-soushin-pace/)

## オファー文面の設計｜段階と決まっていないことと「誰が教えるか」を最初に

- **「成長」「裁量」「ビジョン」「急成長」を、書かない**：知名度のある会社の文面と同じ言葉で、学生が確かめたいことに答えていない。[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)
- **最初の一文に、段階と決まっていないことを**：「〇〇の段階の会社で、△△は決まっていて、□□は決まっていません。入社までに〇〇が変わるかもしれません」
- **「誰が教えるか」を、名前と役割で**：「新卒の最初の一年は、〇〇（役割）の△△が教えます。週に□□の時間」。「先輩がサポート」の一語で済ませない
- **「続くか」に、答えられる範囲で答える**：資金の段階、主な収益、決まっていないこと。数値は自社の実態で。この記事では書かない
- **社長の名義で送る**：スタートアップの採用は社長が決める。学生は「誰と働くか」で承認する
- **プロフィールの「決めた」記述に、一箇所触れる**：「決まっていない〇〇を決めて進めた、と書かれていたので」。[OfferBoxのオファーをパーソナライズする方法](/media/ob-offer-personalize/)

## 面談と内定後｜変わることを先に伝え、変わったら伝える

- **面談に、社長と「教える人」が出る**：「続くか」は社長が、「誰が教えるか」は教える本人が。[OfferBoxの面談の設計](/media/ob-mendan-sekkei/)
- **面談で、決まっていないことと変わるかもしれないことを、聞かれる前に伝える**：「〇〇は入社までに変わるかもしれない」
- **内定後、会社が変わったら、変わったことを伝える**：事業の変更、役割の変更、資金の段階の変化。伝えずに入社日を迎えると、入社後に知られて離れる。[OfferBoxの内定後フォロー](/media/ob-naitei-follow/)
- **内定から入社までの長さを前提に、連絡の頻度を先に決める**：スタートアップは、その間に会社が変わる。[OfferBoxの内定辞退を防ぐ考え方](/media/ob-naitei-jitai/)

| 作業 | 誰が |
|---|---|
| 段階で採るべきかを決め、「誰が教えるか」を決める | 社長 |
| 段階と決まっていないことと「誰が教えるか」を、文面の最初に書く | 社長（下書きは外に出せる） |

| 面談に社長と教える人が出る | 社長・教える人 |
| 内定後、変わったことを伝える | 社長 |

運用代行や代理店が支えられるのは、段階の整理、文面の下書き、検索の絞り込み、送信、一次返信、内定後フォローの型までで、採るべきかの決定、教える人の決定、決まっていないことの開示、社長が話すこと、面談、変わったことを伝えることは会社が行います。代行の範囲は[OfferBoxの運用代行の範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

これは媒体の向き不向きの話です。シード期のスタートアップから、「OfferBoxで新卒を採りたい」と相談されることがあります。当社が見ている範囲で、OfferBoxが向くのは、シリーズB以降の新卒採用と、育てる人がいるシリーズAの少数の採用で、シード期には向きません。OfferBoxは学生が複数のオファーを並べて比べる場で、学生は「続くか」「誰が教えるか」「入社までに変わらないか」で承認します。シード期は、その三つのどれにも答えられない時期で、答えられないまま送ると、承認されないか、入社後に苦しみます。シード期に学生と関わりたいなら、関わってくれる学生に会う入口（インターン、業務委託、イベント）を別に持つ方が合っています。当社がお願いしているのは、自社の段階でOfferBoxとの相性を見て、向く段階で、段階に合った文面で使うことです。向かない段階で使わないことも、設計です。

## まとめ

- OfferBoxは学生が複数のオファーを並べて比べる場で、スタートアップは知名度のある会社と同じ画面に並ぶ。学生が確かめるのは「成長」「裁量」ではなく「続くか」「誰が教えるか」「入社までに変わらないか」
- 段階で採るべきかと書くことを分ける。シード期は向かず、関わる入口を別に。シリーズAは育てる人がいる場合に限り少数を、社長と「決まっていない」を選ぶ学生に。シリーズB以降は新卒の型で「変わる会社で、誰が教えるか」を先に。スピンアウトは親会社の名前を一度だけ
- 検索は「ベンチャー志向」「成長意欲」ではなく、決まっていない中で決めた行動と「終わり方」の記述で絞り、少数に社長の名義で送る
- 文面は「成長」「裁量」「ビジョン」を書かず、段階と決まっていないことと「誰が教えるか（名前と役割と時間）」を最初に。段階が変わったら書き直す
- 面談に社長と教える人が出て、変わるかもしれないことを先に伝える。内定後、会社が変わったら伝える

## よくある質問

### シード期でも、新卒を採りたいのですが

雇用としての新卒採用は、事業と役割と教える人が決まっていない時期には、学生にも会社にも合いません。関わってくれる学生に会う入口（インターン、業務委託、イベント）を別に持ち、事業が見えてきて教える人が決まった段階で、OfferBoxで新卒を採ってください。シード期の入口の設計は[シード期スタートアップのOfferBox運用](/media/ob-startup-seed-unyou/)で書きました。

### 「成長できる」「裁量がある」と書かないと、知名度のある会社に負けませんか

同じ画面に並ぶ知名度のある会社も「成長」「裁量」で書いていて、同じ言葉では区別されません。学生が確かめたいのは「続くか」「誰が教えるか」で、そこに答える文面は、知名度のある会社の文面には無いものです。段階と決まっていないことと教える人の名前と役割を先に書いてください。

### スタートアップのOfferBoxの設計は、御社に相談できますか

できます。当社は、段階の整理、文面の下書き、検索の絞り込み、送信、一次返信、内定後フォローの型を支えられます。採るべきかの決定、教える人の決定、決まっていないことの開示、社長が話すこと、面談、変わったことを伝えることは、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
