上場準備に入っていて、内部管理の体制を整え、人が急に増えている。新卒も採り始めた。「上場予定」を採用の魅力にしたいが、文面に書いてよいか分からず、書かないと何を書けばよいか分からない。確認の手順が厳しくなり、文面と返信に時間がかかる。**結論から言うと、「上場予定」は文面に書けず、書けたとしても学生への約束にはなりません。学生が確かめるのは「上場するのか」ではなく、「上場したあとに自分がどうなるか」です。最初に決めるのは、上場や株式に関わることを文面に書かないこと、準備で整えた労務と評価の実態を書ける形にすること、上場後に変わることを正直に伝えること、名義を現場の若手にすること、確認の手順を共通原稿の一度に絞って承認への返信を遅らせないことです。** この記事では、IPO準備企業が割ける時間と人、学生が確かめること、最初に決めること、文面の書き方、確認の手順、分担、やりがちな失敗を整理します。上場後の運用は[上場企業のOfferBox運用](/media/ob-joujou-unyou/)、急に人が増える時期の運用は[急成長フェーズの会社のOfferBox運用](/media/ob-kyuu-seichou-unyou/)で書きました。上場に関わる情報の扱いは、自社の管理体制と専門家の助言に従ってください。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 内部管理の整備中で、人事も体制を作りながら採用している | 採用の時間が、規程や制度の整備に取られる |
| 人が急に増え、管理部門の採用も増える | 新卒の「最初の年」が、入社時に変わっている |
| 確認の手順が厳しくなった | 文面と返信に、一通ごとの確認が挟まり、遅れる |
| 「上場予定」を魅力にしたい | 書けない、または書いても約束にならない。書き方を誤ると管理上の問題になる |
| 上場後に、裁量や制度が変わる見込み | 学生が「上場したら変わりますか」と聞き、答えが曖昧だと離れる |
| 労務と評価の制度が、準備で整った | 学生の安心の材料になるのに、文面に書いていない |

IPO準備企業がOfferBoxに割ける時間は、人事の人数より、「確認の手順に何日かかるか」と「準備で整えた実態を文面に書ける形にしているか」で決まります。準備は、採用の材料でもあります。

## 学生が、承認の前に確かめること

- **上場するのか、いつか**：文面でも面談でも、答えられない。「言えません」と言える形を先に決める
- **上場したあとに、自分がどうなるか**：裁量、仕事の中身、評価、会社の雰囲気が変わるか。学生が本当に確かめているのはここ
- **労務の実態**：残業、休み、勤怠の管理。準備で整えたことは、学生の安心
- **評価の実態**：評価の基準と、実際に上がった人。準備で制度が整った会社は、書ける
- **人が急に増えて、育てる体制があるか**：新卒の育成が、増員の中で後回しになっていないか
- **辞めた人がいるか、なぜか**：準備の負荷で辞める人がいることを、学生も知っている

学生は、上場そのものより、上場の前後で「自分の毎日がどうなるか」を確かめています。上場に関わることを書けなくても、毎日の実態は書けます。

### エージェントベストの見解

相談で最も多い思い込みは、「上場予定であることを、採用の魅力として文面に書きたい」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、IPO準備企業の文面の相談を受けますが、上場に関わることは、管理体制の上で書けないことが多く、仮に書けたとしても、学生への約束にはならず、上場が遅れたときに「聞いていた話と違う」になります。書けないことを魅力にしようとするより、準備の過程で整えた労務と評価の実態を書くほうが、学生には伝わります。残業の管理、休みの取り方、評価の基準は、準備で整った会社ほど具体に書けて、それは上場の有無に関わらず、学生が確かめていることです。当社がIPO準備企業の文面を作るときは、上場と株式に関わる言葉を消し、「準備で整えたこと」を人事に聞いて、その実態を書きます。上場は書けませんが、準備は書けます。

## 最初に決めること

1. **上場や株式に関わることを、文面に書かない**：「上場予定」「上場後の株式報酬」「時価総額」など。管理体制と専門家の助言に従い、「言えません」と言える形を先に決める
2. **準備で整えた労務と評価の実態を、書ける形にする**：残業の管理、休み、勤怠、評価の基準。制度の名前ではなく、実態で。「〇〇の管理を△△の形で行っています」
3. **上場後に変わることを、隠さず一文で**：「上場後は、〇〇の手続きが増え、△△の裁量は□□の判断を通します」。分かる範囲で。分からないことは「変わることがあります」と
4. **名義を、現場の若手にする**：管理部門でも事業部門でも、入社数年の若手。「増員の中で、どう育てられたか」を書ける人。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
5. **確認の手順を、共通原稿の一度に絞る**：共通原稿、返信の型、書かないことの一覧を管理部門に一度通し、個別の一文は現場が一覧の範囲で。一通ごとに通さない。手順は[上場企業のOfferBox運用](/media/ob-joujou-unyou/)
6. **承認への当日返信を、確認から切り離す**：型のとおりなら確認なしで当日に。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
7. **「最初の年」を四半期で見直す**：人が急に増える時期は、仕事の中身が変わる。[急成長フェーズの会社のOfferBox運用](/media/ob-kyuu-seichou-unyou/)

## 文面の書き方｜上場に触れず、準備で整えた実態を

| 書かない | 書く |
|---|---|
| 「上場予定」「上場に向けて」「株式報酬」 | 準備で整えた労務の実態。「残業は〇〇の形で管理しています」 |
| 「成長中」「急拡大」 | 最近の四半期で、この部署で何が変わったか |
| 「裁量が大きい」 | 「〇〇は現場が決め、△△は□□の判断を通します」。上場後に変わるならその旨 |
| 「安定した会社になります」 | 評価の基準と、実際に上がった人の場面 |
| 業績、資金、見通しの数値 | 数値は書かない。公表している事実だけを、管理部門に確認して |

- **名義の若手が、「増員の中で、誰に教わって、何を任されたか」を一場面**：人が急に増える時期の育成の実態
- **書かないことの一覧を、管理部門と作る**：上場、株式、業績の見通し、未公表の情報、他社の名前。一覧があれば、現場が個別の一文を書いても外れない
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)。労務と評価の実態は採用サイトにも。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 面談で、「上場するのか」と聞かれたら

- **「お答えできません」と、先に決めた形で**：曖昧に濁さず、「その点は、会社としてお答えできない決まりです」
- **代わりに、「上場の前後で、毎日がどう変わるか」を話す**：手続き、裁量、評価、雰囲気。分かる範囲で正直に
- **「準備で整えたこと」を具体で**：労務、評価、育成。学生の安心はここにある
- **面接官に、上場に関わることを言わない、と伝える**：現場の面接官が「たぶん来年」と言うのが、最も避けたい形。[OfferBox経由の学生を面接する現場社員への説明](/media/ob-genba-mensetsukan/)
- **面談の入口は、文面の続きから**：[OfferBox経由の学生との初回面談の設計](/media/ob-mendan-sekkei/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 書かないことの一覧と、「言えません」の形 | 管理部門と人事。専門家の助言を受けて |
| 準備で整えた労務と評価の実態を、書ける形に | 人事 |
| 上場後に変わることの一文 | 経営と人事 |
| 共通原稿、返信の型（一度だけ確認に通す） | 人事 |
| 検索、共通部分の下書き、送信、一次返信 | 人事、または代行 |
| 個別の一文、文面の最終確認、名義、面談 | 現場の若手 |
| 面接官に、上場に関わることを言わないと伝える | 人事 |
| 「最初の年」の四半期の見直し | 人事と現場の責任者 |

- **人事の時間が整備に取られるなら、検索・下書き・送信・一次返信を外に出す**：[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **確認は一度、返信は型で当日**：ここが崩れると、準備期のスカウトは回らない

運用代行や代理店が支えられるのは、書かないことの一覧の型、共通原稿と返信の型、労務と評価の実態を書く型、検索・下書き・送信・一次返信までで、上場に関わる判断、一覧の決定、名義の選定、面談、上場後に変わることの開示は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「準備で整えたこと」を人事が一枚に書き出しておかないと、上場に触れない文面は、書くことがなくなります。当社はOfferBoxの運用代行でIPO準備企業の文面を作りますが、「上場に触れてはいけない」と決めた会社が、次に「では何を書けばよいのか」で止まることがあります。止まる理由は、準備で整えた労務、評価、勤怠、育成の実態を、人事が採用の材料として見ていないからです。準備の一つ一つは、学生が確かめている「毎日の実態」そのもので、整えた会社ほど、具体に書けます。順番は、上場に関わる言葉を消すことより先に、準備で整えたことを一枚に書き出し、その中から学生が確かめる項目（残業の管理、休み、評価、育成）を文面と採用サイトに置くことです。一枚があれば、上場に触れなくても、書くことは足ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「上場予定」を文面に書く | 管理上の問題になり得て、遅れたときに約束違反になる | 書かないことの一覧に入れる |
| 上場に触れないと決めて、書くことがなくなる | 会社紹介だけの文面になる | 準備で整えたことを一枚に |
| 一通ごとに管理部門の確認を通す | 送る時期が遅れ、返信が止まる | 共通原稿に一度だけ |
| 面接官が「たぶん来年」と言う | 約束になり、管理上の問題にも | 言わないと伝える |
| 上場後に変わることを隠す | 入社後に「聞いていない」で離れる | 分かる範囲で一文 |

最も多いのは、一つ目です。上場を魅力だと考えて書こうとし、書けないと分かって、次に何を書くかが決まりません。

## まとめ

- 「上場予定」は文面に書けず、約束にもならない。学生が確かめるのは「上場したあとに自分がどうなるか」
- 上場や株式に関わることは、管理体制と専門家の助言に従って書かない。「言えません」と言える形を先に決め、面接官にも伝える
- 準備で整えた労務と評価の実態（残業の管理、休み、評価の基準、育成）を一枚に書き出し、文面と採用サイトに置く。上場は書けないが、準備は書ける
- 上場後に変わること（手続き、裁量、評価）を、分かる範囲で一文。名義は現場の若手で、増員の中でどう育てられたかを一場面
- 確認は共通原稿・返信の型・書かないことの一覧に一度だけ。承認への返信は型のとおりなら当日に。「最初の年」は四半期で見直す

## よくある質問

### 学生が「上場するんですよね」と聞いてきます。どう答えますか

「会社としてお答えできない決まりです」と、先に決めた形で答えます。濁すと「隠している」に、「たぶん」と言うと約束になります。そのうえで、「上場の前後で、毎日がどう変わるか」を、分かる範囲で正直に話します。学生が確かめたいのは、上場の時期ではなく、上場後の自分の毎日です。

### 準備で忙しく、採用の時間が取れません

検索・下書き・送信・一次返信を外に出し、人事の時間を「準備で整えたことを一枚にする」「確認を一度で通す」「面接官に伝える」の三つに絞ります。準備の時期に採用を止めると、上場後の人が足りなくなります。時間が足りないときの対処は[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)で書きました。

### IPO準備企業のOfferBox運用は、御社に相談できますか

できます。当社は、書かないことの一覧の型、共通原稿と返信の型、労務と評価の実態を書く型、検索・下書き・送信・一次返信を支えられます。上場に関わる判断、一覧の決定、名義の選定、面談、上場後に変わることの開示は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
