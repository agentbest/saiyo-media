面談の日程が決まった。安心して、当日まで連絡しない。当日、相手が来ない、接続先が分からないと連絡が来る、「準備が要ると思って気が重くなった」と辞退される。日程が決まってから当日までの「空白」で、起きます。**結論から言うと、面談の案内は、確定・前日・当日の三通で空白を埋めます。確定の一通に、日時・形式・接続先か場所・誰が出るか・何を話すか・準備は不要・変更のしかた、の七つを入れます。前日は一言、当日は接続先の再送で、どちらも催促にしません。相手からの変更依頼には当日返し、無断キャンセルには一度だけ確認します。三つの媒体で、この考え方は同じです。** この記事では、空白が生む辞退、確定の一通の七つ、前日の一言、当日の案内、変更依頼、無断キャンセル、面談後との関係、媒体ごとの違い、分担を整理します。OfferBoxでの面談前の連絡は[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)、返信後の文面は[スカウトに返信が来たあとの文面](/media/kh-bunmen-henshin/)で書きました。

## この作業の目的｜日程が決まってから当日までの「空白」を埋める

日程が決まると、送る側は「あとは当日」と思います。相手の側は、日程が決まった瞬間から当日まで、「本当にあるのか」「何を話すのか」「準備が要るのか」「どこに接続するのか」を、聞けないまま抱えています。

目的は、その空白を、相手が聞かなくても分かる三通で埋め、当日まで安心して来られる形にすることです。

## 空白が生む、辞退

| 空白で起きること | 相手の側で何が起きるか |
|---|---|
| 忘れられる | 日程が決まってから数日経つと、他の予定に埋もれる |
| 「本当にあるのか」の不安 | 確定の連絡がなく、「日程を出したが、決まったのか」が分からない |
| 当日の接続や場所で迷う | 接続先や場所が届いておらず、当日に探す。遅れるか、来ない |
| 準備が要ると思って、重くなる | 「何を話すか」が分からず、志望動機や自己紹介を準備しようとして、気が重くなり、辞退 |
| 誰が出るか分からない | 「面接官のような人が出るのか」と身構える |

空白の詳しくは[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)の「この作業の目的」で書きました。

## 確定の一通に入れる、七つ

| 入れるもの | 書き方の例 |
|---|---|
| 1. 日時 | 「〇月〇日（曜日）〇時から、〇分程度」（時間の目安は自社の実態で） |
| 2. 形式 | 「オンラインです」または「対面で、〇〇にお越しください」 |
| 3. 接続先か場所 | オンラインなら接続先。対面なら住所と、建物の入り方。「前日にも再送します」 |
| 4. 誰が出るか | 「この文面を書いた私と、現場の△△が出ます」。役割を一言 |
| 5. 何を話すか | 「前半は△△が仕事の一日を話し、後半はあなたの話を聞かせてください」 |
| 6. 準備は不要 | 「準備は不要です。志望動機や自己紹介も要りません。選考ではありません」 |
| 7. 変更のしかた | 「ご都合が変わったら、この連絡に返信いただければ、日程を変えます」 |

七つで一通。「準備は不要」と「変更のしかた」が、相手の側の重さを取ります。確定の連絡の詳しくは[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)の手順1で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「面談の前に連絡を重ねると、相手に催促と受け取られる」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の面談前の対応を見ていますが、日程が決まってから当日まで連絡しなかった会社の面談には、当日に来ない相手と、当日に「準備が要ると思って気が重い」と辞退する相手が出ています。逆に、確定の一通に「準備は不要」「誰が出るか」「何を話すか」を書き、前日に一言、当日に接続先を再送した会社の面談は、相手が来ています。催促になるのは、「お忘れなく」「ご参加をお願いします」の念押しの言葉で、確定・前日・当日の三通そのものは、相手にとって「安心の連絡」です。当社が面談案内の相談を受けるとき、最初にやるのは、確定の一通に七つが入っているかを確かめることです。

## 前日の一言が、催促にならない書き方

- **「明日、〇時にお待ちしています。当日は△△が出ます。接続先は□□です」**：事実だけ
- **「お忘れなく」「ご準備を」の念押しを書かない**：催促になる
- **接続先か場所を、もう一度**：前日に探させない
- **「ご都合が変わっていたら、返信で教えてください」を添える**：変更の道を残す
- **短く**：三文で足りる

前日の一言の書き方は[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)の手順2で書きました。

## 当日の案内

- **開始の少し前に、接続先を再送**：「本日〇時から。接続先は□□です。お待ちしています」
- **対面なら、建物の入り方と、着いたらどうするか**：「受付で〇〇の名前をお伝えください」
- **相手が遅れたときの連絡先**：「遅れそうなときは、この連絡に返信ください」
- **出る人の名前を、もう一度**：「△△がお待ちしています」
- **当日の案内は、一通**：何度も送らない

当日の案内の詳しくは[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)の手順3で書きました。

## 相手からの変更依頼への、返し方

- **当日に返す**：変更を申し出た相手は、気を使っている
- **「承知しました。以下の日程はいかがでしょうか」と、複数の日程を出す**：丸投げしない
- **理由を聞かない**：「差し支えなければ」も要らない
- **変更を責めない**：「ご連絡いただき、ありがとうございます」
- **新しい日程が決まったら、確定の一通をもう一度**：七つを再送

変更への対応は[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)の手順4で書きました。

## 無断キャンセルへの、対応

- **当日、開始の時間を少し過ぎても来なければ、一度だけ連絡**：「本日〇時からの面談ですが、接続で困っていませんか。ご都合が変わっていたら、返信で教えてください」
- **責めない**：「お待ちしていましたが」を重ねない
- **その日の中に返事がなければ、翌日に一度だけ**：「昨日はご都合が合わなかったようですね。改めて、以下の日程はいかがでしょうか。無理なら、返信は不要です」
- **それでも来なければ、追わない**：「潜在」として台帳に残す
- **無断キャンセルを、社内で悪く言わない**：次の相手への対応に出る

無断キャンセルへの対応は[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)の手順5で書きました。

## 面談後の、翌日の一通との関係

- **面談の翌日に、一言**：「昨日はありがとうございました。〇〇のご質問、△△が喜んでいました」
- **次の選択肢を伝える**：「選考に進む・もう一度話す・いったん終わる。今日決めなくて構いません」
- **確定・前日・当日・翌日で、四通**：この四通で、日程確定から面談後までの空白が全部埋まる
- **翌日の一通は[スカウトのフォロー文面](/media/kh-bunmen-follow/)の「面談の翌日」の行**
- **面談後の流れは[OfferBoxの面談後のフォロー](/media/ob-mendan-go-follow/)**

### エージェントベストの見解

これは順番の話です。当社が面談案内の相談を受けたとき、前日と当日の連絡より先に、確定の一通を見ます。確定の一通に「準備は不要」「誰が出るか」「何を話すか」がなければ、前日と当日に何を送っても、相手は「準備が要る面接」だと思ったまま当日を迎え、気が重くなって辞退するか、身構えて来ます。逆に、確定の一通に七つが入っていれば、前日と当日は「事実の再送」だけで足ります。当社が勧める順番は、確定の一通に七つを入れる、前日に一言、当日に接続先、翌日に一言、です。四通の中で、最も重いのは確定の一通です。

## まとめ

- 日程が決まってから当日までの空白で、忘れられる・「本当にあるのか」の不安・接続や場所で迷う・準備が要ると思って重くなる・誰が出るか分からず身構える、が起きる
- 確定の一通に、日時・形式・接続先か場所・誰が出るか・何を話すか・準備は不要・変更のしかた、の七つを入れる。「準備は不要」と「変更のしかた」が重さを取る
- 前日は事実だけの一言（「お忘れなく」の念押しを書かない）、当日は接続先の再送。どちらも短く、催促にしない
- 変更依頼には当日、理由を聞かず、複数の日程で返し、決まったら確定の一通を再送。無断キャンセルには一度だけ確認し、責めず、追わない
- 確定・前日・当日・翌日の四通で、日程確定から面談後までの空白が全部埋まる。最も重いのは確定の一通

## よくある質問

### 三通も送ると、多すぎませんか

三通とも短く、事実だけなら、相手には「安心の連絡」として受け取られます。多いと感じられるのは、一通が長いか、「お忘れなく」のような念押しの言葉が入っているときです。確定の一通は七つで数文、前日は三文、当日は二文で足ります。送らないほうが、相手には「本当にあるのか」「どこに接続するのか」の不安が残ります。

### 対面の面談で、交通費の扱いをどこに書けばよいですか

確定の一通の「形式」のところに、事実で書きます。「対面で、〇〇にお越しください。交通費は△△です」（扱いは自社の制度で確認して、そのとおりに）。書かないと、相手は聞きにくいまま来て、当日に分かることになります。離れた地域の相手への配慮は[地方の学生向けスカウト文面の考え方](/media/kh-bunmen-chihou/)で書きました。

### 面談案内の文面は、御社に相談できますか

できます。当社は、三通の型、七つの整理、変更と無断キャンセルへの返しの型、媒体ごとの違いの整理を支えられます。送ること、日程を出すこと、面談に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
