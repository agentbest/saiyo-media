スカウト文面を学生ごとに変える、と聞くと、「毎回一から書く」と受け取って「そんな時間は無い」となるか、「名前と大学名を差し替えれば個別化」と受け取ってテンプレを送るか、のどちらかになりがちです。ワンキャリアでは、後者は体験談に「テンプレのスカウトだった」と書かれ、次の年の学生も読みます。**結論から言うと、学生ごとに変えるのは「プロフィールの何を読んだか」と「この仕事の最初の1年との重なり」の2か所だけで、選考で何を見るかの一文、話す場か選考かの案内、署名は変えません。2か所を変えるだけで、学生には「自分を読んで送っている」と伝わり、送る側の時間は数文を書く分で済みます。名前と大学名だけの差し替えは、学生に分かり、体験談に残ります。** この記事では、両極の失敗、変える2か所と変えない部分、2か所の書き方、プロフィールが薄い学生の扱い、変えたつもりで変わっていない例、時間の考え方、台帳の使い方、分担を整理します。文面の4段の構成は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。Wantedlyでの考え方は[Wantedlyのスカウトを相手ごとに変える範囲](/media/wt-scout-kojinka/)で書きましたが、ワンキャリアは「体験談に書かれる」が加わります。

## この作業の目的｜続けられる範囲で、学生に「読んだ」と伝える

学生ごとに変える目的は、「あなたを読んで送っている」と学生に伝わることです。全部を変える必要はなく、学生が読んで「自分のことだ」と分かる部分があれば足ります。

同時に、送る側が続けられる範囲であることも条件です。一通に長い時間がかかると、送る数が減り、途中で止まります。目的は、「学生に伝わる最小の範囲を、毎回変える」ことです。

## 両極の失敗

| やり方 | 何が起きるか |
|---|---|
| 毎回、一から全部書く | 一通に時間がかかり、送る数が減り、止まる。書く人によって内容がばらつく |
| 名前と大学名だけ差し替える | 学生には「テンプレ」と分かる。体験談に「テンプレのスカウトが来た」と書かれ、翌年の学生も読む |
| 専攻名だけ入れる（「〇〇学部の方に」） | 専攻は検索で拾えるので、読んだ証拠にならない |
| プロフィールの冒頭の一行だけ引用する | 冒頭だけ読んだと分かる |
| 変える箇所を決めずに、その場で判断する | 送る人によって、変える範囲がばらつく |

「変える箇所を決めておく」が、両極を避ける方法です。決まっていれば、毎回同じ範囲を、同じ時間で変えられます。

## 変える2か所と、変えない部分

| 部分 | 変えるか | 理由 |
|---|---|---|
| 1. プロフィールの何を読んだか | 変える | 学生にしか書けない。ここが読んだ証拠 |
| 2. この仕事の最初の1年との重なり | 変える | 学生の活動のどこが、最初の1年のどこと重なるかは、学生で違う |
| 3. 選考で何を見るかの一文 | 変えない | 募集ごとに一つ。企業ページの選考の流れから取る |
| 4. 話す場か選考かの案内 | 変えない | 募集ごとに一つ |
| 署名 | 変えない | 送る人の名前と近さと会社名 |
| 企業ページへの誘導 | 変えない | 募集ごとに一つ |

変えるのは、最初の2か所です。文面の前半が学生ごとに違い、後半が募集ごとに同じ、という形になります。学生が最初に読むのは前半なので、前半が変わっていれば、後半が同じでも「テンプレ」とは読まれません。

### エージェントベストの見解

これは「どこまでやるか」の線引きの話です。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、「学生ごとに変える」を全部変えることだと受け取った会社は、最初の週は丁寧に書き、翌週から時間が取れずに止まります。逆に、名前と大学名だけ差し替えた会社は、送る数は保てますが、返信が来ず、体験談に「テンプレだった」と書かれ、翌年の学生に読まれます。続いていて返信も来る会社は、変える箇所を2つに決め、一通あたりの時間を一定にしています。当社が線引きを支えるとき、最初に伝えるのは「2か所以外は変えない」ことです。変えないことを決めると、変える2か所に時間を使えます。個別化は、丁寧さの量ではなく、変える箇所の決め方です。

## 変える2か所の書き方

### 1か所目｜プロフィールの何を読んだか

- **プロフィールの中で、募集の「最初の1年」と関係がある箇所を一つ選ぶ**：全部を読んだうえで、一つ
- **その箇所の、本人の言葉をそのまま使う**：「〇〇を続けてきたと書かれていたのを読んで」
- **冒頭ではなく、本文の中から**：冒頭の一行は誰でも読む。活動の具体や興味を挙げると、「全部読んだ」と伝わる
- **大学名、学部名、学年は、1か所目に使わない**：検索で拾える情報は、読んだ証拠にならない
- **1〜2文**

### 2か所目｜最初の1年との重なり

- **1か所目で挙げた活動と、企業ページの「最初の1年」のどこが重なるか**：「その〇〇の経験は、うちの最初の月の△△と、そのまま重なります」
- **企業ページの言葉を使う**：企業ページの「最初の1年」に書いた言葉と揃える。学生が企業ページを読んだときに、つながる
- **一つに絞る**：重なる点が複数あっても、最も強いもの一つ
- **2〜3文**

2か所は、同じ言葉でつなぎます。1か所目で「企画を続けてきた」を挙げたなら、2か所目に「企画」の言葉が入る。つながっていないと、2か所目が型に見えます。

## プロフィールが薄い学生の扱い

学生のプロフィールは、社会人より薄いことが多くあります。

- **書かれている一つ（専攻、興味の一言）から一文を作る**：「〇〇に興味があると書かれていたので」
- **それも無ければ、送らないか、優先を下げる**：話す意思が読めない。絞り込みの段階で優先を下げる。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/)
- **無い情報を推測して書かない**：「〇〇に興味があるのでは」は、外れると信用を失う
- **材料が無いのに送る数を保とうとしない**：材料がある学生に絞るほうが、時間に対する結果が良い

「材料が無ければ送らない」が原則です。材料が無い学生に、大学名だけ差し替えて送ると、テンプレになり、体験談に書かれます。

## 変えたつもりで、変わっていない例

| 変えたつもり | なぜ変わっていないか |
|---|---|
| 「〇〇大学の△△様」 | 大学名と名前は差し替えで入れられる |
| 「〇〇学部で学ばれている方を探しています」 | 検索の条件を書いただけ |
| 「プロフィールを拝見し」 | プロフィールの何を見たかが無い |
| 「素晴らしい活動をされていて」 | 読んでいなくても書ける |
| 「〇〇様の経験は弊社で活かせます」 | どの経験が、最初の1年のどこで、が無い |
| 「〇〇に興味をお持ちの学生の方に」 | 検索の条件 |

共通するのは、「プロフィールの具体的な箇所が無い」ことです。具体的な箇所とは、学生が書いた文の中の、固有の活動や興味です。それが引用されていれば変わっていて、無ければ変わっていません。

## 時間の考え方

一通にかける時間は、「プロフィールを読む時間」と「2か所を書く時間」の合計です。

- **読む時間が大半**：書くのは数文なので、読む時間が一通の時間を決める
- **絞り込みで、読む対象を減らす**：読む対象が絞られていれば、一通の時間が短くなる
- **週に取れる時間から、送れる数を決める**：時間を先に決め、数はその結果
- **一通の時間を一定にする**：2か所だけ変えると決めれば、一定になる

「時間を先に決める」は、絞り込みの記事と同じ考え方です。数を先に決めると、一通の時間が削られ、大学名だけの差し替えになります。

## 台帳で、返信が来た一文と、体験談への言及を見る

送った文面の1か所目と2か所目を、台帳に残します。

- **返信が来た学生の、1か所目と2か所目を並べる**：どんな箇所を挙げたときに返信が来たか。活動か、興味か
- **返信が来ない学生のものと比べる**：具体が薄くなかったか
- **面接で「スカウトのどこに反応したか」を聞く**：1か所目か、2か所目か、選考の一文か
- **体験談にスカウトへの言及があれば読む**：「自分のことを読んでいた」「テンプレだった」。翌年の判断の材料
- **月に一度、読む観点を一つ直す**

「体験談への言及」は、ワンキャリアに特有の材料です。他の媒体では返信と面接の言葉だけですが、ワンキャリアでは学生が体験談にスカウトの印象を書くことがあります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 変えない部分（選考の一文、話す場の案内、署名）を募集ごとに作る | 人事と、面接に出る人 |
| プロフィールを読み、2か所を書く | 読んだ人（人事か、入社してまもない社員） |
| 「変えたつもり」になっていないかを見る | 書いた人と、別の一人（最初の数通だけ） |
| 台帳に2か所を残す | 送った人 |
| 面接で「どこに反応したか」を聞く | 面接に出る人 |
| 体験談へのスカウトの言及を読む | 人事 |
| 月に一度、読む観点を直す | 人事 |

運用代行や代理店が支えられるのは、変える範囲の線引き、変えない部分の作成、「変えたつもり」のチェックの型、台帳の型までで、プロフィールを読むこと、2か所を書くこと、面接で聞くこと、体験談を読むことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「学生ごとに変える部分こそ、代理店に頼めば効率が上がる」という点です。当社がワンキャリアのスカウトの支援をするとき、変えない部分（選考で何を見るかの一文、話す場の案内、署名の形）は当社が作れますし、そのほうが早く整います。ただし、変える2か所は、その仕事を知っている社内の人が書いたほうが、学生に届きます。「この活動が、最初の1年のどこで活きるか」は、その仕事をしている人の言葉で書くと具体になり、当社が書くと一般的になります。当社が最初にお伝えするのは、「変えない部分は当社、変える2か所は社内」の分担です。変えない部分が整っていれば、社内の人が書くのは2か所の数文で、一通あたりの時間は短く済みます。

## まとめ

- 学生ごとに変えるのは「プロフィールの何を読んだか」と「最初の1年との重なり」の2か所だけ。選考の一文、話す場の案内、署名は変えない
- 全部を毎回書くと続かず、名前と大学名だけ差し替えると体験談に「テンプレだった」と書かれ、翌年の学生も読む
- 1か所目は本文の中の具体的な活動や興味を本人の言葉のまま、大学名や学部名は使わない。2か所目は企業ページの「最初の1年」の言葉で、同じ言葉でつなぐ
- 材料が無い学生には送らない。推測で書かない。「変えたつもり」（拝見し、素晴らしい、学部の方に）は変わっていない
- 時間を先に決めて数を決め、台帳に2か所を残し、返信が来た一文と体験談への言及を見て、月に一度読む観点を直す

## よくある質問

### 変えない部分が多いと、学生にテンプレと思われませんか

学生が最初に読むのは前半で、前半（2か所）が学生ごとに違えば、後半が同じでもテンプレとは読まれません。逆に、後半を変えても前半が同じなら、テンプレと読まれます。変える場所は、量ではなく位置です。

### 2か所を書く時間が取れないほど、送る数が多いです

送る数が多すぎます。読んで2か所を書ける数が、送れる数です。大学名だけ差し替えて数を保つと、ワンキャリアでは体験談に残り、翌年まで影響します。絞って2か所を書くほうが、返信の数は増えます。絞り込みの条件を見直します。

### ワンキャリアのスカウトの個別化の線引きは、御社に相談できますか

できます。当社は、変える範囲の線引き、変えない部分の作成、「変えたつもり」のチェックの型、台帳の型を支えられます。プロフィールを読むこと、2か所を書くこと、面接で聞くこと、体験談を読むことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
