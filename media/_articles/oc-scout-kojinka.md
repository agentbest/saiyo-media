「スカウトは一人ずつ変えて送る」と決めても、実際には、毎回ほぼ書き下ろして数週間で手が止まるか、氏名と大学名だけを差し込んで送り続けるかのどちらかに寄りがちです。ワンキャリアでは、学生がスカウトを読んだあとに企業ページ、クチコミ、選考体験談を開いて会社を確かめるため、差し込みだけの文面は確認の段階で見抜かれ、「テンプレのスカウトだった」と体験談に書かれることもあります。**結論から言うと、学生ごとに書くのは「プロフィールから読み取った一点」と「その一点が、企業ページに書いた最初の1年のどこと重なるか」の2か所に絞り、選考で何を見るか、面談かイベントかの案内、署名、企業ページへの誘導は募集ごとに固定します。こうすると、学生には自分に向けた文面だと伝わり、書く側は数文で済むので続けられます。** この記事では、個別化のゴール、続かない二つの形、書く2か所と固定する部分、書き方、材料が少ない場合、個別化したつもりの文面の見分け方、時間と振り返り、分担を扱います。文面全体の構成は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)、Wantedlyでの考え方は[Wantedlyのスカウトを相手ごとに変える範囲](/media/wt-scout-kojinka/)にまとめています。

## 個別化のゴール｜学生が企業ページと体験談で確かめても崩れない文面にする

ワンキャリアのスカウトは、企業ページ、イベントの掲載、クチコミ、選考体験談と同じ会社の枠の中で読まれます。学生は文面で興味を持つと、企業ページで仕事の中身を、体験談で選考や社員の様子を確かめます。

そのため、個別化のゴールは二つあります。一つは、文面を読んだ学生が「自分のプロフィールを読んで送ってきた」と分かること。もう一つは、文面に書いた仕事の話が、企業ページや体験談と食い違わないことです。プロフィールに合わせて文面だけで話を広げると、一つ目は満たせても、二つ目で崩れます。

加えて、送る側が毎週続けられることも条件です。個別化は丁寧さの競争ではなく、続けられる範囲で、学生に届く部分だけを変えることです。

## 書き換えすぎと差し替えだけ、どちらも続かない

| 送り方 | 起きること |
|---|---|
| 毎回、文面を一から書く | 一通の時間が長くなり、数週間で止まる。書き手ごとに内容がばらつき、企業ページとずれる箇所も出る |
| 氏名と大学名だけを差し込む | 学生には一目で分かる。体験談に「誰にでも同じ文面」と残り、翌年の学生も読む |
| 学部や専攻を入れて個別化とする | 検索の条件をなぞっただけで、読んだ証拠にならない |
| プロフィールの最初の一文だけを引く | 冒頭しか読んでいないと伝わる |
| どこを変えるか決めずに、その都度判断する | 書き手によって変える量がばらつき、時間も読めない |

二つの極を避けるには、書く場所を先に決めておくことです。場所が決まっていれば、誰が書いても一通の時間がそろい、続けられます。

## 学生ごとに書く2か所、募集ごとに固定する部分

| 文面の部分 | 扱い | 理由 |
|---|---|---|
| プロフィールから読み取った一点 | 学生ごとに書く | その学生にしか書けない。読んだことが伝わる場所 |
| その一点と最初の1年の重なり | 学生ごとに書く | 学生の経験のどこが仕事のどこにつながるかは、一人ずつ違う |
| 選考で何を見るか | 募集ごとに固定 | 企業ページの選考の流れと同じ言葉にする |
| 面談に誘うか、イベントに誘うか | 募集ごとに固定 | 案内する回や場を募集ごとに決めておく |
| 企業ページへの誘導 | 募集ごとに固定 | 学生が確かめに行く先をそろえる |
| 署名 | 固定 | 送り主の名前、所属、会社名 |

文面の前半が学生ごとに違い、後半が募集ごとに同じ、という形になります。学生が最初に目を通すのは前半なので、そこが自分に向けて書かれていれば、後半が共通でも定型文とは受け取られにくくなります。後半を固定しておくことには、企業ページや体験談と言葉をそろえやすいという利点もあります。

### エージェントベストの見解

個別化の相談を受けると、まず確かめるのは「どこまで書くかを決めているか」です。当社は求人広告代理店として、ワンキャリアのスカウトと掲載をあわせて見ていますが、一人ずつ書くことを全部書き直すことだと受け取った会社は、最初の週に丁寧な文面を送り、その後は時間が取れずに送信が途切れがちです。反対に、差し込みだけで数を保った会社は、受諾が伸びず、体験談に定型文への言及が増えていきます。続いていて受諾もある会社に共通するのは、書く場所を2つに限り、後半を企業ページの言葉で固定していることです。後半がそろっていると、学生が企業ページや体験談を読んだときにも話が一致し、文面への信頼が保たれます。個別化で差がつくのは書いた量ではなく、どこを書き、どこを固定するかの決め方です。

## 2か所の書き方｜プロフィールの言葉と企業ページの言葉をつなぐ

### 1か所目｜プロフィールから読み取った一点

- **プロフィールを最後まで読み、募集の仕事と関わる箇所を一つ選ぶ**：挙げるのは一つで足りる
- **学生自身が書いた言葉を、そのまま使う**：「〇〇に取り組んできたと書かれていたのが目に留まりました」
- **本文の中ほどから選ぶ**：冒頭の一行は誰でも目に入る。活動の具体や関心の一言を挙げると、全体を読んだことが伝わる
- **大学名、学部名、学年は使わない**：検索の条件で拾える情報は、読んだ証拠にならない
- **1〜2文に収める**

### 2か所目｜最初の1年との重なり

- **1か所目の一点が、企業ページの「最初の1年」のどこと重なるかを書く**：「その経験は、入社して最初に担当する△△の場面と近いと感じました」
- **企業ページで使っている言葉を使う**：学生が企業ページを開いたとき、同じ言葉が見つかるようにする
- **重なりは一つに絞る**：複数あっても、最も近いもの一つ
- **企業ページに無い仕事を書き足さない**：確かめに行った学生が見つけられず、文面全体を疑われる
- **2〜3文に収める**

2か所は同じ言葉でつなぎます。1か所目で「〇〇の運営」を挙げたなら、2か所目にも「運営」が出てくるようにします。つながりが切れていると、2か所目だけが定型文に見えます。企業ページとの言葉のそろえ方は[スカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)で書きました。

## 材料が少ないプロフィールへの向き合い方

学生のプロフィールは、書き込みの量に差があります。

- **書かれている一言から書く**：「〇〇に関心があると書かれていたので」のように、短くても本人の言葉を使う
- **何も手がかりが無ければ、送らないか後回しにする**：絞り込みの段階で優先を下げる。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/)
- **書かれていないことを推し量って書かない**：外れると、文面全体の信用を落とす
- **数を保つために材料の無い学生へ送らない**：手がかりのある学生に絞るほうが、時間あたりの受諾は多くなりやすい

手がかりの無い学生に差し込みだけの文面を送ると、それがそのまま体験談の材料になります。送らない判断も、個別化の一部です。

## 個別化したつもりの文面を見分ける

| よくある書き出し | 個別化になっていない理由 |
|---|---|
| 「〇〇大学の△△様」 | 氏名と大学名は差し込みで入る |
| 「〇〇を専攻されている方にお送りしています」 | 検索の条件を書いただけ |
| 「プロフィールを拝見しました」 | 何を読んだかが書かれていない |
| 「魅力的なご経験をお持ちで」 | 読まなくても書ける |
| 「△△様のご経験は弊社で活かせます」 | どの経験が、仕事のどの場面で、が無い |
| 「〇〇に関心のある学生の方へ」 | これも検索の条件 |

見分ける基準は一つで、学生が自分で書いた固有の活動や関心が、文面に引かれているかどうかです。引かれていれば個別化になっており、無ければなっていません。送る前に、別の一人がこの表と照らして読むだけでも、取りこぼしは減ります。

## 一通の時間と、台帳・体験談での振り返り

一通にかかる時間は、プロフィールを読む時間と2か所を書く時間の合計で、そのほとんどは読む時間です。

- **週に使える時間を先に決め、送る数はその結果とする**：数を先に決めると、読む時間が削られ、差し込みに戻る
- **絞り込みで読む人数を減らす**：読む対象が絞れていれば、一通の時間も短くなる
- **書く場所を2つに固定し、一通の時間をそろえる**

送った文面の2か所は、台帳に残して振り返ります。

- **受諾した学生と、しなかった学生の2か所を並べる**：どんな一点を挙げたときに受諾が来たか
- **面談で「スカウトのどこが気になったか」を聞く**：1か所目か、2か所目か、選考の説明か
- **新しく投稿された体験談に、スカウトへの言及があるかを見る**：「自分の話を読んでくれていた」「定型文だった」。翌年の判断の材料になる
- **月に一度、読むときの観点を一つ見直す**

体験談でスカウトの印象を確かめられるのは、ワンキャリアならではの振り返りの材料です。受諾の数だけでは分からない、学生の受け取り方が見えます。

## 社内の分担

| 作業 | 担当 |
|---|---|
| 固定する部分（選考の説明、面談かイベントかの案内、署名）を募集ごとに作る | 人事と、面接に出る社員 |
| プロフィールを読み、2か所を書く | 送り主（人事、または若手社員） |
| 個別化したつもりになっていないかを読む | 書いた人と別の一人（始めの数通だけでも） |
| 2か所を台帳に残す | 送り主 |
| 面談で、スカウトのどこが気になったかを聞く | 面談に出る社員 |
| 体験談のスカウトへの言及を読む | 人事 |
| 月に一度、読む観点を見直す | 人事 |

代理店や運用代行が手伝えるのは、書く場所の線引き、固定する部分の作成、点検の表、台帳の型までです。プロフィールを読むこと、2か所を書くこと、面談で聞くこと、体験談を読むことは企業が担います。

### エージェントベストの見解

個別化を代理店に頼む場合、「学生ごとに書く部分こそ外に出したほうが速い」と考える会社があります。当社がワンキャリアのスカウトを支援するときは、逆の分け方をお勧めしています。固定する部分、つまり選考の説明、面談かイベントかの案内、署名の形は当社で作れますし、企業ページやイベントの掲載と言葉をそろえる作業も、掲載を一緒に見ている立場のほうが進めやすいところです。一方で、学生ごとの2か所は、その仕事をしている社員が書くほうが具体的になります。「この経験が、最初の1年のどの場面につながるか」は、現場を知る人の言葉で書くと学生に届き、外の人が書くと一般論に寄ります。固定する部分を先に整えておけば、社内の人が書くのは数文で済み、一通の時間も短く保てます。

## まとめ

- ワンキャリアの学生は、スカウトのあとに企業ページと体験談で会社を確かめる。個別化は「自分に向けた文面だと分かる」と「企業ページと食い違わない」の両方を満たす
- 学生ごとに書くのは、プロフィールから読み取った一点と、それが最初の1年と重なる点の2か所。選考の説明、面談かイベントかの案内、企業ページへの誘導、署名は固定する
- 1か所目は本人の言葉のまま、大学名や学部名は使わない。2か所目は企業ページの言葉で書き、企業ページに無い仕事を書き足さない
- 手がかりの無い学生には送らない。「拝見しました」「魅力的なご経験」は個別化になっていない
- 時間を先に決めて数を決め、台帳の2か所と体験談でのスカウトへの言及を見て、月に一度読む観点を直す

## よくある質問

### 後半を固定すると、定型文だと思われませんか

学生が最初に読む前半が一人ずつ違えば、後半が共通でも定型文とは受け取られにくくなります。反対に、後半をいくら書き換えても前半が共通なら、定型文に見えます。後半を企業ページの言葉で固定しておくと、学生が企業ページや体験談を確かめたときにも話がそろいます。

### 送る数が多く、2か所を書く余裕がありません

いまの送る数が、書ける数を上回っています。2か所を書ける数を週の送る数とし、絞り込みの条件を見直して読む対象を減らしてください。差し込みで数を保つと、ワンキャリアでは体験談に残り、翌年の受諾にも響きます。

### ワンキャリアのスカウトの個別化を、御社に相談できますか

相談できます。当社は求人広告代理店として、ワンキャリアの掲載とスカウトをあわせて見ており、書く場所の線引き、固定する部分の作成、企業ページとの言葉のすり合わせ、点検の表と台帳の型をお手伝いします。プロフィールを読むこと、2か所を書くこと、面談で聞くこと、体験談を読むことは、企業側で行っていただく形です。
