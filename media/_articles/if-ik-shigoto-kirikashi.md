長期インターン生を受け入れると決めたあと、多くの会社が最初に悩むのは「具体的に何を任せるか」です。思いつくのは雑務ばかりで、それでは学生に申し訳ない。かといって重要な仕事を渡すのは不安がある。**結論から言うと、任せる仕事は、社員の業務を一度書き出し、「手順が決まっている」「途中で止めても困らない」「結果が見える」の三つを満たすものから切り出すと、無理なく始められます。** この記事では、書き出しの手順、切り出しやすい仕事の条件、渡し方の型、起きやすい失敗を整理します。

## 先に社員の業務を書き出す

任せる仕事を考えるとき、「インターン生に何ができるか」から考え始めると、案が出てきません。先にやるのは、受け入れる部署の社員が、いま何に時間を使っているかを書き出すことです。

書き出しは、次の手順で進めます。

1. **一週間の業務を並べる**：部署の社員それぞれに、先週やった仕事を思い出して書いてもらう
2. **繰り返しの仕事に印をつける**：毎週・毎月発生する仕事を見分ける
3. **社員でなくてもできる部分を探す**：一つの仕事の中で、判断が要る部分と、手を動かす部分を分ける
4. **候補を三つほどに絞る**：最初から多くを任せず、受け入れ直後に渡す仕事を決める

3つ目が切り出しの中心です。たとえば「営業資料を作る」という仕事は、構成を決める部分は社員が持ち、過去の事例を集めて表にまとめる部分はインターン生に渡せます。仕事を丸ごと渡すのではなく、仕事の中の一部を切り出すと、任せられるものは意外に多く見つかります。任せる仕事が見つからないときの考え方は[長期インターン生に任せる仕事がないときの切り出し方](/media/if-makaseru-shigoto/)でも扱っています。

## 切り出しやすい仕事の三つの条件

書き出した仕事のうち、最初に任せやすいのは次の三つを満たすものです。

- **手順が決まっている**：やり方を言葉で説明できる。手順書がなくても、社員が口で説明できればよい
- **途中で止めても困らない**：インターン生は授業や試験で出勤しない日がある。その日に仕事が止まっても、顧客や他部署に迷惑がかからない
- **結果が見える**：仕事が終わったかどうか、うまくできたかどうかが、見て分かる

2つ目は、長期インターンならではの条件です。社員と同じように、締め切りが厳しい仕事や、毎日対応が要る仕事を一人で持たせると、学業との両立が難しくなります。締め切りのある仕事を任せる場合は、社員が後ろに控え、インターン生が出勤しない日は社員が引き取る形にしておきます。

3つ目の「結果が見える」は、本人のやりがいにつながります。作業がどこで使われたか分からない仕事は、続けるほど手応えがなくなります。集めたデータが会議の資料に使われた、作った投稿が公開された、といった結果が見える仕事を、少なくとも一つは混ぜておきます。

### エージェントベストの見解

相談で多い思い込みは、「インターン生には、社員がやりたがらない仕事を渡せばよい」というものです。実際には、社員がやりたがらない仕事は、手順が整っていなかったり、判断が多く要ったりして、慣れていない学生には難しいことがよくあります。切り出しの判断に使える問いは、「この仕事を、入社したばかりの社員に渡すとしたら、どう説明するか」です。説明できる仕事は、インターン生にも渡せます。説明できない仕事は、まず社員の側で手順を整えるところから始める必要があります。切り出しは、インターン生のためだけでなく、部署の仕事の中身を見直す機会にもなります。

## 仕事の渡し方の型

切り出した仕事は、次の型で渡すと、本人が迷わず始められます。

| 項目 | 伝えること |
|---|---|
| 目的 | この仕事の結果が、どこで何に使われるか |
| 手順 | 最初から最後までの流れ。分かれ道があれば、その判断の基準 |
| 終わりの形 | どの状態になったら完了か。見本があれば見せる |
| 期限 | いつまでに必要か。出勤しない日を挟む場合の扱い |
| 質問先 | 迷ったときに誰に聞くか |

とくに大切なのは「目的」と「終わりの形」です。目的が分からないと、本人は作業の良し悪しを自分で判断できません。終わりの形が分からないと、完成度にばらつきが出ます。最初の数回は、社員が一緒に手を動かしながら渡し、慣れてきたら確認だけに切り替えます。

手順を言葉にしておくと、次のインターン生にも同じ仕事を渡せます。手順の残し方は[長期インターン向けのマニュアルの作り方](/media/if-ik-manual/)で整理しています。

## 切り出しで起きやすい失敗

切り出しがうまくいかない会社には、いくつかの共通点があります。

1. **細かく切りすぎる**：作業の一部分だけを渡し、全体像が見えない。本人は何のための作業か分からなくなる
2. **一度に多く渡す**：最初から複数の仕事を渡し、どれも中途半端になる
3. **渡したまま広げない**：同じ作業を何か月も続けさせ、次の段階の仕事を渡さない
4. **判断の範囲を決めない**：どこまで自分で決めてよいかが分からず、本人が毎回確認するか、逆に勝手に進める

3つ目は、受け入れから数か月たって起きやすい失敗です。最初に切り出した仕事に慣れたら、次は判断が少し要る部分を渡します。任せる範囲の広げ方は[長期インターン生の育成計画](/media/if-ik-ikusei-keikaku/)で、判断の範囲の決め方は[長期インターン生の責任範囲の決め方](/media/if-ik-sekinin-hanni/)で扱っています。

### エージェントベストの見解

当社は人材紹介も行っているので、中途採用で「即戦力」を求める会社と、長期インターンを受け入れる会社の両方を見ています。即戦力の採用が難しい会社ほど、仕事が切り出されておらず、社員一人ひとりに仕事が固まっています。長期インターンで仕事を切り出す練習をした会社は、その後、中途採用でも「この人には何を任せるか」を具体的に言えるようになります。切り出しに手間取るなら、それは受け入れる側の課題が見えたということです。最初の切り出しには時間がかかりますが、一度やれば部署の仕事の地図ができ、次のインターン生や新しく入る社員にも使えます。

## まとめ

- 任せる仕事は、社員の業務を書き出し、仕事の中の一部を切り出して探す
- 手順が決まっている、途中で止めても困らない、結果が見える、の三つを満たす仕事から始める
- 目的・手順・終わりの形・期限・質問先を伝えて渡す
- 細かく切りすぎず、一度に多く渡さず、慣れたら次の段階の仕事を渡す
- 切り出しは、部署の仕事の中身を見直す機会にもなる

## よくある質問

### 雑務ばかりになってしまいそうで心配です

雑務に見える仕事でも、目的と結果が見えると、本人の受け止め方は変わります。そのうえで、結果が見える仕事を一つは混ぜ、慣れてきたら判断が要る部分を渡していくと、雑務だけで終わることを避けられます。

### 社員の仕事を切り出すと、社員の仕事がなくなりませんか

切り出すのは、社員の仕事の中の手を動かす部分です。社員は判断や顧客対応など、社員にしかできない仕事に時間を使えるようになります。この点を受け入れの前に部署で共有しておくと、社員の協力が得やすくなります。

### 切り出した仕事が、インターン生には難しすぎた場合はどうしますか

仕事をさらに分けるか、社員が一緒に手を動かす期間を延ばします。難しかった理由が手順の説明不足であれば、手順を書き直す機会にもなります。
