長期インターンを受け入れる準備として、「まずマニュアルを作らないと」と考える会社は多いものです。ところが、作り始めると会社の説明から業務の全体像まで書くことが膨らみ、受け入れに間に合わなかったり、作ったものの誰も読まなかったりします。**結論から言うと、インターン向けのマニュアルは、仕事ごとに一枚の手順書を作り、それを積み重ねる形が最も使われます。** この記事では、作る順番、一枚の型、誰が書くか、古くしない工夫を整理します。

## 長期インターンにマニュアルが要る理由

長期インターン生は、社員と違って毎日出勤するわけではありません。授業や試験の合間に、週に数日ずつ働くことが多いです。この働き方には、マニュアルが効く理由がいくつかあります。

- **間が空く**：前の出勤から日が空くと、手順を忘れやすい。見返せるものがあると、思い出す時間が短くなる
- **質問できる相手がいない日がある**：指導する社員が会議や外出でいない日も、手順書があれば作業を進められる
- **入れ替わりがある**：卒業や就職活動で辞める学生がいる。手順書があれば、次の学生に同じ仕事を渡せる

裏返すと、長期インターンのマニュアルに要るのは、会社の歴史や理念の説明よりも、目の前の仕事を一人で進めるための手順です。会社の説明は、初日の受け入れで口頭で伝えれば足ります。

## 作る順番｜全部書こうとしない

マニュアル作りが止まる一番の理由は、最初から全部を書こうとすることです。次の順番で、必要なものから作ります。

1. **最初に任せる仕事を一つ選ぶ**：受け入れ直後に渡す仕事の中で、最も頻度の高いもの
2. **その仕事の手順書を一枚書く**：社員が実際にやりながら、手順を書き出す
3. **インターン生に使ってもらう**：手順書を見ながら作業してもらい、迷った点を聞く
4. **迷った点を書き足す**：本人の質問は、手順書に足りない部分そのもの
5. **次の仕事に進む**：一枚が使えるようになったら、次に任せる仕事の手順書を作る

受け入れ前に用意するのは、最初の一枚か二枚で十分です。残りは、受け入れてから本人と一緒に作ります。任せる仕事の選び方は[長期インターン生に任せる仕事の切り出し方](/media/if-ik-shigoto-kirikashi/)で扱っています。

## 一枚の手順書の型

手順書は、次の項目で一枚にまとめます。

| 項目 | 書くこと |
|---|---|
| 仕事の名前 | 社内で呼んでいる名前。誰が聞いても同じ仕事を指すように |
| 目的 | この仕事の結果が、どこで何に使われるか |
| 準備 | 使うツール、開くファイル、必要な権限 |
| 手順 | 番号をつけて、一つの手順に一つの操作 |
| 迷いやすい点 | 分かれ道と、そのときの判断の基準 |
| 終わりの形 | 完了した状態。見本があればその場所 |
| 質問先 | 迷ったときに聞く人と、その人がいないときに聞く人 |

書くときの注意は次のとおりです。

- **画面の写しを使う**：ツールの操作は、言葉より画面の写しのほうが伝わる
- **一つの手順に一つの操作**：「Aを開いてBを入力しCを押す」ではなく、三つに分ける
- **社内の言葉を説明する**：社員が当たり前に使っている略語や呼び名に、短い説明をつける

とくに「迷いやすい点」は、最初は空欄でも構いません。インターン生の質問が集まるたびに書き足していくと、使うほど良い手順書になります。

### エージェントベストの見解

相談で多い思い込みは、「マニュアルは社員が完成させてから渡すもの」というものです。実際には、社員が書いた手順書は、社員にとって当たり前のことが抜けていて、初めての人には分かりにくいことがよくあります。勧めているのは、社員が最初の版を書き、インターン生がそれを使って作業し、つまずいたところを本人が書き足す流れです。本人が書き足した手順書は、次のインターン生にとって最も分かりやすいものになります。さらに、手順書を直す作業そのものが、本人にとって「仕事を言葉にする」経験になります。手順書の更新を、半年ほどたったインターン生の目標に入れる会社もあります。社員が完璧に書こうとして止まるより、粗い一枚を渡して一緒に育てるほうが、受け入れには間に合います。

## 誰が書くか

手順書を書く役割は、次のように分けると負担が偏りません。

- **最初の版**：その仕事をいまやっている社員。実際にやりながら書くと抜けが少ない
- **書き足し**：手順書を使ったインターン生。迷った点と、その答えを書き加える
- **確かめ**：指導する社員。書き足された内容が正しいかを見る
- **置き場所の管理**：人事・採用担当。手順書の一覧と保存場所をまとめる

置き場所は一か所に決めます。チャットやメールに散らばると、どれが最新か分からなくなります。共有フォルダに手順書の一覧のページを作り、そこから各手順書を開けるようにしておくと探しやすくなります。指導する社員の役割は[長期インターン生を指導する社員の選び方](/media/if-ik-shidou-shain/)で整理しています。

## 古くしない工夫

手順書は、作った時点から古くなり始めます。ツールの画面が変わる、仕事のやり方が変わる、担当者が替わる。古い手順書は、ないよりもかえって混乱のもとになります。

1. **最後に直した日を書く**：手順書の上に日付を書いておくと、古いかどうかが一目で分かる
2. **使った人が直す**：手順と実際の作業が違っていたら、気づいた人がその場で直す
3. **節目に見直す**：学期の切り替わりや、インターン生の入れ替わりのときに、一覧を見て使っていないものを整理する
4. **使っていない手順書は消す**：もうやっていない仕事の手順書は、残しておくと混乱する

### エージェントベストの見解

当社は人材紹介も行っているため、新卒や中途で入った人の立ち上がりが、受け入れ側の準備によってどれほど変わるかを両側から見ています。手順書がある会社では、入った人が最初の数週間で自分の仕事を回せるようになり、指導する社員の負担も早く軽くなります。長期インターン向けに作った手順書は、そのまま新卒や中途の受け入れにも使えます。インターン生は入れ替わりが多い分、手順書が古くなるのも、足りない部分が見つかるのも早い。インターンの受け入れを続けている会社ほど、手順書が使われ続け、新しく入る社員の受け入れも整っていきます。マニュアル作りを受け入れの手間と考えるより、会社の仕事を残す作業と考えるほうが、社内の協力も得やすくなります。

## まとめ

- 長期インターンのマニュアルは、仕事ごとに一枚の手順書を積み重ねる形にする
- 受け入れ前は最初の一枚か二枚だけ作り、残りは受け入れてから一緒に作る
- 目的・準備・手順・迷いやすい点・終わりの形・質問先を一枚にまとめる
- 社員が最初の版を書き、インターン生が書き足し、指導する社員が確かめる
- 最後に直した日を書き、使った人が直し、使わないものは消す

## よくある質問

### 動画のマニュアルと文書のマニュアル、どちらがよいですか

ツールの操作は動画のほうが伝わりやすく、判断の基準や分かれ道は文書のほうが見返しやすい傾向があります。一枚の手順書に、操作の部分だけ短い動画をつけるやり方も使えます。

### 会社の理念や行動の指針も、マニュアルに入れるべきですか

入れるなら、手順書とは別の一枚にします。仕事の手順と混ぜると、どちらも読まれにくくなります。理念は初日に口頭で伝え、振り返りの面談で具体的な場面と結びつけて話すほうが伝わりやすいです。

### インターン生が手順書どおりに作業しません

手順書のほうが実際の作業に合っていない可能性があります。本人がどこで手順を変えたのか、その理由を聞き、手順書を直す機会にします。理由のない省略であれば、手順の目的を改めて伝えます。
