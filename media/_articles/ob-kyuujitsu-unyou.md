OfferBoxの承認は、企業の営業日に合わせて来るわけではありません。週末にも、長期休暇の間にも来ます。**結論から言うと、休日と長期休暇の運用で決めることは3つです。週末の承認は翌営業日の午前に返すと線引きする、長期休暇の前に承認を全部返し切って送る数を減らす、休暇明けの最初の作業を「休暇中の承認への返信」にする。この3つで、休暇明けに承認が溜まっている状態を防げます。** 加えて、学生側も休みなので返信が遅くなる前提で、追いかけを急ぎません。この記事では、週末、長期休暇の前、休暇中、休暇明け、学生側の休み、休暇をまたぐ選考の順で整理します。当日返信の体制の基本は[承認からの連絡を早くする体制](/media/ob-sokujitsu-taiou/)で書きました。この記事は、その体制が崩れやすい休日と休暇に絞った話です。

## この作業の目的｜休暇明けに「溜まった承認」を作らない

長期休暇の明けに管理画面を開くと、休暇中の承認がまとまって溜まっている。まとめて返そうとして数日かかり、承認から返信まで1週間以上空き、承認した学生の多くが他社の面談を入れている。この状態が、休暇明けに最も起きやすい止まり方です。

目的は、休暇明けに溜まった承認を作らないことです。溜まってから速く返すのではなく、溜まらないように休暇前に整えます。

## 手順1｜週末の承認は、翌営業日の午前に返す

週末の承認は、毎週起きます。線引きを決めておきます。

| 承認の時間 | 返信の線引き |
|---|---|
| 平日の営業時間内 | 当日中 |
| 平日の営業時間後 | 翌営業日の午前 |
| 土日・祝日 | 翌営業日の午前。週明けの最初の作業にする |
| 連休の中日 | 連休明けの午前。連休が長い場合は、次の手順の長期休暇として扱う |

「翌営業日の午前」を守るには、週明けの最初の作業を「週末の承認への返信」に固定します。月曜の朝の会議の前に、管理画面を開いて返す。この順番にすると、月曜の午前に返せます。会議のあとにすると、午後か翌日になります。

週末に承認が来ることを前提に、金曜に送る数を調整する考え方もあります。金曜に多く送ると、週末に承認が来て、月曜に溜まります。週の前半に送る山を置くと、承認が平日に来て、当日に返せます。送る曜日の考え方は[送る時期と時間帯の考え方](/media/ob-soushin-timing/)で書きました。

## 手順2｜長期休暇の前に、承認を返し切り、送る数を減らす

年末年始、大型連休、夏季休暇のような長期休暇の前は、次の順で整えます。

1. **休暇の前の週に、送る数を減らす**：休暇中に承認が来ても返せない。休暇に入る数日前からは送らないか、大幅に減らす
2. **休暇前の最終営業日に、承認を全部返す**：溜まっている承認をゼロにしてから休暇に入る
3. **日程調整中の学生に、休暇の予定を伝える**：「〇日から△日まで休業のため、返信が遅れます。△日以降に改めてご連絡します」。学生が「返事が来ない」と不安にならないように
4. **面談の日程を、休暇明けの週に入れすぎない**：休暇明けは承認への返信で手一杯になる。面談は休暇明けの2週目以降に寄せる
5. **休暇中の承認への自動の一言を用意する**：媒体に、承認への自動の返信や不在の案内を設定する機能があれば使う。機能の有無と設定の方法は、管理画面と媒体の案内で確認する。無ければ、休暇前の連絡で伝えておく

「送る数を減らす」が、最も効く準備です。休暇中に承認が来なければ、休暇明けに溜まりません。送る山は、休暇の前ではなく、休暇明けの落ち着いた週に置きます。

### エージェントベストの見解

申し込んだあと、長期休暇の明けに起きやすいのは、「休暇の直前に、休暇中に読まれることを期待して多く送る」ことです。学生は休暇中にプロフィールを見る時間があるから、と考えて送るのですが、承認が休暇中に来て、企業側は返せず、休暇明けに溜まります。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、休暇明けに承認が溜まって面談に進まなかった会社の多くは、休暇前に送る数を増やしていました。逆に、休暇前に送る数を減らし、休暇明けの落ち着いた週に送る山を置いた会社は、承認が平日に来て当日に返せています。学生が読む時間があるかどうかより、企業が返せるかどうかで、送る時期を決める。休暇前は、送る時期ではなく、返し切る時期です。

## 手順3｜休暇中の代理と、見ない判断

休暇中に誰かが管理画面を見るかどうかを、先に決めます。

- **代理を置く**：休暇中も出勤する人がいれば、返信の型と日程の候補を渡し、承認があれば返してもらう。代理の置き方は当日返信の体制の記事で
- **代理を置かず、見ない**：全社が休暇なら、見ない判断も現実的。その場合は、休暇前に送る数を減らし、承認を返し切り、休暇の予定を学生に伝えておく。休暇明けの最初の作業で返す
- **担当だけが見る**：休暇中に担当が管理画面を見るのは、担当の負担になる。続かないので、勧めない。見るなら代理として出勤している人が

「見ない」と決めるなら、その分、休暇前の準備を厚くします。見ないのに準備をしないのが、最も溜まります。

## 手順4｜休暇明けの最初の作業

休暇明けの最初の営業日の午前を、次の作業に使います。

1. **休暇中の承認を、全部返す**：型と候補で。休暇の前に候補を用意しておくと速い
2. **日程調整中だった学生に、改めて連絡する**：「休業が明けましたので、改めて候補をお送りします」
3. **休暇中に届いた質問に答える**：答え方は[学生からの質問に答える文面](/media/ob-offer-gakusei-shitsumon/)
4. **選考中の学生に、次の段階の日程を送る**：休暇をまたいだ分、空白が長い。早めに
5. **その週の送る数を決める**：返信が落ち着いてから送り始める。休暇明けの初日から送らない

休暇明けの最初の午前を、会議や他の業務で埋めないことが要点です。「休暇明けの午前は承認への返信」を、社内で先に決めておきます。

## 手順5｜学生側も休みである前提で、追いかけを急がない

長期休暇は、学生も休みです。帰省、旅行、アルバイト、実家での家族との時間。返信が遅くなる前提で、追いかけの間隔を空けます。

| 場面 | 通常 | 休暇をまたぐ場合 |
|---|---|---|
| 承認への返信に返事が無い | 数日空けて1回追いかけ | 休暇が明けてから数日空けて1回。休暇中には追いかけない |
| 面談後の返事が無い | 期限の前に1回 | 期限を休暇明けに置き直す。休暇中に期限を切らない |
| 選考の結果連絡への返事 | 翌日まで | 休暇明けの数日まで |
| 内定の承諾期限 | 他社の時期を聞いて置く | 休暇をまたぐなら、休暇明けの先に置く。家族と相談する時間を見込む |

内定の承諾期限を休暇中に切ると、学生は家族と相談する時間が取れないまま期限を迎えます。休暇明けの先に置きます。内定後の連絡の考え方は[内定を出したあとのフォロー](/media/ob-naitei-follow/)で書きました。

## 手順6｜休暇をまたぐ選考の連絡

選考の途中で休暇をまたぐ学生には、休暇前に一言入れます。

- **次の段階の日程を、休暇前に確定しておく**：休暇明けの2週目以降で。空白が長くならないように
- **確定できないなら、休暇明けにいつ連絡するかを伝える**：「〇日に次の日程をご連絡します」
- **休暇中は連絡しないことを伝える**：「休業中は返信が遅れます」。学生が「連絡が無い」と不安にならないように
- **休暇明けに、伝えた日に連絡する**：伝えた日を守ることが、信頼になる
- **面接官の枠を、休暇明けに集中して確保する**：休暇をまたいだ学生の面接を、休暇明けに集中させる。面接官に先に頼む

「休暇中は連絡しない」と伝えておくと、学生は待てます。伝えずに連絡が途切れると、学生は「忘れられた」と感じます。連絡設計の考え方は[承認後の辞退を減らす連絡設計](/media/ob-jitai-boushi/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 週末の承認を月曜の午後以降に返す | 週明けの承認から返信まで空く | 週明けの最初の作業に固定 |
| 休暇の直前に多く送る | 休暇中に承認が来て溜まる | 休暇前は送る数を減らす |
| 休暇前に承認を返し切らない | 休暇明けに溜まる | 最終営業日に全部返す |
| 休暇の予定を学生に伝えない | 「返事が来ない」と不安になる | 日程調整中と選考中の学生に一言 |
| 休暇明けの午前を会議で埋める | 返信が午後か翌日に | 午前は返信に固定 |
| 休暇明けの初日から送る | 返信と送信が重なって両方遅れる | 返信が落ち着いてから |
| 休暇中に追いかける | 学生も休み。しつこいと受け取られる | 休暇明けに |
| 承諾期限を休暇中に切る | 家族と相談できずに期限を迎える | 休暇明けの先に置く |

最も多いのは、「休暇の直前に多く送る」です。良かれと思ってやることが、休暇明けの溜まりを作ります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 休暇前後の送る数を決める | 人事 |
| 最終営業日に承認を返し切る | 返信の担当 |
| 学生に休暇の予定を伝える | 人事（または運用代行） |
| 休暇中の代理、または見ない判断 | 人事の責任者 |
| 休暇明けの午前を返信に固定する | 人事の責任者（社内に周知） |
| 休暇明けの面接官の枠を確保する | 面接官 |
| 休暇をまたぐ学生への連絡 | 人事 |

運用代行に出している場合、休暇中も代行が承認を見て返せるかは、代行の営業日によります。当社の場合、休暇の期間と、その間の返信の扱いを、休暇の前に企業と決めます。代行の範囲は[運用代行に任せられる範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと休暇明けが崩れることがあります。「休暇明けの最初の午前は、承認への返信に使う」と、社内で先に決めておくことです。当社がOfferBoxの運用の相談で休暇明けの話を聞くとき、休暇明けの初日が全社会議や挨拶回りで埋まり、管理画面を開くのが午後か翌日、という会社は少なくありません。休暇前に承認を返し切っていても、休暇中に来た承認は、休暇明けの初日に返さないと、承認から返信まで休暇の日数分が空きます。当社がOfferBoxの運用代行で休暇をまたぐときは、休暇前に企業と「休暇明けの初日の午前に、当社が休暇中の承認を全部返す。面談枠は休暇明けの2週目から」と決めておきます。決めてあれば、休暇明けの初日の午前に返せます。決めていなければ、他の業務に押されます。休暇明けの午前は、休暇前に予約しておくものです。

## まとめ

- 週末の承認は翌営業日の午前に返す。週明けの最初の作業に固定する
- 長期休暇の前は、送る数を減らし、最終営業日に承認を返し切り、学生に休暇の予定を伝える
- 休暇中は、代理を置くか、見ないと決めて休暇前の準備を厚くする。担当だけが見るのは続かない
- 休暇明けの最初の午前は、休暇中の承認への返信に使う。送り始めるのは返信が落ち着いてから
- 学生も休み。追いかけは休暇明けに。承諾期限は休暇明けの先に置く

## よくある質問

### 長期休暇の前に送っておけば、休暇中に学生が読んでくれるのではないですか

読む学生はいますが、承認が休暇中に来て、企業側は返せず、休暇明けに溜まります。承認から返信まで休暇の日数分が空き、面談に進まない承認が増えます。休暇前は送る数を減らし、送る山は休暇明けの落ち着いた週に置くことを勧めます。

### 休暇中に承認が来たら、担当が自宅から返してもよいですか

担当の負担になり、続きません。代理として出勤している人がいれば型で返してもらい、いなければ「見ない」と決めて、休暇前に承認を返し切り、学生に休暇の予定を伝えておきます。休暇明けの初日の午前に返せば、学生は待てます。

### 休暇中の運用は、御社に頼めますか

当社の営業日の範囲で、承認への返信を続けられます。当社の休暇と重なる期間は、休暇前に企業と扱いを決め、学生に伝える連絡を当社から送ります。休暇明けの初日の午前に、休暇中の承認を全部返す形にしています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
