ワンキャリアのスカウトから来た学生は、文面を読み、企業ページを読み、自社の体験談を読んで、面談に来ます。他の媒体より、来る前に持っている情報が多い学生です。**結論から言うと、スカウト経由の初回面談は、「文面で案内した人が出て、企業ページに書いたことを話し、学生が『読んだとおりの会社だった』と感じる場」として設計します。話す人・時間・形・流れ・終わったあとの選択肢・選考との関係を先に決め、流れは、短い自己紹介、体験談で気になったことを聞く、最初の1年の場面を一つ話す、質問に答える、次の選択肢を伝える、の順にします。「体験談で気になったことを先に聞く」が、ワンキャリアに特有の要点です。** この記事では、面談の役割、やりがちな失敗、決めること、流れの型、聞くこと・聞かないこと、面談後の連絡、企業ページへの反映、分担を整理します。受諾後の進め方は[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/)で書きました。他媒体の面談は[OfferBoxの面談設計](/media/ob-mendan-sekkei/)と[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

## この作業の目的｜「読んだとおりの会社だった」と感じてもらう

スカウト経由の学生は、文面・企業ページ・体験談の三つを読んで来ています。面談で、それらと違うことが起きると、「文面は釣りだった」「企業ページは建前だった」「体験談のほうが本当だった」と感じます。

目的は、三つと面談が揃っていて、「読んだとおりの人が出てきて、読んだとおりの話が聞けた」と感じてもらうことです。面談は、文面と企業ページの続きです。ワンキャリアでは、面談の印象が体験談に書かれ、次の年の学生が読みます。

## やりがちな失敗

| 失敗 | 学生からどう見えるか |
|---|---|
| 選考の面接にする（志望動機、評価） | 「話す場」と聞いて来たのに、面接だった。体験談に書かれる |
| 人事だけが出る | 「仕事の中身を、やっている人から聞けなかった」 |
| 会社説明会になる | 企業ページに書いてあることを聞かされる |
| 文面で案内した人と違う人が出る | 「この人と話せると思った」 |
| 体験談で気になったことを聞かない | 学生は問いを持って来ているのに、話す機会が無い |
| 企業ページと違うことを言う | 「企業ページは建前」 |
| 学生に話させず、会社側が話しすぎる | 自分のことを聞いてもらえなかった |
| 終わったあとの選択肢が無い | 「楽しかった」で終わる |
| 時間が長い | 授業とアルバイトの合間に来ている |

最も多いのは、最初の「選考にしてしまう」です。会社側は「せっかく来たのだから見極めたい」と考えますが、学生は「話を聞きに来た」だけです。ワンキャリアでは、その失敗が体験談に残ります。

## 決めること

| 決めること | 決め方 |
|---|---|
| 話す人 | 文面で案内した人。入社してまもない社員が主。人事は進行と、終わったあとの案内 |
| 時間 | 短く。授業やアルバイトの合間に来られる長さ |
| 形 | オンラインが基本。来社は学生が望めば |
| 流れ | 下の型を、自社に合わせて。毎回同じ流れにする |
| 終わったあとの選択肢 | 選考に進む、もう一度別の人と話す、いったん終わる、の三つを最後に伝える |
| 選考との関係 | 話す場なら「選考ではない」を守る。年度の公表内容と自社の方針を確認 |
| 話す場面 | 話す人が、最初の1年の場面を一つ用意する |
| 聞くこと・聞かないこと | 事前に決める。下で |

「終わったあとの選択肢を三つ用意する」が、雑談で終わらないための仕組みです。「もう一度別の人と話す」があると、迷っている学生が残ります。

### エージェントベストの見解

相談で最も多い思い込みは、「スカウト経由の学生は会社を知らないので、面談では会社の説明から始めるべきだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、ワンキャリアのスカウト経由の学生は、他の媒体より来る前に持っている情報が多く、企業ページと体験談を読んで、問いを持って来ています。会社の説明から始めると、「企業ページに書いてあったことを聞いた」と体験談に書かれます。当社が面談の設計を支えるとき、最初にやるのは、会社の説明の時間を無くし、「体験談で気になったことはありますか」の一問を最初に置くことです。学生は、その一問で「この会社は、体験談を読んでいる自分を分かっている」と感じます。面談は、説明の場ではなく、学生の問いに答える場です。

## 流れの型

| 順 | 内容 | 時間の配分 |
|---|---|---|
| 1 | 短い自己紹介。「選考ではなく、お互いを知る場です」「企業ページと体験談を読んでいたら、気になったことから聞いてください」と最初に言う | 短く |
| 2 | 体験談や企業ページで気になったことを聞く。学生が持って来た問いに、先に答える | 中くらい |
| 3 | 話す人が、最初の1年の場面を一つ話す。企業ページの「最初の1年」と同じ内容で、実際にあった話 | 中くらい |
| 4 | 質問に答える。人事が最初の質問を出して口火を切ってもよい | 長く |
| 5 | 次の選択肢を伝える。選考に進む、別の人と話す、いったん終わる。「今日決めなくてよい」と添える | 短く |

「2を最初に置く」が、ワンキャリアの面談の型の要点です。学生が持って来た問い（体験談で読んだこと）に先に答えると、そのあとの話が具体になります。

会社の説明、事業の説明、制度の説明は、企業ページに任せ、面談では話しません。「詳しくは企業ページに書いてあります」で足ります。

## 学生に聞くこと、聞かないこと

| 聞くこと | 聞かないこと |
|---|---|
| 「企業ページや体験談で、気になったことは」 | 志望動機、「なぜうちに」 |
| 「スカウトのどこを読んで、話を聞こうと思ったか」 | 就職活動の状況、他社の選考状況 |
| 「いま、学生時代に何に時間を使っているか」 | 評価のための質問（強み、弱み、失敗から学んだこと） |
| 「今日、聞いておきたいことは」（最初に） | 「いつから就職活動を始めたか」 |
| 「働き方で、気になっていることは」 | 仕事に関係ない個人の事情（家族、健康、出身、信条など） |
| 「体験談に書かれていたことで、確かめたいことは」 | 「内定はあるか」 |

「聞かないこと」の一覧を、面談に出る人に渡しておきます。特に、仕事に関係ない個人の事情は、雑談の流れで聞いてしまいやすく、採用の場では配慮が求められる事項です。聞かないことの考え方は[Wantedlyのカジュアル面談で聞くこと・聞かないこと](/media/wt-scout-mendan-shitsumon/)で書きましたが、学生には「就職活動の状況」と「内定の有無」が加わります。

## 話す人の準備

面談に出る人が、事前にやることは四つだけです。

1. **学生のプロフィールと、送ったスカウトの文面を読んでおく**：文面で挙げた活動から話を始められる
2. **企業ページを読んでおく**：書いたことと違うことを言わないため
3. **自社の体験談を読んでおく**：学生が気になっていそうなことを知っておく
4. **最初の1年の場面を一つ用意する**：うまくいった話でなくてよい。詰まった話のほうが、学生は質問しやすい

「自社の体験談を読んでおく」が、他の媒体の面談と違う準備です。学生が体験談で読んだことを、話す人が知らないと、問いに答えられません。

## 面談後の連絡

1. **翌日までに、一言送る**：「昨日はありがとうございました。〇〇の質問、△△が喜んでいました」
2. **面談で伝えた選択肢を、もう一度書く**：選考に進む、別の人と話す、いったん終わる
3. **選考に進む場合の流れを、企業ページと同じ内容で**：面談と選考がずれないように。[カジュアル面談から選考へ移す方法](/media/wt-scout-senkou-ikou/)の考え方
4. **学生の返事を待つ**：急かさない。試験期間なら待つ。数日で返事が無ければ、一度だけ短く確認
5. **「いったん終わる」を選んだ学生にも、お礼を送る**：体験談に書かれるのは、この対応

「翌日までに」は、受諾への対応と同じ原則です。面談の直後が、学生の気持ちが最も動いている時間です。

## 面談で聞いたことを、企業ページに戻す

スカウト経由の面談は、企業ページの材料が集まる場です。

- **「体験談で気になったこと」の答え**：企業ページの「よく聞かれること」に足す
- **「スカウトのどこを読んで来たか」**：文面の型と絞り込みの材料
- **「企業ページで分からなかったこと」**：企業ページに足りない部分
- **学生からの質問**：学生が知りたいことは、企業ページに足りないこと
- **「体験談と違った」と感じたこと**：企業ページか運用を直す。[企業ページを更新し続ける方法](/media/oc-kigyo-page-koushin/)

面談に出る人が、この一行を人事に送る形を作ります。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がワンキャリアのスカウト経由の面談を支えるとき、流れの型、準備の項目、聞かないことの一覧、連絡の型は当社が出せます。ただし、面談に出て話すことは、当社にはできません。スカウト経由の学生は、「文面を送ってきたこの人と話したい」と思って来ています。当社が同席したり、代わりに話したりすると、その時点で「会社の人ではない」と分かり、面談の意味が薄れ、体験談にもそう書かれます。当社が最初にお伝えするのは、「面談に出る人は、文面で案内した社内の人にしてください。当社は、その人が困らないように型と準備を渡します」ということです。文面と同じ人が出ることが、スカウト経由の面談の価値です。

## まとめ

- スカウト経由の学生は、文面・企業ページ・体験談を読んで来る。面談は「読んだとおりの会社だった」と感じてもらう場
- 選考にする、人事だけ、会社説明会、文面と違う人、体験談で気になったことを聞かない、が失敗。体験談に書かれる
- 話す人（文面で案内した人）・時間・形・流れ・三つの選択肢・選考との関係を先に決める
- 流れは、自己紹介→体験談で気になったことを聞く→最初の1年の場面を一つ→質問（長く）→次の選択肢。会社の説明はしない
- 志望動機、就職活動の状況、内定の有無、評価のための質問、個人の事情は聞かない。翌日までに連絡し、聞いた一行を企業ページに戻す

## よくある質問

### 面談で、合わない学生だと分かったらどうしますか

その場では「お互いを知る場」として最後まで進め、選択肢を伝えます。学生も同じように判断しているので、「いったん終わる」を選ぶことが多くあります。会社側から断る必要がある場合は、翌日の連絡で丁寧に伝えます。面談の途中で態度を変えると、体験談に書かれます。

### 学生が、体験談で気になったことを聞いてくれません

最初に「体験談を読んでいたら、気になったことから聞いてください」と言い、それでも出なければ、人事が「体験談に〇〇と書かれていたことについて、話す人から」と口火を切ります。自社の体験談を読んでいれば、学生が気になっていそうなことを先に話せます。話す人が体験談を読んでおくのは、このためです。

### スカウト経由の面談の設計は、御社に相談できますか

できます。当社は、流れの型、聞くこと・聞かないことの一覧、話す人の準備の項目、面談後の連絡の型、聞いた言葉を企業ページに戻す型を支えられます。面談に出ること、話すこと、選択肢を伝えることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
