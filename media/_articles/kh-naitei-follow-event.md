内定者向けのイベントを企画したい。ところが、懇親会と内定式と研修とレクリエーションを並べ、会社の説明を繰り返し、内定者に自己紹介と発表をさせ、現場の社員は出ずに人事だけで回して、内定者から「行く意味が分からない」と欠席が増える。**結論から言うと、イベントは「会う場」で、目的は「入社したら誰と何をするか」を内定者が自分の目で見ることです。中身は「配属先の見学・現場の社員の仕事を見る・同期になる内定者と会う」の三つで足り、懇親会・研修・レクリエーションは要りません。一年に二つか三つに絞り、一つずつに「何を見せるか」を先に決め、承諾前には置きません。企画で決めるのは、日程と会場の前に「誰が現場から出るか」と「その人の時間」です。** 四つの中身の基本は[内定者フォローの基本](/media/kh-naitei-follow-kihon/)、年間の並べ方は[内定者フォローの年間計画](/media/kh-naitei-follow-nenkan/)で書きました。この記事は、会う場の中身と企画の順番を書きます。

## この作業の目的｜内定者が「誰と何をするか」を、自分の目で見る

イベントは、内定者に会社を好きになってもらう場ではなく、内定者が「入社したらこの場所で、この人と、この仕事をする」を自分の目で確かめる場です。それが見えた内定者は、入社の日まで「何をするか」を持ち続けます。

目的は、内定者を集めることではなく、内定者に「見せるもの」を用意することです。

## 内定者イベントで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 懇親会を目的にする | 食事と歓談で終わり、「何をするか」は見えない。静かな内定者が疲れる |
| 会社の説明の場にする | 選考で聞いた話の繰り返しで、残らない |
| 数を増やす | 内定者の時間を奪い、欠席が増え、出席の管理が仕事になる |
| 承諾前に置く | 「囲い込み」と読まれ、押されて決めたと後で気付いて辞退する |
| 内定者に発表させる | 序列ができ、発表が苦手な内定者が離れる |
| 現場の社員が出ない | 人事だけで回し、入社後に一緒に働く人が見えない |

共通するのは、イベントを「会社がすること」で組んでいて、「内定者が見るもの」で組んでいないことです。

## イベントの中身は、三つ

| 中身 | 何を見せるか | 型 |
|---|---|---|
| 配属先の見学 | 実際に働く場所。机、機械、店、現場。移動の道 | 配属先の責任者が案内し、そこで働く社員が一言。時間は短く |
| 現場の社員の仕事を見る | 実際の仕事の一場面。会議、作業、接客、開発の画面 | 見学の中に組む。説明ではなく、実際にしているところを見る |
| 同期になる内定者と会う | 入社後に一緒に働く同期の顔と名前 | 少人数で。発表させず、自己紹介は名前と配属先だけ |

三つを一つのイベントに組んでも、分けてもよく、一年で二つか三つの場で三つが揃えば足ります。懇親会は、見学の後に短く添えるなら意味がありますが、それだけの場は要りません。

### エージェントベストの見解

相談で最も多い思い込みは、「内定者イベントは、内定者どうしを仲良くさせる場で、懇親会を増やすほど辞退が減る」というものです。当社は3媒体すべての販売パートナーとして、内定後の運用まで見ていますが、懇親会を増やした会社ほど、内定者の欠席が増え、「行く意味が分からない」と読まれ、辞退は減りません。内定者どうしの仲は、入社してから自然にできます。内定者が入社前に確かめたいのは、同期の顔より、「自分が働く場所と、一緒に働く人と、する仕事」です。それを見せずに懇親会を重ねると、「会社は何も見せてくれない」と読まれます。当社が最初にお願いするのは、懇親会をやめ、配属先の見学を一つ置くことです。見学は、会場も食事も要らず、現場の責任者と、そこで働く社員が一人出れば済みます。見学で「ここでこの人とこれをする」が見えた内定者は、入社の日まで持ち続けます。懇親会を三つするより、見学を一つするほうが、辞退を減らします。

## 一年に、二つか三つに絞る

- **承諾直後には置かない**：承諾前と承諾直後は「決めるための材料」の時期で、会う場は「囲い込み」と読まれる
- **中だるみの時期に、配属先の見学を一つ**：承諾から時間が経ち、「何をするか」が薄れた頃に、見せる
- **同期と会う場を、一つ**：見学と同じ日に組んでもよい。少人数で、発表させない
- **入社直前には置かない**：引っ越しと卒業の手続きの時期。入社の日に会う
- **内定式は、三つの中身のどれかを含むなら置く**：式典だけなら、内定者の時間を奪う側

二つか三つで足ります。年間の表に、どの月に何を見せるかで書きます。

## 企画の順番｜何を見せるか → 誰が出るか → 日程

1. **何を見せるかを、先に決める**：配属先の見学か、仕事の一場面か、同期か。「懇親」「交流」は見せるものではない
2. **誰が現場から出るかを、決める**：配属先の責任者と、そこで働く社員。人事だけでは見せられない
3. **その人の時間を、確保する**：見学に何分、一言に何分。現場の繁忙期を避ける
4. **日程を、内定者の節目を避けて置く**：卒業研究の山、旅行、帰省を避ける。候補日を複数出して選べる形に
5. **会場は、最後に**：見学なら職場そのもの。外の会場は要らない

会場と日程から決めると、「何を見せるか」が後回しになり、懇親会になります。見せるものと、出る人から決めます。

## 当日の型と、後の一通

- **当日は、短く**：見学と一言と、同期と会う時間で、長くしない。説明の時間を作らない
- **内定者に、発表させない**：自己紹介は名前と配属先だけ。課題の発表、抱負の発表はしない
- **現場の社員が、仕事の話をする**：会社の説明ではなく、「最近の仕事で何があったか」「最初の年に何をしたか」
- **質問の時間より、質問の窓口**：その場で質問が出なくてよい。後で送れる窓口を伝える
- **後の一通は、現場の社員から**：「来てくれてありがとう。見てもらった〇〇は、いま△△になっている」。人事からの礼状より、現場からの一通
- **欠席した内定者には、別の形で**：見学の写真と、現場の社員の一言を送る。次の候補日を伝える

イベントは当日で終わらず、後の一通で「見たもの」が「持ち続けるもの」に変わります。

## 媒体ごとに、変わる点

- **OfferBox**：オファーの文面で書いた仕事と、見学で見せる場所と人が同じであること。文面の名義の社員が見学の一言を担う。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **Wantedly**：記事に書いた日常と、見学で見せる場面をつなげる。記事を書いた社員が案内する。[Wantedly経由の内定辞退が続くとき](/media/wt-naitei-jitai/)
- **ワンキャリア**：体験談で読んだ選考の人と、見学で会える形に。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

三つとも、三つの中身は同じで、入口で読んだものと、見学で見せるものを、同じ場所と人でつなげることが要です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 何を見せるかと、一年の回数を決める | 採用の責任者 |
| 現場から出る人と、その時間を決める | 配属先の責任者 |
| 日程の候補を出し、内定者の節目を避ける | 人事。話す相手（現場の社員）が節目を聞く |
| 当日の案内と一言 | 配属先の責任者と、そこで働く社員 |
| 同期と会う場の進行 | 人事。発表させない |
| 後の一通 | 現場の社員 |
| 欠席者への別の形 | 人事 |

運用代行や代理店が支えられるのは、企画の型、当日の進行の型、後の一通の下書きまでで、見せる場所、現場から出る人、当日の一言は社内が担います。

### エージェントベストの見解

内定者イベントを三つの中身に絞って、当社が先にお伝えしているのは、「配属先の見学は、配属が決まっていないと置けない」ということです。総合職で採り、配属が入社直前に決まる会社では、中だるみの時期に「配属先の見学」ができず、代わりに本社の説明会か懇親会になります。申し込んだあとに内定後の運用が止まる会社に共通するのは、この状態で「見学」と表に書き、直前に「本社で懇親会」に変わって、内定者に「配属はまだ決まらないのか」と読まれることです。当社が案内するのは、配属が決まっていないなら、見学の代わりに「配属先の候補を複数見る日」を置き、「配属はいつ、どう決まるか」をその日に現場の責任者が話すことです。配属の決まり方を隠して懇親会にするより、決まり方を見せる日のほうが、内定者は「何をするか」を持ち続けられます。配属の時期と決め方を、企画の前に確かめることが、内定者イベントの前提です。

## まとめ

- イベントは「会う場」で、目的は「入社したら誰と何をするか」を内定者が自分の目で見ること。懇親会・研修・レクリエーションは要らない
- 中身は「配属先の見学・現場の社員の仕事を見る・同期になる内定者と会う」の三つ。一年に二つか三つで足りる
- 承諾前と承諾直後と入社直前には置かない。中だるみの時期に見学を一つ
- 企画の順番は「何を見せるか → 誰が現場から出るか → その人の時間 → 日程 → 会場」。会場と日程から決めると懇親会になる
- 当日は短く、発表させず、後の一通は現場の社員から。配属が決まっていないなら、決まり方を見せる日を置く

## よくある質問

### 内定者どうしの仲を深めるための懇親会は、やらなくてよいのですか

同期の仲は、入社してから自然にできます。入社前に確かめたいのは、同期の顔より「自分が働く場所と人と仕事」です。同期と会う場は、見学の同じ日に少人数で短く置けば足り、それだけの懇親会は要りません。懇親会をやるなら、見学の後に短く添える形にします。

### 配属が入社直前まで決まらず、配属先の見学ができません

配属先の候補を複数見る日を置き、その日に「配属はいつ、どう決まるか」を現場の責任者が話します。決まり方を隠して懇親会にするより、決まり方を見せる日のほうが、内定者は「何をするか」を持ち続けられます。配属の時期と決め方を、企画の前に社内で確かめます。

### 内定者イベントの企画は、御社に相談できますか

できます。当社は、企画の型、当日の進行の型、後の一通の下書きを支えられます。見せる場所、現場から出る人、当日の一言は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、内定後の運用まで含めて支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
