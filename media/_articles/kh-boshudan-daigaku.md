大学との関係から、母集団を作りたい。ところが、「上位の大学と関係を作れ」と言われて大学名で選び、求人票を出しただけで待ち、一年で数が出ずに止め、担当が変わって関係が切れる。**結論から言うと、大学との関係は、「大学名で選ぶ」ことではなく、「こんな人」がいる場（研究室・ゼミ・キャリアセンター・学内の場）と、時間をかけて続ける関係です。一年で数を求めず、社員の出身と仕事のつながりから始め、大学側に「返せるもの」を用意します。学内の場の扱いは、大学ごとのルールで確認します。** この記事では、大学との関係で起きる失敗、母集団のでき方、どの場と関係を作るか、始め方、返せるもの、続ける形、他の入口との分担、数え方、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、大学名で選ぶことの問題は[OfferBoxで大学名で選ばれ慣れている学生に届く文面](/media/ob-joui-daigaku/)と[OfferBoxで大学群を広げるべきか](/media/ob-daigakugun/)で書きました。

## この作業の目的｜「こんな人」がいる場と、続く関係を作る

大学との関係は、スカウトや掲載と違い、一年で母集団にはなりません。研究室やゼミやキャリアセンターとの関係は、二年、三年と続けて、「あの会社なら」と学生に伝わるようになります。その代わり、続いた関係は、他の入口より安定した母集団になります。

目的は、大学との関係を「大学名の一覧」ではなく、「こんな人がいる場との、続く関係」として作ることです。

## 大学との関係で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 大学名で選ぶ | 「大学名で選ばれ慣れている学生」に、他社と同じ会社に見える。「こんな人」がいる場を見ていない |
| 一年で数を求める | 関係ができる前に「効かない」と止め、翌年に残らない |
| 求人票を出すだけ | 大学側は求人票を多数受け取っており、出しただけでは学生に届かない |
| 大学側に返すものがない | 「採りたい」だけの会社は、大学側が動く理由がない |
| 担当が変わって、関係が切れる | 関係が担当個人に紐づき、引き継がれない |
| 学内のルールを確認しない | 学内の場の使い方や連絡の仕方が大学ごとに違い、ルールに反して関係を失う |

共通するのは、大学との関係を「一年の入口」として扱っていることです。大学との関係は「続ける関係」です。

## 大学との関係の母集団の、でき方

1. **「こんな人」がいる場を、見つける**：研究室、ゼミ、学部、キャリアセンター、学内の場。大学名ではなく「場」
2. **その場と、つながりを作る**：社員の出身、仕事のつながり、教員との接点
3. **大学側に、返せるものを用意する**：仕事の話、研究とのつながり、学生が知りたいこと
4. **学内の場で、学生と会う**：学内の説明会、研究室訪問、ゼミでの話。大学ごとのルールで確認
5. **会った学生を、他の入口の場に誘う**：面談、回、インターン
6. **年度ごとに関係を続け、台帳に入口「大学」で持つ**

「1」で大学名を選ぶと、「2」以降が動きません。「3」がないと、「4」の場がもらえません。

### エージェントベストの見解

相談で最も多い思い込みは、「上位の大学と関係を作れば、質の高い母集団ができる」というものです。当社は3媒体の販売パートナーで、大学との関係づくりは当社の商材ではありませんが、スカウトの「こんな人」の相談の中で、大学との関係の話になることがあります。大学名で関係を作ろうとした会社は、その大学の学生が「大学名で選ばれ慣れている」ことに気づかず、他社と同じ会社に見え、関係も母集団もできていません。逆に、「こんな人」がいる研究室やゼミを、社員の出身や仕事のつながりから見つけて、時間をかけて続けた会社は、大学名に関係なく、その場から毎年近い人が来ています。大学との関係の価値は、大学名ではなく、「こんな人がいる場と、続いていること」です。当社がこの相談を受けるとき、最初にやるのは、大学名の一覧を閉じて、「こんな人」がいる場を社員の出身から探すことです。

## どの場と、関係を作るか

| 場 | 「こんな人」との関係 | 始めやすさ |
|---|---|---|
| 研究室・ゼミ | 研究や専攻が、自社の仕事とつながる場合。特に理系職種 | 社員の出身研究室から。教員との接点 |
| キャリアセンター | 学生の進路相談の窓口。「こんな人」を相談で見ている | 大学ごとの窓口とルールで。求人票以外の関係 |
| 学部・学科 | 専攻が仕事とつながる場合 | 学内の場の案内は大学ごとのルールで |
| 学内の説明会・企業研究の場 | 学生が企業を知る場 | 大学の案内に沿って。ルールで確認 |
| 社員のつながり（同窓、部活、サークル） | 「こんな人」がいる場を、社員が知っている | 社員に「こんな人」を渡す。[リファラルからの母集団形成](/media/kh-boshudan-referral/) |

大学名の一覧から選ばず、「こんな人」がいる場から選びます。大学名で送らない考え方は[OfferBoxで大学名で選ばれ慣れている学生に届く文面](/media/ob-joui-daigaku/)の「大学名を条件から外し、行動で選ぶ」で書きました。

## 始め方｜社員の出身と、仕事のつながりから

- **社員の出身（研究室・ゼミ・学部）を、聞く**：活躍している社員の出身から。「こんな人」がいる場の候補
- **仕事と研究のつながりを、探す**：自社の仕事が、どの研究や専攻とつながるか
- **最初は、一つか二つの場**：多くの大学に一斉に連絡しない
- **社員が、出身の場に戻る形で始める**：「出身者が、仕事の話をしに来る」は、大学側が受けやすい
- **大学ごとのルールを、先に確認する**：学内の場の使い方、連絡の窓口、学生への連絡の仕方

## 大学側に、返せるもの

- **仕事の話**：学生が知りたい「この専攻で、どんな仕事があるか」。会社の宣伝ではなく
- **研究とのつながり**：共同研究、見学、データ。自社の制度と管理部門で確認
- **学生が確かめられる場**：インターン、回、研究室訪問の受け入れ。[インターンからの母集団形成](/media/kh-boshudan-intern/)
- **出身社員の、その後**：「この研究室の出身者が、どう働いているか」は、大学側も学生も知りたい
- **返せるものがないなら、まだ関係を作る時期ではない**：先に、返せるものを用意する

## 続ける形

- **年度ごとに、同じ場に、同じ時期に**：一年空けると、関係が切れる
- **担当を二人に**：一人が変わっても続く。関係を台帳に残す（窓口、教員、やり取り、学内のルール）
- **来た学生の、その後を大学側に返す**：差し支えない範囲で。返すと、次の年も続く
- **数が出ない年も、続ける**：関係は、数の年もない年もある。止めると翌年に残らない
- **担当交代の引き継ぎは[OfferBoxの担当が交代するときの引き継ぎ](/media/ob-tantousha-koutai/)の考え方で**

## 他の入口との、分担

- **大学との関係は「続く関係からの、安定した入口」**：数は少なく、時間がかかる。[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)
- **今年の数は、スカウトと掲載で**：大学との関係は、今年の数を埋めない
- **大学との関係で会った学生を、スカウトや掲載で会う学生と同じ場に**：面談、回、インターン
- **理系職種は、研究室との関係が特に効く**：[OfferBoxで理系学生に届く文面](/media/ob-rikei-gakusei/)、[ワンキャリアで理系学生にスカウトを送る方法](/media/oc-scout-rikei/)
- **スカウトの「こんな人」に、大学名を入れない**：[OfferBoxで大学群を広げるべきか](/media/ob-daigakugun/)

## 数え方

| 数えるもの | 何が分かるか |
|---|---|
| 関係が続いている場の数と、年数 | 関係が作れているか。数より年数 |
| 場から会った学生のうち、「こんな人」に近い人の割合 | 場の選び方が合っているか |
| 場から会った学生の、面談以降の進み方と承諾率 | 安定した入口になっているか |
| 大学側に返せたものの数 | 関係が一方通行になっていないか |

一年の数を目標にしません。台帳で入口「大学」を分け、[採用ファネルの作り方](/media/kh-boshudan-funnel/)の入口ごとの表で、二年、三年で見ます。

| 作業 | 誰が |

| 「こんな人」がいる場を、社員の出身と仕事のつながりから選ぶ | 人事と現場 |
| 大学ごとのルールを確認する | 人事 |
| 返せるものを用意する | 現場と人事責任者。制度は管理部門 |
| 出身社員が場に戻り、仕事の話をする | 出身の社員 |
| 窓口とのやり取りと、台帳 | 人事（二人） |
| 会った学生を、面談・回・インターンに誘う | 人事 |
| 来た学生のその後を、大学側に返す | 人事 |
| 年度ごとに続ける判断 | 人事責任者 |

運用代行や代理店が支えられるのは、「こんな人」がいる場の探し方の整理、他の入口との分担、台帳の型、会った学生を他の入口の場につなぐ型までで、大学との関係そのもの（窓口、返せるもの、場に出ること、続けること）は企業が行います。大学との関係づくりは当社の商材ではありません。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは向き不向きの話です。大学との関係は、「こんな人」が特定の研究室や専攻に集まっていて、返せるものがあり、二年、三年と続ける時間がある会社に向きます。逆に、「こんな人」が専攻に紐づかない職種や、今年の数が要る会社、担当が一人で続ける時間がない会社には、大学との関係は向きません。当社は3媒体の販売パートナーで、大学との関係は扱いませんが、相談の中で「大学との関係で母集団を作りたい」と言われたとき、上の三つ（場があるか、返せるものがあるか、続ける時間があるか）を一緒に確かめます。三つがなければ、今年はスカウトと掲載で「こんな人」に届き、大学との関係は返せるものができてから、と勧めます。

## まとめ

- 大学との関係は「大学名で選ぶ」ことではなく、「こんな人」がいる場（研究室・ゼミ・キャリアセンター・学内の場）と、時間をかけて続ける関係。一年で数を求めない
- 大学名で選ぶと、「大学名で選ばれ慣れている学生」に他社と同じ会社に見える。場は、社員の出身と仕事のつながりから、一つか二つで始める
- 大学側に返せるもの（仕事の話・研究とのつながり・確かめられる場・出身社員のその後）を先に用意する。返せるものがないなら、まだ時期ではない
- 年度ごとに同じ場に同じ時期に、担当を二人に、台帳に残し、来た学生のその後を返し、数が出ない年も続ける。学内のルールは大学ごとに確認
- 今年の数はスカウトと掲載で、大学との関係は安定した入口として二年、三年で見る。会った学生は他の入口と同じ場（面談・回・インターン）へ

## よくある質問

### 上司から「上位の大学と関係を作れ」と言われています

「上位」を「こんな人がいる場」に言い換えて提案します。活躍している社員の出身研究室やゼミを並べ、「この場に『こんな人』がいる。ここから始める」と示すと、大学名の一覧より根拠があります。大学名で関係を作っても、その学生は大学名で選ばれ慣れていて、他社と同じに見えます。上司への答え方は[OfferBoxで大学名で選ばれ慣れている学生に届く文面](/media/ob-joui-daigaku/)の「上司の『上位大学から採れ』への、答え方」で書きました。

### 出身社員がいない大学とは、関係を作れませんか

作れますが、時間がかかります。始めやすいのは、仕事と研究のつながりがある研究室や専攻で、教員との接点（学会、共同研究、見学の受け入れ）から。返せるものがあれば、出身者がいなくても関係は作れます。ただし、出身者がいる場より優先順位は後で、まず出身者がいる場から始めます。

### 大学との関係からの母集団形成は、御社に相談できますか

できます。当社は、「こんな人」がいる場の探し方の整理、他の入口との分担、台帳の型、会った学生を他の入口の場につなぐ型を支えられます。大学との関係そのもの（窓口、返せるもの、場に出ること、続けること）は、企業が行ってください。大学との関係づくりは当社の商材ではありません。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
