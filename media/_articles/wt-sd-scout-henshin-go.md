スカウトに返信が来たあと、何を、いつ、どのくらいの長さで送るか。ここが決まっていないと、返す人によって対応がばらつき、面談の前に相手が離れます。**結論から言うと、返信のあとに送る連絡は「最初の返事」「日程が決まったあとの連絡」「前日の一言」の三つに絞り、どれも短く送ります。** そのうえで、面談に出る人へ相手の情報を一枚で渡します。返信から面談までの全体の考え方は[スカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)で書きました。この記事では、三つの連絡の中身と、返信の種類ごとの返し方、社内の引き継ぎを、実際に使う形まで落として整理します。

## 返信のあとに送るのは三つだけ

返信のあと、面談までに送る連絡を増やすと、相手の負担が増えます。送るのは次の三つです。

| 連絡 | いつ | 中身 |
|---|---|---|
| 最初の返事 | 返信を受けた翌日まで | お礼、日程の候補、誰と話すか |
| 日程が決まったあとの連絡 | 日程が決まったその日 | 日時、形、話す人、読んでおくもの一つ |
| 前日の一言 | 面談の前日 | 時間と、話す人の名前 |

三つとも短くします。長い説明を送ると、「話を聞きに行く」つもりの相手に、読む作業を課すことになります。会社や募集の説明は、会社ページと募集記事に任せます。

## 最初の返事の書き方

最初の返事は、返信の中身によって少し変えます。ただし、どれも短く、日程の候補を添えるのが基本です。

**前向きな返信（「話を聞いてみたい」）には**

> 返信ありがとうございます。話を聞いてもらえるとのこと、うれしいです。〇〇（職種）の△△が、オンラインで仕事の中身をお話しします。選考ではありません。次の日程でご都合のよいものはありますか。（候補を複数）

**質問だけの返信には**

> ご質問ありがとうございます。〇〇については、△△です。詳しくは、実際にその仕事をしている者から話せます。よろしければ、次の日程で短くお話ししませんか。（候補を複数）

**「いまは考えていない」という返信には**

> 返信ありがとうございます。お気持ち、承知しました。またご縁があれば、そのときはよろしくお願いします。

最後の型は、追いかけないことが大切です。次の連絡は、時間を空けて、別の募集のときに考えます。日程の候補は、こちらから出します。「ご都合のよい日を教えてください」と聞くと、往復が増えます。Wantedlyには日程調整の機能もあるので、管理画面で使い方を確かめておきます。

### エージェントベストの見解

申し込んだあと、スカウトで最初の数か月に起きやすいのは、「返信が来るたびに、返す人が文面を一から考えている」ことです。当社は採用媒体の代理店としてWantedlyのスカウトの運用を見ていますが、返事の型がない会社では、返す人が丁寧に書こうとして時間がかかり、翌日までに返せない日が出てきます。丁寧さを出そうとして、会社の説明を足してしまうこともあります。返事の型を三つ用意し、相手の名前と、相手が触れた一文だけを変えて送る形にすると、返す時間が短くなり、文面も短くなります。丁寧さは文面の長さではなく、相手の返信のどこに反応したかを一言入れることで伝わります。型を作るときは、「相手の一文を引用する場所」を一つ空けておくことを勧めます。

## 日程が決まったあとの連絡

日程が決まったら、その日のうちに次の四つを送ります。

1. **日時**：曜日まで書く
2. **形**：オンラインなら接続先、来社なら場所と受付の仕方
3. **話す人**：名前と、どんな仕事をしている人か
4. **読んでおくもの一つ**：募集記事か、話す人のストーリーのどちらか一つ

「読んでおくもの」は一つだけにします。会社ページ、募集記事、ストーリーを全部送ると、どれも読まれません。面談で「読んでいただいた〇〇の話から」と始められるものを一つ選びます。

ここで、履歴書や職務経歴書を求めないようにします。カジュアル面談の前に書類を求めることは、Wantedlyの公式ヘルプで制限の対象として案内されています。相手のことは、プロフィールと面談で知ります。

## 前日の一言

前日の一言は、二行で足ります。

> 明日〇時から、△△がお待ちしています。当日はよろしくお願いします。

前日の一言があると、相手は予定を思い出し、話す人の名前を確かめられます。来られなくなった相手が、日程の変更を言い出しやすくなる効果もあります。

## 面談に出る人への引き継ぎ

返信を受けた人と、面談に出る人が違う場合は、面談の前に相手の情報を渡します。渡すのは一枚で足ります。

| 渡すこと | 使い方 |
|---|---|
| 相手のプロフィールで目に留まった点 | 面談の最初の話題にする |
| 送ったスカウトの文面 | 文面で触れた話から始める |
| 返信の中で相手が触れたこと | 相手が何に関心を持ったかが分かる |
| 相手からの質問 | 面談で答える |
| 送った「読んでおくもの」 | 面談で触れる |

引き継ぎがないと、面談に出る人は相手のことを知らずに始め、「どうしてお話を聞きに来られたんですか」から聞くことになります。相手はスカウトを受けて来ているので、この質問は「送っておいて知らないのか」と受け取られることがあります。面談の準備の全体は[カジュアル面談の準備](/media/wt-sd-casual-mendan-junbi/)で整理しています。

### エージェントベストの見解

自社で持つべきなのは、面談で話すことと、相手の質問に事実で答えることまでです。ここから先、つまり返事の型づくり、日程の調整、前日の一言、引き継ぎの一枚の作成は、人事か外に任せられます。当社がWantedlyのスカウトを支えるとき、この部分は型として用意できます。ただ、相手の質問のうち、仕事の中身や働き方に関わるものは、現場の人の言葉で答えたほうが伝わります。外に任せた返事で「詳しくは面談で」と書きすぎると、相手には中身を答えてもらえない会社に見えます。質問に事実で答えられる一文だけは、現場の人に確かめてから返す。この線を最初に決めておくと、任せる範囲がはっきりします。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 返事の型を三つ用意する | 人事 |
| 返信の通知を受け、翌日までに返す | 返信を受ける人（一人に決める） |
| 日程の候補を出し、決まったら連絡する | 返信を受ける人 |
| 前日の一言を送る | 返信を受ける人 |
| 引き継ぎの一枚を作り、面談に出る人に渡す | 返信を受ける人 |
| 面談で話し、質問に答える | その職種の人 |

返信を受ける人が休む日の代わりも、あわせて決めておきます。

## まとめ

- 返信のあとに送るのは、最初の返事、日程が決まったあとの連絡、前日の一言の三つ
- 最初の返事は翌日までに、短く、日程の候補をこちらから出す
- 「いまは考えていない」には、お礼を返して追いかけない
- 面談の前に書類を求めず、読んでおくものは一つに絞る
- 面談に出る人へ、相手の情報を一枚で渡す

## よくある質問

### 返信が週末に来ました。翌日までに返す必要がありますか

週末も対応する必要はありませんが、週明けの最初の時間に返すと決めておきます。返す人が休みの日の代わりを決めておくと、数日空くことを防げます。

### 日程の候補を出しても返事がありません

数日たっても返事がなければ、一度だけ短く確かめます。「先日の日程の件、ご都合が合わなければ別の候補もお出しします」と書きます。それでも返事がなければ、追いかけません。

### 面談の前に、相手の経歴をもう少し知りたいのですが

プロフィールに書かれている範囲で足ります。足りない部分は、面談で聞きます。面談で聞くことの考え方は[カジュアル面談で聞くこと](/media/wt-sd-casual-mendan-shitsumon/)にまとめています。
