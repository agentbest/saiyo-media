理系学生にオファーを送るとき、「研究内容に触れないと読まれない」と思われがちです。**結論から言うと、研究内容そのものに触れられるのは、社内に研究を読める人がいる場合に限られ、それ以外の場合は「研究の進め方」に触れます。研究の進め方は行動の型なので、研究内容が読めなくても、自由記述から拾えます。** 研究内容に無理に触れると、専門用語を誤用したり、研究と無関係の仕事に「研究を活かせる」と書いたりして、逆に信頼を失います。この記事では、理系学生の文面を、入り方の分け方、研究の進め方の拾い方、研究職以外に誘う場合、専門用語、時期への配慮、人事と現場の分担の順で整理します。文面の基本は[オファー文面の基本](/media/ob-offer-bunmen-kihon/)、理系に特化した媒体との比較は[OfferBoxとLabBaseの違い](/media/hikaku-offerbox-labbase/)で書きました。

## この作業の目的｜「読んだ」と伝わる入り方を、社内の体制で選ぶ

理系学生の自由記述には、研究内容が書かれていることが多くあります。学生は、それを企業がどう読んだかを見ています。「研究を読んでくれた」と伝われば開かれ、「読まずに送っている」と分かれば閉じられます。

ただし、「研究を読んだ」と伝えるには、2つの道があります。

1. **研究内容そのものに触れる**：「〇〇の研究で、△△の手法を使われていましたね」。研究を読める人がいれば書ける
2. **研究の進め方に触れる**：「うまくいかない実験を、条件を変えて何度も試されていましたね」。研究を読めなくても、自由記述の行動から拾える

どちらも「読んだ」と伝わります。1は深く、2は広く使えます。社内に研究を読める人がいるかで、どちらを使うかを決めます。

## 手順1｜入り方を、社内の体制で分ける

| 社内の体制 | 入り方 | 書ける人 |
|---|---|---|
| 研究職を採り、研究内容を読める現場がいる | 研究内容そのものに触れる。手法、テーマ、自社の開発とのつながり | 現場の研究者・技術者 |
| 技術職を採るが、研究内容までは読めない | 研究の進め方に触れる。試行錯誤、データの扱い、チームでの分担 | 人事、または現場 |
| 研究職以外（営業、企画など）に理系学生を誘う | 研究の進め方に触れ、その進め方が仕事にどう活きるかを書く | 人事 |
| 研究内容が自社の事業と近いが、読める人がいない | 進め方に触れる。近さは「分野が近い」程度にとどめ、詳細に踏み込まない | 人事 |

「読める人がいないのに研究内容に触れる」は、最も避けたい形です。専門用語を誤用したり、研究の要点を外したりすると、学生には一目で分かります。読めないなら、進め方に触れます。

## 手順2｜研究の進め方を、自由記述から拾う

研究の進め方は、自由記述に書かれた行動から拾います。読み方の基本は[学生プロフィールの読み方](/media/ob-profile-yomikata/)で書いたとおりで、理系学生の場合は次の点を見ます。

- **うまくいかなかったときに何をしたか**：条件を変えた、先行研究を調べ直した、指導教員や先輩に相談した。試行錯誤の型
- **データや結果をどう扱ったか**：整理の仕方、考察の進め方、次の実験への反映
- **研究室での役割**：後輩の指導、共同研究での分担、装置の管理。チームでの動き
- **研究テーマをどう選んだか**：与えられたのか、自分で決めたのか。決めたなら理由
- **研究以外に書かれていること**：アルバイト、サークル、趣味。研究だけの学生と決めつけない

この5つのうち、1つでも具体的に書かれていれば、文面で触れられます。「〇〇の実験で条件を変えて何度も試されていた、と書かれていて、うちの△△の仕事も同じ進め方をします」のように、進め方と仕事をつなぎます。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行で理系学生への文面を書くとき、「研究の進め方」に触れる文面は、企業のペルソナに沿って当社が書けます。試行錯誤、データの扱い、チームでの役割は、研究分野を問わず読み取れるからです。一方で、「研究内容そのもの」に触れる文面は、当社は書きません。当社に企業の研究を評価する力は無く、書けば誤用が出ます。研究内容に触れたい会社には、当社が進め方の部分を下書きし、研究内容の一文を現場の研究者に足してもらう分担を提案しています。現場の負担は一文で済み、文面は「研究を読んだ人が書いた」形になります。逆に、研究内容の部分まで当社や人事が書くと、学生は「読んでいない」と見抜きます。研究内容は読める人が、進め方は誰でも。この線で分けると、理系学生への文面が社内の体制で回ります。

## 手順3｜研究職以外に誘う場合の書き方

理系学生を、営業や企画、生産管理などに誘う場合があります。このとき「研究を活かせる仕事です」と書くのは、避けます。研究内容が直接活きない仕事にそう書くと、学生は「本当か」と疑い、面談で「どう活きるのか」と聞かれて答えられません。

書き方は、次の形です。

1. **研究の進め方に触れる**：「条件を変えて試す進め方」「データを整理して考察する進め方」
2. **その進め方が、この仕事のどこで要るかを書く**：「営業でも、顧客の課題を仮説を立てて検証する進め方は同じです」
3. **研究内容そのものは活かせないことを、隠さない**：「研究テーマそのものを扱う仕事ではありません」と一言
4. **理系である理由より、その学生の行動の理由で誘う**：「理系だから」ではなく「あなたの進め方だから」

「理系だから技術職」と決めつけないのと同じで、「理系だから研究を活かす」とも決めつけません。学生の自由記述に、研究以外の志向（人と話す、事業を作る）が書かれていれば、そこに触れます。

## 手順4｜専門用語の扱い

研究内容に触れる場合、専門用語の扱いに注意します。

| 場面 | 扱い |
|---|---|
| 学生が使った用語を、文面で使う | 自由記述に書かれた用語をそのまま使う。言い換えない。言い換えると誤用が出る |
| 自社の技術の用語を使う | 学生が知っている保証は無い。一言で説明を添える |
| 分野が近いが、用語が違う | 近さを「分野が近い」程度にとどめる。無理に用語を合わせない |
| 読める人が書く | 用語の精度は現場に任せる。人事は校正だけ |

学生の用語を「そのまま使う」が、誤用を防ぐ最も簡単な方法です。要約したり言い換えたりした瞬間に、精度が落ちます。

## 手順5｜研究室の時期への配慮

理系学生は、研究室の予定で動きにくい時期があります。学会、実験の山、論文の締切、修士なら研究の中間発表。時期は分野や研究室で違うので、具体的には書きませんが、配慮の仕方は共通です。

- **面談の日程の候補を、幅を持って出す**：平日の日中だけでなく、夕方や、週をまたいだ候補
- **オンラインを基本にする**：研究室から移動しなくて済む。進め方は[オンライン面談](/media/ob-mendan-online/)
- **返事が遅くても、追いかけを急がない**：研究の山にいる可能性がある。追いかけは1回、間隔は少し長めに
- **選考の段階の間隔を、学生の予定に合わせる**：「研究の予定に合わせます」と一言添える
- **文面で、時期への配慮を一言**：「研究のお忙しい時期かと思いますので、ご都合に合わせます」

配慮を文面と連絡に入れると、「研究室の事情を分かっている会社」と伝わり、それ自体が「読んだ」の証拠になります。送る時期の考え方は[送る時期と時間帯の考え方](/media/ob-soushin-timing/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 読める人がいないのに研究内容に触れる | 用語の誤用で信頼を失う | 進め方に触れる |
| 研究と無関係の仕事に「研究を活かせる」と書く | 面談で答えられない | 進め方が活きると書き、内容は活かせないと隠さない |
| 理系＝技術職と決めつける | 研究以外の志向を見逃す | 自由記述の研究以外の部分も読む |
| 学生の用語を言い換える | 精度が落ちる | そのまま使う |
| 自社の技術の用語を説明なしで使う | 学生が分からない | 一言添える |
| 研究の山の時期に追いかけを重ねる | しつこいと受け取られる | 間隔を長めに、1回だけ |
| 「理系のあなたなら」と書く | 属性で見られていると感じる | その学生の進め方で誘う |
| 研究内容の部分を人事が書く | 「読んでいない」と見抜かれる | 現場が一文足す |

最も多いのは、最初の「読める人がいないのに研究内容に触れる」です。触れたい気持ちは分かりますが、読めないなら進め方に触れるほうが、読まれます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 入り方を決める（研究内容か、進め方か） | 人事（社内の体制から） |
| 研究の進め方を自由記述から拾う | 人事、または運用代行 |
| 研究内容の一文を足す | 現場の研究者・技術者（読める場合） |
| 研究職以外に誘う文面 | 人事 |
| 専門用語の校正 | 現場 |
| 面談の日程の幅と、時期の配慮 | 人事 |
| 面談に出る | 名義の人（研究職なら現場の研究者） |

現場の研究者の負担は、「研究内容の一文を足す」「用語を校正する」「面談に出る」の3つに絞ります。読む作業と進め方の部分は人事か代行が担います。分担の考え方は[OfferBoxとLabBaseの違い](/media/hikaku-offerbox-labbase/)でも書きました。運用代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「理系学生には研究内容に触れないと読まれない」というものです。実際には、研究内容に触れた文面と、研究の進め方に触れた文面で、承認のされ方に大きな差は出ません。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、研究内容に無理に触れて用語を誤用した文面は、進め方に触れた文面より明らかに承認が落ちます。学生が見ているのは「研究を理解したか」ではなく「自分を読んだか」で、進め方に触れれば「読んだ」は伝わります。研究内容に触れられる体制がある会社は触れればよく、無い会社は進め方で足ります。無い会社が無理に触れるのが、最も避けたい形です。自社の体制に合う入り方を選ぶ。それが、理系学生への文面で最初に決めることです。

## まとめ

- 研究内容そのものに触れるのは、読める人がいる場合だけ。それ以外は研究の進め方に触れる
- 研究の進め方は、試行錯誤、データの扱い、研究室での役割、テーマの選び方から拾う。行動の型なので分野を問わず読める
- 研究職以外に誘うときは、進め方が活きると書き、研究内容は活かせないと隠さない
- 学生の用語はそのまま使う。自社の用語には一言添える
- 研究室の時期に配慮し、日程に幅を持たせ、追いかけを急がない。配慮そのものが「読んだ」の証拠になる

## よくある質問

### 研究内容が自社の事業に近い学生には、研究内容に触れるべきですか

読める人がいるなら触れます。いないなら、「分野が近い」程度にとどめ、進め方に触れます。近いからといって詳細に踏み込むと、誤用が出ます。読める人が一文足す分担が現実的です。

### 理系学生を営業職に誘うのは、無理がありますか

無理ではありませんが、「研究を活かせる」とは書きません。研究の進め方（仮説を立てて検証する、データを整理する）が営業のどこで要るかを書き、研究内容そのものは扱わないと隠さずに伝えます。自由記述に人と話す志向が書かれていれば、そこにも触れます。

### 理系学生への文面は、運用代行に頼めますか

研究の進め方に触れる文面は、当社が書けます。研究内容そのものに触れる一文は、企業の現場の研究者に足していただきます。当社がOfferBoxの運用代行を受けるときは、この分担で進めます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
