内定を出す。「内定をお出しします。条件は以下のとおりです。〇日までにご返答ください」。条件の通知と期限だけの一通。相手には、「選考までは人だったのに、内定で急に事務になった」と読まれます。**結論から言うと、内定連絡は、条件の通知だけで終えません。内定の事実と決めた理由の一文、選考で会った人の一言、面談や募集要項と一致した条件、承諾までに読むものと話す相手、質問の窓口、承諾期限とその決め方、の六つを一通に入れます。押さず、条件を初めて出さず、期限は相手の状況を聞いて決めます。三つの媒体で、この考え方は同じです。** この記事では、内定連絡で起きる失敗、一通に入れる六つ、押さない書き方、期限の決め方、内定後の接点、辞退されたときの返し、分担を整理します。内定後のフォロー全体は[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)、内定辞退が続くときは[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)で書きました。この記事は、内定を出すその一通の文面です。

## この作業の目的｜内定連絡を、「選考の続き」として渡す

相手は、スカウトの文面で「自分宛」を読み、面談で人に会い、選考で話して、ここまで来ています。内定連絡が「条件の通知」だけになると、それまでの流れが切れ、「採用側の顔」に変わったように見えます。

目的は、内定連絡を、スカウトから選考まで続いてきた「人の言葉」の続きとして渡し、相手が「決められる」状態を作ることです。

## 内定連絡で、起きる失敗

| 失敗 | 相手が受け取ること |
|---|---|
| 条件の通知だけ | 「急に事務になった」。それまでの人の言葉が消えた |
| 条件が、面談や募集要項と違う | 「聞いていたのと違う」。最も重い |
| 条件を、内定で初めて出す | 面談で聞けなかったことを、決める段階で知らされた |
| 承諾期限を一方的に切る | 「急がされている」 |
| 「ぜひ」「早めに」「他にも」で押す | 押されている。共感で来た相手ほど離れる |
| 選考で会った人の言葉がない | 「面接で話した人は、もう関係ないのか」 |
| 承諾までに何をすればよいか分からない | 質問先も、話す相手もなく、一人で決めさせられる |

共通するのは、内定連絡を「決定の通知」として書いていることです。相手にとって、内定連絡は「決める材料をもらう一通」です。

## 内定連絡の一通に入れる、六つ

| 入れるもの | 書き方の例 |
|---|---|
| 1. 内定の事実と、決めた理由の一文 | 「内定をお出しします。面接で〇〇の話をされたとき、△△が『一緒に働きたい』と言っていました」 |
| 2. 選考で会った人の一言 | 「面談でお話しした□□からも、一言預かっています。『✕✕の話、また聞かせてください』」 |
| 3. 条件 | 面談や募集要項で伝えたことと、同じことを。金額や制度は自社の制度と管理部門で確認して、そのとおりに。変わった点があれば「〇〇は、面談時から△△に変わりました」と明示 |
| 4. 承諾までに読むものと、話す相手 | 「決めるまでに、□□（企業ページ・内定者の話）を読んでいただけます。〇〇（面談で話した人）や、入社してまもない△△と話す場を用意します」 |
| 5. 質問の窓口 | 「ご質問は、この連絡に返信ください。当日にお答えします」 |
| 6. 承諾期限と、その決め方 | 「承諾のご返答は、〇月〇日までにお願いできればと思いますが、他社の選考が続いているなど、ご事情があれば教えてください。期限を相談します」 |

六つで一通。「1」と「2」が、内定連絡を「人の言葉」にします。「3」は、初めて出さず、一致させます。「4」から「6」が、相手が「決められる」材料です。内定通知に書くことは[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)の手順2で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「内定連絡は正式な通知なので、事務的に条件と期限を書くのが正しい」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体で採った学生や候補者の内定後を見ていますが、条件と期限だけの内定連絡を受け取った相手は、「選考までは自分を見てくれていたのに、内定で急に事務になった」と感じ、その落差が辞退の理由の一つになっています。正式であることと、事務的であることは、別です。内定の事実と条件を正確に書きながら、面接で話したことに触れ、面談で会った人の一言を添え、話す相手と窓口を示す一通は、正式で、事務的ではありません。当社が内定連絡の相談を受けるとき、最初にやるのは、条件の通知の前に「決めた理由の一文」と「会った人の一言」を足すことです。

## 押さない、書き方

- **「ぜひご承諾ください」「早めのご返答を」「他にも候補の方が」を書かない**：押すと、共感で来た相手ほど離れる
- **「〇〇さんの決断を尊重します」「他社と比べていただいて構いません」を書く**：相手の判断を残す
- **期限を切るときも、「ご事情があれば相談します」を添える**
- **内定後に「決めましたか」を繰り返さない**：内定後の接点は、押すためではなく、材料を渡すため
- **押した一通は、辞退の理由になり、ワンキャリアなら体験談に書かれる**

押さない考え方は[Wantedly経由の内定辞退が続くとき](/media/wt-naitei-jitai/)の「内定後に、『読んだ会社の人』と話す場を置く」で書きました。

## 承諾期限を、相手の状況を聞いて決める

- **内定を出す前に、承諾の条件を聞く**：「他社の選考は続いていますか」「決めるまでに、何が分かれば決められますか」。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)の手順1
- **期限は、相手の状況に合わせて**：他社の選考が続いているなら、その旨を聞いてよい
- **期限の目安を出しつつ、「相談します」を添える**：一方的に切らない
- **期限の前に、一度、材料を渡す接点を置く**：期限の直前に「決めましたか」ではなく、期限の前半に「〇〇と話す場を」
- **期限を延ばす場合は、延ばした期限をもう一度明示する**

期限の置き方は[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)の手順3で書きました。時期に関わることは、年度の公表内容と自社の方針で確認してください。

## 内定後の接点の、型

- **内定連絡の翌日以降、「話す相手」との場の日程を出す**：内定連絡で予告したことを、実際に行う
- **話す相手は、面談で会った人・入社してまもない社員・内定者**：人事だけにしない
- **読むものは、一つか二つ**：企業ページの働く人、内定者の話。多く渡さない
- **質問には当日に答える**：条件、配属、最初の一年
- **期限の前半に一度、後半に一度**：多くしない
- **接点の中身は[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)の手順5**

## 辞退されたときの、返し

- **当日、短く、お礼と「またご縁があれば」**：理由を問い詰めず、引き留めない
- **内定後の辞退は、最も丁寧に**：「〇〇さんの決断を尊重します。新しい場所でのご活躍を」
- **理由を聞くなら、一度だけ、「今後の参考に、差し支えなければ」**
- **返しの型は[辞退されたあとの文面](/media/kh-bunmen-jitai/)の「内定後に辞退」の行**
- **辞退の理由を、企業ページの時点まで戻って見る**：[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)

## 媒体ごとに、変わる点

| 媒体 | 内定連絡で気をつけること |
|---|---|
| OfferBox | 面談で話した人の一言を必ずしも人事が代筆せず、本人から一言もらう。内定者の活用は[OfferBoxの内定者の活用](/media/ob-naiteisha-katsuyou/) |
| Wantedly | 共感で来た相手ほど、押すと離れる。「お互いを知る」関係のまま。[Wantedly経由の内定辞退が続くとき](/media/wt-naitei-jitai/) |
| ワンキャリア | 内定連絡と内定後の対応が体験談に書かれる。条件は企業ページと一致させる。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/) |

三つとも、「六つを一通に、押さず、条件を初めて出さない」は同じです。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 内定連絡を六つの型で書く | 人事 |
| 決めた理由の一文と、会った人の一言をもらう | 面接官と面談に出た人 |
| 条件を、面談や募集要項と一致させて書く | 人事と管理部門 |
| 承諾の条件を内定前に聞き、期限を決める | 人事 |
| 話す相手の場を用意し、質問に当日答える | 人事と話す相手 |
| 辞退されたら当日返す | 人事 |

運用代行や代理店が支えられるのは、六つの型、期限の決め方の整理、内定後の接点の型、辞退への返しの型までで、決めた理由の一文、会った人の一言、条件の決定、話す場に出ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社が内定連絡の相談を受けたとき、文面の型を渡す前に、「内定を出す前に、承諾の条件を聞きましたか」を確かめます。聞いていなければ、期限も、話す相手も、読むものも、相手に合わせて決められず、六つの型に埋める中身がありません。逆に、内定を出す前に「他社の選考は」「決めるまでに何が分かれば」を聞いていれば、内定連絡の六つは、その答えに合わせて埋まります。当社が勧める順番は、内定を出す前に承諾の条件を聞く、六つを一通に、翌日以降に話す場を出す、期限の前半に一度、です。内定連絡は、出す前の一つの質問で決まります。

## まとめ

- 内定連絡を「条件の通知」で終えると、「急に事務になった」と読まれ、それまでの人の言葉が切れる。内定連絡は「決める材料をもらう一通」
- 一通に、内定の事実と決めた理由の一文・選考で会った人の一言・面談や募集要項と一致した条件・承諾までに読むものと話す相手・質問の窓口・承諾期限とその決め方、の六つ
- 「ぜひ」「早めに」「他にも」で押さない。「決断を尊重します」「比べていただいて構いません」を書く。押した一通は辞退の理由になり、体験談に書かれる
- 期限は、内定を出す前に承諾の条件を聞いて決め、「相談します」を添える。内定後の接点は期限の前半に一度、後半に一度、材料を渡すため
- 辞退されたら当日、短く、お礼と「決断を尊重します」。理由は一度だけ。辞退の理由を企業ページの時点まで戻って見る

## よくある質問

### 内定連絡は書面で出すので、文面に「会った人の一言」を入れる余地がありません

書面の内定通知とは別に、人事からの一通を添えます。書面は正式な通知で、一通は「人の言葉」です。一通に、決めた理由の一文と会った人の一言と、話す相手と窓口と期限の決め方を書き、書面は条件の正確な通知として添えます。書面だけを送ると、「急に事務になった」が残ります。

### 条件が、面談で伝えたときから変わってしまいました

内定連絡で、変わった点を明示します。「〇〇は、面談時にお伝えした△△から□□に変わりました。理由は✕✕です」。黙って変えると、「聞いていたのと違う」が最も重い辞退の理由になります。変わった点を明示し、質問に当日答え、相手が判断できる形にします。条件の決定と記載は、自社の制度と管理部門で確認してください。

### 内定連絡の文面は、御社に相談できますか

できます。当社は、六つの型、期限の決め方の整理、内定後の接点の型、辞退への返しの型を支えられます。決めた理由の一文、会った人の一言、条件の決定、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
