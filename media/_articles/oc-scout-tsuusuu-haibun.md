ワンキャリアでスカウトを受け取った学生の多くは、すぐには返さず、企業ページを開き、クチコミや選考体験談を読んでから受諾するかを決めます。つまり通数を増やすと、文面だけでなく、企業ページや体験談、そのあとの面談やイベントにも同じだけ人が流れ込みます。**結論から言うと、ワンキャリアのスカウト通数は契約の上限から割り振るのではなく、「送る人が週に読める数」「受諾に翌日までに返せる数」「面談とイベントの空き枠」の小さいほうに合わせ、企業ページと体験談が整っている募集に寄せて配ります。体験談に「掲載と違った」と書かれている募集は、直すまで配分を止めます。上限が余っても、埋めるために送ることはしません。** この記事では、配分の前提になる学生の動き、上限から割り振ると崩れる理由、通数を決める3つの数、枠からの逆算、募集とイベントへの寄せ方、時期と送り手の人数での調整、分担を順に扱います。送信の上限や仕組みはプランと時期で違うため、現在の仕様は管理画面とヘルプで確認してください。他媒体での考え方は[OfferBoxの送信ペースの決め方](/media/ob-soushin-pace/)と[Wantedlyのスカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/)にまとめています。

## 配分を決める前に｜学生は受け取ってから体験談を読み、それから返す

ワンキャリアのスカウトは、企業ページ、イベントの掲載、クチコミ、選考体験談と同じ会社の枠の中で動いています。学生から見ると、スカウトは「この会社を調べ始めるきっかけ」です。

1. スカウトの文面を読み、気になれば企業ページを開く
2. クチコミと選考体験談で、選考や面談の様子を確かめる
3. 納得できれば受諾し、面談かイベントに進む
4. 面談やイベントのあと、その体験を体験談に書くことがある

この流れから、通数の配分で考えることが二つ出てきます。一つは、送った先の企業ページと体験談が、学生の確認に耐える状態かどうか。もう一つは、受諾した学生を面談やイベントで受け止められるかどうかです。どちらかが欠けた募集に通数を割いても、受諾は増えないか、増えても対応しきれず、その様子が次の体験談に残ります。

## 上限から割り振ると崩れる理由

| 割り振り方 | ワンキャリアで起きやすいこと |
|---|---|
| 契約の上限を月の目標にする | 読まずに送る文面が増え、体験談に「誰にでも同じ文面」と書かれる |
| 募集の数で上限を等分する | 枠が埋まっている募集にも送り、空いている募集は足りなくなる |
| 受諾に返す人を決めずに送る | 受諾から連絡までが空き、「受諾したのに音沙汰がない」と残る |
| イベントの定員を見ずに誘う | 満席の回を案内してしまい、学生が別の回を探し直す |
| 企業ページの更新前に送る | 文面と企業ページの内容が食い違い、学生が確認の段階で離れる |
| 体験談の指摘を放置した募集に送る | 学生が体験談を読み、受諾の前に引き返す |
| 送り手ごとに数を任せる | 同じ学生に別の募集から届き、会社の中の連携不足に見える |

この中で最も起きやすいのは、上限を目標にしてしまう形です。契約した枠を残すと損をした気がするためですが、ワンキャリアでは送った数がそのまま体験談の材料になります。読まずに送った分は、受諾が来ないだけでなく、翌年の学生が読む記録として残ります。

## 通数を決める3つの数｜読める数・受諾に返せる数・受け皿の枠

| 数 | 中身 | 誰に聞くか |
|---|---|---|
| 読める数 | 送り手がプロフィールを読み、その学生に向けた一文を書ける週の数 | 送り手本人 |
| 受諾に返せる数 | 受諾が来た日の翌日までに、面談やイベントの案内を返せる数 | 受諾に対応する人事 |
| 受け皿の枠 | その募集で、面談に出られる回数と、案内できるイベントの空き | 面談に出る社員、イベントの担当 |

週に送る数は、この三つのうち最も小さい数に合わせます。たとえば読める数に余裕があっても、面談に出る社員の予定が詰まっていれば、受け皿の枠が上限です。契約の上限は、この三つよりも外側にあることが多く、配分の起点にはしません。

三つのうち、受け皿の枠を数えるときは、面談だけでなくイベントも含めます。ワンキャリアでは同じ会社がイベントを掲載していることが多く、スカウトから「次の座談会へどうぞ」と案内する形も取れます。イベントの空きがある時期は受け皿が広がり、満席が続く時期は狭まります。

### エージェントベストの見解

ワンキャリアのスカウト運用で多い誤解は、「送った数が多いほど、学生に知ってもらえる」というものです。当社は求人広告代理店として、ワンキャリアのスカウトと掲載をあわせて見ていますが、通数を増やした月に受諾が増えず、体験談の評価が下がっていく会社があります。原因を追うと、送った学生の多くが企業ページと体験談を読んだうえで受諾を見送っていたり、受諾した学生への連絡が数日空いていたりします。ワンキャリアでは、スカウトは単独で効く施策ではなく、企業ページ、体験談、面談やイベントを通る入口です。入口だけを広げても、中が詰まっていれば、詰まった様子が体験談に残ります。当社が配分の相談を受けたとき、最初に見るのは通数ではなく、受諾から面談までの日数と、直近の体験談に書かれている対応の様子です。そこが整っていれば通数を増やす余地があり、整っていなければ先に中を直します。

## 面談とイベントの枠から逆算する手順

1. **募集ごとに、来月の面談の回数を出す**：面談に出る社員に、出られる日を先に押さえてもらう
2. **案内できるイベントの回と空きを確認する**：掲載中のイベントのうち、スカウトから案内してよい回を決める
3. **二つを合わせて、受け止められる人数を出す**：受諾した学生が全員来るとは限らないので、少し余裕を残す
4. **その人数に届くための通数を見積もる**：自社の台帳で、過去の送った数と受諾の数の関係を見る。台帳が無い場合は、読める数で一か月送って記録を作る
5. **見積もった通数を、読める数と照らす**：超えるなら、通数を下げるか、読む人を増やす
6. **全募集の合計を、受諾に返せる数と照らす**：超える分は、急がない募集から減らす

逆算の起点を面談とイベントの枠に置くと、上限を埋める発想から離れられます。人数計画からの考え方は[OfferBoxの人数計画の立て方](/media/ob-ninzu-keikaku/)でも扱っています。

## 募集とイベントの状態で寄せる

| 募集の状態 | 配分の考え方 |
|---|---|
| 企業ページが新しく、体験談に大きな指摘がなく、面談かイベントの空きがある | 多めに寄せる |
| 枠はあるが、企業ページの内容が古い | 先に企業ページを更新する。更新後に配分する |
| 体験談に「掲載と違った」「連絡が遅かった」と書かれている | 配分を止め、掲載や対応を直してから再開する。[掲載でやりがちな失敗](/media/oc-keisai-ng/) |
| 近くイベントがあり、まだ空きがある | イベントへの案内を軸にした文面で寄せる。[スカウトとイベントのつなげ方](/media/oc-scout-event-renkei/) |
| 急がないが、受け皿は整っている | 途切れない程度に少なめ |
| 送っても受諾が来ない | 数を増やさず、文面・企業ページ・体験談の順に見直す |
| 面談もイベントも空きがない | 送らない |

ワンキャリアに特有なのは、体験談の内容が配分の判断材料になることです。体験談に指摘がある募集へ通数を寄せると、学生がそれを読む機会が増えるだけになります。企業ページとの言葉の揃え方は[スカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)で書きました。

## 時期と送り手の人数で調整する

### 時期で増やす・減らす

- **イベントの開催前**：空きがある回に向けて少し増やす。開催の直前は、学生が予定を組めないので控える
- **自社の選考が立て込む時期**：面談に出る社員の枠が減るので、その募集の通数も減らす
- **試験期間や連休の前**：受諾の返事が遅れるので減らす。返事を急がせない
- **募集が締め切られた**：その募集の配分をなくし、受け皿が整った募集に回す

募集の時期は、年度ごとの公表内容と自社の方針に沿って決めてください。送る曜日と時間の考え方は[スカウトを送る時期・時間の考え方](/media/oc-scout-timing/)にあります。

### 送り手が複数いるとき

- **一人の学生に、会社として一通にする**：募集をまたいで同じ学生に送らないよう、共通の台帳で送り先を見る
- **送り手ごとの数を、人事が合計して見る**：合計が受諾に返せる数を超えていないか
- **読める数は人によって違う**：一律の割り当てにしない
- **文面の型は揃える**：書く人が違っても、構成と言葉づかいは同じにする。[スカウト文面の書き方](/media/oc-scout-bunmen/)

同じ会社の別の募集から重ねて届くと、学生は「社内でつながっていない会社」と受け取りやすく、その印象もクチコミに表れます。

## 余った上限と、月に一度の見直し

上限が余っても、それは自社で受け止められる数が上限より小さいという意味で、失敗ではありません。余った分の扱い（翌月に回せるかどうかなど）は管理画面とヘルプで確認し、回せない場合でも埋めるために送ることはしません。余りが何か月も続くなら、契約の内容を見直す材料にします。

月に一度は、次の点を台帳と体験談で見ます。

- 募集ごとの、送った数・受諾・面談やイベントへの参加
- 受諾から最初の連絡までの日数
- 面談とイベントの枠の埋まり方
- 新しく投稿された体験談に、スカウトや対応への言及があるか

数字は大きさより前月との差を見ます。受諾が減った月は、通数より先に、文面、企業ページ、体験談の新しい投稿を確かめます。

## 社内の分担

| 作業 | 担当 |
|---|---|
| 面談に出られる日を押さえる | 面談に出る社員 |
| スカウトから案内するイベントの回を決める | イベントの担当と人事 |
| 枠から通数を逆算し、募集に配る | 人事 |
| 企業ページと体験談の状態を見て、配分を止めるか決める | 人事と採用の責任者 |
| 自分の読める数を申告する | 送り手 |
| 共通の台帳で送り先と合計を見る | 人事 |
| 月に一度の見直し | 人事 |

代理店や運用代行が手伝えるのは、逆算の表や台帳の型、配分の案、企業ページと体験談の点検までです。面談の日程を押さえること、送ること、受諾への対応、契約の判断は企業が担います。

### エージェントベストの見解

通数の相談でつまずきやすいのは、配分の表を作る前に「受諾した学生をどこに通すか」が決まっていないことです。当社がワンキャリアのスカウトを支えるとき、表の型は当社で用意できますが、面談に出る社員の予定と、スカウトから案内してよいイベントの回は、社内でしか決められません。ここが空欄のまま通数を決めると、起点が契約の上限になり、受諾が来てから慌てて日程を探すことになります。その間の待ち時間は、学生が書く体験談にそのまま表れます。当社がお願いしているのは、配分の前に「この募集の受諾者を、来月どの面談とどのイベントで受け止めるか」を一枚にまとめてもらうことです。受け皿が見えていれば通数は自然に決まり、受け皿が無い募集には送らない判断もしやすくなります。

## まとめ

- ワンキャリアの学生は、スカウトを受け取ってから企業ページと体験談を読み、受諾するかを決める。通数は、その先の受け皿とあわせて考える
- 週の通数は、読める数・受諾に返せる数・面談とイベントの枠のうち、最も小さい数に合わせる。契約の上限は起点にしない
- 面談とイベントの枠→受け止められる人数→通数→読む時間、の順に逆算する
- 企業ページが新しく、体験談に指摘がなく、空き枠がある募集に寄せる。体験談に「掲載と違った」がある募集は直すまで止める
- 余った上限は埋めない。月に一度、受諾から連絡までの日数と体験談の新しい投稿を見て配分を直す

## よくある質問

### 上限を使い切らないと、社内で「もったいない」と言われます

報告の軸を、送った数から「受諾した学生が面談やイベントに来た数」に替えます。ワンキャリアでは、読まずに送った文面が体験談に残り、翌年の学生にも読まれるため、上限を埋めた月のほうが後で響くことがあります。上限は送れる数の天井であり、達成する数ではないと共有しておきます。

### イベントの空きがあるなら、通数を増やしてよいですか

空きのある回に向けて増やす余地はあります。ただし、読める数と受諾に返せる数を超えないことが条件です。案内する回の日時と内容を文面に書き、受諾した学生がその回に申し込めるかを先に確かめておきます。

### ワンキャリアのスカウトの配分を、御社に相談できますか

相談できます。当社は求人広告代理店として、ワンキャリアの掲載・イベント・スカウトをあわせて見ており、逆算の表、配分の案、台帳の型、企業ページと体験談の点検をお手伝いします。面談の日程、送信、受諾への対応、契約の判断は企業側で行っていただく形です。
