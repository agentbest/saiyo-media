ゲーム、音楽、映像、アニメ、イベント・ライブ、配信、玩具・キャラクターの会社が、Wantedlyで採用する。エンタメは、「好き」で来る候補者が多い業界で、会社ページに作品名を並べれば「話を聞きに行きたい」は押される。会社が採りたいのは「作る側に回る人」で、「好き」で来た候補者の多くは、作る現場（締切、修正、裏方の仕事、自分の好みと違うものを作ること）で離れる。会社の側は「応募は来るが、欲しい人が来ない」と思い、候補者の側は「好きだったのに、作る側は違った」と思う。**結論から言うと、エンタメのWantedlyは、作品名を一度だけ置き、作る現場——誰が何を決めて、締切と修正がどう来て、自分の好みと違うものをどう作るか——を素顔として書きます。「こんな人」を「好き」ではなく「作った経験（何を、どのくらい、誰と）」で決めます。Wantedlyが向くのは、制作の現場の職種（企画、開発、制作進行、デザイン、エンジニア）と、副業・フリーランスの入口で、「好き」の応募が多く来る職種は、別の入口で受けます。** この記事では、エンタメの採用構造とWantedlyとの相性、「好き」で絞らない見せ方、作る現場の書き方、ストーリーとカジュアル面談とスカウトの運用設計、社内の分担を整理します。媒体の選び方は[エンタメ業界の採用媒体の選び方](/media/hikaku-enta-erabikata/)、知名度のある作品の扱いは[Wantedlyで知名度をどう扱うか](/media/wt-chimeido/)で書きました。数値と料金は書きません。

## エンタメの採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| ゲーム（開発・運営） | 企画、エンジニア、デザイン、運営。中途と副業が多い | 向く。作る現場を職種ごとに。並ぶゲーム会社の中で「何を決められるか」で |
| 音楽・ライブ・イベント | 制作、営業、現場運営。季節と週末の仕事 | 労働時間と週末の実態を先に。「好き」で来た人が現場で離れないように |
| 映像・アニメ制作 | 制作進行、演出、作画、編集。締切が仕事を決める | 締切と修正の実態を素顔として。制作進行は「好き」ではなく「回した経験」で |
| 配信・キャラクター・玩具 | 企画、ライセンス、営業、マーケ | 「なにを」を作品ではなく事業で。作品名で埋めない |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| 「好き」で来る候補者が多い | 応募は来るが、作る側が来ない | 「こんな人」を「作った経験」で |
| 作品名で会社ページを埋めやすい | 作品の像で読まれ、作る現場で離れる | 作品名は一度。作る現場を先に |
| 締切と修正が仕事を決める | 「好き」で来た人が締切と修正で離れる | 締切と修正の実態を隠さず |
| 副業・フリーランスとの関わりが多い | 正社員の募集に副業の候補者が来て行き違う | 入口を分ける |

## 「好き」で絞らない｜「こんな人」を「作った経験」で決める

- **「〇〇が好きな方」「エンタメに情熱がある方」を、「こんな人」から外す**：「好き」は絞れない。来る人の多くが持っている
- **「作った経験」で書く**：「〇〇を、△△のくらいの規模で、□□人と作った経験」「締切のある制作を回した経験」「自分の好みと違うものを作った経験」。職種ごとに
- **作品名は、一度だけ**：「なにを」に事実として。募集記事の全部を作品名で埋めない
- **作る現場を、先週の一日で**：「先週は〇〇の仕様を決め、△△の修正を受け、□□の締切に合わせた」。[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)
- **誰が何を決めるかを書く**：「〇〇は担当が決める。△△はプロデューサーが決める。□□はクライアントが決める」。「自分の作品を作れる」の像で来た人が、決める人の多さで離れる
- **待遇と労働時間を、隠さず**：締切前、週末、イベント期間。「エンタメだから」で伏せない。[Wantedlyの募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)

### エージェントベストの見解

これは発注側の誤解の話です。エンタメの会社から、「うちは作品が知られているので、Wantedlyに置けば応募は来る」と相談されることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、作品名で会社ページを埋めると、「話を聞きに行きたい」は押されても、来るのは「作品が好きな人」で、会社が採りたい「作る側に回れる人」は、その中に少ししかいません。面談の時間は「好き」の候補者で埋まり、作る側の候補者に会う時間が無くなります。当社がお願いしているのは、作品名を一度だけ置き、作る現場（誰が何を決めて、締切と修正がどう来るか）を先に書き、「こんな人」を「好き」ではなく「作った経験」で書くことです。書くと、「話を聞きに行きたい」の数は減り、来る候補者が「作る側」に変わります。数が減ることを、会社が先に受け入れておくことが要ります。

## 会社ページと募集記事の見せ方｜作品ではなく、作る現場で

- **「なにを」は、作っているものと届け先で一言**：「〇〇を作って、△△に届けている会社」。作品名の羅列で済ませない
- **「なぜ」は、責任者の「なぜこれを作るか」を体験と場面で**：[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)
- **職種ごとに募集を分け、それぞれで「作った経験」を**：企画、エンジニア、制作進行、デザイン。「クリエイター募集」でまとめない
- **副業・フリーランスの入口を、正社員と分けて**：「何を、どのくらいの期間で、どう関わるか」を最初に。[Wantedlyで副業の募集を書くときの設計](/media/wt-fukugyo-boshu/)
- **「自分の好みと違うものを作る」ことを、隠さず**：クライアントの要望、運営の都合、修正。作る側の実態として
- **作ったものが世に出るまでの時間を書く**：「企画から〇〇まで、△△の期間」。すぐ出ると思って来た人が離れる

会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)、素顔を出す範囲は[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)で書きました。

## ストーリーとカジュアル面談の設計

- **作る現場の人のストーリーで、「締切前の一日」「修正で作り直した日」を本人の言葉で**：[Wantedlyのストーリーで事業の中身を書く方法](/media/wt-story-jigyo/)
- **「好き」で入った人のストーリーで、「好きと、作る側の差」を本人の言葉で**：像との差を、本人が。[Wantedlyの入社後ストーリーの書き方](/media/wt-story-nyusha/)
- **制作進行のストーリーを、別に**：「好き」ではなく「回した経験」で来る職種。回す一日を
- **カジュアル面談で、「作った経験」を聞き、締切と修正の実態を伝える**：「好き」の話で面談を終えない。[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **面談に、作る現場の人が出る**：人事だけの面談は、作る側の実態を伝えられない

## スカウトの設計

- **絞るのは、「作った経験」の記述**：「〇〇を作った」「締切のある制作を回した」「自分の好みと違うものを作った」。「〇〇が好き」「エンタメ志望」で絞らない。[Wantedlyのスカウトで対象を絞る方法](/media/wt-scout-target/)
- **文面は、作る現場と「何を決められるか」を最初に**：「〇〇を作っていて、△△は担当が決められる会社で、あなたの□□を読んで」。作品名で始めない。[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)
- **副業・フリーランスのスカウトは、正社員と分けて**：[Wantedlyの副業スカウトの考え方](/media/wt-scout-fukugyo/)
- **作品が知られている会社ほど、文面から作品名を外す**：作品名は、会社ページで一度読まれている

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「こんな人」を「好き」から「作った経験」に書き直す | 作る現場の責任者と人事 |
| 作る現場（誰が何を決めるか、締切と修正）を書き出す | 作る現場 |
| 待遇と労働時間を、何を書くか決める | 責任者 |
| 責任者が「なぜこれを作るか」を話し、記事に整える | 責任者（整えるのは人事か外に出せる） |
| 作る現場の人が「締切前の一日」「修正の日」を話す | 作る現場 |
| カジュアル面談に作る現場の人が出て、「作った経験」を聞く | 作る現場と人事 |
| スカウトを作る現場を最初に、「作った経験」で絞って送る | 人事（絞る作業は外に出せる） |

運用代行や代理店が支えられるのは、区分の整理、「作った経験」の書き出しの型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業までで、待遇と労働時間の開示、責任者が話すこと、現場が話すこと、面談は会社が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは媒体の向き不向きの話です。エンタメの会社が、Wantedlyで全職種を採ろうとして、「好き」の応募に埋もれる形を、当社は見ています。当社が見ている範囲で、エンタメの会社でWantedlyが向くのは、作る現場の職種（企画、エンジニア、制作進行、デザイン）と、副業・フリーランスの入口です。作る現場の候補者は、作品名ではなく「誰が何を決められるか」「締切と修正がどう来るか」を見て、「話を聞きに行きたい」を押します。副業・フリーランスは、作品単位で関わる人が続く入口になります。一方で、「好き」の応募が多く来る職種（運営、営業、事務、サポート）は、Wantedlyで受けると面談の時間が「好き」で埋まります。当社がお願いしているのは、Wantedlyの募集を作る現場の職種と副業・フリーランスに絞り、他の職種は別の入口で受けることです。絞ると、面談の時間が作る側の候補者に使えます。

## まとめ

- 「好き」で来る候補者は多いが、会社が採りたい「作る側」は「好き」では絞れない。「こんな人」を「作った経験（何を、どのくらい、誰と）」で書く
- 作品名は一度だけ。作る現場（誰が何を決めて、締切と修正がどう来て、自分の好みと違うものをどう作るか）を素顔として先に。待遇と労働時間を「エンタメだから」で伏せない
- 職種ごとに募集を分け、副業・フリーランスの入口を正社員と分ける。作ったものが世に出るまでの時間を書く
- 作る現場の人が「締切前の一日」「修正で作り直した日」を、「好き」で入った人が「好きと作る側の差」を本人の言葉で。面談に現場が出て、「作った経験」を聞く
- Wantedlyの募集は作る現場の職種と副業・フリーランスに絞り、「好き」の応募が多く来る職種は別の入口で。「話を聞きに行きたい」の数が減ることを先に受け入れる

## よくある質問

### 作品が知られているのに、欲しい人が来ません

作品名で会社ページを埋めると、来るのは「作品が好きな人」で、「作る側に回れる人」はその中に少ししかいません。作品名を一度だけ置き、作る現場（誰が何を決めて、締切と修正がどう来るか）を先に書き、「こんな人」を「作った経験」で書いてください。「話を聞きに行きたい」の数は減りますが、来る候補者が作る側に変わります。

### 「好き」を条件にしてはいけませんか

「好き」は、来る人の多くが持っていて、絞れません。「〇〇を作った」「締切のある制作を回した」「自分の好みと違うものを作った」の経験で絞ってください。好きであることは面談で分かります。作った経験は、記事で絞らないと面談の時間が足りなくなります。

### エンタメのWantedlyの設計は、御社に相談できますか

できます。当社は、区分の整理、「作った経験」の書き出しの型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業を支えられます。待遇と労働時間の開示、責任者が話すこと、現場が話すこと、面談は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
