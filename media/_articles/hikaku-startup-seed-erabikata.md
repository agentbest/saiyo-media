シード期のスタートアップが媒体を選ぶとき、最初にぶつかるのは「社長が『新卒を採って一緒に作りたい』と媒体を契約し、学生に会えても『一年後に何をしているか』『給与は続くか』に答えられず、雇用として採った学生の生活と会社の不確かさがぶつかって、学生が離れるか、会社が抱えきれなくなる」という問題です。**結論から言うと、シード期は雇用としての新卒採用の時期ではなく、媒体は「関わってくれる学生に会う」入口です。社長の時間・一年後の姿・給与を続けて払える見込みの三つが揃うまで雇用せず、関わりの形（インターン・業務委託）と終わり方を先に決め、記事を置く型か送る型で会い、比べられる場は使いません。** スタートアップ全体の段階ごとの考え方は[スタートアップ業界の採用媒体の選び方](/media/hikaku-startup-erabikata/)で書きました。この記事はシード期に絞って、雇用の前に決めることと、媒体の位置づけを書きます。

## シード期のスタートアップに、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 社長と数人。事業が決まりきっていない | 「何を任せるか」が月ごとに変わる。一年後の姿が言えない | 雇用より関わり。[シード期スタートアップのOfferBox運用](/media/ob-startup-seed-unyou/) |
| 給与を続けて払える見込みが、資金の残りで決まる | 新卒の生活を預かる責任と、会社の不確かさがぶつかる | 雇用の前に、三つの条件を確かめる |
| 社長の時間が、事業と資金で埋まる | 新卒に教える時間が出ない。関わる学生を放置する | 社長が週に何時間出せるかで、関わりの人数を決める |
| 体験談も知名度も無い | 比べられる場に対象として入れない | 比べられる場は使わない |
| 「一緒に作る仲間」の言葉で集めたくなる | 学生は「仲間」の言葉より、終わり方と対価を読む | 関わりの形と終わり方と対価を先に |
| 関わった学生が、そのまま新卒になる期待 | 段階が変わらないまま雇用し、崩れる | 関わりから雇用へは、条件が揃ってから |

## 判断軸を、シード期に当てる

| 軸 | シード期での見方 |
|---|---|
| 対象（誰に届くか） | 「決まっていない中で、社長と動ける学生」に絞る。「成長したい」は絞る条件にならない。自分で決めて動いた記述、途中で終わった経験の扱いで |
| 型（送るか、来るか、比べられるか） | 送る型は、関わりの提案を一人に向けて書ける。来る型は、社長が「なぜ今、何を、どんな関わりで」を書ければ届く。比べられる型は、体験談も知名度も無いシード期には対象に入れない |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。資金の残りから、続けられる額で。使わない判断も。[予算がほぼ取れない会社の採用媒体](/media/hikaku-yosan-nai/) |
| 運用工数（誰の時間が要るか） | 社長一人。返す時間と会う時間と、関わった学生に教える時間。三つを社長が週に何時間出せるかで、送る数と関わる人数を決める |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。シード期では、「型」で比べられる場を使わないことと、「運用工数」を社長の時間だけで決めることが、他の段階と違います。

### エージェントベストの見解

これをやる前に、先に「社長が週に何時間、学生に教える時間を出せるか」「一年後にその学生が何をしているかを言えるか」「給与を続けて払える見込みがあるか」の三つを確かめておかないと、どの媒体を選んでも、学生と会社の両方に無理が出ます。当社は3媒体すべての販売パートナーとして、シード期の相談を受けますが、「新卒を採りたい」から始まる相談に三つを聞くと、揃っている会社はほとんどありません。揃わないまま雇用として採ると、新卒は「何をすればよいか分からない」まま放置され、給与の見込みが崩れたときに、学生の生活が会社の不確かさに巻き込まれます。順番は、三つが揃うまでは雇用せず、関わりの形（週に何日、何を、いくらで、いつまで）と終わり方を決めてから、媒体で「関わってくれる学生」に会うことです。三つが揃った段階で、関わった学生の中から、雇用として採ります。当社は、シード期の会社には、媒体の提案の前に三つの確認を置いています。

## 学生が、確かめること

- **会社が続くか**：シード期の学生は、家族から「その会社は大丈夫か」と聞かれる。事業と資金の見込みを、言える範囲で
- **関わりの形と終わり方**：週に何日、何を、いくらで、いつまで。「一緒に作る仲間」ではなく、条件で
- **社長と話せるか**：シード期に関わる学生は、社長と直接動くことを望んでいる。社長が出ない募集は読まれない
- **決まっていないことの扱い**：「決まっていない」を隠すか、正直に書くか。学生は決まっていないこと自体より、隠すことを嫌う
- **関わりが新卒につながるか**：つながる条件を言えるか。「まだ言えない」なら、そう書く
- **就活と両立できるか**：関わりの時間が就活を邪魔しないか。試験と就活の時期の扱い

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 社長が「なぜ今、何を、どんな関わりで」を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 関わりの募集を置いて、読んだ学生が話を聞きに来る形。シード期の会社が最も多く並ぶ場でもある |
| 「決まっていない中で動ける」記述で絞って、一人ずつ関わりを提案したい | 企業から送る型（OfferBox） | 関わりの提案を一人に向けて書け、送る数を社長の時間で決められる |
| 体験談も知名度も無い | 学生が並べて比べる場（ワンキャリア）は使わない | 対象に入れない。段階が進んでから |
| 三つの条件（社長の時間・一年後・給与の見込み）が揃っていない | 雇用の募集は出さない | 関わりの募集だけ |
| 関わりの形と終わり方が決まっていない | どれも先ではない | 決めてから |

どれか一つが正解ではなく、社長が書けるか、絞って提案したいかで、先に検討するものが変わります。媒体は一つで足ります。

## 組み合わせ

- **媒体は一つ。二つ目は要らない**：社長一人の時間で回る大きさ。[人事が兼務の会社の採用媒体の選び方](/media/hikaku-jinji-kenmu/)
- **関わりの募集と、学生の紹介を組み合わせる**：関わった学生が友人を連れてくる形が、シード期では媒体より効くことがある
- **インターンの募集として出すなら、条件を先に**：[インターンから採用につなげる考え方](/media/kh-boshudan-intern/)、[Wantedlyでインターンを募集する書き方](/media/wt-boshu-intern/)
- **段階が進んだら、位置づけを変える**：シリーズAで[シリーズAのスタートアップの採用媒体の選び方](/media/hikaku-startup-a-erabikata/)
- **代行は、シード期では合わないことが多い**：関わりの提案は社長の言葉でしか書けない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「一緒に作る仲間」ではなく、関わりの形と終わり方

- **「一緒に作る仲間」「創業メンバー」の言葉で済ませない**：学生は言葉より、条件と終わり方を読む
- **関わりの形を、条件で**：「週に〇日、△△を、□□の対価で、〇か月まで。その後は双方で決める」。数値は自社の実態で。この記事では書かない
- **決まっていないことを、隠さない**：「事業の〇〇は決まっていない。決まっていない中で、△△を一緒に決める」
- **社長が出ることを、書く**：「関わる相手は社長本人。週に〇回、△△の時間」
- **会社が続く見込みを、言える範囲で**：「資金は〇〇まで。□□を目指している」。言えないなら「言えない」と
- **新卒につながる条件を、言えるなら**：「三つの条件が揃ったら、関わった人の中から雇用として声をかける」
- **就活との両立を、書く**：「就活と試験の時期は、関わりを止めてよい」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 三つの条件の確認、関わりの形と終わり方、対価、関わる人数を決める | 社長 |
| 媒体を選ぶ | 社長が書けるか、絞って提案したいかで |
| 記事か文面を書く | 社長本人。他の人が書くと、学生に分かる |
| 返す、会う | 社長。週に何時間と決める |
| 関わった学生に教える | 社長か、初期のメンバー |
| 関わりの終わり方の実行 | 社長。終わりを曖昧にしない |

運用代行や代理店が支えられるのは、三つの条件の整理、関わりの形の型、媒体の選び方、絞る作業までで、記事と文面、返す、会う、教える、終わり方は社長が担います。シード期は、外に出せる作業がほとんどありません。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「シード期に新卒を採れば、安い給与で優秀な人が、会社と一緒に育つ」というものです。シード期に雇用として新卒を採った会社の多くで、新卒は「何をすればよいか」を教える人がおらず、社長は事業と資金で時間が無く、給与の見込みが揺れたときに、新卒の生活が会社の不確かさに巻き込まれます。優秀な学生ほど、それを承認や応募の前に読み取り、来ません。来るのは、条件を読まずに「仲間」の言葉で決めた学生で、決まっていない中で放置されて離れます。逆に、雇用ではなく関わりの形（週に何日、何を、いくらで、いつまで）を条件で書き、社長が直接動き、終わり方を守った会社は、関わった学生が「決まっていない中で動ける人」として残り、三つの条件が揃った段階で、その中から雇用として採れます。当社が最初にお願いするのは、「安く優秀な人を早く」を外し、「関わりの条件と終わり方」を書くことです。シード期の採用は、雇用の数ではなく、関わって残った人の数で見ます。

## まとめ

- シード期は雇用としての新卒採用の時期ではない。社長の時間・一年後の姿・給与を続けて払える見込みの三つが揃うまで雇用しない
- 媒体は「関わってくれる学生に会う」入口。関わりの形（週に何日、何を、いくらで、いつまで）と終わり方を先に決める
- 記事を置く型（Wantedly）は社長が「なぜ今、何を、どんな関わりで」を書ける会社に、送る型（OfferBox）は「決まっていない中で動ける」記述で絞って一人ずつ提案したい会社に。比べられる場（ワンキャリア）は体験談も知名度も無いシード期には使わない
- 学生は「会社が続くか・関わりの形と終わり方・社長と話せるか・決まっていないことを隠していないか・新卒につながるか・就活と両立できるか」を確かめる。「一緒に作る仲間」ではなく条件で
- 媒体は一つ、社長一人の時間で回る大きさ。雇用の数ではなく、関わって残った人の数で見る

## よくある質問

### シード期でも、どうしても新卒を雇用として採りたいです

三つの条件（社長が週に出せる時間・一年後にその新卒が何をしているか・給与を続けて払える見込み）を、文で書いてみます。三つとも書けるなら、シード期でも雇用として採る形はあります。その場合も、「決まっていない」を隠さず、一年後の姿と給与の見込みを本人に伝え、本人が読んで決める形にします。一つでも書けないなら、関わりの形から始めます。関わりから雇用へは、条件が揃ってから、関わった人の中から声をかけます。

### 関わってくれた学生が、そのまま新卒として入ってくれますか

入る学生もいますが、関わりの段階で「新卒として入る」を約束しないことです。約束すると、三つの条件が揃わないまま雇用することになります。関わりの終わり方を守り、三つの条件が揃った段階で、関わった人の中から「雇用として声をかける条件」を先に言っておきます。関わった学生の多くは、他の会社に就職しますが、その学生が会社を知っていて、後で戻ることも、友人を紹介することもあります。

### シード期のスタートアップの媒体選びは、御社に相談できますか

できます。当社は、三つの条件の整理、関わりの形の型、媒体の選び方、絞る作業を支えられます。記事と文面、返す、会う、教える、終わり方は、社長が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、スタートアップの段階ごとの媒体の位置づけを支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
