OfferBoxの運用は、送る前にプロフィールを読み、承認に返し、面談に出て、台帳を付け、見直す、と手が要ります。社内の時間が足りないと、読まずに送り、承認への対応が遅れ、面談の枠が無くなり、台帳が止まり、「効いているのか分からない」で止まります。**結論から言うと、工数が足りないときは、「プロフィールを読んで一文を書く」「承認に当日に返す」「面談に出る」の三つだけを社内に残し、それ以外を減らすか外に出します。減らす順番は、送る数、募集の数、台帳の項目、見直しの頻度で、外に出せるのは検索条件、型、集計、見直しの材料です。現場に頼むのは最小限にし、繁忙期は一時的に縮小し、止める前に小さくします。工数が足りないまま続けると、雑な対応が学生の印象に残ります。** この記事では、工数が足りないと起きること、残す・減らす・外に出すの分け方、減らす順番、現場に頼む最小限、人事一人の場合、繁忙期の縮小、止めるより小さくすること、分担を整理します。人事一人の運用は[人事1人でOfferBoxを回す方法](/media/ob-hitori-jinji/)、代行の範囲は[OfferBoxの運用代行に任せられる範囲](/media/ob-unyou-daikou-hanni/)で書きました。この記事は、それらを「工数が足りない」という症状から辿るものです。

## この作業の目的｜足りない時間で、雑にならずに続ける

工数が足りないときに起きる最も重い問題は、「止まること」と「雑になること」です。止まると、承認した学生が放置されます。雑になると、読まずに送った文面と遅い対応が、学生の印象に残ります。

目的は、足りない時間でも、雑にならず、止まらない大きさに運用を縮めることです。時間を増やすことではなく、時間に合わせて運用を小さくすることです。

## 工数が足りないと、起きること

| 起きること | 何が起きるか |
|---|---|
| 読まずに送る | テンプレになり、開封も承認も減る。学生の印象に残る |
| 承認への対応が遅れる | 承認した学生が他社の面談を先に入れる。[OfferBoxで承認後に返信が来ないときの対応](/media/ob-henshin-konai/) |
| 面談の枠が無い | 承認しても面談に進めない。[OfferBoxで面談につながらないときの原因の切り分け](/media/ob-mendan-tsunagaranai/) |
| 台帳が止まる | 誰に送ったか分からず、重複する。数字が出ない |
| 見直しをしない | 何が効いているか分からず、同じ失敗を繰り返す |
| 全部を少しずつやる | どれも中途半端で、結果が出ず、「効かない」と判断する |
| 止まる | 承認した学生が放置され、再開が重い |

最も多いのは、「全部を少しずつやる」です。減らさずに続けようとして、どれも薄くなります。

## 残す・減らす・外に出す、の分け方

| 社内に残す（削れない） | 減らせる | 外に出せる |
|---|---|---|
| プロフィールを読んで、学生の一文を書く | 送る数（読める数まで） | 検索条件の設計 |
| 承認に当日に返す | 募集の数（一つに） | 文面の型と見本 |
| 面談に出る（現場の人） | 台帳の項目（最小限に） | 台帳の集計 |
| | 見直しの頻度（月に一度に） | 見直しの材料の整理 |
| | 面談の長さ（短く） | 引き継ぎの記録の保管 |
| | 企業ページの更新（起点だけに） | 企業ページの整え方の案 |

「残す」の三つは、学生と直接向き合う部分で、社内の人でないとできません。「減らす」は、量と頻度です。「外に出す」は、設計と集計です。この三つを分けると、足りない時間をどこに使うかが決まります。

### エージェントベストの見解

相談で最も多い思い込みは、「工数が足りないなら、送る数を減らさずに、一通あたりの時間を削るしかない」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、一通あたりの時間を削った会社は、読まずに送る形になり、開封も承認も減り、送った数だけ時間が消えています。逆に、送る数を読める数まで減らした会社は、一通あたりの時間を保ち、開封と承認が保たれ、面談まで進む学生が出ています。当社が工数不足の相談を受けるとき、最初にやるのは、「一通あたりの時間を削る」ではなく「送る数を減らす」ことです。減らした数で結果が出れば、続けられます。削った時間で送った数は、結果が出ず、続きません。

## 減らす順番

1. **送る数を、読める数まで減らす**：最初に。読まずに送る文面は、送らないほうがよい
2. **募集を一つに絞る**：複数の募集を同時に回さない。最も急ぎで、企業ページが整っていて、面談に出る人がいる募集
3. **台帳の項目を減らす**：残すのは、学生・募集・送った日・一文・承認の有無・段・次の連絡日。他は削る
4. **見直しを月に一度にする**：週の見直しは、承認への対応の速さだけ。会は開かない
5. **面談を短くする**：オンラインで、短い時間で、話す人が一つの場面を話す
6. **企業ページの更新を、起点だけにする**：年度の切れ目と、変わったとき

「送る数を最初に減らす」が順番の要点です。数を保ったまま他を減らすと、読まずに送ることになります。送る数の考え方は[OfferBoxの送信ペースの決め方](/media/ob-soushin-pace/)で書きました。

## 現場に頼む、最小限

工数が足りないとき、現場の人に頼むことは増やせません。頼むのを三つに絞ります。

| 頼むこと | いつ | 時間 |
|---|---|---|
| 「最初の月に何をするか」の一文 | 型を作るとき（募集ごとに一度） | 短い |
| 人事が書いた文面の確認 | 送る前（まとめて） | 短い |
| 面談に出る | 承認が来て日程が決まったとき | 面談の時間 |

「読んで書く」は人事が行い、現場の一文を型に入れ、現場が確認して、現場の名前で送ります。名前だけ借りる形にしない条件は、現場が読んで了承することです。現場の巻き込み方は[OfferBoxの現場の巻き込み方](/media/ob-genba-makikomi/)で書きました。

## 人事が一人の場合

- **募集は一つ、週の枠は一つ、読める数だけ送る**
- **承認への対応を、朝と夕方の二回に固定する**：来るたびに返さない。[OfferBoxの即日対応](/media/ob-sokujitsu-taiou/)
- **台帳は最小限、見直しは月に一度**
- **検索条件・型・集計・見直しの材料は、外に出す**
- **止まりそうなサインが出たら、減らす**：止めない

詳しくは[人事1人でOfferBoxを回す方法](/media/ob-hitori-jinji/)で書きました。工数が足りない会社の多くは、この形に近づけると回ります。

## 繁忙期の、一時的な縮小

工数が足りないのが繁忙期だけなら、その期間だけ縮小します。

- **送る数を減らす。ゼロにしない**：ゼロにすると、再開が重い
- **承認への対応だけは続ける**：承認した学生を放置しない。これだけは削れない
- **面談の枠が取れないなら、送る数をさらに減らす**：承認されても面談に進めないなら、送る意味が薄い
- **繁忙期の前に、「この期間は減らす」と決めておく**：始まってから減らすと、承認が来てから枠が無いことに気づく
- **繁忙期が終わったら、戻す時期を決めておく**：「落ち着いたら」にしない

「承認への対応だけは続ける」が、繁忙期の縮小で最も重い一つです。送る数はゼロに近くてよいですが、来た承認には当日に返します。年間の繁忙期の扱いは[OfferBoxの年間スケジュール](/media/ob-nenkan-schedule/)で書きました。

## 止めるより、小さくする

- **止まると、承認した学生が放置され、再開のときに台帳と型が失われる**
- **小さくすれば、承認への対応と面談は続き、台帳が溜まり、再開のときにそのまま戻せる**
- **「月に数通、承認には当日に返す」でも、運用は続いている**
- **止める判断は、面談に出る人がまったく確保できないときだけ**：その場合も、台帳と型は残す
- **小さくした状態を、上司に「縮小中」と伝える**：「効いていない」と判断されないように

「小さくする」と「止める」の違いは、承認への対応が続いているかどうかです。続いていれば、運用は生きています。

## 工数が足りないまま続けると、残るもの

- **読まずに送った文面は、学生に「テンプレ」と記憶される**
- **承認への遅い対応は、学生に「返事が無い会社」と記憶される**
- **面談で人事だけが出て会社説明をすると、「仕事の話が聞けない会社」と記憶される**
- **その記憶は、学生の周りに伝わることがある**

工数が足りないまま数を保つより、数を減らして対応を保つほうが、学生の印象は良く残ります。

| 作業 | 誰が |

| 残す・減らす・外に出すを分ける | 人事と責任者 |
| 送る数と募集を減らす | 人事 |
| プロフィールを読んで一文を書く | 人事 |
| 承認に当日に返す | 人事 |
| 最初の月の一文と文面の確認 | 現場の人 |
| 面談に出る | 現場の人 |
| 台帳（最小限）と月の見直し | 人事 |
| 検索条件・型・集計・材料 | 外部に出してよい |

運用代行や代理店が支えられるのは、残す・減らす・外に出すの分け方の整理、検索条件、型と見本、集計、見直しの材料、縮小の設計までで、読んで書くこと、承認に返すこと、面談、縮小の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの工数不足の相談を受けるとき、検索条件、型、集計、見直しの材料は当社が持てます。人事に残るのは、週に一度の枠で読んで書くことと、毎日二回の承認への対応と、面談の進行と、月の報告です。現場に残るのは、最初の月の一文と、文面の確認と、面談に出ることです。当社が最初にお伝えするのは、「この残る部分が、いまの業務の中に入りますか」という確認です。入るなら、当社は残りを引き受けます。入らないなら、送る数を減らして入る大きさにするか、いったん小さくして承認への対応だけを続けるか、です。無理に続けて雑になるより、入る大きさで続けるほうが、学生の印象と、翌年の運用に残ります。

## まとめ

- 工数が足りないと、読まずに送る・承認への対応が遅れる・面談の枠が無い・台帳が止まる、が起き、雑な対応が学生の印象に残る
- 社内に残すのは「読んで一文を書く・承認に当日に返す・面談に出る」の三つ。減らせるのは送る数・募集の数・台帳の項目・見直しの頻度。外に出せるのは検索条件・型・集計・材料
- 減らす順番は、送る数を読める数まで→募集を一つに→台帳の項目→見直しを月に一度。一通あたりの時間を削らない
- 現場に頼むのは、最初の月の一文・文面の確認・面談、の三つだけ
- 繁忙期は送る数を減らしてゼロにせず、承認への対応だけは続ける。止めるより小さくし、「縮小中」と上司に伝える

## よくある質問

### 送る数を減らすと、上司に「動いていない」と言われます

送った数ではなく、承認と面談の数と、承認への対応の速さで報告します。読まずに多く送って承認が来ないより、読んで少なく送って面談まで進むほうが、結果は出ます。「縮小中で、送る数は減らしているが、承認には当日に返し、面談は続いている」と伝えると、止まっていないことが分かります。

### 外に出せる作業を頼む予算がありません

頼まずに、減らします。検索条件は最初に作った一つを使い続け、型は一つ、台帳は最小限、見直しは月に一度。これで、外に出さなくても、人事一人で回る大きさになります。減らした分、送る数も減りますが、読んで送る形は保てます。

### 工数が足りないときの運用の縮小は、御社に相談できますか

できます。当社は、残す・減らす・外に出すの分け方の整理、検索条件、型と見本、集計、見直しの材料、縮小の設計を支えられます。読んで書くこと、承認に返すこと、面談、縮小の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
