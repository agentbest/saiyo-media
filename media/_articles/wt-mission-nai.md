Wantedlyの会社ページを作ろうとして、「ミッション」の欄で止まる。社内に、ミッションやビジョンの言葉がない。「なぜやるのか」と聞かれても、「仕事だから」「頼まれたから」で、言葉にならない。無理に作ろうとして、どこかで見たような言い回しになる。**結論から言うと、ミッションの一文がなくても、代表の「なぜ」のエピソードがあれば、Wantedlyの会社ページは成立します。無理に作りません。「始めたとき何に困っていたか」「最初のお客さんはどう見つけたか」「辞めなかった理由」を代表に聞き、その話を書きます。話の中で繰り返し出る言葉があれば、それを短い言葉に整え、社内の数人が自分の言葉で言えるようになってから載せます。言えないうちは、その話だけで足ります。スカウトでも、ミッションではなく「なぜ」の具体的な話を置きます。** この記事では、ミッションがないと起きやすい失敗、具体的な話で成立する理由、聞き方、言葉にまとめる手順、社内で言えるまで載せないこと、スカウトでの扱い、分担を整理します。ミッションの書き方は[Wantedlyの会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/)、会社ページの基本は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。この記事は、「ミッションがない」という状態から始める場合です。

## この作業の目的｜「一文」ではなく「場面」で、候補者に「なぜ」を渡す

Wantedlyの候補者が会社ページで読むのは、ミッションの言葉そのものではなく、その言葉の裏にある「なぜこの会社があるのか」です。整った言葉がなくても、「なぜ」が具体的な出来事で書かれていれば、候補者は読めます。

目的は、ミッションを作ることではなく、候補者が「この会社の『なぜ』に自分が重なるか」を判断できる材料を渡すことです。

## ミッションがないと、起きやすい失敗

| 失敗 | 何が起きるか |
|---|---|
| 無理に一文を作る | 「〇〇を通じて社会に貢献する」のような、どの会社でも書ける言葉になる。候補者に響かず、社内でも使われない |
| 他社のミッションを参考にする | 似た表現になり、候補者が「どこかで見た」と感じる |
| 「なぜやるのか」の欄が、事業説明になる | 「〇〇の製造販売を行っています」。「なにを」であって「なぜ」ではない |
| スカウトで想いを語れない | ミッションがないので、共感を伝える文面が書けず、条件の文面になる |
| ミッションの欄を空にする | 「なぜ」がない会社に見える |
| コンサルに作ってもらう | 社内の言葉ではなく、代表も社員も自分の言葉で言えない |

共通するのは、「言葉を作ること」を目的にしていることです。目的は、「なぜ」を候補者に渡すことです。

## ミッションの言葉がなくても、具体的な話で成立する理由

- **候補者は、言葉ではなく、言葉の裏の「なぜ」を読む**：「なぜこの会社を始めたか」「なぜ続けているか」のエピソードがあれば、整った言葉は要らない
- **具体的な話は、標語より伝わり、共感のきっかけになる**：「〇〇で困っている人を見て、△△を始めた」は、「社会に貢献する」より、候補者が自分と重ねやすい
- **代表の話は、社内で使われている**：代表が普段話していることなので、社員も知っている。作った言葉は、社内で使われない
- **代表の話から、あとで言葉が出てくることがある**：先に話、あとで言葉。逆にしない

「ミッションの欄」は、「私たちのなぜ」としてエピソードを書けば成立します。[Wantedlyの会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは共感の媒体なので、ミッションがないと使えない」というものです。当社は採用媒体の代理店として、Wantedlyの運用を見ていますが、立派なミッションの言葉があっても、その裏の具体的な話がなく、社員が自分の言葉で言えない会社の会社ページは、候補者に読まれていません。逆に、ミッションの言葉がなく、「私たちのなぜ」に代表の「始めたとき、〇〇で困っている人を見て」という話だけを書いた会社の会社ページは、話を聞きに来られています。候補者が重なるのは、整った言葉ではなく出来事です。当社がミッションの相談を受けるとき、最初にやるのは、標語を作る手伝いではなく、代表に「会社を始めたとき、何に困っていましたか」と聞いて、その答えを書き起こすことです。書き起こした話で、会社ページの「なぜ」は埋まります。

## 代表の「なぜ」の聞き方

代表に、「ミッションは何ですか」と聞かないことが要点です。具体的な出来事を聞きます。

| 聞くこと | 出てくるもの |
|---|---|
| 「会社を始めたとき、何に困っていましたか」 | 始めた理由。「〇〇で困っている人を見て」「自分が△△で困って」 |
| 「最初のお客さんは、どうやって見つけましたか」 | 事業の原点。「知り合いの□□さんが」「✕✕で声をかけられて」 |
| 「辞めようと思ったことはありますか。なぜ辞めなかったのですか」 | 続けている理由。「〇〇さんに『助かった』と言われて」 |
| 「いまの仕事で、一番嬉しかった場面は」 | 「なぜ」が最も出やすい問い |
| 「これだけは譲れない、と決めていることは」 | 判断の軸。「こういうとき、こうする」 |

代表が話すのは短い時間で、人事が聞いて書き起こします。書かせない考え方は[Wantedlyのストーリーで代表の考えを書く方法](/media/wt-story-daihyo/)、聞いて整える手順は[Wantedlyの記事が書けないときの整理法](/media/wt-kakenai/)で書きました。

## 話から、繰り返し出る言葉を拾って一文にする

1. **書き起こした話を、代表と人事で読み返す**
2. **繰り返し出てくる言葉を探す**：「困っている人を放っておけない」「〇〇が当たり前になってほしい」「△△さんに助かったと言われる」
3. **繰り返し出る言葉があれば、それを整えて短い言葉にする**：新しく考えない。すでにある言葉を整える
4. **繰り返し出る言葉がなければ、無理にまとめない**：その話だけで、会社ページは成立する
5. **まとまった言葉ができても、元の話を消さない**：言葉と話の両方を置く。言葉だけにすると、浮く

「新しく考えない」が要点です。考えた言葉は、社内のものにならず、浮きます。

## 社内の数人が、自分の言葉で言えるまで載せない

- **言葉ができたら、社内の数人に「これを自分の言葉で言ってみてほしい」と頼む**
- **言えなければ、まだ社内のものになっていない**：会社ページに載せる前に、社内で使う
- **社内で使う機会を作る**：判断に迷ったとき、新しい人が入ったとき、「うちは〇〇だから」と短く言えるか
- **社員が言えるようになってから、会社ページに載せる**：候補者が面談で社員に聞いたとき、社員が自分の言葉で答えられる
- **載せるまでの間は、実際の話だけを載せておく**：空にしない

社員が言えないミッションの言葉を載せると、面談で「ミッションについてどう思いますか」と聞かれた社員が答えられず、候補者に「会社ページと違う」が残ります。

## スカウトでは、「なぜ」の具体的な話を置く

- **スカウトの文面で、ミッションの言葉を引用しない**：あっても引用しない。相手には響かない
- **相手の「なぜ」と、自社の「なぜ」の出来事を、それぞれ短く**：「〇〇のために△△をされていると書かれていて。うちも、□□で困っている人を見て始めた会社です」
- **出来事のほうが、標語より重なりが見える**：相手が自分の経験と重ねられる
- **ミッションがない会社ほど、スカウトの共感は代表の経験で伝える**：[Wantedlyのスカウトで共感を伝える書き方](/media/wt-scout-kyoukan/)

共感は、ミッションの言葉で伝わるものではなく、経験の重なりで伝わるものです。

## ミッションが「ない」ままでよい場合

- **代表の「なぜ」のエピソードが、会社ページに書かれている**
- **その話を、社員も知っていて、自分の言葉で話せる**
- **判断に迷ったとき、その原点に戻って決められる**：「〇〇で困っている人のために、なら」
- **候補者が面談で「なぜこの会社を」と聞いたとき、面談に出る人が自分の経験で答えられる**

この四つがあれば、ミッションの一文がなくても、Wantedlyの運用は回ります。まとまった言葉は、あれば便利ですが、なくても困りません。無いことを、欠けていると感じなくてよいです。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「なぜ」のエピソードを、代表に聞く | 人事が聞き、代表が話す |
| 書き起こして、会社ページの「私たちのなぜ」に置く | 人事。代表が「言いそうか」を確認 |
| 繰り返し出る言葉を拾い、一文にするかを決める | 代表と人事 |
| 社内の数人に言ってもらい、載せるかを決める | 人事と社員 |
| スカウトで「なぜ」の出来事を置く | 送る人 |
| 面談で「なぜ」を具体的に答える | 面談に出る人 |

運用代行や代理店が支えられるのは、聞く質問の型、書き起こしと整えること、言葉にまとめる手順、会社ページの「なぜ」の型、スカウトの文面の型までで、代表が自分の話をすること、言葉を作るかの判断、社内で言えるかの確認は企業が行います。

### エージェントベストの見解

これは順番の話です。当社がWantedlyで「ミッションがない」という相談を受けたとき、言葉を作るところから始めません。先に、代表に「会社を始めたとき、何に困っていましたか」と聞き、その答えを書き起こします。エピソードが書けた時点で、会社ページの「なぜ」は埋まり、Wantedlyの運用は始められます。まとまった言葉は、話を書いたあとに、繰り返し出る言葉があれば整え、なければ作りません。逆に、標語を先に作ると、それに合わせて経緯を探すことになり、話が標語の説明になって、候補者に響きません。当社が勧める順番は、聞く、書く、運用を始める、繰り返し出る言葉があれば短く整える、社内で言えるようになったら載せる、です。一文を待って運用を始めない、が最も重い一つです。

## まとめ

- ミッションの一文がなくても、代表の「なぜ」の場面があれば、Wantedlyの会社ページは成立する。候補者は整った言葉ではなく具体的な出来事で重なる
- 無理に作ると、どの会社でも書ける決まり文句になり、社内で使われず、浮く。他社を参考にしない、コンサルに作ってもらわない
- 代表に「ミッションは」と聞かず、「始めたとき何に困っていたか」「最初のお客さん」「辞めなかった理由」を聞き、人事が書き起こす
- 話から繰り返し出る言葉があれば整えて短い言葉に、なければ作らない。言葉ができても元の話を消さない
- 社内の数人が自分の言葉で言えるまで載せず、載せるまではエピソードだけを置く。スカウトでも標語ではなく具体的な話で共感を伝える

## よくある質問

### 代表が「なぜ」を聞かれても、「儲かるから」「頼まれたから」しか言いません

それも「なぜ」を聞くきっかけです。「誰に頼まれましたか」「その人は何に困っていましたか」「儲かると思った最初のきっかけは」と、一つ聞き返します。「頼まれた」の裏には、頼んだ人の困りごとがあり、そこに「なぜ」があります。「社会のため」のような言葉が出なくてよいです。「〇〇さんが困っていて、それを何とかしたかった」で、候補者には届きます。

### ミッションの言葉がないと、スカウトで何を書けばよいか分かりません

相手の「なぜ」と、自社の「なぜ」の出来事を、短く並べて置きます。「〇〇のために△△をされていると書かれていて。うちも、□□で困っている人を見て始めた会社です」。ミッションの言葉より、具体的な話のほうが、相手は自分の経験と重ねられます。書き方は[Wantedlyのスカウトで共感を伝える書き方](/media/wt-scout-kyoukan/)で書きました。

### ミッションが言葉になっていない会社のWantedlyは、御社に相談できますか

できます。当社は、聞く質問の型、書き起こしと整えること、言葉にまとめる手順、会社ページの「なぜ」の型、スカウトの文面の型を支えられます。代表が自分の話をすること、言葉を作るかの判断、社内で言えるかの確認は、企業が行ってください。当社は採用媒体の代理店として、Wantedlyの運用を支えています。
