ワンキャリアのスカウトは、企業ページの掲載やイベントと同じ会社の中で動きます。学生は文面を読んだあと、企業ページと選考体験談・クチコミで確かめ、イベントや面談に来ます。そのため担当決めは、掲載・イベント・面談まで含めた話になります。**結論から言うと、ワンキャリアのスカウトは、プロフィールを読んで一文を書き、面談に出るところを年次の近い社員に、型づくり・受諾への対応・記録・体験談の確認・掲載との言葉合わせを人事に割り振ります。担当は募集ごとに決め、社員の時間は上司と合意して先に押さえ、人事は自分で送るより全体をそろえる役に回ります。割り振りが崩れると、文面の中身が薄くなるか、受諾への対応が遅れるか、体験談に「話が違った」と残るかのいずれかが出るので、その兆しで見直します。** この記事では、偏った体制で起きること、作業の割り振り、募集単位の担当、時間の押さえ方、人事の役回り、崩れの兆し、見直し方を整理します。他媒体での考え方は[OfferBoxの現場の巻き込み方](/media/ob-genba-makikomi/)と[Wantedlyのスカウトを誰が送るか](/media/wt-scout-tantou/)で書きました。

## 割り振りで守るもの｜文面の中身、対応の早さ、掲載・体験談との食い違いのなさ

ワンキャリアのスカウトの成果を左右するのは、主に三つです。文面に学生のプロフィールの一文と入社一年目の具体があること、受諾に翌日までに返せること、そして文面の内容が企業ページ・イベント・体験談と食い違っていないことです。

一つ目は、一年目の仕事を最近経験した社員が書くと具体的になります。二つ目は、毎日管理画面を見られる人がいないと遅れます。三つ目は、掲載とイベントの内容を把握し、体験談を読んでいる人でないと気づけません。三つを一人で抱えるのは難しいので、人を分けて受け持ちます。

## 偏った体制で起きること

| 体制 | ワンキャリアで起きやすいこと |
|---|---|
| 人事がすべて受け持つ | 文面に一年目の具体が入らない。面談も人事だけで、仕事の中身を話せない。体験談に「現場の人と話せなかった」と残る |
| 年次の近い社員に任せきり | 繁忙期に止まる。受諾の通知が本人に届いて返事が遅れる。記録がつかず、体験談も掲載も誰も見ない |
| 担当を決めず、手の空いた人が送る | 誰も送らない週が出る。受諾に誰が返すかで止まる |
| 外部に丸ごと任せる | 文面が会社の言葉から離れ、面談や企業ページと話がずれる。任せられる範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書いた |

よく見かけるのは、一行目の「人事がすべて受け持つ」形です。抱え込んだ結果、文面が一般論になり、面談後の体験談に「一年目の話を実際にやった人から聞けなかった」と書かれます。

## 作業ごとの割り振り

| 作業 | 担当 | 理由 |
|---|---|---|
| 自社の体験談とクチコミを読む | 人事 | 全体を見る人が読み、学生の疑問を送る人に伝える |
| 企業ページ・イベントとスカウトの言葉をそろえる | 人事 | 掲載とイベントを把握している人がそろえる |
| 絞り込みの条件をつくる | 人事と職種の責任者 | 募集の「こんな人」から。責任者が学生像を言葉にする |
| プロフィールを読む | 年次の近い社員 | 学生時代の経験が一年目のどこに重なるかを判断しやすい |
| 学生の一文と一年目との重なりを書く | 読んだ本人 | 読む人と書く人を分けると中身が薄れる |
| 選考で何を見るかの一文 | 面接担当（人事が聞き取って型にする） | 面接で実際に見ている人の言葉を使う |
| 文面のうち変えない部分の型 | 人事 | 募集ごとに用意し、言葉づかいをそろえる |
| 送信 | 読んで書いた本人（その人の名前で） | 送り主と面談相手が同じだと、受諾後の話がつながる |
| 受諾への返事（翌日まで） | 人事 | 毎日見られる人。通知を人事に集める |
| 日程の調整 | 人事 | 学生の都合に合わせた候補を出す |
| 面談 | 年次の近い社員（送った本人が望ましい） | 文面の送り主がそのまま出てくる |
| 記録 | 人事（送った人は一文だけ残す） | 全体を見る人がつける |
| 週・月・年度の振り返り | 人事（送った人は月の会に参加） | そろえる役が回す |

社員に頼むのは「読む・書く・送る・面談に出る」で、週に一度の読み書きの時間と面談の時間に収めます。残りの作業、とくに掲載と体験談に関わるものは人事が受け持ちます。

### エージェントベストの見解

ワンキャリアの担当決めの相談でよく出るのが、「若手は忙しいし会社のこともまだ詳しくないので、スカウトは人事でやるしかない」という声です。当社は求人広告代理店として、ワンキャリアのスカウト運用に関わっていますが、人事だけで書いている文面は、学生のプロフィールは引けていても、その経験が一年目のどこで生きるかが書けていないことがよくあります。人事は一年目の仕事を最近経験していないためです。年次の近い社員なら「自分も学生時代に〇〇をしていて、最初の月の△△で役立った」と書けます。そこで当社は、社員に頼む作業を「読んで一文を書く」と「面談に出る」の二つに絞り、掲載との言葉合わせや体験談の確認を含む残りを人事に寄せる形を提案します。忙しい人に頼むからこそ、頼む範囲を狭くします。

## 担当は募集ごとに一人

- **募集ごとに、読んで書く社員を一人決める**：その職種の年次の近い社員。一人に複数の募集を持たせない
- **その社員が面談にも出る**：文面の送り主と、話す相手を同じにする
- **出られない週の代わりを決めておく**：同じ職種の別の社員か、責任者
- **受諾への返事は、すべての募集分を人事がまとめて**：通知の届く先を一つにする
- **その募集のイベントに、同じ社員が出られるとなおよい**：スカウト、イベント、面談で同じ顔が続く

募集ごとに決めるのは、学生が文面の送り主と話したくて受諾しているからです。面談に別の人が出るとそこで話がずれ、それが体験談に書かれます。ワンキャリアではイベントの体験談も読まれるので、スカウトとイベントで顔ぶれがそろっていると、確かめた学生が安心しやすくなります。

## 社員の時間は、上司と合意して先に押さえる

1. **上司と「週に一度、この時間をスカウトに充てる」と合意する**：本人の善意ではなく業務として位置づける
2. **その枠を本人の予定表に入れておく**：空いたときにやる、にしない
3. **枠の中で読めた人数だけ送る**：送る数を目標にしない
4. **面談の枠も別に押さえる**：受諾が来てから探さない。学生が参加しやすい時間帯を含める
5. **繁忙期は枠を小さくすると、あらかじめ決めておく**：ゼロにはしない
6. **異動や退職で担当が替わるときは、その募集を次の社員へ引き継ぐ**

最初にやるのは上司との合意です。合意がないと、本人は自分の仕事を削って手伝っている感覚になり、長く続きません。社員への頼み方は[記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/)の考え方も参考になります。

## 人事の役回り｜送るより、そろえる

| 人事の作業 | 中身 |
|---|---|
| 体験談とクチコミを読み、要点を伝える | 学生が何を気にしているかを、書く社員に渡す |
| 掲載・イベントとの言葉をそろえる | 文面の「一年目」「選考で見ること」が企業ページやイベントの案内と同じか見る |
| 型を渡す | 募集ごとの文面の型。社員は変える箇所だけ書けばよい形にする。[ワンキャリアのスカウトを相手ごとに変える範囲](/media/oc-scout-kojinka/) |
| 読む候補を絞る | 条件を整えて、社員が読む人数を減らす。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/) |
| 受諾をすべて受ける | 通知を人事に集め、翌日までに返す。[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/) |
| 日程を組む | 社員の面談枠から、学生の都合に合う候補を出す |
| 記録をつける | 社員に残してもらうのは送った一文だけ |
| 振り返る | 週・月・年度。社員には結果と、次に直す一か所だけ伝える |
| 手応えを返す | 「〇〇さんの文面から受諾があり、面談まで進みました」「体験談に『自分を読んでくれていた』とありました」 |

社員の協力を長く続けるうえで効くのが、最後の「手応えを返す」です。ワンキャリアでは体験談に学生の言葉が残るので、良い感想を本人に伝えると、自分の文面が届いたことを実感でき、次の週にもつながります。

## 割り振りが崩れてきた兆し

| 兆し | 何がずれているか | 戻し方 |
|---|---|---|
| 文面に一年目の具体がない | 人事が書いている | 読んで書く作業を社員へ |
| 受諾への返事が遅れる | 通知が社員に届いている | 通知の届く先を人事にする |
| 送らない週が続く | 社員の枠が守られていない | 上司と枠を合意し直す |
| 体験談に「文面と違う人が出てきた」 | 送り主と面談相手が別 | 募集ごとの担当をそろえる |
| 体験談に「企業ページと話が違った」 | 掲載との言葉合わせをしていない | 人事の週の確認に入れる |
| 体験談を誰も読んでいない | 読む役が決まっていない | 人事の週の確認に入れる |
| 社員が「何のためにやるのか」と言い出す | 手応えが返っていない | 結果と体験談の言葉を伝える |

兆しが見えたら、作業の割り振り表に戻り、実際に誰が受け持っているかを確かめます。たいていは、人事か社員のどちらかに作業が寄りすぎています。

## 振り返りの時期と、社内で共有する一文

- **年度の振り返りで、割り振りの崩れを確かめる**：記録の集計や新しい体験談と合わせて見る
- **担当の社員が替わったら、割り振り表を渡す**：口頭だけで引き継がない
- **半年に一度、社員の負担を聞く**：週の枠は無理なく続けられる大きさか
- **割り振り表を、上司・社員・人事の三者で持つ**

社内で共有するのは、「社員に頼むのは、読んで書くことと面談に出ることまで。掲載・体験談・受諾対応を含むほかは人事が受け持つ」という一文で足ります。これが伝わっていれば、社員は引き受けやすく、人事も抱え込みすぎずに済みます。

## 社内の分担

| 作業 | 担当 |
|---|---|
| 割り振り表をつくる | 人事 |
| 募集ごとの担当を決める | 人事と職種の責任者 |
| 上司と時間の合意をとる | 人事 |
| 読んで書いて送る | 年次の近い社員 |
| 選考で見ることを言葉にする | 面接担当 |
| 受諾対応、日程、記録、体験談の確認、掲載との言葉合わせ、振り返り | 人事 |
| 面談 | 年次の近い社員 |
| 結果と体験談の言葉を社員に返す | 人事 |

運用代行や代理店が手伝えるのは、割り振り表のひな形、募集ごとの担当の決め方、社員に渡す型と見本、人事の作業の整理、崩れの兆しの点検までです。読んで書くこと、送ること、受諾への返事、面談、上司との合意は、企業の側で行います。

### エージェントベストの見解

社内に残すべき作業と、外に出せる作業の線引きを考えます。当社がワンキャリアのスカウトの体制づくりに関わる場合、割り振り表、文面の型と見本、人事の作業の整理は当社から出せますし、絞り込みの条件、記録表、振り返りの型、体験談の要点のまとめといった人事側の作業の一部を引き受けることもできます。一方で、「年次の近い社員がプロフィールを読んで一文を書くこと」と「人事が翌日までに受諾へ返すこと」は社内にしか置けません。前者は一年目を最近経験した人の言葉が要り、後者は毎日社内で管理画面を見る人が要るからです。この二つを社内で押さえられるかどうかで、スカウトを始める時期を決めるよう勧めています。押さえられない段階なら、先に企業ページとイベントを整え、掲載で興味を持った学生を待つほうが、体験談に残る失敗を減らせます。

## まとめ

- ワンキャリアのスカウトは掲載・イベントと同じ会社の中で動く。読んで書く・送る・面談に出るは年次の近い社員、型・受諾対応・記録・体験談の確認・掲載との言葉合わせは人事
- 人事だけで回すと一年目の具体が入らず、社員任せにすると止まって対応が遅れ、体験談も掲載も見る人がいなくなる
- 担当は募集ごとに一人決め、その社員が面談やイベントにも出る。受諾への返事は人事が一か所で受ける
- 社員の時間は上司と合意して先に押さえ、人事はそろえる役として型・絞り込み・対応・記録・体験談の要点・手応えの返しを受け持つ
- 文面に具体がない、返事が遅い、送らない週が続く、体験談に「話が違った」が出る、が崩れの兆し。割り振り表を三者で共有する

## よくある質問

### 若手社員は、まだ会社全体のことをよく知りません

スカウトの文面に要るのは会社の全体像ではなく、一年目に何をしたか、学生時代のどんな経験が役立ったかです。これは年次の近い社員がいちばん具体的に書けます。会社全体の説明は企業ページとイベントに任せ、文面には入れません。面談でも社員は一年目の話を受け持ち、全体の説明は人事が補います。

### 人事が一人しかおらず、受諾対応も記録も体験談の確認も手が回りません

社員に渡す作業を増やすより、人事の作業を軽くします。絞り込みの条件、記録表、振り返りの型、体験談の要点のまとめは、外部に整えてもらうこともできます。受諾への返事だけは社内に残し、それ以外は型で負担を減らします。それでも難しければ、送る人数を減らし、募集を一つに絞ります。

### ワンキャリアのスカウトの体制づくりを、御社に相談できますか

できます。割り振り表のひな形、募集ごとの担当の決め方、社員に渡す型と見本、人事の作業の整理、崩れの兆しの点検をお手伝いします。読んで書くこと、送ること、受諾への返事、面談、上司との合意は、企業の側で行ってください。当社は求人広告代理店として、ワンキャリアのスカウト運用を支えています。
