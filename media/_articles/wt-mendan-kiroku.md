Wantedlyのカジュアル面談は、現場の社員が出ることが多い場です。面談の数が増えると、「何を話したのかが人事に分からない」「選考に進んだ人が、面接で同じ話を二度させられる」「面談で出た質問が記事に戻らない」といったことが起きます。**結論から言うと、共有されない原因は、書く人のやる気より、「何に使うか」「何を残すか」「どこに書くか」が決まっていないことにあります。使い道を先に決め、残す項目を絞り、面談の当日に台帳の同じ行へ短く書く形にします。** 面談の流れそのものは[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。この記事は、面談が終わったあとの「残す・渡す」に絞ります。

## 症状の確認｜共有されないと、何が起きるか

| 症状 | 起きていること |
|---|---|
| 人事が、面談の中身を本人に聞きに行っている | 書く場所も項目もない |
| 選考で、同じ質問をもう一度している | 面接に出る人が面談の内容を知らない |
| 面談に出た人ごとに、メモの長さも中身も違う | 項目が決まっていない |
| メモはあるが、誰も読んでいない | 使い道が決まっていない |
| 面談で出た質問が、記事に反映されない | メモが人事の手元で止まっている |
| 仕事に関係のない話まで書かれている | 残さないことが決まっていない |

候補者の側から最も見えやすいのは、二つ目の「同じ質問をもう一度」です。面談で話したことを、選考でまた一から聞かれると、「社内で話がつながっていない会社」と受け取られます。面談から選考への渡し方は[Wantedlyのカジュアル面談から選考へ移す方法](/media/wt-scout-senkou-ikou/)で書きました。

## 原因の切り分け｜この順番で見る

1. **使い道が決まっていない**：次に会う人が読むのか、人事が判断に使うのか、記事を直すのに使うのか。決まっていないメモは書かれず、書かれても読まれない
2. **残す項目が決まっていない**：自由記述にすると、長い人と一行の人に分かれ、読む側が拾えない
3. **置き場が決まっていない**：チャット、個人のメモ、紙に散る。台帳の行とつながっていない
4. **書く時間がない**：面談の直後に次の予定が入っている
5. **読む人が決まっていない**：人事が読むのか、次の面接官が読むのか

1が先に来るのは、使い道が決まると、項目と読む人が自然に決まるからです。

### エージェントベストの見解

面談メモの書式を作る前に、先に「誰が、いつ、何のために読むか」を決めておかないと、メモは続きません。当社がWantedlyの運用の相談で台帳を見ると、項目の多い面談メモの欄が用意されているのに、ほとんど空いている会社があります。聞くと、「書いても誰も読まないので、書かなくなった」という答えが返ってきます。当社が勧めるのは、使い道を二つだけに絞ることです。一つは、次に会う人が面談の続きから話せるようにすること。もう一つは、候補者が読んで分からなかったことを記事に戻すことです。この二つに要る項目だけを残すと、メモは短くなり、読む人もはっきりします。書く人に「この一行は、次の面接官がそのまま読みます」と伝えるだけで、書かれる率が変わります。

## 打ち手1｜面談メモの型を、短く決める

| 項目 | 何を書くか | 誰が使うか |
|---|---|---|
| どこを読んで来たか | 記事の題名か、スカウトの文面 | 人事（記事の見直し） |
| 本人がやりたいと話したこと | 本人の言葉で一行 | 次に会う人 |
| 本人からの質問 | 答えた質問と、答えられなかった質問 | 次に会う人・人事 |
| 読んで分からなかったこと | 記事に足りない部分 | 人事（記事の見直し） |
| 最後に伝えた選択肢と、本人の反応 | 選考・別の人と話す・いったん終わる | 人事 |
| 次の連絡日 | いつ、誰が連絡するか | 人事 |

評価の欄は置きません。カジュアル面談は選考ではないので、点数や合否の印象を残すと、次の面接官が先入観を持って会うことになります。「次に会う人に伝えたいこと」を一行だけ自由に書く欄を置けば足ります。

## 打ち手2｜置き場と書く時期を決める

- **置き場は、台帳の同じ行**：応募やスカウトの返信を一つの台帳で持っているなら、その行に面談メモの列を足す。持ち方は[Wantedlyの応募・スカウトの管理の仕方](/media/wt-scout-oubo-kanri/)
- **書くのは面談の当日**：翌日になると、本人の言葉が自分の言葉に置き換わる
- **面談の後ろに短い時間を空けておく**：日程を入れるときに、面談の直後を空ける
- **書けないときは、人事が聞き取って書く**：面談に出た人に短く話してもらい、人事が台帳に入れる
- **チャットで流さない**：通知で流れたメモは、あとから探せない

## 打ち手3｜読む人と使い方を決める

- **次の面接官は、面接の前にその行を読む**：「面談では〇〇と話していましたね」から始めると、候補者は話の続きだと分かる
- **人事は、月に一度「読んで分からなかったこと」を集める**：同じ質問が続くなら、募集記事か会社ページに足す。直し方は[Wantedlyのコンテンツを四半期で見直す方法](/media/wt-naiyou-review/)
- **面談に出た人に、使われたことを返す**：「あの一行で記事を直しました」と伝えると、次も書かれる

## 残さないこと

面談で聞こえた話でも、仕事に関係のない事情（家族、健康、出身、信条など）は残しません。そもそも聞かないことは[カジュアル面談で聞くこと・聞かないこと](/media/wt-scout-mendan-shitsumon/)で書きました。誰にどこまで見せるかは[Wantedlyの応募者情報を社内でどこまで共有するか](/media/wt-oubosha-jouhou/)で整理しています。残す期間や消し方は、自社の個人情報の取り扱い方針に沿ってください。

## 外に出す場合の範囲

運用代行や代理店が支えられるのは、面談メモの型、台帳の列の設計、「読んで分からなかったこと」の集計と記事の直し案までです。面談に出ること、メモを書くこと、次の面接官が読むことは企業が行います。外部に台帳を見せる場合は、見せる項目を決め、契約で範囲を合意しておきます。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、面談の当日に一行を書くところまでです。当社がWantedlyの運用を支えるとき、面談メモの集計と、そこから記事の直し案を作ることは当社でも持てます。毎月、「読んで分からなかったこと」を並べて、どの記事のどこに一文足すかを出すのは、外にいるほうがかえって偏りなく拾えます。一方で、面談に出た人の一行は、外から代わりに書けません。候補者が何を話し、どこで表情が変わったかは、その場にいた人にしか分かりません。当社が最初にお伝えするのは、「書くのは面談に出た人、集めて使うのは人事か当社」という線です。この線を引くと、面談に出る人の負担は一行だけになり、続きやすくなります。

## まとめ

- 面談の内容が共有されないと、選考で同じ質問を繰り返し、記事も直らない
- 原因は、使い道・項目・置き場・時間・読む人の順に切り分ける。使い道が決まれば、項目と読む人が決まる
- メモは「どこを読んで来たか・やりたいこと・質問・分からなかったこと・選択肢と反応・次の連絡日」に絞り、評価の欄は置かない
- 置き場は台帳の同じ行、書くのは面談の当日。次の面接官は面接の前に読み、人事は月に一度記事に戻す
- 仕事に関係のない事情は残さない。外に出せるのは型と集計と直し案まで

## よくある質問

### 面談に出る社員が忙しく、メモを書いてくれません

書く量を一行まで減らし、面談の直後に短い時間を日程として空けておきます。それでも書けない日は、人事が短く聞き取って台帳に入れます。書いた一行が選考や記事で使われたことを本人に返すと、次から書かれやすくなります。

### 面談の録音や録画を残してもよいですか

残す場合は、事前に相手に目的を伝えて同意を得ることが前提です。カジュアル面談は「気軽に話す場」として来ている人が多いので、録音があると話しにくくなることもあります。扱いは自社の個人情報の取り扱い方針に沿って決め、多くの場合は一行のメモで足ります。

### 面談記録の仕組みづくりは、御社に相談できますか

できます。当社は、面談メモの型、台帳の列の設計、「読んで分からなかったこと」の集計と記事の直し案を支えられます。面談に出ること、メモを書くこと、選考で読むことは企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
