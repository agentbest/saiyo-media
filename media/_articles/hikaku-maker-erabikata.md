BtoCの大手、BtoBの大手、BtoCの中堅・中小、BtoBの中堅・中小、地方のメーカーが、新卒を採る。学生が「メーカー志望」と言うとき、指しているのは製品名で知られたBtoCの大手で、BtoBの中堅・中小のメーカーが「メーカー」の言葉で募集しても、その学生には自社を指していると読まれない。技術系は研究室と学校の推薦の流れで会社を選び、文系は営業と管理。工場が地方にあり、配属が入社後に決まることが多い。**結論から言うと、メーカーは「BtoCかBtoBか」「大手か中堅・中小か」の四つに分けてから媒体を選びます。「メーカー志望」の学生は自社を指していないことを前提に、BtoBは「何の最終製品に入っているか」でつなぐ一文を、中堅・中小は地元と最終製品を最初に置きます。技術系は研究室と推薦の流れを主にし、媒体は推薦の外の学生に研究の距離を渡す補助に、文系は「ものづくりに興味」ではなく「技術や仕組みを人に説明した」の記述で絞ります。BtoC大手は学生が並べて比べる場で職種と配属の実態を、BtoBは最終製品でつなぐ一文で専攻と研究の内容で絞って送る型を、中小は地元と工場の一日の記事を先に検討します。** この記事では、メーカーに共通する採用構造、判断軸の当て方、学生が確かめること、四つの区分ごとの一行、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。業界ごとの違いは[化学](/media/hikaku-kagaku-erabikata/)、[食品](/media/hikaku-shokuhin-erabikata/)、[電機](/media/hikaku-denki-erabikata/)、[半導体](/media/hikaku-handoutai-erabikata/)、[自動車](/media/hikaku-jidosha-erabikata/)の記事で、3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## メーカーの採用構造と、媒体との相性

| 区分 | 採用の形 | 媒体との相性 |
|---|---|---|
| BtoCの大手（食品、家電、日用品、自動車の完成車など） | 製品名で知られ、応募が多い。「メーカー志望」の学生が指している会社 | 比べられる場で職種と配属の実態を。応募の数を成果と見ない |
| BtoBの大手（素材、部品、産業機械、電子部品など） | 業界内では知られ、学生には見えない。技術系を推薦で多く採る | 最終製品でつなぐ一文で、専攻と研究の内容で絞って送る型 |
| BtoCの中堅・中小（地域の食品、日用品、工芸品など） | 商品名で知られ、会社名で知られない。地元で採る | 商品名でつなぐ一文と地元で絞って送る型 |
| BtoBの中堅・中小、地方のメーカー | 学生の候補に入っていない。地元の理系と文系の営業。工場が地方 | 最終製品の一文と地元で絞って送る型か、工場と開発の一日の記事 |

| 共通の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「メーカー志望」の学生はBtoC大手を指している | BtoBと中小が「メーカー」の言葉で募集して届かない | 「メーカー」を前に出さず、最終製品と地元で |
| 技術系は研究室と推薦の流れ | 媒体の外で決まることが多い | 推薦を主に。媒体は推薦の外の学生に |

## 判断軸を、メーカーに当てる

| 軸 | メーカーでの見方 |
|---|---|
| 対象（誰に届くか） | 技術系は専攻と研究の内容で絞れるかを仕様で確認する。推薦で会った学生に送らない。「メーカー志望」「ものづくりに興味」は絞る条件にならない。文系は「技術や仕組みを人に説明した・違う立場の人の間に入った・数字を追った」の記述で。中堅・中小は地元と出身地域で |
| 型（送るか、来るか、比べられるか） | BtoC大手は「比べられる」型が使える。BtoBと中堅・中小は「比べられる」型で大手の隣に並ぶと候補に入りにくく、「送る」型で最終製品と研究の距離を先に渡す。「来る」型は工場と開発の一日を書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 技術者は開発と生産の山で動けない。研究の距離の一文と名義と面談に固定する。送る型は作業を外に出せるが、研究の内容の読み込みは技術者が支える |

### エージェントベストの見解

相談で最も多い思い込みは、「メーカー志望の学生は多いから、『メーカー』で募集すれば届く」というものです。当社は3媒体すべての販売パートナーとして、メーカーの相談を受けますが、学生の記述にある「メーカー志望」は、製品名で知られたBtoCの大手を指していて、BtoBの素材や部品や産業機械の会社、地方の中堅・中小のメーカーを指していません。「メーカー志望」の記述で絞って送ると、承認や応募は付きますが、その学生は自社を「メーカー」として見ておらず、面談で「思っていたメーカーと違う」と離れます。当社がBtoBと中堅・中小のメーカーに勧めているのは、「メーカー志望」で絞らず、「メーカー」を前に出さず、「当社は〇〇（最終製品）の△△に入る□□を作っている」と最終製品でつなぐ一文を最初に置き、技術系は研究の距離、文系は「技術を人に説明した」の記述で絞ることです。

## 学生が、確かめること

- **何を作っている会社か**：BtoCなら製品名、BtoBなら最終製品との関係。「メーカー」の中の何か
- **技術系なら、研究の距離**：自分の研究と、製品の技術の距離
- **勤務地と配属**：工場と本社と開発の場所、配属がいつどう決まるか、転居を伴う異動の範囲

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| BtoCの大手で、製品名で知られ、職種ごとにクチコミと選考情報が付いている | 学生が並べて比べる場（ワンキャリア）で職種と配属の実態を | 比べる対象の中心。開発の枠と営業・生産の実態とクチコミをずらさない |
| BtoBの大手で、技術系を推薦の外の学生に、研究の内容で絞って会いたい | 企業から送る型（OfferBox） | 最終製品の一文と研究の距離で開かれ、専攻と研究の記述で絞れる。[OfferBoxで研究職を採るオファー文面の書き方](/media/ob-kenkyu-offer-bunmen/) |
| 中堅・中小・地方のメーカーで、地元の学生に絞って会いたい | 企業から送る型（OfferBox） | 出身地域と最終製品の一文で絞れる。作業を外に出せる。[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/) |
| 四つの区分のどこにいるかと、最終製品の一文が、まだない | どれも先ではない | 区分と一文を作ってから。「メーカー」の一語では自社を指さない |

どれか一つが正解ではなく、BtoCかBtoBか、大手か中堅・中小か、技術系か文系か、地域かで、先に検討するものが変わります。

## 組み合わせ

- **研究室と推薦の流れと、媒体を組み合わせる**：推薦で会った学生に媒体で送らない。媒体は推薦の外の学生と文系に。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)
- **BtoBと中堅・中小は、送る型と記事を置く型を組み合わせる**：文面で「〇〇に入る□□で、あなたの△△を読んで」を、記事で「製品ができるまで」と「世に出た日」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)

## 見せ方｜「メーカー」ではなく、最終製品と、研究の距離と、勤務地

- **最終製品でつなぐ一文を、最初に**：BtoBは「当社の〇〇は、△△（最終製品）の□□に入っている」。BtoCの中小は「〇〇（商品名）を作っている会社」。「メーカー」「ものづくり」の一語で済ませない
- **研究の距離を、研究の内容で**：「あなたの〇〇の研究と、当社の△△は、□□でつながる」。技術者の名義で
- **勤務地と配属の決まり方を、最初に、隠さず**：「工場は〇〇、本社は△△。配属は□□の時点で、本人の希望と〇〇で」。数値は実態で。この記事では書かない

## 社内の分担

| 作業 | 誰が |
|---|---|
| 四つの区分のどこにいるかと、最終製品でつなぐ一文 | 経営と人事、営業の責任者 |
| 技術系か文系か、区分で、先に検討する型を決める | 人事と責任者 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行（研究の内容の読み込みは技術者が支える） |
| 記事を置く型なら、技術者や工場の若手が一日を話し、整えるのは人事か外に | 若手と人事 |
| 研究の距離の一文、文面の最終確認、名義、面談 | 技術・営業の若手 |

- **技術者に頼むのは、研究の距離の一文・名義・面談の三つ。開発と生産の山を避けて**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)

運用代行や代理店が支えられるのは、区分の整理、一文の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分までで、最終製品の一文の中身、研究の距離の一文、勤務地と配属の開示、名義の選定、面談、推薦の流れは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「自社はBtoCかBtoBか、大手か中堅・中小か」の四つのどこにいるかを決めておかないと、BtoC大手の採用の形（比べられる場、応募が多い、絞る）をBtoBの中小が真似て、届かないまま媒体のせいにします。当社はOfferBoxの運用代行を受けているので、メーカーの承認から面談までを見ていますが、BtoBの中小がBtoC大手のやり方（会社名を前に出す、比べられる場に載せる）をそのまま使っている形が多くあります。四つの区分で、届く学生も、先に検討する型も、最初の一文も違います。順番は、区分を決め、BtoBなら最終製品でつなぐ一文を、中堅・中小なら地元を、技術系なら研究の距離を、文系なら「技術を人に説明した」の記述を、それぞれの区分に合わせて置くことです。

## まとめ

- 学生の「メーカー志望」は製品名で知られたBtoCの大手を指していて、BtoBと中堅・中小のメーカーを指していない。「メーカー志望」の学生の数は、自社に届く学生の数ではない
- 「BtoCかBtoBか」「大手か中堅・中小か」の四つに分けてから媒体を選ぶ。BtoBは最終製品でつなぐ一文、中堅・中小は地元と商品名・最終製品を最初に。「メーカー」「ものづくり」の一語で済ませない
- 技術系は研究室と推薦の流れを主にし、媒体は推薦の外の学生に研究の距離を。文系は「ものづくりに興味」ではなく「技術を人に説明した」の記述で絞る。技術系と文系で型を分ける
- BtoC大手は並べて比べる場で職種と配属の実態を、BtoBは最終製品でつなぐ一文で専攻と研究の内容で絞って送る型を、中小は地元と工場の一日の記事を先に
- 技術者に頼むのは研究の距離の一文・名義・面談で、作業は外に。業界ごとの違いは化学・食品・電機・半導体・自動車の個別の記事で

## よくある質問

### 「メーカー志望」の学生が多いと聞きます。なぜ届きませんか

学生の「メーカー志望」は、製品名で知られたBtoCの大手を指していて、BtoBの素材・部品・産業機械や、地方の中堅・中小のメーカーを指していません。「メーカー志望」の記述で絞って「メーカー」の言葉で送ると、承認は付いても面談で「思っていたメーカーと違う」と離れます。「メーカー」を前に出さず、最終製品でつなぐ一文と、研究の距離か「技術を人に説明した」の記述で絞ります。

### 自社の業界の記事はどれを読めばよいですか

まず、BtoCかBtoBか、大手か中堅・中小かの四つのどこにいるかを決めます。そのうえで、素材が見えないなら[化学](/media/hikaku-kagaku-erabikata/)、応募が多いのに残らないなら[食品](/media/hikaku-shokuhin-erabikata/)、会社名は知られていて事業と配属が見えないなら[電機](/media/hikaku-denki-erabikata/)、取り合いで承認が付かないなら[半導体](/media/hikaku-handoutai-erabikata/)、完成車や親会社の隣に並ぶなら[自動車](/media/hikaku-jidosha-erabikata/)の記事が、業界が違っても近い考え方になります。

### メーカーの媒体選びは、御社に相談できますか

できます。当社は、区分の整理、一文の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分を支えられます。最終製品の一文の中身、研究の距離の一文、勤務地と配属の開示、名義の選定、面談、推薦の流れは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
