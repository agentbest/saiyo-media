大手食品メーカー、中堅、地方の食品メーカー、原料・素材、業務用、食品卸が、新卒を採る。食品は学生に最も身近な業界で、商品名で知られ、応募が集まる。ただし応募の多さは商品の人気で、採用の中心である営業（スーパー・卸・外食への営業、棚の交渉、販促）と生産（工場、交代制、衛生と品質）で残る学生の数ではない。学生は「食が好き」「商品開発をしたい」で来て、開発の枠の少なさと、営業と工場の実態で離れる。中堅・地方のメーカーは、商品名で知られていても会社名で知られていない。**結論から言うと、食品業界は応募の多さを成果と見ず、開発・営業・生産・研究の募集を分けて一行にします。開発の枠が少ないことと、営業と生産が採用の中心であることを隠さず、営業は「人を説得して置いてもらった・続けて信頼された」、生産は「決まりを守って場を回した」の記述で絞ります。大手は学生が並べて比べる場で職種ごとの選考情報と実態を、商品名で知られて会社名で知られない中堅・地方は「〇〇（商品名）を作っている会社」の一文で送る型か、工場と営業の一日を記事で読んでもらう型を先に検討します。** この記事では、食品業界の採用構造、判断軸の当て方、学生が確かめること、職種ごとの一行、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## 食品業界の採用構造と、媒体との相性

| 区分 | 採用の形 | 媒体との相性 |
|---|---|---|
| 大手食品メーカー | 商品名で知られ、応募が多い。営業・生産・研究・開発を職種別に | 比べられる場で職種ごとの選考情報と実態を。開発の枠の少なさをずらさない |
| 中堅、地方の食品メーカー | 商品名は知られ、会社名は知られていない。営業と生産が中心。地元で採る | 商品名でつなぐ一文で送る型。地元で絞る。工場と営業の一日の記事 |
| 原料・素材、業務用 | 学生に見えない。BtoB。研究・生産・法人営業 | 「〇〇（最終商品）の原料」の一文で。専攻で絞って送る型 |

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 身近で、応募が多い | 応募の多さで「採れている」と見て、営業と生産で残らない | 応募の数ではなく、職種ごとに残った数で見る |
| 「商品開発をしたい」で来る。開発の枠は少ない | 営業と生産の配属で離れる | 開発の枠の少なさと、営業・生産が中心であることを最初に |
| 営業は、スーパー・卸・外食への棚の交渉と販促 | 「食が好き」で来て、交渉と数字で離れる | 「人を説得して置いてもらった」の記述で絞る |
| 生産は、工場、交代制、衛生と品質 | 工場の勤務地と交代制を知らずに来て、離れる | 勤務地と交代制を最初に。「決まりを守って場を回した」で絞る |

## 判断軸を、食品業界に当てる

| 軸 | 食品業界での見方 |
|---|---|
| 対象（誰に届くか） | 「食が好き」「商品開発」の記述は多く、絞る条件にならない。営業は「人を説得して置いてもらった・続けて信頼された・数字を追った」、生産は「決まりを守って場を回した・人を動かした」、研究・開発は農学・栄養・化学の専攻と研究の内容で。地方のメーカーは地元で |
| 型（送るか、来るか、比べられるか） | 大手は「比べられる」型の中心。中堅・地方は「比べられる」型で大手と並ぶと候補に入りにくく、「送る」型で商品名の一文を先に渡すか、「来る」型で工場と営業の一日を読んでもらう |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 営業の若手は訪問と販促で外に、工場の若手は交代制で動けない。名義と面談の枠を職種ごとに固定する。送る型は作業を外に出せる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。食品では、応募が多いので「対象」の軸で「絞る」ことが他の業界より大事なことと、開発の枠の少なさを最初に書くことが、他の業界と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「食品は人気で応募が多いから、採用は困っていない」というものです。当社は3媒体すべての販売パートナーとして、食品メーカーの相談を受けますが、応募が多いのは商品が知られているからで、その学生の多くは「商品開発をしたい」「食が好き」で来ていて、営業と生産の配属で離れます。応募の数を見て「採れている」と考え、面談と内定の後に残った数を見ていない会社が多くあります。営業で残るのは「人を説得して置いてもらった・続けて信頼された」経験のある学生で、生産で残るのは「決まりを守って場を回した」経験のある学生で、「食が好き」の学生ではありません。当社が食品の会社に勧めているのは、応募の数を成果と見ずに、開発の枠が少ないことと営業と生産が中心であることを文面の最初に書き、職種ごとの記述で絞り、職種ごとに残った数で見ることです。応募は減りますが、営業と生産で残る学生は増えます。

## 学生が、確かめること

- **商品開発に行けるか**：開発の枠、開発に行く人の割合と道筋、研究と開発の違い
- **営業の実態**：誰に売るか（スーパー、卸、外食）、棚の交渉、販促、土日の店頭、転勤
- **生産の実態**：工場の場所、交代制、衛生の決まり、若手が任される範囲
- **配属の決まり方**：営業か生産か、いつ、どう決まるか。希望が通るか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 大手食品メーカーで、商品名で知られ、職種ごとにクチコミと選考情報が付いている | 学生が並べて比べる場（ワンキャリア）で職種ごとの選考情報と実態を | 比べる対象の中心。開発の枠と営業・生産の実態とクチコミをずらさない |
| 大手で、研究・開発を専攻と研究の内容で、営業の層とは別に採りたい | 企業から送る型（OfferBox） | 農学・栄養・化学の専攻と研究の記述で絞り、別の文面で別に届く。[OfferBoxで研究職を採るオファー文面の書き方](/media/ob-kenkyu-offer-bunmen/) |
| 中堅・地方のメーカーで、商品名でつなぐ一文で営業と生産を採りたい | 企業から送る型（OfferBox） | 「〇〇を作っている会社」の一文で開かれ、記述で絞れる。地元で絞れる。作業を外に出せる |
| 営業や工場の若手が、棚の交渉の一日と工場の一日を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「商品開発」の想像に、営業と生産の一日を先に読んでもらえる |
| 開発・営業・生産の一行が、まだない | どれも先ではない | 一行を分けてから。「食が好きな方へ」では応募だけが増える |

どれか一つが正解ではなく、大手か中堅・地方か、職種、商品名で知られているかで、先に検討するものが変わります。

## 組み合わせ

- **大手は、比べられる場と送る型を組み合わせる**：比べられる場で営業と生産の受け皿を、送る型で研究・開発の専攻を。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **中堅・地方は、送る型と記事を置く型を組み合わせる**：文面で「〇〇を作っている会社で、あなたの△△を読んで」を、記事で「棚に置いてもらった日」と「工場の一日」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **農学・栄養・化学の学部・研究室との関係と組み合わせる**：研究・開発・品質は学科の流れが主。学校で会った学生に媒体で送らない。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)

## 見せ方｜「食が好き」ではなく、開発の枠と、営業と生産の実態

- **開発・営業・生産・研究のどれかを、最初の一文で**：「この募集は営業で、スーパーと卸に〇〇を置いてもらう交渉と販促が仕事です」
- **開発の枠の少なさを、隠さず**：「商品開発は〇〇の割合で、多くは営業と生産から始まります」。数値は実態で。この記事では書かない
- **棚に置いてもらった日の場面を、一つ**：「〇〇のバイヤーに△△を提案して、□□の棚に並んだ日」。営業の若手の名義で。「食が好き」を売る側から
- **工場の一日の場面を、一つ**：「〇〇のラインで、△△が起きて、こう止めて、こう戻した」。工場の若手の名義で。交代制と衛生を隠さず
- **商品名でつなぐ一文を、中堅・地方は最初に**：「〇〇（商品名）を作っている会社です」。会社名で知られていないことを前提に

## 社内の分担

| 作業 | 誰が |
|---|---|
| 開発・営業・生産・研究の一行と、開発の枠・営業と生産の実態・配属の一枚 | 経営と人事、各部門の責任者 |
| 大手か中堅・地方か、職種で、先に検討する型を決める | 人事と責任者 |
| 「こんな人」（説得して置いてもらった・決まりを守って場を回した・研究の内容）の整理 | 人事と各部門の責任者 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、営業と工場の若手が一日を話し、整えるのは人事か外に | 若手と人事 |
| 個別の一文、文面の最終確認、名義、面談 | 各職種の若手 |
| 面談枠を職種ごとに固定する | 人事と各部門の責任者 |

- **営業と工場の若手に頼むのは、名義・一文・面談の三つ**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)

運用代行や代理店が支えられるのは、職種ごとの一行の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分、応募から内定後までの数の整理までで、一行の中身、開発の枠と営業・生産の実態の開示、名義の選定、面談、学科との関係は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

送り始めたあと、最初の年で起きることに共通するのは、「食で人を笑顔に」「商品開発」で応募や承認が付き、面談か入社後に営業の配属、棚の交渉と数字、工場の交代制を知って離れることです。当社はOfferBoxの運用代行を受けているので、食品メーカーの承認から面談までを見ていますが、開発の枠の少なさと営業・生産が中心であることを文面に書かず、「商品開発に関われる」で書いている会社が多く、その言葉で来た学生は、最初の配属が営業か工場であることを面談で初めて知ります。当社が食品の会社に勧めているのは、最初の一文に「商品開発は〇〇の割合で、多くは営業と生産から。営業はスーパーと卸に置いてもらう交渉」と置き、そのうえで「棚に並んだ日」「ラインを止めて戻した日」の場面を若手の名義で書くことです。書いて来た学生は、開発の枠と営業・生産の実態を知ったうえで来ていて、最初の配属で辞めません。

## まとめ

- 食品業界は、学生に最も身近で応募が多いが、応募の多さは商品の人気で、営業と生産で残る学生の数ではない。応募の数を成果と見ず、職種ごとに残った数で見る
- 開発・営業・生産・研究の募集を分けて一行にし、開発の枠の少なさと、営業と生産が中心であることを最初に隠さず。「食が好き」「商品開発」は絞る条件にならない
- 営業は「人を説得して置いてもらった・続けて信頼された」、生産は「決まりを守って場を回した」、研究・開発は農学・栄養・化学の専攻と研究の内容で絞る
- 大手は並べて比べる場で職種ごとの選考情報と実態を、送る型は研究・開発の専攻に。商品名で知られて会社名で知られない中堅・地方は「〇〇を作っている会社」の一文で送る型か、棚と工場の一日を記事で読んでもらう型を先に
- 営業と工場の若手に頼むのは名義・一文・面談で、枠は職種ごとに固定。学科との関係と組み合わせる

## よくある質問

### 応募は多いです。媒体を変える必要がありますか

媒体より先に、応募の後の数を見ることを勧めます。応募の多さは商品の人気で、「商品開発をしたい」学生が営業と生産の配属で離れているなら、応募の数は成果ではありません。開発の枠の少なさと営業・生産が中心であることを文面の最初に書き、職種ごとの記述で絞ると、応募は減り、営業と生産で残る学生は増えます。媒体を変えるかは、その後に決めます。

### 商品名は知られていますが、会社名は知られていません

商品名を前に出します。「〇〇（商品名）を作っている会社です」を最初の一文に置くと、会社名を知らない学生に開かれます。そのうえで、営業なら「置いてもらう交渉」、生産なら「工場と交代制」の実態を書き、記述で絞ります。会社名の知名度は、商品名でつなげば、絞る条件に影響しません。

### 食品業界の媒体選びは、御社に相談できますか

できます。当社は、職種ごとの一行の型、一枚の型、文面と記事の型、送る型の作業、記事を整える部分、応募から内定後までの数の整理を支えられます。一行の中身、開発の枠と営業・生産の実態の開示、名義の選定、面談、学科との関係は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
