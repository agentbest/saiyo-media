いまの媒体から、別の媒体に切り替えるべきか。数が出ない、担当が変わった、他社が使っていると聞いた。ところが、数が出ないから切り替え、原因を切り分けずに媒体のせいにし、年度の途中で急に切り替えて進行中の学生を放置し、切り替えで一枚も型も台帳も捨て、毎年切り替えて何も残らない。**結論から言うと、切り替えは「効かないから別の媒体へ」ではなく、「いまの媒体で直せる段がなくなり、役割が違う入口が要ると分かったとき」に、契約の切れ目で行います。切り替えの前に「小さくする」と「並行して試す」があり、切り替えても一枚・型・台帳・接点は持ち越します。年度の途中で急に切り替えません。** この記事では、切り替えで起きる失敗、前に確かめる四つ、判断の軸、三つの形、時期、持ち越すもの、切り替え先の選び方、進行中の学生、記録、分担を整理します。やめる判断は[媒体をやめる判断基準](/media/hikaku-baitai-tettai/)、代理店の切り替えは[代理店を切り替えるときの手順](/media/kh-dairiten-kirikae/)、媒体ごとの撤退の判断は[OfferBoxで成果が出ないときに撤退を判断する基準](/media/ob-seika-detanai/)で書きました。

## この作業の目的｜「媒体のせい」にせず、切り替えるべきかを記録で決める

数が出ないとき、最も簡単な結論は「媒体が合わない」です。ところが、数が出ない原因の多くは、媒体ではなく、「こんな人」が曖昧、送る相手が広い、返信が遅い、面談の枠がない、のどれかで、切り替えても同じ原因が次の媒体でも起きます。

目的は、切り替えを「感覚」ではなく「記録」で決め、切り替えるなら、原因を持ち越さず、基盤は持ち越すことです。

## 切り替えで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 数が出ないから、切り替える | 原因が社内にあれば、次の媒体でも同じ |
| 原因を切り分けずに、媒体のせいにする | 直せる段があるのに直さず、切り替えで時間と費用を使う |
| 年度の途中で、急に切り替える | 契約の途中で費用が残り、進行中の学生が放置され、翌年に読まれる |
| 切り替えで、一枚と型と台帳を捨てる | 次の媒体で一から。基盤が積まれない |
| 切り替え先を、同じ役割で選ぶ | スカウト型からスカウト型へ。同じ原因で同じ結果 |
| 毎年、切り替える | どの媒体も一年で終わり、二年目から効くものが一つもない |

共通するのは、切り替えを「原因を直す代わり」に使っていることです。切り替えは、原因を直した後の選択肢です。

## 切り替えの前に、確かめる四つ

1. **「こんな人」に近い人が、面談まで来ているか**：来ていれば、媒体は届いている。直すのは面談以降で、切り替えの理由にならない
2. **細い段を直して、その段の数が動いたか**：動いていれば、運用で直せる。動かなければ、次の直しか、切り替えの候補
3. **翌年に残ったものがあるか**：一枚・型・台帳・企業ページ・現場の分担・接点。残っていれば、続ける理由
4. **担当の時間に見合うか**：近い人の面談数あたりの時間を、他の入口と比べる

四つとも「いいえ」なら切り替えの候補、一つか二つなら「小さくする」か「配分を変える」です。軸の詳しくは[OfferBoxで成果が出ないときに撤退を判断する基準](/media/ob-seika-detanai/)の「判断の軸」で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「一年使って数が出なかったから、媒体が合わなかった」というものです。当社は3媒体すべての販売パートナーで、切り替えの相談を受けるとき、どの媒体からどの媒体へでも当社の扱いですが、切り替えを勧めない場合が多い。一年使って数が出なかった会社の記録を見ると、「こんな人」が面接官と合意されていない、送る相手が広い、返信が翌日を超えている、面談の枠が週に一つもない、のどれかが残っていて、切り替え先でも同じことが起きます。逆に、四つを直して、それでも「役割が違う入口が要る」と分かった会社の切り替えは、切り替え先で最初から回っています。当社が切り替えの相談を受けるとき、最初にやるのは、「どの段が細いか」と「その段を直したか」を記録で確かめることで、切り替え先の説明はその後です。

## 切り替えの、判断の軸

| 軸 | 切り替えの理由になる | 切り替えの理由にならない |
|---|---|---|
| 届いているか | 「こんな人」に、その媒体では届かない（いない、探せない）と記録で分かった | 届いているが、面談以降で細い |
| 直せる段が残っているか | 直せる段を直し尽くし、動かない | 直していない段がある |
| 役割 | いまの媒体と役割が違う入口が要ると分かった | 同じ役割の別の媒体に「変えてみる」 |
| 時間の形 | 自社の時間の形と、媒体の時間の使い方の形が合わない（毎週の時間が取れないのに毎週コツコツの形、など） | 時間が取れないこと自体（どの媒体でも取れない） |
| 体制の変化 | 担当が変わり、時間の形が変わった。現場が出られるようになった、または出られなくなった | 担当が変わっただけ（型と台帳があれば引き継げる） |

「理由になる」の側が揃ったときに、切り替えます。時間の形の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」で書きました。

## 切り替えの、三つの形

| 形 | 選ぶ条件 | 何をするか |
|---|---|---|
| 小さくする | 届いているが、時間に見合わない。担当の時間が取れない | 型と台帳を保ち、送る数と時期を絞る。切り替えない。[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/) |
| 並行して試す | 役割が違う入口が要る。いまの媒体を続ける理由もある | いまの媒体を減らさずに、切り替え先を「試す」大きさで。年度の切れ目に判断。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/) |
| 切り替える | 四つの軸が揃い、いまの媒体を続ける理由がない | 契約の切れ目で。一枚・型・台帳・接点を持ち越す |

「切り替える」の前に、二つの形があります。多くの場合、「並行して試す」で足り、試した結果で「切り替える」か「二本で持つ」かが決まります。

## 時期は、契約の切れ目

- **年度の途中で、急に切り替えない**：契約の途中で費用が残り、進行中の学生が放置される
- **契約の更新時期を、先に把握する**：更新の条件は見積もりと契約で確認
- **切り替え先の契約の開始を、いまの媒体の切れ目に合わせる**：空白の期間を作らない
- **並行して試す期間を、切れ目の前に置く**：試した結果で、更新するか切り替えるかを決める
- **時期の選び方は[代理店を切り替えるときの手順](/media/kh-dairiten-kirikae/)の「時期を選ぶ」**

## 切り替えても、持ち越すもの

| 持ち越すもの | 次の媒体でどう使うか |
|---|---|
| 「こんな人」の一枚 | 次の媒体の検索条件と文面の元。媒体が変わっても一枚は同じ |
| 文面の型 | 四段の型は媒体をまたぐ。変えるのは「相手のどこを読むか」と「締めで誘う場」。[スカウト文面の基本](/media/kh-bunmen-kihon/) |
| 台帳と率 | 入口を変えても、段ごとの率は逆算の元 |
| 企業ページの材料 | 媒体ごとに書き直すが、事実は同じ |
| 接点 | いまの媒体で会った人との関係は、媒体を離れても続く |
| 止まった場面の記録 | 次の媒体で同じ場面で止まらない |

持ち越さないと、切り替えは「一から」になります。持ち越し方は[代理店を切り替えるときの手順](/media/kh-dairiten-kirikae/)の「運用データを引き継ぐ」で書きました。

## 切り替え先の、選び方

- **役割が違うものを**：届けるから読む場所へ、読む場所から届けるへ。同じ役割なら、「相手が違う」場合だけ
- **自社の時間の形に合うものを**：毎週コツコツ・通年で育てる・最初に集中
- **持ち越すものが、最も使えるものを**：一枚と型がそのまま使える媒体
- **3媒体の中での選び方は[3媒体の違いと選び方](/media/hikaku-3baitai/)の「この条件なら、どれを先に検討するか」**
- **代理店経由でも料金は変わらない**：切り替えの費用の面は見積もりと契約で確認。[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)

## 進行中の学生の、扱い

- **切り替えの時点で進行中の学生は、選考を続ける**：媒体の契約が終わっても、学生との関係は終わらない
- **連絡の手段を、媒体の外に移しておく**：媒体の管理画面が使えなくなる時期は、現在の仕様で確認
- **切り替えを、学生に説明しない**：学生には関係がない。連絡が途切れないことだけ
- **内定者は、内定者の場で**：媒体と関係なく続く

## 記録

- **切り替えの理由を、四つの軸で記録する**：翌年、同じ判断を繰り返さないため
- **切り替え前の媒体の、効いたもの・効かなかったものを残す**：戻すとき、または別の媒体で使うとき
- **切り替え先で、最初の月に見るものを決めておく**：切り替え前と同じ段で比べる
- **記録の型は[OfferBoxで成果が出ないときに撤退を判断する基準](/media/ob-seika-detanai/)の「撤退の理由を、記録する」**

### エージェントベストの見解

これは順番の話です。切り替えの相談で、「来年から別の媒体にしたいので、今年の残りは最低限で」と言われることがあります。当社がお願いする順番は、今年の残りを「小さくする」形で回し続け（返信は当日、進行中の学生は続ける、台帳は付ける）、契約の切れ目の前に切り替え先を「試す」大きさで並行し、切れ目で判断する、です。今年の残りを止めると、進行中の学生が放置され、今年の記録が途切れ、切り替え先で比べる元がなくなります。当社は3媒体を扱うので、どの媒体からどの媒体へでも支えられますが、切り替えの前に、今年の媒体を「止めずに小さくする」ことを、先にお願いします。

## まとめ

- 切り替えは「効かないから別の媒体へ」ではなく、「直せる段がなくなり、役割が違う入口が要ると分かったとき」に、契約の切れ目で
- 前に確かめるのは四つ：近い人が面談まで来ているか、細い段を直して動いたか、翌年に残ったものがあるか、時間に見合うか。原因が社内にあれば、切り替えても同じ
- 判断の軸は、届いているか・直せる段が残っているか・役割・時間の形・体制の変化。同じ役割の別の媒体に「変えてみる」は理由にならない
- 三つの形は、小さくする→並行して試す→切り替える。多くは「並行して試す」で足りる
- 切り替えても一枚・型・台帳・企業ページの材料・接点・止まった場面の記録は持ち越す。進行中の学生の選考は続け、理由を記録する。年度の途中で急に切り替えない

## よくある質問

### 担当が変わり、新しい担当が「別の媒体のほうが慣れている」と言います

担当の慣れは、切り替えの理由になることもあります（時間の形が変わった、体制の変化）が、一枚と型と台帳があれば、慣れていない媒体も引き継げます。先に、前の担当の一枚・型・台帳・止まった場面の記録を新しい担当に渡し、一か月回してから判断します。慣れだけで切り替えると、前の担当が残した基盤が消えます。引き継ぎは[OfferBoxの担当が交代するときの引き継ぎ](/media/ob-tantousha-koutai/)で書きました。

### 上司から「他社が使っている媒体に変えろ」と言われました

他社が使っている理由は、他社の「こんな人」と時間の形と体制で決まっていて、自社に当てはまるとは限りません。上司に、四つの確認と判断の軸を見せ、「いまの媒体で直せる段が残っているか」「役割が違う入口が要るか」で答えます。それでも切り替えるなら、「並行して試す」形で、いまの媒体を減らさずに試し、年度の切れ目に記録で判断する、と提案します。伝え方は[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)で書きました。

### 媒体の切り替えの判断は、御社に相談できますか

できます。当社は、四つの確認の型、判断の軸の整理、三つの形の整理、持ち越しの型、契約の切れ目と切り替え先の契約の窓口、記録の型を支えられます。切り替えの判断、進行中の学生の対応、一枚と型の持ち越しは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支え、どの媒体からどの媒体への切り替えも扱います。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
