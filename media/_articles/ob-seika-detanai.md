OfferBoxで、成果が出ない。承諾が少ない、あるいはゼロ。契約の更新が近づき、続けるか撤退するかを決めなければならない。「効かないなら、やめよう」と急ぎたくなります。**結論から言うと、撤退の判断は、「測れていない」を「出ていない」と混同しないことから始めます。判断の前に、台帳・段ごとの数・「こんな人」・直しの記録の四つを揃え、止まりの段を直したうえで、「こんな人に近い学生が面談まで来たか」で判断します。選択肢は「続ける・配分を変える・小さくする・撤退」の四つで、撤退の時期は契約の切れ目です。撤退しても、型と台帳と「こんな人」は残し、撤退の理由を記録します。** この記事では、急ぐと起きること、判断の前に揃える四つ、判断の軸、四つの選択肢、時期、残すもの、理由の記録、分担を整理します。「測れていない」の直し方は[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)、契約更新の判断は[OfferBoxを2年目以降に使うときの見直し点](/media/ob-repeat-unyou/)の手順6で書きました。

## この作業の目的｜撤退を、「記録で判断できる」形にする

撤退は、間違った判断ではありません。合わない経路を続けるより、やめて別の経路に時間を使うほうが良いこともあります。問題は、「測れていない」状態で撤退すると、効いていたかどうかが最後まで分からず、翌年に別の経路でも同じ「測れていない」が起きることです。

目的は、撤退するにしても続けるにしても、記録で判断し、その判断の理由が翌年に残る形にすることです。

## 撤退の判断を急ぐと、起きること

| 急ぐと起きること | 何が起きるか |
|---|---|
| 「測れていない」を「出ていない」と混同する | 台帳がなく、段が分かれておらず、「こんな人」がないまま、「効かない」と判断する |
| 初年度で判断する | 型と台帳と企業ページを作った年の承諾数で判断し、翌年の元を捨てる |
| 承諾の数だけで判断する | 「こんな人」に近い学生が面談まで来ていたのに、承諾がゼロで「効かない」 |
| 止まりの段を直さずに判断する | 承認は来ていて面談に進まなかったなら、直すのは面談の枠で、撤退ではない |
| 他社の数字と比べて判断する | 他社の率は他社の運用の結果で、自社の判断に使えない |
| 「担当が忙しかった」を理由にしない | 運用が回っていなかった年の結果は、OfferBoxの結果ではない |

共通するのは、「OfferBoxが効かない」と「自社の運用が回っていない」を分けていないことです。

## 判断の前に、揃える四つ

| 揃えるもの | なければ |
|---|---|
| 1. 台帳 | 誰に送って、誰が承認して、誰が面談に来たかが分からない。判断できない |
| 2. 段ごとの数 | どこで止まっているかが分からない。「効かない」が「どの段か」に変わらない |
| 3. 「こんな人」 | 承認した学生が「合う学生」かが分からない。数だけになる |
| 4. 直しの記録 | 止まりの段を直したかどうかが分からない。直していなければ、判断は早い |

四つのどれかがなければ、「測れていない」で、判断の前に揃えます。揃え方は[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)で書きました。揃えて一か月か二か月見てから、判断します。

### エージェントベストの見解

相談で最も多い思い込みは、「代理店は続けてほしいので、撤退を勧めない」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、四つが揃っていて、止まりの段を直して、なお「こんな人」に近い学生が面談まで来ない会社には、当社は撤退か、別の媒体への切り替えを勧めています。合わない経路を続けても、企業にも当社にも残りません。当社が撤退を勧めないのは、四つが揃っていない、つまり「測れていない」状態のときです。この状態で撤退すると、効いていたかもしれない経路を、分からないまま捨てることになり、翌年に別の経路でも同じことが起きます。当社が撤退の相談を受けるとき、最初にやるのは、続けるよう説得することではなく、四つが揃っているかを確かめることです。

## 判断の軸

| 軸 | 見ること | 判断 |
|---|---|---|
| 1. 「こんな人」に近い学生が、面談まで来たか | 面談した学生のうち、近い学生の数 | 来ていれば「届いている」。承諾がなくても、直すのは面談以降 |
| 2. 直しの前後で、段の数が変わったか | 止まりの段を直して、その段の数が動いたか | 動いていれば、運用で直せる。動かなければ、次の直しか、撤退の候補 |
| 3. 翌年に残ったものがあるか | 型・台帳・「こんな人」・企業ページ・現場の協力 | 初年度なら、これが成果。残っていれば続ける理由 |
| 4. 担当の時間に見合うか | 週の枠と回数で、面談まで来た近い学生の数 | 他の経路と「時間あたり」で比べる |

四つの軸で、「届いていない」「直しても動かない」「残っていない」「時間に見合わない」が揃ったときに、撤退を選びます。一つか二つなら、「配分を変える」か「小さくする」です。数字の読み方は[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)で書きました。

## 四つの選択肢

| 選択肢 | 選ぶ条件 | 何をするか |
|---|---|---|
| 続ける | 近い学生が面談まで来ている。直しで段が動いている | 同じ配分で。止まりの段を直し続ける |
| 配分を変える | 届いているが、時間に見合わない。特定の職種だけ届いている | 職種を絞る。送る数を減らす。他の経路と役割を分け直す |
| 小さくする | 届いているが、担当の時間が取れない | 月に数通、承認には当日返す。型と台帳を保つ。[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/) |
| 撤退 | 四つの軸が揃って「届いていない」。直しても動かない | 契約の切れ目で。型・台帳・「こんな人」を残し、理由を記録する |

「撤退」の前に、「小さくする」があります。小さくすれば、費用と時間を抑えたまま、記録が続きます。撤退すると、記録が止まります。

## 撤退の時期は、契約の切れ目

- **途中で止めない**：進行中の学生を放置することになる。[OfferBoxの運用が止まってしまったときの再開手順](/media/ob-unyou-teitai/)
- **契約の期間と更新時期を、先に把握する**：更新の判断の期限から逆算して、四つを揃える時期を決める
- **切れ目までに、進行中の学生の選考を進めるか、期間後の連絡手段を決める**
- **内定者のフォローは、撤退と関係なく続ける**
- **契約の形と期間は、媒体の現在の仕様と契約で確認する**：この記事では扱わない

契約の切れ目の扱いは[OfferBoxを2年目以降に使うときの見直し点](/media/ob-repeat-unyou/)の手順6、代理店を通した契約の確認は[代理店の契約で確認すること](/media/kh-dairiten-keiyaku/)で書きました。

## 撤退しても、残すもの

- **型**：別の媒体でも、「学生の一文・現場の一文・何を見るか・話す場」の構造は使える
- **台帳**：段ごとの数と日数。別の媒体の段と比べる元
- **「こんな人」の一枚**：媒体に関係なく、採用の物差し
- **企業ページの内容**：「文面の続き」として整えた文章は、別の媒体の会社ページに写せる
- **現場の協力**：面談に出た若手一人。別の媒体でも出てもらえる
- **承認した学生の反応**：「なぜ承認したか」は、別の媒体の文面にも使える

撤退は、OfferBoxをやめることで、採用の運用をやめることではありません。残したものを、次の経路に持っていきます。

## 撤退の理由を、記録する

- **四つの軸で、どれが揃ったか**：「近い学生が来なかった」「直しても動かなかった」「時間に見合わなかった」
- **直したことと、その前後の段の数**：何を試して、どうだったか
- **「こんな人」と、OfferBoxで会えた学生の違い**：「こんな人」がその媒体にいなかったのか、届け方の問題だったのか
- **翌年、別の経路で同じことが起きたときに読み返せる形で**
- **「効かなかった」ではなく、「〇〇の段で、△△を直しても動かなかった」と書く**

理由の記録がないと、翌年に「なぜやめたのか」が分からず、同じ経路をもう一度試すか、同じ理由で別の経路をやめることになります。

### エージェントベストの見解

これは切り分けの話です。当社が撤退の相談を受けるとき、「OfferBoxが合わない」と「いまの運用が合わない」を分けます。前者は、四つが揃っていて、直しても「こんな人」に近い学生が来ない場合で、「こんな人」がその媒体にいないか、届け方では埋まらない差がある場合です。この場合、当社は撤退か切り替えを勧めます。後者は、四つのどれかが欠けているか、止まりの段を直していない場合で、この場合、直せば動くことが多く、撤退の前に直します。相談の多くは後者で、「承諾がゼロだから撤退」の裏に、承認は来ていて面談に進んでいなかった、という止まりがあります。それは撤退の理由ではなく、面談の枠の問題です。分けてから、判断してもらいます。

## まとめ

- 撤退の判断は、「測れていない」を「出ていない」と混同しないことから。台帳・段ごとの数・「こんな人」・直しの記録の四つを揃え、止まりの段を直してから判断する
- 判断の軸は、近い学生が面談まで来たか・直しの前後で段が動いたか・翌年に残ったものがあるか・担当の時間に見合うか。四つが揃って「届いていない」なら撤退
- 選択肢は続ける・配分を変える・小さくする・撤退の四つ。撤退の前に「小さくする」があり、記録を止めずに済む
- 撤退の時期は契約の切れ目。途中で止めず、進行中の学生と内定者への対応を続ける。契約の形と期間は媒体の仕様と契約で確認
- 撤退しても型・台帳・「こんな人」・企業ページの内容・現場の協力・学生の反応を残し、理由を「どの段で何を直して動かなかったか」で記録する

## よくある質問

### 上司が「一年やって承諾ゼロなら撤退」と決めています

承諾ゼロの中身を、段ごとに見せます。承認が来ていて面談に進んでいなかったなら、直すのは面談の枠で、撤退の理由ではありません。「こんな人」に近い学生が面談まで来ていたなら、届いていて、直すのは選考以降です。初年度なら、翌年に残ったものを示します。「承諾ゼロ」を「どの段で止まったか」に変えて、判断の材料にします。判断は上司ですが、材料は人事が出します。

### 撤退したあと、別の媒体に切り替えるときの注意は

残したもの（型・台帳・「こんな人」・企業ページの内容・現場の協力）を持っていきます。切り替え先で、同じ四つ（台帳・段・「こんな人」・直しの記録）を最初から揃えます。撤退の理由の記録を読み返し、「こんな人」がその媒体にいなかったのか、届け方の問題だったのかを、切り替え先の選び方に使います。切り替えの手順は[代理店を切り替えるときの注意](/media/kh-dairiten-kirikae/)で書きました。

### 撤退の判断は、御社に相談できますか

できます。当社は、四つの揃え方、判断の軸の型、選択肢の整理、契約の切れ目と更新時期の確認、残すものの整理、別の媒体への切り替えの案を支えられます。判断そのもの、進行中の学生への対応、理由の記録は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
