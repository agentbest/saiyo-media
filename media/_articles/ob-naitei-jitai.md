OfferBoxのオファー経由で内定を出したのに、辞退が続く。多くの会社が、内定後のフォローを厚くしようとします。ところが、辞退の原因が内定後にあるとは限りません。**結論から言うと、オファー経由の内定辞退は、理由を「オファーの時点で合わない相手に送っていた」「選考中に印象が下がった」「内定後の間に連絡が途絶えた」「他社と比べて条件や仕事の具体で負けた」の四つに分け、辞退した学生の共通点をオファーの時点まで戻って見ます。内定後のフォローだけを厚くしても、原因がオファーの時点や選考中にあれば直りません。辞退の理由は聞ける範囲で聞き、事実と推測を分けて残し、内定者の話を次のオファーに活かします。** この記事では、四つの理由とサインと直す場所、内定後だけを厚くしても直らない理由、理由の集め方、オファーの時点まで戻って見ること、内定者の話の活かし方、承諾までの間の設計、分担を整理します。内定後のフォローの基本は[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)、内定者の活かし方は[OfferBoxの内定者の活用](/media/ob-naiteisha-katsuyou/)で書きました。

## この作業の目的｜辞退の原因がある場所を見つけて、そこを直す

内定辞退は、採用の最後の段で起きるので、最後の段（内定後のフォロー）を直したくなります。ところが、オファー経由の学生の辞退は、最初の段（オファーの時点）に原因があることが多くあります。

目的は、辞退の原因がどの段にあるかを見つけ、そこを直すことです。内定後のフォローを厚くすることが目的ではありません。

## 内定辞退の、四つの理由

| 理由 | 何が起きているか | 直す場所 |
|---|---|---|
| 1. オファーの時点で、合わない相手に送っていた | 「こんな人」とずれた学生が、承認し、選考に進み、内定まで来た。最初から合っていなかった | 検索条件と送る相手。[OfferBoxの承認率が低いときに疑う3つの原因](/media/ob-shounin-hikui/) |
| 2. 選考中に、印象が下がった | オファーと面談の印象を、選考が引き継がなかった。「オファーは営業用だった」 | 選考の各段階。[OfferBox経由の学生が選考途中で離脱する理由](/media/ob-senkou-ridatsu/) |
| 3. 内定後の間に、連絡が途絶えた | 内定を出したあと、承諾までの間に会社からの接点が無く、他社に向いた | 内定後のフォロー。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/) |
| 4. 他社と比べて、条件や仕事の具体で負けた | 学生が最後に比べたとき、自社の条件が見劣りしたか、仕事の具体が他社より薄かった | 条件の書き方と、仕事の具体。オファーの時点から |

「1」と「4」は、内定後のフォローでは直りません。オファーの時点と、企業ページと、文面の話です。

## 内定後のフォローだけを厚くしても、直らない理由

- **合わない相手に内定を出していれば、フォローで合うようにはならない**：辞退が正しい結果
- **選考中に下がった印象は、内定後に戻りにくい**：「選考では違う会社だった」の記憶が残る
- **条件や仕事の具体で負けているなら、フォローの回数では埋まらない**：比べる材料が変わらない
- **フォローを厚くすると、「押されている」と感じる学生もいる**：内定後の連絡は、回数より中身
- **内定後のフォローが効くのは、原因が「3」の場合だけ**：連絡が途絶えたことが原因なら、フォローで直る

「四つのうち、どれか」を見ずにフォローを厚くすると、原因が「1」「2」「4」の場合は変わらず、「押されている」と感じる学生が増えます。

### エージェントベストの見解

相談で最も多い思い込みは、「内定辞退は内定後の問題なので、内定者フォローを見直せば減る」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、辞退した学生の記録を、オファーを送った時点まで戻って並べると、承認した時点で「こんな人」と合っていなかった学生、選考の一次で印象が下がったが最終まで来た学生、が混ざっています。この学生の辞退は、内定後のフォローで防げるものではなく、オファーの時点で送らないか、選考中に印象を保つかで防ぐものです。当社が内定辞退の相談を受けるとき、最初にやるのは、辞退した学生の一覧を、オファーの検索条件と、送った文面と、面談の記録と、各段階の記録と一緒に並べることです。内定後だけを見ると、原因の半分が見えません。

## 理由ごとの、見えるサイン

### 1. オファーの時点で、合わない相手だった

- **辞退した学生の共通点が、検索条件にある**：大学名だけで絞った、プロフィールが薄い、希望が大きく違う
- **承認率は高いが、面談で「合わない」と感じることが多い**
- **辞退の理由が「思っていた仕事と違った」**：オファーの時点で仕事の具体を伝えていない
- **面談で「なぜ承認したか」を聞くと、「とりあえず」だった**

直すのは、検索条件と、文面の「最初の1年」の具体と、送る相手を読める数に絞ることです。[OfferBoxのターゲット設計](/media/ob-target-sekkei/)

### 2. 選考中に、印象が下がった

- **辞退の理由が「面接で雰囲気が違った」「オファーと違う会社に見えた」**
- **面談は良かったのに、一次以降で反応が薄くなった**
- **面接官がオファーと面談の記録を読んでいない**
- **段階が多く、間が空いた**

直すのは、面接官への記録の引き継ぎと、選考の段階と間隔です。

### 3. 内定後の間に、連絡が途絶えた

- **内定を出してから承諾までの間に、会社からの接点が無い**
- **辞退の理由が「他社から連絡があって」「迷っているうちに」**
- **内定後に、話す相手（面談で話した人、内定者）を用意していない**
- **内定の連絡が、条件の通知だけで終わっている**

直すのは、内定後の間の設計です。読むものと話す相手を、承諾までの間に置きます。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)

### 4. 他社と比べて、負けた

- **辞退の理由が「条件が」「他社のほうが仕事が具体的だった」**
- **条件が企業ページに書かれておらず、内定の時点で初めて出た**
- **仕事の最初の1年が、他社より薄い**
- **話す相手が人事だけで、現場の人の話を聞いていない**

直すのは、条件をオファーの時点で企業ページに書くことと、「最初の1年」の具体を厚くすることです。条件で負ける分は、仕事の具体で見せます。[OfferBoxの企業ページの書き方](/media/ob-kigyo-page/)

## 辞退の理由を、聞いて残す

- **聞ける範囲で聞く**：「今後の参考に、差し支えなければ」。内定を出したあとなので、聞きやすい
- **事実と推測を分けて記録する**：「他社に決めた（事実）。自社の一次で印象が下がった様子（推測）」
- **四つのどれかに分類して、月に一度まとめて見る**：同じ理由が続けば、そこを直す
- **面談・面接に出た人にも、「引っかかった様子があったか」を聞く**

内定辞退の理由は、他の段の辞退より聞きやすい段です。聞かずに終わると、四つのどれかが分かりません。

## 辞退した学生の共通点を、オファーの時点まで戻って見る

| 見る場所 | 見ること |
|---|---|
| 検索条件 | 辞退した学生が、どの条件で拾われたか。「こんな人」と合っていたか |
| 送った文面 | 学生の一文と最初の1年の場面があったか。テンプレだったか |
| 承認の理由（面談で聞いた） | 「とりあえず」か、「この仕事の話を聞きたくて」か |
| 面談の記録 | 面談で何を話し、学生が何に反応したか |
| 各段階の記録 | どの段階で反応が変わったか |
| 内定後の接点 | 内定から承諾の期限までに、何回、誰と接点があったか |
| 辞退の理由 | 事実と推測 |

「辞退した学生」と「承諾した学生」の両方を、この表で並べると、違いが見えます。違いがある段が、直す段です。

## 内定者の話を、次のオファーに活かす

承諾した学生の話は、次のオファーの材料になります。

- **「なぜ承諾したか」を聞く**：「オファーの〇〇が」「面談で△△の話が」「内定後に□□と話せて」
- **承諾の理由を、オファーの文面と企業ページに反映する**：承諾した学生が反応した「最初の1年」の場面を、次の文面に
- **内定者に、次の年の面談や内定後の話す相手になってもらう**：本人の同意のうえで。[OfferBoxの内定者の活用](/media/ob-naiteisha-katsuyou/)
- **辞退した学生の理由と、承諾した学生の理由を並べる**：何が分かれ目だったか

「承諾の理由」は、「辞退の理由」と同じくらい、次のオファーに効きます。

## 承諾までの間に、置くもの

原因が「3」の場合、または「3」を防ぐために、内定後の間を設計します。

- **内定の連絡は、条件の通知だけで終えない**：「面談で話した〇〇が、また話したいと言っています」
- **承諾の期限までに、話す相手を一人以上**：面談で話した人、入社してまもない社員、内定者
- **読むものを一つ**：企業ページの「働く人」、内定者の話
- **押さない**：「決めましたか」を繰り返さない。回数より中身
- **承諾の期限を、学生の状況を聞いて決める**：他社の選考が続いているなら、その旨を聞いてよい

内定後の間の設計は[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)で書きました。原因が「3」でないなら、ここを厚くしても変わりません。

### エージェントベストの見解

これは順番の話です。当社がOfferBoxで「内定辞退が続く」という相談を受けたとき、内定後のフォローの話をする前に、辞退した学生の記録をオファーの時点まで戻って並べます。そこで、検索条件が「こんな人」とずれていた、文面がテンプレだった、一次の面接官が面談を知らなかった、が見つかれば、直すのはそこで、内定後のフォローではありません。原因が「内定後の間に連絡が途絶えた」だけなら、フォローを直します。当社が勧める順番は、オファーの時点、選考中、内定後、の順に見ることで、逆から見ると、内定後のフォローを厚くして「押されている」と感じる学生を増やしたあとで、原因がオファーの時点だったと分かることになります。

## まとめ

- 内定辞退の理由は、オファーの時点で合わない相手だった・選考中に印象が下がった・内定後の間に連絡が途絶えた・他社と比べて負けた、の四つ。直す場所が違う
- 内定後のフォローだけを厚くしても、原因がオファーの時点や選考中や条件にあれば直らず、「押されている」と感じる学生が増える
- 辞退の理由を聞ける範囲で聞き、事実と推測を分けて残し、四つに分類して月に一度まとめて見る
- 辞退した学生と承諾した学生の記録を、検索条件・文面・承認の理由・面談・各段階・内定後の接点、で並べて違いを見る
- 承諾した学生の「なぜ承諾したか」を次のオファーの文面と企業ページに反映し、内定者を次の年の話す相手にする

## よくある質問

### 内定辞退の理由が「他社に決めた」ばかりで、自社の原因が分かりません

「他社に決めた」の学生を、オファーの時点まで戻って見ます。検索条件で「こんな人」とずれていたか、文面がテンプレだったか、一次で印象が下がった様子があったか、内定後に接点があったか。承諾した学生と並べると、違いが見えます。「他社に決めた」は結果で、原因は自社の記録の中にあります。

### 条件で他社に負けている場合、どうすればよいですか

条件そのものを変えるかは、自社の判断です。この記事では判断しません。変えない場合は、条件をオファーの時点で企業ページに事実で書き、内定の時点で初めて出さないこと、仕事の「最初の1年」の具体を他社より厚くすること、話す相手を現場の人にすることで、条件以外の比べる材料を渡します。隠して内定まで来て辞退されるより、書いて合う学生が来るほうが、辞退は減ります。

### 内定辞退の見直しは、御社に相談できますか

できます。当社は、四つの理由の切り分けの型、理由の集め方の型、オファーの時点まで戻って並べる表の型、各理由の直し方の案を支えられます。理由を聞くこと、条件の決定、選考の変更、内定後の接点を持つことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
