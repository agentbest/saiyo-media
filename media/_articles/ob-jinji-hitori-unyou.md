人事が一人。新卒採用も、中途採用も、労務も、研修も、一人に集まっている。OfferBoxを回せるかは、「一人で送る数をこなせるか」で考えがちですが、実際に止まるのは、一人が休んだ週、一人の頭の中にしか「こんな人」と型と台帳がなくて、代わりの人が動けない週です。**結論から言うと、人事が一人の会社でOfferBoxが回るかは、媒体の重さではなく、「一人がいなくなっても止まらない形」で決まります。最初に決めるのは、経営と「一人の週の時間」を合意してから送る数を決めること、「こんな人」と型と台帳を一人の頭の外に出すこと、休む週の代わりを先に決めること、名義を現場にすること、外に出す作業を先に決めることです。** この記事では、人事が一人の会社が割ける時間と人、最初に決めること、一人の週の形、運用の分担、やりがちな失敗を整理します。曜日で作業を分ける週の設計は[人事1人でOfferBoxを回す運用設計](/media/ob-hitori-jinji/)、一人で回る媒体の選び方は[人事一人で回せる採用媒体の選び方](/media/hikaku-jinji-hitori/)で書きました。この記事は、その前段の「最初に決めること」を扱います。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 採用以外の業務（労務、研修、中途）が一人に集まる | 採用の時間が「取れたら」になり、送る週と返す週が崩れる |
| 経営が「一人でどこまでできるか」を知らない | 採る人数だけが降りてきて、時間の合意がない |
| 「こんな人」と文面の型が一人の頭の中にある | 休むと止まる。辞めると翌年がゼロから |
| 名義が人事一人 | 面談も一人。面談の枠が上限になる |
| 代わりの人がいない | 承認が来た日に一人が不在だと、返信が翌日以降に |
| 台帳が一人のファイル | 経営が進捗を聞くたびに、一人が説明する時間が要る |

人事が一人の会社がOfferBoxに割ける時間は、「一人の週の時間のうち、採用に使える割合」で決まり、その割合は経営との合意で決まります。合意がないと、採用の時間は他の業務に吸われ、送る数だけが目標として残ります。

## 最初に決めること

1. **経営と「一人の週の時間」を合意してから、送る数を決める**：「週に何時間を新卒採用に使う」を先に合意し、その時間で回せる送る数と面談の数を逆算する。人数の目標から時間を決めない
2. **「こんな人」の一行を、一人の頭の外に出す**：紙一枚に書き、経営と現場で合意する。休んでも、辞めても、翌年も使える。[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
3. **文面の型と、承認後の連絡の型を、一人の頭の外に出す**：テンプレートをファイルに。誰が見ても同じ文面が送れ、同じ返信ができる。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
4. **台帳を、一人のファイルではなく、経営と代わりの人が見られる場所に**：進捗を聞かれたら、台帳を見てもらう。説明の時間が消える
5. **休む週の代わりを、先に決める**：承認への一次の返信だけでよい。総務か、現場の一人か、運用代行か。「休みます」の連絡先を決めておく
6. **名義を、人事ではなく現場にする**：面談の枠が人事一人の枠を超える。現場に頼むのは、名義、文面の最終確認、面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
7. **外に出す作業を、申込の前に決める**：検索、文面の下書き、送信、一次の返信のどこまでを出すか。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)

### エージェントベストの見解

これをやる前に、先に経営と「一人が週に何時間を新卒採用に使うか」を合意しておかないと、どれだけ週の設計を整えても効果が出ません。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、人事が一人の会社の運用が止まる場面を見ていますが、止まる会社に共通するのは、経営から「今年は何人」の目標だけが降りていて、その人数に要る時間が経営に伝わっていないことです。人事は、目標の人数から送る数を決め、他の業務との間で採用の時間を削り、承認が来た日に返せなくなります。順番は、先に「週に何時間」を経営と合意し、その時間で回せる送る数と面談の数を出し、目標の人数がその数で届かないなら、時間を増やすか、作業を外に出すか、人数を見直すかを経営に選んでもらうことです。当社が人事一人の会社の見積もりを出すときも、人数より先に、週の時間を聞いています。

## 一人の週の形

| 曜日 | すること | 時間の性格 |
|---|---|---|
| 毎日、朝 | 通知を見て、承認に返す。面談の日程を返す | 短く。ここだけは毎日 |
| 週の頭 | 検索して、送る相手を選ぶ | まとまった時間。外に出せる |
| 週の中 | 文面を書く、名義の社員に確認を頼む | まとまった時間。下書きは外に出せる |
| 週の後半 | 送る。台帳を更新する | 短く。外に出せる |
| 週に一度 | 数字を見る。止まっている段を直す | 短く。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/) |
| 面談の枠 | 自分の予定に先に入れる。現場の名義なら現場の枠 | 固定 |

- **「毎日、朝」だけは、他の業務より先に置く**：ここが崩れると、承認した学生を失う。他は週の中でずらせる
- **まとまった時間が取れない週は、検索と下書きを飛ばして、返信と面談だけ守る**：送る数が減っても、承認した学生は失わない
- **曜日で分ける設計の詳しくは**：[人事1人でOfferBoxを回す運用設計](/media/ob-hitori-jinji/)。時間が足りないときは[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)

## 一人がいなくなっても止まらない形

- **「こんな人」の一枚、文面の型、承認後の連絡の型、台帳の四つが、一人の頭の外にある**：この四つがあれば、代わりの人が一次の返信をでき、翌年の担当が引き継げる
- **代わりの人に頼むのは、承認への一次の返信だけ**：「承認ありがとうございます。面談の日程を〇日までにご連絡します」の型を渡す。判断は戻ってから
- **休む週の前に、名義の社員と代行に伝える**：「今週は面談の日程を返せないので、来週で」と一次で返せる
- **経営に、台帳を見てもらう**：「進捗はどうか」に、口頭で答える時間を消す
- **辞めるときの引き継ぎは、四つを渡すだけ**：属人化を防ぐのは、引き継ぎ書ではなく、最初から外にある四つ

## 運用の分担

| 作業 | 誰が |
|---|---|
| 週の時間の合意、採る人数 | 経営と人事 |
| 「こんな人」の一枚 | 人事と現場の責任者。経営が合意 |
| 検索、文面の下書き、送信、台帳の更新 | 人事、または代行 |
| 承認への当日の返信 | 人事。休む週は代わりの人か代行 |
| 文面の最終確認、名義、面談 | 現場の社員 |
| 週に一度の数字の確認 | 人事。経営は台帳を見る |
| 外に出す範囲と、時間を増やすかの判断 | 経営 |

- **人事が一人でも、名義と面談は現場に**：人事一人の面談の枠が上限になると、送れる数が小さすぎる
- **代行に出すなら、「毎日、朝」の一次の返信から**：ここが最も落ちやすく、最も外に出しやすい
- **人事は、「こんな人」の見直し、文面の最終確認の依頼、台帳、面談の設定に絞る**：作業を減らして、判断と調整に時間を使う

運用代行や代理店が支えられるのは、四つの型（一枚・文面・連絡・台帳）の型、検索・下書き・送信・一次返信・台帳の更新、週の数字の整理までで、週の時間の合意、「こんな人」の決定、文面の最終確認、面談、時間を増やすかの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

送り始めたあと、最初の年で起きることに共通するのは、一人が休んだ週に承認が放置され、その週に承認した学生が他社に決まることです。当社はOfferBoxの運用代行を受けているので、人事が一人の会社の承認から返信までの日数を見ていますが、平均の日数は保てていても、特定の週だけ数日空いている会社が多くあります。その週は、一人が出張か、休みか、他の業務の締切です。一人の運用は、週の設計が良くても、「いない週」で崩れます。当社が人事一人の会社に最初に決めてもらうのは、送る数でも週の設計でもなく、「いない週に、誰が一次の返信をするか」で、それが総務の一人でも、現場の一人でも、当社でもよく、決まっていることが大切です。決まっていれば、いない週に送らない判断もでき、承認した学生を失いません。決まっていないと、いない週の承認が、そのまま辞退になります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 人数の目標から送る数を決める | 時間が足りず、承認に返せない | 週の時間を経営と合意してから |
| 「こんな人」と型が一人の頭の中 | 休むと止まり、辞めると翌年がゼロから | 四つを外に出す |
| 名義が人事一人 | 面談の枠が上限で、送れる数が小さい | 現場を名義に |
| 休む週の代わりを決めていない | いない週の承認が辞退になる | 一次の返信だけ代わりを決める |
| 外に出す作業を申込後に考える | 申し込んでから時間が足りないと分かる | 申込の前に範囲を決める |

最も多いのは、一つ目です。「今年は何人」から始まり、「週に何時間」が誰にも聞かれないまま送り始めます。

## まとめ

- 人事が一人の会社でOfferBoxが回るかは、媒体の重さではなく「一人がいなくなっても止まらない形」で決まる
- 経営と「一人の週の時間」を合意してから、送る数と面談の数を逆算する。人数の目標から時間を決めない
- 「こんな人」の一枚、文面の型、承認後の連絡の型、台帳の四つを、一人の頭の外に出す。休む週の代わり（一次の返信だけ）を先に決める
- 名義と面談は現場に。人事は「こんな人」の見直し、確認の依頼、台帳、面談の設定に絞る
- 「毎日、朝」の返信だけは他の業務より先に置く。まとまった時間が取れない週は、検索と下書きを飛ばして返信と面談だけ守る

## よくある質問

### 経営に「週に何時間」と聞かれても、答えられません

先に、他の業務を含めた一週間の時間の使い方を一枚に書き、そのうち新卒採用に使える時間を出します。その時間で、検索・文面・送信・返信・面談のどれがどれだけできるかを、この記事の週の形に当てはめます。出てきた送る数と面談の数を経営に見せると、「何人」の目標が、その数で届くかどうかが経営に見えます。

### 名義を現場にすると、現場が嫌がります

頼むことを、名義、文面の最終確認、面談の三つに絞り、文面は人事か代行が下書きし、面談の枠は現場の予定に先に入れておくと、現場の時間は短くて済みます。「採用を手伝ってほしい」ではなく、「この三つだけお願いします」と頼みます。現場が協力しないときの直し方は[現場がOfferBoxの面談に協力してくれないとき](/media/ob-genba-hikyouryoku/)で書きました。

### 人事が一人の会社のOfferBox運用は、御社に相談できますか

できます。当社は、四つの型、検索・下書き・送信・一次返信・台帳の更新、週の数字の整理を支えられます。週の時間の合意、「こんな人」の決定、文面の最終確認、面談、時間を増やすかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
