このメディアの記事は、採用媒体の代理店の選び方や使い方を、当社を含めた代理店一般について書いてきました。この記事では、当社エージェントベストに何ができ、何ができないかを、同じ基準で整理します。**結論から言うと、当社ができるのは、新卒・中途・インターンの媒体を特定の媒体に寄せずに並べた比較、正規料金のままの申込、申込後の運用の相談と代行、そして紹介で採る場合との使い分けの提案です。** できないのは、料金を下げること、採りたい人物像を代わりに決めること、面談と面接を代わりに行うこと、採用を保証することです。代理店の比較の軸は[代理店を比較するときの軸](/media/kh-dairiten-hikaku/)で書きましたが、この記事は当社をその軸に当てはめたものです。

## 当社がどういう会社か

当社は、スカウトと求人媒体の運用代行を本業とするRPO（採用代行）会社です。その運用の経験を土台に、新卒・中途・インターンの求人媒体を扱う求人広告代理店をしています。

申込の取り次ぎから入った代理店ではなく、運用から入った会社なので、相談の中心も「申し込んだあと、誰が何を回すか」になります。媒体の話を始める前に、社内で採用に使える時間を聞くのはそのためです。

## できること1｜媒体を並べて比較する

扱っている主な媒体は、次のとおりです。ここに無い媒体も、扱える場合があります。

| 採用の種類 | 主な媒体 |
|---|---|
| 新卒 | マイナビ2028、OfferBox、ワンキャリア、チアキャリア |
| 中途 | doda、マイナビ転職、type |
| 新卒・中途 | Wantedly |
| 長期インターン | Infra |

代理店の手数料は媒体の側から支払われ、どの媒体を勧めても企業の払う料金は変わりません。だから、自社の条件に合う媒体を、偏りなく並べて言えます。

比較の軸は、届く相手、企業が動く型（掲載・スカウト・共感・イベント）、料金の型、運用にかかる時間の4つです。新卒の主要なスカウト型・共感型・クチコミ型の見取り図は[3媒体の違いと選び方](/media/hikaku-3baitai/)に、新卒と中途で媒体の考え方がどう変わるかは[新卒向けと中途向けの媒体の違い](/media/hikaku-shinsotsu-vs-chuuto-baitai/)に書いてあります。相談では、これに自社の条件（採用人数、時期、人物像、社内の時間、中途の予定）を当てはめて、どれを先に検討するかを一緒に決めます。

「向かない」も言います。人事が兼務でオファーを書く時間が取れない会社にスカウト型を先に勧めることはなく、会社の想いがまだ言葉になっていない会社に共感型を先に勧めることもありません。「いまは申し込まないほうがいい」と言うこともあります。

## できること2｜正規料金のまま申し込む

当社経由で申し込んでも、企業が払う媒体の料金は各媒体の正規料金のままです。当社の手数料は媒体側から支払われ、企業に上乗せされません。仕組みは[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)で書きました。

見積もりは、媒体の正規料金の行と、当社の運用代行の行を分けて出します。代行を頼まない場合は、媒体の料金だけになります。前提（プラン、期間、人数、料金の型、キャンペーン、開始日）は見積もりの上に書きます。稟議に使える形で、提案書と、申込後に社内で必要な作業と時間の1枚もお渡しします。

契約の形と請求元は、媒体ごとの規定によります。申込前に、見積もりと一緒に説明します。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社が線を引くなら、「採用人数と時期」「採りたい人物像」「面談と面接」「面談の結果を戻すこと」の4つは、当社に何を頼んでいても企業が持ちます。この4つは、企業にしか決められず、企業にしかできないことです。当社が持つのは、媒体の比較、申込の手続き、申込後の相談、そして代行を頼まれた場合の検索・文面・送信・一次返信・日程の調整です。この線を最初にお伝えするのは、「代理店に頼めば全部やってくれる」という期待で申し込むと、人物像が決まらず、面談の枠が用意されず、止まるからです。逆に、この4つを企業が持っていれば、当社は申込の翌週から動けます。相談の最初に、この4つがどこまで決まっているかを聞き、決まっていなければ、一緒に決めるところから始めます。

## できること3｜申込後の運用の相談

申込後、運用が止まりかけたときの相談を受けます。媒体の型によって、多い相談は変わります。

| 媒体の型 | 申込後に多い相談 |
|---|---|
| スカウト型（OfferBoxなど） | 検索条件の組み方、文面の直し方、送る時期、承認された学生への返信と面談の組み方 |
| 共感型（Wantedly） | 会社ページとストーリーの書き方、更新の計画、募集記事の見直し、スカウトの送り方 |
| クチコミ・掲載型（ワンキャリア、ナビサイトなど） | 企業ページとイベント情報の整え方、選考体験談の読み方、掲載原稿の見直し |
| 中途の求人広告（doda、マイナビ転職、type） | 職種ごとの原稿の書き分け、掲載の時期とエリア、応募が来ないときの見直し |

相談は、月に一度の定期の打ち合わせと、止まりかけたときの随時の連絡の両方で受けます。送信数や更新の状況を見て、止まっていれば当社から声をかけます。媒体でないと答えられない仕様や不具合の問い合わせは、当社から媒体に取り次ぎます。

契約期間の終わりの前には、更新するか、配分を変えるかを一緒に見ます。複数媒体を使っている場合は、更新時期を揃え、全体を並べて配分を見直せるようにします。まとめ方は[複数媒体を代理店でまとめる方法](/media/kh-dairiten-fukusuu-baitai/)で書きました。

## できること4｜運用代行

送る時間や書く時間が取れない会社には、運用代行を行います。費用の形は代行の種類によって違います。

| 代行 | 費用の形 |
|---|---|
| OfferBox運用代行 | 完全成果報酬。入社承諾時のみ、1名20万円 |
| Green運用代行 | 成功報酬。入社時に1名50万円（税別）。Greenの利用料金は別 |
| そのほかのスカウト代行・掲載原稿の作成支援 | 相談のうえ見積もり |

作業の分け方は、どの代行でも同じです。

| 作業 | 誰が |
|---|---|
| 採りたい人物像を決める | 企業（当社は聞いて条件に整理する） |
| 検索条件を設定する | 当社 |
| 文面を書く | 当社が下書きし、共通部分は企業が確認する |
| 送る・一次返信する | 当社（企業の名義で） |
| 面談の日程を調整する | 当社が案内し、枠は企業が用意する |
| 面談する・選考する | 企業 |
| 面談の結果を当社に戻す | 企業 |
| 条件と文面を見直す | 当社（面談の結果に基づく） |
| 報告する | 当社（週次） |

代行を頼んでも、企業の名義で送られ、候補者との接点は企業に残ります。効いた文面と条件は報告で共有し、代行をやめて自社運用に戻すときは書面で引き継ぎます。代行の費用は、媒体の料金と分けて見積もります。頼める範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で、Greenの費用の形は[Green運用代行の成功報酬の仕組み](/media/gr-seikou-houshu/)で書きました。

## できること5｜紹介で採る場合との使い分け

当社は、求人広告代理店と運用代行の仕事に加えて、紹介で採る支援も行っています。だから、「媒体で採るか、紹介で採るか」を、両側から見て提案できます。

分かれ目は、採用人数と、社内で送る時間の有無です。少人数で、送る時間が週に取れるなら、媒体で自社が選んで届けるほうが、接点と経験が自社に残ります。送る時間がどうしても取れない、急いで少人数を埋めたい、という会社には、選ぶ作業を外に出す形を提案します。違いは[スカウト媒体と新卒紹介の違い](/media/hikaku-scout-vs-shoukai/)で書きました。

ただし、当社は紹介と代行の両方を行っているので、提案が紹介や代行に寄って見える立場でもあります。相談では、自社運用で回るならどの媒体か、媒体で採るならどう設計するかを、紹介や代行の話より先に言うようにしています。この順番になっていなければ、指摘してください。

## できないこと

期待とずれないよう、できないことも書きます。

1. **料金を下げること**：料金は媒体が決めます。当社が独自に値引きすることはありません。キャンペーンは、条件に合うものがあればご案内します
2. **採りたい人物像を代わりに決めること**：聞いて条件に整理することはできますが、決めるのは企業です
3. **面談と面接を代わりに行うこと**：候補者と会うのは企業です
4. **採用を保証すること**：媒体の運用を支援しても、採れるかどうかは候補者の判断です
5. **媒体の仕様を変えること**：管理画面の機能や送れる数は媒体が決めます
6. **どの媒体でも扱えるとは限らないこと**：扱っていない媒体の申込は各社の窓口になります。併用するときの設計の相談は受けます

## 相談からの流れ

1. **相談**：採用人数、時期、人物像、社内の時間、中途の予定を伝えてください。媒体はまだ決めなくて構いません。決まっていない項目は、一緒に決めます
2. **比較と提案**：扱っている媒体を自社の条件で並べ、どれを先に検討するかを提案します。「いまは申し込まない」も含みます
3. **見積もり**：媒体の正規料金と、頼む場合の代行の費用を分けて出します。申込後に社内で必要な作業と時間の1枚を添えます
4. **社内確認と稟議**：稟議に使える形の提案書をお渡しします。書き方は[代理店経由の申込を社内で説明する方法](/media/kh-dairiten-shanai/)
5. **申込と契約**：契約の形と請求元を説明したうえで、媒体に申し込みます
6. **契約開始の翌週**：人物像の確定、文面や原稿の確認、面談の枠、最初の送信日や掲載日の4つに日付を入れて動き始めます
7. **運用**：月に一度の打ち合わせと、止まりかけたときの連絡で支えます

### エージェントベストの見解

同じ相談でも、当社が「まず1つの媒体から」と勧めるのは、担当が1人で、まだ媒体を使ったことがない会社です。複数の媒体を同時に始めると、書く・送る・整えるの作業が同時に来て、手間の重いものから止まります。軸にする媒体を1つ決め、契約開始の翌週にやることに日付を入れ、運用が回ってから次を足す。この順番のほうが、半年後にどの媒体も動いています。逆に、担当が複数いて、新卒と中途の両方を採る計画があり、採りたい人物像も条件で言える会社には、最初から役割を分けて2つか3つを勧めることもあります。当社が「向く会社」と「向かない会社」を分けるなら、向くのは「人数・時期・人物像・時間を決められる会社」で、向かないのは「代理店に決めてもらいたい会社」です。後者の会社には、決めるところから一緒にやりますが、決めるのは企業だということは、最初にお伝えします。

## まとめ

- 当社は運用代行のRPO会社が営む求人広告代理店で、新卒・中途・インターンの媒体を扱う
- できるのは、媒体を並べた比較、正規料金のままの申込、申込後の運用の相談と代行、紹介との使い分けの提案
- できないのは、料金を下げること、人物像を決めること、面談すること、採用の保証
- 採用人数と時期、人物像、面談、結果を戻すことは、何を頼んでも企業が持つ
- 相談は申込前提ではない。「いまは申し込まない」も提案に含む

## よくある質問

### 相談は無料ですか。申し込まないといけませんか

媒体選びと見積もりの相談は無料で、申込前提ではありません。相談の結果「いまは申し込まない」となる会社も、採用の計画が固まってから改めて来る会社もあります。費用がかかるのは、媒体の利用料金と、頼んだ場合の運用代行だけです。

### 一覧に無い媒体を使っています。相談できますか

扱える場合があるので、まず媒体名をお伝えください。扱っていない媒体でも、いま使っている媒体と併用するときの分担や時期の組み方は相談できます。このメディアの媒体比較の記事は、扱っていない媒体との比較も、型の違いとして書いています。

### 御社を他の代理店と比べたいのですが

比べてください。[代理店を比較するときの軸](/media/kh-dairiten-hikaku/)の軸と、[代理店に聞くべき質問](/media/kh-dairiten-shitsumon/)の質問を、当社にもそのまま聞いていただいて構いません。答えに詰まる質問があれば、それは当社が直すべき点です。
