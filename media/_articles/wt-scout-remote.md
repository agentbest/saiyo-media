Wantedlyでは、勤務地から遠くに住む人のプロフィールも見えます。良い相手が見つかっても、「遠いから」で送らないか、送っても勤務地に触れず、返信が来てから「出社が必要です」となって終わる、ということが起きます。**結論から言うと、遠方の候補者にスカウトを送るときは、送る前に「リモートで働けるか、出社が要るか、移住の支援があるか」を決め、文面に働き方の形を一文で書き、会わずに進められることを伝えます。「来てもらう前提」を外さないまま送ると、返信後にずれます。その土地に縁があることをプロフィールで読んだなら、それを一文に使います。** この記事では、遠方の相手に送る意味、やりがちな失敗、送る前に決めること、文面に入れること、返信後の進め方、面談での話し方、地方企業の場合、分担を整理します。リモート勤務の募集記事は[リモート勤務の募集の伝え方](/media/wt-remote-boshu/)、地方企業の募集記事は[地方企業が募集を書くときの伝え方](/media/wt-chihou-boshu/)で書きました。

## この作業の目的｜「遠いから無理」を、双方で先に判断できるようにする

遠方の候補者にとって、最初の疑問は「この会社で働くには、引っ越しが要るのか」です。文面にそれが無いと、返信する前に諦めるか、返信してから分かって終わります。

目的は、働き方の形を文面で先に伝え、「遠くても働ける」か「引っ越しが要る」かを、相手が返信の前に判断できるようにすることです。判断できれば、来る人は合う人だけになり、返信後のずれが無くなります。

## 遠方の相手に、送る意味

| 状況 | なぜ送る意味があるか |
|---|---|
| リモートで働ける仕事 | 住む場所は関係ない。対象が全国に広がる |
| 移住も選択肢に入る人 | プロフィールに「〇〇に住みたい」「地方で働きたい」と書いている人がいる |
| その土地に縁がある人 | 出身、学生時代を過ごした、家族がいる。Uターンを考えている可能性 |
| 一部リモートで、出社の頻度が少ない仕事 | 遠くても、月に数回なら通える人がいる |
| 将来、その地域に拠点を作る予定がある | 先に関係を持てる |

送る意味が無いのは、「毎日出社が要り、移住の支援も無く、相手が移住を考えていない」場合です。この場合は、送りません。絞り込みの段階で外します。

## やりがちな失敗

| 失敗 | 何が起きるか |
|---|---|
| 勤務地に触れない | 返信後に「出社が必要です」で終わる |
| 「転居可能な方」で切る | 移住を考えていない人は来ない。考えている人にも冷たく見える |
| リモートの形が曖昧（「リモート可」だけ） | 常にリモートだと思って返信し、面談で「週に数回は出社」と聞いて離れる |
| 面談を来社前提で組む | 遠方の人は来られない |
| 交通費の扱いに触れない | 来社を頼まれても、負担が分からず断る |
| その土地との縁を読まずに送る | 「なぜ自分に」が無い |
| 移住の支援が無いのに「移住歓迎」 | 面談で実態が分かる |

最も多いのは、最初の「勤務地に触れない」です。文面は仕事の話だけで、相手は勤務地を確かめるために会社ページを見て、遠いと分かって閉じます。

### エージェントベストの見解

相談で最も多い思い込みは、「遠方の人に送っても、どうせ来ない」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、遠方の人が来ないのは、遠いからではなく、文面に働き方の形が無いからです。リモートで働ける仕事なら、遠くても働けます。移住の支援があるなら、移住を考えている人は来ます。その土地に縁がある人は、Uターンを考えていることがあります。当社が遠方の相手への文面を整えるとき、最初にやるのは、「この仕事は、どこに住んでいれば働けるか」を一文で書くことです。その一文があれば、相手は返信の前に判断でき、来る人は合う人だけになります。遠さは、文面で先に伝えれば、障害ではなく条件の一つになります。

## 送る前に、決めること

1. **この募集は、リモートで働けるか、出社が要るか、どの頻度か**：制度ではなく実態。その職種の人に確かめる
2. **移住の支援があるか**：引っ越しの費用、住まいの探し方の支援。自社の制度に沿って。無ければ無いと
3. **地域の制約があるか**：出社できる距離が求められるか、時差の扱い
4. **来社を頼む場合の交通費の扱い**：自社の制度に沿って
5. **面談をオンラインで完結できるか**：話す人が対応できるか
6. **選考も、オンラインで進められるか**：最終だけ来社、など

1が決まっていないと、文面に書けません。決まっていなければ、遠方の相手には送りません。

## 文面に入れること

通常の3段に、次を足します。

| 入れること | 書き方 |
|---|---|
| 働き方の形を一文で | 「この仕事は、常にリモートで、出社は〇〇の場面だけです」「週に数回は〇〇のオフィスに出社が要ります」。実態のとおりに |
| 会わずに進められること | 「面談はオンラインで、来てもらう必要はありません」 |
| その土地との縁を読んだなら | 「〇〇のご出身と書かれていたので」「△△で学生時代を過ごされたと読んで」。Uターンを考えているかもしれない相手に |
| 移住の支援があるなら | 一文で。「移住の場合、〇〇の支援があります」。無ければ書かない |

働き方の一文は、2段目の重なる点のあとか、3段目の話す場の案内の中に入れます。最初の一文は、通常どおり相手のプロフィールの箇所です。文面の基本の構成は[スカウト文面の書き方](/media/wt-scout-bunmen/)で書きました。

「その土地との縁」は、プロフィールに書かれている場合だけ使います。推測で「ご出身では」と書かない。書かれていれば、それを読んだと伝えるのは、相手にとって「なぜ自分に」の答えになります。

## 返信後の進め方

- **面談はオンライン**：来社を前提にしない。日程は、時差があれば配慮
- **来社は、相手が望んだときだけ**：「見に来たい」と言われたら。交通費の扱いを先に伝える
- **働き方の形を、面談の最初に確かめる**：「文面に書いたとおり、〇〇の形です。この形で問題ないですか」。ずれがあれば、ここで分かる
- **移住の話は、相手から出たときに**：会社側から「引っ越せますか」と聞かない
- **選考の流れを、オンラインで進める形で伝える**：「最終だけ来てもらう」なら、それも先に
- **土地の情報を渡す**：移住を考えている相手には、社員の暮らしのストーリー。地方企業の場合は[地方企業が募集を書くときの伝え方](/media/wt-chihou-boshu/)で書いた「移ってきた人の話」

「働き方の形を面談の最初に確かめる」が、返信後の要点です。文面で伝えていても、相手が読み違えていることはあります。最初に確かめれば、面談の時間を無駄にしません。

## 地方企業の場合

地方に拠点がある会社が、都市部の候補者に送る場合は、さらに次を足します。

- **Uターン・Iターンの読み手に分けて、文面を変える**：出身が分かればUターン向け、「地方で働きたい」と書いていればIターン向け
- **仕事の具体を、都市部の会社と同じ水準で書く**：「地方だから」で薄くしない
- **住む場所と暮らしの具体を、面談で話せるように**：社員の暮らしの場面
- **来てもらうときの形を、先に用意する**：交通費、見学できるもの、社員と話せる時間
- **移ってきた人が面談に出る**：「自分も遠くから来た」人の話が、最も具体的

地方企業のスカウトは、「仕事の具体」が先で、「土地の魅力」はあとです。文面でも、面談でも、この順番です。

## 絞り込みでの扱い

- **リモートで働ける募集なら、勤務地で絞らない**：対象を全国に
- **出社が要る募集なら、通える範囲か、移住を考えている人（プロフィールで分かる範囲）に絞る**
- **その土地に縁がある人を、検索の条件に入れられるなら入れる**：出身、学校。仕様は管理画面で確認
- **遠方の相手は、台帳に「遠方」と印を付ける**：返信後の進め方が違う

絞り込みの基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。勤務地の扱いは、募集の働き方で変わります。

| 作業 | 誰が |
|---|---|
| 働き方の実態を確かめる | 人事（その職種の人に） |
| 移住の支援、交通費の扱いを確認する | 人事と管理部門 |
| 遠方の相手に送るかを、募集ごとに決める | 人事と責任者 |
| 文面に働き方の一文を入れる | 人事（型に） |

運用代行や代理店が支えられるのは、送る前に決める項目の一覧、文面に足す一文の型、返信後の進め方の型、地方企業向けの整理までで、働き方の決定、支援の決定、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと返信後にずれることがあります。「この募集の働き方の実態」です。当社がWantedlyで遠方の候補者へのスカウトを支えるとき、文面に入れる一文は当社が型にできますが、その一文の中身（常にリモートか、週に数回出社か、移住の支援があるか）は、社内で決まっていなければ書けません。「リモート可」の制度はあるが、その職種では出社が多い、という会社では、制度ではなく実態を書きます。当社が最初にお願いするのは、その職種の人に「いま、実際にどう働いていますか」と聞いてもらうことです。その答えが、文面の一文になります。遠方の相手に送るかどうかも、その答えで決まります。

## まとめ

- 遠方の候補者に送るときは、送る前に「リモートか出社か、その頻度、移住の支援、地域の制約」を実態で決める
- 勤務地に触れない、「転居可能な方」で切る、リモートの形が曖昧、来社前提の面談、が返信後のずれを生む
- 文面に、働き方の形を一文で、会わずに進められることを、その土地との縁を読んだならその一文を入れる
- 返信後はオンラインで完結し、来社は相手が望んだときだけ、面談の最初に働き方の形を確かめ、移住の話は相手から
- 地方企業は、Uターン・Iターンで文面を変え、仕事の具体を先に、移ってきた人が面談に出る

## よくある質問

### リモートで働ける仕事ですが、最初の数か月は出社してほしいです

そのとおりに、文面に書きます。「最初の〇か月は出社、その後はリモート」。書かずに返信を得て、面談で伝えると、ずれます。書いて返信が来た人は、その形を受け入れて来ています。

### 遠方の人に来社を頼むとき、交通費は出すべきですか

自社の制度で決めます。出すなら、頼むときに先に伝えます。出さないなら、来社は相手が望んだときだけにし、選考をオンラインで進められる形にします。この記事では、出すべきかどうかは書きません。

### 遠方の候補者へのスカウトは、御社に相談できますか

できます。当社は、送る前に決める項目の一覧、文面に足す一文の型、返信後の進め方の型、地方企業向けの整理を支えられます。働き方の決定、支援の決定、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
