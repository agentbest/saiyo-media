ワンキャリアで新卒の品質管理を募集したとき、最初にぶつかるのは「『品質管理』と掲載しても『検査をする仕事』と読まれて理系の学生が来ないか、来ても面接で『何をするのですか』『クレームの対応もするのですか』と聞かれ、入社後に『止める権限が無く、現場と開発の板挟みだった』『クレーム対応ばかりだった』と体験談に書かれる」という問題です。**結論から言うと、ワンキャリアの品質管理の掲載は、「品質管理」の名前ではなく「品質管理か品質保証か、何を検査し何を止める権限があるか、現場と開発の間で何をするか、クレームの対応をするか、最初の年に何を任せるか」を、学生が体験談で読む前に企業ページと募集に書き、面接では「止めた経験」を聞きます。** メーカーとしての設計は[メーカーの新卒採用でワンキャリアを使うときの設計](/media/oc-maker-katsuyou/)で書きました。この記事は品質管理の職種に絞り、掲載とスカウトと選考をつなげて書きます。

## 品質管理志望の学生が、体験談で読んでいること

品質管理は、学生が「検査をする仕事」と思い込んでいる職種です。学生は「品質管理」で探さず、開発や研究の体験談を読む中で「品質に配属された」と知り、企業ページで「何をする仕事か」から確かめています。

| 読んでいること | 掲載への意味 |
|---|---|
| 品質管理か品質保証か | 工程の中で検査し不良を減らすのか、出荷の判断と顧客への保証をするのか。会社によって言葉が違う |
| 何を検査するか | 製品か、材料か、工程か。自分で測るか、データを読むか |
| 止める権限があるか | 不良を見つけたとき、ラインや出荷を止められるか。誰が判断するか。体験談で最も書かれる |
| 現場と開発の間で何をするか | 現場に戻すのか、開発に戻すのか。板挟みになるか |
| クレームの対応をするか | 顧客からのクレームの原因調査と報告をするか。どの頻度か |
| 勤務地 | 工場か本社か |
| 最初の年に何を任されるか | 検査のデータを読むのか、不良の原因調査の一つか |
| 化学や材料系でなくても採るか | 機械系や文系から入った人がいるか |
| 先輩の実態 | 最初の年に何を調べ、いま何を担当しているか |

「止める権限があるか」と「クレームの対応をするか」が、品質管理の体験談で最も読まれ、企業ページで最も書かれない項目です。

## 掲載に書くこと｜管理か保証か、何を検査するか、止める権限、現場と開発の間、クレーム、最初の年

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「品質管理」ではなく「〇〇の工場の工程の品質管理」「△△の製品の出荷判断と品質保証」。管理と保証を分ける |
| 何をする仕事か | 「工程の中で不良の原因を見つけ、減らす。出荷の判断は品質保証が別にある」。一段落で、検査だけの像を外す |
| 何を検査するか | 「□□の製品の、〇〇の工程。自分で測るのは△△。データを読むのは□□」 |
| 止める権限 | 「不良を見つけたら、ラインを止める判断は〇〇がする。品質管理は止めるよう言える」。言えないなら、そう書く |
| 現場と開発の間 | 「原因が現場なら現場に、設計なら開発に戻す。最初の年は先輩が間に入る」 |
| クレームの対応 | 「顧客のクレームの原因調査は品質保証が担い、品質管理は工程の側から調べる。頻度は月に〇件程度」。するなら、そう書く |
| 最初の年 | 「最初の〇か月は検査のデータを読み、傾向を見る。△△か月目に不良の原因調査を一つ、先輩の確認付きで」 |
| 化学や材料系以外から入った人 | 「機械系から入った人が〇人。文系は△人」。いないなら、いないと |
| 先輩の話 | 最初の年に何を調べ、何を止めたか。盛らない |

企業ページには止める権限と現場と開発の間とクレームの扱いを、募集には管理か保証かと何を検査するかと最初の年を、と分担します。

### エージェントベストの見解

品質管理の内定辞退と早期の離職が続く会社から相談を受けたとき、当社が最初に切り分けるのは、「理由が、仕事の像の違いか、止める権限か、クレームの対応か」です。当社は3媒体すべての販売パートナーとして、品質管理の掲載と選考を見ていますが、三つは直し方が違います。仕事の像の違いなら、「検査をする仕事」と読まれないよう、企業ページに「不良の原因を見つけて減らす」を一段落書けば、合わない学生はエントリーの前に離れます。止める権限が理由なら、「止める判断は〇〇がする。品質管理は止めるよう言える」と書き、面接でも言うことで、「権限が無かった」が体験談から消えます。クレームの対応が理由なら、「クレームの原因調査を品質管理がするか、頻度はどれくらいか」を書き、面接で例を話すことで、「クレーム対応ばかり」が消えます。「品質管理は人気が無い」と一括りにして掲載の全体を書き直す会社が多いのですが、辞退した学生の体験談と内定者の面談の記録を読むと、理由は一つに絞れることが多く、直すのも一か所で足ります。

## 品質管理志望の学生の見つけ方

「品質管理」を志望職種に書いている学生はほとんどいません。「几帳面」「慎重」の人柄で絞らず、行動で読みます。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 志望職種 | 開発、研究、それ以外 | 見ない条件。「品質管理」で絞ると、いなくなる |
| 学科 | 化学、材料、機械、それ以外 | あればよい条件。学科で絞らない |
| 違いに気づいて調べた経験 | 「実験の結果がいつもと違い、原因を調べたら△△だった」 | 品質管理の行動。優先 |
| 止めた経験 | 「おかしいと思って、進める前に止めて確かめた」 | 止める権限と重なる。最も重い |
| 決まりを作った経験 | 「同じ失敗が起きないよう、手順を決めた」 | 不良を減らす仕事と重なる |
| 人に伝えて直してもらった経験 | 「年上の人に、やり方の違いを伝えて直してもらった」 | 現場と開発の間と重なる |

「違いに気づいて調べた・止めた・決まりを作った・人に伝えて直してもらった」を書いている学生が、品質管理と重なります。四つの行動は[OfferBoxで品質管理に合う学生を見つける検索の考え方](/media/ob-hinshitsu-target/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

理系向けの文面の型は[ワンキャリアで理系学生にスカウトを送る文面](/media/oc-scout-rikei/)で書きました。品質管理では、次の点を足します。

- **相手の一文は、止めた経験か、違いに気づいた経験で**：「おかしいと思って進める前に止めて確かめたと書かれていたのを読んで」。「几帳面そう」と書かない
- **何をする仕事かを、一文で**：「品質管理は、工程の中で不良の原因を見つけて減らす仕事です。検査だけではありません」
- **止める権限を、一文で**：「不良を見つけたら、止めるよう言える立場です。止める判断は〇〇がします」
- **クレームの扱いを、一文で**：「顧客のクレームの対応は品質保証が担い、品質管理は工程の側から調べます」
- **最初の年を、一文で**：「最初の〇か月は検査のデータを読み、△△か月目に原因調査を一つ任せます」
- **送り主は、品質管理で入った先輩**：人事の名前で「ものづくりに興味のある方」と送らない

## 選考への接続｜「止めた経験」を聞く

- **面接の最初に、何をする仕事かを話す**：学生は「検査をする仕事」と思って来ている。「品質管理は〇〇をする仕事で、検査だけではありません」から始める
- **止める権限とクレームの扱いを、聞かれる前に話す**：「止める判断は〇〇がする。クレームの対応は△△」。面接で「品質を守る仕事」とだけ言い、入社後に権限が無いと、体験談に書かれる
- **聞くのは「止めた経験」**：「おかしいと思ったとき、止めたか、進めたか。止めたなら、どう伝えたか」。「なぜ品質管理か」を聞かない。学生は答えを持っていない
- **現場と開発の間の話を、例で話す**：先輩が現場に戻した例と、開発に戻した例を一つずつ
- **内定後に、検査の場と原因調査の記録を見せる**：先輩が止めた記録と、その後どうなったかを。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

| 作業 | 誰が |
|---|---|
| 管理か保証か、何を検査するか、止める権限、クレームの扱い、最初の年を決める | 品質部門の責任者 |
| 企業ページの品質管理の記述 | 人事が、責任者と先輩に聞いて書く |
| 先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「権限が無かった」「クレームばかり」と書かれていないか） |
| スカウトの一文 | 先輩 |
| 面接 | 責任者と先輩。「止めた経験」を聞く |

運用代行や代理店が支えられるのは、掲載の型、管理と保証の分け方の整理、止める権限を文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、仕事の内容の決定、権限の設計、面接、先輩の話は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「品質管理は几帳面で慎重な人が向いているから、そういう人柄の学生を探せばよい」というものです。人柄で探した会社の体験談には、「慎重な人と言われて入ったが、現場に伝えて直してもらう仕事だった」「几帳面さより、言いにくいことを言う仕事だった」が書かれます。品質管理の仕事の中心は、検査で違いに気づくことより、気づいたあとに止めると言い、現場や開発に伝えて直してもらうことです。几帳面な学生が、年上の職人や開発の担当者に「止めてください」と言えるとは限りません。逆に、「おかしいと思って止めた」「年上の人に伝えて直してもらった」の行動で探し、面接で止めた経験を聞いた会社は、体験談に「止めた経験を聞かれた」と書かれ、次の年に同じ行動を持つ学生が来ます。当社が学生を探す基準を作るとき、人柄の言葉を全部外し、四つの行動に置き換えることから始めています。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「品質管理」の名前だけで書く | 「検査をする仕事」と読まれ、来ない | 不良の原因を見つけて減らす仕事と一段落で |
| 止める権限を書かない | 「権限が無かった」と書かれる | 誰が判断し、言える立場かを書く |
| クレームの扱いを書かない | 「クレームばかり」と書かれる | 誰が担い、頻度はどれくらいかを書く |
| 人柄で絞る | 言えない学生が入り、離れる | 止めた・伝えた行動で読む |
| 「なぜ品質管理か」を聞く | 学生は答えを持っていない | 「止めた経験」を聞く |

## まとめ

- 品質管理は学生が「検査をする仕事」と思い込んでいる職種。学生は「管理か保証か・何を検査するか・止める権限・現場と開発の間・クレームの扱い・最初の年・先輩の実態」を企業ページで確かめる
- 掲載には、管理と保証を分け、何をする仕事かを一段落、何を検査するか、止める権限、現場と開発の間、クレームの扱いと頻度、最初の年を書く
- 辞退と離職の理由は、仕事の像・止める権限・クレームのどれかに切り分けて、一か所を直す
- 学生は、人柄ではなく「違いに気づいて調べた・止めた・決まりを作った・伝えて直してもらった」で見つける
- 面接の最初に何をする仕事かを話し、止める権限とクレームの扱いを先に言い、「止めた経験」を聞く

## よくある質問

### 品質管理と品質保証の違いを、学生に分かるように書くには

会社の言葉ではなく、仕事で書きます。「工程の中で不良の原因を見つけて減らすのが品質管理。出荷してよいかを判断し、顧客に保証するのが品質保証」と、どちらも一文で書き、募集がどちらかを職種名で示します。両方を一人でする会社なら、「最初の年は工程の側。出荷判断は△年目から」と順番で書きます。会社によって言葉の使い方が違うので、自社での意味を書きます。

### 止める権限が、品質管理には無い会社です。書くと学生が来なくなりませんか

「止める判断は〇〇がする。品質管理は止めるよう言える」と、誰が判断し、品質管理がどこまで言えるかを書きます。権限が無いことより、権限が無いのに「品質を守る仕事」と書くことで、体験談に「権限が無かった」と書かれます。「言える立場」であることと、言って止まった例を先輩の話で添えると、権限の無さが「言えない」ではなく「判断は別の人」と伝わります。

### 品質管理の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、管理と保証の分け方の整理、止める権限を文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。仕事の内容の決定、権限の設計、面接、先輩の話は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
