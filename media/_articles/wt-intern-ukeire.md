Wantedlyでインターンの募集を出すと、学生から「話を聞きに行きたい」が届き、面談をして、「来てほしい」と決まります。ところが、その先で「何を任せるかが決まっていない」「見る社員の手が空いていない」「アカウントや席の準備が間に合わない」と、受け入れ側が追いつかないことがあります。**結論から言うと、受け入れが追いつかないのは、募集を出す前に受け入れの上限が決まっていないことが多いです。上限を先に決め、任せる仕事・見る人・手続きの順に整え、開始日をまとめます。上限に達したら、募集を一時止めることもためらわずに考えます。** 募集記事の書き方は[Wantedlyで長期インターンの学生を採る募集記事](/media/wt-intern-boshu/)、体験と労働の線引きは[インターン募集記事で体験と労働の線を引く](/media/wt-boshu-intern/)で書きました。

## 症状の確認｜受け入れが追いつかないと、何が起きるか

| 症状 | 学生からどう見えるか |
|---|---|
| 面談のあと、開始日が決まらない | 「来てほしいと言われたのに、連絡が来ない」 |
| 初日に、やることが決まっていない | 「何をしに来たのか分からない」 |
| 見る社員が忙しく、質問できない | 「放っておかれている」 |
| アカウントや機器が届いていない | 初週が待ち時間になる |
| 募集記事と任された仕事が違う | 「書いてあったことと違う」 |
| 来たインターン生が、早く辞める | 次の学生にも、その話が伝わる |

学生どうしのつながりは強く、インターン先の話は周りに伝わります。受け入れの印象は、次の募集の集まり方にも、その学生が新卒で応募するかどうかにも残ります。

## 原因の切り分け｜この順番で見る

1. **受け入れの上限が決まっていない**：何人まで、いつまでに受け入れられるかを決めずに募集を出している
2. **任せる仕事が一つに決まっていない**：「来てから考える」になっている
3. **見る社員の時間が取れていない**：見る人は決まっていても、その人の業務が減っていない
4. **手続きの担当がいない**：契約、アカウント、機器、入館などを誰が用意するかが決まっていない
5. **面談から開始日までの段取りがない**：学生ごとに開始日がばらばらで、そのたびに準備が要る

1が先に来るのは、上限が決まらないと、2から5をいくら整えても、応募が増えるたびに追いつかなくなるからです。

### エージェントベストの見解

インターンの募集を出す前に、先に決めておかないと効果が出ないことがあります。「同時に何人まで見られるか」です。当社がWantedlyの運用の相談でインターンの受け入れを見るとき、追いつかなくなる会社に共通するのは、募集を出してから受け入れの形を考え始めていることです。Wantedlyは通年で学生が会社を読んで来る場なので、時期を区切った募集より、応募が途切れずに届くことがあります。届いた分をすべて受け入れようとすると、見る社員が手一杯になり、一人ひとりへの関わりが薄くなります。当社が勧めるのは、見る社員一人あたりの受け入れを先に決め、上限に達したら募集を止めるか、開始日を次の区切りに回すことです。少なく受け入れて丁寧に見るほうが、学生の口から次の学生に伝わる話は良くなります。

## 打ち手1｜受け入れの上限と開始日を決める

- **見る社員ごとに、同時に受け入れる人数を決める**：見る人の業務量から決める
- **開始日を区切りでまとめる**：月の初めなど、決まった日にまとめて始めると、準備が一度で済む
- **上限に達したら、募集を一時止める**：募集の公開状態の変え方は[Wantedlyの募集の公開・非公開の設定](/media/wt-boshu-koukai/)。操作の詳細は管理画面とヘルプで確認する
- **止めるあいだに来た「話を聞きに行きたい」には、開始できる時期を伝える**：断るのではなく、時期を示す

## 打ち手2｜任せる仕事・見る人・手続きを整える

| 準備 | 中身 | 誰が |
|---|---|---|
| 任せる仕事 | 最初の数週間で任せる一つの仕事と、そのあとの広げ方 | 見る社員と現場の責任者 |
| 見る人 | 質問を受ける人、週に一度話す時間 | 現場の責任者が業務を調整 |
| 初日と最初の週 | 何を読み、誰と話し、何を一つ終えるか | 見る社員 |
| 契約と条件 | 労働に当たる場合の契約や賃金の扱い、勤務の時間帯と試験期の扱い | 人事と労務の担当 |
| アカウント・機器・入館 | 必要なものの一覧と、用意する日 | 総務や情報システムの担当 |

契約と条件の扱いは、インターンの内容によって変わります。業務に従事してもらう場合の雇用契約や賃金の扱いは、社内の労務担当や専門家に確認してから決めます。募集記事に書いた条件と、実際の契約がずれないようにします。

## 打ち手3｜面談から開始までの段取りを一本にする

1. **面談の最後に、開始できる時期を伝える**：面談の流れは[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
2. **来てほしいと決めたら、翌日までに連絡する**：開始日、初日の流れ、用意してほしいものを書く
3. **開始の前に、見る社員から一言送る**：「初日はこれをやりましょう」と書くと、学生の不安が減る
4. **初日の終わりに、見る社員と短く話す**：分からなかったことを聞く
5. **最初の月の終わりに、続けるかどうかを双方で確認する**

## 外に出す場合の範囲

運用代行や代理店が支えられるのは、募集記事の見直し、受け入れ人数から逆算した募集の出し方の整理、面談の型、面談から開始までの連絡の型、台帳の設計までです。任せる仕事を決めること、見ること、契約と手続きは企業が行います。インターン媒体と併用している場合の入口ごとの分け方は[Wantedlyとインターン媒体の併用](/media/wt-heiyou-intern-baitai/)、スカウトで学生を誘う考え方は[Wantedlyで学生インターンにスカウトを送る文面の考え方](/media/wt-intern-scout/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyのインターン採用を支えるとき、募集記事の直し、連絡の型、台帳は当社でも持てます。ただし、受け入れの側は外に出せません。インターン生が会社をどう感じるかは、見る社員が質問にどう答え、初日に何を任せたかでほとんど決まります。ここは外部の人が代われない部分です。当社が最初にお伝えするのは、「見る社員の業務を、受け入れの期間だけ減らせますか」という確認です。減らせるなら、受け入れの人数をその分だけ設定し、募集を出します。減らせないなら、募集を出す時期を、見る社員の手が空く時期まで遅らせることを勧めます。受け入れの準備が整わないまま学生を迎えるより、そのほうが学生にも会社にも残るものが多くなります。

## まとめ

- 受け入れが追いつかないと、開始日が決まらない・初日にやることがない・質問できない、が起き、学生のあいだで話が伝わる
- 原因は、受け入れの上限・任せる仕事・見る人の時間・手続き・開始までの段取りの順に切り分ける
- 見る社員ごとに同時に受け入れる人数を決め、開始日をまとめ、上限に達したら募集を一時止める
- 契約と条件は、労働に当たる場合の扱いを社内の労務担当や専門家に確認し、募集記事とずらさない
- 外に出せるのは募集・連絡・台帳の型まで。任せる仕事を決めること、見ること、手続きは社内に残す

## よくある質問

### 応募が多く、断るのが申し訳ないです

断る代わりに、開始できる時期を伝えます。「次の区切りからなら受け入れられます」と伝え、その時期に改めて連絡します。それでも受け入れの見込みが立たない場合は、募集を一時止めます。受け入れられない数の学生と面談を続けるより、学生の時間を無駄にしません。

### 見る社員が若手しかいません

若手が見ることは、学生にとって身近で、質問しやすい面があります。ただ、若手が一人で抱えると、自分の業務が回らなくなります。見るのは若手、週に一度の振り返りと、困ったときの相談先は現場の責任者、と二段にしておきます。

### インターンの受け入れ設計は、御社に相談できますか

できます。当社は、募集記事の見直し、受け入れ人数から逆算した募集の出し方、面談と連絡の型、台帳の設計を支えられます。任せる仕事を決めること、見ること、契約と手続きは企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
