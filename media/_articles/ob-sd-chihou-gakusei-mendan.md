OfferBoxでは、勤務地から離れた地域に住む学生とも出会えます。オファーを承認してくれた学生と面談するとき、移動の負担や、勤務地への転居の話をどう扱うかで迷う会社は少なくありません。**結論から言うと、地方の学生との面談は、初回をオンラインにして移動の負担をなくし、勤務地と転居の話を早めに正直に出し、対面の機会は会社が負担を持って用意することが要点です。** この記事では、面談の目的、手順、聞く順番、家族の話の扱い、やりがちな失敗と社内の分担を整理します。オファー文面の書き方は[地方の学生へのオファーの考え方](/media/ob-chihou-gakusei/)で書きました。

## 面談の目的｜勤務地を含めて、働く姿を想像してもらう

勤務地から離れた地域の学生にとって、入社は仕事を選ぶことであると同時に、住む場所を選ぶことでもあります。面談の目的は、仕事の中身に加えて、勤務地での暮らしまで含めて、学生が働く姿を想像できるようにすることです。

確かめたいことは、次の三つです。

- **学生が何に反応して承認したか**：仕事の中身か、勤務地か、会社の考え方か
- **勤務地への移り住みを、学生がどう考えているか**：前向きか、迷っているか、条件があるか
- **学生が仕事と暮らしに何を求めているか**

二つ目は、早めに聞いておくほうが、学生にとっても会社にとっても無駄が少なくなります。選考が進んでから「やはり地元を離れられない」と分かると、どちらの時間も使ったことになります。

## 手順｜面談の進め方

1. **初回はオンラインを基本にする**：学生に移動の負担をかけない。オンラインの進め方は[オンラインで会うときの進め方](/media/ob-mendan-online/)にまとめています
2. **最初の返信で、勤務地をもう一度書く**：オファーで伝えていても、面談の前に改めて示す
3. **面談の前半で、承認の理由と勤務地への考えを聞く**：答えやすい聞き方で
4. **勤務地での暮らしを具体的に話す**：通勤の様子、住む人の多い地域、休日の過ごし方。社員の実例を、特定されない形で
5. **対面の機会は、学生の希望を聞いてから会社が用意する**：交通や宿泊の負担をどう扱うかを、先に示す
6. **結論を出す時期を学生に合わせる**：家族と相談する時間が要る学生もいる

5つ目の交通や宿泊の扱いは、会社によって決め方が違います。どこまで会社が持つかを社内で決め、学生には面談の早い段階で伝えます。あいまいなままだと、学生は対面の機会を遠慮します。

## 聞く順番と、家族の話の扱い

勤務地への考えは、次の順番で聞くと話しやすくなります。

1. **勤務地の地域について、知っていることや印象**
2. **地元を離れることへの考え**：前向きか、迷いがあるか
3. **迷いがあるなら、何が気がかりか**：暮らしの費用、知り合いがいないこと、将来の帰省など
4. **結論を出すまでに、誰かと相談するか**

家族の話は、学生が自分から話すときだけ聞きます。家族の状況や家族の職業を、こちらから尋ねることはしません。選考での配慮すべき事項については、指針などで示された考え方があります。具体的にどこまで聞いてよいかは、公式の案内で確かめ、迷う点は社労士にも確認します。

学生が「家族と相談したい」と言ったら、相談に使える材料を渡します。勤務地での暮らしの様子、住まいについての会社の制度、休暇の取り方などを、短くまとめたものがあると、学生は家族に説明しやすくなります。

### エージェントベストの見解

地方の学生との面談で、契約後によく起きるのは、勤務地の話を後回しにして、選考の最後で学生が迷い始めることです。会社の側は、勤務地の話を早く出すと辞退されるのではと心配し、仕事の魅力を先に伝えようとします。しかし、勤務地への迷いは、面談で触れなくても学生の中にあります。触れないまま選考が進むと、学生は迷いを一人で抱え、内定のあとに家族と話して辞退する、という流れになりがちです。勧めているのは、初回の面談で「勤務地について、いまどう考えていますか」と会社から聞くことです。迷いが話題に上がれば、会社は暮らしの材料を渡せます。迷いが大きい学生とは、早い段階で互いに無理のない判断ができます。勤務地の話を早く出すことは、辞退を増やすのではなく、遅い辞退を減らします。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 初回から対面を求める | 移動の負担で承認しても来ない | 初回はオンラインに |
| 勤務地の話を後回しにする | 選考の最後で迷いが出る | 初回で会社から聞く |
| 交通や宿泊の扱いをあいまいにする | 学生が対面の機会を遠慮する | 社内で決め、早めに示す |
| 家族のことを尋ねる | 学生の不信につながる | 学生が話すときだけ聞く |
| 暮らしの話を抽象的にする | 学生が想像できない | 通勤や休日の様子を具体的に |
| 結論の時期を一律に切る | 家族と相談する時間がない | 学生に合わせる |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 交通や宿泊の扱いを決める | 人事と経営 |
| 日程の調整と、オンラインの案内 | 人事 |
| 初回の面談 | 名義の人 |
| 勤務地での暮らしの話 | 他の地域から移り住んだ社員がいれば、その人 |
| 家族への説明に使える材料の用意 | 人事 |
| 対面の機会の手配 | 人事 |

他の地域から移り住んで働いている社員がいれば、二回目の面談に出てもらうと、学生は暮らしの話を具体的に聞けます。社員の出し方は[OB・OGを面談に出す方法](/media/ob-sd-ob-og/)でも触れています。

### エージェントベストの見解

地方の学生に向けてOfferBoxで送る前に、先に決めておくべきなのは、対面の機会の扱いです。オンラインの面談だけで選考を最後まで進める会社もあれば、最終の前に一度は職場に来てもらう会社もあります。どちらでも構いませんが、決まっていないまま地方の学生にオファーを送ると、面談のたびに「対面にするか、交通をどうするか」をその場で判断することになり、学生ごとに扱いが変わります。扱いが変わると、学生どうしで情報が伝わったときに不信を招きます。送る前に、オンラインで進める範囲、対面にする回、交通や宿泊の扱いの三つを社内で決め、面談の早い段階で全員に同じように伝える。この準備があると、離れた地域の学生にも安心してオファーを広げられます。

## まとめ

- 地方の学生との面談は、勤務地での暮らしまで含めて働く姿を想像してもらう場
- 初回はオンラインにし、勤務地への考えは初回で会社から聞く
- 交通や宿泊の扱いは社内で決め、早い段階で全員に同じように伝える
- 家族のことは学生が話すときだけ聞き、相談に使える材料を渡す
- 他の地域から移り住んだ社員がいれば、暮らしの話を任せる

## よくある質問

### オンラインの面談だけで、学生は入社を決められますか

決められる学生もいれば、一度は職場を見たいという学生もいます。学生の希望を聞き、対面の機会を用意できるようにしておきます。オンラインと対面の分け方は[オンラインと対面の分け方](/media/ob-sd-online-taimen/)で書いています。

### 勤務地への転居に迷っている学生は、選考を続けないほうがよいですか

迷っていること自体は問題ではありません。迷いの中身を聞き、会社が渡せる材料で解けるものかを見ます。材料を渡しても迷いが大きいなら、学生と話し合って判断します。

### 地方に本社がある会社の場合は、考え方が違いますか

都市部の学生を地方の本社に呼ぶ場合も、考え方は同じです。地方に本社がある会社の運用は[地方本社の会社の運用](/media/ob-chihou-honsha/)にまとめています。
