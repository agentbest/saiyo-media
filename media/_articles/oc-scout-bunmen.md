ワンキャリアのスカウト文面は、会社の紹介から始まり、募集の説明が続き、「ぜひエントリーを」で終わるものになりがちです。ところが、受け取る学生は、複数の会社からスカウトを受け取り、体験談で各社の実態を読み比べていて、会社の紹介から始まる文面は最初の数行で閉じられます。**結論から言うと、ワンキャリアのスカウト文面は、「プロフィールの何を読んだか」「この仕事の最初の1年との重なり」「選考の流れと何を見るかの一文」「話す場か選考かの案内」の4段を、短く書きます。会社の説明は企業ページに、条件は掲載に任せ、文面には書きません。体験談を読んだ学生が持っている問い（選考はどうか）に、文面で先に一言答えると、企業ページを読みに行く理由になります。煽り、応募の依頼、条件の羅列、抽象語、選考を急がせる言葉を避けます。** この記事では、文面の役割、4段の構成と書き方、会社の説明を書かない理由、先に答える書き方、避ける言葉、送る前のチェック、型の作り方、分担を整理します。誰に送るかは[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/)で書きました。他媒体の文面は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)と[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)で書きました。

## この作業の目的｜読んで、企業ページと体験談に行き、話す場か選考に来てもらう

ワンキャリアのスカウト文面の役割は、応募させることではなく、「この会社の話を聞いてみよう」と思ってもらい、企業ページと自社の体験談を見に行かせ、話す場か選考に来てもらうことです。

文面で全部を説明しようとすると長くなり、読まれません。文面は入口で、中身は企業ページと体験談にあります。文面に書くのは、「なぜあなたに送ったか」「最初の1年はこうだ」「選考はこう見ている」「次はこれ」の4つだけです。

## 4段の構成

| 段 | 書くこと | 長さ |
|---|---|---|
| 1. 学生時代を読んだ一文 | プロフィールの活動か興味のどこを読んだか。本人の言葉で | 1〜2文 |
| 2. 最初の1年との重なり | その活動や興味が、この仕事の最初の月・最初の1年とどう重なるか。企業ページの「最初の1年」と同じ言葉 | 2〜3文 |
| 3. 選考で何を見るかの一文 | 「選考は〇〇と△△で、学生時代の話を場面で聞きます。詳しくは企業ページに」 | 1〜2文 |
| 4. 話す場か選考かの案内 | 「まず仕事の話を聞く場があります」か「選考にご案内します」か。誰が話すか | 1〜2文 |

署名は、送り主の名前と、入社してまもないなら「入社〇年目」のような近さが分かる一言と、会社名です。会社の説明、事業の説明、募集要項は入れません。

## 1段目｜学生時代を読んだ一文

- **プロフィールの具体的な箇所を挙げる**：「文化祭の企画を三年間続けてこられたと書かれていたのを読んで」
- **本人の言葉をそのまま使う**：「リーダーシップを発揮」に言い換えない
- **大学名や専攻から始めない**：「〇〇大学の△△学部の方に」は、読んでいない証拠
- **褒めない**：「素晴らしい活動」は、読んでいなくても書ける
- **会社名や職種から始めない**：相手の話から始める

学生のプロフィールの箇所ごとの一文の作り方は[新卒向けスカウト文面の型](/media/wt-scout-bunmen-rei-shinsotsu/)で書きました。ワンキャリアでも同じです。

### エージェントベストの見解

相談で最も多い思い込みは、「ワンキャリアの学生は選考に敏感なので、文面では選考の話を避けて、仕事の魅力だけを書くべきだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、選考の話を避けた文面を受け取った学生は、企業ページで選考の流れを探し、無ければ体験談だけで判断します。逆に、文面で「選考は〇〇と△△で、学生時代の話を場面で聞きます」と一言添えた会社は、学生が「この会社は、選考を隠さない」と読み、企業ページを読みに行きます。当社がワンキャリアの文面を整えるとき、他の媒体の型に「選考で何を見るかの一文」を足すのは、この理由です。学生は体験談で選考を読んでいるので、会社の側からも一言添えると、確かめる流れがつながります。

## 2段目｜最初の1年との重なり

学生は職種名から仕事を想像できないので、2段目は「最初の月に何をするか」で書きます。

- **企業ページの「最初の1年」から、一文を取る**：「うちの〇〇職は、最初の月に△△から始めます」
- **その一文と、1段目の活動を重ねる**：「文化祭の企画を続けてこられたあなたなら、その△△が想像できると思い」
- **企業ページと同じ言葉で**：文面で「△△」と書き、企業ページで「□□」と書くと、つながらない
- **重なる点は一つに絞る**：複数書くとテンプレに近づく
- **「経験を活かせる」「即戦力」は書かない**：学生に経験は無い

企業ページの「最初の1年」が無ければ、文面より先に企業ページです。書き方は[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。

## 3段目｜選考で何を見るかの一文

ワンキャリアの文面に特有の段です。

- **段階と、何を見るかを一文で**：「選考は〇〇と△△の二段階で、学生時代の話を場面で聞きます」
- **企業ページの「選考の流れ」と同じ内容で**：文面だけ違うことを書かない
- **「正解はありません」を添えられれば添える**：学生が身構えない
- **「詳しくは企業ページに」で誘導**：文面で流れの全部を書かない
- **時期に関わることは、年度の公表内容と自社の方針を確認して**：この記事では具体は書かない

体験談に「何を見ているか分からなかった」と書かれている会社ほど、この一文が効きます。学生の問いに、会社の側から先に答えます。「何を見るか」の書き方は[本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

## 4段目｜話す場か、選考か

- **どちらかを、曖昧にせず書く**：「まず仕事の話を聞く場があります」か「選考にご案内します」か
- **話す場なら、誰が話すかを**：「入社二年目の〇〇が、仕事の中身を話します。選考ではありません」
- **選考なら、最初の段階で誰と何を話すかを**：「一次は〇〇職の△△と、学生時代の話を」
- **選考との関係は、年度の公表内容と自社の方針を確認して書く**：書いたら守る
- **急がせない**：「〇日までに」「すぐに」は書かない
- **返信の方法を一言**：「このメッセージに返信してもらえれば、日程を調整します」

「話す場と書いて、選考に入れる」は、体験談に書かれます。書いたとおりに進めます。

## 会社の説明を、書かない理由

- **長くなり、1段目が埋もれる**
- **企業ページと重なる**：学生は企業ページを見に行く
- **どの学生にも同じ段落が入り、テンプレに見える**
- **会社の話から始まる文面になる**

会社の説明は企業ページに書き、文面からは「企業ページに書いています」で誘導します。企業ページが整っていなければ、文面で補うのではなく、先に企業ページを整えます。

## 避ける言葉

| 避ける言葉 | 理由 |
|---|---|
| 「ぜひエントリーを」「ご応募ください」 | 応募の依頼。話す段階を飛ばす |
| 「〇日までに」「すぐに」「今すぐ」 | 急がせる。「集まっていない会社」 |
| 「限定」「特別に」「厳選して」 | 煽り。体験談を読み込む学生ほど離れる |
| 「素晴らしい活動」「優秀な学生」 | 褒め言葉。読んでいなくても書ける |
| 「成長」「挑戦」「若手が活躍」 | 抽象語。どの会社も書く |
| 条件の羅列（初任給、勤務地、休日） | 求人票。掲載に任せる |
| 「弊社は〇〇業界で△△な企業で」 | 会社の説明。企業ページに |
| 「経験を活かせる」「即戦力」 | 学生に経験は無い |
| 「〇〇大学の方に」「△△学部の方に」 | 読んでいない証拠 |

## 送る前のチェック

1. **1段目に、プロフィールの具体的な箇所が、本人の言葉であるか**
2. **2段目の「最初の1年」が、企業ページと同じ言葉か**
3. **3段目の「選考で何を見るか」が、企業ページの選考の流れと同じか**
4. **4段目が「話す場」か「選考」か、曖昧でないか。書いたことを守れるか**
5. **会社の説明と条件の羅列が無いか**
6. **避ける言葉が無いか**
7. **時期と選考との関係を、年度の公表内容と自社の方針で確認したか**
8. **スクロールせずに4段が読めるか**
9. **企業ページと自社の体験談が、受け止められる状態か**

1と3と4の3つだけでも、毎回見ます。

## 型の作り方

- **募集ごとに、2段目の「最初の1年」の一文と、3段目と、4段目を用意する**：企業ページから取る
- **1段目は、毎回書く**：相手ごとに違う。型にしない
- **2段目の「重なる点」は、相手ごとに書く**：最初の1年のどこと重なるかは、相手で変わる
- **送る人が複数いるなら、見本を一通作る**：「この形で」と渡す
- **返信が来た文面と、体験談へのスカウトの言及を、台帳に残す**

どこまで相手ごとに変え、どこを型にするかは、[ワンキャリアのスカウトを相手ごとに変える範囲](/media/oc-scout-kojinka/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 募集ごとの型（2段目の一文、3段目、4段目）を作る | 人事と、その職種の責任者と面接に出る人 |
| プロフィールを読み、1段目と重なる点を書く | 読んだ人（人事か、入社してまもない社員） |
| 送る前のチェック | 書いた人 |
| 見本を作って揃える | 人事 |
| 時期と選考との関係を確認する | 人事 |
| 話す場や面接に出る | 入社してまもない社員、面接に出る人 |

運用代行や代理店が支えられるのは、4段の型、募集ごとの型の作成、避ける言葉のチェック、見本の作成までで、相手の一文と重なる点を書くこと、送ること、時期の確認、話す場と面接は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がワンキャリアのスカウト文面を支えるとき、4段の型、募集ごとの2段目から4段目、避ける言葉のチェック、見本は当社が出せます。ただし、1段目の「プロフィールの何を読んだか」と、3段目の「選考で何を見るか」の中身は、社内にしかありません。前者はプロフィールを読んだ人の言葉で、後者は面接に出る人が言葉にしたものです。当社が3段目を「学生時代の話を場面で聞きます」と書いても、面接に出る人が実際にそう聞かなければ、体験談に「スカウトに書いてあったことと違った」と書かれます。当社が最初にお伝えするのは、「型は当社、一文は社内、選考の中身は面接に出る人」の分担です。型があれば、社内の人が書くのは数文で済みます。

## まとめ

- ワンキャリアのスカウト文面は、学生時代を読んだ一文→最初の1年との重なり→選考で何を見るかの一文→話す場か選考か、の4段を短く。会社の説明と条件は書かない
- 1段目は本人の言葉で、大学名や専攻から始めない。2段目は企業ページの「最初の1年」と同じ言葉で、重なる点を一つ
- 3段目は、体験談を読んだ学生の問いに先に答える。企業ページの選考の流れと同じ内容で、「正解はありません」を添える
- 4段目は、話す場か選考かを曖昧にせず、誰が話すかを書き、急がせず、書いたら守る
- 煽り、応募の依頼、急がせる言葉、条件の羅列、抽象語、大学名で始める、を避ける。型は募集ごとに、1段目と重なる点だけ毎回書く

## よくある質問

### 文面が短いと、熱意が伝わらないのではないですか

熱意は、長さではなく、「あなたを読んだ」という一文で伝わります。長い文面は、会社の説明が長いだけで、学生には「誰にでも送っている」と読まれます。短い文面で、プロフィールの具体的な箇所を挙げたもののほうが、「自分に送っている」と伝わります。

### 選考の話を文面に入れると、学生が身構えませんか

「選考は〇〇と△△で、学生時代の話を場面で聞きます。正解はありません」のように、何を見るかを添えると、身構えるより準備の方向が分かります。避けるのは、選考を急がせる言葉と、「エントリーを」の依頼です。選考の流れを隠すほうが、体験談を読んだ学生には「隠している」と見えます。

### ワンキャリアのスカウト文面は、御社に相談できますか

できます。当社は、4段の型、募集ごとの型の作成、避ける言葉のチェック、見本の作成を支えられます。相手の一文と重なる点を書くこと、送ること、時期の確認、話す場と面接は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
