新卒を5名採る会社が媒体を選ぶとき、最初にぶつかるのは「三名までは一人ずつ採れていたのに、五名になった途端『母集団を大きくしないと』と数を集める型に飛び、承認や応募は増えたのに返せず、面談まで来る数が前より減る」という問題です。**結論から言うと、新卒5名は「一人ずつ採る」が成り立つ上限で、数を集める型に飛ぶ人数ではなく、媒体は一つを主軸に、職種が二つなら文面と名義を分け、承認率ではなく一人ひとりの段で見て、一人の辞退が計画の二割になる前提で内定後を設計します。** 1〜3名の会社の選び方は[新卒1〜3名を採る会社の採用媒体の選び方](/media/hikaku-shinsotsu-1-3-erabikata/)で書きました。この記事は5名に絞って、3名との違いと、10名に向けて何を残すかを書きます。

## 新卒5名の会社に、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 採る人数が5名 | 一人ずつ採れば届く人数。ただし一人の辞退が計画の二割 | 一人に深く届く型のまま、送る数を増やす。[新卒5名を採る会社のOfferBox運用](/media/ob-shinsotsu-5-unyou/) |
| 職種が二つになることが多い | 一つの文面と名義で二つの職種を採ろうとして、片方に偏る | 職種ごとに文面と名義を分ける。媒体は増やさない |
| 人事が一人か、兼務 | 返す時間と面談の時間が、五名分で本業を押し始める | 主軸を一つに。絞る作業を外に出せる型を |
| 「母集団」の言葉が入ってくる | 数を集める型に飛び、返せない数が来る | 五名は、数で見る人数ではない |
| 先輩の新卒が数人いる | 職種ごとに名義にできる先輩がいる | 先輩を名義に、職種ごとに |
| 内定辞退で計画が崩れる | 一人の辞退で四名。二人で三名 | 内定後の設計を先に。同期がいる安心を材料に |

## 判断軸を、5名の会社に当てる

| 軸 | 5名の会社での見方 |
|---|---|
| 対象（誰に届くか） | 職種ごとに「この仕事を、この先輩の下で」に合う学生に絞る。二つの職種を一つの条件で絞らない |
| 型（送るか、来るか、比べられるか） | 送る型は、送る数を五名分に増やしても一人ずつ書ける。来る型は、職種ごとの記事を書けるかで届く。比べられる型は、知名度と体験談があれば五名から現実的になるが、主軸にするには早いことが多い |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。五名分の費用を一つの媒体に集める。[年間予算百万円前後の採用媒体の組み方](/media/hikaku-yosan-100/) |
| 運用工数（誰の時間が要るか） | 承認や応募に返す時間が五名分になる。面談の枠を職種ごとに先輩に持ってもらう。絞る作業は外に出せる型で |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。5名の会社では、「対象」を職種ごとに分けることと、「型」で数を集める型に飛ばないことが、3名との違いです。

### エージェントベストの見解

相談で最も多い思い込みは、「五名になったら、母集団を大きくする型に変えないと足りない」というものです。当社は3媒体すべての販売パートナーとして、5名前後の会社の相談を受けますが、三名まで一人ずつ採れていた会社が、五名で数を集める型に変えて、面談まで来る数が前より減った例を多く見ています。数が来ると、返す時間が本業を押し、返信が遅れ、面談の枠が足りず、一人ひとりに「なぜあなたに」を書けなくなります。五名は、一人ずつ採る型のまま、送る数と面談の枠を増やせば届く人数です。逆に、一人ずつ採る型のまま、職種ごとに先輩を名義にして文面を分けた会社は、三名のときと同じ面談の質で五名に届きます。当社が最初にお願いするのは、「母集団」の言葉を外し、「一人ずつ採る型で、送る数と面談の枠を五名分にできるか」を見ることです。できないなら、数を集める型ではなく、絞る作業を外に出すか、面談の枠を先輩に分けます。

## 学生が、確かめること

- **同期が何人か**：「同期は四人」は、一人で入る不安を減らす。書く
- **職種ごとの先輩の実態**：二つの職種があるなら、それぞれの先輩が最初の年に何をしたか
- **何を任されるか**：職種ごとに「最初の年に〇〇を」。「総合職」の一語で済ませない
- **誰が見るか**：職種ごとに誰が横につくか。その人が面談に出るか
- **配属の決まり方**：二つの職種があるなら、いつ、どう決まるか。募集で分けているなら、分けていると
- **内定後の連絡と、同期に会える時期**：内定者同士が会える日があるか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 一人ずつ採る型を続けたい。職種ごとに先輩を名義にできる。担当の時間が限られる | 企業から送る型（OfferBox） | 送る数を五名分に増やしても一人ずつ書け、絞る作業を外に出せる |
| 職種ごとに先輩が記事を書ける。通年で採る | 通年で記事を置く型（Wantedly） | 職種ごとの記事で、先輩の実態を読んでもらえる |
| 知名度と体験談があり、事務や総合職で知られている | 学生が並べて比べる場（ワンキャリア） | 五名から現実的になるが、主軸にするには早いことが多い。補助から |
| 職種が二つあるのに、文面と名義が一つ | どれも先ではない | 分けてから |
| 内定後の設計が無い | どれも先ではない | 一人の辞退が二割。先に決める |

どれか一つが正解ではなく、先輩を名義にできるか、書けるか、知名度で、先に検討するものが変わります。

## 組み合わせ

- **媒体は一つを主軸に、職種は二つまで分ける**：媒体を二つにするより、一つの媒体で職種を分ける。[複数の媒体を同時に使うときの考え方](/media/hikaku-fukusuu-baitai/)
- **送る型と記事を置く型を組み合わせるなら、職種で役割を分ける**：送る型で職種Aを、記事で職種Bを、ではなく、両方の職種を送る型で送り、記事で「なぜ」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **比べられる場を足すなら、翌年から**：五名の実績と体験談ができてから。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **代行と組み合わせるなら、絞る作業と文面の下書きを**：面談と名義は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「総合職」ではなく、職種ごとの先輩と最初の年

- **「総合職5名」と書かない**：「〇〇の職種に△名、□□の職種に◇名」。学生は自分の職種で読む
- **職種ごとの先輩の実態を、盛らずに**：「〇〇の職種で去年入った△△は、最初の年に□□をした」。名義にする先輩本人の話
- **同期の人数を、書く**：「同期は四人。職種は二つ」。一人で入る不安を減らす
- **配属の決まり方を、一文で**：募集で分けているなら「募集の職種のまま。入社後の変更は〇〇のとき」
- **内定後の連絡と、同期に会える日を、先に書く**：「内定から入社まで〇か月に一度。□月に内定者が集まる日がある」
- **数値は自社の実態で**：この記事では書かない

## 社内の分担

| 作業 | 誰が |
|---|---|
| 職種ごとの人数、任せる仕事、名義の先輩、内定後の設計を決める | 経営者か採用の責任者 |
| 媒体を選ぶ | 先輩を名義にできるか、担当の時間で決める |
| 承認や応募に返す | 人事。〇日以内と決める。絞る作業は外に出してもよい |
| 職種ごとの文面と面談 | 名義の先輩。人事が下書き、先輩が直す |
| 内定後の連絡と、内定者が集まる日 | 人事と先輩。決めた間隔で |
| 段ごとの数の記録 | 人事。承認率ではなく、送った・返った・面談した・内定した・残った |

運用代行や代理店が支えられるのは、媒体の選び方、絞る作業、文面の下書き、段ごとの記録の型づくりまでで、職種ごとの人数の決定、名義の先輩、面談、内定後の連絡は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

新卒5名の会社が数字を読むときに先にお伝えしているのは、「承認率や送信数の平均を見ても、五名では意味がない」ということです。五名の採用は、一人ひとりの段（送った・返った・面談した・内定した・残った）で見る人数で、承認率の一割の違いは、一人の返信の有無で変わります。当社が案内するのは、五名分の一人ひとりを表にして、どの段で止まったかを人ごとに見ることです。面談まで来ない人が多いなら文面か名義、面談の後に来ない人が多いなら面談に出る人か任せる仕事、内定の後に落ちる人が多いなら内定後の連絡です。五名では、段ごとの数が「二人」「三人」で、率にすると大きく揺れますが、人ごとに見れば直す場所が分かります。率で見始めるのは、十名を超えて、職種ごとに段の数が十を超えてからです。五名で率を見て媒体を変える会社は、直す場所を見ずに媒体を変えています。[採用の段ごとの数の読み方](/media/kh-boshudan-funnel/)

## まとめ

- 新卒5名は「一人ずつ採る」が成り立つ上限。数を集める型に飛ばず、送る数と面談の枠を五名分にする
- 媒体は一つを主軸に、職種が二つなら文面と名義を分ける。媒体を増やすより職種を分ける
- 送る型（OfferBox）は職種ごとの先輩を名義に、記事を置く型（Wantedly）は職種ごとに書ける会社に、比べられる場（ワンキャリア）は知名度と体験談があれば補助から
- 学生は「同期の人数・職種ごとの先輩の実態・何を任されるか・誰が見るか・配属の決まり方・内定後の連絡」を確かめる。「総合職5名」と書かない
- 承認率ではなく一人ひとりの段で見て、一人の辞退が計画の二割になる前提で内定後の連絡と内定者が集まる日を先に決める

## よくある質問

### 五名を採るのに、一つの媒体で足りますか

一人ずつ採る型で、送る数と面談の枠を五名分にできれば足ります。足りなくなるのは、媒体の数ではなく、返す時間と面談の枠です。媒体を二つにすると、返す人が二つ分要り、面談の枠は増えません。一つの媒体で職種を分け、職種ごとに先輩が面談の枠を持つ形のほうが、五名に届きます。翌年に五名の実績と体験談ができてから、二つ目を足します。

### 職種が三つあります。どうすればよいですか

五名で三つの職種は、一つの職種に一人か二人で、「ゼロか一か」の採用が三つ並ぶ形です。三つを同時に回すと、返す時間と面談の枠が足りません。最初の年は二つに絞り、三つ目は翌年に回すか、三つ目を中途で採ることを検討します。三つとも新卒で採るなら、名義の先輩を三人立て、面談の枠を三人で分け、人事は返す作業と段の記録に専念します。

### 新卒5名の会社の媒体選びは、御社に相談できますか

できます。当社は、媒体の選び方、絞る作業、文面の下書き、段ごとの記録の型づくりを支えられます。職種ごとの人数の決定、名義の先輩、面談、内定後の連絡は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、5名前後の会社の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
