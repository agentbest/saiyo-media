ワンキャリア経由で内定を出した学生と、そのあとどのくらいの頻度で連絡を取ればよいか。多すぎると負担になり、少なすぎると不安にさせる。採用担当者がよく迷う点です。**結論から言うと、内定者との連絡は、頻度を増やすことより、内定から入社までの予定を最初に渡し、窓口を一つにすることが基本です。** 予定が分かっていれば、学生は次の連絡がいつ来るかを知っていて、連絡の間が空いても不安になりにくくなります。この記事では、時期ごとの連絡の中身、連絡する人の分け方、やりがちな失敗、社内の分担を整理します。

## この作業の目的｜内定から入社までの「空白」を不安にしない

内定から入社までは、長い期間になることが多くあります。その間、学生は学業を続けながら、家族や友人と話し、ほかの会社の話を耳にします。連絡がない期間が長いと、「会社は自分のことを忘れていないか」「入社してから何をするのか」が分からないまま時間が過ぎます。

連絡の目的は、つなぎ止めるために接触を増やすことではありません。**学生が入社までの道筋を知っていて、聞きたいときに聞ける状態を作ること**です。ワンキャリアでは、内定後の対応も体験談やクチコミに書かれることがあり、次の年度の学生がそれを読みます。内定後の印象が書かれる仕組みは[クチコミに書かれる内定後の印象](/media/oc-kuchikomi-naitei/)で整理しています。

## 時期ごとの連絡の中身

| 時期 | 連絡の中身 | 連絡の形 |
|---|---|---|
| 内定を伝えるとき | 内定の通知、条件、承諾の期限、その後の予定の全体 | 電話か面談で伝え、文面でも送る |
| 承諾を待つあいだ | 質問への回答、社員と話す場の案内 | 学生の求めに応じて |
| 承諾の直後 | お礼、入社までの予定の詳細、窓口の連絡先 | 文面 |
| 承諾から入社までの間 | 予定どおりの案内（懇親の場、書類、研修など） | 予定に沿って |
| 入社の直前 | 初日の流れ、持ち物、配属の見通し | 文面と、必要なら面談 |

この表の要は、最初の行の「その後の予定の全体」です。内定を伝えるときに、承諾の期限だけでなく、承諾後にどんな連絡や場があるかを一枚で渡します。日付が決まっていないものは「〇月頃」と書き、決まったら知らせると添えます。

条件の伝え方には、法令で定められた項目があります。何をどの時点で書面などで示すかは、社会保険労務士や公式の案内で確認してから、文面に反映してください。

### エージェントベストの見解

内定後の連絡で相談が多いのは、「承諾をもらうまで頻繁に連絡し、承諾後は急に連絡が減る」という形です。学生の側から見ると、承諾した途端に会社の態度が変わったように感じられます。当社は媒体で採る支援と人材紹介の両方をしていますが、紹介で入社する候補者の場合も、承諾から入社までの連絡が途切れた会社ほど、入社前の不安を口にする傾向があります。勧めているのは、承諾の前と後で連絡の量を変えず、「承諾の前は質問に答える連絡」「承諾の後は予定を伝える連絡」と中身を切り替える考え方です。量を一定にしようとすると無理が出ますが、中身を切り替えるだけなら、予定表に沿って連絡するだけで済みます。予定表を作るときに、承諾の後の連絡の回数を先に書き出しておくと、空白の期間が目で見えます。

## 連絡する人の分け方

内定者と連絡を取る人が多いと、学生は誰に何を聞けばよいか分からなくなります。窓口は一つにし、そのうえで役割を分けます。

- **窓口（人事）**：予定の案内、書類、条件に関わる質問。学生からの連絡は、まずここに集まるようにします
- **社員（現場の先輩）**：仕事や職場の雰囲気についての話。人事が場を設け、社員はその場で話します
- **上司になる人（配属先の責任者）**：配属の見通しや、入社後の最初の仕事の話。入社の直前に一度
- **経営者**：内定式や懇親の場で、会社の方向を話す

社員と学生が個別に連絡を取り合う形にすると、人事が状況を把握できなくなります。社員と話す場は人事が設け、話した内容を人事に一言返してもらう決まりにしておくと、窓口が一つのまま保てます。内定者フォローの全体像は[内定者フォローの基本](/media/kh-naitei-follow-kihon/)、内定後の連絡文の型は[内定後の連絡](/media/kh-rn-naitei-go/)で書いています。

## やりがちな失敗

| 失敗 | 起きること | 避け方 |
|---|---|---|
| 予定を小出しにする | 学生が次の連絡を待ち続ける | 内定を伝えるときに全体を渡す |
| 連絡する人がばらばら | 同じことを何度も聞かれ、答えが食い違う | 窓口を人事に一つにする |
| 承諾後に連絡が減る | 「承諾したら放っておかれた」と感じる | 承諾後は予定の連絡に切り替える |
| 懇親の場を詰め込みすぎる | 学業との両立の負担になる | 参加の任意を明確にし、回数を絞る |
| 返信を急かす | 圧力と受け止められる | 期限は最初に伝え、その前は質問への回答にとどめる |

内定の承諾の期限や返事の求め方は、学生が負担に感じやすい点です。期限の考え方は[承諾の期限の決め方](/media/kh-naitei-shoudaku-kigen/)で整理しています。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 内定から入社までの予定表を作る | 人事 |
| 内定の通知と条件の説明 | 人事（必要に応じて上司になる人も同席） |
| 条件の伝え方の確認 | 人事（社労士・公式の案内で確認） |
| 社員と話す場の設定 | 人事 |
| 社員と話す場での対応 | 現場の先輩 |
| 配属の見通しの説明 | 配属先の責任者 |
| 連絡の記録 | 人事 |

### エージェントベストの見解

ワンキャリアで内定を出す会社に、先に決めておくことを勧めているのが「内定後の連絡を記録する場所」です。選考中の記録は残していても、内定後の連絡は担当者のメールの中だけ、という会社は少なくありません。記録がないと、担当者が休んだときや交代したときに、学生に何を伝えたかが分からず、同じことを二度伝えたり、約束した連絡を忘れたりします。内定後の連絡は、選考の記録と同じ場所に、日付と内容を一行で残します。さらに、学生から出た質問も一行ずつ残しておくと、次の年度の予定表に「この時期にこの質問が出やすい」と先回りして書き込めます。内定後の連絡は、一年で終わる作業ではなく、翌年度の内定者への対応の材料になります。

## まとめ

- 内定者との連絡は、頻度より、内定から入社までの予定を最初に渡すことが基本
- 承諾の前は質問に答える連絡、承諾の後は予定を伝える連絡と、中身を切り替える
- 窓口は人事に一つにし、社員や上司になる人と話す場は人事が設ける
- 条件の伝え方には法令で定められた項目があるので、社労士・公式の案内で確認する
- 内定後の連絡と質問は記録し、翌年度の予定表の材料にする

## よくある質問

### 内定者には月に何回くらい連絡するのがよいですか

決まった回数はなく、会社や時期によって異なります。回数を決めるより、予定表に沿って連絡し、予定のない期間が長く続かないかを確かめるほうが、学生の不安を減らせます。

### 内定者どうしの交流の場は必要ですか

会社によります。同期になる人と話せる場を求める学生もいれば、負担に感じる学生もいます。設けるなら、参加は任意であることを明確にし、学業の時期と重ならないようにします。

### 内定辞退の連絡が来たら、どう対応すればよいですか

引き止めるより、理由を一言だけ聞き、お礼を伝えて終えます。聞いた理由は記録し、翌年度の選考や連絡の見直しに使います。辞退の原因の切り分けは[ワンキャリア経由の内定辞退](/media/oc-naitei-jitai/)で整理しています。
