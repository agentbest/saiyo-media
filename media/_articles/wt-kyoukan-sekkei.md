Wantedlyは「共感で人が集まる」と言われます。ところが、「共感を集めよう」として書かれた記事は、想いや情熱の言葉が並び、候補者には届きません。**結論から言うと、Wantedlyでの共感は「感情に訴えて感動させる」ことではなく、「この会社は、なぜこれをやっているのか」を場面で見せて、候補者が「自分もそのなぜに乗れるか」を自分で判断できる状態を作ることです。共感は、会社が起こすものではなく、候補者の側で起きるものです。会社にできるのは、判断の材料を、飾らずに置くことだけです。** この記事では、共感の意味、共感が生まれる3段、会社ページ・募集記事・ストーリーの役割分担、共感を壊すもの、確かめ方、向く会社と向かない会社、分担を整理します。共感型と条件型の媒体の違いは[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。この記事は、Wantedlyの中で共感をどう作るかの話です。

## この作業の目的｜候補者が「自分で判断できる」状態を作る

「共感」という言葉は、採用の場面では2つの意味で使われます。

- **感動させる**：会社の想いを熱く語り、候補者の感情を動かす
- **判断できる**：会社の「なぜ」を具体的に見せ、候補者が「自分はこれに乗れるか」を判断できる

Wantedlyで起きる共感は、後者です。候補者は、会社ページと募集記事とストーリーを読み、「この会社がやっていること、その理由、そこで働く人の様子」を見て、「ここなら自分も」と思うか、思わないかを決めます。

感動させようとする記事は、抽象語と情熱の言葉が並び、「何をやっている会社か」が分かりません。判断の材料が無いので、共感も起きません。共感の設計とは、「判断の材料を、どの順で、どこに置くか」の設計です。

## 共感が生まれる3段

候補者の側で共感が起きるまでには、3つの段があります。

| 段 | 候補者が知ること | 置く場所 |
|---|---|---|
| 1. 会社のなぜ | この会社は、何を、なぜやっているのか | 会社ページ（ミッション、なにをやっているか、なぜやるのか） |
| 2. 募集のなぜ | この募集は、なぜ今、この人を探しているのか。入ったら何をやるのか | 募集記事（なにを・なぜ・どうやって） |
| 3. 場面 | そこで働く人は、実際にどう働き、何に迷い、どう決めているのか | ストーリー（1本に1つの場面） |

1だけでは、「良さそうな会社」で終わります。2があると、「自分に関係がある」になります。3があると、「そこで働く自分が想像できる」になります。共感は、3まで揃って起きます。

多くの会社が1だけを書き、「共感が集まらない」と言います。1は入口で、共感が起きるのは3です。

### エージェントベストの見解

相談で最も多い思い込みは、「共感を集めるには、想いを強く、熱く書くべきだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、候補者が面談で「共感した」と言うとき、挙がるのは想いの言葉ではなく、場面です。「〇〇を断ったという話」「新規事業を一度止めた理由」「入社1年目の意見で決め方が変わった会議」。候補者は、会社が何を言ったかではなく、会社が何をしたかに共感します。想いを強く書くほど、「何をしたか」が薄れ、どの会社にも書いてある言葉になります。当社が共感の設計を支えるときに最初にやるのは、想いの言葉を減らし、最近の判断の場面を足すことです。共感は、熱量ではなく、具体で起きます。

## 会社ページ・募集記事・ストーリーの役割分担

3段を、3つの場所に分けて置きます。同じことを3か所に書くと、どこも薄くなります。

| 場所 | 書くこと | 書かないこと |
|---|---|---|
| 会社ページ | なにをやっているか、なぜやるのか、どうやっているか、価値観を場面で | 募集の詳細、社員個人の話 |
| 募集記事 | この募集でなにをやるか、なぜ今探すのか、どうやって働くか、一緒に働く人 | 会社の理念の再掲、会社紹介 |
| ストーリー | 1本に1つの場面。迷い、失敗、判断、本人の言葉 | 会社紹介、教訓、決意 |

それぞれの書き方は、[会社ページの基本](/media/wt-kaisha-page-kihon/)、[募集記事の基本](/media/wt-boshu-kihon/)、[ストーリーの基本](/media/wt-story-kihon/)で書きました。

3つの場所は、つながっています。募集記事を読んだ候補者は会社ページを見に行き、会社ページを見た候補者はストーリーを読み、ストーリーを読んだ候補者は募集記事に戻ります。どこから入っても、他の2つにたどり着けるよう、それぞれから誘導します。

## 共感を壊すもの

判断の材料を置いても、次のものがあると共感は起きません。

| 壊すもの | なぜ壊れるか | 直し方 |
|---|---|---|
| ポエム（想い・情熱・熱量の言葉） | 何をしているか分からない | 最近の判断の場面に置き換える |
| 抽象語（成長・挑戦・アットホーム・風通し） | どの会社にも書いてある | 場面に置き換える。[価値観を場面で書く方法](/media/wt-kaisha-page-value/) |
| 良いことだけ | 建前と分かる | うまくいかなかったこと、迷ったことを1つ入れる |
| 大きすぎる言葉（世界を変える・業界を変える） | 日々の仕事とつながらない | 誰のどんな困りごとを、どう変えるかに |
| 会社の側からの言葉（わが社は・弊社の強み） | 候補者に向いていない | 候補者が知りたいことから |
| 3か所に同じことを書く | どこも薄い | 役割を分ける |
| 会社ページが古い | 「いまの会社」ではないと分かる | 更新し続ける。[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/) |
| 面談で会社ページと違うことを言う | 読んで来た候補者の信用が消える | 書いたことと、話すことを揃える |

最後の「面談で違うことを言う」は、見落とされやすい壊し方です。記事で「意見が割れたら1年目でも言える」と書き、面談で「まずは言われたことをやってほしい」と言えば、共感は消えます。書いたことは、面談に出る人が読んでおきます。

## 共感の確かめ方

共感が起きているかは、閲覧や応募の数では分かりません。

- **面談で「どこを読んで来ましたか」「どこに惹かれましたか」と聞く**：挙がるのが場面なら、共感が起きている。「雰囲気が良さそう」しか出ないなら、材料が足りない
- **挙がった場面を、書いた人と話した人に戻す**：次の記事の材料になる
- **挙がらない場所を見る**：会社ページしか挙がらないなら、募集記事とストーリーが薄い
- **「読んでいない」が続くなら、誘導と更新を見直す**：読まれない記事は、共感の材料にならない
- **候補者の言葉で、記事を直す**：候補者が惹かれた場面を、もっと具体的に。惹かれなかった部分を減らす

「面談で聞く」が、共感の設計を続ける唯一の手段です。聞かなければ、何が届いているか分からず、想いの言葉を増やす方向に戻ります。

## 向く会社と、向かない会社

共感の設計は、どの会社にも同じように効くわけではありません。

| 向く会社 | 向かない（先に別のことをする）会社 |
|---|---|
| 「なぜやるか」を、代表と社員が同じ言葉で言える | 「なぜ」が代表の中にしか無く、社員に伝わっていない |
| 最近の判断や迷いを、外に書いてよい | 判断の場面を外に出せない |
| 条件（給与・待遇）だけで選ばれると困る | 条件で十分に集まっている |
| 面談に出る人が、書いたことを読んでいる | 面談が人事だけで、現場が記事を知らない |
| 会社ページを更新し続けられる | 一度書いて放置になる |

向かない会社は、Wantedlyが合わないというより、先に社内で「なぜ」を揃える必要があります。代表と社員が「なぜ」を同じ言葉で言えない状態で書くと、会社ページと面談がずれます。先に社内で揃え、その言葉で書くのが順番です。条件で選ばれる職種や、条件で十分に集まっている会社は、条件型の媒体のほうが早いことがあります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 会社の「なぜ」を言葉にする | 代表と、社員数人（人事が聞いて書く） |
| 3段が揃っているかを見る | 人事 |
| 各場所の役割を分けて書く | 人事（話す人から聞いて） |
| 共感を壊すものを取り除く | 人事と、別の1人 |
| 面談で「どこに惹かれたか」を聞く | 面談に出る人 |
| 書いたことと話すことを揃える | 面談に出る人が記事を読む |
| 候補者の言葉で記事を直す | 人事 |

運用代行や代理店が支えられるのは、3段の整理、役割分担の設計、壊すものの指摘、確かめ方の型、候補者の言葉を記事に反映する案までで、「なぜ」を言葉にすること、面談で聞くこと、書いたことを面談で守ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの共感の設計を支えるとき、3段の整理、各場所の役割分担、壊すものの指摘、面談で聞く型、候補者の言葉を記事に戻す案は当社が出せます。ただし、「なぜやるか」を代表と社員が同じ言葉で言えるようにすることだけは、外部の当社にはできません。当社が言葉を作れば、それは当社の言葉で、面談で社員が話す言葉とずれます。当社が共感の設計で最初にお願いするのは、代表と社員数人に、人事が「なぜこの会社があるのか」「最近、なぜあの判断をしたのか」を聞くことです。聞いた言葉が揃っていれば、当社が整えられます。揃っていなければ、先に社内で揃えるのが順番で、当社はその聞き方を支えます。共感は、外注できる文章ではなく、社内で揃った「なぜ」から生まれます。

## まとめ

- Wantedlyの共感は「感動させる」ことではなく、「なぜ」を場面で見せて候補者が自分で判断できる状態を作ること
- 共感は3段で起きる。会社のなぜ（会社ページ）→募集のなぜ（募集記事）→場面（ストーリー）。1だけでは起きない
- 3か所に同じことを書かず、役割を分けて、互いに誘導する
- ポエム、抽象語、良いことだけ、大きすぎる言葉、面談で違うことを言う、が共感を壊す
- 面談で「どこに惹かれたか」を聞いて確かめ、候補者の言葉で記事を直す。「なぜ」が社内で揃っていない会社は、先に揃える

## よくある質問

### 想いを書かないと、共感は集まらないのではないですか

想いは、言葉ではなく判断の場面で伝わります。「〇〇を大切にしています」より、「〇〇のために、△△の依頼を断りました」のほうが、想いが伝わります。想いの言葉を減らし、最近の判断の場面を足すと、共感は増えます。

### 共感で集まった人は、条件を気にしないのですか

気にします。共感は「話を聞きに行く」までの動機で、入社の判断には条件も入ります。共感型の媒体でも、募集記事に条件を書き、面談で正直に伝えます。共感で来た候補者に条件を隠すと、面談で信用が消えます。条件の書き方は[募集記事の条件の書き方](/media/wt-boshu-joukenn/)で書きました。

### 共感の設計は、御社に相談できますか

できます。当社は、3段の整理、役割分担、壊すものの指摘、面談で聞く型、候補者の言葉を記事に戻す案を支えられます。「なぜ」を社内で揃えることと、面談で聞くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
