人事が一人の会社で、Wantedlyのスカウトを回そうとすると、読む・書く・送る・返す・面談・台帳・見直しの全部が一人に乗り、数週間で止まります。**結論から言うと、人事一人で回すなら、募集を一つに絞り、週の枠を一つ決め、読める数だけ送り、型は一つにし、現場には「いま何をしていて何を決めようとしているか」の一文と、書いた文面の確認と、面談だけを頼みます。返信対応は毎日の短い時間に固定し、台帳は項目を減らし、見直しは月に一度だけにします。絞り込み・型・集計は外に出せます。止まりそうなサインが出たら、止める前に減らします。** この記事では、一人で全部やって止まる形、絞り方、現場に頼む最小限、返信対応の固定、台帳の簡略化、見直しの頻度、外に出せる作業、止まりそうなサイン、分担を整理します。チームで回す場合は[スカウトをチームで回す方法](/media/wt-scout-team/)で書きました。人事一人でのOfferBox運用は[人事1人でOfferBoxを回す方法](/media/ob-hitori-jinji/)で書きましたが、考え方は同じです。

## この作業の目的｜止まらない大きさで、続ける

一人で回す目的は、多く送ることではなく、「止まらない大きさで続けること」です。

一人で回す運用は、続いていれば、台帳が溜まり、型が良くなり、面談まで進む相手が出ます。止まると、全部が消えます。目的は、続く大きさを最初に決め、その大きさを守ることです。

## 一人で全部やって、止まる形

| 全部やる | 何が起きるか |
|---|---|
| 複数の募集を同時に送る | 読む対象が増え、読めなくなる。テンプレになる |
| 現場に頼まず、自分で仕事の具体を書く | 文面が薄い。面談で自分が出て、仕事の話ができない |
| 返信を、来るたびに返す | 一日中、通知に振り回される。他の業務が止まる |
| 台帳の項目を多くする | 更新が追いつかず、台帳が古くなる |
| 毎週、見直して直す | 何が効いたか分からず、直すこと自体が負担になる |
| 上限を使い切ろうとする | 読まずに送り、返信が来ず、疲れる |
| 面談に全部自分が出る | 現場の話ができず、面談枠が自分の予定で決まる |

最も多いのは、最初の「複数の募集を同時に」です。一人で回すのに、募集の数が多いと、どれも中途半端になります。

## 一人で回すための絞り方

| 絞るもの | 絞り方 |
|---|---|
| 募集 | 一つ。最も急ぎで、募集記事が整っていて、現場の話す人がいる募集 |
| 週の枠 | 一つ。週に一度、まとめて読んで書いて送る時間。予定に入れる |
| 送る数 | その枠で読める数。数を先に決めない |
| 型 | 一つ。その募集の型だけ |
| 絞り込みの条件 | 狭く。読む対象を少なく。[スカウト対象の絞り方](/media/wt-scout-target/) |
| 面談枠 | 現場の話す人が出られる数。それを超えて送らない |

「募集は一つ」が、最も効く絞り方です。一つの募集に集中すれば、型も一つ、読む観点も一つ、話す人も一人で、負担が定まります。続いたら、二つ目を足します。

### エージェントベストの見解

相談で最も多い思い込みは、「人事一人だから、現場に頼まずに自分で全部やるしかない」というものです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、人事一人で回している会社で続いているのは、現場に「最小限だけ」頼んでいる会社です。頼んでいるのは、「いま何をしていて、何を決めようとしているか」の一文と、書いた文面を送る前に読んでもらうことと、面談に出ることの三つだけで、それ以外は人事が引き受けています。現場の負担は月に数十分で、それで文面に仕事の具体が入り、面談で現場の話ができます。当社が人事一人の会社の相談を受けるとき、最初にお願いするのは、「現場に頼まない」ではなく、「現場に頼む範囲を三つに絞る」ことです。三つなら、忙しい現場でも引き受けます。

## 現場に頼む最小限

| 頼むこと | いつ | 時間 |
|---|---|---|
| 「いま何をしていて、何を決めようとしているか」の一文 | 型を作るとき（募集ごとに一度） | 短い |
| 書いた文面の確認 | 送る前（まとめて） | 短い |
| 面談に出る | 返信が来て日程が決まったとき | 面談の時間 |

「読んで書く」は、人事が行います。現場の一文を型の2段目に入れ、相手のプロフィールを読んで1段目と重なる点を人事が書き、現場が確認して、現場の名前で送ります。名前だけ借りる形にしない条件は、現場が読んで了承することです。考え方は[スカウトを現場社員の名前で送る方法](/media/wt-scout-genba/)で書きました。

面談は、現場の人が出ます。人事だけが出る面談は、仕事の話ができません。人事は進行と最後の案内だけです。

## 返信対応を、毎日の短い時間に固定する

返信は、来るたびに返さず、毎日決まった時間にまとめて返します。

- **朝と夕方の二回、決まった時間に通知と台帳を見る**：それ以外は見ない
- **翌日までに返す、を守れる回数で**：二回なら、どの返信も翌日までに返せる
- **返信の型を用意する**：前向き・質問・条件・断り。毎回書かない。[返信が来たあとの進め方](/media/wt-scout-henshin-go/)
- **日程の候補は、現場の面談枠から先に決めておく**：返信が来てから現場に聞かない
- **通知は、その時間にだけ見る設定にできるなら、する**：仕様は管理画面で確認

「来るたびに返す」と、一日中振り回され、他の業務が止まります。「決まった時間に」で、返信対応は毎日の短い時間に収まります。

## 台帳は、項目を減らす

一人で回すなら、台帳の項目は最小限にします。

| 残す項目 | 減らす項目 |
|---|---|
| 相手、募集、送った日 | 詳しいメモ |
| 送った一文（相手の一文） | 返信の内容の型の細かい分類 |
| 返信の有無 | 面談後の詳しい記録 |
| 段（新規・返信済み・面談予定・面談済み・選考へ・保留・終了） | |
| 次の連絡日 | |

「次の連絡日」だけは減らしません。これが無いと、放置が起きます。台帳の型は[応募・スカウトの管理の仕方](/media/wt-scout-oubo-kanri/)で書きましたが、一人なら項目を半分にします。

## 見直しは、月に一度だけ

- **毎週の見直しはしない**：一人なら、毎日の返信対応で異常には気づく。週の会は開かない
- **月に一度、段ごとの数を並べる**：読んだ・送った・返信・面談・選考。[スカウト運用のKPI設計](/media/wt-scout-kpi/)
- **直すのは一か所だけ**：型の一文か、絞り込みの条件か
- **月の見直しに、現場の話す人と上司に短く報告する**：段の数と、直す一か所。反応を現場に戻す
- **四半期に一度、募集を増やすか減らすかを決める**：続いていれば二つ目、止まりそうなら減らす

「毎週の見直しをしない」は、チームで回す場合との違いです。一人なら、見直しの負担そのものが止まる理由になります。

## 外に出せる作業

一人で回すときこそ、外に出せる作業は出します。

| 外に出せる | 社内に残す |
|---|---|
| 絞り込みの条件の設計 | プロフィールを読んで一文を書く |
| 型と見本の作成、更新 | 現場の一文と確認 |
| 台帳の集計と月の見直しの材料 | 返信対応 |
| 返信の型、面談の型 | 面談 |
| 引き継ぎの一覧の保管 | 上司への報告 |

出せる作業を出せば、人事に残るのは「読んで書く」「返す」「面談の進行」「報告」だけになります。範囲は[スカウトを代行に出せる範囲](/media/wt-scout-daikou/)で書きました。

## 止まりそうなサインと、減らし方

| サイン | 減らし方 |
|---|---|
| 週の枠を、二週続けて使えなかった | 枠を短くする。送る数を減らす。ゼロにしない |
| 返信対応が、翌日までにできていない | 送る数を減らす。返信の型を見直す |
| 台帳が、一週間更新されていない | 項目をさらに減らす |
| 現場の確認が返ってこない | 確認の期限を決め、過ぎたら送らない（送るのではなく、送らない） |
| 面談枠が埋まらない | 現場の話す人に枠を頼み直す。埋まらないなら送る数を減らす |
| 「効いているのか分からない」と感じる | 月の見直しで段の数を見る。面談まで進んだ相手がいれば続ける |

「止める前に減らす」が原則です。止まると再開が重く、減らせば続きます。再開の手順は[スカウト運用が止まったときの再開方法](/media/wt-scout-saikai/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社が人事一人の会社のWantedlyのスカウトを支えるとき、絞り込み、型、台帳の集計、見直しの材料は当社が持てます。人事に残るのは、週に一度の枠で読んで書くことと、毎日二回の返信対応と、面談の進行と、月の報告です。この四つは、社内でしかできません。当社が最初にお伝えするのは、「この四つが、いまの業務の中に入りますか」という確認です。入るなら、当社は残りを引き受けます。入らないなら、スカウトより先に、募集記事と会社ページを整えて、話を聞きに来る人を待つ形が向いています。人事一人の会社で、無理に始めて止まるより、入る大きさで始めて続けるほうが、結果につながります。

## まとめ

- 人事一人で回す目的は、多く送ることではなく「止まらない大きさで続けること」
- 募集は一つ、週の枠は一つ、読める数だけ、型は一つ、絞り込みは狭く、面談枠を超えない
- 現場に頼むのは、「いま何を決めようとしているか」の一文・文面の確認・面談、の三つだけ
- 返信対応は毎日二回の決まった時間に、台帳は項目を減らして「次の連絡日」だけは残し、見直しは月に一度一か所だけ
- 絞り込み・型・集計は外に出す。止まりそうなサインが出たら、止める前に減らす

## よくある質問

### 募集が複数あり、どれも急ぎで、一つに絞れません

それでも一つに絞ります。一人で複数を同時に送ると、どれも読めずにテンプレになり、どの募集も進みません。最も急ぎで、募集記事が整っていて、話す人がいる募集から始め、続いたら次に移ります。他の募集は、募集記事を整えて「話を聞きに行きたい」を待つ形にします。

### 現場が「文面の確認」すら時間が取れないと言います

確認の期限を決め、「期限までに返事が無ければ、今回は送らない」と伝えます。送るのではなく、送らない側に倒すと、現場は「確認しないと送られない」と分かり、短い時間で見てくれます。それでも取れないなら、その募集はスカウトより掲載を優先します。

### 人事一人でのスカウト運用は、御社に相談できますか

できます。当社は、絞り込み、型と見本、台帳の設計と集計、返信の型、面談の型、月の見直しの材料を支えられます。読んで書くこと、返信対応、面談、報告は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
