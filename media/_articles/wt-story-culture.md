カルチャーを伝えるストーリーは、最も書きたくなり、最も抽象語になりやすい型です。「アットホームな雰囲気」「風通しのよい組織」「フラットな関係」。これらは、どの会社のストーリーにも書いてあり、候補者には何も伝わりません。**結論から言うと、カルチャーを伝えるとは、「社内でよくある場面」を1つ、具体的に書くことです。何かを決めるとき、揉めたとき、新しい人が入ったとき、失敗したとき、そのとき誰がどう動くか。1つの場面が、抽象語の何倍も伝えます。** 良い面だけでなく「合わない人はこういう人」も書くと、候補者は自分で判断できます。この記事では、カルチャーの役割、書く場面の型、聞く相手、バリューとの対応、「合わない人」の書き方、イベント報告や制度説明との違い、写真、やりがちな失敗、分担を整理します。ストーリーの位置づけは[ストーリーの基本](/media/wt-story-kihon/)で書きました。

## この作業の目的｜候補者に「自分はここで動けるか」を判断させる

候補者がカルチャーのストーリーを読むのは、「自分はこの会社の空気の中で動けるか」を判断するためです。会社を好きになるためではありません。

判断には、具体的な場面が要ります。「決めるときは、担当が案を出して、翌日までに全員が意見を書き、責任者が決める」と読めば、「自分はその動き方ができるか」を判断できます。「風通しがよい」では、判断できません。

カルチャーのストーリーの目的は、候補者が「自分はここで動けるか」を判断できる場面を渡すことです。合わない候補者が来ないことも、目的のうちです。この考え方は、会社ページのバリューと同じで、[会社ページでバリューを言葉にする方法](/media/wt-kaisha-page-value/)で書きました。

## 手順1｜書く場面の型

カルチャーが出る場面は、だいたい決まっています。型から1つ選び、最近の実例で書きます。

| 場面の型 | 何が見えるか | 聞く質問 |
|---|---|---|
| 何かを決めるとき | 誰が案を出し、誰が意見を言い、誰が決めるか | 「最近、チームで決めたことは。どう決まりましたか」 |
| 揉めたとき | 意見が割れたとき、どう解決するか | 「最近、意見が割れたことは。どう収まりましたか」 |
| 新しい人が入ったとき | 最初の日、最初の週に、周りが何をするか | 「最近入った人に、最初の週に誰が何をしましたか」 |
| 失敗したとき | 誰かが失敗したとき、周りがどう扱うか | 「最近、うまくいかなかったことがあったとき、どうなりましたか」 |
| 忙しいとき | 繁忙期に、誰がどう動き、どう助け合うか | 「一番忙しかった時期、チームはどう動きましたか」 |
| 雑談と休み方 | 昼、休憩、休暇の取り方 | 「昼は誰と何をしていますか」「休暇はどう取っていますか」 |
| 顧客とのやり取り | 顧客に対して、社内が何を優先するか | 「顧客から無理な依頼が来たとき、どうしましたか」 |

「揉めたとき」と「失敗したとき」が、カルチャーを最もよく伝える場面です。うまくいっているときの空気は、どの会社も似ています。うまくいかないときの動き方に、会社の違いが出ます。

## 手順2｜聞く相手｜若手と古参の両方

カルチャーは、立場によって見え方が違います。若手と古参の両方に聞くと、実態に近づきます。

- **若手**：入ってすぐに感じたこと。「前の会社（学生時代）と違ったこと」。空気の違いに敏感
- **古参**：以前と変わったこと、変わっていないこと。「昔はこうだったが、いまは」。カルチャーの由来
- **中間の人**：若手と古参の間で、実際にどう回しているか
- **代表**：カルチャーとして「こうありたい」と「実際」のずれを、正直に

同じ場面を2人に聞くと、「若手は〇〇と感じたが、古参は△△と思っていた」という違いが出ます。この違いを記事に入れると、カルチャーが一面的でなくなります。聞き方は[社員インタビューを書く手順](/media/wt-story-interview/)で書きました。

### エージェントベストの見解

申し込んだあと、カルチャーのストーリーを書き始めた会社で数ヶ月後に起きやすいのは、「カルチャーの記事が、社内イベントの報告になっている」ことです。歓迎会、社員旅行、周年のパーティー。写真が並び、「みんな仲がいいです」で締まる。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、この形の記事には、候補者はほとんど来ません。イベントの様子は、どの会社も似ていて、「自分はここで動けるか」の判断材料にならないからです。候補者が来ているカルチャーの記事は、「先月、意見が割れたときに、こう決めた」「新しく入った人の最初の週に、周りがこうした」のような、日常の1つの場面です。イベントは、カルチャーの結果であって、カルチャーそのものではありません。イベントを書くなら、イベントの裏で誰がどう動いたかを書く。それが、カルチャーの記事です。

## 手順3｜バリューの実例と対応させる

会社ページにバリューがあるなら、カルチャーのストーリーは、バリューの実例を1本ずつ詳しく書く形にできます。

1. **会社ページのバリューの実例（一文）を、ストーリーで1本の場面にする**：「顧客の言葉をそのまま持ち帰る」の実例を、その場面の前後まで含めて
2. **バリューの言葉は、記事の最後に一言で触れる**：「これが、うちで言う〇〇です」。最初に掲げない
3. **バリューに沿わなかった場面も、書いてよい**：「このときは、〇〇できなかった。そのあと、こう変えた」。沿わなかった場面が、バリューを本物にする
4. **会社ページのバリューの実例を、ストーリーを書いたときに差し替える**：数ヶ月に一度の差し替えの材料になる

バリューが無い会社は、場面の型から書いて、あとから共通する動き方が見えたら、それがバリューになります。抽出の考え方は、バリューの記事で書きました。

## 手順4｜「合わない人」も書く

カルチャーの記事で見落とされやすいのが、「合わない人」を書くことです。良い面だけを書くと、候補者は判断できず、合わない人も来て、面談や入社後に離れます。

| 書き方の型 | 例 |
|---|---|
| 「こう動く人には合う」 | 「案を出す前に、周りに聞きに行ける人には合う」 |
| 「こう動きたい人には、合わないかもしれない」 | 「1人で決めて1人で進めたい人には、合わないかもしれない」 |
| 「ここは、しんどいと感じる人もいる」 | 「意見を書くことを求められるので、書くのが苦手な人はしんどいかもしれない」 |
| 「以前、合わなかった人は、こう感じていた」 | 「決めるのが遅いと感じて離れた人もいる」。個人が特定されない形で |

「合わない人」を書くと、来る候補者は減るように見えますが、減るのは「合わない候補者」です。来た候補者は、自分で「合う」と判断して来ているので、面談と入社後の離脱が減ります。正直さの考え方は、[募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)で書いた「欠員なら欠員と」と同じです。

## 手順5｜イベント報告と制度説明との違い

カルチャーの記事と混同されやすいものを、分けておきます。

| 混同されるもの | なぜカルチャーではないか | カルチャーとして書くなら |
|---|---|---|
| 社内イベントの報告 | イベントの様子は、どの会社も似ている | イベントの裏で、誰がどう動いたか。準備で揉めたこと |
| 制度の説明 | 制度は会社ページ。使われているかは別 | 制度を使った人の、実際の場面。「〇〇が△△の制度を使ったとき、周りはこうだった」 |
| 「みんな仲良し」 | 抽象語。判断材料にならない | 仲がよいから何が起きたか。「揉めたとき、こう収まった」 |
| 福利厚生の一覧 | 募集記事の条件 | 書かない |
| 社員の集合写真 | 人は見えるが動きは見えない | 場面の写真。仕事中、会議中 |

イベントの記事を書くときの注意は[社内イベントを書くときの注意](/media/wt-story-event/)で書きました。ここでは、「イベントそのものはカルチャーではない」ことだけを押さえます。

## 手順6｜写真と、書き方

カルチャーの記事の写真は、書いた場面のものにします。決め方の記事なら会議の場面、新しい人の迎え方なら最初の週の場面。集合写真やイベントの写真ではなく。撮り方は[会社ページの写真の選び方](/media/wt-kaisha-page-photo/)で書きました。

書き方は、他のストーリーと同じです。

- **場面から始める**：「先月の会議で」「〇〇が入った最初の週に」
- **誰が、何をして、周りがどう反応したか**：行動と反応で
- **抽象語が出たら、場面に戻す**：「風通しがよい」と書きたくなったら、「先週、入社1年目の意見で□□が変わった」に
- **「合わない人」を1つ入れる**
- **バリューがあれば、最後に一言で**
- **募集記事か会社ページへ誘導する**

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「アットホーム」「風通し」で書く | 何も伝わらない | 社内でよくある場面を1つ |
| イベントの報告になる | 候補者が来ない | イベントの裏の動きを書く |
| 制度の説明になる | 会社ページと重なる | 制度を使った人の場面 |
| 良い面だけ | 合わない人も来て離れる | 「合わない人」を書く |
| うまくいっている場面だけ | どの会社も似る | 揉めたとき、失敗したときを書く |
| 1人にしか聞かない | 一面的になる | 若手と古参の両方 |
| バリューを最初に掲げる | 説教に見える | 場面を書いて、最後に一言 |
| 集合写真を使う | 動きが見えない | 場面の写真 |
| 「みんな仲良し」で締める | 抽象語で終わる | 場面を置いて終える |

最も多いのは、最初の「アットホームで書く」と「イベントの報告になる」です。カルチャーを「雰囲気」と捉えると、こうなります。「動き方」と捉え直します。

### エージェントベストの見解

同じ「カルチャーを伝えたい」という相談でも、当社が「合わない人を書きましょう」と勧めるのは、面談や入社後の離脱が多い会社です。良い面だけのカルチャーの記事で来た候補者は、面談で「思っていたのと違う」となり、入社後に「聞いていなかった」となります。「合わない人」が書いてあれば、その候補者は来ないか、来ても納得して来ます。逆に、来る数を増やしたい段階の会社には、「合わない人」を強く書きすぎないよう言うこともあります。書き方は「合わないかもしれない」で足り、「合わない」と断定する必要はありません。カルチャーの記事は、候補者を増やすためではなく、候補者に判断させるためのものです。判断させるには、良い面と、合わない面の両方が要ります。どちらかだけの記事は、判断材料になりません。

## まとめ

- カルチャーを伝えるとは、抽象語ではなく「社内でよくある場面」を1つ具体的に書くこと。候補者が「自分はここで動けるか」を判断できるように
- 場面の型は、決めるとき・揉めたとき・新しい人が入ったとき・失敗したとき・忙しいとき・雑談と休み方・顧客とのやり取り。揉めたときと失敗したときが最も伝える
- 若手と古参の両方に聞き、見え方の違いも入れる
- バリューがあれば実例を1本の場面にし、バリューは最後に一言。沿わなかった場面も書いてよい
- 「合わない人」を1つ書く。イベント報告・制度説明・集合写真はカルチャーではない

## よくある質問

### 「合わない人」を書くと、応募が減りませんか

減るのは「合わない候補者」で、その候補者は面談や入社後に離れます。「合わないかもしれない」の書き方で足り、断定は要りません。来た候補者は自分で「合う」と判断して来ているので、面談と入社後の離脱が減ります。判断材料を渡すことが、カルチャーの記事の目的です。

### 社内イベントの記事は、書いてはいけませんか

書いて構いませんが、イベントの様子そのものではなく、イベントの裏で誰がどう動いたか、準備で何が起きたかを書きます。「〇〇を開催しました。みんな楽しみました」はカルチャーの記事ではありません。「〇〇の準備で、△△と□□の意見が割れて、こう決めた」なら、カルチャーの記事です。

### カルチャーの記事の作成は、御社に相談できますか

できます。当社は、場面の型と質問、抽象語を場面に置き換える案、バリューとの対応の整理を支えられます。聞くことと、「合わない人」をどう書くかの判断は、企業にお願いしています。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのストーリーの整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
