オファーが承認されると、学生とのやり取りが始まります。ここからの一週間で、学生が面談に来るか、やり取りが途切れるかが分かれます。**結論から言うと、承認からの一週間は「当日の返信」「日程の確定」「面談前の連絡」「面談」「面談後の連絡」の五つを、誰がいつ行うかを先に決めておくことで、途中で止まりにくくなります。** 承認は学生が「話を聞いてもいい」と示した段階で、まだ会社を選んだわけではありません。この記事では、一週間の動きの例と、止まりやすい場所、社内の分担を整理します。

## この作業の目的｜学生の関心が下がる前に会う

承認した学生は、他の企業のオファーも同時に受け取っています。承認した時点では関心がありますが、返信を待つ間に他の企業とのやり取りが進むと、関心は下がっていきます。

承認からの一週間を設計する目的は、**学生の関心が下がる前に、最初の面談まで進むこと**です。そのために、学生を待たせる時間を、社内の都合で生まないようにします。待たせる時間の多くは、「誰が返すか決まっていない」「面談に出る人の予定が分からない」といった社内の事情から生まれます。

承認された直後の返信の中身は[OfferBoxで承認された後の返信](/media/ob-shounin-go/)で詳しく書きました。この記事では、返信を含めた一週間全体の流れを扱います。

## 一週間の動きの例

次の流れは、設計を考えるための一つの例です。会社の体制や学生の都合によって、間隔は変わります。

1. **承認の当日**：お礼と、面談の目的、候補日を返信します。候補日は複数出し、学生が選ぶだけで済む形にします
2. **翌日から数日**：学生から返事が来たら、その日のうちに日程を確定し、面談の形式、所要時間の目安、出る社員、当日の連絡先を伝えます。返事がなければ、一度だけ短く確認の連絡をします
3. **面談の前日**：日時と参加の方法をもう一度伝えます。オンラインなら接続の案内、対面なら場所と受付の方法です
4. **面談の当日**：名義の社員が出ます。選考ではなく、学生の関心を聞き、仕事を見せる場にします
5. **面談の当日か翌日**：お礼と、次に何があるかを伝えます。次の一歩が決まっていれば、その案内も添えます

この流れを、一週間ほどの中に収めるイメージです。間隔が長く空くと、学生は面談の目的を忘れたり、他の企業の予定を優先したりします。面談前の連絡の文面は[OfferBoxの面談前リマインド](/media/ob-mendan-mae-renraku/)にまとめています。

### エージェントベストの見解

承認からの一週間で止まりやすいのは、二つ目の「日程の確定」です。当日の返信は意識している会社が多いのですが、学生から希望日が返ってきたあと、面談に出る社員の予定を確かめるのに時間がかかり、確定の連絡が遅れます。当社は申込後の運用まで見ていますが、この遅れで学生が離れる場面は少なくありません。勧めているのは、承認が来る前に、面談に出る社員の空いている時間をあらかじめ押さえておくことです。週のうち面談に使える時間帯を決め、その中から候補日を出す。こうしておけば、学生が選んだ時点で日程は確定し、社内の確認を待つ必要がありません。返信の速さは、返信を書く人の努力より、候補日の出し方で決まります。

## 止まりやすい場所と手当て

| 止まる場所 | 起きること | 手当て |
|---|---|---|
| 当日の返信 | 担当者が不在で、返信が翌日以降になる | 返信の担当を二人決め、片方が不在でも返せるようにする |
| 日程の確定 | 面談に出る社員の予定の確認で数日かかる | 面談に使える時間帯を先に押さえておく |
| 学生からの返事がない | 確認の連絡を何度も送り、学生が負担に感じる | 確認は一度だけ。それでも返事がなければいったん止める |
| 面談の前日 | 連絡を忘れ、当日に学生が来ない | 確定の時点で前日の連絡を予定に入れる |
| 面談後の連絡 | 次の一歩が決まっておらず、連絡が遅れる | 面談の前に、次の一歩を決めておく |

返事がない学生に何度も連絡を送るのは避けます。学生にとって負担になり、会社の印象が下がります。一度確認しても返事がなければ、いったんやり取りを止め、他の学生への対応に時間を使います。

## 一週間を社内で回す分担

| 作業 | 誰が | いつまでに |
|---|---|---|
| 承認の確認と当日の返信 | 人事（不在時の代わりも決める） | 承認の当日 |
| 面談に使える時間帯の確保 | 面談に出る社員 | 承認が来る前 |
| 日程の確定 | 人事 | 学生の返事の当日 |
| 前日の連絡 | 人事 | 面談の前日 |
| 面談 | 名義の社員 | 確定した日 |
| 面談後の連絡 | 面談に出た社員か人事 | 面談の当日か翌日 |

返信や日程の確定は、運用を外に出すこともできる作業です。外に出す場合も、面談に使える時間帯の確保と、面談後の次の一歩の判断は社内で持ちます。返信を早くする体制の組み方は[OfferBoxで承認からの連絡を早くする体制](/media/ob-sokujitsu-taiou/)で整理しています。

### エージェントベストの見解

相談で多い思い込みは、「承認されたら、すぐに選考に案内したほうが早く採れる」というものです。実際には、承認の段階の学生は、まだ会社をよく知りません。すぐに選考の案内を送ると、学生は「まだそこまでの気持ちではない」と感じて、返事をためらうことがあります。新卒の採用は、媒体で会う学生と紹介で会う学生とで、承認や応募の時点の温度が違います。紹介の場合は間に入る担当が事前に会社の話をしていますが、OfferBoxでは企業が最初の説明をする立場です。だから承認からの一週間は、選考に進めるための時間ではなく、会社を知ってもらうための時間として使います。最初の面談を選考と切り離すと、学生は気軽に来られ、その分、面談のあとに選考へ進む判断を自分でしやすくなります。

## まとめ

- 承認からの一週間は、当日の返信、日程の確定、面談前の連絡、面談、面談後の連絡の五つで組む
- 止まりやすいのは日程の確定。面談に使える時間帯を承認の前に押さえておく
- 返事がない学生への確認は一度だけにする
- 返信の担当は二人決め、不在でも返せるようにする
- 最初の面談は選考と切り離し、会社を知ってもらう時間として使う

## よくある質問

### 承認から一週間以内に面談を組めない場合はどうすればよいですか

学生の都合や社内の事情で間隔が空くことはあります。その場合は、面談までの間に、企業ページの見どころや、面談で話す社員の紹介を短く送ると、関心をつなぎやすくなります。ただし、連絡の回数は増やしすぎないようにします。

### 面談はオンラインと対面のどちらがよいですか

最初の面談は、学生の負担が軽いオンラインを選ぶ会社が多い傾向があります。仕事の様子を見せたい場合は対面が合うこともあります。オンラインでの進め方は[OfferBoxの学生とオンラインで会うときの進め方](/media/ob-mendan-online/)にまとめています。

### 面談で何を聞けばよいか決まっていません

面談の前に、聞くことと伝えることを決めておくと、一週間の流れが面談で途切れません。聞くことの考え方は[OfferBoxの初回面談で聞くこと](/media/ob-sd-mendan-shitsumon/)にまとめています。
