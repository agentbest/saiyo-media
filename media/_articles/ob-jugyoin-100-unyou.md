従業員が百名前後。人事は一人か二人で、総務や労務と兼務していることが多い。新卒は毎年数名。学生には知られていない。OfferBoxで送ると、承認は付くが、面談や内定のあとに「大企業に決めました」で離れる。「規模で負けている」と感じて、文面に「大企業にはない裁量」「アットホーム」と書き、余計に離れます。**結論から言うと、学生が大企業と比べているのは「会社の規模」ではなく、「最初の年に誰と組み、誰に教わるか」の具体です。最初に決めるのは、入社数年の社員を名義にすること、最初の年に誰と組み誰に教わるかを部署の人数で具体に書くこと、会社の「なぜ」を採用サイトに置くこと、送る数を人事の時間と現場の面談枠で決めること、内定後の大企業との比較に備えることです。** この記事では、この規模の会社が割ける時間と人、学生が規模に対して確かめること、最初に決めること、文面の書き方、分担、やりがちな失敗を整理します。人事が一人の会社の運用は[人事が1人の会社のOfferBox運用](/media/ob-jinji-hitori-unyou/)、三百名規模の分担は[従業員三百名規模の会社のOfferBox運用](/media/ob-jugyoin-300-unyou/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 人事が一人か二人で、総務や労務と兼務 | 採用の時間が細切れで、承認への当日返信が落ちる |
| 現場に、入社数年の社員がいる | 名義にできる人がいる。ただし頼み方が決まっていない |
| 学生に知られていない | 会社紹介から始める文面になり、「なぜあなたに」が薄い |
| 部署の人数が少なく、教える人が一人 | 学生が「教育体制は」と聞き、制度の名前で答えて離れる |
| 内定のあとに、大企業と比べられる | 「規模で負けた」と考え、比べ方を間違える |
| 採用サイトが古い、または会社概要だけ | 学生が確かめる先に、会社の「なぜ」がない |

この規模の会社がOfferBoxに割ける時間は、人事の細切れの時間と、現場の入社数年の社員の面談枠で決まります。人事が兼務なら、検索・下書き・送信・一次返信を外に出し、人事の時間を現場との調整と面談の設定に使います。

## 学生が、規模に対して確かめること

- **誰に教わるか**：「教育体制」の制度の名前ではなく、最初の年に誰が隣にいて、何を教えるか
- **部署の人数と、誰と組むか**：数人の部署なら、その数人が誰か。「少ない」ことより「分からない」ことが不安
- **キャリアの道**：数年後に何を任されるか。入社数年の社員が、いま何をしているか
- **辞めた人がいるか、なぜ辞めたか**：小さい会社ほど、一人の退職が目立つ。隠すと不信
- **会社が何のためにあるか**：大企業なら知られている「なぜ」が、この規模では学生に見えない
- **大企業と比べて、何が違うか**：規模の大小ではなく、「最初の年の仕事の違い」を学生は知りたい

学生は、規模そのものを不安に思っているのではなく、規模が小さいと「分からないこと」が増えることを不安に思っています。分かる形で渡せば、規模は不利になりません。

### エージェントベストの見解

相談で最も多い思い込みは、「この規模では、大企業と比べられて負ける」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、この規模の会社の内定辞退の理由を追いますが、「大企業に決めた」と言う学生に理由を聞くと、「規模」ではなく「向こうは最初の年に何をするかが具体的で、こちらは分からなかった」が多く出てきます。大企業は、採用サイトと説明会で最初の年の仕事を具体に見せていて、この規模の会社は、文面に「裁量」「アットホーム」と書いて、最初の年の具体がありません。比べられているのは規模ではなく、具体の量です。当社がこの規模の会社の文面を作るときは、入社数年の社員を名義にし、「私は〇〇の部署で、△△さんに教わりながら、最初の年に□□をしました」の一文を入れます。この一文があると、学生は大企業と「最初の年の仕事」で比べ始め、規模で比べなくなります。

## 最初に決めること

1. **名義を、入社数年の社員にする**：「新卒で入って、こう育った」が、学生の不安に最も直接に答える。頼むことは名義・文面の一言・面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
2. **最初の年に誰と組み、誰に教わるかを、部署の人数で具体に書く**：「〇〇の部署は△人で、最初の年は□□さんと組んで、◇◇を担当します」。人数は文面に書いてよいが、この記事では書かない。制度の名前ではなく、人で
3. **会社の「なぜ」を、社長の言葉で採用サイトに置く**：知られていない会社は、「なぜ」がないと学生が判断できない。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)
4. **送る数を、人事の週の時間と、名義の社員の面談枠で決める**：兼務の人事が持てる返信の数と、名義の社員が月に会える数から逆算
5. **辞めた人がいるなら、聞かれたら答えられる形にする**：「〇〇の理由で辞めた人がいます。それを受けて△△を変えました」。隠さない
6. **内定後の大企業との比較に、先に備える**：内定のあとに学生が比べるのは「最初の年の具体」と「連絡の速さ」。内定者に、教わる人と組む人に会ってもらう。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
7. **承認への当日返信を、兼務の人事から切り離す**：一次の返信は外に出し、人事は面談の日程だけ。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)

## 文面の書き方｜「裁量」ではなく「誰と、誰に教わって、何を」

| 書かない | 書く |
|---|---|
| 「大企業にはない裁量」「アットホーム」 | 「〇〇の部署で、△△さんと組んで、最初の年に□□をします」 |
| 「教育体制が充実」「研修制度あり」 | 誰が、何を、どのくらいの期間、隣で教えるか |
| 「少数精鋭」「一人ひとりが主役」 | 部署の人数と、その人たちが何をしているか |
| 大企業と比べる表現 | 自社の最初の年の仕事。比べない |
| 会社紹介から始める文面 | 記述のどの行動を見たか、から始める。会社の「なぜ」は採用サイトに |

- **名義の社員が「新卒で入って、最初の年に何をしたか」を一場面書く**：この規模の会社の最も強い文面
- **知名度がない会社の書き方**：[知名度がない会社がOfferBoxで学生に届くには](/media/ob-chimeido-nai/)
- **給与で勝負しない会社は、条件を隠さず、仕事と人で**：[給与水準を強みにできない会社のOfferBoxの伝え方](/media/ob-kyuuyo-hikui/)
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)

## 内定後の比較に備える

- **内定者に、教わる人と組む人に会ってもらう**：大企業の内定者懇親会に対抗するのではなく、「自分が誰と働くか」を先に見せる
- **内定のあとの連絡を、名義の社員と人事の二人で**：連絡の速さと、人の顔が見えること
- **辞退の理由を、台帳に残す**：「大企業に決めた」で終わらせず、「何が具体的だったか」まで聞く。[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)
- **翌年の文面に、辞退の理由から分かった「学生が知りたい具体」を入れる**

### エージェントベストの見解

これをやる前に、先に「入社数年の社員」を名義に決め、その社員が最初の年に誰に教わって何をしたかを聞いておかないと、文面を整えても効果が出ません。当社はOfferBoxの運用代行でこの規模の会社の文面を作りますが、「名義は人事で」「現場は忙しいので」と始める会社が多く、人事の名義の文面には「新卒で入って、こう育った」が書けません。この規模の会社の強みは、入社数年の社員が、学生と近い立場で、最初の年の具体を語れることです。順番は、名義の社員を一人決め、その社員に「最初の年に、誰に教わって、何をしたか」を一場面聞き、それを文面の一文にし、その社員の面談枠を先に押さえてから、検索と送信に進むことです。この一場面が、大企業の採用サイトの「最初の年」と並べられる、この規模の会社の唯一の具体です。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「裁量」「アットホーム」で規模の不安に答える | 具体がなく、大企業の具体と比べて離れる | 誰と、誰に教わって、何を、で書く |
| 人事の名義で送る | 「新卒で入って、こう育った」が書けない | 入社数年の社員の名義 |
| 「教育体制」を制度の名前で答える | 学生が知りたい「誰が隣にいるか」に答えていない | 教える人を書く |
| 辞めた人を隠す | 小さい会社ほど目立ち、隠すと不信 | 理由と変えたことを答えられる形に |
| 「大企業に決めた」で辞退を終わらせる | 何が具体的だったかが分からず、翌年も同じ | 理由を聞いて台帳に |

最も多いのは、一つ目です。規模の不安に、規模の言葉（裁量、少数精鋭）で答えて、具体がありません。

## よくある質問

### 部署が数人で、教える人が一人しかいません。それでも書いてよいですか

書いてよく、むしろ書くべきです。「〇〇の部署は△人で、最初の年は□□さんが隣で教えます」は、学生には「分かる」情報です。人数が少ないことを隠して「教育体制あり」と書くと、面談で分かって「隠していた」になります。少ないことより、分からないことが不安です。

### 内定を出しても、大企業に決められます

辞退の理由を「何が具体的だったか」まで聞いてください。多くは「向こうは最初の年の仕事が具体的だった」「連絡が速かった」で、規模ではありません。翌年の文面に最初の年の具体を入れ、内定のあとに教わる人と組む人に会ってもらい、連絡を名義の社員と人事の二人で速く行うと、比べられ方が変わります。

### 従業員百名規模の会社のOfferBox運用は、御社に相談できますか

できます。当社は、学生が確かめることの整理の型、文面の型、検索・下書き・送信・一次返信、内定後の連絡の型を支えられます。名義の選定、教わる人と組む人の決定、会社の「なぜ」、面談、辞退の理由を聞くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
