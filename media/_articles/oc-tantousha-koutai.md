ワンキャリアの担当者が、急に交代した。異動、退職、休職。引き継ぎは短いか、ないままで、管理画面の権限だけが渡された。受諾やエントリーが来ているが、誰が誰にどこまで対応していたか分からない。企業ページに何が書いてあるかも、まだ読んでいない。**結論から言うと、引き継ぎがないまま交代したときは、「返信待ちの学生」を最初に拾って返します。企業ページに書いたことを読み、変えずに守ります。体験談と企業ページと面接官との合意は、作り直すのではなく、管理画面と体験談から復元します。最初の年度は、企業ページを変えません。前任と面接官と代理店に聞けることは聞き、最初の月はスカウトを減らして、返信と守ることに使います。** この記事では、交代直後に起きること、最初の一週間、復元の順番、最初の年度は変えないこと、聞けること、最初の月、分担を整理します。計画的な引き継ぎは[ワンキャリアの掲載運用の引き継ぎ](/media/oc-keisai-hikitsugi/)、OfferBoxの場合は[OfferBoxの担当者が交代したときの立て直し](/media/ob-tantousha-koutai/)で書きました。この記事は、ワンキャリアに特有の「企業ページの約束」と「体験談」を含めた立て直しです。

## この作業の目的｜「止めない」と「守る」と「復元する」を、同時に進める

担当者の交代で最も重いのは、受諾やエントリーした学生が放置されることと、企業ページに書いた連絡の日数が守られなくなることです。ワンキャリアでは、どちらも体験談に「連絡が来なかった」として残ります。

目的は、進行中の学生を止めないこと、企業ページに書いたことを守ること、前任の運用を復元すること、を同時に進めることです。

## 交代直後に、起きること

| 起きること | 体験談にどう残るか |
|---|---|
| 受諾やエントリーが放置される | 「返事が来なかった」 |
| 企業ページに書いた連絡の日数が守られなくなる | 「書いてあった日数より遅かった」 |
| 面接官が「何を見るか」の合意を新任から聞かれず、面接がずれる | 「企業ページと違うことを聞かれた」 |
| 体験談を読んでいた記録が失われる | 企業ページと体験談のずれに気づけない |
| イベントが途切れる | 一覧から消え、「動いていない会社」に |
| 代理店との窓口が途切れる | 契約と更新の状況が分からない |

「返信待ちの学生」と「企業ページの約束」は、今週中に対処します。他は、一か月で復元します。

## 最初の一週間で、やること

### 1. 返信待ちの学生を、拾って返す

- **管理画面で、受諾済み・エントリー済みで未対応の学生を全部拾う**
- **当日、全員に一言返す**：「担当が変わりました。〇〇と申します。お待たせしました」。次の段の日程と形を添える
- **日数が経っている学生には、遅れたことを一言添える**：隠さない
- **返した記録を、新しい台帳の最初の行にする**

返し方は[ワンキャリアでスカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/)で書きました。

### 2. 企業ページに書いてあることを、読んで守る

- **企業ページを全部読む**：選考の流れ、「何を見るか」、連絡の日数、条件、配属の決め方
- **書いてあることが、「学生への約束」であることを知る**：前任が書いた約束を、新任が守る
- **連絡の日数を、台帳の「次の連絡日」に**：今週から守る
- **書いてあることを、変えない**：変えると、体験談に「途中で変わった」が残る
- **守れない約束があれば、上司と相談してから直す**：黙って変えない

### 3. 進行中の学生の状況を、管理画面から復元する

- **受諾済み・エントリー済みの学生を、段ごとに並べる**：受諾のみ、一次済み、選考中、内定
- **やりとりを読み、各学生の「次に何をするか」を一行で**
- **内定者は、次の連絡日と話す相手を確かめる**

### 4. 面接官と代理店に、交代を伝える

- **面接官に、交代と、企業ページの「何を見るか」を伝える**：「前任から聞いていない」を先に言い、「企業ページにこう書いてあるので、このとおりにお願いします」
- **代理店に、新任の連絡先を伝え、前任とのやりとりの記録を聞く**
- **上司に、「返信待ちを返した。企業ページは変えずに守る。復元は一か月で」と伝える**

### エージェントベストの見解

相談で最も多い思い込みは、「担当が変わったので、企業ページを新任の方針で書き直したほうがよい」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、年度の途中で企業ページを書き直した会社は、その年度に選考を受けた学生の体験談に「途中で選考の流れが変わった」「企業ページに書いてあったことと違った」が残り、翌年の学生に読まれています。企業ページは、前任が書いたものではなく、その年度の学生への約束です。約束は、書いた人が変わっても、年度の中では守るものです。当社が担当交代の相談を受けるとき、最初にやるのは、新しい企業ページの提案ではなく、新任と一緒にいまの企業ページを読んで、「この約束を、今年度は守る」と決めることです。書き直すのは、年度の切れ目です。

## 復元の順番

| 復元するもの | どこから | どう復元するか |
|---|---|---|
| 1. 進行中の学生の台帳 | 管理画面のやりとり | 段ごとに並べ、次の一手を一行で（最初の一週間） |
| 2. 企業ページの約束 | 企業ページそのもの | 全部読み、連絡の日数を台帳に、「何を見るか」を面接官に |
| 3. 体験談を読んだ記録 | 体験談そのもの | 自社の体験談を全部読み直し、企業ページとのずれがあれば台帳に一行 |
| 4. 面接官との合意 | 面接官と企業ページ | 「企業ページに書いてある『何を見るか』は、前任とどう決めましたか」と聞く。なければ、企業ページのとおりに聞くことを合意 |
| 5. スカウトの型 | 管理画面の送信済みの文面 | 受諾が来た文面を数通読み、共通の構造を抜き出す |
| 6. 「こんな人」 | 受諾して一次まで進んだ学生のプロフィール | 共通する行動を書き出し、面接官に確かめる |
| 7. イベントの型 | 過去のイベントページ | タイトルと本文の型を写し、小さい回を一つ出す |

「2」と「3」は、ワンキャリアの立て直しに特有です。企業ページと体験談は管理画面と媒体に残っているので、前任がいなくても復元できます。

## 最初の年度は、企業ページを変えない

- **年度の途中で、選考の流れ・「何を見るか」・連絡の日数を変えない**：その年度の学生への約束
- **守れない約束があれば、上司と相談して、変える場合は「変えました」と企業ページに書く**：黙って変えない
- **新任の方針は、年度の切れ目に**：年度の切れ目に合わせる理由は[ワンキャリアの掲載運用の引き継ぎ](/media/oc-keisai-hikitsugi/)の「年度の切れ目に合わせる理由」
- **後任が最初の年度に変えないことは、同じ記事の「後任が、最初の年度に変えないこと」**
- **変えたい点は、台帳に「翌年度に変える候補」として残す**

## 前任と面接官と代理店に、聞けること

| 相手 | 聞けること |
|---|---|
| 前任（連絡が取れるなら） | 台帳の場所、企業ページの「何を見るか」をどう決めたか、体験談で気にしていた点、内定者の状況。短い時間で、一度だけ |
| 面接官 | 前任との合意、面接の進め方、学生の反応 |
| 代理店 | 前任とのやりとりの記録、申込時の「こんな人」、契約と更新時期、管理画面の使い方 |
| 管理画面と媒体 | 企業ページ、送信済みの文面、受諾した学生、やりとり、体験談、過去のイベント |

前任に聞けない場合でも、企業ページと体験談と面接官から、ワンキャリアの運用の大半は復元できます。

## 交代後の最初の月は、スカウトを減らして、返信と守ることに使う

- **スカウトは、復元した型で少数**：型を復元する前に送ると、前任の型と違う文面になる
- **受諾とエントリーへの当日返しだけは、最初から守る**
- **企業ページに書いた連絡の日数を、守る**：これが最初の月の最も重い作業
- **面接官が「何を見るか」のとおりに聞いているかを、面接後の一行で確かめる**
- **イベントは、小さい回を一つ**：一覧から消えないように
- **一か月で復元を終え、翌月からスカウトを読める数に戻す**
- **上司に「最初の月は復元と守ることに使う」と先に伝える**

### エージェントベストの見解

これは契約後に起きることの話です。当社が販売パートナーとして契約後に最も多く関わるのが、担当者の交代です。ワンキャリアでは、交代のときに最も失われやすいのが「企業ページの約束を守る」意識で、新任は企業ページを「前任が書いたもの」として読み、自分の約束として守りません。その結果、連絡の日数が遅れ、面接官への引き継ぎが抜け、体験談に「担当が変わってから雑になった」が残ります。当社が新任にお願いするのは、企業ページを最初に全部読んで、「これは今年度の学生への約束で、私が守る」と決めることです。書き直すのは、年度の切れ目です。当社が契約時にお願いしているのは、企業ページの約束と面接官との合意を、台帳に一行で残しておくことです。交代は、いつ起きるか分かりません。

## まとめ

- 引き継ぎがないまま交代したら、「返信待ちの学生」を当日に拾って返すことと、企業ページに書いた約束を読んで守ることを最初に。どちらも体験談に残る
- 企業ページ・体験談・面接官との合意は、作り直さず、管理画面と体験談と面接官から復元する。前任がいなくても復元できる
- 最初の年度は、企業ページの選考の流れ・「何を見るか」・連絡の日数を変えない。その年度の学生への約束。変えるのは年度の切れ目
- 面接官には「前任から聞いていない」を先に言い、「企業ページにこう書いてあるので、このとおりに」と合意を復元する
- 最初の月はスカウトを減らして、返信と約束を守ることに使い、小さいイベントを一つ出す。台帳に約束と合意を残して次の交代に備える

## よくある質問

### 前任が退職していて、企業ページの「何を見るか」をどう決めたか分かりません

企業ページに書いてあることが、決めた結果です。面接官に「企業ページにこう書いてありますが、このとおりに聞いていましたか」と確かめ、聞いていたなら続け、聞いていなかったなら「今年度はこのとおりに」と合意します。どう決めたかは分からなくても、何が書いてあるかは分かり、それを守れば、体験談は変わりません。

### 企業ページに、守れない約束が書いてあります

黙って変えず、上司と相談します。守れる形に変える場合は、企業ページに「〇〇を△△に変更しました」と書き、進行中の学生に連絡します。変えずに守る努力をする場合は、そのために何を減らすか（スカウトの数など）を決めます。守れないまま放置すると、体験談に「書いてあった日数より遅かった」が残ります。

### ワンキャリアの担当者交代の立て直しは、御社に相談できますか

できます。当社は、復元の順番、前任とのやりとりの記録、申込時の「こんな人」、型の復元の手伝い、管理画面の使い方、契約と更新時期を支えられます。返信待ちへの対応、約束を守ること、面接官との合意、体験談を読むことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
