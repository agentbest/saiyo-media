内定者が「親に反対されて」と辞退した。次から保護者にも対応したいが、会社から保護者に直接連絡してよいのか、保護者向けの説明会を開くべきか、書面を家に送るべきか分からない。**結論から言うと、保護者は「説得する相手」ではなく、内定者が家で「この会社で何をするか」を説明するときに使う材料を渡す相手です。会社から保護者に直接連絡することは原則しません（内定者の了解が無い連絡は、内定者と保護者の両方の信用を失います）。渡すのは、内定者の手を通して家で読める「会社の概要と、配属先の仕事と、最初の年と、条件の書面」で、内定者が家で説明できない箇所が辞退の種になります。保護者の反対が理由の辞退は、多くが「内定者自身が説明できなかった」で、保護者説明会より内定者への材料が先です。** 辞退の理由の分け方は[内定辞退の理由の分け方](/media/kh-naitei-jitai-riyuu/)で書きました。この記事は、保護者への対応の考え方と、渡すものを書きます。

## この作業の目的｜内定者が、家で説明できる状態を作る

保護者が反対する場面の多くは、内定者が家で「どんな会社で、何をするのか」を聞かれて、答えられなかったときです。「よく知らない会社」「何をするか分からない」と保護者が感じるのは、内定者が説明できていないからで、保護者が会社を調べて反対しているのではないことが多いです。

目的は、保護者を説得することではなく、内定者が家で説明できる材料を渡し、説明できない箇所を先に無くすことです。

## 保護者への対応で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 会社から保護者に直接連絡する | 内定者に「勝手に親に連絡された」と読まれ、保護者に「何かあるのか」と警戒される |
| 保護者説明会で説得する | 「囲い込み」と読まれる。参加しない保護者との差ができる |
| 内定者を通さずに書面を家に送る | 内定者の知らないところで家に届き、内定者と保護者の両方の信用を失う |
| 保護者の反対を、内定者の弱さと見る | 「親の言いなり」と決めつけ、内定者に材料を渡さないまま辞退される |
| 家で説明できる材料を渡していない | 内定者が「何をするか」を言えず、保護者が「よく知らない会社」と感じる |
| 反対の理由を聞かない | 「知名度」と決めつけて直す場所を間違える。実際は条件か、勤務地か、仕事の中身が多い |

共通するのは、保護者を「会社が働きかける相手」として見ていて、「内定者が説明する相手」として見ていないことです。

## 保護者は、説得する相手ではなく、材料を渡す相手

- **連絡は、内定者を通す**：会社から保護者への直接の連絡は、内定者が望んで了解した場合だけ。それ以外は原則しない
- **材料は、内定者の手で家に持ち帰る形**：内定者に渡し、「家で説明するときに使ってください」と添える。家に送らない
- **保護者説明会は、開くなら「任意」で「内定者と一緒に」**：保護者だけを集めない。参加しない家との差を作らない
- **説得しない**：会社の良さを訴えるのではなく、「何をする会社で、内定者が何をするか」の事実を渡す
- **反対の理由は、内定者から聞く**：「親御さんは何を気にしていますか」を、話す相手（現場の社員）が聞く。[内定者フォローの基本](/media/kh-naitei-follow-kihon/)

保護者の立場は、内定者の生活を支えてきた人で、会社の営業の対象ではありません。

### エージェントベストの見解

相談で最も多い思い込みは、「親の反対で辞退されるのは、うちの知名度が低いからで、保護者に会社を説明する場を作れば防げる」というものです。当社は3媒体すべての販売パートナーとして、内定後の運用まで見ていますが、「親の反対」と記録された辞退を、承諾期限の前の面談の記録と突き合わせると、多くは「内定者自身が、家で仕事の中身と条件を説明できなかった」に行き着きます。保護者は会社の知名度で反対しているのではなく、子どもが「何をするか」「条件は」「勤務地は」を答えられないことに不安を持っています。会社が保護者に直接説明しても、その不安は消えません。子どもが自分の言葉で説明できたときに消えます。当社が最初にお願いするのは、保護者説明会を企画する前に、内定者に「家で説明するときに使う材料」を渡し、承諾期限の前の面談で「家で説明してみて、答えられなかったことは何か」を聞くことです。答えられなかった箇所が、材料の欠けです。それを足すほうが、保護者説明会より早く、辞退を減らします。

## 内定者の手を通して渡す、書面の中身

| 中身 | 何を書くか |
|---|---|
| 会社の概要 | 何を作り、何を売り、誰が客か。規模と拠点。一枚で |
| 配属先の仕事 | 内定者が配属される部門で、何をするか。一日の流れ |
| 最初の年 | 入社後の最初の年に何を任されるか。教える人がいるか |
| 条件の書面 | 給与、勤務地、転勤の有無、休日、社会保険。口頭ではなく書面で。内定通知と同じもの |
| 質問の窓口 | 内定者が家で聞かれて答えられなかったことを、会社に聞ける先 |

この書面は、内定通知に添えるものと重なります。[内定連絡の文面](/media/kh-bunmen-naitei/)で書いた「承諾までに読むもの」を、家で読める形にしたものです。内定者が家で説明するときに、口頭で足りない箇所を書面で見せられます。

## 内定者が、家で説明できるかを確かめる場

- **承諾期限の前の面談で、聞く**：「家で話してみて、聞かれて答えられなかったことはありますか」。話す相手（現場の社員）が聞く
- **答えられなかった箇所を、材料に足す**：条件なら書面に、仕事の中身なら読むものに、勤務地なら地図と生活の情報に
- **内定者が「親に話していない」なら、話す材料を先に渡す**：話していない理由が「説明できないから」のことがある
- **答えられなかった箇所の記録を、翌年に戻す**：多くの内定者が同じ箇所で詰まるなら、内定通知と入口の文面に足す。[内定辞退の理由の分け方](/media/kh-naitei-jitai-riyuu/)

内定者が家で説明できた時点で、保護者の反対の多くは起きません。

## 保護者から、会社に連絡が来たとき

- **内定者に、先に伝える**：「親御さんから連絡がありました。お答えしてよいですか」。内定者の了解を得てから答える
- **答えるのは、事実だけ**：仕事の中身、条件、勤務地。書面と同じことを。説得しない
- **内定者の評価や選考の内容は、話さない**：内定者の個人の情報は、本人の了解が無ければ保護者にも話さない
- **保護者の懸念を、内定者に返す**：「親御さんは〇〇を気にされていました」と内定者に伝え、内定者が答えられる材料を足す
- **辞退の意向を保護者が伝えてきたら、本人に確認する**：辞退は本人の意思で決まる。保護者からの連絡だけで処理しない

保護者からの連絡は、内定者を通さない形で来ることがありますが、会社の側は常に内定者を通します。

## 媒体ごとに、変わる点

- **OfferBox**：オファーの文面で書いた仕事の中身が、家で説明する材料の元になる。文面の一文を、書面の「配属先の仕事」と同じ言葉に。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **Wantedly**：社員が書いた記事は、家で読める材料になる。「この記事を家で見せてよい」と内定者に渡す。[Wantedly経由の内定辞退が続くとき](/media/wt-naitei-jitai/)
- **ワンキャリア**：企業ページと体験談は、保護者が自分で読むことがある。企業ページに仕事の中身と条件が書かれているかを確かめる。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

三つとも、保護者への対応の型は同じで、家で読める材料の出どころが違います。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 保護者への直接連絡を原則しないと決める | 採用の責任者 |
| 家で読める書面を作る | 人事。条件は労務が確認 |
| 内定者に書面を渡し、「家で使ってください」と添える | 人事 |
| 「家で答えられなかったこと」を聞く | 話す相手（現場の社員）。承諾期限の前の面談で |
| 答えられなかった箇所を材料に足す | 人事 |
| 保護者からの連絡に答える | 人事。内定者の了解を得てから、事実だけ |
| 翌年の内定通知と入口の文面に戻す | 採用の責任者 |

運用代行や代理店が支えられるのは、書面の型、聞き方の型、記録の型までで、内定者に渡すこと、面談で聞くこと、保護者からの連絡への対応は社内が担います。

### エージェントベストの見解

保護者への対応で、当社が先にお伝えしているのは、「保護者が気にするのは、内定者が入口で読んだものと同じ箇所」だということです。勤務地、転勤、配属、最初の年、条件。これらは、内定者が入口（オファーの文面、募集記事、企業ページ）で確かめたことと同じで、内定者が家で説明できないのは、入口でも書かれていなかったからです。申し込んだあとに内定後の運用が止まる会社に共通するのは、入口の文面で勤務地と配属を後ろに置き、内定通知でも口頭で済ませ、内定者が家で「まだ決まっていないらしい」と答えて、保護者が「そんな会社に」と反対することです。当社が案内するのは、保護者対応の書面を作る前に、入口の文面と内定通知に、勤務地・転勤・配属・最初の年・条件が書かれているかを確かめることです。入口で書かれていれば、内定者は家で説明でき、保護者対応の書面は入口の文面と同じ言葉で済みます。保護者対応は、入口の文面を直すことから始まります。

## まとめ

- 保護者は「説得する相手」ではなく、内定者が家で説明するときに使う材料を渡す相手。会社から保護者への直接連絡は原則しない
- 渡すのは、内定者の手を通して家で読める「会社の概要・配属先の仕事・最初の年・条件の書面・質問の窓口」。家に送らない
- 「親の反対」の辞退の多くは、内定者自身が家で説明できなかったこと。承諾期限の前の面談で「家で答えられなかったこと」を聞き、材料に足す
- 保護者から連絡が来たら、内定者に先に伝え、了解を得て、事実だけを答える。辞退の意向は本人に確認する
- 保護者が気にする箇所は、内定者が入口で確かめた箇所と同じ。入口の文面と内定通知に、勤務地・転勤・配属・最初の年・条件を書く

## よくある質問

### 内定者が「親に会って説明してほしい」と言います

内定者が望んで了解した場合は、応じてよいです。その場合も、説得ではなく、内定者と一緒に、仕事の中身と条件の事実を話します。内定者の評価や選考の内容は話しません。会う前に、内定者に「親御さんが何を気にしているか」を聞き、その箇所の材料を用意して行きます。

### 保護者説明会を開いている会社があります。うちも開くべきですか

開くなら、「任意」で「内定者と一緒に」で、説得の場にしないことです。ただ、説明会より先に、内定者に家で説明できる材料を渡し、答えられなかった箇所を聞くほうが、辞退を減らします。説明会に来る保護者は、もともと反対していない保護者が多く、反対している家には届きません。

### 内定者の保護者への対応は、御社に相談できますか

できます。当社は、書面の型、聞き方の型、記録の型を支えられます。内定者に渡すこと、面談で聞くこと、保護者からの連絡への対応は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、内定後の運用まで含めて支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
