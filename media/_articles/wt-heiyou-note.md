代表や社員がnoteで文章を書いている。会社の公式noteもある。Wantedlyのストーリーも長い文章なので、「noteに書いたものをWantedlyに貼ればいいのではないか」「両方書くのは二度手間ではないか」と聞かれます。**結論から言うと、noteは「考えを、会社の外の読者に向けて書く場」、Wantedlyは「こんな人に向けて、応募の文脈で書く場」で、同じ長文でも読む人と読まれ方が違います。使い分けるなら、同じ文章を両方に貼らず、noteに書いた考えをWantedlyでは仕事の場面に書き直し、名義と本音の範囲を決め、noteのスキや閲覧数で採用を判断しないことです。** この記事では、それぞれの役割、使い分けの分担、書き直しの形、名義と本音の範囲、数字の読み方、工数、やりがちな失敗、社内の分担を整理します。Wantedlyのストーリーの基本は[Wantedlyのストーリーの基本](/media/wt-story-kihon/)、SNS全般は[SNSからの母集団形成](/media/kh-boshudan-sns/)で書きました。noteの仕様や数値は書きません。

## それぞれの役割｜noteは「考えを外に」、Wantedlyは「こんな人に」

| | note | Wantedly |
|---|---|---|
| 読む人 | 書き手や話題に関心のある人。同業、業界、一般の読者 | 会社を探している人、会社を読みに来た人 |
| 書く目的 | 考えを残す、伝える。採用に限らない | 「こんな人」に、この会社で働くことを想像してもらう |
| 文脈 | 採用の文脈ではない。読んだ人は応募先を探していない | 採用の文脈。読んだ先に募集記事と「話を聞きに行きたい」がある |
| 名義 | 個人が多い。会社の公式もある | 会社の名義で、社員が話す |
| 向く中身 | 考え、経験、業界への意見、失敗の振り返り | 仕事の場面、なぜこの会社か、誰と何をするか、最初の年 |
| 残り方 | 残る。書き手のものとして | 残る。会社の資産として |

noteとWantedlyは、どちらも長い文章が残る場所です。違うのは、読む人が「応募先を探しているか」です。noteの読者は、考えに関心があって読み、Wantedlyの読者は、会社に関心があって読みます。同じ文章でも、前者には「面白い考え」、後者には「この会社で働くとどうなるか」として読まれます。

## 使い分けの分担｜同じ文章を貼らず、場面に書き直す

- **noteに書いた考えを、Wantedlyでは「仕事の場面」に書き直す**：noteの「〇〇について考えたこと」を、Wantedlyでは「△△の場面で、〇〇と考えて、こうした」に。読む人が働く自分を想像できる形
- **Wantedlyのストーリーを、noteにそのまま貼らない**：応募の文脈で書いた文章は、外の読者には宣伝に読まれる
- **noteの記事から、Wantedlyの会社ページへの導線を置く**：noteで考えに共感した人が、会社を読みに来られる形。貼れる形は現在の仕様で確認
- **Wantedlyのストーリーから、noteへの導線は最小限に**：会社を読みに来た人を、外に出さない。「考えの詳しくは」で一つ置く程度
- **面談で「noteを読んだか」「Wantedlyのどこを読んだか」を聞き、台帳に残す**：どちらから来たかは、来た人の言葉で分かる

noteがある会社は、Wantedlyのストーリーの題材に困りません。noteの「考え」を、「場面」に直すだけで、ストーリーの一本になります。逆に、noteだけでWantedlyの記事を持たないと、考えに共感した人が「この会社で何をするのか」を読む場所がありません。

### エージェントベストの見解

相談で最も多い思い込みは、「代表がnoteで書いているので、Wantedlyのストーリーは要らない」というものです。当社は3媒体すべての販売パートナーとして、noteを持つ会社のWantedlyを見ていますが、noteの記事は代表の考えとしてよく書かれていても、Wantedlyの会社ページを開くと募集要項だけ、という形が多くあります。noteの文章には「こんな人に来てほしい」「来たら何をするか」がなく、共感した人が会社を読みに来ても、読む場所がなければそこで終わります。noteがある会社に当社が勧めるのは、noteを減らすことではなく、noteの考えの中から「仕事の場面」を一つ選び、Wantedlyのストーリーで「誰と、何をして、何が変わったか」に書き直すことです。考えは外の読者に、場面は会社を読みに来た人に。この分け方で、noteとWantedlyは重なりません。

## 書き直しの形｜「考え」を「場面」に

| noteの書き方 | Wantedlyの書き方 |
|---|---|
| 「〇〇について、私はこう考えている」 | 「△△の場面で、〇〇と考えて、□□した。結果、◇◇が変わった」 |
| 業界への意見 | その意見を、自社の仕事でどう実行しているか |
| 失敗の振り返り | 失敗のあと、誰とどう直したか。新しく来た人が同じ場面でどう動けるか |
| 一人称の考え | 一人称の場面。「私」が誰と組んだか |
| 結論が「考え」 | 結論が「この会社で働くと、こういう場面がある」 |

- **書き直しは、本人がする**：人事が代筆すると、本人の言葉でなくなる。人事は「場面はどこか」を聞く側
- **場面は一つ**：noteの一本に複数の考えがあっても、Wantedlyは一場面で一本
- **「こんな人」に向けて書く**：誰に読んでほしいかを、書く前に一行で決める。[Wantedlyのストーリーのテーマの決め方](/media/wt-story-theme/)
- **トーンは、noteの本人の言葉に寄せる**：Wantedlyだから固くする、はしない。[Wantedlyの文章のトーンの決め方](/media/wt-bunsho-tone/)

## 名義と、本音の範囲

- **個人のnoteは、本人のもの**：会社が書かせない、会社が消させない。「書かないこと」の線だけ合意する
- **会社の公式noteは、Wantedlyの会社ページと役割が近い**：両方持つなら、公式noteは「考え」、会社ページは「なぜと場面」に分ける。同じ文章を貼らない
- **本音の範囲は、noteとWantedlyで同じ線で引く**：noteだから出せる、はない。[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)
- **候補者や取引先が特定できることは、どちらにも書かない**
- **書いた本人が辞めたあと**：noteは本人に残る。Wantedlyのストーリーは、会社の判断で残すか消すかを決めておく。[Wantedlyのストーリーの書き手](/media/wt-story-kakite/)

## noteの数字の読み方

- **スキや閲覧数は、考えに関心のある人の数**：会社に関心のある人の数ではない
- **noteで読まれた記事が、採用に効いたかは、会社ページに来たかで見る**：来た人が、面談で「noteの〇〇を読んで」と言うか
- **noteで反応があった考えは、Wantedlyの場面の題材の候補**：反応の大きさで選ぶのではなく、「こんな人」が知りたい場面かで選ぶ
- **Wantedlyの効果を、noteの数字で説明しない**：経営に見せるときは、会社ページに来た人と、面談の言葉で。[経営層にWantedlyの成果を説明する方法](/media/wt-keiei-rikai/)

## 工数の置き方

| 項目 | note | Wantedly |
|---|---|---|
| 書く人 | 本人。人事は関わらないことが多い | 本人が話し、人事が整える。または本人が書く |
| 時間の性格 | 本人の関心で続く。義務にすると止まる | 月に数本。人事の時間と、話す社員の時間 |
| 外に出せる部分 | 出せない | 整える部分は出せる。話す中身は出せない |
| 費用 | 本人の時間 | プランの費用。公式ページで確認 |

- **noteを書いている人に、Wantedlyの書き直しを頼むときは、「場面を一つ聞かせてほしい」から**：一本書いてほしい、と頼むと重い
- **Wantedlyの時間を先に固定する**：noteがあっても、会社ページがなければ連れてくる先がない
- **noteを採用のために始めない**：採用のために書いたnoteは、外の読者に宣伝と読まれる。すでに書いている人がいるときに、使い分けを考える

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| noteの文章をWantedlyに貼る | 応募の文脈がなく、「こんな人」に届かない | 場面に書き直す |
| Wantedlyのストーリーをnoteに貼る | 外の読者に宣伝と読まれる | noteには考えを |
| noteがあるからWantedlyの記事を書かない | 共感した人が、会社を読む場所がない | 会社ページと場面のストーリーを先に |
| 採用のためにnoteを始める | 宣伝に読まれ、続かない | 書いている人がいるときだけ使い分ける |
| スキの数で採用の効果を見る | 会社に関心のある人の数と別の数字で判断する | 面談で「読んだか」を聞く |

最も多いのは、一つ目です。長文だから流用できると考えて貼り、「Wantedlyは読まれない」で止まります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| noteとWantedlyに書くことの線を決める | 人事と責任者 |
| noteの考えから、Wantedlyの場面を一つ選ぶ | 人事と、書いた本人 |
| 場面に書き直す | 本人。人事は聞いて整える |
| noteから会社ページへの導線を置く | 本人と人事 |
| 本音の範囲を、両方で同じ線で合意する | 人事と、書く社員 |
| 面談で「読んだか」を聞き、台帳に残す | 面談に出る人 |
| 辞めたあとのストーリーの扱いを決める | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、書き直しの型、線の型、台帳の型までで、線の決定、場面の選択、書き直し、面談で聞くことは企業と本人が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

noteのスキや閲覧数は、「その考えに関心のある人がどれだけいたか」を示す数字で、「この会社で働きたい人がどれだけいたか」の数字ではありません。当社はWantedlyの運用を申込のあとまで見ていますが、noteでよく読まれた記事がある会社ほど、「noteでこれだけ読まれているのに、Wantedlyから来ない」という相談になります。読まれた人と、応募先を探している人は、別の集まりです。当社が見るのは、noteの数字ではなく、会社ページに来た人のうち、面談で「noteの〇〇を読んで、会社を見に来た」と言う人がいるかです。いれば、noteは導線として効いていて、Wantedlyの側に読む場所があれば来ます。いなければ、noteの読者の中に「こんな人」がいないか、会社ページに読む場所がないかのどちらかで、どちらもnoteの数字からは分かりません。数字は参考に置き、判断は面談の言葉でします。

## まとめ

- noteは「考えを、会社の外の読者に書く場」、Wantedlyは「こんな人に向けて、応募の文脈で書く場」。読む人が応募先を探しているかが違う
- 同じ文章を両方に貼らない。noteの「考え」を、Wantedlyでは「場面（誰と、何をして、何が変わったか）」に本人が書き直す
- noteから会社ページへの導線を置き、Wantedlyから外への導線は最小限に。会社を読みに来た人を外に出さない
- 名義は本人のもの。本音の範囲はnoteとWantedlyで同じ線。採用のためにnoteを始めない
- スキや閲覧数で採用を判断しない。面談で「noteを読んだか」「記事のどこを読んだか」を聞いて台帳で見る

## よくある質問

### 会社の公式noteとWantedlyの会社ページは、どう分けますか

公式noteには「会社として考えていること」を、会社ページには「なぜこの会社か」を代表の言葉の場面で、ストーリーには「社員の仕事の場面」を書きます。同じ文章を貼らず、公式noteから会社ページへの導線を置きます。両方を持つ時間がなければ、会社ページとストーリーを先にします。応募の導線があるのはWantedlyの側です。

### noteで書いている社員に、Wantedlyのストーリーも書いてもらうのは負担ですか

「一本書いてほしい」と頼むと重いので、「noteの〇〇の中の、△△の場面を、話して聞かせてほしい」と頼みます。人事が聞いて整え、本人が確認する形なら、本人の時間は短く済みます。書き直しの中身は本人の言葉のままにし、人事は場面を選ぶ側に回ります。

### Wantedlyとnoteの使い分けは、御社に相談できますか

できます。当社は、役割の整理、書き直しの型、線の型、台帳の型を支えられます。線の決定、場面の選択、書き直し、面談で聞くことは、企業と本人が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
