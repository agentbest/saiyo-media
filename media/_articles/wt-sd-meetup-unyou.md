Wantedlyのイベント（旧ミートアップ）は、一回目は社内の協力もあって盛り上がります。ところが、二回目の企画が決まらないまま数か月が過ぎ、そのまま止まる会社が多くあります。**結論から言うと、ミートアップを続けるには、毎回ゼロから企画せず、テーマの表、話す人の輪番、案内文と当日の流れの型を先に用意し、同じ形で回すことです。** 一回ごとの企画の立て方は[ミートアップの企画の立て方](/media/wt-meetup/)にまとめています。この記事では、それを二回目以降も続けるための仕組みを整理します。

## ミートアップが続かなくなる理由

止まる理由は、だいたい次のどれかです。

- **毎回、企画を一から考えている**：テーマ、話す人、案内文、当日の流れを毎回決め直している
- **一回目の準備が重すぎた**：一回目に力を入れすぎて、二回目を同じ形でやる余力がない
- **話す人が同じ人に偏る**：一回目に話した人にまた頼み、負担が重なる
- **終わったあとに何も起きない**：参加した人が面談に来ず、効果が見えない
- **集客の心配で止まる**：申込が少ないことを恐れて、開催を決められない

どれも、ミートアップの中身ではなく、続けるための準備が足りないことが原因です。一回目を終えたら、二回目の企画より先に、続けるための型を作ります。

## テーマの表を作る

テーマは、開催のたびに考えず、先に表にしておきます。

| テーマの型 | 話す人 | もとにする募集 |
|---|---|---|
| この職種の仕事の一日 | その職種の人 | その職種の募集 |
| 最近の一つの案件の裏側 | 関わった人 | 関係する職種の募集 |
| 未経験で入った人の最初の月 | 未経験で入った人 | 未経験を歓迎する募集 |
| チームの決め方 | チームの人と責任者 | そのチームの募集 |
| 代表に最近の判断を聞く | 代表 | 会社全体の募集 |

表は、公開している募集ごとに作ります。Wantedlyでイベントを作るには、公開している募集が必要です。テーマは、その募集記事だけでは伝わらないこと、たとえば仕事の細部や一緒に働く人の様子を選びます。

テーマの型が決まっていれば、話す人を変えるだけで、同じ型を何度でも使えます。「仕事の一日」の型を、職種ごとに順番に開くだけでも、続ける題材になります。

### エージェントベストの見解

申し込んだあと、ミートアップで半年後に起きやすいのは、「一回目を大きくやりすぎて、二回目が出せない」ことです。当社は採用媒体の代理店としてWantedlyの契約後の運用を見ていますが、一回目に資料を作り込み、多くの社員を集め、軽食まで用意した会社ほど、二回目の企画が止まります。一回目の形が基準になり、それより小さくやるのは失敗のように感じられるからです。ミートアップの価値は規模ではなく、候補者が仕事をしている人に質問できることにあります。話す人が一人か二人、人事が進行、候補者は質問が回る人数。この小さな形を一回目から基準にしておくと、二回目以降も同じ準備で回せます。続けたいなら、一回目を続けられる大きさで始めることを勧めます。

## 話す人を輪番にする

話す人は、同じ人に偏らないよう、輪番にします。

1. **テーマの表から、話せる人を書き出す**：一つのテーマに複数の候補を
2. **順番を決めて、先に頼んでおく**：開催の直前ではなく、少し先の回まで
3. **話す人の上司にも伝えておく**：業務時間を使うことに合意をもらう
4. **話したあとに反応を戻す**：「〇〇の話に、質問が集まっていました」
5. **話した人に、次の人を紹介してもらう**

輪番にすると、一人あたりの負担が軽くなり、話す人の側も「次は自分の番」と準備できます。社員に話してもらう頼み方の考え方は[ストーリーに社員が登場する頼み方](/media/wt-sd-story-shain-sanka/)と共通しています。話す場面を一つに絞る、時間の見通しを示す、断ってよいと伝える、の三つです。

## 案内文と当日の流れを型にする

案内文と当日の流れは、一回目に作ったものを型にして使い回します。

**案内文の型**

- タイトルは「誰と、何を話すか」
- 話す人が、どの場面を話すか
- 誰に来てほしいか（この仕事や分野に関心がある人。転職を考えているかどうかで絞らない）
- 来たら何ができるか（質問できる、仕事の様子が見られる）
- もとにした募集記事への案内

「説明会」「選考会」のように、選考につながる言葉は、タイトルやカバー写真に入れません。イベントで候補者を募る内容を載せることは、Wantedlyの公式ヘルプで制限の対象として案内されています。ガイドラインは開催のたびに確かめます。

**当日の流れの型**

1. 受付と短い自己紹介（会社の説明はしない）
2. 話す人が一つの場面を話す（短く）
3. 質問の時間（長く。人事が最初の質問を出す）
4. もっと話を聞きたい人への一言の案内（その場で選考はしない）

型があれば、話す人とテーマを入れ替えるだけで、案内文と当日の準備が短い時間で整います。

## 終わったあとと、振り返り

終わったあとの連絡と、振り返りも型にします。

- **参加した人に、翌日までに一言**：お礼と、もとにした募集記事の案内
- **話を聞きたいと言った人には、面談の案内**：面談の準備は[カジュアル面談の準備](/media/wt-sd-casual-mendan-junbi/)で整理しています
- **話した人に反応を戻す**
- **出た質問を記録する**：候補者が聞いたことは、募集記事に足りないこと
- **次の回を決めて終える**：テーマの表と輪番から、次の回を選ぶ

振り返りでは、申込の数より、出た質問と、その後に面談へ進んだ人がいたかを見ます。申込が少なくても、質問が多く出た回は、候補者が知りたいことに合っていた回です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| テーマの表と輪番を作り、更新する | 人事 |
| 話す人に先の回まで頼む | 人事 |
| 案内文を型から作る | 人事（話す人に確かめる） |
| 一つの場面を話し、質問に答える | 輪番の社員 |
| 当日の進行と、終わったあとの連絡 | 人事 |
| 出た質問を記録し、記事の見直しに回す | 人事 |

### エージェントベストの見解

これをやる前に、先に決めておかないと二回目が決まりません。「一回目の終わりに、次の回の日とテーマを決めて終える」ことです。当社がWantedlyの運用を支える中で見てきたのは、終わったあとに振り返りの会議を開き、そこで次の回を決めようとして、会議の日程が合わずに止まる流れです。次の回は、振り返りの結果を待たずに、テーマの表と輪番から機械的に選んで決めてしまいます。振り返りで分かったことは、その次の回に反映すれば足ります。決める場を増やすほど止まりやすくなるので、開催の当日に、次の回を決める。この一つを決めておくだけで、続く会社と止まる会社の差が出ます。

## まとめ

- ミートアップが止まるのは、毎回一から企画し、一回目が重すぎ、話す人が偏るから
- テーマの表を募集ごとに作り、話す人を変えて同じ型を使い回す
- 話す人は輪番にし、先の回まで頼んでおく
- 案内文と当日の流れを型にする。選考につながる言葉は使わない
- 終わったら次の回をその場で決め、出た質問を記事の見直しに回す

## よくある質問

### 申込が少ない回が続いています。やめたほうがよいですか

少人数でも、質問が回るなら続ける価値があります。申込が少ないときは、案内文が「誰と、何を話すか」になっているか、もとにした募集記事から案内しているかを見直します。

### どのくらいの間隔で開けばよいですか

決まった答えはありません。輪番が無理なく回る間隔にします。間隔を短くして止まるより、長めの間隔で続けるほうが、候補者にも会社の様子が伝わります。

### オンラインとオフィスのどちらがよいですか

どちらでも構いません。オフィスなら仕事の様子が見られ、オンラインなら遠くの人も参加できます。続けるなら、準備が軽いほうを基本にし、ときどきもう一方を開く形も選べます。
