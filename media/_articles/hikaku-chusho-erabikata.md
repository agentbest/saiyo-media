中小企業が媒体を選ぶとき、最初にぶつかるのは「学生に『大手の滑り止め』として置かれ、比べられる場で大手と並べられて選ばれず、送る型で承認が来ても『大手の結果が出るまで待ってほしい』と言われ、大手の結果が出た途端に辞退され、『中小は不利だ』で終わる」という問題です。**結論から言うと、中小企業は比べられる場で大手と並ぶより、送る型で「第一志望として選ぶ理由」を一人に向けて書き、記事を置く型で経営者との距離と取引先と仕事を読ませます。「大手にはない」で戦わず「この会社にしかない」で書き、承諾の期限は大手の結果待ちに合わせ、承諾率は大手の結果が出る前後で分けて見ます。** 人数ごとの選び方は[新卒5名を採る会社の採用媒体の選び方](/media/hikaku-shinsotsu-5-erabikata/)などで書きました。この記事は「大手の滑り止め」に置かれる中小企業に絞って、位置の変え方と媒体の選び方を書きます。

## 中小企業に、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 学生に知られていないか、業界の中でしか知られていない | 「大手の滑り止め」に置かれ、大手の結果待ちで辞退される | 送る型で第一志望の理由を一人に。[中小企業のOfferBox運用](/media/ob-chusho-unyou/) |
| 業界での位置を、数値で示したくなる | 数値は確認が要り、学生には伝わらない | 取引先と仕事で位置を書く |
| 経営者との距離が近い | 大手にはない実態。ただし「近い」だけでは読まれない | 経営者が何を決め、新卒がどう関わるかを場面で |
| 内定承諾の期限が一律 | 大手の結果が出る前に期限が来て、辞退される | 学生の大手の時期を聞いてから期限を置く |
| 「大手にはない〇〇」で書く | 大手を基準にした書き方は、大手の下に自分を置く | 「この会社にしかない」で書く |
| 辞めた人が業界で知られる | 小さい業界では離職の噂が学生に届く | 隠さず、変えたことで |

## 判断軸を、中小企業に当てる

| 軸 | 中小企業での見方 |
|---|---|
| 対象（誰に届くか） | 「大手も受けている学生」を外さない。外すと、第一志望で選ぶ学生に届かない。絞るのは「経営者の近くで、この仕事を」に合う行動の記述 |
| 型（送るか、来るか、比べられるか） | 送る型は、第一志望の理由を一人に向けて書け、大手と並べられずに届く。来る型は、経営者が「この会社にしかない」を書けるかで届く。比べられる型は、大手と並べられる場で、知名度が無いと対象に入りにくいが、体験談が数年分あれば「大手と違う選考」として読まれる |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。[年間予算百万円前後の採用媒体の組み方](/media/hikaku-yosan-100/) |
| 運用工数（誰の時間が要るか） | 人事が一人か兼務。経営者が面談に出る時間を先に確保。大手の結果待ちの間に会う時間も |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。中小企業では、「対象」で大手を受けている学生を外さないことと、「型」で大手と並べられない届け方を選ぶことが、他の会社と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「中小企業は大手に勝てないから、『大手にはない〇〇』を書いて差をつける」というものです。当社は3媒体すべての販売パートナーとして、中小企業の相談を受けますが、「大手にはない裁量」「大手にはないスピード」「大手にはない距離」と書いた会社は、大手を基準にして自分を書いていて、学生は「大手の下にある会社」と読みます。大手を受けている学生は、大手の実態を知っていて、「大手にはない」の言葉が大手の何を指しているかも知っています。逆に、大手に触れずに「〇〇の取引先の△△を、経営者と一緒に決める。一年目の□□は◇◇を任された」と、この会社にしかない場面を書いた会社は、大手と並べられても「別のもの」として読まれ、第一志望で選ぶ学生が来ます。当社が最初にお願いするのは、企業ページと文面から「大手」の言葉を全部消し、残った文で自社が何の会社か分かるかを見ることです。分からないなら、書くべきは取引先と仕事と経営者の場面です。[知名度が無い会社のOfferBoxの伝え方](/media/ob-chimeido-nai/)

## 学生が、確かめること

- **業界での位置**：何を、誰に、どのくらいの範囲で。数値ではなく取引先と仕事で。「業界〇位」は確認が要り、学生には伝わらない
- **経営者との距離の中身**：「近い」ではなく、経営者が何を決め、新卒がどう関わるか
- **大手と何が違うか**：「大手にはない」ではなく、この会社の場面
- **辞めた人の実態**：小さい業界では噂が届く。隠さず、変えたことで
- **一年目に何を任されるか**：中小は任せる範囲が広いか、逆に決まっていないか。「最初の年に〇〇を」で
- **承諾の期限と、待ってもらえるか**：大手の結果を待ちたい学生は、待てる会社を選ぶ

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 「経営者の近くで、この仕事を」に合う行動で絞り、第一志望の理由を一人に書ける | 企業から送る型（OfferBox） | 大手と並べられずに届き、絞る作業を外に出せる |
| 経営者が「この会社にしかない」を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 取引先と仕事と経営者の場面を、記事で読んでもらえる |
| 体験談が数年分あり、「大手と違う選考」として読まれ始めている | 学生が並べて比べる場（ワンキャリア） | 体験談があれば。無いなら先ではない。[知名度が無い会社のワンキャリアの使い方](/media/oc-chimeido/) |
| 文面に「大手にはない」が残っている | どれも先ではない | 消してから |
| 承諾の期限が一律 | どれも先ではない | 大手の結果待ちに合わせてから |

どれか一つが正解ではなく、書けるか、体験談があるか、経営者の時間で、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせるなら**：文面で「第一志望の理由」を一人に、記事で「この会社にしかない」場面を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **大学のキャリアセンターと組み合わせる**：中小企業は大学経由の紹介が効く。媒体は大学で会えない学生に。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)
- **大手の結果待ちの間に、会う機会を作る**：経営者と現場に会ってもらう。「待たされている」を「知っていく」に。[内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **地方なら、地元とUターンの層を先に**：[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)
- **代行と組み合わせるなら、絞る作業と文面の下書きを**：経営者の場面と面談は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「大手にはない」ではなく「この会社にしかない」

- **「大手」の言葉を、全部消す**：「大手にはない」「大手の滑り止めではなく」「大手に負けない」。大手を基準にしない
- **業界での位置を、取引先と仕事で**：「〇〇の業種の△△社と、□□を◇年続けている」。数値は自社の実態で。この記事では書かない
- **経営者との距離を、場面で**：「経営者は〇〇を決める。新卒は△△の会議に一年目から出て、□□を任された」
- **一年目に任されることを、具体で**：「最初の年に〇〇を。△△が横につく」
- **辞めた人の実態を、隠さない**：「〇年で辞めた人が△人。理由は□□。変えたのは◇◇」
- **承諾の期限を、書く**：「大手の結果を待ちたい人は、時期を教えてください。それに合わせます」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「この会社にしかない」場面、一年目に任せること、承諾の期限の考え方を決める | 経営者 |
| 媒体を選ぶ | 書けるか、体験談があるか、経営者の時間で |
| 文面と記事 | 経営者が話し、人事が書く。「大手」の言葉が残っていないかを確認 |
| 面談 | 経営者と、教わる人 |
| 大手の結果待ちの間の接点 | 人事が日程を、経営者と現場が会う |
| 承諾率の記録（大手の結果が出る前後で分けて） | 人事 |

運用代行や代理店が支えられるのは、「大手」の言葉の点検、媒体の選び方、絞る作業、文面の下書き、承諾の期限の型、記録の型までで、経営者の場面、面談、結果待ちの間の接点は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

中小企業が数字を読むときに先にお伝えしているのは、「内定承諾率を、大手の結果が出る前と後で分けて見る」ということです。中小企業の内定は、大手の結果が出る前に出ることが多く、承諾率を一つの数字で見ると「低い」で終わります。当社が案内するのは、承諾を「大手の結果が出る前に承諾した人」「結果が出た後に承諾した人」「結果が出た後に辞退した人」の三つに分けて記録することです。前に承諾した人が多いなら、第一志望として選ばれていて、文面と面談が効いています。後に承諾した人が多いなら、待つ間の接点が効いています。後に辞退した人が多いなら、承諾の期限が一律か、待つ間の接点が無いかで、直すのは文面ではなく期限と接点です。「中小は承諾率が低い」で終える会社は、三つのどれが多いかを見ずに媒体を変えています。辞退の理由を「大手に決めた」で終わらせず、「何が決め手だったか」まで聞くと、翌年の文面に書く場面が見つかります。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)

## まとめ

- 中小企業は「大手の滑り止め」に置かれやすい。比べられる場で大手と並ぶより、送る型（OfferBox）で第一志望の理由を一人に、記事を置く型（Wantedly）で経営者との距離と取引先と仕事を。比べられる場（ワンキャリア）は体験談が数年分あれば
- 「大手にはない」で戦わない。「大手」の言葉を全部消し、この会社にしかない場面（取引先と仕事、経営者が決めること、一年目に任されたこと）で書く
- 大手を受けている学生を対象から外さない。第一志望で選ぶ学生は、大手も受けている
- 承諾の期限は学生の大手の時期を聞いてから置き、待つ間に経営者と現場に会ってもらう
- 承諾率は大手の結果が出る前と後で分けて見て、辞退の理由を「大手に決めた」の先まで聞く

## よくある質問

### 大手を受けている学生には、送らないほうがよいですか

送ります。第一志望として中小を選ぶ学生は、大手も受けていて、比べたうえで選びます。大手を受けていない学生だけに絞ると、「中小しか受からない」学生に届き、入社後に離れます。送るときは、大手と並べられない形（一人に向けた第一志望の理由、この会社にしかない場面）で書き、承諾の期限を大手の時期に合わせます。大手の結果を待つと言われたら、待つ間に会う機会を作ります。

### 業界での位置を、数値で書いてはいけませんか

数値は確認が要り、確認できないなら書きません。確認できても、学生には「業界〇位」より「〇〇の業種の△△社と□□を◇年続けている」のほうが伝わります。学生は業界の順位を知らず、取引先の名前と仕事の中身で会社を読みます。数値を書くなら、自社の実態を確認したうえで、取引先と仕事の説明に添えます。数値だけで位置を示そうとする文面は、読まれません。

### 中小企業の媒体選びは、御社に相談できますか

できます。当社は、「大手」の言葉の点検、媒体の選び方、絞る作業、文面の下書き、承諾の期限の型、記録の型を支えられます。経営者の場面、面談、結果待ちの間の接点は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、中小企業の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
