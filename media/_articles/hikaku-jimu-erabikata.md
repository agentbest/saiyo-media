事務職を新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『一般事務』『サポート業務』で出したら承認も応募も多く来て『事務は集まる』と安心したのに、面談で『総合職と何が違いますか』『将来はどうなりますか』と聞かれて答えに詰まり、体験談に『総合職との差』『ずっと同じ仕事』と書かれていて、内定を出しても『将来の道がある会社に決めた』と辞退され、数は来るのに残らない」という問題です。**結論から言うと、事務職は志望する学生が多く承認も応募も来ますが、学生が確かめるのは「誰の何を支え、最初の年に何を一人で回し、総合職との違いと待遇はどうで、将来の道があるか」で、企業ページに無いと体験談で確かめられます。勤務地を譲れない条件に「どの事務か」を一つ決め、送る型は「整えた・減らした・続けた」で絞って事務の先輩の名義で、比べられる場は総合職との違いを先に答え、記事を置く型は事務の一日と繁忙期を書き、多すぎるときは絞り方で、少ないときは広げ方で対応します。** 総合職の考え方は[総合職の採用媒体の選び方](/media/hikaku-sogo-erabikata/)で書きました。この記事は事務職に絞って、数は来るのに残らない構造と媒体の選び方を書きます。

## 事務職の採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 事務職を志望する学生が多い | 承認も応募も来て、「集まる」と安心する。多すぎて返せない | 絞り方を先に。[OfferBoxで事務職志望の学生を見つける検索の考え方](/media/ob-jimu-target/) |
| 「一般事務」「サポート業務」で募集する | 誰の何を支えるかが分からず、面談で「何をするのですか」から始まる | 「どの事務か」を一つに |
| 総合職との違いと待遇が書かれていない | 体験談で「総合職との差」を確かめられ、辞退される | 違いを隠さず先に。[ワンキャリアで事務職を募集するときの掲載とスカウト](/media/oc-jimu-keisai/) |
| 将来の道が書かれていない | 「ずっと同じ仕事」と読まれ、将来の道がある会社に決められる | 事務職のまま責任者か、総合職に変われるかを書く |
| 「定時で帰れる」と書く | 月末月初と決算期の実態が体験談に書かれ、ずれで離れる | 繁忙期を書く |
| 勤務地を書かない | 事務職は転勤の無さと通える範囲で選ばれる。書かないと来ない | 勤務地を譲れない条件に |

## 判断軸を、事務職に当てる

| 軸 | 事務職での見方 |
|---|---|
| 対象（誰に届くか） | 勤務地を譲れない条件に。「どの事務か」（経理、総務、人事、営業事務、受発注）を一つ決め、定型か改善かで求める行動を変える。定型なら「続けた」、改善なら「整えた・減らした」。「支えたい」「几帳面」は絞る条件にならない |
| 型（送るか、来るか、比べられるか） | 送る型は、勤務地と「どの事務か」で絞れ、多すぎるときに送る数で調整できる。比べられる型は、事務職の体験談で総合職との違いが最も書かれる場で、企業ページで先に答えられるかで。来る型は、事務の一日と繁忙期と将来の道を事務の先輩が書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。数は来るので、費用は「残った数」で見る |
| 運用工数（誰の時間が要るか） | 数が来るので、返す時間が他の職種より要る。返せる数から送る数と募集の出し方を決める。事務の先輩が面談に出る時間 |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。事務職では、「対象」で勤務地を譲れない条件にして「どの事務か」を一つに絞ることと、「運用工数」で多すぎる数を返せる数に合わせることが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「事務職は志望する学生が多いから、出せば集まって、楽に採れる」というものです。当社は3媒体すべての販売パートナーとして、事務職の採用の相談を受けますが、「一般事務」で出した会社の承認や応募は確かに多く、ところが面談で「総合職と何が違いますか」「将来はどうなりますか」と聞かれて答えに詰まり、内定を出しても「将来の道がある会社」に決められます。数は来るのに残らないのは、事務職の学生が「誰の何を支えるか」「総合職との違いと待遇」「将来の道」を体験談で確かめていて、企業ページにそれが無いからです。逆に、「営業の事務。〇人の営業の見積もりと受発注を支える。最初の年は△か月目に受発注を一人で。給与と昇進は総合職と□□が違う。事務職のまま責任者になった人が◇人」と書いた会社は、承認は減りますが、面談で確かめることが減り、内定後に「将来の道がある会社」に行く辞退が減ります。当社が最初にお願いするのは、「一般事務」を「どの事務か」に変え、総合職との違いと将来の道を、隠さず一段落ずつ書くことです。

## 学生が、確かめること

- **誰の何を支える仕事か**：営業の事務か、経理の入力か、総務の手続きか、受付か。「一般事務」の名前では分からない
- **最初の年に何を回すか**：最初の月に何を教わり、何か月目に何を一人で回すか。「サポート業務」の一語では分からない
- **総合職との違いと待遇**：給与、昇進、転勤、仕事の範囲。違いがあるなら、どこか。体験談で最も多く書かれる
- **将来の道があるか**：事務職のまま責任者になれるか。総合職に変われるか。ずっと同じ仕事か
- **残業と繁忙期**：月末月初、決算期、年度末の実態。「定時で帰れる」が本当か
- **勤務地と転勤**：通える範囲か。転勤が無いか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 勤務地と「どの事務か」で絞り、多すぎる数を送る数で調整したい | 企業から送る型（OfferBox） | 絞れて、数を自分で決められる。「整えた・減らした・続けた」で読む。[事務職向けのオファー文面](/media/ob-jimu-offer-bunmen/) |
| 体験談があり、企業ページに総合職との違いと将来の道を先に書ける | 学生が並べて比べる場（ワンキャリア） | 総合職との違いが最も書かれる場。先に答えれば、体験談と一致して選ばれる |
| 事務の先輩が、事務の一日と繁忙期と将来の道を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「ずっと同じ仕事」の像を、一日と道の記事で置き換える |
| 「一般事務」「サポート業務」のまま | どれも先ではない | 「どの事務か」に変えてから |
| 総合職との違いと将来の道が、社内で言葉になっていない | どれも先ではない | 決めてから。隠すと体験談で確かめられる |

どれか一つが正解ではなく、多すぎるか少ないか、体験談があるか、事務の先輩が書けるかで、先に検討するものが変わります。

## 組み合わせ

- **多すぎるときは、絞り方で**：勤務地を狭める、「どの事務か」を一つに、定型か改善かで行動を絞る、送る数を返せる数に。応募が多すぎる募集は、企業ページに「どの事務か」と繁忙期を書くと、合わない学生が先に離れる
- **少ないときは、広げ方で**：「事務」を志望職種に書いていない学生にも、「整えた・減らした・続けた」の行動で届ける
- **比べられる場と送る型を組み合わせる**：企業ページで総合職との違いを、送る型で「どの事務か」で絞って。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **記事を置く型で、事務の一日と繁忙期を**：[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **総合職と並べて募集するなら、違いを両方の募集に**：[総合職の採用媒体の選び方](/media/hikaku-sogo-erabikata/)
- **面接で「なぜ事務職か」を聞かず、総合職に誘導しない**：体験談に「誘導された」と書かれる
- **代行と組み合わせるなら、絞る作業と返信と文面の下書きを**：総合職との違いの決定と面談は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「一般事務」「サポート業務」ではなく、誰の何を支えるか

- **「一般事務」「サポート業務」「事務全般」を消す**：誰の何を支えるか分からない
- **「どの事務か」を、職種名に**：「営業事務」「経理の入力と照合」「総務の手続き」。誰の何を支えるかを一行で
- **最初の年に回すことを、時期で**：「最初の月は〇〇を教わり、△か月目に□□を一人で回す」
- **総合職との違いと待遇を、隠さず**：「給与と昇進は総合職と〇〇が違う。転勤は無い。仕事の範囲は△△まで」。数値は自社の実態で。この記事では書かない
- **将来の道を、実態で**：「事務職のまま責任者になった人が〇人。総合職に変わった人が△人。変わる条件は□□」。無いなら、無いと
- **繁忙期を、書く**：「月末月初と決算期は〇時ごろまで。それ以外は定時」
- **勤務地と転勤を、最初に**：「勤務地は〇〇。転勤は無い」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「どの事務か」、定型か改善か、総合職との違いと待遇、将来の道、繁忙期を、言葉にする | 事務職の上司と採用の責任者 |
| 企業ページと募集の記述 | 人事が書き、事務職の上司が確認 |
| 絞る条件（勤務地、どの事務か、行動） | 人事か代行 |
| 名義と、オファーの一文 | 事務の先輩 |
| 返す | 人事か代行。数が多いので、返せる数を先に決める |
| 面談 | 事務の先輩と上司。「なぜ事務職か」を聞かず、総合職に誘導しない |
| 残った数の記録 | 人事 |

運用代行や代理店が支えられるのは、「どの事務か」の型、絞る作業、返信、文面の下書き、記録の型までで、総合職との違いと将来の道の決定、名義の先輩、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

事務職の採用で数字を読むときに先にお伝えしているのは、「承認や応募の多さを、効いていると読み違えない。残った数で見る」ということです。事務職は志望する学生が多く、「一般事務」で出せば数は来ます。ところが、その学生の多くは複数の会社の事務職に同じように承認や応募をしていて、面談で「総合職との違い」「将来の道」を確かめ、答えがある会社に行きます。数が多いことで、返す時間が増え、面談の枠が埋まり、答えの無いまま内定を出して辞退される、という流れになります。当社が案内するのは、「送った・承認した・面談した・内定した・残った」を並べ、承認から面談の間と、内定から残るまでの間で、どれだけ減っているかを見ることです。承認から面談で大きく減るなら、「どの事務か」が無く、面談で確かめることが多すぎます。内定から残るまでで減るなら、総合職との違いと将来の道が答えられていません。数が多い職種ほど、数ではなく、減る場所を見ます。多すぎるなら、企業ページに「どの事務か」と繁忙期を書いて、合わない学生に先に離れてもらいます。

## まとめ

- 事務職は志望する学生が多く、承認も応募も来るが、学生が確かめるのは「誰の何を支え、最初の年に何を一人で回し、総合職との違いと待遇はどうで、将来の道があるか」。企業ページに無いと体験談で確かめられ、数は来るのに残らない
- 勤務地を譲れない条件に、「どの事務か」を一つ決め、定型か改善かで「続けた」「整えた・減らした」の行動で絞る
- 送る型（OfferBox）は絞れて数を自分で決められ、比べられる場（ワンキャリア）は総合職との違いを企業ページで先に答え、記事を置く型（Wantedly）は事務の一日と繁忙期と将来の道を
- 「一般事務」「サポート業務」「定時で帰れる」を消し、総合職との違いと待遇、将来の道、繁忙期を隠さず書く。面接で「なぜ事務職か」を聞かず、総合職に誘導しない
- 承認や応募の多さではなく残った数で見て、減る場所（承認から面談か、内定から残るまでか）で直す箇所を決める。多すぎるときは絞り方で

## よくある質問

### 総合職との待遇の違いを書くと、来なくなりませんか

書かないと、体験談で「総合職との差」を確かめられ、書いた場合より残りません。「給与と昇進は総合職と〇〇が違う。転勤は無い。仕事の範囲は△△まで。事務職のまま責任者になった人が□人」と、違いと、事務職の道を並べて書きます。事務職を選ぶ学生は、違いがあること自体より、違いを隠されることと、将来の道が無いことを避けています。違いを書いて減る分は、内定後に辞退する学生です。

### 応募が多すぎて、返しきれません

返せる数を先に決め、その数に合わせて絞ります。勤務地を狭める、「どの事務か」を一つにする、企業ページに「どの事務か」と繁忙期と総合職との違いを書いて合わない学生に先に離れてもらう、送る型なら送る数を減らす、の順で絞ります。返す作業を外に出す形もあります。返しきれずに返信が空くと、「遅い会社」と体験談に書かれ、翌年は数が減ったうえに残らなくなります。

### 事務職の媒体選びは、御社に相談できますか

できます。当社は、「どの事務か」の型、絞る作業、返信、文面の下書き、記録の型を支えられます。総合職との違いと将来の道の決定、名義の先輩、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、事務職の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
