新卒採用で、ワンキャリアとWantedlyの両方を使っている、または使おうとしている。二つの違いは分かっていても、「時期をどう分けるか」「担当を分けるか」「同じ学生が両方を見ていたらどうするか」「予算と時間をどう配分するか」が決まっていないと、どちらも中途半端に回ります。**結論から言うと、ワンキャリアは「学生が選考情報とクチコミとイベントで来る場」、Wantedlyは「会社の中身を読む場」です。同じ学生が両方を見ている前提で、クチコミに書かれる実態と記事をずらさず、時期はイベントと選考の時期をワンキャリア、通年をWantedlyと分け、担当と台帳を一つにします。** この記事では、それぞれの役割、同じ学生が見ている前提での揃え方、時期の分担、担当と台帳、予算と工数の配分、やりがちな失敗、社内の分担を整理します。二つの違いそのものは[ワンキャリアとWantedlyの違い](/media/hikaku-onecareer-wantedly/)で書きました。この記事は、両方を契約したあとの運用の分担を扱います。両媒体の仕様と数値は書きません。

## それぞれの役割｜「就職活動の場」と「会社を読む場」

| | ワンキャリア | Wantedly |
|---|---|---|
| 学生が来る動機 | 就職活動中に、選考情報・クチコミ・イベントを見るため | この会社を知るため |
| 学生が見るもの | 他の学生が書いた選考の体験、企業ページ、イベント | 会社ページ、ストーリー、募集記事 |
| 会社が出すもの | 企業ページ、イベント、選考情報 | 会社ページ、ストーリー、募集記事 |
| 時期 | 就職活動の時期に集中する | 通年。記事が残る |
| 来る学生の状態 | 就職活動中で、複数の会社を並べている。クチコミで会社の実態を見ている | 会社を読んでいる。会社で選んでいる |
| 会社の見られ方 | 学生の側から書かれた情報が中心。会社が全部を決められない | 会社が書いた情報が中心。会社が決められる |

ワンキャリアでは、学生が書いたクチコミと選考の体験が、会社の見られ方を作ります。Wantedlyでは、会社が書いた記事が見られ方を作ります。同じ学生が両方を見ていると、「クチコミに書かれている実態」と「記事に書かれている会社」がずれたときに、学生は「どちらが本当か」で迷い、クチコミの側を信じます。

## 同じ学生が両方を見ている前提での揃え方

- **クチコミに書かれている実態を、記事で否定しない**：クチコミで「選考が長い」と書かれているなら、記事で「スピード選考」と書かない。実態を直すか、実態のとおりに書く
- **クチコミで聞かれていることを、記事の題材にする**：学生が知りたいことは、クチコミの質問に出ている。それに答えるストーリーを書く
- **選考情報と、募集記事の選考の流れをずらさない**：ワンキャリアの選考情報と、Wantedlyの募集記事の「選考の流れ」を同じ日に直す
- **イベントに出る社員を、ストーリーに出す**：イベントで会った学生が、Wantedlyで同じ人の記事を読める形。イベントの会話が記事の場面から始まる
- **企業ページとWantedlyの会社ページの「なにを」を揃える**：文章は変えてよい。事実がずれない

クチコミへの向き合い方は[ワンキャリアのクチコミの基本](/media/oc-kuchikomi-kihon/)で書きました。クチコミとWantedlyの記事は、同じ会社を、学生の側と会社の側から書いたものです。ずれを消すのは、記事の書き方ではなく、実態の側です。

### エージェントベストの見解

同じ新卒採用でも、学生が選考情報を並べて比べる規模と知名度がある会社には、ワンキャリアを先に整え、Wantedlyは「会った学生が読む場所」として置くことを勧めることが多いです。理由は、その会社の学生は、すでにクチコミで会社を見ていて、会社が書いた記事より先に、学生が書いた情報で判断しているからです。逆に、知名度がなく、クチコミがまだ少ない会社には、Wantedlyを先に整え、ワンキャリアはイベントで会う場として置くことを勧めます。学生が並べて比べる材料がまだないので、会社が書いた記事で「読んで選んでもらう」ほうが先に効きます。当社は3媒体すべての販売パートナーとして、どちらを先に整えるかを、媒体の性能ではなく「学生がすでに何を見ているか」で分けています。両方を同時に、同じ力で始めると、どちらも薄くなります。

## 時期の分担｜イベントと選考の時期はワンキャリア、通年はWantedly

| 時期 | ワンキャリア | Wantedly |
|---|---|---|
| 就職活動の前 | 企業ページを整える。イベントの計画 | 会社ページとストーリーを整える。来年の学生が読む |
| イベントの時期 | 準備、当日、フォロー。時間が集中する | 更新の時間を月に一度に固定。止めない |
| 選考の時期 | 選考情報の更新、クチコミの確認 | 面談で「記事を読んだか」を聞く。選考の流れを募集記事で揃える |
| 選考のあと | クチコミを読み、来年の改善点を出す | 内定者にストーリーを書いてもらう。クチコミで聞かれたことを記事に |

ワンキャリアの時期に、Wantedlyの更新が止まるのが、最も多い崩れ方です。イベントの準備で人事の時間が消え、会社ページが去年のままになります。イベントの時期の前に、Wantedlyの更新の日を予定に固定しておきます。年間の組み立ては[ワンキャリアのイベントの年間計画](/media/oc-event-nenkan/)で書きました。

## 担当と台帳を一つにする

- **担当は一人でもよいが、媒体ごとの「見る日」を分ける**：ワンキャリアは週に一度、Wantedlyは月に一度、のように。日を分けると、片方に時間が吸われにくい
- **台帳は一つ**：入口の列に「ワンキャリア（イベント名）」と「Wantedly」を持つ。同じ学生が両方から来たら、最初の入口と、決め手の入口の二つ
- **面談で「何を見て来たか」を聞く**：クチコミか、イベントか、記事か。学生の言葉で、どちらが効いているかが分かる
- **段は共通**：面談・選考・内定は、入口を問わず同じ段と基準。並べ方は[Wantedlyを含む複数媒体の効果を並べて見る方法](/media/wt-heiyou-heiyou-kpi/)
- **混乱したら、役割・担当・台帳・企業ページの四つを媒体ごとに分け直す**：[複数媒体を併用して運用が混乱したときの整理](/media/ob-heiyou-konran/)

## 予算と工数の配分

| 項目 | ワンキャリア | Wantedly |
|---|---|---|
| 費用 | 掲載とイベントに応じた費用。公式ページで確認 | プランの費用。公式ページで確認 |
| 時間の性格 | イベントの準備と当日に集中。企業ページと選考情報の更新 | 通年で薄く。記事と会社ページ、返信と面談 |
| 外に出せる部分 | 企業ページの整備、イベントの運営の一部 | 整える部分。話す中身は出せない |
| 残る資産 | 企業ページ、イベントの型、学生の言葉 | 記事、会社ページ、面談の言葉 |

- **費用は、各媒体の現在の条件を確認してから置く**：この記事では数値を書かない
- **時間は、時期の重なりで見る**：ワンキャリアの時期にWantedlyが止まらないよう、月に一度の時間を先に固定
- **イベントに出る社員の時間と、ストーリーに出る社員の時間を、同じ社員で合わせる**：二人分の時間を一人分にできる
- **配分の考え方**：[Wantedlyを含む複数媒体の予算配分](/media/wt-heiyou-heiyou-yosan/)

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| クチコミの実態と記事がずれる | 学生がクチコミの側を信じ、記事が「盛っている」と読まれる | 実態を直すか、実態のとおりに書く |
| イベントの時期にWantedlyが止まる | 会った学生が読みに来て、去年の会社ページを見る | 更新の日を先に固定 |
| イベントに出る社員がストーリーにいない | 会った学生の行き先の記事がない | 出る社員を先にストーリーに |
| 台帳を媒体ごとに分ける | 同じ学生の重複に気づかず、連絡が二重になる | 一つの台帳に入口の列 |
| 両方を同時に同じ力で始める | どちらも薄くなる | 学生が何を見ているかで先を決める |

最も多いのは、二つ目です。イベントの準備が始まると、Wantedlyの更新が「あとで」になり、そのまま年度が終わります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| どちらを先に整えるかを決める | 人事と責任者 |
| クチコミと記事のずれを確認し、実態を直すか記事を直すかを決める | 人事と現場の責任者 |
| 企業ページと会社ページの事実を揃える | 人事 |
| イベントに出る社員のストーリーを出す | 人事と、出る社員 |
| ワンキャリアとWantedlyの「見る日」を分けて予定に入れる | 人事 |
| 面談で「何を見て来たか」を聞き、台帳に残す | 面談に出る人 |
| 予算と時間の配分 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、揃える項目の一覧、時期の分担の型、台帳の型、企業ページの整備までで、実態を直す判断、出る社員の選定、面談、配分の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。当社は両方の販売パートナーなので、窓口を一つにできます。

### エージェントベストの見解

両方を申し込んだあと、最初の年で起きることに共通するのは、ワンキャリアのクチコミに書かれた実態と、Wantedlyの記事のずれが、学生に見つかることです。当社はWantedlyの運用を申込のあとまで見ていますが、イベントで会った学生がWantedlyの記事を読み、そのあとにクチコミで「実態は違う」と知って、面談に来なくなった、という相談があります。記事が嘘だったのではなく、記事が「こうありたい会社」を書き、クチコミが「今の会社」を書いていたのです。学生は今の会社を見ます。両方を持つ会社に当社が勧めるのは、記事を書く前にクチコミを読み、書かれている実態を記事の側で認めることです。「選考に時間がかかると言われます。理由は〇〇で、今年は△△を変えました」と書ける会社は、クチコミと記事が同じ方向を向き、学生が迷いません。

## まとめ

- ワンキャリアは「学生が選考情報とクチコミとイベントで来る場」、Wantedlyは「会社の中身を読む場」。同じ学生が両方を見ている
- クチコミに書かれる実態と記事をずらさない。ずれを消すのは記事の書き方ではなく実態の側。クチコミで聞かれていることを記事の題材に
- 時期は、イベントと選考の時期をワンキャリア、通年をWantedly。イベントの時期の前に、Wantedlyの更新の日を固定
- 担当の「見る日」を媒体ごとに分け、台帳は一つ。イベントに出る社員をストーリーに出す
- どちらを先に整えるかは、学生がすでに何を見ているかで決める。両方を同時に同じ力で始めない

## よくある質問

### クチコミが少ない会社は、Wantedlyだけでよいですか

学生が並べて比べる材料がまだないなら、Wantedlyを先に整えて「読んで選んでもらう」形が先に効きます。ワンキャリアは、イベントで学生に会う場として、時期を絞って使う形から始められます。クチコミが増えてきたら、記事との揃え方を見直します。

### ワンキャリアのイベントで会った学生に、Wantedlyの記事をどう案内しますか

イベントの当日に、出ている社員が「自分の記事」として案内するのが自然です。「詳しくはこちらに書いてあります」と、社員本人の名前で。会社の公式として案内するより、会った人の記事として案内するほうが読まれます。案内できる形は、両媒体の現在の仕様で確認してください。

### Wantedlyとワンキャリアの併用は、御社に相談できますか

できます。当社は、役割の整理、揃える項目の一覧、時期の分担の型、台帳の型、企業ページの整備を支えられます。実態を直す判断、出る社員の選定、面談、配分の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、両方の運用を一つの窓口で支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
