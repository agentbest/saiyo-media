文系の学生にスカウトを送る。「文系の方も歓迎」「営業職募集」「〇〇業界に興味のある方へ」。学生には、職種名から仕事が想像できず、「文系でも」は「本当は理系がほしい」と読まれ、業界志望の決めつけは「自分のことではない」と読まれます。**結論から言うと、文系学生向けの文面は、職種名から仕事を想像できない学生に、「最初の月に何をするか」を場面で先に見せ、学生時代の行動の型（自分で始めた・続けた・人を巻き込んだ・条件を変えて試した）と重ねる四段の型で書きます。「文系でも」と書きません。仕事の中身が見えにくい職種ほど場面で書き、業界志望が広い学生には仕事内容で入ります。三つの媒体で、骨組みは同じです。** この記事では、文系学生が開かない文面、読む箇所、四段の型、場面で書くこと、業界志望が広い学生、職種ごとの入り方、避ける言葉、分担を整理します。文面全体の骨組みは[スカウト文面の基本構成](/media/kh-bunmen-kihon/)、新卒向けの型は[新卒向けスカウト文面の型](/media/kh-bunmen-shinsotsu/)で書きました。媒体ごとの文系向けは[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)、[ワンキャリアで文系学生にスカウトを送る文面](/media/oc-scout-bunkei/)で書きました。

## この作業の目的｜「何の仕事か」を、先に見せる

理系の学生には研究があり、仕事との重ね方が見えやすいのに対し、文系の学生は、職種名（営業、企画、人事、事務）から仕事の中身を想像できないことが多くあります。「営業」と書かれても、朝から夕方まで何をするかが分かりません。

目的は、職種名ではなく「最初の月に何をするか」を場面で先に見せ、学生が「自分がその仕事をしている場面」を想像できる文面にすることです。

## 文系学生が、開かない文面

| 文面 | 学生が受け取ること |
|---|---|
| 「文系の方も歓迎」「文系でも活躍」 | 本当は理系がほしい。文系は二番目 |
| 「営業職募集」「総合職」（職種名だけ） | 何をする仕事か分からない |
| 「〇〇業界に興味のある方へ」 | 業界を決めていない。自分のことではない |
| 「コミュニケーション力」「人柄」「協調性」 | 抽象語。何を見られるか分からない |
| 「幅広い業務に携われます」 | 何をするかが決まっていない会社 |
| 「〇〇学部の皆さまへ」 | 学部名で送った。読んでいない |

共通するのは、「何の仕事か」が場面で書かれていないことです。文系学生が読んでいることは[ワンキャリアで文系学生にスカウトを送る文面](/media/oc-scout-bunkei/)の「文系学生が、体験談で読んでいること」で書きました。

## プロフィールで、読む箇所

- **学生時代の行動の型**：「自分で始めた」「続けた」「人を巻き込んだ」「条件を変えて試した」「困ったときに〇〇した」
- **行動の中身より、行動の型**：サークルでも、アルバイトでも、ゼミでも、「型」が同じなら重ねられる
- **業界志望**：書かれていても、決めつけに使わない。「広い」学生が多い
- **読まない箇所**：学部名、学科名、資格、語学の点数。これは見出し
- **拾うのは、行動の型を一つ**

行動の型で拾う考え方は[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)の手順2、ガクチカの読み方は[ワンキャリアの学生のガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「文系学生は専門がないので、読む材料が少なく、人柄で選ぶしかない」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の文系向けの文面を見ていますが、「人柄」「コミュニケーション力」で送った文面は、学生に「何を見られるか分からない」として読まれず、返信が来ていません。文系学生の自由記述には、「自分で始めた」「続けた」「人を巻き込んだ」という行動の型が、理系学生の研究と同じくらい具体に書かれています。読む材料が少ないのではなく、専門ではなく行動の型を読む、というだけです。当社が文系向けの文面の相談を受けるとき、最初にやるのは、「人柄」を抜いて、自由記述から行動の型を一つ拾い、「最初の月に何をするか」の場面と重ねることです。

## 四段の型

| 段 | 書くこと | 例 |
|---|---|---|
| 1. 行動を読んだ一文 | 学生時代の行動の型を一つ、学生の言葉のまま | 「〇〇のイベントを、自分で企画して、周りを巻き込んで実現したと書かれているのを拝見しました」 |
| 2. 「最初の月に何をするか」との重なり | 最初の月の仕事を場面で書き、行動の型と重ねる | 「うちの△△の仕事は、最初の月に□□の企画を先輩と二人で持ち、社内の人を巻き込んで進めます。周りを巻き込んで実現する進め方が近いと思いました」 |
| 3. 選考で何を見るか | 学生が準備できる形で | 「選考では、学生時代に自分で始めて続けたことの話を聞きます。業界の知識や志望動機は聞きません」 |
| 4. 話す場 | 誰と、どんな形で、選考ではないこと | 「選考ではなく、この文面を書いた私と、オンラインで短い時間、仕事の一日の話をする場です。一言だけご返信ください」 |

「2」で「最初の月」を先に見せることが、文系向けの要点です。職種名では想像できない仕事を、場面で想像できるようにします。

## 仕事の中身が見えにくい職種ほど、場面で書く

| 職種名 | 職種名だけでは | 場面で書くと |
|---|---|---|
| 営業 | 何を誰に売るか分からない | 「朝は〇〇の確認、午前は△△への訪問に同行、午後は□□の提案書を先輩と作る」 |
| 企画 | 何を企画するか分からない | 「最初の月は、✕✕の企画の会議に出て、議事録と次の案を一つ作る」 |
| 人事 | 採用か労務か分からない | 「最初の月は、〇〇の面談に同席し、二か月目から△△の連絡を持つ」 |
| 事務・管理 | 何の事務か分からない | 「最初の月は、□□の処理を先輩と一緒に。二か月目から一人で」 |
| 総合職 | 何も分からない | 「配属は〇〇の形で決まり、最初の月は△△を」 |

「見えにくい職種ほど、場面で」が要点です。場面の書き方は[ワンキャリアで文系学生にスカウトを送る文面](/media/oc-scout-bunkei/)の「仕事の中身が見えにくい職種ほど、場面で書く」、職種ごとの入り方は[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)の手順5で書きました。

## 業界志望が広い学生には、仕事内容で入る

- **文系学生の多くは、業界を決めていない**：「〇〇業界に興味のある方へ」は、決めつけになる
- **業界ではなく、仕事の内容で入る**：「〇〇の仕事」ではなく「人を巻き込んで企画を実現する仕事」
- **業界名は、「なにを」の一言で事実として**：「△△を作っている会社です」
- **業界のイメージが不利なら、業界に触れず、一日の場面で**：[業界イメージが不利な会社のOfferBox文面](/media/ob-gyokai-image/)
- **入り方は[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)の手順3**

## 「文系でも」と、書かない

- **「文系でも活躍できます」は、「本当は理系がほしい」と読まれる**
- **「文系・理系問わず」も、「問わず」の時点で、どちらでもいいと読まれる**
- **文系学生に送るなら、文系学生に向けて書く**：「文系」という言葉を出さない
- **理系の学生と同じ募集なら、文面は行動の型で分けて、文理では分けない**：「条件を変えて試した」学生には、文理を問わず同じ仕事の場面で重ねる
- **書かない理由は[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)の手順4**

## 避ける言葉

- **「文系でも」「文系歓迎」「文理不問」**：二番目の合図
- **「営業職募集」「総合職」だけ**：仕事の中身がない
- **「〇〇業界に興味のある方」**：決めつけ
- **「コミュニケーション力」「人柄」「協調性」「明るい方」**：抽象語。何を見られるか分からない
- **「幅広い業務」「様々な経験」**：決まっていない
- **「〇〇学部の皆さまへ」**：学部名で送った
- **「志望動機」**：まだ志望していない

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「文系でも」と抽象語を文面から抜く | 人事 |
| 学生時代の行動の型を一つ拾う | 送る人 |
| 「最初の月に何をするか」を職種ごとに場面で話す | 現場の人 |
| 「選考で何を見るか」を決める | 面接官と人事 |
| 四段の型を職種ごとに作り、1と2を相手ごとに埋める | 人事。現場が確認 |
| 話す場に出て、仕事の一日を話す | 現場の人 |

運用代行や代理店が支えられるのは、四段の型、行動の型の読み方、職種ごとの場面の書き方の見本、避ける言葉の点検までで、行動を拾うこと、「最初の月」を話すこと、送ること、話す場に出ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社が文系向けの文面の相談を受けたとき、学生のプロフィールの読み方より先に、「最初の月に何をするか」を現場が場面で言えるかを確かめます。文系学生に向けた文面で最も多い止まりは、「2」の場面がなく、職種名だけで書かれていることです。「1」の行動をどれだけ丁寧に拾っても、重ねる先の場面がなければ、学生には「何の仕事か分からない」として読まれます。当社が勧める順番は、職種ごとに「最初の月」の場面を現場から一つ聞く、学生の行動の型を一つ拾う、重ねる、です。「1」より「2」が先で、それは理系向けの文面と逆の順番です。

## まとめ

- 文系学生は、職種名から仕事を想像できない。「文系でも」「営業職募集」「〇〇業界に興味のある方」「コミュニケーション力」の文面を開かない
- 読むのは、学生時代の行動の型（自分で始めた・続けた・人を巻き込んだ・条件を変えて試した）。学部名・資格・業界志望は見出しか決めつけで使わない
- 四段の型は、行動を読んだ一文→「最初の月に何をするか」との重なり→選考で何を見るか→話す場。「2」で最初の月を先に見せる
- 仕事の中身が見えにくい職種（営業・企画・人事・事務・総合職）ほど、朝から夕方の場面で書く。業界志望が広い学生には、業界ではなく仕事内容で入る
- 「文系でも」「文理不問」と書かない。二番目の合図になる。文系学生に送るなら、文系という言葉を出さずに、その学生に向けて書く

## よくある質問

### 総合職で、配属が決まっておらず、「最初の月」を書けません

配属の決め方と、決まるまでに何をするかを、場面で書きます。「配属は入社後〇〇の形で決まります。決まるまでの最初の月は、△△と□□の部署をそれぞれ数日ずつ回り、先輩の仕事に同席します」。「幅広い業務」ではなく、決まっていないことを事実で書き、その間の場面を書きます。決まっていないことは、隠すより書くほうが、学生には判断できます。

### 学生の自由記述がアルバイトの話ばかりで、仕事と重ねにくいです

アルバイトでも、行動の型は拾えます。「アルバイトで〇〇のやり方を自分で変えて、△△になった」なら「自分で変えて試した」型で、「新人の教え方を工夫した」なら「人を巻き込んだ」型です。行動の中身（アルバイトか、サークルか）ではなく、型で重ねます。型が同じなら、自社の「最初の月」の場面と重ねられます。

### 文系学生向けスカウト文面の型は、御社に相談できますか

できます。当社は、四段の型、行動の型の読み方、職種ごとの場面の書き方の見本、避ける言葉の点検を支えられます。行動を拾うこと、「最初の月」を話すこと、送ること、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
