Wantedlyの記事を書こうとして、手が止まる。会社ページの「なぜ」が書けない、募集記事の「こんなことやります」が業務内容の羅列になる、ストーリーの題材が思いつかない。「文章が苦手だから」と考えがちですが、書けない理由は文章力ではありません。**結論から言うと、「書けない」を四つに分けます。話してくれる社員がいない、話は聞いたが場面がなく抽象になる、記事で何を伝えるかが決まっていない、上手く書こうとして一文目で止まる。原因ごとにサインが違い、埋め方も違います。頼み方を「書いて」から「話して」に変え、「先週の一日」を聞き、記事の種類ごとに伝えることを一つに絞り、型に埋めて整えません。「書く」を「聞いて整える」に変え、完璧な一本ではなく短い一本を出します。** この記事では、四つの原因とサインと埋め方、「聞いて整える」への転換、短い一本、外部に頼める部分、分担を整理します。ストーリーの基本は[Wantedlyのストーリーの基本](/media/wt-story-kihon/)、社員の協力は[Wantedlyの記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/)で書きました。この記事は、「書けない」という症状から逆に辿るものです。

## この作業の目的｜書けない原因を見つけて、そこを埋める

書けないときに、文章の書き方を学ぼうとすると、遠回りになります。原因が「話す人がいない」なら、書き方を学んでも、話は増えません。

目的は、書けない原因が四つのどれかを見つけ、そこを埋めることです。上手く書くことが目的ではなく、記事が出る状態にすることです。

## 「書けない」の、四つの原因

| 原因 | 何が起きているか | 埋めるもの |
|---|---|---|
| 1. 話してくれる社員がいない | 「書いて」と頼んで断られ、人事が一人で書こうとしている。人事は現場の場面を知らない | 頼み方を「話して」に変え、一人から |
| 2. 場面がない | 話は聞いたが、「やりがいがある」「成長できる」の抽象で、場面が出てこない | 「先週の一日」「最初の月」を聞く |
| 3. 何を伝えるかが決まっていない | 会社ページ・募集記事・ストーリーで、同じことを書こうとしている。全部を一本に入れようとする | 記事の種類ごとに、伝えることを一つに |
| 4. 上手く書こうとしている | 一文目を何度も書き直す。「読ませる文章」を目指して止まる | 型に埋める。聞いた言葉をそのまま |

「1」と「2」が揃えば、「3」と「4」は型で解決します。最初に埋めるのは、話す人と場面です。

## 1. 話してくれる社員がいないとき

- **サイン**：「記事を書いてください」と頼んで断られた。人事が会社の説明を書いている。ストーリーが人事の一人称ばかり
- **埋め方**：頼み方を「書いて」から「話して」に変える。「〇〇について、短い時間、話を聞かせてほしい」。書くのは人事
- **一人から**：全員に頼まず、話してくれそうな一人に。その一本が出れば、次の一人に「こんな形で」と見せられる
- **上司の合意を先に**：「業務時間内に、短い時間」を、現場の上司と合意してから頼む
- **頼む形の詳しくは[Wantedlyの記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/)**

「書いて」は重く、「話して」は軽い。書けない会社の多くは、頼み方で止まっています。

## 2. 場面がないとき

- **サイン**：話は聞いたが、「やりがい」「成長」「風通し」の言葉しか出てこない。記事が抽象語で埋まる
- **埋め方**：「先週の一日」を、朝から順に聞く。「先週の月曜、何をしましたか」。抽象語ではなく、その日の行動
- **「最初の月」を聞く**：「入った最初の月、何をしましたか」。募集記事の「こんなことやります」の材料
- **「一番困った場面」を聞く**：ストーリーの題材。「困った」は、場面になりやすい
- **抽象語が出たら、「たとえば、いつ、何がありましたか」と一つ聞き返す**：一度聞き返せば、場面が出る

抽象語を場面に置き換える手順は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)の手順4、ストーリーの題材は[Wantedlyのストーリーのテーマの選び方](/media/wt-story-theme/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「記事が書けないのは、社内に書ける人がいないからで、外部のライターに頼めば解決する」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、外部に丸投げした記事は、「自社の人が言いそうにない言葉」で書かれ、候補者が面談で「記事と違う」と感じています。書けない原因が「話す人がいない」「場面がない」なら、外部のライターも同じ壁に当たり、会社説明の記事になります。逆に、話す人と場面が揃っていれば、文章が得意でない人事でも、聞いた言葉をそのまま並べるだけで、記事は出ます。当社が「書けない」の相談を受けるとき、最初にやるのは、書き方の指導ではなく、「話してくれる人はいますか」「その人の先週の一日を聞きましたか」の二つを聞くことです。この二つが揃った時点で、書けない状態はほぼ終わります。

## 3. 何を伝えるかが決まっていないとき

- **サイン**：会社ページと募集記事とストーリーで、同じ「なぜ」を繰り返している。一本の記事に、会社の説明と仕事の内容と社員の想いを全部入れようとして、長くなる
- **埋め方**：記事の種類ごとに、伝えることを一つに

| 記事の種類 | 伝えること（一つ） | 任せる先 |
|---|---|---|
| 会社ページ | 「なにを・なぜ・どうやって」を代表の言葉で | 仕事の中身は募集記事に、人はストーリーに |
| 募集記事 | 「この募集で何をやるか」を最初の数か月の場面で | 会社の「なぜ」は会社ページに |
| ストーリー | 一人の社員の、一つの場面 | 会社の説明は会社ページに |

- **一本に一つ**：「この記事で、候補者に一つだけ持ち帰ってもらうなら何か」を先に決める
- **入口を分ける考え方は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)の手順2**

## 4. 上手く書こうとしているとき

- **サイン**：一文目を何度も書き直す。「読ませる文章」「印象に残る書き出し」を目指す。時間をかけたのに出せない
- **埋め方**：型に埋める。ストーリーなら「誰が・いつ・何に困って・どうしたか・いまどう思っているか」の順に、聞いた言葉をそのまま
- **整えない**：話し言葉のままでよい。「〜なんですよね」を「〜です」に直すくらいで足りる
- **読み返しは一度だけ**：誤字と、本人が言っていないことを書いていないか、だけ確認して出す
- **本人に確認してもらう**：「こう書きましたが、言っていないことはありませんか」。本人が「言いそう」と思えば、それで出す

文章のトーンは[Wantedlyの記事の文章のトーン](/media/wt-bunsho-tone/)、上手く書かない考え方は[Wantedlyのストーリーで避けること](/media/wt-story-ng/)で書きました。

## 「書く」を、「聞いて整える」に変える

1. **話してくれる一人を決め、「話して」と頼む**：短い時間、業務時間内
2. **「先週の一日」「最初の月」「一番困った場面」のどれかを聞く**：一つで足りる
3. **聞いた言葉を、そのまま書き起こす**：整えない
4. **記事の種類ごとの「伝えること一つ」に沿って、順番を並べ替える**：足さない、削るだけ
5. **本人に「言いそうか」を確認してもらう**
6. **出す**：完璧を目指さない

「書く」工程が、「聞く」と「並べ替える」に変わります。文章力は、「並べ替える」にしか要らず、それも型があれば足ります。

## 完璧な一本ではなく、短い一本を出す

- **書けないときに、長い一本を目指さない**：一つの場面を、短く
- **短い一本が出れば、次の一人に「こんな形で」と見せられる**：書き手が増える。[Wantedlyのストーリーの書き手を社内で増やす方法](/media/wt-story-kakite/)
- **出したあとに、反応を見て直す**：出す前に直さない。[Wantedlyの募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)
- **一本目のストーリーは、会社ページとセットで**：[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)の手順6
- **途切れないことのほうが、一本の完成度より効く**：[Wantedlyのストーリーの更新頻度の決め方](/media/wt-story-hindo/)

## 外部に頼める部分と、頼めない部分

- **頼める**：聞く（取材）、整える（並べ替え、文章の調整）、型を作る、写真の撮り方の案
- **頼めない**：話す人を決めること、場面を持っていること、「伝えること一つ」を決めること、本人が「言いそう」と確認すること
- **外部に頼む前に、「話す人」と「場面」を自社で用意する**：これがないと、外部も書けない
- **丸投げの失敗と、頼む前に渡すものは[Wantedlyの記事を外部に書いてもらうときの注意](/media/wt-gaibu-writer/)**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 書けない原因を四つのどれかに切り分ける | 人事 |
| 話してくれる一人を決め、「話して」と頼む | 人事。現場の上司と合意 |
| 「先週の一日」「最初の月」「困った場面」を話す | 現場の社員 |
| 聞いて書き起こし、並べ替える | 人事 |
| 記事の種類ごとに「伝えること一つ」を決める | 人事と代表 |
| 「言いそうか」を確認する | 話した本人 |
| 短い一本を出し、反応を見る | 人事 |

運用代行や代理店が支えられるのは、原因の切り分け、頼み方の型、聞く質問の型、記事の種類ごとの型、聞いて整える手順、外部に頼む範囲の整理までで、話す人を決めること、話すこと、「伝えること」の決定、本人の確認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社がWantedlyで「記事が書けない」という相談を受けたとき、型を渡す前に、話してくれる一人がいるかを確かめます。型を先に渡すと、空欄を埋める場面がないまま、型の周りの文章を整えることに時間が使われ、結局書けません。当社が勧める順番は、一人に「話して」と頼む、「先週の一日」を聞く、聞いた言葉をそのまま書き起こす、その二つが揃ってから型に並べ替える、です。逆にすると、型が「書けない」を隠します。型はあるが出せていない、という相談は、ほぼこの順番が逆です。

## まとめ

- 「書けない」は文章力ではなく、話す人がいない・場面がない・何を伝えるかが決まっていない・上手く書こうとしている、の四つの原因で起きる
- 最初に埋めるのは話す人と場面。頼み方を「書いて」から「話して」に変え、一人から。「先週の一日」「最初の月」「困った場面」を聞き、抽象語が出たら一度聞き返す
- 記事の種類ごとに伝えることを一つに。会社ページは「なにを・なぜ・どうやって」、募集記事は「何をやるか」、ストーリーは一人の一つの場面
- 上手く書かず、聞いた言葉をそのまま型に並べ替え、本人に「言いそうか」を確認して出す。「書く」を「聞いて整える」に変える
- 完璧な一本ではなく短い一本を出し、反応を見て直す。外部に頼む前に、話す人と場面を自社で用意する

## よくある質問

### 代表が「なぜ」を話してくれず、会社ページが書けません

代表に「なぜを書いてください」ではなく、「会社を始めたとき、何に困っていましたか」「最初のお客さんは、どうやって見つけましたか」と、場面を聞きます。「なぜ」は、場面の中に出てきます。短い時間で、人事が聞いて書き起こし、代表に「言いそうか」を確認してもらう形にすれば、代表の負担は話すことと確認だけです。[Wantedlyの会社ページのミッション](/media/wt-kaisha-page-mission/)

### 聞いた話が短く、記事にするには足りません

短くてよいです。一つの場面が一つ書けていれば、ストーリーとして出せます。長い記事より、短い記事が途切れずに出るほうが、候補者には届きます。足りないと感じたら、「そのとき、周りの人はどうしていましたか」「その後、どうなりましたか」と一つ聞き足します。足すのは聞くことで、書くことではありません。

### 記事が書けないときの整理は、御社に相談できますか

できます。当社は、原因の切り分け、頼み方の型、聞く質問の型、記事の種類ごとの型、聞いて整える手順、外部に頼む範囲の整理を支えられます。話す人を決めること、話すこと、「伝えること」の決定、本人の確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
