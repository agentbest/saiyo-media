Wantedlyで経理にスカウトを送るとき、最初にぶつかるのは「簿記の資格で検索して『資格を活かせます』と送っているのに、返信が来ない。来ても、面談で『決算はどこまで社内ですか』『一人ですか』と聞かれて止まる」という問題です。**結論から言うと、経理へのスカウトは、資格の級や業界で相手を選ぶのではなく、先に自社の社内の範囲と決算の関わり方と確認の仕組みと最初に任せることを決め、「同じ範囲を、同じくらいの規模の会社で、一人か複数かが近い形で回し、何かを直した経験を書いている人」を選び、その人の「何を直したか」を読んだ一文から、社内の範囲と確認の仕組みの実態で誘います。** この記事では、経理がスカウトで見ているもの、送る前に決めること、誰に送るか、文面に書くこと、返信後の面談、社内の分担、やりがちな失敗を整理します。文面の3段の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)、募集記事は[経理を採る募集記事の書き方](/media/wt-keiri-boshu/)で書きました。

## 経理がスカウトで見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰から来たか | 経営者か、いまの経理か、人事か。送り主が数字を見ている人か |
| 自分の仕事の何を読んだか | 資格で検索しただけか、「どの範囲を、一人か複数で回し、何を直したか」を読んだか |
| 社内の範囲 | 仕訳から月次までか、決算まで社内か。会計事務所との分担。文面で分かるか |
| 一人か複数か、確認の仕組み | 一人なら誰が確認するか。休めるか。文面で分かるか |
| 数字が使われるか | 締めた数字を経営者が使うか、締めて終わりか |
| 締めの負荷と、仕組みの実態 | 月末月初の負荷。手作業の残り具合。隠さず書かれているか |

「資格を活かせます」は、資格で検索した文面が多く届いているので、読まれません。

## 送る前に決めること｜社内の範囲、決算の関わり、確認の仕組み、最初に任せること

送る前に、経営者が四つを決めます。決め方は[経理を採る募集記事の書き方](/media/wt-keiri-boshu/)で書きました。

- **社内の範囲**：仕訳／月次の締め／決算／税務。どこまで社内で、どこから会計事務所か。一文で
- **決算の関わり方**：資料を渡すだけか、一部を組むか、自分で組むか。いつから任せるか
- **確認の仕組み**：一人なら、誰が確認するか（経営者、事務所）。休むときどうするか。無いなら、作るところからと
- **最初に任せること**：「月次の〇〇の引き継ぎから」「紙の請求書の入力を仕組みに変えるところから」を一つ。これが文面の2段目になり、送る相手を「それができる人」に絞れる

## 誰に送るか｜資格の級や業界ではなく、範囲と規模、一人か複数か、直した経験の重なり

資格の級が高い人、同じ業界の経理経験者で選ぶと、面談で「範囲が違う」「規模が違う」になります。選ぶ基準は、「同じ範囲を、同じくらいの規模の会社で、一人か複数かが近い形で回し、何かを直した経験を書いているか」です。

| 読む箇所 | 重なりの見方 |
|---|---|
| 担当した範囲 | 仕訳だけか、月次まで回したか、決算を組んだか。自社の社内の範囲と同じか。ここが最も重なりが要る |
| 会社の規模 | 大きな経理部の一部か、小さな会社で全体か。自社の規模と近いか |
| 一人か複数か | 一人で回してきたか、分担の中でやってきたか。自社の形と合うか |
| 何を直したか | 「手作業を仕組みに変えて締めが早くなった」「ずれの原因を見つけて直した」が書かれているか。自社の「最初に任せること」と重なるか |
| 会計事務所との関係 | 事務所とやり取りしてきたか。渡す側か、組む側か。自社の分担と合うか |
| 数字の使われ方 | 経営者に数字を説明した経験があるか。締めて終わりだったか。自社の使われ方と合うか |

「何を直したか」が要点です。自社に手作業が多いなら、この記述のある人を優先します。

### 資格と転職の意思の読み方

経理は、資格の級を書いている人が多い職種です。級は学習の結果で、仕事の行動ではありません。級で絞ると、級は低いが月次を一人で回してきた人を落とし、級は高いが仕訳しか担当していない人が残ります。級は「あればよい条件」に置きます。また、会計士や税理士の試験を続けている人がいます。試験との両立をどう扱うかを社内で決め、外さずに文面で両立の扱いを書き、面談で聞きます。絞り方の基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「経理は、資格の級で絞って『資格を活かせます』と送れば返信が来る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトを見ていますが、経理が返信した文面を並べると、資格の級と「資格を活かせます」の一文は、返信の有無とほとんど関係がありません。経理は資格で検索した文面を多く受け取っていて、「資格を活かせます」は「読んでいない」と読まれます。関係があるのは、「自分がどの範囲を、一人か複数で回し、何を直したかを読んでくれたか」と、「社内の範囲と、一人か複数か、確認の仕組みが文面で分かるか」の二つです。一人経理でも、「一人。確認は月に一度事務所が見る。休むときは〇〇が最低限の入力をする」と書かれていれば、一人で回してきた人から返信が来ます。当社が対象を組み直すとき、最初にやるのは、検索条件から資格の級を外し、「どの範囲を、一人か複数で回した人か」で並べ直し、社内の範囲と確認の仕組みを文面の最初のほうに入れることです。

## 文面に書くこと

文面の型（相手の一文→自社の場面→話す場の案内）は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)に書いたので、ここでは経理特有の要点だけを書きます。

- **相手の一文は、範囲と直したことで**：「一人で月次まで回されていたと書かれていたのを読んで」「紙の請求書の入力を仕組みに変えて締めが早くなったと書かれていた点を読んで」。資格の級ではなく、回した範囲と直したこと
- **社内の範囲を、最初のほうで**：「うちは、仕訳から月次の締めまで社内。決算と税務は会計事務所です」。一文で
- **一人か複数か、確認の仕組みを、一文で**：「経理は一人です。確認は月に一度事務所が見て、経営者が数字の意味を聞きます。休むときは〇〇が最低限の入力をします」。隠さない
- **最初に任せることを、一文で**：「最初の月は、月次の〇〇の引き継ぎから」「紙の請求書の入力を、仕組みに変えるところから」。募集記事と同じ言葉
- **数字の使われ方を、一文で**：「月次の数字は、経営者が翌月の判断に使っています」「いまは締めて終わりで、使う形にしたい」
- **締めの負荷を、隠さずに**：「月末月初は〇〇の状態です」。数値は確認したものだけ
- **話す場は、経営者と**：「経営者の〇〇と、いまの経理の△△が、範囲と仕組みの実態を隠さず話します。転職を決めていなくても構いません」

相手の前の会社の仕組みを評価しません。

## 返信後の面談｜経営者が、数字の使われ方を話す

| 話すこと | 中身 |
|---|---|
| 社内の範囲と、事務所との分担 | 一文で。文面と同じことを。「決算は事務所」なら、そう言う |
| 一人か複数か、確認の仕組み | 誰が確認するか。休めるか。経営者本人が話す。「聞いていない」を出さない |
| 数字の使われ方 | 「月次の数字を見て、〇〇を決めた」。使っていないなら、使っていないと。経営者が話す |
| 仕組みの実態と、締めの負荷 | 手作業の残り具合、紙の有無、月末月初の実態。いまの経理が話す |
| 相手なら何から直すか | 最初に任せることについて、相手の考えを聞く。ここが長い面談ほど次につながる |
| 相手の仕事の話 | どの範囲を、一人か複数で回し、何を直したか。聞く時間を長く |

面談には、経営者と、いまの経理（または前任者、または事務所の担当）が出ます。経営者が「数字をどう使っているか」を本人の言葉で話すことが、「締めて終わりでない」の答えになります。面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

選考に進むとき、仕訳や締めの課題を出すなら、面談のときに「課題がある」「どのくらいの時間がかかるか」を先に伝えます。伝え方は[カジュアル面談から選考に進むときの伝え方](/media/wt-scout-senkou-ikou/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 社内の範囲、決算の関わり、確認の仕組み、最初に任せることを決める | 経営者 |
| 「範囲と規模、一人か複数か、直した経験」で対象を並べ直す | 人事（いまの経理が基準を伝える） |
| 相手の回した範囲と直したことを読み、一文を書く | 経営者かいまの経理（または人事が下書きし、本人が確認） |
| 仕組みの実態と締めの負荷の確認 | いまの経理 |
| 型、送信、返信対応、台帳 | 人事 |
| 面談 | 経営者と、いまの経理（または前任者） |

一人目の経理を採るスカウトでは、いま経営者か総務が兼務で仕訳をしていることが多くあります。その場合は、経営者が相手のプロフィールを読み、「一人目で、いまは私が兼務で入力している。決算は事務所。確認は事務所と私」と正直に文面に書きます。

運用代行や代理店が支えられるのは、対象の並べ直しの基準づくり、型、避ける言葉のチェック、募集記事との整合の確認までで、範囲と確認の仕組みの決定、相手の範囲を読んだ一文、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

経理にスカウトを送る前に、先に決めておかないと効果が出ないのは、「一人経理なら、誰が確認して、休むときどうするか」を一文にすることです。当社がWantedlyの経理向けスカウトを支えるとき、「一人経理だが、確認の仕組みは来た人と考える」という会社が多くあります。ただ、確認の仕組みが文面に無いと、相手には「間違いを一人で抱え、休めない仕事」と読まれて開かれません。逆に、「一人。確認は月に一度事務所が見る。休むときは〇〇が最低限の入力をする」と書いた会社は、返信の数は減っても、一人で回してきた人が来て、面談で「確認する人がいないとは聞いていない」になる人がいなくなります。当社が最初にお願いするのは、対象の絞り込みではなく、経営者に「経理が休んだ週に、誰が何をするか」を一文で言ってもらうことです。その一文が、確認の仕組みの有無を示し、文面の信用を決めます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 資格の級で相手を選ぶ | 級は高いが範囲が違う人が残る | 範囲と規模、一人か複数か、直した経験で選ぶ |
| 「資格を活かせます」と送る | 「読んでいない」と読まれ、開かれない | 相手の回した範囲と直したことを読んだ一文で |
| 社内の範囲を書かない | 「決算業務」と読まれ、面談で「事務所」と出て離れる | 範囲を一文で書く |
| 一人経理と確認の仕組みを隠す | 「休めない仕事」を想像される | 一人と書き、確認と休みの仕組みを書く |
| 締めの負荷を隠す | 入社後に分かり、離れる | 実態を書く。数値は確認したものだけ |
| 面談に経営者が出ない | 「数字が使われるか」が伝わらない | 経営者が出て、数字で何を決めたかを話す |

最も多いのは、最初の「資格の級で選ぶ」と、確認の仕組みの抜けです。

## まとめ

- 経理は、誰から来たか・自分の範囲の何を読んだか・社内の範囲・一人か複数かと確認の仕組み・数字が使われるか・締めの負荷、を文面の段階で見ている
- 送る前に、社内の範囲、決算の関わり方、確認の仕組み（誰が確認し、休むときどうするか）、最初に任せることを、経営者が決める。一人経理でも、隠さない
- 誰に送るかは、資格の級や業界ではなく、範囲と会社の規模、一人か複数か、「何を直したか」の重なりで。級は「あればよい条件」に。試験を続けている人を外さず、両立の扱いを書く
- 文面には、相手の範囲と直したことを読んだ一文、社内の範囲、確認の仕組み、最初に任せること、数字の使われ方、締めの負荷を。「資格を活かせます」を書かない
- 面談は経営者が出て、数字で何を決めたか、誰が確認するか、休めるかを本人の言葉で話す

## よくある質問

### 一人経理で、確認の仕組みがまだありません。文面にそう書くと開かれませんか

書かないほうが、開かれません。確認の仕組みが無い文面は「休めない仕事」と読まれます。「一人。いまは確認の仕組みが無い。月に一度事務所が見る形と、休むときに〇〇が最低限の入力をする形を、一緒に作るところから」と、無いことと、作る意思を一緒に書きます。

### 簿記の級が低い人にも送ってよいですか

級は「あればよい条件」です。級が低くても、「一人で月次まで回した」「手作業を仕組みに変えた」を書いている人は、自社の範囲と重なれば送ります。級が高くても、仕訳しか担当していない人は、月次を回す仕事とは重なりません。「〇〇を一人で回されていたと書かれていたのを読んで」と、範囲で送ります。

### 経理向けのスカウトの対象の絞り込みは、御社に相談できますか

できます。当社は、対象の並べ直しの基準づくり、文面の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。範囲と確認の仕組みの決定、相手の範囲を読んだ一文、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
