OfferBoxで学生がオファーを承認したのに、そのあとの連絡に返信が来ない、という相談があります。承認は、学生にとって「話を聞いてもよい」の意思表示で、応募ではありません。その気持ちは、時間が経つと薄れ、他社の連絡が早ければそちらに向きます。**結論から言うと、承認後に返信が来ないときは、まず自社の承認後の連絡が「当日に、短く、日程の候補を出して、学生の都合に合う形で」送られていたかを確かめます。送られていなければ、そこを直します。送られていて返信が無いなら、数日後に一度だけ短く確認し、それでも無ければ追わず、保留として台帳に残します。返信が来ない学生が多いなら、連絡の速さ・長さ・候補の出し方・時期・届いているか、の順に切り分けます。** この記事では、承認の意味、返信が来ない理由、対応、多いときの切り分け、台帳での見方、分担を整理します。承認後の連絡の基本は[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)で書きました。この記事は、それでも返信が来ないときの話です。

## この作業の目的｜「話を聞いてもよい」の気持ちを、薄れる前に面談につなぐ

承認した学生は、その時点で「話を聞いてみよう」と思っています。ただし、承認は複数の会社に対して行われることが多く、学生は承認したあと、連絡が早く、負担が少ない会社から順に面談を入れます。

目的は、承認の気持ちが薄れる前に、負担の少ない形で面談の日程を決めることです。返信が来ない多くの場合、原因は学生側ではなく、承認後の連絡の側にあります。

## 承認は「話を聞いてもよい」であって、応募ではない

- **選考として扱わない**：書類、志望動機を求めない
- **承認後の連絡は、面談の案内であって、選考の案内ではない**
- **学生は複数の会社を承認している**：自社だけが特別ではない
- **承認から連絡までの時間が、他社との差になる**：速い会社が先に面談を入れる

「承認してくれたのだから、返信するのが当然」という前提で連絡を組むと、返信が来ません。

## 返信が来ない理由

| 理由 | 何が起きているか |
|---|---|
| 承認後の連絡が遅かった | 承認の当日に連絡が無く、他社の面談が先に入った |
| 連絡が長い | 会社の説明、募集の詳細が長く、読まれずに閉じられた |
| 日程の候補が無い | 「ご都合を教えてください」で、学生に考えさせている |
| 学生の都合に合わない候補 | 平日の日中だけ。授業やアルバイトと重なる |
| 誰が話すかが無い | 「人事の説明を受けるだけでは」と後回し |
| 試験期間や選考の山 | 学生が動けない時期。返信が遅れるのは正常 |
| 複数の承認の中で埋もれた | 学生が多くの会社を承認していて、自社の連絡が下に |
| そもそも連絡が届いていない | 送信の設定、通知の仕組み。仕様は管理画面で確認 |
| 承認が、深く考えずに行われた | 承認の時点で「とりあえず」だった。合う相手でない可能性 |

最も多いのは、最初の「承認後の連絡が遅かった」と「日程の候補が無い」の二つです。どちらも、承認後の連絡の型で防げます。

### エージェントベストの見解

相談で最も多い思い込みは、「承認したのに返信が来ないのは、学生の意識が低いからだ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、返信が来ない学生の一覧と、承認後の連絡の記録を並べると、連絡が承認の翌日以降だった、連絡が長くて日程の候補が無かった、候補が平日の日中だけだった、という形がほとんどです。学生は、承認した複数の会社のうち、連絡が早く、候補が出ていて、自分の都合に合う会社から面談を入れます。当社が承認後の返信の相談を受けるとき、最初に見るのは、承認の日時と、こちらの最初の連絡の日時の差です。差が一日を超えていれば、そこが原因です。学生の意識より先に、自社の連絡の速さを見ます。

## 対応｜承認後の連絡を、当日に、短く、候補を出して

1. **承認の当日に返す**：翌日ではなく当日。通知を見る時間を一日二回決めておく。[OfferBoxの即日対応](/media/ob-sokujitsu-taiou/)
2. **短く**：「承認ありがとうございます。話を聞いてもらえるとのこと、うれしいです」と、日程の候補
3. **日程の候補を、こちらから複数出す**：「ご都合を教えてください」にしない
4. **学生の都合に合う候補を**：平日の日中に限らず、夕方以降や授業の無い曜日。オンライン
5. **誰が、どんな形で話すかを一文で**：「入社二年目の〇〇が、オンラインで、短い時間で、仕事の中身を話します。選考ではありません」
6. **返信の方法を一言**：「このメッセージに返信してもらえれば、日程を確定します」
7. **読んでおくものを一つだけ添えるか、添えない**：多く送らない

この形で送っていれば、返信が来ない学生は減ります。送っていなければ、まずここを直します。

## それでも返信が無いとき

| 経過 | 対応 |
|---|---|
| 承認後の連絡から数日 | 一度だけ、短く確認。「先日の日程の件、ご都合いかがでしょうか。候補を出し直します。〇〇と△△はいかがですか」。候補を変えて出す |
| 試験期間や選考の山 | 待つ。「試験が終わってからで構いません」と添えて、確認の時期を遅らせる |
| 確認しても返信が無い | 追わない。台帳に「保留」として残し、次の連絡日を空ける |
| 時期を置いて、材料が出たら | 「参考までに」の形で一度だけ。新しい社員の話、イベントの案内など |
| 「連絡は不要」と言われた | 送らない。台帳に印 |

「一度だけ確認し、追わない」が原則です。何度も送ると、承認した学生の印象が「しつこい会社」に変わり、次の学生にも影響することがあります。フォローの回数の考え方は[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)で書きました。

## 返信が来ない学生が、多いときの切り分け

一人二人ではなく、承認した学生の多くから返信が来ないなら、連絡の側に原因があります。

| 見ること | 見えるサイン | 直す場所 |
|---|---|---|
| 承認から最初の連絡までの時間 | 一日を超えている | 通知を見る時間と対応する人を決める |
| 連絡の長さ | 会社の説明、募集の詳細が入っている | 型を短く |
| 日程の候補 | 「ご都合を」で終わっている | 複数の候補を出す型に |
| 候補の時間帯 | 平日の日中だけ | 夕方以降と授業の無い曜日を |
| 誰が話すか | 書いていない | 名前と形を一文で |
| 送った時期 | 試験期間、選考の山 | 時期を待つ。[OfferBoxの送信タイミング](/media/ob-soushin-timing/) |
| 届いているか | 送信の記録と合わない | 設定を確かめる |
| 承認した学生の層 | プロフィールが薄い、希望が大きく違う | 送る相手のずれ。[OfferBoxの承認率が低いときに疑う3つの原因](/media/ob-shounin-hikui/) |

上から順に確かめます。「承認から最初の連絡までの時間」が一日を超えていれば、他を直す前に、そこを直します。

## 承認から返信までの時間を、台帳で見る

| 残すこと | 使い方 |
|---|---|
| 承認の日時 | 起点 |
| こちらの最初の連絡の日時 | 承認から連絡までの時間。一日を超えていないか |
| 学生の返信の日時 | 連絡から返信までの時間。学生がいつ読んでいるか |
| 返信の有無と、確認の回数 | 追いすぎていないか |
| 面談の日程が決まった日時 | 承認から面談までの間隔 |
| 返信が無かった学生の共通点 | 時期、層、候補の時間帯 |

「承認から最初の連絡までの時間」と「連絡から返信までの時間」を分けて見ると、遅いのがこちらか学生かが分かります。台帳の型は[OfferBoxのKPI設計](/media/ob-kpi-sekkei/)で書きました。

## 対応する人を、一人にする

- **承認の通知が、その人に届く形にする**：送る人が複数でも、通知は対応する人に集まる。設定は管理画面で確認
- **毎日、決まった時間に見る**：朝と夕方。承認の当日に返せる形
- **返信の型を用意する**：承認への返信、確認、保留。毎回書かない
- **対応する人が休む日の代わりを決める**：休みで数日空く、を防ぐ
- **日程の候補は、話す人の枠から先に決めておく**：承認が来てから話す人に聞かない

「対応する人が一人」と「通知が届く」の2つで、承認後の連絡の遅れはほとんど無くなります。チームで回す場合の考え方は[OfferBoxのチーム運用](/media/ob-team-unyou/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 承認後の連絡の型を作る | 人事 |
| 承認の当日に返す | 対応する人（人事） |
| 日程の候補を、話す人の枠から出す | 人事 |
| 一度だけ確認し、追わない | 対応する人 |
| 台帳に時間を残す | 対応する人 |
| 返信が来ない学生が多いときに切り分ける | 人事 |
| 面談で話す | 入社してまもない社員 |

運用代行や代理店が支えられるのは、承認後の連絡の型、確認の型、切り分けの一覧、台帳の型までで、当日に返すこと、日程の調整、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと承認が放置されることがあります。「承認の通知を、当日に対応できる人に集める」ことです。当社がOfferBoxの承認後の返信の相談を受けるとき、通知が送った人にだけ届き、その人が週に一度しか管理画面を開かない、という形をよく見ます。承認から連絡までに数日空き、学生は他社の面談を先に入れています。当社は、承認への返信の型と確認の型を用意して、対応する人に渡します。型があれば、対応する人は毎日数分で返せます。ただし、返すのは社内の人です。承認した学生は、会社の人と話したくて承認しています。当社が代わりに返すと、その時点で「会社の人ではない」と分かります。承認後の連絡は、型は当社、返すのは社内、の分担です。

## まとめ

- 承認は「話を聞いてもよい」の意思表示で応募ではない。学生は複数の会社を承認し、連絡が早く負担の少ない会社から面談を入れる
- 返信が来ない理由の多くは、承認後の連絡が遅い・長い・日程の候補が無い・候補が学生の都合に合わない、という連絡の側にある
- 対応は、承認の当日に、短く、複数の候補を学生の都合に合わせて出し、誰が話すかを一文で。数日後に一度だけ確認し、それでも無ければ追わず保留に
- 多くの学生から返信が来ないなら、承認から連絡までの時間→長さ→候補→時間帯→時期→届いているか→承認した学生の層、の順に切り分ける
- 承認から連絡までの時間と、連絡から返信までの時間を台帳で分けて見る。対応する人を一人にし、通知を集める

## よくある質問

### 承認後に丁寧な連絡を送っているのに、返信が来ません

「丁寧」が「長い」になっていないかを見ます。会社の説明や募集の詳細が入っていると、学生は読まずに閉じます。返す文面は短く、日程の候補と、誰が話すかで足ります。次に、承認から連絡までの時間を確かめます。翌日以降なら、当日に返す形にします。

### 返信が来ない学生に、何度まで連絡してよいですか

承認後の最初の連絡のあと、一度だけ確認します。それでも無ければ追いません。時期を置いて、新しい材料（社員の話、イベント）が出たときに「参考までに」と一度だけ送ることはできます。何度も送ると、印象が「しつこい会社」に変わります。

### 承認後の返信が来ない問題は、御社に相談できますか

できます。当社は、承認後の連絡の型、確認の型、切り分けの一覧、台帳の型を支えられます。当日に返すこと、日程の調整、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
