スタンダードプランは、Wantedlyの3つの有料プランの真ん中にあたり、公式には「募集・ストーリーに加えてスカウトも試したい企業向け」と説明されています。「試したい」という言い方のとおり、スカウトを本格的に回す前の段階の会社を想定したプランです。**結論から言うと、スタンダードプランは6ヶ月で150通のプレミアムスカウトを含み、管理画面に最大30名が入れるプランで、スカウトを少ない通数で試しながら、自社で送る型を作る段階の会社に向いています。** この記事では、公式ヘルプで確認できる中身と、ライト・プレミアムとの分かれ目を整理します（2026年9月30日時点。最新は公式ページでご確認ください）。

## 結論｜スタンダードプランの中身

ウォンテッドリー株式会社の企業向けヘルプの料金プランの表から、スタンダードプランの中身をまとめると次のとおりです。

| 項目 | スタンダードプランの内容 |
|---|---|
| 管理画面に入れる人数 | 最大30名 |
| 募集の掲載本数・応募者数 | 契約期間の中で上限なし |
| ダイレクトスカウト機能 | あり |
| プランに含まれるプレミアムスカウト | 6ヶ月で150通／12ヶ月で300通／24ヶ月で600通 |
| スカウトチケットの追加購入 | 可 |
| 契約期間 | 6ヶ月・12ヶ月・24ヶ月 |
| 料金 | 公式サイトに数字の掲載なし（料金表はフォームから） |

ライトプランの機能に、ダイレクトスカウトの機能が加わった形です。通数は期間に比例していて、6ヶ月あたり150通の割合で増えます。

## 仕組み｜プランの通数・追加購入・無料スカウトの関係

スタンダードプランで使えるスカウトは、大きく3つに分けて考えると整理しやすくなります。

1つ目はプランに含まれるプレミアムスカウトです。期間に応じて150通・300通・600通が付きます。6ヶ月で150通を週に直すと、1週あたり数通の計算です。

2つ目はスカウトチケットの追加購入です。ヘルプによると、スタンダードとプレミアムはチケットを追加で買え、残数がある状態でも購入できます。請求は、申し込んだ月の利用分として扱われます。通数が足りなくなったときに、プラン全体を変えずに補える手段です。

3つ目は無料スカウトです。募集を1本以上公開していれば、プランに関係なく使えます。送れる相手はプロフィールが充実している人やログインの頻度が高い人などに限られますが、通数の上限はありません。

もう1つ、チケットには有効期限があります。スカウトの送信予約のヘルプでは、予約した分がチケットの残数や有効期限を超えるとエラーになると案内されています。期限の近いチケットを予約に回すときは、送信日が期限を過ぎないかを見ておきます。

管理画面に入れる最大30名は、採用の「管理者」と「担当」の権限を付けたアカウントの合計で数えます。人事のほかに、現場のマネージャーや社員が募集記事やスカウトを書く体制でも、30名あれば多くの会社で足ります。

### エージェントベストの見解

スタンダードプランを契約した会社が、最初の1ヶ月で運用が止まるときに共通するのは、「誰に送るか」を決めないまま、プランの通数を目標にしてしまうことです。6ヶ月で150通という数字があると、それを期間内に使い切る計画を先に立てがちです。ところが、送る相手の条件と、その人に読んでほしい募集記事が決まっていないと、1通ごとに検索から考えることになり、書く時間が数倍かかります。当社が申込後の立ち上げで最初に作ってもらうのは、「この募集で会いたい人の条件」を3行で書いたメモと、その人向けの一文の型です。これができると、1通にかかる時間が読めるようになり、週に何通送れるかが見えます。通数を配分する考え方は[Wantedlyのスカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/)にまとめています。スタンダードの「試す」とは、通数を使い切ることではなく、自社で送る型を作ることだと考えると、次の更新でプランを上げるか据え置くかの判断がしやすくなります。

## 確認する項目｜ライト・プレミアムとの分かれ目

スタンダードにするかどうかは、隣の2つのプランと比べると判断しやすくなります。

| 比べる相手 | 確認すること |
|---|---|
| ライトプラン | スカウトを使う見込みがあるか。ライトではプランにスカウトが含まれず、使うならダイレクトスカウトオプションを別に契約する。チケットの追加購入はできない |
| プレミアムプラン | 6ヶ月で150通を超えて送る体制があるか。プレミアムは6ヶ月で300通、管理画面の人数は無制限 |

このほかに、申込前に確かめておく項目は次の4つです。

1. **最新の料金**：料金は公式サイトに数字で出ていません。料金表ダウンロードのフォームか販売パートナーから最新のものを受け取り、期間ごとの総額で比べます
2. **週に書ける通数**：書く人と、1通にかけられる時間から数えます。プランの通数を上回るなら追加購入かプレミアムを、下回るならライトとの比較も視野に入れます
3. **契約期間**：6ヶ月・12ヶ月・24ヶ月から選べます。通数は期間に比例するので、期間を長くしても1ヶ月あたりの通数は変わりません
4. **書く人の人数**：管理画面に入る人が30名に収まるか。現場の社員が書く場合は、誰に「管理者」と「担当」のどちらを付けるかも決めます

## 注意点｜スタンダードで起きやすいこと

スタンダードで起きやすいのは、通数が余る失敗と、足りなくなって慌てる失敗の両方です。

余る失敗は、先の見解に書いたとおり、送る相手が決まらないまま時間が過ぎるときに起きます。期間の後半にまとめて送ると、返信への対応や面談の枠が追いつかず、送った分が活きません。期間の最初から、週ごとに送る数を決めておきます。

足りなくなる失敗は、スカウトの反応が良かったときに起きます。追加購入で補えますが、請求は申し込んだ月の利用分として扱われるので、月の予算の範囲を事前に社内で決めておくと、慌てずに済みます。

もう1つは、名前の混同です。スタンダードプランに含まれるのは「プレミアムスカウト」という種類のスカウトで、ベースプランの「プレミアムプラン」とは別の話です。社内で「プレミアム」とだけ言うと取り違えが起きるので、書類では「スタンダードプラン（プレミアムスカウト150通／6ヶ月）」のように書きます。

最後に、スカウトを送るのは募集記事に人を呼ぶためなので、募集記事が整っていないと返信は伸びにくくなります。スカウトの基本は[Wantedlyのダイレクトスカウトの基本](/media/wt-scout-kihon/)、プラン全体の比べ方は[Wantedlyのプランの選び方](/media/wt-plan-erabikata/)で扱っています。

### エージェントベストの見解

「6ヶ月で150通」という数字は、送れる上限であって、会える人の数の見込みではありません。申込前の相談で、この通数を返信率で割って「何人と面談できるか」を計算しようとする会社がありますが、返信の割合は送る相手の選び方と一文の書き方で大きく変わるので、プランを選ぶ段階では計算の前提が置けません。当社がこの数字の読み方として勧めているのは、逆向きに使うことです。まず、この半年で面談したい人数と、社内で面談に出られる枠を決めます。次に、最初の1か月は週に数通だけ送り、返信と面談に進んだ割合を自社の数字として記録します。その割合が分かれば、150通で足りるのか、追加購入が要るのか、プレミアムにすべきかが、次の更新の前に判断できます。通数は、自社の割合を測るための最初の材料として読むと、プランの上げ下げを数字で決められます。

## まとめ

- スタンダードプランは、管理画面に最大30名が入れて、ダイレクトスカウトの機能を含むプラン
- プレミアムスカウトは6ヶ月で150通、12ヶ月で300通、24ヶ月で600通。期間を長くしても1ヶ月あたりの通数は同じ
- スカウトチケットの追加購入ができる。残数があっても買え、請求は申し込んだ月の利用分
- 料金は公式サイトに数字で出ていない。最新の料金表を公式のフォームか販売パートナーから受け取る
- 「試す」段階では、通数を使い切るより、送る相手の条件と一文の型を作ることを優先する

## よくある質問

### スタンダードプランの通数を使い切ったらどうなりますか

スカウトチケットを追加で購入できます。ヘルプでは、残数がある状態でも購入でき、請求は申し込んだ月の利用分になると案内されています。募集を1本以上公開していれば使える無料スカウトも、あわせて使えます。

### 通数が余った場合、次の期間に持ち越せますか

チケットには有効期限があると、送信予約のヘルプに書かれています。持ち越しの扱いを詳しく説明した公開情報は確認できなかったため、契約前にウォンテッドリー株式会社か販売パートナーに確かめてください。

### スタンダードプランの料金を教えてもらえますか

公式サイトには数字で掲載されていないため、当社から最新の料金表をもとにご案内します。当社は販売パートナーで、代理店手数料は媒体側から支払われるため、企業の料金はWantedlyの正規料金のままです。
