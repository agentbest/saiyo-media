客先常駐のエンジニアを送り出す会社、受託と常駐を併せ持つ会社、未経験の研修から始める会社、フリーランスのエンジニアを扱う会社が、Wantedlyで採用する。SESは、Wantedlyに会社が多く並ぶ業界で、候補者はSES会社の会社ページを何社も並べて読んでいる。並ぶ中で、多くの会社ページが「自社開発もあります」「受託もあります」「エンジニアファースト」で書かれ、業界イメージ（常駐先が決まらない、スキルが付かない、帰属がない）を否定しようとしている。候補者は、その言葉で押しても、面談で「実態は常駐が中心」「常駐先は営業が決める」「待機のときの扱い」を聞いて離れる。**結論から言うと、SESのWantedlyは、業界イメージを否定せず、実態を先に書きます。常駐と受託と自社開発の割合を隠さず、「自社開発もあります」で自社開発の像を呼びません。常駐先の決まり方（誰が決めるか、希望はどう通るか、断れるか、待機のときどうなるか）、単価と評価と収入の関係、帰社日と帰属の実態を、会社ページの最初に書きます。未経験（研修から始める）と経験者（常駐先を選ぶ）の入口を分け、それぞれで「最初の常駐先がどう決まるか」を書きます。「自社開発もあります」で入った人が常駐で離れる形を、割合を先に書くことで防ぎます。** この記事では、SESの採用構造とWantedlyとの相性、イメージを否定しない見せ方、割合と常駐先の決まり方の書き方、未経験と経験者の分け方、ストーリーとカジュアル面談とスカウトの運用設計、社内の分担を整理します。媒体の選び方は[SES業界の採用媒体の選び方](/media/hikaku-ses-erabikata/)、業界の像とのずれは[Wantedlyで業界のイメージとのずれを扱う方法](/media/wt-gyokai-image/)で書きました。数値と料金は書きません。

## SESの採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| 常駐が中心の会社 | 経験者の中途と、未経験の研修。営業が常駐先を決める | 向く。常駐の割合と決まり方を隠さず。「自社開発もあります」で埋めない |
| 受託と常駐を併せ持つ会社 | 受託のチームと常駐のエンジニア。行き来がある | 割合と、受託に移る条件を実態で。「受託もあります」の一語で済ませない |
| 未経験の研修から始める会社 | 未経験を研修して常駐に出す。最初の常駐先が肝 | 未経験の入口を分け、研修の中身と最初の常駐先の決まり方を先に |
| フリーランスを扱う会社 | 業務委託のエンジニアと、社員の営業とサポート | 社員の募集と業務委託の募集を分ける。混ぜない |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| SES会社が多く並ぶ | 「自社開発もあります」で同じに見える | 割合と決まり方の実態で |
| 業界イメージが先にある | 否定する会社ページが疑われる | 否定せず、実態と変えたことを |
| 常駐先の決まり方が会社で違う | 「希望が通る」と思って入って離れる | 誰が決めるか、希望はどう通るか、断れるかを先に |
| 待機と単価と評価が収入を決める | 知らずに来て、待機で離れる | 隠さず先に |

## イメージを否定せず、割合と常駐先の決まり方を先に書く

- **「自社開発もあります」「受託もあります」「エンジニアファースト」を、会社ページの最初から外す**：自社開発の像を呼ぶ言葉。割合が小さいなら、像で押されて常駐で離れる
- **常駐と受託と自社開発の割合を、隠さず**：「常駐が〇〇、受託が△△、自社開発が□□」。数値は自社の実態で。この記事では書かない。「受託に移る条件は〇〇」
- **常駐先の決まり方を、書く**：「常駐先は〇〇（営業・本人・両方）が決める。希望は△△の形で出せて、□□の頻度で通る。断ることは〇〇」。「希望を聞きます」の一語で済ませない
- **待機のときの扱いを、書く**：「常駐先が決まらない期間は〇〇。その間の△△」。伏せると、入った後に知られる
- **単価と評価と収入の関係を、隠さず**：「評価は〇〇で決まり、収入は△△の形。単価は□□」。「SESだから」で伏せない。[Wantedlyの募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)
- **帰社日と帰属の実態を、書く**：「帰社は〇〇の頻度。常駐先での△△。会社との接点は□□」。「帰属意識を大切に」の一語で済ませない
- **何を変えたか、何はまだ変えられていないかを、書く**：「常駐先の決め方を〇〇に変えた。△△はまだ変えられていない」。[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)

### エージェントベストの見解

これは契約後に起きることの話です。SESの会社が、「自社開発もあります」「受託もあります」で募集記事を書いて採り、入った人が最初の常駐か、常駐先が決まらなかった期間か、二つ目の常駐先が希望と違ったときに離れる形を、当社は繰り返し見ています。「自社開発もあります」で来た人は、「いずれ自社開発に関われる」を期待していて、実態が「常駐が中心で、自社開発は一部の人で、移る条件が決まっていない」であることを、入ってから知ります。当社がお願いしているのは、募集記事と面談で「常駐が〇〇、自社開発が△△。移る条件は□□。常駐先は〇〇が決めて、決まらない期間は△△」と先に伝え、常駐しているエンジニアが「最初の常駐先が決まるまで」と「二つ目の常駐先に移った日」をストーリーで本人の言葉で書くことです。実態を知って来た人は、常駐を仕事として引き受けます。「自社開発もあります」で集めた人は、最初の常駐で離れます。

## 未経験と経験者の入口を分ける

- **未経験の募集は、研修の中身と最初の常駐先の決まり方で**：「研修は〇〇の期間で△△を学び、最初の常駐先は□□の形で決まる。最初の常駐先の仕事は〇〇が多い」。「未経験からエンジニアに」の一語で済ませない
- **経験者の募集は、常駐先の選び方と単価と評価で**：「常駐先は〇〇の候補から本人が選べる。単価は△△に反映され、評価は□□」
- **一つの募集に「未経験歓迎・経験者優遇」と並べない**：両方が来て、面談で行き違う
- **フリーランスを扱う会社は、社員の募集と業務委託の募集を分ける**：Wantedlyは自社で働く人を募る場として、社員の営業とサポートの募集に。業務委託のエンジニアの募集と混ぜない。[Wantedlyで副業の募集を書くときの設計](/media/wt-fukugyo-boshu/)
- **「こんな人」は、「常駐先で一人で判断した・違う現場に移って立ち上がった・自分で技術を学び続けた」の記述で**：「向上心がある」「エンジニアになりたい」で絞らない

募集記事の「こんなことやります」は[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)、会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

## ストーリーとカジュアル面談の設計

- **常駐しているエンジニアのストーリーで、「最初の常駐先が決まるまで」「二つ目の常駐先に移った日」を本人の言葉で**：[Wantedlyのストーリーで事業の中身を書く方法](/media/wt-story-jigyo/)
- **未経験で入った人のストーリーで、「研修と、最初の常駐先の実態」を本人の言葉で**：[Wantedlyの入社後ストーリーの書き方](/media/wt-story-nyusha/)
- **代表のストーリーで、「何を変えたか」と「何はまだ変えられていないか」を**：[Wantedlyのストーリーで代表の考えを書く方法](/media/wt-story-daihyo/)
- **カジュアル面談で、割合と常駐先の決まり方と待機と単価を、聞かれる前に伝える**：[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **面談に、営業と常駐しているエンジニアが出る**：決める側と、決められた側の両方が話す

## スカウトの設計

- **絞るのは、「常駐先で一人で判断した・違う現場に移って立ち上がった・自分で技術を学び続けた」の記述**：「エンジニア」「向上心」の言葉で絞らない。[Wantedlyのスカウトで対象を絞る方法](/media/wt-scout-target/)
- **文面は、割合と常駐先の決まり方を最初に**：「常駐が〇〇の会社で、常駐先は△△の形で本人が選べて、あなたの□□を読んで」。「自社開発もあります」で始めない。[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)
- **返信の枠を、営業の稼働と別に決める**：営業が返信を担うと、案件の忙しさで止まる。[Wantedlyのスカウトを一人で回すときの設計](/media/wt-scout-hitori/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「自社開発もあります」を外し、常駐と受託と自社開発の割合を書く | 代表と人事 |
| 常駐先の決まり方、待機の扱い、単価と評価の関係、帰社日を、何を書くか決める | 営業の責任者と代表 |
| 未経験と経験者の入口を分け、業務委託の募集と混ぜない | 人事 |
| 常駐しているエンジニアが「最初の常駐先が決まるまで」を、営業が「どう決めているか」を話す | エンジニア・営業 |
| カジュアル面談に営業とエンジニアが出て、実態を先に伝える | 営業・エンジニアと人事 |
| 返信を、営業の稼働と別の枠で行う | 人事 |
| スカウトを割合と決まり方を最初に、入口ごとの文面で送る | 人事（絞る作業は外に出せる） |

運用代行や代理店が支えられるのは、否定しない書き方の型、入口を分ける型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業までで、割合と決まり方と待機と単価の開示、代表が話すこと、営業とエンジニアが話すこと、面談は会社が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。SESの会社が、一つの募集記事に「未経験歓迎・経験者優遇」と並べ、未経験と経験者の両方を受けようとする形を、当社は見ています。未経験の候補者が知りたいのは、研修の中身と、最初の常駐先がどう決まり、最初の仕事が何かで、経験者の候補者が知りたいのは、常駐先を自分で選べるか、単価がどう収入に反映され、評価がどう決まるかです。一つの募集に混ぜると、どちらの問いにも記事が答えられず、どちらも「自分に向けた募集ではない」と読みます。当社がお願いしているのは、未経験と経験者の募集を分け、未経験には研修と最初の常駐先の決まり方を、経験者には選び方と単価と評価を、それぞれ最初に書くことです。分けると、候補者は自分の入口が分かり、面談で話すことが決まります。

## まとめ

- Wantedlyに並ぶSES会社の多くが「自社開発もあります」「エンジニアファースト」で業界イメージを否定していて、その言葉で押した候補者は常駐の実態で離れる。否定せず、常駐と受託と自社開発の割合を隠さず書く
- 常駐先の決まり方（誰が決めるか、希望はどう通るか、断れるか）、待機のときの扱い、単価と評価と収入の関係、帰社日と帰属の実態を、会社ページの最初に。何を変えたか、何はまだ変えられていないかも
- 未経験（研修の中身と最初の常駐先の決まり方）と経験者（常駐先の選び方と単価と評価）の入口を分ける。フリーランスを扱う会社は、社員の募集と業務委託の募集を混ぜない
- 常駐しているエンジニアが「最初の常駐先が決まるまで」「二つ目の常駐先に移った日」を、営業が「どう決めているか」を本人の言葉で。面談に営業とエンジニアの両方が出る
- スカウトは「向上心」ではなく「常駐先で一人で判断した・違う現場に移って立ち上がった」の記述で絞り、割合と決まり方を最初に。返信の枠を営業の稼働と別に決める

## よくある質問

### 自社開発が少しでもあるなら、書いてよいのでは

事実として、割合と共に書いてください。「常駐が〇〇、自社開発が△△。移る条件は□□」の形で。「自社開発もあります」の一語だけで書くと、自社開発の像で押され、最初の常駐で離れます。割合と移る条件を書くと、常駐を知った上で来る候補者が残ります。

### 業界イメージが悪くて、応募が来ません

「うちは違います」と否定すると、イメージを思い出させ、書かれていない実態を疑わせます。常駐先の決まり方、待機の扱い、単価と評価の関係を実態で書き、「〇〇を変えた。△△はまだ変えられていない」と、変えたことと変えられていないことを分けて書いてください。実態を書いた会社として読まれ、並ぶSES会社の中で区別されます。

### SESのWantedlyの設計は、御社に相談できますか

できます。当社は、否定しない書き方の型、入口を分ける型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業を支えられます。割合と決まり方と待機と単価の開示、代表が話すこと、営業とエンジニアが話すこと、面談は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
