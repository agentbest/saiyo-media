上場企業が媒体を選ぶとき、最初にぶつかるのは「知名度があるので承認も応募も来るのに、文面が本社の名義の会社紹介で『会社が送った』と読まれ、開示のルールで一通ごとに広報と法務の確認が入って返信が数日遅れ、クチコミに書かれたことに公式の返し方が無く、体験談と企業ページのずれを学生に指摘される」という問題です。**結論から言うと、知名度がある上場企業ほど、文面も企業ページも「会社が送った」「会社が書いた」と読まれます。現場の若手の名義で「なぜあなたに」を書き、開示のルールは「書かないことの一覧」を広報・法務と作って確認を共通原稿の一度に絞ります。3媒体はナビと自社応募で来ない層に、クチコミは公式の返し方を決めて、体験談との一致を年に数回確かめます。** 準備期の考え方は[IPO準備企業の採用媒体の選び方](/media/hikaku-ipo-erabikata/)、大企業の本社と部門の分担は[大企業の採用媒体の選び方](/media/hikaku-daikigyo-erabikata/)で書きました。この記事は上場企業に絞って、知名度と開示のルールの中での媒体の使い方を書きます。

## 上場企業に、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 知名度があり、承認も応募も来る | 文面と企業ページが「会社が送った」「会社が書いた」と読まれる | 現場の若手の名義で「なぜあなたに」を。[上場企業のOfferBox運用](/media/ob-joujou-unyou/) |
| 開示のルールがある | 文面や企業ページの確認に広報と法務が入り、返信が遅れる | 書かないことの一覧を作り、確認を共通原稿の一度に |
| 体験談とクチコミが多く、公開されている | 企業ページとのずれを学生に指摘される。クチコミに公式の返し方が無い | 一致を年に数回確かめ、返し方を決める |
| 同業の上場企業と並べられる | 「安定」「上場」は同業も同じで、差がつかない | 配属の決まり方と任される場面で |
| ナビと自社応募で多くが来る | 3媒体で届く学生の多くが、自社応募でも来る | 3媒体は来ない層に絞る |
| 数値を書きたくなる | 開示に触れる数値は書けず、書けても学生には伝わらない | 数値は書かず、場面と決まり方で |

## 判断軸を、上場企業に当てる

| 軸 | 上場企業での見方 |
|---|---|
| 対象（誰に届くか） | ナビと自社応募で来る層と来ない層を、職種ごと層ごとに分ける。3媒体は来ない層に。「上場企業に入りたい」で絞らない。その層は同業の上場企業と並べて離れる |
| 型（送るか、来るか、比べられるか） | 比べられる型は、候補に入っている会社の入口で、企業ページが体験談とクチコミと比べられる前提。送る型は、来ない層に現場の若手の名義で一人ずつ。来る型は、エンジニアなど自社応募の入口で実態が読まれない職種に |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。費用の承認にも手順がある。年間で一度に |
| 運用工数（誰の時間が要るか） | 人事の時間に、広報・法務との確認の時間が加わる。確認を共通原稿の一度に絞らないと、返信の日数が伸びる。クチコミへの返し方の時間も |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。上場企業では、「運用工数」に確認の時間とクチコミの時間を入れることと、「対象」を「上場企業に入りたい」層で絞らないことが、他の会社と違います。

### エージェントベストの見解

上場企業で、媒体を契約した後に起きることを、当社は先にお伝えしています。当社は3媒体すべての販売パートナーとして、上場企業の相談を受けますが、契約の後に最も多く起きるのは、「開示のルールを理由に、文面の一通ごとに広報と法務の確認が入り、承認や応募への返信が数日から一週間遅れる」ことです。学生は返信が遅い会社から順に離れ、上場企業は知名度がある分、「あの会社は返信が遅い」と体験談に書かれて広がります。媒体が悪いのではなく、確認の単位が一通ごとになっていることが原因です。逆に、契約の前に、広報・法務と「書かないことの一覧」（開示に触れる数値、未公表の情報、他社の名前、比較の表現）を作り、「共通原稿と返信の型は一度確認。個別の一文は一覧の範囲で現場の裁量」と決めた会社は、確認が年に数回で済み、返信が遅れません。当社が最初にお願いするのは、媒体を選ぶ前に、広報・法務と一覧を作り、確認の担当と期限（送る時期の〇週間前まで）を決めることです。一覧があれば、現場の若手が自分の言葉で一文を書いても、外れません。

## 学生が、確かめること

- **「会社が送った」か「この人が送った」か**：知名度のある会社の文面は、会社が送ったと読まれる。現場の若手の名義で「なぜあなたに」が書かれているか
- **配属と育成の決まり方**：上場企業で最も読まれる。いつ、誰が、何を見て決めるか。研修の後に誰が横につくか
- **体験談やクチコミとの一致**：企業ページに書いたことが、体験談で「そのとおり」か、クチコミで「違う」と書かれていないか
- **同業の上場企業と何が違うか**：「安定」「上場」ではなく、配属の決まり方と任される場面の違い
- **クチコミに、会社がどう向き合っているか**：書かれたことに公式の返しがあるか、無視しているか
- **返信の速さ**：確認で遅れると、「遅い会社」と広がる

## この条件なら、3媒体をどの役割で使うか

| 会社の条件 | 3媒体の役割 | 理由 |
|---|---|---|
| 候補に入っていて、体験談とクチコミが多い | 比べられる場（ワンキャリア）を入口に。企業ページを体験談と一致させ、クチコミに公式で返す | 候補に入っている会社の入口。比べられる前提で書く。[ワンキャリアのクチコミへの公式の返し方](/media/oc-kuchikomi-koushiki/) |
| 自社応募の記録で、来ていない層（特定の職種、地方、専攻、後期）が分かる | 送る型（OfferBox）でその層に、現場の若手の名義で | 来ない層に一人ずつ。会社紹介を削り「なぜあなたに」に使う |
| エンジニアや研究職など、自社応募の入口では実態が読まれない職種がある | 記事を置く型（Wantedly）でその職種の実態を通年で | 職種ごとの実態を、自社応募の外で読ませる。記事の確認も一度で |
| 書かないことの一覧と確認の単位が、広報・法務と決まっていない | どれも先ではない | 返信が遅れる。決めてから |
| クチコミの公式の返し方が決まっていない | 比べられる場は先ではない | 返し方が無いと、書かれっぱなしになる |

どれか一つが正解ではなく、来ていない層がどこか、体験談の偏り、確認の単位で、3媒体の役割が変わります。

## 組み合わせ

- **共通原稿を一度確認し、全媒体で使い回す**：媒体ごとに確認しない
- **受け皿と3媒体を、層で分ける**：[複数の媒体を同時に使うときの考え方](/media/hikaku-fukusuu-baitai/)
- **比べられる場と送る型を組み合わせる**：[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **クチコミと体験談の扱いを、年に数回の見直しに**：[ワンキャリアとOpenWorkの違い](/media/hikaku-onecareer-openwork/)、[ワンキャリアのクチコミへの向き合い方](/media/oc-kuchikomi-kaizen/)
- **広報と採用の線を引く**：採用の企業ページと文面は広報の原稿とは別の型。[ワンキャリアのクチコミと広報の関係](/media/oc-kuchikomi-kouhou/)
- **代行と組み合わせるなら、共通原稿の下書きと来ない層の絞る作業と台帳を**：広報・法務との確認、名義、面談は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜会社紹介を削り、「なぜあなたに」に使う

- **会社紹介を、削る**：知名度のある会社の紹介は、学生が知っている。文面の共通部分は三行以内
- **「なぜあなたに」を、現場の若手の名義で**：「〇〇と書かれていたのを読んで、△△部門の□□が声をかけたいと言った」。会社が送ったと読まれない形
- **配属と育成の決まり方を、企業ページの最初に**：「入社〇か月の研修の後、本人の希望と研修中の様子と部門の枠で決める。希望と違った人は△割」
- **開示に触れる数値を、書かない**：一覧に従う。数値で示したいことは、場面と決まり方に置き換える。数値は自社の実態を確認したものだけ。この記事では書かない
- **体験談とクチコミと、一致させる**：公開前と年に数回、書いたことが「違う」と書かれていないかを確かめる
- **クチコミに、公式で返す**：返し方の型を決め、書かれたことを無視しない。[ワンキャリアのクチコミの公式の返し方](/media/oc-kuchikomi-koushiki/)
- **同業との違いを、決まり方で**：「同業と違うのは、配属を〇〇が決めること」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 書かないことの一覧、確認の単位と担当と期限を決める | 広報・法務と人事の責任者。契約の前に |
| 共通原稿（企業ページ、文面の型、返信の型、記事）を書く | 人事。広報・法務が一度確認 |
| 個別の一文 | 現場の若手の名義。一覧の範囲で裁量 |
| 返信と日程 | 媒体ごとに担当を一人。日数を決めて守る |
| 面談と面接 | 名義の若手と部門の面接官 |
| 体験談・クチコミとの一致の確認と、公式の返し | 人事と広報。年に数回と、書かれたとき |
| 来ていない層の特定と、近い学生の数の記録 | 人事。自社応募の記録を層ごとに |

運用代行や代理店が支えられるのは、一覧の型、確認の単位の整理、共通原稿の下書き、来ない層の絞る作業、台帳の型、クチコミの返し方の型までで、一覧の決定、広報・法務との確認、名義の若手、面談、公式の返しそのものは社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「上場企業は知名度と安定があるから、企業ページに『上場』『安定』『福利厚生』を書けば学生が選ぶ」というものです。当社が同業の上場企業数社の企業ページを並べて読むと、「上場」「安定」「福利厚生が充実」は全社に書かれていて、学生は読み飛ばし、体験談とクチコミで実態を確かめています。しかも「上場企業に入りたい」で来た学生は、同業の上場企業と並べて、配属の決まり方が明確なほうに行きます。知名度と安定は、選ばれる理由ではなく、候補に入る条件です。逆に、企業ページから「上場」「安定」を減らし、配属と育成の決まり方を最初に置き、現場の若手の名義で「なぜあなたに」を書き、クチコミに公式で返した会社は、同業と並べられたときに「決まり方が書いてあり、クチコミに向き合っている会社」として残ります。当社が最初にお願いするのは、企業ページから「上場」「安定」「福利厚生」を消して、残った文で同業と差がつくかを見ることです。残らないなら、書くべきは決まり方と場面と、クチコミへの返しです。

## まとめ

- 上場企業は、知名度がある分、文面も企業ページも「会社が送った」「会社が書いた」と読まれる。現場の若手の名義で「なぜあなたに」を書き、会社紹介を削る
- 開示のルールは、広報・法務と「書かないことの一覧」を作り、確認を共通原稿の一度に絞る。一通ごとの確認は返信を遅らせ、「遅い会社」と広がる
- 3媒体はナビと自社応募で来ない層に。比べられる場（ワンキャリア）は候補に入っている入口として体験談と一致させ、送る型（OfferBox）は来ない層に若手の名義で、記事を置く型（Wantedly）は実態が読まれない職種に
- クチコミは公式の返し方を決めて無視せず、体験談との一致を年に数回確かめる
- 「上場」「安定」「福利厚生」は候補に入る条件で、選ばれる理由ではない。配属と育成の決まり方と場面で同業と差をつける

## よくある質問

### 開示のルールがあるので、現場の若手に自由に書かせるのは不安です

一覧があれば、不安は減ります。「書かないことの一覧」（開示に触れる数値、未公表の情報、他社の名前、比較の表現）を広報・法務と作り、現場の若手にはその一覧を渡して、一覧の範囲で個別の一文を書いてもらいます。一覧の外に出た文面は人事が止めます。一通ごとに確認するより、一覧で範囲を決めるほうが、外れる文面は減り、返信は遅れません。年に一度、一覧を見直します。

### クチコミに事実と違うことが書かれています

公式の返し方の型を決めて、返します。事実と違う点は、感情を入れずに事実を書き、企業ページの該当箇所を示します。無視すると、学生は「向き合わない会社」と読みます。返しの原稿は共通原稿と同じく広報・法務で一度確認した型を使い、書かれるたびに確認に通さない形にします。事実と一致している指摘なら、企業ページのほうを直し、「変えた」と返します。

### 上場企業の媒体選びは、御社に相談できますか

できます。当社は、一覧の型、確認の単位の整理、共通原稿の下書き、来ない層の絞る作業、台帳の型、クチコミの返し方の型を支えられます。一覧の決定、広報・法務との確認、名義の若手、面談、公式の返しそのものは、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、上場企業の3媒体の役割づけと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
