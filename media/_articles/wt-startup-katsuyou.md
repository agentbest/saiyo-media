シード、シリーズA、シリーズB以降、大学発、地方のスタートアップが、Wantedlyで採用する。Wantedlyはスタートアップが最も多く並ぶ場で、募集記事には「ビジョン」「急成長」「裁量」「一緒に世界を変える」の同じ言葉が並び、候補者には差にならない。候補者が確かめているのは、資金の状況と段階、自分の役割が決まっているか、代表の人柄と考え、「何でもやる」の実態、副業や業務委託から入れるか、で、多くの募集記事はそこに答えていない。**結論から言うと、スタートアップのWantedlyは、「ビジョン」「急成長」の言葉を外し、段階（シード、シリーズA、シリーズB以降）で書くことと会う相手を分けます。募集記事の「なにを」に段階と資金の状況を、「こんなことやります」に役割が決まっているか決まっていないかと「何でもやる」の実態を、「なぜ」に代表の「今週変わったこと」を代表の名義で書きます。副業・業務委託の入口を正社員の募集と分けて置き、「話を聞きに行きたい」への返信を代表が止めない枠を先に取り、カジュアル面談を代表と若手の二人で組みます。** この記事では、スタートアップの採用構造とWantedlyとの相性、段階ごとの書き分け、会社ページと募集記事の見せ方、ストーリーとカジュアル面談とスカウトの運用設計、社内の分担を整理します。媒体の選び方は[スタートアップの採用媒体の選び方](/media/hikaku-startup-erabikata/)、募集記事の基本は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。数値と料金は書きません。

## スタートアップの採用構造と、Wantedlyとの相性

| 段階 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| シード | 代表と数人。役割が決まっていない。資金が限られる | 「何でもやる」を隠さず。副業・業務委託の入口が主。代表の名義で |
| シリーズA | 役割が決まり始める。最初の採用担当がいないことが多い | 役割が決まっている部分と決まっていない部分を分けて書く。代表が返信する枠を先に |
| シリーズB以降 | 役割が分かれ、人事がいる。知られ始める | 職種ごとに募集を分ける。「急成長」で埋めず、今週変わったことを |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| スタートアップが最も多く並ぶ場 | 「ビジョン」「急成長」の同じ言葉で埋まり、差にならない | 言葉を外し、段階と役割と今週変わったことで |
| 資金の状況と段階を、候補者が確かめている | 書かないと、面談で聞かれ、「隠している」と読まれる | 「なにを」に段階と資金の状況を事実で |
| 役割が決まっていない | 「裁量」の言葉で来て、「何でもやる」の実態で離れる | 決まっている部分と決まっていない部分を分けて書く |
| 代表が一人で運用し、返信が止まる | 「話を聞きに行きたい」の後に返信がなく、候補者が離れる | 代表が止めない返信の枠を先に |
| 副業・業務委託から入る人が多い | 正社員の募集だけでは、入口が狭い | 副業の募集を分けて置く |

## 段階で、書くことと会う相手を分ける

- **シードは、「何でもやる」を隠さず、副業・業務委託の入口を主に**：「役割は決まっていない。〇〇と△△と□□を、その日に決める」。正社員の募集より、まず関わってもらう入口を。[Wantedlyの副業・業務委託の募集記事の書き方](/media/wt-fukugyo-boshu/)
- **シリーズAは、決まっている役割と決まっていない役割を分けて書く**：「〇〇は決まっていて△△をする。□□はまだ決まっていない」。「裁量」の一語で済ませない
- **シリーズB以降は、職種ごとに募集を分け、「急成長」を外す**：「〇〇の職種で、△△をする。最初の役割は□□」。他のスタートアップと同じ言葉を外す
- **段階ごとに、会う相手を決める**：シードは「決まっていないことに向く人」、シリーズAは「役割を作れる人」、シリーズB以降は「職種で絞る」

### エージェントベストの見解

これは発注側の誤解の話です。スタートアップの代表から、「募集記事はビジョンと急成長と裁量を前に出して、共感してもらいたい」と相談されることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、Wantedlyはスタートアップが最も多く並ぶ場で、候補者は同じ日に「ビジョン」「急成長」「裁量」「一緒に世界を変える」の募集記事を何本も読んでいて、その言葉はどの会社のものかを区別できません。候補者が確かめているのは、資金の状況と段階、役割が決まっているか、代表の人柄、「何でもやる」の実態で、そこに答えた募集記事だけが、並んだ中で読まれます。当社が代表にお願いしているのは、「ビジョン」「急成長」を外し、「〇〇の段階で、△△の状況、役割は□□が決まっていて〇〇が決まっていない」と事実で書き、「なぜ」に「今週、こう変えた」を代表の名義で書くことです。

## 会社ページと募集記事の見せ方｜同じ言葉を外し、段階と役割と今週変わったことを

- **「なにを」に、段階と資金の状況と顧客を**：「〇〇の段階で、△△の顧客に□□を提供している」。「世界を変える」の一語で済ませない
- **「なぜ」に、代表の「今週変わったこと」を**：「今週、〇〇を見て、△△をやめて□□に変えた」。ビジョンではなく、動いている場面。[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)
- **「こんなことやります」に、役割が決まっているかと「何でもやる」の実態を**：「〇〇は決まっていて、△△は日によって変わる。先週は□□をした」。[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)
- **「こんな人」を、「決まっていないことに向く人」で**：「決まっていない中で〇〇を決めて動いた・自分で作って公開した・違う立場の人を巻き込んだ」の記述で。「ベンチャー志向」「成長したい」で絞らない
- **待遇と資金の状況を、隠さず**：「〇〇の段階の待遇で、△△」。[Wantedlyの募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)
- **副業・業務委託の募集を、正社員と分けて置く**：「まず〇〇を週△△で」。入口を狭くしない

会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)、素顔を出す範囲は[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)で書きました。

## ストーリーとカジュアル面談の設計

- **ストーリーは、代表の「今週変わったこと」を頻度で**：長い理念の記事より、「今週、〇〇を変えた」の短い記事を続ける。[Wantedlyのストーリーの更新頻度の決め方](/media/wt-story-hindo/)
- **若手か副業の人のストーリーで、「何でもやった一か月」を本人の言葉で**：「入った月に〇〇と△△と□□をした。決まっていなかったことを〇〇で決めた」
- **カジュアル面談は、代表と若手の二人で**：代表の人柄と、若手の実態を、同じ場で。選考にしない。[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)

## 「話を聞きに行きたい」への返信と、スカウトの設計

- **代表が返信を止めない枠を、先に取る**：代表が一人で運用すると、資金調達や顧客対応の時期に返信が止まる。返信する曜日と時間を先に決め、止まる時期は若手か副業の人が一次返信をする。[Wantedlyのスカウトに返信が来ないときの見直し](/media/wt-scout-henshin-nai/)
- **スカウトは、代表の名義で、段階と役割と今週変わったことを最初に**：「〇〇の段階で、役割は△△が決まっていて□□が決まっていない。今週〇〇を変えた。あなたの△△を読んで」。[Wantedlyのスカウトを代表名で送るときの考え方](/media/wt-scout-daihyo/)
- **絞るのは、「決まっていない中で決めて動いた・自分で作って公開した・違う立場の人を巻き込んだ」の記述**：「スタートアップに興味」「ベンチャー志向」で絞らない
- **副業から入ってもらう文面を、正社員と分ける**：「まず〇〇を週△△で、一緒にやってみませんか」。[Wantedlyで副業から入ってもらうスカウトの書き方](/media/wt-scout-fukugyo/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 段階と資金の状況と、役割が決まっているか決まっていないかを決めて書く | 代表 |
| 「今週変わったこと」を代表が話し、募集記事とストーリーに整える | 代表（整えるのは若手か外に出せる） |
| 副業・業務委託の募集を正社員と分けて置く | 代表と若手 |
| 若手か副業の人が「何でもやった一か月」を話す | 入ってまもない若手、副業の人 |
| 代表が返信を止めない枠を決め、止まる時期の一次返信を決める | 代表と若手 |
| カジュアル面談を代表と若手の二人で組む | 代表と若手 |
| スカウトを代表の名義で、段階と役割と今週変わったことを最初に送る | 代表（絞る作業は外に出せる） |

運用代行や代理店が支えられるのは、段階ごとの書き分けの型、募集記事の型、「今週変わったこと」の聞き方の型、返信の枠の設計、副業の募集の型、スカウトの絞る作業までで、段階と資金の状況の開示、役割の決定、今週変わったことを話すこと、若手が話すこと、面談は会社が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。スタートアップの代表から、「シードのときの募集記事を、シリーズAになっても使っている」と聞くことがあります。当社は、段階が変わったら、書くことと会う相手を分け直すことをお願いしています。シードで書いた「何でもやる」「役割は決まっていない」は、シードでは素顔で、「決まっていないことに向く人」に届きますが、シリーズAで役割が決まり始めた後に同じ記事を使うと、「決まっていないことに向く人」が来て「決まっている役割」で離れ、「役割を作れる人」には「決まっていない会社」として読まれて届きません。順番は、段階が変わるたびに、決まっている役割と決まっていない役割を書き出し、募集記事とスカウトの文面と会う相手を分け直すことです。分け直すと、シードの記事で来た候補者がシリーズAの実態で離れる形が減ります。

## まとめ

- Wantedlyはスタートアップが最も多く並ぶ場で、「ビジョン」「急成長」「裁量」の同じ言葉は候補者に差にならない。候補者が確かめているのは、資金の状況と段階、役割が決まっているか、代表の人柄、「何でもやる」の実態、副業から入れるか
- 段階（シード、シリーズA、シリーズB以降）で書くことと会う相手を分ける。シードは「何でもやる」を隠さず副業の入口を主に、シリーズAは決まっている役割と決まっていない役割を分けて、シリーズB以降は職種ごとに。段階が変わったら分け直す
- 募集記事の「なにを」に段階と資金の状況と顧客を、「なぜ」に代表の「今週変わったこと」を、「こんなことやります」に役割の実態を。「こんな人」は「決まっていない中で決めて動いた・自分で作って公開した」の記述で。待遇を隠さない
- ストーリーは代表の「今週変わったこと」を頻度で、若手か副業の人の「何でもやった一か月」を本人の言葉で。カジュアル面談は代表と若手の二人で、資金と役割と実態を伝える
- 代表が返信を止めない枠を先に取り、止まる時期の一次返信を決める。スカウトは代表の名義で段階と役割と今週変わったことを最初に、副業から入る文面を分けて、「スタートアップに興味」ではなく記述で絞る

## よくある質問

### ビジョンと急成長で共感してもらいたいのですが、書いてはいけませんか

書いても、候補者は同じ日に同じ言葉の募集記事を何本も読んでいて、区別できません。共感は、ビジョンの言葉ではなく「今週、〇〇を見て△△に変えた」という動いている場面の具体に付きます。「なぜ」に代表の今週変わったことを、「なにを」に段階と資金の状況と顧客を事実で書き、「ビジョン」「急成長」「裁量」を文面から外します。

### 代表が忙しく、「話を聞きに行きたい」への返信が止まります

記事より先に、代表が返信する曜日と時間を決め、資金調達や顧客対応で止まる時期は若手か副業の人が一次返信をする形を決めます。返信が止まると、候補者は離れ、「Wantedlyは効かない」で終わります。カジュアル面談も代表と若手の二人で組み、代表が出られない回を若手が持てる形にします。

### スタートアップのWantedlyの設計は、御社に相談できますか

できます。当社は、段階ごとの書き分けの型、募集記事の型、「今週変わったこと」の聞き方の型、返信の枠の設計、副業の募集の型、スカウトの絞る作業を支えられます。段階と資金の状況の開示、役割の決定、今週変わったことを話すこと、若手が話すこと、面談は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
