外資系企業の日本法人で、新卒を採る。「外資」「グローバル」を前面に出して、英語ができる学生に絞ってOfferBoxで送れば来ると考えて始めると、承認は付いても面談で「新卒でも育ててもらえますか」「英語は毎日使いますか」「本国の判断で配属が変わりますか」と聞かれ、答えが曖昧だと離れます。本国の承認で採用の人数が途中で変わり、承認した学生に断ることになる、ということも起きます。**結論から言うと、学生は「グローバル」より「日本法人で新卒に何をさせるか」「英語はいつどれだけ要るか」「本国の意向で採用や配属が変わるか」を確かめます。最初に決めるのは、日本法人で新卒に何をさせるかを一枚にすること、英語をいつどれだけ使うかを職種ごとに正直に書くこと、英語力で検索を絞りすぎないこと、名義を日本法人の若手にすること、本国承認で人数が動く前提で小さく早く送ることです。** この記事では、外資系企業が割ける時間と人、学生が確かめること、最初に決めること、文面の書き方、運用の分担、やりがちな失敗を整理します。絞られた層の場との使い分けは[OfferBoxと外資就活ドットコムの使い分け](/media/ob-heiyou-gaishishukatsu/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 日本法人の人事が少なく、中途採用が中心 | 新卒の育成の仕組みがなく、文面に「最初の年に何をするか」が書けない |
| 採用の人数と予算が、本国の承認で決まる | 承認が下りる時期が読めず、送る時期が遅れる。途中で人数が減る |
| 「外資」「グローバル」を強みだと考えている | 学生には「英語ができないと無理」「新卒は放置される」と読まれる |
| 英語力で検索を絞る | 対象が少なくなり、英語より仕事に向く学生を落とす |
| 面接官が中途採用の感覚で新卒を見る | 「即戦力か」で見て、新卒の伸びしろを見ない |
| 本国の資料をそのまま文面に使う | 日本の学生に、日本法人の実態が伝わらない |

外資系企業がOfferBoxに割ける時間は、日本法人の人事の時間と、本国承認の時期で決まります。人事の時間は中途採用に取られやすく、本国承認は年度の途中で動きます。この二つを前提に、送る時期を早めに置き、送る数を小さくします。

## 学生が、承認の前に確かめること

- **日本法人で、新卒に何をさせるか**：最初の年に何を任せるか、誰が教えるか、育成の仕組みがあるか。「中途ばかりで新卒は放置」の不安
- **英語は、いつ、どれだけ使うか**：入社時から毎日か、数年後からか、職種で違うか。「英語ができないと無理」の不安
- **本国の意向で、採用や配属が変わるか**：内定のあとに人数が減るか、配属が本国の判断で変わるか、日本法人の裁量はどこまでか
- **雇用と評価の仕組み**：評価の基準、昇進の道、日本法人での長さ。「すぐ切られる」の不安
- **日本法人の規模と、誰と働くか**：本国の規模ではなく、日本法人の規模と、同じ部署の人

学生が確かめているのは、外資であることの魅力ではなく、外資であることの不安です。不安に先に答える文面が、承認のあとに離れない文面です。

### エージェントベストの見解

相談で最も多い思い込みは、「外資なので、英語ができる学生に絞って送るべきだ」というものです。当社は3媒体すべての販売パートナーとしてOfferBoxの運用代行も受けていますが、英語力で絞った検索は、対象が少なくなるだけでなく、英語はできても仕事の中身に向かない学生を選び、英語は途中からでよい職種に、英語で選んだ学生を送ることになります。英語が入社時から毎日要る職種は、実際には限られていて、多くの職種では「数年後から、会議や資料で」です。当社が外資系企業の検索条件を組むときは、職種ごとに「英語をいつからどれだけ使うか」を先に聞き、入社時から要る職種だけ英語で絞り、それ以外は仕事の中身で絞って、文面に「英語は〇〇の時点から、△△の場面で使います」と書きます。英語で絞らない文面のほうが、承認した学生が「英語で選ばれた」と感じずに、仕事で選ばれたと読みます。

## 最初に決めること

1. **日本法人で新卒に何をさせるかを、一枚にする**：最初の年に任せる仕事、誰が教えるか、育成の仕組みの実態。中途採用の型のまま新卒を採らない。書けないなら、育成の形を先に決める
2. **英語をいつ、どれだけ使うかを、職種ごとに正直に書く**：「入社時から毎日」「数年後から会議と資料で」「ほぼ使わない」のどれか。「グローバル」の一語で済ませない
3. **英語力で検索を絞りすぎない**：入社時から要る職種だけ英語で絞り、それ以外は記述の行動で。[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
4. **名義を、日本法人の若手にする**：新卒で入って数年の社員がいれば、その社員。「新卒で入って、こう育った」が学生の不安に答える。頼むことは名義・確認・面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
5. **本国承認で人数が動く前提で、小さく早く送る**：承認が下りる前に大きく送らない。下りた分だけ送り、追加の承認が下りたら足す。承認した学生に断る事態を避ける。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
6. **本国の意向で配属や採用が変わる可能性を、隠さず一文で**：「配属は日本法人で決めます」「採用の人数は年度の途中で変わることがあります」。書けない場合は面談で
7. **面接官に、新卒の見方を伝える**：「即戦力か」ではなく、伸びしろと行動で。[OfferBox経由の学生を面接する現場社員への説明](/media/ob-genba-mensetsukan/)

## 文面の書き方｜「グローバル」ではなく「日本法人で、新卒に、何を」

| 書かない | 書く |
|---|---|
| 「グローバルに活躍」「世界を舞台に」 | 日本法人で、最初の年に、何を、誰と。育成の実態 |
| 「英語力を活かせる」「語学力歓迎」 | 「英語は〇〇の時点から、△△の場面で使います」 |
| 本国の規模と実績 | 日本法人の規模と、同じ部署の人数と、誰と働くか |
| 「実力主義」「成果次第で昇進」 | 評価の基準と、新卒で入った社員が何年目に何を任されたか。数値でなく役割で |
| 本国の資料の日本語訳 | 日本法人の社員の言葉で。名義の若手が「新卒で入って、こう育った」 |

- **名義の若手が「新卒で入って、最初の年に何をしたか」を一場面書く**：外資の新卒の不安（放置される、英語で詰む）に、本人の経験で答える
- **英語の必要度を、職種ごとに一文で**：曖昧にすると、英語ができる学生も、できない学生も、承認しない
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)。育成と評価の実態は採用サイトに。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 本国承認と、送る時期

- **本国承認の時期を、前年のうちに確認する**：日本の就職活動の時期と合わないことが多い。承認が下りる前に、検索条件と文面と名義を用意しておく
- **承認が下りた分だけ、小さく送る**：人数が減っても、承認した学生に断らずに済む数で
- **追加の承認が下りたら、足して送る**：送る時期を二つに分ける前提
- **人数が減った場合の扱いを、先に決める**：承認した学生に断る事態が起きたときの伝え方。起きないように送る数を絞るのが先
- **絞られた層の場に出るかは、自社がその層の候補に入っているかで**：[OfferBoxと外資就活ドットコムの使い分け](/media/ob-heiyou-gaishishukatsu/)

### エージェントベストの見解

送り始めたあと、最初の年で起きることに共通するのは、本国の承認で採用の人数が途中で減り、承認した学生に断ることになることです。当社はOfferBoxの運用代行で外資系企業の送る時期を企業と一緒に決めますが、日本の就職活動の時期に合わせて先に大きく送り、そのあとに本国から「今年は人数を減らす」と来て、承認して面談まで進んだ学生に断った会社があります。断られた学生は、会社名と一緒にその経験を周りに話し、翌年の承認に響きます。当社が外資系企業に勧めているのは、承認が下りた分だけを小さく送り、追加が下りたら足す形で、送る時期を二つに分けることです。最初の送る数が小さいと、承認率が低く見えても、断る事態は起きません。人数が減る可能性は、日本法人の努力では消せないので、消せない前提で送る数を組みます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「グローバル」「英語力歓迎」で送る | 「英語ができないと無理」「放置される」と読まれる | 日本法人で新卒に何をさせるかと、英語の必要度を具体で |
| 英語力で検索を絞る | 対象が減り、仕事に向く学生を落とす | 入社時から要る職種だけ英語で絞る |
| 本国承認の前に大きく送る | 人数が減り、承認した学生に断る | 下りた分だけ小さく早く、二回に分ける |
| 中途採用の感覚で新卒を面接する | 「即戦力か」で見て離す | 面接官に新卒の見方を伝える |
| 本国の資料をそのまま文面に | 日本法人の実態が伝わらない | 日本法人の若手の言葉で |

最も多いのは、一つ目です。外資であることを魅力として書き、学生が確かめている不安に答えていません。

## まとめ

- 学生は「グローバル」より、「日本法人で新卒に何をさせるか」「英語はいつどれだけ要るか」「本国の意向で採用や配属が変わるか」を確かめる。外資の不安に先に答える
- 最初に、日本法人で新卒に何をさせるかを一枚にし、英語の必要度を職種ごとに一文で正直に書く。中途採用の型で新卒を採らない
- 英語力で検索を絞りすぎない。入社時から要る職種だけ英語で絞り、それ以外は記述の行動で。名義は日本法人の若手
- 本国承認で人数が動く前提で、下りた分だけ小さく早く送り、追加が下りたら足す。承認した学生に断る事態を避ける
- 面接官に新卒の見方を伝え、本国の資料を文面に使わず、日本法人の社員の言葉で書く

## よくある質問

### 英語が入社時から要る職種です。英語力で絞ってよいですか

その職種だけは、英語で絞って構いません。文面に「入社時から、〇〇の場面で英語を使います」と書き、英語だけでなく、仕事の中身で選んだ理由も一文入れます。英語で絞る職種と、絞らない職種を混ぜないことが大切です。全職種を英語で絞ると、対象が減り、仕事に向く学生を落とします。

### 本国承認がいつ下りるか分かりません。送るのを待つべきですか

承認が下りるまでに、検索条件、文面、名義、承認後の連絡の型を用意しておき、下りた日に送れる状態にします。下りる前に送るなら、断らずに済む小さな数だけにします。「今年の人数は年度の途中で変わることがあります」と文面か面談で伝えておくと、変わったときの不信が減ります。

### 外資系企業のOfferBox運用は、御社に相談できますか

できます。当社は、一枚の型、英語の必要度の書き方の型、文面の型、検索・下書き・送信・一次返信、送る時期を二つに分ける型を支えられます。一枚の中身、英語の必要度の決定、本国承認の確認、面談、人数が減った場合の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
