新聞、出版、テレビ、ラジオ、Webメディア、またはその制作を担う会社が、新卒を採る。大手は独自の選考日程と試験（作文、時事、面接）で、学生も「マスコミ就職」の対策をして来る。地方局、地方紙、専門出版、制作会社は、学生に知られておらず、大手の選考が終わったあとに「残った学生」に会う形になりがち。学生の「発信したい」「伝えたい」の憧れと、記者・編集・営業・制作の実態、不規則な勤務、デジタルへの変化の中で自社がどこにいるかが、伝わっていません。**結論から言うと、マスコミ業界は、大手と中小で媒体の位置づけが違います。大手は独自の選考日程と試験が中心で、媒体は選考情報を出す補助として。地方局・地方紙・専門出版・制作会社は知られていないので、送る型か記事を置く型を先に検討し、大手の「残り」ではなく「この媒体で、この仕事を」で先に会いに行きます。どちらも、憧れと実態、デジタルへの変化の中で自社がどこにいるかを隠さないことが先です。** この記事では、マスコミ業界の採用構造、判断軸の当て方、学生が確かめること、大手と中小でどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## マスコミ業界の採用構造と、媒体との相性

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 大手は独自の選考日程と試験が中心 | 学生は「マスコミ就職」の対策をし、大手の日程で動く | 媒体は選考情報と会社の見せ方の補助。主軸は独自の選考 |
| 地方局・地方紙・専門出版・制作会社は知られていない | 大手の選考が終わったあとに「残った学生」に会う形になる | 送る型か記事を置く型で、大手の日程より前に会いに行く |
| 記者・編集・営業・制作・技術の職種 | 「発信したい」の憧れが、営業や制作の実態と合わない | 職種ごとに「こんな人」と実態を分ける |
| 不規則な勤務、締切、深夜 | 学生が「実態は」を確かめる | 隠さず書く |
| デジタルへの変化の中にある | 「紙・放送」の現場と「Web・動画」の新しい部署が同じ会社に | 自社が変化のどこにいるか、配属がどちらかを書く |
| 作文・時事・面接の対策をしている学生と、していない学生 | 中小が大手と同じ試験をすると、対策した学生しか残らない | 中小は「作った・書いた経験」で見る |

マスコミの採用は、大手なら「独自の選考の中で会社の見せ方を整えること」、中小なら「大手の残りではなく、先に会いに行くこと」で決まります。

## 判断軸を、マスコミ業界に当てる

| 軸 | マスコミ業界での見方 |
|---|---|
| 対象（誰に届くか） | 「発信したい」の記述は多い。絞るのは「書いた・作った・取材した・発信を続けた」の記述。職種ごとに |
| 型（送るか、来るか、比べられるか） | 大手は「比べられる」型で選考情報を出す。中小は「送る」型で大手の日程の前に会いに行くか、「来る」型で仕事の実態を読んでもらう |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 現場（記者、編集、制作）の時間が不規則で取りにくい。名義と面談の枠を先に固定する |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。マスコミでは、「型」の軸で大手と中小の位置づけが最も分かれ、「対象」の軸で「発信したい」を絞る条件にしないことが、他の業界と違います。

### エージェントベストの見解

同じマスコミでも、独自の選考日程と試験を持つ大手には、ワンキャリアのように学生が並べて比べる場で選考情報を透明に出し、送る型は特定の職種（技術、デジタル）に絞る使い方を勧めることが多く、地方局・地方紙・専門出版・制作会社には、OfferBoxで「書いた・作った・取材した経験」で絞って大手の日程より前に送るか、Wantedlyで仕事の実態を記事で読んでもらう型を先に勧めることが多いです。理由は、中小が大手と同じ日程で待つと、大手の選考が終わったあとの「残った学生」にしか会えず、「この媒体で、この仕事を」で選ぶ学生に先に会うには、企業から送るか、記事で読んでもらうしかないからです。当社は3媒体すべての販売パートナーとして、大手か中小かで位置づけを分け、中小には「残りを待たない」形を提案しています。

## 学生が、確かめること

- **職種の実態**：記者、編集、営業、制作、技術で、日々何をしているか。「発信したい」が営業や制作の実態と合うか
- **不規則な勤務**：締切、深夜、休日の取材や放送。隠すと離れる
- **デジタルへの変化の中で、自社がどこにいるか**：紙・放送の現場と、Web・動画の新しい部署。配属はどちらか。「デジタル化」の一語ではなく実態
- **最初の年に何をするか**：取材に出られるのか、補助から始まるのか
- **地方局・地方紙なら、地域と暮らし**：[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)
- **辞めた人がいるか、なぜか**：「発信したい」で入って辞めた人の理由

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 大手で、独自の選考日程と試験があり、学生の候補に入っている | 学生が並べて比べる場（ワンキャリア）で選考情報を | 主軸は独自の選考。媒体は選考情報と見せ方の補助。クチコミの実態と記事をずらさない |
| 大手で、技術やデジタルの職種を、独自の選考とは別に採りたい | 企業から送る型（OfferBox） | 「マスコミ就職」の対策をしていない学生に、職種で絞って届く |
| 地方局・地方紙・専門出版・制作会社で、「書いた・作った経験」で絞りたい | 企業から送る型（OfferBox） | 大手の日程より前に会いに行ける。作業を外に出せる |
| 中小で、記者や編集や制作の人が仕事の実態を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「発信したい」学生に、実態を先に読んでもらえる。記事が残る |
| 変化のどこにいるかの一行が、まだない | どれも先ではない | 一行を作ってから |

どれか一つが正解ではなく、大手か中小か、職種、書けるかで、先に検討するものが変わります。

## 組み合わせ

- **大手は、比べられる場と送る型を組み合わせる**：比べられる場で独自の選考の情報を、送る型で技術・デジタルの職種を。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **中小は、送る型と記事を置く型を組み合わせる**：文面で「あなたの〇〇の記事・作品を読んで」を、記事で「この媒体の一日」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **中小は、大手の日程より前に送る**：残りを待たない。[OfferBoxを早期に使うときの進め方](/media/ob-souki/)
- **試験（作文、時事）をするなら、中小は「書いた・作った経験」を見る段に置き換える**：対策した学生だけが残る形にしない
- **一年目は一つか二つ**：[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)

## 見せ方｜憧れと実態、変化の中で自社がどこにいるか

- **「発信したい人へ」「伝える仕事」の一語で済ませない**：応募は増えるが、営業や制作の実態で離れる
- **職種ごとの一日を、場面で**：「記者の一日は取材より確認と書き直しが長い」「制作は準備と調整が大半」
- **不規則な勤務を、隠さず、変えたことも**：「締切の前は〇〇で、△△を変えました」。数値は実態で。この記事では書かない
- **デジタルへの変化の中で、自社がどこにいるかを一行で**：「紙・放送が中心で、Web・動画を□□の形で始めている。新卒の配属は◇◇の決まり方」。[エネルギー業界の採用媒体の選び方](/media/hikaku-energy-erabikata/)の「変化のどこにいるか」と同じ考え方
- **新しい部署だけを光らせない**：紙・放送の現場を選ぶ学生に、その中身と誇りを書く
- **業界イメージ（忙しい、古い、縮小）を否定せず、実態で**：[業界イメージが不利な会社のWantedlyの書き方](/media/wt-gyokai-image/)
- **名義は、現場の若手**：「私は〇〇の担当で、最初の年は△△をしました」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 大手か中小かの位置づけと、先に検討する型の決定 | 人事と責任者 |
| 変化のどこにいるかの一行と、配属の決まり方 | 経営と人事 |
| 職種ごとの「こんな人」（書いた・作った・取材した経験） | 人事と現場の責任者 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、現場の若手が場面を話し、整えるのは人事か外に | 若手と人事 |
| 個別の一文、文面の最終確認、名義、面談 | 現場の若手 |
| 独自の選考の日程と、媒体の位置づけの整理（大手） | 人事 |
| 面接官に「発信したい理由」を聞かないと伝える | 人事 |

- **現場の時間は不規則なので、名義と面談の枠を先に固定する**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
- **中小は、検索・下書き・送信・一次返信を外に出し、大手の日程より前に動く時間を確保する**：[運用代行に出す前提の媒体の選び方](/media/hikaku-daikou-zentei/)

運用代行や代理店が支えられるのは、位置づけの整理、一行の型、職種ごとの絞り方の型、文面と記事の型、送る型の作業、記事を整える部分までで、位置づけの決定、変化のどこにいるかの一行、配属の決定、名義の選定、面談、独自の選考の設計は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

媒体を決めたあと、最初の年で起きることに共通するのは、「デジタル化」「新しいメディア」を前面に出した文面と記事で承認や応募が付き、面談か内定のあとに配属が紙・放送の現場と分かって離れることです。当社は3媒体すべての販売パートナーとして、マスコミの会社の申込のあとを見ていますが、Web・動画の新しい部署は会社の中では小さく、新卒の配属の多くは従来の現場で、それを文面と記事に書いていない会社が多くあります。「新しいほうが学生に響く」と考えて書き、響いた学生が配属で離れます。当社が勧めているのは、紙・放送の現場を下に置かず、その中身と誇りを書き、新しい部署への配属の条件を正直に書くことです。従来の現場を選ぶ学生は、「発信したい」学生の中にも多く、その学生は配属で離れません。変化の中でどこにいるかを隠さないことが、マスコミの採用の見せ方の要です。

## まとめ

- マスコミ業界は大手と中小で媒体の位置づけが違う。大手は独自の選考日程と試験が主軸で、媒体は選考情報と見せ方の補助。中小は知られておらず、送る型か記事を置く型で大手の日程より前に会いに行く
- 「こんな人」を「発信したい」ではなく「書いた・作った・取材した・続けた経験」で、職種ごとに決める。中小は大手と同じ試験で対策した学生だけを残さない
- 学生が確かめるのは職種の実態・不規則な勤務・デジタルへの変化の中で自社がどこにいるか・配属。「デジタル化」の一語で済ませず、従来の現場を下に置かない
- 大手は並べて比べる場と送る型（技術・デジタル）を、中小は送る型と記事を置く型を組み合わせる。現場の時間は名義と面談の枠を先に固定
- 見せ方は憧れと実態を隠さず、変化のどこにいるかを一行で。名義は現場の若手

## よくある質問

### 大手の選考が終わってから、残った学生に送っています。それでよいですか

「残り」を待つと、大手の選考で疲れた学生に、大手の日程のあとで会うことになり、「この媒体で、この仕事を」で選ぶ学生には会えません。大手の日程より前に、「書いた・作った経験」で絞って送るか、記事で仕事の実態を読んでもらう形にすると、大手と並べて比べられる前に、自社を知ったうえで来る学生が残ります。順番を変えるだけで、会える学生が変わります。

### 作文や時事の試験を、中小でもするべきですか

大手と同じ試験をすると、「マスコミ就職」の対策をした学生だけが残り、その学生は大手の結果で決めます。中小は、試験の代わりに「書いた・作った・取材した経験」を面談で見る段に置き換えることを勧めます。対策ではなく、経験で見ると、大手を見ていない学生の中から、作れる学生が見つかります。

### マスコミ業界の媒体選びは、御社に相談できますか

できます。当社は、位置づけの整理、一行の型、職種ごとの絞り方の型、文面と記事の型、送る型の作業、記事を整える部分を支えられます。位置づけの決定、変化のどこにいるかの一行、配属の決定、名義の選定、面談、独自の選考の設計は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
