業務ソフトを月額で提供する会社（大手・上場、成長期、創業期、業界に特化したバーティカルSaaS）が、新卒採用でワンキャリアを使う。ワンキャリアの学生層は上位大学志向で、SaaSを「事業を作る」「経営に近い」「プロダクトに関わる」の期待で読み、承認と応募は付く。ただし新卒の最初の役割は分業（インサイドセールス、フィールドセールス、カスタマーサクセス）のどこかで決まり、多くはインサイドセールスの架電とアポの数字から始まり、期待で来た学生は離れて、体験談に「架電だった」「事業を作るとは程遠かった」と残る。同じ学生には「急成長」「調達済み」「世界を変える」の同じ文面が他のSaaSからも届いていて、差にならない。**結論から言うと、SaaSのワンキャリアは、最初の役割から次の役割への移り方（いつ、どう、行く人の割合）を人事の制度として先に決めてから、企業ページの最初に「何の業務を、誰のために変えるソフトか」と「新卒の最初の役割と数字」と「役割の先」を書きます。「急成長」「調達済み」で埋めず、同業と同じ言葉を外します。面接で「なぜSaaSか」「事業を作りたいか」を聞かず、「数字を追って改善した・人に使い続けてもらった」経験を聞き、内定前にインサイドセールスの一日を見せます。メガベンチャー・コンサルとの併願による辞退は、内定者が「なぜ残ったか」を書く形で減らします。** この記事では、SaaS業界の採用構造とワンキャリアとの相性、役割の先を先に決める順番、企業ページの見せ方、選考と内定後の設計、イベントとスカウトの運用設計、社内の分担を整理します。媒体の選び方は[SaaS業界の採用媒体の選び方](/media/hikaku-saas-erabikata/)、企業ページの基本は[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。数値と料金は書きません。

## SaaS業界の採用構造と、ワンキャリアとの相性

| 区分 | 採用の形 | ワンキャリアとの相性 |
|---|---|---|
| 大手・上場のSaaS | 学生に知られ始めている。分業が固まり、役割ごとに採る。体験談が増えている | 役割ごとに募集を分け、最初の役割と数字をずらさない |
| 成長期（資金調達の後） | 採用が急に増える。知られていない。体験談が少ない | 「急成長」を外し、業務とプロダクトと最初の役割で。最初の体験談を今年作る |
| 業界特化（バーティカルSaaS） | 顧客の業界（医療、建設、飲食など）で仕事が決まる | 顧客の業界と業務を一文に。業界の経験で絞る |

| 業界の特徴 | ワンキャリアで起きること | 設計 |
|---|---|---|
| 上位大学志向の学生が「事業を作る」の期待で来る | 最初の役割の架電で離れ、体験談に「架電だった」と残る | 最初の役割と数字を先に |
| 同業が「急成長」「調達済み」の同じ文面で書く | どの会社も同じに見え、差にならない | 業務とプロダクトと役割の先で差を |
| 役割の先が決まっていない | 「架電の先が見えない」で離れる | 制度として先に決め、いつ・どう・割合で書く |
| メガベンチャー・コンサルとの併願で辞退 | 内定者の体験談に「他社に行った」と残る | 内定前に一日を見せ、「なぜ残ったか」を書く設計 |

## 役割の先を、企業ページより先に制度として決める

- **最初の役割から次の役割への移り方を、人事の制度として決める**：「インサイドセールスで〇〇の後、△△の時点で本人の希望と□□で、フィールドかCSかマーケに移る。行く人は〇〇」。決まっていないなら、決まっていないと書く
- **決まり方が書けない企業ページは、「架電の先が見えない」で読まれる**：「成長できる」「キャリアは自由」の言葉は、決まり方の書かれていない文章として読まれる
- **創業期で決まっていないなら、決まっていないことを書く**：「役割の先はまだ決まっていない。今年〇〇を決める」。隠すより先に

### エージェントベストの見解

これは順番の話です。SaaSの会社から、「企業ページで最初の役割がインサイドセールスであることを書きたいが、どう書けば学生が離れないか」と相談されることがあります。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、書き方より先に、「インサイドセールスの後、いつ、どう、どれだけの人が次の役割に移るか」を人事の制度として決めることをお願いしています。ワンキャリアの学生は、体験談の「架電だった」を読んだうえで企業ページを開き、「架電の先に何があるか」を確かめていて、「成長できる」「キャリアは自由」の言葉は、決まり方の書かれていない文章として読まれます。制度が決まると、企業ページは「〇〇の後、△△の時点で□□の形で移り、行く人は〇〇」と決まり方を写すだけで足り、学生は「架電が通過点である」ことを決まり方で読みます。

## 企業ページの見せ方｜業務とプロダクトと、最初の役割と数字と、役割の先

- **「何の業務を、誰のために変えるソフトか」を、最初の一文で**：「〇〇（顧客）の△△の業務を変えるソフトを作っている会社です」。「SaaS」「急成長」「調達済み」の一語で済ませない
- **新卒の最初の役割と数字を、隠さず**：「最初の役割はインサイドセールスで、架電とアポの数字を追います」。数値は実態で。この記事では書かない
- **役割の先を、決まり方と割合で**：「〇〇の時点で△△に移る道があり、行く人は□□」
- **「急成長」「調達済み」「世界を変える」を、企業ページから外す**：同業の共通語。同じ学生に同じ文面が届いている
- **「使い続けてもらえた日」の場面を、一つ**：「解約を考えていた〇〇の顧客に、△△を提案して、続けてもらえた日」。若手の名義で
- **自社の体験談に「架電だった」「事業を作るとは違った」があれば、先に読む**：隠さず、役割の先を添える。[業界イメージが不利な会社のワンキャリアの見せ方](/media/oc-gyokai-image/)

本選考の書き方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

## 選考と内定後の設計

- **面接で「なぜSaaSか」「事業を作りたいか」「経営に興味はあるか」を聞かない**：期待の像を確かめる質問で、像の体験談を作る。代わりに「数字を追って改善した経験」「人に使い続けてもらった経験」「違う立場の人に説明して動かした経験」を聞く
- **面接で、最初の役割と数字と役割の先を伝える**：伝えたことは体験談に「聞いた」と残る
- **面接官に、「架電だった」の体験談を読ませる**：[ワンキャリアのクチコミを面接官教育に使う方法](/media/oc-kuchikomi-mensetsukan/)
- **内定前に、インサイドセールスの一日を見せる**：架電、アポ、商談への引き継ぎ。内定後の辞退と「架電だった」の体験談を減らす
- **メガベンチャー・コンサルとの併願で辞退されるのは、前提**：内定前に役割の先に移った若手と会わせ、残った内定者が「なぜ残ったか」を書く設計に。[ワンキャリア経由の内定辞退が続くときの見直し](/media/oc-naitei-jitai/)

## イベントとスカウトの設計

- **イベントは、若手のインサイドセールスとCSが「使い続けてもらえた日」を話す**：「〇〇の顧客に△△を提案して、続けてもらえた日」。「事業を作る」ではなく場面
- **役割の先に移った若手が、「いつ、どう移ったか」を本人が話す**：「架電の先」の期待に、決まり方で応える
- **枠は、商談の少ない時間に**：若手は架電と商談と顧客対応で日中が埋まる
- **スカウトは、業務とプロダクトと最初の役割と役割の先を最初に**：「〇〇の業務を変えるソフトで、最初の役割はインサイドセールス、△△の時点で□□に移る道がある。あなたの〇〇（ガクチカ）を読んで」。「急成長」「ベンチャー志向」で絞らない
- **セールスは「数字を追って改善した」、CSは「人に使い続けてもらった」のガクチカで**：[ワンキャリアの学生のガクチカを読んでスカウトを送る方法](/media/oc-scout-gakuchika/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 最初の役割から次の役割への移り方（いつ、どう、割合）を制度として決める | 経営と人事、各役割の責任者 |
| 業務とプロダクトの一文と、最初の役割と数字と役割の先の一枚 | 経営と人事 |
| 企業ページから「急成長」「調達済み」を外し、一文と役割と決まり方を先に書く | 人事。各役割の若手が確認 |
| 自社の体験談を読み、「架電だった」「事業を作るとは違った」を分ける | 人事と面接官 |
| 面接で「なぜSaaSか」を聞かず、役割と数字と決まり方を伝える | 面接官 |
| 内定前にインサイドセールスの一日を見せ、役割の先に移った若手と会わせる | 人事と各役割の責任者 |
| イベントで若手のセールスとCSと役割の先に移った若手が話す。枠は商談の少ない時間に | 入社してまもない若手 |
| スカウトを一文と役割と決まり方を最初に、役割ごとにガクチカで絞る | 送る人 |

運用代行や代理店が支えられるのは、企業ページの型、体験談の読み方の型、選考の設計の型、内定後の設計の型、イベントの型、スカウトの型と絞る作業までで、役割の先の制度の決定、業務とプロダクトの一文の中身、最初の役割と数字の開示、面接で伝えること、内定前に見せる一日、若手が話すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは契約後に起きることの話です。SaaSの会社が、「事業を作る」「プロダクトで世界を変える」「急成長」で企業ページを作って内定を出し、内定後にメガベンチャーやコンサルとの併願で辞退され、入社した学生が最初の役割のインサイドセールスの架電とアポの数字で離れ、体験談に「架電だった」「事業を作るとは程遠かった」と残る、という形を、当社は繰り返し見ています。当社がお願いするのは、企業ページと面接で最初の役割と数字と役割の先を先に伝え、内定前にインサイドセールスの一日を見せて、「最初の役割を知ったうえで残った内定者」を作ることです。その内定者の体験談に「架電を通過点として聞いていた」「役割の先を決まり方で聞いた」と残ると、翌年の学生は「事業を作る」ではなく「最初の役割を先に見せる会社」を読んで来ます。

## まとめ

- SaaS業界は、ワンキャリアの上位大学志向の学生が「事業を作る」「経営に近い」の期待で来て、最初の役割のインサイドセールスの架電と数字で離れ、体験談に「架電だった」と残る。同じ学生に「急成長」「調達済み」の同じ文面が他のSaaSからも届いていて、差にならない
- 最初の役割から次の役割への移り方（いつ、どう、行く人の割合）を、企業ページより先に人事の制度として決める。決まり方が書けない企業ページは「架電の先が見えない」で読まれる。創業期で決まっていないなら、決まっていないと書く
- 企業ページの最初に「何の業務を、誰のために変えるソフトか」と「最初の役割と数字」と「役割の先」を書く。「急成長」「調達済み」「世界を変える」を外し、「使い続けてもらえた日」の場面で
- 面接で「なぜSaaSか」「事業を作りたいか」を聞かず、「数字を追って改善した・人に使い続けてもらった」経験を聞き、役割と決まり方を伝える。内定前にインサイドセールスの一日を見せ、役割の先に移った若手と会わせる
- イベントは若手のセールスとCSが場面を、役割の先に移った若手が「いつ、どう移ったか」を本人の言葉で。スカウトは一文と役割と決まり方を最初に、役割ごとにガクチカで絞る

## よくある質問

### 最初の役割がインサイドセールスであることを、どう書けば学生が離れませんか

書き方より先に、インサイドセールスの後にいつ、どう、どれだけの人が次の役割に移るかを制度として決めます。学生は体験談の「架電だった」を読んだうえで「架電の先」を確かめていて、「成長できる」「キャリアは自由」は決まり方の書かれていない文章として読まれます。制度が決まると、企業ページは「〇〇の後、△△の時点で□□の形で移り、行く人は〇〇」と決まり方を写すだけで足ります。

### 「急成長」「資金調達済み」を書いてはいけませんか

書いても差になりません。同じ学生に、他のSaaSから同じ言葉の文面が届いています。「〇〇の業務を、△△のために変えるソフト」と業務とプロダクトを一文にし、「最初の役割は□□で、数字は〇〇、△△の時点で移る道がある」と役割と決まり方を書くほうが、他のSaaSと比べていない学生に届き、翌年の体験談に「書いてあったとおり」と残ります。会社の状態は、隠さず、一枚の中で事実として書きます。

### SaaS業界のワンキャリアの設計は、御社に相談できますか

できます。当社は、企業ページの型、体験談の読み方の型、選考の設計の型、内定後の設計の型、イベントの型、スカウトの型と絞る作業を支えられます。役割の先の制度の決定、業務とプロダクトの一文の中身、最初の役割と数字の開示、面接で伝えること、内定前に見せる一日、若手が話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
