ワンキャリアで動画を使いたい。企業ページやイベントに動画を置けば、文字より伝わるのではないか。ところが、会社紹介の映像を作り、長く、盛り、社員が台本を読み、体験談と揃っておらず、一度作って更新せず、掲載の場所と形式を確認せずに作ってしまう。**結論から言うと、動画は「読む場所」を補うもので、体験談と企業ページを読んだ学生が「文字では分からないこと」（話し方・職場・仕事の手つき）を確かめる材料です。撮るのは、社員が一つの場面を話す短い動画と職場で、会社紹介の映像は撮りません。体験談と揃え、盛らず、更新できる形で。掲載できる場所と形式は管理画面とヘルプで、撮る範囲は自社のルールと媒体の規約で確認します。** この記事では、動画で起きる失敗、役割、確かめられること、撮るものと撮らないもの、作り方、職場の動画、長さ、揃えること、負担、更新、掲載の確認、イベントとの組み合わせ、分担を整理します。企業ページは[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)、写真は[ワンキャリアの掲載の写真](/media/oc-keisai-shashin/)、イベントは[ワンキャリアのイベントの種類と使い分け](/media/oc-event-kihon/)で書きました。

## この作業の目的｜動画を、「文字では確かめられないこと」の材料にする

ワンキャリアの学生は、体験談を読み、企業ページを読んでから、確かめに来ます。文字で読める（事業・選考の流れ・条件）は文字で足りていて、文字で分からないのは、「この人はどういう話し方をするか」「職場はどういう場所か」「仕事の手つき」です。動画の役割は、そこです。

目的は、動画を「会社を良く見せる映像」ではなく、「文字で分からないことを確かめる材料」として作ることです。

## 動画で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 会社紹介の映像を、作る | 事業と理念を映像で語り、文字で読めることを繰り返す。長く、見られない |
| 長い | 途中で閉じられる。短い動画のほうが最後まで見られる |
| 盛る | 音楽と編集で良く見せ、面談で会った人と違う。体験談に「動画と違った」と残る |
| 社員が、台本を読む | 話し方が確かめられない。台本の文字を読む顔になる |
| 体験談と、揃っていない | 体験談で「〇〇だった」と書かれたことと、動画の中身が違う |
| 一度作って、更新しない | 映っている社員がいない、職場が変わった、で古くなる |
| 掲載の場所と形式を、確認せずに作る | 置けない場所に置こうとする、形式が合わない |
| 撮る範囲のルールを、確認しない | 撮ってはいけない場所・人・情報が映る |

共通するのは、動画を「映像作品」として作り、「確かめる材料」として作っていないことです。

## 動画で、確かめられること

| 確かめられる | 文字で足りる |
|---|---|
| 社員の話し方、表情、間 | 事業の内容 |
| 職場の様子、音、広さ | 選考の流れ |
| 仕事の手つき（作業している様子） | 条件 |
| 社員どうしのやり取り | 制度 |
| 「この人と話してみたい」と思えるか | 沿革 |

「確かめられる」の側だけを撮ります。「文字で足りる」の側は、企業ページに書き、動画にしません。

### エージェントベストの見解

相談で最も多い思い込みは、「動画は作り込むほど、会社が良く見える」というものです。当社はワンキャリアの販売パートナーとして、動画の相談を受けていますが、作り込んだ会社紹介の映像は、体験談に「動画は立派だったが、面談で会った人は普通だった」と残り、動画と実際の落差が不信になっています。逆に、社員が一つの場面を自分の言葉で話すだけの短い動画と、職場をそのまま撮った動画を置いた会社は、「動画で見た人と面談で会えた」「職場が動画のとおりだった」と残っています。ワンキャリアでは、今年の動画と面談の落差が、翌年の体験談になります。動画の価値は、作り込みではなく、「面談で会う人と、動画の人が同じ」ことです。当社が動画の相談を受けるとき、最初にやるのは、企画から「会社紹介」を外し、「誰が、どの場面を話すか」に置き換えることです。

## 撮るものと、撮らないもの

| 撮る | 撮らない |
|---|---|
| 社員が、一つの場面を自分の言葉で話す（短く） | 会社紹介、理念、沿革の映像 |
| 職場を、そのまま | 演出した職場、飾った会議室 |
| 仕事の手つき（作業の様子） | 制度や条件の説明（文字で） |
| 社員どうしの、普段のやり取り | 台本のある対話 |
| 入社してまもない社員の、「入る前と後」 | 音楽と編集で盛った映像 |

撮る範囲は、自社のルール（映ってよい人・場所・情報）と媒体の規約で確認します。撮ってよいかを、撮る前に決めます。

## 社員が一つの場面を話す動画の、作り方

- **テーマは一つ**：「最初の一年で覚えている場面」「入る前と後で違ったこと」「一日の流れ」
- **台本を書かない**：質問を一つ用意し、本人が答える形で撮る
- **一度で撮る**：撮り直しを重ねると、話し方が硬くなる
- **編集は最小限**：切るだけ。音楽を入れない、字幕は事実の補足だけ
- **話す人は、面談に出る人か、その職種の人**：動画で見た人に、面談で会える
- **座談会で話したことを、動画にする形もある**：[ワンキャリアの座談会の企画の立て方](/media/oc-zadankai/)のテーマと同じ

## 職場の、動画

- **そのまま撮る**：片付けない、飾らない。普段の様子
- **社員が案内しながら、一言**：「ここで〇〇をしています」
- **見せられない場所は、映さない**：映せないことは、企業ページに「〇〇は見せられない」と書く
- **音を残す**：職場の音は、文字で伝わらないもの
- **オフラインの回で見せる職場と、同じ**：動画で見た職場に、来られる。[ワンキャリアのオフラインイベントの進め方](/media/oc-offline-event/)

## 長さ

- **短く**：一つの場面が話せる長さ。長いと途中で閉じられる
- **一本に、一つのテーマ**：複数のテーマは、複数の短い動画に
- **最初の数秒で、誰が何を話すかが分かる**：会社のロゴから始めない
- **長さの具体は、掲載の形式で決まる部分がある**：管理画面とヘルプで確認

## 体験談と、揃える

- **体験談で「〇〇だった」と書かれたことと、動画の中身を揃える**：体験談で「面接は和やかだった」なら、動画の面接官も同じ話し方
- **動画で見せたことを、面談と選考でそのとおりに**：動画の人が面談に出る、動画の職場に来られる
- **盛った動画は、面談で崩れ、翌年の体験談に残る**：[ワンキャリアの掲載でやりがちな失敗](/media/oc-keisai-ng/)の「最も重い失敗」
- **企業ページの文字と、動画を揃える**：文字で「〇〇」、動画で「〇〇」が違わない

## 社員の負担

- **撮るのは、短い時間で一度**：準備は質問を一つ読むだけ
- **台本を覚えさせない**
- **出たくない社員に、出させない**：出たい人が出る
- **映ることの合意を、書面で**：自社のルールで。退職後の扱いも
- **頼み方は[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)と[Wantedlyの記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/)**

## 更新

- **映っている社員がいなくなったら、差し替える**：古い動画は、面談で会えない人が映る
- **職場が変わったら、撮り直す**
- **年度の切れ目に、動画を見直す**：企業ページの更新と同じ時期に。[ワンキャリアの企業ページの更新](/media/oc-kigyo-page-koushin/)
- **更新できる形で作る**：作り込むと、更新に費用と時間がかかり、古いまま残る
- **短い動画を複数にすると、一本ずつ差し替えられる**

## 掲載の、確認

- **動画を置ける場所（企業ページ、イベントページ、その他）と、形式・長さ・容量**：現在の仕様は管理画面とヘルプで確認
- **置ける場所に合わせて、動画を分ける**：企業ページには社員の場面、イベントページには回の様子、など
- **置けない場所に置こうとしない**：仕様に合わせる
- **媒体の規約で、動画の内容に制限があるかを確認**：自社のルールと合わせて

## イベントとの、組み合わせ

- **イベントページに、出る社員の短い動画**：「誰が出るか」が動画で分かる
- **オンラインの回の前に、職場の動画**：オンラインで確かめられない職場を、動画で。[ワンキャリアのオンラインイベントの進め方](/media/oc-online-event/)
- **回の様子を短く撮って、次の回のイベントページに**：「こういう回です」が分かる。映る学生の合意は自社のルールで
- **回で話した社員の動画を、企業ページに**：回に来られなかった学生も見られる

## 社内の分担

| 作業 | 誰が |
|---|---|
| 撮るもの（社員の場面・職場）を決め、会社紹介を外す | 人事 |
| 撮る範囲を、自社のルールと媒体の規約で確認する | 人事と管理部門 |
| 掲載の場所と形式を、管理画面とヘルプで確認する | 人事 |
| 一つの場面を、自分の言葉で話す | 社員（出たい人） |
| 撮る、最小限の編集 | 人事（または外に出す） |
| 体験談・企業ページ・面談と揃っているかを確かめる | 人事と面接官 |
| 年度の切れ目に見直し、差し替える | 人事 |

運用代行や代理店が支えられるのは、撮るものの整理、作り方の型、体験談と揃えるための確認、掲載の場所と形式の確認の手伝い、更新の型までで、撮る範囲のルールの決定、社員が話すこと、撮ること、揃っているかの判断は企業が行います。撮影と編集を外に出す場合は、自社のルールと見積もりで確認してください。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。当社はワンキャリアの販売パートナーで、動画の企画と作り方の型は支えますが、動画に映る人と場面を決めること、社員が話すこと、撮った動画を「これでよい」と判断することは、企業にお願いしています。学生が動画で確かめるのは「その会社の人と職場」で、当社が企画を主導すると、当社が良いと思う映像になり、面談で会う人と違う動画になります。当社が支えるのは、企画から会社紹介を外すこと、社員が一つの場面を話す形の型、体験談と揃っているかの確認までで、そこから先は企業の判断です。動画は、作り込むほど当社の色が出て、企業の色が薄れます。当社は、動画の相談で、「誰が、どの場面を、自分の言葉で」を企業に決めてもらうところから始めます。

## まとめ

- 動画は「読む場所」を補う、「文字では分からないこと」（話し方・職場・仕事の手つき）を確かめる材料。会社紹介の映像は作らない
- 撮るのは、社員が一つの場面を自分の言葉で話す短い動画と、職場をそのまま。台本を書かず、一度で撮り、編集は切るだけ、音楽を入れない
- 短く、一本に一つのテーマ、最初の数秒で誰が何を話すかが分かる形。長さと形式は掲載の仕様で決まる部分があり、管理画面とヘルプで確認
- 体験談・企業ページ・面談と揃え、盛らない。動画の人が面談に出て、動画の職場に来られる。盛った動画は面談で崩れ、翌年の体験談に残る
- 社員の負担は短い時間で一度、出たい人だけ、映ることの合意は書面で。年度の切れ目に見直し、映っている社員がいなくなったら差し替える。撮る範囲は自社のルールと媒体の規約で確認

## よくある質問

### 動画を作る予算がなく、スマートフォンで撮るしかありません

それで足ります。動画の価値は、作り込みではなく「面談で会う人と同じ人が、自分の言葉で話している」ことで、スマートフォンで一度撮った動画のほうが、作り込んだ映像より落差がありません。明るい場所で、音が拾える距離で、一つの場面を話してもらい、切るだけの編集で置きます。形式と容量が掲載の仕様に合うかは、管理画面とヘルプで確認してください。

### 過去に作った会社紹介の映像があります。使ってよいですか

企業ページの「文字で足りる」部分の補助としてなら置けますが、それを「動画」の主にしないほうがよい。学生が確かめたいのは話し方と職場で、会社紹介の映像はそれに答えません。使うなら、映像の中の「社員が話している部分」と「職場が映っている部分」だけを短く切り出し、体験談と揃っているかを確かめてから。揃っていない部分（いない社員、変わった職場）は使いません。

### ワンキャリアでの動画の使い方は、御社に相談できますか

できます。当社は、撮るものの整理、作り方の型、体験談と揃えるための確認、掲載の場所と形式の確認の手伝い、更新の型を支えられます。撮る範囲のルールの決定、社員が話すこと、撮ること、揃っているかの判断は、企業が行ってください。掲載の仕様は管理画面とヘルプで、撮る範囲は自社のルールと媒体の規約で確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
