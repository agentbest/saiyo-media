自社を「ベンチャー」と呼んでいる。成長志向で、若手が多く、変化が速い。社員は数十名から数百名。新卒採用は毎年行っていて、媒体を選ぶときに「ベンチャー志望の学生が集まる媒体はどれか」で考えている。ところが、学生が「ベンチャー」で思い浮かべるのは、知名度のある成長企業で、自社がその中に入っているかどうかは、会社の側の自己認識と合っていないことがあります。**結論から言うと、「ベンチャー」の一語は、学生と会社で思い浮かべるものがずれます。媒体の選び方は、自社が「知名度のある成長企業」か「知られていない成長企業」かで分かれ、前者は学生が並べて比べる場を先に、後者は企業から送る型か記事を置く型を先に検討します。どちらでも、「ベンチャーらしさ」（成長、裁量、若手）で戦わず、最初の年の具体で見せます。** この記事では、ベンチャーの言葉のずれ、採用構造、判断軸の当て方、学生が確かめること、知名度の有無でどれを先に検討するか、組み合わせ、見せ方、分担を整理します。段階が初期のスタートアップは[スタートアップ業界の採用媒体の選び方](/media/hikaku-startup-erabikata/)、3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## 「ベンチャー」の言葉のずれと、採用構造

| 会社が「ベンチャー」で指すもの | 学生が「ベンチャー」で思い浮かべるもの |
|---|---|
| 成長志向、変化が速い、若手が多い、自分たちの文化 | 知名度のある成長企業の名前。メディアで見る会社 |
| 社員数十名から数百名 | 「ベンチャー」の中でも、名前を知っている数社 |
| 「大企業とは違う」 | 「大企業と並べて比べる対象」か「知らない会社」か |

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 社員数と知名度の幅が広い | 同じ「ベンチャー」でも、学生に知られている会社と知られていない会社がある | 知名度の有無で、先に検討する型が分かれる |
| 新卒採用の型がある会社とない会社 | 型がある会社は複数の媒体を回せる。ない会社は一つから | 型の有無で媒体の数を決める |
| 成長、裁量、若手を魅力だと考えている | 同業が同じ言葉を使い、区別されない | どの媒体でも、共通語を消して具体で |
| 変化が速く、配属と仕事が変わる | 学生が「配属の決まり方」「一年後」を確かめる | 記事や文面で、決まり方を書けるか |
| 若手が多く、名義にできる社員がいる | 現場の若手の名義で送れる、書ける | 送る型と記事を置く型の両方で活きる |

「ベンチャー志望の学生が集まる媒体」を探すより、「自社が学生に知られているか」を先に確かめます。知られているかどうかで、選び方が変わります。

## 判断軸を、ベンチャーに当てる

| 軸 | ベンチャーでの見方 |
|---|---|
| 対象（誰に届くか） | 「ベンチャー志望」の学生は、知名度のある数社を見ている。知られていない会社に来るのは、「この仕事」「この人」で選ぶ学生 |
| 型（送るか、来るか、比べられるか） | 知られていれば「比べられる」型が使える。知られていなければ「送る」型か「来る」型で、まず知ってもらう |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 若手が多い会社は、名義と面談を若手に分けられる。人事の型があるかで、回せる媒体の数が決まる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。ベンチャーでは、「対象」の軸で自社の知名度を正直に見ることが、他の業界より難しく、最も大切です。

### エージェントベストの見解

相談で最も多い思い込みは、「うちはベンチャーなので、ベンチャー志望の学生が集まる媒体に出れば来る」というものです。当社は3媒体すべての販売パートナーとして、自社を「ベンチャー」と呼ぶ会社の相談を多く受けますが、「ベンチャー志望」の学生が思い浮かべているのは、知名度のある成長企業の数社で、相談に来る会社の多くは、その中に入っていません。入っていない会社が、学生が並べて比べる場に出ても、比べる対象として見られず、「ベンチャー志望」の学生の目には入りません。当社が最初に確かめてもらうのは、「学生に、自社の名前を知っているかを聞いたことがあるか」で、知られていないなら、並べて比べる場より、企業から送る型か記事を置く型で、まず「この仕事」「この人」で知ってもらうことを勧めます。「ベンチャー」の自己認識と、学生の認識を分けて見ることが、ベンチャーの媒体選びの最初の一歩です。

## 学生が、確かめること

- **配属の決まり方**：変化が速い会社ほど、「配属ガチャ」を確かめる。「いつ、誰が、何を見て決めるか」
- **早く任される実態**：「若手から裁量」ではなく、入社数年の社員が、何を、いつから、誰の判断で任されたか
- **一年後に、自分は何をしているか**：組織が変わる前提で、変わるときの決め方
- **同業のベンチャーと、何が違うか**：成長、裁量、若手では区別できない
- **辞めた人の道**：ベンチャーは辞める人がいることを、学生も知っている
- **知らない会社なら、何をしている会社か**：知名度がない側の会社は、まず事業の中身

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 学生に名前を知られていて、クチコミや選考情報が付いている | 学生が並べて比べる場（ワンキャリア） | 比べる対象に入っている。クチコミの実態と記事をずらさない |
| 知られていないが、「こんな人」が絞れていて、若手の名義がある | 企業から送る型（OfferBox） | 「この仕事」「この人」で知ってもらう。作業を外に出せる |
| 知られていないが、代表や若手が自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 会社の考え方と場面を読んで選ばれる。記事が残る |
| 知られていて、応募が多い | 送る型は自社応募で来ない層に絞る | 全職種で送らない。[メガベンチャーのOfferBox運用](/media/ob-mega-venture-unyou/) |
| 新卒採用の型がまだない | 一つに絞る | 複数を持つと、どの型も残らない。[初めて新卒採用をする会社のOfferBox運用](/media/ob-hajimete-unyou/) |

どれか一つが正解ではなく、知名度の有無と、社内に何があるか（絞れる「こんな人」、書ける人、若手の名義）で、先に検討するものが変わります。

## 組み合わせ

- **知られていない会社は、送る型と記事を置く型の組み合わせから**：文面で「この仕事」を、記事で「この人」と「会社の考え方」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **知られてきたら、並べて比べる場を足す**：クチコミに書かれる実態と、記事と文面をずらさない。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **急に人が増える時期は、四半期で見直す**：[急成長フェーズの会社のOfferBox運用](/media/ob-kyuu-seichou-unyou/)
- **一年目は一つか二つ、型ができたら足す**：[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)

## 見せ方｜「ベンチャーらしさ」で戦わない

- **「急成長」「裁量」「若手が活躍」「スピード感」を書かない**：同業の共通語で、区別されない。書き方は[メガベンチャーのOfferBox運用](/media/ob-mega-venture-unyou/)の「共通語を消す」と同じ
- **配属の決まり方を、一文で**：「いつ、誰が、何を見て決めます」
- **入社数年の若手が「何を、いつから、誰の判断で任されたか」を一場面**：ベンチャーの実態は、この場面にある
- **知られていない会社は、事業の中身から**：「ベンチャーです」より「〇〇を、△△に届けている会社です」
- **辞めた人の道を、聞かれたら言える形に**：隠さない
- **業界イメージ（不安定、忙しい、若い会社）を否定しない**：事実は認め、実態を書く。[業界イメージが不利な会社のOfferBox文面](/media/ob-gyokai-image/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 自社が学生に知られているかの確認 | 人事（学生に聞く、面談で聞く） |
| 知名度の有無と社内にあるもので、先に検討する型を決める | 人事と経営 |
| 配属の決まり方の一文 | 経営と人事 |
| 「こんな人」の一行と、名義の若手の選定 | 人事と部門 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、若手と代表が話し、整えるのは人事か外に | 若手・代表と人事 |
| 個別の一文、文面の最終確認、名義、面談 | 若手 |
| 四半期の見直し | 人事と部門 |

- **人事は型と台帳と返信、若手は名義と面談**：[大企業のOfferBox運用](/media/ob-daikigyo-unyou/)の線と同じ。若手が多いベンチャーは、この線が引きやすい
- **人事の型がないなら、作業を外に出して型を残す年に**：[運用代行に出す前提の媒体の選び方](/media/hikaku-daikou-zentei/)

運用代行や代理店が支えられるのは、知名度の確かめ方の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分、台帳の型までで、知名度の判断、配属の決まり方の決定、名義の選定、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

同じ「ベンチャー」でも、学生に名前を知られていて、クチコミと選考情報が付いている会社には、ワンキャリアのように学生が並べて比べる場を先に整えることを勧め、知られていない会社には、OfferBoxで「この仕事」で送るか、Wantedlyで「この人」と「会社の考え方」を読んでもらう型を先に勧めることが多いです。理由は、並べて比べる場は、比べる対象に入っている会社にしか機能せず、知られていない会社が出ても、学生の目に入らないからです。逆に、知られている会社が送る型だけで回すと、自社応募で来る層と重なり、送る意味が薄くなります。知名度は、会社の側の自己認識ではなく、学生に聞いて確かめるもので、当社は3媒体すべての販売パートナーとして、確かめた結果で型を分けて提案しています。「ベンチャー」の一語では、媒体は決まりません。

## まとめ

- 「ベンチャー」の一語は、学生と会社で思い浮かべるものがずれる。学生は知名度のある成長企業の数社を指し、会社は自社の成長志向を指す
- 媒体の選び方は、自社が「知られている側」か「知られていない側」かで分かれる。知られているなら並べて比べる場を先に、知られていないなら送る型か記事を置く型で「この仕事」「この人」から
- 知名度は自己認識ではなく、学生に聞いて確かめる。「ベンチャー志望の学生が集まる媒体」を探さない
- 学生が確かめるのは配属の決まり方・任される実態・一年後・同業との違い。「成長」「裁量」「若手」の共通語で戦わず、最初の年の具体と決まり方で
- 人事は型と台帳と返信、若手は名義と面談。型がない年は一つに絞り、型ができたら足す

## よくある質問

### 自社が学生に知られているかどうか、どう確かめますか

面談で「うちの会社を、オファーや記事の前に知っていましたか」と聞き、台帳に残します。内定者にも聞きます。一年分が集まれば、知られている側か、知られていない側かが分かります。自社の社員や取引先の認識ではなく、学生の答えで判断します。知られていないと分かることは、負けではなく、選ぶ型が決まることです。

### 「ベンチャーらしさ」を消すと、何も残らない気がします

残るのは、事業の中身、配属の決まり方、入社数年の若手が任された場面、辞めた人の道、です。これらは会社ごとに違うので、同業と並べても区別がつきます。「ベンチャーらしさ」は同業の全部にあるもので、消しても会社の個性は減りません。消したあとに書けることが、自社の文面と記事の中身です。

### ベンチャーの媒体選びは、御社に相談できますか

できます。当社は、知名度の確かめ方の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分、台帳の型を支えられます。知名度の判断、配属の決まり方の決定、名義の選定、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
