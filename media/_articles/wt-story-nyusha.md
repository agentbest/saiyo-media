入社した人が「なぜこの会社を選び、入ってどうだったか」を書く入社エントリーは、候補者が最も自分を重ねやすいストーリーです。同時に、入社直後に書かせると、感謝と決意の文になり、候補者には届きません。**結論から言うと、入社エントリーは、入社して数ヶ月経って慣れた頃に、「入る前の自分」「決め手」「入って違ったこと」「最初の月に詰まったこと」「いま」の5つを、本人が書くか、書けなければ人事が聞いて書きます。「違ったこと」と「詰まったこと」があって、初めて候補者に信じられる記事になります。** この記事では、入社エントリーの役割、誰に、いつ、何を、本人が書く場合の型、聞いて書く場合、同意と負担、内定者フォローへの転用、やりがちな失敗、分担を整理します。ストーリーの位置づけは[ストーリーの基本](/media/wt-story-kihon/)、社員インタビューの手順は[社員インタビューを書く手順](/media/wt-story-interview/)で書きました。入社エントリーは、インタビューの中でも「入社した本人の視点」に絞った型です。

## この作業の目的｜候補者に「自分の少し先」を見せる

候補者は、入社エントリーを「自分の少し先にいる人の話」として読みます。同じように迷い、同じように決め、入ってみてどうだったか。ここに、会社ページや募集記事では書けない「入ったあとの実感」があります。

入社エントリーの目的は、候補者に「自分の少し先」を見せることです。見せるには、書く人が候補者に近く、書く内容が正直であることが要ります。入社直後の感謝文や、会社の宣伝は、「少し先」ではなく「会社の言葉」に読まれます。

OfferBoxで「入社した社員を次の採用に活かす」と書いた考え方の、Wantedly版です。考え方は[OfferBox経由で入社した社員を次の採用に活かす方法](/media/ob-nyuusha-go/)で書きました。

## 手順1｜誰に、いつ

| 観点 | 決め方 |
|---|---|
| 誰に | 入社して数ヶ月で、仕事に慣れ、「入る前と後の違い」を語れる人。募集している職種で、次の候補者に近い層（新卒向けなら前年の新卒、中途向けなら中途で入った人） |
| いつ書くか | 入社直後ではなく、数ヶ月経って「違ったこと」「詰まったこと」が言えるようになった頃。入社直後は感謝文になる |
| いつ公開するか | 次の候補者が動く時期の前。新卒向けなら次の卒年の学生が動く前、中途向けなら募集を出す前 |
| 何人に | 全員でなくてよい。候補者に近い層から1人か2人。毎年、その年の入社者から |
| 本人の意向 | 書きたくない人には頼まない。「話すだけ」なら、と言う人には聞いて書く |

「入社直後に書かせない」が、最も大事な判断です。入社直後は、まだ違和感が言葉になっておらず、「頑張ります」しか書けません。数ヶ月経つと、「入る前はこう思っていたが、実際はこうだった」が言えます。

## 手順2｜何を書くか｜5つ

入社エントリーに書く5つを、順に置きます。

| 順 | 書くこと | なぜ要るか |
|---|---|---|
| 1 | 入る前の自分 | 何を探していて、何に迷っていたか。候補者が「自分と同じ」と重ねる部分 |
| 2 | 決め手 | 何を見て、誰と話して、何で決めたか。オファーの文面か、面談か、会社ページか、人か |
| 3 | 入って違ったこと | 想像と実際のずれ。良い方向のずれも、そうでないずれも |
| 4 | 最初の月に詰まったこと | 何に詰まり、誰に何を聞き、どう抜けたか |
| 5 | いま | 何をしていて、何ができるようになり、次に何をしたいか |

3と4が、入社エントリーを「会社の宣伝」ではなく「本人の話」にする部分です。良いことだけだと、候補者は「会社に書かされている」と読みます。「違ったこと」「詰まったこと」があると、「本音だ」と読みます。

2の「決め手」は、会社ページ・募集記事・面談・オファーの文面のどれが効いたかを知る材料にもなります。翌年の文面と面談の見直しに使えます。

### エージェントベストの見解

相談で最も多い思い込みは、「入社エントリーは、入社直後の新鮮な気持ちで書いてもらうのがよい」というものです。実際には、入社直後の記事は「入社しました。頑張ります。先輩方が優しいです」で終わり、候補者に「自分の少し先」は見えません。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、候補者が「あの入社エントリーを読んで来た」と言う記事は、入社して数ヶ月経った人が「入る前は〇〇だと思っていたが、実際は△△だった。最初の月は□□に詰まった」と書いたものです。違ったことと詰まったことがあるから、候補者は「この人は本当のことを書いている」と信じ、その先の「いま」も信じます。入社エントリーは、入社の記念ではなく、入社の実感を書くものです。実感が言葉になるまで、待ってから頼むことを勧めます。

## 手順3｜本人が書く場合｜型を渡す

本人が「書きたい」と言う場合は、書いてもらいます。ただし、白紙で頼むと、感謝文か研修日記になります。型を渡します。

1. **5つの見出しを渡す**：「入る前の自分」「決め手」「入って違ったこと」「最初の月に詰まったこと」「いま」。この順で
2. **各見出しに、質問を添える**：「入る前、何を探していましたか」「何で決めましたか」「想像と違ったことは」「最初の月、何に詰まって、誰に聞きましたか」「いま、何をしていますか」
3. **場面で書くよう伝える**：「〇月、△△のとき」。抽象語ではなく
4. **「違ったこと」と「詰まったこと」を省かないよう伝える**：「悪く書いても構わない。本音で」
5. **長さの目安を伝える**：5つをそれぞれ数段落。長くしすぎない
6. **書く時間は業務時間内で確保する**：業務外に書かせない。本人の負担と、公平さの問題
7. **書いたら人事が読み、抽象語を場面に戻す相談をする**：人事が書き換えるのではなく、本人に「たとえば」と聞いて直してもらう

「業務時間内で」は、入社エントリーに限らず、社員に書いてもらうすべてのストーリーに共通します。業務外に書かせると、負担になり、次から断られます。

## 手順4｜書けなければ、聞いて人事が書く

本人が「書くのは無理だが、話すなら」と言う場合は、聞いて人事が書きます。多くの場合、こちらのほうが記事の質も本人の負担も良くなります。

- **5つの質問で、短時間で聞く**：録音する。手順は[社員インタビューを書く手順](/media/wt-story-interview/)と同じ
- **人事が5つの順に整えて書く**：本人の言葉をそのまま残す
- **本人に見せて、直してもらう**：「言っていないこと」が無いか、「載せたくないこと」が無いか
- **一人称で書くか、三人称で書くかは、本人と決める**：一人称なら「私は」、三人称なら「〇〇さんは」。本人が違和感の無いほうで
- **公開の同意を取る**

「本人が書く」にこだわらないことが要点です。書けない人に書かせて止まるより、聞いて書いて出るほうが、候補者に届きます。

## 手順5｜同意、写真、内定者フォローへの転用

| 項目 | 決め事 |
|---|---|
| 同意 | 全文と写真を見せて、「この内容で載せてよいか」。「違ったこと」の部分を本人が載せたくないなら、削るか和らげる |
| 写真 | 本人が仕事をしている場面。入社式や記念写真より、いまの仕事の写真。選び方は[会社ページの写真の選び方](/media/wt-kaisha-page-photo/) |
| 名前 | 出すか出さないかは本人と。出さない形（「今年入社した営業の1人」）でも成立する |
| 内定者フォローへの転用 | 内定を出した候補者に、「昨年入った〇〇さんの入社エントリーです」と送る。内定者が「入ったあと」を想像できる材料になる。考え方は[内定を出したあとのフォロー](/media/ob-naitei-follow/) |
| 会社ページとの対応 | 本人がメンバーの紹介に載っているなら、紹介から入社エントリーへ誘導する。選び方は[会社ページに載せるメンバーの選び方](/media/wt-kaisha-page-member/) |

内定者フォローへの転用は、入社エントリーの効果を2倍にします。候補者の段階でも、内定者の段階でも、「自分の少し先」が読めるからです。

## 手順6｜公開後、反応を本人に戻す

公開したら、面談で「どのストーリーを読みましたか」と聞き、入社エントリーが読まれていたら本人に伝えます。「あなたの記事を読んで来た人が、〇〇の部分が自分と重なったと言っていました」。これが、本人の次の協力と、他の社員への広がりにつながります。反応を戻す考え方は、社員インタビューの記事で書きました。

入社エントリーを書いた人が、翌年、面談に出て「自分もこの記事を書いた」と話せると、候補者に最も届きます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 入社直後に書かせる | 感謝文と決意で終わる | 数ヶ月経って慣れてから |
| 白紙で頼む | 研修日記か会社の宣伝になる | 5つの見出しと質問を渡す |
| 「違ったこと」「詰まったこと」を削る | 会社の言葉に読まれる | 残す。本人が望まない部分だけ和らげる |
| 全員に書かせる | 負担と、似た記事の量産 | 候補者に近い層から1人か2人 |
| 業務外に書かせる | 負担になり、次から断られる | 業務時間内 |
| 書けない人に書かせて止まる | 出ない | 聞いて人事が書く |
| 人事が書き換える | 本人の言葉が消える | 「たとえば」と聞いて本人に直してもらう |
| 公開して終わり | 内定者に届かない | 内定者フォローに転用する |
| 反応を本人に戻さない | 次から断られる | 面談で聞いて戻す |

最も多いのは、最初の「入社直後に書かせる」です。入社のタイミングで頼みたくなりますが、実感が言葉になるまで待ちます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 誰に、いつ頼むかを決める | 人事（募集している職種と、入社者の慣れ具合から） |
| 型（5つの見出しと質問）を渡す | 人事 |
| 書く、または話す | 本人 |
| 聞いて書く（書けない場合） | 人事 |
| 抽象語を場面に戻す相談 | 人事と本人 |
| 直す、同意する | 本人 |
| 写真 | 人事が手配、本人が同意 |
| 内定者フォローに転用する | 人事 |
| 反応を本人に戻す | 人事 |

本人の上司には、業務時間内で書く（話す）時間を確保してもらいます。運用代行や代理店が支えられるのは、5つの型と質問、聞いた話を記事に整えること、内定者フォローへの組み込みまでで、本人に頼むことと同意は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの入社エントリーを支えるとき、5つの型と質問、聞いた話を5つの順に整えること、内定者フォローへの組み込み方は当社が出せます。ただし、「入社した本人に、いつ、誰が頼むか」と「本人の同意」は、企業にしかできません。外部の当社が入社数ヶ月の社員に「入って違ったことは」と聞くのは、本人にとって負担で、本音も出にくい。同じ会社の人事が、業務時間内に、「話すだけでいい」と頼む。この形が、本人の負担を最小にし、本音を引き出します。当社の役割は、頼む前に型と質問を渡し、聞いたあとに記事に整えることです。頼むのは企業、整えるのは当社。この分担で、入社エントリーは毎年1本か2本、無理なく出ます。

## まとめ

- 入社エントリーは、候補者に「自分の少し先」を見せるもの。入社直後の感謝文ではなく、数ヶ月経った実感を書く
- 誰に：入社して数ヶ月で慣れた、候補者に近い層から1人か2人。いつ公開：次の候補者が動く前
- 何を：入る前の自分・決め手・入って違ったこと・最初の月に詰まったこと・いま、の5つ。「違ったこと」と「詰まったこと」を削らない
- 本人が書くなら型を渡して業務時間内で。書けなければ聞いて人事が書き、本人が直して同意する
- 内定者フォローに転用し、面談で聞いた反応を本人に戻す

## よくある質問

### 入社した人が「悪いことは書きにくい」と言います

「違ったこと」は悪口ではなく、想像と実際のずれです。「思ったより顧客と話す時間が長かった」「研修が想像より短くて、最初の月は現場で詰まった」のような、事実のずれで足ります。本人が載せたくない部分は削るか和らげ、それでも「違ったこと」が1つあれば、記事は本音として読まれます。

### 入社エントリーは、毎年書いてもらうべきですか

毎年、その年の入社者から1人か2人に頼むと、候補者に近い層の記事が常にある状態になります。古い入社エントリーも残してよく、日付があるので古いことは伝わります。新しいものがあると、内定者フォローにも使えます。

### 入社エントリーの作成は、御社に相談できますか

できます。当社は、5つの型と質問、聞いた話を記事に整えること、内定者フォローへの組み込み方を支えられます。本人に頼むことと、同意は、企業の人事にお願いしています。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのストーリーの整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
