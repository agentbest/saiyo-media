急成長フェーズの会社が媒体を選ぶとき、最初にぶつかるのは「『成長中』『急拡大』を前に出して送る数を増やし、承認は来るのに返信の体制が追いつかず数日空き、年の途中で採る人数と職種が変わって年初に作った文面が合わなくなり、採用数は達成したのに、教える人が足りずに一年目の離職が続き、翌年の体験談に『放置された』と書かれる」という問題です。**結論から言うと、急成長フェーズは採る人数と「こんな人」が四半期で変わるので、媒体は「四半期で見直せる形」で選びます。送る数を増やす前に返信の体制を作り、名義を複数にし、「成長中」ではなく「最近変わったこと」と「変わることがある」を書きます。送る型は四半期で条件と文面を動かせ、記事を置く型は「なぜ」を年に一度、比べられる場は体験談が成長の速さに追いつかない前提で使い、採用数の達成ではなく一年目の定着で見ます。** スタートアップの段階ごとの考え方は[スタートアップ業界の採用媒体の選び方](/media/hikaku-startup-erabikata/)で書きました。この記事は段階を問わず「急成長している」会社に絞って、変わる前提での媒体の選び方を書きます。

## 急成長フェーズの会社に、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 採る人数と職種が、四半期で変わる | 年初の文面と条件が、年の途中で合わなくなる | 四半期で見直せる形。[急成長フェーズの会社のOfferBox運用](/media/ob-kyuu-seichou-unyou/) |
| 送る数を増やしたい | 返信の体制が追いつかず、返信が空く | 送る数を増やす前に、返信の体制 |
| 組織が変わり、教える人が足りない | 採用数は達成しても、一年目の離職が続く | 育てる人の数で採る数を決める |
| 名義の社員が異動・昇進する | 文面の名義と、面談に出る人がずれる | 名義を複数に |
| 「成長中」「急拡大」を前に出したくなる | 同じ段階の会社が全部書いていて、差がつかず、「人が足りない会社」とも読まれる | 「最近変わったこと」で |
| 体験談が成長の速さに追いつかない | 去年の体験談が、今年の会社と違う | 企業ページに「変わることがある」と、最近変わったことを |

## 判断軸を、急成長フェーズの会社に当てる

| 軸 | 急成長フェーズの会社での見方 |
|---|---|
| 対象（誰に届くか） | 「変わる会社で、決まっていないことを決めて動ける学生」に絞る。「安定」を求める学生には届かない。四半期ごとに職種と「こんな人」を見直す |
| 型（送るか、来るか、比べられるか） | 送る型は、四半期で検索条件と文面を動かせ、送る数を返信の体制で調整できる。来る型は、会社の「なぜ」を年に一度書き、「最近変わったこと」を記事で足していける。比べられる型は、体験談が去年の会社のもので、今年の会社と違う前提。企業ページで「変わることがある」と最近変わったことを書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。年間で決めず、四半期で送る数と一緒に見直せる形で |
| 運用工数（誰の時間が要るか） | 返信の担当を送る数の前に。名義を複数にして、異動しても面談が止まらないように。四半期の見直しの時間を先に確保 |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。急成長フェーズでは、「型」で四半期で動かせるかを見ることと、「運用工数」で返信の体制を送る数の前に置くことが、他の会社と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「急成長は強みだから、『成長中』『急拡大』『毎年倍増』を前に出せば学生が来る」というものです。当社は3媒体すべての販売パートナーとして、急成長フェーズの会社の相談を受けますが、「成長中」で書いた会社の企業ページは、同じ段階の会社と並べると全部同じに見え、学生は読み飛ばします。しかも「急拡大」は、学生には「人が足りない会社」「教える人がいない会社」とも読まれ、成長の裏の離職を体験談で確かめられます。逆に、「成長中」を消して、「最近変わったこと」（「今年から〇〇の部門ができた」「△△の仕組みを□月に変えた」）と、「変わることがある」（「組織は変わる。教える人と最初の年に任せる〇〇は変えない」）を書いた会社は、変わる会社で動ける学生に「実態を書いている会社」として選ばれ、「安定」を求める学生が先に離れて、入社後の「思っていたのと違う」が減ります。当社が最初にお願いするのは、企業ページと文面から「成長中」「急拡大」「倍増」を消し、「最近変わったこと」を三つ、日付つきで書くことです。数値で成長を示したくなりますが、確認できる数値だけを、変わったことの説明に添える形にします。

## 学生が、確かめること

- **変わる会社で、誰が教えるか**：組織が変わっても、教える人が変わらないか。教える人は足りているか
- **一年目に何をするか**：年の途中で変わらないか。「最初の年に任せる〇〇は変えない」と書かれているか
- **成長の裏の離職**：急成長の会社は離職も多いと学生は知っている。隠さず、理由と変えたことで
- **最近変わったこと**：「成長中」ではなく、何が、いつ、どう変わったか
- **体験談と今の会社のずれ**：去年の体験談と、今年の企業ページが違うことを、会社が分かっているか
- **返信の速さ**：送る数を増やして返信が空くと、「人が足りない会社」の印象を裏づける

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 四半期で職種と「こんな人」が変わり、条件と文面を動かしたい。返信の体制を作れる | 企業から送る型（OfferBox） | 四半期で条件と文面を見直せ、送る数を返信の体制で調整できる。名義を複数にしやすい |
| 経営者が会社の「なぜ」を年に一度書け、「最近変わったこと」を記事で足していける | 通年で記事を置く型（Wantedly） | 「なぜ」は年に一度、変わったことは記事で。成長の記録がそのまま実態になる |
| 体験談があり、企業ページに「変わることがある」と最近変わったことを書ける | 学生が並べて比べる場（ワンキャリア） | 去年の体験談と今年の会社のずれに、企業ページで先に答えられるなら |
| 返信の体制が、送る数に追いついていない | どれも先ではない | 送る数を減らすか、返信を外に出してから |
| 教える人が、採る数に足りていない | どれも先ではない | 採る数を育てる人の数で決め直す |

どれか一つが正解ではなく、四半期で動かしたいか、経営者が書けるか、体験談の有無で、先に検討するものが変わります。

## 組み合わせ

- **四半期の頭に、見直すものと見直さないものを分ける**：見直すのは人数、「こんな人」、検索条件、文面の共通部分、名義、送る数の上限。見直さないのは会社の「なぜ」、連絡の型、面談の入口、台帳の型
- **送る型と記事を置く型を組み合わせる**：文面で四半期の「こんな人」を、記事で「なぜ」と「最近変わったこと」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **返信の体制を、送る数の前に**：[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)
- **名義を複数に**：異動・昇進で名義が外れても、面談が止まらない。[OfferBoxをチームで運用するときの役割分担](/media/ob-team-unyou/)
- **採る数を、育てる人の数で決め直す**：[シリーズB以降のスタートアップの採用媒体の選び方](/media/hikaku-startup-b-erabikata/)の一期生の考え方と同じ
- **代行と組み合わせるなら、四半期の見直しの型と絞る作業と一次返信を**：「こんな人」の決定と名義と面談は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「成長中」ではなく「最近変わったこと」と「変わることがある」

- **「成長中」「急拡大」「毎年倍増」を消す**：同じ段階の会社が全部書いていて、「人が足りない会社」とも読まれる
- **「最近変わったこと」を、三つ、日付つきで**：「今年〇月に△△の部門ができた」「□月に◇◇の仕組みを変えた」。数値は確認できるものだけ、変わったことの説明に添える。この記事では書かない
- **「変わることがある」を、一文で**：「組織は変わる。教える人と、最初の年に任せる〇〇は変えない」
- **教える人を、名前と時間で**：「一年目は〇〇が横につく。組織が変わっても、この人は変わらない」
- **離職を、隠さず**：「〇年で辞めた人が△人。理由は□□。変えたのは◇◇」
- **体験談とのずれに、先に答える**：「去年の体験談の〇〇は、今年△△に変わった」
- **返信の日数を、体制ができてから書く**：「応募から〇日以内」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 四半期の人数、職種、「こんな人」、育てる人の数、送る数の上限を決める | 経営者と採用の責任者。四半期の頭に |
| 会社の「なぜ」 | 経営者。年に一度 |
| 「最近変わったこと」 | 人事が集め、経営者が確認。四半期ごとに |
| 返信の体制 | 人事。送る数の前に担当を決める。外に出してもよい |
| 名義（複数） | 職種ごとに二人以上。異動したら差し替え |
| 面談 | 名義の社員と、教える人 |
| 一年目の定着の記録 | 人事。採用数と並べて経営に |

運用代行や代理店が支えられるのは、四半期の見直しの型、絞る作業、文面の共通部分の下書き、一次返信、記録の型までで、人数と「こんな人」の決定、育てる人の確保、名義、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

急成長フェーズの会社が数字を読むときに先にお伝えしているのは、「採用数の達成で見ない。一年目の定着で見る」ということです。急成長の会社は、採る人数が事業の計画から降りてきて、「今年〇名」の達成が採用の目標になります。達成のために送る数を増やし、返信が追いつかず、承認した学生を急いで面談に回し、教える人が足りないまま入社させ、一年目の離職が続きます。翌年の体験談に「放置された」と書かれ、翌年の採用がさらに難しくなります。当社が案内するのは、採用数と並べて「一年目の終わりに残った数」を経営に報告し、採る数を「育てる人の数」から決め直すことです。採用数を達成して定着が低い年は、翌年の採用数を減らしてでも育てる人を増やすほうが、二年後の採用数は増えます。四半期の見直しで、「採る数を増やす」の前に「育てる人は増えたか」を見ます。急成長の会社の採用は、今年の数ではなく、来年の体験談で決まります。

## まとめ

- 急成長フェーズは、採る人数と「こんな人」が四半期で変わる。媒体は「四半期で見直せる形」で選び、見直すものと見直さないものを分ける
- 送る数を増やす前に返信の体制を作り、名義を複数にして異動しても面談が止まらないようにする
- 送る型（OfferBox）は四半期で条件と文面を動かせ、記事を置く型（Wantedly）は「なぜ」を年に一度と「最近変わったこと」を記事で、比べられる場（ワンキャリア）は体験談が成長に追いつかない前提で企業ページに「変わることがある」を
- 「成長中」「急拡大」を消し、「最近変わったこと」を日付つきで三つ、「変わることがある」と教える人を一文で。離職を隠さない
- 採用数の達成ではなく一年目の定着で見て、採る数を育てる人の数で決め直す。今年の数ではなく、来年の体験談で決まる

## よくある質問

### 事業計画で「今年〇名」と決まっていて、減らせません

減らせないなら、育てる人を先に増やします。「〇名を採るなら、育てる人が△人要る」を経営に示し、育てる人が確保できた職種から採り、確保できない職種は時期をずらします。育てる人が足りないまま採ると、採用数は達成しても一年目に離れ、翌年の体験談で採用がさらに難しくなり、二年後の計画が崩れます。今年の数と来年の体験談を並べて、経営と話します。

### 年の途中で職種が変わり、送った文面が合わなくなりました

四半期の頭に、人数と「こんな人」と検索条件と文面の共通部分を見直す形にします。年初に一年分を作らず、四半期分を作ります。すでに送った学生には、変わった内容を正直に伝え、「この職種は今年は採らなくなった。代わりに〇〇の職種で話せるか」と聞きます。文面に「変わることがある」と最初から書いておくと、変わったときに学生が受け止めやすくなります。

### 急成長フェーズの会社の媒体選びは、御社に相談できますか

できます。当社は、四半期の見直しの型、絞る作業、文面の共通部分の下書き、一次返信、記録の型を支えられます。人数と「こんな人」の決定、育てる人の確保、名義、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、急成長フェーズの会社の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
