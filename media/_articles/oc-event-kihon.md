ワンキャリアでイベントを開きたいが、種類が多く、どれを開けばよいか分からない。ところが、「会社説明会」一つで全部を賄おうとして中身が薄く、種類を増やして全部が薄く、体験談を読まずに種類を決め、出る人が型に合っておらず、毎回種類を変えて型が残らない。**結論から言うと、ワンキャリアのイベントは「体験談で気になったことを、直接確かめる場」で、種類は「誰が出て、何を確かめられるか」で分かれます。会社・仕事の説明会、職種別セミナー、座談会、少人数の相談会、選考の説明、インターンの説明、社名を出さない形、オンラインとオフライン。最初は一つの型を小さく続け、体験談と揃え、書いたとおりに運用します。掲載できる種類と仕様は、管理画面とヘルプで確認してください。** この記事では、種類の選び方で起きる失敗、種類を分ける軸、種類ごとの向く場面と出る人、体験談から種類を決めること、最初の一つの型、オンラインとオフライン、スカウトと企業ページとのつなぎ、分担を整理します。イベントページの書き方は[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)、集まらないときは[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)、説明会の掲載は[ワンキャリアで説明会を掲載する](/media/oc-setsumeikai-keisai/)で書きました。

## この作業の目的｜「確かめられる回」を、体験談に合わせて一つ選ぶ

ワンキャリアの学生は、体験談を読んでから企業ページとイベントに来ます。イベントに来る学生は、「体験談で気になったことを確かめたい」を持っています。だから、イベントの種類は、「自社の体験談で、学生が何を気にしているか」から決まります。会社の都合で種類を選ぶと、確かめたいことと合わず、来ても次に進みません。

目的は、種類を「開きやすいもの」ではなく、「体験談で気になったことが確かめられるもの」から一つ選ぶことです。

## 種類の選び方で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 「会社説明会」一つで、全部を賄う | 会社の説明・仕事の中身・選考・質問、が一回に詰まり、どれも薄い。体験談で気になったことに答えない |
| 種類を増やして、全部が薄い | 出る人も準備も分散し、どの回も続かない |
| 体験談を読まずに、種類を決める | 学生が確かめたいこと（「選考で何を見ているか」など）と、開く回（会社の歴史）がずれる |
| 型と出る人が、合っていない | 座談会に人事だけ、職種別セミナーに人事だけ。確かめたい相手がいない |
| オンラインとオフラインを、同じ中身で開く | オンラインで長い説明、オフラインで質問の時間がない |

共通するのは、種類を「体験談で確かめたいこと」から決めていないことです。

## 種類を分ける、軸

| 軸 | 何で分かれるか |
|---|---|
| 誰が出るか | 人事だけか、その職種の人か、入社してまもない社員か、面接に出る人か、経営層か |
| 何を確かめられるか | 会社の中身か、仕事の場面か、人の雰囲気か、選考で見ていることか、インターンの中身か |
| 人数 | 多人数で話す回か、少人数で質問する回か |
| 選考との関係 | 選考と関係ない回か、選考の一部か、選考の前の回か。年度の公表内容と自社の方針で確認 |
| 開く場所 | オンラインか、オフラインか |

軸で分けると、種類の名前より「何の回か」が決まります。掲載できる種類と、各種類の仕様は、管理画面とヘルプで確認してください。

### エージェントベストの見解

相談で最も多い思い込みは、「まず会社説明会を開いて、反応を見てから種類を増やす」というものです。当社はワンキャリアの販売パートナーとして、イベントの相談を受けていますが、「会社説明会」から始めた会社の多くは、体験談を読んで来た学生の「確かめたいこと」に答える回になっておらず、参加者は来ても次に進まず、「イベントは効かない」で止まっています。逆に、自社の体験談を先に読み、「選考で何を見ているか分からなかった」と書かれていれば選考の説明の回を、「社員の雰囲気が分からなかった」なら座談会を、と一つ選んで小さく続けた会社は、参加者の質問が体験談の続きになっていて、次に進んでいます。当社がイベントの相談を受けるとき、最初にやるのは、種類の一覧を見せることではなく、自社の体験談を一緒に読んで「学生は何を確かめたいか」を一つ決めることです。

## 種類ごとの、向く場面と出る人

| 種類 | 確かめられること | 向く場面 | 出る人 |
|---|---|---|---|
| 会社・仕事の説明会 | 会社が何をしていて、〇〇職の最初の一年に何をするか | 体験談が少なく、「何の会社か」から確かめたい学生が多い | その職種の人と人事 |
| 職種別セミナー | その職種の仕事の場面を、実際の案件で | 職種が複数で、職種ごとに確かめたいことが違う | その職種の人 |
| 座談会 | 入社してまもない社員の、入る前と後の違い。人の雰囲気 | 体験談に「雰囲気が分からない」「社員の話を聞きたい」がある | 入社してまもない社員が複数 |
| 少人数の相談会 | 体験談で気になったことを、一つずつ聞ける | 体験談に具体の疑問が多い。質問中心にしたい | 人事と、その職種の人 |
| 選考の説明 | 各段階で、誰と何を話し、何を見ているか | 体験談に「何を見られているか分からなかった」がある | 面接に出る人と人事 |
| インターンの説明 | インターンで何を任せ、誰が見て、何が残るか | インターンを募集する時期 | インターンの担当と、過去の参加者 |
| 社名を出さない形 | 社名の先入観なしに、仕事と会社を | 知名度がなく、社名で流される。体験談を読んで来る流れとは別の入口 | その仕事の人。掲載の可否と仕様は管理画面とヘルプで確認 |

種類ごとの書き方は[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)の「イベントの型ごとの書き方」で書きました。どの種類でも、「話す時間より、質問の時間を長く」です。

## 体験談から、種類を決める

- **自社の体験談とクチコミを、先に読む**：「分からなかった」「気になった」と書かれていることを拾う
- **拾ったことに、最も答えられる種類を一つ**：「選考で何を見ているか」→選考の説明、「社員の雰囲気」→座談会、「仕事の中身」→職種別セミナー
- **体験談に書かれていることと、回の中身を揃える**：体験談で「〇〇と言われた」とあれば、回でも同じことを言う
- **今年の回が、翌年の体験談になる**：「書いたとおりだった」が翌年の材料。[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)の「来た学生が、体験談に書く回にする」

## 最初は、一つの型を小さく続ける

- **一つの種類を、少人数で、同じ型で続ける**：回ごとに種類を変えない
- **出る人を、固定する**：同じ人が出ると、型が良くなり、参加者の質問が積み上がる
- **回の名前を、「何が確かめられるか」で**：「会社説明会」ではなく。[ワンキャリアのイベントページのタイトル](/media/oc-event-page-title/)
- **続け方は[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)の「小さい回を、途切れさせずに続ける」と[イベントからの母集団形成](/media/kh-boshudan-event/)**

## オンラインとオフラインの、使い分け

| | オンライン | オフライン |
|---|---|---|
| 向く種類 | 会社・仕事の説明会、選考の説明、職種別セミナー | 座談会、少人数の相談会、職場を見せる回 |
| 確かめられること | 話の中身 | 人の雰囲気、職場 |
| 中身 | 短く話し、質問の時間を長く。長い説明は離脱する | 質問と対話を中心に。話す時間は短く |
| 地方の学生 | 来られる | 移動の負担。[地方企業の母集団形成](/media/kh-boshudan-chihou/) |

同じ種類でも、オンラインとオフラインで中身を変えます。同じ中身で両方を開くと、オンラインは長く、オフラインは質問の時間がなくなります。仕様（配信の形、申込の形）は管理画面とヘルプで確認してください。

## スカウトと企業ページとの、つなぎ

- **スカウトの締めで、「この回」に誘う**：文面の四段目を回への誘いに。[ワンキャリアのスカウトとイベントの連携](/media/oc-scout-event-renkei/)
- **企業ページに、回の一覧と「何が確かめられるか」を**：体験談を読んだ学生が、企業ページから回へ。[ワンキャリアのイベントページと企業トップページの使い分け](/media/oc-event-page-kigyo-top/)
- **回の中身と、企業ページと、体験談を揃える**：三つがずれると「書いたとおりでない」になる
- **回の後、当日か翌日に一通、次の場を案内する**：[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)の「終わったあとの動き」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 体験談とクチコミを読み、学生が確かめたいことを一つ決める | 人事 |
| 種類を一つ選び、出る人を固定する | 人事責任者と現場の責任者 |
| 回の名前と中身を、「何が確かめられるか」で作る | 人事と出る人 |
| 回に出て、話し、質問に答える | 出る人（その職種の人・入社してまもない社員・面接に出る人） |
| オンラインとオフラインで中身を変える | 人事と出る人 |
| スカウトの締めと企業ページを回につなぐ | 人事 |
| 回を重ねて型を良くし、二つ目の種類を判断する | 人事責任者 |

運用代行や代理店が支えられるのは、種類の軸の整理、体験談から種類を決める手伝い、回の名前と中身の型、イベントページの型、オンラインとオフラインの分け方、スカウトと企業ページとのつなぎの型までで、体験談を読むこと、種類の決定、出ること、質問に答えること、回の後の連絡は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。イベントの相談で、「種類が多いので、全部の種類を一度ずつ試して、反応の良いものに絞りたい」と言われることがあります。当社がお願いする順番は逆で、まず自社の体験談を読む、学生が確かめたいことを一つ決める、その一つに答える種類を一つ選ぶ、少人数で同じ型を続ける、型が良くなってから二つ目、です。全部を一度ずつ試すと、どの回も型ができる前に終わり、参加者の体験談も回ごとにばらばらで、翌年に「この会社のイベントはこうだった」が残りません。一つの型を続けた回は、翌年の体験談に「〇〇の回で、〇〇が確かめられた」と残り、それが翌年の集客になります。ワンキャリアのイベントは、今年の回が翌年の体験談で、一つを続けることが、種類を増やすことより効きます。

## まとめ

- ワンキャリアのイベントは「体験談で気になったことを、直接確かめる場」。種類は「誰が出て、何を確かめられるか」で分かれ、会社の都合ではなく体験談から決める
- 種類は、会社・仕事の説明会、職種別セミナー、座談会、少人数の相談会、選考の説明、インターンの説明、社名を出さない形。掲載できる種類と仕様は管理画面とヘルプで確認
- 「会社説明会」一つで全部を賄わず、種類を増やして薄くせず、最初は一つの型を少人数で同じ人が続ける。回の名前は「何が確かめられるか」で
- オンラインは話の中身、オフラインは人の雰囲気と職場。同じ種類でも中身を変え、どちらも質問の時間を長く
- スカウトの締めと企業ページを回につなぎ、回の中身と企業ページと体験談を揃え、書いたとおりに運用する。今年の回が翌年の体験談になる

## よくある質問

### 出られる社員が少なく、座談会や職種別セミナーが開けません

出られる人で開ける種類から始めます。人事とその職種の人が一人ずつなら「少人数の相談会」、面接に出る人が出られるなら「選考の説明」。出る人が一人でも、少人数で質問中心の回なら成り立ちます。出る人を増やすのは、一つの型が回ってから、反応を戻して。頼み方は[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)の考え方と同じです。

### 社名を出さない形のイベントは、使ったほうがよいですか

知名度がなく、社名で流される会社には、体験談を読んで来る流れとは別の入口として使えることがあります。ただし、体験談を読んで来る学生とは違う人が来るので、企業ページと回の中身を「社名を知らない人」向けに整える必要があります。掲載の可否と仕様は管理画面とヘルプで確認してください。知名度がない会社の入口の考え方は[知名度がない会社の母集団形成](/media/kh-boshudan-chimeido/)で書きました。

### ワンキャリアのイベントの種類の選び方は、御社に相談できますか

できます。当社は、種類の軸の整理、体験談から種類を決める手伝い、回の名前と中身の型、イベントページの型、オンラインとオフラインの分け方、スカウトと企業ページとのつなぎの型を支えられます。体験談を読むこと、種類の決定、出ること、質問に答えること、回の後の連絡は、企業が行ってください。掲載できる種類と仕様は管理画面とヘルプで確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
