Wantedlyでコーポレート（総務・経理・労務・法務などを兼ねる職）の募集記事を出したとき、最初にぶつかるのは「『バックオフィス全般』『会社を支える仕事』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『何と何を兼ねるのですか』『どれが主ですか』『経営者の隣で何を決められますか』を聞かれて答えられない」という問題です。**結論から言うと、コーポレートの募集記事は、「バックオフィス全般」ではなく「何と何を兼ね、どれが主で、何を外に出していて、経営者の隣で何を決められるか」を書き、募集記事を書く前に兼ねる範囲を一覧にし、主を一つに決め、外注との分担と経営者の隣で決められることを決めておきます。** この記事では、コーポレートが募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。経理・法務・人事のそれぞれの専門職としての募集は、[経理を採る募集記事の書き方](/media/wt-keiri-boshu/)、[法務を採る募集記事の書き方](/media/wt-houmu-boshu/)、[人事を採る募集記事の書き方](/media/wt-jinji-boshu/)で書きました。

## コーポレートが募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 何と何を兼ねるか | 総務、経理、労務、法務、情報システム、広報のうち、どれとどれか。「全般」は、全部一人でと読む |
| どれが主か | 兼ねる中で、時間の多くを使うのはどれか。自分の得意と合うか |
| 外に出している範囲 | 会計事務所、社労士、弁護士、情報システムの外注。社内は窓口だけか、自分で手を動かすか |
| 経営者との距離と、決められること | 経営者の隣で、何を決められるか。手続きを回すだけか、仕組みを決められるか |
| 専門に進む道があるか | 兼務の先に、経理なり人事なりの専門に進む道があるか。ずっと兼務か |
| 仕組み化の実態 | 手作業と紙の残り具合。道具の有無。変えられるか |

「どれが主か」と「経営者の隣で何を決められるか」が、コーポレートに特有の点です。「バックオフィス全般」の一語では、ここが分かりません。

## 書く前に決めること｜兼ねる範囲の一覧、主を一つに、外注との分担、決められること

| 決めること | 選択肢 |
|---|---|
| 兼ねる範囲の一覧 | 総務／経理／労務／法務／情報システム／広報。含むものを全部書き出す。含まないものも書く |
| 主を一つに | 時間の多くを使うもの。「主は経理で、総務と労務を兼ねる」のように |
| 外注との分担 | 会計事務所、社労士、弁護士、外注に何を出し、社内は何をするか |
| 経営者の隣で決められること | 道具の選定、仕組みの変更、規程の案、外注の選定。どこまで任せるか |
| 一人目か | 一人目なら、いま誰がやっていて、引き継ぎをどうするか |
| 専門に進む道 | ある／無い／決まっていない。決まっていないなら、決まっていないと |
| 最初の月に任せること | 一つの手続きの引き継ぎか、紙の仕組みの見直しか。誰と組むか |

「主は総務で、経理は入力だけ」「専門に進む道は決まっていない」でも構いません。隠さずに書けば、それを前提に読む人が来ます。

## 「なにを」｜何と何を兼ね、どれが主か

「なにをやっているのか」は、会社の事業の説明ではなく、このコーポレートが兼ねる範囲と、主に絞ります。

- **兼ねる範囲を、一覧で書く**：「総務（備品、契約の窓口、社内の手続き）、経理（仕訳と請求書、月次は事務所）、労務（勤怠と入退社の手続き、給与は社労士）。法務と情報システムは含まない」
- **主を、一文で書く**：「時間の多くは経理。総務と労務は月の決まった時期に」
- **外に出している範囲を書く**：「決算は会計事務所、給与計算は社労士、契約の確認は弁護士。社内は、それぞれへの窓口と、社内の手続き」
- **いま回っていないことを書く**：「いまは経営者が兼務していて、〇〇が滞っている。請求書は紙で来て、手で入力している」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

コーポレートの募集記事を出す前に、先に決めておかないと効果が出ないのは、「兼ねる範囲の一覧と、含まないもの」です。当社がWantedlyのコーポレートの募集を支えるとき、「バックオフィス全般」と書かれているのに、経営者に聞くと「経理の入力と、総務と、労務の手続き。法務は弁護士、情報システムは外注」という会社が多くあります。範囲が決まっていないのではなく、書き出していないだけです。コーポレートが面談で最初に聞くのは、「具体的に、何と何ですか」で、ここで一覧が出ないと、「入ってから何でも足される仕事」を想像して離れます。「総務と経理と労務。主は経理。法務と情報システムは含まない」と一覧で書けば、それを前提に読む人が来ます。当社が最初にお願いするのは、「全般」の中身を、含むものと含まないものに分けて書き出してもらうことです。含まないものを書くことが、「何でも足される」の不安を消します。

## 「どうやって」｜外注との分担と、決められることの書き方

| 書くこと | 書き方 |
|---|---|
| 外注との分担の流れ | 会計事務所に何を、いつ渡すか。社労士に何を。弁護士に何を。社内で何をするか |
| 経営者の隣で決められること | 「道具の選定は任せる」「規程の案は作ってもらい、経営者が決める」「外注の変更は相談」 |
| 仕組みの状態 | 手作業と紙の残り具合。道具の有無。「請求書は紙で、勤怠は表計算」 |
| 月の流れ | 月初と月末に何が集中するか。決算期の負荷。数値は確認したものだけ |
| 前に変えた例 | 「〇〇を紙から△△に変えて、□□が減った」。無ければ書かない |

「会社を支える」と書くより、「決算は事務所、給与は社労士、社内は窓口と手続き。道具の選定は任せる」と書くほうが、仕事の実態が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| バックオフィス経験3年以上 | 複数の仕事を、月の流れに合わせて順番を付けて回したことがある |
| 経理・労務の知識 | 分からないことを、事務所や社労士に聞いて、自分で手続きを回したことがある |
| マルチタスクが得意な方 | 手作業や紙の仕組みを、道具に置き換えて減らしたことがある |
| 縁の下の力持ち | 経営者に「これは仕組みを変えたほうがいい」と提案して、変えたことがある |
| 即戦力 | 最初の月は〇〇の手続きの引き継ぎを任せる予定です。△△と組みます |

「複数の仕事を、月の流れに合わせて順番を付けて回した」が、コーポレートで最も読まれる行動です。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「何と何を兼ね、どれが主か」と同じ言葉で**：相手が「何と何を兼ねて、何を仕組みに変えたか」を読み、自社の一覧と重ねる。[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)
- **面談には、経営者が出る**：コーポレートは経営者の隣で動く仕事なので、経営者が「何を決めてもらいたいか」を本人の言葉で話す
- **面談で話すのは、一覧と実態の話**：兼ねる範囲の一覧、外注との分担、いま回っていないこと、仕組みの状態。相手なら何から手を付けるかを聞く
- **専門に進む道を隠さない**：あるならある、無いなら無い、決まっていないなら決まっていないと

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 兼ねる範囲の一覧、主、外注との分担、決められることを決める | 経営者 |
| 「なにを」（一覧、主、外注、回っていないこと）の下書き | 経営者か、いま兼務している人が書く |
| 「どうやって」（分担の流れ、決められること、仕組みの状態） | 経営者が話し、書き、本人が確認 |
| 外注先との関係の確認 | 会計事務所、社労士、弁護士の担当 |
| 「こんな人」を行動で書く、最初の月の予定 | 経営者 |
| 面談 | 経営者 |

一人目のコーポレートを採る募集では、いま経営者が全部を兼務していることが多くあります。その場合は、「いまは経営者が全部やっていて、〇〇が滞っている。最初の月は△△の引き継ぎから。主は□□。法務と情報システムは含まない」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、一覧と分担を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、範囲の決定、外注との分担、経営者の隣で決められることの線引き、面談は経営者が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「コーポレートは、幅広く任せると書いたほうが、何でもできる人が来る」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyのコーポレートの募集と面談を見ていますが、「バックオフィス全般」「幅広く活躍」と書いた募集記事より、「総務と経理と労務。主は経理。法務と情報システムは含まない。道具の選定は任せる」と一覧と線引きを書いた募集記事のほうが、話を聞きに来る人の経験が合い、入社後に離れる人が少ない傾向があります。コーポレートを専門にしてきた人は、「全般」を読むと「入ってから何でも足される」を最も警戒します。一覧と「含まないもの」と「決められること」が書かれていれば、「範囲と権限が明確な会社」として読みます。当社が案内するのは、「全般」を消し、含むものと含まないものを一覧にし、主を一つ書き、経営者の隣で決められることを書くことです。幅の広さで人は来ません。範囲の明確さと、決められることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「バックオフィス全般」「会社を支える」で書く | 「何でも足される」を想像される | 含むものと含まないものを一覧で書く |
| 主を書かない | 「全部同じ重さで一人で」を想像される | 時間の多くを使うものを一つ書く |
| 外注との分担を書かない | 「全部自分で」か「窓口だけ」を想像される | 何を出して、社内で何をするかを書く |
| 決められることを書かない | 「手続きを回すだけ」を想像される | 道具、仕組み、規程の案。どこまで任せるかを書く |
| 専門に進む道を盛る | 入社後に道が無いと分かり、離れる | あるなら書く。無いなら無いと |
| 面談に経営者が出ない | 「経営者の隣で何を決められるか」が伝わらない | 経営者が出て、本人の言葉で話す |

最も多いのは、最初の「バックオフィス全般」です。

## まとめ

- コーポレートが見ているのは、何と何を兼ねるか・どれが主か・外に出している範囲・経営者の隣で何を決められるか・専門に進む道があるか・仕組みの実態
- 書く前に、兼ねる範囲を含むものと含まないものに分けて一覧にし、主を一つに、外注との分担、経営者の隣で決められることを、経営者が決める。道が無くても、隠さない
- 「なにを」は一覧と主と外注との分担といま回っていないこと。「どうやって」は分担の流れと決められることと仕組みの状態を、実態で。前に変えた例を一つ
- 「こんな人」は経歴ではなく、「複数の仕事を月の流れに合わせて順番を付けて回した」「手作業を道具に置き換えた」の行動で
- 面談には経営者が出て、何を決めてもらいたいかと、専門に進む道の有無を本人の言葉で話す

## よくある質問

### 経理も労務も総務も、本当に一人に全部任せたいです。書くと来ませんか

隠すほうが、入社後に分かって離れます。「総務と経理と労務を一人で。主は経理。決算は事務所、給与は社労士、契約は弁護士に出す。社内は窓口と手続き。法務と情報システムは含まない」のように、全部書き出し、主を一つ、外に出すものと含まないものを書きます。複数を一人で回してきた人には、「範囲が書かれている会社」として読まれます。

### 専門に進む道が無く、ずっと兼務の予定です

そのまま書きます。「専門に分かれる予定は、いまは無い。会社が大きくなったら、経理か労務のどちらかを専任にしたい。時期は決まっていない」のように、無いことと、あるとしたらいつ考えるかを書きます。兼務を自分の専門と考えている人は一定数いて、その人には「兼務のまま任される会社」として読まれます。

### コーポレートの募集記事は、御社に相談できますか

できます。当社は、募集記事の型、一覧と分担を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。範囲の決定、外注との分担、決められることの線引き、面談は、経営者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
