中途採用がうまく進まないとき、原因を媒体の選び方や応募の少なさに求めがちです。しかし、相談を受けて中身を見ていくと、手段より前の段階や、応募が来たあとの段階でつまずいていることが多くあります。**結論から言うと、中途採用の失敗は「始める前」「選考中」「内定後」の三つの時点に分けて見ると、どこを直せばよいかが分かります。** この記事では、時点ごとにやりがちな失敗と防ぎ方を並べ、募集の前に使える点検表にまとめます。

## 失敗は三つの時点で起きる

中途採用の流れを大きく分けると、募集を始める前、応募が来てから内定を出すまで、内定を出してから入社するまで、の三つになります。

- **始める前**：何を任せる人を、どんな条件で採るかを決める段階
- **選考中**：応募や返信に対応し、面接をして、合否を決める段階
- **内定後**：条件を伝え、承諾をもらい、入社日を決めて受け入れる段階

失敗の多くは、前の時点で決めておくべきことが決まっていないまま、次の時点に進んだことで起きます。たとえば、年収の幅を決めずに選考を始めると、最終面接のあとで条件が折り合わず、それまでの選考がやり直しになります。だから、失敗を見るときは、それが表に出た時点ではなく、決めておくべきだった時点で考えます。

## 始める前の失敗

募集を出す前に起きやすい失敗は、次の四つです。

1. **任せる仕事が言葉になっていない**：「即戦力」「経験者」の一言で募集を出すと、応募してくる人の幅が広すぎて、書類選考で毎回迷います。入社後の最初の数か月に何を担ってもらうかを、具体的な仕事の名前で書きます
2. **必須と歓迎が分かれていない**：欲しい経験を全部必須にすると、該当する人がほとんどいなくなります。なくては困るものだけを必須に残します
3. **年収の幅を決めていない**：社内の同じ職種の人との釣り合いを見ずに始めると、良い候補者が出てきたときに提示できる額が決まらず、判断が遅れます
4. **手段を一つに決め打ちしている**：求人媒体だけ、紹介だけ、と決めてしまうと、反応がなかったときに打ち手がありません。最初に、主に使う手段と、反応が薄いときに足す手段を決めておきます

この段階の失敗は、現場と人事の間で「どんな人が欲しいか」をすり合わせる時間を取らなかったことから起きることが多いです。募集の前に一度、現場の責任者と一緒に、任せる仕事と必須の条件を一枚に書き出します。求人票に書く内容の整理は[求人票の書き方の基本](/media/kh-kj-kihon/)も参考になります。

### エージェントベストの見解

当社は求人媒体と人材紹介の両方を扱っているので、同じような募集を、媒体の側と紹介の側の両方から見ることがあります。そこで分かるのは、始める前の失敗は、どの手段を使っても同じように表に出るということです。任せる仕事があいまいな募集は、媒体では応募が来ても書類選考で迷い、紹介では紹介会社が候補者を絞れずに推薦が止まります。手段を替えれば解決するように見えて、実際は同じところで止まり続けます。応募が来ない、推薦が来ないという相談を受けたとき、最初に確かめるのは手段ではなく、「この人に入社後すぐ任せる仕事を三つ挙げてください」という問いに、現場と人事が同じ答えを出せるかどうかです。答えがそろわないなら、手段を見直す前に要件を見直します。

## 選考中の失敗

応募が来たあとの失敗は、速さと判断のずれに集まります。

- **返信が遅い**：中途の候補者は在職しながら複数の会社を同時に受けていることが多く、返信が遅れるとその間に他社の選考が進みます。応募に返信する人と、返信までの目安を先に決めておきます
- **面接官ごとに見ていることが違う**：一次と二次で同じ質問を繰り返したり、面接官によって合否の基準が違ったりします。各回で見ることを決め、記録を次の回に渡します
- **合否の判断が会議待ちになる**：面接が終わっても、判断する人が集まる会議まで結果が出ない状態です。判断する人と、判断までの日数の目安を決めておきます
- **条件を最後まで話さない**：給与や働き方の話を最終面接まで出さないと、最後に折り合わず、それまでの時間が無駄になります。一次の段階で目安だけでも確かめます

面接の回数と各回の役割は[面接の設計｜何回・誰が・何を見るかを先に決める](/media/kh-ms-sekkei-kihon/)に、選考期間と辞退の関係は[選考期間の考え方](/media/kh-ms-senkou-kikan/)にまとめています。

## 内定後の失敗

内定を出したあとは、気が緩みやすい段階です。

- **承諾を待つだけになる**：内定を出したあと、候補者からの返事をただ待っていると、迷っている理由が分からないまま辞退になります。条件を伝える場で、迷っている点を聞いておきます
- **現職の退職を考えていない**：中途の候補者は、現職の引き継ぎや退職の手続きがあります。入社日を会社の都合だけで決めると、無理が生じて辞退につながることがあります
- **受け入れの準備ができていない**：入社初日に机や機材、最初の仕事が用意されていないと、候補者は入社前に聞いた話と違うと感じます。誰が受け入れるかを内定の時点で決めておきます

## 募集前に使う点検表

三つの時点の失敗を防ぐために、募集を出す前に次の点を確かめます。

| 時点 | 確かめること | 決める人 |
|---|---|---|
| 始める前 | 入社後に任せる仕事を具体的に書いたか | 現場の責任者・人事 |
| 始める前 | 必須と歓迎を分けたか | 現場の責任者 |
| 始める前 | 年収の幅と、社内との釣り合いを確かめたか | 人事・経営者 |
| 始める前 | 主な手段と、反応が薄いときに足す手段を決めたか | 人事 |
| 選考中 | 応募への返信を誰がいつまでにするか決めたか | 人事 |
| 選考中 | 各回で見ることと面接官を決めたか | 人事・現場の責任者 |
| 選考中 | 合否を誰が何日以内に決めるか決めたか | 経営者・現場の責任者 |
| 内定後 | 条件を伝える場と、迷いを聞く人を決めたか | 人事 |
| 内定後 | 入社日の決め方と、受け入れる人を決めたか | 人事・現場の責任者 |

表の右の列が空いている項目が、失敗が起きやすい場所です。決める人がいない項目は、誰かが気づくまで止まります。この点検表は、Greenやdoda、typeのような中途向けの求人媒体を使う場合も、紹介やリファラルで採る場合も、同じ形で使えます。

### エージェントベストの見解

媒体の申込のあとの運用まで見ていると、選考中の失敗の多くは、採用担当者の努力不足ではなく、決める人が決まっていないことから起きていると感じます。たとえば、面接が終わってから合否が出るまでに時間がかかる会社では、担当者は早く返事をしたいのに、判断する経営者や現場の責任者の予定が合わず、結果を待っています。この場合、担当者が急いでも速くはなりません。勧めているのは、募集を出す前に「合否は面接官がその日のうちに書き、判断する人は翌営業日までに返す」のように、判断の締め切りを社内で決めておくことです。締め切りが決まっていると、担当者は候補者に「何日までにご連絡します」と言えます。候補者にとっては、結果の早さそのものより、いつ連絡が来るかが分かることが安心につながります。

## まとめ

- 中途採用の失敗は「始める前」「選考中」「内定後」の三つの時点に分けて見る
- 失敗は表に出た時点ではなく、決めておくべきだった時点で直す
- 始める前は、任せる仕事・必須と歓迎・年収の幅・手段の組み合わせを決める
- 選考中は、返信の担当と判断の締め切りを決める
- 内定後は、迷いを聞く場と受け入れる人を決めておく

## よくある質問

### 失敗が多すぎて、どこから直せばよいか分かりません

点検表の「始める前」から順に見てください。後ろの時点の失敗は、前の時点で決めていないことが原因になっていることが多いからです。とくに、任せる仕事と年収の幅が決まると、選考中の迷いが減ります。

### 現場の責任者が忙しく、要件のすり合わせに時間が取れません

長い会議は要りません。人事が任せる仕事と必須の条件の案を書き、現場の責任者には直すところだけを見てもらう形にすると、短い時間で済みます。現場を採用に巻き込む進め方は[現場を採用に巻き込む方法](/media/kh-pl-genba-makikomi/)にまとめています。

### 内定辞退が続いています。何を見直せばよいですか

辞退がどの時点で、どんな理由で起きているかを並べるところから始めます。条件の提示の仕方は[条件提示の進め方](/media/kh-ms-jouken-teiji/)を、辞退の振り返り方は[中途採用の振り返り](/media/kh-ch-review/)を参考にしてください。
