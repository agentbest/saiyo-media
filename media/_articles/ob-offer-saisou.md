一度送ったが反応が無かった学生に、もう一度送ってよいのか。「しつこいと思われないか」「送れば承認されるのではないか」の両方の声を聞きます。**結論から言うと、再送は「前回が無反応で、学生側に変化（プロフィールの更新、時期の変化）があるか、企業側に変化（別の職種、新しい材料）がある場合」に、前回とは違う文面で、1回だけ送るものです。辞退した学生や、面談のあとに進まなかった学生には、再送ではなく別の連絡をします。** 前回と同じ文面を機械的に送り直すのは、学生に「使い回し」と分かり、逆に信頼を失います。この記事では、送ってよい場合と送らない場合、再送の文面の書き方、間隔と回数、二重送信の防ぎ方、媒体の仕様の確認、やりがちな失敗、分担を整理します。同じ学生に再度送れるかどうかは媒体の仕様で決まるので、この記事では仕様には触れず、送れる前提での考え方を書きます。

## この作業の目的｜「一度送った学生」を、読み直す対象に戻す

送った学生の多くは、承認しません。開かれなかった、開いたが閉じた、興味はあったが忙しかった、そのときは他社で進んでいた。理由はさまざまで、「自社に興味が無い」とは限りません。

再送の目的は、一度送った学生を「終わった対象」にせず、変化があれば読み直す対象に戻すことです。ただし、読み直す対象に戻すのであって、送り直す対象に戻すのではありません。読み直して、前回と違う材料があれば送る。無ければ送らない。この順番を守ると、再送はしつこさではなく、丁寧さになります。

## 手順1｜送ってよい場合と、送らない場合を分ける

| 前回の結果 | 再送 | 理由 |
|---|---|---|
| 開かれなかった、または無反応 | 変化があれば送ってよい | 興味が無かったとは限らない。件名か時期の問題かもしれない |
| 開いたが、承認しなかった | 変化があれば送ってよい | 文面の中身か、時期か、他社の進行か |
| 承認したが、返信に返事が無かった | 再送ではなく、追いかけを1回。[承認後の連絡](/media/ob-shounin-go/) | すでに接点がある。オファーを送り直すのは不自然 |
| 承認して面談したが、選考に進まなかった | 再送しない。時期が変わったら別の連絡 | 面談で判断した学生。オファーではなく、名義の人から一言 |
| 辞退した | 再送しない | 学生の判断を尊重する |
| 選考で不採用にした | 再送しない | 企業の判断。送ると混乱する |

再送してよいのは、上の2つだけです。「承認したあと」の学生には、再送ではなく、その段階に合った連絡をします。

「変化があれば」の中身は、次の手順で書きます。

## 手順2｜「変化」があるかを確かめる

再送の条件は、前回から何かが変わっていることです。変化が無いなら、前回と同じ結果になります。

**学生側の変化**

- **プロフィールが更新された**：自由記述が増えた、志望業界が変わった、新しい経験が書かれた。更新日を見る。読み方は[学生プロフィールの読み方](/media/ob-profile-yomikata/)
- **時期が変わった**：前回は学生が動いていない時期で、いまは動いている。時期の考え方は[送る時期と時間帯の考え方](/media/ob-soushin-timing/)
- **前回は早期で、いまは選考期**：早期に浅く送った学生に、選考期に深く送り直す。二段構えの考え方は[早期に使うときの進め方](/media/ob-souki/)
- **後期に動いている**：前回は選考期で他社が進んでいたが、後期に改めて動いている。読み分けは[後期に使うときの進め方](/media/ob-kouki/)

**企業側の変化**

- **別の職種で送る**：前回は営業職で、今回は企画職。仕事の中身が違えば、別の文面になる
- **新しい材料がある**：前回は触れられなかった一文に、今回は触れられる。読み直して見つけた
- **名義の人が変わった**：別の現場社員の名義で、別の仕事の話をする
- **企業ページや募集要項を整えた**：前回は見に来た先が古かった。整えてから送り直す。整え方は[企業ページで伝えること](/media/ob-kigyo-page/)

学生側か企業側か、どちらかに変化があれば再送の理由になります。どちらにも無ければ、送りません。

### エージェントベストの見解

相談で最も多い思い込みは2つあります。1つは「再送はしつこいので、一度送った学生には二度と送らない」。もう1つは「再送すれば、そのうち承認される」。前者は、時期や件名の問題で開かれなかった学生を、興味が無いと決めつけています。後者は、変化が無いまま送り直しても、同じ結果になることを見ていません。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、再送で承認が出ている会社は、「変化があるか」を再送の条件にしています。プロフィールが更新された、時期が変わった、別の職種で送れる。変化があるときだけ、前回と違う文面で送る。変化が無いときは送らない。この条件だと、再送は「しつこい」にも「無駄」にもならず、「読み直した」と伝わります。再送するかどうかは、送るかどうかの問題ではなく、読み直すかどうかの問題です。

## 手順3｜再送の文面は、前回に触れて、新しい材料で書く

再送の文面は、前回と同じにしません。書き方は次のとおりです。

1. **前回送ったことに、一言触れる**：「以前にもお送りしましたが」「〇月頃に一度ご連絡しましたが」。隠さない。隠すと、学生は「同じ会社から2回来た。前のは忘れているのか」と感じる
2. **なぜ改めて送るのかを書く**：「プロフィールを拝見して、新しく〇〇の経験が書かれていたので」「今回は△△の職種で」「前回とは別の担当から」。変化を理由にする
3. **新しい材料に触れる**：前回触れなかった一文、新しく書かれた経験。冒頭の「読んだ・こう思った」を新しく書く。構成は[オファー文面の構成](/media/ob-offer-kosei/)
4. **本文は、変化した部分を中心に**：別の職種なら仕事の中身を、整えた企業ページなら「詳しくはこちら」を
5. **締めは前回より軽く**：「お忙しければ、ご返信は不要です」の一言があると、押しつけにならない
6. **名義**：前回と同じ人なら「改めて」、別の人なら「別の担当から」

「前回に触れる」が、再送で最も大事な点です。触れずに送ると、学生には「使い回し」か「管理できていない会社」に映ります。触れて、理由を書くと、「読み直してくれた」に変わります。

## 手順4｜間隔と回数の上限

再送の間隔と回数は、先に決めておきます。

- **間隔**：前回から、学生側か企業側に変化が起きるだけの時間を空ける。時期の変化なら、学生の動きの山が変わるまで。プロフィールの更新なら、更新を確認してから。数週間では変化は起きにくい
- **回数**：再送は1回。2回目の再送（合計3回目）は、送らない。3回送って反応が無ければ、興味が無いか、他で決めている
- **早期からの再送は別に数える**：早期に浅く送り、選考期に深く送る二段構えは、再送の1回に含めない。最初から計画した二段構えだから。ただし、選考期の文面で「早期にもお送りしましたが」と触れる

上限を決めておかないと、承認が足りないときに「もう一度」を繰り返します。

## 手順5｜管理表で二重送信を防ぐ

再送を計画的に行うには、管理表が要ります。無いと、意図しない二重送信が起きます。

| 管理表に書くこと | 何のために |
|---|---|
| 送った日と、文面の型と、触れた一文 | 再送のときに、前回と違う材料で書くため |
| 結果（開封の有無が見えれば、承認、無反応） | 再送してよい学生かの判断 |
| 再送の可否と、その理由 | 送らない学生（辞退、不採用、面談後）を明示する |
| 再送した日と、変化の内容 | 回数の上限を守る。前回に触れる文面を書くため |
| プロフィールの更新日 | 学生側の変化の確認 |

複数人で運用している場合は、管理表が1つでないと、別の人が同じ学生に送ります。分担は[チームで運用するときの役割分担](/media/ob-team-unyou/)で書きました。

同じ学生に再度送れるか、送れるとしてどういう形になるかは、媒体の仕様で決まります。管理画面や媒体の案内で確認してから、再送の計画を作ります。仕様上できないなら、この記事の考え方は「別の職種の募集で送る」「早期と選考期の二段構え」に限られます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 前回と同じ文面を送り直す | 使い回しと分かる | 前回に触れ、新しい材料で書く |
| 前回送ったことに触れない | 管理できていない会社に映る | 一言触れて、理由を書く |
| 変化が無いのに送る | 同じ結果になる | 変化があるときだけ |
| 辞退した学生に送る | 学生の判断を無視している | 送らない |
| 面談後に進まなかった学生にオファーを送り直す | 不自然。接点がある学生にはオファーではない | 名義の人から一言 |
| 回数の上限が無い | 承認が足りないと繰り返す | 1回まで |
| 管理表が無い | 意図しない二重送信 | 送った学生と結果を記録する |
| 媒体の仕様を確認しない | 送れない、または想定と違う形で届く | 管理画面と案内で確認する |

最も多いのは、最初の「前回と同じ文面を送り直す」です。読み直さずに送り直すと、こうなります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 再送してよい学生を管理表から出す | 人事（または運用代行） |
| プロフィールを読み直し、変化を確認する | 読む人 |
| 再送の文面を書く | 読んだ人 |
| 前回に触れているか、新しい材料かをチェック | 書いた人と別の1人 |
| 間隔と回数の上限を決める | 人事 |
| 媒体の仕様を確認する | 人事（代理店に聞いてもよい） |

運用代行に出している場合、管理表からの抽出、読み直し、再送の文面は代行が行えます。再送の方針（間隔、回数、送らない学生の範囲）は社内で決めます。代行の範囲は[運用代行に任せられる範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行で再送を行うとき、管理表から「前回が無反応で、プロフィールが更新された学生」を出し、読み直し、前回に触れた文面を書くところまでは当社が行います。ただし、「辞退した学生と面談後に進まなかった学生には送らない」「再送は1回まで」「間隔はこれだけ空ける」という方針は、企業に決めてもらいます。方針が無いまま当社が再送を始めると、企業が知らないうちに、面談で会った学生に別の文面が届く、という事故が起きます。再送は、送る作業より、送らない範囲を決めることのほうが重い。送らない範囲を企業が決め、その範囲の外で当社が読み直して送る。この分担で、再送は「読み直した」と伝わる形になります。

## まとめ

- 再送してよいのは、前回が無反応で、学生側か企業側に変化がある場合。辞退、不採用、面談後に進まなかった学生には送らない
- 変化とは、プロフィールの更新、時期の変化、別の職種、新しい材料、名義の変更、企業ページの整備
- 再送の文面は、前回に一言触れ、改めて送る理由を書き、新しい材料で冒頭を書く。同じ文面を送り直さない
- 再送は1回まで。間隔は変化が起きるだけの時間を空ける
- 管理表で送った学生と結果を記録し、二重送信を防ぐ。同じ学生に送れるかは媒体の仕様を確認する

## よくある質問

### 一度送って開かれなかった学生に、もう一度送ってよいですか

学生側（プロフィールの更新、時期の変化）か企業側（別の職種、新しい材料、企業ページの整備）に変化があれば、前回に触れて新しい材料で書いた文面を1回送ってよいです。変化が無いなら、同じ結果になるので送りません。同じ学生に送れるかどうかは、媒体の仕様を確認してください。

### 再送の文面で、前回送ったことに触れないほうが自然ではありませんか

触れたほうが自然です。触れないと、学生には「同じ会社から2回来た。前のは忘れているのか」と映ります。「以前にもお送りしましたが、プロフィールに新しく〇〇が書かれていたので」と理由を添えると、「読み直してくれた」に変わります。

### 再送の運用は、御社に頼めますか

管理表からの抽出、読み直し、前回に触れた文面の作成は当社が行えます。送らない学生の範囲、間隔、回数の上限は、企業に決めていただきます。当社がOfferBoxの運用代行を受けるときは、この方針を最初の打ち合わせで決めてから再送を始めます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
