募集記事の各部分の書き方は、これまでの記事で書いてきました。この記事は、その基本を知っていても起きる失敗を、部分ごとに集めたものです。**結論から言うと、募集記事の失敗は8つの部分に分けると直しやすく、話を聞きに来ないときは、失敗を探す前に「一覧で開かれていないのか、開いて離れているのか、会社ページで離れているのか」を切り分けます。切り分けずに募集記事だけを直すと、原因が会社ページにあるときに直りません。** この記事では、8つの部分ごとの失敗と直し方、出す前のセルフチェック、来ない原因の切り分け、出して放置する失敗、分担を整理します。募集記事の全体は[募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。

## この作業の目的｜失敗に「気づける」状態を作る

募集記事の失敗は、書いた本人には見えにくいものです。書いているときは丁寧に書いたつもりでも、候補者の側から読むと「会社の話しかない」「入ったら何をするか分からない」と映ります。

気づける状態を作るには、2つの手段があります。出す前に部分ごとにチェックすること、出したあとに来た候補者の言葉で気づくことです。後者は、面談の最初に「募集記事のどこを読んで来ましたか」と聞くだけで分かります。この聞き方は[募集記事を差し替えて比べる方法](/media/wt-boshu-abtest/)でも書きました。

## 失敗1｜タイトル

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 職種名だけ | 他社と同じ | 「何をする人を探しているか」を一言。[募集タイトルの付け方](/media/wt-boshu-title/) |
| 「急募」「大募集」 | 会社の都合 | 募集の理由を書く |
| 「挑戦」「成長」 | 抽象語 | 具体的な仕事の一言 |
| 先に作って本文とずれる | 「タイトルと違う」 | 本文を書いてから縮める |
| 新卒向けに「即戦力」 | 学生が閉じる | 志向で書く |

## 失敗2｜「なにをやっているのか」

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 会社ページと同じ文章 | 長い。この職種の位置が見えない | この職種が事業のどこを担うかを数行で。[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/) |
| 業界の言葉 | 何の仕事か分からない | 初めて聞く人に分かる言葉で |
| 沿革や市場の説明 | 読まれない | 会社ページへ |

## 失敗3｜「なぜやるのか」

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 会社の理念をもう一度 | 読み飛ばされる | 「なぜ今この募集か」を書き、理念は一文でつなぐ。[「なぜやるのか」の書き方](/media/wt-boshu-naze/) |
| 「事業拡大のため」で終わる | 役割が見えない | 何が広がって何の手が足りないか |
| 欠員を「増員」と書く | 面談で気づかれる | 正直に書き、支える体制を添える |
| 理由が古いまま | 放置されていると映る | 状況の変化で書き直す |

### エージェントベストの見解

申し込んだあと、募集記事で最初の数ヶ月に起きやすいのは、「出した時点で完成と思い、その後に触らない」ことです。出したときは丁寧に書いても、募集の理由が変わり、チームの人が変わり、道具が変わり、記事は出したときのまま。候補者が面談で「記事に〇〇とありましたが」と聞き、「いまは違います」と答える。この一言で、募集記事の他の部分も疑われます。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、話を聞きに来る候補者が続いている会社は、募集記事を「出して終わり」にせず、募集の開始と数ヶ月に一度、配属先に聞き直しています。聞き直す時間は短く、変わった部分だけを直せば足ります。募集記事は、書いた日から古くなり始めます。「出す前」のチェックと同じくらい、「出したあと」の聞き直しの日を決めておくことを勧めます。

## 失敗4｜「どうやっているのか」

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 会社全体の働き方 | このチームが見えない | このチームの1日、決め方、大変なこと。[「どうやっているのか」の書き方](/media/wt-boshu-dou/) |
| 制度を並べる | 実態が分からない | 制度ではなく、このチームでの実際 |
| 人事が想像で書く | 抽象語になる | 現場に「昨日1日」を聞く |
| 良いことだけ | 建前 | 大変なことを1つ |

## 失敗5｜「こんなことやります」

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 「幅広い業務」 | 何をするか分からない | 最初の月にやることを1つ。[「こんなことやります」の書き方](/media/wt-boshu-konna/) |
| 「ゆくゆくは」が中心 | 最初の日々が見えない | 最初の数ヶ月を先に |
| 決まっていないのに決まっているように | 面談で詰まる | 「一緒に決める」と正直に |
| 誰と組むかが無い | 1人で放り出される | 名前で書く |
| 難しさを書かない | 建前 | 最初に詰まりやすいことを1つ |

## 失敗6｜求める動き方と、条件

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 「主体性」「コミュニケーション力」 | 自分が合うか判断できない | 行動の型で。「〇〇のとき、△△できる人」 |
| 経験と資格の羅列 | 求人票 | 経験が要るなら書き、面談で確かめると添える |
| 条件を隠す | 面談のあとで辞退 | 隠さず、最後に。共感型でも条件は書く。[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/) |
| 条件を中心にする | 求人票 | 中心は「何をやるか」 |
| 「当社規定による」 | 判断できない | 分かる範囲で正確に |

## 失敗7｜カバー写真

| 失敗 | 候補者からどう見えるか | 直し方 |
|---|---|---|
| 全募集で同じ会社の写真 | 職種の違いが分からない | 募集ごとにその職種の場面。[カバー写真の選び方](/media/wt-boshu-shashin/) |
| 集合写真、外観、ロゴ | 仕事の空気が無い | 仕事中の人の場面 |
| タイトルと写真がずれる | 開いて戸惑う | 本文→タイトル→写真の順 |
| 文字入れ | 広告 | 場面だけ |
| フリー素材 | 自社の写真が無い会社 | 無いなら会社ページの近い場面を仮に |

## 失敗8｜運用

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 出して放置 | 古くなり、面談で「違う」 | 募集の開始と数ヶ月に一度、配属先に聞き直す |
| 1本に全部を詰める | 誰にも自分宛に見えない | 誰に向けた入口かで分ける。[複数パターン作る理由](/media/wt-boshu-fukusu/) |
| 同じ内容をコピーして増やす | 候補者が迷う | 軸が違うものだけ |
| 複数の要素を同時に変えて比べる | 何が効いたか分からない | 1要素ずつ、月で |
| 閉じるべき募集を残す | 一覧が古くなる | 埋まったら閉じる |
| 会社ページが古いまま募集だけ直す | 会社ページで離れる | 会社ページも見る。[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/) |
| 面談で「どこを読んだか」を聞かない | 失敗に気づけない | 面談の最初に聞く |

## 出す前のセルフチェック

出す前に、次の順で見ます。数分で済みます。

1. **タイトル**：職種名だけになっていないか。本文の「何をやるか」の要約になっているか
2. **「こんなことやります」**：最初の月にやることが1つ書いてあるか。「幅広い」「ゆくゆくは」で終わっていないか
3. **「なぜ」**：会社の理念の繰り返しになっていないか。なぜ今この募集かが書いてあるか
4. **「どうやって」**：このチームの1日と大変なことがあるか
5. **抽象語**：成長、挑戦、主体性、風通し、が残っていないか
6. **条件**：隠していないか。最後に置いてあるか
7. **写真**：この職種の仕事中の場面か。タイトルと合っているか
8. **会社ページとの重複**：同じ文章が2回出ていないか
9. **別の1人に読んでもらう**：候補者の目線で「入ったら何をするか分かるか」

1と2で止まることが多いので、この2つだけでも毎回見ます。

## 話を聞きに来ないときの、原因の切り分け

話を聞きに来ない、という症状は、原因が3つに分かれます。募集記事だけを直す前に、どこで止まっているかを見ます。

| 止まっている場所 | 見えるサイン | 直す場所 |
|---|---|---|
| 一覧で開かれていない | 閲覧の数が見えるなら少ない。見えなければ、タイトルと写真を他社と並べて比べる | タイトルと写真 |
| 開いたが、本文で離れている | 開かれているが、話を聞きに来ない | 「こんなことやります」「なぜ」「どうやって」 |
| 会社ページで離れている | 募集記事は読まれているが、会社ページが古い、抽象語、人が見えない | 会社ページ。[会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/) |
| 来ているが、面談で「思っていたのと違う」 | 話は聞きに来るが、選考に進まない | 募集記事と実態のずれ。正直に書く |

「会社ページで離れている」は、募集記事の失敗を探しても見つかりません。募集記事を直す前に、会社ページを候補者の目線で開いてみます。この切り分けは、OfferBoxで「承認が少ないときは文面を直す前に検索条件と企業ページを見る」と書いたのと同じ考え方です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 出す前のセルフチェック | 書いた人と、別の1人 |
| 面談で「どこを読んだか」を聞く | 面談に出る人 |
| 来ない原因を切り分ける | 人事 |
| 部分ごとの失敗を直す | 人事（配属先に聞く部分は配属先） |
| 募集の開始と数ヶ月に一度、聞き直す | 人事 |
| 会社ページを見る | 人事 |

「別の1人」がチェックすると、書いた本人には見えない失敗が見えます。運用代行や代理店が支えられるのは、セルフチェックの型、原因の切り分け、部分ごとの直し方の案までで、配属先に聞く実態と、面談で聞くことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの募集記事の見直しを支えるとき、8つの部分のチェック、来ない原因の切り分け、直し方の案は当社が出せます。ただし、「実態と合っているか」だけは、当社には判断できません。「最初の数ヶ月」「このチームの1日」「募集の本当の理由」が、記事のとおりかどうかは、配属先にしか分かりません。当社が見直しを支えるとき、最初に配属先に「この記事に書いてあることは、いまも本当ですか」と聞いてもらうのは、このためです。書き方の失敗は当社が見つけられますが、実態とのずれは企業にしか見つけられません。両方が揃って、募集記事は直ります。書き方だけ直して実態がずれたままだと、来た候補者が面談で離れます。

## まとめ

- 募集記事の失敗は、タイトル・「なにを」・「なぜ」・「どうやって」・「こんなことやります」・求める動き方と条件・カバー写真・運用の8つに分けると直しやすい
- 出す前に、タイトルと「こんなことやります」を最低限チェックし、別の1人に読んでもらう
- 話を聞きに来ないときは、一覧で開かれていないのか、本文で離れているのか、会社ページで離れているのかを切り分けてから直す
- 出して放置が最も多い運用の失敗。募集の開始と数ヶ月に一度、配属先に「いまも本当か」を聞き直す
- 書き方の失敗は外からも見つかるが、実態とのずれは配属先にしか見つけられない

## よくある質問

### 募集記事を直したのに、話を聞きに来る数が変わりません

原因が募集記事以外にある可能性があります。一覧で開かれていないならタイトルと写真、開いて離れているなら本文、募集記事は読まれているのに来ないなら会社ページを見ます。募集記事だけを直し続けても、会社ページが古いままだと変わりません。

### セルフチェックは、全部の項目を毎回やるべきですか

タイトルと「こんなことやります」の2つは毎回見ます。この2つで止まることが最も多いからです。他の項目は、募集記事を新しく作るときと、数ヶ月に一度の見直しのときに見れば足ります。別の1人に読んでもらうことは、新しく作るときに省かないことを勧めます。

### 募集記事の見直しは、御社に相談できますか

できます。当社は、8つの部分のチェック、来ない原因の切り分け、直し方の案を支えられます。実態と合っているかは、配属先に確認していただきます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
