地方に本社があり、母集団が作れない。ところが、勤務地を目立たないところに書き、都市部の学生に都市部の会社と同じ入口で送り、面談は来社が前提で、「地方だから来ない」と諦める。**結論から言うと、地方企業の母集団は、「来られるか」を学生が入口で自分で判断できる材料（勤務地・転居・移動・オンラインの面談）を先に渡し、地元志向と転居可能の二つに分けて入口を組みます。「地方だから」を言い訳にせず、地方にある理由を仕事の具体で書きます。反応が減ることを受け入れ、来た人の割合で見ます。** この記事では、地方企業の母集団で起きる失敗、学生が考える三つ、先に渡す材料、二つに分けた入口、面談と選考の組み方、地方にある理由、出身者との関係、割合で見ること、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、地方向けの文面は[地方の学生・地方の会社のスカウト文面](/media/kh-bunmen-chihou/)、媒体ごとは[地方に本社がある会社のOfferBox運用](/media/ob-chihou-honsha/)、[Wantedlyで地方の募集を書く](/media/wt-chihou-boshu/)、[ワンキャリアで地方の会社が掲載する](/media/oc-chihou-keisai/)で書きました。

## この作業の目的｜「来られるか」を、学生が入口で判断できる状態にする

地方企業の母集団が作れない原因の多くは、「地方だから」ではなく、「来られるかを判断する材料が、入口にない」ことです。材料がなければ、学生は判断を保留し、返信もエントリーもしません。材料があれば、来られる人は来て、来られない人は自分で外れます。

目的は、「来られるか」の判断を面談まで先送りさせず、入口で学生が自分で判断できる形にすることです。

## 地方企業の母集団で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 勤務地を、隠す・目立たないところに書く | 面談で初めて分かり、そこで離れる。時間が双方で無駄になる |
| 都市部の学生に、都市部の会社と同じ入口 | 「来られるか」の材料がなく、判断を保留される |
| 「地方だから来ない」と、諦める | 材料を渡していないだけなのに、地方のせいにして直さない |
| 地元志向と転居可能を、混ぜる | 地元志向の学生に転居の話、転居可能な学生に地元の話。どちらにも届かない |
| 面談を、来社前提にする | 移動の負担で、面談に進まない |
| 移動の負担を、学生任せにする | 交通費・宿泊・日程の扱いが不明で、選考に進まない |

共通するのは、「来られるか」を学生に判断させる材料を、入口の前に置いていないことです。

## 学生が、入口で考える三つ

1. **勤務地は、どこか**：本社か、支社か、転勤はあるか
2. **転居は、要るか**：自宅から通えるか、転居が前提か、転居の支えはあるか
3. **面談と選考に、行けるか**：オンラインか、来社か、来社なら移動の負担は

三つが入口で分からなければ、学生は判断を保留します。三つは[地方に本社がある会社のOfferBox運用](/media/ob-chihou-honsha/)の「都市部の学生が、最初に考える三つ」で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「地方だから、都市部の学生には届かない」というものです。当社は3媒体すべての販売パートナーとして、地方企業の母集団形成を見ていますが、届いていない会社の多くは、勤務地と転居と面談の形を入口に書いておらず、「来られるか」を学生に判断させていません。逆に、三つを入口で先に渡した会社は、返信やエントリーの数は減っても、来た人が「来られる」と判断した人で、面談進行率と承諾率が上がっています。地方は、母集団が作れない理由ではなく、「材料を先に渡す」ことが他より一段多く要る条件です。当社が地方企業の相談を受けるとき、最初にやるのは、文面と企業ページの中で、勤務地・転居・面談の形が「最初の画面」に書かれているかを確かめることです。

## 先に渡す、材料

| 材料 | 書き方 |
|---|---|
| 勤務地 | 最初の画面に。本社・支社・転勤の有無を事実で |
| 転居 | 転居が前提か、転居の支え（社宅・手当）の有無。中身は自社の制度と管理部門で確認し、事実を |
| 面談の形 | オンラインが基本か、来社は選考のどの段階か |
| 移動の負担 | 交通費・宿泊の扱い。自社の制度で確認し、「選考のどの段階から、何を」を事実で |
| 地方にある理由 | 仕事の具体で。「地方だから」ではなく、「この場所で、この仕事をしている理由」 |
| 生活 | 出身者・転居した社員の記事。住まい、通勤、休日 |

材料を渡すと、反応は減ります。減るのは、来られない人の反応です。渡し方は[地方の学生・地方の会社のスカウト文面](/media/kh-bunmen-chihou/)の「文面で渡す、材料」で書きました。

## 地元志向と、転居可能で、入口を分ける

| 相手 | 入口と伝えること |
|---|---|
| 地元志向（その地方の出身、または地方の大学） | 「地元で、この仕事ができる」。地元に残る理由と、仕事の具体。地方の大学との関係。[大学との関係からの母集団形成](/media/kh-boshudan-daigaku/) |
| 転居可能（都市部の学生で、勤務地を問わない） | 「この場所に来る理由」。仕事の具体、転居の支え、生活の記事。「来られるか」の材料を厚く |
| 出身者（都市部の大学に進んだ、地元出身の学生） | 「戻る」選択肢として。出身者の社員の記事 |

三つを一つの文面・一つの企業ページで混ぜません。読み分け方は[地方の学生・地方の会社のスカウト文面](/media/kh-bunmen-chihou/)の「地元志向か、転居可能かを、自由記述で読む」と[地方に本社がある会社のOfferBox運用](/media/ob-chihou-honsha/)の「出身者と、都市部出身者で、文面を分ける」で書きました。

## 面談と選考を、オンラインと移動の負担で組む

- **面談は、オンラインを基本に**：最初の接点で移動を求めない
- **来社は、選考のどの段階かを先に示す**：「最終面接のみ来社」など
- **来社の日に、まとめる**：複数の段階を一日に、職場の見学も同じ日に
- **交通費・宿泊の扱いを、来社の案内と一緒に**：自社の制度で確認し、事実を
- **来社の負担を、社員が都市部に出向く形で減らせるか**：都市部での回、出張面談
- **組み方は[地方に本社がある会社のOfferBox運用](/media/ob-chihou-honsha/)の「面談と選考を、移動の負担で組む」**

## 「地方だから」を、言い訳にしない

- **地方にある理由を、仕事の具体で書く**：「この場所で、この仕事をしている理由」「この場所だから、できること」
- **「地方だから応募が少ない」と社内で言わない**：材料を渡していないだけのことが多い
- **「地方でも」と書かない**：「文系でも」と同じで、不利の前提が伝わる
- **都市部の会社と、条件で比べない**：仕事の具体と、生活の事実で
- **考え方は[地方に本社がある会社のOfferBox運用](/media/ob-chihou-honsha/)の「『地方だから』を、言い訳にしない」**

## 反応が減ることを受け入れ、割合で見る

- **材料を渡すと、返信・エントリーは減る**：来られない人が自分で外れる
- **見るのは、来た人のうち「来られる」と判断した人の割合と、面談進行率**：[採用ファネルの作り方](/media/kh-boshudan-funnel/)
- **面談で「勤務地を知らなかった」人がいるなら、材料が入口に届いていない**
- **減った数を上司に先に伝える**：「エントリーが減った」で戻されないように。[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)
- **考え方は[地方の学生・地方の会社のスカウト文面](/media/kh-bunmen-chihou/)の「勤務地を書くと、反応が減ることを受け入れる」**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 勤務地・転居・面談の形・移動の負担を、自社の制度で確認し事実で決める | 人事責任者と管理部門 |
| 材料を文面と企業ページの最初の画面に置く | 人事 |
| 地元志向・転居可能・出身者で入口を分ける | 人事 |
| 地方にある理由を仕事の具体で書く | 現場と人事 |
| 出身者・転居した社員の記事を書く | 社員 |
| 面談をオンラインで組み、来社の日をまとめる | 人事と面接官 |
| 反応が減ることを上司に先に伝え、割合で報告する | 人事責任者 |

運用代行や代理店が支えられるのは、材料の整理、入口の分け方、文面と企業ページの型、面談の組み方の型、割合の見方の型までで、制度の確認と決定、材料を書くこと、面談、社員の記事は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは数字の読み方の話です。地方企業の相談で、「勤務地を最初に書いたら、返信が減った。書かないほうがよいのでは」と言われることがあります。当社が確かめるのは、「減ったのは何の数か」です。減ったのが返信やエントリーで、面談まで来た人の数と面談進行率が変わっていないか上がっているなら、減ったのは「来られない人」の分で、母集団は減っていません。減ったのが面談まで来た人の数なら、材料の書き方（転居の支えの有無、面談の形）が足りていないか、地方にある理由が仕事の具体で書けていません。返信の数で判断すると、勤務地を隠す方向に戻り、面談で離れる状態に戻ります。当社は、地方企業の数字を、入口の数ではなく、面談まで来た人と面談進行率で見ます。

## まとめ

- 地方企業の母集団が作れない原因の多くは「地方だから」ではなく、「来られるか」を判断する材料（勤務地・転居・面談の形・移動の負担）が入口にないこと
- 材料を最初の画面に事実で置く。制度の中身は自社の制度と管理部門で確認。反応は減り、減るのは来られない人の分
- 地元志向・転居可能・出身者で入口を分け、一つの文面・企業ページで混ぜない。地元志向は地方の大学との関係、転居可能は材料を厚く、出身者は「戻る」選択肢
- 面談はオンラインを基本に、来社は選考のどの段階かを先に示し、来社の日にまとめ、交通費・宿泊の扱いを案内と一緒に
- 「地方だから」「地方でも」を言わず、地方にある理由を仕事の具体で。見るのは入口の数ではなく、面談まで来た人と面談進行率

## よくある質問

### 転居の支え（社宅・手当）がなく、書くと不利になりそうです

書きます。書かなければ、面談で分かって離れ、双方の時間が無駄になります。支えがないなら、「転居の支えは現状ありません。住まいの探し方は、転居した社員が相談に乗ります」のように、ないことと、代わりにできることを事実で書きます。支えの有無は、学生が「来られるか」を判断する材料で、隠す材料ではありません。制度の中身は自社の制度と管理部門で確認してください。

### 都市部の学生と、地元の学生、どちらを先に狙うべきですか

「こんな人」がどちらに多いかで決めますが、先に回しやすいのは地元志向です。「来られるか」の材料が少なくて済み、地方の大学との関係やイベントが使えます。地元で回る形ができてから、転居可能な都市部の学生に、材料を厚くして届けます。同時に両方を薄く回すより、一つを回してから二つ目です。[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)の順番と同じです。

### 地方企業の母集団形成は、御社に相談できますか

できます。当社は、材料の整理、入口の分け方、文面と企業ページの型、面談の組み方の型、割合の見方の型を支えられます。制度の確認と決定、材料を書くこと、面談、社員の記事は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
