Wantedlyで事業開発の募集記事を出したとき、最初にぶつかるのは「『新規事業を推進』『ゼロイチを一緒に』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『何の事業ですか』『いまどの段階ですか』『うまくいかなかったら、いつ誰がやめると決めますか』を聞かれて答えられない」という問題です。**結論から言うと、事業開発の募集記事は、「新規事業を推進」ではなく「何の事業を、どの段階で、経営者とどんな距離で、何の数字で見て、やめる判断を誰がいつするか」を書き、募集記事を書く前に社内で事業と段階を一つに絞り、権限と数字とやめる基準を決めておきます。** この記事では、事業開発が募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)、スカウト文面の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)、権限の線引きの考え方は[プロダクトマネージャーを採る募集記事の書き方](/media/wt-pdm-boshu/)で書きました。

## 事業開発が募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 何の事業の、どの段階か | まだ何をやるか決まっていないのか、案があって検証する段階か、売り始めた段階か。「新規事業」の一語では分からない |
| 提携か、立ち上げか | 他社と組む仕事か、自社で作って売る仕事か。両方か |
| 経営者との距離と、権限 | 経営者が自分でやりたい事業を手伝うのか、任されるのか。何を決められるか |
| 何の数字で見るか | 売上か、顧客の数か、検証の結果か。決まっているか。決まっていないか |
| やめる判断を、誰がいつするか | うまくいかなかったとき、いつ、誰が、何をもとにやめると決めるか。決まっていないと「終わらない仕事」 |
| うまくいかなかったとき、自分はどうなるか | 事業が止まったら、別の事業に移るのか、会社を離れるのか |

「やめる判断を誰がいつするか」と「うまくいかなかったとき自分はどうなるか」が、事業開発に特有の点です。「ゼロイチ」「推進」の一語では、ここが分かりません。

## 書く前に決めること｜事業と段階を一つに、権限、数字、やめる基準

| 決めること | 選択肢 |
|---|---|
| 事業と段階 | 何の事業か。決まっていない／案がある／検証中／売り始めた。最初に任せる事業を一つ |
| 提携か立ち上げか | 他社と組む／自社で作る／両方。最初はどちらか |
| 権限 | 何を決められるか。価格、相手、やり方、予算の配分。経営者が最後に決めることは何か |
| 見る数字 | 売上／顧客の数／検証の結果。段階に合わせて一つ。決まっていないなら、決まっていないと |
| やめる基準 | 「〇〇の期間で△△に届かなければ、経営者と一緒に見直す」。決まっていないなら、決まっていないと書き、一緒に決めると |
| 予算と人 | 使える範囲。一緒に動く人。数値は確認したものだけ |
| 止まったときの扱い | 別の事業に移る／会社に残る道がある／決まっていない |
| 最初の月に任せること | 案の検証か、提携先への最初の連絡か、顧客への聞き取りか。誰と組むか |

「経営者がやりたい事業を手伝う」「やめる基準は決まっていない」「止まったときの扱いは決まっていない」でも構いません。隠さずに書けば、それを前提に読む人が来ます。

## 「なにを」｜何の事業を、どの段階で

「なにをやっているのか」は、会社の既存の事業の説明ではなく、この事業開発が最初に任される事業と、その段階に絞ります。

- **事業を、一つに絞る**：「〇〇の業種向けに、△△を提供する事業。既存の事業の顧客に、□□を足す形」
- **段階を書く**：「案はある。まだ誰にも売っていない。最初の月は、想定する顧客に話を聞くところから」「売り始めて〇〇の期間。顧客は数社。増やし方を決める段階」
- **経営者との距離を書く**：「経営者が言い出した事業。経営者は週に一度話す。決めるのは、価格と相手は任せ、予算は経営者」
- **やめる基準を書く**：「〇〇の期間で△△に届かなければ、経営者と一緒に続けるか見直す。基準はまだ粗く、一緒に決めたい」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

事業開発の募集記事を出す前に、先に決めておかないと効果が出ないのは、「やめる判断を、誰が、いつ、何をもとにするか」です。当社がWantedlyの事業開発の募集を支えるとき、「新規事業を立ち上げてほしい」と書かれているのに、経営者に聞くと「やめる基準は考えていない。うまくいくまでやる」という会社が多くあります。事業開発が面談で最初に聞くのは、事業の中身ではなく、「うまくいかなかったら、いつ、誰がやめると決めますか」です。ここに答えがないと、「終わりの無い仕事」か「経営者の気分でいつ止まるか分からない仕事」を想像して離れます。基準が粗くても構いません。「〇〇の期間で△△を見て、経営者と一緒に続けるか決める。止まったら、既存の事業の□□に移る道がある」と書けば、「やめ方が決まっている会社」として読まれます。当社が最初にお願いするのは、事業の説明ではなく、経営者本人に「この事業を、いつ、何を見て、やめると決めるか」を一文で言ってもらうことです。

## 「どうやって」｜進め方と、権限と、数字の書き方

| 書くこと | 書き方 |
|---|---|
| 進め方 | 週に何を決め、誰に報告するか。検証をどう回すか。「週に一度、経営者と〇〇を決める」 |
| 権限 | 「価格と相手は任せる。予算は〇〇の範囲で自分で。超える判断は経営者」 |
| 見る数字 | 段階に合わせて。「いまは顧客の聞き取りの数と、その中で〇〇と言った人の数」。売上はまだ見ないなら、そう書く |
| やめる基準と、決め方 | 「〇〇の期間で△△を見て、経営者と決める」。決まっていないなら、決まっていないと |
| 前に立ち上げた例と、止めた例 | 「前に〇〇を始めて、△△で止めた。理由は□□」。止めた例を隠さない |

「裁量が大きい」と書くより、「価格と相手は任せ、予算は〇〇まで自分で、超える判断は経営者と月に一度」と書くほうが、権限の範囲が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| 新規事業の経験 | 想定していた顧客に話を聞いて、想定が違うと分かり、案を変えたことがある |
| 事業開発経験3年以上 | 始めた事業を、数字を見て自分から「やめる」と言ったことがある |
| ゼロイチ経験者 | 何も決まっていない状態で、最初の一歩を自分で決めて動いたことがある |
| 起業家精神 | 経営者と意見が分かれ、根拠を持って伝え、最後は決まったことに従ったことがある |
| 即戦力 | 最初の月は〇〇の顧客への聞き取りを任せる予定です。△△と組みます |

「数字を見て、自分からやめると言った」が、事業開発で最も読まれる行動です。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「何の事業を、どの段階で、やめる判断を誰がいつするか」と同じ言葉で**：相手が「何を始めて、何を見て、何をやめたか」を読み、自社の事業と段階と重ねる。[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)
- **面談には、経営者が出る**：事業開発の面談は、経営者が出ないと「経営者との距離」と「やめる判断」が伝わらない
- **面談で話すのは、事業の段階と、やめ方の話**：いま何が決まっていて、何が決まっていないか。うまくいかなかったらどうするか。相手ならどう検証するかを聞く
- **前に止めた事業の話をする**：「前に〇〇を始めて、△△で止めた」。始めた話だけにしない

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 事業と段階、権限、数字、やめる基準、止まったときの扱いを決める | 経営者 |
| 「なにを」（事業、段階、経営者との距離）の下書き | 人事が、経営者に聞いて書く |
| 「どうやって」（進め方、権限、数字、やめ方） | 経営者が話し、人事が書き、本人が確認 |
| 予算と人、前に止めた例の確認 | 経営者 |
| 「こんな人」を行動で書く、最初の月の予定 | 経営者と人事 |
| 面談 | 経営者 |

一人目の事業開発を採る募集では、いま経営者が自分で事業の案を温めていることが多くあります。その場合は、「経営者が言い出した事業で、案の段階。まだ誰にも売っていない。最初の月は想定する顧客への聞き取りから。やめる基準は一緒に決める」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、段階と権限とやめ方を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、事業と段階の決定、やめる基準、面談は経営者が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「事業開発には、事業の可能性の大きさを見せないと来ない」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの事業開発の募集と面談を見ていますが、「市場規模が大きい」「無限の可能性」と書いた募集記事より、「案はあるが、まだ誰にも売っていない。〇〇の期間で△△を見て、経営者と続けるか決める。止まったら□□に移る道がある」と段階とやめ方を書いた募集記事のほうが、話を聞きに来る人の経験が合う傾向があります。事業開発は、「可能性」を読むと「根拠の無い期待を背負わされる仕事」を疑い、やめ方が書かれていないと「終わらない仕事」を想像します。段階とやめ方と止まったときの扱いが書かれていれば、「区切りのある仕事」として読まれます。当社が案内するのは、可能性の大きさを盛らず、段階を正直に書き、やめる基準と止まったときの扱いを書くことです。可能性で人は来ません。やめ方が決まっていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「新規事業を推進」「ゼロイチ」で書く | 何の事業か、どの段階かが分からず、読まれない | 事業を一つ、段階を一文で |
| 可能性の大きさを盛る | 「根拠の無い期待」と疑われる | 段階を正直に。売っていないなら、売っていないと |
| やめる基準を書かない | 「終わらない仕事」を想像される | 期間と数字と決める人を書く。粗くても |
| 経営者との距離を書かない | 「経営者の案を形にするだけ」を想像される | 何を任せて、何を経営者が決めるかを書く |
| 止まったときの扱いを書かない | 「止まったら会社を離れる」を想像される | 移る道の有無を書く。無いなら無いと |
| 面談に経営者が出ない | 「やめる判断」に答えられない | 経営者が出て、本人の言葉で話す |

最も多いのは、最初の「新規事業を推進」と、やめる基準の抜けです。

## まとめ

- 事業開発が見ているのは、何の事業のどの段階か・提携か立ち上げか・経営者との距離と権限・何の数字で見るか・やめる判断を誰がいつするか・止まったとき自分はどうなるか
- 書く前に、事業と段階を一つに絞り、権限、見る数字、やめる基準（期間と数字と決める人）、止まったときの扱いを、経営者本人が決める。粗くても、隠さない
- 「なにを」は事業と段階と経営者との距離とやめる基準。「どうやって」は進め方と権限と数字を、段階に合わせて。前に止めた例を隠さない
- 「こんな人」は経歴ではなく、「想定が違うと分かって案を変えた」「数字を見て自分からやめると言った」の行動で
- 面談には経営者が出て、段階とやめ方を本人の言葉で話し、前に止めた事業の話をする

## よくある質問

### まだ何の事業をやるかも決まっていません。それでも募集できますか

できますが、「何も決まっていない」と書きます。「事業の中身は決まっていない。〇〇の業種の顧客に、いまの事業の隣で何を足せるかを探すところから。最初の月は既存の顧客への聞き取り。〇〇の期間で案を三つに絞り、経営者と一つ選ぶ」のように、決まっていないことと、最初の一歩と、区切りを書きます。

### やめる基準を決めると、来た人が最初から「やめる前提」で動きませんか

逆です。やめる基準が無いと、「終わらない仕事」か「経営者の気分で止まる仕事」を想像して、事業開発の経験がある人ほど離れます。「〇〇の期間で△△を見て、続けるか、変えるか、やめるかを一緒に決める。止まったら□□に移る道がある」と書くと、「区切りがある会社」として読まれます。

### 事業開発の募集記事は、御社に相談できますか

できます。当社は、募集記事の型、段階と権限とやめ方を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。事業と段階の決定、やめる基準、面談は、経営者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
