OfferBoxで新卒を採っていて、ワンキャリアにも掲載している。ところが、二つは別の担当が別の目的で回していて、オファーを受け取った学生がワンキャリアで自社のクチコミを読んでから承認するかを決めている、という流れが見えていない。承認率が下がったときに文面を直しても変わらず、原因がクチコミの側にある、ということも起きます。**結論から言うと、OfferBoxは「企業が選んで送り、承認をもらう入口」、ワンキャリアは「学生が選考情報とクチコミとイベントで、会社を確かめる場」です。オファーを受け取った学生は、承認の前にクチコミと選考体験を見ます。OfferBoxの側から見た組み合わせは、送る前に自社のクチコミを読み、書かれている選考の実態を文面で認め、承認率が下がったときにクチコミを疑い、イベントで会った学生に送らない台帳を持ち、企業ページと文面の会社紹介を揃えることです。** この記事では、それぞれの役割、学生が確かめること、送る前にクチコミを読む、文面で実態を認める、承認率とクチコミ、台帳、企業ページと文面、時期、やりがちな失敗、社内の分担を整理します。二つの違いそのものは[OfferBoxとワンキャリアの違い](/media/hikaku-offerbox-onecareer/)、Wantedlyの側から見たワンキャリアとの併用は[Wantedlyとワンキャリアの併用](/media/wt-heiyou-onecareer/)で書きました。数値は書きません。

## それぞれの役割｜「送って承認をもらう」と「学生が確かめる」

| | OfferBox | ワンキャリア |
|---|---|---|
| 誰が動くか | 企業。学生を検索して選び、文面を送る | 学生。選考情報、クチコミ、イベントで会社を見る |
| 学生の状態 | 送られた側。文面と送ってきた人で興味を持つ。会社の実態は知らない | 確かめる側。他の学生が書いた選考の体験とクチコミで、会社の実態を見る |
| 会社が出すもの | 検索条件、文面、送る社員の名義 | 企業ページ、選考情報、イベント |
| 会社が変えられるもの | 検索条件、文面、送る相手 | 企業ページと選考情報。クチコミは変えられない |
| 決まること | 承認するか。文面と送ってきた人と、確かめた実態で決まる | 「文面と実態がずれていないか」 |
| 時期 | 送る時期に集中 | 就職活動の時期に集中。イベントの日程がある |

オファーを受け取った学生は、承認する前に、会社名で検索します。採用サイトと一緒に、ワンキャリアのクチコミと選考体験が出てきます。そこで見るのは、「文面に書いてあることは本当か」「選考はどう進むのか」「先輩はどう言っているか」です。文面が良くても、クチコミに書かれた実態とずれていると、学生はクチコミの側を信じます。当社が扱う二つの媒体は、「送る側」と「確かめる側」で、学生の中ではつながっています。

## 送る前に、自社のクチコミを読む

- **送る時期の前に、自社のクチコミと選考体験を、人事と送る社員で読む**：学生が承認の前に見るものを、先に見ておく
- **書かれている選考の実態を、文面で否定しない**：クチコミに「選考が長い」とあるなら、文面で「スピード選考」と書かない。実態を直すか、実態のとおりに書く
- **クチコミで聞かれていることを、文面の一文にする**：学生が知りたいことは、クチコミの質問に出ている。「〇〇についてよく聞かれますが、実際は△△です」
- **クチコミの評判と文面のトーンをずらさない**：クチコミで「静かな会社」と書かれているのに、文面が「熱い会社」だと、学生は迷う
- **クチコミへの向き合い方**：[ワンキャリアのクチコミの基本](/media/oc-kuchikomi-kihon/)

### エージェントベストの見解

これをやる前に、先に自社のクチコミと選考体験を読んでおかないと、文面を直しても承認は変わりません。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、承認率が下がったときに文面と送る相手を見直しますが、両方を直しても変わらない会社の多くは、クチコミの側に原因があります。学生は、文面を読んで興味を持ち、会社名で検索して、クチコミで「実態」を見て、承認するかを決めます。文面が実態より良く書かれていると、クチコミとの差で承認せず、文面が実態のとおりでも、クチコミに書かれた選考の長さや面接の印象が承認をためらわせます。当社が送る時期の前に企業と一緒にするのは、文面を作ることより先に、自社のクチコミを一緒に読むことです。読んで、書かれている実態を文面で認める一文を入れると、学生は「知っている会社だ」と読み、クチコミとの差で離れなくなります。

## 承認率が下がったときに、クチコミを疑う順番

1. **送る相手のずれ**：検索条件と「こんな人」が合っているか。[OfferBoxの承認率が低いときに疑う3つの原因](/media/ob-shounin-hikui/)
2. **文面のずれ**：「なぜあなたに」が書けているか、最初の年が書けているか
3. **確かめる先のずれ**：採用サイトの募集要項が古くないか。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)
4. **クチコミとのずれ**：クチコミに書かれた実態と文面が違っていないか。選考体験に「長い」「連絡が遅い」と書かれていないか
5. **実態の側**：クチコミに書かれた実態が、直すべきものなら直す。選考の長さは[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/)

一から三を直しても変わらないなら、四と五です。クチコミは会社が変えられませんが、書かれた実態は変えられます。変えたことを、文面と選考情報で伝えます。

## イベントで会った学生に、OfferBoxで送らない台帳

- **ワンキャリアのイベントで会った学生の名前を、送る側の台帳に入れる**：送る前に突き合わせる
- **会った学生がOfferBoxに登録していても、「初めまして」の文面を送らない**：「イベントで会ったのに」で印象が下がる。イベントの流れで、会った社員の名前で連絡する
- **イベントに出る社員を、文面の名義にする**：イベントで会っていない学生にも、「この人が話す会社」として文面が届く
- **台帳は一つ。入口の列に「ワンキャリア（イベント名・話した社員）」と「OfferBox」**：面談から先は共通の段。[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)
- **面談で「何を見て来たか」を聞く**：文面か、クチコミか、イベントか

## 企業ページと、文面の会社紹介を揃える

- **ワンキャリアの企業ページの「なにを」と、文面の会社紹介の事実を揃える**：文章は違ってよい。事実がずれない。[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)
- **選考情報の「選考の流れ」と、文面の「承認のあと、まず面談」をずらさない**：承認した学生が選考情報を見て「文面と違う」とならない
- **文面の会社紹介は短く**：会社の中身は企業ページと採用サイトに。[スカウトでの会社紹介の書き方](/media/kh-bunmen-kigyo-shoukai/)
- **選考情報を変えたら、文面のテンプレートも同じ日に直す**
- **企業ページと文面を、最後に同じ人が見る**：担当が別でも、見る人は一人

## 時期と、承認率の読み方

- **イベントの日と、送る時期を重ねない**：イベントの準備と当日で人事の時間が消え、承認への当日返信が遅れる。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
- **イベントのあとに、送る時期をもう一つ置く**：イベントで会社名を知った学生が、文面を受け取ると承認しやすい。ただし会った学生には送らない
- **選考の時期に、クチコミの確認を月に一度**：今年の選考体験が書かれ始める。書かれたことを、翌年の文面と選考の設計に
- **承認率とイベントの動員数を並べない**：前提が違う。見るのは、面談まで来た「近い」学生の数を入口ごとに。[OfferBoxを含む複数媒体の効果を並べて見る方法](/media/ob-heiyou-heiyou-kpi/)
- **費用は、各媒体の現在の条件を公式ページで確認する**：配分は[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| クチコミを読まずに送る | 文面と実態の差で承認されない | 送る前に読み、実態を文面で認める |
| 承認率が下がって文面だけ直す | 原因がクチコミの側で、変わらない | 五つの順番で疑う |
| イベントで会った学生に「初めまして」を送る | 「会ったのに」で印象が下がる | 突き合わせ、イベントの流れで連絡 |
| 企業ページと文面の事実がずれる | 承認した学生が「どちらが本当か」で離れる | 同じ人が最後に見る |
| イベントの日と送る時期を重ねる | 当日返信が遅れる | 前後にずらす |

最も多いのは、一つ目です。文面を作ることに時間を使い、学生が承認の前に見るクチコミを、送る側が読んでいません。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 送る時期の前に、自社のクチコミと選考体験を読む | 人事と送る社員 |
| 書かれている実態を、文面で認める一文にする | 人事と送る社員 |
| 検索・文面下書き・送信・一次返信 | 人事、または代行 |
| イベントで会った学生を台帳に入れ、突き合わせる | 人事（代行と） |
| 企業ページと文面の事実を揃えて見る | 人事（一人） |
| 実態を直すかの判断（選考の長さ、連絡の速さ） | 人事と責任者 |
| 面談で「何を見て来たか」を聞く | 面談に出る人 |
| イベントに出る、名義を貸す | 現場の社員 |

運用代行や代理店が支えられるのは、役割の整理、クチコミの読み方の型、文面で実態を認める一文の型、台帳と突き合わせの型、企業ページの整備、OfferBoxの検索・文面下書き・送信・一次返信までで、実態を直す判断、イベントに出ること、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。当社は両方の販売パートナーなので、窓口を一つにできます。

### エージェントベストの見解

これは切り分けの話です。二つを併用するとき、会社が変えられるのは、検索条件、文面、送る相手、企業ページ、選考情報、そして選考の実態までで、クチコミそのものは変えられません。当社はOfferBoxの運用代行を受けているので、承認率が下がった会社から「クチコミを何とかできないか」と聞かれますが、当社が動かせるのは、文面と送る相手と、承認への返信の速さまでです。クチコミに書かれた「選考が長い」「連絡が遅い」は、当社が返信を当日に行い、企業が選考の段階を減らすことで、翌年の選考体験が変わります。書かれたことを消すのではなく、書かれたことが翌年に書かれなくなるよう実態を変え、変えたことを文面と選考情報で伝える。この線で、当社が持つ部分（文面・送る相手・返信の速さ）と、企業が持つ部分（選考の実態・企業ページ）を分けています。

## まとめ

- OfferBoxは「選んで送り、承認をもらう入口」、ワンキャリアは「学生が選考情報とクチコミとイベントで会社を確かめる場」。学生は承認の前にクチコミを見る
- 送る前に自社のクチコミと選考体験を読み、書かれている実態を文面で認める一文を入れる。実態より良く書かない
- 承認率が下がったら、送る相手→文面→採用サイト→クチコミとのずれ→実態、の順で疑う。クチコミは変えられないが、書かれた実態は変えられる
- イベントで会った学生を台帳に入れ、「初めまして」を送らない。イベントに出る社員を文面の名義に
- 企業ページの事実と選考情報を、文面と揃えて同じ人が見る。イベントの日と送る時期を重ねない

## よくある質問

### クチコミに事実と違うことが書かれています。文面で訂正すべきですか

文面で訂正すると、学生は「反論している会社」と読みます。文面では、実態を具体で書くだけにします。「〇〇の点はよく聞かれますが、今年は△△です」と、事実を置く形なら、学生は自分で比べます。クチコミへの対応の考え方は[ワンキャリアのクチコミの基本](/media/oc-kuchikomi-kihon/)で書きました。

### ワンキャリアの担当とOfferBoxの担当が別です。どう連携しますか

送る時期の前に、両方の担当で自社のクチコミを一緒に読む時間を一度取ります。企業ページと文面の事実を、どちらかの担当が最後に見る形にします。イベントの名簿は、送る側の台帳を持つ担当に、イベントの翌日に渡します。この三つで、担当が別でも学生の側では一つの会社に見えます。

### OfferBoxとワンキャリアの併用は、御社に相談できますか

できます。当社は、役割の整理、クチコミの読み方の型、文面で実態を認める一文の型、台帳と突き合わせの型、企業ページの整備、OfferBoxの検索・文面下書き・送信・一次返信を支えられます。実態を直す判断、イベントに出ること、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、両方の運用を一つの窓口で支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
