農業法人、農業関連の会社（資材、流通、加工、農機）、JAなどが、新卒を採る。新卒採用の経験は少なく、社長か現場の責任者が採用を見ている。「農業に興味のある学生は増えている」と聞いて媒体を探すが、興味のある学生が来ても、季節の繁閑、体力、住まい、収入の実態を知って離れる。就農（自分で農業をする）を考えている学生と、農業法人に就職する学生の違いも、会社の側で整理されていない。**結論から言うと、学生の「農業に興味がある」と、季節・体力・住まい・収入の実態には差があります。媒体の前に、就農と就職の違いを分け、暮らしと季節の実態を一枚にします。媒体は、地元やUターンの層に絞って送る型か、暮らしと仕事の場面を記事で読んでもらう型を先に検討し、学生が並べて比べる場は先にすることが少ないです。** この記事では、農業業界の採用構造、判断軸の当て方、学生が確かめること、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。地方の会社の層の分け方は[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)、3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## 農業業界の採用構造と、媒体との相性

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 新卒採用の経験が少なく、社長か現場が採用 | 型がなく、承認や応募のあとに何をするかが決まっていない | 作業を外に出せる型か、書く時間を取れる型か |
| 季節の繁閑、体力、住まい、収入の実態がある | 「興味」で来た学生が実態を知って離れる | 実態を隠さず書ける媒体の使い方 |
| 就農と就職の違いがある | 就農希望の学生を採って、数年で独立される。または就職希望の学生に就農の話をして離れる | 「こんな人」で就農か就職かを分ける |
| 地方で、住まいと車が要る | 都市部の学生が「来られるか」を判断できない | 暮らしの実態を先に渡す |
| 学生の関心（食、環境、地方）と、日々の仕事に差がある | 関心で来て、作業で離れる | 一日の場面を書く |
| 知名度は地域と分野の中に限られる | 学生は法人名で探さない | 送る型か記事を置く型で、まず知ってもらう |

農業の採用は、「農業に興味のある学生に会えるか」より、「会えた学生に、季節と暮らしと収入の実態を隠さず伝え、それでも来る学生を残せるか」で決まります。

## 判断軸を、農業に当てる

| 軸 | 農業での見方 |
|---|---|
| 対象（誰に届くか） | 「農業に興味」の記述は多いが、就農希望と就職希望が混ざる。地元・Uターンの層と、都市部から来る層で分ける。農学系の専攻で絞れるかは各媒体の仕様で確認 |
| 型（送るか、来るか、比べられるか） | 送る型は、地元・Uターンと専攻と記述の行動で絞れる。来る型は、暮らしと仕事の場面を書けるかで届く。比べられる型は、学生の候補に入っている法人は少ない |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。予算が取れない年は、媒体を使わない判断も。[予算がほぼ取れない会社の採用媒体](/media/hikaku-yosan-nai/) |
| 運用工数（誰の時間が要るか） | 社長か現場の時間が上限。繁忙期には採用が止まる。送る型は作業を外に出せる。来る型は、場面を話す時間が要る |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。農業では、「対象」の軸で就農と就職を分けることと、「運用工数」の軸で繁忙期を見込むことが、他の業界と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「農業に興味のある学生が増えているので、送れば来る」というものです。当社は3媒体すべての販売パートナーとして、農業法人や関連の会社の相談を受けますが、「農業に興味」の記述は確かに多く、承認や応募も付きますが、面談で「冬は何をしますか」「住まいはどうなりますか」「収入はどのくらいで安定しますか」と聞かれ、答えが曖昧で離れる、という形が多くあります。学生の「興味」は、食や環境や地方への関心で、日々の作業と季節の繁閑と暮らしの実態とは別のものです。当社が農業の会社に媒体の前に用意してもらうのは、季節ごとの仕事、住まいと車、収入の仕組み、就農と就職の違い（数年後に独立を認めるか、残ってほしいか）を、隠さず書いた一枚です。一枚があれば、どの媒体でも、興味で来た学生が実態を知ったうえで「それでも来る」と決められます。

## 学生が、確かめること

- **季節ごとの仕事**：繁忙期と閑散期に何をするか。「冬は何を」に答えられるか
- **体力と作業の実態**：一日の作業、天候、休み
- **住まいと車**：法人が用意するか、自分で探すか。車が要るか。地方の暮らし。[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)
- **収入の仕組み**：雇用の形、給与の範囲、季節で変わるか。数値は各法人の実態で。この記事では書かない
- **就農と就職の違い**：法人に残る道と、独立する道。法人はどちらを望むか
- **社長や現場の人はどんな人か**：少人数の法人は、相性がすべて
- **辞めた人がいるか、なぜか**：季節の実態で辞めた人がいるなら、隠さない

## この条件なら、どれを先に検討するか

| 法人・会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 地元・Uターンの学生や、農学系の専攻に絞って会いたい | 企業から送る型（OfferBox） | 出身地域と専攻と記述の行動で絞れる（絞れるかは仕様で確認）。作業を外に出せ、社長は面談だけ |
| 社長か現場が、暮らしと仕事の場面を自分の言葉で書ける・話せる | 通年で記事を置く型（Wantedly） | 季節と暮らしの実態を場面で読んで、知ったうえで来る学生に届く。記事が残る |
| 分野で知られていて、学生の候補に入っている（大手の関連会社など） | 学生が並べて比べる場（ワンキャリア） | 比べる対象に入っている法人は少ない。先にすることは少ない |
| インターンや農作業の体験の受け入れが先にある | 関わりから採用へ | 体験で季節と作業を見た人の中から。媒体は関わりの入口として |
| 暮らしと季節の一枚が、まだない | どれも先ではない | 一枚を作ってから |

どれか一つが正解ではなく、絞れるか、書けるか、候補に入っているかで、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせるなら**：文面で「地元で、この作物を、この人と」を、記事で「季節と暮らしの一日」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **地元・Uターンの層を先に、都市部の学生は「来られる材料」が揃ってから**：[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)
- **農作業の体験やインターンと組み合わせる**：体験で季節と作業を見てもらってから。体験の扱い（報酬、保険）は自社の方針と制度の確認のうえで。[OfferBoxとインターンシップをつなげる設計](/media/ob-intern-setsuzoku/)
- **農業系の学校（農業高校、農学部、農業大学校）との関係と組み合わせる**：学校経由の採用がある。学校で会った学生に媒体で送らない。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)
- **時期は、繁忙期の外に**：送る、会う、体験の時期を、繁忙期の外に置く

## 見せ方｜実態を隠さない

- **季節ごとの仕事を、一年の表で**：「春は〇〇、夏は△△、秋は□□、冬は◇◇」。「冬は何を」に先に答える
- **住まいと車と暮らしを、最初に、良い面も不便な面も**：「住まいは法人が用意します」「最寄りの駅から遠く、車が要ります」
- **収入の仕組みを、隠さず**：雇用の形、給与の範囲、季節で変わるか。給与で勝負しない法人は、暮らしと仕事で。[給与水準を強みにできない会社のOfferBoxの伝え方](/media/ob-kyuuyo-hikui/)
- **就農と就職の違いを、法人の望む形で**：「数年後に独立を認める」「残ってほしい」のどちらか。隠すと「話が違う」に
- **「食を支える」「自然の中で」の一語で済ませない**：関心の言葉ではなく、一日の作業の場面で
- **業界イメージ（きつい、稼げない、古い）を否定せず、実態と変えたことで**：[業界イメージが不利な会社のOfferBox文面](/media/ob-gyokai-image/)
- **辞めた人がいるなら、理由と変えたことを**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 暮らしと季節と収入と就農・就職の一枚 | 社長（専門家の助言を受けて条件を整える） |
| 絞れるか・書けるか・候補に入っているかで、先に検討する型を決める | 社長（整理は代行が支える） |
| 「こんな人」の一行（地元・Uターン、専攻、就農か就職か） | 社長と現場 |
| 送る型なら、検索・下書き・送信・一次返信 | 代行 |
| 記事を置く型なら、社長と現場が場面を話し、整えるのは外に | 社長・現場と代行 |
| 面談と、農作業の体験の受け入れ | 社長と現場 |
| 学校との関係 | 社長 |
| 内定後の連絡、住まいの準備 | 社長 |

- **社長の時間は、一枚と面談と体験に**：作業は外に。繁忙期は採用を止める前提で、時期を外に。[運用代行に出す前提の媒体の選び方](/media/hikaku-daikou-zentei/)
- **人事がいない法人の窓口の決め方**：[専任の人事がいない会社のOfferBox運用](/media/ob-jinji-fuzai-unyou/)

運用代行や代理店が支えられるのは、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分までで、一枚の中身、実態の開示、就農と就職の方針、面談と体験、学校との関係は法人が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「就農を認めるか、残ってほしいか」を法人として決めておかないと、送っても、来ても、数年で崩れます。当社は3媒体すべての販売パートナーとして、農業法人の相談を受けますが、「農業に興味のある学生」の中には、いずれ自分で農業をしたい学生が多く含まれていて、法人がそれを想定せずに採ると、数年後に「独立します」で辞め、法人は「育てたのに」となり、学生は「独立を止められた」となります。逆に、就農希望の学生を「いずれ独立してよい」と最初から伝えて採る法人は、数年の間、本気で働いてもらえ、独立後も取引先や仲間になります。順番は、就農を認めるか残ってほしいかを一行にし、文面と記事と面談で同じ言葉で伝え、「こんな人」を就農希望か就職希望かで分けることです。どちらの方針でもよく、決めていないことが崩れる原因です。

## まとめ

- 学生の「農業に興味がある」と、季節・体力・住まい・収入の実態には差がある。興味で来て、実態で離れる
- 媒体の前に、季節ごとの仕事・住まいと車・収入の仕組み・就農と就職の違いを隠さず書いた一枚を作る。「冬は何を」に先に答える
- 地元・Uターンの層や農学系の専攻に絞って会いたいなら送る型を、社長や現場が暮らしと仕事の場面を書けるなら記事を置く型を先に。並べて比べる場は候補に入っている法人が少なく、先にすることは少ない
- 就農を認めるか残ってほしいかを法人として決め、「こんな人」を就農希望か就職希望かで分ける。決めていないことが崩れる原因
- 農作業の体験やインターン、農業系の学校、地元・Uターンの層と組み合わせ、時期は繁忙期の外に。社長の時間は一枚と面談と体験に、作業は外に

## よくある質問

### 都市部の学生にも来てほしいです。どうすればよいですか

先に、地元・Uターンの層で承認と面談の型を作り、面談で聞かれた「住まい」「車」「冬は何を」の答えを材料にしてから、都市部の学生に「来られる材料」を揃えて少なく送ります。都市部の学生への承認率は低い前提で、面談に出られる数だけ。順番は[地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)で書きました。

### 就農希望の学生を採ると、数年で辞められそうで不安です

「数年で独立してよい」と最初から伝えて採るか、「残ってほしい」と伝えて就職希望の学生に絞るか、法人として決めます。前者なら、数年の間に本気で働いてもらえ、独立後も取引先や仲間になることが多く、後者なら、就農希望の学生には送りません。決めずに採ると、どちらの学生とも「話が違う」になります。

### 農業の媒体選びは、御社に相談できますか

できます。当社は、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分を支えられます。一枚の中身、実態の開示、就農と就職の方針、面談と体験、学校との関係は、法人が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
