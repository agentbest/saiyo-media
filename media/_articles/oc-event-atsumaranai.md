ワンキャリアにイベントを掲載した。説明会、座談会、オンラインの短い会。ところが、学生が集まらない。申込がゼロか、数人。「ワンキャリアの学生はイベントに来ないのか」と考える前に、集まらない原因を分けます。**結論から言うと、集まらない原因は五つです。イベントの一覧で見つからない、タイトルが「会社説明会」で誰が何をする回か分からない、体験談で気になったことを確かめられる回に見えない、選考との関係が書かれておらず参加すると何が起きるか不明、申込後の連絡が見えない。この順に直します。人数を追って煽らず、小さい回を途切れさせずに続け、スカウトでこの回に誘い、来た学生が体験談に「聞きたいことが聞けた」と書く回にします。** この記事では、五つの原因とサインと直し方、煽ると起きること、続けること、スカウト、体験談に書かれる回、分担を整理します。イベントページの基本は[ワンキャリアのイベントページの作り方](/media/oc-event-page-kihon/)、説明会の掲載は[ワンキャリアで説明会を掲載するときの書き方](/media/oc-setsumeikai-keisai/)で書きました。この記事は、「集まらない」という症状から逆に辿るものです。

## この作業の目的｜「体験談で気になったことを確かめに来る場」として見える回にする

ワンキャリアの学生がイベントに来る理由は、会社の説明を聞くためではなく、体験談で読んで気になったことを、会社の人に直接確かめるためです。「確かめられそう」と見えなければ、来ません。

目的は、人数を集めることではなく、「この回に来れば、体験談で気になったことが確かめられる」と学生に分かる回にすることです。

## 集まらない、五つの原因

| 原因 | サイン | 直し方 |
|---|---|---|
| 1. 一覧で見つからない | 掲載の項目（日程・形式・対象）が埋まっていない。時期が学生の動きとずれている | 項目を全部埋める。時期を年度の公表内容で確認 |
| 2. タイトルが「会社説明会」 | 一覧で他社と区別がつかない。誰が出て何を話すかが見えない | 「〇〇職の若手と、最初の一年の話をする会」に |
| 3. 確かめられる回に見えない | 本文が会社紹介で、体験談で気になったこと（面接で何を見るか、配属、働き方）に触れていない | 体験談を読み、気になることが聞ける回だと本文で示す |
| 4. 選考との関係が不明 | 参加すると選考に進むのか、参加しないと不利か、が書かれていない | 選考との関係を、事実で一文 |
| 5. 申込後が見えない | 申込したら何が来るか、当日どう参加するかが書かれていない | 「申込後、〇日以内に△△から案内を送ります」を置く |

「1→5」の順に疑います。「1」と「2」は一覧で見える部分、「3」から「5」は開いたあとの部分です。

## 1. 一覧で、見つからないとき

- **掲載の項目を、全部埋める**：日程、形式（対面・オンライン）、対象の学年、職種。空欄は一覧で出ないことがある。現在の仕様は管理画面とヘルプで確認
- **時期が、学生の動きと合っているか**：年度の公表内容と自社の方針で確認して、時期を決める。[ワンキャリアの掲載の時期](/media/oc-keisai-timing/)
- **企業ページからイベントへ、イベントから企業ページへ、つないでいるか**：[ワンキャリアのイベントページと企業トップ](/media/oc-event-page-kigyo-top/)
- **表示の仕組みを推測して直さない**：[ワンキャリアの掲載が見られないときの原因](/media/oc-pv-nai/)

## 2. タイトルが「会社説明会」のとき

- **「誰が・何を」を、タイトルに出す**：「会社説明会」→「〇〇職の入社二年目と、最初の一年に何をするかを話す会」
- **体験談で気になることに、タイトルで触れる**：「面接で何を見ているかを、面接官が話す会」
- **人数や特典をタイトルに入れない**：「限定〇名」「参加特典」は、体験談を読む学生には効かない
- **付け方は[ワンキャリアのイベントページのタイトル](/media/oc-event-page-title/)**

### エージェントベストの見解

相談で最も多い思い込みは、「イベントに集まらないなら、参加特典を付けるか、選考の優遇を書けば集まる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、特典や優遇で集めた回は、集まった学生が「特典目当て」で、体験談に「特典の話ばかりだった」と書かれ、翌年の学生に敬遠されています。ワンキャリアの学生がイベントに来る理由は、体験談で気になったことを確かめるためで、特典ではありません。当社が「集まらない」の相談を受けるとき、最初にやるのは、特典の提案ではなく、自社の体験談を読んで、「学生が気になっているのに、企業ページでは分からないこと」を探すことです。それを「この回で、〇〇が直接話します」とタイトルと本文に置けば、集まります。

## 3. 確かめられる回に、見えないとき

- **自社の体験談とクチコミを読み、学生が気になっていることを拾う**：「面接で何を見られるか分からなかった」「配属がどう決まるか聞けなかった」「残業の実態が分からない」
- **その気になることが、この回で聞けることを本文に書く**：「面接官が、何を見ているかを話します」「配属の決め方を、人事が説明します」
- **会社紹介を、本文の中心にしない**：会社紹介は企業ページに。イベントは「確かめる場」
- **出る人を、名前と役割で**：「入社二年目の〇〇（営業）と、面接官の△△」
- **書き方は[ワンキャリアのイベントページの作り方](/media/oc-event-page-kihon/)の「書く要素」**

## 4. 選考との関係が、不明なとき

- **参加すると選考に進むのか、進まないのか、を事実で一文**：「この回は選考ではありません。参加の有無は選考に影響しません」または「この回のあと、希望者は一次面接に進めます」
- **「参加必須」「参加者は優遇」を、実態と違う形で書かない**：体験談に書かれる
- **年度の公表内容と自社の方針を確認して、書ける範囲で**
- **書き方は[ワンキャリアのイベントページの作り方](/media/oc-event-page-kihon/)の「選考との関係の書き方」**

## 5. 申込後が、見えないとき

- **「申込後、〇日以内に△△から参加の案内を送ります」を、本文の末尾に**
- **当日の参加の仕方（接続先、場所）が、いつ届くかを書く**
- **申込から当日までの連絡を、実際に送る**：書いたことを守る
- **導線の考え方は[ワンキャリアの掲載からエントリーまでの導線設計](/media/oc-entry-douse/)**

## 人数を追って煽ると、起きること

- **「残り〇席」「人気につき増席」は、体験談を読む学生には効かず、「煽っていた」と書かれる**
- **特典や優遇で集めると、来る学生が合わず、回の空気が変わる**
- **大人数を集めると、「聞きたいことが聞けない回」になる**：体験談に「一方的だった」と書かれる
- **来る人数より、来た学生が「聞けた」と感じる回**：小さくてよい

## 小さい回を、途切れさせずに続ける

- **一度きりの大きな回より、小さい回を続ける**：一覧に「続いている会社」として残る
- **オンラインの短い回でよい**：若手一人と人事一人で、体験談で気になることを話す
- **続ける仕組みを先に作る**：月に一度、同じ型で。[ワンキャリアで説明会を掲載するときの書き方](/media/oc-setsumeikai-keisai/)の「終わったあとの動き」
- **集まらなかった回も、開く**：一人でも来たら、その一人に丁寧に。その一人が体験談に書く
- **途切れると、「見つからない」に戻る**

## スカウトで、この回に誘う

- **イベントの掲載だけで待たず、スカウトの文面の末尾を「この回に来てほしい」にする**
- **文面で「この回で、〇〇が△△の話をします」と予告し、当日そのとおりに渡す**
- **文面で触れた学生の気になることが、この回で聞けることを書く**
- **つなぎ方は[ワンキャリアのスカウトとイベントのつなげ方](/media/oc-scout-event-renkei/)**

スカウトで誘った学生は、「来る理由」を持って来ます。掲載だけで待つより、集まります。

## 来た学生が、体験談に書く回にする

- **来た学生が、「聞きたいことが聞けた」と感じる回**：会社紹介ではなく、質問に答える時間を長く
- **出た人が、体験談で気になることに、事実で答える**：良く見せない
- **終わったあと、翌日までに一言**：「本日はありがとうございました。ご質問の〇〇は△△です」
- **体験談に「聞きたいことが聞けた」と書かれると、翌年の回に集まる**：今年の回が、翌年の集客
- **書かれる回の条件は[ワンキャリアの学生が掲載を見る順番](/media/oc-gakusei-mesen/)**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 五つの原因のどれかに絞る | 人事 |
| 掲載の項目を全部埋め、時期を確認する | 人事 |
| タイトルを「誰が・何を」に | 人事 |
| 体験談を読み、気になることを拾う | 人事と面接官 |
| 本文に「この回で聞けること」と「選考との関係」と「申込後」を書く | 人事 |
| 回に出て、気になることに事実で答える | 現場の若手と面接官 |
| 小さい回を月に一度続ける | 人事と現場 |
| スカウトでこの回に誘う | 人事（送る人） |

運用代行や代理店が支えられるのは、五つの原因の切り分け、タイトルと本文の型、体験談の読み方の型、続ける仕組みの型、スカウトとのつなぎ方までで、回に出ること、気になることに答えること、選考との関係の決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。イベントに集まらない会社から、「会社の魅力がもっと伝わる説明会にしたい」と相談されることがあります。当社は、「会社の魅力を伝える回」を提案しません。ワンキャリアの学生は、会社の魅力を聞きに来るのではなく、体験談で気になったことを確かめに来ます。魅力を伝える回は、学生の「確かめたい」に答えず、体験談に「一方的だった」と書かれます。当社がお願いするのは、自社の体験談を読んで、学生が気になっているのに企業ページでは分からないことを一つ選び、「この回で、〇〇がそれを話します」という回にすることです。魅力は、確かめられた学生が自分で感じるもので、会社が伝えるものではありません。

## まとめ

- ワンキャリアの学生は、体験談で気になったことを確かめにイベントに来る。「確かめられそう」と見えなければ来ない
- 五つの原因は、一覧で見つからない・タイトルが「会社説明会」・確かめられる回に見えない・選考との関係が不明・申込後が見えない。この順に直す
- タイトルに「誰が・何を」、本文に「この回で聞けること」「選考との関係（事実で）」「申込後の連絡」。会社紹介を中心にしない
- 特典・優遇・「残り〇席」で煽らない。大人数より、来た学生が「聞けた」と感じる小さい回を、月に一度続ける
- スカウトの末尾でこの回に誘い、来た学生が体験談に「聞きたいことが聞けた」と書く回にする。今年の回が翌年の集客

## よくある質問

### 一人しか申込がなく、開くべきか迷います

開きます。その一人に、体験談で気になることを丁寧に答える回にします。その一人が体験談に「少人数で、聞きたいことが全部聞けた」と書けば、翌年の回に集まります。中止すると、その一人に「軽く扱われた」が残り、体験談に書かれることがあります。

### 選考との関係を書くと、「選考ではない」と書いた回には来なくなりませんか

ワンキャリアの学生は、「選考ではない」と書かれた回のほうが、確かめに来やすいです。選考に影響すると書かれると、確かめるより「良く見せる」に回り、聞きたいことを聞けません。実態が「選考ではない」なら、そう書き、「選考に進みたい人は、回のあとに案内します」と添えれば、両方が成立します。

### イベントに集まらないときの見直しは、御社に相談できますか

できます。当社は、五つの原因の切り分け、タイトルと本文の型、体験談の読み方の型、続ける仕組みの型、スカウトとのつなぎ方を支えられます。回に出ること、気になることに答えること、選考との関係の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
