スカウトの文面を、社内でレビューする。上司が文章の好みで直す、レビューで止まって送れない、全通をレビューして続かない、名義の人が見ていない。レビューが、文面を良くするより、送ることを止めています。**結論から言うと、レビューの観点を「相手が書いたことが入っているか」「会社説明と抽象語になっていないか」「守れないことを書いていないか」の三つに絞ります。レビューする人を型と空欄で分け、期限と「返らなければ送る」を合意し、最初の数通と週に一度の数通だけを並べて読みます。文章の好みでレビューしません。三つの媒体で、この考え方は同じです。** この記事では、レビューで起きる失敗、三つの観点、レビューする人、期限の合意、数通の並べ方、直しの受け方、分担を整理します。文面の失敗の型は[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)、型の管理は[スカウト文面のテンプレート管理](/media/kh-bunmen-template/)、上司の確認の流れはWantedlyの記事の場合として[Wantedlyの記事を上司に確認してもらう流れ](/media/wt-joushi-check/)で書きました。

## この作業の目的｜レビューで止まらず、「自分宛」と「守れること」を保つ

レビューの目的は、文章を整えることではなく、相手に「読んでいない」「盛っている」「話が違う」と読まれる文面を、送る前に止めることです。文章の好みは、相手には関係がありません。

目的は、レビューの観点を、相手が読む観点に絞り、レビューが送ることを止めない形にすることです。

## レビューで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 文章の好みで直す | 「もっと丁寧に」「もっと熱く」で、相手のことが薄れ、会社説明が増える |
| レビューで止まって、送れない | 返らないまま数日。返信の温度が冷めるより先に、送る前で止まる |
| 全通をレビューする | 一通ごとの確認に時間がかかり、続かない。数週間でレビューが形だけになる |
| 名義の人が見ていない | 人事同士でレビューして、名義の人が「自分が言いそうか」を確かめていない |
| 観点が人によって違う | 一人は長さ、一人は敬語、一人は会社説明。どれを直せばよいか分からない |
| レビューする人が多い | 全員の意見を入れて、文面が長くなり、誰のものでもなくなる |

共通するのは、「何をレビューするか」が決まっていないことです。

## 観点を、三つに絞る

| 観点 | 何を見るか | 見つけたら |
|---|---|---|
| 1. 相手が書いたことが、入っているか | 書き出しの「読んだ一文」が、相手の行動か、見出しか、一般化か。重なりが、相手の行動と場面をつないでいるか | 見出しか一般化なら、拾い直す。つないでいなければ、書き直す |
| 2. 会社説明と抽象語に、なっていないか | 事業の全体・実績・理念・「成長できる」「風通し」が入っていないか。会社の一言を超えていないか | 削る |
| 3. 守れないことを、書いていないか | 「代表が出る」「当日返す」「選考ではない」を、実態で守れるか。企業ページと一致しているか | 守れないなら、書かない。守れる形に面談を先に直す |

三つだけです。文章の長さ、敬語の丁寧さ、言い回しの好みは、観点に入れません。三つの観点は、[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)の「失敗の原因は、三つ」と同じです。

### エージェントベストの見解

相談で最も多い思い込みは、「文面は上司や経験者がレビューするほど良くなる」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の文面のレビューを見ていますが、複数の人がそれぞれの好みでレビューした文面は、「もっと丁寧に」で挨拶が長くなり、「会社の魅力を」で会社説明が増え、「熱意を」で抽象語が足され、最初の文面より返信が減っています。相手が読む観点は、「自分のことを読んだか」「何の仕事か」「守れる約束か」の三つだけで、それ以外のレビューは、相手には見えません。当社がレビューの相談を受けるとき、最初にやるのは、レビューの観点を三つに絞って、それ以外の指摘は「参考」として扱う、という合意を作ることです。

## レビューする人を、型と空欄で分ける

| レビューの対象 | レビューする人 | いつ |
|---|---|---|
| 型（仕事の場面・会社の一言・何を見るか・締め・名義の一文） | 名義の人と、人事 | 型を作ったとき、更新の起点があったとき |
| 空欄（読んだ一文・重なり） | 送る人同士。最初は一人が全員分 | 最初の数通と、週に一度の数通 |
| 守れるか | 面談に出る人と、人事 | 型を作ったとき |
| 上司 | 型だけ。空欄はレビューしない | 型を作ったとき |

「型」は一度作れば全通に使うので、名義の人と上司が見ます。「空欄」は相手ごとに変わるので、上司が全通を見る形にせず、送る人同士で数通を並べます。名義の人の確認は、[スカウト文面のテンプレート管理](/media/kh-bunmen-template/)の「募集ごとに一つ、名義ごとに一つ」で書きました。

## 期限と、「返らなければ送る」の合意

- **レビューの期限を、先に決める**：「型は〇日以内、空欄の数通は翌日まで」
- **期限までに返らなければ、送ってよい、と合意する**：レビューで止まって送れない形をなくす
- **上司に、「返らなければ人事の判断で送る」を先に伝える**：あとで「見ていない」と言われない
- **返らないことが続くなら、レビューする人を減らす**：レビューは、送ることを止めるためのものではない
- **合意の作り方は[Wantedlyの記事を上司に確認してもらう流れ](/media/wt-joushi-check/)の手順3と同じ**

## 最初の数通と、週に一度の数通

- **最初の数通は、一人が全員分の空欄を読む**：観点1で、「見出し」「一般化」が混ざっていないかを揃える
- **揃ったら、全通のレビューをやめる**：送る人が自分で三つの観点で読み直し、送る
- **週に一度、数通を並べて読む**：送った人が別々の数通。「見出し」「会社説明」「守れないこと」が戻っていないか
- **月に一度、返信が来た文面と来なかった文面を並べる**：三つの観点で差を見る。[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)の「失敗に、気づく方法」
- **全通をレビューしない**：続かない

## 直しの、受け方

- **三つの観点の指摘は、直す**：「読んだ一文が見出し」「会社説明が入っている」「守れない」
- **三つ以外の指摘（長さ・敬語・言い回し）は、「参考」として扱う**：直すかどうかは、送る人が決める
- **上司の「もっと会社のことを」は、「会社のことは企業ページに」と返す**：[スカウトでの会社紹介の書き方](/media/kh-bunmen-kigyo-shoukai/)
- **上司の「もっと熱く」は、「熱さは場面で」と返す**：抽象語を足さない
- **直したら、直した理由を一行で残す**：「観点1で、見出しを行動に」
- **直しを受けて文面が長くなったら、観点2で削る**

直しの受け方は[Wantedlyの記事を上司に確認してもらう流れ](/media/wt-joushi-check/)の手順5で書きました。

## 送る人が、自分でレビューする形

- **送る前に、自分で三つの観点で読み直す**：「相手のことが入っているか」「会社説明になっていないか」「守れることか」
- **「相手の目で読み直す」を、送る前に毎回**：「自分がこの相手なら、開くか、読み進めるか、返信するか」
- **自分でレビューできる形が、レビューの最終形**：他の人のレビューは、そこに至るまでの補助
- **自分でレビューする観点は、[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)の「失敗に、気づく方法」の1**

## 社内の分担

| 作業 | 誰が |
|---|---|
| レビューの観点を三つに絞り、合意する | 人事と責任者 |
| 型をレビューする | 名義の人と人事と上司 |
| 守れるかをレビューする | 面談に出る人と人事 |
| 最初の数通の空欄を読む | 人事の一人 |
| 週に一度、数通を並べて読む | 人事と送る人 |
| 期限と「返らなければ送る」を合意する | 人事と上司 |
| 送る前に自分で三つの観点で読み直す | 送る人 |

運用代行や代理店が支えられるのは、三つの観点の整理、レビューする人と対象の分け方、並べて読む表の型、直しの受け方の型までで、レビューすること、名義の確認、守れるかの判断、送ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。当社がレビューの相談を受けるとき、「相手に見える観点」と「相手に見えない観点」を分けます。前者は、相手のことが入っているか、会社説明になっていないか、守れることか、の三つで、これは直します。後者は、長さ、敬語、言い回し、調子で、これは相手の返信に影響せず、直しても直さなくても同じです。相談の多くは、後者のレビューに時間が使われていて、前者が見られていません。当社がお願いするのは、レビューの場で「この指摘は、三つのどれですか」と確かめることです。どれでもなければ、参考として扱い、直すかどうかは送る人に任せます。

## まとめ

- レビューの目的は文章を整えることではなく、「読んでいない」「盛っている」「話が違う」と読まれる文面を送る前に止めること。文章の好みでレビューしない
- 観点は三つ。相手が書いたことが入っているか（見出しや一般化でないか）・会社説明と抽象語になっていないか・守れないことを書いていないか
- 型は名義の人と人事と上司が、空欄は送る人同士が、守れるかは面談に出る人が。上司は型だけで、空欄の全通を見ない
- 期限と「返らなければ送る」を先に合意する。最初の数通は一人が全員分を読み、揃ったら全通のレビューをやめ、週に一度数通を並べる
- 三つ以外の指摘は「参考」。「もっと会社のことを」には「企業ページに」、「もっと熱く」には「場面で」と返す。最終形は、送る人が自分で三つの観点で読み直すこと

## よくある質問

### 上司が「全通を自分が見る」と言います

型を見てもらい、空欄は「最初の数通」と「週に一度の数通」にしてもらいます。全通を見ると、上司の時間で送ることが止まり、返信の温度が冷めます。「型を見ていただければ、空欄は型の中で変わる部分だけなので、数通で揃っているかを見ていただく形で」と伝えます。それでも全通を、と言われたら、期限と「返らなければ送る」を合意します。

### レビューする人によって、指摘が違って困ります

観点を三つに絞り、レビューの前に「この三つで見てください」と伝えます。三つ以外の指摘は、「参考として受け取ります」と返し、直すかどうかは送る人が決めます。三つの観点で指摘が分かれることは少なく、分かれるのは三つ以外の観点（好み）です。観点が揃えば、人が違っても指摘は揃います。

### スカウト文面の社内レビューは、御社に相談できますか

できます。当社は、三つの観点の整理、レビューする人と対象の分け方、並べて読む表の型、直しの受け方の型を支えられます。レビューすること、名義の確認、守れるかの判断、送ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
