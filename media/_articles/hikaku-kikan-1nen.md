急がず、一年かけて採用の基盤を作りたい。来年以降も続ける前提で、今年は土台を。ところが、一年目に数を求めて「効かない」と止め、「基盤を作る」が計画に落ちておらず、媒体を増やして基盤が分散し、記録を残さず一年が「経験」で終わり、担当が変わって消える。**結論から言うと、一年の目標は「数」ではなく「翌年、その日から回る基盤」（こんな人の一枚・型・台帳と率・企業ページと記事・現場の分担・接点・振り返り）です。媒体は「積み上がるもの」が多い形を一つ、通年で。一年目に数を求めず、月に一度の見直しで型を良くし、年度の切れ目に翌年の一枚を作ります。** この記事では、一年で基盤を作るときに起きる失敗、基盤とは何か、3媒体で積み上がるもの、七つの期間での作り方、月の見直し、数の扱い、年度の切れ目、二年目、分担を整理します。短い期間は[三か月で結果が要るときの媒体](/media/hikaku-kikan-3kagetsu/)、自社運用は[自社運用する前提の媒体の選び方](/media/hikaku-jisha-unyou/)、年間計画は[母集団形成の年間計画](/media/kh-boshudan-nenkan/)で書きました。

## この作業の目的｜一年の終わりに、「翌年、その日から回る」状態にする

基盤を作る一年は、数が出にくい年です。数を目標にすると、途中で「効かない」と判断されて止まり、基盤が残りません。基盤を目標にすると、一年の終わりに「翌年、契約した日から送れる・掲載できる・会える」状態が残り、二年目から数が出ます。

目的は、一年を「数を出す年」ではなく、「翌年の初日から回る基盤を、七つ残す年」にすることです。

## 一年で基盤を作るときに、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 一年目に、数を求める | 基盤ができる前に「効かない」と判断され、止まる |
| 「基盤を作る」が、計画に落ちていない | 何を残せば「基盤ができた」かが決まっておらず、一年の終わりに何が残ったか分からない |
| 媒体を増やして、基盤が分散する | 型も台帳も記事も媒体ごとに薄く、どれも翌年の元にならない |
| 記録を残さず、「経験」で終わる | 担当の頭の中に残り、翌年に使える形になっていない |
| 月の見直しをせず、一年後に一度 | 型が一年間、最初のまま。良くなる機会を逃す |
| 担当が変わって、基盤が消える | 文書がなく、引き継ぎがない |

共通するのは、「基盤」を目標として具体に置いていないことです。基盤は七つに分けて置きます。

## 基盤とは、何か｜七つ

| 基盤 | 「できた」の状態 | 翌年にどう効くか |
|---|---|---|
| 「こんな人」の一枚 | 行動の事実で書かれ、面接官と合意され、面談の記録で一度更新されている | 送る相手、書く材料、面談の見方の物差し |
| 文面と企業ページの型 | 空欄が「読んだ一文」と「仕事の一文」だけになっている | 翌年、型の更新だけで送り始められる |
| 台帳と率 | 入口・段・日付・近さが付き、段ごとの率が仮置きではなく実績になっている | 翌年の逆算が実績で引ける。[母集団の目標数の決め方](/media/kh-boshudan-keikaku/) |
| 企業ページと記事 | 「こんな人」が自分で選べる材料があり、社員の記事が複数ある | 翌年、更新だけで済む |
| 現場の分担 | 名義・一文・面談に出る人と枠が決まり、一年回っている | 翌年、最初から現場が出る |
| 接点 | 今年会った人、辞退した人、早期の接点が、台帳に残り、関係が続いている | 翌年の母集団の最初の人。[潜在層からの母集団形成](/media/kh-boshudan-senzai/) |
| 振り返りと翌年の一枚 | 入口の三分類と、残す・変える・やめる・時間の配分が一枚にある | 翌年の最初の月から、一枚どおりに動ける。[母集団形成の振り返り方](/media/kh-boshudan-review/) |

七つが「できた」の状態にあれば、基盤ができています。数は、その結果として翌年に出ます。

### エージェントベストの見解

相談で最も多い思い込みは、「一年かけるなら、いろいろな媒体を試して、合うものを見つける年にしたい」というものです。当社は3媒体すべての販売パートナーとして、基盤を作る一年の相談を受けていますが、「試す年」にした会社は、媒体ごとに型も台帳も薄く、一年の終わりに「どれも少し分かったが、どれも基盤になっていない」で、二年目も試す年になっています。逆に、一つの媒体で通年回し、七つの基盤を残した会社は、二年目に「一つ目が回っていて、時間に残りがある」状態で二つ目を足せ、二つ目も最初から型と台帳を持って始められています。基盤を作る一年は、媒体を「試す」年ではなく、「一つで積む」年です。当社が基盤の相談を受けるとき、最初にやるのは、七つの基盤を「できた」の状態で書き出し、一年の目標として置き直すことです。

## 3媒体で、積み上がるもの

| 媒体 | 一年で積み上がるもの | 基盤を作る年に向く条件 |
|---|---|---|
| OfferBox | 読んだ経験、効いた文面の型、台帳の率（承認率・面談進行率）、現場の名義と面談の分担 | 毎週の時間が通年で取れる。「こんな人」を条件で言える。[OfferBoxの二年目以降の見直し点](/media/ob-repeat-unyou/) |
| Wantedly | 記事（資産として残る）、社員の言葉、会社ページ、通年の更新の習慣 | 社員が話せる。書き続ける時間が取れる。記事は書くほど残る。[Wantedlyの記事は資産](/media/wt-story-kihon/) |
| ワンキャリア | 企業ページ、体験談との揃い方、今年の選考が翌年の体験談になること、少人数の回の型 | 最初に整える時間が取れる。書いたとおりに運用できる。[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/) |

優劣ではなく、「一年で、何を積みたいか」で選びます。読んだ経験と率を積むなら毎週コツコツの形、記事を積むなら通年で育てる形、企業ページと体験談を積むなら最初に集中の形。時間の使い方の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」で書きました。

## 一年の七つの期間で、基盤を作る

| 期間 | 基盤のどれを作るか |
|---|---|
| 1. 準備 | 一枚（初版）、型（初版）、台帳の項目、企業ページ、現場の分担、面談の枠 |
| 2. 早期 | 接点（少数）。一枚と型を、最初の反応で直す |
| 3. 選考期 | 台帳と率（実績）、型（月に一度更新）、記事（社員の言葉）、現場の分担が回る |
| 4. 後期 | 率の置き直し、接点（決まらなかった人） |
| 5. 内定フォロー | 一枚の更新（入社を決めた人から）、接点（内定者の紹介） |
| 6. 振り返り | 入口の三分類、翌年の一枚、一枚の更新 |
| 7. 次の準備 | 翌年の初日から回る状態の確認 |

七つの期間の考え方は[母集団形成の年間計画](/media/kh-boshudan-nenkan/)で書きました。基盤を作る年は、各期間の「やること」を「基盤のどれを作るか」で置きます。

## 月に一度の、見直し

- **型を、月に一度、一つだけ直す**：返信が来た文面と来なかった文面を並べる。[スカウト文面の改善](/media/kh-bunmen-kaizen/)
- **率を、月に一度、台帳から出す**：仮置きを実績に
- **細い段を、一つ指す**：[採用ファネルの作り方](/media/kh-boshudan-funnel/)
- **一枚を、面談の記録で確かめる**：入口で「近い」が面談で「遠い」なら、一枚か入口の見方を直す
- **見直しの記録を、残す**：「何月に、何を、なぜ直したか」。振り返りの材料

## 一年目の、数の扱い

- **数を、目標にしない**：目標は七つの基盤
- **数は、記録する**：翌年の率の元
- **上司に、「一年目は基盤、二年目から数」と先に合意する**：一年目の数で止められないように
- **一年目に決まった人がいれば、それは基盤の副産物**：数を求めなくても、近い人と会えていれば決まる
- **合意の取り方は[自社運用する前提の媒体の選び方](/media/hikaku-jisha-unyou/)のよくある質問**

## 年度の切れ目に、翌年の一枚を作る

- **七つの基盤が「できた」の状態かを、一つずつ確かめる**
- **できていない基盤を、翌年の最初の項目に**
- **入口の三分類（今年は一つの媒体でも、リファラルや早期の接点も入口）**
- **残す・変える・足す・時間の配分・翌年の逆算**
- **一枚の作り方は[母集団形成の振り返り方](/media/kh-boshudan-review/)の「翌年の一枚」**

## 二年目の、広げ方

- **一つ目を、通年か厚く**：職種を二つ、時期を広げる。[年間予算百万円前後の採用媒体の組み方](/media/hikaku-yosan-100/)
- **二つ目を足すのは、一つ目が回って時間に残りがあれば**：役割が違う入口を、試す大きさで
- **二年目の目標は、数と基盤の両方**：基盤は「更新」に、数は「一年目の率で逆算」に
- **二年目に起きやすい失敗は[OfferBoxの二年目以降の見直し点](/media/ob-repeat-unyou/)の手順5**

### エージェントベストの見解

これは数字の読み方の話です。基盤を作る一年の相談で、年度の途中に「半年たったが、数が出ていない。このまま続けてよいか」と聞かれることがあります。当社が確かめるのは、数ではなく、七つの基盤のうち、いくつが「できた」の状態に近づいているかです。一枚が面談の記録で一度更新されているか、型の空欄が二つだけになっているか、率が仮置きから実績に変わっているか、現場が面談に出ているか。この四つが動いていれば、基盤の年として順調で、数は翌年に出ます。動いていなければ、数が出ていないこと以上に、基盤が積まれていないことが問題で、そこを直します。基盤の年の途中で見る数字は、数ではなく、基盤の進み方です。

## まとめ

- 一年かけて基盤を作る年の目標は「数」ではなく「翌年、その日から回る基盤」七つ（一枚・型・台帳と率・企業ページと記事・現場の分担・接点・振り返りと翌年の一枚）
- 媒体は「積み上がるもの」が多い形を一つ、通年で。試す年にしない。読んだ経験と率を積むなら毎週コツコツ、記事なら通年で育てる、企業ページと体験談なら最初に集中
- 七つの期間ごとに「基盤のどれを作るか」を置き、月に一度、型を一つ直し、率を実績に置き直し、細い段を一つ指し、見直しの記録を残す
- 一年目の数は目標にせず記録し、上司と「一年目は基盤、二年目から数」を先に合意する。年度の途中で見るのは、数ではなく基盤の進み方
- 年度の切れ目に七つを確かめ、翌年の一枚を作る。二年目は一つ目を厚くし、時間に残りがあれば二つ目を試す。基盤は文書で残し、担当交代に備える

## よくある質問

### 一年かけるなら、途中で媒体を切り替えて比べたほうがよくないですか

途中で切り替えると、七つの基盤が二つの媒体に分かれ、どちらも「できた」に届きません。基盤を作る年は一つで通し、年度の切れ目に「一つ目が回っているか」を確かめてから、二年目に二つ目を試します。比べるのは、一つ目の基盤ができてからで、そのほうが二つ目も速く回ります。切り替えの判断は[自社運用と運用代行の違い](/media/hikaku-baitai-vs-daikou/)の「切り替えの順番」と同じ考え方です。

### 基盤を作る年の途中で、急に採用人数が増えました

基盤の年の運用に、[三か月で結果が要るときの媒体](/media/hikaku-kikan-3kagetsu/)の形を一時的に重ねます。「こんな人」の一枚と型がすでにあるなら、短い期間の準備は済んでいて、送る・返す・会うに集中できます。ただし、短い期間の運用で基盤の記録（月の見直し、率の置き直し）を止めないこと。短い期間が終わったら、基盤の年に戻り、短い期間で得た率と接点を基盤に足します。

### 一年かけて基盤を作る媒体選びは、御社に相談できますか

できます。当社は、七つの基盤の型、期間ごとの作り方の整理、月の見直しの型、翌年の一枚の型、引き継ぎの型を支えられます。目標の合意、一枚の決定、読んで書くこと、面談、記事、接点を続けることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
