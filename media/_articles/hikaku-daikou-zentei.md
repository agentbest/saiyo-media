採用媒体の運用を、代行に出す前提で選びたい。社内に時間がなく、送る作業は外に出す。ところが、「代行に出せば回る」と思って人物像を決めずに出し、面談の枠を用意せず、一次返信の後の返信が遅れ、結果を戻さず、全部を出して自社に何も残らない。**結論から言うと、代行に出せるのは「送る作業」で、「決める作業」と「会う作業」は社内に残ります。だから媒体は「代行に出せる作業の比率が高く、社内に残る作業が面談に集中する」ものが先で、代行に出しても止まらない体制（人物像・面談の枠・返信の続き・結果を戻す）を先に作ります。全部を出すと、代行の質を判断できず、翌年に残りません。** この記事では、代行前提で起きる失敗、出せる作業と残る作業、3媒体での比率の違い、止まらない体制、段階的に出す順番、報告と承認の型、代行の質を判断する材料、翌年に残す形、分担を整理します。自社運用と代行の違いは[自社運用と運用代行の違い](/media/hikaku-baitai-vs-daikou/)、代理店の型は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)、代行の範囲は[OfferBoxの運用代行に出す範囲](/media/ob-unyou-daikou-hanni/)で書きました。

## この作業の目的｜代行に出しても、「社内に残る作業」が回る状態にする

代行に出して止まる原因は、代行の側ではなく、社内の側にあります。人物像が決まらない、面談の枠がない、一次返信の後の連絡が遅い、結果が戻らない。この四つは、代行に出せない作業で、社内が回さなければ、代行がどれだけ送っても止まります。

目的は、代行に出す前に、「社内に残る作業」を回る形にし、その形に合う媒体を選ぶことです。

## 代行前提で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 「代行に出せば回る」と思う | 決める作業と会う作業が社内で回らず、代行が送っても止まる |
| 人物像を決めずに、出す | 代行が検索条件も文面も作れず、「とりあえず広く」で送る。届かない |
| 面談の枠を、用意しない | 承認が溜まり、代行が日程を出せず、学生の温度が下がる |
| 一次返信の後の返信が、遅い | 代行が一次返信しても、社内からの次の連絡が遅く、離れる |
| 結果を、戻さない | 面談の結果が代行に戻らず、条件も文面も直せない |
| 全部を出して、自社に残らない | 翌年に代行をやめると、型も台帳も自社にない |

共通するのは、代行を「運用の全部を外に出すもの」と考えていることです。代行は「送る作業を外に出すもの」です。

## 代行に出せる作業と、社内に残る作業

| 作業 | 出せるか | 理由 |
|---|---|---|
| 採りたい人物像（「こんな人」）を決める | 出せない | 企業が決める。代行は聞いて整理する側 |
| 検索条件を設定する | 出せる | 人物像に基づいて |
| 文面の下書き（読んだ一文・共通部分） | 出せる（共通部分は社内で確認） | 会社の紹介と仕事の中身は社内が確認 |
| 送る | 出せる | 企業の名義で |
| 一次返信（承認への最初の返事と面談の案内） | 出せる | 型に沿って |
| 一次返信の後の返信、学生の質問への答え | 出せない | 学生が話している相手は企業 |
| 面談の日程を出す | 社内 | 面談の枠は社内にしかない |
| 面談・面接 | 出せない | 企業が行う |
| 面談の結果を代行に戻す | 社内 | 戻らないと直せない |
| 集計と見直しの材料 | 出せる | 台帳から |

「出せない」と「社内」の側の時間を、代行に出す前に見込みます。詳しくは[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)の「代行で頼める作業と、頼めない作業」で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「代行に出すなら、社内の時間はほとんど要らない」というものです。当社は3媒体すべての販売パートナーとして、運用代行の相談を受け、当社自身も代行を行っていますが、代行に出して止まった会社で、代行の送る作業が原因だったことは少なく、原因は社内に残る作業（人物像を決める、面談の枠を出す、一次返信の後を返す、結果を戻す）が回っていなかったことです。逆に、代行に出しても回っている会社は、社内に残る作業を「週に面談の枠を出す」「面談の結果を当日に戻す」の二つに絞って、その二つを確かに回しています。代行に出すと社内の時間はゼロにはならず、「送る時間」が「会う時間と戻す時間」に変わります。当社が代行の相談を受けるとき、最初にやるのは、「面談の枠は週に何回出せますか。結果はいつ戻せますか」を確かめることです。

## 3媒体で、代行に出せる比率と、社内に残る作業の違い

| 媒体 | 代行に出せる作業 | 社内に残る作業 | 代行前提での見方 |
|---|---|---|---|
| OfferBox | 検索条件、読んで一文を拾う、文面の下書き、送る、一次返信、集計 | 人物像、名義と口調の確認、面談の枠、面談、結果を戻す | 出せる比率が高い。社内は「面談と結果」に集中できる。[OfferBoxの運用代行に出す範囲](/media/ob-unyou-daikou-hanni/) |
| Wantedly | スカウトの下書き、送る、一次返信、記事の整え、集計 | 会社の想いと記事の中身（話す）、名義、面談、結果を戻す | 記事の中身は出せない。「話す」時間が社内に残る。[Wantedlyのスカウト代行](/media/wt-scout-daikou/) |
| ワンキャリア | 企業ページの整え、スカウトの下書き、送る、受諾への一次返信、集計 | 体験談を読む、書いたとおりに運用する判断、回に出る、面談、結果を戻す | 「書いたとおりに運用する」は出せない。[ワンキャリアのスカウト代行](/media/oc-scout-daikou/)、[ワンキャリアの掲載代行](/media/oc-keisai-daikou/) |

優劣ではなく、「社内に残る作業が、面談に集中するか」で見ます。社内の時間が「面談だけ」なら、出せる比率が高い形が先です。社内に「話す」「回に出る」の時間があるなら、記事や回を軸にした媒体も選べます。

## 代行に出しても、止まらない体制

- **人物像（「こんな人」）を、代行に出す前に決める**：[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)
- **面談の枠を、週の初めに出す**：代行が日程を出せる
- **一次返信の後の返信を、社内で当日か翌日に返す担当を決める**
- **面談の結果を、当日に代行に戻す**：一行でよい
- **文面の共通部分を、社内で確認する**：会社の紹介と仕事の中身
- **四つが回る形を、代行に出す前に作る**：止まる原因は[自社運用と運用代行の違い](/media/hikaku-baitai-vs-daikou/)の「代行で止まる原因」

## 段階的に出す、順番

1. **集計と見直しの材料**：出しても運用が変わらない。最初に
2. **検索条件と文面の型**：人物像を渡して、代行が作る。社内が確認
3. **送る作業と一次返信**：型ができてから。名義は企業
4. **読んで一文を拾う**：代行が読んで拾えるかを、最初の数通で確かめてから
5. **出さない**：人物像、一次返信の後、面談、結果を戻す、企業ページの中身

一度に全部を出さず、順に出して、各段で「代行の質」を確かめます。順番の詳しくは[OfferBoxの運用代行に出す範囲](/media/ob-unyou-daikou-hanni/)の手順3で書きました。

## 報告と承認の、型

- **週に一度、送った数・承認・返信・面談の日程を、一枚で**
- **文面の変更は、社内が承認してから**：代行が勝手に変えない
- **学生からの質問は、当日に社内へ**：代行が答えない
- **月に一度、率と細い段を、代行と社内で見る**
- **型の決め方は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)の「報告と承認の流れで確認する項目」と[OfferBoxの運用代行に出す範囲](/media/ob-unyou-daikou-hanni/)の手順4**

## 代行の質を、判断する材料

- **自社に、型がある**：型があれば、代行の下書きが型に沿っているかが分かる
- **文面に、「読んだ一文」があるか**：同じ文面を全員に送っていないか
- **承認率・返信率より、面談まで来た人の近さ**：数より「こんな人」に近いか
- **報告が、型どおりに来るか**：来なければ、運用が見えていない
- **不満が出たときの切り分けは[OfferBoxの運用代行に不満があるとき](/media/ob-daikou-fuman/)と[Wantedlyの運用代行に不満があるとき](/media/wt-daikou-fuman/)**

## 翌年に、残す形

- **型と台帳は、自社のものとして持つ**：代行が作った型も、自社に写す
- **代行をやめても、自社で回せる状態を保つ**：予算が減った年、代行を切り替える年
- **代行から自社に戻す引き継ぎの型を、先に決めておく**：[OfferBoxの運用代行に出す範囲](/media/ob-unyou-daikou-hanni/)の手順5
- **代行を続けるかは、年度の切れ目に、近い人の面談数あたりで**：[母集団形成の予算配分](/media/kh-boshudan-yosan/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 人物像（「こんな人」）を決める | 人事と現場 |
| 代行に出す範囲と順番を決める | 人事責任者 |
| 面談の枠を週の初めに出す | 面談に出る人 |
| 一次返信の後の返信を当日か翌日に | 人事 |
| 面談し、結果を当日に代行へ戻す | 面談に出る人と人事 |
| 文面の共通部分と変更を承認する | 人事 |
| 週の報告と月の見直しを代行と持つ | 人事 |
| 型と台帳を自社に写し、翌年に残す | 人事 |

運用代行や代理店が支えられるのは、出せる作業（検索条件・文面の下書き・送る・一次返信・集計・企業ページの整え）と、報告の型、引き継ぎの型までで、人物像、面談の枠、一次返信の後、面談、結果を戻すこと、承認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。当社は運用代行を行いますが、代行の相談で「面談の日程調整と、学生への返信も全部お願いしたい」と言われたとき、一次返信（承認への最初の返事と面談の案内）まではお受けし、その後の学生とのやり取りは企業に残していただきます。学生は、その会社の人と話していると思って返信しており、当社が代わり続けると、面談で会った人と文面の人が違う、が起きます。当社が代行で持つのは「送る作業」で、企業が持つのは「決める作業」と「会う作業」です。この線を引かずに全部を出した会社は、翌年に代行をやめたときに自社に何も残っていません。代行に出す前提で媒体を選ぶなら、「社内に残る作業」を先に決めて、それが回る形を作ってから、出してください。

## まとめ

- 代行に出せるのは「送る作業」（検索条件・下書き・送る・一次返信・集計）で、「決める作業」（人物像・承認）と「会う作業」（面談・結果を戻す・一次返信の後）は社内に残る
- 代行で止まる原因は社内の側にある。人物像・面談の枠・一次返信の後の返信・結果を戻す、の四つを代行に出す前に回る形に
- 3媒体で出せる比率と残る作業は違う。社内の時間が「面談だけ」なら出せる比率が高い形を先に、「話す」「回に出る」の時間があるなら記事や回を軸にした媒体も
- 段階的に出す（集計→型→送ると一次返信→読んで拾う）。一度に全部を出さず、各段で代行の質を確かめる。自社に型があれば判断できる
- 型と台帳を自社に写し、代行をやめても回る状態を保つ。全部を出すと、翌年に残らない

## よくある質問

### 社内に時間がないから代行に出すのに、社内に残る作業があると聞いて困っています

社内に残るのは「面談の枠を出す」「面談する」「結果を一行で戻す」「一次返信の後を返す」で、送る作業より少ない時間です。この時間も取れないなら、代行に出しても止まります。代行に出す前に、この四つに要る時間を出し、面談は現場に、返信は毎日の短い時間に固定、で確保します。確保できたら出す、が順番です。[自社運用と運用代行の違い](/media/hikaku-baitai-vs-daikou/)の「時間の性質が違う」で書きました。

### 代行の文面が、自社の言葉と違う気がします

自社に型があるかを、先に確かめます。型がなければ、「違う気がする」を代行に伝えられず、代行は代行の型で書きます。人物像の一枚と、会社の紹介と仕事の中身の共通部分を社内で書き、代行にはその型に沿って「読んだ一文」を足してもらう形にします。型を渡した後も違うなら、代行の質の問題で、切り分けは[OfferBoxの運用代行に不満があるとき](/media/ob-daikou-fuman/)で書きました。

### 代行前提の媒体選びは、御社に相談できますか

できます。当社は、出せる作業と残る作業の整理、媒体ごとの比率の整理、止まらない体制の型、段階的に出す順番、報告の型、引き継ぎの型を支えられます。人物像、面談の枠、一次返信の後、面談、結果を戻すこと、承認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支え、運用代行も行っています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
