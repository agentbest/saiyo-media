スカウトの文面を、毎回ゼロから書いている。時間がかかり、通ごとに質がばらつく。逆に、テンプレートを作ったら、全通が同じになって「テンプレ」と読まれた。**結論から言うと、型は、「送る人が二か所だけ書けば済む状態」を保つためのものです。型に入れるものは、仕事の場面・会社の一言・選考で何を見るか・締めの形・名義の一文で、入れないものは、読んだ一文・重なり・抽象語・会社説明です。空欄は空欄のまま残します。募集ごとに一つ、名義ごとに一つ、型は少なく始めます。置き場を一か所にして、誰でも最新を使える形にし、更新の起点を決めます。三つの媒体で、この考え方は同じです。** この記事では、型の目的、入れるものと入れないもの、空欄、募集と名義、少なく始めること、置き場、更新の起点、型の失敗、媒体ごとの違い、分担を整理します。文面の骨組みは[スカウト文面の基本構成](/media/kh-bunmen-kihon/)、変える範囲は[スカウトを一通ずつ変える範囲の決め方](/media/kh-bunmen-kojinka/)で書きました。この記事は、型そのものの管理です。

## この作業の目的｜数を出しながら、「自分宛」を保つ

型がなければ、一通に時間がかかり、数が出ません。型が全部を埋めていれば、数は出ますが、「自分宛」がなくなります。

目的は、「型が埋める部分」と「送る人が相手を読んで埋める部分」を分け、送る人の仕事を「二か所を書くこと」だけにして、数と「自分宛」を両方保つことです。

## 型に入れるものと、入れないもの

| 型に入れるもの（募集ごとに一度） | 型に入れないもの（相手ごと、または書かない） |
|---|---|
| 仕事の一日の場面（「入社した年に〇〇を先輩と二人で持つ」） | 読んだ一文（相手が書いた行動） |
| 会社の一言（「〇〇を作っている会社です」） | 相手との重なり（読んだ一文と仕事の場面をつなぐ一文） |
| 選考で何を見るか（「選考では〇〇の話を聞きます」） | 抽象語（成長、やりがい、風通し） |
| 締めの形（誰と、どんな形で、選考ではない、一言だけ返信、確かめられる場所） | 会社説明（事業の全体、沿革、実績、理念） |
| 名義の一文（「送っている私は、入社した年に〇〇をしていました」） | 褒め言葉、「ぴったり」「特別」 |
| 件名の型（「〇〇を続けたと拝見して」の「〇〇」が空欄） | 複数の募集 |

「入れるもの」は、相手が誰でも同じでよい部分です。「入れないもの」のうち、読んだ一文と重なりは空欄として残し、抽象語と会社説明と褒め言葉は、型にも空欄にも入れません。

## 空欄は、空欄のまま残す

- **型の中に、「【相手が書いた行動】」「【読んだ一文と仕事の場面をつなぐ一文】」の空欄を、そのまま置く**
- **空欄に、「例文」を入れない**：例文が入っていると、送る人がそれをそのまま使い、全通が同じになる
- **空欄を埋めずに送れないようにする**：空欄が残った文面は、送らない
- **空欄は二か所で足りる**：書き出しの読んだ一文と、本文の重なり。件名は読んだ一文を縮めるので、三か所目ではない
- **空欄の埋め方を、型の横に一行で添える**：「相手が書いた行動を、相手の言葉のまま一つ」

「空欄のまま残す」が、型がテンプレにならない条件です。空欄の埋め方は[スカウトの書き出しで読まれるかが決まる](/media/kh-bunmen-kakidashi/)と[スカウトで「なぜあなたに」を書く方法](/media/kh-bunmen-riyuu/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「良いテンプレートがあれば、誰が送っても同じ質の文面になる」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の文面を見ていますが、「誰が送っても同じ」になった型は、相手にも「誰に送っても同じ」として読まれています。型が全部を埋めていて、送る人が名前を差し替えるだけになった文面です。逆に、型が「仕事の場面・会社の一言・何を見るか・締め」だけを埋めて、「読んだ一文」と「重なり」を空欄のまま残した型は、送る人ごとに空欄の中身が違い、相手ごとに違う文面になり、返信が来ています。良い型とは、全部を埋める型ではなく、埋めない部分を決めている型です。当社が型の相談を受けるとき、最初にやるのは、型から「読んだ一文」の例文を外して、空欄に戻すことです。

## 募集ごとに一つ、名義ごとに一つ

- **募集ごとに一つ**：仕事の場面と「何を見るか」が募集で違う。営業と技術で同じ型にしない
- **名義ごとに一つ**：名義の一文（「送っている私は〜」）が、名義の人で違う。代表の名義と現場の名義で、締めの「誰と話すか」も違う
- **募集×名義の数だけ型ができる**：多くなるなら、募集を絞るか、名義を絞る
- **相手の型（新卒と中途、職種）が複数なら、三層に分ける**：[スカウトを一通ずつ変える範囲の決め方](/media/kh-bunmen-kojinka/)の三層
- **名義の人が、自分の名義の型を確認する**：名前だけ貸さない。[OfferBoxのオファー文面テンプレートを作るときの注意](/media/ob-offer-template/)の注意3

## 型は、少なく始める

- **最初は、一つの募集、一つの名義、一つの型**：回ってから増やす
- **型を増やすのは、「この相手の型には、いまの型の仕事の場面が合わない」と分かったとき**：先に増やさない
- **増やした型は、台帳で「どの型で送ったか」を残す**：型ごとに返信を見られるように
- **使っていない型は、下げる**：型が多いと、送る人がどれを使うかで迷い、時間が増える
- **少なく始める理由は[OfferBoxのオファー文面テンプレートを作るときの注意](/media/ob-offer-template/)の注意4**

## 置き場を一か所にして、誰でも最新を使える形に

- **型の置き場を一か所に**：個人のファイルに置かない。共有の場所に
- **最新の型だけを置く**：古い型は、日付を付けて別の場所に。送る人が古い型を使わないように
- **型の横に、「いつ、誰が、何を変えたか」を一行で**：更新の記録
- **空欄の埋め方の一行も、同じ場所に**
- **担当が変わっても、置き場が同じなら引き継げる**：[OfferBoxの担当者が交代したときの立て直し](/media/ob-tantousha-koutai/)

置き場が一か所にないと、送る人ごとに違う型を使い、質がばらつき、「どの型が効いたか」が分からなくなります。置き場の考え方は[Wantedlyのスカウト文面のテンプレート管理](/media/wt-scout-template/)の「置き場を一か所にする」で書きました。

## 更新の起点

| 起点 | 何を更新するか |
|---|---|
| 現場の一文が古くなった | 仕事の場面を、現場に「今週の一日」を聞き直して入れ替える |
| 面談の形が変わった | 締めの「誰と、どんな形で」を、実際の面談に合わせる |
| 返信が来た文面と来なかった文面に差が見えた | 差が出た部分を、型に反映する。一か所ずつ |
| 担当や名義が変わった | 名義の一文と、締めの「誰と話すか」 |
| 企業ページや会社ページを直した | 締めの「確かめられる場所」と、「何を見るか」を揃える |
| 年度が変わった | 年度の表記、選考の流れ。年度の公表内容と自社の方針で確認 |

頻度で更新しません。起点で更新します。「月に一度見直す」は、起点があるかを確かめる日で、起点がなければ変えません。更新の考え方は[Wantedlyの会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)と同じです。

## 型の、失敗の型

- **型が全部を埋めている**：空欄がなく、名前の差し替えだけ。テンプレと読まれる
- **空欄に例文が入っている**：送る人が例文をそのまま使う
- **型に抽象語が入っている**：「成長できる環境です」が全通に
- **型に会社説明が入っている**：「私たちは〇〇を通じて」が全通に
- **型が多すぎる**：送る人が迷い、古い型を使う
- **置き場が複数ある**：送る人ごとに違う型
- **一度作って、更新の起点がない**：現場の一文が古くなり、面談の形とずれる
- **名義の人が型を見ていない**：名前だけ貸している

型の失敗は、文面の失敗として相手に見えます。型を見直す前に、[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)の五つの場所で、文面の側から見つけることもできます。

## 媒体ごとに、変わる点

| 媒体 | 型で変わる部分 |
|---|---|
| OfferBox | 締めの形が「面談（選考ではない）」。空欄の材料は自由記述。[OfferBoxのオファー文面テンプレートを作るときの注意](/media/ob-offer-template/) |
| Wantedly | 締めの形が「カジュアル面談」。型に自社の「なぜ」の場面を一文。空欄の材料はストーリー。[Wantedlyのスカウト文面のテンプレート管理](/media/wt-scout-template/) |
| ワンキャリア | 締めの形が「企業ページと体験談で確かめてから受諾」。型と企業ページを揃える。空欄の材料は体験談への反応。[ワンキャリアのスカウト文面のテンプレート管理](/media/oc-scout-template/) |

骨組みと空欄の位置は同じで、締めの形と空欄の材料だけが変わります。一つの型から、三つの媒体の型を作れます。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。当社が型の相談を受けるとき、当社が持てるのは、型の構造と、入れるものと入れないものの整理と、置き場の設計と、更新の起点の整理までです。型の中身（仕事の場面、何を見るか、名義の一文）は会社の中にしかなく、空欄（読んだ一文、重なり）は相手を読んだ人でなければ埋められません。当社が線を引くのは、「空欄も埋めた完成形の型がほしい」という依頼です。空欄を埋めた型は、全通が同じになり、テンプレと読まれます。当社が作るのは「空欄のある型」で、空欄を埋めるのは自社の送る人です。型は、送る人の仕事をなくすものではなく、送る人の仕事を「二か所を書くこと」に絞るものです。

## まとめ

- 型は「送る人が二か所だけ書けば済む状態」を保つためのもの。全部を埋める型は、テンプレと読まれる
- 型に入れるのは、仕事の場面・会社の一言・何を見るか・締めの形・名義の一文・件名の型。入れないのは、読んだ一文・重なり（空欄として残す）と、抽象語・会社説明・褒め言葉（どこにも入れない）
- 空欄は空欄のまま残し、例文を入れない。募集ごとに一つ、名義ごとに一つ、型は少なく始めて回ってから増やす
- 置き場を一か所にし、最新の型だけを置き、「いつ、誰が、何を変えたか」を一行で。担当が変わっても引き継げる
- 頻度ではなく起点で更新する。現場の一文が古くなった・面談の形が変わった・返信の差が見えた・名義が変わった・企業ページを直した・年度が変わった

## よくある質問

### 送る人が複数いて、空欄の埋め方がばらつきます

空欄の横に、埋め方を一行で添えます。「相手が書いた行動を、相手の言葉のまま一つ」「その行動と仕事の場面をつなぐ一文。言い切らない」。最初の数通は、一人が全員分を読んで揃えます。週に一度、数通を並べて、「見出しの引用」や「例文のまま」が混ざっていないかを見ます。ばらつきは、型の問題ではなく、空欄の埋め方の合意の問題です。

### 型を作ったら、かえって文面が冷たくなった気がします

型に入れているのが、仕事の場面と人の一文なら、冷たくなりません。冷たく感じるのは、空欄が埋まっていないか、空欄に例文が入って相手のことがないか、です。空欄に相手が書いた行動を相手の言葉のまま入れれば、型は同じでも、相手には「読んで送ってきた」文面になります。型が冷たいのではなく、空欄が空なことが冷たく見えます。

### スカウト文面のテンプレート管理は、御社に相談できますか

できます。当社は、型の構造、入れるものと入れないものの整理、置き場の設計、更新の起点の整理、型ごとの集計を支えられます。仕事の場面を話すこと、名義の一文、空欄を埋めること、送ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
