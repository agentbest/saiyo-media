ワンキャリアの掲載は、起点で更新し、頻度では更新しない、と[掲載内容の更新頻度](/media/oc-keisai-koushin-hindo/)で書きました。では、毎週は何も見なくてよいのか。**結論から言うと、毎週は「直す」ためではなく「異常に気づく」ためだけに、短く見ます。新しい体験談やクチコミが書かれていないか、エントリーやイベントの申込への対応が遅れていないか、終わったイベントの誘導が残っていないか、選考の流れの変更が掲載に反映されているか、管理画面の数字に急な変化が無いか。この5つを、台帳と管理画面を開いて確かめ、その週に対応するものと、起点や年度の切れ目に回すものを分けます。掲載の中身を毎週直すと、体験談とずれます。** この記事では、毎週直すと起きること、毎週の見直しの役割、5つの確認、週の会の持ち方、その週に対応するものと回すものの分け方、選考の時期とそれ以外の違い、記録、分担を整理します。

## この作業の目的｜遅れと放置に、その週のうちに気づく

ワンキャリアで、その週のうちに気づかないと取り返しにくいものがあります。エントリーやイベントの申込への対応の遅れ、新しく書かれた体験談での指摘、終わったイベントへの誘導の残り。これらは、月末まで待つと、学生に「放置している会社」と読まれ、体験談に書かれます。

毎週の見直しの目的は、これらに「その週のうちに気づく」ことです。掲載の中身の良し悪しを毎週判断することではありません。

## 毎週「直す」と、起きること

| 毎週直すと | 何が起きるか |
|---|---|
| 企業ページの言い回しを毎週変える | 前の体験談と揃わなくなる。学生が読むたびに違う |
| 選考の流れの書き方を毎週変える | 面接に出る人が最新を知らず、掲載とずれる |
| 数字の週の動きに反応して直す | 新卒の数字は時期で大きく動く。週の動きに意味は薄い |
| 直すこと自体が負担になる | 続かない |
| 更新の記録が追いつかない | 何を変えたか分からない |

「見ることと直すことを分ける」は、Wantedlyのスカウトの週次の見直しと同じ原則です。[スカウトの返信率を毎週見直す方法](/media/wt-scout-review/)で書きました。ワンキャリアでは、新卒の周期が年単位なので、なおさら週で直しません。

## 毎週の5つの確認

| 確認 | 見るもの | 異常のサイン |
|---|---|---|
| 1. 新しい体験談やクチコミ | 自社の体験談とクチコミに、新しいものが無いか | 「掲載と違った」「連絡が遅い」の記述 |
| 2. 対応の遅れ | エントリー、イベントの申込、問い合わせへの最初の連絡 | 目安の日を過ぎているもの |
| 3. 終わったイベントの誘導 | 企業ページの誘導の先 | 終わった回への誘導が残っている |
| 4. 選考の流れの変更 | その週に社内で決まった変更 | 掲載に反映されていない |
| 5. 数字の急な変化 | 管理画面で見られる範囲の閲覧やエントリー | 前週から極端に変わった（設定の誤り、掲載の停止など） |

「2. 対応の遅れ」が、毎週の確認で最も重い項目です。これは掲載ではなく運用の問題で、その週に直せます。

### エージェントベストの見解

相談で最も多い思い込みは、「毎週見ているのだから、毎週何かを改善すべきだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を支えていますが、毎週企業ページを直している会社の掲載は、前の月に体験談を書いた学生が読んだものと、今月の学生が読むものが違い、体験談との整合が取れなくなります。新卒の採用は年単位で、体験談は消えません。当社が週次の見直しの型を渡すとき、最初に伝えるのは「毎週は見るだけ。掲載を直すのは、起点が来たときと年度の切れ目」です。毎週見るのは、対応の遅れと新しい体験談で、この二つはその週に気づかないと取り返しにくいものです。見ることと直すことを分けると、毎週は数分で済み、掲載は安定します。

## 週の会の持ち方

- **出る人**：人事一人でよい。複数で開かない
- **時間**：短く。台帳と管理画面を開いて、5つを順に見るだけ
- **順番**：対応の遅れ→新しい体験談→終わったイベントの誘導→選考の変更→数字の急な変化
- **記録**：異常があったかどうかと、その週に対応したことを一行
- **直さない**：掲載の中身に気づいたことは「起点で見る」「年度で見る」と書いて置いておく

「人事一人でよい」が、続けるための条件です。会議にすると、議題を作るために直すことになります。

## その週に対応するものと、回すもの

| その週に対応する | 起点や年度に回す |
|---|---|
| エントリーや申込への連絡の遅れ | 企業ページの中身の見直し |
| 終わったイベントの誘導を外す | 写真の入れ替え |
| 選考の流れの変更を反映する（これは起点でもあり、その週に） | 条件の書き方の見直し |
| 明らかな誤り（閉じた募集への誘導、社名や職種の誤記） | コースの分け方 |
| 体験談の指摘のうち、運用で直せるもの（連絡の速さ） | 体験談の指摘のうち、掲載で補うもの（何を見るか） |
| 設定の誤り（掲載が止まっている、通知が届いていない） | 導線の設計の見直し |

「その週に対応する」の多くは、運用と誤りです。掲載の中身は、回します。選考の流れの変更だけは、起点であると同時に、その週に反映します。起点の考え方は[企業ページを更新し続ける方法](/media/oc-kigyo-page-koushin/)で書きました。

## 選考の時期と、それ以外で週の見方を変える

| 時期 | 週の見方 |
|---|---|
| 選考の時期（エントリーや面接が動いている） | 5つのうち「対応の遅れ」を毎日見る。週の会では、遅れが無かったかを確かめる |
| イベントの時期 | 「終わったイベントの誘導」と「申込への対応」を重く |
| 体験談が増える時期（選考の山のあと） | 「新しい体験談」を重く。増えた分を読み、補うか直すかを分けて記録 |
| それ以外の時期 | 5つを短く。異常が無ければ一行で終える |

「選考の時期は対応の遅れを毎日」が、週の見方の中で最も変わる部分です。週に一度では、遅れに気づくのが遅すぎます。

## 新しい体験談を、週に読むときの姿勢

毎週の確認で新しい体験談を見つけたら、その場で読みます。

- **感想として読まず、材料として読む**：「補う」（掲載）か「直す」（運用）かに分ける
- **「直す」で、その週にできるものはやる**：連絡の速さ、面接の型の共有
- **「補う」は、起点として記録し、年度か次の起点で**：その週に掲載を書き換えない
- **「掲載どおりだった」があれば、記録する**：翌年の判断の材料。[掲載のKPI設計](/media/oc-keisai-kpi/)
- **事実と違う記述は、否定せず、事実を淡々と書く準備を**：これも起点で

「その週に掲載を書き換えない」は、体験談を読んだ直後に特に要ります。書かれたことに反応して直すと、次の体験談との整合が崩れます。

## 記録の残し方

| 残すこと | 使い方 |
|---|---|
| 週ごとの一行（異常の有無、対応したこと） | 月と年度の見直しの材料 |
| 対応の遅れがあった件と、理由 | 運用の改善 |
| 新しい体験談の要点と、補うか直すかの分け | 起点と年度の更新の材料 |
| 「起点で見る」「年度で見る」と置いたこと | 忘れないため |
| 数字の急な変化と、原因 | 設定の誤りの記録 |

記録は、他の媒体の台帳と同じ場所に置きます。年度の見直しで、一年分の一行を並べれば、どの時期にどの異常が出やすいかが分かります。

## 3媒体で、週の見方が違う

| 媒体 | 毎週見るもの |
|---|---|
| OfferBox | オファーの返信と面談の日程、送信のペース。[OfferBoxの週次レビュー](/media/ob-shuukan-review/) |
| Wantedly | スカウトの返信対応、話を聞きに行きたいへの対応、ストーリーの更新の途切れ |
| ワンキャリア | エントリーと申込への対応、新しい体験談、終わったイベントの誘導、選考の変更の反映 |

共通するのは「対応の遅れ」で、媒体ごとに違うのは「その媒体特有の異常」です。ワンキャリアの特有は、新しい体験談と、終わったイベントの誘導です。

### エージェントベストの見解

これをやる前に、先に決めておかないと毎週の見直しが「直す会」になることがあります。「毎週は見るだけ、掲載を直すのは起点と年度」を、人事と上司で合意しておくことです。当社がワンキャリアの運用を支える中で、上司が「今週の数字が下がったのはなぜだ、掲載を直せ」と言い、人事が週ごとに企業ページを直し、体験談とずれていく、という形を見ています。新卒の数字は時期で大きく動き、週の動きに意味は薄いことを、上司に先に伝えてもらいます。合意があれば、週の会は人事一人で数分で終わり、掲載は安定し、年度の見直しで根拠を持って直せます。無ければ、毎週の数字のぶれに掲載が振り回されます。

## まとめ

- 毎週は「直す」ためではなく「異常に気づく」ためだけに短く見る。掲載の中身は、起点と年度の切れ目で直す
- 5つの確認は、新しい体験談、対応の遅れ、終わったイベントの誘導、選考の変更の反映、数字の急な変化
- その週に対応するのは、連絡の遅れ、誘導を外す、選考の変更の反映、明らかな誤り、設定の誤り。掲載の中身は回す
- 週の会は人事一人で、台帳と管理画面を開いて、一行の記録。選考の時期は対応の遅れを毎日見る
- 新しい体験談は、その週に読んで補うか直すかに分けて記録し、その週に掲載を書き換えない。「毎週は見るだけ」を上司と合意する

## よくある質問

### 毎週見ていて、掲載の中身の改善点に気づいたら、すぐ直したくなります

「起点で見る」と書いて置いておきます。起点（選考の変更、体験談の増加、年度の切れ目）が来たときに、溜めた気づきをまとめて直します。その週に直すと、前の体験談との整合が崩れ、次の週にまた別の気づきで直すことになります。溜めて、起点でまとめて直すほうが、掲載が安定します。

### 選考の時期は、週に一度では遅れに気づけません

選考の時期は、対応の遅れだけを毎日見ます。朝に台帳と通知を開き、目安の日を過ぎているものが無いかを確かめます。週の会は、それ以外の4つを見る場にします。時期で見方を変えることが、遅れを防ぎます。

### ワンキャリアの掲載の週次の見直しは、御社に相談できますか

できます。当社は、5つの確認の型、週の会の型、その週に対応するものと回すものの分け方、記録の型を支えられます。連絡すること、体験談を読むこと、選考の変更を反映すること、設定の確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
