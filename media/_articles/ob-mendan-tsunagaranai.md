OfferBoxで、承認はされるのに面談まで進まない、という相談があります。承認から面談までの間には、承認後の連絡、日程の確定、前日の連絡、当日、の四つの段があり、どこで落ちているかで直す場所が違います。**結論から言うと、面談につながらないときは、承認から面談までを「連絡→日程→前日→当日」の4段に分け、台帳で各段の日時を見て、どこで落ちているかを見つけてから直します。連絡の段で落ちるなら速さと候補、日程の段で落ちるなら候補の時間帯と枠、前日の段で落ちるなら前日の一言と来る理由、当日の段で落ちるなら無断欠席への備えと面談の負担、です。承認率が高いのに面談が少ない会社には、共通点があります。** この記事では、4段と落ちる理由、段ごとのサインと直し方、面談の枠と学生の都合、「面談」の言葉の重さ、台帳での見方、共通点、分担を整理します。承認後の返信が来ない場合は[OfferBoxで承認後に返信が来ないときの対応](/media/ob-henshin-konai/)、面談前の連絡は[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)で書きました。この記事は、それらを「どの段で落ちているか」の切り分けとしてまとめたものです。

## この作業の目的｜落ちている段を一つ見つけて、そこだけ直す

「面談につながらない」という症状のまま、文面や企業ページを直しても、原因が日程の段や前日の段にあれば変わりません。

目的は、承認から面談までを4段に分け、台帳で各段の日時を並べ、どの段で学生が落ちているかを一つ見つけ、そこだけを直すことです。段が分かれば、直す場所は一つに絞れます。

## 承認から面談までの、4段

| 段 | 何が起きるか | 落ちる理由 |
|---|---|---|
| 1. 承認後の連絡 | こちらから日程の候補を送る | 遅い、長い、候補が無い、誰が話すかが無い |
| 2. 日程の確定 | 学生が候補から選び、確定する | 候補が学生の都合に合わない、往復が多い、確定の連絡が無い |
| 3. 前日の連絡 | 前日に一言送る | 確定後に連絡が途絶える、前日の一言が無い、来る理由が思い出せない |
| 4. 当日 | 面談に来る | 無断欠席、直前の辞退、面談の負担（来社、長い、面接のよう） |

「承認後の連絡」の段で落ちる学生と、「前日」の段で落ちる学生では、直す場所がまったく違います。

## 段ごとの、見えるサインと直し方

### 1. 承認後の連絡で落ちている

| サイン | 直し方 |
|---|---|
| 承認から連絡までが一日を超えている | 当日に返す。通知を集めて対応する人を一人に。[OfferBoxの即日対応](/media/ob-sokujitsu-taiou/) |
| 連絡に返信が無い | 短く、候補を複数、誰が話すかを一文で。[OfferBoxで承認後に返信が来ないときの対応](/media/ob-henshin-konai/) |
| 返信が「検討します」で止まる | 「選考ではなく、話を聞くだけの場」と伝わっていない |

### 2. 日程の確定で落ちている

| サイン | 直し方 |
|---|---|
| 返信はあるが、日程が決まらない | 候補を学生の都合に合わせて出し直す。平日の日中だけにしない |
| 往復が何度も続く | 「候補から選ぶ」形に。「ご都合を」で聞かない |
| 学生が候補を出しても、こちらが返せない | 話す人の枠を先に確保しておく。[OfferBoxの面談設計](/media/ob-mendan-sekkei/) |
| 確定の連絡が無く、学生が「決まったのか」と迷う | 確定したら、その場で「〇日〇時で確定です。当日は△△が出ます」 |

### エージェントベストの見解

相談で最も多い思い込みは、「面談につながらないのは、学生の志望度が低いからだ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、面談まで進まない学生の台帳を見ると、承認から連絡までに数日空いている、日程の候補が平日の日中だけ、確定後に前日の連絡が無い、という形が続いています。学生の志望度は、承認の時点では「話を聞いてもよい」程度で、それを面談まで連れて行くのは、連絡の速さと候補の出し方と前日の一言です。当社が面談の相談を受けるとき、最初にやるのは、台帳の承認・連絡・確定・当日の日時を並べて、どの段で止まっている学生が多いかを数えることです。段が分かれば、直すのは一か所で、志望度の話にはなりません。

### 3. 前日の連絡で落ちている

| サイン | 直し方 |
|---|---|
| 確定後、当日まで連絡が無く、直前に辞退 | 確定・前日・当日の3回の連絡を型に。[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/) |
| 前日の一言が「明日よろしくお願いします」だけ | 「当日は〇〇が出て、△△の話をします」と、来る理由を思い出せる一言に |
| 確定から当日までが長い | 間が空くなら、途中に一度、読んでおくものを一つ送る |
| 「面談」の言葉で学生が身構えている | 「話を聞く場」「仕事の話をする時間」に言い換える |

### 4. 当日で落ちている

| サイン | 直し方 |
|---|---|
| 無断欠席 | 前日と当日の朝の一言。オンラインの接続方法を前日に。無断欠席への備え（枠を無駄にしない形） |
| 直前の辞退 | 理由を聞ける範囲で聞き、台帳に。時期（試験、他社の選考）が重なっていないか |
| 来社が負担 | オンラインを基本に。[OfferBoxのオンライン面談](/media/ob-mendan-online/) |
| 面談が長い、面接のよう | 短く、選考ではない形に。[OfferBoxの面談設計](/media/ob-mendan-sekkei/) |
| 来たが、その後が無い | 面談後の連絡。[OfferBoxの面談後のフォロー](/media/ob-mendan-go-follow/) |

## 面談の枠が、学生の都合に合っていない

日程の段で落ちる原因の多くは、枠の側にあります。

- **平日の日中だけの枠**：授業がある学生は選べない
- **話す人の枠が少ない**：候補を出せず、往復が増える
- **来社が前提の枠**：遠くの学生は来られない
- **試験期間に候補を出す**：学生が動けない
- **枠を、承認が来てから探す**：確定まで時間がかかる

「夕方以降と授業の無い曜日に、オンラインで、先に確保した枠」が、学生の都合に合う枠です。話す人（入社してまもない社員など）の枠を、週の予定に先に入れておきます。

## 「面談」の言葉が、重く聞こえる場合

学生によっては、「面談」が「面接」に近く聞こえ、身構えます。

- **「話を聞く場」「仕事の話をする時間」「〇〇と話す会」に言い換える**：文面と連絡で
- **「選考ではありません」を、承認後の連絡と前日の連絡に入れる**
- **「短い時間で」「オンラインで」を添える**：負担が小さいことを伝える
- **誰が出るかを、名前で**：「人事」より「入社二年目の〇〇」
- **面談の中身を、企業ページや連絡で先に見せる**：「最初の1年の話をします」

言い換えは、言葉のためではなく、学生の負担の感じ方を変えるためです。中身も、言い換えに合わせます。

## 台帳で、4段の日時を見る

| 残すこと | 使い方 |
|---|---|
| 承認の日時 | 起点 |
| 承認後の連絡の日時 | 1段目の速さ |
| 日程が確定した日時 | 2段目。承認から確定までの間隔 |
| 前日の連絡の有無 | 3段目 |
| 当日の結果（来た・辞退・無断欠席） | 4段目 |
| 落ちた段と、分かる範囲の理由 | 段ごとの数を月で見る |

「どの段で落ちた学生が多いか」を月で数えると、直す場所が一つに絞れます。台帳の型は[OfferBoxのKPI設計](/media/ob-kpi-sekkei/)で書きました。

## 承認率が高いのに、面談が少ない会社の共通点

| 共通点 | 何が起きているか |
|---|---|
| 承認後の連絡を、週に一度まとめて送っている | 承認から連絡までが数日空く |
| 承認の通知が、送った人にだけ届く | 対応する人が決まっていない |
| 話す人の枠を、承認が来てから探す | 確定まで往復が続く |
| 候補が平日の日中だけ | 学生が選べない |
| 確定後、当日まで連絡しない | 前日に落ちる |
| 面談が来社前提で長い | 当日に落ちる |
| 面談後の連絡が無い | 来ても次につながらない |

共通点は、「承認を得るまでは力を入れ、承認のあとは手が薄い」ことです。承認は入口で、面談までの4段が本体です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 台帳で4段の日時を並べ、落ちている段を見つける | 人事 |
| 承認後の連絡を当日に返す | 対応する人（人事） |
| 話す人の枠を、学生の都合に合わせて先に確保する | 話す人と人事 |
| 日程を確定し、確定の連絡を送る | 人事 |
| 前日と当日の一言 | 人事 |
| 面談で話す | 入社してまもない社員 |
| 面談後の連絡 | 人事 |
| 月に一度、落ちた段の数を見て、一か所直す | 人事 |

運用代行や代理店が支えられるのは、4段の切り分けの型、段ごとの直し方の案、連絡の型（承認後・確定・前日・当日）、台帳の型までで、連絡を送ること、枠の確保、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと面談の段で落ち続けることがあります。「話す人の枠を、承認が来る前に、学生の都合に合う時間帯で確保しておく」ことです。当社がOfferBoxで面談につながらない相談を受けるとき、承認後の連絡は当日に送れているのに、日程の候補が平日の日中だけで、学生が選べずに落ちている会社があります。話す人が入社してまもない社員で、本業の合間に枠を出しているので、日中しか出せない。当社が最初にお願いするのは、話す人の上司と、「週に〇〇の枠を、夕方以降にスカウトの面談に使う」と合意してもらうことです。枠が先にあれば、承認後の連絡に候補をすぐ書け、確定までの往復が減り、面談の段で落ちる学生が減ります。連絡の速さと同じくらい、枠の時間帯が効きます。

## まとめ

- 承認から面談までは、承認後の連絡→日程の確定→前日の連絡→当日、の4段。どこで落ちているかで直す場所が違う
- 1段目は速さと候補と誰が話すか、2段目は候補の時間帯と枠と確定の連絡、3段目は前日の一言と来る理由、4段目は無断欠席への備えと面談の負担
- 話す人の枠を、夕方以降や授業の無い曜日に、オンラインで、先に確保しておく。「面談」が重く聞こえるなら「話を聞く場」に言い換え、中身も合わせる
- 台帳で承認・連絡・確定・前日・当日の日時を残し、どの段で落ちた学生が多いかを月で数える
- 承認率が高いのに面談が少ない会社の共通点は「承認のあとは手が薄い」こと。承認は入口で、4段が本体

## よくある質問

### 日程まで確定したのに、当日に来ない学生が多いです

前日の連絡があるかを見ます。確定から当日まで連絡が無いと、学生は他社の予定を優先します。確定・前日・当日の朝の3回、短く連絡し、前日には「当日は〇〇が出て、△△の話をします」と、来る理由を思い出せる一言を入れます。それでも来ないなら、面談の負担（来社、長い、面接のよう）を見直します。

### 話す人の枠が、どうしても平日の日中しか出せません

その枠でも、オンラインで短時間なら、授業の合間に来られる学生はいます。候補を多めに出し、「授業の合間でも構いません。短い時間です」と添えます。ただし、夕方以降の枠が一つでもあると、確定する学生は増えます。話す人の上司と、週に一枠だけ夕方以降に、と合意を取ることを勧めます。

### 面談につながらない問題の切り分けは、御社に相談できますか

できます。当社は、4段の切り分けの型、段ごとの直し方の案、連絡の型、台帳の型を支えられます。連絡を送ること、枠の確保、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
