事業型NPO、寄付型NPO、中間支援組織、社会的企業、地方の小さな団体が、OfferBoxで新卒を採る。NPOは、「ミッションで選ばれ、給与で選ばれない」前提の業界で、学生がオファーを承認する前に確かめるのは、共感できるかではなく、「食べていけるか（待遇の形、昇給の実態）」「活動の実態（日々の仕事は何か、現場と事務の割合）」「この先のキャリア（数年後にどうなっているか、他の場に移れるか）」です。OfferBoxは、企業が学生を検索してオファーを送り、雇用として新卒を採る場で、有給職員の新卒の枠があるNPOには向き、ボランティアとプロボノの募集には向きません。**結論から言うと、NPOのOfferBoxは、有給職員の新卒の枠がある団体が、雇用としての募集に絞って使います。ボランティアとプロボノと副業の募集は、別の入口で。文面は、ミッションへの共感を一度だけ置き、最初に待遇の形（固定か、昇給はどう決まるか、書けない事情があるなら何が書けて何が書けないか）と、一日（現場、事務、助成申請、報告書）と、数年後の像（今いる職員の「入ってからの数年」）を書きます。検索は「社会貢献に関心がある」ではなく、課題に関わった行動と、限られた資源で回した行動の記述で絞ります。共感で承認して待遇と実態で離れる形を、待遇と実態を先に書くことで防ぎます。** この記事では、NPOの採用構造とOfferBoxとの相性、雇用の募集への絞り方、検索とターゲットの設計、オファー文面、面談と内定後、団体内の分担を整理します。媒体の選び方は[NPOの採用媒体の選び方](/media/hikaku-npo-erabikata/)、待遇を書きにくい会社の送り方は[OfferBoxで給与が高くない会社の送り方](/media/ob-kyuuyo-hikui/)で書きました。数値と料金は書きません。

## NPOの採用構造と、OfferBoxとの相性

| 区分 | 採用の形 | OfferBoxとの相性 |
|---|---|---|
| 事業型NPO | 事業収入があり、有給職員を採る。運営と現場 | 向く。待遇の形を書ける。事業と受益者で「なにを」を |
| 寄付型NPO | 寄付と助成で運営。有給は少数、ボランティアが多い | 有給の枠がある年だけ。待遇の実態を隠さず。ボランティアの募集を混ぜない |
| 中間支援組織 | 企画・調整・資金の仕事。「NPO＝現場」の像とずれる | 向く。仕事の実態（企画、調整、事務）を先に |
| 社会的企業 | 株式会社の形。事業と収益 | 向く。事業として書く。「NPOっぽさ」で書かない |
| 地方の小さな団体 | 代表と数人。有給の枠はごく少ない | 枠がある年だけ。一人を、代表の名義で丁寧に |

| 業界の特徴 | OfferBoxで起きること | 設計 |
|---|---|---|
| ミッションで選ばれ、給与で選ばれない | 共感で承認して、待遇で離れる | 待遇の形を先に |
| 有給とボランティアとプロボノが混ざる | 雇用の場にボランティア志望が来る | 雇用の募集に絞る |
| 活動の実態が「社会を変える」で書かれる | 日々の仕事を知らずに承認して離れる | 一日を先に |
| 数年後の像が無い | 「この先」で離れる | 職員の数年を実例で |

## 雇用の募集に絞る｜ボランティアとプロボノと副業は別の入口で

- **有給職員の新卒の枠があるかを、先に決める**：枠が無い年は、OfferBoxで送らない。枠があるなら、何人を、どの役割で
- **ボランティアとプロボノと副業の募集を、OfferBoxで混ぜない**：OfferBoxは雇用として新卒を採る場。混ぜると、雇用の募集にボランティア志望が承認して行き違う
- **有給の募集は、有給として**：待遇、一日、数年後の像。「ボランティア歓迎」を混ぜない
- **副業から有給への道があるなら、それは別の場で**：新卒の雇用の募集とは分ける
- **中間支援組織と社会的企業は、「NPO＝現場」の像とずれることを先に**：「企画と調整と資金の仕事で、現場は〇〇の頻度」
- **送る数を、教えられる数で決める**：少人数の団体が育てられる新卒は少ない。[OfferBoxで送る数のペース](/media/ob-soushin-pace/)

### エージェントベストの見解

これは媒体の向き不向きの話です。NPOから、「OfferBoxで、活動に関わってくれる学生を採りたい」と相談されることがあります。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、OfferBoxが向くのは、有給職員の新卒の枠があるNPOの、雇用としての募集です。ボランティア、プロボノ、副業の関わりを募る場ではなく、そこに混ぜると、雇用の募集にボランティア志望の学生が承認し、面談で行き違います。当社がお願いしているのは、有給職員の新卒の枠があるかを先に決め、あるなら雇用の募集に絞って、待遇の形と一日と数年後の像を先に書いて送ることです。枠がある団体が雇用の募集として使うと、共感だけで承認する学生が減ります。向かない年に使わないことも、設計です。

## 検索とターゲットの設計｜「社会貢献に関心がある」ではなく、課題に関わった行動で

- **「社会貢献に関心がある」「NPOに興味」で検索しない**：関心の言葉は、多くの学生が持っていて、絞れない
- **絞るのは、課題に関わった行動の記述**：「〇〇の課題に、△△の期間関わった」「□□の活動を立ち上げて、続けた」「〇〇の人と直接やり取りした」。[OfferBoxのターゲット設計](/media/ob-target-sekkei/)
- **もう一つ絞るのは、限られた資源で回した記述**：「予算の無い〇〇を回した」「少人数で△△を続けた」「□□が足りない中で〇〇を決めた」。NPOの実態に近い経験
- **自由記述で、「現場と事務の両方」を読む**：現場の活動だけでなく、報告書や申請や連絡を担った経験が書かれている学生を。[OfferBoxのプロフィールの読み方](/media/ob-profile-yomikata/)
- **「終わり方」を読む**：活動を始めた学生は多い。続けた、終わらせた、うまくいかなかった後にどうしたか
- **待遇の像で絞らない**：「安定志向」でも「稼ぎたい」でもなく、行動で

## オファー文面の設計｜共感を一度だけ、待遇と一日と数年後の像を先に

- **ミッションへの共感を、一度だけ**：「なぜ」に事実として。文面の全部をそれで埋めない。[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)
- **最初の一文に、待遇の形を**：「待遇は〇〇の形で、昇給は△△で決まります。□□は書けませんが、〇〇は書けます」。「NPOだから」で伏せない。数値は自団体の実態で。この記事では書かない
- **一日を、先週の一日で**：「先週は〇〇の現場に行き、△△の報告書を書き、□□の助成申請を進めた」。「社会を変える」で済ませない
- **数年後の像を、今いる職員の実例で**：「〇〇で入った△△は、今□□を担っています」。「成長できる」の一語で済ませない
- **事業の状態を、隠さず**：「〇〇の事業が主で、△△は助成で運営している」
- **代表の名義で送る**：小さな団体の採用は代表が決める。代表の「なぜ始めたか」を体験で一文
- **プロフィールの「課題に関わった」記述に、一箇所触れる**：[OfferBoxのオファーをパーソナライズする方法](/media/ob-offer-personalize/)

## 面談と内定後｜「食べていけるか」に、聞かれる前に答える

- **面談で、待遇の形と一日と数年後の像を、聞かれる前に伝える**：文面に書いたことを、代表が本人の言葉で。[OfferBoxの面談の設計](/media/ob-mendan-sekkei/)
- **面談に、代表と、入って数年の職員が出る**：「なぜ」は代表が、「入ってからの数年」は職員が
- **共感の話で面談を終えない**：共感は入口で、決め手は待遇と実態と先の像
- **内定後、事業の状態が変わったら伝える**：助成の結果、事業の変更。伝えずに入社日を迎えると、入った後に知られて離れる。[OfferBoxの内定後フォロー](/media/ob-naitei-follow/)
- **内定から入社までの長さを前提に、連絡の頻度を先に決める**：[OfferBoxの内定辞退を防ぐ考え方](/media/ob-naitei-jitai/)
- **内定者を、現場に一度連れて行く**：入社前に活動の実態を見ると、実態で離れない

## 団体内の分担

| 作業 | 誰が |
|---|---|
| 有給職員の新卒の枠があるかを決め、雇用の募集に絞る | 代表 |
| 待遇の形と事業の状態を、何を書いて何を書けないか決める | 代表 |
| 一日と数年後の像を、職員から聞き取る | 事務局（聞き方の型は外に出せる） |
| 代表の名義で、待遇と一日と数年後の像を先に書いた文面を送る | 代表（下書きは外に出せる） |
| 検索を「課題に関わった」「限られた資源で回した」の記述で絞る | 事務局（絞る作業は外に出せる） |
| 面談に代表と職員が出て、待遇と実態を先に伝える | 代表・職員 |
| 内定後、事業の状態が変わったら伝え、現場に連れて行く | 代表 |

運用代行や代理店が支えられるのは、募集を絞る整理、文面の下書き、検索の絞り込み、送信、一次返信、聞き方の型、内定後フォローの型までで、枠の決定、待遇と事業の状態の開示、代表が話すこと、職員が話すこと、面談、内定後の連絡は団体が行います。代行の範囲は[OfferBoxの運用代行の範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

これは契約後に起きることの話です。NPOが、ミッションへの共感で文面を書いて採り、入った新卒が最初の年に「食べていけるか」と「活動の実態」と「この先」で離れる形を、当社は繰り返し見ています。共感で承認した学生は、「活動そのものが仕事の中心」を期待していて、実態が「現場は一部で、報告書と申請と連絡が大きく、待遇は〇〇の形で、数年後の像が見えない」であることを、入ってから知ります。当社がお願いするのは、文面と面談で「待遇は〇〇の形。一日は△△。〇〇で入った職員は今□□を担っている」と先に伝え、入って数年の職員が「入る前に不安だったこと」と「入ってからの数年」を面談で本人の言葉で話し、内定後に現場に一度連れて行くことです。待遇と実態を知って承認した学生は、最初の年を越えます。共感の一語で集めた学生は、最初の報告書の週で離れます。

## まとめ

- NPOは「ミッションで選ばれ、給与で選ばれない」前提を隠さない。学生が承認の前に確かめるのは「食べていけるか」「活動の実態」「この先のキャリア」で、共感ではない
- OfferBoxは雇用として新卒を採る場。有給職員の新卒の枠がある団体が、雇用の募集に絞って使う。ボランティア・プロボノ・副業の募集は混ぜず、別の入口で。枠が無い年は使わない
- 検索は「社会貢献に関心がある」ではなく、課題に関わった行動と、限られた資源で回した行動と、現場と事務の両方を担った記述で絞る
- 文面は共感を一度だけにし、最初に待遇の形（書けない事情があるなら何が書けて何が書けないか）、一日、数年後の像を職員の実例で、事業の状態を隠さず、代表の名義で
- 面談に代表と入って数年の職員が出て、待遇と実態を聞かれる前に伝える。内定後、事業の状態が変わったら伝え、現場に一度連れて行く

## よくある質問

### 待遇を書くと、承認されなくなりませんか

伏せた文面に共感で承認した学生は、面談で待遇を聞いて離れるか、入った後に離れます。書くと、共感だけで承認する学生は減り、待遇と実態を知った上で承認する学生が残ります。書けない事情があるなら、「〇〇は書けませんが、△△は書けます」と、書けることと書けないことを分けて書いてください。

### ボランティアやプロボノも、OfferBoxで探せますか

OfferBoxは雇用として新卒を採る場で、ボランティアとプロボノの募集には向きません。混ぜると、雇用の募集にボランティア志望の学生が承認して面談で行き違います。関わってくれる学生を探すなら、インターンとイベントと別の入口で。有給の枠が無い年は、OfferBoxで送らない方が、団体にも学生にも合っています。

### NPOのOfferBoxの設計は、御社に相談できますか

できます。当社は、募集を絞る整理、文面の下書き、検索の絞り込み、送信、一次返信、聞き方の型、内定後フォローの型を支えられます。枠の決定、待遇と事業の状態の開示、代表が話すこと、職員が話すこと、面談、内定後の連絡は、団体が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
