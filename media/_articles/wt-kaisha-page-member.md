会社ページに載せるメンバーを、どう選ぶか。「全員を載せるべきか」「経歴が立派な人を載せるべきか」という質問を受けます。**結論から言うと、載せるのは「候補者が自分を重ねられる人」で、経歴の立派さではありません。会社ページの「全てのメンバー」には、採用の権限を持つメンバーの個人アカウントが自動で表示されます。選んで載せるのは、ホームに表示するメンバー（最大4名）です。最初は代表と、話を聞きに来た候補者が最初に会う人の2人をホームに置き、次に配属先の若手、候補者に近い人を足します。ホームに置く人は本人の同意を取り、各自のプロフィールの紹介文は、経歴の羅列ではなく「なぜこの会社に・いま何を・大変なこと」で書いてもらいます。** この記事では、メンバーの位置づけ、最初に載せる人、次に足す人、選ぶ軸、紹介文の型、同意と個人情報、更新、やりがちな失敗、分担を整理します。会社ページ全体は[会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

## この作業の目的｜候補者に「一緒に働く人」を見せる

Wantedlyで候補者が会社ページを読むとき、最も知りたいのは「どんな人と働くか」です。事業の説明やミッションの言葉より、人が見えるかどうかで、「話を聞きに行きたい」が決まります。

メンバーの紹介の目的は、会社の人を全員見せることではなく、候補者が「自分がここで働いたら、この人たちと一緒か」を想像できるようにすることです。想像できれば、話を聞きに来ます。想像できなければ、来ません。

想像できるのは、候補者が自分を重ねられる人です。年齢が近い、前職や学生時代が似ている、同じ職種、同じ悩みを持っていた。そういう人が、なぜこの会社に来て、いま何をしていて、何が大変かを語っていると、候補者は自分を重ねます。

## 手順1｜最初に載せる2人

ホームに表示するメンバーは、最大4名まで選べます。最初に置くのは、2人で足ります。

| 誰 | なぜ |
|---|---|
| 代表 | 「なぜやるのか」を語った人。ミッションの場面の主。ミッションの書き方は[会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/) |
| 話を聞きに来た候補者が、最初に会う人 | 候補者が「この人と話すのか」と分かる。会社ページで読んだ人と、実際に会う人が一致する |

2人目が要点です。会社ページで読んだ人と、実際に会う人が違うと、候補者は「ページの人はどこに」と感じます。OfferBoxの文面で「名義の人が面談に出る」と書いたのと同じ考え方です。名義の考え方は[OfferBoxのオファー文面が書けないときの整理法](/media/ob-bunmen-kakenai/)で書きました。

会社ページには非公開にする機能がなく、編集した内容はすぐに公開されます。この2人が決まれば、まずホームに置きます。残りの枠は、翌週から足します。

## 手順2｜次に足す人

2人を置いたあと、ホームの残りの枠に、順に足していきます。採用の権限を持つメンバーは「全てのメンバー」に自動で表示され、チームに分けて見せることもできます。

1. **配属先の若手**：入社して数年の人。候補者に最も近く、「入社後の自分」を想像させる
2. **募集している職種の人**：募集記事から会社ページに来た候補者が、同じ職種の人を探す
3. **候補者に近い前職や経歴の人**：中途なら前職、新卒なら学生時代の経験が近い人。「自分と同じ道から来た人がいる」
4. **異なる年代や職種の人を1人か2人**：会社の幅が見える。ただし多くしすぎない
5. **バリューの実例に出た人**：バリューの場面で動いた人が紹介にいると、バリューと人がつながる。バリューの書き方は[会社ページでバリューを言葉にする方法](/media/wt-kaisha-page-value/)

「全員を紹介する」を目指さないことも大事です。全てのメンバーは自動で表示されるので、ホームの枠には、候補者が重ねられる人を優先して置きます。候補者が重ねられる人が数人いれば足ります。

### エージェントベストの見解

相談で最も多い思い込みは、「経歴が立派な人を載せると、会社の格が上がって候補者が来る」というものです。実際には、候補者は会社の格ではなく、「自分がここで働けるか」を見ています。当社は採用媒体の代理店として、Wantedlyの契約後の運用を見ています。有名企業出身の役員だけが並んでいる会社ページより、入社して数年の若手が語っている会社ページのほうが、候補者が話を聞きに来ています。若手が語っているのは、「なぜここに来て、いま何をしていて、何が大変か」です。経歴が立派な人の紹介は、候補者に「自分とは違う」と読まれ、重ねる対象になりません。載せるかどうかの軸は、経歴ではなく、候補者が自分を重ねられるかです。役員を載せるなら、経歴ではなく「なぜこの会社に来たか」を書く。それだけで、重ねられる紹介になります。

## 手順3｜選ぶ軸

載せる人を選ぶ軸を、3つに絞ります。

| 軸 | 確かめ方 |
|---|---|
| 候補者が自分を重ねられるか | 募集している職種、年代、前職や学生時代が、候補者に近いか |
| 仕事を語れるか | 「昨日1日、何をしたか」「何が大変か」を、自分の言葉で言えるか。言えない人の紹介は薄くなる |
| 本人が同意しているか | ホームに置くこと、プロフィールの紹介文と写真を見せることに同意しているか。断られたらホームに置かない |

3つ目の「同意」は、軸というより前提です。同意なしに載せると、本人が後で知って不信を持ち、社内の空気が悪くなります。ホームに置く前に、本人のプロフィールの紹介文と写真を一緒に見て「これでよいか」を聞きます。この点は、OfferBoxの企業ページで書いたのと同じです。[企業ページで伝えること](/media/ob-kigyo-page/)で書きました。

## 手順4｜紹介文の型

メンバーの紹介に表示されるのは、各自の個人プロフィール（基本情報、紹介文、職歴など）です。紹介文は本人のアカウントで書くので、人事は型を渡して手伝います。経歴の羅列にはしません。候補者が知りたいのは経歴ではなく、「なぜこの会社に・いま何を・大変なこと」です。

1. **名前と、いまの仕事を一言**：「〇〇。△△の仕事をしている」
2. **なぜこの会社に来たか**：前職や学生時代に何があって、何を見て決めたか。場面で
3. **いま何をしているか**：昨日1日の流れ、いま関わっていること。具体的に
4. **大変なこと**：隠さない。「〇〇が難しい」「△△でよく詰まる」。候補者は、大変なことが書いてある紹介を信じる
5. **候補者へ一言**：「〇〇な人と一緒に働きたい」。バリューの動き方につながる言葉があれば

「大変なこと」を書くのは、紹介文で最も抵抗があり、最も効く部分です。良いことだけの紹介は建前に読まれ、大変なことが1つある紹介は本音に読まれます。

紹介文は、本人が自分のプロフィールに書きます。ただ、白紙から書いてもらうと、経歴の羅列か、謙遜だけになりがちです。人事が本人に聞いて下書きを渡し、本人が直して自分のプロフィールに入れる、が作り方です。会社ページの側で人事が紹介文を書けるかどうかは、管理画面と公式ヘルプで確認してください。

## 手順5｜同意、個人情報、更新

載せるときの決め事です。

- **同意は、紹介文と写真を見せてから取る**：「載せてよいか」だけでなく、「この内容でよいか」
- **写真は仕事中の場面で**：集合写真より、働いている姿。顔が見えるもの。本人が嫌なら顔を出さない形も可
- **個人が特定される情報は、本人が望む範囲で**：出身校、前職の社名、年齢。本人が出したくないものは出さない
- **異動や退職のときに、ホームの表示を差し替える**：紹介した人がいなくなった会社ページは、候補者に古さが伝わる。差し替えの担当と時期を決める
- **紹介文の「いま何をしているか」は、数ヶ月に一度見直す**：仕事が変わっていれば直す

「差し替え」が、見落とされやすい点です。作って半年後に、紹介した若手が異動している。候補者が面談で「〇〇さんは」と聞き、「異動しました」と答える。この状態は、会社ページの信頼を落とします。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 全員の紹介を揃えるまでホームを空けておく | 中身の薄いページが見られ続ける | 2人をホームに置き、翌週から足す |
| 経歴が立派な人だけを載せる | 候補者が自分を重ねられない | 配属先の若手、候補者に近い人を |
| 会社ページの人と、実際に会う人が違う | 「ページの人はどこに」 | 最初に会う人を載せる |
| 紹介文が経歴の羅列 | 人が見えない | なぜ来たか・いま何を・大変なこと |
| 良いことだけの紹介 | 建前に読まれる | 大変なことを1つ |
| 本人に白紙から書いてもらう | 羅列か謙遜になる | 聞いて下書きを渡し、本人が直して入れる |
| 同意を取らずにホームに置く | 本人が不信を持つ | 内容を見せてから同意 |
| 異動した人が残っている | 古さが伝わる | 差し替えの担当と時期を決める |

最も多いのは、「全員の紹介を揃えるまで待つ」と「紹介文が経歴の羅列」です。前者は速さ、後者は質を止めます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| ホームに置く人を選ぶ | 人事（募集している職種と候補者の像から） |
| 本人にホームに置いてよいか聞く | 人事（上司を通してもよい） |
| 紹介文の材料を聞く | 人事（本人に「なぜ来たか」「昨日1日」「大変なこと」を聞く） |
| 紹介文の下書きを書く | 人事 |
| 本人が直して自分のプロフィールに入れ、同意する | 本人 |
| 写真の手配と同意 | 人事と本人 |
| 差し替えと見直し | 人事（異動と退職の情報を受けて） |

本人の負担は、「聞かれて答える」「直してプロフィールに入れる」「写真に写る」の3つです。下書きは人事が書きます。運用代行や代理店が支えられるのは、紹介文の型と、聞く質問の用意、書いた紹介文の整理までで、本人に聞くことと同意は企業が行います。

### エージェントベストの見解

これをやる前に、先に決めておかないとメンバーの紹介が機能しないことがあります。「話を聞きに来た候補者が、最初に会う人」を決めることです。当社がWantedlyの運用の相談で会社ページを見るとき、メンバーの紹介は充実しているのに、実際に候補者と会うのはホームにいない人事、という会社があります。候補者は、会社ページで読んだ人と会えると思って来て、違う人が出てくると「読んだ人はどこに」と感じます。当社が勧めるのは、載せる人を選ぶ前に、「話を聞きに来た候補者に、最初に誰が会うか」を決め、その人を、代表でなくてもよいので、2人目としてホームに置くことです。会う人が決まれば、載せる人も決まり、面談の名義も決まります。会社ページのメンバーと、面談に出る人の一致は、Wantedlyの入口で最初に揃えることです。

## まとめ

- 載せるのは、候補者が自分を重ねられる人。経歴の立派さではない
- ホームに表示するメンバー（最大4名）は、最初は代表と「最初に会う人」の2人から。配属先の若手、募集職種の人、候補者に近い人を翌週から足す。採用の権限を持つメンバーは「全てのメンバー」に自動で表示される
- 紹介文は各自のプロフィールで「なぜこの会社に・いま何を・大変なこと」。人事が聞いて下書きし、本人が直して入れる
- 同意は、紹介文と写真を見せてから取る。個人が特定される情報は本人が望む範囲で
- 異動と退職で差し替え、「いま何を」は数ヶ月に一度見直す

## よくある質問

### 社員が少なく、載せられる人がいません

代表と、最初に会う人の2人をホームに置けば足ります。2人が同じ人（代表が面談に出る）なら、代表1人でも構いません。その場合、代表の紹介文を「なぜこの事業を・いま何を・大変なこと」で書き、ミッションの場面とつなげます。人数より、その人が語れているかです。

### 本人が「載せたくない」と言います

ホームには置きません。同意の無い紹介は、本人の不信と社内の空気の悪化につながります。採用の権限を持つメンバーは「全てのメンバー」に自動で表示されるので、プロフィールの公開範囲や見え方も本人と一緒に確認します。ホームには別の人を選びます。

### メンバーの紹介文は、御社に頼めますか

型と、本人に聞く質問と、聞いた内容の整理は当社が行えます。本人に聞くことと、同意を取ることは、企業の人事にお願いしています。当社は採用媒体の代理店として、Wantedlyの会社ページの整備を支えています。
