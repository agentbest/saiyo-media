NPO法人や非営利の団体が、新卒を職員として採る。事務局は少人数で、採用の経験は少ない。ミッションに共感する学生に来てほしいが、給与では企業と並べず、「この仕事で食べていけるのか」を学生も家族も心配している。媒体を選ぶときに、「社会課題に関心のある学生が集まる媒体はどれか」で考えがちですが、学生が確かめているのは、関心の一致ではなく、働き続けられる実態です。**結論から言うと、NPOは「ミッションで選ばれ、給与で選ばれない」前提を隠さず、学生が確かめる「食べていけるか」「活動の実態」「キャリアの道」「財源が続くか」に先に答えます。媒体は、ミッションを理念ではなく場面で書ける団体は記事を置く型を、少人数で書く時間がない団体は企業から送る型を先に検討し、学生が並べて比べる場は候補に入ってから足します。** この記事では、NPOの採用構造、判断軸の当て方、学生が確かめること、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## NPOの採用構造と、媒体との相性

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| ミッションで選ばれ、給与で選ばれない | 関心のある学生は来るが、条件を確かめて離れる | 条件を隠さず、ミッションを場面で書ける媒体の使い方が要る |
| 事務局が少人数で、採用の経験が少ない | 代表か事務局長が採用。型がない | 作業を外に出せる型か、書く時間を取れる型か |
| 財源が寄付・助成・事業で、続くかの不安 | 学生と家族が「団体が続くか」を確かめる | 財源の構造を、数値でなく仕組みで書けるか |
| 活動の実態が、外から見えにくい | 「何をしている団体か」が理念でしか伝わらない | 活動の場面を書く・見せる媒体の使い方 |
| 新卒採用の経験が少ない | 内定から入社まで、インターンやボランティアとの違いが曖昧 | 雇用としての条件と、関わりとしてのインターンを分ける |
| 知名度は、活動の分野の中に限られる | 学生は団体名で探さない | 送る型か記事を置く型で、まず知ってもらう |

NPOの採用は、「関心のある学生に会えるか」より、「会えた学生に、働き続けられる実態を正直に伝えられるか」で決まります。媒体は、その伝え方に合うものを選びます。

## 判断軸を、NPOに当てる

| 軸 | NPOでの見方 |
|---|---|
| 対象（誰に届くか） | 「社会課題に関心のある学生」は、企業のCSRや社会的な事業も見ている。NPOに来るのは、活動の実態と条件を知ったうえで選ぶ学生 |
| 型（送るか、来るか、比べられるか） | 送る型は、記述の行動（活動の経験、続けた経験）で絞れる。来る型は、ミッションを場面で書けるかで届く。比べられる型は、学生の候補に入ってから |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。予算が取れない年は、媒体を使わない判断も。[予算がほぼ取れない会社の採用媒体](/media/hikaku-yosan-nai/) |
| 運用工数（誰の時間が要るか） | 事務局の時間が上限。送る型は作業を外に出せる。来る型は、代表か職員が場面を話す時間が要る |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。NPOでは、「共感型」と相性がよいと考えられがちですが、共感だけで来た学生は条件で離れるので、条件を隠さない前提が先です。

### エージェントベストの見解

相談で最も多い思い込みは、「ミッションに共感する学生を集める媒体を選べば、給与の話は二の次でよい」というものです。当社は3媒体すべての販売パートナーとして、NPOや非営利の団体の相談を受けますが、共感で集めた学生が、面談や内定のあとに「給与は」「続けられますか」「家族に説明できますか」と聞き、答えが曖昧で離れる、という形が多くあります。学生は、ミッションに共感していないのではなく、共感したうえで、働き続けられるかを確かめています。当社がNPOに媒体の前に用意してもらうのは、条件（給与の範囲、雇用の形、休み）、財源の仕組み（寄付・助成・事業のどれで、どう続けているか）、キャリアの道（数年後に何を任され、辞めたあとにどう活きるか）の三つを、隠さず書いた一枚です。一枚があれば、どの媒体でも、共感した学生が「それでも来る」と決められます。一枚がないまま共感だけで集めると、離れる学生が増えます。

## 学生が、確かめること

- **食べていけるか**：給与の範囲、雇用の形（正職員か、契約か）、昇給の仕組み。家族に説明できるか。数値は各団体の実態で。この記事では書かない
- **活動の実態**：日々、何をしているか。事務、現場、資金集め、広報。理念ではなく、一日の場面
- **キャリアの道**：数年後に何を任されるか。辞めたあとに、NPOでの経験がどう活きるか
- **財源が続くか**：寄付・助成・事業の構造。「来年も団体があるか」の不安
- **代表はどんな人か**：少人数の団体は、代表との相性が大きい
- **インターンやボランティアと、職員の違い**：雇用としての新卒採用であることを、はっきりと

## この条件なら、どれを先に検討するか

| 団体の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 代表や職員が、ミッションを理念ではなく活動の場面で書ける・話せる | 通年で記事を置く型（Wantedly） | 活動の実態と考え方を読んで、条件を知ったうえで来る学生に届く。記事が残る |
| 事務局が少人数で、書く時間がないが、「こんな人」（活動の経験、続けた経験）が絞れる | 企業から送る型（OfferBox） | 作業を外に出せ、代表は面談だけ。記述の行動で絞れる |
| 分野で知られていて、学生の候補に入り、選考の流れを透明に出せる | 学生が並べて比べる場（ワンキャリア） | 比べる対象に入ってから。NPOで先にすることは少ない |
| インターンやボランティアの関わりが先にある | 関わりから職員へ | 関わった人の中から。媒体は関わりの入口として |
| 条件の一枚が、まだない | どれも先ではない | 一枚を作ってから |

どれか一つが正解ではなく、書けるか、絞れるか、候補に入っているかで、先に検討するものが変わります。

## 組み合わせ

- **記事を置く型と送る型を組み合わせるなら**：記事で活動の場面と条件を、文面で「あなたの〇〇の経験を読んで」を。承認した学生が記事を読む。[WantedlyとOfferBoxの併用](/media/wt-heiyou-offerbox/)
- **インターン・ボランティアと組み合わせるなら**：関わりの中で活動の実態を見てもらい、合った人に職員の話を。雇用と関わりの線を、自社の方針と制度の確認のうえで引く
- **一年目は一つ**：事務局の時間が足りるかを一年目で見る。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)
- **時期は、活動の繁忙（イベント、助成の申請）の外に**

## 見せ方｜理念ではなく、場面と条件

- **ミッションを、理念の文章ではなく、活動の場面で**：「〇〇の人に、△△を届けた日」の一場面。書き方は[Wantedlyの会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/)
- **条件を、最初に、隠さず**：給与で選ばれない前提だからこそ、条件を後ろに置かない。[給与水準を強みにできない会社のOfferBoxの伝え方](/media/ob-kyuuyo-hikui/)
- **財源の仕組みを、数値ではなく構造で**：「寄付と助成と事業の三つで、〇〇の形で続けている」
- **キャリアの道と、辞めたあとの道を**：「数年後に△△を任せる」「辞めた人は□□に進んでいる」
- **「やりがい」「社会貢献」の一語で済ませない**：企業も同じ言葉を使う。場面で
- **職員とインターン・ボランティアの違いを、はっきり**：雇用としての採用であること
- **業界イメージ（給与が低い、不安定）を否定しない**：事実は認め、実態と仕組みを書く。[業界イメージが不利な会社のWantedlyの書き方](/media/wt-gyokai-image/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 条件・財源の仕組み・キャリアの道の一枚 | 代表と事務局長 |
| 書けるか・絞れるか・候補に入っているかで、先に検討する型を決める | 代表（整理は代行が支える） |
| 「こんな人」の一行（活動の経験、続けた経験） | 代表と職員 |
| 送る型なら、検索・下書き・送信・一次返信 | 代行 |
| 記事を置く型なら、代表と職員が場面を話し、整えるのは外に | 代表・職員と代行 |
| 面談 | 代表と、一緒に働く職員 |
| 内定後の連絡、家族への説明の材料 | 代表 |
| 雇用と関わり（インターン・ボランティア）の線 | 代表。専門家の助言を受けて |

- **事務局の時間は、一枚と面談に**：作業は外に。[運用代行に出す前提の媒体の選び方](/media/hikaku-daikou-zentei/)
- **専任の人事がいない団体の窓口の決め方**：[専任の人事がいない会社のOfferBox運用](/media/ob-jinji-fuzai-unyou/)

運用代行や代理店が支えられるのは、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分までで、一枚の中身、財源とキャリアの道の開示、面談、雇用と関わりの線は団体が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

同じNPOでも、代表や職員が「先週、〇〇で△△があった」と活動の場面を自分の言葉で話せる団体には、Wantedlyで通年の記事を置く型を先に検討することを勧め、事務局が少人数で書く時間がないが「活動を続けた経験のある学生」と絞れる団体には、OfferBoxで企業から送る型を先に勧めることが多いです。理由は、NPOに来る学生は、活動の実態を読んで、条件を知ったうえで選ぶので、場面が書ける団体では記事が最も届き、書けない団体では記述の行動で絞って送るほうが、事務局の時間を面談に残せるからです。ワンキャリアのように学生が並べて比べる場は、分野で知られ、候補に入っている団体から検討し、NPOで先にすることは多くありません。当社は3媒体すべての販売パートナーとして、団体の「書けるか」「絞れるか」で分けて提案しています。

## まとめ

- NPOは「ミッションで選ばれ、給与で選ばれない」前提を隠さない。学生が確かめるのは「食べていけるか」「活動の実態」「キャリアの道」「財源が続くか」で、共感の一致ではない
- 媒体の前に、条件・財源の仕組み・キャリアの道を隠さず書いた一枚を作る。一枚があれば、どの媒体でも「それでも来る」学生が決められる
- ミッションを場面で書ける団体は記事を置く型を、少人数で書く時間がないが「こんな人」が絞れる団体は企業から送る型を先に。並べて比べる場は候補に入ってから
- 見せ方は理念ではなく場面と条件。「やりがい」「社会貢献」の一語で済ませず、職員とインターン・ボランティアの違いをはっきりと
- 事務局の時間は一枚と面談に、作業は外に。一年目は一つ、時期は活動の繁忙の外に

## よくある質問

### 給与を書くと、応募が減りませんか

減ります。減るのは、条件を知ったら来ない学生で、内定のあとに離れる学生です。書いて承認・応募した学生は、条件を知ったうえで来ていて、離れません。NPOの採用で要るのは、共感した学生の数ではなく、条件を知って「それでも来る」学生です。数値の中身は各団体の実態で、この記事では書きません。

### インターンやボランティアで関わっている学生を、そのまま職員にしたいです

関わりの中で活動の実態を見ている学生は、条件を知ったうえで決めやすく、無理のない形です。ただし、関わりと雇用の線（報酬、時間、指揮、契約）を、自社の方針と専門家の助言を受けて分け、職員としての条件を一枚で渡します。関わりの延長で曖昧に雇用すると、あとで「聞いていない」になります。

### NPOの媒体選びは、御社に相談できますか

できます。当社は、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分を支えられます。一枚の中身、財源とキャリアの道の開示、面談、雇用と関わりの線は、団体が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
