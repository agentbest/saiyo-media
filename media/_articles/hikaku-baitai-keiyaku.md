採用媒体を契約する。見積もりを受け取り、金額を見て、稟議に上げる。ところが、契約の型と期間を見ずに金額だけで決め、自動更新の解約の期限を過ぎて次の期間の請求が来て、「途中でやめられる」と思い込み、含まれていないものを後から知り、送れる数の枠を確認せず、切り替えのときにデータを持ち出せず、担当が変わって契約の中身が誰にも分からない。**結論から言うと、金額の前に「契約の型・期間と更新・やめ方・含まれるもの・前提条件・契約の相手と請求・データの扱い・担当交代」の八つを、契約書と見積もりと管理画面のヘルプで確認します。自動更新の解約の期限は、契約時にカレンダーに入れます。代理店経由でも料金は変わらず、確認する項目も同じです。分からない項目は、「確認した日と相手」を残します。** この記事では、契約で起きる失敗、八つの項目、契約の型ごとの注意、更新とやめ方、代理店経由の確認、ヘルプで確認すること、稟議、契約後の記録、分担を整理します。金額や料金はこの記事では扱いません。代理店との契約は[代理店との契約の流れ](/media/kh-dairiten-keiyaku/)、見積もりの見方は[代理店の見積もりの見方](/media/kh-dairiten-mitsumori/)、料金の仕組みは[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)で書きました。

## この作業の目的｜契約の「中身」を、金額の前に確かめる

契約で後から困ることの多くは、金額ではなく、「型・期間・やめ方・含まれるもの・前提」を確認していなかったことで起きます。金額は見積もりに書かれていて見落としませんが、それ以外は書かれていないか、書かれていても読まれません。

目的は、契約の前に八つの項目を確認し、契約後にも「誰が、いつ、何を確認したか」が残る状態にすることです。

## 契約で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 金額だけ見て、型と期間を見ない | 定額か決まったときに発生するか、期間がいつまでかを知らずに始め、費用の発生に驚く |
| 自動更新の期限を、過ぎる | 更新しないつもりだったのに、次の期間の請求が来る |
| 途中でやめられると、思い込む | 途中でやめられない契約で、費用だけ残る |
| 含まれるものを、確認しない | 「代行は別」「更新は別」を後から知る |
| 前提条件を、見ない | 送れる数の枠、職種の数、掲載できる数の上限を知らずに計画を立てる |
| データの扱いを、確認しない | 切り替えのとき、台帳や学生の情報を持ち出せない |
| 担当交代で、契約の中身が分からない | 更新の時期も、やめ方も、誰も知らない |

共通するのは、契約を「金額を承認する手続き」として扱い、「中身を確認する作業」として扱っていないことです。

## 確認する、八つの項目

| 項目 | 確認すること | どこで |
|---|---|---|
| 1. 契約の型 | 定額か、決まったときに費用が発生するか、掲載期間か、回ごとか。発生の条件 | 見積もりと契約書 |
| 2. 期間と更新 | いつからいつまで。自動更新か都度更新か。更新の通知は誰から、いつ | 契約書 |
| 3. やめ方 | 解約の期限（いつまでに、誰に）。方法（書面・メール・管理画面）。途中でやめられるか、その条件 | 契約書 |
| 4. 含まれるもの | 媒体の利用の範囲、代行の有無と範囲、更新の費用、サポートの範囲 | 見積もりを行ごとに |
| 5. 前提条件 | 送れる数の枠、職種の数、掲載できる数、アカウントの数、使える機能 | 見積もりと管理画面のヘルプ |
| 6. 契約の相手と請求 | 媒体と直接か、代理店と契約か。請求元、支払いの時期、単位 | 契約書 |
| 7. データの扱い | 学生の情報、台帳、送った文面が、契約後・切り替え後にどう扱われるか。持ち出せるか | 契約書と管理画面のヘルプ |
| 8. 担当交代 | 契約の窓口が変わったときの手続き。管理画面のアカウントの引き継ぎ | 契約書と管理画面のヘルプ |

八つを、契約の前に一つずつ確認し、確認した日と相手を残します。現在の仕様は、管理画面とヘルプで確認してください。

### エージェントベストの見解

相談で最も多い思い込みは、「契約は媒体の書式で決まっているから、確認しても変わらない」というものです。当社は3媒体すべての販売パートナーとして、契約の窓口を多く持っていますが、契約の中身が変わらなくても、「確認したか」で後の困りごとは変わります。自動更新の解約の期限を過ぎて次の期間の請求が来た会社は、契約時に期限を知らなかったか、知っていてもカレンダーに入れていなかったかで、どちらも「確認して記録する」で防げます。当社が契約の窓口になるとき、契約の前に八つの項目を一緒に確認し、解約の期限と更新の通知の時期を、企業のカレンダーに入れてもらうことをお願いしています。それが、当社の窓口としての仕事の一つです。

## 契約の型ごとの、注意

- **定額（期間で発生）**：期間の途中でやめられるか。送る数の枠。期間の開始と、管理画面が使える時期
- **決まったときに費用が発生**：「決まった」の定義（内定か承諾か入社か）。発生の時期。辞退した場合の扱い。自社の制度と管理部門で確認
- **掲載期間で発生**：掲載できる数と更新の回数。期間の途中の追加
- **回ごとに発生**：回の中止・変更の条件。参加者数の下限
- **複数の型を組み合わせた契約**：どの部分がどの型か、行ごとに。[代理店の見積もりの見方](/media/kh-dairiten-mitsumori/)の「見方1｜行ごとに分ける」
- **型の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」と[定額型と成功報酬型の媒体の違い](/media/hikaku-teigaku-vs-seika/)**

## 更新と、やめ方

| 項目 | 確認すること |
|---|---|
| 契約期間 | いつからいつまでか |
| 更新の方式 | 自動更新か、都度更新か |
| 更新の通知 | 期間の終わりの前に、誰から、いつ通知が来るか |
| 解約の期限 | 解約するなら、いつまでに、誰に伝えるか |
| 解約の方法 | 書面か、メールか、管理画面か |
| 途中解約 | できるか。できる場合の条件 |
| 代理店を変える場合 | 媒体との契約を残したまま、代理店だけ変えられるか |

自動更新の契約で、解約の期限を過ぎる相談は、代理店経由に限らず起きます。契約時に、解約の期限をカレンダーに入れます。やめる判断そのものは[媒体をやめる判断基準](/media/hikaku-baitai-tettai/)、切り替えの時期は[媒体を切り替えるタイミングの判断](/media/hikaku-baitai-kirikae/)で書きました。

## 代理店経由の場合の、確認

- **企業が払う料金は、媒体の正規の料金**：代理店の手数料は媒体の側から出る。[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)
- **契約の相手が、媒体か代理店か**：どちらでも金額は正規料金。請求元と支払いの時期が変わる
- **代行の費用が含まれているか**：含まれるなら、何をどこまでか。「料金が変わったように見える」最も多い原因
- **複数媒体の請求のまとめ方**：一つにまとめられるか
- **代理店を変えるときの、媒体との契約の扱い**：[代理店を切り替えるときの手順](/media/kh-dairiten-kirikae/)の「媒体との契約が残るかを確認する」
- **契約の流れは[代理店との契約の流れ](/media/kh-dairiten-keiyaku/)**

## 管理画面のヘルプで、確認すること

- **送れる数の枠と、枠の更新の仕組み**
- **職種・募集・掲載の数の上限**
- **アカウントの数と、担当交代の手続き**
- **年度の切り替えの扱い**：前の卒年と次の卒年のデータ
- **契約終了後の、管理画面とデータの扱い**：いつまで見られるか、持ち出せるか
- **仕様は変わる**：契約時に確認した内容と日付を残し、更新時に再確認

## 社内の稟議に、要るもの

- **見積もり（行ごとに分かれたもの）**
- **契約書の案（型・期間・更新・やめ方が書かれた部分）**
- **八つの項目の確認の記録（確認した日と相手）**
- **前提条件（送れる数の枠、職種の数）と、自社の計画の対応**
- **解約の期限と更新の通知の時期**
- **稟議の書類の考え方は[代理店との契約の流れ](/media/kh-dairiten-keiyaku/)の「社内の稟議に必要な書類」**

## 契約後に、残す記録

- **契約書と見積もりの保管場所**
- **八つの項目の確認の記録**：担当が変わっても読める形で
- **解約の期限と更新の通知の時期を、カレンダーに**：担当と上司の両方に
- **管理画面のアカウントと、引き継ぎの手順**
- **契約の窓口（媒体か代理店か）と、連絡先**
- **担当交代の引き継ぎは[OfferBoxの担当が交代するときの引き継ぎ](/media/ob-tantousha-koutai/)**

### エージェントベストの見解

これはどこまでやるかの線引きの話です。当社は3媒体の契約の窓口になりますが、契約の条件そのもの（料金、期間、解約の条件）は媒体が決めるもので、当社が変えることはできません。当社ができるのは、八つの項目を契約の前に一緒に確認し、分からないものを媒体に確認し、解約の期限と更新の通知を企業と共有し、更新の前に「更新しますか」と声をかけることまでです。「代理店なら条件を良くできる」と期待されることがありますが、料金は正規料金のまま、条件も媒体の条件のままで、当社が支えるのは「確認と記録と、期限の前の声かけ」です。それでも、この三つがあるかないかで、契約で困る会社の数は変わります。

## まとめ

- 契約で困るのは金額ではなく、型・期間・やめ方・含まれるもの・前提条件・契約の相手と請求・データの扱い・担当交代の八つを確認していないこと。金額の前に八つを確認する
- 契約の型（定額・決まったときに発生・掲載期間・回ごと）ごとに注意が違う。「決まった」の定義、途中解約の可否、枠の上限を契約書と見積もりとヘルプで
- 自動更新の解約の期限は、契約時にカレンダーに入れる。更新の通知が誰からいつ来るかも確認する
- 代理店経由でも料金は正規料金で、確認する項目も同じ。代行の費用が含まれるかが「料金が変わったように見える」最も多い原因
- 確認した日と相手を残し、契約書・見積もり・アカウント・窓口を担当が変わっても読める形で保管する。更新時に八つを再確認する

## よくある質問

### 契約書の内容が難しく、どこを見ればよいか分かりません

八つの項目を、契約書の中で「どこに書かれているか」を印を付けながら探します。見つからない項目は、契約の相手（媒体か代理店）に「この項目はどこに書かれていますか」と聞き、答えと日付を残します。全部を読もうとせず、八つを探す読み方にすると、短い時間で済みます。法務・経理の確認は管理部門に。当社が窓口なら、八つを一緒に探します。

### 前の担当が結んだ契約の中身が分からず、更新の時期も不明です

契約の相手（媒体か代理店）に、契約書の写しと、期間・更新・解約の期限を確認します。管理画面のヘルプで、アカウントの引き継ぎと契約の状態を確認します。分かった時点で、八つの項目を記録し直し、解約の期限をカレンダーに入れます。前の担当の記録がないなら、今回が「記録を作る最初の契約」です。引き継ぎの型は[OfferBoxの担当が交代するときの引き継ぎ](/media/ob-tantousha-koutai/)で書きました。

### 媒体の契約の確認は、御社に相談できますか

できます。当社は、八つの項目の確認の型、見積もりの行ごとの整理、契約の型の説明、更新と解約の期限の共有、契約の窓口を支えられます。契約の判断、法務・経理の確認、カレンダーへの登録、記録の保管は、企業が行ってください。金額と契約の条件は見積もりと契約で確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の契約の窓口と運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
