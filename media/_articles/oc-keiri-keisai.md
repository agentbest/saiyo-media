ワンキャリアで新卒の経理・財務を募集したとき、最初にぶつかるのは「『経理・財務』『管理部門総合職』と掲載したのに、簿記を持つ学生が『大手の経理』の体験談と比べて『この会社は何をどこまでやるのか』が分からず、面接で『決算はどうなりますか』『財務もやるのですか』と聞かれ、入社後に『伝票の入力だけだった』『決算期は聞いていた話と違った』と体験談に書かれる」という問題です。**結論から言うと、ワンキャリアの経理・財務の掲載は、「経理・財務」の名前ではなく「社内でどこまでやり、どこから税理士や会計士か、月の締めと決算で何が起きるか、最初の年に何を任せ、簿記が無くても採るか、経理の先の道があるか」を、学生が体験談で読む前に企業ページと募集に書き、決算期の実態を面接で先に話します。** 「経理業務全般」を範囲で書き直す考え方は[Wantedlyで経理を採る募集記事の書き方](/media/wt-keiri-boshu/)、事務系の掲載は[ワンキャリアで事務職を募集するときの掲載とスカウト](/media/oc-jimu-keisai/)と共通です。この記事は新卒の経理・財務に絞り、掲載とスカウトと選考をつなげて書きます。

## 経理・財務志望の学生が、体験談で読んでいること

学生は、企業ページを読む前に、大手の経理の体験談を読んでいます。大手の体験談は「経理は分業で、最初は一つの科目」と書かれているため、学生は「この会社は分業か、一人で全部か」を確かめています。

| 読んでいること | 掲載への意味 |
|---|---|
| 経理か財務か | 記帳と決算か、資金と銀行か。「経理・財務」の名前では分からない |
| 社内でどこまでやるか | 決算まで社内か。税理士や会計士にどこから頼むか。分業か一人か。体験談で最も書かれる |
| 月の締めと決算の実態 | 月末と決算期に何時まで働くか。何日続くか |
| 最初の年に何を任されるか | 伝票の入力か、一つの科目か、月次の一部か。誰が見るか |
| 簿記が無くても採るか | 簿記を持たずに入った人がいるか。入社後に取るか |
| システムか手作業か | 何のシステムか。紙と表計算が残っているか |
| 経理の先の道 | 経理のまま深くなるのか、財務や経営企画へ行けるか。何人が行ったか |
| 先輩の実態 | 最初の年に何を任され、いま何をしているか |

「社内でどこまでやるか」と「決算の実態」が、経理・財務の体験談で最も読まれ、企業ページで最も書かれない項目です。

## 掲載に書くこと｜範囲、締めと決算、最初の年、簿記、システム、先の道

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「経理・財務」ではなく「月次と決算を社内でやる経理」「資金と銀行を担う財務」。分けて出す |
| 社内でどこまでやるか | 「月次と決算の数字は社内で作り、申告は税理士。〇人の経理で、科目は分けずに全員が見る」。分業か一人かを |
| 月の締めと決算 | 「月末から〇日間は帰りが△時ごろ。決算期は□週間、休日に出ることがあり、代休を取る」。良く見せない |
| 最初の年 | 「最初の〇か月は伝票の入力と照合。△△か月目に一つの科目の月次を、先輩の確認付きで。決算は□年目から一部」 |
| 簿記の扱い | 「簿記を持たずに入った人が〇人。入社後の△か月で□級を取る。費用は会社」。必須なら、必須と |
| システム | 「使うのは□□。紙の伝票は無い」。残っているなら、残っていると |
| 経理の先の道 | 「経理から財務へ行った人が〇人、経営企画へ△人。経理のまま責任者になった人が□人」 |
| 先輩の話 | 最初の年に何を任され、決算期に何をしたか。盛らない |

企業ページには社内でどこまでやるかと経理の先の道を、募集には経理か財務かと締めと決算と最初の年を、と分担します。

### エージェントベストの見解

経理・財務の募集で、ワンキャリアが向いている会社と向いていない会社があります。当社は3媒体すべての販売パートナーとして、経理・財務の掲載と選考を見ていますが、ワンキャリアの学生は、大手の経理の体験談を基準に読みます。ワンキャリアが向いているのは、「大手と違って、分業ではなく、決算までを少人数で見る」ことを、弱みではなく実態として書ける会社です。少人数で決算まで見る経理は、大手の分業の経理と違い、最初の年から数字の全体が見えます。それを「大手のように整っていない」と隠して「経理業務全般」と書くと、体験談に「伝票の入力だけだった」と書かれ、次の年の学生が離れます。逆に、「〇人で決算まで社内で見る。科目は分けない。最初の年から月次の全体を見る」と書いた会社は、大手の体験談を読んだ学生に「分業でない経理」として選ばれ、体験談に「一年目から決算に触れた」と書かれます。当社が最初に確かめるのは、「少人数で決算まで見る」を実態として書けるかです。書けるなら、ワンキャリアに向いています。

## 経理・財務志望の学生の見つけ方

簿記の資格で絞ると、資格を持たない学生の行動が読めません。資格はあればよい条件にします。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 資格 | 簿記〇級 | あればよい条件。資格で絞らない |
| 学科 | 商学、経済、それ以外 | あればよい条件。学科で絞らない |
| お金を扱った経験 | 「サークルの会計で、〇人分の集金と支払いを管理した」 | 経理の行動。優先 |
| 合わなかったときの経験 | 「残高が合わず、原因を一つずつ調べて見つけた」 | 照合の行動。最も重い |
| 決まりを作った経験 | 「精算の締め日と書式を決めて、遅れを無くした」 | 締めの仕事と重なる |
| 締め切りを守った経験 | 「月末の締めを毎月、遅れずに出した」 | 月の締めと重なる |
| 人に説明した経験 | 「お金の使い方を、メンバーに数字で説明した」 | 経理の先の道と重なる |

「集金と支払いを管理した・合わなかったとき原因を見つけた・締め日を決めた」を書いている学生が、経理・財務と重なります。四つの行動は[OfferBoxで経理・財務に合う学生を見つける検索の考え方](/media/ob-keiri-target/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

文系向けの文面の型は[ワンキャリアで文系学生にスカウトを送る文面](/media/oc-scout-bunkei/)で書きました。経理・財務では、次の点を足します。

- **相手の一文は、合わなかったときの経験で**：「残高が合わず原因を一つずつ調べて見つけたと書かれていたのを読んで」。「几帳面そう」と書かない
- **社内でどこまでやるかを、一文で**：「〇人の経理で、決算まで社内で見ます。科目は分けません」
- **締めと決算を、一文で**：「月末から〇日間は帰りが△時ごろ、決算期は□週間忙しくなります」
- **最初の年を、一文で**：「最初の〇か月は伝票の入力と照合で、△△か月目に一つの科目の月次を任せます」
- **簿記の扱いを、一文で**：「簿記を持たずに入った先輩が〇人いて、入社後に取ります」。必須なら書く
- **送り主は、経理で入った先輩**：人事の名前で「管理部門に興味のある方」と送らない

## 選考への接続｜決算期の実態を、先に話す

- **社内でどこまでやるかを、面接の最初に話す**：「決算まで社内。申告は税理士。分業ではない」。大手の体験談を基準に来ている学生に、違いを先に
- **月の締めと決算の実態を、聞かれる前に話す**：「月末から〇日間は△時ごろ、決算期は□週間」。面接で「残業は少ない」と言い、決算期に違うと、体験談に書かれる
- **聞くのは「合わなかったとき何をしたか」**：「なぜ経理か」を聞かない。学生は「数字が好き」と答えを用意している
- **簿記の有無で落とさない**：「無くても採る」と書いたなら、面接で聞かない
- **内定後に、月次の締めの場を見せる**：先輩が締めを回している日を。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 社内でどこまでやるか、締めと決算の実態、最初の年、簿記の扱い、経理の先の道を決める | 経理の責任者 |
| 企業ページの経理・財務の記述 | 人事が、責任者と先輩に聞いて書く |
| 先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「入力だけ」「決算期が違った」と書かれていないか） |
| スカウトの一文 | 先輩 |
| 面接 | 責任者と先輩。決算期の実態を先に話す |

運用代行や代理店が支えられるのは、掲載の型、社内でどこまでやるかを文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、仕事の範囲の決定、決算期の実態の把握、面接、先輩の話は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

経理・財務の募集で、当社が順番として最初にお願いするのは、掲載を直すことではなく、「経理の責任者が、決算期の実態を、日数と時間で言えるようにすること」です。多くの会社で、決算期の実態は経理の中では分かっていても、人事が聞くと「時期による」「年による」と返ってきて、企業ページに書けないまま「経理・財務」の名前で出ています。実態が言えないと、掲載にもスカウトにも面接にも書けず、学生は体験談で確かめるしかありません。逆に、責任者が「月末から〇日間は△時ごろ、決算期は□週間で休日に〇日出た」と言えれば、掲載に一文書け、スカウトにも入り、面接で先に話せます。当社が掲載の直しを引き受けるときも、「決算期の実態を、責任者に日数と時間で聞いてから、掲載を直す」の順番でお願いしています。順番が逆だと、「経理・財務」の名前を範囲の言葉に変えただけで、決算期の実態が抜けたままになります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「経理・財務」「管理部門総合職」で書く | 何をどこまでやるか分からず、「入力だけ」と書かれる | 社内でどこまでやるかを書く |
| 決算期の実態を書かない | 「聞いていた話と違った」と書かれる | 日数と時間で書き、面接で先に話す |
| 少人数で決算まで見ることを隠す | 大手の分業と比べられ、選ばれない | 実態として書く |
| 簿記で絞る | 合わなかったとき原因を見つけた学生を落とす | 行動で読む |
| 「なぜ経理か」を聞く | 「数字が好き」で終わる | 「合わなかったとき何をしたか」を聞く |

## まとめ

- 経理・財務志望の学生は、大手の分業の経理の体験談を基準に、「経理か財務か・社内でどこまでやるか・締めと決算の実態・最初の年・簿記が無くても採るか・システム・経理の先の道・先輩の実態」を確かめる
- 掲載には、経理と財務を分け、社内でどこまでやるかと分業か一人か、締めと決算を日数と時間で、最初の年、簿記の扱い、システム、経理の先の道を書く
- ワンキャリアが向くのは、「少人数で決算まで見る」を実態として書ける会社
- 学生は、資格ではなく「集金と支払いを管理した・合わなかったとき原因を見つけた・締め日を決めた」で見つける
- 決算期の実態を責任者が日数と時間で言えるようにしてから掲載を直し、面接で先に話す

## よくある質問

### 決算期の残業が多い会社です。書くとエントリーが減りませんか

減りますが、減るのは決算期を入社後に知って離れる学生です。「決算期は□週間、帰りが△時ごろで、休日に〇日出て、代休を取る」と日数と時間で書き、面接で先に話します。決算期を減らす取り組みがあるなら、「昨年から□□を変えて、〇日減った」と、変えたことと結果を書きます。書かずに「残業は少ない」と言うと、決算期に体験談に書かれ、次の年の学生が離れます。

### 簿記を持っていない学生からのエントリーが多いです

「簿記が無くても採る」と書いたなら、簿記の有無で落とさず、「合わなかったとき何をしたか」「お金を扱った経験」を聞きます。「サークルの会計で残高が合わず、原因を見つけた」が話せる学生は、簿記は入社後に取れます。簿記を必須にするなら、企業ページに必須と書き、スカウトは持っている学生にだけ送ります。「あれば」と書いて簿記で落とすと、体験談に書かれます。

### 経理・財務の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、社内でどこまでやるかを文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。仕事の範囲の決定、決算期の実態の把握、面接、先輩の話は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
