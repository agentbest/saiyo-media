特定の大学のキャリアセンターに求人票を出し、学内説明会に出て、学生を紹介してもらっている。OfferBoxも使っている。この二つは、同じ「新卒を採る」でも、学生が来る理由が違います。**結論から言うと、キャリアセンター経由は「大学との関係で、学生が会社を案内されて来る入口」、OfferBoxは「大学を問わず、記述の行動で企業が選んで送る入口」です。併用するなら、求人票と文面の「最初の年」を揃え、学内で会った学生にOfferBoxで送らない台帳を持ち、OfferBoxの検索条件を大学名に寄せず、キャリアセンターとの関係を年単位の資産として残すことです。** この記事では、それぞれの役割、来る学生の状態、求人票と文面の揃え方、台帳、検索条件、時期の分担、関係の残し方、やりがちな失敗、社内の分担を整理します。大学との関係からの母集団形成は[大学との関係からの母集団形成](/media/kh-boshudan-daigaku/)、大学群を広げるかの判断は[OfferBoxで大学群を広げるべきか](/media/ob-daigakugun/)で書きました。数値は書きません。

## それぞれの役割｜「大学との関係で来る」と「行動で選んで送る」

| | キャリアセンター経由 | OfferBox |
|---|---|---|
| 学生が来る理由 | 大学が案内したから。求人票を見た、学内説明会に出た、職員に勧められた | 企業が選んで送ったから。文面と送ってきた人に興味を持った |
| 学生の状態 | 大学を通しているので、安心して来る。会社の中身は求人票と説明会の範囲 | 「自分に来た」と感じている。会社の中身は文面の範囲 |
| 選ぶのは誰か | 大学（案内する学生）と学生本人 | 企業。検索の条件で選ぶ |
| 入口の広さ | その大学の学生。狭いが、大学との関係で続く | 登録している学生。大学を問わず広い |
| 時期 | 大学の年間の予定に合わせる。学内説明会の時期が決まっている | 送る時期は企業が決める |
| 残るもの | 大学との関係。職員が会社を知っている | 検索条件と文面の型。送る社員の名義 |

キャリアセンター経由の学生は、「大学が勧めた会社」として来ます。OfferBoxで承認した学生は、「自分に来た会社」として来ます。同じ面談に、この二つの状態の学生が来るので、話の始め方が変わります。

## 求人票と文面の「最初の年」を揃える

- **キャリアセンターに出す求人票の「仕事内容」と、文面の「最初の年に何をするか」を同じ中身にする**：文章は違ってよい。中身がずれない
- **条件は、求人票と文面（触れるなら）と採用サイトで同じにし、同じ日に直す**：[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)
- **学内説明会で話す社員と、文面の名義の社員を同じ人にする**：説明会で会った学生が、あとで文面を見たときに「同じ人」と分かる。ただし、説明会で会った学生には送らない（次の項）
- **職員に渡す会社の説明と、文面の会社紹介を揃える**：職員が学生に案内する言葉が、文面とずれない
- **求人票と文面を、最後に同じ人が見る**

文面の基本は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「〇〇大学のキャリアセンターと関係があるので、OfferBoxでも〇〇大学の学生に送れば来る」というものです。当社は3媒体すべての販売パートナーとしてOfferBoxの運用代行も受けていますが、キャリアセンター経由で採れている会社ほど、検索条件が大学名に寄り、記述の行動を見なくなります。キャリアセンター経由の学生は大学との関係で来ているのであって、その大学の学生が近いからではありません。同じ大学に絞って送ると、大学名で選ばれた学生に、大学名で選んだ文面が届き、承認の理由が「大学名で来た」になります。当社が検索条件を決めるときは、キャリアセンター経由で採れた学生の「大学名」ではなく、「記述にどんな行動が書かれていたか」を先に見て、その行動で大学を問わず検索します。大学は、キャリアセンターの側で持ち、OfferBoxの側では持ちません。

## 学内で会った学生に、OfferBoxで送らない台帳

- **学内説明会で会った学生、職員に紹介された学生の名前を、送る側の台帳に入れる**：送る前に突き合わせる
- **会った学生がOfferBoxに登録していても、送らない**：大学を通した接点があるのに、別の経路で送ると「大学の紹介と関係なく送られた」と読まれる。連絡はキャリアセンターの流れで
- **逆に、OfferBoxで承認した学生が、その大学の学生だったら**：キャリアセンターに「貴学の学生と面談している」と伝えるかは、学生の同意と大学の方針を確認してから
- **台帳は一つ。入口の列に「キャリアセンター（大学名）」と「OfferBox」**：面談から先は共通の段
- **面談で「何を見て来たか」を聞く**：大学の案内か、求人票か、文面か

送る側の台帳と来た学生の台帳の分け方は[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)で書きました。

## 検索条件を、大学名に寄せない

- **「こんな人」の一行を、行動で書く**：「〇〇大学の学生」ではなく、「自分で始めて、人を巻き込んだ経験のある学生」
- **キャリアセンター経由で採れた学生の記述の特徴を、検索の手がかりにする**：大学名ではなく、書かれていた行動。組み方は[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
- **大学群を広げるかは、記述で判断する**：[OfferBoxで大学群を広げるべきか](/media/ob-daigakugun/)
- **上位大学から承認が取れないときに、大学名を上げる方向に行かない**：[上位大学の学生から承認が取れないときの考え方](/media/ob-joui-daigaku/)
- **地方の大学の学生には、勤務地を隠さずに送る**：[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)

キャリアセンターは「大学」で入る入口で、OfferBoxは「行動」で入る入口です。この違いを保つと、二つの入口から来る学生が重ならず、母集団が広がります。

## 時期の分担と、関係の残し方

| 時期 | キャリアセンター | OfferBox |
|---|---|---|
| 年度の前 | 求人票の提出。職員との顔合わせ。学内説明会の申込 | 「こんな人」の一行と検索条件。文面の型 |
| 学内説明会の時期 | 出る社員と当日の時間 | 送る時期と重ならないよう、前後にずらす。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/) |
| 送る時期 | 紹介された学生への連絡を切らさない | 検索・文面・送信・当日返信・面談 |
| 年度の終わり | 職員に結果を報告する。採れても採れなくても | 残った検索条件と文面の型を整理 |

- **職員に結果を返す**：紹介された学生がどうなったか、学内説明会に出た学生から何人会ったか。返すと、翌年も案内してもらえる。返す範囲は学生の同意と個人情報の扱いの範囲で
- **大学との関係は年単位で残る**：担当者が替わっても続くよう、職員とのやり取りを台帳に残す
- **OfferBoxの型も残す**：検索条件、文面の型、送る社員の名義。どちらも翌年の元
- **費用は、OfferBoxのプランの費用と、代行に出すなら代行の費用**：キャリアセンター経由は費用より時間と関係。配分は[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 検索条件を大学名に寄せる | 大学名で選んだ学生に大学名で選んだ文面が届き、承認の理由が大学名になる | 行動で検索する |
| 学内で会った学生にOfferBoxで送る | 「大学の紹介と関係なく送られた」と読まれる | 送る前に突き合わせる |
| 求人票と文面の「最初の年」がずれる | 大学経由の学生とOfferBoxの学生で、面談で聞く内容が違う | 同じ中身にし、同じ日に直す |
| 職員に結果を返さない | 翌年に案内してもらえない | 年度の終わりに返す |
| 学内説明会の時期に送る時期を重ねる | 説明会の準備と当日返信が両方遅れる | 前後にずらす |

最も多いのは、一つ目です。キャリアセンター経由でうまくいっている大学に、OfferBoxでも寄せてしまい、二つの入口が同じ学生を取り合います。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「こんな人」の一行を行動で書く | 人事と現場の責任者 |
| 求人票を出し、職員と関係を作る | 人事 |
| 学内説明会に出る | 人事と、文面の名義の社員 |
| 会った学生の名前を送る側の台帳に入れ、突き合わせる | 人事（代行に出しているなら代行と） |
| 検索条件を行動で組み、送る | 人事と送る社員（検索・文面下書き・送信は代行に出せる） |
| 面談で「何を見て来たか」を聞く | 面談に出る人 |
| 職員に結果を返す | 人事 |
| 大学群を広げるかの判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、求人票と文面の揃え方の型、台帳と突き合わせの型、検索条件を行動で組む作業、OfferBoxの送る時期の代行までで、「こんな人」の決定、大学との関係、面談、職員への報告、大学群の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

両方を使い始めたあと、最初の年で起きることに共通するのは、キャリアセンター経由の学生とOfferBoxで承認した学生で、面談の温度が違って、面接官が戸惑うことです。当社はOfferBoxの運用代行で面談の前後を見ますが、大学の案内で来た学生は「勧められたので来た」の温度で、文面で承認した学生は「自分に来たので来た」の温度です。同じ型で始めると、前者には会社の説明が足りず、後者には多すぎます。直し方は、面談の最初に「何を見て来たか」を聞き、大学経由の学生には求人票と説明会で聞いたことの続きから、OfferBoxの学生には文面の場面の続きから始めることです。面談の型は[OfferBox経由の学生との初回面談の設計](/media/ob-mendan-sekkei/)のままで、入口によって「続き」の元が変わるだけです。面接官に入口の列を見せてから面談に入ってもらうよう勧めています。

## まとめ

- キャリアセンター経由は「大学との関係で学生が案内されて来る入口」、OfferBoxは「大学を問わず行動で選んで送る入口」。来る理由が違う
- 求人票の「仕事内容」と文面の「最初の年」を同じ中身にし、条件は同じ日に直す。説明会に出る社員と文面の名義を同じ人に
- 学内で会った学生の名前を送る側の台帳に入れ、OfferBoxで送らない。台帳は一つで、面談から先は共通の段
- 検索条件を大学名に寄せない。キャリアセンター経由で採れた学生の「記述の行動」を検索の手がかりに
- 学内説明会の時期と送る時期をずらし、職員に結果を返す。大学との関係とOfferBoxの型を、どちらも翌年に残す

## よくある質問

### 特定の大学から毎年採れています。OfferBoxを足す意味はありますか

その大学の学生が「こんな人」に近いから採れているのか、大学との関係で来ているから採れているのかを、記述で確かめます。近いなら、その学生の記述の行動で、大学を問わず検索すると、他の大学にも同じ学生がいます。関係で来ているなら、OfferBoxは「行動で選ぶ入口」として、別の学生に会う目的で足します。同じ大学に寄せるためには足しません。

### キャリアセンターに、OfferBoxを使っていることを伝えるべきですか

伝えて問題になることは少ないですが、大学の方針を確認します。伝えるなら、「大学を問わず、記述で選んで送っている」と、大学名で送っていないことを添えると、大学との関係とぶつかりません。学内で会った学生には送らない、という運用も一緒に伝えると、職員は安心します。

### OfferBoxとキャリアセンター経由の併用は、御社に相談できますか

できます。当社は、役割の整理、求人票と文面の揃え方の型、台帳と突き合わせの型、検索条件を行動で組む作業、OfferBoxの送る時期の代行を支えられます。「こんな人」の決定、大学との関係、面談、職員への報告、大学群の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
