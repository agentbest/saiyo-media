採用予算が、ほぼ取れない。それでも採らなければならない。ところが、「無料で使える入口」を数で回して疲れ、「予算がないから何もできない」と止まり、無理に契約して途中で払えなくなり、上司に「予算がないから採れない」と言って翌年も予算が付かない。**結論から言うと、予算がない年は「媒体を選ぶ年」ではなく、「費用のかからない入口（リファラル・大学との関係・企業ページ・少人数の回）で、こんな人の一枚と型と台帳を作る年」です。契約の型で費用が後ろに来る媒体があるかは見積もりで確認し、無理に契約しません。翌年に予算が付いたとき、その日から回る形を残します。** この記事では、予算がないときに起きる失敗、予算がない年に作れるもの、費用のかからない入口ごとの役割、契約の型の確認、上司への説明、翌年の順番、分担を整理します。金額や料金はこの記事では扱いません。少ない予算の年は[年間予算五十万円台で使える採用媒体の考え方](/media/hikaku-yosan-50/)、3媒体の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)で書きました。

## この作業の目的｜予算がない年に、翌年の「元」を作る

予算がない年に、採用を止めると、翌年に予算が付いても、「こんな人」も型も台帳も企業ページもなく、一から始めることになります。予算がない年に作れるものは、全部、費用がかからず、時間だけで作れるもので、それが翌年の元になります。

目的は、予算がない年を「何もしない年」ではなく、「費用のかからない入口で、翌年の元を作る年」にすることです。

## 予算がないときに、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 無料の入口を、数で回す | SNSや無料掲載に時間を使い切り、「こんな人」に届かず、疲れて止まる |
| 「予算がないから何もしない」 | 翌年に予算が付いても、一から。今年の接点も残らない |
| 無理に契約して、途中で止まる | 途中で払えなくなり、進行中の学生が放置され、翌年に契約しにくくなる |
| 上司に「予算がないから採れない」と言う | 翌年も予算が付かない。「予算があれば採れる」の根拠もない |
| 翌年の元を、残さない | 今年会った人、作った型、書いた企業ページが翌年に使えない |
| 時間まで、削る | 予算がないうえに、担当の時間も他の業務に取られ、何も残らない |

共通するのは、「予算がない＝採用ができない」と考えていることです。予算がなくても、できることは多く、それは翌年の元です。

## 予算がない年に、作れるもの

| 作れるもの | 費用 | 翌年にどう効くか |
|---|---|---|
| 「こんな人」の一枚 | かからない | 翌年、どの媒体を選ぶかの根拠。[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/) |
| 企業ページと社員の記事 | かからない（時間） | 翌年、どの入口から来た人も読む場所。[掲載からの母集団形成](/media/kh-boshudan-keisai/) |
| 文面の型 | かからない | 翌年、送る日から使える。[スカウト文面の基本](/media/kh-bunmen-kihon/) |
| 台帳の型 | かからない | 翌年、段ごとに数える形が最初からある。[採用ファネルの作り方](/media/kh-boshudan-funnel/) |
| 面談の型と、現場の分担 | かからない | 翌年、面談の枠と出る人が決まっている |
| 今年会った人との接点 | かからない | 翌年の母集団の「最初の接点」。[潜在層からの母集団形成](/media/kh-boshudan-senzai/) |

この六つは、予算がある年にも要るもので、予算がある年には作る時間が取れないことが多い。予算がない年は、それを作る年です。

### エージェントベストの見解

相談で最も多い思い込みは、「予算がないなら、当社に相談することはない」というものです。当社は3媒体すべての販売パートナーで、媒体の契約がなければ当社の収入にはなりませんが、予算がない年の相談は受けています。理由は二つあります。一つは、予算がない年に「こんな人」の一枚と型と台帳と企業ページを作った会社は、翌年に予算が付いたとき、その日から回り、媒体が効きやすいこと。もう一つは、予算がない年に無理に契約して途中で止まった会社は、翌年に契約しにくく、当社にとっても続かないことです。当社が予算がない年の相談で最初にやるのは、「今年は契約しないほうがよい」と伝えることも含めて、「翌年の元として、何を今年作るか」を一緒に決めることです。

## 費用のかからない入口ごとの、役割

| 入口 | 役割 | 注意 |
|---|---|---|
| リファラル（社員・内定者の紹介） | 「こんな人」を知っている人が選ぶ。予算がない年の主な入口 | 数を求めない。制度の報奨は自社の制度で確認。[リファラルからの母集団形成](/media/kh-boshudan-referral/) |
| 大学との関係（研究室・ゼミ・キャリアセンター） | 時間をかけて続ける関係。今年始めれば翌年以降の入口 | 大学名で選ばない。学内のルールで確認。[大学との関係からの母集団形成](/media/kh-boshudan-daigaku/) |
| 企業ページと社員の記事 | 探して来た人と、紹介された人が読む場所 | 「誰でも歓迎」と書かない。[掲載からの母集団形成](/media/kh-boshudan-keisai/) |
| 少人数の回（自社開催） | 確かめる場。社員が出て仕事を話す | 会場と時間は自社で。[イベントからの母集団形成](/media/kh-boshudan-event/) |
| 早期の接点・潜在層 | 今年会った人と関係を続ける | 今年の数ではなく、翌年の最初の接点。[早期の母集団形成の考え方](/media/kh-boshudan-souki/) |
| SNS | 読む場所への導線 | 入口ではない。数を追わない。[SNSからの母集団形成](/media/kh-boshudan-sns/) |

どの入口も、費用はかからず、時間がかかります。全部を開けず、リファラルと企業ページから始めます。

## 契約の型で、費用が後ろに来る媒体の確認

- **媒体には、定額の型と、採用が決まったときに費用が発生する型がある**：型の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」
- **費用が後ろに来る型なら、予算がない年でも契約できる場合がある**：可否と条件は、見積もりと契約で確認
- **無理に契約しない**：決まったときに払えるかを、管理部門と先に確認
- **契約するなら、一つの媒体・一つの職種・読める数だけ**：[年間予算五十万円台で使える採用媒体の考え方](/media/hikaku-yosan-50/)
- **代理店経由でも料金は変わらない**：[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)

金額と契約の形は、見積もりと契約で確認してください。この記事では扱いません。

## 上司への説明

- **「予算がないから採れない」と言わない**：翌年も予算が付かない
- **「予算がない年に、翌年の元を作る」と説明する**：六つの作れるものを示す
- **今年の入口（リファラル・大学・企業ページ・回）で、何人と会えたかを記録して見せる**：予算がなくても動いた根拠
- **翌年に予算が付いたとき、「その日から回る」形が残っていることを示す**：翌年の予算の根拠
- **説明の型は[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)**

## 翌年に予算が付いたときの、順番

1. **今年作った「こんな人」の一枚で、媒体を一つ選ぶ**：[年間予算五十万円台で使える採用媒体の考え方](/media/hikaku-yosan-50/)の検討順
2. **今年作った型と台帳で、契約した日から送る・掲載する**
3. **今年の接点（リファラル・大学・早期）に、最初に連絡する**：翌年の母集団の最初の人
4. **今年の入口（リファラル・大学・企業ページ・回）は、続ける**：媒体を足しても、費用のかからない入口はやめない
5. **翌年の終わりに、今年と翌年を並べて振り返る**：[母集団形成の振り返り方](/media/kh-boshudan-review/)

予算がない年の元があると、翌年は「準備」の期間が短く、媒体が効くまでが速くなります。

### エージェントベストの見解

これは順番の話です。予算がない年の相談で、「せめて何か一つ、無料で使えるものを」と言われることがあります。当社がお願いする順番は、「無料の入口」を探す前に、「こんな人」の一枚と企業ページを作ることです。一枚がないと、無料の入口で会った人が「こんな人」に近いかが分からず、企業ページがないと、紹介された人が読むものがありません。一枚と企業ページがあれば、リファラルは動き、大学との関係は始められ、少人数の回は開けます。無料の入口が効かないのは、入口のせいではなく、一枚と読む場所がないからです。当社は、予算がない年を「無料の入口を探す年」ではなく、「一枚と読む場所を作る年」として一緒に組みます。

## まとめ

- 予算がない年は「媒体を選ぶ年」ではなく、費用のかからない入口で「こんな人」の一枚・企業ページ・文面の型・台帳の型・面談の型・今年の接点を作る年。六つとも翌年の元
- 無料の入口を数で回さず、「予算がないから何もしない」にもしない。無理に契約して途中で止まらない
- 入口はリファラルと企業ページから。大学との関係、少人数の回、早期の接点は時間で。SNSは導線
- 費用が後ろに来る契約の型があるかは見積もりと契約で確認し、決まったときに払えるかを管理部門と先に確認。代理店経由でも料金は変わらない
- 上司には「予算がないから採れない」ではなく「翌年の元を作る」と説明し、今年会えた人を記録して見せる。翌年に予算が付いたら、今年の一枚と型で、契約した日から回す

## よくある質問

### 予算がない年に、本当に人は採れますか

リファラルと大学との関係と少人数の回で、「こんな人」に近い人と会えれば、採れることはあります。数は少なく、時間はかかります。今年の数を約束するより、今年会えた人と、翌年の元を残すことを目標に置くと、翌年に効きます。「採れなかった」年でも、一枚と型と台帳と企業ページが残っていれば、その年は無駄ではありません。

### 無料で使える媒体や掲載は、使ってよいですか

使ってよいですが、「こんな人」の一枚と企業ページを先に作ってからです。一枚がないと、無料の入口で来た人が近いかが分からず、読む場所がないと来た人が帰ります。無料の入口も時間がかかるので、リファラルと企業ページを回す時間を先に確保し、残りで一つだけ試します。数で回さず、来た人のうち近い人の割合で見ます。

### 予算がない年の採用は、御社に相談できますか

できます。当社は、作れるものの整理、一枚と型と台帳の型、入口ごとの役割の整理、契約の型の確認の仕方を支えられます。一枚の決定、記事、型を作ること、リファラルと大学の関係、回に出ることは、企業が行ってください。予算がない年に、当社に払うものはありません。金額と契約は見積もりと契約で確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
