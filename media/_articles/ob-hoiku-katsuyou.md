認可保育園、認定こども園、企業主導型保育、小規模保育、運営会社の本部、学童・児童発達支援の会社が、OfferBoxで新卒を採る。保育は、保育士の資格と養成校経由の採用が中心の業界で、学生は実習で園を見ていて、園を決める軸は「子どもが好き」ではなく、「どんな保育をする園か（方針）」「配置と持ち帰り仕事と休憩はどうか」「園長はどんな人か」です。養成校（短大、専門学校）の学生は、実習と学校の就職課の流れで園を決めていて、OfferBoxはその流れの外にある。**結論から言うと、保育のOfferBoxは、向く相手と職種で使います。向くのは、四年制大学で保育士資格を取る学生（養成校の流れが弱く、企業から直接届く入口がある）への直接のオファー、運営会社の本部（園の開発、人事、ICT、栄養、看護、事務）の職種、学童・児童発達支援の資格を問わない職種です。送る前に、保育の方針（何を大事にして、何をしないか）、人員の配置、持ち帰り仕事と休憩と行事の実態を書けるかを確かめ、書けない間は送りません。文面は園の写真と「アットホーム」ではなく、方針と配置と一日を先に書き、園長の名義で送ります。実習と養成校の就職の日程を前提に、送る時期と面談の時期を置き、面談の前か後に保育の時間帯を選んで園を見てもらいます。** この記事では、保育の採用構造とOfferBoxとの相性、向く相手と職種、送る前の順番、検索とターゲットの設計、オファー文面、面談と内定後、園と本部の分担を整理します。媒体の選び方は[保育業界の採用媒体の選び方](/media/hikaku-hoiku-erabikata/)、介護職の検索の考え方は[OfferBoxで介護職志望の学生を探す方法](/media/ob-kaigo-shoku-target/)も参考になります。数値と料金は書きません。

## 保育の採用構造と、OfferBoxとの相性

| 区分 | 採用の形 | OfferBoxとの相性 |
|---|---|---|
| 認可保育園・認定こども園（単独） | 養成校の実習と就職課の流れ。少人数 | 養成校の学生には流れの外。四年制大学の保育学生に、方針と配置と一日で。一人を園長の名義で |
| 運営会社（複数園） | 園の保育士と、本部の職種（開発、人事、ICT、栄養、看護） | 向く。本部の職種で。園の保育士は四年制大学の学生に園ごとの方針で |
| 学童・児童発達支援 | 資格が保育士に限らない。新卒も採る | 向く。「なにを」を子どもの層と支援の内容で。資格を問わない職種として |

| 養成校の学生は実習と就職課の流れで決める | 送っても流れの外で承認されない | 四年制大学の保育学生と本部に絞る |

| 園長の考えが園を決める | 園長の言葉が無いと、園の像が伝わらない | 園長の名義で |

## 向く相手と職種で使う｜四年制大学の保育学生・本部・資格を問わない職種

- **養成校（短大・専門学校）の学生に、OfferBoxで送ることを主にしない**：実習と就職課の流れで決まる。送っても承認されにくい。養成校との関係は別の場で
- **四年制大学で保育士資格を取る学生に、直接送る**：養成校の流れが弱く、企業から直接届く入口がある学生。学部と資格の取得の記述で絞る。[OfferBoxのターゲット設計](/media/ob-target-sekkei/)
- **運営会社の本部の職種は、園の募集と分けて**：園の開発、人事、ICT、栄養、看護、事務。「保育」の像ではなく、本部の仕事と「何を決められるか」で
- **学童・児童発達支援は、資格を問わない職種として**：「〇〇の子どもに△△の支援をしている」。「保育士の資格が要る」の像で承認されない形を防ぐ

### エージェントベストの見解

これは媒体の向き不向きの話です。園や運営会社から、「OfferBoxで保育士の新卒を採りたい」と相談されることがあります。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、保育でOfferBoxが向くのは、養成校（短大・専門学校）の学生ではなく、四年制大学で保育士資格を取る学生と、運営会社の本部の職種と、学童・児童発達支援の資格を問わない職種です。養成校の学生は実習と就職課の流れで園を決めていて、企業からのオファーはその流れの外にあり、四年制大学の保育学生は企業から直接届く入口があると承認します。当社がお願いしているのは、OfferBoxを四年制大学の保育学生と本部と資格を問わない職種に絞り、養成校との関係は別の場で持つことです。絞ると、文面が方針と配置と一日で書く形になり、承認した学生が園の実態を知った上で来ます。

## 送る前の順番｜方針と配置と持ち帰り仕事を、書けるか確かめる

- **①保育の方針を、「何を大事にして、何をしないか」で書けるか確かめる**：「〇〇を大事にしている。△△はしない」。「一人ひとりを大切に」で済ませない
- **②人員の配置を、書けるか確かめる**：「〇〇の年齢のクラスに△△人。加配は□□」。配置が書かれていない園に、学生は来ない。数値は自園の実態で。この記事では書かない
- **③持ち帰り仕事と休憩と行事の実態を、書けるか確かめる**：「書類は〇〇の時間に園でやる。持ち帰りは△△。休憩は□□。行事は年〇〇で、準備は△△」。「働きやすい」で伏せない
- **④一日を、先週の一日で**：「先週は〇〇の担当で、△△の時間に□□をした」
- **書けない間は、送らない**：実習で園を見ている学生は、文面と実態の差をすぐ知る
- **送る時期を、実習と養成校の就職の日程を前提に置く**：四年制大学の実習の時期、就職を決める時期。その前後に面談を置かない。[OfferBoxで送るタイミングの考え方](/media/ob-soushin-timing/)

## 検索とターゲットの設計｜「子どもが好き」ではなく、保育の記述と資格の取得で

- **「子どもが好き」「保育に興味」で検索しない**：像の言葉で、方針と配置で決める学生の絞り込みにならない
- **四年制大学の保育学生は、学部と資格の取得の記述で**：「〇〇学部で保育士資格を取得予定」「△△の実習で□□をした」
- **絞るのは、保育の記述**：「実習で〇〇の保育を見て、△△と思った」「□□の年齢の子どもと〇〇をした」「配置の中で△△を工夫した」
- **もう一つ絞るのは、保護者や家族と対応した記述**：「〇〇の保護者と△△をやり取りした」。園の実態に近い経験。[OfferBoxのプロフィールの読み方](/media/ob-profile-yomikata/)

## オファー文面の設計｜写真と「アットホーム」ではなく、方針と配置と一日を先に

- **園の写真と「アットホーム」「笑顔があふれる」を、文面の最初に置かない**：どの園も同じに見える。写真を載せるなら、保育士の一日の場面で
- **最初の一文に、方針を**：「〇〇を大事にして、△△はしない園です」。[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)
- **配置と持ち帰り仕事と休憩を、隠さず**：「〇〇のクラスに△△人。書類は園で。持ち帰りは□□。休憩は〇〇」
- **園長の名義で送り、「なぜこの保育を」を体験で一文**：学生は「園長がどんな人か」で決める
- **プロフィールの「実習で見た」「配置の中で工夫した」記述に、一箇所触れる**：[OfferBoxのオファーをパーソナライズする方法](/media/ob-offer-personalize/)

## 面談と内定後｜園長が出て、保育の時間帯に園を見せる

- **面談に、園長が出る**：本部だけの面談は、園の方針を伝えられない。[OfferBoxの面談の設計](/media/ob-mendan-sekkei/)
- **面談で、配置と持ち帰り仕事と休憩と行事を、聞かれる前に伝える**：文面に書いたことを、園長が本人の言葉で
- **面談の前か後に、保育の時間帯を選んで園を見てもらう**：実習で他の園を見ている学生は、見れば分かる
- **内定後、配置や方針が変わったら伝える**：伝えずに入社日を迎えると、入った後に知られて離れる。[OfferBoxの内定後フォロー](/media/ob-naitei-follow/)
- **内定から入社までの間に、園に一度来てもらう**：行事の時期を選んで。[OfferBoxの内定辞退を防ぐ考え方](/media/ob-naitei-jitai/)

## 園と本部の分担

| 作業 | 誰が |
|---|---|
| 送る相手を四年制大学の保育学生と本部と資格を問わない職種に絞る | 本部と園長 |
| 方針を「何を大事にして、何をしないか」で書く | 園長 |
| 配置、持ち帰り仕事、休憩、行事を、何を書くか決める | 園長と本部 |
| 園長の名義で、方針と配置と一日を先に書いた文面を送る | 園長（下書きは本部か外に出せる） |
| 検索を学部と資格の取得と保育の記述で絞る | 本部（絞る作業は外に出せる） |
| 送る時期と面談の時期を、実習と就職の日程を前提に置く | 本部 |
| 面談に園長が出て、園を見せる枠を持つ | 園長 |
| 内定後、配置や方針が変わったら伝え、園に来てもらう | 園長と本部 |

## まとめ

- 保育士の新卒は資格と養成校経由が中心で、学生は実習で園を見ていて、「子どもが好き」より方針と配置と持ち帰り仕事と園長で決める。養成校の学生はOfferBoxの流れの外
- OfferBoxが向くのは、四年制大学で保育士資格を取る学生への直接のオファー、運営会社の本部（園の開発・人事・ICT・栄養・看護・事務）、学童・児童発達支援の資格を問わない職種。園ごとに文面を分け、園長の名義で一人か二人に
- 順番は、方針（何を大事にして、何をしないか）→配置→持ち帰り仕事と休憩と行事の実態、を書けるか確かめてから送る。書けない間は送らない。実習と就職の日程を前提に送る時期と面談の時期を置く
- 検索は「子どもが好き」ではなく、学部と資格の取得の記述、保育の記述、保護者と対応した記述で絞る。本部と資格を問わない職種は別の検索で
- 文面は園の写真と「アットホーム」を最初に置かず、方針と配置と一日を先に。面談に園長が出て、保育の時間帯に園を見せ、内定後に配置や方針が変わったら伝える

## よくある質問

### 養成校の学生にも、OfferBoxで送れますか

養成校（短大・専門学校）の学生は、実習と学校の就職課の流れで園を決めていて、企業からのオファーはその流れの外にあり、承認されにくいです。OfferBoxは四年制大学で保育士資格を取る学生と本部の職種に絞り、養成校との関係は実習の受け入れと就職課との関係で持つ方が合っています。

### 園の写真を載せてはいけませんか

載せてよいですが、文面の最初に置かず、子どもの笑顔ではなく保育士の一日の場面にしてください。実習で園を見ている学生は、写真ではなく方針と配置と持ち帰り仕事で決めます。方針を「何を大事にして、何をしないか」で、配置と持ち帰り仕事と休憩を隠さず、文面の最初に書いてください。

### 保育のOfferBoxの設計は、御社に相談できますか

できます。当社は、送る相手の整理、方針と一日の書き出しの型、文面の下書き、検索の絞り込み、送信、一次返信、時期の設計、面談の型、内定後フォローの型を支えられます。方針の決定、配置と持ち帰り仕事の開示、園長が話すこと、保育士が話すこと、面談、園を見せることは、園と本部が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
