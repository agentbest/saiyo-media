複数の媒体を使っていて、どれが効いているかを並べて比べたい。ところが、エントリー数と承認数と参加者数を並べて「多い媒体が良い」と読み、媒体ごとに数え方が違い、「こんな人」も期間も違い、担当の時間が入っておらず、費用だけで並べて、優劣を付けて終わる。**結論から言うと、比べるのは「エントリー数」ではなく、媒体ごとの「こんな人に近い人が面談まで来た数」と「入口→面談の日数」と「近い人の割合」と「担当の時間」です。同じ数え方に揃え、同じ「こんな人」で、同じ期間で並べます。数え方が違う数字を並べると、多く集まる媒体が良く見えます。比べた結果は「役割の違い」として読み、優劣で読みません。** この記事では、比べ方で起きる失敗、揃えるもの、並べる四つの数、入口の違いの揃え方、表の型、読み方、比べた後に決めること、記録がないとき、分担を整理します。媒体ごとの効果測定は[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)、[Wantedlyの効果測定](/media/wt-kouka-sokutei/)、[ワンキャリアの効果測定](/media/oc-kouka-sokutei/)、母集団のKPIは[母集団形成のKPI](/media/kh-boshudan-kpi/)で書きました。

## この作業の目的｜「どれが多いか」ではなく「どれが、どの役割で効いたか」を読む

媒体の効果を並べる目的は、優劣を付けることではなく、翌年の配分を決めることです。配分を決めるには、「どの媒体が、どの役割で、近い人をどれだけ、どれだけの時間で連れてきたか」が要ります。エントリー数の大小では、配分は決まりません。

目的は、比べる表を「多い順」ではなく「役割ごとの、近い人の面談数あたり」で作ることです。

## 比べ方で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| エントリー数や承認数を、並べる | 入口の数で、質が見えない。多く集まる媒体が良く見える |
| 媒体ごとに、数え方が違う | 「承認」「返信」「エントリー」「受諾」を同じ列に並べ、比べられない |
| 「こんな人」が、媒体ごとに違う | 媒体Aは広く、媒体Bは狭く、で近い人の割合が比べられない |
| 期間が、違う | 選考期の媒体と早期の媒体を並べ、時期の差を媒体の差と読む |
| 担当の時間を、入れない | 時間がかかる媒体が「効いた」に見え、時間あたりでは悪い |
| 費用だけで、並べる | 費用が小さい媒体が良く見え、時間と質を見ていない |
| 優劣で、読む | 「Aが良い、Bは悪い」で、Bの役割（Aで会えない人）を見落とす |

共通するのは、「並べる前に揃える」をしていないことです。

## 揃えるもの

| 揃えるもの | どう揃えるか |
|---|---|
| 数え方 | 入口の数（承認・返信・エントリー・受諾・参加）は列を分け、比べる列は「面談まで来た数」以降に。段の切り方は[採用ファネルの作り方](/media/kh-boshudan-funnel/) |
| 「こんな人」 | 一枚を全媒体で同じに。媒体ごとに一枚を変えない。[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/) |
| 期間 | 同じ年度の同じ期間で。時期の役割が違う媒体は、時期ごとに分けて並べる |
| 段 | 入口→面談→一次→内定→承諾を全媒体で同じ段に |
| 近さの判断 | 「近い」「やや近い」「遠い」の三段を、同じ人が同じ物差しで。[OfferBoxで会う学生の評価基準の作り方](/media/ob-gakusei-hyouka-kijun/) |
| 担当の時間 | 媒体ごとに、週にどれだけ使ったかを同じ単位で |

揃えてから並べます。揃っていない表は、読まないほうが安全です。

### エージェントベストの見解

相談で最も多い思い込みは、「媒体ごとの管理画面の数字を並べれば、効果が比べられる」というものです。当社は3媒体すべての販売パートナーとして、比較の表を見せられることが多いのですが、管理画面の数字は媒体ごとに「何を数えているか」が違い、そのまま並べると、入口の数が大きい媒体が良く見えます。逆に、台帳から「面談まで来た人のうち近い人の数」を媒体ごとに出し、担当の時間を横に置いた会社は、入口の数が少ない媒体のほうが時間あたりで良い、と分かって配分を変えています。当社は3媒体を扱うので、どの媒体が良く見える表にも利害はありませんが、揃っていない表で配分を決めた会社は、翌年に「効いていた媒体を減らしていた」ことに気づいています。当社が比較の相談を受けるとき、最初にやるのは、管理画面の数字の表を閉じて、台帳から同じ段で出し直すことです。

## 並べる、四つの数

| 数 | 何が分かるか | 出し方 |
|---|---|---|
| 近い人の面談数 | 媒体の「量」 | 台帳から、媒体ごとに、面談した人のうち近い人 |
| 入口→面談の日数 | 媒体の「速さ」。待たせている媒体 | 台帳の日付から |
| 近い人の割合 | 媒体の「質」。入口の絞り方が合っているか | 面談した人のうち近い人÷面談した人 |
| 担当の時間 | 媒体の「重さ」 | 週の記録から、媒体ごとに |

四つを並べ、「近い人の面談数あたりの時間」と「近い人の面談数あたりの費用（自社の見積もり）」を出します。四つの考え方は[母集団形成のKPI](/media/kh-boshudan-kpi/)の「母集団形成のKPIは、三つ」に「担当の時間」を足したものです。

## 媒体ごとの入口の違いを、揃える

- **OfferBox**：送信→承認→面談。「承認」は入口の数で、比べる列に入れない。[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)
- **Wantedly**：スカウト→返信、または募集記事→「話を聞きに行きたい」→面談。「返信」「話を聞きに行きたい」は入口の数。[Wantedlyの効果測定](/media/wt-kouka-sokutei/)
- **ワンキャリア**：スカウト→受諾→面談、または企業ページ→エントリー→面談、イベント→参加→面談。「受諾」「エントリー」「参加」は入口の数。[ワンキャリアの効果測定](/media/oc-kouka-sokutei/)
- **リファラル・大学・イベント**：紹介→面談、参加→次の場→面談
- **比べる列は「面談まで来た数」から**：入口の数は、媒体ごとの列で持ち、比べない
- **入口の率（承認率・返信率・エントリー率）は、その媒体の運用を直す数**：媒体をまたいで比べない

## 表の型

- **行に、媒体（入口）**：スカウト、掲載、イベント、リファラル、大学、早期、と役割で分けて
- **列に、四つの数と、近い人の面談数あたりの時間と費用**
- **入口の数は、欄外か別の表に**：比べる表に入れない
- **役割を、行の横に書く**：「届ける」「読む場所」「確かめる場」「紹介」
- **期間を、表の上に**：同じ期間であることを明記
- **先月・前年と、並べられる形に**：[採用ファネルの作り方](/media/kh-boshudan-funnel/)の「目標値ではなく、変化で見る」

## 読み方｜役割の違いとして

- **「Aは近い人の面談数が多く、Bは少ない」→「Bは効かない」ではなく、「Bは何の役割か」**：Bでしか会えない人がいたか
- **「Cは時間あたりで悪い」→「Cはやめる」ではなく、「Cの時間の使い方を変えられるか」**：型と集計を外に出せば時間が減る
- **「Dは近い人の割合が低い」→「Dは質が低い」ではなく、「Dの入口の絞り方（送る相手・書く材料）を直せるか」**
- **「Eは日数が長い」→「Eは遅い媒体」ではなく、「Eの返信の対応が遅い」**：媒体ではなく運用
- **優劣で読むと、役割が違う媒体をやめて、届く範囲が狭くなる**

比べた結果は、「効いた・効かなかった・理由が分からない」の三分類に落とします。[母集団形成の振り返り方](/media/kh-boshudan-review/)の「入口を、三つに分ける」で書きました。

## 比べた後に、決めること

- **翌年の配分**：近い人の面談数あたりの時間と費用で、効いた媒体に寄せる。[母集団形成の予算配分](/media/kh-boshudan-yosan/)
- **役割が重なっている媒体**：減らす候補。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)
- **時間の使い方を変える媒体**：型と集計を外に出す、現場に分担
- **入口の絞り方を直す媒体**：送る相手、書く材料
- **やめる媒体**：四つの軸で。[媒体をやめる判断基準](/media/hikaku-baitai-tettai/)
- **比べた表を、上司への説明に**：優劣ではなく役割と配分で。[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)

## 記録がないときの、比べ方

- **今年は、比べない**：揃っていない数字で比べると、誤った配分になる
- **今年の残りで、台帳を媒体ごとに分けて付け始める**：入口・段・日付・近さ
- **面談で「どこで知りましたか」を聞き、台帳に**：入口を後から付ける
- **翌年の年度の切れ目に、揃った表で比べる**
- **今年、どうしても決めるなら、「近い人が面談まで来たか」だけを、記憶の範囲で媒体ごとに**：それ以外は決めない

### エージェントベストの見解

これは数字の読み方の話です。比較の相談で、「Aのほうが承認率が高いので、Aに寄せたい」と言われることがあります。当社が確かめるのは、「承認率」と「面談まで来た近い人の数」が、同じ方向を向いているかです。承認率が高くても、面談に来ない、来ても遠い、なら、Aは「承認されやすい相手に送っている」だけで、近い人を連れてきていません。逆に、承認率が低くても、面談まで来た人が近い人ばかりなら、Bは「絞って送っている」媒体で、近い人の面談数あたりでは良い。当社は3媒体を扱うので、どちらに寄せても当社の扱いですが、承認率で配分を決めた会社は、翌年に近い人の面談数が減っています。比べる数は、入口の率ではなく、面談以降の近い人の数です。

## まとめ

- 比べるのはエントリー数や承認数ではなく、媒体ごとの「近い人の面談数」「入口→面談の日数」「近い人の割合」「担当の時間」の四つと、近い人の面談数あたりの時間と費用
- 並べる前に、数え方・「こんな人」・期間・段・近さの判断・時間の単位を揃える。揃っていない表は読まない
- 媒体ごとの入口の数（承認・返信・エントリー・受諾・参加）は列を分けて比べない。比べる列は「面談まで来た数」から。入口の率はその媒体の運用を直す数
- 結果は優劣ではなく「役割の違い」として読み、「効いた・効かなかった・理由が分からない」の三分類に落とし、翌年の配分・減らす候補・時間の使い方・入口の絞り方・やめる判断を決める
- 記録がないなら今年は比べず、台帳を媒体ごとに分けて付け始め、翌年に揃った表で比べる

## よくある質問

### 管理画面の数字しかなく、台帳がありません。それでも比べたいです

管理画面の数字は「入口の数」で、媒体ごとに何を数えているかが違い、そのまま並べると誤ります。今年は、面談した人を思い出せる範囲で媒体ごとに分け、「近い人だったか」だけを付けて、「近い人が面談まで来た媒体はどれか」だけを見ます。それ以上は決めず、今年の残りから台帳を付け始めます。台帳の項目は[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)の手順5で書きました。

### 上司が「エントリー数の一覧」を求めます

一覧は出しますが、「比べる表」とは分けます。上司の表に、媒体ごとの「近い人の面談数」と「近い人の面談数あたりの費用と時間」を主に置き、エントリー数は参考として欄外に。エントリー数が多い媒体で近い人の面談数が少なければ、「遠い人が多く来て、面談の枠を使っている」と添えます。伝え方は[母集団形成のKPI](/media/kh-boshudan-kpi/)の「上司に見せるKPIと、直すためのKPIを分ける」で書きました。

### 媒体の効果の比べ方は、御社に相談できますか

できます。当社は、揃え方の型、表の型、媒体ごとの入口の揃え方、読み方の整理、配分の材料を支えられます。台帳を付けること、近さの判断、時間の記録、配分の決定、上司への説明は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。どの媒体が良く見える表にも利害はありません。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
