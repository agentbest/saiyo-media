ワンキャリアには、企業のトップページ（企業ページ）と、イベントごとのページがあります。両方を持つと、「同じことを両方に書く」「イベントページに会社紹介を書く」「トップページに日程を書いて古くなる」ということが起きます。**結論から言うと、企業トップページには「いつ読んでも同じこと」（選考の流れと何を見るか・仕事の具体と最初の1年・働く人・よく聞かれること）を置き、イベントページには「その日に、その人と、確かめること」（誰が・何を・何を持ち帰るか・日程・選考との関係）を置きます。両方に置くのは、選考の流れの骨子と話す人の名前だけで、トップからイベントへ、イベントからトップへの導線を付け、更新の頻度を分けます。** この記事では、両方を持つと起きる失敗、置き分けの軸、それぞれに置くもの、両方に置くもの、導線、更新の頻度、分担を整理します。トップページは[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)、イベントページは[イベントページの作り方](/media/oc-event-page-kihon/)で書きました。ページの構成や項目は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜学生が「どこを読めば何が分かるか」に迷わない状態にする

学生は、体験談を読んだあと、企業トップページとイベントページを行き来します。同じことが両方に書いてあると、「どちらが新しいか」で迷い、違うことが書いてあると、「どちらが本当か」で迷います。

使い分けの目的は、「トップを読めば会社の側の説明が分かり、イベントを読めばその日に何が確かめられるかが分かる」と、学生が迷わない状態にすることです。

## 両方を持つと、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 同じことを両方に書く | どちらかが古くなる。学生はどちらが新しいか分からない |
| イベントページに会社紹介を書く | トップと重なり、「誰が・何を」が埋もれる |
| トップページに日程を書く | イベントが終わると古くなる。トップ全体が古く見える |
| トップからイベントへの誘導が無い | トップを読んだ学生が、イベントに気づかない |
| イベントからトップへの誘導が無い | イベントを読んだ学生が、選考の流れや仕事の具体にたどり着かない |
| 選考との関係を、トップとイベントで違う書き方にする | 「どちらが本当か」 |
| 話す人が、トップの「働く人」に出てこない | イベントの「誰が」を、トップで確かめられない |

最も多いのは、最初の「同じことを両方に書く」です。イベントページを作るときに、トップの内容を写す形で起きます。

## 置き分けの軸

| 軸 | トップに置く | イベントに置く |
|---|---|---|
| 時間が経っても変わるか | 変わらないもの（選考の流れの考え方、仕事の具体、働く人） | その日限りのもの（日程、その回の話す人、その回の内容） |
| 誰が話すかで変わるか | 変わらないもの（会社の側の説明） | 変わるもの（その人が話す場面） |
| 学生が「読む」か「確かめる」か | 読む場（体験談を読んだあとに、会社の説明を読む） | 確かめる場（気になったことを、人に聞く） |
| 更新の頻度 | 起点があるときだけ | イベントごとに新しく |

「時間が経っても変わるか」が、最も分かりやすい軸です。日程は変わる、選考の流れの考え方は変わらない。前者はイベント、後者はトップです。

### エージェントベストの見解

相談で最も多い思い込みは、「イベントページは、トップページの内容を要約して日程を付けたものだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を支えていますが、トップの要約で作ったイベントページは、「誰が・何を」が無く、体験談を読んだ学生には「会社説明会」にしか見えません。トップとイベントは、要約の関係ではなく、役割の違いです。トップは会社の側の説明を読む場で、イベントはその日に人と確かめる場。当社が使い分けを整えるとき、最初にやるのは、イベントページから会社紹介と、トップに書いてあることを全部消し、「その日に、その人と、何を確かめられるか」だけを残すことです。残ったものが、イベントページの本体です。

## トップページに置くもの

| 置くもの | 中身 |
|---|---|
| 選考の流れと、各段階で何を見るか | 考え方と骨子。時期の具体は年度の公表内容と自社の方針を確認。日程はイベントへ |
| 仕事の具体と最初の1年 | 職種ごとに。変わらない |
| 働く人の話 | 入社してまもない社員の、入る前と後。イベントで話す人も、ここに出ておく |
| 学生からよく聞かれること | 選考で実際に聞かれた質問と答え。イベントで出た質問も足す |
| 会社の事実 | 事業の一文、なぜやっているか。短く |
| イベントへの誘導 | 「直接確かめたい方は、イベントへ」と、いま開いているイベントの入口 |

トップの4つの要素は[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。ここに「イベントへの誘導」を足します。

## イベントページに置くもの

| 置くもの | 中身 |
|---|---|
| 誰が話すか | その回の話す人。職種、年次、名前 |
| 何を話すか | その回の場面。「最初の1年」「選考で何を見ているか」「〇〇の案件」 |
| 来た学生が何を持ち帰るか | その回で確かめられること |
| 日程、形式、時間 | その回限り |
| 選考との関係 | トップの骨子と同じ内容を、その回について。年度の公表内容と自社の方針を確認 |
| トップへの誘導 | 「選考の流れと仕事の具体は、企業ページに」 |

イベントページの要素は[イベントページの作り方](/media/oc-event-page-kihon/)で書きました。ここに「トップへの誘導」を足し、会社紹介は置きません。

## 両方に置くもの

同じことを両方に書かない原則の例外が、二つあります。

| 両方に置くもの | 理由 | 書き方 |
|---|---|---|
| 選考との関係の骨子 | イベントページだけ読んだ学生も、トップだけ読んだ学生も、同じ理解になるように | 同じ一文を。イベントには「この回について」を添える |
| 話す人の名前 | イベントの「誰が」を、トップの「働く人」で確かめられるように | トップの「働く人」に、イベントで話す人が出ている状態を保つ |

「選考との関係」は、書き方が違うと「どちらが本当か」になるので、同じ一文にします。「話す人」は、イベントページで名前を見た学生が、トップの「働く人」でその人の話を読める形にします。

## 行き来の導線

- **トップからイベントへ**：「選考の流れ」と「よく聞かれること」の近くに、「直接聞きたい方は、イベントへ」。いま開いているイベントの入口
- **イベントからトップへ**：「何を話すか」の下に、「選考の流れと仕事の具体は企業ページに書いています。読んでから来ると、質問しやすいです」
- **イベントが終わったら、トップの誘導を更新する**：終わったイベントへの誘導を残さない
- **イベントで出た質問を、トップの「よく聞かれること」に足す**：イベントからトップへの、内容の流れ

「読んでから来ると質問しやすい」の一文は、学生に「準備して来る」を促し、イベントの質問の時間が生きます。

## 更新の頻度の違い

| | トップページ | イベントページ |
|---|---|---|
| 更新の起点 | 選考の変更、体験談の増加、新しい入社者、よく聞かれることの変化、年度の切れ目 | イベントごとに新しく作る |
| 頻度 | 年に数回 | イベントの数だけ |
| 古くなるもの | 事実、選考の流れ | 日程、話す人 |
| 終わったあと | 残る | 残すか下げるかは仕様と自社の方針で。残すなら「終了」が分かる形に |

トップの更新は[企業ページを更新し続ける方法](/media/oc-kigyo-page-koushin/)で書きました。イベントページは、トップの更新とは別に、イベントごとに作り、終わったら誘導を外します。

## 複数のイベントがあるとき

- **トップの誘導は、いま申し込めるイベントだけ**：終わったものと、まだ先のものを混ぜない
- **イベントページ同士は、話す人と内容で区別する**：タイトルで。付け方は[イベントページのタイトルの付け方](/media/oc-event-page-title/)
- **同じ話す人が複数のイベントに出るなら、トップの「働く人」に一度出ていれば足りる**
- **イベントの型（説明会・座談会・選考の説明）ごとに、トップのどこから誘導するかを決める**：選考の説明はトップの「選考の流れ」から、座談会は「働く人」から

## 社内の分担

| 作業 | 誰が |
|---|---|
| トップとイベントの置き分けを決める | 人事 |
| トップから日程と会社紹介の重複を外す | 人事 |
| イベントページから会社紹介を外す | 人事 |
| 選考との関係の一文を、両方で揃える | 人事（年度の公表内容と自社の方針を確認） |
| 話す人をトップの「働く人」に出す | 人事（話す人に聞いて） |
| 導線を付け、イベント終了後に外す | 人事 |
| イベントで出た質問をトップに足す | 人事 |

運用代行や代理店が支えられるのは、置き分けの軸の整理、重なりと抜けの点検、導線の設計、更新の頻度の型までで、選考との関係の判断、話す人の確保、イベントの運営は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと両方が古くなることがあります。「イベントが終わったら、トップの誘導を外す」という一つの手順です。当社がワンキャリアの掲載を支える中で、トップページに数か月前に終わったイベントへの誘導が残っている会社があります。学生はそれを見て、「更新されていない会社」と読み、トップの選考の流れも古いのではと疑います。当社が使い分けを整えるとき、最初にお願いするのは、イベントの当日の手順の最後に「トップの誘導を外す」を入れることです。数分で済みます。それが無いと、イベントを開くたびに、トップが少しずつ古くなります。

## まとめ

- トップは「いつ読んでも同じこと」（選考の流れと何を見るか・仕事の具体・働く人・よく聞かれること）、イベントは「その日に、その人と、確かめること」（誰が・何を・何を持ち帰るか・日程・選考との関係）
- 同じことを両方に書く、イベントに会社紹介、トップに日程、導線が無い、が失敗
- 両方に置くのは、選考との関係の骨子（同じ一文で）と、話す人の名前（トップの「働く人」に出しておく）だけ
- トップからイベントへ、イベントからトップへの導線を付け、イベントが終わったらトップの誘導を外す
- トップは年に数回の起点で、イベントはイベントごとに。出た質問はトップに足す

## よくある質問

### イベントページだけを読む学生もいるので、会社紹介を入れたほうがよいのではないですか

会社紹介ではなく、トップへの誘導を入れます。「選考の流れと仕事の具体は企業ページに書いています」の一文で、イベントページだけを読んだ学生もトップにたどり着けます。イベントページに会社紹介を入れると、「誰が・何を」が埋もれ、体験談を読んだ学生には届きません。

### トップの「働く人」に、イベントで話す人を全員出す必要がありますか

イベントに出る人は、トップの「働く人」に一度は出ておくことを勧めます。学生はイベントページで名前を見て、トップでその人の話を読み、「この人に聞きたい」と決めます。全員が難しければ、その回の主な話す人だけでも出します。

### トップとイベントの使い分けは、御社に相談できますか

できます。当社は、置き分けの軸の整理、重なりと抜けの点検、導線の設計、更新の頻度の型を支えられます。選考との関係の判断、話す人の確保、イベントの運営は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
