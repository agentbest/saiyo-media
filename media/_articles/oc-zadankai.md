ワンキャリアで座談会を開きたい。体験談に「社員の雰囲気が分からなかった」「もっと社員の話を聞きたかった」と書かれている。ところが、座談会が説明会の小さい版になり、人事が話し、出る社員が一人で、テーマがなく雑談で終わり、学生が質問できず社員が話し続け、案内に「誰が出るか」がなく、社員の負担が重くて二回目が開けない。**結論から言うと、座談会は「入社してまもない社員に、体験談で気になったことを直接聞ける場」で、説明会の小さい版ではありません。企画は「誰が出るか」から始め、社員は複数で学生に近い人、テーマは体験談から一つ、話す時間は最短で質問が中心、人事は輪に入りません。案内には「誰が出て、何を聞けるか」を書き、出る社員の負担を一枚で軽くし、終わった後は当日に一通。** この記事では、座談会で起きる失敗、確かめられること、企画の順番、出る社員、テーマ、当日の型、案内、負担を軽くする一枚、終わった後、分担を整理します。種類の使い分けは[ワンキャリアのイベントの種類と使い分け](/media/oc-event-kihon/)、オフラインの進め方は[ワンキャリアのオフラインイベントの進め方](/media/oc-offline-event/)、少人数の場の考え方は[Wantedlyのミートアップの企画](/media/wt-meetup/)で書きました。

## この作業の目的｜「社員に聞ける場」を、社員の負担を軽くして続ける

座談会の価値は、学生が「入社してまもない社員」に、体験談で気になったことを直接聞けることです。その価値は、出る社員がいて初めて成り立ち、社員の負担が重ければ続きません。続かない座談会は、一回の参加者の体験談にしか残らず、翌年の集客になりません。

目的は、座談会を「社員に聞ける場」として設計し、社員の負担を軽くして、同じ型で続けることです。

## 座談会で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 説明会の小さい版になる | 会社の説明を少人数でするだけ。「社員に聞ける」がない |
| 人事が、話す | 学生が聞きたいのは社員の話。人事が話すと社員が黙る |
| 出る社員が、一人 | 質問が一人に集中し、疲れ、答えが一人の意見になる |
| テーマがなく、雑談で終わる | 「何でも聞いて」で、学生は何を聞けばよいか分からず、雑談になる |
| 学生が質問できず、社員が話し続ける | 質問の出し方がなく、社員が沈黙を埋める |
| 案内に「誰が出るか」がない | 「座談会」だけでは、誰と話せるか分からず、申し込まない |
| 社員の負担が重く、続かない | 準備が重い、時間が長い、で二回目に出ない |
| 体験談と、揃っていない | 体験談で「〇〇と聞いた」とあることと、座談会で言うことが違う |

共通するのは、座談会を「話す場」として設計し、「聞ける場」として設計していないことです。

## 座談会で、確かめられること

- **入社してまもない社員の、入る前と後の違い**：体験談の書き手に近い人の、その後
- **社員どうしの空気**：複数の社員が出ると、やり取りで分かる
- **仕事の日々**：「最初の一年」「一日の流れ」を、その人の言葉で
- **体験談で気になったことの、答え**：「〇〇と言われたが、実際は」
- **質問への答え方**：正直か、答えられないことを認めるか
- **確かめられないこと**：会社の全体、経営の方針、制度の詳細。それは企業ページと別の回に

### エージェントベストの見解

相談で最も多い思い込みは、「座談会は準備が要らないので、気軽に開ける」というものです。当社はワンキャリアの販売パートナーとして、座談会の相談を受けていますが、準備なしで開いた座談会は、テーマがなく雑談になり、質問が出ず、社員が沈黙を埋めて話し続け、体験談に「座談会だったが、聞きたいことが聞けなかった」と残っています。逆に、「誰が出るか」を先に決め、テーマを体験談から一つ置き、質問の出し方を用意し、社員には一枚だけ渡して開いた座談会は、学生の質問が体験談の続きになり、「社員の人に聞けた」と残って、翌年の集客になっています。座談会は、準備が少ない回ではなく、「準備の中身が、説明会と違う回」です。当社が座談会の相談を受けるとき、最初にやるのは、「誰が出ますか」を決めてもらうことです。

## 企画の、順番

1. **誰が出るかを、決める**：入社してまもない社員を、複数
2. **テーマを、体験談から一つ**：体験談で「気になった」「分からなかった」と書かれていること
3. **人数と形を、決める**：少人数、社員一人に学生数人、オンラインかオフラインか
4. **案内を、書く**：「誰が出て、何を聞けるか」
5. **当日の型を、決める**：話す時間は最短、質問が中心
6. **社員に渡す一枚を、作る**
7. **終わった後の一通を、先に書く**

「1」が最初です。出る社員が決まらないまま企画すると、案内に「誰が出るか」が書けず、当日に人事が話すことになります。

## 出る社員の、選び方と頼み方

- **入社してまもない社員**：学生に近く、「入る前と後」を話せる。体験談の書き手と近い立場
- **複数で**：二人以上。質問が分散し、社員どうしの空気が見える
- **同じ職種の人と、違う職種の人**：テーマが職種の話なら同じ職種、雰囲気の話なら違う職種も
- **話が上手な人を選ばない**：自分のことを事実で話せる人
- **頼むのは「出て、自分のことを話す」だけ**：準備は一枚を読むだけ。[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)
- **上司の合意を先に**：業務時間内で、出る時間を業務として

## テーマの、型

| 型 | 話すこと | 向く体験談の記述 |
|---|---|---|
| 入る前と後 | 入る前に思っていたことと、入ってからの実際 | 「雰囲気が分からなかった」「実際どうなのか気になった」 |
| 最初の一年 | 入社した年に、何をして、何につまずいたか | 「若手が何をしているか分からなかった」 |
| 一日の流れ | ある一日を、朝から | 「仕事の中身が見えなかった」 |
| 選考のとき | 自分が選考で何を聞かれ、どう答え、何を見られたと思うか | 「選考で何を見ているか分からなかった」 |
| 決めた理由 | 他社と比べて、この会社に決めた理由と、迷ったこと | 「決め手が分からなかった」 |

テーマは一つ。体験談を読んで、最も多く書かれていることから選びます。「一つの場面から話す」考え方は[Wantedlyのミートアップの企画](/media/wt-meetup/)の「テーマの型」と同じです。

## 当日の、型

| 順 | 内容 | 時間 |
|---|---|---|
| 1 | 人事が、テーマと質問の出し方を案内。「今日は社員に聞く場。人事は輪に入りません」 | 短く |
| 2 | 出る社員が、自己紹介と、テーマについて一つの場面を一人ずつ短く | 短く |
| 3 | 質問。学生から。出なければ人事が最初の質問（体験談の続き）を出す | 最も長く |
| 4 | 社員どうしで、質問に対して意見が違うところを話す | 中くらい |
| 5 | 人事が戻り、次の場の案内。「今日決めなくてよい」 | 短く |

「3」と「4」が中心です。人事は「1」と「5」だけで、輪に入りません。オンラインなら文字の質問も受けます。[ワンキャリアのオンラインイベントの進め方](/media/oc-online-event/)の「質問を、出させる工夫」で書きました。

## 案内の、書き方

- **誰が出るか**：職種、入社してからの年数の目安、名前（出せる範囲で）
- **何を聞けるか**：テーマと、「〇〇について聞けます」
- **人事は輪に入らないこと**
- **人数と形**：少人数、オンラインかオフラインか
- **選考との関係**：年度の公表内容と自社の方針で確認し、明記
- **タイトルは「座談会」ではなく、「〇〇職の入社〇年目の社員に、入る前と後の違いを聞く回」の形で**：年数の表記は自社の実態で。[ワンキャリアのイベントページのタイトル](/media/oc-event-page-title/)
- **書き方は[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)**

## 社員の負担を軽くする、一枚

- **テーマと、当日の流れ**
- **「話すのは自己紹介とテーマの一つの場面だけ。あとは質問に答える」**
- **答えられない質問への答え方**：「分からない」「人事に確認します」でよい
- **聞かれやすい質問と、事実の答え**：条件の質問は「企業ページに書いてあるとおり」
- **話さないこと**：他社の悪口、盛ること、社内の未確定のこと
- **一枚以上、渡さない**：準備が重いと続かない

## 終わった後

- **当日か翌日に、一通**：参加のお礼、出た質問の一つへの答え、出た社員からの一言（事実で）、企業ページと体験談、次の場
- **出た社員に、反応を戻す**：「〇〇の質問が出た」「〇人が次の場に進んだ」。戻さないと二回目に出ない
- **出た質問を、記録する**：翌年の企業ページと座談会の材料
- **同じ型で、次の回を**：出る社員を替えても、型は同じ
- **一通の型は[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)の「終わったあとの動き」**

| 作業 | 誰が |

| 出る社員を決め、上司の合意を取る | 人事と現場の責任者 |
| 体験談を読み、テーマを一つ選ぶ | 人事 |
| 案内を書き、社員に渡す一枚を作る | 人事 |
| 出て、自分のことを話し、質問に答える | 入社してまもない社員（複数） |
| 進行（最初と最後だけ）、時間、次の場の案内 | 人事 |
| 当日か翌日の一通と、社員への反応 | 人事 |
| 出た質問を記録し、次の回を同じ型で | 人事 |

運用代行や代理店が支えられるのは、企画の順番の型、テーマの型、当日の型、案内の型、社員に渡す一枚の型、一通の型までで、出る社員の決定、体験談を読むこと、出ること、質問に答えること、反応を戻すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。座談会の相談で、「座談会を開いたが、次の場に進む学生が少ない」と言われることがあります。当社が確かめるのは、「聞けなかった」のか、「聞けたが、次の場が見えなかった」のか、「聞けて次の場も見えたが、聞いた中身が企業ページや体験談と違った」のか、の三つです。一つ目なら、出る社員の数とテーマと質問の出し方。二つ目なら、当日の次の場の案内と一通。三つ目なら、座談会で社員が言うことと企業ページと体験談を揃えること。三つのどれかで、直す場所が違います。座談会は「開けば進む」回ではなく、「聞けて、次が見えて、揃っている」ときに進む回です。当社は、座談会の相談で、この三つを出た質問の記録から一緒に見ます。

## まとめ

- 座談会は「入社してまもない社員に、体験談で気になったことを直接聞ける場」で、説明会の小さい版ではない。人事が話さず、輪に入らない
- 企画は「誰が出るか」から。社員は複数で学生に近い人、話が上手な人ではなく事実で話せる人。頼むのは「出て、自分のことを話す」だけ
- テーマは体験談から一つ（入る前と後・最初の一年・一日の流れ・選考のとき・決めた理由）。当日は自己紹介と一つの場面を短く、質問を最も長く、社員どうしの違いも
- 案内には「誰が出て、何を聞けるか」と「人事は輪に入らない」を書き、タイトルは「座談会」ではなく中身で。社員には一枚だけ渡し、答えられないことは「分からない」でよい
- 終わった後は当日か翌日に一通、出た社員に反応を戻し、出た質問を記録し、同じ型で次の回を。座談会で言うことは企業ページと体験談と揃える

## よくある質問

### 入社してまもない社員が「学生の質問に答えられるか不安」と言います

答えられないことは「分からない」「人事に確認します」でよい、と一枚に書いて渡します。学生が聞きたいのは、正確な会社の情報ではなく、「その人が実際にどうだったか」で、それは本人しか答えられず、間違えようがありません。会社の制度や数字の質問は、人事が引き取るか「企業ページに」で済ませます。最初の回は、少し上の社員と一緒に出てもらうと、不安が減ります。

### 座談会に来た学生が、質問せずに聞いているだけです

質問の出し方（文字でも、匿名でも、人事が最初の質問を出す）と、テーマがあるか、を確かめます。「何でも聞いて」では聞けず、「体験談で〇〇と書かれていましたが、実際は」と人事が口火を切ると、続きます。オンラインなら文字の質問を先に受けます。それでも出なければ、社員どうしで「入る前と後で違ったこと」を話し合う形にして、聞いているだけでも確かめられる場にします。

### 座談会の企画は、御社に相談できますか

できます。当社は、企画の順番の型、テーマの型、当日の型、案内の型、社員に渡す一枚の型、一通の型を支えられます。出る社員の決定、体験談を読むこと、出ること、質問に答えること、反応を戻すことは、企業が行ってください。掲載の形は管理画面とヘルプで確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
