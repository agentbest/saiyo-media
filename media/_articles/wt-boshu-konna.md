募集記事で候補者が最も読むのは、「入ったら自分は何をするのか」の部分です。Wantedlyの募集記事では「こんなことやります」にあたる部分で、募集記事の中心です。**結論から言うと、ここで書くのは、最初の数ヶ月にやること、その後にやること、関わる案件や顧客の種類、誰と組むか、難しさ、成長の道筋です。「幅広い業務」「ゆくゆくは」で終わらせず、配属先に「最初の3ヶ月、この人は何をしますか」と聞いて、場面で書きます。** 決まっていないなら「一緒に決める」と正直に書きます。この記事では、この部分の役割、書く内容と順番、聞き方、「ゆくゆくは」を避ける理由、正直さ、新卒と中途の書き分け、やりがちな失敗、分担を整理します。募集記事の全体は[募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。この記事は、そこで「募集記事の中心」と書いた部分の書き方です。

## この作業の目的｜候補者に「入った自分の最初の仕事」を見せる

「なにをやっているのか」で職種の位置、「なぜやるのか」で募集の理由、「どうやっているのか」でチームの働き方が分かったら、残るのは「で、自分は何をするのか」です。ここが無いと、候補者は話を聞きに行く理由を持てません。

最も知りたいのは、「最初の数ヶ月」です。入社してすぐ何をするのか、研修なのか現場なのか、誰と組むのか。ここが具体的なら、候補者は自分の最初の日々を想像できます。「ゆくゆくは〇〇」では、最初の日々が見えません。

この部分の目的は、候補者に「入った自分の最初の仕事」を見せることです。

## 手順1｜書く内容と順番

書く内容を、候補者が読む順に並べます。

| 順 | 内容 | 書き方 |
|---|---|---|
| 1 | 最初の数ヶ月にやること | 「最初の月は〇〇、2ヶ月目から△△を任せる」。研修か現場か、誰と組むか |
| 2 | その後にやること | 「半年後には□□を1人で。1年後には◇◇にも」。分かる範囲で |
| 3 | 関わる案件や顧客の種類 | 具体名が出せなければ、種類と規模感。「〇〇のような会社の△△を」 |
| 4 | 誰と組むか | 名前と、その人が何をしている人か。会社ページのメンバー紹介につなげる。[メンバーの選び方](/media/wt-kaisha-page-member/) |
| 5 | 難しさ | この仕事で最初に詰まりやすいこと。隠さない |
| 6 | 成長の道筋 | この仕事を続けると、何ができるようになるか。役職ではなく、できることで |

1の「最初の数ヶ月」に、最も分量を使います。2以降は、1が具体的なら短くて足ります。逆に、1が薄くて2以降が長いと、「ゆくゆくは」の募集記事になります。

## 手順2｜配属先に「最初の3ヶ月」を聞く

この部分の材料は、配属先の責任者にあります。人事が想像で書くと、「幅広い業務」「ゆくゆくは」になります。聞き方を用意します。

1. **「この人が入ったら、最初の3ヶ月は何をしますか」**：週ごと、月ごとに。研修があるならその中身、現場ならどの案件から
2. **「誰と組みますか」**：教える人、一緒にやる人。名前で
3. **「半年後、1年後は」**：分かる範囲で。「未定」なら未定と
4. **「最初に詰まりやすいのは、どこですか」**：過去に入った人が詰まったところ
5. **「関わる案件や顧客は、どんな種類ですか」**：具体名か、種類と規模感
6. **「この仕事を続けると、何ができるようになりますか」**：役職ではなく、できること

「最初の3ヶ月」が答えられない場合は、募集記事を書く前に、配属先で決めます。決まっていないまま書くと、候補者に「入ったら何をするか分からない会社」と映ります。この順番は、募集記事の基本構成の記事で「これをやる前に決めておくこと」として書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「入社後のことは、入ってから決めればいいので、募集記事では『幅広く』としておく」というものです。実際には、「幅広く」と書かれた募集記事を読んだ候補者は、「入ったら何をするか分からない」と受け取り、話を聞きに来ません。来る候補者も、面談で「具体的には何を」と聞き、答えが無ければ離れます。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、話を聞きに来る候補者が多い募集記事は、例外なく「最初の月は〇〇、2ヶ月目から△△」と、最初の数ヶ月が具体的です。「ゆくゆくは」が中心の募集記事には、来ません。入社後のことを決めるのは、募集記事を書くときです。決めていないなら、募集記事を書く前に配属先で決めるか、「一緒に決める」と正直に書くかのどちらかで、「幅広く」でごまかさないことを勧めます。

## 手順3｜「幅広い業務」「ゆくゆくは」を避ける理由

避ける言い方と、なぜ避けるかを並べます。

| 避ける言い方 | 候補者にどう映るか | 代わりに |
|---|---|---|
| 「幅広い業務をお任せします」 | 何をするか決まっていない | 最初の月にやることを1つ |
| 「ゆくゆくは〇〇も」 | 最初は何をするのか分からない | 最初の数ヶ月を先に、ゆくゆくは短く |
| 「様々なプロジェクトに関わる」 | どのプロジェクトか分からない | 種類と規模感、最初に関わる1つ |
| 「成長できる環境で」 | 抽象語 | できるようになることを具体的に |
| 「即戦力として活躍」 | 教える体制が無い | 誰と組んで、何から始めるか |
| 「一緒に会社を大きく」 | 仕事が見えない | この募集の仕事の中身 |

共通するのは、「最初の仕事が見えない」ことです。候補者は、会社の未来より、自分の最初の日々を知りたい。「ゆくゆくは」は、最初の数ヶ月を書いたあとに、短く添えるものです。

## 手順4｜決まっていないなら、正直に

新しく始める事業や、体制がまだ無い募集では、最初の数ヶ月が決まっていないことがあります。その場合は、正直に書きます。

- **「〇〇を始めると決めたが、進め方はこれから。最初の月は、△△と一緒に何をやるかを決めるところから」**：「一緒に決める」を最初の仕事として書く
- **「決まっていること」と「決まっていないこと」を分けて書く**：「関わる顧客は〇〇と決まっている。進め方はまだ」
- **「決まっていないから、こういう人を探している」とつなぐ**：「進め方を自分で決めた経験がある人」。求める動き方につながる
- **「幅広く」でごまかさない**：決まっていないことを「幅広く」と書くと、決まっていないことが隠され、面談で気づかれる

正直に書くと、「決まっていないほうが面白い」と思う候補者が来ます。ごまかすと、誰も来ないか、来ても面談で離れます。正直さの考え方は、[募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)で「欠員なら欠員と」と書いたのと同じです。

## 手順5｜新卒と中途で書き分ける

同じ職種でも、新卒向けと中途向けで、この部分の書き方が変わります。

| 観点 | 新卒向け | 中途向け |
|---|---|---|
| 最初の数ヶ月 | 研修の中身、最初に配属される仕事、誰が教えるか。丁寧に | 最初の案件、引き継ぎの形、任される範囲。すぐの参加を前提に |
| その後 | 1年目、2年目の道筋。「入社1年目の〇〇さんは、いま△△を」 | 半年後、1年後に任される範囲 |
| 難しさ | 学生が想像しにくい実務の難しさを、優しく具体的に | 経験者が詰まりやすい、この会社特有のこと |
| 成長の道筋 | 何ができるようになるか、を長めに | できることの広がりと、役割の変化 |
| 誰と組むか | 教える人、年の近い先輩 | 一緒にやる人、引き継ぐ相手 |

新卒向けに「即戦力」「引き継ぎ」を書くと、学生は「自分ではない」と閉じます。中途向けに「研修から」を長く書くと、経験者は「求められていない」と感じます。誰に向けた募集かで、最初の数ヶ月の書き方を変えます。新卒の学生像の考え方は、OfferBoxの[募集要項の書き方](/media/ob-boshu-youkou/)で「最初の仕事と1日の流れ」と書いたのと同じです。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「幅広い業務」 | 何をするか分からず、来ない | 最初の月にやることを1つ |
| 「ゆくゆくは」が中心 | 最初の日々が見えない | 最初の数ヶ月を先に |
| 人事が想像で書く | 抽象語になる | 配属先に「最初の3ヶ月」を聞く |
| 決まっていないのに決まっているように書く | 面談で気づかれる | 「一緒に決める」と正直に |
| 誰と組むかが無い | 1人で放り出されるように見える | 名前で書く |
| 難しさを書かない | 建前に読まれる | 最初に詰まりやすいことを1つ |
| 新卒向けに「即戦力」 | 学生が閉じる | 研修と教える人を書く |
| 成長の道筋が役職だけ | できることが見えない | できるようになることで書く |

最も多いのは、最初の「幅広い業務」です。決まっていないか、人事に伝わっていないかのどちらかです。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「最初の3ヶ月」を決める | 配属先の責任者 |
| 「最初の3ヶ月」「誰と」「難しさ」「その後」を話す | 配属先の責任者 |
| 聞いて、場面の文にする | 人事 |
| 新卒と中途で書き分ける | 人事 |
| 決まっていない部分を正直に書く | 人事（責任者と合意） |
| 責任者が確認する | 配属先の責任者 |
| 状況が変わったら直す | 人事 |

配属先の責任者の時間は、「最初の3ヶ月を決める」「話す」「確認する」の3つです。最初の「決める」が、この部分で最も重い作業です。運用代行や代理店が支えられるのは、聞く質問の用意、場面の文への整理、新卒と中途の書き分けの型までです。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと募集記事の中心が書けないことがあります。「入った人の最初の3ヶ月を、配属先が決めている」ことです。当社がWantedlyの運用の相談で募集記事を見るとき、「こんなことやります」が「幅広く」で終わっている記事の配属先に聞くと、最初の3ヶ月が決まっていないか、決まっているが人事に伝わっていないかのどちらかです。決まっていないなら、募集記事を書く前に決める。伝わっていないなら、人事が「最初の3ヶ月、この人は何をしますか」と聞く。当社が募集記事の整備を支えるとき、最初にこの質問を配属先にしてもらうのは、この答えが募集記事の中心になるからです。答えがあれば、募集記事の他の部分は短くて済みます。答えが無ければ、他の部分がどれだけ良くても、候補者は「自分の最初の仕事」が見えず、話を聞きに来ません。

## まとめ

- 「こんなことやります」は募集記事の中心。候補者が最も知りたい「入った自分の最初の仕事」を見せる
- 書く順は、最初の数ヶ月→その後→関わる案件や顧客の種類→誰と組むか→難しさ→成長の道筋。最初の数ヶ月に最も分量を
- 配属先に「最初の3ヶ月、この人は何をしますか」と聞く。人事が想像で書くと「幅広い業務」になる
- 「幅広い業務」「ゆくゆくは」で終わらせない。決まっていないなら「一緒に決める」と正直に
- 新卒向けは研修と教える人を丁寧に、中途向けは最初の案件と任される範囲を。「即戦力」は学生を閉じさせる

## よくある質問

### 入社後の配属や仕事が決まっていません。何を書けばよいですか

決まっていることと決まっていないことを分けて書きます。「関わる顧客は〇〇と決まっている。進め方はこれから。最初の月は△△と一緒に何をやるかを決めるところから」のように、「一緒に決める」を最初の仕事として書きます。「幅広く」でごまかすと、面談で気づかれます。

### 「ゆくゆくは」を書いてはいけないのですか

書いて構いませんが、最初の数ヶ月を書いたあとに、短く添えます。「ゆくゆくは」が中心だと、候補者は最初の日々を想像できません。最初の月、2ヶ月目、半年後、1年後、の順で、最初に最も分量を使います。

### 募集記事の中心の作成は、御社に相談できますか

できます。当社は、配属先に聞く質問の用意、聞いた答えを場面の文に整えること、新卒と中途の書き分けを支えられます。「最初の3ヶ月」を決めることと話すことは、配属先の責任者にお願いしています。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
