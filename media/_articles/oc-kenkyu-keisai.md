ワンキャリアで新卒の研究開発職を募集したとき、最初にぶつかるのは「『研究開発職』と掲載したのに、自社の分野と同じ研究室の学生しか来ないか、来ても面接で『何を研究するのですか』『テーマは誰が決めるのですか』『自分の研究は生きますか』と聞かれ、答えた内容が体験談で『研究開発と言いながら評価と分析だった』『テーマは上から降りてくる』と書かれる」という問題です。**結論から言うと、ワンキャリアの研究開発職の掲載は、「研究開発職」の名前ではなく「何を研究するのか、テーマは誰が決めるのか、学生の研究とつながるのか、最初の年に何を任せ、修士でなくても採るか」を、学生が体験談で読む前に企業ページと募集に書き、研究の聞き方の型を揃えて面接をします。** 理系学生全般の掲載は[ワンキャリアで理系学生向けに掲載するとき](/media/oc-rikei-keisai/)で書きました。この記事は研究開発職に絞り、掲載とスカウトと選考をつなげて書きます。

## 研究開発職志望の学生が、体験談で読んでいること

学生は、企業ページを読む前に、研究開発職の選考の体験談と、その会社の先輩の話を読んでいます。研究開発職の体験談は「研究の内容を何分で話したか」「何を突っ込まれたか」が中心で、学生はそこから「この会社は研究をどう見るか」を推し量ります。

| 読んでいること | 掲載への意味 |
|---|---|
| 何を研究するのか | 新しいものを作るのか、いまある製品を改良するのか、評価と分析なのか。「研究開発職」の名前では分からない |
| テーマは誰が決めるか | 上から降りてくるか、自分で提案できるか。いつから提案できるか |
| 自分の研究とつながるか | 分野が違っても採るか。研究の内容ではなく進め方を見るか |
| 最初の年に何を任されるか | 先輩のテーマの一部か、評価と分析か、自分のテーマか |
| 修士でなくても採るか | 学部卒がいるか。博士は採るか、どう扱うか |
| 面接で研究をどう聞かれるか | 内容の深さか、進め方か。専門外の面接官が聞くか |
| 研究開発で入った先輩の実態 | 最初の年に何をし、いま何のテーマを持っているか |

「テーマは誰が決めるか」と「自分の研究とつながるか」が、研究開発職の体験談で最も読まれ、企業ページで最も書かれない項目です。

## 掲載に書くこと｜何を研究するか、テーマの決め方、最初の年、修士でなくても採るか

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「研究開発職」ではなく「〇〇の材料の研究開発」「△△の製品の改良の研究開発」。何をするか |
| 何を研究するか | 「新しい〇〇を作る研究と、いまの△△の改良の両方。最初に任せるのは改良のほう」。良く見せない |
| テーマの決め方 | 「テーマは部門の方針で決まる。□年目から提案できる。提案が通った例が〇件」。降りてくるなら、そう書く |
| 学生の研究との関係 | 「研究の分野は問わない。見るのは進め方。分野が違う人が〇人」。分野を求めるなら、どの分野か |
| 最初の年 | 「最初の〇か月は先輩のテーマの評価と分析。△△か月目に先輩のテーマの一部を。自分のテーマは□年目から」 |
| 修士でなくても採るか | 「学部卒が〇人。博士は△△の扱い」。いないなら、いないと |
| 面接で研究をどう聞くか | 「研究の内容の深さではなく、詰まった場面でどうしたかを聞く。専門外の面接官もいる」 |
| 先輩の話 | 最初の年に何をし、いまのテーマをどう持ったか。盛らない |

企業ページにはテーマの決め方と学生の研究との関係と面接での聞き方を、募集には何を研究するかと最初の年を、と分担します。

### エージェントベストの見解

研究開発職の募集で、ワンキャリアが向いている会社と向いていない会社があります。当社は3媒体すべての販売パートナーとして、研究開発職の掲載と選考を見ていますが、ワンキャリアが向いているのは、「研究の分野を問わず、進め方で採る」会社です。ワンキャリアの理系学生は、自分の研究室の分野と違う会社の体験談も読み、「分野が違っても採った」と書かれている会社を探しています。「〇〇の分野の修士に限る」という募集なら、研究室の推薦とOfferBoxの分野検索のほうが向いていて、ワンキャリアに掲載しても、体験談に「分野が違うと落ちる」と書かれて終わります。逆に、「分野は問わない。見るのは進め方。分野が違う人が〇人」と書いた会社は、体験談に「研究の内容より進め方を聞かれた」と書かれ、次の年に分野の違う学生が来ます。当社が最初に確かめるのは、「分野を問わずに採る用意があるか」です。用意がないなら、ワンキャリアの研究開発職の掲載は、無理に出さないほうがよいと案内します。

## 研究開発職志望の学生の見つけ方

分野とキーワードで絞ると、進め方が合う学生を落とします。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 分野 | 研究室の分野、テーマ | あればよい条件。分野で絞らない |
| 詰まった場面 | 「結果が出ず、条件を変えて〇回試した」「装置が使えず、別の方法で」 | 進め方の記述を優先。テーマの名前より |
| テーマの持ち方 | 「教員のテーマの一部」「自分で提案した」 | どちらでもよい。自分で提案した学生は、テーマが降りてくる会社と合わないことがある |
| 人に説明した経験 | 「学会で発表した」「専門外の人に説明した」 | 専門外の面接官に話せるか |
| 手を動かした量 | 「実験を〇回」「試料を作った」 | 評価と分析の最初の年と重なる |
| 学部卒か修士か | 学年 | 学部卒を採るなら、学部生も読む |

「詰まった場面でどうしたか」を書いている学生が、研究開発職と重なります。四つの進め方の型は[OfferBoxで研究開発職志望の学生を見つける検索の考え方](/media/ob-kenkyu-target/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

理系向けの文面の型は[ワンキャリアで理系学生にスカウトを送る文面](/media/oc-scout-rikei/)で書きました。研究開発職では、次の点を足します。

- **相手の一文は、詰まった場面で**：「結果が出ず条件を変えて〇回試したと書かれていたのを読んで」。テーマの名前を褒めない
- **何を研究するかを、一文で**：「最初に任せたいのは、いまの△△の改良です。新しい〇〇を作る研究は□年目からです」
- **テーマの決め方を、一文で**：「テーマは部門の方針で決まり、□年目から提案できます」
- **分野との関係を、一文で**：「研究の分野は問いません。分野が違う先輩が〇人います」
- **面接での聞き方を、一文で**：「面接では研究の深さではなく、詰まった場面でどうしたかを聞きます」
- **送り主は、研究開発で入った先輩**：人事の名前で「研究に興味のある方」と送らない

## 選考への接続｜研究の聞き方の型を揃える

- **研究の聞き方の型を、一つに決める**：「テーマの説明は短く。聞くのは、詰まった場面でどうしたか、なぜその方法を選んだか、結果が出なかったとき何をしたか」。面接官が変わっても同じ
- **専門外の面接官がいるなら、そう言う**：「私は専門外なので、専門外の人に伝わるように話してください」と最初に言う。学生は専門外の面接官に深く突っ込まれることを体験談で恐れている
- **テーマの決め方を、聞かれる前に話す**：「降りてくる」なら、そう言う。面接で「自由に研究できる」と言い、入社後に降りてくると、体験談に書かれる
- **研究と仕事が離れている場合は、離れていると言う**：「あなたの分野とは違うが、進め方を見て声をかけた」
- **内定後に、研究の場を見せる**：実験室と、先輩のテーマの進め方を。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 何を研究するか、テーマの決め方、最初の年、分野との関係、学部卒と博士の扱いを決める | 研究開発の責任者 |
| 企業ページの研究開発職の記述 | 人事が、責任者と先輩に聞いて書く |
| 先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「評価と分析だった」「テーマは降りてくる」と書かれていないか） |
| スカウトの一文 | 先輩 |
| 面接 | 責任者と先輩。研究の聞き方の型を揃えて。専門外の面接官は最初にそう言う |

運用代行や代理店が支えられるのは、掲載の型、テーマの決め方を文で書く直し方、研究の聞き方の型の整理、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、研究の内容の決定、分野との関係の判断、面接、先輩の話は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

研究開発職の内定辞退が続く会社から相談を受けたとき、当社が最初に切り分けるのは、「辞退の理由が、研究の内容か、テーマの決め方か、面接の聞き方か」です。研究の内容が理由なら、掲載に「何を研究するか」を具体に書けば、合わない学生はエントリーの前に離れ、辞退は減ります。テーマの決め方が理由なら、「降りてくる」と書いて、面接でも言うことで、自分でテーマを持ちたい学生が先に離れます。面接の聞き方が理由なら、研究の聞き方の型を揃え、専門外の面接官が最初にそう言うことで、「深く突っ込まれて答えられなかった」が体験談から消えます。三つは直し方が違うので、辞退した学生の体験談と、内定者の面談の記録を読んで、どれかを切り分けてから直します。「研究開発職は辞退が多い」と一括りにして、掲載の全体を書き直す会社が多いのですが、理由が一つなら、直すのも一か所で足ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「研究開発職」の名前だけで書く | 何をするか分からず、「評価と分析だった」と書かれる | 何を研究するか、最初に任せるのはどちらかを書く |
| テーマの決め方を書かない | 「降りてくる」と体験談に書かれる | 決め方と、提案できる時期を書く |
| 分野とキーワードで絞る | 進め方が合う学生を落とす | 詰まった場面の記述で読む |
| 専門外の面接官が深く突っ込む | 「答えられなかった」と書かれ、辞退する | 型を揃え、専門外と最初に言う |
| 面接で「自由に研究できる」と言う | 入社後に降りてきて、離れる | 決め方をそのまま言う |

## まとめ

- 研究開発職志望の学生は、体験談で「何を研究するか・テーマは誰が決めるか・自分の研究とつながるか・最初の年・修士でなくても採るか・面接で研究をどう聞かれるか・先輩の実態」を読む
- 掲載には、何を研究するか、テーマの決め方と提案できる時期、分野との関係、最初の年、学部卒と博士の扱い、面接での聞き方を書く
- ワンキャリアが向くのは「分野を問わず進め方で採る」会社。分野を限るなら、無理に出さない
- 学生は、分野ではなく「詰まった場面でどうしたか」の記述で見つける
- 研究の聞き方の型を一つに決め、専門外の面接官は最初にそう言う。辞退の理由は、内容・テーマの決め方・聞き方のどれかに切り分けて直す

## よくある質問

### テーマが上から降りてくる会社です。書くと学生が来なくなりませんか

自分でテーマを持ちたい学生は来なくなりますが、その学生は入社後に離れる学生です。「テーマは部門の方針で決まる。□年目から提案できる。提案が通った例が〇件」と、決め方と、提案できる時期と、通った例を書きます。降りてくるテーマの中で工夫した先輩の話を添えると、「降りてくる」の意味が学生に伝わります。書かずに面接で「自由に研究できる」と言うと、体験談に書かれます。

### 学部卒も採りたいのですが、修士の学生ばかり来ます

「学部卒が〇人。最初の年は修士と同じ」と企業ページに書きます。学部生は、研究開発職は修士に限られると思い込んでいて、体験談に学部卒の話が無いとエントリーしません。学部卒の先輩の話を一つ載せ、スカウトは学部生にも送り、「学部卒の先輩が〇人います」と一文入れます。学部生の研究は途中のことが多いので、面接では「いまどこで詰まっているか」を聞きます。

### 研究開発職の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、テーマの決め方を文で書く直し方、研究の聞き方の型の整理、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。研究の内容の決定、分野との関係の判断、面接、先輩の話は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
