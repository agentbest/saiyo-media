Wantedlyの募集記事は、読まれている。管理画面の閲覧の動きはある。ところが、「話を聞きに行く」が来ない。読まれているのに応募が来ないなら、原因は「読まれない」とは別の場所にあります。**結論から言うと、読まれているのに来ない原因は四つです。記事に「話を聞きに行く理由」がない、話を聞きに行った先で何が起きるかが見えない、条件で止まっている、記事から会社ページに行って止まっている。段で切り分け、「話を聞きに行く」の敷居から直します。選考ではないと明記し、誰と話すか、時間と形式を書き、スカウトと募集記事をつなぎ、応募が来ない期間に記事を増やさず、月に一か所ずつ直します。** この記事では、「読まれない」との分け方、四つの原因とサインと直し方、敷居の下げ方、スカウトとのつなぎ、記事を増やさないこと、月に一か所、分担を整理します。読まれない場合は[Wantedlyの募集記事が読まれないときの見直し順](/media/wt-pv-nai/)、来た人が合わない場合は[Wantedlyの応募者の質が合わないときの直し方](/media/wt-oubo-shitsu/)で書きました。

## この作業の目的｜「読んだ人」を、「話を聞きに行く人」に変える

読まれているのに来ないとは、記事を開いて読み終えた候補者が、「話を聞きに行く」を押していない、ということです。押さない理由は、記事の中にあります。

目的は、押さない理由を四つのどれかに絞り、そこを直すことです。読まれる数を増やすことではありません。

## 「読まれない」と「応募が来ない」を、分ける

| 状態 | 管理画面で見える形 | この記事の対象か |
|---|---|---|
| 読まれていない | 閲覧の動きが小さい | 対象外。[Wantedlyの募集記事が読まれないときの見直し順](/media/wt-pv-nai/) |
| 読まれているが、来ない | 閲覧の動きはあるが、「話を聞きに行く」がない | 対象 |
| 来ているが、合わない | 来ているが、面談で募集の意図と合わない | 対象外。[Wantedlyの応募者の質が合わないときの直し方](/media/wt-oubo-shitsu/) |

管理画面で何が見えるかは、現在の仕様を管理画面とヘルプで確認してください。「読まれているか」が分からないまま「応募が来ない」を直すと、直す場所を間違えます。

## 応募が来ない、四つの原因

| 原因 | サイン | 直し方 |
|---|---|---|
| 1. 「話を聞きに行く理由」がない | 記事が会社説明と業務内容で終わり、「この募集で何をやるか」が候補者の「自分のことか」にならない | 「こんなことやります」を場面で。「一緒に働く人」を名前で |
| 2. 行った先で何が起きるかが見えない | 「話を聞きに行く」を押したら選考が始まるのか、誰と何を話すのかが書かれていない | 選考ではないと明記。誰と、何分、オンラインか対面か |
| 3. 条件で止まっている | 条件が冒頭にあり、求人票として読まれて閉じられる。または条件が書かれておらず不安で止まる | 条件は隠さず、最後に、短く |
| 4. 会社ページで止まっている | 記事から会社ページに行き、「なにを・なぜ・どうやって」が薄く、戻ってこない | 会社ページを整える |

四つは、記事を候補者の目で読み直すと、どれかが見えます。一つに絞って直します。

### エージェントベストの見解

相談で最も多い思い込みは、「応募が来ないなら、記事を増やして入口を増やせばよい」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、読まれているのに来ない記事を増やしても、同じ理由で来ない記事が増えるだけで、応募は増えません。読まれているのに来ない記事の多くは、「話を聞きに行く」を押したら何が起きるかが書かれていません。候補者の側から見ると、押した瞬間に選考が始まるのか、誰と話すのか、どのくらいの時間か、が分からないまま押すのは重く、「あとで」になり、そのまま閉じます。当社が「来ない」の相談を受けるとき、最初にやるのは、記事の末尾に「話を聞きに行く」の先で何が起きるかが書かれているかを確かめることです。一段落足すだけで、変わることがあります。

## 1. 「話を聞きに行く理由」を、記事に作る

- **「この募集で何をやるか」を、最初の数か月の場面で書く**：「入って最初の月は〇〇を先輩と二人で」
- **「一緒に働く人」を、名前と一文で**：「この記事を書いている私は、去年△△を担当していました」
- **「なぜこの募集をするか」を、会社の「なぜ」とつなげて一段落**：繰り返さず、つなげる
- **「求める動き方」を、条件ではなく行動で**：「自分で決めて進めたい人」

「理由」は、候補者が「自分のことか」と思える具体です。書き方は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)と[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

## 2. 「話を聞きに行く」の先を、見えるようにする

- **「選考ではありません」と明記する**：押しても選考が始まらないことを、一文で
- **誰と話すか**：「この記事を書いた〇〇と、現場の△△が出ます」
- **時間と形式**：「オンラインで、短い時間です」（時間の目安は自社の実態で）
- **何を話すか**：「お互いを知る場です。仕事の話と、あなたの話を」
- **その後どうなるか**：「話したあと、進むかどうかはお互いに決めます」

カジュアル面談の設計は[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。記事の末尾に、この一段落を置きます。

## 3. 条件の位置と、有無

- **条件が冒頭にあるなら、最後に移す**：求人票として読まれない形に
- **条件が書かれていないなら、最後に短く書く**：勤務地、働き方の形、給与の扱いは自社の制度と管理部門で確認して、事実で
- **「応相談」で濁さない**：候補者は判断できず、止まる
- **条件で止まっているかは、面談で「条件を見て迷ったか」を聞くと分かる**

条件の扱いは[Wantedlyの募集記事に条件をどこまで書くか](/media/wt-boshu-joukenn/)で書きました。

## 4. 会社ページで止まっていないか

- **記事から会社ページに行く候補者は多い**：会社ページの「なにを・なぜ・どうやって」が薄いと、戻らない
- **会社ページの冒頭を、代表の言葉で**：[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)
- **メンバーの顔が見えるか**：[Wantedlyの会社ページのメンバー](/media/wt-kaisha-page-member/)
- **記事と会社ページで、言っていることが揃っているか**：記事で「自分で決めて進める」、会社ページで「指示に従う文化」では止まる

## スカウトと、募集記事をつなぐ

- **募集記事だけで待たず、スカウトで「この記事を読んでほしい」と届ける**：記事は入口で、スカウトは届ける手段
- **スカウトの文面で挙げた「重なり」を、記事の「こんなことやります」に置く**：文面と記事がつながっていると、「話を聞きに行く」が押される
- **スカウトから記事に来た候補者は、「読んだ理由」がある**：記事だけで来た候補者より、進みやすい
- **つなぎ方は[Wantedlyのスカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)**

「応募が来ない」を、記事だけで直そうとせず、届ける手段を持つことも、直し方の一つです。スカウトの基本は[Wantedlyのスカウトの基本](/media/wt-scout-kihon/)で書きました。

## 応募が来ない期間に、記事を増やさない

- **来ない理由が直っていない記事を増やしても、来ない記事が増える**
- **一つの記事で「話を聞きに行く」が来る形を作ってから、増やす**
- **増やすなら、「何をやるか」が違う募集に分ける**：同じ内容を言い換えた記事を増やさない。[Wantedlyの募集記事を複数に分ける判断](/media/wt-boshu-fukusu/)
- **来ない記事は、閉じる判断もある**：[Wantedlyの募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)の「閉じる・分ける判断」

## 月に一か所ずつ

- **四つの原因のうち、一つに絞る**
- **その一か所を直し、一か月、「話を聞きに行く」の動きを見る**
- **変わらなければ、次の原因へ**：戻して、次
- **記録を残す**：「〇月、末尾に面談の説明を追加。話を聞きに行く：△△」
- **来た人が合っているかは、別の段**：来たあとは[Wantedlyの応募者の質が合わないときの直し方](/media/wt-oubo-shitsu/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「読まれない」と「来ない」を管理画面の動きで分ける | 人事 |
| 四つの原因のどれかに絞る | 人事 |
| 「こんなことやります」と「一緒に働く人」を場面で書く | 現場の人が話し、人事が書く |
| 「話を聞きに行く」の先を一段落で書く | 人事 |
| 条件の位置と有無を直す | 人事と管理部門 |
| 会社ページを整える | 人事と代表 |
| スカウトで記事を届ける | 人事（送る人） |
| 月に一か所直し、記録する | 人事 |

運用代行や代理店が支えられるのは、原因の切り分け、「話を聞きに行く」の先の一段落の型、条件の位置の整理、会社ページの項目の案、スカウトとのつなぎ方の型までで、場面を話すこと、書くこと、面談、条件の決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。Wantedlyで応募が来ない会社から、「応募のボタンを目立たせたい」「応募の特典を付けたい」と相談されることがあります。当社は、それを勧めません。Wantedlyの「話を聞きに行く」は、応募ではなく、「お互いを知る場に行く」という敷居の低い動きで、それを「応募」として目立たせたり特典を付けたりすると、敷居が上がるか、特典目当ての候補者が来ます。当社がお願いするのは、「話を聞きに行く」の先で何が起きるかを一段落で書き、敷居を下げることです。押した先が見えれば、候補者は押します。見えなければ、どれだけ目立たせても押しません。

## まとめ

- 「読まれない」と「応募が来ない」を管理画面の動きで分ける。読まれているのに来ないなら、原因は記事の中にある
- 四つの原因は、「話を聞きに行く理由」がない・行った先が見えない・条件で止まる・会社ページで止まる。一つに絞る
- 「話を聞きに行く」の先を、選考ではない・誰と・時間と形式・何を話す・その後、の一段落で記事の末尾に置く
- 条件は隠さず最後に短く、会社ページの「なにを・なぜ・どうやって」を整え、記事と会社ページで言っていることを揃える
- スカウトで記事を届け、来ない期間に記事を増やさず、月に一か所ずつ直して記録する

## よくある質問

### 「選考ではありません」と書くと、本気の候補者が来なくなりませんか

Wantedlyの「話を聞きに行く」は、もともと選考ではなく「お互いを知る場」に行く動きです。「選考ではない」と書くことで、敷居が下がり、話を聞きに来る候補者が増え、その中から進む候補者が出ます。「本気」は、話を聞いたあとに決まるもので、押す前に求めると、押されません。

### 記事を直しても、来ません

一か所ずつ、一か月ずつ見て、四つの原因を順に潰します。それでも来なければ、記事だけで待つ形から、スカウトで届ける形に変えます。記事は入口で、届ける手段がなければ、読まれても来ないことがあります。スカウトの始め方は[Wantedlyのスカウトの基本](/media/wt-scout-kihon/)で書きました。

### 応募が来ないときの見直しは、御社に相談できますか

できます。当社は、原因の切り分け、「話を聞きに行く」の先の一段落の型、条件の位置の整理、会社ページの項目の案、スカウトとのつなぎ方の型を支えられます。場面を話すこと、書くこと、面談、条件の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
