プロダクトマネージャー（PdM）を新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『PdM候補』『PdMコース』で募集すると、『事業を作りたい』『何を作るかを決めたい』の学生が多く来るが、面談で『最初の年は仕様の下書きと数字の集計です』と聞いて離れ、残った学生も入社後に『何も決められない』と体験談に書く。権限の線を書かずに出したので、面談で『何を決められますか』に答えられない」という問題です。**結論から言うと、新卒をプロダクトマネージャーとして採る会社は少なく、「PdM候補」で募集すると、学生は「入社してすぐ何を作るかを決められる」像で来て、最初の年が仕様の下書きと数字の集計だと離れます。媒体を選ぶ前に「新卒がいつからPdMか（入社から・〇年後・コースではなく配属の一つ）」と「何を決める権限があり、誰と決め、決まらなかったとき誰が決めるか」を先に決め、志望職種と「事業を作りたい」の言葉で絞らず、「作る前に誰に聞いて何を変えたか・作ったものが使われず直したか・やらないと決めたか」の行動で探します。送る型は行動で絞ってPdMの名義で、記事を置く型は決めた場面と決まらなかった日を、比べられる場は「新卒PdMは名ばかり」の体験談に対して企業ページに権限の線と最初の年を先に書きます。** 総合職の選び方は[総合職の採用媒体の選び方](/media/hikaku-sogo-erabikata/)、マーケターは[マーケターの採用媒体の選び方](/media/hikaku-marketer-erabikata/)で書きました。この記事はプロダクトマネージャーに絞ります。

## プロダクトマネージャーの採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「PdM候補」「PdMコース」で募集する | すぐ決められる像で来て、最初の年の実務で離れる | いつからPdMかと最初の年を職種名より先に書く。[Wantedlyでプロダクトマネージャーを採る募集記事の書き方](/media/wt-pdm-boshu/) |
| 「事業を作りたい方」で絞る | 志望の言葉は多いが、決めた経験があるかは分からない | 言葉を外し、行動で絞る |
| 権限の線が書かれていない | 「何も決められない」が体験談に書かれる | 何を決める権限があり、誰と決め、決まらなかったとき誰が決めるかを書く |
| 新卒がいつからPdMかが書かれていない | コースの募集に見えて、実際は配属の一つ。「PdMで入ったのに違った」 | 入社からか、〇年後か、配属の一つかを書く |
| エンジニアとデザイナーとの関係が書かれていない | 「言っても作ってもらえない」と離れる | 優先順位を誰が決め、作らないと決めるのは誰かを書く |

## 判断軸を、プロダクトマネージャーに当てる

| 軸 | プロダクトマネージャーでの見方 |
|---|---|
| 対象（誰に届くか） | 志望職種と「事業を作りたい」の言葉を見ない。「作る前に誰に聞いて何を変えたか・作ったものが使われず直したか・やらないと決めたか」の行動で探す。エンジニア志望、デザイナー志望、営業・企画志望の中に、作る前に人に聞いて変えた学生と、やらないと決めた学生がいる |
| 型（送るか、来るか、比べられるか） | 送る型は、行動で絞ってPdMの名義で「あなたの作ったものが使われず直した経験を読んで」と一人に書ける。志望が多いので、送る型では絞りを強くする。来る型は、決めた場面と、決まらなかった日と、やらないと決めた話を記事で通年で。比べられる型は、「新卒PdMは名ばかり」の体験談に対して、企業ページに権限の線と最初の年を先に書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | PdMが名義と面談を持つ時間。リリースの前後で埋まるので、枠を先に固定しないと運用が止まる。PdMが一人の会社では、その一人の時間がすべて |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。プロダクトマネージャーでは、「対象」を志望の言葉ではなく決めた行動で絞ることと、「運用工数」がPdM一人の時間に集中することが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「PdMは人気で、『事業を作りたい』学生に送れば集まる。新卒から任せると書けば差がつく」というものです。当社は3媒体すべての販売パートナーとして、プロダクトマネージャーの採用の相談を受けますが、「新卒から任せる」と書いた会社は、面談で「何を決められますか」と聞かれて答えが割れ、入社後に「何も決められない」と体験談に書かれます。新卒をPdMとして採る会社は少なく、多くの会社では、新卒は仕様の下書きと数字の集計と、エンジニアとデザイナーとの間の調整から入ります。それ自体は問題ではなく、問題は、それを書かずに「PdM候補」で出すことです。当社が最初にお願いするのは、「新卒がいつからPdMか」と「何を決める権限があり、誰と決め、決まらなかったとき誰が決めるか」を、PdMと経営で決めて書くことです。「入社から」なら権限の線を、「〇年後」なら最初の年の実務と、その年に何を任せるかを書きます。絞る条件からは「事業を作りたい」の言葉を消し、「作る前に誰に聞いて何を変えたか・作ったものが使われず直したか・やらないと決めたか」を「優先する条件」に上げます。

## 学生が、確かめること

- **新卒がいつからPdMか**：入社からか、〇年後か、コースではなく配属の一つか。「PdMで入ったのに違った」が最も多く書かれる
- **何を決める権限があるか**：優先順位か、仕様か、作らないと決めることか。決められないことは何か
- **誰と決め、決まらなかったとき誰が決めるか**：エンジニア、デザイナー、営業、経営との関係。最後に決めるのは誰か
- **最初の年に何を任されるか**：仕様の下書きか、数字の集計か、小さな機能の一つか。自分で決める機能はいつからか
- **エンジニアとデザイナーとの関係**：言ったものが作られるか。作らないと言われたとき、どうするか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 行動で絞りを強くし、PdMの名義で「あなたの作ったものが使われず直した経験を読んで」と一人に書ける | 企業から送る型（OfferBox） | 志望の言葉を見ずに、エンジニア・デザイナー・営業志望の中から決めた行動で探せる |
| PdMが、決めた場面と決まらなかった日を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | エンジニアとPdMが読みに来る場で、「名ばかり」の像を、決めた場面と決まらなかった日の記事で置き換える。[Wantedlyでプロダクトマネージャーにスカウトを送る文面](/media/wt-pdm-scout/) |
| 体験談があり、企業ページに権限の線と最初の年を先に書ける | 学生が並べて比べる場（ワンキャリア） | 「新卒PdMは名ばかり」の体験談に対して、入る前に線と最初の年が分かる会社として読まれる |
| 新卒がいつからPdMか、権限の線が決まっていない | どれも先ではない | PdMと経営で決めてから |
| PdMの面談の枠が確保できていない | どれも先ではない | 人事だけの面談では「何を決められるか」に答えられず、運用が止まる |

どれか一つが正解ではなく、行動で絞れるか、PdMが書けるか、体験談があるかで、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせる**：文面で直した経験を読んだ一文を、記事で決めた場面と決まらなかった日を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **エンジニア・デザイナーの探し方と重ねる**：[エンジニアの採用媒体の選び方](/media/hikaku-engineer-erabikata/)、[デザイナーの採用媒体の選び方](/media/hikaku-designer-erabikata/)。作る側の志望の中に、作る前に人に聞いて変えた学生がいる
- **面談の聞き方の型を、揃える**：「作りたいものより、作る前に誰に聞いて何を変えたか、使われなかったとき何を直したか、やらないと決めた理由は何か」。人事とPdMで同じ型
- **内定前に、決める場面を見せる**：優先順位を決める会議と、作らないと決めた記録と、決まらなかった日の話を。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)
- **代行と組み合わせるなら、絞る作業と文面の下書きまで。読んで直すのはPdM**：[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「PdM候補」ではなく、いつからPdMで、何を決められ、決まらなかったとき誰が決めるか

- **「PdM候補」「PdMコース」「事業を推進」「裁量が大きい」を消す**：すぐ決められる像で来て、最初の年で離れる
- **新卒がいつからPdMかを、最初に**：「入社からPdM」か「最初の〇年は△△を担い、□年目からPdM」か「総合職で、PdMは配属の一つ」か。配属の一つなら、PdMの募集として出さない
- **権限の線を、書く**：「優先順位と仕様はPdMが決める。作らないと決めるのもPdM。価格と人員は経営。決まらなかったときは〇〇が決める」。決められないことを隠さない
- **最初の年を、時期で**：「最初の〇か月は仕様の下書きと数字の集計。小さな機能を一つ決めるのは△か月目から。自分の判断で作らないと決めるのは□年目から」。下書きが多いなら、下書きで使う人を覚えると、意味を書く
- **エンジニアとデザイナーとの関係を、実態で**：「言ったものがそのまま作られることは少ない。作らないと言われたとき、〇〇する」

| 行動で絞る条件 | PdMが作り、人事か代行が絞る |
| 文面と記事 | PdMが話し、人事が書き、本人が確認 |
| 名義と、オファーの一文 | PdM |
| 面談 | PdMと人事。聞き方の型を揃えて。志望の熱さで決めない |
| 「思っていたのと違う」の回数の記録 | 人事。権限か、最初の年か、他社かを分けて |

運用代行や代理店が支えられるのは、絞る条件の型、絞る作業、文面の下書き、記録の型までで、いつからPdMかの決定、権限の線の決定、名義、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

プロダクトマネージャーの採用で、申し込んだあとに運用が止まる会社に共通するのは、PdMが一人で、その一人の時間がリリースで埋まり、面談の候補日が出せないことです。人事が承認を集めても、PdMがリリースの前後で出られず、承認から面談までの間に学生は他社で決まります。当社が案内するのは、送り始める前に、PdMの面談の枠をリリースの計画の外に週に何回置くかを固定し、その枠の数から送る数を逆算することです。PdMが一人なら、枠は少なく、送る数も少なくなります。少ない数を、行動で強く絞って、一人ひとりにPdMの名義で書きます。枠に合う数を送って全員にPdMが会う状態のほうが、内定後の辞退が減ります。

## まとめ

- 新卒をPdMとして採る会社は少なく、「PdM候補」で出すと、すぐ決められる像で来て最初の年で離れる。「新卒がいつからPdMか」と「何を決める権限があり、誰と決め、決まらなかったとき誰が決めるか」を先に決めて書く
- 志望職種と「事業を作りたい」の言葉で絞らず、「作る前に誰に聞いて何を変えたか・作ったものが使われず直したか・やらないと決めたか」の行動で、エンジニア・デザイナー・営業志望も含めて探す
- 学生が確かめるのは「いつからPdMか・何を決める権限があるか・誰と決めるか・決まらなかったとき・最初の年・エンジニアとデザイナーとの関係」。決められないことを隠さない
- 送る型（OfferBox）は行動で絞りを強くしてPdMの名義で、記事を置く型（Wantedly）は決めた場面と決まらなかった日を、比べられる場（ワンキャリア）は「名ばかり」の体験談に対して企業ページに権限の線と最初の年を先に
- PdMの面談の枠をリリースの外に先に固定し、その数から送る数を決める

## よくある質問

### 新卒にはまだ決める権限を渡せません。PdMとして募集してよいですか

「入社からPdM」として出すなら、権限の線を書く必要があります。渡せないなら、「最初の〇年は△△を担い、□年目からPdM」と、いつからかを最初に書きます。それも決まっていないなら、PdMの募集として出さず、総合職か企画職として出し、PdMは配属の一つと書きます。決まっていないまま「PdM候補」で出すことが、体験談に「名ばかり」と書かれる原因です。

### 「事業を作りたい」学生は多いのに、面談で残りません。何を変えればよいですか

絞る条件から志望の言葉を消し、「作る前に誰に聞いて何を変えたか」「作ったものが使われなかったとき何を直したか」「やらないと決めた理由」を読んで絞ります。志望の言葉は多く、決めた経験は少ないので、対象は絞れます。面談でも同じ型で聞き、熱さで決めません。

### プロダクトマネージャーの媒体選びは、御社に相談できますか

できます。当社は、絞る条件の型、絞る作業、文面の下書き、記録の型を支えられます。いつからPdMかの決定、権限の線の決定、名義、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、プロダクトマネージャーの媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
