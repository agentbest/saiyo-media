ワンキャリアで営業職を募集したとき、最初にぶつかるのは「『営業職』『総合職（営業）』で掲載し、『人物重視』『成長できる』と書いたのに、エントリーが少ない。来ても、面接で『数字に届かなかったらどうなりますか』『新規ですか、既存ですか』と聞かれ、答えた内容が体験談で『聞いていた話と違う』と書かれる」という問題です。**結論から言うと、ワンキャリアの営業職の掲載は、「営業職」の名前ではなく「誰に、何を、新規か既存か、数字がどう決まり、届かないとき何が起きるか」を、学生が体験談で読む前に企業ページと募集に書き、スカウトと面接でも同じ言葉で話します。** この記事では、営業志望の学生が体験談で読んでいること、掲載に書くこと、営業志望の学生の見つけ方、スカウトの文面、選考への接続、社内の分担、やりがちな失敗を整理します。文系学生向けの掲載の全体は[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/)、スカウト文面の型は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。この記事は、営業職に絞って、掲載とスカウトと選考をつなげて書きます。

## 営業志望の学生が、体験談で読んでいること

ワンキャリアの学生は、企業ページを読む前に、選考の体験談と、その会社の営業で入った先輩の話を読んでいます。営業職は、体験談で最も実態が書かれる職種の一つです。

| 読んでいること | 掲載への意味 |
|---|---|
| 誰に、何を売る営業か | 企業か個人か。何の商品か。「営業職」の名前では分からない |
| 新規か、既存か | 自分で探して開拓するのか、いる顧客を深めるのか。体験談で最も聞かれる |
| 数字の扱いと、届かないとき | 目標があるか、どう決まるか、届かないとき何が起きるか。「詰められる」の有無 |
| 最初の年に何をするか | 同行の期間、一人で持ち始める時期、最初の年の終わりの姿 |
| 営業で入った先輩の実態 | 文系で営業に入った人が、何に困り、いまどうしているか |
| 離職の有無 | 営業で入った人が続いているか。辞めた理由が体験談にあるか |
| 面接で何を聞かれたか | 学生時代の何を、どう聞かれたか。営業らしさをどう見られたか |

「数字の扱いと届かないとき」が、営業職の体験談で最も読まれ、企業ページで最も書かれない項目です。ここを企業ページに書かないと、学生は体験談の記述を「会社が隠していること」として読みます。

## 掲載に書くこと｜職種名、分担、数字の扱い、体験談との整合

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「総合職」ではなく「営業職」。さらに「企業向けの〇〇の営業」まで。配属が営業に決まっているなら、そう書く |
| 誰に、何を、どう売るか | 「〇〇の業種の△△の担当者に、□□を。問い合わせが〇割、自分で探すのが△割」。割合は確認できる範囲で |
| 新規か既存か | 「最初の年は既存の顧客の引き継ぎから。二年目から新規」のように、時期で |
| 数字の扱い | 「目標はある。本人と話して決める。届かない月は〇〇と一緒に見直す。給与には△△の形で連動する」。事実で。数字そのものは書かなくてよい |
| 最初の年 | 「最初の月は同行。三か月目に小さな案件を一人で。一年目の終わりに〇〇」 |
| 営業で入った先輩の話 | 入る前の不安と、最初の年に困ったことと、いまの実態。盛らない |
| 体験談との整合 | 体験談に書かれている「数字の圧力」「新規の割合」と、企業ページの記述が食い違わないようにする |

企業ページには営業職の実態を、募集には最初の年と選考の流れを、と分担します。分担の考え方は[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「営業職は学生が集まりやすいから、『総合職』で広く出して、営業のことは面接で話せばよい」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの営業職の掲載と選考を見ていますが、「総合職」で出して面接で営業の実態を話した会社は、体験談に「面接で初めて営業と聞いた」「数字の話は面接で初めて出た」と書かれ、次の年の学生がそれを読んで離れます。ワンキャリアは、体験談が企業ページより先に読まれる媒体です。営業職の実態を企業ページに書かないことは、体験談に書かれることを「隠していた」と読まれる形で残します。逆に、「営業職。企業向けの〇〇。新規は△割。数字は本人と決め、届かない月は一緒に見直す」と企業ページに書いた会社は、エントリーの数は減っても、面接で「聞いていた通り」と言われ、体験談にもそう書かれます。当社が最初にお願いするのは、「総合職」を「営業職」に変え、数字の扱いを事実で一文書くことです。

## 営業志望の学生の見つけ方

ワンキャリアで営業職に合う学生は、志望職種の記述だけでは見つかりません。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 志望職種 | 「営業」と書く学生は多いが、実態を知らずに書く学生も多い | あればよい条件。これだけで絞らない |
| 接客や販売のアルバイト | 「〇〇で△△を売った」「断られて、言い方を変えた」 | 断られた後に何を変えたか、が書かれている学生を優先 |
| 体育会・部活 | 数字や順位を追った経験。届かなかったときにどうしたか | 「届かなかった月に何を変えたか」と同じ型 |
| ゼミやサークルの渉外・営業 | 協賛集め、店への交渉、参加者集め | 自分で探して、最初の連絡から決めた経験 |
| ガクチカの「詰まった場面」 | 結果ではなく、詰まったときに何をしたか | 営業の「届かない月」と重なる |

「断られた後に何を変えたか」「届かなかったときに何をしたか」を書いている学生が、営業職と重なります。ガクチカの読み方は[ワンキャリアの学生のガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

スカウト文面の型（学生時代を読んだ一文→最初の1年との重なり→選考で何を見るか→話す場か選考か）は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。営業職では、次の点を足します。

- **相手の一文は、断られた後や届かなかったときのことで**：「〇〇のアルバイトで、断られた後に言い方を変えたと書かれていたのを読んで」
- **誰に何を売るかを、一文で**：「うちの営業は、〇〇の業種の△△の担当者に□□を売ります。新規は◇割」
- **数字の扱いを、隠さず一文で**：「目標は本人と決めます。届かない月は〇〇と一緒に見直します」
- **最初の年を、一文で**：「最初の月は同行、三か月目に小さな案件を一人で」
- **送り主は、営業で入った先輩**：文系で営業に入った先輩の名前で。人事の名前で「人物重視」と送らない

スカウトと掲載の言葉が違うと、学生は「どちらが本当か」と体験談で確かめます。つなげ方は[スカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)で書きました。

## 選考への接続｜数字の扱いを、面接で先に話す

- **面接には、営業の責任者と、営業で入った先輩が出る**：「数字が届かないとき何が起きるか」を、責任者本人が話す。先輩が「最初の年に困ったこと」を話す
- **数字の扱いを、聞かれる前に話す**：「目標はこう決まる。届かない月はこうなる」を、面接の最初のほうで。聞かれてから答えると、「隠していた」と体験談に書かれる
- **学生の「断られた後」を聞く**：アルバイトや部活で、断られた後、届かなかった後に何をしたかを聞く。結果ではなく、そのとき何をしたか
- **内定後に、営業の同行を見せる**：内定の後、実際の同行や営業の一日を見せると、辞退が減る。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)
- **体験談に書かれることを前提に**：面接で話したことは、体験談に書かれる。掲載と面接で同じことを言う

## 社内の分担

| 作業 | 誰が |
|---|---|
| 職種名、誰に何を、新規か既存か、数字の扱いを決める | 営業の責任者 |
| 企業ページの営業職の記述 | 人事が、営業の責任者と営業で入った先輩に聞いて書く |
| 営業で入った先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（体験談を読んで、企業ページと食い違う箇所を直す） |
| スカウトの一文 | 営業で入った先輩 |
| 面接 | 営業の責任者と、営業で入った先輩 |

一人目の営業を新卒で採る会社では、「営業で入った先輩」がいません。その場合は、「新卒の営業は一人目。責任者の〇〇が同行する。数字は最初の年は目標を置かない」のように、一人目であることと、最初の年の扱いを書きます。

運用代行や代理店が支えられるのは、掲載の型、数字の扱いを事実で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりまでで、数字の扱いの決定、先輩の話、面接は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

営業職の内定辞退が続く会社に共通するのは、「数字の扱いを、面接で学生に聞かれて初めて答えた」ことです。当社がワンキャリアの営業職の選考を見ていると、企業ページに数字の扱いが無く、面接で学生が「届かなかったらどうなりますか」と聞き、責任者が答え、その答えが体験談に「面接で数字の話が出た」と書かれる形が多くあります。学生は、聞いて初めて出た話を「隠していた」と読みます。辞退の理由は「数字が厳しいから」ではなく、「聞かないと出てこない会社だから」です。逆に、企業ページに「目標は本人と決める。届かない月は一緒に見直す」と書き、面接の最初のほうで責任者が同じことを話した会社は、数字の扱いが同じでも、辞退が減ります。当社が案内するのは、数字の扱いを企業ページに事実で書き、面接で聞かれる前に責任者が話し、体験談に「聞いていた通り」と書かれる形にすることです。数字の厳しさで学生は離れません。聞かないと出てこないことで離れます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「総合職」で出して、営業のことは面接で話す | 体験談に「面接で初めて営業と聞いた」と書かれる | 「営業職」と書き、誰に何をを企業ページに |
| 数字の扱いを書かない | 体験談の記述を「隠していた」と読まれる | 事実で一文。届かないときの扱いまで |
| 新規の割合を盛る | 面接か入社後に分かり、体験談に書かれる | 確認できる範囲で、割合を正直に |
| 「人物重視」「成長できる」で書く | 何の営業かが分からず、読まれない | 誰に何を、最初の年を、場面で |
| 志望職種「営業」だけで学生を絞る | 実態を知らずに書いた学生が来て、離れる | 断られた後に何を変えたか、で読む |
| 面接に営業の責任者が出ない | 「届かないとき」に答えられない | 責任者が出て、聞かれる前に話す |

最も多いのは、「総合職」と、数字の扱いの抜けです。

## まとめ

- 営業志望の学生は、体験談で「誰に何を売るか・新規か既存か・数字の扱いと届かないとき・最初の年・営業で入った先輩の実態・離職」を、企業ページより先に読む
- 掲載には、「営業職」と職種名を書き、誰に何をどう売るか、新規か既存か、数字の扱いを事実で、最初の年、先輩の話を書く。体験談と食い違わないように
- 営業志望の学生は、志望職種だけでなく、「断られた後に何を変えたか」「届かなかったときに何をしたか」の記述で見つける
- スカウトは、営業で入った先輩の名前で、掲載と同じ言葉で。数字の扱いを隠さない
- 面接には営業の責任者と先輩が出て、数字の扱いを聞かれる前に話す。内定後に同行を見せる。面接で話したことは体験談に書かれる前提で

## よくある質問

### 数字の扱いが厳しい会社です。企業ページに書くと、エントリーが減りませんか

減りますが、面接後の辞退と、入社後の離職が減ります。「目標はある。届かない月は〇〇と一緒に見直す。給与には△△の形で連動する」と事実で書けば、それを前提にエントリーする学生が来ます。書かずにエントリーを集めて面接で出ると、体験談に「面接で初めて数字の話が出た」と書かれ、次の年の学生がそれを読みます。厳しさを書いて減るより、隠して体験談に書かれるほうが、長く響きます。

### 配属が営業に決まっていないのに、営業職として出してよいですか

決まっていないなら、「総合職」ではなく「最初の年は営業から始め、〇〇の時期に本人と話して決める」のように、最初の職種と、変わる時期と決め方を書きます。配属が営業と決まっているのに「総合職」で出すのは、体験談に「面接で初めて営業と聞いた」と書かれる形です。配属の決まり方の書き方は[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/)で書きました。

### 営業職の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、数字の扱いを事実で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくりを支えられます。数字の扱いの決定、先輩の話、面接は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
