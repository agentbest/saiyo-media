ワンキャリアの学生は、届いたスカウトを一通ずつ丁寧に読むより先に、一覧に並んだ冒頭の一文で「読む価値があるか」をふるいにかけます。しかも、その多くはすでに自社のクチコミや選考体験談に目を通しており、「この会社は学生をどう扱うか」の印象を持った状態で一文目を見ます。**結論から言うと、ワンキャリアのスカウトの書き出しには、会社名や挨拶ではなく、「プロフィールのどこを読んだか」か「うちの選考は何を聞くか」を置きます。体験談で持たれている印象と食い違わない一文であることも条件です。煽りや褒め言葉で始めた文面は、開かれても体験談に「テンプレのスカウトだった」と残りやすくなります。** この記事では、一文目が担う仕事、ワンキャリアで開かれにくい書き出し、体験談を踏まえた型、使わない言葉、本文への受け渡し、表示の確かめ方、試し方と記録、分担を整理します。本文の組み立ては[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。一覧や通知で何文字まで見えるかは画面や設定で変わるため、現在の表示は管理画面とヘルプで確認してください。媒体をまたいだ考え方は[スカウトの件名の付け方](/media/kh-bunmen-kenmei/)と[Wantedlyのスカウトの書き出しの工夫](/media/wt-scout-kenmei/)で書きました。

## 一文目が担う仕事｜体験談で持たれた印象を、開く理由に変える

ワンキャリアの一文目に求められるのは、学生に「この連絡は自分を読んだうえで来ている」と判断してもらうことです。会社紹介や募集要項は、開いたあとの本文と企業ページが受け持ちます。

ほかの媒体と違うのは、一文目を見る前に、学生がクチコミや選考体験談で会社の像をある程度つくっていることです。体験談に「面接で学生時代の話を深く聞かれた」とあれば、学生は一文目にもその会社らしさを探します。体験談の印象と一文目がかみ合うと開かれやすく、まったく別の会社のような書き出しだと、警戒されます。

## ワンキャリアで開かれにくい書き出し

| 書き出し | ワンキャリアの学生にどう映るか |
|---|---|
| 「株式会社〇〇人事部の△△です」 | 体験談で見た社名がまた出てきただけ。中身に入る前に閉じられる |
| 「はじめまして」「突然のご連絡失礼します」 | 一覧に出る貴重な一文を、内容のない挨拶で埋めている |
| 「スカウトのご案内」「選考のご案内」 | 何についての連絡か伝わらない |
| 「〇〇大学の△△様へ」 | 差し込みで作れる。読んだ証拠にならない |
| 「〇年卒の皆さまへ」 | 対象を言っているだけで、誰にでも送れる |
| 「素晴らしいご経歴を拝見し」 | 読まずに書ける。体験談で「定型文だった」と書かれやすい |
| 「限定」「特別にご案内」「厳選」 | 煽りに見える。クチコミを読み比べる学生ほど距離を置く |
| 「【急募】」「【早期選考】」 | 求人広告のような見た目。急かされている印象が残る |

いちばん多いのは、社名と部署名から入る形です。ビジネス文書としては自然ですが、ワンキャリアの学生は社名をすでにクチコミで知っているため、一文目に社名を置いても新しい情報になりません。社名は署名に移します。

## 体験談を踏まえて使える型

| 型 | 例（型） |
|---|---|
| プロフィールの活動を名指しする | 「ゼミで三年間続けた調査の話を読み、連絡しました」 |
| 本人が書いた言葉を引く | 「『〇〇がいちばん面白かった』という一文が気になって」 |
| 興味と自社の仕事を結ぶ | 「〇〇に関心があると書かれていたので、うちの△△の話をしたくて」 |
| 入社一年目の仕事との重なり | 「〇〇の経験は、うちの一年目の△△にかなり近いと思い」 |
| 年次の近い社員が名乗る | 「入社二年目の〇〇です。あなたの△△を読んで、話してみたくなりました」 |
| 選考で聞くことを先に言う | 「うちの面接は、学生時代の話を場面ごとに聞きます。あなたの〇〇の話を聞かせてください」 |

上の四つは学生のプロフィールの中身から入る型、下の二つは会社の側から「誰が・何を聞くか」を先に示す型です。どちらも、社名や事業説明は一文目に入れていません。

年次の近い社員が名乗る型は、その社員の名前で実際に送る場合に限ります。体験談で「若手社員が親身だった」と書かれている会社なら、その印象と一文目が重なり、開かれやすくなります。

### エージェントベストの見解

ワンキャリアのスカウトを見直す相談で、よく聞くのが「挨拶と自己紹介を省いたら失礼にあたるのでは」という心配です。当社は求人広告代理店として、ワンキャリアのスカウト運用に関わっていますが、学生が一覧で挨拶だけの一文を見たとき、失礼かどうかを考える前に読み飛ばしている、というのが実感です。反対に「ゼミの調査の話を読んで連絡しました」から入る文面は、挨拶がなくても、体験談に「ちゃんと読んでくれていた」と書かれることがあります。当社が文面に手を入れるときは、社名と挨拶を末尾の署名へ移し、空いた一文目に、その学生のプロフィールから拾った語句を入れるところから始めます。礼儀は定型の挨拶ではなく、相手を読んだ跡で伝わる、という考え方です。

## 体験談の「問い」に一文目で答える

ワンキャリアで特に使いやすいのが、自社の選考体験談に出ている学生の疑問に、書き出しで先回りして答える型です。

- **「うちの面接は、学生時代の話を場面ごとに聞きます」**：体験談に「何を評価しているのか読めなかった」と書かれている会社に向く
- **「一次面接には〇〇職の△△が出ます」**：体験談に「面接官の役割が分からなかった」とある場合
- **続けてプロフィールの一文を添える**：「あなたの□□の話を、その場で聞かせてください」
- **企業ページの選考フローと内容を合わせる**：一文目だけ違うことを言わない

この型は、自社の体験談を定期的に読み、学生がどこで迷っているかを把握していないと書けません。体験談の読み方は[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。

## 一文目に使わない言葉

| 使わない言葉 | 理由 |
|---|---|
| 煽り（限定、特別、厳選、急募、早期） | 開いた直後に「釣りだった」と分かり、体験談やクチコミで触れられることがある |
| 褒め言葉（素晴らしい、優秀、輝かしい） | 誰にでも書ける |
| 分類の名前（スカウト、ご案内、ご連絡） | 中身が伝わらない |
| 事業の説明（弊社は〇〇業界で） | 学生はクチコミと企業ページですでに知っている |
| 大学名、学部名、卒業年 | 検索条件の言い直しで、読んだ証拠にならない |
| 記号の多用（【】、★、！の連続） | 広告のように見える |
| 「エントリーを」「応募を」 | 開く前から応募を求めている |

煽りの一文目は、開封を一時的に増やしても、本文を読んだ時点で信用を落とします。ワンキャリアではその落差が、体験談という形で次の学生にも伝わります。

## 一文目で触れた話を、本文の冒頭で受け取る

一文目で名指しした活動や言葉は、本文の最初の段落でもう一度取り上げ、話を広げます。

1. **一文目**：「ゼミで三年間続けた調査の話を読み、連絡しました」
2. **本文1段目**：その調査のどの部分を読んだか、もう一歩具体的に
3. **本文2段目**：その経験が、入社一年目のどの仕事と重なるか
4. **本文3段目**：選考の流れと、面接で何を聞くか（企業ページ・体験談と同じ言葉で）
5. **本文4段目**：話す場か、イベントか、選考かの案内
6. **署名**：名前、学生との近さ、会社名

一文目で「ゼミの調査」と言いながら、本文で会社説明から始めると、一文目が釣りに見えます。ワンキャリアの学生は文面のあとに企業ページと体験談で確かめに行くので、本文3段目の言葉は、掲載している内容とそろえておきます。

## 学生の画面でどう見えるかを確かめる

- **管理画面のプレビューや自分宛ての送信で、一文目のどこで切れるかを見る**：送信やプレビューの方法は管理画面とヘルプで確認
- **切れる位置より手前に、学生の中身を置く**：社名や挨拶に文字数を使わない
- **スマートフォンでの表示を見る**：学生は移動中にスマートフォンで一覧を見ることが多い
- **表示は更新されることがある**：画面の仕様は変わるので、時期を決めて見直す

確かめた結果は、文面のテンプレートの横にメモしておくと、担当が替わっても同じ前提で書けます。

## 書き出しの型は、ひと月にひとつずつ比べる

- **募集、絞り込み、本文はそのままにして、一文目の型だけを替える**：「活動を名指し」と「選考を先に」を比べる、など
- **ひと月は同じ型で送る**：週ごとに替えると、反応が出そろう前に次へ移ってしまう
- **見るのは開封の多さではなく、返信と面接での一言**：煽れば開封は増える
- **本文や送る相手を同時に替えない**：何が効いたか分からなくなる

ワンキャリアでは、新しく書かれた体験談やクチコミに、スカウトについての感想が出ることがあります。これも比べるときの材料になります。

## 送った一文目を記録し、面接と体験談で答え合わせする

| 記録すること | 何に使うか |
|---|---|
| 実際に送った一文目 | あとで型を見分ける |
| 使った型（活動／本人の言葉／興味／一年目との重なり／社員が名乗る／選考を先に） | 型ごとの返信の出方を見る |
| 返信が来たか | 型と返信を突き合わせる |
| 面接で学生が挙げた「開いた理由」 | 効いたのが一文目か本文かを分ける |
| 新しい体験談でのスカウトへの言及 | 「読んでくれていた」「定型文だった」のどちらか |

面接で学生が「最初の一文を見て開いた」と話した書き出しこそ、その会社に合った型です。開封の件数より、こうした学生の言葉を集めていきます。

| 作業 | 誰が |
|---|---|
| 一文目の型を決める | 人事 |
| 自社の体験談とクチコミを読み、学生の疑問を拾う | 人事 |
| プロフィールを読み、一文目を書く | 読んだ人（人事か、年次の近い社員） |
| 学生の画面での見え方を確かめる | 人事 |
| 使わない言葉が入っていないか見る | 書いた本人 |
| 送った一文目と型を記録する | 送った人 |
| 面接で「開いた理由」を聞く | 面接を担当する人 |
| 月に一度、比べる型を決める | 人事 |

運用代行や代理店が支えられるのは、型の提供、使わない言葉の確認、表示を確かめる手順、比べ方の設計、記録表のひな形までです。プロフィールを読むこと、一文目を書くこと、面接で聞くこと、自社の体験談を読むことは、企業の側で行います。

### エージェントベストの見解

書き出しを改善したかどうかを、開封の多い少ないで判断する会社は少なくありません。ただ、開封は一覧で目に留まったというところまでで、読んで返信したかどうかとは別の話です。当社がワンキャリアの書き出しを振り返るときは、開封の件数ではなく、面接で学生が「一文目で開いた」と答えた文面を記録から抜き出して、型を確かめます。そこに残るのは、ほとんどの場合、学生自身のプロフィールの語句か、選考で何を聞くかが一文目にあった文面です。煽りの一文目は開封こそ増えても、面接では話題にのぼらず、体験談で否定的に触れられることもあります。一文目の良し悪しは、返信した学生がその一文を覚えているかどうかで見るのが、ワンキャリアでは確かめやすい方法です。

## まとめ

- ワンキャリアの一文目は、体験談やクチコミで会社の印象を持った学生に「自分を読んで送っている」と伝えるためのもの。社名、挨拶、「スカウトのご案内」、大学名、卒業年から入らない
- 効くのは、プロフィールの活動や言葉、興味、一年目の仕事との重なり、年次の近い社員の名乗り、選考で何を聞くか、を一文目に置く型
- 自社の体験談に出ている学生の疑問に、一文目で先に答える型はワンキャリアで使いやすい。企業ページの選考フローと内容をそろえる
- 煽り、褒め言葉、分類名、事業説明、記号の多用、応募の依頼は一文目に入れない。社名は署名へ
- 一文目で触れた話は本文の冒頭で受け取り、表示の切れ目より手前に中身を置く。型はひと月にひとつずつ比べ、面接の一言と新しい体験談で答え合わせする

## よくある質問

### 一文目に挨拶を入れないのは、学生に対して失礼ではありませんか

挨拶をなくすのではなく、置く場所を変えます。一覧に出る一文目は、学生を読んだ内容に使い、「突然のご連絡で失礼します」といった一言は本文の中に入れます。それで丁寧さは十分に保てます。

### 社名が一文目にないと、どの会社からの連絡か伝わらないのでは

一覧では、送り主の会社名が本文とは別に表示されることが多く、一文目に社名を入れなくても伝わります。表示の仕様は管理画面とヘルプで確認してください。ワンキャリアの学生はクチコミで社名を知っていることも多いので、一文目は学生の中身に使います。

### ワンキャリアのスカウトの書き出しの見直しを、御社に相談できますか

できます。型の提供、使わない言葉の確認、表示を確かめる手順、比べ方の設計、記録表のひな形をお手伝いします。プロフィールを読むこと、一文目を書くこと、面接で聞くこと、自社の体験談を読むことは、企業の側で行ってください。当社は求人広告代理店として、ワンキャリアのスカウト運用を支えています。
