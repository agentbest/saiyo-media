Wantedlyで経営企画の募集記事を出したとき、最初にぶつかるのは「『経営に近いポジション』『経営者の右腕』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『数字を作る側ですか、決める側ですか』『作った案は、誰が、どこで決めるのですか』『経営者は何を手放すのですか』を聞かれて答えられない」という問題です。**結論から言うと、経営企画の募集記事は、「経営に近い」ではなく「数字を作る側か決める側か、経営者の何を代わりに引き受け、作った案がどの場で誰に決められ、現場とどう関わるか」を書き、募集記事を書く前に主な仕事を一つに絞り、権限の線引きと経営者が手放すことを決めておきます。** この記事では、経営企画が募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)、スカウト文面の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)で書きました。事業開発との違いは[事業開発を採る募集記事の書き方](/media/wt-bizdev-boshu/)、データを整える側の仕事は[データエンジニア・アナリストを採る募集記事の書き方](/media/wt-data-boshu/)で書きました。

## 経営企画が募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 数字を作る側か、決める側か | 予算や計画の数字を集めて作るのか、その数字をもとに何かを決めるのか。両方か。「経営に近い」では分からない |
| 経営者の何を代わりに引き受けるか | 会議の運営か、数字の管理か、投資家や銀行への説明か、新しい仕組みの設計か。経営者が手放すものは何か |
| 作った案が、どの場で誰に決められるか | 経営会議か、経営者一人か。案を出して終わりか、決まるまで関われるか。決まらなかった案がどうなるか |
| 数字の状態 | 数字が揃っているか。ばらばらで、まとめるところからか |
| 経営者が経営企画をどう見ているか | 「考える相手」と見ているか、「資料を作る人」と見ているか |

「経営者の何を代わりに引き受けるか」と「作った案がどこで決まるか」が、経営企画に特有の点です。「経営に近い」「右腕」の一語では、ここが分かりません。

## 書く前に決めること｜主な仕事を一つに、権限の線引き、経営者が手放すこと、案の決まり方

| 決めること | 選択肢 |
|---|---|
| 主な仕事 | 計画と予算の作成／経営会議の運営／数字の管理と報告／投資家・銀行への説明／新しい仕組みの設計／事業の見直し。最初に任せるものを一つ |
| 数字を作る側か、決める側か | 作る／決める／両方。両方なら、最初はどちらか |
| 経営者が手放すこと | 経営者が一人でやっていることのうち、渡すものを一つ。経営者本人の言葉で |
| 案の決まり方 | 案をどの場に出し、誰が決めるか。決まらなかった案の扱い。経営者が最後に決めることは何か |
| 現場との関係 | 現場の責任者と数字をすり合わせる場があるか。無いなら、作るところから |
| 数字の状態 | 揃っている／ばらばら。まとめる道具の有無 |
| 最初の月に任せること | 一つの数字の整理か、一つの会議の運営か、一つの案づくりか。誰と組むか |

「資料を作る側が中心」「案は出すが、決めるのは経営者」「数字はばらばら」でも構いません。隠さずに書けば、それを前提に読む人が来ます。

## 「なにを」｜経営者の何を引き受け、何を作るか

「なにをやっているのか」は、会社の事業の説明ではなく、この経営企画が経営者から引き受けることと、最初に作るものに絞ります。

- **経営者が手放すことを、経営者の言葉で書く**：「いまは私が、月次の数字を自分でまとめて、経営会議の資料を作っている。ここを渡したい」
- **数字を作る側か決める側かを書く**：「まず、数字をまとめて、経営会議に出す側。慣れたら、案を出す側に」
- **案の決まり方を書く**：「案は月に一度の経営会議に出す。決めるのは経営者。決まらなかった案は、次の月に理由を添えて戻す」
- **数字の状態を書く**：「事業ごとの数字が別々の表にあり、まとめるところから」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

経営企画の募集記事を出す前に、先に決めておかないと効果が出ないのは、「経営者が、自分がいまやっていることのうち、何を手放すか」を経営者本人が一つ決めることです。当社がWantedlyの経営企画の募集を支えるとき、「経営者の右腕」「経営に近い」と書かれているのに、経営者に聞くと「何を任せるかは、来た人を見て決める」という会社が多くあります。経営企画が面談で最初に聞くのは、「経営者は、何を手放しますか」で、ここに答えがないと、「経営者が全部握ったまま、資料だけ作らされる仕事」を想像して離れます。手放すものが小さくても構いません。「月次の数字のまとめと、経営会議の資料は渡す。決めるのは当面私」と書けば、それを前提に読む人が来ます。当社が最初にお願いするのは、仕事の範囲の確認ではなく、経営者本人に「いま自分が一人でやっていて、渡したいことは何か」を一つ、一文で言ってもらうことです。

## 「どうやって」｜案の決まり方と、現場との関係の書き方

| 書くこと | 書き方 |
|---|---|
| 案の決まり方 | どの場に出し、誰が決め、決まらなかった案がどうなるか。「月に一度の経営会議。決めるのは経営者。決まらなかった案は理由を添えて戻す」 |
| 現場との関係 | 現場の責任者と数字をすり合わせる場。「月初に各事業の責任者と数字を見る」。無いなら、無いと |
| 数字の状態と道具 | 揃っているか、ばらばらか。何でまとめているか。「事業ごとに別の表。まとめる道具は無い」 |
| 前に決まった案と、決まらなかった案 | 「〇〇の案を出して、△△の形で決まった」「□□は出したが、決まらなかった。理由は……」。両方書く |

「経営に近い」と書くより、「月次の数字をまとめて経営会議に出す。決めるのは経営者。決まらなかった案は理由を添えて戻す」と書くほうが、仕事の実態が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| 経営企画経験3年以上 | ばらばらの数字をまとめて、経営者が決められる形にしたことがある |
| コンサル出身歓迎 | 出した案が通らなかったとき、理由を聞いて、次の案を変えたことがある |
| 論理的思考力 | 現場の責任者と数字が合わない状態から、すり合わせて一つにしたことがある |
| 経営視点のある方 | 経営者と意見が分かれ、根拠を持って伝え、最後は決まったことに従ったことがある |
| 即戦力 | 最初の月は〇〇の数字のまとめを任せる予定です。△△と組みます |

「出した案が通らなかったとき、理由を聞いて次を変えた」が、経営企画で最も読まれる行動です。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「経営者の何を引き受け、案がどこで決まるか」と同じ言葉で**：相手が「何をまとめて、何の案を出して、どう決まったか」を読み、自社の引き受けることと重ねる。[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)
- **面談には、経営者が出る**：経営企画の面談は、経営者が出ないと「何を手放すか」「案がどこで決まるか」が伝わらない
- **面談で話すのは、手放すことと、決まり方の話**：経営者がいま一人でやっていること、渡したいこと、案の決まり方。相手なら何からまとめるかを聞く
- **決まらなかった案の話をする**：「前に〇〇の案が出て、決まらなかった。理由は……」。決まった話だけにしない

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 主な仕事、権限の線引き、手放すこと、案の決まり方を決める | 経営者 |
| 「なにを」（引き受けること、作る側か決める側か、数字の状態）の下書き | 人事が、経営者に聞いて書く |
| 「どうやって」（案の決まり方、現場との関係） | 経営者が話し、人事が書き、本人が確認 |
| 数字の状態と、前の案の例の確認 | 経営者か、いま数字をまとめている人 |
| 「こんな人」を行動で書く、最初の月の予定 | 経営者と人事 |
| 面談 | 経営者 |

一人目の経営企画を採る募集では、いま経営者が数字のまとめも会議の資料も全部一人でしていることが多くあります。その場合は、「いまは経営者が数字も資料も一人で作っていて、〇〇が回っていない。最初の月は△△の数字のまとめから。案を決めるのは当面経営者」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、手放すことと決まり方を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、主な仕事の決定、手放すこと、案の決まり方、面談は経営者が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「経営企画には『経営者の右腕』『経営に近い』と書けば、優秀な人が来る」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの経営企画の募集と面談を見ていますが、「右腕」「経営に近い」と書いた募集記事より、「経営者が一人でやっている月次の数字のまとめと経営会議の資料を渡す。決めるのは当面経営者。決まらなかった案は理由を添えて戻す」と実態を書いた募集記事のほうが、話を聞きに来る人の経験が合う傾向があります。経営企画の経験がある人ほど、「右腕」を読むと「資料だけ作らされる」を疑います。手放すものが小さくても、決まり方が書かれていれば、「役割が明確な会社」として読まれます。当社が案内するのは、「右腕」「経営に近い」を消し、経営者が手放すことを一つと、案の決まり方と、決まらなかった案の扱いを書くことです。近さの言葉で人は来ません。手放すものと決まり方が書かれていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「経営に近い」「右腕」で書く | 「資料だけ作らされる」を疑われる | 経営者が手放すことを一つ、一文で |
| 作る側か決める側かを書かない | どちらの人も「自分の話が無い」と読む | 最初はどちらかを書く |
| 案の決まり方を書かない | 「案がどこにも行かない」を想像される | 場と、決める人と、決まらなかった案の扱いを書く |
| 現場との関係を書かない | 「本社の人」扱いを想像される | すり合わせる場の有無を書く |
| 数字の状態を盛る | 面談で聞かれ、答えられない | ばらばらなら、ばらばらと書く |
| 面談に経営者が出ない | 「何を手放すか」に答えられない | 経営者が出て、本人の言葉で話す |

最も多いのは、「経営に近い」と、手放すことの抜けです。

## まとめ

- 経営企画が見ているのは、数字を作る側か決める側か・経営者の何を代わりに引き受けるか・作った案がどこで誰に決められるか・現場との関係・数字の状態・経営者が経営企画をどう見ているか
- 書く前に、主な仕事を一つに絞り、作る側か決める側か、経営者が手放すこと一つ、案の決まり方（場、決める人、決まらなかった案の扱い）を、経営者本人が決める。手放すものが小さくても、隠さない
- 「なにを」は経営者が手放すことを経営者の言葉で、作る側か決める側か、数字の状態。「どうやって」は案の決まり方と現場との関係を、頻度と形で。決まらなかった案の例も
- 「こんな人」は経歴ではなく、「ばらばらの数字を決められる形にした」「通らなかった案の理由を聞いて次を変えた」の行動で
- 面談には経営者が出て、何を手放すか、案がどこで決まるかを本人の言葉で話し、決まらなかった案の話をする

## よくある質問

### 経営者が「まず資料を作ってほしい」と言っています。それでも「経営企画」と書いてよいですか

書けますが、「資料を作る側から」と書きます。「いまは経営者が数字のまとめと資料を一人で作っている。まずそこを渡す。案を出す側に進むかは、〇〇の期間で一緒に決める。決めるのは当面経営者」のように、最初の役割と、その先の可能性と、決める人を書きます。

### 案を出しても、経営者が一人で決める会社です。書くと来ませんか

隠すほうが、面談で分かって離れます。「案は経営会議に出す。決めるのは経営者一人。決まらなかった案は、理由を聞いて次の月に戻す」のように、決める人と、決まらなかった案の扱いを書きます。「決まらなかった案に理由が戻る」が書かれていれば、「案がどこにも行かない会社」ではないと読まれます。

### 経営企画の募集記事は、御社に相談できますか

できます。当社は、募集記事の型、手放すことと決まり方を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。主な仕事の決定、手放すこと、案の決まり方、面談は、経営者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
