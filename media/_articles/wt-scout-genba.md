スカウトの送り主が「人事」か「同じ職種の現場社員」かで、受け取る側の読み方は変わります。人事からの連絡は「採用の営業」に見え、同じ職種の人からの連絡は「仕事の話」に見えます。**結論から言うと、Wantedlyのスカウトは、現場社員の名前で送ると開かれやすく、返信後の面談にもつながります。ただし、名前だけを借りて人事が書く形にすると、文面と本人がずれ、面談で「文面と違う」となります。本人と上司の合意を取り、本人のプロフィールを整え、本人が読んで2か所を書き、人事が確認して送り、返信は人事が受けて本人に伝え、本人が面談に出る、という進め方にします。** この記事では、現場の名前で送る効果、やりがちな失敗、進め方、本人のプロフィールに書くこと、本人の負担を小さくする工夫、分担を整理します。分担の全体は[スカウトを誰が送るか](/media/wt-scout-tantou/)で書きました。送り主のアカウントや送信の仕組みは変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜「仕事の話」として受け取ってもらう

受け取る側は、送り主のプロフィールを見ます。人事なら「採用担当からの連絡」、同じ職種の人なら「その仕事をしている人からの連絡」です。

後者のほうが、文面の「この経験がこの仕事で活きる」に説得力が出ます。書いている人が、その仕事をしているからです。返信後の面談でも、送り主本人が出れば、「読んだとおりの人」と話せます。

目的は、「採用の営業」ではなく「同じ仕事をしている人からの、仕事の話」として受け取ってもらうことです。

## 現場の名前で送る効果

| 効果 | なぜ |
|---|---|
| 開かれやすい | 送り主のプロフィールが「同じ職種の人」。書き出しに「〇〇（職種）の△△です」と書ける。書き出しの工夫は[スカウトの書き出しの工夫](/media/wt-scout-kenmei/) |
| 文面に仕事の具体が入る | 本人が書くので、「この経験がどこで活きるか」が具体になる |
| 返信後がつながる | 返信した人は「この人と話したい」と思っている。本人が面談に出れば、そのまま |
| 面談で「読んだとおりの人」が出る | 文面と面談がずれない |
| 現場の協力が続く | 自分の名前で送り、返信が来て、面談で話す。結果が自分に戻る |

効果は、「本人が書いて、本人が出る」ことで生まれます。名前だけでは生まれません。

## やりがちな失敗

| 失敗 | 何が起きるか |
|---|---|
| 名前だけ借りて、人事が書く | 文面は人事の言葉。面談で本人が出ると「文面と違う」。本人が文面を知らない |
| 本人のプロフィールが空 | 送り主を見ても誰か分からない。効果が無い |
| 返信の通知を本人だけが見る形 | 本人は毎日見られず、対応が遅れる |
| 本人が面談に出ない | 「この人と話したい」と返信した人が、別の人と会う |
| 本人と上司の合意が無い | 本人が「勝手に名前を使われた」と感じる。続かない |
| 本人に全部を任せる | 送る枠が取れず止まる。台帳が付かない |
| 複数の募集を、同じ本人の名前で | 本人が全部の面談に出られない |

最も多いのは、最初の「名前だけ借りる」です。効率のためにやりがちですが、効果が無いうえに、面談でずれます。

### エージェントベストの見解

これをやる前に、先に決めておかないと本人との関係が崩れることがあります。「本人の名前で送る文面は、本人が書いたものか、本人が読んで了承したものに限る」ことです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、人事が現場社員の名前で文面を書いて送り、本人がそれを知らないまま面談に出て、候補者に「文面に書いてあった〇〇の話を」と言われて答えられない、ということが起きています。本人は「自分の名前で、自分が言っていないことが送られている」と知り、次から名前を貸しません。当社が現場の名前で送る形を勧めるとき、最初にお願いするのは、「本人が書くか、本人が読んで了承するか、どちらかを省かない」ことです。効率のために名前だけ借りると、効果と信頼の両方を失います。

## 進め方

1. **本人と上司の合意を取る**：「あなたの名前で、あなたが読んで書いた文面を送りたい。返信対応は人事がやる。面談には出てほしい」。週の枠と面談の枠を業務として合意
2. **本人のプロフィールを整える**：送り主として見られる。次の節で
3. **人事が、募集ごとの型と、絞り込んだ読む対象を渡す**：本人が読む数を減らす
4. **本人が読んで、2か所（相手の一文・重なる点）を書く**：型に沿って。書き方は[スカウトを相手ごとに変える範囲](/media/wt-scout-kojinka/)
5. **人事が確認して送る**：避ける言葉、出してはいけない情報、誘導先の募集記事。本人が送っても、人事が送っても、送信の仕組みに沿って
6. **返信は人事が受ける**：通知を人事に集める。翌日までに人事が返し、本人に「返信が来た」と伝える
7. **本人が面談に出る**：人事が日程を組み、本人が話す
8. **結果を本人に戻す**：「面談まで進んだ」「選考に進んだ」

「本人が書く」と「人事が返信を受ける」の組み合わせが、この進め方の中心です。本人には書くことと話すことだけを頼み、毎日の対応は人事が持ちます。返信対応は[返信が来たあとの進め方](/media/wt-scout-henshin-go/)で書きました。

## 本人のプロフィールに書くこと

送り主のプロフィールは、受け取る側が最初に見るものです。

- **いまの職種と、やっている仕事の一文**：「〇〇（職種）。△△の設計を担当」
- **この会社に入った理由か、いまの仕事で面白いと思っていること**：短く、本人の言葉で
- **顔が分かる写真**：普段の様子。会社ページの写真と同じ考え方
- **本人のストーリーがあれば、そこへ**：面談前に読んでもらえる。書き方は[社員インタビューを書く手順](/media/wt-story-interview/)

プロフィールは、本人が書きます。人事が整えるのは、抽象語と事実と特定の3つだけです。

## 本人の負担を小さくする工夫

| 工夫 | 効果 |
|---|---|
| 読む対象を、人事が絞っておく | 読む数が減る |
| 型で、書くのは2か所だけにする | 書く時間が数文分になる |
| 週に一度、まとめて読んで書く枠を予定に入れる | 日々の割り込みにしない |
| 返信対応・日程・台帳は人事 | 本人は毎日見なくてよい |
| 面談の枠を先に決めておく | 返信が来てから探さない |
| 忙しい時期は、送る数を減らすと先に決める | ゼロにせず、続く |
| 結果を戻す | 「意味があった」と分かる |

本人に頼むのは、「週に一度読んで書く」と「面談に出る」の2つだけです。この2つ以外を頼むと、続きません。

## 本人が変わるとき

担当の本人が異動や退職で変わるときの扱いを、先に決めておきます。

- **返信待ちの相手には、人事から「担当が変わります」と伝える**：無言で送り主が変わらないように
- **面談が決まっている相手には、新しい話す人を伝える**：「〇〇に代わって、△△が出ます」
- **本人の名前で送った文面の台帳は残す**：どの一文に返信が来たかは、次の担当にも使える
- **新しい本人のプロフィールを整えてから、送り始める**

送り主が変わることは、受け取る側にとって「話したかった人がいなくなる」ことです。先に伝えれば、面談はつながります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 本人と上司の合意 | 人事 |
| 本人のプロフィールを書く | 本人（人事が3つだけ整える） |
| 募集ごとの型と、絞った読む対象を渡す | 人事 |
| 読んで2か所を書く | 本人 |
| 確認して送る | 人事（本人と確認） |
| 返信を受けて返す | 人事 |
| 面談に出る | 本人 |
| 結果を本人に戻す | 人事 |

運用代行や代理店が支えられるのは、型と見本、本人のプロフィールの整え方、絞り込み、確認の観点、返信の型までで、本人が書くこと、本人が面談に出ること、合意を取ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「現場社員の名前で送るなら、文面は代理店が書いて名前だけ社員にすれば効率的だ」という点です。当社がWantedlyのスカウトの支援をするとき、この形はお受けしていません。当社が書いた文面を社員の名前で送ると、面談でその社員が文面の内容を知らず、候補者との信頼が崩れます。社員も、自分の名前で当社の言葉が送られることを望みません。当社が支えられるのは、社員が2か所を書けば済む型と、読む対象を絞ることと、返信の型までです。2か所を書くのは社員本人で、それが数文で済むように、当社が周りを整えます。名前と言葉は、同じ人のものでなければ、効果が出ません。

## まとめ

- 現場社員の名前で送ると「同じ仕事をしている人からの仕事の話」として開かれ、返信後の面談がつながる
- 名前だけ借りて人事が書く、プロフィールが空、本人だけが返信を見る、本人が面談に出ない、合意が無い、が失敗
- 本人と上司の合意→プロフィール→人事が型と読む対象を渡す→本人が2か所を書く→人事が確認して送る→返信は人事が受ける→本人が面談に出る→結果を戻す
- 本人に頼むのは「週に一度読んで書く」と「面談に出る」の2つだけ。他は人事
- 本人が変わるときは、返信待ちと面談予定の相手に先に伝える。文面は本人が書くか了承したものに限る

## よくある質問

### 現場社員に「自分の名前で送るのは気が引ける」と言われます

送る文面は本人が書き、人事が確認し、返信対応は人事がやる、と伝えます。本人の負担は、週に一度読んで書くことと面談だけです。「あなたの言葉で、あなたが話したい人に送る」形だと分かれば、引き受けてもらえることが多くあります。それでも気が引けるなら、責任者の名前で送る形にします。

### 送り主のアカウントを、社員ごとに用意する必要がありますか

送り主の設定や、アカウントの仕組みは、Wantedlyの仕様によります。現在の仕様を管理画面とヘルプで確認してください。仕組みがどうであれ、「文面は本人が書くか了承する」「返信は人事が受ける」「本人が面談に出る」の3つを保てば、効果は出ます。

### 現場社員の名前で送る運用は、御社に相談できますか

できます。当社は、型と見本、本人のプロフィールの整え方、絞り込み、確認の観点、返信の型を支えられます。本人が書くこと、本人が面談に出ること、合意を取ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
