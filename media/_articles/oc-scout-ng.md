ワンキャリアのスカウトの各段の進め方は、これまでの記事で書いてきました。この記事は、その基本を知っていても起きる失敗を、5つに分けて集めたものです。**結論から言うと、ワンキャリアのスカウトの失敗は「送る前」「文面」「受諾後」「面談」「運用」の5つに分けると直しやすく、受諾が来ないときは、失敗を探す前に「どの段で止まっているか」を切り分けます。切り分けずに文面だけを直しても、原因が企業ページや体験談や受諾への対応にあれば直りません。最も重いのは、失敗が「体験談に書かれて翌年に残る」ことで、他の媒体より失敗の代償が長く続きます。** この記事では、5つの失敗と直し方、送る前のセルフチェック、受諾が来ないときの切り分け、最も重い失敗、分担を整理します。スカウトの基本は[ワンキャリアのスカウトの基本](/media/oc-scout-kihon/)で書きました。

## この作業の目的｜失敗に「気づける」状態を作り、体験談に書かれる前に直す

ワンキャリアのスカウトの失敗は、送っている本人には見えにくいものです。送っているときは「学生に合わせて書いた」つもりで、受け取る学生には「テンプレ」に見えます。

気づける状態を作るには、送る前に5つの観点でチェックすることと、面談で「文面のどこに反応したか」を聞くことと、体験談を読むことの3つです。ワンキャリアでは、学生が体験談という形で反応を書いてくれるので、読めば分かります。ただし、体験談に書かれた時点で、翌年の学生にも読まれます。書かれる前に直すのが目的です。

## 失敗1｜送る前

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 企業ページが会社紹介から始まったまま送る | 文面で興味を持っても、企業ページで離れる | 選考の流れと何を見るかを最初に。[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/) |
| 自社の体験談を読まずに送る | 学生が体験談で読んでいることを知らない | 送る前に全部読む |
| 体験談に「掲載と違った」があるのに送る | 学生が体験談を読んで離れる。読まれるほど不利 | 先に掲載か運用を直す。[掲載でやりがちな失敗](/media/oc-keisai-ng/) |
| 絞り込みが広い | 読めず、テンプレになる | 読める数まで絞る。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/) |
| 大学名や専攻だけで絞る | 「こんな人」と対象がずれる | 学生時代の状態で絞る |
| 時期を確認せずに送る | 年度の扱いとずれる | 年度の公表内容と自社の方針を確認 |
| 受諾に対応する人と面接の枠を決めずに送る | 最初の受諾で止まる | 一人決めて通知を集める。枠から逆算 |

## 失敗2｜文面

| 失敗 | 学生からどう見えるか | 直し方 |
|---|---|---|
| テンプレの一斉送信 | 「誰にでも送っている」。体験談に「テンプレだった」 | 学生時代を読んだ一文と重なる点を毎回書く。[ワンキャリアのスカウトを相手ごとに変える範囲](/media/oc-scout-kojinka/) |
| 会社名や大学名から始める | 営業に見える。読んでいない証拠 | 学生の何を読んだかを最初に。[ワンキャリアのスカウトの書き出しの工夫](/media/oc-scout-kenmei/) |
| 選考を急がせる（「〇日までに」「早期選考」） | 「集まっていない会社」。体験談に書かれる | 急がせない。事実で |
| 選考の話を避ける | 企業ページで選考の流れを探し、無ければ体験談だけで判断 | 選考で何を見るかの一文を入れる。[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/) |
| 話す場か選考かが曖昧 | 「行くと選考に入るのか」 | 曖昧にせず、書いたら守る |
| 企業ページに無い「最初の1年」を文面に書く | 企業ページを見て「文面と違う」 | 企業ページの言葉と揃える |

### エージェントベストの見解

申し込んだあと、ワンキャリアのスカウトで一年後に起きやすいのは、「受諾が来ない理由を文面に求めて、文面を何度も直し、それでも来ず、体験談に『テンプレだった』と書かれてから気づく」ことです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、受諾が来ない会社の原因を段で切り分けると、文面が原因であることは半分もありません。企業ページが会社紹介から始まっている、体験談に「掲載と違った」がある、絞り込みが広くて読めていない、受諾は来ているのに対応が遅い。これらは文面を直しても変わりません。当社が相談を受けるとき、文面を読む前に、企業ページと自社の体験談を開き、台帳で受諾から対応までの時間を見ます。文面は、その次です。ワンキャリアのスカウトの失敗で最も多いのは、文面の失敗ではなく、「文面以外を見ていない」ことです。

## 失敗3｜受諾後

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 受諾への対応が遅い | 他の会社へ。体験談に「返信が遅かった」 | 翌日までに。対応する人と通知。[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/) |
| 文面で「話す場」と書いて、選考に進める | 「文面は釣り」。体験談に書かれる | 文面で案内した場にそのとおりに |
| 受諾に対して、募集の長い説明を送る | 読む負担 | 短く、日程の候補と、誰が話すか |
| 平日の日中だけの日程の候補 | 授業がある学生は選べない | 夕方以降や授業の無い曜日を候補に |

## 失敗4｜面談

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 選考の面接にする | 「話す場」と聞いて来たのに。体験談に書かれる | お互いを知る場に。[スカウト経由の初回面談の設計](/media/oc-scout-mendan/) |
| 人事だけが出る | 「最初の1年の話を、やった人から聞けなかった」 | 送った入社してまもない社員が出る |
| 会社の説明から始める | 企業ページに書いてあること | 体験談で気になったことを先に聞く |
| 文面で案内した人と違う人が出る | 「この人と話せると思った」 | 送り主と話す人を同じに |
| 終わったあとの選択肢が無い | 「楽しかった」で終わる | 三つの選択肢と「今日決めなくてよい」 |

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 上限を使い切ることが目的になる | 読まずに送る。体験談に「テンプレだった」 | 読める数が送れる数。[ワンキャリアのスカウト通数の配分](/media/oc-scout-tsuusuu-haibun/) |

## 送る前のセルフチェック

送る前に、次の順で見ます。数分で済みます。

1. **企業ページが、選考の流れと何を見るかから始まっているか**：始まっていなければ送らない
2. **自社の体験談を読み、「掲載と違った」が無いか**：あれば先に直す
3. **学生のプロフィールを読んだか**：読んでいなければ送らない
4. **文面の最初に、学生時代の具体的な活動か興味が、本人の言葉であるか**
5. **「最初の1年」が、企業ページと同じ言葉か**
6. **選考で何を見るかの一文が、企業ページの選考の流れと同じか**
7. **話す場か選考かが、曖昧でないか。書いたことを守れるか**
8. **会社の説明と条件の羅列が無いか。急がせる言葉が無いか**
9. **時期を、年度の公表内容と自社の方針で確認したか**
10. **受諾に対応する人と、面談の枠は決まっているか**

1と2と4と7の4つだけでも、毎回見ます。

## 受諾が来ないときの、原因の切り分け

| 止まっている段 | 見えるサイン | 直す場所 |
|---|---|---|
| そもそも送っていない | 送った数がゼロに近い | 送る人の枠、絞り込みの結果、設定の誤り |
| 読まずに送っている | 送った数は多いが、一文が薄い | 絞り込みを狭め、読む時間を確保 |
| 開かれていない | 書き出しが会社名や大学名 | 書き出し |
| 開かれたが受諾が無い | 文面はあるが、企業ページが薄いか、体験談に問題 | 企業ページ、体験談 |
| 受諾は来ているが面談に進まない | 台帳で受諾から対応までが長い。日程の候補が学生の都合に合わない | 受諾への対応 |
| 面談はしたが、選考に進まない | 面談の設計、文面と企業ページとの整合 | 面談 |
| 試験期間や長期休み | 受諾が遅れるのは正常 | 待つ。異常と見ない |

## 最も重い失敗｜体験談に書かれて、翌年に残る

5つの失敗の中で、ワンキャリアで最も重いのは、「体験談に書かれる」ことです。

- **「テンプレだった」「返信が遅かった」「話す場と聞いたのに選考だった」は、翌年の学生も読む**
- **翌年に文面を整えても、その体験談が先に読まれる**
- **直すのに、一年かかる**：翌年の選考で守り、翌年の体験談に「自分のことを読んでくれていた」と書かれるまで
- **防ぐのは、送る前**：読める数だけ送る、対応する人を決める、文面で案内した場を守る

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がワンキャリアのスカウトの見直しを支えるとき、5つの観点のチェック、原因の切り分け、直し方の案、体験談の読み方は当社が出せます。ただし、「面談で学生に『文面のどこに反応しましたか』と聞く」ことと、「自社の体験談を読み続ける」ことは、企業にしかできません。前者が無いと、当社も企業も受諾の数だけで判断することになり、文面を煽る方向に寄ります。後者が無いと、「テンプレだった」と書かれたことに気づかず、翌年も同じ文面を送ります。当社が見直しを支えるとき、最初に「面談の型にこの一言を入れ、週の確認に体験談を読むことを入れてください」とお願いするのは、この理由です。ワンキャリアのスカウトの見直しは、書く技術より、聞く一言と読む習慣から始まります。

## まとめ

- ワンキャリアのスカウトの失敗は、送る前・文面・受諾後・面談・運用の5つに分けると直しやすい
- 送る前に、企業ページが選考の流れから始まっているか、体験談に「違った」が無いか、学生を読んだか、話す場か選考かが曖昧でないか、を最低限チェックする
- 受諾が来ないときは、送っていない・読まずに送っている・開かれない・企業ページか体験談の問題・受諾への対応が遅い・試験期間、を切り分けてから直す。文面が原因であることは半分もない
- 最も重いのは「体験談に書かれて翌年に残る」こと。読める数だけ送る、対応する人を決める、文面で案内した場を守る、で防ぐ
- 面談で「文面のどこに反応したか」を聞き、週の確認で体験談を読むことが、気づく手段

## よくある質問

### 文面を直したのに、受諾が増えません

原因が文面以外にある可能性があります。企業ページが会社紹介から始まっていないか、体験談に「掲載と違った」が無いか、絞り込みが読める数か、受諾は来ているのに対応が遅れていないか、試験期間でないか、を確かめます。面談で「文面のどこに反応したか」を聞き、どこで止まっているかを切り分けてから直します。

### 体験談に「テンプレのスカウトが来た」と書かれてしまいました

その週から、読める数まで送る数を減らし、文面の空欄（学生時代を読んだ一文、重なる点）を毎回埋める形にします。文面の言葉だけを変えても、読んでいなければ同じことが書かれます。翌年の体験談に「自分のことを読んでくれていた」と書かれるまで、一年かけて戻します。体験談は消えませんが、新しい体験談が上書きします。

### ワンキャリアのスカウトの見直しは、御社に相談できますか

できます。当社は、セルフチェックの型、原因の切り分け、5つの失敗の直し方の案、体験談の読み方の観点を支えられます。送ること、受諾への対応、面談で聞くこと、体験談を読むことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
