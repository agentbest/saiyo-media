スタートアップが新卒を採ろうとしている。中途中心で来て、新卒は初めてか、数名。社長が採用を見ている。「スタートアップに興味のある学生が集まる媒体はどれか」で選びがちですが、学生の多くはスタートアップ全体に興味があるのではなく、「この会社が続くか」「誰が育ててくれるか」「一年後に何をしているか」を確かめています。**結論から言うと、スタートアップの媒体は、会社の段階で変わります。シード期は媒体ではなく関わりの入口、シリーズAはインターンから、シリーズB以降で新卒採用として媒体を使います。学生は「成長」「裁量」ではなく「続くか」「誰が育てるか」「一年後」を確かめるので、社長が自分の言葉で書けるか、絞って送りたいか、知名度が出たかで、3媒体のどれを先に検討するかを分けます。** この記事では、スタートアップの採用構造、段階ごとの位置づけ、判断軸の当て方、学生が確かめること、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## スタートアップの採用構造と、媒体との相性

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 中途中心で、新卒は段階が進んでから | 新卒の育成の仕組みがなく、中途の型で回す | 新卒用の型を持つ媒体の使い方が要る |
| 会社の段階で、採用の形が変わる | シード期と、シリーズB以降で、同じ媒体の使い方が違う | 段階で媒体の位置づけを変える |
| 社長が採用を見ていて、社長の言葉が会社の顔 | 社長が書けるか、話せるかで、届き方が変わる | 記事を置く型は社長が書けるかで、送る型は絞れるかで |
| 変化が速く、一年後に組織が変わる | 文面と記事の「最初の年」が入社時に変わっている | 四半期で見直す前提 |
| 調達で採用の人数と時期が動く | 送る時期と人数が途中で変わる | 小さく早く、山を分ける |
| 知名度は段階で変わる | 初期は知られていない。後半で出てくる | 並べて比べる場は知名度が出てから |

## 段階ごとの、媒体の位置づけ

| 段階 | 新卒採用の位置づけ | 媒体の使い方 |
|---|---|---|
| シード期 | 雇用としての新卒採用の時期ではない | 媒体は「関わってくれる学生に会う」入口。インターンか業務委託の形を先に。[シード期スタートアップのOfferBox運用](/media/ob-startup-seed-unyou/) |
| シリーズA | 新卒は珍しい。インターンから | 文面や記事の締めをインターンの案内に。合った人を新卒に。[シリーズAのスタートアップのOfferBox運用](/media/ob-startup-a-unyou/) |
| シリーズB以降 | 中途中心の会社が初めて新卒を採る時期 | 「なぜ新卒か」と育てる担当を決めてから、新卒採用として媒体を使う。[シリーズB以降のスタートアップのOfferBox運用](/media/ob-startup-b-unyou/) |
| メガベンチャー | 知名度があり、応募が多い | 媒体は自社応募で来ない層に絞る。[メガベンチャーのOfferBox運用](/media/ob-mega-venture-unyou/) |

段階を飛ばすと、学生の生活を預かる責任と会社の不確かさがぶつかります。段階に合わせて位置づけを変えます。

### エージェントベストの見解

これをやる前に、先に「今の段階で、新卒を雇用として採る時期か」を決めておかないと、どの媒体を選んでも効果が出ません。当社は3媒体すべての販売パートナーとして、スタートアップの相談を段階を問わず受けますが、「新卒を採りたい」から始まる相談の多くは、段階の確認がなく、シード期の会社が新卒採用の媒体運用を始めようとしていることがあります。当社が最初に聞くのは、「社長が週に何時間、新卒に教える時間を出せるか」「一年後にその新卒が何をしているかを言えるか」「給与を続けて払える見込みがあるか」で、揃わないなら、媒体の前に関わりの形（インターン、業務委託）を整えてもらいます。揃う段階に来たら、社長が書けるか、絞って送りたいか、知名度が出たかで媒体を分けます。段階を飛ばした媒体選びは、学生にも会社にも無理があり、当社は段階の確認を媒体の提案の前に置いています。

## 判断軸を、スタートアップに当てる

| 軸 | スタートアップでの見方 |
|---|---|
| 対象（誰に届くか） | 「スタートアップ志望」の学生はメガベンチャーや後半の会社を見ている。初期の会社に来るのは「社長と」「決まっていない環境で」を選ぶ少数 |
| 型（送るか、来るか、比べられるか） | 送る型は「決まっていない環境で動いた行動」で絞れる。来る型は社長の言葉が読まれる。比べられる型は知名度が出てから |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。調達で予算が動くので、小さく始められる形を |
| 運用工数（誰の時間が要るか） | 社長の時間が上限。送る型は作業を外に出せる。来る型は社長が話す時間が要る |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。スタートアップでは、「対象」の軸で「スタートアップ志望」を追わないことと、「運用工数」の軸で社長の時間を先に見ることが、他の業界と違います。

## 学生が、確かめること

- **会社は続くか**：調達の数値ではなく、「何を、誰に、届けて、続いているか」。数値は安心にならない
- **誰が育てるか**：中途中心の会社に、新卒を教える人がいるか。制度ではなく、人
- **一年後に、自分は何をしているか**：組織が変わることを知ったうえで来る学生を探す
- **社長はどんな人か**：初期の会社は、社長との相性がすべて
- **メガベンチャーや大企業と何が違うか**：「成長」「裁量」では区別できない。部門ができる過程に関われる、という具体

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 社長が「なぜこの事業か」「決め直した場面」を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 学生が社長の言葉を読んで選ぶ。変わる会社の実態を記事で残せる |
| 「決まっていない環境で動いた行動」で絞って、少数に送りたい | 企業から送る型（OfferBox） | 作業を外に出せ、社長は面談だけ。数通で足りる |
| 知名度が出て、学生が並べて比べる対象に入った | 学生が並べて比べる場（ワンキャリア） | 比べる材料（クチコミ、選考情報）が揃ってから |
| 段階がシード期かシリーズA | 媒体より関わりの入口 | インターンか業務委託の形が先 |
| 社長が書けず、絞る条件も決まっていない | どれも先ではない | 「なぜ新卒か」「こんな人」を決めてから |

どれか一つが正解ではなく、社長が出せるものと、段階で先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせるなら**：送る文面の締めで「社長が記事に書きました」と触れ、承認した学生が記事を読む。段階が進んだら、この組み合わせが最も回りやすい。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **インターンと組み合わせるなら**：どの媒体でも、締めをインターンの案内にし、関わった人の中から新卒に。[OfferBoxとインターンシップをつなげる設計](/media/ob-intern-setsuzoku/)
- **知名度が出たら、並べて比べる場を足す**：クチコミに書かれる実態と、記事と文面をずらさない
- **一年目は一つ、段階が進んだら足す**：[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)

## 見せ方｜「成長」「裁量」の共通語を消す

- **「急成長」「若手から裁量」「ゼロイチ」「実力主義」を書かない**：同業のスタートアップが全部書いていて、区別されない
- **社長が最近「決め直した場面」を一つ**：変わり続ける会社の実態は、この場面にある
- **「決まっていること」と「決まっていないこと」を分けて書く**：隠さない。[新規事業を立ち上げる会社のOfferBox運用](/media/ob-shinki-jigyo-unyou/)
- **「最初の新卒」なら、そのまま書く**：「あなたが最初の新卒です。教える仕組みは〇〇が隣で作ります」
- **調達の情報を書かない**：自社の方針と専門家の助言に従う。書いても学生の安心にならない
- **一年後に変わることを、正直に一文**：「変わるときは本人と話して決めます」
- **業界イメージ（不安定、忙しい）を否定しない**：事実は認め、実態を書く。[業界イメージが不利な会社のWantedlyの書き方](/media/wt-gyokai-image/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 段階の確認と、新卒を採る時期かの判断 | 社長 |
| 「なぜ新卒か」の一行と、育てる人の決定 | 社長 |
| 社長が書けるか・絞って送りたいか・知名度が出たかで、先に検討する型を決める | 社長（整理は代行が支える） |
| 送る型なら、検索・下書き・送信・一次返信 | 代行 |
| 記事を置く型なら、社長が話し、整えるのは外に | 社長と代行 |
| 面談 | 社長と育てる人 |
| 四半期で「最初の年」と文面・記事を見直す | 社長と人事（いれば） |
| 調達の情報の扱いの判断 | 社長。専門家の助言を受けて |

- **社長の時間は、書くこと（または話すこと）と面談に**：作業は外に。[運用代行に出す前提の媒体の選び方](/media/hikaku-daikou-zentei/)
- **人事がいないなら、窓口を社長一人に**：[専任の人事がいない会社のOfferBox運用](/media/ob-jinji-fuzai-unyou/)

運用代行や代理店が支えられるのは、段階の整理、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分、四半期の見直しの型までで、段階の判断、「なぜ新卒か」、育てる人、社長が話す中身、面談、調達の情報の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

媒体を決めたあと、最初の年で起きることに共通するのは、社長が記事を書く型を選んだのに、事業の忙しさで記事が止まり、会社ページが「準備中」のまま半年が過ぎることです。当社は3媒体すべての販売パートナーとして、スタートアップの申込のあとを見ていますが、「社長が書ける」と判断して通年で記事を置く型を選んだ会社が、最初の一本を出したあとに書けなくなり、送る型に切り替えるまでの半年を失う、という形が多くあります。書けるかどうかは、意欲ではなく、月に一度の時間を固定できるかで決まります。当社が記事を置く型を勧めるときは、「社長が月に一度、話す時間を固定できるか」を先に確かめ、固定できないなら、送る型を先にして、承認した学生に読ませる短い記事を一本だけ置く形にしています。書けない社長は多く、それは問題ではなく、型の選び方の問題です。

## まとめ

- スタートアップの媒体は会社の段階で変わる。シード期は関わりの入口、シリーズAはインターンから、シリーズB以降で新卒採用として媒体を使う。段階を飛ばさない
- 学生は「成長」「裁量」ではなく「続くか」「誰が育てるか」「一年後」「社長はどんな人か」を確かめる。「スタートアップ志望」の学生を追わない
- 社長が自分の言葉で書けるなら通年で記事を置く型、絞って少数に送りたいなら企業から送る型、知名度が出たら並べて比べる場。優劣ではなく、社長が出せるものと段階で決める
- 「書ける」は意欲ではなく、月に一度の時間を固定できるか。固定できないなら送る型を先に、短い記事を一本だけ
- 見せ方は共通語を消し、決め直した場面と、決まっていること・いないことと、一年後に変わることを正直に。調達の情報は書かない

## よくある質問

### スタートアップ向けの媒体を使ったほうがよいですか

「スタートアップ向け」で選ぶより、今の段階で社長が何を出せるかで選ぶことを勧めます。学生の多くは「スタートアップ」で会社を選んでおらず、「この会社が続くか」「誰が育てるか」で選んでいます。当社が扱う3媒体は、どれもスタートアップで使われていて、段階と社長の出せるもので使い分けています。他の媒体を足すかは、3媒体で型ができてからで足ります。

### 調達の情報は、採用の魅力になりませんか

学生の安心にはなりにくく、「資金が尽きたら」の不安を思い出させることがあります。公表していても、文面と記事には数値を書かず、「調達で何をするか（部門を作る、事業を広げる）」を学生の「最初の年」につなげて書くことを勧めます。扱いは自社の方針と専門家の助言に従ってください。

### スタートアップの媒体選びは、御社に相談できますか

できます。当社は、段階の整理、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分、四半期の見直しの型を支えられます。段階の判断、「なぜ新卒か」、育てる人、社長が話す中身、面談、調達の情報の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
