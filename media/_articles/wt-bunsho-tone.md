会社ページは広報の文体、募集記事は求人票の文体、ストーリーは書いた人ごとにバラバラ。Wantedlyを読む候補者は、同じ会社の3か所を続けて読むので、トーンの違いに気づきます。**結論から言うと、Wantedlyの文章のトーンは「面談でその会社の人が話すときの言葉」に寄せて決め、会社ページ・募集記事・ストーリーで揃えます。Wantedlyの候補者は、読んだあとに「話を聞きに行く」ので、記事の言葉と面談の言葉が同じであることが、そのまま信用になります。** 広報文の硬さでも、砕けすぎでもなく、面談で話す言葉。この記事では、トーンとは何か、Wantedlyでトーンが問題になる理由、やりがちな失敗、決める手順、3つの軸、見本の作り方、ストーリーの例外、分担を整理します。

## この作業の目的｜記事の言葉と、面談の言葉を同じにする

トーンとは、文章の「話し方」です。同じ内容でも、「弊社は〇〇を推進しております」と「うちは〇〇をやっています」では、読む人が受け取る会社の姿が違います。

Wantedlyの候補者は、記事を読んで「話を聞きに行く」を押し、面談で会社の人と話します。このとき、記事が広報文の硬さで、面談がくだけた言葉だと、「記事は誰が書いたのか」と感じます。逆に、記事が親しげで、面談が硬いと、「記事は営業用だった」と感じます。

トーンを決める目的は、記事の言葉と面談の言葉を同じにして、「読んだとおりの会社だった」と思ってもらうことです。

## やりがちな失敗

| 失敗 | 候補者からどう見えるか |
|---|---|
| 会社の広報文・IR文と同じ硬さ | 距離が遠い。「人」が見えない |
| 砕けすぎ、絵文字、内輪の言葉 | 軽い。仕事の話が読めない |
| 記事ごとにトーンがバラバラ | 会社としての姿が定まらない |
| 会社ページと募集記事で一人称が違う（弊社／当社／私たち／うち） | 誰が書いているのか分からない |
| 熱い言葉と硬い言葉が混ざる | 書いた人の迷いが見える |
| 候補者に向かって命令形（〜してください、〜すべき） | 上から。「話を聞きに行く」気にならない |
| 書き手のトーンを人事が直して、全部同じ声になる | ストーリーから本人が消える |

最も多いのは、最初の「広報文の硬さ」です。会社の公式の文書として承認を通すために、既存の広報文に寄せた結果です。

## 手順1｜面談で話している人の言葉を聞く

トーンは、机上で決めません。実際に候補者と話している人の言葉から取ります。

1. **面談に出ている人の話し方を、人事が聞く**：面談の同席、または面談後に「今日、どんな言葉で会社のことを話しましたか」
2. **代表が候補者に話すときの言葉を聞く**：社内向けの言葉ではなく、外の人に話すときの
3. **共通している言葉を拾う**：「うち」「チーム」「お客さん」など、一人称と、相手の呼び方と、仕事の呼び方
4. **書き言葉に直しすぎない範囲で、文にする**：話し言葉のままでは読みにくいので、語尾と句読点は整える

「面談で話す言葉」が、その会社の本当のトーンです。広報文は会社の外向きの顔で、面談の言葉は会社の中の人の顔です。Wantedlyで見せるのは、後者です。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは若い人向けだから、砕けた文体で書くべきだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、砕けた文体にした会社で起きるのは、「記事は親しげなのに、面談が硬い」というずれです。候補者は面談で「記事と違う」と感じ、話を聞きに来た人が次に進みません。逆に、面談で話す言葉のまま書いた会社は、文体そのものは硬めでも、候補者が「読んだとおりの人が出てきた」と感じます。トーンは、若い人向けかどうかで決めるものではなく、その会社の人が実際に話す言葉で決めるものです。面談で硬く話す会社が、記事で砕けても、候補者には二つの顔に見えるだけです。

## 手順2｜3つの軸で決める

聞いた言葉を、3つの軸で整理します。

| 軸 | 選択肢 | 決め方 |
|---|---|---|
| 一人称 | 当社／私たち／うち／会社名 | 面談で最も多く使う言葉。1つに決めて全記事で揃える |
| 語尾と距離 | です・ます（丁寧）／です・ます（少し話し言葉）／である | 面談の距離感に合わせる。Wantedlyは「です・ます、少し話し言葉」に寄ることが多い |
| 言葉の硬さ | 漢語が多い（推進・実施・貢献）／和語が多い（進める・やる・役に立つ） | 面談で使う言葉に。漢語は硬く、和語は近い |

加えて、決めておくと揃いやすいものがあります。

- **候補者の呼び方**：「あなた」「〇〇な方」「一緒に働く人」。命令形は使わない
- **社員の呼び方**：「メンバー」「社員」「〇〇さん」。記事内で揃える
- **顧客の呼び方**：「お客さま」「お客さん」「クライアント」。面談で使う言葉に
- **使わない言葉**：抽象語（成長・挑戦・アットホーム）、煽り（必見・衝撃）、広報の定型（推進・実現・貢献）

「使わない言葉」の一覧は、抽象語の置き換えと同じ考え方です。価値観を場面で書く方法は[価値観を場面で書く方法](/media/wt-kaisha-page-value/)で書きました。

## 手順3｜見本を1本作って、揃える

軸を決めたら、文書にするより、見本を1本作るほうが揃います。

1. **会社ページの「なにをやっているか」を、決めたトーンで書き直す**：短い1段落
2. **募集記事の「なにを」を、同じトーンで書き直す**
3. **この2つを見本にして、他の記事を揃える**：「この2つと同じ話し方で」
4. **書き手には、軸の一覧ではなく見本を渡す**：一覧は守れないが、見本には寄せられる
5. **古い記事を、見本に寄せて直す**：一度に全部ではなく、読まれている記事から

見本があれば、代理店や外部が書く場合も揃います。書き手を増やすときも、見本を渡すだけで済みます。書き手を増やす考え方は[書き手を社内で増やす方法](/media/wt-story-kakite/)で書きました。

## ストーリーの例外｜本人の言葉は、トーンより優先する

トーンを揃えるのは、会社ページと募集記事と、ストーリーの地の文です。ストーリーの中の本人の言葉（インタビューの発言、入社エントリーの本人の文）は、トーンより本人を優先します。

- **本人の発言は、本人の言葉のまま**：会社のトーンに直さない
- **地の文（人事が書く部分）は、会社のトーン**
- **入社エントリーのように本人が全文を書く記事は、本人のトーンのまま**：直すのは抽象語・事実・特定の3つだけ

全記事を同じ声に直すと、ストーリーから人が消えます。トーンを揃えるのは「会社の声」の部分で、「人の声」は揃えません。書き方は[社員インタビューを書く手順](/media/wt-story-interview/)と[入社エントリーを書いてもらう方法](/media/wt-story-nyusha/)で書きました。

## 面談の言葉と、記事の言葉を揃え続ける

トーンは、決めて終わりではなく、面談とずれていないかを見続けます。

- **面談に出る人が、記事を読んでおく**：記事のトーンで話せるように、ではなく、記事が自分の言葉になっているかを確かめるために
- **面談で「記事と違った」と言われたら、記事を面談に寄せる**：面談を記事に寄せるのではなく
- **面談に出る人が変わったら、トーンを見直す**：話す人が変われば、会社の言葉も変わる
- **代表が交代したり、事業が変わったりしたら、見本を作り直す**

「記事を面談に寄せる」が原則です。面談の言葉が会社の本当の言葉なので、記事のほうを合わせます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 面談で話す言葉を聞く | 人事（面談の同席、面談後の聞き取り） |
| 3つの軸で決める | 人事（代表と面談に出る人に確認） |
| 見本を1本作る | 人事 |
| 記事を見本に揃える | 書く人（人事、書き手、代理店） |
| 本人の言葉を残す判断 | 人事 |
| 面談とのずれを見る | 面談に出る人 |

運用代行や代理店が支えられるのは、3つの軸の整理、見本の作成、既存記事の揃え直し、書き手に渡す形の整備までで、面談で話す言葉を聞くこと、面談で記事どおりに話すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの記事のトーンを整えるとき、軸の整理、見本の作成、既存記事の揃え直しは当社が出せます。ただし、「面談でその会社の人が話す言葉」は、当社には作れません。当社が「Wantedlyらしいトーン」を持ち込んで書くと、記事は読みやすくなりますが、面談で話す言葉とずれ、候補者が「記事と違う」と感じます。当社が最初にお願いするのは、面談に出る人が候補者に会社を説明するときの言葉を、人事が一度聞いて書き留めることです。その言葉があれば、当社はそれに寄せて整えられます。無ければ、当社の言葉になり、それは会社の言葉ではありません。トーンは、外から持ち込むものではなく、社内で話されている言葉を書き言葉にしたものです。

## まとめ

- Wantedlyのトーンは「面談でその会社の人が話す言葉」に寄せる。広報文の硬さでも砕けすぎでもなく
- 候補者は読んだあと話を聞きに行くので、記事の言葉と面談の言葉が同じであることが信用になる
- 一人称・語尾と距離・言葉の硬さの3つの軸で決め、候補者と社員と顧客の呼び方、使わない言葉も揃える
- 一覧ではなく、見本を1本作って渡す。古い記事は読まれているものから寄せる
- ストーリーの本人の言葉はトーンより優先。揃えるのは会社の声で、人の声は揃えない

## よくある質問

### 会社の広報のルールで、公式の文体が決まっています

会社の公式サイトやIR文書のルールは、そのまま守ります。Wantedlyは「話を聞きに行く」前に読むもので、面談の言葉に寄せたほうが候補者に信用されます。広報のルールを守る場所と、Wantedlyの場所を分けて、広報の担当者に「Wantedlyは面談の言葉で書く」と合意しておくと、承認で止まりません。

### 書き手が複数いて、トーンが揃いません

軸の一覧ではなく、見本を1本渡します。「この記事と同じ話し方で」と言えば、書き手は寄せられます。ただし、ストーリーの本人の言葉は揃えません。地の文だけを見本に寄せます。

### トーンの整備は、御社に相談できますか

できます。当社は、軸の整理、見本の作成、既存記事の揃え直し、書き手に渡す形の整備を支えられます。面談で話す言葉を聞くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの記事の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
