OfferBoxは、学生が就職活動を本格的に始める前の、早い時期にも使えます。低学年のうちや、選考が動き出す前の時期です。**結論から言うと、早期に使うときの目的は「内定を出す」ではなく「知ってもらい、接点を作り、温度を保つ」です。早期の学生は志望が固まっておらず、プロフィールも薄いことがあります。ここで内定を急ぐと、学生が構えるか、承認しても放置されて温度が下がります。** この記事では、早期の学生の状態、目的の置き方、文面と締め、承認後の連絡、早期が向く会社と向かない会社、記録、やりがちな失敗、人事と現場の分担を整理します。学生が動く時期は卒年ごとに変わるので、具体的な月は書きません。時期の確認の仕方は[送る時期と時間帯の考え方](/media/ob-soushin-timing/)で書きました。

## この作業の目的｜「まだ決めていない学生」と、先に知り合う

早期の学生は、就職活動を「始めていない」か「始めたばかり」です。業界も職種も決めておらず、企業を調べ始めた段階です。この時期の学生に届く企業は、まだ多くありません。

早期に使う意味は、学生が動き出す前に、自社の名前と仕事を知ってもらうことです。学生が本格的に動き出したとき、「あのオファーの会社」として思い出してもらえれば、その時点で他社より一歩前にいます。

逆に、早期の学生に「すぐ選考に」と誘うと、学生は「まだ何も決めていないのに」と構えます。早期の目的は、決めてもらうことではなく、知ってもらうことです。

## 手順1｜早期の学生の状態を前提にする

早期の学生のプロフィールは、選考期の学生と違います。

| 状態 | 何が起きるか | どう向き合うか |
|---|---|---|
| 志望業界が未定 | 業界で絞ると対象が残らない | 業界で絞らず、仕事の中身で入る |
| 自由記述が薄い、または未記入 | 触れる材料が少ない | 少ない材料で書ける入り方を用意する。材料が増えたら改めて送る |
| 就職活動の意識がまだ低い | 「選考」の言葉で構える | 「会社を知る」「話を聞く」の言葉で誘う |
| 学業やサークルが優先 | 返信が遅い、日程が合いにくい | 追いかけを急がず、日程に幅を持たせる |
| プロフィールがこれから更新される | 早期に読んだ内容と、選考期の内容が変わる | 選考期に改めて読み直す |

「自由記述が薄い」学生に、選考期と同じ深さの文面は書けません。早期は、志向や学部から入る「浅い」深さで書き、材料が増えた選考期に改めて「深い」文面を送る、という二段構えにします。深さの段階は[オファーを学生ごとに変える範囲](/media/ob-offer-personalize/)で書きました。

## 手順2｜文面は「会社を知る入口」にする

早期の文面は、選考期の文面と締めが違います。冒頭の「読んだ・こう思った・だから送った」は同じですが、「だから送った」の先が「選考に」ではなく「知ってもらいたい」になります。

1. **冒頭**：材料があれば自由記述の一文に触れる。無ければ志向や学部から。「〇〇に興味があると書かれていて」
2. **本文**：仕事の中身を、選考期より短く。「こういう仕事をしている会社です」と、入口の説明にとどめる
3. **締め**：「まずは会社を知ってもらえたら」「一度、仕事の話を聞いてみませんか」。選考の言葉は使わない
4. **時期への配慮を一言**：「就職活動はまだ先だと思いますが」「学業の合間に」
5. **インターンがあるなら、その案内**：早期の学生には、面談よりインターンのほうが入口が低いことがある。つなげ方は[インターンシップをつなげる設計](/media/ob-intern-setsuzoku/)

早期の文面で「選考」「エントリー」「内定」の言葉を使うと、学生は「まだ早い」と閉じます。「知る」「話を聞く」「見てみる」の言葉で誘います。

### エージェントベストの見解

申し込んだあと、早期に使い始めた会社で起きやすいのは、「早期に承認を取って、選考期まで放置する」ことです。早期に送り、承認され、面談もした。ところが選考はまだ先なので、次の連絡が無いまま数ヶ月が過ぎ、選考期に連絡したときには学生は他社で動いています。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、早期に使って成果が出ている会社は、承認から選考期までの間に、途中の接点を設計しています。インターンの案内、社員との交流の場、会社の近況を伝える短い連絡。内容は軽くてよく、間隔が空きすぎないことが要点です。早期に承認を取るのは入口で、選考期まで温度を保つのが本体です。本体の設計が無いなら、早期に使う意味は薄く、選考期に集中したほうが無駄がありません。

## 手順3｜承認後は、選考を急がず温度を保つ

早期に承認された学生への連絡は、選考期と違います。

| 段階 | 早期の連絡 |
|---|---|
| 承認の直後 | 当日にお礼と、「話を聞く」場の案内。選考の話はしない。連絡の基本は[承認されたあとの連絡手順](/media/ob-shounin-go/) |
| 初回面談 | 会社を知ってもらう場。仕事の話と、学生の話。次のステップは「また連絡します」で足りる |
| 面談から選考期まで | 途中の接点を設計する。インターン、社員との交流、会社の近況。間隔を決める |
| 選考期の始まり | 「そろそろ就職活動が本格化する時期なので」と、改めて面談か選考を案内する。早期に話したことに触れる |
| 選考期以降 | 選考期の学生と同じ流れ。ただし、早期からの接点があるので、段階を短くできる |

「途中の接点」が、早期に使うときの中心です。接点が無いと、早期の承認は選考期に活きません。接点の内容は軽くてよく、「忘れられていない」と伝わることが目的です。連絡の間隔の考え方は[承認後の辞退を減らす連絡設計](/media/ob-jitai-boushi/)で書きました。

## 手順4｜早期が向く会社と、向かない会社

早期に使うには、選考期までの長い期間、接点を保つ体制が要ります。

- **向く会社**：早い時期に少人数と深く接点を持ちたい。インターンや社員との交流の場を用意できる。選考期まで面談枠を継続して出せる。知名度がなく、学生が動き出す前に名前を知ってもらう必要がある
- **向かない会社**：担当が1人で、選考期の運用だけで手一杯。途中の接点を用意する時間が無い。採用人数が多く、選考期に数を送るほうが合う
- **迷う会社**：早期は少数に絞って試し、途中の接点が回るかを見てから広げる

向かない会社が早期に使うと、承認を取って放置する形になり、学生にも自社にも無駄が出ます。採用計画との関係は[OfferBoxのターゲット設計](/media/ob-target-sekkei/)で書きました。

## 手順5｜早期の学生の記録を、選考期に活かす

早期に接点を持った学生の記録は、選考期の運用の材料になります。

1. **早期に触れた一文と、面談で話したことを記録する**：選考期の文面と面接で、「早期にこう話しましたね」と触れられる
2. **選考期にプロフィールを読み直す**：自由記述が増えていることが多い。早期の記録と照らして、変化を見る
3. **早期に承認した学生が、選考期にどう動いたかを記録する**：選考に進んだか、他社に決めたか。早期に使う効果の根拠になる
4. **途中の接点の反応を記録する**：どの接点に反応があったか。次の卒年の設計に使う

「早期に承認した学生のうち、選考期に自社の選考に進んだのは何人か」が、早期に使うかどうかを次の卒年に判断する材料です。数字そのものより、自社の前年と比べます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 早期の学生に選考の言葉で誘う | 「まだ早い」と閉じられる | 「知る」「話を聞く」で誘う |
| 志望業界で絞る | 未定の学生が残らない | 業界で絞らず、仕事の中身で入る |
| 自由記述が薄い学生に深い文面を書こうとする | 書けずに止まる | 浅い深さで送り、選考期に改めて |
| 承認を取って選考期まで放置する | 温度が下がり、他社に動く | 途中の接点を設計する |
| 途中の接点が重い（長い説明会など） | 学業が優先の学生が離れる | 軽く、間隔が空かないように |
| 早期の記録を選考期に使わない | 早期の接点が活きない | 記録し、選考期の文面と面接で触れる |
| 体制が無いのに早期に広く送る | 承認が溜まり放置される | 少数に絞って試す |

最も多いのは、「承認を取って選考期まで放置する」です。早期に使う効果は、途中の接点で決まります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 早期に使うかを決める | 人事と経営（体制と採用計画から） |
| 早期の文面（浅い深さ）を書く | 人事、または運用代行 |
| 初回面談 | 名義の人 |
| 途中の接点を設計する | 人事（インターンや交流は現場と） |
| 途中の接点に出る | 現場の社員 |
| 選考期にプロフィールを読み直す | 読む人 |
| 記録し、次の卒年に戻す | 人事 |

現場の負担は、「初回面談」と「途中の接点に出る」です。途中の接点の頻度は、現場が出られる範囲で決めます。運用代行に出す場合、早期の文面と途中の連絡は代行が行えますが、接点の場（インターン、交流）は社内です。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

同じ「早期に使いたい」という相談でも、当社が勧めるのは、選考期まで接点を保つ体制がある会社に限っています。具体的には、インターンか社員との交流の場を用意でき、選考期まで面談枠を継続して出せ、途中の連絡を担当が回せる会社です。この体制が無い会社には、早期より選考期に集中することを勧めます。早期に送るには、選考期と同じ「読んで書く」時間に加えて、承認後の長い期間の接点の時間が要るからです。当社がOfferBoxの運用代行を受けるときも、早期の運用は「途中の接点を誰がどう回すか」を先に決めてから始めます。決まっていなければ、早期は少数に絞り、体制ができてから広げます。早期は、使えば効くものではなく、選考期までの設計があって初めて効くものです。

## まとめ

- 早期に使う目的は、内定ではなく「知ってもらい、接点を作り、温度を保つ」
- 早期の学生は志望が未定で自由記述が薄いことがある。業界で絞らず、浅い深さで送り、選考期に改めて
- 文面は「選考」ではなく「知る」「話を聞く」の言葉で。締めは軽く
- 承認後は選考を急がず、選考期までの途中の接点を設計する。放置が最も多い失敗
- 早期が向くのは、接点を保つ体制がある会社。無い会社は選考期に集中する

## よくある質問

### 早期に承認された学生に、選考の話をしてもよいですか

早期の面談では、選考の話はしないことを勧めます。「まだ何も決めていないのに」と構えます。会社を知ってもらう場にとどめ、選考期の始まりに改めて案内します。学生から選考の時期を聞かれたら、答えて構いません。

### 早期の学生は、プロフィールが薄くて文面が書けません

志向や学部から入る「浅い」深さで書きます。「〇〇に興味があると書かれていて」で足ります。選考期になると自由記述が増えることが多いので、そのときに改めて読み直し、深い文面を送ります。二段構えにします。

### 早期の運用は、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、早期に使うかどうかを体制から判断し、使うなら途中の接点の設計を一緒に行います。運用代行を受ける場合は、早期の文面と途中の連絡を当社が行い、接点の場は企業が用意します。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
