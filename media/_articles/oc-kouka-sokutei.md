ワンキャリアを回しているが、効果が測れない。「閲覧数は見えるが、それで良いのか悪いのか分からない」「エントリーが少ないが、掲載のせいか、体験談のせいか分からない」「去年の体験談が悪いのか、今年の運用が悪いのか分からない」。この症状は、「ワンキャリアは効果が見えにくい媒体」で片づけられがちです。ところが、測れない原因のほとんどは、測る側の準備にあります。**結論から言うと、「測れない」の正体は五つです。台帳がない、段が分かれていない、「こんな人」が決まっていない、体験談を読んでいない、今年の運用の結果と去年の体験談の結果を分けていない。この五つを順に直します。閲覧数とエントリー数を中心から外し、「書いたとおりに運用できたか」を最初のKPIに置き、段ごとの数と日数で見て、「こんな人」に近い学生の数を持ち、体験談の言葉を数字と並べます。年単位で比べ、「出ていない」のか「測れていない」のかを分けます。** この記事では、五つの正体、順に直す手順、閲覧数を外す理由、「守れたか」のKPI、段ごとの数、近い学生の数、体験談の言葉、置くKPIと置かないKPI、年単位、区別、分担を整理します。KPIの基本は[ワンキャリアの掲載のKPI設計](/media/oc-keisai-kpi/)と[ワンキャリアのスカウトのKPI設計](/media/oc-scout-kpi/)、経営への報告は[経営層にワンキャリアの成果を説明する方法](/media/oc-keiei-rikai/)で書きました。

## この作業の目的｜「効いているか」を、自社の記録と体験談で答えられるようにする

「効果が測れない」とは、「効いていない」ではなく、「効いているかどうかを判断する材料がない」状態です。材料がないまま「効かない」と判断すると、効いていた運用を止めることがあります。

ワンキャリアでは、「今年の運用」と「去年の体験談」の二つが、今年の数字に混ざります。目的は、この二つを分けて、自社の記録と体験談の言葉で「効いているか」を答えられる形を作ることです。

## 「測れない」の、五つの正体

| 正体 | 何が起きているか | 直し方 |
|---|---|---|
| 1. 台帳がない | 誰に送って、誰が受諾して、誰が来て、誰がどの段まで進んだかが記録にない | 台帳を一つ作る |
| 2. 段が分かれていない | 「今年の成果」を閲覧数かエントリー数一つで見ていて、どこで止まっているかが見えない | 段ごとに数と日数を置く |
| 3. 「こんな人」が決まっていない | 来ても、「合う学生か」を判断できず、数だけ見ている | 「こんな人」を一行で書く |
| 4. 体験談を読んでいない | 自社の体験談に何が書かれているかを知らず、企業ページと選考のずれも、学生が何を見ているかも分からない | 月に一度、新しい体験談を読む |
| 5. 今年と去年を分けていない | 今年のエントリーが少ないのが、今年の運用のせいか、去年の体験談のせいかを分けていない | 「守れたか」と「段ごとの数」と「体験談の言葉」を年ごとに並べる |

「1→2→3→4→5」の順に直します。ワンキャリアに特有なのは「4」と「5」で、体験談を読まずに数字だけ見ても、何が効いているかは分かりません。

## 閲覧数とエントリー数を、中心から外す

- **閲覧数は、入口の数字**：体験談の量にも左右され、掲載だけでは動かせない
- **エントリー数は、去年の体験談の結果でもある**：今年の運用だけの結果ではない
- **中心に置くのは、「守れたか」と段ごとの数と体験談の言葉**：閲覧数とエントリー数は、段の一つとして
- **管理画面で何が見えるかは、現在の仕様で確認する**

## 「書いたとおりに運用できたか」を、最初のKPIに置く

- **企業ページに書いた連絡の日数を、守れたか**：台帳の「返信日」で
- **企業ページに書いた「何を見るか」のとおりに、面接官が聞いたか**：面接後の一行で
- **企業ページに書いた選考の流れと、実際が同じだったか**
- **守れた割合を、月に一度**：数字の目標ではなく、「守れたか」
- **これが、翌年の体験談に「企業ページどおりだった」が残るかを決める**：今年の運用で唯一、翌年の体験談を直接動かせるKPI

他の媒体にはない、ワンキャリアの最初のKPIです。守り方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「ワンキャリアは体験談に左右されるので、自社の運用の効果は測れない」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、「測れない」と言う会社の手元を見ると、台帳がなく、段が分かれておらず、体験談を読んでおらず、「守れたか」の記録がありません。体験談に左右されるから測れないのではなく、「今年の運用で動かせるもの（守れたか）」と「去年の体験談の結果（今年の入口の数）」を分けていないから測れないのです。「守れたか」が記録されていれば、今年の運用の効果は今年測れ、その結果は翌年の体験談に出ます。当社が「測れない」の相談を受けるとき、最初にやるのは、閲覧数の見方の説明ではなく、返信の日数と面接官の「何を見るか」の実施を、今月から台帳に一行で残してもらうことです。

## 段を分けて、数と日数を置く

| 段 | 数 | 日数 |
|---|---|---|
| 体験談が読まれる | 管理画面で見える範囲で | — |
| 企業ページが読まれる | 同じく | — |
| エントリー・受諾 | その数 | 送ってから受諾までの日数 |
| 一次 | 進んだ数 | エントリー・受諾から一次までの日数 |
| 二次以降・最終 | 進んだ数 | 段階ごとの日数 |
| 決定 | 決まった数 | — |

「数」で、どの段で減っているかが見えます。「日数」で、どの段で待たせているかが見えます。段の意味は[ワンキャリアの掲載のKPI設計](/media/oc-keisai-kpi/)の「見る段」で書きました。

## 「こんな人」に近い学生の数を、段ごとに持つ

- **「こんな人」を一行で書く**：なければ、ここで書く
- **台帳の「近さ」の項目に、送るときと来たときに印をつける**：三段で足りる
- **段ごとの数を、「近い学生」だけでも出す**：「一次に進んだ学生のうち、近い学生は何人」
- **「近い学生」が一次まで来ていれば、「届いている」**：全体の数が少なくても

## 体験談の言葉を、数字と並べる

- **月に一度、新しく書かれた体験談を読む**：全部を毎回読まなくてよい
- **「企業ページどおりだった」「連絡が速かった」「何を見ているか分かった」があるか**：良い状態
- **「企業ページと違った」「連絡が遅かった」があるか**：守れていない。直す場所
- **体験談の言葉を、台帳の「守れたか」と並べる**：守れた月の体験談と、守れなかった月の体験談
- **来た学生に面談で「企業ページのどこを見て来たか」を聞き、一行で残す**：体験談が出る前の、今年の言葉

独自の指標は[ワンキャリアの掲載のKPI設計](/media/oc-keisai-kpi/)の「ワンキャリアに独自の指標」で書きました。体験談の言葉が、数字の意味を決めます。

## 最初の年に置くKPIと、置かないKPI

| 置く | 置かない |
|---|---|
| 「書いたとおりに運用できたか」（返信の日数・何を見るか・流れ） | 閲覧数・エントリー数の目標値 |
| 段ごとの数と日数 | 受諾率・エントリー率の目標値 |
| 「近い学生」の段ごとの数 | 他社・媒体平均との比較 |
| 今年書かれた体験談の数と中身 | 体験談の本数の目標 |
| 止まっている段と、直したこと | 「効いた・効かない」の結論 |

最初の年は、「置かない」の側を置くと、途中の月が「未達」になり、直す前に「効かない」と判断することになります。目標値は、一年の台帳から割合が出てから、年単位で置きます。

## 年単位で、比べる

- **新卒は、年度で動く**：月ごとの比較は、時期のずれで意味が薄い
- **今年の「守れたか」と、翌年の体験談の言葉を比べる**：今年守れた分が、翌年の体験談に出たか
- **去年の体験談の言葉と、今年の段ごとの数を比べる**：去年の体験談が、今年の入口にどう効いたか
- **年単位の比べ方は[ワンキャリアのスカウトのKPI設計](/media/oc-scout-kpi/)の「新卒は、年単位で比べる」**

## 「出ていない」と「測れていない」を、分ける

| 状態 | サイン | 対処 |
|---|---|---|
| 測れていない | 台帳がない、段が分かれていない、「こんな人」がない、体験談を読んでいない、年を分けていない | 五つを直す。判断はそのあと |
| 測れているが、守れていない | 「守れたか」の記録で、返信が遅れ、面接官が違うことを聞いている | 守る仕組みを直す。「効かない」ではなく「運用できていない」 |
| 測れていて、守れているが、止まっている段がある | 段ごとの数で、一つの段が大きく減っている | その段を直す |
| 測れていて、守れていて、「近い学生」が来ていない | 来ているが、近い学生が少ない | 企業ページを「こんな人」に向けて絞り、スカウトの相手を直す |
| 測れていて、守れていて、翌年の体験談に「どおりだった」が残っても、なお近い学生が来ない | 二年分の記録で変わらない | 続けるかの判断。契約の切れ目で |

「出ていない」と判断できるのは、最後の段だけです。ワンキャリアでは、二年分の記録が要ります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 台帳を一つ作り、月に一度、管理画面から写す | 人事 |
| 返信の日数と「何を見るか」の実施を記録する | 人事と面接官 |
| 段ごとの数と日数を置く | 人事 |
| 「こんな人」を一行で書き、「近さ」の印をつける | 人事と面接官 |
| 月に一度、新しい体験談を読み、言葉を台帳に並べる | 人事と面接官 |
| 今年と去年を分けて、年単位で並べる | 人事と責任者 |
| 「出ていない」の判断 | 責任者 |

運用代行や代理店が支えられるのは、台帳の型、「守れたか」の記録の型、段の分け方、体験談の一覧の型、置くKPIと置かないKPIの整理、年単位の並べ方、「測れていない」の切り分けまでで、台帳を付けること、守ること、体験談を読むこと、「こんな人」の決定、「出ていない」の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。「効果が出ていない」と「効果が測れていない」を、当社は分けて扱います。ワンキャリアでは、さらに「今年の運用ができていない」が混ざります。返信が遅れ、面接官が企業ページと違うことを聞いている状態は、「効かない」のではなく「運用できていない」で、この状態の結果で媒体を判断すると、翌年の体験談に「違った」が残った状態で撤退することになります。当社がワンキャリアで「効かない」の相談を受けるとき、最初に確かめるのは、「守れたか」が記録されているかです。記録がなければ「測れていない」、記録があって守れていなければ「運用できていない」、守れていて近い学生が来ないなら、二年分を見てから判断します。一年目の数字だけで「効かない」と決めることを、当社は勧めません。

## まとめ

- 「測れない」の正体は、台帳がない・段が分かれていない・「こんな人」がない・体験談を読んでいない・今年と去年を分けていない、の五つ。この順に直す
- 閲覧数とエントリー数は入口の数字で、去年の体験談の結果でもある。中心から外し、「書いたとおりに運用できたか」を最初のKPIに置く。これが翌年の体験談を直接動かせる唯一のKPI
- 段ごとの数と日数、「こんな人」に近い学生の段ごとの数、月に一度読む体験談の言葉、を並べる
- 最初の年は、閲覧数・エントリー数・受諾率・体験談の本数の目標値を置かず、守れたか・段・近い学生・体験談の中身・止まりと直しを置く。年単位で比べる
- 「出ていない」と判断できるのは、守れていて、止まりを直して、二年分の記録でなお近い学生が来ないときだけ。それより前は「測れていない」か「運用できていない」

## よくある質問

### 去年の体験談が悪くて、今年の運用の効果が見えません

今年の「守れたか」を記録します。返信の日数、面接官の「何を見るか」、選考の流れ。守れていれば、今年の運用の効果は「守れた」として今年測れ、翌年の体験談に出ます。今年のエントリー数は去年の体験談の結果が混ざっているので、今年の運用の効果の指標にはしません。来た学生に「企業ページのどこを見て来たか」を聞けば、今年の企業ページが効いているかは、今年分かります。

### 体験談を読む時間がありません

月に一度、新しく書かれた分だけを読みます。全部を毎回読まなくてよいです。読んだら、「企業ページどおりだった」か「違った」かを、一行で台帳に。この一行が、数字の意味を決めます。読まないと、閲覧数とエントリー数が何の結果か分からないまま、「測れない」が続きます。

### ワンキャリアのKPIの置き直しは、御社に相談できますか

できます。当社は、台帳の型、「守れたか」の記録の型、段の分け方、体験談の一覧の型、置くKPIと置かないKPIの整理、年単位の並べ方、「測れていない」の切り分けを支えられます。台帳を付けること、守ること、体験談を読むこと、「こんな人」の決定、「出ていない」の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
