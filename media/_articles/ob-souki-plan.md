OfferBoxの早期定額型プランを検討している。ところが、何が含まれていて、どんな会社に向くのかが分からない。**結論から言うと、早期定額型プランは「インターンや早期面談など就活初期からオファーを送りたい会社」向けの定額のプランで、3名採用の場合75万円（税抜）、利用可能期間は最長24ヶ月、オファー枠は120枠（3名採用の場合）です。専任担当のサポートと、既存社員最大30名分の適性検査が付きます。開始をさらに2ヶ月前倒しする「EXオプション」が25万円であります。向くのは、夏から秋にかけてオファーを書く現場の時間が取れる会社で、向かないのは、3月以降しか動けないのに前倒しのプランを取ってしまう会社です。** プランの全体像は[OfferBoxのプランの選び方](/media/ob-plan-erabikata/)で書きました。この記事は早期定額型に絞ります（2026年9月23日時点。最新は公式ページでご確認ください）。

## 結論｜早期定額型プランの中身

| 項目 | 内容 |
|---|---|
| 費用 | 3名採用の場合 75万円（税抜） |
| 利用可能期間 | 最長24ヶ月 |
| オファー枠 | 120枠（3名採用の場合） |
| サポート体制 | 専任担当のサポート |
| 適性検査 | 既存社員 最大30名分無料 |
| 追加オプション | EXオプション 25万円（通常の早期プランより2ヶ月早くオファー送信可能） |

採用予定人数に応じた人数別のプランで、11名以上のプランも用意があります。

## 仕組み｜「早期」と「定額」の二つ

- **早期**：就活が本格化する3月より前、インターンや早期面談の時期からオファーを送れます。成功報酬型は3月以降のアプローチです
- **定額**：採用人数に応じた定額で、採用の結果によって総額が変わりません。先に費用が確定するので、予算が組みやすい形です
- **EXオプション**：オファーの開始時期を2ヶ月前倒しする権利です。期間などの条件は、申し込んだ早期定額型プランに準じます（期間が延びるものではありません）
- **オファー枠は復活する**：オファーを受信した学生が辞退した場合（または3日経過・選考を辞退した場合）、送信枠が復活して別の学生に送れます

### エージェントベストの見解

相談で最も多い思い込みは、「早く始められるプランのほうが有利だから、迷ったら早期定額型にしておけばよい」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの申し込みの相談を受けますが、早期定額型を取ったのに、夏から秋にオファーを書く時間が現場に無く、結局3月から動き始める会社があります。その場合、前倒しで使えるはずだった数か月が空白になり、定額の費用だけが先に決まっている状態になります。早期の価値は「早く送れること」ではなく、「他社が動いていない時期に、一人ひとりに書いたオファーを届けられること」です。書く人がいない時期に枠だけあっても、その価値は出ません。当社が最初にお願いするのは、早期定額型を検討する前に、配属先の責任者と「夏から秋に、月に何通書けるか」「面談に何回出られるか」を確かめることです。書ける体制がある会社にとって、早期定額型は他社と競合しない時期に接点を作れるプランです。体制が無いなら、時期を無理に前倒しせず、成功報酬型で3月から始めるほうが、費用と成果が合います。

## 向く会社・向かない会社

| 会社の状態 | 判断 |
|---|---|
| インターンや早期面談を実施していて、夏から秋に学生と会える | 向く。早期の接点を活かせる |
| オファーを書く現場の社員の時間が、夏から取れる | 向く。枠を使い切れる |
| 採用の人数が決まっていて、予算を先に固定したい | 向く。定額で総額が確定する |
| 2卒年を同時に動かす計画がある | 向く。最長24ヶ月の期間が効く |
| 3月以降しか動けない | 向かない。成功報酬型を先に検討 |
| 書く人が決まっていない | 向かない。体制を決めてから |

## 確認する項目

- **夏から秋の、オファーを書く時間**：月に何通書けるか。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)
- **早期の面談の枠**：承認が来たときに会える枠があるか
- **採用の人数**：人数別のプランなので、先に決める
- **利用する期間**：最長24ヶ月をどう使うか。2卒年にまたがるか
- **EXオプションを使うか**：さらに2ヶ月前倒しする必要があるか
- **適性検査の使い道**：既存社員最大30名分の枠をどう使うか

## 注意点

- **料金は税抜表示**です
- **EXオプションは期間を延ばすものではありません**：開始を2ヶ月前倒しする権利で、その他の条件は申し込んだプランに準じます
- **枠が余っても費用は変わりません**：定額なので、使い切れるかを先に確かめます
- **入社合意枠を超えての採用は成功報酬**になります（成功報酬分の内定承諾後の辞退は全額返金）
- **最新の内容は公式ページで**：[OfferBoxの料金プラン](https://offerbox.jp/company/fee)をご確認ください

## 社内の分担

| 作業 | 誰が |
|---|---|
| 採用の人数と、動き出す時期を決める | 経営と採用の責任者 |
| 夏から秋の、書く時間と面談の枠を確保する | 配属先の責任者 |

| EXオプションの要否を決める | 採用の責任者 |

### エージェントベストの見解

早期定額型で、当社が先にお伝えしているのは、「最長24ヶ月の期間は、2卒年をまたぐ設計にして初めて効く」ということです。1卒年だけの採用で申し込むと、実際に使うのは十数か月で、残りの期間が余ります。24ヶ月という長さは、「27卒に早期から送りつつ、28卒のインターンの時期にも動く」といった、卒年をまたいだ使い方を想定した長さです。申し込んだあとに期間を持て余す会社に共通するのは、1卒年の採用計画だけで期間を選んでいることです。当社が案内するのは、申し込みの前に「来年と再来年の採用計画」を並べて、2卒年を同時に動かすかを決めることです。同時に動かすなら、どの時期にどちらの卒年へ送るかを、現場の書く時間と合わせて先に配ります。期間の長さは、計画の長さと合わせて初めて価値になります。

## まとめ

- 早期定額型プランは、インターンや早期面談の時期からオファーを送れる定額のプラン
- 3名採用の場合75万円（税抜）、利用可能期間は最長24ヶ月、オファー枠は120枠（3名採用の場合）
- 専任担当のサポートと、既存社員最大30名分の適性検査が付く。11名以上のプランも用意がある
- EXオプション25万円で開始をさらに2ヶ月前倒しできる（期間が延びるものではない）
- 向くのは、夏から秋に書く時間と面談の枠がある会社。3月以降しか動けないなら成功報酬型を先に検討する

## よくある質問

### 早期定額型を取ったのに、夏に動けませんでした。どうすればよいですか

残りの期間で、書ける数に合わせて動かします。定額なので費用は戻りませんが、期間は最長24ヶ月あるので、次の卒年の早期の時期に使う設計に切り替えられます。翌年の申し込みでは、書ける体制ができてから早期型を選ぶか、成功報酬型にするかを見直します。

### EXオプションは、どんなときに使いますか

競合が動き出す前に接点を作りたい場合です。ただ、2ヶ月前倒ししても、その2ヶ月に書く人がいなければ意味がありません。EXオプションを検討する前に、その時期に現場が書けるかを確かめます。

### 早期定額型の相談は、御社にできますか

できます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、時期と体制からプランをご案内します。代理店手数料は媒体側から支払われるため、**企業の料金は各媒体の正規料金のまま**です。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
