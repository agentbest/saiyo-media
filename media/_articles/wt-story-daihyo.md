ストーリーで代表の考えを書く。ここで多いのが、会社の理念やミッションをもう一度、代表の名前で書く形です。**結論から言うと、代表の考えのストーリーで書くのは、理念ではなく「最近、代表が何を決め、何に迷い、何がうまくいかなかったか」です。1つの判断に絞り、代表に書かせず、話してもらって人事が書き起こし、本人が直します。** 理念は会社ページに書いてあります。ストーリーで候補者が知りたいのは、その理念で、いま代表が何をどう判断しているかです。この記事では、代表のストーリーの役割、書くこと、聞く質問、書き方と調子、頻度、会社ページのミッションとの関係、代表の確認が遅れる対策、やりがちな失敗、分担を整理します。ストーリーの位置づけは[ストーリーの基本](/media/wt-story-kihon/)、ミッションの書き方は[会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/)で書きました。

## この作業の目的｜候補者に「会社の判断の軸」を見せる

候補者が代表のストーリーを読むのは、「この会社は、何を基準に判断する会社か」を知るためです。理念の言葉より、実際の判断で、それが分かります。「〇〇の依頼を断った。理由は△△」と読めば、その会社の判断の軸が見えます。「私たちは□□を大事にしています」では、見えません。

代表のストーリーの目的は、候補者に会社の判断の軸を、実際の判断で見せることです。判断の軸が見えると、候補者は「自分はこの軸で働けるか」を判断できます。

## 手順1｜書くこと｜理念ではなく、最近の判断

代表のストーリーで書く題材を並べます。どれも「最近の、1つの判断」です。

| 題材 | 書くこと | 候補者が得るもの |
|---|---|---|
| 最近決めたこと | 何を、なぜ、どう決めたか。迷った選択肢と、選ばなかった理由 | 判断の軸 |
| 断ったこと | 何を断り、なぜ断ったか | 大事にしていること、しないこと |
| うまくいかなかったこと | 何を試して、どう失敗して、何を変えたか | 失敗への向き合い方 |
| 迷っていること | いま決めかねていることと、迷いの中身 | 正直さ。「言い切れない」も判断の一部 |
| 変えたこと | 以前と今で、考えを変えたこと。何がきっかけか | 会社が変わる余地 |
| これからやること | 次に始めることと、その理由。まだ決まっていない部分も | 候補者の役割 |

「理念」「創業のきっかけ」は、会社ページの「なぜやるのか」に書いてあります。ストーリーで繰り返すと、読み飛ばされます。書くなら、「その理念で、先月こう判断した」の形で、理念は一文で触れるだけにします。

## 手順2｜代表に書かせず、話してもらう

代表のストーリーで最も多い止まり方は、「代表が書く時間が無い」です。書かせません。話してもらいます。

1. **人事が、テーマを1つ決めて代表に伝える**：「先週断った〇〇の件について聞きたい」
2. **短い時間で、話してもらう**：録音する。書く時間ではなく、話す時間だけをもらう
3. **人事が書き起こし、場面の順に整える**：話した順ではなく、判断の順（何があった→何を迷った→何を決めた→なぜ）
4. **代表に見せて、直してもらう**：言い換えた部分は代表の言葉に戻す
5. **公開する**

「話す」は短時間で済み、「直す」も短時間で済みます。「書く」だけが、代表の時間を大きく使い、止まります。会社ページの「なぜ」を書き起こしたのと同じ手順です。

聞く質問を用意します。

- 「最近、決めたことで、迷ったものはありますか。何と何で迷いましたか」
- 「最近、断ったことはありますか。なぜ断りましたか」
- 「最近、うまくいかなかったことは。そのあと、何を変えましたか」
- 「いま、言い切れないこと、決めかねていることはありますか」
- 「以前と考えが変わったことはありますか。何がきっかけでしたか」

「迷い」「断り」「失敗」「言い切れない」を聞くのは、それが判断の軸を最も具体的に見せるからです。決めたことだけを聞くと、結果だけの記事になります。

### エージェントベストの見解

相談で最も多い思い込みは、「代表のストーリーは、会社の理念や想いを代表の言葉で語るものだ」というものです。実際には、理念は会社ページに書いてあり、ストーリーで同じことを読まされた候補者は、読み飛ばします。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、候補者が「代表の記事を読んで来た」と言うストーリーは、理念の記事ではなく、「先月、大きな案件を断った理由」「新規事業を一度止めた話」のような、1つの判断を書いた記事です。判断には、迷いと、選ばなかった選択肢があり、そこに会社の軸が出ます。理念は「何を大事にしているか」を言葉で言い、判断は「本当に大事にしているか」を行動で見せます。候補者が信じるのは、後者です。代表のストーリーは、理念を減らして、判断を足すもの。理念を書きたくなったら、「その理念で最近どう判断したか」に置き換えることを勧めます。

## 手順3｜書き方と調子

書き起こしを記事にするときの、書き方と調子です。

| 観点 | 避ける | 代わりに |
|---|---|---|
| 相手 | 社員に語る調子（訓示、号令） | 候補者に語る調子。「うちは」ではなく「この会社は」 |
| 断定 | 「〜すべきだ」「〜に決まっている」 | 「〜と考えている」「〜だと思う。ただし〜」。断定は候補者を遠ざける |
| 構成 | 結論→理由の説明 | 場面→迷い→判断→理由。判断に至る過程を見せる |
| 長さ | 長い。全部を語る | 1つの判断を書き切る長さ |
| 終わり方 | 教訓、決意表明、候補者への呼びかけ | 判断を置いて終える。「まだ答えは出ていない」で終わってもよい |
| 言葉 | 経営の用語、抽象語 | 代表が話した言葉のまま。用語は一言で説明する |

「候補者に語る調子」が、見落とされやすい点です。代表は普段、社員に向けて話しているので、書き起こすと訓示の調子になります。人事が「これを読むのは、まだ入っていない人」と意識して、調子を直します。ただし、代表の言葉そのものは変えません。調子だけを直します。

## 手順4｜頻度と、会社ページのミッションとの関係

代表のストーリーは、数ヶ月に一本で足ります。

- **続けて出さない**：代表の記事が続くと、会社が代表の言葉だけに見える。社員の話、事業の裏側と交互に。ローテーションの考え方は[ストーリーのテーマの決め方](/media/wt-story-theme/)
- **会社ページのミッションの「いまの判断」を、ストーリーで膨らませる**：ミッションの部分に「先月、〇〇を断った」と一文で書き、その話をストーリーで詳しく。会社ページとストーリーが対になる
- **会社ページのミッションの「いまの判断」を、ストーリーを書いたときに差し替える**：数ヶ月に一度の差し替えの材料が、代表のストーリー
- **事業や組織が大きく変わったときは、頻度に関わらず書く**：「なぜ変えたか」を候補者は知りたい

代表のストーリーが溜まると、会社ページのミッションが「生きている言葉」になります。判断の記録が、理念の裏づけになるからです。

## 手順5｜代表の確認が遅れる対策

代表のストーリーで、書き起こしのあとに止まるのが「代表の確認待ち」です。対策を先に決めます。

1. **確認の期限を決める**：「書き起こしを渡してから〇日以内に」。期限を代表と合意する
2. **期限を過ぎたら、人事の判断で公開してよいと合意しておく**：代表の言葉を変えていない前提で。この合意は[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)で書いた「代表の確認が遅い」への対処と同じ
3. **直す量を減らす**：代表の言葉をそのまま残していれば、直す箇所は少ない。言い換えが多いと、直す時間が増えて遅れる
4. **確認を「読んで一言」にする**：全文を直してもらうのではなく、「事実と違う箇所があれば」だけ
5. **話してもらう場で、その場で確認する形もある**：書き起こしを待たず、話した直後に「こう書きます」と伝えて口頭で了解を取る

「期限を過ぎたら人事の判断で公開」の合意が無いと、代表のストーリーは月単位で止まります。合意は、最初の1本を書く前に取ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 理念をもう一度書く | 読み飛ばされる | 最近の1つの判断 |
| 決めたことだけで、迷いが無い | 結果だけの記事。軸が見えない | 迷った選択肢と、選ばなかった理由 |
| 代表に書いてもらう | 時間が無く止まる | 話してもらい、書き起こす |
| 社員向けの訓示の調子 | 候補者が遠ざかる | 候補者に語る調子に |
| 断定が強い | 候補者が身構える | 「〜と考えている」「ただし〜」 |
| 失敗や迷いを載せない | 良いことだけ | 失敗と迷いこそ軸が見える |
| 代表の記事が続く | 会社が代表だけに見える | 数ヶ月に一本。他の型と交互 |
| 確認待ちで止まる | 公開されない | 期限と、過ぎたら人事判断の合意 |
| 経営の用語のまま | 候補者に分からない | 一言で説明するか、言い換える |
| 決意表明で終わる | ポエムに見える | 判断を置いて終える |

最も多いのは、最初の「理念をもう一度書く」と、「代表に書いてもらう」です。前者は内容、後者は進め方の問題で、どちらも最初の1本で起きます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| テーマ（最近の判断）を1つ決める | 人事（代表に「最近迷ったことは」と聞いて） |
| 話す | 代表 |
| 録音し、書き起こし、判断の順に整える | 人事 |
| 調子を候補者向けに直す（言葉は変えない） | 人事 |
| 事実の確認と一言 | 代表 |
| 公開する | 人事 |
| 会社ページのミッションの「いまの判断」を差し替える | 人事 |

代表の時間は、「話す」と「一言確認する」の2つです。運用代行や代理店が支えられるのは、聞く質問、書き起こしから記事への整理、調子の調整までで、話すことと確認は代表が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと代表のストーリーが1本も出ないことがあります。「代表は書かない。話すだけ」と、代表本人と合意することです。当社がWantedlyの運用の相談で代表のストーリーの話をするとき、「代表が書く時間が無い」で止まっている会社が多くあります。書く時間は無くても、話す時間は短くて済みます。当社が勧めるのは、人事が代表の予定の合間に短い時間をもらい、「先週、迷ったことは」と1つ聞き、録音して当社か人事が書き起こす形です。代表は、話したあとに一言確認するだけです。この形なら、代表の時間は最小で、記事は代表の言葉で書かれます。「代表に書いてもらう」と決めた時点で、代表のストーリーは止まります。「話してもらう」に変えるだけで、数ヶ月に一本は出ます。

## まとめ

- 代表のストーリーで書くのは、理念ではなく、最近の1つの判断。決めたこと、断ったこと、うまくいかなかったこと、迷っていること、変えたこと
- 判断には、迷った選択肢と選ばなかった理由を入れる。結果だけでは軸が見えない
- 代表に書かせず、話してもらい、人事が書き起こし、代表が一言確認する。確認の期限と、過ぎたら人事判断で公開の合意を先に
- 候補者に語る調子で、断定しすぎず、経営の用語は言い換え、判断を置いて終える
- 数ヶ月に一本。会社ページのミッションの「いまの判断」と対にし、書いたときに差し替える

## よくある質問

### 代表が「理念を語りたい」と言います

理念は会社ページに書いてあるので、ストーリーでは「その理念で、最近どう判断したか」を書くことを勧めます。「先月、〇〇を断った。理念の△△に反するから」の形なら、理念も入り、判断も見えます。理念だけの記事は、会社ページと重なって読み飛ばされます。

### 代表の失敗や迷いを載せて、会社の印象が悪くなりませんか

逆です。決めたことだけの記事は結果しか無く、候補者には「本当にそう判断しているか」が分かりません。失敗と、そこから何を変えたか、迷いと、その中身が書いてあると、候補者は「この会社は正直で、判断の軸がある」と読みます。載せたくない失敗は載せなくて構いませんが、迷いは載せるほうが届きます。

### 代表のストーリーの作成は、御社に相談できますか

できます。当社は、聞く質問の用意、書き起こしから判断の順への整理、候補者向けの調子への調整、会社ページのミッションとの対応を支えられます。話すことと、確認は代表にお願いしています。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのストーリーの整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
