営業、企画、総合職など、文系の学生を採りたい。文系の学生は数が多いので、OfferBoxで「総合職募集」の文面を広く送れば来ると考えて始めると、承認は付いても面談で「何の仕事か分からなかった」で離れ、送った学生の多くは他社からも同じような文面を受け取っていて、自社の文面が埋もれる、という形になります。**結論から言うと、文系の学生は志望職種が広く、記述が「行動」中心で、多くの会社からオファーを受け取っている、という前提で組みます。最初に決めるのは、職種を先に一つに決めること、「こんな人」を職種ごとに行動で書くこと、検索を絞りすぎず広げすぎないこと、名義を現場の若手にすること、承認のあとの当日返信と選考の短さで差をつけることです。** この記事では、文系学生を採りたい会社が割ける時間と人、文系の学生の前提、最初に決めること、文面で書かないこと、運用の分担、やりがちな失敗を整理します。文面そのものの書き方は[OfferBoxで文系学生にオファーを送るときの文面](/media/ob-bunkei-gakusei/)、文系の母集団形成は[文系の母集団形成](/media/kh-boshudan-bunkei/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 採る職種が「総合職」で、配属が入社後に決まる | 文面に仕事の中身が書けず、会社紹介になる |
| 検索すると、対象の学生が多すぎる | 絞れずに広く送り、文面が薄くなる |
| 人事が文面を書き、現場は関わらない | 仕事の場面が書けず、「文系でも活躍」の文面になる |
| 承認は付くが、面談で離れる | 学生は他社からも受け取っていて、速さと具体で比べている |
| 面接官が「なぜうちか」を聞く | 志望職種が広い学生に、志望動機を求めて離れる |

文系学生を採りたい会社がOfferBoxに割ける時間は、送る数ではなく、「承認のあとに当日返し、数日で面談に出る」速さで決まります。文系の学生は、複数の会社と同時に進んでいる前提で、速さで差がつきます。

## 文系の学生の前提

- **志望職種が広い**：「営業」「企画」「事務」を並べて見ていて、職種名で仕事を想像できないことが多い。仕事の場面で伝える
- **記述が「行動」中心**：専攻や研究ではなく、部活、アルバイト、留学、ゼミでの行動が書かれている。行動の型で読む
- **多くの会社からオファーを受け取っている**：同じような「総合職募集」の文面が並んでいる。「なぜあなたに」がない文面は開かれない
- **承認は付きやすいが、面談で離れやすい**：承認は「話を聞いてみよう」で、面談で「何の仕事か」が分からないと離れる
- **「文系でも」と書かれると、下に見られたと読む**：文系を前提にした文面は要らない。仕事の中身で書く

## 最初に決めること

1. **職種を、先に一つに決める**：「総合職」で送らない。営業なら営業、企画なら企画。配属が入社後に決まる会社は、「最初の年に多い配属」を一つ選んで書く。[募集職種が多い会社のOfferBox運用](/media/ob-bosyu-shokushu-ooi/)
2. **「こんな人」を、職種ごとに行動で書く**：「コミュニケーション力」ではなく、「自分で始めて、人を巻き込んだ経験」「相手の言い分を聞いてから決めた経験」。営業の場合の考え方は[OfferBoxで営業職志望の学生を見つける検索の考え方](/media/ob-eigyo-target/)
3. **検索を、絞りすぎず広げすぎない**：文系は対象が多いので、「志望職種」で絞りすぎると近い学生を落とし、広げすぎると文面が薄くなる。行動の記述で絞る。[OfferBoxの検索結果が多すぎて絞れないとき](/media/ob-kensaku-hirosugi/)
4. **名義を、現場の若手にする**：文系の学生は「この人と働くか」で見る。人事の名義より、入社数年の現場の社員の名義。頼むことは名義・文面の確認・面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
5. **承認への当日返信と、選考の短さを、送る前に作る**：他社と同時に進んでいる学生に、速さで差をつける。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)、[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/)
6. **面接官に、「なぜうちか」を聞かないと伝える**：志望職種が広い学生に志望動機を求めない。[OfferBox経由の学生を面接する現場社員への説明](/media/ob-genba-mensetsukan/)

### エージェントベストの見解

相談で最も多い思い込みは、「文系の学生は数が多いので、広く送れば承認が取れる」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、文系向けの文面の承認と、そのあとの面談を見ていますが、広く送った文面は、承認は付いても、面談で「何の仕事か分からなかった」「他の会社と同じ文面だった」で離れます。文系の学生は、多くの会社から同じような「総合職募集」を受け取っていて、自社の文面はその中の一通です。数が多いことは、送る側の有利ではなく、学生の側の比べる材料の多さです。当社が文系向けの文面を作るときは、送る数を増やすことより先に、職種を一つに決め、その職種の仕事の場面を一つ書き、記述のどの行動を見たかを一文入れます。承認の数は減りますが、承認した学生は「仕事の中身で選んだ」学生で、面談で離れません。

## 文面で書かないこと、書くこと

| 書かない | 書く |
|---|---|
| 「総合職募集」「幅広い職種で活躍」 | 一つの職種の、最初の年の仕事の場面 |
| 「文系でも活躍できます」 | 仕事の中身。文系かどうかに触れない |
| 「コミュニケーション力を活かせる」 | 記述のどの行動を見たか。「〇〇の経験を読んで」 |
| 「あなたの可能性」「成長環境」 | 誰と組んで、最初の年に何を任せるか |
| 業界の説明の長文 | 業界を知らない前提で、仕事を一場面で。業界の説明は採用サイトに |

- **職種名から仕事を想像できない学生に、場面で伝える**：「営業」ではなく「〇〇の会社に、△△を提案して、□□を決めてもらう仕事」。文面の型は[文系学生向けスカウト文面の型](/media/kh-bunmen-bunkei/)
- **行動の型で拾う**：部活、アルバイト、ゼミの記述から、「自分で始めた」「続けた」「人を巻き込んだ」を拾う
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)

## 承認のあとの速さで、差をつける

- **承認への返信は当日**：文系の学生は複数の会社と同時に進んでいる。翌日には他社の面談が入っている
- **面談は、承認から数日以内に**：面談の枠を名義の社員の予定に先に入れておく
- **面談は「文面の続き」から**：会社の説明から始めない。「〇〇の経験を読んで送りました。その話から聞かせてください」。[OfferBox経由の学生との初回面談の設計](/media/ob-mendan-sekkei/)
- **選考の段を減らす**：文系の学生は、段が多い会社から離れる。段ごとの目的を一つに
- **面談前の連絡を三回**：確定、前日、当日。[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 職種を一つに決める | 人事と現場の責任者 |
| 「こんな人」の一行と、仕事の場面 | 人事と現場の若手 |
| 検索、文面の下書き、送信 | 人事、または代行 |
| 文面の最終確認、名義 | 現場の若手 |
| 承認への当日の返信 | 人事、または代行 |
| 面談 | 名義の若手と、面接官 |
| 面接官への説明（「なぜうちか」を聞かない） | 人事 |
| 週に一度、承認から面談までの日数を見る | 人事。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/) |

- **現場の若手に頼むのは、名義・文面の確認・面談の三つ**：仕事の場面を一つ話してもらえば、文面は人事か代行が書ける
- **検索と送信を外に出すと、人事の時間を承認後の速さに使える**：[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)

運用代行や代理店が支えられるのは、職種の絞り方の型、「こんな人」の型、文面の型、検索・下書き・送信・一次返信、面談前の連絡までで、職種の決定、仕事の場面、文面の最終確認、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「文系の学生に、どの職種を、最初の年にどの仕事で任せるか」を一つに決めておかないと、文面を整えても効果が出ません。当社はOfferBoxの運用代行で文系向けの文面を作りますが、「総合職で、配属は入社後」の会社に「最初の年に多い配属はどこですか」と聞くと、答えは出てきます。営業が多いなら営業の場面で、企画が多いなら企画の場面で書き、「配属は入社後に決まりますが、最初の年は〇〇が多いです」と正直に添えます。職種を決めずに送ると、文面は会社紹介になり、学生は「何の仕事か」を想像できず、承認しても面談で離れます。順番は、職種を一つに決め、その職種の若手を名義にし、その若手が最初の年にした仕事を一場面聞いてから、検索と文面に進むことです。職種が決まれば、検索の絞り方も、行動の拾い方も決まります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「総合職募集」で広く送る | 他社の文面に埋もれ、承認しても面談で離れる | 職種を一つに |
| 「文系でも活躍」と書く | 下に見られたと読まれる | 仕事の中身で書く |
| 「コミュニケーション力」で検索して送る | 誰にでも当てはまり、「なぜあなたに」がない | 行動の記述で絞る |
| 人事の名義で送る | 「この人と働くか」が見えない | 現場の若手の名義 |
| 承認への返信が翌日以降 | 他社の面談が先に入る | 当日返信と数日以内の面談 |

最も多いのは、一つ目です。文系の学生の多さを、送る側の有利だと考えて、広く薄く送ります。

## まとめ

- 文系の学生は志望職種が広く、記述が行動中心で、多くの会社からオファーを受け取っている。数の多さは学生の比べる材料の多さ
- 最初に、職種を一つに決める。「総合職」で送らず、配属が入社後の会社は「最初の年に多い配属」で書く
- 「こんな人」を職種ごとに行動で書き、行動の記述で絞る。名義は現場の若手で、頼むのは名義・確認・面談の三つ
- 文面に「文系でも」「コミュニケーション力」を書かず、一つの職種の最初の年の場面と、記述のどの行動を見たかを書く
- 承認への当日返信、数日以内の面談、選考の短さで差をつける。面接官に「なぜうちか」を聞かないと伝える

## よくある質問

### 配属が入社後に決まるので、職種を一つに絞れません

「最初の年に多い配属」を一つ選んで、その仕事の場面で書きます。「配属は入社後に決まりますが、最初の年は〇〇の配属が多いです」と添えれば、嘘にはなりません。職種を書かない文面は、学生が仕事を想像できず、承認しても面談で離れます。複数の職種があるなら、職種ごとに文面を分けます。

### 文系の学生に、業界の説明は要りますか

文面には要りません。業界を知らない前提で、仕事を一場面で書きます。業界の説明は採用サイトに置き、面談で聞かれたら答えます。文面で業界を説明し始めると、長くなって「なぜあなたに」が埋もれます。

### 文系学生を採りたい会社のOfferBox運用は、御社に相談できますか

できます。当社は、職種の絞り方の型、「こんな人」の型、文面の型、検索・下書き・送信・一次返信、面談前の連絡を支えられます。職種の決定、仕事の場面、文面の最終確認、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
