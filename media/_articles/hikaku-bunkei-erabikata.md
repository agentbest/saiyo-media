文系学生を採りたい会社が媒体を選ぶとき、最初にぶつかるのは「『総合職』『文系歓迎』で全媒体に出し、承認や応募は多いのに、学生は多くの会社から同じような文面を受け取っていて自社を覚えておらず、面談で『何の仕事をするのですか』と聞かれて『総合職なので幅広く』としか答えられず、内定を出しても『他の会社のほうが仕事が具体的だった』と辞退される」という問題です。**結論から言うと、文系の学生は業界志望が広く、多くの会社からオファーを受け取っているので、「文系」で一括りにせず「何の仕事か」を職種ごとに先に見せます。比べられる場と記事を置く型で「何の仕事か」を場面で見せることを主に、送る型は経験を行動の型で拾って「この仕事のこの場面で」とつなぎ、「総合職」「文系でも」を消し、承認の多さではなく「何の仕事か」が伝わった学生の数で見ます。** 母集団の考え方は[文系の母集団形成](/media/kh-boshudan-bunkei/)で書きました。この記事は媒体の選び方に絞って、入口の比重と「何の仕事か」の見せ方を書きます。

## 文系学生を採りたい会社に、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 文系の学生は業界志望が広い | 「何の仕事か」が見えないと、比べる材料が無い | 職種ごとに「何の仕事か」を先に。[文系学生を採りたい会社のOfferBox運用](/media/ob-bunkei-unyou/) |
| 多くの会社からオファーを受け取っている | 同じような文面は覚えられず、承認しても面談で覚えていない | 経験を行動の型で拾った一文が要る |
| 「総合職」で募集している | 仕事の中身が見えず、「総合職なので幅広く」で終わる | 職種ごとに分ける。[ワンキャリアで文系学生向けに掲載するとき](/media/oc-bunkei-keisai/) |
| 「文系でも」「文系歓迎」で書く | 「文系だから下に見られている」と読まれる | 消す |
| 承認や応募が多い | 数が多いことで「効いている」と読み違える | 「何の仕事か」が伝わった学生の数で |
| 掲載とイベントの比重が高い | スカウトだけで文系を採ろうとして、読まれない | 掲載とイベントを主に、スカウトを補助に |

## 判断軸を、文系学生を採りたい会社に当てる

| 軸 | 文系学生を採りたい会社での見方 |
|---|---|
| 対象（誰に届くか） | 「文系」ではなく、職種ごとに「こんな人」を行動の型（決めきれない人と一緒に選んだ、断られて変えた、集めて選んだ、合わなかったとき原因を見つけた）で絞る。学部と資格はあればよい条件 |
| 型（送るか、来るか、比べられるか） | 比べられる型は、「何の仕事か」を職種ごとに場面で書けば、業界志望が広い学生が比べる材料になる。来る型は、職種ごとの一日を記事で通年で。送る型は、経験を行動の型で拾って「この仕事のこの場面で」とつなぐ一文があってはじめて効く。文面が「文系歓迎」だけなら効かない |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。掲載とイベントに厚く、スカウトは絞った分だけ |
| 運用工数（誰の時間が要るか） | 職種ごとの社員が、仕事の場面を話す時間と、イベントと面談に出る時間。人事は職種ごとの「何の仕事か」を集めて書く時間 |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。文系学生を採りたい会社では、「型」で掲載とイベントの比重が高いことと、「対象」を職種ごとの行動の型で絞ることが、理系と違います。

### エージェントベストの見解

文系学生を採りたい会社に、向いている媒体の使い方と向いていない使い方があります。当社は3媒体すべての販売パートナーとして、文系の採用の相談を受けますが、「文系は数が多いから、送る型で数を送れば採れる」という使い方は、勧めていません。文系の学生は、多くの会社からオファーを受け取っていて、「文系歓迎」「総合職」の文面は読まずに流します。送る型が効くのは、学生の経験を行動の型で拾って、「決めきれない客と一緒に選んだと書かれていたのを読んで、営業の〇〇の場面で」と、一文で仕事につないだときだけです。文系で主になるのは、比べられる場と記事を置く型で、「何の仕事か」を職種ごとに場面で見せることです。業界志望が広い学生は、「何の仕事か」が見える会社を比べる材料にし、見えない会社を候補から外します。当社が最初にお願いするのは、企業ページと記事から「総合職」を職種の名前に変え、職種ごとに「一日」と「一年目に任されること」を場面で書くことです。それが書けてから、送る型で行動の型を拾って送ります。順番が逆だと、送っても「何の仕事か」が無く、読まれません。

## 学生が、確かめること

- **何の仕事か**：「総合職」ではなく、職種ごとに、誰に、何を、どうやって。一日の流れ
- **職種ごとの一年目**：最初の年に何を任され、誰が横につくか
- **配属の決まり方**：職種で募集しているか、入社後に決まるか。「総合職」の学生の最大の不安
- **自分の経験が、読まれたか**：オファーの一文が、自分の経験のどの行動を見たか。「文系歓迎」の一語だけなら、読まれていない
- **他の会社との違い**：業界志望が広いので、業界をまたいで比べている。仕事の場面の具体さで比べる
- **「文系でも」と書かれていないか**：下に見られていると読む

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 職種ごとに「何の仕事か」を場面で書け、体験談があり、候補に入っている | 学生が並べて比べる場（ワンキャリア） | 業界志望が広い学生の比べる材料になる。文系で最も効く入口の一つ |
| 職種ごとの社員が、一日と一年目を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「何の仕事か」を通年で読んでもらえる。営業・企画・人事など |
| 職種ごとに行動の型で絞り、「この仕事のこの場面で」の一文を書ける | 企業から送る型（OfferBox） | 一文があれば、多くのオファーの中で覚えられる。[OfferBoxで文系学生を見つける検索の考え方](/media/ob-bunkei-gakusei/) |
| 「総合職」のままで、職種ごとの「何の仕事か」が書けていない | どれも先ではない | 分けてから |
| 文面が「文系歓迎」だけ | 送る型は先ではない | 読まれない |

どれか一つが正解ではなく、体験談があるか、社員が書けるか、行動の型で絞れるかで、先に検討するものが変わります。

## 見せ方｜「総合職」ではなく、職種ごとの「何の仕事か」

- **「総合職」「文系歓迎」「文系でも活躍」を消す**：仕事が見えず、下に見られていると読まれる
- **職種ごとに、「誰に、何を、どうやって」を一段落で**：「営業は、〇〇の業種の△△に、□□を、◇◇のやり方で。一日の流れは」
- **職種ごとの一年目を、任されることで**：「一年目は〇〇を。△△が横につく」
- **配属の決まり方を、先に**：「募集の職種のまま配属」か、「入社〇か月の研修の後に決める。決め方は」
- **オファーの一文を、行動の型で**：「決めきれない客と一緒に選んだと書かれていたのを読んで、営業の〇〇の場面で」。「文系歓迎」の一語で送らない
- **他の業界と比べられる前提で**：仕事の場面の具体さで比べられる。業界の説明より仕事の場面を
- **数値は自社の実態で**：この記事では書かない

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「総合職」を職種に分ける、職種ごとの人数、配属の決まり方、入口の比重を決める | 採用の責任者 |
| 職種ごとの「何の仕事か」と一年目を集める | 人事が、職種ごとの社員に聞いて書く |
| 企業ページと記事 | 人事が書き、職種の社員が確認 |
| イベントで仕事の場面を話す | 職種の社員。少人数の回 |
| スカウトの絞る条件（行動の型）と一文 | 人事か代行が絞り、職種の社員が一文を足す |
| 面談 | 職種の社員。「何の仕事か」を本人が話す |
| 「何の仕事か」が伝わった学生の数の記録 | 人事。面談で「何の仕事か」を言えた学生を数える |

運用代行や代理店が支えられるのは、職種の分け方の型、「何の仕事か」の書き方の型、行動の型で絞る作業、一文の下書き、記録の型までで、職種ごとの場面の中身、イベントで話す、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

文系学生を採りたい会社が数字を読むときに先にお伝えしているのは、「承認や応募の多さで、効いていると読み違えない」ということです。文系の学生は多く、「総合職」「文系歓迎」でも承認や応募は来ます。ところが、その学生は多くの会社に同じように承認していて、自社を覚えておらず、面談で「何の仕事をするのですか」から始まり、内定を出しても仕事が具体的な会社に行きます。当社が案内するのは、面談で「この会社は何の仕事か」を学生が自分の言葉で言えたかを記録し、「何の仕事か」が伝わった学生の数で見ることです。承認が多くて伝わった学生が少ないなら、企業ページと文面に「何の仕事か」が無く、数を送っても変わりません。承認が減っても伝わった学生が増えていれば、「総合職」を職種に分けた効果が出ています。辞退の理由を「他社に決めた」で終わらせず、「他社の何が具体的だったか」まで聞くと、自社の企業ページに足りない場面が分かります。文系の採用は、数ではなく、「何の仕事か」が伝わった数で見ます。

## まとめ

- 文系の学生は業界志望が広く、多くの会社からオファーを受け取っている。「文系」で一括りにせず、「総合職」を職種に分け、「何の仕事か」を職種ごとに場面で先に見せる
- 比べられる場（ワンキャリア）と記事を置く型（Wantedly）で「何の仕事か」を見せることを主に、送る型（OfferBox）は経験を行動の型で拾って「この仕事のこの場面で」とつなぐ一文があるときに。掲載とイベントの比重が高い
- 「総合職」「文系歓迎」「文系でも」を消す。学生は仕事が見えず、下に見られていると読む
- 学生は「何の仕事か・職種ごとの一年目・配属の決まり方・自分の経験が読まれたか・他の会社との違い」を確かめる。業界をまたいで、仕事の場面の具体さで比べる
- 承認や応募の多さではなく、面談で「何の仕事か」を自分の言葉で言えた学生の数で見る

## よくある質問

### 「総合職」で採って、入社後に配属を決めています。職種に分けられません

分けられないなら、「総合職」の中身を、配属先の職種ごとに「何の仕事か」で書きます。「総合職。配属は入社〇か月の研修の後。配属先は営業・企画・管理のいずれかで、それぞれの一日は」と、職種ごとの場面を並べ、決め方を先に書きます。学生の最大の不安は「配属ガチャ」で、職種ごとの仕事が見えていれば、「どれになっても分かっている」状態で選べます。「総合職なので幅広く」だけでは、何も見えません。

### 文系の学生にスカウトを送っても、承認されません

文面が「文系歓迎」「総合職」だけなら、多くのオファーの中で読まれずに流れます。学生の経験を行動の型（決めきれない人と一緒に選んだ、断られて変えた、集めて選んだ、合わなかったとき原因を見つけた）で拾い、「〇〇と書かれていたのを読んで、営業の△△の場面で」と、一文で仕事につなぎます。その一文があってはじめて、覚えられて承認されます。一文が書けないなら、企業ページと記事で「何の仕事か」を先に整え、スカウトは後にします。

### 文系学生を採りたい会社の媒体選びは、御社に相談できますか

できます。当社は、職種の分け方の型、「何の仕事か」の書き方の型、行動の型で絞る作業、一文の下書き、記録の型を支えられます。職種ごとの場面の中身、イベントで話す、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、文系学生を採りたい会社の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
