スカウトの文面を、二つの案で比べたい。「こっちのほうが良い気がする」で決めるのではなく、返信で確かめたい。ところが、複数か所を同時に変える、相手の型が違う、送る人が違う、期間が短い、で、「どちらが効いたか」が分からずに終わります。**結論から言うと、二つの案で比べるには、仮説を一つ立て、変えるのは一か所だけにし、相手の型と送る人と時期と通数を揃え、返信の数だけでなく返信から面談への進み方と面談で「文面のどこで」と言われたかで見ます。比べる順番は、書き出し、締め、件名、本文です。差が出た型を、テンプレートに戻します。三つの媒体で、この考え方は同じです。** この記事では、比べる前に決めること、起きる失敗、揃えるもの、見る指標、比べる順番、記録と型への反映、分担を整理します。Wantedlyの募集記事で比べる方法は[Wantedlyの募集記事を差し替えて比べる方法](/media/wt-boshu-abtest/)、週の見直しは[OfferBox運用の週次レビューのやり方](/media/ob-shuukan-review/)で書きました。この記事は、スカウト文面に絞った比べ方です。

## この作業の目的｜「気がする」を、「分かった」に変える

文面を直すとき、「こっちのほうが良い」は、送る側の感覚です。相手がどちらに返信するかは、送るまで分かりません。感覚で直し続けると、直した回数だけ、何が効いたかが分からなくなります。

目的は、二つの案を、条件を揃えて送り、返信と面談で差を見て、「この一か所を変えると、こう変わる」を自社の記録として持つことです。

## 比べる前に、決めること

| 決めること | 例 |
|---|---|
| 仮説を一つ | 「書き出しを、会社説明から相手の一文に変えると、返信が増える」 |
| 変える一か所 | 書き出しだけ。件名・本文・締めは同じ |
| 見る指標 | 返信の数、返信から面談までの進み方、面談で「文面のどこで」と言われたか |
| 期間 | 一か月。短いと差が出る前に終わる |
| 揃えるもの | 相手の型、送る人、時期、通数 |

「仮説を一つ」「変える一か所」が、比べる前の全部です。仮説の立て方は[Wantedlyの募集記事を差し替えて比べる方法](/media/wt-boshu-abtest/)の手順1で書きました。

## 比べ方で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 複数か所を同時に変える | 差が出ても、どの変更が効いたか分からない |
| 相手の型が揃っていない | 案Aを技術職に、案Bを営業職に送ると、文面の差ではなく相手の差 |
| 送る人が違う | 送る人ごとに空欄の埋め方が違い、文面の差ではなく人の差 |
| 期間が短い | 数通ずつで、たまたまの差を「効いた」と決める |
| 返信の数だけで見る | 返信は増えたが面談に進まない案を「効いた」と決める |
| 差がないのに、「効いた」と決める | 期待した案のほうを、差がなくても選ぶ |
| 比べている途中で、他の部分も変える | 比べる条件が崩れる |

共通するのは、「文面の差」以外の差が混ざっていることです。

### エージェントベストの見解

相談で最も多い思い込みは、「二つの案を作って、返信が多かったほうを採用すればよい」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体で文面を比べた会社を見ていますが、返信の数だけで選んだ案が、面談への進み方では劣っていた、ということが起きています。件名を「特別」で目立たせた案は開封と返信が増え、面談には進まず、面談で「文面のどこで」と聞くと「特に覚えていない」でした。地味な案は返信が少なく、面談に進み、「〇〇の一文で」と言われています。返信の数は、比べる指標の一つで、全部ではありません。当社が比べ方の相談を受けるとき、最初にやるのは、見る指標に「返信から面談への進み方」と「面談で言われた言葉」を足すことです。

## 揃えるもの

- **相手の型**：同じ「こんな人」の行動の型、同じ職種、同じ学年か経験。案Aと案Bで、相手の分布を同じにする
- **送る人**：同じ人が両方を送る。複数の人が送るなら、それぞれが両方を送る
- **時期**：同じ週に、交互に。案Aを先に全部、案Bをあとで全部、にしない。時期の差が混ざる
- **通数**：同じ数ずつ。片方が多いと、比べられない
- **空欄の埋め方**：「読んだ一文」と「重なり」の拾い方を、両方で同じ丁寧さに。比べるのは型の一か所

揃え方は[Wantedlyの募集記事を差し替えて比べる方法](/media/wt-boshu-abtest/)の手順3と手順4で書きました。

## 見る指標

| 指標 | 何が分かるか |
|---|---|
| 返信の数 | 文面が「開かれて、読まれて、返信された」か |
| 返信から面談への進み方 | 返信した相手が、面談まで来たか。「話す場」の中身が見えていたか |
| 面談で「文面のどこで」と言われたか | どの部分が効いたか。案Aの変えた一か所が挙げられたか |
| 「こんな人」に近い相手からの返信 | 数ではなく、合う相手が返信したか |

四つで見ます。返信の数だけで決めません。面談で聞く言葉の集め方は[Wantedlyの募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)の「面談で聞く言葉を、材料にする」で書きました。

## 比べる順番

1. **書き出し**：会社説明から相手の一文に。最も差が出やすい
2. **締め**：「ご応募ください」から「話す場」に。返信から面談への進み方に差が出る
3. **件名**：書き出しを縮めたものと、それ以外。開封（見える範囲で）に差が出る
4. **本文**：仕事の場面の書き方。差が出るまでに時間がかかる
5. **名義**：人事と現場。相手の型を揃えたうえで

一か所ずつ、一か月ずつ。順番は[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)の「直す順番」と同じです。

## 記録して、効いた型をテンプレートに戻す

- **台帳に、「どの案で送ったか」を残す**：相手ごとに案Aか案Bか
- **一か月で、四つの指標を案ごとに並べる**
- **差が出たら、効いた案の一か所を、型に反映する**：[スカウト文面のテンプレート管理](/media/kh-bunmen-template/)の「更新の起点」の一つ
- **差が出なかったら、どちらでもよい。次の一か所へ**：「差がない」も記録
- **記録の型**：「〇月、書き出しを会社説明から相手の一文に。案A：返信〇、面談△。案B：返信□、面談✕。面談で挙げられた部分：〇〇」

記録の残し方は[Wantedlyの募集記事を差し替えて比べる方法](/media/wt-boshu-abtest/)の手順5で書きました。

## 比べられないとき

- **送る数が少なくて、差が出ない**：無理に比べない。一つの案で送り、返信が来た文面と来なかった文面を並べる形に。[スカウト文面でやりがちな失敗](/media/kh-bunmen-ng/)の「失敗に、気づく方法」
- **相手の型が一つしかなく、揃えられない**：それでよい。揃っている
- **送る人が一人で、時間がない**：比べるより、直す順番で一か所ずつ直して、一か月見る。比べなくても、前月との差で分かる
- **比べることが目的にならないように**：目的は、返信が来る文面を作ること

| 作業 | 誰が |

| 仮説を一つ立て、変える一か所を決める | 人事 |
| 二つの案を作る | 人事。名義の人が確認 |
| 相手の型・送る人・時期・通数を揃えて送る | 送る人 |

| 面談で「文面のどこで」を聞く | 面談に出る人 |
| 一か月で四つの指標を並べ、型に反映する | 人事 |

運用代行や代理店が支えられるのは、仮説の立て方、揃えるものの整理、指標の型、記録の型、型への反映までで、送ること、面談で聞くこと、案を選ぶ判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは数字の読み方の話です。二つの案を比べるとき、「案Aが何通、案Bが何通の返信」の数の差だけで判断すると、たまたまの差を「効いた」と決めることがあります。当社が見るのは、数の差より、「面談で文面のどこを挙げられたか」です。案Aで変えた一か所が、面談で相手から挙げられていれば、数の差が小さくても、その一か所は効いています。挙げられていなければ、数の差があっても、別の理由（時期、相手の型の偏り）かもしれません。数と言葉の両方が揃って、初めて「分かった」になります。

## まとめ

- 二つの案で比べるには、仮説を一つ立て、変えるのは一か所だけ。複数か所を同時に変えると、どれが効いたか分からない
- 相手の型・送る人・時期・通数・空欄の埋め方の丁寧さを揃える。案Aを先に全部、案Bをあとで全部、にしない
- 見る指標は、返信の数・返信から面談への進み方・面談で「文面のどこで」と言われたか・「こんな人」に近い相手からの返信。返信の数だけで決めない
- 比べる順番は、書き出し→締め→件名→本文→名義。一か所ずつ、一か月ずつ
- 台帳に案を記録し、差が出た一か所を型に反映する。差がないことも記録する。送る数が少ないなら、比べずに前月との差で見る

## よくある質問

### 送る数が少なく、二つの案に分けると差が出ません

分けません。一つの案で送り、前月と今月の返信を比べます。一か所を変えて一か月見る、を繰り返せば、比べなくても「この一か所を変えたら、こう変わった」は分かります。二つの案で比べるのは、送る数が十分にある場合の方法で、少ない場合は、一か所ずつの直しと、返信が来た文面と来なかった文面を並べることで足ります。

### 二つの案で、返信の数は同じでした

「差がない」も記録します。その一か所は、返信の数には効いていません。次に、面談への進み方と、面談で挙げられた部分を見ます。そこにも差がなければ、その一か所はどちらでもよく、次の一か所へ進みます。「差がない」が分かることも、「分かった」の一つです。

### スカウト文面の比べ方は、御社に相談できますか

できます。当社は、仮説の立て方、揃えるものの整理、指標の型、記録の型、型への反映を支えられます。送ること、面談で聞くこと、案を選ぶ判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
