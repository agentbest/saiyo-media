前の卒年の内定者をフォローしながら、次の卒年の学生にオファーを送る。この時期、二つの卒年が同時に動きます。台帳が混ざり、文面の卒年表記を間違え、面談に出る人が両方に取られ、数字が混ざる。**結論から言うと、卒年をまたぐ時期の混乱は、二つの卒年を「同じ運用」で回そうとすることから起きます。台帳・文面・面談に出る人・企業ページ・数字を、卒年ごとに分けます。前の卒年の内定者フォローの骨格を先に固め、次の卒年は少数で「接点を作る」目的に絞って始めます。現場の時間を、内定者の場と面談で分け、週の見直しを卒年ごとに行い、年度の切り替えは管理画面とヘルプで確認します。** この記事では、同時に動くと起きる混乱、卒年ごとに分けるもの、内定者フォローを先に固めること、次の卒年を少数で始めること、現場の時間、週の見直し、年度の切り替え、分担を整理します。年間の組み方は[OfferBoxの年間運用スケジュールの組み方](/media/ob-nenkan-schedule/)、内定者フォローは[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)で書きました。この記事は、重なる時期に絞ったものです。

## この作業の目的｜二つの卒年を、「別の運用」として並べる

卒年をまたぐ時期は、「忙しい時期」ではなく、「二つの運用が並ぶ時期」です。忙しいから混乱するのではなく、二つを一つにしているから混乱します。

目的は、前の卒年の運用と次の卒年の運用を、台帳から数字まで分けて、それぞれを一つの運用として回すことです。

## 同時に動くと、起きる混乱

| 混乱 | 何が起きるか |
|---|---|
| 台帳が混ざる | 内定者の連絡日と、次の卒年の承認への返信日が、同じ表に並び、どちらかが抜ける |
| 文面の卒年表記を間違える | 前の卒年の型をそのまま使い、年度の表記が古いまま送る。学生に「使い回し」と読まれる |
| 面談に出る人が両方に取られる | 内定者の場と、次の卒年の面談が、同じ現場の若手に集中する |
| 企業ページの年度表記がずれる | 選考の流れや条件が前の年度のまま。次の卒年の学生が「今年のものか」と迷う |
| 数字が混ざる | 「今月の承認」に、内定者の承諾と次の卒年の承認が混ざり、どちらも見えない |
| 管理画面の卒年の切り替えを忘れる | 次の卒年に送っているつもりで、前の卒年の学生を検索している |
| 内定者フォローが薄くなる | 次の卒年の送信に時間を取られ、内定者への連絡が空く。辞退が出る |

最も重いのは、「内定者フォローが薄くなる」です。次の卒年の承認より、前の卒年の内定者の承諾のほうが、近い成果です。

## 卒年ごとに、分けるもの

| 分けるもの | 前の卒年 | 次の卒年 |
|---|---|---|
| 台帳 | 内定者の一覧（連絡日、話す相手、期限） | 送った・承認・面談の台帳 |
| 文面の型 | 使わない（内定後の連絡は別の型） | 年度表記を更新した型 |
| 面談・場に出る人 | 内定者の場：配属先の若手、内定者同士 | 面談：現場の人（内定者の場と別の人） |
| 企業ページ | 内定者は見ない | 年度表記・選考の流れ・条件を更新 |
| 数字 | 承諾の数、内定者との接点の回数 | 送った→承認→面談の段ごとの数 |
| 週の見直し | 内定者の状況 | 次の卒年の段ごとの止まり |
| 管理画面 | 内定者の状況の確認 | 卒年を切り替えて検索・送信 |

分けると、それぞれが一つの運用になり、どちらかが薄くなったときに、薄くなった側が見えます。

### エージェントベストの見解

相談で最も多い思い込みは、「卒年をまたぐ時期は、次の卒年の早い時期に送ることが最も大事なので、内定者フォローは後回しでよい」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、この時期に内定者フォローが薄くなった会社は、次の卒年の承認は来ているのに、前の卒年の内定者の辞退が出て、採用の結果が減っています。次の卒年の承認は、面談・選考・内定と、まだ先が長く、前の卒年の内定者は、承諾まであと一歩です。当社が卒年をまたぐ時期の相談を受けるとき、最初にやるのは、次の卒年の送る数を決めることではなく、「内定者フォローの骨格が固まっているか」を確かめることです。固まっていれば、次の卒年は少数で始められます。固まっていなければ、次の卒年を始める前に固めます。

## 前の卒年の内定者フォローの骨格を、先に固める

- **内定者の一覧を、一枚に**：名前、配属の見込み、話す相手、次の連絡日、期限
- **連絡の型を決めておく**：「月に一度、〇〇から一言」「期限の前に、一度話す」
- **話す相手を、内定者ごとに決めておく**：面談で話した人、配属先の若手
- **内定者の場を、日程まで決めておく**：内定者同士、社員との場
- **質問の窓口を一つに**：人事の誰か
- **「回すだけ」の状態にする**：次の卒年が始まったあとは、考えずに回せる形

骨格の作り方は[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)、内定者の活かし方は[OfferBoxの内定者の活用](/media/ob-naiteisha-katsuyou/)で書きました。骨格が固まっていれば、フォローに使う時間は短くなります。

## 次の卒年は、少数で「接点を作る」目的に絞る

- **早い時期の送信は、少数**：読める数の中でも少なめに
- **目的は「承認と面談」ではなく「接点を作る」**：年度の公表内容と自社の方針を確認して、この時期にできることの範囲で
- **文面の型を、年度表記を更新して使う**：前の卒年の型をそのまま使わない
- **企業ページの年度表記・選考の流れ・条件を、送る前に更新する**：更新の起点は「次の卒年に送る前」
- **面談に出る人を、内定者の場に出る人と別に決める**
- **本格的に送るのは、内定者フォローの山を越えてから**

早い時期の考え方は[OfferBoxの早期の運用](/media/ob-souki/)、インターンとのつなぎは[OfferBoxとインターンシップをつなげる設計](/media/ob-intern-setsuzoku/)で書きました。

## 現場の時間を、内定者の場と面談で分ける

- **同じ若手に、内定者の場と次の卒年の面談を両方頼まない**：重くなり、どちらも断られる
- **内定者の場は、配属先の若手**：内定者と近い人
- **次の卒年の面談は、別の現場の人**：文面の「最初の1年」を話せる人
- **内定者に、次の卒年の面談に出てもらう**：本人の同意のうえで。現場の負担が減り、内定者の側にも「関わっている」が残る。[OfferBoxの内定者の活用](/media/ob-naiteisha-katsuyou/)
- **現場の責任者に、この時期の依頼を先に伝える**：「〇月から△月は、内定者の場と面談の両方があります」

現場の時間の分け方は[OfferBoxの年間運用スケジュールの組み方](/media/ob-nenkan-schedule/)の手順3で書きました。

## 週の見直しを、卒年ごとに

- **週の見直しの項目を、前の卒年と次の卒年で分ける**：「内定者：連絡が空いている人はいないか」「次の卒年：承認への返しは当日か」
- **同じ場で見てよいが、項目は分ける**：一つの表に混ぜない
- **前の卒年の項目を、先に見る**：承諾まで近いほうを先に
- **次の卒年は、段ごとの止まりだけ**：この時期は数を追わない
- **月に一度、両方の数字を別々に**

週の見直しの型は[OfferBox運用の週次レビューのやり方](/media/ob-shuukan-review/)で書きました。

## 年度の切り替えは、管理画面とヘルプで確認する

- **管理画面の卒年の切り替え、次の卒年の学生の登録状況、送信できる時期は、年度ごとに変わる**：現在の仕様は管理画面とヘルプで確認
- **文面と企業ページの年度表記は、切り替えと同時に更新する**：更新の担当と時期を決めておく
- **前の卒年の学生に、次の卒年の文面を送らない**：切り替えを確認してから送る
- **契約の更新時期と、卒年の切り替えが重なることがある**：契約の切れ目を先に把握する。[OfferBoxを2年目以降に使うときの見直し点](/media/ob-repeat-unyou/)の手順6

### エージェントベストの見解

これは順番の話です。当社がOfferBoxの卒年をまたぐ時期の相談を受けたとき、「次の卒年をいつから送るか」の話を最初にしません。先に、前の卒年の内定者フォローの骨格が固まっているかを確かめ、固まっていなければ固めます。次に、台帳と型と企業ページと数字を卒年ごとに分けます。それから、次の卒年を少数で始めます。逆に、次の卒年の送信から始めると、内定者フォローが薄くなり、辞退が出て、次の卒年の承認で埋め合わせようとして、読まずに送る形に入ります。当社が勧める順番は、骨格を固める、分ける、少数で始める、山を越えたら本格的に送る、です。

## まとめ

- 卒年をまたぐ時期の混乱は、二つの卒年を同じ運用で回すことから起きる。台帳・文面の型・面談に出る人・企業ページ・数字・週の見直しを卒年ごとに分ける
- 最も重いのは、内定者フォローが薄くなること。次の卒年の承認より、前の卒年の内定者の承諾のほうが近い成果
- 内定者フォローの骨格（一覧・連絡の型・話す相手・場・窓口）を先に固め、「回すだけ」にしてから次の卒年を始める
- 次の卒年は少数で「接点を作る」目的に絞り、年度表記を更新した型と企業ページで送る。本格的に送るのは山を越えてから
- 現場の時間は内定者の場と面談で別の人に分け、内定者に面談に出てもらう。年度の切り替えは管理画面とヘルプで確認

## よくある質問

### 人事一人で、両方の卒年を回せません

内定者フォローを「回すだけ」の骨格にして、次の卒年を少数に絞れば、一人で回せる大きさになります。それでも足りなければ、次の卒年を「接点を作る」だけに絞り、本格的に送るのを内定者の期限のあとに回します。内定者フォローを削らないことが、優先です。

### 内定者に次の卒年の面談に出てもらうのは、負担ではありませんか

本人の同意のうえで、回数を少なく、短い時間で、と決めれば、多くの内定者は引き受けます。内定者の側にも、「入社前から関わっている」が残り、承諾後の気持ちの揺れが減ることがあります。頼み方は「出てほしい」ではなく、「話を聞かせてもらえるか」で、断れる形にします。

### 卒年をまたぐ時期の運用は、御社に相談できますか

できます。当社は、卒年ごとに分ける表の型、内定者フォローの骨格の型、次の卒年の型と企業ページの更新の案、週の見直しの項目の分け方を支えられます。内定者との接点、面談、現場の時間の配分、管理画面の操作は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
