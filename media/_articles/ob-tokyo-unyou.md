東京に本社があり、全国に拠点があって、新卒を全国の拠点に配属する。「東京本社」なら全国の学生が来ると考えて、本社の人事の名義で、全国の学生に同じ文面を送ると、承認は付いても、面談で「初任地はどこですか」「転勤はありますか」と聞かれ、答えが曖昧だと離れます。地方の学生は「東京に行くのか、地元の拠点なのか」を、東京の学生は「地方に配属されるのか」を、それぞれ確かめています。**結論から言うと、学生は「東京本社」より「初任地と転勤」を確かめます。最初に決めるのは、初任地の決まり方と転勤の有無を文面に隠さず書くこと、地域ごとに拠点の社員を名義にすること、学生の出身地域と勤務地の関係で検索を分けること、面談をオンラインを基本にすること、地域別の承認率を全体に混ぜないことです。** この記事では、東京本社で全国採用する会社が割ける時間と人、最初に決めること、文面の書き方、地域ごとの運用、運用の分担、やりがちな失敗を整理します。地方の学生への送り方は[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)、地方本社の会社の場合は[地方本社の会社がOfferBoxで都市部の学生に届くには](/media/ob-chihou-honsha/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 拠点が多く、配属先が全国に広がる | 「初任地はどこか」に文面で答えられない |
| 人事が本社に集中している | 全国の学生に、本社の人事の名義で同じ文面が届く |
| 拠点の社員が採用に関わっていない | 地方の学生が「その拠点で誰と働くか」を確かめられない |
| 転勤の有無や頻度が、職種や拠点で違う | 文面で一言では書けず、曖昧になる |
| 面談を本社で行う | 地方の学生の移動の負担が大きく、面談の前に離れる |
| 全国の承認率を一つで見る | 地域ごとの偏りが見えず、送る相手の直し方が分からない |

東京本社で全国採用する会社がOfferBoxに割ける時間は、本社の人事の時間だけではなく、「拠点の社員が、名義と面談にどれだけ出られるか」で決まります。全国の学生に届けるには、全国の名義が要ります。

## 最初に決めること

1. **初任地の決まり方と、転勤の有無を、文面に書ける形に整理する**：「全国転勤あり」の一言ではなく、「初任地は〇〇の時点で本人の希望と拠点の状況で決まる」「転勤は△△の職種であり、□□の職種はない」。書けないことは「面談で伝える」と添える
2. **地域ごとに、拠点の社員を名義にする**：東北の学生には東北の拠点の社員、関西の学生には関西の拠点の社員。「この拠点で、この人と働く」が見える。頼むことは名義・文面の確認・面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
3. **学生の出身地域と勤務地の関係で、検索を分ける**：地元で働きたい学生には地元の拠点の文面、東京で働きたい学生には本社の文面、Uターンを考えている学生には出身地の拠点の文面。記述から希望を読む。[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
4. **面談は、オンラインを基本にする**：本社まで来てもらう形にしない。拠点の社員と、その地域でオンラインで会う。[OfferBoxの学生とオンラインで会うときの進め方](/media/ob-mendan-online/)
5. **送る側の台帳に、地域の列を持つ**：どの地域の学生に、どの拠点の名義で、どの文面を送ったか。承認率を地域ごとに見る
6. **移動の負担を、会社が持つ形を決める**：対面で会う段があるなら、交通費と日程の配慮。書ける範囲で文面か採用サイトに。[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)

### エージェントベストの見解

相談で最も多い思い込みは、「東京本社なら、全国の学生が東京で働きたくて来る」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、全国採用の会社の承認と面談を見ていますが、地方の学生が承認の前に確かめているのは「東京本社」ではなく、「自分は東京に行くのか、地元の拠点なのか、どちらでもないのか」で、東京の学生が確かめているのは「地方に配属されるのか」です。「東京本社・全国に拠点」の一文は、どちらの学生にも「自分がどこに行くか分からない」と読まれます。当社が全国採用の文面を作るときは、初任地の決まり方を一文で書き、転勤の有無を職種ごとに書き、書けないことは「面談で伝えます」と添えます。承認の数は減りますが、承認した学生は「初任地と転勤を知ったうえで来た」学生で、面談で「聞いていない」で離れません。

## 文面の書き方｜「東京本社」ではなく「初任地」と「誰と」

| 書かない | 書く |
|---|---|
| 「東京本社、全国に拠点」 | 「初任地は〇〇の時点で、本人の希望と拠点の状況で決まります」 |
| 「全国転勤あり」の一言 | 「転勤は△△の職種であり、□□の職種はありません。頻度は面談で伝えます」 |
| 本社の人事の名義 | その地域の拠点の社員の名義。「〇〇拠点の△△です」 |
| 「全国で活躍」 | その拠点で、最初の年に何をするか。誰と組むか |
| 「東京で働けます」を地方の学生に一律に | 記述から読んだ希望に合わせて。地元、東京、Uターンのどれか |

- **学生の希望を、記述から読む**：「地元で働きたい」「東京に出たい」「いずれ戻りたい」は記述に書かれていることが多い。読まずに送らない
- **書けない転勤の頻度や条件は、書かない**：「面談で伝えます」と添え、面談で隠さず話す
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)。条件は採用サイトと揃える。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 地域ごとの運用

- **地域ごとに、名義と面談の枠を持つ**：拠点の社員が月に会える数が、その地域に送れる数の上限
- **本社の人事が、検索・下書き・送信・一次返信を全地域分まとめて持つ**：拠点の社員は名義・確認・面談だけ。外に出すなら、この部分。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **承認への当日返信は、本社で一本化する**：拠点ごとに返信の担当を置くと、ばらつく。返信は本社、面談は拠点
- **文面の共通部分（初任地の決まり方、転勤、会社の「なぜ」）は一つの原稿で、拠点ごとの部分（誰と、何を）だけ変える**：原稿を一つで版管理する
- **チームで回す分担**：[OfferBoxをチームで運用するときの役割分担](/media/ob-team-unyou/)

## 地域別の承認率を、全体に混ぜない

- **承認率は、地域ごとに見る**：全国を一つにすると、承認が取れている地域と取れていない地域が見えない
- **取れていない地域は、名義・文面・初任地の書き方のどれかを見る**：「地方は承認が低い」ではなく、その地域の学生に送っている文面と名義を見る。[OfferBoxの承認率が低いときに疑う3つの原因](/media/ob-shounin-hikui/)
- **面談まで来た「近い」学生の数を、地域ごとに**：承認が多い地域より、近い学生が面談まで来ている地域に、翌年の枠を寄せる
- **週に一度、地域ごとの承認から面談までの日数を見る**：[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)
- **来た学生の台帳に、地域と希望の列を持つ**：初任地の希望と、決まった初任地のずれを見る。[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 初任地の決まり方と転勤の有無を、書ける形に整理する | 本社の人事と経営 |
| 地域ごとの「こんな人」と、名義の社員の選定 | 本社の人事と拠点の責任者 |
| 検索、記述から希望を読む、文面の下書き、送信、一次返信 | 本社の人事、または代行 |
| 文面の最終確認、名義、面談（オンライン） | 拠点の社員 |
| 文面の共通原稿の版管理 | 本社の人事 |
| 地域ごとの承認率と面談までの日数を見る | 本社の人事 |
| 初任地の決定と、本人への説明 | 本社の人事と拠点の責任者 |
| 移動の負担を会社が持つ範囲の判断 | 経営 |

- **拠点の社員に頼むのは、名義・確認・面談の三つ**：本社が全部を持つと、地域の名義がなくなる。拠点が全部を持つと、返信がばらつく
- **拠点の社員が協力しないときは、頼む範囲が広すぎることが多い**：[現場がOfferBoxの面談に協力してくれないとき](/media/ob-genba-hikyouryoku/)

運用代行や代理店が支えられるのは、初任地と転勤を書ける形にする型、地域ごとの検索と文面の型、原稿の版管理の型、検索・希望の読み取り・下書き・送信・一次返信、地域別の数字の整理までで、初任地と転勤の方針、名義の社員の選定、面談、初任地の決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

全国の承認率は、「地域ごとに違う名義と文面で送った結果の合計」を示す数字で、どこを直せばよいかを示す数字ではありません。当社はOfferBoxの運用代行を受けているので、全国採用の会社の地域ごとの数字を見ていますが、全体の承認率だけを見て「今年は低い」と言う会社の数字を地域で分けると、本社の名義で送った地域だけが低く、拠点の社員の名義で送った地域は保てている、という形が多くあります。全体で見ると「文面を直す」になりますが、地域で分けると「その地域に拠点の名義を置く」になり、直すものが変わります。当社が全国採用の会社に週の報告を出すときは、全体の数字を出さず、地域ごとの承認率と、承認から面談までの日数と、近い学生の数を並べています。この並べ方にすると、翌年に枠を寄せる地域と、名義を足す地域が、数字から決まります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「東京本社・全国に拠点」の一文で送る | 学生が「自分はどこに行くか」を確かめられない | 初任地の決まり方と転勤を書く |
| 本社の人事の名義で全国に送る | 「その拠点で誰と働くか」が見えない | 地域ごとに拠点の社員を名義に |
| 学生の希望を読まずに送る | 地元志望の学生に「東京で働けます」が届く | 記述から希望を読み、検索を分ける |
| 面談を本社で行う | 地方の学生の移動の負担で、面談の前に離れる | オンラインを基本に |
| 承認率を全国で一つで見る | 直す地域が分からない | 地域ごとに見る |

最も多いのは、一つ目です。「東京本社」が学生にとって魅力だと考え、学生が確かめている「初任地」が文面にありません。

## まとめ

- 学生は「東京本社」より「初任地と転勤」を確かめる。地方の学生は「東京か地元か」、東京の学生は「地方に配属か」
- 最初に、初任地の決まり方と転勤の有無を書ける形に整理し、文面に隠さず書く。書けないことは「面談で伝えます」と添える
- 地域ごとに拠点の社員を名義にし、頼むのは名義・確認・面談の三つ。検索・下書き・送信・一次返信は本社か代行で一本化
- 学生の出身地域と希望（地元・東京・Uターン）を記述から読み、検索と文面を分ける。面談はオンラインを基本に
- 承認率を全国で一つにせず、地域ごとに承認率・面談までの日数・近い学生の数を見て、翌年の枠と名義を決める

## よくある質問

### 初任地が入社の直前まで決まりません。文面にどう書きますか

「初任地は〇〇の時点で、本人の希望と拠点の状況を見て決まります。希望は面談で聞きます」と、決まり方と時期を書きます。「全国どこでも」の一言は、学生には「希望を聞いてもらえない」と読まれます。決まり方が書けない場合は、書ける形に整理することが、送る前の仕事です。

### 拠点の社員が少なく、地域ごとに名義を置けません

置ける地域から始めます。名義を置けない地域には、その地域に近い拠点の社員の名義で、「〇〇拠点の△△です。□□の地域は私が担当しています」と書きます。本社の人事の名義で全国に送るより、近い拠点の名義のほうが、学生は「誰と働くか」を想像できます。

### 東京本社で全国採用する会社のOfferBox運用は、御社に相談できますか

できます。当社は、初任地と転勤を書ける形にする型、地域ごとの検索と文面の型、原稿の版管理の型、検索・希望の読み取り・下書き・送信・一次返信、地域別の数字の整理を支えられます。初任地と転勤の方針、名義の社員の選定、面談、初任地の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
