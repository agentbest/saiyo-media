ワンキャリアの掲載は、一度書いたら終わりではありません。ところが「いつ見直すか」を決めていない会社では、気づいた人が気づいたときに直すか、一年近く手つかずになるかのどちらかに偏りがちです。**結論から言うと、掲載内容の見直しは「起点が来たとき」と「年度の切れ目」の二つに絞り、それ以外の時期は気づいたことを溜めておくのが基本です。** この記事では、見直す起点の見分け方、見直さないほうがよい時期、見直すときの手順、やりがちな失敗、社内の分担を整理します。更新の頻度そのものの考え方は[掲載内容の更新頻度](/media/oc-keisai-koushin-hindo/)で書きました。

## この作業の目的｜学生が読んだ内容と、実際の選考を揃え続ける

ワンキャリアでは、学生は会社の掲載と、ほかの学生が書いた選考体験談やクチコミを並べて読みます。掲載に書いてある流れと、体験談に書かれている流れが違うと、学生はどちらを信じればよいか迷います。

見直しの目的は、文章を良くすることではありません。**学生が読んだ内容と、実際に起きる選考・説明会・面接の中身を揃え続けること**です。揃っていれば、学生は準備して来ます。ずれていれば、選考の途中で「聞いていた話と違う」と感じ、体験談にもそう書かれます。

だから、見直すタイミングは「掲載と実際がずれそうなとき」に合わせます。カレンダーの日付で決めるより、社内で何かが変わったときを起点にするほうが、ずれを小さくできます。

## 見直す起点は五つ

| 起点 | 何が起きているか | 見直す箇所 |
|---|---|---|
| 選考の流れが変わった | 面接の回数、順番、課題の有無が社内で決まった | 本選考の掲載、企業ページの選考の流れ |
| 募集する職種やコースが変わった | 職種の追加、コースの統合、勤務地の変更 | 募集の分け方、仕事の具体、条件の書き方 |
| 体験談やクチコミに「掲載と違った」が出た | 学生の側から、ずれが指摘された | 指摘された箇所と、そのつながりの箇所 |
| 説明会やイベントの予定が変わった | 回の追加・中止、内容の変更 | 誘導の先、予告している内容 |
| 段の数字が細った | 閲覧からエントリー、エントリーから説明会など、ある段だけが前年の同時期より細い | その段の手前で学生が読む箇所 |

五つのうち、上の四つは「社内で決まったこと」か「学生から指摘されたこと」で、起きたと分かりやすい起点です。最後の「段の数字が細った」は、週ごとの動きに反応すると見直しすぎになります。前年の同じ時期と比べて、はっきり細いときだけ起点として扱います。段の見方は[掲載のKPI設計](/media/oc-keisai-kpi/)で整理しています。

年度の切れ目は、五つの起点とは別の、決まった見直しの時期です。一年分の体験談とクチコミ、溜めた気づき、段の数字をまとめて見て、掲載の骨組みから見直します。

### エージェントベストの見解

掲載を見直す前に、先に分けておくべきことがあります。気づいたことを「掲載で直すもの」と「運用で直すもの」に分ける作業です。たとえば体験談に「連絡が遅かった」と書かれたとき、掲載に「結果は〇日以内に連絡します」と書き足しても、連絡の速さが変わらなければ、ずれが一つ増えるだけです。これは運用で直すものです。逆に「面接で何を見ているのか分からなかった」は、掲載で各段階の目的を書けば補えます。申込後の運用まで見ていると、掲載を何度も書き換えているのに体験談の指摘が減らない会社は、この二つを分けずに全部を掲載で直そうとしていることが多いと感じます。見直しの一覧を作るときに、項目ごとに「掲載」「運用」の列を一つ足すだけで、直す人と直す時期がはっきりします。

## 見直さないほうがよい時期

起点が来ても、少し待ったほうがよい時期があります。

- **選考の山の最中**：エントリーや面接が集中している時期に掲載を大きく変えると、同じ時期に応募した学生どうしで読んだ内容が違ってしまいます。誤りの訂正だけにとどめ、中身の見直しは山を越えてからにします
- **担当者が交代した直後**：新しい担当者が、前の掲載がなぜその書き方なのかを知らないまま直すと、体験談とのつながりが切れます。まず前の記録を読み、一巡りしてから見直します
- **数字が一週だけ動いたとき**：新卒の数字は時期で大きく動きます。一週の動きは起点にしません

待つあいだに気づいたことは、捨てずに一覧に溜めておきます。山を越えたときや年度の切れ目に、まとめて見直す材料になります。

## 見直すときの手順

1. **溜めた気づきの一覧を出す**：週ごとの確認で書き留めたこと、体験談やクチコミの要点、面接官からの声を一か所に集めます
2. **起点と結びつける**：一つずつ、どの起点に当たるかを書きます。どの起点にも当たらないものは、年度の切れ目に回します
3. **掲載と運用に分ける**：掲載を直せば補えるものと、運用を変えないと直らないものを分けます
4. **体験談と照らす**：直そうとする箇所が、すでに書かれている体験談とどうつながるかを確かめます。体験談を否定する書き方にはしません
5. **直す箇所を決めて書き換える**：一文だけを直すと前後とずれることがあるので、その箇所を含む段落ごと読み直します
6. **面接官と説明会の担当に伝える**：掲載に書いたことを、実際に学生と話す人が知っている状態にします
7. **記録する**：いつ、どの起点で、何を直したかを一行で残します

手順の中で抜けやすいのは、6の「伝える」です。掲載だけが新しくなり、面接官が前のままの説明をすると、ずれは掲載と実際のあいだに移るだけです。週ごとに何を見るかは[掲載を週次で見直す方法](/media/oc-keisai-review/)、月ごとの見方は[ワンキャリア運用の月次の振り返り](/media/oc-sd-tsukiji-review/)で書いています。

## やりがちな失敗

| 失敗 | 起きること | 避け方 |
|---|---|---|
| 気づくたびにその場で直す | 学生が読む時期によって中身が違い、体験談と揃わない | 一覧に溜め、起点か年度で直す |
| 一文だけを直す | 前後の段落と言っていることがずれる | 段落ごと読み直す |
| 体験談の指摘に反論するように書く | 学生に「言い訳をしている会社」と読まれる | 事実だけを淡々と書く |
| 数字の一時的な動きで直す | 直した効果が分からなくなる | 前年の同時期と比べて判断する |
| 直したことを記録しない | 翌年、なぜその書き方なのか誰も分からない | いつ・何を・なぜを一行で残す |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 気づきを一覧に溜める | 人事（面接官や説明会の担当からも集める） |
| 起点が来たかを判断する | 人事 |
| 選考の流れや職種の変更を人事に知らせる | 変更を決めた会議の出席者 |
| 掲載の書き換え | 人事。仕事の具体は現場に確かめる |
| 面接官・説明会の担当への共有 | 人事 |
| 年度の切れ目の見直しの合意 | 人事と上司 |

外部の運用支援が受け持ちやすいのは、一覧の型、起点の判断の手伝い、書き換えの下書きまでです。仕事の中身の事実確認と、社内への共有は会社の側で行います。

### エージェントベストの見解

申し込んで最初の年度に起きやすいのは、掲載を作った人と、見直す人が違ってしまうことです。最初の掲載は、立ち上げのときに人事の責任者や外部の支援者が力を入れて作ります。ところが見直しの時期には、日々の運用を担う別の担当者に任されていて、その人は「なぜこの書き方なのか」を知りません。結果として、見直しが「よく分からないから触らない」か「全部書き直す」のどちらかに振れます。避けるには、最初の掲載を作るときに、段落ごとに「この段落は何のためにあるか」を一行ずつ残しておくことです。見直す人はその一行を読み、目的が今も同じなら言い回しだけを直し、目的が変わったなら段落ごと書き換えます。これだけで、見直しが作った人の頭の中に頼らなくなります。

## まとめ

- 掲載内容の見直しは、起点が来たときと年度の切れ目の二つに絞る
- 起点は、選考の流れ・募集の変更、体験談での指摘、イベントの予定の変更、段の数字の細り
- 選考の山の最中、担当交代の直後、数字が一週だけ動いたときは、中身の見直しを待つ
- 気づきは「掲載で直すもの」と「運用で直すもの」に分けてから手をつける
- 直したら面接官と説明会の担当に伝え、いつ・何を・なぜを一行で記録する

## よくある質問

### 年度の切れ目とは、いつのことですか

会社によって異なります。多くの会社では、ある卒年の選考が一段落し、次の卒年の募集を出す準備に入る時期を切れ目にしています。卒年の切り替えの考え方は[ワンキャリアの運用を次の卒年に引き継ぐ](/media/oc-sd-sotsunen-hikitsugi/)で整理しています。

### 誤字や終わったイベントへの誘導も、起点まで待つのですか

待ちません。誤記や、閉じた募集・終わったイベントへの誘導は、気づいたその週に直します。待つのは掲載の中身、つまり仕事の書き方や選考の説明、条件の書き方です。

### 上司から「掲載を直せ」と言われたら、どうすればよいですか

どの起点に当たるかを一緒に確かめます。起点に当たるなら直し、当たらないなら一覧に溜めて年度の切れ目で見直すと伝えます。あらかじめ「掲載は起点と年度で直す」と上司と合意しておくと、話が早く進みます。
