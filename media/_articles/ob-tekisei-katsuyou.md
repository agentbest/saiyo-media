OfferBoxの学生プロフィールには、適性検査の結果が表示されます。「これを使えば、面接の前に合う学生を見分けられるのではないか」という期待を、採用担当者からよく聞きます。**結論から言うと、適性検査の結果は、合否の基準や検索の絞り込みに使うものではなく、自由記述と照らして「面接で確かめる仮説」を持つためのものです。** 基準にすると、対象が急に減り、自由記述を読まなくなり、面接官が結果に引きずられます。この記事では、適性検査の結果の位置づけと、選考の各段階での使い方、やりがちな失敗、人事と面接官の分担を整理します。検査の仕様、項目、数値には触れず、使い方の考え方だけを書きます。プロフィールの読む順番は[OfferBoxの学生プロフィールの読み方](/media/ob-profile-yomikata/)で書きました。

## この作業の目的｜面接の質を上げる

適性検査の結果を使う目的は、「面接の前に切る」ことではなく、「面接で何を確かめるかを決める」ことです。

面接は時間が限られています。学生の何を確かめるかが決まっていないと、面接官は雑談で終わるか、自分の印象で判断します。適性検査の結果と自由記述を照らして、「この学生は、ここを確かめたい」という仮説を持って面接に入ると、限られた時間で見るべきところが見られます。

つまり、適性検査の結果は「面接の設計図」の材料であって、「面接に呼ぶかどうかの判定」の材料ではありません。

## 段階1｜検索では使わない

検索条件で適性検査の結果を絞ると、対象が急に減ります。理由は、検査の傾向は「譲れない条件」ではなく「あれば嬉しい条件」だからです。

- 譲れない条件は、無ければ選考に進めないもの（卒年、勤務地、必要な学部や資格）
- 適性検査の傾向は、あっても無くても選考には進める。傾向が違う学生が活躍することも珍しくない

検索で絞る条件の考え方は[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)で書きました。適性検査の傾向で絞ると、自由記述を読む前に、傾向が違うというだけで切ることになります。読めば会いたい学生を、読む前に落とします。

例外があるとすれば、読む対象が読む時間を大きく超えていて、何かで優先順位をつける必要があるときです。その場合も、「絞る」のではなく「読む順番の参考にする」にとどめます。

## 段階2｜読むときは最後に、自由記述と照らす

プロフィールを読むときは、適性検査の結果を最後に見ます。先に自由記述を読み、学生が自分で書いた行動と志向を把握してから、検査の傾向と照らします。

| 自由記述と検査の関係 | どう読むか |
|---|---|
| 自由記述の行動と、検査の傾向が合っている | その行動は本人の型に近い。面接では別の面を確かめる |
| 自由記述の行動と、検査の傾向が合っていない | 面接で「その行動は、どういう状況でしたか」と確かめる仮説になる |
| 自由記述が薄く、検査の傾向だけがある | 傾向だけで判断しない。文面で触れる材料が無いので、送る優先度は下がる |

「合っていない」は、悪いことではありません。自己認識と行動が違う学生は珍しくなく、面接で聞くと「そのときは無理をしていた」「実は得意ではないが、やらざるを得なかった」のような話が出ます。それが分かるのは、仮説を持って聞いたときだけです。

### エージェントベストの見解

相談で最も多い思い込みは、「適性検査の結果で絞れば、面接で失敗しない」というものです。実際には、検査の結果は学生が答えた時点の傾向であって、その学生が自社で活躍するかどうかを決めるものではありません。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、「検査の傾向が自社の活躍社員と違う」という理由で送らなかった学生像を、あとになって「そういう学生こそ採りたかった」と言い直す会社があります。活躍社員の傾向は、いま活躍している数人から見えたものにすぎず、別の傾向の人が活躍しないという証拠ではありません。検査の結果は、切るためではなく、面接で聞くことを決めるために使う。この位置づけを面接官と共有しておくと、面接官が結果を見て「この学生は違う」と決めてしまうことも防げます。

## 段階3｜文面では触れない

オファー文面で、適性検査の結果に触れることは勧めません。

- 学生は、自分の検査結果を企業がどう見ているかを気にしている。結果に触れられると、評価されている感覚が先に立つ
- 文面で触れるべきは、学生が自分の言葉で書いた自由記述の一文。そこに触れると「読んでくれた」と伝わる
- 検査結果は企業側の内部の材料。学生に向けた文面の材料ではない

文面の書き方は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)で書きます。触れるのは自由記述、検査は社内で使う。この分け方を守ります。

## 段階4｜面接では仮説を確かめる

面接の前に、人事が「この学生について、確かめたいこと」を面接官に渡します。適性検査の結果と自由記述を照らして立てた仮説です。

1. **仮説を1つか2つに絞る**：多すぎると面接官が消化できない
2. **仮説を質問の形にする**：「自由記述にある〇〇の経験について、どんな状況で、自分はどう動いたか」のように
3. **検査の結果そのものは面接官に渡さない、または参考として渡す**：結果を渡すと、面接官が結果で判断する。仮説だけを渡すほうが、面接官は学生の話を聞く
4. **面接後に、仮説がどうだったかを戻してもらう**：「合っていた」「違った」「別のことが分かった」

4の「戻す」が、次の面接の設計と、ペルソナの見直しの材料になります。戻ってこないと、仮説を立てる意味が薄れます。

## 段階5｜活躍社員の傾向と照らすときの注意

「自社で活躍している社員の検査の傾向と、学生の傾向を照らす」という使い方があります。これは参考にはなりますが、注意が要ります。

- **活躍社員が少人数なら、傾向は偶然かもしれない**：数人の共通点は、その数人の個性である可能性がある
- **傾向が違う人が活躍しないという証拠にはならない**：活躍している人の傾向は分かっても、活躍していない人の傾向は分からない
- **職種や配属で傾向は変わる**：営業と技術で同じ傾向を求めない
- **傾向は「面接で確かめる仮説」の材料にとどめる**：「活躍社員はこういう傾向だから、この学生も確かめてみよう」まで。「違うから送らない」にしない

ペルソナの作り方で書いた「活躍している若手からの逆算」は、行動と志向を言葉にするためのもので、検査の傾向で絞るためのものではありません。[採りたい学生像を言葉にする](/media/ob-persona/)で書いたとおり、検索で絞れるのは条件だけです。

## やりがちな失敗

| 失敗 | 何が起きるか | 防ぎ方 |
|---|---|---|
| 検索で検査の傾向で絞る | 対象が急に減り、読めば会いたい学生を切る | 譲れない条件だけで絞る。傾向は読む順番の参考まで |
| プロフィールを検査の結果から読む | 結果で切り、自由記述を読まない | 自由記述を先に、検査は最後に |
| 文面で検査の結果に触れる | 学生に評価されている感覚が先に立つ | 文面で触れるのは自由記述の一文 |
| 面接官に結果をそのまま渡す | 面接官が結果で判断し、話を聞かない | 仮説を質問の形で渡す |
| 活躍社員の傾向で切る | 別の傾向の学生を採らない。根拠は数人の共通点 | 仮説の材料にとどめる |
| 面接の結果を戻さない | 仮説が検証されず、次に活きない | 面接後に「合っていた・違った」を戻す |

最も多いのは、「面接官に結果をそのまま渡す」です。渡すと、面接官は結果を見てから学生の話を聞き、結果に沿った印象を持ちます。仮説だけを渡すと、話を聞いてから判断します。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 検査の結果を自由記述と照らし、仮説を立てる | 人事 |
| 仮説を質問の形にして面接官に渡す | 人事 |
| 面接で仮説を確かめる | 面接官 |
| 面接の結果を戻す | 面接官 |
| 活躍社員の傾向を参考として整理する | 人事（現場に聞きながら） |
| 適性検査の位置づけを面接官と揃える | 人事 |

最後の「位置づけを揃える」が、最初にやることです。面接官ごとに「検査は重い」「検査は見ない」と分かれていると、評価が割れます。「検査は仮説の材料で、合否の基準ではない」を、面接の前に面接官と合意します。

### エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。「適性検査の結果を、面接官にどの形で渡すか」を決めることです。当社がOfferBoxの運用の相談を受けるとき、面接で評価が割れる会社の多くは、面接官が検査の結果を直接見ていて、面接官ごとに結果の読み方が違います。ある面接官は結果を重く見て、別の面接官は見ない。同じ学生の評価が割れるのは当然です。当社が勧めるのは、人事が結果と自由記述を照らして仮説を1つか2つ立て、それを質問の形で面接官に渡し、結果そのものは渡さないか参考にとどめる形です。面接官は学生の話を聞いて判断し、人事は面接の結果と仮説を照らして次に活かす。この分担にすると、検査の結果が「面接の質を上げる材料」として働きます。渡し方を決めずに結果を共有すると、検査が「面接官が学生を見る前に決めてしまう材料」になります。

## まとめ

- 適性検査の結果は、合否の基準や検索の絞り込みではなく、面接で確かめる仮説の材料
- 検索では使わず、読むときは最後に自由記述と照らし、文面では触れない
- 面接官には結果そのものではなく、仮説を質問の形で渡す。面接後に結果を戻してもらう
- 活躍社員の傾向は参考まで。少人数の共通点で切らない
- 「検査は仮説の材料で、合否の基準ではない」を面接の前に面接官と合意する

## よくある質問

### 適性検査の結果が自社の活躍社員と違う学生には、送らないほうがよいですか

送る候補から外す理由にはなりません。活躍社員の傾向は、いま活躍している数人から見えたもので、別の傾向の人が活躍しないという証拠ではありません。自由記述に触れる材料があれば送り、面接で「この傾向の違いをどう確かめるか」を仮説にします。

### 面接官が「検査の結果を見せてほしい」と言います。渡すべきですか

渡すなら、結果そのものより、人事が立てた仮説を質問の形にして渡すことを勧めます。結果を直接見ると、面接官は結果を見てから学生の話を聞き、結果に沿った印象を持ちやすくなります。どうしても渡す場合は、「仮説の材料であって基準ではない」と添えます。

### 適性検査の結果の読み方は、御社に相談できますか

検査の仕様や項目の解釈は、媒体の資料と案内で確認してください。当社がお手伝いできるのは、結果を選考のどこでどう位置づけるか、面接官にどう渡すか、という運用の設計です。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
