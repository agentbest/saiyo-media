Wantedlyのストーリーを公開したらSNSでも知らせる。そう決めている会社は多いのですが、続けているうちに「公開した日に一回流して終わり」「SNSの担当とWantedlyの担当が別で、投稿が漏れる」という状態になりがちです。一回流すだけでは、その日にSNSを見ていなかった人には届きません。**結論から言うと、SNSとWantedlyの連携は、記事の公開とSNSの投稿を同じ予定表で持ち、一本の記事から時期をずらして複数の投稿を切り出す運用にすると続きます。** 本人が一言添えて広げる考え方は[Wantedlyの記事をSNSで広げる方法](/media/wt-sns-kakusan/)で書きました。この記事では、それを毎月回すための予定と手順を整理します。

## この作業の目的｜一本の記事を、何度か届ける

Wantedlyの記事は、書くまでに時間がかかります。社員に話を聞き、書き、確認を通して公開する。それだけの手間をかけた記事を、SNSで一度だけ知らせて終わるのは、もったいない使い方です。

SNSとの連携で目指すのは、次の二つです。

- **時期をずらして届ける**：公開の日だけでなく、別の切り口で数回知らせる
- **反応を記事に戻す**：SNSで反応があった話題を、次の記事の材料にする

この二つは、投稿を思いつきで出していると回りません。予定表に載せて、誰がいつ出すかを決めておく必要があります。

## 手順1｜記事と投稿を同じ予定表に載せる

Wantedlyの記事の予定表に、SNSの投稿の列を足します。別の表にすると、片方だけが更新されて、ずれが生まれます。

| 列 | 書くこと |
|---|---|
| 記事 | ストーリーの題名、公開日 |
| 投稿の切り口 | どの一文、どの場面を使うか |
| 投稿する人 | 会社の公式か、記事に出た本人か、書いた人か |
| 投稿の時期 | 公開の日、少しあと、募集を更新したとき、など |
| 反応のメモ | 面談で触れた人がいたか、問い合わせがあったか |

投稿の時期は、日付で決めすぎないほうが続きます。「公開の日」「同じ募集をもう一度目立たせたいとき」「関係する発表があったとき」のように、きっかけで書いておくと、予定がずれても使えます。

## 手順2｜一本の記事から切り出す

一本のストーリーの中には、SNSで使える場面がいくつもあります。公開の前に、切り出す候補を書き出しておきます。

1. **記事の中心の場面**：記事でいちばん伝えたいこと。公開の日に使う
2. **本人の一言**：記事の中で、本人が話した印象的な言葉。本人の投稿で使う
3. **仕事の具体**：使っている道具、会議の進め方など、職種の人が気になる部分
4. **うまくいかなかったこと**：迷ったことや失敗の場面。共感が集まりやすい

切り出した一文は、記事の文章をそのまま使うより、SNSで読まれる短さに言い直します。ただし、記事に書いていないことを足さないようにします。SNSの投稿を見て記事を開いた人が、書いてあることの違いに戸惑わないためです。

### エージェントベストの見解

SNSとの連携の相談で先に確かめるのは、「会社の公式アカウントに、候補者になりうる人がいるか」です。公式アカウントの読者が顧客や取引先中心の会社では、採用の記事を公式で流しても、候補者には届きにくい傾向があります。この場合、投稿の主役は記事に出た本人や、その職種の社員の個人アカウントに置き、公式は「まとめて知らせる場所」として使うほうが届きます。逆に、公式に社員や業界の人の読者が多い会社なら、公式を中心にして構いません。どちらで流すかは、SNSの種類で決めるより先に、いまの読者が誰かで決める。この順番で考えると、投稿の担当も自然に決まります。

## 手順3｜公式と個人の役割を分ける

公式アカウントと個人のアカウントでは、できることが違います。役割を分けて予定表に書きます。

- **公式アカウント**：公開の知らせ、記事のまとめ、募集の更新の知らせ。会社としての言葉で出す
- **記事に出た本人**：自分の言葉で一言添えて共有する。出すかどうかは本人が決める
- **書いた人・人事**：記事ができた経緯や、聞いていて印象に残ったことを出す

個人のアカウントでの投稿は、頼むことはできても、強いることはできません。出すかどうか、いつ出すかは本人に任せ、出しやすいように切り出した一文の案を渡しておくところまでを運用にします。社員に応援を頼むときの考え方は[Wantedlyの応援機能の使い方](/media/wt-ouen/)が参考になります。

## 手順4｜反応を記事の材料に戻す

SNSで反応があった話題は、候補者が関心を持つ話題の手がかりになります。反応を予定表のメモ欄に残し、月に一度見返します。

- 反応が集まった切り口は、同じ職種の別の社員の記事で深める
- 反応が少なかった切り口は、記事の中身ではなく、投稿の言い方や時期を見直す
- 面談で「SNSで見て」と言った候補者がいたら、どの投稿だったかを聞いて残す

SNSの数字だけで記事の良し悪しを決めないようにします。SNSで反応が少なくても、Wantedlyの中で読まれて面談につながっている記事はあります。反応の記録は[Wantedly運用の数字の記録の残し方](/media/wt-sd-kouka-kiroku/)と同じ置き場所にまとめると、見比べやすくなります。

### エージェントベストの見解

SNSとの連携を始めた会社で、数か月後に止まる理由として多いのは、投稿の担当が「手が空いた人」になっていることです。最初は熱心な社員が流してくれますが、その人が忙しくなると投稿が途切れ、記事の公開も知らされなくなります。当社が運用の見直しで勧めるのは、公開の日の公式投稿だけは人事の作業として固定し、それ以外の投稿を「あれば足す」扱いにすることです。最低限の一回が残っていれば、連携は止まりません。そのうえで、本人や社員の投稿が出たときに、人事がそれを公式で紹介する形にすると、個人に負担を寄せすぎずに届く範囲を広げられます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 公開の日に一回だけ流す | その日に見ていない人に届かない | 切り口を変えて時期をずらす |
| 記事にないことを投稿に足す | 記事を開いた人が戸惑う | 記事の中から切り出す |
| 社員に投稿を強いる | 協力が続かなくなる | 一文の案を渡し、判断は本人に任せる |
| SNSの数字で記事を判断する | 面談につながる記事を見落とす | 面談での言葉と並べて見る |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 予定表に投稿の列を足す | 人事 |
| 切り出す候補を書き出す | 記事を書く人 |
| 公開の日の公式投稿 | 人事、または公式アカウントの担当 |
| 個人での共有 | 本人（任意） |
| 反応を残し、月に一度見返す | 人事 |

## まとめ

- 記事の公開とSNSの投稿を同じ予定表で持ち、ずれを防ぐ
- 一本の記事から、中心の場面・本人の一言・仕事の具体・迷った場面を切り出す
- 公式は知らせる場所、本人は自分の言葉で添える場所として役割を分ける
- 公開の日の公式投稿だけは作業として固定し、それ以外は「あれば足す」にする
- 反応は面談での言葉と並べて見て、次の記事の材料に戻す

## よくある質問

### どのSNSを使えばよいですか

読ませたい候補者がいる場所で決めます。職種によって集まる場所が違うため、まずはいまの社員が普段使っているSNSを聞くと手がかりになります。使うSNSを増やしすぎると予定表が回らなくなるので、最初は一つか二つに絞ります。

### 記事の公開から、どのくらい間を空けて再び投稿すればよいですか

決まった間隔はありません。日付より、募集を更新したときや関係する発表があったときなど、きっかけで決めるほうが続きます。同じ記事を続けて何度も流すと、読者に飽きられやすくなります。

### SNSとの連携の仕組みづくりを相談できますか

できます。当社は採用媒体の代理店として、予定表の型、切り出しの考え方、反応の残し方の設計を支えています。投稿の中身と公開の判断は企業と本人が行ってください。
