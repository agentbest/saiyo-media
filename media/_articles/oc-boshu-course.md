ワンキャリアで募集を掲載するとき、「総合職」として一つにまとめるか、職種や地域でコースに分けるか、という判断があります。一つにまとめると、学生は「自分はどの仕事をするのか」が分からず、分けすぎると、各コースの中身が薄くなります。**結論から言うと、募集コースは、「仕事の中身」「最初の1年」「選考の流れ」「勤務地」のいずれかが違うなら分け、違わないなら分けません。分けた各コースには、仕事の具体と最初の1年、こんな人、選考の流れ、配属の決まり方を書きます。ワンキャリアの学生は体験談で「どのコースの選考か」を読んでから見るので、コースの分け方が体験談と揃っていることが前提です。「総合職」で一つにまとめる、分けすぎて薄い、コース名だけで中身が無い、コース間で選考の流れが混ざる、が学生の迷う形です。** この記事では、コースを分ける目的、分ける軸、やりがちな失敗、各コースに書くこと、職種未定コースの書き方、増やす・減らす判断、分担を整理します。設定できる区分の種類や名称は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。本選考の掲載の書き方は[本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

## この作業の目的｜学生が「自分はどれか」を選べて、選んだ先の中身が分かる状態にする

学生は、体験談を読むときに「〇〇コースの一次面接では」「△△職の選考は」と、コースの単位で読んでいます。掲載のコースが体験談と違う単位だと、「自分が受けるのはどれか」が分かりません。

コースを分ける目的は、「学生が自分はどれかを選べて、選んだコースの仕事の具体・最初の1年・選考の流れが分かる」ことです。分けること自体が目的ではなく、選べて、中身が分かることが目的です。

## 分ける軸

| 軸 | 違うなら分ける | 違わないなら分けない |
|---|---|---|
| 仕事の中身 | 営業と開発のように、やることが違う | 同じ職種で、担当する商材が違うだけ |
| 最初の1年 | 最初の月に何をするかが違う | 同じ研修、同じ配属の流れ |
| 選考の流れ | 段階や面接官や何を見るかが違う | 同じ流れで、配属だけあとで決まる |
| 勤務地 | 地域で募集が分かれ、転勤の有無が違う | 全国で同じ扱い |
| 雇用の形 | 正社員と、それ以外 | 同じ |

「一つでも違えば分ける」が原則です。特に、選考の流れが違うのに一つにまとめると、体験談で「同じコースなのに流れが違った」と書かれ、学生が混乱します。

## やりがちな失敗

| 失敗 | 学生からどう見えるか |
|---|---|
| 「総合職」で一つにまとめる | 自分が何をするか分からない。体験談の「〇〇職の選考」と結びつかない |
| 分けすぎて、各コースの中身が薄い | どのコースも「詳しくは説明会で」。選べない |
| コース名だけで、中身が無い | 「営業コース」「技術コース」の名前だけ。最初の1年が無い |
| コース間で、選考の流れが混ざって書かれている | 「自分のコースはどの流れか」で迷う |
| 配属の決まり方が書いていない | 「コースを選んでも、配属は別なのでは」と疑う |
| 体験談のコースの呼び方と、掲載のコース名が違う | 結びつかない |
| コースごとの「こんな人」が全部同じ | 分けた意味が無い |

最も多いのは、最初の「総合職で一つ」です。社内では「入ってから決める」が自然でも、学生からは「何をするか分からない募集」に見えます。

### エージェントベストの見解

相談で最も多い思い込みは、「コースを分けると応募が分散するので、一つにまとめたほうが母集団が大きくなる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を支えていますが、一つにまとめた募集は、学生が「自分はどれか」を判断できず、体験談の「〇〇職の選考」とも結びつかないので、応募は分散しないのではなく、そもそも来ません。分けた募集は、各コースの応募は少なくても、来る学生は「このコースの最初の1年」を読んで来ているので、選考で話が具体になります。当社がコースの相談を受けるとき、最初にやるのは、「最初の1年が違う仕事が、社内にいくつあるか」を数えることです。その数が、コースの数の目安です。母集団の大きさより、学生が選べることが先です。

## 各コースに書くこと

| 書くこと | 中身 |
|---|---|
| 仕事の具体と最初の1年 | そのコースで、最初の月・最初の3か月・1年目の終わりに何をしているか。書き方は[新卒向け募集記事の書き方](/media/wt-boshu-shinsotsu/)と同じ |
| こんな人 | そのコースに来てほしい人。学生時代の状態で。コースごとに違う言葉で |
| 選考の流れと、各段階で何を見るか | そのコースの流れ。他のコースと同じなら「〇〇コースと同じ」と書く |
| 配属の決まり方 | コースを選んだら、配属はどう決まるか。「コースの中で、面談で決める」「入社後の研修を経て決める」など、事実で |
| 勤務地と転勤 | そのコースの勤務地、転勤の有無。自社の制度に沿って |
| 働く人の話 | そのコースの入社してまもない社員。企業トップページの「働く人」から誘導 |
| 他のコースとの違い | 「△△コースと迷う方へ」と、違いを一文で |

「他のコースとの違い」を書くと、学生は迷わず選べます。「営業コースと企画コースの違いは、最初の1年に顧客と直接話すかどうかです」のように。

## 職種未定コースの書き方

「入社してから決める」形のコースも、書き方次第で、学生が選べるものになります。

- **「未定」ではなく、「決め方」を書く**：「最初の半年で〇〇と△△を経験し、本人の希望と面談で決める」
- **決まるまでの最初の1年を、具体的に**：職種は未定でも、最初の月に何をするかは決まっている
- **決まったあとの職種の候補を、並べる**：「〇〇、△△、□□のいずれか。それぞれの仕事の具体は各コースの説明に」
- **職種別コースと、職種未定コースの違いを書く**：「職種を決めている人は各コースへ。迷っている人はこちら」
- **選考で何を見るかを、職種別と分けて書く**：職種未定は「どの仕事にも向く土台」を見る、など

「決め方を書く」が要点です。「未定」の一言は、学生には「何をするか分からない」で、「決め方」があれば「決まるまでの道が分かる」になります。

## コースを増やす・減らす判断

| 判断 | 見るもの |
|---|---|
| 増やす | 一つのコースに、最初の1年が違う仕事が混ざっている。体験談で「同じコースなのに違う」と書かれている。面談で「どの仕事か分からなかった」と言われる |
| 減らす | 各コースの応募が少なく、中身が薄い。コース間で最初の1年も選考も同じ。運用の手間で更新が止まっている |
| そのまま | 学生が「自分はどれか」を選べていて、各コースに中身がある |

増やすときは、各コースに書くことを埋められるかを先に確かめます。埋められないなら、増やしません。減らすときは、まとめたコースに「他のコースとの違い」を書き直します。

## 体験談とコースを揃える

ワンキャリアでは、体験談がコースの単位で書かれます。

- **自社の体験談で、学生がどの呼び方でコースを書いているかを読む**：「営業職」「〇〇コース」「総合職」
- **掲載のコース名を、体験談の呼び方と揃える**：体験談と違う名前にすると、結びつかない
- **コースを変えたら、「今年度から〇〇コースを△△と□□に分けた」と書く**：過去の体験談との対応が分かる
- **コースごとの選考の流れが体験談と揃っているかを、選考後に読む**：[企業ページを更新し続ける方法](/media/oc-kigyo-page-koushin/)

「コース名を体験談と揃える」は、ワンキャリアに特有の注意です。社内の正式名称より、学生が体験談で使っている呼び方のほうが、学生には通じます。

## 他の媒体との揃え方

OfferBoxやWantedlyでも、募集は職種ごとに分けます。3媒体で、コースの単位と名前を揃えます。

- **同じ職種は、同じ名前で**：媒体ごとに違う名前にしない
- **最初の1年の記述を、3媒体で共通に**：材料は一つ。[コンテンツを資産として貯める考え方](/media/wt-naiyou-shisan/)
- **ワンキャリアだけ、選考の流れをコースごとに厚く書く**：体験談がコースの単位だから
- **OfferBoxは、学生ごとにどのコースを案内するかを判断する**：オファー文面の中で

Wantedlyの募集記事の分け方は[募集記事を複数出す考え方](/media/wt-boshu-fukusu/)で書きました。考え方は同じで、ワンキャリアはそこに「体験談と揃える」が加わります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 分ける軸に照らして、コースを決める | 人事と責任者 |
| 各コースの最初の1年を書く | 人事（その職種の人と新卒入社の人に聞いて） |
| 各コースの選考の流れと何を見るかを書く | 人事と、面接に出る人 |
| 配属の決まり方を決めて書く | 責任者と人事 |
| 体験談のコースの呼び方を読み、名前を揃える | 人事 |
| 3媒体でコースの単位と名前を揃える | 人事 |
| 増やす・減らすを判断する | 人事と責任者（選考後に） |

運用代行や代理店が支えられるのは、分ける軸の整理、各コースに書くことの型、職種未定コースの書き方、体験談との揃え方の点検、3媒体の揃え方の整理までで、コースの決定、配属の決まり方の決定、最初の1年の中身、選考の流れの決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないとコースが名前だけになることがあります。「各コースの最初の1年が、社内で決まっているか」です。当社がワンキャリアのコースの整理を支えるとき、分ける軸と書くことの型は当社が出せますが、「営業コースの最初の月は何をするか」は、その職種の責任者にしか言えません。決まっていないコースを作ると、コース名だけで中身が無く、学生は選べず、体験談に「コースを選んだ意味が分からなかった」と書かれます。当社が最初にお願いするのは、コースを決める前に、各コースの責任者に「最初の月、3か月、1年目の終わり」を聞いてもらうことです。答えが出るコースだけを作ります。答えが出ないなら、そのコースはまだ作らず、職種未定コースの「決め方」に含めます。

## まとめ

- コースは、仕事の中身・最初の1年・選考の流れ・勤務地・雇用の形のいずれかが違うなら分け、違わないなら分けない
- 「総合職」で一つにまとめる、分けすぎて薄い、名前だけ、選考の流れが混ざる、配属の決まり方が無い、が学生の迷う形
- 各コースに、仕事の具体と最初の1年、こんな人、選考の流れと何を見るか、配属の決まり方、勤務地、働く人、他のコースとの違いを書く
- 職種未定コースは「未定」ではなく「決め方」と「決まるまでの最初の1年」を書く
- コース名と単位を体験談の呼び方と揃え、3媒体で揃え、選考後に増やす・減らすを判断する。各コースの最初の1年が決まっているコースだけを作る

## よくある質問

### 入社後にジョブローテーションがあり、職種を固定できません

職種未定コースとして、「決め方」と「ローテーションの最初の1年」を書きます。「最初の半年は〇〇と△△を経験し、その後に本人の希望と面談で決める」のように、決まるまでの道を書けば、学生は選べます。「未定」の一言だけにしません。

### コースを分けたら、あるコースだけ応募がほとんどありません

そのコースの「最初の1年」と「こんな人」が薄くないかを見ます。薄ければ足します。中身があっても来ないなら、体験談でそのコースがどう書かれているかを読みます。それでも来ないなら、そのコースは他と統合し、「他のコースとの違い」を書き直します。

### ワンキャリアの募集コースの設計は、御社に相談できますか

できます。当社は、分ける軸の整理、各コースに書くことの型、職種未定コースの書き方、体験談との揃え方の点検、3媒体の揃え方の整理を支えられます。コースの決定、配属の決まり方、最初の1年の中身、選考の流れの決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
