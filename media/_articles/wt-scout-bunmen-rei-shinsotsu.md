学生へのスカウトの考え方は、[新卒にスカウトを送るときの考え方](/media/wt-scout-shinsotsu/)で書きました。この記事は、その考え方を「文面の型」に落としたものです。**結論から言うと、学生向けのスカウト文面は、「学生時代に何をしていたか、何に興味があるか」を本人の言葉で読んだ一文、それがこの仕事の「最初の1年」とどう重なるかの一文、「入社してまもない社員が、仕事の中身を話す場」への案内、の3段で作ります。選考・面接・内定・応募・経験・即戦力の言葉を使わず、就職活動の段階を決めつけず、時期の扱いは年度の公表内容と自社の方針を確認します。** この記事では、3段の型とそれぞれの書き方、プロフィールの箇所ごとの一文の作り方、避ける言葉、書き出しの型、段階を決めつけない書き方、インターンへ誘う場合、送る前のチェック、分担を整理します。文面の基本の構成は[スカウト文面の書き方](/media/wt-scout-bunmen/)で書きました。

## この作業の目的｜学生が「自分に向けて書かれている」と分かる文面を、型で毎回作れるようにする

学生は、企業からの連絡に慣れていません。経歴の言葉で書かれた文面は「自分向けではない」と感じ、選考の言葉が入った文面は身構えます。

目的は、「学生時代の自分を読んで、この仕事の最初の1年の話をしたいと、社員が連絡してきた」と学生が受け取る文面を、型で毎回作れる状態にすることです。型があれば、送る人が変わっても、学生向けの言葉で揃います。

## 3段の型

| 段 | 書くこと | 長さ |
|---|---|---|
| 1. 学生時代を読んだ一文 | プロフィールの活動か興味のどこを読んだか。本人の言葉で | 1〜2文 |
| 2. 「最初の1年」との重なり | その活動や興味が、この仕事の最初の月・最初の1年とどう重なるか。募集記事の「最初の1年」と同じ言葉 | 2〜3文 |
| 3. 仕事を知る場の案内 | 入社してまもない社員が、仕事の中身を話す。選考ではなく、仕事を知る場。無理なら返信は不要 | 1〜2文 |

署名は、送り主の名前と、入社してまもないなら「入社〇年目」のような近さが分かる一言と、会社名です。会社の説明、事業の説明、募集要項は入れません。

## 1段目｜学生時代を読んだ一文

プロフィールの箇所ごとに、一文の作り方が違います。

| 箇所 | 一文の型 |
|---|---|
| サークル・部活 | 「〇〇で△△を続けてこられたと書かれていたのを読んで」。続けたこと、役割、企画したこと |
| アルバイト | 「〇〇のアルバイトで、△△が好きだったと書かれていたので」。本人が「好き」「面白かった」と書いた部分 |
| 研究・専攻 | 「〇〇を研究されていると読んで」。仕事と重なるなら。重ならないなら、無理に触れない |
| 自分で始めたこと | 「〇〇を自分で始められたと書かれていた点を読んで」。最も強い一文になりやすい |
| 興味・やりたいこと | 「〇〇に興味があると書かれていたので」。仕事と重なるもの |
| 留学・長期の経験 | 「〇〇での△△の経験を読んで」。何をしたかが書かれていれば |

「本人の言葉で」が原則です。プロフィールに「文化祭の企画を三年間やっていた」とあれば、「文化祭の企画を三年間続けてこられた点を読んで」と、そのまま使います。「リーダーシップを発揮された」のように言い換えると、読んでいないと分かります。

### エージェントベストの見解

相談で最も多い思い込みは、「学生向けの文面は、会社の魅力や成長環境を伝えるべきだ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxとWantedlyで学生へのスカウトを見ていますが、学生が返信した文面に「成長できる環境」「若手が活躍」の言葉はほとんど出てきません。出てくるのは、「文化祭の企画を続けていたと書かれていたので」「最初の月は先輩の商談に同行するところから」「入社二年目の〇〇が話します」という、学生時代の一文と、最初の1年の一文と、近い社員の一文です。当社が学生向けの型を作るとき、最初にやるのは、会社の魅力の段落を全部消し、この3つだけを残すことです。魅力は、会社ページとストーリーに書いてあります。文面は、そこへ連れて行くためのものです。

## 2段目｜「最初の1年」との重なり

学生は職種名から仕事を想像できないので、2段目は「最初の月に何をするか」で書きます。

| 型 | 例（型） |
|---|---|
| 最初の月の仕事と重ねる | 「うちの〇〇職は、最初の月に△△から始めます。文化祭の企画を続けてこられたあなたなら、その△△が想像できると思い」 |
| 最初の1年の流れと重ねる | 「最初の3か月は□□、1年目の終わりには〇〇を一人で持ちます。アルバイトで△△が好きだったと書かれていた点が、その〇〇と重なります」 |
| 教える人と重ねる | 「最初の月は、入社二年目の〇〇が隣で教えます。〇〇も学生時代に△△をしていて」 |
| なぜ新卒かと重ねる | 「うちは、〇〇の仕事を最初から身につけた人のほうが向いていて、△△を続けてきた人を探していました」 |

「最初の月」「最初の3か月」「1年目の終わり」の言葉は、募集記事の「最初の1年」の段落と揃えます。募集記事の書き方は[新卒向け募集記事の書き方](/media/wt-boshu-shinsotsu/)で書きました。募集記事に「最初の1年」が無ければ、文面より先に募集記事に足します。

## 3段目｜仕事を知る場の案内

| 入れること | 書き方 |
|---|---|
| 誰が話すか | 「入社二年目の〇〇が」。学生に近い人。人事なら「人事の〇〇と、入社してまもない△△が」 |
| 何を話すか | 「仕事の中身と、最初の1年に何をするかを話します」 |
| 選考ではないこと | 「選考ではなく、仕事を知る場です」。「選考」の言葉は、この否定でだけ使う |
| 形 | 「オンラインで、短い時間で。授業やアルバイトに合わせて日程を決めます」 |
| 断りやすさ | 「無理なら、返信は不要です」 |

「授業やアルバイトに合わせて」の一言で、学生は「自分の都合を考えてくれている」と受け取ります。

## 避ける言葉

| 避ける言葉 | 代わりに |
|---|---|
| 選考、面接、内定 | 「仕事を知る場」（「選考ではなく」の否定形でだけ使う） |
| 応募、エントリー | 「まず話を聞きに来て」 |
| 経験、スキル、即戦力 | 「学生時代に〇〇していた」 |
| 優秀な学生、ぜひ弊社に | 相手の具体的な活動 |
| 成長できる環境、若手が活躍 | 最初の月に何をするか、誰が教えるか |
| 転職、キャリア | 「これから仕事を選ぶうえで」 |
| 業界用語、社内の言葉 | 学生の言葉で |
| 「〇〇様」（名前だけの差し替え） | 名前に加えて、活動の一文 |

## 書き出しの型

一覧や通知で最初に見える一文は、会社名ではなく、学生時代の一文にします。

- 「文化祭の企画を三年間続けてこられたと読んで、連絡しました」
- 「〇〇のアルバイトが好きだったと書かれていたので、うちの△△の話をしたくて」
- 「入社二年目の〇〇です。あなたの□□の話を読んで」

会社名は署名に入れます。書き出しの考え方は[スカウトの書き出しの工夫](/media/wt-scout-kenmei/)で書きました。

## 就職活動の段階を、決めつけない

Wantedlyの学生は、就職活動を始めていない人、インターンを探している人、活動中の人が混ざっています。文面は、段階を決めつけません。

- **「就職活動中の」と書かない**：始めていない学生が「自分向けではない」となる
- **「〇年卒の」と書かない**：卒業年で絞っていても、文面には入れない。入れるなら「卒業後の仕事を考えるうえで」程度
- **「仕事を知る場」に誘う**：どの段階の学生でも来られる
- **面談で、段階を聞かない**：「就職活動はどのくらい進んでいますか」は、選考の質問に近い。聞くなら「いま、仕事についてどのくらい考えていますか」程度で、答えなくてよい形で

## インターンへ誘う場合の型

インターンの募集へ誘う場合は、2段目と3段目を変えます。

| 段 | インターンへ誘う場合 |
|---|---|
| 2. 重なる点 | 「うちのインターンでは、最初の週に〇〇を任せます。△△を続けてこられたあなたに、まずそれをやってみてもらえたらと思い」。何を任せるか、誰が見るか |
| 3. 場の案内 | 「インターンの中身を、いま来てもらっている学生と、担当の〇〇が話します」 |

インターンと選考の関係は、年度の公表内容と自社の方針を確認してから、文面に書くかどうかを決めます。この記事では、関係の具体は書きません。インターンの募集記事は[インターン募集記事の書き方](/media/wt-boshu-intern/)で書きました。

## 時期の扱い

学生にスカウトを送る時期、面談の位置づけ（広報か選考か）は、年度ごとに公表される内容と、自社の方針を確認して決めます。この記事では、時期の具体は書きません。型は時期に関わらず使えますが、送るかどうかと、面談の位置づけは、確認してから決めます。

## 送る前のチェック

1. **1段目に、本人の言葉で書かれた学生時代の活動か興味があるか**
2. **1段目を言い換えていないか**（「リーダーシップ」などに変えていないか）
3. **2段目に、「最初の月」か「最初の1年」の具体があるか**
4. **2段目の言葉が、募集記事の「最初の1年」と同じか**
5. **3段目に、入社してまもない社員の名前があるか**
6. **「選考ではなく」以外に、選考・面接・内定・応募の言葉が無いか**
7. **経験・即戦力・優秀・成長環境の言葉が無いか**
8. **「就職活動中」「〇年卒」で段階を決めつけていないか**
9. **業界用語と社内の言葉が無いか**
10. **時期と面談の位置づけを、年度の公表内容と自社の方針で確認したか**

1と3と6の3つだけでも、毎回見ます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 募集記事の「最初の1年」を整える | 人事と、その職種の責任者 |
| 学生向けの型を作る | 人事 |
| プロフィールを読み、1段目と2段目を書く | 入社してまもない社員（または人事が書き、本人が確認） |
| 時期と面談の位置づけを確認する | 人事 |
| 返信対応（授業やアルバイトに合わせた日程で） | 人事 |
| 面談で最初の1年の話をする | 入社してまもない社員 |

運用代行や代理店が支えられるのは、学生向けの型、箇所ごとの一文の型、避ける言葉のチェック、募集記事との整合の確認までで、読んで書くこと、時期と選考の判断、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの学生向けスカウトの型を作るとき、3段の型、箇所ごとの一文の型、避ける言葉、チェックの項目は当社が出せます。ただし、2段目の「最初の月に何をするか」と、3段目の「入社してまもない社員の名前」は、社内で決まっていなければ書けません。当社が最初にお願いするのは、「最初の月に、新卒は誰と何をしますか」を責任者に聞いてもらうことと、「面談に出られる、入社してまもない社員は誰ですか」を決めてもらうことです。この2つがあれば、型は当社が作り、社内の人が書くのは1段目の一文と、2段目の重ね方だけで済みます。無ければ、型は「成長できる環境」に戻り、学生には届きません。

## まとめ

- 学生向けの文面は、学生時代を本人の言葉で読んだ一文→「最初の1年」との重なり→入社してまもない社員と話す「仕事を知る場」、の3段
- 1段目は、サークル・アルバイト・研究・自分で始めたこと・興味から、本人の言葉のまま。言い換えない
- 2段目は、最初の月・最初の3か月・1年目の終わり、で募集記事と同じ言葉。3段目は、近い社員の名前、選考ではないこと、授業に合わせる、返信不要でよい
- 選考・面接・内定・応募・経験・即戦力・優秀・成長環境・就職活動中・〇年卒を避け、段階を決めつけない
- インターンへ誘うなら「最初の週に何を任せるか」で。時期と面談の位置づけは年度の公表内容と自社の方針を確認

## よくある質問

### 入社してまもない社員が、文面を書く時間を取れません

型があれば、書くのは1段目の一文と、2段目の重ね方の一文だけです。人事がプロフィールを読んで下書きし、本人が確認して名前で送る形にすれば、本人の時間は確認と面談だけになります。ただし、本人が読んで了承したものだけを送ります。

### 学生のプロフィールが短く、活動も興味もほとんど書かれていません

書かれている一つ（専攻、興味の一言）から一文を作ります。それも無ければ、送らないか、優先を下げます。推測で「〇〇に興味があるのでは」と書くと、外れたときに信用を失います。書いている学生に絞るほうが、結果につながります。

### 新卒向けのスカウト文面の型は、御社に相談できますか

できます。当社は、学生向けの型、箇所ごとの一文の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。読んで書くこと、時期と選考の判断、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、新卒採用の媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
