人事1人でWantedlyの記事を書き続けるのは難しく、外部のライターや代理店に頼む会社は多くあります。頼むこと自体は問題ありませんが、頼み方を間違えると、「文章はきれいだが、自社の言葉ではない記事」が並びます。**結論から言うと、外部に頼めるのは「聞く・構成する・整える・揃える」で、頼めないのは「話す・なぜを決める・出す範囲を決める・面談で書いたとおりに話す」です。この線を引いたうえで、頼む前にトーンの見本と出さないものの一覧と読ませたい候補者を渡し、取材には社内の人が出て、納品は「自社の人が言いそうか」で見ます。** この記事では、頼めることと頼めないこと、丸投げの失敗、頼む前に渡すもの、取材の形、納品の見方、社内に戻す手順、分担を整理します。

## この作業の目的｜外部の手を借りて、自社の言葉の記事を出す

外部に頼む目的は、「人事の時間を減らす」ことと、「書く技術を借りる」ことの2つです。目的に入っていないのは、「自社の言葉を外部に作ってもらう」ことです。

Wantedlyの記事は、読んだ候補者が面談で会社の人と話します。記事の言葉が外部のものだと、面談で「記事と違う」と感じられます。外部に頼んでも、記事の中身は社内の人が話したことで、言葉は面談で話す言葉に寄せる。この2つが守られていれば、外部に頼んだ記事も自社の記事になります。

## 頼めることと、頼めないこと

| 頼めること | 頼めないこと |
|---|---|
| 社内の人に聞く（取材、インタビュー） | 話す（中身は社内の人からしか出ない） |
| 聞いたことを構成する | 会社の「なぜ」を決める |
| 文章に整える、トーンの見本に揃える | 出してよい範囲を決める |
| 抽象語を場面に置き換える提案 | 場面そのものを持っている |
| タイトルの案、写真の選定の軸 | 写真を撮る（普段の場面は社内の人しか撮れない） |
| 公開後の記事の見直しの提案 | 面談で、書いたとおりに話す |
| 記事の型、チェックの型 | 本人の確認と、責任者の確認 |

「話す」が頼めないことの中心です。外部のライターがどれだけ上手でも、社内の人が話さなければ、書くものがありません。外部に頼むときに社内が減らせるのは「書く時間」で、「話す時間」は減りません。

### エージェントベストの見解

これは、向く会社と向かない会社がはっきり分かれます。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、外部に記事を頼んでうまくいく会社は、「話す人が社内に決まっていて、取材の時間を業務時間内に取れる会社」です。外部が聞きに行けば、話す人がいて、話が出る。それを外部が整える。この形なら、人事の時間は減り、記事は自社の言葉のまま出ます。逆に、「忙しいので外部に全部任せたい」という会社は、取材の時間も取れず、外部は会社の公開情報から記事を作ることになり、きれいだが中身の無い記事になります。当社がWantedlyの記事の支援を受けるとき、最初に確認するのは「話す人と、取材の時間を、社内で確保できますか」です。できるなら当社は役に立ち、できないなら、先に社内でそこを決めるのが順番です。

## 丸投げの失敗

| 失敗 | 何が起きるか |
|---|---|
| 会社の公開情報だけで書いてもらう | どの会社にも書ける記事。場面が無い |
| 取材に社内の人が出ない | 人事が代わりに答え、現場の場面が入らない |
| トーンの見本を渡さない | 外部の「Wantedlyらしい文体」になり、面談の言葉とずれる |
| 出さないものの一覧を渡さない | 外部は判断できず、出しすぎか、無難になるかのどちらか |
| 読ませたい候補者を伝えない | 誰にでも向けた記事になり、誰にも届かない |
| 納品を「文章の上手さ」で見る | 自社の言葉でない記事が通る |
| 外部に頼んだまま、社内に何も残らない | 契約が終わると書けなくなる |

最も多いのは、最初の「公開情報だけで書いてもらう」です。取材の時間を取らず、「うちのサイトを見て書いてください」と頼んだ結果です。

## 頼む前に渡すもの

外部に頼む前に、社内で用意しておくものが3つあります。

1. **トーンの見本**：面談で話す言葉に寄せた、会社ページの1段落と募集記事の1段落。「この話し方で」と渡す。作り方は[文章のトーンの決め方](/media/wt-bunsho-tone/)
2. **出さないものの一覧**：顧客名、機密、個人、数字、他社。外部が判断に迷わないように。考え方は[会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)
3. **読ませたい候補者**：どの募集の、どんな状態の人に読ませたいか。記事ごとに一言

加えて、既存の会社ページと最近のストーリーを読んでもらいます。会社全体の本音の濃さと、書いてきた場面が分かると、外部は同じ濃さで書けます。

この3つが無いまま頼むと、外部は「一般的に良いとされる記事」を書きます。3つがあれば、「この会社の記事」を書けます。

## 取材の形｜社内の人が話し、外部が聞く

取材は、外部のライターが社内の人に直接聞く形にします。人事が代わりに答えない、資料だけを渡さない。

- **話す人を、記事ごとに決める**：インタビューなら本人、事業の裏側なら関わった人、募集記事ならその職種の人
- **業務時間内に、短く**：長い取材は断られる。1つの場面を聞くなら短くて済む
- **人事が同席する**：出さないものの判断、本人が話しにくいことの補い。ただし、人事が代わりに話さない
- **聞き方は「最近の1つの出来事」から**：「会社の良さは」ではなく「先月、何がありましたか」。聞き方は[社員インタビューを書く手順](/media/wt-story-interview/)
- **1行を拾う仕組みがあれば、それを外部に渡す**：取材の前に「今週あったこと」の1行が溜まっていれば、外部はそこから聞ける。仕組みは[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)

「人事が代わりに話さない」が要点です。人事が答えると、記事は人事の言葉になり、現場の場面が消えます。

## 納品の見方｜「自社の人が言いそうか」で見る

納品された記事を、文章の上手さで見ません。見るのは次の点です。

| 見ること | 判断 |
|---|---|
| 自社の人が言いそうな言葉か | 面談で話す言葉とずれていないか |
| 場面が入っているか | 取材で話された出来事が、そのまま書かれているか |
| 抽象語が残っていないか | 外部が「うまくまとめた」結果、抽象語になっていないか |
| 本人の言葉が残っているか | 整えすぎて、本人の言い回しが消えていないか |
| 出さないものが入っていないか | 一覧に照らす |
| 読ませたい候補者に向いているか | 誰にでも向けた文になっていないか |
| 教訓や決意で締めていないか | 外部は締めたがる。場面で終わる |

外部の記事で起きやすいのは、「うまくまとめすぎて、場面が要約になる」ことです。取材で「先月の会議で、〇〇さんが△△と言って、決め方が変わった」と話されたものが、納品では「風通しの良い議論の文化があります」になっている。これは直してもらいます。

## 外部から社内に戻す手順

外部に頼み続けても構いませんが、契約が終わったときに書けなくなる状態は避けます。

1. **外部が使った型を、社内に残す**：取材の聞き方、構成、チェックの型
2. **納品の直しを、人事がやる**：外部に全部直させず、人事が最終の整えをやると、書き方が身につく
3. **地の文を人事が書き、外部が整える形に移す**：慣れてきたら
4. **書き手を社内に増やす**：外部は「整える」に絞り、話す人・拾う人・直す人を社内で。増やし方は[書き手を社内で増やす方法](/media/wt-story-kakite/)

外部の役割は、最初は「聞いて書く」、次に「整える」、最後に「型を渡して離れる」と変わっていくのが、社内に残る形です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| トーンの見本、出さないものの一覧、読ませたい候補者 | 人事（頼む前に） |
| 話す人を決めて、取材の時間を取る | 人事 |
| 話す | 社内の人 |
| 聞く、構成する、整える | 外部 |
| 納品を「自社の人が言いそうか」で見る | 人事 |
| 本人と責任者の確認 | 人事が社内で |
| 型を社内に残す | 人事 |

運用代行や代理店が支えられるのは、聞く・構成する・整える・揃える・型を渡すまでで、話すこと、なぜを決めること、出す範囲を決めること、面談で書いたとおりに話すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「外部のライターに頼めば、社内の時間はゼロになる」という点です。当社がWantedlyの記事の支援をするとき、社内から減るのは「書く時間」で、「話す時間」と「確認する時間」は残ります。むしろ、外部が聞きに来る分、社内の人が話す機会は増えます。これを先に伝えないと、「頼んだのに時間がかかる」という不満になります。当社は、支援を始める前に、「記事1本あたり、社内の人が話す時間と、人事が確認する時間」を先に見積もってお伝えします。それでも、人事が1人で書く場合に比べれば、社内の時間は減ります。減るのは書く時間、残るのは話す時間。この区別を、頼む前に社内で共有しておくと、外部との関係が長く続きます。

## まとめ

- 外部に頼めるのは「聞く・構成する・整える・揃える」。「話す・なぜを決める・出す範囲を決める・面談で守る」は社内
- 丸投げ（公開情報だけで書く、取材に社内が出ない）は、きれいだが自社の言葉でない記事になる
- 頼む前に、トーンの見本・出さないものの一覧・読ませたい候補者の3つを渡す
- 取材は社内の人が話し、外部が聞く。人事は同席するが、代わりに話さない
- 納品は「自社の人が言いそうか」「場面が要約になっていないか」で見る。型を社内に残し、外部の役割を整えるほうへ移す

## よくある質問

### 取材の時間が取れないので、資料だけで書いてもらえませんか

資料だけで書いた記事は、どの会社にも書ける内容になります。取材は短くて構いません。1つの場面を聞くだけなら、業務時間内の短い時間で済みます。話す人と時間を先に決めてから頼むほうが、結果として時間の無駄がありません。

### 外部が書いた記事が、上手すぎて自社らしくありません

トーンの見本と、既存の記事を読んでもらい、「この話し方に寄せてください」と伝えます。納品で見るのは上手さではなく「自社の人が言いそうか」です。要約された場面は、取材で話された出来事に戻してもらいます。

### Wantedlyの記事の制作は、御社に頼めますか

頼めます。当社は、聞く・構成する・整える・揃える・型を渡すところを支えられます。話すこと、なぜを決めること、出す範囲を決めること、確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの記事の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
