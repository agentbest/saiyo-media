説明会を開いて、母集団を作りたい。ところが、参加者数を「母集団」と数え、年に数回の大きな回に人を集め、当日に次の案内がなく、参加後に連絡が切れて、選考に進んだ人はごく一部。**結論から言うと、イベントの母集団は、「参加した人」ではなく「参加後に次の場へ進んだ人」で数えます。小さい回を途切れさせずに続け、「確かめられる回」に見せ、当日に次の案内を出し、参加者を台帳に入口「イベント」で持ちます。人数を追って煽りません。** この記事では、イベントで起きる失敗、数え方、小さい回を続ける理由、「確かめられる回」の設計、入口ごとの誘い方、当日と参加後、台帳、掲載との分担、時間、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、イベントと掲載の違いは[イベントと掲載の違い](/media/hikaku-event-vs-keisai/)、媒体ごとのイベントは[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)と[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)で書きました。

## この作業の目的｜イベントを、「次の場へ進む人」が出る場にする

イベントは、学生が会社の人と雰囲気を確かめる場で、文面や記事では伝わらないものが伝わります。母集団形成にとっては、「確かめた人」が「次の場（面談・選考）」へ進む入口です。参加しただけで止まる人は、母集団になっていません。

目的は、イベントを参加者数の場ではなく、「確かめて、次へ進む人」が出る場として設計することです。

## イベントで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 参加者数を、母集団と数える | 多く集めても、次へ進む人が少なく、選考に来ない |
| 大きな回を、年に数回だけ | 回の間が空き、その間に動いた学生を逃す。一回の準備が重く、現場が疲れる |
| 「会社説明会」の名前で開く | 何が確かめられる回か分からず、来る人が広がり、近い人が薄まる |
| 当日に、次の案内がない | 確かめて温度が上がった人が、帰って冷める |
| 参加後の連絡が切れる | 参加時の記録がなく、選考期に「参加者」として連絡できない |
| 人数を追って煽る | 「残席わずか」で集めた人は確かめに来ておらず、次へ進まない |

共通するのは、イベントを「集める場」として設計していることです。イベントは「確かめる場」です。

## イベントの母集団は、「参加後に次へ進んだ人」で数える

| 数えるもの | 何が分かるか |
|---|---|
| 参加者のうち、「こんな人」に近い人の数 | 回の名前と誘う入口が、近い人を連れてきているか |
| 当日に、次の場を申し込んだ数 | 回の中身と、当日の案内が効いているか |
| 参加後、面談に進んだ数 | イベントが母集団に効いたか。成果はここで測る |
| 参加者から進んだ人の、面談以降の進み方 | イベント経由の人が、他の入口より進むか |

参加者数と満足度だけでは、母集団への効きは分かりません。イベントを一つの入口として、[採用ファネルの作り方](/media/kh-boshudan-funnel/)の入口ごとの表で持ちます。

### エージェントベストの見解

相談で最も多い思い込みは、「イベントは、一回に多く集めるほど効率がよい」というものです。当社は3媒体すべての販売パートナーとして、イベントからの母集団形成を見ていますが、一回に多く集めた会社は、社員と話せた学生が少なく、確かめられずに帰った人が多く、次へ進む人がごく一部です。逆に、少人数の回を途切れさせずに続けた会社は、参加者の多くが社員と話し、当日に次の場を申し込み、回を重ねるほど「確かめられる回」として体験談や口伝えで知られています。イベントの価値は、一回の参加者数ではなく、「確かめて、次へ進んだ人の数」と「回が続いていること」です。当社がイベントの相談を受けるとき、最初にやるのは、一回の人数を減らして、回数を増やす形に変えることです。

## 小さい回を、途切れさせずに続ける

- **少人数の回は、社員と話せる**：確かめられる。大きな回は聞くだけになる
- **回が続いていると、動いた時期に申し込める**：回の間が空くと、その間に動いた学生を逃す
- **一回の準備が軽い**：同じ型で回すので、現場の負担が小さく、続く
- **回を重ねるほど、型が良くなる**：参加者の質問と、次へ進んだ人の記録で
- **続ける形は[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)の「小さい回を、途切れさせずに続ける」**

## 「確かめられる回」に、設計する

| 要素 | 設計 |
|---|---|
| 回の名前 | 「会社説明会」ではなく、「何が確かめられるか」。「〇〇職の一日を、担当者と話す回」など |
| 出る人 | 人事だけでなく、その仕事の社員。学生が確かめたいのは「誰と働くか」 |
| 中身 | 会社の説明は短く、仕事の中身と、質問に答える時間を長く |
| 人数 | 社員と話せる人数。多く集めない |
| 選考との関係 | 明記する。年度の公表内容と自社の方針で確認 |
| 次の場 | 回の最後に、次の場（面談・次の回）を案内。当日に申し込める形 |

設計の詳しくは[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)の「書く要素」と「イベントの型ごとの書き方」で書きました。名前の付け方は[ワンキャリアのイベントページのタイトル](/media/oc-event-page-title/)で書きました。

## 入口ごとの、イベントへの誘い方

| 入口 | 誘い方 | 注意 |
|---|---|---|
| スカウト | 締めを面談ではなく「この回」の案内にする場合がある | 「こんな人」に近い人だけに。[ワンキャリアのスカウトとイベントの連携](/media/oc-scout-event-renkei/) |
| 掲載・企業ページ | 回の一覧と、回の中身を事実で書く | 「残席わずか」と書かない |
| 早期の接点 | 保つ連絡の中で、回を案内 | [早期の母集団形成の考え方](/media/kh-boshudan-souki/) |
| 内定者・社員の紹介 | 「この回に来てみないか」 | 少人数の回なら、紹介で埋まることも |

全入口から誘うと、一回の人数が社員と話せる数を超えます。回の人数に合わせて、誘う入口を絞ります。

## 当日の次の案内と、参加後の連絡

- **回の最後に、次の場を案内する**：面談、次の回、インターン。当日に申し込める形
- **当日か翌日に、一通**：参加のお礼と、その回で出た質問の一つへの答え
- **参加中に分かったことを、台帳に一行**：何を質問したか、どこが「こんな人」に近いか
- **次の場に進まなかった人にも、保つ連絡を**：次の回、仕事の記事
- **選考期に入ったら、参加者に最初に連絡する**：「〇〇の回でご質問いただいた件で」
- **参加後の動きは[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)の「終わったあとの動き」**

## 台帳で、入口「イベント」として持つ

- **台帳の入口を「イベント」で分ける**：スカウトや掲載と混ぜない
- **回ごとに、参加者、近い人の数、次へ進んだ数を持つ**：回の型の改善に使う
- **参加者が他の入口とも接点を持っていたら、両方を記録**：どの入口が効いたかを後で見る
- **回ごとの記録を、翌年の回の設計に**：進んだ人が多い回の型を残す
- **台帳の項目は[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)の手順5**

## 掲載との、分担

- **掲載は「情報と判断材料」、イベントは「人と雰囲気」**：[イベントと掲載の違い](/media/hikaku-event-vs-keisai/)
- **掲載で回を知り、回で確かめ、面談へ**：掲載→イベント→面談の順
- **掲載だけで面談に進む人と、回を経て進む人を、分けて数える**
- **回の中身を、掲載と揃える**：掲載に書いたことを、回でそのとおりに。[掲載からの母集団形成](/media/kh-boshudan-keisai/)
- **回の体験が、翌年の掲載の材料になる**：参加者の質問と、答えた中身

## 社内の分担

| 作業 | 誰が |
|---|---|
| 回の目的と型を決める | 人事責任者 |
| 回の名前と中身を、「確かめられる回」で設計する | 人事と現場 |
| 回に出て、仕事を話し、質問に答える | 現場の社員 |
| 誘う入口を回の人数に合わせて絞る | 人事 |
| 当日に次の場を案内する | 人事 |
| 参加後の一通と、台帳の一行 | 人事 |
| 回ごとの記録を、翌年の回の設計に | 人事 |

運用代行や代理店が支えられるのは、回の型の整理、名前と中身の設計の型、誘う入口の絞り方、当日の案内の型、参加後の連絡の型、台帳の型までで、回の目的の決定、回に出ること、質問に答えること、連絡、記録は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。イベントの相談で、「まず大きな説明会を開いて、そこから母集団を作りたい」と言われることがあります。当社がお願いする順番は逆で、まず「こんな人」を決め、次に「その人が確かめたいこと」を一つ決め、それが確かめられる小さい回を一つ設計し、続ける中で型を良くし、続いている回にスカウトや掲載から誘う、です。大きな回から始めると、「こんな人」が決まる前に人が集まり、確かめられずに帰り、次へ進まず、「イベントは効かない」で止まります。小さい回から始めると、最初の回は少人数でも、次へ進んだ人の記録が残り、回を重ねるほど母集団の入口になります。当社は、大きな回を開く前に、小さい回が続いているかを確かめます。

## まとめ

- イベントの母集団は「参加した人」ではなく「参加後に次の場へ進んだ人」。参加者数を母集団と数えると、次へ進まず選考に来ない
- 小さい回を途切れさせずに続ける。少人数なら社員と話せ、回が続いていれば動いた時期に申し込め、準備が軽く、型が良くなる
- 「会社説明会」ではなく「何が確かめられる回か」で名前を付け、その仕事の社員が出て、選考との関係を明記し、当日に次の場を案内する
- 誘う入口は回の人数に合わせて絞り、「残席わずか」と煽らない。参加後は当日か翌日に一通、台帳に一行、選考期に最初に連絡
- 台帳で入口「イベント」として分け、回ごとに近い人と次へ進んだ数を持ち、翌年の回の設計に。掲載とは「情報」と「人」で分担する

## よくある質問

### 小さい回を続ける、現場の時間がありません

一回の時間を短くし、出る社員を回ごとに交代し、同じ型で回します。大きな回一回の準備と同じ時間で、小さい回を数回できることが多く、一回あたりの現場の負担は小さくなります。続けられないなら、回数を減らしてでも「途切れさせない」ことを優先し、回の間が空くときは、掲載と保つ連絡でつなぎます。現場の巻き込み方は[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)で書きました。

### 少人数の回に、人が集まりません

集まらないのは、回が「確かめられる回」に見えていないことが多く、名前が「会社説明会」、中身が会社の説明、選考との関係が不明、申込後が見えない、のどれかです。人数を追って煽らず、一覧での見つかり方、名前、確かめられる中身、選考との関係、申込後の流れを直します。五つの原因は[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)で書きました。少人数で構わないので、続けます。

### イベントからの母集団形成は、御社に相談できますか

できます。当社は、回の型の整理、名前と中身の設計の型、誘う入口の絞り方、当日の案内の型、参加後の連絡の型、台帳の型を支えられます。回の目的の決定、回に出ること、質問に答えること、連絡、記録は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
