Wantedlyで動画クリエイターの募集記事を出したとき、最初にぶつかるのは「『動画制作全般』『動画で発信を強化』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『企画から編集まで全部ですか』『誰が決めて、誰が直すのですか』『機材は何がありますか』を聞かれて答えられない」という問題です。**結論から言うと、動画クリエイターの募集記事は、「動画制作全般」ではなく「何の動画を、誰に向けて、企画・撮影・編集のどこを担い、何の数字のために、誰が決めて誰が直し、どんな機材と環境で作るか」を書き、募集記事を書く前に種類を一つに絞り、担う範囲と決める人と直す観点と機材の実態を決めておきます。** この記事では、動画クリエイターが募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、作品の求め方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。決める人と直す観点の考え方は[デザイナーを採る募集記事の書き方](/media/wt-designer-boshu/)と[ライター・編集を採る募集記事の書き方](/media/wt-writer-boshu/)と共通です。

## 動画クリエイターが募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 何の動画を、誰に向けて作るか | 製品の紹介か、SNS向けの短いものか、採用向けか、社内向けか、顧客向けの解説か。見る人は誰か。「動画制作」の一語では分からない |
| 企画・撮影・編集の、どこを担うか | 企画から全部か、撮影と編集か、編集だけか。企画は誰が出すか |
| 数字に責任を持つか | 再生か、問い合わせか、応募か。数字が決まっているか。作って終わりか |
| 誰が決めて、誰が直すか | 企画を誰が決め、できたものを誰が直すか。経営者の好みで直されるか。直す観点があるか |
| 機材と環境 | カメラ、照明、音、編集の道具。何があり、何が無いか。自前か会社が用意するか |
| 出演者と、撮影の相手 | 社員が出るか。顧客に撮影に行けるか。出る人がいないのか |

「企画・撮影・編集のどこを担うか」と「機材と環境」が、動画クリエイターに特有の点です。「動画制作全般」の一語では、ここが分かりません。

## 書く前に決めること｜種類を一つに、担う範囲、決める人と直す観点、見る数字、機材の実態

| 決めること | 選択肢 |
|---|---|
| 種類 | 製品の紹介／SNS向けの短いもの／採用向け／社内向け／顧客向けの解説。最初に任せるものを一つ。複数なら、最初の一つと、その後 |
| 担う範囲 | 企画から全部／撮影と編集／編集だけ。企画を出す人は誰か |
| 決める人と直す観点 | 企画を誰が決めるか。できたものを誰が、何を観点に直すか。前にボツにした例 |
| 見る数字 | 再生／問い合わせ／応募。一つに。決まっていないなら、決まっていないと |
| 機材の実態 | 何があり、何が無いか。買う予算があるか。自前を持ち込む前提か |
| 出演者と撮影の相手 | 社員が出るか。顧客に行けるか。出る人がいないなら、いないと |
| 最初の月に任せること | 一本の動画か、既存の動画の直しか、機材の整理か。誰と組むか |

「編集だけ」「機材は無く、これから買う」「出る人がいない」でも構いません。隠さずに書けば、それを前提に読む人が来ます。

## 「なにを」｜何の動画を、誰に、どこを担って

「なにをやっているのか」は、会社の事業の説明ではなく、この動画クリエイターが最初に任される種類と、見る人と、担う範囲に絞ります。

- **種類と見る人を、一つに絞る**：「〇〇の業種の担当者が見る、△△の使い方の解説動画」「候補者が見る、□□の仕事の一日の動画」
- **担う範囲を書く**：「企画は〇〇と一緒に。撮影と編集は任せる」「編集だけ。素材は△△が撮る」
- **どの数字のために作るかを書く**：「見た人からの問い合わせを見る」「まだ数字は決まっていない。まず見られたかを見る」
- **いまの状態を書く**：「いまは外注で作っていて、直す人がおらず、そのまま出している」「経営者が自分で撮って編集していて、続いていない」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

動画クリエイターの募集記事を出す前に、先に決めておかないと効果が出ないのは、「機材と環境の実態」と「出る人がいるか」です。当社がWantedlyの動画クリエイターの募集を支えるとき、「動画で発信を強化したい」と書かれているのに、経営者に聞くと「機材はまだ無い。誰が出るかも決まっていない」という会社が多くあります。動画クリエイターが面談で最初に聞くのは、企画の中身ではなく、「機材は何がありますか」「誰が出ますか」です。ここに答えがないと、「自前の機材で、出る人を自分で探すところから」を想像して離れます。機材が無くても、出る人が決まっていなくても構いません。「機材は無い。〇〇の予算で、来た人と一緒に選んで買う。出るのは、まず経営者。社員は募集してから」と書けば、それを前提に読む人が来ます。当社が最初にお願いするのは、企画の確認ではなく、経営者に「いまある機材と、動画に出てもいいと言っている人」を一覧にしてもらうことです。

## 「どうやって」｜作る流れと、決め方と、機材の書き方

| 書くこと | 書き方 |
|---|---|
| 作る流れ | 企画を誰が出し、誰が撮り、誰が編集し、誰が直し、誰が出すか。「企画は月に一度、〇〇と決める」 |
| 決める人と直す観点 | 「できたものは〇〇が見る。観点は、見る人に伝わるかと、事実。好みでは直さない」。前にボツにした例 |
| 機材と環境 | 何があるか、何が無いか、買う予算、編集の道具。「カメラは〇〇。照明は無い。編集の道具は△△」 |
| 前に作って起きたこと | 「〇〇の動画から△△の問い合わせが来た」「□□は作ったが、見られなかった」。両方書く |

「発信力のある会社」と書くより、「企画は月に一度〇〇と決め、撮影と編集は任せ、できたものは△△が見る人に伝わるかで見る。カメラは□□、照明は無い」と書くほうが、仕事の実態が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| 動画制作経験3年以上 | 見る人に合わせて、長さと切り口を変えたことがある |
| 〇〇（編集の道具）の経験 | 直された理由を聞いて、次の動画で先に直したことがある |
| 企画から編集まで対応できる方 | 出る人が慣れていない状態で、話しやすい形で撮ったことがある |
| センスのある方 | 数字を見て、作らない種類の動画を決めたことがある |
| 即戦力 | 最初の月は〇〇の動画を一本任せる予定です。△△と組みます |

「出る人が慣れていない状態で、話しやすい形で撮った」が、小さな会社の動画クリエイターで最も読まれる行動です。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

### 作品の求め方

作品は「あれば見せてほしい」にとどめます。「必須」にすると、会社の仕事で作ったものを公開できない人が離れます。見るときは、見た目の仕上がりではなく「誰に向けて、何のために作り、何が起きたか」「どの範囲を自分で担ったか」を聞きます。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「何の動画を、誰に、どこを担って」と同じ言葉で**：相手の作品の「誰に向けて、どの範囲を担い、何が起きたか」を読み、自社の種類と重ねる。仕上がりを褒めない。[デザイナー向けスカウト文面の型](/media/wt-scout-bunmen-rei-design/)
- **面談には、決める人と、出る人が出る**：経営者が決めるなら経営者が、出るなら出る人が出る。出る人が面談に出ると、「出る人がいる」が言葉でなく実際に伝わる
- **面談で話すのは、機材と出る人と直し方の話**：いまある機材を見せる、出る人を紹介する、前にボツにした動画と理由を話す、相手ならどう作るかを聞く
- **自社の動画を見せる**：いまの動画を見せて、「これをどう直すか」を聞く。現状を隠さない

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 種類を一つに、担う範囲、決める人と直す観点、見る数字、機材の実態を決める | 経営者（決める人） |
| 「なにを」（種類、見る人、担う範囲、いまの状態）の下書き | 人事が、いま動画を作っている人に聞いて書く |
| 「どうやって」（作る流れ、決め方、機材、出演者） | 決める人が話し、人事が書き、本人が確認 |
| 機材の一覧と、出る人の確認 | 経営者 |
| 「こんな人」を行動で書く、最初の月の予定 | 決める人と人事 |
| 面談 | 決める人と、出る人 |

一人目の動画クリエイターを採る募集では、いま外注か、経営者が自分で撮っていることが多くあります。その場合は、「いまは外注で作っていて、直す人がいない。機材は〇〇だけ。出るのは経営者。最初の月は△△の動画を一本。決めるのは経営者で、観点は□□」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、担う範囲と機材を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、種類の決定、決める人と直す観点、機材と出る人、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「動画クリエイターには、企画から編集まで幅広く任せると書いたほうが、何でもできる人が来る」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの動画クリエイターの募集と面談を見ていますが、「企画から編集まで一貫して」「幅広い表現力」と書いた募集記事より、「最初は〇〇の解説動画の撮影と編集。企画は△△と一緒に。機材は□□で、照明は無い。出るのは経営者」と範囲と実態を書いた募集記事のほうが、話を聞きに来る人の経験が合う傾向があります。動画クリエイターは、「一貫して」を読むと「全部一人で」を想像します。範囲と機材と出る人が書かれていれば、「実態が分かる会社」として読まれます。当社が案内するのは、「全般」「一貫して」を消し、担う範囲を書き、機材の一覧と出る人を隠さず書くことです。幅の広さで人は来ません。範囲と機材と出る人が書かれていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「動画制作全般」「発信を強化」で書く | 何を誰に、どこを担うかが分からず、読まれない | 種類と見る人と担う範囲を一つに |
| 機材の実態を書かない | 「自前を持ち込む前提か」と疑われる | 何があり、何が無く、予算があるかを書く |
| 出る人を書かない | 「出演者探しから一人で」を想像される | 誰が出るか。いないなら、いないと |
| 決める人と直す観点を書かない | 「好みで何度も直される」を想像される | 誰が、何を観点に。前のボツの例 |
| 作品を必須にする | 会社の仕事で作った人を落とす | 「あれば見せてほしい」にとどめる |
| 面談に決める人と出る人が出ない | 決め方と「出る人がいる」が伝わらない | 決める人と出る人が出る |

最も多いのは、「動画制作全般」と、機材と出る人の抜けです。

## まとめ

- 動画クリエイターが見ているのは、何の動画を誰に向けて作るか・企画・撮影・編集のどこを担うか・数字に責任を持つか・誰が決めて誰が直すか・機材と環境・出る人がいるか
- 書く前に、種類を一つに絞り、担う範囲、決める人と直す観点と前のボツの例、見る数字、機材の一覧と出る人を、決める人が決める。機材が無くても、出る人が未定でも、隠さない
- 「なにを」は種類と見る人と担う範囲といまの状態。「どうやって」は作る流れと決め方と機材と出演者を、実態で。前に作って起きたことと見られなかった例も
- 「こんな人」は経歴ではなく、「見る人に合わせて長さと切り口を変えた」「出る人が慣れていない状態で話しやすい形で撮った」の行動で。作品は「あれば」
- 面談には決める人と出る人が出て、機材を見せ、前にボツにした動画と理由を話し、自社の動画を見せてどう直すかを聞く

## よくある質問

### 機材がほとんど無く、これから揃える段階です。書くと来ませんか

隠すほうが、面談で分かって離れます。「機材はカメラ一台だけ。〇〇の予算で、来た人と一緒に選んで買う。編集の道具は△△を用意する」のように、あるものと、無いものと、買う予算と決め方を書きます。

### 社員が動画に出たがりません。それでも採れますか

採れますが、出る人を決めてから書きます。「出るのは、まず経営者。社員は募集してから。出る人がいない動画は、画面と声だけの解説動画で作る」のように、出る人と、出る人がいない場合の作り方を書きます。

### 動画クリエイターの募集記事は、御社に相談できますか

できます。当社は、募集記事の型、担う範囲と機材を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。種類の決定、決める人と直す観点、機材と出る人、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
