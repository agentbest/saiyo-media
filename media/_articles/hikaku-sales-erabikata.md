セールスを新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『セールス』の名前で募集し、『営業ではなく提案』『顧客の成功を支える』と書くと、学生は『営業と何が違うのか』『ノルマはあるのか』を確かめていて、面談で『数字はどう決まりますか』『届かないとき何が起きますか』に答えられないと『言葉を変えただけの営業』と読んで離れる。『コミュニケーション力』で絞ると、対象が多すぎて絞れない」という問題です。**結論から言うと、「セールス」の名前では、学生は営業との違いとノルマを確かめていて、「営業ではなく提案」の言葉では自分の仕事が読めません。媒体を選ぶ前に「誰に、何を、どう売っていて、数字がどう決まり、届かないとき何が起きるか」と「新卒が最初に持つ範囲（インサイドか、フィールドか、既存か）」を先に決め、「営業志望」と「コミュニケーション力」で絞らず、「断られて理由を聞いて変えた・数字を追って足りないとき何をしたか・相手の課題を聞いて提案を変えた」の行動で探します。送る型は行動で絞ってセールスの先輩の名義で、記事を置く型は届かなかった月の一日を、比べられる場は「セールスはきつい・数字」の体験談に対して企業ページに数字の決まり方と届かないとき何が起きるかを先に書きます。ノルマは隠しません。** 営業職全般の選び方は[営業職の採用媒体の選び方](/media/hikaku-eigyo-erabikata/)で書きました。この記事は、「セールス」の名前で募集する会社（SaaS・IT・スタートアップに多い）に絞ります。

## セールスの採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「セールス」「営業ではなく提案」で募集する | 「言葉を変えただけの営業」と読まれ、営業との違いが読めない | 誰に何をどう売るかと、数字の決まり方を職種名より先に書く。[Wantedlyでセールスを採る募集記事の書き方](/media/wt-sales-boshu/) |
| 「コミュニケーション力」「人と話すのが好き」で絞る | 対象が多すぎて絞れない。話せる学生と売れる学生は別 | 言葉を外し、行動で絞る。[OfferBoxで営業職志望の学生を見つける検索の考え方](/media/ob-eigyo-target/) |
| 数字の決まり方を書かない | 「ノルマは無い」と読んで来て、目標があると知って離れる | 目標の決まり方と、届かないとき何が起きるかを実態で書く |
| 新卒が最初に持つ範囲が書かれていない | 提案の像で来て、最初の年がインサイドか既存の対応だと離れる | インサイドか、フィールドか、既存かを時期で書く |
| 評価と給与への反映が書かれていない | 「数字が給与にどう効くか」が分からず、不安で辞退する | 反映の仕組みを、数値ではなく形で書く |

## 判断軸を、セールスに当てる

| 軸 | セールスでの見方 |
|---|---|
| 対象（誰に届くか） | 志望職種と「コミュニケーション力」を見ない。「断られて理由を聞いて変えた・数字を追って足りないとき何をしたか・相手の課題を聞いて提案を変えた」の行動で探す。営業志望だけでなく、企画・マーケ・エンジニア志望の中に、断られて変えた学生がいる。誰に何を売るかで優先する行動を変える |
| 型（送るか、来るか、比べられるか） | 送る型は、行動で絞ってセールスの先輩の名義で「あなたの断られて理由を聞いて変えた経験を読んで」と一人に書ける。来る型は、届かなかった月の一日と、足りないとき何をしたかと、提案を変えた話を記事で通年で。比べられる型は、「きつい」「数字」の体験談に対して、企業ページに数字の決まり方と届かないとき何が起きるかを先に書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | セールスの先輩が名義と面談を持つ時間。月末と四半期末の締めで埋まるので、面談の枠を締めの外に先に固定しないと運用が止まる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。セールスでは、「対象」を話せるかではなく断られて変えた行動で絞ることと、「運用工数」を締めの外に確保することが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「『営業』と書くと学生が避けるので、『セールス』『提案』『顧客の成功』と書けば来る」というものです。当社は3媒体すべての販売パートナーとして、セールスの採用の相談を受けますが、言葉を変えた会社は、承認は増えても、面談で「営業と何が違うのですか」「ノルマはありますか」と聞かれて答えが曖昧になり、「言葉を変えただけの営業」と読まれて離れます。学生が避けているのは「営業」の言葉ではなく、「数字がどう決まり、届かないとき何が起きるか」が分からないことです。当社が最初にお願いするのは、言葉を変えるのをやめ、「誰に、何を、どう売っていて、数字がどう決まり、届かないとき何が起きるか」を文面と掲載の最初に置くことです。「目標は〇〇の形で決まる。届かないとき、上司と原因を分けて次の月の動きを決める。給与への反映は△△の形」と書くと、承認は減りますが、面談で「思っていたのと違う」が減ります。絞る条件からは「コミュニケーション力」を消し、「断られて理由を聞いて変えた・数字を追って足りないとき何をしたか・相手の課題を聞いて提案を変えた」を「優先する条件」に上げます。

## 学生が、確かめること

- **誰に、何を、どう売るか**：誰が客で、何を売り、電話か訪問かオンラインか。「セールス」の名前では分からない
- **数字はどう決まるか**：目標の決まり方。新卒の最初の年の目標はあるか。「ノルマ」の言葉を避けても、学生は聞く
- **届かないとき何が起きるか**：詰められるか、原因を分けて次を決めるか。給与に効くか。最も多く辞退の理由になる
- **新卒が最初に持つ範囲**：インサイドか、フィールドか、既存の対応か。自分の客を持つのはいつからか
- **評価と給与への反映**：数字が給与にどう効くか。固定と変動の形。数値は会社の実態で

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 行動で絞り、セールスの先輩の名義で「あなたの断られて理由を聞いて変えた経験を読んで」と一人に書ける | 企業から送る型（OfferBox） | 志望と話せるかを見ずに、企画・マーケ・エンジニア志望の中から断られて変えた学生を探せる。[営業職向けのオファー文面](/media/ob-eigyo-offer-bunmen/) |
| セールスの先輩が、届かなかった月の一日と足りないとき何をしたかを自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「きつい」の像を、届かなかった月に何をしたかの記事で置き換える。[Wantedlyでセールスにスカウトを送る文面](/media/wt-sales-scout/) |
| 体験談があり、企業ページに数字の決まり方と届かないとき何が起きるかを先に書ける | 学生が並べて比べる場（ワンキャリア） | 「きつい・数字」の体験談に対して、入る前に決まり方と届かないときが分かる会社として読まれる。[ワンキャリアで営業職を募集するときの掲載とスカウト](/media/oc-eigyo-keisai/) |
| 数字の決まり方と届かないとき何が起きるかが、書けるほど整理されていない | どれも先ではない | セールスの責任者と決めてから。「ノルマは無い」と書いて目標があると、体験談に書かれる |
| 新卒が最初に持つ範囲が決まっていない | どれも先ではない | 提案の像で来て、最初の年で離れる |

どれか一つが正解ではなく、行動で絞れるか、先輩が書けるか、体験談があるかで、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせる**：文面で断られて変えた経験を読んだ一文を、記事で届かなかった月の一日を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **営業職全般・インサイドセールスと分ける**：[営業職の採用媒体の選び方](/media/hikaku-eigyo-erabikata/)、[インサイドセールスの採用媒体の選び方](/media/hikaku-inside-sales-erabikata/)。新卒がインサイドから入るなら、インサイドの募集として出す
- **面談の聞き方の型を、揃える**：「話せるかより、断られたとき理由を聞いたか、足りないとき何を変えたか、相手の課題で提案をどう変えたか」。明るさで決めない。[営業向けのスカウト文面](/media/kh-bunmen-eigyo/)
- **内定前に、届かなかった月を見せる**：数字の会議と、原因を分けた記録と、次の月に変えた動きを。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)
- **代行と組み合わせるなら、絞る作業と文面の下書きまで。読んで直すのはセールスの先輩**：[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「セールス」ではなく、誰に何をどう売り、数字がどう決まり、届かないとき何が起きるか

- **「セールス」「営業ではなく提案」「顧客の成功を支える」「コミュニケーション力」を消す**：言葉を変えただけの営業と読まれる
- **誰に何をどう売るかを、職種名に**：「〇〇（業種）の△△（役職）に、□□を、オンラインで提案して契約まで進めるセールス」
- **数字の決まり方を、最初に**：「目標は〇〇の形で決まる。新卒の最初の年の目標は△△」。「ノルマは無い」と書いて目標があると、体験談に書かれる
- **届かないとき何が起きるかを、実態で**：「届かなかった月は、上司と原因を分けて次の月の動きを決める。給与への反映は〇〇の形」。詰める文化があるなら、隠さない
- **新卒が最初に持つ範囲を、時期で**：「最初の〇か月はインサイドで見込み客を進める。自分の客を持つのは△か月目から。提案を一人でするのは□年目から」
- **評価と給与への反映を、形で**：「固定と変動の形は〇〇。数字が届いたときと届かないときの差は△△」。数値は自社の実態で。この記事では書かない

| 面談の枠を、締めの外に固定する | セールスの責任者。書く前に |
| 行動で絞る条件 | セールスの先輩が作り、人事か代行が絞る |
| 文面と記事 | 先輩が話し、人事が書き、本人が確認 |
| 名義と、オファーの一文 | セールスの先輩 |
| 面談 | 責任者と先輩。聞き方の型を揃えて。明るさで決めない |
| 辞退の理由の記録 | 人事。数字か、届かないときか、範囲か、他社かを分けて |

運用代行や代理店が支えられるのは、絞る条件の型、絞る作業、文面の下書き、記録の型までで、数字の決まり方の整理、範囲の決定、名義、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

セールスの採用で、掲載と文面を直した後に起きることを、当社は先にお伝えしています。「目標は〇〇の形で決まり、届かなかった月は原因を分けて次を決め、給与への反映は△△」と正直に書くと、承認とエントリーは減ります。減るのは、「ノルマは無い」と読んで来た学生です。その一方で、面談で「思っていたのと違う」が減り、内定後の辞退が減り、入社後に「聞いていた話と違う」と体験談に書かれることが減ります。減ったのを見て言葉に戻すと、承認は戻りますが辞退と離職も戻ります。当社が案内するのは、承認の数ではなく「面談で数字の話をして残った数」と「内定後の辞退の数」で効果を見ることです。見る場所を決めてから、掲載を直します。

## まとめ

- 「セールス」の名前では、学生は営業との違いとノルマを確かめていて、「営業ではなく提案」の言葉では読めない。言葉を変えるのをやめ、「誰に、何を、どう売っていて、数字がどう決まり、届かないとき何が起きるか」を先に書く
- 「新卒が最初に持つ範囲（インサイドか、フィールドか、既存か）」を先に決め、時期で書く
- 「営業志望」と「コミュニケーション力」で絞らず、「断られて理由を聞いて変えた・数字を追って足りないとき何をしたか・相手の課題を聞いて提案を変えた」の行動で、企画・マーケ・エンジニア志望も含めて探す
- 送る型（OfferBox）は行動で絞って先輩の名義で、記事を置く型（Wantedly）は届かなかった月の一日を、比べられる場（ワンキャリア）は「きつい・数字」の体験談に対して企業ページに数字の決まり方と届かないとき何が起きるかを先に
- 正直に書くと承認は減る。効果は面談で数字の話をして残った数と辞退の数で見て、言葉に戻さない

## よくある質問

### 「ノルマ」と書くと学生が来なくなりませんか

「ノルマ」の言葉を書く必要はありませんが、「目標がどう決まり、届かないとき何が起きるか」は書きます。学生が避けているのは言葉ではなく、分からないことです。「目標は〇〇の形。届かなかった月は原因を分けて次を決める」と書くと、それでも来る学生が残り、入社後に届かなかった月も残ります。「ノルマは無い」と書いて目標があると、体験談に書かれます。

### 営業との違いを、どう書けばよいですか

「提案型」「コンサルティング営業」の言葉では、学生には違いに見えません。違いは、誰に何をどう売るかの中身で書きます。「〇〇（業種）の△△に、□□を、オンラインで、契約まで一人で進める。他社の営業と違うのは〇〇」と、中身の一文で書きます。中身に違いが無いなら、言葉で違いを作らず、数字の決まり方と届かないとき何が起きるかで差を書きます。

### セールスの媒体選びは、御社に相談できますか

できます。当社は、絞る条件の型、絞る作業、文面の下書き、記録の型を支えられます。数字の決まり方の整理、範囲の決定、名義、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、セールスの媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
