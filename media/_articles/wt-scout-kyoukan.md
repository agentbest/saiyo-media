Wantedlyは「共感で人が集まる」媒体と言われるので、スカウト文面にも「私たちの想いに共感してくれる方を」「ビジョンを一緒に実現しませんか」と書きたくなります。ところが、想いや理念を文面に書いても、相手には「どの会社も同じことを書いている」としか映りません。**結論から言うと、スカウトで共感を伝えるとは、想いを語ることではなく、「相手がプロフィールに書いた『なぜ』を読んだ一文」と「自社の『なぜ』を判断の場面で書いた一文」を置き、その二つが重なる点を示すことです。共感は文面で起こすものではなく、相手の側で起きるもので、文面にできるのは、起きる材料を一文ずつ置くことだけです。想いの言葉は会社ページとストーリーに任せます。** この記事では、想いを書くと届かない理由、伝わる形、想いの言葉が同じになる理由、会社ページとストーリーに任せる部分、共感で誘った相手との面談、条件で誘う文面との違い、分担を整理します。共感の設計の全体は[「共感」を設計する考え方](/media/wt-kyoukan-sekkei/)で書きました。この記事は、スカウト文面に絞った話です。

## この作業の目的｜相手が「自分の考えと重なる」と気づく材料を置く

共感は、相手が「この会社の考え方は、自分の考えと重なる」と気づいたときに起きます。会社が「共感してください」と言っても起きません。

目的は、文面の中に、相手が気づく材料を置くことです。材料は2つで、「相手の考えを読んだ一文」と「自社の考えを場面で書いた一文」です。この2つが並んでいれば、相手は重なるかどうかを自分で判断できます。

## 想いを書くと、届かない理由

| 文面 | 相手からどう見えるか |
|---|---|
| 「私たちの想いに共感してくれる方を探しています」 | 想いの中身が無い。「共感して」と言われても |
| 「〇〇で世界を変える」「業界を変革する」 | 大きすぎて、日々の仕事と結びつかない |
| 「ミッション・ビジョン・バリューに共感する方」 | 会社ページに書いてあることを読まされる |
| 「熱い想いを持った仲間を」 | どの会社も書く。区別できない |
| 「私たちは〇〇を大切にしています」 | 大切にした結果、何をしたかが無い |
| 想いの段落が長い | 相手の一文が下に埋もれる |

共通するのは、「何をしたか」が無いことです。想いは、言葉で語られるより、判断の場面で伝わります。「〇〇を大切にしています」より、「〇〇のために、△△の依頼を断りました」のほうが、相手には想いが伝わります。

## 伝わる形｜相手の「なぜ」と、自社の「なぜ」を一文ずつ

| 要素 | 書き方 |
|---|---|
| 相手の「なぜ」を読んだ一文 | プロフィールに書かれた、仕事を選ぶ理由、やりたいことの理由、大切にしていること。「『〇〇のために△△をやりたい』と書かれていたのを読んで」。本人の言葉で |
| 自社の「なぜ」を判断の場面で書いた一文 | 「うちは、〇〇のために、先月△△を断りました」「〇〇を優先して、□□の進め方を変えました」。理念ではなく、最近の判断 |
| 重なる点 | 「あなたの『〇〇のために』と、うちの判断は、同じ方向を向いていると思い」。押しつけず、「思い」で止める |

「自社の『なぜ』を判断の場面で」が要点です。会社ページに書いた理念を写すのではなく、その理念で最近何を決めたかを一文で書きます。判断の場面は、ストーリーに書いたものがあれば、そこから取ります。書き方は[代表の考えを書く方法](/media/wt-story-daihyo/)と[カルチャーを伝える書き方](/media/wt-story-culture/)で書きました。

相手の「なぜ」がプロフィールに書かれていない場合は、この形は使えません。無理に共感の形にせず、仕事の場面で重ねる通常の型を使います。通常の型は[スカウト文面の書き方](/media/wt-scout-bunmen/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは共感型だから、スカウトでも想いを強く書くべきだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、想いの段落が長い文面ほど、返信が来ません。相手は、想いの言葉を読み比べる材料を持っていないので、どの会社の想いも同じに見えます。返信が来る文面は、想いの言葉がほとんど無く、代わりに「先月、〇〇を断った」「△△を優先して進め方を変えた」という判断の一文があります。当社が共感を伝える文面を整えるとき、最初にやるのは、「想い」「情熱」「ビジョン」「共感」の言葉を全部消し、代表か責任者に「最近、なぜあの判断をしましたか」と聞いて、その一文を入れることです。共感は、語るものではなく、判断で見せるものです。

## 会社ページとストーリーに、任せる部分

文面に書かない想いは、会社ページとストーリーに任せます。

- **会社の「なぜ」の全体**：会社ページの「なぜやるのか」。文面からは「詳しくは会社ページに」で誘導。書き方は[ミッションの書き方](/media/wt-kaisha-page-mission/)
- **価値観の場面**：会社ページの価値観を場面で書いた部分
- **判断の場面の詳しい話**：ストーリー。文面で一文だけ触れ、「この話はストーリーに書いています」と誘導
- **社員の「なぜ」**：入社エントリーや社員インタビュー。「一緒に働く人」として

文面は、相手を会社ページとストーリーに連れて行くためのものです。共感が起きるのは、そこを読んだあとです。文面で全部を伝えようとすると、長くなり、読まれません。

## 共感で誘った相手との、面談で守ること

共感の形で誘った相手は、面談で「なぜ」の話を聞きに来ます。

- **文面に書いた判断の場面を、話せる人が出る**：判断に関わった人か、その判断を自分の言葉で説明できる人
- **判断の理由を、飾らずに話す**：「実は迷った」「反対もあった」まで話すと、本物と分かる
- **相手の「なぜ」を、長く聞く**：「〇〇のためにと書かれていましたが、どういう経緯で」。評価ではなく興味として
- **会社の理念を、面談で改めて語らない**：文面と会社ページで読んでいる。面談は、その先の話
- **重ならないと分かったら、それも正直に**：「その点は、うちは違う考えかもしれません」。無理に合わせない

「重ならないと分かったら正直に」が、共感で誘った相手との面談で特に要ります。共感で来た相手に、面談で無理に合わせると、入社後にずれます。面談の型は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

## 条件で誘う文面との違い

| | 条件で誘う文面 | 共感で誘う文面 |
|---|---|---|
| 相手の何を読むか | 経験、いまの仕事 | 仕事を選ぶ理由、大切にしていること |
| 自社の何を書くか | 仕事の場面、条件（募集記事へ） | 判断の場面 |
| 重なる点 | 経験が活きる仕事 | 考えの方向 |
| 向く相手 | 転職を決めていて、仕事の中身で選ぶ人 | 転職を決めていない人、会社の考え方で選ぶ人 |
| 面談で話すこと | 仕事の中身 | 判断の理由と、相手の「なぜ」 |

どちらが良いかではなく、相手のプロフィールで決めます。「なぜ」が書かれている相手には共感の形、書かれていない相手には仕事の場面の形です。共感型と条件型の媒体の違いは[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。

## 避ける言葉

| 避ける言葉 | 代わりに |
|---|---|
| 想い、情熱、熱量 | 最近の判断の場面 |
| ビジョン、ミッションに共感 | 「〇〇のために、△△を決めた」 |
| 世界を変える、業界を変革 | 誰の、どんな困りごとを、どう変えるか |
| 共感してくれる方 | 相手の「なぜ」を読んだ一文 |
| 大切にしています | 大切にした結果、何をしたか |
| 仲間、家族のような | 誰と、どう決めているか |

「共感」という言葉そのものも、文面には書きません。共感は相手の側で起きるもので、会社が「共感して」と書くと、押しつけになります。

## 自社の「なぜ」の一文を、用意する

文面の型に入れる「自社の『なぜ』の判断の場面」は、募集ごとに一つ用意します。

1. **代表か責任者に、「最近、なぜあの判断をしたか」を聞く**：断ったこと、止めたこと、変えたこと、先に始めたこと
2. **その判断が、会社の「なぜ」とどうつながるかを一文にする**：「〇〇のために、△△を断った」
3. **ストーリーに書いてあれば、そこから取る**：無ければ、ストーリーとしても書く候補になる
4. **募集の仕事と関係のある判断を選ぶ**：関係の無い判断は、文面で浮く
5. **型に入れる**：「変えない部分」として。相手の「なぜ」を読んだ一文は、毎回書く

自社らしさを判断の型から拾う方法は[自社らしさを言葉にする方法](/media/wt-kigyou-rashisa/)で書きました。そこで拾った判断の型が、そのまま文面の一文になります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 自社の「なぜ」の判断の場面を一文にする | 代表か責任者（人事が聞いて書く） |
| 型に入れる | 人事 |
| プロフィールの「なぜ」を読み、一文を書く | 読んで書く人 |
| 共感の形か、仕事の場面の形かを選ぶ | 読んで書く人（プロフィールで） |
| 面談で判断の理由を話す | 判断に関わった人か、説明できる人 |
| 重ならないときに正直に伝える | 面談に出る人 |

運用代行や代理店が支えられるのは、伝わる形の型、避ける言葉のチェック、判断の場面を聞く質問、会社ページとストーリーへの誘導の整理までで、判断の場面を話すこと、相手の「なぜ」を読んで書くこと、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyのスカウトで共感を伝える形を支えるとき、型、避ける言葉、聞く質問、誘導の整理は当社が出せます。ただし、「最近、なぜあの判断をしたか」の一文は、当社には作れません。当社が会社の理念から「らしい判断」を想像して書くと、それは当社の言葉で、面談でその判断に関わった人が話す内容とずれます。当社が最初にお願いするのは、代表か責任者に、最近の判断を一つ、理由と一緒に話してもらうことです。その一文があれば、当社は型に組み込み、会社ページやストーリーと揃えられます。無ければ、文面は「想いに共感してくれる方」に戻り、どの会社とも同じになります。共感は、当社が書くものではなく、社内の判断から出てくるものです。

## まとめ

- 共感は文面で起こすものではなく、相手の側で起きるもの。文面にできるのは、材料を一文ずつ置くこと
- 材料は、相手がプロフィールに書いた「なぜ」を読んだ一文と、自社の「なぜ」を最近の判断の場面で書いた一文。重なる点は「思い」で止める
- 想い・情熱・ビジョン・共感・大切にしています、はどの会社も同じに見え、届かない。判断で見せる
- 想いの全体は会社ページとストーリーに任せ、文面からはそこへ誘導する
- 共感で誘った相手との面談は、判断に関わった人が出て、飾らず話し、重ならなければ正直に伝える。相手の「なぜ」が無ければ、仕事の場面の型を使う

## よくある質問

### 自社の「なぜ」が、まだ判断の場面で言えるほど固まっていません

固まっていない状態で、想いの言葉を文面に書くと、面談でずれます。その場合は、共感の形を使わず、仕事の場面で重ねる通常の型を使います。「なぜ」を判断の型から拾う作業を、社内で先に行います。拾い方は[自社らしさを言葉にする方法](/media/wt-kigyou-rashisa/)で書きました。

### 相手のプロフィールに、仕事を選ぶ理由が書かれていません

共感の形は使えません。「いま何をしているか」「やりたいこと」から、仕事の場面で重ねる型を使います。無理に「あなたの想いに」と書くと、読んでいないと分かります。共感は、相手が「なぜ」を書いているときにだけ、その形で伝えます。

### スカウトで共感を伝える文面は、御社に相談できますか

できます。当社は、伝わる形の型、避ける言葉のチェック、判断の場面を聞く質問、会社ページとストーリーへの誘導の整理を支えられます。判断の場面を話すこと、相手の「なぜ」を読んで書くこと、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
