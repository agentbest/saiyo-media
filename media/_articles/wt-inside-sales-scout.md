Wantedlyでインサイドセールスにスカウトを送るとき、最初にぶつかるのは「肩書で検索して『架電のご経験を活かして』と送っているのに、返信が来ない。来ても、面談で『渡した後どうなったか分かりますか』『その先の道はありますか』と聞かれて止まる」という問題です。**結論から言うと、インサイドセールスへのスカウトは、肩書や架電経験で相手を選ぶのではなく、先に自社の見込み客の来方の実態と渡す基準と渡した後の戻りと次の道を決め、「近い来方の見込み客に、何かをもとに連絡し、渡した後に基準を見直した経験を書いている人」を選び、その人の「渡した後どうしたか」を読んだ一文から、渡す基準と戻る仕組みで誘います。** この記事では、インサイドセールスがスカウトで見ているもの、送る前に決めること、誰に送るか、文面に書くこと、返信後の面談、社内の分担、やりがちな失敗を整理します。文面の3段の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)、セールス全般のスカウトの考え方は[セールスにスカウトを送る文面の考え方](/media/wt-sales-scout/)、募集記事は[インサイドセールスを採る募集記事の書き方](/media/wt-inside-sales-boshu/)で書きました。

## インサイドセールスがスカウトで見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰から来たか | 営業の責任者か、渡す先の人か、人事か。送り主が渡した後を見ている人か |
| 自分の仕事の何を読んだか | 肩書で検索しただけか、「何をもとに連絡し、渡した後どうしたか」を読んだか |
| 見込み客の来方 | 問い合わせや資料請求か、名簿か。「自分で一から探す」なら別の仕事。文面で分かるか |
| 渡した後の戻り | 渡した見込み客がどうなったかが戻る仕組みがあるか。文面で分かるか |
| 数字の測り方 | 連絡の数だけで評価されるのか、渡した先で決まった数を見るのか |
| 次の道を盛っていないか | 「将来はフィールドセールスへ」が、実態か、釣りか |

「渡した後の戻り」と「次の道」は、盛っていれば入社後に分かります。

## 送る前に決めること｜来方の実態、渡す基準、戻り、次の道

送る前に、社内で四つを決めます。決め方は[インサイドセールスを採る募集記事の書き方](/media/wt-inside-sales-boshu/)で書きました。

- **見込み客の来方の実態**：問い合わせ・資料請求・来場・名簿・過去の失注の割合。相手の動きが見える情報があるか。盛らない前提で
- **渡す基準**：「〇〇と△△が確認できたら渡す」。無いなら、無いと書き、一緒に作ると
- **渡した後の戻り**：誰が、いつ、何を戻すか。無いなら、これから作ると
- **次の道**：決まっているか。決まっていないなら、決まっていないと

「最初の月に任せること」を一つ（「〇〇の資料請求への対応から」「過去の失注への再連絡から」）決めると、文面の2段目になり、送る相手を「それができる人」に絞れます。

## 誰に送るか｜肩書や業界ではなく、来方の種類と、渡した後に何をしたかの重なり

肩書が「インサイドセールス」で一致していても、扱ってきた見込み客の来方が違えば、面談で「うちの仕事とは違う」になります。問い合わせを受けて連絡してきた人と、名簿に一から連絡してきた人では、仕事の中身が別です。選ぶ基準は、「近い来方の見込み客に、何かをもとに連絡し、渡した後に基準を見直した経験を書いているか」です。

| 読む箇所 | 重なりの見方 |
|---|---|
| 見込み客の来方 | 問い合わせ・資料請求か、来場か、名簿か、失注か。自社の来方と近いか。ここが最も重なりが要る |
| 何をもとに連絡したか | 相手の動き（資料を見た、来場した）を見て切り出しを変えたか。動きが見えない中で工夫したか |
| 渡した後に何をしたか | 「渡した先で決まらなかったので、渡す基準を見直した」「戻りを見る場を作った」が書かれているか。自社の「最初に任せること」と重なるか |
| 渡す先との関係 | 外に出る営業と日々やり取りしていたか、投げて終わりだったか。自社の関係と合うか |
| 次に何をしたいか | この仕事を専門にしたいか、外に出る営業に進みたいか、仕組みを作りたいか。自社の次の道と合うか |

「渡した後に何をしたか」が要点です。自社に戻る仕組みが無く、これから作るなら、この記述のある人を優先します。

### 肩書と業界の幅に配慮する

インサイドセールスの仕事は、「インサイドセールス」「テレアポ」「営業アシスタント」「カスタマーサポートで見込み客を見つけていた人」「営業で自分の見込み客を自分で温めていた人」など、違う肩書で書かれています。肩書で検索すると、来方が合う人を落とします。「何をもとに連絡し、渡した後どうしたか」で読み、肩書と業界は「あればよい条件」に置きます。絞り方の基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「インサイドセールスは未経験でもできるので、幅広く送れば返信が来る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトを見ていますが、インサイドセールスに幅広く送った文面は、ほとんど開かれません。「未経験歓迎」「明るい方」の文面は、「誰でもいい＝評価されない＝次の道が無い」と読まれます。関係があるのは、「自分が渡した後に何をしたかを読んでくれたか」と、「渡す基準と戻る仕組みが文面で分かるか」の二つです。戻る仕組みが無くても、「いまは無い。週に一度、渡した先と一緒に見る場を作るところから」と書かれていれば、「投げて終わりにしない会社」として返信が来ます。当社が対象を組み直すとき、最初にやるのは、幅広く送るのをやめ、「渡した後に基準を見直した経験を書いている人」で並べ直し、渡す基準と戻る仕組みを文面の最初のほうに入れることです。

## 文面に書くこと

文面の型（相手の一文→自社の場面→話す場の案内）は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)に書いたので、ここではインサイドセールス特有の要点だけを書きます。

- **相手の一文は、渡した後にしたことで**：「渡した先で決まらなかったので渡す基準を見直されたと書かれていたのを読んで」「資料のどこを見たかで切り出しを変えられた点を読んで」。肩書や連絡の数ではなく、動き方
- **見込み客の来方を、最初のほうで**：「資料請求と来場が〇〇の割合で、相手の動きが見えます」「名簿への連絡が中心で、相手の動きは分かりません」。盛らない
- **渡す基準と戻りを、一文で**：「〇〇と△△が確認できたら□□に渡し、週に一度、決まったか決まらなかったかを一緒に見ます」。無いなら「作るところから」
- **数字の測り方を、一文で**：「連絡の数ではなく、渡した先で決まった数を見ます」。連絡の数だけなら、そう書く
- **次の道を、盛らずに**：「外に出る営業に進む道があります」「決まっていません。この仕事の仕組みを作った人が次を決めます」
- **話す場は、営業の責任者と渡す先の人と**：「営業の責任者の〇〇と、渡す先の△△が、来方と戻りの実態を隠さず話します。転職を決めていなくても構いません」

相手の前の会社の仕組みを評価しません。

## 返信後の面談｜渡す先の人が出る

| 話すこと | 中身 |
|---|---|
| 見込み客の来方の実態 | 割合、相手の動きが見える情報、道具。文面と同じことを、責任者本人が話す |
| 渡す基準と、戻りの仕組み | 有るか無いか。無いなら、どう作るか。渡す先の人が出て話す |
| 相手ならどう進めるか | 最初に任せることについて、相手の考えを聞く。ここが長い面談ほど次につながる |
| 数字の測り方と、次の道 | 何で評価するか。次の道の実態。責任者本人が話す。「聞いていない」を出さない |
| 相手の仕事の話 | 何をもとに連絡し、渡した後どうしたか、何を仕組みにしたか。聞く時間を長く |

面談には、営業の責任者と、渡す先の人が出ます。渡す先の人が出ると、「渡した後どうなるか」が言葉でなく実際に伝わります。面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

選考に進むとき、模擬の連絡などの課題を出すなら、面談のときに「課題がある」「どのくらいの時間がかかるか」を先に伝えます。伝え方は[カジュアル面談から選考に進むときの伝え方](/media/wt-scout-senkou-ikou/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 来方の実態、渡す基準、戻り、次の道、最初に任せることを決める | 営業の責任者 |
| 「来方の種類と、渡した後にしたこと」で対象を並べ直す | 人事（営業の責任者が基準を伝える） |
| 相手の動き方を読み、一文を書く | 営業の責任者か現場（または人事が下書きし、本人が確認） |
| 渡す先との関係の確認 | 渡す先の人 |
| 型、送信、返信対応、台帳 | 人事 |
| 面談 | 営業の責任者と、渡す先の人 |

一人目のインサイドセールスを採るスカウトでは、いま外に出る営業が自分で連絡していることが多くあります。その場合は、その営業が相手のプロフィールを読み、「一人目で、いまは私が自分で連絡している。渡す基準は一緒に作る。渡した後は私が直接戻す」と正直に文面に書きます。

運用代行や代理店が支えられるのは、対象の並べ直しの基準づくり、型、避ける言葉のチェック、募集記事との整合の確認までで、来方の実態、渡す基準と戻りの決定、相手の動き方を読んだ一文、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

インサイドセールスにスカウトを送る前に、先に決めておかないと効果が出ないのは、「次の道を、盛らずに一文にすること」です。当社がWantedlyのインサイドセールス向けスカウトを支えるとき、「将来はフィールドセールスへ」と書きたいが、実際に進んだ人はまだいない、という会社が多くあります。書けば返信は増えるかもしれませんが、入社後に道が無いと分かった人は、この仕事ごと離れます。逆に、「次の道は決まっていない。この仕事の仕組みを作った人が、次を決める」と書いた会社は、返信の数は減っても、仕組みを作ることに関心がある人が来て、その人が実際に次の道を作ります。当社が最初にお願いするのは、対象の絞り込みではなく、営業の責任者に「この仕事の先に、いま実際に何があるか」を、無ければ無いと、一文で言ってもらうことです。その一文が、文面の信用と、来る人の種類を決めます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 肩書や架電経験で相手を選ぶ | 面談で「来方が違う」「仕組みが違う」 | 来方の種類と、渡した後にしたことで選ぶ |
| 「未経験歓迎」で幅広く送る | 「誰でもいい」と読まれ、開かれない | 渡した後を見る動き方の人に絞る |
| 見込み客の来方を盛る | 面談で違いが分かり、信用を失う | 割合で、盛らずに書く |
| 渡す基準と戻りを書かない | 「投げて終わり」を想像される | 有るなら書く。無いなら、作ると書く |
| 次の道を盛る | 入社後に分かり、離れる | 無いなら無いと書く |
| 面談に渡す先の人が出ない | 「渡した後」が伝わらない | 渡す先の人が出る |

最も多いのは、最初の「肩書で選ぶ」と、次の道の盛りです。

## まとめ

- インサイドセールスは、誰から来たか・自分の仕事の何を読んだか・見込み客の来方・渡した後の戻り・数字の測り方・次の道を盛っていないか、を文面の段階で見ている
- 送る前に、来方の実態、渡す基準、渡した後の戻り、次の道を、営業の責任者が決める。無いものは無いと書く前提で
- 誰に送るかは、肩書や業界ではなく、来方の種類と「渡した後に何をしたか」の重なりで。「渡した先で決まらなかったので基準を見直した」を書いている人を優先し、肩書は「あればよい条件」に
- 文面には、相手の動き方を読んだ一文、来方の割合、渡す基準と戻り、数字の測り方、次の道を盛らずに。「未経験歓迎」「架電経験を活かして」を書かない
- 面談は営業の責任者と渡す先の人が出て、渡した後に実際に起きたことと次の道の実態を話す

## よくある質問

### 肩書が「インサイドセールス」の人が、検索でほとんど出ません

肩書で絞る必要はありません。この仕事は、「テレアポ」「営業アシスタント」「サポートで見込み客を見つけていた人」「営業で自分の見込み客を温めていた人」が担っていることが多くあります。「何をもとに連絡し、渡した後どうしたか」で読み、その人に「〇〇で渡す基準を見直されたと書かれていたのを読んで」と送ります。

### 渡した後の戻りも次の道も無い状態です。文面にそう書くと開かれませんか

盛るほうが、入社後に分かって離れます。「渡した後の戻りは、いまは無い。週に一度、渡す先の〇〇と見る場を作るところから。次の道は決まっていない。仕組みを作った人が次を決める」と、無いことと、これから作ることを分けて書きます。

### インサイドセールス向けのスカウトの対象の絞り込みは、御社に相談できますか

できます。当社は、対象の並べ直しの基準づくり、文面の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。来方の実態、渡す基準と戻りの決定、相手の動き方を読んだ一文、面談は、社内の営業の責任者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
