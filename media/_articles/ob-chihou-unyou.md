地方に本社があり、勤務地もその地域。「地方だから学生が来ない」「都市部の学生に送っても承認されない」と感じていて、OfferBoxを使うか迷っている、または使っていて反応が薄い。**結論から言うと、「地方だから来ない」のではなく、学生を出身地域と希望で層に分けていないから届いていません。最初に決めるのは、学生を「地元に残りたい層」「地元に戻りたい層」「都市部から来る層」に分けること、地元に残る層と戻る層を先に送ること、都市部の学生には「来られる材料」が揃ってから送ること、地元の大学との関係を作ること、勤務地と暮らしの実態を隠さないこと、名義を地元で働く若手にすることです。** この記事では、地方に本社がある会社が割ける時間と人、層の分け方、最初に決めること、文面の書き方、運用の分担、やりがちな失敗を整理します。都市部の学生に届くための材料と移動の負担は[地方本社の会社がOfferBoxで都市部の学生に届くには](/media/ob-chihou-honsha/)、地方の学生への送り方は[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)で書きました。この記事は、その前段の「最初に決めること」を扱います。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 人事が少なく、経営者や総務が兼務 | 承認への当日返信が落ちる |
| 地元の大学との関係はあるが、都市部の大学とはない | 都市部の学生に、会社が知られていない |
| 「地方だから」と最初から諦めている | 送る相手を絞らず、都市部の学生に一律に送って承認されない |
| 勤務地と暮らしの実態を、文面に書いていない | 承認した学生が、面談で「住まいは」「車は」で止まる |
| 面談を本社で行う | 都市部の学生の移動の負担で、面談の前に離れる |
| 出身地域を見ずに送る | 地元出身で戻りたい学生に、届いていない |

地方に本社がある会社がOfferBoxに割ける時間は、都市部の会社と変わりません。変わるのは、送る相手の層の分け方と、暮らしの実態を先に渡す準備です。時間の使い方は、「地元に戻りたい学生を見つける検索」に寄せます。

## 学生を、出身地域と希望で三つの層に分ける

| 層 | 記述に書かれていること | 送る順 | 文面の中心 |
|---|---|---|---|
| 地元に残りたい層 | 地元の大学で、地元で働きたい | 最初に | 地元で、この仕事を、誰と |
| 地元に戻りたい層 | 都市部の大学で、出身地は自社の地域。「戻りたい」「地元に貢献」 | 二番目に | 戻ったあとの暮らしと仕事。「戻る」を後押しする一文 |
| 都市部から来る層 | 都市部の出身で、地域に縁がない | 材料が揃ってから | 来られるかを判断できる材料。暮らし、移動、住まい |

- **三つの層に、同じ文面を送らない**：「地方で働く魅力」の一律の文面は、どの層にも刺さらない
- **出身地域と希望は、記述から読む**：出身地、地元への言及、「戻る」「離れる」の言葉。読まずに送らない
- **層ごとに、承認率を分けて見る**：都市部から来る層の承認率が低いのは前提。地元の層と混ぜない

## 最初に決めること

1. **地元に残りたい層と、戻りたい層を、先に送る**：会社を知っている、または地域を知っている学生。承認の理由が「地元」にある。検索の組み方は[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
2. **都市部の学生に送るのは、「来られる材料」が揃ってから**：暮らし、住まい、移動、交通費の扱い。材料は[地方本社の会社がOfferBoxで都市部の学生に届くには](/media/ob-chihou-honsha/)
3. **地元の大学との関係を作る**：求人票、キャリアセンター、学内説明会。地元に残りたい層は、学校経由でも来る。[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)
4. **勤務地と暮らしの実態を、文面と採用サイトに隠さず書く**：勤務地、車が要るか、住まいの扱い、地域の暮らし。隠すと面談で止まる。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)
5. **名義を、地元で働く若手にする**：戻ってきた社員がいれば、その社員。「戻って働いている人」が、戻りたい層に最も届く
6. **面談は、オンラインを基本にする**：都市部の学生を本社に呼ばない。[OfferBoxの学生とオンラインで会うときの進め方](/media/ob-mendan-online/)
7. **台帳に、出身地域と希望の列を持つ**：層ごとの承認率と、面談まで来た近い学生の数を見る

### エージェントベストの見解

相談で最も多い思い込みは、「地方に本社があるので、OfferBoxで送っても学生は来ない」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、地方本社の会社の承認と面談を見ていますが、「来ない」と言う会社の送り先を見ると、都市部の大学の学生に、出身地域を見ずに、「地方で働く魅力」の一律の文面を送っています。同じ会社で、記述に「出身は〇〇県」「いずれ地元に戻りたい」と書いている学生に絞って、戻ってきた社員の名義で送ると、承認の理由が「地元」になり、面談で離れません。地方に本社があることは、都市部から来る層には壁ですが、戻りたい層には理由です。当社が地方本社の会社の検索条件を組むときは、「地方だから」を一度外して、出身地域と希望の記述で層を分けることから始めます。来ないのではなく、届く層に送っていないだけのことが多いです。

## 文面の書き方｜層ごとに中心を変える

| 層 | 書く | 書かない |
|---|---|---|
| 地元に残りたい層 | 地元で、この仕事を、誰と。最初の年の場面 | 「地方で働く魅力」の一般論 |
| 地元に戻りたい層 | 戻ってきた社員の名義で、「戻ったあとの仕事と暮らし」。「戻る」を後押しする一文 | 「都会に負けない」の比較 |
| 都市部から来る層 | 来られるかを判断できる材料。暮らし、住まい、移動、交通費の扱い | 材料なしの「一度来てみてください」 |

- **勤務地を、最初に書く**：後ろに書くと「隠した」と読まれる
- **暮らしの実態は、良い面も不便な面も**：「車が要る」「最寄りの駅から遠い」を書いたうえで、住まいの扱いを書く。[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)
- **給与で勝負しない会社は、条件を隠さず、仕事と暮らしで**：[給与水準を強みにできない会社のOfferBoxの伝え方](/media/ob-kyuuyo-hikui/)
- **知名度がない会社は、会社名ではなく仕事の場面で**：[知名度がない会社がOfferBoxで学生に届くには](/media/ob-chimeido-nai/)
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)

## 送る時期と、地元の大学との関係

- **地元に残りたい層は、地元の大学の予定に合わせる**：学内説明会、推薦の仕組み。学校に確認する
- **戻りたい層は、都市部の就職活動の時期に合わせる**：都市部の大学にいるので、動く時期は都市部
- **都市部から来る層は、材料が揃ってから、少なく送る**：承認率が低い前提で、面談に出られる数で
- **地元の大学には、結果を返す**：翌年も候補に入る。返す範囲は学生の同意と個人情報の扱いの範囲で
- **送る時期の考え方**：[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 三つの層の「こんな人」と、送る順 | 人事と経営者 |
| 出身地域と希望を記述から読み、検索する | 人事、または代行 |
| 勤務地と暮らしの実態を、文面と採用サイトに | 人事と、地元で働く若手 |
| 文面の下書き、送信、一次返信 | 人事、または代行 |
| 文面の最終確認、名義、面談（オンライン） | 地元で働く若手 |
| 地元の大学との関係、結果の報告 | 人事 |
| 台帳に出身地域と希望の列を持ち、層ごとに見る | 人事（代行と）。[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/) |
| 交通費と宿泊の扱いの判断 | 経営者 |

- **人事が少ない会社は、検索・下書き・送信・一次返信を外に出す**：地元の若手の時間を、確認と面談に。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)

運用代行や代理店が支えられるのは、層の分け方の型、出身地域と希望の読み取り、文面の型、検索・下書き・送信・一次返信、台帳の型までで、送る順の決定、暮らしの実態の開示、地元の大学との関係、面談、交通費の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「地元に残りたい層」と「戻りたい層」に送っておかないと、都市部の学生に材料を揃えて送っても効果が出ません。当社はOfferBoxの運用代行で地方本社の会社の送る順を企業と一緒に決めますが、「都市部の学生を採りたい」から始める会社が多く、地元の層に送っていないことがあります。地元の層は、会社か地域を知っていて、承認の理由が「地元」にあり、面談で離れにくく、承認への返信と面談の型を作る練習になります。この層で型ができてから、都市部の学生に「来られる材料」を揃えて送ると、材料の中身が、地元の層の面談で聞かれたことから決まります。順番は、地元に残る層、戻る層、都市部から来る層で、逆にすると、材料が揃わないまま都市部の学生に送り、承認されずに「地方だから」で終わります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「地方で働く魅力」の一律の文面を送る | どの層にも刺さらない | 層ごとに中心を変える |
| 出身地域を見ずに都市部の学生に送る | 戻りたい層に届かず、縁のない学生に届く | 記述から出身と希望を読む |
| 勤務地と暮らしを後ろに書く、または書かない | 「隠した」と読まれ、面談で止まる | 最初に、良い面も不便な面も |
| 本社の人事の名義で送る | 「地元で働く人」が見えない | 戻ってきた社員か地元の若手 |
| 面談を本社で行う | 都市部の学生が移動の負担で離れる | オンラインを基本に |

最も多いのは、一つ目です。「地方だから来ない」の思い込みで、届く層を分けずに一律に送ります。

## まとめ

- 「地方だから来ない」のではなく、層を分けていないから届かない。学生を「地元に残りたい・戻りたい・都市部から来る」の三つに分ける
- 地元に残る層と戻る層を先に送り、都市部の学生には「来られる材料」が揃ってから少なく送る。層ごとに承認率を分けて見る
- 出身地域と希望を記述から読む。勤務地と暮らしの実態を、最初に、良い面も不便な面も書く
- 名義は戻ってきた社員か地元で働く若手。面談はオンラインを基本に。地元の大学との関係を作り、結果を返す
- 台帳に出身地域と希望の列を持つ。検索・下書き・送信・一次返信は外に出し、地元の若手の時間は確認と面談に

## よくある質問

### 戻ってきた社員がいません。名義は誰にしますか

地元で働く若手の名義にし、文面に「私は〇〇の出身で、地元で働いています」の一文を入れます。戻りたい層には「戻った人」が最も届きますが、「地元で働いている人」でも、都市部の人事の名義より届きます。地元出身でない若手なら、「〇〇から来て、この地域で働いています」と正直に書きます。

### 都市部の学生に送るのは、諦めるべきですか

諦める必要はありませんが、順番はあとです。地元の層で承認と面談の型を作り、面談で聞かれた「暮らし」「住まい」「移動」の質問から材料を揃え、材料が揃ってから、都市部の学生に少なく送ります。承認率が低い前提で、面談に出られる数だけ送ります。

### 地方に本社がある会社のOfferBox運用は、御社に相談できますか

できます。当社は、層の分け方の型、出身地域と希望の読み取り、文面の型、検索・下書き・送信・一次返信、台帳の型を支えられます。送る順の決定、暮らしの実態の開示、地元の大学との関係、面談、交通費の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
