Wantedlyで経理の募集記事を出したとき、最初にぶつかるのは「『経理業務全般』『簿記資格をお持ちの方』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『決算はどこまで社内でやるのですか』『一人ですか』『数字は経営に使われていますか』を聞かれて答えられない」という問題です。**結論から言うと、経理の募集記事は、「経理業務全般」ではなく「社内でどこまでやり、会計事務所に何を出し、決算にどこまで関わり、一人か複数か、出した数字が経営の判断にどう使われるか」を書き、募集記事を書く前に社内の範囲と決算の関わり方と数字の使われ方を決めておきます。** この記事では、経理が募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)、スカウト文面の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)で書きました。新卒の経理は[OfferBoxで経理・財務を採るオファー文面の書き方](/media/ob-keiri-offer-bunmen/)で書きました。

## 経理が募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 社内でしている範囲と、会計事務所に出している範囲 | 仕訳まで社内か。月次の締めは社内か。決算は事務所か。どこからどこまでが自分の仕事か |
| 決算にどこまで関わるか | 資料を集めて渡すだけか、自分で組むか。いつから関われるか |
| 一人経理か | 一人なら、誰が確認するか。休めるか。前任者はいるか。引き継ぎがあるか |
| 数字が経営に使われるか | 出した数字を、経営者が見て何かを決めるか。締めて終わりか |
| 仕組み化の実態 | 手作業がどのくらいか。道具は何か。紙が残っているか |
| 締めの時期の負荷 | 月末月初、決算期に、どのくらいの負荷か。隠さず書いてあるか |
| 経営者との距離 | 数字を経営者に直接説明するか。間に誰かいるか |

「社内の範囲」と「一人経理か」が、経理に特有の点です。「経理業務全般」の一語では、ここが分かりません。

## 書く前に決めること｜社内の範囲、決算の関わり、数字の使われ方、仕組みの状態

| 決めること | 選択肢 |
|---|---|
| 社内でしている範囲 | 仕訳／月次の締め／年次の決算／税務。どこまで社内で、どこから会計事務所か |
| 決算の関わり方 | 資料を渡す／一部を組む／自分で組んで事務所が確認する。いつから任せるか |
| 一人か複数か | 一人なら、誰が確認するか（経営者、事務所）。休むときどうするか。前任者と引き継ぎ |
| 数字の使われ方 | 経営者が見て決めるか。会議で使われるか。締めて終わりか |
| 仕組みの状態 | 道具の名前。手作業の残り具合。紙の有無。変えたいところ |
| 締めの時期の負荷 | 月末月初と決算期の実態。数値を書くなら確認したものだけ |
| 最初の月に任せること | 月次の一部の引き継ぎか、仕訳の見直しか。誰と組むか |

「一人経理」「決算は事務所」「数字は締めて終わり」でも構いません。隠さずに書けば、それを前提に読む人が来ます。「経理業務全般」と書き、面談で「実は一人で、確認する人もいない」「実は決算は全部事務所」と出るのが、最も離れる形です。

## 「なにを」｜社内でどこまでやり、何を出しているか

「なにをやっているのか」は、会社の事業の説明ではなく、この経理が担う範囲と、会計事務所との分担に絞ります。

- **社内の範囲を、一文で書く**：「仕訳から月次の締めまで社内。年次の決算と税務は会計事務所」「仕訳は社内、月次から先は事務所」
- **決算の関わり方を書く**：「決算は、資料を集めて事務所に渡す。来年からは、一部を社内で組みたい」
- **一人か複数かを書く**：「一人。確認は経営者と事務所。前任者から〇〇の期間で引き継ぐ」
- **数字の使われ方を書く**：「月次の数字は、経営者が翌月の判断に使っている」「いまは締めて終わり。使う形にしたい」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

経理の募集記事を出す前に、先に決めておかないと効果が出ないのは、「社内でしている範囲と、会計事務所に出している範囲の線」です。当社がWantedlyの経理の募集を支えるとき、「経理業務全般」「決算業務」と書かれているのに、経営者に聞くと「決算は全部事務所で、社内は仕訳と請求書の処理」という会社が多くあります。それ自体は問題ではありません。問題は、「決算業務」と書いて、決算を組みたい人を集め、面談で「事務所がやる」と出ることです。経理が面談で最初に聞くのは、資格の有無ではなく、「決算はどこまで社内でやりますか」です。「仕訳から月次まで社内。決算は事務所。来年から一部を社内に戻したい」と書けば、それを前提に読む人が来ます。当社が最初にお願いするのは、資格の条件の確認ではなく、経営者に「いま社内でしている経理の仕事を、最初から最後まで一文で言ってもらう」ことです。その一文で、線が見えます。

## 「どうやって」｜仕組みと、締めと、数字の流れの書き方

| 書くこと | 書き方 |
|---|---|
| 仕組みの状態 | 道具の名前、手作業の残り具合、紙の有無。「請求書は紙で来て、手で入力している」 |
| 締めの流れ | 月次を何日で締めて、誰に渡すか。決算期の負荷。数値は確認したものだけ |
| 確認の流れ | 誰が確認するか。一人なら、経営者か事務所か。間違いが見つかったときの直し方 |
| 数字の使われ方 | 締めた数字を、誰が、いつ、何に使うか。使われていないなら、そう書く |
| 会計事務所との関係 | 何を渡し、何が返ってくるか。連絡の頻度 |
| 前に直した例 | 「〇〇を手作業から△△に変えて、締めが□□早くなった」。無ければ書かない |

「効率化を推進」と書くより、「請求書は紙で来て、手で入力している。ここを最初に変えたい」と書くほうが、仕事の実態が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| 簿記2級以上 | 数字が合わなかったとき、ずれの原因を自分で探して直したことがある |
| 経理経験3年以上 | 月次の締めを、決められた日までに自分で回したことがある |
| 決算経験のある方 | 決算の資料を、事務所に言われる前に自分で揃えたことがある（決算に関わるなら） |
| 几帳面な方 | 手作業を仕組みに変えて、締めを早くしたことがある |
| コミュニケーション能力 | 数字を、経理を知らない人に、決められる形で説明したことがある |
| 即戦力 | 最初の月は〇〇の仕訳の引き継ぎを任せる予定です。△△と組みます |

「ずれの原因を自分で探して直した」が、経理で最も読まれる行動です。資格の級は「あればよい条件」に置きます。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「社内でどこまでやり、決算にどこまで関わるか」と同じ言葉で**：相手が「どの範囲を、一人か複数で、何を直したか」を読み、自社の範囲と重ねる。[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)
- **面談には、経営者と、いまの経理（または前任者）が出る**：一人経理なら、経営者が「誰が確認するか」「休めるか」を本人の言葉で話す
- **面談で話すのは、範囲と実態の話**：社内の範囲、仕組みの状態、締めの負荷、数字の使われ方。前の経理が離れた理由があるなら、それも
- **数字の使われ方を、経営者が話す**：「月次の数字を見て、〇〇を決めた」。使っていないなら、使っていないと

## 社内の分担

| 作業 | 誰が |
|---|---|
| 社内の範囲、決算の関わり、数字の使われ方、仕組みの状態を決める | 経営者 |
| 「なにを」（範囲、事務所との分担、一人か複数か）の下書き | 人事が、経営者といまの経理に聞いて書く |
| 「どうやって」（仕組み、締め、確認の流れ） | いまの経理が話し、人事が書き、本人が確認 |
| 締めの負荷と数値の確認 | いまの経理 |
| 「こんな人」を行動で書く、最初の月の予定 | 経営者と人事 |
| 面談 | 経営者と、いまの経理（または前任者） |

一人目の経理を採る募集では、いま経営者か総務が兼務で仕訳をしていることが多くあります。その場合は、「いまは経営者が兼務で入力していて、〇〇が回っていない。決算は事務所。最初の月は△△の引き継ぎから。確認は事務所と経営者」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、範囲と実態を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、範囲の決定、実態の開示、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「経理は、資格の級を条件にすれば良い人が来る」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの経理の募集と面談を見ていますが、「簿記2級以上」を条件にした募集記事より、「請求書は紙で来て手で入力している。月次は〇〇日で締めて経営者に渡す。ここを一緒に変えたい」と実態を書いた募集記事のほうが、話を聞きに来る人の経験が合う傾向があります。経理は、資格の級より「社内でどこまでやり、一人か複数か、数字が使われるか」を見ていて、資格の条件だけの募集記事は「実態を書けていない会社」と読まれます。級は学習の結果で、仕事の行動ではありません。当社が案内するのは、資格を「あればよい条件」に下げ、社内の範囲と仕組みの実態と数字の使われ方を書き、「こんな人」を「ずれの原因を探した」のような行動で書くことです。資格の条件で人は来ません。実態と、数字が使われることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「経理業務全般」「簿記資格をお持ちの方」で書く | 実態が分からず、読まれない | 社内の範囲と、事務所との分担を書く |
| 「決算業務」と書いて、実態は事務所 | 面談で「事務所がやる」と出て離れる | 決算の関わり方を、実態で書く |
| 一人経理を隠す | 入社後に「確認する人がいない」と分かり、離れる | 一人と書き、誰が確認するか、休めるかを書く |
| 締めの負荷を書かない | 「月末は帰れない会社か」と疑われる | 実態を書く。数値は確認したものだけ |
| 数字の使われ方を書かない | 「締めて終わりの仕事」を想像される | 使われているなら書く。無いなら、使う形にしたいと |
| 面談に経営者が出ない | 「数字がどう使われるか」が伝わらない | 経営者が出て、数字で何を決めたかを話す |

最も多いのは、最初の「経理業務全般」と、資格の条件です。範囲と実態が分からない言葉は、読まれません。

## まとめ

- 経理が見ているのは、社内の範囲と会計事務所との分担・決算にどこまで関わるか・一人経理か・数字が経営に使われるか・仕組みの実態・締めの負荷
- 書く前に、社内の範囲、決算の関わり方、一人か複数か、数字の使われ方、仕組みの状態を、経営者が決める。一人経理でも、決算が事務所でも、隠さない
- 「なにを」は社内の範囲と事務所との分担を一文で。「どうやって」は仕組みの状態と締めの流れと確認の流れを、実態で。前に直した例を一つ
- 「こんな人」は資格の級ではなく、「ずれの原因を探して直した」「締めを自分で回した」の行動で。級は「あればよい条件」
- 面談には経営者が出て、数字で何を決めたか、誰が確認するか、休めるかを本人の言葉で話す

## よくある質問

### 一人経理で、確認する人が社内にいません。正直に書くと来ませんか

隠すほうが、入社後に分かって離れます。「一人。確認は月に一度、会計事務所が見る。経営者は数字の意味を聞く。休むときは〇〇が最低限の入力をする」のように、一人であることと、確認と休みの仕組みを一緒に書きます。一人で回してきた人には、「仕組みがある一人経理」として読まれます。確認の仕組みが無いなら、「一緒に作るところから」と書きます。

### 決算は会計事務所に全部出していて、社内は仕訳と請求書の処理だけです

そのまま書きます。「社内は仕訳から月次の締めまで。決算と税務は事務所。まず月次を〇〇日で締められる形にしてほしい。決算に関わりたい人には、来年から一部を社内に戻す予定」のように、いまの範囲と、これから広げたい範囲を分けて書きます。「決算業務」と書いて事務所任せだと、面談で離れます。

### 経理の募集記事は、御社に相談できますか

できます。当社は、募集記事の型、範囲と実態を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。範囲の決定、実態の開示、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
