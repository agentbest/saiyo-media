OfferBoxの運用は、送る時期だけを見ていると、準備が間に合わず、内定後のフォローが手薄になり、次の卒年の準備が遅れます。**結論から言うと、運用は卒年ごとの1年のサイクルで組みます。準備、早期、選考期、後期、内定フォロー、振り返り、次の卒年の準備の7つの期間に分け、それぞれで何をするかと、担当の時間の山がどこに来るかを先に見ます。特に、内定フォローと次の卒年の準備が重なる時期は、先に手を打たないと両方が薄くなります。** この記事では、7つの期間の中身、時間の山、重なる時期の扱い、毎月の固定作業、やりがちな失敗、分担を整理します。学生が動く時期は卒年ごとに変わるので、具体的な月は書きません。時期の確認の仕方は[送る時期と時間帯の考え方](/media/ob-soushin-timing/)で書きました。

## この作業の目的｜「送る時期」だけの運用から、1年の運用へ

送る時期だけを見ている運用は、次のように崩れます。送る時期になってからペルソナとテンプレートを作り始め、準備に時間を取られて送り始めが遅れる。送っている間は送ることで手一杯で、内定後のフォローが手薄になる。年度が終わっても振り返らず、次の卒年も同じ時期に同じことを繰り返す。

1年のサイクルで組むと、準備は送る前に終わり、内定フォローは送る時期と分けて時間が取れ、振り返りが次の準備につながります。目的は、送る時期に「送ることだけ」をできる状態を、1年で作ることです。

## 手順1｜7つの期間に分ける

卒年ごとの1年を、7つに分けます。期間の長さと開始の時期は、学生の動きの山と自社の採用計画で決まります。

| 期間 | やること | 関係する記事 |
|---|---|---|
| 1. 準備 | 採用人数の確定、ターゲット設計、ペルソナ、検索条件、テンプレート、企業ページと募集要項の更新、送信計画、面接官との合意 | [ターゲット設計](/media/ob-target-sekkei/)、[送信計画](/media/ob-ninzu-keikaku/) |
| 2. 早期 | 少数に送り、接点を作る。インターンや交流の場。途中の接点の設計 | [早期に使うときの進め方](/media/ob-souki/) |
| 3. 選考期 | 大半を送る。承認への返信、面談、選考。週次レビュー | [送信ペース](/media/ob-soushin-pace/)、[週次レビュー](/media/ob-shuukan-review/) |
| 4. 後期 | 辞退分の補充。選考を短くして送る | [後期に使うときの進め方](/media/ob-kouki/) |
| 5. 内定フォロー | 承諾までの材料を渡す。現場と話す場。内定者の場 | [内定を出したあとのフォロー](/media/ob-naitei-follow/) |
| 6. 振り返り | 割合の実績、効いた文面、止まった場面、辞退の理由を記録から整理する。内定者から聞く | [2年目以降の見直し点](/media/ob-repeat-unyou/) |
| 7. 次の卒年の準備 | 振り返りを元に、1に戻る。ペルソナとテンプレートの更新、計画の作り直し | 1と同じ |

「1. 準備」を、送る時期の前に終えることが要点です。準備に要る時間は、初年度は長く、2年目以降は振り返りがあれば短くなります。

## 手順2｜担当の時間の山を見る

7つの期間で、担当の時間がどこに集中するかを見ます。

| 期間 | 人事の時間 | 現場の時間 |
|---|---|---|
| 準備 | 大きい（作る作業が集中） | 中くらい（テンプレートの仕事の一文、面接官との合意） |
| 早期 | 小さい（少数） | 小さい（接点の場に出る） |
| 選考期 | 最も大きい（読む・書く・送る・返信・面談・選考） | 大きい（面談と面接の枠） |
| 後期 | 中くらい（短期集中） | 中くらい（短期間に枠を集中） |
| 内定フォロー | 中くらい（連絡と場の設定） | 中くらい（話す場に出る） |
| 振り返り | 中くらい（記録の整理） | 小さい（聞かれたら答える） |
| 次の卒年の準備 | 大きい | 中くらい |

人事の時間は「準備」と「選考期」に山があり、現場の時間は「選考期」に山があります。この山を、他の採用業務（ナビ経由の応募対応、説明会）や、現場の繁忙期と重ねないよう、先に見ます。重なるなら、送る時期をずらすか、読んで書く作業を外に出すか、を準備の期間に決めます。1人で回す場合の時間の固定は[人事1人でOfferBoxを回す運用設計](/media/ob-hitori-jinji/)で書きました。

### エージェントベストの見解

申し込んだあと、1年目の終わりに起きやすいのは、「内定フォローと次の卒年の準備が重なり、両方が薄くなる」ことです。内定者への連絡と場の設定に時間を使っている間に、次の卒年の準備が始まらず、送る時期になってから慌ててテンプレートを作る。逆に、次の準備を優先すると、内定者への連絡が途切れ、承諾の直前で辞退が出る。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、2年目に運用が安定している会社は、この重なる時期を1年目の準備の段階で見つけ、内定フォローの連絡の骨格（内定通知、話せる場の案内、期限の前の一度）を先に決めて、次の準備の時間を確保しています。重なる時期は、来てから対処するのではなく、1年の最初に見つけて、両方の骨格を先に決めておく。それが、2年目が楽になる唯一の方法です。

## 手順3｜2つの卒年が重なる時期の扱い

内定フォローの期間は、次の卒年の準備と早期に重なります。2つの卒年を同時に動かす時期です。

1. **内定フォローの骨格を、選考期の終わりまでに決めておく**：内定通知の型、話せる場の日程、質問の窓口、期限の前の連絡。決まっていれば、フォローは「回す」だけになる
2. **次の卒年の準備を、振り返りから始める**：振り返りが終わっていれば、準備は「更新」で済む。終わっていなければ、準備は「作り直し」になり時間がかかる
3. **現場の時間を、内定者の場と次の卒年の面接官の合意で分ける**：同じ現場社員に両方を頼むと重い。内定者の場は配属先の若手、面接官の合意は面接官、と分ける
4. **早期の送信を少数にする**：重なる時期に早期を広くやると、人事の時間が足りない。早期は少数で、接点を作る目的に絞る
5. **重なる時期の週次レビューは、2つの卒年を分けて見る**：内定者の状況と、次の卒年の準備の進み具合を、別の項目で

重なる時期を「忙しい時期」で終わらせず、「内定フォローの骨格」と「振り返り」の2つが先に終わっていれば重ならない、と捉えます。

## 手順4｜毎月の固定作業

7つの期間とは別に、毎月同じ日にやる作業を固定します。

- **率の置き直し**：その月の合計から、承認率、面談進行率、選考通過率、内定率、承諾率を置き直す。手順は[送信計画](/media/ob-ninzu-keikaku/)
- **見込みの確認**：採る人数に対して、いまの見込みは何人か。経営に伝える。見方は[KPI設計](/media/ob-kpi-sekkei/)
- **テンプレートと企業ページの確認**：紹介した人の異動、書いた場面の変化が無いか。更新の目安は[企業ページで伝えること](/media/ob-kigyo-page/)
- **契約の期限と更新の時期の確認**：媒体との契約、代理店との契約。期限が近ければ判断の準備。流れは[代理店経由の契約と請求の流れ](/media/kh-dairiten-keiyaku/)
- **記録の整理**：週次の記録が溜まっているか。抜けがあれば埋める

毎月の固定作業は、短時間で済みます。固定しておくと、期間が変わっても抜けません。

## 手順5｜1年のスケジュールを1枚にする

7つの期間、時間の山、重なる時期、毎月の固定作業を、1枚にします。

| 書くこと | 内容 |
|---|---|
| 7つの期間の開始と終了 | 学生の動きの山と自社の採用計画から。具体的な日付で |
| 各期間でやること | 手順1の表を自社に合わせて |
| 人事と現場の時間の山 | どの期間に誰の時間が集中するか |
| 他の採用業務との重なり | ナビ経由の応募対応、説明会、面接の集中する時期 |
| 内定フォローと次の準備の重なる時期 | いつからいつまで。骨格を決める期限 |
| 毎月の固定作業の日 | 何日に何をするか |
| 契約の期限と更新の判断の時期 | 媒体と代理店 |

この1枚は、担当が変わっても運用が続くための資料です。引き継ぎの一覧に含めます。引き継ぎは[運用を担当者間で引き継ぐ方法](/media/ob-tantousha-hikitsugi/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 送る時期になってから準備を始める | 送り始めが遅れる | 準備の期間を送る前に置く |
| 内定フォローと次の準備が重なって両方薄くなる | 辞退が出て、次の送り始めも遅れる | 骨格と振り返りを先に終える |
| 振り返りをしない | 次の卒年も同じことを繰り返す | 振り返りの期間を置く |
| 現場の繁忙期に選考期を重ねる | 面談枠が出ない | 準備の段階で重なりを見て、時期をずらす |
| 毎月の固定作業を決めない | 率の置き直しと契約の期限が抜ける | 日を固定する |
| 具体的な月を毎年同じにする | 学生の動きが卒年で変わっている | 卒年ごとに学生の動きの山を確認して置き直す |
| スケジュールが担当の頭の中だけ | 担当が変わると消える | 1枚にする |

最も多いのは、最初の「送る時期になってから準備を始める」です。準備を期間として置くだけで防げます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 7つの期間を置く | 人事（学生の動きの山と採用計画から） |
| 各期間の時間の山を出す | 人事と現場 |
| 他の採用業務と現場の繁忙期との重なりを確認する | 人事と現場の上司 |
| 内定フォローの骨格を先に決める | 人事 |
| 振り返りを行う | 人事（現場と内定者に聞きながら） |
| 毎月の固定作業 | 人事（または運用代行） |
| 1枚にする | 人事 |

運用代行に出している場合、7つの期間のうち、早期・選考期・後期の送る作業と、毎月の率の置き直しは代行が行えます。準備の中の人物像と面接官との合意、内定フォロー、振り返りは社内です。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと年間のスケジュールが機能しないことがあります。「準備の期間を、送る時期の前に、独立した期間として置く」ことです。当社がOfferBoxの運用の相談で1年の計画を見るとき、準備が「送る時期の直前に、送りながらやる」になっている会社は、テンプレートも企業ページも中途半端なまま送り始め、最初の月の承認が低く、そこで直しながら送るので時間が倍かかります。準備を独立した期間として置き、その期間にペルソナ、テンプレート、企業ページ、計画、面接官との合意を終えておくと、送る時期は送ることだけに集中できます。当社がOfferBoxの運用代行を受けるときも、最初の打ち合わせで「送り始めの日」を決め、そこから逆算して準備の期間を確保します。準備が先、送るのはあと。この順番が、1年のスケジュールの土台です。

## まとめ

- 運用は卒年ごとの1年のサイクル。準備、早期、選考期、後期、内定フォロー、振り返り、次の準備の7つに分ける
- 人事の時間の山は準備と選考期、現場の時間の山は選考期。他の採用業務と繁忙期との重なりを先に見る
- 内定フォローと次の準備は重なる。フォローの骨格と振り返りを先に終えておく
- 毎月の固定作業（率の置き直し、見込み、テンプレートと企業ページ、契約の期限、記録）を日で固定する
- 1年のスケジュールを1枚にし、引き継ぎの資料に含める。具体的な月は卒年ごとに置き直す

## よくある質問

### 準備の期間は、どのくらい取ればよいですか

初年度は、ペルソナ、テンプレート、企業ページ、計画、面接官との合意を作るので、長めに取ります。2年目以降は、振り返りがあれば「更新」で済むので短くなります。具体的な長さは、社内で現場に聞ける時間と、テンプレートを直す現場の時間で決まります。送り始めの日を決めて、逆算します。

### 内定フォローと次の卒年の準備が、どうしても重なります

重なること自体は避けられません。重なる時期に「両方を作る」のではなく、内定フォローの骨格は選考期の終わりまでに、振り返りは内定フォローの前半で終え、重なる時期には「回す」と「更新する」だけにします。現場の時間も、内定者の場は配属先の若手、面接官の合意は面接官、と分けます。

### 年間スケジュールの作成は、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、学生の動きの山と自社の採用計画から7つの期間を置き、時間の山と重なる時期を一緒に見て、1枚にします。運用代行を受ける場合は、送る作業と毎月の率の置き直しを当社が持ち、準備の中の人物像と合意、内定フォロー、振り返りは企業が行います。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
