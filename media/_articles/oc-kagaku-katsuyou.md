総合化学、素材、電子材料、化成品、塗料・接着剤、地方の化学メーカーが、新卒採用でワンキャリアを使う。ワンキャリアの学生層は文系が多く、化学・材料の理系は研究室と学校の推薦の流れで会社を選ぶ。大手化学のクチコミには「ホワイト」「安定」「隠れた優良企業」が付きやすく、その像で来た文系の学生が、研究所と工場が地方のコンビナートにあることと、転居を伴う異動を知って辞退か離職し、体験談に「勤務地だった」「地方だった」と残る。製品が最終製品の中に入る素材で、学生には「何をしている会社か」が見えない。**結論から言うと、化学メーカーのワンキャリアは、位置を「文系の営業・管理」「情報系」「推薦の外の理系」の入口に置き、理系の主戦場にしません。企業ページの最初に「当社の素材は〇〇（最終製品）の△△に使われている」の一文と、研究所と工場の場所と異動の範囲を書き、「ホワイト」「安定」の像で来た学生が勤務地で離れない形にします。文系には営業が誰に何を売るか（メーカーへの提案か、商社経由か）を仕事の中身で書き、面接で「なぜ化学か」を聞かず、内定前に工場と研究所の場所を見せます。** この記事では、化学業界の採用構造とワンキャリアとの相性、位置の決め方、企業ページの見せ方、選考と面接の設計、内定後の設計、イベントとスカウトの運用設計、社内の分担を整理します。媒体の選び方は[化学業界の採用媒体の選び方](/media/hikaku-kagaku-erabikata/)、企業ページの基本は[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。数値と料金は書きません。

## 化学業界の採用構造と、ワンキャリアとの相性

| 区分 | 採用の形 | ワンキャリアとの相性 |
|---|---|---|
| 総合化学（大手） | 理系を推薦で多く、文系を営業・管理で少なく。クチコミに「ホワイト」「安定」 | 文系と情報系の募集で使う。勤務地と異動を先に |
| 素材、電子材料、化成品（中堅） | 業界内では知られ、学生には見えない。研究・技術・生産を専攻で | 推薦の外の理系と文系の営業に。最終製品の一文で候補に入れる |
| 塗料、接着剤、地方の化学メーカー | 候補に入っていない。地元の理系と文系の営業。体験談がない | 地元の学生への導線を先に。体験談がない年の入口 |

| 業界の特徴 | ワンキャリアで起きること | 設計 |
|---|---|---|
| 学生層は文系が多く、理系は推薦で決まる | ワンキャリアで研究職を採ろうとして、届かない | 位置を文系・情報系・推薦の外の理系に |
| 「ホワイト」「安定」「隠れた優良企業」のクチコミが付く | その像で来て、地方の勤務地と異動で辞退・離職 | 勤務地と異動を企業ページの最初に |
| 製品が最終製品の中に入り、見えない | 「何をしている会社か」が分からず、開かれない | 最終製品でつなぐ一文で |
| 文系の営業の仕事が見えない | 「化学に興味」で来て、営業の実態で離れる | 誰に何を売るかを仕事の中身で |

## 位置を、「文系の営業・管理」「情報系」「推薦の外の理系」に

- **理系（化学、材料、化学工学）は、研究室と推薦の流れが主**：推薦で会った学生にワンキャリアで送らない。ワンキャリアで会えるのは推薦の外の学生と、研究室の分野が違う学生
- **文系の営業・管理は、民間の学生が民間の会社と並べて選ぶ採用**：ワンキャリアの学生層に合う。「化学に興味」ではなく、「技術や仕組みを人に説明した・違う立場の人の間に入った」の記述で
- **情報系は、IT企業と並べて読まれる前提で**：開発の環境と役割と、素材の会社で情報系が何をするかを先に
- **理系のスカウトは、専攻と研究の内容で絞り、登録を仕様で確かめてから**：[ワンキャリアで理系学生にスカウトを送る方法](/media/oc-scout-rikei/)
- **地方の化学メーカーは、地元の学生への導線を先に**：[ワンキャリアで地方の学生にスカウトを送る方法](/media/oc-scout-chihou/)

### エージェントベストの見解

これは数字の読み方の話です。化学メーカーから、「クチコミの点が高く『ホワイト』『安定』と書かれているから、ワンキャリアでは有利だ」と言われることがあります。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、「ホワイト」「安定」「隠れた優良企業」のクチコミで来る文系の学生は、その像で承認や応募をし、面接か内定後に「研究所と工場は〇〇のコンビナートで、営業も△△に配属される」と知って辞退し、入社した学生も勤務地と異動で離れて、体験談に「ホワイトだが地方だった」と残ります。当社がお願いしているのは、クチコミの点を「有利」と読まず、「勤務地と異動を知らずに来る学生が多い」と読み、企業ページの最初に研究所と工場の場所と異動の範囲を置くことです。「ホワイト」の像で来た学生に勤務地を先に渡すと、承認は減りますが、内定後の辞退と「地方だった」の体験談が減ります。

## 企業ページの見せ方｜最終製品の一文と、勤務地と異動を先に

- **最終製品でつなぐ一文を、最初に**：「当社の素材は、〇〇（スマートフォン、車、衣服）の△△の部分に使われています」。「機能性材料」「化成品」の一語で済ませない。出せる範囲は取引先との関係で線を引く
- **研究所と工場の場所と、異動の範囲を、最初の一文の次に**：「研究所は〇〇、工場は△△にあり、営業の配属は□□、異動は〇〇の範囲」。数値は実態で。この記事では書かない
- **文系の営業は、誰に何を売るかを仕事の中身で**：「〇〇のメーカーに、△△の素材を□□の形で提案する営業。商社経由は〇〇」。「化学に興味」を求めない一文を
- **「ホワイト」「安定」を、企業ページで強調しない**：クチコミにすでにあり、強調すると勤務地とのずれが「盛っている」として残る。事実として書き、勤務地を添える
- **研究の距離を、推薦の外の理系に**：「あなたの〇〇の研究と、当社の△△は、□□でつながる」。研究員の名義で
- **自社の体験談に「地方だった」「勤務地で辞退した」があれば、先に読む**：隠さず、暮らしを添える。[業界イメージが不利な会社のワンキャリアの見せ方](/media/oc-gyokai-image/)

本選考の書き方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

## 選考と面接を、像を確かめない形に

- **面接で「なぜ化学か」「なぜ当社か」を聞かない**：像を確かめる質問は、像の体験談を作る。文系には「技術や仕組みを人に説明した経験」「違う立場の人の間に入った経験」を、理系には「研究の内容と、何を続けたか」を聞く
- **面接で、勤務地と異動と、営業なら誰に何を売るかを伝える**：伝えたことは体験談に「聞いた」と残る
- **理系の面接に、研究員が入る**：研究の距離を本人が話す。人事だけで研究職の面接をしない
- **文系と理系で、面接官と聞くことを分ける**：文系の面接に研究員だけを出さない
- **面接官に、「地方だった」の体験談を読ませる**：[ワンキャリアのクチコミを面接官教育に使う方法](/media/oc-kuchikomi-mensetsukan/)
- **内定前に、工場と研究所の場所を見せる**：地方のコンビナートの暮らしを本人が見る。内定後の辞退を減らす。[ワンキャリア経由の内定辞退が続くときの見直し](/media/oc-naitei-jitai/)

## イベントとスカウトの設計

- **イベントは、若手の営業が「〇〇に使われた日」を、研究員が研究の内容を話す**：文系と理系で回を分ける。[ワンキャリアの理系向けイベントの使い方](/media/oc-event-rikei/)
- **地方の勤務地で働く若手が、暮らしを話す**：「〇〇のコンビナートの近くで、△△の暮らし」。「ホワイト」ではなく場面
- **スカウトは、最終製品の一文と勤務地を最初に**：「〇〇の△△に使われる素材の会社で、研究所は□□、営業の配属は〇〇。あなたの△△（ガクチカ）を読んで」。「化学に興味」で絞らない
- **文系は「技術を人に説明した・違う立場の人の間に入った」のガクチカで**：[ワンキャリアの学生のガクチカを読んでスカウトを送る方法](/media/oc-scout-gakuchika/)
- **理系は専攻と研究の内容で絞り、推薦で会った学生に送らない**

## 社内の分担

| 作業 | 誰が |
|---|---|
| ワンキャリアの位置（文系・情報系・推薦の外の理系）を決める | 人事と研究・技術の責任者 |
| 出せる最終製品の範囲を確認し、一文を作る | 営業の責任者 |
| 企業ページの最初に一文と勤務地・異動を置き、「ホワイト」を強調しない | 人事。若手の営業と研究員が確認 |
| 自社のクチコミと体験談を読み、「ホワイト」の像と「地方だった」を分ける | 人事と面接官 |
| 面接で「なぜ化学か」を聞かず、勤務地と営業の中身を伝える。理系の面接に研究員が入る | 面接官と研究員 |
| 内定前に工場と研究所を見せる | 人事と各拠点の責任者 |
| イベントで若手の営業と研究員と地方の若手が話す | 入社してまもない営業、研究員 |
| スカウトを一文と勤務地を最初に、文系はガクチカで、理系は専攻で絞る | 送る人 |

### エージェントベストの見解

これは媒体の向き不向きの話です。化学メーカーから、「ワンキャリアで研究職を採りたい」と相談されることがあります。当社は、研究職の主戦場をワンキャリアに置きません。ワンキャリアの学生層は文系が多く、化学・材料の理系は研究室と学校の推薦の流れで会社を選んでいて、ワンキャリアで会えるのは推薦の外の学生と、研究室の分野が違う学生です。当社がお願いしているのは、ワンキャリアの位置を「文系の営業・管理」と「情報系」と「推薦の外の理系」に置くことです。文系の営業・管理は民間の学生が民間の会社と並べて選ぶ採用で学生層に合い、情報系はIT企業と並べて読まれる前提で書け、推薦の外の理系には研究の距離を研究員の名義で渡せます。研究職を集める場としてワンキャリアを使うと、企業ページは読まれず、「ワンキャリアは化学に効かない」で終わります。

## まとめ

- 化学業界は、ワンキャリアの学生層が文系が多く、理系は研究室と推薦の流れで決まる。位置を「文系の営業・管理」「情報系」「推薦の外の理系」の入口に置き、研究職の主戦場にしない
- 大手化学のクチコミに付く「ホワイト」「安定」「隠れた優良企業」は、勤務地を知ったうえで残る学生の数ではない。その像で来た学生が地方のコンビナートと異動で辞退・離職し、「地方だった」と体験談に残る
- 企業ページの最初に「何に入っている素材か」の一文と、研究所と工場の場所と異動の範囲を書く。「ホワイト」を強調せず、勤務地を添える。文系の営業は誰に何を売るかを仕事の中身で
- 面接で「なぜ化学か」を聞かず、文系には「技術を人に説明した」経験を、理系には研究の内容を聞き、勤務地を伝える。理系の面接に研究員が入る。内定前に工場と研究所の場所を見せる
- イベントは文系と理系で回を分け、地方の勤務地で働く若手が暮らしを話す。スカウトは一文と勤務地を最初に、文系はガクチカで、理系は専攻で絞り、推薦で会った学生に送らない

## よくある質問

### クチコミの点が高く「ホワイト」と書かれているので、ワンキャリアで有利ですか

「ホワイト」「安定」の像で来た文系の学生は、面接か内定後に研究所と工場が地方にあることと異動を知って辞退し、入社しても勤務地で離れ、体験談に「ホワイトだが地方だった」と残ります。点の高さを「有利」と読まず、「勤務地を知らずに来る学生が多い」と読み、企業ページの最初に研究所と工場の場所と異動の範囲を置きます。承認は減りますが、辞退と「地方だった」の体験談が減ります。

### ワンキャリアで研究職を採れますか

化学・材料の理系は研究室と推薦の流れで会社を選び、ワンキャリアで会えるのは推薦の外の学生と、研究室の分野が違う学生です。研究職の主戦場は推薦に置き、ワンキャリアは推薦の外の理系に研究の距離を研究員の名義で渡す補助にします。ワンキャリアの学生層に合うのは文系の営業・管理と情報系で、そちらを主の位置にします。

### 化学業界のワンキャリアの設計は、御社に相談できますか

できます。当社は、位置の整理、一文の型、企業ページの型、体験談の読み方の型、選考の設計の型、内定後の設計の型、イベントの型、スカウトの型と絞る作業を支えられます。最終製品の一文の中身、勤務地と異動の開示、面接で伝えること、研究員が話すこと、内定前に見せる拠点、推薦の流れは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
