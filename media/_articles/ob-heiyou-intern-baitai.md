インターンの募集をインターン媒体で出していて、OfferBoxも使っている。あるいは、OfferBoxでオファーの締めにインターンの案内を入れていて、インターン媒体を足すか迷っている。この二つは、同じ「インターンに学生を呼ぶ」でも、学生が来る経路と状態が違います。**結論から言うと、インターン媒体は「学生がインターンに行くと決めてから開く、決まった時期に枠を埋める入口」、OfferBoxは「企業が学生を選んで送り、締切と関係なく会う入口」です。併用するなら、枠を埋めるのはインターン媒体、枠の外で会いたい学生に送るのはOfferBoxと分け、同じ学生に二重に連絡しない台帳を持ち、インターン媒体の締切でオファーを止めず、受け入れる側の時間を先に取ることです。** この記事では、それぞれの役割、来る学生の状態、併用するときの分担、台帳、文面とインターン媒体の揃え方、時期と受け入れの時間、やりがちな失敗、社内の分担を整理します。OfferBoxとインターンをつなげる設計そのものは[OfferBoxとインターンシップをつなげる設計](/media/ob-intern-setsuzoku/)、インターンからの母集団形成は[インターンからの母集団形成](/media/kh-boshudan-intern/)で書きました。数値は書きません。

## それぞれの役割｜「枠を埋める」と「選んで会う」

| | インターン媒体 | OfferBox |
|---|---|---|
| 学生が来る経路 | 学生が「インターンに行く」と決めて開き、日程と内容と業界で選んで応募する | 企業が検索して選び、文面を送り、学生が承認する |
| 学生の状態 | 会社を知らない。プログラムで選んでいる。複数の会社を並べている | 会社を知らない。文面と送ってきた人で興味を持っている。「自分に来た」と感じている |
| 時期 | 決まっている。締切がある | 送る時期は企業が決める。締切はない |
| 会社が出すもの | 枠、日程、プログラムの内容 | 検索条件、文面、送る社員の名義、文面の締めのインターン案内 |
| 数の性格 | 応募の数。枠と時期で決まる | 承認の数。送る相手と数で決まる |
| 向く形 | 日程が決まった短期。枠を埋めたいとき | 枠の外で、「こんな人」に会いたいとき。少人数で長期 |

インターン媒体から来る学生は、「インターンに行く」が先で、会社はあとです。OfferBoxで承認した学生は、「この会社から来た」が先で、インターンはあとです。同じインターンの当日に、この二つの状態の学生が座ることになります。

## 併用するときの分担

- **枠を埋めるのはインターン媒体**：日程が決まった短期のインターンで、決まった人数を集めたいとき
- **枠の外で会いたい学生に送るのはOfferBox**：検索で「こんな人」に近い学生を選び、文面の締めでインターンに案内する。案内の書き方は[OfferBoxとインターンシップをつなげる設計](/media/ob-intern-setsuzoku/)の手順2
- **インターン媒体で埋まらない枠を、OfferBoxで埋めようとしない**：OfferBoxは「埋める」ためではなく「会いたい学生に会う」ための入口。埋める目的で送ると、送る相手が広がり、承認した学生が当日に「思っていたのと違う」になる
- **同じインターンを両方で案内するなら、中身を揃える**：インターン媒体の「内容」と、文面の締めの案内が違うと、当日に両方の学生が戸惑う
- **当日は、入口を分けずに同じプログラムで**：OfferBoxで来た学生だけを特別扱いしない。ただし、面談の前後の連絡は入口ごとに

### エージェントベストの見解

インターン媒体の応募数と、OfferBoxの承認数は、どちらも「インターンに来る学生の数」に見えますが、動く理由が違う数字です。当社は3媒体すべての販売パートナーとして、インターンの集め方の相談を受けますが、「インターン媒体では応募が多いのに、OfferBoxからは少ない」という比べ方をする会社が多くあります。インターン媒体の応募は枠と日程と業界で学生が選んだ数で、OfferBoxの承認は企業が選んで送った相手の中の数で、送る数で増減します。同じ列に置けばOfferBoxが少なく見えますが、「選んで送っている」からです。当社が見るのは、応募数と承認数ではなく、当日に来た学生のうち、「こんな人」に近い学生が、どちらの入口から何人いたかです。この見方にすると、インターン媒体は枠を埋め、OfferBoxは近い学生を連れてくる、という役割の違いが数字で見えます。

## 同じ学生に、二重に連絡しない台帳

- **インターンの台帳を一つにし、入口の列に「インターン媒体」と「OfferBox」を持つ**：同じ学生が両方から来ることがある
- **OfferBoxで送る前に、インターン媒体の応募者と名前を突き合わせる**：応募している学生にオファーを送ると、「応募しているのに、なぜ送ってくるのか」になる
- **両方から来た学生は、最初の入口と決め手の入口を記録し、連絡は一本に**
- **当日の前後の連絡は、入口ごとに文面を変える**：OfferBoxで来た学生には送った社員の名前で、インターン媒体で来た学生には人事から
- **当日のあと、「こんな人」への近さを入口ごとに付ける**：翌年の配分の材料

送る側の台帳と、来た学生の台帳の分け方は[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)で書きました。突き合わせは、送る前に一度、当日の前に一度です。

## 文面のインターン案内と、インターン媒体の内容を揃える

| 揃える項目 | 文面の締め | インターン媒体 |
|---|---|---|
| 何を任せるか | 一文で | 内容で詳しく。同じ中身 |
| 誰が見るか | 送る社員の名前で | 担当者として同じ人 |
| 日程と期間 | 「〇月に△日間」の程度 | 正確に。文面とずらさない |
| 終わったら何が残るか | 一文で | 内容に含める |
| 報酬の有無 | 触れるなら概要 | 条件で正確に。自社の方針と制度の確認のうえで |

- **文面の締めで「詳しくはインターン媒体に」と誘導してよいが、貼れる形は仕様で確認**：貼れなければ、「〇〇という名前で募集しています」
- **送る社員と、インターン媒体の担当者を同じ人にする**：当日に会う人が、文面を送った人
- **日程を変えたら、文面のテンプレートとインターン媒体を同じ日に直す**

## 時期と、受け入れの時間

- **インターン媒体の締切と、オファーを送る時期を分けて設計する**：締切の前に送ると、承認した学生がインターン媒体にも応募して二重になる。締切のあとに送ると、枠の外で会える。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
- **インターン媒体の締切で、オファーを止めない**：締切は「枠が埋まった」の合図で、「会いたい学生がいなくなった」の合図ではない。枠の外の面談や少人数の受け入れに案内する
- **受け入れる側の時間を、先に確保する**：どちらの入口から来ても、当日に見る人の時間は同じだけ要る。ここを取らずに枠と送る数を決めない
- **両方を出す年は、受け入れられる人数を先に決め、枠と送る数を逆算する**：媒体が増えると来る学生は増えるが、見る人の時間は増えない
- **早期に送るときは、内定を急がない**：[OfferBoxを早期に使うときの進め方](/media/ob-souki/)

費用は、各媒体の現在の条件を公式ページで確認してください。配分の考え方は[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 埋まらない枠をOfferBoxで埋めようとする | 送る相手が広がり、承認した学生が当日に「違う」になる | OfferBoxは会いたい学生に絞る |
| 応募している学生にオファーを送る | 「応募しているのに」で印象が下がる | 送る前に名前を突き合わせる |
| 文面の案内とインターン媒体の内容がずれる | 当日に両方の学生が戸惑う | 中身を揃え、同じ日に直す |
| インターン媒体の締切でオファーも止める | 枠の外で会える学生を失う | 締切のあとは面談や少人数に案内 |
| 受け入れる人を決めずに両方で集める | 応募は来るが、当日に見る人がいない | 見る人と任せる仕事を先に |

最も多いのは、一つ目です。枠が埋まらない焦りで送る数を増やし、承認した学生の状態が「インターンに行きたい」ではなく「送られたから」になります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| インターンで任せる仕事と、見る人を決める | 人事と現場の責任者 |
| インターン媒体の枠・日程・内容を出す | 人事 |
| 「こんな人」の一行と検索条件を決め、送る | 人事と送る社員（検索・文面下書き・送信は代行に出せる） |
| 送る前と当日の前に、名前を突き合わせる | 人事 |
| 文面の締めとインターン媒体の内容を揃える | 人事（一人） |
| 当日に見る、任せる、振り返る | 現場の担当者 |
| 当日のあと、入口ごとに近さを付ける | 人事と現場 |
| 受け入れる人数と、両方を出すかの判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、台帳の型、突き合わせの型、文面の締めの案内の型、OfferBoxの検索・文面下書き・送信までで、任せる仕事の決定、当日に見ること、受け入れる人数の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

両方を使い始めたあと、最初の年で起きることに共通するのは、インターン媒体の締切に合わせて、オファーを送るのも止めてしまうことです。当社はOfferBoxの運用代行を受けているので、送る時期の設計を企業と一緒に決めますが、インターン媒体を使っている会社では、「インターンの募集が終わったので、オファーも一区切り」という感覚になりやすく、締切のあとに送る計画がありません。締切のあとに送ったオファーで承認した学生は、枠には入れませんが、少人数の面談や、次の回のインターン、通年の受け入れに案内できます。この学生は「自分に来た」と感じて承認した学生なので、枠の外で会うほうが温度が保てます。当社が勧めているのは、インターン媒体の締切のあとに、送る時期をもう一つ置くことです。枠を埋める時期と、会いたい学生に会う時期を分けると、両方の入口が役割を果たします。

## まとめ

- インターン媒体は「学生がインターンに行くと決めてから開く、決まった時期に枠を埋める入口」、OfferBoxは「企業が選んで送り、締切と関係なく会う入口」。来る学生の状態が違う
- 枠を埋めるのはインターン媒体、枠の外で会いたい学生に送るのはOfferBox。埋まらない枠をOfferBoxで埋めようとしない
- 台帳は一つにし、送る前と当日の前に名前を突き合わせる。応募している学生に送らない
- 文面の締めの案内と、インターン媒体の内容を揃え、担当者を同じ人にする。日程を変えたら同じ日に直す
- インターン媒体の締切でオファーを止めない。締切のあとに送る時期をもう一つ置き、受け入れる側の時間を先に取る

## よくある質問

### インターン媒体だけで枠が埋まっています。OfferBoxを足す意味はありますか

枠を埋める目的なら、要りません。「こんな人」に近い学生が枠の中に何人いるかを見て、少ないなら、OfferBoxで選んで送る意味があります。枠の外で、少人数の面談や次の回に案内する形です。埋まっている枠に、さらに送ることはしません。

### OfferBoxで承認した学生が、インターン媒体にも応募していました。どちらの流れで扱いますか

台帳で最初の入口と決め手の入口を記録し、連絡は一本にします。連絡の名義は、送った社員の名前のほうが、学生には「自分に来た」の続きとして自然です。インターン媒体の応募の手続きは、媒体のルールに従い、当日の扱いは他の学生と同じにします。

### OfferBoxとインターン媒体の併用は、御社に相談できますか

できます。当社は、役割の整理、台帳の型、突き合わせの型、文面の締めの案内の型、OfferBoxの検索・文面下書き・送信を支えられます。任せる仕事の決定、当日に見ること、受け入れる人数の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
