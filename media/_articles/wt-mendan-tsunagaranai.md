Wantedlyでスカウトに返信が来た。募集記事に「話を聞きに行く」が来た。ところが、面談まで進まない。日程のやりとりの途中で途切れる、返事が来なくなる、面談の直前に辞退される。**結論から言うと、面談につながらない原因は四つです。返しが遅い、日程を相手に丸投げしている、面談の形（誰と・時間・形式・選考ではない）が見えない、返信に対応する人が決まっていない。返信から面談までの間を、翌日までの返し、複数の日程、形の一段落、面談前に読むもの一つ、で埋めます。面談の枠を送る前に確保し、返信が「話を聞きたい」であって応募ではないことを踏まえた温度で対応します。** この記事では、四つの原因とサインと直し方、返信から面談までの型、枠の確保、温度、面談前の辞退、分担を整理します。返信が来たあとの基本は[Wantedlyでスカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)、面談の設計は[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。この記事は、「面談につながらない」という症状から逆に辿るものです。

## この作業の目的｜「話を聞きたい」を、途切れさせずに面談まで運ぶ

Wantedlyの返信は、応募ではなく「話を聞きたい」という軽い動きです。軽い動きは、途中で少しでも重くなると、止まります。返しが遅い、日程が面倒、何が起きるか分からない。どれも、相手の側の「面倒」になります。

目的は、返信から面談までの間を、相手の側の「面倒」がない形で埋めることです。

## 面談につながらない、四つの原因

| 原因 | サイン | 直し方 |
|---|---|---|
| 1. 返しが遅い | 返信から返すまでに数日空いている。返した頃には相手の「話を聞きたい」が冷めている | 翌日までに返す。当日なら、なお良い |
| 2. 日程を相手に丸投げ | 「ご都合の良い日時をお知らせください」で、相手が考える負担になり、返事が来ない | こちらから複数の日程を出す |
| 3. 面談の形が見えない | 誰と、何分、オンラインか対面か、選考ではないのか、が書かれておらず、相手が「重い」と感じる | 形を一段落で。「選考ではありません」を明記 |
| 4. 対応する人が曖昧 | 返信を誰が見て誰が返すかが決まっておらず、見落とすか、複数の人が別々に返す | 返信に対応する人を一人決める |

四つは、返信から面談までの「間」で起きます。文面や記事が良くても、この「間」で途切れます。

## 1. 返しが遅いとき

- **返信を、朝と夕方の二回確認する**：来るたびに見なくてよいが、翌日以降にしない
- **翌日までに、一言と日程を返す**：「ご返信ありがとうございます。〇〇と申します。ぜひお話ししたく、以下の日程はいかがでしょうか」
- **当日に返せない日は、「明日改めてご連絡します」の一言だけでも返す**
- **返しの速さを、台帳の「返信日」と「返した日」で見る**：日数が空いていれば、ここが原因

速さの考え方は[Wantedlyでスカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)の「進め方」で書きました。

## 2. 日程を丸投げしているとき

- **こちらから、複数の日程を出す**：「〇日の午後、△日の夕方、□日の午前、のいずれかはいかがでしょうか」
- **相手の都合が合わなければ、「他の日程もご希望をお知らせください」を添える**：最初から丸投げしない
- **面談の枠を、送る前に確保しておく**：返信が来てから枠を探すと、日程が出せず遅れる
- **日程の候補は、近い日に**：来週の中で。「来月」では冷める

### エージェントベストの見解

相談で最も多い思い込みは、「返信が来たあとに面談まで進まないのは、相手の志望度が低かったからだ」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、面談につながらない会社の台帳を見ると、返信から返すまでに数日空き、返した文面が「ご都合の良い日時をお知らせください」で、面談の形が書かれていません。Wantedlyの返信は「話を聞きたい」という軽い動きで、志望度で来るものではありません。軽い動きを、遅い返しと丸投げの日程と見えない形で重くすると、止まります。当社が「面談につながらない」の相談を受けるとき、最初にやるのは、志望度の話ではなく、返信から返すまでの日数と、返した文面に日程と形があるかを見ることです。この二つで、多くが直ります。

## 3. 面談の形が見えないとき

- **返す文面に、面談の形を一段落**：「選考ではありません。この文面を書いた〇〇と、現場の△△が出ます。オンラインで、短い時間、お互いを知る場です」
- **「選考ではない」を、明記する**：相手は「返信したら選考が始まるのか」を気にしている
- **誰が出るかを、名前で**：「担当者」ではなく
- **何を話すかを、一文で**：「仕事の話と、あなたの話を」
- **面談前に読むものを、一つだけ**：募集記事か、ストーリー一本。「事前に見ておいてください」の量が多いと重い

面談の形の決め方は[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)の「決めること」で書きました。

## 4. 対応する人が曖昧なとき

- **返信に対応する人を、一人決める**：スカウトを送った人か、人事の一人
- **その人が、朝と夕方に返信を確認する**
- **名義の人（現場や代表）が対応できないなら、人事が「〇〇に代わってご連絡します」と返す**：名義の人の名前で、人事が返さない
- **複数の人が別々に返さない**：台帳で「誰が返したか」を一つに
- **休暇のときの代理を決めておく**：[Wantedlyのスカウトの担当](/media/wt-scout-tantou/)

対応する人を一人にする考え方は[Wantedlyでスカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)の「返信に対応する人を、一人決める」で書きました。

## 返信から面談までの、型

1. **返信が来た日か翌日に、一言と複数の日程と面談の形を返す**：この一通で、三つを済ませる
2. **日程が決まったら、確認の一通**：日時、形式、出る人、読むもの一つ
3. **面談の前日に、一言**：「明日、お待ちしています」。長くしない
4. **当日、始まる前に接続や場所の案内**：オンラインなら接続先を再送
5. **面談のあと、翌日までに一言**：[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)の「面談後の連絡」

「1」で三つを済ませることが要点です。一言だけ返して日程は次、形は次、とすると、やりとりが増え、途中で途切れます。

## 面談の枠を、送る前に確保する

- **スカウトを送る前に、面談に出る人の週の枠を押さえる**：返信が来てから探さない
- **枠は、送る数から逆算する**：返信の割合と面談の割合で、週に何枠か
- **現場の人が出る場合、その人の枠を先に**：[Wantedlyのスカウトを現場の名前で送る](/media/wt-scout-genba/)
- **枠が取れない週は、送る数を減らす**：返信が来ても面談が組めない状態で送らない
- **人事一人なら、枠を固定する**：「毎週〇曜の午後」。[Wantedlyのスカウトを一人で回す](/media/wt-scout-hitori/)

## 「話を聞きたい」の温度に、合わせる

- **返信は、応募ではない**：「ご応募ありがとうございます」と返さない。「ご返信ありがとうございます」
- **選考の書類や志望動機を、この段階で求めない**：重くなり、止まる
- **面談は「お互いを知る場」で、合否を出さない**
- **相手が「まだ転職を考えていない」と書いてきても、面談に誘ってよい**：「いまは考えていなくても、話す場として」
- **押さない**：「ぜひ」「早めに」を重ねない

温度の合わせ方は[Wantedlyでスカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)の「返信は『話を聞きたい』であって、応募ではない」で書きました。

## 面談の前に、辞退される理由

- **日程が決まってから面談までが長い**：間が空くと冷める。近い日程で
- **面談の前に、書類や課題を求めた**：「話を聞くだけ」のつもりが重くなった
- **面談の形が、途中で「選考」に変わった**：「面接」「一次選考」という言葉が出た
- **確認の連絡がなく、忘れられた**：前日の一言がない
- **他社の面談が先に入った**：返しの速さと日程の近さ

面談後の辞退は[Wantedlyで面談後に辞退されるときの見直し](/media/wt-scout-jitai/)で書きました。面談前の辞退は、この記事の四つの原因と、面談までの長さで起きます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 返信を朝と夕方に確認し、翌日までに返す | 返信に対応する人（一人） |
| 複数の日程と面談の形を、最初の一通で返す | 返信に対応する人 |
| 面談の枠を送る前に確保する | 面談に出る人と人事 |
| 返信に対応する人と、休暇の代理を決める | 人事責任者 |
| 面談前日の一言と当日の案内 | 返信に対応する人 |
| 面談に出る | 名義の人か現場の人と人事 |
| 返信日・返した日・面談日を台帳に | 返信に対応する人 |

運用代行や代理店が支えられるのは、四つの原因の切り分け、返す文面の型、日程の出し方の型、面談の形の一段落、台帳の型までで、返すこと、日程を出すこと、面談、対応する人の決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは契約後に起きることの話です。Wantedlyで契約後に最も多く起きるのは、スカウトの文面と募集記事は整えたのに、返信が来たあとの対応が決まっておらず、返信を数日見落として、面談につながらないことです。文面と記事は「送る前」に整えられますが、返信への対応は「送ったあと」に来るので、送る前に決めていないと、来たときに慌てます。当社が契約時にお願いしているのは、「返信に誰が、いつ、何を返すか」と「面談の枠は週にいくつか」を、最初のスカウトを送る前に決めることです。この二つが決まっていれば、返信は面談につながり、決まっていなければ、返信は台帳の中で冷めていきます。

## まとめ

- 面談につながらない原因は、返しが遅い・日程を丸投げ・面談の形が見えない・対応する人が曖昧、の四つ。返信から面談までの「間」で起きる
- 返信から翌日までに、一言・複数の日程・面談の形（選考ではない・誰と・時間と形式・何を話す）を、最初の一通で返す
- 面談の枠を送る前に確保し、送る数から逆算する。枠が取れない週は送る数を減らす
- 返信は応募ではなく「話を聞きたい」。書類や志望動機を求めず、押さず、「お互いを知る場」として誘う
- 面談前の辞退は、日程までの長さ・書類の要求・「選考」への変化・確認の連絡なし・他社の速さで起きる。近い日程と前日の一言で防ぐ

## よくある質問

### 名義の人（代表）が忙しく、返信に対応できません

人事が、「〇〇（代表）に代わってご連絡します」と、人事の名前で返します。代表の名前で人事が返すと、面談で「文面と違う人」になります。面談には代表が出るなら、その旨を返す文面に書きます。代表が面談にも出られないなら、名義を現場の人に変えることを検討します。[Wantedlyのスカウトを代表の名前で送る](/media/wt-scout-daihyo/)

### 日程を出しても、相手から返事が来ません

一度だけ、間隔を空けて、「先日の日程は過ぎてしまいましたが、改めて以下はいかがでしょうか」と新しい日程で送ります。それでも来なければ、追わず、台帳に「次の連絡日」を置いて終えます。返事が来ない理由が返しの遅さや形の見えなさなら、次の相手からは直します。[Wantedlyのスカウト後のフォロー連絡](/media/wt-scout-follow/)

### 面談につながらないときの見直しは、御社に相談できますか

できます。当社は、四つの原因の切り分け、返す文面の型、日程の出し方の型、面談の形の一段落、台帳の型を支えられます。返すこと、日程を出すこと、面談、対応する人の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
