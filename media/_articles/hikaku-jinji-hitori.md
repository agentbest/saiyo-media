人事が一人。採用媒体を使いたいが、回せるか分からない。ところが、複数の媒体を持って全部が薄くなり、全部を自分でやって止まり、「時間が取れたらやる」で時間が取れず、止まりそうになると止めてしまう。**結論から言うと、一人で回るかは媒体ではなく「止まらない大きさ」で決まります。媒体は一つ、職種は一つ、送る数は自分の面談枠から逆算、返信は毎日の短い時間に固定、台帳は最小限、見直しは月に一度、型と集計は外に。3媒体の違いは「時間の使い方」（毎週コツコツ・通年で育てる・最初に集中）で、自分の時間の形に合うものを選びます。** この記事では、一人で起きる失敗、止まらない大きさ、一人で回す形、3媒体の時間の使い方、現場に頼む最小限、外に出せる作業、止まりそうなサイン、一人で回るかの判断、分担を整理します。媒体ごとの一人の運用は[人事一人でOfferBoxを回す方法](/media/ob-hitori-jinji/)、[Wantedlyのスカウトを一人で回す](/media/wt-scout-hitori/)、[ワンキャリアのスカウトを一人で回す](/media/oc-scout-hitori/)、工数が足りないときは[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)で書きました。

## この作業の目的｜一人でも「止まらない大きさ」で、続ける

一人で採用が止まる原因は、媒体ではなく、大きさです。一人で回せる大きさを超えて始め、途中で返信が遅れ、面談が詰まり、台帳が付かなくなり、止まります。止まると、それまでの接点が全部消えます。

目的は、一人で「止まらない大きさ」を先に決め、その大きさに合う媒体と形を選ぶことです。

## 一人で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 複数の媒体を持つ | 返信と更新が二つになり、どちらも遅れる |
| 全部を自分でやる | 検索、文面、送信、返信、面談、台帳、集計、企業ページ、で時間が尽きる |
| 「時間が取れたらやる」 | 取れない。週の枠を固定しないと、他の業務に取られる |
| 送る数を、枠から逆算しない | 返信が来ても会う時間がなく、待たせて離れる |
| 返信を、来るたびに返す | 一日中、通知に追われ、他の業務が止まる |
| 止まりそうなときに、止める | 小さくすれば続くのに、止めて接点が全部消える |

共通するのは、「一人で回せる大きさ」を決めずに始めていることです。

## 一人で回るかを決めるのは、「止まらない大きさ」

- **週に、採用に使える時間は何時間か**：固定できる時間だけを数える
- **その時間で、読んで書いて返して会えるのは、何人か**：一通と一面談に要る時間で割る
- **面談の枠は、週に何回か**：自分が出るなら自分の時間、現場が出るなら現場の時間
- **その大きさで、送る数と掲載の広さを決める**：大きさから媒体を選ぶ。媒体から大きさを決めない
- **大きさの出し方は[人事一人でOfferBoxを回す方法](/media/ob-hitori-jinji/)の手順2「送る数は、自分の面談枠から逆算する」**

### エージェントベストの見解

相談で最も多い思い込みは、「一人だから、手間のかからない媒体を選ぶべきだ」というものです。当社は3媒体すべての販売パートナーとして、人事が一人の会社の相談を多く受けていますが、「手間のかからない媒体」は存在せず、あるのは「時間の使い方の形が違う媒体」です。毎週コツコツ送る形、通年で書いて育てる形、最初に集中して整えて反応を見る形。一人で止まった会社は、媒体の手間が多かったのではなく、自分の時間の形（毎週少しずつ取れるのか、まとまった時間が一度取れるのか）と合わない媒体を、一人で回せる大きさを超えて始めています。当社が一人の相談を受けるとき、最初にやるのは、媒体の説明ではなく、「週に固定できる時間は何時間で、それは毎週ですか、一度にまとまってですか」を聞くことです。

## 一人で、回す形

| 決めること | 一人の答え |
|---|---|
| 媒体 | 一つ。二つ目は、一つ目が回って時間に残りがあれば |
| 職種 | 一つ。最も採りたい職種 |
| 送る数・掲載の広さ | 自分の面談枠から逆算。読める数だけ |
| 返信 | 毎日の短い時間に固定（朝と夕方の二回など）。来るたびに返さない |
| 台帳 | 最小限の項目（入口・段・日付・近さ） |
| 見直し | 月に一度だけ。週次は「返信が遅れていないか」だけ |
| 外に出す | 検索条件、文面の型、集計、見直しの材料 |
| 現場に頼む | 名義と面談。最小限 |

形の詳しくは[人事一人でOfferBoxを回す方法](/media/ob-hitori-jinji/)、[Wantedlyのスカウトを一人で回す](/media/wt-scout-hitori/)、[ワンキャリアのスカウトを一人で回す](/media/oc-scout-hitori/)で書きました。三つの記事の形は、媒体が違っても同じです。

## 3媒体の、時間の使い方と、自分の時間の形

| 媒体 | 時間の使い方 | 合う時間の形 | 止まりやすい場面 |
|---|---|---|---|
| OfferBox | 毎週コツコツ。読んで書いて送り、返信を返す | 毎週、少しずつ固定できる | 週の枠が他の業務に取られたとき |
| Wantedly | 通年で育てる。記事を書き続け、スカウトを送る | 通年で、書く時間が続けて取れる。社員が書ける | 書くことが尽きたとき、一人で書き続けたとき |
| ワンキャリア | 最初に集中。企業ページとイベントを整え、反応を見る | 最初にまとまった時間が一度取れる。その後は更新と返信 | 整えた後に更新が止まったとき |

優劣ではなく、自分の時間の形で選びます。「毎週少しずつ」ならOfferBox、「書く時間が続く」ならWantedly、「最初にまとめて、後は軽く」ならワンキャリアを先に検討します。時間の使い方の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」で書きました。

## 現場に頼む、最小限

- **名義**：文面の送り主を、現場の若手の名前で。「読んだ一文」の候補を人事が出し、現場が選ぶ
- **面談**：現場が出る。人事は日程と案内だけ
- **記事**：Wantedlyなら、「話して」もらい、人事が書く。[Wantedlyの記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/)
- **頼まないこと**：検索、文面の全部、返信、台帳、集計
- **頼み方は[人事一人でOfferBoxを回す方法](/media/ob-hitori-jinji/)の手順4と[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)**

## 外に出せる作業

- **出せる**：検索条件の案、文面の型、企業ページの型、月の集計、見直しの材料、管理画面の使い方、契約の窓口
- **出さない**：「こんな人」の決定、読んで書く最後の一文、返信、面談、企業ページの中身
- **一人の会社は、「出せる」を先に出す**：自分の時間を「読む・書く・返す・会う」に寄せる
- **代理店経由でも料金は変わらない**：出すことで費用が増えるかは見積もりで確認。[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)
- **出し方は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)**

## 止まりそうなサインと、減らし方

| サイン | 減らし方 |
|---|---|
| 返信が翌日を超え始めた | 送る数を減らす。返信の固定の時間を守る |
| 台帳が数週間、付いていない | 項目を減らす。段と日付だけに |
| 面談の日程が、二週間先になる | 送る数を減らす。現場に面談を頼む |
| 企業ページの更新が止まった | 更新の頻度を月に一度に落とす。止めない |
| 週の枠が、二週続けて取れなかった | 一時的に縮小。止めない。[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)の「繁忙期の、一時的な縮小」 |

止めると、接点が全部消えます。小さくすれば、接点は残ります。「止めるより、小さくする」が一人の原則です。

## 一人で回るかの、判断

- **週に固定できる時間が、ある**：なければ、媒体を始める前に時間を作る
- **面談に出る人（自分か現場）の枠が、週に一つ以上ある**：なければ、送っても会えない
- **返信を毎日の短い時間に固定できる**：できなければ、送る数を最小に
- **止まりそうなサインが出たら、減らせる**：減らす判断を自分でできる
- **四つが「はい」なら、一つの媒体・一つの職種で始める**：「いいえ」があれば、そこを先に。判断の型は[人事一人でOfferBoxを回す方法](/media/ob-hitori-jinji/)の「一人で回るかどうかの判断」

### エージェントベストの見解

これは向き不向きの話です。人事が一人で、週に固定できる時間がなく、面談に出る人もいない会社には、スカウト型は向きません。送っても返信を返せず、返信が来ても会えず、待たせて離れ、「媒体が効かない」になります。当社は3媒体すべてのスカウト型を扱いますが、一人の相談で「週に固定できる時間がない」と分かれば、媒体を始める前に、時間を作ること（上司と週の枠を決める、現場に面談を頼む）を先に、と勧めます。時間が作れれば、一人でも一つの媒体は回ります。時間が作れないなら、どの媒体でも止まります。一人で回るかは、媒体の選び方ではなく、時間の作り方で決まります。

## まとめ

- 一人で回るかは媒体ではなく「止まらない大きさ」で決まる。週に固定できる時間と面談の枠から、送る数と掲載の広さを逆算する
- 形は、媒体一つ・職種一つ・逆算した数・返信は毎日の短い時間に固定・台帳は最小限・見直しは月に一度・型と集計は外に・現場には名義と面談
- 3媒体の違いは時間の使い方（毎週コツコツ・通年で育てる・最初に集中）。「手間のかからない媒体」はなく、自分の時間の形に合う媒体を先に検討する
- 止まりそうなサイン（返信が翌日を超える・台帳が止まる・面談が二週間先・更新が止まる・週の枠が取れない）が出たら、止めずに小さくする。止めると接点が全部消える
- 一人で回るかの判断は四つ（固定の時間・面談の枠・返信の固定・減らす判断）。「いいえ」があれば、媒体の前にそこを作る

## よくある質問

### 一人で、二つの媒体を持つのは無理ですか

一つ目が回っていて、週の時間に残りがあり、二つ目を「一職種・短い期間」で試せるなら、持てます。一つ目が回っていない、時間に残りがない、なら二つ目は持ちません。二つ目を持つときは、返信の固定の時間を二つ分にせず、同じ時間で二つを返す形にし、台帳は入口の項目で分けます。二つ目の考え方は[年間予算百万円前後の採用媒体の組み方](/media/hikaku-yosan-100/)の「二つの組み方」で書きました。

### 上司が「一人で複数の媒体を回して、多く採れ」と言います

「止まらない大きさ」を、週の時間と面談の枠で示します。「週に〇時間で、読んで書いて返して会えるのは〇人で、それを超えると返信が遅れて離れる」の形で、数は自社の実態で。複数の媒体で数を追うと、返信が遅れ、全部が薄くなり、結果として少なくなります。一つの媒体で止まらない大きさで回した記録があれば、翌年に「時間を増やせば、これだけ増える」の根拠になります。

### 人事一人の媒体選びは、御社に相談できますか

できます。当社は、止まらない大きさの出し方、媒体の時間の使い方の整理、型と集計、管理画面の使い方、契約の窓口、減らし方の型を支えられます。大きさの決定、読んで書くこと、返信、面談、減らす判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
