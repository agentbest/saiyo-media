「オファーはいつ送るのが効くのか」「何時に送ればいいのか」という質問を受けます。**結論から言うと、時期は「学生が動く時期」と「自社が面談できる時期」の重なりで決め、時間帯は「送った直後に返信できる時間」で決めます。「効く時期」が先にあるのではなく、自社の体制が先です。** 学生が動く時期は卒年ごとに変わり、就職活動のスケジュールも見直されるので、この記事では具体的な月日や時刻には触れません。決め方の考え方だけを書きます。送る数の決め方は[オファー送信ペースの決め方](/media/ob-soushin-pace/)で書きます。この記事は「いつ」の話です。

## この作業の目的｜送った先で止まらない時期を選ぶ

送る時期を決める目的は、承認が来たあとに止まらないようにすることです。

承認は、送った直後から数日の間に来ることが多く、承認された学生は「次に何が来るか」を待っています。ここで面談の案内が遅れると、学生の温度が下がり、他社の選考が進みます。つまり、送る時期を決めるとは、「承認のあとに面談できる時期に送る」ことです。

「学生が最も動いている時期に送る」だけを考えると、自社の面談枠が足りない時期に承認が集中し、対応が遅れて止まります。学生の動きと自社の体制、両方を見ます。

## 手順1｜学生が動く時期を、卒年ごとに確認する

学生がプロフィールを登録し、更新し、オファーを開く時期には、山があります。インターンを探す時期、企業を調べ始める時期、選考が動く時期。ただし、この山は卒年ごとに変わり、就職活動の全体のスケジュールも見直されます。

確認の仕方を並べます。

1. **媒体の公式の案内を見る**：OfferBoxの企業向けの案内には、学生の登録や動きの時期の目安が示されることがあります。そこを起点にする
2. **前年の自社の実績を見る**：前年に送った時期と承認の時期を並べると、自社の学生像が動く時期が見える
3. **代理店に聞く**：複数の企業の運用を見ている代理店なら、時期の傾向を言える。当社も3媒体の運用を見ている立場から、傾向はお伝えできる
4. **卒年が変わったら、また確認する**：前年と同じと決めない

この記事に時期を書かないのは、書いた時点で古くなるからです。確認の手順を持っておくほうが、毎年使えます。

## 手順2｜自社の採用計画の時期を置く

学生の動きとは別に、自社の採用計画の時期があります。

| 採用計画 | 送る時期の考え方 |
|---|---|
| 早い時期に少人数と深く接点を持ちたい | 学生が企業を調べ始める時期に、絞って送る。面談は少人数で丁寧に |
| 解禁後に幅広く母集団を作りたい | 選考が動く時期に合わせて、数を送る。面談枠を多く用意する |
| 内定辞退の補充 | 辞退が出た時期に、絞って送る。学生の動きが落ち着いている時期でも、動いている学生はいる |
| 通年で少しずつ | 山を作らず、毎週一定の数を送る。面談枠も毎週一定 |

自社の計画がどれかで、送る山を作る時期が決まります。学生の動きの山と自社の計画の時期が重なるところが、送る時期です。重ならないなら、自社の計画を学生の動きに寄せるか、学生の動きが小さい時期でも送るかを決めます。採用計画の決め方は[OfferBoxのターゲット設計](/media/ob-target-sekkei/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。「送る時期」より先に「面談できる時期」を決めることです。当社がOfferBoxの運用代行で送る時期を決めるとき、最初に聞くのは学生の動きではなく、「承認された学生と、どの週に、誰が、何枠で会えるか」です。面談枠が無い週に送ると、承認が溜まり、案内が遅れ、学生が離れます。学生の動きの山に合わせて送りたい会社でも、その山の時期に面接官の予定が埋まっているなら、送る時期をずらすか、面談枠を先に確保するかのどちらかです。当社は3媒体すべての販売パートナーとして契約後の運用を見ていますが、「時期は合っていたのに承認が面談につながらなかった」会社の多くは、面談枠を先に決めていませんでした。面談枠が先、送る時期はそれに合わせて。この順番を勧めます。

## 手順3｜競合が集中する時期への向き合い方

学生が動く時期は、多くの企業が同じ時期に送ります。学生のオファー一覧が混み、自社の文面が埋もれやすくなります。

向き合い方は2つあります。

- **山に乗る**：学生が最も動いている時期に送る。埋もれやすいが、開かれれば承認されやすい。文面の件名にあたる部分と冒頭で、他社と見分けがつく形にする。書き方は[オファー文面の構成](/media/ob-offer-kosei/)
- **山をずらす**：競合が少ない時期に送る。学生の動きは小さいが、一覧が空いていて開かれやすい。動いている学生に絞って届く

どちらが向くかは、自社の知名度と文面の質で変わります。知名度がなく、文面で見分けてもらう会社は、山をずらすほうが読まれやすいことがあります。知名度があり、開かれれば承認される会社は、山に乗るほうが数が出ます。

両方をやる形もあります。山の前に少数を送って反応を見て、山で数を送り、山のあとに補充する。この形だと、山の前の反応で文面を直してから山に入れます。

## 手順4｜時間帯は「返信できる時間」で決める

「学生が見やすい時間帯」を探す会社は多いのですが、当社が勧めるのは「送った直後に返信できる時間帯」に送ることです。

理由は、承認が送った直後に来ることが多く、承認への返信が速いほど面談につながりやすいからです。学生が見やすい時間帯に送っても、その時間に社内の誰も返信できなければ、承認から返信までが空きます。

| 時間帯の決め方 | 考え方 |
|---|---|
| 送った直後に返信できる時間 | 担当が管理画面を見られる時間帯に送る。承認に当日中に返信する |
| 学生が見やすい時間 | 会社ごとに違う。前年の自社の承認の時間帯を見て、傾向があれば寄せる |
| 両方が重なる時間 | 理想。担当の勤務時間の中で、前年の承認が多かった時間帯 |
| 深夜や早朝 | 学生が見る時間かもしれないが、返信できない。避ける |

「送る時間帯」と「返信する時間帯」は、セットで決めます。送るだけ送って返信が翌日以降になるなら、送る時間帯を返信できる時間に寄せるほうが、面談につながります。承認のあとの連絡の手順は、この後の記事で書きます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「効く時期」を探して送り始めない | 時期を待っている間に、動いている学生に届かない | 面談枠がある週から送り始める |
| 学生の動きの山に合わせたが、面談枠が無い | 承認が溜まり、案内が遅れて離れる | 面談枠を先に決め、送る時期を合わせる |
| 前年と同じ時期に送る | 卒年で学生の動きが変わっている | 卒年ごとに公式の案内と前年の実績で確認する |
| 山に乗るだけで文面が他社と同じ | 一覧で埋もれる | 件名にあたる部分と冒頭で見分けがつく形に |
| 学生が見やすい時間に送って、返信は翌日 | 承認から返信までが空く | 返信できる時間帯に送る |
| 送る時期を1回の山だけにする | 山の前後の学生に届かない | 山の前に少数、山で数、山の後に補充 |

最も多いのは、「学生の動きの山に合わせたが、面談枠が無い」です。時期は合っているのに、承認が面談につながらない原因になります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 学生が動く時期を確認する | 人事（公式の案内、前年の実績、代理店） |
| 自社の採用計画の時期を置く | 人事と経営・事業部門 |
| 面談枠を確保する | 面接官（現場） |
| 送る時期を決める | 人事（面談枠に合わせて） |
| 送る時間帯と返信の担当を決める | 人事 |
| 承認に返信する | 送った時間帯に管理画面を見られる人 |

面談枠の確保が、現場の仕事として最初に来ます。人事が送る時期を決める前に、現場が「この週は何枠」を出す。この順番だと、送ったあとに止まりません。運用代行に出す場合、送る時期と時間帯は代行が管理できますが、面談枠は社内で確保します。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

媒体を比べたり時期を決めたりするときに、「この時期は承認率が高い」という数字で判断する会社は多いのですが、時期ごとの承認率は分母の作り方で変わります。学生が動く時期は送る企業も多く、学生は多くの文面の中から選ぶので、開かれた数に対する承認は下がりやすい。動きが小さい時期は送る企業が少なく、開かれれば承認されやすいが、開かれる数そのものが少ない。同じ「承認率」でも、何に対する率かが違います。当社がOfferBoxの運用を見るときは、時期ごとの率を横に比べるのではなく、「その時期に送った学生のうち、面談まで進んだのは何人か」を、自社の前年と比べます。率ではなく、面談に進んだ数で時期を見る。それが、自社にとって効く時期を知る唯一の方法です。

## まとめ

- 送る時期は、学生が動く時期と自社が面談できる時期の重なりで決める。面談枠が先
- 学生が動く時期は卒年ごとに変わる。公式の案内、前年の実績、代理店で毎年確認する
- 競合が集中する時期は、山に乗るか、ずらすか、両方をやるか。知名度と文面の質で決める
- 時間帯は「学生が見やすい時間」より「送った直後に返信できる時間」で決める
- 時期ごとの承認率は分母が違う。面談に進んだ数を自社の前年と比べる

## よくある質問

### いつ送るのが一番効きますか

「一番効く時期」は、卒年と自社の学生像で変わるので、この記事では書いていません。決め方は、公式の案内と前年の実績で学生が動く時期を確認し、自社が面談できる時期と重ねることです。面談枠がある週から送り始めるのが、最も無駄がありません。

### 学生が見やすい時間帯に送るべきではないですか

見やすい時間帯に送っても、その時間に社内の誰も返信できなければ、承認から返信までが空きます。返信できる時間帯に送り、承認に当日中に返信するほうが、面談につながります。前年の自社の承認の時間帯に傾向があれば、その中で返信できる時間に寄せます。

### 送る時期の設計は、御社に頼めますか

頼めます。当社がOfferBoxの運用代行を受けるときは、面談枠を先に確認し、それに合わせて送る時期と時間帯を決めます。学生が動く時期の傾向は、3媒体の運用を見ている立場からお伝えできます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
