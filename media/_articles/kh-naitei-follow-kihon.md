内定を出したあと、辞退を防ぐためにフォローをしたい。ところが、何をすればよいか分からず、月に一度の連絡と、内定者の懇親会と、入社前の課題を並べて、内定者から「忙しいのに」と思われ、連絡が来なくなり、入社の直前に辞退される。**結論から言うと、フォローは「つなぎ止める」作業ではなく、内定者が入社の日まで「この会社で何をするか」を具体的に持ち続けられる状態を作る作業です。中身は「読むもの・話す相手・会う場・答えてくれる窓口」の四つで、連絡の頻度より「次に何があるか」が見えていることが効きます。イベントと課題で埋めるフォローは、内定者の時間を奪って離れます。承諾前と承諾後で分け、承諾後は入社の日から逆算して並べます。** 年間の並べ方は[内定者フォローの年間計画](/media/kh-naitei-follow-nenkan/)、遠方の内定者は[オンラインでの内定者フォロー](/media/kh-naitei-follow-online/)で書きます。この記事は、基本の四つと分け方を書きます。

## この作業の目的｜内定者が「何をするか」を、入社の日まで持ち続けられる状態を作る

内定者が辞退する時期は、内定の直後より、承諾から入社までの間が多く、理由は「他社」より「この会社で何をするか分からなくなった」が多いです。選考で聞いた話は、時間が経つと薄れ、他社の内定者の話や、家族の意見や、就職の情報で上書きされます。

フォローの目的は、内定者に会社を好きになってもらうことではなく、「入社したら誰と何をするか」を具体的なまま持ち続けてもらうことです。

## 内定者フォローで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 連絡の回数を増やす | 中身の無い連絡が増え、内定者が疲れ、返事が遅くなる |
| イベントと課題で埋める | 内定者の時間を奪い、「入社前から拘束される」と離れる |
| 人事だけが接点になる | 入社後に一緒に働く人が見えず、「何をするか」が具体にならない |
| 承諾前と承諾後を同じにする | 承諾前に懇親会を入れて「囲い込み」と読まれ、承諾後に接点が途切れる |
| 内定者どうしを比べさせる | 課題の出来や発言で序列ができ、静かな内定者が離れる |
| 辞退の兆しを見ずに続ける | 返事が遅くなった内定者に、同じ連絡を続けて、辞退の連絡で初めて気付く |

共通するのは、フォローを「会社がすること」で組み立てていて、「内定者が持ち続けたいもの」で組み立てていないことです。

## フォローの中身は、四つ

| 中身 | 何を用意するか | いつ |
|---|---|---|
| 読むもの | 配属先の仕事の中身、最初の年に何をするか、一緒に働く人の紹介、社内の日常が分かるもの | 承諾前から。内定通知と一緒に。[内定連絡の文面](/media/kh-bunmen-naitei/) |
| 話す相手 | 選考で会った現場の社員、年の近い先輩。人事ではない人 | 承諾前に一度、承諾後に定期的に |
| 会う場 | 配属先の職場、仕事をしている様子、同期になる内定者 | 承諾後。入社の日から逆算して |
| 答えてくれる窓口 | 質問を送れば数日で返る先。人事と、現場の一人 | 承諾前から入社まで、途切れさせない |

四つのうち、最も効くのは「話す相手」です。人事ではない、入社後に一緒に働く人と話した内定者は、「何をするか」を具体的に持ち続けられます。

### エージェントベストの見解

相談で最も多い思い込みは、「内定者フォローは、連絡を絶やさないことと、内定者を集めるイベントを増やすことだ」というものです。当社は3媒体すべての販売パートナーとして、内定後の運用まで見ていますが、連絡とイベントを増やした会社ほど、内定者の返事が遅くなり、辞退が減りません。内定者は学生で、卒業の研究と、アルバイトと、残りの学生生活があります。会社からの連絡とイベントが増えるほど、「入社前から拘束される」と読み、他社の内定者の「向こうは何も言ってこない」と比べて離れます。当社が最初にお願いするのは、連絡とイベントの数を減らし、「話す相手」を人事から現場の社員に変えることです。選考で会った現場の社員が、承諾の前に一度、承諾の後に何度か、内定者と話す。話す中身は会社の説明ではなく、「最近の仕事で何があったか」です。それを聞いた内定者は、「入社したらこの人とこの仕事をする」を持ち続けます。人事からの月一の連絡より、現場からの一通の「今週こんなことがあった」のほうが、辞退を減らします。

## 承諾前と、承諾後で分ける

- **承諾前**：「決めるための材料」を渡す。読むものと、話す相手と、答えてくれる窓口。会う場（懇親会）は入れない。承諾前の懇親会は「囲い込み」と読まれる
- **承諾後**：「入社の日まで持ち続けるもの」を渡す。会う場を入社の日から逆算して並べ、話す相手との接点を定期にする
- **承諾の直後**：最も接点が途切れやすい時期。承諾の返事に、「次に何があるか」を書く

承諾前に押すと、承諾は取れても、承諾後に「押されて決めた」と気付いて辞退します。承諾前は押さず、材料を渡し、承諾後に接点を作ります。

## 連絡の頻度より、「次に何があるか」

内定者が不安になるのは、連絡が少ないときではなく、「次にいつ何があるか」が見えないときです。

- **連絡のたびに、次を書く**：「次は〇月に配属先の見学があります。その前に△△を送ります」
- **年間の予定を、承諾後に一度渡す**：入社までに何がいつあるか。[内定者フォローの年間計画](/media/kh-naitei-follow-nenkan/)
- **予定の無い月は、無いと伝える**：「〇月は会社からの連絡はありません。質問はいつでも」
- **返事を求めない連絡を混ぜる**：現場からの「今週こんなことがあった」は、返事が要らない

「次に何があるか」が見えていれば、連絡は少なくてよく、内定者は自分の時間を持てます。

## 辞退の兆しを、見る

- **返事の日数が延びる**：以前は翌日に返っていた返事が、一週間後になる
- **質問が無くなる**：承諾前に多かった質問が、承諾後に止まる
- **会う場を欠席する**：理由が「予定が」と曖昧
- **話す相手（現場の社員）が「様子が変わった」と言う**：人事より先に気付くのは現場

兆しがあれば、連絡を増やすのではなく、話す相手（現場の社員）が一度、会社の話ではない話をする場を作ります。「最近どう」の一通で足ります。

## 内定者から、聞く

- **選考で、分かりにくかったところ**：翌年の文面と面談に戻す。[内定者の声を採用に戻す方法](/media/ob-naiteisha-katsuyou/)
- **内定後に、分からなくなったこと**：フォローの読むものに足す
- **他社の内定者の話**：他社が何をしているかを、内定者から聞く。真似るためではなく、自社の四つに欠けが無いかを見るため

聞く場は、承諾期限の前の面談と、承諾後の話す相手との接点です。人事が聞くより、現場の社員が聞くほうが、本当のことが返ります。

## 媒体ごとに、変わる点

- **OfferBox**：オファーの文面で読んだ仕事と、内定後に渡す読むものが同じ言葉であること。文面の名義の社員が、話す相手になると早い。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **Wantedly**：記事で読んだ日常と、承諾後に渡す読むものをつなげる。記事を書いた社員が話す相手になる。[Wantedly経由の内定辞退が続くとき](/media/wt-naitei-jitai/)
- **ワンキャリア**：体験談で読んだ選考と、内定後の接点で会う人が同じ会社だと分かる形に。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

三つとも、四つの中身は同じで、入口で読んだものと、内定後に渡すものを、同じ言葉でつなげることが要です。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 四つの中身を決め、承諾前と承諾後に分ける | 採用の責任者 |
| 読むものを作る | 人事。配属先の責任者が確認 |
| 話す相手 | 選考で会った現場の社員、年の近い先輩。人事ではない |
| 会う場の日程 | 人事と配属先の責任者。入社の日から逆算 |
| 答えてくれる窓口 | 人事と、現場の一人。数日で返す |
| 辞退の兆しを見る | 話す相手（現場の社員）が人事に伝える |
| 内定者から聞いたことを翌年に戻す | 採用の責任者 |

運用代行や代理店が支えられるのは、四つの型、読むものの下書き、年間の並べ方までで、話す相手、会う場、窓口の返事は社内が担います。

### エージェントベストの見解

内定者フォローを四つに分けて、当社が先にお伝えしているのは、「話す相手」を現場の社員にすると、現場の時間が要る、ということです。人事が月に一度の連絡で済ませていたところを、現場の社員が承諾前に一度、承諾後に何度か話す形にすると、一人の内定者に対して現場の社員の時間が数時間は要ります。申し込んだあとに内定後の運用が止まる会社に共通するのは、この時間を先に確保せず、現場に「内定者と話しておいて」と頼んで、現場の繁忙期に途切れることです。当社が案内するのは、内定を出す前に、話す相手になる現場の社員と、その時間（承諾前に一度、承諾後に月に一度、それぞれ何分）を配属先の責任者と決めておくことです。時間が取れないなら、内定者の数に対して話す相手を増やすか、会う場を減らして話す相手に寄せます。四つのうち、話す相手だけは代行できません。そこに現場の時間を先に置くことが、フォローの基本です。

## まとめ

- フォローは「つなぎ止める」作業ではなく、内定者が「この会社で何をするか」を入社の日まで持ち続けられる状態を作る作業
- 中身は「読むもの・話す相手・会う場・答えてくれる窓口」の四つ。最も効くのは、人事ではない現場の社員という「話す相手」
- 承諾前は材料を渡して押さず、会う場は入れない。承諾後は入社の日から逆算して並べ、承諾の直後に「次に何があるか」を書く
- 連絡の頻度より「次に何があるか」が見えていること。イベントと課題で埋めない
- 辞退の兆し（返事の日数・質問の減り・欠席）は現場が先に気付く。兆しがあれば連絡を増やさず、現場が一度話す

## よくある質問

### 内定者が多く、現場の社員が一人ずつ話す時間が取れません

一人の社員が複数の内定者を持つ形にし、会う場を減らして、話す相手に時間を寄せます。懇親会を一つ減らせば、その準備の時間で、現場が内定者と話す時間が作れます。それでも足りないなら、話す相手を年の近い先輩に広げ、人事は窓口に回ります。

### 内定者から連絡が来なくなりました。辞退でしょうか

兆しですが、辞退と決めずに、話す相手（現場の社員）から「最近どう」の一通を送ります。会社の話ではなく、近況を聞くだけの一通です。返事が来たら、次に何があるかを伝えます。来なければ、人事から一度だけ、答えてくれる窓口としての連絡をします。同じ連絡を繰り返さないことです。

### 内定者フォローの型は、御社に相談できますか

できます。当社は、四つの型、読むものの下書き、年間の並べ方を支えられます。話す相手、会う場、窓口の返事は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、内定後の運用まで含めて支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
