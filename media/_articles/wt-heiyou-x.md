社員や代表がXを使っていて、採用に活かせないかと考えている。あるいは、Wantedlyの記事をXで流しているが、何をXに書き、何をWantedlyに書くかが決まっていない。**結論から言うと、Xは「短い言葉で今日の場面を流す場」、Wantedlyは「判断に使う中身を残す場」で、役割が違います。使い分けるなら、本人の名義で今日の場面を流し、応募の判断に要ること（何をしている会社か、なぜか、誰と何をするか、最初の年）はWantedlyに書き、本音の範囲は両方で同じ線を引くことです。** この記事では、それぞれの役割、使い分けの分担、書くことの線、公式と本人の名義、本音の範囲、工数、やりがちな失敗、社内の分担を整理します。Wantedlyの記事をSNSで広げる方法は[Wantedlyの記事をSNSで広げる方法](/media/wt-sns-kakusan/)、SNS全般は[SNSからの母集団形成](/media/kh-boshudan-sns/)で書きました。Xの仕様や数値は書きません。

## それぞれの役割｜Xは「今日を流す」、Wantedlyは「中身を残す」

| | X | Wantedly |
|---|---|---|
| 言葉の長さ | 短い。一つの場面、一つの感想 | 長い。場面の前後、理由、誰と |
| 時間 | 流れる。今日のことが、明日には下がる | 残る。記事は積み上がり、書き直せる |
| 読む人 | フォローしている人。同業、知人、業界の人が多い | 会社を探している人、会社を読みに来た人 |
| 名義 | 本人の名義が届く。公式は届きにくい | 会社の名義で、社員が話す |
| 応募の導線 | ない。読む場所へ連れていく | 募集記事に「話を聞きに行きたい」がある |
| 向く中身 | 今日あったこと、考えたこと、記事を出した知らせ | 何をしている会社か、なぜか、誰と何をするか |

Xは、会社を探している人が最初に来る場所ではありません。すでにフォローしている人に、今日の場面が流れる場所です。その中に、会社を読みに来る人がいれば、Wantedlyに連れていけます。判断に要る中身は、流れる場所には置けないので、残る場所に置きます。

## 使い分けの分担｜本人が今日を流し、Wantedlyが中身を持つ

- **Xに書くのは、本人の名義で、今日の一つの場面**：「今日、〇〇の場面で△△だった」。会社の判断や制度の説明は書かない
- **Wantedlyに書くのは、その場面の前後と理由**：Xで流した場面を、ストーリーで「なぜそうしたか」「誰と」まで書く
- **記事を出したら、記事に出た本人がXで一言添えて流す**：公式が「記事を公開しました」と流すより届く。届く形は[Wantedlyの記事をSNSで広げる方法](/media/wt-sns-kakusan/)
- **Xから会社ページへの導線を置く**：プロフィールに会社ページ、記事を流すときに記事の場所。応募の導線はWantedlyの側にだけ
- **面談で「Xを見ていたか」「記事を読んだか」を聞き、台帳に残す**：Xが効いているかは、来た人の言葉で分かる

Xは、Wantedlyに人を連れてくる導線の一つで、Wantedlyの代わりにはなりません。逆に、Wantedlyの記事をXに貼らずに置いておくと、会社を探している人にしか読まれません。両方あると、「今日を見て興味を持った人」が「中身を読んで判断する」流れができます。

### エージェントベストの見解

相談で最も多い思い込みは、「Xで見ている人が多い社員がいるので、採用に効くはずだ」というものです。当社は3媒体すべての販売パートナーとして、社員のXを採用に使いたいという相談を受けますが、その社員のXを見ている人の多くは、同業の人、取引先、業界の知人で、会社を探している候補者ではありません。Xで見ている人の数が多くても、会社ページに来る人は別の数で、面談で「Xを見て来た」と言う人がいるかで効いているかが分かります。効かせるなら、その社員に「会社を宣伝してもらう」のではなく、その社員のストーリーをWantedlyで先に書き、本人が今日の場面を流すときに記事に戻る導線を持ってもらうことです。見ている人の数ではなく、「本人の場面が記事にあるか」で、Xから来る人が決まります。

## Xに書くことと、Wantedlyに書くことの線

| Xに書く | Wantedlyに書く |
|---|---|
| 今日の一つの場面。感想。考えたこと | 場面の前後、理由、誰と、何が変わったか |
| 記事を出した知らせと、本人の一言 | 記事そのもの |
| 仕事の外の、本人の関心（本人の判断で） | 会社の「なぜ」、事業、最初の年、条件 |
| 会社の出来事の一報（イベント、新しい仲間） | 出来事の中身と、それが誰にとってどういう意味か |
| 書かない：制度の説明、条件、数値、判断の経緯 | 書く：制度は実態で、条件は募集記事で、数値は確認したものだけ |

- **Xに制度や条件を書かない**：変わったときに、流れた言葉は直せない。Wantedlyの記事は直せる
- **Xに書いたことと、Wantedlyの記事がずれない**：Xで「自由な社風」、記事で「厳しい」では、読んだ人が迷う
- **本人が書く言葉のトーンを、記事にも寄せる**：話すときの言葉で。[Wantedlyの文章のトーンの決め方](/media/wt-bunsho-tone/)
- **Xで反応があった場面を、ストーリーの題材にする**：反応が、候補者が知りたい場面の手がかりになる

## 公式と本人の名義、本音の範囲

- **公式アカウントは、記事の一報と会社の出来事に絞る**：公式が「本音」を語ると、宣伝に読まれる。公式の使い方は[Wantedlyの記事をSNSで広げる方法](/media/wt-sns-kakusan/)の「公式アカウントの使い方」
- **本人の名義で書くかは、本人が決める**：会社が書かせない。書く社員がいなければ、Xは使わない
- **本音の範囲は、Wantedlyと同じ線で引く**：Xだから出せる、はない。出せる本音と出さない本音の線は[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)
- **書く前に会社が見る、はしない。書いたあとに会社が消させる、もしない**：線を先に合意しておく。線の中は本人の判断
- **候補者や取引先が特定できることは、どちらにも書かない**：Xは特に、相手に届く

本人の名義で書くことには、辞めたあとも本人の発信が残る、という性質があります。会社の言葉として使わせるのではなく、本人の発信に会社の場面が含まれる形にしておくと、辞めたあとも本人にとって不都合が残りません。

## 工数の置き方

| 項目 | X | Wantedly |
|---|---|---|
| 時間の性格 | 短く、毎日か週に数回。本人の時間 | 月に数本。人事と話す社員の時間 |
| 外に出せる部分 | 出せない。本人の言葉でなければ届かない | 整える部分は出せる。話す中身は出せない |
| 続かなくなる原因 | 本人が忙しい、反応がない、書くことを会社に決められた | 記事を書く時間がない、話す社員がいない |
| 費用 | 費用は本人の時間 | プランの費用。公式ページで確認 |

- **Xを義務にしない**：続ける社員の時間を、業務として認めるかは会社が決める。認めないなら、求めない
- **Wantedlyの時間を先に固定する**：Xがあっても、記事がなければ連れてくる先がない
- **Xの反応で記事を判断しない**：反応があっても会社ページに来ていなければ、採用には効いていない

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 公式で記事の一報だけ流す | 届かず、「効かない」で止まる | 記事に出た本人が一言添えて流す |
| Xに制度や条件を書く | 変わったときに直せず、記事とずれる | 制度と条件はWantedlyに |
| 社員にXを書かせる | 本人の言葉でなくなり、続かない | 書くかは本人が決める |
| Xと記事で会社の姿がずれる | 読んだ人が「どちらが本当か」と迷う | 本音の線を同じにする |
| フォローの数で効果を見る | 会社ページに来たかと別の数字で判断する | 面談で「見たか」を聞く |

最も多いのは、一つ目です。公式アカウントで記事の公開を流し、反応がなく、「Xは効かない」で終わります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| Xに書くことと書かないことの線を決める | 人事と責任者 |
| 本音の範囲を、Wantedlyと同じ線で合意する | 人事と、書く社員 |
| 本人の名義で書くかを決める | 本人 |
| 記事を出したら、本人が一言添えて流す | 記事に出た社員 |
| 公式アカウントで一報を流す | 人事 |
| 面談で「見たか・読んだか」を聞き、台帳に残す | 面談に出る人 |
| Xの反応があった場面を、ストーリーの題材にする | 人事 |

運用代行や代理店が支えられるのは、役割の整理、書くことの線の型、本音の範囲の整理、台帳の型までで、線の決定、本人が書くかの判断、書く中身、面談で聞くことは企業と本人が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。自社で決めるべきなのは、「Xに書かないこと」の線、本音の範囲、本人が書くかどうかの尊重、までです。ここから先の、記事を流すときの形、公式の使い方、台帳の型は、外に出せます。逆に、「何を書くか」まで会社が決めると、本人の言葉でなくなり、見ている人に会社の宣伝だと読まれて、届かなくなります。当社がXとWantedlyの使い分けの相談を受けるとき、最初に確かめるのは、「Xで今日の場面を流している社員の、ストーリーがWantedlyにあるか」です。あれば、本人が流す今日の場面が、記事に戻る導線になります。なければ、Xに何を書くかの前に、その社員のストーリーを書くことから始めてもらいます。書くことを決めるのではなく、戻る先を用意するのが、会社の側の仕事です。

## まとめ

- Xは「短い言葉で今日の場面を流す場」、Wantedlyは「判断に使う中身を残す場」。Xは導線で、Wantedlyの代わりにはならない
- 本人の名義で今日の場面を流し、場面の前後と理由、会社の「なぜ」、最初の年、条件はWantedlyに書く
- Xに制度や条件を書かない。Xと記事で会社の姿をずらさない。本音の範囲は同じ線で
- 公式は一報に絞る。本人が書くかは本人が決め、会社は「書かないこと」の線だけ決める
- フォローの数で見ない。面談で「Xを見たか、記事を読んだか」を聞いて台帳で見る

## よくある質問

### 代表がXで発信しています。採用に使えますか

代表の「なぜ」が、Wantedlyの会社ページに代表の言葉の場面で書かれていれば、代表のXから会社ページへ戻る導線になります。Xで今日の場面を流し、会社ページで「なぜ」を読む流れです。会社ページに「なぜ」がなければ、Xで興味を持った人の行き先がありません。[代表のストーリーの書き方](/media/wt-story-daihyo/)

### 社員がXで会社のことを書くのを、会社が確認すべきですか

書く前に確認する形は、本人の言葉でなくなるので勧めません。「書かないこと」の線（候補者や取引先が特定できること、制度や条件、数値）を先に合意し、線の中は本人の判断に任せます。線を越えたときにどうするかも、先に決めておきます。

### WantedlyとXの使い分けは、御社に相談できますか

できます。当社は、役割の整理、書くことの線の型、本音の範囲の整理、台帳の型を支えられます。線の決定、本人が書くかの判断、書く中身、面談で聞くことは、企業と本人が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
