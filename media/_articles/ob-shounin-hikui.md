OfferBoxで、オファーは開封されているのに承認されない、という相談があります。開封と承認は別の段で、開封の原因（最初に見える一文、時期、届いているか）を直しても、承認は変わりません。**結論から言うと、承認率が低いときに疑う原因は三つで、「送る相手が募集の『こんな人』とずれている」「本文に学生のプロフィールの具体と最初の1年の場面が無い」「開封後に読む企業ページが本文と揃っていない」の順に切り分けます。開封率を上げた直後に承認率が下がるなら、最初の一文が煽りに寄っています。承認した学生と承認しなかった学生の共通点を台帳で見て、月に一か所だけ直します。承認率の目安を他社と比べません。** この記事では、開封と承認が別の段である理由、三つの原因とサインと直し方、煽りで起きること、台帳での見方、月に一か所、分担を整理します。開封の見直しは[OfferBoxでオファーが開封されないときの見直し順](/media/ob-kaifu-sarenai/)で書きました。この記事は、その次の段の話です。承認の仕組みや数字の見え方は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜「開封→承認」の段で、どこが細いかを見つける

学生がオファーを開き、本文を読み、企業ページを見て、承認するかを決めます。承認率が低いということは、「開いたあと」のどこかで学生が離れているということです。

目的は、開いたあとの三つの場所（本文、企業ページ、そもそもの相手）のどこで離れているかを見つけ、そこだけを直すことです。開封の原因と混ぜると、直す場所を間違えます。

## 開封と承認は、別の段

| 段 | 学生がすること | 決めるもの |
|---|---|---|
| 開封 | 一覧で最初に見える一文を見て、開く | 最初の一文、時期、届いているか |
| 本文を読む | 「自分のことを読んでいるか」「何をする仕事か」を見る | 本文の具体、最初の1年の場面 |
| 企業ページを見る | 「本文と同じことが書いてあるか」を確かめる | 企業ページと本文の整合 |
| 承認する | 「話を聞いてみよう」と決める | 送る相手が合っているか、本文と企業ページの結果 |

「開封は良いのに承認が低い」は、最初の一文は効いているが、そのあとの本文か企業ページか相手に原因がある状態です。開封の見直しをここで繰り返しても、変わりません。

## 三つの原因

### 原因1｜送る相手が、募集の「こんな人」とずれている

| 見えるサイン | 直し方 |
|---|---|
| 開封する学生に共通点が無い | 検索条件を、募集の「こんな人」から作り直す。[OfferBoxの検索条件の設計](/media/ob-kensaku-jyoken/) |
| プロフィールが薄い学生に多く送っている | 書き込んでいる学生を優先する |
| 大学名や学部だけで絞っている | 学生時代の活動や興味で絞る。[OfferBoxのターゲット設計](/media/ob-target-sekkei/) |
| 読まずに送っている（送る数が読める数を超えている） | 読める数まで減らす |
| 希望の業界や職種が自社と大きく違う学生に送っている | 「こんな人」に合う学生に絞る。希望は絶対の条件ではないが、本文で重ねられない相手には送らない |

「送る相手がずれている」は、承認率の原因の中で最も多く、最も見落とされます。文面を直す前に、送った学生の一覧を見ます。

### 原因2｜本文に、学生の具体と最初の1年の場面が無い

| 見えるサイン | 直し方 |
|---|---|
| 本文が会社の説明から始まる | 学生のプロフィールの箇所から始める。[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/) |
| 学生のプロフィールの引用が、冒頭の一行だけ | 活動や興味の具体的な箇所を引用する。[OfferBoxのプロフィールの読み方](/media/ob-profile-yomikata/) |
| 「経験を活かせる」「成長できる」の抽象語 | 最初の1年の場面に置き換える |
| 仕事の中身が職種名と業務の一覧 | 最初の月に何をするかを書く |
| 誰と話せるかが無い | 入社してまもない社員の名前と、話す場の形を書く |
| 本文が長く、学生の具体が下に埋もれる | 会社の説明を削り、3段の構成に。[OfferBoxのオファー文面の構成](/media/ob-offer-kosei/) |
| 相手ごとに変えていない | 変える2か所を毎回書く。[OfferBoxのオファー文面の個別化](/media/ob-offer-personalize/) |

「本文が会社の説明から始まる」は、開封の一文が効いていても、本文で「結局、会社の話か」と離れる形です。

### エージェントベストの見解

相談で最も多い思い込みは、「承認率が低いのは、文面の魅力が足りないからだ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、「承認率が低い」という相談で、送った学生の一覧を見ると、募集の「こんな人」と合わない学生に多く送っていることがあります。プロフィールが薄い学生、希望が大きく違う学生、大学名だけで絞った学生。この学生は、開封しても承認しません。文面をどれだけ磨いても、相手がずれていれば変わりません。当社が承認率の相談を受けるとき、最初にやるのは、文面を読むことではなく、承認した学生と承認しなかった学生の一覧を並べて、共通点を見ることです。共通点が見つかれば、直すのは検索条件で、文面ではありません。

### 原因3｜企業ページが、本文と揃っていない

| 見えるサイン | 直し方 |
|---|---|
| 本文で挙げた「最初の1年」が、企業ページに無い | 企業ページに足すか、本文から外す。[OfferBoxの企業ページの書き方](/media/ob-kigyo-page/) |
| 企業ページが会社紹介中心で、仕事の具体が無い | 最初の1年と働く人の話を前に |
| 本文で「話す場」と書いたのに、企業ページの選考の流れに話す場が無い | 揃える |
| 企業ページの写真が古い、集合写真と外観だけ | 普段の仕事中の写真に |
| 本文と企業ページで、条件や勤務地が違う | 揃える。採用サイトを正にする |
| 企業ページの更新が止まっている | 年度の切れ目と、変わったときに |

学生は、本文で興味を持つと、企業ページで確かめます。そこで「本文と違う」「仕事の具体が無い」となると、承認しません。

## 開封率を上げた直後に、承認率が下がる理由

開封の見直しで最初の一文を直したあと、承認率が下がることがあります。

- **最初の一文が煽りに寄った**：「限定」「特別」で開かれるが、本文で「煽りだった」と分かる
- **最初の一文と本文がつながっていない**：一文で挙げた活動が、本文に出てこない
- **開封する学生の層が変わった**：煽りで開く学生は、募集に合わない学生が多い
- **開封が増えた分、本文の薄さが目立つ**：前は開かれなかった学生が開いて、本文で離れる

「開封が増えて承認が減った」は、最初の一文を戻して、本文を直す順番です。開封と承認を同時に見ます。

## 承認した学生と、しなかった学生を台帳で見る

| 見ること | 分かること |
|---|---|
| 承認した学生の、学年・活動・プロフィールの量 | 合う相手の傾向。検索条件に反映 |
| 承認しなかった学生の、共通点 | ずれている条件 |
| 承認した学生に送った本文の、学生の一文 | 効いた一文の型 |
| 承認しなかった学生に送った本文 | 薄かった一文、会社の説明の長さ |
| 承認した学生が、企業ページのどこを見たか（面談で聞く） | 企業ページの効いた部分 |
| 承認から面談までの時間 | 次の段の材料 |

「面談で『企業ページのどこを見て承認しましたか』と聞く」が、企業ページの原因を確かめる直接の材料です。台帳の型は[OfferBoxのKPI設計](/media/ob-kpi-sekkei/)で書きました。

## 承認率の目安を、他社と比べない

- **承認率の水準は、送る相手と募集と時期と文面で変わる**：一般の目安と比べても、自社の判断には使えない
- **自社の前月と、前年の同じ時期と比べる**：変化で見る
- **開封率と承認率を、別々に見る**：どちらが細いかで、直す場所が違う
- **承認率だけを追わない**：承認→面談→選考の段で見る。承認が増えても面談に来なければ、次の段の問題

「一般の目安と比べない」は、開封率と同じ原則です。この記事では、目安の数字は書きません。

## 月に一か所だけ、直す

- **三つの原因のうち、該当する一か所だけを直す**：相手か、本文か、企業ページか
- **直す前の状態を記録する**
- **翌月の変化を見る**：承認率と、承認した学生の傾向
- **変わらなければ、次の原因へ**
- **変わっても、面談の段を見る**：承認だけで判断しない

順番は、相手→本文→企業ページです。相手がずれたまま本文を直しても、承認する相手がいません。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 承認した学生としなかった学生の一覧を並べる | 人事 |
| 検索条件を募集の「こんな人」から作り直す | 人事と、その職種の責任者 |
| 本文の学生の一文と最初の1年の場面を書く | 送る人（入社してまもない社員か人事） |
| 企業ページを本文と揃える | 人事 |
| 面談で「企業ページのどこを見たか」を聞く | 面談に出る人 |
| 月に一か所直し、翌月の変化を見る | 人事 |

運用代行や代理店が支えられるのは、三つの原因の切り分けの型、台帳での見方、検索条件の設計、本文の型、企業ページとの整合の点検までで、送る相手の決定、本文を書くこと、面談で聞くこと、直すかどうかの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社がOfferBoxで「承認率が低い」という相談を受けたとき、最初に確かめるのは、開封率が低いのか、開封はされていて承認だけが低いのか、です。前者なら開封の見直しで、後者ならこの記事の三つの原因です。次に、承認した学生としなかった学生の一覧を並べて、送る相手のずれを見ます。ずれが無ければ本文を、本文に学生の具体があれば企業ページを、の順です。逆から始めると、企業ページを直したのに相手がずれていた、ということになります。承認率は、文面の魅力ではなく、「合う相手に、本人の具体と最初の1年の場面を書き、企業ページで受け止める」の三つが揃ったときに上がります。

## まとめ

- 開封と承認は別の段。開封は良いのに承認が低いなら、開いたあとの三つの場所（相手・本文・企業ページ）のどこかで離れている
- 原因は、送る相手が「こんな人」とずれている、本文に学生の具体と最初の1年の場面が無い、企業ページが本文と揃っていない、の順に切り分ける
- 開封率を上げた直後に承認率が下がるなら、最初の一文が煽りに寄っている。一文を戻して本文を直す
- 承認した学生としなかった学生の共通点を台帳で見て、面談で「企業ページのどこを見たか」を聞く
- 承認率の目安を他社と比べず、自社の前月と前年で変化を見る。月に一か所だけ、相手→本文→企業ページの順で直す

## よくある質問

### 文面を直しても、承認率が変わりません

送る相手を先に見ます。承認した学生としなかった学生の一覧を並べ、しなかった学生に共通点（プロフィールが薄い、希望が大きく違う、大学名だけで絞った）があれば、検索条件を直します。相手がずれたままでは、文面を直しても承認する相手がいません。

### 開封率も承認率も低いのですが、どちらから直せばよいですか

開封からです。開封されなければ本文は読まれず、承認の原因を確かめられません。開封の見直し（設定・時期・相手・最初の一文）を先に行い、開封が動いてから、承認の三つの原因を見ます。ただし、「送る相手」は開封と承認の両方に効くので、最初に見ます。

### OfferBoxの承認率の見直しは、御社に相談できますか

できます。当社は、三つの原因の切り分けの型、台帳での見方、検索条件の設計、本文の型、企業ページとの整合の点検を支えられます。送る相手の決定、本文を書くこと、面談で聞くこと、直すかどうかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
