ワンキャリアには、企業から学生にスカウトを送る仕組みがあります。ただし、ワンキャリアの学生は、スカウトの文面だけで会社を判断しません。文面を読んだあと、自社の企業ページと、他の学生が書いた体験談とクチコミを読んで判断します。**結論から言うと、ワンキャリアのスカウトは、「体験談を読み込んでいる学生に送るもの」として設計します。送る前に企業ページ（選考の流れと何を見るか、よく聞かれること）を整え、募集の「こんな人」から送る相手を絞り、プロフィールを読める数だけ送り、文面は「プロフィールの何を読んだか」「この仕事の最初の1年との重なり」「選考の流れと何を見るかの一文」「話す場か選考か」の4つを短く書きます。テンプレの一斉送信、条件だけ、選考を急がせる文面は、体験談を読んだ学生には届きません。** この記事では、ワンキャリアのスカウトの位置づけ、送る前に整えるもの、誰に送るか、何を送るか、やりがちな失敗、返信後の動き、分担を整理します。スカウトの送信の仕組み、対象の学生の範囲、上限はプランと時期で異なり変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。この記事は、運用の考え方の話です。他の媒体のスカウトの基本は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)と[Wantedlyのダイレクトスカウトの基本](/media/wt-scout-kihon/)で書きました。

## この作業の目的｜文面で興味を持った学生が、企業ページと体験談で「確かめて来る」状態にする

ワンキャリアのスカウトを受け取った学生がたどる順は、「文面→企業ページ→自社の体験談とクチコミ→話す場か選考」です。他の媒体と違うのは、「体験談」が間に入ることです。

目的は、文面で興味を持った学生が、企業ページと体験談で確かめて、「読んだとおりだ」と納得して来ることです。文面が良くても、企業ページが薄いか、体験談と揃っていなければ、そこで離れます。スカウトは、企業ページと体験談が整ってから始めます。

## ワンキャリアのスカウトの位置づけ

| 媒体 | スカウトを受け取る学生の状態 | 文面のあとに読むもの |
|---|---|---|
| OfferBox | オファーを受け取る前提で登録し、プロフィールを就職活動向けに書いている | 企業ページ |
| Wantedly | 転職や就職を決めていない人も多い | 会社ページ、募集記事、ストーリー |
| ワンキャリア | 体験談とクチコミを読んで、選考の実態を知ろうとしている | 企業ページと、自社の体験談・クチコミ |

「自社の体験談を読まれる」が、ワンキャリアのスカウトの前提です。文面で「選考は丁寧です」と書いても、体験談に「連絡が遅かった」とあれば、体験談が信じられます。

## 送る前に、整えるもの

1. **企業ページ**：選考の流れと各段階で何を見るか、仕事の最初の1年、働く人、よく聞かれること。[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)
2. **自社の体験談とクチコミを読んでいること**：何が書かれているかを知らずに送らない。「掲載と違った」があれば、先に直す
3. **選考の流れの掲載**：スカウトから選考に誘うなら、その流れが掲載されている。[本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)
4. **返信への対応の担当と、連絡の目安**：返信が来てから決めない
5. **話す場（説明会、面談）の用意**：選考の前に話す場があるなら、その掲載

整っていない状態で送ると、文面で興味を持った学生が企業ページで離れ、体験談で疑います。

### エージェントベストの見解

これは順番の話です。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、「スカウトの返信が来ない」という相談で、文面より先に確かめるのは、企業ページと、自社の体験談です。文面を整えても、スカウトを受け取った学生がたどり着く企業ページが会社紹介から始まり、体験談に「何を見ているか分からなかった」と書かれていれば、返信は来ません。逆に、企業ページに「各段階で何を見るか」があり、体験談に「企業ページどおりだった」とある会社は、文面が短くても、学生が確かめて返信します。当社が勧める順番は、企業ページ、体験談を読む、選考の掲載、その次にスカウトです。スカウトを先に始める会社は、返信が来ない理由を文面に求めますが、直すべきは文面の先にあるものです。

## 誰に送るか

- **募集の「こんな人」から、絞る条件を作る**：学生時代の状態、興味、専攻（問わないなら問わない）。募集記事の「こんな人」の考え方は[新卒向け募集記事の書き方](/media/wt-boshu-shinsotsu/)
- **プロフィールを読める数だけ送る**：読まずに送る数を増やさない。読める数が、送れる数
- **プロフィールを読んで、「この学生に、この仕事の話をしたい」と言える相手だけに**：言えないなら送らない
- **絞り込みの条件は、管理画面で使えるものから**：項目は仕様で変わる
- **自社の体験談を書いてくれた学生への扱いは、媒体の規約を確認する**：規約は管理画面とヘルプで

「読める数が送れる数」は、他の媒体のスカウトと同じ原則です。ワンキャリアでも、テンプレの一斉送信は、体験談を読み込んでいる学生ほど見抜きます。

## 何を送るか｜4つの要素

| 要素 | 書き方 |
|---|---|
| 1. プロフィールの何を読んだか | 学生時代の活動や興味を、本人の言葉で。「〇〇を続けてこられたと書かれていたのを読んで」。学生向けの読み方は[新卒向けスカウト文面の型](/media/wt-scout-bunmen-rei-shinsotsu/) |
| 2. この仕事の最初の1年との重なり | 「うちの〇〇職は、最初の月に△△から始めます。□□を続けてきたあなたに合うと思い」。企業ページの「最初の1年」と同じ言葉 |
| 3. 選考の流れと何を見るかの一文 | 「選考は〇〇と△△で、学生時代の話を場面で聞きます。詳しくは企業ページに」。体験談を読んだ学生の問いに先に答える |
| 4. 話す場か、選考か | 「まず仕事の話を聞く場があります」か「選考にご案内します」か。曖昧にしない。年度の公表内容と自社の方針を確認 |

「3. 選考の流れと何を見るかの一文」が、ワンキャリアのスカウトに特有の要素です。学生は体験談で「選考はどうか」を読んでいるので、文面で会社の側からも一言添えると、企業ページに読みに行く理由になります。

4つを、短く書きます。会社の説明は企業ページに任せ、文面には書きません。

## やりがちな失敗

| 失敗 | 学生からどう見えるか |
|---|---|
| テンプレの一斉送信 | 「誰にでも送っている」。体験談を読み込む学生ほど見抜く |
| 条件だけ（給与、勤務地）で誘う | 求人票。体験談で実態を読んでいるので、条件だけでは動かない |
| 選考を急がせる（「すぐにエントリーを」「〇日までに」） | 押されている。「集まっていない会社」 |
| 企業ページが整っていないのに送る | 文面で興味を持っても、企業ページで離れる |
| 体験談と違うことを文面に書く | 「文面は良く書いてある」。体験談が信じられる |
| 「選考は丁寧です」「風通しが良い」の抽象語 | 体験談の具体に負ける |
| 送りっぱなしで、返信への対応が遅い | 体験談に「スカウトをもらって返信したが、連絡が遅かった」と書かれる |
| 学生時代の活動を読まずに、大学名や専攻だけで送る | 「読んでいない」 |

最も多いのは、最初の「テンプレの一斉送信」です。送る数を増やせば返信も増える、と考えた結果ですが、ワンキャリアの学生は、体験談で「スカウトはテンプレだった」と書きます。

## 返信が来たあと

1. **翌日までに返す**：スカウトの返信への対応は、体験談に書かれる
2. **文面で案内した場（話す場か選考か）に、そのとおりに進める**：文面と違う流れにしない
3. **話す人は、文面に書いた人か、その職種の入社してまもない社員**：人事だけでない
4. **面談や面接で、企業ページに書いたことを話す**：文面と企業ページと面談が揃っていることが、信用になる
5. **返信への対応の速さと内容を、台帳に残す**：次の体験談に書かれることの記録

「文面で案内した場に、そのとおりに進める」が要点です。「まず話す場」と書いて選考に入れると、体験談に「話す場と聞いたのに選考だった」と書かれます。返信後の基本は[スカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)で書きましたが、ワンキャリアでは「体験談に書かれる」が加わります。

## 送る人と、件数の考え方

- **送る数は、プロフィールを読める数で決める**：読める数が、送れる数
- **送るのは、人事か、その職種の入社してまもない社員**：後者の名前で送ると、学生に近い
- **返信に対応できる数に収める**：返信が来たのに対応できないなら、送る数が多すぎる
- **話す場や面接の枠から逆算する**：枠が無ければ、送っても活かせない
- **送信の上限や仕組みは、プランと時期で異なる**：管理画面で確認する

考え方は[スカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/)と同じで、面接の枠から逆算します。

| 送る | 人事か、入社してまもない社員 |

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「ワンキャリアのスカウトは、体験談が少ない会社でも、文面次第で学生を集められる」という点です。当社がワンキャリアのスカウトの支援をするとき、当社が出せるのは絞り込みの条件と文面の型までで、学生が文面のあとに読む企業ページと体験談は、社内の運用の結果です。体験談がまだ無い会社は、企業ページが学生の最初の印象になるので、企業ページを整えてから送ります。体験談があって「掲載と違った」と書かれている会社は、スカウトより先に、掲載か運用を直します。当社が最初にお伝えするのは、「スカウトは、企業ページと体験談が受け止められる状態になってから」ということです。文面は、そこへ連れて行くためのもので、そこが整っていなければ、文面は入口だけになります。

## まとめ

- ワンキャリアのスカウトは「体験談を読み込んでいる学生に送るもの」。文面→企業ページ→自社の体験談→話す場か選考、の順にたどられる
- 送る前に、企業ページ、体験談を読むこと、選考の掲載、返信対応の担当、話す場を整える
- 誰に送るかは、募集の「こんな人」から絞り、プロフィールを読める数だけ。「この学生に、この仕事の話をしたい」と言える相手だけに
- 何を送るかは、プロフィールの何を読んだか・最初の1年との重なり・選考の流れと何を見るかの一文・話す場か選考か、の4つを短く
- テンプレの一斉送信、条件だけ、選考を急がせる、体験談と違うことを書く、が届かない文面。返信には翌日までに対応し、文面で案内した場にそのとおりに進める

## よくある質問

### 自社の体験談がまだ無い状態で、スカウトを送ってよいですか

企業ページが整っていれば、送れます。体験談が無い場合、学生は文面のあとに企業ページで判断するので、企業ページが最初の印象になります。企業ページに「選考の流れと何を見るか」と「最初の1年」があれば、学生は確かめられます。整っていなければ、先に整えます。

### スカウトの文面に、選考の流れまで書く必要がありますか

一文で足ります。「選考は〇〇と△△で、学生時代の話を場面で聞きます。詳しくは企業ページに」。ワンキャリアの学生は、体験談で「選考はどうか」を読んでから来るので、会社の側からも一言添えると、企業ページを読みに行く理由になります。詳しくは企業ページに任せます。

### ワンキャリアのスカウトの運用は、御社に相談できますか

できます。当社は、送る前の企業ページと体験談の確認、絞り込みの条件の設計、4つの要素の型、返信対応の流れの設計を支えられます。プロフィールを読むこと、相手ごとの一文、返信への対応、話す場と面接は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
