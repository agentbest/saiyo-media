中途採用で、総合型の転職サービス（doda）に求人を出していて、Wantedlyも使っている、または使おうとしている。二つの違いは分かっていても、「求人票に何を書き、Wantedlyに何を書くか」「総合型から来た候補者に、Wantedlyの記事をどう読んでもらうか」「対応の時間と書く時間を、一人でどう分けるか」「掲載期間が終わったらどうするか」が決まっていないと、対応に追われて記事が止まり、Wantedlyが「使っていない媒体」になります。**結論から言うと、総合型は「求人票と複数の窓口で、候補者に会う場」、Wantedlyは「会った候補者が、会社の中身を読む場」です。使い分けるなら、求人票には条件と仕事の中身を、Wantedlyの会社ページには「なぜ」と場面を書き、総合型から来た候補者に面接の前に記事を読んでもらい、対応の時間と書く時間を別の日に置き、掲載期間が終わってもWantedlyを止めないことです。** この記事では、それぞれの役割、書くことの線、記事を読んでもらう導線、時間の置き方、掲載期間と通年、台帳、工数、やりがちな失敗、社内の分担を整理します。二つの違いそのものは[Wantedlyとdodaの違い](/media/hikaku-wantedly-doda/)で書きました。この記事は、両方を持ったあとの運用の使い分けを扱います。両サービスの仕様と数値は書きません。

## それぞれの役割｜「窓口で会う」と「会社を読む」

| | 総合型（doda） | Wantedly |
|---|---|---|
| 候補者が来る経路 | 求人の掲載、企業からの連絡、紹介など、複数の窓口とされています。現在の構成は公式で確認 | 会社ページとストーリーを読んで、「話を聞きに行きたい」と来る |
| 候補者の状態 | 転職活動中。条件と職種で会社を並べている。会社の中身は求人票の範囲 | 会社を読んでいる。会社で選んでいる |
| 会社が出すもの | 求人票、窓口ごとの対応 | 会社ページ、ストーリー、募集記事 |
| 時期 | 掲載期間がある。期間内に集中する | 通年。記事が残る |
| 人事の時間の使い先 | 窓口ごとの対応、応募の受付、面接の設定 | 記事を書く、返信する、面談する |
| 残るもの | 採用した人、求人票の型 | 記事、会社ページ、面談の言葉 |

総合型から来る候補者は、条件と職種で会社を並べ、面接の前に会社名で検索して会社を調べます。調べた先に、会社ページの「なぜ」とストーリーがあると、「条件は合うが、どんな会社か分からない」が「条件も合い、働く場面も想像できる」になります。Wantedlyは、Wantedlyから来た人だけのものではなく、総合型から来た人が読む「会社の説明書」でもあります。

## 求人票に書くことと、Wantedlyに書くことの線

| 求人票（総合型） | Wantedly |
|---|---|
| 職種、仕事の中身、条件（給与の範囲、勤務地、時間、休日） | 会社の「なぜ」を代表の言葉の場面で |
| 応募の要件、選考の流れ | 社員が何をどう変えた場面（ストーリー） |
| 会社概要の公式の説明 | 最初の三か月で何をするか、誰と組むか |
| 「会社の中身はこちら」の導線（置ける形は仕様で確認） | 募集記事。条件は求人票と同じ |
| 書かない：「アットホーム」「風通し」の抽象語 | 書かない：求人票の貼り直し |

- **条件は、求人票と募集記事で同じにし、同じ日に直す**：ずれると、確かめる段で離れる。[Wantedlyの募集記事に条件をどこまで書くか](/media/wt-boshu-joukenn/)
- **求人票の「仕事の中身」と、募集記事の「最初の三か月」を揃える**：文章は違ってよい。中身がずれない
- **求人票に会社の「なぜ」を長く書かない**：並べて比べる場では読まれない。Wantedlyに置く
- **求人票と記事を、最後に同じ人が見る**

### エージェントベストの見解

これは切り分けの話です。総合型とWantedlyを併用するとき、自社で持つべきなのは、会社ページの「なぜ」を代表の言葉で決めること、ストーリーで社員が話す中身、面接、求人票の条件の決定、までです。ここから先の、求人票の整備、窓口ごとの一次の対応、Wantedlyの記事を整える部分、台帳の型は、外に出せます。当社は3媒体すべての販売パートナーとして、総合型と併用する会社のWantedlyを見ていますが、対応に追われる人事が、外に出せる「対応」を抱え、外に出せない「なぜ」と「話す中身」を後回しにしている形が多くあります。順番が逆です。対応は型があれば人を替えられますが、「なぜ」と「話す中身」は自社の人にしか出せません。時間が足りないとき、当社が先に外に出すことを勧めるのは、対応の一次の部分で、記事の中身ではありません。この線で分けると、対応に追われる月でも、記事の時間が残ります。

## 総合型から来た候補者に、記事を読んでもらう導線

- **求人票に、会社ページへの導線を置く**：置ける形と範囲は、総合型の現在の仕様で確認。置けないなら、面接の案内の中で
- **面接の案内に、「面接の前にこちらを」と会社ページとストーリーの場所を添える**：総合型から来た候補者の多くは、会社をまだ読んでいない
- **面接の冒頭で「読んでいただけたか、どこが気になったか」を聞く**：読んでいれば、記事の場面から。読んでいなければ、会社の説明から
- **面接に、ストーリーに出た社員を出す**：読んで来た候補者が、同じ人に会う
- **面接で聞いた「読んだ場面」を、台帳に残す**：総合型から来た人にも、記事が効いているかが分かる

「思っていたのと違う」で内定のあとに離れる候補者は、面接の前に会社の中身を読んでいないことが多くあります。

## 対応の時間と書く時間を、別の日に置く

- **総合型の対応は、日を決めてまとめる**：窓口ごとの確認、応募の受付、面接の設定。毎日少しずつではなく、週に決めた日に
- **Wantedlyの記事の時間は、対応の日と別の日に固定する**：同じ日に置くと、対応に吸われる
- **掲載の開始と終了の時期に、対応の時間が増えることを見込む**：その時期の記事の時間を、前後にずらす
- **書く時間は、「話す社員の時間」と「整える人事の時間」に分ける**：話すのは月に一度の短い時間、整えるのは人事
- **一人で回すなら、対応の日と書く日を週に一日ずつ**：[人事1人でWantedlyのスカウトを回す方法](/media/wt-scout-hitori/)

時間が足りないときの直し方は[Wantedlyの運用に工数が足りないとき](/media/wt-kousuu/)で書きました。総合型と併用する会社で最も多いのは、「対応が忙しくて書けない」で、書けないのではなく、書く日がないことがほとんどです。

## 掲載期間と通年｜掲載が終わっても、Wantedlyを止めない

- **総合型の掲載期間は、採用の枠に合わせて決まる**：期間が終わると、求人票は下がる
- **Wantedlyの記事は、掲載期間と関係なく残す**：期間が終わったあとに会社を読んだ人の行き先になる
- **掲載期間の中で集めた「候補者の言葉」を、掲載が終わったあとにストーリーにする**：面接で聞かれたこと、辞退の理由。次の掲載の求人票の元にもなる
- **次の掲載までの間に、会社ページを直す**：掲載の時期は対応で時間がなく、間の時期が書く時期
- **掲載を再開するときに、会社ページが今の内容になっているかを確認する**：再開の前に一度

## 台帳を一つにする

- **入口の列に「総合型（どの窓口か）」と「Wantedly」を持つ**：応募と「話を聞きに行きたい」はそれぞれの中で、面接から先は共通の段
- **同じ候補者が両方から来たら、最初の入口と決め手の入口を記録し、連絡は一本に**
- **「何を見て来たか」の一行を、入口を問わず残す**：求人票の条件か、会社ページの「なぜ」か、ストーリーの場面か
- **段と基準は、入口を問わず同じ**：総合型から来た人を、応募が多いからと別の基準にしない

台帳と段の揃え方は[Wantedlyを含む複数媒体の効果を並べて見る方法](/media/wt-heiyou-heiyou-kpi/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 求人票をWantedlyに貼る | 会社の「なぜ」がなく、読みに来た人が閉じる | 線を分けて書く |
| 総合型の候補者に記事を案内しない | 会社を読まずに面接に来て、「思っていたのと違う」 | 面接の案内に添える |
| 対応の日と書く日を同じにする | 対応に吸われ、記事が止まる | 別の日に固定 |
| 掲載が終わるとWantedlyも止める | 期間外に会社を読んだ人の行き先がない | 記事は残し、間の時期に書く |
| 総合型の応募数とWantedlyの数を並べる | 前提の違う数で判断し、Wantedlyを止める | 面接から先で並べる |

最も多いのは、三つ目です。対応が忙しい週に「記事はあとで」になり、そのまま掲載期間が終わります。

| 作業 | 誰が |
|---|---|
| 求人票の条件と、募集記事の条件を揃える | 人事 |
| 会社ページの「なぜ」を代表の言葉で | 人事と代表 |
| ストーリーを話す | 社員。人事が整える |
| 総合型の対応（日を決めて） | 人事（一次は外に出せる） |
| 面接の案内に記事を添える。面接で「読んだか」を聞く | 人事と面接官 |
| 対応の日と書く日を決める | 人事と責任者 |
| 掲載の時期と、間の時期の書く計画 | 人事 |

### エージェントベストの見解

両方を使い始めたあと、最初の掲載期間で起きることに共通するのは、掲載期間の終わりと一緒に、Wantedlyの更新も終わることです。当社はWantedlyの運用を申込のあとまで見ていますが、総合型の掲載期間に合わせて採用を「期間」で考える会社では、掲載が終わると人事の関心が次の業務に移り、会社ページがその時点で止まります。次の掲載を始めるときに、半年前の会社ページのまま求人票を出し、面接の前に会社を調べた候補者が古い情報を見る、という形です。掲載期間は「求人票が出ている期間」で、「会社を読む人がいる期間」ではありません。当社が併用する会社に勧めているのは、掲載が終わった週に、面接で聞いた候補者の言葉を一本のストーリーにすることです。間の時期に書いておくと、次の掲載の前に会社ページが今の内容になり、求人票から読みに来た候補者が「今の会社」を読めます。

## まとめ

- 総合型は「求人票と複数の窓口で候補者に会う場」、Wantedlyは「会った候補者が会社の中身を読む場」。Wantedlyは総合型から来た人の「会社の説明書」でもある
- 求人票には条件と仕事の中身を、Wantedlyには「なぜ」と場面を。条件は同じにして同じ日に直す。求人票を貼らない
- 総合型から来た候補者に、面接の案内で記事を添え、面接の冒頭で「読んだか」を聞く。ストーリーに出た社員を面接に出す
- 対応の日と書く日を別に固定する。一人なら週に一日ずつ
- 掲載期間が終わってもWantedlyを止めない。間の時期に、面接で聞いた言葉をストーリーにし、次の掲載の前に会社ページを今の内容に

## よくある質問

### 総合型で応募が十分に来ているのに、Wantedlyを続ける意味はありますか

総合型から来た候補者が、面接の前に会社を読む場所として意味があります。応募の数を増やすためではなく、「思っていたのと違う」で内定のあとに離れる候補者を減らすためです。面接の案内に記事を添え、面接で「読んだか」を聞くと、続ける意味が候補者の言葉で分かります。

### 掲載期間の中は、Wantedlyの記事を書く時間がありません

掲載期間の中は、対応の日を決めてまとめ、記事は「更新の日を月に一度」だけ守ります。新しく書くのは、掲載が終わった週からです。掲載期間に面接で聞いた言葉をメモしておくと、間の時期に書く題材になります。書けない時期があってよく、止まらない形にしておくことが大切です。

### Wantedlyとdodaの使い分けは、御社に相談できますか

できます。当社は、役割の整理、書くことの線の型、導線の置き方、台帳の型、求人票の整備、一次の対応、Wantedlyの整える部分を支えられます。「なぜ」の決定、話す中身、条件の決定、面接は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
