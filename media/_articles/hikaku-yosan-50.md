年間の採用予算が、五十万円台。この予算で、どの媒体を使えばよいか。ところが、「この予算で使える安い媒体」を探して回り、見つかった媒体に薄く分け、質を削って数を追い、一年で結果が出ずに全部やめる。**結論から言うと、この予算帯は「媒体を選ぶ」より「一つに絞って、時間で補う」年です。媒体は一つ、職種は一つ、時期は集中、運用は自社で、削るのは幅で質は削りません。何が契約できるかは見積もりと契約で確認し、翌年の元を作る年にします。** この記事では、この予算帯で起きる失敗、予算帯が変わっても変わらないもの、先に決めること、3媒体の検討順、削るものと残すもの、見積もりで確認すること、上司への説明、分担を整理します。金額や料金はこの記事では扱いません。3媒体の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)、予算の配分の考え方は[母集団形成の予算配分](/media/kh-boshudan-yosan/)、媒体ごとの少ない予算の運用は[予算が少ない会社のOfferBox運用](/media/ob-yosan-sukunai/)、[予算が少ない会社のWantedly運用](/media/wt-yosan/)、[予算が少ない会社のワンキャリア運用](/media/oc-yosan/)で書きました。

## この作業の目的｜少ない予算を、「翌年の元」に変える

この予算帯で、今年、採る人数に届くかは、媒体ではなく、担当の時間で決まります。予算が少ない年に作るべきものは、「型」「台帳」「こんな人の一枚」「企業ページ」で、どれも費用がかからず、翌年に残ります。

目的は、この予算帯を「安い媒体を探す年」ではなく、「一つの媒体で型を作り、翌年の元を残す年」にすることです。

## この予算帯で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 「安い媒体」を探して回る | 「こんな人」に届くかではなく、金額で選び、届かない |
| 複数の媒体に、薄く分ける | どれも回らず、全部が「効かなかった」になる |
| 「予算が少ないから代行は無理」と決めつける | 代行に出せる範囲（型と集計）を見ずに、全部を一人で抱えて止まる |
| 質を削る | 読む時間、返信の速さ、面談に出る人を削り、届いても決まらない |
| 一年で結果が出ないと、全部やめる | 型も台帳も残らず、翌年に一から |
| 金額だけで、媒体を決める | 契約の型（定額か、決まったときに費用が発生するか）と時間の使い方を見ていない |

共通するのは、予算の額を先に置いて、「何をするか」を後から合わせていることです。順番は逆です。

## 予算帯が変わっても、変わらないもの

- **「こんな人」の一枚**：入社後に合う人を、行動の事実で。費用はかからない。[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)
- **一人ずつ読んで書くこと**：[スカウト文面の基本](/media/kh-bunmen-kihon/)
- **返信を当日か翌日に返すこと**
- **面談に、現場が出ること**
- **企業ページに、「こんな人」が自分で選べる材料を置くこと**：[掲載からの母集団形成](/media/kh-boshudan-keisai/)
- **台帳で段ごとに数えること**：[採用ファネルの作り方](/media/kh-boshudan-funnel/)

予算が少ない年は、この「変わらないもの」を、時間で作る年です。予算が増えても、これがなければ届きません。

### エージェントベストの見解

相談で最も多い思い込みは、「予算が少ないから、代理店を通さずに媒体と直接契約したほうが安い」というものです。当社は3媒体すべての販売パートナーとして、この予算帯の相談を受けていますが、代理店経由でも企業が払う料金は媒体の正規の料金で、代理店の手数料は媒体の側から出ます。予算の面で、直接か代理店かは変わりません。変わるのは、型と集計と管理画面の使い方と契約の窓口を、代理店が支えるかどうかです。この予算帯で担当が一人なら、その支えの有無が、一年で型が残るかを分けます。仕組みは[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)で書きました。当社がこの予算帯の相談を受けるとき、最初にやるのは、「安くする方法」ではなく、「一つの媒体で、担当の時間で、何を残せるか」を一緒に決めることです。

## この予算帯で、先に決めること

| 決めること | この予算帯の答え |
|---|---|
| 媒体の数 | 一つ。二つ目は翌年 |
| 職種の数 | 一つ。最も採りたい職種か、最も「こんな人」が言葉にできる職種 |
| 時期 | 集中する時期だけ。通年で薄く回さない |
| 運用 | 自社で。外に出すなら、型と集計だけ |
| 契約の型 | 定額か、決まったときに費用が発生するか。自社の採る人数と時間で選び、見積もりで確認 |
| 残すもの | 「こんな人」の一枚、型、台帳、企業ページ。翌年の元 |

「一つ」に絞ることが、この予算帯の全部です。一つを回す時間があれば、この予算帯でも母集団はできます。順番は[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)の「組み合わせの、順番」で書きました。

## 3媒体の、検討順

優劣ではなく、この予算帯で「先に検討する順番」を、条件ごとに置きます。契約の型と金額は見積もりで確認してください。

- **「こんな人」が条件で言え、週に数時間、読んで書ける人がいる** → OfferBoxを先に。費用が後ろに来る型があり、送る時間を毎週確保できる会社に向く。[予算が少ない会社のOfferBox運用](/media/ob-yosan-sukunai/)
- **社員が会社の想いを言葉にでき、通年で書き続けられる** → Wantedlyを先に。書けば書くほど活かせる型で、書く時間が費用の代わりになる。[予算が少ない会社のWantedly運用](/media/wt-yosan/)
- **送り続ける時間は取れないが、最初に企業ページを整える時間はある** → ワンキャリアを先に。最初に集中して整え、反応を見る型。[予算が少ない会社のワンキャリア運用](/media/oc-yosan/)
- **どれも時間が取れない** → 媒体を増やす前に、時間を作る。[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)

同じ予算でも、担当の時間の「使い方」（毎週コツコツ・通年で育てる・最初に集中）で、先に検討する媒体が変わります。時間の使い方の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」で書きました。

## 削るものと、残すもの

| 削る（幅） | 残す（質） |
|---|---|
| 媒体の数、職種の数 | 「こんな人」の一枚 |
| 送る時期（集中する時期だけ） | 一通あたりの読む時間 |
| 送る数（読める数に） | 返信の当日返し |
| 台帳の項目（最小限） | 面談に現場が出ること |
| 見直しの頻度（月に一度） | 企業ページの、自分で選べる材料 |
| 外に出す範囲（型と集計だけ） | 型を作ること |

「残す」の側は、費用がかからず、時間だけで作れます。予算が少ない年に「残す」を削ると、届いても決まらず、翌年に元が残りません。削る順番は[予算が少ない会社のOfferBox運用](/media/ob-yosan-sukunai/)の「削るのは、費用ではなく『運用の幅』」で書きました。

## 見積もりで、確認すること

- **契約の型と期間**：定額か、決まったときに費用が発生するか。期間の途中で止められるか
- **この予算で、何が含まれ、何が含まれないか**：行ごとに分けて読む
- **前提条件**：採る人数、職種の数、送れる数の枠。現在の仕様は管理画面とヘルプで確認
- **書かれていないもの**：更新の費用、翌年の条件
- **代理店経由でも料金が変わらないこと**：[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)
- **見積もりの見方は[代理店の見積もりの見方](/media/kh-dairiten-mitsumori/)**

金額と契約の形は、見積もりと契約で確認してください。この記事では扱いません。

## 上司への説明

- **「この予算で、これだけ採れる」と約束しない**：採れる数は、担当の時間と型で決まる
- **「一つの媒体で、型と台帳と一枚を残す年」と説明する**：翌年の元
- **削るものと残すものを、分けて見せる**：質は削らない
- **翌年、予算が増えたときに、今年の元がどう効くかを添える**
- **説明の型は[予算が少ない会社のOfferBox運用](/media/ob-yosan-sukunai/)の「上司への説明」と[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)**

| 作業 | 誰が |

| 「こんな人」の一枚を作る | 人事と現場 |
| 契約の型を、採る人数と時間で選び、見積もりで確認する | 人事責任者と管理部門 |

| 面談に出る | 現場 |

運用代行や代理店が支えられるのは、媒体と契約の型の整理、型と集計、管理画面の使い方、契約の窓口までで、「こんな人」の決定、読んで書くこと、返信、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。この予算帯の相談で、「予算が少ないので、今年は様子見で小さく複数を試したい」と言われることがあります。当社は3媒体を扱いますが、この予算帯で複数を試すことを勧めません。小さく複数を試すと、どれも回る前に予算と時間が尽き、「どれも効かなかった」で全部が終わり、翌年に残るものがありません。当社がお願いする順番は、一つを選ぶ、その一つで型と台帳と一枚を作る、翌年に二つ目を足すか判断する、です。一つで回した年は、数が少なくても、翌年の元が残ります。当社にとっても、一つが回って翌年に続くほうが、複数が薄く回って一年で終わるより、長く続きます。

## まとめ

- この予算帯は「媒体を選ぶ」より「一つに絞って、時間で補う」年。媒体は一つ、職種は一つ、時期は集中、運用は自社で
- 予算帯が変わっても変わらないもの（「こんな人」の一枚・読んで書く・当日返し・現場が出る・自分で選べる材料・台帳）を、時間で作る年
- 3媒体の検討順は、担当の時間の使い方（毎週コツコツ・通年で育てる・最初に集中）で決まる。金額で決めない
- 削るのは幅（媒体・職種・時期・送る数・台帳の項目・外に出す範囲）で、質は削らない。代理店経由でも料金は変わらない
- 金額と契約は見積もりと契約で確認。上司には「これだけ採れる」ではなく「翌年の元を残す年」と説明する

## よくある質問

### この予算で、本当に採れますか

採れる数は、予算ではなく、担当の時間と型で決まります。一つの媒体で、一つの職種に、読んで書いて当日に返し、現場が面談に出る形が回れば、この予算帯でも「こんな人」に近い人と会えます。回らなければ、予算が増えても採れません。今年の数を約束するより、今年の型を残すことを目標に置くと、翌年に効きます。

### 予算が少ないので、代行に出すのは無理ですよね

全部を出すのは無理でも、型と集計だけを出す形はあります。代理店経由でも料金は変わらないので、費用の面で代理店を避ける理由はありません。代行に出す範囲を「型と集計と管理画面の使い方」に絞れば、担当一人でも回る範囲が広がります。範囲の分け方は[予算が少ない会社のOfferBox運用](/media/ob-yosan-sukunai/)の「外に出すなら、型と集計だけ」で書きました。

### この予算帯の媒体選びは、御社に相談できますか

できます。当社は、媒体と契約の型の整理、型と集計、管理画面の使い方、契約の窓口を支えられます。「こんな人」の決定、読んで書くこと、返信、面談は、企業が行ってください。金額と契約は見積もりと契約で確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
