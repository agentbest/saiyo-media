「大学群は絞ったほうがいいのか、広げたほうがいいのか」という質問を受けます。**結論から言うと、どちらが正しいかは決まっておらず、判断の軸は「大学群が自社にとって譲れない条件か」「広げたときに読む時間が足りるか」の2つです。大学群を広げても増えるのは読む対象であって承認ではなく、絞っても減るのは読む対象であって質ではありません。** この記事では、大学群の判断を、譲れない条件かどうか、活躍社員の出身の偏りの読み方、読む時間との関係、面接官との合意、文面の材料の有無、の順で整理します。絞るべき、広げるべき、のどちらも書きません。自社で判断するための手順を書きます。検索条件の考え方は[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)で書きました。

## この作業の目的｜「なんとなく」の絞り方をやめる

大学群の絞り方は、「なんとなく前年と同じ」「なんとなくこのあたりまで」で決まっていることが多いものです。理由が無いと、広げるべきか絞るべきかの議論が、感覚のぶつかり合いになります。

判断の目的は、大学群の絞り方に理由をつけることです。理由がつけば、広げるときも絞るときも、社内で説明でき、結果を見て見直せます。

## 軸1｜大学群は「譲れない条件」か

検索で絞るのは、無ければ選考に進めない「譲れない条件」だけです。この考え方は[OfferBoxのターゲット設計](/media/ob-target-sekkei/)で書きました。大学群がこれに当たるかを、最初に確かめます。

| 問い | 答えが「はい」なら | 答えが「いいえ」なら |
|---|---|---|
| 特定の大学群でないと、選考に進めない理由があるか | 譲れない条件。検索で絞る理由がある | 譲れない条件ではない |
| その理由は、仕事に必要な学部や資格で説明できるか | 大学群ではなく、学部や資格で絞る | 大学群で絞る理由は薄い |
| 面接官が、大学群を理由に落としているか | 実態として絞られている。面接官と合意が要る | 検索で絞る必要は無い |

多くの会社で、大学群は「譲れない条件」ではなく「あれば嬉しい条件」です。あれば嬉しい条件は、検索で絞らず、読んで判断します。譲れない条件なら、絞る理由を言葉にして、面接官と共有します。

## 軸2｜活躍社員の出身の偏りをどう読むか

「活躍している社員は特定の大学群の出身が多いから、そこに絞る」という判断があります。この読み方には注意が要ります。

1. **偏りは、採用の偏りの結果かもしれない**：過去にその大学群から多く採っていれば、活躍社員もそこに偏る。他の大学群の学生を採っていないので、比べられない
2. **活躍の理由が、大学群にあるとは限らない**：活躍している理由は、行動の型や志向であることが多い。ペルソナで「行動」と「志向」に分けたのは、このため。分け方は[採りたい学生像を言葉にする](/media/ob-persona/)
3. **少人数の偏りは、偶然かもしれない**：数人の共通点は、その数人の個性である可能性がある。適性検査の傾向と同じ読み方。[適性検査結果の使い方](/media/ob-tekisei-katsuyou/)で書いたとおり
4. **偏りを「仮説」にとどめる**：「この大学群の学生は合いやすいかもしれない」までで、「他の大学群は合わない」にはしない

活躍社員の出身から言えるのは、「その大学群の学生にも合う人がいる」ことまでです。「他には合う人がいない」は言えません。

### エージェントベストの見解

媒体を比べたり検索条件を見直したりするときに、「大学群を広げたら承認が増える」「絞ったら承認の質が上がる」と考える会社は多いのですが、どちらも根拠がありません。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、大学群を広げて増えるのは検索結果の件数、つまり読む対象であって、承認は読んで文面を書いた分しか増えません。読む時間が同じなら、広げても承認は変わりません。絞って減るのも読む対象で、承認の質は文面と面談で決まるので、絞っただけでは変わりません。大学群の議論は、「読む対象をどこまでにするか」の議論であって、「承認の数や質」の議論ではない。この整理をすると、広げるか絞るかは、読む時間で決まる話になります。読む時間が足りるなら広げてよく、足りないなら絞るしかない。それだけです。

## 軸3｜広げたときに、読む時間が足りるか

大学群を広げると、検索結果が増えます。増えた分を読む時間があるかで、広げられる範囲が決まります。

1. **いまの読む時間と、読める数を出す**：週に何時間、その時間で何人読めるか
2. **広げたときの件数を見る**：1つずつ広げて、件数の増え方を見る。動かし方は検索条件の記事で書いたとおり
3. **読める数を超えるなら、広げる幅を戻すか、読む時間を増やす**：読む人を増やす、読む作業を外に出す
4. **読める数の範囲で、最も広い設定にする**：これが、自社の読む時間で広げられる上限

「広げたい」と「読める」の差が、読む時間の問題です。広げたいのに読めないなら、大学群の問題ではなく、読む体制の問題です。件数と読む時間の関係は検索条件の記事で書きました。

## 軸4｜面接官と合意しているか

大学群を検索で広げても、面接官が大学群を理由に落としていれば、広げた意味がありません。学生は面談まで進んで落とされ、面談に出た人の時間も学生の時間も無駄になります。

- **面接官に、大学群をどう見ているかを聞く**：明示的に聞かないと分からない
- **大学群で落としているなら、理由を言葉にしてもらう**：仕事に必要な理由なら、譲れない条件として検索で絞る。理由が無いなら、面接では行動と志向で見ることを合意する
- **広げた結果を、面接官と一緒に見る**：広げた大学群の学生が面談でどうだったかを、記録で見る。「合った」が出てくれば、面接官の見方も変わる
- **合意が取れないなら、広げない**：検索で広げて面接で落とすのは、最も無駄が大きい

面接官との合意は、ペルソナの合意と同じ場でできます。「大学群ではなく、行動と志向で見る」を、ペルソナの1枚に書いておきます。

## 軸5｜文面で触れる材料があるか

大学群を広げても、その学生のプロフィールに文面で触れる材料が無ければ、送っても承認されにくくなります。

- **広げた大学群の学生の自由記述を、いくつか読んでみる**：触れる材料があるか
- **材料があるなら、広げる意味がある**：文面が書ける
- **材料が薄いなら、広げても送る優先度は下がる**：読む時間だけが増える
- **材料の有無は、大学群ではなく学生ごとに違う**：大学群で決めつけず、読んで判断する

つまり、大学群を広げたあとも、判断は「読んで、触れる材料があるか」に戻ります。読み方は[学生プロフィールの読み方](/media/ob-profile-yomikata/)で書きました。

## 判断の手順

5つの軸を、手順にします。

1. **大学群が譲れない条件かを確かめる**：仕事に必要な理由があるか。無ければ、あれば嬉しい条件
2. **活躍社員の出身の偏りを、仮説にとどめる**：「他は合わない」にしない
3. **読む時間で、広げられる上限を出す**：読める数の範囲で最も広い設定
4. **面接官と合意する**：大学群ではなく行動と志向で見る。合意が取れなければ広げない
5. **広げた大学群の学生を読み、触れる材料があるか見る**：あれば送る。無ければ優先度を下げる
6. **結果を記録し、月に一度見直す**：広げた大学群からの承認と面談の結果を、絞っていたときと比べる

6の記録が、次の卒年の判断の根拠になります。「なんとなく」ではなく、記録で決められるようになります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 前年と同じ大学群を理由なく続ける | 広げる機会も絞る根拠も無い | 譲れない条件かを確かめる |
| 活躍社員の出身で絞る | 採用の偏りを再生産する | 仮説にとどめ、行動と志向で見る |
| 広げたら承認が増えると期待する | 読む時間が同じなら増えない | 読む時間を先に確保する |
| 読む時間を見ずに広げる | 読み切れず、途中で止まる | 読める数の範囲で広げる |
| 検索で広げて面接で落とす | 学生も面接官も時間の無駄 | 面接官と合意してから広げる |
| 大学群で文面の書き方を変える | 学生に「大学で見られている」と伝わる | 文面は自由記述の一文から。大学には触れない |
| 結果を記録しない | 次の卒年も「なんとなく」になる | 広げた大学群からの結果を記録する |

最も無駄が大きいのは、「検索で広げて面接で落とす」です。広げる前に、面接官と合意します。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 譲れない条件かを確かめる | 人事と面接官 |
| 活躍社員の出身を整理する | 人事（現場に聞きながら） |
| 読む時間と読める数を出す | 読む人 |
| 検索条件を動かして件数を見る | 人事（または運用代行） |
| 面接官と合意する | 人事 |
| 広げた大学群の学生を読む | 読む人 |
| 結果を記録し、見直す | 人事 |

面接官との合意が、人事の最も重い仕事です。「大学群ではなく行動と志向で見る」を面接官が受け入れないと、広げる意味がありません。ペルソナの合意の場で、一緒に扱います。運用代行に出している場合、検索条件の設定と読む作業は代行が行えますが、譲れない条件の判断と面接官との合意は社内です。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「大学群を広げると、承認は増えるが質が下がる」「絞ると、承認は減るが質が上がる」というものです。実際には、承認の数は読んで書いた数で決まり、承認の質は文面と面談で決まるので、大学群はどちらにも直接は効きません。当社がOfferBoxの運用の相談で大学群の話になったとき、最初に聞くのは「広げたい理由」でも「絞りたい理由」でもなく、「大学群を理由に、面接で落としていますか」です。落としているなら、広げても無駄で、その前に面接官と話す必要があります。落としていないなら、広げるかどうかは読む時間だけの問題で、大学群の議論は要りません。大学群の話は、面接官の見方と読む時間の話に置き換えると、答えが出ます。置き換えずに大学群そのものを議論すると、感覚のぶつかり合いで終わります。

## まとめ

- 大学群を広げるか絞るかは、「譲れない条件か」と「読む時間が足りるか」の2つで決める
- 活躍社員の出身の偏りは、採用の偏りの結果かもしれない。仮説にとどめ、行動と志向で見る
- 広げて増えるのは読む対象で、承認ではない。絞って減るのも読む対象で、質ではない
- 面接官が大学群で落としているなら、広げる前に合意する。合意が取れなければ広げない
- 広げた結果を記録し、次の卒年は「なんとなく」ではなく記録で決める

## よくある質問

### 大学群を広げたら、承認は増えますか

読む時間が同じなら、増えません。増えるのは検索結果の件数で、承認は読んで文面を書いた分しか増えません。広げるなら、読む時間を先に確保します。

### 活躍している社員の出身が偏っています。そこに絞るべきですか

偏りは、過去にその大学群から多く採った結果かもしれません。他の大学群の学生を採っていなければ、比べられません。「その大学群にも合う人がいる」までは言えますが、「他には合う人がいない」は言えません。仮説にとどめ、行動と志向で見ることを勧めます。

### 大学群の判断は、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、譲れない条件かどうか、面接官が大学群で落としていないか、読む時間で広げられる上限はどこか、を一緒に整理します。広げるべき、絞るべき、のどちらも当社からは言いません。自社で判断するための材料を揃えます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
