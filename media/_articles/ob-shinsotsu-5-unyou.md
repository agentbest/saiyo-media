新卒を毎年五名前後採る。人事は一人か、総務との兼務。職種は一つか二つ。OfferBoxを主軸にしていて、「承認率を上げたい」「送信数を増やしたい」と考えて運用しているが、承認率が上がっても採れる人数は変わらず、一人が辞退すると計画の大きな部分が消える。**結論から言うと、五名は「一人ずつ採る」運用で足りる人数で、承認率や送信数を見ても意味がなく、見るのは一人ひとりの段です。最初に決めるのは、名義を現場の若手一、二人に置くこと、送る総量を小さくすること、同期が少ないことを隠さないこと、一人の辞退が計画の大きな部分になる前提で承諾の期限と次の一人を先に決めることです。** この記事では、この人数を採る会社が割ける時間と人、「一人ずつ採る」運用、最初に決めること、文面の書き方、辞退への備え、分担、やりがちな失敗を整理します。より多く採る会社は[新卒十名を採る会社のOfferBox運用](/media/ob-shinsotsu-10-unyou/)、より少なく採る会社は[新卒一〜三名を採る会社のOfferBox運用](/media/ob-shinsotsu-1-3-unyou/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 人事が一人か、総務との兼務 | 送る総量が担当の時間を超えると、承認への返信が遅れる |
| 職種が一つか二つ | 一つの文面で送れる。ただし、名義が人事だと「会社が送った」に読まれる |
| OfferBox主軸で足りる人数 | ナビを足す必要は薄いが、受け皿がない分、次の一人の準備が要る |
| 承認率や送信数を見ている | 五名の採用で、割合の数字はぶれが大きく、判断に使えない |
| 一人の辞退が、計画の大きな部分 | 辞退のあとに慌てて送り、学生の予定が埋まっている |
| 同期が五名前後で、少ない | 学生が「同期が少ない」を気にする。隠すと面談で分かる |

この人数を採る会社がOfferBoxに割ける時間は、人事の細切れの時間と、名義の若手の面談枠です。五名は、「送る総量を増やす」運用ではなく、「一人ずつ、承認から承諾まで丁寧に運ぶ」運用で足ります。

## 「一人ずつ採る」運用｜承認率ではなく、一人ひとりの段で見る

- **五名の採用で、承認率や送信数は判断に使えない**：一人の承認で割合が大きく動く。ぶれを見て一喜一憂しない
- **見るのは、一人ひとりの段**：誰が承認して、いつ返して、いつ面談して、いつ内定を出して、承諾したか。台帳で一人ずつ
- **送る総量を、名義の若手が月に会える数から逆算し、小さく置く**：多く送って一人ひとりに向き合えない形にしない
- **承認した学生に、承認の当日に返し、数日以内に面談を入れる**：五名なら、一人ひとりにこの速さで向き合える。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
- **面談は、文面の続きから**：一人ひとりに「記述のここを読んで送った」を伝えられる人数。[OfferBox経由の学生との初回面談の設計](/media/ob-mendan-sekkei/)
- **週に一度、一人ひとりの段を見る**：割合ではなく、「〇〇さんは面談待ち、△△さんは内定の返事待ち」。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)

### エージェントベストの見解

五名を採る会社の承認率は、一人の承認で大きく動く数字で、運用の良し悪しを示す数字ではありません。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、この人数を採る会社の数字を見ていますが、「今月は承認率が下がった」「送信数を増やしたい」という相談を受けると、送った数も承認した数も小さく、割合が一人で動いている状態です。割合を見て文面や送る相手を変えると、一人のぶれに運用が振り回されます。当社が五名の会社に見てもらうのは、割合ではなく、台帳の一人ひとりの段で、「承認したのに面談の日程が決まっていない人がいないか」「内定の返事を待っている人に、次の連絡をしたか」の二つです。五名の採用は、統計ではなく、一人ひとりの進み具合で回ります。割合の数字は、年に一度、台帳が揃ってから、翌年の送る数の目安に使うだけで足ります。

## 最初に決めること

1. **名義を、現場の若手一、二人に置く**：職種が一つなら一人、二つなら二人。人事の名義で送らない。頼むことは名義・一文・面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
2. **送る総量を、小さく置く**：名義の若手が月に会える数から逆算。「送る数を増やせば採れる」と考えない。[予算が少ない会社のOfferBoxの使い方](/media/ob-yosan-sukunai/)
3. **同期が少ないことを、隠さず書く**：「同期は〇名前後です。最初の年は△△さんが隣で教えます」。人数は文面に書いてよい。この記事では書かない
4. **承認への当日返信の担当を決める**：人事が兼務で返せないなら、一次の返信を外に出す
5. **一人の辞退が計画の大きな部分になる前提で、承諾の期限と次の一人を先に決める**：後述
6. **送る時期を、二つの山に分ける**：最初の山で数名、辞退が出たら二つ目の山で足す。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
7. **台帳は、一人ひとりの段が見える一枚で**：表計算で足りる。[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)

## 文面の書き方｜一人ひとりに「なぜあなたに」を書ける人数

| 書かない | 書く |
|---|---|
| 「新卒〇名募集」の型どおりの文面 | 記述のどの行動を見たか、から始める。一人ひとりに書ける人数 |
| 人事の名義 | 現場の若手の名義で、「私は〇〇の担当で、最初の年に△△をしました」 |
| 「少数精鋭」「一人ひとりを大切に」 | 同期は〇名前後で、最初の年は誰が隣で教えるか |
| 会社紹介から始める | 会社の中身は採用サイトに。文面は学生の側の話に |
| 「アットホーム」 | 部署の人数と、誰と組むか |

- **五名なら、一人ひとりの記述を読んで一文を書く時間がある**：この人数の強みは、個別化の深さ。文面の基本は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)
- **知名度がない会社の書き方**：[知名度がない会社がOfferBoxで学生に届くには](/media/ob-chimeido-nai/)
- **条件は採用サイトに**：[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 一人の辞退が、計画の大きな部分になる前提で

- **五名のうち一人が辞退すると、計画の大きな部分が消える**：「多めに内定を出す」で対応すると、辞退が少なかった年に受け入れ人数を超える
- **承諾の期限を、学生の他社の選考の時期を聞いてから置く**：待つ間に、名義の若手と教える人に会ってもらう。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **次の一人を、最初の山の内定が出る前に用意しておく**：二つ目の山の検索条件と文面。辞退が出たら、すぐ送れる形
- **辞退の理由を、「決め手」まで聞く**：五名なら、一人ひとりに聞ける。[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)
- **内定者同士を、早めに会わせる**：同期が少ないからこそ、「一緒に入る人」の顔が安心になる

## 運用の分担

| 作業 | 誰が |
|---|---|
| 「こんな人」の一行と検索条件 | 人事と現場の責任者 |
| 名義の若手の選定（一、二人） | 人事と現場の責任者 |
| 検索、文面の下書き、送信、一次返信 | 人事、または代行 |
| 一人ひとりへの一文、文面の最終確認、名義、面談 | 現場の若手 |
| 一人ひとりの段を台帳で追う | 人事 |
| 承諾の期限と次の一人の準備 | 人事と責任者 |
| 内定者同士を会わせる、教える人に会わせる | 人事と現場 |
| 辞退の理由を「決め手」まで聞く | 人事 |

- **兼務の人事は、検索・下書き・送信・一次返信を外に出し、一人ひとりの段を追うことに絞る**：[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **人事が一人の会社の週の形**：[人事が1人の会社のOfferBox運用](/media/ob-jinji-hitori-unyou/)

運用代行や代理店が支えられるのは、一人ひとりの段の台帳の型、文面の型、検索・下書き・送信・一次返信、次の一人の準備の型までで、名義の選定、一人ひとりへの一文、面談、承諾の期限の判断、辞退の理由を聞くことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。五名を採る会社で、自社で持つべきなのは、名義の若手の一文、面談、一人ひとりの段を追うこと、承諾までの連絡、までです。ここから先の、検索、文面の下書き、送信、一次返信、台帳の型は、外に出せます。当社がこの人数の会社の運用代行を受けるときは、送る総量を小さく置き、当社が検索して下書きし、名義の若手が一文を足し、承認が来たら当社が当日に返し、面談と承諾までの連絡は企業が一人ひとりに向き合う形にしています。この線を引かずに、「五名なので人事一人で全部できる」とすると、検索と送信に時間が消えて、承認した学生の面談の設定が遅れます。逆に「面談まで外に」とはできません。五名の採用の要は、一人ひとりに会社の人が向き合うことで、それは外に出せない部分です。出すのは作業、残すのは向き合うこと。この人数では、その線が最もはっきりしています。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 承認率や送信数で運用を判断する | 一人のぶれに振り回される | 一人ひとりの段で見る |
| 送る総量を増やして採ろうとする | 一人ひとりに向き合えず、承認した学生を失う | 面談枠から小さく置く |
| 人事の名義で送る | 「会社が送った」に読まれる | 現場の若手一、二人の名義 |
| 一人の辞退で慌てて送り直す | 学生の予定が埋まっている | 次の一人を先に用意 |
| 同期が少ないことを隠す | 面談で分かって「隠していた」 | 人数と教える人を書く |

最も多いのは、一つ目です。五名の採用に、統計の見方を持ち込みます。

## まとめ

- 五名は「一人ずつ採る」運用で足りる人数。承認率や送信数は一人のぶれで動き、判断に使えない。見るのは一人ひとりの段
- 名義は現場の若手一、二人。送る総量は面談枠から小さく置き、一人ひとりの記述を読んで一文を書く
- 同期が少ないことを隠さず、人数と教える人を書く。承認の当日返信と数日以内の面談を、一人ひとりに
- 一人の辞退が計画の大きな部分になる前提で、承諾の期限を置き、次の一人を最初の山の途中で用意し、内定者同士を早めに会わせる
- 出すのは作業（検索・下書き・送信・一次返信・台帳の型）、残すのは向き合うこと（一文・面談・段を追う・承諾までの連絡）

## よくある質問

### 承認率が低いと上司に言われます。どう説明しますか

「五名の採用では、一人の承認で割合が大きく動くので、割合では判断していません。見ているのは一人ひとりの段です」と、台帳を見せます。「承認した〇名のうち、面談が△名、内定の返事待ちが□名」の形で示すと、割合より進み具合が伝わります。上司への説明の作り方は[OfferBoxの運用方針を上司に納得してもらう資料の作り方](/media/ob-joushi-nattoku/)で書きました。

### 五名なら、ナビを使わずOfferBoxだけでよいですか

名義の若手が一、二人いて、人事が承認への返信を当日に行えるなら、OfferBoxだけで足りる人数です。ナビの受け皿がない分、辞退が出たときの次の一人を、最初の山の途中で用意しておきます。知名度がなく、ナビで検索されない会社ほど、OfferBoxだけのほうが届きます。

### 新卒五名を採る会社のOfferBox運用は、御社に相談できますか

できます。当社は、一人ひとりの段の台帳の型、文面の型、検索・下書き・送信・一次返信、次の一人の準備の型を支えられます。名義の選定、一人ひとりへの一文、面談、承諾の期限の判断、辞退の理由を聞くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
