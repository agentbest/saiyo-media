OfferBoxで承認され、初回面談で温度が上がった学生が、選考の途中で離れていく。原因を聞くと、選考が長い、段階が多い、次の連絡まで空く、という話が出てきます。**結論から言うと、OfferBox経由の学生の選考は、ナビ経由の学生と同じ段数にする必要がありません。企業が選んで届け、面談で話した学生なので、段階ごとの目的を1つにして、重なりを消せば、見極めを甘くせずに短くできます。** この記事では、選考を短くする考え方を、いまの段数の書き出し、段階ごとの目的の整理、重なりの統合、期間の目標、面接官との合意、の手順で整理します。初回面談の位置づけは[初回面談の設計](/media/ob-mendan-sekkei/)で書きました。

## この作業の目的｜温度が下がる前に決める

学生の温度は、承認の直後と初回面談の直後が高く、そこから時間とともに下がります。選考が長いほど、温度が下がった状態で最終面接を迎え、内定を出しても承諾されにくくなります。

同時に、学生は複数の企業の選考を並行しています。他社が先に内定を出せば、自社の選考は途中で辞退されます。選考を短くする目的は、温度が高いうちに、他社より先に、決めることです。

「短くする」は「甘くする」ではありません。見極める項目は減らさず、同じ項目を複数の段階で重ねて見ている無駄を消します。

## 手順1｜いまの段数と日数を書き出す

最初に、いまの選考フローを紙に書きます。

1. **段階を並べる**：初回面談、書類、一次面接、二次面接、最終面接、など。自社の実際の順で
2. **段階ごとに「誰が、何を見ているか」を書く**：面接官の名前と、見ている項目
3. **段階の間の日数を書く**：前の段階の結果連絡から、次の段階の実施まで。実績の平均でよい
4. **承認から内定までの合計日数を出す**
5. **途中で辞退が多い段階に印をつける**：記録があれば

書き出すと、「同じ項目を二次と最終で見ている」「一次と二次の間が長い」といった重なりと空白が見えます。書き出さないと、感覚で「長い気がする」で終わります。

## 手順2｜段階ごとの目的を1つにする

各段階で「見る項目」を1つに絞ります。複数の項目を1つの段階で見ようとすると、面接が長くなり、見極めも曖昧になります。

| 段階 | 目的の例（型） | 見る人 |
|---|---|---|
| 初回面談 | 文面の続き。仕事への興味と、自由記述の経験の実態。評価はしない | 名義の人 |
| 一次面接 | 仕事に必要な行動の型があるか | 現場のマネージャー |
| 二次面接 | チームで働く姿が想像できるか | 配属先の責任者 |
| 最終面接 | 会社の考え方に納得しているか。入社の意思 | 経営 |

「目的が同じ段階」があれば、それは重なりです。次の手順で統合します。目的を1つにすると、面接官への依頼も「この段階ではこれを見てください」と明確になります。見る項目の元は、ペルソナの「行動」と「志向」です。ペルソナの作り方は[採りたい学生像を言葉にする](/media/ob-persona/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「段階を減らすと、見極めが甘くなる」というものです。実際には、段階の数と見極めの深さは別です。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、段階が多い会社の選考を書き出すと、同じ項目を複数の面接官が別々に見ていることが多く、段階を減らしても見る項目は減りません。逆に、段階が多いのに、誰も「入社の意思」を確認していない会社もあります。段階を減らす前に、「段階ごとに何を見るか」を1つずつ置く。置いてみると、重なっている段階と、抜けている項目の両方が見えます。重なりを消し、抜けを足すと、段階は減り、見極めは深くなります。段数を議論する前に、目的を置く。この順番を勧めます。

## 手順3｜目的が重なる段階を統合する

目的を置いて、重なりが見えたら統合します。

- **同じ項目を見ている2つの段階**：1つにする。面接官は、どちらか1人か、2人同席
- **初回面談で確かめたことを、一次面接で再確認している**：一次面接では別の項目を見る。初回面談の記録を面接官に渡す
- **書類で見ていることを、面接でも聞いている**：書類で足りるなら、面接では聞かない
- **最終面接が「顔合わせ」になっている**：最終面接の目的を「入社の意思の確認」に置き、それ以外は前の段階で終える

統合すると、段階が減るだけでなく、段階の間の空白も減ります。段階が1つ減れば、結果連絡と日程調整が1回減り、その分の日数が消えます。

初回面談は選考ではありませんが、そこで分かったこと（自由記述の経験の実態、志向）は、選考で再確認しません。面談の記録を面接官に渡し、面接官は「その先」を聞きます。記録の戻し方は初回面談の記事で書きました。

## 手順4｜承認から内定までの期間の目標を置く

統合したフローで、承認から内定までの期間の目標を置きます。具体的な日数は自社の実績と体制で決まるので、ここには書きません。決め方だけを書きます。

1. **前年の実績を見る**：承認から内定までの平均と、途中で辞退した学生の辞退までの日数
2. **辞退が増え始める日数より短くする**：辞退が集中する日数があれば、その前に内定を出す設計にする
3. **段階の間の日数に上限を置く**：結果連絡は当日か翌日、次の段階の実施は結果連絡から1週間以内、のように
4. **面接官の枠から、実現できるかを確かめる**：上限を守るには、面接官が枠を出せる必要がある。出せないなら、段階を減らすか、面接官を増やす
5. **目標を面接官と共有する**：「承認から内定までをこの期間で」を全員が知っている状態にする

3の「段階の間の日数の上限」が、実際に効く部分です。段階の数より、段階の間の空白が、学生の温度を下げます。

## 手順5｜例外を決めておく

短くしたフローでも、例外は起きます。先に決めておきます。

- **面接官の都合で次の段階が遅れる**：代わりの面接官を出せるか。出せないなら、学生に理由と見通しを伝える
- **学生の都合で遅れる**：学生の予定を優先しつつ、他社の進行を聞く。急がせない
- **最終面接の前に、経営が「もう一段階」と言う**：目的を確認する。前の段階で見ていない項目なら足す。見ているなら足さない
- **ナビ経由の学生と同じ日程に合わせたい**：OfferBox経由の学生を待たせない。別のフローとして動かす

例外を決めておかないと、「今回は特別に」が積み重なり、フローが元に戻ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| ナビ経由と同じフローに乗せる | 段階が多く、温度が下がる | OfferBox経由は別のフローで動かす |
| 段数だけを減らす | 見る項目が抜ける | 段階ごとの目的を1つ置いてから統合する |
| 初回面談で確かめたことを一次で再確認する | 学生が「また同じ話」と感じる | 面談の記録を面接官に渡し、その先を聞く |
| 段階の間の日数を決めない | 結果連絡が遅れ、次の日程が空く | 段階の間の日数に上限を置く |
| 面接官の枠を見ずに目標を置く | 目標が守れず、形だけになる | 枠から実現できるかを確かめる |
| 例外を決めない | 「今回は特別に」で元に戻る | 例外の扱いを先に決める |
| 最終面接が顔合わせになっている | 入社の意思を誰も確認していない | 最終の目的を「入社の意思」に置く |

最も多いのは、最初の「ナビ経由と同じフローに乗せる」です。フローが1本しか無い会社では、OfferBox経由の学生もそこに乗り、承認から内定までが長くなります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| いまのフローを書き出す | 人事 |
| 段階ごとの目的を置く | 人事と面接官 |
| 重なりを統合する | 人事が案を作り、面接官と合意 |
| 期間の目標と、段階の間の上限を置く | 人事 |
| 面接官の枠を出す | 面接官 |
| 例外を決める | 人事と経営 |
| 結果連絡と日程調整 | 人事（または運用代行） |

フローの変更は、面接官の合意が要ります。人事だけで決めて「次から二次を無くします」と伝えると、面接官が「見極めが甘くなる」と反発します。段階ごとの目的を一緒に置く場を持ち、重なりを面接官自身に見てもらうと、統合に納得が生まれます。運用代行に出している場合、結果連絡と日程調整は代行が行えますが、フローの設計は社内です。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。「段階の間の日数の上限」を、面接官の枠と一緒に決めることです。当社がOfferBoxの運用の相談で選考フローを見るとき、段階の数を減らした会社でも、結果連絡が数日空き、次の面接が2週間先、という状態だと、承認から内定までは短くなりません。段階の数より、段階の間の空白のほうが、学生の温度を下げます。当社が勧めるのは、「結果連絡は翌日まで」「次の段階は1週間以内」のような上限を置き、それを守るために面接官が週に何枠出せるかを先に確認することです。枠が出せないなら、段階を減らすか、面接官を増やすかのどちらかで、上限を緩めるのは最後です。上限を決めずに段階だけ減らした会社と、上限を決めて枠を確保した会社では、承認から内定までの期間が明らかに違います。

## まとめ

- OfferBox経由の学生は、企業が選んで届け、面談で話した学生。ナビ経由と同じ段数は要らない
- 段階ごとの目的を1つ置き、重なりを統合する。段数を減らすのは結果で、目的が先
- 初回面談で確かめたことは選考で再確認しない。記録を面接官に渡し、その先を聞く
- 段階の間の日数に上限を置き、面接官の枠から実現できるかを確かめる
- 例外を先に決める。決めないと「今回は特別に」で元に戻る

## よくある質問

### 段階を減らすと、面接官が「見極めが甘くなる」と言います

段階ごとの目的を一緒に置く場を持ち、同じ項目を複数の段階で見ていることを面接官自身に見てもらいます。重なりが見えれば、統合しても見る項目が減らないことに納得が生まれます。抜けている項目があれば、それを足すことで、見極めはむしろ深くなります。

### ナビ経由の学生と、選考フローを分けてもよいのですか

分けることを勧めます。OfferBox経由の学生は企業が選んで届けた学生で、初回面談で話した状態から選考に入ります。ナビ経由の学生と同じ入口に戻すと、承認から内定までが長くなり、温度が下がります。フローの途中から合流する形は取れます。

### 選考フローの設計は、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、いまのフローを書き出し、段階ごとの目的を置き、重なりと空白を一緒に探します。面接官との合意の場にも同席できます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
