経験者の採用で、職務経歴を読んで企業から送る形のサービス（ビズリーチ）とWantedlyの両方を使っている、または使おうとしている。二つの違いは分かっていても、「文面に何を書き、記事に何を書くか」「誰が文面を書き、誰が記事を書くか」「経験で口説いた候補者に、何を読んでもらうか」が決まっていないと、要件の羅列を送り、会社ページには事業の説明しかなく、経験者が「任せてもらえる範囲」を確かめられません。**結論から言うと、ビズリーチは「職務経歴で絞って送る場」、Wantedlyは「任せる範囲と意思決定の実態を読んでもらう場」です。経験者ほど、条件より「裁量と意思決定の実態」を確かめます。使い分けるなら、送る前に代表の名義で「任せる範囲の実態」を書き、文面には要件と「なぜあなたか」を、記事には判断の場面を書き、書き手を分け、面接の入口を一つにします。** この記事では、それぞれの役割、経験者が確かめること、送る前に書く記事、文面と記事の線、書き手の分け方、面接の入口と台帳、工数、やりがちな失敗、社内の分担を整理します。二つの違いそのものは[Wantedlyとビズリーチの違い](/media/hikaku-wantedly-bizreach/)で書きました。この記事は、両方を持ったあとの運用の使い分けを扱います。両サービスの仕様と数値は書きません。

## それぞれの役割｜「経歴で絞って送る」と「実態を読む」

| | ビズリーチ | Wantedly |
|---|---|---|
| 送る根拠 | 候補者の職務経歴。実績と役職と経験 | 候補者の関心と、会社の考え方への反応 |
| 候補者の状態 | 送られた側。経験が合うかで開封し、会社は知らない。転職を決めていない人も多い | 読んだ側。会社の考え方を読んで「話を聞きに行きたい」と来る |
| 候補者が次にすること | 会社の事業と、任せる範囲の実態を調べる | 面談に来る |
| 会社が用意するもの | ポジションの要件、候補者ごとの文面、送る人の名義 | 代表の「なぜ」、任せる範囲の実態、意思決定の場面のストーリー |
| 書く人 | 要件を言葉にできる人。事業責任者など | 判断の場面を語れる人。代表や役員 |
| 時期 | 送る時期に集中 | 通年。記事が残る |

経験で絞って送られた候補者は、「経験は活かせそうだ」と思ったあと、「本当に任せてもらえるのか」「意思決定はどう行われているのか」「代表はどんな人か」を調べます。求人票にも、公開されている会社情報にも、これは出てきません。読む場所がWantedlyの会社ページとストーリーです。

## 経験者が確かめること

- **任せる範囲の実態**：「裁量あり」ではなく、何を決められて、何を決められないか。誰の承認が要るか
- **意思決定の速さと、誰が決めるか**：代表が決めるのか、合議か。最近の判断の場面
- **代表と役員がどんな人か**：考え方、話し方、何を大切にして判断するか
- **前任者がいたなら、なぜ空いたか**：書ける範囲で。書けないなら面接で
- **入社した経験者が、最初の三か月で何をしたか**：先に入った経験者のストーリー

経験者は、文面の丁寧さより、この五つを確かめてから返信します。五つが読める記事がないと、「経験は合うが、会社が分からない」で返信が来ません。

### エージェントベストの見解

相談で最も多い思い込みは、「経験が合う人に、要件を丁寧に書いて送れば来る」というものです。当社は3媒体すべての販売パートナーとして、経験者の採用でビズリーチとWantedlyを併用する会社の相談を受けますが、文面は要件と待遇を丁寧に書いているのに、返信が来ない、という状態が多くあります。経験者は、要件で「自分に来た理由」を読み取ったあと、会社を調べます。調べる先に、代表が「何を任せ、何を決めてもらい、どこは自分が決めるか」を書いた記事があるかで、返信するかが決まります。要件は「合うか」の判断に使われ、任せる範囲の実態は「行くか」の判断に使われます。当社が併用の相談で最初に確かめるのは、文面ではなく、代表の名義で任せる範囲の実態が読めるかです。なければ、文面を直す前に、代表に一本話してもらいます。

## 送る前に、代表の名義で「任せる範囲の実態」を書く

- **代表の名義で、「このポジションに何を任せ、何を決めてもらい、どこは自分が決めるか」を一本**：理念ではなく、最近の判断の場面で。[Wantedlyのストーリーで代表の考えを書く方法](/media/wt-story-daihyo/)
- **先に入った経験者のストーリーを一本**：「入って最初の三か月で、何を任され、何に困り、どう決めたか」。[Wantedlyのストーリーで入社エントリーを書いてもらう方法](/media/wt-story-nyusha/)
- **文面に、この二本への導線を置く**：貼れる形は現在の仕様で確認。貼れないなら「代表が〇〇という記事に書きました」
- **募集記事に、任せる範囲を条件と別に書く**：「裁量あり」の一語で済ませない
- **本音の範囲を決めておく**：「決められないこと」も書く。出せる範囲は[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)

## 文面に書くことと、記事に書くことの線

| 文面（ビズリーチ） | 記事（Wantedly） |
|---|---|
| なぜあなたに送ったか。職務経歴のどこを見たか | 代表の「なぜ」と、任せる範囲の実態 |
| ポジションの要件と、任せる範囲の一文 | 意思決定の場面。誰が、どう決めたか |
| 条件の概要（詳細は募集記事に） | 先に入った経験者の最初の三か月 |
| 「任せる範囲は代表が記事に書きました」の導線 | 決められないこと、変えようとしていること |
| 書かない：会社の自慢、待遇の羅列だけ、抽象的な「裁量」 | 書かない：要件の貼り直し、理念だけ |

- **文面の「任せる範囲」と、記事の実態をずらさない**：文面で「全部任せる」、記事で「代表が決める」だと、面接で離れる
- **条件は募集記事に置き、文面と同じにする**：[Wantedlyの募集記事に条件をどこまで書くか](/media/wt-boshu-joukenn/)
- **文面と記事を、最後に同じ人が見る**：書く人が違っても、見る人は一人

## 書き手を分ける

- **要件と文面は、事業責任者か、そのポジションの上司**：経験の何を見たかを書けるのは、仕事を知っている人
- **任せる範囲の実態と意思決定の場面は、代表か役員**：決める人が書かないと、実態にならない
- **人事が持つのは、一次の絞り込み、送信、返信の管理、記事を整える部分**：要件の判断と、任せる範囲の決定は持たない
- **同じ人が文面と記事の両方を抱えない**：代表が文面まで書くと、記事が止まる
- **文面の下書きを外に出すかは、要件が言葉になっているかで決める**：言葉になっていれば出せる。任せる範囲の判断は出せない

## 面接の入口と台帳を一つにする

- **どちらから来ても、最初は「話を聞く面談」から**：経験者ほど、転職を決めていない。選考の意思を確認してから選考に。[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **最初の面談に、代表か決める人が出る**：経験者は、任せる範囲を決める人に会いたい
- **ビズリーチ経由の候補者にも、面談の前に代表の記事を読んでもらう**：文面で導線を置いていれば、読んで来る
- **台帳は一つ**：入口の列に「ビズリーチ」と「Wantedly」。送信と開封と返信はそれぞれの中で、面談から先は共通の段
- **面談で「文面のどこ、記事のどこを見たか」を聞く**：要件と実態の、どちらが効いたかが分かる

台帳と段の揃え方は[Wantedlyを含む複数媒体の効果を並べて見る方法](/media/wt-heiyou-heiyou-kpi/)で書きました。

## 工数の配分

| 時間の種類 | ビズリーチ | Wantedly |
|---|---|---|
| 決める人の時間 | 要件の確認、文面の最終確認、面談 | 任せる範囲を話す時間、記事の確認、面談 |
| 事業責任者の時間 | 候補者ごとの文面 | 意思決定の場面を話す時間 |
| 人事の時間 | 一次の絞り込み、送信、返信の管理 | 記事を整える、募集記事、返信の管理 |
| 外に出せる部分 | 文面の下書き（要件が言葉になっていれば）、送信、一次の返信 | 整える部分。任せる範囲を話す中身は出せない |
| 費用 | 各サービスの現在の条件を公式で確認。この記事では書かない | プランの費用。公式ページで確認 |

- **代表の時間は、文面ではなく、記事と面談に使う**：文面は事業責任者と人事で、記事と面談は代表
- **送る数を、面談に出られる時間から逆算する**：経験者の面談は、決める人が出る。出られる数が送る数の上限
- **記事は積み上がり、文面は残らない**：時間が足りないときは、記事を残す。[Wantedlyを含む複数媒体の予算配分](/media/wt-heiyou-heiyou-yosan/)

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 任せる範囲の記事がないまま送る | 経験者が調べても出てこず、返信が来ない | 代表の一本を先に |
| 文面に「裁量あり」と書き、記事で実態が違う | 面接で「聞いていたのと違う」で離れる | 決められないことも書く |
| 代表が文面まで書く | 記事が止まる | 文面は事業責任者、記事は代表 |
| 最初の面談に決める人が出ない | 経験者が「誰が決めるか分からない」で離れる | 代表か役員が出る |
| 送信数で効果を見る | 返信の内容と面談の言葉を見ない | 面談で「どこを見たか」を聞く |

最も多いのは、一つ目です。文面を丁寧に書くことに時間を使い、経験者が調べに来たときに、任せる範囲の実態が読める記事がありません。

## 社内の分担

| 作業 | 誰が |
|---|---|
| ポジションの要件を言葉にする | 事業責任者と、そのポジションの上司 |
| 任せる範囲の実態と意思決定の場面を話す | 代表か役員。人事が整える |
| 候補者ごとの文面を書く | 事業責任者（下書きは外に出せる） |
| 一次の絞り込み、送信、返信の管理 | 人事 |
| 文面と記事の「任せる範囲」を揃えて見る | 人事（一人） |
| 最初の面談に出る | 代表か決める人と、文面を送った人 |
| 送る数と、代表の時間の配分 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、文面と記事の線の型、台帳の型、Wantedlyの整える部分、文面の下書き（要件が言葉になっていれば）までで、要件の決定、任せる範囲の決定、話すこと、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「このポジションで、何を決めてもらい、何は自分が決めるか」を代表が一行で決めておかないと、どちらの媒体でも効果が出ません。当社はWantedlyの運用を申込のあとまで見ていますが、経験者の採用で両方を使う会社の多くは、要件は細かく決まっているのに、任せる範囲は「裁量を持って」の一語で止まっています。この一語は、文面にも記事にも書けず、面接で候補者に聞かれて初めて、代表の中で決まります。順番は、代表がこの一行を決め、その一行を記事で場面にし、文面で一文にし、面談で同じ言葉で話すことです。一行が決まっていれば、送る数が少なくても、返信の内容が「任せる範囲」の話から始まり、面談が「確かめる場」になります。決まっていなければ、送る数を増やしても、面接で決まらないことが繰り返されます。

## まとめ

- ビズリーチは「職務経歴で絞って送る場」、Wantedlyは「任せる範囲と意思決定の実態を読んでもらう場」。経験者は条件より実態を確かめる
- 送る前に、代表の名義で「任せる範囲の実態」を、先に入った経験者の名義で「最初の三か月」を書き、文面から導線を置く
- 文面には「なぜあなたか」と要件を、記事には判断の場面と決められないことを。「任せる範囲」をずらさず、最後に同じ人が見る
- 書き手を分ける。文面は事業責任者、記事は代表。代表の時間は文面ではなく記事と面談に
- 最初の面談に決める人が出る。台帳は一つ。送る数は、面談に出られる時間から逆算する

## よくある質問

### 代表が「任せる範囲」を記事に書くのを嫌がります

書いてもらうのではなく、「最近、〇〇のポジションで決めてもらったことと、自分が決めたこと」を話してもらい、人事が整える形にします。理念や抱負ではなく、最近の判断の場面なら、短い時間で話せます。「決められないこと」を書くのは、経験者が面接で聞いてくることを先に答える作業で、悪い印象にはなりません。

### ビズリーチの文面に、Wantedlyの記事を貼ってよいですか

貼れる形と範囲は、現在の仕様で確認してください。貼れない場合も、「任せる範囲は、代表が〇〇という記事に書きました」と触れれば、候補者は会社名と代表の名前で探します。大切なのは、貼れるかどうかより、調べたときに出てくる記事があることです。

### Wantedlyとビズリーチの使い分けは、御社に相談できますか

できます。当社は、役割の整理、文面と記事の線の型、台帳の型、Wantedlyの整える部分、文面の下書きを支えられます。要件の決定、任せる範囲の決定、話すこと、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
