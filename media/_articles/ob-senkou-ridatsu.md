OfferBoxのオファーから面談まで来て、選考に進んだのに、途中で離脱する。この症状は、「学生の志望度が低かった」で片づけられがちです。ところが、オファー経由の学生には、他の経路の学生と違う離脱の理由があります。**結論から言うと、オファー経由の学生の離脱の多くは、「オファーで持った印象と、選考で見えたものの差」から起きます。文面で「話を聞くだけ」と誘い、面談は良かったが、選考に入った途端に別の会社に見えた、面接官がオファーの内容を知らなかった、段階が多くて間が空いた。離脱を段ごと（面談→一次→二次以降→最終）に切り分け、差が出た段だけを直します。離脱の理由は聞ける範囲で聞き、事実と推測を分けて残し、離脱が続く段を月に数えます。** この記事では、オファー経由に特有の離脱、段ごとのサインと直し方、理由の集め方、段を数えること、同じ人たちが担うこと、分担を整理します。選考フローの設計は[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/)、面接官の準備は[OfferBoxの現場の面接官の準備](/media/ob-genba-mensetsukan/)で書きました。この記事は、それらを「離脱」という症状から逆に辿るものです。

## この作業の目的｜「オファーの印象」と「選考の実態」の差を無くす

オファー経由の学生は、文面と企業ページと面談で、会社の印象を持って選考に入ります。その印象と、選考で見えるものが違うと、「オファーは営業用だった」と感じて離れます。

目的は、差が出ている段を見つけ、オファーの側を実態に寄せるか、選考の側をオファーの印象に寄せるかを決めて、差を無くすことです。志望度を上げることではなく、差を無くすことです。

## オファー経由の学生に、特有の離脱

| 離脱の形 | なぜ起きるか |
|---|---|
| 面談は良かったが、一次で別の会社に見えた | 面談は「話を聞く場」で、一次が「面接の型」に戻った。面接官が面談の内容を知らない |
| オファーの文面と、面接で聞かれることが違った | 文面で「学生時代の話を場面で」と書き、面接で志望動機と業界知識を聞いた |
| 選考の段階が多く、間が空いた | オファーで「速い」印象を持ったのに、実際は長い |
| 面接官が、オファーを送ったことを知らない | 「オファーをもらって来たのですが」に、面接官が反応できない |
| 他社の選考が速かった | オファー経由の学生は、複数の会社を並行している |
| 面談で話した人が、その後の選考に出てこない | 「あの人はもう出てこないのか」 |
| 書類（志望動機書など）が、面談のあとに急に求められた | 「話す場」から「選考」への切り替えが急 |
| 条件が、オファーや企業ページと違った | 面接で初めて出社の条件や転勤を知った |

共通するのは、「オファーと面談で作った印象」を、選考の側が引き継いでいないことです。

## 段ごとの、離脱のサインと直し方

### 面談のあとに、選考に進まない

| サイン | 直し方 |
|---|---|
| 面談の最後に選択肢を伝えていない | 「選考に進む・もう一度話す・いったん終わる」を伝え、「今日決めなくてよい」と添える |
| 面談後の連絡が遅い、または無い | 翌日までに一言と、選考の流れ。[OfferBoxの面談後のフォロー](/media/ob-mendan-go-follow/) |
| 選考の流れが分からない | 回数、誰と何を話すか、期間の目安、要る書類を、翌日の連絡で具体的に |
| 「面談」が実質「一次面接」だった | 面談の型を守る。[OfferBoxの面談設計](/media/ob-mendan-sekkei/) |

### 一次で離脱する

| サイン | 直し方 |
|---|---|
| 面接官が面談の内容とオファーを知らない | 面談の記録とオファーの文面を、面接官に渡す |
| 面接が、志望動機と業界知識から始まる | 面談の続きとして、学生時代の場面から。[OfferBoxの現場の面接官の準備](/media/ob-genba-mensetsukan/) |
| 面談で話した人が、一次にいない | 一人でも同じ人が出る。出られないなら、面接官が「面談で〇〇の話をされたと聞いています」から始める |
| 書類が急に多い | 最小限に。志望動機書はこの段階で求めない |

### エージェントベストの見解

相談で最も多い思い込みは、「選考途中の離脱は、他社に負けたからで、自社では防げない」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、離脱した学生の記録を段ごとに並べると、「一次で離脱」が集中している会社が多く、その一次の面接官に聞くと、オファーの文面も面談の内容も知らずに、いつもの面接をしていることがあります。学生は、面談で「話を聞く場」の印象を持ち、一次で「面接の型」に会い、「オファーは入口だけだった」と感じて離れます。当社が離脱の相談を受けるとき、最初にやるのは、離脱した段を数えることと、その段の面接官がオファーと面談の記録を読んでいるかを確かめることです。他社に負ける前に、自社の中で印象が切れている段があります。

### 二次以降で離脱する

| サイン | 直し方 |
|---|---|
| 段階が多く、間が空く | 段階を減らすか、間を空けない。[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/) |
| 各段階で、次に何があるかを伝えていない | 毎回、次の段階と時期を伝える |
| 面接官ごとに、聞くことが違う | 面接の型を段階ごとに揃える |
| 条件が、この段階で初めて出る | 条件はオファーの時点で企業ページに。面接で初めて出さない |
| 他社の選考が先に決まった | 自社の段階の間隔を短くする。「もう一度話す」の選択肢で、迷っている学生を残す |

### 最終で離脱する

| サイン | 直し方 |
|---|---|
| 最終の直前に、連絡が途絶える | 最終の前に、一言と、当日の流れ |
| 最終で、それまでと違う人が、違うことを聞く | 最終の面接官にも、オファーと面談と各段階の記録を渡す |
| 最終のあと、結果までが長い | 目安を伝え、守る |
| 内定を出したあとの離脱 | 別の問題。[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/) |

## 離脱の理由を、聞いて残す

- **聞ける範囲で聞く**：「今後の参考に、差し支えなければ」。選考とは関係ないと添える
- **聞けない場合も、推測を記録する**：「一次のあとに返事が無くなった」。事実と推測を分けて
- **面接に出た人にも聞く**：「面接で、学生が引っかかった様子があったか」
- **一行で台帳に**：「離脱。段：一次。理由：面接官がオファーを知らず、志望動機から聞いた（推測）」
- **理由を聞くのは一度だけ**：聞き直さない

「事実と推測を分ける」が要点です。学生が言った理由と、こちらの推測を混ぜると、直す場所を間違えます。辞退の理由の集め方は[OfferBoxで承認後の辞退を減らす連絡設計](/media/ob-jitai-boushi/)で書きました。

## 離脱が続く段を、月に数える

| 段 | 数えるもの |
|---|---|
| 面談→選考 | 面談した学生のうち、選考に進んだ数と進まなかった数 |
| 一次 | 一次を受けた学生のうち、次に進んだ数と離脱した数 |
| 二次以降 | 同じく |
| 最終 | 同じく |
| 各段の理由 | 事実と推測を分けて |

「どの段で離脱が集中しているか」が、月に一度数えるだけで見えます。集中している段が、直す段です。全部を直そうとせず、その段だけを直します。台帳の型は[OfferBoxのKPI設計](/media/ob-kpi-sekkei/)で書きました。

## オファーの文面と面談と選考を、同じ人たちが担う

離脱の根本は、「オファーと面談を担う人」と「選考を担う人」が分かれていることです。

- **面接官に、オファーの文面と面談の記録を渡す**：全文でなくてよい。「文面で〇〇の場面に触れ、面談で△△を話した」の一行
- **面談で話した人が、一次に一人は出る**：出られないなら、記録を読んだ面接官が「面談の続き」として始める
- **選考の各段階で、オファーで伝えた「何を見るか」と同じことを見る**：文面と選考がずれない
- **条件は、オファーの時点で企業ページに書いておく**：選考で初めて出さない
- **選考の流れを変えたら、オファーの文面と企業ページも直す**：オファーと選考が離れない

「面接官がオファーを知っている」だけで、一次の離脱は減ります。面接官の準備は[OfferBoxの現場の面接官の準備](/media/ob-genba-mensetsukan/)で書きました。

運用代行や代理店が支えられるのは、段ごとの切り分けの型、理由の集め方の型、面接官に渡す記録の型、選考フローの見直しの案までで、理由を聞くこと、面接、選考の流れの決定、条件の決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと一次の離脱が続くことがあります。「一次の面接官が、オファーの文面と面談の記録を、面接の前に読む」ことです。当社がOfferBoxの選考離脱の相談を受けるとき、段ごとの切り分けと理由の集め方は当社が出せますが、面接官が記録を読むかどうかは、社内の運用です。読まなければ、面接官は「初めて会う学生」として面接を始め、学生は「オファーと面談は何だったのか」と感じます。当社が最初にお願いするのは、面談の記録を一行にして、面接の前に面接官に渡す形を作ることです。一行で足ります。「文面で〇〇に触れ、面談で△△を話した。選考ではないと伝えてある」。この一行があれば、一次は面談の続きになります。

## まとめ

- オファー経由の学生の離脱は、「オファーと面談で持った印象」を選考の側が引き継いでいないことから起きる
- 段ごと（面談→選考、一次、二次以降、最終）に切り分け、離脱が集中している段だけを直す
- 一次の離脱は、面接官がオファーと面談を知らず、面接の型に戻ることが原因のことが多い。記録を一行で渡し、面談の続きとして始める
- 離脱の理由は聞ける範囲で聞き、事実と推測を分けて一行で残し、月に段ごとの数を数える
- 条件はオファーの時点で企業ページに、選考の流れを変えたらオファーと企業ページも直す。オファーと面談と選考を同じ人たちが担う

## よくある質問

### 離脱の理由を聞いても、「他社に決めた」としか言われません

「他社に決めた」の中に、「自社の次の連絡が遅かった」「自社の段階が多かった」が含まれていることがあります。離脱した段と、その段の前後の日時を台帳で見て、自社の側で間が空いていないかを確かめます。他社の速さに負けたなら、直すのは自社の段階の間隔です。

### 面接官が多く、全員にオファーと面談の記録を渡すのが難しいです

全文でなくてよく、一行で足ります。「文面で〇〇に触れ、面談で△△を話した」。面接の型（聞くことの順番）と一緒に、面接の前に渡します。人事が面談の記録から一行を作る形にすれば、面接官の負担は読むだけです。

### 選考途中の離脱の見直しは、御社に相談できますか

できます。当社は、段ごとの切り分けの型、理由の集め方の型、面接官に渡す記録の型、選考フローの見直しの案を支えられます。理由を聞くこと、面接、選考の流れの決定、条件の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
