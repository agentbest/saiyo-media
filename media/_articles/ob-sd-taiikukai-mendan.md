OfferBoxで体育会系の学生にオファーを送り、承認を得られたら、次は面談です。ここで、競技の実績や「体育会らしさ」の確認に時間を使ってしまう会社が少なくありません。**結論から言うと、体育会系の学生との面談は、競技の成果より「続けた理由」「チームでの役割の変化」「うまくいかなかったときの動き方」という過程を聞き、練習や試合の予定に日程を合わせることが要点です。** この記事では、面談の目的、日程の組み方、聞く順番、面接官の思い込みの防ぎ方、やりがちな失敗と社内の分担を整理します。オファー文面の書き方は[体育会系学生へのアプローチ](/media/ob-taiikukai/)で書きました。

## 面談の目的｜文面で触れた過程の続きを聞く

体育会系の学生にオファーを送るとき、文面では自由記述から拾った「続けた理由」や「チームでの役割」に触れたはずです。面談は、その続きを聞く場です。

面談で確かめたいことは、次の三つです。

- **学生が何に反応して承認したか**：文面のどこが届いたか
- **競技の中で、どう考えて動いてきたか**：成果ではなく、判断と行動の積み重ね
- **学生が仕事に何を求めているか**：競技と同じものを求めているのか、違うものを求めているのか

三つ目は見落とされがちです。競技に打ち込んできた学生が、仕事にも競技と同じ厳しさを求めているとは限りません。むしろ、競技とは違う形で力を使いたいと考えている学生もいます。

## 手順1｜日程を練習と試合に合わせる

体育会系の学生は、練習や試合、遠征の予定で、平日も週末も埋まっていることがあります。

1. **候補日を多めに出す**：平日の夕方以降や、練習のない日を選べるようにする
2. **オンラインを選べるようにする**：移動の時間がなくなるだけで、参加しやすくなる
3. **試合や大会の時期を聞く**：その時期は面談や選考を避ける
4. **引退の時期を聞く**：引退後に時間が取れるようになる学生も多い。次の接点の時期の目安になる

日程の調整に時間がかかると、それだけで学生は「この会社は自分の事情を分かっていない」と感じます。最初の返信で、こちらから練習の予定を気にかける一文を入れるだけでも、受け止められ方が変わります。オンラインの面談の進め方は[オンラインで会うときの進め方](/media/ob-mendan-online/)にまとめています。

## 手順2｜聞く順番を決める

面談では、次の順番で聞くと、学生が話しやすくなります。

1. **承認した理由**：文面のどこに反応したか
2. **競技を始めた理由と、続けた理由**：始めた理由と続けた理由は違うことが多い
3. **チームの中での役割の変化**：入部した頃と、上級生になってからで何が変わったか
4. **うまくいかなかった時期**：けが、選手から外れた時期、チームがまとまらなかった時期にどう動いたか
5. **仕事に求めていること**：競技と同じものか、違うものか

4つ目は、学生によっては話しにくい内容です。無理に聞き出さず、「話せる範囲で」と添えます。話してくれた内容は、その学生の考え方をよく表しています。

最後に、会社の仕事の中で、学生の話とつながる場面を一つだけ話します。「チームの中で役割が変わった話は、うちでは入社二年目に後輩の面倒を見るときに近い」のように、学生の話を自社の仕事に置き換えます。

### エージェントベストの見解

体育会系の学生との面談で、契約後によく起きるのは、面接官が自分の経験と重ねて話しすぎることです。面接官自身が体育会出身だと、競技の話で盛り上がり、面談の時間の多くが面接官の思い出話になります。学生は楽しく話して帰りますが、会社の仕事について知ったことはほとんど残りません。そして選考の場では、盛り上がった分だけ評価が高くなりがちです。勧めているのは、競技の話は学生が話す時間にとどめ、面接官は聞き役に回ることです。面接官が話すのは、最後に学生の話を自社の仕事に置き換える一場面だけにする。体育会出身の面接官は、学生の話を深く理解できる強みがあります。その強みは、自分が話すより、学生の話の要所を聞き返すことに使うほうが活きます。

## 面接官の思い込みを防ぐ

体育会系の学生には、「上下関係に慣れている」「体力がある」「指示に従える」といった決まった見方がついて回ります。この見方で面談を進めると、学生の実際の考え方を見落とします。

- **決まった見方を質問にしない**：「上下関係は大丈夫ですよね」と聞かない
- **競技の種類や実績で評価を変えない**：成果の大きさより、過程の中身を見る
- **評価の基準を、他の学生と同じにする**：体育会系だから別の基準にしない

評価の基準の作り方は[学生の評価基準の作り方](/media/ob-gakusei-hyouka-kijun/)で書きました。体育会系の学生だけを別の物差しで見ると、入社後にずれが出やすくなります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 競技の実績ばかり聞く | 過程が分からない | 続けた理由と役割の変化を聞く |
| 日程を会社の都合で決める | 練習と重なり、参加しにくい | 候補日を多めに出し、オンラインも選べるように |
| 面接官が自分の経験を話す | 学生が会社を知る時間がない | 面接官は聞き役に回る |
| 決まった見方で質問する | 学生の実際の考え方を見落とす | 質問は過程を聞く形に |
| うまくいかなかった時期を問い詰める | 学生が話しにくくなる | 話せる範囲で、と添える |
| 引退の時期を聞かない | 次の接点の時期を外す | 面談で聞き、記録する |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 日程の調整と、練習・試合の予定の確認 | 人事 |
| 面談 | 名義の人、または体育会出身の若手社員 |
| 面談の記録（承認の理由、過程、引退の時期） | 面談に出た人 |
| 評価の基準のすり合わせ | 人事と面接官 |
| 次の接点の調整 | 人事 |

体育会出身の社員を面談に出すと、学生は話しやすくなります。ただ、前の見解で書いたとおり、聞き役に回ることを事前に伝えておきます。

### エージェントベストの見解

体育会系の学生との面談を組む前に、先に決めておくべきなのは、「面談で何が分かったら次に進めるか」です。体育会系の学生は、話し方がはきはきしていて、面談の印象がよくなりやすい傾向があります。印象がよいまま次に進めると、選考の後半で、仕事に求めていることが会社と合わないと分かることがあります。面談の前に、「続けた理由が自分の言葉で語れるか」「役割が変わったときにどう動いたか」「仕事に求めることが、自社で用意できるものと重なるか」の三つを、次に進める目安として面談に出る人と共有しておく。印象ではなく、この三つで次に進めるかを決めると、面接官による差も小さくなります。

## まとめ

- 面談は、文面で触れた「続けた理由」「役割の変化」「うまくいかなかったときの動き方」の続きを聞く場
- 日程は練習・試合・引退の時期に合わせ、オンラインも選べるようにする
- 聞く順番を決め、最後に学生の話を自社の仕事に置き換える
- 面接官は聞き役に回り、決まった見方で質問しない
- 次に進める目安を、面談の前に共有しておく

## よくある質問

### 競技の実績は、まったく聞かなくてよいですか

聞いて構いません。ただ、実績そのものより、実績に至るまでに何を考え、どう動いたかを中心にします。実績の大小で評価を変えないことが大切です。

### 引退前の学生とは、どう関係を保てばよいですか

引退の時期を聞き、その頃にもう一度話す機会を作ります。引退までは連絡を控えめにし、学生の競技の邪魔をしないようにします。面談後の連絡の考え方は[面談後のフォロー](/media/ob-mendan-go-follow/)にまとめています。

### 体育会の先輩社員に面談に出てもらうのは効果がありますか

学生が話しやすくなる点で効果があります。同じ部や大学の先輩である必要はありません。先輩社員の出し方は[OB・OGを面談に出す方法](/media/ob-sd-ob-og/)で書いています。
