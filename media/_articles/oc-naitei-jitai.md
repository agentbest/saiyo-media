ワンキャリアを通じて内定を出した学生から、承諾ではなく辞退の連絡が続くことがあります。そのとき最初に浮かぶのは、内定者への連絡や面談を増やす案です。しかしワンキャリアの学生は、先輩の選考体験談やクチコミ、企業ページを読んで、会社の像を持ったうえで選考に来ています。辞退の理由は、その像と実際の選考や内定の連絡との差として、内定の前から積み上がっていることが少なくありません。**結論から言うと、ワンキャリア経由の内定辞退は、「体験談と企業ページで描いた会社と、選考で会った会社が違った」「内定から承諾までの接点が無かった」「条件を内定の連絡で初めて知った」「他社の体験談と比べて、仕事と配属が見えなかった」の四つの型に分けて考えます。内定後の連絡を増やして直るのは二つ目だけで、残りは企業ページと選考に戻って直します。辞退した学生も体験談を書く側に回る前提で返事をし、承諾した学生の理由は翌年の企業ページとイベントに使います。** 選考の途中で離れる学生については、[ワンキャリア経由の学生が選考で離脱するとき](/media/oc-senkou-ridatsu/)で別に書きました。

## 体験談で読んだ会社像と、内定までの実際の差を探す

内定辞退は採用の最後に起きるため、内定後の対応に目が向きます。ところがワンキャリアの学生の頭の中には、体験談とクチコミ、企業ページを読み、他社とも比べた結果として、選考が始まる前から「この会社はこういう選考で、こういう人がいる」という像ができています。

辞退は、その像と選考や内定の連絡との差が、内定を比べる段階で表に出たものです。見直しの目的は、差が生まれた工程を特定して直すことです。もう一つ、辞退した学生も翌年の学生が読む体験談を書く可能性がある、という点を見直しの前提に置きます。

## 辞退は四つに分けると、直す場所が見える

| 辞退の型 | 学生の側で起きたこと | 手を入れる工程 |
|---|---|---|
| 1. 描いた会社と、選考で会った会社が違った | 体験談で「面接で話をよく聞いてくれる」と読んで来たのに、実際は質問を並べるだけだった。内定を比べるとき、その差が残る | 選考を、企業ページに書いた流れと見る点のとおりに運ぶ |
| 2. 内定から承諾までの接点が無かった | 内定の連絡のあと、承諾の期限まで会社から何もなく、その間に連絡をくれた他社に気持ちが移った | 内定から承諾までの接点の設計 |
| 3. 条件を内定の連絡で初めて知った | 企業ページに条件の記載がなく、内定の連絡で初めて具体を見て、想定と違った | 企業ページへの条件の記載。[ワンキャリアの掲載の条件の書き方](/media/oc-keisai-jouken/) |
| 4. 他社の体験談と比べて、仕事と配属が見えなかった | 他社の体験談やクチコミでは入社後の仕事や配属の決まり方が読めたが、自社では読めなかった | 企業ページの仕事の中身と配属の決め方の記載 |

内定のあとで戻せるのは「2」だけです。「1」は選考、「3」と「4」は企業ページの話で、内定より前の工程にあります。

## 内定後の連絡を増やしても戻らない辞退

内定者への連絡や面談を増やす案は、型によっては効きません。

- **選考で受けた印象は、内定のあとに上書きしにくい**：面接で感じた違和感は、内定後の明るい連絡よりも強く残る
- **条件で比べている学生は、連絡の多さでは考えを変えない**：比べている材料そのものが変わらないため
- **他社の体験談と見比べている学生には、読める材料で応える必要がある**：連絡を増やしても、企業ページに無い情報は読めない
- **連絡が増えると、「急かされた」と受け取る学生がいる**：その受け取り方は、内定者側の体験談やクチコミに残りやすい

内定後の対応そのものも体験談に書かれ、「何度も承諾を迫られた」と残れば翌年の学生が読みます。

### エージェントベストの見解

内定辞退の相談でよく聞くのは、「ワンキャリアの学生はたくさんの会社を比べているから、辞退が多いのは仕方がない」という声です。当社は求人広告代理店として、ワンキャリアの運用を横で見ていますが、辞退した学生から聞けた話を並べてみると、比べた中身はかなり具体的です。「他社は企業ページで配属の決まり方まで読めた」「他社は内定のあとに配属先の社員と話す機会があった」「御社は条件を内定の連絡で初めて知った」といった、手に入った材料の差です。学生は読めた事実どうしを比べており、材料を出していないことがそのまま辞退の理由になります。当社が最初に行うのは、辞退した学生が読んだと考えられる他社の体験談と、自社の企業ページと体験談を横に並べ、「向こうにあって、こちらに無いもの」を一つずつ挙げることです。

## 四つの辞退の見分け方

### 1. 描いた会社と、選考で会った会社が違った

- **辞退のときの言葉が「面接の雰囲気が想像と違った」「ページで読んだ印象と違った」**
- **面接官が、自社の企業ページと体験談に目を通していない**
- **企業ページに「選考で見ること」として書いた点と、面接で実際に聞いた内容が食い違っている**

手を入れるのは選考で、書いたとおりに運ぶことを面接官とそろえます。

### 2. 内定から承諾までの接点が無かった

- **内定の連絡から承諾の期限まで、会社から学生に連絡した記録が無い**
- **辞退のときの言葉が「先に連絡をくれた会社に決めた」「考えているうちに他社で決まった」**
- **内定の連絡が、条件を伝える文書を送るだけで終わっている**

手を入れるのは、内定から承諾までの接点の置き方です。

### 3. 条件を内定の連絡で初めて知った

- **辞退のときの言葉が「条件面で」「想定していた待遇と違った」**
- **企業ページの条件欄が空いている、または「相談のうえ決定」としか書かれていない**
- **選考の途中で、条件の話を一度もしていない**

手を入れるのは企業ページです。条件は事実として載せ、内容は年度の公表内容と自社の制度で確かめます。

### 4. 他社の体験談と比べて、仕事と配属が見えなかった

- **辞退のときの言葉が「他社のほうが入社後の仕事を想像できた」「配属の見通しが立った」**
- **自社の企業ページに、入社後の仕事の中身と配属の決め方の記載が無い**
- **内定のあとに、配属先になりうる部署の社員と話す機会を用意していない**

手を入れるのは、企業ページの仕事の中身と配属の決め方の記載と、内定のあとに配属先の社員と話す機会です。企業ページの書き方は[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で整理しています。

## 辞退の記録を、企業ページと体験談に照らして読む

- **答えてもらえる範囲で尋ねる**：「今後の採用の参考にしたいので、もしよろしければ」と一言添える
- **本人の言葉と社内の見立てを分けて書く**：「他社に決定（本人）」「配属の見通しの差か（見立て）」
- **辞退の連絡には、まずお礼を返す**
- **四つの型に振り分け、月末にまとめて眺める**
- **面接や面談に出た社員にも、学生が気にしていた様子が無かったかを尋ねる**

集めた記録は、学生が最初に読んだものまでさかのぼって照らし合わせます。

| 照らし合わせる場所 | 確かめること |
|---|---|
| 自社の体験談とクチコミ | 学生が選考の前に読んだと考えられる記述は何だったか |
| 企業ページ | 選考の流れ、見る点、仕事の中身、配属の決め方、条件が載っていたか |
| 選考の記録 | 面接が、企業ページに書いた見る点のとおりだったか。どの面接のあとで反応が変わったか |
| 内定から承諾までの記録 | 期限までに、誰が、いつ、どんな形で学生と話したか |
| 辞退の理由 | 本人の言葉と、社内の見立て |

承諾した学生でも同じ表を埋めて並べると、両者が分かれた行が、手を入れる工程の手がかりになります。

## 内定から承諾までの接点と、辞退への返し方

内定から承諾までは、学生が他社の体験談と見比べながら最後の判断をする時間です。用意するのは、判断の材料と話せる相手です。

- **内定の連絡を、条件の文書だけで終わらせない**：「面接を担当した社員が、もう一度お話ししたいと言っています」と添える
- **承諾の期限までに、話せる相手を一人以上用意する**：面接を担当した社員、配属先になりうる部署の若手、先に承諾した内定者など
- **配属の見通しは、伝えられる範囲で伝える**：入社後に決まるなら、その決め方と時期を
- **承諾を急かさない**：「お決まりですか」を何度も送らない。急かされた経験は体験談に残る
- **承諾の期限は、学生の選考状況を聞いたうえで決める**：他社の選考が残っているなら、その予定を尋ねてよい

辞退の連絡を受けたあとの対応も、翌年の学生に届きます。

- **辞退への返事が、そのまま体験談になる**：「丁寧なお礼が届いた」か「返事が無かった」か
- **辞退した学生の周りには、翌年に就職活動をする後輩がいる**：後輩に「丁寧な会社だった」と話してもらえるかが分かれる

## 承諾した学生の理由を、翌年の企業ページとイベントへ

辞退の理由と同じくらい役に立つのが、承諾した学生の理由です。

- **承諾の決め手を尋ねる**：「企業ページのどこを読んで」「どの面接で」「内定のあと誰と話して」
- **決め手になった点を、翌年の企業ページの仕事の中身と配属の決め方に書き足す**：更新の進め方は[ワンキャリアの企業ページの更新](/media/oc-kigyo-page-koushin/)
- **本人の了解を得て、翌年のイベントや面談に内定者として出てもらう**：学生が体験談で読んだ「社員の雰囲気」を、実際に確かめる場になる
- **辞退した学生の理由と、承諾した学生の決め手を一枚に並べる**：どこが分かれ目だったかを社内で共有する

## 社内の分担

| 作業 | 担当 |
|---|---|
| 辞退の理由を尋ね、本人の言葉と社内の見立てを分けて記録する | 人事 |
| 記録を企業ページと体験談までさかのぼって照らし合わせる | 人事 |
| 他社の体験談と自社の企業ページを並べ、自社に無い記述を挙げる | 人事 |
| 選考を企業ページに書いたとおりに運ぶ（型1） | 面接官と人事 |
| 内定から承諾までの接点を設計し、話す相手を用意する（型2） | 人事と、話す社員 |
| 条件を企業ページに事実として載せる（型3） | 人事と管理部門 |
| 仕事の中身と配属の決め方を企業ページに書き足す（型4） | 人事と配属先の部署 |
| 辞退の連絡へのお礼の返事 | 人事 |

運用代行や代理店が手伝えるのは、四つの型への振り分け方、理由の尋ね方、さかのぼって照らし合わせる表、他社の体験談との並べ方、型ごとの直し方の案までです。理由を尋ねること、条件を決めること、選考を変えること、内定者と話すことは企業が行います。

### エージェントベストの見解

見直しは、見る順番で結果が変わります。当社がワンキャリアで「内定辞退が続いている」という相談を受けたときは、内定後の対応を話題にする前に、辞退した学生の記録を企業ページと体験談の時点までさかのぼって並べます。そこで、条件欄が空いていた、配属の決め方が書かれていなかった、面接官が企業ページの「見る点」を読んでいなかった、といったことが見つかれば、手を入れるのはその工程です。内定から承諾までの接点が無かっただけなら、そこで初めて内定後の対応を組み直します。当社が勧めるのは、企業ページ、選考、内定後、の順に見ることです。逆から進めると、連絡を増やして「急かされた」と書かれたあとで、原因が条件欄の空白だったと分かることになりかねません。

## まとめ

- ワンキャリアの学生は、体験談と企業ページで会社の像を持って選考に来る。内定辞退は、その像と選考や内定の連絡との差が、内定を比べる段階で表に出たもの
- 辞退は、描いた会社と違った・承諾までの接点が無かった・条件を内定の連絡で初めて知った・他社の体験談と比べて仕事と配属が見えなかった、の四つの型に分ける。内定後の連絡で戻せるのは二つ目だけ
- 辞退の記録は、本人の言葉と社内の見立てを分け、企業ページと体験談の時点までさかのぼって承諾した学生と並べて読む
- 内定から承諾までは、面接を担当した社員や配属先の若手と話す機会を置き、急かさない。辞退への返事も体験談に残る前提で丁寧に
- 承諾した学生の決め手を、翌年の企業ページとイベントに使う

## よくある質問

### 辞退の理由が「他社に決めた」としか返ってこず、自社の原因が見えません

その学生が、他社のどんな記述と自社のどんな記述を比べたかを、企業ページと体験談までさかのぼって考えます。他社の体験談やクチコミには書かれていて、自社の企業ページには無いもの、たとえば条件、配属の決め方、入社後の仕事の中身があれば、それが比べる材料の差です。承諾した学生と並べると、違いが見えやすくなります。

### 内定のあとに承諾を急かさないと、他社に決められてしまいませんか

急かされた学生は、その経験を体験談やクチコミに書くことがあり、翌年の学生がそれを読みます。急かす代わりに、面接を担当した社員と話す機会を置き、配属の見通しを伝えられる範囲で伝え、質問にはその日のうちに答えます。学生が自分で決められる材料を渡すほうが承諾につながりやすく、辞退になった場合も「丁寧な会社だった」と残ります。

### ワンキャリア経由の内定辞退の見直しは、御社に相談できますか

できます。当社は求人広告代理店として、ワンキャリアの運用を支えており、四つの型への振り分け方、理由の尋ね方、企業ページと体験談までさかのぼって照らし合わせる表、他社の体験談との並べ方、型ごとの直し方の案をお手伝いしています。理由を尋ねること、条件を決めること、選考を変えること、内定者と話すことは、企業の側で行っていただく形です。
