Wantedlyのコンテンツは、毎月の小さな直しと、四半期に一度のまとめた見直しで保ちます。毎月の直しは「止まっている募集記事を1か所」で、四半期の見直しは「会社ページ・募集記事・ストーリーの全体を、面談の言葉と台帳で棚卸しする」ものです。**結論から言うと、四半期の見直しは、面談で聞いた候補者の言葉を集めることから始め、台帳で古い記事と型の偏りを見て、会社ページの事実、募集記事の4段、ストーリーの直す・残す・下げる、導線、の順に短く確かめ、次の四半期に書くものと直すものを決めて終えます。全部を直そうとしない、数字だけで判断しない、見直して終わりにしない、の3つを守ると、続きます。** この記事では、毎月と四半期の役割、見直す順番、会の持ち方、次の予定の決め方、やりがちな失敗、分担を整理します。毎月の1か所直しは[募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)で書きました。

## この作業の目的｜全体を、定期的に、短く確かめる

毎月の直しは、目の前の募集記事に向きます。会社ページが古くなっていること、ストーリーの型が偏っていること、導線が切れていることは、毎月の作業では気づきません。

四半期の見直しの目的は、「全体を、決まった間隔で、短い時間で確かめ、次の四半期の予定を決める」ことです。全部を直す場ではなく、何を直し、何を書くかを決める場です。

## 毎月と四半期の役割

| | 毎月 | 四半期 |
|---|---|---|
| 見るもの | 止まっている募集記事 | 会社ページ・募集記事・ストーリー・導線の全体 |
| 材料 | 面談の言葉、管理画面の変化 | 面談の言葉の3か月分、台帳 |
| やること | 1か所直す | 直すもの・書くもの・下げるものを決める |
| 時間 | 短い | 短い会を1回 |
| 出るもの | 直した記録 | 次の四半期の予定 |

四半期の見直しで「直す」を全部やろうとすると、長くなり、続きません。決めるまでにして、直すのは次の四半期の毎月の作業に回します。

## 見直す順番

1. **面談の言葉を集める**：3か月分の「どこを読んで来たか」「分からなかったこと」「記事と違ったこと」を一覧にする。面談に出る人から、一行ずつ集めたもの
2. **台帳で、古い記事と偏りを見る**：公開から時間が経った記事、同じ型が続いている記事、同じ人ばかり出ている記事、読ませたい候補者が偏っている記事。台帳の型は[コンテンツを資産として貯める考え方](/media/wt-naiyou-shisan/)
3. **会社ページの事実を確かめる**：事業、拠点、代表、メンバー、写真。変わったのに直っていないものが無いか。考え方は[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)
4. **募集記事を4段で見る**：出ている募集ごとに、どこで止まっているか。閉じる・分ける・作り直す・そのままを決める
5. **ストーリーを、直す・残す・下げるに分ける**：古い順に、読まれている記事から。退職者の記事は本人の同意
6. **導線を確かめる**：会社ページ→募集記事→ストーリー→募集記事、の行き来が切れていないか。採用サイトとの行き来も。考え方は[Wantedlyと採用サイトの役割分担](/media/wt-saiyo-hp-renkei/)
7. **次の四半期の予定を決める**：書くもの、直すもの、下げるもの、誰が、いつまでに

1が最初です。面談の言葉が無いと、2以降は数字と印象だけで判断することになります。

### エージェントベストの見解

申し込んだあと、コンテンツの見直しで半年後に起きやすいのは、「見直しの会を開いたが、全部を直そうとして長くなり、二度目が開かれない」ことです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、初回の見直しで記事を全部読み、全部に直しの案を出し、その場で直し始めた会社は、次の四半期に「前回が大変だったから」で見直しが止まります。続いている会社は、見直しの会を短く区切り、「決める」までにして、直すのは翌月からの毎月の作業に回しています。当社が見直しの型を渡すとき、最初に伝えるのは「その場で直さない」ことです。決めた一覧が出れば、見直しは終わりです。直すのは、そのあとです。

## 見直しの会の持ち方

- **出る人**：人事、面談に出る人、責任者。代表は会社ページの事実の確認だけ
- **時間**：短く。長くなるなら、見るものを絞る
- **事前に用意するもの**：面談の言葉の一覧、台帳、出ている募集記事の一覧
- **進め方**：見直す順番のとおりに、1つずつ「直す・残す・下げる・書く」を決める
- **その場で直さない**：決めるだけ
- **出るもの**：次の四半期の予定の一覧（何を、誰が、いつまでに）

面談に出る人が出ることが要点です。面談の言葉を持っているのはその人で、記事と面談のずれに気づけるのもその人です。

## 次の四半期の予定の決め方

| 決めること | 決め方 |
|---|---|
| 書くストーリー | 偏っている型を埋める。次の募集に関わる職種の話。読ませたい候補者が偏っていれば、足りない候補者向け。テーマの決め方は[ストーリーのテーマの決め方](/media/wt-story-theme/) |
| 直す募集記事 | 止まっている段が分かった記事を、月に1本ずつ |
| 直す会社ページ | 事実の更新は今月。価値観の場面の入れ替えは、四半期に1つ |
| 下げる記事 | 退職者の記事、終わった募集、時期限定の告知 |
| 出る人の偏りを直す | 次に頼む人を、台帳の「出た人」から決める。頼み方は[記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/) |
| 導線の修正 | 切れているところを、今月 |

予定は、多くしません。四半期で「書く数本、直す数本、下げる数本」で足ります。多く決めると、毎月の作業が重くなり、途切れます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 全部を直そうとする | 長くなり、二度目が無い | 決めるだけにして、直すのは毎月に |
| 数字だけで判断する | 煽りに寄る、イベントの記事が増える | 面談の言葉を先に集める |
| 見直して終わり | 予定が無く、次の四半期に何も変わらない | 予定の一覧を出す |
| 面談に出る人が出ない | 記事と面談のずれに気づけない | 面談に出る人を入れる |
| 台帳が無い | 何があるか分からず、読み直しから始まる | 台帳を先に作る |
| 会社ページの事実を見ない | 古い事業名や退職者が残る | 順番の3を省かない |
| 予定を多くする | 毎月が重くなり、途切れる | 書く数本、直す数本、下げる数本 |

最も多いのは、最初の「全部を直そうとする」です。見直しの会が「直す会」になると、続きません。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 面談の言葉を一行ずつ集める | 面談に出る人（毎回）、人事（四半期にまとめる） |
| 台帳を整える | 人事 |
| 会社ページの事実の確認 | 人事（代表と責任者に確認） |
| 募集記事の4段の確認 | 人事と責任者 |
| ストーリーの直す・残す・下げる | 人事（本人と責任者に確認） |
| 導線の確認 | 人事 |
| 次の四半期の予定を決める | 人事、面談に出る人、責任者 |

運用代行や代理店が支えられるのは、見直しの型、台帳の整理、面談の言葉の一覧化、直す・残す・下げるの案、次の四半期の予定の案までで、面談で聞くこと、事実の確認、決めることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの四半期の見直しを支えるとき、見直しの型、台帳の整理、面談の言葉の一覧化、直す・残す・下げるの案、次の予定の案は当社が出せます。ただし、「面談で聞いた一行を、3か月間、集め続ける」ことだけは、企業にしかできません。当社が四半期に見直しの会に出ても、面談の言葉が無ければ、当社の案は記事を読んだ印象と管理画面の数字からの推測になります。当社が支援を始めるとき、最初にお願いするのは、面談に出る人が毎回一行を人事に送る形を作ることです。一行が3か月分あれば、見直しは短く、決められます。無ければ、見直しは長く、決まりません。四半期の見直しの質は、当社の案より、3か月分の一行で決まります。

## まとめ

- 毎月は止まっている募集記事を1か所直し、四半期は全体を面談の言葉と台帳で棚卸しする
- 順番は、面談の言葉→台帳→会社ページの事実→募集記事の4段→ストーリーの直す・残す・下げる→導線→次の予定
- 会は短く、人事と面談に出る人と責任者で、その場で直さず決めるだけ
- 次の四半期の予定は、書く数本、直す数本、下げる数本。多くしない
- 全部直す、数字だけ、見直して終わり、が続かない見直し。面談の一行を3か月集めることが土台

## よくある質問

### 四半期に一度では、遅くありませんか

会社ページの事実（退職、事業の変更）は、変わったときにその場で直します。四半期の見直しは、それとは別に「全体の棚卸し」で、間隔が短いと毎回の準備が重くなり、続きません。毎月の1か所直しと組み合わせれば、四半期で足ります。

### 記事が少ないうちから、見直しは必要ですか

記事が少ないうちは、見直しは短く済みます。台帳を付け始め、面談の一行を集め始める習慣を、記事が少ないうちに作っておくと、増えたときに困りません。最初の四半期は、「台帳を作る」と「面談の一行を集める形を作る」の2つで足ります。

### 四半期の見直しは、御社に相談できますか

できます。当社は、見直しの型、台帳の整理、面談の言葉の一覧化、直す・残す・下げるの案、次の四半期の予定の案を支えられます。面談で聞くことと、決めることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
