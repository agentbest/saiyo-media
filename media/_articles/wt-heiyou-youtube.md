Wantedlyで会社ページとストーリーを出している。上司や現場から「動画も作ったほうがいいのではないか」と言われる。あるいは、すでに採用動画をYouTubeに置いていて、Wantedlyとどう組み合わせるかが決まっていない。**結論から言うと、動画は「声と動きで場面を見せるもの」、Wantedlyは「読んで、話を聞きに行きたいと来る場所」で、役割が違います。動画は候補者の温度を上げ、応募の判断はWantedlyの記事の側で決まります。使い分けるなら、動画を作る前にストーリーの場面を決め、動画の中身を記事と揃え、動画から会社ページに戻す導線を置き、古くならない中身で短く撮ることです。** この記事では、それぞれの役割、使い分けの分担、中身の揃え方、工数の置き方、やりがちな失敗、社内の分担を整理します。SNS全般の考え方は[SNSからの母集団形成](/media/kh-boshudan-sns/)、Wantedlyの記事を広げる方法は[Wantedlyの記事をSNSで広げる方法](/media/wt-sns-kakusan/)で書きました。YouTubeの仕様や数値は書きません。

## それぞれの役割｜動画は「場面を見せる」、Wantedlyは「読んで応募する」

| | YouTube（採用動画） | Wantedly |
|---|---|---|
| 伝わるもの | 声、話し方、表情、職場の動き。文章で書けない空気 | 何をしている会社か、なぜか、誰と何をするか。判断に使う中身 |
| 候補者がすること | 見る。温度が上がる、または下がる | 読む。「話を聞きに行きたい」と来る |
| 残り方 | 出た社員が変わると古くなる。作り直しにくい | 記事は書き直せる。積み上がる |
| 作る時間 | 撮影・編集・出る社員の同意。一本が重い | 話を聞いて書く。一本が軽く、数で積める |
| 応募の導線 | 動画の中にはない。戻す先が要る | 募集記事に「話を聞きに行きたい」がある |

動画は、文章で伝えにくい「この人たちと働く感じ」を見せられます。ただし、動画を見ても、候補者はそのまま応募できません。「どんな仕事か」「最初の年に何をするか」を読む場所が要り、それがWantedlyです。動画は入口の温度を上げるもので、判断の材料はWantedlyの側にあります。

## 使い分けの分担｜動画は温度、判断は記事

- **動画で見せるのは、記事に書いた場面の「声と動き」**：記事に書いていない場面を動画だけで出さない。読んだ人が「あの場面だ」と分かる形
- **動画の説明欄と、記事の中に、互いへの導線を置く**：動画から会社ページへ、ストーリーから動画へ。貼れる形は現在の仕様で確認する
- **応募の判断に要ることは、記事に書く**：仕事の中身、最初の年、誰と組むか、条件。動画で「語る」だけにしない
- **動画に出る人は、ストーリーに出ている人にする**：読んで来た候補者が、動画で同じ人の声を聞くと、「読んだとおり」になる
- **面談で「動画を見たか」「記事を読んだか」を聞き、台帳に残す**：どちらが効いているかは、来た人の言葉で分かる

動画があると応募が増える、とは限りません。動画を見て温度が上がった人が、Wantedlyの記事を読んで「合う」と判断したときに来ます。記事が薄いと、動画で上がった温度が、記事で下がります。

### エージェントベストの見解

これをやる前に、先にストーリーの場面を決めておかないと、動画を作っても効果が出ません。当社は3媒体すべての販売パートナーとして、「動画を作ったほうがいいか」という相談を受けますが、話を聞くと、ストーリーがまだ数本で、会社ページの「なぜ」が代表の言葉の場面になっていない段階で、動画の話が先に出ていることが多くあります。この段階で動画を作ると、「会社紹介」の動画になり、事業と沿革と社屋の映像に音楽が付いた形で、候補者が判断に使える場面がありません。順番は、ストーリーで「社員が何をどう変えた場面」を数本書き、来た候補者が挙げる場面が見えてから、その場面を撮ることです。撮る場面が記事の中にあれば、動画は短くて済み、記事を読んだ人が「この人の声を聞きたい」で見る形になります。動画の予算より先に、記事の場面が揃っているかを見ます。

## 動画の中身｜古くならないもので、短く

| 向く中身 | 向かない中身 |
|---|---|
| ストーリーに出た社員が、記事の場面を自分の言葉で話す | 事業と沿革と社屋の紹介に音楽が付いたもの |
| 職場の一日の、動きが見える数分 | 制度や条件の説明。変わると古くなる |
| 代表が「なぜ」を自分の言葉で話す短いもの | 演出された座談会。話し方が本人のものでなくなる |
| 仕事の場面（会議、現場、作業）の断片 | 「アットホーム」「風通し」を映像で言い換えたもの |

- **一本を短く**：長い一本より、場面ごとの短い数本。見る人は、全部を見ない
- **出る社員の同意を、文書で取る**：辞めたあとも公開してよいか、消してほしいと言われたらどうするか
- **数値や制度を、動画の中で言わない**：変わったときに作り直せない。記事に書き、記事を直す
- **撮り方は、記事の写真と同じ考え方で**：演出しない、本人の言葉で、場面が分かる。[Wantedlyのストーリーの写真](/media/wt-story-shashin/)
- **本音の範囲は、記事と同じ線で**：動画だから出せる、はない。[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)

## 工数の置き方｜動画は「一本が重い」、記事は「数で積む」

| 項目 | YouTube | Wantedly |
|---|---|---|
| 作る時間 | 企画、撮影、編集、出る人の確認。一本ごとに大きい | 話を聞いて書く。一本ごとに小さい |
| 出る人の負担 | 顔と声が残る。同意と、辞めたあとの扱い | 名前と写真。書き直せる |
| 外に出せる部分 | 撮影と編集は出せる。話す中身は出せない | 整える部分は出せる。話す中身は出せない |
| 更新 | 作り直しは重い。古くならない中身で作る | 直せる。月に一度見直す |
| 費用 | 外に出すなら制作費。条件は制作会社ごとに違う。この記事では書かない | プランの費用。公式ページで確認 |

- **記事の時間を先に確保し、動画は残った時間で**：動画を作る時期に、記事の更新が止まらないように
- **最初の一本は、社内で短く撮る**：外に出す前に、どの場面が効くかを記事の反応で見る
- **出る人の時間は、現場の責任者と合意してから**：撮影は半日単位で時間を取る
- **動画の数字（再生数）で判断しない**：見た人が、会社ページに来て、面談で「動画を見た」と言うかで見る

時間が足りないときは、動画より記事を残します。記事は積み上がり、動画は古くなります。時間の直し方は[Wantedlyの運用に工数が足りないとき](/media/wt-kousuu/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 記事より先に動画を作る | 会社紹介の動画になり、判断に使える場面がない | ストーリーの場面を先に |
| 動画だけで応募の導線がない | 温度が上がった人の行き先がない | 会社ページと募集記事へ戻す |
| 制度や数値を動画で言う | 変わったときに作り直せず、古い情報が残る | 記事に書き、動画では言わない |
| 出た社員が辞めて、動画が残る | 読んで来た人が、いない人の声を聞く | 同意の文書と、消す判断の担当を決めておく |
| 再生数で効果を見る | 会社ページに来たかと別の数字で判断する | 面談で「見たか」を聞き、台帳で見る |

最も多いのは、一つ目です。動画の話が先に出て、記事の場面が揃う前に撮ってしまいます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| どの記事の、どの場面を動画にするかを決める | 人事と、記事に出た社員 |
| 出る社員の同意と、辞めたあとの扱いを決める | 人事と責任者 |
| 撮影と編集（社内か、外か） | 人事、または制作会社 |
| 動画と記事の導線を置く | 人事 |
| 面談で「見たか・読んだか」を聞き、台帳に残す | 面談に出る人 |
| 動画を消す・作り直す判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、記事の場面から動画にする場面の選び方、導線の置き方、台帳の型までで、場面の決定、出る社員の同意、撮影の実施、消す判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。ワンキャリアで動画を使う考え方は[ワンキャリアで動画を使う方法](/media/oc-douga/)で書きました。

### エージェントベストの見解

動画を作ったあと、最初の年で起きることに共通するのは、動画に力を入れた分、記事の更新が止まることです。当社はWantedlyの運用を申込のあとまで見ていますが、採用動画を作った会社の会社ページを翌年に見ると、動画は残っているのに、ストーリーは動画を作った時期で止まり、動画に出た社員が異動や退職でいなくなっている、という形が多くあります。動画は作ったときの状態で固定され、記事は書き足せる。この違いを分かったうえで、動画は「古くならない場面を短く」、記事は「月に一度、書き足す」と役割を分けておくと、動画の側が古くなっても、記事の側で会社の今が伝わります。動画を作る前に、動画を作ったあとの記事の時間を、先に予定に固定しておくことを勧めています。

## まとめ

- 動画は「声と動きで場面を見せる」、Wantedlyは「読んで、話を聞きに行きたいと来る場所」。動画は温度を上げ、判断は記事の側で決まる
- 動画を作る前に、ストーリーの場面を決める。動画で見せるのは、記事に書いた場面の声と動き
- 動画から会社ページへ、ストーリーから動画へ、互いの導線を置く。応募の判断に要ることは記事に書く
- 古くならない中身で短く。制度や数値は動画で言わない。出る社員の同意と、辞めたあとの扱いを文書で
- 記事の時間を先に確保し、動画は残った時間で。再生数ではなく、面談で「見たか」を聞いて見る

## よくある質問

### 採用動画は、外に出して作るべきですか

最初の一本は、社内で短く撮ることを勧めます。どの場面が候補者に効くかは、記事の反応で見えてくるので、それが見える前に外に出すと、「会社紹介」の動画になりやすいです。効く場面が分かってから、その場面だけを外に出して撮ると、短く、古くならない動画になります。

### Wantedlyのストーリーに、YouTubeの動画を貼れますか

貼れる形と範囲は、現在の仕様で確認してください。貼れる場合も、動画だけを置かず、その場面を文章でも書きます。読む人と見る人の両方がいるので、動画がなくても記事だけで判断できる形にしておきます。

### WantedlyとYouTubeの使い分けは、御社に相談できますか

できます。当社は、役割の整理、記事の場面から動画にする場面の選び方、導線の置き方、台帳の型を支えられます。場面の決定、出る社員の同意、撮影の実施、消す判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
