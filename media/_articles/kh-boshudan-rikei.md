理系の学生の母集団を作りたい。ところが、「理系」で一括りにして送り、研究内容そのもので選び、人事だけで読んで書き、研究室の時期を見ず、条件で勝とうとして、取り合いに負ける。**結論から言うと、理系の母集団は、「理系」で一括りにせず、「こんな人」を研究の進め方で書きます。研究室の時期に合わせ、技術の人が読んで書き、面談に技術の人を出し、研究とのつながりを事実で書きます。入口は研究室との関係・スカウト・インターンで、取り合いは「速さ」と「仕事の具体」で。** この記事では、理系の母集団で起きる失敗、「こんな人」の書き方、入口ごとの役割、技術の人の関わり方、時期、研究と仕事のつながり、取り合い、研究職以外への誘い、分担を整理します。母集団の考え方は[母集団形成の基本｜量と質の順番](/media/kh-boshudan-kihon/)、理系向けの文面は[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)、取り合いは[OfferBoxで理系学生の取り合いに負けるとき](/media/ob-rikei-toriai/)で書きました。

## この作業の目的｜「研究をこう見て、仕事でこう活きる」が伝わる母集団にする

理系の学生は、研究に時間を使っていて、「研究を読んだうえで送っているか」を文面で読み分けます。母集団形成にとっては、「読んだ」と伝わる入口と、研究とのつながりが確かめられる場が要ります。人事だけでは読めないことが多く、技術の人の時間が母集団のでき方を決めます。

目的は、理系の母集団を「理系向けの文面を送る」ことではなく、「技術の人が関わり、研究とのつながりが事実で伝わる入口」として作ることです。

## 理系の母集団で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 「理系」で一括りにする | 専攻も研究の進め方も違う人に、同じ文面。「読んでいない」と分かる |
| 研究内容そのもので、選ぶ | 研究内容が仕事と一致する人だけを追い、母集団が極端に狭くなる。進め方を見ていない |
| 人事だけで、読んで書く | 研究の要点が拾えず、文面が薄い。面談で技術の話ができない |
| 研究室の時期を、見ない | 学会・実験・論文の時期に送り、読まれない。返信が来ても面談の日程が取れない |
| 条件で、勝とうとする | 条件で負ける相手には勝てない。仕事の具体で勝つ場所を見ていない |

共通するのは、理系の母集団を「理系向けの文面」の問題として見ていることです。問題は「誰が読んで、誰が会うか」です。

## 「こんな人」を、研究の進め方で書く

- **研究内容ではなく、「研究の進め方」で書く**：「〇〇を研究している人」ではなく、「仮説を立てて実験を組み、うまくいかなかったときに原因を切り分けて次の実験を設計した人」
- **進め方は、仕事に写せる**：研究内容が仕事と違っても、進め方が近ければ「こんな人」
- **技術の人と、一緒に書く**：人事だけで書くと、内容の一致に寄る
- **専攻を条件にしすぎない**：条件を減らし、進め方で見る。[OfferBoxで大学群を広げるべきか](/media/ob-daigakugun/)の考え方
- **進め方の拾い方は[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)の「プロフィールで、読む箇所」と[OfferBoxで理系学生の取り合いに負けるとき](/media/ob-rikei-toriai/)の「研究内容そのものより、『研究の進め方』を拾う」**

### エージェントベストの見解

相談で最も多い思い込みは、「理系の母集団は、自社の仕事と研究内容が一致する学生を探せばよい」というものです。当社は3媒体すべての販売パートナーとして、理系の母集団形成を見ていますが、研究内容の一致で探した会社は、当てはまる学生が少なく、その少数は他社も追っていて、取り合いに負けています。逆に、「研究の進め方」で「こんな人」を書いた会社は、研究内容が違う学生にも届き、面談で「研究の進め方を見て送った」と伝わり、内容が一致する学生を追う他社と違う会社に見えています。理系の母集団の広さは、研究内容の一致ではなく、進め方で決まります。当社が理系の相談を受けるとき、最初にやるのは、「こんな人」の一枚から研究内容の条件を減らし、進め方の記述を足すことです。

## 入口ごとの、役割

| 入口 | 理系での役割 | 注意 |
|---|---|---|
| 研究室との関係 | 「こんな人」がいる研究室と、続く関係。理系で最も効く入口の一つ | 大学名で選ばず、社員の出身と仕事のつながりから。[大学との関係からの母集団形成](/media/kh-boshudan-daigaku/) |
| スカウト | 研究の進め方を読んで、技術の人が書く | 研究室の時期に合わせる。[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)、[ワンキャリアで理系学生にスカウトを送る方法](/media/oc-scout-rikei/) |
| インターン | 研究とのつながりを、実際の仕事で確かめる場 | 技術の人が受け入れる。[インターンからの母集団形成](/media/kh-boshudan-intern/) |
| 掲載 | 研究と仕事のつながりを、事実で書く | 理系向けの部分を分けて書く。[ワンキャリアで理系向けに掲載する](/media/oc-rikei-keisai/) |
| イベント | 技術の人と話せる少人数の回 | 人事だけの回にしない。[イベントからの母集団形成](/media/kh-boshudan-event/) |

どの入口も、技術の人の時間が要ります。全入口を開けず、技術の人の時間で入口を絞ります。

## 技術の人が、読んで書き、面談に出る

- **読むのは、技術の人**：研究の進め方は、人事だけでは拾えない
- **書くのは、技術の人か、技術の人が読んだ一文を人事が型に入れる形**：[OfferBoxで理系学生に届く文面](/media/ob-rikei-gakusei/)の手順1「入り方を、社内の体制で分ける」
- **面談に、技術の人を出す**：理系の学生は、技術の話ができる相手かを見ている。[OfferBoxで理系学生の取り合いに負けるとき](/media/ob-rikei-toriai/)の「面談に、技術の人を出す」
- **技術の人の時間を、先に確保する**：読む・書く・面談で週にどれだけか。[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)
- **社内に研究を読める人がいない場合**：[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)の「社内に、研究を読める人がいない場合」

## 研究室の時期に、合わせる

- **学会・実験・論文の時期は、読まれない**：送る時期と面談の日程を、研究室の時期で決める
- **学部・修士・博士で、時期が違う**：年度の公表内容と、学生ごとの状況で確認
- **送るときに、時期への配慮を一文**：「研究のお忙しい時期でしたら、時期をずらしてお返事いただいて構いません」
- **時期の配慮は[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)の「研究室の時期への、配慮」**

## 研究と仕事のつながりを、事実で書く

- **「この研究の進め方が、この仕事のこの場面で活きる」を、事実で**：抽象語（「研究で培った論理的思考」）ではなく、場面で
- **研究と仕事が離れている場合は、離れていることを書いたうえで、進め方のつながりを**：[ワンキャリアで理系学生にスカウトを送る方法](/media/oc-scout-rikei/)の「研究と仕事が、離れている場合の一文」
- **技術の人の記事を、読む場所に置く**：「この研究室出身の社員が、どう働いているか」
- **専門用語は、学生の分野の用語で**：自社の用語に言い換えない。[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)の「専門用語の、扱い」

## 取り合いは、「速さ」と「仕事の具体」で

- **理系の学生は、多くのスカウトを受けている**：条件で比べられ、条件で負ける相手には条件では勝てない
- **速さで勝つ**：返信を当日に、面談の日程を最初の返事で、面談から次までを短く。[OfferBoxで理系学生の取り合いに負けるとき](/media/ob-rikei-toriai/)の「承認への対応を、最速にする」
- **仕事の具体で勝つ**：「入社後、最初に何をやるか」「誰と」「どの設備で」を事実で。条件では書けない部分
- **負けの四つの中身を切り分ける**：[OfferBoxで理系学生の取り合いに負けるとき](/media/ob-rikei-toriai/)の「『負ける』の、四つの中身」

## 研究職以外に、誘う場合

- **「研究職ではない」ことを、先に書く**：隠して誘うと、面談で離れる
- **進め方が活きる場面を、その職種で書く**：営業でも企画でも、「仮説を立てて切り分ける」場面はある
- **その職種の、理系出身の社員が書き、面談に出る**：「研究職ではない道を選んだ理由」を話せる人
- **誘い方は[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)の「研究職以外に、誘う場合」と[OfferBoxで理系学生に届く文面](/media/ob-rikei-gakusei/)の手順3**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「こんな人」を研究の進め方で書く | 人事と技術の人 |
| 技術の人の時間を確保し、入口を絞る | 人事責任者と技術の責任者 |
| 研究室との関係を、社員の出身から始める | 出身の技術の人と人事 |
| 研究の進め方を読み、一文を書く | 技術の人 |
| 型に入れて送り、返信を当日に | 人事 |
| 面談に出て、技術の話をする | 技術の人 |
| 研究と仕事のつながりを事実で書き、記事にする | 技術の人と人事 |

運用代行や代理店が支えられるのは、「こんな人」の整理、入口の絞り方、文面の型、時期の配慮の型、取り合いの切り分けまでで、研究を読むこと、書くこと、面談、研究室との関係は企業（技術の人）が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)と[ワンキャリアの理系スカウトを代行に頼むとき](/media/oc-scout-rikei-daikou/)で書きました。

### エージェントベストの見解

これは向き不向きの話です。理系の母集団形成は、技術の人が読んで書いて面談に出る時間を確保できる会社に向きます。逆に、技術の人の時間がまったく取れず、人事だけで回す会社には、理系のスカウト型は向きません。当社は3媒体すべてのスカウト型を扱いますが、理系の相談で「技術の人は忙しくて関われない」と分かれば、スカウトの数を減らして技術の人が読める数にするか、研究室との関係やインターンなど、技術の人が「場に出る」だけで済む入口を先に、と勧めます。理系の学生が見ているのは、「文面が理系向けか」ではなく、「この会社に、研究を読める人がいて、その人と話せるか」です。技術の人が関わらない理系の母集団は、届いても決まりません。

## まとめ

- 理系の母集団は「理系」で一括りにせず、「こんな人」を研究内容ではなく「研究の進め方」で書く。進め方は仕事に写せ、内容が違う学生にも届く
- 入口は研究室との関係・スカウト・インターン・掲載・イベントで、どれも技術の人の時間が要る。技術の人の時間で入口を絞る
- 技術の人が読んで書き（または読んだ一文を人事が型に入れ）、面談に技術の人を出す。学生が見ているのは「研究を読める人がいて、話せるか」
- 研究室の時期に合わせ、研究と仕事のつながりを事実で場面で書き、専門用語は学生の分野の用語で
- 取り合いは条件ではなく「速さ」「仕事の具体」「読んだ一文」で。研究職以外に誘うなら、先にそう書き、その職種の理系出身の社員が出る

## よくある質問

### 技術の人が「採用に時間を使う余裕がない」と言います

技術の人に頼むのは、「読んで一文」と「面談に出る」の二つで、書く作業の全部ではありません。人事が候補を絞り、技術の人は一人あたり短い時間で研究の進め方を読んで一文を返し、人事が型に入れます。面談は、技術の人の枠を週に決めて、その枠に入れます。それでも時間が取れないなら、送る数を技術の人が読める数まで減らします。読まずに送った数は、理系の母集団になりません。頼み方は[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)で書きました。

### 自社の仕事と一致する研究をしている学生が、ほとんどいません

一致する必要はありません。「こんな人」を研究の進め方で書き直すと、内容が違う学生にも「進め方が近い人」がいます。文面には、「研究内容は当社の仕事と離れていますが、〇〇の進め方が、当社の〇〇の場面と重なると感じました」と、離れていることを書いたうえで進め方のつながりを書きます。書き方は[ワンキャリアで理系学生にスカウトを送る方法](/media/oc-scout-rikei/)の「研究と仕事が、離れている場合の一文」で書きました。

### 理系の母集団形成は、御社に相談できますか

できます。当社は、「こんな人」の整理、入口の絞り方、文面の型、時期の配慮の型、取り合いの切り分けを支えられます。研究を読むこと、書くこと、面談、研究室との関係は、企業（技術の人）が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
