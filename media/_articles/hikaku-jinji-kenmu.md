総務や経理や営業と兼務で、採用も担当している。採用媒体を使いたいが、本業の波で採用の時間が取られる。ところが、「手が空いたとき」に送り、本業の繁忙期に返信を数日放置し、専任と同じ大きさで始めて止まり、上司は採用の時間を業務と認めていない。**結論から言うと、兼務は「一人」よりさらに時間が細切れで、本業の波に採用の時間が取られます。だから媒体は「毎日の短い時間」より「まとまった時間を一度」で回せる形が先で、返信だけは毎日固定し、本業の繁忙期に縮小する形を先に決めます。兼務で回るかは、上司と「採用に使う時間」を業務として合意できるかで決まります。** この記事では、兼務で起きる失敗、兼務の時間の形、回す形、3媒体との相性、上司との合意、現場と外に出すもの、回るかの判断、分担を整理します。専任一人の場合は[人事一人で回せる採用媒体の選び方](/media/hikaku-jinji-hitori/)、工数が足りないときは[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)、3媒体の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)で書きました。

## この作業の目的｜本業の波の中で、採用が止まらない形を先に作る

兼務の採用が止まる原因は、本業の繁忙期です。繁忙期に採用の時間がゼロになり、返信が止まり、学生が離れ、繁忙期が明けると接点が消えている。専任一人なら「時間を固定する」で回りますが、兼務は固定した時間も本業に取られます。

目的は、本業の波を前提に、「波の時期にも止まらない最小の形」と「波が明けたときに戻る形」を先に決めることです。

## 兼務で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 本業の波で、採用が止まる | 繁忙期に返信が止まり、学生が離れ、接点が消える |
| 「手が空いたとき」にやる | 空かない。採用が本業の残りになり、動かない |
| 返信を、数日放置する | 学生は複数社を進めており、遅い会社から外れる |
| 専任と同じ大きさで始める | 送る数も掲載の広さも兼務の時間を超え、最初の月で止まる |
| 上司が、採用の時間を業務と認めていない | 本業の評価だけで見られ、採用の時間が「サボり」に見える |
| 繁忙期に止めて、接点が消える | 縮小ではなく停止にすると、進行中の学生が放置される |

共通するのは、「本業の波」を前提にした形を、先に決めていないことです。

## 兼務の、時間の形

- **細切れ**：まとまった時間が取りにくく、日々の短い時間が本業の合間にある
- **波がある**：本業の繁忙期（決算、期末、営業の締め）に、採用の時間がゼロに近づく
- **予定が入りにくい**：面談の日程を、本業の予定の後に入れることになる
- **一人と違うのは、「固定した時間が守れない」こと**：専任一人は固定できる。兼務は固定しても取られる
- **だから、「固定」より「縮小と復帰の形」を先に決める**

### エージェントベストの見解

相談で最も多い思い込みは、「兼務でも、専任一人と同じ運用を、少し小さくすれば回る」というものです。当社は3媒体すべての販売パートナーとして、兼務の担当者の相談を多く受けていますが、専任一人の形（週の時間を固定する）を兼務に当てはめた会社は、本業の繁忙期に固定した時間が消え、そこで返信が止まり、繁忙期が明けたときに学生が残っていません。逆に、「繁忙期には返信だけ、明けたら送る」と縮小と復帰の形を先に決めた会社は、繁忙期に送る数がゼロでも接点が残り、明けてから戻れています。兼務の運用の要点は、時間を固定することではなく、「波の時期に何を残すか」を先に決めることです。当社が兼務の相談を受けるとき、最初にやるのは、「本業の繁忙期はいつで、その時期に採用に使える時間は一日に何分ですか」を聞くことです。

## 兼務で、回す形

| 決めること | 兼務の答え |
|---|---|
| 媒体 | 一つ。「まとまった時間を一度」で整えられる形が先 |
| 職種 | 一つ |
| 送る・整える | まとまった時間が取れる時期に、一度にまとめて。毎日少しずつ、にしない |
| 返信 | 毎日、短い時間に固定。本業の繁忙期でも、返信だけは止めない |
| 面談 | 現場に出てもらう。自分は日程と案内だけ |
| 繁忙期 | 送る数をゼロにし、返信と進行中の学生の対応だけ残す。「縮小」であって「停止」ではない |
| 復帰 | 繁忙期が明けたら、送る・整えるに戻る。戻る日を先に決める |
| 台帳 | 最小限。段と日付だけ |
| 外に出す | 検索条件、型、集計、企業ページの型、契約の窓口 |

「縮小と復帰」を先に決めることが、兼務の形の全部です。縮小の考え方は[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)の「繁忙期の、一時的な縮小」で書きました。

## 3媒体の時間の使い方と、兼務との相性

| 媒体 | 時間の使い方 | 兼務との相性 |
|---|---|---|
| OfferBox | 毎週コツコツ送り、返信を返す | 毎週の時間が本業に取られやすい。送る時期を集中させ、繁忙期は返信だけ、の形にすれば回る |
| Wantedly | 通年で記事を書き、育てる | 書く時間が続けて取れないと止まる。社員が書き、兼務の担当は整えるだけ、なら回る |
| ワンキャリア | 最初に集中して企業ページを整え、反応を見る | 「まとまった時間を一度」の形に最も近い。整えた後は更新と受諾対応。兼務で先に検討しやすい |

優劣ではなく、兼務の時間の形（まとまった時間が一度、その後は細切れ）に合うかで見ます。「最初に集中して、後は軽く」の形が兼務に近く、「毎週コツコツ」は送る時期を集中させる工夫が、「通年で育てる」は社員に書いてもらう工夫が要ります。時間の使い方の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)の「軸3と軸4」で書きました。

## 上司との、合意

- **「採用に使う時間」を、業務として合意する**：週に何時間、繁忙期は何分。本業の評価と別に
- **繁忙期の縮小を、先に合意する**：「この時期は、返信だけ」を上司が知っている
- **面談は現場に出てもらうことを、上司から現場に伝えてもらう**：兼務の担当が現場に頼むより通る
- **止まらない大きさを、上司に見せる**：「この時間で、これだけ」の形。数は自社の実態で
- **合意がなければ、媒体を始めない**：合意なしで始めると、本業の評価で採用が止まる
- **上司の合意の取り方は[Wantedlyの記事づくりに社員の協力を得る方法](/media/wt-shain-kyouryoku/)の「上司の合意を先に取る」**

## 現場と外に、出すもの

- **現場に**：面談（出る人と枠）、名義、記事を「話して」もらう。[OfferBoxの現場を巻き込む方法](/media/ob-genba-makikomi/)
- **外に**：検索条件の案、文面の型、企業ページの型、集計、見直しの材料、管理画面の使い方、契約の窓口。[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)
- **自分に残す**：「こんな人」の決定、読んで書く最後の一文、返信、日程と案内、台帳の最小限
- **兼務は、「自分に残す」を最小にする**：専任一人より、さらに出す
- **代理店経由でも料金は変わらない**：[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)

## 兼務で回るかの、判断

1. **上司と、採用に使う時間を業務として合意できるか**：できなければ、始めない
2. **本業の繁忙期に、一日に返信の時間（短くてよい）が取れるか**：取れなければ、繁忙期に接点が消える
3. **面談に出る現場の人が、決まっているか**：決まっていなければ、送っても会えない
4. **まとまった時間が、年に一度か二度は取れるか**：取れなければ、整える・送るができない
5. **繁忙期の縮小と復帰の日を、先に決められるか**

五つが「はい」なら、一つの媒体・一つの職種で始めます。「いいえ」があれば、そこを先に作ります。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。兼務の相談で、「繁忙期は御社で返信まで代わってほしい」と言われることがあります。当社は、繁忙期の一次返信（承認への最初の返事と面談の案内）を、型に沿って代わる形は相談できますが、学生からの質問への返事、面談の日程の最終確認、進行中の学生の判断は、兼務の担当に残していただきます。学生が話しているのは、その会社の人で、当社ではないからです。繁忙期の縮小で当社が支えられるのは、「一次返信の型」と「繁忙期に何を残すかの整理」までで、返信そのものの全部ではありません。兼務で回すなら、繁忙期にも「一日に短い返信の時間」を残せる形を、上司と先に合意してください。

## まとめ

- 兼務は専任一人よりさらに時間が細切れで、本業の波に採用の時間が取られる。「固定」より「縮小と復帰の形」を先に決める
- 形は、媒体一つ・職種一つ・整える・送るはまとまった時間に一度・返信だけ毎日固定（繁忙期も）・面談は現場・繁忙期は送る数をゼロにして返信と進行中の対応だけ・復帰の日を先に
- 3媒体は時間の使い方の形で見る。「最初に集中して後は軽く」が兼務に近く、「毎週コツコツ」は送る時期の集中、「通年で育てる」は社員に書いてもらう工夫が要る
- 上司と「採用に使う時間」を業務として合意し、繁忙期の縮小と面談を現場に出てもらうことを上司から伝えてもらう。合意なしで始めない
- 現場と外に出せるものを最大に出し、自分に残すのは「こんな人」・最後の一文・返信・日程・台帳の最小限。回るかの判断は五つ

## よくある質問

### 上司が「本業が優先。採用は空いた時間で」と言います

「空いた時間」では動かず、動かない採用は媒体の費用だけが残ります。上司に、「週に〇時間を採用に使い、繁忙期は返信だけに縮小する」の形を見せ、その時間が業務であることを合意してもらいます。合意が取れないなら、媒体を始めないほうが、費用も接点も無駄になりません。「空いた時間で」のまま始めた会社は、最初の繁忙期で止まっています。

### 繁忙期が長く、年の半分近く採用に時間が取れません

繁忙期に「返信だけ」を残せるなら、残りの半分で「整える・送る」を集中させる形で回ります。送る時期を繁忙期の外に置き、企業ページを繁忙期の前に整え、繁忙期は受諾や承認への返信と進行中の学生の対応だけ。それも取れないなら、兼務で採用媒体を回す体制になっておらず、上司と時間の合意を先に作るか、面談と返信を現場に分担してもらう形を先に作ります。

### 人事兼務の媒体選びは、御社に相談できますか

できます。当社は、兼務の時間の形に合う媒体の整理、縮小と復帰の形の型、型と集計、企業ページの型、管理画面の使い方、契約の窓口を支えられます。上司との合意、読んで書くこと、返信、面談の手配、縮小の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
