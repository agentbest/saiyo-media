最初の本格的な資金調達を終えて、事業が固まり始めた。社員は少なく、社長が採用も見ている。「スタートアップに興味のある学生は多いはずだ」と考えて、OfferBoxで「ゼロから事業を作る仲間」と送ると、承認は付くが、面談で「事業は続きますか」「入ったら何をしますか」「新卒は初めてですか」と聞かれ、答えが決まっておらず離れます。**結論から言うと、シリーズAで新卒を採るのは珍しく、採るなら、先にインターンか業務委託で関わってもらい、合った人を新卒として迎える順番にします。「スタートアップ志望の学生が来る」とは思わず、「社長と」「決まっていない環境で」を選ぶ少数に、大きく見せずに、社長の名義で数通だけ送ります。** この記事では、この時期に新卒を採るべきかの判断、インターンから始める順番、学生が確かめること、最初に決めること、文面の書き方、分担、やりがちな失敗を整理します。組織が大きくなってからの運用は[シリーズB以降のスタートアップのOfferBox運用](/media/ob-startup-b-unyou/)、新規事業の「決まっていること・いないこと」の書き方は[新規事業を立ち上げる会社のOfferBox運用](/media/ob-shinki-jigyo-unyou/)で書きました。調達に関わる情報の扱いは、自社の方針と専門家の助言に従ってください。数値は書きません。

## 先に、この時期に新卒を採るべきかを判断する

| 問い | 採ってよい | インターンか業務委託から |
|---|---|---|
| 社長が、最初の年に週に決まった時間、新卒に教える時間を出せるか | 出せる | 「事業が忙しいときは無理」 |
| 一年後に、その新卒が何をしているかを言えるか | 言える | 事業が変わるので言えない |
| 新卒に任せたい仕事が、一行で言えるか | 「〇〇を、ゼロから教えて、△△を任せたい」 | 「手が足りない」「勢いが欲しい」 |
| 雇用の形と条件が、文書になっているか | なっている | これから |
| 中途か業務委託で足りないか | 足りない理由が言える | 中途のほうが早い |

- **五つのうち二つ以上が右なら、新卒ではなく、インターンか業務委託から**：シリーズAで新卒を採ることが珍しい理由は、この五つが揃いにくいから
- **インターンか業務委託で関わってもらい、合った人を新卒として迎える**：事業が変わっても、関わりの中で本人が見ている。入ってから「違った」が減る。[Wantedlyで副業から入ってもらうスカウト設計](/media/wt-scout-fukugyo/)の考え方は、OfferBoxの学生にも同じ
- **採るなら、以下の「最初に決めること」へ**

## 学生が、承認の前に確かめること

- **事業は続くか**：調達の数値ではなく、「何を、誰に、届けて、続いているか」。数値は安心にならない
- **入ったら、何をするか決まっているか**：決まっていないことが多い。決まっていることと決まっていないことを分けて渡す
- **最初の新卒か**：最初なら、教える仕組みがない。知ったうえで来る学生を探す
- **社長と合うか**：この時期は、社長との相性がすべて。社長が面談に出るか、社長の言葉が読めるか
- **事業が変わったら、自分はどうなるか**：ピボットの可能性。隠さず、「変わるときは本人と話す」

### エージェントベストの見解

相談で最も多い思い込みは、「スタートアップに興味のある学生は多いので、シリーズAでも送れば来る」というものです。当社は3媒体すべての販売パートナーとしてOfferBoxの運用代行も受けていますが、「スタートアップ志望」の学生の多くは、メガベンチャーやシリーズの後半の会社を見ていて、シリーズAの会社を「スタートアップ」として選んではいません。シリーズAで承認して面談に来る学生は、「社長と直接働ける」「決まっていないことを自分で決められる」で選ぶ少数で、その少数は、「急成長」「ゼロイチ」の言葉ではなく、「社員は〇名で、あなたが最初の新卒です」の正直な一文で承認します。大きく見せると、スタートアップ志望の学生が来て、面談で規模を知って離れます。当社がシリーズAの文面を作るときは、大きく見せる言葉を全部消し、社長が「なぜ今、新卒か」を自分の言葉で書いた一文だけを残します。

## 最初に決めること

1. **インターンか業務委託で、先に関わってもらう順番にする**：OfferBoxの文面の締めを、インターンの案内にする。[OfferBoxとインターンシップをつなげる設計](/media/ob-intern-setsuzoku/)。関わりの中で合った人に、新卒の話をする
2. **社長が、教える時間を週の予定に固定する**：送る前に。入ってから考えない
3. **決まっていること・いないことを、一枚に分ける**：事業、任せる仕事、誰と組むか、一年後。「決まっていない」を隠さない。書き方は[新規事業を立ち上げる会社のOfferBox運用](/media/ob-shinki-jigyo-unyou/)
4. **名義は、社長**：この時期、社長以外の名義はない。「なぜ今、新卒か」を自分の言葉で。[代表名で送るスカウト文面](/media/kh-bunmen-daihyo/)
5. **送る数を、数通だけに**：社長が向き合える数。「社長と」を選ぶ少数に届けばよい
6. **雇用の形と条件を、文書にしてから送る**：就業規則、雇用契約の形、給与の範囲、休み、保険。専門家の助言を受けて。整うまで送らない
7. **事業が変わる可能性を、隠さず一文で**：「事業の方向は変わることがあります。変わるときは本人と話して決めます」
8. **承認への一次の返信を、外に出す**：社長が事業で返せないなら、型で代行が当日に返す。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)

## 文面の書き方｜大きく見せず、「社長と」「決まっていない」を選ぶ人に

| 書かない | 書く |
|---|---|
| 「急成長中」「シリーズA調達」「ゼロイチ」 | 「社員は〇名です。あなたが最初の新卒です」 |
| 「事業を一緒に作る仲間」 | 決まっていること三つと、決まっていないこと一つ |
| 「圧倒的な裁量」「成長環境」 | 社長の隣で、最初の年に、この仕事を、この順で |
| 「スタートアップで働きたい方へ」 | 「決まっていないことを、自分で決めて進めた経験」を読んで送った、と |
| 調達や見通しの数値 | 数値は書かない。何を誰に届けて続いているか、を事実で |

- **社長が「なぜ今、新卒か」を一文で**：「〇〇を、ゼロから教えて、△△を任せたい」。「勢いが欲しい」は書かない
- **「こんな人」は、「決まっていない環境で動いた行動」で**：「主体性」ではなく、「決まっていないことを自分で決めて進めた」「前提が変わっても続けた」。[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
- **文面の締めを、インターンの案内に**：「まず〇〇のインターンで、一緒に働いてみませんか」
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)

## インターンから新卒へ、の流れ

- **インターンで、事業の実態と社長との相性を、本人が確かめる**：文面と面談では伝えきれないことが、関わりの中で伝わる
- **インターンの扱い（報酬、時間、指揮）は、自社の方針と制度の確認のうえで**：体験と労働の線を引く
- **合った人に、新卒の話をする**：「うちに来ませんか」を、インターンの途中か終わりに。断られても、インターンの経験は本人に残る
- **インターンからの新卒に、内定のあとも社長が向き合う**：[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 新卒を採るべきかの判断（五つの問い） | 社長 |
| 「なぜ今、新卒か」の一行と、決まっていること・いないことの一枚 | 社長 |
| 雇用の形と条件の文書 | 社長（専門家の助言を受けて） |
| 「こんな人」の一行と検索条件 | 社長（型は代行が渡す） |
| 検索、文面の下書き、送信、一次返信 | 代行 |
| 文面の最終確認、名義 | 社長 |
| インターンの受け入れ、面談、内定のあとの連絡 | 社長 |
| 教える時間を予定に固定する | 社長 |

- **この時期は、社長以外に採用に関わる人がいない**：社長の時間を、教える・関わる・決めるに使い、作業は外に。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **費用は、プランの費用と代行の費用**：公式ページと見積もりで確認。予算が取れないなら、今年はインターンだけに。[予算がほぼ取れない会社の採用媒体](/media/hikaku-yosan-nai/)

運用代行や代理店が支えられるのは、五つの問いの型、一枚の型、文面の型、インターンの案内の型、検索・下書き・送信・一次返信までで、採るべきかの判断、一行と一枚の中身、条件の文書、インターンの受け入れ、面談、教えることは企業の社長が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先にインターンか業務委託で関わってもらう順番にしておかないと、シリーズAで新卒をいきなり採るのは、学生にも会社にも無理があります。当社はOfferBoxの運用代行でシリーズAの会社の相談を受けますが、「新卒を採りたい」から始まる相談に、「先にインターンで関わってもらいませんか」と返すと、多くの社長が「その順番があった」と言います。シリーズAは、事業が変わり、社長の時間が足りず、教える仕組みがなく、この三つは文面では隠せず、隠すと入ってから「違った」で辞めます。インターンなら、三つを本人が関わりの中で見て、それでも来たい人が新卒になります。順番は、OfferBoxの文面の締めをインターンの案内にし、関わった人の中から合った一人に新卒の話をすることです。数通で足り、社長の時間は関わることに使えます。採用ではなく、関わりから始めるのが、この時期の新卒採用です。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| いきなり新卒を採る | 事業が変わり、教える時間がなく、一年で辞める | インターンか業務委託から |
| 「スタートアップ志望の学生」を狙う | メガベンチャーを見ている学生が来て、規模を知って離れる | 「社長と」「決まっていない」を選ぶ少数に |
| 「急成長」「ゼロイチ」で大きく見せる | 面談で実態が分かり、離れる | 「〇名です」「最初の新卒です」を最初の一文に |
| 条件を文書にせずに送る | 面談で「決めていない」と答えて離れる | 専門家の助言を受けて整えてから |
| 社長が教える時間を決めずに採る | 入った新卒が放置される | 週の予定に先に固定 |

最も多いのは、一つ目です。「新卒を採る」から始まり、「関わってもらう」の順番がありません。

## まとめ

- シリーズAで新卒を採るのは珍しい。先に五つの問い（社長の時間・一年後・任せたい仕事・条件の文書・中途で足りないか）で判断し、二つ以上が揃わないならインターンか業務委託から
- インターンか業務委託で関わってもらい、事業の実態と社長との相性を本人が見て、合った人を新卒として迎える。OfferBoxの文面の締めをインターンの案内に
- 「スタートアップ志望の学生が来る」と思わない。来るのは「社長と」「決まっていない環境で」を選ぶ少数で、大きく見せると離れる
- 名義は社長。「なぜ今、新卒か」を一文で。決まっていること・いないことを一枚に分け、事業が変わる可能性を隠さない。数通だけ送る
- 雇用の形と条件を専門家の助言を受けて文書にしてから送る。社長の時間は教える・関わる・決めるに使い、作業は外に

## よくある質問

### インターンを受け入れる余裕がありません。それでも新卒を採りたいです

インターンを受け入れる余裕がないなら、新卒を育てる余裕もありません。新卒は、インターンより長く、社長の時間を使います。今年は中途か業務委託で回し、社長の時間が週に固定できる年に、インターンから始めることを勧めます。急いで新卒を採って一年で辞めると、次の新卒がさらに採りにくくなります。

### 「最初の新卒」であることを書くと、承認が減りませんか

減ります。減るのは「スタートアップ志望」で承認する学生で、面談で規模を知って離れる学生です。書いて承認した学生は、「最初の新卒」を知ったうえで来ていて、面談で離れません。数通で足りるこの時期は、承認の数より、「社長と」「決まっていない」を選ぶ一人がいるかが大切です。

### シリーズAのスタートアップのOfferBox運用は、御社に相談できますか

できます。当社は、五つの問いの型、一枚の型、文面の型、インターンの案内の型、検索・下書き・送信・一次返信を支えられます。採るべきかの判断、一行と一枚の中身、条件の文書、インターンの受け入れ、面談、教えることは、企業の社長が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
