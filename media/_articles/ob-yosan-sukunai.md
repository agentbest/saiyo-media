採用の予算が、少ない。OfferBoxを使いたいが、費用を抑えたい。費用を抑えるために期間を短くし、運用は代行に出さず自分でやるつもりが、時間がなくて読まずに送り、結果が出ずに「予算がないから無理だった」となる。**結論から言うと、予算が少ないときに削るのは、費用ではなく「運用の幅」です。職種を一つ、時期を絞り、送る数を読める数に絞ります。自社で運用して人の時間を使い、代行に出さず、外に出すなら型と集計だけにします。代理店経由でも料金は変わらない仕組みを知り、予算の使い方の判断は見積もりと自社の方針で行います。少ない予算の年に残すのは、翌年の元（型・台帳・「こんな人」・現場の協力）です。** この記事では、起きやすい失敗、削るもの、自社運用、外に出すもの、代理店の仕組み、残すもの、上司への説明、分担を整理します。費用の金額そのものは、見積もりと契約で確認してください。定額型と成功報酬型の違いは[定額型と成功報酬型の媒体の違い](/media/hikaku-teigaku-vs-seika/)、代理店経由の料金の仕組みは[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)で書きました。

## この作業の目的｜少ない予算を、「翌年の元」を作ることに使う

予算が少ない年に、その年だけで採用の結果を出そうとすると、無理が出ます。少ない予算の年は、「翌年の元」を作る年と捉えると、使い方が変わります。

目的は、少ない予算で、型と台帳と「こんな人」と現場の協力を残し、翌年に「送る」から始められる状態を作ることです。その年の採用の結果は、出れば良く、出なくても元は残ります。

## 予算が少ないときに、起きやすい失敗

| 失敗 | 何が起きるか |
|---|---|
| 費用を削るために、期間を短くしすぎる | 準備が期間の中に入り、送る時間が消える。[OfferBoxを使える期間が短いときの集中運用](/media/ob-kikan-mijikai/) |
| 代行に出して、自社に何も残らない | 代行の費用がかかり、型も台帳も現場の協力も、自社に残らない |
| 複数の媒体に、薄く分ける | どの媒体も回らず、どの媒体の記録も取れない |
| 「安い経路」だけで組む | 費用は安いが、担当の時間が多く要り、結果として時間が足りない |
| 予算がないから、読まずに数を送る | 「予算がない分、数で」が、読まずに送る形になり、承認が来ない |
| 予算がないから、企業ページを整えない | 承認が来ても、企業ページで止まる |
| 「予算がないから無理だった」で終わる | 記録が残らず、翌年も同じ |

共通するのは、「費用」を削ろうとして「運用」を削っていることです。削るべきは運用の「幅」で、運用の「質」ではありません。

## 削るのは、費用ではなく「運用の幅」

| 削る | 削らない |
|---|---|
| 職種の数（一つに） | 一通あたりの読む時間 |
| 送る時期（集中する時期だけ） | 承認への当日返し |
| 送る数（読める数に） | 面談に現場が出ること |
| 台帳の項目（最小限に） | 企業ページの五つの項目 |
| 見直しの頻度（月に一度） | 「こんな人」の一枚 |
| 複数媒体の併用（一つに） | 型を作ること |

「削らない」の側は、費用がかからず、人の時間だけで作れるものです。予算が少ない会社は、費用の代わりに時間を使います。工数が足りないときの考え方は[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「予算が少ないので、なるべく費用のかからない使い方を教えてほしい」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、費用のかからない使い方を追った会社は、期間を短くし、企業ページを整えず、読まずに数を送り、結果が出ずに翌年は使っていません。逆に、予算が少なくても、職種を一つに絞り、読んで送り、企業ページを整え、面談に現場を出した会社は、承諾が出なくても型と台帳と現場の協力が残り、翌年に「送る」から始めています。予算が少ない年の結果は、承諾の数ではなく、翌年に残ったものです。当社が予算の相談を受けるとき、最初にやるのは、費用を下げる方法の説明ではなく、「この予算で、翌年に何を残しますか」を聞くことです。

## 自社で運用して、人の時間を使う

- **予算が少ないなら、運用は自社で**：代行に出す費用を、人の時間で置き換える
- **人事一人で回る形にする**：[人事1人でOfferBoxを回す方法](/media/ob-hitori-jinji/)
- **週の枠を一つ、承認への対応を朝と夕方の二回、面談は現場の若手一人**
- **時間が足りないなら、送る数を減らす**：時間に合わせて運用を小さくする
- **自社で運用した記録が、翌年の元になる**：代行に出した記録は、代行の側に残る

自社運用と代行の違いは[媒体を自社で運用するか代行に出すかの違い](/media/hikaku-baitai-vs-daikou/)で書きました。予算が少ない年ほど、自社に残す運用が合います。

## 外に出すなら、型と集計だけ

- **外に出してよいもの**：検索条件の設計、文面の型と見本、台帳の集計、見直しの材料の整理、企業ページの整え方の案
- **外に出さないもの**：プロフィールを読んで一文を書く、承認に返す、面談に出る、学生との連絡
- **型と集計は、一度作れば翌年も使える**：外に出す価値がある
- **読んで書くことと面談は、外に出すと自社に残らない**：予算が少ないなら、なおさら自社で

代理店が支えられる範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)、当社の場合は[代理店としてのエージェントベスト](/media/kh-dairiten-agentbest/)で書きました。

## 代理店経由でも、料金は変わらない仕組み

- **代理店経由の申込でも、企業が払う料金は媒体の正規の料金**：代理店の手数料は媒体の側から出る
- **予算が少ないから代理店を通さない、という判断は、費用の面では変わらない**
- **代理店を通す価値は、料金ではなく、型と集計と管理画面の使い方と契約の窓口**
- **見積もりの見方**：行ごとに分け、前提条件を揃え、書かれていないものを足す。[代理店の見積もりの見方](/media/kh-dairiten-mitsumori/)
- **金額や契約の形は、見積もりと契約で確認する**：この記事では扱わない

仕組みの詳しくは[代理店経由でも料金が変わらない理由](/media/kh-dairiten-ryoukin/)で書きました。

## 予算の使い方の判断は、見積もりと自社の方針で

- **予算をOfferBoxに全部使うか、他の経路と分けるかは、自社の方針**：この記事では判断しない
- **分けるなら、薄く分けない**：一つの経路が回る額と時間を確保してから、次を考える
- **予算の使い先を、「費用」と「時間」の両方で見る**：費用が少ない経路は、時間が多く要ることがある。[OfferBoxの採用単価が高く感じるときの見方](/media/ob-tanka-takai/)
- **期間と契約の形の選択肢は、媒体の現在の仕様と見積もりで確認する**
- **予算が少ない年に、成果報酬型を組み合わせるかも、自社の方針で**：[定額型と成功報酬型の媒体の違い](/media/hikaku-teigaku-vs-seika/)

## 少ない予算の年に、残すもの

| 残すもの | なぜ翌年の元になるか |
|---|---|
| 型 | 一つの職種で回った型。翌年、そのまま送れる |
| 台帳 | 段ごとの数と日数。翌年の送る数の逆算に使える |
| 「こんな人」の一枚 | 面接官との合意。翌年に見直す起点 |
| 企業ページ | 「文面の続き」として整ったもの。翌年は更新だけ |
| 現場の協力 | 面談に出た若手一人。翌年に頼みやすい |
| 承認した学生の反応 | 「なぜ承認したか」。翌年の文面の中心 |

これが残っていれば、翌年は準備の時間が要らず、同じ予算でも「送る」から始められます。残っていなければ、翌年も準備から始まり、同じ結果になります。

## 上司への説明

- **「予算が少ないので、その年の承諾の数ではなく、翌年の元を作る年にしたい」と先に伝える**
- **削るもの（職種・時期・送る数）と、削らないもの（読む時間・当日返し・面談・企業ページ）を示す**
- **判断の基準を、「翌年に残ったもの」と「段ごとの止まり」で置く**：[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)
- **費用は、見積もりの行ごとに**：[代理店の見積もりの見方](/media/kh-dairiten-mitsumori/)
- **「予算がないから無理」で終わらせない形を、先に合意する**

## 社内の分担

| 作業 | 誰が |
|---|---|
| 削るもの（職種・時期・送る数）を決める | 人事と責任者 |
| 削らないもの（読む・返す・面談・企業ページ）を守る | 人事と現場 |
| 自社で運用する形（人事一人）を組む | 人事 |
| 外に出すもの（型・集計）を決める | 人事 |
| 見積もりを行ごとに見て、予算の使い先を決める | 責任者と管理部門 |
| 翌年に残すものを書き出す | 人事 |
| 上司に「翌年の元を作る年」と説明する | 人事 |

運用代行や代理店が支えられるのは、削るものと残すものの整理、型と集計、企業ページの整え方の案、見積もりの見方、契約の形の確認までで、予算の判断、読んで書くこと、面談、残すものを作ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。予算が少ない会社から、「費用を抑えるために、代理店で全部やってもらえないか」と相談されることがあります。当社は、読んで書くことと面談を代行しません。それは、予算が少ない会社にとって、最も自社に残すべき部分だからです。当社が持てるのは、型と集計と企業ページの整え方と管理画面の使い方と契約の窓口で、これは一度作れば翌年も使えます。当社が線を引くのは、「予算が少ないから、運用の質を下げる」という方向です。質を下げた運用は、費用が少なくても、翌年に残りません。当社が勧めるのは、幅を削って質を保ち、翌年に残す形で、その形なら、少ない予算でも当社は支えられます。

## まとめ

- 予算が少ないときに削るのは費用ではなく「運用の幅」（職種・時期・送る数・台帳の項目・見直しの頻度・媒体の数）。削らないのは読む時間・当日返し・面談・企業ページ・「こんな人」・型
- 自社で運用して人の時間を使い、代行に出さない。外に出すなら型と集計だけ。読んで書くことと面談は自社に残す
- 代理店経由でも料金は変わらず、価値は型と集計と窓口。金額と契約の形は見積もりと契約で確認し、予算の使い先は自社の方針で
- 少ない予算の年は「翌年の元を作る年」。型・台帳・「こんな人」・企業ページ・現場の協力・承認した学生の反応を残す
- 上司には「その年の承諾ではなく翌年の元」と先に伝え、削るものと削らないものと判断の基準を示す

## よくある質問

### 予算が少なく、期間を短くするしかありません

期間を短くするなら、準備を期間の外で全部済ませ、期間中は送る・返す・面談だけにします。[OfferBoxを使える期間が短いときの集中運用](/media/ob-kikan-mijikai/)で書きました。期間の選択肢は、媒体の現在の仕様と見積もりで確認してください。短い期間でも、型と台帳と現場の協力は残ります。

### 予算が少ないので、複数の媒体を試して比べたいです

薄く分けると、どの媒体も回らず、比べる記録が取れません。一つの媒体が回る額と時間を確保し、その記録で翌年に次を考えるほうが、比べる材料が残ります。比べるなら、年をまたいで、一つずつです。

### 予算が少ない会社の運用は、御社に相談できますか

できます。当社は、削るものと残すものの整理、型と集計、企業ページの整え方の案、見積もりの見方、契約の形の確認を支えられます。予算の判断、読んで書くこと、面談、残すものを作ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
