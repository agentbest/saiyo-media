Wantedlyで学生インターンの募集記事を出したとき、最初にぶつかるのは「『成長できる環境』『裁量を持って働ける』と書いたのに、話を聞きに来る学生が少ない。来ても、面談で『何をやるのですか』『誰が教えてくれますか』『試験の時期は休めますか』『新卒で採ってもらえるのですか』を聞かれて答えられない」という問題です。**結論から言うと、学生インターンの募集記事は、「成長できる環境」ではなく「何を任せ、誰が見て、週に何日どの時間帯で、学業と試験期をどう扱い、新卒採用につなげるのか否か」を書き、募集記事を書く前に社内で任せる仕事を一つに絞り、見る人と両立の扱いと新卒採用との関係を決めておきます。** この記事では、学生が募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。インターン募集記事の型（体験と労働の線引き、有給と無給、受け入れの準備）は[インターン募集記事の書き方](/media/wt-boshu-intern/)で書きました。この記事は、学生を一つの職種として、学生が何を見て、どう選考につなげるかを書きます。

## 学生が募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 何を任されるか | 雑用か、一つの仕事を持てるか。「裁量」の一語では分からない。最初の週に何をするか |
| 誰が見てくれるか | 社員が付くか。質問できる相手がいるか。放置されないか |
| 週に何日、どの時間帯か | 授業のある日に来られるか。夕方からか。土日か。変えられるか |
| 有給か。いくらか | 時給か、無給か。交通費は。数値は確認したものだけ |
| 学業と試験期の扱い | 試験の時期に休めるか。就職活動の時期はどうなるか。「両立を応援」の一語では分からない |
| 新卒採用につながるのか | インターンから新卒で採るのか。採らないのか。決まっていないのか |
| 終わったら何が残るか | 何ができるようになるか。何を自分の経験として話せるか |

「新卒採用につながるのか否か」と「試験期の扱い」が、学生インターンに特有の点です。「成長できる環境」の一語では、ここが分かりません。

## 書く前に決めること｜任せる仕事を一つに、見る人、時間と両立、新卒採用との関係

| 決めること | 選択肢 |
|---|---|
| 任せる仕事 | 一つの仕事（〇〇の記事を書く、△△の問い合わせに答える、□□のデータを整える）。「手伝い全般」にしない |
| 見る人 | 誰が付くか。週に何回、何を確認するか。質問の窓口 |
| 時間 | 週に何日、何時から何時。授業に合わせて変えられるか。土日の有無 |
| 有給か | 時給の有無と額。交通費。数値は確認したものだけ |
| 試験期と就職活動の扱い | 休めるか。減らせるか。「試験の前後は休んで構わない」と書けるか |
| 新卒採用との関係 | つなげる／つなげない／決まっていない。年度の公表内容と自社の方針を確認する |
| 期間 | いつからいつまで。延長の有無 |
| 最初の週に任せること | 一つの作業。誰と組むか |

「無給」「新卒採用にはつなげない」「一人目」でも構いません。隠さずに書けば、それを前提に読む学生が来ます。新卒採用との関係は、年度ごとの公表内容と自社の方針を確認してから書きます。

## 「なにを」｜何を任せ、誰が見るか

「なにをやっているのか」は、会社の事業の説明ではなく、この学生が最初に任される一つの仕事と、見る人に絞ります。

- **任せる仕事を、一つに絞る**：「〇〇の業種向けの記事を、月に△△本書く」「□□の問い合わせに、型に沿って答える」。「幅広く」と書かない
- **最初の週に何をするかを書く**：「最初の週は、△△が書いた記事を読んで、一本を型に沿って書く」
- **見る人を書く**：「〇〇が付く。週に一度、書いたものを一緒に見る。質問は△△で、いつでも」
- **終わったら何が残るかを書く**：「〇〇の期間で、△△が一人でできるようになる。書いたものは自分の経験として話せる」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

同じ学生を採る話でも、新卒として採りたい会社にはWantedlyのインターン募集より先にOfferBoxを勧めることが多いです。理由は、新卒採用は学生が就職活動の時期に一斉に動くので、企業側から学生のプロフィールを読んでオファーを送るOfferBoxのほうが、募集記事を待つより立ち上がりが速いからです。逆に、「新卒採用とは別に、いま手が足りない仕事を学生に任せたい」会社には、Wantedlyの長期インターンの募集が合います。この場合は、募集記事に「新卒採用にはつなげない」または「決まっていない」と正直に書きます。当社は3媒体すべての販売パートナーなので、「学生だからインターン」ではなく、「新卒として採りたいのか、いまの仕事を任せたいのか」で先に分け、前者はOfferBox、後者はWantedlyのインターン募集、という順番で案内しています。新卒向けのオファー文面は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)、インターンの母集団の作り方は[インターンからの母集団形成](/media/kh-boshudan-intern/)で書きました。

## 「どうやって」｜時間と両立と、見る流れの書き方

| 書くこと | 書き方 |
|---|---|
| 時間 | 「週に〇〇日、△△時から□□時。授業に合わせて変えられる。土日は無い」 |
| 試験期と就職活動 | 「試験の前後〇〇週間は休んで構わない。就職活動の時期は、週の日数を減らせる」 |
| 見る流れ | 「毎日の終わりに〇〇に報告。週に一度、△△と一緒に振り返る」 |
| 有給と交通費 | 仕組みだけ。数値は確認したものだけ。無給なら無給と、その理由 |
| 新卒採用との関係 | 「インターンから新卒で採った例がある」「新卒採用は別に行う」「決まっていない」。年度の公表内容を確認して |

「両立を応援」と書くより、「試験の前後は休んで構わない。就職活動の時期は日数を減らせる」と書くほうが、学生には伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経験ではなく、行動で書く

学生は職種の経験が無いので、「経験」で書くと誰も当てはまりません。学生生活の中の行動で書きます。

| 経験で書く（避ける） | 行動で書く |
|---|---|
| 〇〇の経験がある方 | 分からないことを、分からないと言って聞いたことがある |
| 即戦力 | 決めた期限までに、一人で最後まで仕上げたことがある |
| 主体性のある方 | 言われていないことを、自分で見つけてやったことがある（授業、部活、アルバイトで） |
| コミュニケーション能力 | 相手の言っていることを、自分の言葉で言い直して確かめたことがある |
| 成長意欲 | 直された理由を聞いて、次で先に直したことがある |

「分からないことを分からないと言って聞いた」が、学生インターンで最も大事な行動です。学生向けの募集記事の考え方は[新卒向け募集記事の書き方](/media/wt-boshu-shinsotsu/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「何を任せ、誰が見て」と同じ言葉で**：学生のプロフィールの「学んでいること、やってみたこと」を読み、自社の任せる仕事と重ねる。[新卒にスカウトを送るときの考え方](/media/wt-scout-shinsotsu/)
- **面談には、見る人が出る**：付く社員本人が出て、「最初の週に何をするか」を話す。人事だけの面談は、「誰が見てくれるか」に答えられない
- **面談で話すのは、仕事の中身と両立の話**：任せる仕事を実際に見せる、試験期と就職活動の扱いを確認する、新卒採用との関係を隠さず話す
- **学生の側の都合を聞く**：授業、試験、就職活動、他のアルバイト。来られる日を一緒に決める

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 任せる仕事を一つに、見る人、時間と両立、新卒採用との関係を決める | 経営者と、付く社員 |
| 「なにを」（任せる仕事、最初の週、見る人）の下書き | 人事が、付く社員に聞いて書く |
| 「どうやって」（時間、試験期、見る流れ、有給） | 付く社員と人事 |
| 新卒採用との関係の確認 | 経営者（年度の公表内容を確認） |
| 「こんな人」を行動で書く | 付く社員と人事 |
| 面談 | 付く社員と人事 |

一人目の学生インターンを採る募集では、「見る人」の時間が取れるかが要点です。「付く社員は〇〇。週に△△時間を学生のために使う」と社内で決め、決まらないなら、募集を出しません。

運用代行や代理店が支えられるのは、募集記事の型、両立と新卒採用との関係を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、任せる仕事の決定、見る人の時間、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「学生インターンには『成長できる』『裁量がある』と書けば来る」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの学生インターンの募集と面談を見ていますが、「成長」「裁量」と書いた募集記事より、「〇〇の記事を月に△△本書く。□□が付いて週に一度一緒に見る。試験の前後は休んで構わない。新卒採用は別に行う」と実態を書いた募集記事のほうが、話を聞きに来る学生が続き、始めてから離れる学生が少ない傾向があります。学生は、「成長」「裁量」を読んでも何をするか分からず、「試験期に休めるか」「新卒で採ってもらえるか」が書かれていないと、聞きにくいまま離れます。任せる仕事と見る人と試験期の扱いと新卒採用との関係が書かれていれば、「自分の都合を分かっている会社」として読まれます。当社が案内するのは、「成長」「裁量」を消し、任せる仕事を一つ、見る人、試験期の扱い、新卒採用との関係を、隠さず書くことです。成長の言葉で学生は来ません。都合が書かれていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「成長できる環境」「裁量」で書く | 何をするか分からず、読まれない | 任せる仕事を一つ、最初の週に何をするかを書く |
| 見る人を書かない | 「放置される」を想像される | 誰が付き、週に何回見るかを書く |
| 試験期と就職活動の扱いを書かない | 聞きにくいまま離れる | 休めるか、減らせるかを書く |
| 新卒採用との関係を盛る | 「採ってもらえる」と思って来て、離れる | つなげるか、つなげないか、決まっていないかを書く |
| 経験で「こんな人」を書く | 学生は誰も当てはまらない | 学生生活の行動で書く |
| 面談に付く社員が出ない | 「誰が見てくれるか」に答えられない | 付く社員が出て、最初の週の仕事を見せる |

最も多いのは、「成長できる環境」と、新卒採用との関係の抜けです。

## まとめ

- 学生が見ているのは、何を任されるか・誰が見てくれるか・週に何日どの時間帯か・有給か・試験期と就職活動の扱い・新卒採用につながるのか・同じ学生がいるか・終わったら何が残るか
- 書く前に、任せる仕事を一つに絞り、見る人と週に使う時間、時間帯、試験期の扱い、新卒採用との関係（年度の公表内容を確認）を決める。無給でも、つなげなくても、隠さない
- 「なにを」は任せる仕事一つと最初の週と見る人と終わったら残るもの。「どうやって」は時間と試験期の扱いと見る流れと有給を、実態で
- 「こんな人」は経験ではなく、「分からないことを分からないと言って聞いた」「期限までに一人で仕上げた」の学生生活の行動で
- 面談には付く社員が出て、最初の週の仕事を見せ、試験期と新卒採用との関係を隠さず話す。新卒として採りたいなら、先にOfferBoxを検討する

## よくある質問

### インターンから新卒で採りたいのですが、募集記事にそう書いてよいですか

自社の方針と、年度ごとの公表内容を確認してから書きます。書けるなら、「インターンから新卒で採った例がある。ただし、インターンをしたから採るわけではなく、選考は別に行う」のように、つながる可能性と、選考が別であることを両方書きます。「インターンをすれば新卒で採る」と読める書き方は、学生が「採ってもらえる」と思って来て、離れます。新卒として採ることが主目的なら、先にOfferBoxを検討します。

### 無給のインターンです。書くと来ませんか

無給なら無給と、その理由を書きます。「無給。任せるのは〇〇で、△△が付いて教える。交通費は出す。有給に変えるかは、□□の時期に見直す」のように、無給であることと、代わりに何があるかと、見直す時期を書きます。体験と労働の線引きは[インターン募集記事の書き方](/media/wt-boshu-intern/)で書きました。

### 学生インターンの募集記事は、御社に相談できますか

できます。当社は、募集記事の型、両立と新卒採用との関係を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。任せる仕事の決定、見る人の時間、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、新卒として採りたいのか、いまの仕事を任せたいのかで媒体を分けるところから案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
