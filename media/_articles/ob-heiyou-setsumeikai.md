合同説明会に出展していて、OfferBoxも使っている。合同説明会で多くの学生に会えるのに、そのあとに続かない。OfferBoxで承認した学生と、合同説明会で会った学生を、別々に追っていて、同じ学生に二度連絡したことがある。**結論から言うと、合同説明会は「決まった日に、会社を知らない学生に会う場」、OfferBoxは「企業が選んで送り、会う前に興味を持ってもらう場」です。併用するなら、合同説明会で会った学生への連絡とOfferBoxの送信を一本の台帳で持ち、ブースで話す社員を文面の名義にし、合同説明会の前後に送る時期を置き、名簿の数を母集団と読まないことです。** この記事では、それぞれの役割、来る学生の状態、台帳、ブースの社員と文面の名義、時期の設計、名簿の数の読み方、時間と費用、やりがちな失敗、社内の分担を整理します。イベントからの母集団形成は[イベントからの母集団形成](/media/kh-boshudan-event/)、イベント型と掲載型の違いは[イベント型と掲載型の違い](/media/hikaku-event-vs-keisai/)で書きました。数値は書きません。

## それぞれの役割｜「決まった日に会う」と「選んで送って会う」

| | 合同説明会 | OfferBox |
|---|---|---|
| 学生が来る理由 | 就職活動で、会社を知るために回る。業界や配置でブースを選ぶ | 企業が選んで送ったから。文面と送ってきた人に興味を持った |
| 学生の状態 | 会社を知らない。多くの会社を並べて回っている。名簿に書いても、覚えていないことが多い | 「自分に来た」と感じている。会社を知らないが、文面は読んでいる |
| 選ぶのは誰か | 学生。ブースに来るかどうか | 企業。検索の条件で選ぶ |
| 時期 | 決まった日。当日に集中 | 送る時期は企業が決める |
| 会社が出すもの | ブース、話す社員、当日の説明、名簿 | 検索条件、文面、送る社員の名義 |
| 残るもの | 名簿と、会った社員の記憶 | 検索条件と文面の型。送る社員の名義 |

合同説明会で会った学生は、会社を並べて見ている状態で、ブースを離れた瞬間から次の会社に頭が移ります。OfferBoxで承認した学生は、文面を読んで「自分に来た」と感じた状態で、次に何があるかを待っています。同じ「会った」でも、その後に続く力が違います。

## 会った学生への連絡と、送信を一本にする台帳

- **合同説明会の名簿を、送る側の台帳に入れる**：会った日、話した社員、学生が話したこと（一言）
- **名簿の学生がOfferBoxに登録していても、検索で見つけて「初めまして」の文面を送らない**：「ブースで会ったのに、初めましてと来た」で印象が下がる
- **名簿の学生には、合同説明会の連絡先から、会った社員の名前で連絡する**：「〇〇のブースでお話しした△△です」。この連絡は、OfferBoxの文面ではなく、合同説明会の流れ
- **合同説明会で会っていない学生に、OfferBoxで送る**：送る前に名簿と突き合わせる
- **台帳は一つ。入口の列に「合同説明会（イベント名・話した社員）」と「OfferBox」**：面談から先は共通の段
- **両方に該当する学生は、最初の入口を合同説明会にし、連絡は一本に**

送る側の台帳と来た学生の台帳の分け方は[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)で書きました。突き合わせは、送る前に一度、合同説明会のあとに一度です。

### エージェントベストの見解

合同説明会の名簿の数は、「ブースに立ち寄った学生の数」を示す数字で、「会社に興味を持った学生の数」ではありません。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、合同説明会のあとに「名簿が多く集まったので、OfferBoxは減らしてよいか」という相談を受けますが、名簿の学生の多くは、会社を並べて回る途中で立ち寄っただけで、ブースを離れたあとに会社名を覚えていません。名簿は「会った数」、承認は「自分に来たと感じた数」で、動く理由が違います。当社が見るのは、名簿の学生のうち、当日から数日以内の連絡に返事をした学生の数と、OfferBoxで承認した学生のうち、面談まで来た学生の数です。この二つで見ると、合同説明会は「会う」場で、OfferBoxは「続く」場だと分かります。名簿の数で送る数を減らすと、続く学生を減らすことになります。

## ブースで話す社員と、文面の名義を同じ人に

- **ブースに立つ社員を、OfferBoxの文面の名義にする**：合同説明会で会っていない学生にも、「この人が話す会社」として文面が届く。合同説明会で会った学生は、名簿の流れで
- **ブースで話す内容と、文面の「最初の年」を揃える**：当日に話したことと、文面に書いてあることがずれない
- **当日、学生が聞いてきたことを、文面の場面に落とす**：合同説明会は、学生が何を知りたいかを聞ける場。「〇〇について聞かれた」を、文面の一文にする
- **ブースで話す社員が、面談にも出る**：合同説明会で会った学生も、OfferBoxで承認した学生も、同じ人に会う
- **社員に頼むことは三つに絞る**：ブースに立つ、名義を貸す、面談に出る。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)

## 合同説明会の前後に、送る時期を置く

| 時期 | すること |
|---|---|
| 合同説明会の前 | 「こんな人」の一行と検索条件、文面の型を作る。ブースに立つ社員を名義に。会社名を知った学生が承認しやすいよう、当日の前に送る時期を一つ |
| 当日 | 会う。名簿に一言を残す。学生が聞いてきたことを記録する |
| 当日から数日 | 名簿の学生に、会った社員の名前で連絡する。OfferBoxの送信は止めない |
| 合同説明会のあと | 名簿と突き合わせて、会っていない学生に送る時期をもう一つ。当日に聞かれたことを文面に反映 |

- **当日と送る時期を重ねない**：ブースの準備と当日で人事の時間が消え、承認への当日返信が遅れる。送る時期は当日の前後にずらす。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
- **名簿への連絡を、当日から数日以内に**：遅れると、学生は会社名を思い出せない
- **合同説明会が終わったことで、送るのも止めない**：合同説明会は「会う日」で、「送る時期の終わり」ではない

## 時間と費用の配分

| 項目 | 合同説明会 | OfferBox |
|---|---|---|
| 費用 | 出展の費用。主催者ごとに条件が違う。この記事では書かない | プランの費用。公式ページで確認 |
| 時間の性格 | 準備と当日に集中。ブースに立つ社員の一日 | 送る時期に集中。検索・文面・送信・当日返信・面談 |
| 外に出せる部分 | ブースの設営、名簿への一次の連絡の下書き | 検索、文面の下書き、送信、一次の返信 |
| 残る資産 | 名簿、当日に聞かれたこと、話す社員の経験 | 検索条件と文面の型 |

- **ブースに立つ社員の時間と、面談に出る時間を、同じ社員で合わせる**：二人分を一人分に
- **当日に聞かれたことを記録する担当を、当日に置く**：翌年の文面の元
- **費用は、各媒体の現在の条件を確認してから置く**：配分は[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 名簿の学生に「初めまして」の文面を送る | 「ブースで会ったのに」で印象が下がる | 名簿の流れで、会った社員の名前で連絡 |
| 名簿の数で送る数を減らす | 続く学生が減る | 名簿は「会った数」。承認と並べない |
| 当日と送る時期を重ねる | 承認への返信が遅れる | 前後にずらす |
| 名簿への連絡が遅れる | 学生が会社名を思い出せない | 当日から数日以内に |
| ブースの社員と文面の名義が違う | 会った学生と送られた学生で、会社の顔が違う | 同じ人に |

最も多いのは、一つ目です。名簿の突き合わせをせずに送り、ブースで話した学生に「初めまして」が届きます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「こんな人」の一行と検索条件、文面の型 | 人事と現場の責任者 |
| ブースに立つ、名義を貸す、面談に出る | 現場の社員 |
| 名簿を送る側の台帳に入れ、突き合わせる | 人事（代行に出しているなら代行と） |
| 名簿の学生への連絡（会った社員の名前で） | 人事が下書き、社員が確認 |
| 会っていない学生への送信 | 人事、または代行 |
| 当日に聞かれたことを記録し、文面に反映 | 人事 |
| 面談で「何を見て来たか」を聞く | 面談に出る人 |
| 出展するかと、送る時期の判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、台帳と突き合わせの型、名簿への連絡の下書き、当日に聞かれたことを文面に落とす作業、OfferBoxの送る時期の代行までで、「こんな人」の決定、ブースに立つこと、面談、出展の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。合同説明会とOfferBoxを併用するとき、自社で持つべきなのは、ブースに立って話すこと、名簿の学生への連絡の名義、面談、「こんな人」の決定、までです。ここから先の、名簿を台帳に入れて突き合わせる作業、名簿への連絡の下書き、当日に聞かれたことを文面に落とす作業、会っていない学生への検索と送信は、外に出せます。当社がOfferBoxの運用代行を受けている会社で合同説明会に出るときは、名簿を当日の翌日に受け取り、送る側の台帳と突き合わせてから、会っていない学生に送る形にしています。この線を引かずに、「合同説明会は人事、OfferBoxは代行」と入口で分けると、同じ学生に二つの経路から連絡が行きます。分けるのは入口ではなく、「話す・会う・決める」と「台帳・下書き・送信」です。

## まとめ

- 合同説明会は「決まった日に、会社を知らない学生に会う場」、OfferBoxは「選んで送り、会う前に興味を持ってもらう場」。会ったあとに続く力が違う
- 名簿を送る側の台帳に入れ、送る前に突き合わせる。名簿の学生には会った社員の名前で、合同説明会の流れで連絡する。「初めまして」の文面を送らない
- ブースに立つ社員を文面の名義にし、話す内容と「最初の年」を揃える。当日に聞かれたことを文面の場面に
- 当日と送る時期を重ねず、前後に置く。名簿への連絡は当日から数日以内に。合同説明会が終わっても送るのを止めない
- 名簿の数は「会った数」で、承認数と並べない。見るのは、連絡に返事をした学生と、面談まで来た学生の数

## よくある質問

### 合同説明会で会った学生に、OfferBoxで送ってはいけませんか

「初めまして」の文面は送りません。会った社員の名前で、「ブースでお話しした」から始まる連絡を、合同説明会の連絡先から行います。OfferBoxで見つけた場合も、文面の書き出しを「ブースでお話しした」にできるなら別ですが、貼れる形や送れる相手の範囲は現在の仕様で確認してください。大切なのは、経路より、「会ったことを覚えている会社」として届くことです。

### 合同説明会の名簿が多く、全員に連絡する時間がありません

全員に同じ連絡を送るより、名簿の一言（学生が話したこと）を見て、「こんな人」に近い学生から順に、会った社員の名前で連絡します。残りには、人事から短い一報を。連絡の下書きは外に出せますが、名義は会った社員のままにします。

### OfferBoxと合同説明会の併用は、御社に相談できますか

できます。当社は、役割の整理、台帳と突き合わせの型、名簿への連絡の下書き、当日に聞かれたことを文面に落とす作業、OfferBoxの送る時期の代行を支えられます。「こんな人」の決定、ブースに立つこと、面談、出展の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
