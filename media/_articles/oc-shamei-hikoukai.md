ワンキャリアの社名非公開イベント。社名を先に出さずに学生を集める形と聞いて、知名度のない自社に向くのではと思う。ところが、「社名を隠せば来る」と思って中身は通常の説明会のまま、明かした瞬間の落差が大きく、明かした後の導線がなく、来た学生が離れる。**結論から言うと、社名非公開イベントは、社名を先に出さず、業界・職種・テーマで学生を集め、回の中で会社を明かす形です。「体験談を読んで来る」流れとは別の入口で、社名で流される会社・社名の先入観が強い会社・体験談がまだない会社に向き、社名で選ばれている会社・社名を明かした瞬間に離れる理由がある会社には向きません。開催の形と条件は、管理画面とヘルプで確認してください。** この記事では、社名非公開で起きる失敗、通常のイベントとの違い、向く会社と向かない会社、明かす前と後で学生が見ていること、落差を小さくすること、明かした後の導線、分担を整理します。イベントの種類は[ワンキャリアのイベントの種類と使い分け](/media/oc-event-kihon/)、準備は[ワンキャリアの社名非公開イベントの準備](/media/oc-shamei-hikoukai-junbi/)、話すことは[ワンキャリアの社名非公開イベントで話すこと](/media/oc-shamei-hikoukai-touitsu/)で書きました。

## この作業の目的｜「社名を出さない」ことの意味を、自社に当てはめて判断する

社名非公開イベントの価値は、「社名で流される前に、仕事と会社の中身を聞いてもらえる」ことです。その価値がある会社と、ない会社があります。社名を出しても流されない会社には、この形の価値はなく、通常のイベントのほうが体験談を読んだ学生に届きます。

目的は、「社名を出さないと、何が変わるか」を自社に当てはめ、向くかどうかを先に判断することです。

## 社名非公開で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 「社名を隠せば来る」と思う | 来る理由は社名ではなくテーマ。テーマが弱ければ、社名を隠しても来ない |
| 明かした後の落差が、大きい | テーマで集めて、明かした会社の中身がテーマと離れていると、「釣られた」と読まれる |
| 通常のイベントと、同じ中身で開く | 社名を出さないのに会社の説明から入り、「何の会社か」で時間が消える |
| 明かした後の導線が、ない | 明かした後に読む企業ページ、次の場が用意されておらず、そこで終わる |
| 「社名非公開だから」を、言い訳にする | 「社名を出せないから来なかった」と、テーマと中身を直さない |
| 向かない会社が、使う | 社名で選ばれている会社が使うと、社名を出したときの強みを捨てる |

共通するのは、社名非公開を「集客の仕掛け」として見て、「別の入口」として見ていないことです。

## 通常のイベントとの、違い

| | 通常のイベント | 社名非公開イベント |
|---|---|---|
| 入口 | 体験談・企業ページを読んで、その会社の回に来る | 業界・職種・テーマで来る。会社は知らない |
| 来る学生 | その会社に関心がある人 | そのテーマに関心がある人。社名の先入観がない |
| 確かめられること | 体験談で気になったこと | テーマの中身と、明かされた会社が「テーマに合っているか」 |
| 回の中身 | 体験談に答える | テーマを先に、会社を後に。会社の説明は短く |
| 回の後 | 企業ページと次の場へ | 明かした会社の企業ページと体験談を読みに行く。その導線が要る |

社名非公開イベントは、「体験談を読んで来る」ワンキャリアの主な流れとは別の入口です。開催の形・掲載の条件・社名を明かす時期は、現在の仕様を管理画面とヘルプで確認してください。

### エージェントベストの見解

相談で最も多い思い込みは、「知名度がない会社は、社名非公開のほうが人が集まる」というものです。当社はワンキャリアの販売パートナーとして、社名非公開イベントの相談を受けていますが、知名度がないことと、社名で流されることは別です。知名度がなくても、社名を出したときに「知らない会社だが、仕事の中身を読んで来た」という学生が企業ページから来ているなら、通常のイベントで届いていて、社名非公開に変える理由はありません。逆に、業界や社名の響きで「自分には関係ない」と流されている（企業ページの閲覧が少なく、来た学生も業界の先入観を持っている）会社は、社名を先に出さないことで、テーマで聞いてもらえます。当社が社名非公開の相談を受けるとき、最初にやるのは、「社名を出したときに、学生はどこで離れていますか」を確かめることです。

## 向く会社と、向かない会社

| 向く | 向かない |
|---|---|
| 社名や業界の響きで、「自分には関係ない」と流される | 社名で選ばれている。社名を出すほうが来る |
| 社名に、実際の仕事と違う先入観がある | 社名と仕事の中身が、学生の想像どおり |
| 体験談がまだなく、「体験談を読んで来る」流れが使えない | 体験談が多く、その流れで来ている |
| テーマ（職種・仕事の場面・業界の中身）で、話せることがある | 話せるのが会社の説明だけ |
| 明かした後に、企業ページと次の場が整っている | 明かした後の導線がない |
| 明かした瞬間に、離れる理由がない | 明かした瞬間に離れる理由（条件・立地・業界の評判）があり、それを回で解けない |

向かない会社が使うと、社名を出したときの強み（体験談・知られ方）を使わず、テーマだけで集めて明かした後に落ちます。知名度の考え方は[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)と[知名度がない会社の母集団形成](/media/kh-boshudan-chimeido/)で書きました。

## 社名を明かす前と後で、学生が見ていること

- **明かす前**：テーマが自分に関係あるか、話している人が仕事を分かっているか、聞く価値があるか
- **明かす瞬間**：「この会社だったのか」。先入観があれば、ここで出る
- **明かした後**：テーマで聞いたことと、明かされた会社が合っているか。企業ページと体験談で確かめに行く
- **回の後**：企業ページに、回で聞いたことが書かれているか。次の場があるか
- **明かす前の話が、明かした後の評価を決める**：テーマの話が薄いと、明かしても関心が続かない

## 明かした後の落差を、小さくする

- **テーマと、会社の中身を、先に揃える**：テーマで話したことが、そのまま自社の仕事の場面である
- **「実は」の演出をしない**：驚かせる形は、落差を大きくする。明かすのは事実として淡々と
- **先入観に、明かした直後に答える**：「〇〇と思われることが多いが、実際は〇〇」を、聞かれる前に
- **明かした後の時間を、確保する**：明かして終わりにしない。質問の時間を明かした後に長く
- **落差の小ささが、翌年の体験談になる**：「テーマで聞いて、明かされて、そのとおりだった」

## 明かした後の、導線

- **企業ページ**：回で話したテーマが、企業ページの最初で読める。[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)
- **体験談**：体験談があるなら、回の中身と揃っている。ないなら、「体験談はまだないが、選考の流れはこう」と企業ページに
- **次の場**：明かした後に、通常のイベント（少人数の相談会・座談会）か面談へ。当日に申し込める形
- **回の後の一通**：当日か翌日に、明かした会社の名前で、回で話したテーマの続きと次の場
- **導線がなければ、開かない**：明かした後に読むものがないと、そこで終わる

### エージェントベストの見解

これは向き不向きの話です。当社はワンキャリアの販売パートナーで、社名非公開イベントも通常のイベントも扱いますが、社名非公開を勧めるのは、「社名を出したときに、学生がどこで離れているか」が分かっていて、それが「社名や業界の先入観」である会社だけです。離れている場所が、企業ページの中身や、選考の流れや、返信の速さなら、社名を隠しても同じ場所で離れます。社名非公開は、先入観で聞いてもらえない会社が、テーマで聞いてもらうための入口で、聞いてもらった後の中身が薄ければ、明かした後に落ちます。当社は、社名非公開の相談で、先に「社名を出した回の記録」を見せてもらい、離れている場所を確かめてから、向くかを一緒に判断します。

## まとめ

- 社名非公開イベントは、社名を先に出さず、業界・職種・テーマで集め、回の中で会社を明かす形。「体験談を読んで来る」流れとは別の入口。開催の形と条件は管理画面とヘルプで確認
- 向くのは、社名や業界の響きで流される・社名に仕事と違う先入観がある・体験談がまだない・テーマで話せる・明かした後の導線が整っている会社。社名で選ばれている会社、明かした瞬間に離れる理由を回で解けない会社には向かない
- 「社名を隠せば来る」ではなく、来る理由はテーマ。テーマと会社の中身を先に揃え、「実は」の演出をせず、先入観に明かした直後に答え、明かした後の質問の時間を長く
- 明かした後の導線（企業ページ・体験談・次の場・回の後の一通）がなければ、開かない
- 明かす前の話が明かした後の評価を決め、落差の小ささが翌年の体験談になる

## よくある質問

### 社名非公開にすると、来た学生の質が下がりませんか

来る学生は「テーマに関心がある人」で、「社名に関心がある人」ではありません。テーマが自社の仕事の場面と揃っていれば、テーマで来た学生は「こんな人」に近いことが多く、質は下がりません。テーマが広く（「成長したい人集まれ」など）、自社の仕事と離れていれば、遠い人が来ます。質は社名の有無ではなく、テーマの絞り方で決まります。テーマの決め方は[ワンキャリアの社名非公開イベントの準備](/media/oc-shamei-hikoukai-junbi/)で書きました。

### 明かした瞬間に、参加者が減ることはありますか

先入観があれば、あります。減った人は、社名を出した通常の回には最初から来なかった人で、社名非公開で「テーマの話は聞いてもらえた」分だけ、接点が一つ増えています。減らないようにするのは、明かす前のテーマの話を自社の仕事の場面で厚くし、明かした直後に先入観に答えることです。減った数より、「明かした後に残って質問した人」の数と近さを見ます。

### 社名非公開イベントが自社に向くかは、御社に相談できますか

できます。当社は、向き不向きの整理、テーマと会社の中身の揃え方の型、明かした後の導線の型、企業ページの型を支えられます。向くかの判断、テーマの決定、回に出ること、明かすこと、質問に答えることは、企業が行ってください。開催の形・掲載の条件・社名を明かす時期は管理画面とヘルプで確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
