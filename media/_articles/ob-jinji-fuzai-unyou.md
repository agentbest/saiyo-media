専任の人事がいない。採用は社長か、総務か、現場の責任者が本業の合間に見ている。OfferBoxは「人事がいる会社のもの」と感じて、申し込んでも、管理画面の通知を誰も見ておらず、承認が数日放置されて、承認した学生が他社に決まる。**結論から言うと、OfferBoxに要るのは専任の人事ではなく、「通知を受ける窓口の一人」と「面談に出る人」です。最初に決めるのは、窓口を一人に決めること、承認への当日返信を外に出すこと、名義を社長か現場責任者にすること、「こんな人」を社長と現場で一行にすること、送る数を面談に出られる数で絞ること、台帳を一枚で持つことです。専任の人事がいない会社は、外に出せる作業が最も広い会社で、要るのは判断と面談だけです。** この記事では、専任の人事がいない会社が割ける時間と人、最初に決めること、外に出す範囲、運用の分担、やりがちな失敗を整理します。人事が一人いる会社の運用は[人事が1人の会社のOfferBox運用](/media/ob-jinji-hitori-unyou/)、兼務の担当者が回せる媒体の考え方は[人事兼務の担当者が回せる採用媒体](/media/hikaku-jinji-kenmu/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 採用を見ているのが社長、総務、現場の責任者のどれか | 誰が「窓口」かが決まっておらず、通知を誰も見ない |
| 時間が細切れで、本業の波に取られる | 送る週は送れても、承認が来た日に返せない |
| 検索と文面を書く時間がない | 文面が会社紹介の貼り付けになり、承認されない |
| 面談に出られるのは社長か現場責任者 | 面談の枠が少ない。送る数の上限が小さい |
| 採用の経験が社内にない | 「こんな人」が「いい人」のまま。承認後に何をするかが決まっていない |
| 台帳がない | 誰に送って誰が承認したかが、管理画面の中にしかない |

専任の人事がいない会社がOfferBoxに割ける時間は、「本業の合間の細切れ」です。細切れの時間でできるのは、通知を見て一言返すことと、面談に出ることまでで、検索して文面を書く時間は、まとまって取れません。この前提で、まとまった時間が要る作業を外に出し、細切れでできることだけを社内に残します。

## 最初に決めること

1. **通知を受ける窓口を、一人に決める**：社長か、総務か、現場責任者か。管理画面の通知が届く先を一つに。二人にすると、互いに「見ていると思った」になる
2. **承認への当日返信を、外に出す**：窓口が細切れの時間で返せないなら、一次の返信は運用代行に。窓口は「返した」の確認と、面談の日程の判断だけ。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
3. **名義は、社長か現場責任者**：面談に出る人の名義で送る。「採用担当」の名義は、会えない人の名義になる
4. **「こんな人」を、社長と現場で一行にする**：「いい人」ではなく、「〇〇の仕事の中身で選ぶ、△△を自分で始めた経験のある学生」。この一行が、検索条件と文面の元。[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
5. **送る数を、面談に出られる数で絞る**：社長が月に何人と会えるか。その数から、承認の割合を昨年の経験で置いて逆算。経験がないなら、小さく送って様子を見る
6. **台帳を、一枚で持つ**：誰に、いつ、承認したか、返したか、面談の日、結果。表計算の一枚で足りる。管理画面の中だけに置かない

### エージェントベストの見解

相談で最も多い思い込みは、「専任の人事がいないので、OfferBoxのようなスカウト型は無理だ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けていますが、専任の人事がいない会社は、OfferBoxに向かない会社ではなく、外に出せる作業が最も広い会社です。検索、文面の下書き、送信、承認への一次の返信、台帳の更新は、当社が持てます。当社が持てないのは、「こんな人」を決めること、文面の最終確認、面談に出ることの三つで、この三つは社長か現場責任者にしかできず、時間も細切れで足ります。人事がいる会社では、人事が作業と判断の両方を持つので、作業に時間が消えて判断が薄くなることがありますが、人事がいない会社は、最初から作業を外に出す前提で組めるので、社長の時間が判断と面談だけに使えます。無理なのは、専任の人事がいないことではなく、窓口を決めずに始めることです。

## 外に出す範囲｜専任の人事がいない会社は、最も広い

| 作業 | 社内（窓口・社長・現場責任者） | 外（運用代行） |
|---|---|---|
| 「こんな人」の一行 | 決める | 型を渡す |
| 検索と、送る相手の選定 | 一次の候補を確認する | 検索し、候補を出す |
| 文面の下書き | 最終確認する（名義の本人） | 下書きする |
| 送信 | — | 送る |
| 承認への当日の返信 | 面談の日程を判断する | 一次の返信をする |
| 面談前の連絡 | — | 送る。[OfferBoxの面談前の連絡で辞退を減らす方法](/media/ob-mendan-mae-renraku/) |
| 面談 | 出る | — |
| 台帳の更新 | 結果を伝える | 更新する |
| 週に一度の報告 | 見る | まとめる |

- **社内に残るのは、決める・確認する・会う、の三つ**：どれも細切れの時間でできる
- **外に出す範囲を、申込の前に決める**：申し込んでから「誰がやるか」を考えると、通知が放置される。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **費用は、プランの費用と代行の費用**：公式ページと見積もりで確認。この記事では数値を書かない。予算が少ないときは[予算が少ない会社のOfferBoxの使い方](/media/ob-yosan-sukunai/)

## 窓口の一人が、細切れの時間ですること

- **朝に一度、管理画面の通知と、代行からの連絡を見る**：数分。承認が来ていれば、面談の日程の候補を返す
- **面談の枠を、自分の予定に先に入れておく**：「この曜日のこの時間は面談」と決めておくと、日程の判断が一瞬で終わる
- **文面の最終確認は、週に一度まとめて**：下書きを読んで、「自分の言葉として送れるか」だけを見る
- **面談のあとに、結果を一言で台帳の担当に伝える**：「近い・遠い」と、次に進めるか
- **本業の波で見られない週は、先に代行に伝える**：「今週は面談の日程を返せない」と分かっていれば、承認した学生に「来週にご連絡します」と一次で返せる

窓口の時間は、週に合計で短くて足ります。要るのは長さではなく、「毎朝一度見る」の習慣です。

## 運用の分担

| 作業 | 誰が |
|---|---|
| 窓口を決める | 社長 |
| 「こんな人」の一行 | 社長と現場責任者 |
| 検索、文面の下書き、送信、一次返信、面談前連絡、台帳の更新 | 運用代行 |
| 文面の最終確認、名義 | 社長か現場責任者（名義の本人） |
| 面談の日程の判断、面談 | 社長か現場責任者 |
| 週に一度の報告を見る | 窓口 |
| 内定のあとの連絡 | 社長。型は代行が渡す。[OfferBoxの内定者フォロー](/media/ob-naitei-follow/) |

- **窓口と面談に出る人は、同じ人でよい**：社長が窓口で、社長が面談に出る。会社が小さいなら、この形が最も止まらない
- **現場責任者を名義にするなら、頼むことを三つに絞る**：名義、文面の最終確認、面談。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
- **代行に出しても、「こんな人」と面談は出さない**：ここを出すと、誰を採るかを外の人が決めることになる

運用代行や代理店が支えられるのは、上の表の「運用代行」の行の全部と、台帳の型、週の報告の型までで、窓口の決定、「こんな人」の決定、文面の最終確認、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。専任の人事がいない会社で、社内に残すべきなのは、「こんな人」の一行、文面の最終確認、面談の日程の判断、面談、の四つだけです。ここから先の、検索、下書き、送信、一次返信、面談前の連絡、台帳の更新、週の報告は、外に出せます。当社が専任の人事がいない会社の運用代行を受けるときは、社長を窓口にして、毎朝一度、当社からの連絡を見てもらう形にしています。社長の時間は、週に合計で短く、ほとんどが面談です。この線を引かずに、「人事がいないので、社長が全部やる」とすると、検索と文面に社長の時間が消えて、承認が来た日に返せません。逆に、「全部任せる」として面談まで代わりの人を出すと、学生は「社長の名義で来たのに社長に会えない」で離れます。出すのは作業、残すのは会うこと。この線が、専任の人事がいない会社で最も止まらない形です。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 窓口を決めずに申し込む | 通知を誰も見ず、承認が放置される | 窓口を一人に |
| 「採用担当」の名義で送る | 会えない人の名義になり、承認されない | 面談に出る人の名義 |
| 社長が検索と文面まで持つ | 時間が消えて、承認に返せない | 検索と下書きを外に |
| 「いい人」のまま送る | 検索条件が決まらず、文面が会社紹介になる | 一行を社長と現場で |
| 台帳を管理画面の中だけに置く | 誰に送って誰が承認したかが、社内に残らない | 表計算の一枚 |

最も多いのは、一つ目です。申し込んだことで始めた気になり、通知を見る人が決まっていません。

## まとめ

- 専任の人事がいなくてもOfferBoxは回る。要るのは「通知を受ける窓口の一人」と「面談に出る人」で、同じ人でよい
- 最初に、窓口を一人に決め、承認への当日返信を外に出し、名義を社長か現場責任者にし、「こんな人」を一行にし、送る数を面談に出られる数で絞り、台帳を一枚で持つ
- 専任の人事がいない会社は、外に出せる作業が最も広い会社。社内に残すのは、決める・確認する・会う、の三つ
- 窓口の時間は細切れで足りる。毎朝一度、通知と代行の連絡を見て、面談の枠を先に予定に入れておく
- 外に出すのは作業、残すのは会うこと。「社長が全部やる」も「全部任せる」も止まる

## よくある質問

### 社長が窓口になると、面談も社長です。負担が大きくありませんか

送る数を、社長が月に会える数から逆算すれば、負担は面談の数で決まります。少なく送って、承認した学生には社長が会う形のほうが、多く送って誰も会えない形より、採用に近づきます。社長が会えない月は、先に代行に伝えて、送る数を減らします。

### 総務の担当者が窓口になれますか。面談は現場責任者に出てもらいたいです

なれます。その場合、名義は現場責任者にし、総務は通知を見て代行と連絡を取る役、現場責任者は文面の最終確認と面談だけ、という三つの役に分けます。総務が面談の日程を、現場責任者の予定に先に入れておくと、判断が止まりません。

### 専任の人事がいない会社のOfferBox運用は、御社に相談できますか

できます。当社は、検索、文面の下書き、送信、一次返信、面談前の連絡、台帳の更新、週の報告、台帳の型を支えられます。窓口の決定、「こんな人」の決定、文面の最終確認、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
