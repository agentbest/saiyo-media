新卒の学生にスカウトを送る。中途向けに作った文面を、学生にも使う。「ご経歴を拝見し」「即戦力として」「志望動機を」。学生には、自分宛に読めません。**結論から言うと、新卒向けの文面は、経歴ではなく「学生時代に何をしたか」を読み、「最初の一年」と重ね、「話す場」に誘う四段の型で書きます。学生時代を読んだ一文、「最初の一年」との重なり、選考で何を見るかの一文、話す場か選考かの明記、の四段です。「ご経歴」「即戦力」「志望動機」は書きません。学生の時期には配慮し、年度の公表内容と自社の方針で確認します。三つの媒体で、骨組みは同じで、読む場所と誘う場が違います。** この記事では、中途向けの流用で起きること、学生のプロフィールで読む箇所、四段の型、避ける言葉、時期の配慮、媒体ごとの違い、分担を整理します。文面全体の骨組みは[スカウト文面の基本構成](/media/kh-bunmen-kihon/)で書きました。媒体ごとの新卒向けは[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)、[Wantedlyの新卒向けスカウト文面の型](/media/wt-scout-bunmen-rei-shinsotsu/)、[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。

## この作業の目的｜学生が「自分に向けて書かれている」と分かる文面にする

学生には、職種の経歴がありません。中途向けの文面で読む「いまの仕事」がなく、代わりに「学生時代に何をしたか」があります。ここを読まずに送ると、学生には「大人向けの文面を回してきた」と読まれます。

目的は、学生時代の行動を読み、それを入社後の最初の一年と重ね、学生が「自分がその仕事をしている場面」を想像できる文面にすることです。

## 中途向けの文面を学生に流用すると、起きること

| 流用した言葉 | 学生が受け取ること |
|---|---|
| 「ご経歴を拝見し」 | 経歴はない。読んでいない |
| 「即戦力として」「ご活躍を期待」 | 経験がないのに、できることを求められている |
| 「志望動機をお聞かせください」 | まだ志望していない。会社から声をかけてきたのに |
| 「キャリアアップ」「年収」 | 学生の判断の軸ではない |
| 「これまでの実績を活かして」 | 実績はない |
| 「転職をお考えでしたら」 | 転職ではない |

共通するのは、「いまの仕事」を前提にした言葉です。学生の前提は「学生時代」と「最初の一年」です。流用で起きることは[Wantedlyで新卒にスカウトを送るときの考え方](/media/wt-scout-shinsotsu/)の「中途向けの流用で起きること」で書きました。

## 学生のプロフィールで、読む箇所

- **自由記述**：学生が自分の言葉で書いた部分。「〇〇を自分で始めて、△△まで続けた」
- **ガクチカ（学生時代に力を入れたこと）**：結果ではなく、場面。「□□で困って、✕✕した」。[ワンキャリアの学生のガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/)
- **志向**：「どんな仕事をしたいか」より、「どんなことに時間を使ってきたか」
- **読まない箇所**：大学名、学部名、資格の一覧。これは「見出し」で、拾っても「検索で送った」としか伝わらない
- **拾うのは、行動を一つ**：「自分で始めた」「続けた」「人を巻き込んだ」「条件を変えて試した」

学生のプロフィールの読み方は[OfferBoxのプロフィールの読み方](/media/ob-profile-yomikata/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「新卒には経歴がないので、文面で読める材料が少なく、会社の側の説明を厚くするしかない」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の新卒向けの文面を見ていますが、会社説明を厚くした新卒向けの文面は、学生に読まれていません。学生の自由記述とガクチカには、中途の経歴より具体な行動が書かれていることが多く、「〇〇で困って△△した」の場面は、経歴の「〇〇社で△△を担当」より、重ねやすい材料です。読める材料が少ないのではなく、読む場所が経歴ではないだけです。当社が新卒向けの文面の相談を受けるとき、最初にやるのは、会社説明を削って、学生の自由記述から行動を一つ拾い、「最初の一年」と重ねることです。

## 四段の型

| 段 | 書くこと | 例 |
|---|---|---|
| 1. 学生時代を読んだ一文 | 自由記述かガクチカから、行動を一つ、学生の言葉のまま | 「〇〇のサークルで、△△を自分で始めて三年続けたと書かれているのを拝見しました」 |
| 2. 「最初の一年」との重なり | 入社した年に何をするかを場面で書き、1と重ねる | 「うちでは、入社した年に□□の案件を先輩と二人で持ちます。自分で始めて続けることの連続で、近いと思いました」 |
| 3. 選考で何を見るかの一文 | 学生が準備できる形で | 「選考では、学生時代に続けたことの話を聞きます。志望動機は聞きません」 |
| 4. 話す場か選考かを明記 | 誰と、どんな形で、選考ではないこと | 「選考ではなく、この文面を書いた私と、オンラインで短い時間、仕事の話をする場です。一言だけご返信ください」 |

「1」と「2」が相手ごとに変わる部分、「3」と「4」が型のまま使う部分です。四段の詳しくは[Wantedlyの新卒向けスカウト文面の型](/media/wt-scout-bunmen-rei-shinsotsu/)の「3段の型」に、この記事の「3」を足したものです。

## 「最初の一年」を、場面で用意する

- **現場の人に、「入社した年に、何をするか」を一つ聞く**：「最初の月は先輩の打ち合わせに同席、二か月目から小さな案件を一つ持つ」
- **学生の行動の種類に合わせて、重ねやすい場面を選ぶ**：「自分で始めた」学生には「自分で持つ」場面、「人を巻き込んだ」学生には「社内の人と進める」場面
- **「成長できる」「若手が活躍」で埋めない**：場面がなければ、学生は想像できない
- **募集ごとに、場面を二つか三つ持つ**：学生の行動の種類で使い分ける

「最初の一年」の取り方は[OfferBoxの現場の巻き込み方](/media/ob-genba-makikomi/)で書きました。

## 避ける言葉

- **「ご経歴」「実績」「即戦力」「キャリア」「転職」**：中途向けの言葉
- **「志望動機」**：会社から声をかけているのに、動機を問う形になる
- **「優秀な学生」「上位校の」「厳選した」**：持ち上げと、大学名で送った合図
- **「成長できる」「やりがい」「アットホーム」**：場面のない抽象語
- **「ぜひエントリーを」「早めに」**：応募の要請と、押す言葉
- **「〇〇大学の皆さまに」**：大学名で送った合図。[ワンキャリアで上位大学の学生にスカウトを送る考え方](/media/oc-scout-joui-daigaku/)

避ける言葉の詳しくは[Wantedlyの新卒向けスカウト文面の型](/media/wt-scout-bunmen-rei-shinsotsu/)の「避ける言葉」で書きました。

## 学生の時期への、配慮

- **学生には、授業・試験・研究室・就職活動の時期がある**：送る時期と面談の時期は、年度の公表内容と自社の方針で確認して決める
- **文面で、時期に触れる一文**：「お忙しい時期でしたら、時期をずらして構いません」
- **返事が遅くても、時期のせいかもしれないと見る**：再送は一度だけ
- **選考との関係を、事実で**：「この面談は選考ではありません」「参加の有無は選考に影響しません」。年度の公表内容と自社の方針で確認できる範囲で
- **時期の考え方は、媒体ごとに[OfferBoxの送信タイミング](/media/ob-soushin-timing/)、[ワンキャリアのスカウトを送る時期と時間](/media/oc-scout-timing/)**

## 媒体ごとに、変わる点

| 媒体 | 読む場所 | 誘う場 |
|---|---|---|
| OfferBox | プロフィールの自由記述 | 面談（選考ではない）。承認から |
| Wantedly | プロフィールとストーリー。学生の「なぜ」 | カジュアル面談。返信から |
| ワンキャリア | プロフィールとガクチカと、学生が読んだ体験談 | 企業ページと体験談で確かめてから受諾。「何を見るか」を企業ページと揃える |

骨組みの四段は同じで、「1」の材料と「4」の場の形が変わります。

### エージェントベストの見解

これは順番の話です。当社が新卒向けの文面の相談を受けたとき、型を渡す前に、「入社した年に何をするか」を現場が一つ言えるかを確かめます。言えなければ、四段の「2」が埋まらず、型があっても文面は会社説明になります。逆に、「2」の場面が一つあれば、学生の自由記述から行動を拾って重ねるだけで、文面はできます。当社が勧める順番は、「最初の一年」の場面を現場から一つ聞く、学生の行動を一つ拾う、重ねる、「何を見るか」と「話す場」を型のまま添える、です。「最初の一年」がないまま学生に送った文面は、学生に「何をする会社か分からない」として読まれます。

## まとめ

- 新卒には経歴がない。中途向けの言葉（ご経歴・即戦力・志望動機・キャリア・転職）を流用すると、「大人向けの文面を回してきた」と読まれる
- 読む場所は、自由記述とガクチカの「学生時代に自分で始めた・続けた行動」。大学名や資格の一覧は「見出し」で拾わない
- 四段の型は、学生時代を読んだ一文→「最初の一年」との重なり→選考で何を見るかの一文→話す場か選考かの明記。1と2が相手ごと、3と4が型
- 「最初の一年」を場面で二つか三つ持ち、学生の行動の種類で使い分ける。「成長できる」で埋めない
- 学生の時期に配慮し、年度の公表内容と自社の方針で確認する。媒体ごとに「1」の材料と「4」の場の形が変わる

## よくある質問

### 学生の自由記述が薄く、行動が拾えません

薄い学生は後回しにし、拾える学生から送ります。拾えないまま「〇〇大学の」で埋めると、「大学名で送った」と読まれ、返信が来ません。どうしても送るなら、「自由記述は少なかったのですが、〇〇の点で話を聞いてみたいと思いました」と、拾えなかったことを隠さず、無理に読んだふりをしません。

### 「志望動機は聞きません」と書いてよいのですか

書いてよいです。会社から声をかけて、「なぜうちに」を学生に問うのは、順番が逆です。「選考では、学生時代に続けたことの話を聞きます」と書き、面接官もそのとおりに聞きます。志望動機は、学生が話す場と選考の中で、自分で作るものです。面接官への伝え方は[OfferBox経由の学生を面接する現場社員への説明](/media/ob-genba-mensetsukan/)で書きました。

### 新卒向けスカウト文面の型は、御社に相談できますか

できます。当社は、四段の型、学生のプロフィールの読み方の型、避ける言葉の点検、媒体ごとの違いの整理を支えられます。行動を拾うこと、「最初の一年」を話すこと、送ること、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
