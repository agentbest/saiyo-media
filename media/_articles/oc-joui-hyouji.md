「ワンキャリアで、自社の掲載を上位に表示させるにはどうすればよいか」という相談を受けることがあります。**結論から言うと、表示や並び順がどう決まるかは公表されていないので、その仕組みを推測して動かそうとする作業は勧めません。代わりにやるのは、学生が自社を探す動き（体験談から社名で、職種や条件の絞り込みから、イベントの一覧から、友人の話から）ごとに、「見つけられる状態」を作ることです。項目を埋める、職種やコースの名前を学生の呼び方に揃える、イベントを途切れさせない、体験談が増える状態を作る。順位そのものは目標にしません。** この記事では、仕組みを推測しない理由、学生が探す4つの動き、動きごとにやること、順位を目標にしない理由、分担を整理します。表示の仕様や絞り込みの項目は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜探している学生が、自社にたどり着ける状態にする

学生は、「良さそうな会社を上から順に見る」だけでなく、体験談から社名で来る、職種で絞り込む、イベントの一覧を見る、友人に聞いた会社を調べる、という動き方をします。

目的は、どの動きで来た学生も、自社にたどり着き、たどり着いた先に中身がある状態にすることです。順位を上げることではなく、探している学生に届くことです。

## 仕組みを推測して動かそうとしない理由

| 理由 | 何が起きるか |
|---|---|
| 表示や並び順の決まり方は公表されていない | 推測で動かすと、外れたときに何が原因か分からない |
| 仕組みは変わることがある | 一度当たっても、次に当たるとは限らない |
| 推測に合わせると、学生に読まれない掲載になる | 項目を埋めるために、中身の無い言葉を並べることになる |
| 順位が上がっても、中身が無ければ来ない | 表示されて、開かれて、中身で判断される。中身が最後 |
| 媒体の規約や運用に沿わないやり方は、そもそも取らない | 規約は管理画面とヘルプで確認する |

「順位より中身」ではなく、「順位は中身と運用の結果として付いてくるもので、直接動かす対象ではない」と考えます。

## 学生が探す、4つの動き

| 動き | 学生がすること | 自社がやること |
|---|---|---|
| 体験談から、社名で | 体験談やクチコミを読んで、その会社を調べる | 企業ページが整っていること。体験談と揃っていること |
| 職種や条件の絞り込みから | 職種、勤務地、業界などで絞って一覧を見る | 絞り込みに関わる項目を埋め、職種やコースの名前を学生の呼び方に揃える |
| イベントの一覧から | 参加できるイベントを探す | イベントを途切れさせず、タイトルに「誰が・何を」を出す |
| 友人や先輩の話から | 名前を聞いた会社を調べる | 体験談が増える状態（選考を受けた学生が書きたくなる選考） |

どの動きも、最後は企業ページにたどり着きます。企業ページが薄いと、どの動きで来ても、そこで終わります。企業ページの中身は[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「表示の順位を上げる方法があり、それを知っている代理店に頼めば上がる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を支えていますが、表示や並び順の決まり方は公表されておらず、当社もそれを動かす方法は持っていません。持っていると言う相手がいれば、その根拠を確かめてください。当社がやるのは、学生が探す動きごとに、たどり着ける状態と、たどり着いた先の中身を作ることです。項目を埋める、名前を学生の呼び方に揃える、イベントを途切れさせない、体験談が増える選考にする。この四つは、仕組みが変わっても効きます。順位を動かす方法を探すより、確かです。

## 動きごとに、やること

### 1. 体験談から、社名で来る学生に

- **企業ページを整えておく**：選考の流れと何を見るか、仕事の具体と最初の1年、働く人、よく聞かれること
- **体験談と揃っていること**：ずれていると、たどり着いても体験談が信じられる
- **体験談が読まれ始める前に、整えておく**：時期の逆算は[掲載を始める時期の考え方](/media/oc-keisai-timing/)

### 2. 職種や条件の絞り込みから来る学生に

- **絞り込みに関わる項目を、埋める**：職種、勤務地、コースなど。空欄にしない。どの項目が絞り込みに関わるかは管理画面で確認
- **職種やコースの名前を、学生の呼び方に揃える**：社内の正式名称より、体験談で学生が使っている呼び方。[募集コースの考え方](/media/oc-boshu-course/)
- **コースを分けるべきものを分ける**：一つにまとめると、絞り込みで自社が出る機会が減る
- **項目を埋めるために、中身の無い言葉を入れない**：埋めるのは事実だけ

### 3. イベントの一覧から来る学生に

- **イベントを途切れさせない**：一覧に自社が出る機会が減る。ただし、中身のある回だけ
- **タイトルに「誰が・何を」を出す**：一覧で選ばれる。[イベントページのタイトルの付け方](/media/oc-event-page-title/)
- **終わった回の誘導を外す**：[イベントページと企業トップページの使い分け](/media/oc-event-page-kigyo-top/)

### 4. 友人や先輩の話から来る学生に

- **体験談が増える状態を作る**：選考を受けた学生が「書きたい」と思う選考。連絡が早い、何を見ているかが分かる、面接官が話を聞く
- **書いてもらうよう依頼するのではなく、書きたくなる選考にする**：体験談は学生が自分の意思で書くもの
- **良い体験談も悪い体験談も増える**：悪いものが書かれたら、運用を直す。[掲載でやりがちな失敗](/media/oc-keisai-ng/)

## 順位を目標にしない理由

| 順位を目標にすると | 代わりに見るもの |
|---|---|
| 仕組みの推測に時間を使う | 4つの動きのどこが弱いか |
| 項目を中身の無い言葉で埋める | 事実で埋める |
| イベントを中身の無い回で増やす | 中身のある回を途切れさせない |
| 順位が上がっても来ない理由が分からない | 面接で「どこを読んで来たか」を聞く |
| 仕組みが変わると、やり直しになる | 仕組みが変わっても効くことをやる |

見るのは、順位ではなく、企業ページの閲覧の変化と、面接で聞いた「どこから来たか」です。KPIの考え方は[掲載のKPI設計](/media/oc-keisai-kpi/)で書きました。

## 埋めていない項目を、埋める

表示の仕組みに関わらず、埋めていない項目は埋めます。

- **管理画面で、未入力の項目を一覧で見る**：どの項目があるかは仕様で変わる
- **事実で埋められる項目を、全部埋める**：職種、勤務地、コース、選考の流れ、写真
- **埋められない項目は、なぜ埋められないかを社内で確かめる**：決まっていないなら決める。公表できないなら、その旨
- **埋めたら、体験談と揃っているかを確かめる**
- **年度の切れ目に、埋め直す**：項目が増えていることがある

「事実で埋められるのに、埋めていない」項目が残っている会社は多くあります。推測で動かす前に、ここを埋めます。

## 3媒体での考え方の違い

| 媒体 | 見つけられ方 |
|---|---|
| OfferBox | 企業が学生を探して送る。学生に見つけてもらう設計ではない。[OfferBoxの検索条件の設計](/media/ob-kensaku-jyoken/) |
| Wantedly | 募集記事とストーリーが読まれて見つかる。更新の頻度が効く |
| ワンキャリア | 体験談から、絞り込みから、イベントから、友人から。企業ページが受け止める |

ワンキャリアは、「学生が探して見つける」媒体なので、探す動きから逆算します。OfferBoxのように企業から探す媒体とは、設計が違います。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 未入力の項目を洗い出し、事実で埋める | 人事 |
| 職種やコースの名前を、体験談の呼び方に揃える | 人事 |
| イベントを途切れさせない計画 | 人事と責任者 |
| 体験談が増える選考にする（連絡・面接の型） | 人事と面接に出る人 |
| 企業ページを整えておく | 人事 |
| 面接で「どこから来たか」を聞く | 面接に出る人 |
| 年度の切れ目に項目を埋め直す | 人事 |

運用代行や代理店が支えられるのは、未入力の項目の洗い出し、名前の揃え方の点検、イベントの計画の設計、企業ページの整備までで、項目の事実の決定、選考の運用を直すこと、面接で聞くことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「代理店に頼めば、表示を有利にできる」という点です。当社は、表示や並び順を動かす方法は提供していませんし、公表されていない仕組みを推測して動かす作業も請け負いません。当社が請け負うのは、未入力の項目を事実で埋めること、職種やコースの名前を学生の呼び方に揃えること、イベントの計画を立てること、企業ページを体験談と揃えることです。この四つは、仕組みが変わっても効き、学生が探すどの動きにも効きます。「上位表示」を約束する提案を受けたときは、その根拠と、仕組みが変わったときにどうするかを確かめてください。当社が確かなこととしてお伝えできるのは、埋めること、揃えること、途切れさせないこと、の三つです。

## まとめ

- 表示や並び順の決まり方は公表されていないので、推測して動かそうとしない。仕組みは変わることがある
- 学生が探す動きは、体験談から社名で、職種や条件の絞り込みから、イベントの一覧から、友人の話から、の4つ
- 動きごとに、企業ページを整える、項目を事実で埋めて名前を学生の呼び方に揃える、イベントを途切れさせない、体験談が増える選考にする
- 順位を目標にすると、中身の無い言葉で項目を埋め、中身の無い回でイベントを増やすことになる
- 見るのは順位ではなく、企業ページの閲覧の変化と、面接で聞いた「どこから来たか」

## よくある質問

### 項目を多く埋めたほうが、表示に有利ですか

仕組みは公表されていないので、有利かどうかは分かりません。ただし、埋めていない項目があると、絞り込みで自社が出ない可能性があり、たどり着いた学生にも情報が足りません。有利かどうかに関わらず、事実で埋められる項目は埋めます。中身の無い言葉で埋めることは、しません。

### 体験談を書いてもらうよう、学生に依頼してよいですか

体験談は学生が自分の意思で書くもので、依頼の可否や条件は媒体の規約で決まります。規約を管理画面とヘルプで確認してください。当社が勧めるのは、依頼ではなく、「書きたくなる選考」にすることです。連絡が早く、何を見ているかが分かり、面接官が話を聞く選考は、学生が書きたくなります。

### ワンキャリアで見つけられる状態を作る作業は、御社に相談できますか

できます。当社は、未入力の項目の洗い出し、名前の揃え方の点検、イベントの計画の設計、企業ページの整備を支えられます。表示や並び順を動かす方法は提供していません。項目の事実の決定、選考の運用を直すこと、面接で聞くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
