新卒採用で、内定者や若手社員に「合いそうな友人を紹介してほしい」と頼んでいる。OfferBoxも使っている。ところが、「内定者に頼んでも動かない」「紹介された学生が、就活で会った友人というだけで合わない」「紹介とOfferBoxをどう組み合わせればいいか分からない」という状態になりがちです。**結論から言うと、リファラルは「内定者と若手が『こんな人』を知って声をかける入口」、OfferBoxは「企業が検索して選んで送る入口」です。併用するなら、「こんな人」の一行を両方の元にし、紹介で会った学生の特徴を検索条件と文面に落とし、紹介された学生の流れをOfferBox経由の学生と一本にし、声かけは内定者に、選ぶのは人事に、決めるのは面接官に分けることです。** この記事では、それぞれの役割、「こんな人」の一行、紹介で会った学生を検索と文面に落とす方法、流れの一本化、内定者に頼むことの範囲、結果を返す、報奨と時間、やりがちな失敗、社内の分担を整理します。リファラルからの母集団形成の全体は[リファラルからの母集団形成](/media/kh-boshudan-referral/)、Wantedlyとの併用は[Wantedlyとリファラル採用の併用](/media/wt-heiyou-referral/)で書きました。数値は書きません。

## それぞれの役割｜「知っている学生に声をかける」と「検索して選んで送る」

| | リファラル | OfferBox |
|---|---|---|
| 誰が動くか | 内定者と若手社員。知っている学生に声をかける | 人事（または代行）。検索して選び、送る社員の名義で送る |
| 学生の状態 | 内定者から会社の話を聞いている。会社の中身は、内定者の言葉の範囲 | 文面と送ってきた人で興味を持っている。「自分に来た」と感じている |
| 入口の広さ | 内定者の知り合いの範囲。狭いが、合う人が多い | 登録している学生の範囲。広いが、選ぶ精度で変わる |
| 会社が用意するもの | 「こんな人」の一行、声をかけたあとの流れ、結果を返す約束 | 検索条件、文面、送る社員の名義 |
| 時期 | 内定者が決まってから。就職活動の後半に多い | 送る時期は企業が決める |
| 残るもの | 内定者が「声をかけた」経験。紹介で会った学生の特徴 | 検索条件と文面の型。送る社員の名義 |

リファラルは、内定者が「うちに合いそうな友人」を知っているから動く入口で、OfferBoxは、人事が「こんな人」を検索で探す入口です。二つは、「こんな人」の一行を共有すると、互いを補います。紹介で会った学生の特徴が検索条件を具体的にし、OfferBoxで会った学生の反応が、内定者に頼む「こんな人」の言葉を具体的にします。

## 「こんな人」の一行を、両方の元にする

- **「こんな人」を一行で書き、行動で表す**：「コミュニケーション力のある人」ではなく、「自分で始めて、人を巻き込んだ経験のある人」
- **内定者に渡す言葉と、検索条件の元を同じにする**：内定者には「〇〇のような友人」、検索には「〇〇に近い記述のある学生」
- **内定者に「いい人いない？」と聞かない**：一行がないと、内定者は「就活で仲良くなった友人」を思い浮かべる。仲が良いことと、合うことは別
- **内定者と一緒に一行を作る**：内定者は学生だった側の目で、「その一行に当てはまる学生が、どこにいるか」を知っている。[OfferBoxで内定者にオファー文面を手伝ってもらう方法](/media/ob-naiteisha-katsuyou/)

### エージェントベストの見解

これは切り分けの話です。OfferBoxとリファラルを併用するとき、内定者に頼むべきなのは「声をかけること」までで、「選ぶこと」と「決めること」は頼みません。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、内定者の紹介で来た学生の面談にも関わりますが、うまくいかない会社に共通するのは、内定者に「合いそうな人を選んで連れてきて」と頼んでいることです。内定者は、会社の「こんな人」をまだ体で分かっておらず、自分と仲の良い友人を「合う」と思います。選ぶのは、「こんな人」の一行を持っている人事の仕事で、決めるのは面接官の仕事です。内定者には、「この一行に当てはまる友人がいたら、声だけかけてほしい。合うかどうかは、こちらで会って判断する」と頼みます。この線で分けると、内定者は「連れてきた友人が落ちた」と気にせずに済み、声をかけ続けられます。

## 紹介で会った学生の特徴を、検索条件と文面に落とす

- **紹介で会った学生のうち、「近い」と付いた学生の記述の特徴を残す**：どんな経験を、どんな言葉で書いていたか。所属や専攻ではなく、行動の書き方
- **その特徴を、OfferBoxの検索条件に足す**：「近い学生が、こういう記述をしていた」を検索の手がかりに。組み方は[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)
- **紹介で会った学生が「なぜ話を聞こうと思ったか」を、文面の場面にする**：内定者の言葉のどこに反応したかが、文面で書くべき場面
- **逆に、OfferBoxで承認した学生の反応を、内定者に渡す一行に戻す**：「文面の〇〇の場面に反応した学生が多い」を、内定者の声かけの言葉に
- **どちらの入口でも、面談で「何を聞いて、何を見て来たか」を聞く**：紹介なら内定者の言葉のどこ、OfferBoxなら文面のどこ

リファラルとOfferBoxは、片方で得た「こんな人」の解像度を、もう片方に渡すと、年を重ねるごとに精度が上がります。

## 紹介された学生の流れを、一本にする

- **紹介された学生も、OfferBox経由の学生と同じ段と基準で**：「内定者の紹介だから」で段を飛ばさない。飛ばすと、内定者の紹介で入った学生が「特別扱い」で入り、入社後に立場が難しくなる
- **最初は「話を聞く面談」から**：選考の意思を確認してから選考へ。紹介の学生ほど、断りにくくて来ていることがある
- **台帳は一つ**：入口の列に「リファラル（誰の紹介）」と「OfferBox」。面談から先は共通の段
- **紹介された学生が、OfferBoxにも登録していたら**：送らない。すでに接点がある学生に、検索で見つけて送ると二重になる。送る前に名前を突き合わせる
- **面接官には、入口を伝えたうえで、基準は同じにしてもらう**：[OfferBox経由の学生を面接する現場社員への説明](/media/ob-genba-mensetsukan/)

## 内定者に頼むことの範囲と、結果を返す

| 頼むこと | 頼まないこと |
|---|---|
| 「こんな人」の一行に当てはまる友人に、声をかける | 合うかどうかを選ぶ |
| 会社の話を、自分の言葉で伝える | 会社を宣伝する、条件を説明する |
| 「話を聞く面談があるから、よかったら」と案内する | 選考を勧める、内定を約束する |
| 声をかけた相手の名前を、本人の同意のうえで伝える | 相手の同意なく情報を渡す |

- **結果を内定者に返す**：「面談しました」「ご縁がありませんでした」。返す範囲は、紹介された学生の同意と個人情報の扱いの範囲で
- **落ちたときに、内定者が気にしない形にする**：「選ぶのはこちらの仕事」と先に伝えてあれば、内定者は次も声をかけられる
- **内定者の温度を守る**：紹介を頼みすぎると、内定者が「営業させられている」と感じる。頼むのは、内定者の温度が保てている時期に。[OfferBoxの内定者フォロー](/media/ob-naitei-follow/)
- **報奨を置くかは、自社の方針と法令の確認のうえで**：置く場合の条件と金額は、この記事では書かない。新卒の内定者への報奨は、置かない会社も多い

## 時間の置き方

- **人事の時間は、「声をかけたあと」に要る**：紹介された学生への最初の連絡、面談の設定、内定者への結果の返し。ここが遅れると止まる
- **OfferBoxの送る時期と、内定者に頼む時期は、ずれることが多い**：内定者が決まるのは後半。送る時期は前半に多い。時間の重なりは小さい
- **紹介で会った学生の特徴を、送る時期の前に検索条件に落とす**：後半の紹介が、翌年の前半の検索に効く
- **費用は、OfferBoxのプランの費用と、代行に出すなら代行の費用**：公式ページと見積もりで確認。リファラルは費用より時間

配分の考え方は[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「いい人いない？」で頼む | 仲の良い友人が来て、合わない | 「こんな人」の一行を渡す |
| 内定者に「選んで」と頼む | 落ちたときに内定者が気にし、次に動かない | 声かけまで。選ぶのは人事 |
| 紹介の学生の段を飛ばす | 特別扱いで入り、入社後に立場が難しい | 同じ段と基準で |
| 紹介で会った学生の特徴を残さない | 翌年の検索条件に活きない | 「近い」学生の記述の特徴を残す |
| 紹介された学生にOfferBoxで送る | 二重の接点になり、印象が下がる | 送る前に名前を突き合わせる |

最も多いのは、一つ目です。一行がないまま頼み、内定者は自分の友人を思い浮かべ、「合わない紹介」が続いて、紹介そのものが止まります。

| 作業 | 誰が |
|---|---|
| 「こんな人」の一行を作る | 人事と現場の責任者。内定者に意見を聞く |
| 内定者に頼む範囲と言葉を決める | 人事 |
| 声をかける | 内定者・若手社員 |

| 紹介で会った学生の特徴を検索条件と文面に落とす | 人事（代行に出しているなら代行と） |
| 面談で「何を聞いて、何を見て来たか」を聞く | 面談に出る人 |
| 内定者に結果を返す | 人事 |
| 報奨の有無の判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、「こんな人」の一行の型、内定者に渡す言葉の型、台帳の型、紹介で会った学生の特徴を検索条件と文面に落とす作業までで、一行の決定、声をかけること、面談、結果を返すこと、報奨の判断は企業と内定者が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

内定者に紹介を頼み始めたあと、最初の年で起きることに共通するのは、紹介された学生が「就活で仲良くなった友人」で、面談で合わず、内定者の温度も一緒に下がることです。当社はOfferBoxの運用代行で紹介で来た学生の面談の前後を見ることがありますが、内定者は「友人を落とされた」と感じ、次から声をかけなくなり、内定者自身が会社に対して距離を置き始めます。紹介がうまくいかないことより、内定者を失うことのほうが、会社にとって大きな損です。防ぐには、頼む前に「選ぶのはこちらの仕事。声をかけてくれた時点で助かっている」と伝え、落ちたときも内定者に「声をかけてくれてありがとう」で返すことです。当社は、内定者に紹介を頼む会社には、OfferBoxの検索と文面の側で「こんな人」を先に具体的にし、その一行を内定者に渡す順番を勧めています。一行があれば、内定者は仲の良さではなく、一行で友人を思い浮かべます。

## まとめ

- リファラルは「内定者と若手が『こんな人』を知って声をかける入口」、OfferBoxは「企業が検索して選んで送る入口」。「こんな人」の一行を共有すると互いを補う
- 内定者に頼むのは「声をかける」まで。選ぶのは人事、決めるのは面接官。「いい人いない？」ではなく一行を渡す
- 紹介で会った「近い」学生の記述の特徴を検索条件に、反応した場面を文面に落とす。逆も
- 紹介された学生も同じ段と基準で。台帳は一つ。紹介された学生にOfferBoxで送らない
- 結果を内定者に返し、落ちたときも内定者が気にしない形にする。内定者の温度を守る

## よくある質問

### 内定者に紹介を頼むのは、いつがよいですか

内定者の温度が保てている時期です。内定の直後は「入りたい会社」の気持ちが強く、声をかけやすい一方、頼みすぎると「営業させられている」に変わります。頼むのは一度、「こんな人」の一行と一緒に。あとは内定者が思い出したときに声をかけてくれる形で、催促はしません。

### 紹介された学生が、OfferBoxで検索したら出てきました。送ってよいですか

送りません。すでに内定者を通じて接点があるので、検索で見つけて送ると二重になり、「紹介と関係なく送られた」と読まれます。紹介の流れで面談に案内し、台帳に「入口：リファラル」で入れます。送る前に、紹介された学生の名前を突き合わせる手順を、送る側の台帳に入れておきます。

### OfferBoxとリファラルの併用は、御社に相談できますか

できます。当社は、役割の整理、「こんな人」の一行の型、内定者に渡す言葉の型、台帳の型、紹介で会った学生の特徴を検索条件と文面に落とす作業を支えられます。一行の決定、声をかけること、面談、結果を返すこと、報奨の判断は、企業と内定者が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
