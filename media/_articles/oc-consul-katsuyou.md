戦略・総合の大手、IT・業務・人事・財務などの特化型、中堅、地方のコンサルティング会社が、新卒採用でワンキャリアを使う。コンサルは、ワンキャリアで体験談が最も濃く書かれる業界で、学生は企業ページより先に、ケース面接の題材、ジョブの形式、面接の回数と聞かれたことを読み、「選考対策の場」としてワンキャリアを使っている。中堅と特化型は、戦略・総合の大手の体験談で作られた「コンサルの選考」の像で読まれ、ケース面接をしない会社は「コンサルではない」と、する会社は「大手と同じ対策で」と読まれる。**結論から言うと、コンサル業界のワンキャリアは、選考の中身は隠せない前提で、企業ページにケース面接の有無と形式、ジョブの形、面接の回数と、「何の領域で、どの段階の案件を、常駐か自社か」の位置を先に書きます。対策される前提で今年の選考を設計し、「成長」「一流」で企業ページを埋めません。中堅と特化型は大手の像で読まれる前提で、大手との違い（領域、案件の段階、最初の年の仕事）を先に書きます。内定後の辞退を減らすには、今年の内定者が体験談に「なぜ残ったか」を書く選考と内定後の設計をします。** この記事では、コンサル業界の採用構造とワンキャリアとの相性、企業ページの見せ方、対策される前提の選考設計、イベントとスカウトの運用設計、社内の分担を整理します。媒体の選び方は[コンサル業界の採用媒体の選び方](/media/hikaku-consul-erabikata/)、企業ページの基本は[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。数値と料金は書きません。

## コンサル業界の採用構造と、ワンキャリアとの相性

| 区分 | 採用の形 | ワンキャリアとの相性 |
|---|---|---|
| 戦略・総合の大手 | 上位大学志向。ケース面接とジョブ。体験談が最も多い。並べて比べる場の中心 | 体験談に書かれた選考の像を企業ページでずらさない。対策される前提で設計 |
| IT・業務・人事・財務の特化型 | 「コンサル」で大手志望が流れる。ケースの有無が会社で違う | 領域と案件の位置と、ケースの有無を先に。大手との違いを隠さない |
| 中堅、地方のコンサル | 体験談が少ないか、ない。大手の像で読まれる | 体験談がない年の入口。選考の中身を企業ページで先に出す |

| 業界の特徴 | ワンキャリアで起きること | 設計 |
|---|---|---|
| 学生は「選考対策の場」として読む | ケースの題材と聞かれたことが、すでに書かれている | 隠さず、企業ページに選考の中身を先に。対策される前提で組む |
| 大手の体験談で「コンサルの選考」の像ができる | 中堅・特化型が、大手の対策と大手の像で受けに来る | 領域と案件の位置と、大手との違いを最初に |
| 「成長」「一流」で来て、最初の年（資料、議事録、常駐）で離れる | 体験談に「最初の年は資料だった」と残る | 最初の年の仕事を企業ページと面接で先に |
| 内定後に、大手の結果で辞退される | 内定者の体験談に「他社に行った」と残る | 内定者が「なぜ残ったか」を書く設計を今年 |

## 企業ページの見せ方｜選考の中身と、領域と案件の位置を先に

- **ケース面接の有無と形式を、隠さず書く**：「ケース面接は〇〇の形式で△△回。ジョブは□□の形」。体験談にすでに書かれていることを、企業ページが先に言う
- **領域と案件の位置を、最初の一文に**：「〇〇の領域で、△△の段階の案件を、□□（常駐か自社か）で」。「コンサル」の一語で済ませない
- **最初の年の仕事を、場面で**：「最初の年は、〇〇の案件で△△を作り、□□の会議に出る」。「成長」「一流」の一語で埋めない
- **大手との違いを、中堅・特化型は先に**：「戦略の大手と違い、当社は〇〇の領域で、案件の段階は△△、ケース面接は□□」。違いを隠すと「コンサルではない」と読まれる
- **自社の体験談に「ケースが簡単だった」「最初の年は資料だった」があれば、先に読む**：合っているなら隠さず、どう扱っているかを添える。[業界イメージが不利な会社のワンキャリアの見せ方](/media/oc-gyokai-image/)
- **上位大学の学生に読まれる前提で、選考の基準を書く**：「何を見るか」を書くと、対策の方向が揃う。[上位大学の学生から反応が取れないときのワンキャリア運用](/media/oc-joui-daigaku/)

企業ページが選考の中身を先に言うと、体験談との差がなくなり、学生は「隠していない会社」として読みます。本選考の書き方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。コンサルの会社から、「ケース面接の題材や形式を体験談に書かれると対策されるので、企業ページには書きたくない」と相談されることがあります。当社は、それを隠しません。ワンキャリアでは、ケース面接の題材と形式と聞かれたことは、企業が書かなくても、受けた学生が体験談に書いていて、学生はそれを読んで対策してから来ます。企業ページが選考の中身を書かないことは、対策を防がず、「企業ページより体験談を読めばよい会社」として企業ページが読まれなくなるだけです。当社がお願いするのは、対策される前提で、企業ページにケースの有無と形式と「何を見るか」を先に書き、今年のケースを「対策しても差が出る題材」（実態に近い、正解が一つでない、対策した学生とそうでない学生の差が出る）に設計することです。隠して対策される選考より、先に書いて対策される前提の選考のほうが、面接官が見たい差を見られます。

## 対策される前提で、今年の選考を設計する

- **ケースの題材は、対策しても差が出る形に**：自社の領域の実態に近い題材。正解が一つでない。「考え方を見る」と企業ページに書いた基準と一致させる
- **面接で聞くことは、体験談に書かれる前提で決める**：「なぜコンサルか」「なぜ当社か」は像を確かめる質問で、像の体験談を作る。代わりに「最初の年の仕事を聞いて、それでも来るか」を聞く
- **最初の年の仕事を、面接で伝える**：「最初の年は資料と議事録と〇〇」。伝えたことは体験談に「聞いた」と残る
- **ジョブは、実態と同じ形に**：ジョブと入社後の案件がずれると、体験談に「ジョブと違った」と残る
- **面接官に、体験談を読ませる**：自社の面接がどう書かれているかを面接官が知る。[ワンキャリアのクチコミを面接官教育に使う方法](/media/oc-kuchikomi-mensetsukan/)

選考で離れた学生の体験談は[ワンキャリア経由の学生が選考で離脱するときの原因](/media/oc-senkou-ridatsu/)で書きました。

## 内定後の辞退を、内定者の体験談で減らす

- **内定後に大手の結果で辞退されるのは、コンサルの前提**：辞退を「ゼロにする」ではなく、「残った内定者が、なぜ残ったかを書く」設計に
- **内定者と、最初の年の仕事を先に見せる**：案件の資料、会議の見学、若手との時間。「成長」ではなく実態で残す
- **内定者の体験談に「なぜ残ったか」が書かれる形に**：「〇〇の案件を先に見た」「若手の△△と話した」。翌年の学生が読む
- **辞退した学生の体験談も、読む**：「他社に行った理由」が書かれている。[ワンキャリア経由の内定辞退が続くときの見直し](/media/oc-naitei-jitai/)

## イベントとスカウトの設計

- **イベントは、若手が「最初の年の一日」を話す**：「〇〇の案件で、資料を△△回直した日」「□□の会議に初めて出た日」。「成長」ではなく場面
- **中堅・特化型は、大手との違いを若手が話す**：「大手から転職した」「大手を受けて当社に来た」若手がいれば、その本人の言葉で
- **スカウトは、「領域と案件の位置」を最初に**：「〇〇の領域で△△の段階の案件をする会社で、あなたの□□（ガクチカ）を読んで」。「コンサルに興味」で絞らない
- **絞るのは、「自分で問いを立てて調べて決めた・違う立場の人を説得した」のガクチカ**：ケース面接と最初の年に近い経験。[ワンキャリアの学生のガクチカを読んでスカウトを送る方法](/media/oc-scout-gakuchika/)
- **上位大学に送るなら、選考の基準と最初の年を先に**：[ワンキャリアで上位大学の学生にスカウトを送るときの考え方](/media/oc-scout-joui-daigaku/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 領域と案件の位置の一行と、ケースの有無と形式、最初の年の仕事を決める | 経営と人事、案件の責任者 |
| 企業ページに選考の中身と位置を先に書き、「成長」「一流」を外す | 人事。若手のコンサルタントが確認 |
| 自社の体験談を読み、ケースと最初の年に何が書かれているかを分ける | 人事と面接官 |
| 対策しても差が出るケースの題材を作る | 案件の責任者と面接官 |
| 面接官に体験談を読ませ、「なぜコンサルか」を聞かないと伝える | 人事 |
| 内定後に案件の資料と会議と若手との時間を用意する | 案件の責任者と人事 |
| イベントで若手が最初の年の一日を話す | 入社してまもないコンサルタント |

### エージェントベストの見解

これは契約後に起きることの話です。コンサルの会社が、「成長」「一流の環境」で企業ページを書いて内定を出し、内定後に大手の結果で辞退され、残った内定者が入社後に「最初の年は資料と議事録だった」と離れる、という形を、当社は3媒体すべての販売パートナーとして繰り返し見ています。翌年の学生が最初に読むのは、辞退した学生の「他社に行った」体験談と、離れた学生の「資料だった」体験談で、企業ページの「成長」はその後に読まれます。当社がお願いするのは、企業ページと面接で最初の年の仕事を先に伝え、内定後に案件の資料と会議と若手との時間を見せて、「実態を知ったうえで残った内定者」を作ることです。その内定者の体験談に「なぜ残ったか」が書かれると、翌年の学生は「成長」ではなく「最初の年の実態を知って残った人がいる」を読んで来ます。辞退はゼロになりませんが、残る内定者が翌年の像を作ります。

## まとめ

- コンサル業界は、学生がワンキャリアを「選考対策の場」として読み、ケース面接の題材と形式と聞かれたことは体験談にすでに書かれている。隠さず、企業ページに選考の中身と「領域と案件の位置」を先に書き、対策される前提で今年の選考を設計する
- 中堅・特化型は、大手の体験談で作られた像で読まれる。大手との違い（領域、案件の段階、ケースの有無、最初の年）を隠さず先に。「成長」「一流」で企業ページを埋めない
- ケースは対策しても差が出る題材に、面接では「なぜコンサルか」を聞かず最初の年の仕事を伝える。面接官に体験談を読ませる
- 内定後の辞退はコンサルの前提。残った内定者が「なぜ残ったか」を体験談に書く設計（案件の資料、会議、若手との時間）を今年する
- イベントは若手が最初の年の一日を、中堅・特化型は大手との違いを本人の言葉で。スカウトは位置を最初に、「問いを立てて決めた・説得した」のガクチカで絞る

## よくある質問

### ケース面接の中身を企業ページに書くと、対策されませんか

対策は、企業ページに書かなくても、体験談で先にされています。書かないことは対策を防がず、企業ページが読まれなくなるだけです。ケースの有無と形式と「何を見るか」を先に書き、今年の題材を「対策しても差が出る形」（実態に近い、正解が一つでない）にすると、対策した学生とそうでない学生の差を、面接官が見られます。

### 内定後に、大手の結果で辞退されます

コンサルでは前提で、ゼロにはなりません。減らすのは、内定後に案件の資料と会議と若手との時間を見せて、「最初の年の実態を知ったうえで残る内定者」を作ることです。その内定者が体験談に「なぜ残ったか」を書くと、翌年の学生が「成長」ではなく「実態を知って残った人がいる」を読んで来て、辞退が減ります。辞退した学生の体験談も読み、「他社に行った理由」を翌年の企業ページと面接に反映します。

### コンサル業界のワンキャリアの設計は、御社に相談できますか

できます。当社は、企業ページの型、体験談の読み方の型、選考の設計の型、内定後の設計の型、イベントの型、スカウトの型と絞る作業を支えられます。位置の決定、ケースの題材、面接で伝えること、内定後に見せる案件、若手が話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
