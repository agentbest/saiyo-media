スカウトの文面の4段目「話す場か選考か」で、一対一の話す場ではなく、イベント（説明会、座談会、仕事を知る会）に誘う形があります。学生にとっては、一対一の面談より負担が軽く、会社にとっては、話す人と内容を先に見せられます。ところが、文面で「〇〇が話す会に」と誘っておいて、当日に別の人が出る、内容が会社説明会になる、選考との関係が文面と違う、ということが起きると、体験談に書かれます。**結論から言うと、スカウトからイベントに誘うときは、文面の4段目を「この回に、この人と、これを確かめに来てください」の形にし、イベントの掲載（誰が・何を・選考との関係）と、当日の内容と、翌日の連絡を、文面と揃えます。イベントの掲載を先に整え、受諾から申込までの導線を一つにし、当日にスカウト経由の学生を迎える形を決めます。** この記事では、イベントに誘う利点、4段目の書き方、ずれる失敗、掲載を先に整えること、導線、当日の迎え方、翌日の連絡、イベントが無い時期、分担を整理します。イベントの掲載は[イベントページの作り方](/media/oc-event-page-kihon/)、説明会の掲載は[説明会を掲載するときの書き方](/media/oc-setsumeikai-keisai/)で書きました。

## この作業の目的｜文面で予告した「この回・この人・これ」を、当日そのとおりに渡す

イベントに誘うスカウトを受け取った学生は、「文面に書いてあった人が、文面に書いてあった話をする回」に来ます。

目的は、文面で予告したことを、イベントの掲載と当日と翌日の連絡で、そのとおりに渡すことです。予告と当日がずれると、「文面は釣りだった」となり、ワンキャリアではその印象がイベントの体験談に書かれます。

## スカウトからイベントに誘う利点

| 利点 | なぜ |
|---|---|
| 学生の負担が軽い | 一対一の面談は「自分だけ」で身構える。イベントは他の学生もいる |
| 話す人と内容を、先に見せられる | イベントの掲載に「誰が・何を」がある。文面からそこへ誘導できる |
| 早期の学生に合う | 「仕事を知る会」なら、選考の話をせずに誘える。[ワンキャリアのスカウトを早期に始めるときの進め方](/media/oc-scout-souki/) |
| イベントの体験談が、次のスカウトの材料になる | 「〇〇の回は仕事の話が聞けた」が書かれれば、次の文面で触れられる |

## 文面の4段目を、イベントへの誘いにする

| 要素 | 書き方 |
|---|---|
| この回に | 「〇月の『△△職の最初の1年を話す会』に」。回の名前は、イベントの掲載のタイトルと同じ |
| この人と | 「入社二年目の□□が話します」。イベントの掲載の「誰が話すか」と同じ |
| これを確かめに | 「あなたが書かれていた◇◇の場面と、最初の月の仕事がどう重なるか、直接聞いてもらえたらと思い」。文面の1段目と2段目から |
| 日程と形式 | 「〇日、オンライン、短い時間です。授業に合わせて別の回もあります」 |
| 選考との関係 | 「選考ではなく、仕事を知る場です」。イベントの掲載と同じ。年度の公表内容と自社の方針で確認 |
| 申込の方法 | 「このメッセージに返信してもらえれば、申込の案内を送ります」か、掲載への誘導 |

「回の名前と話す人を、イベントの掲載と同じにする」が要点です。文面で「△△が話す」と書き、掲載で「話す人：人事」だと、学生は迷います。文面の4段の基本は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「スカウトからイベントに誘えば、面談の手間が減って効率が良い」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、効率のためにイベントに誘い、当日が会社説明会で、文面で挙げた話す人が出なかった会社では、スカウト経由の学生の体験談に「スカウトに書いてあった人が出なかった」「会社説明を聞いただけだった」と書かれています。イベントに誘う効率は、文面と当日が揃っていて初めて成り立ちます。当社がスカウトとイベントのつなぎを整えるとき、最初にやるのは、文面の4段目に書く「この人・これ」を、イベントの掲載の「誰が・何を」からそのまま取ることです。文面がイベントの掲載の要約になっていれば、当日はずれません。

## ずれる失敗

| 失敗 | 学生からどう見えるか |
|---|---|
| 文面で挙げた話す人が、当日出ない | 「この人と話せると思った」。体験談に書かれる |
| 文面は「仕事の話」なのに、当日は会社説明会 | 「文面は釣り」 |
| 文面は「選考ではない」なのに、イベントの掲載や当日が選考の扱い | 体験談に「選考だった」 |
| 文面で誘導したイベントが、終わっている・満席 | 信用を失う |
| 文面の回の名前と、イベントの掲載のタイトルが違う | どの回か分からない |
| イベントの申込の方法が、文面から分からない | 受諾したのに申し込めない |
| 当日、スカウト経由の学生と一般の申込の学生を区別せず、文面で触れたことに触れない | 「文面に書いてあったことは、何だったのか」 |
| 翌日の連絡が無い | 「イベントで終わり」 |

最も多いのは、最初の「話す人が出ない」です。文面を書く時点で話す人を決め、当日その人が出る、を守ります。

## イベントの掲載を、先に整える

スカウトからイベントに誘うなら、イベントの掲載が先です。

1. **イベントの掲載に「誰が・何を・何を持ち帰るか・選考との関係」がある**：[イベントページの作り方](/media/oc-event-page-kihon/)
2. **タイトルが「誰が・何を」で付いている**：文面の「この回に」で同じ名前を使う。[イベントページのタイトルの付け方](/media/oc-event-page-title/)
3. **申込の方法が明確**：文面から誘導した先で、迷わない
4. **開催前に、申込を判断できる余裕がある**：直前のスカウトは、学生が申し込めない
5. **企業ページから、そのイベントへの誘導がある**：文面→企業ページ→イベント、の道もつながる。[イベントページと企業トップページの使い分け](/media/oc-event-page-kigyo-top/)

イベントの掲載が整っていない状態でスカウトから誘うと、文面で興味を持った学生が、申込の段階で止まります。

## 受諾から申込までの導線

- **受諾の返信に、申込の案内を添える**：「返信ありがとうございます。〇〇の回の申込はこちらです」。翌日までに
- **申込の方法は一つに**：文面からの返信で申し込めるのか、掲載から申し込むのか。両方あるなら、どちらでもよいと明記
- **申込が完了したら、確認の一言**：「〇日の回で、お待ちしています。当日は△△が出ます」
- **前日に一言**：「明日、〇時に。当日は△△が出ます」
- **申込の締切や満席の扱いを、文面を送る前に確かめる**：誘導した先が閉じていないように

導線の基本は[掲載からエントリーまでの導線設計](/media/oc-entry-douse/)で書きました。スカウトからイベントへの導線は、「受諾→申込→確認→前日→当日→翌日」の流れです。

## 当日、スカウト経由の学生を迎える形

- **スカウト経由の学生が誰かを、話す人と進行する人が知っておく**：申込の一覧に印を
- **文面で触れた場面に、当日触れる**：「スカウトで〇〇の場面に触れましたが、その話を」と、質問の時間に。全員の前で個人の話をしすぎない配慮も
- **文面で挙げた話す人が、文面で予告した内容を話す**：「最初の1年」「選考で何を見るか」
- **選考との関係を、文面と同じ言葉で**：「選考ではありません」と文面に書いたなら、当日も
- **質問の時間を長く取る**：スカウト経由の学生は、文面で持った問いを持って来ている
- **終わったあとの選択肢を、スカウト経由の学生にも同じように**：一対一の話す場、選考、いったん終わる

「文面で触れた場面に、当日触れる」で、スカウトとイベントがつながります。触れないと、学生は「文面は何だったのか」と感じます。

## 翌日の連絡と、その後

1. **翌日までに、一言**：「昨日はありがとうございました。スカウトで触れた〇〇の話、△△が喜んでいました」。スカウト経由の学生には、文面に触れる
2. **次の選択肢を伝える**：一対一の話す場、選考、いったん終わる。「今日決めなくてよい」
3. **一対一の話す場に進むなら、文面で挙げた人が出る**：イベントで話した人と同じ
4. **出た質問を、企業ページの「よく聞かれること」に足す**：イベントは企業ページの材料が集まる場
5. **イベントの体験談が書かれたら、読む**：「スカウトに書いてあった人が出た」「文面どおりだった」があれば、次の文面で触れる
6. **台帳に、スカウト→イベント→その後、を残す**：イベント経由の段を、KPIの表で見る

## イベントが無い時期の扱い

- **イベントの予定が無い時期は、一対一の話す場に誘う**：4段目を「入社二年目の〇〇が、オンラインで話します」に
- **「次のイベントは〇月」と文面に書くなら、その回の掲載が出てから**：予定だけで誘わない
- **年間の計画で、スカウトを送る時期とイベントの時期を揃える**：[ワンキャリアの年間掲載計画の組み方](/media/oc-nenkan-keisai/)
- **早期の時期は「仕事を知る会」、選考の時期は「選考の説明の回」**：文面の4段目を時期で変える

| 作業 | 誰が |

| イベントの掲載を先に整える | 人事（話す人から聞いて） |
| 文面の4段目を、イベントの掲載から取る | 人事（型に） |
| 受諾に申込の案内を添える | 受諾対応の担当 |
| 申込の確認と前日の一言 | 人事 |

| 当日、文面で予告した内容を話し、文面で触れた場面に触れる | 話す人 |
| 翌日の連絡（文面に触れて） | 人事 |
| イベントの体験談を読み、次の文面に反映する | 人事 |

運用代行や代理店が支えられるのは、文面の4段目の型、イベントの掲載との整合の点検、受諾から申込までの導線の設計、当日の迎え方の型、翌日の連絡の型までで、話す人の確保、当日話すこと、申込の対応、翌日の連絡は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと文面と当日がずれることがあります。「文面で挙げる話す人が、その回に本当に出られるか」です。当社がワンキャリアのスカウトとイベントのつなぎを支えるとき、4段目の型とイベントの掲載との整合は当社が点検できますが、「入社二年目の〇〇が話します」と文面に書いた〇〇が、当日に出られるかは、社内の予定です。文面を送ったあとで〇〇が出られなくなると、スカウト経由の学生は「この人と話せると思った」となり、体験談に書かれます。当社が最初にお願いするのは、文面を送る前に、話す人の当日の予定を確かめ、変わる可能性があるなら文面に書かないか、「〇〇か△△が話します」と二人を書くことです。文面で予告した人が出ることが、スカウトとイベントをつなぐ最も基本の条件です。

## まとめ

- スカウトからイベントに誘う利点は、学生の負担が軽い、話す人と内容を先に見せられる、早期の学生に合う、一度に複数と会える
- 文面の4段目は「この回に（掲載と同じ名前）・この人と（掲載と同じ人）・これを確かめに（文面の1段目と2段目から）・日程と形式・選考との関係・申込の方法」
- 話す人が出ない、会社説明会になる、選考との関係が違う、終わった回に誘導、が失敗。イベントの体験談に書かれる
- イベントの掲載を先に整え、受諾→申込→確認→前日→当日→翌日の導線を一つにし、当日は文面で触れた場面に触れ、翌日の連絡でも文面に触れる
- イベントが無い時期は一対一の話す場に誘い、文面を送る前に話す人の当日の予定を確かめる

## よくある質問

### スカウト経由の学生と、一般の申込の学生を、当日どう扱い分ければよいですか

扱いは同じで、話す内容も同じです。違うのは、スカウト経由の学生には、文面で触れた場面に一言触れることです。質問の時間に「スカウトで〇〇の場面に触れましたが」と話す人が言えば、その学生は「文面は本当だった」と感じます。全員の前で個人の話をしすぎない配慮をしつつ、一言は触れます。

### イベントの申込が満席で、スカウトを送った学生が申し込めませんでした

文面を送る前に、申込の締切と枠を確かめます。満席になった場合は、その学生に翌日までに連絡し、別の回か一対一の話す場を案内します。「満席でした」で終わらせると、体験談に「誘われたのに参加できなかった」と書かれます。

### スカウトとイベントのつなぎは、御社に相談できますか

できます。当社は、文面の4段目の型、イベントの掲載との整合の点検、受諾から申込までの導線の設計、当日の迎え方の型、翌日の連絡の型を支えられます。話す人の確保、当日話すこと、申込の対応、翌日の連絡は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
