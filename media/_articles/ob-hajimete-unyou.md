これまで中途採用だけで来て、初めて新卒を採る。経営から「今年は〇名」と人数だけが降りてきて、人事は中途の型でOfferBoxを始め、送っても承認が来ず、承認が来ても中途の面接で「即戦力か」を見て離し、内定を出したあとに入社までの長い期間を放置して辞退される。**結論から言うと、初めての新卒採用の初年度の目標は、「何人採る」ではなく「型を残す」に置きます。最初に決めるのは、新卒を採る理由と育てる人を経営と合意すること、媒体を一つに絞ること、送る数を数通にすること、面接官に中途との違いを伝えること、内定から入社までの長さを前提にフォローを先に決めることです。** この記事では、初めての会社が割ける時間と人、初年度の目標の置き方、最初に決めること、中途との違い、内定後のフォロー、分担、やりがちな失敗を整理します。送る前に揃える五つと最初の月の回し方は[初めての新卒採用でOfferBoxから始めるときの順番](/media/ob-hajimete/)で書きました。この記事は、その前段の「経営と何を合意し、初年度をどう位置づけるか」を扱います。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 採用の経験が中途だけ | 中途の型（職務経歴、即戦力、短い入社までの期間）で新卒を回す |
| 育てる仕組みがない | 「誰が教えるか」に答えられない。入った新卒が放置される |
| 経営との合意が「何名」だけ | 時間と予算と育てる人の合意がなく、人数だけが目標になる |
| 新卒の就職活動の時期を知らない | 中途の感覚で「必要になったら送る」で、時期を逃す |
| 採用サイトに新卒向けの情報がない | 学生が確かめる先に、最初の年の仕事も選考の流れもない |
| 初年度に採れないと「新卒は無理」になる | 型が残らず、翌年もゼロから |

初めての会社がOfferBoxに割ける時間は、中途採用と同じ人事の時間ですが、使い方が違います。中途は「来た応募に対応する」時間で、新卒は「送って、返して、会って、内定から入社まで保つ」時間です。時間の形が違うことを、経営と先に合意します。

## 初年度の目標を、「型を残す」に置く

- **初年度に「何名」を目標にすると、採れなかった年に「新卒は無理」で止まる**：初めての年は、採れるかどうかより、翌年に使える型が残るかで見る
- **残す型**：「こんな人」の一行、検索条件、文面、承認後の連絡、面談の入口、内定後のフォロー、台帳。この七つが残れば、翌年は最初からではない
- **採れたら、その一人が翌年の名義になる**：「新卒で入って、最初の年に何をしたか」を語れる人が社内にできる
- **採れなくても、台帳が残る**：誰に送って、誰が承認して、なぜ辞退したか。翌年の送る相手と文面の元
- **経営に、初年度の目標を「型を残す」で合意してもらう**：人数は「採れたら」で。[経営層にOfferBoxの成果を説明する方法](/media/ob-keiei-rikai/)

### エージェントベストの見解

相談で最も多い思い込みは、「初年度から、中途と同じように人数の目標を置いて採る」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、初めて新卒を採る会社の初年度を多く見ていますが、人数の目標だけで始めた会社は、中途の型で回して承認が来ず、来ても面接で「即戦力か」を見て離し、初年度の終わりに「新卒は難しい」で止まります。止まると、翌年も最初からで、新卒採用が根付きません。当社が初めての会社に最初に合意してもらうのは、人数ではなく、「初年度は型を残す年で、採れたら一人でよい」です。この合意があると、送る数を数通に絞れ、承認した一人に丁寧に向き合え、採れても採れなくても七つの型が残ります。二年目に型を使って採れる会社は、初年度に型を残した会社です。人数から入ると、初年度で終わります。

## 最初に決めること

1. **新卒を採る理由を、経営と一行で合意する**：「中途では採れない〇〇を、ゼロから育てて、△△を任せたい」。「若返り」「勢い」は理由にならない。理由がないなら、中途で足りる
2. **育てる人を、一人、名前で決める**：本業との兼務でよいが、「最初の年に隣で教える人」を決める。決まらないなら、その年は採らない
3. **経営と、人数・時期・予算・時間・育てる人を合意する**：「何名」だけでなく、人事が週に使う時間と、育てる人の時間と、初年度の目標（型を残す）まで
4. **媒体を、一つに絞る**：初年度に複数の媒体を持たない。OfferBoxを主軸にするなら、OfferBoxだけで型を作る。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)
5. **送る数を、数通にする**：初めての年は、承認のあとに何が起きるかを知る年。数通で回る形を確かめてから増やす。[初めての新卒採用でOfferBoxから始めるときの順番](/media/ob-hajimete/)
6. **新卒の就職活動の時期を、先に調べる**：中途の「必要になったら」ではない。送る時期は[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
7. **採用サイトに、新卒向けの「最初の年」「選考の流れ」「条件」を置く**：[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 中途との違いを、社内に伝える

| 中途の型 | 新卒の型 |
|---|---|
| 職務経歴を読んで、即戦力かを見る | 記述の行動を読んで、伸びしろを見る。職務経歴はない |
| 応募が来てから対応する | 企業から送って、承認を待ち、当日に返す |
| 面接で「なぜうちか」を聞く | 面談は文面の続きから。志望動機を求めない。[OfferBox経由の学生を面接する現場社員への説明](/media/ob-genba-mensetsukan/) |
| 内定から入社まで短い | 内定から入社まで長い。放置すると辞退する |
| 条件で決まることが多い | 「最初の年に何をするか」「誰と組むか」で決まる |
| 選考の段が多くてもよい | 段が多いと離れる。[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/) |

- **面接官に、この表を渡す**：中途の感覚のまま新卒を面接すると、「即戦力ではない」で離す
- **名義は、人事ではなく現場の若手**：中途で入った若手でもよい。「会社が送った」にしない。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)。中途向けの文面を流用しない

## 内定から入社までの長さを前提に、フォローを先に決める

- **新卒は、内定から入社まで長い**：中途にはない期間。この間に他社の内定を得て、辞退する
- **フォローの型を、内定を出す前に決める**：連絡の頻度、会う機会、教える人と組む人に会わせる時期。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **承諾の期限を、学生の他社の時期を聞いてから置く**：待つ間に、会う機会を作る
- **内定者に、入社の前に何度か会社に来てもらう**：初めての新卒は、社内にとっても初めて。社員が顔を知る機会
- **辞退の理由を「決め手」まで聞く**：初年度の辞退は、翌年の型の材料。[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 新卒を採る理由の一行と、育てる人の決定 | 経営 |
| 人数・時期・予算・時間・初年度の目標の合意 | 経営と人事 |
| 「こんな人」の一行と検索条件 | 人事と現場の責任者（型は代行が渡す） |
| 検索、文面の下書き、送信、一次返信 | 人事、または代行 |
| 文面の最終確認、名義、面談 | 現場の若手 |
| 面接官に中途との違いを伝える | 人事 |
| 内定後のフォローの型と実行 | 人事と育てる人 |
| 七つの型を文書で残す | 人事（代行と） |

- **初めての会社は、検索・下書き・送信・一次返信を外に出し、人事の時間を「型を残すこと」と「経営との合意」に使う**：[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **初めての会社が代理店に頼める範囲**：[初めての新卒採用でOfferBoxから始めるときの順番](/media/ob-hajimete/)の「代理店に頼める範囲」

運用代行や代理店が支えられるのは、七つの型の下書き、経営との合意の材料の整理、検索・下書き・送信・一次返信、内定後のフォローの型までで、新卒を採る理由、育てる人の決定、経営との合意、面談、内定後の連絡は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

内定を出したあと、初めての年で起きることに共通するのは、内定から入社までの長い期間を中途の感覚で放置し、その間に学生が他社に決めて辞退されることです。当社はOfferBoxの運用代行を受けているので、初めて新卒を採った会社の内定後を見ていますが、中途採用では内定から入社まで短く、放置しても問題が起きなかった会社が、新卒でも同じようにして、数か月後に「辞退の連絡が来た」と相談に来ます。新卒の内定から入社までの期間は、会社にとっては待つ時間ですが、学生にとっては比べ続ける時間です。当社が初めての会社に、内定を出す前に決めてもらうのは、「内定から入社まで、月に一度は連絡し、教える人と組む人に会ってもらい、入社の前に何度か来てもらう」の型です。型があれば、初めての一人が入社まで残り、その一人が翌年の名義になります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 初年度から人数の目標だけで始める | 採れないと「新卒は無理」で止まり、型が残らない | 初年度は「型を残す」に |
| 育てる人を決めずに採る | 入った新卒が放置され、辞める | 名前で一人決める |
| 中途の型で新卒を回す | 承認が来ず、面接で「即戦力か」で離す | 中途との違いの表を社内に |
| 初年度に複数の媒体を持つ | どの型も残らない | 一つに絞る |
| 内定から入社まで放置する | 他社に決めて辞退される | フォローの型を先に |

最も多いのは、一つ目です。中途と同じ感覚で「何名」から始め、初年度の位置づけが「型を残す年」になっていません。

## まとめ

- 初めての新卒採用の初年度は、「何人採る」ではなく「型を残す」年。七つの型（こんな人・検索条件・文面・承認後の連絡・面談の入口・内定後のフォロー・台帳）が残れば、翌年は最初からではない
- 新卒を採る理由を一行で、育てる人を名前で、経営と合意する。人数だけでなく、時間・予算・初年度の目標まで
- 媒体は一つに絞り、送る数は数通。新卒の就職活動の時期を先に調べ、採用サイトに新卒向けの情報を置く
- 中途との違い（記述の行動、企業から送る、志望動機を求めない、入社まで長い）を表にして面接官に渡す。名義は現場の若手
- 内定から入社までの長さを前提に、フォローの型を内定を出す前に決める。辞退の理由を「決め手」まで聞いて翌年の型に

## よくある質問

### 経営が「初年度から〇名」と言っています。どう説明しますか

「初年度は、採れるかどうかより、翌年に使える型が残るかで見たい。採れたら一人でよく、採れなくても七つの型と台帳が残れば、二年目に人数を置ける」と説明します。中途と新卒の時間の形の違いの表を添えると、人数だけの目標が初年度には合わないことが伝わります。[OfferBoxの運用方針を上司に納得してもらう資料の作り方](/media/ob-joushi-nattoku/)

### 中途で入った若手しかいません。名義にしてよいですか

してよいです。「私は中途で入りましたが、〇〇の担当で、最初の年に△△をしました」と、入り方を隠さず書きます。学生が知りたいのは「新卒で入ったか」より「この人と働くか」「最初の年に何をするか」です。翌年、初めての新卒が入れば、その人が名義になります。

### 初めて新卒採用をする会社のOfferBox運用は、御社に相談できますか

できます。当社は、七つの型の下書き、経営との合意の材料の整理、検索・下書き・送信・一次返信、内定後のフォローの型を支えられます。新卒を採る理由、育てる人の決定、経営との合意、面談、内定後の連絡は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
