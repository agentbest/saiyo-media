ワンキャリアのスカウトを使い始めるとき、多くの担当者は文面の書き出しから考えます。ところが、最初の一通を書こうとすると、「誰に送るのか」「何に誘うのか」「返信が来たら誰が返すのか」が決まっていないことに気づき、手が止まります。**結論から言うと、最初のスカウトを書く前に決めるのは「誰に送るか」「どこに誘うか」「返信を誰が受けるか」「文面のどこを固定し、どこを学生ごとに書くか」の四つです。** 四つが決まっていれば、一通目は短い時間で書け、二通目以降も同じ形で続けられます。この記事では、四つを決める順番と、送る前に確かめる受け皿、最初に送る数の考え方を整理します。文面の書き方そのものは[スカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。スカウトの機能や条件はプランや時期で変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜一通目を「続けられる型」の最初にする

最初のスカウトは、一通で終わりません。同じ考え方で何十通と送ることになります。一通目を思いつきで書くと、二通目で迷い、三通目で別の書き方になり、学生ごとに誘い先や約束がばらばらになります。

目的は、一通目を書く前に判断を済ませ、一通目を「続けられる型」の最初にすることです。ワンキャリアの学生は、スカウトを受け取ったあと、企業ページと体験談で確かめに来ます。誘い先や約束がばらばらだと、体験談に「スカウトで言われたことと違った」と書かれます。

## 決めることは四つ

| 決めること | 中身 | 決めないと起きること |
|---|---|---|
| 1. 誰に送るか | 採る職種ごとの、送る学生の状態 | 条件だけで絞り、文面が誰にも合わない |
| 2. どこに誘うか | 話す場か、イベントか、選考か | 「ぜひ一度」で終わり、学生が次の動きを決められない |
| 3. 返信を誰が受けるか | 窓口の人、返す目安、日程の出し方 | 返信が来てから慌て、返すのが遅れる |
| 4. 固定と個別の分け方 | 型に入れる部分と、学生ごとに書く部分 | 全部を一から書いて続かないか、全部を型にして一斉送信に見える |

この順番で決めます。誰に送るかが決まらないと誘い先が決まらず、誘い先が決まらないと返信の受け方も決まりません。

## 1. 誰に送るか｜条件より「話したい理由」で決める

検索の条件から考えると、大学、学部、地域の組み合わせで絞ることになります。条件は入口として使いますが、送るかどうかは、プロフィールを読んで決めます。

- **職種ごとに、最初の仕事を一行にする**：入社して最初に何をするか
- **その仕事と重なる学生時代の状態を書き出す**：何を続けてきた人なら、その仕事を面白がれそうか
- **プロフィールを読んで、「この学生に、この仕事の話をしたい」と言えるかで決める**：言えないなら送らない
- **読める数だけ送る**：読まずに送る数を増やさない

プロフィールの読み方は[学生プロフィールの読み方](/media/oc-scout-profile/)にまとめています。

## 2. どこに誘うか｜一つに決めて文面に書く

誘い先は、学生が次に何をすればよいかが分かる一つにします。

| 誘い先 | 向く場面 | 文面に書くこと |
|---|---|---|
| 話す場（面談） | まず仕事の話を聞いてほしいとき | 選考ではないこと、誰が話すか |
| イベント | 同じ回に複数の学生を誘うとき | 回の日程、誰が出て何を話すか |
| 選考 | 選考への案内として送るとき | 選考の流れ、最初の段階で見ること |

話す場に誘うなら、選考ではないことを文面と実際の運用で揃えます。体験談で「面談と書かれていたのに選考だった」と書かれると、翌年の学生が警戒します。誘い先は、年度の公表内容と自社の方針に沿って決めます。

### エージェントベストの見解

これは順番の話です。スカウトを申し込んだあと、最初の月で運用が止まる会社に共通するのは、文面は用意できているのに、誘い先の受け皿が整っていないことです。面談に誘う文面を送り、受諾が来てから「面談には誰が出るのか」を社内で決め始める。その間に、学生は他社の面談に進みます。当社が勧めるのは、一通目を送る前に、誘い先の受け皿の予定を先に押さえることです。面談に誘うなら、面談に出る人の空いている時間を週単位で二つか三つ押さえる。イベントに誘うなら、回の日程とイベントページを先に出しておく。受け皿が先にあれば、受諾が来たその日に日程を返せます。文面の出来よりも、受諾のあとの速さが、ワンキャリアでは体験談に残りやすいところです。

## 3. 返信を誰が受けるか

返信が来てから決めると、返すのが遅れます。送る前に次を決めます。

- **窓口の人**：返信に最初に返す人を一人に決める。不在のときの代わりも
- **返す目安**：受諾や質問が来たら、いつまでに返すか
- **日程の出し方**：こちらから候補を出すか、学生に選んでもらうか
- **記録の置き場**：誰に送り、誰から返信があり、どう返したか

受諾後の進め方は[スカウト受諾後の進め方](/media/oc-scout-judaku-go/)で書きました。

## 4. 固定と個別の分け方

文面は、全部を一から書くと続きません。全部を型にすると、一斉送信に見えます。固定する部分と、学生ごとに書く部分を分けます。

| 固定する部分 | 学生ごとに書く部分 |
|---|---|
| 仕事の最初の1年の説明 | プロフィールの何を読んだか |
| 選考の流れと各段階で見ることの一文 | その学生の経験と仕事の重なり |
| 誘い先の案内と日程の出し方 | （必要なら）その学生への問いかけ |
| 署名と問い合わせ先 | |

学生ごとに書く部分は、多くて二か所に絞ると続けやすくなります。個別化の考え方は[スカウト個別化](/media/oc-scout-kojinka/)にまとめています。

## 送る前に確かめる受け皿

四つを決めたら、送る前に受け皿を確かめます。

1. **企業ページ**：選考の流れと各段階で見ること、仕事の最初の1年が書かれているか
2. **自社の体験談**：何が書かれているかを読んでいるか。スカウトの文面と食い違わないか
3. **誘い先の予定**：面談に出る人の時間、イベントの日程が押さえてあるか
4. **窓口**：返信を受ける人が、送る日に対応できるか

一つでも欠けていれば、送るのはそれを整えてからにします。

## 最初に送る数の考え方

最初の週は、送る数を少なめにします。理由は、返信のあとの流れを一度通して試すためです。返信が来て、日程を返し、面談をして、記録を残す。この流れが一度回れば、次の週から数を増やせます。最初から多く送ると、受諾が重なったときに受け皿が足りなくなります。数の配分は[スカウト通数の配分](/media/oc-scout-tsuusuu-haibun/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 誰に送るか、誘い先を決める | 人事と、配属先の責任者 |
| 固定する部分の文面を書く | 人事 |
| プロフィールを読み、個別の部分を書く | 人事、または現場の若手 |
| 返信を受け、日程を返す | 窓口の一人 |
| 面談に出る | 現場の社員 |

外に出せるのは、文面の型づくり、プロフィールを読んで個別の部分を書く作業、配信までです。誰に送るかの判断、誘い先の受け皿、面談は社内に残ります。代行に出す範囲は[スカウト代行の線引き](/media/oc-scout-daikou/)にまとめています。

### エージェントベストの見解

3媒体を扱っている立場から言うと、最初のスカウトを書く前に決める四つは、OfferBoxでもワンキャリアでも同じです。違いが出るのは、四つのうちどこに時間をかけるかです。OfferBoxは、オファーを受け取ることを前提に登録している学生が多い媒体なので、誰に送るかと、学生ごとに書く部分に時間をかけると反応が変わりやすい。ワンキャリアは、スカウトを読んだ学生が企業ページと体験談で確かめに来る媒体なので、誘い先と受け皿、つまり文面の外側に時間をかける必要があります。両方を使う会社が、OfferBoxで作った文面をそのままワンキャリアで送ると、文面は届いても、確かめに行った先で離れることがあります。どちらを先に使うか迷っている段階なら、社内で書ける時間と、企業ページを整える時間のどちらが取れるかで決めるのが、あとで運用が止まりにくい選び方です。

## まとめ

- 最初のスカウトの前に、誰に送るか、どこに誘うか、返信を誰が受けるか、固定と個別の分け方の四つを決める
- 誰に送るかは、条件ではなく「この学生にこの仕事の話をしたい」と言えるかで決める
- 誘い先は一つに決め、文面と実際の運用で揃える
- 送る前に、企業ページ・体験談・誘い先の予定・窓口の受け皿を確かめる
- 最初の週は少なめに送り、返信から面談までの流れを一度通す

## よくある質問

### 最初の一通は、誰が書くのがよいですか

固定する部分は人事が書き、学生ごとに書く部分は、その仕事を知っている人が書くのが向いています。現場の若手が書くと、仕事の重なりが具体的になりやすいです。ただし、誘い先と約束の部分は人事が揃えます。

### 返信が来なかったら、文面を変えるべきですか

最初の数週は、文面を変える前に、誰に送ったかと、プロフィールを読んで送れていたかを見直します。直す順番は[スカウト文面を直す順番](/media/oc-sd-scout-shuusei/)で書きました。

### 最初のスカウトの準備は、御社に相談できますか

できます。当社は、四つを決める順番の整理、文面の固定部分の型、受け皿の確かめ方、最初に送る数の考え方を支えられます。誰に送るかの判断と、面談に出ることは企業が行ってください。当社は求人広告代理店として、媒体選びから運用までを支えています。
