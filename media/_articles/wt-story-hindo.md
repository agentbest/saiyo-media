「ストーリーは月に何本書けばいいのか」という質問を受けます。目安が欲しい気持ちは分かりますが、本数を先に決めると、最初の月に多く書いて息切れするか、目標に届かずに止まるかのどちらかになります。**結論から言うと、更新頻度は「本数の目標」ではなく「途切れない頻度」で決めます。週に拾える1行の数と、書ける人の時間から、無理なく続く本数を置き、最初は少なく始めて、続く数に合わせて増やします。月に数本が目安ですが、月に1本でも途切れないほうが、月に5本で3ヶ月止まるより、会社ページに人を呼びます。** この記事では、頻度の考え方、決め方、時期による増減、途切れたときの立て直し、頻度を守る仕組み、見直しの仕方、やりがちな失敗、分担を整理します。ネタを集める仕組みは[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)、ストーリーの位置づけは[ストーリーの基本](/media/wt-story-kihon/)で書きました。

## この作業の目的｜「途切れない」を、頻度の基準にする

ストーリーの役割は、候補者が会社ページに来る理由を作り続けることです。「作り続ける」なので、1本の重さより、続くことが効きます。

途切れると、会社ページに来る理由が無くなり、募集記事も動かなくなります。途切れたあとに再開しても、途切れていた期間の分は戻りません。だから、頻度の基準は「途切れないこと」で、「何本書くか」はその結果です。

本数を目標にすると、目標に届かない月に「もう無理だ」となり、止まります。途切れないことを目標にすると、少ない月があっても、続きます。

## 手順1｜集められる材料と、書ける時間から決める

頻度は、2つの上限で決まります。材料の数と、書く時間です。

| 上限 | 確かめ方 | 頻度への影響 |
|---|---|---|
| 週に拾える1行の数 | 集める仕組みで、月に何個の1行が溜まるか | 溜まる数が、書ける本数の上限 |
| 書ける人の時間 | 人事が月に何時間、ストーリーに使えるか。1本を聞いて書くのに要る時間で割る | 時間が、書ける本数の上限 |
| 話してくれる人の数 | 社員インタビューや入社エントリーは、話す人が要る。頼める人が月に何人いるか | 型によって上限が変わる |
| 確認する人の時間 | 代表や本人の確認にかかる時間。遅れると公開されない | 確認の期限を決めて、上限に含める |

4つのうち、最も小さい上限が、続く頻度です。材料は月に5個溜まっても、書く時間が2本分しか無ければ、続くのは2本です。

「月に数本」は目安であって、自社の上限で決めます。1本でも途切れなければ、続いています。

## 手順2｜最初は少なく始めて、続く数に合わせる

最初の月から上限いっぱいに書くと、翌月に息切れします。

1. **最初の月は、上限より少なく**：会社ページの公開と同時に1本、その月にもう1本、程度から
2. **3ヶ月続いたら、上限まで増やすかを見る**：3ヶ月続けば、材料と時間の実態が分かる
3. **増やしたあとに続かなければ、戻す**：戻すことは失敗ではない。途切れるほうが失敗
4. **続く数が分かったら、それを頻度として固定する**：「月に〇本」を、上限ではなく実績で置く
5. **固定した頻度を、締切として運用する**：締切の決め方は手順5で

「最初は少なく」は、OfferBoxで「送る数は面談枠から逆算し、最初の月で置き直す」と書いたのと同じ考え方です。仮で置いて、実績で直します。

### エージェントベストの見解

媒体を比べたり運用を見直したりするときに、「ストーリーは月に何本が目安か」と聞く会社は多いのですが、当社は本数を目安として答えないようにしています。理由は、本数を伝えると、その本数が目標になり、届かない月に止まるからです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、ストーリーが続いている会社と止まった会社の違いは、本数ではなく、途切れたかどうかです。月に1本を1年続けた会社は、会社ページに人が来続けています。最初の月に5本書いて、翌月から止まった会社は、来ません。当社が聞くのは「何本書きたいか」ではなく、「週に何個の1行が拾えて、月に何時間書けるか」です。その答えから、続く本数を一緒に置きます。本数は、決めるものではなく、上限から出てくるものです。

## 手順3｜時期で増減する

年間を通して同じ頻度である必要はありません。募集の時期で増減します。

| 時期 | 頻度 | 書く型 |
|---|---|---|
| 募集記事を出す前 | 少し増やす | 募集する職種の社員の話、事業の裏側。募集記事から誘導する先を用意する |
| 候補者が動く時期 | 続く頻度を守る | 募集記事を補う型を中心に |
| 内定から承諾までの時期 | 続く頻度を守る | 入社の話、カルチャー。内定者が読む前提で |
| 募集が無い時期 | 減らしてよい。ただし止めない | 代表の考え、出来事。月に1本でも |
| 繁忙期で書く時間が無い時期 | 減らす。ただし止めない | 短い記事でも。1行を膨らませた程度でも |

「減らしてよいが、止めない」が要点です。募集が無い時期に止めると、次の募集の前に会社ページに来る人がいなくなり、募集記事を出しても動きません。時期の考え方は[ストーリーのテーマの決め方](/media/wt-story-theme/)でも書きました。

## 手順4｜途切れたときの立て直し

途切れることはあります。途切れたときの立て直し方を、先に決めておきます。

1. **途切れた理由を1つに絞る**：材料が無かったか、書く時間が無かったか、確認が止まったか、書き手がいなくなったか
2. **理由に対処する**：材料なら拾う仕組みを再開、時間なら頻度を下げる、確認なら期限の合意、書き手なら増やす（増やし方は[ストーリーの書き手を社内で増やす方法](/media/wt-story-kakite/)）
3. **再開の1本は、短く、すぐ出せるものにする**：拾ってある1行を膨らませた程度でよい。「久しぶりの大作」を目指さない
4. **途切れたことを記事で謝らない**：候補者は途切れていたことを気にしていない。普通に再開する
5. **再開後は、途切れる前より低い頻度で固定する**：同じ頻度に戻すと、また途切れる

「再開の1本を短く」が、立て直しの要点です。途切れたあとに「しっかりした記事で再開しよう」とすると、再開が遅れます。

## 手順5｜頻度を守る仕組み

頻度は、意志ではなく仕組みで守ります。

| 仕組み | 内容 |
|---|---|
| 候補リスト | 数本先までテーマが決まっている状態。書く時間に「何を書くか」から始めない。作り方はテーマの決め方の記事で |
| 締切 | 「毎月〇日に1本公開」のように、日で固定する。「時間があるときに」は無いのと同じ |
| 拾う曜日 | 週に一度の1行を拾う曜日を固定する。材料が途切れなければ、頻度は守りやすい |
| 確認の期限 | 本人と代表の確認に期限を置き、過ぎたら人事の判断で公開する合意 |
| 短い記事の型 | 時間が無い月に出せる、1行を膨らませた短い記事の型を持っておく |
| 記録 | いつ何を出したかを記録し、途切れかけたら気づけるようにする |

「短い記事の型」は、頻度を守る保険です。時間が無い月に、短い記事でも1本出せれば、途切れません。

## 手順6｜頻度の見直し｜閲覧ではなく、来た人の言葉で

頻度が合っているかは、閲覧の数ではなく、話を聞きに来た候補者の言葉で見ます。

- **面談で「どのストーリーを読みましたか」と聞く**：読まれている記事の型と、読まれていない型が分かる
- **読まれている型を、頻度の中で増やす**：本数を増やすのではなく、配分を変える
- **「最近の記事」が読まれているなら、頻度は足りている**：古い記事しか読まれていないなら、新しい記事が少ないか、届いていない
- **閲覧の数で頻度を変えない**：閲覧はイベントの記事で増え、候補者は来ない。閲覧で判断すると、イベントの記事が増える。注意は[社内イベントを書くときの注意](/media/wt-story-event/)
- **数ヶ月に一度、頻度と配分を見直す**：毎月変えない

「本数を増やす」より「配分を変える」が、見直しの中心です。同じ本数でも、読まれる型に寄せれば、会社ページに来る人は増えます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 本数の目標を先に決める | 届かない月に止まる | 途切れないことを基準に |
| 最初の月に多く書く | 翌月に息切れ | 最初は少なく |
| 材料と時間を見ずに頻度を決める | 続かない | 上限から決める |
| 募集が無い時期に止める | 次の募集の前に人が来ない | 減らしても止めない |
| 途切れたあとに大作で再開しようとする | 再開が遅れる | 短く再開 |
| 頻度を意志で守ろうとする | 忙しい月に途切れる | 候補リスト、締切、短い記事の型 |
| 閲覧で頻度を変える | イベントの記事が増える | 来た人の言葉で |
| 毎月頻度を変える | 何が効いたか分からない | 数ヶ月に一度 |

最も多いのは、最初の「本数の目標を先に決める」です。目標があると安心しますが、その目標が止まる原因になります。

| 作業 | 誰が |

| 続く頻度を置き、締切を固定する | 人事 |

| 書く | 人事（書き手が増えれば分担） |
| 確認の期限を守る | 本人、代表 |

運用代行や代理店が支えられるのは、上限から頻度を置く型、候補リストと締切の型、短い記事の型、拾った1行を記事に膨らませる下書きまでで、拾うことと確認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと頻度が守れないことがあります。「時間が無い月に出せる、短い記事の型」を持っておくことです。当社がWantedlyの運用の相談で「ストーリーが止まった」と聞くとき、止まった月を聞くと、繁忙期か、担当が別の業務で埋まった月です。その月に「いつもの長さの記事」を書こうとして、書けずに止まっています。当社が勧めるのは、拾ってある1行を数段落に膨らませただけの短い記事の型を用意しておき、時間が無い月はそれを出すことです。短くても、出れば途切れません。途切れなければ、翌月にいつもの長さに戻せます。頻度を守るのは、毎月同じ長さの記事を書くことではなく、毎月何かを出すことです。短い記事の型は、そのための保険です。

## まとめ

- 更新頻度は本数の目標ではなく「途切れないこと」で決める。月に1本でも途切れないほうが、月に5本で止まるより効く
- 週に拾える1行の数、書ける人の時間、話してくれる人の数、確認の時間、の最も小さい上限が続く頻度
- 最初は少なく始め、3ヶ月続いたら増やすかを見て、続く数で固定する
- 募集の時期で増減するが、募集が無い時期も止めない。途切れたら短い記事で再開し、前より低い頻度で固定する
- 候補リスト・締切・拾う曜日・確認の期限・短い記事の型・記録で頻度を守る。見直しは閲覧ではなく来た人の言葉で、数ヶ月に一度

## よくある質問

### 月に何本が目安ですか

目安は「月に数本」ですが、自社の材料と時間の上限で決まります。月に1本でも途切れなければ続いています。本数を目標にすると、届かない月に止まるので、「途切れないこと」を目標にし、本数はその結果として置くことを勧めます。

### 繁忙期で、ストーリーに使う時間がありません

時間が無い月は、拾ってある1行を数段落に膨らませた短い記事を1本出します。短くても出れば途切れず、翌月にいつもの長さに戻せます。繁忙期の前に、短い記事の型を用意しておくと、その月に迷いません。

### 更新頻度の設計は、御社に相談できますか

できます。当社は、材料と時間の上限から続く頻度を置く型、候補リストと締切の型、短い記事の型、拾った1行を記事に膨らませる下書きを支えられます。拾うことと、確認は企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのストーリーの整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
