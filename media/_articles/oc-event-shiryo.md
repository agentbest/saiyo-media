ワンキャリアのイベントで使う資料を作りたい。ところが、枚数が多く、会社紹介の資料を流用し、当日は読み上げ、文字が多く、数字を確認せずに載せ、体験談と揃っておらず、資料から作り始めて話すことが増え、配布資料は会社案内。**結論から言うと、資料は「話の目印」で、読み上げるものでも、会社を説明するものでもありません。話す人ごとに数枚、会社の概要のページは入れず「企業ページをご覧ください」の一枚だけ、一枚に一つの場面、数字は確認した事実だけ、文字より話す人の顔。資料を先に作らず、話す人と場面を決めてから作ります。配布は「持ち帰るもの」（企業ページ・次の場・よく聞かれること）の一枚で。** この記事では、資料で起きる失敗、役割、作る順番、話す人ごとの枚数と中身、会社の概要の扱い、一枚に一つの場面、数字、オンラインとオフライン、配布する一枚、更新、分担を整理します。構成の作り方は[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)、動画は[ワンキャリアで動画を使う方法](/media/oc-douga/)、企業ページは[ワンキャリアの企業ページの基本](/media/oc-kigyo-page-kihon/)で書きました。

## この作業の目的｜資料を「話の目印」にして、話す人の言葉を残す

ワンキャリアの学生は、体験談と企業ページを読んで来ます。資料に会社の概要が書かれていても、それは企業ページで読んだことです。学生が回で聞きたいのは、資料に書かれた文字ではなく、話す人の言葉で語られる「一つの場面」です。資料は、その場面を話すための目印で、主役ではありません。

目的は、資料を「読み上げる原稿」でも「会社案内」でもなく、「話す人が一つの場面を話すための目印」として、最小限で作ることです。

## 資料で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 枚数が、多い | 枚数の分だけ話したくなり、話す時間が延び、質問の時間が消える |
| 会社紹介の資料を、流用する | 企業ページに書いてあることを、画面で繰り返す。「企業ページで読んだ」と体験談に残る |
| 読み上げる | 話す人の言葉にならず、顔が資料に向く。オンラインでは特に離脱する |
| 文字が、多い | 学生が文字を読み、話を聞かない。話す人が文字を追う |
| 数字を、確認せずに載せる | 古い数字、誤った数字が、体験談に残る |
| 体験談と、揃っていない | 資料に「〇〇」と書き、体験談に「△△だった」とあれば、「違う」と読まれる |
| 資料から、作り始める | 作った資料の分だけ話すことが増え、構成が資料に引きずられる |
| 配布資料が、会社案内 | 持ち帰っても読まれない。持ち帰るべきは、企業ページと次の場の導線 |

共通するのは、資料を「回の主役」として作り、「話の目印」として作っていないことです。

## 資料の、役割

- **話の目印**：話す人が、次に何を話すかを思い出すため
- **場面の補助**：一つの場面を、写真一枚や図一つで見せる
- **企業ページへの導線**：「詳しくは企業ページに」を示す
- **役割でないもの**：会社の説明、原稿、読み上げるもの、持ち帰って読ませるもの
- **資料がなくても回が成り立つか、で確かめる**：成り立たないなら、資料が主役になっている

### エージェントベストの見解

相談で最も多い思い込みは、「資料を丁寧に作るほど、イベントの質が上がる」というものです。当社はワンキャリアの販売パートナーとして、イベントの資料の相談を受けていますが、丁寧に作り込んだ資料の回は、話す人が資料を読み上げ、枚数の分だけ話が延び、質問の時間が消え、体験談に「資料を読んでいた」「長かった」と残っています。逆に、話す人ごとに数枚、一枚に一つの場面、会社の概要は一枚だけ、の資料の回は、話す人が自分の言葉で話し、質問の時間が残り、「社員の話が聞けた」と残っています。資料の質と回の質は、比例しません。資料が薄いほど、話す人の言葉が前に出ます。当社が資料の相談を受けるとき、最初にやるのは、資料の枚数を減らし、会社の概要のページを抜くことです。

## 作る、順番

1. **自社の体験談を読み、学生が確かめたいことを書き出す**
2. **話すことを二つに絞り、話す人を決める**：[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)
3. **話す人ごとに、「一つの場面」を決める**：本人に聞く
4. **場面ごとに、目印の一枚を作る**：写真一枚か、図一つか、一行
5. **「企業ページをご覧ください」の一枚を作る**
6. **配布する「持ち帰るもの」の一枚を作る**
7. **通しで、資料なしで話せるかを確かめる**：話せなければ、資料が主役になっている

「4」が資料の本体で、「1」から「3」の後です。資料から始めません。

## 話す人ごとの、枚数と中身

| 話す人 | 枚数の目安 | 中身 |
|---|---|---|
| 面接に出る人（選考で何を見ているか） | 一枚か二枚 | 選考の流れの図一つ。「各段階で見ていること」を一行ずつ |
| その職種の入社してまもない社員（最初の一年） | 一枚か二枚 | 最初の一年の場面の写真一枚か、一日の流れの図一つ |
| 人事（宣言・進行・次の場） | 二枚 | 「会社の概要は企業ページに」の一枚、次の場の案内の一枚 |
| 座談会の出る社員 | なし | 資料なしで、自分のことを話す。[ワンキャリアの座談会の企画の立て方](/media/oc-zadankai/) |

合計で数枚です。枚数の具体は自社の実態で。多くなったら、「この一枚がなくても話せるか」で削ります。

## 会社の概要は、一枚だけ

- **「会社の概要は企業ページに書いてあります」の一枚**：企業ページの導線を示す
- **沿革・事業・規模・理念のページを、入れない**：企業ページで読める
- **一言で「何をしている会社か」**：一枚の中に一文
- **会社紹介の資料を流用するなら、この一枚に絞る**：残りは使わない
- **考え方は[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)の「話すことを、二つに絞る理由」**

## 一枚に、一つの場面

- **一枚に、一つの場面だけ**：「最初の一年」なら、その中の一つの場面の写真か図
- **文字は、一行か二行**：話す人が見て思い出せる程度。学生に読ませない
- **写真は、その場面の実際**：飾らない。[ワンキャリアの掲載の写真](/media/oc-keisai-shashin/)
- **図は、一つ**：選考の流れ、一日の流れ。複雑にしない
- **抽象語を、載せない**：「成長」「裁量」「やりがい」は、場面ではない

## 数字の、扱い

- **載せるなら、自社で確認した事実だけ**：採用人数、社員数、制度の数字は、管理部門で確認
- **確認していない数字は、載せない**：古い数字、推測の数字は、体験談に残る
- **数字より、場面**：「若手が多い」より「入社した年に〇〇を担当した」
- **体験談に書かれた数字と、揃える**：体験談で「面接は〇回」とあれば、資料も同じ。違うなら体験談か資料のどちらかが古い
- **条件の数字は、企業ページに**：資料には「企業ページに」

## オンラインとオフラインでの、違い

- **オンライン**：画面共有は最小限、顔を出す。資料の文字は画面で読まれるので、さらに少なく。[ワンキャリアのオンラインイベントの進め方](/media/oc-online-event/)
- **オフライン**：資料より、職場と社員。資料は目印の数枚だけで、対話の時間に使う。[ワンキャリアのオフラインイベントの進め方](/media/oc-offline-event/)
- **どちらも、資料なしで話せる状態を先に作る**：資料は補助

## 配布する、「持ち帰るもの」の一枚

- **企業ページと体験談への導線**：「回で話したことは、企業ページの〇〇に」
- **次の場の案内**：日程、申込の導線。当日に申し込める形
- **よく聞かれることと、事実の答え**：回で出やすい質問。条件は「企業ページに」
- **出た社員の名前と、面談で会えること**
- **会社案内を配らない**：持ち帰っても読まれない。企業ページで読める
- **一枚の中身は、回の後の一通と揃える**：[ワンキャリアのイベント後のフォロー](/media/oc-event-follow/)

## 更新

- **出た質問で、目印の一枚を直す**：同じ質問が続けば、その場面を足す
- **話す人が変わったら、その人の場面で作り直す**：前の人の資料を読ませない
- **体験談が書かれたら、資料と揃っているかを確かめる**：「違った」と書かれた項目を直す
- **数字は、年度の切れ目に確認し直す**
- **企業ページの更新と、同じ時期に**：[ワンキャリアの企業ページの更新](/media/oc-kigyo-page-koushin/)

### エージェントベストの見解

これは順番の話です。資料の相談で、「まず資料を作って、それを見ながら構成を考えたい」と言われることがあります。当社がお願いする順番は、体験談を読む、話すことを二つに絞る、話す人を決める、話す人が一つの場面を決める、そして最後に目印の一枚を作る、です。資料から作ると、作った枚数の分だけ話すことが増え、話す人が資料に合わせて話し、自分の言葉でなくなります。話す人と場面から作ると、目印は数枚で足り、話す人の言葉が前に出ます。当社は、資料の相談で、資料を見る前に、「誰が、どの場面を話しますか」を聞きます。資料は、その答えの後で作ります。

## まとめ

- 資料は「話の目印」で、読み上げる原稿でも会社案内でもない。資料がなくても回が成り立つ状態を先に作る
- 作る順番は、体験談→二つに絞る→話す人→一つの場面→目印の一枚。資料から始めると、話すことが増え、話す人の言葉が消える
- 話す人ごとに数枚、一枚に一つの場面、文字は一行か二行、写真は実際の場面、図は一つ。会社の概要は「企業ページをご覧ください」の一枚だけで、会社紹介の資料は流用しない
- 数字は自社で確認した事実だけ、数字より場面、条件は企業ページに。体験談と揃える
- 配布は「持ち帰るもの」の一枚（企業ページと体験談への導線・次の場・よく聞かれること・出た社員）で、会社案内を配らない。出た質問と体験談と話す人の交代で更新する

## よくある質問

### 経営層が「会社紹介の資料をきちんと使ってほしい」と言います

会社紹介の資料は、企業ページに書いてあることを画面で繰り返すもので、体験談を読んで来た学生には「企業ページで読んだ」になります。経営層には、「会社紹介は企業ページで読まれていて、回では『企業ページをご覧ください』の一枚で導線を示す。回の時間は、企業ページで読めない『社員の言葉』に使う」と、回の目的から説明します。会社紹介の資料は、企業ページの材料として使い、回では一枚に絞ります。

### 話す社員が「資料がないと不安」と言います

目印の一枚か二枚は作ります。「資料なし」ではなく、「読み上げる資料なし」です。一枚に、その社員の一つの場面の写真と、一行の目印。それを見て、自分の言葉で話す形にすると、不安は減り、読み上げになりません。原稿を書いて渡さないことが要点で、原稿があると読み上げます。頼み方は[ワンキャリアのイベントに出る社員の選び方](/media/oc-event-tantou/)の「頼み方」で書きました。

### イベントの資料の作り方は、御社に相談できますか

できます。当社は、資料の役割の整理、作る順番の型、枚数と中身の型、持ち帰る一枚の型、数字の扱いの整理を支えられます。体験談を読むこと、場面の決定、資料を作ること、数字の確認、話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
