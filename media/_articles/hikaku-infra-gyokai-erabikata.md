電力、ガス、鉄道、通信、水道、またはその工事や保守を担う会社が、新卒を採る。学生は「インフラは安定している」で来るが、入ってから「現場が多い」「転勤がある」「夜勤がある」「地方の勤務地だった」で離れる。媒体を選ぶときに「安定志向の学生が集まる媒体はどれか」で考えがちですが、学生が確かめているのは、安定の言葉ではなく、現場と転勤と夜勤と地方の実態です。**結論から言うと、インフラ業界の学生は「安定」で来て、「現場・転勤・夜勤・地方」の実態を確かめて離れます。媒体の選び方は、地域で知られた大手なら学生が並べて比べる場を先に、技術職なら専攻で絞って送る型を、知られていない工事・保守の会社なら送る型か記事を置く型を先に検討します。どの媒体でも、実態を隠さない見せ方が媒体より先です。** この記事では、インフラ業界の採用構造、判断軸の当て方、学生が確かめること、知名度と職種でどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## インフラ業界の採用構造と、媒体との相性

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 学生が「安定」で来る | 安定の中身（雇用、異動、評価）を確かめず、実態で離れる | 実態を書ける媒体の使い方が要る |
| 現場、転勤、夜勤、地方の勤務地がある | 文面と記事に書かないと、面談か入社後に分かる | 隠さず書く。書ける形にする |
| 技術職（電気、土木、機械、通信）と総合職に分かれる | 職種で学生の層と確かめることが違う | 技術職は専攻で絞る型、総合職は仕事の場面で |
| 資格（電気、施工管理など）が関わる | 資格の取得を入社後に支援する会社が多い。学生は「何年で何を」を確かめる | 資格後の道を書けるか |
| 大手は地域で知られ、工事・保守の中小は知られていない | 同じ業界で、知名度の差が大きい | 知名度で先に検討する型が分かれる |
| 業界イメージ（古い、堅い、体力仕事） | 若手が確かめる「変わっているか」に答えられない | イメージを否定せず、実態で |

インフラの採用は、「安定志向の学生に会えるか」より、「会えた学生に、現場と転勤と夜勤の実態を隠さず伝え、それでも来る学生を残せるか」で決まります。

## 判断軸を、インフラ業界に当てる

| 軸 | インフラ業界での見方 |
|---|---|
| 対象（誰に届くか） | 技術職は専攻（電気、土木、機械、情報）で絞れるかを各媒体の仕様で確認。総合職は「安定」で来る層と「地域を支える仕事」で来る層 |
| 型（送るか、来るか、比べられるか） | 知られた大手は「比べられる」型が使える。工事・保守の中小は「送る」型か「来る」型で、まず知ってもらう |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | 技術職の文面は現場の技術者の時間が要る。総合職は人事で回せる。拠点が多い会社は地域ごとに名義が要る |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。インフラでは、「対象」の軸で技術職と総合職を分けることと、「運用工数」の軸で地域ごとの名義を見込むことが、他の業界と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「インフラは安定で選ばれるので、媒体に力を入れなくても来る」というものです。当社は3媒体すべての販売パートナーとして、インフラの会社の相談を受けますが、応募は来ても、面談や内定のあとに「現場はどのくらいですか」「転勤は」「夜勤は」「最初の勤務地は」と聞かれ、答えが「安定していますので」で止まって離れる、という形が多くあります。若手が確かめているのは「安定」ではなく、現場と転勤と夜勤と地方の実態で、これを隠して「安定」だけを出す会社は、応募は来ても残りません。当社がインフラの会社に媒体の前に用意してもらうのは、現場の割合、転勤の範囲、夜勤の有無、初任地の決まり方、資格の取得の道を、隠さず書いた一枚です。一枚があれば、どの媒体でも、実態を知ったうえで来る学生が残ります。安定は入口で、実態が出口です。

## 学生が、確かめること

- **現場の実態**：内勤と現場の割合、現場の環境、体力の要る仕事か
- **転勤と初任地**：転勤の有無と範囲、初任地の決まり方。[東京本社で全国採用する会社のOfferBox運用](/media/ob-tokyo-unyou/)
- **夜勤・シフトの有無**：いつから、どのくらい。隠すと最初の夜勤で辞める
- **資格の取得の道**：入社後に何年で何の資格を、会社がどう支援するか
- **「安定」の中身**：雇用の形、異動、評価、定年までの道
- **業界が変わっているか**：古い、堅いのイメージに対して、何が変わったか
- **技術職なら、最初の年に触る設備と、誰に教わるか**：[理系学生を採りたい会社のOfferBox運用](/media/ob-rikei-unyou/)

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 地域で知られた大手で、クチコミと選考情報が付いている | 学生が並べて比べる場（ワンキャリア） | 比べる対象に入っている。クチコミの実態と記事をずらさない |
| 技術職を、専攻（電気・土木・機械・情報）で絞って採りたい | 企業から送る型（OfferBox） | 専攻で絞れるかは仕様で確認。現場の技術者の名義で「設備」と「教わる人」を書く |
| 業界イメージを変えたい、若手の実態を読んでもらいたい | 通年で記事を置く型（Wantedly） | 「変わっているか」を若手の場面で書ける。記事が残る |
| 工事・保守の中小で、知られていない | 送る型か記事を置く型 | 並べて比べる場では見られない。まず知ってもらう |
| 拠点が多く、地方で採る | 地域ごとに拠点の社員を名義に | [地方に本社がある会社のOfferBox運用](/media/ob-chihou-unyou/)の層の分け方 |

どれか一つが正解ではなく、知名度と職種と拠点の広がりで、先に検討するものが変わります。

## 組み合わせ

- **大手は、比べられる場と送る型を組み合わせる**：比べられる場で総合職の受け皿を、送る型で技術職を専攻で。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **中小は、送る型と記事を置く型を組み合わせる**：文面で「この仕事」を、記事で「若手の実態」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **学校（工業高校・高専・大学の学科）との関係と組み合わせる**：技術職は学校経由も多い。学校で会った学生に媒体で送らない。[高専生を採りたい会社のOfferBox運用](/media/ob-kosen-unyou/)、[OfferBoxと大学キャリアセンター経由の採用の併用](/media/ob-heiyou-daigaku-kyara/)
- **一年目は一つか二つ、型ができたら足す**：[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)

## 見せ方｜安定の中身と、現場の実態を隠さない

- **「安定」を、雇用・異動・評価の中身で**：「安定しています」では残らない
- **現場・転勤・夜勤・地方を、最初に、隠さず**：「現場は〇〇の割合で、転勤は△△の範囲で、夜勤は□□から」。後ろに書くと「隠した」と読まれる
- **資格の取得の道を、年数と役割で**：「入社△年目に□□の資格を、会社の支援で」。数値は実態で。この記事では書かない
- **業界イメージ（古い、堅い、体力仕事）を否定せず、変わったことを場面で**：「〇〇は△△に変わった。□□はまだ変わっていない」。[業界イメージが不利な会社のOfferBox文面](/media/ob-gyokai-image/)、[業界イメージが不利な会社のワンキャリアの見せ方](/media/oc-gyokai-image/)
- **技術職の文面は、現場の技術者の名義で、設備と教わる人を**：人事の名義では書けない
- **「地域を支える」の一語で済ませない**：誰の、何を、どう支えているかの場面で

## 社内の分担

| 作業 | 誰が |
|---|---|
| 現場・転勤・夜勤・初任地・資格の道の一枚 | 人事と現場の責任者 |
| 知名度と職種と拠点で、先に検討する型を決める | 人事と責任者 |
| 技術職の「こんな人」と専攻の絞り方 | 現場の技術者と人事 |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、若手と技術者が場面を話し、整えるのは人事か外に | 若手・技術者と人事 |
| 個別の一文、文面の最終確認、名義（職種と地域ごと）、面談 | 現場の若手と技術者 |
| 学校との関係 | 人事 |
| 面接官に、実態を隠さず話すと伝える | 人事 |

- **技術者に頼むのは、設備と教わる人の一行・名義・面談の三つ**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
- **拠点が多いなら、地域ごとの名義と面談枠を**：[東京本社で全国採用する会社のOfferBox運用](/media/ob-tokyo-unyou/)

運用代行や代理店が支えられるのは、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分、地域ごとの台帳の型までで、一枚の中身、実態の開示、名義の選定、面談、学校との関係は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

同じインフラでも、地域で知られていてクチコミと選考情報が付いている大手には、ワンキャリアのように学生が並べて比べる場を先に整え、送る型は技術職を専攻で絞る用途に絞ることを勧め、工事や保守を担う知られていない会社には、OfferBoxで「この仕事」で送るか、Wantedlyで若手の現場の実態を記事で読んでもらう型を先に勧めることが多いです。理由は、大手は学生の候補に入っていて、比べられる場でクチコミの実態と記事をずらさないことが要で、中小は候補に入っておらず、比べられる場に出ても見られないからです。技術職はどちらでも、現場の技術者の名義で「最初の年に触る設備」と「教わる人」を書けるかで決まります。当社は3媒体すべての販売パートナーとして、知名度と職種で分けて提案しています。

## まとめ

- インフラの学生は「安定」で来て、「現場・転勤・夜勤・地方」の実態を確かめて離れる。安定は入口で、実態が出口
- 媒体の前に、現場の割合・転勤の範囲・夜勤・初任地の決まり方・資格の道を隠さず書いた一枚を作る
- 地域で知られた大手は並べて比べる場を先に、技術職は専攻で絞って送る型を、知られていない工事・保守の会社は送る型か記事を置く型を先に。優劣ではなく知名度と職種で
- 技術職の文面は現場の技術者の名義で「設備」と「教わる人」を。拠点が多いなら地域ごとに名義を。学校で会った学生に媒体で送らない
- 見せ方は「安定」を中身で、現場と転勤と夜勤を最初に、業界イメージを否定せず変わったことを場面で

## よくある質問

### 現場や夜勤を正直に書くと、応募が減りませんか

減ります。減るのは、実態を知ったら来ない学生で、入社後に離れる学生です。書いて来た学生は、知ったうえで来ていて、最初の夜勤で辞めません。インフラの採用で要るのは、「安定」で応募する学生の数ではなく、実態を知って「それでも来る」学生です。隠して採った学生が辞めると、現場の負担が増え、次の採用がさらに難しくなります。

### 技術職と総合職で、媒体を分けるべきですか

分けることが多いです。技術職は専攻で絞れる送る型（絞れるかは各媒体の仕様で確認）で、現場の技術者の名義で設備と教わる人を書き、総合職は知名度に応じて並べて比べる場か記事を置く型で仕事の場面を書きます。同じ文面と同じ名義で両方に送ると、どちらにも刺さりません。

### インフラ業界の媒体選びは、御社に相談できますか

できます。当社は、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分、地域ごとの台帳の型を支えられます。一枚の中身、実態の開示、名義の選定、面談、学校との関係は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
