ワンキャリアでは、自社の勤務地から離れた地域の学生のプロフィールも見えます。良い学生が見つかっても、「遠いから」で送らないか、送っても勤務地に触れず、受諾のあとで「面接は本社で」となって終わる、ということが起きます。ワンキャリアでは、その終わり方が体験談に「面接のために遠くまで行った」「勤務地を知らずに受けた」と書かれます。**結論から言うと、地方の学生にスカウトを送るときは、送る前に「勤務地と転勤、オンラインで完結する段階、来社が要る段階と交通費の扱い、移住の支援の有無」を決め、文面に勤務地の一文とオンラインで話せることを入れ、その土地との縁をプロフィールで読んだならそれを一文に使います。「来てもらう前提」を外さないまま送ると、受諾後にずれ、体験談に残ります。** この記事では、地方の学生が体験談で読んでいること、やりがちな失敗、送る前に決めること、文面に入れること、地方企業と都市部の企業それぞれの場合、受諾後の進め方、分担を整理します。他媒体の考え方は[OfferBoxで地方の学生にオファーを送る考え方](/media/ob-chihou-gakusei/)と[Wantedlyで遠方の候補者にスカウトを送るとき](/media/wt-scout-remote/)で書きました。ワンキャリアは「体験談に書かれる」が加わります。

## この作業の目的｜「遠いから無理」を、学生が受諾の前に判断できるようにする

地方の学生にとって、最初の疑問は「この会社で働くには、引っ越しが要るのか」「面接のために、どこまで行くのか」です。文面にそれが無いと、受諾する前に諦めるか、受諾してから分かって終わります。

目的は、勤務地と選考の形を文面で先に伝え、「遠くても受けられる」か「引っ越しが要る」かを、学生が受諾の前に判断できるようにすることです。判断できれば、来る学生は合う学生だけになり、受諾後のずれが無くなります。

## 地方の学生が、体験談で読んでいること

| 読んでいること | 文面と運用への意味 |
|---|---|
| 「面接のために遠くまで行った」「何度も往復した」 | オンラインで完結する段階を作り、文面に書く |
| 「交通費が出なかった」「出ると思ったら出なかった」 | 交通費の扱いを、自社の制度に沿って文面か企業ページに |
| 「勤務地を知らずに受けて、面接で知った」 | 勤務地を文面の最初のほうに |
| 「移住の支援があると思ったら無かった」 | 有無を事実で |
| 「地方から受けたのは自分だけで、話が合わなかった」 | 地方から入った社員がいれば、その人が話す |

この体験談は、次の年の地方の学生も読みます。「遠くまで行った」が書かれている会社に、地方の学生は受諾の前に諦めます。

## やりがちな失敗

| 失敗 | 学生からどう見えるか |
|---|---|
| 勤務地に触れない | 受諾後に「本社は〇〇です」で終わる。体験談に書かれる |
| 「転居可能な方」で絞る | 移住を考えていない学生は来ない。考えている学生にも冷たく見える |
| 来社前提の話す場に誘う | 遠くの学生は来られない |
| 交通費の扱いに触れない | 来社を頼まれても、負担が分からず断る |
| 移住の支援が無いのに「移住歓迎」 | 面談で実態が分かる。体験談に書かれる |
| その土地との縁を読まずに送る | 「なぜ自分に」が無い |
| 地方の学生と都市部の学生に、同じ文面を送る | 地方の学生が最初に知りたいことが無い |

最も多いのは、最初の「勤務地に触れない」です。文面は仕事の話だけで、学生は勤務地を確かめるために企業ページを見て、遠いと分かって閉じます。

### エージェントベストの見解

相談で最も多い思い込みは、「地方の学生に送っても、どうせ来ない」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、地方の学生が来ないのは、遠いからではなく、文面に勤務地と選考の形が無く、体験談に「遠くまで行った」が書かれているからです。オンラインで完結する段階があり、それが文面に書いてあり、来社が要る段階と交通費の扱いが企業ページに事実で書いてあれば、地方の学生は受諾の前に判断でき、合う学生は来ます。当社が地方の学生への文面を整えるとき、最初にやるのは、「この募集は、どこに住んでいれば受けられて、どこまでオンラインで進められるか」を一文で書くことです。遠さは、文面で先に伝えれば、障害ではなく条件の一つになります。

## 送る前に、決めること

1. **この募集の勤務地と転勤**：実態で。「勤務地は〇〇。転勤は△△」
2. **オンラインで完結する段階**：最初の話す場と、選考のどこまでがオンラインか
3. **来社が要る段階と、交通費の扱い**：「最終だけ来社。交通費は〇〇」。自社の制度に沿って。出せないなら出せないと
4. **移住の支援の有無**：あるなら形を。無いなら無いと。自社の制度に沿って
5. **地方から入った社員がいるか**：いれば、話す場に出てもらう
6. **年度の公表内容と自社の方針**：時期の扱い

1と2が決まっていないと、文面に書けません。決まっていなければ、地方の学生には送りません。

## 文面に入れること

通常の4段に、次を足します。

| 入れること | 書き方 |
|---|---|
| 勤務地の一文 | 「勤務地は〇〇です。転勤は△△」。実態のとおりに。2段目か3段目に |
| オンラインで話せること | 「最初の話す場はオンラインで、来てもらう必要はありません」 |
| 選考でどこまでオンラインか | 「選考も〇〇までオンラインで、来社は△△だけです。交通費は企業ページに」 |
| その土地との縁を読んだなら | 「〇〇のご出身と書かれていたので」。プロフィールに書かれている場合だけ。推測しない |
| 移住の支援があるなら | 一文で。無ければ書かない |

4段の基本は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。地方の学生には、勤務地と選考の形の一文が、選考で何を見るかの一文と同じくらい要ります。

## 地方企業が、都市部の学生に送る場合

地方に拠点がある会社が、都市部の学生に送る場合は、次を足します。

- **Uターン・Iターンの読み手に分けて、一文を変える**：出身が分かればUターン向け、「地方で働きたい」と書いていればIターン向け
- **仕事の具体を、都市部の会社と同じ水準で**：「地方だから」で薄くしない。[地方企業がワンキャリアに掲載するときの伝え方](/media/oc-chihou-keisai/)
- **移ってきた社員が、話す場に出る**：「自分も遠くから来た」人の話が、最も具体的
- **来てもらうときの形を、先に用意する**：交通費、見られるもの、社員と話せる時間。一度の来社で確かめられるように
- **企業ページに「住む場所と通勤」「移住の支援の有無」があるか**：文面から誘導する先

「仕事の具体が先で、土地の魅力はあと」は、文面でも同じです。

## 都市部の企業が、地方の学生に送る場合

都市部に勤務地がある会社が、地方の学生に送る場合は、次を足します。

- **上京や転居が要ることを、文面で先に**：「勤務地は〇〇で、転居が要ります」。隠さない
- **オンラインで完結する段階を、最初に**：「話す場と一次はオンラインです」
- **来社の交通費の扱いを、企業ページに事実で**：文面から誘導
- **地方から入った社員がいれば、その人が話す**：「自分も地方から来た」
- **住まいの探し方や支援があれば、企業ページに**：無ければ無いと

「転居が要ることを先に」が、都市部の企業の場合の要点です。隠しても、受諾後か体験談で分かります。

## 受諾後の進め方

- **話す場はオンライン**：来社を前提にしない。日程は、学生の授業と、時差があれば配慮
- **来社は、学生が望んだときだけ**：「見に来たい」と言われたら。交通費の扱いを先に伝える
- **勤務地と選考の形を、話す場の最初に確かめる**：「文面に書いたとおり、〇〇の形です。この形で問題ないですか」。ずれがあれば、ここで分かる
- **移住の話は、学生から出たときに**：会社側から「引っ越せますか」と聞かない
- **選考の流れを、オンラインで進める形で伝える**：来社が要る段階を、改めて
- **土地の情報を渡す**：地方企業の場合は、社員の暮らしの場面。都市部の企業の場合は、住まいの探し方

受諾後の基本は[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/)で書きました。地方の学生には、「勤務地と選考の形を最初に確かめる」が加わります。

## 絞り込みでの扱い

- **オンラインで完結する段階があるなら、勤務地で絞らない**：対象を広く
- **来社が多い選考なら、通える範囲か、移住を考えている学生（プロフィールで分かる範囲）に**
- **その土地との縁を、条件に入れられるなら入れる**：出身地、学校の所在地。仕様は管理画面で確認
- **地方の学生は、台帳に印を付ける**：受諾後の進め方が違う。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/)

### エージェントベストの見解

これをやる前に、先に決めておかないと受諾後にずれ、体験談に書かれることがあります。「選考のどこまでをオンラインで進められるか」です。当社がワンキャリアで地方の学生へのスカウトを支えるとき、文面に入れる一文は当社が型にできますが、「話す場と一次はオンライン、最終だけ来社」という中身は、面接に出る人が決めることです。「面接は全部来社」のままでは、地方の学生には文面に何を書いても、受諾の前に諦められるか、受諾後に「遠くまで行った」と体験談に書かれます。当社が最初にお願いするのは、面接に出る人に「どの段階をオンラインにできますか」と聞いてもらうことです。その答えが、文面の一文になり、地方の学生に送るかどうかも、その答えで決まります。

## まとめ

- 地方の学生は、体験談で「遠くまで行った」「勤務地を知らずに受けた」を読んでいる。文面で勤務地と選考の形を先に伝える
- 勤務地に触れない、「転居可能な方」で絞る、来社前提、交通費に触れない、移住歓迎の実態不一致、が受諾後のずれと体験談を生む
- 送る前に、勤務地と転勤、オンラインで完結する段階、来社が要る段階と交通費、移住の支援の有無、地方から入った社員の有無を決める
- 文面に、勤務地の一文、オンラインで話せること、選考でどこまでオンラインか、その土地との縁を読んだならその一文を入れる
- 地方企業はUターン・Iターンで一文を変え仕事の具体を同じ水準で。都市部の企業は転居が要ることを先に。受諾後はオンラインで完結し、話す場の最初に勤務地と選考の形を確かめる

## よくある質問

### 面接は対面で行う方針で、オンラインにできません

その方針なら、地方の学生には、来社が要ることと交通費の扱いを文面と企業ページに事実で書き、来社は一度で済む形（一度の来社で複数の段階を行う、見学と面接を同じ日に）にします。それでも来る学生は、その負担を受け入れて来ています。隠して受諾を得るより、書いて受諾を得るほうが、体験談に「遠くまで行った」と書かれる形が減ります。

### 地方の学生に、交通費を出す制度がありません

出せないなら、出せないと企業ページに事実で書き、文面からそこへ誘導します。そのうえで、オンラインで完結する段階を増やし、来社は学生が望んだときだけにします。出せないことを隠して来社を頼むと、体験談に「交通費が出なかった」と書かれます。この記事では、出すべきかどうかは書きません。

### 地方の学生へのスカウトは、御社に相談できますか

できます。当社は、送る前に決める項目の一覧、文面に足す一文の型、受諾後の進め方の型、地方企業と都市部の企業それぞれの整理を支えられます。勤務地と選考の形の決定、支援の決定、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
