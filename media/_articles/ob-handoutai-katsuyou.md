デバイスメーカー、製造受託、製造装置メーカー、材料メーカー、設計・IP、後工程・組立、地方の工場が、OfferBoxで新卒を採る。半導体は、会社の種類で採用の形がまったく違う業界です。設計、製造、装置、材料、設計IP、後工程の会社があり、学生には「半導体」の一語でどの会社も同じに見える。採用は急に増えていて、同じ学生を複数の会社が取り合っている。**結論から言うと、半導体のOfferBoxは、送る前に順番を決めます。最初に「会社の種類と工程の一文」（半導体の中で、この会社は何をしていて、この募集はどの工程か）を書けるかを確かめ、次に取り合いの中で「なぜこの会社か」を実例で書けるかを確かめ、それから地方の工場とクリーンルームと交代制と勤務地を隠さず書けるかを確かめ、検索を研究室のテーマと扱った装置と工程で絞り、最後に送ります。順番を飛ばして「半導体で世界を変える」「成長産業」で送ると、「半導体」の一語で承認され、面談で会社の種類を知って別の会社に流れ、入社してクリーンルームと交代制で離れます。** この記事では、半導体の採用構造とOfferBoxとの相性、順番の設計、検索とターゲットの設計、オファー文面、面談と内定後、工場・技術と人事の分担を整理します。媒体の選び方は[半導体業界の採用媒体の選び方](/media/hikaku-handoutai-erabikata/)、理系の取り合いは[OfferBoxで理系学生の取り合いを避ける方法](/media/ob-rikei-toriai/)で書きました。数値と料金は書きません。

## 半導体の採用構造と、OfferBoxとの相性

| 区分 | 採用の形 | OfferBoxとの相性 |
|---|---|---|
| デバイスメーカー | 設計、プロセス、生産技術。名前で来ることも | 会社の種類と工程を先に。名前で来ない工程に |
| 製造受託 | プロセスと生産技術。地方の工場と交代制 | 向く。工場と交代制を先に、装置の行動で絞る |
| 製造装置メーカー | 機械・電気・制御。装置の設計と据付と保守 | 向く。「装置」を機械・電気の学生に |
| 材料メーカー | 化学・材料の研究室から | 「〇〇の工程の△△」でつなぐ。[化学業界の設計](/media/ob-kagaku-katsuyou/) |
| 設計・IP | 情報・電気。外資とIT企業と比べられる | 何をどの規模で設計するかを正直に |
| 後工程・組立、地方の工場 | 地域の学生。交代制 | 向く。地域と工場と工程で |

| 業界の特徴 | OfferBoxで起きること | 設計 |
|---|---|---|
| 会社の種類で仕事が違う | 「半導体」の一語で承認して、種類を知って離れる | 会社の種類と工程の一文を先に |
| 取り合い | 同じ学生に複数の会社が送り、承認しても面談で別の会社に | 「なぜこの会社か」を実例で。面談を速く |
| 地方の工場とクリーンルームと交代制 | 入社後に知って離れる | 隠さず先に |

## 順番の設計｜会社の種類と工程の一文→なぜこの会社か→勤務地と交代制→検索→送る

- **一番目：「会社の種類と工程の一文」を、書けるか**：「半導体の〇〇（設計・製造・装置・材料・後工程）をしている会社で、この募集は△△の工程」。技術の人と一緒に書く。これが無いと、「半導体」の一語で承認されて、種類で離れる
- **二番目：取り合いの中で「なぜこの会社か」を、実例で書けるか**：「〇〇の工程で△△を、□□の装置で、〇〇人でやっている」「新卒が△△年目で□□を任された」。
- **三番目：地方の工場とクリーンルームと交代制と勤務地を、書けるか**：「工場は〇〇。クリーンルームに△△の時間。交代制は□□」。書けないなら、送る前に決める。[OfferBoxの募集要項の書き方](/media/ob-boshu-youkou/)
- **四番目：検索を、研究室のテーマと扱った装置と工程で絞る**：後述
- **五番目：送る**：一番目から三番目が書けてから。取り合いなので、送ったら面談を速く。[OfferBoxで即日対応する設計](/media/ob-sokujitsu-taiou/)

### エージェントベストの見解

これは順番の話です。半導体の会社から、「OfferBoxで承認はされるのに、面談の後に別の会社に流れる」と相談されることがあります。文面を見ると、「半導体で世界を変える」「成長産業で」が最初にあり、会社の種類（設計か、製造か、装置か、材料か）と募集の工程が後ろに小さく書かれている形が多い。学生は「半導体」の一語で承認していて、面談で会社の種類を初めて知り、比べて、別の会社を選びます。当社がお願いしているのは、送る前に「会社の種類と工程の一文」を技術の人と一緒に書き、「なぜこの会社か」を成長産業ではなく工程と装置と実例で書き、工場とクリーンルームと交代制を書いてから、検索して送ることです。取り合いの中で選ばれるのは、承認の数を増やした会社ではなく、種類と工程と勤務地を先に伝えて、それでも承認した学生を速く迎えた会社です。一文が検索より送信より先に来ることを、最初に決めておいてください。

## 検索とターゲットの設計｜研究室のテーマと、扱った装置と工程で

- **「半導体に興味」「成長産業」で検索しない**：像の言葉で、会社の種類を知らない学生が承認する
- **プロセスと生産技術は、研究室のテーマと扱った装置で**：「〇〇（材料・薄膜・プラズマ・微細加工）を△△の装置で作った・測った」。半導体の研究室だけでなく、物理・化学・材料・機械の研究室にも。[OfferBoxのターゲット設計](/media/ob-target-sekkei/)
- **製造装置は、機械・電気・制御の行動で**：「〇〇（装置・機構）を設計して動かした」「△△を制御した」。「半導体」を見ていない機械・電気の学生に、装置から
- **設計は、書いたコードと設計した回路で**：「〇〇（言語・ツール）で△△を設計して□□で検証した」。外資とIT企業と比べている前提で。[OfferBoxのプロフィールの読み方](/media/ob-profile-yomikata/)
- **後工程と地方の工場は、「工程を回した行動」と「決まりを守り続けた行動」と地域で**：[OfferBoxで地方の学生に届ける方法](/media/ob-chihou-gakusei/)

## オファー文面の設計｜会社の種類と工程の一文を先に、なぜこの会社かを実例で

- **最初の一文は、会社の種類と工程の一文**：「半導体」の一語と「成長産業」は、二文目以降に。[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)
- **「なぜこの会社か」を、工程と装置と実例で**：「〇〇の工程を△△の装置で。新卒が□□年目で〇〇を任された」。「世界シェア」「最先端」の一語で済ませない
- **地方の工場とクリーンルームと交代制と勤務地を、隠さず**：「工場は〇〇。クリーンルームに△△。交代制は□□。最初の配属は〇〇」。承認の後に知られると、別の会社に流れる
- **プロフィールの研究テーマと装置とコードに、一箇所触れる**：「〇〇の研究の△△は、当社の□□の工程に近い」。[OfferBoxで研究職志望に送るオファー文面](/media/ob-kenkyu-offer-bunmen/)
- **技術の人の名義で送る**：[OfferBoxのオファー文面の個別化](/media/ob-offer-personalize/)

## 工場・技術と人事の分担

| 作業 | 誰が |
|---|---|
| 会社の種類と工程の一文と、「なぜこの会社か」の実例を書き出す | 技術の人と人事 |
| 工場とクリーンルームと交代制と勤務地を、何を書くか決める | 経営と工場の責任者と人事 |
| 研究室のテーマと装置と工程で検索を絞る | 技術の人と人事（絞る作業は外に出せる） |
| 一文を先に書いた文面を、技術の人の名義で送る | 人事（下書きは外に出せる） |
| 面談に技術の人が出て、クリーンルームか工場を見せる | 技術・工場と人事 |
| 内定後、配属と交代制を伝え、技術の人と会わせる | 人事 |

運用代行や代理店が支えられるのは、一文と実例の書き出しの型、文面の下書き、検索の絞り込み、送信、一次返信、面談の枠出し、数の見方の型、面談の型、内定後フォローの型までで、工場とクリーンルームと交代制の開示、技術の人が話すこと、面談、クリーンルームを見せること、内定後の連絡は会社が行います。代行の範囲は[OfferBoxの運用代行の範囲](/media/ob-unyou-daikou-hanni/)で書きました。

## まとめ

- 半導体は会社の種類（設計・製造・装置・材料・設計IP・後工程）で採用の形が違い、学生には違いが見えない。「半導体」の一語で承認され、種類を知って別の会社に流れる
- 順番＝会社の種類と工程の一文を書けるか→「なぜこの会社か」を工程と装置と実例で書けるか→工場とクリーンルームと交代制を書けるか→研究室のテーマと装置と工程で絞る→送る。飛ばすと、承認されて、面談で流れ、入社後に離れる
- 取り合いで選ばれるのは、種類と工程と勤務地を先に伝えて、承認した学生を速く迎えた会社。承認の翌日に面談の枠を出す
- 検索は「半導体に興味」ではなく、研究室のテーマと扱った装置と工程で、半導体以外の研究室（物理・化学・材料・機械）と、機械・電気の学生に装置から
- 面談に技術の人が出て「自分の工程と装置」を話し、クリーンルームを見せる。内定後は配属と交代制を伝え、技術の人と会わせ、クリーンルームをもう一度見せる

## よくある質問

### 取り合いなので、実態を先に書くと他の会社に負けます

実態を隠して先に承認を取っても、面談で別の会社と比べられ、入社後にクリーンルームと交代制で離れます。負けているのは承認ではなく、面談の後と入社の後です。会社の種類と工程と「なぜこの会社か」の実例を先に書き、それでも承認した学生を承認の翌日に面談で迎えてください。取り合いで残るのは、実態を知って選んだ学生です。

### 「半導体」の研究室の学生が、少なくて足りません

半導体の研究室だけを探すと、取り合いになります。プロセスと生産技術は物理・化学・材料の研究室の「薄膜・プラズマ・微細加工・材料」のテーマと装置で、製造装置は機械・電気の「装置を設計して動かした」行動で、設計は情報・電気の「設計して検証した」行動で探してください。「半導体」を見ていない学生に、工程と装置から届けると、取り合いの外で会えます。

### 半導体のOfferBoxの設計は、御社に相談できますか

できます。当社は、一文と実例の書き出しの型、文面の下書き、検索の絞り込み、送信、一次返信、面談の枠出し、数の見方の型、面談の型、内定後フォローの型を支えられます。工場とクリーンルームと交代制の開示、技術の人が話すこと、面談、クリーンルームを見せること、内定後の連絡は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
