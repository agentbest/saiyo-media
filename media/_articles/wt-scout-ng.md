スカウトの各段の進め方は、これまでの記事で書いてきました。この記事は、その基本を知っていても起きる失敗を、5つに分けて集めたものです。**結論から言うと、スカウトの失敗は「送る前」「文面」「送ったあと」「面談」「運用」の5つに分けると直しやすく、返信が来ないときは、失敗を探す前に「どの段で止まっているか」を切り分けます。切り分けずに文面だけを直しても、原因が会社ページや返信対応にあれば直りません。最も重い失敗は、文面の質ではなく「止まること」です。** この記事では、5つの失敗と直し方、送る前のセルフチェック、返信が来ないときの切り分け、止まる失敗、分担を整理します。スカウトの基本は[ダイレクトスカウトの基本](/media/wt-scout-kihon/)で書きました。

## この作業の目的｜失敗に「気づける」状態を作る

スカウトの失敗は、送っている本人には見えにくいものです。送っているときは「相手に合わせて書いた」つもりで、受け取る側には「テンプレ」に見えます。

気づける状態を作るには、送る前に5つの観点でチェックすることと、面談で「文面のどこに反応したか」「記事と違ったことは」と聞くことの2つです。後者は、面談で一言聞くだけで、どの段が効いていて、どの段が止まっているかが分かります。

## 失敗1｜送る前

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 会社ページが空のまま送る | 文面で興味を持っても、会社ページで離れる | 先に整える。[会社ページの基本](/media/wt-kaisha-page-kihon/) |
| 募集記事が条件だけ | 文面で挙げた仕事が募集記事に無い | [募集記事の基本](/media/wt-boshu-kihon/) |
| ストーリーが一本も無い | 「一緒に働く人」が見えない | 数本を先に |
| 絞り込みが広い | 読めず、テンプレになる | 読める数まで絞る。[スカウト対象の絞り方](/media/wt-scout-target/) |
| 「こんな人」に無い条件で絞る | 記事と対象がずれる | 「こんな人」から条件を作る |
| 面談枠を決めずに送る | 返信が来ても面談に出られない | 面談枠から逆算。[スカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/) |
| 返信に対応する人を決めずに送る | 最初の返信で止まる | 一人決めて通知を集める |

## 失敗2｜文面

| 失敗 | 相手からどう見えるか | 直し方 |
|---|---|---|
| テンプレの一斉送信 | 「誰にでも送っている」 | 相手の一文と重なる点を毎回書く。[スカウトを相手ごとに変える範囲](/media/wt-scout-kojinka/) |
| 会社名や挨拶から始める | 営業に見える。開かれない | 相手の何を読んだかを最初に。[スカウトの書き出しの工夫](/media/wt-scout-kenmei/) |
| 会社の説明が長い | 会社ページを読まされる | 会社の説明は書かない。[スカウト文面の書き方](/media/wt-scout-bunmen/) |
| 条件の羅列 | 求人票 | 条件は募集記事に |
| 「ぜひご応募ください」 | 話す段階を飛ばしている | 「まず話を聞きに来て」 |
| 煽り（限定・特別・厳選） | 信用されない | 事実の一文 |
| 褒め言葉（素晴らしいご経歴） | 読んでいなくても書ける | プロフィールの具体的な箇所 |
| 募集記事に無い仕事を書く | 募集記事を見て「文面と違う」 | 募集記事にある仕事だけ。[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/) |
| 誰が話すかが無い | 「人事の説明を受けるだけでは」 | 話す人と形を書く |
| 名前だけ借りて人事が書く | 面談で本人が文面を知らない | 本人が書くか了承する。[スカウトを現場社員の名前で送る方法](/media/wt-scout-genba/) |

### エージェントベストの見解

申し込んだあと、スカウトで半年後に起きやすいのは、「返信が来ない理由を文面に求めて、文面を何度も直し、それでも来ずに止まる」ことです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、返信が来ない会社の原因を段で切り分けると、文面が原因であることは半分もありません。会社ページが空、募集記事が条件だけ、絞り込みが広くて読めていない、返信は来ているのに対応が遅い。これらは文面を直しても変わりません。当社が相談を受けるとき、文面を読む前に、会社ページと募集記事を開き、台帳で返信から対応までの時間を見ます。文面は、その次です。スカウトの失敗で最も多いのは、文面の失敗ではなく、「文面以外を見ていない」ことです。

## 失敗3｜送ったあと

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 返信への対応が遅い | 他の会社へ | 翌日までに。対応する人と通知。[返信が来たあとの進め方](/media/wt-scout-henshin-go/) |
| 返信に、募集の長い説明を送る | 読む負担 | 短く、日程の候補と、誰が話すか |
| 日程調整が何往復もする | 面倒で止まる | 候補をこちらから出す |
| 面談の前に書類を求める | 「話す場」が選考に | 求めない |
| 質問だけの返信に、回答だけ返す | 話す場につながらない | 回答に日程の候補を添える |
| 断りの返信に何も返さない | 印象が下がる | お礼を返す |
| 面談までの間、連絡が無い | 気持ちが薄れる | 読んでおくものを一つ、前日に一言 |

## 失敗4｜面談

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 選考の面接にする | 「話す場」と聞いて来たのに | お互いを知る場に。[カジュアル面談の設計](/media/wt-scout-casual-mendan/) |
| 人事だけが出る | 仕事の話が聞けない | 送り主か、その職種の人が出る |
| 会社の説明会になる | 会社ページに書いてあること | 場面を一つ話し、あとは聞く |
| 志望動機や転職理由を聞く | 身構える | 聞かない。[カジュアル面談で聞くこと・聞かないこと](/media/wt-scout-mendan-shitsumon/) |
| 雑談で終わり、次が無い | 進まない | 最後に3つの選択肢 |
| 記事や文面と違うことを言う | 信用が消える | 話す人が記事と文面を読んでおく |
| 選考に入った途端、面接の型に戻る | 別の会社に会ったよう | 面談の続きとして。[カジュアル面談から選考へ移す方法](/media/wt-scout-senkou-ikou/) |

## 失敗5｜運用

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 上限を使い切ることが目的になる | 読まずに送る | 読める数が送れる数 |
| 送信数や返信率の目標値を先に置く | 数字を作る運用に | 段ごとの変化で見る。[スカウト運用のKPI設計](/media/wt-scout-kpi/) |
| 毎週文面を直す | 何が効いたか分からない | 毎週は見るだけ、直すのは月。[スカウトの返信率を毎週見直す方法](/media/wt-scout-review/) |
| 台帳が無い | 誰に何を送ったか分からない。重複 | 台帳を先に |
| 現場に丸投げ／人事が全部 | 止まる／文面が薄い | 分担。[スカウトを誰が送るか](/media/wt-scout-tantou/) |
| 型が増えすぎる、置き場がばらばら | 古い型が使われる | 募集ごとに一つ、一か所。[スカウト文面のテンプレート管理](/media/wt-scout-template/) |
| 「一般に良い時間」に合わせる | 送る側の都合と衝突して止まる | 送る人の枠から。[スカウトを送る曜日・時間の考え方](/media/wt-scout-timing/) |

| 反応を送る人に戻さない | 「やる意味が分からない」 | 結果を戻す |

## 送る前のセルフチェック

送る前に、次の順で見ます。数分で済みます。

1. **会社ページと募集記事は整っているか**：整っていなければ送らない
2. **相手のプロフィールを読んだか**：読んでいなければ送らない
3. **文面の最初に、相手のプロフィールの具体的な箇所があるか**
4. **重なる点が、募集記事にある仕事か**
5. **会社の説明と条件の羅列が無いか**
6. **「応募」ではなく「話を聞きに来て」になっているか**
7. **誰が話すかが書いてあるか**
8. **避ける言葉（煽り・褒め言葉）が無いか**
9. **返信に対応する人と、面談枠は決まっているか**
10. **この相手に「この募集の話をしたい」と言えるか**：言えなければ送らない

3と6と10の3つだけでも、毎回見ます。

## 返信が来ないときの、原因の切り分け

「返信が来ない」という症状は、原因が段で分かれます。文面を直す前に、どこで止まっているかを見ます。

| 止まっている段 | 見えるサイン | 直す場所 |
|---|---|---|
| そもそも送っていない | 送った数がゼロに近い | 送る人の枠、絞り込みの結果 |
| 読まずに送っている | 送った数は多いが、一文が薄い | 絞り込みを狭め、読む時間を確保 |
| 開かれていない | 書き出しが会社名や挨拶 | 書き出し |
| 開かれたが返信が無い | 文面はあるが、会社ページか募集記事が薄い | 会社ページ、募集記事 |
| 返信は来ているが面談に進まない | 台帳で返信から対応までが長い | 返信対応 |
| 面談はしたが、選考に進まない | 面談の設計、選考への移し方 | 面談、移行 |

「そもそも送っていない」は、失敗を探す前に確かめることです。送っていない状態で文面を直しても、意味がありません。

## 最も重い失敗｜止まること

5つの失敗のどれよりも重いのは、「スカウトが止まること」です。

- **文面が少し薄くても、送り続けていれば、返信は来て、台帳が溜まり、直せる**
- **止まると、台帳も溜まらず、何が悪かったかも分からない**
- **止まる理由は、文面の質ではなく、運用（枠・分担・対応する人・反応を戻す）にある**

止まったときの再開の仕方は[スカウト運用が止まったときの再開方法](/media/wt-scout-saikai/)で書きました。止まる前に、運用の失敗5を先に潰しておきます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 送る前のセルフチェック | 送る人 |
| 面談で「文面のどこに反応したか」を聞く | 面談に出る人 |
| 返信が来ない原因を切り分ける | 人事 |
| 5つの失敗を直す | 人事（文面は送る人と） |
| 止まっていないかを見る | 人事（毎週） |

運用代行や代理店が支えられるのは、セルフチェックの型、原因の切り分け、5つの失敗の直し方の案までで、送ること、面談で聞くこと、対応することは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyのスカウトの見直しを支えるとき、5つの観点のチェック、原因の切り分け、直し方の案は当社が出せます。ただし、「面談で候補者に『文面のどこに反応しましたか』と聞く」ことだけは、企業にしかできません。この一言が無いと、当社も企業も、返信の数だけで判断することになり、文面を煽る方向に寄ります。当社が見直しを支えるとき、最初に「面談の型に、この一言を入れてください」とお願いするのは、この理由です。一言があれば、5つのどこで止まっているかが分かり、直せます。無ければ、失敗は見えないまま続きます。スカウトの見直しは、書く技術より、聞く一言から始まります。

## まとめ

- スカウトの失敗は、送る前・文面・送ったあと・面談・運用の5つに分けると直しやすい
- 送る前に、会社ページと募集記事が整っているか・読んだか・相手の一文があるか・話す場か・誰が話すか、を最低限チェックする
- 返信が来ないときは、送っていない・読まずに送っている・開かれない・開いて返信が無い・返信は来るが面談に進まない、を切り分けてから直す
- 文面が原因であることは半分もない。会社ページ、募集記事、返信対応を先に見る
- 最も重い失敗は「止まること」。運用の失敗を先に潰し、面談で「文面のどこに反応したか」を聞く一言が、気づく唯一の手段

## よくある質問

### 文面を直したのに、返信が増えません

原因が文面以外にある可能性があります。会社ページと募集記事が整っているか、絞り込みが読める数か、返信は来ているのに対応が遅れていないか、を台帳で確かめます。面談で「文面のどこに反応したか」を聞き、どこで止まっているかを切り分けてから直します。

### チェック項目が多くて、送るのが遅くなります

10項目のうち、「相手の一文があるか」「話す場になっているか」「この相手に話をしたいと言えるか」の3つだけを毎回見ます。残りは、型と見本で防げます。型の管理は[スカウト文面のテンプレート管理](/media/wt-scout-template/)で書きました。

### スカウトの見直しは、御社に相談できますか

できます。当社は、セルフチェックの型、原因の切り分け、5つの失敗の直し方の案を支えられます。送ること、面談で聞くこと、対応することは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
