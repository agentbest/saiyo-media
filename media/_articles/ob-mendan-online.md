OfferBoxで承認された学生との初回面談は、オンラインで行うことが多くなっています。地方の学生と会える、日程が組みやすい、学生の移動の負担が無い。一方で、対面と同じ進め方では、空気が作れず、仕事の中身が伝わりにくいことがあります。**結論から言うと、オンライン面談は「最初の数分で空気を作る」「画面で仕事を見せる」「短めに終える」の3つを対面より意識し、必要なら対面につなぎます。** この記事では、案内、準備、進め方、複数人で出るときの注意、学生の環境への配慮、対面につなぐ判断を整理します。面談の構成そのものは[初回面談の設計](/media/ob-mendan-sekkei/)で書きました。この記事は、それをオンラインで行うときの違いです。

## この作業の目的｜画面越しでも「文面の続き」にする

オンラインでも、初回面談の目的は変わりません。文面で作った温度を、選考に進む意思に変えることです。

ただし、画面越しでは、対面で自然に伝わるものが伝わりにくくなります。会社の雰囲気、出る人の人柄、仕事の場の空気。これらを、オンラインでは意識して見せる必要があります。

オンライン面談の設計とは、「対面なら自然に伝わるものを、画面越しでどう伝えるか」を決めることです。

## 手順1｜案内に書くこと

日程が決まったら、オンラインの案内を送ります。書くことは次のとおりです。

| 項目 | 書くこと |
|---|---|
| 接続の方法 | 使う仕組みと、接続先。当日に迷わない形で |
| 所要の目安 | 短めであることを伝える |
| 出る人 | 名義の人の名前と、何をしている人か。複数なら全員 |
| 用意するもの | 特に無いことを書く。「手ぶらで」 |
| カメラと音声 | 「カメラは可能ならオンで」程度。強制しない |
| 当日つながらないときの連絡先 | 電話番号かメール。学生が困らないように |
| 面談の位置づけ | 選考ではなく、仕事の話を聞く場であること |

「用意するもの」と「面談の位置づけ」があると、学生は構えずに来られます。案内の文面は型にしておき、日時と出る人だけを変えます。

## 手順2｜接続の準備

出る側の準備です。当日に慌てると、最初の数分が失われます。

1. **接続を前日までに試す**：出る人全員が、使う仕組みで接続できることを確認する
2. **カメラの位置と背景を決める**：顔が見える位置に。背景は散らかっていなければよい。会社の雰囲気が見える場所なら、なおよい
3. **画面共有するものを開いておく**：仕事の中身を見せる資料や画面。当日に探さない
4. **学生の情報を手元に置く**：文面で触れた一文、確かめたいこと。画面の横に
5. **開始の数分前に入る**：学生が先に入って待つ状態を作らない

3の「画面共有するもの」が、オンライン面談で最も効く準備です。次の手順で書きます。

### エージェントベストの見解

同じ初回面談でも、当社がオンラインを先に勧めるのは、地方の学生に送っている会社と、面談枠を平日の隙間に入れたい会社です。移動が無いので、学生も出る人も枠を作りやすく、承認から面談までが短くなります。逆に、対面を勧めるのは、会社の雰囲気や仕事の場が売りで、それを見せることで温度が上がる会社です。工場、店舗、研究所、開発の現場。画面では伝わりにくいものがある会社は、オンラインで会ってから対面につなぐ形にします。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、オンラインだけで進めて選考に進む割合が上がらない会社の一部は、「見せれば伝わるもの」を画面で伝えようとしていました。オンラインで会う、対面で見せる。この分け方にすると、どちらの面談も役割がはっきりします。

## 手順3｜最初の数分で空気を作る

オンラインでは、最初の数分の空気が、その後の全体を決めます。対面なら部屋に入るまでの間に生まれる会話が、オンラインには無いからです。

- **接続の確認を、会話にする**：「音声は聞こえていますか」だけでなく、「今日はどちらからですか」「学校ですか、家ですか」と一言足す
- **名義の人が最初に話す**：「オファーを送った〇〇です。書いた本人です」。文面の続きであることを最初に伝える
- **面談の位置づけを一言で**：「今日は選考ではなく、仕事の話をする時間です」
- **学生の緊張をほぐす一言**：「カメラはオフでも構いません」「途中で音声が切れたら、遠慮なく言ってください」

この数分で「文面の人が来た」「評価されない」が伝わると、学生の話し方が変わります。ここを飛ばして本題に入ると、学生は面接の構えのまま進みます。

## 手順4｜画面で仕事を見せる

対面なら職場を見せられる場面を、オンラインでは画面共有で代えます。

| 見せるもの | 効き方 |
|---|---|
| 実際に使っている画面や資料 | 「この仕事は、こういう画面を見ながら進める」が伝わる |
| 仕事の成果物 | 抽象的な仕事の説明が、具体的になる |
| チームの様子の写真 | 一緒に働く人の顔が見える |
| 職場の写真や短い動画 | 対面で見せられない場を、少しだけ見せる |
| 企業ページの該当箇所 | 面談後に読み返せる場所を示す |

見せる時間は短くします。長く見せると説明会になります。学生の話を聞いたあとに、「いまの話に近い仕事は、こういう画面です」と、学生の話につなげて見せると、文面の続きになります。

見せられるものは、面談の前に決めておきます。当日に探すと、間が空きます。

## 手順5｜沈黙と間の扱い

オンラインでは、沈黙が対面より長く感じられ、話が重なりやすくなります。

- **学生が考えている沈黙は待つ**：画面越しだと不安になるが、対面と同じ長さで待つ
- **話が重なったら、譲る**：「どうぞ」と一言。出る側が譲る
- **相づちを、少し大きめに**：画面越しでは反応が伝わりにくい。うなずきを見せる
- **質問は1つずつ**：一度に複数を聞くと、学生がどれから答えるか迷う

複数人で出る場合は、話す順番を決めておきます。名義の人が主に話し、人事は流れと時間を見る。同時に話し出す事故を防ぎます。

## 手順6｜学生の環境への配慮

学生の側の環境は、企業側と違います。

1. **通信が不安定な学生がいる**：切れたときの連絡先を案内に書いておく。切れても「気にしないで」
2. **カメラをオンにできない事情がある**：強制しない。オフでも面談は成立する
3. **場所が学校や外のこともある**：周囲の音が入っても気にしない。聞き取れなければ聞き直す
4. **画面が小さい端末のこともある**：画面共有の文字は大きめに。細かい資料は後で送る
5. **オンライン面談に慣れていない学生もいる**：最初の数分で、操作に困っていないかを確認する

「学生の環境のせいで面談がうまくいかない」と感じたら、それは設計の問題です。どんな環境でも成立する形にしておきます。

## 手順7｜対面につなぐ判断

オンラインで会ったあと、対面につなぐかどうかを決めます。

- **つなぐ**：会社の雰囲気や仕事の場が売りで、見せると温度が上がる。学生が「見てみたい」と言った。選考の前に一度会っておきたい
- **つながない**：学生が遠方で移動の負担が大きい。オンラインで十分に温度が上がっている。次のステップが選考で、そこで対面になる

つなぐ場合は、面談の最後に「次は会社に来てもらって、実際の場を見てもらえたら」と、次のステップとして示します。学生が決める形にします。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 接続の確認だけして本題に入る | 面接の構えのまま進む | 最初の数分で会話し、名義の人が名乗る |
| 画面共有せずに仕事を口で説明する | 抽象的で伝わらない | 実際の画面や成果物を見せる |
| 画面共有が長い | 説明会になる | 学生の話につなげて短く |
| 沈黙に耐えられず話し続ける | 学生が話せない | 待つ。相づちを大きめに |
| 複数人が同時に話す | 学生が聞き取れない | 話す順番を決めておく |
| カメラオンを強制する | 事情がある学生が困る | 「可能なら」にとどめる |
| 当日に資料を探す | 間が空き、空気が冷める | 前日までに開いておく |
| 対面につなぐかを決めていない | 次のステップが曖昧になる | 面談の前に方針を決める |

最も多いのは、「画面共有せずに仕事を口で説明する」です。対面なら身振りや場で補えるものが、オンラインでは言葉だけになります。見せるものを用意します。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 案内を送る | 人事（型を用意） |
| 接続を試す | 出る人全員 |
| 画面共有するものを用意する | 名義の人（人事が手伝う） |
| 最初の数分の会話 | 名義の人 |
| 流れと時間を見る | 人事（同席する場合） |
| 学生の環境の確認と配慮 | 人事 |
| 対面につなぐ判断 | 名義の人と人事 |
| フォローの連絡 | 人事（名義の人の一言を添える） |

名義の人の準備は、「画面共有するものを用意する」と「接続を試す」の2つに絞ります。案内、環境の確認、フォローは人事が支えます。

### エージェントベストの見解

申し込んだあと、オンライン面談で最初の月に起きやすいのは、「案内は送ったが、当日に接続がうまくいかず、最初の数分が失われる」ことです。学生が接続先を探している、出る側の音声が出ない、画面共有の資料が見つからない。これだけで、文面で作った温度が下がります。当社がOfferBoxの運用の相談でオンライン面談の設計を見るとき、最初に確認するのは、案内の型と、出る人が前日までに接続を試しているかです。この2つがあれば、最初の数分は会話に使えます。無ければ、最初の数分は接続に使われます。面談の中身を工夫する前に、接続と案内を型にする。地味ですが、ここで差がつきます。

## まとめ

- オンライン面談も目的は同じ。文面の続きとして、温度を選考に進む意思に変える
- 案内は型にし、接続の方法・所要・出る人・用意するもの（無し）・位置づけを書く
- 最初の数分で会話し、名義の人が名乗り、評価しないことを伝える
- 仕事は口で説明せず、画面で見せる。学生の話につなげて短く
- 学生の環境に合わせ、対面につなぐかを面談の前に決めておく

## よくある質問

### 初回面談は、オンラインと対面のどちらがよいですか

地方の学生や、面談枠を作りやすくしたい場合はオンラインが向きます。会社の雰囲気や仕事の場が売りなら、オンラインで会ってから対面につなぐ形が向きます。オンラインだけで進める場合は、画面で仕事を見せる準備をします。

### 学生がカメラをオフにしています。どうすればよいですか

事情があることが多いので、強制しません。カメラがオフでも、音声で面談は成立します。出る側はカメラをオンにして、表情を見せます。学生が話しやすい状態を優先します。

### オンライン面談の設計は、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、案内の型、接続の準備、画面で見せるものの用意、最初の数分の進め方を、面談に出る人と一緒に決めます。運用代行を受ける場合も、案内とフォローの連絡は当社が支えますが、面談は企業が行います。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
