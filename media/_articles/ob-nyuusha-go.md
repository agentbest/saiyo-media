OfferBoxで採った学生が、入社した。この社員は、次の卒年の採用にとって最も価値のある材料です。自社の文面を読んで承認し、面談と選考を経て、承諾して入社した本人だからです。**結論から言うと、入社した社員には、入社直後に「なぜ承認したか」「文面のどこに反応したか」「決め手と迷った点」を聞き、その答えでペルソナと評価基準を更新し、面談の同席から名義へと段階的に育てます。ただし、入社直後は本来の仕事が優先で、頼むことを絞り、紹介や写真は本人の同意で行います。** この記事では、入社直後に聞くこと、ペルソナと基準の更新、名義への育て方、企業ページへの登場、頼まないこと、やりがちな失敗、分担を整理します。内定者の段階で聞くことは[内定者に文面を手伝ってもらう方法](/media/ob-naiteisha-katsuyou/)、現場の巻き込み方は[現場社員を巻き込む方法](/media/ob-genba-makikomi/)で書きました。この記事は、その先の「入社した社員」の話です。

## この作業の目的｜採用の結果を、次の採用の元にする

OfferBoxの運用は、送る、承認される、面談する、選考する、内定を出す、承諾される、の流れで書いてきました。入社は、この流れの終点であり、次の卒年の流れの起点です。

入社した社員は、次のことを知っています。自社の文面をどう読んだか、面談で何が響いたか、選考で何を確かめられたか、内定後に何が決め手になったか、そして入社後に仕事がどうだったか。これは、翌年の文面、面談、評価基準、内定フォローの、すべての材料です。

この作業の目的は、入社という結果を、次の採用の元に変えることです。

## 手順1｜入社直後に聞く

入社して落ち着いた頃に、採用の担当者が短い時間で聞きます。研修の一部や、面談の形で。

| 聞くこと | 何に使うか |
|---|---|
| オファーを開いた理由、承認した理由 | 件名にあたる部分と冒頭の効いた部分。[件名で開封が変わる理由](/media/ob-offer-kenmei/) |
| 文面のどこに反応したか、どこを飛ばしたか | テンプレートの見直し |
| 面談で何が響いたか、何が不安だったか | 面談の型の見直し。[初回面談の設計](/media/ob-mendan-sekkei/) |
| 選考で何を聞かれてよかったか、答えにくかったか | 評価基準と質問の見直し。[評価基準の作り方](/media/ob-gakusei-hyouka-kijun/) |
| 内定後、何が決め手になったか、何に迷ったか | 内定フォローの見直し。[内定を出したあとのフォロー](/media/ob-naitei-follow/) |
| 入社前の自分は、どんな学生だったか | ペルソナの更新の材料 |
| 入社して、文面や面談で聞いた話と違ったことはあるか | 文面と企業ページの実態とのずれ |

最後の「違ったことはあるか」が、最も正直な答えが出る質問です。文面と実態がずれていれば、ここで分かります。ずれは、翌年の文面で直します。

聞くのは一度で足ります。何度も聞くと、本人の負担になります。答えは記録し、翌年の準備の期間に使います。

## 手順2｜ペルソナと評価基準を、入社前と入社後で更新する

入社した社員の「入社前の姿」と「入社後の活躍」が、ペルソナと評価基準の更新の元になります。

1. **入社前の姿を、条件・志向・行動で整理する**：本人に聞いた答えと、選考時の記録から。ペルソナの作り方は[採りたい学生像を言葉にする](/media/ob-persona/)
2. **入社後の活躍を、一定の期間で現場に聞く**：最初の数ヶ月で何ができるようになったか、どんな動き方をしているか
3. **選考時の評価と、入社後の活躍を照らす**：「語れる」と判断した項目が、活躍につながっているか
4. **ペルソナと評価基準を直す**：つながっている行動と志向を残し、つながっていないものを見直す。見直しの時期は[2年目以降の見直し点](/media/ob-repeat-unyou/)
5. **複数の入社者で見る**：1人の例で変えない。数人の共通点で

入社者が1人なら、その1人の例を「仮説」として置き、翌年以降に増えた入社者で確かめます。少人数の共通点で決めつけないのは、[適性検査結果の使い方](/media/ob-tekisei-katsuyou/)で書いたのと同じです。

### エージェントベストの見解

相談で最も多い思い込みは、「入社したら、すぐに次の採用の名義になってもらえる」というものです。実際には、入社直後の社員は、本来の仕事を覚えることで手一杯で、採用に時間を割ける状態ではありません。この時期に名義を頼むと、文面の仕事の中身を自分の言葉で書けず（まだ仕事を知らない）、面談で仕事の話ができず、本人も負担に感じます。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、入社した社員が名義として効いている会社は、入社直後は「聞く」だけにとどめ、面談の同席から始めて、仕事を語れるようになってから名義にしています。段階を踏んだ名義は、「自分もこの文面で承認した」と学生に言え、これは他の社員には言えないことです。急がず、聞く、同席する、名義になる、の順で。それが、入社した社員を採用に活かす形です。

## 手順3｜面談の同席から、名義へと段階的に育てる

入社した社員を採用に関わらせるのは、段階を踏みます。

| 段階 | 関わり方 | 条件 |
|---|---|---|
| 1. 聞く | 入社直後に、採用の担当者が聞く | 入社して落ち着いた頃。一度だけ |
| 2. 同席する | 初回面談に同席し、「自分もこの文面で承認した」と学生に話す | 仕事にある程度慣れた頃。話すのは自分の経験だけ |
| 3. 仕事の一文を直す | テンプレートの仕事の中身を、自分の言葉に直す | 自分の仕事を語れるようになった頃 |
| 4. 名義になる | 自分の名義で文面が送られ、面談に出る | 仕事の中身を自分の言葉で話せ、面談枠を出せる頃 |
| 5. 読んで書く | 自由記述を読み、冒頭を書く | 本人が「やりたい」と言ってから。[現場社員を巻き込む方法](/media/ob-genba-makikomi/)の段階と同じ |

2の「同席」が、入社した社員ならではの関わり方です。「自分も去年、この文面を受け取って承認した。面談でこう思った」と、学生と同じ立場だった人が話すと、学生の構えが解けます。この話は、他の社員にはできません。

段階を進める時期は、本人の仕事の状況と、本人の意向で決めます。人事が急がせないことが条件です。

## 手順4｜企業ページと文面に、本人の同意で登場してもらう

入社した社員は、企業ページの「若手の紹介」や、文面の「入社して間もない〇〇さんは、いまこの仕事をしている」の場面に、最も合う人です。学生が自分を重ねやすいからです。

- **本人の同意を取る**：名前、写真、仕事の内容を載せることに、本人が同意しているか。断られたら載せない
- **紹介文は、本人に確認してもらう**：人事が書いた紹介が、本人の実感と違うことがある
- **「OfferBox経由で入社」を書くかは、本人と相談する**：書くと学生には響くが、本人が望まなければ書かない
- **異動や退職のときに、差し替える**：紹介した人がいなくなったら、企業ページを直す。更新の観点は[企業ページで伝えること](/media/ob-kigyo-page/)
- **写真は仕事中の場面で**：集合写真より、働いている姿

「同意」を省くと、本人が後で知って不信を持ちます。載せる前に、必ずしも大がかりな手続きは要りませんが、本人に見せて「これでよいか」と聞くことは省きません。

## 手順5｜頼まないこと

入社した社員に頼まないことを、決めておきます。

1. **入社直後の名義**：仕事を語れない段階では、文面も面談も薄くなる
2. **読む・送る・返信するを、入社直後から**：本来の仕事の時間が採用に食われる
3. **同期や後輩の評価に関わること**：入社した社員は面接官ではない。面談の同席までにとどめる
4. **採用の数字の責任**：「あなたの名義で承認が少ない」と伝えない。名義の人は、承認の結果を負う立場ではない
5. **本人が望まない登場**：紹介、写真、「OfferBox経由」の明記。同意が無ければ載せない
6. **選考中の学生の情報を共有すること**：面談の同席で会う学生の情報は、同席の範囲で。選考の進捗は伝えない

頼まないことを決めておくと、入社した社員は「採用に協力する」ことを負担ではなく、自分の経験を活かす機会として受け取ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 入社直後に名義を頼む | 仕事を語れず、本人も負担 | 聞く→同席→一文→名義の順で |
| 聞かない | 入社という結果が、次に活きない | 入社直後に一度、7つを聞く |
| 1人の入社者でペルソナを変える | 個人の例に寄る | 仮説として置き、複数で確かめる |
| 入社後の活躍と照らさない | 評価基準が活躍とずれたまま | 現場に聞き、選考時の判断と並べる |
| 同意なしに紹介や写真を載せる | 本人が不信を持つ | 見せて聞く |
| 「文面と違った」を聞かない | 文面と実態のずれが残る | 最後の質問として聞く |
| 段階を人事が急がせる | 本人の仕事に支障が出る | 本人の状況と意向で |
| 採用の数字の責任を負わせる | 協力が続かない | 名義の人は結果を負わない |

最も多いのは、最初の「入社直後に名義を頼む」です。入社した社員の価値は、名義になることより、まず「聞かせてもらう」ことにあります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 入社直後に聞く | 採用の担当者（人事） |
| 聞いた答えを記録し、翌年の準備に使う | 人事 |
| 入社後の活躍を現場に聞く | 人事 |
| ペルソナと評価基準を更新する | 人事（現場と面接官に確認） |
| 同席・一文・名義の段階を進める | 人事が本人と上司に相談して決める |
| 企業ページの紹介と写真の同意 | 人事が本人に確認 |
| 本人の仕事の状況を見て、頼む量を調整する | 本人の上司 |

本人の上司が、頼む量の調整役になります。人事が直接本人に頼むと、本人は断りにくい。上司を通すと、本人の仕事の状況に合わせて調整できます。運用代行に出している場合、聞いた答えをテンプレートとペルソナに反映する作業は代行が行えますが、本人に聞くこと、同意を取ること、段階を決めることは社内です。代行の範囲は[運用代行に任せられる範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行で、入社した社員から聞いた答えをテンプレートとペルソナに反映するとき、答えの共有は企業からいただきますが、本人に聞く場、紹介の同意、段階の判断は、当社は持ちません。入社した社員との関係は企業のもので、外部の当社が本人に「文面のどこに反応したか」を聞くのは、本人にとって負担です。企業の人事が、入社直後に一度、短く聞く。その答えを当社に共有してもらい、当社が翌年のテンプレートと件名の型と面談の型に反映する。この分担で、入社した社員の負担は最小で、翌年の文面は「去年承認した本人の答え」で直ります。入社した社員は、翌年の採用にとって最も安い、最も正確な材料です。聞くのは企業、反映するのは当社でも構いません。聞かずに終わらせないことだけが、条件です。

## まとめ

- 入社した社員は、次の採用の最も価値のある材料。入社直後に一度、承認の理由、文面の反応、面談、選考、決め手、入社前の姿、文面との違いを聞く
- 入社前の姿と入社後の活躍で、ペルソナと評価基準を更新する。1人の例で変えず、複数で確かめる
- 関わり方は、聞く→面談の同席→仕事の一文→名義→読んで書く、の段階で。人事が急がせない
- 企業ページの紹介と写真は本人の同意で。「OfferBox経由」を書くかも本人と相談
- 入社直後の名義、読む・送る、評価への関与、数字の責任、望まない登場は頼まない

## よくある質問

### 入社した社員に、いつから名義になってもらえますか

仕事の中身を自分の言葉で話せ、面談枠を出せるようになってからです。時期は本人の仕事の状況と意向で決め、上司を通して相談します。それまでは、入社直後に聞く、面談に同席して自分の経験を話す、テンプレートの仕事の一文を直す、の段階で関わってもらいます。

### 入社した社員が1人しかいません。ペルソナを変えてよいですか

1人の例は、仮説として置きます。その社員の入社前の姿と入社後の活躍を記録し、翌年以降に入社者が増えたときに、共通点があるかを確かめてからペルソナに反映します。1人で変えると、個人の例に寄ります。

### 入社した社員から聞いたことを、御社に共有すれば文面に反映してもらえますか

反映できます。当社がOfferBoxの運用代行を受けている場合、聞いた答えを共有していただければ、翌年のテンプレート、件名の型、面談の型に当社が反映します。本人に聞く場と、紹介の同意と、段階の判断は、企業の人事にお願いしています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
