インターンの募集をインターン媒体で出していて、Wantedlyも使っている。あるいは、Wantedlyでインターンを募集していて、インターン媒体を足すか迷っている。この二つは、同じ「インターンを集める」でも、来る学生の状態が違います。**結論から言うと、インターン媒体は「決まった時期に、決まった枠を埋める入口」、Wantedlyは「会社の中身を読んだ学生が、時期を問わず来る入口」です。併用するなら、入口ごとに来た学生に見せるものを揃え、受け入れる側の時間を先に取り、片方の締切に合わせてもう片方を止めないことです。** この記事では、それぞれの役割、併用するときの分担、募集記事と会社ページの見直し、予算と工数の配分、やりがちな失敗、社内の分担を整理します。Wantedlyのインターン募集記事そのものは[Wantedlyのインターン募集記事の書き方](/media/wt-boshu-intern/)、インターンからの母集団形成の全体は[インターンからの母集団形成](/media/kh-boshudan-intern/)で書きました。

## それぞれの役割｜インターン媒体は「枠と時期」、Wantedlyは「中身と通年」

インターン媒体は、学生が「インターンに行く」と決めてから開く場所です。時期が決まっていて、学生は日程と内容と業界で絞り、複数の会社を並べて応募します。会社の側は、枠と日程を出し、期間内に集めます。締切があり、締切が過ぎると募集は終わります。

Wantedlyは、学生が「この会社はどんな会社か」を読む場所です。募集記事の前に会社ページとストーリーがあり、読んだうえで「話を聞きに行きたい」と来ます。時期は決まっておらず、記事は残り続けます。インターンの募集記事を出しても、学生はまず会社を読み、そのあとに「インターンがあるなら行ってみたい」となります。

| | インターン媒体 | Wantedly |
|---|---|---|
| 学生が開く動機 | インターンに行くと決めたから | この会社を知りたいから |
| 学生が比べるもの | 日程・内容・業界・他社 | 会社の中身・人・仕事 |
| 時期 | 決まっている。締切がある | 決まっていない。記事が残る |
| 会社が出すもの | 枠・日程・プログラム | 会社ページ・ストーリー・募集記事 |
| 来る学生の状態 | 会社を知らない。プログラムで選んだ | 会社を読んでいる。会社で選んだ |
| 向く形 | 短期・日程が決まったインターン | 長期・通年で受け入れるインターン |

どちらが優れているかではなく、来る学生の状態が違います。インターン媒体から来た学生は会社を知らず、Wantedlyから来た学生は会社を読んでいます。この違いが、併用のときの分担の全部です。

## 併用するときの分担｜入口ごとに、見せるものと会う順番を変える

- **インターン媒体から来た学生には、会社を見せる**：プログラムで選んで来ているので、会社を知らない。当日の前に、Wantedlyの会社ページとストーリーを読んでもらう。読む場所がすでにある
- **Wantedlyから来た学生には、仕事を見せる**：会社は読んでいるので、「行ってみたら何をするか」を先に。インターン媒体で出しているプログラムの内容を、そのまま伝えてよい
- **短期はインターン媒体、長期はWantedly、と分ける**：日程が決まった短期は締切のある媒体で集め、通年で受け入れる長期は、記事が残るWantedlyで集める
- **同じインターンを両方で出すなら、記事の中身を変える**：インターン媒体には枠と日程と内容を、Wantedlyには「誰が見るか」「終わったら何が残るか」を。同じ文章を貼らない
- **来た学生の「入口」を台帳に残す**：どちらから来たかで、当日の話し方と、選考への接続が変わる

分担の考え方は、[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)で書いた「一つの入口が回ってから次を足す」と同じです。Wantedlyがすでに回っているなら、インターン媒体を「時期の入口」として足します。インターン媒体がすでに回っているなら、Wantedlyを「来た学生に読ませる場所」として足します。

### エージェントベストの見解

これをやる前に、先に「インターンで何を任せるか」と「当日、誰が見るか」を決めておかないと、どちらの媒体を足しても効果が出ません。当社は3媒体すべての販売パートナーとして、インターンの募集にWantedlyを足したいという相談を受けますが、話を聞くと、任せる仕事と見る人が決まっておらず、「媒体を増やせば学生が増える」と考えている会社が多くあります。任せる仕事が決まっていないと、インターン媒体には「社員と同じ仕事」と書き、Wantedlyには「実践的な経験」と書くことになり、両方から来た学生が当日に「思っていたのと違う」で離れます。任せる仕事と見る人が一行で書けてから、その一行を両方の媒体に合った形で書き分けるのが順番です。媒体の数ではなく、この一行があるかで、インターンからの採用は決まります。

## 募集記事と会社ページを、インターン媒体の側から見直す

インターン媒体から来た学生は、当日の前に会社を調べます。調べる先の一つがWantedlyの会社ページです。ここで、インターン媒体に書いたことと、Wantedlyに書いてあることがずれていると、学生は「どちらが本当か」と迷います。

- **インターン媒体の「内容」と、Wantedlyの募集記事の「何を任せるか」を揃える**：文章は違ってよい。中身がずれない
- **インターン媒体の「担当者」と、Wantedlyの「誰が見るか」を同じ人にする**：当日に会う人が、ストーリーに出ていると、学生は安心して来る
- **会社ページの「なぜ」を、インターン生に話す言葉と揃える**：当日の説明が会社ページと同じ言葉なら、読んで来た学生は「読んだとおり」と感じる
- **インターンの募集記事に、会社ページとストーリーへの導線を置く**：インターン媒体から来た学生が、当日の前に読める形に
- **終わったあとに、インターン生の言葉をストーリーにする**：本人が特定されない形で。次の年のインターン媒体の「内容」の元になる

Wantedlyの募集記事に書く五つの要素（何を任せるか・誰が見るか・期間と頻度・終わったら何が残るか・報酬の有無と条件）は、[Wantedlyのインターン募集記事の書き方](/media/wt-boshu-intern/)で書きました。インターン媒体に出すときも、この五つがあれば、記事の中身は揃います。

## 予算と工数の配分｜時間は「受け入れ」に先に取る

| 項目 | インターン媒体 | Wantedly |
|---|---|---|
| 費用の性格 | 掲載の期間や枠に応じた費用。現在の条件は各媒体の公式ページで確認 | 会社ページと記事を整える時間が中心。プランは公式ページで確認 |
| 会社側の時間が要る場面 | 枠と日程の設計、応募の受付、当日の運営 | 会社ページとストーリーの更新、募集記事、返信と面談 |
| 時期 | 募集期間に集中する | 通年で少しずつ続く |
| 受け入れの時間 | 当日に見る人の時間。ここが最も大きい | 同じ |

- **受け入れる側の時間を、先に確保する**：どちらの媒体から来ても、当日に見る人の時間は同じだけ要る。ここを取らずに媒体の費用を決めない
- **インターン媒体の費用は、募集期間に集中する**：期間の前に、当日の設計を終えておく
- **Wantedlyの時間は、通年で薄く続く**：月に一度、会社ページと記事を見直す時間を、担当者の予定に固定する
- **両方を出す年は、受け入れの人数を先に決める**：媒体が増えると応募が増えるが、見る人の時間は増えない。受け入れられる人数から、募集の出し方を逆算する

媒体を何本併用するかは、予算ではなく担当者の時間で決めます。考え方は[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)で書きました。インターンは、媒体の費用より受け入れの時間のほうが大きい採用です。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 同じ文章を両方に貼る | インターン媒体では枠と日程が足りず、Wantedlyでは中身が足りない | 中身を揃え、書き方を分ける |
| インターン媒体の締切で、Wantedlyの記事も閉じる | 通年の入口が止まり、締切のあとに会社を読んだ学生の行き先がなくなる | Wantedlyの記事は残す。時期だけ「次回」に書き換える |
| Wantedlyから来た学生を、インターン媒体の選考と同じ流れに入れる | 会社を読んで来た学生に、会社の説明から始めてしまい、温度が下がる | 入口を台帳に残し、来た学生の状態に合わせて話す |
| 「Wantedlyでインターン生が来ない」でやめる | Wantedlyは会社を読んでから来る入口なので、会社ページとストーリーがないと、インターンの記事だけでは来ない | 会社ページとストーリーを先に整える |
| 受け入れる人を決めずに、両方で募集する | 応募は来るが、当日に見る人がおらず、「雑用しかない」インターンになる | 見る人と任せる仕事を先に決める |

最も多いのは、二つ目です。Wantedlyは記事が残る媒体なので、締切のあとに会社を読んだ学生が「インターンはもうないのか」で離れます。時期だけを書き換えて、残します。

## 社内の分担

| 作業 | 誰が |
|---|---|
| インターンで任せる仕事と、見る人を一行で決める | 人事と現場の責任者 |
| インターン媒体の枠・日程・内容を出す | 人事 |
| Wantedlyの会社ページとストーリーを整える | 人事と、ストーリーに出る社員 |
| Wantedlyのインターン募集記事を書く | 人事と、当日に見る人 |
| 来た学生の入口を台帳に残す | 人事 |
| 当日に見る、任せる、振り返る | 現場の担当者 |
| 終わったあとに、インターン生の言葉をストーリーにする | 人事と現場 |
| 受け入れる人数と、両方を出すかの判断 | 責任者 |

運用代行や代理店が支えられるのは、入口ごとの分担の整理、記事の書き分けの型、台帳の型、受け入れの時間の見積もりまでで、任せる仕事の決定、当日に見ること、来た学生と話すこと、受け入れる人数の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

申し込んだあと、最初の募集期間が終わったところで運用が止まる会社に共通するのは、「インターンの募集はインターン媒体の締切で終わる」という感覚を、Wantedlyにも持ち込むことです。当社はWantedlyの運用を申込のあとまで見ていますが、インターン媒体で集めた年は、締切のあとに会社ページの更新も止まり、次の年の募集期間まで何も動かない会社が多くあります。その間に、会社を読んで「インターンがあれば行きたい」と思った学生が来ても、記事が閉じていて行き先がありません。インターン媒体の締切は「枠が埋まった」の合図で、「会社を読む学生がいなくなった」の合図ではありません。締切のあとも、月に一度の会社ページの見直しと、募集記事の時期の書き換えだけは続けると、次の年のインターン媒体の募集期間に、すでに会社を読んでいる学生から応募が来ます。

## まとめ

- インターン媒体は「決まった時期に枠を埋める入口」、Wantedlyは「会社を読んだ学生が通年で来る入口」。来る学生の状態が違う
- 併用するなら、インターン媒体から来た学生には会社を見せ、Wantedlyから来た学生には仕事を見せる。短期はインターン媒体、長期はWantedlyと分ける
- 同じインターンを両方で出すなら、中身を揃えて書き方を分ける。インターン媒体の「担当者」とWantedlyの「誰が見るか」は同じ人に
- 予算と工数は、受け入れる側の時間を先に取る。媒体が増えても、見る人の時間は増えない
- インターン媒体の締切で、Wantedlyの記事を閉じない。時期だけ書き換えて残す

## よくある質問

### インターン媒体だけで足りている場合、Wantedlyを足す意味はありますか

インターン媒体から来た学生が、当日の前に会社を調べる場所として、Wantedlyの会社ページとストーリーが使えます。「集める入口」を増やすのではなく、「来た学生に読ませる場所」として足す考え方です。集める入口として足すなら、会社ページとストーリーを先に整えないと、インターンの募集記事だけでは来ません。

### Wantedlyだけでインターンを集めている場合、インターン媒体を足すべきですか

日程が決まった短期のインターンを、決まった時期に集めたいなら、締切のある媒体のほうが向きます。通年で長期のインターンを受け入れているなら、Wantedlyの記事が残る形で足りることが多いです。足すかどうかは、受け入れる人数と、当日に見る人の時間で決めます。媒体を足しても、見る人の時間は増えません。[インターンからの母集団形成](/media/kh-boshudan-intern/)

### Wantedlyとインターン媒体の併用は、御社に相談できますか

できます。当社は、入口ごとの分担の整理、記事の書き分けの型、台帳の型、受け入れの時間の見積もりを支えられます。任せる仕事の決定、当日に見ること、来た学生と話すこと、受け入れる人数の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
