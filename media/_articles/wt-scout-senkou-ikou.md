カジュアル面談がうまくいっても、その先の選考に進まない、進んでも最初の面接で辞退される、ということが起きます。多くの場合、原因はカジュアル面談と選考の「つなぎ目」にあります。**結論から言うと、カジュアル面談から選考へは、「面談の続き」として案内します。面談の最後に3つの選択肢を伝え、翌日の連絡で選考の流れを具体的に書き、選考に入ると何が変わるか（評価があること、書類が要ること、回数と期間）を先に伝え、最初の選考には面談で話した人が出て、書類は最小限にし、間を空けません。カジュアル面談で「読んだとおりの会社」と感じた人が、選考に入った途端に別の会社に会う、という断絶を無くします。** この記事では、つなぎ目の失敗、移す手順、迷っている人への対応、面談で聞いたことの引き継ぎ、辞退の受け止め方、分担を整理します。カジュアル面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

## この作業の目的｜面談で生まれた「話してみたい」を、選考で「働いてみたい」に変える

カジュアル面談を終えた人は、「この会社の人と、もう少し話してみたい」と思っています。まだ「働きたい」ではありません。

選考へ移す目的は、「話してみたい」を「働いてみたい」に変えることで、そのためには、選考が面談の続きとして感じられる必要があります。面談と選考が別の世界だと、「面談は良かったが、選考は普通の会社だった」で終わります。

## つなぎ目で起きる失敗

| 失敗 | 相手からどう見えるか |
|---|---|
| 面談と選考の境目が曖昧 | 「いまは選考なのか、まだ面談なのか」で不安 |
| 面談の最後に、急に「では選考に進んでください」 | 押された。「話す場」だったはずが |
| 選考に入った途端、面接の型（志望動機、強み弱み）に戻る | 別の会社に会ったようで、面談の信用が消える |
| 書類（履歴書、職務経歴書、志望動機書）で止まる | 書く負担で離れる |
| 面談から選考の連絡までが空く | 気持ちが薄れる |
| 面談で話した人と、選考で会う人が全員違う | 「あの人はもう出てこないのか」 |
| 選考の回数と期間を伝えない | 先が見えず、他社を優先 |
| 面談で聞いたことを、選考でまた聞く | 「聞いていなかったのか」 |

最も多いのは、「選考に入った途端、面接の型に戻る」です。カジュアル面談の担当と選考の担当が別で、選考側が面談の内容を知らないときに起きます。

## 移す手順

1. **面談の最後に、3つの選択肢を伝える**：選考に進む、もう一度別の人と話す、いったん終わる。「今日決めなくてよい」と添える
2. **翌日の連絡で、選考の流れを具体的に書く**：回数、それぞれで誰と何を話すか、期間の目安、要る書類。「進む場合は、こういう流れです」と、まだ決めていない人にも見える形で
3. **選考で何が変わるかを、先に伝える**：「ここからは、お互いに評価する段階になります」「書類が一つ要ります」。隠さない
4. **最初の選考には、面談で話した人が出る**：全員でなくてよい。一人でも同じ人がいると、続きになる
5. **書類は最小限にする**：プロフィールで足りる部分は求めない。志望動機書は求めない。要るものだけ、理由を添えて
6. **間を空けない**：進むと決めたら、最初の選考の日程をすぐ出す
7. **選考の各段階で、次に何があるかを毎回伝える**

「選考で何が変わるかを先に伝える」が、面談の信用を選考に持ち込む要点です。カジュアル面談は評価しない場だと伝えたなら、選考に入る時点で「ここからは評価があります」と、はっきり言います。言わずに評価を始めると、「騙された」に近い感じ方になります。

### エージェントベストの見解

申し込んだあと、スカウト運用で半年後に起きやすいのは、「カジュアル面談までは順調なのに、選考の初回で辞退が続く」ことです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、この症状の会社で選考の初回を見ると、面談の内容を知らない面接官が、志望動機と転職理由から聞き始めています。候補者は、カジュアル面談で「聞かない」と言われたことを、選考の初回で聞かれます。面談の信用が、その瞬間に消えます。当社が最初に確かめるのは、「選考の初回に、面談で話した人が出ているか」と「面接官が面談の記録を読んでいるか」の2つです。この2つがあれば、選考は面談の続きになります。無ければ、面談がどれだけ良くても、選考で別の会社になります。

## 迷っている人へ｜「もう一度話す」を用意する

面談のあと、「選考に進む」と「いったん終わる」の間で迷う人が多くいます。この人たちのために、「もう一度、別の人と話す」を選択肢として用意します。

- **別の人**：面談で話した人の上司、同じ職種の別の人、代表。相手の「知りたいこと」に合わせて選ぶ
- **形は、カジュアル面談と同じ**：評価しない。聞くこと・聞かないことも同じ。[カジュアル面談で聞くこと・聞かないこと](/media/wt-scout-mendan-shitsumon/)
- **回数は決めておく**：もう一度、まで。何度も続けない
- **もう一度話したあとに、改めて3つの選択肢**

「もう一度話す」があると、迷っている人が「いったん終わる」を選ばずに残ります。無いと、迷っている人は「まだ決められないので」で離れます。

## 面談で聞いたことを、選考に引き継ぐ

カジュアル面談で聞いたことを、選考の担当者に渡します。

| 引き継ぐこと | 選考での使い方 |
|---|---|
| 何を知りたくて来たか | 選考でも、その点に触れる |
| 働き方の希望 | 選考で条件の話をするときの前提 |
| 気になっていたこと | 解消されたか、選考で確かめる |
| 面談で話した仕事の場面 | 選考で、同じ場面から話を続けられる |
| 聞かないことにしたこと | 選考でも、必要になるまで聞かない |

引き継ぎの形は、面談の記録の一部を選考の担当者に送るだけで足ります。選考の担当者は、面接の前にそれを読みます。「面談で〇〇の話をされたと聞いています」から始まる面接は、面談の続きになります。

## 書類は、最小限にする

選考に書類が要る場合、要るものだけを、理由を添えて求めます。

- **プロフィールで足りるものは、求めない**：経歴はプロフィールに書かれている
- **志望動機書は求めない**：カジュアル面談から来た人に、志望動機を書かせると離れる。志望度は、選考の中で生まれる
- **要る書類は、なぜ要るかを添える**：「〇〇の確認のために」
- **提出の期限を、余裕を持って**：在職中の人は、書く時間が限られる
- **提出を待つ間も、連絡を絶やさない**

会社の制度上、決まった書類が要る場合は、その旨を伝えて求めます。ただし、最初の選考の前に全部を求めず、進むにつれて必要になるものは後で求めます。

## 辞退の受け止め方

選考の途中や、面談後に辞退があった場合、理由を聞ける範囲で聞き、記録します。

- **理由を聞くときは、選考とは関係ないと伝える**：「今後の参考に、差し支えなければ」
- **「面談と違った」があれば、どこが違ったかを記録する**：記事か面談か選考のどこを直すかの材料
- **辞退した人にも、お礼を送る**：会社の印象が残る
- **辞退の理由を、月に一度まとめて見る**：同じ理由が続けば、そこを直す

辞退の理由は、つなぎ目の失敗を見つける最も直接の材料です。聞かずに終わると、同じ失敗が続きます。

運用代行や代理店が支えられるのは、移す手順の設計、翌日の連絡の型、引き継ぎの記録の型、書類の最小化の整理、辞退の理由の集め方までで、面談と選考に出ること、選考の判断、書類の決定は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「カジュアル面談までがスカウト運用で、選考は別の話だ」という点です。当社がWantedlyのスカウトの支援をするとき、返信率や面談の数だけを見ていると、選考の初回で辞退が続いていても気づきません。スカウトの結果は、選考に進んだ人が決まるところまでで見るものです。当社が最初にお伝えするのは、「スカウトの運用の範囲に、選考の初回までを含めてください」ということです。当社が支えられるのは、面談から選考への手順と、記録の引き継ぎの型までで、選考に出ることと判断は社内です。ただし、選考の初回に面談で話した人が出るかどうかで、スカウトの結果は変わります。この一点は、スカウトの運用の一部として、社内で決めてもらっています。

## まとめ

- カジュアル面談から選考へは「面談の続き」として案内する。面談で生まれた「話してみたい」を「働いてみたい」に変える
- 境目が曖昧、急に選考を持ち出す、面接の型に戻る、書類で止まる、間が空く、話した人が出ない、が辞退を生む
- 面談の最後に3つの選択肢、翌日に選考の流れを具体的に、選考で何が変わるかを先に伝え、最初の選考に面談で話した人が出て、書類は最小限、間を空けない
- 迷っている人には「もう一度別の人と話す」を用意し、面談で聞いたことを選考の担当者に引き継ぐ
- 辞退の理由を聞いて記録し、月に一度まとめて見る

## よくある質問

### 選考の初回に、面談で話した人が出られません

一人でもよいので、面談で話した人か、面談に同席した人事が出ます。全員が初対面だと、選考が別の会社になります。どうしても出られないなら、面接官が面談の記録を読み、「面談で〇〇の話をされたと聞いています」から始めます。

### 会社の決まりで、志望動機書が必要です

決まりなら求めますが、最初の選考の前ではなく、進んだ段階で、理由を添えて求めます。カジュアル面談の直後に志望動機書を求めると、「話す場」から来た人は書けず、離れます。志望度が生まれてから書いてもらうほうが、内容も伴います。

### カジュアル面談から選考への流れの設計は、御社に相談できますか

できます。当社は、移す手順の設計、翌日の連絡の型、引き継ぎの記録の型、書類の最小化の整理、辞退の理由の集め方を支えられます。面談と選考に出ること、選考の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
