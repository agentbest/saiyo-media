OfferBoxを使うと決めたあと、「何から申し込めばいいのか」「いつから使えるのか」で手が止まる会社は少なくありません。**結論から言うと、公式に示されている申込の順番は「トライアル → 本登録の申込 → プランの申込」です。申込はi-plugの審査を経て承認され、承認されると契約が成立します。企業向けサイトのトップでは、導入・利用開始まで最短3営業日程度（審査などの状況により前後）とされています。** 手続きそのものは複雑ではありませんが、申込の前に社内で決めておくことがいくつかあります。この記事では、公式の流れと規約から、申込の段取りを整理します（2026年9月30日時点。最新は公式ページでご確認ください）。

## 結論｜申込は3段階、契約は審査のあとに成立する

公式のトライアル申込フォームに示されている流れは、次の3段階です。

1. **トライアル**：1週間、デモ画面で実際の操作を試せます
2. **本登録の申込**：問い合わせフォームから本登録を申し込みます
3. **プランの申込**：早期定額型か成功報酬型かを選んで申し込みます

トライアルを経ずに本登録から始められるかどうかは、公式の公開情報では明記されていないため、問い合わせの際に確認します。まだ使ったことがない会社や、以前使っていた会社は、使い方の説明を申し込める、と公式のよくある質問にあります。

利用開始までの日数は、企業向けサイトのトップで「最短3営業日程度」とされています。一方で、ご利用の流れのページには「約4営業日程度で専用IDが発行」という書き方もあります。表記が2通りあるので、この記事では日数を断定せず、「最短3営業日程度、審査の状況で前後する」と受け止めておくのが安全だと考えます。

## 仕組み｜規約に書かれた申込から利用登録までの手順

企業向け利用規約（29卒対象プラン用）の第3条には、申込から利用登録完了までの手順が定められています。要点を順に並べると次のとおりです。

| 段階 | 内容 |
|---|---|
| 同意と申込 | 利用規約とポリシーに同意したうえで申し込む |
| 審査 | i-plugが申込内容を審査する |
| 承認・契約成立 | 承認されると契約が成立する。IDと初期パスワードの通知が承認の代わりになることがある |
| 利用登録の完了 | 企業情報を登録して、利用登録が完了する |

審査では、虚偽の申告がある場合、過去に契約違反がある場合、反社会的勢力との関係がある場合などに、理由を示さずに申込を断られることがある、とされています。通常の会社がつまずく場面は多くありませんが、申込書の記載内容は正確に書きます。

ID発行のあとは、公式の「ご利用の流れ」にある6つの段階（本登録 → 学生を探す → オファー送信 → オファー承認 → 学生と会う → 内々定）に進みます。使い始めるときに、企業情報や採用担当者の紹介文などを入力する、とされています。

### エージェントベストの見解

申込の相談で先にお伝えしているのは、「ID発行の日が、運用を始められる日ではない」ということです。手続き自体は数営業日で終わりますが、その後に企業情報、採用担当者の紹介文、検索の条件、オファーの文面の型を用意する必要があります。当社は3媒体すべての販売パートナーとして申込後の立ち上げも見ていますが、IDが出てから企業情報を書き始める会社は、最初のオファーを送るまでに数週間かかることがあります。その間に、送り始めたかった時期が過ぎてしまう。当社が勧めているのは、申込書を出すのと同じ週に、企業情報の下書きと、最初に送る学生像を社内で固めておく順番です。手続きの速さより、ID発行の日に何が手元にそろっているかで、立ち上がりの速さが決まります。

## 確認する項目｜申込の前に社内で決めること

申込書を出す前に、次の6つを決めておくと、承認後すぐに動けます。

1. **対象の卒年とプラン**：早期定額型（インターンや早期面談から）か、成功報酬型（3月以降）か。プランの違いは[OfferBoxのプランの選び方](/media/ob-plan-erabikata/)にまとめています
2. **採用予定人数**：早期定額型は人数別のプランです。料金ページに出ているのは3名採用の場合の75万円（税抜）で、11名以上のプランも提供可能とされています
3. **契約の有効期間と支払条件**：どちらも申込書・申込画面で決まると規約にあります
4. **請求先**：規約上、利用企業とは別の請求先を指定できます。グループ会社や本社経理に請求を回したい場合は、申込時に確認します
5. **IDを使う人**：IDは企業の責任で管理し、運用を国内の第三者に委託する場合を除き、第三者に使わせてはいけないと規約にあります。外部に運用を任せる予定があるなら、この時点で決めておきます
6. **最初の1ヶ月の作業の担当**：企業情報の入力、担当者紹介文、検索条件、文面の型を誰が作るか

4と5は、申込が終わってから気づくと手戻りになりやすい項目です。特に運用を外に出すかどうかは、IDの扱いに関わるので、先に決めておきます。

## 注意点

- **利用開始の日数は目安**：トップページは「最短3営業日程度」、ご利用の流れは「約4営業日程度」と表記が違います。審査の状況で前後します
- **申込は規約への同意が前提**：規約は対象の卒年ごとに分かれています。申し込むプランの卒年の規約を読みます
- **審査で断られることがある**：虚偽の申告や過去の契約違反などがあれば、理由を示さずに断られることがあるとされています
- **トライアルはデモ画面**：1週間のトライアルで試せるのはデモ画面です。実際の学生にオファーを送れるのは本登録と申込のあとです
- **料金はすべて税抜**：料金ページの金額は税抜表示です

## 申込から最初のオファーまでの社内分担

| 作業 | 誰が | いつまでに |
|---|---|---|
| プランと人数を決める | 採用の責任者 | 申込前 |
| 申込書の記載と規約の確認 | 人事 | 申込前 |
| 企業情報・担当者紹介文の下書き | 人事と現場 | 申込と同じ週 |
| 最初に送る学生像と検索条件 | 人事 | ID発行まで |
| 文面の型を作る | 書く担当 | ID発行まで |
| 承認への返信体制 | 書く担当 | 最初の送信まで |

### エージェントベストの見解

もう一つ、申込の手続きで見落とされやすいのは「誰の名前で申し込み、誰がIDを持つか」です。当社への相談では、社長が申し込み、実際の運用は人事の兼務者、文面は現場の若手が書く、という形がよくあります。この場合、申込の段階で決めた人と、毎日ログインする人が違うため、支払条件や請求先の確認が運用担当まで伝わっていないことがあります。当社が申込前に一枚にまとめてお渡ししているのは、プラン、人数、有効期間、請求先、IDを使う人の5点です。手続きは一度で終わりますが、この5点は運用の途中で何度も参照されます。申込書の控えとは別に、運用担当が見られる場所に置いておくと、担当の交代があっても止まりません。

## まとめ

- 公式の流れは「トライアル → 本登録の申込 → プランの申込」
- 申込はi-plugの審査を経て承認され、承認で契約が成立する。利用開始は最短3営業日程度（審査状況で前後）
- 規約上、虚偽の申告や契約違反などがあれば申込を断られることがある
- 請求先の指定とIDを使う人は、申込前に決めておく
- ID発行の日に、企業情報と文面の型が手元にそろっているかで立ち上がりが決まる

## よくある質問

### トライアルを受けずに申し込めますか

公式の流れはトライアル、本登録、プラン申込の順ですが、トライアルは実際の画面を体験するためのものです。すでに使い方が分かっている場合の扱いは、問い合わせの際に確認します。個別面談を予約すると、実際の画面で操作説明を受けられ、採用したい学生が何人いるかも調べられる、と公式のよくある質問にあります。

### 申込から何日で使い始められますか

企業向けサイトのトップでは「最短3営業日程度」とされ、審査などの状況により前後するとあります。ご利用の流れのページには「約4営業日程度で専用IDが発行」とも書かれています。送り始めたい日の直前ではなく、余裕を持って申し込みます。

### 申込の手続きを御社経由で進められますか

当社はOfferBox・Wantedly・ワンキャリアの販売パートナーです。申込前のプランの整理から、申込後の立ち上げまで相談を受けています。代理店手数料は媒体側から支払われるため、**企業の料金は各媒体の正規料金のまま**です。はじめて使う会社の準備は[初めての新卒採用でOfferBoxから始めるときの順番](/media/ob-hajimete/)も参考にしてください。
