大手食品メーカー、中堅・地方の食品メーカー、原料・業務用、フードテック、D2C・通販、大手の新規事業・DX部門が、Wantedlyで採用する。食品は、候補者に最も身近な業界で、商品名を会社ページに置けば「話を聞きに行きたい」は集まる。ただ、押す数の多さは、会社が採りたい人の多さではない。「商品が好き」で押した候補者は、開発（商品企画、研究）だけを見ていて、会社が多く採りたい営業（量販店と外食への提案、棚の確保、数字）と工場（交代勤務、衛生、ライン）の実態を面談で聞いて離れる。会社の側は「話を聞きに行きたいは多いのに、営業と工場が採れない」と思う。**結論から言うと、食品のWantedlyは、順番を守ります。①商品名を一度だけにし、「なにを」を客層と売り先と商品の種類で書く。②営業の一日（量販店への提案、棚、数字、配荷）と、工場の一日（交代勤務、衛生、ライン、繁忙期）を、現場から聞き取って書けるかを確かめる。③開発・営業・工場・原料と業務用・本部の募集を分け、開発の募集に「商品が好き」で来る候補者を営業と工場の募集に流さない。④その上で募集を出す。「話を聞きに行きたい」の数を成果と見ず、面談で実態を伝えた後に残った数で運用を見ます。原料・業務用は、見えない前提で最終商品と用途で書きます。** この記事では、食品の採用構造とWantedlyとの相性、書く順番、商品名で埋めない見せ方、営業と工場の一日の書き方、数の読み方、ストーリーとカジュアル面談とスカウトの運用設計、社内の分担を整理します。媒体の選び方は[食品業界の採用媒体の選び方](/media/hikaku-shokuhin-erabikata/)、知名度の扱いは[Wantedlyで知名度をどう扱うか](/media/wt-chimeido/)で書きました。数値と料金は書きません。

## 食品の採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| 大手食品メーカー | 新卒は応募が集まる。中途は新規事業・DX・EC | 本体の新卒を置かない。新規事業・DX・ECの中途で、商品名ではなく部門で決められることで |
| 中堅・地方の食品メーカー | 営業と工場が中心。開発は少人数。知られていない | 向く。客層と売り先で。営業と工場の一日を先に。「地元の商品」で埋めない |
| 原料・業務用 | 顧客はメーカーと外食。候補者に見えない | 最終商品と用途で。「食品」の像とずれることを先に |
| フードテック・D2C | エンジニア、マーケ、CS、物流 | 向く。並ぶ場の中で、客層と商品と売り方と「何を決められるか」で |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| 身近で、押される数が多い | 数を成果と見て、営業と工場が採れない | 残った数で見る |
| 「商品が好き」で来るのは開発志望 | 営業と工場の募集に開発志望が押す | 募集を分け、商品名を一度だけに |
| 営業は量販店への提案と数字 | 「商品が好き」で来た人が数字で離れる | 営業の一日を先に |
| 工場は交代勤務と衛生 | 知らずに来て離れる | 工場の一日を先に |

## 順番①②：商品名を一度だけに、営業と工場の一日を書けるか確かめる

- **商品名を、一度だけ**：「なにを」に事実として。会社ページの全部を商品の写真と名前で埋めない。商品名は開発志望を集める
- **「なにを」は、客層と売り先と商品の種類で一言**：「〇〇の客層に、△△（量販店・外食・通販）で、□□の商品を売っている会社」。「食で笑顔を」で済ませない
- **営業の一日を、営業から聞き取る**：「〇〇の量販店に△△の提案。□□の棚の確保。〇〇の数字」。「商品を届ける」の一語で済ませない。[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)
- **工場の一日を、工場から聞き取る**：「〇〇の交代勤務。△△の衛生の手順。□□のライン。繁忙期は〇〇」。「ものづくり」で済ませない
- **数字の責任を、誰が持つかを書く**：「〇〇の数字は営業の担当が持つ。△△はチームで持つ」
- **営業と工場の一日が書けない間は、募集を出さない**：会社ページの「なにを」だけを整える

### エージェントベストの見解

これは数字の読み方の話です。食品メーカーから、「話を聞きに行きたいは多いのに、営業と工場が採れない」と相談されることがあります。当社は3媒体すべての販売パートナーですが、食品の「話を聞きに行きたい」の多さは商品の身近さを映していて、営業と工場の候補者の多さを映していません。押した候補者の多くは「商品が好き」で開発だけを見ています。当社がお願いしているのは、「話を聞きに行きたい」の数を成果と見ず、募集ごとに「押した数」「面談に来た数」「面談で営業と工場の実態を伝えた後に残った数」を分けて見ることです。営業と工場の募集で押した数が多く残った数が少ないなら、記事が商品名と「商品が好き」で書かれています。実態を先に書き直すと、押した数は減り、残った数が増えます。減った数を「悪くなった」と読まないことが、食品の会社の運用で最初に決めておくことです。

## 順番③④：募集を分ける｜開発・営業・工場・原料と業務用・本部

- **開発の募集は、開発として**：狭き門であることと、開発の一日（試作、評価、工場との調整、営業との会議）を隠さず。「商品が好き」で来てよい募集
- **営業の募集は、営業として**：量販店と外食への提案、棚、数字、配荷。「商品が好き」で開発志望を集めない
- **工場の募集は、工場として**：交代勤務、衛生、ライン、繁忙期、勤務地。品質と生産技術は別に
- **原料・業務用の募集は、最終商品と用途で**：「〇〇（パン・菓子・外食）の△△に使われる□□を作っている」。見えない前提で。[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)
- **本部（マーケ、EC、DX、新規事業）の募集は、商品名で埋めず、「何を決められるか」で**：「〇〇までは部門で決める。△△は役員の決裁」
- **一つの募集に「開発・営業・工場」と並べない**：開発志望だけが押して、面談で行き違う
- **「こんな人」は、「数字を持って改善した・棚や配荷を見た・衛生とラインを回した・工場と営業の間で調整した」の記述で**：「商品が好き」「食に興味がある」で絞らない
- **「なぜ」は、責任者の「なぜこの客層に、この商品を」を体験で**：[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)

会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

## スカウトの設計

- **絞るのは、「数字を持って改善した・棚や配荷を見た・衛生とラインを回した・工場と営業の間で調整した」の記述**：「食品」「商品が好き」の言葉で絞らない。[Wantedlyのスカウトで対象を絞る方法](/media/wt-scout-target/)
- **文面は、客層と売り先と、募集の形（営業／工場／開発）を最初に**：「〇〇の客層に△△で□□を売っていて、営業として数字を持つ仕事で、あなたの〇〇を読んで」。商品名で始めない。[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)
- **送る時期を、繁忙期の外に**：[Wantedlyのスカウトを送る時期の考え方](/media/wt-scout-timing/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 商品名を一度だけにし、客層と売り先と商品の種類で「なにを」を書く | 本部と人事 |
| 営業の一日と数字の責任を書き出す | 営業の責任者 |
| 工場の一日と交代勤務と衛生と勤務地を、何を書くか決める | 工場の責任者 |
| 開発・営業・工場・原料と業務用・本部の募集を分ける | 人事 |
| 責任者が「なぜこの客層に、この商品を」を話し、記事に整える | 責任者（整えるのは人事か外に出せる） |
| 営業が「棚が取れなかった月」を、工場の人が「繁忙期の一日」を話す | 営業・工場 |
| 「話を聞きに行きたい」を募集ごとに、残った数で読む | 人事 |

### エージェントベストの見解

これは順番の話です。食品メーカーが、商品名と写真で会社ページを作り、「開発・営業・工場を募集」と一つに並べて先に出し、開発志望だけが押して、営業と工場が採れないまま「Wantedlyは開発向き」と判断する形を、当社は見ています。当社がお願いしている順番は、①商品名を一度だけにし、客層と売り先と商品の種類で「なにを」を書く、②営業の一日と工場の一日を現場から聞き取り、書けるか確かめる、③開発・営業・工場・原料と業務用・本部の募集を分ける、④その上で募集を出す、⑤募集ごとに残った数で見る、です。②が書けない間は、募集を出さず、会社ページの「なにを」だけを整えておきます。③が無いと、開発志望が営業と工場の募集に押し、面談で行き違います。順番を守ると、営業と工場の募集に、営業と工場に向く候補者が押すようになり、開発の募集は「商品が好き」で来た候補者に狭き門を先に伝える場になります。

## まとめ

- 食品は身近で「話を聞きに行きたい」が集まるが、押す数の多さは採りたい人の多さではない。押すのは「商品が好き」で開発だけを見ている候補者で、営業と工場の実態で離れる
- 順番は、商品名を一度だけにし客層と売り先と商品の種類で「なにを」を書く→営業の一日（量販店への提案、棚、数字）と工場の一日（交代勤務、衛生、ライン、繁忙期）を現場から聞き取り書けるか確かめる→開発・営業・工場・原料と業務用・本部の募集を分ける→募集を出す
- 一つの募集に「開発・営業・工場」と並べない。開発は狭き門を隠さず、営業は数字の責任を、工場は交代勤務と勤務地を先に。原料・業務用は最終商品と用途で。本部は商品名ではなく「何を決められるか」で
- 「話を聞きに行きたい」の数を成果と見ず、募集ごとに実態を伝えた後に残った数で読む。押した数が減って残った数が増えたら、記事が実態に近づいた
- 営業が「棚が取れなかった月」を、工場の人が「繁忙期の一日」を、「商品が好き」で入った人が「営業になった後」を本人の言葉で。面談で実態を先に伝え、稼働の時間帯に工場を見てもらう。繁忙期に面談とスカウトを置かない

## よくある質問

### 商品を前面に出さないと、うちの会社と分かってもらえないのでは

商品名は一度、「なにを」に事実として書いてください。ただ、商品の写真と名前で会社ページを埋めると、「商品が好き」の開発志望だけが押し、営業と工場が採れません。客層と売り先と商品の種類で「なにを」を書き、営業と工場の一日を先に書いてください。商品が身近であることは、一度書けば伝わります。

### 「話を聞きに行きたい」は多いのに、営業と工場が採れません

押した数は商品の身近さを映しています。募集ごとに、押した数・面談に来た数・実態を伝えた後に残った数を分けて見てください。営業と工場の募集で残った数が少ないなら、記事を「商品が好き」ではなく営業と工場の一日と数字で書き直し、開発の募集と分けてください。押した数は減りますが、残った数が増えます。

### 食品のWantedlyの設計は、御社に相談できますか

できます。当社は、順番の型、募集を分ける型、募集記事の型、聞き方の型、数の見方の型、面談の型、スカウトの絞る作業を支えられます。営業と工場の一日の開示、数字と勤務地の開示、責任者が話すこと、現場が話すこと、面談、残った数の判断は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
