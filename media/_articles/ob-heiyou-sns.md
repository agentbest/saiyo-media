OfferBoxでオファーを送っている。会社の公式SNSがあり、社員の中にSNSで発信している人もいる。「SNSを採用に使えないか」「フォロワーが増えれば承認が上がるのではないか」と聞かれます。**結論から言うと、オファーを受け取った学生は、承認する前に、送ってきた人と会社をSNSでも確かめます。OfferBoxは「企業が選んで送る入口」、SNSは「文面の本当らしさを確かめる場」であって、学生を集める入口ではありません。併用するなら、送る社員の名義とSNSの本人像を揃え、公式アカウントは一報に絞り、文面とSNSに書くことの線を引き、SNSの数字で承認を判断しないことです。** この記事では、それぞれの役割、学生が確かめること、送る社員の本人像、公式と本人の名義、書くことの線、数字の読み方、工数、やりがちな失敗、社内の分担を整理します。SNS全般の考え方は[SNSからの母集団形成](/media/kh-boshudan-sns/)で書きました。SNSの種類ごとの仕様と数値は書きません。

## それぞれの役割｜「選んで送る」と「確かめる」

| | OfferBox | SNS |
|---|---|---|
| 誰が動くか | 企業。学生を検索して選び、文面を送る | 学生。送ってきた人の名前と会社名で調べる |
| 学生がすること | 文面を読み、承認するかを決める | 送ってきた人が本当にいるか、会社の今はどうかを見る |
| 決まること | 承認するか。文面と送ってきた人で決まる | 文面と本人像がずれていないか。ずれていると承認をためらう |
| 会社が用意するもの | 検索条件、文面、送る社員の名義 | 送る社員の本人像、公式の一報、書かないことの線 |
| 時期 | 送る時期に集中 | 通年。学生が調べるときに見られる |
| 数の性格 | 送信・開封・承認 | フォロー、閲覧、反応。承認とは別の数字 |

学生は、オファーを受け取ると、送ってきた人の名前と会社名で検索します。採用サイトと一緒に、SNSも出てきます。そこで見ているのは、「この人は本当にいるか」「文面で書いてあった雰囲気と、今の会社は合っているか」です。SNSは、学生を集める入口ではなく、文面の裏を取る場所です。採用サイトでの確かめ方は[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)で書きました。

## オファーを受け取った学生が、SNSで確かめること

- **送ってきた人が実在するか**：名前で検索して出てくるか。出てこなくても問題はないが、出てきたときに文面の本人像とずれていないか
- **会社の今**：公式アカウントの最近の投稿。最後の投稿が数年前だと、「動いていない会社か」と読まれる
- **文面に書いた場面が、SNSにもあるか**：「現場の若手が〇〇を任されている」と書いて、SNSに若手が出てこないと、ずれる
- **社員の発信の雰囲気**：文面で「落ち着いた会社」と書いて、社員の発信が煽る調子だと、ずれる
- **クチコミや評判**：SNS上の第三者の言葉。会社が変えられないので、文面で否定しない

学生はSNSを隅々まで見ません。文面で気になったことを、確かめに来ます。文面に書いたことがSNSで裏切られない形になっていれば足ります。

### エージェントベストの見解

相談で最も多い思い込みは、「SNSのフォロワーを増やせば、承認が上がる」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、承認した理由を面談で聞く機会が多くありますが、学生が挙げるのは、文面の場面と送ってきた人で、「SNSを見て承認した」と言う学生はほとんどいません。SNSが出てくるのは、承認をためらった理由のほうです。「送ってきた人を調べたら、文面の印象と違った」「公式の最後の投稿が古くて、動いている会社か分からなかった」。SNSは承認を増やす場所ではなく、承認をためらわせない場所です。当社が先に見るのは、フォロワーの数ではなく、送る社員の名前で検索したときに出てくるものが、文面の本人像とずれていないかです。ずれていなければ、SNSの運用に時間を使うより、文面と送る相手に時間を使います。

## 送る社員の名義と、SNSの本人像を揃える

- **送る社員が、SNSで発信しているなら、文面の本人像を本人の発信に寄せる**：文面で「私は〇〇の仕事をしています」と書く場面が、本人の発信と合っている
- **文面のトーンを、本人が話すときの言葉に寄せる**：人事が代筆した丁寧すぎる文面と、本人の発信の調子がずれると、「代筆」と読まれる
- **本人の発信に、会社が口を出さない**：「書かないこと」の線だけ合意する。文面のために発信を変えさせない
- **発信していない社員の名義で送ってよい**：出てこないことは問題にならない。出てきたときにずれることが問題
- **送る社員が辞めたら、名義を変える**：辞めた社員の名前で送り、学生が調べると「いない人」になる

文面の名義の考え方は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)、現場社員に頼む範囲は[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)で書きました。

## 公式と本人の名義、書くことの線

| 公式アカウント | 本人の発信 | 文面（OfferBox） |
|---|---|---|
| 会社の出来事の一報。イベント、新しい仲間、記事の公開 | 本人の今日の場面。本人の判断で | なぜあなたか。最初の年に何をするか。誰と組むか |
| 書かない：条件、制度の説明、数値、「アットホーム」の抽象語 | 書かない：条件、制度、候補者や取引先が特定できること | 書かない：SNSを見てくださいの誘導、SNSの数字 |
| 頻度：月に数回でよい。古くならないこと | 頻度：本人が決める | 頻度：送る時期に |

- **公式は「動いている会社」と分かる頻度で足りる**：毎日は要らない。最後の投稿が古くならないことが大切
- **文面にSNSへの誘導を書かない**：学生は書かなくても調べる。書くと、文面が広告に読まれる
- **条件と制度は、文面にもSNSにも書かず、採用サイトに**：変わったときに直せる場所に
- **本音の範囲は、文面と本人の発信で同じ線を引く**：文面で書けないことは、SNSでも書かない
- **第三者のクチコミを、文面で否定しない**：気になるなら、面談で聞かれたときに事実で答える

## SNSの数字の読み方

- **フォロワー、閲覧、反応は、「会社の存在を知っている人の数」**：オファーを承認する学生の数ではない
- **SNSが効いているかは、面談で「SNSを見たか、何を見たか」を聞いて分かる**：ためらった理由に出てくれば、直す。承認の理由に出てくることは少ない
- **SNSの反応で、送る相手や文面を変えない**：反応するのは、学生ではないことが多い
- **並べて見るときは、SNSを入口の列に入れない**：SNSから承認は生まれない。「確かめた場所」として、台帳のメモに。[OfferBoxを含む複数媒体の効果を並べて見る方法](/media/ob-heiyou-heiyou-kpi/)

## 工数と名義

| 項目 | OfferBox | SNS |
|---|---|---|
| 動く人 | 人事と、送る社員。検索・文面下書き・送信は代行に出せる | 公式は人事。本人の発信は本人 |
| 時間の性格 | 送る時期に集中 | 公式は月に数回。本人は本人の関心で |
| 外に出せる部分 | 検索、文面の下書き、送信、一次の返信 | 公式の一報の下書き。本人の発信は出せない |
| 費用 | プランの費用。公式ページで確認 | 有料の仕組みを使うなら条件は各社で確認。この記事では書かない |

- **送る時期の時間を先に確保し、SNSは残った時間で**：SNSに時間を使って、承認への当日返信が遅れるのは逆
- **公式の一報を、送る時期の前に一度出す**：「今年もオファーを送っています」ではなく、会社の出来事を一つ。最後の投稿を新しくする目的
- **本人の発信を義務にしない**：続けるかは本人が決める

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| フォロワーを増やせば承認が上がると考える | SNSに時間を使い、文面と送る相手が薄くなる | 文面と送る相手に時間を戻す |
| 文面の本人像と、本人の発信がずれる | 「代筆」と読まれ、承認をためらう | 文面を本人の言葉に寄せる |
| 公式の最後の投稿が古い | 「動いていない会社」と読まれる | 送る時期の前に一つ出す |
| 文面にSNSへの誘導を書く | 文面が広告に読まれる | 書かない。学生は調べる |
| 辞めた社員の名義で送り続ける | 調べると「いない人」になる | 名義を変える |

最も多いのは、一つ目です。SNSの担当を置き、投稿を増やしたのに承認が変わらず、「SNSは効かない」で終わります。効かないのではなく、承認を増やす場所ではないからです。

| 「書かないこと」の線を決める | 人事と責任者 |

| 本人の発信 | 本人（本人の判断で） |

運用代行や代理店が支えられるのは、役割の整理、文面と本人像の揃え方、線の型、公式の一報の下書き、OfferBoxの送る時期の代行までで、線の決定、本人が発信するかの判断、面談で聞くこと、有料の仕組みの判断は企業と本人が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「送る社員の名前で検索したときに、何が出てくるか」を人事が一度見ておかないと、SNSの運用を始めても効果が出ません。当社はOfferBoxの運用代行を受けているので、承認のあとに面談の前で連絡が途切れた学生の理由を追うと、「送ってきた人を調べたら、文面と印象が違った」が出てきます。文面は人事が丁寧に整え、本人の発信は本人の調子で、という二つが、学生の目には「別の人」に見えます。順番は、SNSを整えることではなく、文面を本人の言葉に寄せることです。本人の言葉で書いた文面は、本人の発信とずれません。当社が代行で文面を下書きするときも、本人が話す言葉を聞いてから書き、本人の発信があれば、その調子に寄せています。

## まとめ

- オファーを受け取った学生は、承認の前に送ってきた人と会社をSNSで確かめる。OfferBoxは「選んで送る入口」、SNSは「文面の本当らしさを確かめる場」で、集める入口ではない
- 送る社員の名義とSNSの本人像を揃える。文面を本人の言葉に寄せ、本人の発信に会社が口を出さない
- 公式は一報に絞り、最後の投稿を古くしない。文面にSNSへの誘導を書かない。条件と制度は採用サイトに
- フォロワーや反応は承認の数ではない。SNSが効いているかは、面談で「見たか、何を見たか」を聞いて分かる
- 送る時期の時間を先に確保し、SNSは残った時間で。SNSに時間を使って承認への返信が遅れるのは逆

## よくある質問

### 学生向けにSNSの公式アカウントを新しく作るべきですか

承認を増やす目的なら、勧めません。学生が確かめに来たときに「動いている会社」と分かる場所が一つあれば足り、既存の公式アカウントで足ります。作るなら、月に数回の一報を続けられる担当がいるかを先に決めます。作って止まると、「止まっている会社」に見えます。

### 送る社員がSNSで会社のことを書いています。会社が確認すべきですか

書く前に確認する形は、本人の言葉でなくなるので勧めません。「書かないこと」の線（候補者や取引先が特定できること、条件や制度、数値）を先に合意し、線の中は本人の判断に任せます。文面の側を本人の言葉に寄せることで、発信とのずれは消えます。

### OfferBoxとSNSの併用は、御社に相談できますか

できます。当社は、役割の整理、文面と本人像の揃え方、線の型、公式の一報の下書き、OfferBoxの送る時期の代行を支えられます。線の決定、本人が発信するかの判断、面談で聞くこと、有料の仕組みの判断は、企業と本人が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
