スカウト運用は、募集が出てから「急いで送ろう」と始まり、繁忙期に返信を放置し、閑散期には何もせず、契約の上限が余る月と足りない月ができる、という形になりがちです。**結論から言うと、スカウト運用は一年の単位で計画します。起点は、年間の募集の予定と、各募集の面談枠と、話す人の繁忙期です。月ごとの配分は、急ぎの募集に寄せ、閑散期に潜在層向けを増やし、連休と期末を避けます。コンテンツ（会社ページ・募集記事・ストーリー）の整備を計画の最初に置き、四半期ごとに見直し、担当の異動と引き継ぎと契約の見直しの時期を計画に入れます。計画は守りすぎず、月の見直しで直します。** この記事では、計画が無いと起きること、計画の起点、月ごとの配分、コンテンツの整備、四半期の見直し、担当の異動、契約の見直し、守りすぎないこと、分担を整理します。月の配分の考え方は[スカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/)、OfferBoxの年間の考え方は[OfferBoxの年間スケジュール](/media/ob-nenkan-schedule/)で書きました。

## この作業の目的｜募集が出る前に準備が終わっていて、繁忙期に止まらない状態にする

年間計画の目的は2つです。

- **募集が出る前に、送れる状態になっている**：会社ページと募集記事が整い、型があり、話す人と面談枠が決まっている
- **繁忙期と閑散期で、送る量と対応の形を変えられる**：繁忙期に返信を放置せず、閑散期に関係を作る

「募集が出てから始める」と、整えている間に募集の期限が来ます。「一年中同じ量」だと、繁忙期に対応できず、閑散期に無駄が出ます。

## 計画が無いと、起きること

| 起きること | なぜ |
|---|---|
| 募集が出てから慌てて送る | 会社ページと募集記事が整っておらず、送っても離れる |
| 繁忙期に返信を放置する | 話す人が面談に出られない時期に、同じ量を送っている |
| 閑散期に何もしない | 「募集が無いから」で止め、関係が途切れる |
| 上限が余る月と足りない月ができる | 月ごとの配分が無い |
| 新卒の時期を逃す | 年度の公表内容を確認せず、動く時期を過ぎている |
| 担当の異動で止まる | 異動の時期が計画に無く、引き継ぎが無い |
| 契約の見直しの時期に、判断の材料が無い | 一年分の段の数字が無い |

最も多いのは、最初の「募集が出てから慌てて送る」です。募集の予定は、多くの場合、数か月前には分かっています。

## 計画の起点

| 起点 | 何を書き出すか |
|---|---|
| 年間の募集の予定 | どの職種を、いつ頃、何人程度。「未定」も含めて。人数の具体は自社の計画で |
| 各募集の面談枠 | 話す人が、その時期に週に何回面談に出られるか |
| 話す人の繁忙期 | 事業の繁忙期、決算、大きな案件の時期。面談に出られない月 |
| 送る人の枠 | 読んで書く人が、週に取れる時間。繁忙期は減る |
| 新卒の場合、年度の公表内容 | 広報と選考の時期の扱い。自社の方針と合わせて確認する。この記事では具体は書かない |
| コンテンツの状態 | 会社ページ・募集記事・ストーリーが、いまどこまで整っているか |
| 担当の異動の予定 | 分かっていれば。引き継ぎの時期 |
| 契約の更新の時期 | 見直しの判断をいつするか |

「面談枠」と「繁忙期」が、起点の中心です。送る量は、この二つから逆算します。逆算の手順は[スカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/)で書きました。

### エージェントベストの見解

申し込んだあと、一年目に起きやすいのは、「契約した月から送り始め、会社ページと募集記事が整わないまま数か月が過ぎ、整った頃には繁忙期で面談に出られない」ことです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、一年目の前半を「整える期間」と決めて、後半から本格的に送った会社と、契約の初日から送り始めた会社では、一年後の結果が違います。前者は、後半に整った状態で送り、面談まで進みます。後者は、整わないまま送った前半の返信が来ず、「効かない」と判断して後半も減らします。当社が年間計画を作るとき、最初に置くのは「コンテンツを整える期間」で、その期間は送る量を小さくします。急がば回れ、を計画に入れます。

## 月ごとの配分の考え方

| 時期 | 送る量 | やること |
|---|---|---|
| コンテンツを整える期間（最初） | 小さく | 会社ページ、募集記事、ストーリー数本、型、台帳、分担 |
| 急ぎの募集がある月 | その募集に寄せて多く | 面談枠を先に確保。返信対応の人を決める |
| 話す人の繁忙期 | 減らす。ゼロにしない | 返信対応だけは続ける。潜在層向けの短い面談なら可能なら |
| 閑散期（急ぎの募集が無い月） | 潜在層向けを増やす | 関係を作る。ストーリーを溜める。[転職を考えていない人にスカウトを送る方法](/media/wt-scout-senzai/) |
| 連休の前後、期末 | 減らす | 返信が連休明けに集中する。期末は相手も動きにくい |
| 新卒の動く時期（年度の公表内容に沿って） | 新卒向けに寄せる | 入社してまもない社員の面談枠を確保 |
| 契約の見直しの前 | 通常どおり | 一年分の段の数字を揃える |

「繁忙期はゼロにしない」が要点です。ゼロにすると、再開が重くなります。減らして、返信対応だけは続けます。

## コンテンツの整備を、計画の最初に置く

スカウトの計画は、コンテンツの計画と一緒に作ります。

1. **会社ページ**：「なにを・なぜ・どうやって」が書かれている。[会社ページの基本](/media/wt-kaisha-page-kihon/)
2. **募集記事**：年間の募集の予定にある職種の募集記事を、募集が出る前に整える。[募集記事の基本](/media/wt-boshu-kihon/)
3. **ストーリー**：各募集の職種の人の話を、募集が出る前に数本。[ストーリーの更新頻度の決め方](/media/wt-story-hindo/)
4. **文面の型**：募集ごとに一つ。[スカウト文面のテンプレート管理](/media/wt-scout-template/)
5. **台帳と分担**：送る前に。[スカウトを誰が送るか](/media/wt-scout-tantou/)

「募集が出る前に、その職種のストーリーがある」状態が、計画の目標です。募集が出てから書くと、間に合いません。コンテンツの四半期の見直しは[コンテンツを四半期で見直す方法](/media/wt-naiyou-review/)で書きました。

## 四半期ごとの見直し

年間計画は、四半期ごとに見直します。

- **段ごとの数の、四半期の変化**：読んだ・送った・返信・面談・選考・決定。[スカウト運用のKPI設計](/media/wt-scout-kpi/)
- **募集の予定の変更**：増えた募集、無くなった募集、時期のずれ
- **面談枠と繁忙期の変更**：話す人の状況
- **次の四半期の配分**：どの募集に、どのくらい
- **コンテンツの状態**：次の四半期の募集の記事とストーリーが整っているか
- **担当の状況**：異動の予定、負担の偏り

「次の四半期の募集の記事が整っているか」を、毎回の見直しで確かめます。整っていなければ、次の四半期の最初は整える期間にします。

## 担当の異動と、引き継ぎを計画に入れる

- **異動の時期が分かっていれば、その前の月に引き継ぎを置く**：一覧、通知の設定、対応中の相手、合意。[スカウト運用の引き継ぎ](/media/wt-scout-hikitsugi/)
- **異動の時期が分からなくても、半年に一度「明日変わったら何が渡せないか」を確かめる**
- **異動の直後の月は、送る量を減らす**：後任が対応中の相手を把握する期間
- **現場の担当（読んで書く人）の異動も、同じ**：募集ごとの担当を、計画に書いておく

「異動の直後は減らす」も、繁忙期と同じで、ゼロにはしません。

## 契約の見直しの時期

契約の更新の判断は、一年分の段の数字で行います。

- **一年分の、段ごとの数と変化**：どの段が細いか、直したことで変わったか
- **上限の使い方**：余った月と足りない月。上限が実態に合っているか
- **面談枠と送る量の関係**：枠が埋まっていたか、空いていたか
- **コンテンツの状態**：整ったうえでの一年か、整わないままの一年か
- **社内に残ったもの**：型、台帳、分担、書き方

「整わないままの一年」なら、判断の材料が揃っていません。契約を止めるより、整えてもう一年、という判断もあります。逆に、整ったうえで面談枠が埋まらないなら、上限を減らすか、掲載に絞るかを検討します。使い分けは[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)で書きました。

## 計画を、守りすぎない

年間計画は、守るためのものではなく、慌てないためのものです。

- **月の見直しで、計画と実態のずれを見る**：ずれていれば、計画を直す
- **急な募集が出たら、その募集に寄せる**：計画にない募集でも、記事を整えてから送る
- **募集が無くなったら、その配分を潜在層向けに回す**
- **繁忙期が長引いたら、減らした状態を続ける**：無理に戻さない
- **計画の変更を、台帳に一行残す**：「なぜ変えたか」

「計画どおりに送ること」が目的になると、読まずに送ることになります。計画は、面談枠と繁忙期から逆算した目安で、実態が変わればずらします。

### エージェントベストの見解

これをやる前に、先に決めておかないと計画が絵に描いた餅になることがあります。「年間の募集の予定」です。当社がWantedlyのスカウトの年間計画を支えるとき、配分の逆算と整備の順番は当社が出せますが、「いつ、どの職種を採るか」が社内で決まっていなければ、逆算の起点がありません。「採用計画はまだ」という会社では、当社は「決まっている募集だけで、まず半年の計画」をお願いしています。半年分でも、面談枠と繁忙期が分かれば、配分は出ます。一年分が無いことを理由に計画を作らないより、分かっている範囲で作り、四半期ごとに足すほうが、慌てない運用になります。計画は、完全でなくてよく、無いことだけが問題です。

## まとめ

- 年間計画の目的は、募集が出る前に準備が終わっていることと、繁忙期と閑散期で送る量を変えられること
- 起点は、年間の募集の予定、各募集の面談枠、話す人の繁忙期、送る人の枠、コンテンツの状態、担当の異動、契約の時期。新卒は年度の公表内容を確認
- 最初にコンテンツを整える期間を置き、急ぎの募集に寄せ、繁忙期は減らしてゼロにせず、閑散期に潜在層向け、連休と期末は避ける
- 四半期ごとに、段の変化・募集の変更・面談枠・次の四半期の配分・コンテンツの状態・担当を見直す
- 引き継ぎと契約の見直しを計画に入れ、一年分の段の数字で判断する。計画は守りすぎず、月の見直しで直す

## よくある質問

### 採用計画が年度の途中で変わることが多く、年間計画を作る意味があるか分かりません

変わることを前提に作ります。分かっている募集で計画を作り、四半期ごとに直します。計画が無いと、変わったときに「募集が出てから慌てる」に戻ります。計画は、変わったときに「どこを直すか」が分かるための土台です。

### 一年目は、いつからスカウトを本格的に送ればよいですか

会社ページと募集記事とストーリー数本が整い、型と台帳と分担が決まってからです。それまでは、小さく送りながら整えます。整える期間の長さは、いまのコンテンツの状態で変わります。整わないまま送った返信の無さを「効かない」と判断しないことが、一年目で最も大切です。

### スカウト運用の年間計画は、御社に相談できますか

できます。当社は、計画の型、配分の逆算、コンテンツの整備の順番の整理、四半期の見直しの型、契約の見直しの材料の整理を支えられます。募集の予定、面談枠、繁忙期の判断、契約の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
