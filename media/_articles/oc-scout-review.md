スカウトの受諾率は、毎週見たほうがよいのか、月に一度でよいのか。毎週見ると直したくなり、直すと何が効いたか分からなくなります。月に一度だと、受諾への対応の遅れや、新しい体験談での指摘に気づくのが遅れます。**結論から言うと、受諾率は毎週、短い時間で「先週と比べて」だけを見て、異常に早く気づくために使い、直すのは月に一度、一か所だけにします。文面と絞り込みの設計を変えるのは、年度の切れ目です。毎週見るのは、送った数、受諾の数と型、受諾への対応の速さ、面談の日程が決まった数、受諾が来た文面の一文、新しい体験談のスカウトへの言及、の6つで、週の会は台帳を開いて短く終えます。** この記事では、毎週と月と年度の役割の違い、毎週見る項目、毎週直してはいけない理由、週の会の持ち方、異常のサインとその週にやること、時期による違い、月と年度へのつなぎ、分担を整理します。月と年度の見方は[ワンキャリアのスカウト運用のKPI設計](/media/oc-scout-kpi/)で書きました。他媒体の週次は[OfferBoxの週次レビュー](/media/ob-shuukan-review/)と[Wantedlyのスカウトの返信率を毎週見直す方法](/media/wt-scout-review/)で書きました。

## この作業の目的｜遅れと放置に、その週のうちに気づく

ワンキャリアで、その週のうちに気づかないと取り返しにくいものがあります。受諾への対応の遅れ、新しく書かれた体験談でのスカウトへの指摘、設定の誤りで送れていないこと。これらは、月末まで待つと、学生に「放置している会社」と読まれ、体験談に書かれます。

毎週の見直しの目的は、これらに「その週のうちに気づく」ことです。文面の良し悪しを毎週判断することではありません。

## 毎週と月と年度の役割

| | 毎週 | 月 | 年度 |
|---|---|---|---|
| 目的 | 異常に早く気づく | 細い段を見つけ、一か所直す | 文面と絞り込みの設計を見直す |
| 見るもの | 6つの項目を先週と比べて | 段ごとの数、前月からの変化、面接の言葉 | 段ごとの前年との変化、体験談の言葉 |
| やること | 異常があれば、その週に対処（運用） | 一か所直す（型の一文、読む観点） | 設計を直す（文面の型、絞り込みの条件、送る人） |
| 時間 | 短く | 短い会を一回 | 年に一回 |

週で対処するのは「運用の異常」（対応の遅れ、送っていない、設定の誤り）で、月で直すのは「型の一か所」、年度で直すのは「設計」です。新卒の周期が年単位なので、設計の変更は年度に置きます。

## 毎週見る項目

| 項目 | 見方 | 異常のサイン |
|---|---|---|
| 送った数 | 先週と比べて | ゼロに近い（送る枠が取れていない、設定の誤り） |
| 受諾の数と型 | 前向き・質問・断りの内訳。先週と比べて | 受諾ゼロが続く。断りばかり |
| 受諾への対応の速さ | 受諾から最初の対応までの時間 | 翌日までに返せていないものがある |
| 面談の日程が決まった数 | 受諾した学生のうち、日程が決まった数 | 受諾は来ているのに日程が決まらない（往復が長い、学生の都合に合わない候補） |
| 受諾が来た文面の一文 | 受諾が来た文面の、学生の一文を並べて眺める | 特に無し。月の見直しの材料として溜める |
| 新しい体験談のスカウトへの言及 | 自社の体験談に、新しくスカウトについて書かれていないか | 「テンプレだった」「返信が遅かった」 |

「受諾への対応の速さ」と「新しい体験談のスカウトへの言及」が、毎週の確認で最も重い項目です。前者は運用の問題でその週に直せ、後者はその週に気づかないと翌年まで残ります。

### エージェントベストの見解

相談で最も多い思い込みは、「毎週数字を見ているのだから、毎週改善すべきだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、毎週文面を変えている会社は、どの文面が効いているか分からなくなり、数か月後に「結局、何が良いのか分からない」で止まります。週の受諾の数は少なく、たまたま受諾が来た週と来なかった週の差が大きいので、それに反応して直すと、ぶれを追いかけることになります。しかも新卒は年周期で、学生の状態が週で変わります。当社が毎週の見直しの型を渡すとき、最初に伝えるのは「毎週は見るだけ。文面を直すのは月に一度、設計を変えるのは年度」です。見ることと直すことを分けると、毎週の見直しは短く済み、年度の直しは根拠を持って一か所に絞れます。

## 毎週直してはいけない理由

- **週の数字は少なく、ぶれる**：たまたまの増減に反応することになる
- **受諾は遅れて来る**：今週送った文面の受諾は、来週以降にも来る。今週の数字は先週の文面の結果
- **学生の状態が週で変わる**：試験期間、選考の山、休みで、受諾の来方が変わる
- **一か所ずつ直せなくなる**：毎週直すと、複数の変更が重なり、何が効いたか分からない
- **送る人が疲れる**：毎週「変えろ」と言われると、続かない
- **体験談との整合が崩れる**：文面が毎週変わると、前の週の学生と今週の学生で受け取ったものが違う

例外は、「明らかな誤り」です。文面の誘導先の企業ページが古い、社名や職種名が間違っている、受諾の通知が届いていない。これらは設計ではなく誤りなので、その週に直します。

## 週の会の持ち方

- **出る人**：送る人と、受諾に対応する人。人事が両方なら一人で
- **時間**：短く。台帳を開いて、6つの項目を先週と比べるだけ
- **順番**：対応の速さ→新しい体験談の言及→受諾の数と型→面談の日程→送った数→受諾が来た一文
- **記録**：異常があったかどうかと、その週にやったこと、を一行
- **直さない**：気づいたことは「月の見直しで見る」「年度で見る」と書いて置いておく

「対応の速さ」と「新しい体験談」を最初に見るのは、その週に気づかないと取り返しにくい二つだからです。

## 異常のサインと、その週にやること

| サイン | 考えられること | その週にやること |
|---|---|---|
| 送った数がゼロに近い | 送る枠が取れていない。読む対象がいない。設定の誤り | 送る人の枠と設定を確かめる。絞り込みの結果が空なら月の見直しへ |
| 受諾ゼロが数週続く | 文面か絞り込みか企業ページか体験談の問題。または通知の設定の誤り | 通知と送信の設定を確かめる。誤りがなければ月の見直しへ |
| 断りが続く | 募集と合わない学生に送っている | 絞り込みは月の見直しで。その週は、送る数を減らして読む時間を増やす |
| 対応が遅れている | 対応する人の枠が無い。通知が届いていない | その週に、対応する人と通知を直す。[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/) |
| 受諾は来るが日程が決まらない | 日程の候補を出していない。平日の日中だけの候補 | 返信の型を「学生の都合に合わせた候補を出す」形に、その週に直す |
| 新しい体験談に「テンプレだった」 | 読まずに送っている | その週から、読める数まで送る数を減らす。月の見直しで絞り込みを |
| 新しい体験談に「返信が遅かった」 | 対応の遅れ | その週に対応する人と通知を直す。体験談には反応して書き換えない |

「その週にやること」の多くは、確かめることと記録することです。直すのは、対応する人・通知・返信の型・送る数の4つで、これらは設計ではなく運用です。

## 選考の時期と、試験期間で週の見方を変える

| 時期 | 週の見方 |
|---|---|
| 選考の山（面接が動いている） | 「対応の速さ」を毎日見る。週の会では、遅れが無かったかを確かめる |
| 試験期間 | 受諾が遅れるのは正常。「受諾ゼロが続く」を異常と見ない。送る数を減らす |
| 体験談が増える時期（選考の山のあと） | 「新しい体験談の言及」を重く。増えた分を読み、要点を記録 |
| 長期休み | 学生の返信の時間帯が変わる。台帳で見る |
| それ以外の時期 | 6つを短く。異常が無ければ一行で終える |

「試験期間の受諾ゼロを異常と見ない」が、学生向けのスカウトに特有の注意です。社会人向けと同じ見方をすると、正常な遅れを異常と判断して直してしまいます。

## 受諾が来た文面の一文を、溜める

毎週、受諾が来た文面の「学生の一文」を並べて眺めます。直すためではなく、月の見直しの材料として溜めるためです。

- **どんな箇所を挙げたときに受諾が来たか**：活動か、興味か、選考を先に書いたか
- **受諾が来なかった文面の一文と、並べて見る**：具体の濃さが違うか
- **月の見直しで、読む観点を一つ直す**：「活動の箇所を挙げると受諾が来やすい」なら、読むときに活動を先に見る

一文の見方は[ワンキャリアのスカウトを相手ごとに変える範囲](/media/oc-scout-kojinka/)で書きました。毎週は眺めるだけで、直すのは月です。

## 月と年度へのつなぎ

毎週の記録を、月と年度の見直しに渡します。

1. **四週分の一行の記録**：異常があった週、やったこと
2. **受諾が来た一文と、来なかった一文**：溜めたもの
3. **新しい体験談のスカウトへの言及**：要点で
4. **「月の見直しで見る」「年度で見る」と置いたこと**

月の見直しでは、これに面接の言葉を足し、段ごとの数を並べて、型の一か所を直します。年度の見直しでは、一年分の記録と体験談で、文面の型と絞り込みの条件を見直します。

### エージェントベストの見解

これをやる前に、先に決めておかないと毎週の見直しが「直す会」になることがあります。「毎週は見るだけ、文面を直すのは月、設計を変えるのは年度」を、送る人と上司で合意しておくことです。当社がワンキャリアのスカウトの運用を支える中で、週の会に上司が出ると、「今週受諾が少ないのはなぜだ、文面を変えろ」となりやすく、送る人は毎週文面を変え始めます。新卒は年周期で、試験期間や選考の山で受諾の来方が変わることを、上司に先に伝えてもらいます。この合意があれば、週の会は数分で終わり、月の会で型の一か所を、年度の会で設計を、根拠を持って直せます。無ければ、毎週の数字のぶれと学生の時期の変化に、運用が振り回されます。

## まとめ

- 毎週の見直しは「異常に早く気づく」ため。文面を直すのは月に一度一か所、設計を変えるのは年度
- 毎週見るのは、送った数、受諾の数と型、受諾への対応の速さ、面談の日程が決まった数、受諾が来た一文、新しい体験談のスカウトへの言及の6つ。先週と比べるだけ
- 週の数字は少なくぶれ、受諾は遅れて来て、学生の状態が週で変わるので、毎週直すと何が効いたか分からなくなる。明らかな誤りだけ、その週に直す
- その週に直せるのは、対応する人・通知・返信の型・送る数の4つ。他は確かめて記録する
- 試験期間の受諾ゼロは異常と見ない。受諾が来た一文と体験談の言及を溜め、月と年度に渡す。「毎週は見るだけ」を上司と合意しておく

## よくある質問

### 受諾が来ない週が続くと、不安で文面を変えたくなります

まず、通知と送信の設定に誤りがないかを確かめます。次に、試験期間や選考の山でないかを見ます。どちらでもなければ、受諾は遅れて来るので、数週は待ちます。それでも続くなら、月の見直しで、文面より先に企業ページと体験談を見ます。週ごとに文面を変えると、原因が分からなくなります。

### 新しい体験談に「テンプレだった」と書かれました。すぐ文面を直すべきですか

文面を書き換える前に、その週から読める数まで送る数を減らします。テンプレと書かれる原因は、文面の言葉ではなく、読まずに送っていることです。月の見直しで絞り込みを見直し、読んで一文を書ける数で送る形にします。体験談に反応して文面の言葉だけを変えても、読んでいなければ同じことが書かれます。

### ワンキャリアのスカウトの週次の見直しは、御社に相談できますか

できます。当社は、毎週見る項目の型、異常のサインの一覧、週の会の型、月と年度へのつなぎの型を支えられます。台帳を付けること、対応の速さを直すこと、送ること、体験談を読むことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
