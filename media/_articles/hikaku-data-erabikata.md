データエンジニア・アナリストを新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『データ分析』を志望する学生は多く数は来るが、その多くが『分析の道具を使って何かを言う』像で来て、面談で『データを集めて整えて、使える状態に保つ仕事が中心です』と聞いて『思っていたのと違う』と離れる。道具の名前と統計の科目で絞ると、対象が少ないうえに同じ学生に多くの会社が送っていて返事が来ない」という問題です。**結論から言うと、「データ分析」は志望する学生が多く数は来ますが、「道具で何かを言う」像で来て、実際の仕事（データを集めて整えて、使える状態に保ち、誰かの判断に使ってもらう）を聞いて離れます。媒体を選ぶ前に「エンジニア寄りか、アナリスト寄りか」と「何のデータが、どこにどんな状態であり、誰の何の判断に使われるか」を先に決め、道具の名前と統計の科目で絞らず、「散らかったデータを整えて使えるようにした・数字を見せて人の判断を変えた・数字が合わないとき原因を探した」の行動で探します。送る型は行動で絞ってデータの先輩の名義で、記事を置く型はデータが判断に使われるまでの一日を、比べられる場は「分析職は狭き門・雑用」の体験談に対して企業ページにデータの状態と判断に使われる場面を先に書きます。** エンジニア全般の選び方は[エンジニアの採用媒体の選び方](/media/hikaku-engineer-erabikata/)、マーケターは[マーケターの採用媒体の選び方](/media/hikaku-marketer-erabikata/)で書きました。この記事はデータエンジニア・アナリストに絞ります。

## データエンジニア・アナリストの採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「データ分析」「データサイエンティスト」の名前で募集する | 数は来るが、「道具で何かを言う」像で来て、整える仕事で離れる | 仕事の中身を職種名より先に書く。[Wantedlyでデータエンジニア・アナリストを採る募集記事の書き方](/media/wt-data-boshu/) |
| 道具の名前と統計の科目で絞る | 対象が少なく、同じ学生に多くの会社が送っていて返事が来ない | 道具と科目をあればよい条件に置き、行動で絞る |
| エンジニア寄りかアナリスト寄りかを決めていない | 整える仕事と読む仕事が混ざり、面談で答えられない | 媒体を選ぶ前に決める |
| データの状態が書かれていない | 整ったデータを分析する像で来て、散らかったデータの整理が中心だと離れる | どこにどんな状態であるかを実態で書く |
| 誰の判断に使われるかが書かれていない | 「分析しても誰も見ない」が体験談に書かれる | 誰の何の判断に使われるか、使われなかった例も書く |

## 判断軸を、データエンジニア・アナリストに当てる

| 軸 | データエンジニア・アナリストでの見方 |
|---|---|
| 対象（誰に届くか） | 道具の名前と統計の科目と志望職種を見ない。エンジニア寄りなら「散らかったデータを整えて使えるようにした・数字が合わないとき原因を探した」、アナリスト寄りなら「数字を見せて人の判断を変えた」の行動で探す。情報系と統計系だけでなく、研究でデータを集めて整えた理系全般と、サークルや店舗の数字で判断を変えた文系を含める |
| 型（送るか、来るか、比べられるか） | 送る型は、行動で絞ってデータの先輩の名義で「あなたの数字が合わないとき原因を探した経験を読んで」と一人に書ける。志望が多いので、送る型では絞りを強くする。来る型は、データが判断に使われるまでの一日と、使われなかった話を記事で通年で。比べられる型は、「狭き門」「雑用」の体験談に対して、企業ページにデータの状態と判断に使われる場面を先に書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | データの先輩が名義と面談と技術面接を持つ時間。締めや報告の時期に埋まるので、枠を先に固定しないと運用が止まる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。データ職では、「対象」が多いので絞りを強くすることと、エンジニア寄りかアナリスト寄りかで求める行動を変えることが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「データ職は志望する学生が多く、統計の科目と分析の道具を使った学生に送ればよい」というものです。当社は3媒体すべての販売パートナーとして、データ職の採用の相談を受けますが、道具と科目で絞った会社は、同じ少数の学生に多くの会社が送っていて返事が来ず、「データ分析」の名前で広げた会社は、「道具で何かを言う」像の学生が来て、整える仕事で離れます。データ職の仕事の多くは、散らかったデータを集めて整えて、使える状態に保ち、誰かの判断に使ってもらうことです。この行動は理系にも文系にも書かれていて、道具と科目の有無と一致しません。当社が最初にお願いするのは、絞る条件から道具と科目を「あればよい条件」に下げ、「散らかったデータを整えて使えるようにした・数字を見せて人の判断を変えた・数字が合わないとき原因を探した」を「優先する条件」に上げることと、その前に「エンジニア寄りか、アナリスト寄りか」を決めることです。

## 学生が、確かめること

- **エンジニア寄りか、アナリスト寄りか**：データを集めて整えて保つ仕事か、読んで判断に使ってもらう仕事か。「データ職」の名前では分からない
- **何のデータが、どこにどんな状態であるか**：整っているか、散らかっているか。集める仕組みがあるか。整える仕事の割合
- **誰の何の判断に使われるか**：誰が見て、何を決めるか。使われなかった例はあるか。「誰も見ない」が最も多く書かれる
- **最初の年に何を任されるか**：データの整理か、定型の集計か、依頼に応える分析か。自分で問いを立てるのはいつからか
- **分析の結果は誰が決めるか**：アナリストの立場。言っても決まらないとき、どうなるか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 行動で絞りを強くし、データの先輩の名義で「あなたの数字が合わないとき原因を探した経験を読んで」と一人に書ける | 企業から送る型（OfferBox） | 道具と科目を見ずに、理系全般と文系にも届く。志望が多い職種で、印象ではなく行動で絞れる。[エンジニア向けのオファー文面](/media/ob-engineer-offer-bunmen/) |
| データの先輩が、データが判断に使われるまでの一日と使われなかった話を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | エンジニアとデータ職が読みに来る場で、「道具で何かを言う」像を、整えて判断に使われた記事で置き換える。[Wantedlyでデータエンジニア・アナリストにスカウトを送る文面](/media/wt-data-scout/) |
| 体験談があり、企業ページにデータの状態と判断に使われる場面を先に書ける | 学生が並べて比べる場（ワンキャリア） | 「狭き門」「雑用」の体験談に対して、入る前に状態と場面が分かる会社として読まれる。[ワンキャリアでエンジニアを募集するときの掲載とスカウト](/media/oc-engineer-keisai/) |
| エンジニア寄りかアナリスト寄りかが決まっていない | どれも先ではない | データの責任者と決めてから |
| 誰の判断に使われるかが、書けるほど整理されていない | どれも先ではない | 「事業の判断に使われる」と書いて誰も見ないと、体験談に書かれる |

どれか一つが正解ではなく、行動で絞れるか、先輩が書けるか、体験談があるかで、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせる**：文面で原因を探した経験を読んだ一文を、記事で判断に使われるまでの一日を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **エンジニア寄りなら、バックエンドの探し方と重ねる**：[バックエンドエンジニアの採用媒体の選び方](/media/hikaku-backend-erabikata/)。データの基盤をどこまで持つかで、募集を分けるか一つにするかが決まる
- **技術面接の聞き方の型を、揃える**：「何の道具を使ったかより、数字が合わなかったときどこから探したか、見せた数字で誰の判断がどう変わったか」。[エンジニア向けのスカウト文面](/media/kh-bunmen-engineer/)
- **内定前に、データの実物を見せる**：散らかった状態のデータと、整えた後と、判断に使われた会議の資料を。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)
- **代行と組み合わせるなら、絞る作業と文面の下書きまで。読んで直すのはデータの先輩、技術面接は社内**：[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「データ分析」ではなく、何のデータをどう整え、誰の判断に使われるか

- **「データ分析」「データサイエンティスト」「データで事業を動かす」と道具の名前の一覧を消す**：道具で何かを言う像で来て、整える仕事で離れる
- **エンジニア寄りかアナリスト寄りかを、職種名に**：「〇〇のデータを集めて整えて使える状態に保つデータエンジニア」「△△の数字を読んで□□の判断に使ってもらうアナリスト」
- **データの状態を、実態で**：「データは〇〇にあり、△△の部分は散らかっている。最初の年の仕事の多くは整えること」。整っていないなら、隠さない
- **誰の何の判断に使われるかを、場面で**：「〇〇の会議で△△が□□を決めるときに使う。使われなかった例は〇〇」。使われない実態があるなら、書く
- **最初の年を、時期で**：「最初の〇か月は定型の集計と整理。依頼に応える分析は△か月目から。自分で問いを立てるのは□年目から」。整理が多いなら、整理でデータの癖を覚えると、意味を書く

## 社内の分担

| 作業 | 誰が |
|---|---|
| エンジニア寄りかアナリスト寄りか、データの状態、誰の判断に使われるか、最初の年を決める | データの責任者 |
| 面談と技術面接の枠を、報告の時期の外に固定する | データの責任者。書く前に |
| 行動で絞る条件 | データの先輩が作り、人事か代行が絞る |
| 文面と記事 | 先輩が話し、人事が書き、本人が確認 |
| 名義と、オファーの一文 | データの先輩 |
| 面談と技術面接 | 責任者と先輩。聞き方の型を揃えて。道具の使い方で決めない |
| 「思っていたのと違う」の回数の記録 | 人事。整える仕事か、使われないことか、他社かを分けて |

運用代行や代理店が支えられるのは、絞る条件の型、絞る作業、文面の下書き、記録の型までで、寄りの決定、判断に使われる場面の整理、名義、技術面接は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

データ職の採用で、当社が媒体より先にお願いしているのは、「誰の何の判断に使われるか」を、使われなかった例も含めて書けるかを確かめることです。これを確かめずに媒体を選び、「データで事業を動かす」の言葉で出すと、効果が出ません。データ職の学生が入社後に最も多く離れる理由は、整える仕事の多さではなく、「整えて分析しても誰も見ない」ことです。当社は、送り始める前に、データの責任者と「最近の分析が、誰の何の判断に使われたか。使われなかったものは何か」を書き出し、使われた場面を文面と掲載の最初に、使われなかった実態を面談で話すことを案内しています。使われない実態が多い会社は、それを隠すより、「使われるようにするのがこの仕事」と書くほうが、判断を変えた行動を持つ学生が来ます。順番を変えると、体験談に「誰も見ない」と書かれなくなります。

## まとめ

- 「データ分析」は志望する学生が多く数は来るが、「道具で何かを言う」像で来て、整える仕事で離れる。道具の名前と統計の科目はあればよい条件に置く
- 媒体を選ぶ前に「エンジニア寄りか、アナリスト寄りか」と「何のデータが、どこにどんな状態であり、誰の何の判断に使われるか」を決める
- 「散らかったデータを整えて使えるようにした・数字を見せて人の判断を変えた・数字が合わないとき原因を探した」の行動で、理系全般と文系も含めて探す
- 送る型（OfferBox）は行動で絞りを強くして先輩の名義で、記事を置く型（Wantedly）は判断に使われるまでの一日を、比べられる場（ワンキャリア）は「狭き門・雑用」の体験談に対して企業ページにデータの状態と判断に使われる場面を先に
- 誰の判断に使われるかは、使われなかった例も含めて実態で書く

## よくある質問

### データがまだ散らかっていて、最初の年は整理ばかりです。書くと来なくなりませんか

「整ったデータを分析できる」と隠して入社後に知られるほうが、体験談に書かれます。「データは〇〇にあり、△△は散らかっている。最初の年の多くは整えること。整えたデータが□□の判断に使われる」と、状態と、整えた先の場面を書きます。整える行動を持つ学生は、それで来ます。

### 統計の科目を取っていない学生を採って、分析はできますか

統計の知識は入社後に必要な範囲で覚えられますが、「数字が合わないときどこから探すか」「見せた数字で判断がどう変わったか」の行動は、短期間では身に付きません。科目を「あればよい条件」に下げ、行動で絞り、技術面接で道具の使い方ではなく探し方を聞きます。

### データエンジニア・アナリストの媒体選びは、御社に相談できますか

できます。当社は、絞る条件の型、絞る作業、文面の下書き、記録の型を支えられます。寄りの決定、判断に使われる場面の整理、名義、技術面接は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、データ職の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
