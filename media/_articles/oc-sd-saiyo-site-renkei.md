自社の採用サイトと、ワンキャリアの企業ページ。どちらにも選考の流れや仕事の説明を書いているのに、更新の時期が違い、いつの間にか内容がずれている。学生から「採用サイトとワンキャリアで書いてあることが違う」と聞かれて初めて気づく、という相談はよくあります。**結論から言うと、採用サイトとワンキャリアの企業ページは、同じ内容を二つ持つのではなく、採用サイトを会社の情報の原本、企業ページを体験談を読んだ学生が確かめに来る場、と役割を分けて整合させることが要点です。** そのうえで、選考の流れ、条件、連絡の目安など、食い違うと困る項目から照らし合わせます。この記事では、目的、手順、やりがちな失敗、照らし合わせる項目、社内の分担を整理します。

## この作業の目的｜食い違いで学生を迷わせない

ワンキャリアの学生は、企業ページだけでなく、選考体験談やクチコミ、会社の採用サイトもあわせて読みます。ある学生は体験談を読んでから企業ページへ、別の学生は採用サイトから企業ページへと、入り口はさまざまです。

どこから入っても、選考の流れや条件が同じに見えれば、学生は安心して次に進めます。逆に、採用サイトでは「面接は二回」、企業ページでは「面接は三回」と書いてあれば、学生はどちらが正しいかを確かめる手間を負います。その迷いは、体験談に「書いてあることが違った」と残ることがあります。

目的は、二つの場所の役割を分けて、食い違いで学生を迷わせないことです。

## 二つの役割を分ける

| | 採用サイト | ワンキャリアの企業ページ |
|---|---|---|
| 役割 | 会社の情報の原本 | 体験談を読んだ学生が確かめに来る場 |
| 主な内容 | 事業、制度、社員紹介、募集の全体 | 選考の流れと各段階で見ること、仕事の具体、よく聞かれることへの答え |
| 更新の起点 | 会社の方針や制度が変わったとき | 体験談で新しい点が出たとき、選考が変わったとき |
| 誰が原本を持つか | 人事（会社の言葉は広報と相談） | 人事 |

企業ページに何を先に置くかは[ワンキャリアの企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)にまとめています。

## 整合させる手順

1. **食い違うと困る項目を決める**：選考の流れ、募集する職種、条件、勤務地、連絡の目安。この五つを最初の対象にします
2. **二つを並べて読む**：採用サイトと企業ページの該当箇所を、一つの表に写して比べます
3. **ずれをどちらに合わせるか決める**：原則は採用サイトに合わせます。ただし、企業ページのほうが新しい選考の内容を反映している場合は、採用サイトを直します
4. **企業ページにしか書かないことを決める**：体験談への補足や、よく聞かれることへの答えは、企業ページに置く情報として残します
5. **更新の約束を決める**：どちらかを直したら、もう一方も同じ週のうちに確かめる、と決めます
6. **記録を残す**：直した日と箇所を一行で残し、次の担当者が分かるようにします

外部リンクを置いて企業ページから採用サイトへ移れるようにするかは、プランによって扱いが異なります。確認の方法は[ワンキャリアの掲載ページに外部リンクを置く](/media/oc-gaibu-link/)を参照してください。

### エージェントベストの見解

相談で多い思い込みは、「採用サイトの文章をそのまま企業ページに写せば、整合が取れる」というものです。当社は申込のあとの運用まで見ていますが、採用サイトの文章を写した企業ページは、内容は合っていても、学生が確かめに来た問いに答えていないことが多くあります。採用サイトは会社の全体を説明する場なので、体験談で気にされている「この段階で何を聞かれるか」「配属はどう決まるか」に直接は答えていません。勧めているのは、事実の項目（選考の流れ、条件、勤務地など）は採用サイトと一字一句そろえ、説明の部分は企業ページ向けに書き分けることです。事実はそろえ、説明は書き分ける。この線を引くと、整合を保ちながら、企業ページを体験談に答える場にできます。

## やりがちな失敗

- **片方だけを更新する**：選考の流れを採用サイトだけ直し、企業ページが古いまま残る
- **年度の途中で書き分けをやめる**：忙しい時期に企業ページの更新が止まり、採用サイトとずれる
- **採用サイトにない約束を企業ページに書く**：連絡の目安などを企業ページにだけ書き、社内で守る人が知らない
- **どちらが原本か決めていない**：ずれを見つけても、どちらに合わせるかで迷い、直されない
- **担当が分かれている**：採用サイトは広報、企業ページは人事が持ち、互いの更新を知らない

三つ目は、ワンキャリアでとくに気をつけたい点です。企業ページに書いた連絡の目安は、学生にとっての約束です。社内で守る人にも、その内容が届いている必要があります。

五つ目の、担当が分かれている場合は、互いの更新を知らせる決まりを一つだけ作ります。たとえば「選考の流れか条件を変えたら、もう一方の担当に一言伝える」です。会議を増やさなくても、この一言があるだけで、ずれに気づくまでの期間が短くなります。

## 照らし合わせる項目の一覧

最初に照らし合わせる項目と、見る点の例です。

| 項目 | 見る点 |
|---|---|
| 選考の流れ | 段階の数と順番、各段階の形式（オンライン・対面） |
| 募集する職種 | 職種の名前と数、配属の決め方の説明 |
| 条件 | 給与や勤務時間などの書き方。記載の時点がいつか |
| 勤務地 | 拠点の名前、転勤の有無の書き方 |
| 連絡の目安 | 選考の結果をいつまでに伝えるか |

条件などの労働条件の書き方は、法令で定められた項目があります。採用サイトと企業ページの両方で、項目の抜けがないかは社労士や公式の案内で確認してください。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 食い違うと困る項目の決定と照らし合わせ | 人事 |
| 採用サイトの原本の更新 | 人事（会社の言葉は広報と相談） |
| 企業ページの書き分けと更新 | 人事 |
| 連絡の目安などの約束を面接に出る人へ伝える | 人事 |
| 直した記録の管理 | 人事 |

### エージェントベストの見解

これは順番の話です。整合の作業を始める前に、先に決めておくべきなのは「どちらが原本か」と「直したら何日以内にもう一方を見るか」の二つです。この二つが決まっていないと、照らし合わせをしてずれを見つけても、どちらに合わせるかの相談で止まり、結局直されません。当社が勧めるのは、事実の項目の原本は採用サイト、と一度決め、企業ページの事実の項目は採用サイトを直したあとに追いかける、という一方向の流れにすることです。体験談で新しい点が出て企業ページを先に直したくなったときは、事実の項目なら採用サイトを先に直し、説明の部分なら企業ページだけを直す。流れを一方向にしておくと、担当が替わっても整合が崩れにくくなります。

## まとめ

- 採用サイトは会社の情報の原本、企業ページは体験談を読んだ学生が確かめに来る場と役割を分ける
- 選考の流れ、職種、条件、勤務地、連絡の目安の五つから照らし合わせる
- 事実の項目はそろえ、説明の部分は企業ページ向けに書き分ける
- どちらが原本かと、直したら何日以内にもう一方を見るかを先に決める
- 企業ページに書いた約束は、守る人に届けておく

## よくある質問

### 採用サイトがない会社は、どうすればよいですか

採用サイトがなければ、会社の情報の原本を一枚の文書にまとめ、それを企業ページの事実の項目の元にします。原本を持つ場所が決まっていれば、ほかの媒体を使うときにも同じ一枚から書けます。

### 採用サイトの更新に時間がかかり、企業ページだけが新しくなります

採用サイトの更新が遅れる間は、企業ページの事実の項目を直したことを記録に残し、採用サイトの更新予定もあわせて書いておきます。ずれている期間を短くすることを優先します。

### 他の媒体の企業ページとも整合させたいです

同じ考え方で、採用サイトを原本にして各媒体の事実の項目をそろえます。説明の部分は媒体ごとの学生の読み方に合わせて書き分けます。3媒体の違いは[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
