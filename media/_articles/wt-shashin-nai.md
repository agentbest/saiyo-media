Wantedlyの会社ページや記事に載せる写真がない。撮ったことがない、あるのは集合写真とロゴと外観だけ、社員が写真を嫌がる、職場が撮れない。写真がないから記事が出せない、と止まる。**結論から言うと、素材写真を買わず、スマートフォンで「仕事中の場面」を今週撮ります。写真がなくても出してよい記事と、写真が要る場所を分け、写真を待って記事を止めません。撮れない職場には代わりの見せ方があり、本人の同意は撮る前と載せる前に取り、撮った写真を貯める仕組みを作ります。** この記事では、起きやすい失敗、今週撮る手順、写真がなくても出す判断、撮れない職場の代わり、同意、貯める仕組み、外部に頼む範囲、分担を整理します。写真の選び方は[Wantedlyの会社ページの写真の選び方](/media/wt-kaisha-page-photo/)、ストーリーの写真は[Wantedlyのストーリーの写真の撮り方](/media/wt-story-shashin/)、募集記事のカバーは[Wantedlyの募集記事のカバー写真の選び方](/media/wt-boshu-shashin/)で書きました。この記事は、「写真がない」という状態から始める場合です。

## この作業の目的｜「人と場」を、作らずに見せる

Wantedlyの写真は、会社の格を見せるためのものではなく、候補者に「どんな人が、どんな場所で働いているか」を見せるためのものです。素材写真は「人と場」を見せず、集合写真は「人」を見せません。

目的は、きれいな写真を揃えることではなく、「この人が、ここで、この仕事をしている」が見える写真を、社内で撮れる形にすることです。

## 写真がないときに、起きやすい失敗

| 失敗 | 何が起きるか |
|---|---|
| 素材写真を買う | 「どこかで見た」写真になり、候補者に「作っている」と読まれる。他社と同じ写真が出ることもある |
| 集合写真だけ | 人数は分かるが、人が見えない。少ない会社ほど、少なさが強調される |
| ロゴ・外観・会議室だけ | 「人」がいない。会社は見えるが、誰と働くかが見えない |
| 写真を待って、記事が止まる | 「写真が揃ってから出そう」で、記事の日付が動かない。[Wantedlyの更新が止まってしまったとき](/media/wt-koushin-tomaru/) |
| 加工しすぎる | 背景を消す、美肌にする、色を変える。「作った写真」に見える |
| 写真を撮る日を決めて、全員を並べる | 構えた顔になる。仕事中の自然な表情が撮れない |

共通するのは、「写真は特別に用意するもの」と捉えていることです。写真は、仕事中に撮るものです。

## スマートフォンで、「仕事中の場面」を今週撮る

1. **撮る場面を、一つ決める**：ストーリーで書いた場面か、募集記事の「こんなことやります」の場面。「〇〇さんが△△をしているところ」
2. **本人に、撮ることを伝える**：「記事に載せる写真を、仕事中に撮らせてほしい。いつもどおりで」。同意を取る
3. **自然光のある時間に、少し離れて、たくさん撮る**：窓の近く、昼間。カメラを意識させず、数十枚
4. **自然な表情の数枚を選ぶ**：本人にも見せて、本人が「これなら」と言うものを
5. **明るさだけ調整して、加工しない**
6. **その週の記事に載せる**：撮ったら、すぐ使う

撮り方の詳しくは[Wantedlyの会社ページの写真の選び方](/media/wt-kaisha-page-photo/)の手順3で書きました。プロでなくて構いません。「仕事中を、そのまま」が、素材写真にない価値です。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは見た目が大事なので、プロのカメラマンに撮ってもらってから始めたい」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、プロの撮影を待って会社ページを整えた会社の写真は、きれいですが構えた顔で、「仕事中の場面」になっておらず、候補者に「作っている」と読まれることがあります。逆に、スマートフォンで撮った、少し暗くて構図の甘い「打ち合わせ中の横顔」のほうが、候補者に「この人と働くのか」として届いています。当社が写真の相談を受けるとき、最初にやるのは、カメラマンの手配ではなく、「今週、誰が何をしているところを、誰が撮るか」を決めることです。一枚撮れれば、記事は出ます。

## 写真がなくても出す記事と、写真が要る場所

| 場所 | 写真がなくても出すか |
|---|---|
| ストーリー | 出す。文章だけで成立する。写真はあとから足せる。[Wantedlyのストーリーの写真の撮り方](/media/wt-story-shashin/)の手順4 |
| 募集記事の本文 | 出す。「こんなことやります」が場面で書かれていれば、写真がなくても読まれる |
| 募集記事のカバー | 要る。一覧で最初に見えるので、ないと開かれにくい。仕事中の一枚を先に撮る。[Wantedlyの募集記事のカバー写真の選び方](/media/wt-boshu-shashin/) |
| 会社ページの冒頭 | 要る。ただし、職場の一枚で足りる。揃うまで待たない |
| メンバー欄 | 顔写真が要る。本人の同意で、仕事中の一枚から切り出してよい |
| 会社ページの「どうやっているのか」 | なくても出す。あとから足す |

「写真がないから記事を出さない」は、最も避ける判断です。写真が要る場所は、募集記事のカバーと会社ページの冒頭とメンバー欄で、それぞれ一枚あれば足ります。

## 撮れない職場の、代わりの見せ方

- **機密で職場が撮れない**：人の手元、道具、画面の一部、休憩の場面。「何をしているか」ではなく「誰がいるか」を見せる
- **顧客先で働いていて、自社の職場がない**：打ち合わせ前の準備、移動中、資料を作っている場面。顧客が写らない場所で
- **在宅で、集まる場がない**：オンラインの打ち合わせの画面（本人の同意で）、各自の作業環境の一部、たまに集まる場面
- **製造や現場で、安全上撮れない**：作業前後の場面、道具の手入れ、詰所での打ち合わせ
- **どうしても撮れない**：文章で場面を書き、写真は「人」だけにする。本人の横顔一枚で足りる

「職場」が撮れなくても、「人」は撮れます。候補者が見たいのは、職場より人です。出してはいけない情報の線引きは[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)で書きました。

## 本人の同意の、取り方

- **撮る前に、「記事に載せる写真を撮らせてほしい」と伝える**：撮ってから頼まない
- **載せる前に、選んだ写真を本人に見せる**：「これを載せます」。本人が嫌なら、別の一枚か、載せない
- **どこに、どのくらいの期間載せるかを伝える**：「会社ページのメンバー欄に、在籍中は」
- **退職したら下げる**：[Wantedlyの会社ページの写真の選び方](/media/wt-kaisha-page-photo/)の手順5
- **顔を出したくない人は、後ろ姿や手元でよい**：無理に顔を出させない
- **顧客や取引先が写る写真は、その人の同意も**：写らない構図で撮るほうが早い

同意は、口頭でもよいですが、「誰が、いつ、何に同意したか」を記録しておきます。

## 写真を、貯める仕組み

- **撮る人を、一人決める**：人事か、写真が好きな社員一人
- **週に一度、仕事中の場面を数枚撮る**：記事のために撮るのではなく、日常として撮る
- **貯める場所を一つ**：撮った日、誰が写っているか、同意の有無、を一行で添えて
- **記事を書くときに、貯めた中から選ぶ**：撮りに行かなくてよい状態にする
- **季節や行事は、そのときに撮る**：新しい人が入った日、何かが完成した日

貯める考え方は[Wantedlyのコンテンツを資産として貯める考え方](/media/wt-naiyou-shisan/)で書きました。写真がないのは、撮っていないからで、撮る仕組みがあれば、なくなりません。

## 外部のカメラマンに頼む場合の、範囲

- **頼むなら、社内で撮った写真が揃ったあと**：先に頼むと、構えた写真だけになる
- **頼むのは、会社ページの冒頭の一枚と、メンバーの顔写真**：仕事中の場面は、社内で撮るほうが自然
- **「仕事中を、そのまま」を伝える**：並ばせない、笑わせない
- **社内の人が同席し、いつもの仕事をしている場面を指す**
- **費用と範囲は、自社の判断で**：この記事では扱わない

## 社内の分担

| 作業 | 誰が |
|---|---|
| 今週撮る場面を一つ決める | 人事 |
| 本人に伝えて、同意を取る | 人事 |
| スマートフォンで撮る | 人事か、撮る人一人 |
| 数枚を選び、本人に見せる | 人事と本人 |
| 写真がなくても記事を出す判断 | 人事 |
| 撮れない職場の代わりを決める | 人事と現場 |
| 貯める場所と、週に一度撮る仕組み | 撮る人 |
| 退職時に下げる | 人事 |

運用代行や代理店が支えられるのは、撮る場面の決め方、撮り方の型、写真が要る場所の整理、代わりの見せ方の案、貯める仕組みの型までで、撮ること、同意を取ること、載せる判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社がWantedlyで「写真がない」という相談を受けたとき、写真を揃えることから始めません。先に、ストーリーを一本、文章だけで出してもらいます。文章だけのストーリーが出た時点で、会社ページの日付は動き、候補者には「動いている会社」と読まれます。そのあとで、そのストーリーの場面を、スマートフォンで一枚撮って足します。逆に、写真を揃えてから記事を出そうとすると、写真が揃うまで記事が止まり、揃った写真は構えた顔で、記事の場面と合いません。当社が勧める順番は、記事を出す、その場面を撮る、足す、貯める、です。写真は記事のあとに来ます。

## まとめ

- 素材写真は「人と場」を見せず、集合写真は「人」を見せない。スマートフォンで「仕事中の場面」を、今週、たくさん撮って数枚選び、加工しない
- 写真がなくても、ストーリーと募集記事の本文は出す。要るのは募集記事のカバー・会社ページの冒頭・メンバー欄で、それぞれ一枚あれば足りる。写真を待って記事を止めない
- 撮れない職場でも「人」は撮れる。手元、道具、準備、移動、横顔。候補者が見たいのは職場より人
- 同意は撮る前と載せる前の二回。どこにどのくらい載せるかを伝え、退職したら下げ、顔を出したくない人は後ろ姿や手元で
- 撮る人を一人決め、週に一度、日常として撮って貯める。外部に頼むなら社内で撮った写真が揃ったあとで、冒頭の一枚とメンバーの顔写真だけ

## よくある質問

### 社員が写真を嫌がります

顔を出さなくてよいと伝えます。後ろ姿、手元、横顔、道具、画面の一部。「人がいる」ことは、顔がなくても伝わります。一人でも顔を出せる人がいれば、その人から。嫌がる人に無理に頼むと、載せたあとに「下げてほしい」になり、記事も止まります。同意のない写真は、載せません。

### スマートフォンで撮った写真では、見劣りしませんか

候補者が見ているのは、写真の質ではなく、「この人が、ここで、この仕事をしている」かどうかです。少し暗くて構図が甘くても、仕事中の自然な表情のほうが、プロが撮った構えた顔より届きます。明るさだけ調整して、あとは加工しないことが、「作っていない」として残ります。

### 写真がない会社のWantedlyは、御社に相談できますか

できます。当社は、撮る場面の決め方、撮り方の型、写真が要る場所の整理、代わりの見せ方の案、貯める仕組みの型を支えられます。撮ること、同意を取ること、載せる判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
