リモート勤務ができる募集は、Wantedlyの候補者にとって大きな判断材料です。ところが、募集記事には「リモート可」「フルリモート」と一言書いてあるだけで、どの形なのか、出社はあるのか、どう働くのかが書かれていないことが多くあります。**結論から言うと、リモート勤務の募集記事は「リモート可」で終わらせず、「どの形か」「出社の有無と頻度」「時間の自由度」「やり取りの形」「人と会う場面」「最初の月の過ごし方」を、実態のとおりに書きます。実態と違う「リモート可」は、面談か入社後に分かり、信用を失います。** この記事では、やりがちな失敗、読み手が知りたいこと、実態を先に確かめること、リモートで働く人の話への誘導、会社ページとの整合、面談で同じことを言うこと、分担を整理します。募集記事の「どうやって働くか」の書き方は[「どうやって」の書き方](/media/wt-boshu-dou/)で書きました。この記事は、その中のリモート勤務に絞った話です。

## この作業の目的｜「リモート可」の中身を、読んで分かるようにする

「リモート可」は、会社によって中身が違います。全員が常にリモートの会社、週に何日か出社する会社、入社後しばらくは出社の会社、部署や職種で違う会社、上司の判断で決まる会社。

候補者は、「リモート可」の一言では、自分の希望に合うか判断できません。判断できないまま話を聞きに来て、面談で「実は週に何日かは出社です」と聞き、辞退する。これは双方の時間の無駄です。

募集記事の目的は、「リモート勤務の形が、読んで分かり、自分に合うかを判断できる」ことです。

## やりがちな失敗

| 失敗 | 候補者からどう見えるか |
|---|---|
| 「リモート可」「フルリモート」の一言だけ | 中身が分からない |
| 実態は出社が多いのに「リモート可」と書く | 面談か入社後に分かり、信用を失う |
| 出社の条件（頻度、時期、場面）が書いていない | 「結局、出社なのでは」と疑う |
| 「相談に応じます」で曖昧にする | 決まっていない会社に見える |
| 部署や職種で違うのに、会社全体の話として書く | 応募した職種では違った、となる |
| 入社後しばらくは出社、が書いていない | 入社後に分かる |
| やり取りの形（道具、頻度、定例）が書いていない | 「リモートで放置されるのでは」と不安になる |
| 人と会う場面が書いていない | 「誰にも会えないのでは」と不安になる |

最も多いのは、最初の「一言だけ」です。制度としてリモート可であることを書いただけで、働き方としての中身が無い状態です。

## 読み手が知りたいこと

| 知りたいこと | 書き方 |
|---|---|
| どの形か | 常にリモートか、出社と組み合わせか、期間や職種で違うか。自社の呼び方ではなく、中身で |
| 出社の有無と頻度 | 出社があるなら、どのくらいの頻度で、どんな場面で（定例、顧客訪問、入社直後） |
| 時間の自由度 | 決まった時間に働くか、時間を自分で決められる範囲があるか、連絡が取れる時間帯の約束 |
| やり取りの形 | どの道具で、どの頻度で、定例があるか、雑談の場があるか |
| 人と会う場面 | 対面で会う機会があるか、どのくらいの頻度か、何のためか |
| 最初の月の過ごし方 | 入社直後はどう教わるか、出社があるか、誰が見るか |
| 機材と費用 | 会社が用意するもの、本人が用意するもの、費用の扱い。自社の制度に沿って |
| 地域の制約 | 住む場所に条件があるか、出社できる距離が求められるか |

「最初の月の過ごし方」は見落とされやすい項目です。リモートで入社した人が最初に困るのは、「誰に何を聞けばいいか分からない」ことで、募集記事にその形が書いてあると、候補者は安心して話を聞きに来ます。

### エージェントベストの見解

申し込んだあと、リモート勤務の募集で半年後に起きやすいのは、「募集記事の『リモート可』と、実際の運用がずれていて、面談での辞退が続く」ことです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、「リモート可」と書いた募集記事で話を聞きに来る人は増えるのに、面談後に進まない会社があります。理由を聞くと、面談で「最初の半年は出社」「週に何日かは出社」と伝えていて、候補者が「記事と違う」と感じています。書いた人は「リモート可なのは本当」と考えていますが、候補者は「常にリモート」と読んでいます。当社が募集記事を整えるとき、最初に聞くのは「いま、その職種の人は実際にどう働いていますか」です。実態を先に確かめ、その形を書く。「リモート可」の一言を、実態の一段落に置き換えるだけで、面談後の辞退が減ります。

## 実態を先に確かめる

募集記事に書く前に、社内で確かめておくことがあります。

1. **その職種の人が、いま実際にどう働いているか**：制度ではなく実態。責任者と、その職種の人に聞く
2. **出社の場面と頻度**：定例、顧客訪問、入社直後、繁忙期
3. **上司の判断で変わる部分があるか**：あるなら、その範囲を書くか、決めてから書く
4. **入社直後の扱い**：しばらく出社なら、その期間と理由
5. **機材と費用の扱い**：自社の制度で決まっているか
6. **今後変わる予定があるか**：変わるなら、変わる前提で書くか、変わってから書く

「制度と実態が違う」場合は、実態を書きます。制度上はリモート可でも、その職種では出社が多いなら、出社が多いと書きます。

## リモートで働く人の話へ誘導する

「どう働くか」は、募集記事に書くだけでなく、実際にリモートで働いている人の話で補います。

- **リモートで働く社員のストーリーを書く**：1日の流れ、最初の月に困ったこと、どう解決したか、人と会う場面。書き方は[社員インタビューを書く手順](/media/wt-story-interview/)
- **募集記事の「一緒に働く人」から、その記事へ誘導する**
- **良い面だけでなく、困ったことも**：「最初の月は、誰に聞けばいいか分からず〇〇した。いまは△△の仕組みがある」

「困ったこと」があると、候補者は「本当のことが書いてある」と読みます。リモートの良い面だけの記事は、どの会社にも書いてあります。

## 会社ページとの整合と、面談で同じことを言う

- **会社ページの「どうやっているか」と、募集記事の働き方を揃える**：会社ページが「出社中心」で、募集記事が「フルリモート」だと、どちらが本当か分からない。会社ページの書き方は[会社ページの基本](/media/wt-kaisha-page-kihon/)
- **職種で違うなら、会社ページに「職種で違う」と書き、募集記事にその職種の形を書く**
- **面談に出る人が、募集記事の働き方を読んでおく**：面談で違うことを言わない。記事と面談を揃える考え方は[文章のトーンの決め方](/media/wt-bunsho-tone/)で書いたのと同じ
- **運用が変わったら、募集記事を先に直す**：変わったあとに記事が古いままだと、面談でずれる

### エージェントベストの見解

相談で最も多い思い込みは、「リモート可と書けば、応募が増える」というものです。当社が3媒体の販売パートナーとして募集記事を見る中で、「リモート可」の一言で話を聞きに来る人が増えるのは確かですが、その人たちが求めているリモートの形は様々で、記事に中身が無ければ、面談で「思っていた形と違う」が起きます。増えた分だけ、面談の時間が増え、進まない。逆に、「週に何日か出社、定例は対面、それ以外はリモート」と実態を書いた募集記事は、話を聞きに来る人は絞られますが、来た人は面談で驚きません。当社は、「リモート可」を応募を増やす言葉としてではなく、働き方を伝える一段落として書くようお願いしています。増やすより、合う人が来ることが、面談の時間を減らします。

## まとめ

- リモート勤務の募集記事は「リモート可」で終わらせず、どの形か、出社の有無と頻度、時間の自由度、やり取りの形、人と会う場面、最初の月の過ごし方を実態のとおりに書く
- 一言だけ、実態と違う、出社の条件が無い、「相談に応じます」で曖昧、が面談か入社後の辞退を生む
- 制度ではなく、その職種の実態を先に確かめ、実態を書く
- リモートで働く人のストーリー（困ったことも含めて）へ誘導する
- 会社ページと揃え、面談で同じことを言い、運用が変わったら記事を先に直す

## よくある質問

### リモートの形が、まだ社内で決まっていません

決まっていない状態で「リモート可」と書くと、面談でずれます。決まっている範囲だけを書きます。「現在は〇〇の形。今後は変わる可能性がある」と、決まっている部分と決まっていない部分を分けて書けば、候補者は判断できます。

### 「リモート可」と書かないと、話を聞きに来る人が減りませんか

減ることはあります。ただし、減るのは「常にリモートを求めている人」で、実態が出社ありなら、その人は面談で辞退します。実態を書いて来る人は、面談で驚かず、進みます。話を聞きに来る人の数より、面談後に残る人で見ることを勧めます。

### リモート勤務の募集記事は、御社に相談できますか

できます。当社は、知りたいことの一覧、実態を聞く質問、記事の作成、会社ページとの整合の確認を支えられます。実態の確認と運用の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
