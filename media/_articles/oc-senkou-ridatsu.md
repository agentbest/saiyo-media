ワンキャリアからエントリーが来た、スカウトが受諾された。選考に進んだのに、途中で離脱する。この症状は、「志望度が低かった」で片づけられがちです。ところが、ワンキャリア経由の学生には、他の経路の学生と違う離脱の理由があります。**結論から言うと、ワンキャリア経由の離脱の多くは、「体験談と企業ページで読んだ選考」と「実際の選考」の差から起きます。企業ページに書いた選考の流れと実際が違う、「何を見るか」と書いたことと面接で聞かれたことが違う、連絡が約束した日数より遅い、面接官が体験談と企業ページを読んでいない。段ごとに切り分け、「書いたとおりに運用する」仕組みを作り、離脱の理由を聞き、離脱が続く段を月に数えます。離脱した学生は、体験談に書きます。翌年に残る前に直します。** この記事では、特有の離脱、段ごとのサインと直し方、書いたとおりに運用する仕組み、理由の集め方、段を数えること、体験談に書かれる前提、分担を整理します。本選考の掲載は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)、初回面談は[ワンキャリアのスカウト経由の初回面談の設計](/media/oc-scout-mendan/)で書きました。この記事は、選考に入ったあとの離脱です。

## この作業の目的｜「読んだ選考」と「実際の選考」の差を無くす

ワンキャリア経由の学生は、体験談で「この会社の選考はこうだった」を読み、企業ページで「会社はこう言っている」を読み、その像を持って選考に入ります。像と実際が違うと、「企業ページは建前だった」と感じて離れます。

目的は、差が出ている段を見つけ、実際の選考を企業ページに書いたとおりにするか、企業ページを実際に合わせるかを決めて、差を無くすことです。

## ワンキャリア経由の学生に、特有の離脱

| 離脱の形 | なぜ起きるか |
|---|---|
| 企業ページの選考の流れと、実際が違った | 「一次はオンライン」と書いて対面だった。回数が違った |
| 「何を見るか」と、面接で聞かれたことが違った | 「学生時代に続けたことを聞く」と書いて、志望動機と業界知識を聞いた |
| 連絡が、書いた日数より遅かった | 「〇日以内に」と書いて、それより遅れた |
| 面接官が、体験談と企業ページを読んでいない | 学生は「体験談に〇〇と書いてあった」を前提に来ているのに、面接官が知らない |
| 体験談に書かれた悪い点が、そのまま起きた | 「連絡が遅い」と体験談にあり、今年も遅かった。「やはり」で離れる |
| 他社の選考が速かった | ワンキャリア経由の学生は、複数の会社を並行している |

共通するのは、「書いたこと」と「実際」の差です。ワンキャリアでは、差がそのまま翌年の体験談になります。

## 段ごとの、離脱のサインと直し方

### エントリー・受諾のあと、進まない

| サイン | 直し方 |
|---|---|
| 最初の連絡が、企業ページに書いた日数より遅い | 書いた日数を守る。守れない日数は書かない |
| 最初の連絡が、テンプレの自動返信だけ | 一言と、次の段の日程と形式を、人が書く。[ワンキャリアでスカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/) |
| 次に何が起きるかが分からない | 回数、誰と何を話すか、期間の目安を、最初の連絡で |

### 一次で離脱する

| サイン | 直し方 |
|---|---|
| 面接官が、企業ページの「何を見るか」を知らない | 企業ページと体験談を、面接官に渡す。「何を見るか」と同じことを聞く |
| 面接が、志望動機と業界知識から始まる | 企業ページに書いた「学生時代に続けたこと」から始める |
| 形式が、書いたものと違う | 書いたとおりに。変えるなら、企業ページも変える |
| 体験談に書かれた悪い点が、今年も起きた | 今年の一次で、その点を直す。翌年の体験談が変わる |

### エージェントベストの見解

相談で最も多い思い込みは、「選考途中の離脱は、他社に負けたからで、自社では防げない」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、離脱した学生の記録を段ごとに並べると、「一次で離脱」が集中している会社が多く、その一次の面接官に聞くと、企業ページの「何を見るか」を読まずに、いつもの面接をしています。学生は、企業ページで「学生時代に続けたことを聞く」と読んで準備し、一次で志望動機を問われ、「企業ページは建前だった」と感じて離れます。そして、その差を体験談に書きます。当社が離脱の相談を受けるとき、最初にやるのは、離脱した段を数えることと、その段の面接官が企業ページと体験談を読んでいるかを確かめることです。他社に負ける前に、自社の中で「書いたこと」と「実際」が切れている段があります。

### 二次以降で離脱する

| サイン | 直し方 |
|---|---|
| 段階が多く、間が空く | 段階を減らすか、間を空けない。企業ページに書いた期間の目安を守る |
| 面接官ごとに、聞くことが違う | 段階ごとに「何を見るか」を揃え、企業ページと一致させる |
| 条件が、この段階で初めて出る | 条件は企業ページに事実で。[ワンキャリアの掲載の条件の書き方](/media/oc-keisai-jouken/) |
| 他社の選考が先に決まった | 自社の段階の間隔を短くする |

### 最終で離脱する

| サイン | 直し方 |
|---|---|
| 最終の面接官（役員・代表）が、企業ページと体験談を読んでいない | 最終の面接官にも渡す。最終で「なぜうちに」に戻らない |
| 最終のあと、結果までが長い | 目安を伝え、守る |
| 内定を出したあとの離脱 | 別の問題。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/) |

## 「書いたとおりに運用する」仕組み

- **企業ページの選考の流れと「何を見るか」を、面接官全員に配る**：面接の前に読む
- **書いた日数を、台帳で守る**：「〇日以内に連絡」を、次の連絡日として台帳に
- **選考を変えるなら、企業ページも同時に変える**：企業ページだけ古いままにしない
- **体験談を、面接官全員が読む**：学生が何を前提に来ているかを知る
- **守れないことは、書かない**：「〇日以内」が守れないなら、書かずに「順次」と書く。ただし、遅いことは体験談に書かれる

仕組みの詳しくは[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)の「書いたとおりに運用する仕組み」で書きました。

## 離脱の理由を、聞いて残す

- **聞ける範囲で聞く**：「今後の参考に、差し支えなければ」
- **聞けない場合も、推測を記録する**：事実と推測を分けて
- **面接に出た人にも聞く**：「引っかかった様子があったか」
- **一行で台帳に**：「離脱。段：一次。理由：面接官が『何を見るか』を知らず志望動機から聞いた（推測）」
- **翌年の体験談に、その理由が書かれる前提で読む**：体験談に書かれてから直すのでは、翌年の学生に残る

## 離脱が続く段を、月に数える

| 段 | 数えるもの |
|---|---|
| エントリー・受諾→一次 | 進んだ数と、進まなかった数 |
| 一次 | 次に進んだ数と、離脱した数 |
| 二次以降 | 同じく |
| 最終 | 同じく |
| 各段の理由 | 事実と推測を分けて |

集中している段が、直す段です。段の見方は[ワンキャリアの掲載のKPI設計](/media/oc-keisai-kpi/)で書きました。

## 離脱した学生が、体験談に書くことを前提にする

- **離脱した学生も、体験談を書く**：「一次で辞退した。理由は〇〇」
- **離脱の段階での対応が、体験談に残る**：辞退の連絡に、丁寧に返す
- **「書いたことと違った」が体験談に残ると、翌年のエントリーが減る**
- **逆に、「企業ページどおりだった」が残ると、翌年に効く**：[ワンキャリアの掲載のKPI設計](/media/oc-keisai-kpi/)の「独自の指標」
- **今年の選考が、翌年の掲載の一部**

### エージェントベストの見解

これは順番の話です。当社がワンキャリアで「選考で離脱する」という相談を受けたとき、選考の流れを組み直す前に、面接官が企業ページと体験談を読んでいるかを確かめます。読んでいなければ、選考の流れをどう変えても、面接官は「初めて会う学生」として「志望動機は」から始め、学生は「書いてあったことと違う」と感じ、体験談に書きます。逆に、面接官が企業ページの「何を見るか」を読んでいて、そのとおりに聞けば、流れが多少長くても、「書いてあったとおりだった」として進みます。当社が勧める順番は、面接官に企業ページと体験談を配る、「何を見るか」と同じことを聞く、書いた日数を守る、段階と間隔を見直す、です。最初の二つは、今週からできます。

## まとめ

- ワンキャリア経由の離脱は、「体験談と企業ページで読んだ選考」と「実際の選考」の差から起きる。差はそのまま翌年の体験談になる
- 段ごと（エントリー後・一次・二次以降・最終）に切り分け、離脱が集中している段だけを直す
- 一次の離脱は、面接官が企業ページの「何を見るか」を知らず、志望動機から聞くことが多い。企業ページと体験談を面接官全員に配り、書いたとおりに聞く
- 書いた日数を台帳で守り、選考を変えるなら企業ページも同時に変え、守れないことは書かない
- 離脱の理由を聞き、事実と推測を分けて残し、月に段ごとの数を数える。離脱した学生も体験談を書く前提で、辞退の連絡に丁寧に返す

## よくある質問

### 面接官が「企業ページは人事が書いたもので、自分の面接とは別だ」と言います

企業ページに書いた「何を見るか」は、学生への約束で、面接官はその約束を果たす側だと伝えます。学生は企業ページを読んで準備して来ていて、違うことを聞かれると「建前だった」と感じ、体験談に書きます。面接官に、企業ページの「何を見るか」の一文と、体験談の数件を渡し、「この前提で学生が来ます」と伝えるだけで、面接の入り方が変わります。面接官が「何を見るか」を変えたいなら、企業ページも一緒に変えます。

### 体験談に「連絡が遅い」と書かれていて、今年も遅れそうです

今年の選考で、書いた日数を守ります。守れる日数を企業ページに書き、台帳の「次の連絡日」で管理し、遅れそうなときは期限の前に一言送ります。今年守れば、翌年の体験談に「今年は速かった」が残り、去年の体験談が上書きされていきます。守れないなら、体験談は翌年も同じままです。

### 選考での離脱の見直しは、御社に相談できますか

できます。当社は、段ごとの切り分けの型、理由の集め方の型、面接官に渡す一枚の型、「書いたとおりに運用する」仕組みの案を支えられます。理由を聞くこと、面接、選考の流れの決定、企業ページの変更は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
