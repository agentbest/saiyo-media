スカウトの文面が、読まれない、返信が来ない。何が悪いのか分からない。媒体を変えても同じ。**結論から言うと、文面の失敗は、件名・書き出し・本文・締め・姿勢の五つの場所に分けると、型が見えます。失敗は文面に出ますが、原因の多くは三つです。相手を読んでいない、会社を説明している、守れないことを書いている。気づく方法は、相手の目で読み直す、返信が来た文面と来なかった文面を並べる、面談で「文面のどこで」を聞く、の三つです。直す順番は、書き出し、締め、件名、本文、姿勢で、一か所ずつ直します。三つの媒体で、失敗の型は同じです。** この記事では、五つの場所ごとの失敗の型、気づく方法、原因の三つ、直す順番、媒体ごとの違い、分担を整理します。文面の骨組みは[スカウト文面の基本構成](/media/kh-bunmen-kihon/)で書きました。媒体ごとの失敗は[OfferBoxのオファー文面でやりがちな失敗](/media/ob-offer-bunmen-ng/)、[Wantedlyのスカウトでやりがちな失敗](/media/wt-scout-ng/)、[ワンキャリアのスカウトでやりがちな失敗](/media/oc-scout-ng/)で書きました。この記事は、三つに共通する型です。

## この作業の目的｜失敗に「気づける」状態を作る

文面の失敗は、送る側には見えにくく、相手には見えます。送る側が「丁寧に書いた」と思っている文面が、相手には「誰にでも送っている文面」に読まれていることがあります。

目的は、自分の文面の失敗に、相手の目で気づける状態を作ることです。気づけば、直せます。

## 五つの場所ごとの、失敗の型

### 件名

| 失敗 | 相手が受け取ること |
|---|---|
| 会社名だけ、「スカウトのご案内」 | 全部の会社と同じ。区別がつかない |
| 「特別」「厳選」「限定」 | 全員に送っていると分かる |
| 職種名だけ | 検索条件で送った |
| 記号と装飾 | 目立たせようとしている |

直し方は[スカウトの件名の付け方](/media/kh-bunmen-kenmei/)で書きました。

### 書き出し

| 失敗 | 相手が受け取ること |
|---|---|
| 会社説明から始まる | 自分宛ではない |
| 挨拶の定型が長い | 本文も定型だろう |
| 「拝見し」の中身がない | 読んでいない |
| 見出し（所属・大学名・職種名）の引用 | 検索で送った |
| 褒め言葉から始まる | 読んでいなくても書ける |

直し方は[スカウトの書き出しで読まれるかが決まる](/media/kh-bunmen-kakidashi/)で書きました。

### 本文

| 失敗 | 相手が受け取ること |
|---|---|
| 事業の全体、沿革、実績、理念 | 会社説明。読みたいのは自分と仕事 |
| 抽象語（成長、やりがい、風通し、裁量） | どの会社でも書ける。判断できない |
| 仕事の場面がない | 何の仕事か分からない |
| 「なぜあなたに」が「ぴったり」「優秀」 | 誰にでも書ける理由 |
| 複数の募集を一通に | どちらでもいいから来てほしい |
| 条件を隠す、または条件だけ | 隠すと後で辞退、条件だけだと求人票 |

直し方は[スカウトでの会社紹介の書き方](/media/kh-bunmen-kigyo-shoukai/)と[スカウトで「なぜあなたに」を書く方法](/media/kh-bunmen-riyuu/)で書きました。

### 締め

| 失敗 | 相手が受け取ること |
|---|---|
| 「ぜひご応募ください」「エントリーを」 | 応募は重い |
| 「ご興味があればご連絡ください」 | 連絡した先が見えない |
| 面談の形（誰と・どんな形・選考ではない）がない | 押せない |
| 押す言葉（早めに、お見逃しなく） | 焦っている会社 |
| 締めがない | 何をすればよいか分からない |

直し方は[スカウトの締めで次の行動を示す書き方](/media/kh-bunmen-cta/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「文面の失敗は文章力の問題なので、書き方を学べば直る」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の文面を見ていますが、失敗している文面の多くは、文章としては整っています。丁寧で、誤字もなく、読みやすい。それでも返信が来ないのは、相手のプロフィールを読まずに書かれ、会社を説明していて、面談で守れない形を締めに書いているからです。文章力の問題ではなく、「何を書くか」と「何を書かないか」の問題です。当社が文面の相談を受けるとき、最初にやるのは、文章の添削ではなく、五つの場所に分けて、「相手が書いたことが入っているか」「会社説明が入っていないか」「締めに書いたことを面談で守れるか」の三つを見ることです。この三つで、失敗のほとんどが見つかります。

### 姿勢

| 失敗 | 相手が受け取ること |
|---|---|
| 送る数を保つために、読まずに送る | テンプレ。送った数だけ時間が消える |
| 返信がない相手に、繰り返し送る | しつこい会社 |
| 返信が来たあと、返すのが遅い | 返事が来ない会社 |
| 文面に書いた人と違う人が面談に出る | 話が違う |
| 文面と企業ページと面談がずれている | 盛っている会社 |
| 文面を一度作って、直さない | 同じ失敗が続く |

姿勢の失敗は、文面の外にあり、文面をどう直しても、ここが変わらなければ返信は来ません。

## 失敗に、気づく方法

1. **相手の目で読み直す**：送る前に、「自分がこの相手だったら、開くか、読み進めるか、返信するか」を問う。一つでも「いいえ」なら、その場所を直す
2. **返信が来た文面と、来なかった文面を並べる**：台帳から数通ずつ。五つの場所で比べる。差が出た場所が、失敗の場所
3. **面談で、「文面のどこで、話を聞いてみようと思ったか」を聞く**：来た相手が挙げた場所が、効いている場所。挙げない場所が、効いていない場所
4. **月に一度、1から3をまとめて見る**：失敗は、気づく前に台帳に出る

「相手の目で読み直す」は、送る前に毎回できます。他の二つは、月に一度です。

## 失敗の原因は、三つ

| 原因 | 文面に出る形 | 直す場所 |
|---|---|---|
| 相手を読んでいない | 書き出しが会社説明、見出しの引用、「なぜあなたに」が「ぴったり」 | 相手のプロフィールを読み、行動を一つ拾う |
| 会社を説明している | 本文が事業の全体と実績、抽象語 | 会社は一言に、仕事の場面と人で見せる |
| 守れないことを書いている | 締めに書いた人が出ない、「選考ではない」が選考になる、文面と企業ページがずれる | 面談と企業ページを先に整え、書けることだけ書く |

五つの場所の失敗は、この三つの原因のどれかから出ています。場所を直すより、原因を直すほうが、他の場所も一緒に直ります。

## 直す順番

1. **書き出し**：「相手のどこを読んだか」から始める。今日直せる
2. **締め**：「応募」を「話す場」に。今日直せる。ただし、面談の形を先に決める
3. **件名**：書き出しを縮める。書き出しが直れば、自動で直る
4. **本文**：会社説明を一言に、仕事の場面を足す。現場に聞く時間が要る
5. **姿勢**：読まずに送らない、追わない、返すのを遅らせない、文面と面談を揃える。運用の形を変える

一か所ずつ直し、一か月見ます。全部を同時に直すと、何が効いたか分かりません。

## 媒体ごとの、失敗の違い

| 媒体 | 特有の失敗 |
|---|---|
| OfferBox | 学生に「ご経歴」を聞く。面談を選考にする。承認に当日返さない。[OfferBoxのオファー文面でやりがちな失敗](/media/ob-offer-bunmen-ng/) |
| Wantedly | 想いを語って場面がない。相手の「なぜ」を読まない。応募を求める。[Wantedlyのスカウトでやりがちな失敗](/media/wt-scout-ng/) |
| ワンキャリア | 文面と企業ページと体験談がずれる。受諾後の連絡が遅い。体験談に書かれる。[ワンキャリアのスカウトでやりがちな失敗](/media/oc-scout-ng/) |

媒体ごとの特有の失敗も、原因は三つ（読んでいない・説明している・守れないことを書いている）のどれかです。

### エージェントベストの見解

これは切り分けの話です。当社が文面の失敗の相談を受けるとき、「文面の失敗」と「姿勢の失敗」を分けます。前者は、書き出し・締め・件名・本文の型で、今日から数週間で直せます。後者は、読まずに送る、追う、返すのが遅い、文面と面談がずれる、で、文面を直しても変わらず、運用の形を変える必要があります。相談の多くは、両方が混ざっていて、文面だけを直して「変わらない」となり、さらに文面を直し続けています。当社は、文面を直す前に、「承認や返信に当日返せていますか」「文面に書いた人が面談に出ていますか」を確かめます。ここが崩れていれば、文面をどう直しても、相手には「話が違う会社」として残ります。

## まとめ

- 文面の失敗は、件名・書き出し・本文・締め・姿勢の五つの場所に分けると型が見える。文章力の問題ではなく、「何を書くか」「何を書かないか」の問題
- 原因は三つ。相手を読んでいない・会社を説明している・守れないことを書いている。場所より原因を直すと、他の場所も一緒に直る
- 気づく方法は、送る前に相手の目で読み直す・返信が来た文面と来なかった文面を月に一度並べる・面談で「文面のどこで」を聞く
- 直す順番は、書き出し→締め→件名→本文→姿勢。一か所ずつ直して一か月見る
- 姿勢の失敗（読まずに送る・追う・返すのが遅い・文面と面談がずれる）は、文面を直しても変わらない。運用の形を変える

## よくある質問

### 五つの場所の全部に失敗があります。どこから直せばよいですか

書き出しからです。書き出しが会社説明なら、他の場所が良くても読まれていません。書き出しを「相手のどこを読んだか」に変えると、件名はそれを縮めるだけで直ります。次に締めを「話す場」に。本文は現場に聞く時間が要るので、そのあとです。姿勢は、文面と並行して、「当日返す」「追わない」から始めます。

### 文面は直したのに、返信が増えません

姿勢の側を見ます。承認や返信に当日返せているか、文面に書いた人が面談に出ているか、文面と企業ページがずれていないか、読まずに送っている通が混ざっていないか。文面を直しても、ここが崩れていれば変わりません。それも整っているなら、送る相手（「こんな人」と、プロフィールから行動が拾える相手か）を見ます。

### スカウト文面の失敗の見直しは、御社に相談できますか

できます。当社は、五つの場所の点検、失敗の型の整理、並べて見る表の型、直す順番の案を支えられます。相手を読むこと、書くこと、面談、運用の形を変えることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
