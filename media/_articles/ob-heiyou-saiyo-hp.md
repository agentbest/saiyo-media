OfferBoxでオファーを送っている。採用サイトはあるが数年前のまま、またはコーポレートサイトの一ページだけ。「採用サイトを作り直したほうが承認が増えるのではないか」「文面と採用サイトに同じことを書くのは無駄ではないか」と聞かれます。**結論から言うと、オファーを受け取った学生は、承認する前に会社名で検索して採用サイトを見ます。OfferBoxは「送って興味を持ってもらう場所」、採用サイトは「学生が確かめる場所」です。承認は文面と送ってきた人で決まり、採用サイトは「文面と違うことが書いてないか」を確かめる場なので、作り直すより先に、文面に書いた「最初の年」と募集要項をずらさず、送る社員を採用サイトに載せ、最低限の五つの項目を今の内容にします。** この記事では、それぞれの役割、学生が確かめること、文面と採用サイトの揃え方、最低限直す項目、費用と時間の配分、制作会社に出す範囲、やりがちな失敗、社内の分担を整理します。Wantedlyと採用サイトの分担は[Wantedlyと採用サイトの役割分担](/media/wt-heiyou-saiyo-hp/)で書きました。数値は書きません。

## それぞれの役割｜「送って興味を持ってもらう」と「確かめる」

| | OfferBox | 採用サイト |
|---|---|---|
| 学生がすること | 文面を読む。送ってきた人と会社に興味を持つ | 会社名で検索して、公式の情報を確かめる |
| 決まること | 承認するかどうか。文面と送ってきた人で決まる | 「文面と違うことが書いてないか」。ずれていると承認しない、または承認のあとに辞退する |
| 置くもの | 検索条件、文面、送る社員の名義 | 募集要項、選考の流れ、先輩社員、会社概要、制度 |
| 時期 | 送る時期に集中 | 作るときに費用。年に数回の更新 |
| ないとどうなるか | 送れない | 「公式の情報がない」で承認をためらう |
| 古いとどうなるか | 文面が学生に合わない | 募集要項が文面と違い、「どちらが本当か」で離れる |

文面は、学生を送ってきた人と会社に向かわせます。採用サイトは、その学生が「本当か」を確かめる場所です。文面が良くても、採用サイトの募集要項が古いと、確かめる段で「聞いていたのと違う」になります。

## オファーを受け取った学生が、採用サイトで確かめること

- **募集要項**：職種、勤務地、給与の範囲、休日。文面で触れた条件と同じか
- **選考の流れ**：承認したあと、何があるか。面談は選考か、面談のあとに何段あるか
- **先輩社員**：送ってきた人が、採用サイトにいるか。いると「本当にこの人が働いている」と分かる
- **会社概要**：設立、所在地、事業内容の公式の説明。文面の会社紹介と同じか
- **最初の年に何をするか**：文面に書いた「最初の年」が、採用サイトの仕事紹介と合っているか
- **更新日**：いつの情報か。数年前の日付なら、他も古いと読まれる

学生は、採用サイトを隅々まで読みません。文面で気になったことを、確かめに来ます。文面に書いたことが、採用サイトで確かめられる形になっていれば足ります。

### エージェントベストの見解

相談で最も多い思い込みは、「採用サイトを作り直せば、承認が増える」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、承認の理由を面談で聞く機会が多くありますが、学生が挙げるのは、文面の場面と送ってきた人で、採用サイトのデザインを挙げる学生はいません。採用サイトは、承認を増やす場所ではなく、承認をためらわせない場所です。募集要項が文面と同じで、送ってきた人が載っていて、更新日が今年なら、それで役割を果たします。当社が先に見るのは、採用サイトの見た目ではなく、文面に書いた「最初の年」と募集要項が、採用サイトと合っているかです。合っていれば、作り直しの費用は文面と面談の時間に回します。承認が伸びないときに採用サイトを疑うのは、文面と送る相手を見直したあとです。

## 文面と採用サイトをずらさない

| 揃える項目 | 文面 | 採用サイト |
|---|---|---|
| 最初の年にすること | 一文で | 仕事紹介で詳しく。文面と同じ中身 |
| 条件 | 触れるなら概要 | 募集要項で正確に。文面と同じ |
| 送る社員 | 名義と、その人の場面 | 先輩社員として載せる。同じ人 |
| 会社紹介 | 短く | 会社概要で公式に。事実がずれない |
| 選考の流れ | 「承認のあと、まず面談」 | 選考の流れで、面談の位置を明示 |

- **文面に書いた「最初の年」を、採用サイトの仕事紹介と同じ中身にする**：文章は違ってよい。中身がずれない
- **条件を変えたら、文面のテンプレートと募集要項を同じ日に直す**
- **送る社員を、採用サイトの先輩社員に載せる**：載せられないなら、文面の名義を、載っている社員にする
- **文面から採用サイトへの導線を置く**：貼れる形と範囲は、OfferBoxの現在の仕様で確認。貼れないなら、文面で「採用サイトの〇〇に書きました」

文面の基本は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)で書きました。文面と採用サイトを、最後に同じ人が見ます。

## 採用サイトで、最低限直す項目

1. **募集要項**：職種ごとの条件。文面とずらさない
2. **選考の流れ**：承認からの段と、目安の期間。面談の位置
3. **先輩社員**：送る社員を載せる。写真と一言で足りる
4. **会社概要**：設立、所在地、代表、事業内容の公式の説明
5. **更新日**：いつの情報かが分かる形

この五つは、作り直さなくても、既存のページの文言を直すだけで済みます。デザインや動画は、この段では触りません。学生が確かめる段で見ているのは、見た目ではなく「文面と同じか」と「今の情報か」です。採用サイトがない会社は、コーポレートサイトに、この五つを一ページで置きます。

## 費用と時間の配分

| 項目 | 採用サイト | OfferBox |
|---|---|---|
| 作るとき | 制作費。制作会社ごとに条件が違う。この記事では書かない | プランの費用。公式ページで確認 |
| 続けるとき | 保守の費用と、年に数回の更新の時間 | 送る時期の時間。検索・文面・送信・返信・面談 |
| 外に出せる部分 | 設計・デザイン・構築。文言と条件は自社 | 検索・文面の下書き・送信・一次の返信。「こんな人」の決定と面談は自社 |
| 資産の性格 | 作った時点で固定。数年で古くなる | 検索条件と文面の型が残る。送る社員の名義 |

- **最初の年は、採用サイトの費用を最低限にし、OfferBoxの送る時期の時間を確保する**
- **採用サイトの作り直しは、面談の言葉が集まってから予算に入れる**：「採用サイトの何を見たか」が分かると、作るページが絞れる
- **両方を同じ年に大きく変えない**：どちらが効いたか分からなくなる
- **配分の考え方**：[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)

## 制作会社に出す範囲と、更新が止まらない体制

- **制作会社に出せるのは、設計・デザイン・構築**：募集要項と選考の流れと会社概要の文言は、自社で書く
- **採用サイトの文言を、文面と同じ人が見る**：別の人が書くと、ずれる
- **更新の担当を、作る前に決める**：作ったあとに担当がいないと、数年で古くなる。送る時期の前に、五つの項目を見直す日を決める
- **文面のテンプレートと採用サイトの更新を、同じ台帳に持つ**：条件を変えたら、両方を同じ日に直す
- **送る社員が変わったら、先輩社員のページも変える**：辞めた社員が載ったままだと、学生は「いない人の名前で送られた」と読む

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 採用サイトの作り直しを先にする | 送る時期の時間と費用が消える。承認は増えない | 五つの項目だけ直し、送る時期に時間を寄せる |
| 募集要項を文面と違うままにする | 確かめる段で「どちらが本当か」で離れる | 同じ日に直す |
| 送る社員が採用サイトにいない | 「本当にこの人が働いているか」が確かめられない | 先輩社員に載せる、または名義を変える |
| 制作会社に文言まで任せる | 事実がずれ、文面と合わない | 文言は自社。設計と構築だけ出す |
| 辞めた社員が先輩社員に残る | いない人の名前で送っていると読まれる | 送る社員が変わったら同じ日に |

最も多いのは、二つ目です。文面のテンプレートを直したのに、採用サイトの募集要項が前年のままで、承認のあとの辞退が増えます。承認後の辞退の直し方は[OfferBoxの選考離脱を減らす方法](/media/ob-senkou-ridatsu/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 採用サイトの五つの項目を直す | 人事 |
| 文面と採用サイトを揃えて見る | 人事（一人） |
| 送る社員を先輩社員に載せる | 人事と、送る社員 |
| 条件を変えたら両方を同じ日に直す | 人事 |
| 面談で「採用サイトを見たか、何を見たか」を聞く | 面談に出る人 |
| 作り直しの時期と範囲、制作会社に出す範囲 | 責任者と人事 |
| 更新の担当と見直す日を決める | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、最低限直す項目の一覧、文面と採用サイトの揃え方の型、OfferBoxの送る時期の時間の代行までで、条件と文言の決定、制作会社の選定と契約、面談で聞くこと、作り直しの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

送り始めたあと、最初の送る時期で起きることに共通するのは、承認のあとの辞退が、採用サイトの募集要項の古さから来ていることです。当社はOfferBoxの運用代行を受けているので、承認のあとに面談の前で連絡が途切れた学生の理由を追いますが、文面で「最初の年は〇〇から」と書いたのに、採用サイトの仕事紹介が数年前の内容で、学生が「どちらが本当か」で止まっていた、という形が多くあります。文面は今年の担当者が書き、採用サイトは数年前の担当者が作ったので、中身がずれます。送り始める前に、文面に書く「最初の年」と、採用サイトの仕事紹介と募集要項を並べて、ずれている箇所を採用サイトの側で直します。作り直しは要りません。当社が代行を受けるときは、文面を作る前に、この突き合わせを企業と一緒にしています。

## まとめ

- オファーを受け取った学生は、承認の前に会社名で検索して採用サイトを見る。OfferBoxは「送って興味を持ってもらう場所」、採用サイトは「確かめる場所」
- 承認は文面と送ってきた人で決まる。採用サイトは承認を増やす場所ではなく、承認をためらわせない場所
- 文面に書いた「最初の年」と募集要項を、採用サイトとずらさない。送る社員を先輩社員に載せる。条件を変えたら同じ日に直す
- 最低限直すのは、募集要項・選考の流れ・先輩社員・会社概要・更新日の五つ。デザインは触らない
- 作り直しは、面談で「採用サイトの何を見たか」が集まってから。送る時期の時間と費用を先に確保する

## よくある質問

### 採用サイトがまったくありません。OfferBoxを始める前に作るべきですか

先に作らなくてよいです。コーポレートサイトに、募集要項・選考の流れ・先輩社員・会社概要・更新日の五つを一ページで置き、文面に書いたことがそこで確かめられる形にします。送り始めて、面談で「何を確かめたかったか」が集まってから、そのページを広げます。

### 文面に採用サイトのリンクを貼ってよいですか

貼れる形と範囲は、OfferBoxの現在の仕様で確認してください。貼れない場合も、学生は会社名で検索します。大切なのは、貼れるかどうかより、検索して出てきた採用サイトに、文面と同じことが書いてあることです。

### OfferBoxと採用サイトの役割分担は、御社に相談できますか

できます。当社は、役割の整理、最低限直す項目の一覧、文面と採用サイトの揃え方の型、OfferBoxの送る時期の時間の代行を支えられます。条件と文言の決定、制作会社の選定と契約、面談で聞くこと、作り直しの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
