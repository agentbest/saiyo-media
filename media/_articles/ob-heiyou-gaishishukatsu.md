いわゆる上位層の学生を採りたい。絞られた層の学生が集まる場（外資就活ドットコム）に出るか、すでに出ている。OfferBoxも使っている。「上位層の場に出れば上位層が来る」と考えて出たものの、学生は自社を見ておらず、OfferBoxで同じ層に送っても承認が取れない、という状態になりがちです。**結論から言うと、絞られた層の場は「学生が企業群を並べて比べる場」、OfferBoxは「企業が選んで、その学生に送る場」です。使い分けは、自社がその層の「候補」にすでに入っているかで決めます。入っていない層には、OfferBoxで「なぜあなたに」から入り、入っている層には、比べられる前提で見せ方と選考を整えます。** この記事では、それぞれの役割、候補に入っているかの確かめ方、入っていない層への入り方、入っている層への見せ方、文面の型、選考の速さと透明さ、台帳、やりがちな失敗、社内の分担を整理します。絞られた層の場そのものの考え方は[ワンキャリアと外資就活ドットコムの違い](/media/hikaku-onecareer-gaishishukatsu/)、上位大学の学生への文面は[上位大学の学生向けスカウト文面の考え方](/media/kh-bunmen-joui/)で書きました。両サービスの仕様と数値は書きません。

## それぞれの役割｜「並べて比べる場」と「選んで送る場」

| | 外資就活ドットコム | OfferBox |
|---|---|---|
| 学生の層 | 絞られた層。対象の範囲は公式で確認 | 幅広い層。上位層も含む |
| 学生がすること | 企業群を並べ、選考情報と体験談で比べ、自分で選ぶ | 送られた文面を読み、承認するかを決める |
| 企業の立場 | 比べられる側。候補に入っていなければ見られない | 選ぶ側。候補に入っていなくても、文面で「なぜあなたに」を言える |
| 会社が出すもの | 企業の情報、選考情報、イベント | 検索条件、文面、送る社員の名義 |
| 決まること | 学生が自社を「比べる対象」に入れるか | 学生が「自分に来た理由」に納得するか |
| 時期 | 絞られた層の就職活動の時期。早いことが多い。公式で確認 | 送る時期は企業が決める |

絞られた層の学生は、すでに比べる企業群を持っていて、その中で細かく比べます。自社がその企業群に入っていなければ、場に出ても見られません。OfferBoxは、企業群に入っていなくても、「あなたの記述のここを見て、うちの仕事とつながると思った」と送れます。二つの違いは、「比べられる」か「選んで送る」かです。

## 自社が「絞られた層の候補」に入っているかを、確かめる

1. **その層の学生が、自社を比べる企業群に入れているか**：業界、職種、働き方で、その学生たちが並べている企業群に自社が並ぶか
2. **並ぶとして、比べられたときに見せられるものがあるか**：仕事の中身、成長の道筋、選考の透明さ。絞られた層は、細かく比べる
3. **選考の速さと段階が、比べられる企業群と大きく違わないか**：違うと、体験談に「違い」として書かれる
4. **過去に、その層の学生が自社に来た実績があるか**：来ていれば、候補に入っている

三つ以上言えるなら、候補に入っています。二つ以下なら、入っていません。入っていない層に、比べられる場で戦うのは、見られないまま費用と時間が出ます。

### エージェントベストの見解

相談で最も多い思い込みは、「上位層の学生が集まる場に出れば、上位層の学生が来る」というものです。当社は3媒体すべての販売パートナーとして、上位層を採りたいという相談を受けますが、絞られた層の場に出て「反応がない」と言う会社の多くは、その層の学生が比べている企業群に自社が入っておらず、学生の目に入っていません。場に出ることと、候補に入ることは別です。候補に入っていない会社に当社が先に勧めるのは、場に出ることではなく、OfferBoxでその層の学生の記述を読み、「なぜあなたに」を書いて送ることです。比べられる場では見られない会社でも、選んで送る場では「自分に来た理由」で読まれます。承認した学生が面談で「比べていなかったが、話を聞いてよかった」と言う会社が、翌年に候補に入ります。順番は、送る側から入り、候補に入ってから、比べられる場に出ることです。

## 候補に入っていない層には、OfferBoxで「なぜあなたに」から入る

- **検索を、大学名や層ではなく、記述の行動で組む**：上位層の学生も、記述の行動で選ぶ。[上位大学の学生から承認が取れないときの考え方](/media/ob-joui-daigaku/)
- **文面の主役を学生側にする**：「あなたの〇〇の場面を読んで、うちの△△の仕事とつながると思った」。会社の自慢から始めない
- **「なぜ自分に来たか」が分かる一文を、冒頭に**：大学名で選ばれ慣れている学生は、大学名で来た文面を読まない。[上位大学の学生向けスカウト文面の考え方](/media/kh-bunmen-joui/)
- **比べられる企業群の名前を出さない**：「〇〇のような会社と迷っているなら」は、比べる側に回すことになる
- **承認への当日返信と、面談の速さで差をつける**：絞られた層は選考が速い企業群と比べている。承認の翌日に面談の日程が決まる体制を。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)

## 候補に入っている層には、比べられる前提で見せる

- **絞られた層の場に出るなら、選考情報を透明にする**：段階、期間、内容。隠すと体験談に書かれる
- **OfferBoxの文面でも、比べられる前提で書く**：「比べていただいて構いません。うちは〇〇で違います」の一文
- **選考の速さを、比べられる企業群に合わせる**：段階を減らし、期間を短く。[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/)
- **文面の名義と、場に出る社員を同じ人に**：比べる学生が、両方で同じ人を見る
- **文面と、絞られた層の場の企業情報と、採用サイトをずらさない**：細かく比べる層ほど、ずれに気づく。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 台帳と、時期

- **送る側の台帳を一つにし、入口の列に「絞られた層の場（イベント名）」と「OfferBox」**：同じ学生が両方にいることがある
- **場で会った学生には、場の流れで連絡し、OfferBoxで「初めまして」を送らない**：送る前に突き合わせる
- **承認からあとは、来た学生の台帳で、同じ段と基準**：[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)
- **絞られた層の時期は早いことが多い**：OfferBoxで送る時期も、その層には早めに。時期は公式と記述で確認。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
- **承認率を、層で分けて見る**：絞られた層への承認率は低くなりやすい。全体の承認率に混ぜない。[OfferBoxの承認率が低いときに疑う3つの原因](/media/ob-shounin-hikui/)
- **費用は、各媒体の現在の条件を公式ページで確認する**：配分は[OfferBoxを含む複数媒体の予算配分の考え方](/media/ob-heiyou-heiyou-yosan/)

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 候補に入っていないのに場に出る | 見られないまま費用と時間が出る | 四つの問いで確かめ、OfferBoxから入る |
| OfferBoxで大学名や層で検索して送る | 大学名で来た文面と読まれ、承認されない | 記述の行動で選び、「なぜあなたに」を書く |
| 承認への返信が翌日以降になる | 選考が速い企業群と比べられ、離れる | 当日返信と翌日の日程確定 |
| 場で会った学生に「初めまして」を送る | 「会ったのに」で印象が下がる | 突き合わせ、場の流れで連絡 |
| 絞られた層の承認率を全体に混ぜる | 全体が下がって見え、送るのをやめる | 層で分けて見る |

最も多いのは、一つ目です。「上位層を採る」の目的から場に出ることを先に決め、候補に入っているかを確かめていません。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 採りたい層の候補に入っているかを、四つの問いで確かめる | 人事と責任者 |
| 記述の行動で検索を組み、「なぜあなたに」の文面を書く | 人事と送る社員（検索・下書き・送信は代行に出せる） |
| 選考の段階と期間を、比べられる企業群に合わせる | 人事と面接官 |
| 絞られた層の場に出る（候補に入っている場合） | 人事と、文面の名義の社員 |
| 送る側の台帳を一つにし、突き合わせる | 人事（代行と） |
| 承認への当日返信と、翌日の日程確定 | 人事、または代行（一次） |
| 面談で「何を見て来たか」を聞く | 面談に出る人 |
| 場に出るかの判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、候補に入っているかの確かめ方の型、文面の型、台帳と突き合わせの型、OfferBoxの検索・文面下書き・送信・一次返信までで、候補に入っているかの判断、選考の設計、面談、場に出るかの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「その層の学生が、なぜうちを選ぶのか」を一行で書いておかないと、どちらの媒体でも効果が出ません。当社はOfferBoxの運用代行を受けているので、上位層に送る文面を企業と一緒に作りますが、「上位層を採りたい」と言う会社に、この一行を聞くと、「成長できる」「裁量がある」が返ってきます。この二つは、比べられる企業群の全部が言っている言葉で、絞られた層の学生は、この言葉で会社を区別しません。一行は、「〇〇の仕事を、△△の規模で、□□の速さで任せる会社は、うちの他にほとんどない」のように、比べられても残る具体でなければ、文面にも、場の企業情報にも書けません。一行が書けたら、OfferBoxで記述の行動で選んだ学生に、その一行と「なぜあなたに」を送ります。一行が書けないなら、絞られた層の場に出る前に、その層を採る理由から見直します。

## まとめ

- 絞られた層の場は「学生が企業群を並べて比べる場」、OfferBoxは「企業が選んで送る場」。使い分けは、自社がその層の候補に入っているかで決める
- 候補に入っているかは、四つの問い（企業群に並ぶか、見せられるものがあるか、選考の速さが違わないか、実績があるか）で確かめる
- 入っていない層には、OfferBoxで記述の行動で選び、「なぜあなたに」から入る。大学名や層で検索しない。当日返信と翌日の日程確定で速さを保つ
- 入っている層には、比べられる前提で、選考を透明にし、速さを合わせ、文面と場の情報と採用サイトをずらさない
- 台帳を一つにし、場で会った学生に「初めまして」を送らない。絞られた層の承認率は全体に混ぜず、層で分けて見る

## よくある質問

### 候補に入っていないと分かりました。上位層は諦めるべきですか

諦める必要はありませんが、比べられる場から入るのは順番が違います。OfferBoxで、その層の学生の記述を行動で読み、「なぜあなたに」と、比べられても残る一行を送ります。承認した学生が面談で「比べていなかったが、話を聞いてよかった」と言う年が続くと、候補に入ります。候補に入ってから、場に出ます。

### 絞られた層に送ると、承認率が下がります。送るのをやめるべきですか

絞られた層への承認率は、低くなりやすい前提で見ます。全体の承認率に混ぜず、層で分けて、「近い」学生が面談まで来ているかで判断します。来ているなら、承認率が低くても続けます。来ていないなら、文面の「なぜあなたに」と、承認への返信の速さを先に見直します。

### OfferBoxと外資就活ドットコムの使い分けは、御社に相談できますか

できます。当社は、役割の整理、候補に入っているかの確かめ方の型、文面の型、台帳と突き合わせの型、OfferBoxの検索・文面下書き・送信・一次返信を支えられます。候補に入っているかの判断、選考の設計、面談、場に出るかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
