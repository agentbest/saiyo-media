OfferBoxは学生の所在地を問わず送れるので、自社の勤務地から離れた地域の学生にも届きます。**結論から言うと、離れた地域の学生に送るときに決めることは2つです。勤務地と転居の扱いを文面と募集要項で隠さないこと、そして移動の負担を企業側で減らすことです。** この2つが無いと、承認のあとに「勤務地が違った」で辞退が出るか、選考のたびに移動を求めて学生が離れます。この記事では、勤務地の扱い、地元志向か転居可能かの読み方、オンラインと対面の使い分け、交通費の扱い、自社が地方にある場合、やりがちな失敗、人事と現場の分担を整理します。勤務地の書き方は[募集要項の書き方](/media/ob-boshu-youkou/)で書きました。

## この作業の目的｜「来られるか」を学生が判断できるようにする

離れた地域の学生が承認するかどうかは、「仕事に興味があるか」の前に、「その勤務地で働けるか」で決まります。勤務地が曖昧だと、興味があっても承認できず、承認しても面談のあとで辞退します。

企業側でできるのは、勤務地と転居の条件を先に示すことと、選考の途中で何度も移動させないことです。この2つで、学生は「来られるか」を自分で判断でき、判断したうえで承認します。

## 手順1｜勤務地と転居の扱いを、文面と募集要項で隠さない

離れた地域の学生に送る文面には、勤務地と転居の扱いを一言入れます。募集要項にも書きます。

| 書くこと | 書き方 |
|---|---|
| 初任の勤務地 | 具体的な場所。「本社および各拠点」ではなく |
| 転居が要るか | 要るなら「転居を伴います」と明記。要らないなら明記 |
| 転居の支援 | 住宅の手当や社宅、引っ越しの費用の扱い。あれば一言、無ければ書かない。金額は募集要項で |
| 学生の地域に拠点があるか | あるなら、その拠点での勤務の可能性 |
| 在宅の可否 | 出社が前提か、在宅が可能か |

文面の冒頭は他の学生と同じ「読んだ・こう思った・だから送った」で、本文の仕事の中身のあとに、勤務地の一言を添えます。「勤務地は〇〇で、転居を伴います。その点も含めて、まず話を聞いてもらえたら」のように。隠して承認を取っても、面談のあとで辞退されます。文面の構成は[オファー文面の構成](/media/ob-offer-kosei/)で書きました。

## 手順2｜地元志向か、転居可能かを自由記述で読む

離れた地域の学生が、その地域で働きたいのか、転居してもよいのかは、プロフィールから読めることがあります。

- **希望勤務地の記入**：記入があれば、そこを見る。自社の勤務地が含まれていれば送る。含まれていなくても、自由記述で判断する
- **自由記述の志向**：「地元に貢献したい」「地元で働きたい」と書かれていれば、転居は難しい可能性が高い。「場所にこだわらない」「都市部で働きたい」と書かれていれば、転居可能
- **留学や遠方でのインターンの経験**：慣れない場所で暮らした経験があれば、転居への抵抗が小さいことがある。決めつけずに、参考として
- **どちらも書かれていない**：判断できない。文面で勤務地を明記して、学生に判断してもらう

「地元志向の学生には送らない」と決めつけないことも大事です。地元志向でも、仕事の中身で転居を決める学生はいます。送るかどうかより、勤務地を隠さないことが要点です。読み方の基本は[学生プロフィールの読み方](/media/ob-profile-yomikata/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「地方の学生は、うちには来ない」というものです。実際には、来るか来ないかは学生ごとで、企業側が勤務地を隠さず示し、移動の負担を減らせば、離れた地域から来る学生はいます。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、離れた地域の学生を採れている会社に共通するのは、文面と募集要項で勤務地と転居の扱いを最初に示し、初回面談と一次面接をオンラインにして、対面は最終に近い段階に1回だけにしている会社です。逆に、「地方の学生は来ない」と決めて送らない会社は、その学生像を最初から母集団に入れていません。送る前に決めつけるのではなく、勤務地を示して送り、学生に判断してもらう。承認が来れば、その学生は勤務地を知ったうえで興味を持っています。決めつけて送らないより、示して送るほうが、母集団は広がります。

## 手順3｜オンラインを基本にして、対面は選考のまとまった段階に寄せる

離れた地域の学生に、選考のたびに移動を求めると、時間と費用の負担で離れます。

1. **初回面談はオンライン**：進め方は[オンライン面談](/media/ob-mendan-online/)
2. **一次面接もオンライン**：可能なら
3. **対面は、選考のまとまった段階に1回**：二次と最終を同じ日に対面で行う、会社見学と最終面接を同じ日に、など。移動を1回にまとめる
4. **対面の日程は、学生の予定に合わせる**：授業や試験の時期を避け、幅を持って候補を出す
5. **対面の前に、何をするかを伝える**：「この日に、二次面接と最終面接と会社見学を行います」と、移動の価値が分かる形で

選考の段階を統合する考え方は[選考フローを短くする考え方](/media/ob-senkou-sekkei/)で書きました。離れた地域の学生の場合、統合の目的に「移動を減らす」が加わります。

## 手順4｜交通費の扱いを先に示す

対面で来てもらう場合、交通費の扱いを、日程を決める前に示します。学生は、交通費を自分で払うかどうかで、来るかどうかを判断します。

- **支給するなら、その旨と範囲を先に伝える**：どの段階から、どこまでを支給するか。金額や上限は、募集要項か案内で明記する
- **支給しないなら、その旨も先に伝える**：学生が判断できるように。隠して来てもらうと、あとで不信が残る
- **宿泊が要る場合の扱い**：遠方で前泊が要るなら、その扱いも
- **精算の方法**：当日か後日か、必要なもの

「交通費は出ます」と面接の当日に言うより、日程を決めるときに伝えるほうが、学生は来やすくなります。この記事では金額には触れません。自社の規定で決め、案内に明記します。

## 手順5｜自社が地方にあり、都市部の学生に送る場合

逆の場合もあります。自社が地方にあり、都市部の大学の学生に送る場合です。考え方は同じですが、読むところが少し変わります。

| 読むところ | 何が分かるか |
|---|---|
| 出身地 | 自社の地域が出身なら、戻る意向があるかもしれない。自由記述で確かめる |
| 自由記述の志向 | 「地元に戻りたい」「地方で暮らしたい」「自然の近くで働きたい」など |
| 希望勤務地 | 自社の地域が含まれているか |
| 都市部にこだわる記述 | あれば、転居は難しい可能性が高い。無ければ判断できない |

文面では、地域で働くことの実態を隠さず書きます。暮らしの環境、通勤の形、都市部との違い。「自然が豊か」だけでは判断できないので、仕事の中身と暮らしの実態の両方を書きます。出身地が自社の地域の学生には、「戻る」という選択肢を文面で示すと、読まれることがあります。ただし、戻ることを前提にはしません。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 勤務地を曖昧にして送る | 面談のあとで「勤務地が違った」で辞退 | 文面と募集要項で明記する |
| 「地方の学生は来ない」と送らない | 母集団に入れていない | 勤務地を示して送り、学生に判断してもらう |
| 地元志向の学生を読まずに切る | 仕事の中身で転居を決める学生を見逃す | 自由記述を読み、勤務地を示して送る |
| 選考のたびに対面を求める | 移動の負担で離れる | オンラインを基本に、対面は1回にまとめる |
| 交通費の扱いを当日に伝える | 学生が来るかどうかを判断できない | 日程を決めるときに伝える |
| 転居の支援を隠す、または誇張する | あとで不信が残る | あるものをそのまま書く |
| 自社が地方で「自然が豊か」だけを書く | 仕事と暮らしの実態が分からない | 両方を隠さず書く |

最も多いのは、最初の「勤務地を曖昧にして送る」です。承認の数は出ますが、面談のあとで辞退が出ます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 勤務地と転居の扱いを確定する | 人事（事業部門に確認） |
| 転居の支援と交通費の規定を確認する | 人事 |
| 文面と募集要項に勤務地を書く | 人事（または運用代行） |
| 自由記述で志向を読む | 読む人 |
| オンラインと対面の段階を設計する | 人事と面接官 |
| 対面の日にまとめる段階を調整する | 面接官 |
| 交通費の案内と精算 | 人事 |

面接官の協力が要るのは、「対面の日に複数の段階をまとめる」ことです。二次と最終を同じ日に行うには、面接官の予定を合わせる必要があります。運用代行に出す場合、文面と連絡は代行が行えますが、勤務地の確定と選考の設計は社内です。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。「転居の支援と交通費の扱い」を、送り始める前に社内で確定することです。当社がOfferBoxの運用の相談で離れた地域の学生の話になったとき、この2つが「その都度判断」になっている会社は、文面にも募集要項にも書けず、学生に聞かれてから答えることになります。答えるまでに日が空き、学生は判断できないまま他社に進みます。逆に、確定している会社は、文面に一言入れ、案内に明記でき、学生は承認の前に判断できます。確定に時間がかかるなら、離れた地域の学生に送り始める時期をそれに合わせます。確定しないまま送るより、確定してから送るほうが、承認のあとに残る学生が増えます。勤務地の話は、文面の書き方ではなく、社内で決める話です。

## まとめ

- 離れた地域の学生に送るときは、勤務地と転居の扱いを文面と募集要項で隠さない
- 地元志向か転居可能かは自由記述で読むが、決めつけて送らないのではなく、勤務地を示して送り、学生に判断してもらう
- 初回面談と一次面接はオンライン、対面は選考のまとまった段階に1回。移動を減らす
- 交通費の扱いは、日程を決めるときに先に示す。金額は規定で決め、案内に明記する
- 自社が地方にある場合は、仕事と暮らしの実態を両方書く。「自然が豊か」だけでは判断できない

## よくある質問

### 地元志向と書いている学生にも、送ってよいですか

送って構いません。仕事の中身で転居を決める学生はいます。ただし、勤務地と転居の扱いを文面で隠さず示し、学生に判断してもらいます。承認が来れば、勤務地を知ったうえで興味を持っています。

### 対面の面接を、何回まで求めてよいですか

離れた地域の学生には、1回にまとめることを勧めます。二次と最終を同じ日に、会社見学と最終を同じ日に、など。回数より、移動の負担と、その日に得られるものの釣り合いで学生は判断します。交通費の扱いも先に示します。

### 離れた地域の学生へのアプローチは、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、勤務地と転居の扱いの確定、文面と募集要項への書き方、オンラインと対面の段階の設計を一緒に行います。運用代行を受ける場合は、勤務地を明記した文面と、日程の幅を持たせた連絡を当社が行います。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
