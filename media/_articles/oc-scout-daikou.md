ワンキャリアのスカウト運用は手間がかかるので、代理店や運用代行に頼みたくなります。頼むこと自体は問題ありませんが、「全部お願いします」と丸投げすると、文面が会社の言葉でなくなり、「選考で何を見るか」が想像で書かれ、面談で学生が「文面と違う」と感じ、ワンキャリアではそれが体験談に書かれ、契約が終わると社内に何も残りません。**結論から言うと、代行に出せるのは、絞り込みの条件・型と見本・台帳の設計と集計・自社の体験談の要点・KPIの表・見直しの材料・受諾への返信の型・引き継ぎの記録で、社内に残すのは、プロフィールを読んで一文を書くこと・送り主・受諾への対応・面談・「選考で何を見るか」を言葉にすること・年度の公表内容の確認です。「読んで書く一文」まで頼む場合は条件を付け、情報共有の範囲を決め、成果は段と体験談で見て、社内に戻す順番を決めておきます。** この記事では、丸投げで起きること、出せる作業と残す作業、一文まで頼む条件、情報共有の範囲、成果の見方、戻す順番、分担を整理します。代理店の代行の全体は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)、Wantedlyのスカウトの代行は[Wantedlyのスカウトを代行に出せる範囲](/media/wt-scout-daikou/)、ワンキャリアの掲載原稿の外注は[ワンキャリアの掲載原稿を外部に頼むときの注意](/media/oc-keisai-daikou/)で書きました。

## この作業の目的｜社内の時間を減らしつつ、会社の言葉で送り、体験談に書かれない形にする

代行に頼む目的は、「社内の時間を減らす」ことと、「運用の技術を借りる」ことの2つです。目的に入っていないのは、「会社の言葉を代行に作ってもらう」ことと、「選考で何を見るかを代行に決めてもらう」ことです。

ワンキャリアのスカウトの文面を読んだ学生は、企業ページと自社の体験談を読み、面談で会社の人と話し、その印象を体験談に書きます。文面の言葉が代行のものだと、面談でずれ、体験談に残ります。代行に頼んでも、文面の一文は社内の人の言葉で、面談に出るのは社内の人。これが守られていれば、代行に頼んだ運用も、会社の運用になります。

## 丸投げすると、起きること

| 起きること | なぜ |
|---|---|
| 文面が「一般的な学生向け」の文面になる | 代行は、会社の最初の1年の具体を知らない |
| 「選考で何を見るか」の一文が想像で書かれる | 面接に出る人の言葉でない。企業ページとずれる |
| 面談で「文面と違う」となる | 送り主と話す人がずれる。話す人が文面を知らない |
| 受諾への対応が、代行を経由して遅れる | 通知が代行に届き、社内に転送される。ワンキャリアでは体験談に書かれる |
| 年度の公表内容の確認が抜ける | 代行が時期の扱いを自社の方針で確認していない |
| 社内に型も台帳も残らない | 代行の中にある |
| 契約が終わると、運用が止まる | 社内に運用する人がいない |

最も重いのは、「体験談に書かれる」と「契約が終わると止まる」です。前者は翌年に残り、後者は代行の期間が運用ではなく外注の期間だったことを意味します。

## 出せる作業と、残す作業

| 出せる（代行が担える） | 残す（社内でしかできない） |
|---|---|
| 絞り込みの条件の設計（募集の「こんな人」から） | プロフィールを読んで、学生時代の場面と重なる点を書く |
| 文面の型と見本の作成（4段の変えない部分） | 送り主（入社してまもない社員の名前） |
| 自社の体験談を読んで、要点を出す | 「補う」と「直す」の分けと、運用を直すこと |
| 台帳の設計と、毎月の集計 | 受諾への対応（翌日までに、後期は当日に） |
| KPIの表の設計と、段の集計 | 面談に出て、最初の1年の話をする |
| 週と月と年度の見直しの材料の整理 | 「選考で何を見るか」を言葉にする |
| 受諾への返信の型（前向き・質問・選考の確認・条件・断り） | 年度の公表内容と自社の方針の確認 |
| 面談の流れの型、聞くこと・聞かないこと | 上司との合意（段で見る、体験談で見る） |
| 引き継ぎの一覧の作成と保管 | 選考の判断 |
| 送る前のチェック（避ける言葉、企業ページとの整合） | 学生への連絡そのもの |

「出せる」は、型・設計・集計・材料・要点で、「残す」は、読む・書く・送る・返す・話す・言葉にする・確認する・決めるです。前者は仕事の具体を知らなくてもでき、後者は知っている人でないとできません。

### エージェントベストの見解

発注する側の会社が誤解しやすいのは、「代行に頼めば、社内の時間はほぼゼロになる」という点です。当社がワンキャリアのスカウトの支援をするとき、社内から減るのは、絞り込みを考える時間、型を作る時間、体験談を読んで要点を整理する時間、台帳を集計する時間、見直しの材料を揃える時間です。残るのは、読んで一文を書く時間、受諾に対応する時間、面談に出る時間、「何を見るか」を言葉にする時間です。むしろ、当社が絞り込みと型を整える分、社内の人が読んで書く数は増えることがあります。当社は、支援を始める前に、「社内に残る時間」を週の単位で先に見積もってお伝えします。それでも、人事が一人で全部を担う場合に比べれば、社内の時間は減ります。減るのは設計と集計の時間、残るのは学生と向き合う時間です。

## 「読んで書く一文」まで代行に頼む場合の条件

社内に読んで書く時間がどうしても無い場合、一文まで代行に頼むことはあります。その場合、次の条件を付けます。

1. **代行が書いた一文を、送り主本人が読んで了承してから送る**：了承なしに送らない。名前だけ借りる形にしない
2. **代行に、企業ページの「最初の1年」と、入社してまもない社員の「最初の月に詰まった場面」を先に渡す**：仕事の具体を知らないまま書かせない
3. **代行に、面接に出る人が言葉にした「何を見るか」を渡す**：代行が想像で書かない
4. **代行に、自社の体験談の要点を共有する**：学生が読んでいることを知らずに書かせない
5. **代行が書いた一文と、受諾の有無と、体験談への言及を台帳に残す**：どの一文が効いたかを社内で見る
6. **期間を決める**：「社内で読める人が確保できるまで」。ずっと代行に書かせない
7. **面談に出る人が、送った文面を面談前に読む**：文面の内容を知らずに出ない

条件が守れないなら、一文まで頼まず、送る数を減らして社内で書きます。数が減っても、会社の言葉で送るほうが、面談でずれず、体験談に書かれません。

## 代行との情報共有の範囲

- **学生の個人情報は、採用の目的の範囲で、必要なものだけ**：氏名や連絡先を共有する必要があるか、代行の作業ごとに確かめる
- **台帳の集計だけを頼むなら、個人が特定できない形で渡せるか**：段の数と一文の型だけなら、特定は要らない
- **自社の体験談の要点を共有する場合、体験談を書いた学生が特定される形にしない**
- **共有の方法と、契約が終わったあとの扱いを、契約で決める**：自社の方針と管理部門の確認に沿って
- **管理画面のアクセス権を渡す場合は、範囲を限る**：送信の権限を渡すか、閲覧だけか。仕様は管理画面で確認
- **媒体の規約で、代行の利用に関わる定めがあれば確認する**：規約は管理画面とヘルプで

この記事では、契約や法的な扱いの具体は書きません。自社の方針と、管理部門や専門家の確認に沿ってください。

## 代行の成果の見方

| 見るもの | 意味 |
|---|---|
| 読んだ数と送った数 | 絞り込みが機能しているか（代行の設計の結果） |
| 受諾の数と型 | 型と絞り込みと企業ページの結果。ただし一文は社内の人の言葉 |
| 受諾から対応までの時間 | 社内の受諾対応の結果。代行の成果ではない |
| 面談から選考への段 | 社内の面談の結果。代行の成果ではない |
| 体験談へのスカウトの言及 | 「自分のことを読んでいた」なら、型と一文が揃っている。「テンプレだった」なら、読める数を超えている |
| 社内に残った型・台帳・体験談の要点・記録 | 代行の期間が終わったあとに使えるか |

「社内に残ったもの」と「体験談への言及」を成果に含めるのが要点です。受諾率だけで代行を評価すると、代行は煽りの型を作り、それが体験談に書かれます。KPIの考え方は[ワンキャリアのスカウト運用のKPI設計](/media/oc-scout-kpi/)で書きました。

## 代行から社内に戻す順番

1. **最初から、型と台帳と体験談の要点は社内の置き場に置く**：代行の中に置かない。代行は、社内の置き場を更新する形で
2. **月の見直しに、社内の人が出る**：代行が材料を揃え、社内が決める
3. **受諾への返信の型と面談の型を、社内の人が使う**：代行が作り、社内が使う。最初から
4. **絞り込みの条件の考え方を、社内に伝えてもらう**：条件そのものではなく、なぜその条件か
5. **体験談の読み方の観点を、社内に伝えてもらう**：代行が読んでも、次の年は社内で読める形に
6. **代行の期間の後半で、集計を社内でやってみる**：代行が確認する形に
7. **引き継ぎの一覧を、代行が作って社内に渡す**：代行が終わるときに

## 社内の分担

| 作業 | 誰が |
|---|---|
| 代行に出す範囲と残す範囲を決める | 人事と責任者 |
| 企業ページの「最初の1年」と「何を見るか」を代行に渡す | 人事 |
| 自社の体験談を読む（代行に要点を頼む場合も、分けは社内） | 人事 |
| 読んで一文を書く（または代行の一文を了承する） | 入社してまもない社員 |
| 受諾への対応 | 人事 |
| 面談 | 入社してまもない社員 |
| 年度の公表内容と自社の方針を確認する | 人事 |
| 代行の成果を段と体験談で見る | 人事 |
| 情報共有の範囲を決める | 人事と管理部門 |
| 型と台帳を社内の置き場に置く | 人事（代行が更新） |

運用代行や代理店が支えられるのは、上の「出せる」の一覧のとおりで、「残す」の一覧は企業が行います。

### エージェントベストの見解

相談で最も多い思い込みは、「代行に頼むなら、文面も送信も受諾対応も、全部やってもらえるはずだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの支援をしていますが、受諾への対応と面談を当社が代わりに行う形はお受けしていません。受諾した学生は、会社の人と話したくて返しています。当社が返すと、その時点で「会社の人ではない」と分かり、面談で会う人とも違い、ワンキャリアではそれが体験談に書かれます。当社が担うのは、絞り込み、型、体験談の要点、台帳、集計、見直しの材料、引き継ぎの記録までで、学生と直接やり取りする部分と、「何を見るか」を言葉にする部分は社内に置きます。この線引きを、頼む前にお伝えするのは、「全部やってもらえる」と思って始めた会社が、社内に残る時間を見積もっておらず、途中で止まることを避けるためです。

## まとめ

- 代行に出せるのは、絞り込み・型と見本・台帳の設計と集計・体験談の要点・KPIの表・見直しの材料・受諾への返信の型・面談の型・引き継ぎの記録。社内に残すのは、読んで一文を書く・送り主・受諾対応・面談・「何を見るか」を言葉にする・年度の公表内容の確認・上司との合意
- 丸投げすると、文面が会社の言葉でなくなり、「何を見るか」が想像で書かれ、面談でずれ、体験談に書かれ、契約が終わると止まる
- 一文まで頼むなら、送り主の了承・最初の1年と何を見るかと体験談の要点を渡す・台帳・期間・面談前に読む、の条件を付ける
- 情報共有は採用の目的の範囲で必要なものだけ、体験談を書いた学生が特定されない形で、契約と管理部門の確認に沿って
- 成果は受諾率ではなく段と体験談への言及と「社内に残ったもの」で見て、型と台帳と体験談の要点は最初から社内の置き場に置き、戻す順番を決めておく

## よくある質問

### 社内に読んで書く人がいないので、一文も代行に頼みたいです

条件付きで頼めます。送り主本人が一文を読んで了承してから送る、企業ページの最初の1年と面接に出る人が言葉にした「何を見るか」と自社の体験談の要点を渡す、期間を決める、の三つは外しません。それでも、送る数を減らして社内で書くほうが、面談でずれず、体験談に「テンプレだった」と書かれず、社内に書き方が残ります。まず、週に一度の短い枠で入社してまもない社員が読めないかを確かめてから、代行に頼む範囲を決めます。

### 代行の契約を終えたら、運用が止まってしまいました

型と台帳と体験談の要点が代行の中にあった可能性があります。代行に引き継ぎの一覧と、型・台帳・要点・記録の引き渡しを頼みます。それが無ければ、企業ページから型を作り直し、管理画面の送信履歴から台帳を起こし、自社の体験談を最新の分から読みます。再開の手順は[Wantedlyのスカウト運用が止まったときの再開方法](/media/wt-scout-saikai/)で書いた考え方と同じです。次に代行を使うときは、最初から社内の置き場に置く形で始めます。

### ワンキャリアのスカウトの運用代行は、御社に頼めますか

頼めます。当社は、絞り込み、型と見本、自社の体験談の要点、台帳の設計と集計、KPIの表、週と月と年度の見直しの材料、受諾への返信の型、面談の型、引き継ぎの記録を担えます。読んで一文を書くこと、受諾への対応、面談、「何を見るか」を言葉にすること、年度の公表内容の確認、上司との合意は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
