ワンキャリアのスカウトは、対象を絞り、プロフィールを読み、文面を書き、受諾に返し、面談につなぐまでの手数が多いため、代理店や運用代行に頼むことを考える会社は少なくありません。ただ、ワンキャリアでは学生が文面のあとに企業ページ、クチコミ、選考体験談を読み、面談やその後の連絡を体験談に書くことがあります。代行の働きぶりも、会社の対応として記録に残るということです。**結論から言うと、代行に任せられるのは、絞り込みの条件、文面の型と見本、台帳と集計、自社の体験談の整理、見直しの材料、受諾への返信の型、引き継ぎの記録です。社内に置くのは、プロフィールを読んで書く一文、送り主、受諾への対応、面談、「選考で何を見るか」を言葉にすること、年度の公表内容の確認です。一文の下書きまで頼むなら約束事を決め、成果は受諾率だけでなく体験談と社内に残ったもので測り、終わる日から逆に引き継ぎを組みます。** 代理店に運用を頼む全体像は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)、掲載原稿の外注は[ワンキャリアの掲載原稿を外部に頼むときの注意](/media/oc-keisai-daikou/)、Wantedlyでの線引きは[Wantedlyのスカウトを代行に出せる範囲](/media/wt-scout-daikou/)で扱っています。

## 代行を考える前に｜学生は文面のあと、企業ページと体験談で会社を確かめる

ワンキャリアでは、スカウト、企業ページ、イベントの掲載、クチコミ、選考体験談が同じ会社の枠の中にあります。学生はスカウトを読んで終わりではなく、その会社の情報を一通り確かめてから受諾を決めます。

このため、代行に頼むときに守りたいのは、文面と企業ページと体験談の言葉が食い違わないことです。文面の中の「最初の1年」の説明や「選考で何を見るか」が代行の想像で書かれると、企業ページや体験談と合わず、学生が確認の段階で離れます。面談で会う社員が文面の内容を知らなければ、そのずれは面談の場で表れ、あとから体験談に書かれます。

代行に頼む目的は、社内の手間を減らすことと、運用の手順を借りることです。会社の言葉そのものを代わりに作ってもらうことや、選考の基準を決めてもらうことは、目的に含めません。

## 任せきりにしたときに体験談に残ること

| 任せきりの形 | 学生の側で起きること |
|---|---|
| 文面を代行がすべて書く | どの学生にも当てはまる文面になり、「自分を読んでいない」と受け取られる |
| 選考の説明を代行が推測で書く | 企業ページの選考の流れと食い違い、どちらを信じるか迷わせる |
| 受諾の通知を代行が受けて転送する | 最初の連絡まで日が空き、体験談に「受諾後の連絡が遅い」と残る |
| 面談に出る社員が文面を読まない | 面談で話がかみ合わず、「スカウトの内容と違った」と書かれる |
| 掲載とスカウトを別の窓口が見る | イベントの案内や企業ページの更新とスカウトの時期がずれる |
| 型や台帳を代行の手元だけに置く | 契約が終わると、社内に何も残らない |

最も重いのは、受諾後の対応の遅れと、契約後に何も残らないことです。前者は体験談として翌年の学生にも読まれ、後者は代行の期間が社内の経験にならなかったことを意味します。

## 代行に渡せる仕事、社内でしか担えない仕事

| 代行に渡せる | 社内で持つ |
|---|---|
| 募集の「こういう学生に会いたい」から絞り込みの条件を組む | プロフィールを読み、学生の経験と仕事が重なる点を書く |
| 文面のうち変えない部分の型と見本を作る | 送り主として名前を出す |
| 自社のクチコミと選考体験談を読み、指摘を整理する | 指摘のうち、運用や選考を直すものを決めて直す |
| 台帳を設計し、月ごとに集計する | 受諾への最初の連絡と日程調整 |
| 受諾への返信の型（日程案内、質問への答え方、辞退への返し方）を作る | 面談に出て、仕事の中身を話す |
| 掲載中のイベントとスカウトの時期を照らし合わせる | 「選考で何を見るか」を面接に出る人の言葉にする |
| 送る前の点検（企業ページとの食い違い、避けたい言い回し） | 年度の公表内容と自社の方針の確認 |
| 見直しの材料と引き継ぎの一覧を作る | 選考の判断と、学生への連絡そのもの |

左側は、仕事の中身を深く知らなくても進められる設計・整理・集計です。右側は、会社の人でなければ書けない、話せない、決められないことです。ワンキャリアの場合、左側に「体験談の整理」と「掲載・イベントとの照合」が入るのが特徴で、掲載まで見ている代理店に頼むと、この部分を一続きで扱えます。

### エージェントベストの見解

代行を検討する会社がよく持っている期待は、「頼めば社内の手間はほとんど無くなる」というものです。当社は求人広告代理店として、ワンキャリアの掲載とスカウトの両方を支援していますが、実際に社内から減るのは、絞り込みを考える時間、型を整える時間、体験談を読み込んで整理する時間、台帳を集計する時間です。一方で、プロフィールを読んで一文を書く時間、受諾に返す時間、面談に出る時間は残ります。絞り込みが整うと読む価値のある学生が増えるため、書く数がかえって増える会社もあります。当社は支援を始める前に、この「残る時間」を週の単位で見積もり、誰が担うかを決めてから始めるようにしています。残る時間を知らずに始めると、受諾への連絡が後回しになり、その遅れがワンキャリアでは体験談に表れるためです。

## 一文の下書きまで頼むときの約束

社内に書く時間がどうしても取れない時期には、学生ごとの一文の下書きまで代行に頼むことがあります。その場合は、次の約束を先に決めます。

1. **送り主が下書きを読み、自分の言葉として納得してから送る**：名前だけを貸す形にしない
2. **企業ページの「最初の1年」と、若手社員が最初に戸惑った場面を先に渡す**：仕事の具体を持たないまま書かせない
3. **面接に出る人が言葉にした「選考で見ること」を渡す**：選考の説明を推測で書かせない
4. **自社のクチコミと選考体験談で指摘されている点を共有する**：学生がそれを読んだうえで文面を読むことを前提にする
5. **下書きの一文、受諾の有無、その後の体験談での言及を台帳に残す**：どの一文が届いたかを社内で振り返れるようにする
6. **期間を区切る**：社内に書く人を確保できるまでとし、ずっと続けない
7. **面談に出る社員が、送った文面を面談の前に読む**

約束が守れない場合は、下書きを頼むより、通数を減らして社内で書くほうを選びます。数が減っても、面談でずれず、体験談に「テンプレのようだった」と書かれにくくなります。

## 個人情報と管理画面の権限をどこまで渡すか

- **学生の情報は、採用の目的の範囲で、その作業に要るものだけを渡す**：作業ごとに、氏名や連絡先が本当に要るかを確かめる
- **集計だけを頼むなら、個人を特定しない形で渡せないかを考える**：受諾の数や文面の型の比較なら、氏名は要らない
- **体験談の整理を頼むときも、投稿者を推測するような扱いをしない**
- **管理画面の権限は範囲を絞る**：送信まで任せるのか、閲覧だけか。権限の設定は管理画面とヘルプで確認する
- **受け渡しの方法と、契約終了後の扱いを契約で決める**：自社の方針と管理部門の確認に沿う
- **媒体の規約に、代行の利用に関わる定めがあれば目を通す**

契約や法務の具体はこの記事では扱いません。自社の方針に沿い、必要に応じて管理部門や専門家に確かめてください。

## 代行の働きを何で測るか

| 指標 | 何の結果か |
|---|---|
| 読んだ数と送った数の比 | 絞り込みの条件が機能しているか（代行の設計） |
| 受諾の数 | 絞り込みと型と企業ページの結果。一文は社内の言葉なので、代行だけの成果ではない |
| 受諾から最初の連絡までの日数 | 社内の対応の結果 |
| 面談からエントリーや選考への進み方 | 社内の面談の結果 |
| 新しい体験談でのスカウトや対応への言及 | 型、一文、対応がそろっているか |
| 社内に残った型、台帳、体験談の整理、記録 | 契約が終わったあとに社内で使えるか |

受諾率だけで代行を評価すると、目を引く言い回しの型に寄り、それが体験談で「釣りのようだった」と書かれることがあります。体験談での言及と、社内に残ったものを測る項目に入れておくと、代行と会社の目線がそろいます。指標の組み方は[ワンキャリアのスカウト運用のKPI設計](/media/oc-scout-kpi/)で書きました。

## 終わる日から逆に考える引き継ぎ

代行は、いつか終わる前提で始めます。終わる日に何が社内に残っているかを先に決め、そこから逆に組みます。

1. **型、台帳、体験談の整理は、初日から社内の共有の場所に置く**：代行はそこを更新する役にする
2. **月の見直しには社内の担当が同席する**：代行が材料をそろえ、決めるのは社内
3. **受諾への返信の型と面談の進め方は、最初から社内の人が使う**
4. **絞り込みの条件は、条件そのものより「なぜその条件か」を説明してもらう**
5. **体験談の読み方の観点を、社内に言葉で残してもらう**：翌年は社内で読めるようにする
6. **期間の後半は、集計を社内で行い、代行が確認する形に切り替える**
7. **最後に、引き継ぎの一覧を受け取る**

契約が終わって運用が止まった場合の立て直しは、[Wantedlyのスカウト運用が止まったときの再開方法](/media/wt-scout-saikai/)で書いた手順が、ワンキャリアでも参考になります。

## 社内の分担

| 作業 | 担当 |
|---|---|
| 代行に渡す範囲と社内に置く範囲を決める | 人事と採用の責任者 |
| 企業ページの「最初の1年」と「選考で見ること」を代行に渡す | 人事 |
| 体験談の指摘のうち、直すものを決める | 人事 |
| 学生ごとの一文を書く（または下書きを読んで納得する） | 若手社員などの送り主 |
| 受諾への最初の連絡と日程調整 | 人事 |
| 面談 | 若手社員など、仕事の中身を話せる人 |
| 年度の公表内容と自社の方針の確認 | 人事 |
| 代行の働きを体験談と社内に残ったもので測る | 人事 |
| 情報の受け渡しの範囲を決める | 人事と管理部門 |

代理店や運用代行が担えるのは「代行に渡せる」の列の作業で、「社内で持つ」の列は企業が担います。

### エージェントベストの見解

代行の範囲を決めるとき、最後まで社内に置くよう勧めているのが、受諾した学生との最初のやり取りと面談です。ワンキャリアで受諾する学生は、企業ページや体験談を読んだうえで、その会社の人と話してみたいと考えて返しています。最初の返信が会社の外の人から届くと、その時点で期待とずれ、面談で会う社員とも別人になります。そうした経緯は、選考体験談に「スカウト後のやり取りが事務的だった」といった形で残りやすいものです。当社は求人広告代理店として、ワンキャリアのスカウトでは返信の型や日程調整の手順までは整えますが、学生への最初の返信と面談は会社の方にお願いしています。この線を先に共有しておくと、「全部任せられると思っていた」という行き違いがなくなり、社内の誰が受諾を受けるかを始める前に決められます。

## まとめ

- ワンキャリアでは学生が文面のあとに企業ページと体験談を読み、その後の対応も体験談に書くことがある。代行の働きも会社の対応として残る
- 代行に渡せるのは、絞り込み、型と見本、台帳と集計、体験談の整理、掲載・イベントとの照合、返信の型、引き継ぎの記録
- 社内に置くのは、読んで書く一文、送り主、受諾への対応、面談、「選考で何を見るか」の言葉、年度の公表内容の確認
- 一文の下書きを頼むなら、送り主の納得・材料の受け渡し・台帳・期間・面談前の確認を約束にする。情報と権限は要る分だけ渡す
- 成果は受諾率だけでなく、体験談での言及と社内に残ったもので測り、終わる日から逆に引き継ぎを組む

## よくある質問

### 書ける社員がいないので、一文も含めて頼みたいのですが

期間を区切って下書きを頼むことはできます。その際は、送り主が読んで納得してから送ること、企業ページの「最初の1年」と面接に出る人の「選考で見ること」、体験談で指摘されている点を代行に渡すことを外さないでください。並行して、月に数回でも若手社員が読める時間を作れないかを確かめ、社内で書く形に戻す日を決めておくと、体験談にも社内にも良い形で残ります。

### 代行が終わったあと、スカウトが止まってしまいました

型、台帳、体験談の整理が代行の手元にしか無かった可能性があります。まず代行に、それらと引き継ぎの一覧の引き渡しを頼みます。手に入らない場合は、企業ページから型を作り直し、管理画面の送信履歴から台帳を起こし、体験談は新しい投稿から読み直します。次に代行を使うときは、初日から社内の共有の場所に置く形で始めてください。

### ワンキャリアのスカウト代行は、御社に頼めますか

頼めます。当社は求人広告代理店として、ワンキャリアの掲載・イベント・スカウトを一続きで見ており、絞り込み、型と見本、体験談の整理、台帳と集計、返信の型、見直しの材料、引き継ぎの記録を担います。学生ごとの一文、受諾への対応、面談、「選考で何を見るか」の言葉、年度の公表内容の確認は、企業側で行っていただく形です。
