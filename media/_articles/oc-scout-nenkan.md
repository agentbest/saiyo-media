ワンキャリアのスカウトは、契約した月から送り始め、企業ページが整わないまま送り、体験談が増えても読まずに送り続け、面接に出る人の繁忙期に受諾を放置し、上限が余る月と足りない月ができる、という形になりがちです。**結論から言うと、ワンキャリアのスカウトは一年の単位で計画し、「企業ページと体験談が整っているか」「面接に出る人の枠」「年度の公表内容と自社の方針」を軸に、整える・送る・読む・直すの四つの期間を置きます。整える期間に企業ページを体験談と揃え、送る期間に選考とイベントの予定に合わせて送り、読む期間に増えた体験談を読み、直す期間に年度の切れ目で文面の型と絞り込みを見直します。担当の異動と引き継ぎを計画に入れ、初年度は「整える」に長く時間を使い、計画は守りすぎず、月の確認で直します。** この記事では、計画が無いと起きること、計画の軸、四つの期間、時期ごとの送る量、異動と引き継ぎ、初年度と二年目以降、守りすぎないこと、掲載の年間計画との揃え方、分担を整理します。時期の具体（何月）は、年度と自社の方針で変わるので、この記事では書きません。掲載の年間計画は[ワンキャリアの年間掲載計画の組み方](/media/oc-nenkan-keisai/)、他媒体のスカウトの年間計画は[Wantedlyのスカウト運用の年間計画](/media/wt-scout-nenkan/)で書きました。

## この作業の目的｜整わないまま送らず、体験談を読む時期を逃さず、繁忙期に止まらない

ワンキャリアのスカウトで取り返しにくいのは、三つです。企業ページが整わないまま送って最初の印象が薄いまま残ること、体験談が増えたのに読まずに送り続けて「テンプレだった」が積み重なること、面接に出る人の繁忙期に受諾を放置して「返信が遅かった」と書かれること。

年間計画の目的は、この三つを防ぐことです。「整える」を送る前に置き、「読む」を選考の山のあとに置き、繁忙期は送る量を減らす。それだけで、三つは減ります。

## 計画が無いと、起きること

| 起きること | なぜ |
|---|---|
| 企業ページが整わないまま送る | 整える期間が無い。文面で興味を持った学生が企業ページで離れる |
| 体験談が増えても、読まずに送り続ける | 読む期間が無い。「テンプレだった」「掲載と違った」に気づかない |
| 面接に出る人の繁忙期に、受諾を放置する | 繁忙期を見ていない。体験談に「返信が遅かった」 |
| 上限が余る月と足りない月ができる | 月ごとの配分が無い |
| 年度の公表内容の扱いとずれた時期に送る | 確認の時期が計画に無い |
| 担当の異動で止まる | 異動の時期が計画に無く、引き継ぎが無い |
| 契約の見直しの時期に、判断の材料が無い | 一年分の段の数字と体験談の言葉が無い |

最も多いのは、最初の「整わないまま送る」です。契約の時期と、送り始める時期は別です。

## 計画の軸

| 軸 | 何を書き出すか |
|---|---|
| 年度の公表内容と自社の方針 | 広報と選考の時期の扱い。スカウトを送ってよい時期と対象。この記事では具体は書かない |
| 自社の選考とイベントの予定 | インターン、説明会、本選考が、いつ頃か。文面の4段目で誘う先が、その時期にあるか |
| 企業ページと体験談の状態 | 企業ページが「選考の流れと何を見るか」から始まっているか。体験談に「掲載と違った」が無いか |
| 面接に出る人と話す人の繁忙期 | 事業の繁忙期、決算。受諾に対応できない、話す場に出られない時期 |
| 体験談が増える時期 | 選考の山のあと。読む期間の起点 |
| 送る人の枠 | 入社してまもない社員が、週に取れる時間 |
| 担当の異動の予定 | 分かっていれば |

「企業ページと体験談の状態」と「面接に出る人の繁忙期」が、軸の中心です。前者から「整える」の期間が、後者から「送る量」が決まります。

### エージェントベストの見解

申し込んだあと、一年目に起きやすいのは、「契約した月から送り始め、企業ページが会社紹介のまま、最初の体験談に『何を見ているか分からなかった』と書かれ、それを読まずに送り続ける」ことです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、一年目の前半を「整える期間」と決めて、企業ページを選考の流れから始める形にし、後半から送った会社と、契約の初日から送り始めた会社では、二年目の体験談が違います。前者は、二年目に「企業ページどおりだった」と書かれ、その体験談を読んだ学生が受諾します。後者は、一年目の「テンプレだった」「掲載と違った」を二年目の学生が読みます。当社が年間計画を作るとき、最初に置くのは「整える期間」で、その期間は送る量を小さくします。

## 四つの期間に、置くこと

| 期間 | いつ | 置くこと |
|---|---|---|
| 1. 整える | 送り始める前 | 企業ページ（選考の流れと何を見るか・最初の1年・働く人・よく聞かれること）、自社の体験談を読む、文面の型、絞り込み、台帳、受諾対応の担当、分担。[ワンキャリアのスカウトの基本](/media/oc-scout-kihon/) |
| 2. 送る | 年度の公表内容と自社の選考の予定に沿って | 面接の枠から逆算した数で。誘う先（話す場・イベント・選考）がある時期に。繁忙期は減らす。[ワンキャリアのスカウト通数の配分](/media/oc-scout-tsuusuu-haibun/) |
| 3. 読む | 選考の山のあと、体験談が増えた時期 | 増えた体験談を読み、スカウトへの言及（「読んでいた」「テンプレだった」「返信が遅かった」）を記録。「補う」と「直す」に分ける |
| 4. 直す | 年度の切れ目 | 読む期間の記録と段の表をもとに、文面の型、絞り込みの条件、送る人、企業ページを見直す。[ワンキャリアのスカウト運用のKPI設計](/media/oc-scout-kpi/) |

## 時期ごとの、送る量

| 時期 | 送る量 | やること |
|---|---|---|
| 整える期間 | 小さく | 企業ページと型と台帳。送るのは、読める数のさらに少なめから |
| 送る期間で、誘う先がある月 | 面接の枠から逆算して | 話す場・イベント・選考の掲載が出ている |
| 面接に出る人の繁忙期 | 減らす。ゼロにしない | 受諾対応だけは続ける |
| 試験期間・長期休み | 減らす | 学生の返信が遅れる。急がせない |
| 選考の山のあと（読む期間） | 減らすか止める | 体験談を読み、次に活かす |
| 後期（年度の公表内容と自社の方針で） | 事実で、対応をさらに速く | [ワンキャリアのスカウトを後期に使うときの進め方](/media/oc-scout-kouki/) |
| 早期（年度の公表内容と自社の方針で） | 「仕事を知る場」に誘う形で | [ワンキャリアのスカウトを早期に始めるときの進め方](/media/oc-scout-souki/) |
| 契約の見直しの前 | 通常どおり | 一年分の段の数字と体験談の言葉を揃える |

## 担当の異動と、引き継ぎを計画に入れる

- **異動の時期が分かっていれば、年度の切れ目に合わせる**：最も安全。「直す」の期間と重なる
- **分からなくても、年度の切れ目に「明日担当が変わったら何が渡せないか」を確かめる**
- **選考の途中で変わる場合の手順を、先に決めておく**：受諾対応の通知の変更と、対応中の学生の一覧だけ先に
- **読んで書く人（入社してまもない社員）の異動も、計画に**：募集ごとの担当を、次の入社してまもない社員へ
- **異動の直後の月は、送る量を減らす**：後任が対応中の学生を把握する期間

引き継ぎの中身は、Wantedlyの[スカウト運用の引き継ぎ](/media/wt-scout-hikitsugi/)で書いたものに、「自社の体験談の読んだ範囲と要点」を足します。

## 初年度と、二年目以降の違い

| | 初年度 | 二年目以降 |
|---|---|---|
| 整える | 長い。企業ページを一から、「何を見るか」を言葉にするから | 短い。前年の体験談を読んで直すだけ |
| 送る | 整った範囲で、小さく | 予定どおりに |
| 読む | 最初の体験談を読む。基準を作る | 前年と比べる。「読んでいた」が増えたか |
| 直す | 「なぜこの形か」を記録する | 段の表と体験談で一か所 |
| 起点 | 自社の選考の予定から逆算 | 前年の体験談が読まれた時期から逆算 |

## 計画を、守りすぎない

- **月の確認で、計画と実態のずれを見る**：選考の予定が変わった、話す人が出られなくなった
- **急な募集が出たら、その募集の企業ページを整えてから送る**：整わないまま送らない
- **体験談に「テンプレだった」があれば、年度の切れ目を待たず、その週から読める数まで減らす**
- **繁忙期が長引いたら、減らした状態を続ける**：無理に戻さない
- **計画の変更を、台帳に一行残す**：「なぜ変えたか」

「整わないまま送らない」と「体験談の指摘には年度を待たず対応する」の二つは、計画がずれても守ります。

## 掲載の年間計画と、揃える

スカウトの計画は、掲載（企業ページ・イベント・選考）の計画と一緒に作ります。

- **掲載の「整える」が終わってから、スカウトの「送る」が始まる**：企業ページが先
- **イベントの時期に、スカウトの4段目でそのイベントに誘う**：[ワンキャリアのスカウトとイベントのつなげ方](/media/oc-scout-event-renkei/)
- **掲載の「読む」（体験談が増える時期）と、スカウトの「読む」は同じ時期**：一度に読む
- **掲載の「直す」（年度の切れ目）で企業ページを直したら、スカウトの型も直す**：[ワンキャリアのスカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)
- **3媒体を併用しているなら、共通の材料（最初の1年、働く人の話）は最も早く要る媒体に合わせて整える**

「掲載とスカウトの四つの期間を、同じ表に置く」と、企業ページを直したのにスカウトの型が古い、という形が減ります。

### エージェントベストの見解

これをやる前に、先に決めておかないと計画が絵に描いた餅になることがあります。「面接に出る人と話す人の繁忙期」です。当社がワンキャリアのスカウトの年間計画を支えるとき、四つの期間の設計と送る量の逆算は当社が出せますが、「いつ、面接に出る人が受諾に対応できず、話す人が話す場に出られないか」は、社内の予定です。それが分からないまま計画を作ると、繁忙期に送り続けて受諾を放置し、体験談に「返信が遅かった」と書かれます。当社が最初にお願いするのは、面接に出る人と話す人に「一年のうち、出られない時期はいつか」を聞いてもらうことです。その答えがあれば、送る量を時期で変える計画が作れます。計画は、送る時期より、送らない時期を先に決めるほうが、確かです。

## まとめ

- 年間計画の軸は、年度の公表内容と自社の方針、選考とイベントの予定、企業ページと体験談の状態、面接に出る人と話す人の繁忙期、体験談が増える時期
- 四つの期間（整える→送る→読む→直す）を置き、整えるは送る前、送るは誘う先がある時期に面接の枠から逆算して、読むは選考の山のあと、直すは年度の切れ目
- 繁忙期・試験期間・長期休みは減らしてゼロにせず、受諾対応だけは続ける。後期と早期は年度の公表内容と自社の方針で
- 異動と引き継ぎを計画に入れ、初年度は整えるに長く、二年目以降は読むと直すに重みを移す
- 「整わないまま送らない」「体験談の指摘には年度を待たず対応する」は計画がずれても守り、掲載の計画と同じ表に置く

## よくある質問

### 契約したのに、整える期間で送らないのはもったいない気がします

契約は整備を始める合図で、送るのは整った時点です。整わないまま送ると、文面で興味を持った学生が企業ページで離れ、最初の体験談に薄い印象が残り、二年目の学生がそれを読みます。整える期間に小さく送りながら、企業ページと型と台帳を整え、整ったら量を増やします。送らなかった上限より、整わないまま送った文面のほうが、翌年に響きます。

### 選考の予定が年度の途中で変わり、計画どおりに進みません

変わることを前提に作ります。「送る」の時期が変われば、その前の「整える」をずらします。「読む」と「直す」は、選考の山のあとと年度の切れ目で変わりません。月の確認で、変わった部分だけ計画を直し、記録に一行残します。

### ワンキャリアのスカウトの年間計画は、御社に相談できますか

できます。当社は、計画の型、四つの期間の設計、時期ごとの送る量の逆算、初年度と二年目以降の整理、掲載の計画との揃え方を支えられます。年度の公表内容の確認、選考の予定の決定、繁忙期の判断、計画の変更の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
