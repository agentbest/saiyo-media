採用のKPIを置きたい。ところが、応募数・承認数・イベントの参加者数・SNSのフォロワー数を並べ、率も全部出し、目標値を先に置いて毎月「未達」の表になり、数が多すぎて誰も見ないまま、翌年も同じ表を作っている。**結論から言うと、測るのは「採る人数に届くか」を示す数だけで、応募数・承認数・イベントの参加者数・SNSのフォロワー数は測っても見ません。KPIは四つ（採用した数／こんな人に近い人が面談まで来た数／各段の日数／一年後に残った数）に絞り、率は分母が動くので参考として横に置きます。KPIを増やすほど誰も見なくなり、率をKPIにすると分母を減らす運用に寄ります。測る前に決めるのは「何人を、いつまでに、どんな人を」の三つで、これが決まらないうちはKPIを置きません。** 母集団形成のKPIは[母集団形成のKPI](/media/kh-boshudan-kpi/)、承諾のKPIは[内定承諾率のKPI](/media/kh-naitei-shoudaku-kpi/)で書きました。この記事は、採用全体のKPIを何にするかを書きます。

## この作業の目的｜「採れるか」に答える数だけを、残す

KPIの目的は、採用の状態を細かく記録することではなく、「採る人数に届くか」と「届かないならどこを直すか」に毎月答えることです。数が多いと、答えが出る前に眺めて終わります。

目的は、測っている数を減らし、四つに絞り、見ない数字を先に決めることです。

## 採用KPIで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 測れる数をKPIにする | 応募数・承認数・フォロワー数は測りやすいが、採る人数と結び付かない |
| 数が多すぎる | 月に一度の場で全部を眺めて終わり、どの数が動いたら何を直すかが決まらない |
| 率をKPIにする | 分母を減らせば上がるので、応募を絞る・内定を出す数を減らす運用に寄る |
| 目標値を先に置く | 毎月「未達」の表になり、直す場所が見えない |
| 「どんな人を」が無い | 数は追えても、採った人が合っているかが追えない |
| 入社の数で切る | 一年目の離職が見えず、入口が良く見せる方向に寄る |

共通するのは、「測りやすい数」を測っていて、「採れるかに答える数」を測っていないことです。

## 測る前に決める、三つ

- **何人を**：職種ごと、部門ごとの採用の人数。経営と決める
- **いつまでに**：入社の時期。そこから逆算して、各段の時期が決まる
- **どんな人を**：「こんな人」の一文。学歴や志望ではなく、行動で。「〇〇したことがある人」

三つが決まると、KPIは自動的に決まります。三つが決まらないうちにKPIを置くと、測れる数が並びます。「どんな人を」が最も抜けやすく、抜けると数だけを追う運用になります。

### エージェントベストの見解

相談で最も多い思い込みは、「採用KPIは、応募数から内定までの数字を全部並べて、毎月追うものだ」というものです。当社は3媒体すべての販売パートナーとして、多くの会社のKPIの表を見ていますが、数が多い表を持つ会社ほど、月に一度の場で「応募が減りました」の一言で終わり、どの数が動いたら何を直すかが決まっていません。逆に、KPIを四つに絞った会社は、月に一度の場で「〇〇の段の日数が延びた。返信の担当を増やす」と、その場で直すことが決まります。当社が最初にお願いするのは、いま測っている数を全部書き出し、「この数が動いたら、何を直すか」を一つずつ書くことです。書けない数は、KPIから外して台帳の参考の欄に移します。ほとんどの会社で、残るのは四つか五つです。数を減らすことは、情報を捨てることではなく、見る場を機能させることです。台帳には全部残し、KPIとして見るのは四つ。それが基本です。

## KPIは、四つ

| KPI | 何が分かるか | 見方 |
|---|---|---|
| 採用した数（職種ごと） | 採る人数に届くか。最後の答え | 「何人を」の目標と比べる。年に一度と、期の途中 |
| こんな人に近い人が面談まで来た数（入口ごと） | 母集団の量と質。届く見込み | 逆算した必要数と比べる。月に一度。[母集団形成のKPI](/media/kh-boshudan-kpi/) |
| 各段の日数（入口→面談→選考→内定→承諾） | 待たせている段。数が減る前の先行の指標 | 先月と比べる。月に一度。[採用ファネルのKPI設計](/media/kh-kpi-funnel/) |
| 一年後に残った数 | 採った人が合っていたか。入口と選考の質 | 年に一度。入社の数ではなく。[早期離職を減らす内定期間の使い方](/media/kh-naitei-souki-rishoku/) |

四つで、「結果」「見込み」「詰まり」「合っていたか」が分かります。四つの外の数字は、台帳に残し、KPIとして見ません。

## 率は、参考として横に置く

- **率は、分母が動くと意味が変わる**：応募を絞れば通過率は上がり、内定を出す数を減らせば承諾率は上がる
- **率をKPIにすると、分母を減らす運用に寄る**：狭めれば率は上がるので、採る人数から遠ざかる
- **率は、四つの横に一行**：前年比だけを見る。目標値は置かない
- **率を使うのは、逆算のとき**：「採用〇人 → 承諾△人 → 内定□人 → 面談〇〇人」の逆算に、前年の率を使う。ここでは率が要る
- **業界平均と比べない**：分母の取り方が違い、直す場所を示さない

率は、数を逆算するための道具で、追う対象ではありません。

## 見ない数字を、先に決める

- **応募数・エントリー数**：多いほど良いとは限らない。「近い人が面談まで来た数」で見る
- **スカウトの承認数**：承認は「像の量」で、面談に来た数と分けて見る
- **イベントの参加者数**：参加した後に面談に来た数で見る
- **SNSのフォロワー数・記事のPV**：採用の数と結び付かない。記事から面談に来た数で見る
- **面接の実施数**：実施した数ではなく、各段の日数と通過した人の質で見る

見ない数字を先に決めると、月に一度の場が短くなります。台帳には残し、必要なときに見ます。

## 誰がいつ見るか

| 頻度 | 誰が | 見るもの |
|---|---|---|
| 週に一度 | 人事 | 各段の日数（延びている段が無いか）。数は見ない |
| 月に一度 | 人事と採用の責任者 | 近い人の面談数（入口ごと）、各段の日数。直すことを一つ決める |
| 期の途中 | 採用の責任者と経営 | 採用した数の見込み。届かないなら入口の配分を変える |
| 年に一度 | 採用の責任者と経営 | 四つの前年比、一年後に残った数。翌年の三つ（何人・いつまでに・どんな人を）を決める |

週に一度は日数だけ、月に一度は数と日数、年に一度に四つ全部。頻度ごとに見る数を分けると、続きます。

## 媒体ごとに、変わる点

- **OfferBox**：媒体の運用のKPI（承認率・返信率・面談率）は、媒体を直すための数として別に持つ。採用全体のKPIには載せない。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)
- **Wantedly**：記事ごとの「話を聞きに来た数」は媒体のKPI。採用全体には「近い人の面談数」として入る。[Wantedlyのスカウト運用のKPI](/media/wt-scout-kpi/)
- **ワンキャリア**：掲載の閲覧数とスカウトの承認は媒体のKPI。採用全体には面談に来た数で入る。[ワンキャリアのスカウト運用のKPI](/media/oc-scout-kpi/)

媒体のKPIと採用全体のKPIを、二階建てにします。媒体のKPIは媒体を直すため、採用全体のKPIは採れるかを見るためです。媒体別の置き方は[媒体別のKPI設計](/media/kh-kpi-baitai/)で書きます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「何人を・いつまでに・どんな人を」を決める | 経営と採用の責任者 |
| KPIを四つに絞り、見ない数字を決める | 採用の責任者 |
| 台帳に全部を残し、四つを毎月出す | 人事 |
| 週に一度、日数を見る | 人事 |
| 月に一度、直すことを一つ決める | 人事と採用の責任者 |
| 経営への報告 | 採用の責任者 |
| 一年後に残った数を、採用に戻す | 採用の責任者 |

運用代行や代理店が支えられるのは、KPIの型、台帳の型、出す作業までで、三つの決定、直すことの決定、経営への報告は社内が担います。

### エージェントベストの見解

採用KPIで、当社が先にお伝えしているのは、「『どんな人を』が決まっていない会社では、KPIを置いても数を追う運用に戻る」ということです。「何人を・いつまでに」は多くの会社が決めていますが、「どんな人を」は「優秀な人」「意欲のある人」のままで、行動の一文になっていません。申し込んだあとにKPIが数の追いかけに戻る会社に共通するのは、この一文が無いことです。一文が無いと、「近い人が面談まで来た数」を数えられず、代わりに応募数と承認数を数えることになります。当社が案内するのは、KPIを置く前に、配属先の責任者と「こんな人」を行動の一文にすることです。「〇〇したことがある人」「△△のとき□□した人」。一文が決まると、面談に来た学生を「近い／近くない」で分けられ、KPIの二番目が数えられるようになります。KPIの設計は、数字の設計ではなく、「どんな人を採るか」の言語化から始まります。

## まとめ

- 測るのは「採る人数に届くか」を示す数だけ。応募数・承認数・参加者数・フォロワー数は台帳に残し、KPIとして見ない
- KPIは四つ（採用した数／近い人が面談まで来た数／各段の日数／一年後に残った数）。率は分母が動くので参考として横に置く
- 測る前に「何人を・いつまでに・どんな人を」を決める。「どんな人を」は行動の一文で
- 率を使うのは逆算のときだけ。率をKPIにすると分母を減らす運用に寄る
- 週に一度は日数、月に一度は数と日数、年に一度に四つ全部。頻度ごとに見る数を分ける

## よくある質問

### 上司が応募数の報告を求めます

台帳には残しているので、聞かれれば出せます。報告の一行目は「採用した数の見込み」と「近い人が面談まで来た数」にし、応募数は参考の欄に置きます。「応募は増えたが近い人の面談は減った」のように並べて見せると、上司の関心が応募数から面談の数に移ります。

### KPIを四つに絞ると、状態が細かく見えなくなりませんか

台帳には全部残すので、状態は見られます。絞るのは「毎月見る数」で、記録する数ではありません。四つ以外の数は、四つが動いたときに原因を探すために見ます。毎月全部を眺めると、どれも見なくなります。

### 採用KPIの設計は、御社に相談できますか

できます。当社は、KPIの型、台帳の型、出す作業を支えられます。「何人を・いつまでに・どんな人を」の決定、直すことの決定、経営への報告は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、媒体のKPIと採用全体のKPIの二階建てを支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
