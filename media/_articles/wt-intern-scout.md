Wantedlyで学生インターンにスカウトを送るとき、最初にぶつかるのは「大学名と学部で検索して『成長できる環境で一緒に働きませんか』と送っているのに、返信が来ない。来ても、面談で『何をやるのですか』『試験の時期は休めますか』と聞かれて止まる」という問題です。**結論から言うと、学生インターンへのスカウトは、大学名や学部で相手を選ぶのではなく、先に自社の任せる仕事と付く社員と時間と両立の扱いと新卒採用との関係を決め、「学んでいることとやってみたことが、任せる仕事と重なり、何かを自分で最後までやった記述のある学生」を選び、その学生の「何をやってみて、どこまで自分でやったか」を読んだ一文から、付く社員の名前で、任せる仕事と両立の実態で誘います。** この記事では、学生がスカウトで見ているもの、送る前に決めること、誰に送るか、文面に書くこと、返信後の面談、社内の分担、やりがちな失敗を整理します。学生向けの文面の基本は[新卒にスカウトを送るときの考え方](/media/wt-scout-shinsotsu/)、募集記事は[学生インターンを採る募集記事の書き方](/media/wt-intern-boshu/)で書きました。

## 学生がスカウトで見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰から来たか | 付く社員か、経営者か、人事か。自分を見てくれる人からか |
| 自分のプロフィールの何を読んだか | 大学名で検索しただけか、「学んでいること、やってみたこと」を読んだか |
| 任せる仕事と、見る人 | 何をするか。誰が付くか。「成長できる」だけなら雑用と読む |
| 時間と、試験期の扱い | 週に何日、何時から。試験の時期に休めるか。文面で分かるか |
| 新卒採用との関係 | つながるのか、つながらないのか。文面で分かるか。「採ってもらえる」と読める盛りが無いか |
| 「成長」で釣っていないか | 「成長」「裁量」「ベンチャー」が前面に出ていると、「何をするか書けない会社」と読む |

「成長できる環境」は、学生に多く届く文面なので、読まれません。

## 送る前に決めること｜任せる仕事、付く社員、時間と両立、新卒採用との関係

送る前に、社内で四つを決めます。決め方は[学生インターンを採る募集記事の書き方](/media/wt-intern-boshu/)で書きました。

- **任せる仕事を一つに**：「〇〇の記事を月に△△本書く」「□□の問い合わせに型に沿って答える」。「手伝い全般」にしない。最初の週に何をするかまで
- **付く社員**：名前で一人。週に何時間を学生のために使うか。決まらないなら送らない
- **時間と両立の扱い**：週に何日、何時から。試験の前後は休めるか。就職活動の時期は減らせるか
- **新卒採用との関係**：つなげる／つなげない／決まっていない。年度の公表内容と自社の方針を確認して。盛らない前提で

## 誰に送るか｜大学名や学部ではなく、学んでいることとやってみたこと、自分でやった範囲の重なり

大学名や学部で選ぶと、面談で「やることに関心が無い」「時間が合わない」になります。選ぶ基準は、「学んでいることとやってみたことが、任せる仕事と重なり、何かを自分で最後までやった記述があるか」です。

| 読む箇所 | 重なりの見方 |
|---|---|
| 学んでいること | 授業、ゼミ、独学。任せる仕事と重なるか。「〇〇の授業で△△を作った」のような記述 |
| やってみたこと | 自分で作った、書いた、売った、集めた。授業の外で何かをやった記述があるか。ここが最も重なりが要る |
| どこまで自分でやったか | 「一人で最後まで」「途中で分からなくなって聞いて進めた」が書かれているか。任せて回る学生か |
| 時間の都合 | 学年、通学、他のアルバイト。自社の時間帯と合いそうか。分からなければ文面で聞く |
| インターンを探しているか | プロフィールに「インターンを探している」「〇〇をやってみたい」があるか。無くても外さない |

「やってみたこと」と「どこまで自分でやったか」が要点です。任せる仕事と重なる「やってみたこと」がある学生を優先します。

### 時期の読み方

学生は、授業、試験、就職活動で、動ける時期が偏ります。プロフィールの更新の時期と学年を読み、「いま動ける学生か」を推し量ります。試験の時期に送るなら、文面に「試験が終わってからで大丈夫です」を添えます。就職活動の時期の学生には、「就職活動の時期は日数を減らせる」を先に書きます。絞り方の基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「学生には、大学名で絞って『成長できる環境』と送れば返信が来る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトを見ていますが、学生が返信した文面を並べると、大学名の一致と「成長」「裁量」の言葉は、返信の有無とほとんど関係がありません。関係があるのは、「自分のやってみたことを読んでくれたか」と、「任せる仕事と、付く人と、試験期の扱いが文面で分かるか」の二つです。「〇〇を作られたと書かれていたのを読んで。うちでは△△を月に□□本書く仕事を任せたい。私が付いて週に一度一緒に見る。試験の前後は休んで構わない」と書かれていれば、「自分の都合を分かっている会社」として返信が来ます。当社が対象を組み直すとき、最初にやるのは、検索条件から大学名を外し、「やってみたことを書いている学生」で並べ直し、「成長」を消して、任せる仕事と付く人と試験期の扱いを文面の最初のほうに入れることです。

## 文面に書くこと

文面の型（相手の一文→自社の場面→話す場の案内）の学生向けの変え方は[新卒にスカウトを送るときの考え方](/media/wt-scout-shinsotsu/)に書いたので、ここではインターン特有の要点だけを書きます。

- **相手の一文は、やってみたことで**：「〇〇の授業で△△を作られたと書かれていたのを読んで」「一人で□□を最後まで書かれたと書かれていた点を読んで」。大学名や学部ではなく、やったこと
- **送り主は、付く社員の名前で**：「私が付きます」と言える人。人事の名前で「成長できる」と送らない
- **任せる仕事を、最初のほうで**：「お願いしたいのは、〇〇の記事を月に△△本書く仕事です。最初の週は、私が書いた記事を読んで一本書いてもらいます」。「幅広く」と書かない
- **付く人と見る流れを、一文で**：「私が付いて、週に一度、書いたものを一緒に見ます。質問はいつでも」
- **時間と試験期の扱いを、一文で**：「週に〇〇日、△△時から。授業に合わせて変えられます。試験の前後は休んで構いません」
- **有給か無給かを、一文で**：「時給があります。額は面談で伝えます」「無給です。理由は〇〇」。数値は確認したものだけ
- **新卒採用との関係を、盛らずに**：「新卒採用は別に行います」「インターンから新卒で採った例はありますが、選考は別です」「決まっていません」
- **話す場は、付く社員と**：「私が、任せる仕事を実際に見せながら話します。インターンを決めていなくても構いません。授業と試験の都合を先に聞かせてください」

「成長できる環境」「裁量」「ベンチャーで力を試す」は書きません。学生の学業を軽く見る書き方（「学業より実践」など）をしません。

## 返信後の面談｜付く社員が出て、都合を先に聞く

| 話すこと | 中身 |
|---|---|
| 学生の都合を、先に聞く | 授業、試験、就職活動、他のアルバイト。来られる日と時間帯。ここを最初に |
| 任せる仕事を、実際に見せる | 最初の週にやることを、実物で。「これを書いてもらう」 |
| 付く人と見る流れ | 付く社員本人が話す。週に何回、何を見るか。「聞いていない」を出さない |
| 試験期と就職活動の扱い | 休めるか、減らせるか。文面と同じことを |
| 新卒採用との関係 | 盛らずに。つながるか、つながらないか、決まっていないか |
| 学生のやってみたことの話 | 何を作って、どこで詰まって、どう進めたか。聞く時間を長く |

面談には、付く社員が出ます。面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

課題を出すなら、面談のときに「課題がある」「どのくらいの時間がかかるか」「授業の後でできる量か」を先に伝えます。学生の時間は授業と試験で埋まっているので、量を小さくします。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 任せる仕事、付く社員、時間と両立、新卒採用との関係を決める | 経営者と、付く社員 |
| 「学んでいることとやってみたこと」で対象を並べ直す | 人事（付く社員が基準を伝える） |
| 学生のプロフィールを読み、一文を書く | 付く社員（または人事が下書きし、付く社員が確認） |
| 新卒採用との関係の確認 | 経営者（年度の公表内容を確認） |
| 型、送信、返信対応、台帳 | 人事 |
| 面談 | 付く社員と人事 |

付く社員が決まらないなら、送りません。

運用代行や代理店が支えられるのは、対象の並べ直しの基準づくり、型、避ける言葉のチェック、募集記事との整合の確認までで、任せる仕事の決定、付く社員の時間、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

学生インターンにスカウトを送る前に、先に決めておかないと効果が出ないのは、「付く社員を、名前で一人決め、週に何時間を学生のために使うかを決めること」です。当社がWantedlyの学生インターン向けスカウトを支えるとき、「来た学生を見て、誰が付くか決める」という会社が多くあります。ただ、付く人が文面に無いと、学生には「放置される」と読まれて開かれません。逆に、「私が付きます。週に一度、一緒に見ます」と付く社員の名前で書いた会社は、返信の数は減っても、任せて回る学生が来て、始めてから離れる学生がいなくなります。当社が最初にお願いするのは、対象の絞り込みではなく、「誰が付くか」を名前で一人決め、その人に「週に何時間なら学生のために使えるか」を言ってもらうことです。決まらないなら、送りません。その一人と時間が、文面の信用を決めます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 大学名や学部で相手を選ぶ | 面談で「やることに関心が無い」「時間が合わない」 | 学んでいることとやってみたこと、自分でやった範囲で選ぶ |
| 人事の名前で「成長できる環境」と送る | 「何をするか書けない会社」と読まれ、開かれない | 付く社員の名前で、任せる仕事を書く |
| 付く人を書かない | 「放置される」を想像される | 名前で一人。週に何回見るか |
| 試験期の扱いを書かない | 聞きにくいまま離れる | 休めるか、減らせるかを書く |
| 新卒採用との関係を盛る | 「採ってもらえる」と思って来て、離れる | 盛らずに書く。年度の公表内容を確認 |
| 試験の時期に送って、返事を急かす | 学生が困る | 「試験が終わってからで大丈夫」を添える |

最も多いのは、最初の「大学名で選ぶ」と、付く人の抜けです。

## まとめ

- 学生は、誰から来たか（付く人か）・自分のやってみたことを読んだか・任せる仕事と見る人・時間と試験期の扱い・新卒採用との関係・「成長」で釣っていないか、を文面の段階で見ている
- 送る前に、任せる仕事を一つ、付く社員を名前で一人と週に使う時間、時間と両立の扱い、新卒採用との関係（年度の公表内容を確認）を決める。付く人が決まらないなら送らない
- 誰に送るかは、大学名や学部ではなく、学んでいることとやってみたこと、「自分で最後までやった」「分からなくなって聞いて進めた」の重なりで。時期を読み、試験期には「終わってからで大丈夫」を添える
- 文面は付く社員の名前で。学生のやってみたことを読んだ一文、任せる仕事と最初の週、付く人と見る流れ、時間と試験期の扱い、有給か、新卒採用との関係を。「成長」「裁量」を書かない
- 面談は付く社員が出て、学生の都合を先に聞き、任せる仕事を実物で見せる。課題は授業の後でできる量に

## よくある質問

### 大学名で絞ったほうが、質の高い学生が来ませんか

大学名は「あればよい条件」です。大学名が合っても、任せる仕事に関心が無い学生、時間が合わない学生は、面談で離れます。「〇〇の授業で△△を作った」「一人で□□を最後まで書いた」を書いている学生は、大学名と関係なく、任せる仕事と重なれば送ります。「△△を作られたと書かれていたのを読んで」と、やってみたことで送ります。

### 付く社員の時間が取れず、人事が見ることになりそうです

人事が実際に見るなら、人事の名前で「私が付きます」と書きます。誰も時間が取れないなら、送りません。付く人がいないインターンは、学生が放置されて離れ、次の募集にも響きます。「付く人は〇〇で、週に△△時間」を決めてから送ります。決まらない間は、募集記事も出しません。

### 学生インターン向けのスカウトの対象の絞り込みは、御社に相談できますか

できます。当社は、対象の並べ直しの基準づくり、文面の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。任せる仕事の決定、付く社員の時間、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、新卒として採りたいのか、いまの仕事を任せたいのかで媒体を分けるところから案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
