総合商社、総合商社の子会社と新規事業、専門商社、メーカー系商社、地域の卸、商社からDXや事業会社へ変わろうとしている会社が、Wantedlyで採用する。商社は、総合商社と専門商社で候補者の見え方がまったく違う業界です。総合商社は、独自の選考で新卒を採り、憧れが集まる。専門商社とメーカー系商社と地域の卸は、知られていない。知られていない会社が、Wantedlyの会社ページを「商社」の一語で書くと、候補者は総合商社の像——海外、大きな取引、投資、事業をつくる——で読み、面談で実態——国内の卸、仕入先と顧客の間の営業、在庫と納期と与信——を聞いて離れる。**結論から言うと、商社のWantedlyは、自社がどの区分かで書くことを分け、「商社」の一語で書きません。総合商社は本体の新卒を置かず、子会社と新規事業の中途で、本体の名前ではなく事業と決裁の実態で。専門商社とメーカー系商社と地域の卸は、「商社」ではなく、扱う商材と仕入先と顧客と、担当が何を決められるか（価格、仕入先の選定、新しい顧客、新しい商材）で書きます。海外に関わる仕事があるなら、誰がどのくらい行くかを実態で。変わろうとしていること（DX、自社製品、サービス化）があるなら、それを最初に。総合商社の言葉を真似ず、卸の実態を素顔として書きます。** この記事では、商社の採用構造とWantedlyとの相性、区分ごとの書き方、「商社」で書かない見せ方、海外と在庫と納期の書き方、ストーリーとカジュアル面談とスカウトの運用設計、社内の分担を整理します。媒体の選び方は[商社業界の採用媒体の選び方](/media/hikaku-shosha-erabikata/)、業界の像とのずれは[Wantedlyで業界のイメージとのずれを扱う方法](/media/wt-gyokai-image/)で書きました。数値と料金は書きません。

## 商社の採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|
| 総合商社の本体 | 新卒は独自選考。中途は職種と領域ごと | 本体の新卒を置かない。中途は領域と決裁の実態で |
| 総合商社の子会社・新規事業 | 出向者と中途。本体の決裁がある | 本体の名前で埋めず、事業と「何を決められるか」を先に |
| 専門商社（食品、化学、機械、繊維、電子部品など） | 営業が中心。知られていない。中途が増えている | 「商社」で書かず、商材と仕入先と顧客で。並ぶ場の中で実態で |
| メーカー系商社・地域の卸 | 親会社の製品や地域の顧客。営業と物流 | 親会社の名前と「商社」の像で埋めず、顧客と担当の一日で |
| 商社から変わろうとしている会社 | DX、自社製品、サービス化。エンジニアと事業開発 | 向く。変わろうとしていることを最初に。「卸」の像で読まれないように |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| 「商社」の一語が総合商社の像を呼ぶ | 専門商社が像で読まれ、実態で離れる | 「商社」で書かず、商材と仕入先と顧客で |
| 海外の像が強い | 「海外で働ける」で来て、国内の卸で離れる | 誰がどのくらい行くかを実態で |
| 在庫と納期と与信が仕事を決める | 「大きな取引」で来て、納期の調整で離れる | 担当の一日を先に |
| 変わろうとしている会社がある | 「卸」の像で読まれ、変化が伝わらない | 変わっていることを最初に |

## 「商社」で書かない｜商材と仕入先と顧客と、担当が何を決められるかで

- **「商社」「トレーディング」「グローバル」を、会社ページの最初から外す**：総合商社の像を呼ぶ言葉。専門商社が使うと「小さい版」になる
- **「なにを」は、扱う商材と仕入先と顧客で一言**：「〇〇の商材を、△△の仕入先から、□□の顧客に届けている会社」。「モノと情報をつなぐ」で済ませない
- **担当が何を決められるかを書く**：「価格は〇〇まで担当が決める。仕入先の選定は△△。新しい顧客と新しい商材は□□」。「裁量がある」の一語で済ませない。[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)
- **海外に関わる仕事を、実態で**：「海外の仕入先とのやり取りは〇〇。出張は△△の頻度で、□□の人が行く」。「海外で働ける」で集めない
- **在庫と納期と与信を、隠さず**：「在庫は〇〇。納期の調整は△△の頻度。与信は□□」。「大きな取引」の像で来た人が離れないように
- **変わろうとしていることがあるなら、最初に**：「〇〇の商材の卸から、△△の自社製品を去年始めた」「□□をDXで変えている」
- **「こんな人」は、「仕入先と顧客の間で調整した・納期と在庫を見た・新しい仕入先や顧客を開いた」の記述で**：「グローバル志向」「商社志望」で絞らない

### エージェントベストの見解

これは切り分けの話です。専門商社やメーカー系商社から、「うちも商社なので、Wantedlyで商社志望の人に届けたい」と相談されることがあります。当社は3媒体すべての販売パートナーですが、候補者の「商社志望」が指しているのは総合商社の像で、専門商社が「商社」の一語で書くと、その像で読まれ、面談で国内の卸と納期と与信の実態を聞いて離れます。専門商社が書けて総合商社が書けないのは、扱う商材の具体、仕入先と顧客の関係、担当が価格と仕入先と新しい商材をどこまで決められるか、担当の一日です。当社がお願いしているのは、自社の区分を先に決め、専門商社以下は「商社」で書かず、商材と仕入先と顧客と「何を決められるか」で書くことです。分けると、「商社志望」ではなく「この商材と、この決められる範囲に向く人」が押します。

## 区分ごとの書き方｜総合商社の子会社・専門商社・変わろうとしている会社

- **総合商社の子会社・新規事業は、本体の名前で埋めず、決裁の実態を先に**：「〇〇までは子会社で決める。△△は本体の決裁で、□□の手順が要る」。「総合商社グループ」の像で来た人が決裁で離れないように
- **専門商社は、商材の領域で「なにを」を**：「〇〇（食品・化学・機械・繊維・電子部品）の△△を扱っている」。知られていない前提で。[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)
- **変わろうとしている会社は、変化を最初に、卸の実態を隠さず**：「〇〇の卸が主で、△△の自社製品を去年始めた。□□は決まっていない」。エンジニアと事業開発の募集は、営業の募集と分けて
- **「なぜ」は、代表や責任者の「なぜこの商材を、この顧客に」を体験で**：[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)
- **待遇と、数字の責任を、隠さず**：「売上と粗利は担当が持つ。与信は△△」。[Wantedlyの募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)

会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

## ストーリーとカジュアル面談の設計

- **営業の人のストーリーで、「納期が間に合わなかった週」「新しい仕入先を開いた日」を本人の言葉で**：[Wantedlyのストーリーで事業の中身を書く方法](/media/wt-story-jigyo/)
- **「商社志望」で入った人のストーリーで、「像と、入った後」と「それでも残った理由」を本人の言葉で**：[Wantedlyの入社後ストーリーの書き方](/media/wt-story-nyusha/)
- **代表・責任者のストーリーで、「なぜこの商材を」と「今、変えようとしていること」を**：[Wantedlyのストーリーで代表の考えを書く方法](/media/wt-story-daihyo/)
- **カジュアル面談で、担当が何を決められるかと海外の実態と在庫と納期を、聞かれる前に伝える**：[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **面談に、営業の責任者が出る**：商材と顧客の話は、人事だけではできない

## スカウトの設計

- **絞るのは、「仕入先と顧客の間で調整した・納期と在庫を見た・新しい仕入先や顧客を開いた」の記述**：「商社」「グローバル」「海外志向」の言葉で絞らない。[Wantedlyのスカウトで対象を絞る方法](/media/wt-scout-target/)
- **文面は、商材と仕入先と顧客と、決められることを最初に**：「〇〇の商材を△△の顧客に届けていて、価格は□□まで担当が決められる会社で、あなたの〇〇を読んで」。「商社」で始めない。[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 自社の区分を決め、「商社」を外して商材と仕入先と顧客で「なにを」を書く | 代表・責任者と人事 |
| 担当が何を決められるか（価格、仕入先、新しい顧客と商材）を書き出す | 営業の責任者 |
| 海外の実態と在庫と納期と与信を、何を書くか決める | 営業の責任者 |
| 変わろうとしていることを、卸の実態と共に書く | 代表・責任者 |
| 代表・責任者が「なぜこの商材を」を話し、記事に整える | 代表・責任者（整えるのは人事か外に出せる） |
| 営業の人が「納期が間に合わなかった週」「新しい仕入先を開いた日」を話す | 営業 |
| カジュアル面談に営業の責任者が出る | 営業の責任者と人事 |
| スカウトを商材と決められることを最初に、記述で絞って送る | 人事（絞る作業は外に出せる） |

運用代行や代理店が支えられるのは、区分の整理、「商社」を外す型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業までで、決められる範囲と在庫と納期の開示、代表が話すこと、営業が話すこと、面談は会社が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。専門商社やメーカー系商社が、「『商社』と名乗れば、総合商社の像で読まれて有利になる」と考えて会社ページを書く形を、当社は見ています。像で読まれることは、有利ではありません。総合商社の像で「話を聞きに行きたい」を押した候補者は、面談で国内の卸と納期と与信の実態を聞いて離れ、実態に向く候補者（仕入先と顧客の間で調整してきた人、納期と在庫を見てきた人）には、「商社」の一語では届きません。当社がお願いしているのは、「商社」「トレーディング」「グローバル」を会社ページの最初から外し、扱う商材と仕入先と顧客と、担当が価格と仕入先と新しい商材をどこまで決められるかを最初に書き、海外に関わる仕事は誰がどのくらい行くかを実態で書くことです。書くと、「商社志望」の候補者は減り、商材と決められる範囲に向く候補者が残ります。

## まとめ

- 総合商社は独自の選考で新卒を採る。Wantedlyは専門商社の営業・事業開発・DX・海外、総合商社の子会社と新規事業の中途、卸から変わろうとしている会社に向く。自社の区分を先に決める
- 専門商社が「商社」「トレーディング」「グローバル」で書くと総合商社の像で読まれ、国内の卸と納期と与信の実態で離れる。「商社」で書かず、扱う商材と仕入先と顧客で「なにを」を、担当が何を決められるか（価格、仕入先、新しい顧客と商材）を書く
- 海外に関わる仕事は「海外で働ける」ではなく、誰がどのくらい行くかを実態で。在庫と納期と与信と数字の責任を隠さない。変わろうとしていること（DX、自社製品）があるなら最初に、卸の実態と共に
- 総合商社の子会社は本体の名前で埋めず、決裁の実態を先に。営業の人が「納期が間に合わなかった週」「新しい仕入先を開いた日」を本人の言葉で
- スカウトは「商社」「海外志向」ではなく「仕入先と顧客の間で調整した・納期と在庫を見た・新しい仕入先や顧客を開いた」の記述で絞り、商材と決められることを最初に。面談に営業の責任者が出る

## よくある質問

### 「商社」と書かないと、何の会社か分かりにくくなりませんか

「〇〇の商材を、△△の仕入先から、□□の顧客に届けている会社」の方が、「商社」より何の会社か分かります。「商社」の一語は総合商社の像を呼び、専門商社の実態とずれて離れる原因になります。商材と仕入先と顧客で書き、「商社」は会社の形として一度、事実として書けば足ります。

### 海外の仕事があるのに、書いてはいけませんか

書いてください。ただ、「海外で働ける」「グローバル」の一語ではなく、「海外の仕入先とのやり取りは〇〇。出張は△△の頻度で、□□の人が行く」と実態で書いてください。一語で書くと、海外の像で来て、国内の卸の実態で離れます。実態で書くと、その実態に向く人が来ます。

### 商社のWantedlyの設計は、御社に相談できますか

できます。当社は、区分の整理、「商社」を外す型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業を支えられます。決められる範囲と在庫と納期の開示、代表が話すこと、営業が話すこと、面談は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
