新卒を一名か、二、三名採る。人事はおらず、社長か現場の責任者が採用を見ている。初めてか、数年に一度。「一名なら簡単だろう」と考えて始めると、一名は「採れるか、採れないか」の二択で、承認した一人が辞退すると、その年の新卒はゼロになり、ゼロになった年は「新卒は難しい」で終わります。**結論から言うと、一名の採用は「ゼロか一か」で、最も難しい採用です。最初に決めるのは、承認した一人に社長か現場が向き合うこと、同期がいないことを隠さないこと、送る数を数通単位にすること、辞退でゼロになる前提で承諾の期限と次の山を先に決めること、採れなかった年に翌年の型を残すことです。** この記事では、この人数を採る会社が割ける時間と人、「ゼロか一か」の難しさ、最初に決めること、文面の書き方、辞退への備え、採れなかった年の残し方、分担、やりがちな失敗を整理します。より多く採る会社は[新卒五名を採る会社のOfferBox運用](/media/ob-shinsotsu-5-unyou/)、初めての新卒採用の順番は[初めての新卒採用でOfferBoxから始めるときの順番](/media/ob-hajimete/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 人事がなく、社長か現場責任者が窓口 | 通知を見る時間が細切れ。承認への返信が遅れる |
| 初めてか、数年に一度 | 承認のあとに何をするかの型がない。前回の記録が残っていない |
| 一名の採用は「ゼロか一か」 | 一人の辞退で、その年がゼロになる |
| 同期がいない | 学生が「一人で入る」ことを気にする。隠すと面談で分かる |
| 「一名なら簡単」と考えている | 送る数も返信の型も決めずに始め、承認を放置する |
| 採れなかった年に、何も残らない | 翌年もゼロから。「新卒は難しい」で止まる |

この人数を採る会社がOfferBoxに割ける時間は、社長か現場責任者の細切れの時間で、送る数は数通単位です。数通でも、承認した一人に向き合えば、一名の採用は成り立ちます。

## 「ゼロか一か」の採用の難しさ

- **一名は、割合で見られない**：承認率も辞退率も、一人で全部が動く。見るのは、承認した一人が今どの段か
- **一人の辞退が、その年のゼロになる**：「多めに出す」ができない。二名に内定を出して一名だけ迎える形は、学生に不誠実で、翌年に響く
- **一人に向き合う時間は取れる**：五名や十名と違い、承認した一人ひとりに社長が会える。この人数の強みは、向き合いの深さ
- **採れなかった年が、翌年の材料になる**：型と台帳が残れば、翌年は最初からではない。残らなければ、翌年もゼロから
- **同期がいないことは、隠せない**：知ったうえで来る学生を探す

「一名なら簡単」ではなく、「一名だから、一人に向き合う運用にする」が、この人数の考え方です。

### エージェントベストの見解

相談で最も多い思い込みは、「一名しか採らないので、OfferBoxの運用は簡単だ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、一〜三名を採る会社の承認から承諾までを見ていますが、一名の採用は、十名の採用より難しいことが多くあります。十名なら、一人の辞退は計画の一部で、次の山で足せますが、一名なら、一人の辞退がその年のゼロで、「多めに出す」も使えません。承認した一人に、承認の当日に返し、数日以内に社長が会い、承諾までの間に教える人と会ってもらい、辞退が出たらすぐ送れる次の山を用意しておく。この全部を、一人のためにやるのが、一名の採用です。当社が一〜三名の会社に最初に伝えるのは、「簡単ではない。ただし、一人に向き合う時間は取れる」で、送る数を数通に絞り、承認した一人に社長の時間を集めてもらいます。

## 最初に決めること

1. **承認した一人に、社長か現場責任者が向き合う**：面談は社長が出る。承諾までの連絡も社長。代わりの人はいない。[代表名で送るスカウト文面](/media/kh-bunmen-daihyo/)
2. **同期がいないことを、隠さず最初の一文に**：「今年の新卒はあなた一人です。〇〇さんが最初の年に隣で教えます」。知ったうえで承認した学生だけが、面談に残る。[従業員三十名規模の会社のOfferBox運用](/media/ob-jugyoin-30-unyou/)
3. **送る数を、数通単位にする**：社長が向き合える数。「多く送れば一人は来る」と考えない。[予算が少ない会社のOfferBoxの使い方](/media/ob-yosan-sukunai/)
4. **承認への当日返信を、外に出す**：社長が細切れの時間で返せないなら、型で代行が当日に返し、社長は面談の日程だけ。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
5. **辞退でゼロになる前提で、承諾の期限と次の山を先に決める**：後述
6. **育てる人を、一人決める**：「みんなで教える」は「誰も教えない」になる。一名の新卒は、教える人が一人いれば育つ
7. **台帳を一枚で持ち、採れなかった年も残す**：誰に送って、誰が承認して、なぜ辞退したか。翌年の型

## 文面の書き方｜「一人で入る」ことへの答えと、「なぜあなたに」

| 書かない | 書く |
|---|---|
| 「新卒若干名募集」 | 「今年の新卒はあなた一人です」 |
| 「アットホーム」「少数精鋭」 | 誰が隣で教えるか。部署の人数と、誰と組むか |
| 「採用担当」の名義 | 社長か育てる人の名義。「私が教えます」 |
| 型どおりの文面 | 記述のどの行動を見たか。数通なら一人ひとりに書ける |
| 「若手が活躍」 | 最初の年に、この仕事を、この順で |

- **数通なら、一人ひとりの記述を読んで、一文を書く時間がある**：この人数の強みは、個別化の深さ。文面の基本は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)
- **社長が「なぜ新卒を採るか」を一文で**：「〇〇の仕事を、ゼロから教えて、△△を任せたい」
- **条件は一ページに**：採用サイトがなければ、コーポレートサイトの一ページ。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 辞退でゼロになる前提で、先に決める

- **承諾の期限を、学生の他社の選考の時期を聞いてから置く**：待つ間に、教える人と社員に会ってもらう。期限を置かずに待たない。[OfferBoxで内定を出したあとのフォロー](/media/ob-naitei-follow/)
- **次の山を、最初の一人の内定が出る前に用意しておく**：二つ目の検索条件と文面。辞退が出たら、すぐ送れる形。[OfferBoxのオファーを送る時期と時間帯の考え方](/media/ob-soushin-timing/)
- **「二名に出して一名だけ迎える」をしない**：辞退の保険に内定を使わない。一名なら一名に出し、辞退なら次の山
- **辞退の理由を、「決め手」まで聞く**：一名なら、じっくり聞ける。翌年の文面と送る相手の元。[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)
- **辞退のあとに慌てて送らない**：次の山が用意してあれば、慌てない。用意がなければ、その年は無理に採らず、翌年の型を残す

## 採れなかった年に、翌年の型を残す

- **採れなかった年は、負けではない**：一名の採用は「ゼロか一か」で、ゼロの年はある
- **残すもの**：「こんな人」の一行、検索条件、文面の型、承認後の連絡の型、台帳（誰に送って、誰が承認して、なぜ辞退したか）
- **残っていれば、翌年は最初からではない**：型があれば、翌年は送る前の準備が要らず、時期を早く置ける
- **「新卒は難しい」で止めない**：難しいのは事実で、止める理由ではない。翌年に型を使って、送る時期を早く、次の山を先に用意する
- **数年に一度の採用なら、型を文書で残す**：担当が替わっても使える形。[人事が1人の会社のOfferBox運用](/media/ob-jinji-hitori-unyou/)の「四つを頭の外に」と同じ

## 運用の分担

| 作業 | 誰が |
|---|---|
| 「なぜ新卒を採るか」の一行と「こんな人」 | 社長 |
| 育てる人の決定 | 社長 |
| 検索、文面の下書き、送信、一次返信 | 代行（人事がいないため） |
| 一人ひとりへの一文、文面の最終確認、名義 | 社長か育てる人 |
| 面談、承諾までの連絡 | 社長 |
| 承諾の期限と次の山の準備 | 社長（型は代行が渡す） |
| 台帳を一枚で残す | 社長（型は代行が渡す） |
| 採れなかった年の型の文書化 | 社長と代行 |

- **社長の時間は、面談と承諾までの連絡と、教えることに**：検索と文面と返信に使わない。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
- **窓口は社長一人**：通知を見る人を決める。[専任の人事がいない会社のOfferBox運用](/media/ob-jinji-fuzai-unyou/)

運用代行や代理店が支えられるのは、文面の型、承認後の連絡の型、台帳の型、次の山の準備の型、検索・下書き・送信・一次返信、採れなかった年の型の文書化までで、理由の一行、育てる人の決定、一文、面談、承諾までの連絡、承諾の期限の判断は企業の社長が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に「承諾の期限」と「次の山」を決めておかないと、一名の採用は、辞退の一報でその年が終わります。当社はOfferBoxの運用代行で一〜三名を採る会社の承諾までを見ていますが、承認した一人に内定を出したあと、期限を決めずに待ち、辞退の一報を受けてから「もう一度送りたい」と相談に来る会社が多くあります。その時点で、学生の予定は埋まっていて、承認しても間に合いません。順番は、最初の一人の内定を出す前に、二つ目の山の検索条件と文面を作っておき、承諾の期限を学生の他社の時期を聞いて置き、期限を過ぎたら聞き、辞退なら翌日に二つ目の山を送ることです。次の山があると、辞退は「その年のゼロ」ではなく、「二つ目の山を送る合図」になります。一名の採用で当社が最初に用意するのは、一つ目の文面ではなく、二つ目の山です。

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「一名なら簡単」と考える | 型も返信も決めず、承認を放置する | 一人に向き合う運用にする |
| 辞退でゼロになってから送り直す | 学生の予定が埋まっている | 次の山を先に用意 |
| 「二名に出して一名だけ迎える」 | 学生に不誠実で、翌年に響く | 一名に出し、辞退なら次の山 |
| 同期がいないことを面談で初めて伝える | 温度が下がる | 最初の一文に |
| 採れなかった年に何も残さない | 翌年もゼロから | 型と台帳を文書で残す |

最も多いのは、一つ目です。一名の採用を、簡単な採用だと考えます。

## まとめ

- 一名の採用は「ゼロか一か」で、最も難しい。割合で見られず、一人の辞退がその年のゼロになる。「簡単」ではなく「一人に向き合う運用」
- 承認した一人に、社長か現場責任者が向き合う。同期がいないことを最初の一文に。送る数は数通単位で、一人ひとりの記述を読んで一文を書く
- 承認への一次返信は外に出し、社長の時間は面談と承諾までの連絡と教えることに。育てる人を一人決める
- 辞退でゼロになる前提で、承諾の期限を置き、次の山を最初の一人の内定が出る前に用意する。「二名に出して一名だけ迎える」をしない
- 採れなかった年は負けではない。「こんな人」・検索条件・文面・連絡の型・台帳を文書で残し、翌年に型を使って早く動く

## よくある質問

### 一名しか採らないのに、代行に出す意味はありますか

意味は、社長の時間を「向き合うこと」に集めることにあります。検索、文面の下書き、送信、承認への一次返信を社長が持つと、細切れの時間が消えて、承認した一人の面談の設定が遅れます。数通の代行は、送る作業より、「承認の当日に返す」と「次の山を用意する」の二つを外に出す意味が大きいです。

### 辞退されて、その年はゼロになりました。来年はどうすればよいですか

台帳と型を残してください。誰に送って、誰が承認して、なぜ辞退したかが残っていれば、来年は「こんな人」と文面の直しから始められ、送る時期を早く置けて、次の山も最初から用意できます。ゼロの年は、一名の採用にはあります。残すものがあれば、来年は最初からではありません。

### 新卒一〜三名を採る会社のOfferBox運用は、御社に相談できますか

できます。当社は、文面の型、承認後の連絡の型、台帳の型、次の山の準備の型、検索・下書き・送信・一次返信、採れなかった年の型の文書化を支えられます。理由の一行、育てる人の決定、一文、面談、承諾までの連絡、承諾の期限の判断は、企業の社長が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
