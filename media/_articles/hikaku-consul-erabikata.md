戦略、総合、IT、業務、人事、専門分野、地方のコンサルティング会社が、新卒を採る。大手は独自の早い選考とケース面接で、学生の憧れが集まる。中小や専門のコンサルは、学生に知られておらず、「コンサル志望」の学生は大手を見ている。学生は「成長できる」「論理的な仕事」の憧れで来て、最初の年の議事録と資料と分析、クライアント先への常駐、長時間の実態を知って離れる。**結論から言うと、コンサル業界の学生は「成長」の憧れで来て、最初の年の実態で離れます。媒体の選び方は、自社の「領域と案件の位置」（何の領域で、どの段階の案件を、常駐か自社か）を一行にしたうえで、大手は学生が並べて比べる場を、中小・専門のコンサルは「分解した・合意させた経験」で絞って送る型か、案件の裏側を記事で読んでもらう型を先に検討します。** この記事では、コンサル業界の採用構造、判断軸の当て方、学生が確かめること、領域と案件の位置の一行、条件ごとにどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像は[OfferBox・Wantedly・ワンキャリアの違いと選び方](/media/hikaku-3baitai/)で書きました。数値と料金は書きません。優劣は断定しません。

## コンサル業界の採用構造と、媒体との相性

| 業界の特徴 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 大手は独自の早い選考とケース面接で、憧れが集まる | 応募には困らないが、憧れで来て最初の年の実態で離れる | 比べられる場で選考情報と実態を。送る型は特定の領域に |
| 中小・専門のコンサルは知られていない | 「コンサル志望」の学生は大手を見ていて、中小は目に入らない | 送る型か記事を置く型で、「この領域で、この案件を」で知ってもらう |
| 職種はコンサルタント一本が多い | 「論理的」「地頭」で絞ると、志望者の全員に当てはまる | 「分解した・合意させた・仕組みで減らした経験」で絞る |
| 最初の年は議事録・資料・分析が中心 | 「すぐ提案できる」と思って来て離れる | 最初の年を正直に書く |
| クライアント先への常駐がある会社と、自社で行う会社がある | 常駐を書かずに送り、面談で離れる | 常駐の有無と範囲を書く |
| 領域（戦略・IT・業務・人事など）と案件の段階で、仕事の中身が違う | 「コンサル」の一語で送り、領域のずれで離れる | 領域と案件の位置を一行にする |

## 判断軸を、コンサル業界に当てる

| 軸 | コンサル業界での見方 |
|---|---|
| 対象（誰に届くか） | 「コンサル志望」の記述は大手を見ている。絞るのは「業務を分解した・人の間に立って合意させた・仕組みで手間を減らした・動かなかったときに切り分けた」の記述 |
| 型（送るか、来るか、比べられるか） | 大手は「比べられる」型が使える。中小は「送る」型で経験で絞るか、「来る」型で案件の裏側を読んでもらう |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | コンサルタントの時間は案件で埋まり、常駐なら社内にいない。名義と面談の枠を先に固定する。送る型は作業を外に出せる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。コンサルでは、「対象」の軸で「論理的」「地頭」を絞る条件にしないことが、他の業界と最も違います。

### エージェントベストの見解

これをやる前に、先に「自社は、何の領域で、どの段階の案件を、常駐か自社かで行っているか」を一行にしておかないと、文面と記事が「コンサル」の一語になり、大手を見ている学生に届かず、届いても領域のずれで離れます。当社は3媒体すべての販売パートナーとして、コンサルの会社の相談を受けますが、「コンサルタント募集」「成長できる環境」で送っている中小の会社が多く、その文面は大手と同じ言葉で、大手を見ている学生には「知らないコンサル」としか読まれません。「〇〇の業界の△△の業務を、要件の段階から、自社で行っている」の一行があると、その領域に関心のある学生に、大手とは違う位置で届きます。順番は、一行を作り、その一行で「こんな人」（業務を分解した、合意させた経験）を決め、そのあとに媒体を選ぶことです。一行がない会社は、どの媒体でも「コンサル」の一語で埋もれます。

## 学生が、確かめること

- **最初の年に何をするか**：議事録、資料、分析、同席。「すぐ提案できる」わけではないことを、先に
- **常駐の有無と範囲**：クライアント先にいるのか、自社にいるのか、頻度。隠すと離れる
- **領域と案件の位置**：何の業界の、何の業務を、どの段階から。「コンサル」の一語ではなく
- **長時間の実態**：案件の山、締切。隠さず、変えたことも
- **成長の中身**：「成長できる」ではなく、何年で何ができるようになるか、誰がどう教えるか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 大手で、独自の早い選考があり、学生の候補に入っている | 学生が並べて比べる場（ワンキャリア）で選考情報と実態を | 主軸は独自の選考。クチコミの実態（長時間、常駐）と記事をずらさない |
| 大手で、特定の領域（IT、業務など）を、憧れの層とは別に採りたい | 企業から送る型（OfferBox） | 領域への関心と「分解した・合意させた経験」で絞れる。[OfferBoxでITコンサルタント志望の学生を見つける検索の考え方](/media/ob-it-consul-target/) |
| 中小・専門で、経験で絞って会いたい | 企業から送る型（OfferBox） | 大手の日程より前に、「この領域で、この案件を」で会いに行ける。[OfferBoxでコンサルタント志望の学生を見つける検索の考え方](/media/ob-consultant-target/) |
| 中小で、コンサルタントが案件の裏側を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「成長」ではなく、案件で何をどう変えたかの場面を読んで選ばれる。記事が残る |
| 領域と案件の位置の一行が、まだない | どれも先ではない | 一行を作ってから |

どれか一つが正解ではなく、大手か中小か、領域、書けるかで、先に検討するものが変わります。

## 組み合わせ

- **大手は、比べられる場と送る型を組み合わせる**：比べられる場で独自の選考の情報を、送る型で特定の領域を。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **中小は、送る型と記事を置く型を組み合わせる**：文面で「あなたの〇〇を分解した経験を読んで」を、記事で「案件の裏側」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **中小は、大手の日程より前に送る**：残りを待たない。[OfferBoxを早期に使うときの進め方](/media/ob-souki/)
- **常駐が多い会社は、名義と面談の枠を先に固定する**：コンサルタントが社内にいない前提で

## 見せ方｜「成長」ではなく、領域と案件と最初の年

- **「成長できる環境」「上流工程から」「若手から裁量」を書かない**：同業の共通語で、区別されない
- **領域と案件の位置を、一行で**：「〇〇の業界の△△の業務を、□□の段階から、自社で（または常駐で）」
- **最初の年を、正直に**：「議事録と資料から始めて、△△の時点で□□を任せます」
- **常駐の有無と範囲を、最初に**：「常駐は〇〇の割合で、△△の頻度で自社に戻ります」。数値は実態で。この記事では書かない
- **案件を一つ、顧客が特定されない形で**：業務をどう変えたか。製品名や顧客名は出さない。書き方は[OfferBoxでITコンサルタントを採るオファー文面の書き方](/media/ob-it-consul-offer-bunmen/)
- **「こんな人」は「論理的」ではなく「分解した・合意させた・仕組みで減らした」で**：[OfferBoxでコンサルタントを採るオファー文面の書き方](/media/ob-consultant-offer-bunmen/)
- **業界イメージ（長時間、常駐、使い捨て）を否定せず、実態で**：[業界イメージが不利な会社のWantedlyの書き方](/media/wt-gyokai-image/)
- **名義は、案件に入っている若手**：「私は〇〇の案件で、最初の年は△△をしました」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 領域と案件の位置の一行 | 経営とコンサルタントの責任者 |
| 大手か中小かの位置づけと、先に検討する型の決定 | 人事と責任者 |
| 「こんな人」（分解した・合意させた・仕組みで減らした経験） | 人事とコンサルタント |
| 送る型なら、検索・下書き・送信・一次返信 | 人事、または代行 |
| 記事を置く型なら、コンサルタントが案件の裏側を話し、整えるのは人事か外に | コンサルタントと人事 |
| 個別の一文、文面の最終確認、名義、面談 | 案件に入っている若手 |
| 常駐の有無と最初の年の実態を、一枚に | 人事と責任者 |
| 面接官に「なぜコンサルか」を聞かないと伝える | 人事 |

- **コンサルタントに頼むのは、名義・一文・面談の三つ。案件の合間で**：[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
- **人事の時間は、一行と一枚と面談の設定に。作業は外に**：[運用代行に出す前提の媒体の選び方](/media/hikaku-daikou-zentei/)

運用代行や代理店が支えられるのは、一行の型、型の選び方の整理、絞り方の型、文面と記事の型、送る型の作業、記事を整える部分までで、一行の中身、常駐と最初の年の開示、名義の選定、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「コンサル志望の学生は多いので、中小でも送れば来る」というものです。当社は3媒体すべての販売パートナーとして、中小や専門のコンサルの相談を受けますが、「コンサル志望」の学生の多くは大手を見ていて、中小の「コンサルタント募集」は目に入らず、届いても「大手に落ちたら」の位置に置かれます。中小のコンサルに来る学生は、「コンサル」ではなく「この領域」「この案件」「常駐でなく自社で」「最初の年からクライアントに会える」で選ぶ学生で、その学生には、大手と同じ言葉ではなく、自社の位置の一行で届きます。当社が中小のコンサルに勧めているのは、「コンサル志望」を追わず、領域への関心と「業務を分解した経験」の記述で絞って、大手の日程より前に、一行と最初の年の実態で送ることです。大手の残りを待つ形から、先に会いに行く形に変えると、会える学生が変わります。

## まとめ

- コンサル業界の学生は「成長」の憧れで来て、最初の年の議事録・資料・分析、常駐、長時間の実態で離れる。「コンサル志望」の学生は大手を見ている
- 媒体の前に、自社の「領域と案件の位置」（何の領域で、どの段階の案件を、常駐か自社か）を一行にし、その一行で「こんな人」（分解した・合意させた・仕組みで減らした経験）を決める。「論理的」「地頭」では絞れない
- 大手は並べて比べる場で選考情報と実態を、送る型は特定の領域に。中小・専門は経験で絞って送る型か案件の裏側を記事で読んでもらう型を先に、大手の日程より前に
- 見せ方は「成長」「上流」「裁量」の共通語を消し、領域と案件の位置、最初の年、常駐の有無を正直に。案件は顧客が特定されない形で一つ
- コンサルタントに頼むのは名義・一文・面談で、案件の合間に枠を固定。人事の時間は一行と一枚と面談の設定に、作業は外に

## よくある質問

### 常駐が多いので、面談に出られるコンサルタントがいません

名義と面談の枠を、案件の合間に先に固定し、その枠から送る数を逆算します。枠が月に少ないなら、送る数も少なく、絞って送ります。常駐が多いことは、文面に「常駐は〇〇の割合で」と隠さず書き、面談はオンラインで常駐先から出られる形も検討します。枠を決めずに送ると、承認した学生が面談を待って離れます。

### 「論理的思考力」で絞りたいのですが、駄目ですか

「論理的」の記述は、コンサル志望の学生のほぼ全員が書いていて、絞る条件になりません。「〇〇の業務を分解して手順にした」「人の間に立って合意させた」「仕組みで手間を減らした」「動かなかったときに原因を切り分けた」の記述で絞ると、論理的に考えたことが行動として読めます。行動で絞ると、「コンサル志望」でない学生の中から、向く学生が見つかります。

### コンサル業界の媒体選びは、御社に相談できますか

できます。当社は、一行の型、型の選び方の整理、絞り方の型、文面と記事の型、送る型の作業、記事を整える部分を支えられます。一行の中身、常駐と最初の年の開示、名義の選定、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
