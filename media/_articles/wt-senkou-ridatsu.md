Wantedlyのカジュアル面談まで来て、選考に進んだのに、途中で離脱する。この症状は、「本気ではなかった」で片づけられがちです。ところが、Wantedly経由の候補者には、他の経路の候補者と違う離脱の理由があります。**結論から言うと、Wantedly経由の離脱の多くは、「読んだ会社」と「選考で会った会社」の差から起きます。会社ページと記事とストーリーを読み、「お互いを知る場」で話し、その会社の印象を持って選考に入ったのに、選考が急に「面接」になり、面接官が記事と面談を知らず「志望動機」から聞き、書類が急に重く、条件が選考で初めて出る。離脱を段ごと（面談→選考の入口・一次・二次以降・最終）に切り分け、差が出た段だけを直します。「面談の続き」として選考を組み、離脱の理由を聞ける範囲で聞き、離脱が続く段を月に数えます。** この記事では、Wantedly経由に特有の離脱、段ごとのサインと直し方、面談の続きとしての選考、理由の集め方、段を数えること、分担を整理します。面談から選考への移し方は[Wantedlyのカジュアル面談から選考へ移す方法](/media/wt-scout-senkou-ikou/)、面談後の辞退は[Wantedlyで面談後に辞退されるときの見直し](/media/wt-scout-jitai/)で書きました。この記事は、選考に入ったあとの離脱です。

## この作業の目的｜「読んだ会社」と「選考で会う会社」の差を無くす

Wantedly経由の候補者は、会社ページの「なぜ」を読み、記事の「こんなことやります」を読み、ストーリーで人を見て、面談で話して、選考に入ります。読んで話して持った印象と、選考で見えるものが違うと、「読んだのは、採用用の顔だった」と感じて離れます。

目的は、差が出ている段を見つけ、選考の側を「読んだ会社」に寄せることです。候補者の「本気」を上げることではなく、差を無くすことです。

## Wantedly経由の候補者に、特有の離脱

| 離脱の形 | なぜ起きるか |
|---|---|
| 面談は良かったが、選考に入った途端に別の会社に見えた | 「お互いを知る場」から「面接」への切り替えが急。面接官が面談の型に戻った |
| 面接官が「志望動機」「なぜうちに」から聞いた | 候補者はスカウトか記事で誘われて来ている。「志望動機」はまだない。面接官が記事と面談を知らない |
| 志望動機書や課題が、面談のあとに急に来た | 「話すだけ」から「選考」への切り替えが、書類で重くなった |
| 記事と面談で聞いた働き方と、選考で見えた実態が違った | 記事は「自分で決めて進める」、面接官の話は「指示に従う」 |
| 条件が、選考で初めて出た | 記事に条件がなく、面接で初めて知った |
| 面談で話した人が、選考に出てこない | 「あの人とは、もう会えないのか」 |
| 段階が多く、間が空いた | 「話す場」の軽さから、選考の長さへの落差 |

共通するのは、「読んで話して持った印象」を、選考の側が引き継いでいないことです。

## 段ごとの、離脱のサインと直し方

### 面談のあと、選考に進まない

| サイン | 直し方 |
|---|---|
| 面談の最後に、次の選択肢を伝えていない | 「選考に進む・もう一度話す・いったん終わる」を伝え、「今日決めなくてよい」と添える |
| 面談のあとに、急に書類を求めた | 書類は最小限に。志望動機書はこの段階で求めない。[Wantedlyのカジュアル面談から選考へ移す方法](/media/wt-scout-senkou-ikou/)の「書類は、最小限にする」 |
| 選考の流れが分からない | 回数、誰と何を話すか、期間の目安を、翌日の連絡で具体的に |
| 「面談」が実質「一次面接」だった | 面談の型を守る。[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/) |

### 一次で離脱する

| サイン | 直し方 |
|---|---|
| 面接官が、記事と面談の内容を知らない | 記事のリンクと面談の記録を、面接官に一行で渡す |
| 面接が「志望動機」「なぜうちに」から始まる | 面談の続きとして、面談で話したことの先から。「志望動機」は聞かない |
| 面談で話した人が、一次にいない | 一人でも同じ人が出る。出られないなら、面接官が「面談で〇〇の話をされたと聞いています」から始める |
| 「面接」という言葉で、空気が変わる | 「次にお話しする場」と呼ぶ。合否は出すが、場の形は面談に近く |

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedly経由の候補者は、カジュアル面談で来ているので、選考に入ると本気度が足りず離脱しやすい」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、離脱した候補者の記録を段ごとに並べると、「一次で離脱」が集中している会社が多く、その一次の面接官に聞くと、記事も面談の記録も読まずに、「志望動機は」から始めています。候補者は、記事で「自分で決めて進める」を読み、面談で「お互いを知る場」の印象を持ち、一次で「志望動機を問う面接」に会い、「読んだ会社と違う」と感じて離れます。本気度の問題ではなく、選考の側が読んだ会社の続きになっていない問題です。当社が離脱の相談を受けるとき、最初にやるのは、離脱した段を数えることと、その段の面接官が記事と面談の記録を読んでいるかを確かめることです。

### 二次以降で離脱する

| サイン | 直し方 |
|---|---|
| 段階が多く、間が空く | 段階を減らすか、間を空けない。各段階で次の日程をその場で決める |
| 面接官ごとに、聞くことが違う | 面接の型を段階ごとに揃える。全員が記事を読んでいる |
| 記事で書いた働き方と、面接官の話す実態が違う | 記事を実態に合わせるか、実態を記事に近づけるかを、社内で決める。良く見せた記事は、ここで戻ってくる |
| 条件が、この段階で初めて出る | 条件は記事の最後に短く。[Wantedlyの募集記事に条件をどこまで書くか](/media/wt-boshu-joukenn/) |
| 他社の選考が先に決まった | 自社の段階の間隔を短くする。「もう一度話す」で迷っている候補者を残す |

### 最終で離脱する

| サイン | 直し方 |
|---|---|
| 最終の面接官（代表）が、記事と面談と一次二次の記録を読んでいない | 代表にも一行で渡す。会社ページの「なぜ」を書いた代表が、それを候補者と話す形に |
| 最終で、「なぜうちに」に戻る | 最終は、「一緒に働く場面を描けるか」を話す場に |
| 最終のあと、結果までが長い | 目安を伝え、守る |
| 内定を出したあとの離脱 | 別の問題。内定後の接点を[Wantedlyでスカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)の要領で途切れさせない |

## 「面談の続き」として、選考を組む

- **面談で聞いたことを、選考に引き継ぐ**：一行で。「記事の〇〇に反応し、面談で△△を話した。□□が気になっている様子」
- **各段階の面接官が、記事と会社ページを読んでいる**：候補者が読んだものを、面接官も読んでいる
- **「志望動機」を聞かない**：Wantedly経由の候補者は、誘われて来ている。動機は選考の中でできる
- **面談で話した人が、どこかの段階に出る**：「変わらない人」が一人いる
- **段階を減らし、各段階で次の日程をその場で決める**：「話す場」の軽さを保つ
- **書類は最小限**：志望動機書は求めない。経歴は、プロフィールで足りることが多い

引き継ぎの型は[Wantedlyのカジュアル面談から選考へ移す方法](/media/wt-scout-senkou-ikou/)の「面談で聞いたことを、選考に引き継ぐ」で書きました。

## 離脱の理由を、聞いて残す

- **聞ける範囲で聞く**：「今後の参考に、差し支えなければ」。選考とは関係ないと添える
- **聞けない場合も、推測を記録する**：「一次のあとに返事が無くなった」。事実と推測を分けて
- **面接に出た人にも聞く**：「候補者が引っかかった様子があったか」
- **一行で台帳に**：「離脱。段：一次。理由：面接官が記事を知らず志望動機から聞いた（推測）」
- **「記事と違った」が理由にあれば、記事を実態に合わせる**：[Wantedlyで面談後に辞退されるときの見直し](/media/wt-scout-jitai/)の「記事や文面と、面談のずれ」と同じ

## 離脱が続く段を、月に数える

| 段 | 数えるもの |
|---|---|
| 面談→選考 | 面談した候補者のうち、選考に進んだ数と進まなかった数 |
| 一次 | 一次を受けた候補者のうち、次に進んだ数と離脱した数 |
| 二次以降 | 同じく |
| 最終 | 同じく |
| 各段の理由 | 事実と推測を分けて |

集中している段が、直す段です。全部を直そうとせず、その段だけを直します。数字の見方は[Wantedlyのスカウトの効果測定](/media/wt-scout-kpi/)で書きました。

### エージェントベストの見解

これは順番の話です。当社がWantedlyで「選考で離脱する」という相談を受けたとき、選考の流れを組み直す前に、面接官が記事と会社ページと面談の記録を読んでいるかを確かめます。読んでいなければ、選考の流れをどう変えても、面接官は「初めて会う候補者」として「志望動機は」から始め、候補者は「読んだ会社と違う」と感じます。逆に、面接官が記事を読んでいて、面談の一行を持っていれば、選考の流れが多少長くても、「面談の続き」として進みます。当社が勧める順番は、面接官に記事と一行を渡す、「志望動機」を聞かない形にする、段階と間隔を見直す、記事と実態のずれを直す、です。最初の二つは、今週からできます。

## まとめ

- Wantedly経由の離脱は、「読んだ会社」と「選考で会った会社」の差から起きる。本気度の問題ではなく、選考の側が読んだ会社の続きになっていない問題
- 段ごと（面談→選考の入口・一次・二次以降・最終）に切り分け、離脱が集中している段だけを直す
- 一次の離脱は、面接官が記事と面談を知らず「志望動機」から聞くことが多い。記事のリンクと面談の一行を渡し、面談の続きとして始める
- 選考を「面談の続き」として組む。書類は最小限、段階は少なく、各段階で次の日程をその場で、面談で話した人がどこかに出る、条件は記事の最後に
- 離脱の理由を聞ける範囲で聞き、事実と推測を分けて残し、月に段ごとの数を数える。「記事と違った」があれば記事を実態に合わせる

## よくある質問

### 「志望動機」を聞かずに、何で判断すればよいですか

記事の「求める動き方」に近い行動を、候補者がこれまでにしてきたかを、事実で聞きます。「自分で決めて進める」なら、「これまでに、自分で決めて進めた仕事の場面を教えてください」。志望動機は、選考が進む中で、候補者の側にできます。最終で、「一緒に働く場面を描けているか」を聞くほうが、Wantedly経由の候補者には合います。

### 記事で良く見せすぎていて、選考で実態との差が出ます

記事を実態に合わせます。良く見せた記事で来た候補者は、選考か入社後に差に気づき、離れます。「自分で決めて進める」が実態でないなら、記事から消し、実態の働き方を場面で書きます。来る数は減りますが、選考以降の離脱が減ります。記事の直し方は[Wantedlyの募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)で書きました。

### 選考での離脱の見直しは、御社に相談できますか

できます。当社は、段ごとの切り分けの型、理由の集め方の型、面接官に渡す記録の型、選考の流れの見直しの案を支えられます。理由を聞くこと、面接、選考の流れの決定、記事と実態のどちらを直すかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
