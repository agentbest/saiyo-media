ワンキャリアでイベントを開いているが、うまくいっていない気がする。何が失敗なのか、自分では分からない。**結論から言うと、やりがちな失敗は五つで、「体験談を読まずに開く」「『会社説明会』で全部を賄う」「ページに書いた人と違う人が出る」「回で言ったことを守らない」「一度で止める」です。最も重いのは「書いたとおりでない」で、翌年の体験談に残ります。回の前のセルフチェックと、反応が薄いときの切り分けを持ち、失敗に「気づける」状態を作ります。** この記事では、五つの失敗とサインと直し方、セルフチェック、切り分け、最も重い失敗、分担を整理します。掲載の失敗は[ワンキャリアの掲載でやりがちな失敗](/media/oc-keisai-ng/)、スカウトの失敗は[ワンキャリアのスカウトでやりがちな失敗](/media/oc-scout-ng/)、集まらないときは[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)で書きました。

## この作業の目的｜失敗に「気づける」状態を作る

イベントの失敗は、当日には分かりにくい。参加者は来て、話を聞いて、帰る。失敗が見えるのは、次の場に進まない、体験談に「違った」と書かれる、社員が二回目に出ない、といった後の場面です。気づいたときには、翌年の体験談に残っています。

目的は、五つの失敗をサインで先に見つけ、回の前のセルフチェックで防ぎ、後の場面で気づける状態にすることです。

## 失敗1｜体験談を読まずに開く

- **サイン**：回の中身が会社の都合（沿革・事業・制度）で決まっている。「体験談で気になったこと」への答えがない。参加者の質問が、回の中身とずれる
- **何が起きるか**：体験談を読んで来た学生の「確かめたいこと」に答えず、来ても次に進まない
- **直し方**：自社の体験談とクチコミを読み、「分からなかった」「気になった」を拾い、それに答える種類を一つ選ぶ。[ワンキャリアのイベントの種類と使い分け](/media/oc-event-kihon/)の「体験談から、種類を決める」
- **体験談がない年**：「何の会社か」から。[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)

## 失敗2｜「会社説明会」一つで、全部を賄う

- **サイン**：回の名前が「会社説明会」。話すことが沿革・事業・制度・選考・仕事と多い。質問の時間が最後に余った分だけ。参加者が多く、社員と話せない
- **何が起きるか**：どれも薄く、確かめたいことにたどり着かない。「企業ページに書いてあることだった」と体験談に残る
- **直し方**：話すことを二つ（選考で何を見ているか・最初の一年）に絞り、会社の概要は企業ページに任せると宣言し、質問の時間を最も長く。[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)。名前を「何が確かめられるか」に。[ワンキャリアのイベントページのタイトル](/media/oc-event-page-title/)

### エージェントベストの見解

相談で最も多い思い込みは、「イベントの失敗は、参加者数が少ないことだ」というものです。当社はワンキャリアの販売パートナーとして、イベントの相談を受けていますが、参加者数が少ないことは、五つの失敗のどれでもありません。少なくても、来た人が近い人で、次に進んでいれば、回は効いています。五つの失敗は、参加者数が多くても起き、多いほど気づきにくい。多く集まった回で、人事が全部を話し、質問の時間がなく、ページに書いた若手が出ず、「入社後に裁量がある」と言って選考で違うことを聞く。参加者数は多いので「成功した」と思い、体験談に「違った」と書かれて翌年に減って、初めて気づく。当社がイベントの相談を受けるとき、最初にやるのは、参加者数を聞くことではなく、直近の回の体験談と、次に進んだ人の数を見ることです。

## 失敗3｜ページに書いた人と違う人が出る、書いた中身と違う話をする

- **サイン**：イベントページに「〇〇職の若手が出る」と書いて、人事だけが出た。「質問の時間を長く」と書いて、話が延びて質問がなかった。「職場を見られる」と書いて、会議室だけだった
- **何が起きるか**：「書いたとおりでない」の最初。参加者は「ページと違った」と体験談に書く
- **直し方**：ページに書くことを、当日に守れることだけにする。出る人が変わったら、ページを更新する。守れないなら、書かない。[ワンキャリアのイベントページの基本](/media/oc-event-page-kihon/)の「終わったあとの動き」、[ワンキャリアのイベントに出る社員の選び方](/media/oc-event-tantou/)の「面談で会える人で、あること」
- **回の前に、ページと当日の分担表を並べる**：ずれている一行を直す

## 失敗4｜回で言ったことを、選考で守らない

- **サイン**：回で「面接ではこう見る」と言ったのに、面接で違うことを聞いた。「間隔を詰めて進める」と言って、面談から次まで長かった。「選考とは関係ない」と言って、参加を選考で使った。回で話した社員が面談に出ず、話が続かない
- **何が起きるか**：回と選考の落差が、翌年の体験談に残る。最も重い失敗
- **直し方**：回で言うことを、面接官・面談に出る人と回の前に揃える。回で話した内容を面接官に一枚で引き継ぐ。[OfferBoxの面接官への引き継ぎ](/media/ob-genba-mensetsukan/)。「選考とは関係ない」は年度の公表内容と自社の方針で確認してから書き、書いたら守る。[ワンキャリアの掲載の担当の分け方](/media/oc-keisai-tantou/)の「『書いたことを守る』の担当」

## 失敗5｜一度で止めて、型が残らない

- **サイン**：回を一度開いて、「集まらなかった」「次に進まなかった」でやめた。次の回の予定がない。出た社員に反応を戻していない。回ごとに種類も出る人も違う
- **何が起きるか**：型ができる前に終わり、参加者の体験談も一回分だけで、翌年の集客にならない。社員は「出た意味がなかった」で次に出ない
- **直し方**：小さい回を同じ型で途切れさせずに続ける。出た社員に反応を戻す。回ごとに出た質問で型を一つ直す。[ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)の「小さい回を、途切れさせずに続ける」、[ワンキャリアのイベント後のフォロー](/media/oc-event-follow/)の「出た社員への、反応」

## 回の前の、セルフチェック

| 確認 | はい／いいえ |
|---|---|
| 自社の体験談を読み、「気になった」ことに答える回か | |
| 回の名前が「会社説明会」ではなく、「誰が出て、何が確かめられるか」か | |
| 話すことが二つ以内で、会社の概要は企業ページに任せると宣言するか | |
| 質問の時間が、最初から最も長く置かれているか | |
| イベントページに書いた人が、当日に出るか | |
| ページに書いた中身（質問の時間・職場を見られる・少人数）が、当日に守れるか | |
| 回で言うことを、面接官・面談に出る人と揃えたか | |
| 選考との関係を、年度の公表内容と自社の方針で確認し、明記したか | |
| 次の場を、当日に申し込める形で用意したか | |
| 回の後の一通の型を、先に書いたか | |
| 次の回の予定があるか | |

一つでも「いいえ」なら、その項目を直してから開きます。「いいえ」のまま開くと、その項目が翌年の体験談になります。

## 参加者の反応が薄いときの、切り分け

| 反応が薄い場面 | 疑うこと | 直す場所 |
|---|---|---|
| 申込が少ない | 一覧で見つからない、名前が「会社説明会」、確かめられる回に見えない、選考との関係が不明、申込後が見えない | [ワンキャリアのイベントに人が集まらないとき](/media/oc-event-atsumaranai/)の五つの原因 |
| 来たが、質問が出ない | 話が長い、質問の出し方の案内がない、人事の口火がない、話の中身が質問したくなる話でない | 質問の設計。[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/) |
| 質問は出たが、次の場に申し込まない | 当日に申し込める形がない、次の場が一つに絞られていない、選考との関係が曖昧 | 当日の案内。[ワンキャリアのイベント後のフォロー](/media/oc-event-follow/) |
| 次の場に申し込んだが、面談に来ない | 一通が遅い、日程の候補がない、面談が遠い日 | 一通と面談の枠 |
| 面談に来たが、進まない | 回で言ったことと面談・選考が違う | 失敗4 |
| 体験談に「違った」と書かれた | 失敗3か失敗4 | ページと当日、回と選考を揃える |

上から順に疑います。切り分けの考え方は[ワンキャリアのイベントのKPI設計](/media/oc-event-kpi/)の「細い段と、直す場所」と同じです。

## 最も重い失敗｜書いたとおりでなく、翌年の体験談に残る

- **五つのうち、失敗3と失敗4が、最も重い**：ページと当日、回と選考の落差は、参加者が体験談に書く
- **体験談は、翌年の学生が読む**：今年の一回の落差が、翌年の集客を減らす
- **参加者数が多いほど、重い**：多くの学生が「違った」を読む
- **直すのは、回の中身より、「書くことと守ること」の関係**：守れることだけを書き、書いたことを守る
- **考え方は[ワンキャリアの掲載でやりがちな失敗](/media/oc-keisai-ng/)の「最も重い失敗」と同じ**：ワンキャリアの全体に通じる

### エージェントベストの見解

これは切り分けの話です。イベントの相談で、「イベントが効かない」と一言で言われることがあります。当社が確かめるのは、「効かない」がどの段の話かで、申込が少ないのか、来ても質問が出ないのか、次の場に進まないのか、面談に来ないのか、面談で進まないのか、体験談に「違った」と書かれたのか、の六つのどれかです。六つで直す場所が違い、申込が少ないのに回の中身を直しても効かず、面談で進まないのに告知を直しても効きません。「効かない」の一言を、六つのどれかに置き換えるのが、当社の最初の作業です。置き換えられれば、直す場所は一つに決まります。

## まとめ

- やりがちな失敗は五つ：体験談を読まずに開く、「会社説明会」で全部を賄う、ページに書いた人と違う人が出る（書いた中身と違う話をする）、回で言ったことを選考で守らない、一度で止める
- 参加者数が少ないことは失敗ではない。五つの失敗は参加者数が多くても起き、多いほど気づきにくい
- 最も重いのは失敗3と失敗4（書いたとおりでない）。参加者が体験談に書き、翌年の学生が読む。守れることだけを書き、書いたことを守る
- 回の前のセルフチェック（体験談・名前・二つに絞る・質問の時間・出る人・守れる中身・面接官との合意・選考との関係・次の場・一通の型・次の回）を通し、「いいえ」を直してから開く
- 反応が薄いときは、申込→質問→次の場の申込→面談→面談以降→体験談の順に切り分け、直す場所を一つに決める

## よくある質問

### 過去の回で「ページと違った」と体験談に書かれました。取り消せますか

体験談は取り消せません。できるのは、次の回で「書いたとおり」を積むことです。「違った」と書かれた項目を特定し、ページと当日を揃え、次の回の参加者が「ページのとおりだった」と書く状態にします。翌年の学生は、複数の体験談を読むので、「違った」の後に「とおりだった」が続けば、直したことが伝わります。一回の「違った」を、次の回の「とおりだった」で上書きしていく形です。

### 五つのうち、どれから直せばよいですか

失敗3と失敗4（書いたとおりでない）から。この二つは翌年の体験談に残り、他の三つより影響が長い。次に失敗1（体験談を読む）で、回の中身を学生の確かめたいことに合わせます。失敗2（二つに絞る）と失敗5（続ける）は、その後で。全部を一度に直そうとせず、失敗3と4を回の前のセルフチェックで防ぐところから始めます。

### ワンキャリアのイベントの失敗の見直しは、御社に相談できますか

できます。当社は、五つの失敗の整理、セルフチェックの型、切り分けの型、ページと当日を揃える確認を支えられます。体験談を読むこと、出ること、守ること、面接官との合意、続ける判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
