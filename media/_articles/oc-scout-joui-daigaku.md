「上位大学の学生にスカウトを送りたい」という相談があります。ここで「上位」と呼ばれる大学の学生は、多くの会社からスカウトを受け取っていて、「〇〇大学の方に」「優秀な学生の方へ」で始まる文面を、毎日のように見ています。**結論から言うと、大学名で選ばれ慣れている学生には、大学名ではなく「本人の言葉」と「自社の最初の月の場面」と「選考で何を見るか」で送ります。大学名を絞り込みの条件にするかどうかは自社で決めることですが、文面に大学名を書くことと、大学名だけで読まずに送ることは、別の話です。後者は、体験談に「大学名だけ変えたスカウト」と書かれ、募集の「こんな人」から外れる学生が来て、大学名で選ばない学生を見落とします。返信が来なくても、大学名のせいにしません。** この記事では、この学生が受け取っている文面、大学名で絞ると起きること、送るなら何で送るか、他社と同じ文面にならない工夫、条件にすることと文面に書くことの違い、返信が来ないときの見方、分担を整理します。絞り込みの基本は[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/)、プロフィールの読み方は[ワンキャリアの学生プロフィールの読み方](/media/oc-scout-profile/)で書きました。

## この作業の目的｜大学名で選ばれ慣れている学生に、「大学名以外を読んだ」と伝わる文面にする

多くのスカウトを受け取っている学生は、文面を開く前に「これは大学名で送っている」と判断します。大学名や「優秀」の言葉があれば、その時点で閉じます。

目的は、その学生に「この会社は、大学名ではなく、自分が書いたことを読んだ」と伝わる文面にすることです。それができれば、大学名で来た他社の文面の中で、自社の文面だけが読まれます。

## この学生が、受け取っている文面

| 受け取っている文面 | 学生の反応 |
|---|---|
| 「〇〇大学の△△様へ」 | 大学名の差し替え。読まない |
| 「優秀な学生の方に、特別に」 | 褒め言葉と煽り。信用しない |
| 「貴学のご出身者が多数活躍」 | 大学名で選んでいる。自分ではない |
| 「早期選考にご案内」 | 急がせている。「集めたい会社」 |
| 「ぜひ一度、弊社の説明会へ」 | 会社の話。営業 |
| 会社の規模や実績の強調 | 自分の話ではない |

この学生の体験談には、「同じような文面が大量に来た」「大学名だけ変えたスカウトが分かる」と書かれることがあります。その体験談は、他の学生も読みます。

## 大学名で絞ると、起きること

| 起きること | なぜ |
|---|---|
| 読まずに送る | 大学名で絞った時点で「送る」と決め、プロフィールを読まない |
| 体験談に「大学名だけ変えたスカウト」と書かれる | 読んでいない文面は、学生に分かる |
| 募集の「こんな人」から外れる学生が来る | 大学名は「こんな人」に書いていない条件 |
| 大学名で選ばない学生を見落とす | 「こんな人」に合う学生が、絞り込みの外にいる |
| 他社と同じ学生に、同じような文面を送る | 差がつかない |
| 返信が来ないと「大学名の学生は難しい」と判断する | 原因は文面と企業ページなのに、大学名のせいにする |

「読まずに送る」が、最も多く起きることです。大学名で絞ると、それだけで「良い学生」を選んだ気になり、プロフィールを読む工程が抜けます。

### エージェントベストの見解

相談で最も多い思い込みは、「上位大学の学生は、条件の良い会社にしか返信しない」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、この学生から返信が来ない会社の文面を読むと、大学名で始まり、「優秀」と褒め、会社の規模を並べています。この学生は、そういう文面を毎日受け取っていて、開く前に閉じます。逆に、規模の大きくない会社でも、「〇〇で詰まったとき□□をされた点を読んで」と本人の言葉で書き、「最初の月は△△から始まります」と場面で書き、「選考では学生時代の話を場面で聞きます」と一文添えた文面には、返信が来ます。当社が絞り込みの相談を受けるとき、最初にやるのは、大学名を条件から外して「こんな人」から条件を作り直すか、大学名を残すにしても、文面から大学名と「優秀」を消すことです。大学名で選んでいる会社は多く、選んでいない文面のほうが目立ちます。

## 送るなら、何で送るか

| 要素 | 書き方 |
|---|---|
| 本人の言葉 | プロフィールの学生時代の場面を、本人の言い回しのまま。大学名、学部名、「優秀」は書かない。[ガクチカを読んでスカウトを書く方法](/media/oc-scout-gakuchika/) |
| 自社の最初の月の場面 | 「最初の月は〇〇から始まります」。他社と同じ「成長できる環境」ではなく、自社でしか書けない場面 |
| 選考で何を見るか | 「選考では学生時代の話を場面で聞きます。正解はありません」。この学生は、選考で何を見られるかを気にしている |
| 話す場と、誰が話すか | 入社してまもない社員の名前。人事の説明会ではなく |
| 企業ページへの誘導 | 「詳しくは企業ページに」。この学生は、確かめてから返信する |

文面の4段の型は、他の学生と同じです。[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。違うのは、「大学名と『優秀』を書かない」ことと、「自社の最初の月の場面を、他社と重ならない具体で書く」ことです。

## 他社と同じ文面に、ならない工夫

この学生には、多くの会社が「学生時代の話を読んで」の型で送り始めています。型が同じなら、差がつくのは中身です。

- **2段目の「最初の月の場面」を、自社でしか書けない具体にする**：「先輩に同行」ではなく、「〇〇業界のお客さまの現場に、最初の週から同行して、△△を見る」
- **「詰まる場面」を書く**：「最初の月は、□□で詰まる人が多い」。良いことだけの会社は多く、詰まる場面を書く会社は少ない
- **3段目の「何を見るか」を、自社の言葉で**：「人物重視」ではなく、「その仕事を自分ならどう進めるかを一緒に考えます」
- **4段目の話す人を、名前と近さで**：「入社二年目の〇〇」
- **企業ページが、他社と違うことを書いているか**：文面で興味を持った学生が確かめる先。[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)

「自社でしか書けない具体」は、入社してまもない社員の「最初の月に詰まった場面」から出てきます。分担は[ワンキャリアのスカウトを誰が送るか](/media/oc-scout-tantou/)で書きました。

## 条件にすることと、文面に書くことは別

大学名を絞り込みの条件に使うかどうかは、自社の方針で決めることです。この記事では、使うべきかどうかは書きません。ただし、次の三つは分けて考えます。

| 分けること | 中身 |
|---|---|
| 条件に使うか | 自社で決める。使うなら、募集の「こんな人」との関係を説明できるか |
| 文面に書くか | 書かない。大学名は「読んでいない」の印 |
| 読まずに送るか | 送らない。条件で絞ったあとに、1人ずつ読む |

「条件に使うが、文面に書かず、読んで送る」は、成り立ちます。「条件に使って、文面に書いて、読まずに送る」が、失敗の形です。

## 大学名で選ばない学生を、見落とさない

大学名で絞ると、募集の「こんな人」に合う学生が、絞り込みの外に残ります。

- **「こんな人」を学生時代の状態で条件にする**：大学名を条件にしても、「こんな人」の条件を別に持つ
- **大学名の外の学生も、読める数の範囲で読む**：条件を二本立てにする
- **面接で「どこを読んで来たか」を聞き、大学名の内外で反応を比べる**：大学名の外から、合う学生が来ていないか
- **選考に進んだ学生と決まった学生の大学名を、台帳で見る**：大学名と結果に関係があるかを、自社の記録で確かめる

「自社の記録で確かめる」が要点です。大学名と結果の関係は、一般論ではなく、自社の台帳で見ます。

## 返信が来なくても、大学名のせいにしない

この学生から返信が来ないとき、「上位大学の学生は難しい」と判断する前に、次を見ます。

- **文面に大学名や「優秀」が入っていないか**
- **文面の最初に、本人の言葉があるか**
- **企業ページが、選考の流れと何を見るかから始まっているか**
- **自社の体験談に「掲載と違った」「テンプレだった」が無いか**
- **受諾への対応が、翌日までにできているか**
- **読める数で送っているか**

この六つのどれかに問題があれば、大学名に関わらず返信は来ません。切り分けの考え方は[ワンキャリアのスカウトでやりがちな失敗](/media/oc-scout-ng/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 大学名を条件に使うかを決める | 人事と責任者（自社の方針で） |
| 「こんな人」を学生時代の状態で条件にする | 人事と責任者 |
| 文面から大学名と「優秀」を消す | 人事（型で） |
| 自社の最初の月の場面を、他社と重ならない具体で | 入社してまもない社員（人事が聞いて型に） |
| プロフィールを読み、本人の言葉で一文を書く | 送る人 |
| 大学名の内外で反応を比べる | 人事（台帳と面接の言葉で） |
| 返信が来ないとき、大学名以外を見る | 人事 |

運用代行や代理店が支えられるのは、条件の二本立ての設計、文面から消す言葉のチェック、他社と重ならない具体の聞き方、台帳での比べ方までで、条件に使うかの判断、最初の月の場面の言語化、読んで書くことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社がワンキャリアで「上位大学の学生に送りたい」という相談を受けるとき、最初に確かめるのは、その会社の文面に大学名と「優秀」が入っていないか、企業ページが会社紹介から始まっていないか、の二つです。この二つがあるまま送っても、この学生は開く前に閉じます。当社が勧める順番は、文面から大学名と「優秀」を消す、企業ページを選考の流れから始める、自社の最初の月の場面を具体にする、その次に、大学名を条件に使うかを決める、です。条件の話は、文面と企業ページが整ってからで、整っていない状態で条件だけを決めても、送る相手が変わるだけで、返信は変わりません。

## まとめ

- 大学名で選ばれ慣れている学生は、大学名と「優秀」で始まる文面を毎日受け取っていて、開く前に閉じる
- 大学名で絞ると、読まずに送り、体験談に「大学名だけ変えたスカウト」と書かれ、「こんな人」から外れる学生が来て、大学名で選ばない学生を見落とす
- 送るなら、本人の言葉、自社の最初の月の場面（他社と重ならない具体、詰まる場面）、選考で何を見るか、話す人の名前で
- 大学名を条件に使うかは自社で決めることで、文面に書かないことと、読んで送ることは別。「条件に使うが、書かず、読んで送る」は成り立つ
- 返信が来なくても大学名のせいにせず、文面・企業ページ・体験談・対応の速さ・読める数を先に見る

## よくある質問

### 大学名を条件に使うのは、やめたほうがよいですか

使うかどうかは自社の方針で決めることで、この記事では判断しません。使う場合も、募集の「こんな人」の条件を別に持ち、文面には大学名を書かず、条件で絞ったあとに1人ずつ読んで送ります。大学名と結果の関係は、一般論ではなく自社の台帳で確かめます。

### この学生から返信が来ず、「うちの規模では難しい」と感じます

規模より先に、文面と企業ページを見ます。大学名や「優秀」が文面に入っていないか、企業ページが選考の流れから始まっているか、自社の最初の月の場面が他社と重ならない具体で書けているか。規模の大きくない会社でも、この三つが整っていれば、この学生は「自分を読んだ会社」として開きます。規模を気にする前に、読んだと伝わる文面かを見ます。

### 上位大学の学生へのスカウトは、御社に相談できますか

できます。当社は、条件の二本立ての設計、文面から消す言葉のチェック、他社と重ならない具体の聞き方、台帳での比べ方を支えられます。条件に使うかの判断、最初の月の場面の言語化、読んで書くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
