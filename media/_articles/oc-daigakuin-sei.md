大学院生へのスカウトは、学部生向けの文面に「研究もされている方に」と一言足して送られがちです。ところが、修士・博士の学生は、研究室の予定の中で就職活動の時間を作っていて、「この会社の選考は、自分の研究の予定と両立できるか」を先に見ています。**結論から言うと、大学院生へのスカウトは、研究の進め方を読んだ一文に加えて、面談の形（短く・オンライン可・日程は学生が選べる）と、選考の時期の目安を文面に書きます。修士と博士は分けて考え、博士には入社後の位置づけを事実で書きます。** この記事では、大学院生が文面で見ていること、修士と博士の違い、送る前の手順、やりがちな失敗、社内の分担を整理します。研究の進め方の読み方は[ワンキャリアで理系学生にスカウトを送る文面](/media/oc-scout-rikei/)、大学院生の年間の動きは[大学院生の採用スケジュール](/media/kh-schedule-daigakuin/)で書きました。この記事は、その二つをつなぐ、スカウトの考え方です。

## この作業の目的｜「研究の時間を知っている会社」と読まれる

大学院生にとって、就職活動は研究と並行する作業です。学会、中間発表、論文の締め切りの前後は、面談の日程を入れにくくなります。

目的は、文面を読んだ時点で「この会社は研究の予定を前提に選考を組んでいる」と分かるようにすることです。研究の中身への理解を示すより先に、時間への配慮が伝わるほうが、受諾の判断がしやすくなります。

## 大学院生が、スカウトを読むときに見ていること

| 見ていること | 文面への意味 |
|---|---|
| 研究のどこを読んだか | テーマではなく、進め方の場面に触れる一文 |
| 面談の負担 | 時間の目安、オンラインの可否、日程の選び方 |
| 選考の時期と回数 | 研究の山と重なるか判断できる目安 |
| 専門と配属の関係 | 研究分野と仕事の距離を、正直に |
| 大学院で過ごした時間の扱い | 学部卒と比べて、入社後に何が違うのか |

最後の項目は、学部生の文面には出てこない関心です。大学院での時間をどう見ているかを、自社の制度の事実として書けるか確認しておきます。

## 修士と博士で、分けて考えること

| 観点 | 修士 | 博士 |
|---|---|---|
| 就職活動の時期 | 入学して早いうちに動き始める学生もいる。研究室や分野で幅がある | 学位の取得の見通しと並行。時期は人によって幅がある |
| 研究で読むところ | 進め方、詰まった場面と工夫 | テーマの立て方、共同研究での役割、後輩への指導 |
| 文面で答えること | 専門と配属の距離、最初の一年 | 入社後の位置づけ、研究の経験をどう扱うか |
| 推薦との関係 | 研究室や専攻の推薦と並行する学生がいる | 指導教員との相談が前提になることが多い |

博士の学生には、「研究職か、それ以外か」「入社後の役割の決まり方」を、自社の制度に沿って事実で書きます。処遇の条件を文面に詳しく書く必要はありませんが、企業ページに書いてある場所を示します。

## 送る前に決めておく手順

1. **大学院生を採る募集を決める**：研究開発職だけか、他の職種にも広げるか。研究開発職の掲載は[ワンキャリアで研究開発職を募集するときの掲載とスカウト](/media/oc-kenkyu-keisai/)
2. **面談の形を決める**：時間の目安、オンラインの可否、日程の選び方。文面に書くので、先に社内で合意する
3. **選考の時期と回数の目安を決める**：研究の山と重なりにくい置き方を、人事と面接官で確認する
4. **対象の絞り方を確かめる**：学年や学歴の条件でどこまで絞れるかは、管理画面と媒体の案内で確認する。読む箇所は[ワンキャリアの学生プロフィールの読み方](/media/oc-scout-profile/)
5. **文面の型を作る**：研究の進め方を読んだ一文、仕事との距離、面談の形、選考の時期の四つ
6. **送る時期を決める**：学会や発表の直前を避ける。時期の考え方は[ワンキャリアのスカウトを送る時期・時間の考え方](/media/oc-scout-timing/)

### エージェントベストの見解

大学院生へのスカウトで効果が出ない会社は、文面より前に、面談の形を決めていないことが多いです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、大学院生向けの文面を整えるとき、最初に確認するのは「面談を短く、オンラインで、学生が選べる日程で組めるか」です。これが決まっていないと、文面で「研究のご予定に合わせます」と書いても、受諾のあとに面接官の都合で日程が決まり、学生は文面との違いを感じます。順番としては、面談の形と選考の時期を社内で決める、それを文面に書く、研究の進め方を読んだ一文を添える、です。一文の質より、書いたとおりに日程が組めることが先です。

## やりがちな失敗

| 失敗 | 大学院生からどう見えるか |
|---|---|
| 学部生向けの文面に「大学院生歓迎」と足す | 大学院の時間を見ていない |
| 研究テーマと仕事を無理につなげる | 研究を分かっていない |
| 面談の日程を会社の候補日だけで出す | 研究の予定と合わない |
| 学会や論文の締め切り前に、返信を急がせる | 研究の山を知らない会社 |
| 博士の学生に、学部生と同じ入社後の説明 | 位置づけが分からない |
| 送り主が人事だけで、研究の話ができる人が出てこない | 研究を聞いてもらえない |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 面談の形と選考の時期の合意 | 人事と面接官の責任者 |
| 博士の入社後の位置づけの整理 | 人事と配属先の責任者 |
| 研究の進め方を読み、一文を書く | 大学院を出た技術系の社員（人事が型を用意） |
| 対象の絞り込み、送信、台帳 | 人事 |
| 面談に出る | 研究の話ができる社員 |

運用代行や代理店が支えられるのは、型、読む箇所の整理、送る時期の設計までで、研究を読んで一文を書くことと、面談に出ることは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

受諾のあとに止まる大学院生の多くは、日程の調整で止まっています。当社がワンキャリアのスカウトの記録を見ると、受諾までは進んだのに、面談の日程が決まらないまま時間が過ぎている大学院生が目立つことがあります。研究室の予定で返信が遅れ、会社が候補日を出し直すうちに、学生の側で優先度が下がります。当社が勧めているのは、受諾の直後の連絡で、日程の候補を会社が並べるのではなく、学生が都合の良い枠を選べる形にすることと、「研究のご予定で返信が遅れても構いません」と一言添えることです。この二つで、日程の往復が減り、学生は研究の山を越えてから落ち着いて返信できます。受諾後の連絡は[ワンキャリアでスカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/)で書きました。

## まとめ

- 大学院生は、研究の予定と両立できるかを先に見ている。面談の形と選考の時期の目安を文面に書く
- 修士と博士は分けて考える。博士には入社後の位置づけを、自社の制度に沿って事実で書く
- 送る前に、面談の形、選考の時期、対象の絞り方を社内で決める。絞り方は管理画面と媒体の案内で確認する
- 研究テーマと仕事を無理につなげず、進め方の場面に触れる
- 受諾のあとは、学生が日程を選べる形にし、返信を急がせない

## よくある質問

### 修士と博士で、文面の型を分けたほうがよいですか

型は一つで構いません。変えるのは、研究で読む箇所と、入社後の説明の一文です。修士には専門と配属の距離を、博士には入社後の位置づけを書きます。型を増やしすぎると、管理の手間が増えます。

### 研究の話ができる社員が面談に出られません

文面の一文の確認だけを頼み、面談は人事が出て、研究の話は次の段で技術系の社員が聞く形にできます。その場合は、文面に「研究の話は、次の段で技術系の社員が伺います」と書き、面談で研究を深く聞かないようにします。

### 大学院生へのスカウトは、御社に相談できますか

できます。当社は、大学院生向けの型、読む箇所の整理、面談の形と送る時期の設計を支えられます。研究を読んで一文を書くこと、面談、選考の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
