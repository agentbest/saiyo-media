内定を辞退された。その場で理由を聞き、「考え直してもらえないか」と引き止め、「残念です」を重ね、次の内定者への連絡が遅れて、辞退した学生からは何も返らず、次の候補は他社で決まっていた。**結論から言うと、辞退の連絡には理由を聞かず「連絡をありがとう」だけで返し、数日後に採用担当ではない別の人から一通で「決め手になった場面を一つ」を聞き、返った言葉を五つの分け方で台帳に残し、次の内定者への連絡を期限の前に用意しておきます。辞退した学生への対応は、その学生の後輩と、体験談を読む次の年の学生に読まれます。引き止め・理由の詰問・「残念です」の重ね・損害の話は、辞退を覆さず、次の年の母集団を減らします。辞退された直後に人事がすることは、その学生への対応より先に「次に誰に出すか」です。** 理由の分け方は[内定辞退の理由の分け方](/media/kh-naitei-jitai-riyuu/)で書きました。この記事は、辞退の連絡が来た日から翌年までの対応を書きます。

## この作業の目的｜辞退を、「終わり」ではなく「翌年の材料」と「次の内定者への切り替え」にする

辞退の連絡が来た瞬間、会社の側にできることは二つしかありません。一つは、辞退した学生への対応を次の年に読まれる形にすること。もう一つは、次の内定者に切り替えることです。辞退を覆すことは、その二つに入りません。

目的は、辞退した学生を引き止めることではなく、辞退から「翌年に直す場所」を取り出し、採用の計画を止めないことです。

## 辞退のあとで、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| その場で理由を詰問する | 角の立たない理由（他社・条件）しか返らず、学生は「詰められた」と覚える |
| 引き止める | 覆らない。覆っても入社前に再び辞退。「引き止められた」が体験談に書かれる |
| 「残念です」を重ねる | 学生に罪悪感を残し、後輩に「あの会社は辞退すると重い」と伝わる |
| 損害の話をする | 法的にも実務的にも会社の損失を大きくする。次の年の母集団が減る |
| 返事をしない | 「辞退したら無視された」が体験談に書かれる |
| 次の内定者への連絡が遅れる | 辞退の対応に時間を使い、次の候補が他社で決まる |

共通するのは、辞退を「取り戻すもの」として扱っていることです。取り戻せず、扱い方だけが次の年に残ります。

## 辞退の連絡への、返し方

- **「連絡をありがとう」で、返す**：理由を聞かない。引き止めない。「残念」は一度だけ、重ねない
- **辞退の意思を、確認する**：「承りました」と、辞退を受けたことを明確に。曖昧にすると、学生が「まだ何か言われる」と構える
- **手続きがあれば、簡潔に**：返送するものがあれば、その方法だけ
- **「戻ってきてよい」を、伝えられるなら一言**：入社後や中途で戻る道があるなら、「またご縁があれば」を事実として
- **返す人は、選考で会った人か人事**：辞退の連絡を受けた人が返す。別の人からの返しは、この時点ではしない
- **当日に返す**：翌日に持ち越さない。返事の速さは、辞退した学生にも読まれる

辞退の連絡への返しは短く、当日に、理由を聞かず。これが、次の年に読まれる形です。

### エージェントベストの見解

相談で最も多い思い込みは、「辞退の連絡が来たら、その場で理由を聞いて、できれば引き止めるのが採用担当の仕事だ」というものです。当社は3媒体すべての販売パートナーとして、内定後の運用まで見ていますが、その場で理由を聞いて引き止めた会社で、辞退が覆った例はほとんど無く、覆った数少ない例も入社前に再び辞退しています。辞退の連絡をする学生は、決めてから連絡していて、その場で聞かれる理由は「他社に決めました」の一語で、引き止められた記憶だけが残ります。その記憶は、その学生の後輩と、翌年の体験談に伝わります。当社が最初にお願いするのは、辞退の連絡への対応を「連絡をありがとう」の一文に固定し、理由を聞く役を、数日後の別の人からの一通に分けることです。一通は、採用担当ではない役員か、選考で会わなかった社員から、「差し支えなければ、決め手になった場面を一つ。今後の選考を直すために使います。返さなくて構いません」と送ります。返さなくてよいと添えた一通に、採用担当には言わなかった理由が返ります。その場で聞くのをやめることが、理由を聞く最も早い方法です。

## 数日後の、別の人からの一通

| 項目 | 中身 |
|---|---|
| 誰から | 採用担当ではない別の人。役員か、選考で会わなかった社員 |
| いつ | 辞退の連絡の数日後。当日と翌日は送らない |
| 何を聞くか | 「決め手になった場面を一つ」「うちの選考で、直したほうがよいと感じたこと」。二つまで |
| 何を添えるか | 「今後の選考を直すために使います」「返さなくて構いません」「辞退の判断を変えてほしいという趣旨ではありません」 |
| 長さ | 短く。会社の説明や、選考の振り返りは書かない |
| 返らなかったら | 追わない。返った分だけを台帳に残す |

一通の目的は、理由を聞くことであって、関係を続けることではありません。返った言葉は、五つの分け方（入口のずれ・選考中の印象・内定後の間・条件・他社）で台帳に残します。

## 次の内定者への、連絡

- **辞退の可能性を、期限の前に織り込む**：内定を出す数を「承諾が全部出なくても足りる数」で決め、次に出す候補を期限の前に用意しておく。[内定承諾の期限の考え方](/media/kh-naitei-shoudaku-kigen/)
- **辞退の連絡が来た日に、次の候補に動く**：辞退した学生への一通より、次の候補への連絡が先
- **次の候補への連絡に、「辞退が出たので」を言わない**：「繰り上げ」と読まれると、学生は「二番目」と感じる。出す順番の理由は言わない
- **次の候補が選考から時間が経っているなら、面談を一度置く**：内定をいきなり出さず、現場の社員と話す場を先に。[内定の出し方と伝え方](/media/kh-naitei-dashikata/)
- **次の候補にも、同じ出し方で**：電話の一言、書面、現場からの一通。辞退の穴埋めで手順を省かない

辞退された直後に人事がすることは、その学生への対応より先に「次に誰に出すか」です。

## 辞退した学生との、関係の残し方

- **「またご縁があれば」を、事実として**：中途での再応募や、知人の紹介の道があるなら、一言で。無いなら書かない
- **辞退の理由を、学生の側の問題にしない**：「もったいない」「後悔しないか」は言わない
- **その学生の大学・研究室・サークルとの関係を、辞退で切らない**：翌年の学生は、辞退した先輩から会社の対応を聞く
- **SNSや体験談で書かれても、反応しない**：書かれた内容が事実なら、直す。事実でなくても、反論しない
- **辞退した学生の情報を、他の内定者に話さない**：「〇〇さんは辞退した」を他の内定者に伝えると、動揺と序列を生む

辞退した学生は、会社の対応を最も近くで見た学生で、次の年の学生への最初の発信者です。

## 翌年に、戻すこと

- **五つの分け方で最も多かったものを、一つ直す**：[内定辞退の理由の分け方](/media/kh-naitei-jitai-riyuu/)の対応表で、直す場所を決める
- **「いつ決めたか」を見る**：面接の日に決めていたなら、選考中の設計。[選考中から辞退を減らす設計](/media/kh-naitei-jitai-boushi-senkou/)
- **辞退への対応そのものを、振り返る**：返事の速さ、一通の返り方、次の候補への切り替えの日数
- **承諾した学生の「迷った理由」と並べる**：辞退した学生だけを見ない
- **承諾率の三つの割り方に載せる**：入口ごと・時期ごと・理由ごと。[内定承諾率の見方](/media/kh-naitei-shoudaku-ritsu/)

辞退は、翌年の運用を直す最も具体的な材料で、材料として使わなければ、同じ辞退が翌年に出ます。

## 媒体ごとに、変わる点

- **OfferBox**：オファーの文面の名義の社員が、辞退の連絡を受けることがある。その場合も返しは「ありがとう」だけで、一通は別の人から。[OfferBox経由の内定辞退が続くとき](/media/ob-naitei-jitai/)
- **Wantedly**：辞退した学生が、記事を書いた社員とつながっていることがある。社員の側から辞退の話題に触れない。[Wantedly経由の内定辞退が続くとき](/media/wt-naitei-jitai/)
- **ワンキャリア**：辞退後の対応が、翌年の体験談に書かれる。「辞退の連絡をしたら、丁寧に返ってきた」は、次の年の学生に読まれる。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

三つとも、辞退後の対応の型は同じで、辞退した学生と誰がつながっているかが違います。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 辞退の連絡への返し（当日、理由を聞かず） | 連絡を受けた人（選考で会った人か人事） |
| 次の候補への連絡 | 人事。辞退の当日に |
| 数日後の一通 | 採用担当ではない別の人（役員か、選考で会わなかった社員） |
| 返った言葉を五つの分け方で記録 | 人事 |
| 辞退した学生の情報を他の内定者に話さない | 全員 |
| 経営に「引き止めない・損害の話をしない」を共有 | 採用の責任者 |
| 翌年に直す場所を一つ決める | 採用の責任者 |

運用代行や代理店が支えられるのは、返しの文面の型、一通の下書き、記録の型までで、返すこと、次の候補への連絡、一通を送る人は社内が担います。

### エージェントベストの見解

辞退後の対応で、当社が先にお伝えしているのは、「引き止めない方針を最も守れないのは、経営」だということです。人事は「ありがとう」で返しますが、経営が辞退の報告を聞いて「自分が電話する」「なぜ引き止めなかった」と言い、経営からの電話で学生が引き止められる形になります。申し込んだあとに内定後の運用が崩れる会社に共通するのは、この経営からの電話で、学生が「役員から電話が来た」と後輩に伝え、次の年の学生が「辞退すると役員が出てくる会社」と読むことです。当社が案内するのは、内定を出す前に、経営に「辞退の連絡が来たら、引き止めず、当日に次の候補に動く。理由は数日後に別の人から一通で聞く」を共有し、経営の役を「数日後の一通の送り主」に置くことです。経営の電話を引き止めに使わず、一通の送り主に使うと、経営の関与が「圧」ではなく「丁寧さ」として残ります。役の置き方が、辞退後の対応を決めます。

## まとめ

- 辞退の連絡には理由を聞かず「連絡をありがとう」だけで、当日に返す。引き止め・詰問・「残念」の重ね・損害の話はしない
- 数日後に、採用担当ではない別の人から一通で「決め手になった場面を一つ」。「返さなくて構いません」を添える
- 辞退された当日に人事がすることは、その学生への対応より先に「次に誰に出すか」。次の候補にも同じ出し方で
- 辞退した学生は、次の年の学生への最初の発信者。関係を切らず、他の内定者に話さず、書かれても反応しない
- 返った言葉を五つの分け方で残し、翌年に直す場所を一つ決める。経営の役は「引き止め」ではなく「一通の送り主」に

## よくある質問

### 辞退の理由をその場で聞かないと、聞く機会を失いませんか

その場で聞いても、「他社に決めました」の一語しか返りません。数日後に、採用担当ではない別の人から「返さなくて構いません」と添えて一通を送ると、一部の学生から本当の理由が返ります。全員から返らなくてよく、返った分を五つの分け方で残します。その場で聞かないことが、理由を聞く最も早い方法です。

### 辞退した学生から、後日「やはり入社したい」と連絡が来ました

受けるかどうかは会社の判断ですが、受けるなら、辞退の理由を確かめてから、次の内定者との関係と、入社後の配属に影響が無いかを見ます。受けないなら、理由を言わず「今回はご縁がなかった」で返します。どちらの場合も、他の内定者にその経緯を話さないことです。

### 内定辞退されたあとの対応は、御社に相談できますか

できます。当社は、返しの文面の型、一通の下書き、記録の型を支えられます。返すこと、次の候補への連絡、一通を送る人は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、内定後の運用まで含めて支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
