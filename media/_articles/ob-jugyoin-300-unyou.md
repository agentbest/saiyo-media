従業員が三百名前後。人事は数人いて、新卒採用の担当もいる。現場に頼めば協力してくれる社員もいる。知名度は業界の中では知られているが、学生には知られていない。この規模の会社がOfferBoxを始めると、「人事が数人いるので、検索も文面も返信も面談も人事で回せる」と考えて人事が全部を持ち、名義が人事になって「会社が送った」に読まれ、面談の枠が人事の予定で埋まり、現場を巻き込める規模なのに巻き込まずに止まります。**結論から言うと、人事が数人いて現場を巻き込める規模だからこそ、「人事が全部持つ」で止まります。最初に決めるのは、名義を職種ごとに現場に置くこと、承認への返信の担当を人事の中で一人に決めること、送る数を現場の面談枠から逆算すること、知名度が中程度なら「なぜあなたに」で差をつけること、選考の段を短くすること、代行に出す範囲を人事の時間で決めることです。** この記事では、この規模の会社が割ける時間と人、最初に決めること、文面の書き方、人事と現場の分担、やりがちな失敗を整理します。人事が一人の会社は[人事が1人の会社のOfferBox運用](/media/ob-jinji-hitori-unyou/)、大企業の本社と部門の線は[大企業のOfferBox運用](/media/ob-daikigyo-unyou/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 人事が数人いて、新卒の担当がいる | 「人事で回せる」と考え、名義も面談も人事が持つ |
| 現場を巻き込める規模 | 頼めば協力してくれるのに、頼み方が決まっておらず頼まない |
| 知名度が中程度（業界では知られ、学生には知られていない） | 会社紹介から始める文面になり、「なぜあなたに」が薄い |
| 採る人数が、一人では回らないが、チームで分けるほどでもない | 返信の担当が曖昧になり、「誰かが返す」で放置される |
| 予算が中程度で、代行に出すか自社で回すか迷う | 決めないまま始め、人事の時間が検索と送信に消える |
| 選考が、大企業の型を真似て段が多い | オファー経由の学生が、段の多さで離れる |

この規模の会社がOfferBoxに割ける時間は、人事の人数ではなく、「人事が型と台帳と返信を持ち、現場が名義と面談を持つ」線が引けているかで決まります。人手があるほど、線を引かないと重なります。

## 最初に決めること

1. **名義を、職種ごとに現場に置く**：人事の名義は「会社が送った」になる。営業なら営業の若手、技術なら技術の若手。頼むことは名義・文面の確認・面談の三つ。[OfferBoxの運用に現場社員を巻き込む方法](/media/ob-genba-makikomi/)
2. **承認への返信の担当を、人事の中で一人に決める**：数人いると「誰かが返す」になる。通知を見て当日に返す人を一人に。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
3. **送る数を、現場の面談枠から逆算する**：名義の社員が月に何人と会えるか。その数から、承認の割合を昨年の台帳で置いて逆算。人事の面談枠ではなく、現場の面談枠
4. **知名度が中程度なら、「なぜあなたに」で差をつける**：学生は会社を知らないので、会社紹介は短く採用サイトに逃がし、記述のどの行動を見たかと、最初の年に何をするかを書く。[知名度がない会社がOfferBoxで学生に届くには](/media/ob-chimeido-nai/)
5. **選考の段を短くする**：大企業の型を真似ない。段ごとの目的を一つに。[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/)
6. **代行に出す範囲を、人事の時間で決める**：人事が数人でも、採用以外の業務がある。検索・下書き・送信・一次返信のどこまでを人事が持てるかを週の時間で出し、持てない分を外に。[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)
7. **台帳を一つにし、職種と名義の列を持つ**：人事が数人いても、台帳は一つ。[OfferBoxと採用管理システム（ATS）の連携の考え方](/media/ob-heiyou-ats/)

### エージェントベストの見解

これをやる前に、先に「職種ごとに、誰の名義で送るか」を現場と決めておかないと、人事が数人いても効果が出ません。当社は3媒体すべての販売パートナーとして、OfferBoxの運用代行を受けているので、この規模の会社の運用を見ていますが、止まる会社に共通するのは、人事が数人いることで「自分たちで回せる」と考え、名義も面談も人事が持ち、現場に頼まないことです。人事の名義の文面は「会社が送った」と読まれ、人事の面談枠は数人分しかなく、承認した学生の面談が入らず、他社に決まります。この規模の会社の強みは、人事がいることではなく、現場を巻き込めることです。順番は、職種ごとに現場の若手を名義に決め、その若手の面談枠を先に押さえ、その枠から送る数を逆算し、そのあとで人事が検索と文面と返信を持つことです。名義が決まれば、人事の時間は「会う」ではなく「回す」に使えます。

## 文面の書き方｜会社紹介を短く、「なぜあなたに」を長く

| 書かない | 書く |
|---|---|
| 会社紹介から始める文面 | 記述のどの行動を見たか、から始める |
| 「業界では知られています」 | 名義の若手が、最初の年に何をしたか |
| 「中堅企業ならではの裁量」 | 誰と組んで、何を任せるか。具体の場面 |
| 大企業と比べる表現 | 自社の仕事の場面。比べない |
| 人事の名義の丁寧な文面 | 若手の言葉。話すときの調子で |

- **知名度が中程度の会社は、会社紹介を一文にして採用サイトに逃がす**：[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)
- **文面の共通部分は人事が、個別の一文は名義の若手が**：若手には「記述のここを見て、一言」だけ頼む
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)

## 人事と現場の分担

| 作業 | 人事 | 現場 |
|---|---|---|
| 「こんな人」の一行と検索条件 | 型を作る | 職種ごとの一行を出す |
| 検索、文面の共通部分、送信 | 持つ（または代行） | — |
| 個別の一文、文面の最終確認 | 下書きを渡す | 一言足して確認する |
| 名義 | — | 職種ごとの若手 |
| 承認への当日の返信 | 一人が持つ（または代行） | — |
| 面談 | 日程を押さえる | 名義の若手と面接官が出る |
| 台帳 | 一つで持つ | 面談の結果を返す |
| 週に一度の数字 | 見る。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/) | 面談枠を返す |

- **人事が数人いるなら、作業で分ける**：検索と送信の担当、返信と台帳の担当、現場との調整の担当。同じ人が全部を持たない。[OfferBoxをチームで運用するときの役割分担](/media/ob-team-unyou/)
- **現場に頼むのは、名義・一言・面談の三つに絞る**：それ以上頼むと、現場が「採用を手伝わされている」になる
- **現場が協力しないときは、頼む範囲が広すぎることが多い**：[現場がOfferBoxの面談に協力してくれないとき](/media/ob-genba-hikyouryoku/)

## 代行に出す範囲を、人事の時間で決める

- **人事が数人いても、採用以外の業務がある**：週に採用に使える時間を、人事の中で合計する
- **その時間で、検索・下書き・送信・一次返信・台帳・現場との調整のどこまで持てるかを見る**：持てないところを外に
- **出すなら、検索・下書き・送信・一次返信から**：人事の時間を、現場との調整と面談の設定に残す
- **出さないなら、返信の担当を一人に決めることだけは守る**：ここが曖昧だと、数人いても放置が起きる
- **時間が足りなくなったら、送る数を減らす**：[OfferBoxの運用に工数が足りないときの対処](/media/ob-kousuu-tarinai/)

運用代行や代理店が支えられるのは、人事と現場の線の型、名義の置き方の型、文面の型、台帳の型、検索・下書き・送信・一次返信までで、名義の選定、個別の一文、面談、代行に出す範囲の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

送り始めたあと、最初の送る時期で起きることに共通するのは、人事が数人で回し始めて、承認は付くのに現場の面談枠が取れず、承認から面談まで日数が伸びて、承認した学生が他社に決まることです。当社はOfferBoxの運用代行で、この規模の会社の承認から面談までの日数を見ていますが、人事の面談枠で面談を組んでいる会社は、人事の予定が先に埋まり、現場の面談枠は押さえられていません。人事が面談に出ると、学生は「名義の人に会えない」で離れ、現場が面談に出るなら、その枠を送る前に押さえておく必要があります。当社がこの規模の会社の代行を受けるときは、送る前に、名義の若手の面談枠を月の予定に固定してもらい、その枠から送る数を決めています。枠が先にあると、承認から面談までの日数が伸びず、人事は面談ではなく調整に時間を使えます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 人事が名義も面談も持つ | 「会社が送った」に読まれ、面談枠が人事で埋まる | 名義と面談を現場に |
| 返信の担当が「誰か」 | 数人いても放置される | 一人に決める |
| 人事の面談枠から送る数を決める | 現場の枠が取れず、日数が伸びる | 現場の面談枠から逆算 |
| 会社紹介から始める文面 | 知られていない会社の紹介で、「なぜあなたに」が薄い | 記述のどの行動を見たか、から |
| 大企業の型を真似て段を増やす | オファー経由の学生が段の多さで離れる | 段を短く |

最も多いのは、一つ目です。人事がいることで、現場を巻き込める規模の強みを使わずに回します。

## まとめ

- 従業員三百名規模の会社は、人事が数人いて現場を巻き込めるからこそ、「人事が全部持つ」で止まる。人事は型と台帳と返信、現場は名義と一言と面談
- 名義を職種ごとに現場の若手に置き、その若手の面談枠を先に押さえ、枠から送る数を逆算する
- 承認への返信の担当を人事の中で一人に決める。人事が数人いるなら、作業で分ける
- 知名度が中程度なら、会社紹介を一文にして採用サイトに逃がし、「なぜあなたに」と最初の年を書く。大企業の型を真似ず、段を短く
- 代行に出す範囲は、人事の週の時間の合計で決める。出すなら検索・下書き・送信・一次返信から

## よくある質問

### 人事が数人いるので、代行に出す必要はないと思っています

出す必要があるかは、人数ではなく、週に採用に使える時間の合計で決まります。数人いても、採用以外の業務があるなら、検索と送信に時間が消えて、現場との調整と面談の設定が薄くなります。時間の合計を出し、持てない作業があれば、そこだけ出します。持てるなら、返信の担当を一人に決めることだけは守ってください。

### 現場の若手に名義を頼むと、「文面を書けない」と言われます

書いてもらうのではなく、人事が下書きを渡し、「記述のここを見て、一言足してください」と頼みます。一言なら、若手の時間は短くて済み、文面には若手の言葉が残ります。面談の枠は人事が先に押さえて、若手には「この日のこの時間に出てください」と伝えます。頼むことを三つに絞れば、現場は協力します。

### 従業員三百名規模の会社のOfferBox運用は、御社に相談できますか

できます。当社は、人事と現場の線の型、名義の置き方の型、文面の型、台帳の型、検索・下書き・送信・一次返信を支えられます。名義の選定、個別の一文、面談、代行に出す範囲の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
