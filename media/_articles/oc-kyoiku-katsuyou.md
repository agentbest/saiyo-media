大手の塾・予備校、地域の塾・教室、通信教育・教育サービス・EdTech、学校法人が、新卒採用でワンキャリアを使う。教育業界のクチコミと体験談には、他の業界にない特徴がある。書いている学生の多くが、その塾や教室でアルバイト講師をした経験者で、選考の印象だけでなく、内部の実態（夕方以降の勤務、保護者対応、教室の数字、社員の様子）が濃く書かれている。学生は「教えるのが好き」で来て、企業ページで「教育への思い」を読み、クチコミで「運営と数字と保護者対応」を読んで、差で離れる。**結論から言うと、教育業界のワンキャリアは、クチコミにアルバイト講師経験者の内部の実態が書かれている前提で、隠さずに設計します。「教える仕事」か「運営・営業の仕事」かを募集で分け、夕方以降の勤務と運営の割合と保護者対応を企業ページの最初に書きます。面接で「教育への思い」を聞かず、運営の実態を伝えます。アルバイト講師からの採用とワンキャリアの位置を分け、面談とイベントの枠を授業の前の時間に固定します。学校法人は免許と独自の採用の流れの中で、ワンキャリアを補助に置きます。** この記事では、教育業界の採用構造とワンキャリアとの相性、企業ページの見せ方、選考と面接の設計、イベントとスカウトの運用設計、社内の分担を整理します。媒体の選び方は[教育業界の採用媒体の選び方](/media/hikaku-kyoiku-erabikata/)、クチコミの基本は[ワンキャリアのクチコミとは](/media/oc-kuchikomi-kihon/)で書きました。数値と料金は書きません。

## 教育業界の採用構造と、ワンキャリアとの相性

| 区分 | 採用の形 | ワンキャリアとの相性 |
|---|---|---|
| 大手の塾・予備校 | 知られている。講師と教室運営・校舎長を多く採る。アルバイト講師からの採用も多い | クチコミが多く、アルバイト経験者の内部の実態が書かれる。隠さず、扱いを添える |
| 地域の塾・教室 | 地元で知られる。少人数。体験談が少ないか、ない | アルバイト経験者の少数のクチコミが像になる。地元の学生への導線を先に |
| 通信教育・教育サービス・EdTech | 企画、営業、開発、教材制作。「教育」の像で来て、営業と企画で離れる | 「教える仕事ではない」を一行に。像とのずれを先に |
| 学校法人 | 教員免許と独自の採用の流れ。事務職員は民間と同じ | 教員は学校の流れが主。事務職員の募集を分けて書く |

| 業界の特徴 | ワンキャリアで起きること | 設計 |
|---|---|---|
| アルバイト講師経験者がクチコミを書く | 内部の実態（勤務、保護者、数字）が濃く書かれ、隠せない | 隠さず、企業ページで先に言い、扱いを添える |
| 「教える仕事」と「運営・営業の仕事」で違う | 「教えたい」で来て、運営と数字で離れ、体験談に残る | 募集を分け、運営の割合を先に |
| 面接で「教育への思い」を聞く | 像を確かめる質問で、像の体験談が残る | 聞かず、運営の実態を伝える |
| 講師と運営の若手が夕方以降に動けない | 面談とイベントの枠が取れない | 授業の前の時間に固定する |

## 企業ページの見せ方｜募集を分け、勤務の時間と運営の割合を先に

- **「教える仕事」と「運営・営業の仕事」を、募集で分ける**：「この募集は教室運営で、授業は〇〇の割合、運営と保護者対応が△△」「この募集は講師で、□□」。一つの募集で両方を書かない
- **夕方以降と土日の勤務を、最初の一文で**：「勤務は〇時から△時で、土日は□□」。数値は実態で。この記事では書かない
- **保護者対応と教室の数字を、事実として書く**：「保護者との面談は〇〇の頻度で、教室の生徒数と継続の目標は△△の決まり方」。どう扱っているかを添える
- **「教育への思い」「子どもの未来」「教える喜び」を、最初の一文から外す**：像を強める言葉。代わりに「保護者と向き合った日」「生徒が変わった日」の場面
- **アルバイト経験者のクチコミに書かれていることを、先に読む**：「持ち帰り」「保護者」「数字」が書かれているなら、隠さず、変えたことを添える。[業界イメージが不利な会社のワンキャリアの見せ方](/media/oc-gyokai-image/)
- **免許の有無を、募集ごとに一文で**：「免許は要らない」「免許は〇〇の時点で」。教育系の学部の学生が確かめている

本選考の書き方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

### エージェントベストの見解

これは数字の読み方の話です。塾や教育サービスの会社から、「クチコミに内部のことが細かく書かれていて、他の業界より厳しい」と相談されることがあります。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、教育業界のクチコミが細かいのは、書いている学生の多くがその塾や教室でアルバイト講師をした経験者で、選考の印象だけでなく、夕方以降の勤務、保護者対応、教室の数字、社員の帰る時間を、内部から見ているからです。当社がお願いしているのは、クチコミの細かさを「厳しい」と読まず、「隠せない業界である」と読むことです。アルバイト経験者が書く実態は、企業ページで否定できず、隠すと「隠していた」と残ります。企業ページが実態を先に言い、どう扱っているかを添えると、クチコミは「書いてあったとおり」の裏付けになります。

## 選考と面接を、像を確かめない形に

- **面接で「なぜ教育か」「教育への思い」を聞かない**：像を確かめる質問は、像の体験談を作る。代わりに「人に教えて変えた・続けた経験」「場を運営した・保護者や大人と向き合った経験」を聞く
- **面接で、夕方以降の勤務と運営の割合と保護者対応を伝える**：伝えたことは体験談に「聞いた」と残る
- **教える仕事と運営の仕事で、面接官と聞くことを分ける**：運営の募集に、講師の面接官だけを出さない
- **アルバイト講師からの採用と、ワンキャリアからの採用を、選考で分ける**：アルバイト経験者は実態を知っている。同じ選考で「教育への思い」を聞くと、経験者には空疎に、未経験者には像に
- **面接官に、アルバイト経験者のクチコミを読ませる**：内部からどう見えているかを面接官が知る。[ワンキャリアのクチコミを面接官教育に使う方法](/media/oc-kuchikomi-mensetsukan/)
- **選考で離れた学生の体験談を読む**：[ワンキャリア経由の学生が選考で離脱するときの原因](/media/oc-senkou-ridatsu/)

## イベントとスカウトの設計｜授業の前の時間に

- **イベントと面談の枠を、授業の前の時間（平日の昼から夕方の前）に固定する**：講師と運営の若手は夕方以降に動けない。学生の授業の時間と重なるなら、オンラインの短い回を
- **登壇は、教室運営の若手**：「保護者との面談で〇〇と言われた日」「教室の数字を初めて任された日」。「教える喜び」ではなく運営の場面
- **アルバイト講師の学生がイベントに来たら、別の枠で**：実態を知っている学生に「教育への思い」の回を見せない
- **スカウトは、教える仕事か運営かを最初に**：「教室運営の募集で、授業は〇〇の割合、勤務は△時から。あなたの□□（ガクチカ）を読んで」。「教育に興味」「子どもが好き」で絞らない
- **絞るのは、運営なら「場を運営した・保護者や大人と向き合った・数字を追った」、講師なら「人に教えて変えた・続けた」のガクチカ**：[ワンキャリアの学生のガクチカを読んでスカウトを送る方法](/media/oc-scout-gakuchika/)
- **地域の塾は、地元の学生への導線を先に**：[ワンキャリアで地方の学生にスカウトを送る方法](/media/oc-scout-chihou/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 教える仕事か運営の仕事かの一行と、免許の有無の整理 | 経営と人事（学校法人なら管理職） |
| アルバイト経験者のクチコミを読み、書かれている実態を分ける | 人事と教室の責任者 |
| 募集を分け、勤務の時間・運営の割合・保護者対応を先に書く | 人事。教室運営の若手と責任者が確認 |
| 面接で「教育への思い」を聞かず、運営の実態を伝える | 面接官 |
| アルバイト講師からの採用とワンキャリアからの採用を選考で分ける | 人事と教室の責任者 |
| イベントと面談の枠を授業の前の時間に固定する | 人事と教室の責任者 |
| イベントで教室運営の若手が話す | 入社してまもない運営の若手 |
| スカウトを教える・運営で分け、ガクチカで絞る | 送る人 |

運用代行や代理店が支えられるのは、クチコミの読み方の型、募集を分ける型、企業ページの型、面接の設計の型、イベントの型、スカウトの型と絞る作業までで、教える・運営の一行の中身、勤務と保護者対応の実態の開示、面接で伝えること、アルバイト採用との分け方、若手が話すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは発注側の誤解の話です。塾や教育サービスの会社から、「面接では『教育への思い』を聞いて、思いの強い学生を採りたい」と相談されることがあります。当社は、それを面接の中心にしません。ワンキャリアの学生は、面接で聞かれたことを体験談に書き、翌年の学生はそれを読んで「教育への思い」を用意して来ます。思いの強さで採った学生は、教室運営の数字と保護者対応で「思いと違う」と離れ、その体験談が「思いを語らせて、運営だった」として残ります。当社がお願いするのは、面接で思いを聞かず、「場を運営した経験」「保護者や大人と向き合った経験」「人に教えて続けた経験」を場面で聞き、夕方以降の勤務と運営の割合を面接で伝えることです。思いを聞かない面接の体験談が、翌年の像を「実態を聞かれる会社」に変えます。

## まとめ

- 教育業界のクチコミは、アルバイト講師経験者が書くので、内部の実態（夕方以降の勤務、保護者対応、教室の数字）が他の業界より濃く書かれ、隠せない。「厳しい」ではなく「隠せない業界」と読み、企業ページで先に言って扱いを添える
- 「教える仕事」か「運営・営業の仕事」かを募集で分け、勤務の時間と運営の割合と保護者対応を最初の一文に。「教育への思い」「教える喜び」で埋めない。免許の有無を募集ごとに
- 面接で「教育への思い」を聞かず、「場を運営した・保護者と向き合った・教えて続けた」経験を場面で聞き、運営の実態を伝える。アルバイト講師からの採用とワンキャリアからの採用を選考で分ける
- イベントと面談の枠は、講師と運営の若手が動ける授業の前の時間に固定。登壇は教室運営の若手が「保護者との面談の日」を本人の言葉で
- スカウトは教える・運営を最初に、「教育に興味」ではなくガクチカで絞る。地域の塾は地元の学生への導線を先に。学校法人は免許と独自の流れの中で補助に

## よくある質問

### クチコミに内部のことが細かく書かれていて、他の業界より厳しく感じます

書いている学生の多くがアルバイト講師の経験者で、内部から見た実態を書いているからです。他の業界の学生が選考でしか会社を見ないのに対し、教育の学生は入社前に内部を見ています。「厳しい」ではなく「隠せない業界」と読み、企業ページで勤務の時間と保護者対応と数字を先に言い、どう扱っているかを添えると、クチコミは「書いてあったとおり」の裏付けになります。

### 面接で「教育への思い」を聞いてはいけませんか

聞くと、体験談に残り、翌年の学生が思いを用意して来ます。思いの強さは、教室運営の数字と保護者対応で残るかを示さず、思いで採った学生の「運営だった」という体験談が翌年の像になります。「場を運営した・保護者や大人と向き合った・人に教えて続けた」経験を場面で聞き、夕方以降の勤務と運営の割合を面接で伝えて、それでも来るかを見ます。

### 教育業界のワンキャリアの設計は、御社に相談できますか

できます。当社は、クチコミの読み方の型、募集を分ける型、企業ページの型、面接の設計の型、イベントの型、スカウトの型と絞る作業を支えられます。教える・運営の一行の中身、勤務と保護者対応の実態の開示、面接で伝えること、アルバイト採用との分け方、若手が話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
