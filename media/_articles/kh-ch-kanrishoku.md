事業が伸びて、現場をまとめる人が足りなくなる。社内から引き上げる人もいない。そうして管理職の中途採用を始める会社は多くあります。ただ、管理職の採用は一般の職種よりも判断が難しく、入社後に「思っていた人と違った」となると、組織への影響も大きくなります。**結論から言うと、管理職の中途採用は、肩書きや部下の人数ではなく「入社後に何を変えてほしいか」から要件を作り、選考に経営者と現場の両方の視点を入れることが基本です。** この記事では、要件の作り方、選考の組み方、条件の扱いを順に整理します。

## 要件は「何を変えてほしいか」から作る

管理職の求人では、「部長経験」「部下を何人か率いた経験」といった肩書きや規模で要件を書きがちです。しかし、同じ部長でも、組織を立ち上げた人と、整った組織を引き継いで回した人では、得意なことが違います。

要件を作る前に、次の問いに答えてみます。

1. **入社後に変えてほしいことは何か**：売上を伸ばす仕組みを作る、離職が続く組織を立て直す、属人化した業務を整える、など
2. **今その役割を誰が担っているか**：代表が兼務しているのか、空席なのか、前任者がいたのか
3. **任せる範囲と任せない範囲**：予算・採用・評価のどこまでを任せるか。経営者が持ち続けることは何か
4. **最初に向き合う課題**：入社直後に、どんな状況の組織を受け持つことになるか

この四つが決まると、求める経験の中身が具体になります。「離職が続く組織を立て直す」なら、組織の立て直しの経験と、部下との対話の進め方を見る。「属人化した業務を整える」なら、仕組みを作った経験を見る。肩書きではなく、変えた経験で要件を書くと、候補者にも自社が何を求めているかが伝わります。

## 任せる範囲を書いておく

管理職の採用で、入社後のずれの原因になりやすいのが、任せる範囲の認識の違いです。候補者は「部長として採用された」と思っていても、実際には予算も採用も経営者が決めていて、何も変えられないと感じることがあります。

任せる範囲は、次の項目で書いておきます。

| 項目 | 任せる | 相談して決める | 経営者が持つ |
|---|---|---|---|
| 部署の目標 | | ○ | |
| 予算の使い方 | ○ | | |
| 部下の採用 | | ○ | |
| 部下の評価 | ○ | | |
| 組織の変更 | | | ○ |

表の中身は会社によって違います。大切なのは、面接の前に経営者がこの表を書いておくことです。書いてみると、経営者自身が任せたい範囲を決めきれていないことに気づくことがあります。その場合は、採用を進める前に、任せる範囲を決めるところから始めます。

### エージェントベストの見解

管理職の採用で相談を受けて多いのは、「大きな会社で部長をしていた人なら、うちでも組織をまとめられるはず」という思い込みです。実際には、大きな会社の管理職は、人事や経理、仕組みの整備を他の部署に頼れる環境で成果を出していることが多く、小さな会社では自分で手を動かす範囲が大きく広がります。当社は媒体で採る支援と人材紹介の両方をしていますが、両側から見ていて、入社後に続く管理職に共通するのは、肩書きの大きさではなく「仕組みがないところで自分で作った経験」です。面接では、前職で使っていた仕組みを誰が作ったかを聞いてください。自分で作ったのか、すでにあったのかで、自社で任せられる範囲が見えてきます。

## 選考の組み方｜経営者と現場の両方を入れる

管理職の選考では、経営者だけで判断しないことを勧めます。管理職は経営者と現場の間に立つ役割なので、両方の視点で見る必要があります。

選考の流れの例を挙げます。

1. **一次（人事または事業の責任者）**：経歴の事実、変えた経験の中身、転職の理由
2. **二次（経営者）**：会社の方向と本人の考えの一致、任せる範囲の認識のすり合わせ
3. **現場との面談（将来の部下や同僚）**：一緒に働く人と話す場。選考ではなく、相互に知る場として
4. **最終（経営者）**：条件の確定、入社の意思

3つ目の現場との面談は、省かれやすい回です。ただ、管理職は入社後に部下と日々向き合うので、部下となる人がどう感じるかは、入社後の立ち上がりを大きく左右します。候補者にとっても、どんな人たちと働くのかを知る機会になります。選考の場ではなく、相互に知る場として設けると、候補者も構えずに話せます。

課題を出す選考を入れる会社もあります。たとえば、自社の組織の状況を説明し、最初の時期にどう進めるかを考えてもらう形です。課題の出し方と扱い方は[課題選考の進め方](/media/kh-ms-kadai-senkou/)に整理しています。

## 条件の扱い｜早めに幅を伝える

管理職の採用では、条件の話が選考の早い段階で出ます。候補者は現職での立場と待遇があるので、条件の幅が見えないまま選考を進めることを避けたがります。

次の点を、一次の段階で伝えられるように準備しておきます。

- **年収の幅**：社内の管理職とのバランスを考えた幅
- **役職と権限**：入社時の役職と、任せる範囲
- **評価の仕組み**：何で評価され、どう見直されるか
- **入社の時期**：現職の引き継ぎにかかる期間を見込んで、いつ頃を想定しているか

年収の幅を決めるときは、既存の社員とのバランスを先に確かめます。社内の管理職より高い年収で迎える場合、その理由を社内に説明できるかを考えておきます。条件の示し方は[条件の提示の仕方](/media/kh-ms-jouken-teiji/)でも整理しています。

管理職の採用では、紹介や媒体のスカウトなど、企業から声をかける手段が中心になることが多くあります。管理職の候補者は現職で忙しく、自分から求人を探していないことがあるからです。媒体を使う場合は、ワンキャリアやGreenのようにスカウトの機能がある媒体で、変えてほしいことを具体に書いた文面を送ると、候補者が自分ごととして読みやすくなります。

## よくある差｜会社の規模と採る理由で変わること

管理職の採用は、会社の規模と採る理由で進め方が変わります。

- **社員数が少ない会社**：管理職といっても、自分で手を動かす範囲が大きくなります。プレイヤーとしての仕事と、まとめる仕事の割合を求人で伝えます
- **組織が大きくなってきた会社**：部署の仕組みを作る役割が中心になります。仕組みを作った経験を見ます
- **後継や幹部候補として採る場合**：経営者との相性と、会社の方向への共感の比重が上がります。選考に時間をかけ、経営者と話す回を増やすこともあります
- **前任者の後任として採る場合**：前任者のやり方を引き継ぐのか、変えてほしいのかを先に決めておきます

### エージェントベストの見解

管理職の採用を始める前に、経営者にお願いしていることがあります。それは、入社した管理職に「最初の時期に変えてほしくないこと」を書き出しておくことです。変えてほしいことはたくさん出てきますが、変えてほしくないことは、聞かれないと言葉になりません。たとえば、顧客との付き合い方、社内の会議の形、創業から続けている習慣など。入社した管理職が良かれと思って変えたことが、経営者や古くからの社員との摩擦になる。そういう流れで早期に離れる管理職は少なくありません。変えてほしいことと変えてほしくないことの両方を、面接の場で率直に伝える。それが、管理職の採用で入社後のずれを減らす、最も手間のかからない準備です。

## まとめ

- 管理職の要件は、肩書きや部下の人数ではなく「入社後に何を変えてほしいか」から作る
- 任せる範囲と経営者が持つ範囲を、面接の前に表にしておく
- 選考には経営者と現場の両方の視点を入れ、将来の部下と話す場を設ける
- 年収の幅、役職と権限、評価、入社の時期は、一次の段階で伝えられるように準備する
- 変えてほしいことと変えてほしくないことの両方を、面接で率直に伝える

## よくある質問

### 管理職の候補者が、現職の都合で入社の時期を遅らせたいと言っています

管理職は現職の引き継ぎに時間がかかることが多く、入社の時期が延びるのは珍しくありません。自社がいつまでなら待てるかを先に決め、その範囲で調整します。待つ間の連絡の取り方は[複数内定を持つ候補者への向き合い方](/media/kh-ch-fukusuu-naitei/)も参考になります。

### 管理職の面接で、過去の実績はどこまで信じてよいですか

実績は、本人の役割と、そのときの環境を分けて聞きます。チームの成果を自分の成果として話していないか、何を自分で決めたかを具体的に聞くと見えてきます。必要に応じて、本人の同意を得たうえでの[リファレンスチェック](/media/kh-ms-reference-check/)を入れる会社もあります。

### 社内から管理職を引き上げるのと、外から採るのはどちらがよいですか

どちらにも良さがあります。社内の人は会社をよく知っていて、外から採る人は別のやり方を持ち込めます。入社後に変えてほしいことが、今のやり方の延長にあるなら社内から、今のやり方を変えることなら外から、という考え方が一つの目安になります。
