デバイスメーカー、製造受託、製造装置、材料、設計・IP、後工程、新設の工場を持つ会社が、新卒採用でワンキャリアを使う。半導体は、工場の新設で採用が急に増えた会社と、装置・材料の会社に、ワンキャリアの体験談が少ないか、ない。学生は「半導体＝チップを作る会社」の像しか持たず、電機・IT・外資の体験談で「理系の選考」の像を作って、半導体の企業ページをその像で読む。「成長産業」「社会を支える」で内定を出した学生は、新しい工場で教える人がいない実態と、地方の勤務地とクリーンルームと交代制を知って離れ、体験談に「教育がなかった」「地方だった」と残る。**結論から言うと、半導体のワンキャリアは、体験談の少なさを「知られていない」の数として読み、他社（電機、IT、外資）の体験談と並べて読まれる前提で、企業ページに「装置・材料・デバイス・製造・設計のどれで、どの工程を担い、他にできる会社が少ないか」を先に書きます。急に増えた採用の中の教育の実態（誰が教えるか、型があるか、最初の年に何をするか）を隠さず書き、「成長産業」で埋めません。面接で「なぜ半導体か」を聞かず、内定前に工場と教える人を見せ、今年の選考で最初の体験談を作ります。** この記事では、半導体業界の採用構造とワンキャリアとの相性、企業ページの見せ方、教育の実態の開示、選考と内定後の設計、イベントとスカウトの運用設計、社内の分担を整理します。媒体の選び方は[半導体業界の採用媒体の選び方](/media/hikaku-handoutai-erabikata/)、知名度の扱いは[知名度がない会社がワンキャリアで学生に届くには](/media/oc-chimeido/)で書きました。数値と料金は書きません。

## 半導体業界の採用構造と、ワンキャリアとの相性

| 区分 | 採用の形 | ワンキャリアとの相性 |
|---|---|---|
| デバイスメーカー、製造受託（大手） | 知られ始めている。工場の新設で多く採る。体験談が少ない | 他社の体験談で像を作られる前提で、工場と教育の実態を先に |
| 製造装置、材料 | 業界内では知られ、学生には「半導体」としか見えない。体験談がない | 会社の種類と工程で候補に入れる。最初の体験談を今年作る |
| 設計・IP | 情報系はIT企業と外資と比べる | 「この工程でしかできないこと」と開発の環境で |
| 新設の工場、後工程 | 地元で採る。教える人が少ない。体験談がない | 教育の実態と地元の学生への導線を先に |

| 業界の特徴 | ワンキャリアで起きること | 設計 |
|---|---|---|
| 体験談が少ないか、ない | 電機・IT・外資の体験談で像を作られ、その像で読まれる | 他社の体験談と並べて読まれる前提で、違いを先に |
| 「半導体＝チップ」の像で、会社の種類が見えない | 装置・材料が候補に入らない | 会社の種類と工程を一行に |
| 採用が急に増え、教える人が足りない | 「教育がなかった」が最初の体験談になる | 教育の実態を隠さず、内定前に教える人を見せる |
| 地方の工場、クリーンルーム、交代制 | 「成長産業」で来て、勤務の形で離れる | 勤務地と勤務の形を最初に |

## 企業ページの見せ方｜他社の体験談と並べて読まれる前提で、種類と工程と教育を先に

- **会社の種類と工程を、最初の一文で**：「当社は〇〇の工程の△△を作る装置メーカーで、この工程は□□社しかできない」。「半導体」「成長産業」の一語で済ませない
- **他にできる会社が少ないことを、事実で**：「この工程を担う会社は、世界で〇〇」。比べられている相手（電機、IT、外資）との違いとして
- **教育の実態を、隠さず**：「新しい工場で、教えるのは〇〇の経験者△△人、型は□□、最初の年は〇〇」。数値は実態で。この記事では書かない
- **勤務地とクリーンルームと交代制を、最初に**：「工場は〇〇にあり、クリーンルームで、交代制は△△」
- **研究の距離を、工程で**：「あなたの〇〇の研究は、この工程の△△につながる」。技術者の名義で
- **他社の体験談を、自社の企業ページの前提として読む**：電機・IT・外資の体験談で学生が持つ像（選考の回数、開発の環境、報酬）を知り、自社の違いを書く。[ワンキャリアで競合企業のクチコミを読む方法](/media/oc-kuchikomi-kyousou/)

本選考の書き方は[ワンキャリアで本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

### エージェントベストの見解

これは数字の読み方の話です。半導体の会社から、「体験談が少ないのは、まだ知られていないからで、時間が解決する」と言われることがあります。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、体験談が少ない会社の企業ページは、学生が何も知らずに読むのではなく、電機・IT・外資の体験談で作った「理系の選考」の像（選考の回数、開発の環境、報酬、配属）で読まれます。体験談の少なさは「像がない」ではなく「他社の像で読まれる」の数です。当社がお願いしているのは、他社の体験談を自社の企業ページの前提として先に読み、学生がどの像で自社を読むかを知ったうえで、「電機と違い、当社は〇〇の工程を担い、IT企業と違い、△△を作る」と違いを企業ページの最初に書き、今年の選考で最初の体験談を作ることです。時間は、他社の像で読まれる年を増やすだけで、自社の像を作りません。

## 教育の実態を、隠さず先に

- **急に増えた採用の中で、誰が教えるかを、決めてから書く**：経験者の数、教える型、最初の年の仕事。決まっていないなら、決まっていないと書く
- **「教育がなかった」が最初の体験談になる形を、避ける**：新しい工場の最初の年の学生が書く体験談が、翌年の像になる
- **内定前に、工場と教える人を見せる**：クリーンルーム、交代制、教える人との時間。「成長産業」ではなく実態で残す
- **最初の年の学生が「教育がどうだったか」を書く前提で、最初の年を設計する**：体験談は今年の最初の年でしか変えられない

体験談の影響は[ワンキャリアの選考体験談が採用に与える影響](/media/oc-kuchikomi-senkou-taikendan/)で書きました。

## 選考と面接を、像を確かめない形に

- **面接で「なぜ半導体か」「成長産業への思いは」を聞かない**：像を確かめる質問は、像の体験談を作る。理系には「研究の内容と、何を続けたか」「〇〇の工程につながる部分」を、情報系には「動くものを作った経験」を聞く
- **面接で、会社の種類と工程と勤務の形と教育の実態を伝える**：伝えたことは体験談に「聞いた」と残る
- **面接で、比べられている相手との違いを本人の言葉で**：「電機やITと比べているなら、当社の違いは〇〇」。技術者が面接に入る
- **面接官に、他社の体験談を読ませる**：学生がどの像で来るかを面接官が知る。[ワンキャリアのクチコミを面接官教育に使う方法](/media/oc-kuchikomi-mensetsukan/)
- **取り合いの相手の結果で辞退されるのは、前提**：内定前に工場と教える人を見せ、残った内定者が「なぜ残ったか」を書く設計に。[ワンキャリア経由の内定辞退が続くときの見直し](/media/oc-naitei-jitai/)

## イベントとスカウトの設計

- **イベントは、技術者が「工程の一日」と「立ち上げの日」を話す**：「〇〇の工程が初めて流れた日」。「社会を支える」ではなく場面
- **新しい工場の若手が、教育の実態と地方の暮らしを話す**：「教えてくれたのは〇〇で、最初の年は△△」。本人の言葉で
- **スカウトは、会社の種類と工程と他にできる会社が少ないことを最初に**：「〇〇の工程の△△を作る会社で、この工程は□□社しかできない。あなたの〇〇の研究はこの工程につながる」。「半導体に興味」で絞らない
- **理系は専攻と研究の内容で絞り、推薦で会った学生に送らない**：[ワンキャリアで理系学生にスカウトを送る方法](/media/oc-scout-rikei/)
- **新設の工場は、地元の学生への導線を先に**：[ワンキャリアで地方の学生にスカウトを送る方法](/media/oc-scout-chihou/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 会社の種類と工程の一行と、他にできる会社が少ないことの整理 | 経営と技術の責任者 |
| 教育の実態（誰が、型、最初の年）を決める | 工場の責任者と人事 |
| 他社の体験談を読み、学生が持つ像と自社の違いを書き出す | 人事と技術の責任者 |
| 企業ページの最初に種類と工程と違い、勤務の形、教育の実態を書く | 人事。技術の若手が確認 |
| 面接で「なぜ半導体か」を聞かず、違いと教育を伝える。技術者が面接に入る | 面接官と技術者 |
| 内定前に工場と教える人を見せる | 人事と工場の責任者 |
| イベントで技術者と新しい工場の若手が話す | 入社してまもない技術者 |
| スカウトを種類と工程を最初に、研究の内容で絞る | 送る人（研究の内容の読み込みは技術者が支える） |

### エージェントベストの見解

これは契約後に起きることの話です。半導体の会社が、「成長産業」「世界と戦う」で企業ページを作って内定を出し、新しい工場で最初の年を迎えた学生が、教える人がいないことと地方の勤務地とクリーンルームの交代制で離れ、最初の体験談に「教育がなかった」「地方だった」と書く、という形を、当社は見ています。体験談がなかった会社の最初の体験談がこれになると、翌年の学生は電機・IT・外資の像に「教育がなかった会社」の像を足して読みます。当社がお願いするのは、教育の実態（誰が教えるか、型、最初の年）を採用の前に決めて企業ページに書き、内定前に工場と教える人を見せ、最初の年の学生が「教育がどうだったか」を書く前提で最初の年を設計することです。最初の体験談に「教えてくれる人がいた」「書いてあったとおりだった」と残ると、体験談がなかった会社が「自社の像」を持ち、翌年の学生は他社の像ではなく自社の体験談で読みます。

## まとめ

- 半導体業界は、採用が急に増えた会社と装置・材料の会社に体験談が少なく、学生は電機・IT・外資の体験談で「理系の選考」の像を作って読む。体験談の少なさは「像がない」ではなく「他社の像で読まれる」の数
- 他社の体験談を自社の企業ページの前提として先に読み、「装置・材料・デバイス・製造・設計のどれで、どの工程を担い、他にできる会社が少ないか」と違いを企業ページの最初に。「成長産業」「社会を支える」で埋めない
- 急に増えた採用の中の教育の実態（誰が教えるか、型、最初の年）を決めてから書き、隠さない。「教育がなかった」が最初の体験談になる形を避け、最初の年の学生が書く前提で最初の年を設計する
- 面接で「なぜ半導体か」を聞かず、研究の内容と工程のつながりを聞き、違いと教育と勤務の形を伝える。技術者が面接に入り、内定前に工場と教える人を見せる
- イベントは技術者が「立ち上げの日」を、新しい工場の若手が教育と暮らしを本人の言葉で。スカウトは種類と工程と他にできる会社が少ないことを最初に、研究の内容で絞り、推薦で会った学生に送らない

## よくある質問

### 体験談が少ないのは、知られていないからで、時間が解決しますか

時間は、他社の像で読まれる年を増やすだけで、自社の像を作りません。体験談が少ない企業ページは、電機・IT・外資の体験談で学生が作った像で読まれます。他社の体験談を先に読み、学生がどの像で自社を読むかを知って違いを企業ページの最初に書き、今年の選考と最初の年で最初の体験談を作ります。最初の体験談が「教えてくれる人がいた」になるか「教育がなかった」になるかが、翌年の像を決めます。

### 新しい工場で、教える人が足りません

足りない実態を、採用の前に決めて書きます。「教えるのは〇〇の経験者△△人で、型は□□、最初の年は〇〇」と企業ページに書き、内定前に教える人と会わせます。「成長産業」で集めて教える人がいない最初の年を迎えると、最初の体験談に「教育がなかった」と残り、翌年の学生が最初に読みます。決まっていないなら「〇〇は決まっていて、△△は今年決める」と書きます。

### 半導体業界のワンキャリアの設計は、御社に相談できますか

できます。当社は、他社の体験談の読み方の型、企業ページの型、教育の実態の整理の型、選考の設計の型、内定後の設計の型、イベントの型、スカウトの型と絞る作業を支えられます。種類と工程の中身、違いの一文、教育の実態の決定と開示、面接で伝えること、内定前に見せる工場、若手が話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
