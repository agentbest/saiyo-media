Wantedlyと、OfferBoxやワンキャリアやナビサイトを併用している。来年の採用予算をどう配分するか、上司に説明を求められる。ところが、媒体ごとの費用を並べて割り振っても、翌年に「Wantedlyの記事を書く時間がなくて止まった」という形で崩れることが多くあります。**結論から言うと、予算は「費用」と「担当の時間」の二つで置きます。Wantedlyは、費用よりも担当の時間の側が大きい媒体なので、費用だけで配分すると回りません。配分は、採る人数と「こんな人」を決め、担当の時間を先に出し、回っている入口に寄せ、費用は各媒体の現在の条件を確認して置き、見直しは契約の切れ目で行います。** この記事では、予算の二つの側、媒体ごとの費用と時間の性格、配分の手順、Wantedlyの予算の置き方、やりがちな失敗、社内の分担を整理します。母集団形成全体の予算は[母集団形成の予算配分](/media/kh-boshudan-yosan/)、効果の並べ方は[Wantedlyを含む複数媒体の効果を並べて見る方法](/media/wt-heiyou-heiyou-kpi/)で書きました。費用の数値は、この記事では書きません。

## それぞれの役割｜予算は「費用」と「担当の時間」の二つで置く

採用の予算を「媒体の費用の合計」で置くと、時間の予算が抜けます。媒体は、契約しただけでは動きません。文面を書く、記事を書く、返信する、面談に出る。この時間を誰がどれだけ出すかが、費用と同じだけ予算です。

| 媒体の型 | 費用の性格 | 時間の性格 |
|---|---|---|
| Wantedly | プランに応じた費用。現在の条件は公式ページで確認 | 会社ページ・ストーリー・募集記事を書く時間、返信と面談の時間。通年で薄く続く |
| スカウト型（OfferBoxなど） | プランや通数の枠に応じた費用。公式ページで確認 | 検索と文面を書く時間、送る時間、返信対応。送る時期に集中する |
| ワンキャリア | 掲載やイベントに応じた費用。公式ページで確認 | 掲載情報の整備、イベントの準備と当日、エントリー対応。時期に集中する |
| ナビサイト | 掲載の枠と期間に応じた費用。各媒体で確認 | 入力、エントリー対応、説明会の運営。開始から締切に集中する |

費用は媒体側の条件で決まり、時間は自社の体制で決まります。Wantedlyは、この表の中で「費用に対して時間の比率が大きい」媒体です。会社ページとストーリーは、自社の社員が話し、自社の言葉で書くものなので、外に出しにくい時間です。

## 併用するときの分担｜配分の手順

1. **採る人数と「こんな人」を先に決める**：職種ごとに、何人を、どんな人で。これがないと、どの媒体に寄せるかが決まらない
2. **担当の時間を先に出す**：人事が何人で、週に何時間を採用に使えるか。現場の社員が、面談とストーリーにどれだけ出られるか。この時間の中に、媒体の運用が収まるかを見る
3. **回っている入口を確認する**：昨年の台帳で、「こんな人」に近い人が面談まで来た入口はどれか。回っている入口に、時間と費用を寄せる
4. **費用は、各媒体の公式ページで現在の条件を確認して置く**：昨年の請求額をそのまま使わない。プランと条件は変わる
5. **時間が足りない媒体は、費用を下げるか、外に出すかを決める**：時間が出せないのに費用だけ置くと、契約して止まる
6. **見直しは、契約の切れ目で行う**：途中の月に「効かない」で止めない。切れ目までは、止まっている段を直す

媒体を何本持つかは、予算ではなく担当の時間で決めます。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)で書いた考え方と同じです。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは費用が小さいので、他の媒体に足しても負担にならない」というものです。当社は3媒体すべての販売パートナーとして、予算の配分の相談を受けますが、Wantedlyを「費用の小さい追加」として足した会社は、翌年に「記事を書く時間がなくて、会社ページが一年前のまま」という状態で止まっています。費用の予算は通っても、時間の予算が通っていなかったからです。Wantedlyの予算を置くときは、費用の欄と別に、「月に一度、会社ページとストーリーを見直す時間」と「ストーリーに出る社員の時間」を、担当者の予定の欄に書きます。その時間が出せないなら、Wantedlyの費用を置く前に、時間を出せる媒体に寄せるか、時間を作る側の相談をするのが順番です。費用の小ささで足すと、時間の側で止まります。

## Wantedlyの予算の置き方｜時間の側を先に書く

| 項目 | 置き方 |
|---|---|
| プランの費用 | 公式ページで現在の条件を確認。年の途中で変えないなら、年額で一つ |
| 会社ページとストーリーの時間 | 人事の時間と、話す社員の時間。月単位で予定に固定 |
| 募集記事の時間 | 職種ごとに一本。書き直しの時間を含める |
| 返信と面談の時間 | 「話を聞きに行きたい」への返信、面談に出る人の時間 |
| 外に出せる部分 | 記事の型、台帳の型、スカウトの文面の型。話す中身は出せない |
| 資産として残るもの | 記事と会社ページ。翌年の予算の元 |

- **時間の側を、費用の側より先に書く**：時間が出せるかで、プランを決める
- **話す社員の時間は、現場の責任者と合意してから置く**：人事だけで置くと、現場が出られず止まる
- **資産を予算の説明に入れる**：記事は翌年も残るので、一年で回収する前提で置かない
- **他の媒体の時期と、時間の要る時期をずらす**：スカウト型やナビの時期に、Wantedlyの更新時間が消えないよう、月に一度を固定

時間が足りないときの直し方は[Wantedlyの運用に工数が足りないとき](/media/wt-kousuu/)で書きました。

## 複数媒体で配分するときの考え方

- **回っている入口を先に埋める**：昨年、近い人が面談まで来た入口に、時間と費用を先に置く。新しい媒体は、余った時間で
- **時期が重なる媒体を、同じ担当者に置かない**：スカウト型の送る時期と、ナビの時期が重なると、一人では回らない。Wantedlyは通年なので、重なりの外に置ける
- **一つの入口に寄せすぎない**：一つの媒体が止まると、採用が止まる。二つ目の入口は、時間の範囲で持つ
- **「一人あたりの費用」で配分しない**：単価は、時期と人数で大きく変わる。一年の台帳が揃ってから、参考として見る。[媒体別の採用単価の見方](/media/hikaku-baitai-tanka/)
- **やめる判断は、配分の場ではなく、契約の切れ目で**：[媒体をやめる判断基準](/media/hikaku-baitai-tettai/)

3媒体の役割は違います。スカウト型は企業から送り、ワンキャリアは学生が情報とクチコミで来て、Wantedlyは会社を読んで来ます。役割が違う媒体を、費用の大小で並べて削ると、来る人の状態が偏ります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 費用の合計だけで予算を組む | 時間が出せない媒体が、契約したまま止まる | 時間の欄を先に書く |
| 昨年の請求額をそのまま置く | プランや条件が変わっていて、ずれる | 公式ページで現在の条件を確認 |
| Wantedlyを「安い追加」として足す | 記事を書く時間がなく、会社ページが古いまま | 時間の予算を通してから足す |
| 途中の月の数字で配分を変える | 時期の偏りで、回っていた入口を削る | 見直しは契約の切れ目で |
| 話す社員の時間を、人事だけで置く | 現場が出られず、ストーリーが止まる | 現場の責任者と合意してから |

最も多いのは、三つ目です。Wantedlyの費用が通ったことで安心し、時間の予算が通っていないことに、契約のあとで気づきます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 採る人数と「こんな人」を決める | 人事と現場の責任者 |
| 担当の時間を出す | 人事と、話す社員の上司 |
| 昨年の台帳から、回っている入口を確認する | 人事 |
| 各媒体の公式ページで現在の条件を確認する | 人事 |
| 時間と費用の配分の案を作る | 人事 |
| 配分の承認、契約の切れ目での見直し | 責任者 |

運用代行や代理店が支えられるのは、媒体ごとの費用と時間の性格の整理、配分の型、時間の見積もり、3媒体を並べた案の提示までで、採る人数と「こんな人」の決定、時間を出す合意、配分の承認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

同じ採用予算でも、担当者が一人で、現場の社員が採用に時間を出せない会社には、Wantedlyより先に、文面と送信の時間を外に出せるスカウト型を軸にすることを勧めることが多いです。理由は、Wantedlyの時間が、社員が話し、自社の言葉で書く時間で、外に出しにくいからです。逆に、現場の若手が話すことに前向きで、人事が月に一度の更新時間を固定できる会社には、Wantedlyに時間を寄せ、スカウト型は時期を絞る配分を勧めます。媒体の費用ではなく、「外に出せない時間を、自社で出せるか」で配分を決めると、翌年に止まりません。当社は3媒体すべてを扱っているので、どれかに寄せる理由がなく、この条件で並べて案を出せます。

## まとめ

- 予算は「費用」と「担当の時間」の二つで置く。費用は媒体側の条件、時間は自社の体制で決まる
- Wantedlyは、費用に対して時間の比率が大きい媒体。時間の欄を費用より先に書き、話す社員の時間は現場の責任者と合意してから置く
- 配分は、採る人数と「こんな人」→担当の時間→回っている入口→費用は公式ページで確認→契約の切れ目で見直し、の順
- 「一人あたりの費用」で配分しない。一年の台帳が揃ってから参考に
- 3媒体は役割が違う。費用の大小で削ると、来る人の状態が偏る

## よくある質問

### 上司に「媒体ごとの費用の一覧」で予算を出すように言われています

費用の一覧に、「担当の時間」の列を足して出します。「この媒体は、費用の他に、月に何時間の時間が要ります。その時間は誰が出します」と添えると、費用だけで削る判断を防げます。Wantedlyは、時間の列がないと、費用の小ささだけで判断されます。

### 予算が減ったとき、Wantedlyから削るべきですか

削るかどうかは、費用の大小ではなく、昨年の台帳で「こんな人」に近い人が面談まで来た入口かどうかで決めます。近い人が来ていて、記事が資産として残っているなら、削ると翌年の元がなくなります。近い人が来ていないなら、削る前に記事の側を直したかを見ます。[媒体をやめる判断基準](/media/hikaku-baitai-tettai/)

### 複数媒体の予算配分は、御社に相談できますか

できます。当社は、媒体ごとの費用と時間の性格の整理、配分の型、時間の見積もり、3媒体を並べた案の提示を支えられます。採る人数と「こんな人」の決定、時間を出す合意、配分の承認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
