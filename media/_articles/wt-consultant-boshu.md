Wantedlyでコンサルタントの募集記事を出したとき、最初にぶつかるのは「『クライアントの課題解決』『成長を支援』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『常駐はありますか』『提案の後まで関わるのですか』『案件が無いときは何をするのですか』を聞かれて答えられない」という問題です。**結論から言うと、コンサルタントの募集記事は、「課題解決」ではなく「誰の何の課題を、提案までか実行までか、常駐か持ち帰りか、案件が無い期間に何をし、売る責任があるか」を書き、募集記事を書く前に社内で領域を一つに絞り、関わる範囲と常駐の実態と案件が無い期間の扱いを決めておきます。** この記事では、コンサルタントが募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)、スカウト文面の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)で書きました。新卒のコンサルタントは[OfferBoxでコンサルタントを採るオファー文面の書き方](/media/ob-consultant-offer-bunmen/)で書きました。

## コンサルタントが募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰の、何の課題か | 顧客の業種と規模。経営の課題か、業務の課題か、仕組みの導入か。「課題解決」の一語では分からない |
| 提案までか、実行までか | 提案書を出して終わりか、実行まで一緒にやるか。実行までなら、誰が手を動かすか |
| 常駐か、持ち帰りか | 顧客先に常駐するか。期間と、自社に戻る頻度。持ち帰りなら、顧客との接点の頻度 |
| 案件が無い期間の扱い | 案件と案件の間に何をするか。給与はどうなるか。「案件が無い＝評価が下がる」か |
| 売る責任があるか | 自分で案件を取るのか。営業が取るのか。売上の数字を持つか |
| 一人で何本持つか | 一本を深くか、複数を並行か。上に誰がいて、誰が案件を決めるか |

「常駐か持ち帰りか」と「案件が無い期間の扱い」が、コンサルタントに特有の点です。「課題解決」「成長支援」の一語では、ここが分かりません。

## 書く前に決めること｜領域を一つに、関わる範囲、常駐の実態、案件が無い期間、売る責任

| 決めること | 選択肢 |
|---|---|
| 領域 | 経営／業務改善／仕組みの導入／人事・組織／財務／特定の業種。最初に任せる領域を一つ |
| 関わる範囲 | 提案まで／実行まで／実行の管理まで。実行するのは誰か |
| 常駐の実態 | 無い／ある。あるなら期間と頻度、自社に戻る日 |
| 案件が無い期間 | 何をするか（提案の準備、社内の仕組み、学習）。給与と評価はどうなるか |
| 売る責任 | 自分で取る／営業が取る／両方。売上の数字を持つか。給与に連動するか |
| 何本持つか | 一本／複数。目安。上に誰がいるか |
| 最初の月に任せること | 進行中の案件の一部か、提案の準備か、同席か。誰と組むか |

「常駐がある」「案件が無い期間は評価に響く」「売る責任がある」でも構いません。隠さずに書けば、それを前提に読む人が来ます。

## 「なにを」｜誰の何の課題を、どの形で

「なにをやっているのか」は、会社の事業の説明ではなく、このコンサルタントが最初に持つ案件の種類と、関わる形に絞ります。

- **顧客と課題を、具体に書く**：「〇〇の業種の、△△の規模の会社。□□が回っていない課題」。顧客が特定されない形で
- **関わる範囲を書く**：「提案して、実行は顧客が行い、月に一度確認する」「提案から実行まで、顧客先で一緒に手を動かす」
- **常駐の実態を書く**：「常駐は無い。週に一度顧客先に行く」「〇〇の期間は顧客先。週に△△日は自社」
- **案件の決まり方を書く**：「案件は営業が取り、責任者が誰に振るかを決める」「自分で提案して取る案件もある」

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

コンサルタントの募集記事を出す前に、先に決めておかないと効果が出ないのは、「案件が無い期間に何をして、給与と評価がどうなるか」です。当社がWantedlyのコンサルタントの募集を支えるとき、案件の内容と「課題解決力」は書かれているのに、案件と案件の間のことが書かれていない募集記事が多くあります。コンサルタントが面談で最初に聞くのは、案件の華やかさではなく、「案件が無いときは、何をして、給与はどうなりますか」です。ここに答えがないと、「案件が途切れたら評価が下がる、または自分で取ってこいと言われる仕事」を想像して離れます。案件が無い期間があっても構いません。「案件と案件の間は、提案の準備と社内の仕組みづくりをする。給与は変わらない。評価は案件の中身で見る」と書けば、それを前提に読む人が来ます。当社が最初にお願いするのは、案件の説明ではなく、責任者に「先月、案件に入っていないコンサルタントは何をしていて、評価はどうしたか」を一文で言ってもらうことです。

## 「どうやって」｜案件の流れと、常駐と、売る責任の書き方

| 書くこと | 書き方 |
|---|---|
| 案件の流れ | 誰が取り、誰が振り、提案を誰が見て、顧客に誰が出すか。「営業が取り、責任者が振る。提案は責任者が見る」 |
| 常駐の実態 | 期間、頻度、自社に戻る日。「〇〇の期間は週に△△日顧客先。それ以外は自社」 |
| 案件が無い期間 | 何をするか。給与と評価。「提案の準備と、社内の型づくり。給与は変わらない」 |
| 売る責任 | 誰が取るか。自分で取る場合の数字と、給与への連動。「営業が取る。自分で提案した案件は、評価に加える」 |
| 前の案件の例 | 「〇〇の業種の△△の課題に、□□を提案して、◇◇の期間で実行した」。顧客が特定されない形で。うまくいかなかった例も |

「裁量が大きい」と書くより、「提案の中身は自分で決め、責任者が出す前に見る。実行は顧客と一緒に」と書くほうが、仕事の実態が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| コンサル経験3年以上 | 顧客が「やりたい」と言ったことと、本当の課題が違うと分かり、提案を変えたことがある |
| 論理的思考力 | 提案が通らなかった理由を聞いて、次の提案を変えたことがある |
| 課題解決力 | 提案した後、実行が止まった理由を見つけて、動かしたことがある |
| コミュニケーション能力 | 顧客の現場の人に話を聞いて、経営者の言っていたことと違う実態を見つけたことがある |
| 即戦力 | 最初の月は〇〇の案件に同席してもらう予定です。△△と組みます |

「やりたいことと本当の課題が違うと分かり、提案を変えた」が、コンサルタントで最も読まれる行動です。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「誰の何を、どの形で、常駐か」と同じ言葉で**：相手が「誰の何の課題に、何を提案して、何が起きたか」を読み、自社の領域と重ねる。[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)
- **面談には、案件の責任者が出る**：「案件が無い期間」「常駐の実態」「提案を誰が見るか」を、責任者本人が話す
- **面談で話すのは、案件の実態の話**：最初に持つ案件の状態、常駐の実態、案件が無い期間の扱い、相手ならどう提案するかを聞く
- **うまくいかなかった案件の話をする**：「前に〇〇の案件で、提案は通ったが実行が止まった」。うまくいった話だけにしない

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 領域、関わる範囲、常駐の実態、案件が無い期間、売る責任を決める | 案件の責任者と経営者 |
| 「なにを」（顧客と課題、関わる形、常駐）の下書き | 人事が、責任者に聞いて書く |
| 「どうやって」（案件の流れ、常駐、案件が無い期間、売る責任） | 責任者が話し、人事が書き、本人が確認 |
| 前の案件の例の確認 | 責任者 |
| 「こんな人」を行動で書く、最初の月の予定 | 責任者と人事 |
| 面談 | 案件の責任者 |

一人目のコンサルタントを採る募集では、いま経営者が自分で案件を見ていることが多くあります。その場合は、「いまは経営者が全案件を見ていて、〇〇が回っていない。最初の月は△△の案件に同席。提案は経営者が見る。案件が無い期間は□□」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、常駐と案件が無い期間を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、領域の決定、案件の実態、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「コンサルタントには、案件の華やかさと成長性を見せないと来ない」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyのコンサルタントの募集と面談を見ていますが、「大手企業の経営課題」「急成長中」と書いた募集記事より、「〇〇の業種の△△の規模の会社の、□□が回っていない課題。常駐は無く週に一度顧客先。案件が無い期間は提案の準備で、給与は変わらない」と実態を書いた募集記事のほうが、話を聞きに来る人の経験が合い、面談後に離れる人が少ない傾向があります。コンサルタントは、「華やかさ」を読むと「実態を隠している」を疑い、常駐と案件が無い期間が書かれていないと「聞いていないことが後から出る」を想像します。当社が案内するのは、案件の華やかさを盛らず、常駐と案件が無い期間と売る責任を隠さず書き、うまくいかなかった案件の例を一つ添えることです。華やかさで人は来ません。実態が書かれていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「課題解決」「成長支援」で書く | 誰の何を、どの形かが分からず、読まれない | 顧客と課題と関わる形を書く |
| 常駐の実態を書かない | 面談で「聞いていない」で離れる | 有無と期間と戻る日を書く |
| 案件が無い期間の扱いを書かない | 「評価が下がる」を想像される | 何をして、給与と評価がどうなるかを書く |
| 売る責任を軽く見せる | 面談か入社後に分かり、信用を失う | 有るなら有ると、数字と連動の仕組みを書く |
| うまくいった案件だけ書く | 「実態を隠している」と疑われる | 実行が止まった例も一つ |
| 面談に責任者が出ない | 「案件が無い期間」に答えられない | 責任者が出て、実態を話す |

最も多いのは、「課題解決」と、常駐と案件が無い期間の抜けです。

## まとめ

- コンサルタントが見ているのは、誰の何の課題か・提案までか実行までか・常駐か持ち帰りか・案件が無い期間の扱い・売る責任・何本持つか・上に誰がいるか
- 書く前に、領域を一つに絞り、関わる範囲、常駐の実態、案件が無い期間に何をして給与と評価がどうなるか、売る責任を、責任者が決める。常駐があっても、隠さない
- 「なにを」は顧客と課題と関わる形と常駐。「どうやって」は案件の流れと案件が無い期間と売る責任を、実態で。うまくいかなかった案件の例も
- 「こんな人」は経歴ではなく、「やりたいことと本当の課題が違うと分かり提案を変えた」「実行が止まった理由を見つけて動かした」の行動で
- 面談には案件の責任者が出て、常駐と案件が無い期間の実態を本人の言葉で話す

## よくある質問

### 常駐が中心の会社です。正直に書くと来ませんか

隠すほうが、面談で分かって離れます。「〇〇の期間は顧客先に週に△△日。それ以外は自社。案件ごとに常駐の長さは違い、最初の案件は□□」のように、期間と頻度と戻る日を書きます。常駐を前提に働いてきた人は一定数いて、その人には「実態が書かれている会社」として読まれます。

### 案件が無い期間は、自分で案件を取ってきてほしいと思っています

そのまま書きます。「案件が無い期間は、自分で提案先を探して提案する。取れた案件は評価に加える。給与は案件の有無で変わらない」のように、期待することと、評価と給与の扱いを書きます。「売る責任がある」と読める書き方にすることで、それを前提に読む人が来ます。

### コンサルタントの募集記事は、御社に相談できますか

できます。当社は、募集記事の型、常駐と案件が無い期間を文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。領域の決定、案件の実態、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
