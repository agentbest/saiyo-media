小さな会社や、代表が採用に深く関わる会社では、スカウトを代表の名前で送ることがあります。「代表から直接連絡が来た」は、受け取る側にとって特別に見え、開かれやすくなります。ところが、代表が書いていない、代表が面談に出ない、全部の募集を代表名にして本人が回らない、という形になると、効果は消え、面談で信用を失います。**結論から言うと、代表名でスカウトを送るのは、「代表が本当に面談に出て話す募集」に限ります。代表が読んで2か所を書き、代表の時間を先に確保し、代表が面談に出る。この3つが揃わない募集は、現場社員か責任者の名前で送ります。代表の文面では、理念の再掲、会社の規模や実績の強調、上からの言葉を避けます。** この記事では、代表名の効果と落とし穴、送る条件、避けること、代表が面談に出る形、忙しくなったときの切り替え、分担を整理します。現場社員の名前で送る方法は[スカウトを現場社員の名前で送る方法](/media/wt-scout-genba/)で書きました。

## この作業の目的｜「代表と直接話せる」を、本当に提供する

代表名で送る効果は、「代表と直接話せる」という価値を、受け取る側が感じることです。この価値は、実際に代表が面談に出て話すことで初めて本物になります。

代表名で送って、面談に人事が出れば、「代表の名前は飾りだった」となります。目的は、代表名を使うことではなく、「代表と話せる」を本当に提供することです。提供できない募集には、代表名を使いません。

## 代表名の効果と、落とし穴

| 効果 | 落とし穴 |
|---|---|
| 開かれやすい。「代表から」は目に留まる | 代表が書いていないと、文面が代表の言葉でなく、面談でずれる |
| 「代表と直接話せる」が、小さな会社では価値になる | 代表が面談に出ないと、その価値が消える |
| 代表の考えに惹かれる人に届く | 代表の言葉が大きすぎる（理念・ビジョン）と、仕事の具体が無い |
| 会社の「なぜ」を代表の言葉で伝えられる | 全募集を代表名にすると、代表が回らず、返信対応と面談が止まる |
| 代表が候補者の顔を早く知れる | 代表の時間が確保されていないと、続かない |

効果は、すべて「代表が本当に書き、本当に出る」ことに依存します。名前だけでは、落とし穴だけが残ります。

## 代表名で送る条件

次の3つが揃う募集だけ、代表名で送ります。

1. **代表が面談に出られる募集**：その募集の面談に、代表が出る。週にどのくらいの枠を取れるかを先に決める
2. **代表が読んで2か所を書く**：相手のプロフィールのどこを読んだか、この募集と重なる点。人事が代わりに書かない。書き方は[スカウトを相手ごとに変える範囲](/media/wt-scout-kojinka/)
3. **代表の時間が、先に確保されている**：読んで書く枠と、面談の枠。「空いたら」にしない

3つが揃わないなら、その募集は責任者か現場社員の名前で送ります。代表名で送る募集は、多くても一つか二つに絞ります。分担の考え方は[スカウトを誰が送るか](/media/wt-scout-tantou/)で書きました。

### エージェントベストの見解

これは、向く会社と向かない会社がはっきり分かれます。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、代表名のスカウトが効くのは、「代表が採用を自分の仕事だと考えていて、週に面談の枠を取れる会社」です。多くは小さな会社で、代表が候補者と直接話すことが、会社の魅力そのものになっています。逆に、代表が採用を人事に任せている会社が、「代表名のほうが開かれるから」と名前だけ使うと、面談で人事が出て、候補者は「代表と話せると思った」と感じます。当社が代表名の相談を受けるとき、最初に聞くのは、「代表は、週に何回、面談に出られますか」です。答えが「出られない」なら、代表名は使いません。開かれることより、開いたあとに本物であることが先です。

## 代表の文面で、避けること

代表が書くと、次のことが起きやすくなります。

| 避けること | なぜ | 代わりに |
|---|---|---|
| 理念やビジョンの再掲 | 会社ページに書いてある。文面が長くなる | 会社の「なぜ」は一文で。詳しくは会社ページへ |
| 会社の規模、実績、成長の強調 | 「大きい会社です」は相手の話ではない | 相手のプロフィールのどこを読んだか、から |
| 上からの言葉（「君の力を」「うちで育てる」） | 相手が身構える | 対等な言葉。「あなたの〇〇の経験について、話を聞かせてもらえませんか」 |
| 「私が直接」の強調 | 押しつけに見える | 署名に代表と書けば足りる |
| 長い文面 | 代表の想いが長くなりがち | 3段の構成を守る。[スカウト文面の書き方](/media/wt-scout-bunmen/) |
| 募集記事に無い仕事の話 | 代表の頭の中の構想が文面に出る | 募集記事にある仕事に限る。[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/) |

「募集記事に無い仕事の話」は、代表に特有の落とし穴です。代表は、まだ募集記事に書いていない構想を持っていて、それを文面に書きます。相手は募集記事を見て「文面と違う」と感じます。

代表の文面も、人事が送る前に確認します。確認の観点は、避ける言葉と、募集記事との整合と、出してはいけない情報の3つです。

## 代表が面談に出る形

- **代表と、その職種の人の2人で出る**：代表が「なぜ」を、現場の人が「なにを」を話す。代表だけだと仕事の具体が薄くなる
- **時間は短く**：代表の枠は限られる。カジュアル面談の型を守る。[カジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **代表が話しすぎない**：相手の話を聞く時間を長く。代表は話し始めると長くなりやすい
- **聞かないことを、代表にも渡す**：志望動機、転職理由、評価のための質問。代表は経営者としての質問をしがち。[カジュアル面談で聞くこと・聞かないこと](/media/wt-scout-mendan-shitsumon/)
- **面談後の連絡は人事**：代表に頼まない

「代表が話しすぎない」と「聞かないことを渡す」は、代表が面談に出るときに特に要ります。代表は話す力があり、聞く場を説明の場に変えやすいからです。

## 代表が忙しくなったときの切り替え

代表の時間は、事業の状況で変わります。切り替えを先に決めておきます。

1. **代表の枠が取れなくなったら、その募集の送り主を責任者に切り替える**：代表名で送ったまま、面談に出ないことを避ける
2. **返信待ちの相手には、「代表に代わって〇〇が話します」と伝える**：無言で変えない
3. **面談が決まっている相手は、代表が出る**：決まった分は守る
4. **切り替えの判断は、月の見直しで**：「来月、代表は枠を取れるか」を毎月確かめる
5. **代表が戻れる時期が見えたら、また代表名に戻してよい**

代表名は、「使い続けるもの」ではなく、「代表が出られる期間に使うもの」です。

## 代表のプロフィール

送り主のプロフィールは、代表の場合も整えます。

- **代表としての肩書きだけでなく、いま自分が何をしているか**：「代表。〇〇の事業を、自分でも顧客と話しながら進めている」
- **なぜこの会社を始めたかの一文**：長くしない。詳しくは会社ページか代表のストーリーへ。書き方は[代表の考えを書く方法](/media/wt-story-daihyo/)
- **顔が分かる写真**：普段の様子
- **最近の判断の場面が書かれたストーリーがあれば、そこへ**

代表のプロフィールが「肩書きと経歴の羅列」だと、受け取る側は「偉い人からの連絡」と身構えます。「いま何をしていて、なぜ始めたか」があると、話しやすい相手に見えます。

| 作業 | 誰が |

| 代表名で送る募集を決める | 代表と人事 |
| 代表の枠（読んで書く・面談）を確保する | 代表と人事 |

| 読んで2か所を書く | 代表 |

運用代行や代理店が支えられるのは、代表名で送る募集の線引き、型、避けることの確認、代表のプロフィールの整え方、切り替えの設計までで、代表が書くこと、代表が面談に出ること、枠の確保は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

申し込んだあと、代表名のスカウトで半年後に起きやすいのは、「最初の数か月は代表が出ていたが、忙しくなって出なくなり、代表名のまま人事が面談に出ている」ことです。切り替えの判断が無いまま、名前だけが残ります。当社が半年後の運用を見ると、返信率は変わっていないのに、面談から選考に進む人が減っていることがあり、理由を聞くと「代表と話せると思って来たのに」という辞退の言葉が出てきます。当社が代表名を始めるときにお願いするのは、「代表が出られなくなったら、その月に送り主を切り替える」と先に決めておくことです。代表名は、代表の時間があるうちだけの形で、それを続ける形ではありません。切り替えを決めておけば、代表の名前も、候補者との信頼も、どちらも守れます。

## まとめ

- 代表名で送るのは「代表が本当に面談に出て話す募集」に限る。名前だけでは効果が消え、面談で信用を失う
- 条件は、代表が面談に出られる、代表が読んで2か所を書く、代表の時間が先に確保されている、の3つ。揃わなければ責任者か現場の名前で
- 代表の文面では、理念の再掲、規模や実績の強調、上からの言葉、長い文面、募集記事に無い仕事の話を避ける
- 面談は代表とその職種の人の2人で、短く、代表が話しすぎず、聞かないことを代表にも渡す
- 代表が忙しくなったら、その月に送り主を切り替え、返信待ちの相手に先に伝える。代表名は代表が出られる期間の形

## よくある質問

### 代表が「名前は使っていいが、文面は人事に任せる」と言います

その形はお勧めしません。代表が書いていない文面で返信が来て、面談で代表が文面の内容を知らないと、候補者の信頼が崩れます。代表が書く時間が無いなら、代表名ではなく責任者の名前で送り、面談に代表が同席する形にします。名前と言葉は、同じ人のものにします。

### 小さな会社で、代表しか面談に出られる人がいません

代表名で送って構いませんが、募集を一つに絞り、代表の枠で回る数だけ送ります。送る数は、代表が読んで書ける数と、面談に出られる枠から逆算します。数を増やすより、代表が本当に出られる範囲で続けるほうが、結果につながります。

### 代表名でのスカウト運用は、御社に相談できますか

できます。当社は、代表名で送る募集の線引き、型、避けることの確認、代表のプロフィールの整え方、切り替えの設計を支えられます。代表が書くこと、代表が面談に出ること、枠の確保は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
