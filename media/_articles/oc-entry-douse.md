ワンキャリアで、企業ページもイベントも整えたのに、エントリーにつながらない。この場合、各ページの中身ではなく、ページとページの「間」が切れていることが多くあります。体験談を読んだ学生が企業ページに来ない、企業ページを読んだ学生がイベントに気づかない、イベントに来た学生が次に何をすればよいか分からない。**結論から言うと、ワンキャリアの導線は、学生の動き「体験談・クチコミ→企業ページ→イベントや説明会→エントリー→選考」に沿って、各段に「次に進む一文」を置いて設計します。エントリーの入口は、企業ページとイベントページと採用サイトの三か所に置き、どこからでも同じ流れに入れるようにし、エントリー後の最初の連絡までを導線に含めます。導線が切れている場所は、段ごとの数の変化と、面接での「どこを読んで来ましたか」で見つけます。** この記事では、学生の動き、導線が切れる場所、各段に置く一文、エントリーの入口、エントリー後、切れていることに気づく方法、3媒体と採用サイトの揃え方、分担を整理します。エントリーの仕組みや入口の設定は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜学生が「次に何をすればよいか」で止まらない状態にする

学生は、体験談を読み、企業ページを見て、イベントに来て、エントリーします。各段で「次に何をすればよいか」が分からないと、そこで止まります。

導線の目的は、各段に「次はこれです」と一文があり、学生が迷わず進める状態にすることです。中身が良いページでも、次への一文が無いと、そこで終わります。

## 学生の動きと、導線が切れる場所

| 段 | 学生の動き | 切れる場所 |
|---|---|---|
| 1. 体験談・クチコミ | 選考や実態を読む | 企業ページに来ない（企業ページが薄く、読む理由が無い） |
| 2. 企業ページ | 会社の側の説明を読む | イベントに気づかない（誘導が無い）。エントリーの方法が分からない |
| 3. イベント・説明会 | 人に確かめる | 終わったあとに次が無い（連絡が無い、選択肢が無い） |
| 4. エントリー | 応募する | 方法が分かりにくい。採用サイトに飛んで迷う。書類が多くて止まる |
| 5. 選考 | 面接など | エントリー後の最初の連絡が遅い。掲載と違う |

「1から2」が最も太い切れ目です。体験談は読まれていても、企業ページが薄いと、学生は企業ページを読まずにエントリーするか、エントリーせずに終わります。企業ページの中身は[企業ページで最初に書くこと](/media/oc-kigyo-page-kihon/)で書きました。

## 各段に置く「次に進む一文」

| 段 | 置く一文 | どこに |
|---|---|---|
| 企業ページ（選考の流れの近く） | 「直接聞きたい方は、イベントへ」（いま申し込めるイベントの入口） | 選考の流れと、よく聞かれることの下 |
| 企業ページ（仕事の具体の近く） | 「この職種の話を、社員から聞ける会があります」 | 仕事の具体の下 |
| 企業ページ（末尾） | 「エントリーはこちら。流れは〇〇です」 | 末尾。選考の流れと揃えて |
| イベントページ（本文） | 「選考の流れと仕事の具体は企業ページに。読んでから来ると質問しやすいです」 | 何を話すかの下 |
| イベントページ（末尾） | 「参加後、エントリーの方法を案内します」 | 末尾 |
| イベントの当日（最後） | 「エントリーは〇〇から。今日決めなくてよい」 | 口頭と、翌日の連絡 |
| イベント後の連絡 | 「昨日はありがとうございました。エントリーはこちら。質問があればいつでも」 | 翌日 |
| エントリーの入口 | 「エントリー後、〇〇までに最初の連絡をします」 | 入口の近く |
| 採用サイト | 「ワンキャリアの企業ページで、選考の流れと働く人の話を書いています」 | 採用サイトからワンキャリアへ |

「今日決めなくてよい」の一文は、イベントの最後に要ります。無いと、学生は「決めないといけない」と感じ、来なくなります。

### エージェントベストの見解

相談で最も多い思い込みは、「エントリーが少ないのは、企業ページの内容が弱いからだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を支えていますが、企業ページの内容が整っているのにエントリーが少ない会社で、導線を追うと、企業ページのどこにもイベントとエントリーの入口が無い、イベントの翌日に連絡が無い、という「間」の切れ目が見つかります。中身を直す前に、間をつなぐと、エントリーが変わります。当社が導線の相談を受けるとき、最初にやるのは、学生の動きの5段を紙に書き、各段の下に「次に進む一文」があるかを一つずつ確かめることです。無い段が、切れている段です。中身は、そのあとです。

## エントリーの入口の置き方

エントリーの入口は、学生がどこにいても入れるよう、三か所に置きます。

| 場所 | 置き方 |
|---|---|
| 企業ページ | 末尾と、選考の流れの近く。「流れは〇〇。エントリー後、△△までに連絡します」と、次に何が起きるかを添える |
| イベントページ | 末尾。「参加後に案内します」。参加しなくてもエントリーできるなら、その旨 |
| 採用サイト | エントリーの本体が採用サイトにある場合、ワンキャリアからの飛び先を、迷わない場所に。「ワンキャリアから来た方はこちら」があると迷わない |

エントリーの本体がワンキャリアの中にあるか、採用サイトにあるかは、仕様と自社の運用で決まります。どちらでも、「入口が三か所にあり、どこから入っても同じ流れになる」ことが要点です。採用サイトとの役割分担は[Wantedlyと採用サイトの役割分担](/media/wt-saiyo-hp-renkei/)で書いた考え方と同じです。

## エントリー後の最初の連絡までを、導線に含める

エントリーは、導線の終わりではありません。

- **エントリー後、最初の連絡をいつまでにするかを、入口に書く**：「〇〇までに」。書いたら守る
- **最初の連絡に、次の段階の日程と、誰と何を話すかを入れる**：企業ページの「選考の流れ」と揃える
- **連絡が遅れそうなら、遅れる旨を先に**：無言で待たせない
- **エントリー後の連絡の速さは、次の体験談に書かれる**：「エントリー後の連絡が遅かった」は、体験談で最も多い不満の一つ

「入口に、最初の連絡の目安を書く」で、学生はエントリー後に待てます。書かずに遅れると、「エントリーしたが、何も来ない」で離れます。

## 導線が切れていることに、気づく方法

| 方法 | 見つかること |
|---|---|
| 段ごとの数を並べる（体験談の閲覧→企業ページの閲覧→イベントの申込→エントリー→選考。管理画面で見られる範囲で） | どの段の間で細くなっているか |
| 面接で「どこを読んで来ましたか」と聞く | 体験談だけか、企業ページも読んだか、イベントに来たか |
| イベント後に、エントリーした人としなかった人を分ける | イベント後の連絡が届いているか |
| 採用サイトの「ワンキャリアから来た人」の動き | 飛び先で迷っていないか |
| 体験談に「エントリーの方法が分かりにくかった」があるか | 入口の問題 |

「面接で聞く」が、最も直接の材料です。「体験談だけ読んでエントリーした」が多いなら、企業ページとイベントが導線に入っていません。

## 3媒体と採用サイトの導線を揃える

OfferBox、Wantedly、ワンキャリアから来た学生が、同じエントリーの流れに入るようにします。

- **エントリーの本体は一つ**：媒体ごとに別の流れを作らない
- **各媒体からの飛び先を、迷わない場所に**：「〇〇から来た方はこちら」
- **選考の流れの記述を、3媒体と採用サイトで揃える**：どこで読んでも同じ流れ
- **エントリー後の最初の連絡の目安を、3媒体で同じに**
- **どの媒体から来たかを、台帳に残す**：媒体ごとの導線の細さを見る

「エントリーの本体は一つ」で、3媒体の導線は、入口が違うだけで、同じ流れになります。

## 導線の更新の起点

- **イベントが終わったら、企業ページの誘導を外す**：終わったイベントへの誘導が残ると、切れた導線になる。[イベントページと企業トップページの使い分け](/media/oc-event-page-kigyo-top/)
- **エントリーの方法や飛び先が変わったら、三か所を同時に直す**
- **選考の流れが変わったら、入口の「次に何が起きるか」も直す**
- **選考の山のあと、段ごとの数と面接の言葉で、切れた段を見る**

導線は、一度作って終わりではなく、イベントごと、選考ごとに、切れていないかを確かめます。

### エージェントベストの見解

これをやる前に、先に決めておかないと導線の最後が切れることがあります。「エントリー後の最初の連絡を、いつまでにするか」です。当社がワンキャリアの導線を支えるとき、各段の一文と入口の置き方は当社が設計できますが、エントリー後の連絡の速さは、社内の運用です。導線の最後がここで切れると、企業ページからイベントからエントリーまでの導線がどれだけ整っていても、「エントリーしたが何も来ない」が次の体験談に書かれます。当社が最初にお願いするのは、エントリー後の最初の連絡の目安を決め、それを守る担当と仕組み（通知、期限）を作ることです。目安が決まれば、入口に書けます。書けば、学生は待てます。守れば、次の体験談に「連絡が早かった」と書かれます。

## まとめ

- 導線は、学生の動き「体験談→企業ページ→イベント→エントリー→選考」に沿って、各段に「次に進む一文」を置く
- 切れやすいのは、体験談から企業ページ（薄い）、企業ページからイベント（誘導が無い）、イベントの後（連絡が無い）、エントリーの方法、エントリー後の連絡
- エントリーの入口は、企業ページ・イベントページ・採用サイトの三か所に。どこから入っても同じ流れに
- エントリー後の最初の連絡の目安を入口に書き、守る。導線の最後まで含める
- 段ごとの数と、面接の「どこを読んで来たか」で切れた段を見つけ、イベント終了後に誘導を外し、3媒体と採用サイトで導線を揃える

## よくある質問

### 企業ページからエントリーする学生と、イベントを経てエントリーする学生、どちらを増やすべきですか

どちらも同じ流れに入るなら、どちらでも構いません。イベントを経た学生は、確かめてから来るので、選考で話が具体になります。企業ページから直接来る学生は、体験談と企業ページで判断しています。面接で「どこを読んで来たか」を聞き、どちらの導線が細いかを見て、細いほうの一文を足します。

### エントリーの本体が採用サイトにあり、ワンキャリアからの飛び先で学生が迷います

採用サイトに「ワンキャリアから来た方はこちら」の入口を作り、企業ページの末尾から直接そこへ飛ぶ形にします。飛び先で、ワンキャリアの企業ページに書いた選考の流れと同じものが見えると、学生は迷いません。採用サイトの担当と、飛び先の場所を決めます。

### ワンキャリアの導線の設計は、御社に相談できますか

できます。当社は、5段の型、各段の一文の型、入口の置き方の設計、切れている段の見つけ方の型、3媒体の揃え方の点検を支えられます。一文を置くこと、連絡を守ること、イベントの運営、採用サイトの更新は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
