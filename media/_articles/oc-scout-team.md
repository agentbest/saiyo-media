ワンキャリアのスカウトは、企業ページの掲載やイベントと同じ会社の中で動きます。学生は文面を受け取ったあと、企業ページと選考体験談・クチコミで確かめ、イベントや面談でその会社の人に会います。書き手が二人、三人と増えると、学生が出会う「会社の人」も増え、説明や対応のずれが体験談に残りやすくなります。**結論から言うと、複数人でスカウトを回すときは、プロフィールを読んで書く社員を募集ごとに一人ずつ置き、受諾への返事・日程の調整・体験談の読み込みは人事の窓口一か所に集めます。そのうえで、スカウト・掲載・イベントで使う言葉と、学生ごとの連絡の記録を一つにまとめ、書き手には週に一度の枠と面談だけを頼みます。人数の上限は、送れる数ではなく、窓口が返しきれる数と面談の枠で決まります。** この記事では、崩れやすい箇所、持ち場、一か所に置くもの、週と月の動かし方、受け渡しと偏りの見方を整理します。担当決めの基本は[ワンキャリアのスカウト担当](/media/oc-scout-tantou/)、一人で回す場合は[人事1人でワンキャリアのスカウトを回す](/media/oc-scout-hitori/)で書きました。Wantedlyでの考え方は[Wantedlyのスカウトをチームで回す方法](/media/wt-scout-team/)にあります。

## 人が増えたときに学生から見えるもの｜送り主・イベントの顔・面談相手

書き手を増やす理由は、送れる量を増やすことと、募集ごとに年次の近い社員が自分の言葉で書けるようにすることです。ただ、ワンキャリアの学生はスカウトだけでその会社を判断するわけではありません。文面の送り主、企業ページに出ている社員、イベントで話した人、面談の相手を、同じ会社の人として続けて見ています。

そのため、複数人で回すときに守りたいのは、誰が送っても次の三つが変わらないことです。

- **説明が同じ**：仕事の内容や選考の進め方が、文面・企業ページ・イベント・面談で食い違わない
- **待たせ方が同じ**：どの書き手の文面に受諾しても、翌日までに返事が届く
- **連絡が重ならない**：同じ学生に、別の募集のスカウトやイベントの案内がばらばらに届かない

書き手ごとの違いは、学生の一文と一年目との重なりに出れば足ります。

## 人が増えたときに崩れやすい箇所

| 崩れ方 | ワンキャリアで残りやすいもの |
|---|---|
| 書き手ごとに台帳を持ち、送った相手が共有されない | 同じ学生に別の募集から届き、「社内で連絡を取り合っていない会社」という印象が体験談に残る |
| スカウトとイベントの案内を別々の人が送っている | 学生が同じ週に二通の別々の誘いを受け取り、どちらに返せばよいか迷う |
| 文面の選考の説明が、書き手ごとに企業ページと違う | 学生が企業ページで確かめたときに「どれが正しいのか」と感じ、面接後の体験談に書かれる |
| 受諾の通知が書き手それぞれに届く | 忙しい書き手の分だけ返事が遅れ、「連絡が遅かった」と残る |
| 体験談とクチコミを読む役が決まっていない | 「定型文だった」という書き込みに誰も気づかず、全員が同じ送り方を続ける |
| 書き手に結果が返ってこない | 自分の文面がどうなったか分からず、送らない週が増える |

多いのは、上の三行のように社内の連絡の切れ目がそのまま学生の目に触れる形です。書き手の文章力より先に、記録と言葉の置き場をそろえます。

## 持ち場の決め方｜書き手は募集ごと、窓口と読み手は一か所

| 持ち場 | 誰が | 受け持つこと |
|---|---|---|
| 書き手 | 募集ごとに一人。その職種の年次の近い社員 | 週に一度の枠でプロフィールを読み、学生の一文と一年目の仕事との重なりを書いて送る。受諾した学生との面談に出る |
| 窓口 | 人事一人 | すべての募集の受諾と質問に翌日までに返し、学生の授業の予定に合う候補日を出す。通知を一か所で受ける |
| 読み手 | 人事（窓口と同じ人でよい） | 新しい選考体験談とクチコミを週に一度読み、スカウトや面談に触れた箇所を書き手全員に伝える |
| 掲載・イベントの担当 | 企業ページとイベントを受け持つ人 | 企業ページやイベントの内容を変えたら、窓口に知らせる |
| まとめ役 | 人事 | 型と見本、絞り込みの条件、台帳、月の見直し、書き手への結果の返し |
| 月の会の決め手 | 職種の責任者 | 募集ごとの配分と、次の月に直す一か所を決める |

中心は「書き手は増やしてよいが、窓口と読み手は増やさない」ことです。返事の速さと体験談の読み込みは、人が分かれるほどばらつきます。人事が一人なら窓口・読み手・まとめ役を兼ねるので、そのぶん募集と書き手の数を絞ります。

### エージェントベストの見解

複数人で回す相談でよく聞くのが、「書き手を増やせば、人事の負担は分散するはず」という見込みです。当社は求人広告代理店として、ワンキャリアのスカウト運用に関わっていますが、実際には書き手を増やすほど、受諾への返事、日程の調整、体験談の読み込み、掲載との言葉合わせといった人事側の作業はかえって増えます。送る量が増えれば受諾も増え、文面の数が増えれば企業ページと照らす箇所も増えるからです。そこで当社は、書き手を一人増やす前に「窓口の人が、増えた受諾に翌日までに返せるか」を先に見積もるよう勧めています。返しきれない見込みなら、書き手を増やすより、まとめ役の作業のうち台帳の集計や型の更新を外に出すほうが先です。書き手の数ではなく、人事の手が空いている量で、チームの大きさを決めます。

## 一か所に置くもの｜型・台帳・掲載と合わせる言葉

| 置くもの | 中身 | 置き場と使う人 |
|---|---|---|
| 文面の型と見本 | 募集ごとの変えない部分、受諾が来た文面の例、使わない言い回し | 一つのフォルダ。書き手全員。管理の考え方は[ワンキャリアのスカウト文面のテンプレート管理](/media/oc-scout-template/) |
| 掲載と合わせる言葉 | 仕事の内容、一年目の過ごし方、選考の流れについて、企業ページとイベントで使っている書き方 | 型の冒頭に貼る。書き手と面接に出る人 |
| 学生ごとの連絡の記録 | 誰が、どの募集で、いつ送ったか。イベントの案内を送ったか。受諾、面談、選考の進み | 一つのファイル。スカウトとイベントの両方の担当 |
| 返事の型 | 受諾・質問・選考の確認・辞退への返し方 | 窓口 |
| 面談の進め方 | 話す順番、聞くことと聞かないこと、最後に示す次の選択肢 | 面談に出る書き手全員。[スカウト経由の初回面談の設計](/media/oc-scout-mendan/) |
| 体験談の要点 | 新しい書き込みのうち、スカウトや面談に触れた箇所 | 読み手がまとめ、書き手全員に |

ワンキャリアで加えたいのは、二行目の「掲載と合わせる言葉」と、記録にイベントの案内を含めることです。文面と企業ページの揃え方は[ワンキャリアのスカウトと掲載のつなげ方](/media/oc-scout-keisai-renkei/)で書きました。そろえるのは言葉と記録で、学生の一文と一年目の重なりは書き手が自分で書きます。

## 週と月の動かし方

週の動きは、書き手の手間を増やさない形にします。

1. **書き手は自分の予定に週一回の枠を持つ**：全員で集まって送る時間は設けない
2. **送ったら、その場で記録に一行**：送り主、学生、募集、引いた一文
3. **窓口は毎日決まった時刻に通知と記録を見る**：受諾と質問に翌日までに返す
4. **読み手は週に一度、体験談の新着を読む**：スカウトや面談に触れた箇所があれば、その週のうちに書き手全員へ
5. **週の確認は人事だけで短く済ませる**：返事の遅れ、送信が止まった書き手、企業ページとの食い違い。見方は[ワンキャリアのスカウト週次確認](/media/oc-scout-review/)

月に一度だけ、書き手と責任者も入れて短い会を開き、記録の数、体験談の要点、掲載やイベントの変更を並べて、配分と型の一か所を決めます。書き手が出るのは月の会と面談だけ、と最初に伝えると協力を得やすくなります。

人事は結果を書き手に個別に返します。「この文面から面談まで進んだ」「体験談に、自分のことを読んでくれていたとあった」と届くと、次の週も枠を守りやすくなります。

## 加わる人への受け渡しと、偏りの見方

新しく書き手が加わるときは、次の順で渡します。

- **一枚にまとめた型と見本、使わない言い回し**
- **掲載と合わせる言葉と、担当する募集の企業ページ**：先に企業ページを読んでもらう
- **自社の体験談とクチコミの要点**：学生が何を確かめに来るかを知ってから書いてもらう
- **記録の場所と、送ったら一行という約束**
- **最初の数通は人事が目を通してから送る**：一文が入っているか、説明が企業ページと同じか
- **最初の受諾と面談の結果を、早めに本人へ返す**

書き手が抜けるときは、その募集の記録と、送ったが返事待ちの学生の一覧を次の人に渡します。担当が替わったときの立て直しは[ワンキャリアの担当者が交代したときの立て直し](/media/oc-tantousha-koutai/)で書きました。

偏りは、月の会の前に記録で確かめます。

| 見るもの | 偏りのサイン | 動かすこと |
|---|---|---|
| 書き手ごとの送った数 | 一人に集まっている、送らない週が続く人がいる | 上司と枠を確かめ直し、募集の配分を変える。[ワンキャリアのスカウト通数の配分](/media/oc-scout-tsuusuu-haibun/) |
| 書き手ごとの面談の数 | 面談の枠を超えている | その書き手の送る量を減らす |
| 窓口の返事までの時間 | 翌日を越える日が出てきた | 書き手を増やす前に、全体の送る量を減らす |
| 体験談の書き込みと送り主の対応 | 「定型文だった」が特定の送り主の文面に重なる | その書き手の読める人数を見直し、受諾が来ている文面を見本として渡す |

## 社内の分担

| 作業 | 担当 |
|---|---|
| 持ち場を決める | 人事と職種の責任者 |
| 型・掲載と合わせる言葉・記録・返事の型・面談の進め方を一か所に置く | 人事（言葉は掲載・イベントの担当と） |
| 読んで書いて送り、記録に一行 | 書き手（募集ごと） |
| 受諾と質問への返事、日程の調整 | 窓口（人事一人） |
| 体験談とクチコミを読み、要点を伝える | 読み手（人事） |
| 企業ページやイベントの変更を知らせる | 掲載・イベントの担当 |
| 月の会 | 人事、責任者、書き手 |
| 加わる人への受け渡し、最初の数通の確認 | 人事 |
| 記録から偏りを見つけ、募集の配分を組み替える | 人事と責任者 |

外部の運用代行や代理店が手伝えるのは、持ち場の設計、型と記録のひな形づくり、掲載と合わせる言葉の整理、受け渡しの一枚、偏りを見る表、体験談の要点のまとめまでです。プロフィールを読んで書くこと、受諾に返すこと、面談に出ること、配分を決めることは、企業の側で行います。

### エージェントベストの見解

ワンキャリアで掲載・イベントとスカウトを並行して使う会社では、数か月たったころ、イベントの担当とスカウトの書き手がそれぞれ別の表で学生を管理している状態をよく見かけます。イベントに申し込んだ学生に、別の書き手から同じ時期にスカウトが届き、さらに別の担当からイベントの案内が届く。学生から見れば、同じ会社から三通の連絡が来ていることになります。当社がこの状態の立て直しに関わるときは、書き手を増やす話より先に、スカウトとイベントの連絡を同じ記録に一行ずつ書く形へ寄せることから始めます。イベントの担当が記録を開いて「この学生にはもう書き手から送っている」と分かれば、案内を一本にまとめられます。表を一つにするだけで、体験談に残る「連絡がばらばらだった」という印象は減らせます。

## まとめ

- 複数人で回すと、学生は送り主・企業ページの社員・イベントの人・面談相手を同じ会社の人として続けて見る。説明、返事の速さ、連絡の重なりをそろえる
- 書き手は募集ごとに一人置き、受諾への返事・日程・体験談の読み込みは人事の窓口一か所に集める
- 型と見本、掲載と合わせる言葉、スカウトとイベントを含む学生ごとの連絡の記録、返事の型、面談の進め方を一か所に置く
- 書き手に頼むのは週一回の枠と面談と月の会だけ。結果は人事から個別に返す
- 人数の上限は、窓口が翌日までに返しきれる量と面談の枠で決まる。偏りは記録と体験談の書き込みで見る

## よくある質問

### 社員によって、受諾が来る人と来ない人がいます。どう揃えればよいですか

記録で、送り主ごとに引いた一文を並べます。来ない人の文面に学生の一文や一年目との重なりが薄いなら、受諾が来ている文面を見本として共有し、その人の読む人数を減らします。返事までの時間に差があるなら、通知が書き手に届いている可能性が高いので、窓口に集め直します。体験談の書き込みが特定の送り主の文面に重なっていないかも、あわせて確かめます。

### イベントの担当とスカウトの担当が別の部署で、記録を一つにできません

表そのものを統合できなくても、学生ごとに「スカウト送付」「イベント案内」の欄を一つ設けた共有の一覧を置き、両方の担当が一行ずつ書く形から始めます。案内を送る前にその一覧を開く、という約束だけでも、同じ学生への重なりは減らせます。企業ページやイベントの内容を変えたときに人事へ知らせる経路も、同じ機会に決めておきます。

### ワンキャリアのスカウトを複数人で回す体制を、御社に相談できますか

できます。持ち場の設計、型と記録のひな形、掲載と合わせる言葉の整理、加わる人への受け渡しの一枚、偏りを見る表、体験談の要点のまとめをお手伝いします。読んで書くこと、受諾への返事、面談、配分の決定は、企業の側で行ってください。当社は求人広告代理店として、ワンキャリアの掲載とスカウトの運用を支えています。
