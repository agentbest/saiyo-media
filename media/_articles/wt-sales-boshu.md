Wantedlyでセールスの募集記事を出したとき、最初にぶつかるのは「『営業経験者歓迎』『成長中の事業を一緒に』と書いたのに、話を聞きに来る人が少ない。来ても、面談で『見込み客はどこから来るのですか』『数字に届かなかったらどうなりますか』を聞かれて答えられない」という問題です。**結論から言うと、セールスの募集記事は、「営業経験者歓迎」ではなく「誰に、何を、どう売っていて、見込み客がどこから来て、数字がどう決まり、届かないとき何が起きるか」を書き、募集記事を書く前に社内で売り方の型と数字の扱いを決めておきます。** この記事では、セールスが募集記事で見ているもの、書く前に決めること、「なにを・なぜ・どうやって」の書き方、「こんな人」の書き方、待遇の書き方、スカウトと面談への接続、社内の分担、やりがちな失敗を整理します。募集記事の基本構成は[Wantedlyの募集記事の基本構成](/media/wt-boshu-kihon/)、スカウト文面の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)で書きました。

## セールスが募集記事で見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰に、何を売るか | 企業か個人か。何の商品か。単価と、決まるまでの期間。自分の売ってきたものと近いか |
| 新規か、既存か | 新しい顧客を開拓するのか、いる顧客を深めるのか、両方か |
| 見込み客がどこから来るか | 問い合わせが来るのか、自分で探すのか、別の部署が作るのか。ここが最も見られる |
| 数字の決まり方と、届かないとき | 目標を誰がどう決めるか。届かないとき、何が起きるか。詰められるのか、一緒に見直すのか |
| 売り方の裁量 | 提案の中身や価格を自分で決められるか。決まった話し方で売るのか |
| 給与の仕組み | 固定と変動の割合。変動が何で決まるか。数値は確認したものだけ |

「見込み客がどこから来るか」と「届かないとき何が起きるか」が、セールスに特有の点です。「成長中」「裁量」の一語では、ここが分かりません。

## 書く前に決めること｜売り方の型と、数字の扱い

| 決めること | 選択肢 |
|---|---|
| 誰に、何を | 企業／個人。商品を一つ。単価と決まるまでの期間の目安（確認できる範囲で） |
| 新規か既存か | 新規／既存／両方。両方なら、最初はどちらから |
| 見込み客の来方 | 問い合わせ中心／自分で探す／別の部署が作る／組み合わせ。割合を書けるか |
| 数字の決め方 | 誰が、何をもとに決めるか。本人と話して決めるか、上から降りるか |
| 届かないときの動き | 一緒に見直す／面談で確認／給与に連動。実態を書く |
| 売り方の裁量 | 提案と価格をどこまで自分で決められるか |
| 最初の月に任せること | 既存顧客の引き継ぎか、同行か、一人で新規か。誰と組むか |

「自分で探す割合が高い」「届かないと給与に連動する」でも構いません。隠さずに書けば、それを前提に読む人が来ます。

## 「なにを」｜誰に、何を、どう売っているか

「なにをやっているのか」は、会社の事業の説明ではなく、このセールスが売る商品と、売る相手に絞ります。

- **売る相手を、具体に書く**：「〇〇の業種の、△△の担当者」「□□に困っている個人」。誰が決裁するか
- **売る商品を、一つに絞る**：複数あるなら、最初に売るものを一つ。何に困っている相手に、何を解決する商品か
- **売り方を、流れで書く**：「問い合わせが来て、話を聞き、提案し、決まるまで〇〇の期間」「自分で探して、最初の連絡から決まるまで」
- **いまの状態を書く**：問い合わせが増えていて手が足りないのか、問い合わせは少なく自分で探す段階か

「なにを」の書き方の基本は[「なにをやっているのか」の書き方](/media/wt-boshu-nani-wo/)で書きました。

### エージェントベストの見解

セールスの募集記事を出す前に、先に決めておかないと効果が出ないのは、「見込み客がどこから来るか」を隠さず書くことです。当社がWantedlyのセールスの募集を支えるとき、「反響が多く、提案に集中できる」と書かれているのに、営業の責任者に聞くと「実際は自分で探す割合が大きい」という会社が多くあります。セールスが面談で最初に聞くのは、商品の説明ではなく、「見込み客はどこから来ますか」「自分で探す割合はどのくらいですか」です。ここで募集記事と違う答えが出ると、その場で信用を失います。自分で探す割合が大きくても構いません。「問い合わせは〇〇の割合で、残りは自分で探す。探す先の一覧は会社が用意する」と書けば、それを前提に読む人が来ます。逆に、本当に問い合わせが中心なら、「問い合わせが増えて手が足りない。最初の月は問い合わせへの対応から」と書くと、それを求める人が来ます。当社が最初にお願いするのは、商品の説明ではなく、営業の責任者に「見込み客の来方の実態」を一文で言ってもらうことです。

## 「どうやって」｜数字の決まり方と、届かないときの書き方

| 書くこと | 書き方 |
|---|---|
| 数字の決め方 | 誰が、何をもとに、いつ決めるか。本人と話して決めるか |
| 届かないときの動き | 「月の途中で〇〇と見直す」「四半期で確認し、給与には△△の形で連動する」。実態を隠さない |
| 売り方の裁量 | 提案の中身と価格を、どこまで自分で決められるか。決まった話し方があるなら、あると |
| 一緒に動く人 | 同行するか、一人か。見込み客を作る部署があるか。支援の部署に引き継ぐか |
| 前に売れた例 | 「〇〇の業種に△△の切り口で提案して、□□の期間で決まった」。顧客が特定されない形で。無ければ書かない |

「裁量が大きい」と書くより、「提案の中身は自分で決め、価格は〇〇の範囲で自分で決められる」と書くほうが、裁量の範囲が伝わります。書き方の基本は[「どうやっているのか」の書き方](/media/wt-boshu-dou/)で書きました。

## 「こんな人」｜経歴ではなく、行動で書く

| 経歴で書く（避ける） | 行動で書く |
|---|---|
| 営業経験3年以上 | 自分で見込み客を探して、最初の連絡から決めたことがある（新規なら） |
| 法人営業の経験 | 決裁する人と、現場の人の言い分が違う状態から、決めてもらったことがある |
| 目標達成意欲の高い方 | 届かなかった月に、何が原因かを自分で分けて、次の月に変えたことがある |
| コミュニケーション能力 | 相手が言っていない困りごとを、聞いて見つけたことがある |
| 即戦力 | 最初の月は〇〇の既存顧客の引き継ぎを任せる予定です。△△と同行します |

「届かなかった月に、原因を分けて変えた」が、セールスで最も読まれる行動です。「最初の月に何を任せ、誰と組むか」を書くと、経験年数の条件がいらなくなります。書き方の基本は[「こんなことやります」の書き方](/media/wt-boshu-konna/)で書きました。

### 待遇の書き方

セールスは、給与の仕組み（固定と変動の割合、変動が何で決まるか）を、他の職種より見ます。隠さず、最後に、短く、確認した内容だけを書きます。数値を書くなら、社内で確認したものだけです。仕組みだけを書き、数値を面談で伝える形でも構いません。書き方は[募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)と[条件をどこまで書くか](/media/wt-boshu-joukenn/)で書きました。

## スカウトと面談への接続

- **スカウトの文面は、募集記事の「誰に、何を、どう売っているか」と同じ言葉で**：相手が「誰に、何を、どう売ってきたか」を読み、自社の売り方と重ねる。「営業経験を活かして」と書かない。[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)
- **面談には、営業の責任者と、一緒に動く人が出る**：「見込み客の来方」と「届かないとき」を、責任者本人が話す。人事だけの面談は、ここに答えられない
- **面談で話すのは、売り方の話**：いまの見込み客の来方の実態、最近決まった例と決まらなかった例、相手ならどう売るかを聞く
- **数字の話を隠さない**：目標の決め方、届かなかった月に実際に何があったか

つなげ方は[スカウトと募集記事のつなげ方](/media/wt-scout-boshu-renkei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 売り方の型、見込み客の来方、数字の扱いを決める | 営業の責任者 |
| 「なにを」（誰に、何を、どう売るか）の下書き | 人事が、営業の責任者と現場のセールスに聞いて書く |
| 「どうやって」（数字の決め方、届かないとき、裁量） | 営業の責任者が話し、人事が書き、本人が確認 |
| 給与の仕組みと数値の確認 | 営業の責任者と人事 |
| 「こんな人」を行動で書く、最初の月の予定 | 営業の責任者と人事 |
| 面談 | 営業の責任者と、一緒に動くセールス |

一人目のセールスを採る募集では、いま経営者が売っていることが多くあります。その場合は、「いまは経営者が売っていて、〇〇ができていない。最初の月は△△の同行から。見込み客は□□から来ている」と正直に書きます。

運用代行や代理店が支えられるのは、募集記事の型、見込み客の来方と数字の扱いを文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認までで、売り方の実態、数字の扱いの決定、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「セールスには、事業の成長性と稼げることを前面に出せば来る」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyのセールスの募集と面談を見ていますが、「急成長」「高収入も可能」と書いた募集記事より、「見込み客は〇〇から来て、残りは自分で探す。数字は本人と話して決め、届かない月は△△と一緒に見直す」と実態を書いた募集記事のほうが、話を聞きに来る人の経験が合い、面談後に離れる人が少ない傾向があります。セールスは、「急成長」「高収入」を読むと「詰められる会社」を想像し、届かないときの扱いが書かれていないと「書けない理由がある」と読みます。届かないときの扱いが厳しくても、書かれていれば、それを前提に読む人が来ます。当社が案内するのは、成長性と収入を前面に出さず、見込み客の来方と届かないときの扱いを隠さず書き、数値は確認したものだけにすることです。稼げることで人は来ません。実態が書かれていることで来ます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「営業経験者歓迎」「成長中」で書く | どの募集記事にもあり、読まれない | 誰に、何を、どう売るか、を文で |
| 見込み客の来方を盛る | 面談で違いが分かり、信用を失う | 実態と割合を書く |
| 届かないときの扱いを書かない | 「書けない理由がある」と読まれる | 実態を書く。厳しくても隠さない |
| 確認していない給与の数値を書く | 面談で違いが分かり、離れる | 確認した数値だけ。無ければ仕組みだけ |
| 「裁量」で済ませる | 提案と価格の範囲が分からない | どこまで自分で決められるかを書く |
| 面談に営業の責任者が出ない | 「届かないとき」に答えられない | 責任者が出て、実態を話す |

最も多いのは、最初の「営業経験者歓迎」と、見込み客の来方の盛りです。

## まとめ

- セールスが見ているのは、誰に何を売るか・新規か既存か・見込み客がどこから来るか・数字の決まり方と届かないとき・売り方の裁量・給与の仕組み
- 書く前に、売り方の型（相手、商品、見込み客の来方）と数字の扱い（誰が決め、届かないとき何が起きるか）を、営業の責任者が決める。自分で探す割合が大きくても、隠さない
- 「なにを」は売る相手と商品を一つに、売り方を流れで。「どうやって」は数字の決め方と届かないときの動きを、実態で。前に売れた例を一つ
- 「こんな人」は経歴ではなく、「届かなかった月に原因を分けて変えた」「言っていない困りごとを見つけた」の行動で。待遇は仕組みと、確認した数値だけ
- 面談には営業の責任者が出て、見込み客の来方と届かないときの実態を話す

## よくある質問

### 見込み客のほとんどを自分で探す会社です。正直に書くと来ませんか

隠すほうが、面談で分かって離れます。「問い合わせは少なく、ほとんどを自分で探す。探す先の一覧と、最初の連絡の型は会社が用意する。最初の月は〇〇と同行する」のように、実態と、会社が用意するものを一緒に書きます。自分で探して決めてきた人には、「自分のやり方が活きる」として読まれます。

### 届かないと給与が下がる仕組みです。書くべきですか

書きます。仕組みを隠して入社後に分かるほうが、離れます。「数字は本人と話して決める。届かない月は〇〇と見直す。給与は固定と変動があり、変動は△△で決まる」のように、仕組みを書き、数値は確認したものだけを書くか、面談で伝えると書きます。

### セールスの募集記事は、御社に相談できますか

できます。当社は、募集記事の型、見込み客の来方と数字の扱いを文で書く直し方、「こんな人」を行動に直す作業、スカウト文面との整合の確認を支えられます。売り方の実態、数字の扱いの決定、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
