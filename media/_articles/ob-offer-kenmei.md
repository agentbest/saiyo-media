丁寧に書いた文面が、開かれずに終わる。原因は、学生の一覧で最初に見える一文にあることが多いものです。**結論から言うと、学生はオファーの一覧で「企業名」と「最初に見える一文」を見て、開くか決めます。この一文が、企業名だけ、定型、会社の都合、煽り、のどれかだと、文面の中身がどれだけ良くても開かれません。開かれる一文は、冒頭の「読んだ・こう思った」を一言に縮めたものです。** この記事では、件名にあたる部分がなぜ開封を左右するか、開かれる型と開かれない型、作る手順、学生像の型ごとの用意、開封の数字の読み方、試し方、やりがちな失敗を整理します。この記事で「件名にあたる部分」と書くのは、学生の一覧で最初に目に入る一文のことで、媒体の項目の仕様には触れません。文面全体の構成は[オファー文面の構成](/media/ob-offer-kosei/)で書きました。

## この作業の目的｜「開く理由」を、一言で渡す

学生は複数の企業からオファーを受け取り、一覧で並んだ中から開くものを選びます。一覧に見えるのは、企業名と最初の一文だけです。文面の冒頭も本文も、開かれてから初めて読まれます。

つまり、件名にあたる部分の役割は1つで、「開く理由を一言で渡す」ことです。会社を説明することでも、仕事を伝えることでもありません。「これは自分に関係がある」と一覧で思ってもらうことです。

冒頭が「自分宛だと分かる理由」、本文が「会う理由」、締めが「次にすること」だとすると、件名にあたる部分は「開く理由」です。役割が違うので、書くことも違います。

## 開かれる型と、開かれない型

| 開かれる型 | 例（型） | なぜ開かれるか |
|---|---|---|
| 学生に関係する一言 | 「〇〇の経験を読んで、△△の仕事でお話ししたく」 | 自分のプロフィールを読んだと分かる |
| 仕事の一言 | 「△△を一緒にやる人を探しています」 | 何の仕事かが一言で分かる |
| 名義の一言 | 「△△担当の〇〇です。あなたの□□について」 | 人から届いたと分かる |
| 学生の志向への一言 | 「業界を絞らずに仕事で選びたい、と書かれていた方へ」 | 自分の考えを読んだと分かる |

| 開かれない型 | なぜ開かれないか |
|---|---|
| 企業名だけ、または「〇〇株式会社からのオファー」 | 一覧で他社と同じに見える |
| 「オファーのご案内」「スカウトのお知らせ」 | 定型。誰にでも送っている |
| 「採用強化中」「積極採用」 | 会社の都合。学生には関係が無い |
| 「限定」「特別」「あなただけ」 | 煽り。信用されない |
| 長すぎて一覧で切れる | 肝心の一言が見えない |
| 記号や飾り | 軽く見える |
| 「優秀なあなたへ」 | 評価する言い方。属性で見られていると感じる |

開かれない型の共通点は、「学生に関係が無い」ことです。企業の都合、定型、煽りは、どれも学生の側から見て「自分のこと」ではありません。

## 手順1｜冒頭を書いてから、縮めて作る

件名にあたる部分は、先に作りません。冒頭を書いてから、その要約として作ります。順番は[オファー文面の構成](/media/ob-offer-kosei/)で書いた「本文の共通部分→締め→冒頭→件名」です。

1. **冒頭を書く**：「読んだ・こう思った・だから送った」の3つ
2. **冒頭の「読んだ」と「こう思った」を、一言にする**：「〇〇の経験を読んで、△△の仕事で」のように
3. **一覧で切れない長さにする**：長ければ「読んだ」だけを残す
4. **企業名と並んだときに、他社と違って見えるかを確かめる**：自社の企業名の横に置いて、一覧を想像する
5. **煽りと評価の言い方が入っていないかを見る**

この順番だと、件名にあたる部分と冒頭の内容が一致します。先に件名を作ると、冒頭と内容がずれ、開いた学生が「件名と違う」と感じます。

### エージェントベストの見解

これをやる前に、先に決めておかないと件名が作れないことがあります。「冒頭を先に書く」ことです。当社がOfferBoxの運用代行で文面を作るとき、件名にあたる部分だけを先に考えようとすると、企業名や仕事名のような一般的な言葉しか出てきません。冒頭で「読んだ・こう思った」を書いてから縮めると、その学生固有の一言が自然に出ます。当社は3媒体すべての販売パートナーとして契約後の運用を見ていますが、開かれない文面の多くは、冒頭は丁寧なのに件名にあたる部分が企業名だけ、という形です。冒頭に時間をかけた分、件名を作る時間が残っていないのです。冒頭を書いたら、最後に一言に縮める。この数分を省くと、冒頭にかけた時間が開かれずに消えます。件名は、冒頭の要約であって、別に考えるものではありません。

## 手順2｜学生像の型ごとに、件名の型を用意する

学生ごとに件名を一から考えると時間がかかります。学生像の型ごとに、件名の型を用意しておきます。テンプレートの3層の考え方は[オファーを学生ごとに変える範囲](/media/ob-offer-personalize/)で書きました。

| 学生像の型 | 件名の型 |
|---|---|
| 自由記述に具体的な行動がある学生 | 「〇〇（行動）を読んで、△△の仕事で」。〇〇だけ学生ごとに変える |
| 志望業界が自社と一致する学生 | 「△△（仕事）で、〇〇（学生の志向）を一緒に」 |
| 志望業界が違うが仕事が近い学生 | 「業界は違いますが、〇〇の経験が△△に近いと思い」 |
| 自由記述が薄い学生 | 「△△担当の〇〇です。□□（学部や志向）の方へ」 |
| 早期の学生 | 「就職活動はまだ先だと思いますが、〇〇について」 |

型を用意しておくと、学生ごとに変えるのは〇〇の部分だけになり、冒頭を縮める作業が数秒で済みます。

## 手順3｜開封の数字の読み方

開封の数字が管理画面で見えるかどうかは、媒体の仕様によります。見える場合も、見えない場合も、読み方は次のとおりです。

- **見える場合**：開封と承認を分けて見る。開封が低ければ件名にあたる部分の問題、開封は高いが承認が低ければ冒頭か本文か見に来た先の問題。切り分けができる
- **見えない場合**：承認で見る。件名を変えた前後で、承認が動いたかを月で比べる
- **どちらの場合も、週で比べない**：分母が小さく、時期で動く。率の読み方は[KPI設計](/media/ob-kpi-sekkei/)
- **開封率だけを追わない**：開かれても承認されなければ意味が無い。件名で開かせて、冒頭で「自分宛」と伝え、本文で会う理由を渡し、承認に至る。件名は入口

開封の数字が見えると、件名の工夫に意識が向きすぎることがあります。件名は「開く理由」を渡すまでで、その先は冒頭と本文の仕事です。

## 手順4｜試し方

件名にあたる部分の型を試すときは、次の形にします。

1. **2つの型を用意する**：たとえば「学生に関係する一言」と「仕事の一言」
2. **同じ学生像の型の学生に、交互に送る**：学生像が違うと比べられない
3. **月の合計で、承認（見えれば開封も）を比べる**：週では比べない
4. **差があれば、効いた型を残す**：差が無ければ、どちらでもよい。時間をかけない
5. **一度に2つ以上を試さない**：件名と冒頭を同時に変えると、何が効いたか分からない

試すのは、月に1つの要素だけです。件名を試す月は、冒頭と本文を変えません。変更を1つずつにする考え方は[週次レビューのやり方](/media/ob-shuukan-review/)で書きました。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 企業名だけ、または定型 | 一覧で埋もれる | 冒頭を縮めた一言にする |
| 先に件名を作る | 冒頭と内容がずれる | 冒頭を書いてから縮める |
| 「採用強化中」など会社の都合 | 学生に関係が無い | 学生に関係する一言に |
| 「限定」「特別」で煽る | 信用されない | 事実だけ |
| 「優秀なあなたへ」 | 評価する言い方 | 経験や志向に触れる |
| 長すぎて一覧で切れる | 肝心の一言が見えない | 「読んだ」だけ残す |
| 全員に同じ件名 | 使い回しに見える | 学生像の型ごとに型を用意し、〇〇を変える |
| 開封率だけを追う | 開かれても承認されない | 冒頭と本文とセットで見る |
| 件名と冒頭を同時に変える | 何が効いたか分からない | 月に1つ |

最も多いのは、最初の「企業名だけ、または定型」です。冒頭に時間をかけた文面ほど、件名が手つかずになりがちです。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 学生像の型ごとの件名の型を作る | 人事（テンプレートと一緒に） |
| 冒頭を書いて、縮める | 読んだ人（人事、現場の若手、または運用代行） |
| 煽りと評価の言い方のチェック | 書いた人と別の1人 |
| 型を試し、月で比べる | 人事（または運用代行） |
| 効いた型をテンプレートに残す | 人事 |

運用代行に出している場合、件名にあたる部分は冒頭と一緒に代行が作ります。型の設計と、効いた型の判断は、代行と社内で一緒に行います。代行の範囲は[運用代行に任せられる範囲](/media/ob-unyou-daikou-hanni/)で書きました。

### エージェントベストの見解

媒体を比べたり運用を見直したりするときに、開封率で件名の良し悪しを判断しようとする会社は多いのですが、開封率が見えるかどうかは媒体の仕様によりますし、見えても週で追える数字ではありません。当社がOfferBoxの運用代行で件名にあたる部分を見直すときは、開封率ではなく、月の承認の合計で、件名の型を変えた前後を比べます。開封は、承認に至る入口の1つで、入口だけ広げても出口（承認）が増えなければ意味がありません。逆に、件名が企業名だけで入口が閉じていると、冒頭と本文がどれだけ良くても承認は出ません。件名は、承認までの流れの最初の関門であって、独立した指標ではない。この位置づけで見ると、件名にかける時間は「冒頭を縮める数分」で足り、開封率の解釈に時間を使う必要は無くなります。

## まとめ

- 学生は一覧で企業名と最初の一文を見て開くか決める。件名にあたる部分の役割は「開く理由を一言で渡す」こと
- 開かれるのは、学生に関係する一言、仕事の一言、名義の一言。開かれないのは、企業名だけ、定型、会社の都合、煽り、評価する言い方、長すぎ
- 冒頭を書いてから縮めて作る。先に作ると冒頭とずれる
- 学生像の型ごとに件名の型を用意し、学生ごとに変えるのは一部だけにする
- 開封の数字が見えても見えなくても、月の承認で前後を比べる。件名と冒頭を同時に変えない

## よくある質問

### 件名にあたる部分に、企業名を入れなくてよいのですか

一覧には企業名が別に表示されることが多く、件名にあたる部分にまで企業名を入れると、学生に関係する一言が入る余地が減ります。企業名は媒体の表示に任せ、一文には学生に関係することを書きます。媒体の表示の仕様は、管理画面で確認してください。

### 開封率が管理画面で見えません。件名の効果はどう測ればよいですか

承認で見ます。件名の型を変えた月と、変える前の月で、承認の合計を比べます。週では比べません。開封が見えなくても、件名が承認の入口であることは変わらないので、承認の変化で十分に判断できます。

### 件名の型の設計は、御社に頼めますか

頼めます。当社がOfferBoxの運用代行を受けるときは、テンプレートと一緒に学生像の型ごとの件名の型を作り、冒頭を書いて縮める作業を当社が行います。効いた型の判断は、月の承認で企業と一緒に見ます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
