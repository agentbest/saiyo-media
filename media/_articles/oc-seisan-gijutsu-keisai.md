ワンキャリアで新卒の生産技術を募集したとき、最初にぶつかるのは「『生産技術』と掲載しても学生が職種を知らずにエントリーが来ないか、来ても面接で『何をする仕事ですか』『工場はどこですか』と聞かれ、内定後に工場の勤務地を伝えると辞退され、入社しても『現場と設計の板挟みだった』と体験談に書かれる」という問題です。**結論から言うと、ワンキャリアの生産技術の掲載は、「生産技術」の名前ではなく「何の工場で、ラインを作るのか直すのか、現場の職人と設計の間で何をするのか、工場の勤務地、最初の年に何を任せるか」を、学生が体験談で読む前に企業ページと募集に書き、内定の前に工場を見せます。** メーカーとしての設計は[メーカーの新卒採用でワンキャリアを使うときの設計](/media/oc-maker-katsuyou/)で書きました。この記事は生産技術の職種に絞り、掲載とスカウトと選考をつなげて書きます。

## 生産技術志望の学生が、体験談で読んでいること

生産技術は、学生が名前を知らない職種です。学生は「生産技術」で探さず、機械設計や開発の体験談を読む中で「生産技術という配属があった」と知ります。企業ページを読む学生は、「何をする仕事か」から確かめています。

| 読んでいること | 掲載への意味 |
|---|---|
| 何をする仕事か | ラインを作るのか、直すのか、工程を変えるのか。「生産技術」の名前では分からない |
| 何の工場か | 何を作る工場か。大きさ。ラインの数 |
| 現場と設計の間で何をするか | 職人に頼む立場か、設計に戻す立場か。板挟みになるか |
| 工場の勤務地 | 工場がどこか。本社と離れているか。工場の間で異動があるか |
| 夜勤や立ち上げの時期 | ラインの立ち上げで夜や休日に出るか。時期はいつか |
| 最初の年に何を任されるか | 現場の改善の一つか、設備の一台か、誰が見るか |
| 機械や電気系でなくても採るか | 化学系や情報系から入った人がいるか |
| 先輩の実態 | 最初の年に何を直し、いま何のラインを担当しているか |

「何をする仕事か」と「工場の勤務地」が、生産技術で最も読まれ、企業ページで最も書かれない項目です。

## 掲載に書くこと｜何をするか、何の工場か、現場と設計の間、勤務地、最初の年

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「生産技術」ではなく「〇〇の工場のラインを直す生産技術」「△△の新しいラインを作る生産技術」。作るか直すか |
| 何をする仕事か | 「いまのラインの止まる原因を見つけて直す。新しいラインは△年目から」。一段落で、職種を知らない学生に |
| 何の工場か | 「□□を作る工場。ラインが〇本。職人が△人」 |
| 現場と設計の間 | 「職人に頼む立場と、設計に戻す立場の両方。最初の年は先輩が間に入る」。板挟みになるなら、そう書く |
| 工場の勤務地 | 「勤務地は□□の工場。本社ではない。工場の間の異動は〇年に一度程度」。地名で |
| 夜勤や立ち上げ | 「ラインの立ち上げは年に〇回。その期間は夜や休日に出ることがあり、代休を取る」 |
| 最初の年 | 「最初の〇か月は先輩の改善の手伝い。△△か月目に設備の一台を、先輩の確認付きで」 |
| 機械や電気系以外から入った人 | 「化学系から入った人が〇人。最初に覚えるのはラインの見方」。いないなら、いないと |
| 先輩の話 | 最初の年に何を直し、何に困ったか。盛らない |

企業ページには何をする仕事かと現場と設計の間と勤務地を、募集には何の工場かと作るか直すかと最初の年を、と分担します。

### エージェントベストの見解

生産技術の募集で、ワンキャリアが向いている会社と向いていない会社があります。当社は3媒体すべての販売パートナーとして、生産技術の掲載と選考を見ていますが、ワンキャリアは、学生が「生産技術」の名前で探さない媒体です。学生は企業の名前と体験談から入り、職種はその後に読みます。ワンキャリアが向いているのは、「企業ページに生産技術が何をする仕事かを一段落で書き、機械設計や開発の募集を見に来た学生に、生産技術も読ませる」ことができる会社です。企業ページが本社の話ばかりで、工場の話が無い会社は、ワンキャリアで生産技術を出しても、学生が職種にたどり着きません。その場合は、OfferBoxで「志望職種は見ずに、工場の勤務地で絞る」検索のほうが向いています。逆に、企業ページに工場の写真と「生産技術は何をする仕事か」を置いた会社は、体験談に「生産技術を知らなかったが、企業ページで分かった」と書かれ、次の年に職種を知って来る学生が増えます。当社が最初に確かめるのは、企業ページに工場の話が置けるかです。

## 生産技術志望の学生の見つけ方

「生産技術」を志望職種に書いている学生はほとんどいません。志望職種で絞らず、行動で読みます。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 志望職種 | 機械設計、開発、それ以外 | 見ない条件。「生産技術」で絞ると、いなくなる |
| 工場の勤務地 | 住みたい地域、通える範囲 | 譲れない条件。工場の地名で絞る |
| 止まったものを直した経験 | 「装置が止まり、原因を見つけて直した」 | 生産技術の行動。優先 |
| 仕組みを変えた経験 | 「作業の順番を変えて、待ち時間を減らした」 | 工程の改善と重なる |
| 人に頼んで動いてもらった経験 | 「年上の人に頼んで、やり方を変えてもらった」 | 職人との関係と重なる |
| 実験装置の扱い | 「装置の調子を見て、使う前に直した」 | あれば読む。無くても外さない |

「止まったものを直した・仕組みを変えた・人に頼んで動いてもらった」を書いている学生が、生産技術と重なります。四つの行動は[OfferBoxで生産技術に合う学生を見つける検索の考え方](/media/ob-seisan-gijutsu-target/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

理系向けの文面の型は[ワンキャリアで理系学生にスカウトを送る文面](/media/oc-scout-rikei/)で書きました。生産技術では、次の点を足します。

- **相手の一文は、止まったものを直した経験で**：「装置が止まり、原因を見つけて直したと書かれていたのを読んで」。「ものづくりが好き」を褒めない
- **何をする仕事かを、一文で**：「生産技術は、いまのラインの止まる原因を見つけて直す仕事です」。職種を知らない学生に、名前の前に仕事を書く
- **何の工場かを、一文で**：「□□を作る工場で、ラインが〇本あります」
- **勤務地を、一文で**：「勤務地は□□の工場で、本社ではありません」
- **最初の年を、一文で**：「最初の〇か月は先輩の改善の手伝いで、職人とのやり取りは先輩が間に入ります」
- **送り主は、生産技術で入った先輩**：人事の名前で「ものづくりに興味のある方」と送らない

## 選考への接続｜内定の前に、工場を見せる

- **面接の最初に、何をする仕事かを話す**：学生は職種を知らないまま来ている。「生産技術は〇〇をする仕事です」から始める
- **勤務地を、聞かれる前に話す**：「勤務地は□□の工場です」。内定後に初めて伝えると、辞退される
- **聞くのは「止まったとき何をしたか」**：「なぜ生産技術か」を聞かない。学生は答えを持っていない
- **内定の前に、工場を見せる**：ラインの前に立ち、職人と話す先輩を見せる。半日でよい。見せてから内定を出すと、内定後の辞退と、入社後の「板挟みだった」が減る
- **先輩が面接に出る**：生産技術で入った先輩が、最初の年に直したものを話す。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 何をする仕事か、何の工場か、作るか直すか、勤務地、立ち上げの時期、最初の年を決める | 生産技術の責任者 |
| 企業ページの生産技術の記述と工場の写真 | 人事が、責任者と先輩に聞いて書く |
| 先輩の話 | 先輩本人が話し、人事が書き、本人が確認 |
| 体験談との整合の確認 | 人事（「板挟みだった」「勤務地が違った」と書かれていないか） |
| スカウトの一文 | 先輩 |
| 面接 | 責任者と先輩。「なぜ生産技術か」を聞かない |
| 工場を見せる日程 | 生産技術の責任者。工場長に先に断る |

運用代行や代理店が支えられるのは、掲載の型、何をする仕事かを文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくり、工場を見せる日程の組み方までで、仕事の内容の決定、先輩の話、面接、工場の受け入れは社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「生産技術は知られていない職種だから、『開発』や『技術職』の名前で広く集めて、配属で生産技術に回せばよい」というものです。「開発」で集めて生産技術に配属した会社の体験談には、「開発のつもりで入ったら工場だった」「配属で勤務地が変わった」が書かれ、次の年の学生がそれを読んで、開発の募集からも離れます。生産技術に配属される可能性を隠して集めると、生産技術だけでなく、開発の募集の信用も落ちます。逆に、「生産技術」を別の募集にし、企業ページに何をする仕事かを一段落書き、開発の募集にも「生産技術の募集は別にある」と書いた会社は、開発を見に来た学生が生産技術も読み、体験談に「生産技術を選んで入った」と書かれます。当社が最初にお願いするのは、生産技術を「開発」に混ぜないことです。知られていない職種は、名前を隠すのではなく、何をする仕事かを書いて知らせます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「生産技術」の名前だけで書く | 学生が職種を知らず、来ない | 何をする仕事かを一段落で |
| 「開発」に混ぜて配属で回す | 開発の募集の信用も落ちる | 別の募集にし、開発の募集にも書く |
| 勤務地を書かない | 内定後に辞退される | 工場の地名で書く |
| 志望職種「生産技術」で絞る | いなくなる | 止まったものを直した記述で読む |
| 内定後に工場を見せる | 「板挟みだった」と離れる | 内定の前に見せる |

## まとめ

- 生産技術は学生が名前を知らない職種。学生は「何をする仕事か・何の工場か・現場と設計の間で何をするか・勤務地・立ち上げの時期・最初の年・先輩の実態」を企業ページで確かめる
- 掲載には、作るか直すか、何をする仕事かを一段落、何の工場か、現場と設計の間、勤務地を地名で、立ち上げの時期、最初の年を書く。「開発」に混ぜない
- ワンキャリアが向くのは、企業ページに工場の話を置き、開発を見に来た学生に生産技術も読ませられる会社
- 学生は、志望職種ではなく、工場の勤務地で絞り、「止まったものを直した・仕組みを変えた・人に頼んで動いてもらった」で見つける
- 面接の最初に何をする仕事かを話し、勤務地を先に言い、内定の前に工場を見せる

## よくある質問

### 学生が「生産技術」を知らないので、エントリーが来ません

名前の前に、仕事を書きます。企業ページの最初のほうに「生産技術は、いまのラインの止まる原因を見つけて直す仕事です」と一段落置き、工場の写真を添えます。開発や機械設計の募集を見に来た学生に読ませる位置に置きます。スカウトも、「生産技術」の名前より先に、何をする仕事かを一文で書きます。開発の募集の中に「生産技術の募集は別にある」と一文入れると、開発を見に来た学生が読みます。

### 工場の勤務地を書くと、エントリーが減りませんか

減りますが、減るのは内定後に勤務地を聞いて辞退する学生です。工場の勤務地は譲れない条件なので、企業ページに地名で書き、スカウトは工場に通える範囲の学生に送ります。書かずに集めると、面接と内定後の連絡の時間を使って、辞退で終わります。地元の工場なら、「□□の出身で、地元で働きたい」と書いている学生に送ると、勤務地が理由の辞退が減ります。

### 生産技術の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、何をする仕事かを文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくり、工場を見せる日程の組み方を支えられます。仕事の内容の決定、先輩の話、面接、工場の受け入れは、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
