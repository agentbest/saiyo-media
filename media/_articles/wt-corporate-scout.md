Wantedlyでコーポレート（総務・経理・労務などを兼ねる職）にスカウトを送るとき、最初にぶつかるのは「『総務』『経理』の肩書で検索して『バックオフィス全般をお任せしたい』と送っているのに、返信が来ない。来ても、面談で『具体的に何と何ですか』『どれが主ですか』と聞かれて止まる」という問題です。**結論から言うと、コーポレートへのスカウトは、肩書で相手を選ぶのではなく、先に自社が兼ねてほしい範囲を含むものと含まないものに分けて一覧にし、主と外注との分担と経営者の隣で決められることと最初に任せることを決め、「近い組み合わせを、同じくらいの規模の会社で兼ね、手作業を仕組みに変えた経験を書いている人」を選び、その人の「何と何を兼ねて、何を変えたか」を読んだ一文から、経営者の名前で、一覧と実態で誘います。** この記事では、コーポレートがスカウトで見ているもの、送る前に決めること、誰に送るか、文面に書くこと、返信後の面談、社内の分担、やりがちな失敗を整理します。文面の3段の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)、募集記事は[コーポレートを採る募集記事の書き方](/media/wt-corporate-boshu/)で書きました。

## コーポレートがスカウトで見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰から来たか | 経営者か、人事か。コーポレートは経営者の隣で動く仕事なので、経営者本人からかを見る |
| 自分の兼務の何を読んだか | 肩書で検索しただけか、「何と何を兼ねて、何を仕組みに変えたか」を読んだか |
| 兼ねる範囲の一覧 | 何と何を含み、何を含まないか。「全般」なら「何でも足される」と読む |
| 主と、外注との分担 | どれに時間を使うか。会計事務所、社労士、弁護士に何を出しているか。文面で分かるか |
| 経営者の隣で決められること | 道具、仕組み、規程の案。手続きを回すだけか。文面で分かるか |
| 専門に進む道を盛っていないか | 「将来は経理の専門へ」が実態か、釣りか |

「バックオフィス全般」の一語は、「何でも足される」を想像させます。

## 送る前に決めること｜一覧、主、外注との分担、決められること、最初に任せること

送る前に、経営者が五つを決めます。決め方は[コーポレートを採る募集記事の書き方](/media/wt-corporate-boshu/)で書きました。

- **兼ねる範囲の一覧**：総務／経理／労務／法務／情報システム／広報のうち、含むものと含まないもの。全部書き出す
- **主を一つに**：時間の多くを使うもの。「主は経理」のように
- **外注との分担**：会計事務所、社労士、弁護士、外注に何を出し、社内で何をするか
- **経営者の隣で決められること**：道具の選定、仕組みの変更、規程の案、外注の選定。どこまで任せるか
- **最初に任せること**：「〇〇の手続きの引き継ぎから」「紙の請求書の仕組みを変えるところから」を一つ。これが文面の2段目になり、送る相手を「それができる人」に絞れる

## 誰に送るか｜肩書ではなく、兼ねた組み合わせと規模、仕組みに変えた経験の重なり

「総務」「経理」の肩書で検索して選ぶと、面談で「組み合わせが違う」「規模が違う」になります。選ぶ基準は、「近い組み合わせを、同じくらいの規模の会社で兼ね、手作業を仕組みに変えた経験を書いているか」です。

| 読む箇所 | 重なりの見方 |
|---|---|
| 兼ねた組み合わせ | 総務と経理か、経理と労務か、総務と労務と法務か。自社の一覧と近いか。ここが最も重なりが要る |
| 会社の規模 | 大きな会社の一部か、小さな会社で一人か。自社の規模と近いか |
| 主にしていたもの | 時間の多くを使っていたのはどれか。自社の主と合うか |
| 何を仕組みに変えたか | 「紙の請求書を〇〇に変えた」「勤怠を表計算から△△に移した」が書かれているか。自社の「最初に任せること」と重なるか |
| 外注との関係 | 会計事務所や社労士とやり取りしてきたか。窓口だったか、自分で手を動かしたか。自社の分担と合うか |

「何を仕組みに変えたか」が要点です。自社に紙や手作業が多いなら、この記述のある人を優先します。

### 肩書の幅に配慮する

コーポレートの仕事は、「総務」「経理」「労務」「管理部」「バックオフィス」「経営者の秘書で手続きも回していた人」「一人で会社の事務を全部見ていた人」など、違う肩書で書かれています。肩書で検索すると、組み合わせが合う人を落とします。「何と何を兼ねて、何を変えたか」で読み、肩書は「あればよい条件」に置きます。絞り方の基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「コーポレートには『幅広く活躍できます』と送れば、何でもできる人から返信が来る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトを見ていますが、コーポレートが返信した文面を並べると、「幅広く」「全般」の言葉は、返信の有無とほとんど関係がないか、むしろ開かれにくい傾向があります。コーポレートを専門にしてきた人は、「幅広く」を読むと「入ってから何でも足される」を最も警戒します。関係があるのは、「自分が何と何を兼ねて、何を変えたかを読んでくれたか」と、「含むものと含まないものの一覧と、決められることが文面で分かるか」の二つです。「総務と経理と労務。主は経理。法務と情報システムは含まない。道具の選定は任せる」と一覧で書かれていれば、「範囲と権限が明確な会社」として返信が来ます。当社が対象を組み直すとき、最初にやるのは、検索条件から肩書を外し、「何と何を兼ねて、何を変えた人か」で並べ直し、「全般」を消して、一覧と含まないものを文面の最初のほうに入れることです。

## 文面に書くこと

文面の型（相手の一文→自社の場面→話す場の案内）は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)に書いたので、ここではコーポレート特有の要点だけを書きます。

- **相手の一文は、兼ねた組み合わせと変えたことで**：「総務と経理を兼ねて、紙の請求書を〇〇に変えられたと書かれていたのを読んで」「一人で事務を全部見ながら、勤怠を△△に移されたと書かれていた点を読んで」。肩書ではなく、組み合わせと変えたこと
- **送り主は経営者で**：コーポレートは経営者の隣で動く仕事なので、経営者本人の名前と言葉で
- **一覧と含まないものを、最初のほうで**：「お願いしたいのは、総務と経理と労務です。主は経理。法務と情報システムは含みません」。「全般」と書かない
- **外注との分担を、一文で**：「決算は会計事務所、給与は社労士、契約は弁護士に出しています。社内は窓口と手続きです」
- **決められることを、一文で**：「道具の選定と仕組みの変更は任せます。規程の案は作ってもらい、私が決めます」
- **最初に任せることを、一文で**：「最初の月は、〇〇の手続きの引き継ぎから」。募集記事と同じ言葉
- **専門に進む道を、盛らずに**：「専門に分かれる予定は、いまはありません」「会社が大きくなったら、経理を専任にしたいと考えています。時期は未定です」
- **話す場は、経営者と**：「私が、一覧といまの実態を隠さず話します。転職を決めていなくても構いません」

相手の前の会社の仕組みを評価しません。

## 返信後の面談｜経営者が、一覧と実態を話す

| 話すこと | 中身 |
|---|---|
| 一覧と、含まないもの | 何と何を含み、何を含まないか。文面と同じことを、経営者本人が話す。「聞いていない」を出さない |
| 主と、外注との分担 | どれに時間を使うか。事務所、社労士、弁護士に何を出しているか |
| いま回っていないことと、仕組みの実態 | 何が滞っているか。紙と手作業の残り具合。隠さない |
| 決められること | 道具、仕組み、規程の案。どこまで任せるか。経営者が本人の言葉で |
| 相手なら何から手を付けるか | 最初に任せることについて、相手の考えを聞く。ここが長い面談ほど次につながる |
| 相手の兼務の話 | 何と何を兼ねて、何を変えて、どう順番を付けて回したか。聞く時間を長く |

面談には、経営者が出ます。面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

選考に進むとき、手続きや仕組みの課題を出すなら、面談のときに「課題がある」「どのくらいの時間がかかるか」を先に伝えます。伝え方は[カジュアル面談から選考に進むときの伝え方](/media/wt-scout-senkou-ikou/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 一覧、主、外注との分担、決められること、最初に任せることを決める | 経営者 |
| 「組み合わせと規模、仕組みに変えた経験」で対象を並べ直す | 経営者か、いま兼務している人 |
| 相手の兼務と変えたことを読み、一文を書く | 経営者（または人事が下書きし、経営者が自分の言葉に直す） |
| 外注との分担の確認 | いま兼務している人か、外注先の担当 |
| 型、送信、返信対応、台帳 | 経営者か、いま兼務している人 |
| 面談 | 経営者 |

一人目のコーポレートを採るスカウトでは、いま経営者が全部を兼務していることが多くあります。その場合は、経営者が相手のプロフィールを読み、「一人目で、いまは私が全部やっている。〇〇が滞っている。総務と経理と労務。主は経理。法務は弁護士」と正直に文面に書きます。

運用代行や代理店が支えられるのは、対象の並べ直しの基準づくり、型、避ける言葉のチェック、募集記事との整合の確認までで、一覧と分担と決められることの決定、相手の兼務を読んだ一文、面談は経営者が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

コーポレートにスカウトを送る前に、先に決めておかないと効果が出ないのは、「含まないものを、一覧に書くこと」です。当社がWantedlyのコーポレート向けスカウトを支えるとき、「含むもの」は書けても、「含まないもの」を書きたがらない会社が多くあります。「後で足すかもしれないので」が理由です。ただ、含まないものが無い文面は、コーポレートには「何でも足される」と読まれて開かれません。逆に、「法務と情報システムは含まない。足すときは、その前に相談する」と書いた会社は、返信の数は減っても、範囲を決めて回してきた人が来て、面談で「聞いていない仕事が増えた」になる人がいなくなります。当社が最初にお願いするのは、対象の絞り込みではなく、経営者に「この人に任せないものは何か」を三つ言ってもらうことです。その三つが、文面の信用と、来る人の種類を決めます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 肩書で相手を選ぶ | 面談で「組み合わせが違う」「規模が違う」 | 兼ねた組み合わせと規模、変えた経験で選ぶ |
| 「バックオフィス全般をお任せ」と送る | 「何でも足される」と読まれ、開かれない | 一覧と含まないもので |
| 含まないものを書かない | 「後で足される」を想像される | 含まないものと、足すときは相談すると書く |
| 主を書かない | 「全部同じ重さで」を想像される | 時間の多くを使うものを一つ |
| 専門に進む道を盛る | 入社後に分かり、離れる | 無いなら無いと書く |
| 面談に経営者が出ない | 「決められること」が伝わらない | 経営者が出て、一覧と実態を話す |

最も多いのは、最初の「肩書で選ぶ」と、含まないものの抜けです。

## まとめ

- コーポレートは、誰から来たか（経営者か）・自分の兼務の何を読んだか・一覧と含まないもの・主と外注との分担・決められること・専門に進む道を盛っていないか、を文面の段階で見ている
- 送る前に、含むものと含まないものの一覧、主、外注との分担、経営者の隣で決められること、最初に任せることを、経営者が決める。含まないものを書く
- 誰に送るかは、肩書ではなく、兼ねた組み合わせと会社の規模、「何を仕組みに変えたか」の重なりで。肩書は「あればよい条件」に
- 文面は経営者の名前で。相手の兼務と変えたことを読んだ一文、一覧と含まないもの、分担、決められること、最初に任せることを。「全般」「幅広く」を書かない
- 面談は経営者が出て、一覧と決められることと専門に進む道を、本人の言葉で盛らずに話す

## よくある質問

### 後で仕事を足すかもしれないので、含まないものを書きたくありません

書かないほうが、開かれません。含まないものが無い文面は「何でも足される」と読まれます。「いまは法務と情報システムは含まない。足す必要が出たら、その前に相談して決める」と、含まないことと、足すときの決め方を書きます。

### 肩書が「総務」の人と「経理」の人、どちらに送るべきですか

肩書で選ぶ必要はありません。自社の一覧と近い組み合わせを兼ねてきた人に送ります。主が経理なら、「経理と総務を兼ねて、経理に時間の多くを使ってきた人」。主が総務なら、その逆です。「総務と経理を兼ねて、〇〇を変えられたと書かれていたのを読んで」と、組み合わせと変えたことで送ります。

### コーポレート向けのスカウトの対象の絞り込みは、御社に相談できますか

できます。当社は、対象の並べ直しの基準づくり、文面の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。一覧と分担と決められることの決定、相手の兼務を読んだ一文、面談は、経営者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
