営業職を新卒で採りたい会社が媒体を選ぶとき、最初にぶつかるのは「志望職種『営業』で絞って送ったら対象が少なく、『人柄重視』『未経験歓迎』で広げたら承認は来るのに面談で『営業はちょっと』と言われ、体験談に『ノルマ』『飛び込み』と書かれていて企業ページで答えておらず、内定を出しても『営業以外の会社に決めた』と辞退される」という問題です。**結論から言うと、営業は学生が「やりたくない」と最初に外す職種で、志望職種で絞ると届きません。学生が確かめるのは「誰に、何を、新規か既存か、数字が届かないとき何が起きるか」です。比べられる場は体験談で営業の実態が最も書かれる職種なので企業ページで先に答え、送る型は志望職種ではなく行動の型（決めきれない人と一緒に選んだ・断られて変えた）で絞り、記事を置く型は営業の一日と数字の決まり方を書き、承認の多さではなく「営業と分かって面談に来た数」で見ます。** 文系学生全般の考え方は[文系学生を採りたい会社の採用媒体の選び方](/media/hikaku-bunkei-erabikata/)で書きました。この記事は営業職に絞って、学生が外す職種をどう届けるかと媒体の選び方を書きます。

## 営業職の採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 学生が「営業はやりたくない」と最初に外す | 志望職種「営業」で絞ると、対象が少ない | 行動の型で絞る。[OfferBoxで営業職志望の学生を見つける検索の考え方](/media/ob-eigyo-target/) |
| 「人柄重視」「未経験歓迎」で広げる | 承認は来るが、面談で営業を避ける学生ばかり | 誰に何を売るかを先に書いて、営業と分かって来る学生に |
| 体験談で「ノルマ」「飛び込み」「詰められる」が書かれる | 企業ページで答えていないと、確かめられて離れる | 数字が届かないとき何が起きるかを企業ページに。[ワンキャリアで営業職を募集するときの掲載とスカウト](/media/oc-eigyo-keisai/) |
| 「営業職」の名前で募集する | 企業向けか個人向けか、新規か既存かが分からない | 誰に、何を、新規か既存かを職種名に |
| 営業の離職が体験談にある | 隠すと、体験談と企業ページのずれで離れる | 隠さず、理由と変えたことで |
| 承認率が高い | 「営業」と分からずに承認した学生が含まれる | 営業と分かって面談に来た数で見る |

## 判断軸を、営業職に当てる

| 軸 | 営業職での見方 |
|---|---|
| 対象（誰に届くか） | 志望職種「営業」で絞らない。行動の型（決めきれない人と一緒に選んだ、断られて理由を聞いて変えた、数字を見て変えた、人に頼んで動いてもらった）で絞る。売り方（企業向け・個人向け、新規・既存）で、優先する行動が変わる |
| 型（送るか、来るか、比べられるか） | 比べられる型は、営業の体験談が最も多く書かれる職種で、企業ページで「数字が届かないとき」に先に答えられるかが全て。送る型は、行動の型で絞って「あなたの〇〇の経験が、うちの営業の△△の場面で」と一文でつなぐ。来る型は、営業の一日と数字の決まり方を営業の若手が書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。承認が多くても営業と分かって来る学生は少ないので、承認の数で費用を見ない |
| 運用工数（誰の時間が要るか） | 営業の若手が名義と面談を持つ時間。営業は忙しく、面談の枠が取りにくい。枠から送る数を決める |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。営業職では、「対象」を志望職種で絞らないことと、「型」で比べられる場の企業ページに「数字が届かないとき」を先に書くことが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「営業は人柄が全てだから、『人柄重視』『未経験歓迎』で広く集めて、面談で見ればよい」というものです。当社は3媒体すべての販売パートナーとして、営業職の採用の相談を受けますが、「人柄重視」で集めた会社の面談は、「営業と知らずに来た学生」が多く、面談の最初に「営業です」と言った時点で離れます。承認率は高いのに、営業と分かって面談に来た学生が少なく、内定を出しても営業以外の会社に行きます。学生が営業を避けるのは、営業の中身（誰に、何を、新規か既存か、数字が届かないとき何が起きるか）が分からないからで、人柄で集めても中身は伝わりません。逆に、「〇〇の業種の△△の担当者に、□□を。最初の年は既存の引き継ぎから。目標はあり、届かない月は◇◇と一緒に見直す」と企業ページと文面に書いた会社は、承認は減りますが、営業と分かって面談に来る学生が増え、内定後に営業以外の会社に行く辞退が減ります。当社が最初にお願いするのは、「人柄重視」「未経験歓迎」を消し、「誰に、何を、新規か既存か、数字が届かないとき」を四行で書くことです。

## 学生が、確かめること

- **誰に、何を売る営業か**：企業か個人か。何の商品か。「営業職」の名前では分からない
- **新規か、既存か**：自分で探して開拓するのか、いる顧客を深めるのか。体験談で最も聞かれる
- **数字の扱いと、届かないとき**：目標があるか、どう決まるか、届かないとき何が起きるか。「詰められる」の有無
- **最初の年に何をするか**：同行の期間、一人で持ち始める時期、最初の年の終わりの姿
- **営業で入った先輩の実態と、離職**：文系で営業に入った人が、何に困り、続いているか。辞めた理由
- **自分の経験が、営業のどの場面と重なるか**：オファーの一文で、自分の行動のどこを見たか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 体験談があり、企業ページに「誰に何を、新規か既存か、数字が届かないとき」を先に書ける | 学生が並べて比べる場（ワンキャリア） | 営業の体験談が最も多い職種。企業ページで先に答えれば、体験談と一致して選ばれる |
| 行動の型で絞り、営業の若手の名義で「あなたの〇〇が、営業の△△の場面で」と一文でつなげる | 企業から送る型（OfferBox） | 営業を外している学生にも、行動の型で届く。[営業向けスカウト文面の型](/media/kh-bunmen-eigyo/) |
| 営業の若手が、営業の一日と数字の決まり方を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「ノルマ」「飛び込み」の像を、一日と決まり方の記事で置き換える。[Wantedlyでセールスを採る募集記事の書き方](/media/wt-sales-boshu/) |
| 「人柄重視」「未経験歓迎」が文面に残っている | どれも先ではない | 四行に置き換えてから |
| 数字が届かないとき何が起きるかが、社内で言葉になっていない | どれも先ではない | 営業の責任者と決めてから |

どれか一つが正解ではなく、体験談があるか、営業の若手が書けるか、行動の型で絞れるかで、先に検討するものが変わります。

## 組み合わせ

- **比べられる場で先に答え、送る型で営業を外している学生に届ける**：企業ページで「数字が届かないとき」を、文面で行動の型を。[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **記事を置く型で、営業の一日を通年で**：[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **売り方で、優先する行動を変える**：新規は「断られて理由を聞いて変えた」、既存は「決めきれない人と一緒に選んだ」、個人向けは「人に頼んで動いてもらった」
- **面談で、数字の扱いを先に話す**：聞かれる前に。面談に営業の若手が出る
- **内定後に、営業以外の会社と比べられる前提で**：営業の若手に会ってもらい、一日を見せる。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)
- **代行と組み合わせるなら、行動の型で絞る作業と一文の下書きを**：数字の扱いの決定と面談は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「営業職」「人柄重視」ではなく、四行で

- **「営業職」「総合職（営業）」「人柄重視」「未経験歓迎」を消す**：中身が伝わらず、営業を避ける学生が承認して面談で離れる
- **誰に、何を、どう売るかを、一行で**：「〇〇の業種の△△の担当者に、□□を。問い合わせが〇割、自分で探すのが△割」
- **新規か既存かを、時期で**：「最初の年は既存の引き継ぎから。二年目から新規」
- **数字の扱いを、届かないときまで**：「目標はある。本人と話して決める。届かない月は〇〇と一緒に見直す。給与には△△の形で連動する」。数値は自社の実態で。この記事では書かない
- **最初の年を、時期で**：「最初の月は同行。三か月目に小さな案件を一人で。一年目の終わりに〇〇」
- **離職を、隠さず**：「営業で入って〇年で辞めた人が△人。理由は□□。変えたのは◇◇」
- **オファーの一文を、行動の型で**：「断られて理由を聞いて変えたと書かれていたのを読んで、新規の〇〇の場面で」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 誰に何を、新規か既存か、数字の扱いと届かないとき、最初の年を、言葉にする | 営業の責任者 |
| 企業ページと文面の四行 | 人事が書き、営業の責任者が確認 |
| 行動の型で絞る条件 | 人事か代行。売り方で優先する行動を営業の責任者と決める |
| 名義と、オファーの一文 | 営業の若手 |
| 面談 | 営業の若手と責任者。数字の扱いを先に話す |
| 「営業と分かって面談に来た数」の記録 | 人事。面談の最初に確かめて記録 |

運用代行や代理店が支えられるのは、四行の型、行動の型で絞る作業、一文の下書き、記録の型までで、数字の扱いの決定、名義の若手、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

営業職の採用で数字を読むときに先にお伝えしているのは、「承認率の高さを、営業を選ぶ学生の多さと読み違えない」ということです。営業職の募集は、「人柄重視」「未経験歓迎」で送ると承認率が高くなりますが、承認した学生の多くは営業と分かっておらず、面談の最初に「営業です」と言った時点で終わります。承認率だけを見ると「効いている」と読めますが、営業と分かって面談に来た学生は少なく、内定を出しても営業以外の会社に行きます。当社が案内するのは、面談の最初に「営業と分かって来たか」を確かめて記録し、「営業と分かって面談に来た数」で見ることです。四行を書くと承認は減りますが、この数は増えます。承認が減ったことを見て「人柄重視」に戻す会社が多いのですが、戻すと、承認は戻り、営業と分かって来る数は減り、面談の時間だけが増えます。辞退の理由を「営業以外に決めた」で終わらせず、「営業の何が不安だったか」まで聞くと、四行のどこが足りないかが分かります。

## まとめ

- 営業は学生が「やりたくない」と最初に外す職種。志望職種で絞ると届かず、「人柄重視」で広げると営業と分からずに承認して面談で離れる
- 学生が確かめるのは「誰に、何を、新規か既存か、数字が届かないとき何が起きるか」。四行で書き、「営業職」「人柄重視」「未経験歓迎」を消す
- 比べられる場（ワンキャリア）は営業の体験談が最も多い職種なので企業ページで先に答え、送る型（OfferBox）は行動の型で絞って一文でつなぎ、記事を置く型（Wantedly）は営業の一日と数字の決まり方を
- 売り方（企業向け・個人向け、新規・既存）で優先する行動を変え、面談で数字の扱いを先に話し、営業の若手が出る
- 承認率ではなく「営業と分かって面談に来た数」で見て、承認が減っても「人柄重視」に戻さない

## よくある質問

### 志望職種「営業」の学生が少なすぎます

営業を志望職種に書く学生は少なく、そこで絞ると対象がいなくなります。志望職種を外し、行動の型（決めきれない人と一緒に選んだ、断られて理由を聞いて変えた、数字を見て変えた、人に頼んで動いてもらった）で絞ります。営業を外している学生も、行動の型で見れば営業と重なる人がいて、「あなたの〇〇の経験が、営業の△△の場面で」と一文でつなぐと、営業を候補に入れます。志望職種は「あればよい条件」に下げます。

### 数字が届かないときのことを書くと、来なくなりませんか

書かないと、体験談で「詰められる」を確かめられて、書いた場合より来なくなります。「目標はある。届かない月は〇〇と一緒に見直す。給与には△△の形で連動する」と、届かないときに何が起きるかを具体で書きます。「詰める」文化が無いなら、無いと書き、あるなら、変えたことを書きます。営業を選ぶ学生は、数字があること自体より、届かないときに何が起きるかが分からないことを避けています。

### 営業職の媒体選びは、御社に相談できますか

できます。当社は、四行の型、行動の型で絞る作業、一文の下書き、記録の型を支えられます。数字の扱いの決定、名義の若手、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、営業職の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
