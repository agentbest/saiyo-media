中途採用の費用を聞かれて、媒体と紹介会社への支払いの合計を採用人数で割った数字を出している会社は多いと思います。その数字は間違いではありませんが、手段を選び直すときの材料としては足りません。**結論から言うと、中途採用の単価は「外に払った費用」「社内で使った時間」「採れるまでの期間」の三つに分けて記録し、募集ごとに見るのが基本です。** この記事では、単価を分解する手順と記録の型、手段ごとの費用のかかり方の違い、比べるときに起きやすい誤りを整理します。

## 単価を一つの数字で見ると何が起きるか

一人あたりの外部費用だけで手段を比べると、次のような判断になりがちです。

- 紹介は一人あたりの支払いが大きく見えるので、まず媒体を増やす
- 媒体は月額や掲載料が先にかかるので、採れなかった月の費用が見えにくくなる
- 社内の面接や返信にかかった時間が、どの手段にも数えられない
- 採れるまでに長くかかった募集でも、最後に採れれば同じ単価として扱われる

この見方では、外に払う額は小さいが社内の手間が大きい手段と、外に払う額は大きいが社内の手間が小さい手段を、正しく比べられません。また、欠員の期間が延びたことによる現場の負担も数えられません。単価は、費用を下げるための数字ではなく、どの手段にどれだけ頼るかを決めるための数字です。そのためには、中身を分けて持っておく必要があります。

## 単価を分解する手順

単価は、次の順番で分けて記録します。募集が一つ終わるたびに、同じ欄を埋めます。

1. **外部費用を手段ごとに分ける**：求人媒体の掲載料、スカウトの利用料、紹介会社への手数料、運用代行への支払い、求人広告の制作費など。どの手段に払ったかが分かるように分ける
2. **採れなかった手段の費用も入れる**：その募集で使ったが、採用につながらなかった手段の費用も、その募集の費用として数える
3. **社内の時間を書く**：求人票の作成、スカウトの送信、応募への返信、日程の調整、面接、選考の会議。担当者と面接官の時間を、大まかな時間の幅で書く
4. **期間を書く**：募集を始めた日、最初の応募が来た日、内定を出した日、入社した日
5. **募集単位で合計する**：一人を採るのにかかった外部費用、社内の時間、期間を並べる

社内の時間は、正確に測ろうとすると記録が続きません。「求人票の作成に半日」「面接官は三人が一回ずつ」くらいの粒度で十分です。大切なのは、毎回同じ粒度で書くことです。

### エージェントベストの見解

当社は求人媒体の販売と、人材紹介の両方をしているので、単価の比べ方で誤解が生まれやすい場面をよく見ます。多いのは、紹介の手数料と媒体の費用を、同じ「一人あたり」として横に並べることです。紹介の手数料は採れたときにだけ発生する費用で、候補者を探す時間や一次の見極めの一部が中に含まれています。媒体の費用は採れなくても発生することが多く、探す時間と見極めの時間は社内に残ります。前提が違う二つを一つの列で比べると、媒体が安く見え、社内の時間が足りずに選考が止まる、という流れになりやすい。比べるときは、外部費用の横に「社内でやった工程」を一行添えてください。それだけで、同じ数字の意味が読み分けられます。

## 単価を記録する型

募集ごとに、次の表を一行ずつ埋めていきます。表計算のシートで十分です。

| 項目 | 書く内容 |
|---|---|
| 募集 | 職種、ポジション、採用人数 |
| 使った手段 | 掲載、スカウト、紹介、リファラル、運用代行など |
| 外部費用 | 手段ごとの支払い。採れなかった手段の分も含める |
| 採用につながった手段 | 入社した人がどの手段から来たか |
| 社内の時間 | 担当者と面接官のおおまかな時間 |
| 期間 | 募集開始から内定まで、内定から入社まで |
| 備考 | 欠員中に起きたこと、条件の変更など |

この表を何件か貯めると、職種ごとに傾向が見えてきます。たとえば、ある職種は紹介からの入社が多く、媒体の費用は毎回かかっているのに採用につながっていない、といったことです。単価の数字そのものより、こうした傾向のほうが、次の募集の判断に役立ちます。

単価の計算の考え方は、新卒も含めた形で[採用単価の考え方](/media/kh-kpi-tanka/)と[採用計画の単価の置き方](/media/kh-pl-tanka/)にもまとめています。

## 手段ごとの費用のかかり方

中途採用の手段は、費用がかかる時点と、社内に残る工程が違います。

- **求人媒体への掲載**：掲載の期間に対して費用がかかる形が多く、応募を待つ間も費用が発生します。応募の確認と返信、選考は社内に残ります
- **スカウト型の媒体**：利用期間や送信に対して費用がかかる形が多く、候補者を探して文面を書く時間が社内にかかります
- **人材紹介**：採れたときに手数料がかかる形が一般的です。探す工程は紹介会社が持ち、社内には面接と判断が残ります
- **リファラル**：外部費用は小さいことが多い一方、社員への協力の依頼や、紹介された人への丁寧な対応が社内に残ります
- **運用代行**：媒体の運用の作業を外に出す形です。支払いの形は会社によって違うので、どの工程を任せ、何が社内に残るかを先に確かめます

たとえば、Greenやdoda、typeのような中途向けの媒体を使う場合でも、掲載を中心にするか、スカウトを中心にするかで、社内に残る時間は変わります。手段を選ぶときは、費用の形と、社内に残る工程をセットで見ます。

### エージェントベストの見解

単価を下げたいという相談を受けたとき、当社が先に確かめるのは、採れなかった募集の費用が記録に入っているかどうかです。採れた募集だけで単価を計算すると、採れなかった募集にかけた媒体の費用や社内の時間が、どこにも残りません。その結果、毎年同じ職種で同じ手段を試し、同じように採れない、という繰り返しが起きます。単価を下げる工夫を考える前に、まず採れなかった募集を一覧にして、どの手段にいくら使い、どこで止まったかを並べてください。止まった場所が応募の段階なら手段か求人票、面接の段階なら選考の設計、内定の段階なら条件や口説き方の問題です。単価は結果の数字なので、止まった場所を直すほうが、手段を安いものに替えるより効くことが多いです。

## 単価を比べるときによくある差

同じ会社の中でも、単価の比べ方で判断がずれることがあります。

- **職種をまたいで比べる**：経験者の少ない職種と、応募が集まりやすい職種の単価を並べても、手段の良し悪しは分かりません。比べるのは同じ職種の中で
- **年度で区切る**：年度末に入社した人の費用が、前の年度の募集に積まれていることがあります。募集単位で区切るほうが読みやすくなります
- **欠員の期間を数えない**：採れるまでの期間が長いほど、現場が穴を埋める負担が続きます。金額にしにくい場合は、期間の列だけでも残します
- **入社後を見ない**：単価が小さくても、早く辞めてしまえばもう一度募集することになります。入社後しばらくして、定着しているかを備考に書き足します

## まとめ

- 中途採用の単価は、外部費用・社内の時間・期間の三つに分けて記録する
- 採れなかった手段や募集の費用も、その募集の費用として数える
- 紹介と媒体は費用の前提が違うので、社内に残る工程を添えて比べる
- 単価を下げる前に、採れなかった募集が止まった場所を確かめる
- 比べるのは同じ職種の中で、募集単位で区切る

## よくある質問

### 社内の時間まで記録する余裕がありません

正確な時間は要りません。「求人票に半日」「面接官が二人で一回ずつ」くらいで十分です。毎回同じ粒度で書くことのほうが大切です。記録が難しい場合は、面接の回数と面接官の人数だけでも残しておくと、手段ごとの手間の違いが見えてきます。

### 単価の目標はどう決めればよいですか

他社や業界の数字を目標にするより、自社の過去の募集の記録から決めるほうが現実的です。記録がない最初の年は、目標を置かずに記録を貯めることを優先します。予算の組み方は[採用予算の組み立て方](/media/kh-pl-yosan-kumitate/)で整理しています。

### 経営者に単価をどう説明すればよいですか

一つの数字で出すと、高いか安いかだけの話になりがちです。外部費用と期間を並べ、採れなかった募集の費用も含めて説明すると、手段の判断の話にできます。説明の型は[採用の数字を経営に説明する方法](/media/kh-tn-keiei-setsumei/)にまとめています。
