プロジェクトマネージャー（PM）を新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『PM候補』『将来のPM』で募集し、『リーダー経験』で絞ると、『人を動かして案件を回す』像の学生が来るが、面談で『最初の年は議事録と進捗の集計と客先への連絡です』と聞いて離れ、残った学生も入社後に『板挟みで何も決められない』と体験談に書く。遅れたとき誰がどう動くかを書かずに出したので、面談で『遅れたらどうなりますか』に答えられない」という問題です。**結論から言うと、新卒をプロジェクトマネージャーとして採る会社は少なく、「PM候補」で募集すると、学生は「人を動かして案件を回す」像で来て、最初の年が議事録と進捗の集計と客先への連絡だと離れます。媒体を選ぶ前に「新卒がいつからPMか」と「何を、誰と、どこまでの権限で進め、遅れたとき誰がどう動くか」を先に決め、「リーダー経験」の言葉で絞らず、「予定が崩れたとき誰に何を頼んで立て直したか・できないと先に言ったか・複数の人の都合を合わせて決めたか」の行動で探します。送る型は行動で絞ってPMの名義で、記事を置く型は遅れた案件の一日と立て直した話を、比べられる場は「PMは調整役・板挟み」の体験談に対して企業ページに権限の線と遅れたときの動きを先に書きます。** プロダクトマネージャーは[プロダクトマネージャーの採用媒体の選び方](/media/hikaku-pdm-erabikata/)、ITコンサルタントは[ITコンサルタントの採用媒体の選び方](/media/hikaku-it-consul-erabikata/)で書きました。この記事はプロジェクトマネージャーに絞ります。

## プロジェクトマネージャーの採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「PM候補」「将来のPM」で募集する | 人を動かして回す像で来て、最初の年の実務で離れる | いつからPMかと最初の年を職種名より先に書く。[Wantedlyでプロジェクトマネージャーを採る募集記事の書き方](/media/wt-pjm-boshu/) |
| 「リーダー経験」「主体性」で絞る | 肩書は多いが、予定が崩れたとき立て直したかは分からない | 言葉と肩書を外し、行動で絞る |
| 権限の線が書かれていない | 「板挟みで何も決められない」が体験談に書かれる | 何を、誰と、どこまでの権限で進めるかを書く |
| 遅れたとき誰がどう動くかが書かれていない | 遅れを一人で抱える像で来て離れる。逆に、遅れたとき誰も助けないと知って離れる | 遅れたときの動きを実態で書く |
| 新卒がいつからPMかが書かれていない | PMの募集に見えて、実際は担当者から。「PMで入ったのに違った」 | 入社からか、〇年後か、担当者を経てからかを書く |

## 判断軸を、プロジェクトマネージャーに当てる

| 軸 | プロジェクトマネージャーでの見方 |
|---|---|
| 対象（誰に届くか） | 志望職種と「リーダー経験」の言葉を見ない。「予定が崩れたとき誰に何を頼んで立て直したか・できないと先に言ったか・複数の人の都合を合わせて決めたか」の行動で探す。肩書が無くても、行事の運営やアルバイトのシフトや研究室の共同作業で、崩れた予定を立て直した学生がいる |
| 型（送るか、来るか、比べられるか） | 送る型は、行動で絞ってPMの名義で「あなたの予定が崩れたとき立て直した経験を読んで」と一人に書ける。来る型は、遅れた案件の一日と、立て直した話と、できないと先に言った話を記事で通年で。比べられる型は、「調整役」「板挟み」の体験談に対して、企業ページに権限の線と遅れたときの動きを先に書けるかで |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない |
| 運用工数（誰の時間が要るか） | PMが名義と面談を持つ時間。案件の山場で埋まり、遅れが出ると予定が崩れるので、枠を先に固定し、崩れたときの代わりを決めないと運用が止まる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。プロジェクトマネージャーでは、「対象」を肩書ではなく崩れた予定を立て直した行動で絞ることと、「運用工数」にPM自身の予定が崩れたときの代わりを含めることが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「PMはリーダー経験のある学生に送ればよい。サークルの代表や部長なら、人を動かした経験がある」というものです。当社は3媒体すべての販売パートナーとして、プロジェクトマネージャーの採用の相談を受けますが、肩書で絞った会社は、「代表」「部長」が自由記述に多いわりに、予定が崩れたとき何をしたかが書かれていない学生が多く来て、面談で立て直した話が出ません。肩書は組織から与えられ、行動は本人が選びます。PMの仕事の中心は、予定が崩れたとき、誰に何を頼んで立て直すか、できないことを先に言えるか、複数の人の都合を合わせて決められるかです。この行動は、肩書が無くても書かれていて、肩書があっても書かれていないことがあります。当社が最初にお願いするのは、絞る条件から肩書と「リーダー経験」の言葉を消し、「予定が崩れたとき誰に何を頼んで立て直したか・できないと先に言ったか・複数の人の都合を合わせて決めたか」を「優先する条件」に上げることです。その前に、「新卒がいつからPMか」を決めます。

## 学生が、確かめること

- **新卒がいつからPMか**：入社からか、担当者を〇年経てからか。「PMで入ったのに違った」が最も多く書かれる
- **何を、誰と、どこまでの権限で進めるか**：予算か、人の配置か、納期か、仕様か。決められないことは何か
- **遅れたとき誰がどう動くか**：一人で抱えるか。上司が入るか。客先に誰が言うか
- **最初の年に何を任されるか**：議事録か、進捗の集計か、客先への連絡か、小さな案件の一つか
- **客先とエンジニアの間の立場**：どちらに何を言うか。エンジニアに頼む立場か、指示する立場か

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 行動で絞り、PMの名義で「あなたの予定が崩れたとき立て直した経験を読んで」と一人に書ける | 企業から送る型（OfferBox） | 肩書と志望を見ずに、行動で絞れる。PMを志望していない学生にも届く |
| PMが、遅れた案件の一日と立て直した話を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「調整役」「板挟み」の像を、立て直した記事で置き換える。[Wantedlyでプロジェクトマネージャーにスカウトを送る文面](/media/wt-pjm-scout/) |
| 体験談があり、企業ページに権限の線と遅れたときの動きを先に書ける | 学生が並べて比べる場（ワンキャリア） | 「板挟み」の体験談に対して、入る前に線と動きが分かる会社として読まれる |
| 新卒がいつからPMか、権限の線が決まっていない | どれも先ではない | PMの責任者と決めてから |
| PMの面談の枠と、崩れたときの代わりが決まっていない | どれも先ではない | 案件の遅れで面談が流れ、承認から面談までの間に他社で決まる |

どれか一つが正解ではなく、行動で絞れるか、PMが書けるか、体験談があるかで、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせる**：文面で立て直した経験を読んだ一文を、記事で遅れた案件の一日を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **ITコンサルタント・SIerの構造と重ねる**：[ITコンサルタントの採用媒体の選び方](/media/hikaku-it-consul-erabikata/)、[SIer業界の採用媒体の選び方](/media/hikaku-sier-erabikata/)。客先常駐があるなら、常駐の範囲はここで
- **プロダクトマネージャーと分ける**：[プロダクトマネージャーの採用媒体の選び方](/media/hikaku-pdm-erabikata/)。何を作るかを決めるのがPdM、決まったものを納期までに進めるのがPM。混ぜて募集しない
- **面談の聞き方の型を、揃える**：「肩書より、予定が崩れたとき誰に何を頼んだか、できないと先に言った場面、都合が合わない人の間で何を決めたか」。人事とPMで同じ型
- **内定前に、遅れた案件の記録を見せる**：遅れが出たときの記録と、客先への連絡と、立て直した後の計画を。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)
- **代行と組み合わせるなら、絞る作業と文面の下書きまで。読んで直すのはPM**：[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「PM候補」ではなく、いつからPMで、何をどこまでの権限で進め、遅れたとき誰が動くか

- **「PM候補」「将来のPM」「案件を推進」「リーダーシップ」を消す**：人を動かして回す像で来て、最初の年で離れる
- **新卒がいつからPMかを、最初に**：「入社から小さな案件のPM」か「担当者を〇年経てからPM」か。担当者からなら、担当者の年に何を覚えるかを書く
- **権限の線を、書く**：「納期と人の配置はPMが決める。予算と仕様は〇〇。決められないことは△△」。決められないことを隠さない
- **遅れたときの動きを、実態で**：「遅れが見えたら〇〇に言う。客先への連絡は△△が一緒に。一人で抱えない仕組みは□□」。仕組みが無いなら、無いと
- **最初の年を、時期で**：「最初の〇か月は議事録と進捗の集計と客先への連絡。小さな案件を一つ持つのは△か月目から」。議事録が多いなら、議事録で案件の崩れ方を覚えると、意味を書く

## 社内の分担

| 作業 | 誰が |
|---|---|
| 新卒がいつからPMか、権限の線、遅れたときの動き、最初の年を決める | PMの責任者 |
| PMの面談の枠を案件の山場の外に固定し、崩れたときの代わりを決める | PMの責任者。書く前に |
| 行動で絞る条件 | PMが作り、人事か代行が絞る |
| 文面と記事 | PMが話し、人事が書き、本人が確認 |
| 名義と、オファーの一文 | PM |
| 面談 | PMと人事。聞き方の型を揃えて。肩書と元気の印象で決めない |
| 「思っていたのと違う」の回数の記録 | 人事。権限か、最初の年か、遅れの扱いか、他社かを分けて |

運用代行や代理店が支えられるのは、絞る条件の型、絞る作業、文面の下書き、記録の型までで、いつからPMかの決定、権限の線の決定、名義、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

プロジェクトマネージャーの採用で、当社が媒体より先にお願いしているのは、「遅れたとき誰がどう動くか」を書けるかを確かめることです。これを確かめずに媒体を選び、「案件を推進」の言葉で出すと、効果が出ません。PMの学生が入社後に最も多く離れる理由は、議事録の多さではなく、「遅れを一人で抱えさせられた」ことです。当社は、送り始める前に、PMの責任者と「最近の案件で遅れが出たとき、誰が何をしたか。一人で抱えた例はあるか」を書き出し、仕組みがあるならそれを文面と掲載の最初に、無いなら「無い。作っている途中」と面談で話すことを案内しています。仕組みが無い会社は、それを隠すより、「遅れたとき〇〇に言えば△△が入る」の一文を作ってから送るほうが、立て直した行動を持つ学生が来ます。順番を変えると、体験談に「板挟み」と書かれなくなります。

## まとめ

- 新卒をPMとして採る会社は少なく、「PM候補」で出すと、人を動かして回す像で来て最初の年で離れる。「新卒がいつからPMか」と「何を、誰と、どこまでの権限で進め、遅れたとき誰がどう動くか」を先に決めて書く
- 「リーダー経験」の言葉と肩書で絞らず、「予定が崩れたとき誰に何を頼んで立て直したか・できないと先に言ったか・複数の人の都合を合わせて決めたか」の行動で探す
- 学生が確かめるのは「いつからPMか・何をどこまでの権限で進めるか・遅れたとき誰が動くか・最初の年・客先とエンジニアの間の立場・案件の規模と数」。決められないことと、遅れを一人で抱えさせない仕組みの有無を隠さない
- 送る型（OfferBox）は行動で絞ってPMの名義で、記事を置く型（Wantedly）は遅れた案件の一日と立て直した話を、比べられる場（ワンキャリア）は「板挟み」の体験談に対して企業ページに権限の線と遅れたときの動きを先に
- PMの面談の枠を案件の山場の外に固定し、崩れたときの代わりを先に決める

## よくある質問

### 遅れたときの仕組みがまだありません。書かないほうがよいですか

書かずに入社後に一人で抱えさせるほうが、体験談に「板挟み」と書かれて次の年の学生が離れます。「遅れが見えたら〇〇に言えば△△が入る」の一文を、送る前に作ります。一文が作れないなら、面談で「仕組みは作っている途中。今は〇〇が入る」と実態を話します。隠すより、作ってから送るほうが、立て直した行動を持つ学生が残ります。

### サークルの代表や部長の学生に送っても、面談で立て直した話が出ません

肩書で絞っているからです。肩書は与えられ、行動は本人が選びます。絞る条件から肩書を消し、「予定が崩れたとき誰に何を頼んだか」「できないと先に言った場面」「都合が合わない人の間で何を決めたか」の行動を読んで絞ります。肩書が無い学生の、行事やアルバイトのシフトや研究室の共同作業の記述に、この行動が書かれています。

### プロジェクトマネージャーの媒体選びは、御社に相談できますか

できます。当社は、絞る条件の型、絞る作業、文面の下書き、記録の型を支えられます。いつからPMかの決定、権限の線の決定、名義、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、プロジェクトマネージャーの媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
