OfferBoxで採った内定者は、少し前まで同じ画面でオファーを受け取っていた学生です。どんな文面に反応し、なぜ承認し、どこで迷ったかを、自分の経験として知っています。**結論から言うと、内定者を運用に巻き込むときは、頼むことを「承認した理由を話す」「学生と話す」「文面を読む」の三つに絞り、送信や評価は頼まないことが要点です。** この記事では、巻き込む目的、頼む範囲、手順、内定者への配慮、やりがちな失敗と社内の分担を整理します。文面の読み合わせに絞った進め方は[内定者に文面を手伝ってもらう方法](/media/ob-naiteisha-katsuyou/)で書きました。この記事は、運用全体の中で内定者にどう関わってもらうかです。

## 巻き込む目的｜学生だった側の目を、運用に戻す

人事や現場の社員は、学生がOfferBoxで何を見て、どう判断しているかを、想像するしかありません。内定者は、その判断を経験したばかりです。

内定者に関わってもらう目的は、次の二つです。

- **学生の判断の材料を知る**：承認した理由、迷った理由、他社と比べた点
- **学生と近い距離で話す人を増やす**：面談や座談会で、学生が気軽に話せる相手になる

目的は「人手を増やすこと」ではありません。内定者に作業を任せて人事の負担を減らそうとすると、頼む範囲が広がり、内定者の負担が重くなります。

## 頼む範囲と頼まない範囲

| 頼むこと | 頼まないこと |
|---|---|
| 自分が承認した理由、迷った理由を話す | オファーの送信、管理画面の操作 |
| 座談会や面談の一部で、学生と話す | 学生の評価、合否への意見 |
| 文面のテンプレートを読み、学生の目で感想を言う | 文面を一から書く |
| 企業ページに載せる声を、本人の言葉で寄せる | 学生への個別の連絡 |

管理画面の操作や送信を頼まないのは、内定者の負担を増やさないためと、学生の個人情報を扱う範囲を広げないためです。OfferBoxの利用の範囲については、企業向けの利用規約で確かめておきます。

評価を頼まないのも大切です。内定者が学生の評価に関わると、学生と話すときに内定者が身構え、学生の側も本音を話しにくくなります。

## 手順｜内定者に関わってもらう進め方

1. **頼む範囲を社内で決める**：上の表をもとに、自社で頼むことを決める
2. **内定者に、目的と範囲を説明する**：何のために、何を頼み、何を頼まないか
3. **参加は任意だと伝える**：参加しなくても内定の扱いは変わらないと、はっきり伝える
4. **最初は「承認した理由を話す」から頼む**：短い時間で、一対一で聞く
5. **話してくれた内容を、文面と面談に戻す**：どう活かしたかを、内定者に伝える
6. **座談会や面談に出てもらうなら、事前に話す内容を一緒に決める**：言ってはいけないこと（他の内定者の情報、選考の中身）も伝える
7. **学業の予定に合わせる**：卒業に向けた研究や試験の時期は頼まない

5つ目の「どう活かしたかを伝える」は、内定者が次も協力してくれるかに関わります。話したことがどう使われたか分からないと、協力は一度きりで終わります。

### エージェントベストの見解

内定者を巻き込むとき、契約後によく起きるのは、内定者の声を文面にそのまま載せてしまうことです。「内定者の言葉なら学生に響くはず」と考え、内定者が話した承認の理由を、オファーの文面や企業ページに引用します。ところが、内定者の言葉は、その内定者がその時期に感じたことで、次の卒年の学生に同じように届くとは限りません。引用が増えると、文面が内定者の感想の寄せ集めになり、名義の人がなぜこの学生に送ったのかが見えなくなります。勧めているのは、内定者の声を、文面の材料として使うことです。内定者が「仕事の一日の様子が書いてあったから承認した」と話したなら、引用するのではなく、名義の人が自分の仕事の一日を書き足す。内定者の声は、何を書くべきかを教えてくれるものとして使うと、文面の芯が崩れません。

## 内定者への配慮

内定者は、まだ学生です。関わってもらうときは、次の点に気を配ります。

- **任意であることを繰り返し伝える**：断りにくい立場にあることを、会社の側が意識する
- **時間を短く区切る**：長い拘束をしない
- **学業を優先してよいと伝える**
- **交通費や謝礼の扱いを先に決める**：扱いは会社によって異なる

内定者に関わってもらう内容や時間によっては、労働時間や報酬の扱いなど、法令で定められた項目に関わることがあります。どこまでが任意の協力で、どこからが業務にあたるかは、社労士や公式の案内で確認してから進めます。

内定者へのフォロー全体の考え方は[内定者フォローの進め方](/media/ob-naitei-follow/)にまとめています。運用への協力は、フォローの一部として位置づけ、負担にならない範囲にとどめます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 人手として頼む | 頼む範囲が広がり、内定者の負担が重くなる | 学生の目を借りることに絞る |
| 送信や管理画面の操作を頼む | 個人情報を扱う範囲が広がる | 頼まない |
| 評価に意見を求める | 内定者も学生も本音を話しにくくなる | 評価は頼まない |
| 任意と言いながら実質は義務 | 内定者が不満を抱える | 参加しなくても扱いは変わらないと伝える |
| 内定者の言葉を文面に引用する | 文面が感想の寄せ集めになる | 材料として使い、名義の人が書く |
| 活かし方を伝えない | 協力が一度きりで終わる | どう使ったかを内定者に伝える |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 頼む範囲を決める | 人事 |
| 内定者への説明と依頼 | 人事 |
| 承認した理由を聞く | 人事、または内定者と年の近い若手社員 |
| 文面への反映 | 名義の人と人事（運用代行に出しているなら代行と一緒に） |
| 座談会や面談への同席の調整 | 人事 |
| 交通費や謝礼、時間の扱いの確認 | 人事（社労士に確認） |

承認した理由を聞く役は、人事より、内定者と年の近い若手社員のほうが、内定者が本音を話しやすいことがあります。

### エージェントベストの見解

内定者に関わってもらう前に、先に決めておくべきなのは「内定者から聞いたことを、誰が文面と面談に戻すか」です。内定者の話を聞く場を設けても、聞いた内容を受け取る人が決まっていないと、話は人事の手元に残ったまま使われません。とくに運用代行に出している会社では、内定者から聞いた内容が代行に伝わらず、文面に反映されないことがあります。聞く場を作る前に、聞いた内容を記録する形と、それを文面の担当と面談に出る人に渡す流れを決めておく。運用代行に出しているなら、代行にも同じ記録を渡す。この流れがあって初めて、内定者の協力が次の学生への文面に活きます。現場の社員の巻き込み方は[現場社員を巻き込む方法](/media/ob-genba-makikomi/)にもまとめています。

## まとめ

- 内定者を巻き込む目的は、人手を増やすことではなく、学生だった側の目を運用に戻すこと
- 頼むのは、承認した理由を話す、学生と話す、文面を読むの三つ。送信と評価は頼まない
- 参加は任意と伝え、学業を優先してよいとし、時間を短く区切る
- 内定者の声は引用せず、名義の人が書くための材料として使う
- 聞いた内容を誰が文面と面談に戻すかを、先に決めておく

## よくある質問

### 内定者に座談会に出てもらうとき、何を話してもらえばよいですか

自分が就職活動で何を見て、どう迷い、なぜこの会社を選んだかを、本人の言葉で話してもらいます。会社の良いところを言わせるのではなく、迷ったことも含めて話してもらうほうが、学生に届きます。

### 内定者に協力を頼むと、内定辞退が減りますか

協力が内定者にとって負担でなければ、会社とのつながりを感じる機会になります。ただ、辞退を減らすことを目的に頼むと、内定者に伝わり、逆効果になりがちです。辞退の考え方は[内定辞退を減らす方法](/media/ob-naitei-jitai/)で書きました。

### 先輩社員と内定者、どちらに面談に出てもらうのがよいですか

役割が違います。先輩社員は仕事の具体を、内定者は学生の判断の経験を話せます。先輩社員の出し方は[OB・OGを面談に出す方法](/media/ob-sd-ob-og/)で書いています。
