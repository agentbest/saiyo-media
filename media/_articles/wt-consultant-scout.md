Wantedlyでコンサルタントにスカウトを送るとき、最初にぶつかるのは「出身ファームで検索して『コンサルのご経験を活かして、課題解決を』と送っているのに、返信が来ない。来ても、面談で『常駐はありますか』『案件が無いときはどうなりますか』と聞かれて止まる」という問題です。**結論から言うと、コンサルタントへのスカウトは、出身ファームや肩書で相手を選ぶのではなく、先に自社の領域と関わる範囲と常駐の実態と案件が無い期間の扱いと最初に持ってもらう案件を決め、「近い規模の顧客の、近い領域の課題に提案し、提案の後の実行に関わった経験と、通らなかった提案の扱いを書いている人」を選び、その人の「誰の何の課題に、何を提案して、実行がどうなったか」を読んだ一文から、常駐と案件が無い期間の実態で誘います。** この記事では、コンサルタントがスカウトで見ているもの、送る前に決めること、誰に送るか、文面に書くこと、返信後の面談、社内の分担、やりがちな失敗を整理します。文面の3段の型は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)、募集記事は[コンサルタントを採る募集記事の書き方](/media/wt-consultant-boshu/)で書きました。

## コンサルタントがスカウトで見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰から来たか | 案件の責任者か、経営者か、人事か。送り主が案件を見ている人か |
| 自分の案件の何を読んだか | 出身ファームで検索しただけか、「誰の何の課題に、何を提案して、実行がどうなったか」を読んだか |
| 領域と、関わる範囲 | 経営か業務か仕組みか。提案までか実行までか。文面で分かるか |
| 常駐の実態 | 有無、期間、自社に戻る日。文面で分かるか。盛っていないか |
| 案件が無い期間の扱い | 何をして、給与と評価がどうなるか。文面で分かるか |
| 華やかさで釣っていないか | 「大手企業の経営課題」「急成長」が前面に出ていると、「実態を隠している」と読む |

## 送る前に決めること｜領域、関わる範囲、常駐の実態、案件が無い期間、最初の案件

送る前に、責任者が五つを決めます。決め方は[コンサルタントを採る募集記事の書き方](/media/wt-consultant-boshu/)で書きました。

- **領域を一つに**：経営／業務改善／仕組みの導入／人事・組織／財務／特定の業種。最初に任せる領域
- **関わる範囲**：提案まで／実行まで／実行の管理まで。実行するのは誰か
- **常駐の実態**：無い／ある。あるなら期間と頻度と自社に戻る日。盛らない前提で
- **案件が無い期間の扱い**：何をして、給与と評価がどうなるか。隠さない前提で
- **最初に持ってもらう案件**：「〇〇の業種の△△の規模の会社の、□□が回っていない案件」を一つ。顧客が特定されない形で。これが文面の2段目になり、送る相手を「その案件を持てる人」に絞れる

## 誰に送るか｜出身ファームや肩書ではなく、顧客の規模と領域、実行に関わった経験、通らなかった提案の扱いの重なり

出身ファームや「コンサルタント」の肩書で選ぶと、面談で「顧客の規模が違う」「提案して終わりの経験しか無い」になります。選ぶ基準は、「近い規模の顧客の、近い領域の課題に提案し、提案の後の実行に関わった経験と、通らなかった提案の扱いを書いているか」です。

| 読む箇所 | 重なりの見方 |
|---|---|
| 顧客の規模と、領域 | 大きな会社か、小さな会社か。経営か業務か仕組みか。自社の顧客と領域と近いか。ここが最も重なりが要る |
| 提案の後、実行に関わったか | 「提案して、実行まで顧客と一緒にやった」「実行が止まった理由を見つけて動かした」が書かれているか。自社の関わる範囲と合うか |
| 通らなかった提案の扱い | 「通らなかった理由を聞いて、次を変えた」が書かれているか。提案が通らない場面を扱える人か |

「実行に関わった経験」と「通らなかった提案の扱い」が要点です。自社が実行まで関わるなら、この記述のある人を優先します。

### 出身と肩書の幅に配慮する

コンサルタントの仕事は、「コンサルタント」「経営企画で社内の課題を解決してきた人」「事業会社で改善を回してきた人」「営業で顧客の課題に提案してきた人」「一人で顧問業をしている人」など、違う肩書で書かれています。出身ファームで検索すると、自社の顧客の規模と領域に合う人を落とします。「誰の何の課題に、何を提案して、実行がどうなったか」で読み、出身と肩書は「あればよい条件」に置きます。絞り方の基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「コンサルタントには、出身ファームで絞って、案件の華やかさで誘えば返信が来る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトを見ていますが、コンサルタントが返信した文面を並べると、出身ファームの一致と「大手企業」「急成長」の言葉は、返信の有無とほとんど関係がありません。関係があるのは、「自分の提案と、その後の実行を読んでくれたか」と、「常駐と案件が無い期間の実態が文面で分かるか」の二つです。「〇〇の規模の会社の□□の課題。常駐は無く週に一度顧客先。案件が無い期間は提案の準備で、給与は変わらない」と書かれていれば、「実態が書かれている会社」として返信が来ます。当社が対象を組み直すとき、最初にやるのは、検索条件から出身ファームを外し、「実行に関わった経験を書いている人」で並べ直し、華やかさの言葉を消して、常駐と案件が無い期間を文面の最初のほうに入れることです。

## 文面に書くこと

文面の型（相手の一文→自社の場面→話す場の案内）は[ビジネス職向けスカウト文面の型](/media/wt-scout-bunmen-rei-biz/)に書いたので、ここではコンサルタント特有の要点だけを書きます。

- **相手の一文は、提案と実行で**：「〇〇の課題に△△を提案して、実行が止まった理由を見つけて動かされたと書かれていたのを読んで」「通らなかった提案の理由を聞いて次を変えられたと書かれていた点を読んで」。出身ファームや案件数ではなく、判断
- **領域と関わる範囲を、最初のほうで**：「〇〇の業種の△△の規模の会社の、業務の課題です。提案から実行まで、顧客と一緒に手を動かします」
- **常駐の実態を、一文で**：「常駐は無く、週に一度顧客先に行きます」「〇〇の期間は週に△△日顧客先で、それ以外は自社です」。盛らない
- **案件が無い期間の扱いを、一文で**：「案件の間は提案の準備と社内の型づくりで、給与は変わりません」。隠さない
- **最初の案件を、一文で**：「最初の月は、〇〇の案件に同席するところから」。募集記事と同じ言葉
- **売る責任を、一文で**：「案件は営業が取ります」「自分で提案した案件は、評価に加えます」
- **話す場は、案件の責任者と**：「案件の責任者の〇〇が、常駐と案件が無い期間の実態と、うまくいかなかった案件の話を隠さずします。転職を決めていなくても構いません」

相手の前の案件の結果を評価しません。

## 返信後の面談｜責任者が、案件の実態を話す

| 話すこと | 中身 |
|---|---|
| 常駐と、案件が無い期間の実態 | 期間、頻度、戻る日。案件の間に何をして、給与と評価がどうなるか。文面と同じことを、責任者本人が話す。「聞いていない」を出さない |
| 最初に持ってもらう案件の状態 | 顧客が特定されない形で、いまの状態と、詰まっているところ |
| 相手ならどう提案するか | 最初の案件について、相手の考えを聞く。ここが長い面談ほど次につながる |
| うまくいかなかった案件 | 「提案は通ったが実行が止まった」「通らなかった提案があった」。うまくいった話だけにしない |
| 相手の案件の話 | 誰の何の課題に、何を提案して、実行がどうなったか。聞く時間を長く |

面談には、案件の責任者が出ます。面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

選考に進むとき、「この課題にどう提案するか考えてほしい」のような課題を出すなら、面談のときに「課題がある」「どのくらいの時間がかかるか」「対価の有無」を先に伝えます。伝え方は[カジュアル面談から選考に進むときの伝え方](/media/wt-scout-senkou-ikou/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 領域、関わる範囲、常駐の実態、案件が無い期間、最初の案件を決める | 案件の責任者と経営者 |
| 「顧客の規模と領域、実行に関わった経験、通らなかった提案の扱い」で対象を並べ直す | 人事（責任者が基準を伝える） |
| 相手の提案と実行を読み、一文を書く | 責任者（または人事が下書きし、責任者が確認） |
| うまくいかなかった案件の例の確認 | 責任者 |
| 型、送信、返信対応、台帳 | 人事 |
| 面談 | 案件の責任者 |

一人目のコンサルタントを採るスカウトでは、いま経営者が自分で案件を見ていることが多くあります。その場合は、経営者が相手のプロフィールを読み、「一人目で、いまは私が全案件を見ている。最初は〇〇の案件に同席から。常駐は無い。案件が無い期間は△△」と正直に文面に書きます。

運用代行や代理店が支えられるのは、対象の並べ直しの基準づくり、型、避ける言葉のチェック、募集記事との整合の確認までで、常駐と案件が無い期間の実態、相手の提案を読んだ一文、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

コンサルタントにスカウトを送る前に、先に決めておかないと効果が出ないのは、「うまくいかなかった案件を、隠さず一つ言えるようにすること」です。当社がWantedlyのコンサルタント向けスカウトを支えるとき、「失敗した案件の話は、信用に関わるので書きたくない」という会社が多くあります。ただ、うまくいった案件しか無い文面は、コンサルタントには「実態を隠している」か「案件が少ない」と読まれて開かれません。逆に、「前に〇〇の案件で、提案は通ったが実行が止まった。理由は△△で、□□に変えて動かした」と書いた会社は、返信の数は減っても、提案の後まで責任を持ってきた人が来て、面談で「実態を聞いていない」になる人がいなくなります。当社が最初にお願いするのは、対象の絞り込みではなく、責任者に「前に実行が止まった案件と、どう動かしたか、または動かせなかったか」を一つ、隠さず言ってもらうことです。その一つが、文面の信用を決めます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 出身ファームや肩書で相手を選ぶ | 面談で「顧客の規模が違う」「提案して終わりの経験だけ」 | 顧客の規模と領域、実行に関わった経験で選ぶ |
| 「コンサルのご経験を活かして、課題解決を」と送る | 開かれない | 相手の提案と実行を読んだ一文で |
| 華やかさで誘う | 「実態を隠している」と疑われる | 顧客の規模と課題を、盛らずに |
| 常駐と案件が無い期間を書かない | 「後から出る」を想像される | 実態を最初のほうで書く |
| うまくいった案件だけ書く | 「案件が少ない」か「隠している」と読まれる | 実行が止まった例を一つ |
| 面談に責任者が出ない | 「案件が無い期間」に答えられない | 責任者が出て、実態を話す |

最も多いのは、「出身ファームで選ぶ」と、華やかさの文面です。

## まとめ

- コンサルタントは、誰から来たか・自分の案件の何を読んだか・領域と関わる範囲・常駐の実態・案件が無い期間の扱い・華やかさで釣っていないか、を文面の段階で見ている
- 送る前に、領域、関わる範囲、常駐の実態、案件が無い期間の扱い（何をして給与と評価がどうなるか）、最初に持ってもらう案件を、責任者が決める。常駐があっても、隠さない
- 誰に送るかは、出身ファームや肩書ではなく、顧客の規模と領域、「実行に関わった経験」「通らなかった提案の扱い」の重なりで。出身と肩書は「あればよい条件」に
- 文面には、相手の提案と実行を読んだ一文、領域と関わる範囲、常駐、案件が無い期間、最初の案件、売る責任を。「課題解決」「大手企業」「急成長」を書かない
- 面談は責任者が出て、常駐と案件が無い期間の実態を話し、うまくいかなかった案件を隠さない

## よくある質問

### 出身ファームで絞ったほうが、質の高い人が来ませんか

出身は「あればよい条件」です。大きなファームの出身でも、大きな会社の経営課題に提案書を出してきた人は、小さな会社の業務の課題に提案して実行まで一緒にやる仕事とは重なりません。「近い規模の顧客に提案し、実行に関わり、通らなかった提案の理由を聞いて次を変えた」を書いている人は、出身と関係なく、自社の領域と重なれば送ります。

### うまくいかなかった案件を文面に書くと、信用を失いませんか

逆です。うまくいった案件しか無い文面は、コンサルタントには「実態を隠している」と読まれます。「前に〇〇の案件で実行が止まった。理由は△△。□□に変えて動かした」と書くと、「提案の後まで見ている会社」として読まれます。動かせなかった案件なら、「動かせなかった。理由は……」と書きます。

### コンサルタント向けのスカウトの対象の絞り込みは、御社に相談できますか

できます。当社は、対象の並べ直しの基準づくり、文面の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。常駐と案件が無い期間の実態、相手の提案を読んだ一文、面談は、社内の責任者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
