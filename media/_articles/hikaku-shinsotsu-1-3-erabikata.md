新卒を1〜3名採る会社が媒体を選ぶとき、最初にぶつかるのは「数を集める前提の媒体を選んで、承認や応募は来たのに、返す時間が無くて止まるか、一人に内定を出して辞退されてゼロになり、『媒体が合わなかった』と翌年に媒体を変える」という問題です。**結論から言うと、新卒1〜3名の会社は、数を集める型ではなく「一人に深く届く型」を選び、媒体は一つ、職種は一つに絞り、承認や応募の数ではなく面談まで来た数で見て、辞退一人でゼロになる前提で内定後の設計を媒体選びと同じ重さで先に決めます。** 初めての会社の選び方は[初めて新卒採用をする会社の採用媒体の選び方](/media/hikaku-hajimete-erabikata/)で書きました。この記事は、採用の経験はあるが人数が1〜3名の会社に絞って、選び方を書きます。

## 新卒1〜3名の会社に、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 採る人数が1〜3名 | 「ゼロか一か」で、一人の辞退で結果が変わる。数の平均が効かない | 数を集める型より、一人に深く届く型。[新卒1〜3名を採る会社のOfferBox運用](/media/ob-shinsotsu-1-3-unyou/) |
| 割ける時間が少ない | 人事が一人か兼務。返す時間が本業に押される | 媒体は一つ、職種は一つ。[人事一人で回せる採用媒体の選び方](/media/hikaku-jinji-hitori/) |
| 同期がいないか、一人か二人 | 学生は「一人で入ること」を気にする | 一人で入ることへの答えを先に書く |
| 先輩の新卒が少ない | 話を聞ける先輩が一人か二人。その人の実態がすべて | 先輩一人の話を、盛らずに |
| 内定後の設計が無い | 内定から入社までの連絡が空き、辞退でゼロになる | 媒体選びと同じ重さで、内定後の連絡の間隔を先に決める |
| 採れなかった年がある | 「媒体が合わなかった」と媒体を変え、型が残らない | 採れなかった年に、型を残す |

## 判断軸を、1〜3名の会社に当てる

| 軸 | 1〜3名の会社での見方 |
|---|---|
| 対象（誰に届くか） | 「一人で入って、この仕事を、この人の下で」に合う学生に絞る。数を広げない。任せる仕事と重なる行動と、一人で動いた記述で |
| 型（送るか、来るか、比べられるか） | 送る型は、一人に向けて書けて、送る数を自分で決められる。来る型は、「なぜ少人数か」を書けるかで届く。比べられる型は、数を集める場で、1〜3名には過剰なことが多い |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。ゼロの年を織り込んで、続けられる額で。[予算が小さい会社の採用媒体](/media/hikaku-yosan-50/) |
| 運用工数（誰の時間が要るか） | 承認や応募に返す時間と、面談の時間と、内定後の連絡の時間。三つを合わせて、本業の合間に入る大きさで。送る型は絞る作業を外に出せる |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。1〜3名の会社では、「対象」を広げないことと、「運用工数」に内定後の連絡の時間を入れることが、他の会社と違います。

### エージェントベストの見解

新卒1〜3名の会社に、向いている媒体と向いていない媒体があります。当社は3媒体すべての販売パートナーとして、少人数の会社の相談を受けますが、「数を集めれば、その中から一人は採れる」の考え方で比べられる場（ワンキャリア）を選んだ会社は、数が来ても返せず、返しても比べられて負け、一人を採る前に時間が尽きます。比べられる場は、学生が並べて選ぶ場で、並べられたときに残る知名度と体験談がある会社に向いています。1〜3名の会社に向いているのは、「一人に向けて書き、送る数を自分で決められる」送る型（OfferBox）と、「なぜ少人数で採るか」を書ける会社の記事を置く型（Wantedly）です。送る型は、承認が来る数を送る数で調整でき、返す時間が本業に押されるときに止められます。当社が最初にお願いするのは、「数を集める」の言葉を外し、「一人に届く」に置き換えて媒体を見ることです。数を集める前提の媒体は、1〜3名の会社には、数が来ること自体が負担になります。

## 学生が、確かめること

- **一人で入ること**：同期がいないか、一人か二人。「一人で入って、誰と話すのか」。答えを先に書く
- **先輩の新卒の実態**：一人か二人の先輩が、最初の年に何をし、いま何をしているか。盛ると、面談で分かる
- **何を任されるか**：少人数の会社は、任せる範囲が広いか、逆に決まっていないか。「最初の年に〇〇を」で
- **誰が見るか**：経営者か、先輩か。その人が面談に出るか。少人数の会社は、見る人との相性がすべて
- **会社が続くか**：小さい会社なら、学生も家族も気にする。事業と取引先で
- **内定後の連絡**：内定から入社まで、放っておかれないか。間隔を決めて、伝える

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 任せる仕事と重なる行動で絞りたい。送る数を自分で決めたい。担当の時間が少ない | 企業から送る型（OfferBox） | 一人に向けて書け、承認の数を送る数で調整できる。絞る作業を外に出せる |
| 経営者か先輩が「なぜ少人数で採るか」を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「一人で入ること」への答えと、先輩一人の実態を記事で読んでもらえる |
| 知名度と体験談があり、並べられても残る | 学生が並べて比べる場（ワンキャリア） | 残れる会社なら。1〜3名では過剰なことが多い |
| 内定後の連絡の間隔が、まだ決まっていない | どれも先ではない | 決めてから。辞退でゼロになる |
| 職種が二つ以上ある | 一つに絞ってから | 二つは、返す時間が足りない |

どれか一つが正解ではなく、書けるか、知名度があるか、担当の時間で、先に検討するものが変わります。

## 組み合わせ

- **媒体は一つ、職種は一つ**：二つ目は、一人目が入ってから。[複数の媒体を同時に使うときの考え方](/media/hikaku-fukusuu-baitai/)
- **送る型と記事を置く型を組み合わせるなら、翌年から**：文面で「一人で入ること」への答えを、記事で「なぜ少人数か」を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **代行と組み合わせるなら、範囲を先に**：絞る作業と文面は外に出せる。面談と内定後の連絡は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)
- **期間は一年で見る**：一人の辞退で三か月の数字は変わる。[一年で見る媒体の期間の考え方](/media/hikaku-kikan-1nen/)

## 見せ方｜「少数精鋭」ではなく、一人で入ることへの答え

- **「少数精鋭」「アットホーム」の一語で済ませない**：学生は「一人で入って、誰と話すのか」を確かめている
- **一人で入ることへの答えを、一段落で**：「同期はいない。最初の年は〇〇が横につき、週に△回、□□と話す時間がある」
- **先輩一人の実態を、盛らずに**：「去年入った〇〇は、最初の年に△△をし、いま□□をしている」。一人しかいないので、面談で本人に会う。盛ると分かる
- **なぜ少人数で採るかを、一文で**：「毎年一人を、〇〇が横について育てる形にしている」。理由が無いと「たまたま」と読まれる
- **内定後の連絡を、先に書く**：「内定から入社まで、〇か月に一度、△△が連絡する」。書くと、辞退が減る
- **会社が続くことを、事業で**：数値は自社の実態で。この記事では書かない

## 社内の分担

| 作業 | 誰が |
|---|---|
| 任せる仕事、見る人、一人で入ることへの答え、内定後の連絡の間隔を決める | 経営者 |
| 媒体を選ぶ | 担当の時間と、書けるかで決める |
| 承認や応募に返す | 人事か兼務の担当。〇日以内と決める。送る型なら送る数で調整 |
| 面談 | 経営者か、見る人 |
| 先輩一人の話 | 本人が話し、担当が書き、本人が確認。面談にも出る |
| 内定後の連絡 | 決めた人が、決めた間隔で。空けない |

運用代行や代理店が支えられるのは、媒体の選び方、絞る作業、文面、内定後の連絡の型づくりまでで、任せる仕事の決定、見る人、面談、内定後の連絡そのものは社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

新卒1〜3名の会社で、媒体を契約した後に起きることを、当社は先にお伝えしています。一人に内定を出し、内定後の連絡が空いて辞退され、ゼロで年が終わる。翌年、「媒体が合わなかった」と媒体を変える。変えた媒体でも、内定後の連絡の設計が無いまま同じことが起きる。当社が見ている少人数の会社で、媒体を変え続けている会社の多くは、媒体ではなく内定後の設計が無いままです。一人の採用は「ゼロか一か」なので、辞退一人が結果のすべてになり、媒体の違いより内定後の連絡の間隔のほうが結果を決めます。逆に、「内定から入社まで〇か月に一度、△△が連絡する。□か月目に会社に来てもらう」と先に決め、掲載にも書いた会社は、同じ媒体で翌年に一人が入ります。当社が案内するのは、媒体を変える前に、「辞退した学生と、内定後の連絡が何回あったか」を数えることです。回数が少ないなら、媒体ではなく連絡の設計を直します。[内定辞退が続くときの見直し方](/media/ob-naitei-jitai/)

## まとめ

- 新卒1〜3名の採用は「ゼロか一か」で、数の平均が効かない。数を集める型ではなく、一人に深く届く型を選ぶ
- 送る型（OfferBox）は一人に向けて書けて送る数で調整でき、記事を置く型（Wantedly）は「なぜ少人数か」を書ける会社に。比べられる場（ワンキャリア）は知名度と体験談があり並べられても残る会社に
- 媒体は一つ、職種は一つ。返す時間と面談の時間と内定後の連絡の時間を合わせて、本業の合間に入る大きさで
- 学生は「一人で入ること・先輩一人の実態・何を任されるか・誰が見るか・内定後の連絡」を確かめる。「少数精鋭」ではなく答えを一段落で
- 辞退一人でゼロになるので、内定後の連絡の間隔を媒体選びと同じ重さで先に決め、媒体を変える前に連絡の回数を数える

## よくある質問

### 一人しか採らないのに、媒体に費用をかける意味はありますか

一人の採用が「ゼロか一か」だからこそ、届く型を選ぶ意味があります。数を集める型に費用をかけると、返せない数が来て止まります。一人に向けて書けて、送る数を自分で決められる型なら、費用と時間を一人に集められます。費用が取れないなら、[予算がほぼ取れない会社の採用媒体](/media/hikaku-yosan-nai/)で書いたとおり、使わない判断もあります。使うなら、一つに絞ります。

### 去年、一人に内定を出して辞退され、ゼロでした。媒体を変えるべきですか

先に、内定から辞退までの連絡の回数を数えます。回数が少ないか、間隔が空いていたなら、媒体ではなく連絡の設計を直します。「〇か月に一度、△△が連絡する。□か月目に会社に来てもらう」と決め、掲載にも書きます。連絡は十分にあったのに辞退されたなら、辞退の理由（仕事の像、見る人との相性、会社が続くかの不安）を聞き、掲載の該当の箇所を直します。媒体を変えるのは、連絡の設計と掲載を直してもなお、届かないときです。

### 新卒1〜3名の会社の媒体選びは、御社に相談できますか

できます。当社は、媒体の選び方、絞る作業、文面、内定後の連絡の型づくりを支えられます。任せる仕事の決定、見る人、面談、内定後の連絡そのものは、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、少人数の会社の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
