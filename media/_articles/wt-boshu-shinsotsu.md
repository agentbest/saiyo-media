Wantedlyで新卒向けの募集記事を書くとき、中途向けの募集記事をそのまま「新卒」に変えて出す会社があります。ところが、新卒の読み手は、その職種で働いた経験が無く、「何をやるか」を読んでも想像できません。**結論から言うと、新卒向けの募集記事は「なにを・なぜ・どうやって」の型は同じでも、書く中身を「最初の1年で何をやるか」「誰がどう教えるか」「入社してまもない人の話」に寄せ、職種経験が無い読み手が想像できる言葉で書きます。「総合職」で職種をぼかす、「成長できる」で終わる、中途向けの流用、が新卒に届かない書き方です。** この記事では、新卒の読み手の違い、やりがちな失敗、書く要素、学生の言葉で書くこと、インターンや説明会との関係、年度の公表内容、分担を整理します。募集記事の基本は[募集記事の基本](/media/wt-boshu-kihon/)で書きました。新卒と中途で媒体をどう分けるかは[新卒と中途で媒体を分ける考え方](/media/hikaku-shinsotsu-vs-chuuto-baitai/)で書きました。

## この作業の目的｜職種経験が無い読み手に、働く自分を想像させる

中途の読み手は、「営業」「エンジニア」と書けば、自分の経験から仕事を想像できます。新卒の読み手は、職種名だけでは想像できません。「営業とは何をする仕事か」から分からないことも普通です。

新卒向けの募集記事の目的は、「この職種で働いたことが無い人が、入社後の自分を想像できる」ことです。想像できれば、「話を聞きに行く」を押します。想像できなければ、「なんとなく良さそう」で終わり、動きません。

## やりがちな失敗

| 失敗 | 新卒の読み手からどう見えるか |
|---|---|
| 中途向けの募集記事を「新卒」に変えて流用 | 「経験を活かして」と書いてあり、自分向けではない |
| 「総合職」「幅広い業務」で職種をぼかす | 何をする仕事か分からない |
| 「成長できる環境」「若手が活躍」で終わる | どの会社にも書いてある |
| 会社の事業の説明が長い | 自分が何をするかにたどり着かない |
| 「求める人物像」が抽象的（主体性・コミュニケーション力） | 自分が当てはまるか分からない |
| 教える仕組みが書いていない | 「入ってすぐ放置されるのでは」と不安になる |
| 最初の1年の話が無い | 数年後の話をされても想像できない |
| 選考の流れが無い | 話を聞きに行った先に何があるか分からない |

最も多いのは、最初の「中途向けの流用」です。「なにを」の部分が、経験者向けの言葉のまま残ります。

## 書く要素

新卒向けの募集記事に入れる要素を、「なにを・なぜ・どうやって」に沿って並べます。

| 要素 | 書き方 |
|---|---|
| なにを（最初の1年で何をやるか） | 職種名ではなく、最初の月、最初の3か月、1年目の終わりに何をしているかを、順に。「最初の月は先輩の商談に同行し、3か月目に小さな案件を1人で持ち、1年目の終わりには〇〇をしている」のように |
| なぜ（なぜ新卒を採るのか） | 「若い力」ではなく、なぜ経験者ではなく新卒なのか。「〇〇の仕事は、うちのやり方を最初から身につけた人のほうが向いている」のように。書き方は[「なぜ」の書き方](/media/wt-boshu-naze/) |
| どうやって（誰がどう教えるか） | 教える人がいるか、どう教えるか、詰まったときに誰に聞くか。「研修があります」ではなく、最初の月に誰と何をするか |
| 一緒に働く人 | 入社してまもない人の話へ誘導する。「入る前と後」の記事。書き方は[入社エントリーを書いてもらう方法](/media/wt-story-nyusha/) |
| こんな人 | 経験ではなく、学生時代に何をしていた人か、何が好きな人か。「〇〇のような経験がある人」ではなく「〇〇が好きな人」「△△で困った人」 |
| 条件 | 初任給の範囲、勤務地、勤務時間、休日。新卒は条件を比べる。書き方は[条件の書き方](/media/wt-boshu-joukenn/) |
| 選考の流れ | 話を聞きに行ったあと、何があるか。面談、説明会、選考の順 |

「最初の1年で何をやるか」が中心です。数年後のキャリアより、最初の月の話のほうが、新卒の読み手には具体的です。

### エージェントベストの見解

相談で最も多い思い込みは、「新卒向けは、会社の魅力を伝えるのが先で、仕事の細かい話は面談で」というものです。当社は3媒体すべての販売パートナーとして、新卒の候補者がWantedlyの募集記事をどう読むかを面談で聞いてきましたが、話を聞きに来た学生が挙げるのは、会社の魅力ではなく「最初の月に何をするかが書いてあった」「教える人が誰か分かった」という部分です。学生は、会社の魅力を語る記事をたくさん読んでいて、比べられません。「最初の月に先輩の商談に同行する」と書いてある記事は少なく、それが比べる材料になります。当社が新卒向けの募集記事を整えるとき、最初に足すのは「最初の1年」の段落です。会社の魅力は会社ページに書いてあり、募集記事に書くのは仕事の最初です。

## 学生の言葉で書く

新卒の読み手は、業界の言葉と社内の言葉を知りません。

- **業界用語を使わない**：使うなら、一言で説明を添える
- **職種名を、仕事の中身で言い換える**：「法人営業」→「企業のお客さまに、〇〇を提案する仕事」
- **社内の言葉を使わない**：部署名、制度の略称、社内でしか通じない呼び方
- **「学生時代に〇〇だった人が」と、読み手の状態から書く**：「主体性のある人」ではなく「サークルで企画を立てたことがある人」「アルバイトでお客さまと話すのが好きだった人」
- **数年後より、最初の月**：「将来はマネジメントも」より「最初の月は」

書いたら、社内の新卒入社の人に読んでもらい、「入る前の自分に分かったか」を聞きます。分からない言葉があれば、直します。

## インターンや説明会との関係

新卒の募集記事は、単独で完結しないことが多くあります。

- **インターンの募集がある場合**：新卒の募集記事から、インターンの募集記事へ誘導する。「まず仕事を体験したい人はこちら」。インターンの募集記事の書き方は[インターン募集記事の書き方](/media/wt-boshu-intern/)
- **説明会やミートアップがある場合**：募集記事から誘導し、募集記事の「最初の1年」をその場で詳しく話す。企画は[ミートアップの企画の立て方](/media/wt-meetup/)
- **他の新卒媒体と併用している場合**：Wantedlyの募集記事は「話を聞きに行く」の入口で、選考は他の媒体や採用サイトで、という分担を書く。OfferBoxとの併用は[OfferBoxとWantedlyの違い](/media/hikaku-offerbox-wantedly/)、ワンキャリアとの併用は[ワンキャリアとWantedlyの違い](/media/hikaku-onecareer-wantedly/)

「話を聞きに行く」の先に何があるかを、募集記事に書いておきます。新卒の読み手は、その先が分からないと動きません。

## 年度の公表内容を確認する

新卒の募集は、年度ごとに、選考の時期や広報の扱いについて公表される内容があります。募集記事に書く時期や選考の流れは、その年度の公表内容と、自社の方針を確認したうえで書きます。この記事では、時期や流れの具体は書きません。年度で変わるものは、書く時点で確かめるのが確かな方法です。

Wantedlyの募集の区分（新卒、中途、インターンなど）の設定や、掲載の条件も変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 最初の1年で何をやるかを聞く | 人事（その職種の責任者と、新卒入社の人に） |
| なぜ新卒を採るのかを決める | 代表と責任者 |
| 誰がどう教えるかを書く | 人事（教える人に確認） |
| 学生の言葉に直す | 人事（新卒入社の人に読んでもらう） |
| 条件と選考の流れ | 人事（年度の公表内容と自社の方針を確認） |
| 入社してまもない人の記事 | 人事が本人に頼む |
| 面談で、記事のとおりに話す | 面談に出る人 |

運用代行や代理店が支えられるのは、新卒向けの要素の型、聞く質問、学生の言葉への直し、他媒体との分担の整理までで、最初の1年の中身、教える仕組み、条件の決定、年度の確認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは、向く会社と向かない会社がはっきり分かれます。Wantedlyで新卒向けの募集記事が機能するのは、「最初の1年に何をするかが決まっていて、教える人がいる会社」です。当社が3媒体の販売パートナーとして新卒採用の相談を受ける中で、「新卒を採りたいが、入ってから何をしてもらうかはまだ決めていない」という会社があります。この状態で募集記事を書くと、「成長できる環境」しか書けず、学生には届きません。逆に、最初の月に誰と何をするかが決まっている会社は、それを書くだけで、他の会社の記事と比べられます。当社は、新卒向けの募集記事を書く前に、「最初の月、3か月、1年目の終わり」を責任者に聞き、答えが出なければ、記事より先にそこを決めることをお願いしています。

## まとめ

- 新卒の読み手は職種経験が無い。「最初の1年で何をやるか」「誰がどう教えるか」を、想像できる言葉で書く
- 中途向けの流用、「総合職」でぼかす、「成長できる」で終わる、は届かない
- なにを（最初の月・3か月・1年目）、なぜ（なぜ新卒か）、どうやって（誰が教えるか）、一緒に働く人（入社してまもない人の話）、こんな人（学生時代の状態）、条件、選考の流れ
- 業界用語と社内の言葉を使わず、新卒入社の人に「入る前の自分に分かったか」を聞く
- インターン・説明会・他の新卒媒体との分担を書き、時期や流れは年度の公表内容と自社の方針を確認して書く

## よくある質問

### 職種を決めずに、総合職として採りたいです

職種を決めなくても、「最初の1年で何をやるか」は書けます。「最初の半年は〇〇と△△を経験し、その後に配属を決める」のように、最初の動きを具体的に書きます。「総合職」という言葉だけでは、学生は何をするか分かりません。

### 新卒向けと中途向けで、募集記事を分けるべきですか

分けます。同じ職種でも、読み手が違えば「なにを」の書き方が変わります。中途向けは「これまでの経験をどう使うか」、新卒向けは「最初の1年で何をやるか」です。1本にまとめると、どちらにも届きません。複数の募集の分け方は[募集記事を複数出す考え方](/media/wt-boshu-fukusu/)で書きました。

### 新卒向けの募集記事は、御社に相談できますか

できます。当社は、新卒向けの要素の型、聞く質問、学生の言葉への直し、他媒体との分担の整理を支えられます。最初の1年の中身と教える仕組み、条件の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、新卒採用の媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
