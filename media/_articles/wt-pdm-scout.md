Wantedlyでプロダクトマネージャーにスカウトを送るとき、最初にぶつかるのは「肩書で検索して『裁量を持ってプロダクトを推進してほしい』と送っているのに、返信が来ない。来ても、面談で『何を決められるのですか』と聞かれて止まる」という問題です。**結論から言うと、プロダクトマネージャーへのスカウトは、肩書の一致で相手を選ぶのではなく、先に経営者が権限の線引きと「いま迷っていること」を決め、「同じ段階のプロダクトを、同じ種類の利用者のために持っていて、何かを作らないと決めた人」を選び、その人が決めたことを読んだ一文から、経営者の名前で「いま迷っていること」の場面で誘います。** この記事では、プロダクトマネージャーがスカウトで見ているもの、送る前に決めること、誰に送るか、文面に書くこと、返信後の面談、社内の分担、やりがちな失敗を整理します。文面の基本は[スカウト文面の書き方](/media/wt-scout-bunmen/)、募集記事は[プロダクトマネージャーを採る募集記事の書き方](/media/wt-pdm-boshu/)で書きました。

## プロダクトマネージャーがスカウトで見ているもの

| 見ているもの | 何を確かめているか |
|---|---|
| 誰から来たか | 経営者か、開発の責任者か、人事か。経営者からなら、その人がプロダクトをどう見ているか |
| 自分の何を読んだか | 肩書で検索しただけか、決めたことや作らないと決めたことを読んだか |
| 決められる範囲 | 何を決められて、何を経営者が決めるか。文面で分かるか |
| 経営者との距離 | 経営者がプロダクトをどこまで見ていて、意見が分かれたらどうなるか |
| いま何に迷っているか | 会社説明ではなく、いま決めようとしていることが書かれているか |
| 話す場か、応募の依頼か | 迷っていることを一緒に考える場か、応募を求められているのか |

「誰から来たか」が最初です。プロダクトマネージャーへのスカウトは、送り主が経営者であることで、開かれる率と面談のつながりが変わります。経営者の名前で送る方法は[代表の名前でスカウトを送る方法](/media/wt-scout-daihyo/)で書きました。

## 送る前に決めること｜権限の線引きと、いま迷っていること

送る前に、経営者が二つを決めます。

- **権限の線引き**：何を任せて、何を経営者が最後に決めるか。意見が分かれたときの決め方。決め方は[プロダクトマネージャーを採る募集記事の書き方](/media/wt-pdm-boshu/)で書きました
- **いま迷っていること**：「〇〇と△△のどちらを先に作るか、いま迷っている」を一つ。これが文面の2段目になり、送る相手を「その迷いに意見を持てる人」に絞れる

「いま迷っていること」は、経営者本人の言葉で一文にします。人事が整えた「プロダクトの成長戦略」ではなく、「正直、〇〇を切るべきか決めきれていない」のような、生の迷いです。

## 誰に送るか｜肩書の一致ではなく、段階と利用者、決めたことの重なり

肩書が「プロダクトマネージャー」で一致していても、持っていたプロダクトの段階と利用者の種類が違えば、面談で「うちの段階とは違う」になります。選ぶ基準は、「同じ段階のプロダクトを、同じ種類の利用者のために持っていて、何かを作らないと決めたことがあるか」です。

| 読む箇所 | 重なりの見方 |
|---|---|
| プロダクトの段階 | 作り始めを持ったか、伸びている段階を持ったか、伸びが止まって見直す段階を持ったか。自社のいまの段階と重なるか |
| 利用者の種類 | 企業の担当者向けか、個人向けか。利用者に直接会える種類か。自社と近いか |
| 何を決めたか | 「〇〇を先に作ると決めた」「△△を作らないと決めた」が書かれているか。決めた理由が書かれているか |
| 誰と決めたか | 経営者と直接か、エンジニアと一緒か、依頼を受けて整理する側か。自社の線引きと合うか |
| 数字で取り下げた経験 | 「数字を見て、決めていたことを変えた」が書かれているか |
| 書いているもの | プロダクトの判断についての記事。あれば、何を大事にする人かが分かる |

「何を作らないと決めたか」が要点です。「作ったもの」は多くの人が書きますが、「作らないと決めたものと、その理由」を書いている人は、決める仕事をしてきた人です。

### 肩書がプロダクトマネージャーでない人も読む

プロダクトマネージャーの仕事は、肩書が違う人が担っていることが多くあります。「事業責任者」「企画」「開発の責任者」「経営者の右腕」「一人で作って売っている人」。肩書で検索すると、これらの人を落とします。「何を作るかを決めて、作らないと決めた」記述で読み、肩書は「あればよい条件」に置きます。絞り方の基本は[スカウト対象の絞り方](/media/wt-scout-target/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「プロダクトマネージャーは肩書で検索して、裁量の大きさを見せれば返信が来る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトを見ていますが、プロダクトマネージャーが返信した文面を並べると、肩書の一致と「裁量」の一語は、返信の有無とほとんど関係がありません。関係があるのは、「経営者本人から来たか」と、「経営者がいま迷っていることが、生の言葉で書かれているか」の二つです。人事の名前で「裁量を持って推進」と送った文面は開かれず、経営者の名前で「正直、〇〇を切るべきか決めきれていない。あなたが△△を作らないと決めた理由を読んで、意見を聞きたい」と送った文面は、肩書が違う人からも返信が来ます。当社が対象を組み直すとき、最初にやるのは、検索条件から肩書を外し、「何を作らないと決めた人か」で並べ直し、経営者に「いま迷っていること」を一文で言ってもらうことです。

## 文面に書くこと

文面の型（相手の一文→自社の場面→話す場の案内）は[スカウト文面の書き方](/media/wt-scout-bunmen/)に書いたので、ここではプロダクトマネージャー特有の要点だけを書きます。

- **相手の一文は、決めたことで**：「〇〇を作らないと決めた理由を書かれていたのを読んで」「△△の段階で□□を先に作ると決められた点を読んで」。肩書ではなく、決めたこと
- **送り主は経営者で、経営者の言葉で**：人事が整えた文にしない。「正直、〇〇で迷っている」の言い方をそのまま
- **権限の線引きを、最初のほうで**：「優先順位と機能の中身は任せたい。事業の方向と価格は私が決める。分かれたら話し合って、最後は私が決める」。隠さない
- **いま迷っていることを、一つ**：「〇〇と△△のどちらを先に作るか、いま迷っている。あなたならどう決めるか聞きたい」。会社説明ではなく、迷い
- **前に決めたことの例を、一つ**：「前に〇〇を切って、△△が変わった」。無ければ書かない
- **話す場は、経営者本人と**：「私が、いま迷っていることを話します。転職を決めていなくても、意見を聞かせてもらえるだけで構いません」

「推進」「裁量」「全権」「右腕」は書きません。相手の前の会社のプロダクトを評価しません。

## 返信後の面談｜経営者が、迷っていることを話す

| 話すこと | 中身 |
|---|---|
| いま迷っていることを、経営者が話す | 文面に書いた迷いの詳細。判断の材料を見せる。相手ならどう決めるかを聞く。ここが長い面談ほど次につながる |
| 権限の線引きの確認 | 何を任せて、何を経営者が決めるか。文面と同じことを経営者本人が話す。「聞いていない」を出さない |
| 意見が分かれた例 | 「前に〇〇で分かれて、△△の形で決めた」。隠さない |
| 開発の責任者が出る | エンジニア・デザイナーとの関係が、言葉でなく実際に伝わる |
| 相手の決めたことの話 | 相手が何を決めて、何を作らないと決めて、どうなったか。聞く時間を長く |

面談には、経営者と開発の責任者が出ます。経営者が出ない面談は、「経営者との距離」が伝わらず、プロダクトマネージャーの面談としては成り立ちません。面談の設計は[カジュアル面談の設計](/media/wt-scout-casual-mendan/)で書きました。

選考に進むとき、「このプロダクトの次の一手を考えてほしい」のような課題を出すなら、面談のときに「課題がある」「どのくらいの時間がかかるか」を先に伝えます。伝え方は[カジュアル面談から選考に進むときの伝え方](/media/wt-scout-senkou-ikou/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 権限の線引きと、いま迷っていることを一文にする | 経営者 |
| 「段階と利用者、決めたこと」で対象を並べ直す | 人事（経営者が基準を伝える） |
| 相手の決めたことを読み、一文を書く | 経営者（または人事が下書きし、経営者が自分の言葉に直す） |
| 型、送信、返信対応、台帳 | 人事 |
| 面談 | 経営者と、開発の責任者 |

経営者の時間を、「線引きと迷いを一文にする」「読んで一文を書く」「面談」に限ると続きます。並べ直し、型、送信、台帳は人事が持ちます。人事が下書きする場合も、経営者が自分の言葉に直してから送ります。人事の整えた文は、プロダクトマネージャーには「経営者が書いていない」と分かります。

運用代行や代理店が支えられるのは、対象の並べ直しの基準づくり、型、避ける言葉のチェック、募集記事との整合の確認までで、権限の線引き、いま迷っていることの一文、相手の決めたことを読んだ一文、面談は経営者が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、「いま迷っていること」の一文と、相手の決めたことを読んだ一文までです。当社がWantedlyのプロダクトマネージャー向けスカウトを支えるとき、型、対象の基準、避ける言葉、募集記事との整合は当社が出せます。ただし、「正直、〇〇を切るべきか決めきれていない」という迷いは、経営者本人にしか書けません。当社がそれらしい迷いを作れば、プロダクトマネージャーには「経営者が書いていない」と一目で分かります。ここを外に出すと、文面は「裁量を持って推進」に戻り、返信は来ません。当社が最初にお願いするのは、経営者に「いま一番決めきれていないことは何か」を、飾らずに一文で言ってもらうことです。その一文があれば、当社は型に組み込み、線引きと募集記事を揃えて、送れる形にします。無ければ、対象をどう絞っても、文面は届きません。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 肩書の一致で相手を選ぶ | 肩書が違う「決めている人」を落とす | 決めたこと、作らないと決めたことで選ぶ |
| 人事の名前で「裁量を持って推進」と送る | 開かれない | 経営者の名前で、迷っていることを生の言葉で |
| 権限の線引きを文面で隠す | 面談で「実は経営者が決める」と出て離れる | 最初のほうで、狭くても隠さず書く |
| 会社説明を書く | 「迷い」が無く、話す理由が無い | いま決めようとしていることを一つ |
| 面談に経営者が出ない | 「経営者との距離」が伝わらない | 経営者が出て、迷っていることを話す |
| 課題を後から出す | 「聞いていない」で離れる | 面談で先に伝える |

最も多いのは、最初の「肩書の一致で選ぶ」です。検索の条件がそのまま文面の言葉になり、相手には「検索しただけ」と分かります。

## まとめ

- プロダクトマネージャーは、誰から来たか（経営者か）・自分の何を読んだか・決められる範囲・経営者との距離・いま何に迷っているか、を文面の段階で見ている
- 送る前に、経営者が権限の線引きと「いま迷っていること」を、生の言葉で一文にする
- 誰に送るかは、肩書の一致ではなく、プロダクトの段階と利用者の種類、「何を作らないと決めたか」の重なりで。肩書が違う「決めている人」を落とさない
- 文面は経営者の名前で、相手の決めたことを読んだ一文、線引き、迷っていること、前に決めた例を。「推進」「裁量」「全権」を書かない
- 面談は経営者が出て、迷っていることを話し、相手ならどう決めるかを聞く。意見が分かれた例を隠さない

## よくある質問

### 経営者が忙しく、文面を書く時間がありません

頼むのは「いま一番決めきれていないことは何か」の一文と、送る前に人事の下書きを自分の言葉に直すことだけです。並べ直し、型、送信、台帳は人事が持ちます。経営者の時間は、一文を言うことと、直すことと、面談だけになります。ただし、経営者の名前で送る以上、経営者が読んでいない文面を送らないでください。

### 肩書が「プロダクトマネージャー」の人が、検索でほとんど出ません

肩書で絞る必要はありません。プロダクトマネージャーの仕事は、「事業責任者」「企画」「開発の責任者」「一人で作って売っている人」が担っていることが多くあります。「何を作るかを決めて、何かを作らないと決めた」記述で読み、その人に「〇〇を作らないと決めた理由を読んで」と送ります。肩書が違う人からのほうが、返信が来ることもあります。

### プロダクトマネージャー向けのスカウトの対象の絞り込みは、御社に相談できますか

できます。当社は、対象の並べ直しの基準づくり、文面の型、避ける言葉のチェック、募集記事との整合の確認を支えられます。権限の線引き、いま迷っていることの一文、相手の決めたことを読んだ一文、面談は、経営者が担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
