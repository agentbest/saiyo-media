OfferBoxは、企業が学生を選んでオファーを送る媒体です。選ぶ基準が人事の頭の中にしか無いと、送る相手も文面も、現場の面接で「思っていた学生と違う」とひっくり返ります。**結論から言うと、運用を始める前に、人事と現場で一度だけ「採用要件を決める打ち合わせ」を持ち、要件を1枚のメモにして終えるのが近道です。** この記事では、その打ち合わせを、呼ぶ人、事前の準備、議題の順番、決めることと保留にしてよいこと、終わったあとの扱いの順で整理します。要件の中身そのものの考え方は[OfferBoxのターゲット設計](/media/ob-target-sekkei/)と[採りたい学生像の作り方](/media/ob-persona/)で書きました。この記事は、それを社内で決める「場」の作り方です。

## この打ち合わせの目的｜要件を「人事の案」から「社内の合意」にする

打ち合わせの目的は、良い要件を作ることより、要件に現場が合意している状態を作ることです。

人事が1人で要件を書いても、内容は間違っていないことが多いです。ただ、現場の面接官が知らない要件は、面接の段で使われません。結果として、オファーでは「挑戦する姿勢」を見て送り、面接では「即戦力の知識」で落とす、というずれが起きます。

打ち合わせで決まると、次の三つが揃います。

- **送る相手の基準**：検索条件と、プロフィールを読むときの見どころ
- **文面に書く仕事の中身**：最初の1年に何をするか
- **面接で見ること**：段階ごとに何を確かめるか

この三つが同じ言葉でつながっていれば、オファーから内定までの判断がぶれにくくなります。

## 手順1｜呼ぶ人を決める

人数を増やすほど決まりにくくなります。決める権限がある人と、実際に一緒に働く人を呼びます。

| 呼ぶ人 | 役割 |
|---|---|
| 人事の担当 | 進行と記録。案を用意する |
| 配属先の責任者 | 要件を決める。最後に「これで行く」と言う人 |
| 配属先の若手社員 | 入社1〜2年目の実態を話す。名義や面談を頼む候補 |
| 経営（必要な場合だけ） | 採用人数や方針に関わるときだけ。最初から呼ばなくてよい |

若手社員を呼ぶのは、責任者が思う「最初の1年」と、実際の最初の1年が違うことがあるからです。現場の協力を継続して得る方法は[現場社員を巻き込む方法](/media/ob-genba-makikomi/)で書きました。

## 手順2｜事前に持ち寄るものを依頼する

打ち合わせの場で考え始めると、時間内に決まりません。事前に材料を集めます。

1. **人事**：採用人数と時期の案、職種、いまの募集要項、前年の選考で落とした理由の傾向
2. **配属先の責任者**：「この1年で活躍している若手」を思い浮かべ、何をしている人かを数行で
3. **若手社員**：入社してから最初の数か月にやったこと、苦労したこと、続けられた理由
4. **全員**：「この学生は採らない」と言えるケースを1つずつ

「採らないケース」を持ち寄ってもらうのは、譲れない条件が、良い例より悪い例から出てきやすいからです。

## 手順3｜議題を、この順番で進める

議題の順番を固定すると、話が文面や媒体の話に流れません。

1. **何人を、いつまでに、どの職種で**：人事の案を確認する。ここが揺れていると後が決まらない
2. **最初の1年に何をするか**：若手の話を元に、場面で言葉にする
3. **活躍している若手の共通点**：知識ではなく、行動と志向で
4. **譲れない条件と、育てられること**：持ち寄った「採らないケース」から、譲れない条件を絞る
5. **段階ごとに見ること**：面談では評価しない、面接の各段で何を確かめるか
6. **誰が何を担うか**：名義、面談、面接、日程の枠

文面の書き方、送る数、媒体のプランの話は、この打ち合わせではしません。要件が決まる前に話すと、要件が「送りやすい学生」に寄っていきます。

## 手順4｜決めることと、保留にしてよいこと

一度の打ち合わせで全部は決まりません。決める範囲を先に分けます。

| その場で決める | 保留にしてよい |
|---|---|
| 職種と、その職種の最初の1年 | 検索条件の細かい組み合わせ |
| 譲れない条件 | 文面の言い回し |
| 面接の段階ごとに見ること | 面接で使う質問の細部 |
| 名義と面談に出る人 | 送る数とペース |
| 見直しの打ち合わせの日 | 評価の物差しの細部 |

保留にした項目は、人事が案を作って現場に確認する形で進めます。検索条件の組み方は[OfferBoxの検索条件の組み方](/media/ob-kensaku-jyoken/)、評価の物差しは[会う学生の評価基準の作り方](/media/ob-gakusei-hyouka-kijun/)で書きました。

### エージェントベストの見解

これは順番の話です。当社は3媒体すべての販売パートナーとして、申込前の相談を受けますが、「OfferBoxとワンキャリアのどちらにするか」を決める前に、この打ち合わせが済んでいるかを確かめます。要件が決まっていれば、企業が選んで送る型が合うか、掲載で集める型が合うかが見えてきます。決まっていないまま媒体を選ぶと、契約したあとに要件の議論が始まり、その間は送る相手が決まらず、管理画面を開いても何もできない期間が続きます。打ち合わせ自体は、準備があれば1回で足ります。媒体の比較より先に、この1回の日程を押さえる。そのほうが、契約後の立ち上がりが早くなります。

## 手順5｜終わったら、1枚の要件メモにする

打ち合わせの内容は、その日のうちに1枚にまとめて参加者に返します。

- **職種と人数と時期**
- **最初の1年の場面**：文面と企業ページにそのまま使える言葉で
- **活躍している若手の行動と志向**
- **譲れない条件**：少なく。多いほど送る相手がいなくなる
- **面接の段階ごとに見ること**
- **担う人**：名義、面談、面接、日程の枠
- **見直しの日**

1枚にするのは、面接官が面接の前に読める量にするためです。長い議事録は読まれません。このメモは、担当が変わったときの引き継ぎの元にもなります。引き継ぎの考え方は[担当者間で引き継ぐ方法](/media/ob-tantousha-hikitsugi/)で書きました。

## 手順6｜見直しの打ち合わせを、最初から日付で置く

要件は、送ってみて、会ってみて初めて分かることがあります。見直しの場を先に決めておきます。

- **最初の見直しは、面談が数件たまった頃に**：会った学生の話と、要件のずれを確かめる
- **見直すのは要件メモの項目だけ**：議題を広げない
- **面接官からの「思っていた学生と違う」を集めておく**：見直しの材料になる
- **変えたら、要件メモを更新して配り直す**

見直しの時期を決めずに始めると、ずれに気づいても直す場がなく、面接での不満だけが溜まります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 人事が要件を書いて、現場には送るだけ | 面接で別の基準が使われる | 打ち合わせで責任者に「これで行く」と言ってもらう |
| 責任者だけで若手を呼ばない | 最初の1年が理想の姿になる | 若手の実際の話を聞く |
| 文面や媒体の話から始める | 要件が送りやすい学生に寄る | 議題の順番を固定する |
| 譲れない条件が増え続ける | 送る相手が見つからない | 「採らないケース」から絞る |
| 議事録が長い | 面接官が読まない | 1枚にまとめる |
| 見直しの日を決めない | ずれが溜まる | 最初から日付で置く |

## 社内の分担

| 作業 | 誰が |
|---|---|
| 議題と事前の依頼を用意し、進行する | 人事 |
| 要件を決め、「これで行く」と言う | 配属先の責任者 |
| 最初の1年の実態を話す | 配属先の若手社員 |
| 要件メモにまとめて配る | 人事 |
| 見直しの材料を集める | 面接官と人事 |

### エージェントベストの見解

自社で持つべきなのは、要件を決めることと、現場が合意することまでです。当社のような代理店や運用代行が手伝えるのは、議題の型を用意する、事前に持ち寄るものの依頼文を作る、要件メモを検索条件と文面の材料に置き換える、といった作業の部分です。ここで線を越えて、代行の側が要件を書いてしまうと、現場は「外の人が決めた基準」として受け取り、面接で使いません。要件の言葉は、責任者と若手が自分で話した言葉のほうが、あとで面接や文面に残ります。外に出すのは、打ち合わせの準備と、決まったあとの置き換えまで。打ち合わせの中身は社内で持つ。この分け方が、運用が始まってからの手戻りを減らします。

## まとめ

- 打ち合わせの目的は、要件を人事の案から社内の合意にすること
- 呼ぶのは人事、配属先の責任者、若手社員。経営は必要なときだけ
- 事前に「活躍している若手」と「採らないケース」を持ち寄ってもらう
- 議題は人数と時期→最初の1年→若手の共通点→譲れない条件→段階ごとに見ること→分担の順。文面と媒体の話はしない
- その日のうちに1枚の要件メモにし、見直しの日を最初から置く

## よくある質問

### 現場の責任者が忙しく、打ち合わせの時間が取れません

事前の持ち寄りを人事が聞き取りで集め、打ち合わせでは「譲れない条件」と「段階ごとに見ること」の二つだけを決める形に絞ります。この二つは、責任者がいないと決まりません。残りは人事が案を作り、要件メモで確認してもらいます。

### 複数の職種で採用する場合はどうしますか

職種ごとに打ち合わせを分けます。一度にまとめると、職種ごとの最初の1年が混ざり、要件メモも曖昧になります。職種が多い場合の運用は[募集職種が多い場合の運用](/media/ob-bosyu-shokushu-ooi/)で書きました。

### 打ち合わせの進め方から相談できますか

できます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、議題の型や要件メモの形を用意し、決まった要件を検索条件と文面の材料に置き換えるところを支えます。要件そのものは、御社の責任者と現場で決めてください。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
