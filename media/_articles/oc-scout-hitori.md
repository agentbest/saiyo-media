人事が一人の会社で、ワンキャリアのスカウトを回そうとすると、読む・書く・送る・返す・面談・台帳・体験談を読む・見直しの全部が一人に乗り、数週間で止まります。ワンキャリアでは、止まる前に雑になった対応が、体験談に書かれます。**結論から言うと、人事一人で回すなら、募集を一つに絞り、週の枠を一つ決め、読める数だけ送り、型は一つにし、入社してまもない社員には「最初の月に詰まった場面の一文」と「文面の確認」と「話す場」だけを頼みます。受諾対応は毎日の短い時間に固定し、台帳は項目を減らし、見直しは月に一度だけにします。ただし、「自社の体験談を読む時間」だけは削りません。絞り込み・型・集計・体験談の要点は外に出せます。止まりそうなサインが出たら、止める前に減らします。** この記事では、一人で全部やって止まる形、絞り方、入社してまもない社員に頼む最小限、受諾対応の固定、台帳の簡略化、体験談を読む時間、見直しの頻度、外に出せる作業、止まりそうなサイン、分担を整理します。分担の基本は[ワンキャリアのスカウトを誰が送るか](/media/oc-scout-tantou/)、他媒体の一人運用は[人事1人でOfferBoxを回す方法](/media/ob-hitori-jinji/)と[人事1人でWantedlyのスカウトを回す方法](/media/wt-scout-hitori/)で書きました。

## この作業の目的｜止まらない大きさで続け、体験談に「雑だった」と書かれない

一人で回す目的は、多く送ることではなく、「止まらない大きさで続けること」と、「対応が雑にならないこと」です。

ワンキャリアでは、止まることと雑になることの両方が、体験談に残ります。「スカウトをもらって返信したが、連絡が来なかった」は、止まった結果です。「テンプレだった」は、読めない数を送った結果です。目的は、続く大きさを最初に決め、その大きさを守ることです。

## 一人で全部やって、止まる形

| 全部やる | 何が起きるか |
|---|---|
| 複数の募集を同時に送る | 読む対象が増え、読めなくなる。テンプレになり、体験談に書かれる |
| 入社してまもない社員に頼まず、自分で「最初の1年」を書く | 文面が薄い。話す場で自分が出て、仕事の話ができない |
| 受諾を、来るたびに返す | 一日中、通知に振り回される。他の業務が止まる |
| 台帳の項目を多くする | 更新が追いつかず、台帳が古くなる |
| 毎週、見直して直す | 何が効いたか分からず、直すこと自体が負担になる |
| 上限を使い切ろうとする | 読まずに送り、体験談に「テンプレ」と書かれる |

最も多いのは、最初の「複数の募集を同時に」です。一人で回すのに、募集の数が多いと、どれも中途半端になります。

## 一人で回すための絞り方

| 絞るもの | 絞り方 |
|---|---|
| 募集 | 一つ。最も急ぎで、企業ページが整っていて、話す人がいて、体験談に「違った」が無い募集 |
| 週の枠 | 一つ。週に一度、まとめて読んで書いて送る時間。予定に入れる |
| 送る数 | その枠で読める数。数を先に決めない |
| 型 | 一つ。その募集の型だけ。[ワンキャリアのスカウト文面のテンプレート管理](/media/oc-scout-template/) |
| 絞り込みの条件 | 狭く。読む対象を少なく。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/) |
| 面談の枠 | 入社してまもない社員が出られる数。それを超えて送らない |
| 企業ページ | 4つの要素のうち「選考の流れと何を見るか」と「その募集の最初の1年」を先に。他は話せる職種から |

### エージェントベストの見解

相談で最も多い思い込みは、「人事一人だから、入社してまもない社員に頼まずに自分で全部やるしかない」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、人事一人で回している会社で続いているのは、入社してまもない社員に「最小限だけ」頼んでいる会社です。頼んでいるのは、「最初の月に詰まった場面を一つ」を一度話してもらうことと、人事が書いた文面を送る前に読んでもらうことと、話す場に出ることの三つだけで、それ以外は人事が引き受けています。入社してまもない社員の負担は月に数十分で、それで文面に最初の1年の具体が入り、話す場で学生に近い人が話せます。当社が人事一人の会社の相談を受けるとき、最初にお願いするのは、「現場に頼まない」ではなく、「現場に頼む範囲を三つに絞る」ことです。

## 入社してまもない社員に頼む、最小限

| 頼むこと | いつ | 時間 |
|---|---|---|
| 「最初の月に詰まった場面」を一つ話す | 型を作るとき（募集ごとに一度） | 短い |
| 人事が書いた文面の確認 | 送る前（まとめて） | 短い |
| 話す場に出る | 受諾が来て日程が決まったとき | 話す場の時間 |

「読んで書く」は、人事が行います。入社してまもない社員の一文を型の2段目に入れ、学生のプロフィールを読んで1段目と重なる点を人事が書き、本人が確認して、本人の名前で送ります。名前だけ借りる形にしない条件は、本人が読んで了承することです。

話す場は、入社してまもない社員が出ます。人事だけが出る話す場は、学生に「最初の1年の話を、やった人から聞けなかった」と体験談に書かれます。人事は進行と最後の案内だけです。[スカウト経由の初回面談の設計](/media/oc-scout-mendan/)

## 受諾対応を、毎日の短い時間に固定する

- **朝と夕方の二回、決まった時間に通知と台帳を見る**：それ以外は見ない
- **翌日までに返す、を守れる回数で**：二回なら、どの受諾も翌日までに返せる。後期は当日に
- **返信の型を用意する**：前向き・質問・選考の確認・条件・断り。毎回書かない。[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/)
- **日程の候補は、入社してまもない社員の枠から先に決めておく**：受諾が来てから聞かない。学生の授業に合わせた候補を
- **通知は、その時間にだけ見る設定にできるなら、する**：仕様は管理画面で確認

## 台帳は、項目を減らす

| 残す項目 | 減らす項目 |
|---|---|
| 学生、募集、送った日 | 詳しいメモ |
| 送った一文（学生の一文） | 受諾の内容の型の細かい分類 |
| 受諾の有無 | 面談後の詳しい記録 |
| 段（新規・返信済み・面談予定・面談済み・選考へ・保留・終了） | |
| 次の連絡日 | |
| 体験談にスカウトへの言及があったか | |

「次の連絡日」と「体験談への言及」だけは減らしません。前者が無いと放置が起き、後者が無いとワンキャリア特有の指標が消えます。台帳の型は[ワンキャリアの学生プロフィールの読み方](/media/oc-scout-profile/)や[ワンキャリアのスカウト運用のKPI設計](/media/oc-scout-kpi/)で書いたものを、一人なら項目を半分にします。

## 体験談を読む時間だけは、削らない

一人で回すと、削れるものは削ります。ただし、自社の体験談を読む時間は残します。

- **週の確認で、新しい体験談が無いかを見る**：数分で済む。[ワンキャリアのスカウトの受諾率を毎週見直す方法](/media/oc-scout-review/)
- **選考の山のあとに、増えた分を読む**：全部ではなく、増えた分だけ
- **「掲載と違った」「テンプレだった」「返信が遅かった」を探す**：この三つが、一人運用で起きやすい失敗
- **見つけたら、その週に対応するもの（返信の速さ）と、月に直すもの（読める数、企業ページ）に分ける**
- **体験談の要点の整理は、外に出してもよい**：読むのは社内、分けるのは社内、整理は外でもよい

## 見直しは、月に一度だけ

- **毎週の見直しは、体験談と受諾の対応の速さを見るだけ**：週の会は開かない。一人で数分
- **月に一度、段ごとの数を並べる**：読んだ・送った・受諾・面談・選考
- **直すのは一か所だけ**：型の一文か、絞り込みの条件か
- **月の見直しに、入社してまもない社員と上司に短く報告する**：段の数と、直す一か所と、体験談の言葉。反応を現場に戻す
- **年度に一度、募集を増やすか減らすかと、文面の型の設計を見直す**：続いていれば二つ目、止まりそうなら減らす

## 外に出せる作業

| 外に出せる | 社内に残す |
|---|---|
| 絞り込みの条件の設計 | プロフィールを読んで一文を書く |
| 型と見本の作成、更新 | 入社してまもない社員の一文と確認 |
| 自社の体験談の要点の整理 | 体験談を読むことと、「補う」「直す」の分け |
| 台帳の集計と月の見直しの材料 | 受諾対応 |
| 返信の型、面談の型 | 話す場 |

出せる作業を出せば、人事に残るのは「読んで書く」「返す」「体験談を読む」「話す場の進行」「報告」だけになります。範囲は[ワンキャリアのスカウトを代行に出せる範囲](/media/oc-scout-daikou/)で書きました。

## 止まりそうなサインと、減らし方

| サイン | 減らし方 |
|---|---|
| 週の枠を、二週続けて使えなかった | 枠を短くする。送る数を減らす。ゼロにしない |
| 受諾対応が、翌日までにできていない | 送る数を減らす。返信の型を見直す |
| 台帳が、一週間更新されていない | 項目をさらに減らす |
| 入社してまもない社員の確認が返ってこない | 確認の期限を決め、過ぎたら送らない（送るのではなく、送らない） |
| 話す場の枠が埋まらない | 入社してまもない社員に枠を頼み直す。埋まらないなら送る数を減らす |
| 体験談を読めていない | 週の確認を「体験談だけ」に絞る。他を減らしても、これは残す |
| 「効いているのか分からない」と感じる | 月の見直しで段の数を見る。面談まで進んだ学生がいれば続ける |

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社が人事一人の会社のワンキャリアのスカウトを支えるとき、絞り込み、型、台帳の集計、体験談の要点の整理、見直しの材料は当社が持てます。人事に残るのは、週に一度の枠で読んで書くことと、毎日二回の受諾対応と、話す場の進行と、自社の体験談を読んで「補う」「直す」に分けることと、月の報告です。この五つは、社内でしかできません。当社が最初にお伝えするのは、「この五つが、いまの業務の中に入りますか」という確認です。入るなら、当社は残りを引き受けます。入らないなら、スカウトより先に、企業ページとイベントを整えて待つ形が向いています。人事一人の会社で、無理に始めて雑になり、体験談に書かれるより、入る大きさで始めて続けるほうが、翌年につながります。

## まとめ

- 人事一人で回す目的は、多く送ることではなく「止まらない大きさで続けること」と「対応が雑にならないこと」。ワンキャリアでは両方が体験談に残る
- 募集は一つ、週の枠は一つ、読める数だけ、型は一つ、絞り込みは狭く、話す場の枠を超えない、企業ページは選考の流れとその募集の最初の1年を先に
- 入社してまもない社員に頼むのは、「最初の月に詰まった場面」の一文・文面の確認・話す場、の三つだけ
- 受諾対応は毎日二回の決まった時間に、台帳は項目を減らして「次の連絡日」と「体験談への言及」は残し、見直しは月に一度一か所だけ
- 自社の体験談を読む時間だけは削らない。絞り込み・型・集計・体験談の要点は外に出す。止まりそうなサインが出たら、止める前に減らす

## よくある質問

### 募集が複数あり、どれも急ぎで、一つに絞れません

それでも一つに絞ります。一人で複数を同時に送ると、どれも読めずにテンプレになり、体験談に「テンプレだった」と書かれ、翌年まで残ります。最も急ぎで、企業ページが整っていて、話す人がいて、体験談に「違った」が無い募集から始め、続いたら次に移ります。他の募集は、企業ページとイベントを整えて「エントリー」を待つ形にします。

### 体験談を読む時間まで取れません

体験談を読む時間は、週に数分です。新しい体験談が無いかを確かめ、あれば「掲載と違った」「テンプレだった」「返信が遅かった」の三つだけを探します。この数分を削ると、気づかないまま送り続け、体験談が積み重なります。他の作業（絞り込み、型、集計）を外に出してでも、この数分は残します。

### 人事一人でのワンキャリアのスカウト運用は、御社に相談できますか

できます。当社は、絞り込み、型と見本、台帳の設計と集計、返信の型、面談の型、体験談の要点の整理、月の見直しの材料を支えられます。読んで書くこと、受諾対応、話す場、体験談を読んで分けること、報告は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
