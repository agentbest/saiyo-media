ワンキャリアのスカウトを受け取った学生は、文面だけで返事を決めません。企業ページを開き、先輩が書いた選考体験談とクチコミを読み、「この会社の対応は信用できるか」を確かめてから動きます。人事が一人の会社では、そのスカウトと、企業ページの掲載、イベントのあとの連絡が、同じ一人の時間の上に乗っています。**結論から言うと、人事一人でワンキャリアのスカウトを回すときは、スカウトを「掲載とイベントの対応を崩さずに残る時間」で回せる大きさにします。募集は一つ、送る時間は週に一度の枠、送る数はその枠で読める分だけにし、入社してまもない社員には三つだけ頼みます。受諾への返事は一日二回の時間に寄せ、自社の体験談を読む数分は最後まで残します。** この記事では、時間の分け合い方、最初に絞るもの、社員への頼み方、受諾への返事、台帳と体験談の確認、見直しと減らす合図、分担を順に書きます。分担の考え方は[ワンキャリアのスカウトを誰が送るか](/media/oc-scout-tantou/)、媒体をまたいだ一人運用は[人事一人で回す採用媒体の大きさ](/media/hikaku-jinji-hitori/)で整理しています。

## 人事一人の時間は、掲載・イベント・スカウトで分け合っている

ワンキャリアでは、企業ページの掲載、イベント、スカウトが同じ会社の中で動きます。学生から見れば、どれも一つの会社の対応です。スカウトに時間を寄せすぎると、別の場所が先に崩れます。

| スカウトに寄せすぎたとき | 学生の側で起きること |
|---|---|
| 送る募集を増やし、文面を似せて量を出す | 体験談やクチコミに「一斉送信のようだった」と書かれる |
| 受諾への返事が、イベントの準備と重なって数日空く | 「返事をしたのに音沙汰がなかった」と残る |
| イベントのあとのお礼や案内が遅れる | イベント経由の学生の印象が下がる |
| 企業ページの選考の流れを更新できない | スカウトの文面と企業ページの説明が食い違う |
| 自社の体験談を読まなくなる | 同じ不満が書かれ続けていることに気づけない |

一人運用の目的は、送る数を増やすことではありません。掲載・イベント・スカウトの三つが同時に崩れない大きさを最初に決め、その大きさで年度を通すことです。崩れた対応は体験談に残り、翌年の学生もそれを読んで来ます。

## 最初に絞る：募集一つ・週一枠・読める数

一人で回せる大きさは、送る前に決めます。始めてから削ると、途中で返事が止まった学生が出ます。

| 決めること | 一人運用での決め方 |
|---|---|
| 送る募集 | 一つだけ。企業ページの説明が整っていて、話す社員がいて、体験談に「説明と違った」という声が無い募集から |
| 送る時間 | 週に一度、予定表に固定した枠。プロフィールを読む・書く・送るをこの枠でまとめて行う |
| 送る数 | 枠の中で読み切れる分。先に数を決めて、読まずに埋めない |
| 文面の型 | その募集の型を一つ。[ワンキャリアのスカウト文面のテンプレート管理](/media/oc-scout-template/) |
| 対象の条件 | 狭めに置き、読む人数を抑える。[ワンキャリアのスカウト対象の絞り方](/media/oc-scout-target/) |
| 面談の枠 | 話す社員が出られる回数を上限にし、それを超えて送らない |
| イベントの時期 | 説明会やイベントの前後の週は、送る数を減らしておく |

最後の「イベントの時期」は、ワンキャリアで一人運用をするときに見落とされやすい点です。イベントの週にスカウトの受諾が重なると、どちらの連絡も遅れます。

### エージェントベストの見解

一人で回している人事の方からよく聞くのは、「社員に頼むと迷惑になるので、文面も面談も自分で持つしかない」という声です。当社は求人広告代理店として、ワンキャリアのスカウト運用を横で見ていますが、一人でも続いている会社は、入社して間もない社員に、頼む中身をはっきり三つに限っています。入社した最初の月に戸惑った場面を一度だけ話してもらうこと、人事が書いた文面を送る前に読んでもらうこと、面談に出てもらうことです。社員の負担は月に数十分ほどに収まり、そのかわり文面に「最初の一年」の手ざわりが入り、学生は年の近い人から話を聞けます。ワンキャリアの学生は体験談で「誰が面談に出たか」まで読んでいるので、人事だけが話す形は記録に残りやすい。頼むのをやめるのではなく、頼む範囲を先に決めて社員に見せることが、一人運用を続ける近道です。

## 入社してまもない社員には、三つだけ頼む

| 頼むこと | タイミング | 負担の目安 |
|---|---|---|
| 入社した最初の月に戸惑った場面を一つ話す | 募集の型を作るとき、一度だけ | 短い会話一回 |
| 人事が書いた文面を読む | 週の枠のあと、まとめて | 数分 |
| 面談に出る | 受諾があり日程が決まったとき | 面談の時間 |

プロフィールを読んで書くのは人事です。社員の話した場面を型の中段に入れ、学生のプロフィールと重なる点を人事が一文で書き足します。送る名前を社員にする場合は、本人が文面を読んで了承してからにします。

面談の主役も社員に任せ、人事は進行と次の案内に回ります。選考体験談には「誰と話したか」「何を聞かれたか」が書かれやすく、実際に働いている人が話した記録は、翌年の学生にとって判断の材料になります。面談の組み立ては[スカウト経由の初回面談の設計](/media/oc-scout-mendan/)を参照してください。

## 受諾への返事は、一日二回の時間に寄せる

受諾への返事を、通知が来るたびに書いていると、掲載の更新やイベントの準備が細切れになります。返す時間を先に決めます。

- **昼前と終業前の二回だけ受諾を確認する**：その時間以外は他の業務に使う
- **どの受諾にも翌営業日までに返す**：二回の確認があれば守れる。選考が進む時期は当日中に寄せる
- **返事の型を内容ごとに用意しておく**：前向き・質問・選考かどうかの確認・条件の質問・辞退。受諾後の流れは[スカウトが受諾されたあとの連絡](/media/oc-scout-judaku-go/)
- **面談の日程候補は、社員の空きから先に押さえる**：受諾が来てから社員に聞きに行かない
- **通知の受け取り方を変えられるか確かめる**：設定の可否は管理画面とヘルプで確認

ワンキャリアの学生は、他社の体験談で「返事が早かった会社」も読んでいます。早さは比べられる項目だと考えておきます。

## 台帳と体験談の確認は、最小限で残す

一人運用では、記録の作業も削ります。ただし、二つだけは手放しません。

| 台帳に残す | 一人なら省く |
|---|---|
| 学生名・募集・送った日 | 面談の詳しい議事メモ |
| 文面に書いた、その学生向けの一文 | 受諾の理由の細かい分類 |
| 受諾したかどうかと、いまの進み具合 | 毎週の数字の推移表 |
| 次に連絡する日 | |
| 体験談やクチコミにスカウトの話が出たか | |

手放さないのは「次に連絡する日」と「体験談に出たか」です。前者が無いと返事の抜けが起き、後者が無いとワンキャリアでしか見えない反応が台帳から消えます。項目の考え方は[ワンキャリアの学生プロフィールの読み方](/media/oc-scout-profile/)と[ワンキャリアのスカウト運用のKPI設計](/media/oc-scout-kpi/)に詳しく書きましたが、一人ならその半分で足ります。

体験談の確認も同じ考え方です。

- **週の枠の最初に、新しい体験談とクチコミがあるかだけ見る**：数分で終わる。見方は[ワンキャリアのスカウトの受諾率を毎週見直す方法](/media/oc-scout-review/)
- **選考やイベントが集中した時期のあとは、増えた分を読む**
- **探す言葉は三つ**：「説明と違った」「定型文だった」「連絡が遅かった」。一人運用で起きやすいのはこの三つ
- **見つけたら、すぐ直せるもの（返事の早さ）と、月に一度直すもの（送る数、企業ページ）に分ける**

## 月に一度の見直しと、減らす合図

週ごとに文面や条件を変えると、何が効いたのか分からなくなります。週は体験談と返事の早さを見るだけにし、直すのは月に一度にします。

- **月に一度、段階ごとの人数を並べる**：読んだ・送った・受諾・面談・選考
- **その月に直すのは一点に限る**：文面の一文か、対象の条件のどちらか
- **社員と上司に短く伝える**：人数、直す一点、体験談に出た言葉。社員の協力が続く理由になる
- **年度の終わりに、募集を増やすか減らすかを決める**：続いていれば二つ目を足し、苦しければ一つのまま

続けるうちに、苦しくなる合図が出ます。そのときは止めるより先に、小さくします。

| 合図 | 小さくする方法 |
|---|---|
| 週の枠が二週続けて取れない | 枠を短くし、送る数をその分だけ減らす。ゼロにはしない |
| 受諾への返事が翌営業日を過ぎる | 送る数を落とし、返事の型を見直す |
| 台帳を一週間開いていない | 残す項目をさらに減らす |
| 社員の文面確認が戻らない | 確認の期限を決め、過ぎた文面は送らない |
| 面談の枠が埋まらない | 社員に枠を頼み直す。それでも足りなければ送る数を減らす |
| イベントの週に返事が遅れた | 翌年度からイベントの前後の週はスカウトを休む |
| 体験談を読めていない | 週の枠をいったん体験談の確認だけにする |

## 社内の分担

| 作業 | 担当 |
|---|---|
| 送る募集を一つ決める | 人事と責任者 |
| 週の枠でプロフィールを読み、文面を書く | 人事 |
| 最初の月に戸惑った場面を話す・文面を読む | 入社してまもない社員 |
| 社員の名前で送る（本人の了承のうえ） | 人事 |
| 受諾への返事（一日二回） | 人事 |
| 面談 | 入社してまもない社員（人事は進行） |
| 台帳の更新と、自社の体験談・クチコミの確認 | 人事 |
| 月の見直しと社内への報告 | 人事 |
| 対象の条件の設計、文面の型と見本、台帳の集計、体験談の要点の整理、返事と面談の型 | 外部に任せてよい |

運用代行や代理店に渡せるのは、表の最後の行の作業です。プロフィールを読んで書くこと、受諾への返事、面談、体験談を読んで直す点を決めること、社内への報告は企業に残ります。どこまで渡せるかは[ワンキャリアのスカウトを代行に出せる範囲](/media/oc-scout-daikou/)で書きました。

### エージェントベストの見解

一人の会社を支えるとき、当社が引き受けられるのは、対象の条件、文面の型、台帳の集計、体験談の要点の整理、見直しの材料づくりです。人事の方に残るのは、週に一度の枠で読んで書くこと、一日二回の受諾への返事、面談の進行、体験談を読んで直す点を決めること、月の報告の五つで、ここは社内の人にしかできません。ワンキャリアでは、この五つに加えて、企業ページの更新とイベントの対応も同じ人に乗ります。そのため当社は、始める前に「五つを、掲載とイベントの対応と並べても予定表に入りますか」と確かめます。入るなら残りを当社が持ちます。入らない時期は、スカウトを急がず、企業ページとイベントを整えてエントリーを待つほうを勧めます。無理に送って対応が乱れ、それが体験談に残るより、入る大きさで始めるほうが翌年の学生に良い記録が残ります。

## まとめ

- ワンキャリアでは掲載・イベント・スカウトが同じ会社の中で動き、学生は体験談とクチコミで対応を確かめてから返事をする。一人運用は、三つが同時に崩れない大きさを先に決める
- 募集は一つ、週に一度の枠、枠で読める数、型は一つ、面談の枠を上限にし、イベントの前後は送る数を減らす
- 入社してまもない社員に頼むのは、最初の月に戸惑った場面・文面の確認・面談の三つに限る
- 受諾への返事は一日二回、台帳は「次に連絡する日」と「体験談に出たか」を残して軽くし、直すのは月に一度一点だけ
- 苦しくなる合図が出たら、止める前に小さくする。体験談を読む数分は最後まで残す

## よくある質問

### 急ぎの募集が三つあり、一つに絞る判断ができません

送る募集は一つにし、残りは企業ページとイベントで待つ形にします。三つを同時に送ると、どの文面も読み込みが浅くなり、体験談やクチコミに「定型文だった」と残ります。選ぶ順は、企業ページの説明が整っているか、面談に出る社員がいるか、体験談に「説明と違った」という声が無いか、の三点です。一つ目が回るようになってから、二つ目に移ります。

### 体験談やクチコミを読む時間が取れません

週の枠の最初に、新しい投稿があるかを確かめるだけなら数分です。あったときに「説明と違った」「定型文だった」「連絡が遅かった」の三つを探します。この確認をやめると、同じ不満が書かれ続けても気づけません。時間が足りないときは、対象の条件づくりや集計を外に任せてでも、この数分は残してください。

### 人事一人でのワンキャリアのスカウト運用は、御社に相談できますか

できます。当社は求人広告代理店として、対象の条件、文面の型と見本、台帳の設計と集計、返事と面談の型、体験談の要点の整理、月の見直しの材料までを支えています。プロフィールを読んで書くこと、受諾への返事、面談、体験談を読んで直す点を決めること、社内への報告は、企業の側で持っていただく形です。掲載やイベントと合わせて、一人で回る大きさを一緒に決めます。
