研究開発職を新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「自社の分野のキーワードと修士以上で絞って送り、研究室の推薦で決まっている学生にしか届かず承認されず、承認しても人事だけの面談で『テーマは誰が決めるのですか』『自分の研究は生きますか』に答えられず、専門外の面接官が研究を深く突っ込んで『答えられなかった』と体験談に書かれ、『研究開発職は研究室の推薦でしか採れない』で終わる」という問題です。**結論から言うと、研究開発職の学生は研究室の推薦と分野で決まりやすく、媒体が向くのは「分野を問わず、研究の進め方で採る」会社です。「研究寄りか開発寄りか」と「テーマの目的」を先に決め、分野とキーワードはあればよい条件に、学位の条件は理由を決めてから置きます。送る型は「詰まった場面でどうしたか」で絞って研究開発の先輩の名義で研究室の時期に、記事を置く型はテーマの決め方と最初の年を、比べられる場は研究の聞き方の型を企業ページで先に書き、辞退の理由を「研究の内容・テーマの決め方・面接の聞き方」に切り分けます。** 理系学生全般は[理系学生を採りたい会社の採用媒体の選び方](/media/hikaku-rikei-erabikata/)で書きました。この記事は研究開発職に絞ります。

## 研究開発職の採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 学生は研究室の推薦と分野で決まりやすい | 分野で絞って送っても、決まっている学生に届く | 分野を問わず進め方で採る会社に媒体が向く。[OfferBoxで研究開発職志望の学生を見つける検索の考え方](/media/ob-kenkyu-target/) |
| 修士以上を理由なく必須にする | 学部生の進め方が合う学生を落とす | 学位の条件は理由を決めてから |
| テーマの決め方が書かれていない | 「テーマは上から降りてくる」が体験談に書かれる | 決め方と提案できる時期を書く。[ワンキャリアで研究開発職を募集するときの掲載とスカウト](/media/oc-kenkyu-keisai/) |
| 「研究開発職」の名前で募集する | 新しいものを作るのか、改良か、評価と分析かが分からず、「評価と分析だった」と書かれる | 研究寄りか開発寄りかと、テーマの目的を書く |
| 専門外の面接官が深く突っ込む | 「答えられなかった」と体験談に書かれ、辞退される | 研究の聞き方の型を揃え、専門外の面接官は最初にそう言う |
| 研究室の時期を知らない | 実験と学会と修論の時期に送って読まれない | 研究室の時期に合わせる |

## 判断軸を、研究開発職に当てる

| 軸 | 研究開発職での見方 |
|---|---|
| 対象（誰に届くか） | 「研究寄りか開発寄りか」と「テーマの目的」で、求める進め方（変数を分けて確かめる・測り方を疑う・外れた仮説の後に何をしたか）を三つ書き出して絞る。分野とキーワードはあればよい条件。学位の条件は「進め方が書けている」で代えられるなら置かない |
| 型（送るか、来るか、比べられるか） | 送る型は、進め方で絞って研究開発の先輩の名義で「あなたの詰まった場面の進め方を読んで」と一人に書け、研究室の時期に合わせて送れる。来る型は、テーマの決め方と最初の年と分野との関係を記事で通年で。比べられる型は、研究の聞き方の型と最初の年を企業ページで先に書けるかで。理系の体験談が無いなら先ではない |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。理系向けの媒体を併用するなら役割で。[OfferBoxとLabBaseの違い](/media/hikaku-offerbox-labbase/) |
| 運用工数（誰の時間が要るか） | 研究開発の人が、読む・書く・面接に出るの三つに週に何時間出せるかで、入口と送る数を絞る。研究室の時期の管理は人事 |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。研究開発職では、「対象」を分野ではなく進め方で絞ることと、学位の条件に理由を求めることが、他の職種と違います。

### エージェントベストの見解

研究開発職の採用に、媒体が向いている会社と向いていない会社があります。当社は3媒体すべての販売パートナーとして、研究開発職の相談を受けますが、媒体が向いているのは「研究の分野を問わず、進め方で採る」会社です。分野を限った募集は、推薦で決まる学生の中の取り合いになり、媒体で届く学生は少なくなります。「〇〇の分野の修士に限る」募集なら、研究室との関係と研究室の推薦のほうが向いていて、媒体に出しても、体験談に「分野が違うと落ちる」と書かれて終わります。逆に、「分野は問わない。見るのは進め方。分野が違う人が〇人」と書いた会社は、研究室の推薦の外にいる学生（分野が違う、推薦を受けなかった、学部生）に届き、体験談に「研究の内容より進め方を聞かれた」と書かれて、次の年に分野の違う学生が来ます。当社が最初に確かめるのは、「分野を問わずに採る用意があるか」です。用意がないなら、媒体は無理に出さず、研究室との関係を主にするほうがよいと案内します。

## 学生が、確かめること

- **何を研究するのか**：新しいものを作るのか、いまある製品を改良するのか、評価と分析なのか。「研究開発職」の名前では分からない
- **テーマは誰が決めるか**：上から降りてくるか、自分で提案できるか。いつから提案できるか。体験談で最も読まれる
- **自分の研究とつながるか**：分野が違っても採るか。研究の内容ではなく進め方を見るか
- **最初の年に何を任されるか**：先輩のテーマの一部か、評価と分析か、自分のテーマか
- **修士でなくても採るか**：学部卒がいるか。博士は採るか、どう扱うか
- **面接で研究をどう聞かれるか**：内容の深さか、進め方か。専門外の面接官が聞くか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 分野を問わず進め方で絞り、研究開発の先輩の名義で研究室の時期に送りたい | 企業から送る型（OfferBox） | 進め方で絞れ、時期を動かせる。推薦の外の学生に届く。[研究開発職向けのオファー文面](/media/ob-kenkyu-offer-bunmen/) |
| 研究開発の人が、テーマの決め方と最初の年と分野との関係を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 研究室の時期に関わらず、通年で読まれる |
| 理系の体験談があり、企業ページに研究の聞き方の型と最初の年を先に書ける | 学生が並べて比べる場（ワンキャリア） | 「答えられなかった」の体験談に先に答えられるなら。[ワンキャリアで理系学生向けに掲載するとき](/media/oc-rikei-keisai/) |
| 分野を限って採る | 媒体は先ではない | 研究室との関係と推薦を主に。[大学との関係からの母集団形成](/media/kh-boshudan-daigaku/) |
| 研究の聞き方の型が揃っていない | どれも先ではない | 揃えてから。専門外の面接官の深追いで辞退される |

どれか一つが正解ではなく、分野を問うか、研究開発の人が書けるか、体験談があるかで、先に検討するものが変わります。

## 組み合わせ

- **研究室との関係を主に、媒体を推薦の外の学生に**：研究室で会った学生に媒体で送らない。結果を研究室に返す
- **理系向けの媒体と組み合わせるなら、役割で**：研究の内容で探す場と、進め方で絞って送る場。[OfferBoxとLabBaseの併用](/media/ob-heiyou-labbase/)
- **送る時期を、研究室の時期に合わせる**：実験、学会、修論の時期を避ける。[理系学生向けのスカウト文面](/media/kh-bunmen-rikei/)
- **研究の聞き方の型を、一つに決める**：「テーマの説明は短く。聞くのは、詰まった場面でどうしたか、なぜその方法を選んだか、結果が出なかったとき何をしたか」。専門外の面接官は最初にそう言う
- **研究と仕事が離れている場合は、離れていると言う**：「あなたの分野とは違うが、進め方を見て声をかけた」。[ワンキャリアで理系学生にスカウトを送る文面](/media/oc-scout-rikei/)
- **代行と組み合わせるなら、絞る作業と文面の下書きまで。読んで直すのは研究開発の人**：[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「研究開発職」ではなく、何を研究するかとテーマの決め方

- **「研究開発職」「研究職歓迎」「修士以上」の一語で済ませない**：何をするか、テーマは誰が決めるかが分からない
- **研究寄りか開発寄りかと、テーマの目的を、一行で**：「〇〇の材料の研究開発。新しい〇〇を作る研究と、いまの△△の改良の両方。最初に任せるのは改良のほう」
- **テーマの決め方を、隠さず**：「テーマは部門の方針で決まる。□年目から提案できる。提案が通った例が〇件」。降りてくるなら、そう書く
- **分野との関係を、実態で**：「研究の分野は問わない。見るのは進め方。分野が違う人が〇人」。数値は自社の実態で。この記事では書かない
- **最初の年を、時期で**：「最初の〇か月は先輩のテーマの評価と分析。△か月目に先輩のテーマの一部を。自分のテーマは□年目から」
- **学位の扱いを、理由つきで**：「学部卒が〇人。博士は△△の扱い」。修士以上を必須にするなら、その理由
- **研究の聞き方を、先に**：「面接では研究の深さではなく、詰まった場面でどうしたかを聞く。専門外の面接官もいて、最初にそう言う」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 研究寄りか開発寄りか、テーマの目的、テーマの決め方、分野を問うか、学位の条件と理由、研究の聞き方の型を決める | 研究開発の責任者 |
| 進め方で絞る条件 | 研究開発の人が作り、人事か代行が絞る |
| 文面と記事 | 研究開発の人が読んで書く。人事が下書き |
| 名義と、オファーの一文 | 研究開発で入った先輩 |
| 面接 | 研究開発の人。型を揃えて。専門外の面接官は最初にそう言う |
| 研究室の時期の管理と、研究室との関係 | 人事と、出身の研究室を持つ研究開発の人 |

運用代行や代理店が支えられるのは、進め方で絞る条件の型、文面の下書き、研究室の時期の台帳、聞き方の型の整理までで、テーマの決め方の決定、分野を問うかの判断、読んで直す、面接は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

研究開発職の内定辞退が続く会社から相談を受けたとき、当社が最初に切り分けるのは、「辞退の理由が、研究の内容か、テーマの決め方か、面接の聞き方か」です。三つは直し方が違います。研究の内容が理由なら、「研究開発職」の名前の下に「何を研究するか」を具体に書けば、合わない学生はエントリーの前に離れ、辞退は減ります。テーマの決め方が理由なら、「降りてくる」と書いて面接でも言うことで、自分でテーマを持ちたい学生が先に離れます。面接の聞き方が理由なら、研究の聞き方の型を揃え、専門外の面接官が最初にそう言うことで、「深く突っ込まれて答えられなかった」が体験談から消えます。辞退した学生の体験談と内定者の面談の記録を読むと、理由は一つに絞れることが多く、直すのも一か所で足ります。

## まとめ

- 研究開発職の学生は研究室の推薦と分野で決まりやすい。媒体が向くのは「分野を問わず、研究の進め方で採る」会社で、分野を限るなら研究室との関係と推薦を主に
- 「研究寄りか開発寄りか」と「テーマの目的」を先に決め、進め方（変数を分けて確かめる・測り方を疑う・外れた仮説の後に何をしたか）で絞る。分野とキーワードはあればよい条件、学位の条件は理由を決めてから
- 送る型（OfferBox）は先輩の名義で研究室の時期に、記事を置く型（Wantedly）はテーマの決め方と最初の年を通年で、比べられる場（ワンキャリア）は研究の聞き方の型を企業ページで先に
- 学生が確かめるのは「何を研究するか・テーマは誰が決めるか・自分の研究とつながるか・最初の年・修士でなくても採るか・面接で研究をどう聞かれるか」
- 辞退の理由は「研究の内容・テーマの決め方・面接の聞き方」のどれかに切り分けて、一か所を直す

## よくある質問

### 修士以上を必須にしています。学部生にも送るべきですか

必須にする理由が「進め方が書けているか」で代えられるなら、学位の条件を外して学部生にも送ります。学部生は研究が途中のことが多いので、面接では「いまどこで詰まっているか」を聞きます。理由が「研究の深さが要る」で、学部生では足りないと研究開発の責任者が判断するなら、必須にして、その理由を企業ページに書きます。

### 研究室の推薦で採れているので、媒体は要らないのではないですか

推薦で足りているなら、無理に媒体を使う必要はありません。媒体が要るのは、推薦の外にいる学生（分野が違う、推薦を受けなかった、学部生、他の地域の大学）に届けたいときと、分野を広げたいときです。推薦で採れる分野が固定されていて、新しい分野の人が要るなら、分野を問わず進め方で絞る送る型が入口になります。

### 研究開発職の媒体選びは、御社に相談できますか

できます。当社は、進め方で絞る条件の型、文面の下書き、研究室の時期の台帳、聞き方の型の整理を支えられます。テーマの決め方の決定、分野を問うかの判断、読んで直す、面接は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、研究開発職の媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
