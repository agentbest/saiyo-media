初めてWantedlyを使う。管理画面を開くと、会社ページ、募集記事、ストーリー、スカウト、と入口が多く、何から手をつければよいか分からない。「会社ページを完璧にしてから」と考えて、最初の一か月が準備で消える。**結論から言うと、最初の一か月は、週ごとに順番を決めます。一週目に、会社ページの「なにを・なぜ・どうやって」と一本目のストーリーと一つの募集記事を、短く出します。二週目から、返信への対応と面談の枠を決めたうえで、スカウトを読める数で始めます。三週目に、話を聞きに来た人の言葉を集め、四週目に一か所だけ直します。最初の一か月で残すのは型と台帳と社員の協力で、最初の一か月で「効くか」は判断しません。** この記事では、初めての会社がやりがちなこと、週ごとの順番、残すもの、判断しないこと、分担を整理します。会社ページの基本は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)、ストーリーの基本は[Wantedlyのストーリーの基本](/media/wt-story-kihon/)、スカウトの基本は[Wantedlyのスカウトの基本](/media/wt-scout-kihon/)で書きました。この記事は、それらを最初の一か月の順番に並べたものです。

## この作業の目的｜「完璧な準備」ではなく「回る形」を一か月で作る

Wantedlyは、会社ページ・記事・ストーリー・スカウトが互いに支え合う媒体です。どれか一つを完璧にしてから次に進むと、他が空のまま候補者に見られます。

目的は、最初の一か月で、四つが「短くても揃って、回っている」状態を作ることです。完璧にすることは、二か月目以降の仕事です。

## 初めての会社が、やりがちなこと

| やりがちなこと | 何が起きるか |
|---|---|
| 会社ページを完璧にしてから出す | 一か月が準備で消え、候補者に見られる状態にならない |
| 募集記事を、職種の数だけ出す | 全部が薄く、面談に出る人も決まらない。[募集職種が多い会社のOfferBox運用](/media/ob-bosyu-shokushu-ooi/)と同じ |
| スカウトを、最初から数で送る | 相手を読まずに送り、返信が来ず、「Wantedlyは効かない」と判断する |
| 写真を待つ | 記事が止まる。[写真素材がない会社のWantedly](/media/wt-shashin-nai/) |
| 反応を、数字だけで見る | 閲覧の数を見て一喜一憂し、「話を聞きに来た人」の言葉を集めない |
| 返信への対応を決めずにスカウトを送る | 返信が来て慌て、遅れる |

共通するのは、「揃えてから」「完璧にしてから」で、最初の一か月を準備に使っていることです。

## 一週目｜会社ページと一本目のストーリーと一つの募集記事を、短く出す

- **会社ページの「なにをやっているのか」を、一言で**：「〇〇向けの△△を作っている会社です」
- **「なぜやるのか」を、代表の言葉で、場面で**：「始めたとき、□□で困っている人を見て」。人事が聞いて書き起こす。[Wantedlyの会社ページでミッションを伝える書き方](/media/wt-kaisha-page-mission/)
- **「どうやっているのか」を、一つの場面で**：「納期が厳しいとき、うちは〇〇する」
- **一本目のストーリー**：代表か社員一人の、一つの場面。短く。「入社した最初の月」か「一番困った案件」
- **一つの募集記事**：最も急ぎで、現場の一文が取れて、面談に出る人がいる職種。「こんなことやります」を最初の数か月の場面で。条件は最後に短く、書けない場合は「面談で伝える」と明記
- **写真は、あれば一枚。なければ文章だけで出す**
- **メンバー欄は、代表と一人**：[Wantedlyの会社ページに載せるメンバーの選び方](/media/wt-kaisha-page-member/)の手順1

「短く出す」が一週目の要点です。完璧にしない。会社ページの作り方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは会社ページが顔なので、しっかり作り込んでから公開しなければ」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、作り込んでから公開した会社は、公開までに一か月以上かかり、公開したときには「なぜ」が長すぎて読まれず、ストーリーがなく、スカウトも始まっていません。逆に、一週目に短い会社ページと短いストーリーと一つの募集記事を出し、二週目からスカウトを少数で始めた会社は、一か月で「話を聞きに来た人」が出て、その人の言葉で会社ページを直しています。当社が初めての会社の相談を受けるとき、最初にやるのは、会社ページの作り込みではなく、「一週目に何を出すか」を一枚で決めることです。出したものを、来た人の言葉で直すほうが、作り込むより早く良くなります。

## 二週目｜返信対応と面談の枠を決めてから、スカウトを少数で

- **先に決めること**：返信に誰が、いつ（朝と夕方）、何を返すか。面談に誰が出て、週に何枠か。[Wantedlyで面談につながらないとき](/media/wt-mendan-tsunagaranai/)
- **送る相手**：一つの募集記事の「こんなことやります」に近い行動を、プロフィールかストーリーに書いている人。[Wantedlyのスカウトのターゲット](/media/wt-scout-target/)
- **文面**：相手の一文と、自社の「なぜ」の場面の一文。末尾に「選考ではなく、〇〇と話す場」。[Wantedlyのスカウトで共感を伝える書き方](/media/wt-scout-kyoukan/)
- **数**：読める数の中でも少なめに。数を出す週ではなく、流れを確かめる週
- **名義**：代表か現場の人。名義の人が文面を確認する
- **台帳**：相手・募集・送った日・一文・返信の有無・次の連絡日

スカウトの始め方は[Wantedlyのスカウトの基本](/media/wt-scout-kihon/)、通数の考え方は[Wantedlyのスカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/)で書きました。

## 三週目｜話を聞きに来た人の言葉を、集める

- **返信が来たら、翌日までに日程と面談の形を返す**：[Wantedlyでスカウトに返信が来たあとの進め方](/media/wt-scout-henshin-go/)
- **面談で、「記事のどこを見て、話を聞きに来ようと思ったか」を聞く**：数字より、この言葉が最初の一か月の最も重い材料
- **「読んだとおりの会社だったか」を聞く**：記事と実態のずれが、ここで分かる
- **面談の記録に、一行で残す**：「来た理由：〇〇。読んだとおりか：△△」
- **返信が来なくても、三週目で判断しない**：文面と相手を見直す材料として台帳に

面談の設計は[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)、聞く言葉の集め方は[Wantedlyの募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)の「面談で聞く言葉を、材料にする」で書きました。

## 四週目｜一か所だけ、直す

- **三週目に集めた言葉で、直す場所を一つ決める**：「〇〇の一文に反応した人が多い」なら、その一文を会社ページの冒頭に。「△△が分かりにくかった」なら、そこを場面に
- **一か所だけ**：全部を直さない。何が効いたか分からなくなる
- **二本目のストーリーを出す**：一週目の一本目とは別の人の、一つの場面。途切れないことが、二か月目以降の起点
- **来月の頻度を決める**：「月に一本のストーリー、スカウトは読める数」。続く数に合わせる。[Wantedlyのストーリーの更新頻度の決め方](/media/wt-story-hindo/)
- **一か月の記録を一枚に**：出したもの、送った数、返信、面談、来た人の言葉、直した一か所

## 最初の一か月で、残すもの

| 残すもの | 二か月目以降にどう効くか |
|---|---|
| 会社ページの「なぜ」の場面 | 直し続ける元。ゼロから書かなくてよい |
| ストーリー二本 | 三本目からは「同じ形で」と社員に頼める |
| 一つの募集記事の型 | 二つ目の募集は、型を写して |
| スカウトの文面の型と台帳 | 二か月目は「送る」から始められる |
| 返信対応と面談の枠の形 | 決まっていれば、増やしても回る |
| 話を聞きに来た人の言葉 | 会社ページと記事を直す材料 |
| 話してくれた社員一人か二人 | 次の記事の書き手の候補。[Wantedlyのストーリーの書き手を社内で増やす方法](/media/wt-story-kakite/) |

最初の一か月の記録が、二か月目以降の全部の元になります。

## 最初の一か月で、判断しないこと

- **「効くか、効かないか」**：一か月では、話を聞きに来た人が数人いるかどうかで、判断の材料にならない
- **「Wantedlyは合うか」**：合うかは、三か月から半年の記録で
- **「スカウトの返信が少ない」**：文面と相手を直す材料であって、止める理由ではない
- **「閲覧が少ない」**：一か月目の閲覧は、出したばかりの記事の閲覧で、増えるのはこれから

判断は、三か月の記録が出てから、[Wantedlyの効果測定](/media/wt-scout-kpi/)の型で行います。最初の一か月は、「回る形ができたか」だけを見ます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 一週目に出すものを一枚で決める | 人事 |
| 「なぜ」を場面で話す | 代表 |
| 一本目のストーリーの場面を話す | 代表か社員一人 |
| 「こんなことやります」を話す | 現場の人 |
| 聞いて書き起こし、短く出す | 人事 |
| 返信対応と面談の枠を決める | 人事と面談に出る人 |
| スカウトを少数で送る | 人事（名義は代表か現場） |
| 面談で「記事のどこを見て来たか」を聞く | 面談に出る人 |
| 四週目に一か所直し、二本目を出し、記録を一枚に | 人事 |

運用代行や代理店が支えられるのは、一か月の順番の設計、会社ページと記事とスカウトの型、聞く質問の型、台帳の型、一か月の記録の一枚の型までで、「なぜ」と場面を話すこと、書くこと、送ること、面談は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは順番の話です。当社が初めてWantedlyを使う会社からの相談を受けたとき、管理画面の操作の説明から始めません。先に、「一週目に、代表が『なぜ』を話す時間と、社員一人が場面を話す時間と、現場が『こんなことやります』を話す時間が、取れますか」を確かめます。取れれば、一週目に三つが出て、二週目からスカウトが始まり、一か月で回る形ができます。取れなければ、取れる週を一週目にします。当社が勧める順番は、話す時間を確保する、短く出す、少数で送る、来た人の言葉を集める、一か所直す、です。「会社ページを作り込んでから」は、この順番の全部を遅らせます。

## まとめ

- 最初の一か月は、完璧な準備ではなく「四つが短くても揃って回っている」状態を作る月。会社ページを作り込んでから公開しない
- 一週目：会社ページの「なにを・なぜ・どうやって」を短く、一本目のストーリーを一つの場面で、一つの募集記事を「こんなことやります」の場面で。写真がなくても出す
- 二週目：返信に誰がいつ何を返すか、面談に誰が出て週に何枠か、を決めてから、スカウトを読める数の中でも少なめに。名義は代表か現場
- 三週目：面談で「記事のどこを見て来たか」「読んだとおりだったか」を聞き、一行で残す。数字より、この言葉が最も重い材料
- 四週目：来た人の言葉で一か所だけ直し、二本目のストーリーを出し、来月の頻度を決め、一か月の記録を一枚に。「効くか」は三か月の記録で判断する

## よくある質問

### 代表が忙しく、一週目に「なぜ」を話す時間が取れません

短い時間で足ります。「会社を始めたとき、何に困っていましたか」の一つを、立ち話か移動中に聞いて、人事が書き起こします。代表の負担は、話すことと、書き起こしを「言いそうか」で確認することだけです。それも取れなければ、一週目は社員一人のストーリーと募集記事を先に出し、会社ページの「なぜ」は二週目に回します。順番は変えてよく、止めないことが大切です。

### 一か月で、話を聞きに来た人がゼロでした

一か月の返信と面談の数は、判断の材料になりません。見るのは、「四つが揃って回っているか」「返信対応と面談の枠が決まっているか」「送った文面に相手の一文と自社の『なぜ』の場面があるか」です。揃っていれば、二か月目に送る数を読める数まで増やし、三か月の記録で判断します。揃っていなければ、揃えることが二か月目の仕事です。

### 初めてのWantedlyの一か月は、御社に相談できますか

できます。当社は、一か月の順番の設計、会社ページと記事とスカウトの型、聞く質問の型、台帳の型、一か月の記録の一枚の型を支えられます。「なぜ」と場面を話すこと、書くこと、送ること、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
