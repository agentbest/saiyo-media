OfferBox経由で採った学生が、入社してまもなく離職した。「本人が合わなかった」で終わらせたくなりますが、採用の側にも、見直す点があります。**結論から言うと、離職を「本人の問題」で終わらせず、ずれが起きた場所を四つに分けます。オファーで伝えた仕事と実態、面談で見せた人と配属先の人、選考で見た「こんな人」と入社後に求めた行動、約束した最初の1年と実際の1年。本人に聞ける範囲で聞き、事実と推測を分けます。配属先と採用の間のずれを見て、文面と企業ページと面談の型を直し、「こんな人」を入社後の活躍と照らして見直します。一件で全部を変えず、直す場所を一つに絞ります。** この記事では、本人の問題で終わらせないこと、四つの場所、聞き方、配属先とのずれ、直し方、「こんな人」の見直し、一件で全部を変えないこと、分担を整理します。入社後の活かし方は[OfferBox経由で入社した社員を次の採用に活かす方法](/media/ob-nyuusha-go/)、評価基準の見直しは[OfferBoxで会う学生の評価基準の作り方](/media/ob-gakusei-hyouka-kijun/)で書きました。

## この作業の目的｜離職を、次の採用の「直す場所」に変える

早期離職は、採用の結果が最も強く出る場面です。「本人が合わなかった」で終わらせると、同じずれで次も採り、同じ離職が起きます。

目的は、離職した本人を責めることでも、採用担当を責めることでもなく、「どこでずれたか」を見つけて、次のオファーの時点から直すことです。

## 「本人の問題」で終わらせない

- **本人の側の理由は、あってよい**：それを否定しない。同時に、採用の側の理由も見る
- **「合わなかった」の中身を分ける**：仕事が違った、人が違った、求められる行動が違った、最初の1年が違った
- **採用の側で直せるものと、直せないものを分ける**：直せるものだけを直す
- **一件で、採用の全部を否定しない**：「OfferBoxは合わない」「オファー経由は定着しない」に飛ばない
- **離職した本人への対応は、人事と管理部門の範囲**：この記事は、採用の側の見直しだけを扱う

「本人の問題」と「採用の問題」は、両方あることが普通です。片方だけにすると、直す場所が見えません。

## ずれが起きた場所を、四つに分ける

| 場所 | ずれの中身 | 見るもの |
|---|---|---|
| 1. オファーで伝えた仕事と、実態 | 文面で書いた「最初の1年」と、実際に任された仕事が違った | 送った文面と、配属先の実際の仕事 |
| 2. 面談で見せた人と、配属先の人 | 面談に出た人と、配属先で一緒に働く人が違い、「話が違う」 | 面談に出た人と、配属先の人 |
| 3. 選考で見た「こんな人」と、入社後に求めた行動 | 「自分で始めて続ける人」を採り、入社後に「言われたことを正確に」を求めた | 「こんな人」の一枚と、配属先の評価の軸 |
| 4. 約束した最初の1年と、実際の1年 | 「二か月目から一つ持つ」と書き、実際は半年間補助だった | 文面・企業ページ・面談で言ったことと、実際 |

四つは、採用と配属先の間で起きるずれです。採用の側だけで直せるのは「1」「2」「4」の「伝え方」で、「3」と「4」の「実態」は配属先との話です。

### エージェントベストの見解

相談で最も多い思い込みは、「オファー経由で採った学生は志望度が低いから、早期離職しやすい」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、離職した本人に聞ける範囲で聞いた記録を並べると、「志望度」ではなく、「オファーと面談で聞いた仕事と、配属先の仕事が違った」「面談で会った人と、配属先の人が違った」が多くあります。これは志望度の問題ではなく、採用の側が伝えたことと実態のずれです。オファー経由の学生は、「オファーで書かれた仕事」を信じて来るので、そのずれに敏感です。当社が早期離職の相談を受けるとき、最初にやるのは、志望度の話ではなく、送った文面と、面談の記録と、配属先の実際の仕事を、並べることです。並べると、ずれの場所が見えます。

## 本人に、聞ける範囲で聞く

- **退職の手続きの中で、人事が聞ける範囲で**：「今後の採用の参考に、差し支えなければ」
- **四つの場所を、順に聞く**：「オファーで書いた仕事と違ったか」「面談で会った人と配属先は違ったか」「求められることが選考のときと違ったか」「最初の1年は、聞いていたとおりだったか」
- **事実と推測を分けて記録する**：「本人が言った：〇〇（事実）。人事の推測：△△」
- **聞けない場合も、四つの場所を採用の記録と配属先の実態で見る**：文面、面談の記録、「こんな人」、配属先の仕事
- **本人を責める形にしない**：「なぜ辞めるのか」ではなく、「採用の側で直せることを知りたい」

聞き方は、辞退の理由の聞き方と同じです。[OfferBox経由の内定辞退が続くときに見直すこと](/media/ob-naitei-jitai/)で書きました。

## 配属先と採用の間の、ずれ

- **採用が「こんな人」を配属先と合意していたか**：合意なしに採ると、「3」のずれが起きる
- **文面の「最初の1年」を、配属先が知っていたか**：知らないと、「1」「4」のずれが起きる
- **面談に出た人が、配属先の人だったか**：違う部署の若手が出て、配属先は別、で「2」のずれが起きる
- **入社後の最初の1年を、配属先が「約束」として受け取っていたか**：採用が書いたことを、配属先が知らないことがある
- **配属先に、採用の記録（文面・面談・選考）を渡していたか**：渡していないと、配属先は「初めて会う新人」として受け入れる

ずれの多くは、「採用が伝えたこと」を「配属先が知らない」ことから起きます。採用の記録を配属先に渡す形は[OfferBox経由で入社した社員を次の採用に活かす方法](/media/ob-nyuusha-go/)で書きました。

## 直し方

| ずれの場所 | 採用の側で直すこと | 配属先と直すこと |
|---|---|---|
| 1. 仕事 | 文面の「最初の1年」を、配属先の実際に合わせて書き直す | 配属先に文面を見せ、「これで合っているか」を確かめてから送る |
| 2. 人 | 面談に、配属先の人を出す。出せないなら、「配属先は別の部署です」と面談で言う | 配属先の人が面談に出る形を作る |
| 3. 行動 | 「こんな人」を配属先と合意し直す | 配属先の評価の軸と、「こんな人」の行動を揃える |
| 4. 最初の1年 | 文面・企業ページ・面談で言ったことを、配属先の実際に合わせる。実態と違うことを書かない | 配属先が「約束」として受け取り、最初の1年を実際にそうする |

「実態に合わせて書く」が、採用の側の直しの中心です。良く見せて採り、実態でずれると、離職で戻ってきます。文面の書き方は[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)で書きました。

## 「こんな人」を、入社後の活躍と照らして見直す

- **離職した人と、定着して活躍している人を、「こんな人」の一枚で並べる**：どこが違うか
- **「こんな人」の行動が、入社後に求められる行動と合っていたか**：合っていなければ、「こんな人」を直す
- **選考で見た「行動の事実」が、入社後の行動と一致していたか**：一致していなければ、面接で見る項目を直す
- **年に一度、入社後の記録で見直す**：一件で変えない
- **「こんな人」を直したら、検索条件と文面も直す**

見直しの手順は[OfferBoxで会う学生の評価基準の作り方](/media/ob-gakusei-hyouka-kijun/)の手順6で書きました。

## 一件で、全部を変えない

- **一件の離職で、「こんな人」も文面も面談も全部変えると、何が効いたか分からなくなる**
- **四つの場所のうち、最もずれが大きかった一つを直す**
- **直した結果を、次の採用と入社後で見る**：一年
- **同じずれが二件続いたら、その場所を重く見る**
- **離職の記録を、四つの場所で分類して残す**：件数が増えると、直す場所が見える

一件は、直す場所の「候補」で、複数件が「証拠」です。候補の段階で全部を変えると、翌年の判断ができません。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 本人に聞ける範囲で聞き、事実と推測を分けて記録する | 人事 |
| 送った文面・面談の記録・「こんな人」・配属先の実際を並べる | 人事 |
| ずれの場所を四つのどれかに分類する | 人事と責任者 |
| 文面・企業ページ・面談を実態に合わせて直す | 人事と配属先 |
| 「こんな人」を配属先と合意し直す | 人事と配属先の責任者 |
| 面談に配属先の人が出る形を作る | 配属先 |
| 採用の記録を配属先に渡す | 人事 |
| 直す場所を一つに絞る判断 | 責任者 |

運用代行や代理店が支えられるのは、四つの場所の切り分け、聞き方の型、並べる表の型、文面と面談の直し方の案までで、本人に聞くこと、配属先との合意、実態を変えるかの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは契約後に起きることの話です。OfferBoxで採った学生が早期に離職すると、社内で「オファー経由は定着しない」という声が出て、翌年の運用が止まることがあります。当社が契約後にお願いしているのは、離職が出たときに、「経路」で判断せず、「ずれの場所」で判断することです。ナビ経由でも、紹介経由でも、同じずれがあれば同じ離職が起きます。オファー経由で目立つのは、文面で仕事を具体に書く分、実態とのずれが学生に見えやすいからで、それは「伝えたことを実態に合わせる」ことで直せます。逆に言えば、オファー経由の離職は、「どこがずれたか」が文面という記録で残っているので、直す場所が見つけやすい離職です。

## まとめ

- 早期離職を「本人の問題」で終わらせず、採用の側のずれの場所を四つ（オファーの仕事・面談の人・「こんな人」と入社後の行動・最初の1年）に分ける
- 本人に聞ける範囲で四つを順に聞き、事実と推測を分けて記録する。聞けなくても、文面・面談の記録・「こんな人」・配属先の実際を並べる
- ずれの多くは「採用が伝えたこと」を「配属先が知らない」ことから起きる。文面を配属先に見せてから送り、配属先の人が面談に出る
- 直しの中心は「実態に合わせて書く」。良く見せて採ると、離職で戻ってくる
- 一件で全部を変えず、最もずれが大きい一つを直して一年見る。「こんな人」は入社後の活躍と照らして年に一度見直す

## よくある質問

### 本人が理由を言わずに辞めました

四つの場所を、採用の記録と配属先の実態で見ます。送った文面の「最初の1年」と配属先の実際、面談に出た人と配属先の人、「こんな人」と配属先の評価の軸、を並べると、本人に聞かなくても、ずれの候補は見えます。候補の段階で一つ直し、次の採用と入社後の記録で確かめます。

### 配属先が「採用の書いたことは知らない」と言います

そこがずれの元です。次からは、文面を送る前に配属先に見せ、「最初の1年」が実際と合っているかを確かめ、内定が出たら採用の記録（文面・面談・選考）を配属先に渡します。配属先が「約束」として受け取っていれば、「4」のずれは減ります。

### 早期離職の見直しは、御社に相談できますか

できます。当社は、四つの場所の切り分け、聞き方の型、並べる表の型、文面と面談の直し方の案を支えられます。本人に聞くこと、配属先との合意、実態を変えるかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
