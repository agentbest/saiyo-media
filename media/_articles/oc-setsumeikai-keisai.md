ワンキャリアで説明会を掲載するとき、「会社説明会」という名前と日時と、会社の概要を並べた形になりがちです。ところが、ワンキャリアの学生は、体験談で会社の実態と選考の様子を読んでから説明会を探しています。会社の概要は、読む前から知っていることです。**結論から言うと、ワンキャリアの説明会は、「体験談で分からなかったことを、会社の人に確かめる場」として掲載します。誰が話すか、何を話すか（選考の流れと各段階で何を見るか、仕事の最初の1年）、質問の時間をどのくらい取るか、選考との関係、事前に読んでおくもの、を書き、当日は話す時間より質問の時間を長く取ります。会社紹介が中心、人事だけが出る、質問の時間が無い、選考との関係が曖昧、が学生の来ない形です。** この記事では、ワンキャリアの学生の説明会の探し方、書く要素、やりがちな失敗、当日の流れの型、終わったあと、複数回の区別、分担を整理します。イベントページの全体は[イベントページの作り方](/media/oc-event-page-kihon/)、タイトルは[イベントページのタイトルの付け方](/media/oc-event-page-title/)で書きました。この記事は、その中の「説明会」に絞った話です。掲載の項目や条件は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

## この作業の目的｜体験談を読んだ学生が、「聞きたいことが聞ける」と分かる掲載にする

ワンキャリアの学生は、説明会に「会社を知りに」来るのではなく、「体験談で読んだことを確かめに」来ます。「選考で何を見ているのか」「面接官はどんな人か」「仕事の最初の1年は本当に体験談どおりか」。

掲載の目的は、「その確かめたいことが、この説明会で、この人に聞ける」と、ページを読んだ時点で分かることです。会社の概要を並べた掲載では、確かめたいことが聞けるかどうかが分からず、体験談を読んだ学生ほど来ません。

## 書く要素

| 要素 | 書き方 |
|---|---|
| 誰が話すか | 職種と年次。「入社二年目の〇〇職」「面接に出る△△部門の責任者」。人事も出るなら、その旨。名前を出せるなら出す |
| 何を話すか | 「会社の説明」ではなく、二つに絞る。「選考の流れと、各段階で何を見ているか」「〇〇職の最初の1年に何をするか」 |
| 質問の時間 | どのくらい取るか。「話す時間より長く」と書けるなら書く |
| 形式と時間 | 対面かオンラインか、長さ |
| 選考との関係 | あるか無いか。あるならどういう形か。年度の公表内容と自社の方針を確認して書く。曖昧にしない |
| 事前に読んでおくもの | 「企業ページの選考の流れと仕事の具体を読んでから来ると、質問しやすい」 |
| 来た学生が持ち帰るもの | 「選考で何を見ているかが分かる」「最初の1年が想像できる」「体験談で気になったことを直接聞ける」 |
| 対象 | 学年、職種の興味。決めつけずに |

「何を話すか」を二つに絞るのが、説明会の掲載の要点です。会社の沿革、事業、規模、制度を全部話す説明会は、体験談を読んだ学生には長く、確かめたいことにたどり着きません。「選考」と「最初の1年」の二つが、学生の確かめたいことに最も近い話です。

## やりがちな失敗

| 失敗 | 学生からどう見えるか |
|---|---|
| 会社紹介が中心 | 企業ページと体験談で読んだこと。来る意味が薄い |
| 人事だけが出る | 「仕事の話を、やっている人から聞けない」「面接官に会えない」 |
| 質問の時間が無い、または最後に短く | 確かめに行けない |
| 選考との関係が曖昧 | 「行くと選考に入るのか」で迷う |
| 「会社説明会」の一言と日時だけ | 何が聞けるか分からない |
| 資料を読み上げる | 資料をもらえば済む |
| 話す人が、企業ページに出ていない | 「誰か分からない人が話す」 |
| 事前に読んでおくものの案内が無い | 学生が準備できず、質問が出ない |

最も多いのは、最初の「会社紹介が中心」です。他の媒体の説明会の型を、そのまま持ってきた形です。

### エージェントベストの見解

相談で最も多い思い込みは、「説明会は、会社の全体像を伝える場なので、事業・制度・キャリアを網羅すべきだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの説明会の掲載を支えていますが、網羅した説明会に来た学生の体験談には、「企業ページに書いてあることを聞いた」「質問の時間が無かった」と書かれます。体験談を読んだ学生は、全体像より「確かめたい一点」を持って来ています。当社が説明会の掲載を整えるとき、最初にやるのは、話す内容を「選考の流れと何を見るか」と「仕事の最初の1年」の二つに絞り、残りは企業ページに任せることです。二つに絞ると、話す時間が短くなり、質問の時間が長くなり、学生は確かめて帰ります。網羅は企業ページで、説明会は確かめる場です。

## 当日の流れの型

| 順 | 内容 | 時間の配分 |
|---|---|---|
| 1 | 短い自己紹介。「会社の概要は企業ページに書いてあります。今日は選考と最初の1年の話をします」と最初に言う | 短く |
| 2 | 選考の流れと、各段階で何を見ているか。面接に出る人が話す | 中くらい |
| 3 | 〇〇職の最初の1年。その職種の入社してまもない社員が、場面で話す | 中くらい |
| 4 | 質問の時間。人事が最初の質問を出して口火を切る。「体験談で気になったことを聞いてください」と促す | 長く |
| 5 | 次の案内。選考の流れ、イベント、企業ページ。「今日決めなくてよい」 | 短く |

「1で、会社の概要は話さないと宣言する」のが、この型の要点です。学生は「この説明会は違う」と分かり、質問を用意します。

流れは毎回同じにし、話す人が変わっても場が安定するようにします。

## 選考との関係の書き方

- **年度の公表内容と、自社の方針を確認してから書く**：広報と選考の扱いは年度で変わる。この記事では具体は書かない
- **曖昧にしない**：「関係あり」なら、どういう形か。「関係なし」なら、その旨
- **「関係なし」と書いたら、守る**：参加の有無で扱いを変えない
- **企業トップページの「選考の流れ」と揃える**：[イベントページと企業トップページの使い分け](/media/oc-event-page-kigyo-top/)
- **説明会の中で選考の話を「する」ことと、説明会が選考に「関係する」ことは別**：前者は内容、後者は扱い。分けて書く

「選考の流れを話す説明会」と「選考に関係する説明会」は違います。前者は、学生が確かめたい内容で、後者は、参加の扱いです。掲載では、両方を分けて書きます。

## 終わったあとの動き

1. **来た学生に、翌日までに一言**：「昨日はありがとうございました。〇〇の質問、△△が喜んでいました。次の案内は……」
2. **出た質問を、企業ページの「よく聞かれること」に足す**：説明会は、企業ページの材料が集まる場。[企業ページを更新し続ける方法](/media/oc-kigyo-page-koushin/)
3. **話した人に、反応を戻す**：「〇〇の話に、質問が集まっていました」
4. **説明会の体験談が書かれたら、読む**：「掲載と違った」「質問できた」を次の掲載と当日の進め方に
5. **次回を決める**：話す人を変えて、同じ型で

「出た質問を企業ページに足す」で、説明会と企業ページがつながります。学生が実際に聞いたことは、企業ページに足りなかったことです。

## 複数回開くときの区別

- **話す人で区別する**：「〇〇職の△△が話す回」「面接官の□□が話す回」
- **話す内容で区別する**：「選考の流れの回」「最初の1年の回」。二つを分けて、それぞれを深く
- **形式で区別する**：「オンラインで質問中心の回」「対面で現場を見られる回」
- **タイトルに区別を出す**：「第〇回」ではなく、誰が何を話すかで。[イベントページのタイトルの付け方](/media/oc-event-page-title/)
- **企業トップページの誘導は、いま申し込める回だけ**

「二つを分けて、それぞれを深く」は、複数回開ける会社に向く形です。一回で両方を話すより、学生は自分の確かめたいほうを選べます。

## 他の媒体の説明会との違い

OfferBoxやWantedlyでも説明会や少人数の場を開きますが、ワンキャリアの説明会は「体験談を読んだ学生が来る」点が違います。

- **OfferBoxの面談・説明の場**：オファーを受け取った学生が、会社を知りに来る。会社の概要から話してよい。考え方は[OfferBoxの面談設計](/media/ob-mendan-sekkei/)
- **Wantedlyのミートアップ**：募集記事を読んだ人が、仕事の話を聞きに来る。[ミートアップの企画の立て方](/media/wt-meetup/)
- **ワンキャリアの説明会**：体験談を読んだ学生が、選考と実態を確かめに来る。会社の概要は話さず、選考と最初の1年に絞る

同じ「説明会」でも、来る学生が何を読んでいるかで、話す内容が変わります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 話す人（面接に出る人、入社してまもない社員）を決める | 人事と責任者 |
| 「何を話すか」を二つに絞って書く | 人事（話す人から聞いて） |
| 選考との関係を確認して書く | 人事（年度の公表内容と自社の方針） |
| 事前に読んでおくものを企業ページに整える | 人事 |
| 当日、選考の流れを話す | 面接に出る人 |
| 当日、最初の1年を話す | 入社してまもない社員 |
| 当日の進行と質問の口火 | 人事 |
| 翌日の一言、企業ページへの反映、反応を戻す | 人事 |

運用代行や代理店が支えられるのは、掲載の要素の型、当日の流れの型、選考との関係の書き方の整理、終わったあとの動きの型までで、話す人の確保、選考との関係の判断、当日の運営、学生への連絡は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは、向く会社と向かない会社がはっきり分かれます。ワンキャリアの説明会が機能するのは、「面接に出る人と、入社してまもない社員の、両方が出られる会社」です。当社が3媒体の販売パートナーとして相談を受ける中で、説明会を人事だけで回している会社がありますが、体験談を読んだ学生が確かめたいのは「面接官はどんな人か」と「最初の1年は本当か」で、どちらも人事では答えられません。当社が説明会を勧める前に確かめるのは、「面接に出る人と、入社してまもない社員が、説明会に出られるか」です。出られるなら、掲載に「誰が話すか」を書けます。出られないなら、説明会より先に、企業ページの「選考で何を見るか」と「よく聞かれること」を整えるほうが、学生の確かめたいことに応えられます。

## まとめ

- ワンキャリアの学生は体験談を読んでから説明会を探す。説明会は「体験談で分からなかったことを確かめる場」として掲載する
- 書く要素は、誰が話すか、何を話すか（選考の流れと何を見るか・仕事の最初の1年の二つに絞る）、質問の時間、形式と時間、選考との関係、事前に読んでおくもの、持ち帰るもの、対象
- 会社紹介が中心、人事だけ、質問の時間が無い、選考との関係が曖昧、一言と日時だけ、が来ない形
- 当日は「会社の概要は話さない」と最初に言い、選考と最初の1年を話し、質問の時間を長く取る。選考の話を「する」ことと選考に「関係する」ことを分けて書く
- 終わったあとに翌日の一言、出た質問を企業ページに足す、反応を戻す、体験談を読む、次回を決める。複数回は話す人と内容で区別する

## よくある質問

### 会社の概要をまったく話さないのは、初めての学生に不親切ではないですか

概要は、企業ページに書いておき、掲載で「事前に読んでおくと質問しやすい」と案内します。説明会の冒頭で「概要は企業ページにあります」と一言添えれば、初めての学生もそこで読めます。説明会の時間は、企業ページでは読めない「人が話す選考と最初の1年」に使います。

### 面接に出る人が「何を見ているか」を話すと、学生が対策してしまいませんか

「何を見ているか」を話すことは、準備の方向を示すことで、答えを教えることではありません。話さない会社の体験談には「何を見ているか分からなかった」と書かれ、学生は準備せずに来て、面接で話が深まりません。「正解はありません」と添えて話すと、暗記ではなく準備をして来ます。考え方は[本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

### ワンキャリアの説明会の掲載は、御社に相談できますか

できます。当社は、掲載の要素の型、当日の流れの型、選考との関係の書き方の整理、終わったあとの動きの型を支えられます。話す人の確保、選考との関係の判断、当日の運営、学生への連絡は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
