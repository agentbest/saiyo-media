オファーの文面を、学生の目で読んでくれる人が社内にいます。内定者です。1年前まで学生で、自分もオファーを受け取り、開いたものと閉じたものがあり、自社の文面を読んで承認した本人です。**結論から言うと、内定者に頼めるのは「学生だった側の目で読んで、感想を言う」ことまでで、「送る」「返信する」「学生のプロフィールを読む」は頼みません。内定者はまだ社員ではなく、学生の個人情報を見せる立場にも、採用の作業を担う立場にもないからです。** この線を守ったうえで、内定者研修や懇親の場の枠内で、強制せずに頼むと、文面の質が上がります。この記事では、頼めることと頼まないこと、頼み方、内定者から聞くこと、やりがちな失敗、分担を整理します。文面の作り方は[オファー文面テンプレートを作るときの注意](/media/ob-offer-template/)で書きました。

## この作業の目的｜書く側では見えないものを、読む側から聞く

文面を書く人事や現場は、企業の側から文面を見ています。学生がどう読むかは、想像するしかありません。内定者は、想像ではなく経験で「こう読んだ」と言えます。

内定者から聞けるのは、次のようなことです。「この件名は開かない」「この書き出しで自分宛だと思った」「この一文は会社の話で飛ばした」「面談で聞かれたこの質問は答えにくかった」。どれも、書く側では気づきにくいものです。

この作業の目的は、文面のレビューを「企業側の想像」から「学生側の経験」に変えることです。ただし、内定者の負担と立場を守ることが前提です。

## 手順1｜頼めることと、頼まないことを分ける

最初に線を引きます。

| 頼めること | 頼まないこと |
|---|---|
| 自分がオファーを開いた理由、閉じた理由を語ってもらう | 学生のプロフィールを見せる（個人情報。内定者は社員ではない） |
| 自社の文面（テンプレート）を読んで、感想を言ってもらう | 文面を送る、返信する（採用の作業。内定者の立場ではない） |
| 抽象語や分かりにくい言葉を指摘してもらう | 承認した学生や選考中の学生の情報を伝える |
| 件名にあたる部分の候補を、学生の目で選んでもらう | 学生の評価や合否に関わること |
| 自分が面談で聞かれて答えにくかった質問を教えてもらう | 現場社員の代わりに面談に出る（名義にもならない） |
| 企業ページや募集要項を学生の目で読んでもらう | 定期的な作業として時間を拘束する |

「学生のプロフィールを見せない」は、最も守る線です。内定者は入社前で、守秘の義務を負う社員ではありません。文面のレビューは、テンプレート（学生の情報が入っていない状態）で行います。

「送る・返信する」も頼みません。内定者は採用の担当ではなく、頼めば「入社前から仕事をさせられている」と受け取られます。

## 手順2｜内定者研修や懇親の場の枠内で、強制せずに頼む

内定者に頼むときは、場と頼み方を整えます。

1. **内定者向けの場の一部として組む**：内定者研修、懇親会、会社見学の一部に「採用の文面を学生の目で見てもらう時間」を置く。別途呼び出さない
2. **任意であることを明示する**：「協力できる人だけ」「答えたくないことは答えなくてよい」。断っても評価に影響しないと伝える
3. **時間を短くする**：長い時間は拘束になる。感想を聞く程度で終える
4. **報酬の扱いを確認する**：内定者研修の枠内で、研修として扱えるか。社内の規定と、必要なら専門家に確認する。無償で作業をさせる形にしない
5. **聞いたことをどう使うかを伝える**：「来年の後輩に送る文面を良くするため」。使い道が分かると、協力しやすい

「任意」と「短く」と「場の一部」が、内定者の負担と立場を守ります。この3つが無いと、内定者は断れず、負担に感じ、入社前の印象が悪くなります。

### エージェントベストの見解

相談で最も多い思い込みは、「内定者は来年の社員だから、採用の作業を手伝ってもらってよい」というものです。実際には、内定者は入社前で、社員ではなく、学生の個人情報を見る立場にも、採用の作業を担う立場にもありません。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、内定者に「読んで送る」まで頼んだ会社で、内定者が「入社前から無償で働かされている」と感じ、承諾後の関係が悪くなった例があります。内定者に頼むのは、「自分が学生だったときにどう読んだか」を語ってもらうことまでです。これは作業ではなく、経験の共有です。テンプレートを読んで感想を言う、開いた理由と閉じた理由を語る、答えにくかった質問を教える。これだけで、文面は変わります。線を越えて頼むと、文面は良くなっても、内定者との関係が崩れます。線の内側で、十分に得られます。

## 手順3｜内定者から聞くこと

聞く内容を、あらかじめ決めておきます。その場で思いつきで聞くと、答えにくいことを聞いてしまいます。

| 聞くこと | 何に使うか |
|---|---|
| オファーを受け取ったとき、どの企業のものを開いて、どれを閉じたか。理由は | 件名にあたる部分と冒頭の見直し。構成は[オファー文面の構成](/media/ob-offer-kosei/) |
| 自社の文面のどこで「自分宛だ」と思ったか | 冒頭の「読んだ・こう思った」が効いているかの確認 |
| 自社の文面で飛ばした部分、読まなかった部分 | 削る部分の特定 |
| 分からなかった言葉、社内用語に見えた言葉 | 抽象語と用語の置き換え。失敗の型は[オファー文面でやりがちな失敗](/media/ob-offer-bunmen-ng/) |
| 承認したあと、返信までの間に何を思ったか。企業ページを見たか | 返信の速さと企業ページの確認。[企業ページで伝えること](/media/ob-kigyo-page/) |
| 面談で聞かれて答えにくかった質問、聞かれてよかった質問 | 面談の型の見直し。[初回面談の設計](/media/ob-mendan-sekkei/) |
| 内定のあと、決めるまでに何が分かれば早く決められたか | 内定後のフォローの見直し。[内定を出したあとのフォロー](/media/ob-naitei-follow/) |

「自社の文面」は、その内定者が実際に受け取ったものです。本人が承認した文面なので、「なぜ承認したか」を本人に聞けます。承認した理由は、文面の効いた部分そのものです。

聞くときは、複数の内定者から聞くと、個人の好みと共通の傾向が分かれます。1人の意見で文面を変えないようにします。

## 手順4｜聞いたことを、文面と面談に戻す

内定者から聞いたことは、そのまま文面に写すのではなく、テンプレートの見直しの材料にします。

- **件名にあたる部分**：内定者が「開いた」と言った型に寄せる
- **冒頭**：内定者が「自分宛だと思った」部分を、テンプレートの空欄の指示に反映する
- **本文**：内定者が「飛ばした」部分を削る。「分からなかった」言葉を置き換える
- **面談の型**：「答えにくかった質問」を型から外し、「聞かれてよかった質問」を型に入れる
- **企業ページ**：内定者が「見た」と言った部分を整え、「見なかった」部分を短くする
- **内定後のフォロー**：「これが分かれば早く決められた」を、次の卒年の材料にする

見直したテンプレートは、翌年の送信で使います。内定者が入社したあとに、「あなたの意見で変えた文面で、後輩が承認しました」と伝えると、入社後の採用への協力（[現場社員を巻き込む方法](/media/ob-genba-makikomi/)）につながります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 学生のプロフィールを内定者に見せる | 個人情報を社員でない人に見せることになる | テンプレートだけを見せる |
| 内定者に送信や返信を頼む | 入社前に働かされていると感じる | 頼まない。感想を聞くまで |
| 別途呼び出して時間を取る | 拘束になる | 内定者向けの場の一部に組む |
| 任意と言わない | 断れず、負担になる | 任意と明示し、断っても影響しないと伝える |
| 1人の意見で文面を変える | 個人の好みに寄る | 複数から聞き、共通の傾向で変える |
| 聞いたことを使わない | 内定者が「言った意味が無かった」と感じる | 変えた点を内定者に戻す |
| 選考中の学生の話をする | 選考の情報が内定者に渡る | 学生の話はしない。文面の話だけ |
| 報酬の扱いを確認しない | 無償の作業と受け取られる | 研修の枠内かを規定で確認する |

最も守るのは、最初の2つです。「見せない」「送らせない」。この2つを越えると、内定者との関係が崩れます。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 頼める範囲を決め、規定を確認する | 人事（必要なら専門家に） |
| 内定者向けの場に組み込む | 人事 |
| 聞くことを決める | 人事 |
| 聞く | 人事（現場の名義の人が同席してもよい） |
| 文面と面談の型に戻す | 人事と名義の人 |
| 変えた点を内定者に戻す | 人事 |

運用代行に出している場合、内定者から聞いたことをテンプレートに反映する作業は代行が行えますが、内定者に聞く場は社内です。代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行でテンプレートを見直すとき、内定者から聞いた「開いた理由」「飛ばした部分」「分からなかった言葉」は、企業から共有してもらえれば、テンプレートに反映できます。ただし、内定者に聞く場は、当社は持てません。内定者との関係は企業のもので、外部の人間が内定者に文面の感想を聞くのは、内定者にとって負担です。企業の人事が、内定者向けの場の一部として、任意で短く聞く。聞いたことを当社に共有してもらい、当社がテンプレートに戻す。この分担なら、内定者の負担は最小で、文面は学生の目で直ります。内定者の声は、書く側の想像では届かない部分を埋める、最も安い材料です。線の内側で、使わない手はありません。

## まとめ

- 内定者に頼めるのは「学生だった側の目で読んで、感想を言う」ことまで。送る・返信する・学生のプロフィールを見ることは頼まない
- 内定者向けの場の一部として、任意で、短く頼む。報酬の扱いは規定で確認する
- 聞くのは、開いた理由と閉じた理由、自分宛だと思った部分、飛ばした部分、分からなかった言葉、面談で答えにくかった質問、内定後に何が分かれば早く決められたか
- 複数から聞き、共通の傾向でテンプレートと面談の型を直す
- 変えた点を内定者に戻す。入社後の採用への協力につながる

## よくある質問

### 内定者に、後輩へのオファーを書いてもらってはいけませんか

テンプレートの感想を言ってもらうことはできますが、実際の学生のプロフィールを読んで書くことは頼みません。学生の個人情報を社員でない人に見せることになるからです。書く作業は、入社後に現場社員として巻き込む形で、改めて頼みます。

### 内定者から聞いた意見が、人事の考えと違います。どちらを採るべきですか

複数の内定者から聞いて、共通の傾向があれば、学生側の経験として重く見ます。1人の意見なら、個人の好みの可能性があるので、そのまま変えません。人事の考えと内定者の傾向が違うなら、その部分を翌年の文面で小さく試して、承認の反応で判断します。

### 内定者の声を文面に戻す作業は、御社に頼めますか

聞いたことを共有していただければ、当社がテンプレートに反映できます。内定者に聞く場は、企業の人事が持ってください。当社がOfferBoxの運用代行を受けるときは、内定者から聞いた点を年に一度のテンプレートの見直しに入れます。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
