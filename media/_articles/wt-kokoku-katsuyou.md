大手代理店のデジタル部門、Web広告代理店、制作会社、中小・専門代理店、インハウス支援、広告テクノロジーの会社が、Wantedlyで採用する。広告は、憧れで来る候補者が多い業界で、Wantedlyには「クリエイティブ」「面白いことをやる」「世の中を動かす」の記事が並んでいる。広告の会社の記事もその並びで読まれ、同じ言葉では差にならない。憧れで「話を聞きに行きたい」を押した候補者は、面談で実態——数字の責任を誰が持つか、クライアントの修正がどう来るか、締切前の時間——を聞いて離れる。会社の側は「話を聞きに行きたいは多いのに、採れない」と思う。**結論から言うと、広告のWantedlyは、「クリエイティブ」を一度だけ置き、「なにを」をクライアントの業種と扱う領域（運用、制作、企画、データ）で、「こんなことやります」を先週の案件で、数字の責任を誰が持つかとクライアントの修正がどう来るかを素顔として書きます。「話を聞きに行きたい」の数を成果と見ず、面談で実態を聞いた後に残った数で運用を見ます。副業・フリーランスの入口を正社員と分けて置きます。** この記事では、広告の採用構造とWantedlyとの相性、憧れで埋めない見せ方、数字の責任と修正の書き方、ストーリーとカジュアル面談とスカウトの運用設計、数の読み方、社内の分担を整理します。媒体の選び方は[広告業界の採用媒体の選び方](/media/hikaku-kokoku-erabikata/)、業界の像とのずれは[Wantedlyで業界のイメージとのずれを扱う方法](/media/wt-gyokai-image/)で書きました。数値と料金は書きません。

## 広告の採用構造と、Wantedlyとの相性

| 区分 | 採用の形 | Wantedlyとの相性 |
|---|---|---|

| Web広告代理店 | 運用、営業、データ。多数で知られていない | 向く。並ぶ場の中で「クライアントの業種と扱う領域」で |
| 制作会社 | 企画、デザイン、映像、コピー。締切と修正 | 修正と締切を素顔として。「クリエイティブ」で埋めない |
| 中小・専門代理店 | 特定の業種や領域に強い | 強い業種と領域を「なにを」に。憧れの像で読まれないように |
| インハウス支援・広告テクノロジー | 開発、データ、コンサル。スタートアップも多い | 事業と製品で。「広告」の像とずれることを先に |

| 業界の特徴 | Wantedlyで起きること | 設計 |
|---|---|---|
| 「クリエイティブ」の記事が並ぶ | 同じ言葉で差にならない | クライアントの業種と扱う領域で |

## 憧れで埋めない｜クライアントの業種と扱う領域、数字の責任、修正で書く

- **「クリエイティブ」「面白いことをやる」を、一度だけ**：「なぜ」に事実として。募集記事の全部をそれで埋めない
- **「なにを」は、クライアントの業種と扱う領域で一言**：「〇〇業界のクライアントの△△（運用・制作・企画・データ）を担っている会社」。「広告で世の中を動かす」で済ませない
- **「こんなことやります」は、先週の案件で**：「先週は〇〇の案件で△△の数字を見て、□□の修正を受け、〇〇の提案を出した」。[Wantedlyの募集記事「こんなことやります」の書き方](/media/wt-boshu-konna/)
- **数字の責任を、誰が持つかを書く**：「〇〇の数字は担当が持つ。△△はチームで持つ」。「数字に追われる」を隠すと、入った後に知られる
- **クライアントの修正が、どう来るかを書く**：「〇〇の段階で△△から修正が来る。□□は自分で判断して返す」
- **締切前の時間と、その後の時間を、隠さず**：「〇〇の前は△△。それ以外は□□」。「広告だから」で伏せない。[Wantedlyの募集記事で待遇をどう扱うか](/media/wt-boshu-kyuuyo/)
- **「こんな人」は、「数字を持って改善した・修正を受けて作り直した・複数の案件を同時に回した」の記述で**：「クリエイティブに興味がある」「広告が好き」で絞らない

### エージェントベストの見解

これは数字の読み方の話です。広告の会社から、「Wantedlyで話を聞きに行きたいはたくさん来るのに、採れない」と相談されることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、広告は憧れで来る候補者が多い業界で、「話を聞きに行きたい」の数は、記事の良し悪しではなく業界の憧れの量を映しています。数が多いことを成果と見ると、面談の時間が憧れの候補者で埋まり、実態を聞いた後に残る候補者に会う時間が無くなります。当社がお願いしているのは、「話を聞きに行きたい」の数ではなく、面談で数字の責任と修正と時間の実態を伝えた後に残った数と、その後に進んだ数で運用を見ることです。実態を記事に先に書くと、「話を聞きに行きたい」の数は減り、残る数は増えます。減った数を「記事が悪くなった」と読まないことが、広告の会社の運用の最初の決めごとです。

## 会社ページと募集記事の見せ方｜副業・フリーランスの入口を分ける

- **「なぜ」は、責任者の「なぜこのクライアントの、この領域を」を体験と場面で**：[Wantedlyの募集記事「なぜやるのか」の書き方](/media/wt-boshu-naze/)
- **職種ごとに募集を分ける**：運用、営業、企画、デザイン、データ。「広告に関わる仕事」でまとめない
- **副業・フリーランスの入口を、正社員と分けて**：デザイン、コピー、映像、運用は、案件単位で関わる人が続く。「何を、どのくらいの期間で」を最初に。[Wantedlyで副業の募集を書くときの設計](/media/wt-fukugyo-boshu/)
- **大手代理店のデジタル部門は、本体の名前で埋めず、部門で決められることを先に**：「〇〇までは部門で決める。△△は本体の決裁」
- **中小・専門代理店は、強い業種と領域を最初に**：「〇〇業界の△△に強い」。知られていない前提で。[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)
- **作ったものが世に出るまでの時間と、出ないこともあることを書く**：提案が通らない、修正で変わる

会社ページの書き方は[Wantedlyの会社ページで最初に書くこと](/media/wt-kaisha-page-kihon/)で書きました。

## ストーリーとカジュアル面談の設計

- **現場の人のストーリーで、「数字が悪かった週」「修正で作り直した日」を本人の言葉で**：[Wantedlyのストーリーで事業の中身を書く方法](/media/wt-story-jigyo/)
- **憧れで入った人のストーリーで、「憧れと、入った後」を本人の言葉で**：[Wantedlyの入社後ストーリーの書き方](/media/wt-story-nyusha/)
- **副業で関わっている人のストーリーを、別に**：「どのくらいの時間で、何を」
- **カジュアル面談で、数字の責任と修正と時間を、聞かれる前に伝える**：憧れの話で面談を終えない。[Wantedlyのカジュアル面談の設計](/media/wt-scout-casual-mendan/)
- **面談に、現場の人が出る**：数字と修正の実態は、人事だけでは伝えられない

## スカウトの設計

- **絞るのは、「数字を持って改善した・修正を受けて作り直した・複数の案件を同時に回した」の記述**：「広告」「クリエイティブ」の言葉で絞らない。[Wantedlyのスカウトで対象を絞る方法](/media/wt-scout-target/)
- **文面は、クライアントの業種と扱う領域と、数字の責任を最初に**：「〇〇業界の△△を担っていて、□□の数字は担当が持つ会社で、あなたの〇〇を読んで」。[Wantedlyのスカウト文面の書き方](/media/wt-scout-bunmen/)

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「なにを」をクライアントの業種と扱う領域で書く | 責任者と人事 |
| 数字の責任と修正の来方と締切前の時間を、何を書くか決める | 責任者 |
| 先週の案件を、職種ごとに書き出す | 現場 |
| 現場の人が「数字が悪かった週」「修正の日」を話し、記事に整える | 現場（整えるのは人事か外に出せる） |
| カジュアル面談に現場の人が出て、実態を先に伝える | 現場と人事 |
| 「話を聞きに行きたい」の数ではなく、残った数で運用を見る | 人事と責任者 |
| スカウトを扱う領域と数字の責任を最初に、「数字を持って改善した」の記述で絞って送る | 人事（絞る作業は外に出せる） |

運用代行や代理店が支えられるのは、区分の整理、先週の案件の書き出しの型、募集記事の型、聞き方の型、面談の型、数の見方の型、スカウトの絞る作業までで、数字の責任と時間の開示、現場が話すこと、面談、残った数の判断は会社が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは契約後に起きることの話です。広告の会社が、「クリエイティブ」「面白いことをやる」で募集記事を書いて採り、入った人が数字の責任とクライアントの修正で離れる形を、当社は繰り返し見ています。憧れで来た人は、「自分の企画が世に出る」を期待していて、実態が「数字を持ち、修正を受け、提案が通らないことも多い」であることを、入ってから知ります。当社がお願いするのは、募集記事と面談で「〇〇の数字は担当が持つ。△△の段階で修正が来る。提案は通らないこともある」と先に伝え、現場の人が「数字が悪かった週」と「修正で作り直した日」をストーリーで本人の言葉で書くことです。実態を知って来た人は、数字と修正を仕事として引き受けます。憧れの一語で集めた人は、最初の修正で離れます。「話を聞きに行きたい」の数は減りますが、残る人が変わります。

## まとめ

- Wantedlyには「クリエイティブ」「面白いことをやる」の記事が並び、同じ言葉では差にならない。一度だけ置き、「なにを」をクライアントの業種と扱う領域で、「こんなことやります」を先週の案件で書く
- 数字の責任を誰が持つか、クライアントの修正がどう来るか、締切前の時間を素顔として先に。「広告だから」で伏せない。「こんな人」は憧れではなく「数字を持って改善した・修正を受けて作り直した」の記述で
- 職種ごとに募集を分け、副業・フリーランスの入口を正社員と分ける。大手のデジタル部門は本体の名前で埋めず、中小・専門代理店は強い業種と領域を最初に
- 現場の人が「数字が悪かった週」「修正の日」を本人の言葉で。面談に現場が出て、実態を聞かれる前に伝える。繁忙期にスカウトを送らない
- 「話を聞きに行きたい」の数を成果と見ず、実態を伝えた後に残った数と進んだ数で運用を見る。実態を書くと数は減り、残る人が変わる

## よくある質問

### 「話を聞きに行きたい」は多いのに、採れません

広告は憧れで来る候補者が多く、「話を聞きに行きたい」の数は業界の憧れの量を映しています。数字の責任と修正と時間の実態を記事に先に書き、面談で聞かれる前に伝えてください。「話を聞きに行きたい」の数は減りますが、面談の時間が実態を知った上で来る候補者に使えるようになり、残る数が増えます。

### 「クリエイティブ」を売りにしてはいけませんか

「なぜ」に一度、責任者の体験と場面で書いてください。ただ、Wantedlyには同じ言葉の記事が並び、一語では差になりません。クライアントの業種と扱う領域、先週の案件、数字の責任、修正の来方を先に書き、「クリエイティブ」はその後に置いてください。

### 広告のWantedlyの設計は、御社に相談できますか

できます。当社は、区分の整理、先週の案件の書き出しの型、募集記事の型、聞き方の型、面談の型、数の見方の型、スカウトの絞る作業を支えられます。数字の責任と時間の開示、現場が話すこと、面談、残った数の判断は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
