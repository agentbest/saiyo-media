OfferBoxの成功報酬型プランを検討している。ところが、費用がいつ発生するのか、辞退されたらどうなるのかが分からない。**結論から言うと、成功報酬型プランは利用料・初期費用が0円で始められ、費用が発生するのは「内定承諾の時点」です。1名採用あたり45万円（税抜）、利用可能期間は最長13ヶ月、オファー枠は1名あたり40枠。内定辞退の場合は全額返金されます。内定承諾とは、学生が特定の企業への入社の意向があることを指します。就活が本格化する3月以降にアプローチするプランで、早期から動きたい場合は早期定額型を選びます。** プランの全体像は[OfferBoxのプランの選び方](/media/ob-plan-erabikata/)で書きました。この記事は成功報酬型に絞ります（2026年9月23日時点。最新は公式ページでご確認ください）。

## 結論｜成功報酬型プランの中身

| 項目 | 内容 |
|---|---|
| 費用 | 1名採用あたり 45万円（税抜） |
| 利用料・初期費用 | 0円 |
| 利用可能期間 | 最長13ヶ月 |
| オファー枠 | 40枠（1名あたり） |
| サポート体制 | 専任担当のサポート |
| 適性検査 | 既存社員 最大30名分無料 |
| 返金 | 内定辞退の場合は全額返金 |
| アプローチの時期 | 就活が本格化する3月以降 |

## 仕組み｜費用が発生するのはいつか

- **申し込みの時点**：利用料・初期費用は0円です
- **オファーを送っている間**：費用は発生しません
- **内定を出した時点**：まだ発生しません
- **学生が内定を承諾した時点**：ここで請求が発生します。内定承諾とは、学生が特定の企業への入社の意向があることを指します
- **内定承諾の後に辞退された場合**：全額返金されます
- **入社合意枠を超えて採用した場合**：その分は成功報酬になります（この成功報酬分も、内定承諾後の辞退なら全額返金）

「採れたら払う」形で、しかも承諾の後に辞退されたら戻る、という設計です。

### エージェントベストの見解

相談で最も多い思い込みは、「成功報酬型は採れなければ0円だから、リスクなく始められる」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの申し込みの相談を受けますが、費用のリスクが無いことと、運用のコストが無いことは別です。成功報酬型でも、学生のプロフィールを読んで絞り、一人ひとりに文面を書き、承認が来たら面談を組む時間は、早期定額型と同じだけかかります。かからないのは費用だけで、現場の時間はかかります。申し込んだあとに止まる会社に共通するのは、「0円だから、とりあえず契約して様子を見る」と決めて、書く人を決めないまま枠だけ持つことです。当社が最初にお願いするのは、費用が0円でも、「誰が、月に何通書くか」を申し込みの前に決めることです。成功報酬型の40枠（1名あたり）は、一通ずつ読んで書くと、それなりの時間になります。費用の入り口が低いプランほど、運用の体制を先に決めておく必要があります。

## 向く会社・向かない会社

| 会社の状態 | 判断 |
|---|---|
| 3月以降に絞って動く計画 | 向く。プランの想定どおりの時期 |
| 採用の人数が読めず、先に定額を払うのが難しい | 向く。採れた分だけの費用 |
| 初めてスカウト型の媒体を使う | 向く。入り口の費用が低い |
| インターンや早期面談の時期から接点を持ちたい | 向かない。早期定額型を検討 |
| 2卒年を同時に動かしたい | 向かない。期間が最長13ヶ月 |
| 書く人が決まっていない | どちらも向かない。体制を決めてから |

## 確認する項目

- **3月以降に、オファーを書く時間**：月に何通書けるか。[OfferBox運用のKPI設計](/media/ob-kpi-sekkei/)
- **面談の枠**：3月以降は他社と重なるので、承認から面談までの速さが効きます。[スカウトのKPI](/media/kh-kpi-scout/)
- **採る人数の見込み**：1名あたりの計算なので、何名分の枠を持つか
- **内定承諾の定義の社内共有**：請求のタイミングに関わるので、経理と共有しておく
- **利用する期間**：最長13ヶ月で足りるか
- **適性検査の使い道**：既存社員最大30名分の枠をどう使うか

## 注意点

- **料金は税抜表示**です
- **請求は内定承諾時**：内定を出した時点ではありません。経理と共有しておきます
- **オファー枠は復活する**：オファーを受信した学生が辞退した場合（または3日経過・選考を辞退した場合）、送信枠が復活して別の学生に送れます
- **入社合意枠を超えての採用は成功報酬**になります
- **期間は最長13ヶ月**：2卒年をまたぐ設計には、早期定額型（最長24ヶ月）のほうが合います
- **最新の内容は公式ページで**：[OfferBoxの料金プラン](https://offerbox.jp/company/fee)をご確認ください

### エージェントベストの見解

成功報酬型で、当社が先にお伝えしているのは、「3月以降は、承認から面談までの速さが費用の効率を決める」ということです。3月以降の学生は、複数の会社から同時にオファーを受け取り、同時に選考が進みます。承認が来てから面談の日程を出すまでに数日かかると、その間に他社の面談が入り、日程が埋まります。成功報酬型は採れた分だけの費用なので、承認が面談につながらないと、時間だけが消えます。申し込んだあとに成果が出ない会社に共通するのは、承認の通知に気付くのが翌週になっていることです。当社が案内するのは、申し込みの前に「承認が来たら誰が何日以内に返すか」と「面談の候補日を先に何枠持っておくか」を決めることです。3月以降のプランでは、送る数より、返す速さと会える枠のほうが、結果を分けます。

## まとめ

- 成功報酬型プランは利用料・初期費用0円。費用が発生するのは「内定承諾の時点」で、1名採用あたり45万円（税抜）
- 内定辞退の場合は全額返金。入社合意枠を超えての採用は成功報酬になる
- 利用可能期間は最長13ヶ月、オファー枠は1名あたり40枠。専任担当のサポートと既存社員最大30名分の適性検査が付く
- 想定は「就活が本格化する3月以降」のアプローチ。早期から動くなら早期定額型
- 費用が0円で始まっても、書く時間と面談の枠は同じだけかかる。体制を先に決める

## よくある質問

### 内定を出した時点で請求されますか

されません。請求は、学生が内定を承諾した時点です。内定承諾とは、学生が特定の企業への入社の意向があることを指します。承諾の後に辞退された場合は全額返金されます。請求のタイミングは経理と共有しておくと、処理がスムーズです。

### 採用に至らなかった場合、何か費用はかかりますか

利用料・初期費用は0円です。費用が発生するのは内定承諾の時点なので、採用に至らなければ費用は発生しません。ただ、オファーを書く時間と面談の時間は社内でかかっているので、「0円で試せる」というより「費用の発生が後ろにある」と考えるほうが、運用の設計がしやすくなります。

### 成功報酬型の相談は、御社にできますか

できます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、時期と体制からプランをご案内します。代理店手数料は媒体側から支払われるため、**企業の料金は各媒体の正規料金のまま**です。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
