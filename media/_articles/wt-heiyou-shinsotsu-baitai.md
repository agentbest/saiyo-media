新卒採用をナビサイトで回していて、Wantedlyを足すか迷っている。あるいは、Wantedlyで新卒を集めていて、ナビサイトを足すべきか考えている。この二つは、同じ「新卒を集める」でも、学生が開く動機と、来たときの状態が違います。**結論から言うと、ナビサイトは「決まった時期に、エントリーを集める場」、Wantedlyは「会社の中身を読んだ学生が、時期を問わず来る場」です。併用するなら、Wantedlyを「ナビから来た学生に会社を読ませる場所」として置き、ナビの時期にWantedlyの更新を止めず、二つに同じ文章を貼らないことです。** この記事では、それぞれの役割、併用するときの分担、書くことの分け方、予算と工数の配分、やりがちな失敗、社内の分担を整理します。スカウト型とナビ型の違いは[スカウト型とナビ型の違い](/media/hikaku-scout-vs-navi/)、Wantedlyの新卒向け募集記事は[新卒向け募集記事の書き方](/media/wt-boshu-shinsotsu/)で書きました。ナビサイトの仕様や数値は、この記事では書きません。

## それぞれの役割｜ナビは「エントリーを集める場」、Wantedlyは「会社を読んでもらう場」

ナビサイトは、学生が就職活動を始めるときに登録し、業界や職種や地域で会社を探す場所です。時期が決まっていて、学生は多くの会社を並べ、エントリーや説明会の予約をします。会社の側は、掲載の枠に会社の情報を入れ、期間内にエントリーを集めます。

Wantedlyは、学生が「この会社はどんな会社か」を読む場所です。会社ページとストーリーがあり、募集記事はそのあとにあります。学生は会社を読んでから「話を聞きに行きたい」と来ます。時期は決まっておらず、記事は残ります。

| | ナビサイト | Wantedly |
|---|---|---|
| 学生が開く動機 | 就職活動を始めたから。会社を探すため | この会社を知りたいから |
| 学生が比べるもの | 業界・職種・地域・条件・他社 | 会社の中身・人・仕事の場面 |
| 時期 | 決まっている。開始と締切がある | 決まっていない。記事が残る |
| 会社が出すもの | 掲載枠の情報・説明会の日程 | 会社ページ・ストーリー・募集記事 |
| 来る学生の状態 | 会社をまだ知らない。条件で選んだ | 会社を読んでいる。会社で選んだ |
| 数の性格 | エントリーの数が出る | 「話を聞きに行きたい」の数が出る |

どちらが優れているかではなく、学生の状態が違います。ナビから来た学生は会社を知らず、Wantedlyから来た学生は会社を読んでいます。当社が扱うOfferBoxは企業側から学生に送るスカウト型、ワンキャリアは学生の側のクチコミと情報を軸にした媒体で、ナビとも Wantedlyとも役割が違います。役割の違いは[OfferBoxとWantedlyの違い](/media/hikaku-offerbox-wantedly/)と[ワンキャリアとWantedlyの違い](/media/hikaku-onecareer-wantedly/)で書きました。

## 併用するときの分担｜ナビから来た学生に、どこで会社を読ませるか

- **Wantedlyを「ナビから来た学生が会社を読む場所」として置く**：ナビでエントリーした学生は、説明会の前に会社を調べる。調べる先に、会社ページとストーリーがある形にする
- **ナビの掲載情報から、Wantedlyの会社ページへ導線を置く**：ナビの仕様で貼れる範囲で。貼れないなら、説明会の案内の中で「会社の中身はこちらで」と伝える
- **説明会の前後で、読んだかを聞く**：「会社ページを読んで来た学生」と「読んでいない学生」で、説明会の話し方を変える
- **Wantedlyから来た学生を、ナビの説明会と同じ流れに入れない**：会社は読んでいるので、会社の説明から始めると温度が下がる。仕事の場面から話す
- **来た学生の「入口」を台帳に残す**：ナビからか、Wantedlyからか、両方か。選考の途中で「会社を読んでいるか」が分かる

分担の基本は[母集団形成の媒体の組み合わせ方](/media/kh-boshudan-baitai-kumiawase/)で書いた「一つの入口が回ってから次を足す」です。ナビがすでに回っているなら、Wantedlyは「集める入口」ではなく「読ませる場所」として足すのが、最初の形です。集める入口として育てるのは、会社ページとストーリーが揃ってからです。

### エージェントベストの見解

相談で最も多い思い込みは、「ナビでエントリーが足りないから、Wantedlyを足して数を補う」というものです。当社は3媒体すべての販売パートナーとして、ナビと併用したいという相談を受けますが、Wantedlyは会社を読んでから来る場なので、ナビと同じ「エントリーの数」は出ません。数を補うつもりで足すと、初年度に「Wantedlyは来ない」と判断して止めることになります。実際にWantedlyを足して変わるのは、数ではなく、ナビから来た学生の状態です。説明会の前に会社ページとストーリーを読んだ学生は、説明会で「読んだとおりか」を確かめに来るので、選考の途中で離れにくくなります。足す目的を「数」から「ナビから来た学生に読ませる場所」に置き換えられるかで、併用が続くかが決まります。

## ナビに書くことと、Wantedlyに書くことを分ける

学生は両方を見るので、同じ文章が二度出てくると、「どちらも本気で書いていない」と読まれます。

| 書く場所 | 書くこと | 書かないこと |
|---|---|---|
| ナビの掲載情報 | 事業・職種・勤務地・募集要項・説明会の日程。学生が並べて比べる項目 | 「なぜこの会社か」の長い文章。ここで読まれない |
| Wantedlyの会社ページ | 「なぜ」を代表の言葉の場面で。何をしている会社か | 募集要項の羅列。ナビと同じ項目 |
| Wantedlyのストーリー | 社員が何をどう変えた場面。学生が働く自分を想像できる話 | 「アットホーム」「風通しがよい」の抽象語 |
| Wantedlyの募集記事 | 最初の年に何をするか、誰と組むか、どう決まるか | ナビの募集要項の貼り直し |

- **中身は揃える、文章は分ける**：ナビの「事業内容」とWantedlyの「何をしている会社か」がずれていると、学生は迷う
- **ナビの「先輩社員の声」に出る社員を、Wantedlyのストーリーにも出す**：同じ人が、違う場面を話している形。学生は「同じ人だ」で安心する
- **説明会で話す言葉を、会社ページの「なぜ」と揃える**：読んで来た学生が、「読んだとおり」と感じる
- **新卒と中途を同じ会社ページで扱うなら、募集記事で分ける**：[Wantedlyで新卒と中途を同時に採るときの整理](/media/wt-shinsotsu-chuuto/)

## 予算と工数の配分｜ナビの時期に、Wantedlyの時間を止めない

| 項目 | ナビサイト | Wantedly |
|---|---|---|
| 費用の性格 | 掲載の枠と期間に応じた費用。現在の条件は各媒体の公式ページで確認 | 会社ページと記事を整える時間が中心。プランは公式ページで確認 |
| 会社側の時間が要る場面 | 掲載情報の入力、エントリーの受付、説明会の運営、選考の連絡 | 会社ページとストーリーの更新、募集記事、返信と面談 |
| 時期 | 開始から締切までに集中する | 通年で少しずつ続く |
| 止まりやすい時期 | 締切のあと | ナビの時期。エントリー対応に時間が取られる |

- **ナビの時期に、Wantedlyの更新時間を予定に固定する**：エントリー対応で手一杯になり、会社ページの更新が止まる。月に一度、時間を固定しておく
- **ナビの締切のあとに、Wantedlyのストーリーを増やす**：説明会で学生に聞かれたことを、ストーリーの題材にする。ナビの時期に集めた言葉が、Wantedlyの元になる
- **両方を出す年は、説明会と面談の人数を先に決める**：媒体が増えても、会う人の時間は増えない

媒体を何本併用するかは、予算ではなく担当者の時間で決めます。[媒体を何本併用するか](/media/hikaku-fukusuu-baitai/)で書いた考え方と同じです。ナビとWantedlyは、時間の要る時期がずれているので、担当者が一人でも回せますが、ナビの時期にWantedlyが止まることだけは、予定で防ぎます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| ナビと同じ文章をWantedlyに貼る | 学生に「どちらも本気で書いていない」と読まれる | 中身を揃え、文章と場面を分ける |
| Wantedlyに「エントリーの数」を求める | 初年度に「来ない」と判断して止める | 目的を「読ませる場所」に置き直す |
| ナビの時期に、Wantedlyの更新を止める | 説明会の前に読みに来た学生が、古い会社ページを見る | 月に一度の更新時間を予定に固定 |
| ナビの締切で、Wantedlyの募集記事も閉じる | 締切のあとに会社を読んだ学生の行き先がなくなる | 記事は残し、時期だけ書き換える |
| Wantedlyから来た学生を、ナビの流れで扱う | 会社を読んで来た学生に、会社の説明から始めて温度が下がる | 入口を台帳に残し、仕事の場面から話す |

最も多いのは、二つ目です。Wantedlyの効果は、数ではなく、来た学生が「記事のどこを見て来たか」を言えるかで見ます。見方は[Wantedlyの効果が測れないときのKPIの置き直し](/media/wt-kouka-sokutei/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| ナビの掲載情報を入れ、エントリーを受ける | 人事 |
| Wantedlyの会社ページの「なぜ」を代表の言葉で書く | 人事と代表 |
| ストーリーに出る社員を決め、話を聞く | 人事と、出る社員 |
| ナビの導線と説明会の案内に、会社ページへの案内を入れる | 人事 |
| 説明会で「読んで来たか」を聞き、台帳に残す | 説明会に出る人 |
| ナビの時期のWantedlyの更新時間を固定する | 人事と責任者 |
| 説明会と面談の人数、両方を出すかの判断 | 責任者 |

運用代行や代理店が支えられるのは、役割の整理、書き分けの型、導線の置き方、台帳の型、時間の置き方までで、会社ページの「なぜ」の決定、ストーリーに出る社員の選定、説明会で話すこと、会う人数の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先にWantedlyの会社ページの「なぜ」を代表の言葉の場面で書いておかないと、ナビと併用しても効果が出ません。当社はWantedlyの運用を申込のあとまで見ていますが、ナビと併用する会社で起きるのは、ナビから来た学生が説明会の前に会社ページを開いたときに、募集要項の貼り直しだけがあって「なぜ」がない、という状態です。学生は「ナビと同じことが書いてある」と閉じて、説明会に「読んで来た」学生がいなくなります。会社ページの「なぜ」が一つあれば、ナビから来た学生はそれを読んで説明会に来て、説明会で同じ言葉を聞いて「読んだとおり」と感じます。ナビの掲載を申し込む前に、会社ページの「なぜ」を書き終えるのが順番です。ナビの時期に入ってからでは、エントリー対応で時間が取れません。

## まとめ

- ナビは「決まった時期にエントリーを集める場」、Wantedlyは「会社を読んだ学生が通年で来る場」。学生の状態が違う
- 併用するなら、Wantedlyを「ナビから来た学生が会社を読む場所」として置く。集める入口として育てるのは、会社ページとストーリーが揃ってから
- ナビには並べて比べる項目を、Wantedlyには「なぜ」と場面を。中身は揃え、文章は分ける
- ナビの時期にWantedlyの更新時間を固定する。ナビの締切で記事を閉じない
- Wantedlyにナビと同じ「エントリーの数」を求めない。効果は、来た学生が「記事のどこを見て来たか」を言えるかで見る

## よくある質問

### ナビだけで足りている場合、Wantedlyを足す意味はありますか

「集める入口」としてではなく、「ナビから来た学生が説明会の前に会社を読む場所」として足す意味があります。読んで来た学生は、説明会で「読んだとおりか」を確かめに来るので、選考の途中で離れにくくなります。集める入口として足すなら、会社ページとストーリーを先に整えます。

### Wantedlyだけで新卒を集めている場合、ナビを足すべきですか

決まった時期に、条件で探している学生にも会いたいなら、ナビは向きます。Wantedlyだけでは、会社を読んで来る学生に限られるので、母集団の広さが要る年は、ナビを「時期の入口」として足します。足すなら、ナビの時期にWantedlyの更新が止まらないよう、時間を先に固定します。スカウト型とナビ型の違いは[スカウト型とナビ型の違い](/media/hikaku-scout-vs-navi/)で書きました。

### Wantedlyとナビサイトの併用は、御社に相談できますか

できます。当社は、役割の整理、書き分けの型、導線の置き方、台帳の型、時間の置き方を支えられます。会社ページの「なぜ」の決定、ストーリーに出る社員の選定、説明会で話すこと、会う人数の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
