創業家が経営していて、役員に家族がいる。オーナーが決めることが多い。OfferBoxで送るときに、同族であることを文面に書くか迷い、書かずに送ると、承認した学生が会社名で検索して「同族経営」と知り、面談で「意思決定はどうなっていますか」「評価は公平ですか」と聞いて、答えが曖昧だと離れます。**結論から言うと、学生は調べれば同族と分かるので、隠さず、「意思決定は誰がどう行うか」「評価は公平か」「経営者はどんな人か」を先に渡します。最初に決めるのは、名義を経営者にするか若手にするかを決めること、承認への当日返信を経営者の決裁から切り離すこと、面談に経営者が出る段を決めること、家族の役員と後継の扱いを聞かれたら答えられる形にすること、「アットホーム」を書かないことです。** この記事では、同族・オーナー企業が割ける時間と人、学生が確かめること、最初に決めること、文面の書き方、運用の分担、やりがちな失敗を整理します。代表の名義で送る文面の考え方は[代表名で送るスカウト文面](/media/kh-bunmen-daihyo/)で書きました。数値は書きません。

## この規模で割ける時間と人

| 状況 | 起きること |
|---|---|
| 採用の決裁が経営者に集中している | 承認への返信が「社長の確認待ち」で翌日以降にずれる |
| 経営者が採用に強い関心を持っている | 文面と面談に経営者が関わりすぎ、人事が動けない。または関心が薄く、人事だけで回して経営者が面談に出ない |
| 役員に家族がいる | 学生が「評価は公平か」「家族でない社員はどこまで上がれるか」を確かめる |
| 後継が決まっている、または決まっていない | 学生が「この会社は続くか」「誰が次に決めるか」を確かめる |
| 「家族的」「アットホーム」を強みだと考えている | 学生には「家族でない自分は外側」と読まれる |
| 社員の定着が長い | 学生には安心の材料。ただし「変わらない会社」とも読まれる |

同族・オーナー企業がOfferBoxに割ける時間は、経営者の時間の使い方で決まります。経営者が文面の確認と面談に時間を使うなら、それを上限に送る数を決め、経営者が関わらないなら、若手の名義と人事で回す形にします。決めていないと、承認が経営者の確認待ちで止まります。

## 学生が、承認の前に確かめること

- **意思決定は、誰が、どう行うか**：オーナーが一人で決めるのか、役員で決めるのか、現場に任せる範囲はどこまでか
- **評価は、公平か**：家族でない社員が、どこまで任され、どこまで上がれるか。実際に上がった社員がいるか
- **経営者は、どんな人か**：話し方、判断の仕方、社員との距離。会社名で検索して出てくる経営者の発信
- **家族の役員は、何をしているか**：役員に家族がいること自体より、「何を担当していて、社員とどう関わるか」
- **後継は、どうなっているか**：決まっているか、決まっていないか。「続く会社か」の材料
- **「家族的」の実態**：飲み会や行事が多いのか、休みは取れるのか、家族でない社員の扱い

学生は、これを面談で聞くか、聞けずに離れるかのどちらかです。先に渡せば、聞かれる前に判断できます。

### エージェントベストの見解

相談で最も多い思い込みは、「同族経営であることは、文面に書かないほうがよい」というものです。当社は3媒体すべての販売パートナーとしてOfferBoxの運用代行も受けていますが、書かずに送った会社でも、学生は承認の前に会社名で検索して、役員の名前と経営者の発信を見て、同族だと分かっています。分かったうえで承認した学生が面談で聞くのは、「同族ですか」ではなく、「家族でない社員は、どこまで任されますか」「決めるのは誰ですか」で、この二つに具体で答えられない会社から離れます。隠しても分かることは、隠すと不信になり、先に渡すと判断の材料になります。当社が同族・オーナー企業の文面を作るときは、「家族が経営しています」の一文と、「家族でない社員が〇〇まで任されています」の具体を、文面か採用サイトに入れます。承認の数は減りませんし、面談で「聞いていない」で離れる学生が減ります。

## 最初に決めること

1. **名義を、経営者にするか、若手にするかを決める**：経営者の名義は「経営者と直接話せる」が効くが、経営者の時間が上限になり、「経営者が全部決める会社」とも読まれる。若手の名義は「家族でない社員が働いている姿」が見える。会社の状態で選ぶ。経営者名義の効果と負担は[代表名で送るスカウト文面](/media/kh-bunmen-daihyo/)
2. **承認への当日返信を、経営者の決裁から切り離す**：一次の返信は人事か代行が型で行い、経営者の確認は面談の日程の判断だけに。「社長に聞いてから」で翌日にしない。[OfferBoxでオファーが承認されたあとの連絡手順](/media/ob-shounin-go/)
3. **面談に経営者が出る段を決める**：最初の面談から出るのか、二回目からか、最終だけか。決めていないと、経営者の予定で選考が止まる。[OfferBox経由の選考フローを短くする考え方](/media/ob-senkou-sekkei/)
4. **家族の役員と後継の扱いを、聞かれたら答えられる形にする**：「役員の〇〇は△△を担当しています」「後継は決まっています／決まっていません」。文面に長く書く必要はないが、面談で答える言葉を経営者と合意しておく
5. **家族でない社員が、どこまで任されているかを、一つの例で書ける形にする**：「入社〇年目の社員が、△△の責任者を任されています」。数値ではなく、役割で
6. **「アットホーム」「家族的」を書かない**：実態を場面で書く。「昼は全員で食べます」「行事は年に数回で、参加は自由です」

## 文面の書き方｜「家族的」ではなく「決め方」と「任され方」

| 書かない | 書く |
|---|---|
| 「アットホームな会社」「家族のような職場」 | 意思決定の実態。「〇〇は現場が決め、△△は役員会で決めます」 |
| 同族であることを隠す | 「創業家が経営しています」の一文と、家族でない社員が任されている例 |
| 「社長との距離が近い」だけ | 経営者が最近決めた場面と、その決め方 |
| 「安定した会社」 | 続いてきた理由を一つ。変えてきたことを一つ |
| 「長く働ける」 | 定着している社員が、何年目に何を任されたか。数値でなく役割で |

- **経営者の名義なら、経営者が最近決めた場面を一つ**：理念ではなく、判断の仕方が見える場面
- **若手の名義なら、家族でない自分が任されている場面を一つ**：「私は〇〇の担当で、△△を自分で決めています」
- **文面の基本**：[OfferBoxのオファー文面の基本](/media/ob-offer-bunmen-kihon/)。採用サイトに意思決定と評価の実態を置く。[OfferBoxと採用サイトの役割分担](/media/ob-heiyou-saiyo-hp/)

## 面談で確かめてもらうこと

- **経営者が出る面談で、「決め方」を話す**：最近決めたこと、迷ったこと、社員に任せたこと
- **家族でない社員に、面談に出てもらう**：「家族でない自分が、どこまで任されているか」を本人の口から。名義が経営者でも、この面談は要る
- **家族の役員について聞かれたら、担当と関わりを具体で**：「聞かないでほしい」の空気を出さない
- **後継について聞かれたら、決まっている・いないをそのまま**：「決まっていないが、〇〇の時点で決める」でよい
- **面談の入口は、文面の続きから**：[OfferBox経由の学生との初回面談の設計](/media/ob-mendan-sekkei/)

## 運用の分担

| 作業 | 誰が |
|---|---|
| 名義を経営者にするか若手にするかの決定 | 経営者と人事 |
| 意思決定・評価・家族の役員・後継を、答えられる形に合意する | 経営者と人事 |
| 「こんな人」の一行と検索条件 | 人事と現場（経営者が合意） |
| 検索、文面の下書き、送信、一次返信 | 人事、または代行 |
| 文面の最終確認 | 名義の本人（経営者か若手） |
| 面談の日程の判断 | 人事。経営者の予定は先に押さえる |
| 面談 | 経営者（決めた段で）と、家族でない社員 |
| 内定のあとの連絡 | 経営者か人事。[OfferBoxの内定者フォロー](/media/ob-naitei-follow/) |

- **経営者の決裁を、承認への返信の手前に置かない**：型で返し、経営者は面談から
- **経営者が関わりすぎるなら、頼むことを三つに絞る**：名義（するなら）、決め方を話す面談、内定の連絡
- **経営者が関わらないなら、若手の名義と人事で回し、経営者は最終の面談だけ**：[OfferBoxの運用代行に任せられる範囲と自社で持つ判断](/media/ob-unyou-daikou-hanni/)

運用代行や代理店が支えられるのは、学生が確かめる五つを整理する型、文面の型、検索・下書き・送信・一次返信、面談の段の設計までで、名義の決定、意思決定と評価の実態の開示、面談、内定の連絡は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

送り始めたあと、最初の送る時期で起きることに共通するのは、承認への返信が「社長に確認してから」で翌日以降にずれることです。当社はOfferBoxの運用代行で同族・オーナー企業の承認から返信までの日数を見ていますが、経営者が採用に関心を持っている会社ほど、承認のたびに経営者の判断を待ち、返信が遅れ、面談の日程が経営者の予定待ちになり、承認した学生が他社に決まります。経営者の関心は、承認への返信ではなく、面談で「決め方」を話すことに使うのが、学生にとっても会社にとっても効きます。当社が同族・オーナー企業の代行を受けるときは、承認への一次の返信を型で当社が行い、経営者には「面談に出る段」と「その予定を先に押さえること」だけを決めてもらいます。経営者の判断を承認の手前から外すと、返信は当日に戻り、経営者の時間は面談に集まります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 同族であることを隠して送る | 学生が調べて分かり、面談で「隠していた」と読む | 一文と、家族でない社員の例を先に渡す |
| 「アットホーム」「家族的」で書く | 「家族でない自分は外側」と読まれる | 決め方と任され方を場面で |
| 承認への返信を経営者の確認待ちにする | 翌日以降にずれ、他社に決まる | 一次の返信を型で切り離す |
| 経営者が面談に出る段を決めない | 経営者の予定で選考が止まる | 出る段と予定を先に |
| 家族でない社員が面談に出ない | 「どこまで任されるか」を本人から聞けない | 家族でない社員の面談を入れる |

最も多いのは、一つ目です。同族であることを弱みだと考えて隠し、学生が調べて分かったときに、不信に変わります。

## まとめ

- 学生は調べれば同族と分かる。隠さず、「意思決定は誰がどう行うか」「評価は公平か」「経営者はどんな人か」を先に渡す
- 名義を経営者にするか若手にするかを会社の状態で決める。経営者名義は「直接話せる」が効くが、時間が上限になる
- 承認への当日返信を経営者の決裁から切り離し、経営者は面談に出る段を決めて予定を先に押さえる
- 「アットホーム」を書かず、意思決定の実態と、家族でない社員が任されている例を場面で書く。家族の役員と後継は聞かれたら答えられる形に
- 家族でない社員を面談に出す。経営者の時間は、返信ではなく「決め方」を話す面談に使う

## よくある質問

### 後継が決まっていません。学生に聞かれたらどう答えますか

「決まっていません。〇〇の時点で決めます」とそのまま答えます。決まっていないことを隠すより、決める時期と決め方を言うほうが、学生は「続く会社か」を判断できます。「そのうち」「まだ先」と濁すと、「決めていない会社」と読まれます。

### 経営者が「自分が全部見る」と言って、人事が動けません

経営者に頼むことを、名義（するなら）、面談に出る段、内定の連絡の三つに絞り、承認への返信と面談の日程は人事か代行が型で行う形を、経営者と合意します。「全部見る」と返信が遅れて学生を失うことを、承認から返信までの日数で見せると、合意しやすくなります。

### 同族・オーナー企業のOfferBox運用は、御社に相談できますか

できます。当社は、学生が確かめる五つを整理する型、文面の型、検索・下書き・送信・一次返信、面談の段の設計を支えられます。名義の決定、意思決定と評価の実態の開示、面談、内定の連絡は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用代行も受けています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
