社内イベントは、ストーリーの題材として最も書きやすく、最も候補者に届きにくいものです。歓迎会、社員旅行、周年、運動会。写真が撮りやすく、書くことに困らず、社内の反応も良い。ところが、候補者にとっては「どの会社も似た楽しそうな写真」で、自分が働く姿を想像する材料になりません。**結論から言うと、社内イベントを書くなら、イベントの様子ではなく「裏で誰がどう動いたか」を書きます。準備で揉めたこと、参加しなかった人をどう扱ったか、イベントで何が変わったか。ここにカルチャーが出ます。楽しさの報告は、閲覧が多くても候補者は来ません。** この記事では、イベントの記事の位置づけ、書く内容、写真とプライバシー、参加が任意であることの明記、頻度、イベントが少ない会社の判断、やりがちな失敗、分担を整理します。カルチャーの書き方は[カルチャーを伝える書き方](/media/wt-story-culture/)、ストーリーの位置づけは[ストーリーの基本](/media/wt-story-kihon/)で書きました。

## この作業の目的｜イベントを「動き方」の材料にする

候補者がイベントの記事を読んで知りたいのは、「楽しそうか」ではなく、「この会社の人は、仕事以外の場面でどう動くか」です。誰が企画し、誰が手伝い、意見が割れたときにどう決め、参加したくない人はどうしたか。

イベントの目的は、社内の関係を作ることです。記事の目的は、その関係の作り方を候補者に見せることです。楽しかった様子を伝えることではありません。

イベントは、カルチャーの「結果」です。記事にするのは、結果ではなく、そこに至る「動き」です。この考え方は、カルチャーの記事で書いたとおりです。

## 手順1｜書く内容｜様子ではなく、動き

イベントの記事に書くことを、「書きがち」と「書くべき」で分けます。

| 書きがち（様子） | 書くべき（動き） |
|---|---|
| 「〇〇を開催しました」 | 「〇〇を、誰が言い出して、なぜやることになったか」 |
| 「みんな楽しみました」 | 「準備で、△△と□□の意見が割れて、どう決めたか」 |
| 「料理がおいしかったです」 | 「当日、想定と違うことが起きて、誰がどう動いたか」 |
| 「新入社員も参加しました」 | 「新しく入った人が、初めてのイベントで、周りがどう接したか」 |
| 「来年もやります」 | 「イベントのあと、社内で何が変わったか。変わらなかったか」 |
| 「参加率が高いです」 | 「参加しなかった人がいて、それをどう扱ったか。参加は任意で、任意であることをどう保っているか」 |

「参加しなかった人の扱い」は、見落とされやすく、最もカルチャーが出る部分です。参加しない人を責めない会社か、参加が事実上の強制になっている会社か。候補者は、ここを読んでいます。

## 手順2｜参加が任意であることを書く

イベントの記事で、候補者が最も気にするのは「自分も参加しなければならないのか」です。

1. **参加が任意であることを、記事に明記する**：「参加は任意で、今回は〇割程度」のように。ただし数字は出さなくてよい。「参加しない人もいる」で足りる
2. **参加しなかった人が不利にならないことを、事実で書く**：「参加しなかった人にも、翌日に写真と様子を共有した」のように
3. **業務時間内か、業務外かを書く**：業務外のイベントなら、そのことを書く。候補者は「業務外に拘束されるか」を見ている
4. **費用の負担を書く**：会社負担か、自己負担か。金額は書かなくてよい。負担の有無だけ
5. **「全員参加」「参加率」を強みとして書かない**：候補者には「強制」に映る

任意であることを書くと、「参加が当たり前」の会社より候補者に選ばれやすくなります。「みんな参加します」は、候補者を遠ざける言葉です。

### エージェントベストの見解

相談で最も多い思い込みは、「イベントの記事は楽しそうに見せて、会社の雰囲気の良さをアピールするものだ」というものです。実際には、楽しそうなイベントの写真と「みんな仲良し」の文章は、どの会社のストーリーにもあり、候補者は見分けがつきません。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、イベントの記事は閲覧が多くなることがあっても、そこから話を聞きに来る候補者はほとんどいません。閲覧は「見た」までで、「この会社で働きたい」にはつながっていないのです。逆に、「イベントの準備で意見が割れて、こう決めた」「参加しなかった人に、翌日こう共有した」と書いた記事は、閲覧は少なくても、読んだ候補者が面談で「あの記事の決め方が自分に合うと思った」と言います。イベントの記事は、楽しさを減らして、動きを足すもの。閲覧の多さに安心しないことを勧めます。

## 手順3｜写真とプライバシー

イベントの写真は、通常のストーリーより注意が要ります。

| 注意 | 理由と対処 |
|---|---|
| 写っている全員の同意 | イベントの写真は多人数が写る。全員に見せて同意を取る。同意しない人が写っていれば、その写真は使わない |
| 飲食の場面、酒が写る場面 | 候補者に「飲み会が多い会社」と映る。載せない |
| 私的な場面 | 業務外の私的な時間は、本人が望まなければ載せない |
| 家族が写る場面 | 社員の家族は社員ではない。同意が取れても、原則載せない |
| 顔を出したくない人 | 後ろ姿や、写っていない写真を選ぶ |
| 場所や日時が特定される写真 | 社員の私生活の特定につながるなら、避ける |

「動き」を書く記事なら、写真は準備の場面や、当日の裏方の場面で足ります。集合写真や乾杯の写真は要りません。写真の選び方の基本は[会社ページの写真の選び方](/media/wt-kaisha-page-photo/)で書きました。

## 手順4｜頻度を上げない

イベントの記事は、書きやすいので増えがちです。増えると、ストーリー全体が「イベントの会社」に見えます。

- **イベントの記事は、他の型の間に挟む程度に**：社員の話、事業の裏側、代表の考えが中心。ローテーションの考え方は[ストーリーのテーマの決め方](/media/wt-story-theme/)
- **すべてのイベントを記事にしない**：動きが書けるイベントだけ。「準備で何かが起きた」イベントを選ぶ
- **イベントが続く時期でも、記事は絞る**：年に数本で足りる
- **イベントの記事が続いたら、しばらく書かない**：候補者に「仕事の話が無い」と映る

イベントの記事の数が、ストーリーの中で目立つなら、多すぎます。

## 手順5｜イベントが少ない会社は、書かなくてよい

イベントが少ない、または無い会社が、無理にイベントを企画して記事にする必要はありません。

1. **イベントが無いことは、カルチャーの一部**：「集まりは少なく、仕事の場で関係を作る」と書けば、それが会社の動き方
2. **イベントの代わりに、日常の場面を書く**：昼の過ごし方、雑談、仕事の合間。カルチャーの記事の場面の型で足りる
3. **イベントを企画して記事にするなら、企画の動きを書く**：「初めて〇〇をやることにした。言い出したのは△△で、□□が反対した」。動きがあれば記事になる
4. **イベントが少ないことを、候補者に隠さない**：「集まりが好きな人には物足りないかもしれない」と、「合わない人」として書く。書き方はカルチャーの記事で

「イベントが無いから書けない」ではなく、「イベントが無いこと自体を、動き方として書く」形です。

## 手順6｜書き方

イベントの記事の書き方を、手順にします。

1. **「準備で何が起きたか」を、企画した人に聞く**：誰が言い出したか、反対はあったか、どう決めたか
2. **「当日、想定と違ったこと」を聞く**：何が起きて、誰がどう動いたか
3. **「参加しなかった人」の扱いを聞く**：どう案内し、どう共有したか
4. **「イベントのあと、何が変わったか」を聞く**：変わっていなければ、変わっていないと書く
5. **場面から書き始める**：「〇〇をやることになった日」。「開催しました」から始めない
6. **任意であること、業務時間か業務外か、費用の負担を、一言で**
7. **写真は、準備か裏方の場面。全員の同意**
8. **募集記事か会社ページへ誘導する**：「この決め方をしているチームの募集はこちら」

聞き方の基本は[社員インタビューを書く手順](/media/wt-story-interview/)と同じで、「楽しかったですか」ではなく「何が起きましたか」を聞きます。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「開催しました。楽しみました」 | どの会社も同じ。候補者が来ない | 準備の動きと、揉めたこと |
| 「全員参加」「参加率」を強みに | 強制に映る | 任意であることと、参加しない人の扱い |
| 酒や飲食の場面の写真 | 「飲み会の会社」に映る | 準備や裏方の場面 |
| 写っている人の同意を全員から取らない | 後で問題になる | 全員に見せる |
| 家族が写る写真 | 社員でない人が載る | 原則載せない |
| イベントの記事が続く | 仕事の話が無い会社に見える | 他の型の間に挟む |
| 閲覧が多いので良い記事と思う | 来ない | 話を聞きに来た数で見る |
| イベントが無いので何も書かない | 日常の場面が書けるのに書いていない | 昼、雑談、仕事の合間を書く |
| 無理にイベントを企画して記事にする | 動きが無く、記事も薄い | 企画の動きがあるときだけ |

最も多いのは、最初の「開催しました。楽しみました」です。イベントの記事を「報告」と捉えると、こうなります。「動きの記録」と捉え直します。

| 作業 | 誰が |
|---|---|

| 企画した人と、参加しなかった人の扱いを聞く | 人事 |
| 書く | 人事 |
| 任意・時間・費用の一言を確認する | 人事（総務に確認） |

運用代行や代理店が支えられるのは、書く内容の型と聞く質問、様子を動きに書き換える案までで、写真の同意と、任意・時間・費用の事実確認は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

媒体を比べたり運用を見直したりするときに、イベントの記事の閲覧の多さを「ストーリーがうまくいっている証拠」と見る会社は多いのですが、閲覧と、話を聞きに来る数は別です。当社がWantedlyの運用でストーリーの効果を見るときは、記事ごとの閲覧ではなく、面談で候補者に聞く「どのストーリーを読んで来ましたか」で見ます。この聞き方で、イベントの記事が挙がることはほとんどなく、社員の話や事業の裏側が挙がります。イベントの記事は、閲覧を稼いでも、候補者を連れてきません。閲覧のために書くなら、書かないほうがストーリー全体の質が上がります。書くなら、動きを書く。それが、イベントの記事が候補者に届く唯一の形です。

## まとめ

- 社内イベントを書くなら、様子や楽しさではなく、準備で誰がどう動いたか、揉めたこと、参加しなかった人の扱い、イベントで何が変わったかを書く
- 参加が任意であること、業務時間か業務外か、費用の負担を一言で書く。「全員参加」「参加率」を強みにしない
- 写真は全員の同意を取り、酒や飲食、私的な場面、家族が写る場面は載せない。準備や裏方の場面で足りる
- イベントの記事は他の型の間に挟む程度に絞る。閲覧が多くても候補者は来ない
- イベントが少ない会社は、無いこと自体を動き方として書く。無理に企画して記事にしない

## よくある質問

### 社員旅行や周年のイベントを、記事にしてよいですか

構いませんが、様子ではなく動きを書きます。誰が企画し、準備で何が起きて、参加しなかった人をどう扱い、あとで何が変わったか。写真は準備や裏方の場面にし、全員の同意を取り、酒や私的な場面は載せません。「楽しかった」で終わる記事にはしません。

### イベントがほとんど無い会社です。カルチャーをどう伝えればよいですか

イベントが無いこと自体を、動き方として書きます。「集まりは少なく、仕事の場で関係を作る」と書き、昼の過ごし方、雑談、仕事の合間の場面をカルチャーの記事にします。「集まりが好きな人には物足りないかもしれない」と、合わない人も書くと、候補者が判断できます。

### イベントの記事の作成は、御社に相談できますか

できます。当社は、書く内容の型、聞く質問、様子を動きに書き換える案を支えられます。写真の同意と、任意・時間・費用の事実の確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのストーリーの整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
