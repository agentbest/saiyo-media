募集記事は、一覧の中でタイトルだけが見えます。候補者は、タイトルで開くかどうかを決め、開いてから本文を読みます。**結論から言うと、募集タイトルは職種名ではなく「何をする人を探しているか」を一言で伝えるもので、本文の「この募集で何をやるか」を書いてから、それを縮めて作ります。「急募」「大募集」のような会社の都合や、「挑戦」「成長」のような抽象語は、一覧で他社と見分けがつかず開かれません。** この記事では、タイトルの役割、開かれる型と開かれない型、作る手順、新卒と中途での言葉の違い、試し方、やりがちな失敗、分担を整理します。募集記事の全体の構成は[募集記事の基本構成](/media/wt-boshu-kihon/)で書きました。この記事は、その中の「タイトル」の部分です。

## この作業の目的｜一覧で「自分に関係がある」と思ってもらう

候補者は、Wantedlyで複数の募集を一覧で見ます。見えるのは、会社名、タイトル、写真の一部です。タイトルが「営業」「エンジニア」のような職種名だけだと、他の会社の同じ職種名と並び、見分けがつきません。

タイトルの目的は、一覧で「これは自分に関係がある」「この会社は何か違う」と思ってもらい、開いてもらうことです。会社を説明することでも、条件を伝えることでもありません。OfferBoxのオファーで「件名にあたる部分は開く理由を一言で渡す」と書いたのと同じ役割です。考え方は[件名で開封が変わる理由](/media/ob-offer-kenmei/)で書きました。

## 手順1｜開かれる型と、開かれない型

| 開かれる型 | 例（型） | なぜ開かれるか |
|---|---|---|
| 何をする人を探しているか | 「〇〇を一緒に立ち上げる△△」 | 入ったら何をするかが一言で分かる |
| 誰のために何をするか | 「□□に困っている人を、〇〇で助ける△△」 | 仕事の意味が分かる |
| どんな状況で | 「事業が広がって、〇〇を任せられる人を探しています」 | この募集が生まれた理由が分かる |
| 誰と | 「〇〇出身のチームで、△△をやる人」 | 一緒に働く人の像が見える |
| 候補者の状態に向けて | 「〇〇に飽きた人へ。△△をやりませんか」 | 自分のことだと思う |

| 開かれない型 | なぜ開かれないか |
|---|---|
| 職種名だけ（「営業」「エンジニア」「総合職」） | 他社と同じ |
| 「急募」「大募集」「積極採用中」 | 会社の都合。候補者に関係が無い |
| 「挑戦したい人」「成長できる環境」 | 抽象語。どの会社にも書いてある |
| 「未経験歓迎」だけ | 条件であって、何をするかが無い |
| 社内用語や独自の職種名 | 候補者に何の仕事か分からない |
| 「！」や記号、絵文字の多用 | 軽く見える |
| 長すぎて一覧で切れる | 肝心の一言が見えない |

開かれない型に共通するのは、「候補者に関係が無い」ことです。会社の都合、抽象語、条件だけは、どれも候補者の側から見て「自分のこと」ではありません。

## 手順2｜本文を書いてから、縮めて作る

タイトルは、先に作りません。本文の「この募集で何をやるか」を書いてから、その要約として作ります。募集記事の書く順番は、[募集記事の基本構成](/media/wt-boshu-kihon/)で「タイトルは最後に」と書きました。

1. **本文の「この募集で何をやるか」を書く**：最初にやること、その後、この募集が生まれた理由
2. **「最初にやること」と「理由」を、それぞれ一言にする**：「〇〇を立ち上げる」「事業が広がったので」
3. **どちらか、または組み合わせで、一文にする**：「事業が広がって、〇〇を立ち上げる△△を探しています」
4. **一覧で切れない長さにする**：長ければ「何をやるか」だけを残す
5. **会社名と並んだときに、他社と違って見えるかを確かめる**：同じ職種の他社の募集を一覧で見て、自社のタイトルを横に置いてみる
6. **煽りと抽象語が入っていないかを見る**

先にタイトルを作ると、本文と内容がずれます。「〇〇を立ち上げる」とタイトルにあるのに、本文には立ち上げの話が無い。開いた候補者は「タイトルと違う」と感じます。本文が先、タイトルはあと。この順番だと、ずれません。

### エージェントベストの見解

これをやる前に、先に決めておかないとタイトルが作れないことがあります。「本文の『この募集で何をやるか』が書けているか」です。当社がWantedlyの運用の相談で募集記事を見るとき、タイトルが職種名だけの記事は、本文の「何をやるか」も「幅広い業務」で終わっていることが多くあります。タイトルに書くことが無いのは、本文に書くことが無いからです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、開かれているタイトルは、例外なく本文の「何をやるか」が具体的で、タイトルはその要約になっています。タイトルの工夫より、本文の「最初にやること」を配属先に聞いて書く。書けていれば、タイトルは数分で縮められます。書けていなければ、どれだけタイトルを工夫しても、開いた候補者が本文で止まります。

## 手順3｜新卒と中途で、言葉を変える

同じ募集でも、新卒向けと中途向けで、タイトルに使う言葉が違います。

| 観点 | 新卒向け | 中途向け |
|---|---|---|
| 探している人の表し方 | 「〇〇に興味がある学生」「□□を一緒に学ぶ人」。経験ではなく志向で | 「〇〇の経験を△△に活かす人」。経験と、その先で |
| 仕事の表し方 | 何をする仕事かを、業界を知らない前提で | 職種の一般的な言葉で。ただし社内用語は避ける |
| 状況の表し方 | 「来年、〇〇を始めるので」。入社時期を意識して | 「いま、〇〇が動いているので」。すぐの参加を意識して |
| 避ける言葉 | 「即戦力」「経験者」 | 「学生」「新卒」向けの言葉 |

新卒向けのタイトルに「即戦力」と書くと、学生は「自分ではない」と閉じます。中途向けに「一緒に学ぶ」と書くと、経験者は「求められていない」と感じます。誰に向けた募集かで、言葉を選びます。

## 手順4｜試し方

タイトルの型を試すときは、次の形にします。OfferBoxの件名の試し方と同じです。

1. **2つの型を用意する**：たとえば「何をする人を探しているか」と「誰のために何をするか」
2. **同じ募集で、期間を分けて使う**：同時に2つは出せないので、月ごとに
3. **月の「話を聞きに来た数」で比べる**：閲覧の数が見えるなら参考にするが、開かれても話を聞きに来なければ意味が無い
4. **差があれば、効いた型を残す**：差が無ければ、どちらでもよい
5. **タイトルと本文を同時に変えない**：何が効いたか分からなくなる

閲覧の数だけを追うと、煽りのタイトルに寄ります。煽りは開かれても、話を聞きに来ません。比べるのは、話を聞きに来た数です。

## 手順5｜募集の状況が変わったら、タイトルも変える

募集は、時間とともに状況が変わります。タイトルもそれに合わせます。

- **募集が生まれた理由が変わった**：「立ち上げ」が終わって「拡大」になった。タイトルの状況の部分を変える
- **最初にやることが変わった**：本文を直し、タイトルも縮め直す
- **長く出していて反応が落ちた**：型を変えて試す。ただし本文も見直す
- **募集を閉じるとき**：閉じる。古い募集が残っていると、会社ページの印象が古くなる。更新の仕組みは[会社ページを更新し続ける仕組み](/media/wt-kaisha-page-koushin/)

「長く出していて反応が落ちた」は、タイトルの問題より、本文が古くなっている問題であることが多いです。タイトルだけ変えて本文が古いままだと、開いた候補者が本文で止まります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 職種名だけ | 他社と同じで開かれない | 何をする人を探しているかを一言 |
| 「急募」「大募集」 | 会社の都合。候補者に関係が無い | 募集が生まれた理由を書く |
| 「挑戦」「成長」 | 抽象語。見分けがつかない | 具体的な仕事の一言 |
| 先にタイトルを作る | 本文とずれる | 本文を書いてから縮める |
| 新卒向けに「即戦力」 | 学生が閉じる | 志向で書く |
| 煽りで閲覧を増やす | 開かれても話を聞きに来ない | 話を聞きに来た数で比べる |
| 長すぎる | 一覧で切れる | 何をやるかだけ残す |
| 状況が変わっても変えない | 本文と合わなくなる | 本文を直したらタイトルも |

最も多いのは、最初の「職種名だけ」です。募集記事のタイトルの欄に、職種名を入れる習慣から来ています。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 本文の「この募集で何をやるか」を書く | 人事（配属先の責任者に聞いて） |
| 縮めてタイトルにする | 人事 |
| 他社の募集と並べて確かめる | 人事 |
| 配属先の責任者が確認する | 配属先の責任者 |
| 型を試し、月で比べる | 人事 |
| 状況が変わったら直す | 人事 |

配属先の責任者の時間は、「何をやるか」を話すことと、タイトルを確認することの2つです。運用代行や代理店が支えられるのは、開かれる型の提供と、本文から縮める作業までで、「何をやるか」の実態は配属先にしか出せません。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

媒体を比べたり募集記事を見直したりするときに、閲覧の数でタイトルの良し悪しを判断しようとする会社は多いのですが、閲覧は「開かれた」までで、「話を聞きに来た」ではありません。当社がWantedlyの運用でタイトルを見直すときは、閲覧ではなく、月の「話を聞きに来た数」で、タイトルの型を変えた前後を比べます。閲覧だけを追うと、「急募」「限定」のような煽りに寄り、開かれても本文で離れ、話を聞きに来る人は増えません。タイトルは、話を聞きに来るまでの流れの最初の関門であって、独立した指標ではない。この位置づけで見ると、タイトルにかける時間は「本文を縮める数分」で足り、閲覧の解釈に時間を使う必要は無くなります。本文が良ければ、タイトルはその要約で足ります。

## まとめ

- 募集タイトルは職種名ではなく、「何をする人を探しているか」を一言で。一覧で「自分に関係がある」と思ってもらうため
- 開かれるのは、何をする人か・誰のために何を・どんな状況で・誰と・候補者の状態に向けて。開かれないのは、職種名だけ・会社の都合・抽象語・条件だけ・社内用語・長すぎ
- 本文の「この募集で何をやるか」を書いてから縮める。先に作ると本文とずれる
- 新卒向けと中途向けで言葉を変える。「即戦力」は学生を閉じさせる
- 閲覧ではなく、月の「話を聞きに来た数」で型を比べる。状況が変わったら本文とタイトルを直す

## よくある質問

### 職種名を入れないと、候補者に何の募集か分かりませんか

職種名を入れても構いませんが、職種名だけにしません。「〇〇を立ち上げる営業」のように、何をする人かを職種名に添えます。職種名だけだと、同じ職種名の他社の募集と並んで見分けがつきません。

### タイトルを変えたら閲覧は増えましたが、話を聞きに来る人が増えません

煽りの言葉で開かれている可能性があります。開いた候補者が本文で離れているなら、本文の「この募集で何をやるか」が薄いか、タイトルと本文がずれています。タイトルではなく本文を見直し、タイトルはその要約に戻します。

### 募集タイトルの作成は、御社に相談できますか

できます。当社は、開かれる型の提供と、本文の「何をやるか」から縮める作業、他社の募集と並べて確かめることを支えられます。「何をやるか」の実態は、配属先に出していただきます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
