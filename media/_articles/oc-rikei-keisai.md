理系学生に向けた掲載で、「研究を活かせます」「専門性を発揮できます」と書く会社は多くあります。ところが、理系学生は、自分の研究と会社の仕事が直接つながることは少ないと分かっていて、この言葉を読むと「研究のことを分かっていない」と感じます。**結論から言うと、理系学生向けの掲載は、「研究との関係」を無理に書かず、技術職の最初の1年に何をするか、開発や設計をどう進めているか、選考で研究をどう聞くか（内容ではなく進め方）、技術系の社員の話、専攻と配属の関係、を書きます。理系学生は体験談で「研究をどう聞かれたか」「技術面接の中身」を読んでから来るので、選考で研究をどう聞くかを企業ページに書き、技術面接の型を揃えます。** この記事では、理系学生が体験談で読んでいること、やりがちな失敗、置くもの、研究と仕事が離れている場合、技術面接の型、分担を整理します。OfferBoxで理系学生に送る文面は[OfferBoxで理系学生にオファーを送るときの文面](/media/ob-rikei-gakusei/)で書きましたが、考え方は同じで、「研究内容より研究の進め方」です。

## この作業の目的｜理系学生が「この会社は、研究をこう見て、技術をこう使う」と分かる状態にする

理系学生は、「研究がそのまま仕事になる」とは思っていません。知りたいのは、「この会社は、自分の研究のどこを見て、入ったら何をやらせて、技術をどう使っているか」です。

目的は、その三つに、事実で答えることです。「活かせる」の一言ではなく、「研究の進め方を聞く」「最初の月は〇〇から」「設計は△△の形で進めている」と書けば、理系学生は自分の研究と比べて判断できます。

## 理系学生が、体験談で読んでいること

| 読んでいること | 掲載への意味 |
|---|---|
| 研究をどう聞かれたか（内容か、進め方か、深さ） | 「選考で研究をどう聞くか」を企業ページに |
| 技術面接の中身（何を聞かれ、何を見られたか） | 技術面接の型と、何を見るかを書く |
| 配属と研究の関係（研究と近い部署に行けたか） | 専攻と配属の関係を事実で |
| 技術系の社員がどんな人か | 技術系の社員の話を置く |
| 開発や設計の進め方（体制、道具、裁量） | 進め方を具体的に |
| 研究と仕事が違ったときにどうだったか | 離れている場合の書き方 |

「研究をどう聞かれたか」が、理系学生の体験談で最も多く書かれることの一つです。ここに企業ページで先に答えると、学生は準備の方向が分かります。

## やりがちな失敗

| 失敗 | 理系学生からどう見えるか |
|---|---|
| 「研究を活かせる」「専門性を発揮」の抽象語 | 研究のことを分かっていない |
| 研究内容と仕事を無理に結びつける（「〇〇の研究は当社の△△に直結」） | 直結しないことを学生は知っている。無理があると分かる |
| 技術職の最初の1年が無く、「幅広い業務」だけ | 何をするか想像できない |
| 選考で研究をどう聞くかが無い | 体験談だけで準備する。「何を見ているか分からなかった」 |
| 技術面接の型が面接官で違う | 体験談に「面接官によって全然違った」 |
| 専攻で絞る（「〇〇系のみ」）が、実態は違う | 「専攻は関係なかった」と体験談に |
| 技術系の社員の話が無く、人事の言葉だけ | 「技術の話ができる人がいない会社」 |
| 業界用語と社内の言葉で書く | 分野が違う理系学生には分からない |

最も多いのは、最初の「活かせる」です。会社側は配慮のつもりですが、学生には空の言葉に映ります。

### エージェントベストの見解

相談で最も多い思い込みは、「理系学生には、研究と仕事のつながりを示さないと来ない」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を支えていますが、理系学生の体験談を読むと、「研究とのつながり」より「研究の進め方をどう聞かれたか」「入ってから何をするか」が書かれています。学生は、研究がそのまま仕事にならないことを知っていて、会社が無理につなげると「分かっていない」と読みます。当社が理系向けの掲載を整えるとき、最初にやるのは、「研究を活かせる」の一文を消し、「選考では、研究の内容そのものより、どう進めたか、どこで詰まったかを聞きます」の一文に置き換えることです。この一文で、理系学生は準備の方向が分かり、「研究を見てくれる会社」と読みます。

## 置くもの

| 置くもの | 書き方 |
|---|---|
| 技術職の最初の1年 | 最初の月・3か月・1年目の終わりに何をしているか。「最初の月は〇〇の設計を先輩と一緒に、3か月目に△△を一人で」。書き方は[新卒向け募集記事の書き方](/media/wt-boshu-shinsotsu/)と同じ |
| 開発や設計の進め方 | 体制、レビュー、道具、何を自分で決められるか。技術名の羅列ではなく、進め方。エンジニアの場合は[エンジニア向けスカウト文面の型](/media/wt-scout-bunmen-rei-eng/)の考え方 |
| 選考で研究をどう聞くか | 「内容そのものより、どう進めたか、どこで詰まったか、どう解決したかを聞きます」「分野が違っても構いません」 |
| 技術面接で何を見るか | 「〇〇を一緒に考える」「正解より、考える順番」。抽象語にしない |
| 技術系の社員の話 | 入社してまもない技術系の社員の、研究と仕事の違い、最初の1年 |
| 専攻と配属の関係 | 事実で。「専攻は問わない」なら、その旨と、実際に違う専攻から入った人の話 |
| 研究を続けられるか、学会に出られるか | 聞かれることが多い。事実で。制度が無ければ無いと |

「選考で研究をどう聞くか」を企業ページに書くと、体験談の「研究をどう聞かれたか」と揃い、学生は「企業ページどおりだった」と書きます。

## 研究と仕事が、離れている場合の書き方

多くの会社で、理系学生の研究と仕事は直接つながりません。その場合、次の形で書きます。

- **「研究の内容は問いません」と明記する**：「分野が違っても構いません」
- **見るのは「研究の進め方」だと書く**：仮説を立て、試し、詰まり、直す、という進め方が仕事と重なる
- **実際に、違う分野から入った技術系の社員の話を置く**：「〇〇を研究していた人が、いま△△をしている」
- **最初の1年で、研究と違う技術をどう身につけるかを書く**：「最初の3か月は〇〇の研修と、先輩との設計」
- **「研究を活かせる」とは書かない**：離れているなら、離れていると書く

「離れていると書く」ことが、理系学生には「正直な会社」と読まれます。無理につなげると、体験談に「研究は関係なかった」と書かれます。

## 技術面接の型を、揃える

理系学生の体験談で多いのが、「面接官によって聞くことが全然違った」です。

- **技術面接で聞くことの型を、段階ごとに作る**：「研究の進め方を聞く段階」「〇〇を一緒に考える段階」
- **面接に出る技術系の人全員に、型を渡す**：掲載に書いた「何を見るか」と揃える
- **研究の内容の深掘りは、するかしないかを決める**：するなら「分野が違う面接官でも聞ける聞き方」で
- **技術の課題を出すなら、掲載に書く**：「〇〇の段階で、△△の課題があります」。書かずに出さない
- **面接後の一行を、技術系の面接官からも集める**：「よく聞かれたこと」「詰まった様子」

型を揃える考え方は[本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。理系の場合、技術系の面接官が複数いて、型が無いとばらつきが大きくなります。

## イベントの型

| 型 | 中身 | 話す人 |
|---|---|---|
| 技術職の仕事を知る会 | 最初の1年、開発の進め方、いま詰まっていること | 技術系の入社してまもない社員 |
| 選考で研究をどう聞くかの説明 | 研究の進め方をどう聞くか、技術面接で何を見るか | 技術系の面接官 |
| 研究と仕事の違いを聞く会 | 違う分野から入った社員の話 | 技術系の社員 |
| 開発の現場を見る会 | 設計や実験の場を見る。写り込みに注意 | 技術系の責任者 |

「いま詰まっていること」を話すのは、エンジニア向けのスカウトと同じで、理系学生は「本当のことを言っている」と受け取ります。イベントの掲載の基本は[イベントページの作り方](/media/oc-event-page-kihon/)で書きました。

## 言葉の扱い

- **業界用語と社内の言葉を使わない**：分野が違う理系学生には分からない。使うなら一言の説明
- **技術名を並べない**：進め方で書く
- **「研究室」「ゼミ」の違いに配慮する**：理系でも研究室に所属していない学生がいる
- **「理系」で一括りにしない**：分野で仕事との距離が違う。「〇〇系の方は△△の仕事に近く、□□系の方は最初の研修から」のように

## 社内の分担

| 作業 | 誰が |
|---|---|
| 技術職の最初の1年を言葉にする | 技術系の責任者と、入社してまもない技術系の社員（人事が聞いて書く） |
| 開発や設計の進め方を言葉にする | 技術系の責任者 |
| 選考で研究をどう聞くかを決めて言葉にする | 技術系の面接官（人事が聞いて書く） |
| 技術面接の型を作り、揃える | 技術系の面接官と人事 |
| 専攻と配属の関係を事実で書く | 責任者と人事 |
| 技術系の社員の話を聞いて書く | 人事 |
| イベントで話す | 技術系の社員 |
| 理系学生の体験談を読み、揃える | 人事と技術系の面接官 |

運用代行や代理店が支えられるのは、置くものの型、離れている場合の書き方、技術面接の型の整理、言葉の扱いのチェックまでで、最初の1年と進め方の言語化、研究をどう聞くかの決定、技術面接、イベントで話すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がワンキャリアの理系向けの掲載を支えるとき、置くものの型、離れている場合の書き方、技術面接の型の整理は当社が出せます。ただし、「選考で研究をどう聞くか」と「技術職の最初の1年」は、技術系の面接官と責任者にしか言えません。当社が「研究の進め方を聞きます」と書いても、技術系の面接官が研究の内容を深掘りすれば、体験談にその差が書かれます。当社が最初にお願いするのは、技術系の面接官に「研究について、何を聞きたいですか」を聞いてもらうことと、その答えを面接官全員で揃えてもらうことです。揃えば、当社は企業ページに書けます。揃わなければ、書いても面接でずれます。理系向けの掲載は、技術系の面接官の言葉から始まります。

## まとめ

- 理系学生は、研究がそのまま仕事にならないと知っている。「研究を活かせる」は「分かっていない」と読まれる
- 置くのは、技術職の最初の1年、開発や設計の進め方、選考で研究をどう聞くか（内容より進め方）、技術面接で何を見るか、技術系の社員の話、専攻と配属の関係
- 研究と仕事が離れているなら、離れていると書き、見るのは進め方だと書き、違う分野から入った社員の話を置く
- 技術面接の型を段階ごとに作り、技術系の面接官全員で揃える。課題を出すなら掲載に書く
- 業界用語と技術名の羅列を避け、「理系」で一括りにせず分野で分ける。技術系の面接官の言葉から始める

## よくある質問

### 研究の内容を、選考で深く聞きたいのですが

聞いてよいですが、「深く聞く」と企業ページに書き、面接官全員が同じ深さで聞ける聞き方にします。分野が違う面接官が深掘りすると、ばらつきが出ます。当社が勧めるのは、内容の深掘りより「どう進めたか、どこで詰まったか」を聞く形で、これなら分野が違っても聞け、学生の準備の方向も定まります。

### 理系の学生が来るのに、技術系の社員が面接に出られません

人事だけが出る面接だと、理系学生の体験談に「技術の話ができなかった」と書かれます。技術系の社員が出られる段階を一つでも作り、その旨を企業ページに書きます。全段階でなくてよく、「二次面接は技術系の〇〇が出ます」と書けば、学生は準備できます。

### ワンキャリアの理系向けの掲載は、御社に相談できますか

できます。当社は、置くものの型、離れている場合の書き方、技術面接の型の整理、言葉の扱いのチェックを支えられます。最初の1年と進め方の言語化、研究をどう聞くかの決定、技術面接、イベントで話すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
