スカウトの運用は、始めるより続けるほうが難しく、止まった運用を再開するのはさらに難しくなります。「また始めよう」と思っても、何から手を付ければよいか分からず、前と同じやり方で始めて、同じ理由で止まります。**結論から言うと、再開は、止まった理由を運用の中から一つ特定することから始め、返信対応の人と通知を先に整え、会社ページと募集記事を確かめ、絞り込みを前より狭くし、送る数を前より小さくして始めます。台帳を再開し、最初の返信と面談を送る人に戻します。前と同じ大きさで再開すると、同じ理由で止まります。** この記事では、止まる理由、再開の手順、止まっている間の相手への対応、止め方を先に決めておくこと、止めるという判断、分担を整理します。止まる前の失敗は[スカウトでやりがちな失敗](/media/wt-scout-ng/)で書きました。

## この作業の目的｜同じ理由で、また止まらないようにする

再開の目的は、送り始めることではなく、「同じ理由で止まらない形で始める」ことです。

止まった理由を見ずに再開すると、最初の数週は動きますが、同じところで止まります。再開は、前の運用の反省ではなく、止まった理由を一つだけ見つけて、そこを変えて始める作業です。

## 止まる理由は、文面ではなく運用にある

| 止まった理由 | 何が起きていたか |
|---|---|
| 担当が異動・退職した | 引き継ぎが無く、型も台帳も置き場が分からない |
| 送る枠が予定から消えた | 「空いたらやる」になり、空かなかった |
| 返信が来ず、意味を見失った | 文面か会社ページか絞り込みの問題を切り分けずに、「効かない」で止めた |
| 返信が来たのに対応できず、疲れた | 対応する人が決まっていなかった。面談枠が無かった |
| 上限を追って、燃え尽きた | 読まずに送り、返信が来ず、時間だけ消えた |
| 反応が戻らず、現場が離れた | 送った結果を誰も伝えなかった |
| 忙しい時期に止め、そのまま | 「減らす」ではなく「ゼロ」にした |
| 上司に「効果が無い」と言われた | 段ごとの数字ではなく、返信率だけで報告していた |

共通するのは、「文面の質」ではないことです。文面を直しても、これらは解決しません。

## 再開の手順

1. **止まった理由を、一つ特定する**：上の表から。複数あっても、最も大きい一つ
2. **返信対応の人と、通知の設定を、先に整える**：再開後の最初の返信で止まらないように。[返信が来たあとの進め方](/media/wt-scout-henshin-go/)
3. **会社ページと募集記事を確かめる**：止まっている間に古くなっていないか。閉じた募集に誘導していないか
4. **絞り込みを、前より狭くする**：読める数を、前より少なく見積もる。[スカウト対象の絞り方](/media/wt-scout-target/)
5. **送る数を、前より小さくする**：週に読んで書ける数の、さらに少なめから
6. **送る人の枠を、予定に入れる**：上司の合意を取り直す
7. **台帳を再開する**：前の台帳があれば続きから。無ければ新しく
8. **型を開いて、募集記事と照らす**：古い型をそのまま使わない。[スカウト文面のテンプレート管理](/media/wt-scout-template/)
9. **最初の返信と面談を、送る人に戻す**：「再開して、返信が来た」を早く伝える
10. **月の見直しを、一回目から入れる**：再開後の最初の月に、段ごとの数を見る

「前より小さく」が、再開の原則です。前と同じ大きさで始めると、同じ負担で同じところで止まります。小さく始めて、続いたら増やします。

### エージェントベストの見解

相談で最も多い思い込みは、「止まったのは文面が悪かったからで、再開するなら文面を作り直すべきだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyのスカウトの運用を見ていますが、止まった運用の理由を聞くと、ほとんどが「担当が変わった」「枠が消えた」「返信に対応できなかった」で、文面が理由であることはまれです。文面を作り直して再開しても、枠が無ければまた止まります。当社が再開の相談を受けるとき、最初にやるのは、文面を見ることではなく、「前回、最後に送ったのはいつで、そのあと何があったか」を聞くことです。そこに止まった理由があります。理由が分かれば、変えるのは一つで済みます。文面は、そのあとで足ります。

## 止まっている間の、相手への対応

止まっている間にも、前に送った相手からの返信や、面談待ちの相手がいることがあります。

- **返信が来ていて、未対応のものを確かめる**：管理画面で。時間が経っていても、お礼と、いま話せるかの確認を送る
- **面談が決まっていたのに流れた相手**：お詫びと、改めて日程を出す。相手が望まなければ追わない
- **「担当が変わった」を伝える**：前の担当の名前で送っていた場合は、新しい担当を伝える
- **古い募集に誘導していた相手**：募集が変わったことを伝える

未対応の返信が残ったまま再開すると、その相手の印象は戻りません。再開の前に、残っているものを片づけます。

## 再開を前提に、止め方を決めておく

止まることは起きます。次に止まるときのために、「止め方」を先に決めておくと、再開が楽になります。

| 決めておくこと | 中身 |
|---|---|
| 「減らす」を先に、「止める」は最後 | 忙しい時期は数を減らす。ゼロにしない。減らし方は[スカウト通数の配分の考え方](/media/wt-scout-tsuusuu-haibun/) |
| 止めるときに残すもの | 台帳、型、送った相手の一覧、未対応の返信 |
| 止めるときにやること | 返信待ちの相手に一言、面談予定の相手に連絡 |
| 担当が変わるときの引き継ぎ | 置き場、型、台帳、対応する人の設定、上司の合意 |
| 再開の条件 | 誰が、いつ、どの募集で。「落ち着いたら」ではなく具体に |

「担当が変わるときの引き継ぎ」は、止まる理由の最も多いものへの備えです。引き継ぎの一覧があれば、担当が変わっても止まりません。引き継ぎの考え方は[OfferBoxの担当者の引き継ぎ](/media/ob-tantousha-hikitsugi/)で書いたのと同じです。

## 止めるという判断

再開しないという選択もあります。

- **募集記事が整っていて、掲載だけで話を聞きに来る人が足りているなら、スカウトは要らない**
- **読んで書く人も、返信に対応する人も、社内に確保できないなら、いまは止める**
- **面談枠が無いなら、送っても活かせない**
- **止める場合も、台帳と型は残す**：条件が整ったときに再開できる
- **止める判断は、月の見直しで**：「今月も送れなかった」が続くなら、止める理由を確かめる

「止めること」は失敗ではありません。条件が整わないまま形だけ続けるほうが、社内の時間と相手の印象を消費します。スカウトと掲載の使い分けは[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)で書きました。

## 再開後の最初の月

再開後の最初の月は、結果より「続いたか」を見ます。

- **送る枠が、予定どおりに使われたか**
- **返信への対応が、翌日までにできたか**
- **台帳が付いているか**
- **送る人に、結果が戻ったか**
- **段ごとの数を、一回目の月の見直しで並べたか**

数字の大小は見ません。前の運用と比べもしません。「続く形になったか」だけを見て、続いていれば翌月から少し増やします。見直しの型は[スカウト運用のKPI設計](/media/wt-scout-kpi/)で書きました。

運用代行や代理店が支えられるのは、止まった理由の特定の観点、再開の手順、引き継ぎの一覧の型、小さく始める配分の案、未対応の返信への文面の型までで、返信に対応すること、送ること、枠の確保、止めるか続けるかの判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これをやる前に、先に決めておかないとまた止まることがあります。「再開の大きさを、前より小さくする」ことです。当社がWantedlyのスカウトの再開を支えるとき、送る側は「今度こそ」と前より大きく始めようとします。前と同じか大きい数で始めると、読む時間も対応の時間も前と同じだけ要り、前と同じ理由で止まります。当社が最初にお願いするのは、「前の半分以下の数で、返信対応の人を先に決めてから」始めることです。小さく始めて、返信が来て、面談まで進んで、送る人に結果が戻れば、続ける理由ができます。理由ができてから、増やします。再開は、勢いではなく、小ささで続きます。

## まとめ

- 止まる理由は文面ではなく運用（担当の異動・枠が消えた・返信対応できず疲れた・上限を追った・反応が戻らない）にある
- 再開は、理由を一つ特定→返信対応の人と通知→会社ページと募集記事→絞り込みを狭く→送る数を小さく→枠と合意→台帳と型→結果を戻す
- 未対応の返信と面談待ちを片づけてから再開する。前の担当の名前で送っていたなら、担当が変わったと伝える
- 「減らす」を先に「止める」は最後。止めるときに残すもの、引き継ぎの一覧、再開の条件を先に決めておく
- 条件が整わないなら止めてよい。台帳と型は残す。再開後の最初の月は「続いたか」だけを見る

## よくある質問

### 前の担当が退職して、台帳も型も見つかりません

新しく作ります。管理画面に残っている送信の履歴から、送った相手の一覧を起こし、未対応の返信を確かめます。型は、いまの募集記事から作り直します。前のものを探す時間より、新しく作る時間のほうが短いことが多くあります。作ったら、置き場を一か所にし、引き継ぎの一覧を残します。

### 上司に「前に効果が無かったのに、また始めるのか」と言われます

前に止まった理由が文面ではなく運用にあったことと、今回は返信対応の人と枠を先に決めて小さく始めることを伝えます。報告は返信率ではなく、段ごとの数と「続いているか」で行うと合意しておきます。最初の月は「続く形になったか」を見せ、翌月から数字の変化を見せます。

### スカウト運用の再開は、御社に相談できますか

できます。当社は、止まった理由の特定の観点、再開の手順、引き継ぎの一覧の型、小さく始める配分の案、未対応の返信への文面の型を支えられます。返信に対応すること、送ること、枠の確保、止めるか続けるかの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
