ワンキャリアの体験談に、説明会のことが書かれる。「企業ページに書いてあることだった」「長かった」「質問できなかった」。説明会の評価を上げたい。ところが、満足度を上げようとし、演出で楽しくし、会社の魅力を厚く話し、質問の時間は余った分だけ、ページに書いた人と違う人が出て、次の場の案内がなく、一度で止める。**結論から言うと、説明会の評価は「満足度」ではなく、体験談に書かれる四つ（企業ページに書いてあることの繰り返しでなかった・聞きたいことが聞けた・ページに書いた人が出て書いた中身だった・次に何をすればよいか分かった）で決まります。会社の概要を話さないと宣言し、質問の時間を最も長く、書いた人が出て、当日に次の場を案内します。「楽しかった」を狙わず、「確かめられた」を残します。** この記事では、評価を上げようとして起きる失敗、体験談に書かれる記述、四つ、宣言と構成、質問の時間、書いた人と書いた中身、次の場、一通、回ごとの直し方、分担を整理します。構成は[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)、掲載は[ワンキャリアで説明会を掲載する](/media/oc-setsumeikai-keisai/)、失敗は[ワンキャリアのイベントでやりがちな失敗](/media/oc-event-ng/)で書きました。

## この作業の目的｜「評価」を、体験談に書かれる四つに分解する

説明会の「評価が高い」とは、体験談に「行ってよかった」と書かれることですが、その中身は「楽しかった」ではありません。体験談を読んで来た学生が書く「よかった」は、「確かめたいことが確かめられた」です。それは、説明会の運用で作れます。

目的は、「評価を上げる」を、体験談に書かれる四つに分解し、説明会の運用で作ることです。

## 評価を上げようとして、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 満足度を、上げようとする | 「楽しかった」は残っても、「確かめられた」が残らず、次に進まない |
| 演出で、楽しくする | 「盛り上がっていたが、仕事のことは分からなかった」 |
| 会社の魅力を、厚く話す | 「企業ページに書いてあることだった」「長かった」。体験談で最も多い説明会の記述の一つ |
| 質問の時間が、余った分だけ | 「質問できなかった」。話が延びれば質問が消える |
| ページに書いた人と、違う人が出る | 「若手が出ると書いてあったが、人事だけだった」 |
| 次の場の案内が、ない | 「次に何をすればよいか分からなかった」 |
| 一度で、止める | 一回分の体験談しか残らず、型が良くならない |

共通するのは、評価を「楽しさ」で上げようとし、「確かめられたか」で作っていないことです。

## 体験談に書かれる、説明会の記述

| 良く書かれる | 厳しく書かれる |
|---|---|
| 「企業ページにないことが聞けた」 | 「企業ページに書いてあることだった」 |
| 「質問の時間が長く、聞きたいことが聞けた」 | 「質問できなかった」「質問の時間がなかった」 |
| 「若手社員の話が具体的だった」 | 「人事の話だけだった」 |
| 「ページに書いてあったとおりの回だった」 | 「ページと違った」 |
| 「選考で何を見ているかが分かった」 | 「会社の説明ばかりだった」 |
| 「次の案内が分かりやすかった」 | 「その後どうすればよいか分からなかった」 |
| 「少人数で話せた」 | 「人が多くて話せなかった」「長かった」 |

「楽しかった」「雰囲気が良かった」は、良い記述の中でも、次に進む理由にはなりにくい。残るのは「聞けた」「分かった」「とおりだった」です。

### エージェントベストの見解

相談で最も多い思い込みは、「説明会の評価は、アンケートの満足度で測る」というものです。当社はワンキャリアの販売パートナーとして、説明会の評価の相談を受けていますが、アンケートの満足度が高い説明会が、体験談では「企業ページに書いてあることだった」と書かれ、次に進む人が少ない例を多く見ています。満足度は「その場が楽しかったか」で、体験談は「確かめたいことが確かめられたか」で、二つは別です。逆に、会社の概要を話さないと宣言し、質問に時間を使った説明会は、アンケートでは「もっと会社のことを聞きたかった」と書かれることもありますが、体験談には「聞きたいことが聞けた」と残り、次に進んでいます。説明会の評価は、その場のアンケートではなく、翌年の学生が読む体験談で決まります。当社が説明会の評価の相談を受けるとき、最初にやるのは、アンケートの満足度の列を外して、体験談の記述を四つで見ることです。

## 良い評価として残る、四つ

| 四つ | 説明会の運用で作るもの |
|---|---|
| 1. 企業ページの繰り返しでなかった | 最初に「会社の概要は企業ページに。今日は話さない」と宣言し、話すことを「選考で何を見ているか」と「最初の一年」の二つに絞る |
| 2. 聞きたいことが聞けた | 質問の時間を最初から最も長く置き、出し方を案内し、人事が体験談の続きで口火を切る |
| 3. ページに書いた人が出て、書いた中身だった | イベントページに書いた人が出て、書いた二つを話す。守れないことを書かない |
| 4. 次に何をすればよいか分かった | 当日に次の場を一つ、申し込める形で案内し、終わった後の一通で再掲する |

四つとも、構成と運用で作れます。構成の型は[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)で書きました。

## 宣言と、構成

- **最初の一分で、宣言する**：「会社の概要は企業ページに書いてあります。今日は、選考で何を見ているかと、最初の一年の話をします」
- **宣言で、学生は「この説明会は違う」と分かる**：質問を用意し始める
- **話すことは二つ**：面接に出る人が「選考で何を見ているか」、その職種の若手が「最初の一年」の一つの場面
- **会社の沿革・事業・制度を、話さない**：企業ページで読める
- **時間の配分は、話す二つを短く、質問を最も長く**：[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)の「話すことを、二つに絞る理由」

## 質問の時間

- **最初から、最も長く**：「余った分」にしない。話が延びたら切る
- **出し方を、最初に案内する**：声でも、文字でも（オンライン）、匿名でも
- **人事が、最初の質問を出す**：「体験談に〇〇と書かれていましたが、実際は」と体験談の続きで
- **答えられない質問は、「確認して一通で」**
- **質問が出ない時間を、埋めない**：よくある質問を用意し、それに答える
- **質問の設計は[ワンキャリアの説明会の構成の作り方](/media/oc-setsumeikai-sekkei/)の「質問の、設計」**

## 書いた人が出て、書いた中身

- **イベントページに書いた人が、当日に出る**：「〇〇職の若手」と書いたら、その人
- **出る人が変わったら、ページを更新する**：当日に違う人が出ない
- **書いた二つを、話す**：「選考で何を見ているか」「最初の一年」と書いて、会社の概要を話さない
- **「質問の時間を長く」と書いたら、長く取る**
- **守れないことを、書かない**：[ワンキャリアのイベントでやりがちな失敗](/media/oc-event-ng/)の失敗3
- **出る人の選び方は[ワンキャリアのイベントに出る社員の選び方](/media/oc-event-tantou/)**

## 次の場

- **当日に、次の場を一つ案内する**：面談か、次の回か。複数を並べない
- **申し込める形で**：その場で、または画面で。「ご希望があれば」にしない
- **選考との関係を、明記する**：年度の公表内容と自社の方針で確認
- **「今日決めなくてよい」と添える**：急かさない
- **次の場の日程を、回の前に押さえる**：案内してから枠を探さない

## 終わった後の、一通

- **当日か翌日に**：参加のお礼、回で出た質問の一つへの答え、次の場、企業ページと体験談への導線
- **答えられなかった質問への答え**
- **「次に何をすればよいか」を、文字で再掲**：閉じた後に見返せる
- **来た全員に**：次に進む人だけでなく
- **一通の型は[ワンキャリアのイベント後のフォロー](/media/oc-event-follow/)**

## 回ごとの、直し方

- **回の体験談が書かれたら、四つのどれが書かれたかを見る**：書かれなかった項目が、次の回で直す場所
- **出た質問を、次の回の話すパートか、企業ページの「よく聞かれること」に**
- **流れは変えず、中身を一つ直す**
- **一度で止めない**：小さい回を同じ型で続ける。[ワンキャリアのイベント集客の考え方](/media/oc-event-shuukyaku/)
- **アンケートを取るなら、「満足したか」ではなく「聞きたいことが聞けたか」「ページと違ったことはあったか」「次に何をするか分かったか」**：四つに対応する質問で

### エージェントベストの見解

これは順番の話です。説明会の評価の相談で、「評価を上げるために、会社の魅力が伝わる構成にしたい」と言われることがあります。当社がお願いする順番は、会社の魅力を話す部分を削る、質問の時間を増やす、書いた人が出る、次の場を当日に案内する、です。会社の魅力を厚くするほど、「企業ページに書いてあることだった」が増え、質問の時間が消えて「質問できなかった」が増え、体験談の評価は下がります。魅力は、企業ページで読まれていて、説明会で伝えるものは「企業ページで読めないこと」（見ていること、最初の一年の場面、質問への答え）です。当社は、説明会の評価の相談で、構成に足すことではなく、削ることから始めます。

## まとめ

- 説明会の評価は「満足度」ではなく、体験談に書かれる四つ（企業ページの繰り返しでなかった・聞きたいことが聞けた・ページに書いた人が出て書いた中身だった・次に何をすればよいか分かった）で決まる。「楽しかった」は次に進む理由になりにくい
- 最初の一分で「会社の概要は企業ページに。今日は話さない」と宣言し、話すことを「選考で何を見ているか」と「最初の一年」の二つに絞る。魅力を厚くするほど評価は下がる
- 質問の時間を最初から最も長く置き、出し方を案内し、人事が体験談の続きで口火を切る。答えられない質問は一通で
- イベントページに書いた人が出て、書いた中身を話し、守れないことを書かない。当日に次の場を一つ、申し込める形で案内し、一通で再掲する
- 回の体験談で四つのどれが書かれたかを見て、次の回で一つ直す。アンケートを取るなら四つに対応する質問で。一度で止めず、小さい回を同じ型で続ける

## よくある質問

### 上司が「説明会のアンケートの満足度」で評価します

満足度の隣に、四つに対応する質問（聞きたいことが聞けたか・ページと違ったことはあったか・次に何をするか分かったか）と、「次の場に進んだ人の数」を並べます。満足度が高くて次に進まない回と、満足度が普通で次に進む回を並べて見せると、評価の軸が変わります。最終的に上司が見たいのは採用の数で、それに効くのは満足度ではなく「確かめられたか」です。伝え方は[ワンキャリアのイベントのKPI設計](/media/oc-event-kpi/)で書きました。

### 体験談に「説明会が長かった」と書かれました。時間を短くすればよいですか

時間の長さより、中身です。「長かった」は、多くの場合「企業ページに書いてあることを聞かされた時間が長かった」で、同じ長さでも質問の時間が長ければ「長かった」とは書かれにくい。まず会社の概要のパートを削り、質問の時間に渡します。それでも長いなら、話す二つをさらに短く。時間を短くしても会社の概要を話していれば、「短いが企業ページと同じだった」になります。

### 説明会の評価の上げ方は、御社に相談できますか

できます。当社は、四つの整理、構成の型、質問の設計の型、次の場と一通の型、回ごとの直し方の型を支えられます。出ること、話すこと、質問に答えること、ページに書いたことを守ること、次の回を開くことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
