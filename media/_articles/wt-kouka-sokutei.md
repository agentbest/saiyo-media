Wantedlyを回しているが、効果が測れない。「閲覧数は見えるが、それで良いのか悪いのか分からない」「応援が増えたが、何に効いているのか分からない」「記事を書いているが、採用に効いているのか分からない」。この症状は、「Wantedlyは効果が見えにくい媒体」で片づけられがちです。ところが、測れない原因のほとんどは、測る側の準備にあります。**結論から言うと、「測れない」の正体は五つです。台帳がない、段が分かれていない、「こんな人」が決まっていない、面談で「記事のどこを見て来たか」を聞いていない、比べる相手が他社や媒体平均になっている。この五つを順に直します。閲覧数と応援数を中心から外し、段ごとの数と日数で見て、「こんな人」に近い人の数を段ごとに持ち、来た人の言葉を数字と並べます。記事の資産をKPIに入れ、「出ていない」のか「測れていない」のかを分けます。** この記事では、五つの正体、順に直す手順、閲覧数を外す理由、段ごとの数、近い人の数、言葉、置くKPIと置かないKPI、資産、区別、分担を整理します。KPIの基本は[Wantedlyのスカウト運用のKPI設計](/media/wt-scout-kpi/)、経営への報告は[経営層にWantedlyの成果を説明する方法](/media/wt-keiei-rikai/)、OfferBoxの場合は[OfferBoxの効果が測れないときのKPIの置き直し](/media/ob-kouka-sokutei/)で書きました。

## この作業の目的｜「効いているか」を、自社の記録と言葉で答えられるようにする

「効果が測れない」とは、「効いていない」ではなく、「効いているかどうかを判断する材料がない」状態です。材料がないまま「効かない」と判断すると、効いていた運用を止めることがあります。

目的は、自社の記録と面談の言葉で「効いているか」を答えられる形を作ることです。他社の数字や、媒体の平均と比べることではありません。

## 「測れない」の、五つの正体

| 正体 | 何が起きているか | 直し方 |
|---|---|---|
| 1. 台帳がない | 誰に送って、誰が返信して、誰が来たかが記録にない | 台帳を一つ作る |
| 2. 段が分かれていない | 「今月の成果」を閲覧数一つで見ていて、どこで止まっているかが見えない | 段ごとに数と日数を置く |
| 3. 「こんな人」が決まっていない | 来ても、「合う人か」を判断できず、数だけ見ている | 「こんな人」を一行で書く |
| 4. 来た人の言葉を集めていない | 面談で「記事のどこを見て来たか」を聞いておらず、記事が効いたかが分からない | 面談で聞いて、一行で残す |
| 5. 比べる相手が違う | 他社の閲覧数、媒体の平均、他媒体の応募数と比べていて、自社の判断に使えない | 自社の先月と比べる |

「1→2→3→4→5」の順に直します。Wantedlyに特有なのは「4」で、記事の効果は、数字ではなく来た人の言葉に出ます。

## 閲覧数と応援数を、中心から外す

- **閲覧数は、入口の数字**：読まれたかは分かるが、「こんな人」に届いたかは分からない
- **応援数は、社員と周りの動きの数字**：候補者が来たかとは別
- **閲覧数を上げようとすると、記事が広く薄くなる**：来る人が合わなくなる
- **中心に置くのは、段ごとの数と、来た人の言葉**：閲覧数と応援数は、参考として末尾に
- **管理画面で何が見えるかは、現在の仕様で確認する**：見える数字の中から、段ごとに写す

閲覧数だけを追うと起きることは[Wantedlyのスカウト運用のKPI設計](/media/wt-scout-kpi/)の「返信率だけを追うと起きること」と同じ構造です。

### エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは共感の媒体なので、効果は数字で測れない」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、「測れない」と言う会社の手元を見ると、管理画面の閲覧数は見ていて、台帳がなく、段が分かれておらず、面談で「記事のどこを見て来たか」を聞いていません。共感の媒体だから測れないのではなく、共感が伝わったかを確かめる言葉を集めていないから測れないのです。来た人が「〇〇のストーリーの△△の場面に重なった」と言えば、その記事は効いていて、言わなければ、効いていないか、届いていません。当社が「測れない」の相談を受けるとき、最初にやるのは、閲覧数の見方の説明ではなく、面談で聞く一つの質問を決めて、今月から一行で残してもらうことです。

## 段を分けて、数と日数を置く

| 段 | 数 | 日数 |
|---|---|---|
| 読んだ（スカウトの開封、記事の閲覧） | 管理画面で見える範囲で | — |
| 返信・「話を聞きに行く」 | その数 | 送ってから返信までの日数 |
| 面談 | 面談した数 | 返信から面談までの日数 |
| 選考 | 選考に進んだ数 | 面談から一次までの日数 |
| 内定 | 内定を出した数 | — |

「数」で、どの段で減っているかが見えます。「日数」で、どの段で待たせているかが見えます。段の意味は[Wantedlyのスカウト運用のKPI設計](/media/wt-scout-kpi/)の「見る段と、それぞれの意味」で書きました。

## 「こんな人」に近い人の数を、段ごとに持つ

- **「こんな人」を一行で書く**：なければ、ここで書く。「〇〇の仕事の中身で選ぶ、△△を自分で始めた人」
- **台帳の「近さ」の項目に、送るときと来たときに印をつける**：「近い」「やや近い」「遠い」の三段で足りる
- **段ごとの数を、「近い人」だけでも出す**：「面談した人のうち、近い人は何人」
- **「近い人」が面談まで来ていれば、「届いている」**：全体の数が少なくても
- **「遠い人」ばかりが来ていれば、記事を絞る**：[Wantedlyの応募者の質が合わないときの直し方](/media/wt-oubo-shitsu/)

## 来た人の言葉を、数字と並べる

- **面談で、「記事のどこを見て、話を聞きに来ようと思ったか」を聞く**：一つの質問
- **「読んだとおりの会社だったか」を聞く**：記事と実態のずれ
- **答えを、一行で台帳に**：「来た理由：〇〇のストーリーの△△。読んだとおりか：□□」
- **月に一度、言葉を並べる**：どの記事の、どの場面が挙げられているか
- **挙げられた場面が、「こんな人」の行動と重なっているか**：重なっていれば、記事は届いている

言葉の集め方は[Wantedlyの募集記事の反応を見て直す手順](/media/wt-boshu-hyouka/)、共感の確かめ方は[Wantedlyで「共感」を設計する考え方](/media/wt-kyoukan-sekkei/)の「共感の確かめ方」で書きました。Wantedlyの効果測定は、数字と言葉の両方で成立します。

## 最初の年に置くKPIと、置かないKPI

| 置く | 置かない |
|---|---|
| 段ごとの数と日数 | 閲覧数・応援数の目標値 |
| 「近い人」の段ごとの数 | 返信率・応募率の目標値 |
| 来た人が挙げた記事の場面 | 他社・媒体平均との比較 |
| 止まっている段と、直したこと | 記事の本数の目標 |
| 出した記事の本数と、話した社員 | スカウトの送信数の目標 |
| 残った資産（ストーリー・会社ページ・型・協力） | 「効いた・効かない」の結論 |

最初の年は、「置かない」の側を置くと、途中の月が「未達」になり、直す前に「効かない」と判断することになります。目標値は、一年の台帳から割合が出てから置きます。

## 記事の資産を、KPIに入れる

- **ストーリーの本数と、話した社員の数**：翌年の元
- **会社ページの「なぜ」が、代表の言葉の場面になったか**
- **募集記事の型が、一つできたか**
- **面談に出る人と、返信に対応する形ができたか**
- **これらは、採用の結果が出なくても、残る**：[Wantedlyのコンテンツを資産として貯める考え方](/media/wt-naiyou-shisan/)

Wantedlyは、記事が残る媒体です。「採れたか」だけで測ると、初年度は「効いていない」に見えますが、資産を入れると、「翌年の元ができた年」として測れます。

## 「出ていない」と「測れていない」を、分ける

| 状態 | サイン | 対処 |
|---|---|---|
| 測れていない | 台帳がない、段が分かれていない、「こんな人」がない、言葉を集めていない | 五つを直す。判断はそのあと |
| 測れているが、止まっている段がある | 段ごとの数で、一つの段が大きく減っている | その段を直す。「効かない」ではない |
| 測れていて、「近い人」が来ていない | 来ているが、近い人が少ない。挙げる場面が「こんな人」と重ならない | 記事を絞り、スカウトの相手を直す |
| 測れていて、直しても近い人が来ない | 直しの前後で変わらない | 「こんな人」がWantedlyにいるかを疑う。[Wantedlyのスカウトのターゲット](/media/wt-scout-target/) |
| 出ていない | 上の全部を経て、なお来ない | 続けるかの判断。契約の切れ目で。記事は残る |

「出ていない」と判断できるのは、最後の段だけです。それより前で「効かない」と判断すると、測れていないだけの運用を止めることになります。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 台帳を一つ作り、月に一度、管理画面から写す | 人事 |
| 段ごとの数と日数を置く | 人事 |
| 「こんな人」を一行で書き、「近さ」の印をつける | 人事と面接官 |
| 面談で「記事のどこを見て来たか」を聞き、一行で残す | 面談に出る人 |
| 比べる相手を自社の先月にする方針を、上司と合意する | 人事と責任者 |
| 月に一度、数字と言葉を並べて止まりを指す | 人事と責任者 |
| 「出ていない」の判断 | 責任者 |

運用代行や代理店が支えられるのは、台帳の型、段の分け方、聞く質問の型、言葉の一覧の型、置くKPIと置かないKPIの整理、「測れていない」の切り分けまでで、台帳を付けること、「こんな人」の決定、面談で聞くこと、直しの実行、「出ていない」の判断は企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これは切り分けの話です。「効果が出ていない」と「効果が測れていない」を、当社は分けて扱います。Wantedlyでは、この二つがさらに混ざりやすく、「閲覧数はあるのに採れない」を「効いていない」と読む会社が多くあります。閲覧数は入口で、その先の段と、来た人の言葉がなければ、効いているかは分かりません。当社がWantedlyで「効かない」の相談を受けるとき、最初に確かめるのは、面談で「記事のどこを見て来たか」を聞いているかです。聞いていなければ、「測れていない」で、判断の前に聞いてもらいます。聞いていて、来た人が記事の場面を挙げていれば、記事は効いていて、止まりは別の段にあります。挙げていなければ、記事の側を直します。

## まとめ

- 「測れない」の正体は、台帳がない・段が分かれていない・「こんな人」がない・来た人の言葉を集めていない・比べる相手が他社、の五つ。この順に直す
- 閲覧数と応援数は入口の数字。中心から外し、参考として末尾に。中心に置くのは段ごとの数と日数と、来た人の言葉
- 「こんな人」に近い人の数を段ごとに持つ。面談で「記事のどこを見て来たか」を聞いて一行で残し、月に一度、挙げられた場面を並べる
- 最初の年は、閲覧数・返信率・記事の本数・送信数の目標値を置かず、段ごとの数・近い人の数・言葉・止まりと直し・残った資産を置く
- 「出ていない」と判断できるのは、五つを揃えて直してなお近い人が来ないときだけ。それより前は「測れていない」。やめても記事は残る

## よくある質問

### 面談で「記事のどこを見て来たか」を聞くのが、不自然に感じます

面談の最初に、「お話の前に、記事のどこを見て、話を聞いてみようと思われたか、教えていただけますか」と聞くと、自然に始まります。候補者の側も、自分が何に反応したかを話す入口になり、面談の話が「読んだ場面」から始められます。聞かないと、記事が効いたかが最後まで分かりません。

### 閲覧数が減っているのですが、それは「効いていない」ですか

「読んだ」の段で止まっているか、記事が古くなっているか、の材料です。「効いていない」ではありません。閲覧数が減っても、来た人のうち近い人が面談まで来ていれば、届いています。閲覧数が減って、近い人も来ていないなら、記事のタイトルと冒頭と写真を見ます。[Wantedlyの募集記事が読まれないときの見直し順](/media/wt-pv-nai/)

### WantedlyのKPIの置き直しは、御社に相談できますか

できます。当社は、台帳の型、段の分け方、聞く質問の型、言葉の一覧の型、置くKPIと置かないKPIの整理、「測れていない」の切り分けを支えられます。台帳を付けること、「こんな人」の決定、面談で聞くこと、直しの実行、「出ていない」の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
