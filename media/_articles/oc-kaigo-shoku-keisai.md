ワンキャリアで新卒の介護職を募集したとき、最初にぶつかるのは「『介護職』『未経験歓迎』『人の役に立つ仕事』と掲載してもワンキャリアの学生は介護職を候補にしておらず来ないか、『福祉に興味』で来た学生に夜勤と体を使う場面を内定後に伝えると辞退され、入社しても『夜勤が聞いていたより早かった』『体がもたなかった』と体験談に書かれる」という問題です。**結論から言うと、ワンキャリアの介護職の掲載は、「介護職」「未経験歓迎」の言葉ではなく「何の施設で、誰の何をして、夜勤はいつからで何回か、体を使う場面と守り方、最初の年に何を任せ、資格は入社後に取れるか、介護職の先の道があるか」を、学生が読む前に企業ページと募集に書き、内定の前に施設の一日を見せます。** 法人としての位置の設計は[介護業界の新卒採用でワンキャリアを使うときの設計](/media/oc-kaigo-katsuyou/)で書きました。この記事は介護職に絞り、掲載とスカウトと選考をつなげて書きます。

## 介護職を候補にする学生が、読んでいること

ワンキャリアの学生の多くは、介護職を候補にしていません。介護職を候補にする学生は、福祉系の学校経由か、家族の介護を見た学生か、アルバイトで施設に入った学生です。その学生は、「人の役に立つ」の言葉ではなく、「実態が書いてあるか」を読んでいます。

| 読んでいること | 掲載への意味 |
|---|---|
| 何の施設か | 特養か、老健か、グループホームか、通所か。入居者の状態。「介護職」の名前では分からない |
| 誰の何をするか | 食事、入浴、排せつ、移動のどれを、何人に。日中の流れ |
| 夜勤の時期と回数 | 入社して何か月目から夜勤か。月に何回か。一人で何人を見るか。体験談で最も書かれる |
| 体を使う場面と守り方 | 移乗と入浴で体を使うか。機械や道具があるか。腰を守る決まりがあるか |
| 最初の年に何を任されるか | 先輩と一緒に何か月か。一人で受け持つのはいつからか |
| 資格の取り方 | 無資格で入れるか。入社後に何を取るか。費用と時間は誰が持つか |
| 介護職の先の道 | 介護職のまま責任者か。相談員や運営に行けるか。何人が行ったか |
| 福祉系でなくても採るか | 一般の大学から入った人がいるか |
| 先輩の実態 | 最初の年に何をし、夜勤をいつから始め、いま何をしているか |

「夜勤の時期と回数」と「体を使う場面と守り方」が、介護職で最も読まれ、企業ページで最も書かれない項目です。

## 掲載に書くこと｜施設、誰の何を、夜勤、体の守り方、最初の年、資格、先の道

| 書くこと | 書き方 |
|---|---|
| 職種名 | 「介護職」ではなく「〇〇（施設の種類）の介護職」。何の施設か |
| 施設と入居者 | 「□□の施設。入居者が〇人。△△の状態の方が多い」 |
| 誰の何をするか | 「日中は〇人を△人で。食事と入浴と移動の介助。記録は□□で」。良く見せない |
| 夜勤 | 「夜勤は入社〇か月目から。月に△回。夜は□人で〇人を見る。夜勤の前後の休み」。早いなら、早いと |
| 体を使う場面と守り方 | 「移乗と入浴で体を使う。機械は□□があり、腰を守る決まりは〇〇。腰を痛めた人がいれば、その後どうしたか」 |
| 最初の年 | 「最初の〇か月は先輩と一緒。△か月目から日中の受け持ち。夜勤は□か月目から」 |
| 資格 | 「無資格で入れる。入社後〇か月で□□を取る。費用は法人、時間は勤務内」。自費なら、自費と |
| 介護職の先の道 | 「介護職から相談員へ行った人が〇人、運営へ△人。介護職のまま責任者が□人」 |
| 一般の大学から入った人 | 「福祉系でない大学から入った人が〇人。最初に覚えるのは△△」 |
| 先輩の話 | 最初の年に何をし、夜勤をどう始めたか。盛らない |

企業ページには夜勤と体の守り方と介護職の先の道を、募集には何の施設かと誰の何をするかと最初の年を、と分担します。「人の役に立つ」「やりがい」の言葉で企業ページを埋めると、介護職を候補にしている学生ほど、「実態が書いていない」と読んで離れます。

### エージェントベストの見解

介護職の募集で、ワンキャリアが向いている法人と向いていない法人があります。当社は3媒体すべての販売パートナーとして、介護職の掲載と選考を見ていますが、ワンキャリアの学生の多くは介護職を候補にしておらず、「未経験歓迎」で広く出しても、候補にしていない学生には届きません。ワンキャリアが向いているのは、「介護職を候補にしている少数の学生に、実態を書いて選ばれる」形をとれる法人と、介護職と並べて相談員や運営の募集も出せる大きな法人です。「介護職を候補にしていない学生を、やりがいの言葉で振り向かせる」形は、ワンキャリアでは続きません。体験談が無い法人がほとんどなので、企業ページに書いた実態が、そのまま学生の読む唯一の情報になります。逆に、「夜勤は〇か月目から月に△回、移乗の機械は□□、腰を守る決まりは〇〇」と書いた法人は、介護職を候補にしている学生に「実態を書いている法人」として選ばれ、最初の体験談に「書いてあるとおりだった」と書かれます。当社が最初に確かめるのは、「介護職を候補にしている少数の学生に絞って、実態を書けるか」です。

## 介護職を候補にする学生の見つけ方

「優しい」「人が好き」で絞ると、候補にしていない学生に送ることになります。施設の場所と夜勤の可否を先に決め、行動で読みます。

| 見る箇所 | 何が書かれているか | 読み方 |
|---|---|---|
| 施設の場所 | 住みたい地域、通える範囲 | 譲れない条件。範囲の外には送らない |
| 夜勤の可否 | 書かれていれば | 譲れない条件。書かれていなければ、スカウトで先に伝える |
| 介護職を候補にしているか | 福祉系の学科、家族の介護、施設のアルバイト | あればよい条件。無い学生には、候補にしていない前提で送る |
| 人の体に触れた経験 | 「祖父母の移動を手伝った」「施設のアルバイトで入浴を手伝った」 | 介護職の行動。優先 |
| 相手に合わせて変えた経験 | 「話せない人に、身振りで伝え方を変えた」 | 入居者に合わせる仕事と重なる |
| 変化に気づいた経験 | 「いつもと違う様子に気づいて、人に伝えた」 | 記録と申し送りと重なる。最も重い |
| 続けた経験 | 「〇年、同じ場所で続けた」 | 夜勤と体の負担を続けられるか |

「体に触れた・相手に合わせて変えた・変化に気づいて伝えた」を書いている学生が、介護職と重なります。四つの行動は[OfferBoxで介護職に合う学生を見つける検索の考え方](/media/ob-kaigo-shoku-target/)で書きました。

## スカウトの文面｜掲載と同じ言葉で

スカウト文面の型は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)で書きました。介護職では、次の点を足します。

- **相手の一文は、変化に気づいた経験か、体に触れた経験で**：「いつもと違う様子に気づいて人に伝えたと書かれていたのを読んで」。「優しそう」と書かない
- **何の施設で、誰の何をするかを、一文で**：「□□の施設で、〇人の入居者の食事と入浴と移動の介助をします」
- **夜勤を、最初の段落で**：「夜勤は入社〇か月目から月に△回です」。読んでから決めてもらう
- **体の守り方を、一文で**：「移乗は機械の□□を使い、腰を守る決まりが〇〇です」
- **資格を、一文で**：「無資格で入れて、入社後〇か月で□□を法人の費用で取ります」
- **送り主は、介護職で入った先輩**：人事の名前で「福祉に興味のある方」と送らない

## 選考への接続｜内定の前に、施設の一日を見せる

- **夜勤と体を使う場面を、面接の最初に言う**：「夜勤は〇か月目から月に△回。移乗で体を使う。この前提で進めてよいですか」。内定後に初めて言うと、辞退される
- **聞くのは「いつもと違う様子に気づいたとき、何をしたか」**：「なぜ介護か」を聞かない。学生は「人の役に立ちたい」と答えを用意している
- **内定の前に、施設の一日を見せる**：先輩の横で、朝の申し送りから夕方まで。入浴の介助の場面も。見せてから内定を出すと、内定後の辞退と、入社後の「体がもたなかった」が減る
- **体を守る決まりを、見せる**：機械と道具の使い方を、その場で。決まりが紙の上だけでないことを見せる
- **先輩が面接に出る**：介護職で入った先輩が、夜勤をどう始めたかを話す。[ワンキャリア経由の内定辞退が続くとき](/media/oc-naitei-jitai/)

| 作業 | 誰が |

| スカウトの一文 | 先輩 |
| 面接 | 施設長と先輩。夜勤を最初に言う |
| 施設の一日を見せる日程 | 施設長。入居者と家族に先に断る |

運用代行や代理店が支えられるのは、掲載の型、夜勤と体の守り方を文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくり、施設を見せる日程の組み方までで、夜勤の時期の決定、体を守る決まり、面接、先輩の話、施設の受け入れは法人が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

介護職の募集で、当社が順番として最初にお願いするのは、掲載を直すことではなく、「夜勤を始める時期と、体を守る決まりを、施設長が文で言えるようにすること」です。多くの法人で、夜勤の時期は「その人による」、体を守る決まりは「気をつけている」と返ってきて、企業ページに書けないまま「未経験歓迎」で出ています。実態が文で言えないと、掲載にもスカウトにも面接にも書けず、学生は「書いていない」と読んで離れるか、入社後に知って離れます。逆に、施設長が「夜勤は〇か月目から、その前に△回の夜勤の見学。移乗は機械の□□を使い、二人で行う決まり」と言えれば、掲載に書け、スカウトに入り、面接で先に話せ、施設の見学で見せられます。当社が掲載の直しを引き受けるときも、「施設長に、夜勤の時期と体を守る決まりを文で聞いてから、掲載を直す」の順番でお願いしています。順番が逆だと、「未経験歓迎」を「介護職」に変えただけで、夜勤と体の実態が抜けたままになります。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「未経験歓迎」「人の役に立つ」で埋める | 候補にしている学生ほど「実態が無い」と離れる | 夜勤と体の守り方を先に書く |
| 夜勤の時期を書かない | 内定後に辞退される | 何か月目から月に何回かを書き、面接の最初に言う |
| 体の守り方を書かない | 「体がもたなかった」と書かれる | 機械と決まりを書き、見学で見せる |
| 候補にしていない学生に広く送る | 届かず、返信が無い | 施設の場所と夜勤の可否で絞り、候補にしている学生に |
| 「なぜ介護か」を聞く | 「人の役に立ちたい」で終わる | 「変化に気づいたとき何をしたか」を聞く |

## まとめ

- ワンキャリアの学生の多くは介護職を候補にしていない。候補にしている少数の学生は、「何の施設か・誰の何をするか・夜勤の時期と回数・体を使う場面と守り方・最初の年・資格・介護職の先の道・先輩の実態」を読む
- 掲載には、何の施設か、誰の何をするか、夜勤の時期と回数、体を守る機械と決まり、最初の年、資格の取り方と費用、介護職の先の道、一般の大学から入った人の有無を書く。「未経験歓迎」を外す
- 学生は、施設の場所と夜勤の可否を先に決め、「優しい」ではなく「体に触れた・相手に合わせて変えた・変化に気づいて伝えた」で見つける
- 面接の最初に夜勤を言い、内定の前に施設の一日と体を守る決まりを見せる
- 夜勤の時期と体を守る決まりを施設長が文で言えるようにしてから、掲載を直す

## よくある質問

### 夜勤が早い時期から始まる施設です。書くと学生が来なくなりませんか

来なくなるのは、夜勤を内定後に知って辞退する学生です。「夜勤は入社〇か月目から。その前に△回、先輩の夜勤に一緒に入る。月に□回。夜勤の前後の休み」と、時期と、その前の準備と、回数と、休みを書きます。夜勤を始める前に何をするかを書くと、「早い」の意味が「準備なしに始まる」から「準備してから始まる」に変わります。書かずに集めると、面接と内定後の連絡の時間を使って、辞退で終わります。

### 体験談が無いので、学生が読むものがありません

企業ページに書いた実態が、学生の読む唯一の情報になります。体験談が無いことは、書いたとおりに読まれることでもあります。夜勤の時期、体を守る決まり、最初の年、資格の取り方を、数字と時期で書きます。最初に入った新卒が体験談を書くとき、「書いてあるとおりだった」と書かれれば、次の年から体験談が企業ページを支えます。書いたことと違えば、最初の体験談がそれを書きます。

### 介護職の掲載とスカウトは、御社に相談できますか

できます。当社は、掲載の型、夜勤と体の守り方を文で書く直し方、体験談との整合の確認、スカウトの型、学生の見つけ方の基準づくり、施設を見せる日程の組み方を支えられます。夜勤の時期の決定、体を守る決まり、面接、先輩の話、施設の受け入れは、法人で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載とスカウトの運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
