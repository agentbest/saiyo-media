ワンキャリアの選考体験談やクチコミを、学生に書いてもらいたい。体験談が少ないので、増やしたい。ところが、規約を確認せずに案内し、「良いことを書いて」と頼み、通過した学生にだけ案内し、対価や条件を付け、内容を指定し、案内だけして選考は直さず、頼んで書かれたものが読んだ学生に分かってしまう。**結論から言うと、案内できるか・どう案内してよいかは媒体の規約で先に確認し、案内するなら「事実のまま、書く・書かないは自由、内容は指定しない、対価は出さない」の形で、選考の結果に関わらず全員に同じ文面で行います。「良いことを書いて」は頼みません。案内より先に「書かれる選考」をすることが、投稿を増やす最も確かな方法です。** この記事では、案内で起きる失敗、案内の前に確認すること、してよい形としてはいけない形、時期と文面、全員に同じにすること、「書かれる選考」、社員のクチコミ、分担を整理します。クチコミの基本は[ワンキャリアのクチコミとは｜企業がまず知っておくこと](/media/oc-kuchikomi-kihon/)、体験談の影響は[ワンキャリアの選考体験談が採用に与える影響](/media/oc-kuchikomi-senkou-taikendan/)で書きました。

## この作業の目的｜投稿を「頼む」のではなく、「書かれる状態」を作る

体験談は、学生が書くものです。企業が頼んで書かれたものは、読んだ学生に分かり、企業への信頼を下げます。企業ができるのは、「書きたくなる選考」をすることと、規約の範囲で「書いてよいことを知らせる」ことまでです。

目的は、投稿の案内を「増やす手段」ではなく、「書かれる選考をしたうえで、書いてよいことを知らせる」ものとして位置づけ、規約の範囲で行うことです。

## 案内で、起きる失敗

| 失敗 | 何が起きるか |
|---|---|
| 規約を確認せずに、案内する | 媒体の規約に反する案内をして、企業と学生の両方に影響する |
| 「良いことを書いて」と、頼む | 頼まれた学生は書きにくく、書いても読んだ学生に「頼まれた」と分かる |
| 通過した学生にだけ、案内する | 偏った体験談になり、読んだ学生に「選んで頼んでいる」と分かる。落ちた学生の体験が残らない |
| 対価や条件を、付ける | 規約で確認が要る。対価で書かれたものは、信頼されない |
| 内容を、指定する | 「〇〇について書いて」は、企業の言葉になる。事実のままでなくなる |
| 案内だけして、選考は直さない | 「連絡が遅い」まま案内すれば、「連絡が遅い」が増える |
| 頼んで書かれたものが、分かる | 同じ言い回し、同じ時期、同じ項目。読んだ学生が「頼まれたもの」と読む |

共通するのは、投稿を「企業が増やすもの」として扱っていることです。投稿は「学生が書くもの」です。

## 案内の前に、確認すること

- **媒体の規約**：企業が学生に投稿を案内してよいか、どの範囲で、どの表現で。対価の扱い。現在の規約で確認し、確認した日と内容を残す
- **自社のルール**：学生への連絡の範囲、個人情報の扱い
- **案内の目的**：「書いてよいことを知らせる」であって、「増やす」でも「良くする」でもない
- **案内しない選択**：規約で不明な点があれば、案内せず、「書かれる選考」だけをする
- **確認の型は[ワンキャリアのクチコミとは｜企業がまず知っておくこと](/media/oc-kuchikomi-kihon/)の「社内で、最初に決めること」**

### エージェントベストの見解

相談で最も多い思い込みは、「体験談が少ないから、内定者に頼んで書いてもらえばよい」というものです。当社はワンキャリアの販売パートナーとして、投稿の案内の相談を受けていますが、内定者だけに頼んで書かれた体験談は、内容が良くても、読んだ学生に「内定者に頼んだもの」と分かり、企業ページの信頼まで下がっています。逆に、規約の範囲で、選考を受けた全員に「書く・書かないは自由、事実のまま」と同じ文面で知らせ、それより先に連絡を速くし、面接官を揃えた会社は、頼まなくても書かれ、落ちた学生の「丁寧だった」も残っています。体験談を増やす最も確かな方法は、案内ではなく、書きたくなる選考です。当社が案内の相談を受けるとき、最初にやるのは、規約を一緒に確認することと、「いまの選考は、書かれたい選考ですか」を確かめることです。

## 案内してよい形と、してはいけない形

| してよい形（規約で確認のうえ） | してはいけない形 |
|---|---|
| 「選考の体験を、事実のまま書いてもらって構いません」 | 「良いことを書いてください」 |
| 「書く・書かないは自由です」 | 「書いてください」（義務に聞こえる） |
| 選考の結果に関わらず、全員に同じ文面 | 通過した学生、内定者にだけ |
| 内容を指定しない | 「〇〇について」「〇〇な点を」 |
| 対価を出さない（対価の扱いは規約で確認） | 謝礼、特典、選考の有利不利 |
| 選考の終わりに、一度だけ | 何度も、しつこく |
| 「厳しい内容でも構いません」 | 「厳しいことは書かないで」 |

「してよい形」も、媒体の規約で案内そのものが認められている範囲でのみ行います。規約で不明なら、案内しません。

## 案内する、時期と文面

- **時期**：選考の結果を伝えた後。通過・不通過・内定・辞退のどの結果でも、同じ時期に
- **文面**：結果の連絡とは別の一通、または結果の連絡の末尾に一文。「ワンキャリアに、選考の体験を事実のまま書いていただいて構いません。書く・書かないは自由で、選考には関係ありません」の形
- **一度だけ**：繰り返さない。返事を求めない
- **書き方の指定を、しない**：項目、長さ、方向、どれも
- **文面は、規約に沿っているかを確認してから**：確認した日を残す

## 全員に、同じに

- **通過した学生にも、落ちた学生にも、辞退した学生にも**：同じ文面、同じ時期
- **偏った体験談は、読んだ学生に分かる**：通過者の体験談だけなら、「落ちた人の話がない」と読まれる
- **落ちた学生の「丁寧だった」が、最も信頼される記述の一つ**：落ちても書ける対応が、書かれる選考
- **辞退した学生にも**：辞退の理由に関わらず、対応が丁寧なら書かれる
- **内定者にだけ頼まない**：内定者の体験談は、内定者が自分の判断で書くもの

## 案内より先に、「書かれる選考」をする

- **連絡が速い**：当日か翌日。「連絡が速かった」は書かれやすい
- **企業ページに書いた「何を見るか」のとおりに聞く**：「書いてあるとおりだった」
- **結果の連絡が丁寧**：通過も不通過も、理由が分かる範囲で
- **落ちた学生にも、一言**：「丁寧だった」が残る
- **面接官が、学生の話を聞く**：「話を聞いてくれた」
- **書かれる選考の作り方は[知名度がない会社のワンキャリア運用](/media/oc-chimeido/)の「『書かれる選考』を、今年する」と[ワンキャリア経由の学生が選考で離脱するとき](/media/oc-senkou-ridatsu/)**
- **書かれる選考をしていれば、案内しなくても書かれる**：案内は、その上に一文添えるだけ

## 社員のクチコミの、扱い

- **社員が書くクチコミがある場合、企業が社員に書かせない**：社員のクチコミの仕組みと規約は、媒体で確認
- **社員に「良いことを書いて」と頼まない**：学生と同じ。頼んで書かれたものは分かる
- **社員に知らせるなら、「書く・書かないは自由、事実のまま」と同じ形で**：自社のルールで確認
- **社員のクチコミに書かれた「働き方」は、企業ページと揃っているか**：[ワンキャリアの自社クチコミの読み方](/media/oc-kuchikomi-yomikata/)
- **退職した社員のクチコミは、動かせない**：今年の働き方で、翌年のクチコミを作る

## 社内の分担

| 作業 | 誰が |
|---|---|
| 媒体の規約と自社のルールを確認し、案内するかを決める | 人事責任者と管理部門 |
| 案内の文面を規約に沿って作り、確認した日を残す | 人事 |
| 選考の結果を伝えた後、全員に同じ文面で一度だけ | 人事 |
| 「書かれる選考」の条件（連絡の速さ・見ることを聞く・丁寧な結果・落ちた学生への一言・話を聞く）を守る | 面接官と人事 |
| 社員のクチコミの扱いを、規約と自社のルールで決める | 人事責任者 |
| 書かれた体験談を読み、案内の効果ではなく選考の結果として見る | 人事 |

運用代行や代理店が支えられるのは、規約の確認の手伝い、してよい形としてはいけない形の整理、文面の型、「書かれる選考」の条件の整理までで、規約の最終確認、案内するかの判断、案内を送ること、選考を直すことは企業が行います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

これはどこまでやるかの線引きの話です。当社はワンキャリアの販売パートナーですが、投稿の案内について、当社が学生に案内を送ることも、案内の文面で「良いこと」を促すことも、対価を扱うことも、しません。当社が支えるのは、規約を一緒に確認すること、してよい形としてはいけない形を整理すること、「書かれる選考」の条件を今年の選考に入れることまでです。体験談は学生が書くもので、当社も企業も、その外にいます。相談の中で「体験談を増やす方法はないか」と言われたとき、当社が答えるのは案内の方法ではなく、「連絡を当日に返していますか。面接官は揃っていますか。落ちた学生に一言添えていますか」の三つです。この三つが「はい」なら、案内をしなくても書かれます。

## まとめ

- 案内できるか・どう案内してよいかは、媒体の規約で先に確認し、確認した日と内容を残す。不明なら案内しない
- 案内するなら「事実のまま、書く・書かないは自由、内容は指定しない、対価は出さない、厳しい内容でも構わない」の形で、選考の結果に関わらず全員に同じ文面で、選考の結果を伝えた後に一度だけ
- 「良いことを書いて」「通過した学生・内定者にだけ」「対価や条件」「内容の指定」「繰り返し」はしない。頼んで書かれたものは読んだ学生に分かり、企業ページの信頼まで下げる
- 案内より先に「書かれる選考」（連絡が速い・書いた「何を見るか」のとおりに聞く・結果の連絡が丁寧・落ちた学生にも一言・面接官が話を聞く）をする。それができていれば案内しなくても書かれる
- 社員のクチコミも同じで、社員に書かせない、良いことを頼まない。書かれた体験談は、案内の効果ではなく選考の結果として読む

## よくある質問

### 内定者から「体験談を書きましょうか」と言われました

内定者が自分の判断で書くのは、内定者の自由です。企業は「書く・書かないは自由で、事実のままで、内容は指定しません」とだけ伝え、方向を示さず、確認も求めません。「良い内容で」「〇〇について」と言った時点で、頼んだものになります。内定者の体験談だけが並ぶと偏って読まれるので、選考を受けた全員に同じ案内をしている状態が前提です。

### 案内したのに、書かれません

案内の問題ではなく、選考の問題です。「書かれる選考」の五つの条件（連絡が速い・書いたとおりに聞く・結果が丁寧・落ちた学生にも一言・話を聞く）のどれが欠けているかを確かめます。案内を繰り返しても書かれず、繰り返すほど「頼んでいる会社」になります。案内は一度で止め、今年の選考の運用を直し、翌年に書かれるかを見ます。直し方は[ワンキャリア経由の学生が選考で離脱するとき](/media/oc-senkou-ridatsu/)で書きました。

### クチコミ投稿の案内は、御社に相談できますか

できます。当社は、規約の確認の手伝い、してよい形としてはいけない形の整理、文面の型、「書かれる選考」の条件の整理を支えられます。規約の最終確認、案内するかの判断、案内を送ること、選考を直すことは、企業が行ってください。当社が学生に案内を送ることはしません。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
