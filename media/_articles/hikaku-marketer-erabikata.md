マーケターを新卒で採る会社が媒体を選ぶとき、最初にぶつかるのは「『マーケティング職』で出したら憧れの学生が多く来て安心したのに、面談で『新卒でマーケに配属されますか』『最初の年は何をしますか』と聞かれて『最初は営業から』と答えた時点で離れ、体験談に『マーケと言いながら営業だった』と書かれ、来た学生の多くが『何の数字を動かしたか』を話せない」という問題です。**結論から言うと、「マーケティング職」は学生に人気で数は来ますが、多くの会社で新卒はマーケに配属されず、学生は「新卒がマーケに配属されるのか、最初の年に何をし、何の数字を誰が見て、どの手段を使うか」を確かめます。「どのマーケか」（広告運用・SNS・コンテンツ・調査・商品企画）を一つ決め、送る型は「試した・測った・直した」で絞ってマーケの若手の名義で、記事を置く型は数字を動かした場面を、比べられる場は「新卒がマーケに配属されるか」を企業ページで先に書き、憧れで来た学生の数ではなく、数字を動かした経験を話せた学生の数で見ます。** 文系学生全般は[文系学生を採りたい会社の採用媒体の選び方](/media/hikaku-bunkei-erabikata/)で書きました。この記事はマーケターに絞ります。

## マーケターの採用で、起きること

| 会社の状態 | 採用で起きること | 媒体との相性 |
|---|---|---|
| 「マーケティング職」は学生に人気 | 憧れで数は来るが、数字を動かした経験を話せる学生は少ない | 「試した・測った・直した」で絞る。[OfferBoxでマーケター志望の学生を見つける検索の考え方](/media/ob-marketer-target/) |
| 新卒はマーケに配属されないことが多い | 「最初は営業から」で離れ、「マーケと言いながら営業」と体験談に書かれる | 配属の実態を企業ページで先に。[ワンキャリアでマーケターを募集するときの掲載とスカウト](/media/oc-marketer-keisai/) |
| 「マーケティング全般」で募集する | 広告運用かSNSかコンテンツか調査か商品企画かが分からない | 「どのマーケか」を一つに |
| 何の数字を誰が見るかが書かれていない | 学生は「数字を見る仕事か、作る仕事か」を確かめている | 数字と見る人を書く。[Wantedlyでマーケターを採る募集記事の書き方](/media/wt-marketer-boshu/) |
| マーケの若手が名義でない | 人事の名義の「マーケティング職」は憧れの像を強める | マーケの若手の名義で、数字を動かした場面を |
| 承認や応募が多い | 数で「効いている」と読み違える | 数字を動かした経験を話せた学生の数で |

## 判断軸を、マーケターに当てる

| 軸 | マーケターでの見方 |
|---|---|
| 対象（誰に届くか） | 「マーケ志望」で絞らない。「どのマーケか」で求める行動を決め、「試した・測った・直した」（何かを出して、反応を測って、変えた記述）で絞る。「発信が好き」「SNSをよく見る」は絞る条件にならない |
| 型（送るか、来るか、比べられるか） | 送る型は、行動で絞ってマーケの若手の名義で「あなたの〇〇を試して測った経験を読んで」と一人に書ける。来る型は、数字を動かした場面（何を出して、何が動いて、どう直したか）を記事で通年で。比べられる型は、「新卒がマーケに配属されるか」を企業ページで先に答えられるかで。答えられないなら「営業だった」と書かれる |
| 課金（費用の性格） | 各媒体の公式ページで現在の条件を確認。この記事では書かない。数は来るので、費用は「数字を動かした経験を話せた学生の数」で見る |
| 運用工数（誰の時間が要るか） | マーケの若手が名義と面談を持つ時間。数が来るので、返す時間が他の職種より要る |

軸の詳しい見方は[掲載型とスカウト型の違い](/media/hikaku-keisai-vs-scout/)、[共感型と条件型の媒体の違い](/media/hikaku-kyoukan-vs-jouken/)で書きました。マーケターでは、「対象」を憧れではなく行動で絞ることと、「型」で比べられる場の企業ページに配属の実態を先に書くことが、他の職種と違います。

### エージェントベストの見解

相談で最も多い思い込みは、「マーケティングは人気職種だから、『マーケティング職』で出せば集まる」というものです。当社は3媒体すべての販売パートナーとして、マーケターの採用の相談を受けますが、「マーケティング職」で出した会社の承認や応募は確かに多く、ところが面談で「何かを出して、反応を測って、直した経験」を聞くと、話せる学生は少なく、多くは「発信が好き」「SNSをよく見る」で止まります。新卒の配属が「最初は営業から」だと、憧れで来た学生は面談で離れます。逆に、「広告運用のマーケター。新卒は一年目からマーケに配属。最初の年は〇〇の広告の数字を毎日見て、△△（若手）と一緒に直す。見る数字は□□で、見るのは◇◇」と書き、「試した・測った・直した」で絞った会社は、承認は減りますが、数字を動かした経験を話せる学生が来ます。当社が最初にお願いするのは、「マーケティング全般」を「どのマーケか」に変え、「新卒がマーケに配属されるか」を最初に書き、絞る条件から「マーケ志望」を外して行動に置き換えることです。

## 学生が、確かめること

- **新卒がマーケに配属されるか**：一年目からか、営業を経てからか。「最初は営業から」なら、そう書かれているか
- **最初の年に何をするか**：数字を見るのか、作るのか、調べるのか。誰と組むか
- **何の数字を、誰が見るか**：売上か、反応か、来た数か。数字を見るのは自分か、上司か。届かないとき何が起きるか
- **どの手段を使うか**：広告運用か、SNSか、コンテンツか、調査か。「マーケティング全般」では分からない
- **営業との関係**：マーケが営業の下にあるのか、並ぶのか。数字の責任はどちらか
- **自分の経験が、読まれたか**：オファーの一文が、自分の「試した・測った・直した」のどこを見たか

## この条件なら、どれを先に検討するか

| 会社の条件 | 先に検討する型 | 理由 |
|---|---|---|
| 「どのマーケか」で行動を絞り、マーケの若手の名義で「あなたの〇〇を試して測った経験を読んで」と一人に書ける | 企業から送る型（OfferBox） | 憧れで来る学生ではなく、行動で絞った学生に届く。[マーケター向けのオファー文面](/media/ob-marketer-offer-bunmen/) |
| マーケの若手が、数字を動かした場面を自分の言葉で書ける | 通年で記事を置く型（Wantedly） | 「何を出して、何が動いて、どう直したか」の記事が、憧れの像を実態に置き換える |
| 体験談があり、企業ページに「新卒がマーケに配属されるか」と最初の年を先に書ける | 学生が並べて比べる場（ワンキャリア） | 「営業だった」の体験談に、企業ページで先に答えられるなら |
| 新卒がマーケに配属されない | マーケの募集としては出さない | 配属される職種（営業など）の募集に、「〇年目からマーケの道がある」と一文で |
| 「マーケティング全般」のまま | どれも先ではない | 「どのマーケか」に変えてから |

どれか一つが正解ではなく、配属の実態、マーケの若手が書けるか、体験談の有無で、先に検討するものが変わります。

## 組み合わせ

- **送る型と記事を置く型を組み合わせる**：文面で「試した・測った・直した」を読んだ一文を、記事で数字を動かした場面を。[OfferBoxとWantedlyの併用](/media/ob-heiyou-wantedly/)
- **比べられる場で配属の実態を先に答え、送る型で行動で絞る**：[OfferBoxとワンキャリアの併用](/media/ob-heiyou-onecareer/)
- **「どのマーケか」で、優先する行動を変える**：広告運用は「測って直した」、SNSとコンテンツは「出して反応を見た」、調査は「調べて分けた」
- **営業を経てマーケに行く会社は、営業の募集に道を書く**：[営業職の採用媒体の選び方](/media/hikaku-eigyo-erabikata/)
- **面談で、数字を動かした経験を聞く**：「なぜマーケか」を聞かない
- **代行と組み合わせるなら、行動で絞る作業と返信と一文の下書きを**：配属の実態の決定と面談は出せない。[媒体と代行の違い](/media/hikaku-baitai-vs-daikou/)

## 見せ方｜「マーケティング全般」ではなく、配属と数字と手段

- **「マーケティング職」「マーケティング全般」「発信が好きな方」を消す**：憧れの像を強め、数字を動かせる学生に届かない
- **「新卒がマーケに配属されるか」を、最初に**：「新卒は一年目からマーケに配属」か「最初の〇年は営業。マーケへは△年目から□□の条件で」。隠すと「営業だった」と書かれる
- **「どのマーケか」を、職種名に**：「〇〇の広告運用のマーケター」「△△のコンテンツのマーケター」
- **最初の年を、数字と組む人で**：「最初の年は〇〇の数字を毎日見て、△△（若手）と一緒に直す」
- **何の数字を誰が見るかを、届かないときまで**：「見る数字は□□。見るのは◇◇。届かない月は〇〇と一緒に見直す」。数値は自社の実態で。この記事では書かない
- **数字を動かした場面を、若手の話で**：「〇〇を出したら△△が動かず、□□に変えたら◇◇になった」
- **オファーの一文を、行動で**：「〇〇を試して反応を測って変えたと書かれていたのを読んで」

## 社内の分担

| 作業 | 誰が |
|---|---|
| 「どのマーケか」、新卒の配属の実態、何の数字を誰が見るか、最初の年を、言葉にする | マーケの責任者 |
| 企業ページと文面 | 人事が書き、マーケの責任者が確認 |
| 行動で絞る条件 | 人事か代行。「どのマーケか」で優先する行動を責任者と決める |
| 名義と、オファーの一文 | マーケの若手 |
| 数字を動かした場面の記事 | マーケの若手が話し、人事が書き、本人が確認 |
| 面談 | マーケの若手と責任者。「なぜマーケか」を聞かず、数字を動かした経験を聞く |
| 「数字を動かした経験を話せた学生の数」の記録 | 人事 |

運用代行や代理店が支えられるのは、「どのマーケか」の型、行動で絞る作業、返信、一文の下書き、記録の型までで、配属の実態の決定、名義の若手、記事の中身、面談は社内が担います。代理店の代行の範囲は[代理店に運用まで頼めるか](/media/kh-dairiten-unyou/)で書きました。

### エージェントベストの見解

マーケターの採用で数字を読むときに先にお伝えしているのは、「承認や応募の多さを、効いていると読み違えない。数字を動かした経験を話せた学生の数で見る」ということです。「マーケティング職」は人気で、憧れで承認や応募が来ます。数だけを見ると「効いている」と読めますが、面談で「何かを出して、反応を測って、直した経験」を聞くと話せる学生は少なく、話せない学生に内定を出すと、入社後に数字を見る仕事に耐えられずに離れます。当社が案内するのは、面談で「試した・測った・直した」の経験を聞き、話せた学生を記録し、その数で見ることです。「どのマーケか」と配属の実態を書き、行動で絞ると、承認は減りますが、この数は増えます。承認が減ったことを見て「マーケティング職」に戻すと、憧れの学生が戻り、話せる学生は減ります。辞退の理由を「他社に決めた」で終わらせず、「配属か、数字か、手段か、どれが違ったか」まで聞くと、企業ページのどこが足りないかが分かります。

## まとめ

- 「マーケティング職」は学生に人気で数は来るが、多くの会社で新卒はマーケに配属されず、数字を動かした経験を話せる学生は少ない
- 学生が確かめるのは「新卒がマーケに配属されるか、最初の年に何をし、何の数字を誰が見て、どの手段を使うか」。配属の実態を最初に書き、「どのマーケか」を一つに
- 送る型（OfferBox）は「試した・測った・直した」で絞ってマーケの若手の名義で、記事を置く型（Wantedly）は数字を動かした場面を、比べられる場（ワンキャリア）は「新卒がマーケに配属されるか」を企業ページで先に
- 新卒がマーケに配属されない会社は、マーケの募集として出さず、配属される職種の募集に道を書く
- 承認の多さではなく「数字を動かした経験を話せた学生の数」で見て、承認が減っても「マーケティング職」に戻さない

## よくある質問

### 新卒は営業を経てからマーケに配属しています。「マーケティング職」で募集してはいけませんか

「マーケティング職」で募集して営業に配属すると、「マーケと言いながら営業だった」と体験談に書かれ、翌年から憧れの学生も来なくなります。営業の募集として出し、「〇年目からマーケの道がある。条件は△△。営業からマーケに行った人が□人」と道を書きます。マーケに行きたい学生は、道が書かれていれば営業の募集にも来ます。

### 「試した・測った・直した」の経験がある学生が、見つかりません

マーケの経験に限ると見つかりません。サークルの集客、アルバイトの売り場、個人の発信など、「何かを出して、反応を見て、変えた」経験は、マーケ以外の場面にあります。「〇〇の企画で人が集まらず、△△を変えたら□□人来た」の記述を、記述の中から探します。

### マーケターの媒体選びは、御社に相談できますか

できます。当社は、「どのマーケか」の型、行動で絞る作業、返信、一文の下書き、記録の型を支えられます。配属の実態の決定、名義の若手、記事の中身、面談は、社内で担ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、マーケターの媒体選びと運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
