退職した元社員は、会社の中を知っていて、いまは外から会社を見ている読者です。Wantedlyの会社ページやストーリーは、候補者だけでなく、こうした元社員にも読まれます。「元社員に戻ってきてほしい」「辞めた人ともつながりを保ちたい」という相談を受けることが増えました。**結論から言うと、元社員に向けた発信は「戻ってきてください」という募集にせず、「辞めてから会社の何が変わったか」を場面で書くことが中心です。その前に、戻る道をどう扱うかを社内で決めておきます。決まっていないまま発信すると、在籍している社員と元社員の両方に誤解が残ります。** ストーリーの基本は[Wantedlyのストーリーの基本](/media/wt-story-kihon/)、入社した人に書いてもらう方法は[入社エントリーを書いてもらう方法](/media/wt-story-nyusha/)で書きました。

## この作業の目的｜元社員が「いまの会社」を知れる状態にする

元社員が知っている会社は、辞めた時点の会社です。その後に事業が変わり、働き方が変わり、人が入れ替わっても、元社員の中の会社は止まったままです。元社員が周りに会社のことを話すとき、話すのはその止まった会社です。

目的は、元社員が「いまの会社」を知れる状態を作ることです。そのうえで、戻りたい人が戻る道を知り、戻らない人も、いまの会社を正しく周りに話せるようにします。戻ってきてもらうことは、その結果の一つです。

## 手順1｜戻る道の扱いを、社内で先に決める

発信の前に、次のことを人事と経営で決めます。

| 決めること | 決め方 |
|---|---|
| 再入社を受け入れるか | 受け入れるなら、どの職種で、どの選考の形で |
| 処遇の考え方 | 在籍している社員との公平さを、どう説明するか |
| 対象 | 退職の経緯によって扱いを分けるか |
| 窓口 | 元社員が相談したいとき、誰に連絡すればよいか |
| 書かないこと | 決まっていない制度、個別の約束 |

決まっていないことは書きません。「いつでも戻ってきてください」と書いたあとで、実際には選考の形も処遇も決まっていなかった、となると、元社員にも、それを読んだ在籍している社員にも、不信が残ります。

## 手順2｜題材の型を決める

| 型 | 何を書くか | 元社員が得るもの |
|---|---|---|
| 辞めてから変わったこと | 事業、働き方、決め方で、この数年に変わった一つの場面 | いまの会社の姿 |
| 戻った人の話 | 一度外に出て、戻ってきた社員が、外で何を見て、戻って何が違ったか | 戻る道の実際 |
| 変わっていないこと | 辞めた人が覚えているであろう、いまも続いている習慣や考え方 | 会社の軸 |
| 外での経験が生きた話 | 他社の経験を持って入った人が、それをどう使っているか | 外に出ることへの会社の見方 |

どの型でも、書くのは一つの場面です。「戻った人の話」は、本人が話したいと言った場合だけ書きます。題材の選び方は[ストーリーのテーマの決め方](/media/wt-story-theme/)と同じです。

### エージェントベストの見解

相談で多い思い込みは、「元社員向けの発信とは、出戻りの募集記事を出すことだ」というものです。当社は紹介で採る場合と媒体で採る場合の両方を見ていますが、元社員が戻ってくる流れの多くは、募集記事を見て応募するところからではなく、元の同僚と話したり、会社の記事を読んだりして、「いまはこうなっているのか」と知るところから始まっています。出戻りの募集を先に出すと、元社員は「人が足りないから呼んでいる」と読みます。当社が勧めるのは、まず「辞めてから変わったこと」のストーリーを一本出すことです。いまの会社を知った元社員が自分で考え、戻りたい人は窓口に連絡してきます。募集は、その連絡が来るようになってから考えても遅くありません。

## 手順3｜届け方を決める

- **会社ページとストーリーは、誰でも読める**：元社員にだけ届ける場ではない。候補者が読んでも違和感のない書き方にする
- **在籍している社員から、元の同僚に伝えてもらう**：会社が直接送るより、知っている人の一言のほうが読まれる。頼み方は[Wantedlyの記事をSNSで広げる方法](/media/wt-sns-kakusan/)と同じで、本人が一言添えて出す形
- **元社員の連絡先の使い方は、自社の方針に沿う**：退職時の取り決めや、自社の個人情報の取り扱い方針の範囲で連絡する
- **元社員向けの交流の場がある会社は、そこで記事を共有する**：場がない会社が、記事のために新しく作る必要はない

社員のつながりから来る人の流れは、[Wantedlyとリファラル採用の併用](/media/wt-heiyou-referral/)で書いたものと近い考え方です。

## やりがちな失敗

| 失敗 | 何が起きるか | 直し方 |
|---|---|---|
| 「戻ってきて」だけを書く | 人手不足の告知に見える | 変わったことを場面で書く |
| 辞めた人を否定的に書く | 元社員にも候補者にも印象が悪い | 辞めた理由に触れない。触れるなら本人の言葉で |
| 元社員の現在の勤め先を、同意なく書く | 本人と、いまの勤め先に迷惑がかかる | 本人が出してよい範囲だけ |
| 戻った人を特別扱いして書く | 在籍している社員が不公平に感じる | 外での経験がどう生きたかを、事実で書く |
| 決まっていない制度を書く | 問い合わせが来ても答えられない | 決まってから書く |

出してよい情報の線引きは[Wantedlyで会社の素顔を出す範囲](/media/wt-kaisha-no-sugao/)で書きました。

## 社内の分担

| 作業 | 誰が |
|---|---|
| 戻る道の扱いを決める | 人事と経営 |
| 題材を拾う（変わったこと、戻った人） | 人事と現場に近い人 |
| 話す | 戻った本人、変化を知る社員 |
| 書く・本人の確認を取る | 人事 |
| 元の同僚に伝える | 在籍している社員（頼む形で） |
| 元社員からの連絡を受ける | 決めた窓口 |

### エージェントベストの見解

元社員に向けて発信する前に、先に決めておかないと効果が出ないことがあります。「戻った人を、社内でどう迎えるか」です。当社がWantedlyの運用の相談で戻った人のストーリーを見るとき、記事そのものはよく書けているのに、在籍している社員から「戻った人ばかり持ち上げられている」という声が出て、次の記事が止まる会社があります。原因は、処遇や役割の考え方が社内で説明されないまま、記事だけが先に出たことです。当社が勧める順番は、まず戻る道の扱いを社内に説明し、次に「辞めてから変わったこと」の記事を出し、戻った人の話はそのあとにすることです。社内が納得している状態で出た記事は、在籍している社員も自分から元の同僚に伝えてくれます。

## まとめ

- 元社員は、辞めた時点の会社を覚えている読者。目的は「いまの会社」を知ってもらうこと
- 発信の前に、再入社の扱い・処遇の考え方・対象・窓口を社内で決める。決まっていないことは書かない
- 題材は、辞めてから変わったこと・戻った人の話・変わっていないこと・外での経験が生きた話。一本に一つの場面
- 届け方は、在籍している社員から元の同僚へ一言添えて。連絡先の使い方は自社の方針に沿う
- 「戻ってきて」だけの記事、辞めた人を否定する記事、同意のない現職の記載を避ける

## よくある質問

### 円満に辞めたとは言えない元社員にも、届いてしまいませんか

会社ページとストーリーは誰でも読めるので、届くことを前提に書きます。そのため、辞めた理由や個別の事情には触れず、いまの会社の場面を事実で書きます。特定の元社員に向けた書き方をしなければ、誰が読んでも受け取り方は大きく変わりません。

### 戻った社員が、記事に出ることをためらっています

無理に頼みません。戻った人の話は、本人が話したいときにだけ書く題材です。代わりに「辞めてから変わったこと」を、在籍している社員の目で書けば、元社員に向けた記事として成り立ちます。名前を出さずに、外での経験がどう生きたかの場面だけを書く方法もあります。

### 元社員に向けた発信は、御社に相談できますか

できます。当社は、題材の型、記事の構成、戻る道の扱いを社内で決めるための論点の整理を支えられます。戻る道の扱いを決めること、本人に話してもらうこと、確認は企業が行ってください。当社は採用媒体の代理店として、Wantedlyのコンテンツづくりを支えています。
