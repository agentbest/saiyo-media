スカウト文面のテンプレートは、作ること自体は難しくありません。難しいのは、作ったあとです。送る人ごとに少しずつ変わり、企業ページの選考の流れを直しても型は古いまま、面接に出る人が型に書いた「何を見るか」を知らず、体験談に「テンプレだった」と書かれても型を見直さない。**結論から言うと、テンプレートには「変えない部分」（最初の1年の一文、選考で何を見るかの一文、話す場か選考かの案内、署名、企業ページへの誘導）だけを入れ、「変える部分」（学生時代を読んだ一文、重なる点）は入れません。型は募集ごとに一つ、置き場は一か所、企業ページの選考の流れと同じ内容で、企業ページを直したら型を見る、選考が変わったら型を見る、年度の切れ目に型を見る、体験談で指摘されたら型を見る。古い型は消さずに「使わない」印を付けます。** この記事では、型に入れるものと入れないもの、やりがちな失敗、置き場、募集ごとに一つ、更新の起点、古い型の扱い、送る人に渡す形、体験談との関係、分担を整理します。文面の4段は[ワンキャリアのスカウト文面の書き方](/media/oc-scout-bunmen/)、変える範囲は[ワンキャリアのスカウトを相手ごとに変える範囲](/media/oc-scout-kojinka/)で書きました。他媒体の型の管理は[OfferBoxのオファー文面のテンプレート](/media/ob-offer-template/)と[Wantedlyのスカウト文面のテンプレート管理](/media/wt-scout-template/)で書きました。

## この作業の目的｜送る人が2か所だけ書けば済み、企業ページと揃った状態を保つ

テンプレートの目的は、「送る人が、学生時代を読んだ一文と重なる点の2か所だけを書けば、文面が完成する」状態を作り、それを保つことです。

ワンキャリアでは、もう一つ目的があります。型に入っている「選考で何を見るかの一文」が、企業ページの選考の流れと揃っていることです。ずれていると、学生が文面と企業ページを読み比べたときに「どちらが本当か」となります。管理の目的は、「作る」ではなく「保つ」と「揃える」です。

## 型に入れるもの、入れないもの

| 入れる（変えない部分） | 入れない（変える部分） |
|---|---|
| 最初の1年の一文（企業ページから） | 学生時代を読んだ一文 |
| 選考で何を見るかの一文（企業ページの選考の流れから） | 最初の1年との重なる点 |
| 話す場か選考かの案内（誰が、どんな形で） | |
| 企業ページへの誘導の一文 | |
| 署名（名前、近さ、会社名） | |
| 書き出しの型（「〇〇を読んで連絡しました」の形。〇〇は空欄） | |

「変える部分」を型に入れると、送る人はそこを埋めずに送ります。空欄にして、「ここは毎回書く」と明示するほうが、テンプレの一斉送信を防げます。ワンキャリアでは、埋めずに送った結果が体験談に「テンプレだった」と書かれます。

## やりがちな失敗

| 失敗 | 何が起きるか |
|---|---|
| 型が増えすぎる（学年別、専攻別、時期別） | どれを使うか迷う。古い型が使われ続ける |
| 置き場がばらばら（個人のメモ、チャット、管理画面の下書き） | 誰が最新を持っているか分からない |
| 企業ページの選考の流れを直したのに、型が古いまま | 文面と企業ページがずれる。学生が「どちらが本当か」 |
| 面接に出る人が、型の「何を見るか」を知らない | 文面に書いたことと違う面接。体験談に「スカウトと違った」 |
| 送る人が、型を自分の好みで変える | 送る人ごとにトーンがばらつく |
| 型に「変える部分」まで書いてある | 埋めずに送られ、体験談に「テンプレだった」 |
| 体験談で「テンプレだった」と書かれても、型を見直さない | 翌年も同じことが書かれる |
| 「話す場」と型に書いたまま、運用が選考に変わった | 型と運用がずれる |

最も多いのは、「型が増えすぎる」と「企業ページとずれる」の二つです。前者は属性ごとに型を作った結果、後者は企業ページと型の置き場が別で、片方だけ直した結果です。

### エージェントベストの見解

相談で最も多い思い込みは、「学年や専攻ごとに型を分けておくと、個別化になる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、「三年生向け」「理系向け」「早期向け」と型を分けている会社の文面を読むと、どの型も「変える部分」が型の中に書かれていて、送る人は型を選ぶだけで送っています。属性ごとの型は、個別化ではなく、テンプレの種類が増えただけで、学生の体験談には「テンプレだった」と書かれます。当社が型を整理するとき、最初にやるのは、型の数を募集ごとに一つに減らし、「変える部分」を型から抜いて空欄にすることです。個別化は、型の数ではなく、空欄を毎回埋めることで起きます。型は少ないほど、空欄が目立ち、埋められます。

## 置き場を一か所にする

- **社内で普段使っているドキュメントか表計算に、一つのファイル**：専用の道具は要らない
- **募集ごとに一つの型が、並んでいる形**：募集名、型、見本、最終更新日、担当、対応する企業ページの箇所
- **管理画面の下書きや個人のメモは、置き場にしない**
- **送る人全員が、同じ場所を見る**：「最新はここ」が共通
- **企業ページの写しと同じ場所か、隣に置く**：型の「選考で何を見るか」と企業ページの選考の流れを、並べて見られる

「企業ページの写しと隣に置く」が、ワンキャリアの型の置き場の要点です。片方を直したときに、もう片方が目に入ります。

## 募集ごとに一つ

- **同じ募集に、複数の型を持たない**：学年や専攻で分けたくなったら、「変える部分」で対応する
- **募集が増えたら、型も一つ増える**：企業ページの「最初の1年」と「選考の流れ」から取って作る
- **募集が終わったら、型に「使わない」印を付ける**：消さない
- **コースを分けたら、型も分ける**：[募集コースの考え方](/media/oc-boshu-course/)

「募集の数＝型の数」が、管理できる上限です。

## 更新の起点

| いつ | やること |
|---|---|
| 企業ページの「最初の1年」や「選考の流れ」を直したとき | 型を開いて、同じ内容かを見る。違えば直す |
| 選考の流れが変わったとき | 型の「何を見るか」と「話す場か選考か」を直す。面接に出る人にも伝える |
| 話す人や面接に出る人が変わったとき | 話す場の案内と署名を直す |
| 年度の切れ目 | 型を開いて、企業ページと並べる。年度の公表内容と自社の方針に関わる記述を確認 |
| 体験談にスカウトへの指摘があったとき | 「テンプレだった」なら、変える部分が埋められているかを見直す。「話す場と聞いていたのに」なら、4段目と運用を揃える |
| 月に一度 | 受諾が来た一文を見て、書き出しの型を一つだけ直すかを決める |

「企業ページを直したら型を見る」を、企業ページの更新の手順の最後に入れます。企業ページの更新の起点は[企業ページを更新し続ける方法](/media/oc-kigyo-page-koushin/)で書きました。

## 古い型の扱い

- **「使わない」印を付けて、一覧の下に移す**：送る人が間違って使わないように
- **受諾が来た一文と一緒に残す**：どの型でどの一文が効いたかは、次の型の材料になる
- **募集が再開したら、印を外して、企業ページと照らしてから使う**：そのまま使わない
- **担当が変わったとき、古い型の一覧を渡す**：「なぜこの形になったか」が分かる

## 送る人に渡す形｜型と見本

- **型**：変えない部分が書かれ、変える部分が空欄
- **見本**：空欄が埋まった、実際に受諾が来た文面（学生の情報は伏せる）
- **「ここは毎回書く」の注記**：空欄の横に
- **避ける言葉の一覧**：短く
- **送る前のチェックの三つ**：学生の一文があるか、選考の一文が企業ページと同じか、話す場か選考かが曖昧でないか
- **企業ページの該当箇所**：「最初の1年」と「選考の流れ」の写し。送る人が読んでおく

見本があれば、「このくらいの具体で」が伝わります。分担の考え方は[ワンキャリアのスカウトを誰が送るか](/media/oc-scout-tantou/)で書きました。

## 面接に出る人に、型の「何を見るか」を渡す

ワンキャリアの型には、「選考で何を見るか」が入ります。この一文を、面接に出る人が知らないと、文面と面接がずれます。

- **型を作るときに、面接に出る人に「何を見るか」を聞く**：人事が想像で書かない
- **型ができたら、面接に出る人全員に、その一文を渡す**：「スカウトの文面には、こう書いています」
- **面接の型（聞くことの順番）と揃える**
- **選考の流れが変わったら、型と面接の型を同時に直す**
- **面接に出る人が変わったら、その一文を渡す**

「型の一文を面接に出る人が知っている」状態が、文面と面接が揃う条件です。掲載との揃え方は[本選考を掲載するときの書き方](/media/oc-honsenkou-keisai/)で書きました。

## 体験談の指摘と、型の関係

| 体験談の指摘 | 型で見ること |
|---|---|
| 「テンプレだった」「大学名だけ変えたような」 | 変える部分が空欄になっているか。送る人が埋めているか。読める数で送っているか |
| 「話す場と聞いていたのに、選考だった」 | 4段目の案内と、運用が揃っているか |
| 「スカウトに書いてあった選考の流れと違った」 | 3段目と、企業ページと、面接の型が揃っているか |
| 「自分のことを読んでくれていた」 | 良い例。その文面を見本に |
| 「スカウトの選考の説明が分かりやすかった」 | 3段目が効いている。残す |

### エージェントベストの見解

申し込んだあと、型の管理で一年後に起きやすいのは、「企業ページの選考の流れを年度で直したのに、スカウトの型は前年のままで、文面に古い選考の流れが書かれて送られる」ことです。当社は、ワンキャリアの型の置き場を聞いて、企業ページの写しと同じ場所にあるかを見ます。別の場所にあると、片方だけ直され、ずれます。当社が型の管理を支えるとき、最初にお願いするのは、型と企業ページの写しを一か所に並べて置くことと、「企業ページを直したら型を開く」を更新の手順の最後に入れることです。開くだけで足ります。開けば、ずれに気づきます。型は、作ることより、企業ページと並べて開き続けることで保たれます。

## まとめ

- 型には「変えない部分」（最初の1年の一文、選考で何を見るかの一文、話す場か選考かの案内、署名、誘導）だけを入れ、「変える部分」は空欄にする。属性ごとに型を分けない
- 型が増える、置き場がばらばら、企業ページとずれる、面接に出る人が「何を見るか」を知らない、体験談の指摘で見直さない、が失敗
- 置き場は一か所、企業ページの写しと隣に、型は募集ごとに一つ。企業ページを直したら型を見る、選考が変わったら型と面接の型を直す、年度の切れ目に開く、体験談の指摘で見る
- 古い型は消さず「使わない」印。送る人には型と見本と避ける言葉とチェックと企業ページの該当箇所を渡す
- 型の「何を見るか」を面接に出る人全員に渡す。体験談の「テンプレだった」には、言葉ではなく空欄が埋まっているかと読める数を見直す

## よくある質問

### 送る人が「この学生には型が合わない」と言います

型は「変えない部分」だけなので、学生に合わせるのは空欄の2か所です。合わないと感じるのは、「最初の1年」や「何を見るか」が企業ページとずれているか、その学生が募集の「こんな人」から外れているかです。前者なら型と企業ページを揃え、後者なら送らない判断をします。型を増やしません。

### 型を作る時間がありません

企業ページから、「最初の1年」の一文、「選考で何を見るか」の一文、話す場の案内を抜き出し、署名を付ければ、型はできます。企業ページが整っていれば、短時間で済みます。整っていなければ、型より先に企業ページです。企業ページが整っていない状態で型を作ると、型に想像の「何を見るか」が入り、面接とずれます。

### ワンキャリアのスカウト文面の型の管理は、御社に相談できますか

できます。当社は、型の作成、置き場の設計、更新の起点の型、見本の作成、古い型の整理、体験談の指摘と型の対応の整理を支えられます。「最初の1年」と「何を見るか」の決定、空欄を埋めること、送ること、面接は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は[3媒体の違いと選び方](/media/hikaku-3baitai/)にまとめています。
