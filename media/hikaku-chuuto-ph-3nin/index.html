年に数名を中途採用する会社の媒体の選び方

年に数名を中途採用する会社では、募集が一つで終わらなくなります。営業を一人、事務を一人、技術職を一人。職種も時期もずれた募集が、一年のうちに重なったり離れたりします。結論から言うと、年に数名を採る会社は、媒体を職種ごとに一つずつ選ぶより、募集を二つ程度の型に分けて回すほうが、手間と結果の両方で無理がありません。 「条件で探される募集」と「中身で選んでほしい募集」のように型で分けると、媒体の数が増えすぎずに済みます。この記事では、この規模で割ける時間、最初に決めること、型の分け方、併用の目安、分担を整理します。数値と料金は書かず、媒体の優劣も断定しません。

年に数名の会社で割ける時間と人

年に数名を採る会社では、採用を担う人がはっきりし始めます。総務や管理部門の担当が、他の仕事と兼ねながら採用を受け持つ形が多く見られます。

この規模で起きやすいのは、次のようなことです。

  • 募集ごとに別の媒体を申し込み、管理画面と返信の窓口が増える
  • 前の募集の選考が終わる前に次の募集が始まり、面接の日程が重なる
  • 職種によって面接に出る人が違い、日程の調整に時間がかかる
  • 求人票の書き方が募集ごとにばらばらで、会社の印象がそろわない

年に1人の会社との違いは、採用が「たまにやるもの」から「いつも何かが動いているもの」に変わる点です。だから、一回ごとに設計するやり方から、共通の型を持つやり方に移る時期でもあります。

最初に決めること

年の初め、または採用の計画を立てる時点で、次のことを決めます。

  1. 今年の募集の一覧：職種、人数、入社してほしい時期。決まっていないものは「予定」として書く
  2. 募集の型の分け方：それぞれの募集が、条件で探される募集か、中身で選んでほしい募集か
  3. 共通にするもの：会社の紹介文、条件の書き方、面接の流れ。募集ごとに変えない部分
  4. 担当者が使える時間：採用の担当が週にどれだけ採用に使えるか。重なる時期はどこか

一覧を作ると、募集が重なる時期が見えます。重なる時期に面接が集中しないよう、掲載の開始やスカウトの時期をずらすことができます。

今年の募集の一覧から、どの型の媒体で回すかを整理します。新卒と中途で媒体を分けるかの相談もどうぞ。

媒体選びを相談する

エージェントベストの見解

年に数名を採る会社から受ける相談で多いのは、「職種ごとに一番合う媒体を選びたい」というものです。当社は総合型の転職サイトも、IT・Web業界に寄った媒体も、共感型の媒体も、紹介で採る形も扱っているので、職種ごとに候補を挙げることはできます。ただ、この規模の会社に先に勧めるのは、媒体を二つ程度に絞ることです。媒体が増えるたびに、管理画面、返信の窓口、求人票の書き方の作法が一つずつ増え、兼務の担当者の時間がそこに吸われます。たとえば、条件で探される募集はまとめて総合型の転職サイトに出し、会社の考えで選んでほしい募集は共感型の媒体に寄せる。この二つで回らない職種が出たときだけ、紹介か業界寄りの媒体を足す。職種ごとの最適より、担当者が回せる数を先に決めるほうが、一年を通して止まりにくくなります。

型の分け方｜二つの型で回す

募集を型で分けると、次のように整理できます。

募集の型例先に検討する媒体の型
条件で探される募集経理、事務、経験のある営業総合型の転職サイト（doda、マイナビ転職、type など）の掲載とスカウト
中身で選んでほしい募集新しい役割、経験を問わない職種共感型のWantedlyの記事とカジュアル面談
IT・Web系の職種エンジニア、デザイナーIT・Web業界の求人を中心に扱うGreenの求人とスカウト

すべてを使う必要はありません。今年の募集の一覧を見て、多い型を二つ選びます。残りの募集は、その二つのどちらかに寄せられないかを先に考え、寄せられないものだけ別の手段を足します。

型の違いは掲載型とスカウト型の違い、共感型と条件型の媒体の違いで詳しく書いています。

併用の目安｜どこまで増やすか

二つの型を併用するときは、次の点を決めておきます。

  • 窓口を一つにする：どの媒体から来た応募も、同じ担当者が同じ場所で管理する
  • 会社の紹介文を共通にする：媒体ごとに書き直さず、元の文章を一つ持ち、媒体に合わせて長さだけ変える
  • 面接の流れを共通にする：職種ごとに面接官は変わっても、回数と各回で見ることの型はそろえる
  • 振り返りの時期を決める：募集が一つ終わるたびに、どの型から来た人が、どこまで進んだかを見る

併用の考え方は複数の媒体を併用するときの考え方にもまとめています。面接の流れの型は面接の設計で一枚の表にできます。

二つの型の併用で、どこを共通にし、どこを外に出すか。運用の相談を受けています。

運用の相談をする

エージェントベストの見解

年に数名の採用で、申込のあとに運用が崩れる会社に共通するのは、募集が重なった時期に返信が遅れることです。一つの募集の面接を進めている最中に、別の媒体から別の職種の応募が届き、担当者が気づくのが数日後になる。候補者から見れば、その数日で会社の印象が決まります。当社が勧めているのは、募集が重なる時期を一覧で先に見つけ、その時期だけ応募への一次返信と日程の調整を外に出すことです。一年中外に出す必要はなく、重なる時期だけでも返信の遅れは防げます。採用の担当者が面接の準備と判断に集中できる時期を作ることが、この規模の会社の採用を安定させる近道だと考えています。

社内の分担

  • 代表・部門の責任者：募集の一覧の決定、職種ごとの最終面接
  • 採用の担当（兼務）：応募の管理、返信、日程の調整、媒体ごとの状況の把握
  • 現場の社員：面接への同席、記事やスカウトへの登場
  • 外に出せること：求人票の文章、スカウトの配信、重なる時期の一次返信と日程の調整

新卒も含めた社員数ごとの考え方は従業員30名規模の会社の採用媒体の選び方で書いています。

まとめ

  • 年に数名の会社は、職種ごとに媒体を選ぶより、二つ程度の型に分けて回す
  • 年の初めに募集の一覧を作り、重なる時期を見つけておく
  • 会社の紹介文と面接の流れは、媒体をまたいで共通にする
  • 二つで回らない募集だけ、紹介や業界寄りの媒体を足す
  • 募集が重なる時期だけ、返信と日程の調整を外に出す方法もある

よくある質問

職種ごとに媒体を変えないと、合う人が来ないのではありませんか

職種によっては、業界に寄った媒体のほうが出会いやすいこともあります。ただ、媒体を増やすほど管理の手間が増えるので、まず二つの型で試し、届かない職種だけ足す順番を勧めます。

募集が重なって面接が回りません

募集の一覧を見て、掲載の開始やスカウトの時期をずらせないかを先に考えます。ずらせない場合は、一次の面接を短いオンラインにする、返信と日程の調整を外に出すなど、面接官の時間を守る形を検討します。

振り返りは何を見ればよいですか

型ごとに、応募、面接、内定、入社のどこまで進んだかを見ます。どこで止まった人が多いかで、見直すのが求人票なのか、選考の速さなのかが分かります。
