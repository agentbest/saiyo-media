WantedlyとGreenの違い｜共感で集めるか、求人で応募を集めるか

公開 2026-09-10

  3. 運用の時間の使い方が違う

  5. 併用するときの分担

「エンジニアやWeb系の職種を中途で採りたい。WantedlyとGreenのどちらがいいか」という相談を、IT系の会社やスタートアップからよく受けます。結論から言うと、この2つは候補者が集まる理由が違います。Wantedlyは会社の想いに共感した人が集まる型、Greenは求人票の条件を見て応募する型です。 どちらが優れているかではなく、自社が「想いを書いて見せられるか」と「条件で応募を集めたいか」で先に検討する媒体が決まります。Wantedlyはウォンテッドリー株式会社が運営する、会社と人がつながるビジネスSNSで、募集情報を掲載する場です。Greenは株式会社アトラエが運営する、IT・Web業界を中心とした中途採用の求人サイトです。この記事ではGreenの仕様や料金には触れず、集まる理由の違いが採用の設計にどう効くかを整理します。

候補者が集まる理由が違う

Wantedlyでは、候補者は会社ページ、募集記事、ストーリー（会社の日常や考えを書く記事）を読みます。「なにをやっているのか」「なぜやるのか」「どうやっているのか」を読み、共感したら「話を聞きに行きたい」と動きます。給与や条件を前面に出さない設計で、まず会って話すことが入口です。

Greenでは、候補者は求人票を読みます。職種、仕事内容、求める経験、給与、勤務地。条件を見て、合うと思えば応募します。求人票の情報量と具体性が、応募の質を決めます。

観点WantedlyGreen
候補者が読むもの会社ページ・募集記事・ストーリー求人票
集まる理由会社の想い・カルチャーへの共感条件と経験のマッチ
入口の動き話を聞きに行く（まず会う）応募する（選考に入る）
企業が用意するもの想いを言葉にした記事と、更新し続ける時間具体的な求人票と、応募への対応

つまり、Wantedlyは「書いて見せる」ことに時間を使い、Greenは「求人票を整えて、応募に対応する」ことに時間を使います。新卒採用でのWantedlyの位置づけはOfferBoxとWantedlyの違いで書きましたが、中途採用でも「書いて見せる」型であることは同じです。

企業が用意するものが違う

Wantedlyで必要なのは、会社の想いを言葉にした記事です。ミッション、バリュー、代表や社員の考え、日々の仕事の様子。これを会社ページとストーリーに書き、更新し続けます。書けていない会社は、始めてから「何を書けばいいか分からない」で止まります。

Greenで必要なのは、具体的な求人票です。仕事内容、使う技術、チームの構成、求める経験、給与の幅。抽象的な求人票には応募が集まりにくく、具体的な求人票には条件の合う応募が集まります。書くものは「想い」ではなく「仕事の中身と条件」です。

この違いは、社内で誰が書けるかに直結します。

  • Wantedly：会社の想いを自分の言葉で語れる人が要る。代表、創業メンバー、現場のリーダー
  • Green：仕事の中身と条件を具体的に書ける人が要る。現場のマネージャー、人事

会社の想いがすでに言葉になっているか、求人票を具体的に書ける人がいるか。整理するだけでも媒体は絞れます。

媒体選びを相談する

エージェントベストの見解

中途採用でWantedlyを検討する会社に、当社がまず聞くのは「会社の想いを、社内の誰かがすでに言葉にしているか」です。ミッションやバリューが言葉になっていて、代表や社員が自分の言葉で語れる会社は、Wantedlyの会社ページとストーリーが自然に書けます。逆に、それがまだ言葉になっていない会社が、Wantedlyを先に始めると、記事が書けずに止まります。その場合は、先に求人票で条件を出して応募を集める型で候補者に会い、面談で「自社の何が響くか」を掴んでから、Wantedlyの記事に落とすほうが順番として無理がありません。Wantedlyの販売パートナーである当社が、あえてこの順番を勧めるのは、契約したあとに書けずに止まる会社を多く見てきたからです。書けるかどうかを、申込前に社内で確かめてから決めることを勧めます。

運用の時間の使い方が違う

Wantedlyは、通年で動きます。募集記事は出しっぱなしでは読まれにくく、ストーリーの更新やスカウトの送信を続けることで、会社ページに人が来る状態を保ちます。採用したい時期だけ動かすより、年間で回すほうが、投じた時間に対して成果が安定します。

Greenは、求人を出している期間に動きます。求人票を出し、応募に対応し、選考に進める。採用が決まれば求人を閉じ、次の募集で再び出す。募集ごとに山を作る運用です。

  • Wantedly：通年で育てる運用。会社ページを「会社の説明書」として育て、募集が出るたびに活かす
  • Green：募集ごとに山を作る運用。求人票を整え、応募に対応する期間に集中する

採用の予定が通年で続く会社はWantedlyの型が向き、特定の職種を特定の時期に採りたい会社は求人型が向く傾向があります。

この条件ならどちらを先に検討するか

優劣ではなく、先に検討する順番として置きます。

  • 会社の想いが言葉になっていて、語れる人がいる。通年で採用が続く → Wantedlyを先に
  • 求める経験と条件がはっきりしていて、求人票を具体的に書ける。特定の時期に採りたい → Greenのような求人型を先に
  • 条件より価値観で集めたい。まず会って話すことから始めたい → Wantedlyを先に
  • 経験者を条件で絞って、応募から選考に入りたい → 求人型を先に
  • 会社の想いがまだ言葉になっていない → 求人型で先に候補者に会い、何が響くかを掴んでからWantedlyへ

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。書く時間と応募対応の時間は、媒体で違います。

運用の相談をする

併用するときの分担

両方を使うなら、次の分担が分かりやすいです。

  1. 会社の見せ方はWantedly：会社ページとストーリーを「会社の説明書」として整え、面談や面接の前後に読んでもらう
  2. 条件で応募を集めるのはGreen：求人票に仕事の中身と条件を具体的に書き、合う経験の応募を集める
  3. 求人票からWantedlyへ誘導する：求人票を見た候補者が、会社の日常を読んでから応募できる流れを作る
  4. 選考フローは1本にする：入口が違うだけで、面談以降は同じ流れに乗せる
  5. 書く人を分ける：想いを書く人と、求人票を書く人は、同じ人でなくてよい

求人票で「条件は合う」と思った候補者が、Wantedlyのストーリーで「この会社で働く姿」を読んでから応募する。この流れができると、応募後の「思っていたのと違う」が減ります。

エージェントベストの見解

申し込んだあと、Wantedlyで最初の数ヶ月で運用が止まる会社に共通するのは、「募集記事を1本出して、ストーリーを書かずに待つ」ことです。Wantedlyの募集記事は、求人票のように条件で検索されて応募が来る設計ではありません。会社ページとストーリーに人が来て、そこから募集に入ります。ストーリーがないと、会社ページに来る理由がなく、募集記事だけが置かれた状態になります。当社が契約後の運用まで見ている経験では、Wantedlyで成果が出る会社は、最初の月にストーリーを複数本書き、その後も月に数本の更新を続けた会社です。求人型の感覚で「出して待つ」運用をすると、「Wantedlyは効かなかった」で終わります。申込前に「月に何本、誰が書くか」を決めておくことを勧めます。

まとめ

  • Wantedlyは会社の想いに共感した人が集まる型、Greenは求人票の条件を見て応募する型
  • Wantedlyは「書いて見せる」に、Greenは「求人票を整えて応募に対応する」に時間を使う
  • Wantedlyは通年で育てる運用、Greenは募集ごとに山を作る運用
  • 会社の想いが言葉になっていない会社は、求人型で先に候補者に会い、何が響くかを掴んでからWantedlyへ
  • 併用するなら、会社の見せ方はWantedly、条件で応募を集めるのはGreen。求人票からWantedlyへ誘導する

よくある質問

エンジニアを採るなら、どちらが向いていますか

職種より、「想いで集めるか、条件で集めるか」で決まります。会社の技術への考え方やチームの文化を書いて共感で集めたいならWantedly、使う技術と求める経験を具体的に書いて条件で集めたいなら求人型です。両方を使い、求人票からWantedlyのストーリーへ誘導する形も多いです。

Wantedlyは応募ではなく「話を聞きに行きたい」から始まると聞きました。選考にどうつなげますか

まず会って話すことが入口なので、最初の面談はカジュアルな形で、会社と候補者がお互いを知る場にします。そのうえで、選考に進む意思を確認してから、通常の選考フローに乗せます。面談と選考を分けておくと、候補者も企業も無理なく進めます。

Greenの申込も御社経由でできますか

当社が販売パートナーとして窓口になるのは、OfferBox・Wantedly・ワンキャリアの3媒体です。Greenの申込は各社の窓口になりますが、共感型と求人型を併用するときの分担や、書く人の決め方は、Wantedlyの運用を見ている立場からご相談いただけます。3媒体の全体像は3媒体の違いと選び方にまとめています。
