複数媒体を代理店でまとめる方法｜役割分担、窓口、請求、更新時期を揃える

「新卒と中途で媒体が分かれ、契約も請求も担当者もバラバラになっている」「複数の媒体を1つの窓口でまとめられないか」という相談を受けます。結論から言うと、複数の媒体を扱う代理店なら、その代理店が扱う範囲で、窓口・請求・更新時期・配分の相談をまとめられます。ただし、まとめる前に、媒体ごとの役割分担を社内で決めておかないと、窓口が1つになっても運用は整理されません。 当社はOfferBox・Wantedly・ワンキャリアの3媒体を扱う販売パートナーですが、この記事は当社に限らず、複数媒体を代理店でまとめる一般的な手順と、まとめられる範囲の限界を整理します。

まとめられるものと、まとめられないもの

最初に、代理店でまとめられる範囲を押さえます。

項目まとめられるか条件
申込と相談の窓口まとめられる代理店が扱う媒体の範囲で
請求代理店による代理店と契約する形なら、まとめられることがある
更新時期揃えられることがある契約期間の開始日を合わせる
配分の相談まとめられる全体を見ている代理店なら
運用代行代理店による代行まで行う代理店で、対応する媒体の範囲で
媒体の管理画面まとめられない媒体ごとに別。代理店を挟んでも1つにはならない
扱っていない媒体まとめられないその媒体は別の窓口

「窓口が1つになる」のは、申込・相談・請求・更新の話です。管理画面や候補者とのやり取りは、媒体ごとに残ります。代理店の仕組みは採用媒体の代理店とは、契約と請求の形は代理店経由の契約と請求の流れで書きました。

手順1｜媒体ごとの役割分担を社内で決める

代理店にまとめる前に、社内で「どの媒体に何を任せるか」を決めます。ここが決まっていないと、窓口を1つにしても、代理店は配分の相談ができません。

よくある組み合わせと分担を並べます。

  • 新卒と中途：新卒はOfferBoxやワンキャリアのような新卒専用の媒体、中途は中途向けの媒体。会社の見せ方はWantedlyのような両方を扱える媒体で共通にする。詳しくは新卒媒体と中途媒体の違い
  • スカウト型と掲載型：見つけてもらえない層にはスカウト型で届け、見に来る場所は掲載型で整える。詳しくは掲載型とスカウト型の違い
  • 3媒体：学生への直接アプローチはOfferBox、学生が見に来る場はワンキャリア、会社の見せ方と中途はWantedly。詳しくは3媒体の違いと選び方

分担を決めるときの問いは3つです。この媒体で誰に届けるか、この媒体で何を見せるか、この媒体に誰が時間を使うか。3つが媒体ごとに書けていれば、代理店に渡せます。

新卒と中途で媒体を分けるか、一度整理してみませんか。3媒体の役割から一緒に組み立てます。

媒体選びを相談する

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社が線を引くなら、「どの媒体に何を任せるか」の判断と、「どの媒体に予算と時間を寄せるか」の配分の決定は、社内で持ちます。代理店は、全体を見て「この媒体は動いていて、こちらは止まっている」と伝え、配分の案を出す側です。決めるのは社内です。当社が3媒体すべての販売パートナーとして複数媒体の相談を受けるとき、まとめる前に「3つの問い（誰に届けるか、何を見せるか、誰が時間を使うか）」を媒体ごとに書いてもらいます。書けない媒体があれば、その媒体は役割が決まっていないので、まとめる前に決めるか、いったん外します。役割が決まっていない媒体を窓口だけまとめても、請求が1枚になるだけで、運用は変わりません。窓口をまとめる価値は、役割が決まっている媒体の配分を、全体を見ながら動かせることにあります。

手順2｜窓口を1つにする

役割分担が決まったら、代理店に窓口をまとめます。

  1. 代理店が扱う媒体を確認する：自社が使う媒体のうち、どれをその代理店で扱えるか。扱えない媒体は別の窓口のまま
  2. 申込後の相談の範囲を確認する：媒体ごとに、相談まで受けるか、代行まで行うか。範囲の型は代理店に運用まで頼めるか
  3. 担当者を1人にする：代理店側の担当が媒体ごとに分かれると、全体を見る人がいなくなる。1人が全体を見る形にする
  4. 社内側の窓口も1人にする：社内で媒体ごとに担当が分かれていても、代理店とのやり取りは1人に集める
  5. 定期の打ち合わせを決める：月に一度など、全媒体の状況を並べて見る場を作る

窓口を1つにする意味は、「全媒体を並べて見る場」ができることです。媒体ごとに別々に相談していると、配分の判断ができません。

手順3｜請求と更新時期を揃える

契約の形によって、請求をまとめられるかが変わります。

  • 代理店と契約する形：代理店によっては、複数媒体を1つの請求にまとめられる。締め日と支払日も揃えられる
  • 媒体と直接契約する形：請求は媒体ごと。代理店が申込を取り次いでいても、請求はまとまらない
  • 混在：媒体によって契約の形が違うことがある。まとめられる範囲だけまとめる

更新時期は、契約期間の開始日を合わせると揃います。すでに動いている契約は、次の更新のときに開始日を寄せます。

状況やること
新規で複数媒体を同時に始める開始日を揃える。ただし準備が整う順に始めてもよい
すでに動いている契約がある次の更新で開始日を寄せる。途中で揃えようとしない
定額型と成功報酬型が混ざる定額型の期間を基準にし、成功報酬型は発生ベースで別に見る

更新時期が揃うと、「来年度は3媒体のうちどれを続けるか」を一度に判断できます。バラバラだと、1つずつ更新の判断を迫られ、全体の配分を見直す機会がありません。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。複数媒体なら、時間の配分まで含めてお伝えします。

運用の相談をする

手順4｜配分を定期的に見直す

窓口が1つになり、更新時期が揃ったら、配分の見直しができるようになります。

見直しで見るものを並べます。数字は媒体間で横に比べず、それぞれの媒体の中で前後を比べます。

  1. 動いているか：送信数、更新数、閲覧数が、前月と比べてどうか。止まっている媒体はないか
  2. 役割を果たしているか：新卒の直接アプローチを任せた媒体で、面談が生まれているか。会社の見せ方を任せた媒体で、記事が更新されているか
  3. 時間の配分は合っているか：担当の時間が、役割の重い媒体に寄っているか。止まっている媒体に時間だけ取られていないか
  4. 来期の配分：続ける媒体、減らす媒体、足す媒体。更新時期に合わせて決める

見直しは、代理店との定期の打ち合わせで行います。代理店は全体を並べて見せる側、決めるのは社内です。

エージェントベストの見解

申し込んだあと、複数媒体を代理店でまとめた会社で起きやすいのは、「窓口は1つになったが、更新時期がバラバラで、配分を見直せない」ことです。ある媒体の更新が来月、別の媒体が半年後、という状態だと、「来年度はどう配分するか」を一度に決められず、来た順に「とりあえず更新」を繰り返します。当社が3媒体すべての販売パートナーとして契約後の運用を見ている経験では、配分を見直せている会社は、更新時期を揃えた会社です。揃えるには、次の更新のときに開始日を寄せる、という一度の調整で済みます。窓口をまとめるときに、「更新時期を揃えたい」と代理店に伝えておくことを勧めます。揃った翌年から、「3媒体のうちどれに寄せるか」を毎年一度、全体を見て決められるようになります。

まとめ

  • 代理店でまとめられるのは、申込・相談・請求・更新時期・配分の相談。管理画面と扱っていない媒体はまとまらない
  • まとめる前に、媒体ごとの役割分担（誰に届けるか、何を見せるか、誰が時間を使うか）を社内で決める
  • 窓口は代理店側も社内側も1人にし、全媒体を並べて見る定期の場を作る
  • 請求は代理店と契約する形ならまとめられることがある。更新時期は次の更新で開始日を寄せて揃える
  • 配分の見直しは、更新時期が揃って初めてできる。決めるのは社内、並べて見せるのが代理店

よくある質問

使っている媒体の一部を、その代理店が扱っていません。まとめられますか

扱っている媒体の範囲でまとめ、扱っていない媒体は別の窓口のままになります。それでも、扱っている媒体の配分を全体で見られる利点は残ります。当社の場合、OfferBox・Wantedly・ワンキャリアの3媒体の範囲でまとめられます。

請求を1枚にしたいのですが、できますか

代理店と契約する形で、代理店が複数媒体の請求をまとめられる場合にできます。媒体と直接契約する形だと、請求は媒体ごとです。申込前に、契約の形と請求のまとめ方を代理店に確認してください。

3媒体を同時に始めるべきですか

役割分担が決まっていれば同時に始められますが、担当が1人なら、まず1つを軸にして運用が回ってから足す順番のほうが止まりません。窓口をまとめることと、同時に始めることは別の話です。窓口は最初から1つにし、始める順番は準備が整った媒体からで構いません。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

あわせて読む

  • 代理店経由でキャンペーン情報を得る方法｜適用の条件と、キャンペーンで媒体を決めない理由
  • 代理店の提案が中立かどうかの見分け方｜手数料の出どころと、提案の根拠を見る
  • 代理店を比較するときの軸｜扱う媒体、中立性、申込後の範囲、担当の体制、引き継ぎ
  • 代理店経由の契約と請求の流れ｜契約の相手、請求元、更新と解約を申込前に確認する
