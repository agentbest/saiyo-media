代理店とのやり取りでやりがちな失敗｜条件を出さない、数字で決める、申込後に連絡しない

代理店を使って採用媒体を申し込んだのに、うまくいかなかった。その原因を聞くと、代理店側の問題より、企業側のやり取りの失敗であることが少なくありません。結論から言うと、失敗は「申込前に条件を出さない」「数字やキャンペーンで決める」「申込後に連絡が途切れる」の3つに集約されます。 どれも防げます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、契約後の運用まで見ていますが、この記事は当社との間でも起きる失敗を含めて、企業側がやりがちなものを時期ごとに整理します。

申込前の失敗

申込前の失敗は、比較の質を下げます。

失敗何が起きるか防ぎ方
条件を伝えずに「おすすめは」と聞く一般論が返ってくる。自社向けの提案にならない人数・時期・人物像・時間を1枚に書いて持っていく
登録者数で媒体を決める総数は自社の母集団ではない。契約後に「思ったより会えない」自社の条件で絞った層の説明を求める
キャンペーンで媒体を決める期間が終わると運用が止まる。合わない媒体を安く始めただけ条件で媒体を決めてからキャンペーンを見る
「全部使いましょう」に乗る担当が1人なら手間の重いものから止まる1つを軸にし、回ってから足す
人物像を代理店に決めてもらう面談に来た人と社内の期待がずれる人物像は社内で決める。代理店は聞いて整理する側
申込後の相談の範囲を聞かない申込のみの代理店だと、止まっても誰も気づかない「申込後に何をどのくらいやってくれるか」を聞く

このうち、最初の「条件を伝えない」が、他の失敗の入口になります。条件が無いと、数字やキャンペーンで決めるしかなくなるからです。準備の仕方は代理店に聞くべき質問で書きました。

申込時の失敗

申込時の失敗は、稟議と契約で出ます。

  1. 見積もりの合計だけを見る：媒体の料金と、それ以外の費用が混ざっている。行ごとに分けて見る。見方は代理店経由でも料金が変わらない理由
  2. 契約の相手を確認しない：媒体と直接か、代理店とか。稟議で「なぜ代理店と契約するのか」と聞かれて止まる
  3. 稟議で「誰がやるか」を書かない：承認されたあとに運用する人が決まっていない。運用に必要な時間の見積もりを代理店に頼んで添付する
  4. キャンペーンの期限に合わせて準備を飛ばす：契約期間が動き出しても人物像も文面も無い。準備が整う日と期限を比べる
  5. 更新の方式と解約の期限を確認しない：自動更新で次の期間に入り、「もう1期間分の請求が来た」となる

契約の流れは代理店経由の契約と請求の流れで書きました。

いま使っている媒体の運用の相談だけでも構いません。止まっている原因が、代理店側か自社側かから一緒に見ます。

運用の相談をする

エージェントベストの見解

申し込んだあと、最初の1ヶ月で運用が止まる会社に共通するのは、「申込が終わった時点で、担当者の仕事が終わったと感じる」ことです。申込までは稟議も契約もあって忙しく、承認が下りると一息つく。その間に契約期間が動き出し、管理画面を開かないまま数週間が過ぎます。当社が3媒体すべての販売パートナーとして契約後の運用を見ている経験では、この「申込直後の空白」が、最も多い止まり方です。防ぎ方は1つで、申込の前に「契約開始の翌週にやること」を決めておくことです。人物像の確定、文面の確認、面談の枠、最初の送信日。この4つに日付が入っていれば、申込直後の空白は起きません。当社は申込を受けるときに、この4つの日付を一緒に決めるようにしています。日付が入らない項目があれば、申込を1週間遅らせてでも決めることを勧めます。

申込後の失敗

申込後の失敗は、運用を止めます。代理店との間で最も多いのが、この時期です。

失敗何が起きるか防ぎ方
申込後に連絡が途切れる代理店が状況を知れず、止まっても声をかけられない定期の打ち合わせを月に一度決めておく
文面の確認を後回しにする代理店が下書きしても送れない。送信が始まらない確認の期限を決め、期限内に返す
面談の枠を用意しない承認が溜まり、候補者の温度が下がる承認された候補者と翌週に会える枠を先に決める
面談の結果を代理店に戻さない条件と文面を直せない。同じ層に送り続ける面談のたびに「合った・合わなかった・理由」を戻す
報告を読まない止まっていることに気づかない報告の数字を前月と比べる。止まっていたら聞く
「効かない」と結論を急ぐ最初の数週間で判断し、条件と文面を直す前にやめる最初の見直しを1ヶ月後と決めておく
社内の担当が変わって引き継がれない代理店との関係がゼロに戻る担当交代のときに、代理店を交えて引き継ぎの場を持つ

「面談の結果を戻さない」は見落とされやすい失敗です。代理店は送ることはできても、会った結果は企業しか知りません。結果が戻らないと、代理店は改善できず、企業は「代理店が改善しない」と感じます。この行き違いは、結果を戻す流れを最初に決めておけば起きません。代行の範囲は代理店に運用まで頼めるかで書きました。

更新と切り替えの失敗

契約の終わりにも、失敗が出ます。

  1. 更新の期限を忘れる：自動更新で次の期間に入る。契約時に期限をカレンダーに入れる
  2. 「とりあえず更新」を繰り返す：配分を見直さないまま続ける。更新の前に、動いているか・役割を果たしているかを見る
  3. 成果が出ない理由を代理店の問題と決める：送っていないなら送る人の問題、承認が少ないなら条件と文面の問題。切り替えても変わらない
  4. 切り替えを伝えてから運用データを頼む：文面と条件が手元に残らない。伝える前に書面でもらう
  5. 採用の山の時期に切り替える：引き継ぎの間に運用が止まる。山の前か後に寄せる

切り替えの注意は代理店を切り替えるときの注意で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。契約開始の翌週にやることまで、日付を入れてお伝えします。

媒体選びを相談する

失敗が出やすい時期と、先に決めておくこと

時期ごとに、先に決めておくことをまとめます。

時期先に決めておくこと
申込前人数・時期・人物像・時間の1枚。申込後の相談の範囲
申込時契約の相手、請求、更新と解約の期限。稟議に「誰がやるか」
契約開始の翌週人物像の確定、文面の確認、面談の枠、最初の送信日の4つに日付
最初の1ヶ月月に一度の打ち合わせ。面談の結果を戻す流れ。最初の見直しの日
更新の前動いているか、役割を果たしているか。続ける・減らす・足すの判断

「先に決めておく」が全部に共通しています。決まっていれば、代理店は動けます。決まっていなければ、代理店が何をしても止まります。

エージェントベストの見解

自社で持つべきなのは、どこまでか。代理店との失敗の多くは、この線が曖昧なことから起きます。当社が線を引くなら、「人物像を決める」「文面の共通部分を確認する」「面談する」「面談の結果を戻す」の4つは、代理店に何を頼んでいても社内が持ちます。この4つが社内で回っていれば、送る作業を代理店に出しても、自社で送っていても、運用は止まりません。逆に、この4つのどれかを代理店に任せようとすると、面談に来た人がずれる、送れない、承認が溜まる、改善できない、のどれかが起きます。「代理店に頼んだのに」と感じたときは、この4つのうちどれが社内で止まっているかを先に見ることを勧めます。多くの場合、代理店の問題ではなく、この4つのどれかです。

まとめ

  • 失敗は「条件を出さない」「数字やキャンペーンで決める」「申込後に連絡が途切れる」の3つに集約される
  • 申込前は条件の1枚を用意し、申込時は契約の形と「誰がやるか」を決め、契約開始の翌週にやることに日付を入れる
  • 申込後は、面談の枠を用意し、面談の結果を代理店に戻し、報告を前月と比べる
  • 更新の期限をカレンダーに入れ、「とりあえず更新」を繰り返さない
  • 人物像・文面の確認・面談・結果を戻す、の4つは代理店に何を頼んでいても社内が持つ

よくある質問

代理店に頼んでいるのに成果が出ません。代理店の問題ですか

先に、送信数・承認数・面談数が月ごとにどう動いているかを見てください。送っていないなら送る人の問題、送っているのに承認が少ないなら条件と文面の問題、承認はあるのに面談に進まないなら面談の枠の問題です。代理店の問題は、相談を受けてもらえない、報告が来ない、担当が引き継がれない、といった形で出ます。

申込後、代理店とどのくらいの頻度で連絡を取ればいいですか

月に一度の定期の打ち合わせを決めておくと、連絡が途切れません。加えて、面談のたびに結果を戻す流れがあると、条件と文面の改善が続きます。運用代行を頼んでいる場合は、週次の報告を受け取る形が一般的です。

担当者が変わります。代理店にどう伝えればいいですか

交代の前に、新旧の担当者と代理店を交えた引き継ぎの場を持つことを勧めます。人物像、文面、面談の枠、報告の流れ、更新の期限を、その場で確認します。代理店側が状況を全部持っているので、社内の引き継ぎ資料としても使えます。3媒体の全体像は3媒体の違いと選び方にまとめています。
