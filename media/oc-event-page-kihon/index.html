ワンキャリアでは、企業ページに加えて、説明会や座談会などのイベントを掲載できます。ところが、イベントページは「会社説明会」「〇〇セミナー」という名前と日時だけで、何が話され、誰が出て、来た学生が何を得るのかが書かれていないことが多くあります。結論から言うと、ワンキャリアのイベントページは、「誰が、何を話し、来た学生が何を持ち帰るか」が読める形で作ります。ワンキャリアの学生は、体験談とクチコミを読んでからイベントを探すので、イベントページは「体験談で気になったことを、会社の人に直接確かめられる場」として書きます。「会社説明会」の一言、会社紹介が中心、選考との関係が曖昧、話す人が不明、が学生の来ない形です。 この記事では、ワンキャリアの学生のイベントの探し方、書く要素、やりがちな失敗、イベントの型ごとの書き方、時期の扱い、終わったあとの動き、分担を整理します。イベントページの項目や掲載の条件は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。イベントと掲載の一般的な違いはイベントと媒体掲載の違いで書きました。

この作業の目的｜体験談で気になったことを、直接確かめられる場だと分かるようにする

ワンキャリアの学生は、イベントを探す前に、その会社の体験談とクチコミを読んでいます。「選考で何を見ているのか」「仕事の実態はどうか」「面接官はどんな人か」。体験談で読んだうえで、まだ分からないことを持っています。

イベントページの目的は、「その分からないことを、会社の人に直接聞ける場だ」と、ページを読んだ時点で分かることです。「会社説明会」の一言では、何が聞けるか分からず、体験談を読んだ学生は来ません。

書く要素

要素書き方
誰が話すか職種と年次。「入社二年目の〇〇職」「〇〇部門の責任者」。人事だけなら、その旨。名前を出せるなら出す
何を話すか「会社の説明」ではなく、話す場面。「最初の1年に何をするか」「選考の各段階で何を見ているか」「〇〇の案件で、どう進めたか」
来た学生が何を持ち帰るか「選考で何を見ているかが分かる」「この職種の最初の1年が想像できる」「体験談で気になったことを直接聞ける」
形式と時間対面かオンラインか、時間の長さ、話す時間と質問の時間の配分
選考との関係あるか、無いか。あるならどういう形か。年度の公表内容と自社の方針を確認して書く。曖昧にしない
持ち物と準備要るなら。「事前に企業ページの〇〇を読んでおくと、質問しやすい」
対象どの学生に来てほしいか。学年、職種の興味。決めつけずに

「誰が話すか」と「何を話すか」が、要素の中心です。この二つがあると、学生は「体験談で読んだ〇〇のことを、この人に聞ける」と分かります。

やりがちな失敗

失敗学生からどう見えるか
「会社説明会」の一言と日時だけ何が聞けるか分からない。体験談のほうが詳しい
内容が会社紹介（沿革、事業、規模）企業ページとコーポレートサイトで読める
選考との関係が曖昧「行くと選考に入るのか」で迷う
話す人が書いていない「人事の説明を聞くだけでは」
「ぜひご参加ください」「先着順」の煽り中身が無い
質問の時間が無い、または短い確かめに行けない
何を持ち帰れるかが無い行く理由が無い
体験談で書かれていることに触れない「体験談を読んでいない会社」

最も多いのは、最初の「一言と日時だけ」です。イベントページを「告知」として書き、「内容」を書いていない形です。

いま使っている媒体の運用の相談だけでも構いません。いまのイベントページを、「誰が・何を・何を持ち帰るか」の形に一緒に直します。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「イベントページは告知なので、日時と場所が分かれば足りる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのイベントの掲載を支えていますが、日時と場所だけのイベントページに来る学生は、体験談を読んでいない学生か、とりあえず申し込む学生で、来ても質問が無く、終わったあとに進みません。体験談を読んだ学生は、「この人にこれを聞きたい」と分かるイベントページにだけ申し込みます。当社がイベントページを整えるとき、最初にやるのは、「誰が話すか」と「何を話すか」を、告知の下ではなく、最初に置くことです。日時は、その次で足ります。イベントページは告知ではなく、内容の予告です。

イベントの型ごとの書き方

型「何を話すか」の書き方「誰が話すか」
会社・仕事の説明会「〇〇職の最初の1年に何をするか」「選考の各段階で何を見ているか」。会社紹介は短くその職種の人と人事
座談会「入社してまもない社員に、入る前と後で違ったことを聞ける」。質問の時間が中心入社してまもない社員が複数
職種別セミナー「〇〇職の仕事の場面を一つ、実際の案件で話す」その職種の人
インターンの説明「インターンで何を任せ、誰が見て、終わったら何が残るか」。インターン募集記事と揃える。書き方はインターン募集記事の書き方の考え方と同じインターンの担当と、過去の参加者
選考の説明「各段階で、誰と何を話し、何を見ているか」。体験談で「分からなかった」と書かれたことに答える面接に出る人と人事
少人数の相談会「体験談で気になったことを、一つずつ聞ける」。質問中心人事と、その職種の人

どの型でも、「話す時間より、質問の時間を長く」を書きます。体験談を読んだ学生は、聞きたいことを持って来ます。少人数の場の企画はミートアップの企画の立て方で書いた考え方と同じです。

選考との関係の書き方

イベントと選考の関係は、学生が最も気にする点です。

  • 年度の公表内容と、自社の方針を確認してから書く：広報と選考の扱いは年度で変わる。この記事では具体は書かない
  • 曖昧にしない：「関係あり」なら、どういう形か。「関係なし」なら、その旨を
  • 「関係なし」と書いたら、守る：イベントの参加で選考の扱いを変えない
  • 企業ページの「選考の流れ」と揃える：イベントページだけ違うことを書かない

「書いたら守る」は、企業ページの選考の流れと同じ原則です。イベントの体験談にも、「関係なしと書いてあったのに」と書かれます。

時期と、掲載のタイミング

  • イベントの時期は、年度の公表内容と自社の方針を確認して決める：この記事では書かない
  • 掲載は、学生が申し込みを判断できる余裕を持って：直前の掲載は、体験談を読んでから判断する学生に届かない
  • 同じ型のイベントを複数回開くなら、それぞれのページに「誰が話すか」を書く：回ごとに話す人が違えば、学生は選べる
  • 企業ページから、イベントページへ誘導する：企業ページの「選考の流れ」や「よく聞かれること」の近くに

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。イベントページの作成と、当日の準備に要る時間を、型ごとにお伝えします。

媒体選びを相談する

終わったあとの動き

イベントページに書いたことは、当日と、そのあとに続きます。

  1. 当日、ページに書いた人が出て、書いた話をする：「誰が」「何を」を守る
  2. 質問の時間を、書いたとおりに取る
  3. 来た学生に、翌日までに一言：「昨日はありがとうございました。〇〇の質問、△△が喜んでいました。次の案内は……」
  4. 出た質問を、企業ページの「よく聞かれること」に足す：イベントは、企業ページの材料が集まる場。更新の起点は企業ページを更新し続ける方法
  5. イベントの体験談が書かれたら、読む：「ページと違った」があれば、次のページか当日の進め方を直す
  6. 次回を決める：一度で止めない。同じ型を、話す人を変えて

「出た質問を企業ページに足す」が、イベントの副産物です。学生が実際に聞いたことは、企業ページに足りなかったことです。

エージェントベストの見解

これは、向く会社と向かない会社がはっきり分かれます。ワンキャリアのイベントが機能するのは、「体験談で書かれたことに、直接答えられる人が出られる会社」です。当社が3媒体の販売パートナーとして相談を受ける中で、「イベントは人事が会社説明をする場」と考えている会社がありますが、体験談を読んだ学生は、会社説明を聞きに来るのではなく、体験談で分からなかったことを確かめに来ます。人事だけが出て会社説明をするイベントは、学生の「確かめたいこと」に答えられず、終わったあとに進みません。当社がイベントを勧める前に確かめるのは、「その職種の人か、面接に出る人が、イベントに出られるか」です。出られるなら、イベントページに「誰が話すか」を書けます。出られないなら、イベントより先に、企業ページの「よく聞かれること」を整えるほうが、学生の確かめたいことに応えられます。

まとめ

  • ワンキャリアの学生は体験談を読んでからイベントを探す。イベントページは「体験談で気になったことを、直接確かめられる場」として書く
  • 書く要素は、誰が話すか、何を話すか、来た学生が何を持ち帰るか、形式と時間、選考との関係、持ち物と準備、対象
  • 「会社説明会」の一言と日時だけ、会社紹介が中心、選考との関係が曖昧、話す人が不明、が学生の来ない形
  • 型（説明会・座談会・職種別・インターン説明・選考の説明・相談会）ごとに「何を話すか」を場面で書き、質問の時間を長く取る
  • 選考との関係は年度の公表内容と自社の方針を確認し、曖昧にせず、書いたら守る。終わったあとに翌日の一言、出た質問を企業ページに足す、体験談を読む、次回を決める

よくある質問

話す人を、まだ決められません

決めてから掲載します。「誰が話すか」が無いイベントページは、体験談を読んだ学生には届きません。話す人が確保できないなら、イベントより先に、企業ページの「よく聞かれること」を整えます。人事だけが出るなら、その旨を書き、「何を話すか」を選考の流れと何を見るかに絞ります。

イベントに来た学生が、質問をしません

イベントページに「何を話すか」が無いと、学生は聞きたいことを持たずに来ます。ページで「〇〇について話します。体験談で気になったことを聞いてください」と予告し、当日は人事が最初の質問を出して口火を切ります。それでも出ないなら、話す時間が長すぎて、質問の時間が短い可能性があります。

ワンキャリアのイベントページの作成は、御社に相談できますか

できます。当社は、イベントページの要素の型、型ごとの書き方、選考との関係の書き方の整理、終わったあとの動きの型を支えられます。話す人の確保、選考との関係の判断、当日の運営、学生への連絡は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
