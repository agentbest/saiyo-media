内定者をワンキャリアの運用に巻き込む｜頼めることと頼まないこと

内定者に、次の年の採用を手伝ってもらいたい。座談会に出てもらう、企業ページの言葉を見てもらう、選考を受けた感想を聞く。ワンキャリアの運用では、内定者の声は学生にとって身近で、届きやすいものです。結論から言うと、内定者を巻き込むときは、「内定者にしか語れないこと」だけを頼み、作業や判断は社内に残すことが要点です。 内定者はまだ社員ではなく、学業も残っています。頼み方を誤ると、内定者の負担になり、入社前の気持ちにも響きます。この記事では、頼む目的、手順、やりがちな失敗、頼まないこと、社内の分担を整理します。

この作業の目的｜選考を受けた側の言葉を、次の学生に渡す

ワンキャリアの学生は、他の学生が書いた選考体験談やクチコミを読んで会社を確かめます。内定者は、つい最近その選考を受けた当事者です。だから内定者の言葉は、体験談に近い温度で学生に届きます。

内定者にしか語れないことの例は次のとおりです。

  • 選考のどの段階で、何を聞かれ、どう感じたか
  • 他社と比べて、なぜこの会社に決めたか
  • 選考の前に知りたかったのに、知るのが遅れたこと
  • 企業ページを読んだとき、分かりにくかった言葉

これらは、人事や社員が書くと会社側の説明になります。内定者が語ると、学生の側の言葉になります。目的は、この「学生の側の言葉」を、次の年の運用に生かすことです。

もう一つの目的は、内定者自身にとっての意味です。自分の選考を振り返り、次の学生に話すことで、なぜこの会社に決めたかを言葉にし直す機会になります。入社までの時間が長い新卒採用では、内定者が会社との関わりを持ち続けること自体が、入社前の不安を和らげることにつながる場合があります。ただし、それは頼み方が内定者の負担になっていないことが前提です。負担が重ければ、逆に気持ちが離れる原因になります。

巻き込む手順

  1. 頼む内容を一つか二つに絞る：座談会への参加、企業ページの読み合わせ、選考の振り返りのどれにするかを決めます。全部を頼まないことが続けるこつです
  2. 任意であることを最初に伝える：断っても内定や入社後の扱いに関係しないことを、人事の口から明確に伝えます
  3. 時間と場所を内定者に合わせる：学業や卒業研究の予定を先に聞き、無理のない日程にします。オンラインで短く済む形も用意します
  4. 話してほしいことを一枚にする：選考で感じたこと、決めた理由など、話す範囲を示します。言ってはいけないことも書きます
  5. 当日は社員が同席する：内定者だけに任せず、答えにくい質問は社員が引き取ります
  6. 終わったらお礼と、どう生かしたかを伝える：企業ページのどこを直したか、座談会で学生から何を聞かれたかを共有します

座談会の企画の順番はワンキャリアの座談会の企画の立て方にまとめています。

内定者に何を頼み、何を社内に残すか。運用の分け方から一緒に整理します。

運用の相談をする

エージェントベストの見解

相談で多い思い込みは、「内定者に任せれば、学生に近い言葉で自然に広報ができる」というものです。当社は申込のあとの運用まで見ていますが、内定者に投稿や広報の作業まで任せた会社では、内定者が会社の代弁者のように振る舞い、かえって学生に構えられることがあります。内定者の言葉が届くのは、会社の説明をするときではなく、自分の選考の体験を話すときです。そこで勧めているのは、内定者には「選考を受けてどうだったか」だけを話してもらい、会社の制度や事業の説明は社員が持つ形です。もう一つ効くのが、企業ページの読み合わせです。内定者に企業ページを読んでもらい、「選考を受ける前に、ここが分かりにくかった」と言ってもらう。その一言は、次の年の企業ページを直す材料になります。内定者の時間は、語ることと気づきを返すことに使ってもらうのがよい配分です。

やりがちな失敗

  • 頼む内容が増え続ける：座談会、SNSの投稿、説明会の運営と広がり、内定者の負担になる
  • 断りにくい頼み方をする：内定を出した直後に頼み、事実上断れない形になる
  • 台本を渡して読ませる：内定者の言葉が会社の言葉になり、学生に届かない
  • 内定者だけで学生と話させる：答えにくい質問を受け止められず、誤った説明が体験談に残る
  • 入社前の不安を聞かずに頼む：内定者自身が迷っているときに広報を頼むと、気持ちが離れることがあります

内定者の気持ちを先に聞く場は、内定者フォローの一部です。内定のあとの辞退の考え方はワンキャリア経由の内定辞退も参考になります。

頼まないこと

内定者に頼まないほうがよいことも決めておきます。

  • 会社の制度や条件の説明：内定者はまだ社員ではないので、正確に答えられないことがあります
  • 選考の合否に関わる判断：学生の評価を内定者に聞かない
  • 学生の個人情報の扱い：学生の連絡先やプロフィールを内定者に渡さない
  • 体験談やクチコミへの投稿のお願い：書くかどうかは本人の自由で、会社が頼む性質のものではありません

また、内定者に作業を頼み、謝礼や交通費を出す場合や、まとまった時間を使ってもらう場合は、扱いによって法令で定められた項目に関わることがあります。形を決める前に、社労士や公式の案内で確認してください。

社内の分担

作業誰が

エージェントベストの見解

これは順番の話です。内定者を巻き込む前に、先に決めておくべきなのは「内定者の入社までの予定」です。内定式、研修、学業の山場がいつかを把握しないまま頼むと、内定者が一番忙しい時期に座談会が重なります。当社が勧める順番は、まず内定者フォローの予定を一枚にまとめ、そこに空いている時期を見つけ、その時期にだけ一つの依頼を置くことです。次の年の採用の山と、内定者が動ける時期は、ずれることが多いものです。ずれる場合は、内定者に当日出てもらうのではなく、事前に企業ページの読み合わせだけをしてもらい、その気づきを社員が座談会で使う形も選べます。内定者の負担を減らすことが、入社まで気持ちが続くことにもつながります。

内定者フォローと次の年の採用の予定を、一枚で並べて整理するところから相談できます。

無料で相談する

まとめ

  • 内定者には、選考を受けた側の言葉など、内定者にしか語れないことだけを頼む
  • 任意であることを最初に伝え、頼む内容は一つか二つに絞る
  • 当日は社員が同席し、制度の説明や答えにくい質問は社員が持つ
  • 学生の個人情報や合否の判断、体験談への投稿のお願いは頼まない
  • 謝礼や時間の扱いは、法令で定められた項目がないか社労士や公式の案内で確認する

よくある質問

内定者に座談会へ出てもらうのは、何人くらいがよいですか

決まった人数はありません。学生が聞きたい内容に合わせて、文系・理系や志望職種の違う内定者に一人ずつ出てもらう形が考えられます。人数を増やすより、一人ひとりが話しやすい場にすることを優先します。

内定者から、選考への厳しい意見が出ました

貴重な材料です。企業ページや選考の流れで直せる点がないかを確かめます。直した点は、内定者に「この意見を受けて、ここを変えました」と伝えると、意見を出した側の納得にもつながります。

内定者の声を企業ページに載せたいです

本人の了解をとり、名前や大学名など個人が特定される情報を載せるかどうかも本人と決めます。載せる言葉は本人に確認してもらい、会社が言い換えすぎないようにします。企業ページの書き方はワンキャリアの企業ページで最初に書くことにまとめています。
