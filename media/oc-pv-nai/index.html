ワンキャリアに掲載したが、企業ページが見られない。閲覧の動きが小さいまま。「上に表示されていないからだ」と考えて、表示の仕組みを調べ始める。結論から言うと、表示や並び順の仕組みを推測して直しません。学生が自社にたどり着く動きは四つあり、体験談やクチコミを読んで社名で、職種や条件の絞り込みから、イベントの一覧から、友人や先輩の話から。このどこが弱いかで見ます。体験談が少ない会社は、体験談が書かれる選考から始めます。順位を目標にせず、月に一か所ずつ直します。 この記事では、仕組みを推測すると起きること、四つの動き、動きごとのサインと直し方、体験談が少ない場合、順位を目標にしないこと、月に一か所、分担を整理します。表示の考え方はワンキャリアで上位に表示されるための考え方、見られたが来ない場合はワンキャリアでエントリーが来ないときの見直し順で書きました。この記事は、「見られない」という症状から逆に辿るものです。

この作業の目的｜「探している学生」が、自社にたどり着ける状態にする

ワンキャリアの学生は、自社を「見つけに来る」のではなく、体験談・絞り込み・イベント・人の話のどれかから「たどり着く」動きをしています。見られないのは、どの動きからもたどり着けない状態です。

目的は、表示の順位を上げることではなく、四つの動きのそれぞれで、自社にたどり着ける入口を作ることです。

表示の仕組みを推測して直すと、起きること

  • 「更新すれば上に出る」「イベントを増やせば上に出る」は、推測：公表されている範囲で確認し、それ以外は仕組みへの対策として直さない
  • 推測で直すと、企業ページの中身が変わらない：仕組みが変わると、効かなくなる
  • 順位を目標にすると、「上に出たのに来ない」で終わる：順位は、来る理由にならない
  • 現在の仕様は、管理画面とヘルプで確認する
  • 直すのは、学生が自社にたどり着く動きの側

推測しない理由の詳しくはワンキャリアで上位に表示されるための考え方の「仕組みを推測して動かそうとしない理由」で書きました。

学生が自社にたどり着く、四つの動き

動き学生がすること弱いときのサイン
1. 体験談から体験談やクチコミを読んで、社名で調べる自社の体験談が少ない、または古い
2. 絞り込みから職種・勤務地・業界で絞って一覧を見る絞り込みの項目が埋まっていない。職種の名前が学生の呼び方と違う
3. イベントから参加できるイベントを探すイベントが途切れている。タイトルに「誰が・何を」がない
4. 人から友人や先輩に名前を聞いて調べる選考を受けた学生が、周りに話したくならない選考

どの動きも、最後は企業ページにたどり着きます。四つのうち、自社が弱い動きを一つ指します。

いま使っている媒体の運用の相談だけでも構いません。学生が自社にたどり着く四つの動きのうち、どこが弱いかを一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「掲載が見られないのは、ワンキャリアの表示の仕組みで上に出ていないからだ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、表示の仕組みは公表されている範囲でしか分からず、推測で直すと、直す場所が「仕組みへの対策」になり、学生がたどり着く動きの側が変わりません。見られていない会社の多くは、体験談が少なく、絞り込みの項目が空欄で、イベントが一度きりで、企業ページが薄い、という状態で、この状態では、どの動きからもたどり着けません。当社が「見られない」の相談を受けるとき、最初にやるのは、表示の仕組みの話ではなく、四つの動きを一つずつ確かめることです。現在の表示の仕様は、管理画面とヘルプで確認します。

動きごとの、直し方

1. 体験談が少ないとき

  • 体験談は、自社が書くものではなく、学生が書くもの：増やすには、体験談が書かれる選考にする
  • 書かれる選考とは：連絡が速い、面接で何を見るかが伝わる、結果の連絡が丁寧、落ちた学生にも一言ある
  • 選考を受けた学生に、書くことを頼まない：頼まれて書いた体験談は、読む学生に分かる
  • 体験談が書かれ始めるまで、時間がかかる：翌年の体験談に残る選考を、今年する
  • 体験談の読み方と、選考への反映はワンキャリアの学生目線

2. 絞り込みの項目が埋まっていないとき

  • 管理画面で、埋めていない項目を全部埋める：勤務地、職種、業界、募集の形。空欄は、絞り込みで出ない
  • 職種の名前を、学生の呼び方に揃える：社内の呼び方（「ソリューション営業」）ではなく、学生が絞る名前（「営業」）
  • コースの名前も同じ：ワンキャリアの募集コースの分け方
  • 埋め方はワンキャリアで上位に表示されるための考え方の「埋めていない項目を、埋める」

3. イベントが途切れているとき

  • イベントを、一度きりにしない：小さくても、続ける。説明会、座談会、オンラインの短い会
  • タイトルに「誰が・何を」を出す：「会社説明会」ではなく「〇〇職の若手と話す会」。ワンキャリアのイベントページのタイトル
  • イベントページから企業ページへ、企業ページからイベントへ、つなぐ：ワンキャリアのイベントページと企業トップ
  • イベントの続け方はワンキャリアの説明会の掲載

4. 人の話からたどり着かないとき

  • 選考を受けた学生が、周りに話したくなる選考か：「面接官が自分の話を聞いてくれた」「落ちたが丁寧だった」
  • 内定者が、後輩に話したくなる会社か：内定者の活かし方
  • これは、体験談と同じ元：書かれる選考は、話される選考
  • 選考の設計はワンキャリアの本選考の掲載

体験談が少ない会社は、「書かれる選考」から

  • 体験談は、掲載を直しても増えない：選考を直すと、翌年に増える
  • 今年できること：連絡の速さ、面接で見ることを伝える、結果の連絡の丁寧さ、を今年の選考で守る
  • 今年の間は、絞り込みとイベントとスカウトで、たどり着く入口を作る：体験談が増えるまでのつなぎ
  • スカウトで届ける：体験談が少ない会社ほど、学生が自分でたどり着かない。ワンキャリアのスカウトの基本
  • 翌年、体験談が増えたら、企業ページを体験談と揃える

「見られない」の根本が「体験談が少ない」なら、直すのは掲載ではなく選考で、効くのは翌年です。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。体験談が増えるまでの間に、絞り込みとイベントとスカウトで入口を作る時間をお伝えします。

媒体選びを相談する

順位を、目標にしない

  • 順位が上がっても、企業ページが薄ければ来ない
  • 順位を追うと、更新やイベントが「順位のため」になり、学生に向いた中身にならない
  • 見るのは、四つの動きごとに、たどり着いた学生が企業ページで確かめられたか
  • 順位を目標にしない理由はワンキャリアで上位に表示されるための考え方の「順位を目標にしない理由」

月に一か所ずつ

  • 四つの動きのうち、弱い一つを直す
  • 一か月、閲覧の動きを見る：数字の大小ではなく、変化
  • 変われば、次の動きへ。変わらなければ、その一か所を見直して次へ
  • 記録を残す：「〇月、絞り込みの項目を埋めた。閲覧の動き：△△」

イベントを途切れさせず、タイトルに「誰が・何を」人事と現場
選考を「書かれる選考」にする面接官と人事

月に一か所直し、記録する人事

運用代行や代理店が支えられるのは、四つの動きの切り分け、絞り込みの項目の埋め方、イベントのタイトルの型、「書かれる選考」の条件の整理、スカウトの型までで、選考そのもの、イベントに出ること、送ることは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは順番の話です。当社がワンキャリアで「見られない」の相談を受けたとき、企業ページの書き直しから始めません。先に、四つの動きのどこが弱いかを見て、絞り込みの項目とイベントは今月直せるので先に直し、体験談は「書かれる選考」を今年して翌年に効かせる、と分けます。逆に、企業ページを先に直すと、たどり着く入口がないままで、直した企業ページが見られません。当社が勧める順番は、絞り込みの項目を埋める、イベントを続ける、スカウトで届ける、選考を書かれる形にする、翌年に体験談と企業ページを揃える、です。今年効くものと、翌年効くものを分けることが、この媒体の運用の要点です。

まとめ

  • 表示や並び順の仕組みを推測して直さない。現在の仕様は管理画面とヘルプで確認し、直すのは学生がたどり着く動きの側
  • 学生がたどり着く動きは、体験談から・絞り込みから・イベントから・人から、の四つ。弱い一つを指す
  • 体験談が少ないなら、「書かれる選考」（連絡が速い・見ることが伝わる・結果が丁寧）を今年して、翌年に効かせる。頼んで書かせない
  • 絞り込みの項目を全部埋め、職種とコースの名前を学生の呼び方に。イベントを途切れさせず、タイトルに「誰が・何を」
  • 順位を目標にせず、体験談が増えるまではスカウトで届け、月に一か所ずつ直して記録する

よくある質問

体験談がゼロで、学生が調べても何も出ません

体験談は今年の選考で作るものなので、今年はゼロのまま始めます。今年たどり着く入口は、絞り込みの項目とイベントとスカウトです。特にスカウトは、体験談がなくても学生に届きます。今年の選考を「書かれる選考」にすれば、翌年に体験談が出始め、翌年の入口が増えます。

職種の名前を学生の呼び方に変えると、社内で通じません

企業ページの本文では社内の呼び方を使ってよく、絞り込みの項目と募集コースの名前だけを学生の呼び方にします。「絞り込みで出るための名前」と「社内の正式名」を分けて、本文に「社内では〇〇と呼んでいます」と添えれば、両方が成立します。

掲載が見られないときの見直しは、御社に相談できますか

できます。当社は、四つの動きの切り分け、絞り込みの項目の埋め方、イベントのタイトルの型、「書かれる選考」の条件の整理、スカウトの型を支えられます。選考そのもの、イベントに出ること、送ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
