長期インターン生に任せる仕事がないときの切り出し方

「長期インターンを受け入れたいが、学生に任せる仕事が思いつかない」「受け入れたものの、数週間で任せる仕事が尽きてしまった」。どちらもよく聞く悩みです。結論として、任せる仕事がないと感じるときは、仕事が本当にないのではなく、社員の仕事の中に埋もれていて見えていないことがほとんどで、業務を書き出して「学生に向く条件」で選ぶと切り出せます。 頭の中で考えているうちは、社員の仕事を丸ごと渡すか、雑用を渡すかの二択になりがちです。この記事では、症状の確認、原因の切り分け、切り出しの手順、外に頼める範囲を整理します。

症状を確認する｜「ない」のはどの段階か

任せる仕事がないという悩みは、二つの段階に分かれます。

  • 受け入れる前に、任せる仕事が思いつかない
  • 受け入れた後に、任せる仕事が尽きてしまう

前者は、業務の棚卸しができていない状態です。後者は、最初に任せた仕事が終わったあと、次の仕事を用意する仕組みがない状態です。どちらに当たるかで、取りかかる場所が違います。

原因を切り分ける

任せる仕事が見つからない原因は、次の3つに分けられます。

1. 業務が書き出されていない

社員が日々している仕事は、本人の頭の中にあり、書き出されていないことが多いです。書き出されていない仕事は、誰かに渡せる形になっていません。

2. 仕事を「丸ごと」で考えている

「営業」「マーケティング」といった単位で考えると、学生には任せられないように見えます。営業の中にも、顧客の調査、リストの整理、資料の下書き、商談の記録など、細かい作業があります。仕事を細かく分けて考えていないと、切り出せる部分が見えません。

3. 「社員でないとできない」という思い込み

社員が慣れでこなしている作業の中には、手順さえあれば学生にも任せられるものが多くあります。「説明するより自分でやったほうが早い」という感覚が、切り出しを止めていることもあります。

社員の業務を書き出すところから、学生に任せられる仕事を一緒に探します。募集に書ける形まで整理できます。

無料で相談する

切り出しの手順

手順1：社員の業務を書き出す

受け入れを考えている部署の社員に、1週間の仕事を書き出してもらいます。大きな仕事だけでなく、その中の細かい作業まで書いてもらうのがポイントです。

手順2：学生に向く条件で選ぶ

書き出した作業の中から、次の条件に当てはまるものを選びます。

  • 手順が説明できる：やり方を言葉や見本で伝えられる
  • 止まっても致命的でない：学生の都合で数日止まっても、事業に大きな影響がない
  • 結果が確かめられる：仕上がりが良いか悪いかを、社員が判断できる
  • 後回しになっている：社員が「やりたいが手が回っていない」と感じている

最後の条件が特に大切です。社員が後回しにしている仕事を任せると、受け入れる側にとって助けになり、学生にとっても「必要とされている」実感につながります。

手順3：仕事を段階に分ける

選んだ作業を、難しさで段階に分けます。最初は手順どおりに進められる作業から始め、慣れたら判断が入る作業、さらに目的だけを伝えて任せる作業へと広げていきます。

手順4：仕事の一覧を作る

切り出した作業を一覧にし、インターン生も見られる場所に置きます。手が空いたときに一覧から次の仕事を選べるようにしておくと、仕事が尽きる事態を防げます。

エージェントベストの見解

任せる仕事がないという相談を受けたとき、当社が最初に聞くのは「社員の方が、最近『誰かやってくれないかな』と思った作業は何ですか」という質問です。この質問をすると、たいてい複数の答えが出てきます。過去の顧客の情報が整理されていない、営業資料が古いまま、社内の手順書がない、SNSの更新が止まっている。どれも、社員が重要だと分かっていながら手が回っていない仕事です。こうした仕事は、緊急ではない分、学生が自分のペースで取り組めます。そして、終わったときに社員から感謝されやすい仕事でもあります。仕事を探すときは「学生に何ができるか」ではなく「社員が何を後回しにしているか」から考えると、見つかる仕事の質が変わります。

切り出した仕事の渡し方と広げ方

切り出した仕事を渡すときは、次の点を伝えます。

  1. 作業の目的：なぜこの作業が必要で、結果が誰に何に使われるか
  2. 終わりの形：どんな状態になったら完成か
  3. 見本：過去の例や、完成形の見本
  4. 相談先：迷ったときに誰に聞けばいいか

仕事を広げるときは、インターン生自身に「この仕事の次に、何ができそうか」を聞いてみるのも一つです。仕事をしているうちに、学生の側が改善点や関連する作業に気づいていることがあります。本人の提案から仕事を広げると、任される範囲が広がった実感も持ちやすくなります。

外に頼める範囲

業務の棚卸しや切り出しを、外部と一緒に進めることもできます。

外部と一緒に進めやすいこと

  • 切り出した仕事を、募集の文面に書ける形に整える
  • 学生の目線から見て、魅力の伝わる仕事の書き方を考える

自社で持つこと

  • 社員の業務の書き出しと、任せる仕事の選択
  • 日々の仕事の割り振りと確認

エージェントベストの見解

当社はInfraの代理店として求人原稿を作るとき、任せる仕事の書き方に最も時間をかけます。切り出した仕事を募集に書くとき、「資料作成」「リサーチ業務」とだけ書くと、学生には仕事の中身が想像できません。同じ仕事でも「代表が来月の商談で使う、業界の動向をまとめた資料をつくる」と書けば、何のために、誰と、どんな仕事をするかが伝わります。仕事の切り出しと原稿の書き方は、別々の作業に見えて実はつながっています。切り出した仕事を、目的と相手が分かる一文で書けるかどうか。書けない場合は、まだ切り出しが粗い段階です。募集の文面を書くことが、切り出しの確認にもなります。

部署をまたいで仕事を集めるときの注意

一つの部署で任せる仕事が足りない場合、他の部署から仕事を集めることも考えられます。ただし、部署をまたいで仕事を集めるときは、次の点に注意します。

  1. 仕事の依頼は指導役を通す：他の部署の社員が直接インターン生に頼む形にすると、仕事の量と優先順位が管理できなくなる
  2. 優先順位を指導役が決める：複数の部署から仕事が来たとき、どれを先に進めるかを本人に判断させない
  3. 依頼する部署にも確認の役割を持ってもらう：仕上がりの確認は、仕事を頼んだ部署の社員が行う
  4. 仕事の一覧に依頼元を書く：誰の仕事をしているのかを、本人も周りも分かるようにする

部署をまたぐと、インターン生は社内の多くの人と関われる一方、誰の指示を優先すればいいかで迷いやすくなります。窓口を一つにしておくことで、仕事の幅を広げながら、本人の混乱を防げます。

部署をまたいだ仕事の集め方と、募集での見せ方をあわせてご相談いただけます。

運用の相談をする

まとめ

  • 任せる仕事は、社員の仕事の中に埋もれていて見えていないことがほとんど
  • 社員の業務を細かい作業まで書き出し、学生に向く条件で選ぶ
  • 「社員が後回しにしている仕事」から探すと、助けになる仕事が見つかる
  • 仕事の一覧を作り、インターン生が次の仕事を選べるようにする
  • 切り出した仕事を、目的と相手が分かる一文で書けるかで切り出しの粗さを確かめる

よくある質問

雑用ばかり任せることになりそうで心配です

雑用に見える作業でも、目的と結果の使われ方を伝えれば、学生にとって意味のある仕事になります。ただし、同じ作業ばかりが続くと成長の実感がなくなるため、段階的に判断が入る仕事へ広げていくことが大切です。

機密情報が多く、任せられる仕事が限られます

機密情報に触れずに進められる仕事、たとえば公開情報の調査や、社内の手順書の整理などから始める方法があります。触れてよい情報の範囲を先に決めておくと、任せられる仕事を探しやすくなります。

仕事を説明する時間が取れません

最初の説明には時間がかかりますが、手順書や見本を一度作れば、次からは使い回せます。社員の負担の考え方は長期インターンの受け入れで社員の負担が大きいときでも整理しています。
