ワンキャリアの選考体験談を自社の選考改善に使う

ワンキャリアには、自社の選考を受けた学生が書いた選考体験談が残ります。読んではいるが、読んだあとに何も変わらない。人事の多くがこの状態にいます。読んで落ち込む、読んで安心する、読んで上司に報告する。そこで止まると、翌年も同じことが書かれます。結論から言うと、体験談を選考改善に使うには、「段階ごとに並べる」「直す候補を一つに絞る」「面接官と一緒に直し方を決める」「翌年の体験談で確かめる」の四つの流れにします。 一度に全部を直そうとせず、一年に一つでも、段階を決めて直すことが改善につながります。この記事では、読む前の準備、並べ方、直す一つの選び方、面接官への渡し方、翌年の確かめ方を整理します。クチコミ全体の読み方は自社クチコミの読み方で書きました。

この作業の目的｜体験談を「感想」から「直す材料」に変える

体験談には、学生が選考の各段階で見たこと、聞かれたこと、感じたことが書かれています。企業から見ると、自社の選考を外から見た記録です。面接官は自分の面接を外から見る機会がほとんどないので、体験談は貴重な材料になります。

ただし、感想として読むと、良い・悪いの評価で終わります。目的は、体験談を「どの段階で、何が起きたか」の記録として読み、直せることを取り出すことです。

読む前の準備

  1. 読む期間を決める：前回読んだ時期以降の分だけを読む。全部を毎回読み直さない
  2. 今年の選考の流れを手元に置く：段階ごとに、面接官に渡している「見ること」の一覧
  3. 企業ページの選考の流れを手元に置く：学生が読んでいる内容
  4. 一人で読まない：人事と、面接に出る人の二人で読むと、直す判断がその場でできる
  5. 記録の表を用意する：段階、書かれたこと、件数、直すか補うか

二つの流れ（社内の流れと企業ページの流れ）を手元に置くのは、体験談と照らし合わせるためです。体験談だけを読むと、どこがずれているのかが分かりません。

体験談を読む観点と、記録の表の作り方を一緒に整えます。いま使っている媒体の運用の相談だけでも構いません。

運用の相談をする

段階ごとに並べる

体験談を一件ずつ読むのではなく、段階ごとに並べ直します。

段階拾うこと照らし合わせる先
説明の場話の中身、出た社員、質問への答え説明会で話すと決めたこと
書類設問の意図が伝わったか、結果の連絡書類で見ると決めたこと
一次の面接聞かれたこと、面接官の様子、時間一次で見ると決めたこと
二次以降の面接聞かれたこと、前の回との違い各回で見ると決めたこと
結果の連絡連絡までの期間、伝え方連絡の目安
内定後連絡の頻度、社員と話す場内定後の予定

並べると、「一次では見ると決めたことを聞けているが、二次で同じ質問を繰り返している」「結果の連絡が段階によって遅い」のように、段階ごとの傾向が見えてきます。一件だけの記述は、傾向とは分けて記録しておきます。

直す候補を一つに絞る

並べると、直したいことが複数出てきます。全部を一度に直そうとすると、面接官の負担が大きくなり、どれも中途半端になります。次の順で一つに絞ります。

  1. 複数の体験談に同じことが書かれているか：一件より複数を先に
  2. 企業ページや社内の決めごととずれているか：決めたことが守られていない点を先に
  3. 選考の途中の段階か：途中の段階は今年の運用で直しやすい
  4. 直す人がはっきりしているか：誰が何を変えればよいかが分かるものを先に

絞った一つ以外は、記録に残して次の機会に回します。一年に一つでも、段階を決めて直すと、翌年の体験談に変化が出やすくなります。

エージェントベストの見解

相談で多い思い込みは、「体験談は面接官の評価表として使える」というものです。体験談に面接官の印象が書かれていると、その面接官を外すか、注意するかで済ませたくなります。しかし、当社が申込後の運用を見ている中で感じるのは、面接官個人の問題に見えることの多くが、実は「その回で何を見るか」が決まっていないことから起きている点です。見ることが決まっていなければ、面接官は自分の関心で質問を広げ、学生には「面接官によって違った」と映ります。体験談に面接官の印象が書かれていたら、まず「その回で見ることを、その面接官に渡していたか」を確かめてください。渡していなかったなら、直すのは面接官ではなく、渡し方です。面接の設計の考え方は面接の設計｜何回・誰が・何を見るかにまとめています。

面接官への渡し方

絞った一つを直すとき、面接官には次の形で渡します。

  • 体験談の文章をそのまま見せない：学生の言葉が強い場合、受け取る側が身構える。段階と事実に要約して渡す
  • 一枚にまとめる：書かれたこと、件数、直したいこと、そのための一つの行動
  • 理由を一度説明する：「翌年の学生が、この記述を読んで来る」ことを伝える
  • 責める材料にしない：誰が担当した回かを探すより、次の回から何を変えるかを決める
  • 面接のあとに一行で戻してもらう：変えた行動を試せたかどうか

面接官への説明の型はクチコミを面接官教育に使う方法でも書きました。

体験談から直す一つを決めたあと、選考の運用にどう落とすか。相談だけでも構いません。申込前提ではありません。

無料で相談する

企業ページで補うか、選考で直すか

体験談で見つかったことは、二つに分けます。

見つかったこと分け方
「何を見ているか分からなかった」企業ページで補い、面接でもそのとおりに聞く
「連絡が遅かった」選考の運用で直す。企業ページで約束しない
「面接官によって聞くことが違った」選考の運用で直す。各回で見ることを渡す
「仕事の具体が分からなかった」企業ページで補う。説明の場でも話す
事実と違う受け取り企業ページで事実を先に書く

選考で直すことを企業ページの言葉で済ませると、翌年の体験談に負けます。補うのは学生が知らなかったことだけで、起きたことは運用で直します。

翌年の体験談で確かめる

直した結果は、翌年の体験談に出ます。

  • 直した段階の記述を、前年と並べる：同じことが書かれていないか
  • 新しく書かれた記述を見る：直したことで別の段階にしわ寄せが出ていないか
  • 面接官に結果を戻す：変化があれば伝える。続ける理由になる
  • 次の一つを選ぶ：記録に残しておいた候補から

体験談の影響の段ごとの見方は選考体験談が採用に与える影響で書きました。

社内の分担

作業誰が
体験談を読み、段階ごとに並べる人事と面接に出る人
直す一つを絞る人事責任者
面接官に一枚で渡す人事
選考の運用を直す面接官
企業ページで補う人事
翌年の体験談で確かめる人事

外に出せるのは、読み方の観点、並べ方の表、渡す一枚の型までです。直す一つを決めることと、選考の運用を変えることは社内で行います。

エージェントベストの見解

当社は媒体で採る支援と人材紹介の両方をしているので、同じ会社の選考を、媒体経由の学生と紹介経由の学生の両方の側から見ることがあります。紹介経由では、選考のあとに担当者が学生の感想を聞き、企業に戻す流れがあります。媒体経由では、その役割を体験談が担っています。違いは、体験談は企業が頼んで集めたものではなく、学生が自分の言葉で書いたものだという点です。だからこそ、企業に遠慮のない記述が残ります。体験談を選考改善に使う会社には、体験談を「紹介会社から戻ってくる学生の感想」と同じ重さで扱うことを勧めます。紹介会社から「二次で同じ質問を繰り返された、と学生が言っていました」と聞けば、多くの会社は次の回から直します。体験談に同じことが書かれていても直さないのは、読んでいる人が一人で、直す人に届いていないからです。

まとめ

  • 体験談は感想ではなく、自社の選考を外から見た記録として読む
  • 読む前に、社内の選考の流れと企業ページの選考の流れを手元に置く
  • 段階ごとに並べ、直す候補を一つに絞る。複数の記述、決めごととのずれ、途中の段階を先に
  • 面接官には体験談をそのまま見せず、段階と事実の一枚で渡し、責める材料にしない
  • 直した結果は翌年の体験談で確かめ、次の一つに進む

よくある質問

体験談がほとんどありません。何から始めればよいですか

体験談が少ない時期は、面接のあとに面接官が残す記録と、学生から出た質問を材料にします。今年の選考が翌年の最初の体験談になるので、各回で見ることを決め、そのとおりに進めることから始めます。

体験談に事実と違うことが書かれています。直す対象にすべきですか

事実と違う記述は、選考の運用ではなく、企業ページで事実を先に書いて補う対象です。否定の言葉を使わず、実際の流れを淡々と書きます。向き合い方は厳しいクチコミへの向き合い方で書きました。

体験談の読み込みは、御社に相談できますか

できます。当社は、読む観点、段階ごとの並べ方、直す一つの選び方、面接官に渡す一枚の型を支えられます。体験談を読んで直す一つを決めることと、選考の運用を変えることは、企業が行ってください。当社は求人広告代理店として、媒体選びから運用までを支えています。
