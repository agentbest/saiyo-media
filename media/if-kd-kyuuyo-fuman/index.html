長期インターンの給与に不満が出たとき｜見直す順番

Infra・長期インターン課題別（追加） 更新日 2026/11/4

長期インターン生から「時給を上げてほしい」「友人のインターン先のほうが高い」と言われることがあります。言われた側は、金額を上げるか断るかの二択で考えがちです。結論から言うと、給与の不満に向き合うときは、金額を動かす前に「何と比べての不満か」を確かめると、上げなくても納得が得られる場合と、上げるべき場合を分けられます。 給与は一度上げると下げにくく、他のインターン生との釣り合いにも響きます。この記事では、症状の確かめ方、原因の切り分け、打ち手、外に任せられる範囲を順に整理します。

症状を確かめる｜誰が、どんな言い方で伝えてきたか

給与への不満は、出方によって中身が違います。まず次の点を整理します。

  • 伝え方：本人が直接言ってきた、担当の社員を通じて聞いた、辞める理由として出てきた
  • 言葉の中身：「上げてほしい」なのか、「いつ上がるのか分からない」なのか
  • 本人の状況：受け入れからの期間、任せている仕事の変化、勤務日数の変化
  • 広がり：一人だけの声か、複数のインターン生から同じ声が出ているか

「上げてほしい」と「いつ上がるか分からない」は、似ているようで違います。前者は金額への不満、後者は見通しへの不満です。見通しへの不満なら、金額をすぐに動かさなくても、昇給の考え方を示すことで落ち着くことがあります。

複数のインターン生から同じ声が出ている場合は、個別の話ではなく、給与の決め方そのものを見直す合図です。

原因を切り分ける｜三つの比べ方

給与の不満は、本人が何と比べているかで三つに分けられます。

  1. 他社との比較：友人のインターン先や、募集サイトで見た他社の時給と比べている
  2. 仕事の重さとの比較：受け入れ当初より仕事が増えた、責任が重くなったのに給与が変わらない
  3. 見通しとの比較：昇給があると聞いていたのに起きない、何をすれば上がるのか分からない

見る順番は、3つ目の見通しから始めるのが効率的です。昇給の考え方を伝えていなかっただけ、という場合は、説明を整えるだけで済みます。次に2つ目の仕事の重さを見ます。仕事の範囲が広がっていれば、給与の見直しを考える理由があります。1つ目の他社との比較は、職種や仕事の中身が違うことも多く、金額だけを並べても答えは出ません。

給与の決め方そのものを整理したい場合は、長期インターンの給与の決め方で考える順番をまとめています。

給与の見直しが、次の募集にどう響くか。原稿の書き方と合わせて整理します。

運用の相談をする

打ち手｜見直す場合と据え置く場合

切り分けの結果に応じて、打ち手を選びます。

原因打ち手
見通しが分からない昇給の条件と時期の考え方を文章にして伝える
仕事が重くなった仕事の範囲を確認し、給与の見直しか仕事の調整かを決める
他社と比べている仕事の中身と得られる経験を含めて話す。必要なら相場を確かめる
複数人から同じ声給与の決め方全体を見直し、全員に同じ説明をする

据え置くと決めた場合も、理由を伝えることが欠かせません。「会社の決まりなので」だけでは、不満は残ります。いまの仕事に対する考え方、どうなれば見直すか、を具体的に伝えます。

見直すと決めた場合は、一人だけ上げるのか、同じ条件の全員を見直すのかを先に決めます。インターン生どうしは給与の話をすることが多く、説明のつかない差は別の不満を生みます。

給与の見直しは、契約内容の変更にあたります。手続きの考え方は長期インターンの契約内容を途中で変えるときで扱っています。なお、給与の支払いや最低賃金には法令で定められた項目があります。金額を決める前に、社労士や公式の案内で確認してください。

エージェントベストの見解

給与の不満の相談で多い思い込みは、「時給を上げれば解決する」というものです。実際には、時給を上げても数か月後に同じ声が出ることがあります。不満の中身が金額ではなく、「自分の働きが見られていない」という感覚だった場合です。この場合、本人が求めているのは評価の言葉と、次に何を任されるかの見通しです。だから、給与の話が出たら、まず「いまの仕事をどう見ているか」を会社から伝え、そのうえで給与の話をする順番を勧めます。評価の伝え方が整っていない会社では、給与を上げる前に評価の場を作るほうが、同じ費用でも効き目が長く続きます。評価の考え方は長期インターン生の評価も参考になります。

次の募集に反映する

給与の不満が出たことは、次の募集の書き方を見直す材料にもなります。

  • 昇給の考え方を原稿に書く：何をすれば、どのくらいの時期で見直すかの考え方
  • 仕事の広がり方を書く：最初の仕事と、慣れてから任せる仕事
  • 給与以外に得られるものを書く：任される範囲、関わる社員、身につく経験

最初から見通しを示しておくと、受け入れ後に「聞いていなかった」という不満が出にくくなります。給与の書き方は長期インターンの給与の書き方でも整理しています。

エージェントベストの見解

Infraの代理店として募集の相談を受けると、給与の欄だけを先に決めて、仕事の中身はあとから書く会社が少なくありません。この順番だと、給与と仕事の釣り合いを学生に説明できないまま受け入れが始まり、半年ほどして不満の形で表に出ます。先に決めたいのは、最初に任せる仕事と、慣れたあとに任せる仕事の二段階です。二段階が書けると、「最初はこの給与、この仕事ができるようになったら見直す」という説明が自然にできます。給与の不満は、受け入れたあとに出てくる問題に見えて、実は募集の前に決めておく順番の問題であることが多いです。

Infraの料金は正規のままです。募集の前に、給与と仕事の書き方だけ相談することもできます。

無料で相談する

社内で給与の考え方をそろえる

給与の不満は、受け入れ部署ごとに扱いがばらばらになると広がりやすくなります。ある部署では仕事が増えたら上げ、別の部署では据え置く。インターン生どうしで話をすれば、その差はすぐに伝わります。

社内でそろえておきたいのは次の点です。

  • 見直しの時期：受け入れから一定の期間が過ぎたとき、学年が上がるときなど、見直す時期の考え方
  • 見直しの条件：任せる仕事の段階が上がったとき、など説明できる条件
  • 決める人：受け入れ部署の判断だけで決めるのか、人事と相談して決めるのか
  • 伝え方：見直す場合も据え置く場合も、理由を伝えることを決まりにする

決まりを作ると、受け入れ部署の社員も、インターン生から聞かれたときに答えやすくなります。答えられないまま「確認します」が続くと、それ自体が不満の種になります。

まとめ

  • 給与の不満は、金額への不満か、見通しへの不満かを先に分ける
  • 原因は見通し、仕事の重さ、他社との比較の順に見る
  • 据え置くときも、理由とどうなれば見直すかを伝える
  • 見直すときは、一人だけか全員かを先に決める
  • 昇給の考え方と仕事の広がり方を、次の募集の原稿に書く

よくある質問

他社の時給と比べられたとき、どう答えればよいですか

金額だけで比べず、仕事の中身と任される範囲を合わせて話します。そのうえで、自社の給与が相場から大きく離れていないかは、一度確かめておくと安心です。

一人だけ給与を上げてもよいですか

上げる理由を、他のインターン生にも説明できるなら構いません。仕事の範囲や役割の違いなど、説明できる基準を先に決めておきます。

給与の不満が出たインターン生が辞めそうです

給与の話だけで引き留めようとすると、話がこじれることがあります。いまの仕事への評価と今後の見通しを伝え、そのうえで本人の希望を聞きます。辞める場合も、理由を聞いて次の受け入れに生かします。
