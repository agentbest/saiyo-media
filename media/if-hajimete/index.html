初めて長期インターンを受け入れる会社の準備

初めて長期インターンを受け入れる会社は、「何から準備すればいいのか」が分からないまま、募集を出すことから始めてしまいがちです。結論として、初めての受け入れは「目的」「仕事」「人」「条件」の順で準備し、募集はその最後に出すと、受け入れたあとのずれが小さくなります。 募集を先に出すと、応募が来てから準備に追われ、最初のインターン生の経験が手探りになります。この記事では、初めての会社が割ける時間の考え方、準備の順番、初日から最初の1か月の過ごし方を整理します。

初めての会社で割ける時間を見積もる

初めて長期インターンを受け入れる会社では、受け入れにどれだけ時間がかかるかの感覚がありません。最初に、どの段階でどれくらいの手間がかかるかを大まかに見積もっておきます。

  • 準備の段階：目的と仕事の整理、契約や勤怠の確認、募集の文面づくり
  • 選考の段階：応募への返信、面接、合否の連絡
  • 立ち上げの段階：最初の数週間、仕事を教え、横について見る
  • 継続の段階：週ごとの仕事の割り振りと振り返り

初めての会社が見落としやすいのは、立ち上げの段階の手間です。社員を一人採ったときと同じように、最初は教える側の時間が取られます。この期間を、会社の繁忙期と重ねないように計画します。

準備の順番｜目的・仕事・人・条件

1. 目的を言葉にする

なぜ長期インターンを受け入れるのかを、一文で書けるようにしておきます。

  • 将来の新卒採用につなげたい
  • 社内で手が回っていない仕事を進めたい
  • 若い世代の視点を事業に取り入れたい
  • 学生に働く経験を提供したい

目的は一つでなくても構いませんが、優先順位をつけておきます。目的によって、任せる仕事も、選ぶ学生も、成果の測り方も変わるからです。

2. 任せる仕事を棚卸しする

社内の仕事を書き出し、インターン生に任せられるものを選びます。最初は、範囲がはっきりしていて、終わりの形が説明できる仕事を一つか二つに絞ります。仕事の切り出し方は任せる仕事がないときの切り出し方で詳しく書いています。

3. 指導役を決める

日々の質問に答え、仕事を確認する社員を一人決めます。指導役が週にどれくらいの時間を割けるかを、本人と上司の間で確認しておきます。

4. 勤務の条件と契約を確認する

週の勤務日数と時間、出社かリモートか、給与、交通費、試験期間の扱いを決めます。雇用契約を結ぶ場合は、最低賃金や労働時間の規定を守る必要があります。契約まわりの確認は雇用契約と労働時間｜受け入れ前に確認することにまとめています。

目的・仕事・人・条件の4つを整理すれば、募集の文面はほぼ書けます。初めての受け入れの準備から一緒に進めます。

エージェントベストの見解

初めての会社が準備の段階で最もつまずきやすいのは、目的を「将来の採用につなげたい」だけにしてしまうことです。この目的だけだと、インターン生が入社しなかったときに「失敗だった」という評価になり、二回目の受け入れの判断が難しくなります。当社が勧めるのは、採用以外の目的も一つ並べておくことです。たとえば「手が回っていなかった業務の手順書を整える」「学生向けの会社紹介の資料を学生の目線で作り直す」。こうした目的があると、インターン生が別の会社に就職しても、受け入れの成果が社内に残ります。初めての受け入れは、二回目を続けるかどうかの判断材料を集める期間でもあります。成果が採用の一点だけだと、その判断材料が少なすぎます。

募集を出すときに書くこと

準備の4つが整ったら、募集の文面を書きます。初めての会社の募集で書いておきたいのは次の点です。

  1. 会社の事業：何をしている会社かを、学生にも分かる言葉で
  2. 任せる仕事：最初に任せる仕事と、慣れたら任せたい仕事
  3. 一緒に働く人：指導役がどんな人か、チームの雰囲気
  4. 勤務の条件：日数、時間、場所、給与、試験期間の扱い
  5. 初めての受け入れであること：隠さずに書く。一緒に仕組みを作っていく姿勢として伝える

初めての受け入れであることを書くのは、不利に思えるかもしれません。しかし、学生の中には「仕組みができあがっていない会社で、自分で考えて動きたい」という層もいます。正直に書くことで、入ってからのずれも減ります。

初日から最初の1か月の過ごし方

受け入れが決まったら、最初の1か月の計画を立てておきます。

初日

  • 会社の事業と、チームの紹介
  • 働き方のルール（勤怠、連絡の方法、情報の扱い）
  • 最初の仕事の説明と、困ったときの相談先

最初の1週目

  • 指導役が横について、仕事の進め方を見せる
  • 小さな仕事を一つ終えてもらい、確認してコメントを返す

2週目から4週目

  • 仕事の範囲を少しずつ広げる
  • 週に一度、仕事の振り返りの時間を持つ

1か月の終わり

  • 本人の感想と、会社から見た手応えを話す
  • 次の1か月に任せたい仕事を決める

最初の1か月は、仕事の成果よりも「この会社でやっていけそうか」を本人がつかむ期間です。

エージェントベストの見解

当社はInfraの代理店として、初めて長期インターンを受け入れる会社の募集を支援しています。その中で、最初の受け入れがうまくいった会社に共通していたのは、受け入れの最初の1か月の記録を残していたことです。何を教え、どこで本人がつまずき、どの仕事が手応えにつながったか。指導役が週に一行でも書き残しておくと、二人目を受け入れるときに、最初の1か月の計画をそのまま使えます。記録がないと、二人目のときにまた手探りから始まり、指導役が「前回はどうしたっけ」と思い出すことに時間を使います。初めての受け入れは、自社の受け入れの型を作る機会でもある、と考えて記録を残すことを勧めます。

受け入れ前に、社内へ伝えておくこと

初めての受け入れでは、インターン生が来ることを社内の全員が知っているとは限りません。指導役以外の社員が事情を知らないと、初日に誰も声をかけない、何者か分からず遠慮される、といったことが起こります。受け入れの前に、次のことを社内に伝えておきます。

  1. いつから、どの部署に、どんな学生が来るか
  2. 任せる仕事と、指導役が誰か
  3. 受け入れる目的：なぜ長期インターンを始めるのか
  4. 社員にお願いしたいこと：あいさつをする、質問されたら答える、指導役に様子を伝える

特に、受け入れる目的を伝えておくことは大切です。目的が共有されていないと、社員の中には「なぜ学生を入れるのか」「自分の仕事が増えるのでは」と感じる人もいます。代表や責任者から一言説明があるだけで、受け止め方は変わります。初めての受け入れは、社内にとっても新しい経験です。

初めての受け入れで、社内への説明や受け入れ体制をどう整えるか。準備の段階からご相談いただけます。

よくある質問

何人から受け入れ始めるのがよいですか

初めての受け入れは、一人から始めることを勧めます。一人のほうが、指導役の手間も見通しやすく、うまくいかなかったときの原因も分かりやすくなります。型ができてから、二人目、三人目を考えるほうが進めやすいです。

準備にどれくらいの期間がかかりますか

会社の規模や、契約まわりの決まりがどれだけ整っているかによって異なります。目的と仕事の整理は短期間でもできますが、契約や勤怠の仕組みを新しく作る場合は時間がかかります。募集を出す時期から逆算して、早めに準備を始めておくと安心です。

受け入れてみて合わなかった場合はどうすればよいですか

合わないと感じたときは、まず本人と話し、仕事の内容や働き方を調整できるかを確かめます。調整しても難しい場合は、契約の期間や終了の手続きに沿って対応します。契約の内容は、受け入れ前に決めておくことが大切です。
