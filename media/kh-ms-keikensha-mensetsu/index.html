経験者の面接で見ること｜実績の聞き方

経験者の面接は「実績を聞けばいい」と思われがちですが、実績の聞き方で判断の質が大きく変わります。結論から言うと、経験者の面接では、実績をそのまま受け取らず「どんな状況で・どんな役割で・何をして・何が起きたか」に分解して聞き、本人の寄与と環境の寄与を分けます。 分解しないと、チームの成果を本人の成果として評価したり、前職の環境があったからできたことを自社でもできると見込んだりします。この記事では、実績を分解する枠、裏を取る重ね方、失敗の聞き方、自社で再現できるかの確かめ方、やりがちな失敗を整理します。未経験者の面接は未経験者の面接で見ることに分けています。

実績をそのまま受け取ると何が起きるか

経験者の面接で、実績をそのまま受け取ったときに起きることを先に挙げます。

  • 「売上を大きく伸ばした」が、実際には市場全体が伸びた時期の話だった
  • 「プロジェクトを成功させた」が、本人は複数いるメンバーの一人だった
  • 「新規事業を立ち上げた」が、前職の資金と看板があってできたことだった
  • 「部下を育てた」が、部下が優秀で自分で育った

どれも嘘ではありません。候補者は自分の経験を良く見せようとしますし、面接という場でそれは自然なことです。問題は、受け取る側が分解せずに評価することです。分解は、候補者を疑うためではなく、同じ基準で候補者を比べるために行います。

実績を分解する四つの枠

実績は、次の四つに分けて聞きます。

枠聞くこと見たいこと
状況そのとき、会社・部門・市場はどんな状態だったか。何が課題だったか実績の出発点。簡単な状況だったか、難しい状況だったか
役割チームの中で本人は何を担っていたか。決める立場か、動く立場か本人の寄与の範囲
行動本人が具体的に何をしたか。何を決め、何を変えたか本人の判断と工夫
結果何が起き、どう評価されたか。うまくいかなかった部分はどこか行動と結果のつながり

面接では、候補者が「結果」から話し始めることが多いので、面接官は「状況」と「役割」に戻して聞きます。「それは、どんな状態から始めましたか」「チームは何人で、あなたはどの部分を担当していましたか」という質問です。四つがそろうと、同じ実績でも候補者ごとの違いが見えてきます。

一つの実績を四つの枠で聞くと、時間がかかります。候補者の実績をすべて聞くのではなく、募集する役割に最も近い実績を一つか二つ選び、それを深く聞きます。広く浅く聞くより、一つを深く聞くほうが本人の力が分かります。

経験者を採る媒体で、どんな実績の候補者が集まるかは媒体ごとに違います。並べてご案内します。

媒体選びを相談する

裏を取る重ね方

分解したうえで、答えの裏を取る聞き方があります。候補者を追い詰めるのではなく、具体に降りていく聞き方です。

  1. 「具体的には」を重ねる：「工夫しました」には「どんな工夫ですか」、「調整しました」には「誰と、何を調整しましたか」と重ねる。具体が出てこない部分は、本人の寄与が薄い可能性がある
  2. 「一人でやった部分」を聞く：「そのうち、あなた一人の判断でやった部分はどこですか」。チームの成果と本人の成果を分ける最も単純な質問
  3. 「やらなかった選択肢」を聞く：「他にどんなやり方がありましたか。なぜそれを選びませんでしたか」。本人が考えて選んだのか、流れでそうなったのかが分かる
  4. 「違う環境なら」を聞く：「同じことを、人も予算も少ない環境でやるとしたら、何を変えますか」。環境への依存度と、自社での再現性が見える
  5. 「うまくいかなかった部分」を聞く：成功した実績にも、思いどおりにいかなかった部分がある。それを言える人は、実績を客観的に見ている

この五つを、すべての実績に使う必要はありません。募集する役割に近い実績に、二つか三つを重ねます。重ねた結果を記録に残すと、他の面接官と比べられます。

エージェントベストの見解

相談で多い思い込みは、「大きな会社で実績を出した人は、うちでも同じことができる」というものです。実際には、大きな会社の実績は、会社の看板、既存の顧客、整った仕組みの上に成り立っていることが多く、それらがない環境で同じ結果が出るかは別の話です。当社は人材紹介で経験者を企業に送る側にいて、入社後に期待どおりに立ち上がる人とそうでない人を見ています。分かれ目は、実績の大きさではなく「前職の仕組みがないところで、自分で仕組みを作った経験があるか」です。これは「違う環境なら何を変えるか」と聞くと見えます。前職の仕組みの話しか出てこない人は、仕組みがない環境で止まることがあります。「まず顧客の一覧を自分で作るところから始める」のように、仕組みがない前提の話が出てくる人は、環境が変わっても動けます。自社の規模が候補者の前職より小さいなら、この質問を外さないことを勧めます。

自社で再現できるかを確かめる

実績が本人のものだと分かっても、自社で同じことができるとは限りません。再現性は、次の三つで確かめます。

  • 道具と予算：前職で使っていた道具や予算が、自社にもあるか。なければ、それなしでやった経験があるか
  • 周りの人：前職で頼っていた専門の部署や同僚が、自社にもいるか。いなければ、自分でやれるか、外に頼む判断ができるか
  • 役割の幅：前職では分業されていた仕事が、自社では一人で担う範囲になるか。その幅を本人が受け止めているか

三つ目は、特に小さな会社で起きるずれです。前職で企画だけをやっていた人が、自社では企画から実行、報告まで一人で担うことになる。この幅を面接で伝え、本人がどう受け止めるかを見ます。「できます」という答えより、「実行の部分は経験が薄いので、最初は時間がかかるかもしれません」という答えのほうが、現実を見ている場合があります。

再現性の確認は、候補者を落とすためではなく、入社後の受け入れ方を決めるためにも使います。道具がない部分は会社が用意する、周りに専門の人がいない部分は外に頼む、と決めておけば、実績のある人を活かせます。

失敗の実績を聞く

成功した実績だけでなく、失敗した経験を聞きます。聞きたいのは失敗の大きさではなく、失敗のあとにどうしたかです。

  • 何が起きて、どこで気づいたか
  • 気づいたとき、誰に、いつ伝えたか
  • その後、何を変えたか
  • 同じ状況が来たら、今はどうするか

失敗を聞くと「特にありません」と答える候補者がいます。経験が長い人で失敗がないことは考えにくいので、「思いどおりに進まなかったこと」「あとから振り返ると別のやり方があったと思うこと」と言い換えて聞きます。それでも出てこない場合は、自分の仕事を振り返る習慣が薄い可能性があります。

経験者の面接に現場の責任者が出る時間が取れないとき、どこまで外に出せるかを一緒に整理します。

運用の相談をする

やりがちな失敗

経験者の面接で起きやすい失敗を挙げておきます。

  • 肩書で判断する：「部長だった」「リーダーだった」という肩書は、会社によって意味が違います。肩書ではなく、何を決める立場だったかを聞きます
  • 会社名で判断する：有名な会社にいたことは、その会社の選考を通ったことの証明にはなりますが、自社で活躍することの証明にはなりません
  • 話の上手さで判断する：実績の説明が上手い候補者に、分解せずに納得してしまう。すべての実績に「一人でやった部分はどこか」と聞くと決めておくと、流されにくくなります
  • 人事だけで面接する：実績の中身は、その仕事を知っている人でないと分解できません。現場の責任者か同じ職種の社員を入れます
  • 転職の理由を聞かない：実績に集中して、なぜ辞めるのかを聞き忘れる。理由が自社で解消されないなら、実績があっても早く離れます

エージェントベストの見解

経験者の面接を設計するとき、先に決めておかないと効果が出ないのは「募集する役割で、入社後の最初の数か月に出してほしい結果」です。これが決まっていないと、どの実績を深く聞くべきかが決まらず、候補者の実績を広く浅く聞く面接になります。当社が複数の会社の中途採用の運用を横から見ていると、面接がうまく回っている会社は、求人票を書く時点で「最初に任せる仕事」を一つに絞っています。その仕事に近い実績を候補者の経歴から選び、四つの枠で深く聞く。それ以外の実績は、記録に残す程度にとどめる。この絞り方をすると、面接の時間が足りなくなることが減り、候補者ごとの比較もしやすくなります。逆に、「幅広く活躍してほしい」という募集は、面接で聞くことが定まらず、印象で決まりやすくなります。経験者を採るときは、最初に任せる仕事を一行で書けるかを、面接の前に確かめることを勧めます。

まとめ

  • 経験者の実績は、状況・役割・行動・結果の四つに分解して聞く
  • 「一人でやった部分」「違う環境なら何を変えるか」で、本人の寄与と環境の寄与を分ける
  • 道具・予算・周りの人・役割の幅で、自社での再現性を確かめる
  • 失敗の経験は、失敗のあとにどうしたかを聞く
  • 肩書・会社名・話の上手さで判断せず、現場を知る人を面接に入れる

よくある質問

実績を深く聞くと、候補者に圧迫していると思われませんか

聞き方で変わります。「本当ですか」と疑う聞き方ではなく、「もう少し詳しく教えてください」「そのとき、あなたはどの部分を担当していましたか」と具体に降りる聞き方なら、候補者は自分の経験を丁寧に聞いてもらえていると感じることが多いです。冒頭で「実績を詳しく伺います」と伝えておくと、候補者も準備ができます。

職務経歴書に書かれた実績と、面接での話が違う場合はどうしますか

その場で指摘するのではなく、「経歴書にはこう書かれていますが、今のお話との関係を教えてください」と聞きます。書き方の問題であることも、本人の寄与が小さいことを言いにくかったこともあります。違いの理由を聞いたうえで、記録に残します。

経験者の面接を人事だけで行っています。現場を入れるべきですか

実績の分解は、その仕事を知っている人でないと難しいので、一度は現場の人を入れることを勧めます。現場の責任者が出られないなら、同じ職種の社員でも構いません。人事は、進め方の型と記録を担い、実績の中身の判断は現場に任せる分け方が合います。
