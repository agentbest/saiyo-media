教育業界の長期インターン採用｜生徒や受講者と接する仕事の線引き

学習塾、英会話教室、オンラインの学習サービス、教育のソフトウェアを作るEdTechの会社。教育業界は、大学生が講師のアルバイトとして関わることの多い業界です。そのため、長期インターンを募集すると、学生から「講師のアルバイトと何が違うのか」と思われることがあります。結論から言うと、教育業界の長期インターンは、教える仕事ではなく「教育の仕組みを作る仕事」を任せる場として位置づけ、その違いを原稿で明確にすることが、合う学生に届く出発点になります。 違いが伝わらないと、講師のアルバイトを探している学生が集まり、仕組みづくりに関心のある学生には届きません。この記事では、学生向けの長期インターン求人サイトInfraで募集する教育業界の会社に向けて、仕事の分け方と運用設計を整理します。

教育業界の採用構造と、長期インターンの位置

教育業界の会社は、教室や講師を運営する事業と、教材やサービスを作る事業の両方を持っていることが多くあります。採用では、教室の運営を担う職種や、教材やサービスを作る職種、営業職などがあります。

長期インターンは、この業界で次の役割を持ちます。

  • 教育の仕組みづくりの手：教材の作成、学習のデータの分析、サービスの改善
  • 運営の手：教室の運営の補助、保護者向けの資料の作成、イベントの企画
  • 新卒採用の入口：教育に関心のある学生と関係を作る
  • 学習者に近い目線：学生自身が少し前まで学習者だった

四つ目は、教育業界ならではの価値です。中高生向けのサービスなら、学生は数年前まで同じ立場にいました。その記憶は、教材やサービスの改善に生かせます。

講師のアルバイトとの違いを明確にする

教育業界の長期インターンの原稿では、講師のアルバイトとの違いを最初に伝えます。

項目講師のアルバイト長期インターン
主な仕事生徒に教える教材・サービス・運営の仕組みを作る
関わる相手担当の生徒社員、生徒全体、保護者、データ
得られる経験教える力企画・分析・改善の経験
成果の見え方担当の生徒の成長仕組みの改善、多くの生徒への影響

この表のように、関わる範囲と得られる経験の違いを示すと、学生は自分がどちらを求めているかを判断できます。講師の経験がある学生が、次の段階として仕組みづくりに関わりたいと考えて応募してくることもあります。そうした学生は、教える現場を知っているぶん、仕組みの改善で現場に役立つ意見を出せます。

エージェントベストの見解

教育業界の会社が長期インターンを募集するとき、当社がよく見るのは、原稿の仕事内容に「生徒のサポート」と書いた結果、講師のアルバイトを探している学生が多く集まる、という状況です。「サポート」という言葉は、学生には個別の指導や質問への対応として読まれやすいからです。仕組みづくりの仕事を任せたいなら、原稿の最初の数行で、教える仕事ではないことを明確に書くことです。たとえば「生徒に直接教える仕事ではありません。生徒が使う教材や学習のサービスを、社員と一緒に作り、改善する仕事です」と書く。この一文があるだけで、応募してくる学生の層が変わります。講師の経験がある学生には、その経験が仕組みづくりにどう生きるかを書き添えると、次の段階を探している学生に届きます。原稿の書き出しの考え方はInfraの求人原稿の書き方でも扱っています。

講師のアルバイトとの違いを、原稿でどう伝えるか。書き出しから一緒に考えます。

生徒や受講者と接する仕事の線引き

教育業界の長期インターンでは、生徒や受講者と接する場面をどこまで学生に任せるかを決めておきます。

学生に任せやすい仕事（生徒と直接接しない）

  • 教材や問題の作成の補助
  • 学習のデータの集計と分析
  • 保護者向けの資料やお知らせの下書き
  • 自社サービスの使いやすさの確認

社員と一緒に進める仕事

  • 教室のイベントや説明会の運営
  • 生徒向けのアンケートの設計と集計

学生には任せない仕事

  • 生徒や保護者との個別の面談
  • 成績や進路に関わる判断
  • 生徒の悩みや家庭の事情に関わる対応

三つ目の仕事は、生徒や保護者の人生に関わる判断や、配慮が必要な対応です。学生にとっても負担の大きい仕事であり、社員が持つことを明確にしておきます。

未成年の個人情報の扱い

教育業界の仕事では、未成年の生徒の個人情報に触れる場面があります。氏名、学校、成績、家庭の情報。扱いは特に慎重にします。

  • 触れてよい情報：個人が特定できない形に加工したデータ
  • 段階的に触れる情報：教室の運営に必要な範囲の氏名など
  • 触れない情報：成績の詳細、家庭の事情、面談の記録

学生が生徒と同じ地域の出身である場合、知り合いの家族の情報に触れる可能性もあります。その場合は担当の社員に伝え、その情報には触れないようにする決まりを作っておきます。

秘密保持の約束は、雇用契約や誓約書の中で書面にしておきます。賃金や時間の面は、雇用で迎える以上、最低賃金と労働時間の規定を下回らない条件で組みます。

業界のイメージと、見せ方

教育業界に対して、学生は次のようなイメージを持っていることがあります。

  • 人の成長に関われる、やりがいがある
  • 講師や先生の仕事が中心
  • 繁忙期は忙しい（受験の時期など）

一つ目は学生にとっての大きな魅力です。長期インターンの原稿では、仕組みづくりを通じて多くの生徒の成長に関われることを、具体的な例で書きます。「インターン生が作った問題集が、教室の生徒全員に使われています」のような例があれば、学生は自分の仕事の広がりを想像できます。

二つ目のイメージは、先ほどの講師のアルバイトとの違いで応えます。EdTechの会社なら、開発やマーケティングの仕事もあることを書くと、教育に関心のある理系の学生や、ITに関心のある学生にも届きます。

エージェントベストの見解

教育業界の長期インターンを新卒採用につなげたい会社に、当社が伝えていることがあります。教育に関心のある学生は、新卒の就職活動で、教員や公務員、大手の教育会社、EdTechの会社など、幅広い選択肢を比べることが多いという点です。当社は長期インターンの媒体と新卒向けの媒体の両方を扱っていますが、教育に関心のある学生が会社を選ぶとき、「教育にどう関われるか」の具体さが大きな判断材料になっています。教員として一つの教室に関わる道と、会社として多くの生徒に関わる道。長期インターンで仕組みづくりを経験した学生は、後者の価値を自分の言葉で語れるようになります。その経験を新卒採用につなげるには、インターン中に学生の作ったものが生徒にどう使われたかを、数字や声で伝えておくことです。自分の仕事が多くの生徒に届いたという実感は、教員と並べて比べたときにも、学生の判断を支える材料になります。

教育に関心のある学生を、新卒採用まで見据えて採りたい会社のご相談をお受けしています。

よくある質問

講師のアルバイトをしている学生を、長期インターンに誘ってもよいですか

誘うことはできます。講師の経験がある学生は、教える現場を知っているぶん、教材や仕組みの改善に役立つ意見を出せます。ただし、講師の仕事と長期インターンの仕事を兼ねる場合は、それぞれの勤務時間と条件を分けて管理する必要があります。

教育学部の学生だけを対象にしたほうがよいですか

教育学部の学生は教育への関心が深い一方、仕組みづくりの仕事には、データの分析や企画、開発など、さまざまな力が役立ちます。学部を限定せず、教育への関心と、任せる仕事に必要な力を条件として書くと、幅広い学生に届きます。

受験の時期など、繁忙期の受け入れはどうすればよいですか

繁忙期は社員も忙しく、学生に教える時間が取りにくくなります。繁忙期の前に学生に任せる仕事を決めておき、その時期は決まった作業を中心に進めてもらう形にすると無理がありません。学生自身の試験の時期とも重なることがあるため、事前に予定を確認しておきます。
