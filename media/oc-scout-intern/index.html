ワンキャリアのスカウトは、本選考だけでなく、インターンに誘うためにも使えます。ところが、本選考に誘う文面をそのまま「インターンにご参加ください」に変えると、「何を任せるのか」「選考と関係があるのか」が無く、学生は受諾の前に迷います。ワンキャリアでは、インターンの体験談（何をしたか、選考につながったか、掲載と違ったか）が書かれるので、文面と実態がずれると、そこに残ります。結論から言うと、インターンにスカウトでつなぐときは、文面に「何を任せ、誰が見て、終わったら何が残るか」を一文で書き、選考との関係を年度の公表内容と自社の方針で確認して曖昧にせず、担当者と過去の参加者と話す場に誘います。自社のインターンの体験談を読んでから送り、受け入れの準備を先に済ませ、送る時期は年度の公表内容と自社の方針で決めます。 この記事では、インターンに誘うスカウトの役割、やりがちな失敗、文面の4段のインターン向けの書き方、体験談を読んでから送ること、受け入れの準備、時期、参加後の連絡、分担を整理します。インターンの掲載はワンキャリアでインターンを掲載するときの書き方、OfferBoxでのインターンへの接続はOfferBoxからインターンへの接続で書きました。

この作業の目的｜「仕事を体験する入口」を、学生が判断できる形で渡す

インターンに誘うスカウトは、本選考に誘うスカウトと目的が違います。本選考は「この会社を受けるか」の入口で、インターンは「この仕事を体験してみるか」の入口です。

就職活動を始めたばかりの学生や、仕事の中身を知りたい学生にとって、インターンは本選考より入りやすい場です。目的は、その学生に「何をするインターンか」「選考と関係があるのか」を文面で先に伝え、受諾の前に判断できるようにすることです。

やりがちな失敗

失敗学生からどう見えるか
本選考と同じ文面で「インターンにご参加ください」何をするインターンか分からない
「実践的なインターン」「社員と同じ仕事」の一言体験談に「雑用だった」とあれば、文面が疑われる
選考との関係が曖昧「参加すると選考に入るのか」で迷う。体験談で「関係があった」と書かれていれば、なおさら
受け入れの準備が無いまま送る来た学生に任せる仕事が無い。体験談に「行ってみたら違った」
インターンの体験談を読まずに送る学生が体験談で読んでいることを知らない
「早期選考につながる」で誘う年度の公表内容と自社の方針に沿っていない可能性。急がせている
期間や頻度が無い学業と両立できるか判断できない
誰が見るかが無い「放置されるのでは」

最も多いのは、最初の「本選考と同じ文面」です。インターンの文面には、「何を任せるか」の一文が要ります。

いま使っている媒体の運用の相談だけでも構いません。インターンに誘うスカウトの文面を、「何を任せるか」と「選考との関係」の一文から一緒に作ります。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「インターンへの誘いは、本選考より気軽なので、文面も軽くてよい」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、インターンの体験談は、本選考の体験談より「行ってみたら違った」が多く書かれます。文面で「実践的」と誘い、実際は見学と雑用だった、という形です。学生は、インターンの体験談を読んでから受諾するので、文面と体験談がずれていれば、受諾の前に閉じます。当社がインターンへの誘いの文面を整えるとき、最初にやるのは、「最初の週に何を任せるか」を担当者に聞き、それを文面の一文にすることです。「実践的」の一言より、「最初の週は〇〇の下調べを任せます」の一文のほうが、学生には具体で、体験談とも揃います。

文面の4段を、インターン向けに

段インターン向けの書き方
1. 学生時代の場面を読んだ一文「〇〇を続けてこられたと書かれていたのを読んで」。本選考と同じ。本人の言葉で
2. インターンで最初の週に任せることとの重なり「うちのインターンでは、最初の週に△△を任せます。□□を続けてきたあなたに、まずそれをやってみてもらえたらと思い」。何を任せ、誰が見て、終わったら何が残るかを、一文ずつ
3. 選考との関係の一文「このインターンは、選考とは〇〇です」。年度の公表内容と自社の方針を確認して、曖昧にせず。詳しくは掲載へ
4. 担当者と過去の参加者と話す場「インターンの中身を、担当の〇〇と、去年参加した△△が話します。参加を決める前に聞いてください」

「2段目に、何を任せ、誰が見て、終わったら何が残るか」が、インターン向けの要点です。本選考の文面の「最初の1年」の位置に、「インターンの最初の週」が入ります。4段の基本はワンキャリアのスカウト文面の書き方で書きました。

選考との関係は、年度の公表内容と自社の方針で確認して、曖昧にしない

インターンと選考の関係は、年度ごとに公表される内容があり、扱いが変わることがあります。

  • 文面に書く前に、年度の公表内容と自社の方針を確認する：この記事では、関係の具体は書かない
  • 「関係なし」なら、その旨を一文で：「このインターンは、選考とは関係ありません」
  • 「関係あり」なら、どういう形かを：曖昧な「有利になります」は書かない
  • 書いたら守る：参加の有無で選考の扱いを変えない。体験談に「関係なしと書いてあったのに」と書かれる
  • インターンの掲載と同じ内容で：文面だけ違うことを書かない。ワンキャリアでインターンを掲載するときの書き方

「書いたら守る」は、本選考の掲載と同じ原則です。インターンは特に、次の年の体験談に「関係があった」「無かった」が書かれやすい場です。

自社のインターンの体験談を、読んでから送る

  • 「何をしたか」がどう書かれているか：「雑用だった」「任せてもらえた」
  • 「誰が見たか」がどう書かれているか：「放置された」「担当が毎日見てくれた」
  • 「選考につながったか」がどう書かれているか：文面の3段目と揃っているか
  • 「掲載と違ったか」があるか：あれば、文面より先にインターンの中身を直す
  • 良いと書かれたことは、文面の2段目に：「参加者が『〇〇を任せてもらえた』と書いてくれている形は、今年も同じです」

「掲載と違った」がある状態で送ると、学生は体験談を読んで離れます。読まれるほど不利になる状態で送っても、受諾は来ません。

受け入れの準備を、先に

文面を送る前に、社内で決めておくことは、インターンの掲載と同じです。

  1. 最初の週の仕事、任せないこと
  2. 担当する社員と、その合意：見る時間が業務に入る
  3. 期間と頻度：学業と両立できる形か
  4. 報酬と時間の扱い：管理部門と。体験と労働の線引きは自社の方針と制度で確認
  5. 終わりの形：振り返りの場、成果物の扱い
  6. 選考との関係：年度の公表内容と自社の方針
  7. 過去の参加者に、話す場に出てもらう同意

決まってから送ります。文面は、決めたことを学生の言葉で書いたものです。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。インターンにスカウトでつなぐ場合の、受け入れの準備と送る時間をお伝えします。

媒体選びを相談する

送る時期と、誰に送るか

  • 時期は、年度の公表内容と自社の方針で：インターンの募集の時期の扱い。この記事では具体は書かない
  • 就職活動を始めたばかりの学生、仕事を知りたい学生に：本選考の文面より、インターンの文面のほうが届く。早期（低学年向け）掲載の考え方
  • プロフィールが薄い学生も、インターンなら送れることがある：「最初の週に何を任せるか」が具体なら、学生時代の一つの事実から重ねられる
  • 早期の学生には、「選考の話はしない」を守る：文面でも、話す場でも
  • 絞り込みは、インターンの「こんな人」から：本選考の「こんな人」と違うことがある

「早期の学生には選考の話をしない」は、インターンに誘うスカウトで特に守ることです。学年と時期の扱いは、年度の公表内容と自社の方針を確認します。

参加後の連絡

インターンに参加した学生との関係は、参加後に続きます。

  1. 参加の翌日までに、一言：「〇〇の下調べ、△△が助かっていました」
  2. 振り返りの場で、聞いたことを記録する：「行ってみて、掲載や文面と違ったことは」
  3. 本選考の時期が来たら、年度の公表内容と自社の方針に沿って案内する：参加者への扱いは、書いたとおりに
  4. 参加者の話を、次の年のインターンの掲載と文面に：本人の同意のうえで
  5. 参加者の体験談が書かれたら、読む：「文面どおりだった」「違った」

「振り返りで聞いたことを記録する」で、次の年の文面と掲載の材料が集まります。

社内の分担

作業誰が
最初の週に任せること、誰が見るかを決めるインターンの担当と責任者
選考との関係を、年度の公表内容と自社の方針で確認する人事
自社のインターンの体験談を読む人事
文面の2段目と3段目を型に人事（担当者に聞いて）
プロフィールを読み、一文を書く送る人（インターンの担当か、過去の参加者に近い社員）
話す場に出るインターンの担当と、過去の参加者
参加後の連絡と振り返りの記録人事とインターンの担当

運用代行や代理店が支えられるのは、インターン向けの4段の型、体験談の読み方の観点、受け入れの準備の項目、参加後の連絡の型までで、任せる仕事の決定、担当者の確保、選考との関係の判断、話す場に出ることは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これをやる前に、先に決めておかないと文面が書けないことがあります。「最初の週に何を任せるか」と「選考との関係」の二つです。当社がワンキャリアでインターンに誘うスカウトを支えるとき、4段の型は当社が出せますが、2段目の「最初の週に〇〇を任せます」は担当者にしか言えず、3段目の「選考とは〇〇です」は年度の公表内容と自社の方針を確認した人事にしか言えません。この二つが決まっていないまま送ると、文面は「実践的なインターンにご参加ください」に戻り、学生は体験談を読んで判断し、受諾しません。当社が最初にお願いするのは、担当者に「最初の週の仕事を一つ」を聞き、人事に「選考との関係を一文で」を確認してもらうことです。二つの一文が揃えば、インターンへの誘いは書けます。

まとめ

  • インターンに誘うスカウトは「仕事を体験する入口」を渡すもの。本選考の文面をそのまま使わない
  • 文面の4段は、学生時代の場面を読んだ一文→インターンで最初の週に任せることとの重なり（何を任せ、誰が見て、終わったら何が残るか）→選考との関係の一文（年度の公表内容と自社の方針で確認、曖昧にしない、書いたら守る）→担当者と過去の参加者と話す場
  • 自社のインターンの体験談を読んでから送り、「掲載と違った」があれば先にインターンの中身を直す
  • 受け入れの準備（最初の週の仕事、担当者、期間、報酬と時間、終わりの形、選考との関係）を先に済ませる
  • 時期は年度の公表内容と自社の方針で。早期の学生には選考の話をしない。参加後は翌日の一言と振り返りの記録

よくある質問

インターンに来てほしい学生に、本選考の話もしたほうがよいですか

インターンの文面では、選考との関係を一文で書くだけにし、本選考の誘いはしません。関係の有無は、年度の公表内容と自社の方針を確認して書き、書いたら守ります。早期の学生は特に、選考の話が前面に出ると身構えます。本選考の案内は、参加後に、年度の公表内容と自社の方針に沿って行います。

過去の参加者に、話す場に出てもらうのは難しいです

出られる人がいなければ、担当者だけで話す場を開き、文面の4段目にはその旨を書きます。過去の参加者の話は、本人の同意を得た範囲で、担当者が「去年の参加者はこう言っていた」と伝える形でも足ります。参加後の振り返りで「来年、話す場に出てもらえるか」を聞いておくと、次の年に出てもらいやすくなります。

インターンにスカウトでつなぐ運用は、御社に相談できますか

できます。当社は、インターン向けの4段の型、体験談の読み方の観点、受け入れの準備の項目、参加後の連絡の型を支えられます。任せる仕事の決定、担当者の確保、選考との関係の判断、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • ワンキャリアのスカウト文面の書き方｜学生時代を読んだ一文→最初の1年との重なり→選考で何を見るかの一文→話す場か選考か、の4段を短く
  • ワンキャリアのスカウトの書き出しの工夫｜一覧や通知で最初に見える一文に、会社名ではなく「学生時代の何を読んだか」を置く
  • ワンキャリアのスカウトの基本｜誰に何を送るか｜体験談を読み込んでいる学生に、「あなたのここを読んだ」と「うちの選考はこう」を短く送る
  • ワンキャリアのスカウトを相手ごとに変える範囲｜全部を書き換えるのでも大学名だけ差し替えるのでもなく、「学生時代を読んだ一文」と「最初の1年との重なり」の2か所を変える
