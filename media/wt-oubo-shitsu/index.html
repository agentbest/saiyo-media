Wantedlyの応募者の質が合わないときの直し方

公開 2026-09-12

Wantedlyで、話を聞きに来る候補者はいる。ところが、面談で話すと、募集の意図と合わない。経験が違う、求める動き方が違う、条件の認識が違う。「応募者の質が低い」と感じる。結論から言うと、「質が低い」ではなく、「募集の意図と合わない」と捉えます。合わない人が来るのは、記事が合わない人にも「自分のことか」と読める形になっているからです。理由は四つ。「何をやるか」が広く誰にでも当てはまる、求める動き方が書かれていない、条件が書かれておらず条件で来る人と合わない、タイトルが職種名だけで職種で来る。面談で「なぜ来たか」を聞いて理由を集め、合う人だけが来る書き方に絞ります。来る人が減ることを受け入れ、合わない人にも面談で丁寧に、スカウトで合う人に届けます。 この記事では、「質が低い」と捉えると直せない理由、四つの理由、面談で聞くこと、絞る書き方、減ることの受け入れ、面談での対応、スカウト、分担を整理します。応募が来ない場合はWantedlyで応募が来ないときに疑う原因、反応を見て直す手順はWantedlyの募集記事の反応を見て直す手順で書きました。

この作業の目的｜記事を、「合う人にだけ届く」形にする

Wantedlyの募集記事は、誰でも読めます。合わない人が来るのは、記事が合わない人にも届く形になっているからで、来た人のせいではありません。

目的は、記事を「合う人には自分のことに読め、合わない人には自分のことに読めない」形に絞ることです。来る数を増やすことではなく、来る人を合わせることです。

「質が低い」と捉えると、直せない

  • 「質」は、候補者の側の属性に見える：直すのは記事なのに、候補者を選別しようとする
  • 「合わない」は、記事と候補者の間の問題：記事を直せば、来る人が変わる
  • 「質が低い」と面談で感じると、態度に出る：候補者の側に残り、記事にも会社にも良くない
  • 「合わない」の中身を、面談で聞ける：「なぜ来たか」を聞くと、記事のどこで「自分のことか」と思ったかが分かる
  • 「質」ではなく、「募集の意図とのずれ」で見る：ずれの場所が、直す場所

「合わない人が来る」は、記事が発している信号の結果です。信号を変えれば、来る人が変わります。

合わない人が来る、四つの理由

理由何が起きているか直し方
1. 「何をやるか」が広い「〇〇の業務全般」「△△に関わる仕事」で、どんな経験の人でも「自分にもできそう」と読める最初の数か月の場面で具体に。誰にでも当てはまる書き方をやめる
2. 求める動き方が書かれていない「自分で決めて進める」のか「決められたことを正確に」なのかが書かれておらず、逆の人が来る求める動き方を、行動で一段落。「こういう人には向かない」も書いてよい
3. 条件が書かれていない条件が書かれておらず、条件で選んでいる人が「条件が良いかも」で来て、面談で合わない条件を最後に短く、事実で。隠さない
4. タイトルが職種名だけ「エンジニア」「営業」で、その職種名で探している人が全員来る「何をする人を探しているか」をタイトルに

四つは、面談で「なぜ来たか」を聞くと、どれかが見えます。「業務内容を見て、自分にもできそうだと」なら「1」、「エンジニアの募集だったので」なら「4」です。

いま使っている媒体の運用の相談だけでも構いません。合わない人が来る理由が四つのどれかを、面談の記録から一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは若い層が多いから、経験のある候補者は来ない」というものです。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、「合わない人が来る」と言う会社の記事を読むと、「何をやるか」が広く、求める動き方が書かれておらず、条件がなく、タイトルが職種名だけで、どんな候補者にも「自分のことか」と読める形になっています。この記事に、経験のある候補者が来ないのではなく、経験のある候補者が「自分のことだ」と思う材料がないのです。当社が「合わない」の相談を受けるとき、最初にやるのは、候補者の層の話ではなく、記事を「合う人にだけ自分のことに読める」形に絞ることです。絞ると、来る数は減り、来る人が変わります。

面談で、「なぜ来たか」を聞いて理由を集める

  • 面談の最初に、「記事のどこを見て、話を聞きに来ようと思ったか」を聞く：「なぜ来たか」ではなく、「記事のどこで」
  • 答えを、四つの理由に分類する：「業務内容が広かった」「動き方が書かれていなかった」「条件が」「職種名で」
  • 合う人にも聞く：合う人が「自分のことだ」と思った箇所が、記事に残す箇所
  • 合わない人が多く挙げる箇所が、直す箇所
  • 面談の記録に、一行で残す：「来た理由：〇〇。合う度合い：△△」

面談で聞く言葉を材料にする手順はWantedlyの募集記事の反応を見て直す手順の「面談で聞く言葉を、材料にする」で書きました。

合う人だけが来る、書き方

「何をやるか」を、絞る

  • 最初の数か月の場面で、一つの仕事を具体に：「〇〇の案件を、△△の形で、先輩と二人で」
  • 「業務全般」「幅広く」を消す
  • その仕事に要る経験や関心を、行動で：「□□を自分で作ったことがある人」
  • 書き方はWantedlyの募集記事「こんなことやります」の書き方

求める動き方を、書く

  • 「自分で決めて進める」か「決められた型で正確に」か：どちらかを明記
  • 「こういう人には向かないかもしれません」を、一文書いてよい：「指示を待って動く形が合う人には、窮屈かもしれません」
  • 「どうやっているのか」を、その募集のチームの場面で：Wantedlyの募集記事「どうやっているのか」の書き方

条件を、最後に短く書く

  • 勤務地、働き方の形、給与の扱い：自社の制度と管理部門で確認して、事実で
  • 条件で来る人と合わないなら、条件を書くことで、条件で選ぶ人が先に判断できる
  • Wantedlyの募集記事に条件をどこまで書くか

タイトルを、「何をする人か」にする

  • 「エンジニア募集」→「〇〇の△△を、自分で決めて作る人」
  • 職種名で探している人が全員来る形から、その仕事をしたい人が来る形へ
  • Wantedlyの募集タイトルの付け方

来る人が減ることを、受け入れる

  • 絞ると、「話を聞きに行く」の数は減る：合わない人が来なくなる分
  • 減った分は、面談の時間が減った分：合わない人との面談に使っていた時間が戻る
  • 見るのは、来た数ではなく、来た人のうち合う人の数：合う人の数が変わらなければ、絞りは成功
  • 上司に「減る」と先に伝える：「来る数は減るが、面談の時間あたりで合う人は増える」
  • 減りすぎたら、絞りすぎ：「何をやるか」が狭すぎるか、「向かない人」の書き方が強すぎる。一か所戻す

「減る」を受け入れないと、絞れません。数字の読み方はWantedlyのスカウトの効果測定で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。記事を絞って、合う人にだけ届く形にする時間をお伝えします。

媒体選びを相談する

合わない人にも、面談で丁寧に

  • 合わないと分かっても、面談は「お互いを知る場」として最後まで：選考ではない
  • 「今回の募集とは合わないかもしれません」を、面談の中で正直に：理由を添えて。「今回は〇〇の経験がある方を探していて」
  • 別の募集があれば、案内する：「△△の募集のほうが近いかもしれません」
  • 候補者の側に、「話を聞いてよかった」が残る形で終える：Wantedlyでは、候補者が会社の印象を周りに伝えることがある
  • 合わない人との面談から、記事の直す箇所を拾う：無駄な面談ではなく、材料の場

カジュアル面談の設計はWantedlyのカジュアル面談の設計で書きました。

スカウトで、合う人に届ける

  • 記事だけで待つと、記事を読んだ全員が来る：絞っても、合わない人がゼロにはならない
  • スカウトで、合う人を選んで「この記事を読んでほしい」と届ける：来る人を、送る側で選べる
  • スカウトの文面で挙げた「重なり」を、記事に置く：文面と記事がつながる
  • スカウトの相手の選び方はWantedlyのスカウトのターゲット、つなぎ方はWantedlyのスカウトと募集記事のつなげ方

「合わない人が来る」は、記事を絞ることと、スカウトで届けることの、両方で直ります。

エージェントベストの見解

これは向き不向きの話です。Wantedlyで「合う人だけが来る」形に向いているのは、「何をやるか」と「求める動き方」を、狭く具体に書ける会社です。向いていないのは、「誰でもいいから多く来てほしい」会社で、その会社は、記事を広く書き、多く来て、面談で選ぶ形になり、面談の時間で消耗します。当社が申込前に確かめるのは、「この募集で、最初の数か月に何をするかを、一つの場面で言えますか」です。言えれば、記事は絞れ、合う人が来ます。言えなければ、記事は広くなり、合わない人が来て、「質が低い」という感じ方になります。「質」の問題ではなく、「絞れるか」の問題です。

まとめ

  • 「質が低い」ではなく「募集の意図と合わない」と捉える。合わない人が来るのは、記事が合わない人にも「自分のことか」と読める形だから
  • 四つの理由は、「何をやるか」が広い・求める動き方がない・条件がない・タイトルが職種名だけ。面談で「記事のどこを見て来たか」を聞いて絞る
  • 「何をやるか」を最初の数か月の場面で、求める動き方を行動で（「向かない人」も一文）、条件を最後に短く、タイトルを「何をする人か」に
  • 絞ると来る数は減る。見るのは来た数ではなく、来た人のうち合う人の数。上司に「減る」と先に伝える
  • 合わない人にも面談で丁寧に、正直に伝え、材料を拾う。スカウトで合う人に届け、記事だけで待たない

よくある質問

「向かない人」を書くと、印象が悪くなりませんか

「〇〇が合う人には窮屈かもしれません」のように、相手を否定せず、自社の動き方を事実として書く形なら、印象は悪くなりません。むしろ、合う人には「正直な会社」として残り、合わない人は来る前に判断できます。書くのは一文で、記事の中心にはしません。

絞ったら、来る人がほとんどいなくなりました

絞りすぎです。「何をやるか」が狭すぎるか、「向かない人」の書き方が強すぎるか、条件の書き方が冷たいか。一か所ずつ戻して、一か月見ます。同時に、記事だけで待たず、スカウトで合う人に届ける形を足します。絞った記事は、スカウトで届けたときに、合う人に「自分のことだ」と読まれやすくなっています。

応募者が合わないときの見直しは、御社に相談できますか

できます。当社は、四つの理由の切り分け、面談で聞く言葉の型、絞る書き方の型、条件とタイトルの整理、スカウトとのつなぎ方を支えられます。面談で聞くこと、場面を話すこと、書くこと、合う・合わないの判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

媒体選びを相談する

あわせて読む

  • Wantedly経由の入社者が早期離職したとき｜「共感で来た人ほど、読んだ会社と入った会社の差に敏感」
  • Wantedlyで応募が来ないときに疑う原因｜読まれているのに来ないなら、原因は「話を聞きに行く理由がない・行った先が見えない・条件で止まる・会社ページで止まる」の四つ
  • Wantedlyの募集記事が読まれないときの見直し順｜「読まれない」を「一覧で開かれない」と「開かれても読み進められない」に分け、タイトル→冒頭→本文→会社ページ→社員の動きの順に一か所ずつ直す
  • 知名度がない会社がWantedlyで読まれるには｜Wantedlyの候補者は会社名ではなく「なぜ」と「人」で読む
