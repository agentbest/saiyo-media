Wantedlyの会社ページでミッションを伝える書き方｜由来と判断での使われ方

会社ページの「なぜやるのか」の中心に、ミッションを置く会社は多くあります。ところが、ミッションの言葉だけを載せても、候補者には伝わりません。結論から言うと、ミッションを伝えるとは、一文を載せることではなく、その言葉が生まれた場面と、日々の判断でどう使われているかと、まだできていないことを書くことです。この3つがあって、ミッションは候補者の中で意味を持ちます。 ミッションが無い会社は、代表の「なぜやるのか」の原体験から言葉を抽出しますが、無理に作りません。作ったミッションは、読めば分かります。この記事では、ミッションの位置づけ、ある場合と無い場合の手順、書き方の型、やりがちな失敗、代表と人事の分担を整理します。会社ページ全体の書き方は会社ページで最初に書くことで書きました。

この作業の目的｜掲げた言葉を、候補者が「自分ごと」にできる形にする

ミッションの一文は、社内の人には意味が通じます。何年もその言葉で仕事をしてきたからです。候補者には、その積み重ねがありません。「〇〇で世界を変える」と読んでも、何をどう変えるのか、自分がそこで何をするのかが分かりません。

ミッションを伝える目的は、その言葉を候補者が「自分ごと」にできる形にすることです。言葉が生まれた経緯を読めば、代表が何を見て何を思ったかが分かります。日々の判断での使われ方を読めば、入社したら自分もその判断をすることが分かります。まだできていないことを読めば、自分が何をしに入るのかが分かります。

言葉だけでは、候補者は「立派な言葉」で終わります。3つが揃うと、「自分がやること」に変わります。

手順1｜ミッションがある会社は、具体的な出来事で補う

すでにミッションの言葉がある会社は、その言葉をエピソードで補います。

書くこと内容
ミッションの文言言葉そのもの。変えない
言葉が生まれた場面誰が、いつ、何を見て、この言葉になったか。創業のきっかけ、転機になった出来事
日々の判断での使われ方最近、この言葉を理由に何かを決めた例。「〇〇を断った」「△△を優先した」のような具体的な判断
まだできていないことミッションに対して、いまどこまで来ていて、何が残っているか。正直に
候補者に何をしてほしいか残っていることのうち、入社した人が関わる部分

「日々の判断での使われ方」が、最も伝わる部分です。ミッションを理由に何かを断った、選んだ、変えた、という出来事があれば、その言葉が飾りではないと分かります。無ければ、ミッションは飾りになっていて、候補者にもそう見えます。

「まだできていないこと」を書くのは、候補者が「自分の役割」を想像するためです。すべてできている会社に、候補者は入る理由を見つけられません。

手順2｜ミッションが無い会社は、「なぜ」の原点から抽出する。無理に作らない

ミッションの言葉が無い会社は、作るかどうかを先に決めます。

  1. 代表の「なぜやるのか」のきっかけを、先に書く：書き方は会社ページの基本の記事で
  2. その話の中に、繰り返し出てくる言葉を探す：「困っている人を放っておけなかった」「〇〇が当たり前になる状態にしたい」など
  3. 繰り返し出てくる言葉があれば、それを短い言葉にまとめる：新しく考えるのではなく、すでにある言葉を整える
  4. 無ければ、作らない：「なぜやるのか」の話だけで、会社ページは成立する。ミッションの欄は「私たちのなぜ」として具体的な経緯を書く
  5. 社内の数人に、その言葉を言ってもらう：代表以外の人が自分の言葉で言えなければ、まだ社内のものになっていない。会社ページに載せる前に、社内で使う

「無理に作らない」を強く書くのは、作ったミッションが、候補者にも社内にも響かないからです。作ったミッションは、日々の判断で使われず、裏付けになる出来事が無く、言葉だけが浮きます。ミッションが無くても、「なぜやるのか」が具体的に書かれていれば、候補者は共感できます。共感の入口は共感型と条件型の媒体の違いで書きました。

会社の想いがすでに言葉になっているか、整理するだけでも媒体は絞れます。相談だけでも構いません。

媒体選びを相談する

エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは共感で集める媒体だから、ミッションが無いと使えない」というものです。実際には、Wantedlyで候補者が読むのは、ミッションの一文より、「なぜやるのか」の場面と、日々の仕事の様子です。当社は採用媒体の代理店としてWantedlyの契約後の運用を見ていますが、ミッションの言葉が無くても「なぜ」の中身が具体的な会社には候補者が来ていて、立派なミッションがあっても裏付けの話が無い会社には来ていません。ミッションは、あればエピソードで補い、無ければ作らずに「なぜ」の原点を書く。Wantedlyを始めるためにミッションを作る、という順番は逆です。ミッションは、事業を続ける中で言葉になるもので、会社ページのために作るものではありません。無い会社は、無いまま始めて構いません。

手順3｜書き方の型

ミッションの部分を、次の型で書きます。長さは、エピソードが具体的なら短くて足ります。

  1. ミッションの言葉：あれば。無ければ「私たちがやっている理由」のような見出しで
  2. 言葉が生まれた経緯：「〇年前、代表が△△を見て、□□と思った」。1つの出来事を、状況と感じたことで
  3. いまの判断：「先月、〇〇の依頼を断った。理由は△△だから」。最近の1つ
  4. まだできていないこと：「〇〇はできたが、△△はまだ」。正直に
  5. 入る人へ：「△△を、一緒にやってくれる人を探している」

「経緯」と「いまの判断」は、代表にしか書けません。人事が想像で書くと、抽象語になります。代表に話してもらい、書き起こし、本人に直してもらう。この手順は会社ページの基本の記事で書いたとおりです。

手順4｜候補者がミッションのどこを読むか

候補者は、ミッションの部分を「自分が合うか」で読みます。読み方を知っておくと、書くことが決まります。

候補者が見ること書く側が用意すること
この言葉は本気か、飾りか日々の判断での使われ方。断った例があれば本気と伝わる
自分の価値観と合うかエピソードの中の「感じたこと」。代表が何に怒り、何を喜んだか
自分の役割があるかまだできていないこと
入社後もこの言葉で判断されるかいまの判断が、最近のものであること
社員もこの言葉を使っているかストーリーやメンバーの紹介で、社員が同じ言葉を使っているか

最後の「社員も使っているか」は、会社ページのミッションの部分だけでは伝わりません。ストーリーや、メンバーの紹介で、社員が自分の言葉でミッションに触れていると伝わります。メンバーの選び方は会社ページに載せるメンバーの選び方で書きます。

手順5｜ミッションと事業のずれを確かめる

ミッションと、実際の事業や仕事の中身がずれていると、候補者は面談で気づきます。書く前に確かめます。

  • ミッションから、いまの主な事業が説明できるか：説明できないなら、ミッションが古いか、事業が変わっている
  • ミッションから、募集している仕事が説明できるか：説明できないなら、募集記事とミッションが別々に見える
  • ミッションと違う判断を、最近していないか：していれば、その理由も書くか、ミッションを見直す
  • 社員が「うちのミッションは」と聞かれて言えるか：言えなければ、社内のものになっていない

ずれがあるなら、会社ページに書く前に、ずれの扱いを決めます。ミッションを直すか、事業との関係を説明するか、ミッションを載せずに「なぜ」の話だけにするか。ずれたまま載せるのが、最も候補者に見抜かれます。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。会社ページの「なぜ」を書き起こす時間も含めてお伝えします。

運用の相談をする

やりがちな失敗

失敗何が起きるか直し方
一文だけを載せる立派な言葉で終わる経緯、判断、できていないことを足す
壮大すぎて事業とつながらない何をする会社か分からないミッションから事業と仕事を説明できるか確かめる
会社ページのために作る飾りになり、読めば分かる無ければ作らず「なぜ」の原点を書く
人事が書く借りてきた言葉になる代表が話し、書き起こし、本人が直す
日々の判断が書かれていない本気か飾りか分からない最近の判断を1つ
全部できているように書く候補者の役割が無いまだできていないことを正直に
社員が言えない言葉を載せる面談で「社内では使っていない」と分かる社内で使ってから載せる
ミッションと違う判断を隠す面談で気づかれる理由を書くか、見直す

最も多いのは、「一文だけを載せる」です。ミッションは載せた。それで伝わったと思う。候補者には伝わっていません。

社内の分担

作業誰が
ミッションがあるか、作るかを決める代表
言葉の原点と、いまの判断を話す代表
書き起こし、型に整える人事
本人が直す代表
事業と仕事とのずれを確かめる人事（事業部門に確認）
社員が言えるかを確かめる人事（数人に聞く）
まだできていないことを整理する代表と人事

代表の時間は、「話す」と「直す」の2つです。書くのは人事です。運用代行や代理店が支えられるのは、書き起こしと型への整理、抽象語の指摘までで、原体験と判断は代表にしか出せません。

エージェントベストの見解

申し込んだあと、Wantedlyで数ヶ月経った会社の会社ページを見ると、ミッションの部分が契約時のままで、「いまの判断」が古くなっていることがあります。契約時に書いた「先月、〇〇を断った」が、半年前の話になっている。候補者には「最近は判断していないのか」と映ります。当社がWantedlyの運用の相談を受けるときは、ミッションの部分のうち「いまの判断」だけは、数ヶ月に一度、最近の出来事に差し替えることを勧めます。一文と、言葉が生まれた場面は変わりません。変わるのは、日々の判断と、できていないことの進み具合です。ここを更新すると、ミッションが「生きている言葉」として候補者に届きます。更新しないと、どれだけ良い言葉でも、飾りに戻ります。ミッションの部分は、書いて終わりではなく、判断のたびに足していくものです。

まとめ

  • ミッションを伝えるとは、一文を載せることではなく、言葉が生まれた場面、日々の判断での使われ方、まだできていないことを書くこと
  • ある会社は具体的なエピソードで補う。無い会社は代表の「なぜ」から抽出し、無ければ作らない
  • 原点の話と判断は代表にしか出せない。話してもらい、書き起こし、本人が直す
  • 候補者は「本気か飾りか」「自分の役割があるか」で読む。断った例と、できていないことが答えになる
  • ミッションと事業や仕事のずれを、載せる前に確かめる。「いまの判断」は数ヶ月に一度差し替える

よくある質問

ミッションが無いのですが、Wantedlyを始められますか

始められます。会社ページの「なぜやるのか」を、代表の体験で書けば、ミッションの言葉が無くても候補者は共感できます。会社ページのために無理にミッションを作ると、飾りになり、読めば分かります。事業を続ける中で言葉になったら、そのときに載せます。

ミッションが壮大で、募集している仕事とつながりません

ミッションから、いまの事業と募集している仕事が説明できるかを確かめます。説明できないなら、「いまはミッションのうち、この部分をこの事業でやっている」と関係を書くか、会社ページではミッションの文言より「なぜ」の原点を中心にします。ずれたまま載せると、面談で気づかれます。

ミッションの書き起こしは、御社に頼めますか

代表に話していただいた内容の書き起こしと、型への整理、抽象語の指摘は当社が行えます。原体験と判断は代表にしか出せないので、話す時間と直す時間はいただきます。当社は採用媒体の代理店として、Wantedlyの会社ページの整備を支えています。
