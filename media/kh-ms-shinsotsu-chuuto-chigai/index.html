新卒と中途で面接の見方をどう変えるか

採用ノウハウ面接・選考設計 更新日 2026/11/3

新卒採用と中途採用の両方をしている会社で、同じ面接官が同じ質問リストで両方を面接していることがあります。結論から言うと、新卒と中途では「見るもの」の軸を変える必要があります。新卒は「これからどう伸びるか」を過去の行動の履歴から読み、中途は「同じことがこの会社でもできるか」を実績の中身から確かめます。 軸を変えずに面接すると、新卒には答えようのない質問をし、中途には実績の確認が薄い面接になります。この記事では、新卒と中途で何が違うのか、質問の作り方、評価の軸、面接官の選び方、両方を同じ会社でやるときの混同の避け方を整理します。未経験者・経験者という切り口の話は未経験者の面接で見ることと経験者の面接で見ることに分けています。

新卒と中途で何が違うのか

面接の前に、候補者の側の違いを押さえておきます。

観点新卒中途
判断の材料仕事の実績はほぼない。学業・課外活動・アルバイトの行動前職での実績と役割
候補者が決めている時期複数社を並行して見て、最後に決める転職の理由が先にあり、それが解消される会社を選ぶ
入社後の立ち上がり教える前提。配属先が後で決まることもある役割が決まっていて、早く任せる前提
面接で候補者が知りたいこと自分がやっていけるか、どんな人と働くか転職の理由が解消されるか、条件と役割
時期年間のスケジュールに沿って同時期に多数通年。欠員や増員のたびに個別に

最も大きな違いは、判断の材料です。新卒には実績がないので、「何をしたか」ではなく「どう考えて動いたか」を聞くしかありません。中途には実績があるので、「何をしたか」を具体的に確かめることが面接の中心になります。この違いが、質問と評価の軸を変える理由です。

新卒の面接で見る軸

新卒の面接では、次のような軸で見ます。

  1. 行動の履歴：何かに取り組んだとき、どう考え、どう動いたか。結果の大きさより、考えて動いた過程
  2. 学ぶ姿勢：分からないことにどう向き合ってきたか。人に聞くか、自分で調べるか、放置するか
  3. 人との関わり方：集団の中でどんな役割を取ることが多いか。前に出るか、支えるか、調整するか
  4. 会社の理解：会社が何をしている会社かを、自分の言葉で言えるか。志望の理由が会社の実態に沿っているか

結果の大きさで評価しないことが要点です。学生時代の活動の結果は、環境と運の影響が大きく、仕事での再現性を保証しません。「大会で優勝した」より「負けたあとに何を変えたか」のほうが、入社後の行動を予測する材料になります。

質問は、「〜のとき、あなたはどうしましたか」という行動を聞く形にします。「あなたの強みは何ですか」のような自己評価を聞く質問は、準備した答えが返ってくるだけで、行動の履歴が見えません。

中途の面接で見る軸

中途の面接では、軸が変わります。

  1. 実績の中身：前職で何を担い、何を達成したか。そのうち本人の寄与はどこまでか
  2. 再現性：その実績が、この会社の環境・規模・道具でも出せるか
  3. 転職の理由：前職の何を変えたくて転職するのか。それがこの会社で解消されるか
  4. 役割の受け止め：募集している役割を正しく理解しているか。期待と本人の希望がずれていないか

実績は、聞き方で見え方が変わります。「売上を伸ばしました」という答えには、「チームの中で自分が担った部分はどこか」「前任者から引き継いだ時点の状態はどうだったか」「同じことを環境の違う場所でやるとしたら、何を変えるか」と重ねて聞きます。実績を分解して聞く方法は経験者の面接で見ること｜実績の聞き方で詳しく書いています。

転職の理由は、中途の面接でしか聞けない項目です。理由が「前職の人間関係」であれば、この会社でも同じことが起きないかを本人と一緒に考えます。理由が「やりたい仕事ができなかった」であれば、この会社でそれができるかを正直に答えます。理由が解消されない転職は、入社後の早い時期の離職につながります。

新卒と中途で媒体を分けるか、面接の設計を分けるか、一度整理してみませんか。

媒体選びを相談する

エージェントベストの見解

相談で多い思い込みは、「中途は実績を見ればいいので、新卒より面接は楽だ」というものです。実際には、実績は本人の寄与とチームの寄与が混ざっていて、分解しないと判断に使えません。新卒の面接のほうが、行動を聞くという一つの型で進められる分、慣れれば楽になります。当社は新卒の媒体と中途の媒体の両方を扱い、人材紹介で中途の候補者を企業に送る側にもいます。その立場で見ると、中途の面接で判断を誤りやすいのは、実績が大きい候補者より「実績の説明が上手い候補者」です。説明が上手いと、分解せずに納得してしまいます。中途の面接では、話の上手さと実績の中身を分けて聞く設計を先に用意しておくことを勧めます。具体的には、どの実績にも「あなた一人でやった部分はどこか」と聞くと決めておく。これだけで、話の上手さに流される面接が減ります。

面接官の選び方を変える

見る軸が変わるので、面接官も変えます。

新卒の面接官に向くのは、入社から数年の若手社員と、新人を育てた経験のある社員です。若手は、候補者の学生時代の話を自分の経験と重ねて聞けます。新人を育てた社員は、「この人は教えれば伸びるか」を入社後の姿で想像できます。経営者や役員は、学生時代の話から潜在的な力を読むのが得意とは限りません。

中途の面接官に向くのは、その役割の実務を知っている人です。実績の中身を確かめるには、その仕事を知っている人が聞くしかありません。営業の中途を人事だけで面接すると、実績の話を分解できず、話の印象で決まります。現場の責任者か、同じ職種の社員を面接に入れます。

両方に共通して避けたいのは、「新卒と中途の両方を同じ面接官が同じ日に見る」ことです。頭の切り替えが追いつかず、新卒に実績を求め、中途に潜在的な力の話を求める面接になります。日を分けるか、面接官を分けます。

同じ会社でやるときの混同を避ける

新卒と中途の両方を採用している会社で起きる混同を、先に挙げておきます。

  • 質問リストを使い回す：新卒用の「学生時代に力を入れたこと」を中途に聞く、中途用の「前職の実績」を新卒に聞く。リストは分けます
  • 評価の言葉を使い回す：新卒の「伸びそう」と中途の「できそう」は違う評価です。記録の項目を分けます
  • 選考の長さを同じにする：新卒は複数社を並行して見るので、選考が長いと他社に決まります。中途は転職の理由が切実な人ほど早く決めたい。どちらも長引かせない理由は違いますが、短くする方向は同じです
  • 合格の基準を同じにする：新卒は「教えれば三年後に戦力になるか」、中途は「数か月で役割を担えるか」で、時間の軸が違います

評価の記録は、新卒と中途で項目を分けた記録表を用意するのが簡単です。同じ表で両方を評価すると、どちらかに合わない項目が空欄になり、評価が偏ります。面接の記録の残し方は、評価を後で比べられる形にしておくことが要点です。

新卒の媒体と中途の媒体で、面接に入ってくる候補者の状態が違います。媒体ごとの違いからご案内します。

無料で相談する

エージェントベストの見解

新卒と中途の面接の設計を見直すとき、先に決めておかないと効果が出ないのは「この会社は、新卒と中途のどちらを主に育てる会社か」です。両方を同じ比重で採る会社は多くありません。新卒を主に採る会社は、面接も育成の前提で設計し、中途は不足した役割を埋めるための例外として扱います。中途を主に採る会社は、面接を実績の確認で設計し、新卒は長期の投資として別の基準を置きます。この主従を決めずに両方の面接を同じ水準で整えようとすると、どちらも途中で止まります。当社が複数の媒体を扱って見ている範囲では、新卒の媒体と中途の媒体を同じ年に始めた会社で、両方の運用が続く例は多くありません。先に主にするほうの面接を整え、もう一方は最小限の型だけ用意する。この順番で進めると、面接の設計が会社の実態に合います。

媒体による候補者の状態の違い

新卒と中途では、候補者が面接に来るまでの経路も違います。OfferBoxのように企業から学生にオファーを送る新卒の媒体では、候補者は会社のことをオファーの文面でしか知らない状態で面接に来ます。面接の冒頭で会社の説明に時間を使う必要があります。中途の求人媒体から応募してくる候補者は、求人票を読んで自分で応募しているので、会社の説明は短くて済み、その分を実績の確認に使えます。ワンキャリアのように企業ページと選考体験談を学生が読む媒体では、候補者は選考の流れを先に知っていることが多く、面接の進め方が事前の情報と大きく違うと不信につながります。どの媒体から来た候補者かで、面接の冒頭の配分を変えます。

まとめ

  • 新卒は「これからどう伸びるか」を行動の履歴から、中途は「同じことがここでできるか」を実績の中身から見る
  • 新卒には行動を聞く質問、中途には実績を分解する質問と転職の理由を聞く質問を用意する
  • 新卒の面接官は若手と育成経験のある社員、中途の面接官はその役割の実務を知る人
  • 質問リスト・評価の記録・合格の基準を新卒と中途で分け、使い回さない
  • 新卒と中途のどちらを主に採る会社かを先に決め、主にするほうの面接から整える

よくある質問

第二新卒の面接は、新卒と中途のどちらの軸で見ればよいですか

実績が少ない点では新卒に近く、働いた経験がある点では中途に近い層です。基本は新卒の軸で行動の履歴を見ながら、「前職を短い期間で離れた理由」だけは中途の軸で確かめます。理由がこの会社でも繰り返される種類のものかを、本人と一緒に考えます。

新卒と中途で面接の回数は変えるべきですか

回数より、各回の役割を変えます。新卒は会社を知ってもらう場を一つ多く置くことがあり、中途は実績を確かめる場に現場の責任者を入れることが多くなります。回数そのものは、会社の規模と候補者の状況で決めます。

中途で未経験の職種に応募してきた候補者は、どちらの軸で見ますか

実績の軸では見られないので、行動の履歴の軸に寄せます。ただし、前職での仕事の進め方は実績として確かめられるので、職種は違っても「どう仕事を進めてきたか」は中途の軸で聞きます。詳しくは未経験者の面接で見ることで整理しています。
