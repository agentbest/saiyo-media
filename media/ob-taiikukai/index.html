「体育会系の学生を採りたい」という相談を受けます。理由を聞くと、「粘り強い」「上下関係に慣れている」「営業に向いている」という言葉が出てきます。結論から言うと、この理由のまま文面を書くと、学生には「属性で見られている」と伝わり、承認されません。部活動に打ち込んできた学生にアプローチするときに触れるのは、競技の成果でも「体育会系だから」でもなく、続けた理由、チームでの役割、うまくいかなかったときの動き方です。 これは他の学生と同じで、自由記述から行動の型を拾う作業です。違うのは、時期と日程への配慮です。この記事では、読み方、文面の入り方、時期と日程、選考の速さ、名義、やりがちな失敗、人事と現場の分担を整理します。文面の基本はオファー文面の基本で書きました。

この作業の目的｜「体育会系」という言葉を、行動の型に戻す

「体育会系」は、学生を分類する言葉として便利ですが、文面や面談で使うと、学生を1つの型に押し込めます。同じ部活動でも、続けた理由、チームでの役割、競技への向き合い方は学生ごとに違います。

「粘り強い」と一括りにされた学生は、「自分の何を見たのか」が分からず、文面を閉じます。「〇〇の練習を、結果が出ない時期も続けた理由が書かれていて」と触れられた学生は、「自分を読んだ」と感じます。

この作業の目的は、「体育会系」という言葉を、その学生固有の行動の型に戻すことです。分類ではなく、読む。他の学生への文面と、原則は同じです。

手順1｜自由記述で見るところ

部活動に打ち込んできた学生の自由記述には、競技のことが書かれています。見るのは成果ではなく、次の点です。読み方の基本は学生プロフィールの読み方で書いたとおりです。

見るところ何が分かるか触れ方の型
続けた理由何のために続けたか。勝つため、仲間のため、自分を試すため「続けた理由が〇〇だと書かれていて」
チームでの役割主将、副将、マネージャー、控え、記録係。役割の中で何をしたか「〇〇の役割で、△△を工夫した、と書かれていて」
うまくいかなかったときの動き方けが、スランプ、レギュラー落ち、チームの不振。そこで何をしたか「結果が出ない時期に、こう動いた、と書かれていて」
競技以外に書かれていること学業、アルバイト、競技以外の関心。競技だけの学生と決めつけない競技以外の一文にも触れる
競技を通じて変わったこと入部時と引退時で、自分がどう変わったか「〇〇が変わった、と書かれていて」

成果（大会の順位、記録）に触れるのは避けます。成果は学生にとって誇りですが、企業が触れると「成果で選ばれた」と映り、成果が出なかった学生には届きません。触れるのは、成果に至る動き方です。

手順2｜文面の入り方

冒頭は、他の学生と同じく「読んだ・こう思った・だから送った」です。書き方はオファー文面の構成で書きました。部活動の学生の場合、「こう思った」で気をつけることがあります。

  1. 「体育会系だから」と書かない：「体育会系のあなたなら営業に向いている」は、属性で見ている。「〇〇の役割で△△を工夫した動き方が、うちの営業のこの場面に近い」と、行動と仕事でつなぐ
  2. 競技名で入らない：「〇〇部だったんですね」は読んだ証拠だが、「こう思った」が無い。競技名より、続け方や役割に触れる
  3. 根性や体力に触れない：学生は、それ以外の自分を見てほしいと思っていることが多い。行動の型で書く
  4. 仕事の場面を具体的に：営業なら「週に何社かを訪ねて困りごとを聞く」のように。部活動の役割の型と、仕事の場面の型をつなぐ。場面の作り方は文系学生にオファーを送るときの文面で書いた
  5. 競技を続けられるかを、聞かれる前に書く：社会人になっても競技を続けたい学生がいる。続けられるか、続けている社員がいるかを、分かる範囲で一言

「営業に向いている」と決めつけないのは、部活動の学生の志向が営業に限らないからです。自由記述に、企画や技術への関心が書かれていれば、そこに触れます。

いま使っている媒体の運用の相談だけでも構いません。「体育会系」を行動の型に戻す読み方を、一緒に見直します。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「体育会系の学生は営業に向いていて、粘り強く、上下関係に慣れている」というものです。実際には、部活動に打ち込んだ学生の中に、営業向きの人も、企画向きの人も、技術向きの人もいて、粘り強さの出方も人によって違います。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、「体育会系だから」で文面を書いた会社は、承認が来ないか、来ても面談で「思っていた学生と違う」となります。学生の側も、「体育会系」という言葉で見られることに慣れていて、その言葉が出た時点で「この会社は自分を読んでいない」と判断します。逆に、続けた理由や役割の工夫に触れた文面は、学生に「ここは違う」と映ります。「体育会系を採りたい」という相談が来たとき、当社が最初に聞くのは、「活躍している社員のうち、部活動出身の人は、具体的にどんな動き方をしていますか」です。その答えが、行動の型になります。「体育会系」という言葉は、ペルソナには入れません。

手順3｜時期と日程への配慮

部活動に打ち込んでいる学生は、競技の予定で動く時期が決まっています。ここが、他の学生と最も違う点です。

  • 就職活動の開始が遅い、または短期集中になる：大会のシーズンや引退の時期まで、就職活動に時間を割けない学生がいる。引退後に短期間で動く
  • 練習と遠征で、平日の日中が空きにくい：面談の日程の候補は、夕方以降や、練習が無い曜日に幅を持たせる
  • オンラインを基本にする：遠征先や練習の合間でも参加できる。進め方はオンライン面談
  • 返事が遅くても、追いかけを急がない：大会の時期は返信できない。追いかけは1回、間隔は長めに
  • 送る時期を、学生の動く時期に合わせる：引退の時期は競技によって違う。自社が採りたい学生の競技の時期を、前年の実績や本人に聞いて把握する。時期の考え方は送る時期と時間帯の考え方

「就職活動の開始が遅い」は、企業から見ると「他社より先に接点を持てる」機会でもあります。学生が動き始める前に文面を送り、動き始めたときに「あの会社」と思い出してもらう形です。ただし、動き始める前の学生に承認を急かさないことが条件です。

手順4｜選考の速さ

引退後に短期集中で動く学生は、複数の企業を同時に短期間で受けます。選考が長い企業は、その期間に他社が内定を出して離れます。

  1. 承認から内定までの期間を、他の学生より短く設計する：段階を統合し、段階の間の空白を無くす。考え方は選考フローを短くする考え方
  2. 面談の日程を、承認から近い日に：候補を出すときに、最も近い日を含める
  3. 他社の進行を聞く：短期集中の学生は他社も同時に動いている。聞き方は承認後の辞退を減らす連絡設計
  4. 内定の期限を、学生の動きに合わせる：短期間で複数の内定が出る学生には、他社の結果の時期を聞いてから期限を置く。置き方は内定を出したあとのフォロー

「速く」は「急かす」ではありません。企業側の段階の間の空白を無くすことで、学生を待たせずに進める、という意味です。

手順5｜名義と面談に出る人

社内に、部活動に打ち込んだ経験のある社員がいれば、名義と面談に出る人の候補になります。

  • 同じ経験を持つ社員が名義になる：「自分も〇〇部で、引退後に就職活動を始めた」の一言が、文面に入る。学生は「分かってもらえる」と感じる
  • ただし、競技の話だけにしない：面談で競技の話ばかりになると、仕事の話が無いまま終わる。仕事の場面を話す時間を先に取る
  • 同じ経験の社員がいなければ、無理に探さない：名義は、仕事の中身を語れる現場の社員でよい。「体育会系の学生には体育会系の社員を」も、決めつけの一つ
  • 面談で、競技を続けられるかを話せる準備をする：続けている社員がいるか、勤務の形で続けられるか。聞かれたときに答えられるように

名義の考え方は他の学生と同じです。仕事の中身を語れる人が出て、文面の続きとして話す。面談の設計は初回面談の設計で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。短期集中で動く学生に合わせた選考の速さまで含めてお伝えします。

運用代行に出す場合、自由記述から行動の型を拾って冒頭を書く作業と、日程の幅を持たせた連絡は代行が行えます。「体育会系」を行動の型に戻すペルソナの作業と、選考の統合は社内です。代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。「採りたい学生の競技の時期」を把握することです。当社がOfferBoxの運用の相談で「体育会系を採りたい」と聞いたとき、文面の話の前に確認するのは、その学生が引退するのはいつ頃で、就職活動をいつ始めるか、です。ここを把握せずに、他の学生と同じ時期に送り、同じ間隔で追いかけ、同じ長さの選考に乗せると、大会の時期に返信が来ず、引退後に動き始めたときには自社の選考が他社より遅れています。時期を把握していれば、引退前に一度文面を送って名前を知ってもらい、引退後に改めて連絡し、短い選考で内定まで進められます。時期を先に、文面はそのあと。部活動の学生へのアプローチで、最初に決めるのはこの順番です。

まとめ

  • 「体育会系」という言葉を、続けた理由・チームでの役割・うまくいかなかったときの動き方という行動の型に戻す
  • 競技の成果、根性、体力、「営業向き」で語らない。行動の型と仕事の場面でつなぐ
  • 競技の時期で就職活動の開始が遅く短期集中になる学生に、日程の幅、追いかけの間隔、送る時期で配慮する
  • 選考は段階を統合して空白を無くし、短期集中の学生を待たせない
  • 名義は仕事を語れる現場の社員。同じ経験があればなお良いが、無理に探さない

よくある質問

体育会系の学生は、営業に向いていますか

向いている人もいれば、企画や技術に向いている人もいます。「体育会系だから営業」と決めつけると、他の志向を見逃し、文面でも「属性で見られている」と伝わります。自由記述に書かれた役割の工夫や、競技以外の関心を読んで、その学生の行動の型と仕事の場面をつなぎます。

大会のシーズンで、返信が来ません。どうすればよいですか

追いかけは1回、間隔は長めにします。競技の時期は返信できないことが多く、重ねて追いかけると、しつこいと受け取られます。引退の時期を把握していれば、その後に改めて連絡する形も取れます。

体育会系の学生へのアプローチは、御社に相談できますか

できます。当社がOfferBoxの運用の相談を受けるときは、「体育会系」を行動の型に戻すペルソナの作業、競技の時期の把握、日程と選考の設計を一緒に行います。運用代行を受ける場合は、行動の型を拾って冒頭を書き、日程の幅を持たせた連絡を当社が行います。3媒体の全体像は3媒体の違いと選び方にまとめています。
