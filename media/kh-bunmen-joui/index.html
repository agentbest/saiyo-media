上位大学の学生へのスカウト文面｜3媒体で使う一つの型

上位大学の学生に向けた文面を、媒体ごとに別々に用意している会社があります。OfferBox用、Wantedly用、ワンキャリア用と分け、さらに「上位大学向け」の版まで作る。型が増えるほど手入れが追いつかず、どの媒体でも反応が伸びない。結論を先に書くと、型は媒体をまたいで一つで足ります。大学名に触れず、相手の行動を一文引き、その行動と重なる仕事の場面を書く。この骨組みは三つの媒体で変わりません。媒体ごとに変わるのは、その一文を拾う材料と、返事が来たあとの流れです。 この記事では、型を一つに保つ理由、共通の骨組み、媒体ごとの材料の違い、空欄での吸収のしかた、反応が来ないときの切り分け、上司への説明、分担を整理します。文面全体の骨組みはスカウト文面の長さの考え方で書きました。媒体ごとの掘り下げは、OfferBoxは上位大学の学生から承認が取れないときの考え方、ワンキャリアはワンキャリアで上位大学の学生にスカウトを送る考え方にあります。

型を、媒体ごと・大学ごとに分けない理由

型を分けたくなる気持ちは分かります。媒体ごとに画面も送れる内容も違い、上位大学の学生は特別な相手に見えるからです。ただ、分けた型は、それぞれ別々に古くなります。

  • 型の数だけ手入れが要る：ある媒体で効いた直しが、別の媒体の型に移らない
  • 同じ学生に、違う顔の会社として届く：学生が複数の媒体を使っていることもあり、媒体ごとに口ぶりの違う文面は、同じ会社の話に見えにくい
  • 反応の差を読み分けられない：型が違うと、差が出たときに媒体の差なのか文面の差なのかが分からない
  • 「上位大学向け」の版は、大学名で相手を見る癖を残す：送る人が、行動より先に大学名を見るようになる

上位大学の学生が文面を読み分ける基準は、媒体を問わず「自分のことを読んで送ってきたか」です。この基準は媒体で変わらないので、型も一つに寄せられます。

三つの媒体で共通する、文面の骨組み

部品書くこと入れないこと
件名相手のプロフィールの一文を縮めた言葉大学名、「特別なご案内」
書き出しプロフィールから拾った行動を一文で引く挨拶と会社名から始める
本文入社一年目の仕事の場面と、選考で聞くこと事業の全体説明、実績や受賞
送り手送る人の名前と、その人の経験を一言「採用担当一同」
締め話す場への誘い「ご応募お待ちしております」だけ

部品ごとの書き方は、件名の付け方、書き出し、締めの書き方、会社紹介の書き方で書きました。

上位大学の学生に向けて差し替える部品は、この表の中にはありません。重さが変わるのは「大学名に触れない」の一点です。大学名を理由にした連絡を受け慣れている傾向があるため、冒頭で大学名に触れた時点で、他の多くの連絡と同じ扱いで読まれます。

いま使っている媒体の運用の相談だけでも構いません。媒体ごとに分かれた文面を、一つの型にまとめる手順を一緒に考えます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「上位大学の学生には、それ相応の格の文面が要る」というものです。当社は求人広告代理店として三つの媒体の文面を見ていますが、格を意識して整えた文面は、丁寧な挨拶と会社の実績と「優秀な貴方に」で組み立てられていることが多く、学生には型通りの一通として読まれています。媒体を替えても、この傾向は同じです。反対に、大学名に触れず、プロフィールの行動を一文で引き、仕事の場面を書いた文面は、知名度の高くない会社からでも反応が来ています。上位大学の相談を受けたとき、当社が最初にするのは、媒体別・大学別に増えた型を並べ、格のために足した部分を削って、骨組みを一つに戻すことです。

媒体によって変わるのは、一文を拾う材料と、その後の流れ

骨組みは同じでも、書き出しの一文をどこから拾うか、返事が来たあとに何が起きるかは、媒体の作りによって違います。

媒体媒体の作り一文を拾いやすい材料返事のあとの流れ
OfferBox企業から学生にオファーを送る学生が自分で書いたプロフィールの文章承認のあと、面談や選考の日程を決める
Wantedly共感を軸に、会社ページやストーリーを読んで人が来るプロフィールの経験と、自社のストーリーとの重なりカジュアル面談から始まる
ワンキャリア掲載や体験談を読んで、学生が会社を知るプロフィールの行動と、体験談に出てくる仕事との重なり面談や選考への案内

送れる文字数や送れる数、プロフィールの項目や絞り込みの条件は、媒体とプランで違い、変わることもあります。型に当てはめる前に、管理画面とヘルプで確認してください。

媒体ごとの差は、型の空欄で吸収する

型は「固定の文」と「空欄」に分けておきます。空欄は二つです。相手の行動の一文と、その行動に重なる仕事の場面。媒体ごとの差は、この空欄の埋め方と、締めの言葉だけで扱います。

  1. OfferBoxで送るとき：空欄の一文は、学生が書いた自由記述から取る。締めは、承認のあとに何を話すかを一言で示す
  2. Wantedlyで送るとき：本文は短めにして、会社ページやストーリーへの道筋を一つ添える。カジュアル面談から始まる流れなので、選考の話より「話を聞く場」を前に出す
  3. ワンキャリアで送るとき：掲載や体験談で自社を知っている学生もいるため、掲載で読める内容を文面で繰り返さない。体験談の仕事の場面と、相手の行動をつなぐ
  4. どの媒体でも変えないもの：大学名に触れないこと、会社説明を一言にすること、送る人の名前を出すこと

型のどこを一通ずつ変えるかはスカウトを一通ずつ変える範囲の決め方、媒体の中での管理はWantedlyのスカウト文面のテンプレート管理で書きました。

送る相手は、大学名ではなく行動で選ぶ

絞り込みの画面や項目は媒体ごとに違いますが、選び方の考え方は共通です。

  • 大学名は、絞り込みではなく読むときの情報にとどめる：大学名で入口を狭めると、行動の近い学生が先に消える
  • 自社で長く活躍している人の行動を、三つほど言葉にする：「自分で始めて続けた」「周りを巻き込んだ」「やり方を変えて試した」など
  • その言葉を、プロフィールの中で探す：言葉で探せる範囲は媒体で違う。探しきれない媒体では、読む順番の基準に使う
  • 行動で選んだ結果として、上位大学の学生が混ざれば足りる：狙う対象を大学名ではなく行動に置く

上位大学の学生に限って反応が少ないという相談は、送る相手を大学名で選んでいることの裏返しであることが少なくありません。選び方を変えると、悩みの形そのものが変わります。

自社に合う媒体がどれか、3媒体を並べてご案内します。行動で選ぶ運用にしたとき、媒体ごとに読む手間がどう違うかもお伝えします。

媒体選びを相談する

反応が来ないとき、媒体の差と文面の差を分ける

同じ型を複数の媒体で使っていると、反応の差を切り分けやすくなります。

見るもの確かめること
文面大学名や「優秀」「厳選」に触れていないか。書き出しが相手の一文になっているか
返す速さ返事が来てから面談の案内までに、何日かかっているか
仕事の具体入社一年目の場面が、他社と入れ替えのきかない形で書けているか
媒体の流れその媒体で次に起きること（承認、カジュアル面談、選考の案内）を、締めで示せているか
条件募集要項と文面の内容がずれていないか

全部の媒体で低いなら、まず文面と仕事の具体を疑います。一つの媒体だけ低いなら、その媒体での一文の拾い方か、返事のあとの流れを疑います。理由の見方は上位大学の学生から反応が取れないときでも書きました。

上司に「上位大学を採れ」と言われたときの説明

  • 要望は退けない：「上位大学の学生にも届く文面にする」と言い換えて受ける
  • 媒体ごとに、二つの期間の反応を並べる：大学名で選んだ期間と、行動で選んだ期間
  • 社内で活躍している人の経歴を、行動で書き出す：大学名より行動に共通点があるかを、上司と一緒に確かめる
  • 媒体を増やす前に、型を一つに揃えた結果を見る：媒体の数より、文面が読まれているかを先に確かめる

社内の分担

作業誰が
媒体別・大学別に増えた型を、一つの骨組みに戻す人事
媒体ごとの空欄の埋め方と締めの言葉を決める人事
プロフィールから行動の一文を拾って書く送る人
入社一年目の仕事の場面を出す現場の人
媒体の差と文面の差を、反応の記録で切り分ける人事
上司に、媒体ごとの記録で説明する人事

運用代行や代理店が支えられるのは、型の整理、媒体ごとの空欄の埋め方の案、反応の切り分け、上司への説明の型までです。相手を読んで書くこと、仕事の場面、どんな人を採りたいかの決定は企業が行います。代理店に頼める範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは順番の話です。上位大学の学生を採りたい会社から、「どの媒体なら上位大学に届くか」という相談で始まることがよくあります。当社は三つの媒体を扱っているので、どれか一つを勧める理由はありません。そのうえで、媒体を選ぶより先に確かめるのは、型の空欄を社内で埋められるかです。送る人が週に数時間、プロフィールを読んで書けるなら、企業から文面を送るOfferBoxで型を回せます。現場の様子を会社ページやストーリーに書ける人がいるなら、Wantedlyで読んでもらう流れが作れます。掲載や体験談で仕事を知ってもらう準備があるなら、ワンキャリアと文面を組み合わせられます。どの媒体でも、空欄が埋まらないまま送ると、上位大学の学生には型通りに読まれます。

まとめ

  • 上位大学の学生へのスカウト文面は、媒体ごと・大学ごとに型を分けず、一つの骨組みで足りる。分けた型は別々に古くなり、反応の差も読み分けにくい
  • 骨組みは三つの媒体で共通。大学名に触れず、プロフィールの行動を一文で引き、仕事の場面と話す場への誘いで締める
  • 媒体で変わるのは、一文を拾う材料と返事のあとの流れ。差は型の空欄と締めの言葉で吸収し、細かな仕様は管理画面とヘルプで確認する
  • 送る相手は大学名ではなく行動で選ぶ。反応が来ないときは、全媒体で低いか一つだけ低いかで、文面の問題か媒体での使い方の問題かを分ける

よくある質問

媒体ごとに送れる長さが違うのに、型を一つにできますか

できます。固定の文を短く保ち、長さの差は本文の仕事の場面を何文書くかで調整します。書き出しの一文、会社紹介の一言、締めの誘いは、どの媒体でも残します。送れる文字数は媒体とプランで違うことがあるため、管理画面とヘルプで確認してから、削る順番を決めておくと迷いません。

上位大学の学生には、どの媒体から始めるのがよいですか

媒体の性能より、社内で型の空欄を埋められるかで決めるのが現実的です。プロフィールを読んで書く時間がある会社、会社ページやストーリーを書ける人がいる会社、掲載や体験談で仕事を伝える準備がある会社で、先に検討する媒体が変わります。3媒体の全体像は3媒体の違いと選び方にまとめています。

媒体をまたいだ文面の整理は、御社に相談できますか

できます。当社は求人広告代理店として、媒体選びから運用までを支えています。型の整理、媒体ごとの空欄の埋め方の案、反応の切り分け、上司への説明の型をお手伝いできます。相手を読んで書くこと、仕事の場面、どんな人を採りたいかの決定は、企業で行ってください。
