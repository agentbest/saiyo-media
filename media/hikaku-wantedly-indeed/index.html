WantedlyとIndeedの違い｜検索で見つかるか、会社ページに来てもらうか

公開 2026-09-10

  3. 時間の使い方が違う

「Indeedに求人を出している。Wantedlyも足すべきか」「Wantedlyの募集は、検索で見つかるのか」という相談を受けます。結論から言うと、この2つは候補者が自社を見つける起点が違います。Indeedは求人が検索で見つかる型、Wantedlyは会社の想いを読んで共感した人が会社ページに来る型です。 「探している人に見つけてもらう」のか、「読んで共感した人に来てもらう」のかで、先に検討する媒体が決まります。Wantedlyはウォンテッドリー株式会社が運営する、会社と人がつながるビジネスSNSで、募集情報を掲載する場です。Indeedは、求人情報を検索できる求人検索エンジンです。この記事ではIndeedの仕様や料金には触れず、見つかる起点の違いが採用の設計にどう効くかを整理します。

候補者が自社を見つける起点が違う

Indeedでは、候補者は職種や勤務地などのキーワードで求人を検索します。検索結果に自社の求人が出て、読まれ、応募される。起点は「探している人の検索」で、企業は検索に合う求人票を置きます。

Wantedlyでは、候補者は会社ページ、募集記事、ストーリー（会社の日常や考えを書く記事）を読んで自社を知ります。起点は「会社が書いたもの」で、共感した人が「話を聞きに行きたい」と動きます。企業からスカウトを送ることもできますが、送られた人もまず会社ページを読みます。

観点WantedlyIndeed
候補者の起点会社が書いた記事を読むキーワードで求人を検索する
見つかる仕組み会社ページに来る・スカウトが届く検索結果に求人が出る
企業が書くもの会社の想いと日常（ストーリー）検索に合う具体的な求人票
集まる理由共感条件の一致
入口の動きまず会って話す応募する

つまり、Indeedは「探している人に見つけてもらう」設計、Wantedlyは「読んで共感した人に来てもらう」設計です。求人型との違いはWantedlyとGreenの違いでも書きましたが、Indeedは「検索」が起点である点で、さらに違いがはっきりします。

企業が書くものが違う

Indeedで書くのは、検索に合う求人票です。職種名、仕事内容、勤務地、給与、求める経験。候補者が検索するキーワードで見つかるよう、具体的で、一般的な言葉で書くことが要ります。独自の職種名や社内用語では、検索に引っかかりません。

Wantedlyで書くのは、会社の想いと日常です。「なにをやっているのか」「なぜやるのか」「どうやっているのか」を、自分の言葉で書きます。検索のためではなく、読んだ人が共感するために書くので、一般的な言葉より、その会社らしい言葉が効きます。

  • Indeed：検索される言葉で、具体的に。探している人が「これだ」と思う求人票
  • Wantedly：その会社らしい言葉で、想いを。読んだ人が「この人たちと働きたい」と思う記事

同じ会社でも、書き方が正反対です。求人票をそのままストーリーにしても読まれず、ストーリーをそのまま求人票にしても検索されません。

検索で見つけてもらうのか、読んで来てもらうのか。整理するだけでも媒体は絞れます。

媒体選びを相談する

エージェントベストの見解

相談で最も多い思い込みは2つあります。1つは「Indeedに出しておけば、それで足りる」。もう1つは「Wantedlyは検索されないから、見つけてもらえない」。実際には、検索で見つかるのは「その職種や条件で探している人」だけで、探していない人には届きません。一方でWantedlyは、探していない人にも、会社ページやスカウトを通じて届きますが、書いたものが無ければ何も起きません。当社は3媒体すべての販売パートナーとして、Wantedlyの契約後の運用まで見ていますが、両方を使って成果が出ている会社は、この2つを「別の入口」として扱っています。検索で来た人に、面接の前にストーリーを読んでもらう。スカウトで来た人に、求人票で条件を確認してもらう。どちらか一方で全部済ませようとするより、入口を分けて、読むものを渡す順番を決めるほうが、応募後のずれが減ります。

時間の使い方が違う

Indeedの運用は、求人票を整え、応募に対応することです。検索に合う求人票を書き、応募が来たら確認し、選考に進める。応募が多いほど、対応の時間が増えます。求人票の見直しは、応募の質を見ながら行います。

Wantedlyの運用は、通年で会社ページを育てることです。ストーリーを書き足し、募集記事を見直し、スカウトを送る。書くのをやめると、会社ページに来る人が減ります。来た候補者への対応は、まず会って話す面談から始まります。

観点WantedlyIndeed
時間の使い先書く求人票を整え、応募に対応する
時間が増える条件書く量を増やしたとき応募が増えたとき
止まりやすい場面書く人の時間が取れなくなったとき対応に追われ、求人票の見直しが止まったとき

「時間があるか」ではなく「どの作業の時間なら取れるか」で見ると、自社に合う型が分かります。この見方はWantedlyとdodaの違いでも書きました。

この条件ならどちらを先に検討するか

優劣ではなく、先に検討する順番として置きます。

  • 職種名と条件が明確で、その職種で探している人が多い → Indeedを先に。検索に合う求人票を書く
  • 会社の想いが言葉になっていて、共感で集めたい → Wantedlyを先に
  • 職種名が一般的でなく、検索されにくい仕事 → Wantedlyを先に。仕事の中身をストーリーで伝える
  • 探していない人にも届けたい → Wantedlyを先に。スカウトと会社ページで届ける
  • 応募は来るが、合う人が少ない → Wantedlyを足す。面接の前にストーリーを読んでもらう
  • 会社の想いがまだ言葉になっていない → 求人票で先に候補者に会い、面接で「自社の何が響くか」を掴んでからWantedlyへ

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。書く時間と応募対応の時間は、媒体で違います。

運用の相談をする

併用するときの分担

両方を使うなら、次の分担が分かりやすいです。

  1. 検索で見つけてもらうのはIndeed：検索に合う具体的な求人票を置く
  2. 会社の見せ方はWantedly：会社ページとストーリーを「会社の説明書」として整える
  3. 求人票からWantedlyへ誘導する：検索で来た人が、面接の前に会社の日常を読んでから来る流れを作る
  4. Wantedlyから来た人に、求人票で条件を確認してもらう：共感で来た人が、条件のずれで辞退しないようにする
  5. 面談と選考を分ける：Wantedlyから来た人はまず会って話し、選考に進む意思を確認してから、Indeedから来た人と同じ選考フローに乗せる

検索で「条件は合う」と思った人が、ストーリーで「この会社で働く姿」を読んでから面接に来る。共感で「話を聞きたい」と思った人が、求人票で条件を確認してから選考に進む。この2つの流れがあると、どちらの入口から来た人も、応募後の「思っていたのと違う」が減ります。

エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。それは「求人票とストーリーを、同じ人が書かない」ことです。検索される言葉で具体的に書く求人票と、その会社らしい言葉で想いを書くストーリーは、書き方が正反対です。同じ人が両方を書くと、どちらかに寄ります。求人票に想いが混ざって検索されなくなるか、ストーリーが条件の羅列になって読まれなくなるか。当社が契約後の運用まで見ている経験では、両方が機能している会社は、求人票は採用担当か現場のマネージャーが、ストーリーは代表や現場のリーダーが、と書く人を分けています。1人で両方を書かざるを得ないなら、先に求人票を仕上げてから、頭を切り替えてストーリーを書く。同時に書かないだけでも、寄り方が減ります。

まとめ

  • Indeedは求人が検索で見つかる型、Wantedlyは会社の想いを読んで共感した人が来る型
  • Indeedは検索される言葉で具体的に、Wantedlyはその会社らしい言葉で想いを。書き方が正反対
  • 検索で届くのは探している人だけ。探していない人にはWantedlyのスカウトと会社ページで届く
  • 併用するなら、検索で見つけてもらうのはIndeed、会社の見せ方はWantedly。互いに読むものを渡す
  • 求人票とストーリーは、書く人を分けるか、同時に書かない

よくある質問

Wantedlyの募集記事は、検索で見つかりますか

Wantedlyは、検索で見つけてもらう設計ではなく、会社ページとスカウトで届ける設計です。探している人に検索で見つけてもらいたいなら、Indeedのような求人検索の場を先に検討します。探していない人にも届けたいなら、Wantedlyの型が向きます。

Indeedの求人票を、そのままWantedlyの募集記事に使えますか

書き方が違うので、そのままでは読まれにくいです。求人票は条件の一致で読まれ、募集記事は会社の想いへの共感で読まれます。募集記事には、仕事の中身と、なぜその仕事をやるのか、どんな人と働くのかを、その会社らしい言葉で書き直すことを勧めます。

Indeedの申込も御社経由でできますか

当社が販売パートナーとして窓口になるのは、OfferBox・Wantedly・ワンキャリアの3媒体です。Indeedは各社の窓口になりますが、検索型と共感型を併用するときの入口の分け方や、書く人の決め方は、Wantedlyの運用を見ている立場からご相談いただけます。3媒体の全体像は3媒体の違いと選び方にまとめています。
