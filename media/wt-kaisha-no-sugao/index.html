Wantedlyの記事は「素顔を出す」「本音で書く」と言われます。ところが、どこまで出してよいかが決まっていないと、書く人は迷い、迷った結果は「良いことだけ」になります。結論から言うと、Wantedlyで出す「素顔」とは、うまくいっていないこと・迷い・判断の理由であり、顧客名や機密や個人の情報ではありません。出せる本音と出してはいけない情報を先に分けておけば、書く人は迷わず、良いことだけにも、出しすぎにもなりません。 この記事では、素顔の意味、出したほうがよいもの、出してはいけないもの、迷うものの扱い、2つの失敗、範囲を先に決める手順、確認の流れ、分担を整理します。

この作業の目的｜「迷って良いことだけになる」を防ぐ

素顔を出す範囲が決まっていない会社で起きるのは、次の流れです。

  1. 書く人が「これは出していいのか」と迷う
  2. 確認する上司も基準が無く、「念のため外そう」と言う
  3. 迷ったものを全部外すと、良いことだけが残る
  4. 候補者は「建前の記事」と読み、共感が起きない

この流れを止めるには、「出してよいもの」と「出してはいけないもの」を先に分け、書く人と確認する人が同じ基準を持つことです。基準があれば、迷うのは境界の少数だけになります。

素顔とは何か｜「本音」であって「内部情報」ではない

「素顔を出す」を「社内のことを何でも書く」と受け取ると、出しすぎか、怖くなって何も出せないかのどちらかになります。分けて考えます。

素顔（出す）内部情報（出さない）
うまくいっていないこと、詰まったこと顧客名、取引の内容、契約の条件
迷ったこと、意見が割れたこと機密（技術、価格、計画）
判断の理由、断ったこと、止めたこと個人の評価、健康、家庭の事情
まだ無いもの、これから作るもの未公表の数字（売上、人数、給与の実額）
変えたこと、変えた理由他社の名前を出した比較や評価
働く人の、仕事の中での本音社員の私生活

素顔は「会社の判断と、その過程」で、内部情報は「会社の外に出ると誰かが困るもの」です。前者は出すほど信用され、後者は出すと問題になります。

出したほうがよいもの

候補者が「本当のことが書いてある」と感じるのは、次のものです。

  • 失敗と、そのあと：うまくいかなかった案件、止めた事業。「そのあとどうしたか」までを書く。書き方は事業の裏側を書く方法
  • 迷いと判断：意見が割れた会議、断った依頼、変えた決め方。カルチャーを伝える書き方
  • まだ無いもの：「〇〇の仕組みはまだ無く、入った人と作る」。無いことを隠すより、無いと書いたほうが、それを作りたい人が来る
  • 入る前と後で違ったこと：良い方向にも、悪い方向にも。入社エントリーを書いてもらう方法
  • 募集の背景の本当の理由：「増員」ではなく、なぜ今探すのか。募集記事「なぜ」の書き方
  • 条件で良くない部分：残業がある時期、まだ整っていない制度。面談で分かることは、先に書く

「まだ無いもの」は、見落とされやすい素顔です。制度や仕組みが揃っていない会社ほど、揃っているように書きたくなりますが、「無い」と書いた記事のほうが、作りたい人に届きます。

いま使っている媒体の運用の相談だけでも構いません。いまの記事のうち、出せるのに出していない本音がどこにあるかを一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「素顔を出すと、応募が減る」というものです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、失敗や迷いや「まだ無いもの」を書いた会社で減るのは、応募ではなく「面談で初めて実態を知って辞退する人」です。記事で良いことだけを書き、面談で実態を話すと、そこで辞退が起きます。記事で先に書いておくと、それを読んで来る人だけが来て、面談での辞退が減ります。話を聞きに来る人の数は変わらないか、少し減ることもありますが、面談に進んだあとの歩留まりが変わります。素顔を出すことは、応募を減らすのではなく、「合わない人が面談まで来る」のを減らすことです。当社は、記事の本音を「応募数」ではなく「面談後に残る人」で見るようお願いしています。

出してはいけないもの

素顔と混同して出してしまうと問題になるものを、先に一覧にしておきます。

出さないものなぜ代わりに
顧客名、案件の具体的な内容契約と信頼の問題「〇〇業界の顧客」「ある案件で」。許可があれば名前を出せる
技術、価格、計画などの機密競争上の問題判断の理由と過程だけを書く
個人の評価、健康、家庭本人の問題仕事の中の話に限る。本人の確認
未公表の数字会社の公表判断数字を使わず、状況を言葉で
他社の名前を出した比較・評価相手の問題自社の判断だけを書く
社員の私生活、イベントの酒の場面本人の問題、会社の見え方仕事の場面。社内イベントを書くときの注意
退職した人の話本人の問題書かない。書くなら本人の同意
社内の対立を、個人が分かる形で本人の問題「意見が割れた」までで、誰と誰かは書かない

「意見が割れた」は素顔で、「〇〇さんと△△さんが対立した」は内部情報です。同じ出来事でも、個人が特定される形にすると、出してはいけないものに変わります。

判断に迷うものの扱い

境界にあるものは、次の順で判断します。

  1. 外に出て、誰かが困るか：顧客、取引先、社員個人、会社の競争上の立場。誰かが困るなら出さない
  2. 困る人の許可が取れるか：顧客名なら顧客の許可、個人の話なら本人の同意。取れれば出せる
  3. 特定できない形にできるか：名前を消す、業界名にする、「ある案件で」にする。できれば、その形で出す
  4. それでも迷うなら、責任者に聞く：書く人が1人で抱えない。聞く相手を先に決めておく

「迷ったら外す」ではなく、「迷ったら、特定できない形にできるかを考える」が、良いことだけにならないための順番です。

2つの失敗

失敗何が起きるか直し方
良いことだけ（出さなすぎ）建前と読まれ、共感が起きない。面談で実態を知って辞退失敗・迷い・まだ無いものを1つ入れる
出しすぎ顧客や社員や会社が困る。一度起きると、社内が全部を止める出さないものの一覧を先に作り、確認の流れを通す

出しすぎが一度起きると、反動で「全部止める」になり、良いことだけに戻ります。出しすぎを防ぐ仕組み（一覧と確認）があることが、本音を出し続けるための条件です。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。出せる範囲を先に決める作業は、最初の一度で済みます。

媒体選びを相談する

範囲を先に決める手順

  1. 「出さないもの」の一覧を、責任者と管理部門で作る：上の表を元に、自社の事情を足す
  2. 「出したほうがよいもの」の一覧を、人事と代表で作る：自社で書ける失敗・迷い・まだ無いもの
  3. 迷ったときに聞く相手を決める：事業の話なら責任者、法務や契約なら管理部門
  4. 書く人と確認する人に、同じ一覧を渡す：基準が同じなら、確認で止まらない
  5. 半年に一度、見直す：事業が変われば、出せるものと出せないものも変わる

確認の流れ

素顔を出す記事は、確認の流れを決めておくと、出しすぎを防ぎつつ止まらずに出せます。

  • 本人の確認：本人が出ている記事は、全文と写真を見せる
  • 責任者の確認：事業の裏側、案件の話は、その責任者が「出さないもの」の観点で見る
  • 管理部門の確認：顧客名、契約、数字に触れる記事だけ
  • 期限を決める：確認が返らなければ、人事の判断で出す、と先に合意
  • 確認で直すのは「出さないもの」だけ：本音を薄める方向の直しはしない

「確認で本音を薄めない」を、先に合意しておきます。確認する人が「念のため」で本音を削ると、良いことだけに戻ります。確認の観点は「出してはいけない情報が無いか」に限ります。

社内の分担

作業誰が
出さないものの一覧責任者と管理部門
出したほうがよいものの一覧人事と代表
迷ったときに聞く相手先に決めておく（責任者、管理部門）
書く人事、書き手
本人の確認人事が本人に
出さないものの観点での確認責任者（事業）、管理部門（契約・数字）
半年に一度の見直し人事

運用代行や代理店が支えられるのは、出さないものの一覧の型、出したほうがよいものの候補の整理、特定できない形への書き換え、確認の流れの設計までで、自社で何を出せるかの判断と、確認そのものは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これをやる前に、先に決めておかないと本音が出せなくなることがあります。「確認する人の観点を、出してはいけない情報の有無に限る」ことです。当社がWantedlyの記事の相談を受ける中で、本音を書いた記事が確認で「良いことだけ」に直されて戻ってくる会社があります。確認する人に悪意はなく、「会社の見え方が心配」で削ります。ところが、削られた記事は候補者に建前と読まれ、書いた人も本人も「本音を書いても消される」と学び、次から書かなくなります。当社が範囲を決める作業で最初にやるのは、確認の観点を「顧客・機密・個人・数字・他社」の5つに限り、それ以外は直さないと合意することです。この合意があると、本音の記事が確認を通り、書く人が続きます。無いと、どれだけ書き方を教えても、確認で消えます。

まとめ

  • 素顔とは「うまくいっていないこと・迷い・判断の理由」で、内部情報ではない。分けて考える
  • 出したほうがよいのは、失敗とそのあと、迷いと判断、まだ無いもの、入る前と後の違い、条件で良くない部分
  • 出さないのは、顧客・機密・個人・未公表の数字・他社への言及・私生活・退職者・個人が分かる対立
  • 迷ったら「外す」ではなく「特定できない形にできるか」を考え、それでも迷えば決めておいた相手に聞く
  • 出さないものの一覧と確認の流れを先に作り、確認の観点は「出してはいけない情報の有無」に限る

よくある質問

失敗を書くと、会社の評判が下がりませんか

失敗そのものではなく、「失敗のあとどうしたか」が無い記事が評判を下げます。失敗と、そのあとの判断と、いまの状態までを書けば、候補者は「失敗を隠さず、直す会社」と読みます。失敗だけで終わる記事は書きません。

顧客の名前を出せないと、事業の裏側が書けません

名前を出さなくても書けます。「〇〇業界のある顧客で、最初の提案が通らなかった」で、場面は伝わります。書きたいのは顧客ではなく、自社の判断と過程です。許可が取れる顧客なら、名前を出す選択もあります。

素顔を出す範囲の整理は、御社に相談できますか

できます。当社は、出さないものの一覧の型、出したほうがよいものの候補の整理、特定できない形への書き換え、確認の流れの設計を支えられます。何を出せるかの判断と確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの記事の整備を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

あわせて読む

  • Wantedlyの募集記事を差し替えて比べる方法｜1要素ずつ、月の「話を聞きに来た数」で、記録を残して
  • Wantedlyの募集記事「どうやっているのか」の書き方｜会社全体ではなく、このチームの1日と決め方を場面で
  • Wantedlyで募集記事を複数パターン作る理由｜1本に全部を詰めず、誰に向けた入口かで分ける
  • Wantedlyの募集記事の反応を見て直す手順｜どこで止まっているかを切り分け、月に一度、1か所だけ直す
