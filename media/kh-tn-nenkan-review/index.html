採用担当者の年間の振り返り｜次の年に残す三つ

採用の一年が終わると、多くの会社は「何人採れたか」だけを確かめて、次の年の準備に入ります。採れた年は同じやり方を続け、採れなかった年は媒体を替える。その判断が当たることもありますが、何が効いて何が効かなかったかは分からないままです。結論から言うと、年間の振り返りは結果を評価する場ではなく、次の年に「続けること」「やめること」「決め直すこと」の三つを残す作業です。 この記事では、振り返る範囲、材料の集め方、工程ごとの見方、社内への報告のまとめ方を整理します。

振り返りの目的を先に決める

振り返りを始める前に、何のために振り返るかを決めます。目的が決まっていないと、数字を並べただけの資料になります。

年間の振り返りで決めたいのは、次の年の計画に関わることです。

  • 来年も同じ媒体を使うか、組み合わせを変えるか
  • 選考の回数や流れを変えるか
  • 社内の分担を変えるか
  • 外部に出している工程を増やすか、戻すか

この四つの判断に使える材料を集める、と決めておくと、振り返りの範囲が絞れます。採れた人数の評価は、その材料の一つにすぎません。

集める材料

振り返りには、次の材料を集めます。一年分を後から集めるのは大変なので、日頃の記録がそのまま使える形にしておくと楽になります。

  • 工程ごとの動き：媒体ごとの応募や返信、書類の通過、各回の面接の通過、内定、承諾、入社
  • 期間：応募から最初の面接まで、面接から合否の連絡まで、内定から承諾まで
  • 辞退の理由：どの段階で、どんな理由で辞退があったか
  • かけた時間：担当者や面接官が採用に使った時間の感覚
  • 関わった人の声：面接官、現場の責任者、入社した人からの話

数字だけでなく、入社した人に「なぜこの会社に決めたか」を聞くことを勧めます。会社が思っていた魅力と、入社した人が決めた理由がずれていることは少なくありません。

一年の振り返りをもとに、来年の媒体の組み合わせを一緒に整理します。比較だけでもどうぞ。

媒体選びを相談する

工程ごとの見方

集めた材料は、工程ごとに見ます。結果だけを見ると原因が分からないので、どの工程で止まったかを探します。

  1. 母集団：狙った候補者に届いていたか。応募や返信の数より、狙った層かどうかを見る
  2. 最初の接点から面接まで：返信や応募のあと、面接が決まるまでに離れた人が多くないか
  3. 面接の各回：特定の回で通過や辞退が偏っていないか。面接官によって差がないか
  4. 内定から承諾：承諾までの期間と、辞退の理由
  5. 入社後：入社した人が、期待した仕事に就けているか

工程ごとに見ると、「媒体を替えるべきか」の答えが変わることがあります。母集団には狙った層が来ていたのに面接で離れていたなら、替えるべきは媒体ではなく選考です。選考の途中で離れる理由は、選考の途中の辞退を減らすで整理しています。

エージェントベストの見解

年末の相談で多いのは、「今年は採れなかったので、来年は媒体を替えたい」というものです。当社は3媒体すべてを扱っているので、替えること自体を止める理由はありません。ただ、振り返りの材料を一緒に見ると、媒体ではなく途中の工程で止まっていた会社がかなりあります。スカウトへの返信は来ていたのに、日程の調整に時間がかかって面接まで進まなかった、というような形です。その場合、媒体を替えても同じところで止まります。媒体を替える判断は、「狙った層が母集団に入っていなかった」と分かったときに限ると、次の年の打ち手がぶれません。替える前に、どの工程の数字を根拠にするかを決めてください。

次の年に残す三つ

工程ごとに見たら、結論を三つに分けて書きます。

  • 続けること：効いていたと材料から言えること。たとえば、現場の若手が同席するカジュアル面談
  • やめること：時間をかけたのに効かなかったこと。たとえば、反応のなかった文面の型
  • 決め直すこと：前提が変わったこと。たとえば、採る人の要件、選考の回数、社内の分担

「決め直すこと」は見落とされがちです。事業の方向が変わった、現場の責任者が替わった、採用の人数が増えた。こうした変化があると、去年うまくいったやり方がそのまま使えないことがあります。

社内への報告のまとめ方

振り返りの結果は、経営者や現場の責任者に報告します。報告は、次の順に一枚にまとめると伝わりやすくなります。

  1. 今年の結果（採用した人数と、計画との差）
  2. 止まった工程と、その理由
  3. 続けること・やめること・決め直すこと
  4. 来年の計画で判断してほしいこと（予算、媒体、分担）

報告で大事なのは、4つ目の「判断してほしいこと」をはっきり書くことです。振り返りの報告が「今年はこうでした」で終わると、来年の計画は担当者が一人で決めることになります。経営者への伝え方は、上司への採用の報告も参考にしてください。

来年の計画で、どの工程を社内に残しどこを外に出すか。分け方の相談を受けています。

運用の相談をする

エージェントベストの見解

振り返りの順番について一つ勧めていることがあります。結果の数字を見る前に、年の初めに立てた計画を読み直すことです。計画で「何を、いつまでに、何人」と決めていた会社は、結果との差から振り返れます。計画が曖昧だった会社は、結果を見ても良かったのか悪かったのか判断できません。その場合、今年の振り返りで最も大事な結論は「来年は計画をこう立てる」になります。振り返りと次の年の計画は、別々の作業ではなく一続きです。年末に振り返りの時間を取るなら、その場で来年の計画の骨組みまで作ってしまうほうが、年明けの立ち上がりが早くなります。

まとめ

  • 年間の振り返りは、次の年に続けること・やめること・決め直すことを残す作業
  • 材料は工程ごとの動き、期間、辞退の理由、かけた時間、関わった人の声
  • 工程ごとに見て、止まったところを探す。媒体を替えるかはその後で決める
  • 報告には、経営者に判断してほしいことをはっきり書く
  • 振り返りの場で、来年の計画の骨組みまで作る

よくある質問

記録がほとんど残っていません。何から振り返ればよいですか

媒体の管理画面に残っている動きと、面接の日程の履歴から、工程ごとの数を拾います。完全でなくても、どの工程で止まったかの見当はつきます。来年に向けては、面接の記録の残し方を面接の記録を参考に決めておくと、次の振り返りが楽になります。

振り返りは誰と行うのがよいですか

担当者だけで材料をまとめ、結論の案を作ってから、現場の責任者と経営者に見てもらう形が進めやすいです。最初から全員で集まると、材料の読み方で時間がかかります。

新卒と中途で振り返り方は変わりますか

新卒は年間の流れが決まっているので、一年をまとめて振り返ります。中途は募集ごとに区切りがあるので、募集が終わるたびに短く振り返り、年末にまとめる形が向いています。
