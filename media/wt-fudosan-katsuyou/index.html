デベロッパー、売買仲介、賃貸仲介、管理会社、投資用不動産、不動産テック、デベロッパーの新規事業が、Wantedlyで採用する。不動産は、開発・売買仲介・賃貸仲介・管理・投資用で仕事がまったく違う業界で、候補者が知っている「不動産」は、デベロッパーの像——街をつくる、大きな案件、企画——です。仲介や管理や投資用の会社が「不動産」の一語で会社ページを書くと、その像で「話を聞きに行きたい」が押され、面談で仲介の数字と土日と歩合、管理のクレーム対応、投資用の電話営業の実態を聞いて離れる。結論から言うと、不動産のWantedlyは、自社が五つの仕事のどれかを最初に書き、「不動産」の一語で書きません。仲介は数字と土日と収入の形（固定と歩合）と一日を、管理はクレーム対応と物件数と一日を、投資用は営業の方法（誰に、どうやって）を、隠さず先に書きます。デベロッパーの新規事業と不動産テックは、本体の名前や「不動産」ではなく、事業と顧客と製品と「何を決められるか」で。「話を聞きに行きたい」の数はデベロッパーの像の量を映しているので、成果と見ず、面談で実態を伝えた後に残った数で運用を見ます。 この記事では、不動産の採用構造とWantedlyとの相性、五つの仕事の切り分け、「不動産」で書かない見せ方、数字と収入の形の書き方、数の読み方、ストーリーとカジュアル面談とスカウトの運用設計、社内の分担を整理します。媒体の選び方は不動産業界の採用媒体の選び方、業界の像とのずれはWantedlyで業界のイメージとのずれを扱う方法で書きました。数値と料金は書きません。

不動産の採用構造と、Wantedlyとの相性

区分採用の形Wantedlyとの相性

売買仲介営業が中心。数字と土日と歩合。中途が多い「不動産」で書かず、扱う物件と客層と数字と収入の形で

「不動産」で書かない｜自社の仕事を最初に、数字と収入の形と一日を隠さず

  • 「不動産」「街をつくる」「資産をつくる」を、会社ページの最初から外す：デベロッパーの像を呼ぶ言葉。仲介と管理と投資用が使うと、像で押されて実態で離れる
  • 「なにを」は、自社の仕事で一言：「〇〇の地域の△△の物件を、□□の客層に仲介している会社」「〇〇の投資家に△△の物件を、□□の方法で売っている会社」
  • 仲介は、数字と土日と収入の形を先に：「契約の数字は担当が持つ。土日は〇〇。収入は固定が△△、歩合が□□の形」。「稼げる」で集めない。Wantedlyの募集記事で待遇をどう扱うか
  • 管理は、クレーム対応と物件数と一日を先に：「担当は〇〇件の物件。△△の頻度で入居者と大家の対応。□□の時間帯に呼ばれる」。「安定」で埋めない
  • 投資用は、営業の方法を隠さず：「〇〇の投資家に、△△（紹介・問い合わせ・電話）で。□□はしない」。イメージを否定せず、何をして何をしないかを
  • 「こんな人」は、「数字を持った・土日の仕事を続けた・クレームや要望に対応した・断られた後も続けた」の記述で：「不動産に興味がある」「稼ぎたい」で絞らない

いま使っている媒体の運用の相談だけでも構いません。会社ページが「不動産」の一語でデベロッパーの像を呼んでいないか、自社の仕事と数字と収入の形が先に書かれているか、「話を聞きに行きたい」の数だけで見ていないかを一緒に見ます。

運用の相談をする

エージェントベストの見解

これは切り分けの話です。仲介や管理の会社から、「Wantedlyで不動産に興味がある人を採りたい」と相談されることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、候補者の「不動産に興味がある」は、デベロッパーの像（街をつくる、大きな案件、企画）で、仲介の数字と土日と歩合や、管理のクレーム対応や、投資用の営業の実態を指していません。開発・売買仲介・賃貸仲介・管理・投資用は、仕事も、一日も、収入の形も、向く人も違います。当社がお願いしているのは、自社が五つのどれかを最初に書き、「不動産」で書かず、その仕事の数字と収入の形と一日を隠さず書くことです。分けると、「不動産に興味がある」候補者ではなく、「この仕事の数字と土日を引き受ける人」「クレーム対応を仕事にできる人」が押します。

会社ページと募集記事の見せ方｜イメージを否定せず、何をして何をしないかを

  • 業界イメージ（強引な営業、長時間）を、否定しない：「うちは違います」は、イメージを思い出させ、書かれていない実態を疑わせる
  • 何をして、何をしないかを、書く：「〇〇の方法で営業する。△△はしない。□□の時間には連絡しない」。否定ではなく、実態で
  • 数字に達しなかったときに何が起きるかを、隠さず：「達しなかった月は〇〇」
  • 「なぜ」は、代表や責任者の「なぜこの物件を、この客層に」を体験で：Wantedlyの募集記事「なぜやるのか」の書き方
  • 「こんなことやります」は、先週の一日で：「土曜は〇〇組の内見。月曜は△△の追客と□□の契約」。Wantedlyの募集記事「こんなことやります」の書き方
  • デベロッパーの新規事業と不動産テックは、本体の名前と「不動産」で埋めず、事業と顧客と製品と「何を決められるか」で：「〇〇までは事業部で決める。△△は本体の決裁」

会社ページの書き方はWantedlyの会社ページで最初に書くこと、素顔を出す範囲はWantedlyで会社の素顔を出す範囲で書きました。

数の読み方｜像の量ではなく、実態を伝えた後に残った数で

  • 「話を聞きに行きたい」の数は、デベロッパーの像の量を映している：仲介と管理と投資用で数が多いなら、像で押されている
  • 募集ごとに、「押した数」「面談に来た数」「面談で数字と収入の形と一日を伝えた後に残った数」を分けて見る：残った数が少ないなら、記事が「不動産」の像で書かれている
  • 実態を先に書くと、押した数は減り、残った数が増える：減った数を「悪くなった」と読まない

ストーリーとカジュアル面談の設計

  • 営業のストーリーで、「契約が取れなかった月」「断られた週」と「それでも残った理由」を本人の言葉で：Wantedlyのストーリーで事業の中身を書く方法
  • 「不動産」の像で入った人のストーリーで、「像と、入った後」を本人の言葉で：Wantedlyの入社後ストーリーの書き方
  • カジュアル面談で、数字と収入の形と土日と一日を、聞かれる前に伝える：デベロッパーの像で来た候補者に、自社の仕事を最初に。Wantedlyのカジュアル面談の設計
  • 面談を、平日と繁忙期の外に置く：土日は内見と契約で、面談の時間が無い

スカウトの設計

  • 絞るのは、「数字を持った・土日の仕事を続けた・クレームや要望に対応した・断られた後も続けた」の記述：「不動産」「稼ぎたい」の言葉で絞らない。Wantedlyのスカウトで対象を絞る方法
  • 文面は、自社の仕事と数字と収入の形を最初に：「〇〇の物件を△△の客層に仲介していて、数字は担当が持ち、収入は□□の形で、あなたの〇〇を読んで」。「不動産」で始めない。Wantedlyのスカウト文面の書き方
  • 送る時期を、繁忙期（賃貸は年明けから春）の外に：Wantedlyのスカウトを送る時期の考え方

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。不動産の会社で、自社の仕事の整理、数字と収入の形と一日の書き出し、営業や管理担当が話す時間、募集ごとの数の見方をお伝えします。

社内の分担

作業誰が

エージェントベストの見解

これは数字の読み方の話です。仲介や投資用の会社が、Wantedlyの「話を聞きに行きたい」が多いことを成果と見て、面談を重ねても採れず、「Wantedlyは合わない」と判断する形を、当社は見ています。仲介と管理と投資用で「話を聞きに行きたい」が多いなら、それはデベロッパーの像の量を映していて、記事の良し悪しを映していません。見るべきは、募集ごとに「押した数」「面談に来た数」「実態を伝えた後に残った数」を分けたときの、残った数です。残った数が少ないなら、記事が「不動産」の像で書かれています。自社の仕事と数字と収入の形を先に書き直すと、押した数は減り、残った数が増えます。当社がお願いしているのは、押した数が減ることを「記事が悪くなった」と読まず、残った数で運用を見ることです。不動産テックと新規事業は、押した数が少なくてよく、「何を決められるか」で来た候補者が残れば動いています。

まとめ

  • 候補者の「不動産」はデベロッパーの像で、仲介・賃貸仲介・管理・投資用の実態ではない。「不動産」「街をつくる」で書かず、自社が五つの仕事のどれかを最初に書く
  • 仲介は数字と土日と収入の形（固定と歩合）を、管理はクレーム対応と物件数と呼ばれる時間帯を、投資用は営業の方法（誰に、どうやって、何をしないか）を、隠さず先に。数字に達しなかったときに何が起きるかも
  • 業界イメージ（強引な営業、長時間）を「うちは違います」で否定しない。何をして何をしないかを実態で書く
  • 「話を聞きに行きたい」の数は像の量。募集ごとに実態を伝えた後に残った数で読む。営業が「契約が取れなかった月」を、管理担当が「夜に呼ばれた日」を本人の言葉で。面談と返信を平日と繁忙期の外に置く

よくある質問

「不動産」と書かないと、何の会社か分かりにくくなりませんか

「〇〇の地域の△△の物件を、□□の客層に仲介している会社」の方が、「不動産」より何の会社か分かります。自社の仕事で書き、「不動産」は業種として一度、事実として書けば足ります。

業界イメージが悪くて、応募が来ません

「うちは違います」と否定すると、イメージを思い出させ、書かれていない実態を疑わせます。「〇〇の方法で営業する。△△はしない。□□の時間には連絡しない。数字は〇〇が持ち、達しなかった月は△△」と、何をして何をしないかを実態で書いてください。実態を書いた会社として読まれ、イメージではなく実態で選ぶ候補者が残ります。

不動産のWantedlyの設計は、御社に相談できますか

できます。当社は、仕事の切り分けの整理、否定しない書き方の型、募集記事の型、聞き方の型、数の見方の型、面談の型、スカウトの絞る作業を支えられます。数字と収入の形の開示、何をしないかの決定、代表が話すこと、営業と管理が話すこと、面談、残った数の判断は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
