Wantedlyとビズリーチの違い｜経験で絞って送るか、共感で集めるか

公開 2026-09-10

「経験のある人を中途で採りたい。Wantedlyとビズリーチのどちらがいいか」という相談を、事業の拡大期にある会社から受けます。結論から言うと、どちらも企業から候補者へスカウトを送れますが、候補者の何を読んで送るかが違います。ビズリーチは職務経歴を読んで経験で絞って送る型、Wantedlyは会社の想いへの共感を起点に、会って話すことから始める型です。 Wantedlyはウォンテッドリー株式会社が運営する、会社と人がつながるビジネスSNSで、募集情報を掲載する場です。ビズリーチは株式会社ビズリーチが運営する、経験を積んだ候補者に向けたスカウト型の転職サービスです。この記事ではビズリーチの仕様や料金には触れず、送る起点の違いが文面と社内の分担にどう効くかを整理します。

候補者の何を読んで送るかが違う

ビズリーチでは、企業は候補者の職務経歴を読みます。どの会社で、どの職種を、どれくらいの期間、どんな成果を出したか。企業はそこから経験で絞り、「その経験がこのポジションに要る」と書いて送ります。文面の主役は、候補者の経験と自社のポジションのつながりです。

Wantedlyでは、企業は候補者のプロフィールを読みますが、それ以上に、候補者が企業の会社ページとストーリーを読みます。企業がスカウトを送るときも、「うちの考えに共感してもらえそうだから、まず話を聞きに来てほしい」という起点です。文面の主役は、会社の想いと、候補者の志向のつながりです。

観点Wantedlyビズリーチ
企業が読むものプロフィール・志向職務経歴・成果
候補者が読むもの会社ページ・ストーリー・募集記事スカウトの文面・ポジションの内容
文面の主役会社の想いと候補者の志向候補者の経験とポジションの要件
入口の動きまず会って話すポジションへの応募・面接
文面を書ける人会社の想いを語れる人職務経歴を読んで要件を言える人

どちらも「企業から動く」点は同じです。違うのは、動く根拠が「経験」か「共感」かです。

文面を書く人が違う

送る起点の違いは、文面を誰が書けるかに直結します。

ビズリーチの文面は、職務経歴を読んで「この経験のここが、うちのこのポジションに要る」と書けないと、無差別に送っている印象になります。書けるのは、ポジションの要件を具体的に知っている現場のマネージャーか、要件を深く理解した採用担当です。

Wantedlyの文面は、会社の想いと候補者の志向をつなげて「一度話を聞きに来てほしい」と書きます。会社ページとストーリーが整っていれば、文面は短くても、候補者がストーリーを読んで判断してくれます。書けるのは、会社の想いを自分の言葉で語れる人です。

  • ビズリーチ：現場のマネージャーが要件を言語化し、採用担当が文面にする分担
  • Wantedly：代表や現場のリーダーがストーリーを書き、採用担当がスカウトを送る分担

経験で絞って送るのか、想いで集めるのか。社内で誰が書けるかから、一緒に整理します。

媒体選びを相談する

エージェントベストの見解

相談で最も多い思い込みは、「経験のある人はビズリーチ、若手やスタートアップ志向の人はWantedly」という区分です。実際には、どちらにもいろいろな経験の人がいます。分かれ目は候補者の層ではなく、「自社がその人を、経験で口説くのか、想いで口説くのか」です。ポジションの要件が明確で、経験のつながりを文面で示せるなら、ビズリーチの型が素直です。要件より「この会社でこういうことをやりたい」という共感で動いてほしいなら、Wantedlyの型です。当社は3媒体すべての販売パートナーとして、Wantedlyの契約後の運用まで見ていますが、経験豊富な候補者をWantedlyで採っている会社は少なくありません。共通するのは、ストーリーで「経験者がこの会社で何をやっているか」を書いている会社です。層で媒体を分けるより、「口説く根拠」で分けることを勧めます。

時間の使い方が違う

ビズリーチの運用は、ポジションごとに山を作ります。募集するポジションが決まったら、要件を言語化し、職務経歴を読んで絞り、文面を書いて送り、返信に対応する。ポジションが埋まれば、次のポジションで再び動きます。

Wantedlyの運用は、通年で会社ページを育てます。ストーリーを更新し、募集記事を整え、スカウトを送る。ポジションが空いていなくても会社ページに人が来る状態を保ち、募集が出たときにそこから入ってもらいます。

観点Wantedlyビズリーチ
時間の使い方通年で育てるポジションごとに山を作る
止まりやすい場面ストーリーを書かなくなったとき職務経歴を読んで絞る時間が取れなくなったとき
準備の中心会社ページとストーリーポジションの要件の言語化

採用の予定が通年で続く会社はWantedlyの型が向き、特定のポジションを特定の時期に埋めたい会社はビズリーチの型が向く傾向があります。

この条件ならどちらを先に検討するか

優劣ではなく、先に検討する順番として置きます。

  • ポジションの要件が明確で、経験のつながりを文面で示せる → ビズリーチを先に
  • 会社の想いが言葉になっていて、共感で動いてほしい → Wantedlyを先に
  • 通年で採用が続く。会社ページを育てる時間がある → Wantedlyを先に
  • 特定のポジションを特定の時期に埋めたい → ビズリーチを先に
  • 要件はあるが、まず会って話してから決めたい → Wantedlyを先に。面談で要件を確かめる
  • 職務経歴を読んで要件を言える現場の人が、採用に時間を割ける → ビズリーチが活きる

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。要件の言語化と、ストーリーの執筆は、必要な人が違います。

運用の相談をする

併用するときの分担

両方を使うなら、次の分担が分かりやすいです。

  1. 経験で絞って送るのはビズリーチ：要件が明確なポジションに、職務経歴を読んで送る
  2. 会社の見せ方はWantedly：会社ページとストーリーを「会社の説明書」として整え、面接の前後に読んでもらう
  3. ビズリーチの文面からWantedlyへ誘導する：経験で口説いた候補者が、会社の日常を読んでから面接に来る流れを作る
  4. 選考フローは1本にする：入口が違うだけで、面接以降は同じ流れに乗せる
  5. 書く人を分ける：要件を言語化する人と、ストーリーを書く人は、同じ人でなくてよい

経験で「合う」と思った候補者が、ストーリーで「この会社で働く姿」を読んでから面接に来る。この流れができると、面接での「条件は合うが、雰囲気が合わない」が減ります。

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社が線を引くなら、ポジションの要件の言語化と、会社の想いを書くストーリーは、社内で持ちます。どちらも社外の人には書けません。一方で、職務経歴を読んで絞る作業、文面の型を作る作業、送信と一次返信は、外に出せる部分です。当社がWantedlyの運用の相談を受けるときも、この線で分けます。ビズリーチとWantedlyを併用する会社ほど、現場のマネージャーの時間を要件の言語化と面接に、代表やリーダーの時間をストーリーに集中させ、送る作業は外に出す設計にすると、両方が止まらずに回ります。逆に、要件の言語化まで外に出すと、面接に来た候補者と社内の期待がずれます。

まとめ

  • ビズリーチは職務経歴を読んで経験で絞って送る型、Wantedlyは会社の想いへの共感を起点に、まず会って話す型
  • 文面を書けるのは、ビズリーチが要件を言える現場、Wantedlyが想いを語れる人
  • ビズリーチはポジションごとに山を作り、Wantedlyは通年で会社ページを育てる
  • 分かれ目は候補者の層ではなく、経験で口説くか、想いで口説くか
  • 併用するなら、経験で絞って送るのはビズリーチ、会社の見せ方はWantedly。文面からストーリーへ誘導する

よくある質問

経験豊富な候補者は、Wantedlyでは採れませんか

採れている会社はあります。共通するのは、ストーリーで「経験者がこの会社で何をやっているか」を書いている会社です。候補者の層で媒体を分けるより、自社がその人を経験で口説くのか、想いで口説くのかで分けることを勧めます。

Wantedlyのスカウトは、ビズリーチのスカウトと何が違いますか

送る起点が違います。ビズリーチは職務経歴を読んで「その経験が要る」と送り、Wantedlyは会社の想いを起点に「まず話を聞きに来てほしい」と送ります。Wantedlyでは、文面より会社ページとストーリーが読まれるので、文面を長く書くより、ストーリーを整えるほうが効きます。

ビズリーチの申込も御社経由でできますか

当社が販売パートナーとして窓口になるのは、OfferBox・Wantedly・ワンキャリアの3媒体です。ビズリーチの申込は各社の窓口になりますが、経験で絞る型と共感型を併用するときの分担や、書く人の決め方は、Wantedlyの運用を見ている立場からご相談いただけます。Greenとの比較はWantedlyとGreenの違い、3媒体の全体像は3媒体の違いと選び方にまとめています。
