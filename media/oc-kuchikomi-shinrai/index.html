ワンキャリアのクチコミは、どこまで信じてよいのか。「一人の意見だ」「事実と違う」「感情的だ」と思うことがある。ところが、「信じられない」で読まず、一件を全体と思い、厳しい記述を「嘘だ」と決め、良い記述を「本当だ」と決め、自社の記録と照らさず、信頼性が低いと判断して放置し、学生が信じて読んでいることを忘れる。結論から言うと、企業がクチコミの信頼性を見る目的は「信じてよいか」を決めることではなく、「学生が信じて読んでいる」前提で、どの記述を直す材料にするかを決めることです。見るのは、事実か印象か・一件か複数か・段階と時期が特定できるか・自社の記録と照らせるか・企業ページと矛盾しないか、の五つ。信頼性が低いと判断した記述も、学生は読みます。投稿の基準と確認の仕組みは、媒体の規約で確認してください。 この記事では、信頼性の見方で起きる失敗、目的、五つ、それぞれの見方、判断の後にすること、媒体の仕組み、分担を整理します。読み方はワンキャリアの自社クチコミの読み方、厳しいクチコミはワンキャリアに厳しいクチコミがあるときの向き合い方、影響はワンキャリアの選考体験談が採用に与える影響で書きました。

この作業の目的｜信頼性を「信じるか」ではなく「どう使うか」の物差しにする

クチコミの信頼性を「信じてよいか」で見ると、厳しい記述は「信じない」、良い記述は「信じる」になりがちで、どちらも直す材料になりません。企業にとっての信頼性は、「この記述を、直す材料として、どの重さで扱うか」を決めるための物差しです。そして、企業がどう判断しても、学生はその記述を信じて読んでいます。

目的は、信頼性を五つの物差しで見て、記述ごとに「直す材料としての重さ」を決め、信頼性が低いと判断した記述にも「学生は読んでいる」前提で対応することです。

信頼性の見方で、起きる失敗

失敗何が起きるか
「信じられない」で、読まない学生は読んでいる。企業だけが知らない
一件を、全体と思う一人の体験で選考を変え、他の学生に合わなくなる
厳しい記述を、「嘘だ」と決める事実だった場合に直せない。「その学生が特殊」で終わる
良い記述を、「本当だ」と決める残すべき進め方を確かめず、変えてしまう
自社の記録と、照らさない事実か誤解かが分からないまま、印象で判断する
信頼性が低いと判断して、放置する学生は読んで確かめに来る。答えられない

共通するのは、信頼性を「企業が信じるか」で見て、「学生が信じて読んでいる前提でどう使うか」で見ていないことです。

見る、五つ

物差し見ること重さ
1. 事実か、印象か「連絡が二週間来なかった」は事実。「冷たかった」は印象事実は自社の記録で確かめ、直す。印象は複数で傾向を見る
2. 一件か、複数か同じことが複数に書かれているか複数は傾向。一件は「その一件で何が起きたか」
3. 段階と時期が、特定できるか「二次で」「早期に」と書かれているか特定できれば直す場所が決まる。できなければ面談で聞く
4. 自社の記録と、照らせるか台帳の日付、面接官、結果の連絡の日と合うか合えば事実。合わなければ誤解か記録の漏れ
5. 企業ページと、矛盾しないか企業ページの記述と、クチコミの記述が違うか違えば、どちらかが古いか、書いたとおりでない

五つで、記述ごとに「直す材料としての重さ」を決めます。重い記述から直します。拾い方はワンキャリアの自社クチコミの読み方の「七つの、拾うもの」と組み合わせます。

いま使っている媒体の運用の相談だけでも構いません。自社のクチコミの記述を、五つの物差しで「直す材料としての重さ」に分けるところを一緒にやります。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「厳しいクチコミは、落ちた学生が感情で書いたもので、信頼性が低い」というものです。当社はワンキャリアの販売パートナーとして、信頼性の相談を受けていますが、「感情で書いたもの」と判断された記述を自社の記録と照らすと、「連絡が来なかった」が台帳の日付で事実だった、「面接官によって違った」が面接官ごとの評価のばらつきで事実だった、という例が多い。落ちた学生の記述は、感情が混ざっていても、事実の部分があります。逆に、良い記述を「本当だ」と決めて確かめなかった会社は、良いと書かれた面接官の進め方を知らず、翌年にその面接官が異動して、良い記述が消えています。信頼性は、書いた学生の立場で決めるものではなく、自社の記録と照らして決めるものです。当社が信頼性の相談を受けるとき、最初にやるのは、記述と台帳を並べることです。

事実か、印象か

  • 事実：日付、回数、時間、言われた言葉、聞かれた質問。自社の記録で確かめられる
  • 印象：「冷たい」「圧迫」「雰囲気が良い」。確かめられないが、複数なら傾向
  • 事実は、記録と照らして、合えば直す：「連絡が遅い」→台帳の日付で確認→事実なら返信の運用
  • 印象は、複数の記述で傾向を見て、傾向なら運用を見直す：「圧迫」が複数なら、面接の入り方と言葉
  • 分け方はワンキャリアに厳しいクチコミがあるときの向き合い方の「最初に、すること」

一件か、複数か

  • 複数に同じことが書かれていれば、傾向：直す材料として重い
  • 一件なら、「その一件で何が起きたか」を記録で確かめる：事実なら直す。傾向ではないが、次の学生にも起きうる
  • 一件で全体を変えない：一人の体験で選考の流れを変えると、他の学生に合わなくなる
  • 時期をまたいで、同じことが書かれていれば、直っていない：年度で見る

段階と時期が、特定できるか

  • 「二次で」「最終で」「早期に」「後期に」と書かれていれば、直す場所が決まる
  • 特定できない記述は、面談で聞く：「体験談で〇〇と書かれているのを読みましたか。どの段階のことだと思いましたか」
  • 段階が特定できれば、面接官ごと・段階ごとに揃える：ワンキャリアのクチコミから選考を改善する方法の「記述を、段に置く」

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。記述と自社の記録を並べて信頼性を見る運用に要る時間をお伝えします。

媒体選びを相談する

自社の記録と、照らす

  • 台帳：入口、段、日付、結果の連絡の日。「連絡が遅い」を日付で確かめる
  • 面接官の記録：誰が、何を聞いたか。「面接官によって違った」を評価のばらつきで確かめる
  • 企業ページの履歴：いつ、何が書かれていたか。「企業ページと違った」を当時の記述で確かめる
  • 記録がなければ、照らせない：信頼性を判断できないのは、記述ではなく記録の側の問題。台帳を付け始める。OfferBox運用のKPI設計の手順5

企業ページと、矛盾しないか

  • クチコミの記述と、企業ページの記述が違う：「面接は〇回」と「〇回」が違う
  • どちらが事実か、記録で確かめる：企業ページが古いなら更新、クチコミが古いなら「今年はこう」を企業ページに
  • 矛盾は、学生が最も気にする：「どちらが本当か」。ワンキャリアの掲載でやりがちな失敗の「体験談と揃っていない」
  • 年度の切れ目に、矛盾を一度全部確かめる：ワンキャリアのクチコミと採用広報の関係の「クチコミと広報を、揃える確認」

信頼性の判断の後に、すること

判断すること
事実で、複数今年の選考で直す。最も重い
事実で、一件その一件で起きたことを直す。次の学生にも起きうる
印象で、複数傾向として、運用（入り方・言葉・速さ）を見直す
印象で、一件記録に残し、翌月以降に同じ記述が出るかを見る
事実と違う企業ページで事実を先に書く。否定せず、事実を置く
判断できない（記録がない）台帳を付け始め、面談で聞く

どの判断でも、「学生は読んでいる」前提で、企業ページと回と面談で答えられる状態にします。信頼性が低いと判断した記述を、放置しません。

投稿の基準と、媒体の仕組み

  • 投稿の基準（何が書けるか、何が削除の対象か）：媒体の規約で確認
  • 媒体が投稿を確認する仕組みがあるか：あるとしても、企業がその仕組みに頼って「信頼性が低い記述は消える」と考えない
  • 企業が「事実と違う」と感じた記述の扱い：規約で確認。削除を依頼できるかどうかと、依頼すべきかどうかは別。ワンキャリアのクチコミガイドラインの考え方
  • 企業が返せるか：規約で確認。返すなら否定せず事実で
  • 媒体の仕組みの中身は、ここでは書かない：原文で確認

社内の分担

作業誰が
記述を五つの物差しで見て、重さを決める人事
台帳・面接官の記録・企業ページの履歴と照らす人事
事実で複数の記述を、今年の選考で直す面接官と人事責任者
事実と違う記述に、企業ページで事実を先に書く人事
記録がない場合、台帳を付け始める人事
投稿の基準と仕組みを規約で確認する人事

運用代行や代理店が支えられるのは、五つの物差しの整理、記録と照らす型、判断の後にすることの整理、規約で確認する項目の整理までで、記述の判断、記録と照らすこと、選考を直すこと、企業ページの中身は企業が行います。当社は記述の真偽を判断しません。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは発注側の誤解の話です。信頼性の相談で、「この記述は事実と違うので、削除してもらえないか」と言われることがあります。当社が確かめるのは、「事実と違う」の根拠が自社の記録にあるか、そして、削除できたとして学生の読み方が変わるか、です。根拠が記録になく「そんなはずはない」の印象なら、事実の可能性を先に確かめます。根拠があっても、削除の扱いは規約で決まり、当社が代わりに依頼することはしません。そして、削除できたとしても、その記述を読んだ学生はすでにいて、翌年の学生は別の記述を読みます。企業ができるのは、事実を企業ページに先に書き、今年の選考で「違った」を作ることで、それは削除の可否と関係なくできます。当社は、信頼性の相談を、「消せるか」ではなく「記録と照らして、直すか補うか」から始めます。

まとめ

  • 企業がクチコミの信頼性を見る目的は「信じてよいか」ではなく、「学生が信じて読んでいる」前提で、どの記述を直す材料としてどの重さで扱うかを決めること
  • 五つの物差し：事実か印象か、一件か複数か、段階と時期が特定できるか、自社の記録と照らせるか、企業ページと矛盾しないか
  • 事実は記録（台帳・面接官の記録・企業ページの履歴）と照らして直す。印象は複数で傾向を見る。一件で全体を変えないが、事実で重い一件は直す。記録がなければ判断できず、それは記録の側の問題
  • 判断の後は、事実で複数→今年の選考で直す、事実と違う→企業ページで事実を先に、判断できない→台帳と面談。信頼性が低いと判断した記述も放置しない
  • 投稿の基準・確認の仕組み・削除・返信の扱いは規約で確認。当社は真偽を判断せず、削除を代わりに依頼しない。「消せるか」ではなく「記録と照らして、直すか補うか」

よくある質問

明らかに事実と違う記述があります。どうすればよいですか

自社の記録で「事実と違う」ことを確かめ、企業ページにその点の事実を先に書きます。否定ではなく、「実際は〇〇です」の形で。回と面談で、聞かれる前に触れます。削除の扱いは規約で確認しますが、削除できたとしても、読んだ学生はすでにいるので、企業ページと今年の選考での対応が主です。「明らかに」の根拠が記録にあるかを、先に確かめてください。向き合い方はワンキャリアに厳しいクチコミがあるときの向き合い方で書きました。

良いクチコミばかりで、逆に信頼性が心配です

良い記述も、五つの物差しで見ます。事実（「連絡が当日に来た」）か印象（「雰囲気が良かった」）か、複数か一件か、自社の記録と合うか。事実で複数なら、その進め方を型にして残します。良い記述が「本当か」を確かめることは、厳しい記述を確かめることと同じ価値があります。確かめずに安心すると、良い進め方をしていた面接官が異動した年に、良い記述が消えます。残し方はワンキャリアのクチコミを面接官教育に使う方法で書きました。

クチコミの信頼性の見方は、御社に相談できますか

できます。当社は、五つの物差しの整理、記録と照らす型、判断の後にすることの整理、規約で確認する項目の整理を支えられます。記述の判断、記録と照らすこと、選考を直すこと、企業ページの中身は、企業が行ってください。当社は記述の真偽を判断せず、削除を代わりに依頼しません。投稿の基準と仕組みは規約で確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
