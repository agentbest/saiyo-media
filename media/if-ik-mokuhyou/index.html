長期インターン生の目標の立て方

Infra・長期インターン受け入れ・育成 更新日 2026/11/4

長期インターン生に「目標を決めてみて」と渡すと、「成長したい」「社会人の基礎を身につけたい」といった大きな言葉が返ってくることがよくあります。本人の気持ちとしては本当でも、そのままでは日々の仕事につながりません。結論から言うと、インターン生の目標は「会社が任せたい仕事」と「本人が伸ばしたい力」を一つずつ並べ、外から確かめられる形で書くと機能します。 この記事では、目標を立てる順番、書き方の型、本人と話すときの進め方、目標を直すタイミングを整理します。

目標が日々の仕事につながらない理由

インターン生の目標が形だけになる理由は、おおむね次の三つです。

  • 本人だけで決めている：会社が何を任せたいかを知らないまま、本人が目標を書いている
  • 会社だけで決めている：作業の量や締め切りだけが目標になり、本人が何を得るかが見えない
  • 確かめられない言葉で書いている：「主体性を持つ」「積極的に発言する」など、できたかどうかの判断が人によって違う

長期インターンは、アルバイトとも新卒社員とも違う立場です。学生は仕事の経験を通じて何かを得たいと考えて応募し、会社は戦力として働いてもらうことを期待しています。目標は、この二つをすり合わせる場所です。どちらか一方だけで決めると、もう一方の納得が得られません。

目標を立てる順番

目標は、次の順番で立てます。

  1. 会社が任せたい仕事を書く：受け入れの前に、指導する社員と部署の責任者で決めておく
  2. 本人が伸ばしたい力を聞く：初日から最初の面談までに、応募の理由や将来の関心を聞く
  3. 重なる部分を探す：任せたい仕事のうち、本人の伸ばしたい力につながるものを選ぶ
  4. 確かめられる形に書き直す：いつまでに、何ができている状態かを書く
  5. 確かめる日を決める：次の面談や振り返りの日を、目標と一緒に決める

1つ目を先に決めておくのが大切です。本人の希望を先に聞いてから仕事を探すと、希望に合う仕事が社内になかったときに、目標が宙に浮きます。任せたい仕事の候補を先に持っておけば、本人の希望を聞いたうえで「それなら、この仕事が近い」と提案できます。任せる仕事の分け方は長期インターン生に任せる仕事の切り出し方で扱っています。

受け入れの前に、インターン生に任せたい仕事を整理しておくと、目標の話し合いが進めやすくなります。整理の段階から相談できます。

目標の書き方の型

目標は、一人につき二つか三つに絞ります。多すぎると、どれも中途半端になります。書き方の型は次のとおりです。

項目書くこと例
仕事の目標いつまでに、どの仕事を、どこまで一人でできるか次の振り返りまでに、問い合わせへの一次返信を確認なしで出せる
力の目標その仕事を通じて、何ができるようになるか相手の質問の意図を読み、短い文で返せる
確かめ方誰が、何を見て判断するか指導する社員が、送った返信を週に一度まとめて見る

「仕事の目標」と「力の目標」を分けて書くのがこの型の要点です。仕事の目標は会社が確かめやすく、力の目標は本人が手応えを感じやすい。二つが並んでいると、作業の量だけで評価されているわけではないことが本人に伝わります。

避けたいのは、数や量だけを目標にすることです。「月に何件」という目標は分かりやすい反面、学業の都合で出勤が減った月に達成できず、本人が自信をなくす原因になります。量を目標に入れる場合も、出勤できる時間に合わせて見直す前提で置きます。

エージェントベストの見解

これをやる前に、先に「インターン生の目標は誰が見るのか」を決めておかないと、目標は立てた日で止まります。相談を受けていて多いのは、初日に目標シートを書いてもらい、その後は誰も開かないという形です。目標を見る人が決まっていないと、本人は「書かされただけ」と受け止めます。勧めているのは、目標を立てる面談に、日々の指導をする社員を同席させることです。目標を聞いた社員は、日々の仕事の割り振りでそれを思い出せますし、本人も「この人が見てくれている」と分かります。目標の中身を磨くより、見る人と見る日を決めるほうが、目標が日々の仕事に残ります。

本人と話すときの進め方

目標の話し合いは、面接ではありません。本人が何を考えているかを聞く場です。次の流れで進めると、話が具体的になります。

  • 応募の理由を聞き直す：面接で聞いた内容を、入社後にもう一度聞く。働き始めてから考えが変わっていることも多い
  • やってみたいことを一つ挙げてもらう：大きな言葉が出たら、「それは、どんな場面でできたと感じそうか」と聞き返す
  • 会社が任せたい仕事を伝える：候補を見せ、本人の関心に近いものを一緒に選ぶ
  • 書いた目標を読み上げる：本人が自分の言葉で言い直せるかを確かめる

学生の中には、目標を聞かれること自体に慣れていない人もいます。答えが出ないときは、無理に決めず、最初の数週間の仕事を経験してから決め直すと伝えます。最初の数週間の組み方は長期インターン初日の受け入れが参考になります。

目標が合わなくなったときの直し方

目標は、立てたときの状況に合わせたものです。状況が変われば、目標も変えます。直すタイミングは次のとおりです。

  1. 目標が早く達成できた：次の段階の仕事を足し、力の目標も一段上げる
  2. 目標に届かない：仕事の手順や質問できる相手が足りているかを先に確かめる。本人の努力だけの問題にしない
  3. 学期が切り替わった：出勤できる時間が変わったら、量に関わる目標を見直す
  4. 本人の関心が変わった：別の仕事に関心が移ったら、部署の中で近い仕事がないかを探す

目標を直すことは、失敗ではありません。直した理由を記録しておくと、本人の成長の過程が分かり、次の振り返りで話しやすくなります。節目ごとの見直しは長期インターン生の育成計画とあわせて考えると整理しやすくなります。

エージェントベストの見解

当社は人材紹介も行っているので、学生が就職活動で何を話すかも見ています。長期インターンを経験した学生は、面接で「インターンで何をしたか」をよく聞かれます。そのとき、目標を立て、直し、振り返った経験がある学生は、自分の言葉で具体的に話せます。目標の話し合いは、会社にとっては仕事を進める道具ですが、本人にとっては経験を言葉にする練習でもあります。この点を最初の面談で伝えると、目標を「書かされるもの」ではなく「自分のためのもの」と受け止める学生が増えます。インターン生が自社に入らなくても、在学中に良い経験をした会社として話してもらえることは、次の募集の助けになります。

目標の立て方や振り返りの進め方を、受け入れの体制に合わせて整理します。いま受け入れている途中の相談でも構いません。

運用の相談をする

まとめ

  • 目標は、会社が任せたい仕事と本人が伸ばしたい力をすり合わせて決める
  • 任せたい仕事の候補を先に持ち、本人の希望を聞いてから重なる部分を選ぶ
  • 「仕事の目標」「力の目標」「確かめ方」を分けて、二つか三つに絞って書く
  • 目標を見る人と見る日を、目標と同時に決める
  • 達成・未達・学期の切り替わり・関心の変化に合わせて目標を直す

よくある質問

目標を立てるのは、受け入れてからどのくらいの時期がよいですか

初日に仮の目標を立て、最初の数週間の仕事を経験したあとに本人と話して決め直す流れが進めやすいです。仕事の中身を知らないうちに立てた目標は、実際の仕事とずれることが多いためです。

目標の達成度を、時給や評価に反映してよいですか

反映の仕方は会社によって異なります。ただし、賃金の決め方には法令で定められた項目があるため、評価と時給を結びつける場合は、社労士や公式の案内で確認してから決めてください。評価の考え方は長期インターン生の評価とフィードバックの返し方で整理しています。

本人が目標を思いつかない場合はどうすればよいですか

無理に決めず、会社が任せたい仕事の中から一つを選んでもらい、その仕事を一人でできるようになることを最初の目標にします。仕事に慣れてくると、やってみたいことが見えてくる学生は少なくありません。
