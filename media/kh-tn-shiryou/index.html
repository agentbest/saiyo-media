採用の社内資料の作り方

採用担当者は、経営者への報告、現場への依頼、会議の議題と、毎週のように社内向けの資料を作ります。時間をかけて作っても、読まれずに終わる、質問が別のところに飛ぶ、ということが少なくありません。結論から言うと、採用の社内資料は「誰が読むか」と「その人に何を決めてほしいか」を冒頭の一行に書き、そのあとに根拠を並べる形にすると、読まれて、判断につながります。 この記事では、資料の種類の分け方、一枚の型、数字の見せ方、作る手間の減らし方を整理します。

社内資料は読む人で三つに分ける

採用の資料は、内容よりも先に、読む人で分けます。読む人が違えば、知りたいことも、使える時間も違うからです。

読む人知りたいこと資料の形
経営者・役員計画どおりか、判断が要ることはあるか一枚。結論と判断事項を先に
現場の責任者自分に何を頼まれているか、いつまでか依頼の一覧。期限と所要時間を添える
面接官・協力する社員候補者のこと、自分の役割候補者ごとの短い要約と、見る観点

一つの資料で全員に向けて書こうとすると、経営者には細かすぎ、現場には何を頼まれているのか分からない資料になります。同じ数字を使っていても、読む人ごとに切り口を変えて作るほうが、結果として手間は減ります。

冒頭の一行に「決めてほしいこと」を書く

資料の一番上には、タイトルの次に、読む人に求めることを一行で書きます。

  • 「営業職の求人票を、この修正案で公開してよいかを決めてください」
  • 「来週の二次面接に出られる日を、金曜までに教えてください」
  • 「今月の進み具合の報告です。判断が要る事項はありません」

3つ目のように、判断が要らない資料であることを書くのも大事です。読む人は、自分が何かを決めなければならないのかを最初に知りたいので、それが分かれば読み方を変えられます。

この一行のあとに、判断の根拠を並べます。根拠は、事実、そこから読めること、案、の順に書きます。事実と推測が混ざると、読む人は資料全体を疑い始めます。

社内に説明するための媒体の比較が要るときは、3媒体を並べた整理をご用意します。比較だけでもどうぞ。

媒体選びを相談する

エージェントベストの見解

媒体の申込を社内で通すときの資料で、よく見る誤りがあります。媒体の特徴や機能を並べることに紙面を使い、「なぜ今、この媒体なのか」が書かれていないことです。経営者が知りたいのは機能の一覧ではなく、自社の採用の課題に対して、その媒体がどう効くかと、運用に誰の時間がどれだけ要るかです。当社は3媒体の申込から運用までを見ていますが、申込のあとに運用が止まる会社は、社内資料の段階で運用の時間が書かれていないことが多いです。勧めているのは、媒体の資料に「誰が、週にどのくらい、何をするか」の一行を入れることです。この一行があると、経営者は費用だけでなく人の時間も含めて判断でき、申込のあとで「そんなに手間がかかるとは聞いていない」と言われることが減ります。社内での通し方は代理店選びの社内の通し方も参考になります。

一枚の型｜経営者向けの報告

経営者向けの定例の報告は、次の型で一枚にまとめます。

  1. 判断が要ること：なければ「なし」と書く
  2. 計画との差：採用の計画に対して、進んでいるか、遅れているか。遅れているなら、どの段階か
  3. 先週から変わったこと：応募、面接、内定のうち、動きがあったところだけ
  4. 次にやること：担当者が次の期間に何をするか
  5. 補足：細かな数字や候補者の一覧。読まなくても判断できる位置に置く

この順番は、読む人が途中で読むのをやめても、判断に要ることが先に伝わるように並べています。補足に回した数字は、質問が来たときに見せられれば十分です。経営者への報告の中身は、経営への採用の報告でも詳しく扱っています。

数字の見せ方｜比べる相手を一緒に置く

数字を資料に載せるときは、数字だけを並べず、比べる相手を一緒に置きます。

  • 計画と比べる：今月の応募の数を、計画で見込んだ数と並べる
  • 前の期間と比べる：先週や先月と比べて、増えたか減ったか
  • 段階どうしを比べる：応募から面接、面接から内定へ、どこで減っているか

比べる相手がない数字は、読む人が多いのか少ないのかを判断できません。「応募が少ない」と書くより、「計画より少なく、とくに書類から面接に進む段階で減っている」と書くほうが、次の打ち手の話につながります。

数字の定義も、一度決めたら変えないようにします。「応募」に媒体経由のスカウトの返信を含めるのかどうかが月によって違うと、比べる意味がなくなります。定義は資料の末尾に一行で書いておきます。

集計や資料の下書きに時間を取られているなら、運用の部分を外に出す形もあります。相談だけでも構いません。

運用の相談をする

エージェントベストの見解

これをやる前に、先に「数字をどこから取るか」を決めておかないと、資料づくりの手間は減りません。媒体の管理画面、応募の管理表、面接官のメモと、数字の出どころが散らばっていると、毎週の資料のたびに集め直すことになります。当社が運用を見ている会社でも、資料づくりが重い会社ほど、媒体ごとに別の表を作っています。勧めているのは、媒体を問わず一つの表に、候補者ごとに「どの媒体から来たか」「今どの段階か」を記録することです。OfferBoxのスカウトの返信も、ワンキャリアの応募も、紹介の推薦も、同じ表に入れます。表が一つになれば、資料の数字はその表から数えるだけになり、資料づくりは集計ではなく、読み取りと案を書く作業になります。

作る手間を減らす方法

社内資料に毎週何時間も使っているなら、次の順で手間を減らします。

  1. 型を固定する：毎回の資料を同じ型にし、変わったところだけ書き換える
  2. 数字の出どころを一つにする：前の見解で触れたとおり、表を一本化する
  3. 読む人に必要な分だけ作る：経営者向けに作った詳細な資料を、現場向けにそのまま流用しない
  4. 口頭で済むものは資料にしない：判断が要らない報告は、短い連絡で済ませる

資料を作る時間は、採用担当者の1週間のなかで後回しにされやすい作業です。時間の置き方は採用担当者の1週間の組み方にまとめています。

まとめ

  • 社内資料は、経営者・現場・面接官と、読む人で分けて作る
  • 冒頭の一行に、読む人に決めてほしいことを書く。判断が要らないこともそう書く
  • 経営者向けの報告は、判断事項、計画との差、変化、次にやることの順で一枚にする
  • 数字には比べる相手を置き、定義を変えない
  • 数字の出どころを一つの表にまとめると、資料の手間が減る

よくある質問

経営者が資料を読んでくれません

資料が長いか、冒頭で何を求めているかが分からないことが多いです。一番上に「判断してほしいこと」を一行で書き、残りは補足に回します。それでも読まれないなら、資料を渡すのではなく、短い時間をもらって口頭で一行目だけを伝えます。

現場への依頼の資料はどう書けばよいですか

頼むこと、期限、かかる時間の三つを先に書きます。「面接に出てください」ではなく、「この日のこの時間に、一時間ほど、二次面接に出てください」のように具体にします。現場との調整の進め方は現場との調整で整理しています。

資料に候補者の個人情報を載せてもよいですか

社内での選考に必要な範囲にとどめ、配る相手を限ります。会議用の資料に候補者の詳細を載せる場合は、配布の範囲と、会議のあとの扱いを決めておきます。扱い方は候補者の個人情報の扱いにまとめています。
