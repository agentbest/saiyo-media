インサイドセールスの長期インターン求人原稿｜学生が応募を決める書き方

インサイドセールスの長期インターンは、学生にとって名前は聞いたことがあっても、中身が想像しにくい仕事です。「電話をかけ続ける仕事」と受け取られると、それだけで応募をためらう学生も少なくありません。結論から言うと、インサイドセールスの求人原稿は、電話への不安に先回りして「誰に」「どの手段で」「何を話し」「どう記録するか」を具体的に書くと、学生は自分にできる仕事かどうかを判断しやすくなります。 この記事では、Infraにインサイドセールスの原稿を出す会社の担当者に向けて、タイトル、冒頭、仕事内容、条件、見直す点の順に整理します。採り方と任せ方の全体はインサイドセールスの長期インターンを採るで書いています。

インサイドセールスの原稿で学生が確かめること

インサイドセールスの原稿を開いた学生は、次の点を確かめています。

  • 連絡する相手：まだ取引のない会社か、資料を請求した会社か、既存のお客様か
  • 連絡の手段：電話が中心か、メールやチャットもあるか
  • 話す内容：決まった型があるか、自分で考えて話すのか
  • ゴール：何ができたら一件の仕事が終わるのか。商談の日程を決めることか、情報を聞き取ることか
  • 断られたとき：冷たい対応を受けたときに、どう扱われるのか

インサイドセールスへの不安の多くは、「見知らぬ相手に電話して、断られ続ける」という想像から生まれます。実際の仕事が、資料を請求した会社への連絡や、既存のお客様への案内が中心なら、それを原稿の早い位置に書くだけで、受け取られ方は大きく変わります。

タイトルと冒頭で「誰に連絡する仕事か」を示す

インサイドセールスのタイトルは、職種名だけでなく、連絡する相手と学生の始め方を入れます。

  • 避けたい例：「テレアポ・インサイドセールスのインターン募集」
  • 書き直した例：「資料請求をした企業への連絡が中心｜メール対応から始めるインサイドセールス」

「テレアポ」という言葉は、学生に飛び込みの電話を想像させやすい言葉です。実態に近い言葉を選び、相手と始め方を示します。

冒頭の数行では、仕事の流れを一続きで見せます。

書き方の例

私たちは、会社の経理の手間を減らすサービスを提供しています。インターン生には、サービスの資料を請求した企業のご担当者に連絡し、困りごとを伺って、営業担当との打ち合わせの日程を決める仕事をお願いします。

最初はメールでのご連絡と、社員の電話を横で聞くところから始めます。話す内容には型があり、慣れるまでは型に沿って進めます。

相手、手段、型、ゴールが冒頭で分かると、学生は続きを「自分にできるか」を確かめるつもりで読めます。

インサイドセールスの原稿で、電話への不安にどう先回りするか。いまの原稿を見ながら一緒に考えます。

無料で相談する

仕事内容は「一件の流れ」で書く

インサイドセールスの仕事内容は、作業の名前を並べるより、一件の連絡の流れで書くと伝わります。

  1. 連絡の前：相手の会社の情報と、これまでのやり取りの記録を確かめる
  2. 連絡する：型に沿って、相手の困りごとを伺う。電話がつながらなければメールで連絡する
  3. ゴールにつなぐ：営業担当との打ち合わせの日程を決める。今は必要ないという相手には、次に連絡する時期を伺う
  4. 記録する：話した内容と次の動きを、顧客管理の表やシステムに残す

流れで書くと、電話をかけている時間は仕事の一部にすぎないことが学生に伝わります。準備と記録の比重が大きいことを知ると、話すことに自信がない学生でも、自分の得意を活かせる場面を思い描けます。

話す内容の型があることも、原稿に書いておきます。型そのものを載せる必要はありませんが、「最初の一言、伺う質問、日程の決め方には型があり、入ってから一緒に練習します」と書くだけで、学生の不安は和らぎます。

エージェントベストの見解

インサイドセールスの原稿について相談で多い思い込みは、「件数の多さや報酬の高さを前に出せば応募が集まる」というものです。当社は掲載後の応募対応まで見ていますが、件数や報酬を強く打ち出した原稿には、続けて働くより短く稼ぎたい学生が集まりやすく、受け入れてから記録の丁寧さや話し方の改善を求めたときに噛み合わないことがあります。インサイドセールスで伸びるのは、断られたときに記録を見直し、次の一言を変えられる学生です。原稿で前に出すべきなのは、件数より「一件ごとに振り返る時間がある」「型を一緒に直していく」といった、仕事の進め方です。そこに惹かれて応募してくる学生のほうが、受け入れたあとに型を育てる相手になります。

断られたときの扱いと、ゴールの定義を書く

インサイドセールスでは、断られることは日常です。原稿では、それを隠さずに、断られたときにどう扱うかを書きます。

  • 断られた連絡も、記録して振り返る材料にすること
  • 強い口調で断られたときは、担当社員に引き継いでよいこと
  • 断られた件数ではなく、話の進め方を振り返ること

あわせて、一件の仕事のゴールを定義します。「打ち合わせの日程が決まったら一件」「困りごとを聞き取って記録できたら一件」のように、学生が自分で達成を確かめられるゴールにします。ゴールが曖昧なまま件数だけを追うと、学生はかけた電話の数で自分を測るようになり、疲れやすくなります。

条件の欄で書いておきたいこと

条件の欄には、勤務の日数と時間の目安、勤務地、時給、試験期間の扱いに加えて、インサイドセールスならではの次の点を書きます。

  • 連絡する時間帯：相手の会社の営業時間に合わせて、平日の日中が中心になること
  • オンラインでの勤務の可否：電話や顧客管理のシステムを自宅から使えるか。使えるなら、静かな環境が必要なことも書く
  • 使う道具：電話の仕組み、顧客管理のシステムなど。名前を出せない場合は種類だけでよい

平日の日中が中心の仕事は、授業との両立が課題になります。「授業の空き時間に入れる」「週の勤務日は相談して決める」のように、学生が予定を組めるかどうかが分かる書き方にします。インターン生の労働時間の扱いには法令で定められた項目があるため、条件の書き方は社労士や公式の案内で確認しておきます。

原稿を見直すときの点

インサイドセールスの原稿を見直すときは、次の点を確かめます。

  • 冒頭で、連絡する相手が分かるか
  • 電話以外の手段や、準備と記録の仕事が書かれているか
  • 話す内容に型があること、練習の時間があることが書かれているか
  • 一件のゴールが定義されているか
  • 断られたときの扱いが書かれているか

応募が来ても面接に進まない場合は、電話の仕事について、原稿と面接での説明がずれていないかも確かめます。原稿全体の組み立てはInfraの求人原稿の書き方、応募後の動きは長期インターンの選考の速さで整理しています。

原稿の作成、応募への返信、面接の日程調整まで、Infraの運用を代理店としてお手伝いしています。

運用の相談をする

エージェントベストの見解

インサイドセールスの長期インターンを考えている会社から、「営業職として募集するか、インサイドセールスとして募集するか」を聞かれることがあります。先に確かめたいのは、学生が担う仕事の中心が「話して決める」ことか、「聞いて記録し、次につなぐ」ことかです。前者なら営業職として、後者ならインサイドセールスとして書くほうが、原稿と実態がずれません。当社は人材紹介で営業系の中途採用にも関わっていますが、職種名と中身がずれた求人は、応募する側の期待がずれ、面接や入社後に話が合わなくなる傾向があります。インターンでも同じで、職種名は学生が最初に目にする約束です。迷うときは、担当社員が学生に毎日何をしてほしいかを書き出し、その中で一番時間を使う仕事の名前で募集してください。営業職として書く場合は営業職の長期インターン求人原稿を参考にしてください。

まとめ

  • インサイドセールスの原稿は、連絡する相手・手段・話す内容の型・ゴールを具体的に書く
  • タイトルと冒頭で、誰に連絡する仕事か、どこから始めるかを示す
  • 仕事内容は一件の流れで書き、準備と記録の比重を見せる
  • 断られたときの扱いと、一件のゴールの定義を書いておく
  • 条件は連絡する時間帯と授業の両立が見える書き方にし、法令に関わる点は確認する

よくある質問

新規の会社への電話が中心です。どう書けばよいですか

隠さずに書いたうえで、最初は型の練習と社員の電話を聞く段階があること、断られたときに引き継げることを添えます。準備と記録の仕事があることも書くと、話すことだけが仕事ではないと伝わります。

件数の目標は原稿に書くべきですか

目標がある場合は、入ってすぐではなくどの段階から持つか、件数のほかに何を見るかを一緒に書くことを勧めます。件数だけを書くと、学生は厳しい仕事を想像しがちです。

入ってからの最初の1か月はどう組めばよいですか

聞く、型を覚える、メールで連絡する、電話をかけるの順に、週ごとに一段ずつ広げる組み方をインサイドセールスの長期インターン生の最初の1か月で書いています。
