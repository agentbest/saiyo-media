「採用体制」の記事

「採用体制」のタグが付いた記事です。媒体ごとの柱・媒体比較・採用ノウハウをまたいで並べています。

21件

  • 媒体ごとの予算配分の考え方｜役割を決めてから額を割る 媒体ごとの予算配分は、各媒体に「何を担わせるか」の役割を決めてから割ると、途中で止まりません。役割の決め方、固定費と成功報酬の組み合わせ、担当者の時間という第二の予算、期の途中で配分を動かす合図、配分を均等にしない理由を整理します。 採用ノウハウ採用計画・体制
  • 地方企業の採用計画｜商圏と採用圏の違い 地方企業の採用計画は、商売の範囲（商圏）と採れる範囲（採用圏）が重ならないことを前提に組むと、計画が現実に合います。採用圏を三つの層に分ける方法、層ごとの時期と入口の置き方、移動と面接の設計、計画に書く項目を整理します。 採用ノウハウ採用計画・体制
  • 採用に現場を巻き込む仕組み 採用に現場を巻き込むには、頼む作業を具体にし、時間の負担を減らし、結果を返し、評価に反映する四つを仕組みにします。現場が動かない理由、頼む作業の絞り方、面接の枠と基準のそろえ方、現場の時間を守る工夫、続けるための循環を整理します。 採用ノウハウ採用計画・体制
  • 人事1人で採用を回す体制 人事が1人の会社で採用を回すには、やらないことを先に決め、返信と面接の日程だけは止めない仕組みを作り、文面やスカウトの作業を型と外部で軽くします。1人で抱えるときに起きる停滞、時間の使い方、現場と経営との接点の持ち方、外に出す範囲を整理します。 採用ノウハウ採用計画・体制
  • 一括採用と通年採用の使い分け｜職種と受け入れで決める 一括採用と通年採用は、どちらかを選ぶものではなく、職種・受け入れの仕組み・面接官の時間・候補者の動き方の四つの軸で、採用ごとに使い分けるものです。負荷のかかり方の違い、四つの判断軸、組み合わせの型、片方から移すときの手順を整理します。 採用ノウハウ採用計画・体制
  • 採用方針を経営と合意する方法｜人数の前に決める五つ 採用方針を経営と合意するには、人数ではなく「誰を採り、誰を採らないか」「採れなかったときにどうするか」まで一枚にまとめて決裁をもらうことが要ります。合意する五つの項目、取り方の手順、途中で崩れる典型と防ぎ方を整理します。 採用ノウハウ採用計画・体制
  • 採用計画の振り返り｜来期に残すこと 採用計画の振り返りは、期末に反省を並べる場ではなく、来期の計画に「残すもの」を決める場です。振り返る順番、計画と実際のずれの見方、残すものと捨てるものの分け方、文書の型、来期の計画への渡し方を、人事と現場と経営で共有できる形で整理します。 採用ノウハウ採用計画・体制
  • 採用担当が兼務のときの時間の作り方 採用担当が兼務のときは、本業との優先順位を上司と合意し、週の固定枠と当日中の即応に時間を分け、文面と日程の作業を型にして減らします。兼務で時間が消える原因、上司との合意の取り方、時間を減らす型、外に出す範囲を整理します。 採用ノウハウ採用計画・体制
  • 新しい拠点の採用計画｜本社の型を持ち込まない組み方 新しい拠点の採用計画は、本社の採用の型をそのまま持ち込まず、立ち上げの責任者を先に決め、開設前・開設直後・安定後の三つの時期に分けて本社と拠点の分担を組むことから始めます。最初に決める三つ、時期ごとの採用、分担、地域の候補者の見方。 採用ノウハウ採用計画・体制
  • 採用を止める・減らすときの判断と対応｜候補者と媒体の扱い 採用を止める・減らすときは、「止める」の中身を全停止・一部停止・先送り・条件の絞り込みの四つに分け、進行中の候補者と内定者、媒体の契約、再開のときに残すものを順に決めます。判断の基準、止め方の種類、候補者への伝え方、媒体の扱いを整理します。 採用ノウハウ採用計画・体制
  • 急に採用人数が増えたときの対応｜増やす前に確かめる三つ 急に採用人数が増えたときは、媒体を増やす前に「本当に採用で埋めるのか」「いつまでに」「同じ水準か」の三つを確かめ、面接官の時間と受け入れの体制という増やせない資源に合わせて手段を重ねます。確かめる順番、手段の重ね方、選考の組み替え方。 採用ノウハウ採用計画・体制
  • 年間の採用カレンダーの作り方｜会社の暦に採用を重ねる 年間の採用カレンダーは、媒体の日程を並べるものではなく、会社の繁忙期・決算・評価の暦の上に新卒・中途・インターンの採用を重ね、「誰がいつ時間を出せるか」を見える形にするものです。四つの層の重ね方、作る手順、月ごとの見直し方を整理します。 採用ノウハウ採用計画・体制
  • 採用の定例会議の進め方｜報告で終わらせず決める場にする 採用の定例会議は、進捗の報告会ではなく「来週までに何を変えるか」を決める場にすると機能します。参加者の決め方、議題の順番、持ち込む数、決めること・決めないこと、議事録の型を、人事と現場と経営の三者で回せる形で整理します。 採用ノウハウ採用計画・体制
  • 採用計画の見直しポイント｜計画どおりに進まないとき 採用計画が予定どおり進まないときは、計画全体を作り直す前に、ずれている段を一つ特定し、運用・要件・入口・計画の順に動かせる所を探します。ずれに気づく合図、見直す順番、人数と時期のどちらを動かすか、やってはいけない見直しを整理します。 採用ノウハウ採用計画・体制
  • 新規事業の採用計画｜要件が固まらないときの進め方 新規事業の採用計画は、要件が固まるのを待たず、「固まらないもの」と「今決められるもの」を分け、最初の一人を役割の幅で定義し、段階を分けて採ることで進められます。決められる四つ、最初の一人の決め方、段階の分け方、見直しの時期を整理します。 採用ノウハウ採用計画・体制
  • 新卒と中途の採用を同時に動かすときの整理 新卒と中途を同時に動かすときは、時間軸・人数と予算・担当・媒体・報告の五つを分けて整理すると、どちらかが止まる事態を防げます。混ぜたときに起きる問題、分ける項目、面接官の時間が重なる月の避け方、一つの計画表にまとめる型を整理します。 採用ノウハウ採用計画・体制
  • 複数職種を募集するときの優先順位｜先に動かす職種の決め方 複数の職種を同時に募集するときは、全部を均等に進めるのではなく、「入社が遅れると事業が止まる度合い」と「採るまでにかかる時間」の二軸で先に動かす職種を決めます。優先順位の付け方、媒体と面接枠の割り当て、後回しにした職種の扱い方を整理します。 採用ノウハウ採用計画・体制
  • スタートアップの採用計画｜資金調達と採用の関係 スタートアップの採用計画は、資金調達の時期と使える期間に採用を結びつけて組むと、採りすぎも採り遅れも減ります。調達と採用が結びつく仕組み、調達の前後で分ける計画の型、順番の決め方、止める判断を先に置く理由、入口の選び方を整理します。 採用ノウハウ採用計画・体制
  • 採用体制の作り方｜人事・現場・経営の役割 採用体制は、人事・現場・経営のそれぞれが「決めること」「動くこと」「会うこと」のどれを持つかを先に決めると機能します。役割が曖昧なときに起きる停滞、三者の役割の分け方、決める場の持ち方、規模が変わったときの直し方を整理します。 採用ノウハウ採用計画・体制
  • 採用管理の道具の選び方｜表計算からATSまで 採用管理の道具は、採用人数ではなく「誰が見るか」「媒体の数」「引き継ぎの必要」で選びます。表計算、媒体の管理画面、採用管理システム（ATS）の三段階が回る条件、切り替えの目安、選ぶときに確かめる項目、入れる前に決める運用の決まり。 採用ノウハウ採用計画・体制
  • 採用費の使い方を経営に報告する型｜使った額より何を買ったか 採用費の報告は、使った額を並べるのではなく「何を買い、何が残り、次に何を決めてほしいか」の順で組むと経営が判断できます。報告の骨格、入口ごとの分け方、固定費と成功報酬の見せ方、使い残しと超過の説明、報告の頻度を整理します。 採用ノウハウ採用計画・体制
