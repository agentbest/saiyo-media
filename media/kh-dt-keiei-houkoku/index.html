経営への採用報告の型｜数字・読み・お願いの三段で一枚

経営会議で採用の状況を報告する時間は短い。数字を並べて説明しているうちに時間が過ぎ、「で、どうするの」と聞かれて終わる。採用担当者からよく聞く悩みです。結論から言うと、経営への採用報告は「数字」「その読み」「経営へのお願い」の三段で一枚にまとめると、説明で終わらず、判断をもらえる報告になります。 経営が知りたいのは数字そのものより、計画どおりに進んでいるか、自分が何を決めればよいかです。この記事では、三段の型と、載せる数字の選び方、読みの書き方、お願いの出し方を整理します。

報告が説明で終わる理由

採用の報告が判断につながらないのは、たいてい次のどれかです。

  • 数字を全部載せ、どれが大事かが分からない
  • 数字の意味を説明するだけで、良いのか悪いのかを言っていない
  • 悪い数字を後ろに回し、時間がなくなって触れられない
  • 経営に何を決めてほしいかを書いていない
  • 毎回、報告の形が違い、前回と比べられない

どれも、報告する側が「全部を正確に伝えなければ」と考えるほど起きやすくなります。経営に向けた報告は、全部を伝える場ではなく、判断をもらう場だと考えて組み立てます。

一枚の型｜数字・読み・お願い

報告は、次の三段で一枚にまとめます。

段書くこと分量の目安
数字計画に対する進み具合を示す数字を、三つか四つ表一つ
読み数字から何が言えるか。計画どおりか、遅れているか、その理由三行ほど
お願い経営に決めてほしいこと、協力してほしいこと一つか二つ

三段の順番は変えません。毎回同じ順番、同じ数字で報告すると、経営は前回との違いだけを見ればよくなり、報告の時間が短くなります。

細かい数字や入口ごとの内訳は、一枚の後ろに付けておき、聞かれたときに出します。一枚の中には入れません。採用KPIの報告の考え方は採用KPIを経営に報告する方法でも扱っています。

経営に「どの媒体にいくら使うか」を報告する前に、3媒体を並べた比較を一緒に整理します。比較だけでもどうぞ。

媒体選びを相談する

載せる数字の選び方

一枚に載せる数字は、計画との差が分かるものに絞ります。多くの会社で使えるのは次の四つです。

  1. 目標に対する累計：内定・承諾・入社が、計画の人数に対してどこまで来たか
  2. これから見込める数：いま選考中の候補者のうち、内定まで進みそうな人数の目安
  3. 使った費用と予定の費用：予算に対して、どこまで使ったか
  4. 変えたこととその結果：前回の報告から変えたこと一つと、その結果

二つ目の「これから見込める数」は、経営がいちばん知りたい数です。累計だけでは、残りの期間で計画に届くかが分かりません。選考中の候補者が段ごとに何人いるかを示し、そこから見込める人数を添えます。見込みは外れることもあるので、「いまの通過の様子が続けば」という前提を一言書いておきます。

採用管理システムや台帳から数字を出すときは、数字の定義をそろえておくことが前提です。定義のそろえ方は採用のダッシュボードの作り方で整理しています。

読みの書き方

数字の下に、読みを三行ほどで書きます。読みは、次の三つの問いに答える形にします。

  • 計画どおりか：計画より進んでいるか、遅れているか
  • 理由は何か：遅れているなら、どの段で、なぜか
  • このままだとどうなるか：何もしなければ、期末にどこまで届きそうか

たとえば、「内定は計画の途中まで来ている。ただし、最終面接の日程が合わず、最終の前で止まっている候補者がいる。このままだと、期末の内定は計画に届かない見込み」。このように、数字の意味ではなく、数字から言えることを書きます。

読みには、担当者の考えを入れて構いません。経営は数字の説明より、現場をいちばん見ている担当者の読みを聞きたいと考えていることが多いからです。

エージェントベストの見解

経営への報告で、悪い数字を後ろに回したり、言い訳を添えたりしたくなるのは自然なことです。ただ、媒体の申込後の運用まで見ていると、採用が計画に届かなかった会社では、遅れが見えた時点で経営に伝わっていなかったことが少なくありません。経営が早く知っていれば、最終面接の日程を空ける、条件を見直す、入口を足す、といった判断ができたかもしれない場面です。勧めているのは、悪い数字こそ一枚の最初に置き、読みとお願いをすぐ後ろに続けることです。「遅れている。理由はここ。経営にはこれを決めてほしい」と並べると、悪い数字は担当者の失敗の報告ではなく、判断をもらう材料になります。報告の順番を変えるだけで、経営の反応が変わる会社があります。

お願いの出し方

三段目のお願いは、経営にしか決められないことを一つか二つ書きます。

  • 時間のお願い：最終面接の日程を週に一枠空けてほしい、内定者と話す場に出てほしい
  • 判断のお願い：条件の幅を広げるか、採用人数を見直すか、入口を足すか
  • 予算のお願い：使う予定の費用を、ある入口から別の入口に移してよいか

お願いは、選択肢の形で出すと決めてもらいやすくなります。「入口を足すか、今の入口で文面を見直すか、どちらにするか」のように二つ並べ、それぞれの見込みと担当者のおすすめを添えます。経営にゼロから考えてもらう形にすると、その場で決まらず、次の会議に持ち越されます。

お願いがない月もあります。その場合は、「今月はお願いなし。計画どおり進めます」と書きます。三段目を空けたままにしないことで、経営は今月決めることがないと分かります。

「入口を足すか、今の媒体の運用を見直すか」。経営に出す選択肢を作る段階から相談できます。

報告の頻度と準備の手順

報告の頻度は、会社の経営会議に合わせます。多くの会社では月に一度、四半期ごとに少し長めの報告を加える形が使いやすい形です。

準備は、次の手順で進めます。

  1. 台帳や採用管理システムから、決まった数字を出す：毎回同じ数字を、同じ定義で出す
  2. 前回の報告と並べる：前回から何が変わったかを確かめる
  3. 読みを三行で書く：計画どおりか、理由、このままだとどうなるか
  4. お願いを選択肢で書く：経営にしか決められないことだけ
  5. 後ろに付ける資料をそろえる：入口ごとの内訳、段ごとの日数など、聞かれたときに出すもの

週次で見ている細かい数字は、経営の報告には載せません。週次と月次で見る数の分け方は週次で見る数字と月次で見る数字で整理しています。費用の使い方を報告するときは、採用予算の効果の見方も参考になります。

エージェントベストの見解

経営への報告で、媒体の数字をどう載せるかに迷う会社は多いです。3媒体を扱っている立場から勧めているのは、媒体ごとの数字を一枚の中に並べないことです。OfferBoxのようなスカウト型、ワンキャリアのような掲載・クチコミ型、Greenのような中途の求人型では、数字の動き方も、成果が出るまでの時間も違います。一枚の中に並べると、経営は数の大小で媒体を比べ、成果が出るまでに時間のかかる媒体を早く見切る判断をしがちです。一枚には入口をまたいだ合計を載せ、媒体ごとの数字は後ろの資料に回し、「この媒体は成果が出るまでにこれくらいかかる前提で見ている」と読みを添えて出す。こうすると、媒体の向き不向きを数の大小ではなく、自社の採用の進み方で判断してもらえます。

まとめ

  • 経営への報告は、数字・読み・お願いの三段で一枚にまとめる
  • 載せる数字は、目標に対する累計、見込み、費用、変えたことの四つが基本
  • 読みは、計画どおりか、理由、このままだとどうなるかの三行で書く
  • お願いは、経営にしか決められないことを選択肢の形で出す
  • 悪い数字は最初に置き、細かい内訳は後ろの資料に回す

よくある質問

経営から細かい数字を聞かれたらどうしますか

一枚の後ろに付けた資料から出します。聞かれる数字がいつも同じなら、それは一枚に載せる数字に入れることを考えます。逆に、一度も聞かれない数字は、後ろの資料からも外して構いません。

経営者が採用に関心を持ってくれません

報告が数字の説明で終わっていると、関心を持たれにくくなります。お願いの段で、経営者にしか決められないことを具体的に出すと、採用が経営の判断に関わることだと伝わります。採用の方針を経営と合わせる方法は採用方針を経営と合意する方法にまとめています。

上司への日々の報告と、経営への報告は同じ形でよいですか

目的が違うので、分けることを勧めます。上司への日々の報告は、進み具合と困っていることを短く伝えるものです。形は採用の進捗を上司に報告する型で整理しています。
