ワンキャリアの企業ページを、他のナビ媒体の企業ページと同じ感覚で「会社紹介」から書き始めると、学生が読みたいものとずれます。ワンキャリアの学生は、募集を探しに来るのではなく、「この会社の選考はどうだったか」「実際はどうか」を、他の学生が書いた選考体験談やクチコミで確かめに来ています。結論から言うと、ワンキャリアの企業ページは、「体験談を読んだ学生が、会社の側の説明を確かめに来る場所」として書きます。最初に置くのは、選考の流れと各段階で何を見るか、仕事の具体と最初の1年、働く人の話、学生からよく聞かれることへの答え、の4つです。会社紹介と魅力の言葉は後ろに回し、自社の体験談を先に読んでから書き、体験談と食い違わないようにします。 この記事では、ワンキャリアの学生の読み方、最初に置く4つ、やりがちな失敗、自社の体験談を先に読むこと、書く順番、他媒体との使い回し、分担を整理します。ワンキャリアと他媒体の違いはワンキャリアとマイナビの違い、3媒体の中での位置づけは3媒体の違いと選び方で書きました。企業ページの項目の名称や構成は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

この作業の目的｜体験談を読んだ学生に、会社の側の説明を渡す

ワンキャリアで学生が読んでいるものの中心は、企業が書いたものではなく、他の学生が書いた選考体験談とクチコミです。学生は、そこで「この会社の選考は、こういう流れで、こういうことを聞かれた」「働いている人はこう言っている」を読み、そのうえで企業ページを見ます。

企業ページの目的は、体験談を読んだ学生に、「会社の側は、選考をこう考えていて、仕事はこうで、働く人はこうだ」という説明を渡すことです。体験談と企業ページが揃っていれば、学生は「体験談のとおりで、会社もそう言っている」と確かめられます。ずれていれば、「体験談と違う」となり、体験談のほうが信じられます。

最初に置く4つ

置くもの中身
1. 選考の流れと、各段階で何を見るか段階の順番、それぞれで誰と何を話すか、何を見ているか（経験ではなく、どんな話を聞きたいか）。体験談に書かれている流れと揃える
2. 仕事の具体と、最初の1年職種ごとに、最初の月・最初の3か月・1年目の終わりに何をしているか。誰が教えるか。書き方は新卒向け募集記事の書き方で書いたのと同じ
3. 働く人の話入社してまもない社員の、入る前と後で違ったこと。場面で。教訓や決意でまとめない
4. 学生からよく聞かれること選考で実際に聞かれた質問と、その答え。体験談で誤解されやすい点への説明。「選考で何を見ていますか」「面接は何回ですか」など

「1. 選考の流れと、何を見るか」を最初に置くのが、ワンキャリアの企業ページの要点です。学生は、体験談で選考の流れを読んでから来ています。会社の側が、同じ流れを、「なぜその段階があるか」「何を見ているか」と一緒に書くと、学生は「体験談のとおりだ」と確かめ、「会社は何を見ているか」を知ります。

いま使っている媒体の運用の相談だけでも構いません。ワンキャリアの企業ページに、最初に何を置くかを一緒に決めます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「企業ページは、会社の魅力を伝える場所だ」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの企業ページの整備を支えていますが、他のナビ媒体の企業ページをそのまま移した会社では、学生の反応が薄いことが多くあります。理由は、ワンキャリアの学生は、魅力の言葉を読む前に、体験談で「実際はどうか」を読んでいるからです。魅力の言葉が、体験談と違えば、体験談が信じられます。当社が企業ページを整えるとき、最初にやるのは、その会社の体験談とクチコミを全部読み、学生が何を読んで来るかを把握することです。そのうえで、体験談に書かれている選考の流れを、会社の側から「何を見ているか」と一緒に書きます。魅力の言葉は、そのあとで足ります。

やりがちな失敗

失敗学生からどう見えるか
会社紹介（沿革、事業、規模）を長く書く体験談で知りたいことは読んだ。会社紹介は読み飛ばす
「成長できる」「風通しが良い」の魅力の言葉だけ体験談と比べられ、抽象語は負ける
選考の流れが書いていない、または体験談と違う「体験談のほうが本当」
仕事の具体が無く、職種名と業務の一覧だけ最初の1年が想像できない
働く人の話が、経歴と「やりがい」だけ体験談のほうが具体的
学生からよく聞かれることに答えていない体験談で誤解されたままになる
一度書いて更新しない選考の流れが変わっても古いまま。体験談は毎年増える
体験談に書かれた「連絡が遅い」などを、企業ページで否定する否定すると、体験談のほうが信じられる。直すのは選考の運用

最も多いのは、最初の「会社紹介を長く書く」です。ナビ媒体の企業ページの型を、そのまま持ってきた形です。

自社の体験談とクチコミを、先に読む

企業ページを書く前に、自社の選考体験談とクチコミを読みます。

  1. 選考の流れが、どう書かれているか：段階の順番、聞かれた質問、連絡の速さ
  2. 学生が引っかかった点：「何を見ているか分からなかった」「連絡が遅かった」「面接官によって違った」
  3. 学生が良いと書いた点：「面接官が話を聞いてくれた」「仕事の具体を教えてくれた」
  4. 誤解されている点：事実と違う記述、古い情報
  5. 社員のクチコミがあれば、働き方についての記述

読んだうえで、企業ページで「補う」ものと、「選考の運用を直す」ものを分けます。「連絡が遅い」と書かれているなら、企業ページで「早く連絡します」と書くのではなく、実際の連絡を早くします。企業ページで補うのは、「何を見ているか」「なぜその段階があるか」のような、会社の側の考えです。クチコミとの向き合い方はワンキャリアとマイナビの違いで書きました。

書く順番

  1. 自社の体験談とクチコミを読む：上のとおり
  2. 選考の流れと、各段階で何を見るかを書く：体験談の流れと揃える。担当と人事で
  3. 学生からよく聞かれることを、体験談と面接の記録から拾って書く：答えは短く、事実で
  4. 仕事の具体と最初の1年を、職種ごとに書く：その職種の人と、新卒入社の人に聞いて
  5. 働く人の話を、入社してまもない社員に頼む：入る前と後の場面で
  6. 会社紹介は、最後に短く：事業の一文、なぜやっているか。詳しくはコーポレートサイトへ
  7. 写真は、普段の仕事中のもの：集合写真や外観より。考え方は会社ページの写真の選び方と同じ
  8. 項目の名称と構成を、管理画面で確認して当てはめる

「会社紹介は最後に短く」が、ナビ媒体との違いです。学生が確かめに来るのは、選考と仕事と人です。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。ワンキャリアの企業ページを最初に整える時間を、4つの要素ごとにお伝えします。

媒体選びを相談する

選考の流れを書くときの注意

「選考の流れ」は、ワンキャリアの企業ページで最も読まれる部分で、書き方に注意が要ります。

  • 体験談と揃える：体験談に書かれている流れと、企業ページの流れが違うと、企業ページが疑われる。変わったなら、「今年度から〇〇に変えた」と書く
  • 各段階で「何を見るか」を、経験ではなく「どんな話を聞きたいか」で：「学生時代に何をしていたかを、場面で聞きます」「その仕事を、自分ならどう進めるかを一緒に考えます」
  • 面接官が誰かを書く：人事か、現場か、役員か。学生は体験談で「面接官によって違う」を読んでいる
  • 連絡の目安を、書けるなら：「結果は〇〇までに連絡します」。書いたら守る。守れないなら書かない
  • 時期は、年度の公表内容と自社の方針を確認して：この記事では時期の具体は書かない

「書いたら守る」が、選考の流れに関する原則です。書いて守らないと、次の年の体験談に「企業ページと違った」と書かれます。

他の媒体の企業ページとの使い回し

OfferBoxやWantedlyの企業ページ・会社ページと、ワンキャリアの企業ページは、同じ材料を使えます。ただし、順番と重みが違います。

材料OfferBoxWantedlyワンキャリア
仕事の具体と最初の1年中心募集記事の中心2番目
働く人の話中心ストーリーの中心3番目
会社の「なぜ」補い会社ページの中心短く最後
選考の流れと何を見るか補い補い最初
学生からよく聞かれること補い補い4番目

「仕事の具体」と「働く人の話」は、3媒体で同じものを使えます。ワンキャリアだけ、「選考の流れと何を見るか」が最初に来ます。OfferBoxの企業ページの書き方はOfferBoxの企業ページの書き方で書きました。材料を貯めて使い回す考え方はコンテンツを資産として貯める考え方で書きました。

更新の考え方

  • 選考の流れが変わったら、その場で直す：最も読まれる部分が古いと、全体が疑われる
  • 体験談が増える時期（選考の後）に、読み直す：新しい体験談で誤解や引っかかりがあれば、企業ページで補うか、運用を直す
  • 年に一度、「よく聞かれること」を面接の記録から足す
  • 働く人の話は、新しい入社者が出たら足す
  • 会社紹介は、事実が変わったときだけ

「体験談が増える時期に読み直す」が、ワンキャリアに特有の更新です。

エージェントベストの見解

これをやる前に、先に決めておかないと企業ページが体験談に負けることがあります。「選考の各段階で、何を見ているか」を、面接に出る人が言葉にできることです。当社がワンキャリアの企業ページを支えるとき、型と順番は当社が出せますが、「一次面接では〇〇を、二次では△△を見ている」という中身は、面接に出る人にしか言えません。「何を見ているか分からなかった」は、体験談で最も多く書かれることの一つで、企業ページでそこに答えられる会社は、学生に「考えて選考している会社」と読まれます。当社が最初にお願いするのは、面接に出る人に「その段階で、どんな話を聞きたいですか」を聞いてもらうことです。その答えがあれば、企業ページの最初の段落は書けます。無ければ、企業ページは会社紹介に戻り、体験談に負けます。

まとめ

  • ワンキャリアの学生は、選考体験談とクチコミを読んでから企業ページに来る。企業ページは「体験談を読んだ学生が、会社の側の説明を確かめに来る場所」
  • 最初に置くのは、選考の流れと各段階で何を見るか、仕事の具体と最初の1年、働く人の話、学生からよく聞かれること、の4つ。会社紹介は最後に短く
  • 会社紹介を長く、魅力の言葉だけ、体験談と食い違う、更新しない、体験談を否定する、が失敗
  • 自社の体験談とクチコミを先に読み、企業ページで「補う」ものと、選考の運用を「直す」ものを分ける
  • 選考の流れは体験談と揃え、「何を見るか」は「どんな話を聞きたいか」で書き、書いたら守る。項目の構成は管理画面で確認し、体験談が増える時期に読み直す

よくある質問

自社の体験談やクチコミが、まだほとんどありません

企業ページを「学生が最初に読むもの」として書きます。その場合も、順番は同じで、選考の流れと何を見るか、仕事の具体、働く人、よく聞かれること、の順です。体験談が無いうちに書いた企業ページが、最初の体験談と揃っていれば、学生は「企業ページのとおりだった」と書きます。

体験談に、事実と違うことが書かれています

企業ページで否定する形にせず、事実を淡々と書きます。「選考の流れは、現在は〇〇です」「面接は△△が担当します」のように。否定の言葉を使うと、学生は体験談の側に立ちます。事実が変わったなら、「今年度から変えた」と書きます。

ワンキャリアの企業ページの整備は、御社に相談できますか

できます。当社は、体験談の読み方の観点、4つの要素の型、書く順番の整理、他媒体との使い回しの整理、更新の型を支えられます。選考の流れの決定、何を見るかの言語化、話す人の確保、選考の運用を直すことは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの掲載の整備を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • ワンキャリアの学生が掲載を見る順番｜体験談→企業ページの最初の段落→働く人→条件→イベント、の順に読まれる前提で置き方を決める
  • グループ企業をワンキャリアに掲載するときの整理｜学生が体験談で「どの会社の選考か」を区別できる単位に分け、共通の材料と各社の固有を分けて置く
  • ワンキャリアで本選考を掲載するときの書き方｜選考体験談を読んだ学生に、「各段階で誰と何を話し、何を見るか」を会社の側から書き、書いたとおりに運用する
  • ワンキャリアで上位に表示されるための考え方｜表示の仕組みを推測して動かそうとせず、学生が探す動きから逆算して「見つけられる状態」を作る
