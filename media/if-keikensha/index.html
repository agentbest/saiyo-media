長期インターン経験者を新卒で採る｜他社経験の見方

新卒の選考で、他社での長期インターンの経験を話す学生が増えています。「スタートアップで営業をしていた」「事業の立ち上げに関わった」といった話を聞くと、即戦力のように感じる面接官もいるでしょう。ただ、長期インターンの経験は、会社名や肩書きで見ると見誤りやすく、「何を任され、何を自分で判断し、どう振り返っているか」で見ると、学生の力が見えてきます。 この記事では、他社で長期インターンを経験した学生を新卒で採るときの見方を整理します。自社で長期インターンを受け入れている会社にとっても、受け入れの設計を見直す手がかりになるはずです。

長期インターンの経験は、中身の幅が広い

長期インターンと一口に言っても、学生が経験している中身はさまざまです。

経験の型内容の例
作業中心決まった手順の作業を繰り返す。データ入力、調べもの、資料の整形など
補助中心社員の仕事の一部を手伝う。資料の下書き、商談の同席、企画の調査など
担当中心一つの業務を任され、自分で進める。顧客への連絡、小さな企画の運営など
判断中心業務の中で、自分で判断する範囲がある。施策の選択、予算の一部の使い道など

同じ「営業のインターン」でも、作業中心の学生と判断中心の学生では、経験の質が大きく違います。会社名や「営業」という職種だけで判断すると、この違いが見えません。

見るべき3つの観点

他社での長期インターンの経験を見るときは、次の3つの観点で聞きます。

1. 任された範囲

何を任されていたのか。担当していた業務の範囲と、その業務が会社の事業のどこにつながっていたかを聞きます。範囲を具体的に話せる学生は、自分の仕事を全体の中で理解しています。

2. 判断の量

自分で判断したことは何か。指示どおりに動いた部分と、自分で決めた部分を分けて聞きます。判断の経験がある学生は、新卒で入社した後も、任せられる範囲が広がるのが早い傾向があります。

3. 振り返りの深さ

うまくいかなかったことは何か。そこから何を学び、次にどう変えたか。振り返りが深い学生は、経験の長さに関係なく、仕事から学ぶ力を持っています。

この3つのうち、最も差が出やすいのは3つ目です。長く続けていても振り返りが浅い学生もいれば、短い期間でも深く振り返っている学生もいます。

新卒の選考で見る項目と、長期インターンの受け入れで見る項目をそろえたい会社はご相談ください。

無料で相談する

面接での聞き方

経験を聞くときは、学生がまとめた成果の話をそのまま受け取らず、具体的な場面に分けて聞きます。

  1. 一番時間を使った仕事を聞く：「インターンで一番時間を使った仕事は何か」と聞くと、実際の業務の中身が見えます。成果として話す内容と、実際に時間を使っていた内容が違うこともあります
  2. その仕事の中で、自分で決めたことを聞く：「その仕事で、誰にも相談せずに自分で決めたことはあるか」と聞くと、判断の量が見えます
  3. うまくいかなかった場面を聞く：「一番うまくいかなかった場面と、その後どうしたか」と聞くと、振り返りの深さが見えます
  4. インターン先の社員から言われたことを聞く：「インターン先の社員から、どんなことを言われたか」と聞くと、周りからどう見られていたかが分かります

「成果」を聞くより、「場面」を聞くほうが、経験の中身が見えてきます。成果は大きく話されがちですが、場面は具体的にしか話せないからです。

エージェントベストの見解

当社は人材紹介も行っていますが、中途採用の面接で前職の経験を見るときも、会社名と肩書きに引きずられて判断を誤る例を見てきました。長期インターンの経験も同じ構図です。知名度のある会社や、勢いのあるスタートアップでのインターン経験は、それだけで評価されやすい。しかし、その会社でどんな仕事を任されていたかは、会社によっても、時期によっても、受け入れた部署によっても違います。当社が面接の設計で勧めるのは、インターン先の会社名を聞く前に、仕事の中身を聞くことです。会社名を先に聞くと、その印象で後の話を解釈してしまいます。仕事の中身を一通り聞いたあとで会社名を聞けば、印象に引きずられずに経験の質を判断できます。面接官が複数いる場合は、この順番を面接の手順としてそろえておくと、評価のばらつきも減ります。

気をつけたい見方の偏り

他社での長期インターンの経験を見るとき、次のような偏りに気をつけます。

  • 経験の有無で差をつけすぎない：長期インターンに参加できるかどうかは、学生の時間や住んでいる地域、家庭の事情などにも左右されます。経験がない学生にも、学業や課外活動で同じ観点を確かめる機会を用意します
  • 経験の長さで判断しない：長く続けたこと自体は評価できますが、長さと質は別です
  • 自社のやり方に合うかどうかで判断しすぎない：他社で身につけたやり方が自社と違っても、それは入社後に学べることがあります

1つ目はとくに大切です。長期インターンの経験を重く見すぎると、参加できなかった学生を選考の段階で不利にしてしまいます。

長期インターンの募集を始めて、自社で経験の場をつくりたい会社は代理店としてお手伝いします。

運用の相談をする

評価の記録に残すこと

面接で聞いた経験は、後で比べられる形で記録しておきます。面接官ごとに印象で書くと、「すごい経験をしている」「話がうまい」といった言葉ばかりが並び、学生同士を比べられなくなります。

記録には、次の欄を設けておくと役立ちます。

  • 経験の型（作業中心・補助中心・担当中心・判断中心のどれに近いか）
  • 任された範囲を、学生がどこまで具体的に話せたか
  • 自分で判断した場面の例
  • うまくいかなかった場面と、その後の行動

この欄で記録すると、長期インターンの経験がない学生についても、学業や課外活動の話を同じ欄に書き込めます。経験の有無ではなく、経験の中身で比べられるようになります。

自社の受け入れの見直しにつなげる

他社で長期インターンを経験した学生の話を聞くと、自社の受け入れを見直す手がかりが得られます。

  • 他社では、学生にどこまで任せているか
  • 学生が「よかった」と話す受け入れの工夫は何か
  • 学生が「物足りなかった」と話すことは何か

面接は学生を見る場ですが、同時に、他社の長期インターンの様子を知る機会でもあります。聞いたことを受け入れ部署と共有すると、自社の受け入れの設計に活かせます。

エージェントベストの見解

他社での長期インターン経験者を新卒で採りたい会社に、当社が提案することがあるのは、自社でも長期インターンの受け入れを始めることです。当社はInfraの代理店として、長期インターンの募集の立ち上げを手伝っています。他社での経験を面接で聞いて判断するのと、自社で数か月一緒に働いて判断するのとでは、見えるものの量がまったく違います。面接では、学生が話したいことしか聞けませんが、受け入れの中では、学生が話さないことも見えます。もちろん、自社で受け入れるには準備と時間が要ります。ただ、新卒の選考で「他社のインターン経験」を重く見ている会社ほど、その経験を自社で提供する側に回ったほうが、採用の質を自分たちで確かめられるようになります。受け入れ側に回るときの全体の流れは長期インターンから新卒採用へつなぐ設計で整理しています。

まとめ

  • 長期インターンの経験は、作業中心から判断中心まで中身の幅が広い
  • 見るべきは、任された範囲・判断の量・振り返りの深さの3つ
  • 面接では成果ではなく場面を聞き、会社名は仕事の中身を聞いた後に聞く
  • 経験の有無や長さで差をつけすぎず、経験のない学生にも同じ観点を確かめる機会を用意する
  • 面接で聞いた他社の受け入れの様子は、自社の受け入れの見直しに活かせる

よくある質問

長期インターンの経験がある学生は、入社後の立ち上がりが早いですか

早い傾向はありますが、経験の中身によります。判断の経験がある学生は早く立ち上がりやすい一方、作業中心の経験だった学生は、新卒として基礎から学ぶ点は他の学生と変わりません。

インターン先の社員に、学生の評価を問い合わせてもよいですか

学生の同意なく問い合わせることは避けるべきです。個人情報の扱いにも関わるため、判断に迷う場合は社内の法務担当や専門家に確認してください。

経験を盛って話している学生を見抜くには、どうすればよいですか

成果ではなく具体的な場面を聞き、その場面で誰が何をしたかを細かく聞いていくと、実際の役割が見えてきます。疑ってかかるより、具体的に聞くことを心がけるほうが、学生も話しやすくなります。
