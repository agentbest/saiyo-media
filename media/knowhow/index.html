  • 採用管理システムでKPIを見る方法｜入れる前に確かめる三つ 採用管理システム（ATS）が出す数は入っている情報から出せる数で、自社が見たい数とは限りません。システムで起きる失敗、入れる前に確かめる三つ、段の名前と入力のルール、媒体の管理画面との違いを整理します。 採用ノウハウ採用KPI
  • 媒体別のKPI設計｜採用全体と分けて二階建てで持つ 媒体別のKPIは媒体を直すための数で、採用全体のKPIとは別に二階建てで持ちます。承認率や返信率をKPIにするなど起きる失敗、媒体ごとに置く三つ、下の階に置く数、媒体の比べ方と配分の決め方を整理します。 採用ノウハウ採用KPI
  • 中途採用のKPI｜新卒と分けて募集ごとに見る数 中途採用のKPIは新卒のKPIをそのまま使わず、募集ごとに「なぜ長引いているか」に答える数を置きます。中途のKPIで起きる失敗、新卒との違い、置く三つ、率をKPIにしない理由、入社後に見る数を整理します。 採用ノウハウ採用KPI
  • 採用KPIのダッシュボードの作り方｜誰が何を決めるために見るか 採用KPIのダッシュボードは、見た目を整える前に誰が、いつ、何を決めるために見るかを決めて作ります。起きる失敗、見る人ごとに三枚に分ける方法、載せる数と載せない数、グラフの選び方、更新が止まらない形を整理します。 採用ノウハウ採用KPI
  • イベントのKPI｜参加者数でなく面談まで来た数で見る イベントのKPIは参加者数や満足度ではなく、参加後に面談まで来た近い人の数、一人を面談に呼ぶまでの費用と時間、当日に現場の社員が話した数の三つです。起きる失敗と、続けるか止めるかの判断を整理します。 採用ノウハウ採用KPI
  • 採用ファネルに置くKPI｜通過率を置かず、日数と近い人の数を見る 採用ファネルの各段に通過率を置くと、率を上げるために人を落とす運用に寄ります。置くのは数・日数・近い人の数の三つで、目標値は最後の段だけです。段の切り方、日数で先に気付く見方、月一度の見方を整理します。 採用ノウハウ採用KPI
  • 採用KPIから改善点を見つける方法｜悪い場所と直す場所は違う 採用KPIで数字が悪い場所と、直す場所は違います。改善で起きる失敗、何を一つ変えるかを決める五つの手順、段ごとに疑う場所、数字ではない三つの材料、変えた後の見方と変えないことの決め方を整理します。 採用ノウハウ採用KPI
  • 採用KPIを経営に報告する方法｜説明でなく判断をもらう報告 採用KPIの経営への報告は、数の説明ではなく判断をその場でもらうためのものです。報告で起きる失敗、毎月載せる四つ、悪い数の出し方、経営に返す二つの選択肢、聞かれたときに出す数、報告の型を整理します。 採用ノウハウ採用KPI
  • 掲載のKPI｜閲覧数ではなく直した日と面談数で見る 掲載のKPIは閲覧数やエントリー数ではなく、近い人が面談まで来た数、掲載を直した日、エントリーから面談までの日数の三つです。起きる失敗、閲覧数の扱い、直した日を記録して前後で比べる方法を整理します。 採用ノウハウ採用KPI
  • 採用KPIの基本｜採る人数に届くかを示す四つの数 採用KPIで測るのは、採る人数に届くかを示す数だけです。測る前に決める三つ（何人・いつまでに・どんな人を）、採用した数や近い人の面談数などKPIの四つ、率の扱い、見ない数字の決め方を整理します。 採用ノウハウ採用KPI
  • 採用リードタイムの見方｜段ごとの日数に割って延びた段を指す 採用リードタイムは入口から入社までの一つの数で見ず、段ごとの日数に割って延びた段を指します。起きる失敗、中央値と最長で見る理由、延びる三つの原因、学生が確かめる時間との両立、週と月の見方を整理します。 採用ノウハウ採用KPI
  • 面接のKPI｜通過率でなく面接官ごとの日数と辞退で見る 面接のKPIは通過率ではなく、面接官ごとの日数、面接官ごとの辞退の数、面接の後に近い人が残った数の三つです。起きる失敗、通過率を置かない理由、評価ではなく型を直すために面接官ごとに割る方法を整理します。 採用ノウハウ採用KPI
  • 採用KPIの目標の決め方｜逆算と時間の上限の小さいほうに置く 採用KPIの目標は前年比や他社並みで決めず、採る人数からの逆算と担当・現場の時間からの上限を出し、小さいほうに置きます。起きる失敗、二つが合わないときに経営に返すこと、見直す時期を整理します。 採用ノウハウ採用KPI
  • 内定のKPI｜承諾した数と承諾までの日数で見る 内定のKPIは出した数や承諾率ではなく、入口ごとの承諾した数、内定から承諾までの日数、入口のずれによる辞退の数の三つです。起きる失敗、内定を出す数の決め方、承諾率と期限切れの扱いを整理します。 採用ノウハウ採用KPI
  • スカウトのKPI｜送った数でなく面談まで来た数で見る スカウトのKPIは送った数や承認率ではなく、近い人が面談まで来た数、一通を書くのにかかった時間、名義ごとの面談数の三つです。承認と面談を分ける理由、文面の型と名義で割る方法、送る数の逆算を整理します。 採用ノウハウ採用KPI
  • 新卒採用のKPI｜二つの卒年を分けて持つ四つの数 新卒採用のKPIは、一年の流れと二つの卒年が重なる前提で、卒年ごとに持ちます。起きる失敗、置く四つ、一年後に出る数を途中で先取りする「先に動く数」、期間ごとの見る数の変え方、学生の層での分け方を整理します。 採用ノウハウ採用KPI
  • 採用KPIの週次レビュー｜日数だけを見て十五分で終える 採用KPIの週次レビューで見るのは日数だけで、数は見ません。週次で起きる失敗、見る三つ（段ごとの日数・延びた段の原因・今週の担当）、資料を作らず十五分で終える進め方、月次との分け方を整理します。 採用ノウハウ採用KPI
  • スプレッドシートで採用KPIを管理する方法｜持つのは三枚だけ スプレッドシートで採用KPIを管理するときは、シートを増やさず台帳・月次の集計・変えた記録の三枚に絞ります。表計算で起きる失敗、台帳の列を十以内にする方法、入力の選択肢化、複数人で使うときの決めごとを整理します。 採用ノウハウ採用KPI
  • 採用単価の計算と見方｜人件費まで入れて入口ごとに出す 採用単価は媒体費だけでなく、代行費・イベントの費用・社内の人件費を足して採用した人数で割り、入口ごとに出します。単価で起きる失敗、人件費の出し方、一年後に残った数で割る理由、高い入口の読み方を整理します。 採用ノウハウ採用KPI
  • 採用KPIの月次レビュー｜翌月に変えることを一つ決める 採用KPIの月次レビューで決めるのは、翌月に変えることを一つだけです。月次で起きる失敗、見る三つ（入口ごとの近い人の面談数・日数の前年比・文面と名義と掲載の効果）、四十五分の進め方を整理します。 採用ノウハウ採用KPI
  • 内定の出し方と伝え方｜電話・書面・現場の一通で伝える順番 内定は選考の続きとして、出す前に条件を聞き、電話の一言、書面、現場からの一通の順で伝えます。内定の伝え方で起きる失敗、書面に入れるもの、伝えるときに言わないこと、出した後の接点を整理します。 採用ノウハウ内定辞退・承諾率
  • 内定者向けイベントの企画｜誰と何をするかを見せる三つの中身 内定者向けイベントは懇親会ではなく、入社したら誰と何をするかを内定者が自分の目で見る場です。起きる失敗、配属先の見学・現場の仕事・同期と会うの三つの中身、一年に二つか三つに絞る理由、企画の順番を整理します。 採用ノウハウ内定辞退・承諾率
  • 内定者に課題を出すときの注意｜出すかの判断と、守る四つ 内定者への課題は学ばせるためではなく、確かめてもらうために出します。課題で起きる失敗、出すか出さないかの判断、出すなら守る四つ（配属先の仕事の一場面・短く・一人で・評価しない）、課題の型を整理します。 採用ノウハウ内定辞退・承諾率
