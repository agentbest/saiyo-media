ワンキャリアでエントリーが来ないときの見直し順

公開 2026-09-12

ワンキャリアに掲載した。ところが、エントリーが来ない。企業ページは見られているようだが、エントリーの数が動かない。「ワンキャリアは合わないのか」と考える前に、「来ない」の中身を分けます。結論から言うと、「見られていない」と「見られたが来ない」を管理画面の動きで分けます。前者はワンキャリアの掲載が見られないときの原因で、後者がこの記事です。見られたが来ない原因は四つ。体験談で読んだ会社と企業ページが違う、選考の流れが書かれておらず何が起きるか分からない、企業ページからエントリーへの「次に進む一文」がない、条件で止まる。この順に一か所ずつ直します。自社の体験談とクチコミを先に読み、煽りで増やさず、スカウトで届けます。 この記事では、分け方、四つの原因とサインと直し方、体験談を先に読むこと、煽らないこと、スカウト、月に一か所、分担を整理します。エントリーを増やす直し方はワンキャリアでエントリーを増やす掲載の直し方、導線はワンキャリアの掲載からエントリーまでの導線設計で書きました。この記事は、「来ない」という症状から逆に辿るものです。

この作業の目的｜「体験談を読んで来た学生」を、止めずにエントリーまで運ぶ

ワンキャリアの学生は、体験談とクチコミを読んでから、企業ページに来ます。「この会社の選考はどうか」を確かめに来ていて、企業ページで確かめられなければ、エントリーしません。

目的は、体験談を読んで来た学生が、企業ページで「確かめられた」と感じて、次に進める状態にすることです。エントリーの数を増やすことではありません。

「見られていない」と「見られたが来ない」を、分ける

状態管理画面で見える形この記事の対象か
見られていない企業ページの閲覧の動きが小さい対象外。ワンキャリアの掲載が見られないときの原因
見られたが、来ない閲覧の動きはあるが、エントリーがない対象

管理画面で何が見えるかは、現在の仕様を管理画面とヘルプで確認してください。「見られているか」が分からないまま「来ない」を直すと、直す場所を間違えます。

見られたが来ない、四つの原因

原因サイン直し方
1. 体験談と企業ページが違う体験談に「面接が厳しかった」「連絡が遅かった」があり、企業ページが「和やかな選考」と書いている体験談を先に読み、企業ページを体験談と揃える
2. 選考の流れが見えない企業ページに、選考の回数・誰と何を話すか・期間の目安がない選考の流れを、回数と期間の目安で書く
3. 「次に進む一文」がない企業ページを読み終えても、エントリーするとどうなるかが分からない「エントリー後、〇日以内に△△からご連絡します」を置く
4. 条件で止まる条件が書かれていない、または「応相談」条件を事実で。年度の公表内容と自社の方針で確認

四つは、企業ページを学生の目で読み直すと、どれかが見えます。「1」から順に疑います。

いま使っている媒体の運用の相談だけでも構いません。見られているのに来ない原因が四つのどれかを、企業ページと体験談から一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「エントリーが来ないなら、企業ページをもっと魅力的に書き直せばよい」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、企業ページを魅力的に書き直した会社で、エントリーが増えていないことがあります。理由は、学生が企業ページより先に体験談を読んでいて、体験談に書かれていることと企業ページが食い違うと、企業ページのほうを信じないからです。「魅力的」に書くほど、体験談との差が広がり、「盛っている会社」と読まれます。当社が「来ない」の相談を受けるとき、最初にやるのは、企業ページの改善案ではなく、自社の体験談とクチコミを一緒に読むことです。読んでから、企業ページを体験談と揃えます。揃った企業ページは、魅力的でなくても、エントリーされます。

1. 体験談と企業ページを、揃える

  • 自社の体験談とクチコミを、全部読む：学生が読んでいるものを、自社も読む。ワンキャリアの企業ページで最初に書くことの「自社の体験談とクチコミを、先に読む」
  • 体験談に書かれている選考の実態を、企業ページに書く：「面接では〇〇を聞きます」と、体験談の「〇〇を聞かれた」を揃える
  • 体験談に書かれている悪い点を、隠さない：「連絡が遅かった」があるなら、企業ページで「連絡は〇日以内に」と約束し、守る
  • 企業ページで「盛らない」：体験談と食い違うと、企業ページが信じられなくなる
  • 翌年の体験談に「企業ページどおりだった」と書かれる形に：ワンキャリアの掲載のKPI設計の「独自の指標」

2. 選考の流れを、見えるようにする

  • 回数、誰と何を話すか、期間の目安：「一次はオンラインで現場の社員と、二次は対面で責任者と、最終は代表と。エントリーから内定まで〇週間程度」（日数は自社の実態で）
  • 各段階で見ることを、一文で：「一次では、学生時代に続けたことの話を聞きます」
  • 体験談に書かれている流れと、揃っているか
  • 書き方はワンキャリアの企業ページで最初に書くことの「選考の流れを書くときの注意」

3. 「次に進む一文」を、置く

  • 企業ページの末尾に、エントリーするとどうなるかを一文：「エントリー後、〇日以内に人事の△△からご連絡します」
  • エントリーの入口を、見つけやすい場所に：ワンキャリアの掲載からエントリーまでの導線設計
  • エントリー後の最初の連絡までを、導線に含める：「次に何が起きるか」が分かれば、学生は進む
  • 説明会やイベントがあるなら、それも「次」として置く：ワンキャリアのイベントページの基本

4. 条件の有無と、書き方

  • 条件が書かれていないなら、事実で書く：勤務地、働き方の形、給与の扱いは、年度の公表内容と自社の制度で確認して、そのとおりに
  • 「応相談」で濁さない：学生は判断できず、止まる
  • 条件で止まっているかは、体験談やクチコミに「条件が」があるかで分かる
  • 条件の書き方はワンキャリアの掲載の条件の書き方

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。体験談を読んで企業ページを揃える作業の時間をお伝えします。

媒体選びを相談する

煽りで、増やさない

  • 「人気企業」「急募」「残り枠わずか」は、体験談を読む学生には効かない：体験談に「煽っていた」と書かれる
  • 増やすのは、合う学生からのエントリー：数ではなく、選考の枠に見合う数
  • 煽りで増やすと、選考の側が詰まり、連絡が遅れ、体験談に「遅かった」と書かれる
  • 煽りで増やすと起きることはワンキャリアでエントリーを増やす掲載の直し方の「煽りで増やすと、起きること」

スカウトで、届ける

  • 掲載だけで待たず、スカウトで「企業ページを読んでほしい」と届ける
  • スカウトの文面で、学生の体験談やプロフィールの一文に触れ、企業ページで確かめられる形に：ワンキャリアのスカウトと掲載のつなげ方
  • スカウトから企業ページに来た学生は、「読んだ理由」がある：掲載だけで来た学生より、進みやすい
  • スカウトの基本はワンキャリアのスカウトの基本

月に一か所ずつ

  • 四つの原因のうち、一つに絞る
  • その一か所を直し、一か月、エントリーの動きを見る
  • 変わらなければ、次の原因へ
  • 記録を残す：「〇月、選考の流れを追加。エントリー：△△」
  • 来た学生が合っているかは、別の段：面談やエントリー後の対応で

直す手順はワンキャリアの掲載を週次で見直す方法の月の項で書きました。

エージェントベストの見解

これは切り分けの話です。当社がワンキャリアで「エントリーが来ない」の相談を受けるとき、「見られていない」と「見られたが来ない」を分け、後者なら「体験談と企業ページのずれ」を最初に疑います。ワンキャリアは、学生が体験談を読んでから来る媒体で、他の媒体と違い、企業ページは「最初に読むもの」ではなく「確かめるもの」です。確かめに来た学生が、体験談と違うことを読めば、企業ページのほうを信じません。この順番を分けずに企業ページを「魅力的に」直すと、体験談との差が広がり、かえって来なくなります。当社が勧める順番は、体験談を読む、揃える、選考の流れを書く、次に進む一文を置く、です。

まとめ

  • 「見られていない」と「見られたが来ない」を管理画面の動きで分ける。見られたが来ないなら、原因は企業ページの中にある
  • 四つの原因は、体験談と企業ページが違う・選考の流れが見えない・「次に進む一文」がない・条件で止まる。この順に疑う
  • ワンキャリアの企業ページは「確かめるもの」。体験談を全部読み、企業ページを体験談と揃え、盛らない。悪い点は隠さず約束して守る
  • 選考の流れを回数と期間の目安で書き、末尾に「エントリー後、〇日以内に△△から連絡」の一文を置き、条件を事実で書く
  • 煽りで増やさず、スカウトで届け、月に一か所ずつ直して記録する

よくある質問

体験談に悪いことが書かれていて、企業ページで打ち消したいです

打ち消しません。体験談を読んだ学生は、企業ページで打ち消されても、体験談のほうを信じます。悪いことが書かれているなら、それが実態だったのかを確かめ、実態なら直して、企業ページで「〇〇については、△△の形にしました」と事実で書きます。実態でないなら、企業ページで反論せず、選考で守ることを書き、翌年の体験談に「書いてあるとおりだった」と書かれる形にします。

企業ページを直しても、来ません

一か所ずつ、一か月ずつ見て、四つの原因を順に潰します。それでも来なければ、掲載だけで待つ形から、スカウトで届ける形に変えます。掲載は入口で、届ける手段がなければ、見られても来ないことがあります。それでも来なければ、「見られていない」の側を疑います。ワンキャリアの掲載が見られないときの原因

エントリーが来ないときの見直しは、御社に相談できますか

できます。当社は、原因の切り分け、体験談の読み方の型、企業ページの項目の案、「次に進む一文」の型、スカウトとのつなぎ方を支えられます。体験談を読むこと、書くこと、選考の流れの決定、条件の決定は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • 業界イメージが不利な会社のワンキャリアの見せ方
  • 知名度がない会社がワンキャリアで学生に届くには｜ワンキャリアの学生は会社名ではなく体験談で会社を知る
  • 上位大学の学生から反応が取れないとき｜大学名で選ばれ慣れている学生は、体験談の量と質で会社を比べる
  • ワンキャリアの効果が測れないときのKPIの置き直し｜「測れない」の正体は台帳がない・段が分かれていない・「こんな人」がない・体験談を読んでいない・今年と去年の体験談を分けていない
