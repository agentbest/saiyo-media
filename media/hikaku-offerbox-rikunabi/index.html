OfferBoxとリクナビの違い｜母集団の広さで選ぶか、届ける相手で選ぶか

「リクナビに載せているが、応募は来ても採りたい学生に会えない」「OfferBoxは登録者数がナビより少ないと聞くが、それで足りるのか」という相談を受けます。結論から言うと、母集団の広さで選ぶか、届ける相手で選ぶかの違いであって、登録者数の大小で決める話ではありません。 リクナビは学生が企業を探して応募するナビ型、OfferBoxは企業が学生を選んでオファーを送るスカウト型です。この記事ではリクナビの仕様や数値には触れず、母集団の性質、採用の時期、採用担当の時間の使い方、併用するときの分担の順で、型の違いを整理します。

母集団の性質が違う｜広く集まるか、絞って届くか

リクナビは、株式会社リクルートが運営する就職情報サイトです。企業が募集情報を掲載し、学生が検索してエントリーします。母集団は「探しに来た学生が、自分で選んで応募した集まり」です。

OfferBoxは、株式会社i-plugが運営するスカウト型の媒体です。企業が学生のプロフィールを検索し、会いたい学生にオファーを送ります。母集団は「企業が選んで届け、学生が承認した集まり」です。

観点OfferBoxリクナビ
母集団のでき方企業が選び、学生が承認する学生が探し、自分で応募する
母集団の広さ送った分だけ。絞られている検索に引っかかった分だけ。広い
条件に合う人の割合企業が先に絞るので高くなりやすい学生の判断で応募するので幅がある
母集団を増やす手段オファーを送る数と文面を変える掲載内容と露出を変える

「母集団が多いほうがよい」と考えると、ナビ型が有利に見えます。ただし、母集団の多さと、条件に合う学生の多さは別です。ナビ型は広く集まる分、条件から外れた応募も含みます。スカウト型は狭く届く分、条件に合う人の割合が高くなりやすい。どちらがよいかではなく、自社が「広さ」と「合う割合」のどちらを先に欲しいかで決まります。

エージェントベストの見解

媒体を比べるときに登録者数を持ち出す会社は多いのですが、公表されている登録者数は「その媒体に登録している学生の総数」であって、自社の母集団にはなりません。ナビ型なら、そのうち自社の掲載を検索で見つけ、読んで、応募した学生だけが母集団です。スカウト型なら、自社がオファーを送り、学生が承認した分だけです。つまり、登録者数がどれだけ多くても、そこから自社に届く割合は媒体の型と自社の動き方で決まります。当社が3媒体すべての販売パートナーとして相談を受けるときは、登録者数の話は脇に置き、「自社の条件に合う学生が、その媒体でどう見つかるか」だけを話します。総数で選ぶと、契約後に「思ったより会えない」となりやすいからです。

採用の時期の使い方が違う

ナビ型は、就職活動の解禁時期に合わせて学生が一斉に動きます。企業は解禁前に掲載原稿と説明会を整え、解禁後に応募対応と説明会の運営が集中し、その後に選考が続きます。年間のスケジュールが、学生の動きに合わせて外から決まる型です。

OfferBoxは、卒年ごとに企業が送る時期を決めます。解禁前から個別に接点を作ることもできますし、解禁後に絞って送ることもできます。学生の一斉の動きに乗るのではなく、自社の採用計画に合わせて山を作る型です。

  • リクナビのようなナビ型：解禁のスケジュールに乗る。準備は前倒し、対応は解禁後に集中
  • OfferBox：自社で送る時期を決める。早期の接点も、解禁後の補充も、計画次第

早い時期に少人数と深く接点を持ちたい会社と、解禁後に広く母集団を持ちたい会社では、先に検討する媒体が変わります。両方をやりたい会社は、時期をずらして併用する設計になります。

新卒の採用計画に、早期の接点と解禁後の母集団のどちらが要るか。時期から一緒に整理します。

媒体選びを相談する

採用担当の時間の使い方が違う

同じ「採用担当の時間」でも、使う先が違います。

ナビ型では、時間の多くが「来た応募を捌く」ことに使われます。応募者の確認、説明会の案内と運営、選考の日程調整。応募が多いほど、この時間が増えます。学生像が広い会社では、この時間が成果に直結します。学生像が絞れている会社では、条件から外れた応募への対応が時間の多くを占めることがあります。

OfferBoxでは、時間の多くが「送る」ことに使われます。検索条件の設定、文面の作成、送信、承認された学生への返信。毎週コツコツ続ける型で、送るのをやめると母集団も止まります。面談以降は、企業が先に選んだ相手なので、条件確認の時間は短くて済みます。

観点OfferBoxリクナビ
時間の使い先送る前の作業（条件・文面・送信）来たあとの作業（応募対応・説明会・選考）
時間が増える条件送る数を増やしたとき応募が増えたとき
現場社員の関わり方文面の名義・面談説明会の登壇・面接

「時間があるか」ではなく「どの作業の時間なら取れるか」で見ると、自社に合う型が分かります。応募対応は人事が一手に引き受けられるが文面を書く時間はない、という会社もあれば、現場の若手が学生に文面を送るのは得意だが説明会を回す人がいない、という会社もあります。

この条件ならどちらを先に検討するか

  • 採りたい学生像が条件で言える。応募の多くが条件から外れている → OfferBoxを先に
  • 学生像が広く、まず母集団を大きく持ちたい。説明会を回す体制がある → リクナビのようなナビ型を先に
  • 早い時期に少人数と深く接点を持ちたい → OfferBoxを先に
  • 解禁後のスケジュールに合わせて、一斉に動きたい → ナビ型を先に
  • 社名や業界で探されにくく、企業から名前を知ってもらう必要がある → OfferBoxを先に
  • 知名度があり、志望業界として探してもらえる → ナビ型を先に、OfferBoxは特定の層の補完に

条件の並びは、OfferBoxとマイナビの違いとほぼ同じです。ナビ型としての性質は共通しているためで、リクナビとマイナビのどちらを使うかは、この記事の範囲では扱いません。

いま使っている媒体の運用の相談だけでも構いません。応募の内訳を見て、足すべきかを判断します。

運用の相談をする

併用するときの分担

リクナビを残したままOfferBoxを足す会社が多いので、その分担を書きます。

  1. 解禁後の母集団はナビ型で：掲載原稿と説明会を整え、一斉に動く学生の受け皿にする
  2. 早期の接点と、条件で絞った層はOfferBoxで：ナビの応募では会いにくい学生に、企業から個別に届ける
  3. オファーの山を、応募対応の山と重ねない：ナビの応募が一斉に来る時期にオファーも送ろうとすると、どちらかが止まる
  4. 選考フローは1本にする：オファーで会った学生も、ナビで応募した学生も、同じ選考に乗せる。入口が違うだけで、途中から別扱いにしない
  5. 面接官に入口を伝える：オファー経由の学生は自分宛の文面を読んでから来ている。ナビ経由の学生は会社を比べている途中。入り方を変える

分担が決まると、採用担当の時間の配分も決まります。解禁前はOfferBoxに時間を使い、解禁後はナビの対応に時間を使う、というように、時期で切り替える設計が回りやすいです。

エージェントベストの見解

申し込んだあと、リクナビとOfferBoxを同じ担当が同時に回し始めた会社で起きやすいのは、解禁後にナビの応募対応に追われ、OfferBoxのオファーが止まることです。応募対応は「来たものを処理する」作業なので目の前に積み上がり、オファーは「自分から送る」作業なので後回しになります。気づくとオファーを送らない月が続き、承認も面談も止まり、「OfferBoxは効かなかった」という感想だけが残ります。当社が契約後の運用まで見ている立場から勧めるのは、担当を分けるか、時期を分けるか、送る作業を外に出すかの3つのうち、どれか1つを申込前に決めておくことです。決めずに始めると、ほぼこの順番で止まります。

まとめ

  • OfferBoxは企業が選んで届ける型、リクナビは学生が探して応募する型。登録者数の大小で決める話ではない
  • 母集団は「広さ」と「条件に合う割合」が別。ナビ型は広く、スカウト型は合う割合が高くなりやすい
  • ナビ型は解禁のスケジュールに乗り、OfferBoxは自社で送る時期を決める
  • 採用担当の時間は、ナビ型が「来たあと」、OfferBoxが「送る前」に使われる
  • 併用するなら、解禁後の母集団はナビ型、早期の接点と絞った層はOfferBox。山を重ねず、選考フローは1本にする

よくある質問

リクナビとマイナビの両方に載せています。OfferBoxを足す意味はありますか

ナビ型を2つ載せていても、母集団のでき方は同じ「学生が探して応募する」型です。応募の多くが条件から外れている、あるいは採りたい層に会えていないなら、企業から選んで届けるOfferBoxを足すことで、母集団の性質が変わります。ナビ型を増やすのとは別の効果です。

登録者数が多い媒体を選べば、母集団も大きくなりますか

登録者数は媒体全体の総数であり、自社の母集団ではありません。ナビ型なら自社の掲載を見つけて応募した分、スカウト型なら自社が送って承認された分が母集団です。総数より、「自社の条件に合う学生が、その媒体でどう見つかるか」で比べることを勧めます。

併用するとき、どちらに時間を多く使うべきですか

時期で切り替えるのが回りやすいです。解禁前はOfferBoxで早期の接点を作り、解禁後はナビ型の応募対応に時間を移す。同じ時期に両方の山を作ると、応募対応のほうが目の前に積み上がるので、オファーが止まりがちです。3媒体を含めた全体の分担は3媒体の違いと選び方にまとめています。
