OfferBoxの運用代行に毎週確認すること｜見る順番と聞き方

OfferBoxの運用代行と毎週打ち合わせをしているのに、何を確かめればよいのか分からず、代行の報告を聞いて終わってしまう。こうした相談は、代行に出して間もない会社からよく受けます。結論から言うと、毎週確かめるのは「誰に送ったか」「どこで止まっているか」「何を変えたか」「学生が何を言っているか」「翌週に何をするか」の五つで、この順番に聞きます。 数の多さを確かめるより、送った相手と止まっている段階を確かめるほうが、翌週の判断につながります。この記事では、五つの確認の中身と聞き方、聞かなくてよいこと、記録の残し方を整理します。代行との連携の全体像はOfferBoxの運用代行との連携の型で書きました。

この作業の目的｜報告を聞く場から、判断する場へ

週次の打ち合わせが報告を聞くだけの場になると、企業の側は代行の運用をそのまま追認することになります。うまくいっている週はそれでも困りませんが、止まり始めたときに気づくのが遅れます。

毎週確かめる目的は、代行の仕事を監視することではなく、企業にしかできない判断を毎週一つずつ下すことです。面談枠を増やすか、条件を変えるか、面接官を足すか。こうした判断の材料を、代行から受け取る場として週次を使います。

週次レビューの一般的な進め方はOfferBoxの週次レビューで書きました。この記事は、代行に出している場合に、企業の側から何を確かめるかに絞った話です。

確認1｜誰に送ったか

最初に確かめるのは、送った数ではなく、送った相手です。

  • 送った学生は、人物像に合っているか：代行から、送った学生のうち数人のプロフィールの要点と、触れた一文を見せてもらう
  • 検索条件を変えていないか：変えたなら、なぜ変えたか
  • 送らなかった学生はいるか：迷った学生がいたなら、どこで迷ったか

数人の例を見るだけで、代行がどんな学生を「合う」と判断しているかが分かります。社内の人物像とずれていれば、その週のうちに伝えます。人物像のずれは、面談に来た学生を見て初めて気づくと、それまでに送った分が戻せません。

代行に出したあと、週次で何を見ればよいか。運用の状況を見ながら一緒に整理します。

運用の相談をする

確認2｜どこで止まっているか

次に、送ってから面談までのどこで止まっているかを確かめます。

  1. 送ったが承認されていない：文面か、見に来た先か、送った相手か
  2. 承認されたが日程が決まらない：面談枠が足りないか、返信が遅いか
  3. 日程は決まったが面談に来ない：面談の前の連絡が足りないか
  4. 面談したが選考に進まない：人物像のずれか、面談の中身か

止まっている段階によって、直すのが代行か企業かが変わります。一つ目は代行が文面や条件を直す話で、二つ目と四つ目は企業の面談枠や面接官の話であることが多いです。どちらが直すかを、この確認の場で決めます。

エージェントベストの見解

申し込んだあとに代行との週次が形だけになる会社に共通するのは、「承認の数」だけを毎週聞いていることです。承認の数は代行の仕事の結果として分かりやすいので、そこに目が行きます。しかし、承認の数が十分でも、日程が決まらない、面談で進まない、という止まりは承認の数には表れません。当社は運用代行も扱っているので、代行の側から見て企業に判断してほしい場所が、承認より後ろにあることが多いと感じています。勧めるのは、毎週「いちばん止まっている段階はどこか」を一つだけ代行に挙げてもらい、その段階を直すのが代行か企業かをその場で決めることです。止まりを一つずつ片づけるほうが、数を並べて眺めるより翌週が変わります。

確認3｜何を変えたか

代行が先週から変えたことを確かめます。

  • 文面：どこを、なぜ変えたか。変えたあとの反応はまだ分からなくても、理由を聞く
  • 検索条件：広げたか、絞ったか、その理由
  • 送るペース：増やしたか、減らしたか、面談枠との関係

変えたことと、その理由を聞いておくと、数週あとに「何が効いたか」を振り返れます。理由のない変更が続いているなら、いったん止めて、一つずつ変えるように頼みます。同時にいくつも変えると、何が効いたか分からなくなるからです。

確認4｜学生が何を言っているか

数の報告に出てこないのが、学生の声です。

  • 承認のときや日程調整のときに、学生から来た質問
  • 面談の前後に学生が気にしていたこと
  • 辞退の連絡に書かれていた理由

代行は、承認のあとのやり取りを受け持っていることが多いので、学生の言葉に触れています。ここに、企業ページの古さや選考の流れの分かりにくさが表れます。「選考は何回ありますか」という質問が続くなら、企業ページの選考の流れが伝わっていない可能性があります。企業ページの見直しの時期はOfferBoxの企業ページを更新するタイミングで書きました。

確認5｜翌週に何をするか

最後に、翌週の計画を確かめます。

  1. 翌週に送る相手と、そのペース
  2. 翌週に必要な面談枠
  3. 代行が直すことと、企業が直すこと
  4. 企業に判断してほしいこと

四つ目を代行から挙げてもらうのが要点です。代行の側に、企業の判断を待っていることがあれば、ここで出てきます。その場で決められないものは、いつまでに返すかを決めます。

週次の場で決めることと、代行に任せることの線引きを一緒に考えます。申込前の相談も受けています。

無料で相談する

聞かなくてよいこと・記録の残し方

毎週聞かなくてよいものもあります。

聞かなくてよいことなぜ
送った一人ひとりの詳細数人の例で、判断の傾向は分かる
毎週の率の細かな上下週ごとの上下は大きく、月で見たほうが判断できる
代行の作業の段取り作業は代行に任せている

率の置き直しは月次の振り返りで行います。進め方はOfferBox運用の月次の振り返りで書きました。

記録は、五つの確認に沿って一週一枚にまとめます。止まっていた段階、直したこと、誰が直したか、企業が判断したこと、学生の声。代行が資料を作り、企業の窓口が判断した内容を書き足す形にすると、両方の手間が少なく済みます。この記録は、後で担当が替わったときの引き継ぎにも使えます。

エージェントベストの見解

発注側の誤解で多いのは、「代行に出したら、週次では代行の報告を聞くだけでよい」というものです。実際には、週次は企業が判断する場で、企業が何も決めない週は、翌週の運用も変わりません。とはいえ、毎週大きな判断があるわけではありません。勧めるのは、毎週の終わりに「企業が決めたこと」を一行でよいので記録に残すことです。面談枠を一つ増やした、条件の一つを外した、面接官に若手を足した。一行も書けない週が続くなら、代行に判断を預けたままになっている合図です。その場合は、五つの確認のうち、止まっている段階の確認に戻ります。

まとめ

  • 毎週確かめるのは、誰に送ったか・どこで止まっているか・何を変えたか・学生の声・翌週の計画の五つ
  • 送った数より送った相手を、数人の例で確かめる
  • 止まっている段階を一つ挙げてもらい、直すのが代行か企業かをその場で決める
  • 学生の質問や辞退の理由に、企業ページや選考の流れの手がかりがある
  • 毎週「企業が決めたこと」を一行記録に残す

よくある質問

週次の打ち合わせは、どのくらいの時間を取ればよいですか

決まった長さはありません。代行が事前に資料を送り、企業の窓口が読んでから臨むと、打ち合わせは判断に絞れて短く済みます。資料を打ち合わせの場で初めて見る形だと、報告を聞くだけで終わりがちです。

代行の報告が、毎週同じ内容に見えます

数の報告が中心になっている可能性があります。止まっている段階を一つ挙げてもらい、先週から何を変えたかを聞くと、週ごとの違いが見えるようになります。

担当者が替わっても、週次の確認を続けられますか

五つの確認と一週一枚の記録があれば、新しい担当者も同じ順番で確かめられます。運用の記録を引き継げる形にまとめる方法はOfferBoxの運用資料の作り方で書きました。
