OfferBoxのオプションの種類と使いどころ｜EXオプションは「2ヶ月早く送れる権利」

OfferBoxの料金ページを見ると、早期定額型プランの下に「追加オプション」としてEXオプションが載っています。「付けたほうがいいのか」「ほかにどんなオプションがあるのか」は、申込前によく聞かれる質問です。結論から言うと、公式の料金ページで確認できる有償オプションはEXオプションで、料金は25万円（税抜）です。通常の早期プランより2ヶ月早くオファーを送れるもので、公式には「オファー開始時期を前倒しする権利」と説明され、期間以外の条件は申し込んだ早期定額型プランに準じます。28卒では、通常は4月1日からのオファー開始が、EXオプションで2月1日からになると発表されています。 EXオプション以外のオプションの名前や価格は、公開情報では確認できませんでした。この記事では、オプションの仕組みと使いどころを整理します（2026年9月30日時点。最新は公式ページでご確認ください）。

結論｜公開されている有償オプションはEXオプション

公式の料金ページと規約から確認できるオプションの位置づけは次のとおりです。

項目内容
名前EXオプション
料金25万円（税抜）
付けられるプラン早期定額型プラン（追加オプションとして掲載）
中身通常の早期プランより2ヶ月早くオファーを送れる
性質オファー開始時期を前倒しする権利。期間以外は申し込んだ早期定額型プランに準じる
提供の開始28卒から（28卒は2026年2月1日からオファー送信可能。通常は4月1日）

EXオプションは、枠を増やすものでも、機能を増やすものでもありません。同じ早期定額型プランの中身を、2ヶ月早く使い始められるようにするものです。何が増えるのかを取り違えないことが、付けるかどうかを判断する出発点になります。

仕組み｜規約上のサービス区分とEXオプションの位置

企業向け利用規約（29卒対象プラン用）の第4条では、サービスを5つに分けています。

  1. 成功報酬サービス
  2. 早期オファー枠サービス
  3. 入社合意枠サービス
  4. オプションサービス：別途申し込む有償のサービス
  5. その他のサービス：適性検査サービスなど、申込不要の無償のサービス

料金ページで「既存社員最大30名分無料」とされている適性検査は、5の申込不要の無償サービスに入ります。EXオプションは、料金ページで「追加オプション」として別料金で載っているものです。

規約の第2条・第4条には「基準日」という言葉があります。基準日は、早期オファー枠がなくてもオファーを送れるようになる日で、i-plugが別に定めます。早期オファー枠サービスは、利用開始日から基準日の前日までオファーを送れる権利です。EXオプションは、この早期のオファーを送り始められる日を、さらに2ヶ月前に動かすもの、と読むと位置づけが分かりやすくなります。

EXオプションを付けるかどうか、自社の採用計画に当てはめて一緒に確認します。

媒体選びを相談する

エージェントベストの見解

EXオプションの相談で先にお伝えしているのは、「2ヶ月早く送れても、2ヶ月早く会える準備がなければ効かない」ということです。当社は3媒体すべての販売パートナーとして申込後の運用も見ていますが、早く送り始めた会社で成果が出るのは、その時期の学生に案内できる場があるところです。28卒の例でいえば、2月は学生の登録が始まって間もない時期で、志望が固まっていない学生も多い。この時期に本選考の案内を送っても、承認されにくい傾向があります。一方で、座談会や仕事体験のように、会社を知る入口を用意している会社は、早い時期のほうが他社のオファーと重なりにくく、接点を作りやすい。当社がEXオプションを勧めるのは、2月と3月に案内できるイベントや面談の枠を、申込の時点で決めている会社です。早期の時期の進め方はOfferBoxを早期に使うときの進め方に書いています。

確認する項目｜EXオプションを付ける前に

EXオプションを付けるかどうかは、次の6つで判断します。

  1. 2ヶ月早い時期に案内できる場があるか：座談会、仕事体験、個別面談など。本選考だけなら、前倒しの効果は出にくくなります
  2. その時期に書く人と会う人がいるか：前倒しした2ヶ月の間、オファーを書き、承認に返し、面談に出る人の時間
  3. 対象の卒年のオファー開始日：28卒では通常4月1日、EXオプションで2月1日と発表されています。29卒以降は、その卒年の発表で確認します
  4. 枠の配分：EXオプションで枠は増えません。早期定額型は3名採用の場合120枠です。前倒しした時期にどれだけ使うかを決めます
  5. 期間の終わり：EXオプションは開始時期を前倒しする権利で、期間以外の条件は早期定額型プランに準じます。期間の扱いは申込時に確認します
  6. 費用の比べ方：25万円（税抜）を、前倒しで増える面談の数で割って考えます

1と2が決まっていない場合は、まず早期定額型を通常の時期から始め、翌年にEXオプションを検討する順番もあります。早期定額型そのものの中身はOfferBoxの早期定額型プランとはにまとめています。

注意点

  • EXオプション以外のオプションは公開されていない：規約上「オプションサービス」という区分はありますが、公開されている名前と価格はEXオプションだけです
  • 枠は増えない：前倒しする権利で、期間以外は申し込んだ早期定額型プランに準じます
  • 成功報酬型には載っていない：料金ページでEXオプションが追加オプションとして載っているのは早期定額型プランです
  • 卒年ごとに日付が違う：前倒し後のオファー開始日は、卒年ごとの発表で確認します
  • 料金はすべて税抜：料金ページの金額は税抜表示です

前倒しした2ヶ月で何を案内するか。運用の設計の相談だけでも構いません。

運用の相談をする

前倒しした2ヶ月の使い方

EXオプションを付けると決めたら、前倒しした2ヶ月を何に使うかを先に決めます。考え方の順番は次のとおりです。

時期学生の状態（一般的な傾向）案内するもの
前倒しした最初の月登録して間もない。志望が広い会社を知る入口（座談会・仕事体験）
前倒しした次の月業界や職種を絞り始める個別面談、現場社員との対話
通常のオファー開始以降他社のオファーも増える早期に会った学生のフォローと、新規の送信

前倒しの2ヶ月で会った学生は、通常のオファー開始以降、他社のオファーと並んで比べられる立場になります。早く会えたことを、その後のフォローにつなげる計画まで立てておくと、25万円の使い道がはっきりします。

エージェントベストの見解

もう一つ、EXオプションで見落とされやすいのは「前倒しで増えるのは、会える期間であって、採れる人数ではない」ということです。相談では、EXオプションを付ければ採用人数が増えると考えている会社があります。実際には、枠の数は早期定額型プランのままで、変わるのは送り始める日です。当社が申込前に一緒に確認しているのは、前倒しした2ヶ月で「何人と会い、そのうち何人と通常の時期まで関係を続けるか」という数字です。たとえば、前倒しの期間に会った学生を本選考まで追いかける担当が決まっていれば、早く会えた分だけ関係を深める時間になります。担当が決まっていなければ、早く会った学生が、他社のオファーが増える時期に離れていきます。オプションの料金を比べる前に、前倒しで会った学生を誰が追いかけるかを決めてください。

まとめ

  • 公式に公開されている有償オプションはEXオプション（25万円・税抜）
  • 通常の早期プランより2ヶ月早くオファーを送れる。期間以外は申し込んだ早期定額型プランに準じる
  • 28卒では、通常4月1日のオファー開始が、EXオプションで2月1日からになると発表されている
  • 規約上のサービス区分は5つ。EXオプション以外のオプションの名前と価格は公開されていない
  • 付けるかどうかは、前倒しした2ヶ月に案内できる場と、会った学生を追いかける人がいるかで決める

よくある質問

EXオプションを付けるとオファー枠は増えますか

料金ページでは、EXオプションはオファー開始時期を前倒しする権利で、期間以外は申し込んだ早期定額型プランに準じるとされています。枠を増やすものではありません。

成功報酬型プランにEXオプションを付けられますか

料金ページでEXオプションが追加オプションとして載っているのは、早期定額型プランです。成功報酬型に付けられるかは公開情報では確認できないため、必要なら担当者に確認します。

EXオプション以外にどんなオプションがありますか

規約上、「オプションサービス」（別途申し込む有償のサービス）という区分はありますが、公式に公開されている名前と価格はEXオプションだけでした。適性検査は、既存社員最大30名分が無料の、申込不要のサービスに入っています。
