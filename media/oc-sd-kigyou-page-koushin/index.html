ワンキャリアの企業ページを「いつ直せばよいか」は、担当者が迷いやすい問いです。思い立ったときに直すと、忙しい時期には放置され、余裕のある時期に言い回しばかり直すことになります。結論から言うと、企業ページの更新は、新卒採用の一年の節目に合わせて予定に入れておくのが基本です。インターンの募集を始める前、本選考を始める前、選考の山が過ぎた後、内定を出した後、年度の切れ目の五つです。 加えて、選考を進めている最中は大きく書き換えない、という控える時期も決めておきます。この記事では、節目ごとに見る箇所と、控える時期、予定への入れ方を整理します。何を起点に直すかの考え方は企業ページを更新し続ける方法で書きました。企業ページの項目の名称や構成は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。

この作業の目的｜学生が読む時期の前に、ページを揃えておく

ワンキャリアの学生は、インターンを探す時期、本選考に応募するか決める時期、内定を承諾するか決める時期に、それぞれ企業ページと体験談を読みます。読まれる時期の直前に、そのとき確かめられることが揃っていれば、学生は企業ページを信じて次に進みます。

更新のタイミングを決める目的は、「読まれる前に揃える」ことです。読まれている最中に慌てて直すのでも、読まれ終わってから直すのでもありません。

更新の五つの節目

節目学生がこの時期に確かめたいこと見る箇所
1. インターンの募集を始める前どんなことを体験できるか、本選考とどうつながるかインターンの内容、参加後の流れ、働く人の話
2. 本選考を始める前選考の流れ、各段階で見ること、時期選考の流れ、よく聞かれること
3. 選考の山が過ぎた後（翌年の学生が）体験談と企業ページが揃っているか増えた体験談との食い違い
4. 内定を出した後入社後の最初の1年、配属の考え方仕事の具体、最初の1年、働く人の話
5. 年度の切れ目会社の基本の事実が今のものか事業、拠点、写真、時期に関わる記述

節目は会社の採用の暦で決まります。早期に選考を始める会社は1と2が近く、本選考が遅めの会社は3と4が近くなります。自社の一年の流れに五つを置いて、それぞれの週を予定に入れます。

自社の採用の一年に、企業ページの更新の節目をどう置くか。いま使っている媒体の運用の相談だけでも構いません。

運用の相談をする

節目ごとの進め方

インターンの募集を始める前

インターンの企業ページやイベントページを出す前に、企業ページ本体も見ます。インターンで興味を持った学生は、企業ページで「この会社の本選考はどうか」を確かめに来るからです。インターンと本選考のつながりを書くときは、年度の公表内容と自社の方針に沿って、守れる範囲だけを書きます。

本選考を始める前

最も重い節目です。選考の流れと各段階で見ることを、今年の面接官に渡す内容と照らし合わせます。前年から一つでも変わった点があれば、ここで直します。面接に出る人に、企業ページの選考の流れを一度読んでもらうと、ずれに気づきやすくなります。

選考の山が過ぎた後

増えた体験談とクチコミを読み、企業ページとの食い違いを探します。この節目の更新は、今年の学生のためではなく、翌年の学生のためのものです。体験談で見つかったことを、企業ページで補うものと、選考の運用で直すものに分けます。読み方は自社クチコミの読み方にまとめています。

内定を出した後

内定を承諾するか迷う学生は、入社後の様子を確かめに企業ページへ戻ります。仕事の具体と最初の1年、働く人の話が古くないかを見ます。新しく入社した社員がいれば、その話を足す材料を集めるのもこの時期です。

年度の切れ目

全体を一度読み直します。事業の説明、拠点、写真、「今年度は」のような時期に関わる言葉が残っていないかを確かめます。

エージェントベストの見解

これは契約後に起きることの話です。申し込んだ年は、企業ページを整える時間が取れます。問題は二年目です。二年目の本選考の前は、前年の内定者のフォローと、今年のインターンの運営が重なり、企業ページの見直しが後回しになりがちです。その結果、前年の選考の流れのまま本選考が始まり、今年の体験談に「企業ページと違った」と書かれます。当社が勧めるのは、申し込んだ年のうちに、翌年の五つの節目の週を人事の予定表に入れてしまうことです。中身はその時に考えればよく、まず週を押さえます。「空いたら見る」にした節目は、ほとんど見られないまま過ぎます。予定表に入っているだけで、少なくとも本選考の前の一回は守られやすくなります。

更新を控える時期

節目と同じくらい大切なのが、触らない時期を決めておくことです。

  • 選考を進めている最中：選考の流れを途中で書き換えると、すでに応募した学生と、これから応募する学生で読んだ内容が変わる。変えるなら、変えた時期と理由を一文で添える
  • イベントの直前：イベントで話す内容と企業ページの言葉がずれると、参加した学生が混乱する
  • 言い回しだけを直したくなったとき：事実が変わっていなければ、言葉を磨くために触らない
  • 体験談を一件読んで気になったとき：一件で全体を書き換えず、次の節目でまとめて判断する

選考中に事実が変わった場合は、控える時期でも直します。控えるのは、事実が変わっていない書き換えです。

企業ページの更新を、ほかの媒体の更新とまとめて回す形もあります。3媒体を並べてご案内します。

媒体選びを相談する

予定への入れ方

  1. 自社の採用の一年を書き出す：インターン、本選考、内定、入社の時期
  2. 五つの節目を置く：それぞれの時期の少し前に
  3. 人事の予定表に、週単位で入れる：日付ではなく週で押さえる
  4. 節目ごとに見る箇所を一行で添える：後任が見ても分かるように
  5. 選考の流れを変える会議に、企業ページの担当を入れる：節目以外の変更も漏れない

節目の予定は、ほかの媒体と同じ表に置いて構いません。OfferBoxやWantedlyの更新と同じ週にまとめると、材料を一度に集められます。媒体ごとの更新の違いはWantedlyの会社ページを更新し続ける仕組みと比べると分かりやすくなります。

社内の分担

作業誰が
五つの節目を予定に入れる人事
本選考の前に、選考の流れを確かめる人事と面接に出る人
選考の山の後に、体験談を読む人事
内定後に、働く人の話の材料を集める人事（入社してまもない社員に聞く）
年度の切れ目の読み直し人事

エージェントベストの見解

自社で持つべきなのは、どこまでか。更新のタイミングの管理は、外に出しやすい作業に見えます。当社のような代理店や運用代行が、節目の前に「そろそろ本選考の前の見直しの時期です」と声をかけることはできます。ただし、本選考の前の見直しで最も大切な「今年の選考の流れは前年と同じか」は、社内でしか答えられません。外に出せるのは、節目の管理、体験談の読み方の観点、直す文章の下書きまでです。今年の選考をどうするかを決める会議と、企業ページの担当を結ぶことは、社内に残してください。ここが切れていると、どれだけ声をかけても、直す中身が出てきません。

まとめ

  • ワンキャリアの企業ページは、思い立ったときではなく、採用の一年の節目に合わせて更新する
  • 節目はインターン募集の前、本選考の前、選考の山の後、内定後、年度の切れ目の五つ
  • 最も重いのは本選考の前。面接に出る人に選考の流れを読んでもらう
  • 選考中・イベント直前・言い回しだけの直しは控え、事実が変わったときだけ直す
  • 節目は申し込んだ年のうちに、翌年分まで週単位で予定に入れる

よくある質問

節目以外に、急いで直したほうがよいときはありますか

選考の流れや時期が変わったとき、事業や拠点などの基本の事実が変わったときは、節目を待たずに直します。学生が読んで行動を決める情報だからです。言い回しや写真は、次の節目まで待って構いません。

体験談がまだ少ない会社でも、選考の山の後の更新は必要ですか

必要です。体験談が少ない会社ほど、今年の選考で書かれた数件が翌年の学生に強く読まれます。少ない分、全部を読んで、企業ページとの食い違いがないかを確かめます。

企業ページの更新の管理は、御社に相談できますか

できます。当社は、節目の置き方、節目ごとに見る箇所の整理、体験談の読み方の観点を支えられます。選考の流れの決定と、事実の確認は企業が行ってください。当社は求人広告代理店として、ワンキャリアの掲載を支えています。
