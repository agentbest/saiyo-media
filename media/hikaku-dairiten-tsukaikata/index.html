採用媒体の代理店を、どう使えばよいか。ところが、「値引きの窓口」と思って申込だけで終わり、または全部を任せて自社に何も残らず、条件を出さずに提案を待ち、報告を見ず、更新の声かけを待つだけになる。結論から言うと、代理店は「安く契約する窓口」ではなく、「申込前の比較と時間の見積もり・申込時の契約の確認・申込後の型と集計と期限の声かけ」を使う相手です。使い方は自社の体制で変わり、一人なら「型と集計と窓口」を、複数媒体なら「契約と更新の窓口」を、代行前提なら「送る作業」を渡します。渡さないのは、「こんな人」と返信と面談です。 この記事では、使い方で起きる失敗、時期ごとに使うこと、体制ごとの使い方、渡すものと渡さないもの、出す条件と質問、報告の受け方、使いこなせているかの確かめ方、分担を整理します。代理店の仕組みは採用媒体の代理店とは、料金は代理店経由でも料金が変わらない理由、選び方は採用媒体の代理店の選び方で書きました。

この作業の目的｜代理店を、「自社の体制で足りない部分」に使う

代理店の価値は、料金ではなく（代理店経由でも正規料金）、自社の体制で足りない部分を支えることにあります。足りない部分は、会社の体制で違います。一人の会社は型と集計、複数媒体の会社は窓口、代行前提の会社は送る作業。

目的は、代理店に「何を渡し、何を渡さないか」を、自社の体制から決めることです。

代理店の使い方で、起きる失敗

失敗何が起きるか
「値引きの窓口」と思う料金は変わらないので、期待が外れ、他の使い方をしない
申込だけで、終わる申込後の相談・型・集計・期限の声かけを使わず、自社だけで回して止まる
全部を、任せる「こんな人」も返信も面談も渡し、自社に残らず、代理店の質を判断できない
条件を出さずに、提案を待つ代理店が「よくある提案」を出し、自社に合わない
報告を、見ない止まっていることに気づかず、契約の切れ目で「効かなかった」
更新の声かけを、待つだけ声かけが来なければ自動更新。自社でも期限を持つ

共通するのは、代理店を「契約の手続きの相手」としてだけ使い、「体制の足りない部分を支える相手」として使っていないことです。

時期ごとに、使うこと

時期使うこと
申込前3媒体の比較（自社の条件から）、運用に必要な時間の見積もり、料金の型の説明、「こんな人」の整理の手伝い
申込時契約の八つの項目の確認、プランと前提条件の確認、管理画面の初期設定の案内。媒体の契約で確認する項目
申込後型（文面・企業ページ）、集計と見直しの材料、管理画面の使い方、止まったときの相談、（代行なら）送る作業
更新と切り替え更新の前の声かけ、記録の整理、切り替え先の契約、引き継ぎ

時期ごとの使い方の詳しくは採用媒体の代理店とはの「代理店がしてくれること」で書きました。

いま使っている媒体の運用の相談だけでも構いません。いまの代理店の使い方が、自社の体制で足りない部分に当たっているかを一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「代理店を通す理由は、料金が安くなるか、手続きが楽になるかのどちらかだ」というものです。当社は3媒体すべての販売パートナーですが、料金は正規料金のままで、手続きの楽さは申込のときだけの話です。当社が使われている場面で最も多いのは、申込後の「型」「集計」「止まったときの相談」「更新の前の声かけ」で、これは自社だけで回す会社が、担当一人の時間で作りにくいものです。当社を「申込の窓口」としてだけ使った会社は、申込後に自社だけで回して止まり、「代理店を通した意味がなかった」と言い、申込後の相談を使った会社は、止まる前に相談が来て、小さくして続いています。当社が最初にお伝えするのは、「申込後に、何を当社に頼めるか」の一覧です。

体制ごとの、使い方

体制代理店に渡すもの自社に残すもの
人事一人検索条件の案、文面の型、集計、見直しの材料、管理画面の使い方、契約の窓口「こんな人」、読んで書く最後の一文、返信、面談。人事一人で回せる採用媒体の選び方
人事兼務一人と同じ＋繁忙期の一次返信の型一人と同じ。繁忙期も返信の続きは自社。人事兼務の担当者が回せる採用媒体
現場を巻き込める型と集計。現場の負担を吸収する下書き現場の名義・一文・面談。現場を巻き込める会社の媒体の選び方
複数媒体契約と更新の窓口、請求のまとめ、媒体ごとの型媒体ごとの役割・担当・台帳。複数媒体を代理店でまとめる方法
代行前提検索条件、文面の下書き、送る、一次返信、集計人物像、一次返信の後、面談、結果を戻す。運用代行に出す前提の媒体の選び方
自社運用申込前の比較と時間の見積もり、契約の窓口、止まったときの相談運用の全部。止まった作業だけ渡す。自社運用する前提の媒体の選び方

体制が変われば、渡すものも変わります。年度の切れ目に見直します。

渡すものと、渡さないもの

  • 渡す：比較、時間の見積もり、契約の確認、型、集計、管理画面の使い方、（代行なら）送る作業と一次返信、更新の声かけ、契約と更新の窓口
  • 渡さない：「こんな人」の決定、読んで書く最後の一文、一次返信の後の返信、面談、企業ページの中身の判断、配分の決定、やめる判断
  • 渡さない理由：学生が会うのは企業で、代理店ではない。渡すと自社に残らず、代理店の質を判断できない
  • 線引きは代理店に運用まで頼めるかの「代行で頼める作業と、頼めない作業」

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。自社の体制で、当社に渡せるものと自社に残るものを一覧でお伝えします。

媒体選びを相談する

代理店に出す、条件と質問

  • 出す条件：採る人数、職種、「こんな人」（できている範囲で）、担当の時間の形（毎週・通年・最初に集中）、面談に出る人、予算の型（決めていれば）、来年以降も続けるか
  • 申込前に聞く：「どの媒体を勧めても収入は変わりませんか」「申込後に何をどの頻度で」「運用に要る自社の時間は」
  • 申込時に聞く：契約の八つの項目。「解約の期限はいつで、誰に」
  • 申込後に聞く：「止まっているのはどの段か」「小さくするならどこか」
  • 質問の型は代理店に聞くべき質問、失敗は代理店とのやり取りでやりがちな失敗

報告の、受け方

  • 報告の型を、先に決める：週に一度、送った数・返信・面談の日程を一枚で。月に一度、率と細い段
  • 報告を、見る時間を固定する：週の見直しの中に
  • 報告に、自社の数字（面談の結果、近さ）を戻す：戻さないと、型も条件も直らない
  • 報告で「止まっている段」が見えるか：見えない報告は、型を変えてもらう
  • 報告の型は代理店に運用まで頼めるかの「報告と承認の流れで確認する項目」

使いこなせているかの、確かめ方

  1. 申込後に、代理店と話した回数が、申込前より多いか：申込前だけなら、窓口としてしか使っていない
  2. 代理店から受け取った型を、自社で直せるか：直せなければ、代理店の型に依存している
  3. 止まったとき、代理店に相談したか、自社で抱えたか
  4. 更新の期限を、代理店の声かけと別に自社でも持っているか
  5. 代理店に渡しているものの一覧を、上司が知っているか

五つが「はい」なら、使いこなせています。「いいえ」があれば、その項目から。

社内の分担

作業誰が
自社の体制から、渡すものと渡さないものを決める人事責任者
代理店に出す条件を揃える人事
申込前の比較と時間の見積もりを受け、判断する人事責任者
契約の八つの項目を代理店と確認し、期限をカレンダーに人事責任者と管理部門
型と集計を受け取り、自社の数字を戻す人事
報告を週と月で見る人事
年度の切れ目に、渡すものを見直す人事責任者

運用代行や代理店が支えられるのは、比較、時間の見積もり、契約の確認、型、集計、管理画面の使い方、（代行なら）送る作業と一次返信、更新の声かけ、窓口までで、「こんな人」、返信の続き、面談、企業ページの中身、配分とやめる判断は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これはどこまでやるかの線引きの話です。当社は、渡していただけるものは多く受けますが、「こんな人」の決定と、一次返信の後の返信と、面談は、どの体制の会社からもお受けしません。理由は一つで、学生が会うのはその会社で、当社ではないからです。当社がこの三つを代わると、文面の人と面談の人が違い、学生に「誰と話しているのか」が分からなくなります。相談の中で「全部お願いしたい」と言われたときは、この三つを企業に残す前提で、残りを当社が持つ形を提案します。この三つが自社で回らない会社は、当社に渡す前に、この三つを回す時間を作ることが先で、当社はその時間の見積もりから一緒に見ます。

まとめ

  • 代理店は「安く契約する窓口」ではなく（料金は正規料金のまま）、申込前の比較と時間の見積もり、申込時の契約の確認、申込後の型と集計と期限の声かけを使う相手
  • 使い方は体制で変わる。一人なら型と集計と窓口、兼務なら繁忙期の一次返信の型も、複数媒体なら契約と更新の窓口、代行前提なら送る作業、自社運用なら止まった作業だけ
  • 渡さないのは「こんな人」・読んで書く最後の一文・一次返信の後・面談・企業ページの中身・配分とやめる判断。学生が会うのは企業で、渡すと自社に残らない
  • 条件（採る人数・職種・こんな人・時間の形・面談に出る人・来年以降）を出してから提案を受け、報告の型を先に決め、自社の数字を戻す
  • 使いこなせているかは五つで確かめる。申込後に話す回数、型を自社で直せるか、止まったときに相談したか、期限を自社でも持つか、渡しているものを上司が知っているか

よくある質問

代理店を通すと、媒体との直接のやり取りができなくなりますか

契約の形によります。媒体と直接契約し、代理店が申込と相談を担う形もあれば、代理店と契約する形もあり、どちらでも管理画面は企業が使います。媒体のサポートに直接聞けるかは、契約の形と媒体の仕様で、契約時に確認します。当社の場合、管理画面の使い方は当社が案内し、媒体の仕様の細かい確認は媒体のヘルプとサポートを一緒に使います。

代理店に相談しても「様子を見ましょう」としか言われません

出している条件と、報告の型を確かめます。条件（「こんな人」、担当の時間、面談の枠）が出ていないと、代理店も「様子を見る」しか言えません。報告に「止まっている段」が見えていないなら、報告の型を変えてもらいます。それでも変わらないなら、代理店の申込後の相談の範囲が「申込のみ」に近く、選び直しの候補です。選び方は採用媒体の代理店の選び方で書きました。

代理店の使い方は、御社に相談できますか

できます。当社は、比較、時間の見積もり、契約の確認、型、集計、管理画面の使い方、代行なら送る作業と一次返信、更新の声かけ、窓口を支えられます。「こんな人」、返信の続き、面談、企業ページの中身、配分とやめる判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • 採用媒体の代理店の選び方
  • 媒体の契約で確認する項目｜金額の前に「契約の型・期間と更新・やめ方・含まれるもの・前提条件・契約の相手と請求・データの扱い・担当交代」の八つを、契約書と見積もりと管理画面のヘルプで確認する
  • 媒体を切り替えるタイミングの判断｜切り替えは「効かないから別の媒体へ」ではなく、「いまの媒体で直せる段がなくなり、役割が違う入口が要ると分かったとき」に、契約の切れ目で
  • 媒体の効果を並べて比べる方法｜比べるのは「エントリー数」ではなく、媒体ごとの「こんな人に近い人が面談まで来た数」と「入口→面談の日数」と「近い人の割合」と「担当の時間」
