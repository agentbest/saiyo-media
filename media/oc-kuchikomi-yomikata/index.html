ワンキャリアに書かれた自社の選考体験談とクチコミを、読みたい。ところが、評価の高低だけを見て、一件の厳しい記述で判断し、厳しい記述を読まず、または良い記述を読まず、読んで終わりで記録せず、面接官と現場に共有せず、企業ページで打ち消そうとする。結論から言うと、読むのは「評価」ではなく「事実として何が書かれているか」で、選考の流れ・聞かれた質問・連絡の速さ・面接官の印象・企業ページとの違い・良かった点・誤解、の七つを拾い、「補う」（企業ページ）と「直す」（選考の運用）に分けます。月に一度、担当を決めて、一枚に残し、面接官と現場に「書かれている事実」として共有します。一件で判断せず、複数の記述で傾向を見ます。 この記事では、読み方で起きる失敗、読む前に決めること、七つ、分け方、傾向の見方、一枚の型、共有、頻度と担当、読んだ後、分担を整理します。クチコミの基本はワンキャリアのクチコミとは｜企業がまず知っておくこと、企業ページへの反映はワンキャリアの企業ページの更新、掲載のKPIはワンキャリアの掲載のKPIで書きました。

この作業の目的｜クチコミを「学生が何を読んで来ているか」の材料として読む

自社のクチコミを読む目的は、評価を知ることではなく、「学生が自社について何を読んで、何を確かめに来るか」を知ることです。それが分かれば、企業ページで何を先に書くか、イベントで何に答えるか、選考のどこを直すかが決まります。

目的は、クチコミを「評価」ではなく「事実の材料」として読み、「補う」と「直す」に落とすことです。

読み方で、起きる失敗

失敗何が起きるか
評価の高低だけ、見る「良い」「悪い」で終わり、何を直すかが分からない
一件で、判断する一人の体験を全体と思い、直さなくてよいことを直す、または直すべきことを見落とす
厳しい記述を、読まない直す場所が分からない。翌年も同じことが書かれる
良い記述を、読まない残すべきこと（面接官が話を聞いてくれた、など）を、変えてしまう
読んで終わり、記録しない翌月に同じことを読み直し、傾向が見えない
面接官と現場に、共有しない「連絡が遅い」「面接官によって違う」を直す人が知らない
企業ページで、打ち消そうとする「そんなことはない」と書き、企業ページのほうが信じられなくなる

共通するのは、クチコミを「評価」として読み、「事実の材料」として読んでいないことです。

読む前に、決めること

  • 誰が読むか：人事の担当一人。月に一度
  • 何を拾うか：七つ（次の節）
  • 一枚の型：拾ったものを書く表
  • 誰に共有するか：面接官、現場の責任者、経営層
  • 「補う」と「直す」の判断を、誰がするか：企業ページは人事、選考の運用は人事責任者と面接官
  • 読める範囲と仕組みは、管理画面とヘルプで確認：どこに何が書かれているか

いま使っている媒体の運用の相談だけでも構いません。自社のクチコミを七つで拾い、「補う」と「直す」に分けるところを一緒にやります。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「クチコミは、評価が下がっていないかを確かめるために見る」というものです。当社はワンキャリアの販売パートナーとして、クチコミの読み方の相談を受けていますが、評価だけを見ていた会社は、「下がっていない」で安心して何も直さず、「下がった」で慌てて企業ページを書き換え、どちらも翌年の体験談に効いていません。逆に、評価を見ずに「事実として何が書かれているか」を七つで拾い、「連絡が遅い」を選考の運用で直し、「何を見ているか分からない」を企業ページで補った会社は、翌年の体験談に「去年と違って速かった」「企業ページに書いてあるとおりだった」と残っています。クチコミの読み方は、評価を追うことではなく、事実を拾って直す場所を決めることです。当社がクチコミの相談を受けるとき、最初にやるのは、評価の欄を隠して、記述だけを一緒に読むことです。

七つの、拾うもの

拾うもの何を見るか落とし先
1. 選考の流れ段階の順番、回数、間隔が、どう書かれているか。企業ページと同じか違えば「補う」か「直す」
2. 聞かれた質問面接で何を聞かれたと書かれているか。面接官ごとに違うか違えば「直す」（面接官の引き継ぎ）
3. 連絡の速さ「連絡が遅い」「返事が来ない」があるか「直す」（返信の運用）
4. 面接官の印象「話を聞いてくれた」「圧迫だった」「面接官によって違った」良い印象は残す。違いは「直す」
5. 企業ページとの違い「ページと違った」「書いてあるとおりだった」違えば「補う」か「直す」。とおりなら残す
6. 良かった点学生が良いと書いたこと残す。企業ページとイベントの材料に
7. 誤解事実と違う記述、古い情報「補う」（企業ページで事実を先に）

七つを、記述ごとに拾います。評価の数字は拾いません。読む箇所の元はワンキャリアの企業ページの基本の「自社の体験談とクチコミを、先に読む」です。

「補う」と「直す」に、分ける

分け方何をするか例
補う（企業ページ）会社の側の考えを、企業ページで先に書く「何を見ているか分からなかった」→企業ページに「各段階で見ていること」を書く
直す（選考の運用）選考そのものを変える「連絡が遅かった」→返信を当日か翌日に。「面接官によって違った」→面接官の引き継ぎの一枚
残す良かった点を、変えない「面接官が話を聞いてくれた」→その面接官の進め方を、他の面接官にも
誤解を解く事実を企業ページに先に書く「〇〇と思われている」→企業ページに事実を

「連絡が遅い」を企業ページで「早く連絡します」と書くのは、「補う」ではなく、打ち消しです。直すものは直します。分け方の考え方はワンキャリアの掲載のKPIの「段が細いときに、直す場所」と同じです。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。月に一度クチコミを読み、一枚に残して共有する運用に要る時間をお伝えします。

媒体選びを相談する

傾向の、見方

  • 複数の記述で、見る：一件で判断しない。同じことが複数に書かれていれば傾向
  • 時期で、見る：早期・選考期・後期で、書かれることが違う。後期の「速かった」は後期の運用の結果
  • 段階で、見る：一次で書かれること、最終で書かれること。段階ごとに面接官が違う
  • 年度で、見る：去年と今年で、同じことが書かれているか、変わったか。直した結果が翌年に出る
  • 一件の厳しい記述は、「その一件で何が起きたか」を確かめる：傾向でなくても、事実なら直す
  • 傾向の考え方は母集団形成の振り返り方の「材料」

一枚の、型

  • 縦に七つの拾うもの、横に「書かれていること（事実）」「補う／直す／残す／誤解」「担当」「直した日」
  • 記述は、要約せず、書かれた言葉のまま：「連絡が遅い」を「対応の課題」に言い換えない
  • 時期と段階を、記述ごとに
  • 月に一度、追記する：前月からの変化が見える
  • 一枚は、共有の材料：次の節

共有の、仕方

  • 面接官に：「聞かれた質問」「面接官の印象」「面接官によって違った」を、「書かれている事実」として。責める材料にしない。OfferBoxの面接官への引き継ぎ
  • 現場の責任者に：「働き方」「配属」についての記述。企業ページと回で答える材料
  • 経営層に：傾向と、直したことと、翌年に期待する記述。経営層にOfferBoxの成果を説明する方法
  • 共有の形は、一枚をそのまま：口頭で要約すると、事実が変わる
  • 「こう書かれている。翌年にこう書かれるために、ここを直す」の順で

読む頻度と、担当

  • 月に一度：体験談が増える時期は、二週間に一度でも
  • 担当を一人に固定する：読む目が揃う
  • 担当が変わったら、一枚を引き継ぐ：ワンキャリアの担当が交代するときの引き継ぎ
  • 読む時間を、固定する：「時間が取れたら」では読まない
  • 年度の切れ目に、一年分を通して読む：ワンキャリアの掲載の年間計画の「読む」の期間

読んだ後に、動くこと

  • 「直す」を、その月に一つ：全部を一度に直さない
  • 「補う」を、企業ページの更新に：ワンキャリアの企業ページの更新
  • 「残す」を、イベントと企業ページの材料に：良かった点を、社員の記事と回に
  • 「誤解」を、企業ページの最初に：事実を先に
  • 直した結果を、翌年の体験談で確かめる：「去年と違って」が書かれたか

社内の分担

作業誰が
読める範囲と仕組みを管理画面とヘルプで確認する人事
月に一度、七つで拾い、一枚に残す人事の担当一人
「補う」「直す」「残す」「誤解」に分ける人事責任者
面接官・現場・経営層に一枚で共有する人事
「直す」を選考の運用で面接官と人事責任者
「補う」「誤解」を企業ページで人事
年度の切れ目に一年分を読み、翌年の体験談で確かめる人事と責任者

運用代行や代理店が支えられるのは、七つの型、分け方の型、一枚の型、共有の型、傾向の見方の整理までで、クチコミを読むこと、分ける判断、共有、選考を直すこと、企業ページの中身は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは切り分けの話です。クチコミの相談で、「厳しいことが書かれているが、何を直せばよいか分からない」と言われることがあります。当社が確かめるのは、その記述が七つのどれかです。「連絡が遅い」なら三で「直す」、「何を見ているか分からない」なら一か二で「補う」、「面接官によって違う」なら四で「直す」、「ページと違う」なら五で「補う」か「直す」。七つのどれかに置けば、直す場所は一つに決まります。置けないのは、記述を「厳しい」という評価で読んでいるときで、「事実として何が書かれているか」で読めば置けます。当社は、クチコミの相談で、「厳しい」の一言を、七つのどれかに置き換えるところから始めます。

まとめ

  • クチコミは「評価」ではなく「事実として何が書かれているか」で読む。評価の高低で安心も慌てもせず、記述を拾う
  • 拾うのは七つ：選考の流れ・聞かれた質問・連絡の速さ・面接官の印象・企業ページとの違い・良かった点・誤解。記述は書かれた言葉のまま一枚に
  • 「補う」（企業ページで会社の側の考えを先に書く）と「直す」（選考の運用を変える）と「残す」（良かった点を変えない）と「誤解を解く」に分ける。「連絡が遅い」を企業ページで「早く連絡します」と書くのは打ち消し
  • 一件で判断せず、複数の記述・時期・段階・年度で傾向を見る。一件の厳しい記述は「何が起きたか」を確かめる
  • 月に一度、担当一人が固定の時間で読み、一枚を面接官・現場・経営層に「書かれている事実」として共有し、その月に一つ直す。翌年の体験談で結果を確かめる

よくある質問

面接官に厳しい記述を見せると、反発されそうです

見せ方を「責める」ではなく「事実」にします。「〇〇と書かれている。翌年に『面接官が話を聞いてくれた』と書かれるために、ここを揃えたい」の順で、一枚をそのまま。良かった点も同じ一枚にあれば、「厳しいことだけ言われた」になりません。見せないと、直す人が知らないままで、翌年も同じことが書かれます。共有の型はOfferBoxの面接官への引き継ぎで書きました。

体験談の数が少なく、傾向が見えません

少ないなら、一件ずつ「何が起きたか」を確かめます。傾向でなくても、事実なら直します。体験談が少ない年は、今年の選考が最初の体験談になる年で、「書かれる選考」をすることが読むことより先です。読む型（七つと一枚）は、少ない年に作っておくと、増えた年にそのまま使えます。体験談がない年の考え方は知名度がない会社のワンキャリア運用で書きました。

自社クチコミの読み方は、御社に相談できますか

できます。当社は、七つの型、分け方の型、一枚の型、共有の型、傾向の見方の整理を支えられます。クチコミを読むこと、分ける判断、共有、選考を直すこと、企業ページの中身は、企業が行ってください。読める範囲と仕組みは管理画面とヘルプで確認してください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

あわせて読む

  • 知名度がない会社がワンキャリアのクチコミで見つけてもらうには｜ワンキャリアで「見つかる」のは、社名で探されることではなく、学生が読む体験談の中に自社があること
