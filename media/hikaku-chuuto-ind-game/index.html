ゲーム業界の中途採用で媒体をどう選ぶか

ゲームを企画して販売する会社、開発を受託する会社、配信したゲームを長く運営する会社、小さなスタジオ、ゲームに関わるサービスの会社が、中途で人を採ろうとしています。ゲーム業界は、プランナー、エンジニア、デザイナーやアーティスト、運営、品質管理と職種が分かれていて、職種ごとに候補者の見るものも、選考の進め方も違います。結論から言うと、ゲーム業界の中途採用では、業界でまとめて媒体を選ぶのではなく、「会社の種類」と「職種」で募集を分け、開発中の作品を見せられない事情も踏まえて見せ方を決めてから媒体を選ぶのが基本です。 この記事では、媒体の料金や数値には触れず、判断の順番を整理します。

ゲーム業界の採用構造と、媒体との相性

ゲーム業界の中途採用には、次のような特徴があります。

  • 作品が実力の証明になる：デザイナーやアーティストは作品集、エンジニアは作ったもの、プランナーは企画書や関わったタイトルで見られる
  • 開発中の作品は見せられないことが多い：会社も候補者も、守秘の約束で作品を出せない場面がある
  • 会社の種類で仕事が違う：企画して販売する会社、受託で作る会社、運営する会社では、同じ職種でも担う範囲が違う
  • 業界の外から移る人もいる：エンジニアはほかのIT業界から、運営や企画はほかのサービス業から移ることがある

媒体の型との相性を整理します。

型ゲーム業界での使いどころ
業界に強い求人型（Greenなど）IT・Web業界の求人を中心に扱う。エンジニアや運営を、業界の外も含めて集めたいとき
共感型（Wantedlyなど）作っているものへの想いや、スタジオの雰囲気で集めたいとき
総合型（doda、typeなど）幅広い職種を、業界の内外から集めたいとき
スカウト型の中途向け媒体経歴や作品を見て、会社から声をかけたいとき
紹介ディレクターや、特定の技術を持つ人を採りたいとき

判断軸｜対象・型・課金・運用工数

  • 対象：ゲーム業界の経験者か、ほかの業界から移る人か。職種はどれか
  • 型：待つか、声をかけるか、共感で集めるか、紹介を使うか
  • 課金：掲載の期間で払うか、採用が決まったときに払うか
  • 運用工数：応募のたびに作品を見て、評価できる現場の人の時間があるか

ゲーム業界で重くなるのは、運用工数のうち「作品を見る時間」です。作品を評価できるのは現場の開発者ですが、開発の山の時期には時間が取れません。作品を見る担当と時間を決めないまま応募を集めると、書類選考で止まります。

会社の種類と職種ごとに、どの媒体を先に検討するか。募集の分け方から一緒に整理します。

媒体選びを相談する

エージェントベストの見解

ゲーム業界の会社の相談で多い思い込みは、「ゲームが好きな人を採れば、熱量のある人が集まる」というものです。実際には、ゲームが好きであることは、この業界の候補者のほとんどに当てはまるので、それを条件にしても絞り込みになりません。好きなジャンルで絞ると、かえって仕事に必要な力を見落とすこともあります。候補者を分けるのは、職種ごとの仕事の力と、会社の種類との相性です。運営型の会社なら、配信後の数字を見て改善を続けることに向いているか。受託の会社なら、顧客の求めに合わせて作ることに向いているか。当社が勧めるのは、求人の「求める人物像」から「ゲームが好き」を外し、会社の種類に合った仕事の進め方を書くことです。熱量は、選考の中で作品の話を聞けば伝わります。

候補者に見せること｜開発中の作品の扱い

ゲーム業界の求人では、開発中のタイトルを見せられないことが、見せ方の難しさになります。見せられないものを無理に見せるのではなく、見せられる範囲で仕事の中身を伝えます。

  1. 公開しているタイトル：関わったタイトルと、その中でこの職種が担ったこと
  2. 開発中の作品の伝え方：ジャンル、対応する機器、開発の段階など、出せる範囲で
  3. 開発の体制：チームの人数の感覚、職種の分担、使っている開発の道具
  4. 会社の種類に合った仕事：企画して販売するのか、受託か、運営か。それぞれで担う範囲
  5. 作品の扱い：入社後に作ったものを、自分の実績としてどこまで出せるか

候補者の側も、前職の作品を見せられないことがあります。その場合は、公開されている範囲の作品や、個人で作ったもの、守秘に触れない形での説明を受け付けると書いておくと、応募のためらいが減ります。

この条件なら、どの型を先に検討するか

優劣ではなく、条件ごとに先に検討する形として置きます。

  • 運営型の会社で、運営やエンジニアを採る → 業界に強い求人型（Greenなど）を先に。業界の外のサービス運営やIT業界の経験者にも届けやすい
  • 小さなスタジオで、作るものへの共感で採る → 共感型（Wantedlyなど）を先に。作っているものへの想いと、スタジオの日常を見せる
  • 受託の会社で、幅広い職種を採る → 総合型（doda、typeなど）を先に。顧客の求めに合わせて作る仕事を具体的に書く
  • ディレクターや特定の技術を持つ人を採る → 紹介を先に。並行してスカウトで声をかける

業界全体の考え方はIT・Web業界の中途採用で媒体をどう選ぶか、作品で判断する職種の考え方は中途採用で動画クリエイターを採るときの媒体の選び方、新卒向けはゲーム業界の採用媒体の選び方にまとめています。

運用の組み方と選考への接続

ゲーム業界の選考では、作品を見る段階を、職種ごとに設計しておきます。

  • 作品を見る人：職種ごとに一人決め、見る時間を週の予定に先に入れる
  • 見る観点：職種ごとに観点を三つ程度に絞って書いておく。現場の人によって評価が割れないように
  • 面接で聞くこと：作品の中で本人が担った範囲、迷ったところ、チームとのやり取り
  • 課題の扱い：出すなら短く、作ったものの扱い（社内の確認だけに使うなど）を先に伝える

開発の山の時期でも選考が止まらないよう、応募対応や日程の調整を外に出す形もあります。運用の相談だけでも構いません。

運用の相談をする

エージェントベストの見解

ゲーム業界の会社が媒体を申し込んだあと、最初の一か月で運用が止まる会社に共通するのは、作品の審査が現場待ちになることです。応募が来て、作品を現場の開発者に回す。開発者は開発の締め切りを抱えていて、見るのが週末になり、さらに次の週になる。そのあいだに、候補者はほかの会社の選考に進みます。とくに経験者は、複数の会社を同時に受けていることが多く、待たせることがそのまま辞退につながります。当社が勧めるのは、作品を見る担当と曜日を、募集を出す前に決めておくことです。見る観点を三つに絞っておけば、一人あたりの時間も短くなります。応募への最初の返信と日程の調整は、作品の審査とは切り離して先に進められるので、ここを止めないことも大切です。

まとめ

  • ゲーム業界は職種ごとに見られるものが違い、作品が実力の証明になる
  • 業界でまとめず、会社の種類と職種で募集を分けて媒体の役割を決める
  • 「ゲームが好き」は絞り込みにならないので、会社の種類に合った仕事の進め方を書く
  • 開発中の作品は出せる範囲で伝え、候補者が作品を出せない事情にも受け口を用意する
  • 作品を見る担当と曜日を、募集を出す前に決めておく

よくある質問

ゲーム業界の経験がない人を採ってもよいですか

エンジニアや運営、企画では、ほかの業界の経験が活きることがあります。その場合は、ゲームの開発や運営のどの部分に、前職のどんな経験が活きるかを求人に書きます。

作品を見せられない候補者は、どう見極めればよいですか

公開されている範囲の作品や、個人で作ったもの、守秘に触れない形での説明を受け付けます。面接で仕事の進め方を具体的に聞くと、作品がなくても力が見えてきます。

運営型の会社の採用で気をつけることはありますか

運営型の会社では、配信を始めたあとも改善を続ける仕事が中心になります。新しく作ることより、遊んでいる人の反応を見て直すことに向いているかを、面接で前職の改善の経験から確かめます。求人にも、配信後の仕事の流れを具体的に書いておくと、作ることだけを求める人とのずれが減ります。
