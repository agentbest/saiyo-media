代理店に運用まで頼めるか｜頼める範囲、頼めない範囲、頼む前に決めること

「媒体を契約しても、運用する時間がない。代理店に運用まで頼めるのか」という相談を受けます。結論から言うと、頼める代理店と頼めない代理店があり、頼める場合でも、頼める作業と頼めない作業があります。 検索、文面の作成、送信、一次返信は頼めます。採りたい人物像を決めること、面談と面接は頼めません。当社はOfferBoxを中心に運用代行を行っている代理店ですが、この記事は当社に限らず、代理店に運用を頼むときの一般的な範囲と、頼む前に決めておくことを整理します。自社運用と代行の違いそのものは媒体を自社で運用するか代行に出すかの違いで書きました。

代理店の3つの型｜申込のみ・相談まで・代行まで

代理店が運用にどこまで関わるかは、3つの型に分かれます。

型関わる範囲向く会社
申込のみ媒体の申込を取り次ぐ。申込後は媒体のサポート窓口へ運用が社内で回っていて、申込の窓口だけ欲しい
相談まで申込後も、検索条件・文面・掲載内容の相談を受ける。作業は社内運用は社内でやるが、止まりかけたときの相談先が欲しい
代行まで検索・文面・送信・一次返信を代理店が行う。人物像と面談は社内送る作業の時間が取れない

「代理店に運用まで頼めるか」は、その代理店がどの型かで決まります。申込前に聞くのは、「申込後に、何を、どのくらいの頻度でやってくれるか」です。代理店の仕組みそのものは採用媒体の代理店とはで書きました。

代行で頼める作業と、頼めない作業

代行まで行う代理店に頼む場合でも、全部を任せられるわけではありません。

作業頼めるか理由
採りたい人物像を決める頼めない企業が決める。代理店は聞いて整理する側
検索条件を設定する頼める人物像に基づいて代理店が設定する
文面を書く頼める（共通部分は社内で確認）会社の紹介や募集の内容は社内が確認する
送る頼める代理店の名義ではなく、企業の名義で送られる
一次返信する頼める承認への最初の返信と、面談の案内
面談の日程を調整する代理店による社内のカレンダーとの連携が要る
面談する・面接する頼めない企業が行う
面談の結果を代理店に戻す社内がやる結果が戻らないと条件と文面を直せない

頼めない作業は、代行に出しても社内に残ります。この時間を見込んでおかないと、「代行に出したのに止まった」となります。

いま使っている媒体の運用の相談だけでも構いません。代行に出すか、相談だけにするか、線を引くところから。

運用の相談をする

エージェントベストの見解

申し込んだあと、運用代行込みで契約した会社で最初の1ヶ月に起きやすいのは、「代理店が送っているのに、社内で面談が組めない」ことです。当社が代行を受けている経験では、送る作業を当社が担っても、承認された候補者に社内が翌週の面談枠を出せない会社では、承認が溜まり、候補者の温度が下がって離れます。送るのは当社、会うのは社内。会う側が詰まると、送っても先に進みません。代行込みで申し込む前に、「承認された候補者と、翌週に面談できる枠が週に何回取れるか」を社内で決めておくことを勧めます。枠が取れない会社には、当社は代行より先に、面談の体制を作る話をします。代行は「送る時間」を外に出す手段であって、「会う時間」を外に出す手段ではありません。

頼む前に社内で決めておくこと

代行に出す前に、次の4つを社内で決めておきます。決まっていないと、代理店は動けません。

  1. 採りたい人物像：卒年、学部、志向、経験。条件で言える形にする。代理店に聞いてもらいながら決めてもよいが、決めるのは社内
  2. 文面の共通部分：会社の紹介、募集する仕事、選考の流れ。代理店が下書きしても、確認と承認は社内
  3. 面談の枠：承認された候補者と、いつ、誰が、どのくらいの頻度で会えるか
  4. 結果を戻す担当：面談の結果を代理店に伝える人。戻らないと、条件と文面の改善が止まる

この4つが決まっていれば、代行に出した翌週から動きます。決まっていなければ、代行に出しても最初の数週間は「決める」ことに使われます。

報告と承認の流れで確認する項目

代行まで頼む場合、契約前に「どう回すか」を確認します。代理店によって差が大きい部分です。

項目確認すること
文面の承認送る前に社内が確認するか。確認の頻度と方法
報告の頻度週次か月次か。何を報告するか（送信数・承認数・面談数）
条件と文面の見直し誰が、いつ、何を根拠に見直すか
連絡の窓口代理店側の担当は誰か。社内側の担当は誰か
候補者への返信の名義企業の名義で送られるか。代理店の名前が出るか
経験の共有効いた文面や条件を、社内に共有してもらえるか
やめるとき代行をやめて自社運用に戻すとき、文面と条件を引き継げるか

最後の「やめるとき」は見落とされやすい項目です。代行を頼んでいる間に蓄積された文面と条件は、自社に引き継げる形にしておきます。この点はスカウト媒体と新卒紹介の違いで書いた「接点と経験の残り方」と同じ話です。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。代行に出す場合でも、社内に残る時間をお伝えします。

媒体選びを相談する

相談までで足りる会社、代行が要る会社

代行を頼むかどうかは、「送る時間が取れるか」で決まります。

  • 送る時間が週に取れる。文面を書ける人がいる → 相談までで足りる。自社運用で回し、止まりかけたら相談する
  • 送る時間が取れない。面談と選考の時間なら取れる → 代行が要る。送る作業を外に出し、社内は会うことに集中する
  • 文面を書ける人がいないが、送る時間はある → 相談まで。文面の型を代理店と作り、送るのは社内
  • 人物像がまだ決まっていない → どちらでも止まる。先に人物像を決める。代理店に聞いてもらいながら決める形もある
  • 自社運用で止まった経験がある → 止まった作業を特定し、その作業だけ代行に出す

「全部代行」か「全部自社」かではなく、「止まる作業だけ外に出す」が無駄の少ない形です。

エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。代行を頼む会社には、「人物像を、条件で言える形にする」ことを先にお願いしています。「いい人を採りたい」「うちに合う人」では、当社は検索条件を作れません。卒年、学部、志向、経験のうち、どれで絞るかが決まって初めて、検索と文面が作れます。当社が代行の相談を受けるとき、最初の打ち合わせの大半は、この人物像を条件に落とす作業に使います。ここを飛ばして「とにかく送ってほしい」と始めると、承認された候補者が社内の期待とずれ、面談で「思っていた人と違う」となります。代行は人物像が決まってから。決まっていないなら、決める作業を代理店と一緒にやるところから始めるのが順番です。

まとめ

  • 代理店には申込のみ・相談まで・代行までの3つの型がある。申込前に「申込後に何をどのくらいやってくれるか」を聞く
  • 代行で頼めるのは検索・文面・送信・一次返信。人物像を決めることと面談・面接は頼めない
  • 頼む前に、人物像・文面の共通部分・面談の枠・結果を戻す担当の4つを社内で決める
  • 契約前に、文面の承認、報告の頻度、見直しの根拠、やめるときの引き継ぎを確認する
  • 「止まる作業だけ外に出す」が無駄の少ない形。会う時間は外に出せない

よくある質問

代行に出せば、社内の時間はゼロになりますか

なりません。送る作業の時間は不要になりますが、人物像を決める時間と、面談と面接の時間は社内に残ります。特に面談の枠が用意できないと、承認が溜まるだけで先に進みません。代行に出す前に、翌週に面談できる体制があるかを確認することを勧めます。

代行の文面は、自社の名前で送られますか

一般には企業の名義で送られます。候補者から見ると、企業から届いた文面です。代理店の名前が出るかどうか、一次返信の名義はどうなるかは、契約前に確認してください。当社の場合、企業の名義で送り、一次返信も企業の担当者として行います。

御社の運用代行は、どの媒体に対応していますか

当社はOfferBoxを中心に、スカウトの運用代行を行っています。当社がOfferBox・Wantedly・ワンキャリアの販売パートナーでもあるので、媒体の申込と運用の相談を同じ窓口で受けられます。相談までで足りるか、代行が要るかは、送る時間が取れるかで一緒に判断します。3媒体の全体像は3媒体の違いと選び方にまとめています。
