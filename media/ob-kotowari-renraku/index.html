OfferBoxで出会った学生に、選考の見送りを伝える場面は、どの会社にも来ます。ナビ型の応募と違うのは、最初に声をかけたのが企業の側だという点です。学生は「読んで送ってくれた」と思って承認し、時間を使って会いに来ています。結論から言うと、見送りの連絡は、決まったらなるべく早く、短く、オファーで声をかけたことへの責任を一言添えて送ります。評価の中身を細かく書かず、学生の時間へのお礼と、今後の就職活動への言葉で締める。連絡が遅れる・来ない、という形だけは避けます。 この記事では、見送り連絡の目的、時期、文面に入れること、段階ごとの書き分け、名義と分担、やりがちな失敗を整理します。学生の側から辞退や「進まない」と言われたときの返し方はOfferBoxの面談後のフォロー連絡で書きました。

この作業の目的｜「声をかけた側」として、関係をきれいに閉じる

見送りの連絡の目的は、選考の結果を伝えることだけではありません。こちらからオファーを送って始まった関係を、学生が納得できる形で閉じることです。

  • 学生は結果を待つあいだ、他社の予定を組めずにいることがある。早く伝えれば、次に進める
  • 連絡の印象は、学生の周りの友人や後輩、大学のキャリアセンターにも伝わることがある
  • 見送った学生が、数年後に中途の候補者や取引先の担当として出会い直すこともある

オファー経由の学生は、自分から応募した学生より「選ばれた」という感覚を持って来ています。だからこそ、連絡が無いまま終わると、受け止めは厳しくなります。丁寧さより、まず「届くこと」と「早いこと」を守ります。

手順1｜見送りが起きる段階を分けておく

OfferBox経由の学生への見送りは、いくつかの段階で起きます。段階で書き方が変わるので、先に分けておきます。

段階状況書き方の要点
承認後、会う前募集枠が埋まった・職種の募集を止めた会社の事情であることを率直に。学生の評価ではないと分かるように
面談のあと選考に進む案内をしない面談の時間へのお礼。面談は選考ではないと伝えていたなら、その言葉と矛盾しない書き方に
選考の途中面接で見送り結果を短く。理由は細かく書かない
最終選考内定を出さない時間を多く使ってもらったことへのお礼を、他の段階より厚めに

面談を「選考ではない」と案内していた場合、面談のあとに「今回はご縁がなく」と書くと、学生は「やはり選考だった」と受け取ります。面談の位置づけは初回面談の設計で決めたとおりに扱い、面談後は「選考へのご案内は控える」という言い方に寄せます。

手順2｜連絡の時期を決めておく

時期は、文面より先に決めます。

  1. 結果を出す日を、面接の前に決めておく：面接官が評価を戻す期限と、人事が連絡する日をセットで
  2. 学生に伝えた日までに連絡する：「〇日までにご連絡します」と伝えたなら、その日を過ぎない
  3. 見送りの連絡を、合格の連絡より後回しにしない：合格の学生だけ先に連絡し、見送りを放置する形が最も多い失敗
  4. 保留にする場合は、保留と伝える：他の候補者との比較で決められないなら、「もう少しお時間をいただく」と連絡し、新しい期日を示す

評価が戻ってこないことが遅れの原因なら、面接官への依頼の仕方を直します。評価の戻し方は面接評価がばらつくときで書きました。

いま使っている媒体の運用の相談だけでも構いません。選考の連絡が遅れている段を、一緒に見つけます。

手順3｜文面に入れること、入れないこと

見送りの文面は、短くてかまいません。入れるのは次の要素です。

入れること

  • 時間へのお礼：面談や面接に来てくれたこと。オファーに応えてくれたこと
  • 結果：遠回しにしすぎず、見送りだと分かる言葉で。読み終えて結果が分からない文面は、かえって不親切
  • 声をかけた側としての一言：「こちらからお声がけしたにもかかわらず」のような言葉を、自社の言葉で
  • 今後への言葉：就職活動が実りあるものになるよう願う、という締め
  • 名義：オファーや面談で名前を出した社員か、人事の担当者

入れないこと

  • 評価の細かい内容や、他の候補者との比較
  • 「次の機会に」など、実際には無い再挑戦を期待させる言葉
  • 学生の人柄や能力を否定するように読める言葉
  • 他社や他の選択肢を勧める言葉（意図が良くても、押しつけに読まれやすい）

型を作るときは、相手ごとに変える一文を残します。面談で話した話題や、学生が時間を割いてくれた事情に一言触れるだけで、一斉送信の印象は薄れます。型の作り方の考え方はオファー文面テンプレートを作るときの注意と共通です。

エージェントベストの見解

相談で多い思い込みは、「見送りの連絡は丁寧に長く書くほど誠実だ」というものです。実際には、学生の側から見て困るのは、長い前置きのあとに結果が埋もれている文面と、結果が分かるまで日数がかかることです。当社は3媒体すべての販売パートナーとしてOfferBoxの運用を見ていますが、見送りの連絡で学生の受け止めが荒れにくい会社は、文面が短く、結果が最初の数行で分かり、そこに「こちらから声をかけたのに」という一言が入っています。逆に、文面を整えることに時間をかけ、連絡が遅れる会社のほうが、学生の不満につながりやすい印象です。誠実さは、文面の長さではなく、約束した日までに届くことと、声をかけた側としての一言で伝わります。

手順4｜理由をどこまで伝えるか

学生から「理由を教えてほしい」と返事が来ることがあります。社内で扱いを先に決めておきます。

  • 会社としての方針を一つに決める：個別の理由は伝えない、または、伝えられる範囲だけ伝える、のどちらか
  • 伝える場合は、「事実」と「募集との合い方」だけ：「今回の募集で重視した点と、お話の内容が重なりにくかった」程度にとどめ、人柄や能力の評価を書かない
  • 伝えない場合は、その旨を丁寧に：方針として控えていることを伝え、問い合わせへのお礼を添える
  • 担当者が個別に判断しない：人によって答えが変わると、学生同士で比べられたときに不公平に映る

評価の物差しが社内で揃っていないと、理由を聞かれたときに答えに詰まります。基準の作り方は学生の評価基準の作り方で書きました。

手順5｜送る手段と記録

連絡は、学生とやり取りしている窓口で送ります。OfferBox上のメッセージで続けてきたのか、メールに移っているのかで変わります。メッセージの使い方と、媒体上での扱いの細かい点は、管理画面と媒体の案内で確認してください。窓口の考え方はメッセージ機能の使い方で書きました。

送ったら、管理表に残します。

  1. 見送りの段階（会う前・面談後・選考途中・最終）
  2. 連絡した日と、面接から連絡までの日数
  3. 理由の問い合わせがあったか、どう答えたか
  4. 見送りの理由の分類（募集との合い方、時期、条件など）

分類が溜まると、「最初から送る相手がずれていた」のか「選考で見るものがずれていた」のかが見えます。送る相手の見直しは、オファーの検索条件に戻します。

相談だけでも構いません。申込前提ではありません。選考の連絡まで含めた運用の分担を整理します。

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行で連絡の作業を担うときも、見送りの判断と、見送りの連絡を誰の名義で送るかは企業に残します。代行が担えるのは、期日の管理、文面の下書き、送信と記録までです。判断の理由を知らない側が文面を整えても、理由を聞かれたときに答えられません。また、オファーと面談で名前を出した社員がいるなら、最後の連絡もその人の名義で送るほうが、学生にとって話の筋が通ります。名義の社員が忙しければ、下書きは人事か代行が作り、本人は一文を足して確認するだけ、という形で負担を抑えられます。見送りの連絡は、関係を始めた人が閉じる。この線を先に決めておくと、代行に出す範囲も迷いません。代行の範囲は運用代行に任せられる範囲で書きました。

まとめ

  • オファーは企業から声をかけて始まる関係。見送りの連絡は、その関係をきれいに閉じる作業
  • 時期を文面より先に決め、伝えた日までに連絡する。見送りを合格より後回しにしない
  • 結果は最初の数行で分かるように。声をかけた側としての一言と、時間へのお礼を入れる
  • 理由の扱いは会社として一つに決め、評価の細部を書かない
  • 段階と理由の分類を記録し、送る相手と選考の見直しに戻す

よくある質問

面談だけで終わった学生にも、連絡は要りますか

要ります。面談のあとに選考の案内をしない場合も、その旨を一度は伝えます。面談を「選考ではない」と案内していたなら、「選考へのご案内は控える」という書き方にし、時間を取ってもらったことへのお礼を添えてください。

連絡しないことで「察してもらう」のは避けたほうがよいですか

避けたほうがよいです。こちらから声をかけて始まった関係なので、連絡が来ないまま終わると、学生の受け止めは厳しくなります。短い文面でも、結果が分かる連絡を一度送ってください。

見送った学生に、別の職種でもう一度オファーを送ってもよいですか

職種や募集の条件が変わり、学生のプロフィールにも重なる点があるなら、考える余地はあります。前回の経緯に触れずに送ると不自然に映るので、送るかどうかの判断と書き方は同じ学生に再度オファーを送るときの考え方を参考にしてください。
