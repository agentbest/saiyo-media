Infraの求人原稿の書き方｜学生が応募を決める順番

Infraは、学生向けの長期インターン求人サイトです。掲載を始めた会社から「原稿を出したのに応募が来ない」という相談を受けると、多くの場合、書いてある内容そのものより書いてある順番が学生の読み方とずれています。結論から言うと、原稿は「学生が応募を決めるまでに確かめる順番」に沿って並べると、同じ情報量でも応募の判断がしやすくなります。 この記事では、その順番と、各段で何を書くかを、社内で原稿を書く担当者向けに整理します。媒体の仕様の細部は変わることがあるため、ここでは原稿の中身の組み立て方に絞ります。

学生は原稿を「確かめる順番」で読んでいる

長期インターンを探す学生は、新卒の就職活動ほど企業研究をしてから応募するわけではありません。授業やサークルと並行して、空いた時間に一覧を眺め、気になったものを開きます。開いたあとに確かめることは、おおむね次の順番です。

  1. 何をする仕事か（タイトルと冒頭で分かるか）
  2. 自分にできそうか（仕事内容の具体さ、未経験でも始められるか）
  3. 続けられそうか（勤務日数・時間・場所・リモートの可否・時給）
  4. 誰と働くか（担当社員、チームの雰囲気、ほかのインターン生）
  5. 応募したら何が起きるか（選考の回数、面接の形式、開始時期）

この順番のどこかで「分からない」が出ると、学生はそこで原稿を閉じます。特に1と3は判断が速く、ここで迷わせると、仕事の魅力をどれだけ書いても読まれません。

会社の理念や事業の歴史を冒頭に長く置く原稿をよく見ますが、学生がそれを読むのは4の段階、つまり「この会社で働いてみたい」と思い始めてからです。理念を書くなとは言いませんが、置く場所を後ろに下げるだけで読まれ方が変わります。

順番ごとに書くこと

1. 何をする仕事か

タイトルと本文の冒頭2〜3行で、職種と主な業務が分かるようにします。「急成長ベンチャーで裁量ある仕事」では、学生は何をするのか分かりません。「法人向けSaaSのインサイドセールス。電話とメールで商談を作る」のように、職種と動作を書きます。タイトルの付け方はInfraの求人タイトルの付け方で詳しく書きました。

2. 自分にできそうか

任せる業務を、1日の流れや週の流れとして書きます。最初の1か月に何をして、慣れたら何を任せるか。未経験歓迎なら、最初に教えることと、教える人を書きます。「未経験歓迎」の一言より、「最初の2週間は先輩の商談に同席し、議事録を書く」のほうが、学生は自分がそこにいる姿を想像できます。

3. 続けられそうか

勤務日数、1日の時間、曜日の自由度、試験期間の扱い、リモートの可否、時給と昇給の考え方。ここは学生の生活と直結するので、曖昧に書くと応募後の面接で毎回同じ質問を受けることになります。最低賃金や労働時間の規定を守ったうえで、実際の運用に近い形で書きます。

4. 誰と働くか

担当社員の役割、チームの人数感、いま働いているインターン生の学年や専攻の傾向。写真があれば、オフィスの様子より、実際に働いている場面のほうが伝わります。

5. 応募したら何が起きるか

応募から開始までの流れを番号で書きます。「書類確認→面接1回（オンライン可）→開始日の相談」のように書くと、学生は応募のハードルを低く感じます。

原稿の並べ方だけ見直したい、という相談も受けています。いまの原稿を一緒に読むところから始められます。

運用の相談をする

エージェントベストの見解

原稿を書き直すとき、当社が最初に手を付けるのは文章の言い回しではなく、勤務条件の段です。応募が少ない原稿を並べてみると、仕事内容は丁寧に書かれているのに、週に何日、何時間入ればよいのかが「応相談」で終わっているものが目立ちます。学生にとって「応相談」は、自分の予定を伝えたら断られるかもしれない、という不安の種になります。だから先に、社内で「週2日・1日4時間から」「試験期間は休めるか」といった下限と例外を決めてもらい、それを原稿に書きます。決めてから書くので、原稿作業の前に現場との調整が一度入ります。遠回りに見えますが、この調整を飛ばして文章だけ整えても、面接で同じ質問が繰り返され、そこで辞退が出ます。原稿は社内の取り決めを写す紙だと考えると、書く順番が決まります。

やりがちな失敗

  • 会社紹介から書き始める：学生が最初に知りたいのは仕事内容です。会社紹介は後半に置きます
  • 業務を名詞で並べる：「営業補助、資料作成、データ入力」だけでは様子が浮かびません。誰に、何を、どのくらいの頻度で、を足します
  • 「成長できる」を繰り返す：どの原稿にも書いてあるため、差になりません。何ができるようになるかを、具体的な業務で書きます
  • 条件を面接で話すつもりで省く：省いた条件は、応募の前に学生が離れる理由になります
  • 一度書いたら更新しない：任せる業務やインターン生の様子は変わります。季節ごとに見直すと、原稿と実態のずれが小さく保てます

仕事内容の段の書き方は、長期インターンの仕事内容の書き方でもう一段細かく扱っています。

社内の分担

原稿は人事が1人で書くと、仕事内容が薄くなりがちです。現場の担当社員にしか分からないことが多いからです。分担の目安は次のとおりです。

段主に書く人確認する人
タイトル・冒頭人事現場
仕事内容・1日の流れ現場の担当社員人事
勤務条件・時給人事労務・経理
一緒に働く人現場人事
選考の流れ人事面接する人

現場に書いてもらうときは、白紙で頼まず、「最初の1か月にやってもらうこと」「慣れたら任せること」「教える人」の3つの欄だけを渡すと、短い時間で材料が集まります。

原稿の作成から掲載後の運用まで、Infraの代理店として支援しています。プランの違いも含めてご案内します。

無料で相談する

エージェントベストの見解

原稿づくりを外に出すとき、どこまでを社内に残すべきかをよく聞かれます。当社がInfraの原稿作成を支援する場合でも、仕事内容の材料と勤務条件の決定は企業側に残してもらっています。文章にすることは外でできますが、「この学生に何を任せるか」は、受け入れる現場が決めることだからです。ここを外に任せると、原稿はきれいでも、入ってきた学生が現場で手持ち無沙汰になり、早く辞めます。逆に、言い回しの調整、タイトルの見直し、学生に伝わる言葉への置き換え、掲載後の反応を見た書き直しは、外に出しても質が落ちにくい部分です。社内は「決めること」、外は「伝わる形にすること」。この線で分けると、原稿の作業時間を減らしても、中身が薄くなりません。

まとめ

  • 学生は「何をする仕事か→できそうか→続けられそうか→誰と働くか→応募後の流れ」の順に確かめている
  • 会社紹介や理念は、学生が働いてみたいと思い始める後半に置く
  • 勤務条件の「応相談」は不安の種になる。社内で下限と例外を決めてから書く
  • 仕事内容は現場、条件は人事と分担し、現場には欄を渡して材料を集める
  • 原稿は社内の取り決めを写すもの。決めることは社内、伝わる形にすることは外に出せる

よくある質問

原稿はどのくらいの長さにすればよいですか

長さより、学生が確かめる5つの段がそろっているかを見ます。どれかが欠けていると、長い原稿でも応募は増えにくい傾向があります。段ごとに数行ずつあれば、まずは十分です。

複数の職種を1つの原稿で募集してもよいですか

まとめると、学生は自分が何をするのか判断しにくくなります。任せる業務や担当社員が違うなら、原稿を分けるほうが読みやすくなります。分けた原稿どうしで、会社紹介の段は共通にして構いません。

原稿の書き直しはどのタイミングで行えばよいですか

応募が止まったときだけでなく、任せる業務が変わったとき、インターン生が入れ替わったとき、学生の長期休みの前など、実態が変わる節目に見直すのが目安です。面接で同じ質問が続いたら、その答えを原稿に足すと書き直しの材料になります。
