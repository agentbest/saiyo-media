文系・理系で長期インターンの募集を分けるべきか

Infra・長期インターン課題別 更新日 2026/10/29

長期インターンの募集を出すとき、「文系向け」「理系向け」と分けるべきかどうか迷う会社は少なくありません。判断の軸は文系か理系かではなく、仕事に要る前提知識と、学生が使える時間の形です。 文理で分けることが目的になると、仕事の中身が伝わらない原稿ができてしまいます。この記事では、学生向けの長期インターン求人サイトInfraなどで募集を出す会社に向けて、文系・理系で分けるかどうかの判断と、分ける・分けない場合それぞれの書き方を整理します。

分けるかどうかの判断軸

文系・理系で募集を分けるかどうかは、次の2つで判断します。

  1. 仕事に要る前提知識：その仕事を始めるのに、特定の専攻で学ぶ知識が要るか。たとえば、プログラミングの基礎、統計の知識、設計の考え方など
  2. 学生が使える時間の形：対象とする学生の時間の取り方に、大きな違いがあるか。理系の学生は実験や研究室の予定で時間が決まりやすく、文系の学生は授業の組み方で時間を調整しやすい傾向があると言われます

1番目で「特定の知識が要る」なら、その知識を持つ学生に向けて書くことになりますが、それは必ずしも「理系向け」と同じではありません。文系でもプログラミングを独学している学生はいますし、理系でも営業や企画に関心のある学生はいます。

2番目で大きな違いがあるなら、時間の条件を分けて書く意味があります。

分けない場合の書き方｜仕事と前提で書く

多くの仕事は、文系・理系で分けなくても募集できます。その場合は、文理の言葉を使わず、仕事の中身と前提知識で書きます。

書き方例
文理で書く「理系学生歓迎」「文系の方も活躍中」
仕事と前提で書く「データを表計算ソフトで集計し、傾向を読み取る仕事です。関数を使った経験があれば十分です」

後者のほうが、学生は自分に合うかどうかを判断しやすくなります。文系で表計算ソフトに慣れている学生も、理系で集計の経験がある学生も、同じように応募を考えられます。

仕事の中身と前提知識で書く求人原稿へ、書き直しの段階から一緒に進めます。

無料で相談する

分ける場合に気をつけること

文系・理系で募集を分けると決めた場合は、次の点に気をつけます。

時間の条件を学生の予定に合わせる

理系の学生、とくに研究室に所属する学年の学生は、実験や研究の予定で使える時間が限られることがあります。週の日数を少なくする、在宅でできる作業を混ぜる、研究の繁忙期に休めるようにする、といった配慮を原稿に書いておくと、応募をためらう学生が減ります。

仕事の見せ方を変える

理系の学生には、専攻で学んだことが仕事のどこで使えるかを書くと関心を持ってもらいやすくなります。文系の学生には、仕事を通じてどんな考え方や技能が身につくかを書くと伝わりやすい傾向があります。ただし、これはあくまで傾向で、学生一人ひとりの関心はさまざまです。

「向け」を排除の意味にしない

「理系向け」と書いた募集に文系の学生が応募してきたとき、一律に断るのは避けます。前提知識を持っていれば、専攻にかかわらず検討する姿勢を原稿にも書いておくと、応募の幅を狭めすぎずに済みます。

エージェントベストの見解

文系・理系で募集を分けたいという相談を受けて詳しく聞くと、実際には「エンジニアの仕事」と「それ以外の仕事」を分けたい、という意味であることが多くあります。その場合、当社が勧めるのは、文理で分けるのではなく、仕事ごとに原稿を分けることです。「エンジニアのインターン」と「営業企画のインターン」という原稿を別々に用意し、それぞれの仕事に要る前提知識を書く。そうすると、エンジニアの仕事に関心がある文系の学生や、営業企画に関心がある理系の学生も、迷わずに応募できます。当社はInfraの代理店として求人原稿の作成から支援していますが、文理で分けた原稿より、仕事で分けた原稿のほうが、学生が自分に合うかどうかを判断しやすい書き方になると考えています。文理という大きな括りは、学生にとって自分を当てはめる枠にはなっても、仕事を想像する手がかりにはなりにくいからです。

今の原稿を見直すときの確認項目

すでに文理を分けた原稿、あるいは分けていない原稿を出している会社は、次の項目で見直してみてください。

  • 「文系」「理系」という言葉が、仕事の説明の代わりになっていないか
  • 仕事に要る前提知識が、専攻名ではなく、具体的な経験や道具の名前で書かれているか
  • 研究や授業の予定に合わせた時間の条件が書かれているか
  • 応募してきた学生の専攻と、受け入れ後に続いた学生の専攻を記録しているか

最後の記録があると、「理系向けとして出したが、続いたのは文系の学生だった」といった発見が得られます。思い込みで募集を分けていたことに気づくきっかけになります。

新卒採用への接続を考える

長期インターンを新卒採用の入口として使う会社は、文系・理系の違いが就職活動の進み方にも関わることを知っておくと役立ちます。

一般に、理系の学生は研究の予定や学校推薦の流れによって、就職活動に使える時期が文系より限られる傾向があると言われます。長期インターンの段階で接点を持っておくと、本選考の時期に慌てずに済むことがあります。文系の学生は、業界や職種の志望が広く、多くの会社と並行して進む傾向があるため、インターンの経験が志望を絞るきっかけになることがあります。

学生の就職活動の進み方の違いは、理系学生の採用スケジュールと文系学生の採用スケジュールで詳しく整理しています。

長期インターンと新卒の媒体を、文理の違いも含めてどう組み合わせるか相談できます。

媒体選びを相談する

受け入れ後の配慮

文系・理系にかかわらず、受け入れたあとは、学生の専攻と仕事の関係を意識した関わり方が役立ちます。

  • 専攻で学んだことが仕事で活きる場面があれば、具体的に伝える
  • 専攻と関係のない仕事を任せる場合は、その仕事で何が身につくかを伝える
  • 研究や卒業論文の繁忙期を事前に聞き、シフトを調整する

とくに理系の学生の研究の予定は、本人も直前まで読めないことがあります。予定が変わりやすいことを前提に、連絡の仕方を決めておくと、学生が無理をして続けることを防げます。

エージェントベストの見解

当社は人材紹介も行っており、社会人の採用では「文系出身のエンジニア」や「理系出身の営業」が珍しくありません。学生時代の専攻と、社会に出てからの仕事は、思っている以上に結びつきが緩いものです。長期インターンは、学生がその結びつきの緩さに気づく最初の場になることがあります。文系の学生がデータ分析の面白さに気づく、理系の学生が顧客と話す仕事に手応えを感じる。そうした発見は、文理で募集を分けている会社では起きにくくなります。もちろん、前提知識が要る仕事に知識のない学生を受け入れるのは双方にとって負担ですが、前提知識を「専攻」ではなく「経験」で書いておけば、こうした発見の機会を閉ざさずに済みます。募集の段階で枠を狭めすぎないことが、結果として会社にとっても学生の可能性を広く見ることにつながります。

まとめ

  • 文系・理系で分けるかどうかは、仕事に要る前提知識と、学生が使える時間の形で判断する
  • 分けない場合は、文理の言葉を使わず、仕事の中身と前提知識で書く
  • 分ける場合は、時間の条件と仕事の見せ方を変え、「向け」を排除の意味にしない
  • 文理で分けるより、仕事ごとに原稿を分けるほうが学生は判断しやすい
  • 新卒採用への接続を考えるなら、文理による就職活動の進み方の違いも意識する

よくある質問

理系の学生に絞りたい仕事でも、文系の学生の応募を受け付けるべきですか

前提知識で判断するのが基本です。仕事に要る知識を原稿に書いておき、その知識を持っていれば専攻にかかわらず検討する、という姿勢にすると、応募の幅を不必要に狭めずに済みます。

大学院生は理系として扱えばよいですか

大学院生は文系・理系とも研究の比重が大きく、時間の取り方が学部生とは違います。文理より、研究の予定に合わせた時間の条件を書くことを優先してください。

文理で分けると、応募数は増えますか

分けたことで応募数が増えるかどうかは、仕事の内容や原稿の書き方によって異なります。数より、仕事に合った学生が応募してくれるかどうかで判断するほうが、受け入れ後の定着につながりやすくなります。
