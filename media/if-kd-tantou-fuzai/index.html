長期インターンの担当社員が不在になったとき｜止めない段取り

Infra・長期インターン課題別（追加） 更新日 2026/11/4

長期インターン生を日々見ていた社員が、異動や休職、退職で急にいなくなる。受け入れを続けている会社では、いずれ一度は起きることです。結論から言うと、担当社員が不在になったときは、後任を探すより先に「明日からの窓口を一人決める」「任せる仕事を一度絞る」の二つを済ませると、インターン生の離脱を防ぎやすくなります。 担当者の不在そのものより、インターン生が「誰に聞けばいいか分からない」状態が続くことのほうが、関係を傷めます。この記事では、症状の確認から原因の切り分け、打ち手、外に出せる範囲までを順に整理します。

担当が不在になったときに起きていること

担当社員がいなくなった直後、インターン生の側では次のような変化が起きがちです。

  • 出勤しても、その日に何をすればいいかが決まっていない
  • 作業の確認を誰に頼めばいいか分からず、提出物が止まる
  • シフトや勤怠の連絡先が曖昧になり、連絡が遅れる
  • 「自分は必要とされていないのでは」と感じ、出勤の頻度が下がる

会社の側から見ると、インターン生が静かになっただけに見えることがあります。表立った不満が出ないまま、ある日「学業が忙しくなったので」と退職の連絡が来る。担当者の不在が原因だったと気づくのは、その後です。

まず確かめたいのは、インターン生が今どの状態にあるかです。担当者がいなくなってから、出勤の頻度、提出物の量、連絡の速さに変化があるか。変化が出ていれば、すでに影響は始まっています。

原因の切り分け｜この順番で確かめる

「担当がいないから困っている」と一言で済ませず、何が欠けているのかを分けて見ます。確かめる順番は次のとおりです。

  1. 連絡の窓口が欠けているか：シフト、勤怠、体調の連絡を受ける人が決まっているか
  2. 仕事の割り振りが欠けているか：その日の作業を決め、渡す人がいるか
  3. 確認と助言が欠けているか：作業の出来を見て、直し方を伝える人がいるか
  4. 相談の相手が欠けているか：仕事以外の悩みや進路の話を聞く人がいるか

担当社員は、この四つを一人で兼ねていることが多いです。そのため、いなくなると四つが同時に止まります。ただ、四つを同じ人に引き継ぐ必要はありません。一番上の連絡の窓口が欠けていると、他の三つも回らないので、ここから埋めます。

二つ目以降は、仕事の中身によって埋め方が変わります。作業の確認ができる社員は部署の中にいても、相談の相手まで務められるとは限りません。どれが欠けていて、誰なら埋められるかを、この順番で一つずつ確かめます。

担当者が抜けたあとの受け入れの組み直しを、一緒に整理します。相談だけでも構いません。

運用の相談をする

打ち手｜窓口を決め、仕事を絞り、引き継ぐ

切り分けができたら、次の順で手を打ちます。

1. 窓口を一人決めて、インターン生に伝える

後任が決まるまでの仮の窓口で構いません。部署の責任者でも、人事でも、年の近い社員でも、連絡を落とさず受けられる人を一人決めます。決めたら、その日のうちにインターン生へ伝えます。「担当が変わります。しばらくは〇〇さんに連絡してください」という短い連絡だけでも、不安はかなり減ります。

2. 任せる仕事を一度絞る

前の担当者が任せていた仕事を、そのまま引き継ごうとすると無理が出ます。仮の窓口の社員は、本業を持ったまま見ることになるからです。いったん、確認の手間が少なく、手順が決まっている仕事に絞ります。広げるのは、新しい担当が慣れてからで十分です。

3. 前の担当者から引き継ぎを受ける

異動や休職で、前の担当者と連絡が取れるなら、次の点を短く聞き取ります。

  • インターン生に任せていた仕事と、その進み具合
  • 本人の得意なことと、つまずきやすいこと
  • 学業の予定や、出勤できる曜日・時間の傾向
  • 卒業後の進路について、本人が話していたこと

退職などで聞き取りが難しい場合は、インターン生本人から聞きます。本人に「今どんな仕事を、どこまでやっていたか」を書き出してもらうと、引き継ぎの資料にもなります。

4. 本人と一度話す

担当が変わったことを、本人がどう受け止めているかを聞く場を設けます。新しい窓口の社員と、可能なら部署の責任者も同席します。続けたいか、仕事の量や内容に希望はあるかを聞き、会社としてどう受け入れを続けるかを伝えます。

エージェントベストの見解

担当者の不在が起きた会社から相談を受けると、多くの場合、後任を「前の担当者と同じように全部見られる人」の中から探そうとして、決まるまでに時間がかかっています。その間、インターン生は窓口のない状態に置かれます。先に決めるべきなのは完全な後任ではなく、連絡を受ける人です。仕事の割り振りや確認は、部署の中の複数の社員で分けても回ります。むしろ、担当を一人に集めていたことが、今回の不在で受け入れが止まった原因でもあります。後任を決めるときは、窓口と仕事の確認を別の人に持たせる形を検討してください。一人に戻すと、次に同じことが起きたとき、また同じ止まり方をします。

外に出す場合の範囲

担当者の不在をきっかけに、受け入れの一部を外に任せることを考える会社もあります。このとき、外に出せるものと、社内に残すべきものを分けておきます。

  • 外に出しやすいこと：次のインターン生の募集原稿の作成と更新、応募への一次対応、面接日程の調整
  • 社内に残すこと：日々の仕事の割り振りと確認、本人との面談、受け入れを続けるかの判断

日々の受け入れそのものは、職場の中にいる社員でなければ担えません。外に出せるのは主に、次の募集に関わる作業です。担当者の不在で現場の負担が増えている時期に、募集の作業まで社員が抱えると、二重に手が回らなくなります。

なお、担当者の交代に伴って、勤務の時間や曜日、仕事の内容が変わる場合は、インターン生との間の取り決めを見直す必要が出ることがあります。労働条件の明示などは法令で定められた項目があるため、変更の扱いは社労士や公式の案内で確認してください。

次の募集の作業だけを外に出す形もあります。どこまで任せられるか、範囲から相談できます。

無料で相談する

エージェントベストの見解

担当者が抜けたあとに「インターンの受け入れそのものを見直したい」という相談になることもあります。そのとき、すぐにやめるか続けるかを決める前に、今いるインターン生の卒業や退職の時期を確かめることを勧めます。在籍している学生が数か月以内に卒業するなら、その期間は仮の窓口で受け入れを続け、卒業を区切りに体制を組み直すほうが、本人にも社内にも負担が少なくて済みます。逆に、まだ在籍の期間が長い学生がいるなら、仮の体制で長く引っ張らず、早めに正式な担当を決めるべきです。判断の材料は、担当者の不在そのものではなく、在籍している学生の残りの期間です。

次に同じことが起きないための備え

担当者の不在は、人の異動がある以上、避けられません。起きたときに止まらないよう、平時から次の点を整えておきます。

  • 担当を二人にする：主に見る人と、代わりに見られる人を決めておく
  • 任せている仕事を一覧にしておく：仕事の名前、手順、確認する人を一枚にまとめる
  • 連絡の窓口を個人でなく共有の場所にする：シフトや勤怠の連絡は、部署で見られる場所に集める

手順書や業務の一覧の作り方は、長期インターン生の卒業と引き継ぎにまとめています。受け入れの体制全体の考え方は、長期インターンの受け入れ体制も参考になります。

まとめ

  • 担当社員が不在になったら、後任より先に、明日からの窓口を一人決めて本人に伝える
  • 欠けているものを、連絡・仕事の割り振り・確認・相談の順に切り分ける
  • 仮の体制のあいだは、任せる仕事を手順の決まったものに絞る
  • 外に出せるのは主に次の募集の作業で、日々の受け入れは社内に残す
  • 平時から担当を二人にし、任せている仕事を一覧にしておく

よくある質問

後任の担当者がしばらく決まりません。どうすればよいですか

後任が決まるまでは、連絡を受ける仮の窓口を一人置き、その人の名前をインターン生に伝えます。仕事の確認は部署の中で分けても構いません。仮の期間が長くなりそうなら、その見通しも本人に伝えておくと、不安が和らぎます。

インターン生が担当者を慕っていて、辞めたいと言っています

担当者との関係で続けていた学生にとって、交代は大きな変化です。まず本人の話を聞き、続けるかどうかを急がせないことです。新しい窓口の社員と話す機会を作ったうえで、それでも辞めると決めたなら、卒業の扱いとして気持ちよく送り出します。

担当者の不在をきっかけに、受け入れをやめるべきか迷っています

在籍している学生の残りの期間と、次の担当を立てられるかの二点で考えます。受け入れをやめるかの判断の進め方は、長期インターンの受け入れをやめる判断で整理しています。
