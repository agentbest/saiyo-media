採用サイトの作り方｜最初に載せる内容

採用サイトを作ろうとすると、デザインや動画、社員の写真をどう見せるかに目が向きがちです。しかし、候補者が採用サイトを開くのは、多くの場合スカウトや求人を見たあとの「確かめる」段階です。結論から言うと、最初の採用サイトは、候補者が応募の前に確かめたいことに答えるページだけで十分です。 この記事では、最初に載せる内容の優先順位と、ページ構成の型、作る手順を整理します。

採用サイトは「確かめる場所」として作る

候補者が採用サイトにたどり着く流れは、おおむね次のどれかです。

  • 媒体でスカウトや求人を見て、会社名で検索する
  • 説明会や面談のあとに、もう一度会社を確かめる
  • 友人や知人から会社の名前を聞いて調べる

どの流れでも、候補者はすでに会社の名前を知っています。採用サイトの役割は、会社を初めて知ってもらうことよりも、「この会社に応募してよいか」「面接に進んでよいか」を判断する材料を渡すことにあります。

この前提に立つと、最初に作り込むべきなのは見た目ではなく、候補者の疑問に答える中身だと分かります。見た目は、中身がそろってから整えても遅くありません。

最初に載せる内容の優先順位

最初に載せる内容は、候補者が判断に使う順に並べます。

  1. 募集している仕事：職種ごとの仕事の中身、入社後に担うこと、応募の条件
  2. 働く環境：勤務地、働き方、給与の考え方、評価のされ方
  3. 一緒に働く人：チームの構成、社員の経歴や入社の理由
  4. 選考の流れ：応募から内定までの流れと、各段階で何をするか
  5. 会社の考え：事業の方向、代表のメッセージ

1と4は、候補者が応募の手前でもっとも確かめたい情報です。ここが空いている採用サイトは、ほかがどれほど整っていても、候補者を応募に進めにくくなります。

逆に、会社の沿革や受賞の一覧、福利厚生の細かな列挙は、後回しにして構いません。載せるなら、候補者の判断に関わるものに絞ります。

採用サイトと媒体のページで、どこに何を載せるかを分けて整理します。相談だけでも構いません。

ページ構成の型

最初の採用サイトは、次の構成で始められます。ページ数を増やすより、一つずつの中身を具体的にします。

ページ載せる内容書き方の注意
トップどんな会社で、誰を募集しているか一文で言えるようにする。抽象的な言葉だけで終わらせない
仕事・募集職種ごとの仕事内容、条件、応募の入口求人票と内容をそろえる
働く人社員の紹介を数名分職種や経歴が偏らないように選ぶ
働き方・制度勤務、給与の考え方、評価、休み整っていない制度は今後の考えとあわせて
選考の流れ段階ごとの内容と、誰が出るか面接の設計と合わせる
代表メッセージ事業の方向と、求める人長さより中身。書き方は代表メッセージの書き方

仕事・募集のページは、求人票と食い違わないことが大切です。求人票の書き方は求人票の書き方の基本で整理しています。社員の紹介ページは、社員インタビューの作り方の質問の型を使うと、人によって中身がばらつきにくくなります。

エージェントベストの見解

採用サイトを作る前に、先に決めておかないと効果が出ないことがあります。それは「採用サイトと媒体のページで、何を分担するか」です。当社は申込後の運用まで見ていますが、媒体のページと採用サイトに同じ文章を並べている会社は、候補者が両方を開いても新しい情報が得られず、確かめる材料が増えません。勧めているのは、媒体のページには候補者が最初に知りたい仕事の要点と会う理由を短く書き、採用サイトには選考の流れや評価の考え方、社員の詳しい話のように、応募を決める前に深く確かめたい情報を置く分け方です。媒体のページから採用サイトへ、採用サイトから応募へ、という順に読み進められると、候補者が一つの場所で迷わずに済みます。作り始める前に、この分担を一枚に書いておくことを勧めます。

作る手順｜原稿から先に、見た目はあとで

作る手順は、次の順番を勧めます。

  1. 載せる内容の原稿を先に書く：ページごとに、文章と必要な写真を一覧にする
  2. 社内で事実を確認する：給与、制度、選考の流れが現状と合っているかを人事と現場で確かめる
  3. 作り方を決める：自社のサイトの中に作るか、採用サイト用の作成サービスを使うか、制作を外に頼むか
  4. 公開して、候補者に案内する：スカウトや面談の案内に、該当するページを添える
  5. 候補者の反応を聞く：面接で「どのページを読んだか」「分からなかったことは何か」を聞く

3の作り方は、更新を誰がするかで決めます。外に頼んで作り込んでも、更新のたびに依頼が必要になると、情報が古くなりがちです。更新の仕組みは採用サイトを更新し続ける仕組みにまとめています。

原稿を先に書くと、写真の撮影も必要な場面だけで済みます。撮る場面の決め方は採用広報の写真で扱っています。

会社の規模や採用の状況による差

同じ型でも、会社の状況によって重みが変わります。

  • 社員が少ない会社：ページを分けず、一枚のページに全部を載せる形でも構いません。代表の考えと一緒に働く人の顔が見えることが、判断の材料になります
  • 新卒を中心に採る会社：選考の流れと、入社後の育て方の比重が上がります。学生は、何を学べるかと、誰に教わるかを確かめに来ます
  • 中途を中心に採る会社：仕事の中身と、評価や給与の考え方の比重が上がります。経験者は、自分の経験がどう生きるかを確かめに来ます
  • 複数の職種を募集している会社：職種ごとのページを分け、それぞれに社員の紹介を一人ずつ置くと、読み手が自分に近い情報を探しやすくなります

新卒と中途で、採用サイトと媒体の組み合わせをどう分けるか、一度整理してみませんか。

媒体選びを相談する

媒体のページとのつなぎ方

採用サイトは、媒体と組み合わせて使うと役割がはっきりします。

OfferBoxでは、スカウトを受け取った学生が企業ページを確かめます。Wantedlyでは、募集ページやストーリーで会社を知った人が、さらに詳しく調べることがあります。ワンキャリアでは、選考の情報やクチコミとあわせて会社を見る学生がいます。どの媒体でも、媒体のページで興味を持った人が、次に確かめる場所として採用サイトを開きます。

そのため、媒体のページには採用サイトへの導線を入れ、採用サイトには応募の入口を分かりやすく置きます。媒体の規約で外部への導線が制限される場所もあるので、各媒体の案内に沿って入れます。

エージェントベストの見解

当社は媒体で採る支援と、紹介で採る支援の両方をしているので、候補者が採用サイトをどう使うかを両側から見ています。紹介で会う候補者は、担当者から会社の話を聞いたうえで、採用サイトを「聞いた話が本当か」を確かめるために開きます。媒体で会う候補者は、スカウトや求人の短い情報しか持っていないので、採用サイトを「この会社をもっと知りたいか」を決めるために開きます。同じ採用サイトでも、前者には事実の裏付けが、後者には会う理由が求められます。だから最初の採用サイトでは、仕事と選考の流れを具体的に書いて裏付けに応え、トップの一文で「誰に、何を任せたいか」を言い切って会う理由に応える。この二つがそろっていれば、作り込みが少なくても、どちらの候補者にも判断の材料を渡せます。

まとめ

  • 採用サイトは、すでに会社を知った候補者が「確かめる場所」として作る
  • 最初に載せるのは、募集している仕事と選考の流れを優先する
  • 媒体のページと採用サイトで、載せる情報の深さを分担する
  • 原稿を先に書き、見た目や写真はあとで整える。作り方は更新する人で決める
  • 規模や新卒・中途によって比重を変え、媒体のページとつなげて使う

よくある質問

採用サイトはどれくらいの規模で作ればよいですか

最初は、募集している仕事、働く人、選考の流れの三つが分かれば十分です。ページ数を増やすより、一つずつの中身を具体的にするほうが、候補者の判断に役立ちます。足りない情報は、面接で候補者に聞きながら足していきます。

自社の会社サイトの中に作るのと、別に作るのはどちらがよいですか

どちらでも構いません。決め手になるのは、採用担当者が自分で更新できるかどうかです。更新に毎回依頼が必要な形だと、募集の変更に追いつかず、情報が古くなりやすくなります。

採用サイトを作れば、媒体を使わなくても応募は来ますか

採用サイトは、会社の名前を知った人が確かめに来る場所なので、それだけで新しい候補者に見つけてもらうのは難しいことが多いです。媒体やスカウトで接点を作り、採用サイトで判断の材料を渡す、という組み合わせで考えるほうが現実的です。
