応募直後の連絡｜当日に返す型

採用ノウハウ候補者との連絡 更新日 2026/11/4

応募が来たあと、書類を読んで判断してから返信しようとすると、どうしても数日かかります。その数日の間に、候補者は他社の選考に進んでいることがあります。結論から言うと、応募直後の連絡は、判断を待たずに受け取った当日に返し、「受け取ったこと」「次に何が起きるか」「いつまでに連絡するか」の三つだけを伝える型にすると、速さと丁寧さを両立できます。 この記事では、当日に返すための体制、文面の型、応募経路ごとの書き分け、遅れたときの対応を整理します。

応募直後の連絡が効く理由

応募した直後の候補者は、その会社への関心が最も高い状態にあります。この時期に反応がないと、関心は少しずつ他社に移ります。

応募直後の連絡で候補者が知りたいのは、次の三つです。

  • 応募が届いたかどうか
  • これから何が起きるのか（書類選考なのか、面談なのか）
  • いつごろ連絡が来るのか

媒体の自動返信で「受け付けました」と届くことはありますが、それだけでは二つ目と三つ目が分かりません。会社から一通、次の流れと時期を伝えるだけで、候補者は安心して待てます。連絡の全体の考え方は、候補者との連絡の基本にまとめています。

当日に返すための体制

当日に返すには、文面より先に体制を決めます。

  1. 確認する時間を決める：一日のうち、媒体の管理画面とメールを見る時間を決めます。朝と夕方の二回など
  2. 返す人を一人に決める：応募への一次返信の担当を一人に決め、休む日の代わりも決めます
  3. 判断と返信を分ける：一次返信では合否に触れません。書類の判断は、返信のあとで行います
  4. 型を用意しておく：応募経路ごとに型を作り、個別の一文を足すだけで送れるようにします

三つ目が特に大事です。判断と返信をつなげてしまうと、判断が遅れた分だけ返信も遅れます。一次返信は「受け取りました、次はこうなります」で十分です。

応募への一次返信を当日に回せる体制を、社内の人数に合わせて一緒に考えます。

運用の相談をする

エージェントベストの見解

当社は媒体の運用代行で応募への一次対応を受け持つことがあります。そこで見えるのは、一次返信が遅れる会社の多くが、「書類を読んでから返そう」と考えていることです。担当者は丁寧に対応しようとしているのですが、書類の判断には現場の責任者の確認が要ることも多く、その確認を待つうちに数日が過ぎます。勧めているのは、一次返信で「書類の確認に何日いただくか」を伝えてしまうことです。期限を先に伝えると、社内にも「この日までに判断する」という締め切りができ、判断そのものも早まります。一次返信を当日に返すことは、候補者のためだけでなく、社内の判断を前に進める仕組みにもなります。

文面の型

応募直後の連絡は、次の型で組みます。

件名：ご応募ありがとうございます（会社名）

本文の構成

  1. 応募へのお礼と、受け取ったこと
  2. 個別の一文（応募書類やプロフィールで目に留まった点）
  3. 次に起きること（書類選考、カジュアル面談、など）
  4. 次の連絡の時期（「◯日までにご連絡します」と具体的に）
  5. 問い合わせ先（担当者の名前と連絡方法）

個別の一文は、たとえば「これまでの経験の中で、◯◯の仕事に関わっていらしたことに関心を持ちました」のように、応募書類から一つ拾います。書類を読み込んで判断する必要はなく、目に留まった事実を一つ書けば足ります。

文面は短くまとめます。会社の説明や選考の詳しい流れは、この段階では要りません。長い説明は、次の連絡か面談の場で伝えます。

応募経路ごとの書き分け

応募の経路によって、候補者の状態が違います。型は同じでも、書き分けるところがあります。

  • 掲載型の媒体からの応募（ワンキャリアなど）：候補者が自分から選んで応募しているので、応募へのお礼をはっきり書きます。次の段階が説明会なのか選考なのかを明確に
  • スカウトへの返信（OfferBoxなど）：企業から声をかけた相手なので、返信をもらったことへのお礼と、なぜ声をかけたかを一言添えます。次の段階は面談にすることが多いです
  • 中途の求人サイトからの応募（Greenなど）：在職中の候補者が多いので、面談や面接の日程は平日の夜やオンラインも選べることを伝えると、次に進みやすくなります
  • 自社サイトからの応募：媒体の自動返信がないことが多いので、受け取ったことの連絡が特に大事です

応募経路ごとの流れを、使っている媒体に合わせて整理します。比較だけでもどうぞ。

媒体選びを相談する

返信が遅れたときの対応

体制を整えても、返信が遅れることはあります。そのときは、次のように対応します。

  • 遅れたことを一言わびる：長い謝罪は要りません。「ご連絡が遅くなり申し訳ありません」の一文で十分です
  • 次の連絡の時期を改めて伝える：遅れた分、次の連絡は早めに設定します
  • 遅れた理由を記録する：確認する時間が取れなかったのか、担当が不在だったのか。理由が分かれば、体制を直せます

遅れが続くなら、体制の見直しが必要です。確認の時間を増やす、担当の代わりを増やす、一次対応を外に出す、のいずれかを検討します。

エージェントベストの見解

応募直後の連絡の型を作るとき、当社が先に確かめることを勧めているのが、「次に起きること」を会社として決めているかどうかです。型の三番目に「次は書類選考です」と書くには、書類選考を誰が何日で行うかが決まっていなければなりません。ここが決まっていない会社は、一次返信の文面が曖昧になり、「追ってご連絡します」としか書けません。それでは、候補者はいつまで待てばよいのか分かりません。型を作る作業は、そのまま選考の流れを決める作業でもあります。一次返信の文面で詰まったら、文面ではなく、次の工程の担当と日数を先に決めてください。

まとめ

  • 応募直後の連絡は、判断を待たずに受け取った当日に返す
  • 伝えるのは、受け取ったこと・次に起きること・次の連絡の時期の三つ
  • 確認する時間と返す人を決め、判断と返信を分ける
  • 応募経路によって、お礼の書き方と次の段階の伝え方を変える
  • 遅れたら一言わびて、次の時期を伝え、理由を記録して体制を直す

よくある質問

媒体の自動返信があれば、会社からの連絡は要りませんか

自動返信は、応募が届いたことしか伝えられません。次の流れと連絡の時期は、会社から伝える必要があります。短くても一通送ると、候補者の待ち方が変わります。

応募が多く、当日に全員へ返せません

まず型を整え、個別の一文を短くして、送る手間を減らします。それでも追いつかないなら、確認の時間を増やすか、一次対応を外に出すことを検討します。分担の考え方は採用チームの役割分担を参考にしてください。

要件に明らかに合わない応募にも、同じ連絡をしますか

一次返信は同じ型で構いません。そのうえで、書類選考の結果として不合格を伝えます。結果の伝え方は書類選考の結果連絡にまとめています。
