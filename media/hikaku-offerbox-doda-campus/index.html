OfferBoxとdodaキャンパスの違い｜自社で小さく試して比べる手順

「OfferBoxとdodaキャンパスの資料を並べたが、どちらも同じように見える」という声を、新卒採用の担当者からよく聞きます。結論から言うと、この2つは型が同じなので、資料を並べても決め手は出ません。決め手は、自社の学生像と文面で小さく試したときに、どちらの運用が社内で続くかです。 OfferBoxは株式会社i-plug、dodaキャンパスは株式会社ベネッセi-キャリアが運営する、どちらも新卒向けのオファー型（逆求人型）サービスです。この記事ではdodaキャンパスの仕様や料金には触れず、資料で分かることと分からないことを分けたうえで、自社で比べる手順を整理します。

型が同じ媒体は、資料の比較で差が出にくい

ナビ型とオファー型のように動き方が違う媒体なら、動き方の違いで比べられます。OfferBoxとリクナビの違いで書いたとおりです。OfferBoxとdodaキャンパスは、どちらも「学生がプロフィールを登録して待ち、企業が検索して送る」型なので、動き方では比べられません。

資料を並べると、登録している学生の層、プロフィールの項目、オファーの仕組み、料金の型といった項目が出てきます。これらは各社の公式サイトや料金表で確認できるもので、変わるものでもあるので、この記事には書きません。ここで押さえたいのは、資料で分かることと分からないことの線です。

資料で分かること資料では分からないこと
型（オファー型かどうか）自社の文面に、その媒体の学生がどう反応するか
料金の型（定額か、採用時に費用が出るか）自社の学生像と、その媒体の登録者の重なり
プロフィールの項目社内の担当が、その媒体の管理画面で毎週送り続けられるか
送れる数の決まり方面談に来た学生と、社内の期待が合うか

右の列は、自社で動かしてみないと分かりません。だからこそ、型が同じ2つの媒体は「資料で選ぶ」より「試して選ぶ」ほうが、契約後の後悔が少なくなります。

自社で小さく試して比べる手順

試すといっても、両方を本契約して比べる必要はありません。営業担当に相談すれば、デモ画面や試用の形で管理画面を触れる場合があります。その範囲で、次の順番で見ます。

  1. 学生像を1つに固定する：卒年・志望業界・志向を決め、両方の媒体で同じ条件で検索する
  2. 文面の型を1つに固定する：共通の原稿を用意し、媒体ごとにプロフィールから拾う一文だけを変える
  3. 送る人を同じにする：担当が違うと、文面の質と返信の速さが変わり、媒体の差が見えなくなる
  4. 見る指標は「承認→面談→選考」の流れ：承認の数だけでなく、面談に来た学生が社内の期待と合っていたかを見る
  5. 数字は媒体間で比べず、自社内の前後で比べる：媒体ごとに分母の作り方が違うので、承認率のような数字を横に並べても意味が薄い
  6. 担当の感触を記録する：管理画面の使いやすさ、検索のしやすさ、送るまでの手数。これは毎週続くかどうかに直結する

このうち、いちばん見落とされるのが6番です。媒体の性能が同じなら、最後に効くのは「担当が毎週触りたくなるか」です。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。試す前に、社内の体制から整理します。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは2つあります。1つは「オファー型はどれも同じだから、登録者数の多いほうを選べばよい」。もう1つは「営業担当の説明が良かったほうを選べばよい」。実際には、登録者数は媒体全体の総数であって、自社の学生像に合う層がどれだけいるかは別の話です。営業担当の説明も、契約後に毎週管理画面を触るのは社内の担当なので、説明の良し悪しと運用の続きやすさは別です。当社は求人広告代理店として、OfferBoxの契約後の運用まで見ていますが、契約後に止まる会社の多くは、この2つの理由で選んだ会社です。「自社の学生像で検索して、採りたい学生が出てくるか」と「担当が毎週触れる画面か」の2点だけを、申込前に自分の目で確かめることを勧めます。

この条件なら、先に検討する形

優劣ではなく、先に検討する順番として置きます。

  • まだオファー型を使ったことがない → 1つから始める。当社が窓口になれるOfferBoxからご案内できる
  • すでに片方を使っていて、送る時間が余っている → もう片方を小さく試す。上の手順で比べる
  • すでに片方を使っていて、送る時間が足りていない → 足す前に、いまの媒体で送る数と文面を見直す
  • 採りたい学生像が2つあり、片方の媒体では検索で出てきにくい → もう片方を試す価値がある
  • 担当がいまの管理画面を触るのを負担に感じている → 媒体を変える理由になる。ただし文面や条件の問題でないか先に確認する

自社に合う媒体がどれか、取り扱い媒体を並べてご案内します。申込前提ではありません。

媒体選びを相談する

併用するときの分担

試した結果、両方を使うことになった場合の分担です。

  1. 学生像で分ける：検索で出てきやすい層を、媒体ごとに決める。同じ層を両方から追わない
  2. 時期で分ける：早期の接点はこちら、解禁後の補充はあちら、というように送る山をずらす
  3. 文面は共通部分と媒体ごとの部分に分ける：1つの原稿から流し、プロフィールから拾う一文だけを書き分ける
  4. 管理表を1つにする：誰に、どの媒体から、いつ送り、どうなったかを一覧で持つ。重なりに気づくため
  5. 選考フローは1本にする：入口が違うだけで、面談以降は同じ流れに乗せる

分担の考え方はOfferBoxとキミスカの違いでも書いています。オファー型を2つ使うときの注意は共通です。

エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。それは「1つ目の媒体で、運用が毎週回っている状態を作る」ことです。1つ目が回っていない段階で2つ目を試しても、比べる基準がありません。文面の質も、送る習慣も、面談の進め方も定まっていないので、どちらの媒体でも同じように止まり、「どちらも効かない」という結論になります。当社が契約後の運用まで見ている立場から言うと、OfferBoxで毎週送る型ができてから2つ目を試した会社は、比較の結果がはっきり出ます。逆の順番で始めた会社は、比較にならないまま両方をやめることが多い。先に1つで型を作る、その次に試す。この順番だけは崩さないことを勧めます。

まとめ

  • OfferBoxとdodaキャンパスは、どちらもオファー型。資料を並べても決め手は出にくい
  • 資料で分かるのは型・料金の型・項目まで。自社の文面への反応と、社内で続くかは試さないと分からない
  • 試すときは、学生像・文面の型・送る人を固定し、承認から選考までの流れと、担当の感触を見る
  • 数字は媒体間で比べず、自社内の前後で比べる
  • 1つ目の運用が毎週回ってから2つ目を試す。この順番を崩すと、比較にならない

よくある質問

両方を本契約して比べたほうが正確ですか

正確にはなりますが、送る人の時間が2つに分かれるので、どちらも中途半端になりやすいです。まず営業担当に相談して、デモ画面や試用の形で管理画面を触れるかを確認し、その範囲で学生像の検索と担当の感触を見るほうが、費用も時間も少なく済みます。

承認率で比べてはいけないのですか

分母の作り方が媒体ごとに違うので、横に並べても意味が薄いです。同じ媒体の中で、文面や条件を変えた前後で比べるのには使えます。媒体を比べるなら、面談に来た学生が社内の期待と合っていたか、という質の話を先に見ることを勧めます。

dodaキャンパスの申込も御社経由でできますか

当社は求人広告代理店として、OfferBox・Wantedly・ワンキャリアのほかにも複数の媒体の窓口になっています。dodaキャンパスの申込は各社の窓口になりますが、オファー型を試して比べる手順や、併用するときの分担は、OfferBoxの運用を見ている立場からご相談いただけます。3媒体の全体像は3媒体の違いと選び方にまとめています。
