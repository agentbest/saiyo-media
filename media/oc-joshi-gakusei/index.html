ワンキャリアで女子学生のエントリーが少ないとき｜「女性向けの発信」より先に、働き方の事実と登場する社員とクチコミを見直す

ワンキャリアからのエントリーを見て、女子学生が少ないと感じる。この相談には、「女性向けの特集を作る」「女性社員の写真を増やす」という打ち手がすぐに出てきます。ところが、学生が企業を選ぶときに見ているのは、性別に向けた言葉より、その会社で自分がどう働くかが具体的に分かるかどうかです。結論から言うと、女子学生のエントリーが少ないときは、女性向けの発信を足す前に、企業ページの働き方の情報が「制度の名前」ではなく「使われ方」で書かれているか、登場する社員が実際の職場の姿に合っているか、クチコミや選考体験談に何が書かれているかを順に確かめます。 見直すのは、どの学生にとっても判断しやすい情報です。この記事では、少なさの確かめ方、原因の切り分け、打ち手、やってはいけないこと、外に頼める範囲を整理します。

症状の確認｜「少ない」をどこで見ているか

まず、何と比べて、どの段で少ないのかを確かめます。

  • 何と比べているか：前年の同じ時期か、自社の他の経路か、社内の感覚か
  • どの段で少ないか：企業ページを見た段か、エントリーの段か、選考の途中か
  • 職種で違うか：特定の職種だけで少ないのか、全体か

エントリーの段で少ないなら、企業ページとクチコミの見え方が中心です。選考の途中で減るなら、面接での扱われ方を疑います。段の見方はワンキャリアの掲載のKPI設計で書きました。

原因の切り分け｜この順番で見る

  1. 働き方の情報が、事実で書かれているか：勤務時間、異動・転勤の有無と頻度の考え方、休暇や両立の制度が実際にどう使われているか
  2. 登場する社員が、実際の職場の姿に合っているか：同じ年代、同じ立場の社員ばかりになっていないか
  3. クチコミや選考体験談に、何が書かれているか：面接での質問や扱われ方、社内の雰囲気についての記述
  4. 仕事の説明の言葉が、具体的か：精神論や抽象語が中心だと、働く姿を想像できない
  5. スカウトの対象と文面：対象の絞り方に偏りが入り込んでいないか

1から3は、学生がエントリーの前に読むものです。ここに判断の材料が無いと、性別を問わず、働き方を具体的に知りたい学生が先に離れます。学生が読む順番はワンキャリアの学生が掲載を見る順番で書きました。

いま使っている媒体の運用の相談だけでも構いません。企業ページの働き方の情報を、学生の目線で一緒に読み直します。

運用の相談をする

エージェントベストの見解

相談で多い思い込みは、「女子学生を増やすには、女性向けの特集や言葉を足せばよい」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの掲載を見ていますが、エントリーの偏りの相談で企業ページを読むと、足りないのは女性向けの言葉ではなく、働き方の事実であることが多いです。制度の名前は並んでいるのに、実際に誰がどう使っているかが書かれていない。異動や転勤について触れていない。こうしたページは、性別を問わず、入社後の暮らしを具体的に考えたい学生には判断の材料が足りません。当社が最初にお願いするのは、特集を作る前に、働き方の欄を「制度の名前」から「使われ方」に書き直すことです。

打ち手1｜働き方を、制度の名前ではなく使われ方で書く

書きがちなこと書き直す方向
「両立支援の制度があります」制度を使っている社員がいる部署や職種、使い方の例
「働きやすい職場です」一日の流れ、繁忙期の過ごし方
「転勤の可能性があります」転勤の有無の決まり方、本人の希望の聞き方
「風通しが良い」相談の窓口、上司との面談の頻度の考え方

数値を書く場合は、自社で確かめた事実に限ります。確かめられないものは、場面の説明にとどめます。条件の書き方はワンキャリアの掲載に条件をどこまで書くかで書きました。

打ち手2｜登場する社員を、実際の職場に合わせて選ぶ

学生は、企業ページやイベントに登場する社員から「自分が入ったらこうなる」を想像します。

  • 見せるために選ばず、実際にいる人を選ぶ：写真のためだけに特定の社員を並べると、面接や入社後に違いが出る
  • キャリアの段階を広く：入社してまもない社員だけでなく、数年目、管理職、復職した社員など、実際にいる人の幅を見せる
  • 仕事の中身で語ってもらう：属性ではなく、担当している仕事と、そこで詰まった場面を
  • イベントや座談会に出る社員も同じ考え方で：ワンキャリアの座談会の企画の立て方

打ち手3｜クチコミや選考体験談に書かれていることを確かめる

エントリーの前に、学生はクチコミや体験談を読んでいます。読み方はワンキャリアの自社クチコミの読み方で書きました。

  • 面接での質問に、選考に関係のないものが書かれていないか：私生活や将来の家族の予定を聞いたという記述があれば、今年の面接で直す
  • 社内の雰囲気についての記述：事実なら直し、誤解なら企業ページで事実を先に書く
  • 面接官にクチコミを読んでもらう：ワンキャリアのクチコミを面接官教育に使う方法

やってはいけないこと

  • 性別を条件にスカウトの対象を絞る、性別で文面を変える：募集や採用で性別による差を設けることは、法令の考え方にも反するおそれがある
  • 「女性が活躍」の言葉だけを足す：中身の事実が無いと、学生は言葉だけと読む
  • 写真だけを差し替える：面接や入社後に、ページとの違いが出る
  • 職種に性別の印象を結びつける表現：「細やかさが求められる」などを、特定の性別に向けて書かない

働き方の欄と登場する社員の見直しを、掲載の改善と合わせてご案内します。相談だけでも構いません。

エージェントベストの見解

これは順番の話です。当社がこの相談を受けたとき、掲載の見直しより先に、選考体験談とクチコミを読みます。面接で選考に関係のない質問をしたという記述があれば、企業ページをどれだけ書き直しても、読んだ学生はエントリーを見送ります。逆に、面接での扱われ方に問題が無く、企業ページの働き方の欄が薄いだけなら、欄を書き直すことで判断の材料が増えます。当社が勧める順番は、クチコミと体験談を読む、面接で直すことがあれば今年の選考で直す、働き方の欄を使われ方で書き直す、登場する社員の幅を実際の職場に合わせる、です。最初の二つは、掲載の費用をかけずに始められます。

まとめ

  • 女子学生のエントリーが少ないときは、何と比べて、どの段で少ないかを先に確かめる
  • 原因は、働き方の事実、登場する社員、クチコミと体験談、仕事の説明の言葉、スカウトの対象の順に見る
  • 働き方は制度の名前ではなく使われ方で書く。どの学生にとっても判断しやすい情報にする
  • 登場する社員は見せるためではなく、実際の職場の幅に合わせて選ぶ
  • 性別で対象を絞らない、性別で文面を変えない。言葉や写真だけを足さない

よくある質問

女性社員が少ない職場です。何を書けばよいですか

人数を飾る必要はありません。いまの職場の事実と、働き方の使われ方、相談の窓口を書きます。少ないことを隠すより、実際の姿と、会社が取り組んでいることを事実で書くほうが、入社後の違いが出にくくなります。

女性向けのイベントを開くのはどうですか

イベントの中身が、働き方の事実や仕事の実際を伝えるものであれば、検討の余地があります。ただし、参加の条件や扱いで性別による差を設けることには法令上の論点があるため、企画の段階で社内の労務・法務と確認してください。

エントリーの偏りの見直しは、御社に相談できますか

できます。当社は、企業ページの働き方の欄の読み直し、クチコミの記述の整理、登場する社員の選び方、表現の点検を支えられます。働き方の事実の確認、面接の改善、制度の見直しは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
