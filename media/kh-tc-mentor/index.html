メンター制度の作り方｜誰が何をするか

採用ノウハウ入社後の定着 更新日 2026/11/4

入社した人には、仕事を教える上司のほかに、気軽に相談できる相手が要ります。その相手を制度として決めておくのがメンター制度です。ところが、名前だけ決めて中身を決めていないと、メンターは何をすればよいか分からず、数週間で自然に消えていきます。結論から言うと、メンター制度は「誰が、何を、いつまで」を先に決め、上司の役割と重ならないように分けておくことが基本です。 この記事では、メンターの役割、選び方、上司・人事との分担、始め方の手順を整理します。

メンターの役割は「相談を受ける」こと

メンターの役割は、仕事を教えることではありません。仕事を教えるのは上司や配属先の先輩です。メンターが担うのは、次のようなことです。

  • 聞きにくいことの相談：上司には聞きにくい小さな疑問。社内の慣習、会議での振る舞い、誰に何を頼めばよいか
  • 仕事以外の困りごと：通勤、昼食、休みの取り方、社内の人間関係
  • 気持ちの受け止め：慣れない環境での疲れや不安を話せる相手になること
  • 必要なときのつなぎ：本人が抱えている問題を、本人の了解を得て上司や人事につなぐこと

上司と役割が重なると、本人はどちらに相談すればよいか迷います。メンターは評価に関わらない立場に置くと、本人は安心して話せます。

メンターの選び方

メンターは、次の条件で選びます。

  1. 直属の上司ではない：評価に関わる人には、本人は本音を話しにくい
  2. 年次が近すぎず遠すぎない：入社した人と立場の感覚が近い人。新卒なら数年上の先輩、中途なら同じ職種の経験者が合いやすいです
  3. 話を聞く時間がある：繁忙期にまったく時間が取れない人は避けます
  4. 本人がやってみたいと思っている：頼まれて仕方なく引き受けた人は、続きにくい

4つ目が見落とされがちです。メンターを任されることを負担と感じる人もいます。事前に役割と期間を説明し、引き受けるかどうかを本人に選んでもらいます。

内定の期間からメンターを付ける考え方は内定者にメンターを付ける方法で扱っています。内定期間のメンターと入社後のメンターを同じ人にすると、本人にとって知っている人が続けて相談相手になります。

採用から入社後の受け入れまで、社内で誰が何を持つか。分担の整理から一緒に考えます。

無料で相談する

エージェントベストの見解

メンター制度を始めた会社から聞く失敗で多いのが、「メンターが上司の代わりに仕事を教えるようになった」というものです。上司が忙しいと、近くにいるメンターに仕事の質問が集まります。メンターも頼られると応えたくなり、気づけば教える役になっている。そうなると、本人が聞きにくいことを相談する相手がいなくなります。勧めているのは、メンターを決めるときに「教えないこと」を書いておくことです。仕事の手順、評価に関わる助言、配属や異動の話。これらは上司か人事に回すと決めておくと、メンターは相談の受け手に集中できます。もう一つは、メンターを別部署から選ぶことです。同じ部署だとどうしても仕事の話が中心になります。部署が違うと、仕事以外の話もしやすくなります。

上司・人事との分担

メンター制度は、上司と人事との分担を決めておくと回ります。

役割担う人やること
仕事を教える上司・配属先の先輩仕事の説明、確認、評価
相談を受けるメンター聞きにくいこと、仕事以外の困りごと
全体を見る人事、または採用の担当者メンターの選定、期間の管理、困りごとの受け皿

メンターが本人から聞いた話は、原則として本人の了解なく上司に伝えません。この約束がないと、本人はメンターにも本音を話さなくなります。ただし、本人の健康や安全に関わることなど、放っておけない話もあります。そうした場合にどうするかは、事前に人事と決めておきます。

人事は、メンター自身の相談相手にもなります。メンターも、相談を受けて困ることがあります。メンターが一人で抱え込まないように、人事に話せる場を作っておきます。

始め方の手順

メンター制度は、次の手順で始めます。

  1. 目的を決める：何のための制度か。入社後の不安を減らす、相談の受け皿を作る、など一行で書きます
  2. 役割と「教えないこと」を書く：メンターがやること、やらないことを一枚にまとめます
  3. 期間を決める：いつまで続けるか。入社後3か月、半年など、区切りを決めます
  4. 会う頻度を決める：最初は短い間隔で、慣れてきたら間隔を空けます。具体的な頻度は会社ごとに決めて構いません
  5. メンターを選び、説明する：役割と期間を説明し、引き受けてもらえるか確かめます
  6. 区切りで振り返る：期間の終わりに、本人とメンターの両方から感想を聞きます

期間を決めるのは、メンターの負担を見えるようにするためです。終わりのない役割は、引き受ける側にとって重くなります。期間が終わったあとも関係が続くのは構いませんが、制度としては区切ります。

受け入れの体制まで考えて、新卒と中途の採用の比重を決めたい。そういう相談も受けています。

運用の相談をする

エージェントベストの見解

社員が少ない会社から「メンターを付けられる人がいない」と相談を受けることがあります。この場合、制度を形どおりに作るより、「上司以外で話せる人を一人決める」ことから始めることを勧めます。別部署の人でも、経営者でも、場合によっては社外の人でも構いません。大事なのは、評価する人とは別の相談先があることです。当社は紹介で採る支援もしているので、入社後しばらくして候補者から相談の連絡が来ることがあります。話を聞くと、社内に相談できる人がいれば解決したような小さな困りごとが多いです。社内に相談先がないと、本人は外に答えを探しにいきます。小さな会社ほど、一人の相談先を決めておく効き目は大きいです。

やりがちな失敗と規模による差

よくある失敗を挙げます。

  • 名前だけ決めて放っておく：最初の面談の日程すら決めず、自然に消える
  • 相性を見ない：年次や部署だけで機械的に決め、話が合わない
  • メンターの業務を減らさない：本来の仕事を減らさずに役割を足し、忙しくて会えなくなる

規模によって、制度の形も変わります。

  • 新卒を毎年まとめて採る会社：メンターを毎年同じ人に頼まないように、順番を決めておきます
  • 中途を一人ずつ採る会社：入社のたびに選ぶので、引き受けてくれそうな人をあらかじめ何人か決めておきます
  • 社員が少ない会社：制度にせず、相談先を一人決めるだけで十分なこともあります

入社後の受け入れ全体の組み方はオンボーディングの設計にまとめています。

まとめ

  • メンターの役割は仕事を教えることではなく、相談を受けること
  • 直属でなく、時間があり、引き受けたいと思っている人を選ぶ
  • 「教えないこと」を書き、上司との役割の重なりを防ぐ
  • 期間と会う頻度を先に決め、メンターの負担を見えるようにする
  • 小さな会社では、上司以外の相談先を一人決めることから始める

よくある質問

メンターは同じ部署の人がよいですか、別部署の人がよいですか

相談の受け手として置くなら、別部署の人のほうが仕事以外の話をしやすい傾向があります。ただし、同じ職種の悩みを話せる相手が欲しい場合は、同じ部署の先輩が合うこともあります。目的に合わせて選びます。

メンターと本人の相性が合わなかったらどうしますか

途中で変えられることを、最初から本人とメンターの両方に伝えておきます。変えることを失敗と扱わないようにします。人事が区切りごとに様子を聞き、合っていなければ別の人に替えます。

メンターにも研修が要りますか

大がかりな研修は要りませんが、役割と「教えないこと」、聞いた話の扱いだけは事前に説明します。初めてメンターを担う人には、話の聞き方を短く伝えておくと進めやすくなります。日ごろの対話の進め方は入社後の1on1も参考になります。
