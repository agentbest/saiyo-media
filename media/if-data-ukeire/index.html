データ分析の長期インターン生の最初の1か月｜任せる仕事と育て方

データ分析の長期インターン生を受け入れると、最初の数日で「どのデータから見せればよいか」に迷う会社が少なくありません。分析の手法を学んできた学生ほど、早く手を動かしたがります。結論から言うと、最初の1か月は「データの意味を覚える」「決まった集計を回す」「小さな問いを調べて報告する」の三段で任せる範囲を広げ、毎回の報告を育成の場にすると、学生が事業の判断に使える分析をできるようになります。 この記事では、Infraで採用したデータ分析の長期インターン生を受け入れる会社に向けて、週ごとの任せ方と育て方を整理します。

最初の1か月で目指す状態を決める

受け入れの前に、1か月後に学生がどうなっていればよいかを一文で決めます。たとえば「事業の担当者から受けた小さな問いを、自分でデータを選んで調べ、結論から報告できる」といった形です。

データ分析の職種で目指す状態を決めるときは、次の三つを確かめます。

  • データの意味：どの表にどんな情報があり、それぞれの項目が事業の何を表しているかが分かるか
  • 問いの受け取り方：依頼された問いが、何を決めるためのものかを確かめられるか
  • 報告の形：結論、根拠、確かめきれていない点を分けて伝えられるか

学生が授業で身につけてきたのは、主に手法です。実務で最初につまずくのは、手法よりも、データの意味と問いの受け取り方です。目指す状態にこの二つを入れておくと、最初の1か月の重心が定まります。

学生に触らせるデータの範囲を事前にどう決めるかはデータ分析の長期インターンを採るで整理しています。この記事では、範囲が決まったあとの1か月の進め方に絞ります。

週ごとの任せ方

最初の1か月は、次のような段階で組むと無理がありません。週の区切りは設計上の例で、学生の稼働日数に合わせて調整します。

  1. 一週目：データの意味を覚える：初日から渡せる範囲のデータを見て、表と項目の一覧を作ってもらう。分からない項目は質問のリストにまとめる
  2. 二週目：決まった集計を回す：毎週の数字の集計など、手順が決まっている作業を、手順書に沿って担当する。前の週の数字と比べて変化を書き添える
  3. 三週目：集計の変化を説明する：数字が動いた理由の候補を挙げ、データで確かめられるものを調べる
  4. 四週目：小さな問いを調べて報告する：事業の担当者から一つ問いを受け、データを選んで調べ、報告までを一人で進める

一週目の「表と項目の一覧を作ってもらう」は、データの説明書がない会社ほど効きます。学生が作った一覧を社員が確かめて直すと、それが次に入る人の資料になり、社員にとっても、項目の意味を改めて整理する機会になります。

データ分析の長期インターン生に、最初の1か月で何を任せるか。週ごとの組み方から一緒に考えます。

無料で相談する

データの渡し方と、扱いの決まり

データ分析の受け入れでは、データを渡す段階を、作業の段階と合わせておきます。

時期渡す範囲の例
初日個人が特定できない集計済みのデータ、社内の公開資料
二週目から決まった集計に使う表。手順書とあわせて
慣れてから個人情報を除いた明細、匿名化したログ

あわせて、扱いの決まりを最初の週に伝えます。データを手元の端末に保存してよいか、社外の道具に貼り付けてよいか、結果をどこに置くか。学生は授業の感覚で、便利な道具にデータを入れてしまうことがあります。悪気がないぶん、決まりを最初に言葉にして渡すことが大切です。情報の管理の考え方は長期インターン生の情報管理でもまとめています。扱う情報の範囲は、雇用契約や誓約書の中で確認しておきます。

エージェントベストの見解

データ分析の長期インターンで、最初の1か月のうちに学生の手が止まる会社に共通するのは、「問いを渡さずにデータだけを渡す」ことです。「このデータで何か面白いことが分かったら教えて」という頼み方は、自由に見えて、学生にとっては最も難しい依頼です。何を決めるための分析かが分からないと、学生は手法を試すことに時間を使い、結果は出ても事業の判断に使えません。当社が勧めるのは、四週目に渡す問いを、受け入れの前に事業の担当者と一緒に一つ決めておくことです。「先月の申し込みが減ったのは、どの経路からの利用者が減ったからか」のように、答えが出れば次の行動が決まる問いを選びます。最初の問いが具体的であるほど、学生は分析の目的を体で覚え、二つ目からは自分で問いを確かめられるようになります。

報告の型で育てる

データ分析の職種では、研修の時間を別に取るより、毎回の報告で育てるほうが続きます。報告のたびに同じ型を使ってもらうと、学生は考え方の順番を身につけます。

  1. 結論：問いへの答えを一文で
  2. 根拠：結論を支える数字や図を、少ない数だけ
  3. 確かめきれていない点：データが足りない、別の見方もある、という点
  4. 次に調べるとよいこと：結論を確かめるため、あるいは次の判断のために

学生は、調べたことを全部見せたくなります。報告を受ける社員は、結論が先に出ているか、根拠が絞られているかを見て返します。三つ目の「確かめきれていない点」を書けるようになると、分析の結果を事業の担当者が安心して使えるようになります。

週に一度、その週の報告を振り返る時間を取ると、個別の指摘が学生自身の考え方に変わります。振り返りの進め方は長期インターン生との1on1も参考になります。

つまずきの見つけ方と戻し方

データ分析の長期インターン生のつまずきは、次のような様子に表れます。

  • 報告が手法の説明から始まる：何を調べたかではなく、どう調べたかを話している
  • 数字の確かめが抜ける：集計の条件が違うのに、別の数字と比べている
  • 質問が減る：データの意味が分からないまま、推測で進めている

一つ目は、報告の型に戻ることで改善することが多いです。二つ目は、集計の条件を報告の中に書いてもらう決まりにすると防げます。三つ目は、一週目に作った項目の一覧に立ち返り、分からない項目を一緒に確かめます。つまずいたときに前の段階に戻すことは、失敗ではなく計画の調整です。

勤務の時間や学業との両立に関わる調整が必要になることもあります。インターン生の労働時間や学業への配慮には法令で定められた項目や指針がありますので、詳しくは社会保険労務士や公式の案内で確認してください。

報告を受ける社員が足りない、受け入れの人数を増やしたい。体制の見直しもご相談いただけます。

運用の相談をする

社内の分担

データ分析の受け入れでは、次のように役割を分けます。

  • 報告を受ける人：事業の担当者。問いを渡し、報告を受け、目的の観点で返す
  • 分析を教える人：社内で分析を担う社員がいれば、手法や集計の確かめ方を見る。いなければ、報告を受ける人が兼ねる
  • データの管理者：渡す範囲の判断と、権限の手続き
  • 人事・総務：契約、勤怠、端末の貸与の手続き

エージェントベストの見解

当社は長期インターンの募集を支援する立場で、データ分析の学生が長く続く会社とそうでない会社の違いを見てきました。違いが出るのは、学生の分析の結果が、実際の判断に使われたことを学生本人に伝えているかどうかです。報告を受けた事業の担当者が、その結果をもとに何かを決めても、そのことが学生に伝わらなければ、学生は自分の分析が役に立ったのか分かりません。勧めたいのは、報告を受けたあと、その結果で何を決めたか、あるいは決めなかったかを、短くてもよいので学生に返すことです。結果が使われなかった場合も、なぜ使わなかったかを伝えれば、学生は次の分析の方向を変えられます。1か月の終わりには、四週目の報告が何に使われたかを一緒に振り返ってください。それが学生にとって、次の1か月の目標になります。

まとめ

  • 最初の1か月は、データの意味を覚える、決まった集計を回す、変化を説明する、小さな問いを報告する、の順に任せる
  • データを渡す段階は作業の段階と合わせ、扱いの決まりを最初の週に言葉で渡す
  • データだけでなく、答えが出れば次の行動が決まる問いを渡す
  • 報告は、結論・根拠・確かめきれていない点・次に調べることの型で育てる
  • 分析の結果が何に使われたかを、学生本人に返す

よくある質問

社内に分析を教えられる社員がいません

報告を受ける事業の担当者が、結論が問いに答えているか、根拠が納得できるかの観点で返す形で始められます。手法の細かな確かめは、学生自身に手順を書いてもらい、その手順が筋の通ったものかを一緒に見ます。

最初の1か月で、学生にモデル作りまで任せてもよいですか

データの意味と報告の型が身についてからのほうが、モデル作りの結果も事業に使いやすくなります。最初の1か月は、集計と小さな問いに絞り、モデル作りは二か月目以降に段階として組むことを勧めます。

決まった集計の作業ばかりで、学生が退屈しないか心配です

集計の作業に「前の週と比べて変化を書き添える」ことを加えると、作業が考える仕事に変わります。変化の理由を調べる段階に進めると、学生は集計の意味を実感できます。学生がすぐ辞めてしまうのを防ぐ考え方は長期インターン生がすぐ辞めるときに見直すことでまとめています。
