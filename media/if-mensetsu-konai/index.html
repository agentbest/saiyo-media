長期インターンの面接に学生が来ないとき

長期インターンの募集に応募は来るのに、面接の日程が決まらない、決まっても当日に学生が来ない。こうした状況は、応募が来ないことと同じくらい担当者を疲れさせます。結論として、面接に来ない問題は、学生の側の気まぐれではなく、応募から面接までの間で「連絡が途切れる」「面倒になる」「不安が残る」のどれかが起きていることが多く、その順に見直すと改善の糸口が見つかります。 この記事では、症状の確認、原因の切り分けの順番、打ち手、外に任せる範囲を整理します。

症状を確認する｜どこで途切れているか

まず、学生との連絡がどの段階で途切れているかを確かめます。

  • 応募後の最初の連絡に返事がない：こちらからの連絡に、学生が反応していない
  • 日程の候補を出したが決まらない：やりとりが続くうちに返信が来なくなる
  • 日程は決まったが当日に来ない：連絡なしで面接に現れない
  • 当日の直前に辞退の連絡が来る：他の会社に決めた、予定が合わなくなった、など

段階によって、原因も打ち手も変わります。担当者の記録を見返し、応募した学生がどの段階で離れているかを数えておくと、見直しの優先順位が決まります。

原因を切り分ける順番

原因は、次の順番で確かめます。

1. 返信の速さ

最初に確かめるのは、応募から最初の連絡までの時間です。長期インターンを探す学生は、複数の会社に同時に応募していることが多く、最初に連絡をくれた会社から面接に進んでいきます。応募から数日経って連絡しても、すでに他の会社の面接が決まっていることがあります。

2. 日程調整の手間

次に、日程を決めるまでのやりとりの回数を確かめます。候補日を一つずつ提示し、合わなければまた別の候補を出す、というやりとりが何往復も続くと、学生の側は面倒になり、返信が途絶えます。

3. 面接前の不安

最後に、面接の前に学生が不安を抱えていないかを確かめます。

  • 面接の場所や形式（対面かオンラインか）が分かりにくい
  • 何を聞かれるのか、何を準備すればいいのかが分からない
  • 面接の時間がどれくらいかかるのか分からない
  • 服装や持ち物の指定が分からない

不安が残っていると、当日に気が重くなり、来ない理由になります。

応募から面接までの連絡の流れを、学生の側から見直してみませんか。返信の文面づくりからご相談いただけます。

無料で相談する

エージェントベストの見解

面接に来ないという相談を受けたとき、当社がまず聞くのは「応募のあと、最初の連絡でいくつの質問をしているか」です。多くの会社は、最初の連絡で希望の日程、勤務できる曜日、学年や学部、志望の理由などをまとめて聞いています。会社の側からすれば効率のよい聞き方ですが、学生の側からすると返信を書くのが重く、後回しにしているうちに他の会社が先に進みます。当社が勧めるのは、最初の連絡でお願いすることを「面接の日程を選ぶ」の一つだけにすることです。勤務できる曜日や志望の理由は、面接の中で聞けば足ります。返信のしやすさを優先すると、最初の段階で途切れる学生が減ります。

打ち手｜段階ごとの見直し

返信の速さを上げる

  1. 応募の通知が届く場所を、複数人が見られるようにする
  2. 毎日決まった時間に応募を確認し、その日のうちに最初の連絡をする
  3. 最初の連絡の定型文を用意し、書く手間を減らす

日程調整の手間を減らす

  1. 面接の枠を先に複数用意し、その中から選んでもらう
  2. 日程調整のツールを使い、学生が自分で枠を選べるようにする
  3. 平日の夕方や授業のない時間帯など、学生が参加しやすい枠を入れる

面接前の不安を減らす

  1. 面接の形式、場所、所要時間、当日の流れを日程確定の連絡に書く
  2. オンラインの場合は、接続先と、つながらないときの連絡先を書く
  3. 前日に短いリマインドの連絡を送る
  4. 面接で何を話すのかを、ざっくりと伝えておく

前日のリマインドは、単純ですが効果のある打ち手です。授業や課題に追われている学生は、面接の日時を忘れてしまうこともあります。

面接そのものを見直す

連絡の流れを見直しても来ない学生がいる場合は、面接の位置づけそのものを考え直すことも一つです。

  • 最初の面接を「面談」にする：選考ではなく、お互いを知る場として案内する
  • 面接の時間を短くする：最初は短い時間で、仕事の説明と質問への回答を中心にする
  • オンラインを選べるようにする：移動の負担がない分、参加のハードルが下がる

長期インターンの面接は、学生にとって初めての「働く場の面接」であることも多く、緊張が大きいものです。最初の接点を軽くするだけで、来る学生が増えることがあります。

外に任せる範囲

面接の日程調整や連絡は、外部に任せることもできます。ただし、任せる範囲は分けておきます。

外部に任せやすいこと

  • 応募への最初の連絡と、日程調整のやりとり
  • リマインドの連絡
  • 連絡の文面や流れの見直し

自社で持つこと

  • 面接そのものと、受け入れるかどうかの判断
  • 面接で伝える仕事の中身と、受け入れの体制の説明

エージェントベストの見解

当社は採用の運用代行も行っており、媒体での応募から面接までの連絡を企業に代わって担うことがあります。その経験から言えるのは、面接に来ない学生の多くは、悪意があるわけではなく、連絡のどこかで「会社の顔が見えなくなった」学生だということです。定型文だけのやりとりが続くと、学生は相手が人であることを忘れ、他の予定を優先しやすくなります。当社が連絡を担うときは、定型文を使いながらも、一行だけその学生の応募内容に触れる文を入れるようにしています。「〇〇の経験について面接で伺えるのを楽しみにしています」という一文があるだけで、学生の側の受け止め方は変わります。自社で連絡する場合も、この一行を省かないことを勧めます。

辞退した学生の声を集める

面接に来なかった学生や、直前に辞退した学生から理由を聞く機会は多くありません。それでも、辞退の連絡があったときに、短く理由を尋ねておくと、見直しの手がかりが得られます。

  • 辞退の連絡への返信で、一言だけ聞く：「今後の参考に、差し支えなければ理由を教えてください」
  • 答えを強制しない：答えたくない学生もいるため、聞くのは一度だけにする
  • 集めた理由を分類する：他社に決めた、予定が合わない、仕事の内容が合わない、など
  • 分類ごとに打ち手を考える：他社に決めたなら返信の速さ、予定が合わないなら日程の枠、内容が合わないなら募集の書き方

数が少なくても、同じ理由が繰り返し出てくるなら、それが見直すべき点です。辞退した学生への対応を丁寧にしておくと、その学生が別の時期に再び応募してくることもあります。

辞退の理由から、応募から面接までの流れのどこを直すかを一緒に考えます。

運用の相談をする

まとめ

  • 面接に来ない問題は、応募から面接までのどこで連絡が途切れているかを先に確かめる
  • 原因は「返信の速さ」「日程調整の手間」「面接前の不安」の順に切り分ける
  • 最初の連絡でお願いすることは、面接の日程を選ぶことだけに絞る
  • 面接の枠を先に用意し、前日のリマインドを送る
  • 定型文の中にも、その学生の応募内容に触れる一文を入れる

よくある質問

連絡なしで来なかった学生に、もう一度連絡すべきですか

一度だけ、体調や予定の変化を気遣う形で連絡するのは自然です。日程を改めて選べる案内を添えると、再び面接に進むこともあります。返事がない場合は、それ以上追いかけず、次の応募に時間を使うほうがよいでしょう。

面接をオンラインにすると、受け入れ後に合わないことが増えませんか

オンラインでも、仕事の中身と働き方を具体的に説明し、学生の質問に丁寧に答えれば、ずれは減らせます。可能であれば、受け入れを決める前に一度、職場を見に来てもらう機会を作ると安心です。

応募そのものが少なく、面接の数が足りません

面接の前の段階、つまり応募が来ない原因を見直す必要があります。見直しの順番はInfraで応募が来ないときの見直し順で整理しています。
