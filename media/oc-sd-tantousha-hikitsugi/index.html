ワンキャリアの運用を引き継ぐときの資料｜束ねる5点と渡し方

異動や退職が決まり、ワンキャリアの運用を後任に渡すことになった。管理画面の権限は渡せても、何を資料として残せばよいか分からない。ファイルは散らばり、大事なことは自分の頭の中にある。結論から言うと、引き継ぎの資料は、進行中の学生の台帳、企業ページに書いた約束、体験談を読んだ記録、面接に出る人との合意、なぜこの形にしているかのメモ、の5点を一つに束ねることが要点です。 後任が最初の一週間で迷うのは、作業の手順より「なぜこうしているか」と「誰に何を約束しているか」です。この記事では、資料の目的、作る手順、束ねる5点の中身、やりがちな失敗、渡し方と分担を整理します。

引き継ぎ全体の順番と年度の切れ目の考え方はワンキャリアの掲載運用の引き継ぎに、引き継ぎがないまま交代した場合はワンキャリアの担当者が交代したときの立て直しにまとめています。この記事は、渡す資料そのものの作り方に絞ります。

この作業の目的｜後任が一人で一週目を回せるようにする

資料の目的は、後任が前任に聞かなくても、最初の一週間の運用を回せることです。ワンキャリアの運用では、止まると困るものが三つあります。

  • 返信待ちの学生への対応：スカウトを受けた学生やエントリーした学生への連絡
  • 企業ページに書いた約束：選考の流れ、連絡の目安など
  • 面接に出る人との合意：各段階で何を見るか

この三つは、管理画面を見ただけでは分かりにくいものです。資料は、この三つが後任に途切れずに渡るように作ります。

資料を作る手順

  1. 置き場を一つに決める：共有フォルダの一か所に、引き継ぎ用のフォルダを作ります。散らばったファイルはここに集めます
  2. 最初に読む一枚を作る：資料の目次と、最初の一週間にやることを一枚にまとめます
  3. 束ねる5点をそろえる：下の表の5点を、それぞれ一つのファイルにします
  4. 日付を入れる：各ファイルに「いつ時点の情報か」を書きます
  5. 後任に一度読んでもらい、分からない点を聞く：前任がいるうちに、質問を受ける時間を一度取ります
  6. 権限と連絡先を最後に渡す：管理画面の権限、代理店や社内の連絡先をまとめて渡します

日々の運用の資料をふだんから整えておくと、引き継ぎの資料はそれを束ねるだけで済みます。日々の資料の作り方はワンキャリアの運用資料の作り方にまとめています。

引き継ぎの資料を何から作るか、置き場と最初の一枚の整理から相談できます。

運用の相談をする

束ねる5点の中身

資料中身後任が使う場面
1. 進行中の学生の台帳学生ごとの段階、最後の連絡日、次にすること最初の日に返信待ちを拾う
2. 企業ページの約束選考の流れ、連絡の目安、各段階で見ること約束を守る。年度の途中で変えない
3. 体験談を読んだ記録読んだ範囲、気になった点、企業ページで補った点次に体験談を読むときの起点
4. 面接に出る人との合意誰が、どの段階で、何を見るか。合意した日面接に出る人に交代を伝えるとき
5. なぜこの形かのメモスカウトの型や企業ページの書き方を、なぜそうしたか後任が変えたくなったときの判断材料

5つ目のメモは、最も書かれにくく、最も役に立つ資料です。「この文面にしているのは、受諾のあとの面談で何を話すかと揃えるため」のように、一つの判断に一行で理由を書きます。

エージェントベストの見解

これは契約後に起きることの話です。当社は求人広告代理店として、ワンキャリアの運用の引き継ぎに関わることがあります。うまくいかない引き継ぎに共通するのは、資料が「作業の手順書」だけになっていることです。手順は管理画面を触れば分かるようになります。分からないのは、なぜその手順にしたか、誰に何を約束しているかです。手順書だけを受け取った後任は、自分のやり方に変えたくなり、年度の途中で企業ページやスカウトの型を変えてしまいます。そこで勧めているのが、「なぜこの形かのメモ」を5点のうち一つとして独立させることです。理由が書いてあれば、後任は変える前に一度立ち止まれます。手順書を厚くするより、理由のメモを一枚足すほうが、引き継ぎの質は上がります。

やりがちな失敗

  • ファイルの場所だけを伝える：散らばったファイルの一覧を渡し、どれを先に読むかが分からない
  • 情報の日付がない：いつ時点の台帳か分からず、後任が古い情報で動く
  • 手順だけを書く：なぜそうしているかが抜け、後任が変えてしまう
  • 面接に出る人との合意を書かない：口頭で決めたことが残らず、面接がずれる
  • 最後の日にまとめて渡す：後任が読んで質問する時間がない

引き継ぎの資料は、渡す日の少なくとも一週間前に後任に見せられる状態にしておくと、質問を受ける時間が取れます。

もう一つ見落とされやすいのが、体験談を読んだ記録です。前任がどの体験談を読み、何を気にして企業ページを直したかが残っていないと、後任は同じ体験談を最初から読み直すことになります。読んだ範囲と、そこから企業ページで補った点を一行ずつ残しておくだけで、後任は続きから読めます。体験談は増えていくものなので、どこまで読んだかの印が、後任の時間を大きく減らします。

渡し方と分担

資料を渡すときは、次の順で進めます。

  1. 最初に読む一枚を一緒に読む
  2. 進行中の学生の台帳を、一人ずつ確かめる
  3. 企業ページの約束と、面接に出る人との合意を一緒に読む
  4. 後任から面接に出る人へ、交代と合意の内容を伝えてもらう
  5. 代理店がいれば、新しい連絡先を伝える
作業誰が
資料の作成と置き場の整理前任
資料を読み、質問をまとめる後任
面接に出る人への交代の連絡後任（前任が同席できれば同席）
権限の移し替え前任と上司
代理店への連絡前任または上司

エージェントベストの見解

これは切り分けの話です。引き継ぎの資料のうち、外部に手伝ってもらえるのは、台帳の形を整えること、スカウトの型や企業ページの版を整理すること、代理店側に残っている申込時の情報や契約の状況を渡すことまでです。一方、企業ページの約束を守る判断や、面接に出る人との合意は、社内でしか引き継げません。とくに面接に出る人との合意は、外部が代わりに伝えると、面接に出る人が「人事が替わったのに、人事から何も聞いていない」と受け取ります。後任が自分の言葉で伝えることが、合意を引き継ぐ一番の方法です。当社が引き継ぎの相談を受けるときも、資料の整理は手伝い、面接に出る人への連絡は後任にお願いする形にしています。

申込時の情報や契約の状況など、代理店側に残っている記録の確認も含めて相談できます。

無料で相談する

まとめ

  • 引き継ぎの資料は、台帳・企業ページの約束・体験談の記録・面接に出る人との合意・理由のメモの5点を束ねる
  • 置き場を一つにし、最初に読む一枚と、各ファイルの日付を入れる
  • 「なぜこの形か」のメモが、後任が年度の途中で変えてしまうのを防ぐ
  • 渡す日の前に後任が読み、質問できる時間を取る
  • 面接に出る人への交代の連絡は、後任が自分の言葉で伝える

よくある質問

引き継ぎまでの時間が短く、5点をそろえられません

最初に台帳と企業ページの約束の二つをそろえます。この二つがあれば、後任は返信待ちの学生に対応し、約束を守れます。残りの三つは、前任に連絡が取れるうちに、短いメモでも残してもらいます。

後任が採用の経験の浅い人です

最初に読む一枚に、ワンキャリアの学生が体験談やクチコミを読んで会社を確かめること、企業ページの約束が体験談に残ることを、短く書いておきます。媒体の性格が分かると、資料の意味が伝わりやすくなります。

引き継ぎのあと、前任に聞いてもよいですか

聞ける関係なら、一度だけまとめて聞く時間を取ると負担が少なくて済みます。聞きたいことを後任がためておき、上司が仲介すると、前任の新しい業務の妨げになりにくくなります。
