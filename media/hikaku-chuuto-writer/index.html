中途採用でライター・編集を採るときの媒体の選び方

媒体比較・選び方中途採用の媒体選び（職種別） 更新日 2026/11/4

オウンドメディアを立ち上げた会社、広報の発信を増やしたい会社、編集プロダクション、Webメディアの運営会社が、中途でライターや編集者を採ろうとしています。ところが「ライター募集」で求人を出すと、取材記事を書く人、検索向けの記事を書く人、広告のコピーを書く人、進行を管理する編集者が同じ箱に入ってきます。結論から言うと、ライター・編集の中途採用では、媒体を選ぶ前に「この募集は書く人か、まとめる人か」を決めておくと、どの媒体を先に検討するかが自然に決まります。 この記事では、媒体の料金や数値には触れず、判断軸の当て方と組み合わせ方を整理します。

ライター・編集の候補者が媒体で見ているもの

ライター・編集の候補者は、求人の条件と同じくらい「どんな文章を、どんな体制で作る会社か」を見ています。職務経歴書の肩書きより、書いてきたものが本人の名刺になる職種だからです。

候補者が求人を読むときに確かめていることは、おおむね次のとおりです。

  • 書く媒体の種類：自社のオウンドメディアか、クライアントの記事か、広告か、紙の媒体か
  • 書く仕事と編集する仕事の比率：自分で書くのか、外部のライターに依頼してまとめるのか
  • 扱うテーマ：専門の領域があるか。未経験の領域を学びながら書けるか
  • 編集の体制：書いた原稿を誰が見るのか。校閲や事実確認の手順があるか
  • 名前が出るか：署名記事として実績にできるか

とくに編集の体制は、経験のある人ほど気にします。原稿を見る人がいない会社では、品質の責任を一人で負うことになるからです。体制が整っていなくても構いません。整っていないなら、そう書き、入社後にどう作っていくかを添えると、読み手の判断材料になります。

判断軸｜対象・型・課金・運用工数

媒体を比べるときは、次の四つの軸で見ます。どの媒体が優れているかではなく、自社の募集にどの軸が効くかを確かめます。

軸ライター・編集の募集での見方
対象経験者を狙うのか、他職種から書く仕事に移りたい人も含めるのか
型求人を出して待つ掲載型か、会社から声をかけるスカウト型か、会社の考え方に共感した人が来る共感型か、紹介か
課金掲載の期間で払うか、採用が決まったときに払うか
運用工数応募書類と実績を読む時間、スカウトを書く時間が社内にあるか

ライター・編集の募集で見落とされやすいのが、運用工数のうち「実績を読む時間」です。応募が来るたびに、候補者の書いた記事を何本か読み、文章の質と得意な領域を見極めます。この時間は、書類の経歴を読む時間よりずっと長くかかります。応募の数を増やす型の媒体を選ぶほど、読む時間も増えます。

書く人を採るのか、まとめる人を採るのか。募集の整理から媒体の選び方まで一緒に考えます。

媒体選びを相談する

エージェントベストの見解

ライター・編集の採用で相談が多い思い込みは、「ライター経験者で絞れば、求める人に会える」というものです。実際には、ライター経験者のなかでも、取材をして書く人、検索の意図を読んで構成を組む人、短い言葉で売る人、人に書いてもらって整える人で、仕事の中身がまったく違います。経験年数や「ライター」という肩書きでは、この違いは見えません。当社が勧めているのは、募集を出す前に「入社後の一か月で、何を何本作るか」を書き出し、その仕事が書く比重の大きいものか、依頼と修正の比重が大きいものかを決めることです。書く比重が大きいなら、実績の記事を読める媒体と選考を組みます。まとめる比重が大きいなら、進行管理や外部とのやり取りの経験を職務経歴から読める媒体を先に検討します。

求人・スカウトの文面に書くこと

ライター・編集の候補者は、文章を見る目が厳しい読み手です。求人票やスカウトの文面そのものが、会社の文章の水準として読まれます。

書いておくとよい項目を挙げます。

  1. 最近作った記事の例：自社のオウンドメディアなら、代表的な記事を数本挙げる。クライアントワークなら、領域と形式だけを書く
  2. 一本の記事ができるまでの流れ：企画、取材、執筆、編集、公開までを誰が担うか
  3. 入社後に任せること：最初は書く仕事から始めるのか、編集の仕事から始めるのか
  4. 評価の見方：記事の本数で見るのか、読まれ方で見るのか、品質で見るのか
  5. 働き方：取材の外出があるか、在宅で書けるか

スカウトを送るなら、候補者の書いた記事を読んだうえで、どの記事のどこに目が留まったかを一文で書きます。中途の候補者に送る文面の基本は中途採用のスカウト文面の書き方にまとめています。

この条件なら、どの型を先に検討するか

優劣ではなく、条件ごとに先に検討する形として置きます。

  • 自社のオウンドメディアで書く人を採る → 会社の考え方やメディアの方針に共感した人が来る共感型（Wantedlyなど）を先に。会社ページで編集方針を語れると、文章の方向が合う人が集まりやすい
  • IT・Web企業でコンテンツを作る人を採る → IT・Web業界に強い求人型の媒体（Greenなど）を先に。事業とセットで仕事を見せられる
  • 幅広い経験者から選びたい → 求人掲載・スカウト・紹介の窓口を持つ総合型（doda、typeなど）を先に。応募が増えるぶん、実績を読む時間を見込む
  • 編集長や責任者を採る → 紹介で採る形を先に。候補者が少なく、条件のすり合わせに時間がかかるため

掲載で待つか、スカウトで動くかの考え方は掲載型とスカウト型の違い、共感で集めるか条件で集めるかは共感型と条件型の違いも参考になります。

組み合わせ方と選考への接続

媒体は一つで足りることも多いのですが、組み合わせるなら役割を分けます。たとえば、共感型の媒体で会社ページと編集方針を見せ、書く人の応募を受ける。並行して、編集の責任者は紹介で探す。同じ募集を複数の媒体に出すより、募集ごとに媒体を分けるほうが、実績を読む人の負担が偏りません。

選考では、書類の段階で実績の記事を読み、面接では「その記事をどう作ったか」を聞きます。完成した記事だけでは、本人がどこまで担ったかが分からないからです。取材の段取り、構成の決め方、編集者とのやり取りを聞くと、仕事の進め方が見えてきます。

課題を出す場合は、範囲を絞ります。長い記事を一本書いてもらうより、既存の記事の構成案を作る、短い導入文を書くといった形にすると、候補者の負担が小さくなります。課題の扱い（使う範囲、返却や破棄）も先に決めて伝えます。

実績を読む時間が足りないときは、応募対応や日程の調整を外に出す形もあります。運用の相談だけでも構いません。

運用の相談をする

エージェントベストの見解

ライター・編集の採用で、媒体を申し込んだあとに止まりやすいのは、書類選考の段階です。応募が来ても、実績の記事を読む担当がいない。編集長が読むことになっているが、締め切り前は手が回らない。そのあいだに、候補者は他社の面接に進みます。自社で持つべきなのは、実績を読んで「この人に会うか」を決める判断までです。応募への最初の返信、面接の日程の調整、選考の進み具合の連絡は外に出せます。当社は媒体で採る支援と、紹介で採る支援の両方をしているので、どちらの経路でも、判断の前の作業が詰まると候補者が離れることを見ています。読む人を一人決め、読む時間を週の予定に先に入れておく。これだけで書類選考の待ち時間が短くなる会社があります。

まとめ

  • ライター・編集の候補者は、条件と同じくらい、書く媒体・テーマ・編集の体制を見ている
  • 媒体を選ぶ前に「書く人か、まとめる人か」と、入社後の一か月で作るものを決める
  • 運用工数では、応募のたびに実績の記事を読む時間を見込む
  • 自社メディアなら共感型、IT・Web企業なら業界に強い求人型、責任者なら紹介を先に検討する
  • 自社で持つのは書類を読んで会うかを決める判断まで。返信と日程は外に出せる

よくある質問

未経験の人も応募対象にしてよいですか

書く仕事が中心で、社内に原稿を見られる人がいるなら、他職種から移りたい人も対象にできます。その場合は、前職で書いてきた文章（企画書、社内報、ブログなど）を見せてもらう形にします。原稿を見る人がいないなら、まずは経験者を対象にするほうが、入社後の立ち上がりが安定します。

業務委託のライターではなく、社員で採るべきですか

書く本数が多く、テーマが安定しているなら、業務委託で足りることもあります。社員で採る理由になるのは、編集方針を作る、社内の人に取材する、外部のライターを束ねるといった、会社の中にいないとできない仕事があるときです。どちらで採るかを決めてから、媒体を選びます。

新卒でライター・編集を採る場合も同じ考え方ですか

新卒は実績で判断できる部分が少ないので、文章の課題や志向を見る比重が上がります。業界ごとの新卒向けの考え方はメディア業界の採用媒体の選び方にまとめています。
