スカウトの一文を書くには、学生のプロフィールを読む必要があります。ところが、プロフィールの項目は多く、どこを読めばよいか分からないと、大学名と学部と希望の業界だけを見て「〇〇大学の△△学部で、□□業界を希望されている方に」と書いてしまいます。学生には「読んでいない」と分かります。結論から言うと、ワンキャリアの学生プロフィールは、「検索で拾える項目」（大学、学部、学年、希望の業界や職種）と「本人が書いた項目」（自己紹介、学生時代に力を入れたこと、興味、やりたいこと）に分けて読み、前者は送るかどうかの判断に使い、後者だけを文面に使います。読む順番は、本人が書いた項目→最初の1年と重なる点→合わない点→送るか送らないか、で、薄いプロフィールには推測で書かず、読む観点を絞って時間を短くします。 この記事では、項目の分け方、やりがちな失敗、読む順番、薄いプロフィールの扱い、読む時間を短くする観点、体験談を書いた学生への扱い、分担を整理します。ガクチカの読み方はガクチカを読んでスカウトを書く方法で書きました。プロフィールの項目の種類は変わることがあるので、現在の仕様は管理画面で確認してください。

この作業の目的｜「読んだ」と伝わる一文を、短い時間で書けるようにする

プロフィールを読む目的は、学生を評価することではなく、「あなたのここを読んだ」と伝わる一文を書くことと、「この学生に、この仕事の話をしたい」と言えるかを判断することの2つです。

全部を丁寧に読むと、一人に時間がかかり、送れる数が減ります。読む項目と順番を決めておくと、短い時間で、一文が書ける状態になります。

項目の分け方

検索で拾える項目本人が書いた項目
大学、学部、学科自己紹介の文章
学年、卒業予定学生時代に力を入れたこと
希望の業界、職種興味のあること、やりたいこと
希望の勤務地書いている言い回し、選んだ言葉
資格、語学「なぜそれをしたか」「何が好きか」の記述
所属（サークル名、部活名）その活動で何をしたか、何に詰まったか

「検索で拾える項目」は、絞り込みの条件に使い、送るかどうかの判断に使います。文面には書きません。書くと、「検索して送っただけ」と分かります。

「本人が書いた項目」は、文面に使います。ここにしか、「あなたを読んだ」と伝わる材料がありません。

やりがちな失敗

失敗学生からどう見えるか
検索で拾える項目を文面に書く（「〇〇大学の△△学部の方に」）「読んでいない」
本人が書いた項目を読まない一文が書けない。テンプレになる
整った自己紹介を要約する（「主体性のある方と拝見し」）本人の言葉が消える
書かれていないことを推測する（「きっと〇〇に興味があるのでは」）外れると信用を失う
所属だけで判断する（「体育会の方は」「留学経験のある方は」）一括り
希望の業界と自社が違うから送らない希望は変わる。本人が書いた項目に重なる点があれば送ってよい
資格や語学だけを拾う仕事の中身と結びつかない
体験談を書いた学生への扱いを確認せずに送る媒体の規約に関わる可能性

最も多いのは、最初の「検索で拾える項目を文面に書く」です。読む時間を省こうとした結果です。

いま使っている媒体の運用の相談だけでも構いません。プロフィールのどの項目を判断に使い、どの項目を文面に使うかを一緒に線引きします。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「学生のプロフィールは薄いので、読んでも書くことが無い」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアのスカウトの運用を見ていますが、「書くことが無い」と言う会社の送る人が読んでいるのは、大学名と学部と希望の業界で、本人が書いた自己紹介と学生時代の記述を読み飛ばしています。本人が書いた項目には、多くの場合、一文に使える言葉が一つはあります。「〇〇が好きだった」「△△で困った」「□□をやってみたい」。当社がプロフィールの読み方を渡すとき、最初に伝えるのは、「検索で拾える項目は見なくてよい。本人が書いた項目だけを読んでください」ということです。読む項目を減らすと、時間は短くなり、一文は書けるようになります。

読む順番

  1. 本人が書いた項目を読む：自己紹介、学生時代に力を入れたこと、興味、やりたいこと。検索で拾える項目は、絞り込みで済んでいるので飛ばす
  2. 本人の言葉で、そのまま使える一文を探す：「〇〇が好きだった」「△△で詰まった」。型の言葉ではなく、本人が選んだ言い回し
  3. 自社の「最初の1年」と重なる点を探す：その言葉や場面が、最初の月・最初の3か月のどこと似ているか。一つ見つかれば足りる
  4. 合わない点を見る：希望の勤務地、働き方、やりたいことが募集と明らかに違うか。違うなら送らない
  5. 送るか送らないかを決める：「この学生に、この仕事の話をしたい」と言えるか
  6. 拾った一文と重なる点を、そのまま文面に：ワンキャリアのスカウトを相手ごとに変える範囲

「本人が書いた項目から読む」が順番の要点です。検索で拾える項目から読み始めると、そこで判断が終わり、本人の言葉にたどり着きません。

薄いプロフィールの扱い

薄さの程度扱い
本人が書いた項目が、一つでもあるその一つから一文を作る。「〇〇に興味があると書かれていたので」
本人が書いた項目が無く、検索で拾える項目だけ送らないか、優先を下げる。一文が書けない
早期の学生で、まだ書いていない時期を待つ。または、企業ページとイベントで見つけてもらう。早期（低学年向け）掲載の考え方
整いすぎていて、本人の言葉が見つからない型の外にある具体的な場面を探す。無ければ活動の事実を一つ

「薄いなら、推測で埋めない」が原則です。推測で書いた一文は、外れると「読んでいない」より悪い印象になります。

読む時間を、短くする観点

読む項目と順番を決めても、一人に時間がかかることがあります。

  • 「最初の1年」の場面を、先に頭に入れておく：自社の最初の月に何が起きるかを知っていれば、似た場面を探すだけになる
  • 本人が書いた項目の、最初と最後を読む：最初に「何をしたか」、最後に「何を思ったか」が書かれていることが多い
  • 一文に使える言葉が一つ見つかったら、それ以上読まない：全部を読まなくてよい
  • 合わない点は、先に見る：勤務地や働き方が明らかに違えば、そこで終わり
  • 読む観点を、面接で見る観点と同じにする：一度決めれば、迷わない。ガクチカを読んでスカウトを書く方法

「一つ見つかったら、それ以上読まない」が、時間を短くする最も大きな観点です。一文に使うのは一つの箇所で、全部を読む必要はありません。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。プロフィールを読む観点があれば、一人あたりの時間がどのくらいになるかお伝えします。

媒体選びを相談する

検索で拾える項目の、使い方

文面には書きませんが、判断には使います。

  • 絞り込みの条件：募集の「こんな人」を置き換えた条件。ワンキャリアのスカウト対象の絞り方
  • 合わない点の確認：希望の勤務地、学年と時期（年度の公表内容と自社の方針で）
  • 希望の業界や職種は、絶対の条件にしない：学生の希望は変わる。本人が書いた項目に重なる点があれば、希望が違っても送ってよい。ただし、文面で「希望と違いますが」とは書かない
  • 資格や語学は、募集で要るときだけ：要らないなら見ない

「希望の業界が違うから送らない」は、絞りすぎです。早期の学生は特に、希望を仮で書いていることが多くあります。

体験談を書いた学生への扱い

ワンキャリアには、学生が体験談やクチコミを書く仕組みがあります。自社の体験談を書いた学生、他社の体験談を書いた学生が、スカウトの対象に含まれることがあります。

  • 自社の体験談を書いた学生への扱いは、媒体の規約を確認する：送ってよいか、送るときの注意があるか。規約は管理画面とヘルプで
  • 体験談の内容を、文面に書かない：「体験談を拝見し」は、学生が書いた場所と文脈を超えて使うことになる
  • 他社の体験談を書いた学生に、その内容に触れて送らない
  • 体験談を書いていることをプロフィールから読める場合も、判断に使うだけ：文面には使わない

この記事では、規約の具体は書きません。自社で確認してください。

作業誰が

プロフィールを読む送る人（入社してまもない社員）
一文と重なる点を書く読んだ人
薄いプロフィールの扱いを決める人事

読む観点を面接で見る観点と揃える人事と面接に出る人

運用代行や代理店が支えられるのは、項目の分け方の整理、読む順番の型、薄いプロフィールの扱いの基準、時間を短くする観点までで、プロフィールを読むこと、一文を書くこと、規約の確認は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これをやる前に、先に決めておかないと読む時間が減らないことがあります。「自社の最初の1年の場面」です。当社がワンキャリアのプロフィールの読み方を支えるとき、項目の分け方と順番は当社が出せますが、「重なる点を探す」には、何と重ねるかが決まっていないと探せません。「最初の月に何が起きるか」が読む人の頭に無いと、プロフィールの全部を読んで、それでも何を拾えばよいか分からず、時間がかかります。当社が最初にお願いするのは、入社してまもない社員に「最初の月の場面を三つ」を聞いてもらい、読む人に渡すことです。三つの場面があれば、読む人は「この三つのどれかと似た場面を探す」だけになり、一人あたりの時間は短くなります。読む観点は、プロフィールの側ではなく、自社の側にあります。

まとめ

  • プロフィールは「検索で拾える項目」（大学・学部・学年・希望）と「本人が書いた項目」（自己紹介・学生時代・興味・やりたいこと）に分け、前者は判断に、後者だけを文面に使う
  • 検索で拾える項目を文面に書く、本人が書いた項目を読まない、整った文章を要約する、推測する、所属で一括りにする、が失敗
  • 読む順番は、本人が書いた項目→使える一文→最初の1年と重なる点→合わない点→送るか送らないか
  • 薄いプロフィールは、一つでも本人の言葉があればそこから、無ければ送らない。推測で埋めない
  • 「最初の1年」の場面を先に頭に入れ、一つ見つかったらそれ以上読まない。体験談を書いた学生への扱いは規約を確認し、体験談の内容を文面に書かない

よくある質問

希望の業界が自社と違う学生には、送らないほうがよいですか

本人が書いた項目に、自社の最初の1年と重なる点があれば、送ってよい相手です。学生の希望は、就職活動の途中で変わります。ただし、文面で「希望と違いますが」とは書かず、重なる点だけを書きます。希望の業界は、絞り込みの条件の一つで、絶対の条件ではありません。

プロフィールを読む時間が、一人あたり長くかかります

「最初の1年」の場面が、読む人の頭に入っているかを確かめます。入っていれば、似た場面を探すだけになります。次に、本人が書いた項目だけを読み、一文に使える言葉が一つ見つかったら、それ以上読まない形にします。合わない点は先に見て、明らかに違えばそこで終えます。

プロフィールの読み方は、御社に相談できますか

できます。当社は、項目の分け方の整理、読む順番の型、薄いプロフィールの扱いの基準、時間を短くする観点を支えられます。プロフィールを読むこと、一文を書くこと、規約の確認は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアのスカウト運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • ワンキャリアの学生のガクチカを読んでスカウトを書く方法｜結果ではなく「詰まった場面と、そのとき何をしたか」を拾い、最初の1年の場面と重ねる
  • ワンキャリアのスカウト文面の書き方｜学生時代を読んだ一文→最初の1年との重なり→選考で何を見るかの一文→話す場か選考か、の4段を短く
  • ワンキャリアで地方の学生にスカウトを送る考え方｜勤務地を文面で先に伝え、オンラインで完結する話す場を案内し、体験談の「遠くまで行った」を防ぐ
  • ワンキャリアのスカウトを代行に出せる範囲｜絞り込み・型・台帳・体験談の要点・見直しは出せる、読んで書く一文・受諾対応・面談・「何を見るか」は社内に残す
