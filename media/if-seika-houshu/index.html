Infraのデポジットプランの考え方

学生向けの長期インターン求人サイトInfraには、サブスクリプションとデポジットプランの2つがあります。デポジットプランは、「採れたときだけ費用がかかる」形と受け取られることがありますが、実際は採用する人数を先に決めて契約し、その人数を採用できるまで使うプランです。結論から言うと、デポジットプランが合うかどうかは、契約する人数を、受け入れの体制から無理なく決められるかで決まります。 人数を多めに見込むと採り切れない人数が残り、少なめに見込むと途中で追加を考えることになります。この記事では、デポジットプランの考え方、人数の決め方、契約前に確かめる点を整理します。具体的な金額や条件は時期によって変わるため、ここでは扱いません。

デポジットプランの仕組みの考え方

Infraの企業向けページでは、サブスクリプションは契約期間中に人数の上限なく採用でき、デポジットプランは契約したデポジットの人数を採用できるまで使える、と説明されています。費用の考え方は、次のように違います。

観点デポジットプランサブスクリプション
何に対して契約するか採用する人数期間
使える範囲契約した人数を採用できるまで契約期間中は人数の上限なく採用できる
予算の立て方採る人数の見込みから立てる期間から立てる
気にすべきこと契約した人数を採り切れるか採用が少ない期間にも費用がかかる

どちらも、求人の掲載とスカウトを使って学生に届ける点は同じです。掲載できる期間、スカウトの通数、早期に辞めた場合の扱いなど、条件の細部はプランによって違うので、申し込みの前に料金表で確かめてください。

契約する人数をどう決めるか

デポジットプランで最初に決めるのは、何人分を契約するかです。ここを「採りたい人数」だけで決めると、後でずれます。人数は、次の三つのうち小さいものに合わせます。

  1. 任せる仕事の数：受け入れた学生に、最初の1か月から任せられる仕事が何人分あるか
  2. 見る人の数：日々の仕事を見て、振り返りの時間を取れる社員が何人いるか
  3. 応募に返せる時間：応募が来たときに、数日以内に返事をして面談を組める時間があるか

「採りたい人数」がこの三つより大きいなら、先に受け入れの体制を広げるか、人数を下げて契約します。体制より多い人数で契約すると、採り切れない人数が残るか、採っても見る人がいなくて続かない、のどちらかになりやすいからです。

デポジットプランとサブスクリプションのどちらが自社に合うか、受け入れの体制から一緒に確かめます。

デポジットプランが合う会社

デポジットプランは、次のような会社に合いやすい考え方です。

  • 初めて長期インターンを受け入れる：まず一人を受け入れて、受け入れの形を作りたい
  • 採る人数が少なく、決まっている：1〜2人など、受け入れる人数を先に言える
  • 採る時期が限られている：特定のプロジェクトや時期に合わせて受け入れたい
  • 人数で予算を説明したい：「何人分」という形のほうが、予算を持つ部署に伝わりやすい

一方、次のような会社は、サブスクリプションも合わせて検討します。

  • 長期インターン生を年間を通じて継続して受け入れている
  • 多くの職種で募集している
  • 受け入れる人数が、時期によって大きく変わる

エージェントベストの見解

デポジットプランを選ぶ会社の中には、「人数分を契約したのだから、あとは応募を待てばよい」と考える会社があります。当社が気になるのは、この考え方だと運用に力が入らなくなることです。原稿を出したまま見直さない、応募があっても返事が遅れる、面談の日程がなかなか決まらない。契約した人数を採り切るのは、契約そのものではなく、その後の運用です。当社はInfraの代理店として、求人原稿の作成から運用までを支援していますが、デポジットプランを選んだ会社にこそ、運用の担当者と、応募への返事の期限を決めておくことを勧めています。採れないまま過ぎた期間に失っているのは、その間に出会えたはずの学生との接点です。

契約前に確かめておくこと

デポジットプランを選ぶとき、次の点を申し込みの前に確かめます。

掲載できる期間

契約した人数を採り切るまでに、どのくらいの期間、求人を掲載できるかを確かめます。採る時期が先の場合は、掲載を始める時期も合わせて決めます。

受け入れ後に続かなかったとき

受け入れた学生が短期で辞めた場合の扱いは、条件で決まっています。対象になる期間などを、申し込みの前に確かめておきます。ただ、短期で辞める学生が多い会社は、条件の扱いより先に、受け入れの体制を見直すことが先です。

人数を増やしたくなったとき

受け入れがうまくいき、契約した人数より多く採りたくなったときに、どう追加するか、サブスクリプションに切り替えるとどうなるかを聞いておくと、後で慌てずに済みます。

デポジットプランを選んだ後の運用の体制づくりも、代理店として支援します。

運用の相談をする

申し込む前に社内で決めておくこと

デポジットプランを選ぶと決めたら、申し込む前に次のことを社内で決めておきます。

  1. 契約する人数：今期に何人を受け入れるか。三つの上限のうち、どれで決まったか
  2. 運用の担当者：原稿の見直しと応募への返事を、誰が担当するか
  3. 返事の期限：応募があってから何日以内に返事をするか
  4. 受け入れの判断者：面談の後、受け入れるかどうかを誰が決めるか

4つ目が決まっていないと、面談の後に判断が遅れ、その間に学生が他社に決めてしまうことがあります。契約した人数を採り切れるかどうかは、この判断の速さにも左右されます。

社内で費用をどう説明するか

デポジットプランの費用を社内で説明するときは、費用の額だけでなく、その費用で何が得られたかを合わせて伝えます。

  • 採用した学生の人数と、続いている期間
  • 学生が担った業務と、その成果
  • 新卒の本選考に進んだ学生の数

「何人分」という分かりやすさがある反面、採った学生がその後どうなったかを説明しないと、費用の意味が伝わりにくいことがあります。とくに、学生が短期で辞めた場合、「費用をかけたのに残らなかった」と受け取られることがあります。

エージェントベストの見解

当社は人材紹介も行っています。人材紹介は採用が決まったときに費用を支払う成果報酬型の形ですが、そこで見てきたのは、企業の側が「採れたかどうか」だけに目を向けがちだということです。採れた後に定着したか、期待した仕事ができているかは、費用の議論の外に置かれやすい。長期インターンのデポジットプランでも同じことが起きます。契約した人数を採り切っても、その学生が数週間で辞めてしまえば、会社にとっての成果はほとんど残りません。人数で契約するなら、契約の人数と、自社が本当に欲しい「続いて戦力になる学生」の人数の差を、受け入れの体制で埋める必要があります。この差を意識しておくと、契約する人数も、受け入れの準備の優先度も変わってきます。

プランの選び方の全体はInfraのサブスクリプションとデポジットの選び方で整理しています。

まとめ

  • デポジットプランは、採用する人数を先に決めて契約し、その人数を採用できるまで使うプラン
  • 契約する人数は、任せる仕事の数・見る人の数・応募に返せる時間のうち小さいものに合わせる
  • 契約した人数を採り切るのは運用なので、担当者と返事の期限を決めておく
  • 掲載できる期間、短期で辞めたときの扱い、人数を増やすときの方法を事前に確かめる
  • 社内では、費用の額と合わせて、採用した学生のその後を説明する

よくある質問

デポジットプランは、採れなかったら費用がかからないプランですか

そうではありません。デポジットプランは、採用する人数を先に決めて契約し、その人数を採用できるまで使うプランです。採れなかったときの費用の考え方ではなく、契約した人数を採り切れるかで考えます。条件の細部は申し込みの前に料金表で確かめてください。

デポジットプランからサブスクリプションに切り替えることはできますか

どんな条件でいつ切り替えられるかは、契約の前に聞いておくと後で慌てずに済みます。受け入れる人数が増えてサブスクリプションのほうが見通しを立てやすくなった場合は、相談してみてください。

プランによって、応募の質は変わりますか

料金の形と応募の質は、直接は関係しません。応募の質を左右するのは、原稿の書き方や、応募への対応の早さなど、運用の中身です。
