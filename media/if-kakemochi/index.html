インターン先を掛け持ちする学生への向き合い方

面談で「ほかの会社でも長期インターンをしています」と言われ、受け入れるかどうか迷う担当者は少なくありません。掛け持ちそのものを理由に見送る必要はありませんが、時間・情報・優先順位の3点で線を引かずに受け入れると、どこかで問題が表に出ます。 掛け持ちを認めるかどうかではなく、認めるならどの条件で認めるかを先に決めておくことが大切です。この記事では、学生向けの長期インターン求人サイトInfraなどで掛け持ちの学生が応募してきたときの向き合い方を整理します。

学生が掛け持ちをする理由

まず、学生がなぜ掛け持ちをするのかを知っておくと、向き合い方を決めやすくなります。

  • 経験の幅を広げたい：業界や職種の違う会社で働き、自分に合う仕事を探している
  • 収入を確保したい：1社だけでは働ける時間が足りず、生活費のために複数社で働いている
  • 比較している途中：どちらの会社で長く続けるかを決めるため、一時的に両方で働いている
  • 前の会社を辞めきれていない：新しい会社に移りたいが、前の会社の業務を引き継ぎ中

理由によって、受け入れ後の動き方が違います。経験の幅を広げたい学生は、両方を長く続けることが多い。比較している学生は、数か月のうちにどちらかに絞る可能性が高い。面談で理由を聞いておくと、受け入れ後の見通しが立ちます。

掛け持ちで起きやすい問題を3つに分ける

掛け持ちで実際に起きる問題は、おおむね次の3つに分けられます。

問題起きること事前に決めておくこと
時間試験期間や繁忙期が重なり、両方のシフトを満たせなくなる最低限確保してほしい時間と、減らすときの連絡の仕方
情報同業の会社で掛け持ちしている場合、業務上の情報が混ざるおそれがある同業との掛け持ちを認めるか、認めるなら何を扱わせないか
優先順位締め切りが重なったとき、どちらを優先するかが曖昧で、結果として両方が遅れる自社の業務で締め切りがあるものを事前に伝え、重なりそうなら早めに相談してもらう

このうち、会社が最も気にするのは2つ目の情報です。同業の会社でインターンをしている場合、顧客や企画の情報が混ざらないよう、扱う業務の範囲を調整する必要があります。

掛け持ちの扱いを求人原稿にどう書くか、原稿づくりの段階から相談できます。

無料で相談する

面談で確かめること

掛け持ちの学生と面談するときは、次の点を具体的に聞きます。聞き方は詰問にならないよう、受け入れのための確認として伝えます。

  1. もう1社の業界と仕事の内容：社名まで聞く必要はありません。同業かどうか、どんな仕事をしているかが分かれば十分です
  2. もう1社での1週間の時間：何曜日の何時間を使っているか。自社に使える時間がどこにあるか
  3. 今後の見通し：もう1社をいつまで続けるつもりか。自社と比べて決めるつもりか
  4. 繁忙期の重なり：試験期間、もう1社の繁忙期、自社の繁忙期が重なる時期はあるか

4番目は見落とされがちですが、受け入れ後のトラブルの多くはここから生まれます。重なる時期が分かっていれば、その時期のシフトを事前に調整できます。

エージェントベストの見解

掛け持ちの扱いで相談を受けると、多くの会社は「掛け持ちは禁止」と求人原稿に書くかどうかで迷っています。当社が勧めるのは、禁止と書くより「掛け持ちの場合は面談で相談してください」と書くことです。禁止と書くと、掛け持ちをしている学生は応募を控えるか、掛け持ちを隠して応募します。隠して応募されると、受け入れ後に時間や情報の問題が見えにくくなり、かえって管理が難しくなります。相談してくださいと書けば、学生は正直に話しやすくなり、面談の段階で線を引けます。当社はInfraの代理店として求人原稿の作成から関わりますが、原稿に書く一文で応募の段階の正直さが変わる場面を何度も見ています。掛け持ちを管理する一番の方法は、隠さなくてよい空気を最初につくることです。

受け入れ後のルール

掛け持ちを認めて受け入れたあとは、次のルールを本人と共有します。

シフトと連絡

  • 最低限確保してほしい時間を、曜日と時間帯で具体的に決める
  • もう1社の都合でシフトを変えるときは、何日前までに連絡するかを決める
  • 試験期間など、事前に分かっている休みはまとめて伝えてもらう

情報の扱い

  • 同業の会社と掛け持ちする場合、担当させない業務を明示する
  • 自社で知った情報をもう1社で使わないこと、もう1社の情報を自社に持ち込まないことを、具体例を挙げて伝える
  • 判断に迷ったら相談する窓口を決めておく

見直しの時期

受け入れから1〜2か月たったところで、掛け持ちの状況を確認する面談を設けます。両方を続けるのが難しくなっていないか、どちらかに絞るつもりがあるかを聞きます。絞る場合に自社を選んでもらえるかどうかは、この時点までの受け入れ方で決まります。

受け入れ後の運用まで見据えた募集の設計を、代理店として一緒に考えます。

運用の相談をする

社内で判断をそろえる

掛け持ちの扱いは、面接官や受け入れ部署によって判断が変わりやすいテーマです。ある部署では認め、別の部署では断る、という状態になると、学生の間で「言う相手によって扱いが違う会社」と受け取られます。

判断をそろえるために、次のことを社内で決めておきます。

  • 掛け持ちを認める条件（同業かどうか、最低限の時間を確保できるか）
  • 同業と掛け持ちする場合に担当させない業務の一覧
  • 面談で掛け持ちを聞いたときに、誰に相談して判断するか
  • 受け入れ後に問題が起きたとき、誰が本人と話すか

決めた内容は、受け入れ部署の社員にも共有します。日々学生と接している社員が知らないと、シフトの相談を受けたときに対応がぶれてしまいます。

掛け持ちの学生を新卒採用の視点で見る

掛け持ちをしている学生は、複数の会社を内側から比べているとも言えます。新卒採用を意識している会社にとっては、比べられた結果として選ばれるかどうかが問われる相手です。

掛け持ちの学生が最終的に自社を選ぶかどうかは、仕事の中身だけでなく、受け入れの丁寧さに左右されることが多いようです。シフトの相談に柔軟に応じた、困ったときに相談しやすかった、といった経験が、比べたときの差になります。

エージェントベストの見解

当社は人材紹介も行っており、社会人の転職でも「副業」や「兼業」の扱いをめぐる相談を受けます。そこで感じるのは、掛け持ちの扱いに会社の姿勢が出るということです。一律に禁止する会社、黙認する会社、条件を決めて認める会社。学生も社会人も、この姿勢を見て会社を判断しています。長期インターンでは、学生がまだ社会人としての働き方を知らない段階なので、ここで条件を決めて認める会社は「話の通じる会社」として記憶されやすい。新卒採用への接続を考えるなら、掛け持ちを問題として扱うより、学生の働き方を一緒に設計する機会として扱うほうが、長い目で見て得るものが大きいと考えています。インターンを新卒採用にどうつなぐかは長期インターンから新卒採用へつなぐ設計でも整理しています。

まとめ

  • 掛け持ちの理由は、経験の幅・収入・比較・引き継ぎなどさまざまで、理由によって見通しが違う
  • 起きやすい問題は時間・情報・優先順位の3つに分けて、事前に決めておく
  • 面談では、もう1社の業界と時間、今後の見通し、繁忙期の重なりを聞く
  • 求人原稿には「禁止」より「相談してください」と書くほうが、正直な応募につながりやすい
  • 受け入れから1〜2か月後に状況を確認する面談を設ける

よくある質問

競合他社でインターンをしている学生は、受け入れないほうがよいですか

一律に断る会社もありますが、担当させる業務を限定して受け入れる会社もあります。顧客情報や企画の情報に触れない業務に絞れるかどうかで判断します。迷う場合は、社内の法務担当などに相談してください。

掛け持ちによって労働時間が長くなりすぎないか心配です

学生の健康と学業を守る観点から、面談でもう1社を含めた1週間の働き方を確認しておくことは大切です。労働時間の扱いや規定の解釈で迷う場合は、社会保険労務士などの専門家に確認してください。

掛け持ちしていることを途中で知った場合、どうすればよいですか

まず本人と話し、時間・情報・優先順位の3点で問題が起きていないかを確認します。問題がなければ、今後の連絡のルールを決めて続けてもらう選択肢もあります。
