事業開発の長期インターンを採る｜裁量と責任のバランス

Infra・長期インターン職種別 更新日 2026/10/16

事業開発の長期インターンは、学生にとって人気の高い募集です。「裁量が大きい」「経営に近い」という言葉に惹かれて応募する学生が多く、原稿を出すと意欲の高い学生が集まりやすい傾向があります。結論から言うと、事業開発の長期インターンで大切なのは、裁量を大きく見せることより「学生が決めてよいこと」と「社員が責任を持つこと」を最初に分けて伝えることです。 その線が曖昧だと、学生は何を任されているのか分からず、社員は学生の動きを後から止めることになります。この記事では、学生向けの長期インターン求人サイトInfraで事業開発を募集する会社に向けて、裁量と責任の分け方を整理します。

「事業開発」という言葉が学生にどう読まれるか

事業開発という職種名は、会社によって中身が大きく違います。新しい取引先の開拓、提携の交渉、新しい商品の検証、既存事業の販路拡大。学生は原稿を読んで、それぞれ違う仕事を想像します。

  • 新しい事業を一から立ち上げる仕事
  • 大手企業との提携を進める仕事
  • 営業に近い、新しい顧客を探す仕事
  • 経営者の隣で戦略を考える仕事

原稿で職種名だけを書くと、学生はもっとも魅力的な像を想像して応募してきます。入ってみたら新規の顧客への電話が中心だった、ということになると、早い段階で気持ちが離れます。仕事の中身を、学生の一週間の動きで書くことが、原稿の最初の仕事です。

学生が決めてよいこと、社員が持つこと

裁量と責任を分けるときは、次のような表で整理しておくと、学生にも社内にも説明しやすくなります。

区分例
学生が決めてよいこと調べる対象の選び方、連絡する候補先のリスト、資料の構成、仮説の立て方
学生が案を出し、社員が決めること実際に連絡する相手、提案の内容、検証の進め方
社員が持つこと契約の判断、金額や条件の提示、社外への正式な回答

この表の一段目が広いほど、学生は裁量を感じます。三段目は、学生を守るためにも社員が持つべき領域です。学生が取引先と条件の話を進めてしまい、後から会社として撤回することになると、学生にとっても相手にとっても負担が大きくなります。

原稿には、この一段目と二段目に何が入るかを具体的に書きます。「裁量がある」と一言書くより、「連絡先のリストづくりから提案資料の構成まで、学生の案をもとに進めます」と書くほうが、学生は自分の動きを想像できます。

エージェントベストの見解

事業開発の長期インターンの相談で多い思い込みは、「優秀な学生なら、新規事業を任せられる」というものです。実際には、学生の能力より、社員側に事業の判断を引き取る時間があるかどうかで結果が決まります。学生がどれだけ良い仮説を立てても、それを検証するかどうかを決める社員が忙しくて返事をしないと、学生は待つしかありません。当社が見てきた中では、事業開発の長期インターンがうまく回っている会社は、週に一度、学生と社員が三十分でも話す場を固定しています。その場で学生の案に「進める」「やめる」「条件付きで進める」を返す。返事の速さが、学生にとっての裁量の実感になります。募集を出す前に、その三十分を誰が持つかを決めておくことを勧めます。

事業開発の原稿で「任せる範囲」をどう書くか。言葉選びから一緒に整理します。

無料で相談する

社外と接するときの名義と確認

事業開発の仕事は、社外の人と接する場面が多くなります。学生が会社を代表して連絡するときのルールを決めておきます。

  • 名刺やメールの署名：会社としてどう名乗るか。インターンと明記するか
  • 初回の連絡の確認：最初の連絡文は社員が確認してから送る
  • 打ち合わせへの参加：最初は社員に同席し、慣れたら学生だけで行く範囲を決める
  • 約束してよいこと：日程の調整、資料の送付まで。条件や金額は約束しない

相手の会社から見れば、学生も会社の担当者です。学生が何かを約束すれば、相手はそれを会社の約束として受け取ります。この点を最初に学生に説明しておくと、学生も責任の重さを理解したうえで動けます。

面談で見ること

事業開発の長期インターンには、意欲の高い学生が多く応募します。意欲は大切ですが、それだけで選ぶと、受け入れ後に「思っていた仕事と違う」が起きやすくなります。面談では次の点を確かめます。

  1. 地道な作業への向き合い方：調べ物やリストづくりを続けた経験があるか
  2. 断られた経験：何かを提案して断られたとき、どう受け止めたか
  3. 数字で考える癖：自分の取り組みの結果を、何かの数で振り返ったことがあるか
  4. 報告の仕方：うまくいっていないことを早めに伝えられるか

四つ目は特に重要です。事業開発の仕事は、うまくいかないことのほうが多い仕事です。進んでいないことを隠さずに伝えられる学生は、社員にとって任せやすい存在になります。

長期インターンを雇用として受け入れるなら、働いた時間に応じた賃金と労働時間の上限の決まりが土台になります。成果に応じた報酬を考える場合は、扱いが複雑になることがあるため、社会保険労務士などの専門家に確認してください。

成果の見せ方と、振り返りの場

事業開発の仕事は、成果が出るまでに時間がかかります。長期インターンの期間内に事業の形になることは多くありません。そのため、学生の成果を何で見るかを決めておきます。

  • 検証した仮説の数と、分かったこと
  • 連絡した相手の数と、話を聞けた数
  • 作った資料や提案書
  • 社内で採用された提案

月に一度、学生自身にこれらを振り返ってもらう場を作ると、学生は自分の成長を確かめられます。事業として成果が出ていなくても、検証して分かったことがあれば、それは会社にとっても価値のある情報です。

エージェントベストの見解

事業開発の長期インターンを、新卒採用や中途採用とどう使い分けるかも考えておく必要があります。当社はInfraの代理店として長期インターンの募集を支援しつつ、人材紹介で事業開発の経験者の採用にも関わっています。その両方を見ていると、「新しい事業を誰かに立ち上げてほしい」という課題に対して、長期インターンを最初の手段にするのは順番が逆な場合があると感じます。事業の方向がまだ決まっていない段階では、学生は何を調べればよいか分からず、社員も指示を出せません。一方、方向が決まっていて、検証の手を増やしたい段階なら、長期インターンの学生は大きな力になります。今の事業がどちらの段階にあるかで、経験者を探すか、学生を迎えるかを分けて考えると、受け入れ後のすれ違いが減ります。

経験者を探すか、学生を迎えるか。事業の段階に合わせた採り方をご相談いただけます。

無料で相談する

事業の方向そのものが変わりやすい段階での受け入れ方は、新規事業の長期インターンを採るで詳しく扱っています。

まとめ

  • 事業開発という職種名は会社ごとに中身が違うため、学生の一週間の動きで仕事を書く
  • 学生が決めてよいこと・案を出して社員が決めること・社員が持つことを表で分ける
  • 社外に対しては、約束してよいのは日程と資料まで。条件や金額は社員が持つ
  • 週に一度、学生の案に「進める・やめる」を返す場を固定する
  • 事業の方向が決まっていない段階では、長期インターンより経験者の採用を先に検討する

よくある質問

学生に新規事業の企画を一から任せてもよいですか

任せる場合は、企画を判断する社員と、判断の基準を先に決めておくことです。基準がないまま企画を任せると、学生は何を目指せばよいか分からず、社員も評価の仕方に迷います。最初は既存事業の中の小さな検証から始め、慣れてから企画の段階を任せる会社が多いようです。

成果報酬のような形で報酬を決めてもよいですか

長期インターンで雇用契約を結ぶ場合、労働時間に応じた賃金の扱いや最低賃金の規定を守る必要があります。成果に応じた上乗せを考える場合も、その前提の上で設計することになります。扱いに迷う場合は、社会保険労務士などの専門家に確認してから決めてください。

事業開発の長期インターンは、どの学年の学生が多いですか

学年は会社の募集の書き方によって変わります。低学年の学生は長く働ける一方で経験が少なく、高学年の学生は経験がある一方で就職活動と重なります。受け入れの期間と、教える時間のどちらを重視するかで、原稿に書く対象の学年を決めるとよいでしょう。
