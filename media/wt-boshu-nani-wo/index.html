Wantedlyの募集記事「なにをやっているのか」の書き方｜会社ページの繰り返しではなく、この職種の範囲で

募集記事の「なにをやっているのか」に、会社ページと同じ文章を貼る会社は多いものです。会社の事業を説明する部分だから同じでよい、という判断です。ところが、候補者は募集記事を「この職種の話」として読んでいます。結論から言うと、募集記事の「なにをやっているのか」は、会社全体の事業説明ではなく、「この職種が関わる範囲の事業」を、初めて聞く人に分かる言葉で書くものです。会社全体は会社ページに任せ、募集記事では「この職種は、事業のどこを担っているか」を書きます。 会社ページの繰り返しだと、募集記事が長くなり、候補者が知りたい「自分の仕事の位置」が見えません。この記事では、この部分の役割、会社ページとの分担、書く内容、言葉の選び方、長さ、やりがちな失敗、分担を整理します。募集記事の全体は募集記事の基本構成、会社ページの「なにを」は会社ページで最初に書くことで書きました。

この作業の目的｜候補者に「自分の仕事の位置」を見せる

候補者が募集記事の「なにをやっているのか」で知りたいのは、会社の全事業ではなく、「自分が入る仕事は、この会社の中でどこにあって、誰に何を提供する仕事か」です。

会社が複数の事業を持っていても、候補者が関わるのは、そのうちの1つか一部です。全部を説明されると、自分の仕事がどこか分からなくなります。この職種が関わる範囲だけを書くと、「自分はここで、これをやる」が見えます。

この部分の目的は、会社を説明することではなく、候補者に「自分の仕事の位置」を見せることです。

手順1｜会社ページとの分担

会社ページと募集記事で、「なにをやっているのか」の役割を分けます。

観点会社ページ募集記事
範囲会社全体の事業この職種が関わる範囲
視点会社は何をしている会社かこの職種は事業のどこを担うか
長さ主な事業を数段落で数行。詳しくは会社ページへ
誰向け会社を初めて知る人この職種に興味がある人
更新事業が変わったとき募集の開始と終了、職種の仕事が変わったとき

募集記事の「なにを」には、「会社全体は会社ページに書いています」の一言を添えます。候補者は、必要なら会社ページに行きます。募集記事に全部を書く必要はありません。

会社ページより先に募集記事を書くと、この分担ができず、募集記事に会社の説明が全部入ります。会社ページが先です。

手順2｜書く内容

募集記事の「なにをやっているのか」に書くのは、次の4つです。数行で足ります。

  1. この職種が関わる事業を、一言で：「〇〇に困っている△△に、□□を提供している事業」。会社に複数の事業があっても、この職種が関わるものだけ
  2. この職種は、その事業のどこを担うか：「□□を提供するうえで、この職種は〇〇の部分を担う」。顧客と会う部分か、作る部分か、支える部分か
  3. いま、この事業で力を入れていること：この募集が生まれた背景につながる。「〇〇を広げている」「△△を新しく始めた」
  4. 規模感を、様子で：「数人のチームで」「顧客は〇〇のような会社」。数字より、候補者が想像できる様子で

2の「事業のどこを担うか」が、募集記事の「なにを」の中心です。会社ページには無い、この職種だけの情報です。ここが書かれていると、候補者は「自分の仕事の位置」を掴めます。

いま使っている媒体の運用の相談だけでも構いません。募集記事の「なにを」を、この職種の範囲に一緒に絞ります。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「募集記事の『なにをやっているのか』は、会社の事業説明だから、会社ページと同じでよい」というものです。実際には、候補者は募集記事を「この職種の話」として読んでいて、会社全体の説明を求めていません。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、会社ページと同じ文章を貼った募集記事は、長くなり、「この募集で何をやるか」にたどり着く前に候補者が離れています。逆に、「この職種は事業の〇〇を担う」と数行で書いた募集記事は、短いのに「自分の仕事の位置」が伝わり、話を聞きに来る候補者が増えています。募集記事の「なにを」は、会社の説明を減らして、職種の位置を足すもの。会社ページと同じ文章を貼っていたら、まずそれを数行に削り、「この職種はどこを担うか」の一文を足す。それだけで、募集記事は読まれるようになります。

手順3｜初めて聞く人に分かる言葉で

「なにをやっているのか」で最も多い失敗は、業界の言葉で書くことです。同じ業界の人には通じても、候補者には通じません。

業界の言葉（避ける）初めて聞く人に分かる言葉（型）
「〇〇ソリューションの提供」「〇〇に困っている会社に、△△の仕組みを作って渡している」
「BtoBの□□事業」「会社向けに□□を売っている。相手は〇〇のような会社」
「〇〇領域でのバリューチェーン構築」「〇〇を作る会社と使う会社の間に入って、△△をやっている」
社内の事業名や製品名「〇〇という名前で呼んでいる、△△のサービス」と一言添える

言い換えの確かめ方は、社外の知人に読んでもらい、「何の仕事か分かった」と言われるかです。新卒向けの募集なら、学生に近い年代の人に読んでもらいます。

「業界を知っている人だけ来てほしい」という会社でも、募集記事の「なにを」は分かる言葉で書きます。業界を知っている人にも分かりますし、業界を知らないが仕事内容で選びたい候補者にも届きます。志望業界を絞らない候補者に届く考え方は、OfferBoxの検索条件の組み方で「志望業界で絞らない」と書いたのと同じです。

手順4｜長さの目安と、会社ページへ委ねる部分

募集記事の「なにを」は、短く書きます。

  • 目安は数行：4つの内容を、それぞれ一文か二文で
  • 事業の沿革、複数事業の一覧、市場の説明は書かない：会社ページに任せる。「会社全体は会社ページで」の一言を添える
  • この募集で何をやるかは、別の部分に書く：「なにを」は事業の話、「何をやるか」は入った人の仕事の話。混ぜない
  • 長くなったら、会社ページに移す：募集記事に書きたくなった会社の説明は、会社ページに書き、募集記事からは委ねる

短くする理由は、候補者が募集記事で知りたい中心が「この募集で何をやるか」だからです。「なにを」が長いと、中心にたどり着く前に離れます。

手順5｜募集ごとに書き分ける

職種が複数ある会社は、募集記事ごとに「なにを」を書き分けます。

  1. 同じ事業の別職種：事業の一言は同じでよい。「事業のどこを担うか」を職種ごとに変える
  2. 別の事業の職種：事業の一言から変える。その職種が関わる事業だけ
  3. 総合職：関わる可能性のある事業を挙げ、配属の決まり方を添える。全事業を説明しない
  4. 新卒と中途で同じ職種：「なにを」は同じでよい。変わるのは「何をやるか」と「求める動き方」

書き分けると、募集記事ごとに「自分の仕事の位置」が変わり、候補者はそれぞれの募集で自分を想像できます。全部同じ「なにを」だと、どの募集も同じ会社説明に見えます。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。募集記事を職種ごとに書き分ける時間もお伝えします。

媒体選びを相談する

やりがちな失敗

失敗何が起きるか直し方
会社ページと同じ文章を貼る長くなり、中心に届かない数行に削り、職種の位置を足す
会社の全事業を説明する自分の仕事がどこか分からないこの職種が関わる範囲だけ
業界の言葉で書く候補者に分からない初めて聞く人に分かる言葉で。社外の人に読んでもらう
「事業のどこを担うか」が無い職種の位置が見えない一文足す
沿革や市場の説明を入れる読まれない会社ページへ
「何をやるか」と混ぜる事業の話と仕事の話が分からなくなる分けて書く
全募集で同じ「なにを」どの募集も同じに見える職種ごとに書き分ける
規模を数字だけで書く想像できない様子で書く

最も多いのは、最初の「会社ページと同じ文章を貼る」です。募集記事を作るときに、会社ページから写す作業が習慣になっていると、こうなります。

社内の分担

作業誰が
この職種が関わる事業を一言にする人事（事業部門に確認）
「事業のどこを担うか」配属先の責任者（人事が聞いて書く）
力を入れていること配属先の責任者
業界の言葉の言い換え人事（社外の人に読んでもらう）
会社ページへ委ねる部分の整理人事
職種ごとの書き分け人事
配属先が確認する配属先の責任者

配属先の責任者の時間は、「どこを担うか」と「力を入れていること」を話すことと、確認の2つです。運用代行や代理店が支えられるのは、会社ページとの分担の整理、業界の言葉の言い換えの案、職種ごとの書き分けの型までです。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がWantedlyの募集記事の整備を支えるとき、「なにをやっているのか」のうち、会社ページとの分担を整理することと、業界の言葉を初めて聞く人に分かる言葉に言い換える案は、当社が出せます。ただし、「この職種は事業のどこを担うか」は、配属先の責任者にしか言えません。当社が事業の説明から推測して書くと、「顧客と会う部分」なのか「作る部分」なのかを外し、候補者に間違った位置を見せることになります。当社の役割は、配属先に「この職種は、事業のどの部分を担っていますか」と聞く質問を用意し、答えを一文に整えることです。この一文が募集記事にあるかどうかで、「なにを」が会社の説明か職種の位置かが分かれます。聞くのは企業、整えるのは当社でも構いません。聞かずに写さないことだけが、条件です。

まとめ

  • 募集記事の「なにをやっているのか」は、会社全体ではなく「この職種が関わる範囲の事業」を書く
  • 会社ページに全体を任せ、募集記事では「この職種は事業のどこを担うか」を数行で。「会社全体は会社ページで」の一言を添える
  • 初めて聞く人に分かる言葉で。業界の言葉と社内用語は言い換え、社外の人に読んでもらって確かめる
  • 沿革、複数事業の一覧、市場の説明は書かない。「この募集で何をやるか」とは分けて書く
  • 職種が複数なら、募集ごとに「事業のどこを担うか」を書き分ける

よくある質問

会社に事業が1つしかありません。会社ページと同じになりませんか

事業の一言は同じでも、「この職種は事業のどこを担うか」は職種ごとに違います。顧客と会う部分か、作る部分か、支える部分か。そこを一文足せば、会社ページと同じにはなりません。会社全体の説明は会社ページに委ね、募集記事は数行にします。

業界を知っている人に来てほしいので、業界の言葉で書いてよいですか

業界を知っている人にも、分かる言葉で書いた募集記事は読めます。逆に、業界の言葉で書くと、業界を知らないが仕事内容で選びたい候補者に届きません。「なにを」は分かる言葉で書き、業界の知識が要るなら「求める動き方」や「何をやるか」で示します。

募集記事の「なにを」の整理は、御社に相談できますか

できます。当社は、会社ページとの分担の整理、業界の言葉の言い換えの案、職種ごとの書き分けの型を支えられます。「この職種は事業のどこを担うか」は、配属先の責任者に聞いていただきます。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの募集記事の整備を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
