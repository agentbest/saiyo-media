Greenでテックリード・CTO候補を採る｜経営との距離を書く

テックリードやCTO候補の求人では、使っている技術や開発の環境を詳しく書く会社が多い一方で、経営との距離について書いている求人票は多くありません。しかし、この立場の候補者が転職先を選ぶときに重視するのは、技術の判断が経営の判断とどうつながっているかです。技術的な提案が事業の計画に反映されるのか、それとも決まった計画を技術で実現するだけなのか。この記事では、Greenでテックリード・CTO候補を採るときに、経営との距離をどう書き、どう選考で確かめるかを整理します。ここで取り上げるGreenは、株式会社アトラエが運営する、IT・Web業界の中途採用を主に扱う求人サイトです。

テックリードとCTO候補の違いを先に決める

まず、自社が求めているのがどちらなのかを決めます。両者は重なる部分もありますが、経営との距離が違います。

立場主な責任経営との距離
テックリード技術の方針、設計の判断、コードの品質、メンバーへの技術的な助言技術の判断を事業側に説明し、合意を取る
CTO候補上記に加え、技術組織の方向、採用、技術への投資の判断経営の一員として、事業計画そのものに関わる

「CTO候補」と書く場合は、どのような道筋でCTOになるのかを示します。「入社後はテックリードとして開発を率い、組織の拡大に合わせて役員への登用を検討する」のように、時期や条件を可能な範囲で書きます。道筋が書かれていないと、候補者は「候補」という言葉を、具体的な約束のない呼び名だと受け取ります。

経営との距離を測る4つの項目

経営との距離は、次の四つの項目で具体的に書けます。

  1. 会議への参加：経営会議や事業の計画会議に出るか。出るなら、発言の位置づけは報告か、議論の参加者か
  2. 技術投資の決め方：インフラの刷新や、技術的な負債の返済に時間を割くことを、誰がどう決めるか
  3. 事業計画への関わり：新しい事業や機能の計画を立てるとき、技術側の見立てがいつ求められるか
  4. 採用と組織：エンジニアの採用人数や、チームの編成を誰が決めるか

この四つを求人票に書くと、候補者は経営との距離を自分で判断できます。すべてを最大の関わりにする必要はありません。「現在は経営会議に出ていないが、入社後半年をめどに参加してもらいたい」のように、今と今後を分けて書きます。

テックリードとCTO候補のどちらで募集するか、経営側の考えの整理からご一緒します。

無料で相談する

エージェントベストの見解

CTO候補の採用を相談される会社で、先に確かめておきたいのは「今の経営陣の中で、技術の判断を最終的に下しているのは誰か」です。創業者自身がエンジニアで、技術の判断も握っている会社では、CTO候補が入っても判断がぶつかりやすくなります。創業者に技術の経験がなく、外部の開発会社に頼ってきた会社では、CTO候補に期待することが広すぎて、何から手をつけるべきか本人が迷います。どちらの場合も、採用を始める前に、創業者が手放す判断と、手放さない判断を書き出しておくと、求人票の内容がはっきりします。当社は、この整理ができてから求人票に取りかかる順番を勧めています。整理が終わる前に候補者と会うと、面接のたびに説明が変わってしまうからです。

求人票に書く技術の情報

経営との距離に加えて、技術の情報も書きます。テックリード・CTO候補の候補者は、技術の現状を細かく見ます。

  • 使っている技術と、選んだ理由：なぜその言語や構成にしたのかを一文添える
  • 技術的な負債の状況：古い仕組みが残っているか、置き換えの計画はあるか
  • 開発チームの規模と経験：何人いて、どのくらいの経験の人が多いか
  • 外部の開発会社との関係：外部に任せている部分があるか、内製に切り替えたいか

開発チームがまだいない、または外部の開発会社に頼っている会社の場合は、そのことを冒頭に書きます。「一人目の社員エンジニアとして、内製の体制を作るところから」と書けば、立ち上げに関わりたい候補者が反応します。反対に、すでに数十人規模の組織がある会社なら、テックリードが見る範囲をチーム単位で示し、ほかのテックリードとの役割分担も書いておくと、候補者は自分の位置を想像しやすくなります。

技術的な負債については、隠さずに書くほうが良い結果につながります。負債の解消に取り組みたい候補者にとっては、それが仕事のやりがいになるからです。

声をかける相手の選び方

技術の責任者クラスに対しても、Greenでは企業側から「気になる」やスカウトを送れます。テックリード・CTO候補の候補者は、すでに現職で重要な立場にいることが多く、転職の意欲が強くない人も含まれます。

声をかけるときは、次の点を意識します。

  • 送り主を経営者または技術責任者にする：人事からの文面より、経営者や今の技術責任者からの文面のほうが、この立場の候補者には届きやすい傾向があります
  • いきなり選考に誘わない：まずは経営者と話す場を提案し、事業の方向を説明する
  • 経営との距離を一文で書く：「経営会議に参加していただき、技術の観点から事業計画に意見をもらいたい」

技術者へのスカウト文面の組み立ては、エンジニア向けスカウト文面の型でも整理しています。

選考で確かめること

選考では、技術の力と、経営の言葉で話す力の両方を確かめます。

  • 技術的な投資を、事業の言葉で説明して通した経験
  • 技術の判断と事業の要望がぶつかったとき、どう折り合いをつけたか
  • 技術組織を大きくするとき、何を最初に整えたか

技術面では、自社の現在の構成を見せたうえで、「一年後に同じ構成のままでよいか、変えるなら何からか」を話してもらう方法があります。既存の仕組みを尊重しながら変える順番を考えられるかどうかは、テックリードにとって欠かせない資質です。

選考の後半では、経営者との面談を複数回設けることもあります。経営との距離を確かめたいのは候補者も同じで、経営者と何度か話すことで、入社後の関係を想像できるからです。

候補者との面談の日程調整や連絡を任せて、経営者が話すことに時間を使える形もご提案できます。

運用の相談をする

エージェントベストの見解

テックリードやCTO候補を求人型の媒体で探す場合と、紹介で探す場合では、出会える候補者の層が違います。どちらの経路にも関わってきた経験では、Greenのような求人型で反応があるのは、現職で技術的な判断を担ってきて、より経営に近い立場を自分で探している人が中心です。こうした人は、求人票に経営との距離が書かれていれば、自分から比べて判断します。一方、今の会社で十分に評価されていて、自分からは動かない人に会うには、紹介の担当者が背景を説明しながら声をかけるほうが向いています。CTO候補を急いで採りたい会社ほど、どちらか一方に絞らず、求人票を整えたうえで両方を並行させることを勧めています。

まとめ

  • テックリードとCTO候補は、経営との距離が違う。どちらを求めるかを先に決める
  • CTO候補と書くなら、CTOになるまでの道筋を示す
  • 経営との距離は、会議・技術投資・事業計画・採用と組織の四項目で書く
  • 技術的な負債は隠さず書く。解消に取り組みたい候補者にとってはやりがいになる
  • 声をかけるときは、経営者や技術責任者を送り主にし、まず話す場を提案する

よくある質問

CTO候補を募集するとき、役員の約束は書いたほうがよいですか

約束できないことを書くのは避けます。登用を検討する時期や条件を可能な範囲で書き、確約ではないことを明記します。曖昧な約束は、入社後の信頼を損ないます。

技術顧問や副業の人をテックリードにすることはできますか

関わる時間が限られる場合、技術の方針を決める役割は担えても、日々の判断やメンバーへの助言は難しくなります。常勤のテックリードを採るまでのつなぎとして活用する会社もあります。

エンジニアリングマネージャーとテックリードのどちらを先に採るべきですか

いま足りないのが技術の判断なのか、人を見る仕組みなのかで決まります。組織の課題が中心ならGreenでエンジニアリングマネージャーを採るも参考にしてください。
