OfferBox経由の学生から、質問が来る。条件、配属、仕事の中身、選考の流れ、働き方。答えようとすると、答えを持っていない、答えてよいか分からない、現場に聞かないと分からない、同じ質問が何度も来て時間が取られる。答えが遅れ、曖昧になり、学生が離れる。結論から言うと、答えきれない理由は四つです。答えを人事が持っていない、答えてよいか判断できない、答える人が決まっていない、質問が多すぎる。理由ごとに直します。答えを先に集め、答えてよい範囲を管理部門と決め、質問の種類ごとに答える人を決め、繰り返す質問を企業ページと募集要項に戻します。当日に「いつまでに答えるか」だけは返し、面談に持ち越す質問はそう伝え、答えられない質問には正直に答え、質問を記録します。 この記事では、四つの理由と直し方、当日の返し方、面談への持ち越し、正直な答え方、記録、分担を整理します。質問に答える文面の型はOfferBoxで学生からの質問に答える文面で書きました。この記事は、「答えきれない」状態の直し方です。

この作業の目的｜質問を、「答える」から「先に置いておく」に変える

学生の質問は、一つ一つ答えるものに見えますが、多くは「企業ページと募集要項に書かれていれば、来なかった質問」です。答えきれないのは、答える力の問題ではなく、答えを先に置いていないことから起きます。

目的は、質問に速く答えることと、質問そのものを減らすことの、両方です。

答えきれない、四つの理由

理由サイン直し方
1. 答えを持っていない条件、配属、研修、転勤の質問に、人事が即答できない。管理部門や現場に聞いてから答えを先に集めて一枚にする
2. 答えてよいか分からない「この条件を言ってよいのか」「配属の見込みを伝えてよいのか」で止まる答えてよい範囲を、管理部門と責任者と先に決める
3. 答える人が決まっていない仕事の中身の質問を現場に転送し、返事が来ない。誰が答えるかが曖昧質問の種類ごとに、答える人と期限を決める
4. 質問が多すぎる同じ質問が学生ごとに来る。答える時間が送る時間を圧迫する繰り返す質問を企業ページと募集要項に戻す

四つは、重なることがあります。「答えを持っていない」うえに「答えてよいか分からない」なら、一枚を作るときに範囲も決めます。

1. 答えを、先に集めて一枚にする

  • よく来る質問を、種類ごとに並べる：条件（給与・休日・勤務地・転勤）、配属、仕事の中身、研修、選考の流れ、働き方（残業・在宅・休みの取り方）
  • それぞれの答えを、管理部門と現場から集める：事実で。「〜の予定」「〜を検討中」は、そのまま書く
  • 一枚にして、送る人と面談に出る人が持つ：「質問が来たら、この一枚を見る」
  • 年度で変わるものは、年度の公表内容と自社の方針を確認して更新する
  • 答えが「決まっていない」ものは、「決まっていない」と一枚に書く：決まっていないことを、学生にも正直に言える

一枚があれば、質問の多くは当日に答えられます。

2. 答えてよい範囲を、先に決める

  • 条件で、どこまで伝えてよいか：募集要項に書いたことは伝えてよい。書いていないことは、管理部門に確認
  • 配属の見込みを、伝えてよいか：「〇〇の可能性が高い」と言えるか、「入社後に決まる」と言うか。責任者と決める
  • 働き方の実態を、どこまで伝えてよいか：残業の時期、在宅の実態。事実として伝えてよい範囲
  • 答えてよくない質問は、「お答えできません」と、理由を添えて：「決まっていないため」「個別には決められないため」
  • 範囲を決めたら、一枚に印をつける：「伝えてよい」「確認が要る」「伝えられない」

範囲が決まっていれば、「答えてよいか」で止まる時間が消えます。条件の伝え方は給与水準を強みにできない会社のOfferBoxの伝え方で書きました。

いま使っている媒体の運用の相談だけでも構いません。答えきれない理由が四つのどれかを、最近の質問から一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「学生の質問には、一つ一つ丁寧に答えるのが誠実だ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、一つ一つ答えている会社の質問の記録を見ると、同じ質問が学生ごとに繰り返されていて、その答えは企業ページにも募集要項にも書かれていません。学生は、書かれていないから聞いていて、聞く前に読める場所にあれば、聞きません。当社が「答えきれない」の相談を受けるとき、最初にやるのは、答え方の型を渡すことではなく、最近の質問を種類ごとに数えて、繰り返されている質問を企業ページと募集要項に戻すことです。戻すと、質問が減り、残った質問は「その学生だけの質問」になり、そこに時間を使えます。

3. 質問の種類ごとに、答える人と期限を決める

質問の種類答える人期限
条件（募集要項に書いてあること）人事。一枚を見て当日当日
条件（書いていないこと）管理部門に確認して人事翌日まで
配属の見込み責任者と決めた範囲で人事当日
仕事の中身現場の人。人事が転送し、期限を伝える二日以内。無理なら面談で
選考の流れ人事。一枚を見て当日当日
働き方の実態人事。一枚を見て当日。細かい点は現場当日か面談で
答えられない質問人事。「お答えできません」と理由当日

「現場に転送して返事が来ない」を防ぐには、転送時に期限を伝え、期限を過ぎたら「面談でお答えします」に切り替えます。

4. 繰り返す質問を、企業ページと募集要項に戻す

  • 月に一度、質問の記録を種類ごとに数える：多い質問が、書かれていない質問
  • 多い質問の答えを、企業ページか募集要項に書く：条件は募集要項、仕事と働き方は企業ページ
  • 文面の「話す場」の一文に、「詳しくは企業ページに」を添える：聞く前に読める場所を示す
  • 書いたあと、その質問が減ったかを翌月見る
  • 減らない質問は、書き方が分かりにくいか、書いた場所が見つけにくい

企業ページの作り方はOfferBoxの企業ページで伝えること・伝えないこと、募集要項はOfferBoxの募集要項の書き方、質問を蓄積して戻す手順はOfferBoxで学生からの質問に答える文面の手順5で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。質問の一枚と答える人の分担を作る時間をお伝えします。

媒体選びを相談する

当日に、「いつまでに答えるか」だけは返す

  • 答えが今日出なくても、今日、一言返す：「ご質問ありがとうございます。〇〇に確認して、△日までにお答えします」
  • 期限を守る：守れなければ、期限の前にもう一度連絡する
  • 「確認中です」だけで終えない：いつまでかを書く
  • 質問が複数なら、答えられるものは当日に、残りは期限を書いて：全部を待たせない

「当日に一言」が、学生の側の「返事が来ない会社」を防ぎます。承認への対応の速さと同じです。OfferBoxの即日対応

面談に持ち越す質問の、伝え方

  • 文面で答えるより、面談で話したほうがよい質問がある：仕事の中身、働き方の実態、配属の見込み
  • 「面談で、〇〇さんから直接お話しします」と、誰が答えるかを添える：「面談で」だけでは、はぐらかしに見える
  • 面談に出る人に、その質問を先に渡す：面談で「聞いていません」にならないように
  • 面談の日程が先なら、文面で概略だけ答えて、詳しくは面談で：全部を持ち越さない

面談の設計はOfferBoxの面談設計で書きました。

答えられない質問への、正直な答え方

  • 決まっていないなら、「決まっていません」：「検討中です」で濁さない
  • 個別に決められないなら、「入社後に、〇〇の時点で決まります」：決まる時期と、決める人を
  • 伝えられない理由があるなら、「お答えできません。理由は〇〇です」：理由を添える
  • 「良い答え」を作らない：作った答えは、入社後に戻ってくる
  • 答えられないことが多い質問は、社内で「決める」ことを検討する：決まっていないこと自体が、学生の判断を止めている

答えにくい質問の書き方はOfferBoxで学生からの質問に答える文面の手順4で書きました。

質問の記録の残し方

  • 質問と答えを、学生ごとに台帳に一行：「質問：〇〇。答え：△△。答えた日」
  • 種類ごとに印をつける：月に一度数えるため
  • 答えられなかった質問に印をつける：「決める」ことを検討する材料
  • 同じ学生から続けて来る質問は、その学生の関心：面談の材料
  • 内定後の質問は、別の項目で：内定者の不安の材料。OfferBoxで内定を出したあとのフォロー

社内の分担

作業誰が
質問を種類ごとに並べ、答えを集めて一枚にする人事
答えてよい範囲を決める管理部門と責任者
質問の種類ごとに答える人と期限を決める人事責任者

運用代行や代理店が支えられるのは、質問の一枚の型、答える人の分担の型、答え方の型、企業ページと募集要項への戻し方の案、記録の型までで、答えの中身、答えてよい範囲の決定、答えること、面談は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これはどこまでやるかの線引きの話です。当社がOfferBoxで「学生の質問に答えきれない」という相談を受けたとき、当社が持てるのは、質問の一枚の型と、答える人の分担の型と、答え方の型と、企業ページに戻す案までです。答えの中身は、会社の中にしかありません。当社が線を引くのは、「学生の質問に、代わりに答えてほしい」という依頼です。当社が答えると、学生は「会社の人ではない人が答えた」と受け取り、面談で「話が違う」が起きることがあります。当社がお願いするのは、質問の一枚を会社で作ることで、一枚があれば、送る人が当日に答えられ、当社が答える必要はなくなります。

まとめ

  • 答えきれない理由は、答えを持っていない・答えてよいか分からない・答える人が決まっていない・質問が多すぎる、の四つ。理由ごとに直す
  • 答えを先に集めて一枚にし、答えてよい範囲を管理部門と責任者と決めて印をつける。「決まっていない」もそのまま書く
  • 質問の種類ごとに答える人と期限を決め、現場に転送するときは期限を伝え、過ぎたら面談に切り替える
  • 繰り返す質問は月に一度数えて企業ページと募集要項に戻し、翌月減ったかを見る。残った質問がその学生だけの質問
  • 答えが今日出なくても当日に「いつまでに」を返し、面談に持ち越すなら誰が答えるかを添え、答えられないなら理由を添えて正直に

よくある質問

現場に転送した質問の返事が、いつも遅れます

転送するときに期限を伝え、過ぎたら「面談でお答えします」に切り替えて、学生には先にそう伝えます。現場に、質問の答えを「面談で話す材料」として渡すと、文面で返す負担が減り、面談で答える形に変わります。同じ質問が続くなら、現場に一度聞いて一枚に書き、次からは人事が答えます。

「決まっていません」と答えると、学生が離れませんか

「検討中です」で濁して、面談や内定時に「決まっていなかった」と分かるほうが、離れ方が重いです。「決まっていません。〇〇の時点で決まります」と、決まる時期を添えれば、学生は判断できます。決まっていないことが多いなら、社内で「決める」ことを検討する材料にします。

学生からの質問への対応は、御社に相談できますか

できます。当社は、質問の一枚の型、答える人の分担の型、答え方の型、企業ページと募集要項への戻し方の案、記録の型を支えられます。答えの中身、答えてよい範囲の決定、答えること、面談は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • 福利厚生が弱い会社のOfferBoxでの見せ方｜一覧を並べず、あるものは事実で、ないものはないと書き、「働き方の実態」と「働く人」で学生が判断できる材料にする
  • 募集職種が多い会社のOfferBox運用｜全職種を同時に回さず、「現場の一文が取れる職種」から順に回し、職種ごとに型と名義と面談に出る人を持つ
  • OfferBoxのオファー文面が書けないときの整理法｜「書けない」を四つに分け（材料がない・相手を読んでいない・何を伝えるか決まっていない・上手く書こうとしている）、原因ごとに埋める
  • OfferBoxのオファー文面がマンネリ化したとき｜マンネリの正体は「型」ではなく「空欄が埋まらなくなったこと」。型は変えず、学生の一文の拾い方と現場の一文の鮮度を戻し、承認の記録で直す場所を決める
