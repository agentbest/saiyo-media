ワンキャリアの採用管理システム（ATS）｜できることと、ワンキャリア経由の応募が自動でつながる範囲

公開 2026-09-30

  2. 仕組み｜ワンキャリアとつながる部分
  3. 確認する項目｜導入の前に決める5つ
  4. 注意点

新卒採用の応募者の管理を、スプレッドシートや複数の媒体の管理画面で続けていると、「いま誰がどの段階にいるか」を集計するだけで週の何時間かが消えます。ワンキャリアには、こうした管理を一つにまとめる採用管理システム（ATS）があります。結論から言うと、ワンキャリアのATSは、応募の受付から選考・入社までを一元管理し、採用HP・ナビ・イベント・紹介会社など全経路の応募を1画面に集めるものです。ワンキャリア経由の応募者の個人情報は自動で連携され、新規契約の企業には初年度無料のプランがあります。料金の金額は公開されていません。 この記事では、公式ページで確認できる機能と、導入の前に社内で決めておくことを整理します（2026年9月30日時点。最新は公式ページでご確認ください）。

結論｜ATSでできること

採用管理システムのページに出ている機能は、大きく分けて次の4つです。

機能公式ページでの説明
一元管理応募受付から選考・入社までを一元管理
進捗と歩留まりの見える化選考フロー別に、進捗と歩留まりを見える化
全経路の集約採用HP・ナビ・イベント・紹介会社などの応募を1画面に集約
アンケートアンケートの作成と配信

費用について、求人掲載のページには「初年度無料プランあり（新規契約の企業に限る）」と書かれています。2年目以降の金額や、プランごとの違いは公開情報では確認できません。見積もりの段階で確かめます。

仕組み｜ワンキャリアとつながる部分

ワンキャリア経由の応募は自動で入る

ワンキャリア経由で応募した学生の個人情報は、ATSに自動で連携されると説明されています。媒体の管理画面から応募者を書き写す手間がなくなる、ということです。

さらに、学生が登録していれば、他社の内定・選考状況やインターンの参加実績をATS上で見られるとされています。対象は、自社に応募し、かつプロフィールにその情報を登録している学生だけです。応募していない学生や、登録していない学生の情報は見られません。

連携できない場面がある

公式ページには、一部のライブイベントはATSと連携できない（今後リリース予定）と書かれています。イベントから来た学生を管理するときは、どのイベントが対象外なのかを導入時に確かめ、対象外のものは別の方法で取り込む段取りを決めておきます。

外部ツールとの連携

面接の日程調整に関わるツールとの連携として、Googleカレンダー（面接官の空いている日程の抽出）と、Zoom・Google Meet（会議のURLをワンクリックで発行）が挙げられています。ほかのツールとも順次連携する予定とされています。日程の候補を出してURLを送るまでの手作業は、応募が増える時期ほど積み上がるので、面接官の予定をGoogleカレンダーで管理しているかどうかは、導入前に確かめておく項目の一つです。予定を紙や別の仕組みで管理している面接官が多い場合、この連携の効き目は小さくなります。

すでに別の採用管理システムを使っている会社が、ワンキャリアの応募をそちらに流す話は、ワンキャリアと採用管理システムの連携で分けて書いています。

ATSを入れるか、いまの管理方法のまま媒体だけ足すか。応募の経路から一緒に整理します。

運用の相談をする

エージェントベストの見解

ATSの導入で先に決めておかないと効果が出ないのは、「選考フローの段階の名前」です。ATSは選考フロー別に歩留まりを見える化しますが、段階の切り方が決まっていないまま入れると、ある担当は「一次面接」、別の担当は「面談」と登録して、あとで数字が比べられなくなります。当社は3媒体の販売パートナーとして申し込み後の運用も見ていますが、管理の道具を替えても歩留まりが見えない会社は、たいてい段階の定義が人によって違います。導入の前に、エントリーから内定承諾までを5〜7段階ほどに分け、各段階に「何が起きたら次に進めるか」を一行で書いておきます。これが決まっていれば、ATSの画面は初日から比べられる数字になります。ATSを選ぶ前に、段階の表を一枚作るのが順番です。

確認する項目｜導入の前に決める5つ

  1. 管理する経路の一覧：採用HP、ナビ、イベント、紹介会社など、どこから応募が来るかを書き出します。ATSは全経路を1画面に集めるものなので、経路が曖昧だと集計も曖昧になります
  2. 選考の段階と進める条件：上の見解で書いたとおりです
  3. 連携できないイベントの扱い：一部のライブイベントは連携できないとされています。対象を確かめ、取り込み方を決めます
  4. 他社の選考状況をどう使うか：自社に応募し登録している学生の、他社の内定・選考状況が見られます。面談で何を聞くかの準備に使うのか、見るだけにするのかを決めておきます
  5. 2年目以降の費用：初年度無料は新規契約の企業に限る扱いです。2年目の金額と契約の形を、申し込む前に聞いておきます

段階ごとの数字の見方はワンキャリアの効果測定と選考途中で学生が離れるときの見直しも参考になります。

注意点

  • 料金の金額は公開されていない：公開されているのは「初年度無料プランあり（新規契約の企業に限る）」までです
  • 他社の選考状況が見えるのは一部の学生だけ：自社に応募し、プロフィールに登録している学生に限られます
  • 一部のライブイベントは連携できない：今後リリース予定とされています。導入時点の対象を確かめます
  • 外部ツールは今後増える予定：現時点で挙げられているのはGoogleカレンダー、Zoom、Google Meetです
  • 使える機能はプランで異なる場合がある：ワンキャリアの各機能ページには、使える機能はプランによって異なると注記されています

料金は各媒体の正規料金のままです。初年度無料の条件も含めて、比較だけでもどうぞ。

無料で相談する

エージェントベストの見解

ATSを入れた会社で、半年ほどたって起きやすいのは「ワンキャリアの応募だけがきれいに入っていて、ほかの経路が抜けている」状態です。ワンキャリア経由の応募は自動で入りますが、採用HPや紹介会社から来た応募は、取り込みの手順が決まっていないと手入力のまま漏れます。すると、ATSの歩留まりはワンキャリアの数字に偏り、経路どうしの比較ができません。当社が導入時にお伝えしているのは、自動で入る経路と、人が入れる経路を分けて一覧にし、人が入れる経路には担当者と締め切り（応募から何日以内に登録するか）を決めることです。全経路を1画面に集められる道具でも、集めるのは人の段取りです。自動連携の便利さに頼るほど、手で入れる経路の抜けが目立たなくなる点に気をつけます。

まとめ

  • ワンキャリアのATSは、応募受付から入社までの一元管理、選考フロー別の歩留まりの見える化、全経路の応募の集約、アンケートの作成・配信ができる
  • ワンキャリア経由の応募は自動で連携され、登録している応募者については他社の選考状況も見られる
  • 一部のライブイベントは連携できない。外部ツールはGoogleカレンダー、Zoom、Google Meetと連携
  • 新規契約の企業には初年度無料プランがある。金額は公開されていない
  • 導入の前に、選考の段階の定義と、手で入れる経路の担当を決める

よくある質問

ワンキャリアのATSの料金はいくらですか

公式ページに金額は出ていません。求人掲載のページに「初年度無料プランあり（新規契約の企業に限る）」とあるだけです。2年目以降の費用は見積もりで確かめます。

ワンキャリア以外から来た応募も管理できますか

公式ページでは、採用HP・ナビ・イベント・紹介会社など全経路の応募を1画面に集約できると説明されています。ワンキャリア経由は自動で連携されますが、それ以外の経路をどう取り込むかは導入時に確認します。

ATSの導入だけ、御社に相談できますか

できます。当社はワンキャリアを含む3媒体の販売パートナーとして、媒体とあわせて管理の方法も相談を受けています。初めてワンキャリアを使う会社の最初の段取りは初めてワンキャリアを使うときの最初の30日にまとめています。

媒体選びを相談する

あわせて読む

  • ワンキャリアを代理店経由で申し込むメリット｜販売パートナーの3つの型と、申し込む前に確かめること
  • ワンキャリアのプランの選び方｜3つの代表プランは「何に困っているか」で分かれている
  • ワンキャリアのキャンペーンの種類と申込時期｜公開されているのは「新規向け」中心、締切は公表されていない
  • ワンキャリアのイベント枠の料金の見方｜「1回いくら」の前に、回ごとに何が付くかを確かめる
