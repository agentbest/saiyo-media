IT・Web業界の会社がWantedlyで採用するときの設計

公開 2026-09-21

  2. 自社の区分を、会社ページの最初に書く
  3. エンジニアと非エンジニアの入口を分け、技術スタックとリモートを実態で
  4. ストーリーとカジュアル面談の設計

SIer、SES、Web系自社開発、SaaS、ゲーム、ネット広告、メガベンチャー、受託開発、ITコンサル、大手の子会社・DX部門が、Wantedlyで採用する。候補者の「IT業界志望」は、この全部を一語で指していて、Wantedlyにはその全部が並んでいる。並ぶ中で、候補者が持っている像は一つ——Web系自社開発の、自分でコードを書き、製品を作り、裁量がある会社——で、自社がどの区分かを会社ページの最初に書かないと、その像で「話を聞きに行きたい」が押され、面談でSIerの「作らせて管理する」、SESの常駐、SaaSの分業、受託の納期とクライアントの仕様、ネット広告の数字を聞いて離れる。結論から言うと、IT・Webの会社のWantedlyは、自社がどの区分かを会社ページの最初に書きます。「IT企業です」「エンジニアが活躍」で書かず、「〇〇業界の顧客に△△を提供している自社開発の会社」「□□の工程を受託で担っている会社」「常駐が〇〇の割合のSES」と、区分と顧客と作る割合で書きます。区分ごとにWantedlyとの相性が違い、Web系自社開発・SaaS・スタートアップは向いていて、並ぶ中で「何を決められるか」と技術スタックとリモートの実態で区別され、SIer・SESは書き方を変えて、作る割合と常駐の割合を先に書きます。エンジニアと非エンジニアの入口を分け、副業・業務委託の入口を正社員と分けます。 この記事はIT・Webの総論で、区分ごとの各論はSIer、SES、SaaS、ゲーム、スタートアップ、広告で書きました。媒体の選び方はIT・Web業界の採用媒体の選び方で書きました。数値と料金は書きません。

自社の区分を、会社ページの最初に書く

  • 「IT企業です」「エンジニアが活躍する会社」で書かない：どの区分にも当てはまり、Web系自社開発の像で読まれる
  • 「なにを」は、区分と顧客と作る割合で一言：「〇〇業界の顧客に△△を提供している自社開発の会社」「□□の工程を受託で担っている会社」「常駐が〇〇の割合のSES」「△△を要件定義から管理するSIer」
  • Web系自社開発とSaaSは、並ぶ中で「何を決められるか」で：「〇〇の技術選定は担当が決める。△△はPdMが決める。□□は決まっていない」。「裁量がある」の一語で済ませない。Wantedlyの募集記事「こんなことやります」の書き方
  • SIer・SES・受託は、作る割合と常駐の割合と仕様の実態を先に：Web系の顔で書くと、像で押されて離れる
  • 「こんな人」は、区分ごとの記述で：自社開発なら「〇〇を作って運用した」、SIerなら「要件を決めて工程を管理した」、SESなら「常駐先で一人で判断した」。「ITに興味がある」「エンジニアになりたい」で絞らない

いま使っている媒体の運用の相談だけでも構いません。会社ページが「IT企業です」でWeb系自社開発の像を呼んでいないか、自社の区分と顧客と作る割合が最初に書かれているか、区分に合った書き方になっているかを一緒に見ます。

運用の相談をする

エージェントベストの見解

これは切り分けの話です。IT・Webの会社から、「Wantedlyに会社ページを作ったが、他のIT企業と差がつかない」と相談されることがあります。当社は3媒体すべての販売パートナーとして、Wantedlyの運用を見ていますが、差がつかない理由の多くは、SIer・SES・Web系自社開発・SaaS・受託という仕事の違う会社が、同じ「IT企業」「エンジニアが活躍」「最新技術」の顔で書いていることです。候補者はWeb系自社開発の像で読み、面談で実態を聞いて離れます。当社がお願いしているのは、自社の区分を会社ページの最初に書き、区分ごとに書くことを変えることです。自社開発とSaaSは「何を決められるか」と技術スタックで、SIerとSESは作る割合と常駐の割合で、受託は仕様と納期で。分けると、「この区分の、この仕事に向く人」が押します。

エンジニアと非エンジニアの入口を分け、技術スタックとリモートを実態で

  • エンジニアの募集と、非エンジニア（営業、CS、マーケ、コーポレート）の募集を分ける：「IT企業で働きたい」で非エンジニアがエンジニアの募集に押す
  • 技術スタックを、実態で書く：「〇〇を△△の用途で使っていて、□□は移行の途中。〇〇は決まっていない」。「モダンな技術」の一語で済ませない。使っていない技術を並べない
  • リモートの実態を、隠さず：「〇〇の頻度で出社。△△の職種はフルリモート。□□はオフィス」。「リモート可」の一語で伏せない。Wantedlyでリモートの募集を書くときの設計
  • 副業・業務委託の入口を、正社員と分ける：「何を、どのくらいの期間で、週何時間」を最初に。Wantedlyで副業の募集を書くときの設計

会社ページの書き方はWantedlyの会社ページで最初に書くこと、素顔を出す範囲はWantedlyで会社の素顔を出す範囲で書きました。

ストーリーとカジュアル面談の設計

  • エンジニアのストーリーで、「技術選定を決めた日」「障害の週」を本人の言葉で：Wantedlyのストーリーで事業の中身を書く方法
  • 他の区分から移った人のストーリーで、「何が違ったか」を本人の言葉で：Wantedlyの入社後ストーリーの書き方
  • カジュアル面談で、区分と作る割合と技術スタックとリモートの実態を、聞かれる前に伝える：Wantedlyのカジュアル面談の設計
  • エンジニアの面談に、エンジニアが出る：技術の話は、人事だけではできない

スカウトの設計

  • 絞るのは、区分ごとの記述：自社開発なら「〇〇を作って運用した・技術選定をした」、SIerなら「要件を決めて工程を管理した」、SESなら「常駐先で一人で判断した」。「エンジニア」「IT」の言葉で絞らない。Wantedlyのスカウトで対象を絞る方法
  • 文面は、区分と顧客と、決められることを最初に：「〇〇業界の△△を自社開発していて、技術選定は担当が決められる会社で、あなたの□□を読んで」。「IT企業」「最新技術」で始めない。Wantedlyのスカウト文面の書き方

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。IT・Webの会社で、区分の整理、区分に合った書き方の型、技術スタックとリモートの実態の書き出し、エンジニアが話す時間をお伝えします。

エージェントベストの見解

これは媒体の向き不向きの話です。IT・Webの会社から、「Wantedlyはエンジニア採用に強いと聞いた」と一括りに相談されることがありますが、当社が見ている範囲で、Wantedlyとの相性は区分で違います。Web系自社開発・SaaS・スタートアップは、候補者の像と実態が近く、並ぶ中で「何を決められるか」と技術スタックとリモートの実態を書けば区別され、向いています。SIerとSESは、候補者の像（作る）と実態（管理する、常駐する）が離れていて、Web系の顔で書くと像で押されて離れるので、作る割合と常駐の割合を先に書く形に変えれば動きます。受託とネット広告は、仕様と納期と数字を先に書けば動きます。当社がお願いしているのは、「IT業界」と一括りにせず、自社の区分で相性を見て、区分に合った書き方をすることです。

まとめ

  • 候補者の「IT業界志望」はSIer・SES・Web系自社開発・SaaS・ゲーム・ネット広告・メガベンチャーを一語で指し、像はWeb系自社開発。「IT企業です」「エンジニアが活躍」で書くとその像で押され、管理と常駐と分業と仕様で離れる。自社の区分を会社ページの最初に書く
  • 区分ごとに相性が違う。Web系自社開発・SaaS・スタートアップは「何を決められるか」と技術スタックとリモートの実態で区別される。SIer・SESは作る割合と常駐の割合を先に。受託とネット広告は仕様と納期と数字を先に
  • エンジニアと非エンジニアと副業・業務委託の入口を分ける。技術スタックは使っていない技術を並べず実態で、リモートは「リモート可」の一語で伏せず頻度と職種で
  • エンジニアが「技術選定を決めた日」「障害の週」を、他の区分から移った人が「何が違ったか」を本人の言葉で。エンジニアの面談にエンジニアが出る
  • 区分ごとの各論はSIer・SES・SaaS・ゲーム・スタートアップ・広告で。スカウトは「エンジニア」「IT」ではなく区分ごとの記述で絞り、区分と決められることを最初に

よくある質問

「IT企業」と書かないと、何の会社か分からなくなりませんか

「〇〇業界の顧客に△△を提供している自社開発の会社」「□□の工程を受託で担っている会社」の方が、「IT企業」より何の会社か分かります。「IT企業」の一語はWeb系自社開発の像を呼び、SIer・SES・受託の実態とずれて離れる原因になります。区分と顧客と作る割合で書いてください。

技術スタックは、できるだけ多く書いた方がよいのでは

使っていない技術を並べると、面談でエンジニアに聞かれて分かり、信用を失います。「〇〇を△△の用途で使っていて、□□は移行の途中。〇〇は決まっていない」と、実態と段階で書いてください。エンジニアが見ているのは技術の数ではなく、技術選定を誰が決めるかです。

IT・WebのWantedlyの設計は、御社に相談できますか

できます。当社は、区分の整理、区分ごとの書き方の型、募集記事の型、聞き方の型、面談の型、スカウトの絞る作業を支えられます。作る割合と常駐と技術スタックとリモートの開示、CTOが話すこと、エンジニアが話すこと、面談は、会社が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。
