カスタマーサクセスの長期インターンを採る｜顧客対応の任せ方

SaaSや会員制のサービスを持つ会社では、カスタマーサクセスの仕事を長期インターンの学生に任せたいという声がよく聞かれます。問い合わせへの返答、使い方の案内、利用状況の確認など、日々の仕事量が多い職種だからです。結論から言うと、カスタマーサクセスの長期インターンは「顧客に直接出る前の仕事」から始めて、返答の確認の流れを決めたうえで段階的に顧客対応を任せると、学生にも顧客にも負担の少ない受け入れになります。 初日から顧客の前に立たせるのは、学生にとっても会社にとってもリスクが大きい選択です。この記事では、学生向けの長期インターン求人サイトInfraでカスタマーサクセスを募集する会社に向けて、任せ方の段階と原稿の書き方を整理します。

学生がカスタマーサクセスに惹かれる理由

カスタマーサクセスという職種名は、学生にはまだなじみが薄いものです。それでも応募してくる学生には、いくつかの理由があります。

  • 営業ほど数字に追われたくないが、人と関わる仕事がしたい
  • サービスがどう使われているかを知りたい
  • 将来、企画やマーケティングに進みたく、その前に顧客の声を聞きたい
  • IT企業で働いてみたい

一つ目の理由で応募してくる学生は少なくありません。ただし、カスタマーサクセスにも解約の防止や契約の更新といった目標があります。原稿の段階で「どんな目標を持つ仕事か」を正直に書いておかないと、入ってから想像との違いに戸惑うことになります。

任せ方を三段階に分ける

顧客対応を学生に任せるときは、顧客に見える度合いで段階を分けます。

第一段階：顧客に出ない仕事

  • よくある質問の回答集の整理と更新
  • 使い方の案内資料やマニュアルの下書き
  • 利用状況のデータを見て、使われていない機能や顧客を洗い出す
  • 問い合わせ内容の分類と集計

第二段階：確認を経て顧客に出る仕事

  • 問い合わせへの返答の下書き（社員が確認してから送る）
  • 定型の案内メールの送信
  • オンラインの説明会での補助

第三段階：学生が直接対応する仕事

  • よくある質問の範囲での問い合わせへの一次対応
  • 決められた手順に沿った、顧客への使い方の案内

第一段階の仕事は、地味に見えて学生にとっての学びが大きい仕事です。問い合わせの内容を分類すると、顧客がどこでつまずくかが見えてきます。その理解があってから第二段階に進むと、返答の質が上がります。

エージェントベストの見解

カスタマーサクセスの長期インターンでよくある失敗は、人手が足りないから受け入れたのに、第一段階の仕事を飛ばして問い合わせ対応から任せてしまうことです。学生はサービスの仕組みを知らないまま答えるので、確認の手間がかえって増え、社員の負担が減りません。順番としては、受け入れ後の最初の数週間は問い合わせの分類と回答集の整理に充てるのが効率的です。この作業を通じて、学生はサービスの仕組みと顧客のつまずきを一通り知ることになり、同時に会社には整理された回答集が残ります。第二段階に移ってからの確認の手間も、回答集があることで小さくなります。人手が欲しい時期ほど、最初の数週間を「準備の期間」として確保することを勧めます。

カスタマーサクセスの原稿で、仕事の段階と目標をどう書くか。下書きからお手伝いします。

無料で相談する

名乗り方と、返答の確認の流れ

学生が顧客と接する前に、決めておくことがあります。

  • 名乗り方：「インターン」と名乗るか、部署名で名乗るか。会社としての方針を決める
  • 答えてよい範囲：料金や契約条件、不具合の原因など、学生が答えない話題を決める
  • 確認の流れ：返答を送る前に誰が確認するか、急ぎのときはどうするか
  • 困ったときの引き継ぎ先：顧客が怒っている、判断できない質問が来た、などの場合

名乗り方は会社によって考え方が分かれます。インターンと名乗ると顧客が不安を感じる場合もあり、名乗らないと責任の所在が曖昧になる場合もあります。どちらを選ぶにしても、学生が判断に迷わないように決めておくことが大切です。

確認の流れは、最初は全件、慣れてきたら定型の返答だけは確認なし、のように段階的に緩めていく方法があります。

原稿に書くこと

Infraの原稿では、カスタマーサクセスという言葉の説明から入るより、仕事の中身を具体的に書くほうが伝わります。

  • 担当するサービスと顧客：どんな会社や人が、何のために使っているサービスか
  • 最初の仕事：問い合わせの分類、回答集の整理など、第一段階の仕事
  • 顧客と接するまでの流れ：何週間ほどで返答の下書きを始めるか
  • 持つ目標：解約の防止、利用の定着など、チームとして追っているもの
  • 教える人：カスタマーサクセスの社員が何人いるか

顧客対応の経験がない学生でも、段階が書かれていれば「自分にもできそうか」を判断できます。

面談で見ること

カスタマーサクセスの適性は、話し方の上手さだけでは測れません。面談では次の点を確かめます。

  1. 相手の困りごとを聞き返せるか：質問の意図を確かめてから答える癖があるか
  2. 分からないと言えるか：知らないことを推測で答えずに、確認すると言えるか
  3. 文章で説明できるか：メールやチャットでの返答が中心になるため
  4. 地道な作業を続けられるか：分類や集計を嫌がらないか

面談の中で、自社のサービスについて架空の問い合わせを一つ見せ、「どう返すか」を聞いてみる方法もあります。答えの正しさではなく、何を確かめようとするかを見ます。

顧客対応は問い合わせの波に合わせて残業が生じやすい仕事です。雇用で迎える学生の勤務は、最低賃金と労働時間の決まりの範囲に収め、問い合わせが集中する時間帯は社員が受ける配置にしておきます。

エージェントベストの見解

カスタマーサクセスの長期インターンは、新卒採用の入口としても相性のよい職種です。インターンの間に顧客の声を直接聞いた学生は、サービスの価値を自分の言葉で語れるようになります。当社はInfraの代理店として長期インターンの募集を支援し、新卒向けの媒体も扱っていますが、新卒の選考で「なぜこの会社か」を最も具体的に話せるのは、顧客と接した経験のある学生だと感じます。ただし、それを新卒採用につなげたいなら、インターン中に任せる仕事を問い合わせ対応だけにとどめないことです。問い合わせの分類から見えた改善案を、プロダクトの担当者に伝える場を作る。学生の提案が実際に反映される経験があると、入社後に何ができるかを想像しやすくなります。顧客対応の手としてだけ扱うと、新卒の選考時期に他社と比べたとき、選ぶ理由が残りにくくなります。

長期インターンを新卒採用につなげたい会社に、媒体の組み合わせをご提案しています。

無料で相談する

インターンでの経験が新卒の応募に結びつかないときの見直し方は、長期インターンが新卒採用につながらないときで扱っています。

まとめ

  • 顧客対応は、顧客に出ない仕事・確認を経て出る仕事・直接対応の三段階で任せる
  • 最初の数週間は問い合わせの分類と回答集の整理に充てると、後の確認が楽になる
  • 名乗り方・答えない範囲・確認の流れ・引き継ぎ先は、顧客と接する前に決める
  • 原稿にはカスタマーサクセスが持つ目標も正直に書く
  • 新卒採用につなげるなら、学生の改善案がプロダクトに届く場を作る

よくある質問

電話対応も任せてよいですか

任せること自体はできますが、電話はその場で答える必要があるため、メールやチャットより難しい対応です。メールやチャットでの返答に慣れてから、決まった手順の範囲で始めるのが無難です。答えられない質問が来たときの引き継ぎ方も、先に決めておきます。

顧客からクレームが来たとき、学生はどう対応すべきですか

学生には一次的な受け止めまでを任せ、内容の判断と回答は社員が引き取る形にしておくと安心です。「担当の者から改めてご連絡します」と言える状態にしておけば、学生が一人で抱え込むことを防げます。

カスタマーサクセスの経験がない会社でも募集できますか

社内に専任の担当者がいなくても、問い合わせ対応や使い方の案内をしている社員がいれば、その人が教える役になれます。ただし、学生に「カスタマーサクセスの仕組みを作ってほしい」と期待する場合は、その期待を原稿に書き、仕組みづくりに関心のある学生に届くようにしてください。
