OfferBoxのメッセージ機能の使い方｜承認後に開く窓口と、書いてはいけないこと

公開 2026-09-30

OfferBoxのオファーが承認されると、そこから先は学生とのメッセージのやり取りになります。オファー文は時間をかけて書いても、承認後のメッセージは「とりあえず返す」になっている会社が少なくありません。結論から言うと、OfferBoxのメッセージ機能は、学生がオファーを承認したときに開く、企業と学生のチャット形式の窓口です。使える範囲には利用規約の決まりがあり、サイト外へのエントリーを促すことや、他社サイトの採用ページのURLを載せることなどは禁止事項に入っています。この記事では、公式情報で確認できるメッセージ機能の仕組みと、書いてはいけないこと、返信の体制で確かめる項目を整理します（2026年9月30日時点。最新は公式ページでご確認ください）。

結論｜メッセージは「承認した学生とだけ」つながる窓口

公式情報で確認できるメッセージ機能の仕様をまとめると、次のとおりです。

項目公式情報で確認できること
使えるようになる時点学生がオファーを承認したとき
形式学生とチャット形式でコミュニケーションが取れる
位置づけ1to1の個別メッセージで、企業の魅力を直接届けられる
辞退された場合学生が辞退すると、企業とは連絡が取れなくなる
保留された場合企業に保留理由と、不明点・保留理由詳細のメッセージが届く
i-plugによる確認問い合わせ対応などのため、学生とのメッセージを含む利用状況を確認することがある

つまり、メッセージは誰にでも送れる連絡手段ではなく、オファーを承認した学生との間にだけ開く窓口です。承認前は、保留のときに届くメッセージを除けば、学生と会話をする窓口は開いていないと考えておきます。

仕組み｜承認から面談までの流れの中のメッセージ

「ご利用の流れ」のページでは、OfferBoxの使い方は「本登録 → 学生を探す → オファー送信 → オファー承認 → 学生と会う → 内々定」の順で示されています。メッセージが使われるのは、このうち「オファー承認」から「学生と会う」までの間です。

承認されたとき

学生がオファーを承認すると、企業と学生がメッセージでやり取りできるようになります。ここで面談や説明会の日程を決めていきます。公式の機能ページでは、オファー承認後に選考の日程調整を自動で行う「かんたん日程調整」も紹介されていて、面談やセミナーイベントを作って学生を招待し、申込を管理できます。メッセージで話し、日程は日程調整の機能で決める、という分担ができます。

保留されたとき

学生向けの公式ヘルプによると、学生がオファーを「保留」にすると、企業には保留理由と「不明点・保留理由詳細のメッセージ」が届きます。保留されたオファーは7日後に自動で取り消されるとされているので、学生が書いてきた不明点に答えられる時間は限られています。

辞退されたとき

学生向けの公式ページでは、学生がオファーを辞退すれば、その企業とは連絡が取れなくなると説明されています。辞退のあとにメッセージで引き止めることはできません。

承認後のメッセージを誰がいつ返すか、社内の体制から一緒に考えます。

運用の相談をする

エージェントベストの見解

申し込んだあと、最初の1ヶ月で当社がよく見るのは、オファーを書く担当者とメッセージを返す担当者が違っていて、承認の通知に誰も気づかないまま1〜2日が過ぎる、という状態です。OfferBoxはオファーを書くところに手間がかかる媒体なので、社内の準備もオファー文に集中しがちです。ところが、学生から見ると、承認した瞬間から会話が始まっています。承認したのに返事が来ない間に、ほかの企業との日程が先に埋まっていきます。当社が申込前にお願いしているのは、オファーを送った人がそのままメッセージを返すのか、人事がまとめて返すのかを、送信を始める前に決めておくことです。書いた人が返すなら、オファー文の続きとして自然な会話ができます。人事がまとめるなら、承認の通知を受け取る人と、平日に確認する時刻を決めておきます。どちらでも構いませんが、決めていないことがいちばん承認を無駄にします。返信の速さの考え方は承認からの連絡を早くする体制にまとめています。

確認する項目｜メッセージを使い始める前に

  1. 承認の通知を受け取る人：誰の画面やメールに承認が届くのか、担当者が複数いる場合の分け方
  2. 返信の目安の時間：承認から最初の返信までを、平日なら当日中にするなど、社内の目安を決めます。承認直後の連絡の中身はOfferBoxでオファーが承認されたあとの連絡手順
  3. 保留の不明点に答える人：保留のメッセージには、仕事内容や選考の流れについての質問が来ることがあります。答えられる人を決めておきます
  4. 日程を決める方法：メッセージのやり取りで決めるのか、かんたん日程調整で決めるのか
  5. 面談の前に送る内容：面談の案内に何を書くか。面談前の連絡はOfferBoxの面談前の連絡
  6. 禁止事項の共有：下の「注意点」にある規約の禁止事項を、メッセージを書く全員に共有します

注意点

  • サイト外へのエントリーを促さない：利用規約では、オファー文でサイト外からのエントリーを促すことが禁止事項に入っています。選考の申込はOfferBoxの中で進めます
  • 他社サイトのURLを載せない：他社サイトの合同説明会や採用ページのURLを載せることも禁止事項です
  • 自社や関係会社のサービスを案内しない：学生に自社や関係会社のサービスを案内することも禁止事項に入っています。採用以外の目的でメッセージを使わないようにします
  • メッセージはi-plugが確認することがある：利用規約では、問い合わせ対応などのため、i-plugが学生とのメッセージを含む利用状況を確認することがあるとされています。社外の人が読んでも問題のない書き方をします
  • 保留・返答期限の説明は学生向けヘルプ：企業の画面での表示とは表現が違うことがあります。細かな扱いは担当者に確かめます
  • 最新の内容は公式ページで：規約は卒年ごとに分かれています。自社が申し込むプランの利用規約をご確認ください

相談だけでも構いません。申込前提ではありません。メッセージの書き方や体制も含めてお話しします。

無料で相談する

エージェントベストの見解

メッセージ機能の相談で多い思い込みは、「承認されたら、あとは日程を決めるだけ」というものです。実際には、承認のあとの最初のメッセージで、学生がその企業にどれくらい本気で向き合うかが変わります。承認した学生は、オファー文の中で自分のどこが読まれたのかを覚えています。そこに、どの学生にも同じ定型文で「ご承認ありがとうございます。日程をお送りください」とだけ返すと、オファーで伝えた「あなたを読んで送った」という印象が薄れます。当社が勧めているのは、最初のメッセージに、オファー文で触れた学生の経験に一言だけもう一度触れ、面談で何を話したいかを1行で書くことです。長く書く必要はありません。オファー文とメッセージがつながっていれば、学生は面談の場で話すことを準備してきます。承認後のメッセージは、オファー文の後半だと考えると書きやすくなります。

まとめ

  • OfferBoxのメッセージは、学生がオファーを承認したときに開く、チャット形式の窓口
  • 保留された場合は保留理由と不明点のメッセージが届き、辞退されると連絡は取れなくなる
  • 日程は「かんたん日程調整」でも決められる。メッセージと日程調整の分担を決めておく
  • 規約上、サイト外へのエントリーの誘導、他社サイトのURL、自社や関係会社のサービスの案内は禁止
  • 承認の通知を受け取る人と返信の目安を、送信を始める前に決めておく

よくある質問

オファーを送る前の学生に、メッセージを送れますか

公式情報では、メッセージでやり取りできるようになるのは、学生がオファーを承認したときとされています。承認前の学生との接点は、オファーのほか、検討中リストへの追加（学生に企業名が通知される）などに限られます。オファーの種類の選び方はOfferBoxのオファーの種類と使い分けに書いています。

メッセージで自社の採用サイトへの応募をお願いしてもよいですか

利用規約では、オファー文でサイト外からのエントリーを促すことが禁止事項に入っています。他社サイトの合同説明会や採用ページのURLを載せることも禁止です。選考の申込はOfferBoxの中で進める前提で運用してください。

メッセージの返信を外部に任せることはできますか

利用規約では、本サイトの運用（オファー送信を含む）を日本国内の第三者に委託する場合に限り、その第三者にID等を使わせることができるとされています。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、運用の分担の相談も受けています。企業の料金は各媒体の正規料金のままです。
