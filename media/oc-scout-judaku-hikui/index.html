ワンキャリアでスカウトを送っている。ところが、受諾が来ない。送った数は増えているのに、受諾率が低いまま。「文面が悪いのか」と、文面ばかりを直す。結論から言うと、ワンキャリアの学生は、文面だけでは受諾しません。文面で興味を持ち、企業ページと体験談で確かめてから、受諾します。低い原因は四つ。開かれていない、開かれたが「自分宛」と思われなかった、文面で興味を持ったが企業ページで確かめられなかった、文面で書いたことと体験談がずれている。段で切り分け、原因ごとに直します。受諾率だけを追わず、受諾しなかった学生を追わず、低い期間に通数を増やさず、受諾された文面と受諾されなかった文面を並べます。 この記事では、ワンキャリアの受諾の起き方、四つの原因とサインと直し方、段ごとの見方、追わないこと、通数を増やさないこと、並べて見ること、分担を整理します。スカウトの基本はワンキャリアのスカウトの基本、受諾されたあとはワンキャリアでスカウトが受諾されたあとの連絡、週次の見直しはワンキャリアのスカウトの受諾率を毎週見直す方法で書きました。この記事は、「受諾率が低い」という症状から逆に辿るものです。

この作業の目的｜「文面→企業ページ→体験談→受諾」の流れの、どこで止まっているかを指す

ワンキャリアのスカウトは、文面を読んで受諾するものではなく、文面を読んで企業ページに行き、体験談を読んで、「この会社なら」と確かめてから受諾するものです。文面だけを直しても、企業ページと体験談で止まっていれば、受諾は増えません。

目的は、この流れのどこで止まっているかを指し、そこだけを直すことです。

ワンキャリアの受諾は、こう起きる

  1. 文面が開かれる：件名と送る人の名前で
  2. 文面で「自分宛」と思う：体験談やプロフィールから拾った一文があるか
  3. 企業ページに行き、確かめる：文面で書かれた仕事と選考が、企業ページにあるか
  4. 体験談を読み、確かめる：文面と企業ページで書かれたことが、体験談と揃っているか
  5. 受諾する：「話を聞いてみたい」

他の媒体より、「3」と「4」の段が重いのが、ワンキャリアの特徴です。位置づけはワンキャリアのスカウトの基本の「ワンキャリアのスカウトの位置づけ」で書きました。

受諾率が低い、四つの原因

原因段サイン直す場所
1. 開かれていない1開封の動きが小さい（見える範囲は現在の仕様で確認）件名、送る人の名前
2. 「自分宛」と思われない2開かれているが受諾がない。文面の冒頭が会社説明。学生に触れる一文がプロフィールの見出し学生の一文、冒頭の順番
3. 企業ページで確かめられない3文面は整っているのに受諾がない。企業ページが薄い、文面で書いた仕事や選考が企業ページにない企業ページを文面と揃える
4. 体験談とずれている4企業ページも整っているのに受諾がない。文面で「和やかな面接」、体験談で「厳しかった」文面を体験談と揃える。選考を直す

「1→2→3→4」の順に疑います。文面ばかり直して「3」と「4」を見ないと、受諾は増えません。

いま使っている媒体の運用の相談だけでも構いません。受諾率が低い原因が四つのどれかを、文面と企業ページと体験談から一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「受諾率が低いのは文面の問題なので、文面を直せば上がる」というものです。当社は3媒体すべての販売パートナーとして、ワンキャリアの運用を見ていますが、文面を何度も直しても受諾率が変わらない会社の企業ページを開くと、文面で書いた「最初の一年の仕事」が企業ページになく、体験談には文面と違う選考の様子が書かれています。学生は、文面で興味を持って企業ページに行き、確かめられずに戻り、受諾しません。文面は「入口」で、受諾は「確かめたあと」に起きます。当社が受諾率の相談を受けるとき、最初にやるのは、文面の添削ではなく、文面と企業ページと体験談を三つ並べて、ずれを探すことです。ずれがあれば、直すのは文面ではなく、企業ページか選考です。

1. 開かれていないとき

  • 件名が「スカウトのご案内」になっていないか：学生に触れる一文を件名に。ワンキャリアのスカウトの件名
  • 送る人の名前が、会社名や人事部になっていないか：現場の人か、人事の個人名で
  • 送る時期と時間が、学生の動きと合っているか：ワンキャリアのスカウトを送る時期と時間
  • 開封の動きが管理画面で見えるかは、現在の仕様で確認する

2. 「自分宛」と思われないとき

  • 冒頭が会社説明から始まっていないか
  • 学生に触れる一文が、プロフィールの見出しになっていないか：「〇〇大学の△△学部で」ではなく、学生が書いた行動や、学生が読んだ体験談に近い一文
  • 文面の四つの要素が揃っているか：ワンキャリアのスカウトの基本の「何を送るか」
  • 個人化の範囲が、学生ごとに変わっているか：ワンキャリアのスカウトの個人化
  • 避ける言葉を使っていないか：ワンキャリアのスカウトで避けること

3. 企業ページで確かめられないとき

  • 文面で書いた「最初の一年の仕事」が、企業ページにあるか：ないなら、企業ページに書く
  • 文面で書いた「選考で何を見るか」が、企業ページの選考の流れと揃っているか
  • 企業ページが薄くないか：ワンキャリアの企業ページで最初に書くこと
  • 文面と企業ページのつなぎ方はワンキャリアのスカウトと掲載のつなげ方
  • スカウトを送る前に、企業ページが整っているか：整っていない状態で送らない

4. 体験談とずれているとき

  • 自社の体験談を、全部読む：文面と企業ページで書いていることと、体験談が揃っているか
  • ずれていれば、文面と企業ページを体験談に揃える：体験談のほうが、学生に信じられている
  • 体験談の悪い点を、文面で打ち消さない：「面接は和やかです」と書いても、体験談に「厳しかった」があれば、文面が信じられない
  • 体験談に書かれた選考を、今年の選考で直す：翌年の体験談が変わる
  • 体験談の読み方はワンキャリアの学生目線

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。文面と企業ページと体験談を揃える作業の時間をお伝えします。

媒体選びを相談する

受諾率だけを追わず、段ごとの数と日数で見る

  • 送った→開封→受諾→面談→選考、の段ごとの数：受諾率は「送った→受諾」の一つの割合で、途中の段が見えない
  • 受諾から面談までの日数：受諾されたあとに止まっていれば、受諾率の問題ではない
  • 「こんな人」に近い学生の受諾の数：受諾率が低くても、近い学生が受諾していれば届いている
  • 受諾率を上げるために送る相手を広げると、近い学生の割合が下がる
  • 段の見方はワンキャリアのスカウトのKPI設計

受諾しなかった学生を、追わない

  • 受諾がない学生に、二度、三度と送らない：体験談に「しつこかった」と書かれる
  • 送り直しは一度、間隔を空けて、新しい材料で：それでも来なければ、終える
  • 受諾しなかったことを、台帳に残す：時期が変わったときに、新しい材料で
  • フォローの型はワンキャリアのスカウトの基本の「返信が来たあと」の逆側として、送らない判断も含める

受諾率が低い期間に、通数を増やさない

  • 低い原因が直っていないまま通数を増やすと、低いまま送った数が増えるだけ
  • 通数を増やすと、一通あたりの読む時間が減り、「2」の原因が強くなる
  • 受諾される形を、少数で作ってから増やす：ワンキャリアのスカウト通数の配分

受諾された文面と、受諾されなかった文面を並べる

  • 台帳から、受諾された文面と受諾されなかった文面を数通ずつ
  • 件名、冒頭、学生の一文、仕事の場面、選考で見ること、末尾、で比べる
  • 受諾された学生が読んだ企業ページと体験談も、並べる：文面だけでなく
  • 差が出た場所を、一か所ずつ直す
  • 月に一度、並べる：ワンキャリアのスカウトの受諾率を毎週見直す方法の月の項

エージェントベストの見解

これは数字の読み方の話です。「受諾率が低い」と言う会社の台帳を見ると、「送った数」と「受諾の数」しかなく、その間の開封と、受諾のあとの面談が分かれていないことがあります。当社がワンキャリアのスカウトで見るのは、受諾率ではなく、「開封」「受諾」「受諾から面談までの日数」「近い学生の受諾」の四つで、この四つが分かれていれば、止まっている段が指せます。開封が少なければ件名と名前、開封はあるが受諾がなければ文面と企業ページと体験談、受諾はあるが面談に進まなければ受諾後の対応です。受諾率という一つの数字を上げようとすると、送る相手を広げて数字だけを動かすことになり、近い学生の割合が下がります。

まとめ

  • ワンキャリアの学生は、文面で興味を持ち、企業ページと体験談で確かめてから受諾する。文面だけを直しても、確かめる段で止まっていれば増えない
  • 四つの原因は、開かれていない・「自分宛」と思われない・企業ページで確かめられない・体験談とずれている。この順に疑い、文面と企業ページと体験談を三つ並べる
  • 企業ページが整っていない状態で送らない。体験談の悪い点を文面で打ち消さず、文面と企業ページを体験談に揃え、選考を直して翌年の体験談を変える
  • 受諾率だけを追わず、開封・受諾・受諾から面談までの日数・近い学生の受諾、の四つで見る。受諾率のために送る相手を広げない
  • 受諾しなかった学生を追わず、低い期間に通数を増やさず、月に一度、受諾された文面とされなかった文面を企業ページと体験談ごと並べる

よくある質問

文面を何度直しても、受諾率が変わりません

文面ではなく、企業ページと体験談を見ます。文面で書いた仕事と選考が企業ページにあるか、体験談と揃っているか。ずれていれば、直すのは企業ページか選考で、文面ではありません。文面と企業ページと体験談を三つ並べて、ずれを探すことから始めます。

体験談に悪いことが書かれていて、それが原因だと思います

体験談は、文面で打ち消せません。書かれた選考が実態なら、今年の選考で直し、翌年の体験談に残る形にします。今年の文面と企業ページでは、その点を隠さず、「〇〇については、△△の形にしました」と事実で書きます。実態でないなら、反論せず、今年の選考で守ることを書き、翌年の体験談に「書いてあるとおりだった」と書かれる形にします。

スカウトの受諾率が低いときの見直しは、御社に相談できますか

できます。当社は、四つの原因の切り分け、件名と文面の型、企業ページとのつなぎ方、体験談の読み方の型、並べて見る表の型を支えられます。学生を読むこと、送ること、企業ページの中身、選考の直しは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、ワンキャリアの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
