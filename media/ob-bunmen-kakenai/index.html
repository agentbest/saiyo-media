OfferBoxで送る相手は決まったのに、文面が書けずに手が止まる。この症状は、「文章が苦手だから」で片づけられがちです。ところが、書けない理由は文章力ではなく、書く前の材料と、相手を読むことと、何を伝えるかの決定が欠けていることがほとんどです。結論から言うと、「書けない」を四つに分けます。現場の材料がない、学生のプロフィールを読んでいない、文面で何を伝えるかが決まっていない、上手く書こうとして進まない。原因ごとにサインが違い、埋め方も違います。材料は現場の一文と最初の1年、相手は自由記述から一文を拾う、伝えることは「読んだ・仕事の場面・何を見るか・話す場」の四つ、上手く書かずに型に埋めます。書けない状態で送らず、型で一通目を出して直します。 この記事では、四つの原因とサインと埋め方、型に埋める手順、一通目の出し方、送らない判断、分担を整理します。文面の基本はOfferBoxのオファー文面の基本、型はOfferBoxのオファー文面のテンプレートで書きました。この記事は、それらを「書けない」という症状から逆に辿るものです。

この作業の目的｜書けない原因を見つけて、そこを埋める

書けないときに、文章の書き方を学ぼうとすると、遠回りになります。原因が材料の不足なら、書き方を学んでも材料は増えません。

目的は、書けない原因が四つのどれかを見つけ、そこを埋めることです。上手く書くことが目的ではなく、書けるようにすることです。

「書けない」の、四つの原因

原因何が起きているか埋めるもの
1. 現場の材料がない仕事の具体を、人事が知らない。「事業内容」しか書けない現場の一文と、最初の1年
2. 相手を読んでいないプロフィールを読まずに書こうとしている。「学生の一文」が書けない自由記述から一文を拾う
3. 何を伝えるかが決まっていない文面に何を入れて何を入れないかが決まっておらず、全部書こうとする伝えることを四つに絞る
4. 上手く書こうとしている文章として整えようとして、一文目で止まる型に埋める。整えない

四つは重なることがありますが、最初に埋めるのは「1」と「2」です。材料と相手が揃えば、「3」と「4」は型で解決します。

原因ごとの、サインと埋め方

1. 現場の材料がない

  • サイン：書けるのが会社の説明だけ。「成長中」「風通し」「若手が活躍」で埋まる。仕事の場面が一つも出てこない
  • 埋め方：現場の人に「最初の月に何をするか」を一つ、口頭で聞く。「初日は先輩の打ち合わせに同席」「二週目から小さな案件を一つ持つ」。その一文を文面の中心にする
  • 聞くのは一つでよい：募集ごとに一つの場面があれば、文面は書ける
  • 聞き方：「文面に入れたいので、最初の月にやることを一つだけ教えてください」

現場の巻き込み方はOfferBoxの現場の巻き込み方で書きました。材料がない状態では、どれだけ時間をかけても、文面は事業紹介にしかなりません。

2. 相手を読んでいない

  • サイン：文面の冒頭が「貴方のプロフィールを拝見し」で止まる。学生に触れる一文が書けない。誰に送っても同じ文面になる
  • 埋め方：自由記述を先に読み、「触れる一文」を一つ拾って印をつける。「〇〇のサークルで△△を続けた」「□□の授業で✕✕を作った」
  • 拾うのは一つ：全部を読んで全部に触れようとしない。一つ拾えば、その一文で書ける
  • 拾えないなら、その学生には送らない：自由記述が空で拾えない学生は、後回し

読み方はOfferBoxのプロフィールの読み方で書きました。読んでから書く順番を逆にすると、書けません。

いま使っている媒体の運用の相談だけでも構いません。書けない原因を、いまの文面と材料から一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「文面が書けないのは、担当者の文章力の問題だ」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、書けずに止まっている担当者の手元を見ると、現場の一文がなく、プロフィールを読む前に書き始めています。材料と相手が揃っていない状態で、文章力があっても書けません。逆に、現場の一文が一つあり、学生の自由記述から一文を拾ってあれば、文章が得意でない人事でも、型に埋めるだけで文面ができます。当社が「書けない」の相談を受けるとき、最初にやるのは、文章の指導ではなく、「現場の一文はありますか」「この学生の自由記述で、触れる一文はどれですか」の二つを聞くことです。この二つが揃った時点で、書けない状態はほぼ終わります。

3. 何を伝えるかが決まっていない

  • サイン：文面が長くなる。事業、社風、福利厚生、選考の流れ、全部を入れようとする。何を削ればよいか分からない
  • 埋め方：伝えることを四つに絞る。「読んだ（学生の一文）」「仕事の場面（最初の1年）」「何を見るか（選考で見ること）」「話す場（面談に誘う）」。この四つ以外は、企業ページに任せる
  • 順番も固定する：読んだ→仕事の場面→何を見るか→話す場。入れ替えない
  • 削るものを先に決める：会社の沿革、事業の全体、福利厚生の一覧、選考の詳細は、文面に入れない

構成はOfferBoxのオファー文面の構成で書きました。「四つだけ」と決めると、長さも自然に収まります。

4. 上手く書こうとしている

  • サイン：一文目を何度も書き直す。「失礼のない」「印象に残る」を同時に狙う。時間をかけたのに送れない
  • 埋め方：型に埋める。型の空欄は、学生の一文、現場の一文、何を見るかの一文、面談の誘い、の四か所だけ。空欄を埋めたら、読み返しは一度だけで送る
  • 整えない：文章として美しくする必要はない。「読んで書いた」ことが伝われば足りる
  • 一通目は型のまま出す：反応を見てから直す。書く前に完成を目指さない

型はOfferBoxのオファー文面のテンプレートで書きました。「型に埋めるだけ」と決めることで、上手く書こうとする手が止まります。

型に埋める手順

  1. 現場の一文を、募集ごとに一つ用意する：一度作れば、その募集の全学生に使える
  2. 学生の自由記述を読み、触れる一文を一つ拾う：一人ごと
  3. 型の空欄に、拾った一文と現場の一文を入れる：この時点で、文面の大半はできている
  4. 「何を見るか」の一文を入れる：募集ごとに固定でよい。「選考では、学生時代に続けたことの話を聞きます」
  5. 面談の誘いを入れる：「選考ではなく、話す場です」を添える
  6. 読み返しは一度だけ：誤字と、学生の名前と、一文が合っているかだけ確認して送る

一人あたりの時間は、読む時間が大半で、書く時間は短くなります。書く時間が長いなら、「3」か「4」の原因が残っています。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。材料を揃えて型に埋める場合の、一人あたりの時間をお伝えします。

媒体選びを相談する

書けない状態で、送らない

  • 材料がないまま送ると、事業紹介の文面になり、開封も承認も来ない：送った数だけ時間が消える。OfferBoxのオファーが開封されないときの見直し
  • 相手を読まずに送ると、テンプレと記憶される：学生の印象に残る
  • 書けないときは、送る数を減らして、材料を揃える時間に回す：今週送らないより、読まずに送るほうが損が大きい
  • 「書けない」を上司に伝える：「材料がないので、現場に一文を聞く時間が要る」と具体的に

送らないことより、読まずに送ることのほうが、翌年に残ります。

社内の分担

作業誰が
書けない原因を四つのどれかに切り分ける人事
現場の一文と最初の1年を聞く人事が聞き、現場が答える
自由記述から一文を拾う人事（送る人）
伝えることを四つに絞り、削るものを決める人事
型を作る人事。外部に頼んでもよい
型に埋めて送る人事
文面の確認現場の人（名前を出す場合）

運用代行や代理店が支えられるのは、原因の切り分け、型と見本、伝えることの絞り方、現場への聞き方の型までで、現場の一文を聞くこと、プロフィールを読んで一文を拾うこと、送ることは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは順番の話です。当社がOfferBoxで「文面が書けない」という相談を受けたとき、型を渡す前に、現場の一文があるかを確かめます。型を先に渡すと、空欄を埋める材料がないまま、型の周りの文章を整えることに時間が使われ、結局書けません。当社が勧める順番は、現場の一文を一つ聞く、学生の自由記述から一文を拾う、その二つが揃ってから型を開く、です。逆にすると、型が「書けない」を隠します。型はあるが送れていない、という相談は、ほぼこの順番が逆です。

まとめ

  • 「書けない」は文章力ではなく、現場の材料がない・相手を読んでいない・何を伝えるかが決まっていない・上手く書こうとしている、の四つの原因で起きる
  • 最初に埋めるのは材料と相手。現場の一文を募集ごとに一つ、学生の自由記述から一文を一つ
  • 伝えることは「読んだ・仕事の場面・何を見るか・話す場」の四つに絞り、順番を固定し、他は企業ページに任せる
  • 上手く書かず、型の空欄を埋め、読み返しは一度だけで送る。一通目は型のまま出して反応で直す
  • 書けない状態では送らず、送る数を減らして材料を揃える時間に回す。読まずに送るほうが翌年に残る

よくある質問

現場が忙しく、一文を聞く時間が取れません

聞くのは一つで、口頭で短い時間で足ります。「文面に入れたいので、最初の月にやることを一つだけ」と伝えると、答えは短くなります。会議を設けず、立ち話かチャットで聞きます。募集ごとに一度聞けば、その募集の全学生に使えます。

自由記述が短い学生が多く、触れる一文が拾えません

拾えない学生は後回しにし、拾える学生から送ります。自由記述以外に、志向の項目や、経験の項目から拾えることもあります。それでも拾えない学生は、「読んで書いた」文面が作れないので、送っても反応は薄くなります。拾える学生に時間を使うほうが、結果が出ます。

文面が書けないときの整理は、御社に相談できますか

できます。当社は、原因の切り分け、型と見本、伝えることの絞り方、現場への聞き方の型を支えられます。現場の一文を聞くこと、プロフィールを読んで一文を拾うこと、送ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • OfferBoxのオファー文面がマンネリ化したとき｜マンネリの正体は「型」ではなく「空欄が埋まらなくなったこと」。型は変えず、学生の一文の拾い方と現場の一文の鮮度を戻し、承認の記録で直す場所を決める
  • 知名度がない会社がOfferBoxで学生に届くには｜オファーは「会社名で開く」のではなく「自分宛の一文で開く」。知名度の不利を、読んで書くことと仕事の具体で埋める
  • 業界イメージが不利な会社のOfferBox文面｜イメージを否定せず、「その仕事の一日」を場面で書き、学生が持っている像と実態の差を、学生自身に見つけてもらう
  • OfferBoxでオファーが開封されないときの見直し順｜文面を直す前に「届いているか・一覧で見えているか・誰に送っているか」を切り分け、最初に見える一文を最後に直す
