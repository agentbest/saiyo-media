長期インターンの採用単価の考え方

長期インターンの採用費用を振り返るとき、「1人採るのにいくらかかったか」という採用単価で考える会社は多いと思います。ただ、長期インターンの採用単価は、媒体の費用を採用人数で割るだけでは、ほとんど何も分かりません。 社内の時間がどれだけかかったか、採った学生がどれだけ続いたか、新卒採用につながったか。これらを含めて見ないと、費用が高いのか安いのかを判断できないからです。この記事では、学生向けの長期インターン求人サイトInfraなどで長期インターン生を採る会社に向けて、採用単価の考え方を整理します。具体的な金額の相場には触れません。自社の数字で計算するための枠組みとして読んでください。

一般的な採用単価の計算では足りない理由

一般的な採用単価は、次のように計算されることが多いと思います。

採用単価 ＝ 媒体の費用 ÷ 採用した人数

この計算は分かりやすい反面、長期インターンでは次の点が抜け落ちます。

  • 社内の時間：原稿づくり、応募への対応、面談、受け入れの準備にかかる社員の時間
  • 続いた期間：採った学生が数週間で辞めたのか、1年以上続いたのか
  • 業務の成果：学生が担った業務によって、社員の時間がどれだけ空いたか
  • 新卒採用への接続：インターン生が新卒で入社した場合、その採用の費用をどう扱うか

とくに「続いた期間」は、長期インターンならではの観点です。同じ費用で採った2人の学生でも、1人は数週間、もう1人は1年続いたなら、その費用の意味はまったく違います。

単価に含める費用を広げる

長期インターンの採用単価を考えるときは、含める費用を次のように広げます。

費用の種類例
媒体の費用求人サイトの掲載や成果に応じた費用
外部への委託の費用原稿作成や運用の支援を外部に頼んだ場合の費用
社内の時間原稿の確認、応募への対応、面談、受け入れの準備に使った時間
受け入れの費用道具や端末の用意など、受け入れのためにかかった費用

社内の時間は、正確に測るのが難しいので、まずはおおまかな見積もりで構いません。「面談1回あたり何時間」「受け入れ1人あたり最初の1か月で何時間」といった目安を置き、人数を掛けて見積もります。

社内の時間を費用に含めると、「媒体の費用は安かったが、面談の数が多すぎて社員の時間が大量にかかった」といったことが見えてきます。採用単価の考え方全般は媒体別の採用単価の見方でも整理しています。

媒体の費用と社内の時間を合わせて、長期インターン採用の費用を一緒に見直すことができます。

無料で相談する

「続いた期間」で割る見方

長期インターンでは、採用人数で割る単価に加えて、「続いた期間」で割る見方を持つと、費用の意味が見えやすくなります。

期間あたりの費用 ＝ 採用にかかった費用の合計 ÷ 採った学生が続いた期間の合計

たとえば、同じ費用で採った学生が全員数週間で辞めた場合と、全員が1年近く続いた場合では、期間あたりの費用に大きな差が出ます。採用人数で割った単価は同じでも、続いた期間で割ると、受け入れの質の違いが数字に表れます。

この見方を持つと、費用を下げる方法が「安い媒体を探す」だけでなく、「続く学生を採る」「受け入れの体制を整えて続いてもらう」にも広がります。

エージェントベストの見解

採用単価の相談を受けると、多くの会社は「媒体の費用をどう下げるか」から考え始めます。しかし、長期インターンの費用の振り返りを一緒にしてみると、費用を押し上げている原因が、媒体の費用ではなく、採った学生の早い離脱であることがよくあります。数週間で辞めた学生の分も、採用の費用と社内の時間は同じようにかかっています。当社はInfraの代理店として、求人原稿の作成から運用までを支援していますが、採用単価を下げたい会社には、まず受け入れた学生がどれだけ続いているかを確かめることを勧めています。続いていないなら、原稿で伝えている仕事と実際の仕事のずれ、最初の1か月の受け入れの体制から見直すほうが、媒体を変えるより費用に効くことが多いからです。期間で割る見方は、その原因を見つけるための道具です。

新卒採用につながった分をどう扱うか

長期インターン生が新卒で入社した場合、その採用の費用をどう扱うかも決めておきます。

  • 長期インターンの費用の成果に含める：インターン生の採用費用が、新卒採用の成果も生んだと考える
  • 新卒採用の費用と比べる：その学生を新卒の媒体で採った場合にかかったであろう費用と比べて、長期インターン経由の効果を見る
  • 別々に扱う：長期インターンは業務の担い手としての費用、新卒採用は別の費用として切り分ける

どの扱いが正しいということはありませんが、社内で扱いをそろえておかないと、部署ごとに違う数字が報告されて混乱します。長期インターンを新卒採用の入口として位置づけている会社なら、1つ目か2つ目の扱いで、長期インターンの価値を説明しやすくなります。

長期インターンと新卒の媒体の費用を並べて、どこに予算を寄せるか相談できます。

媒体選びを相談する

単価を記録する表の例

採用単価を振り返るために、次のような項目を記録しておきます。

  1. 募集の期間と、使った媒体やプラン
  2. 媒体と外部委託の費用
  3. 応募の数、面談の数、受け入れた人数
  4. 面談と受け入れにかかった社内の時間の見積もり
  5. 受け入れた学生ごとの、続いた期間と終わった理由
  6. 新卒の本選考に進んだ学生の数と、入社した数

半年や1年ごとにこの表を振り返ると、どこに費用と時間がかかっているかが見えてきます。

振り返るときは、次の順で見ると原因にたどり着きやすくなります。

  • 応募の数に比べて面談の数が少ない → 原稿と応募してくる学生の層が合っていない可能性
  • 面談の数に比べて受け入れの数が少ない → 面談での見極めの基準か、条件の提示に課題がある可能性
  • 受け入れの数に比べて続いた期間が短い → 入口の説明と実際の仕事のずれか、受け入れの体制に課題がある可能性

どの段階で数字が落ちているかが分かれば、費用を下げるために手を入れる場所が絞れます。

エージェントベストの見解

当社は人材紹介も行い、新卒・中途の媒体も扱っていますが、採用の入口ごとに単価を比べるとき、長期インターンは不利に見えやすい入口だと感じています。採用人数で割ると、受け入れの手間が大きいぶん、単価が高く見えることがあるからです。しかし、長期インターン生は業務を担ってくれますし、新卒採用につながれば、新卒の媒体で同じ学生に出会うためにかかったはずの費用と時間を省けます。こうした価値は、単純な採用単価の計算には表れません。長期インターンの費用を社内で説明するときは、採用人数で割った単価だけを出すのではなく、続いた期間、担った業務、新卒採用への接続を並べて示すことを勧めます。数字の見せ方を変えるだけで、長期インターンへの社内の評価が変わることがあります。予算の組み方は長期インターン採用の予算の組み方で整理しています。

まとめ

  • 長期インターンの採用単価は、媒体の費用を採用人数で割るだけでは実態が見えない
  • 単価に含める費用を、外部委託の費用、社内の時間、受け入れの費用まで広げる
  • 「続いた期間」で割る見方を持つと、受け入れの質の違いが数字に表れる
  • 新卒採用につながった分の扱いを、社内でそろえておく
  • 単価を記録する表をつくり、半年や1年ごとに振り返る

よくある質問

長期インターンの採用単価の相場はいくらですか

相場は、媒体、プラン、職種、地域、会社の受け入れの体制などによって大きく変わるため、この記事では扱っていません。自社の数字で計算し、時期ごとの変化を見るほうが、判断の材料になります。

社内の時間を費用に含めるのは大げさではありませんか

正確に測る必要はありませんが、含めないと、時間のかかる採用の方法を「安い」と判断してしまうことがあります。おおまかな見積もりでも、含めておくと判断を誤りにくくなります。

採用単価を下げるために、まず何をすべきですか

受け入れた学生がどれだけ続いているかを確かめることから始めます。早く辞める学生が多いなら、媒体を変えるより、原稿の書き方や受け入れの体制を見直すほうが、費用に効くことが多いです。
