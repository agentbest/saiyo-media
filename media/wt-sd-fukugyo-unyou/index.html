Wantedlyで副業・業務委託を集める運用｜切り出しから終わりまで

社員を一人採るほどではないが、この仕事を手伝ってくれる人がほしい。そう考えて、Wantedlyで副業や業務委託の人を探し始める会社があります。ところが、雇用の募集と同じ感覚で始めると、頼む範囲があいまいなまま面談が進み、始まってから「思っていた仕事と違う」となりがちです。結論から言うと、副業・業務委託の運用は、頼む仕事の切り出しと契約の形を先に決め、そのうえで募集記事、スカウト、面談、開始、期間中、終わり方の順に流れを作ります。集め方より、頼み方を先に決めることが要になります。 この記事では、各段階でやることと、社内の分担を整理します。

この作業の目的｜頼む仕事が、始める前に双方で一致している状態にする

副業や業務委託の人は、本業や他の仕事を持ちながら関わります。使える時間が限られているので、何を頼まれているかが分からない状態は、雇用の社員以上に負担になります。

運用の目的は、頼む仕事、期間、進め方が、始める前に双方で一致している状態にすることです。ここが一致していれば、短い時間でも成果が出やすく、続けるかどうかの判断もしやすくなります。

最初に決めること｜仕事の切り出しと契約の形

募集記事を書く前に、次のことを社内で決めます。

  1. 頼む仕事を切り出す：何を、いつまでに、どこまでやってもらうか。成果物や、関わる範囲で書きます
  2. 契約の形を決める：業務委託として頼むのか、副業として雇用の形で関わってもらうのか。形によって扱いが変わります
  3. 社内の窓口を決める：誰が依頼の相手になり、進み具合を確かめるか
  4. 使える時間の想定：週のどのくらいの時間で関わってもらうことを想定するか
  5. 社員への切り替えの考え方：将来、社員として迎える道があるか、ないか

2つ目の契約の形は、とくに注意が要ります。業務委託と雇用では、指示の出し方や時間の管理の考え方が違い、法令で定められた考え方や指針があります。どちらで頼むかは、社労士や専門家、公式の案内で確かめてから決めてください。業務委託と雇用の区別の考え方は副業・業務委託の募集記事の書き方でも触れています。

頼む仕事の切り出し方から、副業で関わってもらう形を一緒に整理します。相談だけでも構いません。

運用の相談をする

募集記事とスカウト

切り出しと契約の形が決まったら、募集記事を書きます。

  • 募集記事は雇用の募集と分ける：雇用の募集記事に「副業も可」と一行足すより、副業・業務委託の募集記事を別に立てたほうが、読み手が迷いません
  • 何を、いつまでに、どの形で頼むかを書く：仕事の範囲と期間、進め方の想定を具体的に書きます
  • 社内の窓口の人を出す：誰と一緒に進めるかが分かると、読み手は関わり方を想像しやすくなります
  • スカウトは「まず一緒に」と誘う：転職の決断を求めず、頼みたい仕事で誘います

スカウトの文面の作り方は副業から入ってもらうスカウト設計にまとめています。

エージェントベストの見解

当社は媒体で採る支援と、紹介で採る支援の両方をしているので、副業や業務委託から始める関わり方が向く場面と、向かない場面を両側から見ています。勧めている判断は、「この仕事は、社内の誰かが日々指示を出さないと進まないか」を最初に問うことです。日々の指示が要る仕事は、副業や業務委託で頼むと、指示を出す側も受ける側も時間が合わず、進みにくくなります。その場合は、社員として採る道を、媒体で採るか紹介で採るかを含めて検討したほうが合うことがあります。一方、成果物と期限が決められ、途中の確認が週に一度で足りる仕事は、副業や業務委託に向きます。Wantedlyで副業の人を集める前に、頼みたい仕事をこの問いで仕分けておくと、募集記事に書く内容も、面談で確かめることも、はっきりします。

面談から開始まで

  • 面談では、頼む仕事を先に話す：会社の説明より先に、何をどこまで頼みたいかを伝え、相手ができる範囲を聞きます
  • 使える時間と連絡の取り方を確かめる：平日の日中に連絡が取れるか、やり取りの手段は何かを合わせます
  • 本業との関係を相手に確かめてもらう：副業として関わる場合、本業の会社のルールは相手が確かめることになります。その点を面談で伝えておきます
  • 契約と開始の手続きを先に用意する：契約の書類や、使う道具の準備を、面談の前にそろえておきます

期間中と終わり方

始まったあとは、短い確認を定期的に置きます。

  • 進み具合を確かめる時間を決める：週に一度など、短い時間で、成果物の進み具合と困っていることを確かめます
  • 頼む範囲が広がりそうなら、一度止めて話す：始めた後に範囲が広がると、契約の形と合わなくなることがあります
  • 期間の終わりに、続けるかを双方で決める：続ける、範囲を変える、終えるのどれかを、期間の終わりの前に話します
  • 社員への切り替えの話は、決めた人が決めた時期にする：曖昧なまま期待させないようにします

副業のまま終わる場合も、関わってくれた人は会社のことをよく知る人になります。終わり方を丁寧にしておくと、次に別の仕事を頼むときや、知人を紹介してもらうときにつながることがあります。

副業で集めるか、社員として採るか。職種ごとにWantedlyと他の媒体の分け方も相談できます。

媒体選びを相談する

社内の分担

  • 人事・Wantedlyの担当：募集記事とスカウト、面談の段取り、契約の手続きの段取り
  • 頼む仕事の窓口（現場の責任者）：仕事の切り出し、面談、期間中の確認、続けるかの判断
  • 法務・労務の担当、または外部の専門家：契約の形の確認
  • 経営者：社員への切り替えの方針、予算の判断

エージェントベストの見解

申し込んだあと、副業・業務委託の運用が止まる会社に共通するのは、窓口になる現場の責任者が決まらないまま募集を出していることです。人事が募集記事を書き、スカウトを送り、面談まで進めても、始まったあとに誰が日々の相手になるかが決まっていない。副業の人は質問の行き先が分からず、成果物の確認も遅れ、期間の終わりを待たずに離れていきます。当社は契約後の運用まで見ていますが、この形の失敗は、媒体の使い方ではなく社内の受け止め方で起きています。勧めているのは、募集記事に窓口の人の名前を出せるかどうかを、出す前の確認にすることです。名前を出せないなら、まだ受け入れの準備ができていないと判断し、窓口を決めてから出します。この一つの確認で、始まってから止まる事態を減らせます。

まとめ

  • 副業・業務委託の運用は、頼む仕事の切り出しと契約の形を先に決める
  • 契約の形には法令で定められた考え方や指針があるので、社労士・専門家・公式の案内で確かめる
  • 募集記事は雇用の募集と分け、何を、いつまでに、どの形で頼むかを書く
  • 日々の指示が要る仕事かどうかで、副業で頼むか社員として採るかを仕分ける
  • 窓口の人の名前を出せるようになってから募集を出す

よくある質問

雇用の募集記事に「副業も可」と書くだけではいけませんか

書くこと自体はできますが、読み手は雇用と副業のどちらで関わることになるのか分かりにくくなります。副業・業務委託で頼みたい仕事がはっきりしているなら、別の募集記事を立てたほうが、集まる人と頼む仕事が合いやすくなります。

副業の人の報酬は募集記事に書けますか

Wantedlyの募集記事には、給与や待遇の書き方についてのガイドラインがあります。ウォンテッドリー株式会社の公式ヘルプで確かめたうえで、具体的な条件は面談で伝える形も選べます。

副業から社員になってもらいたいときは、いつ話せばよいですか

期間中に、決めた人が、決めた時期に話すと決めておくことを勧めます。始める前に「社員になる道があるかどうか」だけは伝えておき、具体的な話は、一緒に仕事をして双方が判断できる材料がそろってからにします。
