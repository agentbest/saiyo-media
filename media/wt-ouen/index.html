Wantedlyの応援機能を社内で使う方法｜頼んで押させるのではなく、社員が「自分の言葉で紹介したい記事」を出し続ける

Wantedlyには、社員が募集やストーリーを自分のつながりに広める「応援」の仕組みがあります。会社の公式の発信ではなく、社員個人が「この募集を紹介したい」「この記事を読んでほしい」と広めるものです。結論から言うと、応援は「社員に頼んで押させる」ものではなく、「社員が自分の言葉で紹介したくなる記事を出し続けた結果」として起きるものです。全社に一斉に頼む、ノルマにする、押すだけで一言が無い、という使い方は、社員のつながりに「会社の宣伝」を流すだけで、候補者には届きません。 この記事では、応援の役割、やりがちな失敗、記事が先という順番、頼む相手と頼み方、一言の型、続ける仕組み、反応を戻すこと、分担を整理します。応援の機能の詳細（どこに表示され、どのつながりに届くか）は変わることがあるので、現在の仕様は管理画面とヘルプで確認してください。この記事は、機能の操作ではなく、社内での使い方の話です。

この作業の目的｜会社の発信を、社員の言葉で届ける

会社ページも募集記事もストーリーも、会社が書いたものです。候補者は「会社の言葉」として読みます。応援は、それを「社員の言葉」に変えて、社員のつながりに届けます。

同じ記事でも、会社が出すのと、知り合いの社員が「うちのこの話、読んでみて」と一言添えて出すのとでは、読まれ方が違います。前者は宣伝、後者は紹介です。応援の目的は、この「紹介」を増やすことです。

紹介になるには、2つの条件があります。社員が紹介したいと思う記事であることと、社員が自分の言葉を一言添えることです。どちらが欠けても、宣伝になります。

やりがちな失敗

失敗何が起きるか
全社に「応援してください」と一斉に頼む一度は押されるが、二度目から反応が無くなる
ノルマや評価にする押すだけの応援が並ぶ。社員のつながりに宣伝が流れ、社員の信用が減る
押すだけで、一言が無い会社の発信がそのまま流れる。紹介にならない
応援したくなる記事が無いのに頼む社員が困る。「何を言えばいいか分からない」
募集記事だけを応援させる「うちに応募して」しか言えない。ストーリーのほうが紹介しやすい
応援した社員に、何が起きたかを戻さない「押した意味があったのか」で止まる
人事だけが応援している人事のつながりは採用担当者ばかりで、候補者に届かない

最も多いのは、最初の「一斉に頼む」です。契約直後に、記事が揃わないうちに全社へ頼み、一度押されて終わります。

手順1｜応援したくなる記事を出す（頼むのは、そのあと）

順番は、記事が先です。社員が「これは知り合いに見せたい」と思う記事が無いのに頼んでも、押すだけの応援になります。

社員が紹介したくなる記事には、共通点があります。

  • 自分が出ている記事：インタビュー、入社エントリー。本人は知り合いに見せたい。書き方は社員インタビューを書く手順と入社エントリーを書いてもらう方法
  • 自分のチームや、自分の関わった仕事の記事：事業の裏側、カルチャーの場面。「あの話が記事になった」
  • 自分が話した1行から生まれた記事：拾う仕組みで出た1行が記事になると、話した本人は紹介したくなる。仕組みは会社ページを更新し続ける仕組み
  • 本音が書かれている記事：うまくいかなかったこと、迷ったことが書かれていると、社員は「うちの会社はこういうところが本当だ」と紹介できる

逆に、社員が紹介しにくい記事は、会社の紹介、受賞、理念の再掲、条件だけの募集記事です。「知り合いに何と言って見せればいいか分からない」記事は、応援されません。

いま使っている媒体の運用の相談だけでも構いません。いまの記事のうち、社員が紹介したくなるものがどれかを一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「応援は、社員数が多いほど効く。だから全員に頼むべきだ」というものです。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、応援で候補者が来る会社は、応援している社員の数が多い会社ではなく、「一言を添えて応援する社員が数人いる会社」です。数人が、自分の出た記事や自分のチームの記事を、「この話、実際はこうだった」と一言添えて出す。そのつながりの中に、候補者になる人がいる。全員が押すだけの応援は、数は多くても、誰のつながりにも紹介として届きません。当社が応援を勧めるとき、最初にお願いするのは「全員に頼まないでください」です。記事に出た本人と、その記事に関わった人、数人に、一言を添えて頼む。それだけで、応援は紹介になります。

手順2｜頼む相手と、頼み方

全社に頼まず、記事ごとに数人に頼みます。

記事頼む相手
社員インタビュー、入社エントリー本人と、本人の上司かチームの人
事業の裏側その案件に関わった人
カルチャー（会議の場面など）その場にいた人
社内の出来事準備した人、裏方
募集記事その職種で働いている人（「一緒に働く人」として）
代表の考え代表本人と、その判断に関わった人

頼み方は、「応援してください」ではなく、「この記事、〇〇さんの話が入っているので、よければ知り合いに一言添えて紹介してもらえますか。無理なら大丈夫です」です。要点は3つです。

  1. 理由を添える：なぜあなたに頼むのか（あなたの話が入っている、あなたが関わった）
  2. 一言を添えて、と頼む：押すだけではなく
  3. 断ってよいと言う：つながりに何を流すかは本人の判断。断られたら次の記事で

「断ってよい」は、応援を続けるための条件です。断れない頼み方は、押すだけの応援を増やし、次から避けられます。

手順3｜一言の型

社員が「何を書けばいいか分からない」で止まらないよう、一言の型を渡します。書くのは本人ですが、型があると書きやすくなります。

型例（型）
自分が出ている「初めて記事にしてもらいました。〇〇のところ、実際はもっと大変でした」
自分が関わった「この案件、裏ではこういうことがありました。記事にはその一部が」
本音の補足「記事に書いてある〇〇は本当で、自分も入る前は想像していなかった」
誰かに向けて「〇〇に興味がある人には、この記事のこの部分を読んでほしい」
募集記事「うちのチームで一緒に働く人を探しています。この記事の『何をやるか』は自分が書いた仕事そのままです」

型に共通するのは、「記事に書いていないことを一言足す」ことです。「読んでください」「応援します」だけの一言は、押すだけと変わりません。記事の外にある本人の一言が、紹介になります。

型は渡しますが、書き直させません。本人の言葉のまま出すことが、紹介の条件です。

手順4｜続ける仕組みと、反応を戻す

応援は、一度の号令ではなく、記事が出るたびに数人に頼む、を続けます。

  • 記事を出すときの手順に「誰に頼むか」を入れる：公開→本人と関係者に一言を添えて頼む、を毎回
  • 面談で「どこでこの記事を知りましたか」と聞く：社員の紹介で来たなら、その社員に戻す
  • 応援した社員に、何が起きたかを伝える：「〇〇さんの紹介から、話を聞きに来た人がいました」。何も起きなくても「読まれていました」を戻す
  • 応援を評価や数字にしない：数字にすると、押すだけが増える。戻すのは「反応」で、数ではなく
  • 人事が自分のつながりで応援するのは、補助：人事のつながりは採用側が多い。社員のつながりのほうが候補者に近い

「反応を戻す」が、続く仕組みの中心です。ストーリーの書き手が続く理由と同じで、話した人・書いた人・紹介した人に、何が起きたかが戻ると、次も動きます。考え方は書き手を社内で増やす方法で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。応援を頼む手順は、記事を出すときの数分で済みます。

媒体選びを相談する

応援と、募集記事・ストーリーの関係

応援は、記事の質を代替しません。順番を整理します。

  1. 会社ページが、なぜこの会社があるかを書いている：会社ページの基本
  2. 募集記事が、この募集で何をやるかを具体的に書いている：募集記事の基本
  3. ストーリーが、1本に1つの場面で、本音を書いている：ストーリーの基本
  4. その記事を、関わった社員が一言添えて応援する：この記事

1から3が無い状態で4だけをやると、社員のつながりに「中身の無い記事」が流れます。社員の信用を使って届けるものなので、届ける価値のある記事にしてから頼みます。

社内の分担

作業誰が
記事ごとに「誰に頼むか」を決める人事
一言を添えて頼む人事（理由と「断ってよい」を添えて）
一言を書いて応援する社員本人（書き直させない）
面談で「どこで知ったか」を聞く面談に出る人
応援した社員に反応を戻す人事
応援したくなる記事を出し続ける人事と、話す人・拾う人

運用代行や代理店が支えられるのは、記事ごとの頼む相手の整理、一言の型、続ける手順の設計、反応を戻す型までで、頼むこと・応援すること・反応を聞くことは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これをやる前に、先に決めておかないと社員の信用を減らすことがあります。「応援を評価や数字にしない」ことです。当社がWantedlyの運用の相談を受ける中で、応援の回数を月の目標にしたり、部署ごとに比べたりした会社があります。数字にした月は応援が増えますが、中身は「押すだけ」で、社員のつながりに会社の宣伝が並びます。社員は自分のつながりに宣伝を流したことになり、次から応援を避けます。数字にしなかった会社は、応援の数は少ないままですが、記事に出た本人が一言を添えて出し、そのつながりから話を聞きに来る人がいます。応援は、社員の信用を借りて記事を届ける仕組みです。借りたものを数字で管理すると、信用のほうが減ります。当社は、応援を「数人に、理由を添えて、断ってよいと言って頼む」形でしか勧めません。

まとめ

  • 応援は「社員が自分の言葉で紹介したくなる記事を出し続けた結果」。頼んで押させるものではない
  • 全社に一斉に頼む、ノルマにする、押すだけで一言が無い、は宣伝を流すだけで届かない
  • 記事が先。本人が出ている記事、関わった記事、本音のある記事が、紹介される
  • 記事ごとに数人に、理由を添えて、一言を添えて、断ってよいと言って頼む
  • 面談で「どこで知ったか」を聞き、応援した社員に反応を戻す。評価や数字にしない

よくある質問

社員が誰も応援してくれません

記事が、社員が紹介したいものになっているかを先に見ます。会社の紹介や理念の再掲、条件だけの募集記事は、紹介の言葉が見つかりません。社員が出ている記事、関わった記事を出し、その本人に理由を添えて頼むところから始めます。全社への号令は止めます。

応援の効果は、どう見ればよいですか

閲覧や応援の回数ではなく、面談で「どこでこの記事を知りましたか」と聞いて、社員の紹介で来た人がいるかで見ます。数は少なくても、社員の紹介で来た候補者は、会社の中身を読んで来ています。

応援の使い方は、御社に相談できますか

できます。当社は、記事ごとに誰に頼むかの整理、一言の型、続ける手順、反応を戻す型を支えられます。頼むことと応援することは、企業と社員が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの運用の整備を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

あわせて読む

  • Wantedlyの募集記事の反応を見て直す手順｜どこで止まっているかを切り分け、月に一度、1か所だけ直す
  • Wantedlyのコンテンツを四半期で見直す方法｜会社ページ・募集記事・ストーリーを、面談の言葉と台帳で棚卸しする
  • Wantedlyのコンテンツを資産として貯める考え方｜記事は「出して終わり」ではなく、面談・採用サイト・次の募集で使い回す
  • Wantedlyの記事づくりに社員の協力を得る方法｜「書いて」ではなく「話して」と頼み、短く、業務時間内で、反応を戻す
