OfferBox経由の学生の面接評価がばらつくとき｜4つの元と直し方

OfferBox経由の学生が、面接に進んだ。一次の面接官は「良い」と言い、二次の面接官は「合わない」と言う。同じ学生で評価が割れ、最終で決められない。逆に、面接官が変わると、通る学生の傾向が変わる。結論から言うと、ばらつきの元は四つです。「こんな人」が面接官の間で合意されていない、段階ごとに見る項目が決まっていない、印象や志望動機で評価している、面接官がオファーの文面と面談の記録を知らない。四つを直し、評価を「行動の事実」で一行に書く型にし、面接官ごとの評価を並べてばらつきの場所を見ます。大学名・適性検査・志望動機は評価に入れず、面接後に評価を戻し合う場を持ちます。 この記事では、四つの元とサインと直し方、一行の型、並べて見ること、割れた学生の扱い、入れないもの、戻し合う場、分担を整理します。評価基準の作り方はOfferBoxで会う学生の評価基準の作り方、面接官への説明はOfferBox経由の学生を面接する現場社員への説明で書きました。この記事は、ばらつきが出たあとの直し方です。

この作業の目的｜「誰が面接しても、同じ学生が通る」状態に近づける

面接評価のばらつきは、面接官の能力の差ではなく、面接官が「何を見るか」を共有していないことから起きます。共有されていれば、見方は違っても、評価は近づきます。

目的は、面接官を揃えることではなく、「何を見るか」と「どう書くか」を揃えることです。

ばらつきの、四つの元

元サイン直し方
1. 「こんな人」が合意されていない面接官ごとに「良い学生」の像が違う。「元気がある」と「落ち着いている」で割れる「こんな人」を一枚にして、面接官全員と合意する
2. 段階ごとに見る項目が決まっていない一次と二次で同じことを聞き、同じことを違う基準で評価する段階ごとに、見る項目を一つに
3. 印象や志望動機で評価している「話しやすかった」「熱意があった」「志望動機が薄い」で評価が書かれている「行動の事実」で書く型に
4. 面接官がオファーと面談を知らない「なぜうちに」と聞き、「オファーをもらったから」に「志望度が低い」をつけるオファーの文面と面談の記録を、面接前に一行で渡す

四つは、上から順に直します。「こんな人」がなければ、段階ごとの項目は決まらず、項目がなければ「行動の事実」で書けません。「4」は、OfferBox経由の学生に特有のばらつきです。

1. 「こんな人」を、面接官全員と合意する

  • 「こんな人」を、条件・志向・行動の三つに分けて一枚に：OfferBoxで採りたい学生像を言葉にする
  • 面接官全員に見せ、「これで見る」と合意する：見せるだけでなく、「違うと思う点はあるか」を聞く
  • 面接官ごとの「良い学生」の像を、先に出してもらう：出してもらうと、ずれが見える
  • 合意した一枚を、面接のたびに手元に：合意して終わりにしない

面接官が「こんな人」を自分の言葉で言えるようになれば、ばらつきの半分は減ります。

2. 段階ごとに、見る項目を一つにする

段階見る項目（例）見ない項目
面談「こんな人」に近いか（一つの行動で）合否は出さない
一次行動：「自分で始めて続けた」の事実があるか志望動機、業界知識
二次志向：「最初の1年」の仕事に、本人が向かえるか一次で見た行動をもう一度
最終条件と、入社後の場面を本人が描けているか一次と二次で見たことの再確認

段階ごとに項目を一つにすると、面接官は「自分は何を見る係か」が分かり、他の段階の項目で評価しなくなります。段階の分け方はOfferBoxで会う学生の評価基準の作り方の手順2で書きました。

いま使っている媒体の運用の相談だけでも構いません。面接評価のばらつきが、四つのどれから来ているかを一緒に切り分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「面接評価がばらつくのは、面接官の経験の差なので、面接官研修で直す」というものです。当社は3媒体すべての販売パートナーとして、OfferBoxの運用を見ていますが、ばらついている会社の評価の記録を並べると、経験の長い面接官と短い面接官で割れているのではなく、「こんな人」の像が面接官ごとに違い、「元気」「落ち着き」「熱意」といった印象の言葉で評価が書かれています。印象の言葉は、面接官の数だけ違います。「行動の事実」で書く型にした会社では、経験の差があっても、評価が近づいています。当社が面接評価の相談を受けるとき、最初にやるのは、面接官研修ではなく、評価の記録を「行動の事実」の型に変えることです。型が変わると、面接官は事実を聞くようになり、評価が揃います。

3. 評価を、「行動の事実」で一行に書く

  • 型：「学生時代に〇〇を（自分で始めた／続けた／人を巻き込んだ）事実：△△。『こんな人』の行動との近さ：近い／やや近い／遠い」
  • 印象の言葉を使わない：「元気」「熱意」「落ち着き」「話しやすい」「素直」は書かない
  • 事実が聞けなかったら、「聞けなかった」と書く：「良い」でも「悪い」でもない
  • 一行で足りる：長い評価は、印象が混ざる
  • 「こんな人」との近さを、三段で：数字の点数にすると、点数の付け方でばらつく

「行動の事実」の物差しはOfferBoxで会う学生の評価基準の作り方の手順3で書きました。

4. 面接官に、オファーと面談を一行で渡す

  • 「文面で〇〇に触れ、面談で△△を話した。選考ではないと伝えてある」：一行
  • 「なぜうちに」を聞かない：オファー経由の学生は、会社から声をかけられて来ている。志望動機は、選考が進む中でできる
  • 面談の続きとして始める：「面談で△△の話をされたと聞いています。その続きを」
  • オファーで伝えた「何を見るか」と同じことを見る：文面と面接がずれない

OfferBox経由の学生の面接の入り方はOfferBox経由の学生を面接する現場社員への説明で書きました。「4」を直さないと、オファー経由の学生だけ、評価が低く出ます。

面接官ごとの評価を並べて、ばらつきの場所を見る

  • 面接官ごとに、評価の「近い／やや近い／遠い」の分布を並べる：一人だけ「遠い」が多い、一人だけ「近い」が多い、が見える
  • 同じ学生を複数の面接官が見た場合、評価が割れた学生を並べる：どの項目で割れたか
  • 割れた元が、四つのどれかを見る：「こんな人」の像か、項目か、印象か、オファーを知らないか
  • 月に一度、面接官と一緒に見る：責めない。「ここで割れたので、こう揃えたい」

並べて見ると、ばらつきが「誰と誰の間」「どの項目」で起きているかが分かります。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。面接評価を揃えるための、「こんな人」の一枚と評価の型をお伝えします。

媒体選びを相談する

評価が割れた学生の扱い

  • 割れたら、「行動の事実」に戻る：「一次で聞いた事実」と「二次で聞いた事実」を並べる。印象で決めない
  • 事実が足りないなら、もう一度会う：「話す場」として。合否のためではなく、事実を聞くために
  • 面接官同士で、事実を持ち寄って話す：「あなたが聞いた事実は何か」
  • それでも割れたら、「こんな人」の一枚に戻る：一枚のどこに近いか、遠いか
  • 割れたこと自体を、記録に残す：「こんな人」の見直しの材料

割れた学生を「どちらかの面接官が正しい」で決めると、面接官の間に上下ができ、次から評価が偏ります。

評価に入れないもの

  • 大学名：「こんな人」の行動と別の軸。OfferBoxで大学群を条件にすることについて
  • 適性検査の結果：合否の基準にせず、面接で確かめる仮説に。OfferBoxの適性検査結果を選考にどう使うか
  • 志望動機：オファー経由の学生には、選考の前に志望動機がなくてよい
  • 印象の言葉：「元気」「熱意」「落ち着き」
  • 面接官との相性：「話しやすかった」は、面接官の側の評価

入れないものを先に決めておくと、面接官が「何で評価してよいか」に迷わなくなります。

面接後に、評価を戻し合う場

  • 面接のあと、面接官同士で「行動の事実」を持ち寄る：短い時間で
  • 人事が、四つの元のどれかでずれていないかを見る
  • ずれがあれば、その場で「こんな人」の一枚か、段階の項目に戻る
  • 月に一度、面接官全員で評価の分布を見る：ばらつきの場所と、揃え方
  • 「こんな人」を、面接の記録から見直す：年に一度。OfferBoxで会う学生の評価基準の作り方の手順6

戻し合う場がないと、ばらつきは面接官ごとに固定します。

作業誰が

運用代行や代理店が支えられるのは、「こんな人」の一枚の型、段階ごとの項目の型、「行動の事実」の一行の型、並べて見る表の型、戻し合う場の進め方までで、「こんな人」の決定、面接、評価、割れた学生の判断は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは切り分けの話です。当社がOfferBoxで「面接評価がばらつく」という相談を受けるとき、「OfferBox経由の学生だけばらつく」のか「全部の経路でばらつく」のかを分けます。前者なら、四つ目の元（面接官がオファーと面談を知らない）が主で、一行を渡すだけで直ることが多いです。後者なら、一つ目から三つ目の元で、「こんな人」の合意と段階の項目と「行動の事実」の型が要り、時間がかかります。相談の多くは、両方が混ざっていて、「OfferBox経由の学生の評価が低く出る」ことから、「OfferBoxの学生は質が低い」という判断に行きかけています。当社は、その判断の前に、面接官がオファーの文面を読んでいたか、「なぜうちに」を聞いていなかったか、を確かめてもらいます。

まとめ

  • ばらつきの元は、「こんな人」の合意がない・段階ごとの項目がない・印象や志望動機で評価・面接官がオファーと面談を知らない、の四つ。上から順に直す
  • 「こんな人」を条件・志向・行動の一枚にし、面接官全員と合意する。段階ごとに見る項目を一つにし、他の段階の項目で評価しない
  • 評価は「行動の事実」で一行。印象の言葉を使わず、事実が聞けなかったら「聞けなかった」と書き、近さは三段で
  • 面接官にオファーと面談の記録を一行で渡し、「なぜうちに」を聞かず、面談の続きとして始める。OfferBox経由の学生だけ低く出るなら、ここ
  • 面接官ごとの評価を並べてばらつきの場所を見る。割れた学生は事実に戻り、大学名・適性検査・志望動機・印象・相性を評価に入れず、月に一度戻し合う

よくある質問

面接官が「印象も大事だ」と言って、事実の型を使いません

印象を否定せず、「印象は書かず、印象の元になった事実を書いてほしい」と伝えます。「元気があった」の元には、「〇〇の話を、身を乗り出して話した」という事実があります。事実を書けば、印象は他の面接官にも伝わり、印象だけを書くと、伝わりません。型は、印象を消すものではなく、印象を事実に変えるものです。

最終の面接官（経営）だけ、評価が違います

最終の面接官にも、「こんな人」の一枚と、段階ごとの項目（最終は「条件と入社後の場面を本人が描けているか」）と、オファーと面談と一次・二次の記録の一行を渡します。経営は、一次・二次の記録を読まずに最終に入ることが多く、そこで「なぜうちに」に戻ります。記録を読んでもらうだけで、ばらつきは減ります。

面接評価の整理は、御社に相談できますか

できます。当社は、「こんな人」の一枚の型、段階ごとの項目の型、「行動の事実」の一行の型、並べて見る表の型、戻し合う場の進め方を支えられます。「こんな人」の決定、面接、評価、割れた学生の判断は、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、OfferBoxの運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。
