OfferBoxの運用が回り始めると、承認した学生との面談が人事の手に余るようになります。オファーを現場の社員の名義で送っているなら、面談もその社員が担うほうが、学生にとって話の筋が通ります。ただ、「面談をお願い」と頼むだけでは、社員は何を話せばよいか分からず、選考のような面談や、会社の説明だけの面談になりがちです。結論から言うと、面談を任せられる社員は、同席から始めて段階で任せ、「話してよいこと」と「人事に戻すこと」の線と、面談後の振り返りの型を渡すことで育ちます。面談の上手さは才能ではなく、準備と振り返りの回数で決まります。 この記事では、任せる人の選び方、段階の踏み方、渡すもの、練習、振り返り、業務としての位置づけを整理します。面談そのものの構成は初回面談の設計、面接官への説明は現場社員を面接官にするときの説明で書きました。

この作業の目的｜面談を「人事しかできない仕事」から外す

面談を人事だけで担っていると、承認が増えた時期に日程が組めなくなり、承認から面談までが延びます。延びるほど、学生は他社の予定を先に入れます。

育てる目的は、次の3つです。

  • 面談の枠を増やす：人事が出られない日も、面談を組める
  • 学生が仕事の話を直接聞ける：現場の社員は、日々の仕事を具体的に話せる
  • オファーの名義と面談の人を揃える：「この人に会える」と思って承認した学生に、その人が会う

人事の役割は、面談をすることから、面談の型を持ち、任せた社員を支えることに移ります。

手順1｜任せる人を選ぶ

最初に任せる人は、職位や話のうまさより、次の点で選びます。

見ること理由
自分の仕事を、具体的な場面で話せるか学生が知りたいのは、最初の1年に何をするか
学生の話を最後まで聞けるか面談は学生の関心を聞く場。話しすぎる人は練習が要る
定期的に時間を出せるか月に数回でも、決まった枠を出せる人のほうが続く
採用に協力したい気持ちがあるか頼まれて仕方なく出る人の面談は、学生に伝わる
入社して数年の社員か学生と年が近く、入社前の迷いを話せる。ただし年次で決めつけない

最初は1人か2人に絞ります。一度に多くの人に任せると、人事が振り返りを見きれず、面談の質がばらつきます。社員の巻き込み方は現場社員を巻き込む方法で書きました。

手順2｜同席から単独まで、段階で任せる

いきなり1人で面談させず、段階を踏みます。

  1. 見学：人事の面談に同席し、最後に数分だけ自分の仕事を話す
  2. 一部を担当：面談の中の「仕事の話」と「学生からの質問」の時間を受け持つ。始めと終わりは人事
  3. 主担当・人事が同席：最初から最後まで社員が進め、人事は横で聞く。終わったあとに振り返る
  4. 単独：社員が1人で面談し、終わったら振り返りの型で人事に戻す

段階を進めるかは、回数ではなく、振り返りで見ます。「学生の関心を聞けたか」「話してよい範囲を守れたか」の2点が続けてできていれば、次に進みます。オンラインで面談する場合の進め方はオンラインで会うときの進め方が参考になります。

いま使っている媒体の運用の相談だけでも構いません。面談を誰がどの段階で担うかを、一緒に整理します。

運用の相談をする

手順3｜面談の前に渡すもの

社員が準備に迷わないよう、面談ごとに渡すものを決めておきます。

  • 面談の位置づけ：選考ではない、学生の関心を聞いて仕事を伝える場、という一文
  • 送ったオファーの文面：学生は文面を読んで承認している。社員がそれを知らないと、話が食い違う
  • 学生のプロフィールで触れた箇所：オファーで触れた一文と、学生が書いている活動
  • 面談の流れの型：最初の数分、学生の関心を聞く、仕事の話、質問、次の案内
  • 話してよいことと、人事に戻すことの一覧：次の手順で作る

渡す形は、1枚にまとめます。毎回同じ形だと、社員は数分で目を通せます。プロフィールの読み方はプロフィールの読み方で書きました。

手順4｜「話してよいこと」と「人事に戻すこと」の線を引く

社員が面談で迷うのは、聞かれたことにどこまで答えてよいか、です。線を先に引きます。

話してよいこと人事に戻すこと
自分の仕事の一日、最初の1年にしたこと給与・賞与・手当の具体的な条件
入社前に迷ったこと、入社してから感じた差選考の結果や、通るかどうかの見込み
職場の雰囲気、一緒に働く人配属の確約や、希望が通るかの約束
仕事で大変なこと、向いていないと感じた場面他の学生や他社との比較
自分が分からないことは「人事から連絡します」学生の個人的な事情に踏み込む質問

「分からないことは分からないと言い、人事に回す」を許しておくと、社員は無理に答えず、誤った約束も生まれません。学生の個人的な事情に踏み込まないことは、面談の前に一度、言葉で伝えます。

エージェントベストの見解

これをやる前に、先に決めておくことがあります。面談を任せる社員の、その月の面談の枠です。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、社員の育成で止まる会社に多いのは、育て方より先に、枠が出てこないことです。同席までは進んでも、単独で任せる段になると「今月は忙しい」で枠が消え、結局人事が面談を引き取ります。これでは社員は振り返りの回数を重ねられず、いつまでも育ちません。育成を始める前に、上長と合意して「毎月この曜日のこの時間は面談の枠」と決めておく。枠が先に決まっていれば、承認への返信で日程の候補をすぐ出せ、社員も面談を本業の一部として扱えます。育て方の工夫は、そのあとです。

手順5｜練習と、面談後の振り返り

単独に進む前に、人事が学生役になって一度練習します。学生のプロフィールを1つ用意し、最初の数分から次の案内までを通します。練習で見るのは、話しすぎていないか、学生の関心を聞く質問が出るか、の2点です。

面談後は、型で振り返ります。

  1. 学生が関心を持っていたこと（学生の言葉で1行）
  2. 自分が話した仕事の場面
  3. 答えられず人事に回したこと
  4. 学生の次への温度（進みたい・迷っている・合わない）
  5. 次に試したいこと

この5つを、面談した当日に管理表へ書いてもらいます。人事は週に一度まとめて読み、気になる点だけ短く返します。温度の記録は、面談後のフォロー連絡に使えます。フォローの書き方は面談後のフォロー連絡で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。面談を社員に任せた場合の人事の時間も含めて考えます。

手順6｜面談を業務として扱う

面談を任せた社員の時間は、善意に頼らず業務として扱います。

  • 上長と合意する：面談の時間は本業の一部、と上長が認めている状態にする
  • 面談の数を見えるようにする：誰が月に何件担ったかを管理表で共有する
  • 評価の場で触れてもらう：採用への協力を、上長が評価の場で取り上げる。どう扱うかは会社の制度で決める
  • 負担が偏ったら分ける：1人に面談が集まったら、次の社員を育てる

社員に任せたあとの全体の分担はチームで運用するときの役割分担で書きました。

エージェントベストの見解

外に出せるものと、出せないものの切り分けです。当社がOfferBoxの運用代行を受けるとき、面談の日程調整、面談ごとの1枚の準備、振り返りの記録の整理までは当社で担えます。ただし、面談そのものと、社員を育てる役目は企業に残ります。学生が承認したのは、その会社の人と話すためで、面談に代行の担当が出ても、仕事の場面は伝わりません。また、社員の振り返りに一言返す役は、社内の事情と評価の基準を知っている人事でないと務まりません。代行に出すと決めた会社ほど、面談の準備の手間が減った分を、社員への振り返りに回すと、任せられる社員が早く増えます。準備は外に、面談と育成は内に。この切り分けで、人事の時間は面談をこなすことから、社員を支えることに移せます。

まとめ

  • 面談を任せる目的は、枠を増やし、仕事の話を直接届け、オファーの名義と面談の人を揃えること
  • 任せる人は、仕事を具体的に話せ、聞ける人から1〜2人。見学から単独まで段階で任せる
  • 面談ごとに位置づけ・オファー文面・プロフィール・流れ・線引きを1枚で渡す
  • 条件・合否・配属の約束は人事に戻す。分からないことは分からないと言ってよい
  • 当日の振り返りを型で残し、面談の枠と時間を業務として上長と合意する

よくある質問

話すのが得意でない社員にも、面談を任せられますか

任せられます。面談で大事なのは、学生の関心を聞き、自分の仕事を具体的に話すことで、話のうまさではありません。流れの型と線引きの一覧があれば、落ち着いて進められる社員は多いです。練習で、聞く質問が出るかを確かめてから単独に進めてください。

社員が面談で、選考の見込みを話してしまいました

その後の連絡で、人事から正式な選考の案内として改めて伝え直します。社員を責めるより、「人事に戻すこと」の一覧に加え、次の面談の前に一度確認する形にしてください。

面談の担当を何人まで増やせばよいですか

人数より、人事が振り返りを読みきれる範囲で増やします。承認が増えて枠が足りなくなったら、次の1人を見学から始めます。送る数と面談の枠の関係はオファー送信ペースの決め方で書きました。
