SNS運用の長期インターン求人原稿｜学生が応募を決める書き方

SNS運用は、ふだんからSNSに親しんでいる学生にとって、関心を持ちやすい長期インターンの職種です。ただ、自分のアカウントで投稿することと、会社のアカウントを運用することは別の仕事で、その違いが原稿から伝わらないと、入ってから「思っていたより自由がない」「思っていたより責任が重い」と感じる学生が出ます。結論から言うと、SNS運用の求人原稿は、「運用するアカウントの性格」「学生が担う範囲」「投稿前の確認の流れ」「顔出しや勤務時間外の扱い」を具体的に書くと、学生は会社のアカウントを預かる仕事として応募を判断できます。 この記事では、InfraにSNS運用の原稿を出す会社の担当者に向けて、タイトル、冒頭、仕事内容、条件、見直す点の順に整理します。任せる範囲の決め方はSNS運用の長期インターンを採るで書いています。

SNS運用の原稿で学生が確かめること

SNS運用の原稿を開いた学生は、次の点を確かめています。

  • どのアカウントか：会社の公式か、商品やサービスのアカウントか、採用のアカウントか
  • 誰に向けた発信か：お客様か、取引先か、就職活動中の学生か
  • 自分が担う範囲：投稿の案を考えるだけか、文章や画像も作るか、公開や返信もするか
  • 確認の流れ：投稿の前に誰が見るのか、どのくらいで返事がもらえるのか
  • 自分が表に出るか：写真や動画に顔が出るか、名前が出るか

特に最後の点は、学生の判断を大きく左右します。顔や名前が出ることを前向きに受け止める学生もいれば、それだけで応募を見送る学生もいます。どちらであっても、原稿に書かれていれば学生は自分で判断できます。

タイトルと冒頭で、アカウントと担う範囲を示す

タイトルには、運用するアカウントの性格と、学生が担う範囲を入れます。

  • 避けたい例：「SNS好き歓迎｜インスタ運用インターン」
  • 書き直した例：「雑貨ブランドの公式アカウント担当｜投稿の企画と画像づくりから始めるSNS運用」

「SNS好き」という言葉は、好きであることと仕事として運用することの違いを曖昧にします。アカウントの性格と担う範囲を書くほうが、仕事として向き合える学生に届きます。タイトルの付け方はInfraの求人タイトルの付け方も参考にしてください。

冒頭の数行では、アカウントが何のためにあるのかを書きます。

書き方の例

私たちは、暮らしの雑貨をつくるブランドです。公式アカウントでは、商品の使い方や、つくり手の思いを、商品を使ってくださるお客様に向けて発信しています。

インターン生には、投稿の企画と、文章・画像の下書きづくりを担当してもらいます。投稿の前には担当社員が内容を確認し、公開とコメントへの返信は、慣れてきてから少しずつお願いします。

アカウントの目的、発信の相手、担う範囲、確認の流れが冒頭で分かると、学生は「会社のアカウントを預かる仕事」として続きを読めます。

SNS運用で、インターン生に任せる範囲と確認の流れをどう原稿に書くか。いまの原稿を見ながら一緒に整理します。

無料で相談する

エージェントベストの見解

SNS運用の原稿について相談で多い思い込みは、「個人のアカウントで発信している学生、フォロワーが多い学生を集めるべきだ」というものです。当社は掲載後の応募対応まで見ていますが、個人の発信が得意な学生が、会社のアカウントの運用でもうまくいくとは限りません。個人の発信は自分の好みで決められますが、会社のアカウントは確認の流れがあり、ブランドの言葉づかいに合わせる必要があります。会社のアカウントで伸びるのは、ルールの中で工夫できる学生です。原稿で個人の発信の実績を応募の条件にすると、ルールの中での工夫に向く学生が応募を見送ることがあります。個人の発信の経験は「あれば教えてください」の扱いにとどめ、条件にはしないことを勧めます。

仕事内容は「担う範囲」と「確認の流れ」で書く

SNS運用の仕事内容では、担う範囲を段階で書き、それぞれの段階で誰が確認するかを添えます。

  1. 最初の段階：投稿の企画と、文章・画像の下書きをつくる。公開は担当社員が行う
  2. 次の段階：確認を受けた投稿を、決まった時間に公開する。投稿の反応をまとめる
  3. その先：コメントやメッセージへの返信の一部を担う。返信の型があり、迷うものは社員に引き継ぐ

確認の流れは、「誰が」「どのくらいで」見るのかを書きます。確認に時間がかかりすぎると、学生は作った投稿がいつ公開されるのか分からず、張り合いをなくします。「下書きは、翌営業日までに担当社員が確認します」のように、返事の目安を書いておくと、学生は仕事の進み方を想像できます。

あわせて、運用のルールがあることも書きます。言葉づかい、使ってよい画像、触れない話題など、ルールの中身まで書く必要はありませんが、「入ってから運用のルールを一緒に確認します」と書くと、学生は会社のアカウントを扱う責任を感じ取れます。

顔出しと勤務時間外の扱いを書く

SNS運用の原稿で、書き漏れが多いのが次の二つです。

  • 顔出し・名前の扱い：学生が写真や動画に出るか。出る場合は、本人の同意を取ることと、出たくない場合の扱い
  • 勤務時間外の対応：休日や夜にコメントが来たときに、学生が対応する必要があるか

勤務時間外の対応は、学生が気にしていても質問しにくい点です。対応が要らないなら「勤務時間外の返信は社員が対応します」と書き、対応が要るなら、その扱いを勤務の時間として決めておきます。インターン生の労働時間の扱いには法令で定められた項目があるため、勤務時間外の作業の扱いは社労士や公式の案内で確認しておきます。受け入れ前に確かめることは長期インターンの雇用契約と労働時間にまとめています。

条件の欄には、ほかに勤務の日数と時間の目安、勤務地、オンラインでの勤務の可否、時給、試験期間の扱いを書きます。撮影がある場合は、撮影の日に出社が要ることも添えます。

応募時に見せてもらうもの

SNS運用では、応募の時点で何を見せてもらうかを原稿に書いておくと、応募と選考が進めやすくなります。

  • 自社のアカウントを見て、気になった投稿と、その理由
  • 好きな企業のアカウントと、どこが好きか
  • 画像や文章をつくった経験があれば、その例

個人のアカウントの提出は求めないか、任意にします。会社のアカウントを見て考えてもらうほうが、学生の見方と工夫の仕方が分かります。

原稿の作成から応募への返信、面接の日程調整まで、Infraの運用を代理店としてお手伝いしています。

運用の相談をする

エージェントベストの見解

SNS運用の原稿を書く前に、先に決めておきたいのは「誰が最後に公開を決めるか」です。これが決まっていないと、原稿の確認の流れが書けず、入ってからも学生の下書きが社内のあちこちで止まります。投稿の中身を見る人と、公開を決める人が違う会社では、二人の意見が食い違うたびに学生が板挟みになります。公開を決める人を一人に決め、その人が忙しいときに代わる人も決めておく。これだけで、原稿に「下書きは翌営業日までに確認します」と書けるようになります。当社は掲載のあとの運用まで見ていますが、SNS運用の受け入れが続いている会社に共通するのは、確認の流れが短く、誰が決めるかがはっきりしていることです。原稿に確認の流れを書けるかどうかは、受け入れの準備ができているかを確かめる目安にもなります。

原稿を見直すときの点

  • アカウントの性格と、発信の相手が書かれているか
  • 担う範囲が段階で書かれ、公開と返信をいつから任せるかが分かるか
  • 確認する人と、返事の目安が書かれているか
  • 顔出し・名前の扱いと、勤務時間外の対応が書かれているか
  • 個人の発信の実績を、応募の条件にしていないか

原稿全体の組み立てはInfraの求人原稿の書き方で整理しています。

まとめ

  • SNS運用の原稿は、アカウントの性格・担う範囲・確認の流れ・顔出しと時間外の扱いを書く
  • タイトルと冒頭で、どのアカウントを、どこから担うかを示す
  • 確認する人と返事の目安を書くと、学生は仕事の進み方を想像できる
  • 個人の発信の実績は条件にせず、会社のアカウントを見て考えてもらう
  • 勤務時間外の作業の扱いは、社労士や公式の案内で確認しておく

よくある質問

写真や動画に学生が出てほしい場合、どう書けばよいですか

出てもらう可能性があることを原稿に書き、出るかどうかは本人の同意で決めること、出たくない場合も仕事は続けられることを添えます。後から知らされると、学生は断りにくくなります。

SNSの種類は原稿に書くべきですか

書くことを勧めます。SNSの種類によって、投稿の形も、必要な作業も違うからです。複数のSNSを運用している場合は、学生が最初に担当するものを書きます。

入ってからの最初の1か月はどう組めばよいですか

ルールを知る、過去の投稿を読む、下書きをつくる、公開するの順に、週ごとに一段ずつ広げる組み方をSNS運用の長期インターン生の最初の1か月で書いています。
