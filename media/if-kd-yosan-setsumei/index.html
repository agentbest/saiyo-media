長期インターンの費用を社内に説明できないとき｜資料の組み方

Infra・長期インターン課題別（追加） 更新日 2026/11/4

長期インターンを続けたい、あるいは新しく始めたいと考えても、予算を決める経営者や上司に費用の意味をうまく説明できず、話が進まないことがあります。「学生のアルバイトと何が違うのか」「その費用で何が得られるのか」と聞かれて、言葉に詰まる。結論から言うと、費用を社内に説明するときは、費用を「募集にかかるもの」「インターン生に払うもの」「社員の時間」の三つに分け、受け入れの目的と並べて一枚にまとめるのが基本です。 費用の総額だけを示すと、高いか安いかの議論で終わってしまいます。この記事では、説明に詰まる原因の切り分け、費用の分け方、説明の型、問われやすい点を順に整理します。

説明に詰まるときの症状

費用の説明に詰まるとき、次のような状態になっていることが多いです。

  • 媒体の費用だけを示し、受け入れにかかる他の費用が見えていない
  • 「何が得られるか」を聞かれて、感覚的な答えしかできない
  • アルバイトや新卒採用の費用との違いを説明できない
  • 受け入れの効果を示す記録がない
  • 説明する相手によって、伝える内容がばらばらになっている

これらは、費用と目的が別々に語られていることから起きます。費用の側だけを見ると、何に使うお金なのかが伝わりません。目的の側だけを語ると、そのためにいくらかかるのかが分かりません。

原因の切り分け｜この順番で確かめる

説明に詰まる原因を、次の順で確かめます。

  1. 受け入れの目的が言葉になっているか：何のために受け入れるのかを、一文で言えるか
  2. 費用の全体が見えているか：媒体の費用だけでなく、賃金や社員の時間まで含めて把握しているか
  3. 費用と目的がつながっているか：それぞれの費用が、目的のどこに効くかを説明できるか
  4. 比べる相手が決まっているか：アルバイト、派遣、新卒採用など、何と比べて説明するかが決まっているか

一つ目ができていないと、残りは組み立てられません。目的の決め方は、長期インターンの効果が分からないときで整理しています。

四つ目は見落とされがちです。経営者が頭の中で比べている相手が分かれば、説明の焦点が定まります。「アルバイトで足りるのでは」と考えている相手と、「新卒採用の費用を増やすべきでは」と考えている相手では、伝えるべきことが違います。

長期インターンの費用の見積もりと、社内への説明の組み立てを、一緒に整理します。比較だけでもどうぞ。

無料で相談する

費用を三つに分ける

受け入れにかかる費用を、次の三つに分けて書き出します。

1. 募集にかかるもの

求人媒体の利用料金、募集原稿の作成や応募対応を外に出す場合の費用などです。Infraのような長期インターンの求人サイトを使う場合は、プランによって料金の仕組みが異なるため、自社の受け入れの見通しに合う形を選びます。料金の詳細は、公式の案内や代理店で確認します。

2. インターン生に払うもの

賃金と、交通費などの手当です。長期インターンは有給で働く形が多く、賃金の扱いや勤務時間の管理には法令で定められた項目があります。詳細は社労士や公式の案内で確認してください。

3. 社員の時間

担当社員が指導や確認に使う時間、面接や面談に使う時間です。お金として出ていくものではありませんが、受け入れの費用の大きな部分です。経営者が気にしているのは、むしろこの部分であることもあります。

三つに分けると、どこを工夫すれば費用を抑えられるかも見えてきます。たとえば、社員の時間がかかりすぎているなら、任せる仕事の選び方や指導の仕方を見直す、といった判断ができます。

エージェントベストの見解

費用の説明で相談が多いのは、経営者から「アルバイトで足りるのでは」と問われる場面です。このとき、時給や賃金の違いで説明しようとすると、話がかみ合いません。経営者が知りたいのは、払うお金の違いではなく、得られるものの違いだからです。説明の軸にしてほしいのは、任せる仕事の違いです。アルバイトには手順の決まった作業を任せ、長期インターンには、考えて進める仕事を任せる。その違いを、自社で実際に任せている仕事の名前で示します。そのうえで、長期インターン生の中から新卒の候補が生まれることや、指導する社員が育つことを補足として添える。費用の議論の前に、何を任せるかの議論を置くと、説明は通りやすくなります。

説明の型｜一枚にまとめる

社内への説明は、次の項目を一枚にまとめます。

項目書くこと
目的受け入れで得たいことを一文で
任せる仕事インターン生に任せる仕事の名前と範囲
費用募集・賃金・社員の時間の三つに分けて
見る項目目的の達成を何で確かめるか
見直しの時期いつ、何をもって続けるかを判断するか

最後の「見直しの時期」を入れておくと、経営者は判断しやすくなります。一度決めたら続けるのではなく、一定の期間で見直すと約束することで、試しに始めることへの抵抗が下がります。

予算の組み立て全体の考え方は、長期インターンの予算の考え方にまとめています。採用予算を経営に報告するときの型は、採用予算の報告も参考になります。

募集にかかる部分を外に出すと、社員の時間の見積もりも変わります。どこまで任せられるか相談できます。

運用の相談をする

エージェントベストの見解

費用の説明を組み立てる前に、先に確かめておいてほしいのは、説明する相手が何を決めるのかです。始めるかどうかを決めるのか、続けるかどうかを決めるのか、人数を増やすかどうかを決めるのか。始める判断なら、目的と任せる仕事、見直しの時期が中心になります。続ける判断なら、これまでの記録と、指導にかかった時間の変化が中心になります。増やす判断なら、受け入れの上限と、まとめ役の有無が中心になります。同じ一枚の資料でも、相手が決めることによって、強調する欄が変わります。資料を作る前に「この説明で、相手に何を決めてもらうのか」を一文で書いておくと、説明が散らかりません。

問われやすい点と答え方

社内の説明で問われやすい点と、答え方の方向を整理しておきます。

  • 「新卒採用につながるのか」：つながる可能性はあるが、それだけを目的にはしていない、と目的に戻して答える。新卒で採らない方針なら、その考え方は長期インターン生を新卒で採らないと決めたときで整理しています
  • 「途中で辞めたらどうなるのか」：卒業や離脱を前提に、仕事の手順を残す仕組みを作ると答える
  • 「社員の負担が増えるのでは」：社員の時間を費用として見積もり、見直しの時期に確かめると答える
  • 「他の採用手段と比べてどうか」：優劣ではなく、任せる仕事と目的の違いで答える

答えられない問いが出たら、その場で無理に答えず、次の見直しまでに確かめると伝えます。

まとめ

  • 費用は、募集にかかるもの、インターン生に払うもの、社員の時間の三つに分ける
  • 費用の前に、受け入れの目的と任せる仕事を言葉にしておく
  • 比べる相手を確かめ、払うお金ではなく得られるものの違いで説明する
  • 目的・仕事・費用・見る項目・見直しの時期を一枚にまとめる
  • 相手が何を決めるのかによって、資料の強調する欄を変える

よくある質問

媒体の料金だけを示せば十分ではありませんか

媒体の料金だけを示すと、賃金や社員の時間が見えず、後で「思ったより手間がかかる」という話になりがちです。三つに分けて最初から示しておくほうが、続けるかどうかの判断がぶれません。

効果の記録がなく、説明の材料がありません

これから始める場合は、見る項目と見直しの時期を決めて、試しに始める形で説明します。すでに受け入れている場合は、担当社員とインターン生の記憶から、任せた仕事と結果を書き起こすところから始めます。

料金のプランの違いがよく分かりません

プランの仕組みは、受け入れの人数や期間の見通しによって合うものが変わります。選び方の考え方は、Infraのプランの選び方で整理しています。料金の詳細は公式の案内や代理店で確認します。
