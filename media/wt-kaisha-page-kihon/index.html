Wantedlyの会社ページで最初に書くこと｜なにを・なぜ・どうやって

Wantedlyを申し込んで、管理画面を開いて、会社ページの入力欄を前に手が止まる。「何から書けばいいのか」という相談を、Wantedlyを始めたばかりの会社から受けます。結論から言うと、最初に書くのは「なにをやっているのか」「なぜやるのか」「どうやっているのか」の3つで、この順に、会社の想いを自分の言葉で語れる人が書きます。写真とメンバーの紹介は後回しでよく、完璧を目指さず、1本目のストーリーとセットで載せて、更新の起点にします。 会社ページは会社アカウントの作成と同時に作られ、非公開にする機能はなく、編集した内容はすぐに公開されます。完成させてから載せようとすると、その間は中身の薄いページが候補者に見られます。この記事では、会社ページの位置づけ、3つの順番と書き方、書く人、抽象語の避け方、最初に載せるものの判断、やりがちな失敗、社内の分担を整理します。Wantedlyはウォンテッドリー株式会社が運営する、会社と人がつながるビジネスSNSで、募集情報を掲載する場です。この記事ではページの項目の仕様には触れず、書き方の考え方だけを書きます。

この作業の目的｜候補者が「話を聞きに行きたい」と思う入口を作る

Wantedlyでは、候補者は会社ページ、募集記事、ストーリーを読んで、「話を聞きに行きたい」と動きます。この動き方はOfferBoxとWantedlyの違いで書きました。会社ページは、その入口です。

入口なので、会社ページが空か、抽象語で埋まっているか、古いままだと、募集記事とストーリーがどれだけ良くても、候補者は「この会社は」と思う前に離れます。逆に、会社ページで「なにを、なぜ、どうやって」が伝われば、募集記事とストーリーが読まれ、「話を聞きに行きたい」につながります。

会社ページの目的は、会社を説明し尽くすことではなく、候補者が次を読みたくなる入口を作ることです。

手順1｜「なにをやっているのか」を、最初に書く

3つのうち、最初に書くのは「なにをやっているのか」です。候補者が最初に知りたいのは、何の会社かだからです。

書くこと書き方
誰に、何を、どう提供しているか「〇〇に困っている△△に、□□を提供している」の形。業界の言葉ではなく、初めて聞く人に分かる言葉で
事業の全体像は一言で事業が複数あっても、最初は主なもの1つ。全部並べない
会社の規模感数字より様子。「少人数で全員が顧客と会っている」のように
いま力を入れていること候補者が入ったら関わることになる仕事

「なにをやっているのか」で最も多い失敗は、業界の言葉で書くことです。同じ業界の人には分かっても、候補者には分かりません。社外の知人に読んでもらい、「何の会社か分かった」と言われるまで直します。

手順2｜「なぜやるのか」を、代表の言葉で書く

次に「なぜやるのか」です。ここが、Wantedlyで最も読まれ、最も差がつく部分です。

  1. 代表か創業メンバーが書く：人事が代筆すると「借りてきた言葉」になる。書けないなら、話してもらって人事が書き起こし、本人に直してもらう
  2. きっかけを書く：「なぜこの事業を始めたか」の場面。困った経験、見た光景、言われた一言。具体的な出来事が1つあれば、抽象語は要らない
  3. いまも続けている理由を書く：始めたときと、いま。変わったことがあれば、それも
  4. ミッションの言葉があれば添える。無ければ作らない：無理に作ったミッションは、読めば分かる。書き方は会社ページでミッションを伝える書き方で書いた
  5. 「社会を良くしたい」で終わらせない：誰の、何を、どう良くしたいか。そこまで書いて初めて、その会社の「なぜ」になる

「なぜやるのか」は、書く人の言葉でしか書けません。代表が語れる会社は、ここが強く、語れない会社は、ここで止まります。語れないなら、先に候補者や顧客と話して、自社の「なぜ」を掴んでから書くほうが、順番として無理がありません。この順番は共感型と条件型の媒体の違いでも書きました。

会社の想いがすでに言葉になっているか、整理するだけでも媒体は絞れます。相談だけでも構いません。

媒体選びを相談する

エージェントベストの見解

これをやる前に、先に決めておかないと会社ページが書けないことがあります。「なぜやるのか」を、代表が自分の言葉で話せるかどうかです。当社がWantedlyの運用の相談で会社ページを見るとき、「なにをやっているのか」は書けているのに「なぜやるのか」が空か、「社会に貢献」「お客様のために」で埋まっている会社が多くあります。人事が書こうとして、書けないのです。当社は採用媒体の代理店としてWantedlyの契約後の運用を見ていますが、「なぜ」が読まれている会社は、例外なく代表か創業メンバーの言葉で書かれています。人事が代筆した「なぜ」は、候補者に見抜かれます。書けないなら、代表に話してもらい、録音して書き起こし、本人に直してもらう。この手間を省いて人事が書くと、会社ページは「会社紹介」になり、Wantedlyの入口として機能しません。「なぜ」は、書く前に、語れる人を決めることです。

手順3｜「どうやっているのか」を、場面で書く

3つ目は「どうやっているのか」です。仕事の進め方、チームの様子、大事にしていることを、具体的な出来事で書きます。

  • 1日の流れ：朝から夕方まで、誰が何をしているか。職種が複数なら主なもの1つ
  • 決め方：何かを決めるとき、誰がどう決めるか。会議の様子、意見の出し方
  • 働き方の実態：出社と在宅、時間の使い方。良い面だけでなく、大変な面も
  • 大事にしていること：バリューや行動指針があれば、それを「行動」で。「顧客第一」ではなく「顧客の〇〇のために、△△したことがある」。書き方は会社ページでバリューを言葉にする方法で書いた
  • 人：どんな人が働いているか。年齢の幅、前職、性格の傾向。数字ではなく様子で

「どうやっているのか」は、現場の社員に聞くと出てきます。人事が想像で書くと抽象語になります。現場に「昨日1日、何をしましたか」「最近、何かを決めたことはありますか」と聞き、その答えを書きます。

手順4｜抽象語を場面に置き換える

3つを書き終えたら、抽象語を探して置き換えます。Wantedlyの会社ページで多い抽象語を並べます。

抽象語置き換え方
成長できる環境「入社して間もない〇〇は、いま△△を任されている」
風通しがよい「先週の会議で、入社1年目の意見で□□が変わった」
挑戦を歓迎「〇〇が提案した△△を、失敗覚悟で始めた。結果は□□」
アットホーム具体例で書けないなら削る。書けるなら「毎週〇〇をしている」
社会に貢献「誰の、何を、どう良くしたか」を1つ
少数精鋭「〇人で△△をやっている。1人が□□まで見る」のように様子で。人数は書いても書かなくてもよい
お客様第一「顧客の〇〇のために、△△をしたことがある」

抽象語が残っているかは、社外の人に読んでもらうと分かります。「どの会社にも書いてありそう」と言われた部分が、抽象語です。抽象語の置き換えの考え方は、OfferBoxの企業ページで伝えることと同じです。

手順5｜写真とメンバーは後回しでよい

会社ページには、写真とメンバーの紹介も載せられます。ただし、最初に載せる段階では後回しで構いません。

  • 写真：無いよりあるほうがよいが、無いために3つを載せるのが遅れるなら、後で足す。選び方は会社ページの写真の選び方で書いた
  • メンバー：代表と、話を聞きに来た候補者が最初に会う人の2人がいれば足りる。全員を揃えるまで待たない。選び方は会社ページに載せるメンバーの選び方で書いた
  • 最初に載せるもの：「なにを・なぜ・どうやって」の3つと、1本目のストーリーと、話を聞きに来た候補者が最初に会う人の紹介

「全部揃えてから載せる」が最も多い遅れの原因です。3つと1本を先に載せ、写真とメンバーは翌週から足します。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。会社ページに最初の3つを載せるまでの時間と、その後の更新の時間を分けてお伝えします。

運用の相談をする

手順6｜1本目のストーリーとセットで公開し、更新の起点にする

会社ページは、単体では読まれにくいものです。ストーリー（会社の日常や考えを書く記事）が1本あると、候補者がストーリーから会社ページに来る流れができます。

  1. 1本目のストーリーを、会社ページと同時に書く：「なぜやるのか」の経緯を、少し詳しく書いた記事でよい
  2. 会社ページに3つを入れ、ストーリーを公開する：完成ではなく、更新の起点として。会社ページには下書きとプレビューの機能がなく、入れた内容はすぐに公開されるので、文章は先に社内で直しておく
  3. その翌週から、写真とメンバーを足す
  4. ストーリーを月に数本、書き足す：会社ページに人が来る理由を作り続ける。仕組みは会社ページを更新し続ける仕組みで書いた
  5. 会社ページは、卒年の切り替わりや事業の変化で直す：作って終わりにしない

載せて止まる会社が多いのは、WantedlyとGreenの違いでも書きました。

やりがちな失敗

失敗何が起きるか直し方
「なにを」を業界の言葉で書く候補者に何の会社か分からない初めて聞く人に分かる言葉で。社外の人に読んでもらう
「なぜ」を人事が代筆する借りてきた言葉になる代表が話し、書き起こし、本人が直す
「なぜ」が「社会に貢献」で終わるどの会社も同じ誰の何をどう良くしたいかまで
「どうやって」を想像で書く抽象語になる現場に昨日1日を聞く
抽象語を残す他社と見分けがつかない場面に置き換える
写真とメンバーを揃えてから載せる中身の薄いページが見られ続ける3つと1本を先に載せ、後で足す
載せて止まる会社ページに人が来ない1本目のストーリーとセット、月に数本足す
完成させてから載せるいつまでも中身が入らない更新の起点として出す

最も多いのは、「なぜを人事が代筆する」と「写真とメンバーを揃えてから載せる」です。

社内の分担

作業誰が
「なにをやっているのか」の下書き人事（代表と事業部門に確認）
「なぜやるのか」代表か創業メンバー（人事は書き起こしと整理）
「どうやっているのか」の材料現場の社員（人事が聞いて書く）
抽象語の置き換え人事（具体例は現場と代表から）
社外の人に読んでもらう人事が手配
1本目のストーリー代表か、「なぜ」の場面を知っている人
載せる内容の最終確認人事の責任者と代表
写真とメンバーの追加人事（本人の同意を取る）

代表の時間は、「なぜやるのか」を話すことと、書き起こしを直すことの2つに絞ります。書く作業は人事が持ちます。運用代行の考え方は、OfferBoxと同じで、想いを書くことは外に出せませんが、書き起こしと整理と抽象語の置き換えの案は支えられます。

エージェントベストの見解

申し込んだあと、Wantedlyで最初の月に起きやすいのは、「会社ページを完成させようとして、中身を入れるのが遅れる」ことです。写真を撮り直し、メンバー全員の紹介を集め、「なぜ」の文章を何度も直し、気づくと契約期間の最初の月が過ぎています。当社がWantedlyの運用の相談を受けるときは、「なにを・なぜ・どうやって」の3つと、1本目のストーリーと、最初に会う人の紹介、この3点が揃った時点で載せることを勧めます。会社ページは非公開にできず、入れた内容はすぐに公開されるので、待つ間は中身の薄いページが見られています。写真とメンバーは、その翌週から足せます。会社ページは、完成させるものではなく、更新し続けるものです。完成を待つ会社は、中身が入るのが遅れるだけでなく、「完成したから更新しない」に陥ります。最初から更新の起点として出す会社は、中身が入るのが早く、その後も更新が続きます。

まとめ

  • 会社ページは会社を説明し尽くす場ではなく、候補者が次を読みたくなる入口
  • 最初に書くのは「なにを・なぜ・どうやって」の3つ。この順で
  • 「なにを」は初めて聞く人に分かる言葉で、「なぜ」は代表の言葉で出来事から、「どうやって」は現場に聞いて具体的に
  • 抽象語は場面に置き換える。社外の人に読んでもらい「どの会社にも書いてありそう」と言われた部分が抽象語
  • 写真とメンバーは後回し。3つと1本目のストーリーを先に載せ、更新の起点にする

よくある質問

代表が忙しくて、「なぜやるのか」を書く時間がありません

書く時間は要りません。話す時間があれば足ります。人事が代表に「なぜこの事業を始めたのですか」「いまも続けている理由は」と聞き、録音して書き起こし、本人に直してもらいます。代表の時間は、話す時間と、直す時間の2つだけです。

写真が無い状態で載せてよいのですか

構いません。会社ページは非公開にできず、入れた内容はすぐに公開されます。「なにを・なぜ・どうやって」の3つと、1本目のストーリーと、最初に会う人の紹介を先に載せ、写真は翌週から足します。先に載せてから足すほうが、候補者に届く時期が早くなります。

会社ページの作成は、御社に相談できますか

できます。当社は採用媒体の代理店として、Wantedlyの会社ページに最初の3つを載せるまでの手順と、「なぜやるのか」の書き起こしと整理、抽象語の置き換えの案をお手伝いします。
