カスタマーサクセスの長期インターン生の最初の1か月｜任せる仕事と育て方

カスタマーサクセスの長期インターン生を受け入れると、問い合わせの多いチームほど、早く返答を任せたくなります。けれども、顧客への返答は、一度の誤りがサービスへの信頼に響きます。結論から言うと、最初の1か月は「サービスを使う側として覚える」「顧客に出ない仕事」「確認を経て顧客に出る仕事」の順に任せる範囲を広げ、返答の確認を育成の中心に置くと、学生が早く安心して顧客とやりとりできるようになります。 この記事では、Infraで採用したカスタマーサクセスの長期インターン生を受け入れる会社に向けて、週ごとの任せ方と育て方を整理します。

最初の1か月で目指す状態を決める

受け入れの前に、1か月後に学生がどうなっていればよいかを一文で決めます。たとえば「よくある問い合わせへの返答を、回答集をもとに下書きし、社員の確認を経て送れる」といった形です。

カスタマーサクセスで目指す状態を決めるときは、次の三つを確かめます。

  • サービスの理解：顧客がよく使う機能と、よくつまずく箇所を、自分で触って説明できるか
  • 問い合わせの読み取り：顧客が何に困っているのかを、文面から読み取れるか
  • 確認の流れ：どの返答を確認に回し、どの返答を一人で送ってよいかが分かっているか

学生が最初につまずくのは、言葉づかいよりも、顧客の困りごとの読み取りです。問い合わせの文面には、本当に困っていることが書かれていないことがよくあります。目指す状態にこの点を入れておくと、最初の1か月の重心が定まります。

顧客対応を任せる段階の考え方と、名乗り方の決め方はカスタマーサクセスの長期インターンを採るで整理しています。この記事では、その段階を最初の1か月にどう割り当てるかに絞ります。

週ごとの任せ方

最初の1か月は、次のような段階で組むと無理がありません。週の区切りは設計上の例で、学生の稼働日数と問い合わせの量に合わせて調整します。

  1. 一週目：サービスを使う側として覚える：顧客と同じ立場でサービスを触り、迷った箇所を書き出してもらう。過去の問い合わせと返答を読み、よくある問い合わせの種類をまとめる
  2. 二週目：顧客に出ない仕事：回答集の整理と更新、使い方の案内資料の下書き、問い合わせ内容の分類と集計
  3. 三週目：返答の下書き：よくある問い合わせへの返答を下書きし、社員が確認してから送る
  4. 四週目：確認を経て顧客に出る仕事を広げる：定型の案内の送信、社員と一緒にオンラインの説明会に出る、など

一週目の「迷った箇所を書き出してもらう」は、カスタマーサクセスの受け入れで特に効く任せ方です。長く使っている社員には、新しく使い始めた人がどこで迷うかが見えなくなっています。学生が書き出した迷いの一覧は、そのまま案内資料や回答集の改善の材料になります。

カスタマーサクセスの長期インターン生に、最初の1か月で何を任せるか。週ごとの組み方から一緒に考えます。

無料で相談する

返答の確認の流れを決める

カスタマーサクセスの受け入れで、最初に決めておきたいのが、顧客への返答の確認の流れです。次のような流れにしておくと、学生も社員も迷いません。

  1. 学生が下書きする：回答集と過去の返答をもとに作る。分からない点は、下書きの中に印を付けて残す
  2. 社員が確かめる：内容の正しさ、言葉づかい、顧客の困りごとに答えているかを見る
  3. 直した点を学生に返す：どこを、なぜ直したかを一言添える
  4. 学生が送る：送ったあと、対応の記録を決められた場所に残す

あわせて、学生が一人で答えてはいけない問い合わせの種類を決めておきます。料金や契約に関わること、不具合の可能性があること、顧客が強い不満を示していること。こうした問い合わせは、下書きもせずに社員へ渡す決まりにしておくと、学生は判断に迷わずに済みます。

エージェントベストの見解

カスタマーサクセスの受け入れで、最初の1か月のうちに学生が自信をなくす会社に共通するのは、「確認に回す返答と、そうでない返答の線が曖昧」なことです。社員は忙しいと、「簡単なものは自分で送っていいよ」と伝えます。けれども、何が簡単かは学生には分かりません。結果として、学生は全部を確認に回して社員の手を止めるか、判断を誤って送ってしまうかのどちらかになります。当社が勧めるのは、問い合わせの種類ごとに「一人で送ってよい」「確認に回す」「社員に渡す」の三つの箱を、受け入れの前に決めておくことです。最初はほとんどを確認に回す箱に入れておき、同じ種類の返答で指摘がなくなったものから、一人で送ってよい箱に移していきます。箱の中身が少しずつ移っていくことが、学生にとっての成長の手応えになります。

返答の確認で育てる

カスタマーサクセスの職種では、研修の時間を別に取るより、日々の返答の確認で育てるほうが続きます。確認のときに、次の三つの観点で返すと、学生の判断が育ちます。

  • 困りごとに答えているか：顧客が聞いていることだけでなく、その奥で困っていることに届いているか
  • 次の行動が分かるか：返答を読んだ顧客が、次に何をすればよいかが分かるか
  • 言葉が顧客に合っているか：サービスの中の言葉を、顧客が使う言葉に置き換えているか

一つ目の観点は、学生にとって最も難しく、最も伸びる部分です。「この顧客は設定の方法を聞いているけれど、本当は月末の締めの作業に間に合うかを心配している」のように、社員が読み取ったことを言葉にして返すと、学生は問い合わせの読み方を覚えます。

週に一度、その週の確認で多かった指摘を振り返る時間を取ると、個別の指摘が学生自身の判断に変わります。振り返りの進め方は長期インターン生との1on1も参考になります。

つまずきの見つけ方と戻し方

カスタマーサクセスの長期インターン生のつまずきは、次のような様子に表れます。

  • 返答が丁寧すぎて長くなる：失礼がないようにと、前置きが増えている
  • 顧客の強い言葉に引きずられる：厳しい問い合わせのあと、手が止まる
  • 回答集にないことを推測で答える：調べ方が分からず、それらしい答えを書いている

一つ目は、返答の型を決めると改善することが多いです。結論、手順、補足の順で書く型を渡します。二つ目は、強い言葉の問い合わせを社員に渡す箱に入れておくことで防げますが、受け取ってしまったときは、その日のうちに社員が話を聞く時間を取ります。三つ目は、分からないときの調べ方と、聞く相手を改めて伝えます。つまずいたときに前の段階に戻すことは、失敗ではなく計画の調整です。

勤務の時間や学業との両立に関わる調整が必要になることもあります。顧客との打ち合わせは時間帯が決まるため、授業と重なることがあります。インターン生の労働時間や学業への配慮には法令で定められた項目や指針がありますので、詳しくは社会保険労務士や公式の案内で確認してください。

返答の確認に手が回らない、問い合わせの対応の分担を見直したい。運用の相談だけでも構いません。

運用の相談をする

社内の分担

カスタマーサクセスの受け入れでは、次のように役割を分けます。

  • 確認する人：チームの社員。返答の確認、週の振り返り、箱の中身の見直し
  • 受け入れの責任者：目指す状態の決定、一人で送ってよい範囲の判断、月の終わりの振り返り
  • 年の近い社員：仕事以外の相談、強い問い合わせを受けたあとの声かけ
  • 人事・総務：契約、勤怠、顧客の情報を扱う権限の手続き

顧客の情報に触れる仕事なので、扱う情報の範囲は、雇用契約や誓約書の中で確認しておきます。情報の管理の考え方は長期インターン生の情報管理でもまとめています。

エージェントベストの見解

当社は長期インターンの募集を支援する立場で、カスタマーサクセスの学生が長く続く会社とそうでない会社の違いを見てきました。違いが出るのは、顧客からの感謝の言葉を、学生本人に届けているかどうかです。学生が下書きし、社員が確認して送った返答に、顧客から「助かりました」と返事が来る。この返事が社員の受信箱で止まっていると、学生は自分の仕事が顧客に届いたことを知りません。勧めたいのは、学生が関わった返答への顧客の反応を、良いものも厳しいものも、学生に共有する決まりにすることです。厳しい反応も、なぜそうなったかを一緒に見直せば、次の返答の材料になります。カスタマーサクセスは、自分の仕事の結果が顧客の言葉で返ってくる職種です。その言葉を学生に届けることが、最初の1か月の手応えを作ります。

まとめ

  • 最初の1か月は、使う側として覚える、顧客に出ない仕事、返答の下書き、確認を経て顧客に出る仕事の順に任せる
  • 一週目に、学生がサービスを使って迷った箇所を書き出してもらい、案内の改善に使う
  • 問い合わせの種類ごとに、一人で送ってよい、確認に回す、社員に渡す、の三つの箱を決めておく
  • 返答の確認は、困りごとに答えているか、次の行動が分かるか、言葉が顧客に合っているかで返す
  • 学生が関わった返答への顧客の反応を、学生本人に共有する

よくある質問

問い合わせが少なく、返答の練習の機会がありません

過去の問い合わせを使って、返答の下書きを練習してもらう方法があります。実際に送った返答と見比べてもらうと、社員の判断の理由を学ぶ材料になります。回答集の整理や案内資料の作成など、顧客に出ない仕事の比重を上げても構いません。

学生に電話の対応を任せてもよいですか

最初の1か月は、社員の対応を横で聞くことから始めることを勧めます。任せる場合も、話す内容の型を決め、答えられないことは社員に代わる流れを先に決めておきます。

1か月が過ぎても、一人で送ってよい返答が増えません

確認の指摘の種類を分けて見ます。内容の誤りが多いなら回答集を整え、言葉づかいの指摘が多いなら返答の型を見直します。箱の中身を移す基準を学生と共有しておくと、学生も何ができれば次に進めるかが分かります。受け入れの体制全体を見直す考え方は長期インターンの受け入れ体制にまとめています。
