OfferBoxで電気・電子設計を採るオファー文面の書き方

OfferBoxで電気・電子設計を採るとき、文面で最も多い失敗は「電気・電子系の学生なら回路設計に興味があるはずだから、扱う技術を並べれば届く」と考えることです。結論から言うと、電気・電子設計志望の学生に届く文面は、部品名や規格名を並べた文面ではなく、何の製品の、回路・制御・組み込みのどれを設計するかを一つ書き、新卒が最初に担う工程を正直に書き、学生が「回路を組んで動かした」「測って原因を探した」経験に触れ、名義が設計者になっている文面です。 電気・電子系の学生の志望は、電力、インフラ、通信、ソフトウェアまで広く、回路や制御の設計を志望する学生はその一部です。その一部の学生に届くのは、設計の中身が具体的に書かれた文面です。この記事では、電気・電子設計志望の学生がOfferBoxで何を見ているか、文面に書くこと、面談への接続を整理します。文面全体の基本はOfferBoxのオファー文面の基本で書いたので、ここでは電気・電子設計に固有の部分だけを扱います。OfferBoxの仕様や数値には触れず、運用の考え方だけを書きます。

電気・電子設計志望の学生がOfferBoxで見ているもの

電気・電子設計を志望する学生は、オファーを開いたときに、次のことを見ています。

学生が見分けたいこと文面で見ている箇所
何の製品の設計か製品が一つ書いてあるか。何を動かすための回路か
回路か、制御か、組み込みかアナログやデジタルの回路設計か、制御の設計か、組み込みソフトか。境目がどこか
自分で作って測れるか試作の基板を自分で組み、測定器で確かめられる環境か
設計のどこまで関わるか仕様から回路、基板、評価、量産まで、設計者がどこまで見るか
自分の作ったものを読んだか書き出しに、研究の実験回路、電子工作、ロボコンの制御への言及があるか
言葉が正直か部品名や規格名が、実態の説明の代わりになっていないか

二つ目が、電気・電子設計の文面で特に重要です。電気・電子系の学生は、回路とソフトの境目にいます。回路を組みたい学生に組み込みソフトが中心の文面を送っても、組み込みソフトを書きたい学生に回路設計が中心の文面を送っても、面談で分かって離れます。文面で「回路か、制御か、組み込みか」を一つ書くと、その仕事を望む学生だけが残ります。

もう一つ、学生が見ているのは、部品名や規格名の扱いです。人事が調べて並べた部品名や規格名は、設計を志望する学生には見抜かれます。学生が待っているのは、技術の名前ではなく、「その技術で何を作り、どこで苦労しているか」です。

文面に書くこと｜製品一つ、回路か制御か組み込みか、最初に担う工程

電気・電子設計向けの文面は、次の順で組みます。

  1. 書き出し：学生が回路を組んで動かした、測って原因を探した経験に触れる。「読んだ」「こう思った」「だから送った」の三つ
  2. 何の製品の設計かを一つ：公開できる範囲で。何を動かすための、どの部分か
  3. 回路か、制御か、組み込みかを一つ：境目がある場合は、境目がどこかも
  4. 新卒が最初に担う工程を正直に：評価と測定から、なのか、既存回路の改良から、なのか
  5. 次の行動を一つ：設計者との面談の案内だけ

四つ目が、電気・電子設計の文面の中心です。「回路設計をお任せします」では、何をするか分かりません。「最初の年は、先輩が設計した基板の評価で、測定器で波形を取り、仕様と違う箇所の原因を探すところからです。二年目から、既存回路の改良を担当します」のように書きます。評価と測定から始まることを正直に書いても、学生は離れません。測って原因を探す作業が設計の入口であることを、研究で実験回路を組んだ学生は知っています。

書き出しで学生の経験に触れるとき、電気・電子設計の場合は「電気が好き」「回路に興味がある」の言葉ではなく、「組んで動かした」「測って原因を探した」の行動で触れます。「研究で、測定回路のノイズが大きくて、接地の取り方を変えて解決したのを読みました」のような形です。評価はしません。何を組み、何が起き、どう解いたかを読んだ事実と、自社の設計のどこに近いかを書きます。機械設計で「作って動かした」経験に触れる考え方はOfferBoxで機械設計を採るオファー文面の書き方、組み込みソフトが中心の会社はOfferBoxでエンジニアを採るオファー文面の書き方も合わせて読んでください。

電気・電子設計の文面が部品名と規格名で埋まっていて、何を作る会社か書けていない。そう感じたら、製品一つと最初に担う工程を一文にするところから。

運用の相談をする

エージェントベストの見解

電気・電子設計の文面で、発注側が最も誤解しているのは「電気・電子系の学生は、回路設計を志望している」という考え方です。実際には、電気・電子系の学生の志望は、電力会社、インフラ、通信、ソフトウェア開発まで広く、回路や制御の設計を志望する学生はその一部です。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、電気・電子設計で承認と面談が続いている会社は、「電気・電子系なら回路に興味がある」とは考えず、回路設計を志望する少数の学生に、回路設計の中身を具体的に書いて届けています。その少数の学生は、他の電気設計の会社からも文面を受けていますが、多くの文面が「回路設計職募集」と部品名の羅列で、中身が書かれていません。「何の製品の、どの回路を、最初の年はどの工程から」が書かれた文面は、その中で区別されます。電気・電子設計の採用は、専攻の学生の数が多いように見えて、実際に探しているのは少数の学生で、その学生に届くのは中身の具体さです。専攻の広さで安心しないことが、文面を書く前提になります。

部品名・規格名で釣らない

電気・電子設計の文面で、部品名、規格名、開発環境の名前を並べることは、勧めません。理由は三つあります。

  • 学生は名前で会社を選ばない：大学で触った部品や環境と、会社のものが違うのは普通
  • 名前を並べると、設計の中身が消える：何を作り、どこで苦労しているかが伝わらない
  • 人事が調べて書いた名前は、ずれる：使い方や組み合わせが実態と違うと、設計を志望する学生に見抜かれる

書くなら、名前ではなく、設計者が何をするかを書きます。「回路図を自分で描き、基板を起こして、測定器で評価するところまで設計者が見ます」のような形です。文面の失敗の型はOfferBoxのオファー文面でやりがちな失敗で書きました。

検索・ターゲットの考え方との関係

電気・電子設計の文面は、回路を組んで動かした経験が書かれている学生と、専攻と研究テーマだけの学生で、書き出しが変わります。前者にはその経験のどこを読んだかを、後者には研究の進め方と自社の設計のつながりを書きます。また、回路を志望する学生と組み込みソフトを志望する学生では、送る文面そのものが変わります。検索の段階で「この検索の相手には、書き出しに何を置くか」を決めておきます。検索の考え方は、次の記事で書きます。

選考への接続｜設計者が面談で測定の話をする

電気・電子設計向けの文面は、面談で設計者が設計と評価の話をすることを前提に書きます。

  • 面談の担当は、名義になった設計者か、同じ製品の設計者：人事だけで面談をしない
  • 文面で触れた「組んで動かした」「測って原因を探した」経験を、面談で聞く：何を組み、何が起き、どう解いたか
  • 自社の製品と基板を、面談で実物か図面で見せながら話す：文面で書いた一つを、実際の工程で
  • 回路か制御か組み込みかは、面談でも同じことを言う：文面と面談で違うと、学生はそこで離れる

文面と面談で話すことが揃っていると、承認から面談、面談から選考への流れが読めます。面談の組み方はOfferBoxの面談設計、現場の社員を面談に出す整え方はOfferBoxの面談に現場の面接官を出すで書きました。

設計者が忙しくて文面に関われず、人事が技術の名前を調べて書いている。そう感じたら、設計者から「測って原因を探した」一つの話を取るところから。

運用の相談をする

エージェントベストの見解

電気・電子設計で申し込んだ会社が、最初の数週間で共通してつまずくのは、設計者が文面に関われず、人事が製品カタログや技術資料から部品名と規格名を拾って文面を書き、承認が付かない、という流れです。当社が運用を見ている会社でも、この流れに入った会社は、文面の技術の言葉を増やす方向に直そうとして、さらに承認が落ちます。抜け方は、技術の言葉を増やすことではなく、設計者から「最近、測って原因を探した一つの話」を取ることです。「量産前の評価で、温度を上げると出力が不安定になり、原因を探したら部品の配置だった」のような一つの話があれば、文面は「うちの設計はこういう仕事です」に変わり、学生の「測って原因を探した」経験とのつながりも書けます。設計者に頼むのは、この一つの話と、送る前の確認と、面談の三つで、文面の組み立ては人事が持ちます。電気・電子設計の文面で最初に用意するのは、技術の一覧ではなく、設計者の「測って、原因を探した」一つの話です。それがあれば、部品名を並べる必要はなくなります。理系学生に送る文面の基本はOfferBoxで理系学生を採るで書きました。

社内の分担

作業担当決めておくこと
「製品一つ」と「回路か制御か組み込みか」設計部の責任者公開できる範囲で。境目があるなら境目も
「測って原因を探した」一つの話名義になる設計者何が起き、何を測り、原因は何だったか
新卒が最初に担う工程の一文設計部の責任者正直に。評価と測定からなら、そう書く
学生の作ったものを読み、近さを一言名義の設計者（一通あたり数分）評価ではなく、自社の設計のどこに近いか
文面を型に入れて組み立てる人事（または運用代行）部品名・規格名を並べない
面談で経験を聞き、製品と基板を見せる名義の設計者文面に書いたことを同じ言葉で

設計者に頼むのは、一つの話と、近さの一言と、確認と、面談です。「製品一つ」「回路か制御か組み込みか」「最初に担う工程」は責任者が決めます。

やりがちな失敗

失敗何が起きるか直し方
部品名・規格名・開発環境の名前を並べる設計の中身が消え、人事が書いたと分かる設計者が何をするか、一つの話で書く
「回路設計職募集」で止める何の製品の、どの回路か分からない製品一つと、回路か制御か組み込みかを書く
回路とソフトの境目を書かない回路を望む学生に組み込みの仕事が当たり、面談で離れるどれか一つと、境目を書く
「電気が好き」で学生に触れるどの文面にも同じ言葉が並ぶ組んで動かした・測って原因を探した行動で触れる
人事名義で送り、人事だけで面談する測定の話ができず、読んだことが伝わらない設計者の名義にし、面談に出る

まとめ

  • 電気・電子系の学生の志望は広く、回路や制御の設計を志望するのは一部。その学生に届くのは中身の具体さ
  • 何の製品の設計かを一つ、回路か制御か組み込みかを一つ、新卒が最初に担う工程を正直に
  • 学生には「電気が好き」ではなく「組んで動かした・測って原因を探した」で触れ、評価しない
  • 部品名・規格名で釣らない。設計者の「測って原因を探した」一つの話を文面の中心に置く
  • 名義は設計者。面談で同じ経験を聞き、同じ製品と基板を見せる

よくある質問

最初の年は評価と測定ばかりで、設計はさせられません。正直に書くと来ないのでは

正直に書きます。評価と測定が設計の入口であることを、研究で実験回路を組んだ学生は知っています。書き方は「最初の年は先輩の基板の評価で、波形を取り、仕様と違う箇所の原因を探す」のように、測定の先に何があるかまで書きます。「原因を探す」が書かれていれば、測るだけの仕事ではないと伝わります。隠して「回路設計をお任せします」と書くと、面談で分かった学生が離れます。

回路とソフトの両方をやってもらう予定です。どちらで書くべきですか

最初の年に多いほうで書きます。両方を並べると、回路を望む学生にもソフトを望む学生にも中身が伝わりません。「最初の年は回路の評価が中心で、二年目から組み込みソフトにも入ります」のように、順番を書きます。境目が決まっていない会社は、文面を書く前に、最初の年の仕事を一つ決めるほうが先です。

電気・電子設計の文面は、運用代行に頼めますか

頼めますが、「製品一つ」「回路か制御か組み込みか」「最初に担う工程」「測って原因を探した一つの話」と、名義になる設計者は社内で用意しておきます。代行に任せられるのは、学生の作ったものを読み、決まった話とつなげて書き、名義の設計者に確認を回す作業です。話と担当が用意されていないと、代行は部品名を並べるしかなく、人事が書いた文面と同じになります。範囲の決め方は運用代行に任せる範囲で書きました。
