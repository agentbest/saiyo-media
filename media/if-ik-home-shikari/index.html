長期インターン生の褒め方と注意の仕方

長期インターン生を指導する社員から、「どこまで厳しく言ってよいか分からない」「褒めているつもりが伝わっていない」という声をよく聞きます。学生だからと遠慮して注意できず、同じ間違いが続く。反対に、社員と同じ調子で注意して、本人が萎縮してしまう。結論から言うと、褒めるときも注意するときも、「具体的な行動」と「その結果」を、時間を置かずに伝えるという型は同じです。 この記事では、褒め方と注意の仕方の型、伝える場所とタイミング、言ってはいけないこと、同じことが続くときの対応を整理します。

褒めることと注意することは、同じ型でできる

褒めることと注意することは、反対のことのように思えます。しかし、伝え方の型は共通しています。

  1. 行動を具体的に言う：「よく頑張った」「ちゃんとして」ではなく、何をしたかを言う
  2. 結果を伝える：その行動で、誰に、どんな影響があったかを言う
  3. 次につなげる：褒めるときは「この調子で」ではなく何を続けてほしいか、注意するときは次にどうしてほしいかを言う

たとえば、褒めるときは「議事録を会議の当日に出してくれたので、参加できなかった人がすぐに内容を確かめられた。次の会議でも同じように出してほしい」。注意するときは「顧客への返信を確認前に送ってしまったので、内容を後から訂正することになった。次からは、送る前に一度見せてほしい」。どちらも、行動・結果・次の三つがそろっています。

この型を使うと、褒め言葉が大げさにならず、注意が人格への批判になりません。長期インターン生は、社員よりも言葉を重く受け止めやすいため、型があると伝える側も安心して話せます。

褒め方｜小さなことを、すぐに

長期インターン生を褒めるときの注意点は次のとおりです。

  • 小さなことを褒める：大きな成果を待つと、褒める機会がほとんどない。手順どおりにできた、早めに質問できた、といった小さな行動を拾う
  • すぐに伝える：出勤の間が空くため、次の出勤日まで待つと本人が覚えていない。その日のうちに伝える
  • 結果を見せる：作った資料が会議で使われた、集めたデータで判断ができた、といった結果を、本人が見える形で伝える
  • 人前で褒めることも考える：部署の会議で仕事の結果を紹介すると、本人の手応えになる。ただし、人前が苦手な学生もいるため様子を見る

3つ目は、とくに長期インターンで効きます。インターン生は、自分の作業がその後どう使われたかを知る機会が少ないためです。フィードバックの頻度の組み方は長期インターン生へのフィードバックの頻度で扱っています。

指導する社員の伝え方をそろえるための、受け入れ側の準備から相談できます。

注意の仕方｜一対一で、一つずつ

注意するときの注意点は次のとおりです。

  1. 一対一で伝える：他の社員やインターン生の前で注意しない
  2. 一度に一つ：気になる点が複数あっても、一度に伝えるのは一つか二つに絞る
  3. 事実から入る：「いつも」「また」といった言葉を使わず、その日の行動から話す
  4. 理由を聞く：なぜそうしたのかを聞く。手順書が分かりにくかった、質問できる相手がいなかった、といった理由が分かることがある
  5. 次の行動を一緒に決める：注意だけで終わらせず、次にどうするかを本人と決める

4つ目が大切です。インターン生の間違いの多くは、本人の不注意よりも、手順や責任範囲が伝わっていなかったことが原因です。理由を聞けば、会社の側で直すべき点が見つかります。責任範囲の決め方は長期インターン生の責任範囲の決め方で、手順書の作り方は長期インターン向けのマニュアルの作り方で整理しています。

エージェントベストの見解

相談で多い思い込みは、「インターン生は学生だから、注意は控えめにしたほうがよい」というものです。実際には、注意されないまま同じ間違いを続けることのほうが、本人にとってつらい経験になります。後から別の社員に強く言われたり、任される仕事が減ったりして、理由が分からないまま居づらくなるからです。インターン生の多くは、仕事の経験を得たいと考えて応募しています。具体的な注意は、その期待に応えることでもあります。控えるべきなのは注意そのものではなく、人前で言う、まとめて言う、人柄を責める、という伝え方です。行動・結果・次の型で一対一で伝えれば、注意を控える理由はほとんどありません。

言ってはいけないこと

伝える型を守っていても、次のような言葉は避けます。

  • 人柄を責める言葉：「だらしない」「やる気がない」など、行動ではなく人を評価する言葉
  • 他の人と比べる言葉：「前のインターン生はできた」「同じ学年の社員は」など
  • 学生であることを持ち出す言葉：「学生だから分からないだろうけど」「学生気分で」など
  • 学業や私生活に踏み込む言葉：試験や授業を理由に休むことを責める、私生活の過ごし方に口を出す

4つ目は、長期インターンならではの注意点です。学業との両立は、長期インターンの前提です。試験期間の出勤や休み方は、受け入れの前に決めておき、個別に責めないようにします。学業との両立の考え方は長期インターンと学業の両立で扱っています。

職場での言動については、ハラスメントの防止について法令で定められた項目や指針があります。インターン生への接し方も含め、社内のルールの作り方で迷う点は、社労士や公式の案内で確認してください。

同じことが続くときの対応

注意しても同じことが続く場合は、伝え方より先に、仕組みを見直します。

  1. 手順書と責任範囲を確かめる：本人が見返せる形で、やり方と判断の線が書かれているか
  2. 任せる仕事の難しさを確かめる：本人の慣れに対して、仕事が難しすぎないか
  3. 出勤の間隔を確かめる：間が空きすぎて、前回のことを忘れていないか
  4. 指導する社員以外が話す：部署の責任者や相談役の社員が、本人の困りごとを聞く

それでも続く場合は、任せる仕事を変えることも考えます。本人のやる気が下がっているように見えるときは長期インターン生のやる気が下がったときの関わり方も参考になります。

エージェントベストの見解

当社は人材紹介も行っているため、若手が前の職場を離れた理由を聞く機会があります。理由として挙がるのは、厳しく注意されたことよりも、「何がよくて何が悪いのか言われなかった」ことのほうが多い印象です。褒められも注意されもしない状態は、本人にとって最も判断のつかない状態です。長期インターン生も同じで、褒めることと注意することの両方がそろって、初めて「見てもらえている」と感じます。指導する社員に伝えておきたいのは、褒める回数を注意より多くすることです。小さな行動を拾って褒めておくと、注意が必要になったときも、本人は「この人は自分のことを見ている」と受け止め、指摘を聞き入れやすくなります。

受け入れてからの指導の悩みや、インターン生との関わり方の相談だけでも構いません。

運用の相談をする

まとめ

  • 褒めるときも注意するときも、行動・結果・次の三つを、時間を置かずに伝える
  • 褒めるときは、小さな行動をすぐに拾い、作業の結果を本人に見せる
  • 注意するときは、一対一で、一度に一つ、理由を聞いてから次の行動を決める
  • 人柄を責める、比べる、学生であることや学業を持ち出す言葉は使わない
  • 同じことが続くときは、手順書・責任範囲・仕事の難しさ・出勤の間隔を見直す

よくある質問

褒めすぎると、インターン生が慢心しませんか

行動と結果を具体的に伝える褒め方であれば、慢心にはつながりにくいです。大げさな言葉で人柄を褒めるより、何が良かったかを伝えるほうが、本人も次に何を続ければよいか分かります。

チャットで注意してもよいですか

小さな作業の訂正であればチャットでも構いません。ただし、本人が気にしそうな内容や、繰り返しの注意は、文字だけで伝えると強く受け止められることがあります。顔を合わせて、またはオンラインで話すほうが伝わりやすいです。

指導する社員によって、伝え方がばらばらです

行動・結果・次の型と、言ってはいけない言葉を、部署で共有しておきます。指導役の選び方と伝えておくことは長期インターン生を指導する社員の選び方で整理しています。
