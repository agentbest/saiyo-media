自治体、独立行政法人、業界団体、財団、組合など、官公庁や団体が新卒を採る。官公庁は独自の採用試験と日程があり、民間の採用媒体を使えるかどうかは各機関の規定で決まる。団体は民間に近い形で採用していることが多く、媒体を使える。学生の多くは「安定」を求めて来るが、「安定」の中身と、仕事の実態を確かめられず、入ってから「思っていたのと違う」で離れる。結論から言うと、官公庁・団体の媒体選びは、まず「民間の媒体を使えるか」を各機関の規定で確かめ、使える団体では、学生が確かめる「安定の中身」「試験との両立」「仕事の実態」を書けるかで、3媒体のどれを先に検討するかを分けます。官公庁で媒体を使えない場合は、媒体ではなく、独自の試験と日程の中で、仕事の実態を伝える方法を整えます。 この記事では、官公庁・団体の採用構造、媒体利用の可否の確かめ方、判断軸の当て方、学生が確かめること、使える団体でどれを先に検討するか、組み合わせ、見せ方、分担を整理します。3媒体の全体像はOfferBox・Wantedly・ワンキャリアの違いと選び方で書きました。数値と料金は書きません。優劣は断定しません。媒体を使えるかどうかは、各機関の規定と各媒体の利用の条件で、現在の内容を確認してください。

官公庁・団体の採用構造と、媒体との相性

区分採用の形媒体との相性
官公庁（自治体、省庁など）独自の採用試験と日程が中心。民間の媒体を使えるかは規定で決まる使えない場合が多い。使える場合も、試験と日程の中で位置づける
独立行政法人、公的な機関機関ごとに独自の採用か、民間に近い採用か規定で確認。民間に近いなら媒体を使える
業界団体、財団、社団、組合民間に近い採用が多い。少人数で、採用の経験が少ない媒体を使える。中小企業と同じ考え方が当てはまる
業界の特徴採用で起きること媒体との相性
学生が「安定」を求めて来る「安定」の中身（雇用、異動、評価）を確かめられず、入ってから離れる安定の中身を書ける媒体の使い方
試験や日程が独自学生は試験勉強と民間の就職活動を両立している試験と両立できる時期と伝え方
仕事の実態が外から見えにくい「何をする仕事か」が制度の名前でしか伝わらない仕事の場面を書く・見せる媒体の使い方
少人数の団体は、採用の経験が少ない型がなく、事務局長や理事が採用作業を外に出せる型か、書く時間を取れる型か
知名度は、分野の中に限られる学生は団体名で探さない送る型か記事を置く型で、まず知ってもらう

官公庁・団体の採用は、「安定を求める学生に会えるか」より、「会えた学生に、安定の中身と仕事の実態を伝えられるか」で決まります。

まず、民間の媒体を使えるかを確かめる

  1. 自機関の規定を確認する：民間の採用媒体を使えるか、使えるならどの範囲か。企業からのスカウトの形が使えるか、掲載の形だけか
  2. 各媒体の利用の条件を確認する：官公庁や団体が利用できるか、どんな募集に使えるか。各媒体の公式ページと利用のルールで現在の内容を。この記事では条件を書かない
  3. 使えない場合：媒体ではなく、独自の試験と日程の中で仕事の実態を伝える方法（説明会、職場見学、職員の話）を整える。この記事の「見せ方」は、媒体を使わない場合にも当てはまる
  4. 使える場合：以下の判断軸と、先に検討する型へ

自社に合う媒体がどれか、3媒体を並べてご案内します。官公庁・団体で、民間の媒体を使えるかの確認から、使える場合の型の選び方まで一緒に整理します。

媒体選びを相談する

エージェントベストの見解

これをやる前に、先に「民間の採用媒体を、自機関が使えるか」を規定で確かめておかないと、媒体の選び方を考えても始まりません。当社は3媒体すべての販売パートナーとして、団体や公的な機関からの相談を受けますが、「どの媒体がよいか」の相談に、まず規定と各媒体の利用の条件を確認してもらうと、使えない、または使える範囲が限られる、と分かることがあります。使えない場合、媒体の話は終わりで、代わりに、独自の試験と日程の中で仕事の実態を伝える方法を整えることが、学生が「思っていたのと違う」で離れることを減らします。使える団体（業界団体、財団、組合など）は、中小企業と同じ考え方で、少人数の事務局の時間の形と、仕事の実態を書けるかで型を分けます。当社は、使えるかの確認を媒体の提案の前に置いています。

判断軸を、媒体を使える団体に当てる

軸団体での見方
対象（誰に届くか）「安定志向」の学生は官公庁と大企業も見ている。団体に来るのは、分野への関心と、安定の中身を知ったうえで選ぶ学生
型（送るか、来るか、比べられるか）送る型は、分野への関心の記述で絞れる。来る型は、仕事の実態と安定の中身を書けるかで届く。比べられる型は、学生の候補に入ってから
課金（費用の性格）各媒体の公式ページで現在の条件を確認。この記事では書かない。予算の承認の手続きが長い団体は、年度の前に
運用工数（誰の時間が要るか）事務局の時間が上限。送る型は作業を外に出せる。来る型は、職員が仕事の場面を話す時間が要る

軸の詳しい見方は掲載型とスカウト型の違い、共感型と条件型の媒体の違いで書きました。団体では、「課金」の軸で予算の承認の手続きに時間がかかることを、年度の前に見込みます。

学生が、確かめること

  • 「安定」の中身：雇用の形、異動の有無と範囲、評価の仕組み、定年までの道。「安定しています」ではなく、中身で
  • 試験との両立：官公庁の試験を受けながら、団体の選考も受けられるか。時期の重なり
  • 仕事の実態：日々、何をしているか。事務、会員対応、事業、調査、広報。制度の名前ではなく、一日の場面
  • キャリアの道：数年後に何を任されるか。異動があるなら、どんな部署をどう回るか
  • 職員はどんな人か：少人数の団体は、一緒に働く職員との相性が大きい
  • 辞めた人がいるか、なぜか：「安定」の団体を辞めた理由は、学生が最も知りたいこと

この条件なら、どれを先に検討するか

団体の条件先に検討する型理由
職員が、仕事の実態と安定の中身を自分の言葉で書ける・話せる通年で記事を置く型（Wantedly）「安定」の中身と一日の場面を読んで、知ったうえで来る学生に届く。記事が残る
事務局が少人数で、書く時間がないが、分野への関心で絞れる企業から送る型（OfferBox）作業を外に出せ、事務局は面談だけ。記述の関心で絞れる。利用の可否は確認
分野で知られていて、学生の候補に入り、選考の流れを透明に出せる学生が並べて比べる場（ワンキャリア）比べる対象に入ってから。団体で先にすることは少ない
官公庁で、媒体を使えない媒体ではなく、試験と日程の中で実態を伝える説明会、職場見学、職員の話
安定の中身と仕事の実態の一枚が、まだないどれも先ではない一枚を作ってから

どれか一つが正解ではなく、使えるか、書けるか、絞れるか、候補に入っているかで、先に検討するものが変わります。

組み合わせ

  • 記事を置く型と送る型を組み合わせるなら：記事で仕事の場面と安定の中身を、文面で「あなたの〇〇への関心を読んで」を。WantedlyとOfferBoxの併用
  • 官公庁の試験の時期と重ねない：学生が試験勉強をしている時期を避け、両立できる時期に送る・会う
  • 学校との関係と組み合わせる：団体は、学校の推薦や紹介で採ることもある。学校で会った学生に媒体で送らない。OfferBoxと大学キャリアセンター経由の採用の併用
  • 一年目は一つ：事務局の時間が足りるかを一年目で見る。媒体を何本併用するか

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。団体の事務局の時間だけで回す形と、職員が仕事の場面を話す時間を取る形の両方をお伝えします。

運用の相談をする

見せ方｜「安定」の中身と、仕事の実態

  • 「安定しています」ではなく、中身で：「雇用は〇〇の形で、異動は△△の範囲で、評価は□□の仕組みです」
  • 仕事の実態を、制度の名前ではなく一日の場面で：「朝は会員からの問い合わせ、午後は◇◇の事業の準備」
  • 辞めた人がいるなら、理由と変えたことを：「安定」の団体を辞めた理由を隠すと、不信になる
  • 試験との両立を、時期で：「選考は〇月で、試験の時期と重なりません」。両立できる形を先に
  • 「社会に貢献」「公共性」の一語で済ませない：企業も同じ言葉を使う。誰の、何を、どう支えているかで
  • 業界イメージ（堅い、変わらない、年功）を否定しない：事実は認め、実態を書く。業界イメージが不利な会社のWantedlyの書き方
  • 媒体を使えない官公庁でも、この見せ方は説明会と職場見学で

社内の分担

作業誰が
民間の媒体を使えるかの、規定と利用の条件の確認事務局長、または人事担当
安定の中身と仕事の実態の一枚事務局長と職員
書けるか・絞れるか・候補に入っているかで、先に検討する型を決める事務局長（整理は代行が支える）
「こんな人」の一行（分野への関心、続けた経験）事務局長と職員
送る型なら、検索・下書き・送信・一次返信代行
記事を置く型なら、職員が場面を話し、整えるのは外に職員と代行
面談事務局長と、一緒に働く職員
予算の承認の手続き事務局長。年度の前に
  • 事務局の時間は、一枚と面談に：作業は外に。運用代行に出す前提の媒体の選び方
  • 少人数の団体の窓口の決め方：専任の人事がいない会社のOfferBox運用

運用代行や代理店が支えられるのは、利用の可否の確かめ方の整理、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分までで、規定の確認、一枚の中身、安定の中身の開示、面談、予算の手続きは団体が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

相談で最も多い思い込みは、「安定を求める学生が多いので、団体は黙っていても応募が来る」というものです。当社は3媒体すべての販売パートナーとして、団体の相談を受けますが、応募は来ても、面談や内定のあとに「異動はどのくらいありますか」「評価はどう決まりますか」「辞めた人はいますか」と聞かれ、答えが「安定しているので」で止まって離れる、という形が多くあります。学生が求めているのは「安定」の言葉ではなく、雇用・異動・評価の中身と、それでも辞めた人がいるなら理由で、中身が書けない団体は、応募は来ても残りません。当社が団体に媒体の前に用意してもらうのは、安定の中身と仕事の一日の場面と辞めた人の理由の一枚で、一枚があれば、どの媒体でも、また媒体を使えない官公庁の説明会でも、学生が「知ったうえで来る」形になります。

まとめ

  • 官公庁・団体の媒体選びは、まず「民間の媒体を使えるか」を自機関の規定と各媒体の利用の条件で確かめる。使えない官公庁は、試験と日程の中で仕事の実態を伝える方法を整える
  • 使える団体（業界団体、財団、組合など）は、中小企業と同じ考え方。事務局の時間の形と、仕事の実態を書けるかで型を分ける
  • 学生が確かめるのは「安定」の中身（雇用・異動・評価）、試験との両立、仕事の一日の場面、辞めた人の理由。「安定しています」では残らない
  • 職員が場面と中身を書ける団体は記事を置く型を、少人数で書く時間がないが分野への関心で絞れる団体は企業から送る型を先に。並べて比べる場は候補に入ってから
  • 媒体の前に、安定の中身と仕事の実態の一枚を作る。試験の時期と重ねず、学校で会った学生に送らず、予算の手続きは年度の前に

よくある質問

自治体ですが、民間の媒体を使えますか

自機関の規定と、各媒体の利用の条件で、現在の内容を確認してください。この記事では可否を書きません。使えない場合は、独自の試験と日程の中で、説明会と職場見学と職員の話で、仕事の実態と安定の中身を伝える形を整えます。この記事の「見せ方」は、媒体を使わない場合にもそのまま当てはまります。

「安定」を前面に出すと、挑戦したい学生が来なくなりませんか

「安定」を前面に出すのではなく、安定の中身（雇用・異動・評価）を隠さず書き、仕事の一日の場面と、数年後に任されることを書きます。中身が書かれていれば、安定を求める学生も、仕事の中身で選ぶ学生も、それぞれ判断できます。「安定」の一語だけを前面に出すと、どちらの学生も判断できません。

官公庁・団体の媒体選びは、御社に相談できますか

できます。当社は、利用の可否の確かめ方の整理、一枚の型、型の選び方の整理、文面と記事の型、送る型の作業、記事を整える部分を支えられます。規定の確認、一枚の中身、安定の中身の開示、面談、予算の手続きは、団体が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体を並べてご案内しています。3媒体の全体像は3媒体の違いと選び方にまとめています。
