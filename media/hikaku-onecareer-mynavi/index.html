ワンキャリアとマイナビの違い｜学生が見に来る理由が違う

「マイナビに載せている。ワンキャリアにも載せる意味はあるか」「どちらも掲載型なら、片方で足りるのではないか」という相談を受けます。結論から言うと、どちらも学生が見に来る型ですが、見に来る理由が違います。マイナビには募集情報を探しに来て、ワンキャリアにはクチコミや選考体験談を見に来ます。 この違いは、企業が置く情報の種類と、社内で誰が何をするかを変えます。マイナビは株式会社マイナビが運営する就職情報サイト、ワンキャリアは株式会社ワンキャリアが運営する、クチコミと選考体験談を土台にした新卒向けの媒体です。この記事ではマイナビの仕様や料金には触れず、学生が見に来る理由の違いが採用の設計にどう効くかを整理します。

学生が見に来る理由が違う

ナビ型のマイナビでは、学生は「どんな会社が募集しているか」を探しに来ます。業界や勤務地などの条件で検索し、一覧から企業を見て、エントリーします。企業が置くのは募集情報と説明会の案内で、学生はそれを読んで応募するかを決めます。

ワンキャリアでは、学生は「この会社の選考はどうだったか」「実際に働いている人はどう言っているか」を見に来ます。クチコミと選考体験談が土台にあり、そこにインターンや本選考の情報、イベント、スカウトが載っています。企業が置くのは企業ページとイベント情報ですが、学生が読むものの中心は、企業が置いたものではなく、他の学生や社員が書いたものです。

観点ワンキャリアマイナビ
学生が見に来る理由選考体験談・クチコミを読む募集情報を探す
企業が置くもの企業ページ・イベント情報募集情報・説明会案内
学生が読むものの中心他の学生・社員が書いたもの企業が書いたもの
企業が直接コントロールできる範囲一部（置いた情報だけ）大部分（掲載原稿）

この違いが意味するのは、ワンキャリアでは「企業が書いたものだけでは印象が決まらない」ということです。ナビ型と同じ感覚で企業ページを置いて終わりにすると、学生が読んでいるものと企業が見せたいものがずれます。

企業が置く情報と、クチコミへの向き合い方

ナビ型では、掲載原稿の質がほぼすべてです。募集要項、仕事内容、会社の特徴、説明会の案内。ここを整えれば、学生の読むものは整います。

ワンキャリアでは、企業ページとイベント情報に加えて、クチコミと選考体験談への向き合い方が要ります。向き合うといっても、書き換えることはできません。できるのは、次のことです。

  1. 自社のクチコミと選考体験談を読む：学生が何を見て自社を判断しているかを知る
  2. 選考の運用を直す：体験談に「連絡が遅い」「面接で何を見ているか分からない」とあれば、選考そのものを直す
  3. 企業ページで補う：クチコミで誤解されやすい点を、企業ページとイベント情報で先に説明する
  4. イベントで直接会う：クチコミで判断される前に、学生と会う場を作る

つまり、ワンキャリアの運用には「選考を直す」という、媒体の外の仕事が含まれます。これが、ナビ型と最も違う点です。

いま使っている媒体の運用の相談だけでも構いません。クチコミにどう向き合うかから、一緒に整理します。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「ワンキャリアもナビと同じで、掲載原稿を出せば終わり」というものです。実際には、ワンキャリアで学生が読んでいるのは、企業が置いたものより、他の学生が書いた選考体験談です。企業ページを整えても、体験談に「面接の連絡が遅い」と書かれていれば、学生はそちらを信じます。当社が3媒体すべての販売パートナーとして契約後の運用を見ている経験では、ワンキャリアで成果が出る会社は、掲載を整えた会社ではなく、体験談を読んで選考の運用を直した会社です。連絡の速さ、面接で何を見ているかの説明、辞退した学生への対応。この3つを直すと、体験談の内容が変わり、企業ページを読みに来る学生の温度が変わります。申込前に「自社の選考体験談を読んで、直せる点があるか」を確認してから決めることを勧めます。

社内の分担が違う

ナビ型の作業は、人事が中心です。掲載原稿を整え、説明会を運営し、応募に対応する。現場社員は説明会の登壇と面接で関わります。

ワンキャリアの作業は、人事だけでは完結しません。選考体験談に書かれた内容を直すには、面接官である現場社員の協力が要ります。「面接で何を見ているかを最初に説明する」「結果の連絡を早める」といった直し方は、面接官の動きを変えることだからです。

観点ワンキャリアマイナビ
人事の主な作業企業ページ・イベント・体験談の確認・選考の運用改善掲載原稿・説明会・応募対応
現場の関わり方面接の進め方を変える協力説明会の登壇・面接
止まりやすい場面体験談を読まなくなったとき応募対応に追われ、更新が止まったとき

「現場に面接の進め方を変えてもらえるか」が、ワンキャリアを活かせるかの分かれ目です。

この条件ならどちらを先に検討するか

優劣ではなく、先に検討する順番として置きます。

  • 学生像が広く、まず母集団を大きく持ちたい。説明会を回す体制がある → マイナビのようなナビ型を先に
  • 選考の途中や内定後に辞退が多い。学生が何を見て判断しているか分からない → ワンキャリアを先に。体験談を読むところから
  • 人事が兼務で、応募対応の一斉の山を捌く余裕がない → ワンキャリアの企業ページとイベントで、見に来た学生に絞って対応する形を先に
  • 現場が面接の進め方を変える協力をしてくれる → ワンキャリアが活きる
  • 現場の協力は面接の実施までで、進め方の変更は難しい → ナビ型を先に。ワンキャリアは体験談の確認だけでも価値がある

自社に合う媒体がどれか、当社が扱う3媒体を並べてご案内します。申込前提ではありません。

媒体選びを相談する

併用するときの役割

ナビ型にすでに載せている会社が多いので、その前提で分担を書きます。

  1. 母集団の入口はナビ型に：説明会とエントリーの窓口として残す
  2. 学生が判断する場面はワンキャリアで：応募した学生が選考の途中で自社を調べるとき、体験談と企業ページを読む。ここを整える
  3. 選考の運用を直す：体験談に書かれた点を、面接官と一緒に直す。直した結果は、ナビ型から来た学生にも効く
  4. イベントは目的を分ける：ナビ型の説明会は募集の説明、ワンキャリアのイベントは体験談で判断される前に会う場、と役割を分ける
  5. 選考フローは1本にする：入口が違うだけで、途中から別扱いにしない

ナビ型で集めた学生が、選考の途中でワンキャリアの体験談を読んで判断する、という流れは、企業が併用していなくても起きています。併用するかどうかにかかわらず、自社の体験談を読んでおくことは、ナビ型の成果にも効きます。

エージェントベストの見解

申し込んだあと、ワンキャリアで最初の数ヶ月で運用が止まる会社に共通するのは、「企業ページを整えて、体験談を読まなくなる」ことです。ナビ型の感覚で掲載を整えた時点で作業が終わったと感じ、その後は反応を見るだけになります。ところが学生が読んでいるのは体験談なので、企業ページを整えても学生の判断は変わらず、「載せたのに効かない」となります。当社が契約後の運用まで見ている立場から勧めるのは、申込前に自社の体験談を読み、直せる点を3つ書き出し、そのうち1つを面接官と一緒に直すところまでやることです。それができる会社は、ワンキャリアに載せる意味があります。できない会社は、先にナビ型で母集団を作り、選考の運用を直す準備ができてからワンキャリアを足す順番のほうが、費用が無駄になりません。

まとめ

  • ワンキャリアとマイナビはどちらも学生が見に来る型だが、見に来る理由が違う。募集情報を探すか、体験談を読むか
  • ナビ型は掲載原稿の質がほぼすべて。ワンキャリアは企業ページに加えて、体験談を読んで選考の運用を直す仕事が含まれる
  • ワンキャリアを活かせるかは、現場が面接の進め方を変える協力をしてくれるかで決まる
  • 併用するなら、母集団の入口はナビ型、学生が判断する場面はワンキャリア。選考フローは1本にする
  • 併用するかどうかにかかわらず、自社の選考体験談を読んでおくことは、ナビ型の成果にも効く

よくある質問

マイナビに載せていれば、ワンキャリアは要りませんか

母集団の入口としてはナビ型で足りることがあります。ただし、応募した学生が選考の途中で自社を調べるとき、読んでいるのはワンキャリアの体験談であることが多いです。辞退が多い、学生が何を見て判断しているか分からない、という会社は、ワンキャリアの体験談を読むところから始める価値があります。

クチコミに悪いことが書かれています。載せないほうがいいですか

載せるかどうかにかかわらず、学生はその体験談を読んでいます。載せないことで見られなくなるわけではありません。書かれた内容が選考の運用で直せることなら、直したうえで企業ページとイベントで補うほうが、学生の判断は変わりやすいです。書かれた内容を確認してから決めることを勧めます。

マイナビの申込も御社経由でできますか

当社が販売パートナーとして窓口になるのは、OfferBox・Wantedly・ワンキャリアの3媒体です。マイナビの申込は各社の窓口になりますが、ナビ型と併用するときの役割の分け方や、体験談への向き合い方は、ワンキャリアの運用を見ている立場からご相談いただけます。OfferBoxとの比較はOfferBoxとマイナビの違い、3媒体の全体像は3媒体の違いと選び方にまとめています。
