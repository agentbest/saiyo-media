理系の学生にスカウトを送る。「理系の方に」「研究を活かして」で始める。研究テーマの名前を引用する。専門用語を無理に使う。あるいは、研究を無視して「営業でも活躍できます」と書く。どれも、理系の学生には「読んでいない」と読まれます。結論から言うと、理系学生向けの文面は、研究テーマではなく「研究の進め方」を読み、自社の仕事の進め方と重ねる四段の型で書きます。研究職以外に誘うときも、研究を無視しません。社内に研究を読める人がいなくても、「進め方」なら専門が違っても読めます。研究室の時期に配慮し、技術の人と話す場に誘います。三つの媒体で、骨組みは同じです。 この記事では、理系学生が開かない文面、読む箇所、四段の型、読める人がいない場合、研究職以外に誘う場合、時期の配慮、分担を整理します。文面全体の骨組みはスカウト文面の基本構成、新卒向けの型は新卒向けスカウト文面の型で書きました。媒体ごとの理系向けはOfferBoxで理系学生にオファーを送るときの文面、ワンキャリアで理系学生にスカウトを送る文面で書きました。

この作業の目的｜「研究をこう見て、仕事でこう使う」と分かる文面にする

理系の学生は、多くのスカウトを受け取っていて、「理系というだけで送ってきた会社」と「研究を読んだ会社」を読み分けます。読み分けの基準は、研究テーマの名前を引用したかではなく、研究の「進め方」に触れたかです。

目的は、研究の進め方を読み、それを自社の仕事の進め方と重ねて、学生が「この会社は、自分の研究のやり方を見ている」と感じる文面にすることです。

理系学生が、開かない文面

文面学生が受け取ること
「理系の方に」「理系学生の皆さまへ」理系なら誰にでも送っている
「〇〇の研究をされていて」（テーマ名の引用だけ）プロフィールの見出しをコピーした。中身を読んでいない
専門用語を無理に使う分かっていないのに使っている。技術の人には見抜かれる
「研究を活かして」（何にどう活かすかがない）抽象。活かし方が分からない
研究を無視して「営業でも活躍できます」研究を否定された感じ
「素晴らしい研究ですね」褒め言葉。読んでいなくても書ける

共通するのは、「研究の進め方」に触れていないことです。テーマ名は見出しで、進め方は本文です。

プロフィールで、読む箇所

  • 研究の進め方：「条件を変えて比べた」「先行研究を読んで仮説を立てた」「装置を自分で組んだ」「データの取り方を変えた」「詰まったとき、〇〇に相談して△△した」
  • 研究以外の行動：「サークルで□□を自分で始めた」。理系学生にも、研究以外の行動がある
  • なぜその研究を選んだか：書かれていれば、「なぜ」で重ねられる
  • 読まない箇所：研究テーマの名前、研究室の名前、専攻、資格の一覧。これは見出し
  • 拾うのは、進め方を一つ：専門が違っても、「条件を変えて比べた」は読める

研究の進め方の拾い方はOfferBoxで理系学生にオファーを送るときの文面の手順2、体験談で理系学生が読んでいることはワンキャリアで理系学生にスカウトを送る文面で書きました。

いま使っている媒体の運用の相談だけでも構いません。いまの理系向けの文面が、研究の「進め方」に触れているかを一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「理系学生には、研究の中身を理解した人が書かなければ、文面は書けない」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の理系向けの文面を見ていますが、返信が来ている文面の多くは、研究の中身に踏み込んでいません。「〇〇の条件を変えて比べたと書かれていて、うちの△△の仕事も、条件を変えて比べることの連続です」のように、「進め方」だけを読んで、仕事の進め方と重ねています。進め方は、専門が違っても読め、人事でも読めます。逆に、研究の中身に踏み込もうとして専門用語を無理に使った文面は、学生に「分かっていないのに使っている」と見抜かれています。当社が理系向けの文面の相談を受けるとき、最初にやるのは、研究テーマの名前と専門用語を抜いて、自由記述から「進め方」の動詞を一つ拾うことです。

四段の型

段書くこと例
1. 進め方を読んだ一文研究の進め方を一つ、学生の言葉のまま。テーマ名は引用しない「〇〇の条件を変えて何度も比べたと書かれているのを拝見しました」
2. 自社の仕事の進め方との重なり「最初の一年」の仕事を、進め方で書き、1と重ねる「うちの△△の仕事も、条件を変えて比べることの連続です。入社した年は、□□の案件で先輩と二人でそれをします。近いと思いました」
3. 選考で何を見るか学生が準備できる形で「選考では、研究をどう進めたかの話を聞きます。研究の内容そのものは、専門外でも分かるように話していただければ大丈夫です」
4. 技術の人と話す場誰（技術の人）と、どんな形で、選考ではないこと、時期の配慮「選考ではなく、技術の〇〇と、オンラインで短い時間、研究と仕事の進め方の話をする場です。研究室のお忙しい時期でしたら、時期をずらして構いません」

「1」で研究テーマの名前を引用しないことが、他の型と違う点です。テーマ名を引用すると、「見出しをコピーした」と読まれます。

社内に、研究を読める人がいない場合

体制入り方
技術の人が読める技術の人が自由記述を読み、「進め方」の一文を人事に渡す。名義も技術の人
技術の人は読めないが、面談には出られる人事が「進め方」を拾って書き、技術の人が確認し、技術の人の名義で。研究の専門には触れない
技術の人がいない人事が「進め方」を拾い、自社の仕事の「進め方」と重ねる。名義は人事。「研究の内容は専門外ですが、進め方が近いと思いました」と正直に

「研究を読める人がいないから、理系には送れない」ではなく、「進め方」なら誰でも読めます。体制別の入り方はOfferBoxで理系学生にオファーを送るときの文面の手順1で書きました。

研究職以外に、誘う場合

  • 研究を無視しない：「営業でも活躍できます」は、研究を否定された感じになる
  • 研究の「進め方」と、その仕事の「進め方」を重ねる：「条件を変えて比べる進め方は、うちの営業の、提案の切り口を変えて試す仕事でそのまま使えます」
  • 「研究とは違う仕事です」と、違いを隠さない：そのうえで、進め方の重なりを書く
  • 研究職と研究職以外の両方に誘わない：一通に一つの募集。相手の進め方に近いほうを選ぶ
  • 書き方はOfferBoxで理系学生にオファーを送るときの文面の手順3、ワンキャリアで理系学生にスカウトを送る文面の「研究と仕事が、離れている場合の一文」

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。研究を読める人がいない場合の入り方と、「進め方」を拾って書く時間をお伝えします。

媒体選びを相談する

研究室の時期への、配慮

  • 自由記述に、学会・論文・実験の時期が書かれていれば、それを外す
  • 書かれていなければ、「研究室のお忙しい時期でしたら、時期をずらして構いません」を締めに
  • 面談の日程に、幅を持たせる：自社の方針で
  • 返事が遅くても、時期のせいかもしれないと見る：再送は一度だけ
  • 送る時期は、年度の公表内容と学生の学年の動きを確認して決める
  • 時期の配慮はOfferBoxで理系学生にオファーを送るときの文面の手順5、取り合いに負けるときは理系学生の取り合いに負けるときのOfferBox運用

専門用語の、扱い

  • 学生が使った言葉だけを使う：学生が「〇〇」と書いていれば「〇〇」。言い換えない
  • 自社が使わない専門用語を、無理に使わない：分かっていないことは見抜かれる
  • 分からないことは、分からないと書く：「研究の内容は専門外ですが」
  • 自社の仕事の技術は、事実として一言：「うちは△△を使っています」
  • 扱いの詳しくはOfferBoxで理系学生にオファーを送るときの文面の手順4

社内の分担

作業誰が
テーマ名の引用と専門用語を文面から抜く人事
自由記述から研究の「進め方」を一つ拾う技術の人か人事（体制で）
自社の仕事の「進め方」と「最初の一年」を話す技術の人か現場の人
「選考で何を見るか」を決める面接官と人事
四段の型を作り、1と2を相手ごとに埋める人事。技術の人が確認
技術の人の名義で送り、話す場に出る技術の人
時期を年度の公表内容と学生の学年で確認する人事

運用代行や代理店が支えられるのは、四段の型、「進め方」の拾い方の型、体制別の入り方の整理、専門用語の扱いの整理までで、進め方を読むこと、自社の進め方を話すこと、名義、話す場に出ることは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは切り分けの話です。当社が理系向けの文面の相談を受けるとき、「研究の内容を読む」と「研究の進め方を読む」を分けます。前者は、専門が同じ人でなければできず、多くの会社にはその人がいません。後者は、「条件を変えて比べた」「装置を組んだ」「仮説を立てた」という動詞を拾うことで、専門が違っても、人事でもできます。相談の多くは、前者ができないことを理由に「理系には送れない」となっていますが、返信が来る文面に要るのは後者です。当社が確かめるのは、「研究の内容を理解できる人がいますか」ではなく、「自由記述の中の動詞を、一つ拾えますか」です。拾えれば、理系向けの文面は書けます。

まとめ

  • 理系学生は、「理系の方に」・テーマ名の引用・無理な専門用語・研究を無視した誘い、を「読んでいない」と読む。読み分けの基準は「進め方」に触れたか
  • 読むのは、研究の進め方（条件を変えて比べた・装置を組んだ・仮説を立てた・詰まったときどうしたか）と、研究以外の行動。テーマ名・研究室名・専攻は見出しで拾わない
  • 四段の型は、進め方を読んだ一文（テーマ名を引用しない）→自社の仕事の進め方との重なり→選考で何を見るか→技術の人と話す場（時期の配慮を添えて）
  • 研究を読める人がいなくても、「進め方」なら読める。体制で入り方を選び、分からないことは分からないと書く
  • 研究職以外に誘うときも研究を無視せず、進め方で重ね、違いを隠さない。研究室の時期に配慮し、専門用語は学生が使った言葉だけ

よくある質問

自由記述が研究の内容ばかりで、進め方が書かれていません

研究の内容の中に、動詞を探します。「〇〇を測定した」「△△を比較した」「□□を作製した」の動詞が、進め方です。「測定した」なら「測る仕事」、「比較した」なら「比べる仕事」、「作製した」なら「作る仕事」と重ねられます。それでも拾えなければ、後回しにして、拾える学生から送ります。

技術の人が「研究の専門が違うから、読めない」と言います

読むのは専門ではなく、進め方だと伝えます。「条件を変えて比べた」「装置を自分で組んだ」は、専門が違っても分かります。技術の人には、「専門を理解しなくてよいので、どう進めたかだけ読んでほしい」と伝えます。それでも難しければ、人事が進め方を拾い、技術の人は「自社の仕事の進め方」を話す側に回り、面談で出る形に分けます。

理系学生向けスカウト文面の型は、御社に相談できますか

できます。当社は、四段の型、「進め方」の拾い方の型、体制別の入り方の整理、専門用語の扱いの整理を支えられます。進め方を読むこと、自社の進め方を話すこと、名義、話す場に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • 文系学生向けスカウト文面の型｜職種名から仕事を想像できない学生に、「最初の月に何をするか」を場面で先に見せ、学生時代の行動の型（始めた・続けた・巻き込んだ）と重ねる四段の型。「文系でも」と書かない
  • 中途向けスカウト文面の型｜経歴の「事実」ではなく「いま、どう仕事を進めているか」を読み、「入ったら何が変わるか」と重ね、在職中の相手が返信できる形で「話す場」に誘う四段の型
  • 営業向けスカウト文面の型｜「営業経験」ではなく「何を、誰に、どう売っていたか」を読み、自社の「売り方と決め方」と重ね、営業の人の名義で「話す場」に誘う四段の型
  • エンジニア向けスカウト文面の型｜技術名の羅列ではなく「何を、どう作ったか」を読み、自社の開発の「進め方と決め方」と重ね、送り主はエンジニアに
