ワンキャリアのスカウト対象｜体験談で確かめに来る学生に絞る

ワンキャリアでスカウトを始めた会社が最初に迷うのが、「どこまで広く送るか」です。対象を広げるほど一人ひとりのプロフィールに割ける時間は減り、文面は似通っていきます。そしてワンキャリアでは、受け取った学生が選考体験談やクチコミに「スカウトは定型文だった」と書くことがあり、それを翌年の学生が読みます。結論から言うと、ワンキャリアのスカウト対象は、募集の「こんな人」を学生時代の状態に言い換えて条件にし、社内で読める人数まで絞り込み、そのうえで一人ずつ読んで「この学生とこの仕事の話がしたい」と言える相手に送ります。文面を読んだあと企業ページと体験談で確かめに来そうな学生を先に読むと、掲載・イベントとスカウトが一続きになります。大学名や専攻だけで選ぶのは避け、面接で聞いた言葉と新しい体験談をもとに条件を直していきます。 この記事では、絞り込みで決まること、条件の組み立て、プロフィールの読み方、確かめに来る学生を先に読む理由、失敗の例、見送る基準、条件の直し方、記録と分担を整理します。スカウトの全体像はワンキャリアのスカウトの基本で書きました。絞り込みに使える項目は変わることがあるので、最新の仕様は管理画面とヘルプで確認してください。他媒体での考え方はOfferBoxの学生検索機能の使い方とWantedlyのスカウト対象の絞り方で書きました。

絞り込みで決まること｜体験談に何が残るか

ワンキャリアのスカウトで返信が来るかどうかは、文面の冒頭に「プロフィールのどこを読んだか」が書けているかに大きく左右されます。そして、その一文が書けるかどうかは、送る前にプロフィールを読む時間があるかどうかで決まります。

ワンキャリアの場合、結果は返信の有無だけで終わりません。読まずに送った文面は体験談に「定型文」として残り、読んで送った文面は「自分のことを見てくれていた」として残ります。絞り込みは送る数を減らす作業というより、一通ずつ読んで書ける範囲に送り先を収め、その結果として体験談に残る印象を選ぶ作業です。

条件の組み立て｜「こんな人」を学生時代の姿に言い換える

募集の「こんな人」条件としての言い換え
「自分で企画して動ける人」ゼミ、サークル、学園祭などで企画を担った記述があるか
「お客様と話すのが好きな人」接客のアルバイトや、人と関わる活動
「〇〇に関心がある人」興味の項目や、プロフィールに書かれている言葉
「専攻は問いません」専攻では絞らない
「〇〇系の素養がある人」（技術職など）専攻や研究の分野（中身ではなく分野で）
「この職種の一年目に合う人」入社最初の月の仕事と重なる活動

企業ページや募集に書いていない条件を、スカウトの絞り込みにだけ足さないようにします。掲載で「専攻は問いません」と言いながら専攻で絞ると、学生が企業ページで確かめたときに話が食い違います。

対象とする学年や、スカウトを送ってよい時期は、その年度に公表されている内容と自社の方針を確認して決めます。時期の具体はこの記事では扱いません。

絞り込んだ一覧から、一人ずつ読む

検索条件が受け持つのは、読む候補を手の届く範囲に減らすところまでです。誰に送るかは、読んでから決めます。

読むところ見ること
学生時代の活動サークル、アルバイト、研究、自分で始めたこと。自分の言葉で書いているか
興味とやってみたいこと「〇〇に関心がある」「△△に挑戦したい」
言葉づかい文面の冒頭でそのまま引ける表現があるか
業界や会社を調べている様子同業や近い業界への関心が読み取れるか（推測しすぎない）
募集の一年目との重なり一つあれば、冒頭の一文が書ける
合わないところ勤務地の希望や、やりたいことが募集と離れていれば送らない

読む目的は、募集の一年目の仕事と重なるところを一つ探すことです。見つかれば、それを文面の一文目に据えて送ります。見つからなければ、その学生には送りません。新卒のプロフィールの読み方は新卒向けスカウト文面の型も参考になります。

いま使っている媒体の運用の相談だけでも構いません。募集の「こんな人」を、ワンキャリアの絞り込み条件に一緒に言い換えます。

運用の相談をする

エージェントベストの見解

ワンキャリアのスカウトの相談でよく出てくるのが、「対象を広げて数を送れば、返信の件数も増えるはず」という考えです。当社は求人広告代理店として、ワンキャリアのスカウト運用に関わっていますが、広げて数を送った会社ほど、プロフィールを読む時間がなくなり、同じ文面の一斉送信になりがちです。その結果が体験談に「定型文のスカウトが届いた」と書かれ、翌年にその会社を調べる学生の目にも入ります。反対に、絞って一人ずつ読んで送った会社は、返信が来るだけでなく、体験談に「自分のプロフィールを読んでいた」と残ることがあります。当社が絞り込みの話をするとき、条件より先に確認するのは「一週間で何人分のプロフィールを読めるか」です。その人数が、送れる数の上限になります。

企業ページと体験談で確かめに来る学生を、先に読む

ワンキャリアの学生は、スカウトを読んだあと、企業ページと自社の選考体験談・クチコミを開いて確かめてから返信を考えることが多い、とされています。

  • 同業や近い業界に関心がある学生は、その業界の体験談をすでに読んでいることが多い：自社の体験談まで読み進め、文面と照らし合わせてくれる
  • 掲載とイベントの内容が整っている会社ほど、確かめられるほど信頼が積み上がる：「掲載どおりだった」という体験談があれば、学生は返信しやすい
  • 自社の体験談に「掲載と違った」という声があるなら、送る前にそちらを直す：確かめられるほど不利になる
  • 「体験談を読んでいそうか」は、関心の方向から読める範囲にとどめる：推測を文面に書かない

先に読むという順番の話であって、それ以外の学生を外すという意味ではありません。読める人数の中で、重なりが見つかった学生に送ります。

絞り込みでつまずく例

つまずき起きること立て直し方
対象が広すぎる読み切れず定型文になり、体験談に残る一週間で読める人数まで絞る
対象が狭すぎる送る相手が見つからない条件を一つずつ外して様子を見る
大学名や専攻だけで選ぶ読んでいないことが文面から伝わる学生時代の状態で絞り、一人ずつ読む
掲載にない条件で絞る企業ページで確かめた学生が違和感を持つ「こんな人」から条件を組み立てる
記述の少ないプロフィールにも送る冒頭の一文が書けない書き込みのある学生を先に読む
時期を確かめずに送る年度の扱いと食い違う公表内容と自社の方針を確認する
一度作った条件を使い続ける学生の反応が変わっても気づけない面接の言葉と体験談で直す
体験談の「掲載と違った」を放置して送る確かめた学生から離れていく掲載か運用を先に直す

いちばん多いのは、一行目の「広すぎる」です。たいていは「できるだけ多くに届けたい」という気持ちから始まります。

見送る基準を先に決めておく

  • 一年目の仕事との重なりが見つからない：冒頭の一文が書けないので見送る
  • 希望が募集と離れている：勤務地、やりたいこと、働き方
  • 記述がごく少ない：話してみたいという意思が読み取りにくいので、読む順番を後ろにする
  • 以前に送った相手：記録で確かめる。別の募集で、新しく重なりが見つかったときに限って改めて送る
  • 自社の体験談を書いた学生：扱いは媒体の規約に沿う。規約は管理画面とヘルプで確認する
  • 年度の公表内容や自社の方針と時期が合わない：送らない

見送る基準があると、迷う時間が減り、そのぶん送る相手の文面に時間をかけられます。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。読める人数から逆算した、ワンキャリアのスカウトにかかる時間をお伝えします。

媒体選びを相談する

面接での一言と新しい体験談で、条件を見直す

  1. 返信した学生に共通する活動や関心を探す：共通点があれば、条件をそちらに寄せる
  2. 返信がなかった学生の共通点も見る：条件のどこかが募集とずれている
  3. 面接で「スカウトのどこで返信を決めたか」「企業ページや体験談のどこを読んだか」を聞く：文面、企業ページ、体験談のどれが効いたかが分かる
  4. 見直しは月に一度、条件を一つだけ：まとめて変えると何が効いたか分からない
  5. 募集の「こんな人」も見直す：返信する学生と「こんな人」が離れているなら、掲載のほうが実態とずれている
  6. 選考後に書かれた体験談で、スカウトへの感想を読む：「定型文だった」「よく読んでいた」

見直しの中心は、面接で直接聞くことです。返信の件数を数えるだけでは、学生が何に反応したのかまでは見えません。ワンキャリアでは体験談にスカウトの印象が書かれることがあるので、それも手がかりになります。

送った相手と理由を記録する

記録すること何に使うか
送った学生、募集、送った日重ねて送っていないかの確認、返信の追いかけ
冒頭の一文に使った重なりどんな一文に返信が来たかを見る
返信の有無と面接で聞いた言葉条件を直す手がかり
見送った理由条件が広すぎないかを見る手がかり
体験談やクチコミでのスカウトへの言及翌年度の条件づくり

最後の欄は、ワンキャリアならではの項目です。体験談に残った言葉は、その年の条件が学生にどう受け取られたかを示します。

作業誰が

一週間で読める人数を決める人事
時期を公表内容と自社の方針で確かめる人事
条件で候補を絞る人事

月に一度、条件を一つ直す人事

運用代行や代理店が手伝えるのは、条件の設計、読むところの型、見送る基準づくり、記録表のひな形、見直し案の提示までです。プロフィールを読むこと、送るかどうかの判断、面接で聞くこと、時期の確認は企業が受け持ちます。

エージェントベストの見解

条件づくりより前に決めておきたいのが、「一週間で読める人数」です。当社がワンキャリアのスカウトの絞り込みに関わる場合、条件の案はこちらで用意できます。ただ、読める人数が決まっていないと、どこで線を引くかが決められません。「できるだけ多く」から始めると、条件はゆるくなり、読み切れない人数になり、定型文の一斉送信になり、それが体験談に残ります。そこで当社は最初に、プロフィールを読んで一文を書く時間を週に何時間取れるかを社内で決めてもらいます。時間が決まれば、その人数に収まる条件を組めます。掲載やイベントの準備と同じ担当者が受け持つことが多いので、その予定も含めて時間を見積もるのが現実的です。

まとめ

  • ワンキャリアの絞り込みは、送り先を一通ずつ読める範囲に収め、体験談に残る印象を選ぶ作業。数を減らすこと自体が目的ではない
  • 条件は募集の「こんな人」を学生時代の状態に言い換えて作り、掲載にない条件は足さない。時期は年度の公表内容と自社の方針で決める
  • 絞った一覧を一人ずつ読み、一年目の仕事との重なりが一つあれば送り、なければ見送る。企業ページと体験談で確かめに来そうな学生を先に読む
  • 広すぎる、大学名や専攻だけ、記述の少ないプロフィールに送る、条件を変えない、体験談の「違った」を放置する、がつまずきやすい点
  • 面接での一言と新しい体験談をもとに、月に一度条件を一つ直す。出発点は一週間で読める人数

よくある質問

条件を絞ったら、候補がほとんど残りません

条件を一つずつ外していきます。「こんな人」の要素のうち、募集に欠かせないものだけを条件に残し、ほかは読んで判断します。それでも候補が少なければ、「こんな人」が狭すぎないか、その募集はスカウトより掲載やイベントを軸にしたほうがよいかを考えます。

プロフィールを読む時間がなかなか取れません

読める人数まで、送る人数を減らします。読まずに送る数を増やしても返信にはつながりにくく、ワンキャリアでは体験談に「定型文だった」と残ることもあります。週のどこかに読む時間を決めて確保し、その時間で読めた学生にだけ送る形にします。

ワンキャリアのスカウトの絞り込みを、御社に相談できますか

できます。条件の設計、読むところの型、見送る基準、記録表のひな形、見直しの案をお手伝いします。プロフィールを読むこと、送るかどうかの判断、面接で聞くこと、時期の確認は、企業の側で行ってください。当社は求人広告代理店として、ワンキャリアのスカウト運用を支えています。
