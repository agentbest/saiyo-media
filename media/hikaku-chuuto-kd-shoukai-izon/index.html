人材紹介に頼りすぎているときの媒体の足し方

媒体比較・選び方中途採用の媒体選び（課題別） 更新日 2026/11/4

中途採用のほとんどを紹介会社に頼っている。費用はかかるが、自社で媒体を回す余裕がない。いつかは自社で採れるようにしたいと思いながら、手がつけられずにいる。そうした相談をよく受けます。結論から言うと、紹介に頼りすぎているときは、紹介をやめるのではなく、職種ごとに「紹介で採る」と「媒体で採る」を分け、媒体で採れそうな職種から一つずつ媒体を足していきます。 紹介にも媒体にも、それぞれに合う職種と状況があります。どちらかに寄せきるのではなく、役割を分けることで、費用と社内の時間の釣り合いが取れていきます。

頼りすぎかどうかを見分ける

紹介を多く使っていること自体は、問題ではありません。頼りすぎかどうかは、次の点で見分けます。

  • 紹介でなくても採れそうな職種まで、紹介に出している：応募が集まりやすい職種や、経験の水準がそれほど高くない職種も、紹介に任せている
  • 紹介会社からの推薦が止まると、採用も止まる：自社で候補者に出会う入口が、ほかにない
  • 候補者との最初の接点が、いつも紹介会社にある：自社の言葉で会社を伝える場が少ない
  • 採用の経験が社内にたまらない：どんな求人の書き方で、どんな人が来るのかが社内で分からない

当てはまるものが多いほど、紹介以外の入口を足す意味が大きくなります。

一方で、紹介に頼ることに理由がある場合もあります。経験者の数が少ない専門職を採っている、採用の担当者が置けない、急ぐ募集が続いている、といった状況では、紹介で採るほうが社内の時間を含めて釣り合うこともあります。頼りすぎかどうかは、紹介の割合の大きさではなく、紹介でなくても採れる職種まで任せていないか、紹介が止まったときに採用も止まらないか、で判断します。この二つに当てはまらなければ、無理に媒体を足す必要はありません。紹介会社との付き合い方そのものは、人材紹介の使い方｜依頼の仕方と付き合い方で整理しています。

紹介と媒体の違いを押さえる

媒体を足す前に、紹介と媒体の違いを押さえておきます。

観点紹介で採る媒体で採る
候補者を探すのは紹介会社企業（掲載で待つ、スカウトで探す）
費用が発生する時点入社時媒体の型による（定額、採用決定時など）
社内に要るもの求める人物像の説明、面接の枠求人票、スカウトの文面、応募への返信の時間
社内にたまるもの紹介会社との関係求人の書き方、候補者の反応、運用のやり方

紹介は、探す作業を紹介会社が担うので、社内の時間が少なく済みます。媒体は、探す作業を自社で持つ分、時間はかかりますが、求人の書き方や候補者の反応が社内に残ります。どちらが良いかではなく、何を自社で持つかの違いです。

紹介で採る職種と、媒体で試せる職種。分け方の整理だけでも構いません。

無料で相談する

エージェントベストの見解

当社は人材紹介も媒体の販売もしているので、紹介に頼る会社の悩みを両側から見ています。紹介に頼る会社が媒体を足そうとして止まりやすいのは、紹介と同じ感覚で媒体を始めてしまうときです。紹介では、条件を伝えれば候補者が推薦されてきます。媒体では、求人票を書き、応募に返信し、スカウトなら自分で探して文面を書く必要があります。紹介に慣れた会社は、この作業の量を見込まずに媒体を契約し、最初のひと月で運用が止まることがあります。媒体を足すときは、契約の前に「誰が、週にどれだけの時間を媒体に使えるか」を決めておくことを勧めます。時間が取れないなら、作業の部分を外に出す前提で媒体を選ぶ、という順番もあります。紹介を減らすことより、媒体を回せる形を先に作ることが、紹介への依存を無理なく下げる近道です。

媒体を足す職種の選び方

すべての職種で一度に媒体を始める必要はありません。次のような職種から試すと、媒体の効果を確かめやすくなります。

  1. 同じ職種を続けて採る予定がある：一度作った求人票やスカウトの文面を使い回せる
  2. 応募が集まりやすい職種：営業職や事務職など、転職サイトで探す人が多い職種
  3. 経験の水準を幅で持てる職種：経験者でなくても、入社後に育てられる範囲がある
  4. 会社の特徴を伝えやすい職種：働き方や任せる仕事に、ほかの会社と違う点がある

逆に、経験者の数が少ない専門職や、急ぐ募集は、紹介で採るほうが進めやすいことが多くあります。こうした職種は、紹介に残しておきます。

足す順番と社内の準備

媒体を足すときは、次の順番で進めます。

  1. 試す職種を一つ決める：上の条件に当てはまる職種から、一つだけ選ぶ
  2. 求人票を自社の言葉で書く：紹介会社に伝えていた人物像を、候補者に向けた文章に直す。書き方は中途向けの求人票｜経験者が確認する項目を参考にします
  3. 掲載か、スカウトかを決める：社内で探す時間が取れるならスカウト、取れないなら掲載から始める。違いは掲載型とスカウト型の使い分け｜中途採用の場合にまとめています
  4. 紹介との重なりを決める：同じ職種を紹介と媒体の両方で募集する場合、同じ候補者に重ねて声をかけないよう、扱いを決めておく
  5. 契約の切れ目で見直す：その職種で媒体から応募や採用がどれだけ出たかを見て、続けるか、職種を広げるかを決める

掲載型の転職サイトには、doda、type、Greenなどがあります。IT・Web職を試すならGreenのように業界を絞った媒体も候補になります。どれを選ぶかは、試す職種と社内の時間で決めます。

媒体を足す前に、運用に必要な時間の見積もりだけでも聞いてみませんか。

運用の相談をする

エージェントベストの見解

紹介と媒体を並行させるときに、相談で多い思い込みは「同じ職種を両方で募集すれば、候補者が倍に増える」というものです。実際には、同じ職種で同じ層を狙えば、紹介会社が推薦する候補者と、媒体で出会う候補者が重なることがあります。重なると、どちらの経路で来たかで費用の扱いが変わり、社内も候補者も混乱します。勧めたいのは、職種か、狙う層で分けることです。たとえば、経験の深い層は紹介で、経験を幅で見る層は媒体で、というように分けると、重なりが減り、それぞれの経路の効果も見やすくなります。紹介会社にも、媒体を並行させることと、分け方を先に伝えておくと、付き合いが続けやすくなります。

まとめ

  • 紹介に頼ること自体は問題ではない。紹介でなくても採れる職種まで任せていないかを見る
  • 紹介と媒体の違いは、探す作業と、社内にたまるものを誰が持つか
  • 媒体は、続けて採る職種、応募が集まりやすい職種、育てられる職種から試す
  • 契約の前に、媒体に使える社内の時間を決めておく
  • 紹介と媒体を並行させるなら、職種か狙う層で分け、重なりを減らす

よくある質問

紹介をやめて、すべて媒体に切り替えたほうがよいですか

一度に切り替えることは勧めません。経験者の少ない職種や急ぐ募集では、紹介のほうが進めやすいことがあります。媒体で採れそうな職種から一つずつ試し、採れることを確かめてから広げるほうが、採用を止めずに進められます。

社内に媒体を回す時間がありません

作業の部分を外に出す前提で媒体を選ぶ方法があります。求人票の作成、スカウトの送信、応募への一次返信、日程調整は外に出せます。どこを外に出すかは採用のどこを外に出すか｜代行・紹介・媒体の切り分けを参考にしてください。

複数の紹介会社を使っていて、整理ができていません

紹介会社ごとに、任せる職種と、推薦から入社までの流れを並べると、どこに頼っているかが見えます。考え方は複数の紹介会社と付き合うときの整理にまとめています。
