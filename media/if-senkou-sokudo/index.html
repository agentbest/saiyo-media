長期インターンの選考は速さが大事な理由と進め方

長期インターンの採用で「応募はあるのに、なかなか決まらない」という悩みは、選考にかかる日数を測ると原因が見えることが多くあります。結論から言うと、長期インターンの選考は、応募から開始日までの日数を短くするほど、決まる数が増える傾向があります。 学生は複数の会社に並行して応募し、先に話が進んだところから決めていくからです。この記事では、速さが大事な理由を学生の動き方から説明したうえで、どこで日数がかかっているかの測り方と、短くするための具体的な進め方を整理します。Infraで応募を受けている会社を想定していますが、ほかの媒体でも同じ考え方が使えます。

速さが大事な理由は、学生の動き方にある

新卒の就職活動では、学生は時期を決めて企業を比べ、選考を受けます。長期インターンは事情が違います。

  • 始めたい時期がはっきりしている：「来月から」「夏休みから」など、学生は自分の予定に合わせて始めたい
  • 並行して応募している：気になる求人に続けて応募し、早く話が進んだ会社から面接を受ける
  • 決めたら他を断る：週に何日も入る仕事なので、掛け持ちは難しい。一社に決めると、残りは辞退する

この3つが重なると、選考が遅い会社は、学生が他社に決めた後に連絡をすることになります。会社の魅力が足りなかったのではなく、順番で負けている状態です。

どこで日数がかかっているかを測る

速くしようとする前に、今どこで日数がかかっているかを測ります。直近の応募について、次の日付を書き出します。

区間測る日数
応募 → 一通目の連絡初回連絡までの日数
一通目 → 面接日日程調整と待ちの日数
面接 → 合否の連絡判断にかかる日数
合否の連絡 → 開始日受け入れ準備の日数

区間ごとに並べると、たいていどこか一つが長くなっています。多いのは「面接 → 合否の連絡」と「合否の連絡 → 開始日」です。前者は判断者の確認待ち、後者は受け入れ準備ができていないことが原因です。

測るのは、手書きの表でも構いません。数件分を並べるだけで、どこを直すべきかが分かります。辞退や返信の途絶えがあった応募には、どの区間で途切れたかの印も付けておきます。途切れた区間と日数が長い区間が重なっていれば、そこが最初に手を入れる場所です。指標の考え方はInfra運用のKPIでも整理しています。

応募から開始日までの日数を一緒に洗い出すところから、運用の見直しをお手伝いします。

運用の相談をする

短くする進め方

1. 一通目を当日中に返す

応募から一通目までは、最も短くしやすい区間です。誰の判断も待たずに返してよい範囲を決め、面接の日程候補を一通目に入れます。文面の組み立てはInfraで応募が来た後の初回連絡で書きました。

2. 面接の枠を先に押さえておく

面接官の予定が空いてから日程を探すと、一週間先になることがあります。週に数回、面接用の枠をあらかじめ確保しておき、その中から候補を出すと、日程調整が一往復で済みます。

3. 面接は原則1回にする

長期インターンでは、面接を複数回に分ける理由はあまりありません。人事と現場の担当社員が同じ面接に入れば、1回で判断できます。どうしても2回必要な場合は、同じ日に続けて行う形を考えます。

4. 合否はその日のうちに出す

判断を面接の場、または当日中に出せるように、判断の基準を先に決めておきます。基準が決まっていないと、面接の後に「どうしようか」と相談が始まり、日数が延びます。見るべき点は長期インターンの面接の進め方にまとめています。

5. 合格から開始日までに接点を作る

合格を伝えてから初日まで間が空くと、その間に学生の気持ちが揺れることがあります。開始日が先になる場合は、入る前に読んでおく資料を送る、担当社員から一言連絡を入れる、などで接点を作ります。

エージェントベストの見解

速さを上げようとして、まず面接の回数を減らす会社が多いのですが、当社が日数を測ってみると、遅れの原因は面接の回数より「合否が出てから開始日までの空白」にあることが少なくありません。合格を出したのに、パソコンやアカウントの準備、担当社員の予定が整わず、初日が数週間先になる。その間に学生は別の会社の面接も受け続け、より早く始められるほうを選びます。順番として、選考を速くする前に、受け入れの準備を先に済ませておく必要があります。合格を出したら一週間以内に初日を迎えられる状態にしておく。そのためには、掲載を始める前に、パソコン、アカウント、初日の予定、担当社員を決めておくことです。準備が先、募集は後。この順番を逆にすると、どれだけ選考を速くしても最後の区間で取りこぼします。

速さと丁寧さは両立できる

速くすると雑になるのでは、という心配を受けることがあります。実際には、速さを妨げているのは丁寧さではなく、確認の多さと判断の先送りです。

  • 確認の多さ：一通目を送る前に複数人の確認を通す。面接の日程を決めるのに上長の承認を待つ
  • 判断の先送り：合否の基準がなく、面接のたびに相談が始まる

確認の多さを減らすには、「誰の確認なしに進めてよいか」を文章にしておくのが近道です。たとえば、勤務日数の下限を満たしている応募には人事の判断で面接の日程を出す、面接で3つの項目に大きなずれがなければ担当社員の判断で合格を出す、といった形です。権限を文章にしておくと、担当者が休んでいる日でも代わりの人が同じ判断で進められます。

この2つを減らしても、学生への説明や連絡の丁寧さは落ちません。むしろ、待たされない学生は会社への印象がよくなり、入った後の関係も作りやすくなります。

Infraの代理店として、応募対応を含む運用を支援しています。社内の体制に合わせて分担を決められます。

無料で相談する

エージェントベストの見解

選考の速さを数字で見るとき、平均日数だけを見ないことを勧めています。平均が短くても、一部の応募で極端に時間がかかっていれば、その学生たちは取りこぼしている可能性が高いからです。当社は人材紹介でも、候補者ごとに選考の日数を追っていますが、決まらなかった候補者の多くは、平均から外れて長くかかった人たちでした。長期インターンでも同じで、見るべきは「一番長くかかった応募は何日だったか」と「なぜ長くかかったか」です。担当者が休みだった、判断者が出張だった、書類を見落としていた。理由が分かれば、代わりに返す人を決める、判断の基準を共有するなど、手当てができます。平均は全体の調子を見るために、最長は取りこぼしを見つけるために使い分けると、改善の打ち手がはっきりします。

まとめ

  • 学生は並行して応募し、先に話が進んだ会社に決める。遅い会社は順番で負ける
  • 応募から開始日までを区間に分けて、どこで日数がかかっているかを測る
  • 一通目は当日中、面接枠は先に確保、面接は原則1回、合否は当日中
  • 合格から開始日までの空白が長いと取りこぼす。受け入れ準備を募集の前に済ませる
  • 平均日数だけでなく、最も長くかかった応募の理由を見る

よくある質問

応募が多くて、すべてに速く対応できません

応募が多い場合は、一通目の返信と面接の日程調整を定型化し、担当を分けると対応しやすくなります。応募の数に対して受け入れられる人数が少ないなら、原稿の条件を明確にして、合う学生だけが応募する形に寄せることも検討します。

速く決めると、ミスマッチが増えませんか

速さそのものよりも、判断の基準が決まっているかどうかがミスマッチを左右します。基準が決まっていれば、速く判断しても質は落ちにくくなります。迷う場合は、条件を調整して始める方法もあります。

学生の都合で開始日が先になる場合はどうすればよいですか

開始日が先でも、合格を伝えた時点で関係は始まっています。入る前に読んでおく資料を送る、担当社員から一言連絡を入れる、事前に一度オフィスに来てもらうなど、開始日までに接点を作っておくと、途中で気持ちが離れにくくなります。
