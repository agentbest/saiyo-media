長期インターン生がすぐ辞めるときに見直すこと

Infra・長期インターン課題別 更新日 2026/10/16

長期インターン生を受け入れたものの、数週間や数か月で辞めてしまう。それが何人か続くと、「最近の学生は続かない」と結論づけたくなります。結論から言うと、すぐ辞める理由の多くは学生の側の根気ではなく、「募集と実際の仕事のずれ」「最初の数週間の放置」「働き方の負担」のどれかにあり、受け入れ側の見直しで減らせることが多いです。 辞めた時期によって、原因の当たりもつけられます。この記事では、症状の確認、原因の切り分けの順番、打ち手、外に任せられる範囲を整理します。

症状を確認する｜いつ、何と言って辞めたか

まず、これまでに辞めたインターン生について、次の点を振り返ります。

  • 辞めた時期：受け入れから何週間、何か月で辞めたか
  • 辞めるときに伝えられた理由：学業、就職活動、他のインターン、体調、その他
  • 辞める前の様子：勤務の日数が減っていた、質問が減っていた、連絡が遅くなっていた
  • 任せていた仕事：どんな仕事を、どれくらいの量で任せていたか

伝えられた理由は、そのまま受け取れないこともあります。「学業が忙しくなった」という理由の裏に、仕事が合わなかった、居心地が悪かった、という本音が隠れていることもあるからです。辞める前の様子と合わせて見ると、本当の理由に近づけます。

原因を切り分ける順番

辞めた時期を手がかりに、次の順番で原因を確かめます。

1. 最初の数週間で辞める｜募集と実際のずれ

受け入れから数週間で辞める場合は、募集で伝えた内容と、実際に任された仕事のずれが原因であることが多いです。

  • 募集では企画の仕事と書いていたが、実際は資料整理ばかりだった
  • 裁量があると書いていたが、細かい指示どおりの作業が中心だった
  • 週の勤務日数や時間が、聞いていた話より多かった

2. 1か月から2か月で辞める｜最初の時期の放置

1か月から2か月ほどで辞める場合は、最初の時期に十分に関われていなかったことが原因であることが多いです。

  • 質問できる相手が決まっていなかった
  • 仕事の確認や反応がなく、うまくできているか分からなかった
  • チームの中で、自分の居場所を感じられなかった

3. 数か月以上経って辞める｜働き方の負担と成長の止まり

数か月以上経ってから辞める場合は、働き方の負担や、仕事に変化がないことが原因になりがちです。

  • 試験期間や就職活動の時期に、勤務を減らす相談ができなかった
  • 同じ作業が続き、任される範囲が広がらなかった
  • 勤務時間の外にも連絡が来て、休めなかった

辞めた時期と理由を並べるだけでも、見直すところは見えてきます。受け入れの流れを一緒に振り返ります。

無料で相談する

エージェントベストの見解

インターン生がすぐ辞めるという相談で、当社がよく見る原因は、募集の文面と最初の仕事の落差です。募集では「事業の企画に関わる」「裁量を持って働ける」と書き、最初の1か月はデータ入力や資料の整理をお願いする。会社の側としては、まず基本を覚えてもらう意図ですが、学生の側には「聞いていた話と違う」と映ります。当社が勧めるのは、募集の段階で「最初の1か月は何をするか」を正直に書くことです。基本の作業から始まること、その作業がどの仕事につながるのか、いつ頃から何を任せたいのかを書いておく。最初の仕事が地味でも、その先が見えていれば、学生は納得して続けます。辞める理由の多くは仕事の地味さではなく、先が見えないことです。

打ち手｜時期ごとの見直し

募集と実際のずれを減らす

  1. 募集に、最初の1か月の仕事と、その先に任せたい仕事を分けて書く
  2. 面接で、実際の仕事の例を見せながら説明する
  3. 勤務の日数と時間の下限と上限を、面接ではっきり伝える

最初の時期の関わりを増やす

  1. 指導役を一人決め、毎回の勤務で一度は話す時間を作る
  2. 最初の数週間は、作業の途中で確認し、こまめに反応を返す
  3. 1か月の時点で、本人の感想と会社の評価を話す面談を設ける

働き方の負担と成長の止まりを防ぐ

  1. 試験期間や就職活動の時期の勤務について、事前に相談の機会を設ける
  2. 数か月ごとに、任せる仕事の範囲を見直す
  3. 勤務時間の外には仕事の連絡をしない、という約束を守る

学業との両立の考え方は長期インターンと学業の両立、就職活動の時期の扱いは就活の時期に長期インターン生が離れるときでも整理しています。

辞めることを前提にした仕組み

長期インターンは、いずれ終わるものです。卒業、就職活動、学業の都合で、どのインターン生もいつかは辞めます。すぐ辞めることを減らす工夫と同時に、辞めることを前提にした仕組みも用意しておきます。

  • 作業の手順を記録に残してもらい、引き継げる状態にする
  • 辞める時期の相談は、早めにしてもらえるよう伝えておく
  • 辞めるときに、受け入れの感想を聞く機会を設ける

辞めるときに聞いた感想は、次の受け入れを見直す一番の材料になります。

エージェントベストの見解

当社はInfraの代理店として募集を支援するなかで、定着がうまくいっている会社が辞めるインターン生とどう向き合っているかも見ています。続く会社に共通しているのは、辞めるインターン生に「次に入る学生のために、何を変えたらいいか」を聞いていることです。在籍中には言いにくかったことも、辞めるときには話してもらえることがあります。「最初の週に何をすればいいか分からなかった」「質問していいのか迷った」といった声は、受け入れる側からは見えにくいものです。その声をもとに募集の文面や最初の1か月の計画を直すと、次のインターン生の定着が変わります。辞めることを失敗とだけ捉えず、受け入れを直す材料として扱うことを勧めます。

面談で離脱の兆しをつかむ

すぐ辞める学生の多くは、辞めると伝える前に、いくつかの兆しを見せています。勤務の日数が少しずつ減る、質問が減る、報告が短くなる、表情が硬くなる。こうした兆しを早めにつかむために、定期的な面談を設けておきます。

面談では、仕事の進み具合だけでなく、次のようなことを聞きます。

  1. 今の仕事は、思っていた仕事と比べてどうか
  2. 困っていること、聞きにくいと感じていることはないか
  3. 学業や他の予定との両立に無理はないか
  4. 次に任されたい仕事はあるか

面談の相手は、指導役だけでなく、指導役以外の社員や人事が担うこともあります。指導役には言いにくい不満も、別の人になら話せることがあるからです。兆しに早く気づけば、仕事の内容や勤務の形を調整して、辞める前に手を打てることがあります。面談の頻度は、最初の数か月は多めに、慣れてきたら間隔を空けていく形が無理のない進め方です。

定期の面談や受け入れの流れをどう組むか。定着の仕組みを一緒に見直します。

運用の相談をする

まとめ

  • すぐ辞める理由の多くは、受け入れ側の見直しで減らせる
  • 辞めた時期で原因の当たりをつける：数週間ならずれ、1〜2か月なら放置、数か月以上なら負担と成長の止まり
  • 募集に、最初の1か月の仕事とその先に任せたい仕事を分けて書く
  • 最初の数週間は、こまめに確認し、反応を返す
  • 辞めるときに感想を聞き、次の受け入れの見直しに使う

よくある質問

辞める理由を本人がはっきり言いません

辞める時点では、本音を言いにくいことも多いです。責める意図がないことを伝え、「次に入る学生のために」という形で聞くと、話してもらいやすくなります。それでも言いにくそうなら、無理に聞き出さず、辞める前の様子から原因を考えます。

受け入れの期間をあらかじめ決めておくべきですか

期間を決めておくと、学生も会社も見通しを持てます。たとえば数か月ごとに区切り、そのたびに続けるかどうかを話し合う形にすると、辞めることも続けることも話題にしやすくなります。

辞めるのを引き止めてもよいですか

本人の事情を聞き、勤務の日数を減らす、時期を区切るなど、続けられる形があれば提案するのは自然です。ただし、強く引き止めると関係が悪くなることもあります。本人の判断を尊重し、辞めたあとも関係が残る形で送り出すことを勧めます。
