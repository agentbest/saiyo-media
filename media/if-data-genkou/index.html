データ分析の長期インターン求人原稿｜学生が応募を決める書き方

「データ分析」という職種名は、学生によって思い浮かべる仕事が大きく違います。表計算で売上を集計する仕事を想像する学生もいれば、機械学習のモデルを作る仕事を想像する学生もいます。結論から言うと、データ分析の長期インターンの原稿は、「分析」の中身を集計・可視化・モデル作りなどの具体的な作業に言い分け、扱うデータの範囲と結果を報告する相手を書くと、合う学生からの応募が決まりやすくなります。 この記事では、株式会社Legaseedが運営する大学生向けの長期・有給インターン求人サイトInfraでデータ分析の学生を募集する会社に向けて、原稿の組み立て方を整理します。

データ分析志望の学生が原稿で確かめていること

データ分析の長期インターンを探す学生は、統計や情報系の学部の学生が多い一方で、経済や心理など、授業で分析の手法に触れた文系の学生もいます。原稿を読むときに確かめていることは、おおむね次の五つです。

  • 作業の中身：集計か、可視化か、仮説を立てて検証するのか、モデルを作るのか
  • 扱うデータ：実際の事業のデータに触れられるのか、練習用のデータが中心なのか
  • 使う道具：表計算、データベースへの問い合わせ、プログラミング言語、可視化の道具
  • 結果の行き先：分析の結果を誰に報告し、それが何に使われるのか
  • 教えてくれる人：社内に分析を担う社員がいるのか

学生が最も気にするのは、二つ目と四つ目です。授業や独学では、用意されたデータで分析の練習はできます。足りないのは、実際の事業のデータを使い、その結果が誰かの判断に使われる経験です。原稿でこの二つが見えると、学生は「ここで働く意味」を見つけやすくなります。

扱えるデータの範囲を社内でどう決めるかは、データ分析の長期インターンを採るで詳しく整理しています。この記事は、その範囲が決まったあとに、原稿の文章へどう落とすかに絞ります。

原稿に書く項目と順番

原稿全体の組み立てはInfraの求人原稿の書き方にまとめていますが、データ分析の職種では次の順番を勧めます。

  1. 分析で何を決めたいチームか：事業の中で、分析の結果がどんな判断に使われるか
  2. 作業の中身：集計、可視化、検証、モデル作りのうち、中心になるもの
  3. 扱うデータの範囲：最初に触れるデータと、慣れてから触れるデータ
  4. 報告の相手と頻度：誰に、どのくらいの間隔で結果を伝えるか
  5. 教える人：社内で分析を担う社員、または報告を受ける事業の担当者
  6. 使う道具：事実だけを並べる
  7. 求める経験と、求めない経験
  8. 働き方：週の稼働の目安、リモートか出社か、試験期間の扱い

1番目を最初に置くのは、学生が「何のための分析か」を知りたがっているからです。「広告の出し方を決めるために、どの経路から来た利用者が長く使い続けているかを調べています」と一文あるだけで、分析の目的が伝わり、作業の中身も想像しやすくなります。

データ分析の原稿で、作業の中身と扱うデータをどう書くか。下書きの段階からご相談いただけます。

無料で相談する

作業の中身と、扱うデータの書き方

作業の中身は、「データ分析」とまとめず、学生が自分の経験と比べられる言葉で書きます。

  • 集計が中心なら：「毎週の売上や利用状況の数字を集計し、表とグラフにまとめます」
  • 検証が中心なら：「施策の前後で利用者の行動がどう変わったかを調べ、結果を担当者に報告します」
  • モデル作りが中心なら：「利用をやめそうな利用者を見つける仕組みの改善を、社員と一緒に進めます」

一つに絞れない場合は、中心になる作業と、ときどき入る作業を分けて書きます。どれも少しずつ、という書き方は、学生には中身が見えにくくなります。

扱うデータは、範囲の段階を書きます。たとえば「最初は個人が特定できない集計済みのデータで作業し、慣れてきたら匿名化した利用のログも扱います」のような書き方です。具体的な項目名まで書く必要はありませんが、段階があることを示すと、学生は会社がデータを慎重に扱っていると受け取ります。情報の扱いは、学生に安心感を与える材料にもなります。

エージェントベストの見解

データ分析の長期インターンで、原稿の相談を受けたときに最も多い思い込みは、「分析の手法を並べたほうが、優秀な学生が来る」というものです。実際には、手法の名前を並べた原稿は、手法を学びたい学生を集めますが、事業の判断に分析を使いたい学生には響きにくい傾向があります。会社が受け入れたいのは多くの場合後者で、ここに食い違いが生まれます。当社が原稿の下書きを見るとき、確かめるのは「分析の結果が、誰のどんな判断に使われるか」が冒頭に書いてあるかどうかです。この一文があると、手法そのものに関心がある学生も、事業に関心がある学生も、自分に合うかを判断できます。手法の名前は、使う道具の欄に事実として並べるだけで十分です。原稿の重心を、手法から判断へ移してください。

書き換えの例

よくある書き方と、書き換えた例を並べます。

よくある書き方書き換えた例
データ分析業務をお任せします毎週の利用状況を集計し、変化があった点を事業の担当者に報告します
ビッグデータに触れられます最初は集計済みのデータから始め、慣れたら利用のログも扱います
データドリブンな意思決定に貢献できます分析の結果は、翌月の広告の配分を決める会議で使われます
統計の知識を活かせます授業で検定や回帰を学んだ経験があれば、実際のデータで使う場面があります

書き換えた例は、どれも「入ってから何をするか」が見える書き方です。「ビッグデータ」「データドリブン」のような言葉は、学生にとって中身の手がかりになりません。

やりがちな失敗

データ分析の原稿で起きやすい失敗は、次の四つです。

  1. 求める道具の経験が多すぎる：プログラミング言語、データベース、可視化の道具をすべて必須にすると、どれかに経験がある学生が応募を見送ります。最初に使うものだけを必須にします
  2. 報告の相手が書かれていない：結果を誰に伝えるかがないと、学生は分析をしても使われないのではと感じます
  3. データの範囲が書かれていない：触れるデータが分からないと、学生は練習用のデータだけを触る仕事だと受け取ることがあります
  4. 教える人がいないのに書いていない：社内に分析を担う社員がいない場合は、それを書き、誰が結果を受け止めるかを書きます

働き方の欄では、勤務時間や学業との両立について書くことになります。学生の労働時間や学業への配慮には法令で定められた項目や指針がありますので、条件を決める段階で社会保険労務士や公式の案内で確認しておいてください。給与の書き方は長期インターンの給与の書き方を参考にしてください。

求める経験をどこまで絞るか、報告の相手をどう書くか。原稿の見直しだけでも構いません。

運用の相談をする

原稿から選考への接続

原稿の最後には、選考の流れを書きます。データ分析の職種では、面談で過去の分析の経験を聞くことが多く、その準備のしかたを原稿で伝えておくと、学生は応募しやすくなります。

  • 面談で聞くこと：授業や研究、個人で取り組んだ分析を一つ話してもらう、と書いておく
  • 技術の確認：その場で簡単な集計の方針を話してもらう、などの形があるなら書く
  • 課題の有無：持ち帰りの課題を出すなら、その目安を書く

面談には、原稿に「報告の相手」として書いた事業の担当者が出ると、学生は分析の結果が使われる場面を具体的に聞けます。原稿と面談の内容がそろっていると、書かれていたことへの信頼が増します。

エージェントベストの見解

当社は長期インターンの募集を支援する一方で、新卒や中途の採用の相談も受けています。その立場から言えるのは、データ分析の長期インターンは、原稿を出す前に「学生がいなくなったあと、その分析を誰が続けるか」を決めておく必要がある、ということです。学生が毎週の集計の仕組みを作り、卒業とともにいなくなると、仕組みだけが残って誰も使えなくなることがあります。原稿の「報告の相手」の欄に書く社員が、そのまま引き継ぐ人になる形にしておくと、この問題は起きにくくなります。原稿を書くときに、報告の相手を「結果を受け取る人」としてだけでなく、「仕組みを引き継ぐ人」としても選んでおく。これは原稿の書き方というより順番の話ですが、原稿を書く段階で決めておくと、受け入れのあとで慌てずに済みます。

まとめ

  • 「データ分析」は、集計・可視化・検証・モデル作りのどれが中心かに言い分けて書く
  • 原稿の冒頭に、分析の結果が誰のどんな判断に使われるかを置く
  • 扱うデータは段階で書き、慎重に扱っていることを伝える
  • 必須の道具は最初に使うものだけに絞る
  • 報告の相手は、仕組みを引き継ぐ人としても選んでおく

よくある質問

文系の学生も対象にしてよいですか

作業の中身が集計や可視化中心なら、授業で分析の手法に触れた文系の学生も十分に対象になります。原稿の「求めない経験」の欄に「学部は問いません」と書いておくと、応募をためらう学生が動きやすくなります。

社内に分析の専任がいません。それでも募集してよいですか

募集はできますが、結果を受け止める事業の担当者を決めておくことが前提です。原稿にも、専任がいないことと、誰が結果を受け止めるかを書いておくと、入ってからの食い違いを防げます。

タイトルはどう付ければよいですか

「データ分析」だけでなく、何の分析かを一言入れると、一覧で開いてもらいやすくなります。たとえば「利用者の行動データの集計と報告」のように、対象と作業を入れます。タイトルの組み立て方はInfraの求人タイトルの付け方にまとめています。
