新規事業の長期インターン生の最初の1か月｜任せる仕事と育て方

Infra・長期インターン職種別の受け入れ 更新日 2026/11/4

新規事業の長期インターン生を迎えた会社が、最初の1か月でつまずきやすいのは、事業の責任者の頭の中にある考えが学生に伝わらないまま、仕事だけが渡されることです。学生は言われた作業をこなしますが、その作業が何を確かめるためのものか分からず、方向が変わるたびに戸惑います。結論から言うと、最初の1か月は事業の仮説を言葉にして学生と共有し、小さな検証を一つずつ任せて、週ごとに結果を一緒に振り返ると、方向が変わっても学生が迷わずに進めます。 この記事では、受け入れ前の準備から1か月の振り返りまでを週ごとに整理します。募集の段階の原稿は新規事業の長期インターン求人原稿で扱っています。

受け入れ前に決めておくこと

初日の前に、次の四つを決めておきます。

  1. 主に見る社員：多くの場合は事業の責任者。責任者が忙しい場合は、日々の相談を受ける社員を別に決める
  2. 仮説の一枚：誰の、どんな困りごとを、どう解決しようとしているか。いま確かめたいことは何か
  3. 最初の検証：学生に最初に任せる、小さな検証を一つか二つ
  4. 触れてよい情報の範囲と守秘の約束：まだ公表していない事業なら、口外しないことを書面で取り交わす

二つ目の「仮説の一枚」が、新規事業の受け入れで最も効く準備です。事業の責任者は仮説を頭の中に持っていますが、言葉になっていないことが多いものです。一枚に書いておけば、学生は自分の仕事がどこにつながるかを理解でき、方向が変わったときも、どの仮説が変わったのかを追えます。

雇用で受け入れる場合、労働条件の明示や労働時間について法令で定められた項目があります。契約の中身は社労士や公式の案内で確認しておきます。受け入れ全体の準備は長期インターンの受け入れ体制も参考になります。

1週目｜仮説を共有し、調べる仕事から始める

1週目の目的は、学生が事業の仮説を自分の言葉で説明できるようになることです。

  • 事業の責任者が、仮説の一枚を使って事業の考えを説明する
  • 学生に、仮説を自分の言葉で言い直してもらう
  • 公開情報を使って、似た事業や対象の顧客について調べてもらう

二つ目の言い直しは、短い時間でできて効果の大きい方法です。学生の言い直しを聞くと、責任者の説明のどこが伝わっていないかが分かります。仮説の一枚を直すきっかけにもなります。

最初の調べ物は、問いを責任者が決めて渡します。「似た事業はどんな人に向けて、どんな売り方をしているか」のように問いがあると、学生はどこまで調べればよいかが分かります。初日の組み方は長期インターン初日の受け入れでも整理しています。

新規事業の学生に、最初の検証として何を任せるか。仮説の整理から一緒に考えます。

2週目から3週目｜小さな検証を一つずつ任せる

仮説が共有できたら、小さな検証を任せます。一度に複数を任せず、一つずつ進めます。

  • 見込み客に話を聞くための質問の案を作り、責任者と一緒に一人目の聞き取りをする
  • 試作のページや資料に対する反応を集計し、一覧にまとめる
  • 売り込み先の候補を調べ、社員と一緒に最初の連絡をする

聞き取りは、新規事業の学生にとって学びの多い仕事です。最初の数回は社員が同席し、聞き方を見せます。学生が一人で聞き取りをするのは、質問の型と記録の仕方が身についてからにします。顧客と話す仕事を任せるときは、学生が会社を代表して話していることを伝え、約束してはいけないことを先に決めておきます。

検証の結果は、思ったとおりにならないことが多いものです。結果が仮説と違っても、学生の仕事の失敗ではないと、最初から伝えておきます。

エージェントベストの見解

新規事業の受け入れで、学生のやる気が下がりやすいのは、検証の結果が出たあと、その結果がどう使われたかが学生に伝わらないときです。責任者は結果を見て、次の手を考えますが、その判断の過程を学生に話さないまま、次の仕事を渡してしまいます。学生から見ると、自分の集めた事実が事業にどう効いたのか分かりません。勧めたいのは、検証の結果を受けて責任者が何を決めたかを、一言でよいので学生に返すことです。「この結果を見て、対象を個人から法人に変えることにした」と伝えるだけで、学生は自分の仕事が事業を動かしたと感じられます。新規事業の仕事のやりがいは、事業が成功するかどうかより、自分の集めた事実が判断に使われる手応えにあります。その手応えを返す一言を、責任者の習慣にしておくと続けてもらいやすくなります。

4週目｜検証を一つ、始めから終わりまで受け持つ

4週目には、小さな検証を一つ、問いを立てるところから結果をまとめるところまで受け持ってもらいます。

  1. 確かめたいことを一文で書く
  2. 確かめ方を決める（聞き取り、集計、試しの公開など）
  3. 結果を集め、分かったことと分からなかったことに分けてまとめる
  4. 会議で共有し、次に確かめたいことを提案する

問いを立てる段階で、責任者に一度見せてもらいます。問いが大きすぎると、1週間では確かめきれません。範囲を絞る手伝いをするのが、この段階の責任者の役割です。仕事の切り方は新規事業の長期インターンを採るにもまとめています。

1か月の振り返りで話すこと

1か月が終わったら、主に見る社員と学生で振り返ります。

  • この1か月で関わった検証と、それぞれで分かったこと
  • 仮説の一枚のうち、変わった部分と変わらなかった部分
  • 聞き取りや連絡の仕事で、やりにくかったこと
  • 2か月目に、どんな検証を任せるか。一人で進める範囲をどこまで広げるか

方向が変わった場合は、変わった理由を振り返りの中であらためて伝えます。学生が関わった検証が変更のきっかけになったなら、そのことも伝えます。振り返りの面談の型は長期インターン生との1on1も参考になります。

受け入れのあと、2か月目以降の任せ方や、事業が変わったときの学生への伝え方の相談も受けています。

運用の相談をする

エージェントベストの見解

新規事業の長期インターン生を、新卒採用につなげたいと考える会社もあると思います。新規事業の仕事は、学生の考え方や動き方がよく見える仕事なので、つなげる判断の材料は集まりやすい。ただ、新規事業で活躍した学生が、入社後に既存の事業で同じように動けるとは限りません。決まりごとの少ない中で動くことが得意な学生は、決まりごとの多い仕事で窮屈さを感じることもあります。当社は長期インターンの媒体のほか、新卒採用の媒体や紹介での採用にも関わっていますが、入社後のずれを小さくするために勧めたいのは、新卒の選考に誘う前に、入社後に配属されうる部署の社員と話す場を一度作ることです。学生が新規事業の外の仕事も知ったうえで選べば、入ってからの落差が小さくなります。つなげ方は長期インターンから新卒採用へつなぐ設計も参考になります。

まとめ

  • 受け入れ前に、主に見る社員・仮説の一枚・最初の検証・守秘の約束を決める
  • 1週目は仮説を共有し、学生に自分の言葉で言い直してもらう
  • 2〜3週目は小さな検証を一つずつ任せ、聞き取りは社員の同席から始める
  • 検証の結果を受けて何を決めたかを、学生に一言返す
  • 4週目に検証を一つ受け持ってもらい、振り返りで2か月目の範囲を決める

よくある質問

事業の責任者が忙しく、学生を見る時間がありません

日々の相談を受ける社員を別に決め、責任者は週に一度の振り返りだけに出る形でも回ります。その場合も、仮説の一枚は責任者が書き、検証の結果を受けた判断は責任者から学生に伝えるようにします。

学生に見込み客への聞き取りを一人で任せてもよいですか

質問の型と記録の仕方が身につき、約束してはいけないことを学生が理解してからにします。最初の数回は社員が同席し、慣れてから一人で任せる会社が多いようです。聞き取りの記録は、その日のうちに共有してもらいます。

1か月で事業の方向が大きく変わり、学生の仕事がなくなりました

それまでの検証の結果を一緒に振り返り、何が分かったから方向が変わったのかを伝えます。そのうえで、新しい方向で最初に確かめたいことを学生に任せます。方向が変わったときの扱いは、受け入れの前に決めておくと、慌てずに済みます。
