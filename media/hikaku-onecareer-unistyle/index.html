ワンキャリアとunistyleの違い｜学生が読む情報の種類と、企業が置く情報

「学生はワンキャリアとunistyleのどちらを見ているのか」「うちの選考の情報が、どこにどう出ているのか分からない」という相談を受けます。結論から言うと、どちらも学生が選考の情報を読みに来る場ですが、読みに来る情報の種類が違います。ワンキャリアでは選考体験談とクチコミを、unistyleではエントリーシートの例や選考対策を読みます。 この違いは、企業が置く情報と、選考そのものの設計に効きます。ワンキャリアは株式会社ワンキャリアが運営する、クチコミと選考体験談を土台にした新卒向けの媒体。unistyleは、就職活動中の学生に向けて、エントリーシートや選考対策の情報を提供する場として公表されています。この記事ではunistyleの仕様や料金には触れず、学生が読む情報の種類の違いから、企業が何を見直すかを整理します。

学生が読みに来る情報の種類が違う

ワンキャリアで学生が読むのは、「この会社の選考はどう進んだか」「面接で何を聞かれたか」「実際に働いている人はどう言っているか」です。選考の体験と、会社の印象です。

unistyleで学生が読むのは、「この会社のエントリーシートには何を書けばよいか」「先輩はどう書いて通ったか」「選考の各段階で何を対策すればよいか」です。選考を通るための情報です。

観点ワンキャリアunistyle
学生が読む中心選考体験談・クチコミエントリーシートの例・選考対策
学生の目的受けるか、続けるかを判断する通るために準備する
読まれる段階応募前から内定承諾までエントリーシート提出前、面接前
企業の見え方選考の印象と会社の評判設問の意図と、通る答え方

ここで企業が押さえたいのは、学生が「通るための情報」を読んでから選考に来る、という事実です。自社のエントリーシートの設問に対して、学生は先輩の書き方を読み、型を知ったうえで書いてきます。企業が設問で見たかったことと、学生が用意してきた答えがずれる原因の1つが、ここにあります。

企業が置く情報が違う

ワンキャリアでは、企業は企業ページとイベント情報を置き、体験談を読んで選考の運用を直します。この点はワンキャリアとマイナビの違いで書きました。

unistyleのような対策の場では、企業が直接置く情報は多くありません。学生が読んでいるのは、先輩の書き方と対策の解説です。企業ができるのは、「自社の設問の意図を、企業側から先に説明しておく」ことです。設問の意図が公開されていれば、学生は先輩の型を写すより、意図に沿って書こうとします。

企業側から説明しておけることを挙げます。

  1. エントリーシートの設問で、何を知りたいのか：経験の大きさではなく、考え方を知りたい、など
  2. 面接の各段階で、何を見ているのか：一次は志向の確認、二次は仕事の適性、など
  3. 対策で埋まらない部分は何か：正解の型がなく、その人の言葉で書いてほしい部分

これらを企業ページや説明会、選考の案内文で先に出しておくと、対策の場で読んだ型と、企業の意図のずれが減ります。

いま使っている媒体の運用の相談だけでも構いません。選考の設問と学生の準備がずれていないか、一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「学生が対策サイトで自社のエントリーシートの書き方を読んでいることを、企業は止められないし、関係もない」というものです。実際には、止められないのはそのとおりですが、関係はあります。当社が3媒体すべての販売パートナーとして契約後の運用を見ている経験では、「エントリーシートの内容が似ていて選べない」「面接で話すことが用意された答えに聞こえる」という悩みを持つ会社は、設問の意図を企業側から説明していない会社です。学生は意図が分からないから、先輩の型を写します。意図を先に出せば、型より意図に沿って書く学生が増え、その人の言葉が出てきます。対策サイトを敵と見るより、「自社の設問の意図が学生に伝わっているか」を確認する鏡として使うことを勧めます。自社の設問が対策の場でどう解説されているかを一度読むと、設問の直し方が見えます。

選考の設計を見直す順番

対策の場で学生が読んでいることを前提にすると、選考の設計を見直す順番が決まります。

  1. 自社の設問が、対策の場でどう扱われているかを読む：先輩の書き方の型が、自社の意図と合っているかを確認する
  2. 意図とずれている設問を直す：型で書けてしまう設問は、意図に沿って書かないと答えられない設問に変える
  3. 設問の意図を企業側から説明する：企業ページ、説明会、選考の案内文に、何を知りたいかを書く
  4. 面接で確認する内容を、設問と対応させる：エントリーシートで書いたことを、面接で深く聞く。用意した答えの先を聞く
  5. ワンキャリアの体験談で、学生の受け取り方を確認する：直した選考が、学生にどう体験されたかを読む

この順番のうち、1と5が「読む」作業で、2から4が「直す」作業です。読む作業を飛ばして直すと、ずれの原因を見ないまま設問を変えることになります。

この条件なら、どちらを先に見るか

どちらも「学生が読んでいる場」なので、申し込むかどうかとは別に、先に読む場を置きます。

  • エントリーシートの内容が似ていて選べない → unistyleのような対策の場で、自社の設問がどう解説されているかを先に読む
  • 面接で話すことが用意された答えに聞こえる → 同上。設問の意図を企業側から説明する準備を先に
  • 選考の途中や内定後に辞退が多い → ワンキャリアの体験談を先に読む。選考の運用を直す
  • 自社の選考の印象が、学生の間でどう語られているか分からない → ワンキャリアを先に
  • 設問の意図は説明できているが、選考の進め方に不安がある → ワンキャリアを先に

自社に合う媒体がどれか、当社が扱う3媒体を並べてご案内します。相談だけでも構いません。

媒体選びを相談する

両方を前提にした選考の組み立て

学生が両方を読んでいることを前提に、企業側の動きを組み立てます。

  • 設問の意図は、企業側から先に出す：対策の場で型を読む前に、意図が伝わる状態にする
  • 選考の進め方と結果連絡は、体験談を読んで直す：ワンキャリアの体験談は、直した結果が学生にどう体験されたかを教えてくれる
  • 面接では、書いたことの先を聞く：用意された答えの先にある、その人の考えを聞く。これは対策では埋まらない
  • 企業ページには、設問の意図と、面接で見ていることを書く：ワンキャリアの企業ページは、そのための場として使える

エージェントベストの見解

これをやる前に、先に決めておかないと効果が出ないことがあります。それは「面接官が、設問の意図と、面接で見ていることを、自分の言葉で言えるか」です。企業ページや説明会で意図を説明しても、面接官がそれと違うことを見ていれば、学生は面接で混乱し、体験談に「説明と違った」と書かれます。当社が契約後の運用まで見ている立場から勧めるのは、設問の意図を公開する前に、面接官と「この設問で何を知りたいか」「面接で何を見るか」を1枚にまとめて合意することです。この合意があると、設問の意図の公開も、面接の進め方も、体験談の内容も、同じ方向を向きます。合意がないまま意図だけ公開すると、学生に約束したことを面接で破る形になり、ワンキャリアの体験談がそれを記録します。

まとめ

  • ワンキャリアとunistyleは、どちらも学生が選考の情報を読みに来る場だが、読む情報の種類が違う。体験談とクチコミか、エントリーシートの例と対策か
  • 学生は「通るための情報」を読んでから選考に来る。設問の意図と学生の答えがずれる原因の1つ
  • 企業ができるのは、設問の意図を企業側から先に説明すること。対策の場は、意図が伝わっているかを確認する鏡として使う
  • 選考の設計は、読む→直す→説明する→面接で確認する→体験談で受け取り方を見る、の順番で見直す
  • 意図を公開する前に、面接官と「この設問で何を知りたいか」を1枚で合意する

よくある質問

学生が対策サイトで自社の情報を読むのを、止められますか

止められません。前提として受け入れたうえで、自社の設問の意図を企業側から先に説明すると、型を写す学生より、意図に沿って書く学生が増えます。対策の場で自社の設問がどう解説されているかを読むと、設問の直し方が見えます。

ワンキャリアとunistyleは、どちらを先に見るべきですか

悩みの種類で決まります。エントリーシートの内容が似ている、面接で用意された答えに聞こえる、という悩みなら対策の場を先に読みます。選考の途中や内定後の辞退が多い、自社の選考の印象が分からない、という悩みならワンキャリアの体験談を先に読みます。

unistyleの掲載も御社経由でできますか

当社が販売パートナーとして窓口になるのは、OfferBox・Wantedly・ワンキャリアの3媒体です。unistyleは各社の窓口になりますが、学生が読んでいる情報を前提にした選考の設計や、設問の意図の説明の仕方は、ワンキャリアの運用を見ている立場からご相談いただけます。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。
