長期インターンの受け入れで社員の負担が大きいとき

Infra・長期インターン課題別 更新日 2026/10/29

長期インターン生を受け入れたあと、指導役の社員から「自分の仕事が進まない」という声が上がることがあります。放っておくと、受け入れそのものに否定的な空気が社内に広がります。結論として、社員の負担は「時間の負担」「気持ちの負担」「評価されない負担」の3つに分かれ、それぞれに効く打ち手が違うため、負担の中身を分けてから手を入れると改善しやすくなります。 時間だけを減らしても、評価されないという不満が残れば、指導役は疲れたままです。この記事では、症状の確認、原因の切り分けの順番、打ち手、外に任せる範囲を整理します。

症状を確認する｜負担の中身を3つに分ける

指導役や周りの社員から負担の声が上がったら、その中身を次の3つに分けて聞きます。

  • 時間の負担：質問への対応、仕事の確認、説明に時間を取られ、自分の仕事が進まない
  • 気持ちの負担：何を任せればいいか考え続けることや、学生への接し方に気を使うことが重い
  • 評価されない負担：指導に時間を使っても、それが自分の評価に反映されない

声を上げている社員は、この3つが混ざった状態で「負担が大きい」と表現していることが多いです。一対一で話を聞き、どれが大きいのかを確かめるところから始めます。

原因を切り分ける順番

1. 質問への対応が集中していないか

時間の負担の多くは、質問への対応から来ます。次の点を確かめます。

  • 同じような質問が何度も来ていないか
  • 質問が、指導役一人に集中していないか
  • 質問のタイミングが、指導役の仕事の流れを頻繁に止めていないか

2. 仕事の切り出しが毎回ゼロからになっていないか

気持ちの負担の多くは、「何を任せるか」を毎回考えることから来ます。

  • 任せる仕事の一覧がなく、その都度考えている
  • インターン生が手持ち無沙汰になるたびに、仕事を探している
  • 任せた仕事の説明を、毎回一から行っている

3. 指導役が一人に偏っていないか

評価されない負担は、指導役が特定の社員に偏り、その役割が組織として認められていないときに大きくなります。

  • 指導役を、本人の希望や上司の判断なしに決めていないか
  • 指導の時間が、業務の時間として扱われているか
  • 指導役の働きが、上司や会社から言葉にして認められているか

指導役の負担が時間なのか、気持ちなのか、評価なのか。中身を分けると打ち手が変わります。受け入れの体制を一緒に見直します。

無料で相談する

エージェントベストの見解

社員の負担が大きいという相談で、当社がよく見るのは、指導役が「インターン生の上司」と「インターン生の同僚」と「インターン生の相談相手」の3つの役割を一人で抱えている形です。仕事を割り振り、隣で一緒に作業し、悩みも聞く。どれも必要な役割ですが、一人で担うと時間も気持ちも削られます。当社が勧めるのは、この3つを分けることです。仕事の割り振りと評価は指導役、作業の隣で質問を受けるのはチームの別の社員、仕事以外の悩みを聞くのは人事や年の近い社員。役割を分けると、それぞれの社員の負担は小さくなり、インターン生も相談先が増えて質問しやすくなります。指導役を一人決めることと、一人に全部を任せることは別だと考えてください。

打ち手｜負担の中身ごとの見直し

時間の負担を減らす

  1. よくある質問と答えを、共有の場所にまとめる
  2. 質問の時間を決め、その時間にまとめて答える
  3. 質問の窓口を、指導役以外の社員にも広げる
  4. 作業の途中確認を、決まったタイミングに絞る

気持ちの負担を減らす

  1. 任せる仕事の一覧を作り、インターン生が自分で次の仕事を選べるようにする
  2. 仕事ごとに手順書や見本を残し、次に任せるときに使い回す
  3. 何を任せるかを、チームで月に一度話し合う

評価されない負担を減らす

  1. 指導役を決めるときに、本人の意向と上司の了承を得る
  2. 指導の時間を業務の時間として扱い、本人の仕事量を調整する
  3. 指導役の働きを、上司や会社から言葉にして認める
  4. 指導の経験を、本人の評価の項目に入れる

評価の見直しは、すぐにできないこともあります。それでも、上司が指導役の働きを言葉にして認めるだけで、受け止め方は変わります。

受け入れの規模を見直す

打ち手を講じても負担が減らない場合は、受け入れの規模そのものを見直すことも考えます。

  • インターン生の人数が、指導できる社員の数に対して多すぎないか
  • 週の勤務日数が、指導役の手が空く日と合っているか
  • 受け入れる部署が、繁忙期に重なっていないか

規模を小さくすることは、後退ではありません。指導役に余裕がある状態で受け入れるほうが、インターン生の経験もよくなり、結果として受け入れが長く続きます。複数名の受け入れの考え方は長期インターン生を複数名同時に受け入れるときでも整理しています。

外に任せる範囲

社員の負担のうち、外部に任せられる部分もあります。

外部に任せやすいこと

  • 募集の原稿の作成と見直し
  • 応募への連絡や面接の日程調整
  • 受け入れ前の段階で、任せる仕事と期待を整理する相談

自社で持つこと

  • 日々の仕事の割り振りと指導
  • インターン生との振り返りと評価

エージェントベストの見解

当社はInfraの代理店として、募集の段階から受け入れの相談まで関わることがあります。社員の負担が大きくなりやすい会社には、募集の段階である共通点が見えます。それは、任せる仕事を決めないまま「いろいろ手伝ってほしい」と募集を出していることです。仕事が決まっていない募集で受け入れると、受け入れた後に何を任せるかを社員が考え続けることになり、気持ちの負担が大きくなります。募集の前に任せる仕事を決めておくと、受け入れた後の負担が軽くなるだけでなく、応募してくる学生の関心も仕事に合ったものになります。社員の負担を減らす打ち手は、受け入れた後よりも、募集を出す前のほうが打ちやすいのです。

受け入れの効果を社内に見せる

社員の負担の感じ方は、受け入れの効果が見えているかどうかでも変わります。手間だけが見えて、効果が見えないと、負担は実際以上に重く感じられます。

  • インターン生が進めた仕事を一覧にする：後回しになっていた仕事のうち、何が進んだか
  • 社内の会議で紹介する：インターン生の成果物を、部署や会社の会議で紹介する
  • 指導役の働きを合わせて伝える：成果の裏に、指導役の関わりがあったことを言葉にする
  • 次の受け入れに生かす点を共有する：うまくいった仕事の渡し方を、他の社員にも伝える

効果を見せることは、指導役の評価されない負担を軽くすることにもつながります。インターン生の成果が社内で認められると、指導役の働きも自然と目に入るようになります。受け入れに消極的だった社員が、成果を見て考えを変えることもあります。

受け入れの効果を社内にどう見せ、指導役の負担をどう減らすか。体制の見直しをご相談ください。

運用の相談をする

まとめ

  • 社員の負担は、時間・気持ち・評価されないの3つに分けて確かめる
  • 原因は、質問の集中、仕事の切り出し、指導役の偏りの順に切り分ける
  • 指導役の役割を、仕事の割り振り・作業の隣での質問対応・相談相手に分ける
  • 指導の時間を業務として扱い、指導役の働きを言葉にして認める
  • 負担が減らない場合は、受け入れの規模や時期を見直す

よくある質問

指導役を誰にすればよいか迷っています

インターン生に任せる仕事を日常的にしている社員で、週に決まった時間を割ける人が向いています。本人の意向を確かめ、上司が仕事量の調整を了承していることが前提です。経験の浅い社員が指導役になる場合は、相談できる先輩をつけておくと安心です。

インターン生からの質問が多すぎて困っています

よくある質問をまとめておき、まずそこを見てもらうようにすると、同じ質問は減ります。質問の時間を決めてまとめて答える形にすると、指導役の仕事が細かく止まることも減ります。

受け入れを続けるべきか、やめるべきか迷っています

負担の中身を分け、打ち手を講じても改善しない場合は、規模を小さくする、時期をずらすといった選択肢があります。やめるかどうかを決める前に、今の受け入れで何がうまくいき、何が負担だったのかを記録しておくと、再開するときに役立ちます。
