Wantedlyの費用を、入社を承諾した人の数で割ってみる。思ったより高い。記事を書く時間やカジュアル面談に出る時間まで考えると、さらに高く感じる。結論から言うと、「費用÷承諾数」の一つの数では、記事が残り、共感で人が来る媒体の単価は測れません。Wantedlyでは四つの見方で分けます。共感からカジュアル面談、選考、承諾までのどの段で止まっているかを先に見る。初年度に書いた記事と型を翌年に繰り越す。人事と社員と代表の時間を入れる。他の経路とは同じ物差しで並べる。単価を下げる手立ては、費用を削ることでも記事を減らすことでもなく、止まっている段を直すことです。費用の金額は、見積もりと契約で確認します。 KPIの置き方はWantedlyの効果が測れないときのKPIの置き直し、記事の資産はWantedlyのコンテンツを資産として貯める考え方、OfferBoxの場合はOfferBoxの採用単価が高く感じるときの見方で書きました。

Wantedlyの単価の一つの数に、何が混ざっているか

採用単価の中には、期間で決まる費用、運用の出来、初年度かどうか、何を分母にしたか。Wantedlyではこれに、会社ページやストーリーが翌年も読まれること、社員が話す時間を使うことが加わります。

この記事で目指すのは、混ざったものをほどき、どれが「高い」の正体かを見つけ、直せるところを直したうえで、続けるかを決められる形にすることです。単価の数だけを見て、続ける・やめるを決めないようにします。

「費用÷承諾数」で割ると、Wantedlyで見落とすもの

見落とすものなぜ見落とすか
初年度に作った土台会社ページの「なぜ」、ストーリー、募集記事の型、社員の協力を作った年の費用が、その年の承諾数だけで割られる
翌年も読まれる記事記事はその年の費用として扱われ、翌年の候補者が読む分が入らない
社員と人事の時間費用だけを見ていて、話した時間と書いた時間が入らない。反対に、時間を入れずに「安い」と見ることもある
経路ごとの費用のかかり方期間で決まる費用と、承諾ごとにかかる費用を、同じ割り算で並べている
近い人が来たかどうか承諾の数だけで、自社が採りたい人に近い人がカジュアル面談まで来たかが見えない

Wantedlyの成果は、承諾の手前の段と、承諾の外に残る記事にも出ます。承諾数だけを分母にすると、その二つが見えなくなります。

見方1｜共感からカジュアル面談、承諾までのどこで止まっているか

Wantedlyでは、候補者が会社ページやストーリーを読み、「話を聞きに行きたい」と思って来る流れが中心です。最初の接点はカジュアル面談で、選考はその先にあります。段もその流れで並べます。

  1. 段を並べる：募集やスカウトが読まれる → 「話を聞きに行きたい」や返信が来る → カジュアル面談 → 選考 → 内定 → 承諾
  2. 最も大きく減っている段を一つ選ぶ：承諾の少なさは、たいていこの段の結果として出ている
  3. その段に合う直しを一つだけ決める：返信の段なら文面と送る相手、カジュアル面談の段なら返す速さと面談の形、選考の段なら面談で話したことが選考に引き継がれているか、内定後なら接点の保ち方
  4. 直す前と後で、次の段へ進んだ数を比べる：進む数が増えた分だけ、単価は下がって見える

「高い」と感じたとき、手を付ける順番は費用の見直しではなく、どこで止まっているかの確認です。段の見方はWantedlyのスカウト運用のKPI設計、内定後の止まりはWantedly経由の内定辞退が続くときで書きました。

いま使っている媒体の運用の相談だけでも構いません。「高く感じる」が四つのどれに当たるかを、いまの数字から一緒に分けます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「Wantedlyは記事を書く時間がかかるので、単価が高くなる」というものです。当社は採用媒体の代理店として、Wantedlyの運用を見ていますが、記事を書く時間を単価に入れる会社が、その記事が翌年も使えることを単価に入れていないことがほとんどです。記事は、書いた年だけの費用ではなく、翌年以降の候補者にも読まれ、翌年の記事を書く時間を減らします。初年度に書いた時間を初年度の承諾数だけで割ると、高く出て当然です。当社が単価の相談を受けるとき、最初にやるのは、費用の比較ではなく、共感からカジュアル面談までの段の数を並べて止まりを指すことと、「翌年も使える記事が何本残ったか」を書き出すことです。この二つで、「高い」の中身が変わります。

見方2｜初年度に書いた記事と型を、翌年に繰り越す

  • 初年度に作ったもの：会社ページの「なぜ」、ストーリー、募集記事の型、スカウトの文面の型、社員の協力の形、カジュアル面談に来た人の言葉
  • これは、翌年に使える：翌年の費用には、この分が入らない。翌年の記事は、初年度の型で短い時間で書ける
  • 初年度の数には、土台づくりの費用が乗っている：その年に入社を決めた人の数だけで割れば、数が大きく出るのは自然なこと
  • 二年目の単価は、記事と型がある状態で出る：同じ費用で、書く時間が減り、承諾が増えれば下がる
  • 初年度の判断は、単価ではなく「残った記事と協力」で：経営層にWantedlyの成果を説明する方法

Wantedlyは、記事が残る媒体です。「残る」を単価に入れないと、初年度は実態より重く見えます。資産の考え方はWantedlyのコンテンツを資産として貯める考え方で書きました。

見方3｜人事と社員と代表の時間を、入れる

  • 人事の時間：社員に話を聞いて記事にする、スカウトを読んで書く、返信に返す、カジュアル面談に出る。週の枠で
  • 社員の時間：記事のために話す（月に一人、短い時間）、記事の確認、カジュアル面談に出る
  • 代表の時間：会社の「なぜ」を話す（最初に一度）、確認
  • 他の経路の時間：ナビなら説明会の準備と登壇、紹介会社を使うなら推薦された人への対応、イベントなら準備と当日
  • 費用の比較に、かかる時間を横に並べる：同じくらいの費用でも、人事と社員の時間を多く使う経路と、あまり使わない経路がある
  • 時間をお金に置き換えるかどうかは、会社ごとに決めてよい：置き換えなくても、「費用は近いが、使う時間はこれだけ違う」と並べば判断できる

Wantedlyは、社員の時間を使う媒体です。入れないと「安く」見え、入れると「高く」見えますが、どちらも一面です。使った時間あたりで、近い人がカジュアル面談まで来た数を見ると、見合うかが分かります。社内で回す場合と外に出す場合の時間の差は、運用代行に出す前提の媒体の選び方で比べています。

見方4｜他の経路と並べるなら、物差しを揃える

経路費用がかかるタイミング並べるときに気をつけること
Wantedly（期間で費用が決まる形）契約した期間ごと。承諾の数に関わらない承諾が増えるほど単価が下がる。残った記事を翌年に繰り越す
成功報酬型の経路（紹介会社など）承諾ごと一人あたりは固定。段の直しで単価は下がらない。記事は残らない
ナビ（掲載型）掲載期間ごとエントリー数と「話を聞きに行きたい」の数を、同じものとして並べない
イベント回ごと参加者数とカジュアル面談の数を並べない

物差しを揃えるとは、三つで並べることです。自社の見積もりの費用を「採りたい人に近い人がカジュアル面談まで来た数」で割ったもの、人事と社員の時間、翌年に残るもの。費用のかかり方の違いそのものは、定額型と成功報酬型の媒体の違いに整理しています。Wantedlyは募集情報等提供事業者として運営される場で、紹介会社のように人を推薦する仕組みではないため、費用のかかり方も違って当然です。費用の金額は、見積もりと契約で確認してください。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。費用と時間と残る記事を並べて見るための、人事と社員の時間の見積もりをお伝えします。

媒体選びを相談する

単価を下げるのは、カジュアル面談の先へ進む人を増やすこと

  • 費用を抑えても、入社を決める人の数が変わらなければ、単価はほぼ動かない：期間で費用が決まる形では、費用を小さくできる余地が限られる
  • 記事を減らしても、単価は下がらない：記事が減ると、読まれる入口が減り、承諾も減る。Wantedlyの運用に工数が足りないとき
  • 増やすのは、承諾まで進む人の数：そのために、止まっている段を一つずつ直す
  • 返信の段：文面と相手。Wantedlyのスカウトに返信が来ないときの対応
  • カジュアル面談の段：返しの速さと形。Wantedlyで面談につながらないとき
  • 選考の段：カジュアル面談の続きとして組む。Wantedly経由の候補者が選考で離脱する理由
  • 内定後の段：接点を途切れさせない。Wantedly経由の内定辞退が続くとき
  • スカウトの数で分母を増やそうとしない：読まずに送る形になり、共感で来る流れが細る

分母を増やすとは、数を送ることでも記事を量産することでもなく、共感で来た人が次の段へ進めるようにすることです。

エージェントベストの見解

これは数字の読み方の話です。当社がWantedlyで採用単価の相談を受けるとき、単価の数字そのものについては、「高い」とも「低い」とも言いません。他社の単価は、他社の記事と社員の協力と初年度かどうかの結果で、自社の判断に使えないからです。当社が見るのは、その単価の分母が「どの段の結果か」と、「初年度か」と、「人事と社員の時間が入っているか」と、「翌年に残る記事が入っているか」の四つです。Wantedlyは、四つ目が特に重く、記事を「その年の費用」として扱うと、初年度の単価は高く出て、二年目以降に下がる構造を見落とします。四つをほどいてもなお高いと感じるなら、そのときに初めて、続けるかどうかを話し合う材料になります。

まとめ

  • 「費用÷承諾数」の一つの数では、記事が残り共感で人が来る媒体の単価は測れない。初年度の土台、翌年も読まれる記事、社員の時間、費用のかかり方の違い、近い人が来たかが抜け落ちる
  • 先に、共感からカジュアル面談、選考、承諾までの数を並べ、最も減っている段を一つ選ぶ。承諾の少なさは、その段の結果として出ている
  • 初年度に作った会社ページ・ストーリー・型・社員の協力は翌年に使える。初年度の判断は単価ではなく「残ったもの」で、単価は二年目を見てから
  • 人事・社員・代表の時間を入れ、他の経路とは「近い人がカジュアル面談まで来た数」「時間」「翌年に残るもの」で物差しを揃える
  • 単価を下げるのは、費用を削ることでも記事を減らすことでもなく、止まっている段を直して承諾まで進む人を増やすこと。費用は見積もりと契約で

よくある質問

上司に「成功報酬型の経路のほうが一人あたり安い」と言われます

費用のかかり方が違うことを伝えます。成功報酬型は承諾ごとに費用がかかり、一人あたりは固定で、段の直しでは下がらず、記事は残りません。Wantedlyは契約した期間で費用が決まり、承諾が増えるほど一人あたりが下がり、記事が翌年に残ります。並べるなら、「近い人がカジュアル面談まで来た数」「時間」「翌年に残るもの」の三つで揃え、費用は自社の見積もりで確認します。結論は、自社の数字をこの形に置いてからです。

記事を書く時間を減らせば、単価は下がりますか

下がりません。記事を減らすと、読まれる入口が減り、スカウトで誘った候補者が会社ページに来て古い日付を見て返信しなくなり、承諾が減ります。分母が減って、単価は上がります。減らすなら、記事の長さと頻度を「短く途切れない」大きさにすることで、記事そのものを止めることではありません。

Wantedlyの採用単価の見方は、御社に相談できますか

できます。当社は、四つの見方の整理、段の見方、資産の書き出しの型、時間あたりの見方、物差しを揃える型を支えられます。費用の確認、時間の見積もり、選んだ段の直し、続けるかの判断は、各社で決めていただく部分です。当社は採用媒体の代理店として、Wantedlyの運用を支えています。
