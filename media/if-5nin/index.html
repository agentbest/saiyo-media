社員5名以下の会社が長期インターンを受け入れるとき

社員が5名以下の会社が長期インターンを検討するとき、迷いの中心は「受け入れる余裕が本当にあるのか」です。結論として、5名以下の会社の長期インターンは、代表か一人の社員が「週に決まった時間だけ見る」と決められるなら成り立ちます。 余裕ができるのを待つより、見る時間を先に決めて、その時間に収まる仕事を任せるほうが現実的です。この記事では、少人数の会社で割ける時間の見積もり方、最初に決めること、日々の運用を順に整理します。

5名以下の会社で割ける時間と人

社員5名以下の会社では、採用の窓口も、面接も、受け入れ後の指導も、たいてい同じ人が担います。多くの場合は代表です。代表が営業も経営も現場も見ている中で、長期インターンにどれだけ時間を使えるかを、最初に見積もっておきます。

目安として考えたいのは、次の3種類の時間です。

  • 募集と選考の時間：募集の文面を書く、応募に返信する、面接をする
  • 立ち上げの時間：最初の数週間、仕事の進め方を教え、横について見る
  • 継続の時間：仕事を渡し、確認し、振り返る。毎週の決まった時間

特に重いのは立ち上げの時間です。最初の数週間は、教える側の手が止まります。繁忙期と重なると、受け入れそのものが崩れます。受け入れの開始時期は、会社の仕事が比較的落ち着いている時期に置くのが基本です。

少人数の会社だからこそ選ばれる理由

5名以下の会社は、規模や知名度で大きな会社と比べられると不利に見えます。しかし、長期インターンを探す学生の中には、少人数の会社をあえて選ぶ層がいます。

  • 代表の近くで働きたい：経営の判断がどう決まるかを間近で見たい
  • 任される範囲が広い仕事がしたい：担当の枠にとらわれず、いろいろな仕事に関わりたい
  • 将来、起業や独立を考えている：会社が小さいうちの動き方を知りたい

募集では、この層に向けて「代表と一緒に働く」「任せる範囲」をはっきり書きます。少人数であることを隠すより、前面に出したほうが、合う学生に届きます。

代表が週に何時間見られるかから逆算して、任せる仕事と勤務の型を決めるお手伝いをします。募集原稿の作成からご相談ください。

無料で相談する

最初に決める3つのこと

5名以下の会社が長期インターンを始める前に、最低限決めておきたいのは次の3つです。

  1. 任せる仕事を一つに絞る：営業リストの作成、SNSの運用、問い合わせの一次対応など、範囲がはっきりした仕事を一つ
  2. 勤務の型を決める：週に何日、何時間。出社かリモートか。代表がいない日にどうするか
  3. 見る時間を決める：週に一度、何曜日の何時から何分、という形で固定する

この3つが決まっていれば、募集の文面もほぼ書けます。逆に、ここが曖昧なまま募集を出すと、面接で学生から聞かれても答えられず、学生の側が不安を感じて辞退につながります。

エージェントベストの見解

5名以下の会社から相談を受けたとき、当社が最初に確認するのは「代表が不在の日に、インターン生は何をしているか」です。少人数の会社では、代表が外出や商談で一日いない日が珍しくありません。その日にインターン生が出社しても、聞ける相手がいなければ作業が止まり、本人は時間を持て余します。これが数回続くと、学生は「自分は必要とされていない」と感じます。当社が勧めるのは、代表がいない日は在宅勤務にする、または代表がいない日でも進められる作業を一週間分まとめて渡しておくことです。少人数の会社では、受け入れる人がいない時間の設計が、受け入れる時間の設計と同じくらい重要です。

運用の分担と、日々の回し方

社員が5名以下でも、受け入れの役割を代表一人に集中させないほうが続きます。

  • 代表：面接、仕事の方向づけ、月に一度の振り返り
  • 社員の一人：日々の質問への対応、作業の確認
  • インターン生本人：週の作業の記録と報告

社員がいない、または全員が手一杯の場合は、作業の記録と報告を本人に任せ、代表は週に一度その記録を見る形にします。チャットツールで日報を書いてもらうだけでも、代表が状況を把握する手間は小さくなります。

日々の回し方としては、次の流れが続けやすい形です。

  1. 週の初めに、その週の作業を短く伝える
  2. インターン生は作業ごとに進み具合を記録する
  3. 週の終わりに、代表か社員が記録を見てコメントを返す
  4. 月に一度、仕事の手応えと次に任せたいことを話す

少人数の会社で気をつけたいこと

5名以下の会社では、インターン生の存在が組織に与える影響が大きくなります。注意したい点を挙げておきます。

  • 社員の一人として扱いすぎない：学業が優先であること、勤務時間が限られていることを前提にする
  • 雇用の条件を曖昧にしない：最低賃金や労働時間の規定を守る。判断に迷えば社会保険労務士などの専門家に確認する
  • 辞めたときに仕事が止まらないようにする：インターン生しか分からない仕事を作らない

エージェントベストの見解

当社はInfraの代理店として、少人数の会社の長期インターンの募集を支援することがあります。そこで見えるのは、5名以下の会社が長期インターンを通じて得るものが、採用だけではないということです。インターン生を受け入れるために、代表が頭の中にあった仕事の手順を書き出し、任せられる形に整理する。その過程で、社員を採るときに必要な業務の切り分けが自然に進みます。つまり、長期インターンの受け入れは、最初の正社員を採る前の練習になります。長期インターンでうまく回った仕事の渡し方は、社員が増えたときにそのまま使えます。いきなり正社員を採るのが不安な会社ほど、長期インターンから始める意味があると考えています。

募集の時期は、事業の波から逆算する

5名以下の会社では、事業の波がそのまま全員の忙しさになります。受注が集中する月、決算の時期、展示会やイベントの前後。こうした波の中で、受け入れの立ち上げをいつに置くかを決めておきます。

  1. 一年の中で落ち着いている時期を書き出す：立ち上げの数週間を、その時期に当てる
  2. 学生の動く時期と重ねる：学期の始まりの前後や長期休暇の前は、学生が長期インターンを探しやすい
  3. 募集から勤務開始までの期間を見込む：応募、面接、契約の手続きに時間がかかることを前提にする

学生の動く時期と、会社が落ち着いている時期が重ならない場合は、会社の側の都合を優先し、受け入れを少し後ろにずらすほうが無理がありません。忙しい時期に受け入れると、代表もインターン生も消耗し、最初の受け入れの印象が悪くなります。少人数の会社では、最初の一人の経験が、その後に受け入れを続けるかどうかの判断を大きく左右します。

事業の忙しい時期と学生の動く時期をどう合わせるか。少人数の会社の受け入れ計画を一緒に立てます。

運用の相談をする

まとめ

  • 5名以下の会社でも、週に決まった時間だけ見ると決められれば長期インターンは成り立つ
  • 立ち上げの時間が最も重い。受け入れの開始は落ち着いた時期に置く
  • 少人数であることを隠さず、代表の近くで働けることを前面に出す
  • 任せる仕事を一つに絞り、勤務の型と見る時間を先に決める
  • 代表が不在の日の過ごし方と、辞めたときの引き継ぎまで設計する

よくある質問

社員が自分一人だけでも、長期インターンを受け入れられますか

受け入れること自体は可能ですが、教える人も確認する人も一人になるため、任せる仕事の範囲を小さくしておく必要があります。リモートで進められる作業を中心にし、週に一度の確認の時間を固定すると、続けやすくなります。

オフィスがなく、自宅で仕事をしています。受け入れは難しいでしょうか

フルリモートで受け入れる形もあります。その場合は、作業の進め方と連絡の取り方をはっきり決めておくことが大切です。リモートでの受け入れの考え方はフルリモートの組織で長期インターンを受け入れるにまとめています。

インターン生にどこまで経営の話をしてよいですか

少人数の会社を選ぶ学生は、経営の判断を間近で見たいと考えていることが多いです。秘密にすべき情報の範囲を決めたうえで、判断の背景を話すと、学生にとって大きな学びになります。扱う情報については、守秘の取り決めを結んでおくと安心です。
