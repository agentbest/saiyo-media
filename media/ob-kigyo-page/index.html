OfferBoxの企業ページで伝えること・伝えないこと｜文面で興味を持った学生が見に来る先として作る

オファーの文面を読んで興味を持った学生は、承認する前に企業ページを見に来ます。結論から言うと、OfferBoxの企業ページは「会社を説明する場」ではなく、「文面で作った興味を、承認まで運ぶ場」です。書くのは、文面と揃えた仕事の中身、一緒に働く人、会社が何をしているかの一言、選考の流れ、そして写真。書かないのは、沿革の羅列、抽象語、制度の一覧、そして文面と矛盾することです。 企業ページが古い、空、文面と違う、のどれかだと、文面で作った興味がそこで消えます。この記事では、企業ページの位置づけ、伝えること、伝えないこと、作る手順、更新、やりがちな失敗、人事と現場の分担を整理します。OfferBoxのページの項目の仕様には触れず、考え方だけを書きます。文面の書き方はオファー文面の基本で書きました。

この作業の目的｜文面の続きを、学生が自分で読める場にする

文面は短くします。会社の説明は文面に書かず、企業ページに任せます。この設計はオファー文面の構成で書いたとおりです。つまり、企業ページは「文面で省いた会社の説明」を引き受ける場です。

学生の動きは、次の順です。

  1. 文面を開く
  2. 冒頭で「自分宛」だと分かる
  3. 本文で仕事の中身に興味を持つ
  4. 企業ページを見に来る
  5. 承認するかを決める

4で見るものが、文面と揃っていて、仕事の中身が詳しく分かり、一緒に働く人が見えれば、5で承認されます。4で見るものが、文面と違う、古い、会社の話しかない、だと、5で離れます。企業ページの目的は、4から5をつなぐことです。「整えてから送る」の順番は掲載型とスカウト型の違いでも書きました。

伝えること1｜文面と揃えた仕事の中身

企業ページで最も読まれるのは、仕事の中身です。文面で「この仕事で」と書いた仕事が、企業ページでは詳しく書かれている状態にします。

書くこと書き方
職種ごとの仕事の中身1日の流れ、最初の数ヶ月で何をするか、誰と一緒にやるか
その仕事で求めること経験や資格ではなく、行動の型。「自分で調べて動く」「人に聞ける」など
その仕事の難しさ良いことだけでなく、大変な部分も。隠すと面談で「違う」となる
文面の名義の人の仕事名義の人が何をしている人かが、企業ページで分かる

文面と企業ページで、仕事の説明が食い違うのが最も避けたいことです。文面のテンプレートの「仕事の中身」の部分と、企業ページの仕事の説明は、同じ元から作ります。テンプレートの作り方はオファー文面テンプレートを作るときの注意で書きました。

伝えること2｜一緒に働く人

学生が企業ページで知りたいのは、「どんな人と働くか」です。会社の規模や事業より、人が見えるかどうかで、承認が変わります。

  • 名義の人の紹介：何をしている人か、なぜこの会社にいるか。数行でよい
  • 配属先の若手の紹介：入社して数年の人が、いま何をしているか。学生が自分を重ねられる
  • 写真：働いている場面の写真。集合写真より、仕事をしている姿。顔が見えるもの
  • チームの様子：人数の規模感、年齢の幅、どう仕事を分けているか。数字でなく様子として

「人」の情報は、古くなります。紹介した人が異動したら、企業ページも直します。更新の担当は後述します。

いま使っている媒体の運用の相談だけでも構いません。企業ページを、学生の目線で一緒に見直します。

運用の相談をする

エージェントベストの見解

申し込んだあと、数ヶ月経った会社で起きやすいのは、「企業ページが契約時のまま、古くなっている」ことです。契約時に一度整えて、その後は文面と送信に時間を使い、企業ページを開かなくなる。紹介した若手が異動し、仕事の中身が変わり、写真の人がもういない。文面は最新でも、見に来た先が古いと、学生は「この会社は更新していない」と感じます。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、承認が落ちてきた会社の原因が、文面ではなく企業ページの古さだったことがあります。文面を直す前に、企業ページを学生の目線で開いてみる。契約時と、卒年の切り替わりと、送る山の前。この3回を更新の目安にすることを勧めます。企業ページは作って終わりではなく、文面と同じ頻度で見直すものです。

伝えること3｜会社が何をしているかの一言と、選考の流れ

会社の説明は、一言で足ります。「何を、誰に、どうやって提供している会社か」を数行で。事業の全体像や沿革は、学生がここで読むものではありません。

選考の流れは、具体的に書きます。

  1. 承認したあとに何が起きるか：まず面談、選考ではない
  2. 面談のあとの流れ：段階の数と、それぞれで何を見るか
  3. 時期の目安：承認から内定までの、おおよその期間
  4. 誰が出るか：面談は名義の人、面接は現場のマネージャー、など

選考の流れが書いてあると、学生は「承認したら何が起きるか」が分かり、承認しやすくなります。書いていないと、「承認したらいきなり選考か」と構えます。選考フローの設計は選考フローを短くする考え方で書きました。

伝えないこと

企業ページに書かないものを並べます。書くと、読まれる部分が埋もれます。

書かないものなぜ
沿革の羅列学生は読まない。会社の説明は一言で
抽象語（成長・挑戦・アットホーム・風通し）どの会社も同じ。具体的な仕事の場面に置き換える
制度や福利厚生の一覧募集要項に書く。企業ページでは、その学生に関係するものだけ
数字で押す表現数字は根拠を示せないと空回りする。様子として書く
文面と矛盾すること最も避ける。文面と企業ページは同じ元から
経営者の長い挨拶読まれない。名義の人の紹介のほうが読まれる
「求める人物像」の抽象的な列挙「主体性」「コミュニケーション力」では判断できない。行動の型で書く

抽象語の置き換えは、文面のテンプレートと同じです。「成長できる環境」と書きたくなったら、「入社して間もない〇〇さんは、いまこの仕事をしている」と、場面を1つ書きます。

作る手順

  1. 文面のテンプレートを先に固める：仕事の中身、名義の人、締め。企業ページはここから作る
  2. 仕事の中身を、テンプレートと同じ元から書く：職種ごとに、1日の流れと最初の仕事、難しさ
  3. 人の紹介を書く：名義の人、配属先の若手。本人に確認してもらう
  4. 写真を用意する：仕事をしている場面。顔が見えるもの。本人の同意を取る
  5. 会社の一言と、選考の流れを書く
  6. 抽象語を探して置き換える
  7. 学生の目線で開いてみる：文面を読んだ学生が見に来た、という前提で。別の1人にも見てもらう
  8. 更新の担当と時期を決める：契約時、卒年の切り替わり、送る山の前

7の「学生の目線で開く」を、送る前に一度やります。文面を書いた人は企業ページを見慣れているので、別の1人（できれば入社して間もない社員）に見てもらうと、古さや矛盾が見えます。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。企業ページを整える時間も含めてお伝えします。

やりがちな失敗

失敗何が起きるか直し方
会社の説明が中心で、仕事の中身が薄い文面で持った興味の続きが無い仕事の中身を最も詳しく
文面と企業ページで仕事の説明が違う「どちらが本当か」と学生が迷う同じ元から作る
人が見えない一緒に働く姿を想像できない名義の人と若手の紹介、仕事中の写真
抽象語で埋まっている他社と見分けがつかない場面に置き換える
選考の流れが無い承認したら何が起きるか分からず構える段階と誰が出るかを書く
契約時のまま更新しない古さが伝わる年3回を目安に見直す
良いことだけ書く面談で「違う」となる仕事の難しさも書く

最も多いのは、「会社の説明が中心で、仕事の中身が薄い」です。企業ページを「会社紹介」と捉えると、こうなります。「文面の続き」と捉え直します。

社内の分担

作業誰が
仕事の中身を書く人事が下書き、現場が直す（テンプレートと同じ元）
人の紹介人事が聞き取り、本人が確認
写真人事が手配、本人が同意
会社の一言、選考の流れ人事
抽象語の置き換え（場面を出す）現場
学生の目線で見る入社して間もない社員
更新人事が主担当、現場が確認

現場の負担は、「仕事の中身を直す」「場面を出す」「紹介を確認する」の3つに絞ります。書く作業は人事が担います。運用代行に出している場合、企業ページの下書きは代行が行えますが、仕事の中身と人の紹介は企業のものです。代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

自社で持つべきなのは、どこまでか。当社がOfferBoxの運用代行で企業ページの整備を手伝うとき、構成、会社の一言、選考の流れ、抽象語の置き換えの案は当社で作れますが、仕事の中身の実態、人の紹介、写真は企業にしか出せません。ここを当社が想像で書くと、文面と同じで、面談で「ページと違う」となります。逆に、仕事の中身と人が企業のものなら、当社が構成を整えても「その会社のページ」になります。企業ページで最も時間がかかるのは、現場に仕事の中身を聞き、若手に紹介を頼み、写真を撮ることです。ここは代行に出せません。その代わり、一度作れば、更新は年に数回で済みます。文面のテンプレートと企業ページを同じ打ち合わせで作ると、現場の時間は一度で済み、両方が揃います。

まとめ

  • 企業ページは「会社を説明する場」ではなく「文面で作った興味を承認まで運ぶ場」
  • 伝えるのは、文面と揃えた仕事の中身、一緒に働く人、会社の一言、選考の流れ、仕事中の写真
  • 伝えないのは、沿革、抽象語、制度の一覧、数字で押す表現、文面と矛盾すること
  • 文面のテンプレートと同じ元から作り、学生の目線で別の1人に見てもらう
  • 契約時、卒年の切り替わり、送る山の前の年3回を目安に更新する

よくある質問

企業ページに、会社の強みや実績を書かなくてよいのですか

一言で足ります。学生が企業ページで知りたいのは、仕事の中身と一緒に働く人です。強みや実績は、面談や選考で話すか、企業ページの会社の一言に含める程度にします。長く書くと、仕事の中身が埋もれます。

写真は、集合写真ではだめですか

仕事をしている場面の写真のほうが、学生には「働く姿」が伝わります。集合写真は、雰囲気は伝わりますが、仕事の中身は伝わりません。両方あるなら、仕事中の写真を先に置きます。本人の同意を取ることを忘れずに。

企業ページの整備は、御社に頼めますか

構成、会社の一言、選考の流れ、抽象語の置き換えの案は当社で作れます。仕事の中身、人の紹介、写真は企業に出していただきます。当社がOfferBoxの運用代行を受けるときは、文面のテンプレートと企業ページを同じ打ち合わせで整えます。3媒体の全体像は3媒体の違いと選び方にまとめています。
