営業職の長期インターン生の最初の1か月｜任せる仕事と育て方

営業職の長期インターン生を受け入れた会社が、最初の1か月で迷うのは「いつから商談を任せてよいか」です。早すぎると学生は断られた経験だけを持ち帰り、遅すぎると「見ているだけ」の日が続いて意欲が下がります。結論から言うと、営業職の最初の1か月は、数字を持たせる前の「聞く・記録する・準備する」を週ごとに一段ずつ任せ、1か月の終わりに次の月の担当を学生と一緒に決めると、無理なく商談に近づけます。 この記事では、1か月後に目指す状態、週ごとの組み方、担当社員の関わり方、つまずきやすい点を順に整理します。原稿の書き方は営業職の長期インターン求人原稿で書いています。

1か月後に目指す状態を先に決める

受け入れの前に、1か月が終わったときに学生がどうなっていればよいかを決めます。営業職の場合は、次の三つが目安になります。

  • 商材を自分の言葉で説明できる：お客様の困りごとと、それに対して何を提案しているかを短く話せる
  • 商談の記録を一人でまとめられる：同席した商談の議事録を、担当社員が少し直すだけで使える形にできる
  • 提案の準備の一部を担える：決まった型の資料に、お客様の情報を入れて下書きを作れる

ここで「受注を一件取る」のような数字を目指す状態に入れないことがポイントです。1か月で数字を求めると、学生は準備の段階を飛ばして話すことに向かい、何を話せばよいか分からないまま断られます。数字は、この三つがそろってから持たせます。

決めた状態は、初日に学生にも伝えます。何ができればこの月は合格なのかが分かっていると、学生は自分で進み具合を確かめられます。

1週目｜会社と商材を知り、商談に同席する

最初の週は、会社とお客様と商材を知る週です。

  • 会社の事業と、主なお客様の業界・立場を担当社員から聞く
  • 商材の説明資料を読み、分からない言葉を書き出す
  • 社員の商談に同席し、お客様が話したことをそのまま記録する
  • その日の終わりに、記録をもとに「お客様は何に困っていたか」を担当社員と話す

同席の段階では、学生に話させる必要はありません。お客様の言葉を記録することに集中してもらいます。商談のあとに「どこが分かりにくかったか」を聞くと、学生が商材のどこでつまずいているかが見えます。初日の組み方は長期インターン初日の受け入れも参考にしてください。

2週目｜記録を議事録にし、お客様の情報を整える

2週目は、同席の記録を議事録の形にまとめる練習をします。

  • 議事録の型（お客様の状況、困りごと、こちらの提案、次にやること）を渡す
  • 同席した商談ごとに議事録を作り、担当社員が赤を入れる
  • 顧客管理の表やシステムに、商談の内容を入力する
  • 既存のお客様の情報を見直し、抜けている項目を整理する

議事録の型を先に渡すと、学生は何を聞き取ればよいかが分かり、同席の質が上がります。2週目の終わりには、担当社員の直しが少しずつ減っていくはずです。減らない場合は、型のどの欄で迷っているかを一緒に確かめます。

営業職のインターン生に、どの週に何を任せるか。受け入れの組み方から相談できます。

無料で相談する

エージェントベストの見解

営業職の長期インターンで、最初の1か月のうちに離れてしまう学生が出る会社に共通するのは、「同席の段階で何を見ればよいか」を伝えていないことです。当社は掲載や応募対応だけでなく、受け入れたあとの相談も受けていますが、学生が辞める理由として多いのは、仕事が厳しいことより「何のために座っているのか分からない」ことです。同席はただ見ているだけに見えるので、目的を言葉にしないと、学生は自分が役に立っていないと感じます。勧めているのは、同席の前に「今日はお客様が何に困っているかを三つ書き出してほしい」と一つだけ課題を渡すことです。課題があると、同じ同席でも学生は手応えを持てますし、担当社員も振り返りで話すことが決まります。

3週目｜提案の準備を一部担う

3週目からは、提案の準備の一部を任せます。

  • 決まった型の提案資料に、お客様の情報や困りごとを入れて下書きを作る
  • 担当社員の商談で、学生が作った資料の一部を使ってもらう
  • 商談のあとに、資料のどこが使われ、どこが直されたかを振り返る

自分の作った資料が商談で使われる経験は、学生にとって大きな手応えになります。ここで、議事録で聞き取った困りごとと、資料の中身がつながっているかを確かめます。つながっていれば、聞く・まとめる・準備するの流れが身についてきた証拠です。

4週目｜振り返りと、次の月の担当を決める

4週目は、それまでの仕事を続けながら、1か月の振り返りをします。

  1. 初日に伝えた三つの状態のうち、どこまで届いたかを学生と一緒に確かめる
  2. 届いていない項目は、何が足りないかを具体的に話す
  3. 次の月に任せる仕事を決める。既存のお客様への定期の連絡、担当社員が同席する商談で提案の一部を話す、などから選ぶ
  4. 数字の目標を持つかどうか、持つならいつからかを話し合う

次の月の担当を学生と一緒に決めると、学生は自分の進み方に納得して続けられます。数字への不安を話す学生には、次の月も数字を持たない選択肢を残しておきます。評価の伝え方は長期インターン生の評価とフィードバックの返し方で書いています。

担当社員の関わり方

最初の1か月は、担当社員の関わり方で学生の伸び方が大きく変わります。次の三つを担当社員と決めておきます。

  • 毎日の短い振り返り：その日の同席や作業について、終わりに少しだけ話す。長い時間は要らない
  • 質問を受ける時間：「この時間なら聞いてよい」という時間帯を決める。営業の社員は外出が多く、学生が質問できずに止まることがある
  • 商談のあとの一言：同席のあと、移動中や通話を切ったあとに「今の商談で一番大事だったのはどこか」を話す

担当社員の負担が重いときは、議事録の確認を別の社員と分けるなど、役割を分けます。1on1の進め方は長期インターン生との1on1を参考にしてください。

つまずきやすい点

営業職の最初の1か月で、よく起きるつまずきは次のとおりです。

  • 人手が足りない日に、準備のないまま電話や商談を任せてしまう
  • 同席はさせているが、振り返りの時間が取れず、学生が何を学んだか分からない
  • 商談の予定に合わせて勤務の日時を何度も変え、学生の授業の予定とぶつかる
  • 試験期間に勤務が減ることを想定しておらず、担当の仕事が止まる

勤務の日時を変えるときは、学生の授業を優先する前提で相談します。インターン生の労働時間や学業への配慮には、法令で定められた項目や指針があります。勤務の組み方が契約の内容と合っているかは、社労士や公式の案内で確認しておきます。

受け入れたあとの組み方で迷ったときも、Infraの代理店として相談を受けています。いまの状況の整理だけでも構いません。

運用の相談をする

エージェントベストの見解

営業職の受け入れを始める前に、先に決めておきたいのは「学生に見せてよい商談」の線引きです。これを決めないまま始めると、担当社員はその日の商談ごとに同席させるか迷い、結果として同席の機会が減ります。お客様との関係が深い商談、条件の交渉が中心の商談、社外に出せない情報が多い商談は外す。初回の訪問や定期の連絡、提案の説明が中心の商談は同席させる。こうした線引きを先に一覧にしておくと、1週目から同席の予定を組めます。当社は人材紹介で営業職の中途採用にも関わっていますが、入社後に伸びる営業担当は、早い時期に多くの商談を見ている人が多い印象です。学生も同じで、最初の1か月に見られる商談の数が、その後の伸び方を左右します。情報の扱いのルールは長期インターン生の情報管理で整理しています。

まとめ

  • 1か月後の状態は「商材を説明できる・記録をまとめられる・準備の一部を担える」で決め、数字は入れない
  • 1週目は同席と記録、2週目は議事録、3週目は提案の準備と、週ごとに一段ずつ広げる
  • 4週目に振り返り、次の月の担当と数字を持つかどうかを学生と一緒に決める
  • 担当社員は毎日の短い振り返り、質問の時間、商談のあとの一言を持つ
  • 勤務の日時は授業を優先して組み、法令に関わる点は社労士や公式の案内で確認する

よくある質問

1か月で商談を任せるのは早すぎますか

学生によりますが、一人で商談を進めるのは早いことが多いです。1か月の時点では、担当社員が同席する商談で提案の一部を話す程度にとどめ、一人で進めるのは記録と準備が安定してからにすることを勧めます。

担当社員が外出ばかりで、学生を見る時間がありません

同席を中心に組めば、外出の時間そのものが育成の時間になります。オンラインの商談に同席してもらう、移動中に振り返りをするなど、担当社員の予定に学生の仕事を重ねる組み方を考えます。それでも難しい場合は、育成に時間をかけられないときも参考にしてください。

1か月たっても議事録がうまくまとまりません

型のどの欄で迷っているかを確かめます。困りごとの欄が埋まらないなら、商談中に聞き取れていない可能性があります。同席の前に聞き取ることを一つ決めて渡し、それだけを書く練習から戻ると、少しずつまとまるようになります。
