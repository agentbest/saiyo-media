長期インターンの給与の決め方｜考える順番

Infra・長期インターン課題別 更新日 2026/10/16

長期インターンの募集を出すとき、多くの会社が迷うのが給与の決め方です。「他社はいくらにしているのか」「高くすれば応募が増えるのか」と、相場から考え始めることが多いでしょう。結論として、長期インターンの給与は、相場から決めるのではなく「法令の下限」「任せる仕事」「比べられ方」「上げ方」「社内の釣り合い」の順に考えると、説明のつく金額に落ち着きます。 相場だけで決めると、任せる仕事と給与がかみ合わず、社内でも学生にも説明しにくくなります。この記事では具体的な金額には触れず、決め方の順番を整理します。

症状を確認する｜給与で起きている問題

給与の決め方に迷っている会社では、次のような問題が起きていることがあります。

  • 応募が少ない：給与の条件が、比べられる他の募集の中で目立たない
  • 応募はあるが、仕事との釣り合いがとれていない：任せたい仕事に対して給与が低い、または高い
  • 長く働いても給与が変わらない：昇給の仕組みがなく、続ける理由が薄れる
  • 社内の他の雇用との差が気になる：アルバイトや契約社員との差を説明できない

どの問題に当たるかで、見直すところが変わります。応募が少ないからといって、給与だけを上げても解決しないこともあります。応募が来ないときの見直しの順番はInfraで応募が来ないときの見直し順でも整理しています。

考える順番

1. 法令の下限を確かめる

最初に確かめるのは、守るべき法令の下限です。長期インターン生と雇用契約を結ぶ場合、学生であっても最低賃金や労働時間の規定を守る必要があります。最低賃金は地域や時期によって変わるため、募集を出す時点で確認してください。判断に迷う場合は、社会保険労務士などの専門家に確認しておくと安心です。

2. 任せる仕事の中身から考える

次に、任せる仕事の中身から考えます。

  • 手順どおりに進める作業が中心か
  • 判断が入る作業や、専門的な技能が要る作業があるか
  • 成果に対して、どれくらいの責任を持ってもらうか

専門的な技能が要る仕事、たとえばプログラミングやデザインなどは、一般的な事務の作業と比べて給与を高く設定することが多いです。仕事の中身と給与がかみ合っていると、学生にも社内にも説明しやすくなります。

3. 比べられ方を意識する

学生は、複数の長期インターンの募集を並べて比べています。給与の条件は、その中で見られる項目の一つです。

  • 給与の書き方が分かりやすいか（時給なのか、月給なのか、成果に応じた部分があるのか）
  • 交通費の扱いが書かれているか
  • 昇給の可能性が書かれているか

金額そのものより、書き方の分かりやすさで印象が変わることもあります。

任せる仕事に見合った給与の考え方と、募集での書き方を一緒に整理します。金額の決め方に迷っている段階からご相談ください。

無料で相談する

エージェントベストの見解

給与の決め方について相談を受けたとき、当社がよく見るのは、給与を上げることで応募を増やそうとする考え方です。給与が条件として見られていることは確かですが、学生が長期インターンを選ぶ理由は給与だけではありません。任せてもらえる仕事、一緒に働く人、身につく経験。これらが募集に書かれていないまま給与だけを上げても、応募は思ったほど増えないことがあります。当社が勧めるのは、給与を決めるのと同じだけの時間を、任せる仕事の書き方に使うことです。給与は比べられる項目の一つにすぎず、仕事の中身が伝わっていなければ、給与で選んだ学生が集まり、仕事に合わずに辞めていくこともあります。給与は仕事の中身と一緒に見せることで、初めて意味を持ちます。

4. 上げ方を決めておく

給与を決めるときは、最初の金額だけでなく、上げ方も決めておきます。

  • 勤務の期間に応じて上げるのか
  • 任せる仕事の段階が上がったときに上げるのか
  • 成果に応じて上げるのか

長期インターンは数か月から一年以上続くこともあり、その間に任せる仕事は広がっていきます。仕事が広がっても給与が変わらないと、続ける理由が薄れます。上げ方を最初に決め、募集にも書いておくと、長く働く学生にとっての励みになります。

5. 社内の他の雇用との釣り合いを見る

最後に、社内の他の雇用との釣り合いを確かめます。

  • アルバイトやパートの給与と比べて、説明できる差になっているか
  • 新卒の社員の初任給と比べて、無理のない設定か
  • 部署によって給与を変える場合、その理由を説明できるか

社内の他の雇用との差は、インターン生同士や社員の間で話題になることがあります。差がある場合は、その理由を仕事の中身で説明できるようにしておきます。

給与以外の条件も合わせて考える

給与と合わせて、次の条件も整理しておきます。

  • 交通費：支給するかどうか、上限を設けるか
  • リモート勤務の扱い：通信費などの扱いをどうするか
  • 勤務時間の記録：給与の計算の基になる時間の記録の方法

これらの条件は、給与と同じくらい学生が気にする項目です。曖昧なまま受け入れると、後から問題になることがあります。

エージェントベストの見解

当社はInfraの代理店として求人原稿を作るとき、給与の欄に「昇給の条件」を書くことを勧めています。長期インターンの募集の多くは、最初の給与だけが書かれていて、その後どうなるかが書かれていません。「任せる仕事の範囲が広がったら見直す」「数か月ごとに面談で見直す」と一行あるだけで、学生は長く働くことを前提に応募を考えられます。昇給の条件を書くことは、会社の側が「長く働いてほしい」と考えていることを示すことにもなります。最初の金額で他社と比べられたとき、少し見劣りしても、上がり方が見えている募集のほうが選ばれることもあります。給与は最初の金額だけでなく、時間の流れの中で見せることを勧めます。

給与の条件を募集にどう書くか

給与を決めたら、募集の文面にどう書くかも考えます。同じ金額でも、書き方で学生の受け止め方は変わります。

  1. 計算の方法を明記する：時給なのか、日給なのか、月ごとの金額なのか
  2. 金額の幅がある場合は理由を書く：経験や任せる仕事によって変わる場合は、その基準を書く
  3. 交通費の扱いを書く：支給するかどうか、上限があるかどうか
  4. 見直しの機会を書く：いつ、どんな条件で給与を見直すか
  5. 試用の期間の扱いを書く：最初の期間に条件が異なる場合は、それも書いておく

書かれていない条件は、学生が面接で聞きにくい項目でもあります。聞けないまま入社し、あとで知って不満に思うことを防ぐためにも、条件は募集の段階で書いておきます。書いた内容は、契約の書面と一致させてください。

決めた給与を募集でどう見せるか、仕事の中身とあわせて原稿づくりから一緒に考えます。

まとめ

  • 長期インターンの給与は、相場からではなく考える順番に沿って決める
  • 最初に法令の下限を確かめ、迷ったら専門家に確認する
  • 任せる仕事の中身から給与を考え、仕事と給与をかみ合わせる
  • 最初の金額だけでなく、上げ方を決めて募集に書く

よくある質問

他社の長期インターンの給与を参考にしてもよいですか

参考にすることはできますが、他社と同じ金額にすることが正解とは限りません。任せる仕事の中身や、社内の他の雇用との釣り合いによって、適した金額は変わります。他社の金額は、比べられたときにどう見えるかの目安として使ってください。

成果報酬の形にしてもよいですか

成果に応じた部分を設けることは考えられますが、雇用契約を結ぶ場合は、最低賃金を下回らないことが前提です。成果報酬の設計は労務の面で注意が必要なため、社会保険労務士などの専門家に確認してから決めてください。

給与を払わない長期インターンは可能ですか

働き方の実態が雇用にあたる場合は、給与を払う必要があります。実態の判断は個別の状況によって変わるため、無給の形を考えている場合は、専門家に確認することを勧めます。契約まわりの確認事項は長期インターンの雇用契約と労働時間でも整理しています。
