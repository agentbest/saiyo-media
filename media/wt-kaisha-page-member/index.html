会社ページに載せるメンバーを、どう選ぶか。「全員を載せるべきか」「経歴が立派な人を載せるべきか」という質問を受けます。結論から言うと、載せるのは「候補者が自分を重ねられる人」で、経歴の立派さではありません。最初は代表と、話を聞きに来た候補者が最初に会う人の2人で公開し、次に配属先の若手、候補者に近い人を足します。全員を載せる必要はなく、載せる人は本人の同意を取り、紹介文は経歴の羅列ではなく「なぜこの会社に・いま何を・大変なこと」で書きます。 この記事では、メンバーの位置づけ、最初に載せる人、次に足す人、選ぶ軸、紹介文の型、同意と個人情報、更新、やりがちな失敗、分担を整理します。会社ページ全体は会社ページで最初に書くことで書きました。

この作業の目的｜候補者に「一緒に働く人」を見せる

Wantedlyで候補者が会社ページを読むとき、最も知りたいのは「どんな人と働くか」です。事業の説明やミッションの言葉より、人が見えるかどうかで、「話を聞きに行きたい」が決まります。

メンバーの紹介の目的は、会社の人を全員見せることではなく、候補者が「自分がここで働いたら、この人たちと一緒か」を想像できるようにすることです。想像できれば、話を聞きに来ます。想像できなければ、来ません。

想像できるのは、候補者が自分を重ねられる人です。年齢が近い、前職や学生時代が似ている、同じ職種、同じ悩みを持っていた。そういう人が、なぜこの会社に来て、いま何をしていて、何が大変かを語っていると、候補者は自分を重ねます。

手順1｜最初に載せる2人

最初の公開で載せるのは、2人で足ります。

誰なぜ
代表「なぜやるのか」を語った人。ミッションの場面の主。ミッションの書き方は会社ページでミッションを伝える書き方
話を聞きに来た候補者が、最初に会う人候補者が「この人と話すのか」と分かる。会社ページで読んだ人と、実際に会う人が一致する

2人目が要点です。会社ページで読んだ人と、実際に会う人が違うと、候補者は「ページの人はどこに」と感じます。OfferBoxの文面で「名義の人が面談に出る」と書いたのと同じ考え方です。名義の考え方はオファー文面の基本で書きました。

この2人が揃えば、会社ページは公開できます。他のメンバーは、公開の翌週から足します。

手順2｜次に足す人

公開したあと、順に足していきます。

  1. 配属先の若手：入社して数年の人。候補者に最も近く、「入社後の自分」を想像させる
  2. 募集している職種の人：募集記事から会社ページに来た候補者が、同じ職種の人を探す
  3. 候補者に近い前職や経歴の人：中途なら前職、新卒なら学生時代の経験が近い人。「自分と同じ道から来た人がいる」
  4. 異なる年代や職種の人を1人か2人：会社の幅が見える。ただし多くしすぎない
  5. バリューの実例に出た人：バリューの場面で動いた人が紹介にいると、バリューと人がつながる。バリューの書き方は会社ページでバリューを言葉にする方法

「全員」を目指さないことも大事です。全員を載せると、候補者は誰を見ればいいか分からず、紹介の質も薄くなります。候補者が重ねられる人が数人いれば足ります。

いま使っている媒体の運用の相談だけでも構いません。会社ページに誰を載せるか、候補者の目線で一緒に選びます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「経歴が立派な人を載せると、会社の格が上がって候補者が来る」というものです。実際には、候補者は会社の格ではなく、「自分がここで働けるか」を見ています。当社は3媒体すべての販売パートナーとしてWantedlyの契約後の運用を見ていますが、有名企業出身の役員だけが並んでいる会社ページより、入社して数年の若手が「なぜここに来て、いま何をしていて、何が大変か」を語っている会社ページのほうが、候補者が話を聞きに来ています。経歴が立派な人の紹介は、候補者に「自分とは違う」と読まれ、重ねる対象になりません。載せるかどうかの軸は、経歴ではなく、候補者が自分を重ねられるかです。役員を載せるなら、経歴ではなく「なぜこの会社に来たか」を書く。それだけで、重ねられる紹介になります。

手順3｜選ぶ軸

載せる人を選ぶ軸を、3つに絞ります。

軸確かめ方
候補者が自分を重ねられるか募集している職種、年代、前職や学生時代が、候補者に近いか
仕事を語れるか「昨日1日、何をしたか」「何が大変か」を、自分の言葉で言えるか。言えない人の紹介は薄くなる
本人が同意しているか名前、写真、紹介文を載せることに同意しているか。断られたら載せない

3つ目の「同意」は、軸というより前提です。同意なしに載せると、本人が後で知って不信を持ち、社内の空気が悪くなります。載せる前に、紹介文と写真を本人に見せて「これでよいか」を聞きます。この点は、OfferBoxの企業ページで書いたのと同じです。企業ページで伝えることで書きました。

手順4｜紹介文の型

紹介文は、経歴の羅列にしません。候補者が知りたいのは経歴ではなく、「なぜこの会社に・いま何を・大変なこと」です。

  1. 名前と、いまの仕事を一言：「〇〇。△△の仕事をしている」
  2. なぜこの会社に来たか：前職や学生時代に何があって、何を見て決めたか。場面で
  3. いま何をしているか：昨日1日の流れ、いま関わっていること。具体的に
  4. 大変なこと：隠さない。「〇〇が難しい」「△△でよく詰まる」。候補者は、大変なことが書いてある紹介を信じる
  5. 候補者へ一言：「〇〇な人と一緒に働きたい」。バリューの動き方につながる言葉があれば

「大変なこと」を書くのは、紹介文で最も抵抗があり、最も効く部分です。良いことだけの紹介は建前に読まれ、大変なことが1つある紹介は本音に読まれます。

紹介文は、人事が本人に聞いて書き、本人に直してもらいます。本人に書いてもらうと、経歴の羅列か、謙遜だけになりがちです。「聞いて書いて、直してもらう」が、紹介文の作り方です。

手順5｜同意、個人情報、更新

載せるときの決め事です。

  • 同意は、紹介文と写真を見せてから取る：「載せてよいか」だけでなく、「この内容でよいか」
  • 写真は仕事中の場面で：集合写真より、働いている姿。顔が見えるもの。本人が嫌なら顔を出さない形も可
  • 個人が特定される情報は、本人が望む範囲で：出身校、前職の社名、年齢。本人が出したくないものは出さない
  • 異動や退職のときに差し替える：紹介した人がいなくなった会社ページは、候補者に古さが伝わる。差し替えの担当と時期を決める
  • 紹介文の「いま何をしているか」は、数ヶ月に一度見直す：仕事が変わっていれば直す

「差し替え」が、見落とされやすい点です。作って半年後に、紹介した若手が異動している。候補者が面談で「〇〇さんは」と聞き、「異動しました」と答える。この状態は、会社ページの信頼を落とします。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。メンバーの紹介を聞いて書く時間と、更新の時間を分けてお伝えします。

媒体選びを相談する

やりがちな失敗

失敗何が起きるか直し方
全員を載せようとして公開が遅れる候補者に届く時期が遅れる2人で公開し、翌週から足す
経歴が立派な人だけを載せる候補者が自分を重ねられない配属先の若手、候補者に近い人を
会社ページの人と、実際に会う人が違う「ページの人はどこに」最初に会う人を載せる
紹介文が経歴の羅列人が見えないなぜ来たか・いま何を・大変なこと
良いことだけの紹介建前に読まれる大変なことを1つ
本人に書いてもらう羅列か謙遜になる聞いて書いて、直してもらう
同意を取らずに載せる本人が不信を持つ内容を見せてから同意
異動した人が残っている古さが伝わる差し替えの担当と時期を決める

最も多いのは、「全員を載せようとして公開が遅れる」と「紹介文が経歴の羅列」です。前者は速さ、後者は質を止めます。

社内の分担

作業誰が
載せる人を選ぶ人事（募集している職種と候補者の像から）
本人に載せてよいか聞く人事（上司を通してもよい）
紹介文の材料を聞く人事（本人に「なぜ来たか」「昨日1日」「大変なこと」を聞く）
紹介文を書く人事
本人が直し、同意する本人
写真の手配と同意人事と本人
差し替えと見直し人事（異動と退職の情報を受けて）

本人の負担は、「聞かれて答える」「直す」「写真に写る」の3つです。書くのは人事です。運用代行や代理店が支えられるのは、紹介文の型と、聞く質問の用意、書いた紹介文の整理までで、本人に聞くことと同意は企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これをやる前に、先に決めておかないとメンバーの紹介が機能しないことがあります。「話を聞きに来た候補者が、最初に会う人」を決めることです。当社がWantedlyの運用の相談で会社ページを見るとき、メンバーの紹介は充実しているのに、実際に候補者と会うのは紹介にいない人事、という会社があります。候補者は、会社ページで読んだ人と会えると思って来て、違う人が出てくると「読んだ人はどこに」と感じます。当社が勧めるのは、載せる人を選ぶ前に、「話を聞きに来た候補者に、最初に誰が会うか」を決め、その人を必ずしも代表でなくてよいので2人目として載せることです。会う人が決まれば、載せる人も決まり、面談の名義も決まります。会社ページのメンバーと、面談に出る人の一致は、Wantedlyの入口で最初に揃えることです。

まとめ

  • 載せるのは、候補者が自分を重ねられる人。経歴の立派さではない
  • 最初は代表と「最初に会う人」の2人で公開し、配属先の若手、募集職種の人、候補者に近い人を翌週から足す。全員は要らない
  • 紹介文は「なぜこの会社に・いま何を・大変なこと」。聞いて書いて、本人に直してもらう
  • 同意は、紹介文と写真を見せてから取る。個人が特定される情報は本人が望む範囲で
  • 異動と退職で差し替え、「いま何を」は数ヶ月に一度見直す

よくある質問

社員が少なく、載せられる人がいません

代表と、最初に会う人の2人で公開できます。2人が同じ人（代表が面談に出る）なら、代表1人でも構いません。その場合、代表の紹介文を「なぜこの事業を・いま何を・大変なこと」で書き、ミッションの場面とつなげます。人数より、その人が語れているかです。

本人が「載せたくない」と言います

載せません。同意の無い紹介は、本人の不信と社内の空気の悪化につながります。顔を出さない形、名前を出さない形（「営業の1人」）で載せられるかを聞き、それも望まないなら、別の人を選びます。

メンバーの紹介文は、御社に頼めますか

型と、本人に聞く質問と、聞いた内容の整理は当社が行えます。本人に聞くことと、同意を取ることは、企業の人事にお願いしています。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、Wantedlyの会社ページの整備を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

あわせて読む

  • Wantedlyの会社ページの写真の選び方｜仕事中の場面を、本人の同意で、作り込まずに
  • Wantedlyの会社ページで最初に書くこと｜「なにを・なぜ・どうやって」を、代表の言葉で、完璧を目指さず
