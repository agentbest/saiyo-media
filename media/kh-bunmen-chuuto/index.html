中途の相手にスカウトを送る。「〇〇社で△△職を□年ご経験と拝見し」と、経歴の事実を並べる。相手には、「検索条件で送ってきた」と読まれます。経歴の事実は、相手が自分で書いた「見出し」で、読まなくても拾えるからです。結論から言うと、中途向けの文面は、経歴の「事実」ではなく「いま、どう仕事を進めているか」を読み、「入ったら何が変わるか」と重ね、在職中の相手が返信できる形で「話す場」に誘う四段の型で書きます。「転職をお考えなら」で始めません。在職中の相手には、時間帯と秘密と急がせないことに配慮します。経験者と未経験転職で、重ねる場所を変えます。三つの媒体で、骨組みは同じです。 この記事では、経歴の事実が届かない理由、読む箇所、四段の型、在職中への配慮、経験者と未経験転職、避ける言葉、媒体ごとの違い、分担を整理します。文面全体の骨組みはスカウト文面の基本構成、Wantedlyでの中途向けはWantedlyで中途にスカウトを送るときの考え方で書きました。新卒向けは新卒向けスカウト文面の型で書きました。

この作業の目的｜「自分の仕事を分かっている人からの連絡」にする

中途の相手は、いま仕事をしています。その仕事を「分かっている人」からの連絡には返信し、「社名と職種だけを見た人」からの連絡には返信しません。

目的は、相手のいまの仕事の「進め方」を読み、それを自社での仕事と重ねて、「この会社は自分の仕事を分かっている」と相手が感じる文面にすることです。

経歴の「事実」を並べても、届かない理由

書き方相手が受け取ること
「〇〇社で△△職を□年ご経験と拝見し」検索条件の言い換え。読んでいない
「豊富なご経験をお持ちの方に」誰にでも書ける
「〇〇のスキルをお持ちの方を探しております」求人票の要件。自分宛ではない
「転職をお考えでしたら」考えていないかもしれない。決めつけ
「キャリアアップのチャンス」「年収アップ」会社の側の売り文句

共通するのは、相手が「書いた事実」だけを拾い、「どう進めているか」「なぜそうしているか」を読んでいないことです。事実は見出しで、進め方は本文です。

中途のプロフィールで、読む箇所

  • いまの仕事の進め方：「〇〇を、△△の順で進めている」「□□で詰まったとき、✕✕した」。経歴の中の、動詞の部分
  • 「なぜ」：「なぜその仕事を選んだか」「なぜその進め方をしているか」。Wantedlyならストーリーに、他の媒体なら自由記述に
  • 自分で決めて動いた場面：「提案して変えた」「一人で立ち上げた」「やり方を変えた」
  • 読まない箇所：社名、職種名、年数、資格の一覧。これは見出し
  • 拾うのは、進め方を一つ：「条件を変えて試す」「人を巻き込む」「自分で設計から実装まで」

中途のプロフィールの読み方はWantedlyで中途にスカウトを送るときの考え方の「中途のプロフィールで、読む箇所」で書きました。

いま使っている媒体の運用の相談だけでも構いません。いまの中途向けの文面が、経歴の事実だけを拾っていないかを一緒に見ます。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「中途は経歴が全てなので、経歴に触れれば『読んだ』と伝わる」というものです。当社は3媒体すべての販売パートナーとして、三つの媒体の中途向けの文面を見ていますが、「〇〇社で△△職を□年」と経歴の事実に触れた文面は、相手に「検索条件で送ってきた」と読まれ、返信が来ていません。相手にとって、社名と職種と年数は、自分で書いた見出しで、それを繰り返されても「読んだ」にはなりません。逆に、「□□で詰まったとき、✕✕したと書かれていて」と、経歴の中の進め方に触れた文面は、「自分の仕事を分かっている人からの連絡」として、返信が来ています。当社が中途向けの文面の相談を受けるとき、最初にやるのは、経歴の事実を文面から抜いて、進め方を一つ拾うことです。

四段の型

段書くこと例
1. いまの仕事の進め方を読んだ一文経歴の中の「どう進めているか」を一つ、相手の言葉のまま「〇〇の案件で、△△の順で進め、□□で詰まったときに✕✕したと書かれているのを拝見しました」
2. 「入ったら何が変わるか」との重なり自社での仕事の進め方を場面で書き、1と重ねる。変わる点も書く「うちの〇〇の仕事も、△△の順で進めます。違うのは、□□を一人で決められる範囲が広いことです。近いと思いました」
3. 選考で何を見るかの一文相手が準備できる形で「選考では、いまの仕事でどう進めているかの話を聞きます。志望動機は聞きません」
4. 在職中でも返信できる「話す場」誰と、どんな形で、選考ではないこと、時間帯の配慮「選考ではなく、この文面を書いた私と、オンラインで短い時間、仕事の話をする場です。就業後や昼休みでも構いません。一言だけご返信ください」

中途の「2」は、新卒と違い、「重なり」だけでなく「変わる点」も書きます。相手は、いまの仕事と同じことをするために転職しません。「同じ進め方で、ここが変わる」が、中途の重なりです。

在職中の相手への、配慮

  • 時間帯：面談の候補を、就業時間外や昼休みに。「就業後や昼休みでも構いません」を締めに
  • 秘密：「現職に知られない形で進めます」を一文。面談の場所と形（オンライン）
  • 急がせない：「今すぐ転職をお考えでなくても」「時期はご都合に合わせます」。在職中の相手は、決断に時間が要る
  • 「転職をお考えなら」で始めない：考えていない相手にも、「話す場」は開いている
  • 返信がなくても、追わない：在職中の相手に繰り返し送ると、現職での立場に関わることがある

配慮の詳しくはWantedlyで中途にスカウトを送るときの考え方の「在職中の人への配慮」で書きました。

経験者と、未経験転職で変える点

変える点経験者（同じ職種）未経験転職（違う職種）
1で読むものいまの仕事の進め方いまの仕事の中の、転職先で使える進め方（「人を巻き込む」「条件を変えて試す」）
2の重なり進め方の重なりと、変わる点進め方の種類の重なり。職種が違っても、行動の種類で重ねる
3の何を見るかいまの仕事の進め方いまの仕事で自分で決めて動いた場面
避けること「即戦力」（経験者でも、相手の側が判断すること）「未経験でも歓迎」だけで終えない。何が使えるかを書く

未経験転職の相手に、「未経験歓迎」だけを書くと、「誰でもいい」と読まれます。「いまの仕事の〇〇の進め方は、うちの△△でそのまま使えます」が、未経験転職の「なぜあなたに」です。重ね方はスカウトで「なぜあなたに」を書く方法の「重なりの、見つけ方」で書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。中途向けの四段の型を作り、進め方を読んで書く場合の一通あたりの時間をお伝えします。

媒体選びを相談する

避ける言葉

  • 「ご経歴を拝見し」「豊富なご経験」：見出しの引用と持ち上げ
  • 「即戦力」「ご活躍を期待」：相手の側が判断すること
  • 「転職をお考えなら」「転職市場で」：決めつけ
  • 「キャリアアップ」「年収アップ」「待遇改善」：会社の側の売り文句。条件は隠さないが、文面の中心にしない
  • 「志望動機」：会社から声をかけているのに、動機を問う
  • 「〇〇のスキルをお持ちの方を探しております」：求人票の要件
  • 「至急」「早急に」「枠が」：在職中の相手を急がせる

媒体読む場所誘う場

OfferBox新卒向けの媒体で、中途は主な対象ではない。使う場合は媒体の現在の仕様で確認—

社内の分担

作業誰が
経歴の事実を文面から抜く人事
いまの仕事の進め方を一つ拾う送る人
自社の仕事の進め方と「変わる点」を話すその職種の現場の人
「選考で何を見るか」を決める面接官と人事
四段の型を作り、1と2を相手ごとに埋める人事と送る人
在職中の相手の時間帯に合わせて面談に出る現場の人か名義の人

運用代行や代理店が支えられるのは、四段の型、中途のプロフィールの読み方の型、経験者と未経験転職の分け方、在職中への配慮の型までで、進め方を拾うこと、自社の進め方を話すこと、送ること、面談に出ることは企業が行います。代理店の代行の範囲は代理店に運用まで頼めるかで書きました。

エージェントベストの見解

これは向き不向きの話です。中途向けのスカウトに向いているのは、「自社の仕事の進め方を、現場の人が場面で言える」会社で、向いていないのは、「要件（職種・年数・スキル）は言えるが、進め方は言えない」会社です。後者は、文面が求人票の要件になり、相手に「検索条件で送ってきた」と読まれます。当社が中途向けの文面の相談を受けるとき、最初に確かめるのは、「この仕事を、どう進めていますか。入った人は、いまの仕事と何が変わりますか」を、現場の人が言えるかです。言えれば、四段の「2」が埋まり、文面は「自分の仕事を分かっている人からの連絡」になります。言えなければ、文面の前に、現場に聞く時間を取ります。

まとめ

  • 経歴の事実（社名・職種・年数）は相手が書いた見出しで、拾っても「読んだ」にならない。読むのは「いま、どう仕事を進めているか」と「なぜ」
  • 四段の型は、進め方を読んだ一文→「入ったら何が変わるか」との重なり（重なりと変わる点の両方）→選考で何を見るかの一文→在職中でも返信できる「話す場」
  • 在職中の相手には、時間帯・秘密・急がせない、の配慮を締めに。「転職をお考えなら」で始めず、返信がなくても追わない
  • 経験者は進め方の重なりと変わる点、未経験転職は行動の種類で重ね、「未経験歓迎」だけで終えない
  • 中途向けの主な場はWantedly。他の媒体で扱う場合は現在の仕様と対象を確認

よくある質問

相手のプロフィールに、経歴の事実しか書かれていません

事実の中に、動詞を探します。「〇〇を担当」の「担当」の中身、「△△を立ち上げ」「□□を改善」の場面。それでも進め方が読めなければ、後回しにして、進め方が書かれている相手から送ります。どうしても送るなら、「〇〇を立ち上げられたと拝見し、その進め方をお聞きしてみたいと思いました」と、聞きたいことを正直に書き、無理に読んだふりをしません。

在職中の相手に、条件をどう伝えればよいですか

文面の中心にはせず、隠しもしません。締めに「条件は面談でお伝えします」と書き、面談で事実として伝えます。「年収アップ」を文面の売り文句にすると、条件で来る相手が集まり、進め方の重なりで来る相手が減ります。条件の伝え方は待遇を強みにできない会社のWantedlyの伝え方で書きました。

中途向けスカウト文面の型は、御社に相談できますか

できます。当社は、四段の型、中途のプロフィールの読み方の型、経験者と未経験転職の分け方、在職中への配慮の型を支えられます。進め方を拾うこと、自社の進め方を話すこと、送ること、面談に出ることは、企業が行ってください。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、3媒体の運用を支えています。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

媒体選びを相談する

あわせて読む

  • 文系学生向けスカウト文面の型｜職種名から仕事を想像できない学生に、「最初の月に何をするか」を場面で先に見せ、学生時代の行動の型（始めた・続けた・巻き込んだ）と重ねる四段の型。「文系でも」と書かない
  • 営業向けスカウト文面の型｜「営業経験」ではなく「何を、誰に、どう売っていたか」を読み、自社の「売り方と決め方」と重ね、営業の人の名義で「話す場」に誘う四段の型
  • エンジニア向けスカウト文面の型｜技術名の羅列ではなく「何を、どう作ったか」を読み、自社の開発の「進め方と決め方」と重ね、送り主はエンジニアに
  • 理系学生向けスカウト文面の型｜研究テーマではなく「研究の進め方」を読み、自社の仕事の進め方と重ね、研究職以外に誘うときも研究を無視しない四段の型。社内に研究を読める人がいなくても、進め方なら読める
