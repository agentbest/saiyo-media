ワンキャリアのイベントに登壇する社員の選び方

ワンキャリア運用の深掘り 更新日 2026/11/4

ワンキャリアのイベントで、前に立って話す社員を誰にするか。多くの会社は、話が上手な人や、社内で目立つ人に頼みます。ところが、学生は体験談を読んで「実際はどうか」を確かめに来ています。話が上手でも、学生の知りたいことに自分の経験で答えられなければ、回のあとに残るものは少なくなります。結論から言うと、登壇する社員は「話がうまいか」ではなく、「その回で確かめてもらうことに、自分の経験で答えられるか」で選びます。回の目的から話す内容を決め、内容に合う人を選び、一人で足りなければ立場の違う二人を組み合わせます。 この記事では、話す内容からの逆算、組み合わせ方、頼み方と話してよい範囲、話す練習、断られたときの考え方を整理します。イベントに出る社員全体の選び方はイベントに出る社員の選び方で書きました。

この作業の目的｜学生が「確かめられた」と思える話し手を置く

イベントの登壇は、会社の紹介をする場ではありません。ワンキャリアの学生にとっては、体験談で読んだことや、企業ページで気になったことを、社員の口から確かめる場です。

目的は、回のあとに学生が「聞きたかったことが聞けた」「書いてあったとおりだった」と思える話し手を置くことです。その話し手が誰かは、回の目的によって変わります。

話す内容から逆算する

登壇する人を先に決めると、その人が話せることに回の中身が引っ張られます。順番を逆にして、話す内容から決めます。

  1. 回の目的を一文にする：「入社後の最初の一年が分かる回」など
  2. 学生が確かめたいことを三つ書き出す：体験談と、説明会で出た質問から
  3. 三つに、自分の経験で答えられる人を探す：役職ではなく経験で
  4. その人が話せる具体の場面を一つ聞いておく：最初に任された仕事、つまずいたこと
回の目的答えられる人の例
最初の一年の仕事入社して数年以内の社員
選考で何を見ているか面接に出ている社員
仕事の進め方や職種の中身その職種の中堅社員
会社の方向事業の責任者、経営者

回の目的に合う登壇者の選び方を、一緒に整理します。いま使っている媒体の運用の相談だけでも構いません。

運用の相談をする

組み合わせ方｜立場の違う二人にする

一人の登壇者で回の目的に答えきれないときは、二人を組み合わせます。組み合わせるときは、立場を変えます。

  • 入社年次の違う二人：最初の一年を話す若手と、その先の道筋を話す中堅
  • 職種の違う二人：同じ事業の中で、別の役割を担っている人
  • 話す人と答える人：一人が話し、もう一人が質問に答える役に回る

同じ立場の二人を並べると、話が重なります。立場が違うと、学生は一つの会社を二つの角度から見られます。人数を増やしすぎると、一人ひとりの話が浅くなるので、多くても二人か三人にとどめます。

エージェントベストの見解

相談で最も多い思い込みは、「登壇は、会社の顔になる人に頼むべきだ」というものです。役職の高い人や、社内で評判の良い人が前に立てば、学生の印象が良くなると考えがちです。しかし、体験談を読んで来るワンキャリアの学生が確かめたいのは、多くの場合、入社してから最初に何が起きるかです。それに自分の経験で答えられるのは、役職の高い人より、入社して数年以内の社員であることが多い。当社が勧めるのは、会社の顔になる人は回の最初か最後に短く出てもらい、本題は最初の一年を話せる若手に任せる形です。会社の方向を話す人と、最初の一年を話す人が両方いると、学生は入社後の自分を具体的に想像できます。

頼み方と、話してよい範囲

登壇を頼むときは、負担を見える形にしてから頼みます。

  1. 上司の合意を先に取る：業務の時間として登壇してもらう
  2. 頼むことを絞る：話す内容の柱を二つか三つ、質問に答えること、回のあとに一言戻すこと
  3. 話す内容の柱を一緒に決める：本人の経験の中から、場面を一つずつ選ぶ
  4. 話してよい範囲を一枚で渡す：話してよいこと、人事に回す質問
話してよいこと人事に回す質問
自分が担当した仕事と、その場面選考の合否や評価の基準の詳細
入社前に思っていたことと、入ってからの違い給与や制度の細かい条件
働く中で難しかったことほかの社員の個人的なこと
一日の過ごし方まだ決まっていない会社の方針

「難しかったこと」を話してよいと伝えておくのは大切です。良いことだけを話すと、体験談を読んで来た学生には、かえって作られた話に聞こえます。

社員に登壇を頼むときの一枚や、イベントの組み立てを一緒に考えます。相談だけでも構いません。申込前提ではありません。

無料で相談する

話す練習は、場面の確認にとどめる

登壇の前に、話す練習をします。ただし、原稿を読み上げる練習にはしません。

  • 話す場面を一つずつ確かめる：最初に任された仕事、そのときに何をしたか
  • 質問を三つほど投げてみる：体験談で多い質問を人事が聞き、答え方を一緒に考える
  • 答えにくい質問の返し方を決める：「それは人事からお答えします」と言ってよいこと
  • 言い回しは直しすぎない：本人の言葉のほうが、学生には伝わる

原稿を作り込むと、話が整いすぎて、学生の質問に答えるときに戸惑います。場面さえ決まっていれば、言葉は本人に任せます。

断られたときの考え方

登壇を断られることは珍しくありません。断られたときは、理由を聞いて、頼み方を変えます。

  • 時間が取れない：話す時間を短くする、質問の時間だけに出てもらう
  • 人前で話すのが苦手：一人で話すのではなく、人事との対話の形にする
  • 何を話せばよいか分からない：話す場面を人事と一緒に一つ選ぶところから
  • 上司が難色を示している：回の目的と、本人に頼む理由を上司に説明する

それでも難しければ、無理に頼まず、ほかの人を探します。嫌々出た社員の話は、学生にも伝わります。

社内の分担

作業誰が

エージェントベストの見解

これは契約後に起きることの話です。イベントを開き始めた年は、登壇してくれる社員が見つかります。問題は二回目、三回目です。最初に登壇した社員に、次の回も頼み、その次も頼む。一人に集中した結果、本人が疲れて次の年は断られます。当社が勧めるのは、一回目の登壇が終わった時点で、次の登壇者の候補をもう一人決めておくことです。一回目の登壇者に、次の回では二人目の組み合わせとして出てもらい、もう一人を隣に座らせる。こうすると、二人目は一度横で見てから自分の番を迎えられ、登壇者が少しずつ増えていきます。登壇者が一人しかいない状態は、その人が異動した時点で回が止まります。回のあとに反応を戻すことも、続けてもらう理由になります。

まとめ

  • 登壇する社員は、話のうまさではなく、回で確かめてもらうことに自分の経験で答えられるかで選ぶ
  • 登壇者を先に決めず、回の目的と学生が確かめたいことから逆算する
  • 一人で足りなければ、入社年次や職種の違う二人を組み合わせる
  • 頼むときは上司の合意を先に取り、話してよい範囲を一枚で渡す。難しかったことも話してよいと伝える
  • 練習は場面の確認にとどめ、登壇者を一人に集中させず、次の候補を早めに決める

よくある質問

若手社員に登壇を頼むと、話が拙くならないか心配です

話の上手さより、自分の経験の具体が学生には伝わります。話す場面を一緒に選び、答えにくい質問を人事に回してよいと決めておけば、若手でも十分に話せます。不安なら、人事との対話の形にすると負担が小さくなります。

経営者が登壇したがります。止めたほうがよいですか

止める必要はありません。会社の方向を話す役として、回の最初か最後に短く出てもらう形が向いています。本題の最初の一年の話は、それに答えられる若手に任せると、回の目的と役割が揃います。

登壇者選びは、御社に相談できますか

できます。当社は、回の目的からの逆算、組み合わせの考え方、頼むときの一枚の型、練習の進め方を支えられます。登壇者への依頼と、上司の合意を取ることは企業が行ってください。当社は求人広告代理店として、媒体選びから運用までを支えています。
