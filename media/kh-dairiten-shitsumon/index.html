「代理店と話すことになったが、何を聞けばいいか分からない」という声を、初めて採用媒体を検討する担当者から聞きます。結論から言うと、聞くことは4つの段階に分かれます。申込前に「中立か・根拠は何か・時間はどれくらいか」、申込時に「契約の形・請求・更新」、申込後に「相談の範囲・報告・見直し」、やめるときに「引き継ぎ・解約」です。 質問は代理店を試すためではなく、自社が申込後に止まらないための確認です。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーですが、この記事の質問は当社にもそのまま聞いてください。答えられない質問があれば、それは当社の課題です。

質問の前に用意するもの

質問の前に、自社の条件を用意します。条件がないと、代理店は答えようがなく、質問も「一般論はどうですか」になります。

  1. 採用人数と時期：何人を、いつまでに
  2. 採りたい人物像：条件で言える形に。卒年、学部、志向、経験
  3. 社内で動ける人と時間：誰が、週に何時間
  4. 中途採用の予定：同じ場で集めるか、別にするか
  5. いま使っている媒体と、その状況：使っているなら、動いているか止まっているか

この5つを1枚に書いて持っていくと、質問への答えが自社向けになります。この準備は採用媒体を代理店経由で申し込むメリットでも書きました。

申込前に聞く質問

申込前は、代理店を選ぶ段階です。中立か、提案に根拠があるか、申込後に何をしてくれるかを聞きます。

質問答えの見方
どの媒体を扱っていますか自社が使いたい媒体が含まれているか。扱っていない媒体は別窓口
どの媒体を勧めても、御社の収入は変わりませんか率直に答えるか。詰まるなら中立を売りにできない
うちの条件だと、どの媒体を先に検討すべきですか。理由は理由が自社の条件（人数・時期・人物像・時間）から組み立てられているか
うちの条件だと、後回しでいい媒体はどれですか「向かない」を言えるか。全部を勧める提案は比較していない
うちは、いま申し込むべきですか「先に固めることがある」と言えるか
申込後、社内で誰が週に何時間やることになりますか具体的に答えられるか。答えられないなら申込後を見ていない
申込後に、何を、どのくらいの頻度でやってくれますか申込のみ・相談まで・代行までのどれか
運用代行を頼まない場合、自社で回る媒体はどれですか代行前提の提案になっていないか

中立性の見分け方は代理店の提案が中立かどうかの見分け方で詳しく書きました。

自社に合う媒体がどれか、3媒体を並べてご案内します。この記事の質問を、そのまま聞いてください。

媒体選びを相談する

エージェントベストの見解

相談で最も多い思い込みは、「細かく質問すると、営業がしつこくなる」というものです。実際には逆で、条件を出して具体的に質問する会社ほど、代理店は答えやすく、申込を急かす理由もなくなります。「まだ決めていない」「いまは申し込まない」と言われても、条件が分かっていれば、次に相談が来たときに続きから話せるからです。当社が3媒体すべての販売パートナーとして相談を受けるとき、いちばん困るのは質問が多い会社ではなく、条件が無く「おすすめは何ですか」だけを聞かれる会社です。答えようがないので、一般論になり、お互いの時間が無駄になります。質問は多いほど、答えも具体的になります。この記事の質問を全部持ってきていただいて構いません。

申込時に聞く質問

申し込むと決めたら、契約と請求の形を確認します。稟議と経理に関わる項目です。

  1. 契約の相手は、媒体ですか、御社ですか：契約書に誰の名前が載るか
  2. 請求は誰から、いつ、どの単位で来ますか：締め日と支払日
  3. 見積もりの内訳で、媒体の料金と、それ以外の費用は分かれていますか：合計だけでなく行で見る
  4. いま使えるキャンペーンはありますか。条件と期限と、終了後の料金は：キャンペーンで媒体を決めない
  5. 契約期間と、更新の方式、解約の期限は：自動更新なら期限をカレンダーに
  6. 複数媒体をまとめて請求できますか：契約の形で変わる
  7. 稟議に出す書類を揃えてもらえますか：見積書、提案書、媒体の資料、契約書のひな形、運用に必要な時間の見積もり

契約と請求の流れは代理店経由の契約と請求の流れ、料金が変わらない仕組みは代理店経由でも料金が変わらない理由で書きました。

申込後に聞く質問

申込後は、運用が止まらないための確認です。申込時に聞いておくのが理想ですが、申込後に改めて確認しても遅くありません。

質問答えの見方
最初の1ヶ月で、社内がやることは何ですか人物像の確定、文面の確認、面談の枠の用意、が出てくるか
止まりかけたとき、御社は気づけますか。どう連絡してくれますか送信数や更新を見ているか。声をかける仕組みがあるか
報告は、何を、どのくらいの頻度でもらえますか送信数・承認数・面談数など。週次か月次か
条件や文面の見直しは、誰が、何を根拠に行いますか面談の結果を戻す流れがあるか
媒体に聞きたいことがあるとき、御社経由で聞けますか取り次ぎの範囲
運用代行を頼む場合、頼める作業と頼めない作業は検索・文面・送信・一次返信は頼め、人物像と面談は頼めない

代行の範囲は代理店に運用まで頼めるかで書きました。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。「社内で誰が週に何時間か」まで答えます。

運用の相談をする

やめるとき、変えるときに聞く質問

契約の終わりと、代理店の切り替えは、申込時に聞いておくと困りません。

  1. 契約を終えるとき、いつまでに、誰に、どう伝えますか
  2. 御社に頼んだ文面と検索条件は、書面でもらえますか：企業の名義で送った文面は、自社で使い続けられるか
  3. 管理画面のアカウントとデータは、契約が終わっても残りますか
  4. 代理店を変える場合、媒体との契約は残りますか：契約の形で変わる
  5. 効いた文面や条件の記録を、まとめてもらえますか

切り替えの注意は代理店を切り替えるときの注意で書きました。「やめるとき」を申込時に聞くのは失礼ではありません。答えられる代理店は、引き継ぎまで設計しています。

エージェントベストの見解

これをやる前に、先に決めておかないと質問が空回りすることがあります。質問の前に、自社の条件（人数・時期・人物像・時間・中途の予定）を1枚に書くことです。当社が相談を受けるとき、条件が書かれた1枚を持ってきた会社との打ち合わせは、最初の数分で媒体の候補が絞れ、残りの時間を運用の設計に使えます。条件が無い会社との打ち合わせは、最初から最後まで条件を聞き出すことに使われ、質問に答える時間が残りません。同じ1時間でも、中身が違います。質問リストを用意するより先に、条件の1枚を用意する。それだけで、代理店から引き出せる答えの質が変わります。書けない項目があれば、それを「一緒に決めたい」と最初に言ってください。そこから始めます。

まとめ

  • 質問は申込前・申込時・申込後・やめるときの4段階に分かれる。目的は自社が止まらないための確認
  • 質問の前に、人数・時期・人物像・時間・中途の予定を1枚に書く。条件が無いと答えは一般論になる
  • 申込前は中立性と提案の根拠と申込後の範囲、申込時は契約の形と請求と更新、申込後は報告と見直し、やめるときは引き継ぎを聞く
  • 「やめるとき」を申込時に聞くのは失礼ではない。答えられる代理店は引き継ぎまで設計している
  • 細かく質問するほど、代理店は答えやすく、申込を急かす理由もなくなる

よくある質問

質問が多すぎると、代理店に嫌がられませんか

条件を出したうえでの質問なら、嫌がられることはほぼありません。むしろ、条件が無く「おすすめは」だけを聞かれるほうが、代理店は困ります。この記事の質問を全部持っていって構いません。答えられない質問があれば、それがその代理店の弱い部分です。

電話とメール、どちらで聞くのがよいですか

最初の相談は、条件を伝えながら話せる打ち合わせ（対面かオンライン）が向きます。契約の形や請求など、記録が要る項目は、打ち合わせのあとにメールで確認し、書面で残します。稟議に使う書類は、メールで受け取っておくと社内に回しやすいです。

御社に、この質問をそのまま聞いてもよいですか

構いません。当社はOfferBox・Wantedly・ワンキャリアの販売パートナーとして、この記事の質問には全部答えるつもりで書いています。答えに詰まる質問があれば、それは当社が直すべき点です。3媒体の全体像は3媒体の違いと選び方にまとめています。

OfferBox・Wantedly・ワンキャリアを、ひとつの窓口で

エージェントベストは3媒体の販売パートナーです。媒体の比較からお申込み、運用まで伴走します。料金は各媒体の正規料金のままです。

  • 代理店を比較するときの軸｜扱う媒体、中立性、申込後の範囲、担当の体制、引き継ぎ
