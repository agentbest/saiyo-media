インサイドセールスの長期インターン生の最初の1か月｜任せる仕事と育て方

インサイドセールスの長期インターン生は、最初の1か月の過ごし方で、その後も続くかどうかが分かれやすい職種です。初日から電話をかけ続けてもらうと、断られる経験が重なり、話し方を直す前に気持ちが折れてしまうことがあります。結論から言うと、インサイドセールスの最初の1か月は、「聞く」「型を覚える」「メールで連絡する」「電話をかける」の順に週ごとに一段ずつ任せ、毎日の振り返りで型を一緒に直していくと、断られても続けられる土台ができます。 この記事では、1か月後に目指す状態、週ごとの組み方、振り返りの仕方、つまずきやすい点を整理します。原稿の書き方はインサイドセールスの長期インターン求人原稿で書いています。

1か月後に目指す状態

受け入れの前に、1か月が終わったときの状態を決めます。インサイドセールスでは、次の三つが目安です。

  • 型に沿って一件の連絡を進められる：最初の一言から、困りごとを伺い、次の動きを決めるまでを一人で進められる
  • 記録を次の人が使える形で残せる：話した内容と次の動きを、営業担当が読んで分かる形で記録できる
  • 断られた連絡を振り返れる：どこで話が止まったかを記録から見つけ、次の一言を考えられる

件数や打ち合わせの数は、この時点では目指す状態に入れません。件数を追うのは、型と記録が安定してからです。決めた状態は初日に学生に伝え、1か月の終わりに一緒に確かめます。

1週目｜聞いて、商材と相手を知る

最初の週は、電話をかけずに、聞くことに集中します。

  • 商材の説明資料を読み、相手の会社がどんな困りごとを持っているかを担当社員から聞く
  • 社員の電話を横で聞き、相手の反応と社員の返し方を書き留める
  • これまでの連絡の記録を読み、うまく進んだ連絡と止まった連絡の違いを考える
  • その日の終わりに、聞いた電話の中で印象に残った一言を担当社員と話す

社員の電話を聞く時間は、ただ待っている時間ではありません。「相手が話し始めたのはどの質問のあとか」を書き留めてもらうなど、聞く目的を一つ渡します。通話の録音を使う場合は、社内の情報の扱いのルールに沿って、どこで、誰が聞けるかを決めておきます。ルールの決め方は長期インターン生の情報管理で整理しています。

2週目｜型を覚え、練習する

2週目は、話す内容の型を覚えて、社内で練習します。

  • 最初の一言、困りごとを伺う質問、次の動きの決め方の型を渡す
  • 担当社員を相手役にして、型に沿って話す練習をする
  • よくある断り方（今は忙しい、担当ではない、検討していない）への返し方を一緒に考える
  • 記録の型を渡し、練習の内容を記録する練習もする

練習では、うまく話せたかより、型のどこで止まったかを見ます。止まった場所が分かれば、その部分の言い方を学生と一緒に直せます。型は会社が渡すものですが、学生が話しやすい言い方に少し変えてよいことも伝えておくと、本番で自分の言葉として話せます。

インサイドセールスのインターン生に、どの週に何を任せるか。受け入れの組み方から相談できます。

無料で相談する

エージェントベストの見解

インサイドセールスの受け入れで、最初の1か月のうちに学生が離れてしまう会社に共通するのは、1週目から電話の件数を任せていることです。人手が足りないから採ったという事情は分かりますが、当社が受け入れの相談を受ける中で見えるのは、型の練習をしないまま電話をかけた学生ほど、断られた理由を自分の性格のせいにしてしまう流れです。理由が分からないまま断られ続けると、学生は直し方が見えず、続ける意味を見失います。勧めているのは、電話を任せる前に「型のどこで止まったら、何を直すか」を一度だけ練習で体験してもらうことです。直し方を知っている学生は、断られても「次はこの質問を変えてみる」と考えられます。最初の2週を練習に使っても、その後に続けてくれるほうが、結果として受け入れの手間は少なくなります。

3週目｜メールでの連絡から始める

3週目から、実際のお客様への連絡を任せます。最初はメールからです。

  • 資料を請求した会社など、関心を持っている相手へのメールを型に沿って書く
  • 送る前に担当社員が確認し、直したところを学生に伝える
  • 返信が来たら、内容を記録し、次の動きを担当社員と決める

メールから始めるのは、学生が考える時間を持ちながら、相手とのやり取りを体験できるからです。返信が来たときの手応えは、電話をかける前の自信になります。メールの確認で担当社員が直す点が減ってきたら、次の週に進みます。

4週目｜電話をかけ、毎日振り返る

4週目は、担当社員がそばにいる時間に、電話をかけてもらいます。

  1. 最初は、関心を持っている相手への電話から始める
  2. かける前に、相手の情報と記録を確かめる
  3. かけたあとに、記録を残す
  4. その日の終わりに、記録をもとに、うまく進んだ一件と止まった一件を担当社員と振り返る

振り返りでは、止まった一件について「どの質問のあとで止まったか」「次は何を変えるか」を学生に話してもらいます。担当社員が答えを言うより、学生が自分で次の一言を考えるほうが、型が学生のものになります。1か月の終わりには、初日に伝えた三つの状態を一緒に確かめ、次の月に任せる相手の範囲や、件数を持つかどうかを話し合います。評価の伝え方は長期インターン生の評価とフィードバックの返し方を参考にしてください。

担当社員の関わり方

最初の1か月、担当社員に持ってもらうことは次の三つです。

  • 電話をかける時間にそばにいる：特に4週目は、学生が電話をかける時間帯に担当社員が席にいるように予定を組む
  • 強い断りを受けたときの引き継ぎ：相手が強い口調だったときは、担当社員に代わってよいと伝えておく
  • 毎日の短い振り返り：長い時間は要らない。一件ずつ、止まった場所と次の一言を話す

インサイドセールスの仕事は、相手の会社の営業時間に合わせて平日の日中が中心になります。学生の勤務の日時は授業を優先して組み、試験期間の扱いも先に話しておきます。インターン生の労働時間や学業への配慮には、法令で定められた項目や指針があるため、勤務の組み方は社労士や公式の案内で確認しておきます。

つまずきやすい点

インサイドセールスの最初の1か月で、よく起きるつまずきは次のとおりです。

  • 型を渡さず、「自由に話してよい」と任せてしまう
  • 記録の型がなく、学生ごとに書き方がばらばらになる
  • 件数だけを振り返り、話の中身を振り返らない
  • 担当社員が席を外している時間に電話をかけさせ、困ったときに相談できない

受け入れたあとの組み方や、型づくりで迷ったときも相談を受けています。いまの状況の整理だけでも構いません。

運用の相談をする

エージェントベストの見解

インサイドセールスの受け入れを始める前に、先に決めておきたいのは「記録の型」です。話す内容の型は多くの会社が用意しますが、記録の型は後回しにされがちです。記録の型がないと、学生が連絡した内容が営業担当に伝わらず、せっかく決めた打ち合わせで同じ質問を繰り返すことになります。そうなると営業担当は学生の記録を信用しなくなり、学生は自分の仕事が役に立っていないと感じます。記録の型は、相手の状況、困りごと、こちらが伝えたこと、次の動きの四つの欄があれば始められます。当社は人材紹介で営業系の中途採用にも関わっていますが、インサイドセールスの経験者が転職の場で評価されるのは、話し方より、次の人に渡せる記録を残せることだと見ています。インターン生にも、記録を残す仕事の意味を最初の週に伝えておくと、仕事への向き合い方が変わります。

まとめ

  • 1か月後の状態は、型に沿って一件を進める・記録を残す・断られた連絡を振り返るの三つで決める
  • 1週目は聞く、2週目は型の練習、3週目はメール、4週目は電話と、一段ずつ広げる
  • 電話を任せたら、毎日、止まった一件と次の一言を振り返る
  • 担当社員は電話の時間にそばにいて、強い断りのときは引き継ぐ
  • 勤務は授業を優先して組み、法令に関わる点は社労士や公式の案内で確認する

よくある質問

人手が足りず、1週目から電話を任せたいです

最初から件数を任せるより、関心を持っている相手への電話に絞り、担当社員がそばにいる時間だけにすることを勧めます。型の練習を短くしてでも一度は行い、止まったときの直し方を知ってから始めると、続けやすくなります。

学生が電話を怖がっています。どうすればよいですか

メールでの連絡を長めに続け、返信が来る手応えを積んでから電話に移ります。最初の電話は、すでにメールでやり取りした相手にかけると、話が進みやすく、怖さが和らぎます。やる気が下がったときの関わり方は長期インターン生のやる気が下がったときも参考になります。

型を学生が自分で変えてもよいですか

言い方を話しやすく変えるのは構いません。ただし、伺う質問や次の動きの決め方は変えずに、変えた言い方は振り返りで担当社員と共有してもらいます。うまくいった言い方は、型に取り込んでほかの学生にも使ってもらえます。
