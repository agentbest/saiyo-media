承認のあと、面談の前に、学生から質問が届くことがあります。「勤務地はどこですか」「面談は選考ですか」「残業はどのくらいですか」。ここでの答え方が、面談に来るかどうかを決めます。結論から言うと、学生からの質問には、当日に、結論から、隠さずに、次に何が起きるかを添えて答えます。分からないことは「確認して〇日までに」と期限を添え、文面で答えきれないことは面談で話すと伝えます。答えにくい質問ほど、ぼかさずに事実を短く書きます。 ぼかした答えは、学生に「隠している」と伝わり、面談の前に離れます。この記事では、質問の型ごとの答え方、答える文面の型、分からないときの対応、面談に持ち越す判断、答えにくい質問への書き方、質問の蓄積、やりがちな失敗、分担を整理します。承認直後の返信は承認されたあとの連絡手順で書きました。この記事は、その後に届く質問への対応です。

この作業の目的｜質問を、面談に来る理由に変える

学生が質問を送るのは、興味があるからです。興味が無ければ、質問せずに離れます。質問は、学生が「確かめたい」と思っている印で、答え方次第で「来る理由」にも「来ない理由」にもなります。

答え方の目的は、学生の疑問を解消することだけではなく、「この会社は質問にきちんと答える」と感じてもらうことです。速さ、結論の明確さ、隠さない姿勢。この3つが伝わると、質問の内容が何であれ、学生は面談に来ます。

手順1｜質問の型と、答え方

学生からの質問は、型が決まっています。型ごとに答え方を用意します。

質問の型例答え方
仕事の中身「具体的にどんな仕事ですか」「1日の流れは」場面で答える。文面の本文と企業ページと揃える。詳しくは面談で名義の人が話すと添える
勤務地と条件「勤務地は」「転勤は」「給与は」「残業は」募集要項に書いた内容を、正確に短く。募集要項の該当箇所を示す。書き方は募集要項の書き方
選考の流れ「承認したら選考ですか」「何段階ですか」「いつ結果が出ますか」面談は選考ではないこと、段階の数、期間の目安。流れはOfferBox経由の学生が選考途中で離脱する理由
面談の位置づけ「面談で何を聞かれますか」「準備は」評価しないこと、仕事の話をすること、準備は不要。型は初回面談の設計
服装や接続「服装は」「オンラインのつなぎ方は」指定が無ければ「自由」と明記。接続は案内を再送
他社との違い「〇〇社と何が違いますか」他社を下げない。自社の仕事の中身と人の話で答え、比較は学生に任せる
答えにくい質問「離職は多いですか」「残業の実態は」「クチコミに書かれていることは本当ですか」事実を短く、取り組みを添える。ぼかさない。次の手順で詳しく

「勤務地と条件」と「答えにくい質問」で、答え方に差が出ます。ここをぼかすと、面談の前に離れます。

手順2｜答える文面の型

答える文面は、次の型で固定します。長くしません。

  1. お礼：「ご質問ありがとうございます」の一言
  2. 結論：質問への答えを、最初に。「勤務地は〇〇です」「面談は選考ではありません」
  3. 補足：結論に必要な範囲で、一言か二言。「転勤は入社後数年で可能性があります」「面談では仕事の話をします」
  4. 次に何が起きるか：「面談の日程はこのままで」「詳しくは面談で〇〇が話します」
  5. 名義：オファーの名義の人か、人事。人事なら名義の人の一言を添える

結論を最初に置くのは、学生が知りたいことを先に渡すためです。「ご質問の件ですが、弊社としましては」から始まる文面は、結論にたどり着く前に読まれなくなります。

いま使っている媒体の運用の相談だけでも構いません。学生からよく来る質問と、その答えの型を一緒に作ります。

運用の相談をする

エージェントベストの見解

相談で最も多い思い込みは、「答えにくい質問は、面談で会ってから話したほうがよい」というものです。実際には、文面でぼかして面談に持ち越すと、学生は「聞いたのに答えなかった」と受け取り、面談の前に離れるか、面談に来ても構えています。当社は求人広告代理店としてOfferBoxの契約後の運用を見ていますが、残業や離職についての質問に、文面で事実を短く答えた会社のほうが、面談への出席が安定しています。答えは、学生が満足する内容である必要はありません。「残業は月によって差があり、繁忙期は増えます。減らす取り組みとして〇〇をしています」のように、事実と取り組みを短く書く。学生が知りたいのは、良い答えではなく、正直な答えです。面談に持ち越してよいのは、「文面では長くなる話」であって、「答えにくい話」ではありません。

手順3｜分からないときと、面談に持ち越すとき

その場で答えられない質問と、文面では答えきれない質問があります。

分からないとき

  • 「確認して、〇日までにご連絡します」と、期限を添えて返す。当日中に、分からないことだけを先に返す
  • 期限までに答える。期限を過ぎるなら、過ぎる前に「もう少しかかります」と一言
  • 社内の誰に聞くかを決めておく。勤務地と条件は人事、仕事の中身は名義の人、制度は総務、のように

面談に持ち越すとき

  • 持ち越してよいのは、「文面で書くと長くなる話」「実際の仕事を見せながらのほうが伝わる話」。仕事の中身の詳細、チームの雰囲気、キャリアの道筋など
  • 持ち越すときは、文面で「概要」だけ答え、「詳しくは面談で〇〇が話します」と、誰が話すかまで書く
  • 「面談で話します」だけで終えない。概要が無いと、ぼかしたと受け取られる
  • 答えにくい質問は持ち越さない。事実を文面で先に

「分からない」と「持ち越す」を混ぜないことも大事です。分からないことを「面談で」と言うと、面談でも答えられず、信頼を失います。

手順4｜答えにくい質問への書き方

残業、離職、給与の実態、クチコミに書かれていること。学生が聞きにくい質問を、あえて聞いてきたときの書き方です。

質問書き方の型
残業の実態「月によって差があり、〇〇の時期は増えます。減らす取り組みとして△△をしています」。数字は募集要項に書いた範囲で。書いていないなら「募集要項に記載の範囲です」
離職について「入社して数年で離れる人はいます。理由として多いのは〇〇で、△△を直しています」。隠さない。多いか少ないかの評価はしない
クチコミに書かれていること「読みました。書かれている〇〇は事実で、△△に取り組んでいます」または「〇〇は以前の状態で、いまは△△です」。向き合い方はワンキャリアとOpenWorkの違い
給与の実態募集要項の範囲で正確に。「当社規定による」は避ける。個別の額は面談か選考で
配属の希望が通るか「希望を聞いたうえで、〇〇の事情で決まります。通らないこともあります」。通ると言い切らない

共通するのは、「事実を短く」「取り組みを添える」「評価しない」「言い切らない」です。良く見せようとした瞬間に、学生は気づきます。

手順5｜質問を蓄積して、企業ページと募集要項に戻す

同じ質問が複数の学生から来るなら、それは企業ページか募集要項に書かれていないことです。

  1. 質問を記録する：誰から、いつ、何を聞かれ、どう答えたか
  2. 月に一度、同じ質問をまとめる：勤務地、面談の位置づけ、残業、のように型で
  3. 企業ページと募集要項に、答えを書く：聞かれる前に読める状態にする。整え方は企業ページで伝えること
  4. 文面のテンプレートに、よく聞かれることを一言足す：「面談は選考ではありません」を締めに入れる、など
  5. 答えの型をFAQとして持つ：担当が変わっても同じ答えができる。引き継ぎの資料にも

質問が減ることが、企業ページと募集要項が整った印です。質問がゼロになる必要はありませんが、同じ質問が繰り返し来るなら、書く場所に戻します。

申込前に、運用に必要な時間の見積もりだけでも聞いてみませんか。質問への返信の時間と、蓄積の仕組みまでお伝えします。

媒体選びを相談する

やりがちな失敗

失敗何が起きるか直し方
返信が翌日以降面談の前に温度が下がる当日に。分からなければ「確認します」だけ先に
結論が最後読まれない結論を最初に
答えにくい質問をぼかす隠していると伝わる事実を短く、取り組みを添える
「面談で話します」だけで返すぼかしたと受け取られる概要を書いて、誰が話すかを添える
分からないことを「面談で」と言う面談でも答えられない「確認して〇日までに」
他社を下げて答える信用を失う自社の話だけ
長く書く読まれない型の5つで短く
質問を記録しない同じ質問が来続ける記録して企業ページに戻す
名義がばらばら誰と話しているか分からなくなる名義の人か、人事が名義の一言を添えて

最も多いのは、「答えにくい質問をぼかす」です。良く見せたい気持ちが、正直さより先に出ると、こうなります。

社内の分担

作業誰が
質問を当日に受け取り、返す人事（または運用代行。名義の一言を添える）
仕事の中身の質問に答える材料名義の人（人事が聞いて書く）
勤務地と条件の確認人事
制度や実態の確認人事（総務や現場に聞く）
答えの型とFAQを作る人事

運用代行に出している場合、質問への一次返信と、FAQに沿った回答は代行が行えます。答えにくい質問への事実と取り組みは、企業が決めて代行に渡します。代行が事実を想像で書くことはできません。

エージェントベストの見解

申し込んだあと、質問への返信で最初の月に起きやすいのは、「返信が翌日以降になり、面談の前に学生が離れる」ことです。承認への返信は当日と決めていても、その後の質問は「あとで答えよう」になりがちです。当社がOfferBoxの運用代行で返信を担うときは、質問も承認と同じ「当日」の枠で扱い、FAQに沿って答えられるものはその場で、分からないものは「確認して〇日までに」だけを当日に返します。企業には、答えにくい質問への事実と取り組みを、最初の打ち合わせでFAQとして決めてもらいます。決まっていれば、代行でも当日に返せます。決まっていなければ、当社は返せず、企業に聞き、返信が遅れます。質問への答えは、学生から聞かれてから考えるものではなく、聞かれる前に決めておくものです。

まとめ

  • 学生からの質問には、当日に、結論から、隠さずに、次に何が起きるかを添えて答える
  • 型は、お礼→結論→補足→次→名義。長くしない
  • 分からないことは「確認して〇日までに」。文面で長くなる話は概要を書いて面談へ。答えにくい話は持ち越さない
  • 答えにくい質問は、事実を短く、取り組みを添え、評価せず、言い切らない
  • 質問を記録し、同じ質問が来るなら企業ページと募集要項に書く。答えの型をFAQとして持つ

よくある質問

残業や離職について聞かれました。正直に書くと来なくなりませんか

ぼかしたほうが来なくなります。学生は「隠している」と受け取り、面談の前に離れるか、来ても構えています。事実を短く書き、取り組みを添えれば、満足する答えでなくても「正直な会社」と伝わり、面談に来ます。来なかった学生は、面談のあとで辞退する学生です。

質問が多くて、返信に時間がかかります

同じ質問が繰り返し来ているなら、企業ページと募集要項に書かれていないことです。質問を記録して型でまとめ、書く場所に戻すと、質問は減ります。残った質問には、答えの型とFAQを用意しておけば、返信は短時間で済みます。

学生からの質問への返信は、御社に頼めますか

FAQに沿った回答と、一次返信は当社が行えます。答えにくい質問への事実と取り組みは、企業に決めていただき、FAQとして当社に渡してもらいます。当社がOfferBoxの運用代行を受けるときは、最初の打ち合わせでFAQを一緒に作ります。
