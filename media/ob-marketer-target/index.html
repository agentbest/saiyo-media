OfferBoxでマーケター志望の学生を見つける検索の考え方｜三つの行動で読む

OfferBoxでマーケターを採るとき、検索条件で最初にぶつかるのは「マーケ志望の学生は多いのに、自社のマーケに合う学生が見つからない」という問題です。結論から言うと、マーケターの検索は「マーケ志望」や「SNSが得意」で探すのではなく、「どのマーケか」で求める行動を決め、学生が書いた数値の大小ではなく「試した・測った・直した」の行動で読みます。 マーケ志望の学生の多くはSNSの運用経験を書きますが、自社のマーケがSNSでないなら、その経験は自社の仕事と離れています。探すのは経験の種類ではなく、行動の型です。この記事では、マーケター志望の学生がプロフィールに何を書いているか、検索条件の組み方、自由記述の読み方、文面と面談への接続を整理します。検索項目の名称や仕様には触れず、考え方だけを書きます。現在の項目は管理画面とヘルプで確認してください。文面の書き方はOfferBoxでマーケターを採るオファー文面の書き方で書きました。

マーケター志望の学生がプロフィールに書いていること

マーケターを志望する学生のプロフィールには、二つの傾向があります。一つは、SNSの運用、イベントの集客、アルバイト先の販促など、「人を集めた」経験が書かれていることです。もう一つは、その経験が「フォロワーが何人になった」「来場者が何倍になった」のように、結果の数値で書かれていることです。

結果の数値は、確認できません。数値の大小で学生を見ると、大きい数字を書いた学生に偏ります。見るのは、その数字に至るまでに「何を変えて、何を見て、次に何をしたか」です。

学生が書いていることマーケターの検索で読み替えると
新歓の告知を、投稿の時間帯を変えて出し、反応を比べて時間を決めた試して、測って、決める
イベントの集客で、チラシと投稿のどちらから来たかを聞いて集計した何から来たかを測る
アルバイト先で商品の置き場所を変え、売れ方の違いを見た変えて、反応を見る
動画の冒頭を変えて、最後まで見られる割合が変わるか試した一つだけ変えて、比べる
うまくいかなかった投稿を分析し、次の投稿で直した外れたあとに、直す

「試して、測って、直した」の三つが、マーケターの検索で読む行動です。この行動は、SNSの運用以外にも見つかります。研究で条件を変えて結果を比べた理系の学生、営業のアルバイトで話し方を変えて反応を比べた学生、サークルの会計で支出を分けて見た学生の中に、この行動があります。

検索・ターゲットの考え方｜「どのマーケか」で求める行動を決める

マーケターの検索条件は、次の手順で組みます。

  1. 「何を売る会社の、どのマーケか」を一つ決める：広告の運用、SNS、記事や動画、調査、商品企画のどれか。マーケの責任者と決める
  2. そのマーケで求める行動を三つ書き出す：広告の運用なら「一つだけ変えて比べる」「毎日見て直す」、調査なら「何から来たかを測る」など
  3. 条件を三段に分ける：譲れない条件、あればよい条件、見ない条件
  4. SNSの運用経験を、あればよい条件に置く：自社のマーケがSNSであっても、譲れない条件にしない
  5. 検索の名前を「どのマーケか」で付ける：「マーケ」の一語で付けない

三段の分け方は、他の職種と同じです。

  • 譲れない条件：卒業年、勤務地の可否、入社時期。面談まで進めても変えられないもの
  • あればよい条件：志望職種「マーケティング」、専攻（統計、心理、経営など）、SNSや集客の経験。入っていれば優先するが、外れていても読む
  • 見ない条件：大学名、学生が書いた数値の大小

学生が書いた数値の大小を見ない条件に置くのは、マーケターの検索で特に重要です。フォロワーの数、来場者の数、売上の伸びは、学生が書いた数字で、確認できません。数字が大きい学生が、試して測って直した学生とは限りません。ターゲット設計全体の考え方はOfferBoxのターゲット設計で書きました。

マーケターの検索が「マーケ志望」と「SNS経験あり」で止まっている。そう感じたら、自社のマーケで求める行動を三つ書き出すところから。

運用の相談をする

エージェントベストの見解

マーケターの検索で、当社が先に直してもらうのは「学生が書いた数字の読み方」です。マーケ志望の学生のプロフィールには、フォロワー数、来場者数、売上の伸び率のような数字が並びます。この数字を見て「実績のある学生」と読む会社がありますが、学生が書いた数字は確認できず、数字の大きさと、その学生が何をしたかは別のことです。当社は3媒体すべての販売パートナーとしてOfferBoxの契約後の運用を見ていますが、マーケターで面談後に進んでいる会社は、数字の大小ではなく、数字の前に書かれている「何を変えたか」「何を見たか」を読んでいます。フォロワーが少なくても、投稿の時間帯を変えて反応を比べた学生は、広告の運用で同じことをします。フォロワーが多くても、何を変えたかが書かれていない学生は、面談で聞いても「続けていたら増えた」で終わることがあります。数字は、学生が書いた「結果」で、会社が見るのは「過程」です。学生の数字を評価の材料にしないことが、マーケターの検索で最初に決める読み方です。

自由記述をどう読むか｜「試した・測った・直した」の三つ

検索で絞ったあと、送る相手を決めるのは自由記述です。マーケターの場合、自由記述で見るのは次の三つです。

  • 試したか：何かを変えた記述があるか。「頑張って投稿した」ではなく「時間帯を変えた」「文言を変えた」
  • 測ったか：変えた結果を、何かで見た記述があるか。「反応が良かった」ではなく「どの投稿がどう違ったか」
  • 直したか：測った結果から、次に何をしたか。一度で成功した話より、外れて直した話

三つが揃っている学生は多くありません。二つあれば送る相手に入れます。「センス」「発想力」「トレンド」の言葉があるかは見ません。「バズった」「話題になった」のような結果の言葉も見ません。プロフィールの読み方はOfferBoxの学生プロフィールの読み方で書きました。

読んで見つけた行動は、文面の書き出しに使います。「投稿の時間帯を変えて反応を比べた」を見て送ったなら、その行動に触れ、自社の広告の運用で同じことをする、とつなげます。

多すぎるときの絞り方と、少ないときの広げ方

マーケターの検索は、「どのマーケか」によって、多すぎる場合と少なすぎる場合の両方があります。

多すぎるときは、次の順で絞ります。

  1. 「どのマーケか」で求める行動を一つ足す：広告の運用なら「一つだけ変えて比べる」、調査なら「何から来たかを測る」で、読む基準を狭める
  2. 「測った」記述がある学生に絞る：試しただけの学生を外す
  3. 専攻をあればよい条件に入れる：統計や心理を優先する。譲れない条件にはしない

少なすぎるときは、次の順で広げます。

  1. 志望職種の絞りを外す：企画、営業、事務を選んでいる学生の中に、試して測った学生がいる
  2. SNSや集客の経験の絞りを外す：研究で条件を変えて比べた学生、アルバイトで置き場所を変えた学生は、経験の種類は違っても行動は同じ
  3. 専攻の絞りを外す：マーケターは専攻を問わないことが多い

どちらの場合も、「試した・測った・直した」の行動で読むことは変えません。条件が広すぎるときの直し方はOfferBoxの検索条件が広すぎるときで書きました。

選考への接続

検索で見つけた学生は、文面と面談でも「同じ行動」と「同じマーケ」で見ます。

  • 検索で使った行動を、文面の書き出しに使う：「一つだけ変えて比べた」を見て送ったなら、その行動に触れる
  • 文面には、検索の元になった「どのマーケか」と、見る数字を書く：「マーケティング全般」で止めない
  • 面談で、同じ行動を学生に聞き、自社の数字を見せられる範囲で見せる：面談に出るのは、そのマーケを回している人
  • 学生の数字は、面談でも評価しない：聞くのは「何を変えて、何を見て、次に何をしたか」

検索、文面、面談で見るものが揃っていると、「どの検索で見つけた学生が、面談まで来て、その先に進んだか」が読めます。効果の見方はOfferBoxの効果測定で書きました。

SNSが得意な学生を探しているが、自社のマーケはSNSではない。そう感じたら、経験の種類ではなく行動の型で探すところから。

運用の相談をする

エージェントベストの見解

マーケターの検索で、発注側がよく誤解しているのは「マーケ志望の学生を探す＝SNSが得意な学生を探す」という考え方です。学生の側でSNSの運用経験が書きやすいので、検索でもSNSの経験が目に付きます。ただ、自社のマーケが広告の運用や調査や商品企画であれば、SNSの経験は自社の仕事と離れていて、文面でつながりが書けません。当社が運用を見ている会社で、マーケターの面談後に進んでいる会社は、「どのマーケか」を先に決め、SNSの経験ではなく、そのマーケで求める行動で探しています。広告の運用なら「一つだけ変えて比べた」学生、調査なら「何から来たかを測った」学生、商品企画なら「変えて反応を見た」学生です。SNSの経験は、その行動が書かれていれば材料になりますが、SNSであること自体は材料になりません。マーケターの検索で最初に決めるのは、SNSの経験の有無ではなく、「自社のマーケで、学生に何を毎日してもらうか」です。それが決まれば、探す行動も決まります。週の見直しの型はOfferBoxの週次レビューで書きました。

社内の分担

作業担当決めておくこと
「何を売る会社の、どのマーケか」の一つマーケの責任者（一人目なら経営者）検索・文面・面談で同じものを使う
そのマーケで求める行動三つマーケの責任者と担当「試した・測った・直した」を自社の仕事の言葉で
条件を三段に分けて検索を組む人事（または運用代行）数値の大小は見ない。SNS経験はあればよい条件
自由記述を読み、送る相手を決める人事（または運用代行）結果の数字ではなく、変えたこと・見たことで読む
検索条件と面談後の進み方の記録人事週に一つ動かし、翌週に見る
面談で同じ行動を聞き、自社の数字を見せるマーケの担当文面で触れた行動を最初の質問にする

検索条件そのものは人事が組めますが、「どのマーケか」と求める行動はマーケの責任者と決めます。ここが決まっていれば、読む作業は人事でも代行でも同じ基準でできます。

やりがちな失敗

失敗何が起きるか直し方
学生が書いた数値の大小で選ぶ確認できない数字で偏り、過程が読めない数値は見ない条件。何を変えて何を見たかで読む
「SNS経験あり」を譲れない条件にする自社の仕事と離れた経験の学生に偏るあればよい条件に置き、行動で読む
「センス」「発想力」の言葉で読むどの学生も同じに見える試した・測った・直したで読む
「どのマーケか」を決めずに組む全学生が相手になり、文面に書くことがない責任者と一つ決め、求める行動を三つ
条件を一度に複数変える何が効いたか分からない週に一つ動かし、記録を残す

まとめ

  • マーケ志望の学生はSNSの経験と結果の数値で自分を書く。数値の大小ではなく「試した・測った・直した」で読む
  • 「何を売る会社の、どのマーケか」を責任者と決め、求める行動を三つ書き出す
  • 条件は譲れない・あればよい・見ないの三段。SNS経験はあればよい条件、数値の大小と大学名は見ない条件
  • 経験の種類ではなく行動の型で探す。研究や販売の経験の中にも同じ行動がある
  • 検索・文面・面談で同じ行動を見る。学生の数字は面談でも評価せず、過程を聞く

よくある質問

フォロワーが多い学生は、やはり優先すべきではないですか

数の大小は確認できないので、優先の材料にはしません。優先するのは、その数字の前に「何を変えて、何を見たか」が書かれている学生です。フォロワーが多くても、それが書かれていない学生は、面談で聞いてから判断します。フォロワーが少なくても、投稿の時間帯や文言を変えて反応を比べた学生は、自社の広告や記事の運用で同じことをします。数字を材料にすると、大きい数字を書いた学生に偏り、過程が読めなくなります。

理系の学生にも送るべきですか

送ります。研究で条件を一つ変えて結果を比べ、外れた仮説を直した経験は、「試した・測った・直した」そのものです。広告の運用や調査のマーケでは、理系の学生の行動が自社の仕事に近いことがあります。文面では、研究の進め方を読んだことに触れ、自社の運用で同じことをする、とつなげます。SNSの経験の有無ではなく、行動で読みます。

マーケターの検索設計は、運用代行に頼めますか

頼めますが、「どのマーケか」と求める行動の三つは社内で決めておきます。代行に任せられるのは、決まった行動で検索を組み、自由記述を三つの行動で読み、送る相手を選び、面談後の進み方を記録する作業です。行動が決まっていないと、代行は「マーケ志望」と「SNS経験あり」で絞るしかなく、数字の大きい学生に偏る運用になります。範囲の決め方は運用代行に任せる範囲で書きました。
